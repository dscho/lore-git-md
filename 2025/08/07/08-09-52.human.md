This is part 2 of Patrick Steinhardt's 9-part series refactoring multi-pack index (MIDX) handling to better integrate with Git's object database (ODB) source system. The patch modifies `odb_find_source()` to return NULL rather than dying when it can't find a matching object directory, pushing the error handling to callers.

The change is a preparatory step for future patches that will need to handle missing sources gracefully. The patch updates three callers in `commit-graph` and MIDX writing code to maintain the existing die-on-error behavior, and adjusts the function's documentation to reflect its new contract.

This is a straightforward mechanical change that follows the series' theme of ODB source abstraction. The implementation looks clean, with clear documentation updates and consistent error handling at all call sites. As part of the larger refactoring effort, it helps pave the way for more flexible ODB source handling while maintaining current behavior for existing code paths.
