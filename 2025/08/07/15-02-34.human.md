This is a follow-up patch series to the already-merged `git repo info` command implementation, addressing final style nits from reviewers. The v9 series makes minor test formatting adjustments to align with Git's conventions, particularly around quoting style in test messages.

The changes are purely cosmetic, standardizing on the `${SQ}` convention for single-quote escaping in test output comparisons and fixing a few whitespace issues. The BUG() message format was also adjusted to put human-readable text first. These changes don't affect functionality, which was already approved and merged in v8 series.

Lucas Seiki Oshiro is submitting this v9 at the request of mentors Karthik Nayak and Patrick Steinhardt to clean up the few remaining style issues before final integration. The series maintains all the core functionality from v8, including the new `git repo info` command with its ability to report repository metadata like ref storage format, bare status, and shallow status in both key-value and nul-terminated output formats.

The patchset is ready for final inclusion, with all substantive review feedback already addressed in previous versions. This represents the completion of a successful GSoC project under Karthik Nayak and Patrick Steinhardt's mentorship, migrating repository metadata reporting from `git rev-parse` to a more structured command hierarchy.
