This is part 7 of Patrick Steinhardt's 9-part series refactoring multi-pack index (MIDX) handling to use the object database (ODB) source system. The patch focuses on updating MIDX writing operations to work with ODB sources rather than direct repository/object_dir parameters.

The changes modify MIDX writing functions across several files to:
- Replace `repository` and `object_dir` parameters with `odb_source` parameters
- Update callers in `builtin/multi-pack-index.c` and `builtin/repack.c` to use the new interface
- Remove now-redundant helper function `lookup_multi_pack_index()` since sources can be obtained directly
- Adjust path computations and file operations to use `source->path` instead of separate object_dir
- Maintain all existing functionality while simplifying the interface

Key technical details:
- Affects MIDX writing operations including `write_midx_file()`, `write_midx_file_only()`, `expire_midx_packs()`, and `midx_repack()`
- Updates path handling for MIDX files and related operations to use ODB source paths
- Preserves all existing flags and options while changing the parameter passing mechanism
- Modifies 4 files with 47 insertions and 51 deletions
- Continues the series' pattern of deduplicating information flow by using ODB sources consistently

The changes build on previous parts in the series (particularly part 6's MIDX loading refactoring) to complete the transition of MIDX operations to the ODB source system. The patch maintains behavioral compatibility while removing redundant parameter passing and centralizing path handling.
