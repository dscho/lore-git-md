This is a refactoring patch in Patrick Steinhardt's ongoing ODB source system integration series, specifically addressing how object database locality is tracked. The patch simplifies how Git determines whether an object source is local (the main repository) versus non-local (alternates/quarantine) by storing this information directly in the `odb_source` struct rather than recomputing it each time.

Taylor Blau provides a positive review, noting the change looks correct as long as the `->local` flag is properly set when the source matches the repository's primary objects directory. The change affects `packfile.c`'s `prepare_packed_git()` function, which is currently the only caller needing this information.

This appears to be a straightforward improvement that makes the code more maintainable by eliminating ad-hoc locality checks. The change aligns with the series' broader goal of cleaning up the ODB source interface. Taylor's review suggests the implementation is sound, though he implicitly confirms the assumption about proper flag setting rather than explicitly verifying it.
