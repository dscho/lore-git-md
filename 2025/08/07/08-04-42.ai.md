This is the third version of a series continuing the `the_repository` removal effort in the commit-graph subsystem, now expanded to 10 patches. The series systematically eliminates global state usage while enabling future pluggable object storage.

The v3 changes focus on integer type refinements based on maintainer feedback:
- Patch 3 now uses `unsigned` instead of `size_t` for commit-graph write parameters (`max_commits` and `size_multiple`), following Junio Hamano's recommendation
- Maintains all other v2 changes including the conversion to repository-specific hash algorithms and removal of redundant repository parameters
- Preserves the key architectural improvements from v2 that complete the commit-graph subsystem's independence from global state

The series has already addressed all substantive technical feedback from reviewers in particular:
- Incorporated Junio's guidance on integer types throughout
- Accepted Taylor Blau's suggestion for repository parameter handling
- Resolved Oswald Buddenhagen's concerns about unsigned integers with clear justification for the Bloom filter case
- Maintains all test coverage including fuzzer cases

The changes are mechanical but foundational, with the final patch (10/10) cleaning up redundant parameter passing now that the repository can be reliably derived from object database sources. The series appears merge-ready with consensus established in previous rounds, representing a significant step in both the `the_repository` removal effort and the broader ODB abstraction work. The philosophical debate about signed vs unsigned integers continues separately but does not affect the technical decisions in this series.
