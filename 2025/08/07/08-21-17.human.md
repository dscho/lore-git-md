This is a refactoring patch in Patrick Steinhardt's ongoing ODB source system integration series (patch 3/8). Karthik Nayak provides a review of changes to `link_alt_odb_entry()` that make it return the created `odb_source` pointer rather than just a success/failure code, which will be needed by a subsequent patch. The function signature also changes to take a `const char*` for the entry path rather than a `strbuf`, making it more flexible.

Karthik approves the core change but suggests the commit message could better explain the rationale for switching from `strbuf` to `const char*` parameters. The changes are straightforward - the function now initializes the alternate source to NULL, drops the error return code in favor of returning the source pointer directly, and updates callers to pass the string buffer contents rather than the buffer itself.

This continues the series' pattern of incremental ODB interface improvements, here preparing for future work that will need access to newly created alternate sources. The review indicates the changes are sound but could be more thoroughly documented in the commit message.
