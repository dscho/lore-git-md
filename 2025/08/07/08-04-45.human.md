**Refactoring patch in the commit-graph global state removal effort**

This is patch 3/10 in Patrick Steinhardt's series to eliminate global state from the commit-graph subsystem. The patch changes the type of two commit-graph write options ("max-commits" and "size-multiple") from signed to unsigned integers, since they are documented as always being positive values. This fixes sign comparison warnings in `split_graph_merge_strategy()` and uses the newer `OPT_UNSIGNED()` macro for option parsing.

The change is straightforward and mechanical - it updates the field types in three files (commit-graph.h, commit-graph.c, and builtin/commit-graph.c) while maintaining the same behavior. The commit message notes this likely wasn't done originally because `OPT_UNSIGNED()` was only introduced recently.

This patch follows maintainer feedback from Junio Hamano preferring `unsigned` over `size_t` for these counters, as discussed in the thread. It's a small but meaningful step in the series' broader goal of removing `the_repository` dependencies from the commit-graph code. The change is uncontroversial and has already received positive feedback from reviewers.
