This is the final patch in the v9 series introducing the new `git repo info` command hierarchy. It adds a `--format` flag to control output formatting, completing the command's functionality.

The patch implements two output formats modeled after `git config`:
1. `keyvalue` (default) - human-readable format with `key=value` pairs, one per line, with proper quoting of special characters
2. `nul` - machine-readable format with null-terminated values and newline-separated keys, without quoting

The implementation:
- Adds format parsing via `parse_options()`
- Modifies the output generation to handle both formats
- Extends tests to verify both formats work correctly
- Updates documentation with examples and format descriptions
- Includes comprehensive test coverage for error cases (invalid formats)

The patch maintains the series' architectural consistency, using the dual-strbuf approach established earlier. It follows Git conventions for command-line interfaces and output formatting, with particular attention to machine-parsable output needs. The implementation is clean and well-tested, with proper error handling for invalid format requests.

This completes the planned functionality for the initial `git repo info` command, providing both human-friendly and script-friendly output options while maintaining the command's experimental status as noted in the documentation.
