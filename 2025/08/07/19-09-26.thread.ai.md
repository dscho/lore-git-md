Git for Windows 2.51.0-rc1 release announcement from Johannes Schindelin. This is a test version of the Windows-specific Git distribution, based on Git 2.51.0-rc1 core. Component updates include: 7-Zip 25.00 for portable installers, cURL 8.15.0, and MSYS2 runtime built on Cygwin 3.6.4. Provides SHA-256 checksums for multiple distribution formats: standard installers (64-bit/ARM64), portable 7-Zip packages, MinGit distributions (32/64-bit and BusyBox variants), and tarballs. Follows standard Git for Windows release practices with no Windows-specific bug fixes or features mentioned beyond the component updates.
