This is a follow-up patch series (v9) for the already-merged `git repo info` command implementation, addressing final style nits from the v8 review. The series represents the completion of a GSoC project to migrate repository metadata reporting from `git rev-parse` to a new command hierarchy.

The v9 changes are purely cosmetic, standardizing test output formatting and error message style as requested by mentors Karthik Nayak and Patrick Steinhardt. Key adjustments include: using `${SQ}` consistently for test quoting, fixing whitespace in test commands, and reordering a BUG() message to put human-readable text first. The functional implementation remains unchanged from the approved v8 series.

The patchset maintains all previously implemented functionality: reporting ref storage format (`references.format`), repository layout (`layout.bare` and `layout.shallow`), with both key-value and nul-terminated output formats. Test coverage remains comprehensive, now with more consistent quoting style.
