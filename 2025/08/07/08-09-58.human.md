This is part 8 of Patrick Steinhardt's 9-part series refactoring the multi-pack index (MIDX) system to better integrate with Git's object database (ODB) source abstraction. The patch removes redundant information from the `multi_pack_index` struct that was already available in its containing `odb_source` struct.

The change eliminates three redundant fields from MIDX:
- The `local` flag (tracking whether the source is primary or alternate)
- The object directory path
- The repository pointer

Instead, MIDX now stores just a pointer to its `odb_source`, which already contains all this information. The patch updates all MIDX-related code to access these values through the source pointer rather than the now-removed direct fields. This affects MIDX loading, writing, bitmap handling, and revindex operations across several files.

The changes are mechanical and maintain all existing behavior while reducing duplication. This continues the series' pattern of deduplicating information flow in the MIDX system as part of the broader ODB source integration effort. The patch follows naturally from earlier parts that established the ODB source infrastructure and migrated MIDX to use it.

This is a well-executed refactoring that tightens up the MIDX implementation by removing redundant state. The changes are straightforward and the patch includes updates to all affected subsystems, showing good test coverage. As with the rest of the series, there are no behavior changes - just cleaner internal organization.
