Bugfix for `git diff --no-index` stdin handling in subdirectories.

This patch addresses a heap buffer overflow that occurs when running `git diff --no-index /dev/null -` from a subdirectory. The issue stems from the path normalization code incorrectly handling the special "-" (stdin) case, leading to memory corruption that ASAN detects. Gregoire Geis provides a clear reproduction case showing the crash and proposes a straightforward fix that exempts "-" from path prefix stripping.

The solution adds a `strcmp()` check for "-" alongside the existing absolute path check in `strip_prefix()`. This maintains the existing behavior for absolute paths while properly handling stdin. The patch includes a new test that verifies the fix works both in the root directory and deep subdirectories. The test is carefully constructed to ensure it would catch the issue even without ASAN instrumentation.

The patch appears well-crafted - it's narrowly focused on the specific bug, includes a clear explanation of both problem and solution, and adds appropriate test coverage. The change is small and low-risk, touching only the path normalization logic while leaving other behaviors unchanged. This looks like a solid fix for a real (if somewhat edge-case) bug.
