This is part 8 of Patrick Steinhardt's 9-part series refactoring the multi-pack index (MIDX) system to better integrate with Git's object database (ODB) source architecture. The series is focused on mechanical refactoring with no behavior changes.

This patch removes redundant information from `struct multi_pack_index` that duplicates data already available in its `odb_source` member. Specifically, it eliminates:
- The `local` flag (tracking whether the source is primary or alternate)
- The `object_dir` path string
- The `repo` pointer 

All these values are now accessed through the MIDX's `source` pointer instead. The changes propagate through MIDX handling code, pack-bitmap operations, and pack-revindex functionality, with corresponding updates to path computations and hash algorithm access to use the source's repository pointer.

Key technical impacts:
- 7 files modified with 36 insertions and 35 deletions
- Path handling now consistently uses `source->path` instead of `object_dir`
- Repository access now goes through `source->odb->repo` chain
- Test helper updated to show source path instead of object_dir
- Maintains all existing functionality while reducing data duplication

The changes continue the series' pattern of deduplicating information flow and better integrating MIDX operations with the ODB source system. This patch builds on the foundation established in earlier parts of the series where the ODB source infrastructure was made available to MIDX operations.
