This is part 4/10 of Patrick Steinhardt's series to remove global state from the commit-graph subsystem, specifically addressing sign comparison warnings. The patch systematically converts signed integer variables to unsigned types where they are used to count entities or represent positive quantities, eliminating compiler warnings while maintaining correctness.

The changes are mechanical but thorough, covering:
- Loop counters iterating over unsigned counts
- Progress tracking variables
- Commit graph chain counts
- Bloom filter settings (where -1 was being used as a sentinel value)
- File size comparisons
- Chunk writing counters

The patch follows through on the series' theme of type correctness while being careful to preserve behavior - for example, maintaining the -1 sentinel value for Bloom filter hash version by using an explicit cast rather than changing the semantic meaning. This continues the series' high standard of attention to detail while addressing a practical concern (compiler warnings) that was noted in earlier review feedback.

As with the rest of the series, these changes are preparatory work for removing global state dependencies, though this particular patch focuses more on code hygiene than architectural changes. It demonstrates the same careful, systematic approach seen in earlier patches of the series.
