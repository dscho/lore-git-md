Thread summary:

Heap overflow fix for `git diff --no-index` stdin comparison in subdirectories. The bug occurs when using "-" (stdin) as a path while running from a subdirectory, causing path normalization in `diff.c`'s `strip_prefix()` to overflow. The fix adds explicit stdin path checks alongside existing absolute path handling. 

Changes in v1:
- Modified `diff.c` to check for "-" in `strip_prefix()`
- Added new test file `t4072-diff-no-index-dash.sh` verifying correct behavior in root and deep subdirectories (`aa/bb/cc`)
- Updated meson.build to include new test
- Confirmed fix addresses ASAN/valgrind reports

Technical details:
- Bug manifests when normalizing stdin path ("-") in subdirectory context
- Fix preserves existing output format ("a/- b/-") for stdin comparisons
- Test coverage includes both direct reproduction and edge case validation
