This is a preparatory refactoring patch for the `--max-depth` diff series. It fixes a minor memory initialization issue in the combine-diff code where `diff_filepair` structs were allocated but not zeroed, potentially leaving fields with random values. The change switches from `xmalloc()` to `CALLOC_ARRAY()` to ensure clean initialization.

The patch is straightforward and uncontroversial - it addresses a clear technical debt where the combine-diff code wasn't following the same initialization pattern as the regular diff code. The commit message notes there's a larger question about whether these filepairs should have a special status flag (like `DIFF_STATUS_COMBINED`), but defers that decision for future discussion while making the immediate improvement.

As the first patch in a 3-part series introducing `--max-depth` functionality, this change helps ensure stable behavior for the subsequent patches that will build on this infrastructure. The patch carries Jeff King's original authorship with Toon Claes now shepherding it through the review process.
