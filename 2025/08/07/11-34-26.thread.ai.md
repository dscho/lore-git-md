Partial clone submodule filter proposal (RFC) from Petar Vutov. The proposal introduces a new `submodule.<name>.filter` configuration in `.gitmodules` to enable path-based filtering of submodule contents during clone and update operations. The implementation would leverage Git's existing partial clone machinery (`--filter`), with recursive operations respecting the filter specifications. Key open questions include the exact filter syntax and how filtered submodules should appear in status output. The change would affect submodule handling in `git-submodule.sh` and require integration with the partial clone implementation. This is an early-stage proposal seeking feedback before implementation.
