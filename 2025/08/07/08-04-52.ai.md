This is the final patch in Patrick Steinhardt's series removing global state from the commit-graph subsystem as part of the `the_repository` removal effort. The patch eliminates redundant repository parameters from commit-graph functions where the repository can be derived from the object database source.

The key change is removing `struct repository*` parameters from 12 functions where the repository could be obtained via `source->odb->repo` instead. This includes functions like `load_commit_graph_one_fd_st()`, `verify_commit_graph()`, and various internal helpers. The exception is `load_commit_graph_chain_fd_st()` which needs to work across repositories and thus takes an object database directly.

The patch touches core commit-graph operations including loading, verification, parent handling, and tree lookups. It maintains all existing behavior while making the code more consistent by using the repository from the ODB source when available. The changes are mechanical but complete the architectural shift started in earlier patches.

This concludes the series' goal of removing all `the_repository` usage from commit-graph.c while properly handling cross-repository cases. The changes have been reviewed and approved, with all major technical discussions resolved in previous iterations. The patch series is now merge-ready.
