This is part of Patrick Steinhardt's ongoing series to remove reliance on global state in the commit-graph subsystem, specifically targeting the `the_hash_algo` usage. The patch converts two hash-algorithm-dependent macros (`GRAPH_DATA_WIDTH` and `GRAPH_MIN_SIZE`) into functions that take the hash algorithm as a parameter, eliminating their dependency on the global `the_hash_algo` variable. This is a mechanical but important step in the larger effort to make the commit-graph code repository-agnostic.

The changes are straightforward - the macros are replaced with static functions that perform the same calculations but accept a `git_hash_algo` parameter. All call sites are updated to use these new functions while still passing `the_hash_algo` for now (the complete transition will happen in later patches). The diff shows careful attention to maintaining the exact same calculations while just changing the access pattern.

This is patch 5/10 in v3 of the series, which has already received significant review and appears ready for merging. The changes are non-controversial and align with the established pattern being used throughout this series to remove global state dependencies. The patch maintains all existing functionality while making the code more flexible for future work with multiple repository instances.
