Refactoring patch in Patrick Steinhardt's MIDX/ODB integration series (part 3/9). This change modifies the object database (ODB) source creation functions to return the newly created source structure rather than just succeeding/failing. 

The key change is converting `link_alt_odb_entry()` and `odb_add_to_alternates_memory()` to return the `struct odb_source*` instead of void/int. This prepares for future need to access the newly created source pointer, though the commit message notes this capability isn't used yet. The implementation handles path normalization and alternate ODB registration similarly to before, just with the additional return value plumbing.

This is a mechanical change that maintains all existing behavior while making the interface more flexible for future needs. It's part of the larger effort to better integrate MIDX handling with Git's ODB source system and remove redundant information from `struct multi_pack_index`. The changes are straightforward and focused, touching only ODB internals without affecting callers yet.
