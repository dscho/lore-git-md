This is a refactoring patch that's part of Patrick Steinhardt's ongoing work to integrate MIDX handling with Git's object database (ODB) source system. The patch simplifies how Git tracks whether an object database source is local (the main repository's object store) versus non-local (alternates or quarantine directories).

Previously, locality was determined on-the-fly by checking if a source was first in the list. The patch now stores this information directly in the `odb_source` struct via a new `local` boolean field. This makes the code more straightforward by eliminating repeated ad-hoc checks.

The changes affect several key areas: MIDX loading, pack preparation, and repository setup. The patch updates all relevant functions to use the new field rather than passing around a separate `local` parameter. This is a mechanical change that doesn't alter behavior, but makes the code more maintainable by centralizing the locality information.
