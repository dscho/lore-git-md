This is the foundational patch in a series introducing a new `git repo` command hierarchy, part of a GSoC project to migrate repository metadata functionality out of `git rev-parse`. The patch establishes the basic scaffolding for the new command, including:

1. A new `builtin/repo.c` implementing the command structure with an initial `info` subcommand (currently a no-op placeholder)
2. Documentation in `git-repo.adoc` describing the experimental nature of the command and its purpose for retrieving metadata
3. Build system integration across Makefile, meson.build, and other configuration files
4. Command registration in git.c and command-list.txt

The commit message explains the motivation well: `git rev-parse` has accumulated many unrelated features over time, and this creates a more logical home for repository metadata operations. The patch has received extensive review and mentoring, with multiple Helped-by and Mentored-by tags showing community involvement.

As the first in the series, this is primarily infrastructure work - the actual functionality will be added in subsequent patches. The implementation looks clean and follows Git's established patterns for new commands. The documentation clearly marks this as experimental, setting appropriate expectations.
