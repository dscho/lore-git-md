This is a refactoring patch in Patrick Steinhardt's ODB source system integration series, specifically addressing locality tracking in object database sources. Taylor Blau provides a brief but positive review of the changes.

The patch introduces explicit tracking of locality (local vs non-local) in object database sources, replacing the previous ad-hoc approach that checked if a source was first in the list. The change makes this information more directly accessible and robust. The only current caller is `prepare_packed_git()` in packfile.c, which sets the locality flag when the source matches the repository's primary objects directory.

Taylor confirms the technical approach looks sound, noting the implementation correctly handles the case where `source == r->objects->sources` should be marked as local. The review is concise but positive, with no concerns raised about the change. This appears to be a straightforward improvement that aligns with the series' goals of making ODB source handling more direct and maintainable.

The change affects `odb.c` and `odb.h`, continuing the pattern of interface simplification seen in earlier patches. While small, it contributes to the larger effort of ODB source system integration by removing implicit behavior in favor of explicit state tracking. The review suggests this patch is ready to proceed as-is in the series.
