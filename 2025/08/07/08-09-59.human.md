This is the final patch in Patrick Steinhardt's 9-part series refactoring the multi-pack index (MIDX) system to better integrate with Git's object database (ODB) source abstraction. The series has been progressively eliminating duplicate information flow between MIDX operations and the ODB source system.

The patch completes the transition by changing how MIDX paths are computed. Instead of passing around separate hash algorithm and object directory parameters, all path-related functions now work directly with the ODB source object. This affects MIDX file operations across writing, loading, and cleanup, with changes to path computation functions in midx.c/h and updates to callers in midx-write.c, pack-bitmap.c, and pack-revindex.c.

The changes are mechanical and maintain existing behavior while removing redundant parameter passing. The patch follows the series' pattern of deduplicating information flow through the ODB source system, building on the foundation established in earlier patches. With this change, MIDX operations now consistently use the source abstraction for all path-related operations, completing the series' goal of tighter ODB integration.

The patch is well-contained, touching only the expected subsystems with straightforward updates to call sites. It represents the culmination of the series' refactoring work, leaving the MIDX system in a cleaner state for future ODB backend development.
