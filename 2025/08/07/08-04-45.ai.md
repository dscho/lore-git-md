This is part 3/10 of Patrick Steinhardt's series to remove global state from the commit-graph subsystem, specifically focusing on fixing type declarations for write options. The patch converts `max_commits` and `size_multiple` options from signed to unsigned integers, addressing sign comparison warnings in `split_graph_merge_strategy()`.

The changes are straightforward mechanical conversions: the options are documented as positive integers but were previously stored as signed. The patch updates the field types in `struct commit_graph_opts` and local variables in `commit-graph.c`, while switching the option parsing to use `OPT_UNSIGNED()` instead of `OPT_INTEGER()`. This matches the actual usage where negative values would be invalid.

The commit message notes this likely wasn't done earlier because `OPT_UNSIGNED()` is a relatively recent addition. The changes align with Junio Hamano's feedback in the thread about preferring unsigned types for these non-negative counters. The patch is a clean, focused change that resolves compiler warnings while maintaining the existing functionality, with no behavioral impact expected since negative values were never valid here anyway.
