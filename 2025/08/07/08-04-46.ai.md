This is patch 4/10 in Patrick Steinhardt's series to remove global state from the commit-graph subsystem, part of the broader `the_repository` removal effort. The patch focuses on fixing sign comparison warnings in commit-graph.c by converting various counters and loop variables from signed to unsigned types where appropriate.

Key changes include:
- Converting counters like `num_commit_graphs_before/after` from `int` to `uint32_t`
- Changing loop variables to `size_t` when iterating over unsigned counts
- Making `write_graph_chunk_base_1()` return `size_t` instead of `int`
- Using explicit casts for special cases like the Bloom filter hash version sentinel value (-1)
- Removing the `DISABLE_SIGN_COMPARE_WARNINGS` define as it's no longer needed

The changes are mechanical but important for type safety, eliminating warnings while maintaining the same behavior. The patch follows the pattern established in earlier patches of the series, continuing the transition to proper unsigned types for counts and sizes. It handles several edge cases:
- File size comparisons with `st_size` using `ssize_t` cast
- Preserving the Bloom filter hash version sentinel value through unsigned cast
- Maintaining progress counter compatibility while changing its type

This patch doesn't introduce new functionality but cleans up the codebase in preparation for the larger architectural changes in subsequent patches. The changes align with the series' goal of removing global state while improving code quality.
