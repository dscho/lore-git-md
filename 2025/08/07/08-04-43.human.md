This is the first patch in a 10-part series removing global state from the commit-graph subsystem as part of the `the_repository` removal effort. The patch introduces a new tracing function `trace2_data_uintmax()` to complement the existing `trace2_data_intmax()`, providing unsigned integer tracing capability.

The change is straightforward - it adds the new function with identical structure to its signed counterpart, using `PRIuMAX` for formatting. The patch includes both the implementation in trace2.c and the corresponding header declaration with a convenience macro. While simple, this utility function will be used in subsequent patches of the series for tracing unsigned values in the commit-graph code.

As the first patch in a well-reviewed series that has already gone through multiple iterations, this appears mechanically sound and uncontroversial. It serves as foundational infrastructure for the more substantial changes that follow in the series. The patch follows established patterns in the codebase and maintains consistency with existing tracing functionality.
