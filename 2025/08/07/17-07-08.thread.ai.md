Git v2.51.0-rc1 release announcement thread summary:

First release candidate for Git 2.51.0, containing 542 non-merge commits from 81 contributors (22 new). Major changes span UI/workflow, performance, and fixes. UI highlights: new R language userdiff patterns, improved `git send-email` credential docs, `git cat-file --batch` distinguishes missing objects vs submodules, `git diff --no-index` pathspec support, `git subtree` GPG signing, `git whatchanged` deprecation plan, new stash import/export format, `git merge/pull --compact-summary`, revived `git imap-send` with OAuth2.0, reftable backend to become default in Git 3.0. Performance/internal: `pack-objects` path-based delta optimizations, batched ref updates in push/fetch, ongoing `the_repository` removal, SHA-256 transition prep, official `bool` type adoption, reftable unit tests migrating to clar framework. Fixes address memory leaks, submodule handling, index locking, ref deletion edge cases, remote name collisions, GPG path expansion, platform-specific issues (FreeBSD, Windows, macOS). Includes doc updates, test improvements, build system enhancements. Tarballs available for testing, release candidate tag on public mirrors.
