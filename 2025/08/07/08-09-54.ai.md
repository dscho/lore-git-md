This is a refactoring patch in Patrick Steinhardt's multi-pack index (MIDX) series, specifically part 4/9 of v2. The change simplifies the interface of `link_alt_odb_entry()` by removing a redundant path parameter that callers were previously required to pass.

The patch eliminates the `normalized_objdir` parameter from `link_alt_odb_entry()` since this path could already be derived from the `odb` parameter that callers must provide. While this means some callers that previously computed the path once must now recompute it (notably `link_alt_odb_entries()` which processes alternates in a loop), the author argues this is a worthwhile tradeoff for cleaner interface semantics.

Key technical details:
- Removes `normalized_objdir` parameter from `link_alt_odb_entry()`
- Moves path resolution into the function using `odb->sources->path`
- Updates all callers (`link_alt_odb_entries()` and `odb_add_to_alternates_memory()`) to use the simpler interface
- Maintains same functionality while reducing parameter passing complexity
- Part of broader effort to clean up ODB/MIDX interfaces in preparation for deeper integration

The change is a mechanical refactoring with no behavior changes, continuing the series' pattern of interface improvements while maintaining strict internal consistency. It addresses feedback from v1 reviews by simplifying the API surface area.
