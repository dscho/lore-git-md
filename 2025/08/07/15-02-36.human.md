This is part 2 of a series introducing the new `git repo info` command, specifically adding support for querying the repository's reference storage backend (either "files" or "reftable"). The patch moves functionality from `git rev-parse --show-ref-format` to the new command hierarchy.

The implementation establishes the core architecture for the `repo info` subcommand, including:
- A new `references.format` field that reports the ref storage format
- Key-value output formatting with proper quoting of unusual characters
- Lexicographical sorting of output keys
- Basic error handling for invalid keys
- Comprehensive tests verifying the behavior with both files and reftable backends

The patch shows careful attention to detail with:
- Clean separation of formatting logic into helper functions
- Proper memory management using strbufs
- Test coverage for edge cases like duplicate keys and mixed valid/invalid requests
- Documentation of the new field in git-repo.adoc
