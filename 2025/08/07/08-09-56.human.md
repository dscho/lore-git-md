This is part 6 of Patrick Steinhardt's 9-part series refactoring multi-pack index (MIDX) handling to better integrate with Git's object database (ODB) source system. The patch focuses on loading MIDX files via their ODB source rather than passing redundant repository and object directory parameters.

The key changes in this patch:
- Refactors MIDX loading functions to take an `odb_source` parameter instead of separate repository and object directory parameters
- Updates the MIDX` test helper and `git-multi-pack-index` command to handle alternate object directories by adding them as in-memory alternates
- Removes redundant parameters that can now be derived from the source structure
- Maintains all existing functionality while simplifying the interface

The changes continue the series' goal of deduplicating information and better integrating MIDX with the ODB source system. This is a mechanical refactoring with no behavior changes, though it does surface one edge case around alternate object directories that is addressed by the in-memory alternates approach.

The patch affects MIDX loading functionality across several files, with corresponding test updates. It builds on the foundation established in earlier parts of the series while preparing for future work on pluggable object backends.
