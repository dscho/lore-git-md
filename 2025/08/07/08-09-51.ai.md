This is part 1 of Patrick Steinhardt's v2 series refactoring multi-pack index (MIDX) handling to better integrate with Git's object database (ODB) source system. The patch focuses on tracking locality (whether a source is the primary local repository vs. an alternate) directly in the `struct odb_source` rather than computing it ad-hoc.

The key changes:
- Adds a `local` boolean field to `struct odb_source` to explicitly track whether the source is the primary repository's object directory
- Initializes this field when creating sources (true for main repo, false for alternates)
- Updates MIDX and packfile preparation functions to use the stored `local` field rather than passing it as a parameter
- Modifies 6 files with 18 lines added and 8 lines removed

This is a mechanical refactoring with no behavior change, establishing the foundation for later patches in the series that will further deduplicate MIDX handling. The change makes the code more robust by centralizing locality tracking rather than recomputing it based on source position. The patch appears well-contained and properly motivated, with clean separation from the larger refactoring goals of the series.
