Refactoring patch completing a three-part bugfix series in remote.c's push error handling. This final patch converts an if-else chain into a switch statement for better readability in the show_push_unqualified_ref_name_error() function, while also removing a now-unused type variable. The change maintains identical behavior to the previous version, just with cleaner control flow.

Key technical details:
- Eliminates the intermediate `type` variable by moving the odb_read_object_info() call directly into the switch expression
- Preserves all existing advise() messages for different object types (commit, tag, tree, blob) and the fallback case
- Follows through on a suggestion from Patrick Steinhardt to make this stylistic improvement after the core bugfix was addressed
- Builds on earlier patches that fixed a BUG() assertion when pushing invalid OIDs and cleaned up related tests

The patch has already received positive feedback from both Junio C Hamano and Patrick Steinhardt, with no outstanding concerns. This concludes the series which improves error handling for invalid refspecs while modernizing the code structure. The changes are purely internal with no user-facing impact beyond the previously improved error messages.
