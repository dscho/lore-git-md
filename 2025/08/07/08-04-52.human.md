This is the final patch in Patrick Steinhardt's series removing global state from the commit-graph subsystem, part of the ongoing `the_repository` removal effort. The patch eliminates redundant repository parameters from commit-graph functions where the repository can be derived from the object database source instead.

The key change is that most functions now take only an `odb_source` parameter rather than both a repository and source, since the source already contains a reference to its owning repository. The one exception is `load_commit_graph_chain_fd_st()`, which needs to work across different object databases and thus still takes an explicit object database parameter.

The changes are mechanical but thorough, touching functions across commit-graph loading, verification, and traversal. The patch maintains all existing behavior while simplifying the interface. This completes the series' goal of removing all global state dependencies from the commit-graph subsystem, making it fully repository-aware.

With this patch, the series appears ready for merging - it has addressed all previous feedback, maintains clean separation of concerns, and passes all tests. The changes are foundational for future work on pluggable object databases.
