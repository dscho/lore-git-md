This is the first patch in Patrick Steinhardt's v2 series refactoring multi-pack index (MIDX) handling to better integrate with Git's object database (ODB) source system. The patch focuses on tracking locality (whether an ODB source is the primary repository or an alternate) directly in the `struct odb_source` rather than computing it repeatedly.

The change adds a `local` boolean field to `struct odb_source` and initializes it when sources are created - true for the main repository's object directory and false for alternates. This replaces several ad-hoc checks that previously determined locality by comparing source pointers. The patch updates MIDX and packfile handling code to use this stored value rather than passing around a separate `local` parameter.

This appears to be a clean mechanical refactoring with no behavior changes, just moving the locality tracking to a more logical place. It's part of a larger effort to reduce duplication between MIDX and ODB handling. The changes touch core object database code but are well-contained and clearly explained in the commit message.
