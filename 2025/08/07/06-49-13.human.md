Performance optimization for Bloom filters with wildcard pathspecs. This is a reply to Lidong Yan's patch that enables Bloom filter usage with pathspecs containing wildcards and certain magic signatures. Patrick Steinhardt provides a detailed code review suggesting several improvements.

The key technical points center around how pathspec wildcards and magic signatures interact with Bloom filters. Patrick agrees with the approach of using the non-wildcard portion of pathspecs (up to the last directory separator) for Bloom matching, but suggests using an allow-mask rather than forbid-mask for magic signatures to be more future-proof. He also notes edge cases around paths where the first component contains a wildcard.

The review includes specific suggestions for test improvements: using proper indentation in heredocs, employing `test_when_finished` for cleanup, and clarifying test names. Patrick questions whether the optimization still provides benefits when matching against empty paths (from leading wildcards), though he expects it should work correctly.
