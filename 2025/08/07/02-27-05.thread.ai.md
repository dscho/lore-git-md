Bug report: `git stash --include-untracked` modifies timestamps of .pack files in object store without content changes, causing unnecessary backup transfers. Patrick Steinhardt clarifies this is expected behavior from Git's object freshening mechanism, which updates access times of objects (and their containing packfiles) during object database writes. He notes this is fundamental to garbage collection and not specific to `stash` - any command writing objects could trigger it. The behavior occurs in `save_untracked_files()` but isn't limited to that codepath. Patrick suggests backup systems needing to avoid timestamp churn may need to adapt to Git's object storage behavior rather than expecting Git to change this mechanism, as it serves important object management purposes. No indication yet of planned changes to the freshening behavior.
