This is a refactoring patch that's part of Patrick Steinhardt's ongoing ODB source system integration work. Karthik Nayak is reviewing patch 1/8 from the series, which introduces a new `local` field in `struct odb_source` to track whether an object database source is the primary local repository (".git/objects") versus an alternate or quarantine directory.

The patch eliminates ad-hoc locality checks that previously compared sources against the first entry in the list, instead storing the information directly in the source struct when it's created. This affects MIDX and packfile preparation functions across 6 files, removing the `local` parameter from `prepare_multi_pack_index_one()` and `prepare_packed_git_one()` since they can now get this information directly from the source struct.

Key technical details:
- Adds `bool local` field to `struct odb_source` with documentation
- Initializes alternates as non-local (`false`) in `link_alt_odb_entry()`
- Marks primary repository source as local (`true`) in `repo_set_gitdir()`
- Updates MIDX and packfile preparation to use source->local instead of parameter
- Maintains same behavior while making the code more robust and self-documenting

The review notes the changes look good, particularly appreciating how it simplifies the interface by removing redundant parameters. This is a foundational change for the larger series that will make subsequent MIDX integration patches cleaner.
