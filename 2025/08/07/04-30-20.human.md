This is a follow-up refactoring patch to the recently concluded bugfix series in remote.c. The diff shows the mechanical conversion from conditionals to switch cases, with each object type (commit, tag, tree, blob) getting its own case plus a default case for invalid objects.

Since this was an explicitly suggested follow-up and the original series has already been approved, this patch seems likely to be accepted as a separate cleanup.
