This is a refactoring patch series that continues Patrick Steinhardt's work to integrate Git's multi-pack index (MIDX) handling with the object database (ODB) source system. The 9-part series builds on previous work to eliminate redundant information stored in MIDX structures by fully utilizing the ODB source abstraction.

The key technical changes in v2 include:
- Adding a new patch (4/9) to simplify the `link_alt_odb_entry()` calling convention
- Fixing a comment typo in the first patch
- Maintaining all the core refactoring from v1 that removes duplicate fields from MIDX structures and updates path computations to use ODB sources

The series touches multiple subsystems including MIDX loading/writing, bitmap handling, and revindex operations. It represents a significant step in abstracting Git's object storage layer, with all review feedback from v1 addressed. The changes are mechanical refactoring with no behavior changes, continuing the project's ongoing effort to clean up the object storage implementation.

The patch series appears well-structured and focused, with each commit building logically on the goal of deduplicating information between MIDX and their ODB sources. The v2 changes show responsiveness to review feedback while maintaining the technical direction established in v1.
