This is part 6/10 of Patrick Steinhardt's series to remove global state from the commit-graph subsystem, specifically targeting the `the_repository` removal effort. The patch refactors how hash algorithm information is stored in the commit-graph structure.

Currently, the commit-graph only stores the length of the hash algorithm it uses. This patch changes the storage to keep a pointer to the full hash algorithm` structure instead. This is a preparatory change needed for subsequent patches that will need access to the full algorithm details rather than just its length.

The change is mechanical but widespread, touching many parts of the commit-graph code that previously used `hash_len` to now use `hash_algo->rawsz`. The diff shows updates to chunk size calculations, offset computations, and various hash-related operations throughout commit-graph.c, plus the corresponding struct field change in commit-graph.h.

This continues the series' pattern of methodically removing implicit dependencies on global state while maintaining identical behavior. The change appears straightforward and well-contained, with all modifications directly related to the hash algorithm storage refactoring. As part of a well-reviewed series that has already addressed key technical concerns in earlier iterations, this patch seems ready for inclusion.
