Bugfix follow-up to interactive rebase merge commit handling. This is a brief acknowledgement from Phillip Wood in response to Johannes Sixt's patch that fixed an oversight in the sequencer's handling of merge commits during interactive rebase. The original fix (4c063c82e9) added error messages for incompatible commands but missed the 'drop' case, which would hit a BUG(). Sixt's patch added TODO_DROP to the permitted commands in check_merge_commit_insn() alongside TODO_MERGE, with a corresponding test case in t3404. Wood thanks Sixt for both the fix and the test extension, confirming the solution. The exchange is purely positive, with no new technical discussion beyond the original patch's acceptance. The changes remain minimal (sequencer.c and test file only) and this appears to be closing discussion on this particular edge case in the rebase sequencer logic.
