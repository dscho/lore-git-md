This is part 7 of Patrick Steinhardt's 9-part series refactoring multi-pack index (MIDX) handling to better integrate with Git's object database (ODB) source system. The patch continues the mechanical conversion from passing repository/object_dir parameters to using ODB source objects instead.

The changes update MIDX writing operations (`write_midx_file`, `write_midx_file_only`, `expire_midx_packs`, and `midx_repack`) to take an `odb_source` parameter rather than separate repository and object directory strings. The implementation follows the same pattern as previous patches in the series - maintaining the same behavior while removing duplicate parameter passing and consolidating information flow through the ODB source system.

The patch affects several commands that work with MIDX files (`multi-pack-index write/expire/repack` and `repack`), updating their call sites to use the new interface. Test infrastructure remains unchanged since the behavior is preserved, just implemented through different plumbing.

This continues the series' steady progress toward fully integrating MIDX operations with the ODB source abstraction while maintaining strict backward compatibility. The changes are mechanical but important for the larger goal of deduplicating object directory handling across Git's codebase.
