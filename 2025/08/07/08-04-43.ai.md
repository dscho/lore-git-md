This is the first patch in a 10-part series removing global state from the commit-graph subsystem as part of the `the_repository` removal effort. It introduces a new tracing utility that will be used in subsequent patches.

The patch adds `trace2_data_uintmax()` to complement the existing `trace2_data_intmax()` function, providing unsigned integer tracing capability. The implementation follows the same structure as its signed counterpart, formatting the value as a string and passing it to the existing string tracing infrastructure. The change is straightforward - adding parallel function signatures in both the implementation and header files.

This foundational change enables proper tracing of unsigned values that will be needed when converting commit-graph counters to unsigned types in later patches. The patch is mechanical and uncontroversial, with the thread context showing it has already been reviewed and approved as part of the larger series. The function will be used specifically for tracing unsigned commit-graph statistics in subsequent patches.

Key technical details:
- New function `trace2_data_uintmax()` mirrors `trace2_data_intmax()` but for unsigned values
- Uses `PRIuMAX` format specifier for uintmax_t
- Follows same pattern of file/line/category/repo/key/value parameters
- Includes both FL (file-line) and convenience macro versions
- Will be used to trace unsigned commit-graph counters in later patches
- Part of systematic removal of global state dependencies in commit-graph code
