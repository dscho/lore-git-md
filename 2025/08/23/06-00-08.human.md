Feature patch series introducing `git refs exists` as part of ref command consolidation. This is version 2 of a 4-patch series from Meet Soni, rebased onto master after prerequisite commits were merged.

The series adds a new `git refs exists` subcommand that duplicates the functionality of `git show-ref --exists`, checking whether a reference exists and returning appropriate exit codes (0=exists, 2=missing, 1=error). This continues the effort to consolidate ref-related commands under the `git refs` namespace.

Key changes in v2:
- Rebased onto master branch now that prerequisites are merged
- Split test infrastructure into shareable components:
  - Extracted common test logic into show-ref-exists-tests.sh
  - Created t1422-show-ref-exists.sh as a driver script
  - Added t1462-refs-exists.sh to test the new command

The implementation is straightforward, calling refs_read_raw_ref() directly with the same error handling as show-ref. The test strategy ensures behavioral parity between the old and new commands by sharing test cases. Documentation is added to git-refs.adoc.
