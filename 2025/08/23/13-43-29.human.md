This is a feature patch introducing Rust infrastructure for xdiff, part of a larger series (v3 02/15). Randall Becker raises a concern about platform compatibility, questioning whether Rust becomes a mandatory dependency that could exclude some platforms.

The patch adds Rust build infrastructure (Makefile/meson changes) and type definitions in git-compat-util.h to facilitate C/Rust interop. It introduces:
- Rust workspace with xdiff and interop crates
- build_rust.sh script handling debug/release modes
- Platform-specific handling (notably Windows/MSVC vs others)
- Integration with existing build systems

Becker's concern focuses on whether this creates new platform requirements. The patch does add Rust toolchain requirements, though the series appears to maintain existing platform support (as noted in the thread summary for later patches). The response will likely need to address how platforms without Rust toolchains are handled, possibly through build-time configuration or fallback paths.

This early infrastructure patch sets up the build system before the actual Rust code is introduced in subsequent patches. The concern raised suggests this aspect may need clarification in the cover letter or documentation about platform requirements.
