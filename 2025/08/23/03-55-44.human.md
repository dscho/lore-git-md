This is a CI/build system patch in the ongoing Rust infrastructure series for xdiff (now at v3/15). It focuses on installing Rust toolchains in GitHub Actions workflows, handling platform-specific requirements:

The patch adds Rust installation to all CI jobs, with special handling for different platforms:
- Windows needs Rust 1.78.0+ and specific target triples (gnu for make, msvc for meson)
- musl builds require Rust 1.72.0+ due to libc differences
- 32-bit Linux containers need explicit target overrides since rustup misdetects bitness

The implementation uses `actions-rs/toolchain` where possible, falling back to custom scripts for Docker environments. It consolidates version/target definitions in `main.yml` and adds new helper scripts (`install-rust-toolchain.sh`, `install-rustup.sh`).

The changes appear thorough and well-motivated, with clear explanations for each platform quirk. Johannes Schindelin contributed to the library name selection logic, which was reworked into this commit. This continues the series' methodical approach, now ensuring the CI system can properly test the Rust components being developed.
