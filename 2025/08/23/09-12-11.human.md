This is a documentation patch continuing the discussion about remote repository setup in Git's "My First Contribution" guide. Daniele Sassoli updates the documentation to more clearly explain that contributors can use either `git/git` or `gitgitgadget/git` as their remote, with a link to a page explaining the differences between the two approaches.

The patch simplifies the PR creation instructions by removing the conditional language about fork requirements when using `git/git`, instead presenting both options equally with a reference to external documentation for the workflow differences. This appears to incorporate feedback from Elijah Newren about making the GitHub PR mechanics more technically accurate while maintaining Daniele's position that both approaches should be documented neutrally.

The changes are focused and well-contained, modifying only the "Sending a PR to GitGitGadget" section of the guide. The patch maintains the document's beginner-friendly tone while providing clearer direction for contributors about their remote options. This version drops some of the more prescriptive language from v1 about fork requirements, likely in response to the ongoing discussion about keeping the documentation technically precise while remaining accessible.
