This is part of the ongoing Rust infrastructure series for xdiff (patch 9/15 in v3). The patch makes xdiff's internal data structures more Rust-friendly by adjusting type definitions and adding necessary casts to maintain compatibility between C and Rust code.

The key changes involve updating the `xrecord_t` struct to use Rust-compatible types (`u8 const*` for pointers, `usize` for sizes, and `u64` for hashes) and propagating these changes through the xdiff codebase. This requires adding explicit casts in various places where the code interacts with these fields, particularly around string operations and pointer arithmetic. Johannes Schindelin noted that `xdlclass_t::ha` should also be updated to `u64` to match `xrecord_t::ha`, which is included in this patch.

The changes are mechanical and focused on type compatibility rather than functionality - all existing behavior is preserved. This continues the series' pattern of careful, incremental preparation work for Rust integration while maintaining the current C implementation's correctness. The patch touches multiple xdiff components (diff generation, merging, patience algorithm) but doesn't introduce any new functionality or behavior changes.
