This is a documentation patch updating Git's "My First Contribution" guide, part of an ongoing discussion about remote repository configuration for new contributors. Daniele Sassoli's v2 revision clarifies that both `git/git` and `gitgitgadget/git` can be used as remotes when submitting PRs, with a link to documentation explaining their differences.

The patch simplifies the PR submission instructions by presenting both remote options upfront rather than initially suggesting only `gitgitgadget/git`. It removes potentially confusing fork requirements language from v1 and instead provides a neutral reference link comparing the workflows. The changes maintain Daniele's consistent position that first-time contributors benefit from straightforward documentation without premature optimization for future contributions.

Key technical elements include the modified PR submission instructions in `MyFirstContribution.adoc`, the added workflow comparison link to gitgitgadget.github.io, and the removal of fork-specific language that Elijah Newren noted was technically inaccurate about GitHub's PR mechanics. The patch continues the thread's theme of balancing technical accuracy with beginner-friendliness, though it leans more toward Daniele's preference for initial simplicity over Junio Hamano's suggested proactive guidance toward `gitgitgadget/git`.
