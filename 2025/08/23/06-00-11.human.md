Test refactoring patch in the `git refs exists` series. This is the third patch in a 4-part series introducing a new `git refs exists` command as part of Git's ref-related command consolidation effort.

The patch reorganizes the test infrastructure to make it shareable between the existing `git show-ref --exists` tests and the upcoming `git refs exists` implementation. The core test logic is moved from `t1422-show-ref-exists.sh` to a new `show-ref-exists-tests.sh` file, with the original test file becoming a simple driver that sources the shared tests. The tests now use a `$git_show_ref_exists` variable instead of hardcoded `git show-ref --exists` calls, allowing the same test cases to be reused for the new command.

The changes follow an established pattern for sharing tests in Git's test suite and implement the test reorganization suggested by Patrick Steinhardt in the v1 review. The test coverage remains comprehensive, checking various ref types (regular refs, HEAD, symrefs, special refs) and edge cases (invalid ref names, non-existent objects). The implementation looks clean and well-structured, maintaining all the original test assertions while making them reusable.
