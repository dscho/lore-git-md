This is a refactoring and Rust integration series for xdiff, now at version 3/15. The series has evolved from its original focus on hashing optimizations to establishing Rust infrastructure and cleaning up xdiff internals for future Rustification.

Key technical changes in this version:
- Introduces an `ivec` type for safe C/Rust interop of vector data
- Adds Rust build infrastructure (Makefile/meson integration, CI workflows)
- Documents Rust usage policy in `rust-support.adoc`
- Performs preparatory xdiff cleanups (removing unused fields, standardizing memory management)
- Implements `xdl_trim_ends()` in Rust as the first translated function

The series now focuses on architectural foundations rather than immediate performance gains, addressing maintainer feedback to prioritize framework establishment over optimization. Notable aspects include:

- Windows/MSVC compatibility through adjusted target specifications
- Platform support clarified to exclude Cygwin (tracked separately)
- Rust style guidelines adopting rustfmt defaults
- Zero-copy FFI approach with Rust managing diff operations

The cover letter highlights interest in feedback on the `ivec` interop type and shows the series has rebased on `am/xdiff-hash-tweak`. Build results are available via GitHub Actions.

This iteration drops earlier hashing changes to unblock other xdiff work while maintaining the Rust integration path. The series appears well-structured with incremental changes building toward broader Rust adoption in xdiff.
