This is a platform compatibility patch in the ongoing Rust xdiff infrastructure series (now v3 4/15), addressing Windows-specific linking requirements when using the Rust-built xdiff library.

The patch adds `userenv` library linking for Windows builds across both Makefile and Meson systems, required due to Rust's `std::env::home_dir()` implementation calling `GetUserProfileDirectoryW()`. The CI workflow is updated to ensure `libuserenv.a` is present in the Windows SDK environment, fetching it if missing. This is a new dependency not yet included in the minimal Git for Windows SDK.

Key technical details:
- Makefile changes in `config.mak.uname` add `-luserenv` to `EXTLIBS`
- Meson build system gains equivalent `userenv` library dependency
- GitHub Actions workflow adds a pre-step to verify/install `libuserenv.a`
- The issue manifests differently in Make vs Meson builds but requires the same underlying fix

The patch maintains consistency with the series' systematic approach, handling platform requirements before moving to core functionality. Windows/MSVC target handling remains an open item from previous patches, though this addresses one concrete linking issue. The solution is temporary until `userenv` can be properly included in the Windows SDK.
