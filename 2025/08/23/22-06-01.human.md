This is a documentation patch clarifying the experimental status of the `extensions.compatobjectformat` config option. Brian Carlson notes that the feature is currently incomplete - it only works with loose objects, not packed ones, and the underlying storage format is likely to change. The patch adds an explicit warning that the functionality is experimental and subject to change.

The motivation comes from real-world confusion, as some users (notably Gitolite administrators) expected the feature to work more completely than it actually does. While the current implementation technically functions for loose objects, Carlson explains it performs poorly and lacks key functionality like submodule support.

This appears to be a straightforward documentation improvement that accurately reflects the current technical limitations. The commit message provides clear context about why the warning is being added now rather than when the feature was first introduced. The change itself is minimal - just a three-line addition to the config documentation.
