This is part 2/15 of a series introducing Rust infrastructure for xdiff, focusing on build system integration. The patch lays groundwork for future Rust components by:

1. Adding Rust build infrastructure to both Makefile and meson systems, with support for debug/release modes and platform-specific handling (notably Windows MSVC)
2. Introducing a `build_rust.sh` helper script to coordinate cargo builds
3. Defining Rust primitive types in `git-compat-util.h` for C/Rust interop
4. Setting up a multi-crate Rust workspace with initial empty crates for xdiff and interop functionality
5. Adding Rust-specific clean targets and build artifacts to `.gitignore`

The changes are mechanical but foundational - they enable subsequent patches to add actual Rust implementations while ensuring the build integration works across platforms. The approach keeps Rust builds separate (handled by cargo) while linking the resulting static libraries into Git's main build. This patch doesn't yet include any Rust logic - that comes later in the empty `lib.rs` files are just placeholders.

As part of the larger series to modernize xdiff with Rust, this patch focuses on the unglamorous but critical build plumbing needed to make mixed C/Rust development possible. The implementation looks thorough, with clear attention to cross-platform compatibility concerns.
