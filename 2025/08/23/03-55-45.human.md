This is a platform compatibility patch in the ongoing Rust xdiff infrastructure series (now v3/15). It addresses a Windows-specific linking issue that arises when using the Rust-built xdiff library.

The patch adds a new dependency on the Windows system library `userenv` for both Makefile and Meson builds, required because Rust's standard library`std` calls `GetUserProfileDirectoryW` internally. The change includes:

1. Adding `-luserenv` to linker flags in `config.mak.uname` for Makefile builds
2. Including `userenv` in Meson's dependency list
3. A CI workaround to manually fetch `libuserenv.a` if missing in the Windows SDK

The patch acknowledges this is a new requirement not yet part of the minimal Git for Windows SDK, with plans to properly include it later. The change appears straightforward and well-justified, though Windows users will need to ensure they have this library available until it's properly integrated into the SDK.

This continues the series' methodical approach, now addressing platform-specific build requirements that emerged from the Rust integration work. The patch is cleanly focused on solving the immediate linking problem while noting the longer-term SDK integration path.
