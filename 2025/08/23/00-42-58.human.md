This is the first patch in the final v9 series improving the git-rebase documentation, now fully approved and ready for merge. Julia Evans restructures the man page to begin with a concrete example showing how rebase transplants commits, mirroring the approach used in git-merge's documentation to help users understand the difference between merging and rebasing.

The patch moves the rebase example from later in the document to the very beginning of the DESCRIPTION section, adding introductory text that explains rebase can both transplant commits and reorder/combine them (with a pointer to the interactive mode section). The example demonstrates rebasing a topic branch onto an updated master branch, showing both the before and after states of the commit graph.

This change is part of a larger documentation cleanup that has gone through multiple rounds of review, with the final version incorporating maintainer feedback about proper section organization. The series as a whole reduces the man page by 104 lines while improving clarity, with this particular patch establishing a more pedagogical flow by leading with practical examples before diving into technical details.
