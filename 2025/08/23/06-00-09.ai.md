This is the first patch in a 4-part feature series introducing the `git refs exists` subcommand, part of Meet Soni's GSoC project to consolidate ref-related commands under the `git refs` namespace. The patch adds the core implementation of the new subcommand, which duplicates the functionality of `git show-ref --exists` with identical exit code behavior (0=exists, 2=missing, 1=error).

The implementation in builtin/refs.c uses refs_read_raw_ref() for ref lookup, matching show-ref's error handling. The author deliberately chose to duplicate the ~20 lines of existence-checking logic rather than creating a shared helper, considering this simpler than abstracting such a small piece of code. Documentation is added to git-refs.adoc specifying the command's behavior and exit codes.

This version builds on Git v2.51.0 with the prerequisite `ms/refs-list` branch merged, and follows Patrick Steinhardt's suggestion to reorganize the test infrastructure (which appears in later patches in the series). The implementation maintains behavioral parity with show-ref while moving the functionality under the refs namespace as part of the broader ref command reorganization effort.
