Test refactoring patch in the `git refs exists` series. This is patch 2/4 in the second version of Meet Soni's GSoC project to add a new `git refs exists` subcommand. The patch moves all `--exists` tests from `t1403-show-ref.sh` into a new dedicated test file `t1422-show-ref-exists.sh` with no functional changes, preparing for shared test infrastructure between the existing `show-ref --exists` and new `refs exists` implementations.

The test cases cover various ref existence scenarios including: normal refs, missing refs, HEAD, symrefs (both valid and dangling), invalid ref names, non-commit objects, directory paths, and special refs like FETCH_HEAD. The test setup creates a small repository with commits and branches to exercise these cases. The patch follows Patrick Steinhardt's suggestion from v1 review to reorganize the test infrastructure for better sharing between implementations.

Key technical details preserved in the move:
- All original test cases and their assertions
- Setup using test-tool ref-store for low-level ref manipulation
- Error message verification
- Cleanup of temporary refs via test_when_finished
- Special ref handling (FETCH_HEAD)
- DWIM behavior verification

The pure code movement makes this a straightforward refactoring that maintains identical test coverage while enabling the next patch to share these tests between both existence-checking implementations. The meson.build file is updated to include the new test file.
