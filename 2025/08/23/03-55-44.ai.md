CI / build system patch adding Rust toolchain installation to GitHub workflows, part of the ongoing Rust xdiff infrastructure series (3/15). This patch focuses on setting up Rust in CI environments with platform-specific handling.

The changes standardize Rust installation across GitHub Actions workflows, using `actions-rs/toolchain` where possible and falling back to custom scripts for Docker targets. Key platform-specific considerations include:
- Windows: Requires Rust 1.78.0+ for bcrypt library resolution and different target triples for make vs meson builds
- musl: Needs Rust 1.72.0+ for libc compatibility
- 32-bit Linux containers: Explicit target triple override needed due to rustup host detection issues

The implementation introduces two new scripts:
- `install-rustup.sh` for Docker environments
- `install-rust-toolchain.sh` for version/target management

The patch consolidates version and target definitions in `main.yml`'s maintaining minimum Rust 1.61.0 as baseline while allowing platform-specific overrides. It also includes various CI script adjustments to ensure Rust toolchain availability during builds and tests.

This continues the series' methodical approach, now addressing CI infrastructure needs after establishing build system foundations in previous patches.
