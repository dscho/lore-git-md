Subject: Replacing setitimer() with alarm() for progress meter signaling

This two-patch series by [author] improves platform compatibility by replacing `setitimer()` with `alarm()` for progress meter updates, addressing `setitimer()`'s obsolescent status in POSIX.1-2017. The changes simplify signal handling while maintaining progress reporting during operations like clones and fetches.

Patch 1 performed the direct replacement from `setitimer()` to `alarm()` in `progress.c`, removing 108 lines of platform-specific code while adding only 34. Key changes included eliminating `compat/` layers for `setitimer()`, removing related build system checks, adding MinGW `alarm()` support, and simplifying Windows timer thread handling. It identified a shutdown race condition to be fixed in patch 2.

Patch 2 introduces a three-state shutdown protocol for the SIGALRM handler, replacing the boolean `progress_update` flag with tri-state values (0=no progress, 1=update needed, 2=shutdown). The signal handler now checks this state before rearming timers, and `clear_progress_signal()` properly sequences the shutdown transition. All progress display logic uses `(progress_update & 1)` to maintain functionality while adding safe termination. The changes are contained to `progress.c` and focus on the shutdown sequence without altering core reporting behavior.

Technical details:
- Progress meter now uses standard `alarm()` instead of POSIX `setitimer()`
- Tri-state `progress_update` flag ensures safe shutdown sequencing
- Removed `NO_SETITIMER` and `NO_STRUCT_ITIMERVAL` build flags
- Simplified Windows compatibility code (`compat/mingw*`)
- MinGW timer thread modified to check signal handler changes
- All progress checks updated to handle new state transitions

The series achieves its goal of modernizing the signal handling infrastructure while maintaining functionality and adding robust shutdown safety. Reviewers should verify:
- Atomicity of the tri-state transitions
- Absence of edge cases in shutdown sequences
- Compatibility with throughput display updates
