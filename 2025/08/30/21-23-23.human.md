Bugfix patch for midx error handling in Git's multi-pack-index functionality.

This is the second patch in a series addressing issues with midx (multi-pack-index) writing, specifically fixing a regression introduced in Git 2.47.0. The patch restores a missing error code assignment that was accidentally dropped in commit fcb2205b77, which could prevent proper error propagation when packfiles fail to load.

The change is straightforward - it adds back a `result = 1` assignment before cleanup when `fill_packs_from_midx()` fails. The patch also enhances an existing test case to verify that the error now properly propagates to the `git multi-pack-index write` command, checking both the failure status and the error message about pack loading.

This appears to be a well-justified fix for a clear regression, with a test that directly verifies the corrected behavior. The patch builds on existing test infrastructure rather than adding new complexity, and the change aligns with the series' overall goal of improving midx error handling reliability. As part of a reviewed series that's already received positive feedback, this patch seems ready for inclusion.
