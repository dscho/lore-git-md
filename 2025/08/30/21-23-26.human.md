Refactoring patch in the midx-write.c cleanup series, focusing on type safety and signed/unsigned comparisons.

This is patch 5/6 in Derrick Stolee's series fixing midx (multi-pack-index) writing issues. The patch removes the `DISABLE_SIGN_COMPARE_WARNINGS` flag and cleans up signed/unsigned comparison warnings in midx-write.c by properly typing loop variables. The main changes involve:

1. Converting loop variables from `int` to appropriate unsigned types (`uint32_t` or `size_t`) when they're compared against unsigned values
2. Replacing some strict inequality checks with non-strict ones where appropriate
3. Adding a defensive check against UINT32_MAX for the number of incremental midx files (though this is noted as being extremely unlikely in practice)

The changes are mechanical but improve type safety and prepare the codebase for stricter compiler warnings. This follows logically from patch 4's conversion of `preferred_pack_idx` to `uint32_t`. The patch appears straightforward and uncontroversial, completing the type safety work started earlier in the series.
