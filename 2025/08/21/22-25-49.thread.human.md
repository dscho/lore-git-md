This thread documents the addition of a README file for gitk, Git's repository browser. Johannes Sixt (Hannes), the gitk maintainer, initiated the effort to fill this documentation gap. Michael Rappazzo contributed a v2 patch that simplified the contributing section from v1 and added comprehensive usage examples, build instructions (covering both make and meson), and contribution guidelines.

Johannes has now reviewed v2, providing detailed feedback to polish the documentation. His suggestions focus on formatting consistency (using "Gitk" with uppercase G, underline headers instead of markdown syntax, 70-column line wrapping) and adding a note about running gitk directly from source during development. He also raised questions about whether `make install` should recommend system-wide installation (it defaults to $HOME/bin) and expressed some uncertainty about the meson build instructions while accepting them. The core content remains substantively unchanged from v2, with Johannes' review focusing on presentation details and technical accuracy. The thread shows an active maintainer carefully guiding documentation improvements for this long-standing Git component.
