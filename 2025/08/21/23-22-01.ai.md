This is the third patch in a bugfix series addressing issues with `git repack --path-walk` and singleton objects. The patch refactors path list initialization in `path-walk.c` by introducing a new helper function `add_path_to_list()` that consolidates three similar initialization patterns that were previously duplicated. The helper handles the common case of allocating a new `type_and_oid_list`, setting its type, adding it to the paths map, and managing the `maybe_interesting` flag and oid array.

The refactoring directly addresses the root cause fixed in patch 2, where missing `maybe_interesting` initialization led to bugs. By centralizing this logic, the change aims to prevent similar oversights in the future while making the code more maintainable. The patch maintains the existing behavior for fixed lists (tags, commits, root trees etc.) that don't use the new helper.
