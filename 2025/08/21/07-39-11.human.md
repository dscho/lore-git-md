This is part 13 of Patrick Steinhardt's ongoing series to abstract packfile management into a dedicated `packfile_store` structure. The patch moves the `get_multi_pack_index()` function from packfile.c to midx.c, where it more logically belongs as part of the multi-pack index subsystem.

The change is motivated by the need to expose `packfile_store_prepare()` (which the function calls) for future use outside the packfile system. The patch makes this preparation function public in packfile.h with documentation, then relocates `get_multi_pack_index()` to midx.c while keeping its implementation identical. 

This is a straightforward mechanical change that improves code organization by moving MIDX-related functionality to its proper subsystem. The patch maintains all existing behavior while setting up for future changes that will need to call `packfile_store_prepare()` from other locations. It fits naturally into the series' progression toward better separation of concerns between the packfile and MIDX subsystems.
