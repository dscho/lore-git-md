This is a feature patch (part 1/2) adding a `-z` flag to `git repo info` as part of a GSoC project. The patch makes the command consistent with other Git commands like `git-config` and `git-status` by providing `-z` as a shorthand for `--format=nul` to produce null-terminated output.

The implementation adds the new flag with proper option parsing that prevents using `-z` and `--format` together, following Git's standard patterns. Documentation is updated in both the command help and man page to explain the new flag. The patch includes two new tests: one verifying the null-terminated output works correctly, and another ensuring the flags can't be combined.

Karthik Nayak provides a minor nit about formatting in the documentation (suggesting spaces around the pipe character for readability) but otherwise approves the patch. The changes touch builtin/repo.c for the flag implementation, Documentation/git-repo.adoc for the docs, and t/t1900-repo.sh for tests. This is a straightforward addition that follows established Git conventions for null-terminated output flags.
