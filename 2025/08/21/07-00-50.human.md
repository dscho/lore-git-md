This is a documentation follow-up in the ongoing thread about color handling inconsistencies in Git's interactive patch mode.

Jeff King acknowledges Isaac Oscar Gariano's confirmation that using `interactive.diffFilter` with `diff-highlight` successfully works around the color configuration issues in interactive patch mode. He notes that the README file currently only documents using `pager.<cmd>` for similar purposes, likely because it predates the introduction of the `interactive.diffFilter` option.

King indicates he's preparing patches that will include updating the documentation to properly reflect this workaround. This addresses one of the open questions from the thread about whether the `interactive.diffFilter` workaround should be documented. The response suggests the documentation gap will be closed soon, though the underlying color handling inconsistency in the affected commands remains to be fixed separately.
