Refactoring patch in Patrick Steinhardt's ongoing object database abstraction series. This is patch 5/16 moving the MRU (most-recently-used) list of packfiles from `struct object_database` to the new `struct packfile_store`.

The change relocates the MRU list tracking recently accessed packfiles, which helps optimize object lookups by prioritizing frequently used packs. The patch mechanically moves the list initialization and all related operations (in midx.c, odb.c, and packfile.c) to the packfile store while maintaining identical behavior. 

This continues the series' pattern of systematically moving packfile-specific state out of the generic ODB structure. The changes are straightforward - removing the MRU list from odb.h while adding it to packfile.h, updating all references to use the new location, and initializing it in `packfile_store_new()`. 

The patch appears cleanly implemented with no behavior changes, just structural relocation of code as part of the larger effort to enable pluggable ODB backends. It follows the same proven pattern as previous patches in the series that moved other packfile-related components.
