This Documentation patch finalizing git-add's ignored files explanation

This is the final patch in Julia Evans' v3 series improving `git-add` documentation, specifically focusing on simplifying the explanation of how ignored files are handled. The patch replaces a more verbose and technical description with a clearer, more direct explanation of the behavior when adding ignored files.

The new version makes several improvements:
- Moves the `--force` option mention earlier for better visibility
- Distinguishes between explicitly named files (which produce an error) and globbed/recursive cases (which are silent)
- Removes now-unnecessary discussion of shell globbing vs Git globbing
- Uses simpler, more direct language while maintaining technical accuracy

Junio Hamano reviews the change positively, calling it "much simplified, yet still teaches the same thing." This concludes the v3 series which has now incorporated all feedback from reviewers. The author will rebase the series to target the proper base version (v2.50.0) as noted in the thread, but the technical content is complete and approved.

This represents the culmination of careful work to make Git's documentation more accessible while preserving its technical precision - a good example of documentation improvement that benefits both new and experienced users.
