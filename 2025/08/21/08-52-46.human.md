Test patch for the new `git refs exists` subcommand, part of Meet Soni's GSoC project to consolidate ref-related commands. This is the second patch in a 2-part series that introduces a new way to check ref existence under the `git refs` namespace.

The patch focuses on testing, ensuring the new `git refs exists` command behaves identically to the existing `git show-ref --exists` functionality. Rather than duplicating tests, it extracts the existing show-ref existence tests into a shared helper script (`show-ref-exists-tests.sh`) that both the old and new commands can use. This approach demonstrates good test hygiene by avoiding redundancy while maintaining comprehensive coverage.

The tests verify various edge cases including: checking HEAD, handling bad ref names, testing with symrefs (both valid and dangling), and verifying behavior with special refs like FETCH_HEAD. The new test file `t1462-refs-exists.sh` sets up a basic repository state before running the shared test suite.

The patch appears well-structured and follows Git's testing conventions. It's part of a larger effort to reorganize ref-related commands under the `git refs` namespace, with clear mentorship from Patrick Steinhardt and shejialuo. The shared test approach suggests this will be maintainable as the refs command family evolves.
