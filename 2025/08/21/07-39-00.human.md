This is part 2 of Patrick Steinhardt's 16-part series refactoring Git's object database to introduce a dedicated `struct packfile_store` for packfile management. The patch moves the core `packed_git` list from `struct object_database` to the new store structure, along with related cleanup logic.

The changes are mechanical but wide-ranging, updating all code that accessed the packfile list directly through the ODB to instead go through the packfile store. Key changes include:
- Moving the `packed_git` list pointer to `struct packfile_store`
- Extracting packfile cleanup from `odb_clear()` into new `packfile_store_free()`
- Adding a new `packfile_store_close()` function for packfile closing
- Updating all iteration over packfiles to use the new location

The patch maintains identical behavior while better organizing the code. It's part of a larger effort to separate packfile concerns from the generic object database, paving the way for future pluggable ODB backends. The changes are straightforward and follow the pattern established in earlier patches of the series.
