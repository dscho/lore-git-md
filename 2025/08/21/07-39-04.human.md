This is part 6 of Patrick Steinhardt's ongoing series to refactor packfile management into a dedicated `struct packfile_store`. The patch moves the "kept pack cache" - used by `git-pack-objects` to handle cruft objects - from `struct object_database` to the new packfile store structure.

The changes are mechanical but important: the patch relocates the cache data structure and updates all related functions to reference it through the packfile store instead of directly through the object database. This completes the migration of all packfile-related state from the generic ODB to the specialized store.

The patch maintains identical behavior while improving code organization. It's a straightforward continuation of the series' pattern, following the same approach used in previous patches for other packfile components. The commit message clearly explains the change and its motivation, noting this was the last remaining packfile-specific state in the ODB structure.

This change helps pave the way for future work on pluggable ODB backends by further separating concerns between the generic object database interface and packfile-specific implementation details. The patch appears well-tested and uncontroversial, following the established pattern from earlier in the series.
