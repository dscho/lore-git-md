This is a documentation patch adding a README for gitk, Git's graphical repository browser. It's the second version of this patch, with some simplifications from the initial submission.

The new README provides clear usage examples for common gitk commands, including viewing repository history, specific files/directories, and commit ranges. It also covers build instructions for both make and meson build systems, noting gitk's Tcl/Tk dependency.

For contributors, it outlines the preferred email-based patch submission process while acknowledging GitHub PRs as an alternative. The v2 changes removed some detailed workflow instructions and repository status details that were in v1, making the document more focused.

The patch looks well-structured and fills a clear documentation gap - gitk has existed for years without its own README. The content appears accurate and matches gitk's actual behavior. While simple, this is a useful addition that will help new users and contributors understand the tool better.
