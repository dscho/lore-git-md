Refactoring patch in Patrick Steinhardt's ongoing object database abstraction series. This is patch 9/16, continuing the effort to move packfile management into a dedicated `struct packfile_store`.

The patch splits the responsibilities of `reprepare_packed_git()` by:
1. Introducing a new `odb_reprepare()` function in odb.c that handles general object database maintenance (reloading alternates, clearing caches)
2. Refactoring the existing function to become `packfile_store_reprepare()`, now focused solely on packfile operations
3. Updating 12 call sites across the codebase to use the new function

The change better aligns with the series' goal of separating packfile concerns from the generic object database. The mechanical nature of the change (just moving code between files with minimal logic changes) makes it low-risk, though it touches many files. The patch follows the established pattern of the series by maintaining identical behavior while improving architectural clarity.
