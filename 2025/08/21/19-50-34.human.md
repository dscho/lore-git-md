This is a documentation follow-up to a concluded discussion about patch hunk headers.

Junio Hamano responds to Seyi Kuforiji's realization that the hunk headers (`@@ -L,K +M,N @@`) in patch output already provide the line number context that their withdrawn `--with-line-numbers` proposal sought to add. Kuforiji suggests adding documentation about hunk header interpretation, admitting they previously overlooked this standard diff format feature.

Hamano notes that while core documentation shouldn't duplicate the POSIX diff specification (which already defines the format), the "MyFirstContribution" tutorial might be an appropriate place to explain this for newcomers. The exchange serves as a postscript to the earlier discussion, shifting focus from feature implementation to potential for better onboarding documentation.

The thread remains closed regarding the original proposal, but leaves the door open for documentation improvements targeting new contributors who may similarly misunderstand patch format conventions.
