Follow-up discussion on `git repo info` man page formatting. This is part of a GSoC project adding two enhancements to `git repo info`: a `-z` flag for null-terminated output and an `objects.format` field showing the object format.

Patrick Steinhardt raised a question about the man page syntax for the mutually exclusive options `--format` and `-z`, suggesting an alternative bracketed format `[(--format=(keyvalue|nul)|-z)]` but noting it looks awkward. Author Lucas Seiki Oshiro responds that they couldn't find precedent for this syntax in Git's existing documentation and remains open to suggestions.

This is a minor documentation formatting question in an otherwise technically sound patch series that has received implementation approval from both mentors (Karthik Nayak and Patrick Steinhardt). The series builds on the `lo/repo-info` topic and targets v2.51.0. The only outstanding issues are this syntax question and a minor style nit (missing space before closing brace) in the second patch.
