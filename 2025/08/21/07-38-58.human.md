This is a refactoring series that continues Patrick Steinhardt's work on abstracting Git's packfile management as part of the object database (ODB) effort. The 16-patch series introduces a new `struct packfile_store` to centralize packfile-related state and operations, moving them out of the more generic `struct object_database`.

The key change is the creation of this new structure to become the single source of truth for packfile management. The series systematically moves various packfile-related fields from the packed_git list, MRU list, packfile map, and other state into this new store. This is groundwork for future work on pluggable object databases, where packfile management will need to be handled at a lower level.

Version 2 includes some minor refinements from the first version: converting an initialization flag to a boolean, polishing commit messages, and making some formatting adjustments. The changes are mechanical but wide-ranging, touching packfile.c/h, odb.c/h, and several other files that interact with packfiles.

The series appears well-structured and focused, with each patch handling a specific piece of the refactoring. Patrick has already addressed some initial feedback about MIDX handling and commit message clarity. The changes maintain identical behavior while improving the architecture - a textbook example of a careful refactoring series.
