- Updates all affected functions to reference the new structure instead of individual globals
- Maintains identical behavior while restructuring the internal implementation
- Touches 46 lines across `bulk-checkin.c` (24 insertions, 22 deletions)

The patch follows the established pattern for `the_repository` removal by first consolidating state before wiring through proper repository context in subsequent patches. It addresses the architectural concern about state management while preserving all existing functionality. The changes are mechanical but important groundwork for the rest of the series.
