This is a feature proposal introducing a new `git refs exists` subcommand, part of a GSoC project to consolidate ref-related commands. The 2-patch series aims to provide a modern alternative to `git show-ref --exists` by moving this functionality under the `git refs` namespace.

The first patch implements the new subcommand by duplicating the core logic from `show-ref` rather than abstracting it, keeping the initial implementation simple. The second patch thoroughly tests the new command by refactoring existing `show-ref --exists` tests into a shared helper script, ensuring both commands maintain identical behavior.

The changes touch documentation, the refs builtin, and test infrastructure, adding about 150 lines while removing 66 lines of redundant test code. The approach appears well-considered - it provides feature parity with the existing command while following Git's recent trend of grouping ref-related operations under `git refs`. The test coverage is particularly thorough, suggesting this is a robust implementation.
