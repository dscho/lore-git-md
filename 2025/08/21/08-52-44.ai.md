This is a cover letter for a feature patch series introducing a new `git refs exists` subcommand. The series consists of 2 patches from Meet Soni as part of GSoC, continuing the effort to consolidate ref-related commands under the `git refs` namespace.

The first patch implements the new `exists` subcommand in builtin/refs.c, duplicating the core logic from `git show-ref --exists` rather than abstracting it. The second patch refactors existing `show-ref --exists` tests into a shared helper script (t/show-ref-exists-tests.sh) and adds new tests specifically for `git refs exists` in t/t1462-refs-exists.sh.

The changes touch documentation (git-refs.adoc), core refs functionality (builtin/refs.c), and test infrastructure (multiple test files). The implementation appears straightforward with clear test coverage, though the choice to duplicate rather than share the existence-checking logic between commands may warrant discussion about long-term maintenance. The series builds on a substantial base of prerequisite patches (listed in the lengthy prerequisite-patch-id section).
