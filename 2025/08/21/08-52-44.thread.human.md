Meet Soni has proposed a new `git refs exists` subcommand as part of their GSoC project to consolidate ref-related commands under the `git refs` namespace. The initial two-patch series implements the command (which duplicates `git show-ref --exists` functionality) and adds comprehensive testing.

The first patch introduces the subcommand in builtin/refs.c, calling refs_read_raw_ref() with the same error handling as show-ref. The second patch, which just arrived, focuses on testing - it extracts existing show-ref tests into a shared helper script and adds a new test specifically for the refs exists command. The tests verify behavior across various edge cases including regular refs, HEAD, symrefs, and error conditions, ensuring the new command matches show-ref's behavior.

An open question remains about whether maintaining duplicate existence-checking logic between show-ref and refs exists is sustainable long-term. This is Meet's first submission of the series, so we're awaiting initial reviews from the community. The work builds on prerequisite patches for the broader refs command consolidation effort.
