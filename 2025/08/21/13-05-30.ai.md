This is a follow-up in the submodule gitdir path encoding series, specifically responding to review feedback on patch 3/9 which introduced a config override mechanism for submodule gitdir paths.

Adrian Ratiu acknowledges Josh Steadmon's request to document the new `submodule.<name>.gitdirpath` config option in `Documentation/config/submodule.adoc`. The author confirms this documentation gap will be addressed in the upcoming v2 revision of the patch series. This is one of several refinements being made based on reviewer feedback, alongside test script improvements and platform-specific fixes identified in the thread.

The core functionality of patch 3/9 remains unchanged - it provides a way to override the default path encoding scheme for submodule gitdirs, particularly useful for interoperability with other implementations like JGit. The patch adds both the config option implementation and test infrastructure (including a new helper script) to verify gitdir path locations. The response confirms the series is progressing through the review process with incremental improvements being incorporated while maintaining its technical approach.
