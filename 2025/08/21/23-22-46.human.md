This is the first patch in a 4-part series refactoring Git's bulk-checkin subsystem as part of the `the_repository` removal effort. It introduces a new `struct odb_transaction` to consolidate several global variables that track state during bulk-checkin operations.

The patch moves three previously separate globals (`odb_transaction_nesting`, `bulk_fsync_objdir`, and `bulk_checkin_packfile`) into a single structured container. This is a preparatory change that enables the subsequent patches to properly parameterize the bulk-checkin operations with repository context. The diff shows mechanical updates to all affected code paths to use the new structure while maintaining identical behavior.

The change is cleanly implemented with straightforward variable renames and structure changes. As the first step in the series, it doesn't yet address the full context propagation goals, but establishes the foundation by centralizing the state management. The patch maintains all existing functionality while making the codebase more amenable to the larger refactoring effort.
