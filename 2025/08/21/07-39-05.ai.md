Refactoring patch in Patrick Steinhardt's ODB abstraction series. This is patch 7/16, which reorganizes functions in packfile.c to eliminate a forward declaration of `prepare_packed_git()` by moving `repo_approximate_object_count()` below the function it depends on.

The change is purely mechanical - the implementation of `repo_approximate_object_count()` remains identical, just relocated after `get_packed_git_mru()` where `prepare_packed_git()` is now defined. This follows the established pattern in the series of making structural improvements while maintaining identical behavior.

Key technical details:
- Moves `repo_approximate_object_count()` down in the file
- Removes its `prepare_packed_git()` forward declaration
- No functional changes to the object counting logic
- Maintains all existing packfile/MIDX counting behavior
- Part of broader effort to clean up packfile.c organization
