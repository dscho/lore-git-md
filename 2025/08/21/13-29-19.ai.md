This is a follow-up discussion in a feature patch series about syntax formatting in the man page for the new `-z` flag in `git repo info`.

The thread has reached a minor stylistic question about how to best represent the mutually exclusive options in the man page syntax. Patrick Steinhardt suggested an alternative formatting `[(--format=(keyvalue|nul)|-z)]` but noted it looks somewhat ugly. The author Lucas Seiki Oshiro reports not finding similar complex syntax patterns elsewhere in Git's documentation and remains open to suggestions.

This is a minor polish point in an otherwise technically complete patch series that has already received implementation approval from both mentors (Karthik Nayak and Patrick Steinhardt). The series adds two independent features to `git repo info`: a `-z` shorthand for null-terminated output and an `objects.format` field showing the repository's object format. All substantive technical feedback has been addressed, with only this documentation formatting question remaining open.

The discussion appears to be winding down, with the author awaiting consensus on the preferred syntax format before making any final documentation tweaks. The patches are targeted for v2.51.0 and build on the existing `lo/repo-info` topic.
