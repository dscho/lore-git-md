Refactoring patch in the ongoing packfile store abstraction series. This is the final patch (16/16) in Patrick Steinhardt's v2 series that moves packfile management from `struct object_database` to the new `struct packfile_store`.

The patch changes `get_packed_git_mru()` to work directly with the packfile store rather than going through the repository. The function is renamed to `packfile_store_get_packs_mru()` to reflect its narrower scope. The implementation remains essentially the same - it prepares the packfile store (if needed) and returns a pointer to the MRU list - but now takes the store directly as a parameter rather than getting it from the repository.

The changes are mechanical and follow the pattern established in previous patches:
1. Updates the function signature and name
2. Modifies the implementation to use the store` parameter directly
3. Updates callers (in this case just `builtin/pack-objects.c`) to first get the packfile store from the repository
4. Moves the declaration from packfile.h to be with other packfile store functions

The patch maintains all existing behavior while continuing the series' goal of encapsulating packfile operations within the packfile store abstraction. This completes the transition of packfile-related functions to work directly with the store structure rather than going through the repository or object database.

Key technical details:
- Function renamed from `get_packed_git_mru()` to `packfile_store_get_packs_mru()`
- Parameter changed from `struct repository *` to `struct packfile_store *`
- Callers updated to first access `the_repository->objects->packfiles`
- MRU list access remains unchanged (`store->mru`)
- Maintains same preparation behavior via `packfile_store_prepare()`
- Only caller is in `builtin/pack-objects.c` for pack-objects operations

This is a straightforward conclusion to the series that follows the established pattern while maintaining all existing functionality. The change is purely mechanical with no behavior modifications, just continuing the encapsulation of packfile operations within the new store abstraction.
