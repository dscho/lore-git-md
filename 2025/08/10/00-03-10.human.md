Bugfix for the `git-jump` contrib script handling filenames with spaces in diff output. This is a follow-up to Greg Hurrell's patch that addressed a long-standing issue where `git-jump` would incorrectly process filenames containing spaces due to Git's diff output appending tabs to such filenames.

Junio Hamano acknowledges the patch while noting he's not a user of `git-jump` or Vim's quickfix mode himself. He agrees with the pragmatic approach of breaking the edge case of filenames ending with literal tabs to fix the much more common case of filenames containing spaces. The patch remains in the 'seen' branch for now since Jeff King (the usual maintainer for this area) is offline.

The change itself is minimal - a one-line Perl regex modification to optionally strip trailing tabs when parsing diff output. While this technically drops support for the obscure case of filenames ending with tabs, the tradeoff is considered worthwhile given how rare such filenames would be in practice. The thread suggests this simple solution is appropriate for now, leaving open the possibility of more complex handling if the edge case ever becomes problematic.
