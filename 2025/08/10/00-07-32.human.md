This is a documentation fix for the Git merge command. The patch corrects an incorrect help string for the `--compact-summary` option in `builtin/merge.c` that mistakenly suggested the option takes an argument when it actually doesn't.

The issue was introduced in commit 3a54f5bd5d when the `--compact-summary` option was added to both `git merge` and `git pull`. While the pull implementation correctly showed the option as taking no arguments, the merge implementation incorrectly included an argument help string ("compact-summary").

René Scharfe identified and fixed this inconsistency with a simple one-line change that replaces the misleading argument description with NULL while preserving the main help text. Junio C Hamano has already acknowledged the patch with a "Thanks" reply, indicating this straightforward documentation correction is likely to be accepted.

The change is small, focused, and uncontroversial - it simply aligns the merge command's documentation with both its actual behavior and the pull command's implementation of the same option. No behavioral changes are introduced by this patch.
