Documentation fix for git-clone option syntax. This is version 2 of a patch that corrects the nested bracket formatting for `--filter` and `--also-filter-submodules` options in the git-clone man page. The change properly nests `--also-filter-submodules` within `--filter`'s brackets to reflect that submodule filtering requires regular filtering.

The patch follows up on Junio Hamano's review of v1, which clarified the correct nesting relationship between these options. Changes from v1 include updating the commit message to be more direct (removing "this patch" phrasing) and ensuring the author name matches the commit signature. The actual doc change remains the same - removing an extra closing bracket that made the syntax incorrect.

The fix targets Documentation/git-clone.adoc, specifically the command-line synopsis section. This is a line that was originally introduced in commit f05da2b4 and later reformatted in 76880f05. The patch content shows the before/after diff, with the corrected syntax now showing `[--filter=<filter> [--also-filter-submodules]]` instead of the previous incorrect `[--filter=<filter>] [--also-filter-submodules]]`.

No functional impact - purely a documentation formatting correction.
