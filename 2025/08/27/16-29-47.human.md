Documentation patch providing clearer alternatives for deprecated commands. This is the second in a series improving guidance around `git whatchanged` deprecation.

Kristoffer Haugsbakk updates the error message and documentation to directly show users the `git log` equivalent (`--raw --no-merges`) when they try to use the deprecated `git whatchanged` command. The patch modifies both the man page and the runtime error message to include this concrete alternative, addressing user confusion that arose after Git 2.51.0's release.

The changes include adding a new optional `hint` parameter to the `you_still_use_that()` function in usage.c`, allowing callers to provide specific migration advice. The patch maintains all existing functionality while making the transition path clearer. The author cites multiple real-world reports of user confusion as motivation.
