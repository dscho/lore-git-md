Bugfix and documentation patch in the "Better guidance for users of deprecated commands" series. This is patch 2/4, addressing feedback on whitespace formatting in the implementation of improved deprecation warnings for `git whatchanged`.

The author acknowledges a whitespace formatting issue in the previous version of the patch, where tabs were accidentally replaced with spaces in the `builtin/log.c` file. Kristoffer Haugsbakk notes they'll correct this in the next version and mentions finding the `ci/check-whitespace.sh` script helpful for catching such issues.

This exchange comes after maintainer Junio Hamano initially thought the patch introduced a whitespace issue, but then realized it was actually fixing an existing inconsistency. The patch is part of a larger effort to provide better guidance when users encounter deprecated commands, with this specific change adding a hint parameter to show users the modern `git log` equivalent of `git whatchanged`.

The series has been receiving positive feedback from the maintainer, with this being a minor formatting correction needed before final inclusion. The core functionality changes (adding specific command translation guidance) remain uncontested.
