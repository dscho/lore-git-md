This is a refactoring patch in Patrick Steinhardt's ongoing series to abstract the object database by moving packfile management to `struct packfile_store`. 

The patch relocates `get_multi_pack_index()` from packfile.c to midx.c, where it more logically belongs. The function had previously lived in packfile.c because it needed to call the (then-private) `packfile_store_prepare()`. Since future changes will require exposing this function anyway, the patch makes the move now while also exposing `packfile_store_prepare()` in packfile.h.

Taylor Blau reviews the change and finds it straightforward - the code movement makes sense and the implementation looks correct. This continues the series' pattern of carefully reorganizing code to better separate concerns between the packfile and MIDX subsystems while maintaining existing behavior. The change is uncontroversial and fits well with the series' architectural goals.
