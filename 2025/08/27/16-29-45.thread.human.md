This thread documents the evolution of a comprehensive command deprecation framework for Git, now in its sixth iteration. The series introduces alias shadowing support and specifically targets the deprecation of `git-whatchanged`, providing users with clear migration paths to `git log --raw --no-merges`. The technical implementation spans nine patches covering everything from core infrastructure to documentation refinements.

Key contributors including Jeff King, Junio Hamano, and Kristoffer Haugsbakk have thoroughly reviewed the series. The latest discussion focuses on a build system edge case where leftover `git-whatchanged` binaries might cause confusion when switching between builds with and without the `WITH_BREAKING_CHANGES` flag. While acknowledging this as a minor operational issue, the consensus is to proceed with the current `.gitignore`-based solution and monitor the situation, with Kristoffer suggesting isolated worktrees as a practical workaround.

The series has addressed all technical and documentation aspects, with maintainers confirming the approach.
