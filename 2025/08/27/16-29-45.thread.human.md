The series introduces "alias shadowing" - allowing users to create aliases that override deprecated commands while making these deprecations more visible. The current version includes both technical implementation (adding a DEPRECATED flag to commands and programmatic listing support) and improved user messaging with clear guidance on alternatives.

Key contributors have been actively shaping the approach: Jeff King (Peff) proposed the core idea, Eric Sunshine helped refine the interactive usage aspects, and Kristoffer Haugsbakk polished the documentation. The series builds on prior work deprecating `git whatchanged` and now marks both `whatchanged` and `pack-redundant` as deprecated.

He recommends adjusting this to fully utilize the flag system, which would make the code more maintainable as more commands are deprecated in the future. This is a focused implementation refinement rather than a fundamental concern - the core design appears sound and ready for merging once this polish is addressed.
