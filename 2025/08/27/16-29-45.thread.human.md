This thread has been discussing a series to improve Git's command deprecation system by adding alias shadowing support for deprecated commands like `whatchanged` and `pack-redundant`. The fourth version of the patch series is now technically complete after Jeff King (Peff) resolved a memory leak in the core alias shadowing functionality. The implementation includes a new `DEPRECATED` command flag, optimized command listing, comprehensive test coverage, and improved user-facing error messages.

Junio Hamano has indicated the series is ready for integration into the 'next' branch once the final technical issue (a memory leak caught in CI) is resolved. Jeff King has confirmed the leak exists but considers it straightforward to fix, maintaining the series' path toward merging. The design has been explicitly approved by both Junio and Patrick Steinhardt, with all prior feedback incorporated. Documentation updates from Kristoffer Haugsbakk are also complete, making this a fully-baked solution for handling deprecated commands in Git.
