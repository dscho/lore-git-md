The implementation uses a `DEPRECATED` flag in git.c and relocates alias loop detection to properly handle deprecated commands.

The latest patch focuses specifically on improving the transition for `git whatchanged` users by enhancing the error message to show the exact `git log` equivalent (`--raw --no-merges`) and alias creation instructions. This builds on earlier work that established the deprecation infrastructure, fixed memory leaks, and validated behavior through comprehensive testing.
