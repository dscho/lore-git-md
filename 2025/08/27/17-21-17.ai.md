This is a discussion thread about the first patch in the 6-part series changing Git's default branch name from "master" to "main". Junio C Hamano responds to Phillip Wood's test update patch with two key concerns.

First, Junio questions whether removing GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME support is premature, suggesting the mechanism should remain available in case future naming changes are needed. He expresses skepticism that "main" will be the permanent solution, referencing the industry's previous shift from "master".

Second, Junio notes a minor error where Phillip's commit message refers to changing from 'topic' rather than 'trunk' in the test updates. The actual patch correctly updates the test file from using "trunk" to "main" in four locations, modifying the GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME setting and branch name assertions in the test expectations.

This exchange highlights an important design decision in the series - whether to maintain the test override mechanism long-term. Junio's position suggests he views the branch naming as potentially evolving rather than settled permanently on "main". The discussion doesn't yet indicate whether this will require changes to patch 6/6 which currently removes the test support when WITH_BREAKING_CHANGES is enabled.
