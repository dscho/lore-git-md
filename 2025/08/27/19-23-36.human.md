Feature proposal for hostname-based config includes, follow-up ping.

This is a follow-up email checking for feedback on a previously submitted patch that proposes a new `hostname:` condition for Git's `includeIf` config feature. The original patch would allow users to include different config files based on their machine's hostname, similar to existing `gitdir` and `onbranch` conditions.

The implementation adds a new `include_by_hostname()` function that uses `gethostname()` to check against the specified condition, with proper memory management via `strbuf`. The change is relatively small (31 lines added) and follows the pattern of other conditional includes, though it does introduce a new system dependency on hostname resolution.

The author demonstrates use cases for maintaining separate work and home configurations through different hostnames. While the core implementation appears solid, the initial submission notably lacked test coverage and documentation updates that would typically accompany a new feature of this nature. The thread has seen no responses since the original submission 6 days ago, prompting this polite ping from the author. The feature appears well-motivated and could be useful for users managing multiple machines, but would need those additional components (tests/docs) before being ready for inclusion.
