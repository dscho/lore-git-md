This is part 2/6 in a series updating tests to use "main" as the default branch name in preparation for changing Git's default initial branch name from "master" to "main" when WITH_BREAKING_CHANGES is enabled.

The patch mechanically updates t4013-diff-various.sh and its test expectation files to replace "master" with "main" in test commands and output. This includes:
- Changing GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME in the test script
- Updating branch references in test commands (e.g., `git log master` -> `git log main`)
- Renaming 97 test expectation files (diff.*) with "master" in their names to use "main" instead
- Updating the content of those files to reflect the branch name change

The changes are purely mechanical string replacements as confirmed by the commit message. This follows the series' approach of updating tests first before changing the implementation. The patch is large (97 files modified) but straightforward, with each change following the same pattern of branch name substitution.

This continues the work started in patch 1/6 (which updated t0018-advice.sh) to prepare the test suite for the eventual default branch name change.
