This thread explores a proposal to add commit comment functionality to Git, allowing supplemental notes to be attached to existing commits and displayed in `git show` output. Rune Philosof initiated the discussion by outlining potential use cases and technical considerations, including storage format and platform integration possibilities.

Kristoffer Haugsbakk has pointed out that Git's existing `git-notes` feature already provides similar capabilities, and noted that GitHub discontinued their commit comments feature in 2014 - raising questions about both technical redundancy and actual demand. The discussion now centers on whether the proposal should build upon `git-notes` or create a new mechanism, and whether GitHub's experience suggests the feature may not widely needed. No implementation work has begun yet, and the conversation remains at the conceptual stage while these fundamental questions are considered.
