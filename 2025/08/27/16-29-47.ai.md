Documentation patch providing concrete migration guidance for deprecated commands, specifically `git whatchanged`. This is part 2 of Kristoffer Haugsbakk's series to improve user experience around deprecated commands.

The patch enhances the error message and documentation for `git whatchanged` by explicitly showing users the equivalent `git log` command (`git log --raw --no-merges`). It modifies the `you_still_use_that()` function in usage.c to accept an optional hint parameter, which is used to display this specific guidance. The patch also updates the git-whatchanged.adoc man page to include the same command equivalency.

Key technical changes include:
- Added hint parameter to `you_still_use_that()` function signature (git-compat-util.h)
- Modified error message formatting in usage.c to display the hint if provided
- Updated builtin/log.c to pass the specific git log equivalent for whatchanged
- Maintained backward compatibility by allowing NULL hints (used in pack-redundant.c)
- Added concrete command in git-whatchanged.adoc documentation

The changes are motivated by multiple user reports showing confusion about the whatchanged deprecation, with the author noting that users weren't finding the man page guidance. The implementation follows up on previous patch's URL-based guidance system while adding more direct migration instructions.
