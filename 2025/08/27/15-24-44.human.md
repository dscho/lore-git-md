This is a feature proposal to change Git's default initial branch name from "master" to "main" when built with WITH_BREAKING_CHANGES enabled. Phillip Wood presents a 6-patch series that prepares for and implements this long-discussed change, following the ecosystem trend where major Git forges have already made this switch.

The first five patches update test infrastructure to handle "main" as the default branch name, with patch 2 being particularly large mechanical update to test expectations. The final patch makes the actual behavior change while removing the transitional GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME option. The changes are gated behind WITH_BREAKING_CHANGES to avoid surprising users who haven't opted into breaking changes.

The series appears well-structured, building on warnings about this change that have been in place since 2020. The mechanical test updates suggest careful preparation, though reviewers will want to verify the automated changes in patch 2. This represents a significant but well-signaled shift in Git's defaults, aligning with broader industry practices around branch naming.
