Feature proposal for commit comments. Rune Philosof suggests adding a mechanism to attach supplemental comments to existing commits, similar to GitHub's comment system but built into Git itself. The proposal envisions comments being stored as special commit objects with a reference field linking them to the target commit, and suggests this could integrate with platform-specific comment systems. The motivation is to allow adding contextual information to commits after they're created, which would be visible in `git show` output. No implementation details or patches are provided - this is purely a conceptual proposal at this stage. The idea touches on Git's object model and would require careful design around storage format, performance (indexing is mentioned), and potential integration with external platforms.
