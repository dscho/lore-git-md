This is the first patch in a 6-part series changing Git's default initial branch name from "master" to "main" when WITH_BREAKING_CHANGES is enabled. The patch updates t0018-advice.sh test file to use "main" instead of "trunk" as the default branch name in test cases.

The changes are mechanical - replacing "trunk" with "main" in test expectations and setup. The commit message explains that while these tests previously used "trunk", the actual name was incidental to testing the advice message functionality. The change prepares for Git 3.0's planned switch to "main" as the default branch name and removal of GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME support.

The patch is straightforward with a clear, focused scope (just one test file) and follows the series' strategy of updating tests first before changing the actual default branch implementation. The test changes look correct and maintain the same verification logic while adapting to the new naming convention. This appears to be a well-executed first step in the larger transition effort.
