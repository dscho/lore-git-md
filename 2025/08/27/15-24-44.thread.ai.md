Thread identity: Cover letter for a 6-patch series proposing to change Git's default initial branch name from "master" to "main" when WITH_BREAKING_CHANCHES is enabled.

Core problem: Align Git's default branch naming with industry practice by changing the default from "master" to "main" for users opting into breaking changes, following a deprecation warning introduced in 2020 (commit 675704c74dd).

Current status: First two patches submitted for review. Patch 1/6 updated t0018-advice.sh to use "main" instead of "trunk" in test cases. Patch 2/6 mechanically updates t4013-diff-various.sh and 97 associated test expectation files to replace "master" with "main" in test commands and output.

Technical details:
- Changes gated behind WITH_BREAKING_CHANGES compile-time flag
- Removes GIT_TEST_DEFAULT_INITIAL_BRANCH_NAME when enabled
- Updates refs.c and advice.c/h to implement new default (pending in later patches)
- Documents change in BreakingChanges.adoc and git-init.adoc
- 109 files modified (281+253 line changes) in total series
