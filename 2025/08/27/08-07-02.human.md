This is a bugfix patch addressing a test failure caused by changes in libcurl's logging behavior. Jeff King noticed that a Git test (t5564) checking SOCKS proxy functionality started failing with libcurl 8.16-rc2 because the proxy-related debug messages moved to a new component-based tracing system.

The patch adds support for curl_global_trace() to selectively enable logging components, specifically targeting the "socks" component needed by the test. The implementation is backward-compatible, gracefully handling older curl versions that don't support this feature. The new GIT_TRACE_CURL_COMPONENTS environment variable controls which components are enabled, though this is intentionally undocumented as an internal debugging aid.

The change is minimal and focused, touching only three files: adding a version check in git-curl-compat.h, implementing the component support in http.c, and updating the test to use the new tracing mechanism. The patch appears well-considered, with Jeff noting he considered alternative approaches (like hardcoding "socks" or matching different output formats) but settled on this more flexible solution that could be useful for future debugging.
