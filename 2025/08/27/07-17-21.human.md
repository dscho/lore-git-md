This is a documentation patch for `git cherry-pick`. Emily Shaffer adds missing documentation for rev-list options that were added to `git cherry-pick` back in 2010 but never properly documented in the man page. The options were previously only shown in examples, making them effectively hidden features.

The patch simply includes the standard rev-list options documentation section that appears in many other Git commands' man pages. This brings `git cherry-pick` in line with other commands and makes these options properly discoverable to users. The change was prompted by a user report on social media noting the undocumented options.

The implementation is straightforward - just a two-line addition to include the standard rev-list options documentation. This is a clear improvement that follows Git's established documentation patterns. The patch series appears to be a single commit addressing this specific documentation gap.
