This is part of Karthik Nayak's series to implement header checking in Meson builds, specifically focusing on refactoring header variable definitions. The patch moves header-related variables from contrib/coccinelle/meson.build to the root meson.build file to enable sharing between different build components.

Key technical changes include:
1. Renames 'coccinelle_headers' to 'headers_to_check' and moves it to root meson.build
2. Moves 'third_party_sources' exclusion list to root meson.build
3. Maintains path prefixing logic in coccinelle-specific build file while using the shared header list
4. Adds conditional initialization of headers_to_check list (only when git is found)
5. Uses git ls-files with third_party_sources exclusions to populate headers_to_check
6. Fixes a duplicate entry for t/unit-tests/clar in third_party_sources

The changes prepare for upcoming header checking functionality while improving code organization by centralizing header definitions. The patch follows the established pattern of moving build configuration upwards in the hierarchy while keeping implementation-specific details localized. This continues the series' trend of refining variable scoping and naming conventions based on prior review discussions.
