This is a small refactoring patch series that removes redundant NULL checks in two Git commands, following a recent change to `repo_config()` that made these checks unnecessary.

The series removes NULL checks before `repo_config()` calls in `builtin/add.c` and `builtin/difftool.c`, since commit f29f1990b5 ("config: teach repo_config to allow `repo` to be NULL") made the function safely handle NULL repository arguments. The change was suggested by Patrick Steinhardt.

The patches are straightforward - each removes a conditional wrapper around a `repo_config()` call, simplifying the code. The changes are mechanical and appear correct, though they don't include test updates since they don't change behavior, just remove now-unnecessary checks. 

This is a minor cleanup that aligns with the ongoing effort to modernize Git's codebase, though it's not part of any larger initiative. The changes are small, focused, and well-explained, making them easy to review.
