This is a build system patch that finalizes the naming convention for header checking targets in both Makefile and Meson builds. The patch introduces 'check-headers' as a more readable alternative to the existing 'hdr-check' target, which was considered unclear since 'hdr' isn't a standard abbreviation. The change maintains backward compatibility by keeping 'hdr-check' as an alias with a planned deprecation in Git 2.51+ (about two releases from now).

The implementation updates both build systems consistently - the Makefile now declares both targets with 'check-headers' depending on 'hdr-check', while Meson uses alias_target() to create the same relationship. The CI script is also updated to use the new target name. This change follows through on earlier naming discussions in the thread where Phillip Wood and Junio C Hamano preferred the more explicit 'check-headers' naming convention.

The patch is straightforward and well-contained, completing the series' goal of bringing Meson's header checking functionality to parity with Makefile while improving the target naming. Since this is the final patch in the series and all technical aspects have been thoroughly reviewed, it appears ready for merging.
