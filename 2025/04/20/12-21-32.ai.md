This is a CI/build system patch series completing the implementation of header checking in Meson builds, now with final technical refinements. The series has evolved through multiple versions with extensive review, addressing naming conventions, exclusion handling, and dependency chaining.

The key technical aspects in this v4 version include:
- Renaming `headers` to `headers_to_check` to clarify purpose
- Converting `third_party_sources` to `third_party_excludes` with cleanup
- Fixing a crypto backend typo (`gcrpyt` -> `gcrypt`)
- Removing redundant `generated_headers` exclusion since `git ls-files` already handles ignored files
- Documenting the rationale for excluding xdiff/ headers
- Properly chaining dependencies between `hdr-check` and `check-headers` targets via `alias_target()`

The implementation now matches Makefile's hdr-check functionality while introducing the better-named `check-headers` alias (keeping `hdr-check` temporarily for compatibility). The series has addressed all feedback from reviewers including Phillip Wood, Patrick Steinhardt, and Junio C Hamano, with particular attention to:
- Variable naming conventions (`check-headers` over `headers-check`)
- Exclusion list handling (directory patterns, crypto backend conditionals)
- Generated file handling
- Dependency chain correctness

The changes touch the main meson.build file, coccinelle build file, Makefile, and CI script, with clean separation between the header checking infrastructure and the actual header lists.
