This is part of Karthik Nayak's series implementing header checking functionality in Meson builds, matching the Makefile's 'hdr-check' capability. The patch adds the core implementation for header verification in Meson, completing the technical foundation established in earlier patches.

The implementation creates a two-stage process for each header file: first generating a simple C file that includes the header (hcc target), then compiling it (hco target). It handles exclusions for platform-specific headers and crypto backends, mirroring the Makefile's behavior. Key technical details include proper dependency chaining, GCC-specific compilation flags, and path handling for out-of-tree builds. The patch also adds xdiff/ to third_party_excludes (now renamed from third_party_sources in this version) since those headers are external dependencies.

The implementation shows careful attention to detail, with proper conditional checks for Git availability and GCC syntax, and maintains consistency with the Makefile version while adapting to Meson's out-of-tree build model. The exclusion logic is robust, handling both directory patterns and specific files. The patch builds on previous architectural decisions in the series while completing the core functionality.
