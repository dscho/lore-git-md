This is part of Karthik Nayak's series to port Git's header checking functionality from Makefile to Meson builds. The patch implements the 'hdr-check' target in Meson, which verifies that individual header files can be compiled independently.

The implementation closely follows the Makefile version but adds necessary dependency handling for Meson's out-of-tree builds. It includes exclusions for platform-specific headers (like those in compat/) and conditionally excludes crypto headers based on the active backend. The patch also adds xdiff/ to the third_party_excludes list since those headers are external dependencies.

The technical implementation uses Meson's custom_target() to create temporary compilation units for each header, with proper include paths and compiler flags. The final 'hdr-check' target is created as an alias to these individual checks. This appears to be a well-considered port of existing functionality, with attention to the differences between Make and Meson build systems.

This is the fourth patch in a 5-part series that has undergone thorough review, with all major technical decisions already settled in previous iterations. The implementation looks complete and ready for merging.
