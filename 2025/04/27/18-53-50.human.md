Test modernization patch converting reftable record tests to Clar framework. This is patch 8/9 in a series standardizing Git's test infrastructure by migrating reftable tests to the Clar unit testing framework. The patch follows the established pattern of converting `t-reftable-record.c` to `u-reftable-record.c`, replacing custom test assertions with Clar's `cl_assert*` macros while maintaining the same test coverage.

The tests verify reftable's record handling for various record types (ref, log, obj, index) including comparison operations, roundtrip encoding/decoding, and edge cases. The conversion is mechanical but thorough - the new file is 565 lines compared to the original 585, showing some consolidation while keeping all the test cases. Build system files (Makefile and meson.build) are updated to reference the new test file.

This continues the series' consistent approach with no functional changes to reftable itself, just test infrastructure modernization. The patch appears well-formed and follows the same high quality as previous conversions in the series.
