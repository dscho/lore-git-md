This is the 8th patch in a 9-part series converting reftable unit tests to the Clar framework. The patch focuses on converting the reftable record test file (t-reftable-record.c -> u-reftable-record.c).

The conversion follows the established pattern seen in previous patches of the series:
- Renames the test file from t- to u- prefix
- Replaces custom test assertions with Clar's cl_assert* macros
- Maintains all existing test coverage while modernizing the implementation
- Updates build system references (Makefile and meson.build)

The test file being converted verifies core reftable record functionality including:
- Record type comparisons and equality checks
- Roundtrip encoding/decoding of ref, log, obj, and index records
- Varint encoding/decoding operations
- Key handling and comparison operations

The patch shows the typical mechanical conversion pattern with:
- 585 lines removed from old test file
- 565 lines added in new Clar-based version
- Build system updates to remove old test and add new one

This continues the systematic conversion of all reftable test files to Clar, with only one remaining test file (reftable-stack) left to convert in the series. The changes are purely test infrastructure with no functional impact on reftable itself.
