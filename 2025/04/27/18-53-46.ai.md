This is the fourth patch in a 9-part series converting reftable unit tests to the Clar framework, specifically targeting the merged table functionality. The patch follows the established pattern of the series, converting `t-reftable-merged.c` to `u-reftable-merged.c` with Clar assertions.

The conversion maintains all test coverage while reducing the file size from 546 to 515 lines. The tests verify core merged table operations including:
- Single record retrieval
- Multiple ref updates
- Repeated seeks
- Log record merging
- Default write options handling

Key technical changes mirror previous patches in the series:
- Replace custom `check()` assertions with Clar's `cl_assert*`
- Rename test functions to Clar's `test_*__*` pattern
- Update Makefile/meson.build to reference new u-reftable-merged.c
- Preserve all test cases and edge case coverage

The patch continues the series' mechanical conversion approach with no functional changes to the reftable implementation itself. It maintains identical test coverage while modernizing to the Clar framework. The merged table tests are particularly important as they verify the core functionality that combines multiple reftables.
