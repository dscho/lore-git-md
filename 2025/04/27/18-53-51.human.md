This is the final patch in a 9-part series converting reftable unit tests to the Clar framework. The patch converts the reftable stack test file from the old `t-` prefix format to the new Clar-based `u-` prefix format.

The conversion follows the same pattern as previous patches in the series:
- Renames the test file from `t-reftable-stack.c` to `u-reftable-stack.c`
- Updates build system files (Makefile and meson.build) to reference the new filename
- Converts test assertions to use Clar's `cl_assert*` macros
- Removes the old test file and its references

The patch also removes the now-unneeded sanity check for `t-*.c` files since this marks the completion of all test conversions in the series. The changes are mechanical and maintain the same test coverage while modernizing the test infrastructure.

This concludes the standardization effort to migrate all reftable-related tests to the Clar framework, following the pattern established in prior conversions. The series appears well-structured with each patch handling a specific test file conversion while maintaining consistency across the changes.
