Test modernization patch in the reftable Clar conversion series. This is the second of nine patches converting reftable tests from the old `t-` prefix format to the new Clar-based `u-` prefix framework.

The patch converts the reftable basics test file, which covers core utility functions like binary search, string array handling, buffer operations, and endian conversion helpers. The conversion follows the established pattern:
- Replaces `check_*` assertions with Clar's `cl_assert_*` equivalents
- Splits the single test function into multiple Clar test cases (one per logical test)
- Updates build system files (Makefile and meson.build) to reference the new test file
- Maintains identical test coverage while improving modularity

Key technical changes:
- Deletes `t-reftable-basics.c` (219 lines)
- Adds `u-reftable-basics.c` (195 lines) with same test cases reorganized into Clar format:
  - `test_reftable_basics__binsearch`
  - `test_reftable_basics__names_length`
  - `test_reftable_basics__names_equal`
  - `test_reftable_basics__parse_names`
  - `test_reftable_basics__common_prefix_size`
  - `test_reftable_basics__put_get_be24`
  - `test_reftable_basics__put_get_be16`
  - `test_reftable_basics__grow_alloc`
  - `test_reftable_basics__grow_alloc_or_null`

The patch appears mechanically sound, following the same conversion approach as the series' first patch and prior Clar migrations in Git. No functional changes to the actual reftable code - this is purely a test infrastructure update.
