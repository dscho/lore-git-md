The conversion reduces the file size from 161 to 152 lines while maintaining the same test coverage of priority queue functionality.

The tests verify three key aspects of reftable's priority queue implementation: record-based comparison (ensuring refnames sort correctly), index-based comparison (for tie-breaking), and proper behavior of the queue's top operation. The tests use synthetic data with predictable patterns (using modulo arithmetic to generate test cases) to thoroughly exercise the pq implementation.

Like previous patches in the series, this is a mechanical conversion that doesn't modify the actual reftable functionality - it just updates how the tests are written. The patch appears cleanly implemented, following the same style and approach as the earlier conversions in the series.
