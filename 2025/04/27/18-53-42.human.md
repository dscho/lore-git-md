This is a test infrastructure patch series completing the migration of reftable unit tests to the Clar framework. Seyi Kuforiji submits the final batch of conversions, covering all remaining reftable test files (basics, block, merged, priority queue, reader, read/write, record, and stack functionality).

The series represents a significant but mechanical change - deleting the old test implementations (totaling ~4,400 lines removed) and adding new Clar-based versions (adding ~4,000 lines). The cover letter notes this is part of an ongoing effort to standardize Git's test framework for better maintainability. Build system files (Makefile and meson.build) receive minor updates to accommodate the new test locations.

While the diffstat is large, the changes appear focused and consistent with previous Clar migration work. The series depends on the broader test framework transition already being agreed upon, so unless reviewers spot specific issues in the reftable test translations, this should be straightforward to merge as part of the standardization effort.
