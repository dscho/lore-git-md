This is the first patch in a 9-part series converting reftable tests to the Clar framework, part of Git's ongoing test infrastructure modernization. The patch focuses on adapting helper functions in `lib-reftable.{c,h}` from the old test framework to Clar's conventions.

The changes are mechanical but important groundwork - the helper functions provide common utilities for all reftable tests. Key changes include renaming functions with a `cl_` prefix (Clar's convention) and updating assertions to use Clar's macros (`cl_assert` instead of `check`). The patch also reorganizes build system files to properly include these helpers in the Clar-based test builds.

The conversion appears thorough, touching all the key helper functions for writing and verifying reftable data. Build system changes correctly move the helpers from the old test infrastructure to the new Clar-based one.
