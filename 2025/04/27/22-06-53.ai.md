Performance optimization patch for xdiff's `--minimal` mode, refining the approach from the previous discussion. This v2 iteration implements Phillip Wood's suggestions by deriving the `need_min` flag directly from `cf->flags` rather than passing it through functions, and uses the test helper functions (`test_write_lines`, `test_grep`) as recommended. The core change remains the same: modifying xdiff's `cleanup_records` heuristic to skip marking lines as changed when surrounded by many changes, but only when `--minimal` is explicitly requested. The test case verifies that unchanged lines surrounded by changes don't appear in minimal diffs. The patch remains narrowly focused on cases where `--minimal` is explicitly requested, where shortest-possible diffs are the expected behavior. No performance measurements are included, but the author notes the change affects about 1.3% of diffs in Git's history. The implementation appears clean and more robust with the test helper usage.
