This is the final patch in a 9-part series converting reftable unit tests to the Clar framework. The patch converts the reftable stack test file from the old `t-` prefix format to the new Clar-based `u-` prefix format, completing the migration of all reftable test files.

The changes follow the established pattern seen in previous patches in the series:
- Renames `t-reftable-stack.c` to `u-reftable-stack.c`
- Converts test assertions to Clar's `cl_assert*` macros
- Updates build system files (Makefile and meson.build) to reference the new filename
- Removes the now-unused sanity check for `t-*.c` files since this is the last conversion

The test coverage remains comprehensive, exercising all key reftable stack functionality including:
- Basic ref and log record operations
- Transaction handling
- Auto-compaction behavior
- Concurrency scenarios
- Error cases and edge conditions

With this patch, the entire reftable test suite has been modernized to use the Clar framework, marking the completion of this standardization effort. The changes are mechanical with no functional impact on the tests themselves or the reftable implementation.
