This is the third patch in a 9-part series converting reftable tests to the Clar framework. The series is part of Git's ongoing test infrastructure modernization effort.

Seyi Kuforiji converts the reftable block test file from the old `t-` prefix format to the new Clar-based `u-` prefix format. The patch follows the established pattern: it deletes the 383-line `t-reftable-block.c` and adds a new 373-line `u-reftable-block.c` with equivalent test coverage reorganized into Clar's format. The tests verify read/write operations for different block types (ref, log, obj, index) with the same test cases but using Clar assertions (`cl_assert*`) instead of the old custom assertions.

The conversion appears mechanical and thorough, maintaining all the test cases while modernizing the implementation approach. Build system files (Makefile and meson.build) are updated to reference the new test file location. This continues the series' work of standardizing Git's test infrastructure without changing any reftable functionality.
