This is part of Patrick Steinhardt's ongoing series to make Perl optional for running Git's test suite, specifically focusing on Makefile updates. The patch modifies the test execution infrastructure to only require Perl when actually needed, rather than making it a blanket requirement.

The changes focus on three key areas: First, it makes the `check-chainlint` target conditional on Perl being available, since chainlint.pl requires Perl. Second, it similarly makes shell syntax checking (via Perl-based tools) optional. Third, it adjusts the `prove` target to only run chainlint checks when Perl is present. The patch maintains all existing functionality when Perl is available while gracefully degrading when it's not.

For future reference, this touches the test execution infrastructure in t/Makefile, specifically around the `test`, `prove`, and `test-lint` targets. Key changes include the introduction of `ifneq ($(PERL_PATH),)` conditionals and the conditional setting of `GIT_TEST_CHAIN_LINT`. This builds on previous work that established the PERL_TEST_HELPERS infrastructure and converted core test functionality away from Perl dependencies.

The patch appears well-contained and follows the established pattern of the series, maintaining backward compatibility while progressing toward the goal of optional Perl. Given the prior approvals from Johannes Schindelin and Phillip Wood on the overall approach, this incremental change seems uncontroversial and aligned with the series' objectives.
