This is part 13/20 of Patrick Steinhardt's series to remove Perl as a mandatory test dependency, focusing on textconv-related tests. The patch converts three test files (t4030, t4031, t7815) that previously relied on Perl for text conversion scripts to use shell utilities instead.

The key changes replace Perl-based text conversion with simpler shell tools:
- t4030's hexdump script is replaced with a `tr` command that converts specific bytes ("\000" and "\001") to ASCII
- t4031 switches from Perl to `test-tool hexdump` for binary diff rewriting
- t7815 replaces a Perl NUL-to-Q converter with a simple `tr` command

The commit notes a deliberate design choice in t4030 to avoid a cascading change across many tests by not using `test-tool hexdump` everywhere, instead opting for minimal changes that maintain test expectations. All three tests drop their PERL_TEST_HELPERS prerequisite as a result of these changes.

This continues the series' pattern of methodical Perl removal while maintaining test functionality. The changes appear straightforward and maintain backward compatibility that has been a hallmark of the series. The patch follows the established approach of using simple text processing tools where possible while reserving Perl only for more complex cases.
