Part of Patrick Steinhardt's ongoing series to eliminate Perl dependencies in Git's test suite (12/20). This patch focuses on converting tests that use Perl for printing data into equivalent shell/awk/sed implementations.

The changes fall into three categories: conditional pattern matching (converted to awk), repeated output generation (using test-tool genzeros + sed), and reversing output (using sort/awk). The patch touches 14 test files, removing PERL_TEST_HELPERS prerequisites where no longer needed while maintaining the same test functionality.

Notable conversions include replacing Perl's string repetition operators in t0610 (large commit messages) with awk, using test-tool genzeros for generating test data in t0613 and t5300, and replacing Perl-based line reversal with sort -r in t1010. The changes are mechanical but thorough, following the established pattern of the series.

This continues the series' steady progress toward making Perl optional for running Git's test suite, with each conversion carefully preserving the original test behavior. The patch appears well-constructed and consistent with previous work in the series that has already received positive feedback.
