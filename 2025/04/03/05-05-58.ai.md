Test modernization patch in Patrick Steinhardt's Perl removal series. This is patch 7/20 in the v4 series, focusing on cleaning up PERL prerequisites in test scripts that no longer need them.

The patch updates several test files to remove unnecessary PERL prerequisites, falling into three categories: tests where Perl was previously used but no longer is, tests that never actually needed Perl, and tests that still require Perl but should use the new PERL_TEST_HELPERS prerequisite instead. A notable change is in t1006-cat-file.sh where a new PERL_IPC_OPEN2 prerequisite is introduced to handle IPC::Open2 module availability, requiring a variable rename from "script" to "perl_script" to avoid conflicts with test infrastructure.

The changes affect test files dealing with conversion filters (t0021), cache tree behavior (t0090), cat-file operations (t1006), and commit functionality (t7501). The patch maintains careful backward compatibility while progressing the series' goal of making Perl optional for the test suite. This follows the established pattern from earlier patches in the series, with Johannes Schindelin having already approved the approach after thorough review.
