This is part of Patrick Steinhardt's ongoing series to make Perl optional for Git's test suite (8/20). The patch updates the Meson build system to no longer require Perl just for running tests, reflecting changes from earlier patches that made the test suite work without Perl. 

The change is straightforward - it removes the `get_option('tests')` check from the Perl requirement condition in `meson.build`. Perl is still be required for Gitweb and the netrc' credential helper, but tests can now run without it. This aligns with the series' goal of reducing Git's dependencies while maintaining functionality.

The patch follows the established pattern of the series, which has already received positive feedback from reviewers. It's a logical next step after the core test infrastructure changes in earlier patches. The change is small and focused, just modifying one line in the build configuration while the heavy lifting of making tests Perl-optional was done in previous patches.
