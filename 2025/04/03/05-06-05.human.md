This is patch 14/20 in Patrick Steinhardt's series to remove Perl as a mandatory test dependency. The patch refactors the `sanitize_pgp()` test helper to use sed instead of Perl for stripping PGP signatures, allowing removal of the PERL_TEST_HELPERS prerequisite from tests that use this function.

The change is straightforward - replacing a Perl one-liner with an equivalent sed command that matches the PGP signature boundaries. The patch also updates t6300-for-each-ref.sh to explicitly mark Perl-dependent tests with PERL_TEST_HELPERS rather than skipping all tests when Perl isn't available, which is a more granular approach that better reflects the series' incremental Perl removal strategy.

This continues the series' pattern of mechanical substitutions where possible, with Johannes Schindelin's help indicating the approach has maintainer approval. The change is small and focused, maintaining backward compatibility while progressing the overall goal of Perl removal.
