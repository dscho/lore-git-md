This is part 9/20 of Patrick Steinhardt's series to make Perl optional for running Git's test suite, following the build system updates in patch 8/20. The patch modifies the Makefile to remove Perl as a hard requirement for test execution while maintaining existing functionality when Perl is available.

The changes make several test-related targets conditional on Perl's presence:
- `check-chainlint` is now optional (only runs if PERL_PATH is set)
- Shell syntax linting is similarly made optional
- The prove target maintains its chainlint check when Perl is available
- GIT_TEST_CHAIN_LINT is automatically disabled when Perl isn't present

This continues the series' careful approach of maintaining backward compatibility while progressively removing Perl dependencies. The changes are surgical - just 16 lines modified with clear conditional logic. As with previous patches in the series, this appears well-considered and builds logically on the established PERL_TEST_HELPERS infrastructure from earlier.

The patch keeps the test suite fully functional when Perl is present while properly implementing the series' goal of making Perl truly optional. It's a straightforward but important step in the overall effort to reduce Git's mandatory dependencies.
