Refactoring patch in Patrick Steinhardt's series to make Perl optional in Git's test suite. This patch specifically targets tests that use Perl's transliteration operators (y/ and tr/), replacing them with the standard `tr(1)` utility. The changes affect several test scripts that previously relied on Perl for character substitution, including test-sha1.sh, lib-diff.sh, and various test cases in t/t* directories.

The patch removes PERL_TEST_HELPERS prerequisites from multiple test cases where Perl was only used for simple character transliteration, though one test (t4103-apply-binary.sh) retains the prerequisite for a more complex case involving truncated binary diff rejection. The changes are mechanical substitutions of Perl's y///` and tr///` operators with equivalent `tr` command invocations, maintaining identical functionality while reducing Perl dependencies.

This continues the systematic elimination of Perl requirements from the test suite, following the pattern established in earlier patches of the series. The changes are straightforward and maintain backward compatibility, with no expected impact on test behavior beyond the Perl dependency removal.
