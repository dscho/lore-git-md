Feature/refactoring patch in Patrick Steinhardt's Perl removal series (19/20). This converts the `max_chain()` test helper in t5316-pack-delta-depth.sh from Perl to awk, removing the final Perl dependency in this test file. The helper extracts the maximum delta chain length from `git index-pack --verify-stat-only` output.

Key technical details:
- Replaces Perl regex `/chain length = (\d+)/` with awk pattern `/chain length = [0-9]+:/` (note the added colon matching)
- Uses awk's field splitting ($4`) to extract the numeric value rather than Perl's $1 capture group
- Adds `tr -d ':'` to clean the output since awk captures the trailing colon
- Removes PERL_TEST_HELPERS prerequisite from four test cases that now use the awk implementation
- Maintains identical test expectations and delta chain validation behavior

This follows the series' established pattern of mechanical but careful substitutions, here targeting pack delta testing infrastructure. The change is straightforward since the Perl usage was limited to simple text extraction. With this patch, only one conversion remains in the 20-part series to fully eliminate mandatory Perl dependencies from Git's test suite.
