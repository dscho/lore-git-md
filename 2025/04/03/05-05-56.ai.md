This is part 5 of Patrick Steinhardt's 20-patch series to remove Perl as a mandatory dependency from Git's test suite, now in its 4th iteration. The patch replaces a Perl-based `test_readlink()` helper function with a C implementation in `test-tool path-utils`.

The change moves the existing Perl implementation that reads symlink targets into a new `readlink` subcommand of the test helper. The C version uses Git's existing `strbuf_readlink()` function to handle the actual symlink reading, maintaining identical behavior while eliminating the Perl dependency. The shell wrapper in `test-lib-functions.sh` is updated to call the test-tool instead of Perl.

This is a straightforward conversion that follows the series' pattern of replacing Perl functionality with native Git implementations where possible. The patch is small (14 lines net) and focused, touching only the test infrastructure without affecting production code. It enables more tests to run on systems without Perl installed, contributing to the series' goal of making Perl optional for the test suite.

Key technical details:
- Adds new `readlink` subcommand to `test-tool path-utils`
- Uses `strbuf_readlink()` for the actual symlink reading
- Maintains same command-line interface as Perl version
- Updates test helper script to use new implementation
- Part of broader effort to eliminate 30342/31358 Perl uses in tests

The change is well-contained and unlikely to be controversial, following the established pattern of the series which has already received positive review feedback. It demonstrates the incremental approach of the overall effort - replacing individual Perl dependencies one by one while maintaining compatibility.
