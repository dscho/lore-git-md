This is part of Patrick Steinhardt's ongoing series to remove Perl as a mandatory dependency from Git's test suite (patch 17/20). The patch refactors the `generate_random_characters()` helper function in t0021-conversion.sh to eliminate its Perl dependency.

The function generates random lowercase letters by:
1. Using `test-tool genrandom` to produce random bytes (now as an infinite stream)
2. Filtering to just 'a-z' range via `tr -dc`
3. Copying exactly N bytes with `test_copy_bytes`

The change removes the PERL_TEST_HELPERS prerequisite from three test cases that use this helper. This follows the established pattern of the series - replacing Perl one-liners with shell/tr/sed equivalents while maintaining identical test behavior. The implementation appears straightforward and maintains the same functionality, just with different plumbing tools.

This conversion is mechanically similar to previous patches in the series (like patches 9-11 that converted s/// operators) and continues the systematic removal of Perl from test infrastructure. The patch doesn't introduce any new concepts or complications beyond what's already been reviewed and approved in earlier parts of the series.
