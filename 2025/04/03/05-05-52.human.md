This is the first patch in Patrick Steinhardt's major series to remove Perl as a mandatory dependency from Git's test suite. The patch addresses the chainlint script, which verifies proper '&&' chaining in test files and currently requires Perl.

The change makes chainlint automatically disable itself when Perl isn't available (PERL_PATH unset), unless the linter was explicitly requested via GIT_TEST_CHAIN_LINT. This provides a smoother experience for developers working without Perl while maintaining the ability to enforce chainlint when desired.

The implementation adds logic block to t/test-lib.sh that:
1. Defaults to disabling chainlint when Perl is missing
2. Preserves explicit disable requests (GIT_TEST_CHAIN_LINT=0)
3. Errors helpfully if someone tries to run chainlint without Perl

This is a sensible quality-of-life improvement that fits well with the series' broader goal of making Perl optional. The patch is cleanly implemented with clear commit message explaining both the technical change and its motivation within the larger context of Perl removal. As the first patch in a well-reviewed series that has Johannes Schindelin's approval, this appears ready for inclusion.
