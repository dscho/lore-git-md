This is a build system patch in Patrick Steinhardt's ongoing series to make Perl as an optional dependency for Git's test suite (patch 8/20). The change updates the Meson build configuration to no longer require Perl just for running tests, reflecting the work done in previous patches to make the test suite work without Perl.

The patch modifies the `meson.build` file to remove `get_option('tests')` from the conditions that trigger Perl being marked as required. Perl will still be required for Gitweb and the netrc credential helper, but the test suite itself can now run without it. This is a straightforward mechanical change that follows through on the architectural work done in earlier patches to make tests Perl-optional.

The change is small (just one line modified) but important for the overall goal of the series. It completes the logical separation between test execution and Perl requirements that was established in the technical groundwork of previous patches. The patch maintains all existing functionality for cases where Perl is still needed (Gitweb and netrc), while properly reflecting the new Perl-optional state of the test system in the build configuration.
