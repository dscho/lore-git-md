This is patch 15/20 in Patrick Steinhardt's series to remove Perl as a mandatory test dependency. The patch refactors the `name_from_description()` test helper function in t/lib-t6000.sh, converting it from Perl to a combination of sed and tr commands. This change allows removing PERL_TEST_HELPERS prerequisites from two test scripts (t6002-rev-list-bisect.sh and t6003-rev-list-topo-order.sh) that use this helper.

The conversion maintains identical functionality - the function still converts alphanumeric descriptions into normalized names by replacing non-alphanumeric characters with dashes, compressing multiple dashes, stripping leading/trailing dashes, and lowercasing letters. The implementation now uses a series of sed expressions and y/// (translate) command instead of Perl's s/// and y/// operators.

This follows the established pattern of the series: focused mechanical conversions that maintain behavior while incrementally reducing Perl dependencies. The change is straightforward and maintains the test suite's functionality while progressing toward the goal of optional Perl usage. Johannes Schindelin's previous sign-off on the architectural approach remains applicable here.
