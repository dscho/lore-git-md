This is the final version of a bugfix for `git blame`'s porcelain output, addressing an inconsistency where ignored/unblamable line markers weren't shown in porcelain mode despite being documented as working there. The patch has gone through extensive review and testing over multiple iterations.

Karthik Nayak's implementation adds "ignored" and "unblamable" markers as new metadata lines in porcelain output, maintaining backward compatibility while fixing the documentation gap. The solution carefully preserves the existing SHA-1 line format that tools might parse, adding the newline-separated markers instead of modifying existing lines.

The patch includes thorough test coverage for both `--porcelain` and `--line-porcelain` modes, with special attention to portability - the final version uses heredoc-based sed scripts to handle newlines and tabs in a POSIX-compliant way, addressing feedback from Phillip Wood. Documentation is updated to clarify the behavior.
