Key technical details for future reference:
- Verification uses raw commit object minus signature header block
- Signature headers may be `gpgsig` or `gpgsig-sha256`
- Continuation lines (space-prefixed) must be stripped with main header
- Header order is not guaranteed
- No hashing/encoding step beyond the raw object format
- `ssh-keygen` interface quirks may contribute to verification failures
