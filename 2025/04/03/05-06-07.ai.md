This is patch 16/20 in Patrick Steinhardt's series to remove Perl as a mandatory test dependency. The patch refactors the HTTPD test infrastructure to replace a Perl-based CGI script ("one-time-perl") with a more generic shell-based solution ("one-time-script").

The key changes are:
- Renames the endpoint from `/one_time_perl/` to `/one_time_script/`
- Replaces `apply-one-time-perl.sh` with `apply-one-time-script.sh` that executes arbitrary scripts rather than specifically Perl
- Updates all test scripts that used this functionality to use shell utilities (sed, grep) instead of Perl
- Removes PERL_TEST_HELPERS prerequisites from several tests that no longer need them

The patch follows the established pattern of the series by making mechanical but careful substitutions that maintain test behavior while incrementally removing Perl dependencies. It touches HTTPD configuration files, CGI scripts, and multiple test files that use the modified functionality (t5537, t5616, t5702, t5703). The changes are straightforward and maintain backward compatibility while progressing the series' goal of eliminating Perl from the test suite.
