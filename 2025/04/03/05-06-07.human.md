Perl removal series: HTTPD test helper modernization

This is patch 16/20 in Patrick Steinhardt's series to eliminate Perl as a mandatory test dependency. The patch converts the "one-time-perl" HTTPD test helper to a more generic "one-time-script" that can run arbitrary shell scripts rather than requiring Perl specifically.

The change involves:
1. Renaming all references from "one-time-perl" to "one-time-script"
2. Replacing the Perl-specific execution with a generic script runner
3. Updating several test scripts that used this helper to now use shell utilities like sed instead of Perl
4. Removing the PERL_TEST_HELPERS prerequisite from affected tests

The conversion follows the established pattern of the series - mechanical but careful substitutions that maintain identical test behavior while incrementally removing Perl dependencies. The patch touches multiple HTTPD-related test files (t5537, t5616, t5702, t5703) to update their usage of this helper.

This continues the series' steady progress toward eliminating Perl from the test suite, with the changes being straightforward and well-contained like previous patches in the series. The conversion appears complete and maintains all existing test functionality while removing another Perl dependency.
