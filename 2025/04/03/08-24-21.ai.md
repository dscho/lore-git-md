This is a build system fix addressing curl detection in the Meson build configuration. The patch corrects how Git checks for curl availability when built with `-Dcurl=auto`, ensuring HTTP-related features properly build when curl is auto-detected rather than explicitly enabled.

The issue stems from checking `get_option('curl').enabled()` which returns false for 'auto' values, even when curl is found. The fix changes this to check `curl.found()` instead, which properly reflects whether the library was detected. This affects HTTP remote helper functionality which is considered essential for most Git installations.

The change is minimal (one line in meson.build) but important for correct feature detection. The patch is part of a larger series of build system improvements, with this particular fix being uncontroversial and technically sound. The thread context shows this was already reviewed positively as part of the v2 series, with no outstanding concerns about this specific patch.
