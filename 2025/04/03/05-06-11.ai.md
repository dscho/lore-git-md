Final patch in the Perl removal series for test suite. This is the 20th and concluding patch in Patrick Steinhardt's effort to eliminate Perl as a mandatory dependency from Git's test infrastructure.

The patch focuses on t5703-upload-pack-ref-in-want.sh, which previously used Perl for two purposes: filtering advertised capabilities and setting up CGI scripts with HTTPD. The changes here:
1. Replaces Perl-based capability filtering with `test_grep` for simpler pattern matching
2. Explicitly marks HTTPD/CGI-related tests with PERL_TEST_HELPERS prerequisite rather than requiring it globally
3. Maintains all test behavior while reducing the test file by 9 lines (17 deletions, 8 additions)

Key technical details:
- Removes global PERL_TEST_HELPERS check that previously skipped all tests
- Converts three test cases from Perl regex filtering to `test_grep` assertions
- Adds PERL_TEST_HELPERS to six remaining test cases that still need Perl for HTTPD setup
- Preserves all test scenarios (config controls, server ahead/behind cases, ref loss)

This completes the series' goal of making Perl optional for core test execution while maintaining backward compatibility. The remaining Perl usage is now limited to specific HTTPD test scenarios that would require more substantial refactoring. The patch follows the series' established pattern of mechanical but careful substitutions, with Schindelin's prior architectural approval still applying.
