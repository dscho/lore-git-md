This is part of Patrick Steinhardt's major refactoring series to eliminate Perl as a mandatory dependency for Git's test suite (patch 2/20). The change replaces a Perl script used for test environment sanitization with a `sed`-based solution.

The patch removes a Perl snippet that was previously used to unset environment variables starting with 'GIT_' while preserving a whitelist of exceptions (like GIT_TRACE, GIT_TEST, etc.). The new implementation uses a series of `sed` expressions to achieve the same filtering logic. This makes the test suite runnable without Perl while maintaining identical behavior.

The change is straightforward and well-contained, touching only `t/test-lib.sh`. It builds on an earlier approach suggested by Johannes Schindelin and appears to be a clean mechanical conversion from Perl to shell. As part of the larger Perl removal effort that has already received review consensus, this particular patch seems uncontroversial and technically sound.
