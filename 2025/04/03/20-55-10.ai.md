Feature proposal for configurable partial clone filters.

Sylvain Fardeau proposes adding a configuration option to set `--filter=blob:none` as the default for clone operations. The email references two Stack Overflow posts showing real-world use cases where this would be valuable: one asking how to configure this behavior by default, and another discussing cleanup of binary files in repositories.

The proposal suggests this would be particularly useful for development workflows involving binary files. Currently, users must manually specify the filter flag on each clone operation. The email does not propose a specific configuration syntax but asks whether this feature is planned in Git's roadmap.

This appears to be a well-motivated feature request from a real-world usability perspective, though the implementation details would need to be worked out. The request touches on Git's partial clone functionality and configuration system, potentially requiring changes to both the config parsing and clone command infrastructure. The lack of a patch suggests this is more of an RFC than an implementation proposal at this stage.
