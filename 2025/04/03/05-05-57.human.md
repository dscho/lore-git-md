This is part of Patrick Steinhardt's ongoing refactoring series (v4 6/20) to eliminate Perl as a mandatory dependency for Git's test suite. The patch introduces a new `PERL_TEST_HELPERS` prerequisite to distinguish between tests that inherently depend on Perl (using the existing `PERL` prerequisite) and tests that use Perl as a testing aid.

The change carefully separates two concepts: whether Perl-built features are present (`PERL`) versus whether Perl is available to run test helpers (`PERL_TEST_HELPERS`). This allows the test suite to run more completely on systems without Perl, while still properly skipping tests that truly require Perl functionality.

The patch updates 71 test files to use this new prerequisite, mostly for tests that use Perl for data generation, parsing, or text manipulation. The changes are mechanical but thorough, showing the author has systematically identified all Perl-dependent test cases. This continues the series' pattern of maintaining identical test behavior while removing Perl dependencies.

The work is part of a larger effort that has already removed Perl from 97% of tests (30,342/31,358). This particular change helps formalize the remaining Perl dependencies in the test suite infrastructure itself. Reviewers including Johannes Schindelin have already approved earlier versions of this series, indicating it's technically sound and ready for consideration.
