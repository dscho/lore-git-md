Feature enhancement for `git version --build-options` reporting SHA implementations. This is the first patch in a 2-part series that has already gone through multiple iterations and reached consensus.

The patch adds SHA implementation details to Git's version output when using `--build-options`. It works by defining standardized `SHA1_BACKEND` and `SHA256_BACKEND` symbols in hash.h that each backend must provide, then displaying these in help.c's version output. The documentation in git-version.adoc is updated to explain the new output format and includes security warnings about non-collision-detecting SHA-1 variants.

Key technical aspects:
- Defines backend strings in hash.h with compile-time safety
- Reports both SHA-1 and SHA-256 implementations
- Documents the output format and security implications
- Uses preprocessor symbols to avoid runtime overhead
- Includes explicit warnings about non-collision-detecting SHA-1 variants (marked with "(No collision detection)")

The implementation spans three files:
- hash.h: Defines the backend symbols for all SHA implementations
- help.c: Adds the SHA reporting to version output
- git-version.adoc: Documents the new output and security considerations
