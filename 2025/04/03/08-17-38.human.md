This is a performance optimization patch that completes a series adding object filtering capabilities to `git cat-file --batch-all-objects`. The patch leverages bitmap indices to dramatically speed up type-based filtering, achieving a 41x speedup for commit filtering in large repositories like Chromium (from ~86s to ~2s).

The series, now in its v3 iteration, introduces three filter types: `blob:none`, `blob:limit=<n>`, and `object:type=<type>`. The key innovation in this final patch is using bitmap traversal when available, avoiding the need to scan entire packfiles. The implementation adds a new `batch_one_object_bitmapped` callback that integrates with the refactored `batch_each_object()` interface from earlier patches.

Review feedback from v2 has been addressed, including better documentation of filter interactions with batch modes and proper handling of the "excluded" status for filtered objects. The patch maintains all architectural integrity from previous versions while delivering the promised performance improvements. Test coverage has been expanded to verify the acceleration works as expected.

The changes are well-motivated by real-world use cases at GitLab where filtering objects by type was previously I/O-bound. The series now stands complete with this final optimization that makes type filtering scale with the number of matching objects rather than total repository size.
