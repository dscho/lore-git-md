This is a major refactoring series (20 patches) to eliminate Perl as a mandatory dependency for running Git's test suite, representing the culmination of an ongoing effort to modernize Git's testing infrastructure.

The series systematically replaces Perl usage across the test suite with shell utilities (sed, awk, tr, sort) and Git's own test-tool, achieving 97% test coverage (30342/31358 tests) without Perl. Key technical changes include:

- New PERL_TEST_HELPERS prerequisite for remaining Perl-dependent tests
- Textconv script conversions using tr for binary-to-ASCII translation
- PGP signature sanitization via sed instead of Perl
- Random character generation through shell pipelines
- HTTP protocol test modernization
- Reverse printing via sort -r/awk
- Careful preservation of test expectations while simplifying implementations

The v4 changes focus on improved commit message clarity and minor refinements to the textconv approach (now using tr for specific byte translations rather than full hexdump emulation). The series has received thorough review from Johannes Schindelin (including verification of PERL_TEST_HELPERS and textconv stability) and maintains Phillip Wood's v3 approval.

This work enables significant downstream benefits including a 10MB size reduction for Git for Windows and potential CI optimizations. The thread shows this effort expanding beyond its original test-suite focus to address broader Perl removal goals in Git's tooling (filter-branch, request-pull), with git-filter-repo emerging as a long-term replacement path.
