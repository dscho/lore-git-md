This is part 11/20 in Patrick Steinhardt's series to remove Perl as a mandatory test dependency. The patch focuses on replacing Perl's substitution operators (s///) with equivalent sed/tr commands across multiple test scripts.

The changes are mechanical replacements of Perl's pattern matching with sed/tr equivalents, removing PERL_TEST_HELPERS prerequisites where they're no longer needed. Key transformations include:
- Replacing `perl -pe` with sed/tr pipelines for simple substitutions
- Converting character transliterations (y///, tr///) to standard `tr(1)`
- Maintaining identical functionality while reducing dependencies
- Keeping Perl only where truly needed (like binary diff handling in t4103)

The patch touches 11 test files, with most changes following a pattern of:
1. Removing PERL_TEST_HELPERS prereq where no longer needed
2. Converting Perl one-liners to sed/tr commands
3. Using temporary files (via .munged suffix) for in-place editing where needed

Notable test areas affected include:
- Ignore rules (t0008)
- Diff handling (t4029)
- Rerere functionality (t4200)
- Pack corruption tests (t5303)
- Bitmap handling (t5310)
- Signed pushes (t5534)
- Submodule URL handling (t7416)

The changes maintain strict backward compatibility and follow the series' established approach of mechanical substitutions where possible. This continues the systematic progress toward making Perl optional for running Git's test suite.
