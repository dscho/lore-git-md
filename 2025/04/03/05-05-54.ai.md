This is part 3 of Patrick Steinhardt's 20-patch series to remove Perl as a mandatory dependency from Git's test suite, specifically focusing on character translation helpers.

The patch replaces three Perl-based helper functions in `t/test-lib-functions.sh` with equivalent `tr(1)` implementations:
- `lf_to_nul` (LF → NUL)
- `nul_to_q` (NUL → 'Q')
- `q_to_nul` ('Q' → NUL)

The commit message addresses potential portability concerns regarding NUL handling in `tr`, noting that POSIX-compliant implementations must properly process NUL characters. This change allows several tests to pass without Perl while maintaining identical functionality. The implementation is straightforward, with each Perl one-liner being replaced by a direct `tr` command using the same character mappings.

This patch exemplifies the series' consistent strategy of replacing Perl with more portable shell tools while carefully considering edge cases and historical portability concerns. The changes are minimal (3 lines modified) but impactful for the broader Perl removal effort, particularly for tests dealing with binary data transformations.
