This is a feature enhancement to `git version --build-options` that's now in its third version with all technical aspects settled. The series adds reporting of SHA implementation details to help with diagnostics.

The patches now show which SHA-1 and SHA-256 implementations Git was built with, including special handling for non-collision-detecting SHA-1 variants (like Apple/OpenSSL/block-sha1) which are labeled clearly with security warnings. The implementation uses compile-time symbols (SHA1_BACKEND, SHA1_UNSAFE_BACKEND, SHA256_BACKEND) defined in hash.h to ensure accuracy without runtime detection.

Version 3 makes final documentation refinements, particularly around explaining the security implications of non-collision-detecting SHA-1 variants. The output format has been simplified by inlining the SHA implementation reporting function, and the terminology has been standardized to "non-collision-detecting-SHA-1" for clarity.
