Perl removal series: Converting trace2 test scrubbing from Perl to sed

This is patch 18/20 in Patrick Steinhardt's series to eliminate Perl from Git's test suite. The patch converts the trace2 test output scrubbing logic from Perl to sed, allowing removal of the PERL_TEST_HELPERS dependency from t0210-trace2-normal.sh.

The change replaces a Perl script that sanitized variable fields in trace2 test output (like elapsed times and executable paths) with an equivalent sed implementation. The new `scrub_normal()` shell function handles the same transformations:
- Replacing elapsed times with _TIME_ placeholder
- Normalizing executable paths to _EXE_
- Omitting platform-specific cmd_path and cmd_ancestry messages

All test cases are updated to use the new sed-based scrubbing while maintaining identical expected output. The original Perl script (t0210/scrub_normal.perl) is deleted as it's no longer needed.

This follows the series' established pattern of methodical, behavior-preserving conversions. The change is straightforward and maintains test reliability while progressing the overall goal of Perl removal. With Johannes Schindelin's continued sign-off on the approach, this patch appears uncontroversial and well-executed.
