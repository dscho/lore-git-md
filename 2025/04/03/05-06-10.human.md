Perl removal series: Converting pack delta test helper from Perl to awk.

This is patch 19/20 in Patrick Steinhardt's series to eliminate Perl as a test dependency. The patch refactors the `max_chain()` helper function in t5316-pack-delta-depth.sh, which extracts the maximum delta chain length from packfile statistics. The original Perl implementation is replaced with an equivalent awk solution that performs the same parsing of `git index-pack --verify-stat-only` output.

The change follows the series' established pattern of mechanical but careful substitutions, removing Perl while maintaining identical test behavior. This allows dropping the PERL_TEST_HELPERS prerequisite from four test cases that verify delta chain behavior under different packing configurations. The tests confirm that packing with --window=0 produces long chains, while --depth limits and --depth=0/-1 disable delta chains as expected.

The patch is straightforward and maintains the test's functionality, continuing the series' steady progress toward complete Perl removal. With only one patch remaining after this, the series is nearing completion of its goal to make Perl optional for Git's test suite.
