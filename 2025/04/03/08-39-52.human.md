This is a build system patch series consolidating several fixes and improvements to Git's build infrastructure. The v2 series from Patrick Steinhardt includes five distinct changes:

1. A fix for `-Dcurl=auto` detection in Meson builds, ensuring proper HTTP feature detection by using `curl.found()` instead of the previous method. This has been confirmed as technically sound.

2. A correction for gitweb JavaScript generation that fixes a regression where the Makefile rule incorrectly included the build script in the output. There's ongoing discussion about whether to use `filter` or `filter-out` in the solution, with both approaches having tradeoffs.

3. Ensures contrib tests (netrc credential helper and git-subtree) properly respect the `-Dtests=false` flag in Meson builds by adding conditional blocks.

4. Adds comprehensive cross-compilation support with clear distinction between build-host and target-host binaries, including new variables and documentation. While technically sound, it still needs review from Windows/Meson experts.

5. Updates CI workflows to use Visual Studio for Windows builds, though there are indications this CI support may be dropped in the future due to resource constraints.

The series appears well-crafted with clear commit messages and addresses real build system issues. The most notable open question is the gitweb Makefile implementation detail (filter vs filter-out), and there's recognition that gitweb JavaScript build process needs test coverage as a follow-up task. The cross-compilation changes, while thorough, would benefit from platform-specific review.
