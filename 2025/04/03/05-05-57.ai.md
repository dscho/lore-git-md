This is part 6/20 of Patrick Steinhardt's series to remove Perl as a mandatory dependency for Git's test suite. The patch introduces a new `PERL_TEST_HELPERS` prerequisite to distinguish between tests that require Perl because the underlying feature depends on it (handled by existing `PERL` prerequisite) versus tests that use Perl as a testing helper.

Key technical details:
- Adds `PERL_TEST_HELPERS` checks to 71 test files (281 insertions, 93 deletions)
- Skips tests with Perl helper dependencies when Perl isn't available
- Maintains existing test behavior when Perl is present
- Documents the distinction between `PERL` (feature dependency) and `PERL_TEST_HELPERS` (test implementation dependency)

The change is part of a larger effort that has already removed Perl from 97% of tests (30342/31358). This patch handles the remaining cases where tests use Perl for auxiliary functions like:
- Character generation/translation
- Binary data handling
- Complex text processing
- Protocol testing
- The patch follows the series' pattern of maintaining identical test behavior while removing Perl dependencies
- Johannes Schindelin has approved the technical approach after thorough review
- Windows compatibility benefits have emerged as a significant side benefit (10MB installer size reduction)

The series is now technically ready for maintainer consideration, with this patch completing the core test suite Perl removal by properly categorizing the remaining Perl-dependent tests.
