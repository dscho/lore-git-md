Sylvain Fardeau has proposed adding a configuration option to make `--filter=blob:none` the default for clone operations, which would help developers working with repositories containing binary files. Currently, users must manually specify this filter on each clone. The suggestion is motivated by real-world use cases from Stack Overflow where developers have expressed need for this functionality.

The proposal is currently at the idea stage without specific implementation details or patches. It touches on Git's partial clone capabilities and configuration system, suggesting this would be a quality-of-life improvement for certain workflows. The email asks whether this feature aligns with Git's roadmap, indicating the author is seeking feedback before potentially developing a concrete implementation.
