This is a build system fix addressing curl detection in Git's Meson build configuration. The patch corrects how the build system checks for curl availability when users specify `-Dcurl=auto`, ensuring HTTP-related features properly build when curl is auto-detected.

The issue stems from checking `get_option('curl').enabled()` which only returns true for explicitly enabled states, not auto-detection. Patrick Steinhardt's solution switches to checking `curl.found()` instead, which properly reflects whether the library was actually detected. This matters because curl is essential for HTTP functionality, and the default build expects it to be present.

The change is minimal (a single line in meson.build) but important for correct feature detection. It's part of a larger series of build system improvements, with this particular fix appearing uncontroversial based on the thread context. The patch demonstrates clear understanding of Meson's feature detection semantics and provides a straightforward solution to the problem.
