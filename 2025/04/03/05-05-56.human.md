This is part of Patrick Steinhardt's major refactoring series to eliminate Perl as a mandatory requirement for Git's test suite. The patch replaces a Perl-based implementation of `test_readlink()` with a native C version in `test-tool`.

The change moves the symlink reading functionality from a Perl one-liner to a new command in `test-tool path-utils`. The implementation uses Git's existing `strbuf_readlink()` function to handle the actual symlink reading, making it more portable while maintaining the same behavior. This allows tests using this helper to pass even when Perl isn't available.

The patch is straightforward - it adds the new `readlink` subcommand to the test helper while updating the shell function to call it instead of Perl. This follows the pattern seen elsewhere in the series of moving test infrastructure from Perl to more portable alternatives. Given the thorough review this series has already undergone and the non-controversial nature of this particular change, it appears ready for inclusion.
