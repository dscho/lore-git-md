This is a feature patch series that enhances `git cat-file` with object filtering capabilities, now incorporating bitmap acceleration for significant performance improvements. The series builds on previous versions (v3-v6) that established the core filtering infrastructure.

The key technical components in this final version include:

1. **Bitmap integration** - The new `batch_one_object_bitmapped` callback handler enables efficient bitmap traversal when filtering by object type, achieving a 41x speedup for commit filtering in large repositories like Chromium (from ~86s to ~2s). This builds on the earlier refactoring that unified object iteration paths.

2. **Filter support** - The series implements three filter types: `blob:none` (omit blobs), `blob:limit=<n>` (size-based blob filtering), and `object:type=<type>` (type filtering). The bitmap acceleration specifically benefits the type filter.

3. **Infrastructure changes** - Key supporting changes include:
   - New `for_each_bitmapped_object()` in pack-bitmap.c
   - `bitmap_index_contains_pack()` function for pack verification
   - Refactored `batch_each_object()` helper unifying iteration paths
   - Callback infrastructure with payload support in pack-bitmap subsystem

4. **Behavior preservation** - The implementation maintains existing behavior when no filters are applied and provides proper fallback paths when bitmaps aren't available. Filtered objects are clearly marked as "excluded" in batch output.
