Cross-compilation support patch in build system series. This is the 4th of 5 patches in Patrick Steinhardt's series improving Git's build infrastructure, focusing on proper handling of cross-compilation scenarios.

The patch distinguishes between build-host binaries (tools needed during compilation) and target-host binaries (programs that will be embedded in the final Git executable). It introduces explicit `native: true/false` parameters to Meson's `find_program()` calls and creates new variables like `target_shell`, `target_perl`, and `target_python` for the target system versions. The changes affect documentation generation, gitweb configuration, and various build-time tool lookups.

Karthik Nayak's review confirms the technical soundness, noting the logical separation between build-time tools (like version generators) and runtime dependencies. The patch appears well-considered, with clear documentation added about cross-compilation machine file configuration. This addresses a real gap in Git's build system, though as noted in the thread context, it still needs review from Windows/Meson experts to confirm all edge cases are handled.
