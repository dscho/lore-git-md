This is a GSoC project proposal for a new Git command focused on repository metadata queries. Jayatheerth K presents a refined version of their earlier idea, now narrowed to specifically migrate file-related query options from `git rev-parse` to a new `git repo-info` command, following guidance from Patrick Steinhardt.

The proposal outlines a clear plan to extract path/directory query options (like `--git-dir`, `--show-toplevel`) and repository state checks (like `--is-bare-repository`) from rev-parse into a dedicated command. The work would involve creating a new C implementation, comprehensive tests, and documentation while maintaining backward-compatible text output. A stretch goal mentions potential JSON output, but this is clearly marked as secondary.

The student demonstrates good preparation through prior microproject work and shows understanding of Git's development process by planning incremental patch submissions. The timeline is well-structured in phases, with clear milestones for implementation batches and documentation. The scope appears appropriately constrained to be achievable within GSoC while providing tangible benefits by cleaning up rev-parse's overloaded interface.
