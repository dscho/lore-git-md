This is part of Patrick Steinhardt's ongoing series to remove Perl as a mandatory test dependency (patch 14/20). The patch refactors the `sanitize_pgp()` test helper in `t/lib-gpg.sh` to use sed instead of Perl for stripping PGP signatures from stdin, allowing removal of the PERL_TEST_HELPERS prerequisite from tests that use this functionality.

The change involves replacing a Perl one-liner that toggled state between PGP begin/end markers with a sed command that deletes lines between markers while preserving the marker lines themselves. This maintains the same core functionality while eliminating Perl. The patch also updates `t6300-for-each-ref.sh` to explicitly add PERL_TEST_HELPERS to specific tests that still require Perl, rather than bailing out the entire test file when Perl isn't available.

This continues the series' pattern of methodical, focused conversions that maintain backward compatibility while incrementally reducing Perl usage. The change is straightforward and mechanical substitution of equivalent functionality, with careful attention to test prerequisites. Johannes Schindelin's sign-off indicates continued architectural approval of the approach. The patch affects test infrastructure files (`t/lib-gpg.sh`) and one test file (`t/t6300-for-each-ref.sh`), with the latter changes being prerequisite adjustments rather than functional modifications.
