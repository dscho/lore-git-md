This is the second and final patch in a series enhancing `git version --build-options` to report SHA implementations, now at version 3 with all technical and documentation aspects finalized.

The patch completes the implementation by adding reporting for non-crypto SHA-1 backends, which were introduced in commit 06c92dafb8. It defines `SHA1_UNSAFE_BACKEND` symbols in hash.h for Apple/OpenSSL/block-sha1 implementations and updates help.c to report these under the "non-collision-detecting-SHA-1" label when present. The documentation in git-version.adoc is updated to explain the new output format and reiterate the security implications of using these non-collision-detecting variants.

Key technical details include:
- Maintains zero runtime overhead by using preprocessor symbols
- Follows the final agreed terminology of "non-collision-detecting-SHA-1"
- Only shows the unsafe SHA-1 line when such a backend is actually selected
- Documents the security warnings clearly in the manual page

The patch represents the culmination of discussion from the thread, incorporating all agreed-upon points about output format, terminology, and documentation. It builds on the foundation established in patch 1/2 while adding the specific handling for unsafe SHA-1 variants. The implementation is clean and matches the technical direction approved by all participants.
