This is patch 18/20 in Patrick Steinhardt's series to remove Perl as a mandatory test dependency, focusing on converting trace2 test scrubbing from Perl to sed.

The patch converts the trace2 test output scrubbing logic from Perl to a shell function using sed. The scrubbing process normalizes variable fields in trace2 output (like elapsed times and executable paths) to make test output predictable. The new `scrub_normal()` function handles four key transformations: replacing elapsed times with a placeholder, normalizing executable paths, omitting cmd_path lines (which are runtime-prefix dependent), and skipping cmd_ancestry lines (which aren't universally implemented).

The conversion follows the series' established pattern of mechanical but careful substitutions, maintaining identical test behavior while removing Perl dependencies. All test cases in t0210-trace2-normal.sh are updated to use the new sed-based scrubbing instead of the Perl script, which is deleted. The change allows removing the PERL_TEST_HELPERS prerequisite from these tests.

This patch continues the series' systematic approach, with the conversion being straightforward since the scrubbing logic is well-contained and the sed substitutions directly mirror the previous Perl functionality. The patch maintains all existing test expectations while achieving the series' goal of Perl removal.
