This is the fourth version of Patrick Steinhardt's major refactoring series to remove Perl as a mandatory dependency for running Git's test suite. The series has reached final review consensus and now makes 97% of Git's tests (30,342 out of 31,358) pass without requiring Perl.

The series systematically replaces Perl usage in test infrastructure and individual tests with shell utilities like sed, awk, and tr. Key changes in v4 include improved commit messages explaining the conversions and additional Perl-dependent commands noted in the PERL_TEST_HELPERS prerequisite (git-request-pull and git-filter-branch). The implementation carefully maintains test stability while removing Perl, particularly in textconv script conversions where some functionality is simplified to avoid ripple effects across tests.

The series is now technically ready for maintainer consideration, having addressed all feedback from Johannes Schindelin and Eric Sunshine. It represents a significant step in Git's modernization, with notable secondary benefits for Windows users including a 10MB installer size reduction. The work has expanded from its original test-suite focus to inform broader Perl removal efforts in Git's tooling.
