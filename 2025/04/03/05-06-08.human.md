This is patch 17/20 in Patrick Steinhardt's series to remove Perl as a mandatory test dependency. It refactors the `generate_random_characters()` helper function in t0021-conversion.sh to use shell utilities instead of Perl.

The change replaces a Perl-based random character generator with a combination of `test-tool genrandom`, `tr` for filtering characters, and `test_copy_bytes` to get the right length. This allows removing the PERL_TEST_HELPERS prerequisite from three test cases that use this helper.

The conversion follows the series' established pattern of mechanical but careful substitutions, maintaining identical test behavior while incrementally removing Perl dependencies. The patch is straightforward and builds on previous infrastructure work (like the enhanced `test-tool genrandom` functionality). As with earlier patches in the series, this change maintains backward compatibility while moving Git closer to being Perl-free in its test suite.
