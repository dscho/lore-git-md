This is a platform compatibility patch in Patrick Steinhardt's v3 series integrating Git's performance benchmarks with Meson. It addresses Perl script portability by using the configured `PERL_PATH` rather than hardcoding `/usr/bin/perl`.

The patch modifies three files to consistently use the build-configured Perl path:
1. Changes the shebang in `aggregate.perl` to use `env` for better PATH lookup
2. Updates `perf-lib.sh` to explicitly call Perl scripts via `$PERL_PATH`
3. Makes the same change in the `run` script's aggregation commands

This ensures benchmark scripts work on systems with non-standard Perl locations (like NixOS) while maintaining consistency with Git's existing build infrastructure that already tracks Perl's location in `GIT-BUILD-OPTIONS`. The change is straightforward but important for portability, particularly as the Meson integration expands the build configuration possibilities.

The patch fits into the broader series by addressing one of the environment-specific issues needed for robust cross-platform benchmark support. It doesn't touch the core Meson integration work but removes a potential portability roadblock for users with custom Perl installations.
