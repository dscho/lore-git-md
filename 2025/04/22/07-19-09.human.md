Feature patch adding OAuth2 authentication support to `git send-email`. This is the first of a 2-part series improving email functionality for Microsoft ecosystem users, rebasing prior work to comply with Microsoft's mandatory OAuth2 requirements.

The patch implements SMTP bearer token authentication (OAUTHBEARER and XOAUTH2) directly in `git-send-email.perl`, bypassing Perl's Authen::SASL module which lacks support for these methods. Users can configure OAuth2 via git config with a credential helper like git-credential-oauth, with examples provided for both Gmail and Office 365 setups. The implementation follows RFC standards (5801, 7628) for the authentication protocol and includes proper TLS enforcement.

The changes appear well-researched with clear references to relevant RFCs and include a Tested-by from the git-credential-oauth maintainer. Documentation is updated to explain the new authentication options. While the implementation looks solid, the patch would benefit from more detail about testing methodology across different OAuth2 providers.
