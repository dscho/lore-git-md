This is part 2 of a 5-part test modernization series, converting string-list tests from shell to C unit tests. The patch focuses on moving the "test_split" functionality from t0063-string-list.sh to the new u-string-list.c file in the unit-tests directory.

The patch introduces helper functions t_vcreate_string_list_dup() and t_create_string_list_dup() to simplify test setup by creating string_lists from variable arguments. It ports all split operation test cases (testing various delimiter cases and maxsplit values) to the new framework while maintaining identical test coverage. The original shell test code and corresponding test-tool functionality are removed.

Key technical details include:
- New test file at t/unit-tests/u-string-list.c with 86 lines of test infrastructure
- Removal of 53 lines from t/t0063-string-list.sh and 14 lines from test-string-list.c
- Makefile and meson.build updates to include the new test suite
- Test assertions using the clar framework (cl_assert* macros)
- Preservation of all test cases (empty strings, edge splits, maxsplit limits)

The changes are mechanical and maintain the same test coverage while improving execution speed and readability through the unit test framework. This continues the series' goal of modernizing Git's test infrastructure.
