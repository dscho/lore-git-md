Performance patch series integrating Git's benchmark infrastructure with Meson.

This is the third version of Patrick Steinhardt's series to wire up Git's performance benchmarks (`t/perf`) to work with the Meson build system. The series doesn't replace the existing `t/perf/run` script (which supports more advanced use cases like comparing across Git versions) but enables basic benchmarks against the current build.

Key changes in v3 focus on documentation and edge cases:
- Added documentation in meson.build explaining how to run benchmarks
- Expanded the commit message for out-of-tree build support to clarify how build directory paths are determined differently for Make vs Meson
- Fixed some terminology ("usecases" -> "use cases")

The implementation handles several technical challenges:
- Works with alternate repository formats (SHA256/reftable)
- Respects configured PERL_PATH
- Supports out-of-tree builds via GIT_BUILD_DIR environment variable
- Adds Meson configuration options for benchmark control

The series appears well-tested and addresses previous review comments. While some CI environment issues remain (tracked separately), the core functionality looks solid. This represents an important step in the broader Meson integration effort, making performance testing available across build systems.
