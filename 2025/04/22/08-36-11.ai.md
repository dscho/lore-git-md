This is a build system patch (Meson and Makefile) that implements the agreed-upon approach for installing completion scripts, focusing first on Bash support while deferring Zsh due to platform complexities. The patch follows up on prior discussion where Junio Hamano and others confirmed Bash completion installation is straightforward with well-defined paths.

The Meson implementation handles version compatibility by using `fs.copyfile()` for Meson >=1.3.0 and falling back to `configure_file()` for older versions. The Makefile addition introduces a new `bash_completion_dir` variable while maintaining the existing build directory behavior for testing.

- Uses standard installation path with distro customization via build variables
- Explicitly skips Zsh support due to unresolved path resolution issues
- Follows Junio's suggestion to mirror Makefile's `datadir` approach
- Files modified:

  - `contrib/completion/meson.build`: Implements version-aware installation
