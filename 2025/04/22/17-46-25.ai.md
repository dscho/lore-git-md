Performance test addition for the new `git-blame-tree` command.

This patch adds performance benchmarks for the new `git-blame-tree` command in `t/perf/p8020-blame-tree.sh` while also making some minor adjustments to the existing test file. The performance tests cover three scenarios: top-level non-recursive blame, top-level recursive blame, and recursive blame on a subdirectory. The tests use the standard Git test performance framework and will help track performance regressions across versions.

The patch also updates the existing test file `t/t8020-blame-tree.sh` to:
1. Consistently use the short `-r` flag instead of `--recursive`
2. Remove redundant `--no-recursive` flags (since non-recursive is the default)
3. Fix a previously failing test case for traversal limits
4. Adjust some test expectations to match the command's actual behavior

These changes appear to be straightforward test improvements that align with the command's design as described in the RFC. The performance tests in particular will be valuable for evaluating the command's scalability as the feature develops. The patch maintains the same testing rigor seen in the rest of the series.
