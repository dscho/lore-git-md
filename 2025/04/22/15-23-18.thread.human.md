Aditya Garg and Julian Swagemakers have been working on improving Git's `send-email` compatibility with OAuth2 authentication and Outlook's SMTP servers. Their v3 patch series adds support for modern authentication methods (OAUTHBEARER and XOAUTH2) directly in Perl since existing libraries lack this functionality, while also handling Outlook's behavior of replacing Message-IDs with its own proprietary format. The implementation enforces TLS encryption and includes helper functions for token generation.

The latest addition introduces a `--smtp-passeval` option that allows generating OAuth2 tokens dynamically via external scripts, completing the Outlook integration by addressing token refresh requirements. This mirrors functionality in other mail clients while maintaining Git's security model. The series has been tested in real-world use with Outlook and includes example configurations for both Gmail and Office 365 setups. With this final piece now in place, the series provides comprehensive solution for using Git's email workflow with modern authentication systems and Outlook's specific behaviors.
