This thread focuses on improving Outlook SMTP compatibility in `git send-email`, specifically around OAuth2 authentication and Message-ID handling. Aditya Garg and Julian Swagemakers' v3 series adds support for SMTP bearer authentication (OAuth2) and fixes Outlook's behavior of replacing Message-IDs with its own proprietary format. The implementation includes new helper functions for OAuth2 tokens and modifies the email-sending flow to extract Outlook's server-assigned Message-ID from SMTP responses, ensuring thread continuity when using Office365 servers.

Junio Hamano has reviewed the Message-ID handling patch (2/3) and identified a discrepancy between the implementation and its documentation. While the patch claims to set the Message-ID in email headers, it actually modifies it after headers are sent, affecting subsequent replies rather than the current message. Junio suggests rewording the commit message to accurately reflect this behavior and proposes extracting the Outlook domain check into a helper function for better maintainability. The discussion is focused on clarifying these technical details rather than challenging the overall approach, indicating the series is nearing readiness with some final polishing needed for accuracy and maintainability. The authors have confirmed real-world validation through testing, including from the git-credential-oauth maintainer.
