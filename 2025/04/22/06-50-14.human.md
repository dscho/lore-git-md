This is a performance-related patch in Patrick Steinhardt's series integrating Git's benchmark infrastructure with Meson. It wires up 47 existing performance benchmarks to run under Meson's `benchmark()` function, which provides special handling compared to regular tests (no parallel execution, not run with default test suite, no memory perturbation).

The patch adds documentation examples for running benchmarks via Meson while noting that advanced use cases (like comparing multiple Git versions) still require the traditional `t/perf/run` script. The implementation ensures the `time` utility is available and properly configured via the `GTIME` environment variable.
