This is a CI/build system patch addressing a test execution issue with Perforce (p4) tests in GitHub Actions. 

Patrick Steinhardt identifies why git-p4 tests weren't failing in CI despite known issues: the p4d executable path differs between dependency installation (run as root) and test execution (run as unprivileged user) due to $HOME changes. While GitLab CI already handles this by using /custom path, GitHub Actions was missing this configuration.

The proposed fix adds CUSTOM_PATH=/custom to GitHub Actions workflow, mirroring GitLab's setup. This should make the Perforce tests execute properly in GitHub Actions, helping catch regressions like those seen in the aw/t9811-modernize series. The patch is straightforward and addresses a clear CI coverage gap that allowed test failures to go undetected.
