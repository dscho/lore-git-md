This is a bugfix patch in the Meson build system refactoring series, addressing a typo in function availability checks.

The patch corrects an error in the build system's networking function checks where `strerror` was incorrectly included in the list of networking functions to verify, while the intended function `hstrerror` was missing. Eli Schwartz spotted that we never actually check for or use `strerror` in the codebase, while `hstrerror` (a networking function) should have been included in the verification list.

The change is minimal - just a one-line substitution in meson.build that replaces `strerror` with `hstrerror` in the networking function check loop. This ensures proper detection of the `hstrerror` function availability and potential definition of `NO_HSTRERROR` when missing, while removing the irrelevant `strerror` check.

Patrick Steinhardt acknowledges the fix as obviously correct, confirming this was an oversight in the original series. The patch maintains the series' goal of standardizing function availability checks while fixing this specific networking-related detection issue. This appears to be a straightforward correction with no outstanding questions or controversy.
