Performance patch fixing benchmark behavior with alternate repository formats (SHA256/reftable).

This is part of Patrick Steinhardt's v3 series integrating Git's performance benchmarks with Meson. The patch addresses an issue where benchmark tests copying repositories weren't properly preserving the source repository's format (object and ref storage), which could cause failures when testing with SHA256 or reftable formats.

The fix modifies `t/perf/perf-lib.sh` to extract the source repository's format information before copying, then passes those formats explicitly to `git init` when setting up the benchmark environment. This maintains the existing safety of not copying the full config (to avoid performance skew) while ensuring format compatibility.

The change is straightforward - just 4 lines added to query and pass through the formats. This builds on the series' broader work to make the benchmark infrastructure work reliably under Meson while maintaining all existing functionality. The patch appears well-contained and addresses a clear gap in the benchmark setup logic.
