This is a discussion about build system modernization, specifically regarding the detection of the deprecated `getpagesize()` function in the transition from autoconf to Meson.

Patrick Steinhardt responds to Eli Schwartz's note about `getpagesize()` being deprecated in POSIX 2001 and its special handling in Solaris. He acknowledges the autoconf infrastructure currently lacks this check, suggesting it might be worth adding there as well. However, the main thrust of his response is about the broader build system transition - he expresses hope that Git can soon drop autoconf entirely in favor of Meson, with only git-gui and gitk remaining as blockers (git-gui already adapted upstream, gitk changes still in review).

The email provides important context about the build system roadmap, positioning this specific function detection discussion within the larger transition effort. It reveals that the Meson migration is nearing completion, with just two GUI components remaining before autoconf could potentially be deprecated. The tone suggests confidence in this direction while still acknowledging the need to handle legacy cases like Solaris properly during the transition period.
