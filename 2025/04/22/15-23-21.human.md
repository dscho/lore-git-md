This is the final patch in a series adding OAuth2 and Outlook compatibility to `git send-email`. It introduces a new `--smtp-passeval` option that lets users specify a command to generate OAuth2 tokens dynamically, similar to how `passwordeval` works in msmtp. This is particularly useful for Outlook/Office365 users who require OAuth2 authentication.

The patch adds both documentation and implementation for the new option, which executes a user-specified command (like a Python script) to generate the authentication credential. The generated token overrides any static password that might be configured. Error handling ensures the command's failure will abort the email sending process.

This completes the series' goal of supporting modern authentication methods in `git send-email`, with this final piece providing the runtime token generation capability that some OAuth2 workflows require. The implementation looks clean and well-integrated with the existing SMTP authentication flow, maintaining the security requirement that OAuth2 must use TLS encryption.
