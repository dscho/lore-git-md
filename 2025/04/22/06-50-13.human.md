This is a performance test infrastructure patch that enables out-of-tree builds for Git's benchmark suite. It's part of Patrick Steinhardt's v3 series integrating the performance tests with Meson, addressing one of the key technical requirements identified in earlier discussion.

The patch modifies `perf-lib.sh` to properly locate the Git build directory when running benchmarks, which previously assumed build and source directories were the same (true for Make but not for Meson/CMake). The solution uses either a `GIT_BUILD_DIR` environment variable (for Meson) or path traversal (for Make), with special handling for Windows paths. It also fixes the path to `aggregate.perl` to work correctly in out-of-tree contexts.

The changes are well-motivated and clearly explained in the commit message, showing how this enables the Meson integration while maintaining backward compatibility with the Make-based build. The patch appears technically sound, with proper error handling and platform-specific considerations. This is a focused, necessary change in the broader effort to make Git's performance benchmarks work across all build systems.
