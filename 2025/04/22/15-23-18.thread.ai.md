Git send-email OAuth2 and Outlook compatibility series (v3) by Aditya Garg and Julian Swagemakers. Adds SMTP bearer authentication (OAuth2) support via OAUTHBEARER and XOAUTH2 mechanisms (RFCs 5801 and 7628), implemented directly in `git-send-email.perl` since Perl's Authen::SASL lacks support. Includes new helper functions (`generate_oauthbearer_string`, `generate_xoauth2_string`) and main `smtp_bearer_auth` function that enforces TLS encryption. Also fixes Outlook-specific Message-ID handling and introduces `--generate-password` option for OAuth2-like token generation. The changes modify both implementation (~90+ lines added) and documentation, with example configurations for Gmail and Office 365 setups using git-credential-oauth. Tested-by from git-credential-oauth maintainer confirms real-world validation. Currently being used by authors to send from Outlook. Open questions may include maintainability tradeoffs of Outlook-specific behaviors versus broader standards compliance.
