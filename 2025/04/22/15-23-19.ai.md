This is a feature patch adding OAuth2 authentication support to `git send-email`, specifically implementing SMTP bearer authentication (OAUTHBEARER and XOAUTH2 mechanisms). It's the first in a 3-part series focused on improving email sending compatibility with modern services like Gmail and Office 365.

The patch manually implements the SMTP AUTH command for OAuth2 since Perl's Authen::SASL module doesn't support these mechanisms. It adds two new helper functions (`generate_oauthbearer_string` and `generate_xoauth2_string`) that construct the proper authentication strings according to RFCs 5801 and 7628, plus a main `smtp_bearer_auth` function that handles the SMTP protocol interaction. The implementation enforces TLS encryption as required by the standards and includes example configurations for both Gmail and Office 365 setups showing how to use the new functionality with git-credential-oauth.

The changes modify both the `git-send-email.perl` implementation (adding ~60 lines of new auth handling code) and the documentation to explain the new OAuth2-specific requirements. The patch has been tested with real-world usage and includes a Tested-by from the git-credential-oauth maintainer. The implementation appears thorough, with proper attention to protocol standards and security requirements.
