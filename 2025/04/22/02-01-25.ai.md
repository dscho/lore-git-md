This is a test failure report for the performance test suite. Philippe Blain reports that the test p5332-multi-pack-reuse.sh, introduced in commit ba47d88795 ("t/perf: add performance tests for multi-pack reuse", 2023-12-14), fails consistently in its second test case ("setup bitmaps for 1-pack scenario") on both macOS and Linux systems, including in Git 2.44.0 where the test was first included.

The failure occurs early in the test sequence, and because performance tests run with '--immediate', it's unclear if subsequent tests in the file would also fail. Philippe notes an additional CI-related issue where GitHub Actions Linux jobs can't properly run the test at all due to missing Git installation in the container images, causing a different failure in perf-lib.sh.

The report includes links to private CI logs demonstrating the failures (GitHub Actions and GitLab CI) and discusses the GitHub CI limitation where the test environment lacks Git installation, preventing proper repository setup. Philippe suggests this could be addressed by installing Git before the checkout step but notes the complexity of handling different Linux package managers.

Key technical details for future reference:
- Failing test: p5332-multi-pack-reuse.sh, specifically the "setup bitmaps for 1-pack scenario" case
- Original commit introducing the test: ba47d88795
- CI environment issues: GitHub Actions containers lack Git installation, causing perf-lib.sh to fail with "No $GIT_PERF_REPO defined" error
- Affected versions: At least since Git 2.44.0
- Platforms affected: macOS and Linux (though CI limitations obscure full Linux testing)
