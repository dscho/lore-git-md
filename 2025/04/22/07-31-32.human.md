This is a technical follow-up in the ongoing Meson build system refactoring series, specifically addressing function availability checks.

Patrick Steinhardt responds to Eli Schwartz's suggestion about how to check for `sysinfo()` availability in the Meson build configuration. The discussion centers around commit c9a51775a36 which introduced usage of `struct sysinfo::mem_unit` for RAM calculations in `git gc`. While that commit uses multiple struct members, Patrick agrees that checking for just one member (`totalram`) is sufficient for the build system's purposes.

The exchange shows the careful attention being paid to build system modernization details, with Patrick validating Eli's proposed change to make the sysinfo check more precise by verifying struct member existence rather than just header presence. This fits into the series' broader goal of standardizing function availability checks while maintaining compatibility with existing Git behavior.
