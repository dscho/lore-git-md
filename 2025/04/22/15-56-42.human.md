Junio C Hamano acknowledges Karthik Nayak's explanation of a chicken-and-egg problem in the CI setup: the script that installs dependencies (`ci/install-dependencies.sh`) requires the source code to be available first, but the source checkout itself may need Git to be installed first (particularly when GitHub Actions uses tarball extraction rather than a Git clone).

The exchange confirms the complexity of the CI setup where package installation and source availability have mutual dependencies.
