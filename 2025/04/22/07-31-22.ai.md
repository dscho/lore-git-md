Refactoring of Git's Meson build system to standardize function availability checks, now in discussion of implementation details.

This email from Patrick Steinhardt responds to Eli Schwartz's patch that refactors Meson build system checks into a more maintainable array-based approach. The key points:

- Patrick agrees with the general direction of standardizing function checks but notes some stylistic and implementation concerns
- Points out the current code style requires spaces around colons in foreach loops
- Suggests making the `checkfuncs` array more explicit by using a dictionary that maps functions to their compatibility implementations, rather than the current "magic" approach of looking for files in compat/
- Overall approves of the simplification but wants to refine the implementation details

The discussion continues the thread's focus on build system modernization, now drilling into specific coding style and data structure choices for the function checking mechanism. This represents the fine-tuning phase after the broader architectural approach was established in earlier messages.
