Feature patch adding OAuth2 authentication support for `git send-email`. This is the first of two patches in a series aimed at improving Microsoft email service compatibility.

The patch implements SMTP bearer authentication (OAUTHBEARER and XOAUTH2 protocols) directly in the Perl script since these methods aren't supported by the Authen::SASL module. The implementation follows RFC standards (5801 and 7628) for the authentication string format and includes proper TLS enforcement as required by the spec. Users can configure this with existing credential helpers like git-credential-oauth, with examples provided for both Gmail and Office 365 setups.

The changes are well-documented in both code and man pages, explaining the new authentication flow and configuration requirements. The patch appears carefully implemented with attention to protocol details, including proper handling of authentication failures as specified in RFC7628. This should significantly improve the experience for developers needing to use Git with modern email services that require OAuth2 authentication.
