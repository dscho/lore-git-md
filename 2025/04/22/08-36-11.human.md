This is a build system patch addressing shell completion installation in both Makefile and Meson builds. It follows up on previous discussion about standardizing how Git's completion scripts get installed system-wide.

The patch focuses solely on Bash completion for now, installing it to the standard `/usr/share/bash-completion/completions/git` location (with appropriate fallbacks). This addresses user confusion where completion scripts were only copied to the build directory for testing but never installed properly. The implementation handles both pre- and post-Meson 1.3.0 versions with different file-copy methods.

The author deliberately skips Zsh completion for now due to its more complex platform-specific path requirements, though the commit message leaves the door open for future support. The patch also adds parallel Makefile support for consistency across build systems.

This appears to be a well-considered solution to the immediate Bash completion issue, incorporating feedback from the thread where Junio Hamano and others validated the approach. The implementation looks clean with proper version handling and maintains backward compatibility while fixing the core usability problem.
