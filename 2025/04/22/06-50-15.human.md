This is the final patch in Patrick Steinhardt's v3 series integrating Git's performance benchmarks with the Meson build system. The patch wires up three benchmarking configuration options that will be written to the GIT-BUILD-OPTIONS file, allowing users to control benchmark execution parameters.

The patch exposes three new Meson build options:
- `benchmark_repo` - specifies the repository to copy for performance tests (should be at least Git repository size)
- `benchmark_large_repo` - specifies a larger test repository (Linux kernel size recommended)
- `benchmark_repeat_count` - sets how many times each test should run (defaults to 3)

The implementation properly quotes these values when writing them to GIT-BUILD-OPTIONS, though it notably excludes two existing Makefile variables (`GIT_PERF_MAKE_COMMAND` and `GIT_PERF_MAKE_OPTS`) since they're only used by the legacy `t/perf/run` script that Meson uses.

This appears to be a straightforward technical completion of the benchmark integration work, with clear documentation of each option's purpose. The patch maintains consistency with the rest of the series and doesn't introduce any new dependencies or complications. With this in place, users can now fully configure benchmark execution through Meson's build system interface.
