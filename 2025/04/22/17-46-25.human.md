Performance test addition for the new `git-blame-tree` command.

This patch adds performance benchmarks script for the new `git-blame-tree` command as part of the RFC series introducing tree-level blame functionality. The new `t/perf/p8020-blame-tree.sh` script includes three basic performance tests: top-level blame (non-recursive), recursive blame across the whole tree, and blame focused on a specific subdirectory.

The patch also makes some minor adjustments to the existing test script (`t/t8020-blame-tree.sh`), primarily standardizing the use of `-r` for recursive mode rather than the longer `--recursive` flag, and fixing a previously failing test case for traversal limits. The changes appear straightforward and focused on establishing a performance baseline for the new command.

As this is part of an RFC series, these tests will help evaluate the command's performance characteristics before finalizing the design. The simple test cases cover the main operational modes but leave room for expanding the benchmarks with more complex scenarios if needed during review.
