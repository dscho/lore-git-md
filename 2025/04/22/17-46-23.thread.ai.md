Updated AI thread summary for the `git last-modified` command series:

The series implements a tree-level path modification tracker (`git last-modified`) with Bloom filter optimization, distinct from line-by-line `git blame`. Core functionality includes:
- Command interface with `-r` (recursive), `-t` (tree entries) flags and `--extended` format for forge-style output
- Path handling following `git diff-tree` conventions
- Bloom filter integration via `rev.bloom_filter_settings` with updated API calls
- `last_modified_entry` structs with hashmap lookups
- `maybe_changed_path()` helper for Bloom checks
- Extended format using `pretty_print_commit()` with `CMIT_FMT_RAW`
- Comprehensive test coverage in `t/t8020-last-modified.sh`
- Performance benchmarking suite in `t/perf/p8020-last-modified.sh` with three test scenarios (top-level, recursive, subdirectory)
