This RFC thread introduces and optimizes a new command for tracking modifications across directory trees (currently named `git-blame-tree`). The 7-patch series implements core functionality in new files `blame-tree.[ch]` and `builtin/blame-tree.c`, with test coverage in `t/t8020-blame-tree.sh` and performance benchmarks in `t/perf/p8020-blame-tree.sh`. The command tracks path states via `blame_tree_entry` structs with three performance optimization layers (Bloom filters, priority queue algorithm, revision walk initialization bypass) providing significant speedups.

Technical implementation includes generation-number-sorted priority queue, active path propagation, truncated revision walks, optimized parent diff processing, and direct boundary commit handling. Functionality preserves recursive/non-recursive modes, path filtering, and commit-hash/path output format, with tradeoffs around revision walk initialization.
