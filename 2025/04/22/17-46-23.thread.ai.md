Here is the updated AI thread summary for the `git last-modified` command series:

The `git last-modified` plumbing command series (originally `blame-tree`) tracks when paths were last modified in repository history at tree-level (unlike line-by-line `git blame`), using `last_modified_entry` structs with hashmap lookups and Bloom filter support (`bloom_key`) for performance. Core implementation resides in `builtin/last-modified.c` with revision walking infrastructure to compare tree states.

Technical implementation details:
- Command interface:

  - New `--extended` format in v5 for forge-style tree views with full commit metadata (OID, tree, parents, author/committer info, message)
  - Path handling follows `git diff-tree` conventions (directory aggregation)
- Core functionality:
  - `maybe_changed_path()` helper for Bloom filter checks (new in v5)
  - `mark_path()` handling path comparison logic (deletions, renames)

  - Bloom filter integration via `rev.bloom_filter_settings`
