Feature addition to `git send-email` implementing OAuth2 bearer authentication, rebased authorship from Julian Swagemakers with Aditya Garg now carrying the patch. This is the first patch in a two-part series that aims to enable Git email submission through Microsoft services.

The patch adds direct support for OAUTHBEARER and XOAUTH2 authentication mechanisms in `git-send-email.perl`, bypassing Perl's Authen::SASL module which lacks these methods. Key technical aspects include:
- New helper functions `generate_oauthbearer_string` and `generate_xoauth2_string` that format credentials according to RFCs 5801/7628 (OAUTHBEARER) and Google's XOAUTH2 protocol
- TLS encryption is enforced for OAuth authentication per RFC requirements
- Documentation updates explain the new `smtpAuth` values and credential requirements
- Integration with `git-credential-oauth` helper is demonstrated via configuration examples for both Gmail and Office 365

The implementation handles authentication handshake directly with the SMTP server, including proper error handling with dummy requests on failure as specified in RFC7628. The patch appears well-researched with clear references to relevant standards and has been tested by the original author and M Hickford. This provides a path forward for users whose email providers (particularly Microsoft services) now require OAuth authentication.
