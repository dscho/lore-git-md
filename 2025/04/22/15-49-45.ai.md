This is a performance test fix addressing an issue in the p5332-multi-pack-reuse.sh script. The patch corrects a leftover artifact from an earlier version of the multi-pack-index feature where packs were marked with "+" prefixes to indicate disjoint status - a feature that was removed before merging but left this vestigial syntax in the performance test.

The fix simplifies the sed invocation to just strip directory paths when feeding pack names to `git multi-pack-index write --stdin-packs`, matching the current implementation's expectations. Jeff King's commit message provides thorough historical context, tracing the issue back to the dropped disjoint packs feature from Taylor Blau's original series. The change is minimal (a one-line sed modification) but resolves the test failures that were occurring on both macOS and Linux systems.
