This is the final patch in Patrick Steinhardt's v3 series integrating Git's performance benchmarks with Meson, focusing on benchmark configuration options. The patch exposes three Meson build options for controlling benchmark execution: `benchmark_repo` (path to a standard-sized test repo), `benchmark_large_repo` (path to a Linux-sized repo), and `benchmark_repeat_count` (defaulting to 3 test repetitions). These values get written to GIT-BUILD-OPTIONS for use by the test infrastructure.

The implementation properly quotes the string values in meson.build and converts the repeat count to a string, while explicitly noting that some legacy Make-related variables (GIT_PERF_MAKE_COMMAND/OPTS) remain unexposed since they're only used by the non-Meson `t/perf/run` script. The patch maintains consistency with the series' approach of preserving existing benchmark behavior while adapting it to Meson's configuration system.
