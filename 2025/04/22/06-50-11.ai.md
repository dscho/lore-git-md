This is a performance test infrastructure patch in Patrick Steinhardt's v3 series integrating Git's benchmarks with Meson. It fixes an issue where benchmark repositories weren't properly preserving their object and ref storage configurations when copied for testing.

The patch modifies `t/perf/perf-lib.sh` to extract and pass through the source repository's format settings (`--show-ref-format` and `--show-object-format`) when initializing the benchmark copy. This ensures SHA256 and reftable repositories work correctly in performance tests, while still avoiding copying other potentially performance-impacting configuration.

The change is technically straightforward - just two new `rev-parse` calls and passing the results to `git init`. This maintains the existing safety of not copying the full config (which could skew results) while fixing the format compatibility issue. The patch fits cleanly into the ongoing Meson benchmark integration work, addressing one of the technical requirements for full compatibility.

Key technical details for future reference:
- Adds `refformat` and `objectformat` variable extraction in `test_perf_create_repo_from`
- Modifies the `git init` call to pass these formats explicitly
- Still skips copying hooks and general config to maintain benchmark isolation
- Specifically enables SHA256 and reftable format testing in Meson environment

The patch appears well-contained and correctly implements its stated purpose without introducing new complexity. It's a focused fix that moves the Meson benchmark integration closer to completion.
