This is a CI/build system patch addressing the git-p4 test execution issue in GitHub Actions. The email continues the ongoing discussion about test failures in the aw/t9811-modernize series, where p4 tests were silently skipped in CI.

Patrick Steinhardt identifies the root cause: the p4d and p4 binaries installed by ci/install-dependencies.sh are placed in "$HOME/path", but this location differs between the installation (privileged) and test execution (unprivileged) phases. The patch proposes setting CUSTOM_PATH to "/custom" in GitHub Actions (matching GitLab CI's approach) to ensure consistent binary location.

The change is minimal - a one-line addition to .github/workflows/main.yml - but addresses a critical CI coverage gap that allowed p4 test failures to go undetected. This builds on prior investigation by Jeff King and Junio C Hamano into why the test failures weren't caught by CI. The fix is straightforward but important for maintaining test reliability across platforms.
