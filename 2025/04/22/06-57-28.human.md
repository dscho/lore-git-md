This is a follow-up discussion in the ongoing thread about implementing header checking in Meson builds, specifically addressing how to handle the case when Git isn't available during the build process.

Patrick Steinhardt agrees with Phillip Wood's assessment that header checking targets should be skipped when either Git isn't installed or the source tree isn't a Git directory, rather than failing the build. He questions whether implementing a fallback to `find` (as the Makefile does) is worth the added complexity, since most users running these checks would likely have Git available anyway. 

The discussion highlights that CI environments are a special case where this issue surfaces, but Patrick suggests this should be straightforward to fix there. This continues the thread's exploration of how to best adapt Makefile functionality to Meson while considering real-world usage patterns and CI requirements. The exchange shows the project's careful consideration of when to maintain exact parity with existing behavior versus when to diverge for simplicity.
