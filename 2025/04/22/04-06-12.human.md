This is a follow-up in the thread about performance test failures in p5332-multi-pack-reuse.sh. Junio C Hamano responds to Philippe Blain's observation about CI issues preventing proper testing on GitHub Actions Linux jobs. 

The core issue is that GitHub's Linux CI containers don't have Git pre-installed, causing the performance test infrastructure to fail early. Philippe had noted this could potentially be fixed by installing Git before checkout, but mentioned the complexity of handling different Linux package managers.

Junio suggests a broader solution - that CI jobs should generally install all dependencies (including Git itself) before attempting to check out the repository. He notes this isn't just a problem for this specific test case, as they've recently encountered similar issues with other topics. The comment is more of a general CI process observation than a direct fix for the performance test failure, but it points to a systemic issue affecting multiple test scenarios.
