Thread identity: Bugfix patch addressing wildcard pathspec handling in Git commands, reported by Piotr Siupa and mentored by Jeff King. Focuses on `git add` and `git commit` behavior with wildcard pathspecs.

Core problem: When a literal file named like a wildcard pattern exists (e.g. `f*`), commands like `git add f*` incorrectly skip matching files (e.g. `foo`). The patch ensures proper handling of escaped wildcards (e.g. `f\*` for literal matching) by modifying `do_match_pathspec` in `dir.c` to correctly handle the `nowildcard_len` case.
