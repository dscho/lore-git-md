This is a performance-related patch in the ongoing Meson benchmark integration series. It wires up Git's performance benchmarks (`t/perf/`) to the Meson build system, completing the core functionality for running benchmarks through Meson.

The patch adds 47 benchmark scripts to Meson's benchmark() function, which provides special handling compared to regular tests: benchmarks don't run in parallel, aren't executed by default with tests, and avoid MALLOC_PERTURB injection. The implementation requires the `time` utility (detected at configure time) and sets up the GTIME environment variable. Benchmark execution preserves the existing `t/perf/run` script for advanced use cases while providing basic Meson support.

Key technical details include:
- Benchmark scripts are listed in the `benchmarks` array in t/meson.build
- Each benchmark runs in the `perf/` work directory with timeout disabled
- The implementation shares test environment/dependencies (`test_environment`, `test_dependencies`)
- Documentation in meson.build is updated with benchmark usage instructions
- The patch maintains compatibility with existing benchmark infrastructure while adding Meson support
- Known limitations documented (e.g., no support for running benchmarks against multiple Git versions)
