Refactoring patch in Patrick Steinhardt's object storage modularization series (v3 06/10). This change splits the overloaded `HASH_*` flags into separate sets for different object-file functions, improving code clarity and maintainability.

The patch addresses a longstanding issue where `hash_object_file()`, `write_object_file()`, and `index_fd()` all used the same set of flags despite each function only supporting a subset. This created confusion about which flags were valid where and made the implementations unnecessarily entangled. The solution introduces distinct flag enums for each function group: `INDEX_*` flags for index-related operations and `WRITE_OBJECT_FILE_*` flags for writing objects.

Key changes include:
- New `INDEX_WRITE_OBJECT`, `INDEX_FORMAT_CHECK`, and `INDEX_RENORMALIZE` flags replace the old `HASH_*` variants for index operations
- New `WRITE_OBJECT_FILE_PERSIST` and `WRITE_OBJECT_FILE_SILENT` flags handle object writing behavior
- Updates all callers across 9 files to use the new flags
- Maintains all existing behavior while making the interface more self-documenting

This is a well-executed cleanup that follows through on the series' goal of better code organization. The changes are mechanical but meaningful, touching several subsystems (builtins, bulk-checkin, cache-tree) while keeping the diff focused. As with previous patches in the series, this demonstrates careful attention to detail in updating all callers.
