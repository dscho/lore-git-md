Documentation patch converting command list generation from Perl to shell, part of the ongoing Perl dependency reduction effort. This is the final patch in Eric Wong's series to make Perl optional for core Git functionality.

Patrick Steinhardt converts the `cmd-list.perl` script to a shell implementation (`cmd-list.sh`), removing the last Perl dependency for building Git's documentation. The script generates categorized command lists for inclusion in the git(1) manpage by parsing command descriptions from individual manpages. While the shell version is about 7x slower (74ms vs 10ms in benchmarks), the performance impact is deemed acceptable since this runs only during build time.

The patch updates both Makefile and meson build systems to use the new shell script, and removes the Perl requirement from meson.build when documentation is enabled (though Perl is still needed for gitweb and netrc credential helper). The conversion carefully preserves all existing behavior including manpage section detection, command description extraction, and deprecated command marking. This continues the project's broader effort to reduce mandatory Perl dependencies following earlier test infrastructure conversions.
