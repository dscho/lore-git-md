This is a discussion about Cygwin version support in the ongoing build system alignment series.

Junio Hamano responds to Patrick Steinhardt and Ramsay Jones regarding the question of dropping support for pre-2.0 Cygwin versions. The context is Ramsay's earlier patch that would remove conditional configuration for older Cygwin versions entirely dropping pre-v2.x support, which he deferred to Cygwin maintainer Adam Dinwoodie to decide.

Junio expresses openness to dropping pre-2.0 support if Adam confirms it's no longer relevant, noting that fewer configuration knobs are generally better. He raises a practical concern about maintaining changes for untestable older systems, stating he's comfortable with either approach: either explicitly noting certain systems are untested, or simply not supporting them at all in the patchset.

The discussion highlights the project's broader challenge of balancing backward compatibility with maintainability, particularly for platforms that core developers cannot easily test. This ties into the series' larger goal of build system simplification and standardization.
