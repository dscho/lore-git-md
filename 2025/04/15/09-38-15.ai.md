This is part of Patrick Steinhardt's v3 series refactoring object storage, specifically moving directory creation utilities from object-file.c to path.c. The patch relocates `safe_create_leading_directories()` and related functions to path.c where they better belong with other path utilities, while making them repository-aware to advance the `the_repository` removal effort.

The changes involve:
- Moving the SCLD (safe create leading directories) functions from object-file.[ch] to path.[ch]
- Adding repository parameters to handle core.sharedRepository config properly
- Updating 150+ call sites across the codebase to pass the repository parameter
- Renaming `mkdir_in_gitdir()` to `safe_create_dir_in_gitdir()` for consistency
- Splitting the changes into a separate commit from the original relocation

Key technical details:
- Functions moved: `safe_create_leading_directories()`, `safe_create_leading_directories_const()`, `safe_create_leading_directories_no_share()`
- New location: path.c alongside related utilities like `safe_create_dir()`
- Caller updates span builtins (clone, worktree, submodule), object-file.c, refs/files-backend.c, and more
- Behavior remains identical except for the new parameterization

The patch demonstrates careful attention to the series' architectural goals while maintaining backward compatibility. It completes the directory utility relocation that was discussed and refined across previous iterations of the series.
