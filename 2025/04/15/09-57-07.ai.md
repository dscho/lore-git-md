This is a cover letter for a patch series continuing the effort to make Perl an optional dependency in Git. The series follows up on previous work to remove Perl from the test suite, now targeting three additional areas: `git-filter-branch`, `git-request-pull`, and documentation building.

The cover letter clearly positions this as part of an ongoing effort, referencing a prior series that removed Perl from test infrastructure. The technical approach appears to be replacing Perl scripts with shell equivalents, as seen in the file changes where `.perl` files are removed and `.sh` counterparts are added.

The series consists of 4 patches that:
1. Convert filter-branch from Perl to shell
2. Convert request-pull from Perl to shell
3. Replace Perl-based user manual processing with shell
4. Replace Perl-based command list generation with shell
