This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking (v3, 4/9). The patch moves the initialization and execution of the reachability traversal from `read_packs_list_from_stdin()` to its caller `read_stdin_packs()`, preparing for future changes where this traversal will also be used to find reachable objects from input packs that are packed elsewhere.

Key technical details:
- The `rev_info` struct initialization and traversal code is extracted from `read_packs_list_from_stdin()` to `read_stdin_packs()`
- The traversal will be reused for both the current name-hashing optimization and future functionality to include reachable objects from unlisted packs
- The patch maintains identical behavior while restructuring for better code sharing
- Changes focus on `builtin/pack-objects.c` with no user-visible effects
- This is a preparatory step for patch 8/9 which will introduce `--stdin-packs=follow` mode
- The refactoring follows the series' pattern of structural improvements before feature additions

The patch continues the series' careful approach to code organization, with this change specifically enabling future functionality while keeping the current behavior intact. It demonstrates good separation of concerns by moving the traversal logic to where it conceptually belongs (in the caller that orchestrates the packing process).
