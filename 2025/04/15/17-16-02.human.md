Build system fix for meson regression. Ramsay Jones reports that the current 'seen' branch fails to build with meson due to a missing `target_shell` variable definition, which was apparently dropped in commit 916e0fb7c0 (a merge of the 'ps/meson-build-perf-bench' branch). The error occurs during configuration with `meson setup`.

Jones provides a straightforward fix that restores the `find_program()` call to set `target_shell`, using the same pattern as other tool lookups in the meson.build file. The patch appears to be a clear bugfix for an unintended regression, though it's worth noting that the commit message doesn't explain why the variable was removed in the first place. The fix is minimal and follows existing conventions in the build file.
