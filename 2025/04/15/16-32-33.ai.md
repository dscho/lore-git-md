This is a documentation build system patch in the ongoing Perl removal effort, specifically addressing the command list generation script. The patch converts `cmd-list.perl` to a shell script (`cmd-list.sh`) that produces identical output for Git's command documentation, though with a noted 7x performance penalty (74ms to 10ms). The slowdown is deemed acceptable given the benefit of removing Perl as a build requirement.

Key technical details include:
- The script parses command documentation from `.adoc` files, extracting command names, manpage sections, and descriptions
- Maintains special handling for deprecated commands via `(deprecated)` markers
- Preserves the same output format (`linkgit:cmd[section]::\n\tdescription`) as the Perl version
- Uses shell case statements for parsing, with Junio noting minor style preferences for alignment
- Implements atomic file updates with `cmp`/`mv` to avoid partial writes

Junio Hamano's review approves the conversion despite the performance tradeoff, suggesting only minor stylistic tweaks to case statement formatting and `for` loop syntax. This completes the series' goal of eliminating Perl from documentation building, following earlier conversions of `filter-branch` and `request-pull`. The patch appears merge-ready with no substantive objections.
