This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction. It's patch 3/9 in v3 of the series.

The patch extracts the inline handling of `--stdin-packs` from `cmd_pack_objects()` into a new function `read_stdin_packs()`. This prepares for future expansion of the stdin-packs functionality while keeping the main command function clean. The change is purely structural - the behavior remains identical, just moved to a dedicated function. The new function maintains the same two key operations: setting `ignore_packed_keep_in_core` and conditionally calling `add_unreachable_loose_objects()` based on the `rev_list_unpacked` parameter.

This continues the series' pattern of improving code organization before adding new features. The change touches `builtin/pack-objects.c` with a straightforward extraction that should be uncontroversial, following the earlier refactoring work in patches 1/9 and 2/9. The patch maintains all existing functionality while setting up for the more substantial changes to come in later patches (particularly patch 8/9 which introduces the new `--stdin-packs=follow` mode).
