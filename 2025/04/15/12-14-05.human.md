Refactoring patch converting parse-options initializations to use designated initializers. This is the first patch in Patrick Steinhardt's v2 series hardening integer handling in Git's parse-options infrastructure.

The patch systematically converts all manual struct initializations of parse-options to use designated initializers (field.name = value syntax) rather than positional initialization. This provides several benefits: clearer code by explicitly naming fields, easier maintenance when adding new fields, and the ability to skip default-initialized fields. The changes span 24 files across Git's codebase, touching many commands' option parsing code.

This foundational change enables the subsequent patches in the series which add type safety for integer options. The conversion is mechanical but thorough, maintaining exact behavior while improving code structure. The patch follows Git's established style for designated initializers and appears well-tested given the wide scope of changes.

As the first step in a larger effort to improve parse-options safety, this refactoring sets up the infrastructure needed for the more substantive type-checking changes to come in later patches. The changes are low-risk since they don't modify behavior, just initialization syntax.
