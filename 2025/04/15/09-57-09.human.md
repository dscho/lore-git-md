This is part 2 of a 4-part series to make Perl optional in Git, focusing on converting `git-request-pull` from Perl to shell. The patch removes Perl as a dependency for `git-request-pull`, which previously could fail if Perl wasn't available despite being installed unconditionally.

Patrick Steinhardt refactors the script to replace a Perl-based reference matching function with an equivalent shell implementation. The core functionality remains the same - finding a remote ref that matches the local commit - but now uses shell string manipulation and pattern matching instead of Perl regexes. The test changeset removes the Perl prerequisite check since it's no longer needed.

The conversion appears thorough, maintaining the same behavior while eliminating the Perl requirement. This aligns with the series' goal of reducing Git's Perl dependencies, following similar conversions of other scripts. The changes are relatively straightforward, focusing on one specific component of the request-pull functionality, and the patch maintains all existing test coverage while removing the Perl-specific skip condition.
