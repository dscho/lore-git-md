Git mentoring programs AI-spam guidelines thread summary:

Christian Couder reports a surge in AI-generated spam proposals for Git's 2025 mentoring programs (GSoC/Outreachy), with 71 of 79 GSoC submissions being low-quality AI content. In response, mentors and org admins developed anti-AI-spam guidelines documented in GitHub PR #771, linked from Git's General Application Information page. Early data suggests organizations with such guidelines experience reduced spam volume. The email raises the question of whether these measures should expand project-wide contribution policies, indicating this may initiate broader discussions about AI use in Git development. Current guidelines specifically target mentoring program applications, addressing an acute problem where manual review became impractical due to spam volume (71/79 ratio representing a significant year-over-year increase). The GitHub PR contains the exact policy language being implemented.
