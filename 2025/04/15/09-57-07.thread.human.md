The thread documents the successful completion of a multi-year effort to remove Perl as a hard dependency from core Git, with Eric Wong's series converting the last remaining Perl scripts (`git-filter-branch`, `git-request-pull`, and documentation tooling) to shell implementations. The work was reviewed and merged by Junio Hamano, with Patrick Steinhardt contributing the command list generation component. Performance impacts were measured (notably a 7x slowdown for command list generation deemed acceptable) and behavior was carefully preserved across all conversions.

A follow-up discussion clarified one subtle difference in the `git-request-pull` ref matching behavior between the original Perl and new shell versions. While already merged, Patrick Steinhardt acknowledged that the shell implementation was slightly stricter about dereferenced ref patterns (`^{}` suffixes) than the original, and proposed how it could have matched the Perl version's more flexible handling. This exchange serves as documentation of the design consideration, though no code changes are needed since the series is complete. The thread stands as a milestone in Git's dependency reduction, with only gitweb and send-email remaining as notable Perl dependencies for future work.
