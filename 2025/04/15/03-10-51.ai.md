This is a performance optimization patch in Taylor Blau's series about MIDX and cruft pack interaction during repacking. The patch focuses on improving delta compression for loose objects when using `--unpacked` with `--stdin-packs`.

The key change makes loose objects participate in the name-hash traversal when they're added to the pack, which can lead to better delta compression (though the patch notes this doesn't affect correctness). The implementation passes the `rev_info` struct through to the loose object addition code so commits can be added as traversal tips.

Elijah Newren raises two points in his review:
1. A typo correction (effect/affect) in the commit message
2. A question about whether tests should demonstrate the behavioral difference in included objects

The changes are relatively contained to `builtin/pack-objects.c`, modifying how loose objects are handled in several functions (`add_unreachable_loose_objects`, `add_loose_object`, and their callers). The patch maintains the existing behavior when `revs` is NULL (as seen in the `enumerate_cruft_objects` and `get_object_list` call sites).

This appears to be a straightforward optimization that builds on the series' earlier refactoring work. The lack of tests demonstrating the delta improvement might be worth addressing, though the core change seems sound. The patch fits cleanly into the larger series' goal of optimizing pack maintenance operations.
