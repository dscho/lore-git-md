Performance optimization introducing a new `--stdin-packs=follow` mode for pack-objects, part of a series improving MIDX and cruft pack handling during repacking.

This patch adds a new "follow" mode to `--stdin-packs` that includes reachable objects from unlisted packs, addressing a key limitation in geometric repacking scenarios. The change allows Git to properly handle cases where objects in cruft packs become reachable through new commits, ensuring MIDX can maintain accurate reachability bitmaps. The implementation modifies the pack-objects traversal logic to optionally include these "resurrected" objects while respecting excluded packs.

The patch includes thorough documentation updates and a new test case verifying the behavior with various pack combinations. This builds on previous work in the series that refactored option handling and prepared the code structure. The change is well-motivated by real-world repacking needs and maintains compatibility with existing behavior when not using the new mode.

This is part 8/9 of Taylor Blau's v3 series, which has seen careful review and refinement through multiple iterations. The implementation appears solid, with clear test coverage demonstrating both the basic functionality and edge cases involving loose objects and multiple excluded packs.
