Performance optimization for MIDX and cruft pack interaction during repacking. This is version 3 of Taylor Blau's series that explores creating MIDX files that exclude cruft packs where possible, while maintaining reachability guarantees for bitmap generation.

The series has been refined based on feedback from Junio Hamano and Elijah Newren, with several notable since v2:
- Dropped a patch about designated initializers to keep focus on the core functionality
- Reordered an error message check to match standard function behavior
- Split out some code movement changes to make substantive patches clearer
- Added documentation improvements and test updates
- Introduced a new `--stdin-packs=follow` mode that helps resurrect once-cruft objects when needed

The key technical change is that geometrically-repacked packs will now include copies of once-unreachable objects when needed to maintain reachability closure, allowing the MIDX to safely exclude cruft packs. This should improve performance since most cruft pack objects are rarely accessed but currently must be searched during MIDX lookups.

The series appears well-tested and documented, with Taylor planning to deploy it on GitHub's infrastructure for real-world validation. The discussion shows careful attention to edge cases and maintainability concerns, suggesting this is nearing readiness for inclusion.
