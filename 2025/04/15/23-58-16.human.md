CI infrastructure fix addressing a sudden Fedora pedantic job failure.

Junio Hamano reports that GitHub Actions CI started failing on Fedora jobs with complaints about missing "awk", despite no recent awk-related changes landing in master. The patch provides a minimal fix by making awk installation conditional on Fedora (where it's now apparently missing) while leaving AlmaLinux systems unchanged (where awk either isn't needed or has a different package name).

The change modifies `ci/install-dependencies.sh` to only request awk when running on Fedora. This follows a pattern seen before with Ubuntu 20.04 image retirements causing CI issues, suggesting another silent base image update may be the root cause.

While the patch works around the immediate problem, Hamano notes the underlying cause remains unclear, which he finds unsatisfactory. The fix is presented as a band-aid solution while the investigation continues. The change is minimal and low-risk, affecting only the CI dependency installation script.
