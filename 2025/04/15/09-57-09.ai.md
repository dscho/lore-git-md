This is part 2 of a 4-part series to make Perl optional in Git, specifically converting `git-request-pull` from Perl to shell. The patch focuses on removing Perl as a runtime dependency for `git-request-pull.sh`.

The key change replaces a Perl script that matched remote refs with an equivalent shell implementation. The original used Perl to parse `git ls-remote` output and find refs matching the requested branch, while the new version implements the same logic in shell using a `find_matching_ref` function. The function handles both direct ref matches and dereferenced tags, maintaining the same behavior while eliminating the Perl requirement.

The patch removes Perl-specific test prerequisites since the functionality no longer depends on Perl being available. This makes `git-request-pull` more portable as it will work on systems without Perl installed. The conversion appears thorough, preserving all the original matching logic while using shell constructs like `case` statements and variable substitution.

This change aligns with the series' goal of reducing Git's Perl dependencies, following similar conversions in other scripts. The implementation looks clean and maintains backward compatibility of the request-pull functionality while removing a build-time requirement.
