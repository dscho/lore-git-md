This is a cover letter for v3 of a performance optimization series about MIDX and cruft pack interaction during repacking. The series introduces configurable optimization of pack maintenance through enhanced pack-objects behavior, particularly for cruft pack inclusion in MIDX during repacking while maintaining reachability guarantees.

Key changes in v3:
- Dropped the designated initializer warning patch to keep focus on core functionality
- Split code movement changes into separate patches for better reviewability

- Added more test coverage

The core technical work remains:
- New `repack.midxMustContainCruft` config option (patch 9/9)
