Performance optimization for MIDX and cruft pack interaction during repacking. This is the final patch in Taylor Blau's 9-part series, introducing configurable control over whether cruft packs must be included in the MIDX during repacking.

The patch adds a new `repack.midxMustContainCruft` config option (defaulting to true for backward compatibility) that determines whether cruft packs should always be included in the MIDX. When set to false, Git will only include cruft packs when necessary to maintain reachability guarantees for MIDX bitmaps. The implementation builds on the `--stdin-packs=follow` mode introduced in patch 8/9, which ensures geometric repacks properly include any objects that become reachable from cruft packs.

Key technical details:
- New config option in `repack.midxMustContainCruft` with true/false values
- When false, uses `--stdin-packs=follow` during geometric repacking to include necessary objects in new packs
- Adds `midx_has_unknown_packs()` helper to detect when cruft packs must be included for reachability
- Comprehensive test coverage in t7704-repack-cruft.sh with three scenarios:
  * Excluding cruft packs when possible
  * Including cruft packs when instructed
  * Including cruft packs when necessary for reachability
- Maintains backward compatibility with existing behavior by default

The change addresses performance concerns where MIDX bloat from cruft packs can slow down object lookups, while maintaining the ability to generate bitmaps. The implementation carefully handles edge cases where cruft packs might still be needed for reachability closure.
