A refactoring and hardening series for Git's parse-options integer handling. This is version 2 of Patrick Steinhardt's 5-part series that systematically improves type safety when handling integer options throughout Git's codebase.

The series builds on previous discussions about integer handling issues, introducing several key improvements:
1. Uses designated initializers for all parse-options structs (24 files)
2. Adds precision tracking for `OPTION_INTEGER` and `OPTION_MAGNITUDE` to support arbitrary integer sizes
3. Introduces a new `OPTION_UNSIGNED` type for positive-only values
4. Adds build-time assertions to catch signedness mismatches

Version 2 incorporates feedback from René Scharfe, notably changing the bounds calculation to use logic similar to `maximum_signed_value_of_type()`. The series affects many commands (31 files modified) including `git grep`, `git apply`, and `git backfill`, fixing real-world issues with integer handling on big-endian systems and elsewhere.

The changes maintain backward compatibility while preventing future misuse through compile-time checks rather than runtime validation. The series appears well-tested with comprehensive coverage in both C tests and shell scripts. This is a significant hardening effort that addresses systemic issues in Git's option parsing infrastructure.
