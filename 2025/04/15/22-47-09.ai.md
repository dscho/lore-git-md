This is a preparatory refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking.

The patch swaps the order of two functions in `builtin/pack-objects.c` to prepare for future changes where `show_commit_pack_hint()` will need to call `show_object_pack_hint()`. Currently `show_commit_pack_hint()` is a no-op function that handles commits (which don't have namehashes), while `show_object_pack_hint()` contains the actual logic for tracking pack hints. The reordering minimizes code movement in the upcoming patch that will implement this call relationship.

The change is straightforward - it moves the `show_commit_pack_hint()` function definition after `show_object_pack_hint()` with no other modifications. This was suggested by Elijah Newren as part of the ongoing code review. The patch maintains the series' focus on clean, reviewable structural changes while preparing for the more substantive functionality to come in patch 8/9.
