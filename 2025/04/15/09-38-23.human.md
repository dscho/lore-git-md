This is the final patch in Patrick Steinhardt's object store refactoring series (v3 10/10). It completes the consolidation of object store headers by merging "object-store-ll.h" into "object-store.h" now that all the low-level object store functionality has been properly organized.

The change removes the remaining distinction between the two headers by moving the `odb_path_map` definition from the header into object-store.c, making "object-store.h" the single authoritative header for object store functionality. The patch updates 124 files to use the unified header, showing the wide impact of this change across the codebase.

This is a mechanical change that doesn't introduce any functional differences - it's purely about code organization and reducing header complexity. The series has already addressed all architectural questions in previous iterations, and this final patch cleanly wraps up the header consolidation effort. The change is well-contained and follows the pattern established by earlier patches in the series.
