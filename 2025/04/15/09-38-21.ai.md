This is part of Patrick Steinhardt's ongoing object storage refactoring series (v3 08/10), continuing the effort to modularize Git's object storage subsystem. The patch moves object store management functions from object.c to object-store.c, maintaining the series' pattern of logical code organization while preserving all behavior.

Key changes:
- Moves `raw_object_store_new()`, `free_object_directory()`, `free_object_directories()`, and `raw_object_store_clear()` to object-store.c
- Updates related header includes (removing object-store.h from object.c)
- Keeps all functionality identical while improving subsystem separation
- Follows the established pattern from earlier patches in the series

The changes affect:
- Object store initialization/cleanup (`raw_object_store_new/clear`)
- ODB directory management (`free_object_directory/directories`)
- Related subsystems: commit-graph, loose objects, packed objects
- Build impact: object-store.c now handles these functions
- Header cleanup: object.c no longer needs object-store.h
- Thread context: Continues v3's finalized architectural decisions

This is a straightforward organizational change that completes the separation of object store management from the core object handling code, maintaining all prior decisions from the series while furthering the codebase's modularization. The patch appears well-contained and mechanically sound, with no behavior changes beyond the intended relocation of functionality.
