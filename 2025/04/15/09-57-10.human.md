This is part 3 of a 4-part series to make Perl optional in Git, focusing on documentation build system changes. The patch converts the `fix-texi.perl` script to a shell equivalent (`fix-texi.sh`), removing Perl as a requirement for building the user manual.

The script performs two simple text transformations on the output of `docbook2x-texi`: changing the output filename to "git.info" and inserting a standardized directory entry for the manual. The conversion from Perl to shell (using `awk`) is straightforward and maintains identical functionality. The patch updates the Makefile to use the new shell script instead of the Perl version.

This change is a clean, mechanical conversion that follows the series' goal of reducing Perl dependencies. The patch appears well-executed, with the shell implementation being just as readable as the original Perl version. As with the rest of the series, this is a non-controversial change that continues established work to make Git's build system less Perl-dependent.
