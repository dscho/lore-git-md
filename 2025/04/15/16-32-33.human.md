This is the final patch in a series removing Perl dependencies, specifically converting the command list generation script from Perl to shell. Patrick Steinhardt's conversion maintains identical output while accepting a 7x performance penalty (74ms to 10ms) as a worthwhile tradeoff for eliminating Perl as a build requirement.

Junio Hamano provides a light code review, noting the performance impact is acceptable since the script isn't run frequently. He points out minor shell script style nits - suggesting better alignment of `case` statements and omitting unnecessary `in "$@"` - but these are purely cosmetic improvements rather than functional issues.

The patch represents the completion of this particular Perl removal effort, following earlier conversions of `filter-branch` and `request-pull`. While the series appears merge-ready, Junio's review confirms the documentation build system changes are technically sound, leaving only trivial style tweaks as optional follow-ups.
