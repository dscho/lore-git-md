This is a performance optimization patch in Taylor Blau's ongoing series improving MIDX and cruft pack interactions during repacking. It's part 5 of 9 in v3 of the series.

The patch fixes an oversight where loose objects (those not in any excluded packs) weren't being considered as reachability tips for the name-hash traversal when using `--unpacked`. While this didn't affect correctness, it meant Git wasn't finding optimal deltas for these objects. The change passes the `rev_info` struct to the loose object handling code so these objects can participate in the traversal.

The implementation is straightforward - it modifies `add_unreachable_loose_objects()` to accept the `rev_info` struct and uses it to mark commit objects as traversal tips. The patch maintains backward compatibility by allowing NULL `rev_info` in other call sites. This is a clean, focused change that builds on the structural refactoring done in earlier patches of the series.

The improvement should result in slightly more efficient packs when repacking with loose objects, though the actual impact would depend on the repository's object graph. This continues the series' pattern of methodical improvements to the pack-objects machinery.
