This is a CI/build system patch addressing a Fedora-specific test failure. Junio Hamano reports that GitHub Actions CI started failing on Fedora pedantic jobs due to missing "awk", though it's unclear why this suddenly became a problem since no recent changes to master should affect awk usage. The patch conditionally installs awk only on Fedora systems (not AlmaLinux) as a quick fix, though the root cause remains unknown.

The change modifies `ci/install-dependencies.sh` to make awk installation Fedora-specific, while maintaining the existing dependency list for other platforms. This follows a pattern seen with Ubuntu 20.04 image retirements causing similar CI issues. The commit message expresses dissatisfaction with not understanding why the failure occurred, suggesting this may be a temporary workaround rather than a proper solution.

Key technical details for future reference:
- Only affects Fedora CI jobs (not AlmaLinux)
- Modifies package installation logic in the shared CI script
- Introduces conditional awk installation via distro detection
- Follows precedent of similar CI workarounds for platform changes
- Unclear what actually requires awk in the Fedora environment

The patch appears to be low-risk as it only affects CI infrastructure, but the mystery around why awk became suddenly required may warrant further investigation in follow-up discussions.
