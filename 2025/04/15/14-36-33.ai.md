This is a CI/build system follow-up regarding the recently merged Meson benchmark integration series. Junio Hamano reports that merging the series has caused failures in all GitHub Actions CI jobs related to Meson builds, including the newly added documentation verification step for Meson builds. He suspects a merge error may be responsible and asks Patrick Steinhardt to investigate.

The context shows this was the final patch series integrating Git's performance benchmarks with Meson, which had previously achieved technical consensus. The series maintained compatibility with `/usr/bin/env perl` shebangs and added out-of-tree build support while keeping the existing `t/perf/run` script functional. All core technical requirements were satisfied before merging.

The current issue appears to be a post-merge integration problem rather than a flaw in the original design. The failures affect both benchmark-related CI tasks and unrelated documentation verification steps in Meson builds, suggesting a broader build system issue was introduced during merge. This warrants investigation to determine whether the problem stems from the benchmark integration itself or from how it was merged with other ongoing changes.
