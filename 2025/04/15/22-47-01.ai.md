Performance optimization patch in the MIDX/cruft pack series, focusing on delta compression improvements.

This patch (5/9 in v3) addresses a missed optimization opportunity in pack-objects' handling of loose objects when using `--unpacked` with `--stdin-packs`. The original implementation didn't include loose objects in the name-hash traversal used for delta compression, which could result in suboptimal delta chains. The key change moves the `rev_info` struct declaration to make it accessible to `add_unreachable_loose_objects()`, allowing loose objects to be considered as potential delta bases. While this doesn't affect correctness (the resulting packs would still contain all required objects), it should produce slightly more space-efficient packs by enabling better delta opportunities.

The implementation modifies several functions in `builtin/pack-objects.c` to pass the `rev_info` struct through the call chain, with special handling for commit objects which are added as traversal tips. The changes maintain all existing behavior when no `rev_info` is passed (as in the cruft objects enumeration case), showing careful attention to backward compatibility.

This patch builds on the structural refactoring done in earlier patches of the series, particularly the movement of reachability traversal initialization in patch 4/9. It demonstrates the series' methodical approach - first establishing clean foundations, then implementing optimizations. The change is well-contained and follows the established pattern of the series, with clear documentation in the commit message about both the problem and solution.
