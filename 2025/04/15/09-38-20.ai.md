This is a refactoring patch in Patrick Steinhardt's ongoing object storage refactoring series (v3 07/10). The patch removes the `index_blob_stream()` wrapper function from object-file.c, which has been a trivial passthrough to `index_blob_bulk_checkin()` since 2011. The function's explanatory comment is moved to bulk-checkin.h where the target function is declared.

The change is straightforward - it's part of the series' effort to clean up and rationalize the object-file implementation. The patch maintains all existing behavior while simplifying the call chain for blob indexing. The comment migration ensures the important context about streaming behavior and filter bypass remains available to callers.

This continues the series' pattern of organizational improvements without functional changes, here focusing on removing an unnecessary indirection layer in the bulk checkin code path. The patch affects only two files (object-file.c and bulk-checkin.h) with simple deletions and comment relocation.
