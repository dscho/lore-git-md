Refactoring patch in a performance optimization effort for MIDX and cruft packs.

This is a small but strategic code movement in Taylor Blau's ongoing series to optimize pack maintenance. The patch swaps the order of two functions in `builtin/pack-objects.c` to prepare for future changes where `show_commit_pack_hint()` will need to call `show_object_pack_hint()`. 

Currently, `show_commit_pack_hint()` is a no-op function (as commits don't have namehashes), but the reordering minimizes code movement in an upcoming patch that will add this call relationship. The change comes with Elijah Newren's suggestion and maintains the series' careful attention to code organization.

While this change doesn't affect functionality on its own, it's part of the larger effort to improve pack-objects behavior, particularly around cruft pack inclusion in MIDX during repacking. The series as a whole is in its third iteration with most technical questions resolved, now undergoing final review before real-world testing.
