Bug report documenting email header compatibility issue with `git send-email` and exmail.qq.com servers. Thread originated by windowsair reporting that exmail.qq.com modifies Message-ID headers when using RFC2822-compliant "Message-ID" capitalization (introduced in Git v2.41.0 via commit 647a2bb3ffc0) but leaves them unchanged with the legacy "Message-Id" form. This server-side behavior affects email threading while not being a Git bug per se. The report serves as documentation of this edge case without proposing specific fixes, noting the version boundary (v2.41.0+) where the standardized header format was introduced. Key technical detail: the header capitalization change from "Message-Id" to "Message-ID" triggers the server behavior, with the commit hash and affected version clearly identified for future reference. No proposed solutions or workarounds are included - the email primarily establishes the compatibility observation for archival purposes.
