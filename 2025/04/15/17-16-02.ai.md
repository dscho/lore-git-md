Platform compatibility fix for meson build system.

Ramsay Jones reports a build failure when using meson on the 'seen' branch at commit 916e0fb7c0. The error occurs because the 'target_shell' variable is undefined after a merge dropped the 'find_program()' call that previously set it. This affects the build configuration step, specifically failing at line 769 of meson.build where it tries to reference the missing variable.

The email includes a simple diff that fixes the issue by restoring the 'target_shell' variable assignment, using 'sh' as the target shell program. The fix follows the same pattern as other program lookups in the meson.build file, searching the program path and marking it as non-native (unlike the 'sh' lookup earlier in the file which is marked as native).

This appears to be an accidental regression introduced by the merge of the 'ps/meson-build-perf-bench' branch. The fix is straightforward and correctly follows the existing build system conventions. Ramsay notes that with this change, compilation proceeds, though test results are still pending at the time of writing. The issue is specific to meson builds and doesn't affect other build systems.
