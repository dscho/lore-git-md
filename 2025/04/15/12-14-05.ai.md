Refactoring patch converting parse-options initializations to use designated initializers. This is the first of five patches in Patrick Steinhardt's v2 series hardening integer handling in Git's parse-options infrastructure.

The patch systematically converts all manual struct initializations in parse-options calls to use designated initializers (field.name = value syntax) rather than positional initialization. This affects 24 files across Git's codebase, with changes to commands like `git commit`, `git merge`, `git grep`, and many others. The conversion provides several benefits: clearer code by naming fields explicitly, easier maintenance when structs change (no need to update every callsite), and the ability to skip default-initialized fields.

The changes are mechanical but extensive, touching core command implementations. Each conversion preserves the exact same runtime behavior while making the initialization more robust against future changes to the option struct. The patch maintains all existing option behaviors, callbacks, and flags - it only changes the initialization syntax.

This foundational refactoring enables the subsequent patches in the series which introduce stricter integer handling, as the designated initializers make it easier to add new fields and validation. The changes align with Git's ongoing code modernization efforts while being strictly behavior-preserving.
