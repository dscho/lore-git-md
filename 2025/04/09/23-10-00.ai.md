This is a "What's cooking" status update from Junio C Hamano, summarizing the current state of various Git development topics. The report covers both newly introduced topics and updates to ongoing work.

The new topics include several performance optimizations and code cleanups: kn/bundle-dedup-optim improves bundle creation performance for repositories with many refs, ps/object-file-cleanup continues the object store refactoring work, and ps/refname-avail-check-optim fixes a BUG() when handling UTF-8 refs. The kn/meson-hdr-check topic adds header checking support to meson builds, while rj/build-tweaks makes various platform-specific build improvements including CSPRNG selection.

Several existing topics have progressed: pb/status-rebase-fixes (status display during rebase) and ua/update-update-server-info (code simplification) are now ready for merging to 'next'. The en/merge-recursive-debug topic has completed the removal of the old recursive merge strategy in favor of ort. The jk/fetch-follow-remote-head-fix series has grown to better handle remote HEAD updates during fetch.

The report indicates most of these topics are either ready for merging to 'next' or awaiting final minor revisions. The changes span performance, refactoring, build system improvements, and bug fixes, with particular focus on the ongoing object store cleanup work and meson build system support.
