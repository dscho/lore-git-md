This is part 3 of a 4-patch series implementing header checking in meson build system, matching Makefile's 'hdr-check' functionality. The series has already addressed naming consistency and build system hygiene in previous iterations.

The patch adds the core implementation of header checking to meson.build, creating custom targets that verify each header can compile independently after including git-compat-util.h. It handles several technical aspects:

1. Defines lists of generated files (command-list.h, etc.) and platform-specific exclusions (compat/ files, test headers, etc.)
2. Conditionally excludes crypto backend headers based on build configuration
3. For each header, creates two custom targets:
   - hcc: generates a minimal C file including the header
   - hco: attempts to compile that file with proper include paths
4. Groups all header check targets under 'hdr-check' alias

The implementation carefully mirrors the Makefile behavior while using meson idioms:
- Uses meson's custom_target() for build steps
- Handles path resolution with project_source_root()
- Maintains identical exclusion patterns to Makefile
- Preserves conditional crypto backend exclusions

This represents the technical core of the feature, following the design consensus established in earlier thread exchanges about naming and scope. The patch shows thorough attention to matching Makefile behavior while using meson's native constructs.
