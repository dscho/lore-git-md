This is a naming refinement in the ongoing meson build system header checking implementation thread.

Junio C Hamano responds to Phillip Wood's suggestion about target naming in Karthik Nayak's patch series. The original patch proposed adding 'headers-check' as an alias for the existing 'hdr-check' target used for verifying header compilability. Phillip Wood had suggested instead using 'check-headers' to better align with existing Makefile conventions (like check-docs, check-pot).

Junio strongly endorses Phillip's proposal, emphasizing the importance of getting the naming right in a single change rather than needing further adjustments later. This moves the thread closer to resolution on the final naming question that had been one of the open items in the discussion.

The technical implementation details (dual target support, deprecation path, etc.) remain unchanged from previous patches - this exchange purely focuses on the target naming convention. With Junio's approval of 'check-headers', this likely settles the last major naming question in the series, leaving only minor style refinements noted in earlier reviews.
