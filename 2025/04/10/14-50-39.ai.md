This is a build system patch adding header-checking support to meson, part of Karthik Nayak's series to bring feature parity between meson and Makefile builds. The patch implements the 'hdr-check' target in meson that verifies each header can compile independently after including git-compat-util.h.

Phillip Wood provides review feedback on the implementation, noting several potential improvements: suggesting "generated_headers" would be a more natural variable name matching existing conventions, questioning the need for manual maintenance of the exclusion list when the Makefile uses path-based filtering, pointing out minor style issues with long lines and unnecessary echo -n usage, and asking why certain include paths are needed in meson but not the Makefile equivalent.

The technical implementation follows the Makefile's two-stage process (generate test file then compile it) and handles the same exclusions for platform-specific headers and crypto backends. The review focuses on build system hygiene and consistency rather than fundamental design issues, suggesting the core approach is sound but could be refined in implementation details. This continues the thread's pattern of careful attention to maintain consistency between build systems while improving internal organization.
