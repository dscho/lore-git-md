Build system refactoring to prevent variable scope pollution in meson builds.

This patch is the first in Karthik Nayak's v2 series implementing header checking in meson builds. It addresses a specific technical issue where variables defined in contrib/coccinelle/meson.build (`sources` and `headers`) were polluting the top-level meson namespace due to meson's variable scoping rules. The solution renames these to `coccinelle_sources` and `coccinelle_headers` to make their scope explicit and prevent potential naming collisions in the build system.

The changes are straightforward and mechanical - each variable reference is updated consistently throughout the file, including in the custom target definitions. The patch also standardizes on `[]` for empty list initialization to match other meson.build files. This is purely a build system internal change with no impact on the resulting binaries or functionality.

This work is part of the broader effort to bring meson build system feature completeness with the traditional Makefile system, specifically around header checking capabilities. The thread context shows this series has already gone through review iterations and reached consensus on the approach.
