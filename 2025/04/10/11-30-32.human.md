This is a refactoring patch in Karthik Nayak's series to implement header checking in meson builds. It moves header definitions from the coccinelle-specific meson.build file to the root meson.build, improving build system organization.

The patch relocates two key definitions: the list of headers to analyze (`coccinelle_headers`, now renamed to just `headers`) and the exclusions list (`third_party_sources`). This centralization serves two purposes: it makes these definitions available for upcoming header checking functionality, and it better reflects their role as project-wide build configuration rather than coccinelle-specific settings.

The changes maintain identical functionality while cleaning up the build system structure. The coccinelle build now references the centralized headers list rather than maintaining its own copy, with the path prefixing (which is coccinelle-specific) remaining in the contrib directory. This is part of a broader effort to align meson build capabilities with the Makefile's 'hdr-check' feature, as established in the thread's earlier discussion.
