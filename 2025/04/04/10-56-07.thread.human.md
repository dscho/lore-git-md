This thread addresses a bugfix for Git's performance test infrastructure. The patch corrects an issue where runtime `GIT_PERF_*` environment variable settings were being unintentionally overwritten by values recorded during compilation in `GIT-BUILD-OPTIONS`. This regression was introduced by commit 4638e8806e3a, which changed how these variables were handled.

The solution involves carefully preserving runtime environment settings by stashing them before sourcing `test-lib.sh` and restoring them afterward, with special handling to escape values safely. While this fix specifically targets performance test variables, the commit message notes that similar issues likely exist for `GIT_TEST_*` variables and may need addressing in future patches. The change is motivated by real-world use cases where users need to override these settings when benchmarking large repositories.
