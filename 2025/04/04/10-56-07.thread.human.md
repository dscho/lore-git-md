Jeff King's analysis confirmed the regression stems purely from this incorrect ordering - the code now sources build configuration before stashing the variables when it should do the opposite. Junio Hamano has acknowledged this explanation. While the immediate solution is straightforward (restore the correct operation sequence), both King and the maintainer recognize this as symptomatic of deeper issues in how Git's test framework handles variable interactions between build-time and runtime environments.
