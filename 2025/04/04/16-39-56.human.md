This is a documentation patch in a series modernizing Git's man pages. Martin Ågren reports a regression in the Asciidoctor toolchain changes from patch 2/5, where extra spaces appear in rendered output (e.g., "bundle.*  keys" with two spaces after the asterisk). The patch intended to fix handling of backslashes and stars in command synopses, but appears to have introduced unintended formatting artifacts.

The issue is specific to the Ruby extensions that process AsciiDoc markup, with changes focused on regular expressions that match special characters. Martin notes the problem occurs with Asciidoctor 2.0.18 but hasn't analyzed the regex patterns in depth. This feedback comes after reviewing the first patch in the series, which had already identified a missing backtick issue.

The series as a whole is converting `git-reset`, `git-rm`, and `git-mv` documentation to use modern AsciiDoc features, with this particular issue affecting the toolchain that processes special characters in command syntax. While the changes are mechanical and well-intentioned, this regression suggests the regex modifications need refinement to maintain proper spacing in the rendered output.
