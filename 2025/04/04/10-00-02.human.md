Bugfix follow-up in refs optimization series addressing UTF-8 comparison issue. 

Patrick Steinhardt confirms and reproduces a bug reported by Elijah Newren where the packed-ref iterator fails when encountering Unicode branch names (specifically emoji characters). The issue occurs during ref iteration when comparing UTF-8 characters in the packed-ref backend, causing a BUG() assertion when fetching from repositories containing such refnames.

The bug was discovered in patch 14/16 of the performance optimization series for the refs subsystem, which introduced seeking capability for packed-ref iterators. While the core optimizations remain valid, this edge case requires fixing before the series can proceed. Steinhardt provides a minimal reproduction case using a test branch name containing the Unicode character "".

This appears to be a straightforward but important fix - the current implementation incorrectly uses signed char comparison for what should be unsigned byte comparison when checking refname prefixes. The fix will likely be small but necessary for proper Unicode support, especially as emoji branch names become more common. The series maintainers had already been discussing whether to add Unicode test cases, making this discovery timely.
