This is a bugfix for the Bash prompt functionality in `git-prompt.sh`. The patch addresses an issue where the command line would wrap prematurely when using Git's Bash prompt due to incorrect escaping of control characters.

The problem stems from how `\001` and `\002` (used as delimiters for prompt sequences) were being handled. These were being interpreted as binary values rather than literal strings, causing display issues. The fix properly escapes these sequences with an additional backslash, ensuring they're treated as intended.

The change is minimal but important - it modifies just two files: the main prompt script and its test file. The test updates show the same fix being applied to color code definitions, maintaining consistency. While small, this appears to be a well-targeted fix for a real usability issue in Bash prompt display.
