This is a portability fix for Git's performance benchmark infrastructure as part of the ongoing Meson build system integration. The patch ensures Perl scripts used in benchmarks work correctly on systems where Perl isn't installed in the standard `/usr/bin/perl` location.

The change modifies three files to use the configured `PERL_PATH` variable (set during build configuration) rather than assuming a fixed Perl location. It also updates the shebang line in `aggregate.perl` to use the more portable `/usr/bin/env perl` approach. This addresses issues that would occur on systems like NixOS with non-standard Perl installations.

As part of Patrick Steinhardt's v5 series for Meson benchmark support, this is a straightforward but important technical improvement that maintains compatibility with existing test infrastructure while making the benchmarks more portable. The changes are minimal and focused, touching only the necessary Perl script invocations without introducing new complexity.
