This is the fifth version of a series integrating Git's performance tests with the Meson build system, focusing on benchmark support. The series builds on previous work that established core functionality and now adds final user-facing controls and documentation clarifications.

The v5 iteration makes one key clarification in the documentation - explicitly stating that benchmarks run serially (unlike tests which run in parallel by default). This addresses a potential point of confusion that wasn't fully clear in earlier versions. The series maintains all previously implemented functionality including the `benchmarks` feature option (auto/enabled/disabled states), benchmark repository path configuration, Perl dependency handling, and status reporting in Meson summary.

Technical implementation details remain consistent with v4: repository format preservation (SHA256/reftable), Perl script portability improvements, out-of-tree build support via GIT_BUILD_DIR, and wiring of 47 benchmark tests via Meson's benchmark() function. The configuration options (benchmark_repo, benchmark_large_repo, benchmark_repeat_count) are still written to GIT-BUILD-OPTIONS as before.

The patch series appears complete and well-polished, with each version addressing feedback from previous rounds. The documentation now clearly differentiates between test and benchmark execution behavior, removing any ambiguity. The implementation maintains compatibility with complex benchmarking scenarios that still require the original t/perf/run script while providing a simpler Meson-based interface for basic use cases.
