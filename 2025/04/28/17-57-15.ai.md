This is a feature patch adding configurability to the Outlook Message-ID handling in `git send-email`, building on the core solution already queued for integration. The patch implements the tri-state configuration option (`--smtp-outlook-id-tweak=always|never|auto`) that was discussed in the thread, with 'auto' as the default maintaining the existing hostname-based detection for standard Outlook SMTP servers.

The changes modify the `is_outlook()` helper function to respect the new configuration, allowing enterprise users with custom domains to force-enable the workaround while maintaining backward compatibility. Documentation clearly explains the three modes with appropriate warnings about using 'always' mode only Microsoft-hosted services. The implementation follows Junio Hamano's feedback to use string values rather than booleans for clearer configuration.
