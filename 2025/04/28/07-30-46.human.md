This is a bugfix patch in the ongoing series to integrate Git's performance benchmarks with the Meson build system. The patch addresses an issue where benchmark tests could fail when run against repositories using alternate formats (SHA256 object format or reftable ref format).

The problem occurs because the benchmark setup code copies repository contents but intentionally skips copying the config file to avoid performance impacts from stray configuration. However, this means repository format information is lost, causing failures for non-default formats. The fix extracts the reference and object formats from the source repository and passes them explicitly to `git init`.

This is the first of five patches in v5 of the series, which as noted in the thread context is focused on final documentation polish. The implementation here is straightforward - just a few lines added to read and pass through the format settings. The change maintains the security benefit of not copying the full config while fixing the format compatibility issue.

The patch appears well-considered and addresses a clear technical gap in the benchmark infrastructure. Since this is part of a mature series that has seen multiple rounds of review, and given the focused nature of the change, it seems unlikely to be controversial.
