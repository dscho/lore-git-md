CI configuration patch aligning GitLab CI behavior with GitHub Actions for MSVC Meson builds. This is a follow-up to Patrick Steinhardt's earlier patch that introduced MSVC Meson CI testing but left the GitLab job as manual-only while GitHub ran it automatically.

The change removes the `when: manual` directive from GitLab's `test:msvc-meson` job, making it run by default like its GitHub counterpart. Johannes Schindelin acknowledges the rationale - preventing GitLab-specific breakages from being missed - though expresses broader concerns about CI resource usage, noting Git's test suite may have redundant coverage.

The one-line change appears straightforward and uncontroversial, building on prior work to modernize Git's build system testing. While Schindelin questions the efficiency of Git's overall CI approach, he doesn't object to this specific alignment between the two CI systems.
