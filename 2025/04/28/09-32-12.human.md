This is a CI/build system patch that makes the MSVC-based Meson build job run automatically on GitLab CI, matching the behavior already present on GitHub Workflows. 

Patrick Steinhardt notes that currently this job requires manual triggering on GitLab CI, which means platform-specific breakages might go unnoticed by developers who primarily use GitHub. The change simply deletes the `when: manual` line from the GitLab CI configuration, making the job run by default like its GitHub counterpart.

The patch is minimal (a one-line deletion) and appears well-motivated - it closes a gap between two CI systems that should ideally provide consistent coverage. A test run was already performed via GitLab's merge request system, suggesting this change has been verified to work as intended. This seems like a straightforward improvement to the project's continuous integration setup.
