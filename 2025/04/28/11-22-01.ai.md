Follow-up question about SSL backend configuration in resolved Git for Windows/Norton issue

This is a brief technical follow-up in the now-resolved thread about Norton Antivirus interference with Git for Windows' certificate verification. Johannes Schindelin asks one final diagnostic question to confirm whether the affected system was using Secure Channel (schannel) or OpenSSL as its HTTPS backend, directing the user to check the `install-options.txt` file. The question appears aimed at satisfying technical curiosity now that the root cause (Norton's Safe Web feature blocking schannel access to Let's Encrypt certificates) and solution (disabling Safe Web) are established.

Key technical details preserved for future reference: the distinction between WinSSL (schannel) and OpenSSL backends in Git for Windows installations, with the configuration stored in `C:\Program Files\Git\etc\install-options.txt` under "CURL option". The thread remains effectively closed, with this being a minor post-resolution clarification rather than reopening the investigation.
