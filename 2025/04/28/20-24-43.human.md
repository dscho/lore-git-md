This is a test infrastructure patch adding a new helper tool for creating packfiles with specific delta structures. It's part of a series fixing `git index-pack`'s incorrect cycle detection in REF_DELTA chains.

Derrick Stolee introduces `test-tool pack-deltas`, which allows tests to precisely control packfile delta structures rather than relying on `git pack-objects`'s compression heuristics. The tool reads instructions from stdin specifying objects and their delta relationships, currently supporting only REF_DELTAs (the type needed for the bug being fixed). Each line specifies an object type ("REF_DELTA"), content OID, and base OID.

The implementation handles packfile creation with proper headers, compression, and hashing. While currently limited to REF_DELTAs, the design anticipates future support for OFS_DELTAs and FULL objects. The tool uses Git's standard `parse_options()` interface with a required `--num-objects` parameter (a v2 change from the original positional argument based on prior discussion).

This helper will be used in subsequent patches to create test cases demonstrating the `index-pack` bug where valid REF_DELTA chains were incorrectly flagged as cycles when intermediate objects existed locally. The clean implementation follows Git's test helper conventions and provides a foundation for more precise packfile testing.
