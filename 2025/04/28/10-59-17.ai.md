CI / build system patch adjusting GitLab CI behavior for MSVC Meson builds. This is a follow-up to Patrick Steinhardt's patch that makes the MSVC Meson build job run automatically on GitLab CI, matching GitHub's behavior. The change removes the `when: manual` directive from the `test:msvc-meson` job while keeping its 6h timeout and build dependency.

Johannes Schindelin agrees with the rationale that manual triggering could miss GitLab-specific breakages, though he expresses broader concerns about CI resource usage and test redundancy in Git's infrastructure. The patch itself is straightforward - a one-line removal in `.gitlab-ci.yml` - and references a successful test run [2] and prior discussion [1].

The change builds on commit 7304bd2bc39 which originally introduced MSVC Meson support. While the technical change is simple, Johannes' comment about CI efficiency suggests this might spark wider discussion about optimizing Git's test infrastructure, though no concrete objections are raised to this particular patch. The thread shows alignment on making test coverage consistent across CI platforms, even if opinions differ on broader CI strategy.
