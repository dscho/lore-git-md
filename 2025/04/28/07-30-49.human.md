Performance feature for Meson build system integration. This patch wires up Git's performance benchmarks (47 tests from `t/perf/`) to work with Meson builds, completing the benchmark support that was previously only available via Make. The implementation uses Meson's `benchmark()` function which provides special handling: benchmarks run serially (never in parallel), aren't executed by default with regular tests, and avoid memory perturbation instrumentation.

The patch adds documentation showing how to run benchmarks via `meson test --benchmark` and maintains compatibility with the existing `t/perf/run` script for advanced use cases like cross-version comparisons. It requires Perl and GNU time when benchmarks are enabled, and properly integrates with the build system's dependency tracking.

This is part of Patrick Steinhardt's v5 series to fully integrate Git's test infrastructure with Meson. The implementation looks thorough, preserving all existing benchmark functionality while adapting it to Meson's conventions. The only noted limitation is that Meson benchmarks only work for the current build, leaving `t/perf/run` as the tool for more complex benchmarking scenarios.
