This is a UI consistency patch for gitk, part of a 3-patch series improving Tk interface behavior. The change replaces direct combobox widget creation with a `makedroplist` helper function for text wrapping preferences, ensuring consistent behavior whether gitk is running with themed or unthemed Tk widgets. The modification affects two settings in the general preferences panel: comment text wrapping and other text wrapping, both of which now use the same widget factory approach. The patch appears straightforward, replacing two nearly identical widget instantiations with the helper call. This is a small but meaningful quality-of-life improvement that helps maintain UI consistency across different Tk configurations. The change aligns with the series' goal of making gitk's interface more reliable regardless of theming choices.
