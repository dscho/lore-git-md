This is a test infrastructure patch introducing a new helper tool for creating packfiles with specific delta structures, part of a bugfix series addressing `git index-pack`'s incorrect cycle detection.

The patch adds `test-tool pack-deltas`, a 148-line C program that generates packfiles with precisely controlled delta relationships. Currently it only implements REF_DELTAs (needed for the immediate bugfix), though the interface is designed to potentially support OFS_DELTAs and full objects later. The tool reads instructions from stdin specifying object types and relationships, then writes a packfile to stdout.

Key technical details:
- Uses Git's standard `parse_options()` for CLI argument handling (accepting `--num-objects`)
- Implements packfile writing via `hashfile` API
- Handles delta generation and compression using Git's existing delta and zlib infrastructure
- Reads object contents via `repo_read_object_file()`
- Maintains compatibility with the_repository while the global is still in use

The tool is designed to replace manual packfile construction in tests (previously done via opaque scripts in t/lib-pack.sh), making it easier to create targeted test cases for packfile parsing edge cases. This first version focuses on the immediate need for testing REF_DELTA chain handling, but leaves the door open for future extensions to test other packfile scenarios.

The implementation follows Git's test helper conventions and integrates cleanly with the build system (Makefile and meson). As part of the larger series fixing `index-pack` cycle detection, this provides the necessary test infrastructure to verify both the bug and its fix.
