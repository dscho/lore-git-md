This is a performance-related patch in the ongoing Meson build system integration series, specifically wiring up Git's benchmark infrastructure.

The patch adds Meson support for running Git's performance benchmarks (47 tests from t/perf/) through Meson's `benchmark()` function. Key technical details include:

- Benchmarks are treated differently than regular tests: they never run in parallel, aren't executed by default with tests, and avoid `MALLOC_PERTURB` environment variable injection
- Requires Perl and GNU time (USR_BIN_TIME) as prerequisites
- Uses Meson's benchmark() function with similar wiring to existing test infrastructure
- Maintains compatibility with the existing t/perf/run script for complex benchmarking scenarios
- Adds a new 'benchmarks' meson option (auto/enabled/disabled)
- Includes documentation updates showing benchmark execution syntax
- Preserves all existing benchmark functionality while adding Meson support

The implementation handles path resolution for benchmark dependencies and maintains the same environment setup as tests. The patch explicitly notes limitations - Meson benchmark support is for current-build-only comparisons, while cross-version comparisons still require t/perf/run.
