This is a test infrastructure patch in a series converting reftable tests to the Clar framework. Junio C Hamano reports build failures when applying just the first patch of the 9-part series, noting that `t-reftable-merged.c` fails to find the now-renamed helper function `t_reftable_write_to_buf` (which the patch changes to `cl_reftable_write_to_buf`).

The issue arises because this initial patch updates the helper library but not yet the test files that depend on it - a classic incremental conversion problem where intermediate states don't build cleanly. The series appears designed to be applied atomically (all 9 patches at once), but Junio is testing the first patch in isolation, revealing this dependency chain.

Key technical points:
- Patch renames helper functions from `t_` to `cl_` prefix in `lib-reftable.{c,h}`
- Updates build system references (Makefile and meson.build)
- Changes function signatures to match Clar framework conventions
- Leaves test files unconverted at this stage, causing the reported build failures

This is expected behavior for the series structure - the conversion must be completed across all patches to maintain buildability. The error confirms the helper function renaming is working as intended, just not yet propagated to all callers. The full series will resolve this by converting all test files to use the new Clar-based helpers.
