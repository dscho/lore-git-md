This is a bugfix for the git-prompt.sh Bash completion script. The patch addresses an issue where command line wrapping occurs prematurely when using the prompt due to incorrect escaping of control characters.

The root cause is that the SOH (start of heading) and STX (start of text) control characters (represented as \001 and \002) were not properly escaped in the script. This caused the shell to interpret them as binary values rather than literal strings, leading to incorrect prompt rendering behavior. The fix adds proper escaping (\\001 and \\002) to ensure these control characters are treated as intended.

The changes affect both the main git-prompt.sh script and its test file t/t9903-bash-prompt.sh, updating all instances where these control characters are used for color formatting. The test modifications suggest this was caught through the existing test suite, though the commit message doesn't explicitly mention test verification.
