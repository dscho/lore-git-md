This is the third and final patch in a series improving gitk's Tk interface, specifically focusing on themed Tk (TTk) usability. The patch adds visible sash handles between panes when using themed Tk, addressing discoverability issues for window resizing.

The change introduces custom bitmap images for vertical and horizontal sashes, using gitk's existing `uicolor` variable for consistency with the interface. The patch creates new Tk::style elements and layouts for these sashes, ensuring they appear in themed environments where they would otherwise be invisible. A new `createttkimages` procedure generates the sash graphics, while `setui_dialog` ensures color changes propagate to the sashes. The implementation carefully preserves the existing behavior for non-themed Tk while adding the new functionality for themed environments.

This completes the series' goal of improving gitk's theming support, following the earlier patches that unified text wrapping preferences and fixed color handling. The change is well-contained, touching only gitk's Tk-specific code with clear bitmap data and style definitions. The use of existing color variables maintains consistency with gitk's theming system while solving a real usability issue in themed environments.
