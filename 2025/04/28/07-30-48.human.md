This is a platform compatibility patch in Patrick Steinhardt's series to integrate Git's performance benchmarks with the Meson build system. It fixes an issue where benchmark scripts failed when run from out-of-tree build directories (common with Meson and CMake builds).

The patch modifies `t/perf/perf-lib.sh` to properly locate the build directory in two scenarios: when using Make (where build and source directories are the same) and when using Meson (where they can differ, requiring a `GIT_BUILD_DIR` environment variable). It also adds Windows path handling and ensures the benchmark aggregation script is found correctly.

This is the third patch in a 5-part series that has been through several iterations.
