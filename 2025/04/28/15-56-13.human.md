This is the third and final patch in a series improving gitk's Tk interface, focusing on themed Tk (TTk) usability. The patch adds visible sash handles between panes when using themed Tk, addressing a discoverability issue where users couldn't easily see where to click to resize window panes. 

The change creates custom bitmap images for vertical and horizontal sashes, using gitk's existing uicolor` setting for consistency with the interface. The color can be adjusted via gitk's preferences dialog, allowing users to control how prominent the sashes appear. The implementation adds new procedures `createttkimages` and modifies `setttkstyle` to handle the sash creation and styling.

 

This completes the series' goal of improving gitk's themed interface, following earlier patches that refactored text wrapping preferences and fixed color scheme handling. The change is well-contained and maintains backward compatibility with unthemed Tk. While a small visual enhancement, it meaningfully improves usability by making the pane resizing functionality more discoverable in themed mode.
