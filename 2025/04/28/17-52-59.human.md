This is the final patch in Aditya Garg's series addressing Outlook SMTP Message-ID handling in `git send-email`. The core solution (queued in v6) automatically detects standard Outlook SMTP hosts, while this v7 patch adds enterprise configurability through a new `--smtp-outlook-id-tweak` option with three modes: 'auto' (default, works like v6), 'always' (force Outlook behavior for custom domains), and 'never' (disable entirely).

The implementation is clean - a 14-line documentation addition and 14-line code change that modifies the existing `is_outlook()` helper to respect the new configuration. The patch maintains backward compatibility and follows Junio Hamano's suggestion to use string values ('always'/'never'/'auto') rather than numeric codes for clarity.

This completes the technical solution for Outlook's non-standard Message-ID behavior, with all prior feedback incorporated. The only remaining items are final documentation polish and distribution of the dependent Authen-SASL 2.1800 release containing OAuth2 support. The patch appears ready for inclusion, providing a flexible solution that handles both standard Outlook and enterprise configurations.
