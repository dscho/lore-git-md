This is the final patch in Patrick Steinhardt's series integrating Git's benchmark infrastructure with Meson. It wires up user-configurable benchmark options that get written to GIT-BUILD-OPTIONS.

The patch exposes three key benchmark configuration options through Meson:
- `benchmark_repo` - specifies the repository to copy for standard performance tests (should be at least Git repo size)
- `benchmark_large_repo` - specifies a larger repository for scaling tests (Linux repo size recommended)
- `benchmark_repeat_count` - sets the number of test repetitions (defaults to 3)

The implementation handles these options differently from the Makefile build - it explicitly excludes `GIT_PERF_MAKE_COMMAND` and `GIT_PERF_MAKE_OPTS` since those are only used by the legacy `t/perf/run` script that Meson doesn't use. The patch modifies `meson.build` to properly quote the string values when writing them to GIT-BUILD-OPTIONS.

This completes the technical implementation of the benchmark support in Meson, following earlier patches that added core functionality, fixed repository format preservation, improved Perl script portability, and added out-of-tree build support. The series appears ready for integration with all documented functionality now implemented.
