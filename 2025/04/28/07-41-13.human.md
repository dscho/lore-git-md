This is a workflow suggestion in response to a bisect+testing question. Christian Couder proposes using `git worktree` as a cleaner solution for maintaining stable test files during a bisect operation, where the test files live in a different branch than the one being bisected.

The suggestion addresses Victor Engmark's problem of manually extracting test files at each bisect step. Couder's approach would create a separate worktree containing the unchanging test files from `my-test-branch`, while the main worktree performs the bisect. The test files could then be copied over in bulk with `cp -a` rather than individual `git show` commands.

Couder notes this is conceptually more of a build system responsibility than a Git SCM concern, suggesting the solution might better belong in test infrastructure rather than core Git functionality. The response is brief but points to a potentially more maintainable approach than the current manual file management.
