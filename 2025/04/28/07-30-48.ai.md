This is a platform compatibility fix in the ongoing Meson benchmark integration series. The patch addresses out-of-tree build support for Git's performance test infrastructure (`t/perf`).

The key technical changes:
- Modifies `perf-lib.sh` to properly locate the build directory when running benchmarks under Meson/CMake (via new `GIT_BUILD_DIR` environment variable)
- Maintains backward compatibility with Makefile builds by falling back to source directory when `GIT_BUILD_DIR` isn't set
- Adds Windows path handling for the build directory location
- Updates the Perl` aggregate script path to use `GIT_SOURCE_DIR` for proper script location
- Preserves all existing benchmark functionality while adding the new build system support

The implementation handles several edge cases:
- Build directory detection via `GIT-BUILD-DIR` file when present
- Windows path conversion for MinGW environments
- Fallback paths for traditional Makefile builds
- Proper script path resolution for the performance aggregation step

This is part of the v5 series that has already addressed repository format preservation and documentation concerns. The change is a prerequisite for the final Meson benchmark wiring that will follow in later patches. No new functionality is introduced - this purely enables the existing benchmark infrastructure to work correctly with non-Make build systems.
