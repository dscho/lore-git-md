This is the fifth version of a series integrating Git's performance benchmarks with the Meson build system, building on previous work that established core functionality. The series now focuses on final user-facing controls and documentation clarifications.

Patrick Steinhardt's v5 patch set maintains all previously implemented benchmark support while adding explicit documentation that benchmarks run serially (unlike tests which run in parallel by default). The series introduces a 'benchmarks' feature option with auto/enabled/disabled states, reports benchmark status in Meson's summary output, and properly declares Perl as a dependency. The implementation preserves repository formats (SHA256/reftable) and supports out-of-tree builds.

The changes since v4 are minimal - primarily clarifying benchmark execution behavior in documentation. The series remains non-disruptive, keeping the more advanced `t/perf/run` script as the recommended tool for complex benchmarking scenarios. With all technical aspects now clearly covered and documentation concerns addressed, this appears ready for final review. The implementation cleanly handles 47 existing benchmark tests while providing appropriate controls for developers.
