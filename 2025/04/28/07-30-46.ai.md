This is a bugfix patch in the performance benchmark infrastructure series, addressing repository format preservation in benchmark tests. The patch ensures benchmarks correctly handle repositories with alternate formats (SHA256 object format and reftable ref format) when copying test repositories.

The issue occurs when benchmarks copy a repository but skip copying its configuration to avoid performance impacts from unintended config settings. However, this also skips critical repository format information, causing failures with non-default formats. The fix extracts the reference and object formats from the source repository and passes them explicitly to `git init` when creating the benchmark copy.

Key technical details:
- Adds `--show-ref-format` and `--show-object-format` calls to extract formats from source repo
- Passes formats via new `--ref-format` and `--object-format` flags to `git init`
- Modifies `t/perf/perf-lib.sh` with 3-line addition and 1-line modification
- Maintains all existing behavior (skipping hooks, config) while fixing format preservation
