Feature suggestion for branch creation behavior. This is a user experience proposal suggesting that Git should warn users when creating a local branch with `git branch` if a same-named remote branch already exists, offering to set up tracking. The author encountered this when accidentally creating an untracked local branch when they meant to check out an existing remote branch, leading to confusion. The proposed solution would add an interactive prompt suggesting to connect the new local branch to its remote counterpart.
