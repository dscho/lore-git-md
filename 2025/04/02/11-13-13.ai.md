Technical response addressing callback parameter typing in Git cat-file batch filtering.

This email from Patrick Steinhardt responds to Toon Claes's question about the typeless `_payload` parameter in the `batch_each_object()` function from the cat-file batch filtering series. He provides concrete examples showing the function is called with two distinct payload types in the current implementation: `struct object_cb_data` and `struct oid_array`. This demonstrates the need for type flexibility in the callback infrastructure.
