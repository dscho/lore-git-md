This is a refactoring patch in the Git cat-file batch mode filtering enhancement series (v3 7/11). The patch updates the callback type definition in pack-bitmap.h and adjusts all implementations across the codebase (pack-objects.c, rev-list.c, pack-bitmap.c, reachable.c) to match the new signature. Each callsite currently passes NULL for the payload, maintaining existing behavior while enabling future extensions. The changes are mechanical and focused on the commit message clearly states this is groundwork for a subsequent change (likely related to the filtering functionality being developed in this series).
