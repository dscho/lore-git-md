Feature enhancement for `git cat-file`'s batch mode filtering, specifically implementing the "blob:none" object filter. This is part 4/11 of the v3 series that was later finalized in v6.

The patch adds support for the `--filter=blob:none` option to `git cat-file`, which causes the command to omit all blob objects from its output. The implementation requires careful handling of object type information since the filter needs to know object types but the batch mode tries to avoid reading objects when possible. The solution involves conditionally setting the type pointer when filters are active.

Key technical details include:
- Modifies `batch_object_write()` to check for blob objects when the blob:none filter is active
- Adds validation to ensure filters are only used in batch mode
- Extends the test suite with comprehensive coverage including:
  - Verification that filtered output matches `rev-list --filter` results
  - Testing of excluded object reporting
  - Coverage across packed, loose, and bitmap-enabled objects

The implementation builds on the filter infrastructure introduced earlier in the series while maintaining the performance optimizations. The tests demonstrate the filter works correctly across different object storage types (packed with/without bitmaps, loose objects). This was one of the foundational patches in the series that established the filter architecture later expanded in subsequent versions.
