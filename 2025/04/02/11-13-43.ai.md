This is a refactoring patch in the Git cat-file batch mode filtering enhancement series, specifically preparing the bitmap traversal infrastructure for filter integration.

The patch introduces a new public function `for_each_bitmapped_object()` in pack-bitmap.c that allows iterating over bitmapped objects while applying a filter. The function takes a bitmap index, filter options, and payload parameter, then applies the filter to create a filtered bitmap before showing objects of each type (commit, tree, blob, tag) through the provided `show_reach` callback. The implementation preserves the existing behavior when no filter is applied.

Key technical details include:
- The function first checks if filtering is supported via `can_filter_bitmap()`
- Creates an initial all-1 bitmap and filters it down using `filter_bitmap()`
- Iterates through each object type with the filtered results
- Returns -1 for unsupported filters, 0 on success
- Updates `show_objects_for_type()` to accept an explicit bitmap parameter rather than using the global result bitmap
- Adds corresponding declarations to pack-bitmap.h

This builds on the callback infrastructure changes from patch 7/11 in the series, maintaining the payload parameter addition while adding the actual filtering capability. The changes are behavior-preserving when no filter is applied, but set up the plumbing needed to support filtered bitmap traversals in subsequent patches. The implementation carefully handles bitmap allocation and cleanup, with the filtered bitmap being temporary.
