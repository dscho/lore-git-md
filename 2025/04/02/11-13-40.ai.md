Feature enhancement for `git cat-file` adding blob size limits to object filtering.

This patch (v3 05/11) introduces a new `blob:limit=<n>` filter option for `git cat-file --batch mode`, building on the filter infrastructure established in earlier patches. The filter excludes blobs larger than the specified size threshold, with support for byte units (k/m/g suffixes). The implementation:

1. Adds documentation for the man page explaining the new filter syntax and units
2. Extends the batch object processing to:
   - Track blob sizes when the limit filter is active
   - Skip output for blobs exceeding the limit
   - Maintain consistent "excluded" status reporting
3. Includes comprehensive tests covering:
   - Various size thresholds (1, 500, 1000 bytes, 1k)
   - Different storage backends (packed/loose)
   - New test infrastructure with large blob generation

The change integrates with the existing filter architecture from patch 4/11, using the same `list_objects_filter_options` infrastructure and error reporting patterns. It maintains the series' performance focus while adding more granular control over filtered content. The implementation appears clean, with proper type handling and test coverage matching the established pattern for the blob:none filter.
