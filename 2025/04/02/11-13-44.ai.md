This is a preparatory patch in the Git cat-file batch mode filtering enhancement series (v3), introducing infrastructure for bitmap pack checking.

The change adds a new function `bitmap_index_contains_pack()` to the pack-bitmap subsystem that checks whether a given pack is referenced in a bitmap index, either directly or through a multi-pack-index. The implementation handles both regular pack bitmaps and MIDX bitmaps by walking the bitmap chain (to account for layered bitmaps) and comparing pack pointers. The function returns 1 if the pack is found, 0 otherwise.

The patch is part of the larger series that ultimately enables filtering in `git cat-file --batch` mode, though this particular change is focused on the low-level bitmap infrastructure. It's a straightforward addition that will be used by subsequent patches in the series, as noted in the commit message. The implementation includes proper header comments explaining the function's purpose and parameters.

Key technical details for future reference:
- New public function `bitmap_index_contains_pack()` in pack-bitmap.h
- Handles both single-pack and MIDX cases
- Walks bitmap->base chain for layered bitmaps
- Returns boolean result (1/0)
- Will be used by later patches in the series
- Includes documentation in header file
- No behavior changes to existing code paths
