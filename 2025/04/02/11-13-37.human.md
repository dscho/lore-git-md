Refactoring patch in the Git cat-file batch mode filtering series (v3, historical context). This is part 2 of 11 in the v3 series, which was later refined into v6 with all feedback incorporated.

The patch introduces a new helper function `report_object_status()` to consolidate status reporting for objects in `builtin/cat-file.c`. This prepares for upcoming additions that will report on "excluded" objects. The function handles both the status message formatting and the required stdout flushing, which is critical for batch mode's request-response behavior.

The author notes there's a redundant flush in `batch_one_object()` that could theoretically be removed, but keeps it for pragmatic reasons - it's a no-op performance-wise and ensures future callers get the flushing behavior correct by default. The change affects how missing and ambiguous object statuses are reported, but doesn't modify the actual functionality.

This was an early step in the series that established some foundational cleanup before the more substantial filtering functionality was added in later patches. The variable renaming and status reporting improvements from v3 were carried forward into the final v6 version.
