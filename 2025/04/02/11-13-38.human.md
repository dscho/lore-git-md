Performance enhancement for `git cat-file` batch mode with object filtering. This is patch 3/11 in a series that was ultimately resolved in v6, showing the early implementation of object filtering capabilities.

The patch introduces a `--filter` option to `git cat-file`'s batch modes, matching the syntax used by `git rev-list`. Currently, all filter types are rejected (they'll be implemented in later patches), but the infrastructure is now in place. The commit explains that while initial filtering won't speed up operations (since packfiles must still be fully read), future bitmap integration will enable significant performance gains by skipping irrelevant objects entirely.

The implementation touches documentation, core filtering logic in `builtin/cat-file.c`, and adds comprehensive tests. The code handles filter initialization and cleanup properly, with clear error messages for unsupported filters. This appears to be a well-structured foundation for the feature, though the actual performance benefits won't materialize until later in the series.
