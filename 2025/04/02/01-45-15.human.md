Bugfix for column display logic with security implications.

This patch addresses a potential integer underflow issue in Git's column display code that could lead to memory allocation problems or crashes. The problem occurs when the indent length specified for column output is larger than the total width, causing an unsigned underflow in the column calculation. The fix adds an early check to fail gracefully with a clear error message when this invalid input is detected.

The change affects several commands that use column formatting (`git branch`, `git tag`, `git column`), though the security impact appears limited since these options are rarely used in scripts. The patch includes two new tests to verify the error handling works as expected.

Notably, this was initially reviewed by the Git security team who confirmed the issue wasn't critical enough to require private disclosure. The author has incorporated their feedback, replacing a `BUG()` call with `die()` and adding test coverage. The implementation looks solid with clear error messages and maintains existing behavior for valid inputs.
