This is a follow-up discussion in the "Git cat-file batch mode filtering enhancement" series, specifically responding to Karthik Nayak's review comments on patch 02/10. Patrick Steinhardt clarifies several points about the filtering behavior in different batch modes:
1. The filter applies to all batch modes, not just `--batch-all-objects`, though the latter is the primary use case.
2. He identifies a potential issue with `--batch` mode where filtered objects would be silently skipped, which might confuse scripts expecting responses. He proposes treating filtered objects similarly to missing objects by providing explicit output.
3. Agrees to add tests for the `--no-filter` option as suggested by Karthik.

The discussion shows careful consideration of edge cases in the batch filtering implementation, particularly around script interaction patterns. While the core technical questions were resolved in later versions, this exchange reveals the thought process behind some design decisions in the early iterations of the patch series.
