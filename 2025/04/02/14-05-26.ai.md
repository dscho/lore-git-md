This is a build system discussion about shell completion script installation in the meson build system, specifically focusing on path standardization across distributions.

Todd Zullinger responds to Patrick Steinhardt's proposal to avoid excessive configurability for completion script paths, agreeing that if paths are consistent across target systems, making them configurable may be unnecessary. The email confirms Fedora's current paths for bash (`/usr/share/bash-completion/completions`), fish (`/usr/share/fish/vendor_completions.d`), and zsh (`/usr/share/zsh/site-functions`) as reference points, while noting Git currently lacks fish completions entirely.

Key technical details include:
- Fedora's packaging macros for these three shell completion paths
- The absence of fish shell completions in Git
- The observation that path consistency across distributions may make configuration options unnecessary

The discussion continues to favor Steinhardt's approach of starting with sensible defaults (using Fedora's paths as models) and only adding configurability if real-world problems emerge. Zullinger expresses cautious optimism about path consistency across systems while acknowledging exceptions often exist. The exchange maintains focus on practical implementation rather than theoretical edge cases.
