This is a feature patch series introducing object filtering to `git cat-file`'s batch modes, with significant performance improvements when using type filters with bitmaps. The series has evolved through multiple versions (now at v3) with all technical concerns addressed.

The core functionality adds `--filter` support to `git cat-file --batch-all-objects` and related modes, allowing users to efficiently query objects of specific types without scanning the entire packfile. The implementation supports three filter types: `blob:none`, `blob:limit=<size>`, and `object:type=<type>`. When combined with bitmap indices, type filters can achieve dramatic speedups - benchmarks show a 41x improvement for filtering commits in the Chromium repository.

Key technical components include:
- New filtering logic in `builtin/cat-file.c` that integrates with existing batch modes
- Modifications to `pack-bitmap.c` to support filtered bitmap traversal
- Careful handling of edge cases like `--no-filter` and explicit object requests
- Comprehensive test coverage in `t1006-cat-file.sh`

The series has been through rigorous review, with all feedback from Toon Claes and Karthik Nayak addressed. Notable refinements include:
- Standardizing on `OPT_PARSE_LIST_OBJECTS_FILTER` for option parsing
- Clear documentation of filter behavior across different batch modes
- Explicit handling of filtered objects in `--batch` output
- Additional test cases for edge scenarios

The implementation is technically sound and provides a significant performance optimization for a real-world use case (filtering objects by type in large repositories). The bitmap integration in particular makes this a compelling feature for users working with massive repositories like Chromium.
