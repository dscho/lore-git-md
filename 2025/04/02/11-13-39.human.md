Feature enhancement for `git cat-file`'s batch mode filtering, specifically adding "blob:none" support. This is part 4 of an 11-patch series (v3) that was later finalized in v6.

The patch implements the "blob:none" filter for `git cat-file --batch`, which causes the command to omit all blob objects from its output. The implementation requires careful handling of object type information since the filter needs to know object types but the batch mode tries to avoid reading objects when possible. The solution conditionally sets type information when filters are active.

Key technical points:
- Adds documentation for the new filter
- Modifies `batch_object_write()` to handle blob filtering
- Includes comprehensive tests covering packed/loose objects and verification of excluded object reporting
- Maintains existing performance optimizations while adding filter support

This was part of a well-received series that ultimately achieved 41x performance improvements. The v3 implementation shown here formed the foundation for the final v6 version that addressed all reviewer feedback. The patch demonstrates careful consideration of edge cases and maintains Git's existing behavior patterns while adding new functionality.
