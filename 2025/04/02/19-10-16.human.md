This is a review discussion in Patrick Steinhardt's ongoing series to remove Perl dependencies from Git's test suite. Johannes Schindelin provides feedback on patch 06/20, which introduces a `PERL_TEST_HELPERS` prerequisite for tests requiring Perl.

Schindelin notes two additional Perl dependencies that weren't mentioned in the original patch: `git request-pull` (which uses Perl to parse `ls-remote` output) and `git filter-branch --state-branch`. He suggests these should either be properly marked as requiring Perl or converted to eliminate the dependency entirely, with a joking reference to Elijah Newren's approach of simply removing problematic code.

The review confirms the technical correctness of the `PERL_TEST_HELPERS` implementation after Schindelin spent significant time manually verifying the large patch. While the exchange is positive overall, it highlights how this Perl removal effort continues to uncover additional dependencies beyond the test suite itself. The discussion suggests these peripheral findings may spawn follow-up work to either properly document or eliminate remaining Perl usage in Git's tooling.
