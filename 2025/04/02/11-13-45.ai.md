This is a refactoring patch in the Git cat-file batch mode filtering enhancement series (v3 patch 10/11). It prepares for upcoming bitmap integration by consolidating object iteration logic in `builtin/cat-file.c`.

The patch introduces a new helper function `batch_each_object()` that unifies the loose and packed object iteration paths. Currently this is a simple refactor that replaces two direct function calls with a wrapper, but the commit will extend this to handle bitmap traversal. Key changes include:

1. New callback infrastructure with `for_each_object_fn` type and `for_each_object_payload` struct to standardize the iteration interface
2. Removal of redundant `collect_loose_object` and `collect_packed_object` functions in favor of a unified `collect_object`
3. Elimination of separate `batch_unordered_loose` and `batch_unordered_packed` functions by routing through the new `batch_each_object` helper
4. Preservation of existing behavior through adapter functions `batch_one_object_loose` and `batch_one_object_packed`

The changes are purely structural at this point, maintaining identical functionality while setting up for the bitmap integration that will follow in the next patch. The refactoring affects the core object iteration paths used by both ordered and unordered batch modes in `builtin/cat-file.c`.

This is part of the larger series that introduces filtering capabilities to `git cat-file --batch`, with this particular change being an internal preparation step. The patch follows the series' established pattern of careful refactoring with clear separation of concerns.
