This is a preparatory patch in the Git cat-file batch mode filtering enhancement series (v3). It introduces a new helper function `bitmap_index_contains_pack()` to check whether a given packfile is referenced by a bitmap index, either directly or through a multi-pack-index.

The patch adds a straightforward utility function that will be used in subsequent commits of the series. It handles both regular packfiles and MIDX cases by recursively checking the bitmap's base index. The implementation is clean and well-contained, with proper documentation in the header file.

As part of the larger series that improves `git cat-file --batch` performance with bitmap filtering (demonstrating 41x speedups), this patch represents foundational infrastructure work. The series has already gone through multiple iterations (now at v6) and has addressed all technical concerns from reviewers.
