This is a feature patch adding type-based object filtering to `git cat-file --batch`, part of a larger series enhancing batch mode filtering capabilities. 

The patch introduces a new `object:type=<type>` filter that lets users exclude objects not matching the specified type (blob, commit, tag, or tree). The implementation follows the same pattern as previous filters in the series, using the existing `list_objects_filter_options` infrastructure. 

Key changes include:
- Documentation of the new filter syntax
- Logic to check object types against the filter
- Test cases verifying the filter works for all four object types
- Integration with the batch mode's existing error reporting system

This appears to be a straightforward extension of the filtering framework established in earlier patches (like the blob size filter from patch 5/11). The implementation is clean and maintains consistency with the existing code, adding the new filter type alongside the previously implemented blob filters. The tests cover all object types and follow the same pattern as other filter tests in the suite.

As part of the v3 series, this patch was uncontroversial and formed part of the foundation for the final v6 implementation that was later accepted. The changes here are focused and well-contained, building logically on the filter architecture introduced earlier in the series.
