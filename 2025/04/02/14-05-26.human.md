This is a build system discussion about shell completion script installation in the meson build system, continuing the thread about tcsh completion paths. Todd Zullinger responds to Patrick Steinhardt's proposal to use stable default paths for shell completions rather than making them configurable.

Zullinger agrees with the approach of using consistent paths across distributions when possible, though he's skeptical that all systems will align perfectly. He confirms Fedora's standard paths for bash, fish, and zsh completions (though notes Git doesn't actually have fish completions yet), providing useful reference points for establishing defaults.

The exchange shows growing consensus around Steinhardt's position to start with sensible defaults (likely based on Fedora's paths) and only add configurability if real-world use reveals problems. Zullinger's packaging experience lends weight to this direction while acknowledging the practical reality that some systems may still need special handling. The discussion remains focused and productive, with both contributors working toward a solution that balances standardization with practical needs of different distributions.
