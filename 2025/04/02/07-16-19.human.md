This is a follow-up discussion in Patrick Steinhardt's ongoing series to eliminate Perl dependencies from Git's test suite (now at 20 patches). The exchange focuses on patch 06/20 which introduces a `PERL_TEST_HELPERS` prerequisite for tests requiring Perl.

Johannes Schindelin points out two additional Perl-using components that weren't mentioned in the original patch: `git request-pull` (which uses Perl for parsing) and `git filter-branch` (with its `--state-branch` option). Patrick acknowledges these omissions and considers whether to document them as Perl dependencies or work toward eliminating Perl usage entirely, noting that many conversions would be "low-hanging fruit."

The discussion confirms the technical soundness of the patch, with Schindelin having manually verified the changes (which are too large for easy mailing-list review) and found only expected patterns of prerequisite additions. The exchange shows the series continuing to refine its approach while maintaining positive review momentum, with Patrick incorporating feedback about overlooked Perl dependencies while keeping focus on the test suite conversions.
