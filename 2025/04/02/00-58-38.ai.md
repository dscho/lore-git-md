Contribution to the meson build system thread about shell completion installation paths. Todd Zullinger provides concrete packaging details from Fedora's perspective, adding valuable distribution-specific context to the ongoing discussion about standardizing completion script installation.

The email confirms Fedora currently only packages bash and tcsh completions, with tcsh using a non-standard path (`/usr/share/git-core/contrib/completion/`) that requires manual user configuration. Zullinger notes this setup has remained unchanged since 2013 due to lack of user feedback, suggesting either low tcsh usage or user acceptance of the manual steps. For zsh, Fedora doesn't install Git's completion script at all, likely because upstream zsh already provides completions and there's no consensus on system-wide installation.

Key technical details include Fedora's current completion locations: bash uses `/usr/share/bash-completion/completions`, fish uses `/usr/share/fish/vendor_completions.d`, and zsh (for other packages) uses `/usr/share/zsh/site-functions`. This provides concrete reference points for the meson build system discussion, though Zullinger emphasizes these should be compared with other distributions before establishing defaults.

The email reinforces the need for flexibility in path specification that Akshay Hegde proposed, while providing real-world evidence that completion script installation practices vary significantly between shells even within a single distribution. The historical context about tcsh's manual configuration suggests some shells may not need automatic installation paths as urgently as others.
