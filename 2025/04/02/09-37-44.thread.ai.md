Git 2.50.0 release notes documentation update (patch 1/2). Covers new features, bugfixes, and internal improvements for the upcoming release. Key additions:

Features:
- `git fast-export|import` now properly handle signed objects
- Optimizations for refname availability verification
- Beginning of merge-recursive deprecation
- Protocol v2 ref advertisement behavior improvements
- Build system updates including Meson support changes and enabling -Wunreachable-code for developer builds

Bugfixes:
- Cruft pack refreshing with multiple packs fixed
- xdiff context size handling on 32-bit systems corrected
- Various merge/rename crash scenarios addressed
- Includes numerous smaller merges for code cleanup, documentation fixes, and build improvements from maint
