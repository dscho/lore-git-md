This is the final patch in Patrick Steinhardt's reftable API refactoring series, completing the cleanup of debugging functionality. The patch moves block printing logic from the core reftable library into a test helper, where it belongs now that the new `reftable_table_iterator` interface provides proper block-level access.

The change removes `reftable_table_print_blocks()` from the public API and reimplements it as `dump_blocks()` in the test helper. The new version is more complete - it now includes index sections that were previously omitted, allowing better verification of reftable file structure in tests.
