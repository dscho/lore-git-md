This is part of Patrick Steinhardt's ongoing series to remove Perl dependencies from Git's test suite (now 20 patches). The current patch focuses on converting tests that use Perl's substitution operator (`s/`) to equivalent shell tools like `sed` and `tr`.

The patch handles straightforward conversions where Perl was being used for simple text transformations that can be done with standard Unix tools. One example shown converts a test that used Perl to replace newlines with null bytes (`perl -pe "s/\012/\000/g"`) to use `tr` instead (`tr "\012" "\000"`). 

Johannes Schindelin noted that while the commit message mentions `sed`, some conversions actually use `tr`, suggesting this particular change might have fit better in the previous patch. Patrick acknowledges this but explains the patch organization was meant to keep review manageable, grouping similar changes together while admitting the boundaries between patches can be fuzzy.

The work continues to demonstrate careful attention to maintaining test behavior while removing Perl dependencies, with reviewers providing detailed feedback that Patrick is incorporating. This patch represents incremental progress in the larger effort, with the series overall receiving positive feedback and nearing maturity.
