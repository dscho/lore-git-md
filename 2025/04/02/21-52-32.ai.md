This is the final patch in Patrick Steinhardt's reftable API refactoring series, completing the transition to a cleaner public interface by moving block printing functionality from the library to test helpers. The change builds on the new table iterator interface introduced in patch 14/16.

The patch removes `reftable_table_print_blocks()` from the public API and reimplements it as `dump_blocks()` in the test helper. Key technical details:
- Moves 65 lines from `table.c` to `test-reftable.c`
- Adds index section dumping capability that was previously missing
- Updates test expectations to include index block output
- Uses the new `reftable_table_iterator` interface throughout
