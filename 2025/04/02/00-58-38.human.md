This is a build system discussion about shell completion installation paths in the meson build system, continuing the thread about standardizing completion script deployment.

Todd Zullinger provides concrete packaging details from Fedora's perspective, noting that tcsh completions are currently installed in a Git-specific path rather than a standard location, with manual configuration required. He shares historical context - this setup has remained unchanged since 2013 due to lack of user feedback, suggesting either low tcsh usage or user acceptance of the manual process.

The email highlights Fedora's current completion paths for bash, fish, and zsh, offering them as reference points for potential defaults. Zullinger notes an apparent inconsistency where zsh completions aren't installed in Fedora packages despite upstream zsh providing them, possibly due to concerns about forcing them on all users.

This contribution adds valuable distribution-specific data to the discussion, reinforcing the need for flexible path configuration while providing real-world examples of current practices. The tone suggests openness to standardization while acknowledging that some shells (like tcsh) may have lower priority due to apparent lack of demand. The email doesn't propose specific code changes but strengthens the case for making completion installation configurable in meson.
