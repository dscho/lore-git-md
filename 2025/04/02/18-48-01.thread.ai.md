Thread summary:

Martin von Zweigbergk announces a cross-tool standardization effort for change IDs, with Gerrit, GitButler, and Jujutsu collaborating to unify their implementations. The proposal introduces a new `change-id` header using Jujutsu's 32-character reverse-hex encoding (z=0 to k=15) for CLI usability. Current implementations differ: Gerrit uses 40-hex-digit `Change-Id` trailers, GitButler uses UUID-formatted `gitbutler-change-id` trailers, and Jujutsu stores IDs externally. The standardization aims to enable workflows like rebasing by ID rather than hash and improve code review integration. A Gerrit design doc addresses edge cases like cherry-pick behavior, though this initial email primarily notifies the Git project rather than requesting specific changes. The effort focuses on interoperability between tools rather than modifying Git's core functionality.
