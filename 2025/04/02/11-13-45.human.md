This is a refactoring patch in the Git cat-file batch mode filtering enhancement series. It's part of the v3 infrastructure work that provides foundational changes for the final v6 implementation.

The patch simplifies the code in `builtin/cat-file.c` by extracting common logic for iterating over all objects (both loose and packed) into a new `batch_each_object()` helper function. While this change appears minor now, it sets up the codebase for more significant modifications in the next patch where bitmap support will be added to this iteration logic.

The refactoring:
1. Combines four separate callback functions into two (`batch_one_object_loose` and `batch_one_object_packed`)
2. Introduces a new `for_each_object_payload` struct to standardize how callbacks are handled
3. Replaces direct calls to `for_each_loose_object` and `for_each_packed_object` with the new helper

This is a clean, focused change that follows the series' pattern of careful architectural preparation. The commit message clearly explains the motivation (upcoming bitmap integration) and the patch maintains all existing functionality while making the code more maintainable.
