Implementation patch for Git cat-file filtering enhancement series (v3 patch 8/11).

This patch introduces `for_each_bitmapped_object()`, a new function that enables filtered iteration over bitmapped objects. It's part of Patrick Steinhardt's series to optimize `git cat-file --batch` with object filtering, building on the callback infrastructure changes from patch 7/11.

The new function takes a bitmap index and filter options, then efficiently walks through matching objects using the existing bitmap machinery. It creates a temporary all-ones bitmap and filters it down before dispatching to type-specific show functions. The implementation handles all four object types (commit, tree, blob, tag) and includes proper error handling for unsupported filters.

This is a technical building block that enables the actual filtering optimizations coming in later patches. The changes are behavior-preserving - existing callers continue working as before since they don't use the new filtering capability yet. The patch includes necessary adjustments to `show_objects_for_type()` to work with explicit bitmaps rather than always using the result bitmap.

The implementation looks solid, with clear error handling and proper resource cleanup. It demonstrates the careful architectural planning seen throughout this series, where each piece builds logically on the last while maintaining backward compatibility.
