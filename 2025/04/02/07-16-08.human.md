This is a follow-up discussion in Patrick Steinhardt's ongoing series to remove Perl dependencies from Git's test suite, specifically addressing patch 12/20 which converts various test cases that print data using Perl to alternative shell-based solutions.

The email responds to Johannes Schindelin's suggestion about potentially extending `test-tool genzeros` to handle non-NUL byte generation, which would provide a cleaner solution than the current approach using `genzeros` + `sed`. Patrick acknowledges the elegance of this idea but explains he avoided it to minimize new tool proliferation, while remaining open to implementing it if there's strong consensus.

Schindelin also pointed out that one case could use `sort -r` instead of awk for reversing data, which Patrick has incorporated. The exchange shows the careful consideration being given to choosing the most appropriate tools for each conversion while maintaining the series' goal of eliminating Perl without introducing unnecessary complexity.

The discussion continues the pattern seen throughout this mature series - minor refinements being suggested and accepted, with no fundamental objections to the technical approach. This patch appears to be in good shape, with only small potential optimizations remaining under consideration.
