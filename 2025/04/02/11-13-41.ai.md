Feature enhancement for `git cat-file`'s object filtering capabilities, specifically adding type-based filtering. This is patch 6/11 in the v3 series that ultimately led to the finalized v6 implementation.

The patch introduces a new `object:type=<type>` filter option for `git cat-file --batch mode`, allowing users to exclude objects that don't match the specified type (blob, commit, tag, or tree). The implementation follows the same pattern established in earlier patches for blob filtering, using the `list_objects_filter_options` infrastructure.

Key technical details:
- Adds new `LOFC_OBJECT_TYPE` filter choice case in `builtin/cat-file.c`
- Uses the existing `typep` pointer mechanism (introduced in earlier patches) to check object types
- Maintains consistent "excluded" status reporting for filtered objects
- Includes documentation updates and test cases for all four object types
- Validates that the filter is only used in batch mode (consistent with other filters)

The implementation is thorough, with tests covering all object types and proper integration with the existing filter infrastructure. This was one of the uncontroversial patches in the series that formed part of the foundation for the final v6 implementation, with its architecture and approach being maintained through to the final version.
