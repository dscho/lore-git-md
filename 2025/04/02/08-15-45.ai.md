This is a test patch addressing a common shell scripting issue in Git's test suite. The patch modifies `t/t9811-git-p4-label-import.sh` to avoid using pipes when checking git tag output, since pipes suppress the exit codes of the left-hand command. Instead, it writes the output to a temporary file first before grepping, which properly captures the exit status of the `git tag` command.

The changes affect two test cases that verify Perforce label import functionality. In both cases, the pattern of `git tag | grep` is replaced with `git tag >output && grep` followed by checks against the output file. This is a standard best practice in Git's test suite to ensure proper error detection.

It follows existing patterns seen elsewhere in the test suite for handling command output verification.
