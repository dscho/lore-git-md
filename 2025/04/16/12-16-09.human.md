This is part 3 of a 4-patch series to make Perl optional in Git, focusing on the documentation build system. The patch converts the `fix-texi.perl` script to a shell version (`fix-texi.sh`), removing another Perl dependency.

The `fix-texi` script performs two simple tasks when processing the user manual: it sets the output filename to "git.info" and inserts a standard directory entry for the manual. Patrick Steinhardt's conversion replaces the Perl implementation with an equivalent `awk` script, maintaining the same functionality while eliminating the Perl requirement.

The change is straightforward - the new shell script uses `awk` to handle the text processing, with logic that mirrors the original Perl version. The Makefile is updated to use the new script instead of the Perl version, which is removed. This is a clean, mechanical conversion that's part of the broader effort to reduce Git's Perl dependencies.

As with the other patches in this series, this change has been reviewed and approved, with all feedback from the initial version incorporated. The series appears ready for merging as it preserves all existing behavior while making the build system more portable.
