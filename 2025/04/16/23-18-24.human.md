This is a build system patch in the ongoing Makefile/meson alignment series. It focuses on optimizing how default values are handled in the meson build configuration.

Ramsay Jones' patch makes the meson build system only pass DEFAULT_EDITOR and DEFAULT_PAGER definitions to the compiler when they differ from Git's built-in defaults ('vi' and 'less'). This avoids unnecessary command-line flags when using standard values, making the build output cleaner. The change affects both the core build configuration and documentation generation.

The patch also ensures the documentation (specifically `git-var` man pages) only includes conditional text about the configured defaults when non-standard values are used. This maintains clean documentation output for the common case while still supporting customization.

This appears to be a straightforward optimization that follows the series' goal of rationalizing the build system. The implementation is clean and maintains all existing functionality while reducing build noise. It's part of a larger effort (now at v3 with 13 patches) to align Makefile and meson behaviors.
