This is a build system patch removing an unnecessary compiler flag in the meson build configuration. It's part of a larger series (v3, patch 1/13) focused on Makefile/meson consistency and platform-specific cleanup.

The change removes `-DCURL_DISABLE_TYPECHECK` from the meson build's `libgit_c_args`. This flag was originally added to suppress sparse warnings about function pointer type checking in curl-related files, but meson doesn't support sparse builds. The removal aligns meson's behavior with the Makefile build where this flag is only used for sparse builds.

The patch appears straightforward and well-justified - it removes build system cruft that serves no purpose in the meson configuration. The commit message clearly explains the history (dating back to 2013) and rationale for the change. As the first patch in the series, it sets the tone for the technical precision seen throughout the build system alignment work.

Key technical detail for future reference: The flag affected curl-related files (http-push.c, http.c, http-walker.c, remote-curl.c) by disabling type checking from curl's typecheck-gcc.h header, but only when built with sparse. The meson build never used sparse, making this flag redundant in that context.
