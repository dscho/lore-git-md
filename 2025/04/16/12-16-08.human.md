This is the second patch in a series converting Git's remaining Perl scripts to shell, specifically targeting `git-request-pull`. The patch removes the script's dependency on Perl while maintaining identical behavior.

Patrick Steinhardt rewrites the ref-matching logic in shell, replacing a Perl snippet that previously handled finding matching remote refs. The new implementation uses a shell function with case statements to handle both direct refs and dereferenced tags (those with ^ suffixes), exactly matching the original Perl behavior. The change means `git-request-pull` will now work on systems without Perl installed.

The patch removes Perl-specific test prerequisites, since the functionality no longer requires Perl. This is part of a broader effort to make Perl optional in Git, following similar conversions of `git-filter-branch` and documentation tools in other patches of this series. The implementation appears thorough, with the commit message noting it addresses cases where `@PERL_PATH@` substitutions could previously fail.
