This is part 3/4 of the Perl removal series, focusing on converting the documentation build system from Perl to shell. The patch replaces `fix-texi.perl` with a shell script (`fix-texi.sh`) that performs the same transformations on the user manual output.

The script handles two specific tasks in the documentation build process: changing the output filename to "git.info" and inserting the correct directory category/entry information. The conversion uses `awk` for text processing, maintaining the same functionality while removing the Perl dependency. The Makefile is updated to use the new shell script instead of the Perl version.

The changes are straightforward - 21 lines of new shell script replace 15 lines of Perl, with corresponding Makefile adjustments. This aligns with the series' goal of eliminating Perl as a build requirement, following similar conversions for `git-filter-branch` and `git-request-pull` in earlier patches. The implementation appears clean and maintains the exact same output behavior as the original Perl version.
