This is a build system patch in the ongoing Makefile/meson alignment series, specifically addressing Cygwin compatibility for the `sysinfo()` function. The patch makes three key changes:

1. Moves the `HAVE_SYSINFO` definition from a direct `BASIC_CFLAGS` addition in the Linux section of `config.mak.uname` to a proper build variable, matching the pattern used for other feature detections. This makes the configuration more consistent and maintainable.

2. Adds `HAVE_SYSINFO` support for Cygwin, which provides a working implementation of this Linux-originated function. This enables proper RAM detection in Cygwin environments, particularly important for `git gc`'s auto-scaling behavior.

3. Introduces an autoconf check for `sysinfo()` to ensure consistent detection across all build systems (Makefile, meson, and autoconf). The check follows the established pattern seen with other function detections like `clock_gettime`.

The changes are straightforward and well-contained, continuing the series' theme of build system standardization. The patch maintains backward compatibility while improving cross-platform support. The autoconf addition ensures future builds will properly detect `sysinfo()` availability regardless of platform, though the immediate impact is primarily for Cygwin users. This aligns with the series' broader goal of making platform-specific features consistently available where supported.
