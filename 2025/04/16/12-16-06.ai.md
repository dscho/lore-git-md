This is a v2 resubmission of the Perl dependency removal series, now incorporating feedback from the initial review round. The series continues the effort to make Perl truly optional by converting remaining Perl scripts to shell, specifically targeting `git-filter-branch`, `git-request-pull`, and documentation building infrastructure.

The key changes in v2 version address review feedback:
1. In `request-pull`, the ref pattern matching for dereferenced tags (handling of `^` suffix) has been loosened to exactly match the original Perl behavior, addressing Junio's optional suggestion from v1 review.
2. Shell script formatting improvements, particularly in the `cmd-list.sh` case statements, following Junio's stylistic preferences.
3. Minor shell script cleanups like removing explicit `in "$@"` in loops.

The technical approach remains consistent with v1:
- `filter-branch` uses shell I/O redirection and `git hash-object` for state handling
- `request-pull` implements ref matching in shell with process substitution
- Documentation builds use new shell versions of `fix-texi` and command list generation scripts

The series now appears merge-ready with all components reviewed and approved, though with some stylistic adjustments made. It builds on the test suite Perl removal work and leaves only non-critical components (gitweb, send-email, etc.) still requiring Perl. The documentation changes align with broader build system modernization efforts.
