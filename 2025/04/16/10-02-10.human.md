This is the first patch in Patrick Steinhardt's v3 series hardening integer handling in Git's parse-options infrastructure. It's a refactoring patch that converts all manual option structure initializations to use designated initializers.

The patch modernizes how Git initializes its command-line option structures by replacing positional initialization with named field initialization. This makes the code more maintainable by:
- Allowing optional fields to be skipped rather than requiring zero-initialization
- Making the code more self-documenting by showing which field each value corresponds to
- Future-proofing against structure changes by removing ordering dependencies

The changes touch 24 files across the codebase, primarily converting `OPTION_CALLBACK` and similar macros to their expanded form with explicit field names. The patch maintains identical behavior while improving code hygiene.

As the first in a series that will add integer parsing safety checks, this foundational change makes the subsequent patches cleaner to implement. It has already gone through two rounds of review (v1 and v2) and remains unchanged from the previous version, suggesting it's stable and ready for inclusion.
