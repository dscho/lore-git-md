This is the final patch in a series removing Perl dependencies from Git's build system, specifically targeting documentation generation. Patrick Steinhardt converts the `cmd-list.perl` script to shell (`cmd-list.sh`), which generates the categorized command listings for git(1) manpages.

The shell version is about 7x slower (74ms vs 10ms) due to shell's inherent overhead, but the performance impact is deemed acceptable since documentation builds are infrequent. The patch carefully avoids spawning external commands in the hot `format_one()` function to minimize the slowdown.

This completes the series' goal of making Perl optional for core Git functionality, following earlier conversions of `filter-branch` and `request-pull`. The changes are straightforward - replacing Perl file parsing with shell equivalents while maintaining identical output behavior. Build system files (Makefile, meson.build) are updated to use the new script.

The patch appears well-considered, with thorough benchmarking and clear justification for the performance tradeoff. As the final piece of this reviewed and maintainer-approved series, it seems ready for merging.
