This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack handling. It's the third patch in a 9-part series that aims to make pack maintenance more configurable and efficient.

The patch extracts the `--stdin-packs` handling code from `cmd_pack_objects()` into a new helper function `read_stdin_packs()`. This is a straightforward code organization change that prepares for future additions to the stdin-packs functionality in later patches. The change is mechanical - the same logic is moved into a separate function with no behavior changes.
