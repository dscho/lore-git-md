Bugfix patch in Patrick Steinhardt's series hardening integer handling in Git's parse-options infrastructure (now v3, patch 6/7). This patch specifically addresses signedness mismatches in option parsing that caused test failures on big-endian platforms like s390x and sparc64.

The issue occurs when callers pass unsigned variables (like `size_t`) to `OPT_INTEGER()`, which expects signed integers. While this worked by coincidence on little-endian systems, it broke on big-endian ones. The patch introduces compile-time assertions (`BARF_UNLESS_SIGNED`/`BARF_UNLESS_UNSIGNED`) to catch these mismatches early, then fixes several instances where the wrong option macro was being used (converting `OPT_INTEGER` to `OPT_UNSIGNED` where appropriate).

Affected commands include `git backfill`, `git apply`, `git column`, and `git grep`, all of which had cases where unsigned values were being parsed with signed option handlers. The changes maintain the same functionality while ensuring type safety across all platforms. This completes the type safety layer of the series, with all prior review feedback now addressed.
