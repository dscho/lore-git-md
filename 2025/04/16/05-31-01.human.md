CI infrastructure patch addressing Fedora test failures by explicitly installing gawk. This follows up on Junio Hamano's initial workaround and Todd Zullinger's investigation into why Fedora 42 container images no longer include awk by default (unlike Fedora 41). Johannes Schindelin's patch takes Zullinger's suggestion to explicitly install gawk rather than relying on Fedora's package manager to resolve 'awk' to gawk, which wouldn't work on AlmaLinux. The change is well-justified with detailed reasoning about package management differences between distributions and future-proofing considerations. The patch has already proven effective in fixing CI failures for Git for Windows. This appears to be a solid solution to the immediate problem while being more robust against future container image changes.
