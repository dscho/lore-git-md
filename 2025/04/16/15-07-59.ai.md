This is a follow-up discussion in the completed Perl removal series, specifically addressing the `git-request-pull` conversion from Perl to shell. Patrick Steinhardt responds to Junio Hamano's review of the ref matching pattern in the shell implementation.

The key technical point concerns the pattern matching for dereferenced refs (those ending with `^{}`). Junio noted the shell version is slightly stricter than the original Perl implementation, which could handle any suffix after `^`. Patrick agrees to maintain the original behavior and suggests a corrected shell pattern (`ref="${ref%"^"*}"`) that would match the Perl version's flexibility.

This is a minor refinement to ensure behavior parity in the already-merged conversion. The discussion confirms the series' goal of faithful rewrites rather than behavior changes, with Patrick acknowledging the original commit message should have noted this difference. The actual implementation remains unchanged since the series is merged, but the exchange documents the design consideration for future reference.
