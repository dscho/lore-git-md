This is a build system patch in the ongoing series aligning Makefile and meson configurations, with a focus on Cygwin compatibility. It enables `sysinfo()` support for Cygwin, which despite being a Linux-specific function, has a working implementation in Cygwin.

The patch makes three key adjustments: moves the `HAVE_SYSINFO` definition from a direct `-D` flag to a config variable in `config.mak.uname` for Linux), adds Cygwin to the list of platforms with `HAVE_SYSINFO` support, and adds an autoconf check for the function. The changes are straightforward and maintain consistency with how other platform-specific features are handled in the build system.

This is part of the broader effort to standardize build configurations across platforms and build systems. The patch follows the series' pattern of moving platform-specific logic into `config.mak.uname` while ensuring feature detection works consistently across all build systems (Makefile, meson, and autoconf). The change is well-contained and appears to be a logical extension of existing infrastructure.
