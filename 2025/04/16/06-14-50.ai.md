- Updating the tutorial text to explain these repository-aware variants
- Showing how to pass the repository parameter through to `wt_status_prepare()`
- Including "repository.h" where needed for the new API usage

The patch completes the series' goal of updating the tutorial to reflect current best practices, following earlier patches that addressed repository parameter usage and UNUSED macros.
