This is version 2 of a patch series continuing the effort to make Perl an optional dependency in Git, focusing on converting `git-filter-branch`, `git-request-pull`, and documentation building infrastructure from Perl to shell scripts.

The series builds on previous work that removed Perl from the test suite. The main changes in v2 address feedback from Junio Hamano, including:
- Loosening the ref pattern matching in `git-request-pull` to exactly match the original Perl behavior when handling dereferenced tags (the `^{}` suffix case)
- Fixing indentation in case statements in the command list generation script
- Removing an unnecessary explicit `in "$@"` in a for loop

The conversions maintain all existing functionality while removing Perl as a hard requirement. The filter-branch conversion uses shell I/O redirection and `git hash-object` for state handling, request-pull implements equivalent logic in shell with process substitution, and the documentation build system now uses shell scripts with awk processing.

With these changes, only non-critical features like gitweb, git-send-email, and some contrib scripts would still require Perl. The series appears ready for merging with all components reviewed and approved, though there was a noted 7x performance penalty in command list generation (74ms vs 10ms) that was deemed acceptable.
