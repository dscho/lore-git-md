This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction. It's the third patch in a 9-part series (v3).

The patch factors out the `--stdin-packs` handling logic from `cmd_pack_objects()` into a new `read_stdin_packs()` function. This is preparatory work for making the implementation more complex in a subsequent patch. The change moves the inline handling of stdin packs (introduced in commit 339bce27f4) into its own function while maintaining identical behavior.

The refactoring is straightforward - it extracts the existing logic with no functional changes, just moving the code block and adjusting some declarations (like moving `add_unreachable_loose_objects()` forward). Junio Hamano has reviewed and approved the change with a simple "Makes sense" comment.

This is part of the larger effort to optimize pack maintenance by making cruft pack inclusion in MIDX configurable, with the series introducing a new `repack.midxMustContainCruft` config option in the final patch. The current patch is purely structural, setting up for the more substantial changes to come in later patches of the series.
