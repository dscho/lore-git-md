Build system cleanup removing an unnecessary compiler flag in the meson build. This is part of a larger series aligning the Makefile and meson build systems.

The patch removes `-DCURL_DISABLE_TYPECHECK` from the meson build configuration. This flag was originally added to suppress sparse warnings about curl's type checking headers, but since meson doesn't support sparse builds, the flag serves no purpose and can be safely removed. The change helps keep the meson build configuration clean and focused on what it actually needed.

The commit message clearly explains the history and rationale - the flag was only needed for sparse builds (which meson doesn't do) and removing it re-enables curl's type checking in the meson build. This is a straightforward, well-justified cleanup that moves the meson build closer to parity with the Makefile build system.
