This is the first patch in a series converting Git's remaining Perl dependencies to shell scripts, specifically targeting `git-filter-branch`. The patch removes Perl usage from the `--state-branch` feature, which previously relied on Perl for saving and loading commit object ID mappings.

The conversion addresses two key issues: (1) the script was calling Perl directly without respecting `PERL_PATH`, potentially using the wrong Perl version, and (2) the feature would fail entirely on systems without Perl installed. The new implementation uses shell I/O redirection and `git hash-object` to handle the state mapping, maintaining the same `from_commit:to_commit` format in the `filter.map` file.

Technical changes include replacing Perl's file handling with shell `while read` loops and `case` pattern matching for validation, and using `git hash-object` directly for state blob creation. The patch shows 19 insertions and 18 deletions in `git-filter-branch.sh`, with the core functionality preserved while eliminating the Perl dependency. This aligns with the series' broader goal of making Perl optional in Git's codebase.

The patch appears well-contained and maintains the existing behavior while solving the stated problems. Since this is v2 of the series and the maintainer already approved the approach in v1, it seems likely to be merge-ready.
