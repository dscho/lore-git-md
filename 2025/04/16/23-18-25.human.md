Build system refinement for help format defaults on Windows. This patch from Ramsay Jones is part of the ongoing Makefile/meson alignment series (now at v3 with 13 patches). It addresses how the default help format (man vs html) is handled in the meson build system.

The change makes two key adjustments: First, it stops passing the DEFAULT_HELP_FORMAT define to the compiler when using the standard 'man' format, reducing build system noise. Second, it introduces a new 'platform' option that automatically selects 'html' on Windows (matching Makefile behavior) while keeping 'man' elsewhere. The implementation uses meson's host_machine.system() to determine the platform.

This is a clean, focused change that maintains compatibility with existing behavior while simplifying the build configuration. The patch follows the series' pattern of making meson behave consistently with the Makefile build while taking advantage of meson's native features where appropriate. The change is well-motivated and appears to be a straightforward improvement with no obvious downsides.
