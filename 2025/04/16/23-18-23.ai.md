This is a build system refactoring patch in the ongoing Makefile/meson alignment series. It focuses on `RUNTIME_PREFIX`-related compiler flags.

The patch restructures how certain platform-specific flags are added to `BASIC_CFLAGS`, making them conditional on `RUNTIME_PREFIX` being defined. Five previously unconditional flag sets (`HAVE_BSD_KERN_PROC_SYSCTL`, `PROCFS_EXECUTABLE_PATH`, `HAVE_NS_GET_EXECUTABLE_PATH`, `HAVE_ZOS_GET_EXECUTABLE_PATH`, `HAVE_WPGMPTR`) are now nested under an `ifdef RUNTIME_PREFIX` block, since they only affect runtime path resolution behavior. The change is purely organizational - no functionality is altered, just the conditions under which these flags are applied.

The implementation shows careful attention to detail: the `PROCFS_EXECUTABLE_PATH` handling maintains its quoting behavior (now with a more concise variable name `pep_SQ`), and all indentation follows existing patterns. This appears to be a straightforward cleanup that logically groups related build configuration while maintaining exact behavior parity. The change fits well with the series' broader goal of build system rationalization and meson compatibility.
