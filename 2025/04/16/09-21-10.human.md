Performance optimization patch in the MIDX/cruft pack series. This is patch 5/9 in Taylor Blau's v3 series about optimizing pack maintenance, specifically improving delta compression for loose objects when using `--stdin-packs`.

The patch fixes an oversight where loose objects weren't being considered as potential delta bases during pack creation with `--unpacked`. By passing the `rev_info` struct to the loose object enumeration code, these objects can now participate in the name-hash traversal, which should produce slightly more efficient packs through better delta selection. The changes are minimal but effective - mainly plumbing the `rev_info` through several functions and adding commits from loose objects to the pending list when appropriate.

Junio Hamano approves the change, calling it "clever" and noting the surprisingly small diff size. The patch maintains all existing functionality while adding the optimization, passing NULL for the `rev_info` in cases where the traversal isn't needed (like cruft object enumeration). This is a solid technical improvement that fits well with the series' goal of optimizing pack maintenance operations.
