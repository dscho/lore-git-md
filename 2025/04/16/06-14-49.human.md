This is the third patch in a documentation series modernizing the MyFirstContribution tutorial. It updates the `cmd_psuh` example to demonstrate proper repository handling patterns for new contributors.

The patch makes two key improvements to the tutorial's example command implementation. First, it shows the complete function signature for a `struct repository` parameter, matching modern Git built-in conventions. Second, it removes the `UNUSED` macros since the example now actually uses these parameters, including demonstrating how to access the repository's Git directory via `repo->gitdir`.

The changes provide a more realistic example of command implementation while maintaining the tutorial's pedagogical approach. The patch keeps the existing `printf()` calls that show argument handling, adding new output for the repository information. This appears to be a straightforward documentation improvement that aligns with the series' goal of updating contributor guidance to reflect current practices.
