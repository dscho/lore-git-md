This is a build system patch in the ongoing Makefile/meson alignment series, specifically addressing help format defaults on Windows. The change makes meson's behavior match the Makefile build by defaulting to HTML help format on Windows while keeping man pages as the default elsewhere.

The patch introduces a new 'platform' option for `default_help_format` that automatically selects HTML on Windows and man pages on other systems. This eliminates the need to pass the `-DDEFAULT_HELP_FORMAT` define to the user wants something other than the platform default, reducing build system noise. The change maintains all existing functionality while making the build configuration more maintainable by removing redundant defines when they match defaults.

Key technical details:
- Adds platform-specific default handling via `host_machine.system()` check
- Only passes `-DDEFAULT_HELP_FORMAT` when non-default value is needed
- Updates meson_options.txt to include new 'platform' choice as default
- Follows same pattern as earlier DEFAULT_EDITOR/DEFAULT_PAGER optimizations in this series
- Maintains exact same behavior as Makefile build (HTML on Windows, man elsewhere)

This is a straightforward improvement that aligns meson behavior with the Makefile build while simplifying the build configuration. It's part of the broader effort to standardize build system behavior across platforms and build tools. The change is well-contained and unlikely to be controversial, following established patterns from earlier patches in the series.
