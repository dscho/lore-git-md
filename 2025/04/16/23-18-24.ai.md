Build system refinement in the meson build configuration, part of the larger Makefile/meson alignment series. This patch (3/13 in v3) optimizes how default editor and pager settings are handled in the build process.

The change makes the build system only pass DEFAULT_EDITOR and DEFAULT_PAGER defines to the compiler when they differ from the hardcoded defaults ('vi' and 'less'). This avoids redundant command-line flags when using standard values while maintaining the ability to override them. The same logic is applied to the asciidoc documentation generation, where conditional text about these defaults would otherwise appear awkwardly for standard values.

Key technical details:
- Modifies both meson.build and Documentation/meson.build
- Affects libgit_c_args compilation flags and asciidoc_common_options
- Maintains identical behavior while reducing build system noise
- Handles both asciidoc and asciidoctor documentation backends
- Preserves all existing override capabilities

This is a clean, focused change that follows the series' theme of build system rationalization. The patch demonstrates careful attention to both compilation and documentation consistency, with no apparent downsides to the approach. It fits well with the series' broader goals of eliminating unnecessary build variations while maintaining all necessary flexibility.
