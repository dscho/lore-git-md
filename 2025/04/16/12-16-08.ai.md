This is the second patch in a series removing Perl dependencies, specifically converting `git-request-pull` from Perl to shell. The patch focuses on eliminating the script's reliance on Perl for ref matching logic while maintaining identical behavior.

The key change replaces a Perl script that processed `git ls-remote` output with a shell function `find_matching_ref` that uses `case` pattern matching. The new implementation handles both direct ref matches and dereferenced tags (those with `^` suffixes) exactly as the Perl version did. The patch removes the `PERL` prerequisite from tests since it's no longer needed.

Technical details show the conversion preserves the original functionality:
- Maintains the same ref matching logic for both direct refs and patterns
- Keeps the same output format (`remote_sha1 found_ref`)
- Uses shell process substitution to avoid variable scoping issues
- Removes the `@PERL_PATH@` substitution that could fail on Perl-less systems

The patch is part of a well-reviewed series where Junio Hamano had already approved the approach in v1, and this version incorporates all feedback to ensure behavior matches the original Perl implementation exactly. The changes are focused and mechanical, with test coverage remaining intact (just without the Perl prerequisite check). This continues Git's broader effort to reduce Perl dependencies following earlier test infrastructure conversions.
