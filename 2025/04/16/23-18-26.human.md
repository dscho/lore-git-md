Build system cleanup removing obsolete Linux compatibility code. This patch from Ramsay Jones eliminates the NEEDS_LIBRT build variable, which was originally added in 2016 to handle linking with librt for clock_gettime() on older Linux systems with glibc < 2.17. The commit message provides a detailed timeline showing that all major Linux distributions have long since moved to newer glibc versions where this workaround is unnecessary, with the last affected system (Debian 7) reaching end-of-life in 2018.

The change removes both the variable definition from the Makefile documentation and its Linux-specific setting in config.mak.uname. This is part of the ongoing build system modernization effort to remove legacy compatibility code, following the project's trend of dropping support for obsolete platforms. The patch is straightforward and well-justified, with clear evidence that the functionality is no longer needed on any supported system.
