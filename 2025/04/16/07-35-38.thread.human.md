Kitty Chang reported a regression where Git for Windows versions 2.44.0 and above fail to clone from Azure DevOps repositories, showing SSL-related RPC failures during large transfers. The issue doesn't affect versions 2.30.2 through 2.43. brian m. carlson has responded, suggesting this is likely a Windows-specific issue rather than a core Git problem.

The thread has progressed with brian m. carlson providing guidance on next steps: the issue should be reported to the Git for Windows issue tracker, as it may relate to the libcurl versions bundled with Git for Windows. He referenced potential similarities with issue #4997 in the Windows tracker and requested more specific version information to help pinpoint the regression. The response also asks whether the issue reproduces with other hosting services like GitHub or GitLab, which could help isolate whether this is Azure DevOps-specific.

For now, the reporter remains stuck using older versions (2.30.2-2.43) for Azure DevOps access while the Windows maintainers investigate. The thread awaits further diagnostic information and a proper issue tracker filing to make progress on this Windows-specific networking problem.
