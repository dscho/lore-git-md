This thread reports a regression in Git for Windows versions 2.44.0 and above when cloning from Azure DevOps repositories. Kitty Chang from Cathay Financial Holdings provided detailed reproduction cases showing the issue: cloning succeeds with Git for Windows versions 2.30.2 through 2.43 but fails with 2.44.0-rc0 and later, consistently producing an SSL-related RPC failure (curl 56 OpenSSL SSL_read: SSL_ERROR_SYSCALL, errno 0). The failure occurs during large transfers (one case showed 2.18 GiB transferred before failing) and affects both command-line Git and SourceTree. 

The reporter is currently pinned to older Git versions to maintain functionality while seeking workarounds or fixes. The error suggests a potential SSL/network layer issue in the Windows build configuration, though it remains unclear whether this stems from Git core changes or Windows-specific in the 2.44.0 update. The clear version boundaries and reproduction cases make this a well-documented regression report.
