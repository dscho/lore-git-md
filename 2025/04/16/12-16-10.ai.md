This is the final patch in Eric Wong's series to make Perl optional, specifically targeting the documentation build system. Patrick Steinhardt contributes the conversion of `cmd-list.perl` to a shell script (`cmd-list.sh`), completing the removal of Perl dependencies from Git's core documentation generation.

The patch replaces the Perl script that generates categorized command lists for git(1) documentation with a shell implementation. Key technical aspects include:
- Maintains identical output format (linkgit entries with man section numbers and descriptions)
- Preserves all functionality including deprecated command marking
- Introduces a 7x performance penalty (74ms vs 10ms) which is deemed acceptable given the infrequency of documentation builds
- Updates both Makefile and meson build systems to use the new shell script
- Removes Perl as a build requirement when only documentation is needed (though Perl remains required for gitweb and netrc credential helper)

The conversion follows the series' pattern of careful behavior preservation while eliminating Perl dependencies. The performance impact is explicitly measured and justified in the commit message. This completes the series' goal of making Git buildable without Perl for core functionality, leaving only gitweb and send-email as remaining Perl-dependent components.
