Bugfix patch completing Patrick Steinhardt's series hardening integer handling in Git's parse-options infrastructure (now v3, patch 6/7). This installment specifically tackles signedness mismatches between option declarations and their backing variables, which caused test failures on big-endian platforms like s390x and sparc64.

The patch introduces compile-time assertions `BARF_UNLESS_SIGNED()` and `BARF_UNLESS_UNSIGNED()` to catch type errors where integer options are declared with the wrong signedness. These assertions are applied to `OPT_INTEGER()`, `OPT_UNSIGNED()`, and `OPT_MAGNITUDE()` macros, forcing proper type alignment. The changes expose and fix several existing mismatches:

1. In `apply.c`, changes `-C` context option from `OPT_INTEGER` to `OPT_UNSIGNED` since it stores to a `size_t`
2. In `builtin/backfill.c`, fixes the originally reported `--min-batch-size` option that used `OPT_INTEGER` with a `size_t`
3. Updates `builtin/column.c` and `builtin/grep.c` to use proper unsigned variants for options storing to unsigned fields

The implementation builds on the series' earlier work with precision handling and type safety, now adding signedness verification. The compile-time checks use `__builtin_types_compatible_p` where available, falling back to runtime-compatible checks otherwise. This patch was previously approved in v2 and completes the core safety improvements for the parse-options subsystem.

Key technical details:
- New macros in `git-compat-util.h` for signedness validation
- Updates to option macros in `parse-options.h` to enforce type checking
- Fixes in 4 commands (`apply`, `backfill`, `column`, `grep`)
- Maintains API compatibility while adding safety
- Follows same pattern as previous patches in the series
- Includes reported-by tags for the original bug reports

This patch represents the last of the mandatory changes in the series, with patch 7/7 being an optional proof-of-concept for bounded integers. The work now provides comprehensive compile-time and runtime validation for all numeric option types in Git's option parsing infrastructure.
