This is a GSoC project proposal for a new feature: a machine-readable repository information query tool. Lucas Oshiro proposes creating a new `git metadata` command that would output repository information (currently scattered across various `git rev-parse` flags) in structured JSON format.

The proposal points include:
- Centralizing repository metadata like object format, Git dir location, ref storage format, and bare/shallow status
- Targeting tools that currently parse `rev-parse` output (IDEs, repository browsers, tracking software)
- A development plan spanning requirements gathering, JSON schema design, and incremental implementation
- The student's relevant background including prior Git contributions and C experience

The proposal is a revised version incorporating feedback from Patrick Steinhardt, with more focus on `rev-parse` features and a clearer development timeline. The student has demonstrated engagement with the community through several small contributions already merged. The project appears well-scoped for GSoC, addressing a clear need for machine-readable repository metadata while building on existing Git infrastructure.
