This is the first patch in Patrick Steinhardt's v2 reftable API refactoring series, focusing on license header formatting standardization. The patch updates the BSD license headers across all 34 reftable source files to match Git's typical multi-line comment style, adding asterisks at the start of each line and proper indentation.

The changes are purely mechanical formatting updates with no functional impact. Each file's license block is transformed from a simple block comment to the standard Git-style multi-line comment format with consistent asterisk alignment. The patch includes one special case in `reftable-basics.h` which already had partial formatting but needed the closing comment marker aligned.

As the opening patch in a larger series that will refactor reftable internals and APIs, this establishes consistent style before more substantive changes. The changes are straightforward and uncontroversial, serving as groundwork for the subsequent patches that will introduce functional improvements to the reftable implementation.
