This is a GSOC 2025 proposal for a new feature: a machine-readable repository information query tool to declutter `git rev-parse`. The proposal comes from Moumita Dhar, a self-taught programmer with some prior experience contributing to Git's `userdiff` system for shell scripts.

The core idea is to extract non-revision-parsing functionality from `git rev-parse` (like repository status checks, path queries, and environment reporting) into a new dedicated command (tentatively called `git repo-info`). The new command would provide structured output (likely JSON) for better scriptability. The proposal includes a detailed 12-week timeline covering implementation of different functionality areas, from basic repository path information to superproject awareness and path resolution logic.
