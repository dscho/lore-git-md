This is a build system patch addressing shell completion script installation in the Meson build. It follows up on a previous discussion (referenced but not provided in context).

The patch modifies the Meson build configuration to properly install Bash and Zsh completion scripts to their canonical system locations (`/usr/share/bash-completion/completions/git` and `/usr/share/zsh/site-functions/_git` respectively). Currently, Meson only copies these files to the build directory for test purposes when explicitly enabled via `-Dcontrib=completion`, which Patrick notes is confusing for users who expect installation.

The implementation handles both Meson versions before and after 1.3.0, maintaining the existing test behavior while adding proper installation paths. The patch preserves the current behavior for tcsh completion and git-prompt.sh which remain uninstalled. The commit suggests this initial approach uses standard paths but leaves room for future customization if distribution-specific needs arise.

Key technical details:
- Adds per-script configuration specifying output filenames and install directories
- Maintains test compatibility by keeping original filenames in build directory
- Uses Meson's `fs.copyfile()` for newer versions, falling back to `configure_file()`
- Installs only Bash/Zsh completions (others remain build-only)
