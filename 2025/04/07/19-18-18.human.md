This is a GSoC project proposal for a new feature: a machine-readable repository information query tool. Lucas Oshiro proposes creating a new `git metadata` command that would output repository information (currently scattered across various `git rev-parse` flags) in structured JSON format.

The proposal has evolved through three versions, with v3 focusing more tightly on `rev-parse` functionality after community feedback. Key planned outputs include repository format, paths, ref storage type, and bare/shallow status. The command aims to help tools like IDEs and repository trackers that currently parse `rev-parse` output.

The implementation plan involves creating new `builtin/metadata.c` and `json.c` files, with development phases for data gathering, JSON serialization, and schema design. The 6-phase schedule runs from requirements gathering through August, with time allocated for community feedback at each stage.

Oshiro demonstrates relevant experience through prior Git contributions (including merged documentation patches), C/C++ work, and academic/open-source involvement. The proposal is well-structured and shows familiarity with Git internals, though the JSON approach may need careful design to avoid schema pitfalls common in early versions.
