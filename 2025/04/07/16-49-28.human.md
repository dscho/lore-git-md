This is Junio C Hamano's monthly "What's cooking in git.git" status report, providing updates on the state of various Git development branches and patches under consideration. The report covers both graduated topics (merged to 'next' or 'master') and new topics being worked on.

The report highlights include:

Several topics have recently graduated to 'master', including:
- Optimizations for refname availability checks
- Fixes for TCP keepalive behavior in HTTP transports
- Improvements to fast-export/fast-import handling of signed commits
- First steps in deprecating merge-recursive in favor of merge-ort
- Various code cleanups and warning fixes

New topics under development include:
- A major reftable API revamp to make the library more standalone
- Support for filtering objects in `git cat-file --batch`
- Rewriting tests to reduce Perl dependencies
- Improvements to `git status` output during rebase
- New `--path-walk` option for pack-objects to find better deltas
- Non-transactional batch reference updates
- New maintenance task for reflog expiration

The report also notes several topics that have been discarded or superseded by other work, and provides status indicators (like "Will merge to 'next'" or "Needs more work") for each active topic. This gives a comprehensive overview of the current state of Git development and what changes might be coming in future releases.
