This thread addresses how Git's Meson build system handles installation of shell completion scripts (Bash and Zsh). The initial patch proposed fixing a confusing behavior where scripts were only copied to the build directory for testing rather than being installed to standard system locations. The solution modifies Meson configuration to properly install to canonical paths while maintaining test compatibility, handling both pre- and post-Meson 1.3.0 versions.

Akshay Hegde confirmed the patch works correctly in both standard installations and custom setups using `-Ddatadir`. The Zsh completion's documented dependency on the Bash script location was noted as properly handled through existing documentation for edge cases. 

In a follow-up, Todd Zullinger raised a design question about whether to use `pkg-config` to query system completion directories instead of Git's `$datadir`, particularly for handling mixed installation paths (like when Git is in `/usr/local` while bash-completion lives in `/usr`). However, this appears more as a refinement suggestion than a blocker, since `/usr/local` is already in bash-completion's default search paths and the current implementation has been validated as functional. The thread shows consensus that the core issue is solved, with potential future consideration for path determination strategy.
