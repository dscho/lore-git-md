This thread discusses improving how Git's Meson build system handles shell completion script installation. The current behavior only copies Bash and Zsh completion scripts to the build directory for testing, rather than installing them to standard system locations, which has caused user confusion.

The proposed patch modifies the Meson configuration to properly install these scripts while maintaining test compatibility. Akshay Hegde confirmed the solution works in both standard and custom installations. Todd Zullinger raised the idea of using `pkg-config` for more flexible path resolution, prompting Junio Hamano to weigh in. Junio noted that the current approach (using `$datadir`) was deliberately chosen in the Makefile system to avoid complexity around installation paths, and that distributions already customize these paths appropriately. He suggested that if Git were to handle this directly, it would likely need a dedicated configuration variable rather than auto-detection via `pkg-config`.

The discussion shows consensus that the patch solves the core issue while properly handling edge cases. The remaining questions center on whether to extend the installation to other completion scripts (tcsh, git-prompt.sh) and whether to adopt more sophisticated path resolution strategies, though Junio's comments suggest the simpler approach may be preferable. The patch appears ready for merging with its current design.
