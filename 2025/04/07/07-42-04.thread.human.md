This thread discusses improving the installation of shell completion scripts in Git's Meson build system. The initial patch noted that while completion scripts were built for testing, they weren't installed to standard system locations, creating confusion for users. 

Key participants including Akshay Hegde, Todd Zullinger, and Eli Schwartz have analyzed the technical details, with Schwartz providing particularly thorough analysis of path handling complexities. The discussion has revealed that Bash completion installation is straightforward, with robust fallback paths and good distro support, while Zsh presents more challenges due to rigid path requirements and platform-specific variations like Debian's `vendor-completions` directory.

Junio Hamano, weighing in on the design philosophy, agrees the Bash portion should proceed, suggesting adding a standard `bash_completion_dir` configuration. For Zsh, he acknowledges the complications Schwartz identified and leaves open whether to implement standard paths (even if not auto-discovered) or defer support entirely. The emerging consensus is to move forward with Bash completion installation while postponing Zsh support until its platform-specific issues can be properly addressed.
