This thread discusses improving how Git's Meson build system handles shell completion script installation. The current setup only copies Bash and Zsh completion scripts to the build directory for testing when explicitly enabled, rather than installing them to standard system locations, which has confused users expecting proper installation.

The proposed patch modifies Meson configuration to install these scripts to their canonical paths while maintaining test compatibility. It handles different Meson versions and preserves the ability to test from the build directory. Patrick Steinhardt previously noted the current behavior's shortcomings.

Akshay Hegde confirmed the patch works as intended in real-world testing, including with custom installation paths via `-Ddatadir`. He noted an edge case where Zsh completion depends on the Bash script's location in non-standard installations, but this is already documented in the Zsh script and doesn't require patch changes. The discussion confirms the solution addresses the core issue while maintaining flexibility for different installation scenarios.
