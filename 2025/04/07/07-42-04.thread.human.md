This thread has been discussing how to properly install Git's shell completion scripts when building with Meson, which currently only copies them to the build directory for testing. The core issue is that users expect these scripts to be installed to standard system locations like `/usr/share/bash-completion/completions/git`.

After technical discussion, there's clear consensus to proceed with installing Bash completions while deferring Zsh support due to platform-specific complexities. Junio Hamano confirmed the current `datadir` approach was deliberate in the Makefile system and that distributions already customize paths appropriately. Eli Schwartz and others validated that its path resolution is robust across different installations.

The latest patch implements this agreed direction, adding Bash completion installation to both Meson and Makefile build systems. It places the file at the standard location while remaining configurable via build variables, and handles Meson version compatibility cleanly. The changes are minimal and focused, preserving test behavior while fixing the user-facing installation issue. With Junio's input incorporated and the technical questions resolved, this appears ready for merging. The more complex Zsh completion support remains an open question for future work.
