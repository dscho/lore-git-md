This thread discusses improving the Meson build system's handling of shell completion script installation. The initial patch proposed installing Bash and Zsh completion scripts to standard system locations, addressing user confusion where they were previously only copied to the build directory for testing. The implementation handles both pre- and post-Meson 1.3.0 versions while preserving test compatibility.

Key participants have weighed in with different perspectives. Akshay Hegde confirmed the patch works in both default and custom installations. Todd Zullinger raised design considerations about path resolution strategies. Junio Hamano provided maintainer perspective, noting distributions already customize paths appropriately and favoring simple, predictable path handling over complex auto-detection mechanisms.

The latest contribution from Eli Schwartz provides important technical analysis of the differences between Bash and Zsh completion systems. While the Bash installation approach (using standard `/usr/share/bash-completion/completions`) is robustly supported across distributions, Zsh presents challenges with its rigid path requirements and Debian-specific deviations. Schwartz suggests proceeding with the Bash completion installation while deferring Zsh support until its path handling can be properly resolved, possibly requiring distro-specific workarounds.

The thread shows consensus on moving forward with Bash completion support while recognizing Zsh situation needs more consideration. Junio's earlier comments about favoring simplicity align with this approach. The discussion has identified all key technical considerations and appears ready for the author to send an updated version focusing on Bash completion first.
