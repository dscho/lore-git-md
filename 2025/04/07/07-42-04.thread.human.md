This thread discusses improvements to the Meson build system's handling of shell completion scripts. The initial patch (not shown here) appears to have identified an issue where completion scripts were only being copied to the build directory for testing purposes, rather than being properly installed to system locations.

The current patch from Patrick Steinhardt addresses this by modifying the Meson configuration to install Bash and Zsh completion scripts to their standard system paths (/usr/share/bash-completion/completions/git and /usr/share/zsh/site-functions/_git). The implementation carefully maintains backward support for both older and newer Meson versions while preserving the existing test behavior. Notably, tcsh completion and git-prompt.sh remain uninstalled under this change, keeping the scope focused on the most commonly used completions.

The patch appears to be a straightforward solution to the installation issue, with Patrick suggesting this initial approach could be extended later if distribution-specific customization needs arise. The technical implementation handles version compatibility and maintains the existing test infrastructure while adding proper installation paths.
