This is a build system patch finalizing the discussion about shell completion script installation paths in the meson build system. Patrick Steinhardt follows up on the earlier conversation with Todd Zullinger, confirming their agreement to standardize completion script paths based on Fedora's conventions.

The key takeaways are:
1. The patch implements automatic installation for bash and zsh completions using Fedora's standard paths (/usr/share/bash-completion/completions and /usr/share/zsh/site-functions respectively)
2. tcsh completions will remain manually installed as before, maintaining backward compatibility
3. No configuration options are being added for path customization unless real-world problems emerge
4. Fish shell completions remain unimplemented as there's no current demand

The patch appears to be the implementation of the consensus reached in the thread, favoring simplicity over premature configurability. The approach uses Fedora's established paths as a reference model while acknowledging that tcsh's special handling should remain unchanged. This seems like a pragmatic solution to the completion script installation problem that has been under discussion.
