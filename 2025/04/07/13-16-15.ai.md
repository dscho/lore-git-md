This is a refactoring patch in Patrick Steinhardt's reftable API improvement series (patch 3/16). It consolidates all block source handling code into dedicated `blocksource.[ch]` files, moving functionality previously scattered across multiple files. The changes include:

Key technical changes:
- Moves `reftable_block_done()` from `block.c` to `blocksource.c` as `block_source_return_block()`
- Relocates `block_source_read_block()`, `block_source_size()`, and `block_source_close()` from `table.c` to `blocksource.c`
- Updates all callers to use the new centralized functions
- Adds proper documentation headers for the new public functions in `blocksource.h`
- Updates test files to use the new function names

The patch maintains all existing functionality while improving code organization. As noted in the thread context, Karthik Nayak previously reviewed this as an improvement, though Justin Tobler suggested documenting the function renames more clearly. The changes are mechanical with no behavior modifications, just better scoping and naming of the block source operations.
