This is a refactoring patch in Patrick Steinhardt's reftable API series, specifically renaming `struct reftable_reader` to `struct reftable_table` to better reflect its purpose. The change is part of making the reftable library more usable as a standalone component.

The patch renames the data structure that represents an individual reftable file from "reader" to "table", since it encapsulates the table content rather than just the reading functionality. This aligns with other reftable structure names like `reftable_merged_table` and `reftable_stack`. The change is mechanical but extensive, touching 19 files with 467 lines added and 467 removed.

The motivation is to improve API clarity for external users of the reftable library (like libgit2) by using more accurate terminology. The patch is well-contained within the reftable subsystem and doesn't affect core Git functionality. It's part of a larger v2 series that has received positive reviews, with all feedback addressed in this version.

Key changes:
- Renames `struct reftable_reader` to `struct reftable_table`
- Updates all related function names (e.g. `reftable_reader_new` → `reftable_table_new`)
- Modifies test files to use the new naming
- Updates documentation comments to reflect the changes
