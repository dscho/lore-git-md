This is a CI/build system patch that improves Meson's handling of shell completion scripts. Patrick Steinhardt addresses an inconsistency where Meson could build completion scripts but not install them, matching the Makefile's current limitations.

The patch teaches Meson to properly install Bash and Zsh completion scripts into their canonical system locations (`bash-completion/completions` and `zsh/site-functions` respectively) when building with Meson. This was previously only done during testing, leaving users who explicitly requested completions via `-Dcontrib=completion` without actually getting them installed.

The implementation handles both modern Meson versions (≥1.3.0) and older ones, maintaining the existing test behavior while adding proper installation support. The commit notes this follows up on prior discussion (referenced by message ID) and takes a pragmatic approach - using standard paths while leaving room for future adjustments if distribution-specific needs arise.

This appears to be a well-justified quality-of-life improvement for Meson users, with careful attention to backward compatibility and clear documentation of the rationale. The patch is focused and maintains existing behavior where appropriate (like for tcsh completions and the prompt script).
