Test suite improvement patch modifying Perforce integration tests to better capture exit codes. This is patch 1/3 in Anthony Wang's v3 series addressing test reliability in t/t9811-git-p4-label-import.sh.

The patch replaces pipe-based command chaining with temporary file output to preserve Git command exit codes, a change that was suggested in earlier review rounds. The technical approach uses `git tag >output` followed by `grep` on the output file rather than piping directly to grep. This ensures test failures properly propagate the exit code from the `git tag` command.

The changes affect two test cases that verify Perforce label import behavior. The first test checks for multiple tags on the same changelist, while the second verifies tag import/export with git config. Both now write tag output to a file before grepping.
