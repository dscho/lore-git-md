This is a style cleanup patch in Patrick Steinhardt's reftable API refactoring series (patch 1/16). The change standardizes the formatting of BSD license headers across 34 files in the reftable library to match Git's typical multi-line comment style.

The patch mechanically reformats each license header from a compact single-block style to the more standard Git format with asterisk-prefixed lines. The actual license text remains identical - this is purely about presentation consistency. The changes are straightforward and uncontroversial, touching only comment formatting without affecting any code logic.

As the first patch in a larger series that has already received positive reviews in its v2 iteration, this serves as a clean foundation for the more substantive API changes that follow. The thoroughness of the change (updating every reftable file) demonstrates attention to detail in establishing consistent style across the subsystem.
