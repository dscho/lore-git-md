This is a refactoring patch in Patrick Steinhardt's reftable API series, introducing a public interface for block-level access in the reftable library. The change moves block-related declarations from internal headers to new public headers (`reftable-block.h` and `reftable-basics.h`), exposing them for external use while maintaining the same functionality.

Key technical details:
- Moves `struct reftable_block` and related functions from internal `block.h` to new public `reftable-block.h`
- Exposes `struct reftable_buf` (used by `reftable_block_first_key()`) by moving it from `basics.h` to `reftable-basics.h`
- Preserves all existing functionality while making the interface available for future verification work
- The commit notes this is preparatory work for implementing consistency checks that will need low-level block access

The patch continues the series' pattern of improving the reftable API's public interface, following earlier structural and naming changes. It maintains the same careful approach seen in previous patches, with thorough header file reorganization and clear documentation of the exposed structures and functions. The change is well-contained and builds logically on the block source consolidation work done in earlier patches.
