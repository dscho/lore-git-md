This is the final patch in Patrick Steinhardt's v2 reftable API refactoring series, completing the transition of block-level access utilities from internal library functions to test helpers. The change moves the block printing logic from `reftable/table.c` to `t/helper/test-reftable.c`, leveraging the new public block iteration interface introduced earlier in the series.

The patch removes `reftable_table_print_blocks()` from the public API since this debugging functionality is only needed for tests. The new implementation in the test helper is more comprehensive - it now includes index section dumping which was previously omitted, allowing better verification of reftable file structure. The test updates show the new output format including index blocks ("idx") that weren't visible before.

This change represents the last piece of the architectural work to expose reftable internals for verification while keeping the core focused on its primary purpose. The series has maintained careful backwards compatibility throughout, with this final cleanup demonstrating how the new interfaces enable moving debugging tools out of the main library. The comprehensive test updates confirm the implementation works as intended.
