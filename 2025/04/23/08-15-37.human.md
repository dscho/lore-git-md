This is a refactoring patch in Karthik Nayak's ongoing series to implement header checking in Meson builds. The patch renames a variable from `third_party_sources` to `third_party_excludes` to better reflect its actual purpose - it's used to exclude certain files from header checking rather than list sources. The change is straightforward and improves clarity, following the pattern of moving variable definitions to the root meson.build file that was established in previous patches.

The patch also removes a duplicate entry for `t/unit-tests/clar` from the exclusion list, a minor cleanup that was likely noticed during the rename. This continues the series' trend of careful attention to detail in organizing the build system configuration. The changes are mechanical and unlikely to be controversial, maintaining compatibility with the existing header checking functionality while making the code more self-documenting.
