This is a test infrastructure patch introducing a new helper tool for packfile testing. Derrick Stolee adds `test-tool pack-deltas`, a 140-line utility that lets tests precisely construct packfiles with specific delta structures. The tool reads instructions from stdin to create REF_DELTA entries (the only type implemented so far) in a custom packfile, bypassing `git pack-objects`'s usual delta selection heuristics.

The motivation is to enable more controlled testing of `git index-pack`'s delta handling, particularly for edge cases that are hard to produce via normal packfile generation. The commit notes this will be used to test a specific `index-pack` bug with REF_DELTA chains, though that bugfix comes in later patches. The implementation handles basic packfile construction with proper headers, compression, and hash writing.

This appears to be a well-constructed foundation for the subsequent bugfix - the helper is focused on the specific delta types needed for the upcoming test case while leaving room for future expansion (noted by the stubbed-out OFS_DELTA and FULL type handlers). The patch follows Git's test helper conventions and integrates cleanly with the build system.
