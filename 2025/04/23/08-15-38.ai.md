This is part 5 of Karthik Nayak's series implementing header checking in Meson builds, focusing on the 'hdr-check' target functionality. The patch ports the Makefile's header compilation check to Meson while addressing out-of-tree build considerations.

The implementation:
1. Adds 'xdiff/' to third_party_excludes to skip external dependency headers
2. Defines exclude_from_check_headers with platform-specific and crypto backend exclusions
3. Creates a two-stage compilation process (hcc/hco targets) for each header
4. Only activates when headers_to_check is populated and using GCC syntax
5. Properly chains dependencies between targets
6. Maintains the same exclusion patterns as Makefile (compat/, unicode-width.h)
7. Handles conditional crypto backend header exclusions (openssl/nettle/gcrypt)

The patch builds on previous refinements in the series by:
- Using the finalized variable names (third_party_excludes, headers_to_check)
- Maintaining centralized header definitions in root meson.build
- Following the established pattern of creating custom targets for compilation checks
- Preserving the CI workflow considerations from earlier patches

Key technical details:
- Uses meson's custom_target() for compilation steps
- Implements header exclusion logic via startswith() checks
- Generates temporary .cc files with include directives
- Outputs to /dev/null since we only care about compilation success
- Aliases the target collection as 'hdr-check' for compatibility
- Skips checks when Git isn't available (headers_to_check empty)

The implementation appears complete and well-integrated with the build system architecture established in previous patches. It handles the same edge cases as the Makefile version while properly accounting for Meson's out-of-tree nature. The patch maintains the series' focus on clear variable naming and centralized configuration.
