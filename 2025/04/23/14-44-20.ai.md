This appears to be the last remaining UX polish item before the benchmark integration can be considered complete, as all other technical concerns have been addressed in the v3 series. The discussion focuses on whether to maintain consistency with Meson's current behavior or adopt Git's more verbose error reporting style for this case.

- Proposed alternative: Explicit error message via `time.found()` check
- Comparison point: Similar to `msgfmt` handling in internationalization setup
