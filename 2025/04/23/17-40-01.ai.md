This is a bugfix series addressing a latent issue in `git index-pack`'s handling of REF_DELTA chains. The cover letter explains that while processing packfiles during fetches, `index-pack` can incorrectly die() on legitimate packfiles containing inter-pack REF_DELTA references, which are uncommon but valid.

The series takes a thorough approach by first introducing a new test helper (`test-tool pack-deltas`) specifically designed to construct packfiles with precise delta configurations. This utility will make it easier to create targeted test cases for delta-related behaviors in the future. The second patch adds a failing test demonstrating the REF_DELTA chain issue, while the third patch modifies `index-pack` to properly handle these chains without failing.

The changes touch core packfile handling code in builtin/index-pack.c and add significant test infrastructure (140 lines of new test helper code plus test cases). The approach suggests this is a well-considered fix - it not only solves the immediate problem but also improves the project's ability to test similar edge cases in the future. The patch series is cleanly structured with each commit serving a distinct purpose in the debugging and fixing process.
