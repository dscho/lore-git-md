Patrick Steinhardt is working on fixing a bug in `git index-pack` where it incorrectly fails when processing valid packfiles containing REF_DELTA chains. The issue occurs when objects in the chain (like A->B->C) already exist in the repository - `index-pack` wrongly detects this as a cycle.

The series starts by introducing a new test helper called `test-tool pack-deltas` that lets developers precisely construct packfiles with specific delta structures. This tool, which currently supports REF_DELTAs, will be used to create the problematic test cases. The second patch adds a failing test that demonstrates the bug by creating a repository with a REF_DELTA chain where some objects exist in the client repository while others come from a thin pack.

The test shows that `index-pack` currently fails when it shouldn't, marking the expected behavior as a known failure. This sets up for the actual fix in upcoming patches. The approach is methodical - first building the test infrastructure, then demonstrating the bug, before fixing it. The changes touch core packfile handling code while improving the project's ability to test similar edge cases in the future.
