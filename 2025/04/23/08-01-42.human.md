This is a platform compatibility patch series (v2) enabling Windows/ARM64 support, co-authored by Dennis Ameling and Johannes Schindelin. The series builds on Git for Windows' existing ARM64 work and takes advantage of newly available GitHub Actions runners for testing.

The 6-patch series introduces several key changes: adding built-in bswap function detection for ARM64, configuring the build system for clangarm64, disabling the unmaintained nedmalloc allocator on this platform, handling MSVC builds, adjusting config file locations, and reducing max tree depth to prevent stack overflows. The v2 revision contains a minor cleanup in the tree depth patch, replacing an `#else #if` with `#elif`.

The changes appear well-considered, following established patterns for Windows toolchain support while addressing ARM64-specific considerations. The allocator discussion from v1 thread suggests this is part of a broader transition away from nedmalloc, with Git for Windows already using mimalloc. The tree depth adjustment is noted as a temporary measure until recursive traversal can be replaced with an iterative solution.

Maintainer Junio Hamano previously acknowledged the v1 series as "cleanly structured," and this revision addresses a style nit while maintaining the same technical approach. The work enables Git to build and pass tests on Windows/ARM64 systems, with future work likely needed for allocator transitions and tree traversal improvements.
