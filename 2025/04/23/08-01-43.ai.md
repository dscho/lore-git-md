Platform compatibility patch adding built-in bswap support for Windows/ARM64 compilers. This is the first of six patches in v2 of a series enabling Git on Windows/ARM64 systems.

The patch modifies `compat/bswap.h` to detect and use compiler-builtin byte swap functions (`__builtin_bswap32/64`) when available, which is particularly useful for CLANGARM64 on Windows. It implements a fallback chain: first checking for builtins via `__has_builtin` (supported in Clang 10+/GCC 10+), then falling back to the existing x86-specific inline functions. The change maintains compatibility with older compilers through a `__has_builtin` fallback definition.

Key technical details:
- Adds compiler feature detection for built-in byte swap functions
- Preserves existing x86-specific inline implementations as fallback
- Specifically benefits CLANGARM64 compilation on Windows
- Part of broader Windows/ARM64 support effort using new GitHub Actions runners
- Follows established pattern of compiler feature detection in Git's codebase
