This is a test infrastructure patch introducing a new `test-tool pack-deltas` helper for constructing packfiles with specific delta structures. The tool is designed to help test `git index-pack`'s handling of edge cases, particularly REF_DELTA chains, by allowing precise control over packfile contents rather than relying on `git pack-objects`'s heuristic-based delta selection.

The 140-line implementation in `t/helper/test-pack-deltas.c` provides a command-line interface that reads instructions from stdin to construct packfiles with specified delta relationships. Currently it only implements REF_DELTA support (the immediate need for testing), though the code structure leaves room for adding OFS_DELTA and FULL object support later. The tool uses Git's existing delta generation and compression routines to create valid packfile entries.

This patch is part of a series addressing a bug in `index-pack`'s REF_DELTA chain handling, and this first commit focuses on building the test infrastructure needed to reproduce the issue. The implementation appears thorough, with proper error handling and cleanup, though it currently lacks accompanying tests for the test helper itself (likely coming in later series patches). The changes touch core packfile infrastructure code but are well-contained within the test helper framework.
