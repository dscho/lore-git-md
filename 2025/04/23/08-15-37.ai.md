This is a refactoring patch in Karthik Nayak's series implementing header checking in Meson builds. The patch renames the variable `third_party_sources` to `third_party_excludes` to better reflect its actual purpose of listing paths to exclude from header checking. The change affects both the root meson.build file and contrib/coccinelle/meson.build, where the variable is used in `git ls-files` commands to filter out third-party code.

The patch also removes a duplicate entry for `:!t/unit-tests/clar` from the exclusion list. This continues the series' trend of improving variable naming and organization, following the previous patch's move of this variable to the root meson.build file. The change is straightforward and maintains consistency with the series' goal of centralizing header checking configuration while making the build system more maintainable.
