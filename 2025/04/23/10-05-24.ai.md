This is a build system patch adding header checking support to Meson, part of Karthik Nayak's ongoing series to port Makefile functionality to Meson. The patch implements the 'hdr-check' target that verifies headers can be compiled independently, matching Makefile behavior while adding necessary dependency handling for Meson's out-of-tree builds.

Key technical details include: adding xdiff/ to third_party_excludes (skipping this external dependency from checks), implementing header exclusion patterns (compat/, unicode-width.h, and crypto-specific headers based on backend), and creating a two-stage compilation process via custom Meson targets (hcc/hco). The check only when headers_to_check is populated and using GCC syntax, with output directed to /dev/null since only compilation success matters.

Phillip Wood notes in his review that while xdiff is skipped from hdr-check (as it fails these checks), the Makefile does run coccinelle on xdiff files despite it being external code. He observes this is likely fine since most coccinelle rules are Git-specific anyway. The patch maintains consistency with Makefile's exclusions while properly adapting the implementation to Meson's build model.

The implementation completes the core functionality for header checking in Meson, with subsequent patches in the series handling target aliasing and CI integration. Phillip's review confirms the xdiff handling approach is reasonable given the code's hybrid status as both external dependency and Git-maintained copy.
