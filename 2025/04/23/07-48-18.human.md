This is the eighth patch in Patrick Steinhardt's 13-part series refactoring the object store subsystem, part of the ongoing effort to remove `the_repository` global and clean up object file handling.

The patch modifies `git show-ref` to stop unnecessarily fetching promisor objects when verifying refs. Currently, the command uses `repo_has_object_file()` which automatically fetches missing objects from promisor remotes - a behavior that doesn't make sense for ref verification since refs should never point to missing objects in the first place. The change switches to `has_object()` with `HAS_OBJECT_RECHECK_PACKED` flag, which verifies object existence without triggering fetches.

This is a straightforward change that aligns with the series' goal of cleaning up object existence checks. The patch is small (just one line changed) and well-justified, though it might be worth checking if similar changes are needed in other ref-printing commands. The change maintains the existing error behavior when refs point to missing objects, just without the unwanted fetch side effect.
