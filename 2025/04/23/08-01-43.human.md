Platform compatibility patch adding built-in bswap support for Windows/ARM64. This is the first of six patches in v2 of a series to enable Git on Windows/ARM64 systems.

The patch modifies `compat/bswap.h` to detect and use compiler-builtin byte swap functions (`__builtin_bswap32/64`) when available, which is particularly useful for the CLANGARM64 target on Windows. It maintains fallback implementations for older compilers and x86 architectures. The change is cleanly structured with proper documentation of the `__has_builtin` check.

This appears to be a straightforward technical improvement that follows established patterns in the codebase. The commit message clearly explains the change and its motivation. As part of the larger Windows/ARM64 support effort, this foundational change helps enable the rest of the series' platform compatibility work.
