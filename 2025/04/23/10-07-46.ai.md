- Updated documentation clarifying partial clone behavior defaults
- Flag logic restructuring that makes the control flow more transparent
- Preservation of the repository startup check guard clause

The review indicates approval of the approach while noting this is preparatory work for conversions that will follow in later patches. The thread context shows this is part of a systematic conversion effort touching 22 call sites across show-ref.c, refs.c, http-walker.c and other components, with particular attention to partial clone and promisor pack handling.
