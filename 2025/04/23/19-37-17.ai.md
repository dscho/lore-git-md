This is a test case addition in the ongoing `index-pack` REF_DELTA chain handling bugfix series. Junio Hamano is reviewing Derrick Stolee's test patch that demonstrates the issue where `index-pack` incorrectly detects cycles in valid REF_DELTA chains (A->B->C) when intermediate objects exist locally.

The test creates a server repo with commits, then constructs a thin pack containing REF_DELTA chains where A depends on B and B depends on C. The client repo already contains B and C, so the pack should be processable, but currently fails with false cycle detection. Junio confirms the test setup makes sense, though suggests a minor improvement to the test script layout by eliminating the temporary file.

The test uses the new `test-tool pack-deltas` helper introduced earlier in the series to generate the specific delta structure needed. This patch is part of the validation for the core fix that will follow in patch 3/3, showing both the broken behavior and providing a case that should work once the fix is applied. Junio's review focuses on test clarity rather than functionality, indicating the test is otherwise sound.
