This is the fourth patch in Patrick Steinhardt's 13-part series refactoring the object store subsystem, part of the ongoing effort to remove `the_repository` global. The patch focuses on code organization by relocating function declarations to their proper header files.

The change moves several loose object handling functions from object-store.h to object-file.h, and packed object iteration functions to packfile.h. This creates clearer separation between subsystems - loose object operations now live with other file-based object code, while pack-specific declarations stay with packfile operations. The patch updates includes in 8 files to point to the new header locations.

This is a straightforward structural cleanup that doesn't change functionality. The changes are mechanical but important for maintaining good code organization as the object store evolves. The patch follows the series' pattern of reducing object-store.h's scope by moving declarations to more specific headers.

Reviewers will want to verify the header choices make logical sense and that no necessary includes were missed in the transition. The wide impact across multiple files means careful checking of the build is warranted, though the changes appear well-contained to header organization.
