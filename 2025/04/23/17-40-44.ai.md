This is the final implementation patch in Karthik Nayak's series porting the 'hdr-check' functionality from Makefile to Meson builds. The patch adds the core implementation for header compilation checking in meson.build, matching the Makefile's behavior while accounting for Meson's out-of-tree build requirements.

The key technical components are:
1. Adds xdiff/ to third_party_excludes, following Phillip Wood's confirmation that while the Makefile runs Coccinelle on xdiff files, skipping them for hdr-check is appropriate given their hybrid status as external-but-maintained code.
2. Implements exclude_from_check_headers with the same patterns as Makefile (compat/, unicode-width.h) plus conditional exclusions for crypto backend headers based on build configuration.
3. Creates a two-stage compilation process using meson.custom_target():
   - hcc target generates temporary .cc files with include directives
   - hco target compiles these with proper include paths and flags, outputting to /dev/null
4. Only activates when headers_to_check is populated and using GCC syntax
5. Provides 'hdr-check' target alias for backward compatibility

The discussion with Phillip Wood confirms the xdiff exclusion approach and suggests removing xdiff from Makefile coccinelle checks could be done separately. The implementation now has final approval from both Phillip Wood and Junio C Hamano, with all earlier feedback incorporated. This completes the series' goal of bringing Makefile's header checking capability to Meson while following Meson best practices for target definition and dependency handling.
