This is a build system patch series that adds header checking support to Git's Meson build system, matching the existing Makefile functionality. Karthik Nayak's v5 series introduces several refinements to bridge the remaining gaps between the two build systems.

The series adds 'hdr-check' to Meson (with 'check-headers' as a better-named alias) to verify header file integrity. The implementation handles generated files, platform exclusions, and proper dependency chaining. Key changes in this version include:

1. A new CI fix that ensures Git is installed before repository checkout to prevent GitHub Actions from using tarballs instead of clones
2. Better handling of header checks in non-repository contexts (like tarballs)
3. Variable renaming for clarity (headers_to_check, third_party_excludes)
4. Proper .git directory checking before populating header lists

The series builds on extensive prior discussion about CI workflows, package manager detection (now using POSIX-standard `command -v`), and repository detection strategies. The implementation appears thorough, with careful attention to edge cases and cross-platform compatibility. The changes are well-documented in commit messages and maintain consistency with existing practices while cleaning up some technical debt in the Meson build files.

This represents the culmination of several rounds of review, incorporating input from multiple contributors about naming, CI behavior, and implementation details. The patch series looks ready for final consideration, with all major technical questions from earlier rounds now addressed.
