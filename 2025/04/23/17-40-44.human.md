This is the final patch in Karthik Nayak's series porting the 'hdr-check' functionality from Makefile to Meson builds. The patch implements the actual header checking mechanism in meson.build, following the same exclusion patterns as the Makefile version while adding proper dependency handling needed for Meson's out-of-tree builds.

The implementation checks each header by:
1. Creating a temporary .cc file that includes git-compat-util.h and the target header
2. Attempting to compile it with the same flags used for libgit
3. Skipping platform-specific headers and crypto backend headers that aren't in use
4. Adding xdiff/ to the exclusions (as discussed, since it's effectively third-party code)

Phillip Wood confirms in this email that excluding xdiff/ from both hdr-check and coccinelle checks makes sense given its hybrid status as effectively third-party code, though notes this differs slightly from the Makefile behavior. Karthik agrees but suggests any Makefile alignment should be handled separately.

The patch has already received approvals from both Phillip Wood and Junio C Hamano, making this effectively the final version ready for merging. The implementation achieves functional parity with the Makefile version while properly adapting to Meson's build model.
