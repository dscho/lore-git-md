Refactoring patch in the Meson build system header checking series. This is part 2 of 6 in Karthik Nayak's v5 series implementing header verification in Meson builds.

This prevents potential naming collisions since Meson exports subdirectory variables to the top level. The change follows the thread's established pattern of variable standardization and makes the build system more explicit about which components these variables belong to.

The modification is consistent with the series' overall goal of bringing Makefile's 'hdr-check' capability to Meson while improving code organization. The change is straightforward and uncontroversial, just renaming variables while maintaining identical functionality.
