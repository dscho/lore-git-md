This is part 5 of Karthik Nayak's series to implement header checking in Meson builds, bringing parity with the Makefile's 'hdr-check' target. The patch adds the core implementation for checking that individual header files can be compiled independently in the Meson build system.

The implementation handles several key requirements: it skips third-party headers (now including xdiff/), excludes platform-specific headers based on crypto backend selection, and properly chains dependencies for out-of-tree builds. The check works by generating temporary source files that include each header and verifying they compile cleanly.

This version incorporates feedback from previous iterations, with clear variable naming (third_party_excludes, headers_to_check) and proper handling of generated files. The patch maintains the existing behavior while adapting it to Meson's build model, including proper dependency tracking that wasn't needed in the Makefile version.

The implementation appears thorough, with careful attention to edge cases like different crypto backends and generated headers. It follows the established pattern of the series by centralizing configuration in meson.build while keeping Coccinelle-specific logic in its subdirectory. The patch seems ready for inclusion, completing one of the final pieces needed for full feature parity between Make and Meson builds.
