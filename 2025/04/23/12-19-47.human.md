This is the third and final patch in a series adding OAuth2 support and Outlook compatibility fixes to `git send-email`. The patch introduces a new `smtp-passeval` option that allows dynamically generating OAuth2 tokens via external scripts, similar to functionality in other email clients.

The change adds a configuration option that lets users specify a command to run that will generate an OAuth2 token, which is then used for SMTP authentication. This is particularly useful for services like Outlook that require OAuth2 tokens rather than static passwords. The patch includes both implementation in `git-send-email.perl` and corresponding documentation updates.

The implementation shows careful consideration of security practices - it requires TLS encryption when using OAuth2 and properly handles script execution failures. The example configuration shows integration with a real-world OAuth2 token refresh script (M365-IMAP), demonstrating practical use.

This completes the series' goal of modernizing `send-email` authentication to work with providers like Outlook that mandate OAuth2. The patch appears well-crafted with proper error handling and documentation, though reviewers may want to scrutinize the security implications of executing arbitrary commands for token generation.
