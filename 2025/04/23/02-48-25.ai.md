This is Junio Hamano's regular "What's cooking in git.git" status update, summarizing the current state of various patch series in the Git development pipeline. The email provides a categorized overview of new topics being introduced, patches that are cooking (under review), and their current integration status in Git's development branches ('next' and 'seen').

The new topics section includes several notable changes:
- A fix for `GIT_PERF_*` environment variable handling in performance tests
- Cleanups around `repo_config()` usage in builtins
- Meson build system improvements and Windows/ARM64 support updates
- A launchctl scheduling fix for maintenance tasks
- String-list API cleanups and test consolidation

The cooking section shows more substantial ongoing work:
- Documentation of `core.hooksPath=/dev/null` convention
- Midx and pack-bitmap optimizations around cruft packs and lookup tables
- Continued reduction of Perl dependencies in the codebase
- Parse-options API improvements for integer handling
- A major reftable API overhaul
- Path-based delta compression experiments in pack-objects

Several patches are marked as ready to merge to 'next' or 'master', while others await further review or rerolls. The email serves as both a progress report and a call for feedback on the various topics, with Junio noting specific concerns about some patches (like the meson hdr-check breaking CI) and expectations for rerolls on others.
