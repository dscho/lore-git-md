This is a CI/build system patch that's part of Karthik Nayak's ongoing series to implement header checking in Meson builds. The current patch focuses on improving the GitHub CI workflow to ensure Git is installed before repository checkout.

The patch modifies the GitHub Actions workflow to install Git in the container before checking out the repository. This ensures the checkout action will clone the repository (rather than falling back to a tarball download) and makes the behavior consistent with GitLab CI. The implementation handles multiple package managers (apk, dnf, apt-get) and includes package cache updates where needed.

Phillip Wood has reviewed the changes and suggested minor wording tweaks to the commit message (removing redundant words, clarifying the checkout fallback behavior, and using "source tree" instead of "repository"). The technical implementation has been approved, with Karthik noting he'll incorporate the suggested wording changes if a re-roll is needed for other reasons.

This is the first patch in what appears to be a technically complete series that has received final approval from Phillip Wood, with only minor editorial comments remaining. The changes help ensure consistent build environments across CI systems while following Meson best practices.
