This is a platform compatibility fixup in the Windows/ARM64 patch series. Junio Hamano points out that two patches in the series (one about disabling nedmalloc on ARM64, another about MSVC toolchain support) need style fixes to comply with recent GNU make requirements. The conditionals in config.mak.uname should use spaces rather than tabs for indentation, following the pattern established in commit c18400c6.

The fixups maintain the technical changes from the original patches while adjusting the formatting. The nedmalloc patch still disables the allocator for CLANGARM64 builds, and the MSVC patch still handles the /clangarm64 prefix, just with corrected indentation. Junio provides clean range-diffs showing the exact changes being applied.

This is a straightforward maintenance correction to an otherwise solid series that's adding Windows/ARM64 support. The changes don't affect functionality but ensure consistency with the project's build system conventions. The series as a whole appears well-considered, with these being minor polish items caught during review.
