This is a build system patch adding header-checking support to Meson, part of Karthik Nayak's ongoing series to port Makefile functionality to Meson. Phillip Wood provides review feedback on the handling of xdiff headers, noting they exist in a gray area - while the Makefile runs Coccinelle checks on them, header checking fails, so skipping them in Meson (as Karthik proposes) seems reasonable given xdiff's status as effectively Git-maintained third-party code.

The patch itself implements header compilation checking via Meson custom targets, mirroring the Makefile's 'hdr-check' functionality while accounting for Meson's out-of-tree builds by explicitly adding dependencies. It includes platform-specific exclusions (compat/, unicode-width.h) and conditional crypto header exclusions based on the active backend. The implementation only activates when headers_to_check is populated and when using GCC syntax.

This appears to be a well-considered port of existing functionality, with Phillip's review confirming the xdiff handling approach. The thread shows this is the fifth iteration of the series, having incorporated extensive prior feedback, suggesting it's nearing final form.
