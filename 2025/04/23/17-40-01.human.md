This is a bugfix series addressing a latent issue in `git index-pack`'s handling of REF_DELTA chains in packfiles. The problem occurs when processing packfiles that contain REF_DELTAs referencing objects within the same pack - an uncommon but valid case that currently causes `index-pack` to crash.

The series starts by introducing a new test helper (`test-tool pack-deltas`) to make it easier to construct custom packfiles with specific delta arrangements. This utility is then used to create a failing test case demonstrating the REF_DELTA chain issue. The final patch fixes the bug in `index-pack` by properly handling these intra-pack REF_DELTA references.

The changes look well-considered, with thorough test coverage including both the new test helper and the actual bugfix. The commit messages clearly explain the problem and solution. This appears to be a solid fix for an edge case that could affect users receiving specially crafted packfiles, though the issue seems rare in normal usage.
