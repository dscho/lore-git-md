This is the fourth patch in Patrick Steinhardt's 13-part refactoring series cleaning up the object store subsystem, part of the ongoing `the_repository` removal effort. The patch focuses on reorganizing function declarations to better align with their implementations.

The main change moves declarations for loose object and packfile iteration functions from object-store.h to their more logical homes: loose object functions go to object-file.h (where their implementations live) and packfile iteration functions go to packfile.h. This reduces object-store.h by 91 lines while adding 73 to object-file.h and 19 to packfile.h. The patch also updates several files to include object-file.h instead of object-store.h where appropriate.

Key technical details:
- Moves `odb_loose_cache()`, `odb_clear_loose_cache()`, and related loose object iteration functions to object-file.h
- Moves `for_each_object_in_pack()` and `for_each_packed_object()` to packfile.h
- Updates includes in builtin/count-objects.c, builtin/gc.c, object-name.c, prune-packed.c, and reachable.c
- Keeps enum `for_each_object_flags` in object-store.h since it's used by both loose and packed object iteration
- Maintains all function implementations exactly as-is - this is purely a header reorganization

The patch continues the series' pattern of reducing object-store.h's scope by moving declarations closer to their implementations. This is a straightforward structural change that should not affect runtime behavior, though reviewers will want to verify the include updates don't break any implicit dependencies.
