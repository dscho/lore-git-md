Aditya Garg's `git send-email` patch series to handle Outlook's Message-ID modification behavior has progressed through multiple iterations, with the core solution for standard Outlook domains (v6) already queued by Junio Hamano. The latest version (v7) added enterprise configurability through a tri-state `--smtp-outlook-id-tweak` option, addressing earlier concerns about hardcoded hostname checks. The implementation cleanly separates authentication concerns, with OAuth2 support now officially released in Authen-SASL 2.1800.

Yao Zi has now raised an interesting follow-up, noting that Tencent's mail service exhibits similar Message-ID modification behavior and suggesting runtime detection via cover letter probing. This would make the solution more general while maintaining backward compatibility. The proposal builds on Greg Kroah-Hartman's earlier enterprise configuration suggestions but takes a more automated approach. While the core solution is already in good shape, this new idea could potentially inform future refinements to handle a broader range of mail providers with similar threading quirks. Documentation has been polished with Eric Sunshine's feedback, and there are no remaining technical blockers for the current approach.
