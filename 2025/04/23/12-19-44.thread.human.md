This thread continues the development of a patch series adding OAuth2 support and Outlook compatibility fixes to `git send-email`. The series has seen active review, with Junio Hamano recently catching a documentation formatting issue - the `--smtp-passeval` option was incorrectly marked as taking an optional argument when it should be mandatory, consistent with Git's option syntax. This follows earlier security concerns from Junio about the credential handling approach, leading Julian Swagemakers to propose using Git's existing credential helper mechanism as an alternative to the initial `smtp-passeval` design.

Technical discussions remain ongoing, particularly around the OAuth2 implementation (awaiting Authen::SASL maintainer Greg Kroah-Hartman's review) and Outlook detection robustness (with feedback from Brian M.
