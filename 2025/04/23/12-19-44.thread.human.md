This thread documents the evolution of Aditya Garg's patch series to improve `git send-email`'s handling of Outlook Message-IDs, which went through several iterations before reaching its final form. The core issue was ensuring reliable thread tracking across different SMTP configurations while maintaining backward compatibility.

The series began with a simple boolean toggle in v3, then progressed through a transitional v4 that introduced automatic detection for standard Outlook hosts while keeping the boolean interface. By v6, the solution had evolved to use hostname checking for standard Outlook SMTP services, which Junio Hamano queued for inclusion. The final v7 patch implemented a tri-state configuration (`--smtp-outlook-id-tweak=always|never|auto`) to handle enterprise cases, which Junio approved despite his personal preference for a boolean interface design.

Throughout the series, documentation was refined based on feedback from Junio and Eric Sunshine, particularly around clarifying the behavior of automatic detection versus manual overrides. The implementation maintains backward compatibility and delegates authentication to the updated perl-authen-sasl package (version 2.1800), which now includes OAuth2 support. While some future considerations remain around documenting OAuth2 usage and potential expansion to other providers' quirks, the core technical issues have been resolved with the queued solution.
