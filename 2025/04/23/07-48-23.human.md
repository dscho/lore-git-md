This is the final patch in Patrick Steinhardt's 13-part series refactoring Git's object store subsystem as part of the `the_repository` removal effort. The series has systematically modernized object storage code by reorganizing headers, removing wrapper functions, and improving promisor object handling.

The previous 12 patches converted all callers from `repo_has_object_file()` and its `_with_flags()` variant to use the more modern `has_object()` API instead. This patch completes the cleanup by removing those now-unused functions entirely, deleting 31 lines of code across object-store.c and object-store.h.

The removal is straightforward since all callers have been migrated, and the commit message notes this was the explicit goal of the preceding work. The patch follows the series' pattern of simplifying the object store interface while maintaining careful control over promisor object fetching behavior. This change represents the culmination of a significant architectural cleanup that touched many parts of Git's object storage system.
