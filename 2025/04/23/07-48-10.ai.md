This is a refactoring patch series aimed at cleaning up the object store subsystem, with a focus on preparing for the removal of `the_repository` global. The series comes with 13 patches that perform various cleanups and deprecations.

The main technical changes revolve around moving definitions to more appropriate headers, removing redundant functions, and deprecating `repo_has_object_file()` in favor of `has_object()`. The new `has_object()` function is highlighted as an improvement because it avoids reloading packfiles by default and makes promisor object fetching behavior more explicit. Several callers across the codebase are updated to use the new function.

The series touches numerous files (37 modified) with a net reduction of 281 lines, showing significant consolidation. Key subsystems affected include the object store itself (with major header file reorganization), builtin commands like `index-pack` and `show-ref`, and ref-related code. The changes appear to be straightforward mechanical updates rather than behavior-altering modifications, though some callers are adjusted to be more explicit about object fetching behavior.

This appears to be part of Patrick Steinhardt's ongoing work to modernize Git's object storage code, building on previous cleanup work (referenced by the ps/object-file-cleanup base). The changes are well-scoped and focused, with each patch handling a specific aspect of the cleanup. The series seems ready for review, though the wide impact across the codebase may warrant careful consideration of potential edge cases.
