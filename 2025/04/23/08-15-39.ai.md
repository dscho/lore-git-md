This is the final patch in Karthik Nayak's series porting header checking to Meson builds, focusing on target naming consistency. The patch introduces 'check-headers' as a more readable alias for the existing 'hdr-check' target used to verify header compilability. It adds the new target to both Makefile and Meson builds while maintaining backward compatibility through the old name, with a TODO comment indicating plans to deprecate 'hdr-check' after two releases.

The implementation updates three files:
1. Makefile: Adds 'check-headers' as a phony target aliased to 'hdr-check'
2. ci/run-static-analysis.sh: Updates the static analysis script to use the new target name
3. meson.build: Implements the same aliasing in Meson, with identical deprecation plans

The changes are straightforward mechanical replacements that don't affect functionality, just the interface. The patch maintains the series' focus on build system modernization while improving usability through clearer target naming. The deprecation plan shows thoughtful consideration of backward compatibility for internal tooling.
