This is a platform compatibility patch in the Windows/ARM64 support series, specifically addressing system configuration file locations. 

The patch modifies where Git for Windows looks for system-wide configuration files (`gitconfig` and `gitattributes`) on ARM64 systems. Previously, these files were placed in `/mingw64/etc/` for x64 builds and would have defaulted to `/clangarm64/etc/` for ARM64 builds. The change ensures ARM64 builds also use the more standard `/etc/` location that was introduced for x64 builds in 2021.

The modification is straightforward - it updates the conditional logic in `config.mak.uname` to recognize ARM64 toolchain paths (which use `/clangarm64/` prefix) and treat them the same way as the x64 paths. This fixes GitHub issue #5431 and maintains consistency across architectures.

As part of the larger Windows/ARM64 effort, this is a small but important quality-of-life improvement that ensures users find configuration files where they expect them, regardless of architecture. The change is narrowly scoped to the build system configuration and doesn't affect runtime behavior beyond file location.
