This is the third patch in a series adding OAuth2 support and Outlook compatibility fixes to `git send-email`. The patch introduces a new `smtp-passeval` option for dynamically generating OAuth2 tokens via external scripts, similar to msmtp's passwordeval functionality.

The implementation adds a new `--smtp-passeval` command-line option and corresponding `sendemail.smtpPassEval` config setting that executes a user-specified command to generate an authentication token. The command's output becomes the SMTP password, overriding any static password set via `--smtp-pass`. The patch includes documentation updates and modifies `git-send-email.perl` to handle the new option, with error handling for script execution failures.

Key technical details include:
- New `$smtp_authpasseval` variable and corresponding config/CLI option
- Execution of user-provided command via backticks in `smtp_auth_maybe()`
- Error handling for non-zero exit codes from the token generation script
- Documentation noting the override behavior relative to `smtpPass`
- Example configuration showing integration with a Python token refresh script

The patch builds on the OAuth2 authentication work from earlier in the series, providing a way to handle expiring OAuth2 tokens without requiring manual updates. Security considerations around command execution remain an open question from previous reviews, with Junio Hamano having raised concerns that still need addressing. The author demonstrates successful usage by sending this patch via Outlook using the new functionality.
