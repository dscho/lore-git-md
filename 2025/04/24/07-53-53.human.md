Feature patch implementing OAuth2 authentication for `git send-email`. This is the first of three patches in a series aimed at making Git's email functionality work with modern email providers like Gmail and Outlook.

The patch adds direct SMTP bearer token authentication support for OAuth2 (OAUTHBEARER and XOAUTH2 protocols), bypassing Perl's Authen::SASL module which doesn't support these methods. It enforces TLS encryption for OAuth2 connections and provides helper functions to generate the proper authentication strings following RFCs 5801/7628 (OAUTHBEARER) and Google's XOAUTH2 protocol. The implementation includes example configurations for both Gmail and Office 365 workflows.

This version (v5) shows improved code formatting with 80-character line wrapping and adds a new `is_smtp_bearer_auth()` helper function. The patch has been tested successfully with real-world usage (the email itself was sent using the patched version). While the technical approach appears sound, the patch still awaits review from Authen::SASL maintainer Greg Kroah-Hartman to confirm the direct SMTP bearer auth implementation is correct.
