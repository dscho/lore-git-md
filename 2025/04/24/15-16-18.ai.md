This is a build system patch for the meson build configuration, specifically addressing Perl library path customization. The change brings meson's behavior in line with the existing Makefile build system by allowing customization of the Perl library installation directory.

The patch introduces a new meson option `perllibdir` that defaults to `<datadir>/perl5` but can be overridden, which is particularly useful for distributions like Fedora that install non-core Perl libraries in `/usr/share/perl5/vendor_perl`. The change affects 10 files, mostly updating paths in various Perl-related meson build files to use the new `perllibdir` variable instead of hardcoding the path.

Key technical details include:
- New meson option `perllibdir` added to meson_options.txt
- Default remains `<datadir>/perl5` if not specified
- Changes propagate through all Perl module installation paths
- Affects both core Git Perl files and CPAN-related modules
- Maintains compatibility with the existing Makefile behavior
