Thread identity: Bug report about HTTP/2 support regression in Git for Windows 2.49.0, reported by Lars Eriksen.

Core problem: After upgrading to Git for Windows 2.49.0, the embedded cURL no longer supports HTTP/2, breaking authentication against corporate backends that require HTTP/2. This worked in version 2.39.0.windows.2. The reporter cannot install a custom cURL due to corporate restrictions.

Key technical details: System info shows libcurl 8.12.1 and OpenSSL 3.2.4, but `curl --version` indicates HTTP/2 support is missing. This appears to be a Windows-specific build configuration regression, not a general Git bug. The reporter provided clear reproduction steps and version information.

Current status: Unresolved regression affecting users who rely on HTTP/2 for authentication in corporate environments with restricted software installation policies. No known workaround in the reporter's environment.

Impact: Breaks existing functionality that worked in previous versions (2.39.0.windows.2), with no available workaround due to corporate restrictions on installing alternative cURL versions.
