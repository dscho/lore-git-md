This is a response in the ongoing thread about HTTP/2 support regression in Git for Windows. Johannes Schindelin provides technical clarification about the issue, noting that the HTTP/2 support depends on which SSL backend is being used (OpenSSL vs Secure Channel). 

The key insight is that while the Secure Channel version of cURL in Git for Windows is compiled without HTTP/2 support, the OpenSSL version does include it. Schindelin suggests trying `http.sslBackend = openssl` as a potential workaround and points to build logs showing the different configurations. 

He also notes that the bug reporting template could be improved to include the SSL backend information, which would help diagnose such issues more easily. This response provides actionable technical details while confirming the reporter's observation about HTTP/2 support being missing in the default configuration.
