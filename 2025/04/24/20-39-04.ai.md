This is a feature patch improving signature handling in `git fast-export` and `git fast-import`. It follows up on the recently merged support for signed commits (commit d9cb0e6ff8) which had some format limitations.

The patch makes several key changes:
1. `fast-export` now properly identifies signature types (OpenPGP, X.509, SSH) using existing gpg-interface code rather than just labeling everything as "sha1"
2. `fast-import` validates signature algorithm names and warns about unknown ones while still preserving them
3. Documentation is updated to clarify supported signature types and their format in the export stream
4. New tests verify X.509 and SSH signature handling

The changes make the signature handling more accurate and consistent with Git's existing signature infrastructure. The patch adds new public functions to gpg-interface.h (`get_signature_name()` and `valid_signature_name()`) that will be useful for other signature-related work. While signatures still aren't verified during import, the groundwork is laid for future verification support.

This appears to be a well-constructed follow-up to the initial signed commit support, with thorough test coverage and documentation updates. The changes are focused and build logically on existing infrastructure.
