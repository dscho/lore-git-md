This is a build system patch that adds flexibility to the meson build system for Perl library installation paths. 

The patch allows customizing where Perl libraries are installed by adding a new `perllibdir` meson option, matching functionality that already exists in the Makefile build system. The motivation is to support distributions like Fedora that want to install non-core Perl libraries in specific directories like `/usr/share/perl5/vendor_perl`.

The changes are straightforward - they add the new configuration option and update all the Perl-related meson build files to use it instead of hardcoding the installation path. The default behavior remains unchanged (installing to `datadir/perl5`) when the option isn't set.

This appears to be a well-scoped, mechanical change that brings meson in line with existing Makefile functionality. The patch touches several files but all changes follow the same simple substitution pattern. It should be uncontroversial for distributions that need this flexibility.
