This is a test modernization patch in the ongoing string-list test conversion series. The patch moves the "test_split" functionality from shell scripts to C unit tests using the clar framework, as part of the broader effort to replace shell-based tests with C unit tests.

The patch introduces key helper functions `t_vcreate_string_list_dup()` and `t_create_string_list_dup()` to simplify test setup by creating string lists from varargs. It also includes validation functions like `t_check_string_list()` for comparing actual vs expected results. The implementation follows Patrick Steinhardt's suggested varargs approach for test inputs.

Junio C Hamano provided detailed review feedback on naming and implementation choices, suggesting:
- Renaming `t_check_string_list()` to something more specific like `string_list_equal()`
- Removing unnecessary intermediate variables that the optimizer would handle
- Being more judicious about where to use t_string_list_clear()` versus the direct `string_list_clear()` call
- Avoiding over-engineering test helpers with excessive validation

The author acknowledges these points and plans to incorporate them in the next version. This patch represents a solid step in the test conversion effort, with the review discussion focusing on refinement rather than fundamental issues. The helper functions introduced here will be reused in subsequent patches in the series.
