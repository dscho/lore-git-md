This is a build system patch series that addresses shell path detection in Meson builds. Patrick Steinhardt reports that Git's Meson build system currently looks up the shell via PATH, which can cause issues when the build host and target host have different PATH configurations. The problem was reported by both GitLab users and Debian maintainers.

The series consists of two patches: first adding better reporting of detected runtime paths, then changing the shell detection to prefer the POSIX-specified `/bin/sh` path rather than PATH lookup. The change is motivated by real-world compatibility issues, and the proposed solution follows the pattern of other build systems that hardcode standard paths.

The patchset is small (8 lines across one file) and appears well-motivated by concrete problems. The cover letter helpfully includes the workaround currently used (a Meson cross file) and references prior discussion about the Debian issue. This looks like a straightforward improvement to build reliability.
