Windows-specific bugfix for certificate verification in Git for Windows update mechanism.

Johannes Schindelin responds to a user report about certificate verification failures when running `git update-git-for-windows` on Brazilian Portuguese locale. The error manifests as CRYPT_E_NO_REVOCATION_CHECK with corrupted Portuguese error text, suggesting a locale-specific handling problem in the Windows schannel security provider.

The proposed solution is to manually edit the update script (as administrator) to add curl's `--ssl-revoke-best-effort` flag to bypass strict certificate revocation checks. This workaround is suggested for both curl invocations in the script, with a link to curl's documentation explaining the option.

This appears to be a Git-for-Windows-specific issue rather than a general Git problem, and the response helpfully provides concrete technical guidance for affected users while avoiding deeper system modifications. The solution is pragmatic but leaves open whether this should be the default behavior or if there are underlying schannel configuration issues to address.
