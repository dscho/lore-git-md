This is a build system patch series that addresses shell path detection in Meson builds. The series consists of two patches that modify the Meson build configuration to make Git's shell detection more reliable across different host systems.

The motivation comes from real-world issues encountered at GitLab and previously reported by Debian, where Git would fail to find its shell when built with Meson because it relied on PATH lookup. The current workaround requires manual cross-file configuration, which this series aims to make unnecessary.

The first patch adds reporting of detected runtime executable paths, while the second changes the shell detection logic to prefer the POSIX-specified `/bin/sh` path over PATH-based lookup. This should make builds more reliable when the build host and target host environments differ. The changes are minimal (8 lines total across both patches) and focused specifically on the shell detection issue.

Key technical details for future reference:
- Modifies `meson.build` to report detected paths (patch 1)
- Changes shell detection to prefer `/bin/sh` (patch 2)
- References prior issue report (20250209133027.64a865aa@gmx.net)
- Affects cross-compilation scenarios where PATH differs between build and target hosts

The patch appears well-motivated by concrete problems and follows the pattern of making builds more reliable. The changes are surgical and focused on a specific pain point in the Meson build system.
