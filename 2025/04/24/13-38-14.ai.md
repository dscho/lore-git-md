This is the first patch in a two-part series improving shell path detection in Meson builds. The patch adds reporting of detected runtime executable paths (Perl, Python, and shell) in the Meson build summary output. 

The change exposes which paths Meson's `find_program()` has autodetected via PATH lookup, making it more transparent to developers which executables Git will use at runtime. The implementation adds a new "Runtime executable paths" section to the Meson summary output, showing the full paths of detected programs or "none" if not found (for optional dependencies like Perl and Python).

The patch is minimal (6 lines added) and focused specifically on improving build system diagnostics. It serves as groundwork for the second patch which will modify the shell detection logic itself. The change touches only meson.build, adding the path reporting summary while maintaining the existing detection behavior. This appears to be a straightforward quality-of-life improvement for build system debugging, particularly useful when diagnosing cross-compilation issues where build and target environments differ.
