This is a build system patch that makes Meson builds more transparent by reporting detected executable paths. It's the first of a two-part series addressing shell path issues in Meson builds, particularly relevant for cross-compilation scenarios where build and target environments differ.

The patch adds runtime path reporting for key executables (shell, Python, Perl) that Git needs to locate. Currently Meson finds these via PATH lookup during configuration, but doesn't show developers which paths were actually detected. The change surfaces this information in the build summary output, helping diagnose issues when the detected paths don't match expectations.

The implementation is straightforward - just 6 lines added to meson.build to expose the already-collected path information. This appears well-motivated by real-world problems encountered at GitLab and reported by Debian, where PATH discrepancies caused runtime failures. The change follows the series' theme of making Meson builds more reliable through targeted improvements to path handling.

As the first step in the series, this patch focuses on visibility rather than behavior changes. The companion patch will modify the actual shell detection logic to prefer /bin/sh over PATH lookups. Together they address a specific pain point in the Meson build system's handling of runtime dependencies.
