This is the first patch in a v5 series adding OAuth2 support to `git send-email`, specifically implementing SMTP bearer authentication. The patch bypasses Perl's Authen::SASL module limitations by directly implementing OAUTHBEARER (RFCs 5801/7628) and XOAUTH2 (Google's variant) authentication protocols.

Key technical details include:
- New `generate_oauthbearer_string()` and `generate_xoauth2_string()` functions that format authentication strings according to their respective specs
- TLS encryption is enforced for OAuth2 connections (per RFC7628)
- New `is_smtp_bearer_auth()` helper function to check authentication type
- Integration with git-credential-oauth for token management
- Example configurations provided for both Gmail (OAUTHBEARER) and Office 365 (XOAUTH2) workflows
- Documentation updates explaining the new OAuth2 authentication requirements

The patch demonstrates successful real-world usage by being sent from an Outlook account using the new functionality. It has been tested by M Hickford and incorporates feedback from previous iterations, including code formatting improvements (80-character wrapping). The implementation remains pending review from Authen::SASL maintainer Greg Kroah-Hartman regarding the technical correctness of bypassing the SASL module.
