This thread has converged on a solution for reliable shell path detection in Meson builds, particularly addressing cross-compilation issues encountered at GitLab and Debian. The core solution hardcodes `/bin/sh` as the preferred shell path while maintaining the ability to override it via Meson's `program_path` configuration, matching the behavior of Makefile's `SHELL_PATH` but implemented through Meson's native mechanisms. The latest version includes simplified diagnostic output for detected paths (Perl/Python/shell) and explicit documentation about the path priority rationale, addressing Justin Tobler's suggestion.

All substantive feedback has been incorporated, including Junio's request to verify functional equivalence with the Makefile approach. The changes are minimal (just 11 lines in meson.build) but effectively resolve the original cross-build discrepancies while preserving POSIX compliance and backward compatibility. The thread shows clear consensus that this approach solves the problem without introducing new concerns, and the series now appears complete.
