This is a refinement to the recently merged signed commit support in `git fast-export` and `git fast-import`. The patch improves how signature algorithms are identified and handled during fast-import/export operations.

Currently, `fast-export` labels all signatures as "sha1" regardless of their actual type (OpenPGP, X509, SSH). The patch introduces proper signature type detection using existing gpg-interface functions, outputting the correct algorithm name ("openpgp", "x509", "ssh") or "unknown" for unidentifiable signatures. On the import side, it adds validation of algorithm names while maintaining backward compatibility.

The changes include new public functions in gpg-interface.h (`get_signature_name()` and `valid_signature_name()`), documentation updates clarifying supported signature types, and new tests verifying X.509 and SSH signature handling. Elijah Newren raises some questions about test coverage and edge cases, particularly around signature preservation when commits are modified during export/import.

The patch appears well-constructed with thorough test coverage, logically extending the signature infrastructure without introducing verification at this stage. It addresses a clear limitation in the current implementation while maintaining backward compatibility.
