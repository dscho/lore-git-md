This thread reports a regression in Git for Windows 2.49.0 where the embedded cURL no longer supports HTTP/2, breaking authentication against corporate backends that require this protocol. Lars Eriksen provides detailed technical context showing the system has libcurl 8.12.1 and OpenSSL 3.2.4, but HTTP/2 support is missing despite working in version 2.39.0.windows.2. The issue is particularly impactful because corporate policies prevent installing alternative cURL versions as a workaround.

The report follows good bug reporting practices with clear reproduction details and version information. The problem appears specific to the Windows build's cURL configuration rather than being a general Git issue. Since this breaks existing functionality with no viable workaround for the reporter, it will likely require attention from the Git for Windows maintainers to investigate the build configuration changes that led to the regression.
