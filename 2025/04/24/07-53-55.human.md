Feature patch adding OAuth2 token generation support to `git send-email`. This is the third and final patch in a series enabling OAuth2 authentication for modern email providers like Outlook.

The patch introduces a new `smtp-passeval` option that lets users specify a command to generate OAuth2 tokens dynamically, similar to how `passwordeval` works in msmtp. The command's output becomes the authentication token, overriding any static password. The implementation includes documentation updates and the core execution logic in `git-send-email.perl`.

This addresses a key limitation where some providers (like Outlook) require fresh OAuth2 tokens rather than static passwords. The example shows integration with a Python script (`refresh_token.py`) to generate Office 365 tokens. While functionally complete, the security implications of command execution remain an open discussion point from earlier reviews.

The patch demonstrates real-world viability by being sent through Outlook using the new functionality. It builds on the OAuth2 foundation from earlier patches while solving the practical problem of token generation. Documentation clearly notes the override behavior versus static passwords.
