This is a minor fixup patch in the `index-pack` bugfix series from Junio Hamano. It addresses a memory leak in the new `test-tool pack-deltas` helper that was introduced earlier in the series. The helper is used to construct test cases for validating `index-pack`'s handling of REF_DELTA chains.

The patch adds a single line to properly clear a string list` that was being used to parse input for the test packfiles. Without this cleanup, the test tool would leak memory when run under leak detection tools like ASAN. Junio verified the fix by running the test suite with leak checking enabled and confirmed the test now passes cleanly.

This is a straightforward cleanup that follows up on the main series' test infrastructure work. The change is small but important for maintaining the test suite's hygiene, especially when running with sanitizers enabled. It doesn't affect the core bugfix for REF_DELTA chain handling but ensures the testing tools themselves are robust.
