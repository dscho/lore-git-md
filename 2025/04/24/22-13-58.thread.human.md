This thread focuses on improving Git's CI infrastructure to handle external dependencies more robustly. The initial work made downloads of tools like JGit, Perforce, and Git-LFS optional with proper error handling, while recent refinements improved warning presentation and updated JGit's download source to Maven Central per the maintainer's recommendation. These core changes are already in master.

The discussion has shifted to optimizing CI performance by caching dependencies. Junio Hamano noted the inefficiency of repeatedly downloading the same files across CI jobs, suggesting a once-per-platform download model. Jialuo has taken up this suggestion and is investigating implementation approaches, which may involve GitHub Actions caching or platform-specific state management. This would build on the existing atomic download-cleanup pattern while avoiding redundant network transfers.

The thread has seen active participation from key contributors: Johannes Schindelin helped refine the warning system, Matthias Sohn provided guidance on JGit sources, and Junio continues to steer the overall direction. While caching remains under discussion, the foundational work to make dependency handling more resilient is complete and merged.
