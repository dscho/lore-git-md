This is patch 2/8 in Elijah Newren's series to remove the merge-recursive backend in favor of merge-ort, representing a major refactoring milestone.

The patch converts builtin/merge-recursive.c to use merge_ort_generic() instead of merge_recursive_generic(), completing the transition of this builtin to the new merge backend. The key technical changes are:
1. Swapping the include from merge-recursive.h to merge-ort-wrappers.h
2. Replacing the merge_recursive_generic() call with merge_ort_generic()
3. Updating several test files to account for behavioral differences between the backends

The test updates reflect merge-ort's improved handling of directory/file conflicts and rename/delete cases, where it now produces two index entries per conflict rather than one. The patch also removes a test checking merge-recursive's special toplevel tree matching behavior, which merge-ort handles differently by checking throughout the tree rather than just at the toplevel.

This change is part of the final phase of a multi-year effort to replace merge-recursive, with merge-ort having been the default backend since Git 2.33. The patch appears technically sound, maintaining the same interface while switching implementations, and includes thorough test updates to verify the transition. The v2 iteration suggests the changes have been reviewed and are ready for merging.
