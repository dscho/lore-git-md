This is patch 7/8 in Elijah Newren's series to remove the legacy merge-recursive implementation in favor of merge-ort. The patch removes test infrastructure that was used to compare behavior between the two merge backends.

The key changes are:
- Deletes `GIT_TEST_MERGE_ALGORITHM` environment variable which was used to toggle between merge-recursive and merge-ort
- Removes `test_expect_merge_algorithm` helper function from t/lib-merge.sh
- Updates numerous test files to remove conditional logic based on merge algorithm
- Converts remaining `test_expect_merge_algorithm` calls to regular `test_expect_success` since they no longer need to test both algorithms
- Removes merge-recursive specific test expectations and behaviors
- Updates CI configuration to stop setting GIT_TEST_MERGE_ALGORITHM

The changes are mechanical removals of now-unneeded scaffolding since merge-ort is now the only merge backend. All test modifications align with merge-ort's behavior. The patch represents the continued cleanup after the merge-recursive code was removed in previous patches of this series.

The removal of this test infrastructure is safe because:
1) The previous patches have already removed all merge-recursive code
2) The test changes just remove now-redundant conditionals
3) The series has been through multiple iterations (v2) with review feedback incorporated
4) The overall goal of removing merge-recursive has consensus in the community

This is part of the final cleanup in the multi-year effort to replace merge-recursive with merge-ort as Git's sole merge strategy implementation.
