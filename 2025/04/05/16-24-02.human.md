This is a reply in the ongoing discussion about enhancing `git stash list` output with more metadata. Lucas Seiki Oshiro responds to Yuri's feature proposal by pointing out that much of the requested functionality is already available through existing `git log` options that `git stash list` inherits.

The reply suggests using `--stat` to show diff statistics and `--pretty=reference` for compact formatting, noting that users can further customize the output using Git's existing pretty formats. This provides a workaround without requiring changes to Git's stash implementation.

While not rejecting the original proposal outright, this response implies the enhancement might be less urgent since similar information can already be accessed through current mechanisms. The exchange highlights an important consideration for the feature proposal - whether the new metadata should be built into the default stash listing or left as an opt-in through existing formatting options.
