This is patch 7/8 in Elijah Newren's series to remove the legacy merge-recursive implementation in favor of merge-ort. The patch removes test infrastructure that was used to compare behavior between the two merge backends.

The key changes are:
- Removal of GIT_TEST_MERGE_ALGORITHM environment variable that allowed toggling between merge-recursive and merge-ort
- Removal of test_expect_merge_algorithm helper function that ran tests with different expected outcomes for each backend
- Cleanup of test files that had conditional logic based on the merge algorithm
- Updates to CI configuration to remove GIT_TEST_MERGE_ALGORITHM setting

Since merge-recursive is being completely removed, this scaffolding is no longer needed. The patch is straightforward mechanical cleanup, with no functional changes to the test suite other than removing now-irrelevant conditional logic. 

This is part of the final cleanup after merge-ort has fully replaced merge-recursive's functionality. The changes look correct and well-contained, following the pattern established in earlier patches of the series. The removal of this test infrastructure confirms that merge-ort is now the sole merge backend.
