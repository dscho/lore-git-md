Final cleanup patch in the merge-recursive removal series. This patch removes the GIT_TEST_MERGE_ALGORITHM environment variable and related test scaffolding from three builtin commands (merge, rebase, revert) now that merge-ort is the only merge backend. The variable was previously used to toggle between the old merge-recursive and merge-ort backends during testing, but with merge-recursive gone and 'recursive' remapped to mean 'ort', this infrastructure is no longer needed.

The changes are straightforward removals of environment variable checks and associated fallback logic. The patch touches the strategy selection code in builtin/merge.c (removing three separate checks for GIT_TEST_MERGE_ALGORITHM), builtin/rebase.c (removing one check), and builtin/revert.c (removing one check). All removals are clean with no residual dependencies or required behavior changes.

This represents the final technical step in the series, following the core merge-recursive removal in patch 6/8. The changes are mechanical and well-contained, with the commit message clearly explaining the rationale.
