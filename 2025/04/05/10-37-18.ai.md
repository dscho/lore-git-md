This is a test improvement patch that addresses a common shell scripting pitfall in Git's test suite. The patch modifies t/t9811-git-p4-label-import.sh to avoid using pipes in test assertions, since pipes suppress the exit codes of the left-hand command. Instead, it redirects `git tag` output to a temporary file and then greps that file, which properly preserves exit codes for test verification.

The changes affect two test cases that verify Perforce label import functionality:
1. 'two labels on the same changelist' test now writes tags to 'output' before grepping
2. 'use git config to enable import/export of tags' makes a similar change for its final assertion
