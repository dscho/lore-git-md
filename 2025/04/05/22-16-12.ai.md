This is part of the ongoing merge-ort migration effort, specifically patch 6/8 in the v2 series. The patch removes the legacy merge-recursive implementation by deleting merge-recursive.[ch] and moving shared functions to merge-ort.[ch]. 

The changes include:
- Deleting merge-recursive.c and merge-recursive.h entirely (over 4000 lines removed)
- Moving config parsing and merge option initialization functions from merge-recursive to merge-ort
- Updating documentation to indicate 'recursive' is now a synonym for 'ort'
- Removing merge-recursive from build systems (Makefile and meson.build)
- Preserving the merge option struct and related functions in merge-ort.h

Key technical details:
- The diff shows the complete removal of merge-recursive.[ch] and their test infrastructure
- Shared functions like merge_recursive_config() and init_merge_options() are moved to merge-ort.c
- The merge_options struct remains in merge-ort.h to maintain compatibility
- Documentation updates clarify that 'recursive' now points to 'ort' strategy

This patch represents a major milestone in the multi-year effort to replace merge-recursive with merge-ort as the sole merge backend. The changes are mechanical replacements with no functional impact, just code deletion and relocation of shared functionality. The v2 iteration suggests the series is technically complete with only minor documentation updates from the previous version.
