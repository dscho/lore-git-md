This is part of the major refactoring series to fully replace merge-recursive with merge-ort. Patch 3/8 specifically enables diff-algorithm selection for merge-ort, bringing it to parity with merge-recursive's capabilities.

The patch removes merge-ort's hardcoded use of the histogram diff algorithm, making it configurable like merge-recursive was. The change moves the default algorithm setting to init_merge_options() where it can be overridden, though histogram remains the default. Documentation is updated to reflect that both strategies now support the same diff-algorithm options, removing the previous distinction between them.

Key technical changes:
- Deletes the hardcoded DIFF_WITH_ALG setting in merge-ort.c's merge_start()
- Adds default xdl_opts setting in merge-recursive.c's init_merge_options()
- Updates merge-strategies.adoc to unify the documentation between ort and recursive
- Maintains backward compatibility by keeping histogram as default
- Removes now-redundant documentation about recursive-specific diff options

This is a straightforward change that completes merge-ort's feature parity with merge-recursive regarding diff algorithm selection, removing one of the last behavioral differences between the two implementations. The documentation updates help pave the way for merge-recursive's eventual removal by making it clear ort supports all the same options.
