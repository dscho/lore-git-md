Test improvement patch fixing a common shell scripting pitfall in Git's test suite.

Anthony Wang addresses an issue in the git-p4 label import test script where pipe operations were silently swallowing exit codes. The patch modifies two test cases to write command output to temporary files first, then grepping those files, rather than piping directly. This ensures test failures will be caught if the initial `git tag` command fails.

The changes are straightforward and follow established patterns seen elsewhere in the test suite for handling command output safely. While the impact is limited to test reliability (the actual git-p4 functionality isn't changed), it's a clean improvement that prevents potential false test passes. The commit message clearly explains the rationale and the changes match that explanation.
