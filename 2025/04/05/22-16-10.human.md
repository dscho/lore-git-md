This is patch 4/8 in Elijah Newren's series to fully remove the legacy merge-recursive implementation in favor of merge-ort. The patch focuses on converting the sequencer's non-recursive merge operations to exclusively use the ort backend.

The change simplifies `do_recursive_merge()` in sequencer.c by removing the conditional logic that previously allowed selecting either the recursive or ort backends. Since merge-ort has been the default for a long time and this series aims to completely eliminate merge-recursive, the patch removes 22 lines of now-unnecessary code while keeping the ort-specific path (reduced from 35 to 13 lines).

The commit message notes the function's misleading name - despite being called `do_recursive_merge()`, it actually performs non-recursive merges. The patch maintains all existing functionality while cleaning up the codebase in preparation for the final removal of merge-recursive in later patches.

This appears to be a straightforward mechanical conversion as part of the larger series, with no behavior changes expected since merge-ort has been the default backend. The patch follows the established pattern seen in earlier parts of the series, systematically removing merge-recursive support from various callers.
