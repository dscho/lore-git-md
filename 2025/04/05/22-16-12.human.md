This is part 6/8 of Elijah Newren's series to remove the legacy merge-recursive implementation in favor of merge-ort. The patch completely removes the merge-recursive.[ch] files, deleting over 4000 lines of code. It also moves the few functions that were shared between merge-recursive and merge-ort into merge-ort.[ch], and updates documentation to reflect that the "recursive" merge strategy is now just a synonym for "ort".

The changes are mechanical and straightforward - this patch represents the culmination of the multi-year effort to replace merge-recursive with merge-ort. The commit message humorously notes that "deleted code is debugged code" as it removes the old implementation. 

This is a significant milestone in Git's architecture cleanup, as merge-ort is now the only merge backend in the codebase. The patch series has gone through review iterations (this is v2) and appears ready for merging. The removal of merge-recursive represents the completion of a major refactoring effort that began with merge-ort's introduction in Git 2.33.0.
