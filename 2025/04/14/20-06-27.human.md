Performance optimization patch in Taylor Blau's MIDX/cruft pack series. This is part 6/8 of v2, focusing on improving delta compression for loose objects during repacking.

The patch fixes an oversight where loose objects weren't being included in the name-hash traversal when using `--unpacked`, which meant Git wasn't finding optimal deltas for them. While this didn't affect correctness, it could result in slightly larger packs. The change passes the `rev_info` struct to the loose object handling code so these objects can participate in the delta selection process.

This builds on earlier refactoring in the series (particularly patch 5/9 which moved the `rev_info` setup) and demonstrates the preparatory work paying off. The implementation touches the core pack-objects logic but maintains all existing behavior - it's now just more efficient about delta selection. The change is relatively contained, modifying about 20 lines in `builtin/pack-objects.c` with straightforward additions to pass through the revision walk context.

As with the rest of the series, this appears to be a well-considered change with clear motivation (better delta compression) and builds logically on previous preparatory work. It's part of Taylor's broader effort to optimize MIDX and cruft pack interactions during repacking, with real-world testing planned at GitHub.
