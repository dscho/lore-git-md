This is part 3 of a 4-part series implementing header checking in Meson builds, matching the Makefile's 'hdr-check' functionality. The patch adds the core implementation for verifying header file independence in Meson builds.

The implementation handles several technical challenges specific to Meson's out-of-tree builds. It creates a two-stage compilation check for each header (hcc/hco targets) while properly accounting for dependencies. The patch introduces a `generated_headers` list (renamed from `headers_generated` per earlier feedback) and adds several generated headers to it (command-list.h, config-list.h, hook-list.h). It also properly excludes third-party sources and platform-specific headers from checking, including adding xdiff/ to the exclusion list as requested in reviews.

Key technical details include conditional exclusion of crypto backend headers based on build configuration, proper include path handling for out-of-tree builds, and use of `fs.replace_suffix()` for clean filename handling (a suggestion from Patrick Steinhardt). The implementation creates an alias target 'hdr-check' (with 'check-headers' as the primary name, per Junio and Phillip's preference) that groups all header verification targets.

The patch reflects thorough incorporation of prior review feedback, including:
- Using directory patterns for exclusions (compat/, xdiff/)
- Proper categorization of third_party_sources
- Conditional initialization when git is found
- Clean filename handling via fs.replace_suffix()
- Centralized header definitions in root meson.build

This represents the core technical implementation of the header checking functionality, with all major architectural decisions now settled from previous discussion. The implementation is robust, handling generated files, platform exclusions, and crypto backend conditional checks while maintaining compatibility with Git's build philosophy.
