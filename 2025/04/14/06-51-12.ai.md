This is a performance infrastructure patch that improves Perl script portability in Git's benchmark system. It modifies the benchmark scripts to use the configured `PERL_PATH` rather than hardcoding `/usr/bin/perl`, addressing compatibility issues on systems like NixOS where Perl may be installed in non-standard locations. The changes span three files: updating the shebang in `aggregate.perl` to use `#!/usr/bin/env perl`, and modifying `perf-lib.sh` and `run` to explicitly invoke Perl scripts via `$PERL_PATH`.

The patch builds on previous discussion in this thread about Perl path handling, implementing the agreed-upon solution of using the environment variable while maintaining the `env` shebang for direct script execution. This represents a straightforward but important improvement to the benchmark infrastructure's portability, particularly benefiting users with custom Perl installations. The changes are minimal (5 lines modified total) and focused, with clear backward compatibility.
