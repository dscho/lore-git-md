Performance optimization for MIDX and cruft pack interaction during repacking. This v2 series from Taylor Blau builds on the earlier RFC to implement a configurable way to exclude cruft packs from MIDX when possible, while maintaining reachability guarantees. The key technical changes include:

1. A new `repack.midxMustContainCruft` config option (default true) to control whether cruft packs must be included in MIDX
2. More robust handling of pack relationships through a generalized `midx_has_unknown_packs()` check rather than cruft-specific logic
3. Expanded test coverage with three scenarios: default exclusion, forced inclusion, and required inclusion when necessary
4. Additional preparatory commit explaining designated initializer behavior in `object-store-ll.h`

The core optimization works by using a new `--stdin-packs=follow` mode during geometric repacking that ensures generated packs are reachability-closed without requiring cruft pack inclusion in MIDX. The implementation carefully handles edge cases where cruft packs must remain in MIDX to maintain bitmap correctness.

Files modified include `builtin/repack.c`, `builtin/pack-objects.c`, and new tests in `t/t7704-repack-cruft.sh`. The author plans to test this in production at GitHub before finalizing. This represents a more polished version of the RFC with clearer configuration and testing.
