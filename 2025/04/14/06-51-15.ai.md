This is a configuration patch completing the Meson benchmark integration series by wiring up benchmark-specific build options. It's the final patch in a 5-part series that has been iterating on bringing Git's performance test infrastructure into the Meson build system.

The patch exposes three Meson configuration options for benchmark tests: `benchmark_repo` (for standard test repositories), `benchmark_large_repo` (for Linux-sized repositories), and `benchmark_repeat_count` (defaulting to 3 runs). These get written into the GIT-BUILD-OPTIONS file with proper quoting. Notably, it excludes `GIT_PERF_MAKE_*` options since they're only used by the legacy `t/perf/run` script that Meson doesn't use.

The changes are minimal (9 lines total) but complete the technical integration by providing the same configuration surface area that was available in the Makefile build system. The implementation follows the established pattern of the series, maintaining separation between Meson and legacy benchmark execution paths while ensuring proper quoting of values. This appears to be the final functional piece needed for full Meson benchmark support.
