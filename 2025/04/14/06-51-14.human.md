This is a performance infrastructure patch that wires up Git's benchmark suite to work with the Meson build system. It's part 4 of a 5-part series integrating `t/perf` benchmarks with Meson while maintaining compatibility with the existing `t/perf/run` script.

The patch adds Meson configuration for 47 performance tests, treating them as benchmarks rather than regular tests. This gives them special handling: they won't run in parallel, won't execute by default with other tests, and avoid memory perturbation instrumentation. The implementation mirrors the test wiring but uses Meson's `benchmark()` function instead of `test()`.

Key limitations noted are that this only supports benchmarking the current Git build - cross-version comparisons still require the traditional `t/perf/run` script. The patch cleanly separates these use cases, deferring Meson support for cross-version benchmarking to future work.

The changes are straightforward - adding a benchmark list and wiring logic to `t/meson.build`, plus detecting the `time` utility in the main `meson.build`. The implementation appears complete and well-considered, maintaining the benchmark suite's isolation properties while making it accessible through Meson's interface. This is a logical step in the broader Meson integration effort.
