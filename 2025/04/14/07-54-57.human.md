Build system alignment: Help format defaults discussion.

This is a brief follow-up in the ongoing build system alignment series, specifically about help format defaults between Makefile and meson builds. Patrick Steinhardt responds to Ramsay Jones' observation that the Makefile build includes 'info' and 'pdf' help format options that weren't ported to meson.

Steinhardt explains this was a conscious choice based on not finding these formats actually used in distributions, though he leaves the door open to adding them back if there's user demand. The exchange serves as a minor checkpoint in the broader effort to rationalize build system features - here considering whether to maintain legacy format support or use the meson transition as an opportunity to prune rarely-used options.

The tone suggests this isn't a contentious point, more an acknowledgement of a deliberate simplification choice that could be revisited if needed. This fits with the series' overall goal of making meson behavior match Makefile where it matters while potentially streamlining some historical cruft.
