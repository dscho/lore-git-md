This is a build system alignment patch in the ongoing series to improve consistency between Makefile and meson builds. The patch conditionally sets certain `BASIC_CFLAGS` only when `RUNTIME_PREFIX` is defined, since several build variables (like `HAVE_BSD_KERN_PROC_SYSCTL` and `PROCFS_EXECUTABLE_PATH`) are meaningless without it. 

Patrick Steinhardt confirms this matches meson's existing behavior, so no additional meson-side changes are needed. The change is straightforward and uncontroversial, simply removing unnecessary compiler flags when they wouldn't be used anyway. This continues the series' theme of cleaning up platform-specific build logic while maintaining functional equivalence between build systems.
