This is a cover letter for a 5-part series integrating Git's performance tests with the Meson build system, following up on D. Ben Knoble's earlier work. The series maintains compatibility with the existing `t/perf/run` script while adding Meson support for single-version benchmarking.

Key changes in v2:
- Modified `aggregate.perl` to use `#!/usr/bin/env perl` shebang (resolving the Perl path discussion from previous thread)
- Keeps all other functionality from v1 intact

The series handles several technical aspects:
1. Repository format compatibility (SHA256/reftable)
2. Perl path portability using configured `PERL_PATH`
3. Out-of-tree build support
4. Meson target configuration for 47 performance tests
5. Benchmarking options integration

Notable characteristics:
- Explicitly does not replace `t/perf/run` (which supports cross-version benchmarking)
- Maintains backward compatibility
- Changes are focused (3-9 lines per functional change)
- Build system changes span `meson.build`, `meson_options.txt`, and `t/meson.build`
- Affects benchmark infrastructure files like `t/perf/perf-lib.sh`

The v2 revision resolves the main open question from the thread (Perl path handling) by adopting the `env`-based shebang approach. The series appears well-constructed with clear commit messages and maintains the separation between Meson single-version and traditional cross-version benchmarking workflows.
