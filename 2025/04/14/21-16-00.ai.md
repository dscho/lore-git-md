This is a refactoring patch in Karthik Nayak's series to implement header checking in Meson builds, moving header definitions to a more centralized location. The patch relocates the `coccinelle_headers` and `third_party_sources` variables from contrib/coccinelle/meson.build to the root meson.build file, renaming the former to simply `headers` since it will be reused by upcoming header-checking functionality.

The key changes are:
1. Moves header list definition to root meson.build for broader accessibility
2. Renames `coccinelle_headers` to `headers` to reflect its expanded purpose
3. Keeps path prefixing logic in coccinelle-specific build file
4. Makes header collection conditional on git.found() for robustness
5. Maintains identical exclusion patterns via `third_party_sources`

The patch follows the thread's established patterns of centralizing build definitions and follows through on earlier discussions about variable scoping. It prepares for the upcoming header-check implementation while maintaining the existing coccinelle functionality. The changes are straightforward and align with the series' goal of matching Makefile capabilities in Meson.
