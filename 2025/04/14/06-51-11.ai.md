Performance benchmark infrastructure patch addressing repository format compatibility in the Git test suite.

This patch fixes an issue in the performance benchmark infrastructure where copying test repositories would lose their format specifications (SHA256 object format or reftable ref format). The current implementation deliberately skips copying repository configuration to avoid performance measurement contamination, but this breaks benchmarks using alternate repository formats.

The solution extracts the source repository's reference and object formats using `git rev-parse --show-ref-format` and `--show-object-format`, then passes these to `git init` when creating the benchmark copy. The change is minimal (3 lines added, 1 modified in `t/perf/perf-lib.sh`) and maintains the existing safety measures like skipping hooks and config files.

This is part of a v2 series integrating Git's performance benchmarks with Meson, though this particular fix is orthogonal to the build system changes. The patch cleanly addresses a real technical limitation while preserving the benchmark infrastructure's intentional isolation properties. The implementation follows established patterns in the performance test framework and includes appropriate error handling through existing Git command failure propagation.
