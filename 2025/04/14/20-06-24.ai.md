Refactoring patch in Taylor Blau's performance optimization series for MIDX/cruft pack interaction. This is patch 5/8 in v2 of the series, focusing on restructuring the pack-objects code to prepare for upcoming changes to the reachability traversal logic.

The patch moves the initialization and execution of the `rev_info` structure used for reachability traversal from `read_packs_list_from_stdin()` to its caller `read_stdin_packs()`. This change enables future sharing of this traversal logic with the `--unpacked` case, where it will be used to find reachable objects in unknown packs. The commit message explains this prepares for a future change where the traversal will also find objects reachable from input pack commits but packed elsewhere.

Key technical changes:
- Extracts `rev_info` setup and traversal from `read_packs_list_from_stdin()` to `read_stdin_packs()`
- Passes `revs` as parameter to `read_packs_list_from_stdin()`
- Maintains all existing behavior including `ignore_packed_keep_in_core` handling
- Preserves the reachability walk's role in populating name hashes for delta optimization

This continues the series' pattern of preparatory refactoring before implementing the core optimization. The change touches the same `builtin/pack-objects.c` file as previous patches, with the diff showing mostly code movement rather than functional changes. The commit builds on the earlier extraction of stdin pack handling in patch 4/8 while setting up for the upcoming changes to the reachability traversal's purpose.
