This is a platform compatibility patch in the ongoing build system alignment series, specifically addressing Cygwin support for the `sysinfo()` function.

The patch builds on Ramsay Jones' earlier work to enable `sysinfo()` for Cygwin by properly configuring it in `config.mak.uname`. The key technical point is that while `sysinfo()` is traditionally considered Linux-specific, Cygwin provides a functional implementation that should be detected and used. The changes involve reworking the Linux-specific handling of HAVE_SYSINFO in both the Makefile and config.mak.uname to accommodate Cygwin.

Patrick Steinhardt notes that meson already handles this case correctly, so no meson changes are needed. This continues the series' theme of aligning Makefile and meson behavior while expanding platform support. The patch appears straightforward and uncontroversial, being a logical extension of existing platform detection logic. It follows the series' pattern of methodically addressing platform-specific build configurations.
