Refactoring patch as part of the promisor-remote capability extension series.

This first patch in the 4-part series moves and renames a config validation helper function in preparation for its reuse in the promisor-remote work. The `iskeychar()` function from config.c is relocated to config.h and renamed to `is_config_key_char()`, making it available for other parts of the codebase to validate config key characters. The change is straightforward - the function's logic remains identical (checking for alphanumeric or hyphen characters) but is now exposed via header. All existing call sites in config.c are updated to use the new name. 

This appears to be foundational work for the series' main goal of validating remote configuration fields, where the helper will be needed to check field names. The patch maintains perfect backward compatibility since it doesn't change any behavior, just reorganizes existing code. The commit message clearly explains the motivation and the change follows standard Git code organization patterns.
