This is the final patch in a series implementing header checking in Meson builds, focusing on target naming consistency. The patch introduces 'check-headers' as a more readable alternative to the existing 'hdr-check' target for verifying header compilability, while maintaining backward compatibility.

Karthik Nayak proposes making 'check-headers' the primary name, with 'hdr-check' kept as a transitional alias that will be deprecated after 2 releases. The change follows feedback from Phillip Wood and Junio C Hamano who preferred the new name for better consistency with Git's Makefile conventions (other targets use 'check-*' pattern).

The implementation updates both the Makefile and Meson build system, plus the CI script that runs the check. The patch is straightforward - it adds the new target name while keeping the old one functional, with clear TODO markers about the planned deprecation. This concludes the series that has seen thorough review and iteration, with all major technical and naming questions now resolved.
