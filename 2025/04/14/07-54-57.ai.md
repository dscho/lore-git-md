Platform compatibility update in the build system alignment series.

This email from Patrick Steinhardt responds to Ramsay Jones' observation about differences in help format targets between Makefile and meson builds. The discussion centers on the decision to not port the 'info' and 'pdf' help format targets to meson builds, which were present in the Makefile system.

Key technical points:
- Makefile builds include 'info' and 'pdf' help format targets
- Meson builds deliberately omit these formats
- Rationale given is lack of observed usage in distributions
- Positioned as opportunity to potentially deprecate unused build targets if no users object

The exchange highlights an ongoing theme in the series about making intentional choices when aligning build systems rather than blindly copying all legacy features. This particular case shows the meson conversion being used as an opportunity to reevaluate and potentially simplify the build infrastructure by removing apparently unused components. The email leaves the door open to reconsider if users demonstrate need for these formats, suggesting this could serve as a test case for broader cleanup of rarely-used build features.
