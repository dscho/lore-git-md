This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack handling. It's the first of eight patches in v2 of the series.

The patch standardizes how `pack-objects` handles incompatible command-line options by replacing custom error checks with the shared `die_for_incompatible_opt2()` function. This brings consistency to error messages while maintaining the same functionality. The changes affect several option pairs like `--stdin-packs` with `--filter`, and `--keep-unreachable` with `--unpack-unreachable`.

Junio Hamano provides a brief review noting that while the order of checks is reversed in the implementation, the error message maintains the same option ordering as before, which he finds preferable. The patch includes corresponding test updates to match the new standardized error message format.

This appears to be a straightforward cleanup with no behavioral changes, serving as groundwork for the more substantial performance optimizations that follow in the series. The implementation looks clean and the test coverage remains thorough.
