This thread documents the completion of a 5-patch series that enhances Git's promisor-remote protocol with configurable validation of remote attributes during clone and fetch operations. The changes allow servers to advertise additional fields (partialCloneFilter and token) via a new `promisor.sendFields` config, while clients can validate these fields using `promisor.checkFields`. The implementation maintains backward compatibility while adding security-conscious validation.

The series went through four iterations, with key contributions from Karthik Nayak implementing structural changes and Christian Couder providing thorough review. Junio Hamano suggested important architectural improvements, including refactoring to use `struct promisor_info` and `string_list` for better type safety. The patches include comprehensive test coverage and detailed documentation using BNF notation for field specifications.

All major design points have been settled, with CI passing and documentation complete. Christian Couder has given final approval, noting only minor nits remain that don't require another revision. The series is now ready for merging as part of Git's broader Large Object Promisors (LOP) effort, representing a significant step forward in making the promisor-remote protocol more secure and flexible.
