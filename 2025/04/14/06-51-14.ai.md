This is a performance infrastructure patch that wires up Git's benchmark tests to work with the Meson build system. It's part of a series integrating Git's performance testing framework (`t/perf`) with Meson while maintaining compatibility with the existing `t/perf/run` script.

The patch adds 47 benchmark tests to Meson's configuration, using Meson's `benchmark()` function which provides special handling compared to regular tests: benchmarks don't run in parallel, aren't run by default with tests, and avoid memory perturbation. The implementation follows similar patterns to the test wiring but adds a dependency on the `time` utility for benchmarking measurements.

Key technical details include:
- Adds `time` program detection in `meson.build`
- Lists all benchmark scripts in `t/meson.build` (47 tests from p0000 to p9300)
- Configures benchmark execution with proper environment setup
- Maintains the same workdir and dependencies as regular tests
- Preserves the limitation that Meson benchmarks only work for the current build (cross-version comparisons still require `t/perf/run`)

The patch builds on previous work in the series that handled repository format compatibility and Perl path portability, now completing the core Meson integration for benchmarks. The implementation is straightforward and maintains clear separation between Meson's single-version benchmarking and the traditional cross-version capabilities of `t/perf/run`.
