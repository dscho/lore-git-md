Refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction.

This first patch in the v2 series standardizes how `pack-objects` handles incompatible command-line options. It replaces several ad-hoc error checks with calls to the unified `die_for_incompatible_opt2()` function, which provides consistent error messaging when users supply mutually exclusive options like `--stdin-packs` with `--filter` or `--keep-unreachable` with `--unpack-unreachable`.

The change is purely mechanical - it doesn't alter functionality but makes the code more maintainable by using Git's standard pattern for option incompatibility checks. One test in t5331 needed updating to match the new standardized error message format. This cleanup precedes the more substantive performance optimizations in later patches of the series.

The patch is straightforward and well-contained, touching only two files with clear, focused changes. It demonstrates good attention to detail by including the test update to maintain consistency. As an infrastructure improvement, it provides a solid foundation for the subsequent patches that will build on these option-handling patterns.
