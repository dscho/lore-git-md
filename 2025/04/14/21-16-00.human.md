This is a refactoring patch in Karthik Nayak's series to implement header checking in Meson builds, moving variable definitions to better locations in preparation for adding new functionality.

The patch relocates two key variable definitions from contrib/coccinelle/meson.build to the root meson.build file:
1. The `third_party_sources` exclusion list (used to filter out non-Git headers)
2. The header collection logic (renamed from `coccinelle_headers` to just `headers`)

The changes make these variables available at the top level where they'll be needed for upcoming header checking functionality, while maintaining the coccinelle-specific path handling in its original location. The implementation is careful to conditionally initialize the `headers` list only when Git is found in the build environment.

This is part of a well-reviewed series that has evolved through multiple versions with input from several maintainers. The changes here are straightforward and align with the thread's consensus on proper variable scoping and organization in the Meson build system.
