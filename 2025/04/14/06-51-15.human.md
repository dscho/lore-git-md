Performance test integration for Meson build system (final patch in series).

This fifth and final patch in the series completes the integration of Git's performance benchmark infrastructure with Meson by wiring up three key configuration options. Patrick Steinhardt takes over from D. Ben Knoble to handle these final build system tweaks.

The patch exposes three Meson options for benchmark configuration:
1. `benchmark_repo` - specifies the repository to copy for standard performance tests
2. `benchmark_large_repo` - defines a larger repository (Linux-sized) for more demanding tests
3. `benchmark_repeat_count` - sets the number of test repetitions (defaulting to 3)

Notably, the patch excludes `GIT_PERF_MAKE_COMMAND` and `GIT_PERF_MAKE_OPTS` from Meson since they're only used by the legacy `t/perf/run` script. The changes ensure proper quoting of string values in the generated build options.

This completes the technical work started in earlier patches, maintaining compatibility with the existing performance test infrastructure while adding proper Meson support. The series appears well-considered, with clear separation between the Meson-specific and legacy components.
