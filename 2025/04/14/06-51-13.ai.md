This is a performance test infrastructure improvement for out-of-tree builds, part of the ongoing Meson integration effort. The patch modifies `t/perf/perf-lib.sh` to properly handle build directories that aren't colocated with source directories, which is common in Meson and CMake builds.

The key changes introduce proper detection of the build directory via `GIT-BUILD-DIR` file (with special Windows path handling) and update paths to reference both build and source directories correctly. It ensures `GIT-BUILD-OPTIONS` can be found in out-of-tree builds and fixes the path to `aggregate.perl` to use `$GIT_SOURCE_DIR`. The changes maintain backward compatibility while adding support for the new build system workflows.

This builds on previous work in the series that addressed Perl path handling and repository format compatibility.
