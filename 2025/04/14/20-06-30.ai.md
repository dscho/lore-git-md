Performance optimization for pack-objects with new `--stdin-packs=follow` mode.

This patch introduces a new mode for `--stdin-packs` that changes how pack-objects handles objects from packs not explicitly listed in the input. The standard behavior excludes objects from unlisted packs, but the new "follow" mode includes objects reachable from the listed packs, except those in excluded packs. This is particularly useful for maintaining reachability guarantees when repacking with cruft packs, addressing the scenario described in commit ddee3703b3 where resurrected objects from cruft packs need to be included in the MIDX for proper bitmap generation.

The implementation adds a new `stdin_packs_mode` enum with three states (NONE, STANDARD, FOLLOW) and modifies the pack-objects traversal logic to handle the new mode. When in FOLLOW mode, the traversal includes reachable objects from unlisted packs while still respecting exclusions. The patch includes thorough tests demonstrating the behavior with various pack combinations and interactions with `--unpacked`.

This is part of Taylor Blau's ongoing series optimizing pack maintenance (now at v2 7/8), building on earlier refactoring and preparation work. The change touches core pack-objects functionality but maintains backward compatibility. Test coverage in t5331-pack-objects-stdin.sh verifies both the new follow behavior and its interaction with existing features.
