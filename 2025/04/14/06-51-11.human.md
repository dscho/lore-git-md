This is a bugfix patch in a series integrating Git's performance benchmarks with Meson. It addresses an issue where benchmark tests copying repositories would fail when working with alternate repository formats (SHA256 object format or reftable ref format).

The patch modifies `t/perf/perf-lib.sh` to properly handle repository formats during benchmark setup. Previously, the benchmark infrastructure would skip copying repository configuration to avoid performance impacts, but this caused problems with format-specific repositories. The fix extracts the reference and object formats from the source repository and passes them explicitly to `git init`.

The change is small (4 lines modified) but important for maintaining compatibility with different repository formats during performance testing. This is part of a larger effort (v2 series) that has already addressed several technical concerns around Meson integration, with this particular patch being the first in the series. The solution appears straightforward and well-contained, preserving the original goal of avoiding configuration side effects while fixing the format compatibility issue.
