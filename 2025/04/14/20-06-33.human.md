Performance optimization for MIDX and cruft pack interaction. This is the final patch in Taylor Blau's 8-part series improving pack maintenance, introducing a way to optionally exclude cruft packs from the MIDX when they aren't needed for reachability.

The patch adds a new config option `repack.midxMustContainCruft` (defaulting to true for backward compatibility) that, when set to false, allows Git to omit cruft packs from the MIDX during geometric repacking if they aren't required to maintain reachability closure. This addresses both the bloat problem (MIDX tracking many rarely-accessed objects) and the performance overhead (slower object lookups through the MIDX).

The implementation is thorough, with careful handling of edge cases and comprehensive test coverage in t7704-repack-cruft.sh. The change builds on the new `--stdin-packs=follow` mode introduced in patch 7/8, using it to ensure reachability is maintained without cruft packs when possible. The commit message clearly explains the motivation and technical tradeoffs.

This appears to be a well-considered optimization that could significantly improve performance for repositories with many unreachable objects, while maintaining all the correctness guarantees needed for features like MIDX bitmaps. The series as a whole shows careful attention to both performance and backward compatibility.
