This is a follow-up discussion in the ongoing thread about Meson build system support for installing shell completion scripts. Eli Schwartz from Gentoo weighs in with detailed analysis of path resolution complexities, particularly for Zsh completions.

The email provides a thorough technical breakdown of how different shells handle completion script locations. For Bash, the path resolution is robust and works across various installation layouts, making it safe to install by default. However, Zsh presents significant challenges - its path handling is less flexible, varies by distribution (notably Debian's non-standard paths), and lacks good defaults for user-local installations.

Schwartz suggests proceeding with Bash completion installation while deferring Zsh support until its path issues can be properly resolved. The analysis confirms Junio Hamano's earlier position that simple, predictable paths are preferable to complex auto-detection, while highlighting the particular difficulties Zsh introduces compared to Bash.

This contribution adds important real-world distribution perspective to the thread, particularly around edge cases and cross-distro compatibility. It reinforces that the Bash portion of the patch is uncontroversial while identifying Zsh-specific complications that may need separate handling. The technical depth suggests this comes from someone with direct experience maintaining these components in a major distribution.
