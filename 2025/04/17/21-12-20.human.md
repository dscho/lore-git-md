Performance test cleanup in Taylor Blau's bitmap lookup table series.

This is the third patch in a 4-part series that makes bitmap lookup tables the default when writing bitmaps. The patch simplifies several performance test scripts by removing redundant testing of the non-lookup-table case, since that configuration will soon be obsolete. The changes affect four test scripts (p5310, p5311, p5326, and p5333) that previously ran each test twice - once with lookup tables enabled and once without. Now they only test the lookup-table-enabled path, which will be the only supported configuration after this series lands. The patch maintains all the core test logic while eliminating about 130 lines of duplicate test setup and execution.

This is a straightforward cleanup that follows logically from the series' goal of making lookup tables the default. The changes are mechanical but well-justified, and the patch keeps all the important test coverage while removing redundancy. It builds on the performance data shown in earlier patches that demonstrated lookup tables' benefits.
