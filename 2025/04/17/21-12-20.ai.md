Test maintenance patch in a series making bitmap lookup tables the default. This third patch in the 4-part series simplifies performance test scripts by removing redundant test cases that previously compared bitmap performance with and without lookup tables. Since lookup tables are now enabled by default (as established in earlier patches), these dual test paths are no longer needed.

The changes focus on four performance test scripts (p5310, p5311, p5326, p5333) that previously had parallel test paths for lookup-table and non-lookup-table scenarios. The patch:
- Removes the conditional test wrappers that ran tests twice with different lookup table settings
- Eliminates explicit configuration of pack.writeBitmapLookupTable since it's now the default
- Maintains all core bitmap functionality testing
- Preserves the performance measurement framework while focusing only on the now-standard lookup table case

The patch follows logically from the series' earlier decision to make lookup tables the default, cleaning up test code that would otherwise test deprecated configurations. The changes are mechanical but thorough, touching 281 lines across the four test files while maintaining their essential testing purposes. This aligns with the series' secondary goal of test suite maintenance following the lookup table promotion to default status.
