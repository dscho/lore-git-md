Test maintenance patch in a series making bitmap lookup tables the default. This is the fourth and final patch in Taylor Blau's series, focusing on optimizing the performance test infrastructure.

The change switches a repacking operation in the test_pack_bitmap() helper from using test_perf to test_expect_success. This makes sense because the repack is just setup work - we don't need to measure its performance, and repeating it multiple times (as test_perf would do) is wasteful since the operation is idempotent. The patch is small and straightforward, just changing one line in the test helper script.

This follows logically from the series' main goal of simplifying bitmap testing now that lookup tables are the default. The change should make the performance tests run slightly faster by avoiding unnecessary repack repetitions, while maintaining the same test coverage. As with the rest of the series, this shows careful attention to test infrastructure details.
