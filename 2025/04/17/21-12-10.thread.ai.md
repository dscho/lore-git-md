Thread identity: Patch series by Taylor Blau changing default behavior for bitmap lookup tables in pack-bitmaps, with related test suite maintenance.

Core problem/goal: Make bitmap lookup tables enabled by default when writing bitmaps, reflecting their stable status after initial introduction as opt-in. Secondary goals include cleaning up performance test scripts to match this new default and optimizing the test harness itself.

Current status: Series at v1 with 2 patches. First patch changes default of pack.writeBitmapLookupTable config from false to true and removes redundant performance test scripts. Second patch optimizes test harness by converting a setup-phase `test_perf` call to `test_expect_success` in the `test_pack_bitmap()` helper function. Performance data shows consistent improvements when lookup tables are enabled, with the tables having been used successfully in production at GitHub for nearly three years.

Key technical details:
- Modifies bitmap writing behavior in both multi-pack-index (MIDX_WRITE_BITMAP_LOOKUP_TABLE) and pack-objects (BITMAP_OPT_LOOKUP_TABLE)
- Removes tests for bitmap configurations without lookup tables
- Updates lib-bitmap.sh to avoid test_perf during setup phases
- Deletes redundant performance tests (p5312 and another from a8dd7e05b1) which duplicated rev-list bitmap testing
- Simplifies p5310, p5311, p5326, p5333 by removing conditional test wrappers
- Optimizes test_pack_bitmap() helper by making initial repack use test_expect_success instead of test_perf
- Eliminates explicit configuration of pack.writeBitmapLookupTable since it's now the default
- Performance data shows optimization is particularly effective for rev-list operations

Open questions/loose ends:
- Junio C Hamano raises maintainability concern about parallel bitmap flag systems (BITMAP_OPT_LOOKUP_TABLE in pack-objects vs MIDX_WRITE_BITMAP_LOOKUP_TABLE in midx) needing manual synchronization
- No automatic mechanism exists to ensure future default changes remain consistent across both subsystems
- Potential need for documentation of this relationship or restructuring of flag systems
- Discussion may lead to design changes before series progresses
