Test maintenance patch in a series about bitmap lookup tables. This is the final patch in Taylor Blau's series to enable bitmap lookup tables by default. While the main series changes configuration defaults and removes redundant performance tests, this patch optimizes the test harness itself.

The change switches a `test_perf` call to `test_expect_success` in the `test_pack_bitmap()` helper function. The function's initial repack operation was being unnecessarily timed and repeated, despite being purely setup code that doesn't affect the actual performance measurements. The patch notes this repack is idempotent and only needed for consistency, making the timing overhead wasteful.

This is a straightforward test infrastructure improvement that complements the series' broader goal of streamlining bitmap performance testing. The change reduces noise in performance measurements by eliminating irrelevant timing of setup steps, though the impact is likely minor since it only affects the test harness rather than core functionality. The patch maintains all existing test coverage while making the test suite slightly more efficient.
