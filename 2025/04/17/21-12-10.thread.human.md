Taylor Blau is proposing to enable bitmap lookup tables by default, reflecting their stable status after years of production testing at GitHub. The initial two-patch series changes the default configuration and cleans up related performance tests, removing redundant scripts and optimizing the test harness. Performance data shows consistent improvements when lookup tables are enabled.

Junio C Hamano has raised several concerns about the broader implications. He notes the parallel flag systems for bitmap lookup tables in pack-objects versus midx could become a maintenance burden without any automatic synchronization. He also questions whether completely removing performance tests for the non-default (lookup-table-disabled) configuration is premature, since the code still supports both paths. For the test harness optimization specifically - changing a setup repack from `test_perf` to `test_expect_success` - Junio has given his approval ("OK."), recognizing it as a straightforward improvement regardless of the larger discussion.

The thread remains open on the architectural questions and test philosophy, with Junio suggesting alternatives like modifying rather than removing some tests to maintain coverage of non-default paths. Taylor may need to address these points in a v2 of the series.
