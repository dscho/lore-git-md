This is a test cleanup patch in Taylor Blau's series about enabling bitmap lookup tables by default. The patch removes performance tests that exercised bitmap behavior both with and without lookup tables, since the tables are now the default and have proven beneficial.

Junio C Hamano questions whether removing these tests is premature, noting that while they're performance rather than correctness tests, the project still technically supports both configurations. He wonders about the maintenance cost of keeping them versus the value of continued testing of the non-default path.

The exchange highlights an ongoing discussion about test philosophy - how much to test non-default configurations, and whether performance tests should follow the same rules as correctness tests. Junio's comment suggests he may want to keep some coverage of the lookup-table-disabled case, even if not in the exact form being removed here.
