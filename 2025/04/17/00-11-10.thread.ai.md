This is a "What's cooking" interim status update from Junio C Hamano summarizing recent changes merged to Git's development branches. The core focus is CI stability fixes fast-tracked to 'master' ahead of schedule, along with twelve other topics graduating from 'next' to 'master' after standard stabilization.

Three urgent CI fixes were prioritized: Đoàn Trần Công Danh and Johannes Schindelin (Dscho) addressed GitHub Actions Ubuntu 20.04 runner deprecation, Dscho (with Todd Zullinger) fixed a Fedora CI image issue with missing awk, and a glibc workaround for sparse builds was implemented. These are marked for backporting to 'maint'.

Twelve additional topics completed the standard 'next' stabilization period and moved to 'master'. These include: build system fixes, test modernization (including Perl prerequisite removal), ref transaction handling improvements, send-email error handling fixes, rev-list optimizations, trailer parsing test coverage, non-transactional batch update support, and reflog expiration in maintenance. The changes range from single-commit fixes to 20-commit test modernization efforts, with test infrastructure work being particularly prominent.

The update shows Git's development process balancing urgent infrastructure maintenance (CI stability) with steady feature development flow through the standard integration branches. The fast-tracking of CI fixes reflects their impact on the project's ability to validate changes, while the graduated topics demonstrate ongoing work across multiple subsystems.
