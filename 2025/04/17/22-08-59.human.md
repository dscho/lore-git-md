This is a test cleanup patch in Taylor Blau's series about enabling bitmap lookup tables by default. The patch removes a redundant performance test script (p5312) that became functionally identical to p5310 after reverse indexes were enabled by default in an earlier change. 

Junio C Hamano points out two minor grammatical issues in the commit message and suggests an alternative approach - rather than deleting the duplicate test, the series could have modified one of the tests to explicitly disable reverse indexes to maintain distinct coverage. However, the current approach of simply removing the duplicate seems reasonable given that the test scenarios are now identical.

The change itself is straightforward - it deletes the p5312 script which was originally meant to test bitmap performance with reverse indexes enabled, but now that reverse indexes are always enabled, it duplicates p5310's functionality. This is part of a larger effort to clean up the test suite in preparation for making bitmap lookup tables the default behavior.
