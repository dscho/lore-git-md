Test maintenance patch in a series about enabling bitmap lookup tables by default.

This is the second patch in Taylor Blau's series to make bitmap lookup tables the default. It removes a redundant performance test script (p5312) that became functionally identical to p5310 after reverse indexes were enabled by default in 2023. The commit explains that p5312 was originally created to test bitmap performance with reverse indexes enabled, but since reverse indexes are now always on, the test duplicates p5310's functionality.

The change is straightforward - it simply deletes the now-unnecessary script. This cleanup aligns with the series' broader goal of simplifying the test suite to match the new default configuration where lookup tables are always enabled. The patch doesn't introduce any new functionality but helps maintain test hygiene by removing obsolete code.
