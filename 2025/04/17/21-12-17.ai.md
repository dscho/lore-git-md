Test maintenance patch removing a redundant performance test script as part of the bitmap lookup tables series.

This patch deletes the p5312 performance test script which became redundant after reverse indexes were enabled by default in Git. The script was created to test bitmap performance with reverse indexes enabled, but once that became the default behavior, it became functionally identical to p5310. The commit message notes this should have been cleaned up in a8dd7e05b1 but was overlooked.

The diff shows the complete removal of the test file, which contained duplicate test infrastructure for measuring bitmap performance with lookup tables enabled/disabled. This change is part of Taylor Blau's broader effort to make bitmap lookup tables the default and clean up related test infrastructure. The removal is straightforward and uncontroversial, aligning with the series' goal of simplifying the test suite to match the new default configuration.
