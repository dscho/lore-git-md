This is a build system patch continuing the discussion about installing shell completion scripts in the Meson build system. The email captures Junio Hamano's response to Eli Schwartz's detailed analysis of path handling complexities for Bash and Zsh completions.

Junio agrees with Schwartz's assessment that Bash completion installation is straightforward and should proceed, suggesting a simple addition of `bash_completion_dir` alongside other standard installation paths in both Makefile and Meson configurations. For Zsh completions, he acknowledges the more problematic path resolution issues Schwartz outlined, offering two possible approaches: either mirroring the standard `/usr/share/zsh/site-functions` path structure (even if not automatically discovered by Zsh) or deferring Zsh support entirely as Schwartz recommended.

The email reinforces the emerging consensus from the thread: Bash completion installation is technically sound and aligns with existing practices, while Zsh support presents non-trivial platform-specific challenges that may warrant postponement. Junio's response indicates the Bash portion could move forward independently while leaving the Zsh question open for future resolution.
