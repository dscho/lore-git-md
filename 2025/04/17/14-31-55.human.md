This is a build system patch addressing shell completion script installation in the Meson build system. Junio Hamano weighs in on the ongoing discussion about where and how to install Git's shell completion scripts, building on Eli Schwartz's detailed analysis.

The key takeaway is that Bash completion installation appears straightforward - it can follow the same pattern as other data files, using standard paths that work reliably across distributions. Hamano suggests simply mirroring the Makefile approach by adding a `bash_completion_dir` variable alongside existing paths like `infodir`.

For Zsh completion, the situation is more complex due to rigid path requirements and distribution-specific quirks. Hamano acknowledges Schwartz's recommendation to defer Zsh support, though he floats the idea of using a standard path (`share/zsh/site-functions`) for consistency's sake, even if it might not work perfectly in all cases.

The discussion shows the Git maintainers leaning toward a pragmatic approach: implement the straightforward Bash solution now while punting on Zsh until its path handling complexities can be properly addressed. This reflects the project's general philosophy of preferring simple, maintainable solutions where possible.
