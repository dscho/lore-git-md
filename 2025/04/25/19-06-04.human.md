Performance optimization for bundle-uri reference handling, part 1/2 of a v5 series. This patch expands the bundle-uri functionality to copy all references (not just `refs/heads/`) into the `refs/bundles/` namespace during fetches, which significantly improves subsequent fetch negotiation by including more reference points.

The key change is a one-line modification in `bundle-uri.c` that removes the `refs/heads/` restriction, allowing all references to be considered. The patch includes extensive test coverage (172 lines modified in `t/t5558-clone-bundle-uri.sh`) to verify the new behavior, particularly around the new reference placement in `refs/bundles/heads/` rather than directly in `refs/bundles/`.

This is the first of two patches in a series that has already undergone significant review and is queued for integration. The implementation is technically sound with robust test coverage, though documentation updates remain outstanding from prior reviews. The performance benefits are clear, with the author noting "significantly helps the subsequent fetch" by including more references in negotiation.
