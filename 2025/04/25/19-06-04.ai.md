Performance optimization for bundle-uri reference handling, part 1/2 of v5 series. This patch expands the reference namespace handling in `bundle-uri.c` from just `refs/heads/` to all `refs/` prefixes while maintaining hierarchy by placing them under `refs/bundles/heads/`. The key change is a one-line modification to `skip_prefix` in `bundle-uri.c` to remove the hardcoded `heads/` restriction. 

The patch includes extensive test updates in `t/t5558-clone-bundle-uri.sh` (172 line changes) to verify the new reference hierarchy works across all bundle scenarios: path/HTTP bundles, failure modes, non-default hashes, and negotiation cases. Tests now consistently check for references under `refs/bundles/heads/` rather than directly under `refs/bundles/`. The test suite uses `for-each-ref` verification as previously suggested by Taylor Blau.

This change enables more efficient fetch negotiation by including all references from bundles rather than just branch heads, which the commit message notes provides significant performance improvements (reducing object downloads from 32% to 1% in some cases). The implementation is technically identical to the v4 version already queued by Junio Hamano, with only commit message cleanup in this v5 iteration. Documentation updates remain the only outstanding item from Phillip Wood's review.
