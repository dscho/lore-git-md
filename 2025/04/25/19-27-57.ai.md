Performance optimization for bundle-uri reference handling, part 1/2 of a v6 series. This patch expands the bundle-uri functionality to copy all references (not just `refs/heads/`) into the `refs/bundles/` namespace during clone operations, improving subsequent fetch negotiation by including more reference data. The key change is a one-line modification in `bundle-uri.c` to remove the `heads/` restriction from the `skip_prefix` check, allowing all references to be processed.

The patch updates the documentation in `bundle-uri.adoc` to reflect that the refspec is now fixed as `+refs/*:refs/bundles/*` rather than being configurable. It also includes extensive test updates (172 line changes) in `t/t5558-clone-bundle-uri.sh` to verify the new reference hierarchy where bundle references are now placed under `refs/bundles/heads/` rather than directly in `refs/bundles/`. The tests cover path-based and HTTP bundle handling, failure modes, and negotiation scenarios.
