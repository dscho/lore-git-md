Performance patch fixing benchmark behavior with alternate repository formats.

This is the first patch in Patrick Steinhardt's v4 series integrating Git's performance benchmarks with Meson. It addresses a specific issue where benchmark tests weren't properly handling repositories with non-default formats (like SHA256 object hashes or reftable ref storage).

The problem occurs when benchmarks copy a test repository - they intentionally skip copying most configuration to avoid performance skew, but this was causing failures for alternate formats since the format information wasn't being preserved. The fix extracts the source repository's format information and passes it explicitly to `git init` when setting up the benchmark.

The change is small (just 3 lines added to `t/perf/perf-lib.sh`) but important for ensuring benchmarks work correctly with all repository formats. This appears to be a straightforward technical fix that completes part of the broader Meson benchmark integration effort, which has already received maintainer approval in principle. The patch follows the series' established pattern of maintaining existing behavior while adding necessary support.
