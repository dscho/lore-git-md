This is a refactoring patch in Derrick Stolee's series to decompose `git gc` functionality into granular maintenance tasks. Patrick Steinhardt contributes a helper function that extracts worktree name retrieval logic from the pruning code, making it reusable.

The patch introduces `get_worktree_names()` in worktree.[ch] to list worktree directories from ".git/worktrees", then simplifies `prune_worktrees()` in builtin/worktree.c to use this new helper. The change replaces direct directory traversal with a cleaner interface that returns names via a strvec.

This appears to be a code hygiene improvement that doesn't change behavior, though the commit message is quite terse about the motivation beyond "will be used in a subsequent commit." The implementation looks straightforward, moving error handling and directory iteration into the new function while maintaining the same skip-dot-and-dotdot behavior. The patch is part of a larger effort but stands as a self-contained refactoring.
