This is a CI/build system patch that refines the warning messages for unavailable third-party dependencies in Git's CI system. It's part of an ongoing series addressing how Git handles external tool downloads (JGit, Perforce, Git-LFS) in CI environments.

Junio Hamano follows up on Johannes Schindelin's suggestion to improve the warning message format, changing from plain "WARNING:" to GitHub Actions' "::warning::" syntax which will make the messages more visible in CI logs. The patch also eliminates redundant warning messages that were being emitted during the download process itself, consolidating them to a single check at the end of the installation script.

The changes maintain the existing atomic download-cleanup pattern while making the output cleaner and more actionable. This appears to be a straightforward improvement that aligns with the thread's direction, though it represents Junio's preference for keeping warning messages at the final check rather than during the download process (a point where he and Johannes have previously discussed alternatives).

This is the first of two patches in this series, with the effort to make CI dependency handling both more robust and user-friendly continuing to evolve. The changes are surgical and focused specifically on message presentation, leaving the underlying download/cleanup behavior unchanged.
