This is a follow-up in the `git send-email` Outlook SMTP thread, confirming the upstreaming of OAuth2 support to perl-authen-sasl.

Erik Huelsmann announces the official release of Authen-SASL 2.1800 on CPAN, which now includes the XOAUTH2 and OAUTHBEARER authentication mechanisms that were previously discussed in this thread. This release represents the final piece of the authentication side of the solution, complementing Aditya Garg's Message-ID handling patch for Outlook SMTP servers in `git-send-email`.

The email serves as confirmation that the authentication work has successfully moved upstream, with Erik's commit (958a3aa) now part of the official CPAN distribution. This completes the separation of concerns that was a key goal of the thread - with authentication handled by perl-authen-sasl and threading behavior handled in Git's send-email implementation.

The release on CPAN means the OAuth2 support is now be available to all Perl applications using Authen::SASL, not just Git. This was the preferred approach over implementing OAuth2 directly in Git, as it benefits the broader Perl ecosystem while keeping Git's changes focused on email-specific behavior.

This email doesn't introduce new technical content but marks an important milestone in the thread by confirming the upstream availability of the authentication components. With both the Message-ID handling in Git and now OAuth2 support in perl-authen-sasl released, the original problem statement appears fully addressed through this modular approach.
