This is a feature patch series that continues the effort to fully replace `git gc` with finer-grained maintenance tasks. The cover letter explains that this implements the last remaining tasks needed to match `git gc`'s functionality, though the actual switchover isn't part of this series.

The 7 patches focus on two main tasks that `git gc` performs but weren't yet available as standalone maintenance tasks: worktree pruning and rerere garbage collection. The series starts with some preparatory refactoring in `builtin/gc.c` to extract these operations into separate functions, then implements new "worktree-prune" and "rerere-gc" maintenance tasks. Along the way it also cleans up some global variables and indentation in the gc code.

Key technical details include:
- New `get_worktrees()` helper exposed in worktree.h
- `prune_worktrees()` function extracted from gc.c
- `gc_rerere()` function extracted from gc.c
- Two new maintenance tasks added with corresponding tests
- Documentation updates in git-maintenance.adoc
- Changes touch worktree and rerere subsystems

The series appears well-structured with each patch building toward the goal. The commit messages are clear about motivations and changes. Test coverage is added for the new maintenance tasks. This looks like a solid step toward the long-term goal of deprecating `git gc` in favor of more granular maintenance control.
