This is the final patch in Patrick Steinhardt's v4 series integrating Git's benchmark infrastructure with Meson. The patch wires up three new benchmark-related configuration options that will be written to GIT-BUILD-OPTIONS.

The changes expose user controls for benchmark execution parameters:
- `benchmark_repo`: Specifies the repository to copy for performance tests (should be Git-sized)
- `benchmark_large_repo`: Specifies a larger test repository (Linux-sized)
- `benchmark_repeat_count`: Sets the number of test repetitions (default 3)

The implementation uses Meson's configuration system to properly quote string values and convert the repeat count to a string. Notably, it does not expose `GIT_PERF_MAKE_COMMAND` or `GIT_PERF_MAKE_OPTS` since those are only used by the legacy `t/perf/run` script that Meson doesn't use.

This completes the technical implementation of the benchmark integration, following the previously approved approach. All core functionality is now in place, with only documentation updates remaining as noted in the thread summary. The patch maintains consistency with the series' focus on proper build system integration while preserving existing benchmark capabilities.
