Performance optimization for bundle-uri reference handling, part 1/2 of a v6 series. This patch expands the bundle-uri functionality to copy all references (not just branches) from bundles into the `refs/bundles/` namespace, improving subsequent fetch negotiation efficiency.

The key change is a one-line modification in `bundle-uri.c` that removes the `heads/` restriction from the reference prefix check, allowing tags and other references to be included. This results in more complete object negotiation during fetches, with the commit message noting significant performance improvements (reducing downloaded objects from 32% to 1% in some cases).

The patch updates documentation to clarify the fixed refspec behavior (`+refs/*:refs/bundles/*`) and includes extensive test updates (172 lines changed) to verify the new reference hierarchy where branches now live under `refs/bundles/heads/`. The tests cover path-based and HTTP bundles, failure modes, and non-default hashes.

This is the first of two patches in a series that has already undergone several rounds of review, with all substantive feedback addressed. The implementation is now queued in Git's integration branch, indicating maintainer approval of the technical approach.
