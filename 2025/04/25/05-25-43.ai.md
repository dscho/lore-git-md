This is a platform compatibility patch in the completed series standardizing platform-specific handling in Git's Meson build system. It focuses on networking library dependencies, specifically addressing cases needed for SunOS/Solaris systems.

The patch adds detection and linking for `-lnsl` and `-lsocket` alongside the existing `-lresolv` check, matching what's already present in the autoconf-based build system (`config.mak.uname` and `configure.ac`). The change consolidates these library checks into a single array addition rather than separate conditional blocks.

Key technical details:
- Maintains the existing Windows-specific handling via `winsock`
- Changes the non-Windows path to check for all three networking libraries (`nsl`, `resolv`, `socket`) in one operation
- Uses Meson's `find_library()` with `required: false` to gracefully handle missing libraries
- The libraries are added to the existing `networking_dependencies` array which ultimately gets included in `libgit_dependencies`

This completes the platform-specific networking library handling portion of the build system modernization, ensuring Solaris compatibility matches the autoconf behavior. The change is straightforward and aligns with the series' goal of standardizing platform-specific checks in the Meson build.
