This is a CI/build system patch addressing a Windows-specific test hang. Johannes Schindelin reports that the t7001-mv test consistently times out after six hours in GitHub Actions when running Meson builds with `--vsenv`. The culprit is a test case that triggers an assertion failure, which on Windows in Debug mode pops up a modal dialog that hangs CI.

The fix is straightforward: build in Release mode (like the VS-based Windows CI already does) where assertions don't show dialogs. The change modifies the Meson setup command in GitHub Actions to include `-Dbuildtype=release`. This appears to be a well-justified tweak to prevent wasted resources, though it's notable that the problematic test case itself is described as demonstrating a known bug rather than testing fixed behavior.
