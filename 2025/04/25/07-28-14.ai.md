This is a performance test infrastructure patch in Patrick Steinhardt's v4 series integrating Git's benchmark system with Meson. The patch addresses Perl script portability in the performance test framework.

The change makes three adjustments to ensure Perl scripts work across different system configurations:
1. Updates the shebang in `aggregate.perl` to use `/usr/bin/env` for better portability
2. Modifies `perf-lib.sh` to use the configured `PERL_PATH` when executing `min_time.perl`
3. Updates the `run` script to similarly use `PERL_PATH` for `aggregate.perl` execution

The patch solves a real problem where performance tests would fail on systems with non-standard Perl locations (like NixOS) by leveraging Git's existing Perl path configuration. This builds on the series' goal of making the benchmark infrastructure more robust and portable, particularly important as part of the Meson integration work. The changes are straightforward and maintain existing behavior while improving compatibility.
