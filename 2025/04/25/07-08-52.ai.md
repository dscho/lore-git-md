This is the first patch in Patrick Steinhardt's v2 series refactoring the object store subsystem, part of the ongoing `the_repository` removal effort. The patch moves the `struct packed_git` definition and related `pack_map_entry_cmp()` function from the generic `object-store.h` header to the more specific `packfile.h` header where they more naturally belong.

The change is a straightforward header reorganization that:
- Removes 59 lines from `object-store.h` (leaving just a forward declaration)
- Adds the same content to `packfile.h` (plus one new include)
- Updates `pack-objects.h` to include `packfile.h` since it needs the moved definition

The rationale is that `struct packed_git` contains packfile-specific details that don't belong in the generic object store header. This is a clean, mechanical change that doesn't modify any behavior - it just improves code organization by putting packfile-related definitions together. The patch is well-contained and uncontroversial, serving as groundwork for the more substantive changes that follow in the series.
