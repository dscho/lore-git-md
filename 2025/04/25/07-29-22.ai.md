This is a refactoring patch in Patrick Steinhardt's series to decompose `git gc` functionality into standalone maintenance tasks. It focuses on the rerere garbage collection component.

The patch extracts the rerere garbage collection logic from `cmd_gc()` into a new `maintenance_task_rerere_gc()` function, following the same pattern used earlier in the series for worktree pruning. The new function creates a child process to run `git rerere gc`, matching the original behavior but now in a standalone form suitable for the maintenance framework.

Key technical changes include:
- New `maintenance_task_rerere_gc()` function in builtin/gc.c
- Removal of the `rerere_cmd` variable from `cmd_gc()`
- Conversion to use the maintenance task function signature with `opts` and `cfg` parameters
- Error handling remains identical via `die(FAILED_RUN, "rerere")`

This is a straightforward structural change that completes the extraction of rerere garbage collection from the monolithic gc command, preparing for its inclusion as a standalone maintenance task in the next patch. The implementation is clean and maintains all existing functionality while fitting into the maintenance task framework.
