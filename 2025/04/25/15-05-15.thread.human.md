This thread addressed a Windows CI issue where test hangs occurred in Meson-based GitHub Actions workflows. The core fix was switching to Release mode builds via `-Dbuildtype=release` in the Meson configuration, which resolved assertion-related hangs. The discussion evolved to include Visual Studio environment setup, specifically whether the `--vsenv` flag (originally added to properly configure VS builds) should be preserved when backporting to the 'maint' branch.

The CI configuration change has achieved consensus, with Acked-by tags from both Johannes Schindelin (Git for Windows maintainer) and Patrick Steinhardt. Johannes confirmed that the assertion behavior triggering the Debug-to-Release change appears to be Visual Studio-specific, and both agree the `--vsenv` flag should be preserved alongside the Meson change for correct Visual Studio environment setup. Junio Hamano is preparing to integrate these changes to 'maint' after this final clarification.

While this thread is now effectively resolved, a parallel discussion continues about the underlying `git mv` behavior that surfaced these test issues, where Patrick Steinhardt is working on fixes for parent/child directory move edge cases. The CI configuration changes will proceed independently of that ongoing work.
