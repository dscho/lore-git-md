Refactoring patch in Derrick Stolee's maintenance task decomposition series. This is patch 2/7 in the v1 series that aims to complete the standalone maintenance tasks needed to eventually replace `git gc`.

Patrick Steinhardt contributes a cleanup of `builtin/gc.c`, removing several global variables that were only needed locally for assembling subprocess arguments. The patch eliminates `prune`, `prune_worktrees`, and `rerere` strvec globals, instead constructing the command arguments directly in the functions where they're used. Only the `repack` strvec remains as a global since it's used in multiple places.

This appears to be a straightforward code hygiene improvement that reduces unnecessary global state, though it's somewhat tangential to the main goal of the series (which is extracting worktree and rerere maintenance tasks). The changes are mechanical and don't affect functionality - they just make the code's data flow more localized and explicit. The patch maintains all existing behavior while simplifying the code structure.
