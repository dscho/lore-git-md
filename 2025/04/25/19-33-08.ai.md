Performance optimization for bundle-uri reference handling, part 1/2 of a v7 series that has already been approved for merging. This patch expands the reference namespace handling in bundle-uri functionality from just `refs/heads/` to all `refs/` namespaces while preserving hierarchy under `refs/bundles/`. The key change is a one-line modification in `bundle-uri.c` to remove the `heads/` restriction in the `skip_prefix` check, allowing all references to be copied into the bundle namespace.

The patch updates documentation in `bundle-uri.adoc` to reflect that the refspec is now fixed as `+refs/*:refs/bundles/*` rather than being configurable. It also includes extensive test updates in `t/t5558-clone-bundle-uri.sh` (172 line changes) to verify the new reference placement under `refs/bundles/heads/` rather than directly under `refs/bundles/`. The test changes are mechanical updates to reference paths rather than functional changes.

This is the final iteration of a series that has already addressed all substantive feedback, with v7 containing only whitespace fixes to documentation. The change provides significant performance benefits (reducing object downloads from 32% to 1% in testing) by including all references in fetch negotiation rather than just branch heads. The implementation is now queued in Junio Hamano's `seen` branch and considered ready for merging.
