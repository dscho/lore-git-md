Refactoring patch completing Patrick Steinhardt's 13-part series modernizing Git's object store subsystem as part of the `the_repository` removal effort. This final patch removes the now-obsolete `repo_has_object_file()` and `repo_has_object_file_with_flags()` functions after all callers have been converted to use the new `has_object()` API introduced earlier in the series.

The changes are straightforward deletions of the deprecated functions and their documentation from both object-store.c and object-store.h, totaling 31 lines removed. The patch follows through on the series' architectural direction of replacing the old API that implicitly handled promisor object fetching with the more explicit `has_object()` that gives callers control over this behavior through flags (`HAS_OBJECT_FETCH_PROMISOR` and `HAS_OBJECT_RECHECK_PACKED`).

This completes the technical work of the series, which has already received positive review feedback on earlier parts from Karthik Nayak. The removal of these functions was telegraphed in their documentation (marked as deprecated in previous patches) and represents the logical conclusion of the API migration. No performance impact validation is included in this patch, as that was handled in earlier parts of the series when the new API was introduced and callers were converted.
