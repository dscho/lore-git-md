Final patch in a series standardizing platform-specific handling in Git's Meson build system, specifically addressing networking function checks on non-Windows platforms. This completes a 6-patch effort to align the Meson build with existing Makefile behavior while improving cross-platform compatibility.

The patch makes two key changes to how Git checks for networking functions (inet_ntop, inet_pton, hstrerror) during Meson builds. First, it skips these checks entirely on Windows, where the functions don't exist, saving build time. Second, it properly adds compatibility implementations (from compat/*.c) when functions are missing on other platforms, matching the behavior of the Makefile build system.

The author notes this corrects an inconsistency with CMake's approach, which incorrectly labeled hstrerror as "incompatible" with Windows rather than simply nonexistent. The change maintains the series' pattern of generating NO_ macros for missing functions while adding the missing compatibility layer.

This concludes the platform-specific function checking work in the Meson build system, with all issues around getpagesize(), sysinfo(), and Solaris networking libraries now resolved. The patch follows the established technical approach of the series and has already been merged, marking the completion of this particular build system modernization effort.
