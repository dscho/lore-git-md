This is a refactoring patch in Patrick Steinhardt's ongoing series to clean up the object store subsystem, part of the larger `the_repository` removal effort.

The patch removes the `loose_object_path()` function, which was a thin wrapper around `odb_loose_path()` that always used the primary object database. The change inlines this simple functionality at all call sites (in http-walker.c, http.c, and object-file.c) while maintaining the same behavior. The documentation for `odb_loose_path()` is moved to object-file.h where the function is declared.

This is a straightforward cleanup that eliminates an unnecessary layer of indirection. The changes are mechanical and well-contained, touching only the specific files that used the removed function. As part of a larger refactoring series that has already received positive review feedback, this patch appears uncontroversial and aligns with the project's ongoing codebase modernization efforts.
