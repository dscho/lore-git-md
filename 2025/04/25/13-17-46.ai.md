Performance optimization patch for bundle-uri reference handling, part 1/2 in v4 series. This patch expands the bundle-uri functionality to copy all references from `refs/` namespaces (not just `refs/heads/`) into `refs/bundles/` while preserving hierarchy, which significantly optimizes subsequent fetch negotiation by including more reference tips. The core change is a one-line modification in `bundle-uri.c` to remove the `heads/` restriction from the `skip_prefix` check.

The bulk of the patch updates the test suite (`t/t5558-clone-bundle-uri.sh`) to reflect the new reference hierarchy, changing all `refs/bundles/` checks to `refs/bundles/heads/` where appropriate. Test coverage remains comprehensive, verifying behavior for:
- Path-based and HTTP bundles
- Various failure modes (bad headers, bad objects)
- Non-default hash algorithms
- Bundle list negotiation scenarios
- CreationToken heuristic behavior

This version incorporates all test improvements requested in previous reviews, including Taylor Blau's direct `for-each-ref` verification approach. The implementation appears solid with thorough test coverage, though documentation updates (to be addressed in a follow-up) are still needed to explain the new reference hierarchy behavior. The changes maintain backward compatibility while enabling the performance benefits of broader reference inclusion in bundle negotiation.
