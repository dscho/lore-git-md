This is a CI/build system patch that refines the warning message handling for unavailable third-party dependencies in Git's CI setup. It's part of the ongoing series addressing CI reliability around external downloads (JGit, Perforce, Git-LFS).

The patch removes redundant warning messages that were added during the download phase, consolidating them to the final check at script's end. This maintains cleaner output while preserving the same information. It also implements Johannes Schindelin's suggestion to change the warning format from "WARNING:" to "::warning::" which GitHub Actions will display more prominently in CI summaries.

Key technical changes:
- Removes 3 per-download warning messages from the atomic download-cleanup blocks
- Keeps the final dependency check warnings but reformats them
- Maintains the same error handling flow (rm on failure) but with less output
- Changes warning format to GitHub Actions' preferred "::warning::" syntax

The change reflects Junio's position in the thread that warnings should appear at the final check rather than during download, while incorporating Johannes' suggestion about making them more visible. This patch doesn't address the caching discussion happening in parallel - it's focused purely on message presentation.

The implementation is straightforward and maintains all existing safety checks while reducing noise. The warning format change should make CI failures more noticeable without requiring any GitHub Actions configuration changes.
