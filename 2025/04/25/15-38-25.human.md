This is a follow-up to the CI/build system patch series addressing external dependency downloads, specifically updating the JGit source and improving warning messages. The two patches refine the earlier solution that was fast-tracked to handle eclipse.org outages.

The first patch updates the warning message shown when third-party software like JGit, Perforce, or Git-LFS is unavailable. The new message is clearer about which specific dependency failed to download. The second patch switches JGit downloads from eclipse.org to Maven Central as a more reliable source, implementing Johannes Schindelin's suggestion from earlier discussion.

These changes build on the core solution that treats downloads as atomic operations (download+chmod succeeds or fails completely) while maintaining the current warning presentation approach that Junio prefers (showing warnings at final check rather than during download). The patches are minimal tweaks to the already-accepted approach, keeping the same error handling patterns but improving both the user messaging and download reliability.

The series doesn't address the newer caching discussion that emerged in the thread, focusing instead on these immediate refinements to the outage-handling solution. The changes are straightforward with clean diffs (21 lines changed total) and since they're based on maintainer-approved directions from the ongoing discussion, they'll likely be uncontroversial.
