Feature request for `git blame` to handle missing ignore-revs files more gracefully. 

Michael Grosser proposes two solutions to make `.git-blame-ignore-revs` more convenient for users who maintain this file across multiple repositories. Currently, setting a global `blame.ignoreRevsFile` configuration fails when the file doesn't exist in a given repository, producing a fatal error. 

The first suggested approach would make `git blame` automatically check for `.git-blame-ignore-revs` in each repository without requiring explicit configuration. The second, more flexible solution proposes adding a `blame.ignoreMissingFile` boolean option that would suppress the fatal error when the configured ignore file is absent. 

The proposal appears well-motivated by real-world usability concerns - the current workaround requires either per-repo configuration or remembering to create empty ignore files in repositories that don't need them. The suggested solutions maintain backward compatibility while addressing the pain point. No implementation details or patches are provided in this initial feature request email.
