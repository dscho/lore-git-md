This is a technical follow-up in the Meson build system thread about shell path reporting. Eli Schwartz points out a simplification opportunity in Patrick Steinhardt's patch that adds runtime executable path reporting to the Meson build summary.

The original patch explicitly checked whether Perl and Python were found before displaying their paths, but Schwartz notes Meson's `summary()` already handles this automatically - it will show the full path when found and mark missing programs clearly in red. This would make the conditional checks redundant while maintaining the same functionality.

The suggestion is a minor cleanup that doesn't affect the patch's core purpose of making detected paths visible during configuration.
