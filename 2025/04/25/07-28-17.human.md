This is the final patch in Patrick Steinhardt's v4 series integrating Git's performance test infrastructure with Meson. It wires up three benchmarking configuration options that will be written to the GIT-BUILD-OPTIONS file.

The patch adds explicit Meson options for:
- `benchmark_repo` - specifies the repository to copy for performance tests (should be Git-sized)
- `benchmark_large_repo` - specifies a larger test repository (Linux-sized)
- `benchmark_repeat_count` - sets how many times tests should be repeated (defaults to 3)

These options complement the existing `benchmarks` feature flag that was added earlier in the series. The implementation is straightforward, converting the Meson options into the appropriate build configuration variables. Notably, it doesn't expose `GIT_PERF_MAKE_COMMAND` or `GIT_PERF_MAKE_OPTS` since those are used by the legacy `t/perf/run` script that Meson uses.

This completes the technical implementation of the Meson benchmark integration, following the approach previously approved by Junio Hamano. The patch maintains consistency with the existing test infrastructure while providing proper Meson integration points.
