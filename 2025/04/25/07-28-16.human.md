This is part of Patrick Steinhardt's series to integrate Git's performance benchmarks with the Meson build system. The patch specifically wires up the benchmark infrastructure, making 47 existing performance tests available through Meson's benchmark runner.

The implementation mirrors the test infrastructure but with key differences: benchmarks don't run in parallel, aren't executed by default with tests, and avoid MALLOC_PERTURB interference. Users can run benchmarks via `meson test --benchmark` with the same filtering patterns as regular tests. The patch maintains compatibility with the existing `t/perf/run` script for cross-version comparisons, though future Meson support for that is noted as out of scope.

The changes add a new `benchmarks` feature option (defaulting to auto-detection), require GNU `time` when benchmarks are enabled, and include benchmark status in Meson's summary output. The implementation appears thorough, with proper handling of Perl and path dependencies that were discussed earlier in the thread. This completes the core functionality for benchmark support in Meson, leaving only documentation updates as remaining work in the series.
