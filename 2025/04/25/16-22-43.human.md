This is a brief follow-up in the `git send-email` Outlook SMTP handling thread, confirming the upstream status of the OAuth2 authentication work. Erik Huelsmann notes that the XOAUTH2/OAUTHBEARER support in perl-authen-sASL (which was split off from Aditya Garg's original patch series) has now been officially released as Authen-SASL-2.1800 on CPAN. This marks the completion of the authentication portion of the work, leaving only the Outlook-specific Message-ID handling changes in Git itself. The update provides a clear reference point for future documentation about OAuth2 support in `git send-email`. No new technical changes are proposed here - it's simply a status update confirming the upstream work is now production-ready.
