This is a two-patch series addressing shell path detection in Meson builds, following up on cross-compilation issues reported at GitLab and Debian. The core change makes Meson prefer `/bin/sh` (the POSIX-specified path) over PATH lookups to avoid discrepancies between build and target hosts.

The first patch simplifies how detected runtime executable paths (Perl, Python, shell) are reported in the build summary. The second patch implements the main fix by explicitly prioritizing `/bin/sh` in the search path while maintaining the ability to override via `program_path`. A new comment explains this search order priority, addressing feedback from the previous version.
