This is the final version (v6) of Aditya Garg's patch to fix thread tracking in `git send-email` when using Outlook SMTP servers. The patch has been reduced to its essential core - handling Outlook's nonstandard Message-ID rewriting behavior - after successfully upstreaming the OAuth2 authentication work to perl-authen-sasl (PR #19).

The technical solution detects Outlook servers (smtp.office365.com/smtp-mail.outlook.com) via an `is_outlook()` helper, then parses the SMTP response to retrieve Outlook's assigned Message-ID when present. This 21-line change in git-send-email.perl ensures proper threading by using the server-assigned ID for In-Reply-To and References headers, while maintaining backward compatibility with other email providers.
