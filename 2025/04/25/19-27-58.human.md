This is the second and final patch in a performance optimization series for bundle-uri reference negotiation, adding test coverage for tag handling. The series expands bundle-uri's reference handling to support all ref namespaces (not just branches) while preserving hierarchy, which has shown significant performance improvements (reducing object downloads from 32% to 1% in some cases).

This specific test addition verifies that tags in bundles are properly transferred during clones and included in subsequent fetch negotiations. The test creates a repository with branches and tags, bundles it, then clones using the bundle and verifies all references (including tags) are correctly placed under the `refs/bundles/` hierarchy. The test follows the verification approach suggested by Taylor Blau, using `for-each-ref` with lstrip to compare references.
