This is a performance and platform compatibility patch series for the Meson build system, addressing shell path detection issues in cross-compilation scenarios. The series has gone through multiple iterations (now at v3) to refine the approach and address feedback from various contributors.

The core issue stems from Meson's PATH-based shell lookup, which can cause problems when the build host and target host have different shell locations. The solution modifies the detection to prefer `/bin/sh` (a common but not POSIX-mandated path) while maintaining user configurability. The second patch in particular changes the path search order to append `/bin` rather than prepend it, ensuring user-configured paths still take precedence.

Notable changes in this version include dropping an incorrect claim about POSIX compliance (following feedback from brian m. carlson) and clarifying the rationale for choosing `/bin/sh` based on practical compatibility across Linux/BSD systems and alignment with the Makefile's default behavior. The series appears technically sound, with all substantive feedback from previous rounds incorporated, and seems ready for final review.
