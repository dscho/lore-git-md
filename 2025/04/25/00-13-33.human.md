This is a platform compatibility patch in a completed 6-part series modernizing Git's Meson build system for various platforms. It specifically addresses networking library dependencies on Solaris (SunOS) systems.

The patch adds checks for and links against `-lnsl` and `-lsocket` libraries when available, in addition to the existing `-lresolv` check. This matches behavior already present in Git's traditional `config.mak.uname` and `configure.ac` build systems, ensuring consistent networking functionality across platforms.

The change is straightforward - it converts the single-library check into an array of optional library dependencies. The implementation is clean and maintains the existing code's pattern of optional linking. Since this is part of a completed series that has already been reviewed and merged, it represents a final polish to ensure Solaris compatibility in the Meson build.
