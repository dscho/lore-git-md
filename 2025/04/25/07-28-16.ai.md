This is a performance-related patch in Patrick Steinhardt's v4 series integrating Git's benchmark infrastructure with Meson. It wires up 47 existing performance benchmarks to work under Meson's build system while maintaining compatibility with the existing `t/perf/run` script for more complex use cases.

The patch introduces several key technical elements:
- Benchmarks are registered via Meson's `benchmark()` function rather than `test()`, giving them special treatment (no parallel execution, not run by default with tests, no `MALLOC_PERTURB` injection)
- The `time` program is now a required dependency when benchmarks are enabled
- Benchmark execution follows the same pattern as tests but uses the `--benchmark` flag
- The implementation preserves the existing benchmark environment setup while adding `GTIME` for GNU time path
- All 47 existing performance tests from `t/perf/` are listed explicitly in the Meson build file

The patch maintains the series' approach of keeping the feature optional (controlled by the `benchmarks` meson option) and properly integrates with the build system's dependency tracking. It explicitly notes that more complex benchmarking scenarios (like comparing Git versions) should still use the existing `t/perf/run` script, leaving Meson integration of that script as future work.

This appears to be a straightforward implementation of the benchmark wiring that completes the pattern established by the test integration earlier in the series. The patch maintains consistency with existing behavior while properly adapting to Meson's conventions.
