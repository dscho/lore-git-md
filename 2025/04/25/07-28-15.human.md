Performance test infrastructure patch for out-of-tree builds in the Meson integration series.

This is the third patch in Patrick Steinhardt's v4 series to integrate Git's performance benchmarks with the Meson build system. It fixes a key assumption in the benchmark infrastructure that currently breaks with out-of-tree builds (used by both CMake and Meson).

The core issue is that `perf-lib.sh` assumes the build and source directories are the same, which isn't true for Meson/CMake builds. The patch makes two main changes:
1. Adds logic to properly locate the build directory, either via `GIT_BUILD_DIR` environment variable (for Meson) or by traversing up from the test directory (for Makefile builds)
2. Updates the Perl aggregation script path to use the correct source directory location

The changes include Windows path handling via `cygpath` and maintain all existing functionality while adding the new build system compatibility. This is a straightforward technical change that completes an important piece of the Meson benchmark integration, following the approach already approved by the maintainers. The patch appears well-tested with clear commit message explanations of both the problem and solution.
