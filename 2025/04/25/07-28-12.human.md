This is a feature patch series integrating Git's performance benchmarks with the Meson build system. Patrick Steinhardt's v4 series builds on previous consensus about the benchmark implementation approach, now adding configuration options and dependency handling.

The series enables running `t/perf` benchmarks through Meson while maintaining the existing `t/perf/run` script for more advanced use cases. The key addition in v4 is a new `benchmarks` feature option that can be set to `auto` (default), `enabled`, or `disabled`, with `auto` silently disabling benchmarks when dependencies (Perl and GNU `time`) are missing. The series also properly declares Perl as a benchmark dependency and reports benchmark status in the build summary.

Implementation-wise, the patches fix several benchmark issues: handling alternate repository formats, using the configured PERL_PATH, and supporting out-of-tree builds. The changes appear well-contained, touching only build system files and benchmark infrastructure. The series has already addressed previous feedback and gained maintainer approval for the core approach in earlier versions.
