This is a platform compatibility patch in the completed 6-patch series modernizing Git's Meson build system for platform-specific handling. It focuses on networking library dependencies, particularly for Solaris (SunOS) systems.

The patch adds checks for and links against `-lnsl` and `-lsocket` libraries alongside the existing `-lresolv` check, matching behavior that was previously implementing in the autoconf-based build system. The change consolidates these library lookups into a single array-style addition to `networking_dependencies`, making the build more maintainable.

Key technical details:
- Maintains compatibility with Solaris systems where these additional networking libraries are needed
- Preserves the existing Windows-specific handling via `winsock`
- Uses Meson's `find_library()` with `required: false` to gracefully handle missing libraries
- The change is minimal and focused, touching only the meson.build file

This appears to be a straightforward platform compatibility improvement that completes the platform-specific work in the series. The patch follows the established pattern from earlier in the series and doesn't introduce new concepts or mechanisms.
