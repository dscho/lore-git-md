This is part 4 of Patrick Steinhardt's 13-patch refactoring series cleaning up the object store subsystem, which is part of the larger `the_repository` removal effort. The patch focuses on header reorganization by moving function declarations from "object-store.h" to their proper subsystem-specific locations.

The changes relocate declarations for loose object handling functions to "object-file.h" and packed object iteration functions to "packfile.h". This makes the headers better reflect where the actual implementations live, reducing the "object-store.h" size by 91 lines while adding 73 lines to "object-file.h" and 19 to "packfile.h". The patch updates include directives in several files to point to the new header locations.

This is a straightforward code organization improvement that follows logically from the earlier patches in the series. The changes are mechanical and well-contained, with no behavior modifications. Karthik Nayak has already reviewed and approved the earlier patches in this series, and this one appears equally well-crafted. The patch helps advance the overall goal of reducing `object-store.h` to just forward declarations.
