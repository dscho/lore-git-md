This is a build system patch that improves visibility into detected runtime paths during Meson builds. It's part of a two-patch series addressing cross-compilation reliability issues, with this first patch focusing on better reporting.

The change adds a summary section to Meson's build output that shows which executable paths were detected for Perl, Python, and the system shell. This makes the build process more transparent by explicitly showing which binaries will be used at runtime, rather than having developers infer this from PATH lookups.

The patch is small (6 lines) and straightforward, adding the summary output without changing any actual path detection behavior. It follows the thread's established direction after incorporating feedback rounds, including simplified diagnostic output as suggested by Eli Schwartz. The change helps developers understand and verify the runtime environment configuration, particularly useful for debugging cross-compilation scenarios where PATH discrepancies can cause issues.
