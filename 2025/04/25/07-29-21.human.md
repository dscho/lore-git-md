This is a feature patch in Derrick Stolee's series to decompose `git gc` into granular maintenance tasks. It introduces a new "worktree-prune" task for `git maintenance` that handles stale worktree cleanup, matching functionality previously only available through `git gc`.

The patch adds the new task implementation with proper condition checking to determine when pruning is needed, following the pattern of other maintenance tasks. It includes documentation updates and tests verifying both manual execution and auto-mode behavior (where pruning only occurs when stale worktrees are detected). The implementation builds on Patrick Steinhardt's earlier helper function for worktree name handling from patch 4/7.

This is a straightforward addition that fills a clear gap in the maintenance command's capabilities. The code appears well-structured with appropriate test coverage, moving Git closer to the goal of making `git gc` obsolete through specialized maintenance tasks.
