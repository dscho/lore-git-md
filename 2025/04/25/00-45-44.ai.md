This is a technical refinement to the Meson build system patch series about runtime executable path detection. Eli Schwartz provides a suggested simplification to Patrick Steinhardt's diagnostic patch that reports detected paths for Perl, Python, and shell executables.

The key observation is that Meson's `summary()` function already handles the "not found" case by displaying "NO" in red, making the explicit ternary checks (`target_perl.found() ? ... : 'none'`) redundant. The proposed change would simplify the output section by just passing the raw target variables.

This builds on the thread's focus on improving build system reliability while maintaining clarity. The suggestion aligns with Meson's built-in conventions and would make the code slightly more maintainable by removing conditional logic that duplicates framework functionality. The change doesn't affect the actual path detection behavior - it's purely about presentation in the build summary output.
