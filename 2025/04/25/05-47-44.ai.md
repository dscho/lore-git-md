This is part of the ongoing Meson build system improvements, specifically addressing runtime path detection. The patch adds explicit reporting of detected paths for Perl, Python, and shell executables during Meson configuration.

The change exposes the detected paths (stored in `target_perl`, `target_python`, and `target_shell` variables) via Meson's summary output mechanism. This makes the build configuration more transparent by showing which executables will be used at runtime, which was previously only visible by examining Meson's internal state. The implementation matches the existing summary format used for backend configuration reporting.

The patch is a straightforward 6-line addition that doesn't change any behavior - it only adds diagnostic output. This builds on previous thread discussion where participants requested clearer visibility into detected paths. The change is part of a 2-patch series that has already incorporated multiple rounds of feedback, with this particular patch implementing Eli Schwartz's suggestion for simplified diagnostic output. The series as a whole aims to improve cross-compilation reliability by making path detection more robust and transparent.
