This is a CI/build system patch that updates the source for downloading JGit in Git's CI infrastructure. 

The patch changes the download URL for JGit from eclipse.org to maven.org, following a recommendation from JGit maintainer Matthias Sohn. This appears to be a straightforward maintenance update rather than a functional change - the same JGit version is being downloaded, just from a different repository location.

The change is part of an ongoing series improving CI dependency handling, though this particular patch focuses narrowly on the JGit download source. Johannes Schindelin provided input (as noted in the Helped-by tag), and Junio Hamano is submitting the final version.

The implementation is minimal - just a one-line URL change in ci/install-dependencies.sh. Given the maintainer recommendation and simple nature of the change, this appears to be a low-risk update that aligns with the broader CI stability improvements being made.
