This is a v4 patch series implementing Meson build system support for Git's performance benchmarks, following up on previous consensus about the feature option approach for `time` command handling.

The series now introduces a new 'benchmarks' Meson option with three states (auto/enabled/disabled) that cleanly handles the GNU `time` dependency while maintaining compatibility with existing test infrastructure. The default 'auto' setting matches current behavior by silently disabling benchmarks if dependencies are missing, while 'enabled' provides strict checking as requested in earlier discussion. The implementation confirms the GNU `time` requirement matches the existing `USR_BIN_TIME` prerequisite.

Key technical additions in v4 include:
- New `benchmarks` feature option with auto-detection
- Explicit Perl dependency for benchmarks
- Benchmark status reporting in Meson summary
- Two new benchmark-related Meson options for repository paths
- Rebase on latest master to resolve conflicts

The implementation remains focused on single-tree benchmarking via Meson while deferring more complex multi-tree scenarios to the existing `t/perf/run` script. All core functionality appears complete following the v3 technical resolution, with this version adding the agreed-upon user-facing controls. The series now awaits final review pending documentation of the new feature option behavior.
