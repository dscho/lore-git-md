This is part 6 of a 7-patch series implementing standalone maintenance tasks to replace `git gc` functionality, specifically focusing on rerere garbage collection.

The patch extracts the rerere garbage collection logic from `cmd_gc()` into a new `maintenance_task_rerere_gc()` function, following the same pattern used earlier in the series for worktree pruning. The new function maintains the same behavior - it runs `git rerere gc` as a subprocess - but now does so through the maintenance task interface. This is a straightforward refactoring that removes the temporary `rerere_cmd` variable from `cmd_gc()` and prepares for the new "rerere-gc" maintenance task that will be introduced in the next patch.

The change is clean and mechanical, matching the established pattern from earlier in the series. It touches only builtin/gc.c and doesn't introduce any new behavior, just reorganizes existing code to fit the maintenance task model. This continues the series' steady progress toward decomposing all `git gc` functionality into discrete maintenance tasks.
