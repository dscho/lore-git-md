Derrick Stolee continues his long-running effort to decompose `git gc` into granular maintenance tasks with this series implementing the final two missing components: worktree pruning and rerere garbage collection. The current focus is on the worktree pruning aspect, with Patrick Steinhardt contributing refinements to the implementation.

The series introduces a new `worktree-prune` maintenance task that replicates `git gc`'s worktree pruning behavior with a 3-month expiry threshold. The implementation includes proper test coverage for both manual invocation and automatic pruning when stale worktrees are detected. Patrick has contributed several improvements to the original submission, including code hygiene patches and a helper function to cleanly handle worktree name scanning.

This represents the penultimate step in Stolee's multi-year effort to replace the monolithic `git gc` with focused maintenance subcommands. Once the parallel rerere garbage collection task is implemented, all core gc functionality will be available as individual maintenance operations. The patches show careful attention to maintaining backward compatibility while providing a cleaner architectural foundation.
