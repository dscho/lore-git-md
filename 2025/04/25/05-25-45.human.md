This is the final patch in a completed 6-part series standardizing platform-specific handling in Git's Meson build system. The patch focuses on networking function checks, specifically correcting the handling of `inet_ntop`, `inet_pton`, and `hstrerror` functions on Windows.

The change makes two key improvements: First, it skips checking for these networking symbols entirely on Windows (where they don't exist), which slightly speeds up the build configuration. Second, it properly adds compatibility implementations (from compat/*.c files) when these functions are missing on non-Windows systems, matching the behavior already present in the Makefile build system.

The patch represents the culmination of the platform-specific fixes in this series, having addressed all technical concerns raised during review. It follows the established pattern of the series by centralizing function checks and properly handling platform differences. With this change, the networking library detection and function availability checking is now fully aligned between Meson and the traditional Makefile build system.
