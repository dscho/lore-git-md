Platform compatibility patch in a completed series standardizing Meson build system checks. This third patch in the 6-part series fixes Solaris-specific handling of the `sysinfo.h` header.

The patch replaces a simple header existence check with a more precise verification that `struct sysinfo` contains the `totalram` field Git actually uses in `builtins/gc.c`. This correctly handles Solaris systems where `sys/sysinfo.h` exists but provides incompatible functionality. The author notes Solaris's different `sysinfo()` API but leaves Solaris support as a potential follow-up for interested contributors.

This change is part of Eli Schwartz's broader effort to improve cross-platform compatibility in Git's Meson build system, with all technical and style concerns in the series already addressed and merged. The patch demonstrates the series' approach of replacing simplistic checks with precise usage-based verification.
