This is a platform compatibility patch in the completed series standardizing platform-specific handling in Git's Meson build system. It specifically addresses Solaris compatibility for the `sysinfo` function check.

The patch changes how we verify availability of the Linux-style `sysinfo` functionality by checking for the specific struct member (`totalram`) we actually use in `builtins/gc.c`, rather than just checking for the header existence. This correctly handles Solaris systems where `sys/sysinfo.h` exists but provides a completely different API with different semantics.

Key technical details:
- Removes simple `sys/sysinfo.h` header check that was too broad
- Adds precise check for `struct sysinfo.totalram` member we actually need
- Documents Solaris's incompatible `sysinfo()` implementation that takes different parameters
- Maintains same `HAVE_SYSINFO` define but with more accurate detection

The change is part of the broader effort to make platform detection more precise in the Meson build system, following the pattern established earlier in the series for other platform-specific checks. The patch is now final with all requested changes implemented.
