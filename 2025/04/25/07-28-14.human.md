This is a performance test infrastructure patch in Patrick Steinhardt's v4 series integrating Git's benchmark system with Meson. The patch addresses Perl script portability in the performance test framework.

The change makes the benchmark Perl scripts respect the configured `PERL_PATH` rather than hardcoding `/usr/bin/perl`, which improves compatibility with systems like NixOS where Perl may be installed in non-standard locations. It also updates the shebang to use `#!/usr/bin/env perl` for better portability when scripts are run directly.

The modification touches three files: the main aggregation script, the performance test library, and the test runner. Each is updated to explicitly use `$PERL_PATH` when invoking Perl scripts. This is a straightforward improvement that aligns with Git's existing build system behavior where Perl location is configurable.

This patch is part of the larger effort to properly support performance benchmarks in the Meson build system, with previous discussion having established the approach. The change is small and focused, with clear motivation and straightforward implementation.
