This is the first patch in a 6-part series refactoring Git's Meson build system to standardize function availability checks. The series has already gone through previous iterations addressing technical debates, and this version appears ready for adoption.

The patch simplifies repetitive function availability checks in meson.build by introducing an array-based approach. Instead of individual checks for each function (like `strcasestr`, `memmem`, etc.), it now processes them through a unified loop that automatically handles the common pattern of defining `NO_` macros and including compatibility implementations when needed. The change reduces code duplication while maintaining the same functionality, with special handling for Windows-specific cases like `mmap`.

The refactoring is clean and focused, touching only the build system logic without affecting runtime behavior. It's part of a broader effort to modernize Git's build infrastructure as the project transitions away from autoconf. The patch follows the series' established patterns and appears well-tested, with all prior discussion points from the mailing list already addressed.
