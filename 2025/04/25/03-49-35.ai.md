This is a security-focused follow-up in the `index-pack` bugfix thread regarding REF_DELTA chain handling. Derrick Stolee responds to Junio Hamano's concerns about maintaining protection against malicious cyclic packfiles while allowing valid REF_DELTA chains.

The key security verification points are:
1. The test suite's existing REF_DELTA cycle detection test (t5309) remains unchanged and continues to catch true cycles
2. The patch maintains safety by failing when encountering unresolvable REF_DELTAs where base objects are missing (preventing partial expansion of cyclic deltas)

This addresses Junio's concern about on-the-wire attacks by maintaining the failure path for unresolvable deltas.
