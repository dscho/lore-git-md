This is a follow-up discussion about the now-finalized `git send-email` Outlook compatibility patch series, specifically regarding the OAuth2 authentication support that was split out to the Authen-SASL Perl module.

Junio Hamano acknowledges the official release of Authen-SASL 2.1800 (which includes the OAuth2/XOAUTHBEARER support needed for Outlook authentication) but raises a practical concern about distribution lag times. He's asking when this updated module will reach major Linux distributions, as Git needs to remain usable for users whose systems may not immediately get the latest Perl module updates.

The thread context indicates this was the last remaining loose end after the main Outlook Message-ID handling patch was finalized in v6. While the technical solution is complete and validated, this touches on the real-world rollout challenges that often affect Git's broad user base across different platforms and distribution cycles.
