This is the second patch in a series to wire up header checking in meson builds, following Emily Shaffer's preparatory cleanup. The patch moves header-related definitions from contrib/coccinelle/meson.build to the root meson.build file to make them available for an upcoming 'hdr-check' equivalent in meson.

Key technical changes:
- Relocates 'coccinelle_headers' to root as 'headers', removing per-header path prefixing (kept only in coccinelle build)
- Moves 'third_party_sources' exclusion list to root since it's needed for header enumeration
- Maintains same header enumeration logic using `git ls-files` but now centralized
- Touches only build system files (meson.build) with no runtime impact

The changes support future header dependency checking while cleaning up variable scoping. The patch appears mechanically sound, continuing the series' goal of matching Makefile functionality in meson. No functional changes are introduced yet - this is infrastructure preparation for the actual header check implementation expected in subsequent patches.
