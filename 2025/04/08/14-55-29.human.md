This is the final patch in a series porting the 'hdr-check' functionality from Makefile to meson builds, now renamed to the clearer 'headers-check'. The patch implements the actual header checking by creating custom build targets that verify each header can be independently compiled when included after git-compat-util.h.

The implementation carefully mirrors the Makefile version's behavior, maintaining the same exclusion list for platform-specific and generated headers. It uses meson's custom_target() infrastructure to generate temporary compilation units for each header, checking them with the same compiler flags used for the main build. The check only runs for GCC/clang syntax compilers, matching the Makefile's behavior.

The patch appears well-constructed, with a thorough exclusion list that accounts for various build configurations (SHA backends, platform headers). It completes the series' goal of making meson builds feature-complete with Makefiles for header validation. Since this builds on the preparatory work in earlier patches to centralize header definitions, the implementation here is clean and focused on the core checking logic.
