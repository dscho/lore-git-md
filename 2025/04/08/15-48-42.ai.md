This is the final patch in the merge-ort conversion series, removing test scaffolding that's no longer needed now that merge-recursive has been fully replaced. The patch eliminates the GIT_TEST_MERGE_ALGORITHM environment variable from three builtin commands (merge, rebase, revert) that previously used it to toggle between the old and new merge backends during testing.

The changes:
1. Removes all checks for GIT_TEST_MERGE_ALGORITHM in builtin/merge.c, including fallback strategy selection logic
2. Deletes the environment variable check from builtin/rebase.c that would override the merge strategy
3. Eliminates the same check from builtin/revert.c's sequencer operations

Technical details:
- The patch removes 20 lines while adding just 1 (setting default_strategy to NULL)
- Affects core merge operations in three major commands
- Follows through on the series' goal of completely removing merge-recursive infrastructure
- Maintains identical runtime behavior since 'recursive' now always means 'ort'

This represents the last piece of test infrastructure cleanup in the multi-year merge-ort migration. With merge-recursive fully removed, there's no longer any need for testing both algorithms, making this environment variable obsolete. The changes are straightforward removals with no behavior changes expected in normal operation.
