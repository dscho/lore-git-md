This is a test cleanup patch in Elijah Newren's series removing the legacy merge-recursive implementation. As part of the final removal of merge-recursive, this patch eliminates test infrastructure that was used to compare behavior between merge-recursive and merge-ort.

The patch removes:
1. The GIT_TEST_MERGE_ALGORITHM environment variable that let tests run with either backend
2. The test_expect_merge_algorithm helper function that conditionally ran tests based on the algorithm
3. Updates numerous test files to remove conditional logic that handled differences between the algorithms

Since merge-recursive is now completely removed and 'recursive' is just an alias for 'ort', this test scaffolding is no longer needed. The changes are mechanical removals of now-unnecessary code rather than functional test changes. This is patch 7/8 in the v3 series, building on earlier patches that completed the transition of all callers to merge-ort.

The patch looks straightforward and well-scoped, focused purely on test cleanup now that the underlying code unification is complete. It maintains all test coverage while simplifying the test suite by removing obsolete conditional logic.
