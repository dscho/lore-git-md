This is the final patch in a series porting the 'hdr-check' functionality from Makefile to meson builds, now named 'headers-check' for clarity. The patch implements the actual header checking by creating custom meson targets that verify each header can be compiled independently when included after git-compat-util.h.

The implementation:
1. Defines a list of generated headers (command-list.h, etc.) and platform-specific exclusions (compat/*, test headers, etc.)
2. Conditionally excludes crypto backend headers based on build configuration
3. For each remaining header, creates two custom targets:
   - One to generate a minimal .c file including the header
   - Another to compile that file with appropriate include paths
4. Groups all checks under an alias_target('headers-check')

The patch follows meson conventions using project_source_root() and custom_target(), matching the Makefile's behavior while avoiding abbreviations. It builds on the preparatory work in earlier patches that centralized header definitions. The implementation appears thorough, excluding the same headers as Makefile and handling conditional crypto backends properly. This completes the feature parity goal for header checking between build systems.
