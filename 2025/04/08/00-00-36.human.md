This is a follow-up discussion about the Meson build system's shell completion script installation. Akshay Hegde confirms that Patrick Steinhardt's patch successfully installs Bash and Zsh completion scripts to standard locations while maintaining flexibility for custom datadir paths.

Akshay notes an important edge case: the Zsh completion script depends on finding the Bash script, which can fail with non-standard installation paths (like his custom macOS setup). The solution is documented in the Zsh script itself - users need to explicitly set the Bash script location via a zstyle` configuration in their `.zshrc`. While most users won't encounter this issue with standard installations, it's good awareness for those with custom setups.

The exchange shows the patch is working as intended, while surfacing a known limitation of the Zsh completion's dependency on the Bash script location. This doesn't indicate a problem with the patch itself, but rather documents a configuration consideration for users with non-standard paths.
