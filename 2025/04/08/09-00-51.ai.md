Performance optimization series addressing O(N^2) scaling in bundle creation. This v2 cover letter from Karthik Nayak presents a two-patch series that replaces the inefficient duplicate refname checking in bundle creation with an O(1) `strset`-based solution. The series builds on established consensus from the thread that the approach is correct and ready for merging.

The key changes in v2 are purely stylistic - switching from explicit `strset_init()` to the `STRSET_INIT` macro as agreed in the discussion. The implementation remains functionally identical to v1, which showed dramatic performance improvements: 6x speedup (14.6s → 2.4s at 100k refs) and linear scaling where the original showed 2200x slowdown. The solution handles both same-refname cases (regardless of object identity) and exclusion patterns.

The series consists of:
1. Comprehensive test coverage in t6020-bundle-misc.sh documenting current limitations
2. The optimization itself, which removes the now-unneeded `object_array_remove_duplicates()` function entirely

Files modified include bundle.c, object.c, object.h, plus the new test file. Karthik notes a simple merge conflict with ps/object-wo-the-repository that will need resolution. The thread shows technical consensus on the solution's correctness, with Toon Claes having verified edge cases beyond the test suite. This appears ready for merging pending the trivial conflict resolution.
