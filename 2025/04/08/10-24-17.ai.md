This is the final patch in Patrick Steinhardt's 9-part series refactoring Git's object-file subsystem to enable modular object storage backends. The patch completes the consolidation of object store headers by merging "object-store-ll.h" into "object-store.h" now that all its contents have been properly relocated.

The change removes the transitional "object-store-ll.h" header that was introduced to manage compile-time dependencies, inlining its remaining `odb_path_map` definition directly into "object-store.h". This simplification affects 124 files that previously included the low-level header, all updated to include "object-store.h" instead.

Key technical details:
- The patch moves the khash initialization for `odb_path_map` from the implementation file to the header
- Maintains all existing functionality while reducing header complexity
- Follows the series' pattern of careful subsystem boundary definition
- Completes the architectural separation between generic utilities and object storage components

This change represents the culmination of the series' systematic splitting of object-file.c into logical components while preserving platform behaviors and thread safety. The series has successfully moved Git closer to supporting pluggable object storage backends through this methodical elimination of global state.
