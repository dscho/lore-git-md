This is a platform compatibility patch that addresses a build warning from sparse when using newer glibc headers. The original patch by Đoàn Trần Công Danh adds `-D__STDC_NO_VLA__` to `SPARSE_FLAGS` in the Makefile to suppress warnings about variable-length arrays in glibc's regex.h header. The warning occurs because glibc 2.39's POSIX-compliant `regexec()` declaration uses a VLA parameter, which sparse flags as an error.

Johannes Schindelin replies with appreciation for the patch, noting it's particularly timely due to CI infrastructure changes. He includes his own follow-up patch that migrates Git's sparse CI job from Ubuntu 20.04 to 22.04 runners, since the older runners are being phased out. His patch removes the custom sparse package download/install steps since Ubuntu 22.04 provides a suitable sparse package natively.
