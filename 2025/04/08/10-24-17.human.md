This is the final patch in Patrick Steinhardt's 9-part series refactoring Git's object-file subsystem. The patch completes the modularization effort by merging the "object-store-ll.h" header into "object-store.h" now that all low-level components have been properly separated.

The change removes the transitional "object-store-ll.h" header that was introduced earlier in the series to manage header dependencies and compile times. With the refactoring complete, the remaining `odb_path_map` component has been moved out of the header, allowing the two files to be merged. The patch updates 124 files to use the unified header.

This is a clean-up patch that follows through on the architectural separation established by the previous patches in the series. It doesn't introduce functional changes but simplifies the codebase by eliminating the now-redundant header split. The change is mechanical but extensive, touching nearly every part of Git that interacts with object storage.

The patch maintains all the careful separation of concerns established earlier in the series while reducing complexity in the header structure. It represents the completion of the object store modularization work that has been methodically built up through the previous 8 patches.
