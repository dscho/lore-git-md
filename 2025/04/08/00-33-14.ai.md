Series completion acknowledgement for SHA implementation reporting in `git version --build-options`.

Junio Hamano confirms the 2-patch series is ready for merging into 'next' after receiving final approvals from both Patrick Steinhardt and Christian Couder. The series adds SHA implementation reporting to `git version --build-options` output, with special handling for non-collision-detecting SHA-1 variants. The implementation uses compile-time symbols (SHA1_BACKEND, SHA1_UNSAFE_BACKEND, SHA256_BACKEND) from hash.h to report the selected backends while maintaining zero runtime overhead. Documentation includes explicit security warnings about non-collision-detecting SHA-1 variants, and the output format omits the unsafe SHA-1 line when no such backend is selected. All architectural decisions and documentation wording were settled through three iterations of the patch series, with consensus reached on the final "non-collision-detecting-SHA-1" terminology and output format. The thread has concluded with no outstanding issues.
