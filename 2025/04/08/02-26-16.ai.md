This is a follow-up discussion about the Meson build system's handling of shell completion script installation paths. Todd Zullinger raises a question about whether the current approach of installing completion scripts relative to Git's `$datadir` is optimal, suggesting instead using `pkg-config` to query the system's preferred completion directory (as referenced in the Zsh completion script's documentation).

The email notes potential edge cases around mixed installation paths (particularly when Git is installed in `/usr/local` while bash-completion lives in `/usr`), though acknowledges `/usr/local` is one of bash-completion's default search paths. The core question is whether the added complexity of querying `pkg-config` would be worthwhile given these path resolution scenarios.

This discussion occurs after the initial patch has been validated to work in both default and custom installations (`-Ddatadir`), with the thread having previously established that the Zsh completion's dependency on Bash script location is properly documented for non-standard installations. The new point raises a design consideration about path determination strategy rather than reporting any functional issue with the current implementation.
