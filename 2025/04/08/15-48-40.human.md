This is part 6/8 of Elijah Newren's series to remove the legacy merge-recursive implementation in favor of merge-ort. The patch completes the removal by deleting merge-recursive.[ch] after moving shared functions to merge-ort.[ch]. 

The commit message humorously notes that "deleted code is debugged code" while explaining the serious motivation: merge-ort has been the intended replacement for merge-recursive for some time, offering performance improvements and bug fixes. With all callers now converted to merge-ort equivalents, this patch moves the few remaining shared functions to merge-ort and removes the now-obsolete files.

The changes include:
- Moving config and option handling functions from merge-recursive to merge-ort
- Updating documentation to note that 'recursive' is now just a synonym for 'ort'
- Removing merge-recursive from build systems (Makefile and meson.build)
- Deleting merge-recursive.[ch] entirely

This represents the culmination of a multi-year effort to replace merge-recursive with the more robust merge-ort implementation. The patch is well-motivated and follows the established pattern of the series, with thorough updates to documentation and build systems to reflect the removal.
