This is a follow-up discussion about the Meson build system's handling of shell completion script installation paths. The thread has already established consensus on the core solution, but Todd Zullinger raises a new consideration about default installation locations.

Todd questions whether completion scripts should default to Git's `$datadir` rather than using `pkg-config` to query the system's preferred completion directory (as referenced in the Zsh script's documentation). He notes this could help handle edge cases where Git is installed in non-standard locations (like `/usr/local`) while completion scripts live elsewhere (like `/usr`). 

The concern seems well-intentioned but appears to be a hypothetical edge case - the current solution already works for standard installations and custom paths (via `-Ddatadir`), and the Zsh script's fallback logic plus documented configuration options cover most non-standard scenarios. The thread's prior validation by Akshay Hegde suggests the current approach is practical, though Todd's point about potential `/usr` vs `/usr/local` confusion is technically valid.

This doesn't appear to require any immediate changes to the accepted patch, but might be worth documenting as a known limitation or future consideration for distribution packagers. The discussion remains technical and constructive, focused on making the solution robust across more installation scenarios.
