This is a major refactoring effort targeting the object-file subsystem, splitting up the monolithic "object-file.c" into more logically organized components. The patch series moves various functions to more appropriate locations and creates a dedicated "object-store.c" for higher-level object management.

The series systematically relocates functionality from "object-file.c" to more suitable homes: directory handling to "dir.c", mmap utilities to "wrapper.c", file opening to "compat/open.c", index-related functions to "read-cache.c", and object store management to the new "object-store.c". The remaining "object-file.c" will focus specifically on loose object I/O operations.

The changes are extensive, touching 145 files with over 2000 lines added and removed. The refactoring builds on recent work to remove `the_repository` global usage, suggesting this is part of broader architectural improvements. The patch appears well-organized with clear commit separation and comprehensive file updates, though the wide impact means careful review will be needed to verify no behavior changes were introduced.

Key technical points for future reference: new "object-store.c" file created, "object-store-ll.h" merged into "object-store.h", HASH_* flags handling reorganized, and global cached objects array removed. The changes position the codebase for future development of a more modular object storage backend architecture.
