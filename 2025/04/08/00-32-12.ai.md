Final approval and integration notice for cat-file batch filtering series.

This is Junio Hamano's final approval message for the cat-file batch filtering series, confirming it will be queued for the 'next' branch. The message acknowledges Karthik Nayak's positive review of the latest version, specifically noting the addition of tests for the "excluded" message functionality. This marks the completion of the review cycle that spanned versions v3 through v6, with all technical concerns addressed and performance improvements validated.

The series introduces bitmap-accelerated filtering for `git cat-file --batch` with significant speed improvements (41x for type filtering) while maintaining fallback paths and comprehensive test coverage. Key components include new filter types (`blob:none`, `blob:limit`, `object:type`), unified iteration architecture via `batch_each_object()`, and modifications to the pack-bitmap subsystem. All reviewers (Toon Claes, Karthik Nayak, Patrick Steinhardt) have signed off, with the final minor style clarification about pointer declarations from Junio not affecting the technical implementation.
