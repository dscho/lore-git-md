This is the 6th patch in a series removing the legacy merge-recursive implementation in favor of merge-ort. The patch moves shared functions from merge-recursive to merge-ort and deletes the remaining merge-recursive code.

The key changes are:
- Moves merge_recursive_config(), init_merge_options(), and related functions from merge-recursive.c to merge-ort.c
- Updates documentation to reflect that 'recursive' is now just a synonym for 'ort'
- Removes merge-recursive.c and merge-recursive.h entirely
- Updates build files (Makefile, meson.build) to stop compiling merge-recursive.c

The commit message humorously notes this is "debugging by deletion" since removing code is the best way to ensure it's bug-free. More seriously, it marks the completion of the multi-year effort to replace merge-recursive with the faster and more correct merge-ort implementation.

The patch follows the established pattern of the series - systematically moving functionality before removal. It maintains behavioral compatibility while cleaning up the codebase. Test coverage was already comprehensive from earlier patches in the series.

Technical details:
- Preserves all config handling and option parsing behavior
-merge-ort now contains the canonical implementations
- Documentation updates clarify the transition
- No functional changes, just code movement and deletion
- Part of larger architectural cleanup
- Final step in making merge-ort the sole merge backend
