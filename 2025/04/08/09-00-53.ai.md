Performance optimization patch completing Karthik Nayak's series addressing O(N^2) scaling in bundle creation. This final patch replaces the quadratic `object_array_remove_duplicates()` function with an O(1) `strset`-based solution in `write_bundle_refs()`, achieving a 6x speedup (14.6s → 2.4s at 100k refs) while fixing previously identified bugs where duplicates slipped through with `--all` and short/long refname variants.

The implementation introduces a `strset` to track seen refnames during bundle header writing, eliminating the need for full duplicate checking. It handles two key scenarios: (1) same refnames pointing to identical objects (common case) and (2) same refnames pointing to different objects (exclusion patterns), only processing INTERESTING objects. The patch removes `object_array_remove_duplicates()` entirely, touching bundle.c, object.c, and object.h while updating tests to reflect fixed behavior.

Changes from v1 are minimal (switching to `STRMAP_INIT` macro per prior feedback), with the approach having received positive review from Toon Claes who verified edge cases. The solution demonstrates linear scaling where the original was quadratic, with comprehensive test coverage across four scenarios in t6020-bundle-misc.sh. A simple merge conflict with ps/object-wo-the-repository remains the only outstanding issue before merging.
