Refactoring patch moving directory-creation utilities from object-file.c to dir.c. This is the first of a 9-part series reorganizing Git's object-file subsystem for better modularity.

Patrick Steinhardt relocates `safe_create_leading_directories()` and related functions from object-file.c to dir.c, where they more logically belong since they provide general directory-handling functionality rather than object-specific operations. The change updates include paths in 13 files that use these utilities, with the bulk of the diff being a straightforward code move.

This appears to be a clean, well-scoped change that makes architectural sense. The patch maintains all existing functionality while improving code organization. As part of a larger refactoring effort to enable pluggable object storage backends, this initial step focuses on properly categorizing utility functions before deeper structural changes.
