Test patch establishing coverage for bundle refname deduplication, part of a performance optimization series. This first patch adds comprehensive test cases for `git bundle create`'s handling of duplicate refnames, documenting both current behavior and known limitations. The tests cover four scenarios: direct duplicate refs, duplicates when combined with `--all`, exclusion patterns (`main^!`), and short/long refname variants. The commit message notes two current bugs where duplicates slip through (with `--all` and short/long variants), which the subsequent optimization patch will address. The test file (t6020-bundle-misc.sh) gains 57 lines of new test code with clear expectations and comments marking the bug cases. This establishes a safety net for the O(N^2) to O(1) optimization coming in patch 2/2, which was already discussed and approved in the thread with only minor macro naming changes requested.
