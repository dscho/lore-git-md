The key changes introduce a new `reflog_expire_entry_option` struct to hold per-ref expiry patterns and dates, with all related functions now operating on the options struct rather than globals.

The patch updates all related functions to work with the new structure, including `find_cfg_ent()`, `reflog_expire_config()`, and `set_reflog_expiry_param()`. A new `reflog_expire_entry_option` struct is added to reflog.h to contain the per-ref configuration data that was previously in `reflog_expire_cfg`.
