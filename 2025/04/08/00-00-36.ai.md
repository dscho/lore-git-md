This is a follow-up discussion about the Meson build system's shell completion script installation patch. Akshay Hegde confirms the patch works as intended, installing Bash and Zsh completion scripts to standard locations while allowing customization via `-Ddatadir`. 

The key new information is about an edge case where Zsh completion depends on the Bash script's location. When using non-standard install paths (like in Akshay's custom macOS setup), users may need to explicitly configure the Bash script location in their `.zshrc` via `zstyle` directives. The Zsh completion script already includes helpful documentation about this, and the issue only affects non-standard installations.

The discussion reinforces that the patch solves the core problem while maintaining flexibility, with Akshay's testing providing real-world validation of both the standard and custom installation scenarios. The edge case noted doesn't require changes to the patch itself, as it's a known configuration consideration already documented in the Zsh script.
