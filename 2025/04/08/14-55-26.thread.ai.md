This thread documents Karthik Nayak's implementation of header checking in Meson builds, now merged to 'master' as a 6-patch series. The work ports Makefile's 'hdr-check' capability to Meson with these key elements: 1) renamed variables in contrib/coccinelle/meson.build (coccinelle_sources/coccinelle_headers), 2) centralized header definitions in root meson.build, 3) moved exclusion lists to root meson.build, 4) implemented checking via Meson custom targets with proper dependency chaining, and 5) finalized target aliasing ('check-headers' with 'hdr-check' alias).

The implementation includes:
1. 'xdiff/' in third_party_excludes to skip external dependency headers (with Phillip Wood noting this differs from Makefile's coccinelle behavior but is appropriate given xdiff's hybrid status)
2. exclude_from_check_headers with platform-specific and crypto backend exclusions
3. Two-stage compilation process (hcc/hco targets) per header
4. Activation only when headers_to_check is populated and using GCC syntax
5. Same exclusion patterns as Makefile (compat/, unicode-width.h)
6. Conditional crypto backend header exclusions (openssl/nettle/gcrypt)
7. 'check-headers' target introduced as preferred alias for 'hdr-check' with planned deprecation of old name

Technical implementation uses:
- meson.custom_target() for compilation steps
- startswith() checks for header exclusion logic
- Temporary .cc files with include directives
- Output to /dev/null (only compilation success matters)
- Dual target names for backward compatibility
- Skip when Git unavailable (headers_to_check empty)
