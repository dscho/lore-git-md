Documentation patch adding function-level docstrings to the json-writer API.

Lucas Seiki Oshiro proposes adding comprehensive documentation to the json-writer.h interface, which provides utilities for generating JSON output. The patch adds docstrings for all public functions in the header, explaining their purpose and parameters. This is preparatory work for a GSoC project that will use this JSON functionality.

The documentation covers the full API surface, from basic initialization (jw_init, jw_release) to object/array manipulation functions (jw_object_begin, jw_array_begin) and various value-adding methods (jw_object_string, jw_array_intmax, etc). Each docstring clearly explains the function's behavior and any special parameters (like the precision control for double values).

The patch appears well-crafted - the docstrings are clear and consistent, and the entire API is covered in one logical change. Since json-writer is a general-purpose utility used across Git, this documentation will help both the author's GSoC work and future contributors who need to work with JSON output. The author notes they can split this into smaller patches if preferred, though the single-patch approach seems reasonable for this cohesive documentation addition.
