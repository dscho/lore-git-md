Bugfix for the Scalar performance test suite. This is the second patch in a three-part series addressing test issues, specifically fixing `p9210-scalar.sh` to work correctly when run from a detached HEAD state.

The patch solves a problem where `scalar clone` would fail when determining the remote's default branch if the test was run from a detached HEAD. The fix is straightforward - it creates an explicit local branch ('test-branch') during test setup using `git checkout -B`, ensuring `scalar clone` has a valid branch reference to work with. 

This change has already received explicit approval from Patrick Steinhardt as "an easy and pragmatic fix" in the thread. The patch is minimal (just 3 lines changed), well-explained, and clearly addresses a concrete test infrastructure issue. It's the most uncontroversial part of the series, with no changes needed between v1 and v2 of the patch series. 

The fix ensures the Scalar performance tests can run reliably regardless of the HEAD state of the test environment, which is particularly important for CI systems that often operate in detached HEAD states.
