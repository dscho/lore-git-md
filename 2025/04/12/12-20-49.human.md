Documentation patch addressing a technical edge case in the AsciiDoc toolchain for Git's documentation. This is part 6/7 of Jean-Noël Avila's series modernizing command documentation, specifically fixing how triple-dot notation (used in commands like `git mv <source>... <dest>`) is processed by the documentation toolchain.

The patch makes subtle but important changes to the regex patterns in both `asciidoc.conf.in` and `asciidoctor-extensions.rb.in` to properly distinguish between literal triple-dots (command syntax) and ellipses (punctuation). The changes ensure correct rendering in both DocBook/XML and HTML output formats while maintaining consistency with the documentation standards established in earlier patches.

This follows up on earlier feedback in the thread about special character handling, though it doesn't yet resolve the remaining TROFF rendering issue noted in the series. The changes are surgical and focused, demonstrating the careful attention to detail characteristic of this documentation standardization effort.
