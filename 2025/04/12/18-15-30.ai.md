Performance test fix addressing prerequisite handling in grep engine tests. This is the first of three patches in Philippe Blain's series fixing test suite issues, specifically targeting the p7821-grep-engines-fixed.sh performance test script.

The patch corrects how test prerequisites are specified in `test_perf` invocations, bringing them into compliance with the format established by commit 5dccd9155f. The old format would cause test failures when prerequisites like PCRE support were missing, rather than properly skipping the unsupported tests. The changes move prerequisite declarations to use the `--prereq` flag after the test title, affecting both single-threaded and threaded grep test cases.

The changes are mechanical - swapping parameter positions without altering test behavior - but important for proper test skipping. The patch follows up on earlier discussion about edge cases in prerequisite handling, though it doesn't yet address all concerns raised about empty prerequisite variables. This appears to be the minimal fix needed for basic functionality while leaving room for potential follow-up refinements to prerequisite string construction.
