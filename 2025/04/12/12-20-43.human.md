This is a documentation patch series updating the man pages for `git-reset`, `git-rm`, and `git-mv` to the modern AsciiDoc format. It's the second version of Jean-Noël Avila's effort to standardize these command documentations, following up on reviewer feedback from Martin Ågren.

The series makes several improvements to the documentation format:
- Converts all three commands to use consistent AsciiDoc syntax with proper synopsis sections
- Standardizes placeholder notation (`_<placeholder>_`) and option formatting (`-v`, `-f`)
- Fixes the handling of triple-dot notation in command synopses
- Updates the built-in command help text in `builtin/mv.c` to match
- Adds markup guidelines for special characters in CodingGuidelines

Notable changes since v1 include:
- Stacked commit fixing the three-dot notation handling
- Addressed all reviewer comments except for remaining TROFF rendering quirks
- Added a new patch (7/7) documenting character markup rules

The work continues Git's documentation modernization effort, building on previous AsciiDoc conversion patterns. While the technical content remains unchanged, the presentation is now more standardized and maintainable. The series appears well-polished, with all substantive reviewer feedback incorporated, leaving only some edge cases in TROFF rendering to be resolved separately.
