Documentation modernization series converting `git-reset`, `git-rm`, and `git-mv` man pages to AsciiDoc format, version 2. This cover letter introduces a 7-patch series that builds on previous work standardizing Git documentation, with specific attention to synopsis formatting and special character handling.

The series addresses reviewer feedback from v1, particularly around the handling of three-dot notation in command synopses. Key technical changes include:
- Fixed synopsis analysis logic in the documentation toolchain
- Proper formatting of triple-dot notation in `git-mv` documentation and built-in help text
- Added markup guidance for special characters in CodingGuidelines
- Maintained consistency with prior documentation conversions while addressing edge cases

The patches touch documentation files, build configuration (asciidoc.conf.in, asciidoctor-extensions.rb.in), and built-in command help text (builtin/mv.c). The work continues the project's documentation standardization effort, with particular attention to:
- Correct rendering of special characters in both XML/DocBook and TROFF output formats
- Precise handling of command variants in SYNOPSIS sections
- Consistent placeholder notation (_<placeholder>_) and option formatting (`-v`, `-f`)

This version resolves all previously identified issues except for the known TROFF rendering quirk with special characters in bold spans, which remains an open question requiring deeper toolchain investigation. The series demonstrates careful attention to detail in both content and presentation, following established patterns from prior documentation modernization work.
