Performance test fix correcting prerequisite handling in grep engine benchmarks.

This is the first patch in a series addressing test suite issues, specifically fixing how performance tests are invoked in p7821-grep-engines-fixed.sh. The patch updates two `test_perf` calls to properly declare their prerequisites using the `--prereq` flag, following a 2022 change to the perf test infrastructure. Without this fix, the test would fail with an error about missing parameters when run on systems lacking PCRE support.

The changes are straightforward mechanical adjustments - moving the prerequisite strings to the new `--prereq` parameter position in the test invocations. The patch handles both single-threaded and multi-threaded test cases, with the latter requiring an additional "PTHREADS" prerequisite.

While the fix itself appears correct, the thread context shows there's ongoing discussion about edge cases in prerequisite handling for these grep engine benchmarks. This patch represents the basic fix while leaving room for further refinement of the prerequisite string construction. The change is part of a series where the other patches (including a scalar test fix) have already received positive feedback.
