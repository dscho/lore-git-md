This is a documentation patch in Jean-Noël Avila's series modernizing command man pages to AsciiDoc format, specifically converting `git-mv` documentation. The patch updates both the man page and built-in help text to use consistent formatting standards.

The changes standardize the synopsis block format with proper placeholder notation (_<placeholder>_) and backtick-wrapped options (`-f`, `-n`). It addresses the three-dot notation ambiguity where "..." can indicate either repeatable options or commit ranges, though notes the rendering engine can't distinguish these cases. The patch also updates submodule path references to use the new config key formatting (`submodule.<name>.path`).

Key technical details include:
- Conversion of the synopsis to use AsciiDoc's `[synopsis]` block
- Standardized option formatting with backticks (`-v`, `--force`)
- Consistent placeholder notation (_<source>_, _<destination-directory>_)
- Built-in help text update in `builtin/mv.c` to match documentation
- Submodule documentation now uses proper config key markup
- Special character handling for backslashes and asterisks in command synopses

The patch follows the same rigorous standards applied to `git-reset` and `git-rm` in earlier parts of the series, maintaining consistency across all three command documentations. The changes preserve all semantic content while improving presentation through standardized formatting.
