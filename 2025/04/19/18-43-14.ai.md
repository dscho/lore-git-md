This is a bugfix patch addressing an issue with `blame.ignoreRevsFile` configuration. The current behavior exits if any specified ignore file doesn't exist, which becomes problematic when trying to set a default ignore file (like GitHub's `.git-blame-ignore-revs`) in global config that may not exist in all repositories.

The patch makes several key changes:
1. Separates config-specified ignore files from command-line specified ones, storing them in a new `ignore_revs_config_file_list`
2. Modifies `build_ignorelist()` to skip (rather than fail on) missing config-specified files while maintaining strict checking for command-line files
3. Adds a new `oidset_parse_filep_carefully()` function to handle already-opened file streams
4. Updates documentation to clarify the new behavior
5. Adds a test case verifying the new tolerant behavior for config-specified files

The implementation maintains backward compatibility while solving the practical use case of optional ignore files in config. The changes touch core blame code, oidset internals, and test infrastructure, with careful attention to error handling and documentation.
