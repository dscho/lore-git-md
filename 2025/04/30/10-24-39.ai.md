First patch in a 2-part series adding `--no-maintenance` flag to Scalar commands. This part modifies `scalar register` to optionally skip background maintenance setup, addressing interference issues in automation scenarios where background maintenance could block foreground operations.

The change introduces a new `--no-maintenance` flag that preserves the current default behavior (enabling maintenance) while allowing opt-out. Implementation touches:
- Updates `register_dir()` function signature to accept maintenance flag
- Adds flag handling in `cmd_register()`
- Documents new option in `scalar.adoc`
- Adds test case verifying `--no-maintenance` behavior

The patch maintains backward compatibility and follows Scalar's established patterns. Test coverage verifies the new flag works with the maintenance scheduler disabled, suggesting attention to edge cases. The change is narrowly scoped to just the register command, with the clone command modification coming in the next patch.
