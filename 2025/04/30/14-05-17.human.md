This appears to be a bug report about unexpected behavior in `git stash` when used with submodules. The reporter, Alex Arques, describes how using `git stash push -m` in a repository with submodules incorrectly prepends "On master:" to the stash message, even when the current branch isn't master. The bug occurs specifically when using the `-m` flag - without it, the branch name is correctly reported as the current branch.

The issue was found on Git for Windows 2.49.0, in a setup with two submodules tracking "master". The incorrect message format makes `git stash list` output confusing since it shows the wrong branch name. This seems to be a confirmation of a previously reported bug, though the original report isn't shown in this context. The behavior suggests a problem with how `git stash` handles branch name detection in repositories containing submodules.
