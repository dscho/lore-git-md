Bugfix for `git mv` addressing parent-child directory move conflicts. This is the first patch in a two-part series that fixes an assertion failure when attempting to move both a directory and its child simultaneously (e.g. `git mv dir dir/subdir newlocation`). The issue was previously marked as a known failure in the test suite and could cause CI hangs on Windows due to modal dialog boxes from failed assertions.

The patch introduces proper error handling by:
1. Adding a new `MOVE_VIA_PARENT_DIR` flag to track implicit moves
2. Using a hashmap to detect parent-child move conflicts
3. Converting the problematic assert into a user-friendly error message that prevents the invalid operation

The changes are well-contained to `builtin/mv.c` and include two new test cases that verify the error behavior for both files and nested directories. The solution appears robust, with clear error messages and proper cleanup of allocated resources. This addresses a real edge case that could confuse users and cause CI failures, though it's not a common workflow.
