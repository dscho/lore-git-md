Refactoring patch in Patrick Steinhardt's series to decompose `git gc`. This is patch 3/8 in v2 of the series that moves worktree pruning functionality into a standalone function within `builtin/gc.c`.

The change extracts the worktree pruning logic from `cmd_gc()` into a new `maintenance_task_worktree_prune()` function, maintaining identical behavior but in a more modular form. This is a preparatory step for introducing worktree pruning as a standalone maintenance task, which will be added in a subsequent patch.

The implementation remains straightforward - it still uses `git worktree prune --expire` under the hood with the same configuration handling. The patch is cleanly implemented with no behavior changes, just code reorganization to support the larger goal of making worktree pruning available as an independent maintenance operation.

This continues the series' pattern of incrementally refactoring `gc.c` to enable the eventual replacement of `git gc` with granular maintenance tasks. The change is well-contained and follows the established approach seen in earlier patches of the series.
