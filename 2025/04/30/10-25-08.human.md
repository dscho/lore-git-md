Refactoring patch in the ongoing maintenance task decomposition series.

This is patch 4/8 in Patrick Steinhardt's v2 series that completes the standalone implementation of maintenance tasks to replace `git gc`. The patch extracts worktree name retrieval into a new `get_worktree_names()` function in worktree.c, making this functionality reusable elsewhere in the codebase.

The change simplifies `prune_worktrees()` by replacing direct directory handling with calls to the new helper function. The implementation remains functionally equivalent but is now more modular, with proper error handling and memory management. The new function returns worktree names via a `strvec` and handles edge cases like missing worktrees directory gracefully.

This appears to be a preparatory change for the subsequent patch that will implement worktree pruning as a standalone maintenance task. The clean separation of concerns here follows good refactoring practice and should make the maintenance task implementation cleaner. The patch maintains all existing behavior while improving code organization.
