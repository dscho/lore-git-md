This is a feature addition to Scalar, Git's large-repo optimization tool. The patch series adds a `--no-maintenance` option to both `scalar register` and `scalar clone` commands, allowing users to skip the automatic background maintenance setup that normally happens by default.

The motivation comes from automated environments where Scalar is used to set up repositories on disk images. In these cases, background maintenance running during later setup steps can cause unexpected behavior or even block subsequent maintenance commands due to lockfile conflicts. The change maintains the current default behavior (which enables maintenance) while giving advanced users an opt-out mechanism.

The implementation touches documentation, core scalar functionality, and adds tests for both commands. The changes look straightforward and well-motivated, with clear test coverage for the new option. This appears to be a practical quality-of-life improvement for users managing Scalar in automated workflows.
