This is a refactoring patch in Patrick Steinhardt's series to decompose `git gc` functionality into standalone maintenance tasks. The patch removes unnecessary global variables in `builtin/gc.c` that were used to store command-line arguments for subprocess calls (`prune`, `worktree prune`, and `rerere gc`). 

The change simplifies the code by eliminating variables that were only used once, instead constructing the command arguments directly when needed. This makes the code more straightforward to follow while maintaining identical behavior. The `repack` variable remains as it's used in multiple places.

This is a straightforward cleanup that doesn't affect functionality but improves code hygiene. It's part of the larger effort to make the maintenance subsystem more maintainable as it takes over responsibilities from `git gc`. The patch follows the series' pattern of incremental improvements while preserving existing behavior.
