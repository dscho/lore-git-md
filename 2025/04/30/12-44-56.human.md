This is a bugfix series addressing an issue in `git mv` when moving both a parent directory and its child. The problem was discovered through CI failures on Windows, though the underlying issue appears platform-agnostic.

The first patch prevents `git mv` from attempting to move both a directory and its immediate child, which currently triggers an assertion failure. The second patch converts the problematic assert into a proper `BUG()` call, following Git's error handling conventions.

The changes are accompanied by test updates to verify the new behavior. The series is small (2 patches) and focused, with clear motivation from real-world CI failures. The fix appears straightforward and well-tested, addressing a clear edge case in directory moving logic.
