Feature patch adding a `--no-maintenance` option to `scalar register`, part of a series addressing background maintenance interference in automated environments. This first patch focuses on the registration command, allowing users to opt out of automatic maintenance setup while still getting Scalar's other configuration benefits.

The change is motivated by scenarios where background maintenance could conflict with foreground automation tasks, particularly when setting up repositories for later use (like disk image creation). The implementation maintains the current default behavior of enabling maintenance while adding the new flag, requiring updates to the `register_dir()` function prototype and its callers.

Documentation is thorough, explaining both the default behavior and the new option's purpose. Test coverage includes a new case verifying `--no-maintenance` works as expected. The changes appear well-contained and backward-compatible, with no obvious technical concerns. This looks like a straightforward quality-of-life improvement for Scalar users in automated environments.
