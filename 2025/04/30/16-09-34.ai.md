This is a documentation patch proposing improvements to the discoverability of the `--no-single-branch` flag in `git-clone`'s help text.

The author notes that the current documentation buries the `--no-single-branch` option within the `--depth` paragraph, making it hard to find when searching for the exact option names. They also point out that the `--[no]-single-branch` syntax requires users to deduce what the "no-" prefix negates, which may confuse inexperienced users.

The proposed change would:
1. Give each option (`--single-branch` and `--no-single-branch`) its own dedicated paragraph
2. Explicitly document the negated form's behavior rather than relying on the "no-" prefix convention
3. Make both forms more easily discoverable via search/grep

The patch focuses on improving documentation structure rather than changing functionality. The suggested wording maintains the existing behavior while making it clearer. This appears to be a well-motivated change from a user experience perspective, though the impact is relatively minor since it only affects help text organization.
