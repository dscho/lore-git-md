This is a bugfix patch series addressing an issue in `git mv` when moving both a parent and child directory. The series comes from Patrick Steinhardt and appears to be motivated by CI failures on Windows systems.

The cover letter explains that the core issue involves an assertion failure when attempting to move both a child directory and its parent. The first commit adds explicit error checking to prevent this invalid operation, while the second converts the problematic assert into a proper `BUG()` call. The changes touch both the `builtin/mv.c` implementation and its test suite.

Key technical details for future reference:
- The issue manifests when running `git mv dir dir/subdir dir/newlocation`
- The fix adds explicit validation to detect parent-child move conflicts
- Changes include 64 lines of implementation code and 24 lines of test updates
- The second commit's conversion from `assert` to `BUG()` suggests this is considered a programmer error case
- The original report came from a GitGitGadget pull request (#1908)
