This thread addresses a bugfix series from Patrick Steinhardt that fixes assertion failures in `git mv` when moving both a parent and child directory simultaneously. The core solution uses a hashmap to track moved directories and explicitly rejects invalid parent-child moves with a clear error message. Junio Hamano has approved the technical approach, which includes converting an `assert()` to `BUG()` for consistent behavior across build configurations.

In the latest exchange, Junio discusses the CI implications of this change, noting that the series may make Johannes Schindelin's proposed "assert() as no-op" patch for Windows/Meson builds unnecessary. While maintaining approval of the core solution, Junio raises broader questions about assertion handling in CI - whether we should prioritize catching potential bugs (even at the risk of test hangs) over test reliability. The series appears ready for merging once this final policy question is resolved, with Junio suggesting Johannes's patch could be dropped when this lands in 'next'. The changes are well-contained (affecting about 150 lines total) and come with thorough test coverage for the directory move scenarios.
