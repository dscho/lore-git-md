Bugfix for macOS launchctl scheduler in git maintenance.

This is a single-patch fix addressing incorrect calendar interval settings for `git maintenance` when using launchctl scheduler on macOS. The author, Josh Heinrichs, discovered that with current settings, daily jobs incorrectly run on the first six days of the month rather than daily, and weekly jobs run daily instead of weekly. He verified this behavior by manually testing with system time adjustments.

The patch is straightforward, modifying just two lines in builtin/gc.c to correct the interval specifications. The author notes this is likely a low-impact issue since git maintenance is somewhat niche on macOS, and suggests no special handling is needed for existing configurations. The fix appears well-motivated and narrowly scoped, though it might benefit from including the actual incorrect/correct interval strings in the commit message for clarity.
