Platform compatibility patch adding clangarm64 support to Git's build system. This is patch 2/6 in a series enabling Windows/ARM64 support, specifically targeting the new CLANGARM64 MSYSTEM environment from MSYS2.

The change adds a new conditional block to config.mak.uname that sets the correct prefix (/clangarm64), CPU architecture (aarch64), and linker flags when building under CLANGARM64. The structure mirrors existing blocks for other Windows environments like MINGW64. The patch is straightforward and focused - it doesn't touch any core Git functionality, just ensures the build configuration recognizes this new platform.

As part of the larger Windows/ARM64 effort, this appears to be a necessary but relatively uncontroversial piece of infrastructure. The commit message is clear about the purpose, though it doesn't explain why these specific settings are needed for CLANGARM64 (likely because they parallel other Windows configurations).
