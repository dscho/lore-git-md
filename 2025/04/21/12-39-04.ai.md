This is a platform compatibility patch series introducing Windows/ARM64 support, consisting of 6 patches (2 from Dennis Ameling, 4 from Johannes Schindelin). The series aims to enable Git to build and pass tests on Windows/ARM64 systems, particularly targeting the newly available Windows/ARM64 GitHub Action runners.

The changes include:
1. Adding built-in bswap function support for ARM64 in bswap.h
2. Adding clangarm64 support in config.mak.uname
3. Disabling nedmalloc specifically for Windows/ARM64
4. Handling MSVC builds on ARM64
5. Moving the `/etc/git*` location for mingw/arm64
6. Lowering max_tree_depth for clangarm64 on Windows

The series touches core compatibility files (bswap.h, config.mak.uname) and Windows-specific components (mingw, msvc). The motivation stems from Git for Windows' existing ARM64 support and the recent availability of ARM64 GitHub runners, suggesting this is timely infrastructure work rather than speculative porting. The changes appear focused and minimal, with no major architectural changes visible in the_repository or core Git functionality.
