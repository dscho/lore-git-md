Subject: macOS launchctl maintenance scheduler bugfix
Thread type: Bug fix
Author: Josh Heinrichs
Files: builtin/gc.c
Key changes: Corrects launchctl calendar specifications by replacing Day with Weekday keys per launchd.plist(5) documentation

The thread addresses incorrect scheduling intervals for Git maintenance jobs when using launchctl on macOS, where daily jobs ran only the first six days of each month (from malformed "*-*-* 1..6:0:0" spec) and weekly jobs ran daily (from "*-*-*" spec). Josh Heinrichs' patch fixes this by replacing the `Day` key with `Weekday` in `launchctl_schedule_plist` to properly specify days-of-week scheduling. Junio C Hamano reviewed and approved the fix, confirming it correctly schedules daily jobs Monday-Saturday and weekly jobs on Sunday via `Weekday:0`, while noting platform inconsistencies in Sunday numbering (0 vs 7) are out of scope for this macOS-specific fix. Derrick Stolee has since added an enthusiastic endorsement ("good find!") reinforcing the solution's acceptance. The patch remains queued for integration with no outstanding objections, impacting only macOS users employing launchctl for maintenance scheduling, with changes confined to scheduling templates in builtin/gc.c.
