Subject: macOS launchctl maintenance scheduler bugfix
Thread type: Bug fix
Author: Josh Heinrichs
Files: builtin/gc.c
Key changes: Corrects launchctl calendar specifications by replacing Day with Weekday keys per launchd.plist(5) documentation

The thread addresses incorrect scheduling intervals for Git maintenance jobs when using launchctl on macOS. The original bug caused daily jobs to run only the first six days of each month (from malformed "*-*-* 1..6:0:0" spec) and weekly jobs to run daily (from "*-*-*" spec). Josh Heinrichs' patch identifies the root cause as incorrect use of the `Day` key, replacing it with `Weekday` in `launchctl_schedule_plist` to properly specify days-of-week scheduling.

Junio C Hamano has reviewed and approved the fix, confirming it correctly schedules daily jobs Monday-Saturday and weekly jobs on Sunday via `Weekday:0`. While noting platform inconsistencies in Sunday numbering (0 vs 7), Junio considers this out of scope for the macOS-specific fix. The solution is technically sound with clear documentation backing and testing verification. The patch is now queued for integration, with no outstanding objections. Impact remains limited to macOS users employing launchctl for maintenance scheduling, with changes confined to scheduling templates in builtin/gc.c.
