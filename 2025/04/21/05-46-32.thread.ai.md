Subject: macOS launchctl maintenance scheduler bugfix
Thread type: Bug fix
Author: Josh Heinrichs
Files: builtin/gc.c
Key changes: Corrects launchctl calendar specifications by replacing Day with Weekday keys per launchd.plist(5) documentation, now approved for merging

The thread addressed incorrect scheduling intervals for Git maintenance jobs when using launchctl on macOS, where daily jobs ran only the first six days of each month (from malformed "*-*-* 1..6:0:0" spec) and weekly jobs ran daily (from "*-*-*" spec). Josh Heinrichs' patch fixes this by replacing the `Day` key with `Weekday` in `launchctl_schedule_plist` to properly specify days-of-week scheduling (Monday-Saturday for daily, Sunday for weekly via `Weekday:0`).

Junio C Hamano reviewed and approved the fix, noting platform inconsistencies in Sunday numbering (0 vs 7) are out of scope for this macOS-specific solution. Derrick Stolee endorsed the change with an enthusiastic "good find!". Junio has now confirmed the patch will proceed to the 'next' branch for integration, marking final approval with no outstanding objections. The changes remain confined to macOS launchctl scheduling templates in builtin/gc.c, impacting only users employing this specific maintenance scheduler implementation.
