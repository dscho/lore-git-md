Refactoring of the Meson build system to standardize function availability checks. This is part 1 of a 6-patch series (no cover letter seen yet).

The patch consolidates repetitive function availability checks in meson.build into a more maintainable array-based approach. Instead of individual blocks checking each function, it introduces a `checkfuncs` array listing functions to test, then processes them in a loop. For each missing function, it adds the appropriate `-DNO_XXX` define and includes a compatibility implementation if one exists in compat/.

Key functions handled include strcasestr, memmem, strlcpy, strtoull, setenv, mkdtemp, initgroups, mmap, and unsetenv (with Windows-specific handling for the latter two). The patch preserves special cases like sync_file_range (which uses HAVE_ rather than NO_ prefix) and Windows-specific MMAP handling. Some functions remain as individual checks outside the new system (strdup, strtoumax, qsort, getdelim, clock_gettime) likely due to their unique requirements.

The change reduces code duplication while maintaining the same functionality, making the build configuration more maintainable. The commit message notes that not all functions could be moved to the new system due to varying macro naming conventions. The implementation checks for existence of compatibility files before adding them to sources, avoiding errors for functions without compat implementations.
