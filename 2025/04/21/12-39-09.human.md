Platform compatibility patch adjusting Windows/ARM64 configuration paths, part of a series enabling Git on Windows/ARM64 systems.

This fifth patch in the six-part series fixes where Git looks for system-wide configuration files on Windows/ARM64 builds. The change ensures ARM64 builds follow the same `/etc/` location convention established for x86_64 builds in 2021, rather than using the less intuitive `/clangarm64/etc/` path. The fix addresses a specific issue reported in the Git for Windows tracker (#5431).

The patch modifies `config.mak.uname` to normalize path handling between different Windows architectures. It builds on Johannes Schindelin's earlier work that standardized configuration file locations, extending that logic to properly handle the new ARM64 toolchain paths. The change is minimal - just two lines modified to account for the `clangarm` prefix in ARM64 builds.

This appears to be a straightforward platform-specific adjustment that maintains consistency with existing behavior. The patch follows the series' pattern of making Windows/ARM64 support mirror the established x86_64 setup where possible. As with the rest of the series, this change appears well-motivated and narrowly scoped to its platform compatibility goal.
