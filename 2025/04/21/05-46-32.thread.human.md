The thread addresses a bug in Git's macOS maintenance scheduler where launchctl calendar specifications incorrectly used `Day` keys instead of `Weekday` keys, causing daily jobs to run only the first six days of each month and weekly jobs to run daily. Josh Heinrichs submitted a fix that replaces `Day` with `Weekday` in `builtin/gc.c`, properly scheduling daily jobs Monday-Saturday and weekly jobs on Sunday.

Junio C Hamano reviewed and approved the patch, noting platform inconsistencies in Sunday numbering were out of scope for this macOS-specific fix. Derrick Stolee later added an enthusiastic endorsement of the solution. In the latest update, Junio confirmed the patch will be merged into the 'next' branch, marking the final administrative step for this straightforward bugfix. The change only affects macOS users employing launchctl for maintenance scheduling, with no impact on other platforms or broader Git functionality.
