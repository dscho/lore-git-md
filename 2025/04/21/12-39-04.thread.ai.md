Thread identity: Platform compatibility patch series introducing Windows/ARM64 support, authored by Dennis Ameling and Johannes Schindelin (Dscho). Current version is initial submission (v1).

Core problem or goal: Enable Git to build and pass tests on Windows/ARM64 systems, particularly targeting newly available Windows/ARM64 GitHub Action runners. The work builds on Git for Windows' existing ARM64 support.

Current status: Initial patch series (6 patches) submitted for review. Not yet in any integration branch. Patches cover:
1. ARM64 bswap support in bswap.h via compiler built-ins (__builtin_bswap32/64) with fallbacks
2. clangarm64 support in config.mak.uname (recognizing CLANGARM64 MSYSTEM, setting prefix to /clangarm64, HOST_CPU to aarch64, and PIC flags)
3. Disabling nedmalloc for Windows/ARM64 builds due to compilation failures and project unmaintained status (since 2017)
4. MSVC ARM64 build handling
5. mingw/arm64 /etc/git* location adjustment
6. Lowered max_tree_depth for clangarm64 on Windows

Key technical details:
- Files modified: bswap.h (now with compiler built-in detection), config.mak.uname (CLANGARM64 support and nedmalloc exclusion), Windows-specific components (mingw, msvc)
- bswap.h changes use __has_builtin for detection while maintaining x86 fallback
- Build system changes follow established patterns for Windows toolchain support
- Nedmalloc disabled only for Windows/ARM64 via CLANGARM64 MSYSTEM check
- No changes to the_repository or core Git architecture
- Test coverage implied by targeting GitHub Action runners but not explicitly shown in patches
