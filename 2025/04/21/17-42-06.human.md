Bugfix for macOS launchctl maintenance scheduling. This is a follow-up to Josh Heinrichs' patch that corrects how Git specifies daily and weekly maintenance job schedules when using launchctl on macOS. The original fix addressed incorrect scheduling intervals, and Junio C Hamano is now queuing it for inclusion.

The key change replaces the `Day` key with `Weekday` in launchctl plist configuration, which properly specifies days-of-week scheduling according to macOS documentation. This ensures daily jobs run every day (Monday-Saturday) and weekly jobs run weekly (on Sundays). Junio notes some platform inconsistencies in how different schedulers handle Sundays but considers this macOS-specific fix correct as-is.

The patch is small and focused (just 2 lines changed in builtin/gc.c), with clear justification from both documentation and testing. While Junio doesn't personally use macOS, he's satisfied with the technical explanation and is proceeding with the change. No outstanding concerns remain in the thread.
