This is a bugfix for macOS launchctl scheduling in Git's maintenance jobs. The patch corrects incorrect calendar specifications that were causing daily jobs to run only on the first six days of each month and weekly jobs to run daily instead of weekly.

Josh Heinrichs identifies the root cause as using the wrong key ("Day" instead of "Weekday") in the launchd.plist calendar intervals. The "Day" key specifies days of the month, while "Weekday" is needed for days-of-week scheduling. The patch makes this straightforward correction in `builtin/gc.c`, changing the daily and weekly schedule templates to use "Weekday" instead.

The change is well-explained with reference to launchd documentation and appears to have been tested through manual time adjustments and log checking. This is a clear platform-specific bug that only affects macOS users using launchctl for maintenance scheduling. The fix is minimal and focused, with no apparent risk to other platforms or functionality.

Given the thread summary indicates this is the first patch in the discussion, it seems likely to be accepted as-is unless macOS experts spot any issues with the launchctl configuration syntax. The change improves behavior for a niche but legitimate use case without introducing new complexity.
