This is a refactoring patch for Git's Meson build system, part of a 6-patch series (though we haven't seen the cover letter yet). Eli Schwartz simplifies the repetitive function availability checks in meson.build by parameterizing them into a list-driven approach. The patch consolidates checks for standard library functions like `strcasestr`, `memmem`, and `strlcpy`, automatically adding the appropriate `-DNO_XXX` flags and compatibility implementations when needed.

The change makes the build configuration more maintainable by reducing copy-pasted code blocks while preserving the same functionality. Some functions remain as special cases outside the new system (like `sync_file_range` and Windows-specific checks) where they don't fit the pattern. The patch appears well-constructed with a clear commit message explaining both the motivation and implementation approach.
