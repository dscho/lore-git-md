CI / build system fix for Meson header checking implementation.

Karthik Nayak identifies and proposes a solution for the CI failure in the ongoing effort to add `hdr-check` functionality to Meson builds. The root cause is that GitHub Actions defaults to downloading a tarball (via REST API) when Git isn't installed, breaking the `git ls-files` command used by the new header checking code. 

The proposed fix adds a step to install Git before repository checkout in the GitHub workflow, ensuring proper Git repository structure is maintained. Karthik notes this issue was specific to GitHub CI - the same tests pass on GitLab CI where the environment differs. The patch includes platform-specific installation commands (apt/apk/dnf) to handle different Linux distributions in the CI environment.

This appears to be the final blocker for merging the Meson header checking series, which has otherwise been thoroughly reviewed and iterated upon with input from multiple contributors. The solution is straightforward and addresses the environmental dependency cleanly.
