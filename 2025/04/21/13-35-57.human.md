Platform compatibility patch series for Windows/ARM64 support, now queued for integration. This initial 6-patch series from Dennis Ameling and Johannes Schindelin enables Git to build and pass tests on Windows/ARM64 systems, particularly targeting newly available GitHub Action runners for this architecture.

The changes follow established Windows toolchain patterns, with patches covering compiler built-in detection for ARM64 bswap operations, clangarm64 build configuration, nedmalloc disablement (which fails to compile on this platform), MSVC build handling mirroring existing MINGW support, config file path normalization, and a stack overflow mitigation specific to clang/ARM64. The work builds on Git for Windows' existing ARM64 support that has been shipping since late 2024.

Junio Hamano has reviewed the series and found it "cleanly structured", indicating it will be queued for integration. The patches appear well-scoped and focused on the immediate needs for ARM64 compatibility without introducing broader changes. The timing aligns with GitHub's recent public preview of Windows/ARM64 runners, suggesting this will soon see real-world testing.

While the series introduces some platform-specific behaviors (like the stack depth adjustment and nedmalloc disablement), these follow existing patterns for handling Windows platform quirks. The changes are contained to build system configuration and platform compatibility layers rather than core Git functionality.
