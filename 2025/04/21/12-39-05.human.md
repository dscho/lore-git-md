Platform compatibility patch adding ARM64 support via compiler built-ins. This is the first of six patches in a series to enable Git on Windows/ARM64 systems, particularly targeting new GitHub Action runners.

The patch modifies `compat/bswap.h` to use compiler built-in byte swap functions (`__builtin_bswap32/64`) when available, which is needed for CLANGARM64 support on Windows. The change first checks for these built-ins using `__has_builtin` (available since Clang 10/GCC 10), with a fallback for older compilers. This maintains the existing x86 assembly implementations as a fallback path.

The change is narrowly scoped to the byte swapping functionality needed for ARM64 support, with clear compiler version requirements documented in the code. As the first patch in the series, it establishes a foundation for the subsequent Windows/ARM64 specific changes while being generally useful for any platform with modern compilers. The commit message could be more explicit about how this specifically enables Windows/ARM64 support, but the technical approach appears sound.
