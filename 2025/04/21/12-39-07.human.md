This is a platform compatibility patch in a series adding Windows/ARM64 support. It disables the nedmalloc allocator for Windows/ARM64 builds where it fails to compile, noting that nedmalloc appears unmaintained since 2017 with little hope for fixes.

The change modifies `config.mak.uname` to only enable nedmalloc when not building for CLANGARM64. The commit message provides clear justification for the change, pointing to an open issue showing the project's inactive status. This appears to be a straightforward build system adjustment to make Git compile on the new ARM64 Windows platform.

The patch is part of a coordinated effort to enable Git on Windows/ARM64 GitHub Action runners, with this specific change addressing a build blocker. Johannes Schindelin brings Windows-specific expertise to the series, and the change follows established patterns for platform-specific build tweaks.
