This is a platform compatibility patch series adding Windows/ARM64 support to Git. The series comes from the Git for Windows project, which has already been shipping ARM64 builds since late 2024. With GitHub Actions now offering ARM64 Windows runners in public preview, the maintainers want to upstream the minimal changes needed for proper ARM64 support.

The 6-patch series includes:
- Two patches from Dennis Ameling adding bswap.h support and build system configuration for clangarm64
- Four patches from Johannes Schindelin covering Windows-specific adjustments: avoiding nedmalloc on ARM64, MSVC build handling, adjusting config file locations, and lowering max tree depth for clangarm64 builds

The changes touch compatibility headers, build configuration, and environment handling, with most modifications being straightforward ARM64 adaptations. The series appears well-motivated given the growing ARM64 ecosystem and GitHub's new CI support, and comes from experienced Windows Git maintainers.
