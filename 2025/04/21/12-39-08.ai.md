Platform compatibility patch extending MSVC build support for Windows/ARM64, part of a series introducing ARM64 support for Windows builds. This is patch 4/6 in the initial submission.

The patch modifies config.mak.uname to properly handle Windows/ARM64 builds when using MSVC (Microsoft Visual C++). It mirrors the existing CLANGARM64 support already implemented for MINGW builds, setting the installation prefix to /clangarm64 when MSYSTEM=CLANGARM64 is detected. The change maintains backward compatibility by falling back to /mingw64 for other MSYSTEM values.

Key technical details:
- Single file modified: config.mak.uname
- Build system change follows same pattern as earlier MINGW ARM64 support
- Uses same CLANGARM64 MSYSTEM detection as patch 2/6
- Maintains existing behavior for non-ARM64 builds
-else conditional structure preserves existing logic flow

This patch completes the ARM64 build support by covering the MSVC toolchain case, complementing the earlier MINGW/GCC support. The change is straightforward and consistent with the series' approach of adapting existing Windows build infrastructure rather than introducing new mechanisms. As with other patches in the series, this appears to be a necessary but non-controversial change to enable Windows/ARM64 compilation.
