Dennis Ameling and Johannes Schindelin (Dscho) are collaborating to add Windows/ARM64 support to Git, targeting newly available GitHub Action runners. The initial patch series (v1, 6 patches) introduces platform-specific changes needed for building and testing on this architecture. 

The latest patch in the series addresses a build issue by disabling the nedmalloc allocator specifically for Windows/ARM64 targets, as it fails to compile and appears unmaintained. The change is cleanly scoped to only affect the ARM64 case while preserving nedmalloc usage for other Windows builds. This follows established patterns for platform-specific configuration in Git's build system.

The series builds on Git for Windows' existing ARM64 support and includes other necessary adjustments like ARM64 bswap support, clangarm64 build configuration, MSVC ARM64 handling, and mingw/arm64 path fixes. So far there hasn't been review feedback on the initial submission, but the patches appear well-justified and focused on the immediate goal of enabling basic functionality on the new platform. The next steps will likely involve testing on actual ARM64 Windows runners and addressing any additional platform quirks that emerge.
