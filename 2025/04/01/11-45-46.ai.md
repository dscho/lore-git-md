Performance enhancement for `git cat-file` batch filtering, building on the bitmap acceleration work.

This is a reply in the ongoing series about optimizing `git cat-file`'s batch mode filtering capabilities. Toon Claes points out that since the decision has been made to use `--filter` as the option name, the code can now directly use the `OPT_PARSE_LIST_OBJECTS_FILTER` macro for consistency with other Git commands. This is a minor but important implementation detail that ensures the new filtering functionality aligns with existing Git conventions.

The original patch being replied to (from Patrick Steinhardt) introduced the initial plumbing for object filtering in `git cat-file`, though the actual filtering wasn't yet implemented at that point. The current discussion shows the series has progressed significantly since then, with bitmap acceleration now fully implemented and showing dramatic performance improvements (41x speedup in benchmarks).

The key technical detail here is the use of `OPT_PARSE_LIST_OBJECTS_FILTER` which handles the filter specification parsing consistently with how `git rev-list` and other commands process their `--filter` options. This maintains a unified interface across Git commands while enabling the performance optimizations demonstrated in later patches of the series.
