Documentation patch addressing Asciidoctor formatting issues with triple-dot notation in Git manual pages. This is part of an ongoing series to fix rendering artifacts that appear when building docs with Asciidoctor, particularly affecting synopsis sections.

The patch focuses on improving the processing of ellipsis (`...`) in three contexts: main text processing, monospaced text, and inline quotes. Key changes include adding `{empty}` markers around dots in the main processing function and special handling for standalone dots in monospaced contexts. A specific example fixed is the `git-mv <source>... <dest>` pattern which was previously problematic.

The changes build on prior work (patch 0b080a70ab) and appear to resolve the immediate issues, though the thread indicates some edge cases may remain. The patch is technically sound but represents an intermediate step toward a more comprehensive solution, with the author mentioning work on a parser generator alternative to address growing regex complexity.

This continues the effort to ensure Git's documentation renders correctly across different Asciidoctor versions and environments, with particular attention to synopsis sections that use special formatting.
