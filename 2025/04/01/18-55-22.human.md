Perl removal series feedback on textconv test conversions. Johannes Schindelin provides review comments on patch 13/20 in Patrick Steinhardt's series to eliminate Perl dependencies from Git's test suite. This patch converts textconv-related tests in t4030, t4031, and t7815 from Perl to shell utilities.

Schindelin notes the patch is more puzzling than others in the series, questioning why t4030 uses `tr` conversion rather than the more obvious `test-tool hexdump` approach used in t4031. He observes that while the test expectations weren't updated in t4030, the t4031 conversion actually strengthens the test assertions by being more specific about the expected output. The review confirms the technical correctness of the changes while expressing mild preference for consistency with the `test-tool hexdump` approach seen elsewhere in the series. 

This continues the pattern of minor optimization feedback on an otherwise well-reviewed series, with no requests for changes to the patch. The feedback focuses on implementation choices rather than functionality, as the core Perl-to-shell conversion work has already been validated through earlier reviews.
