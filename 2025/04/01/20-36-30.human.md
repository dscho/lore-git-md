This is the second and final patch in a series enhancing `git version --build-options` to report SHA implementations. The patch focuses on adding display of the "non-crypto-SHA-1" backend used for faster but cryptographically unsafe operations.

The changes:
1. Adds documentation explaining the new "non-crypto-SHA-1" line in the version output
2. Defines `SHA1_UNSAFE_BACKEND` symbols in hash.h for each unsafe SHA-1 implementation
3. Updates help.c to show the unsafe backend alongside the regular SHA-1 implementation

The patch follows the maintainer-approved approach from the first patch, using preprocessor symbols for compile-time safety. It implements the final agreed terminology ("non-crypto-SHA-1") and maintains the simple output format showing raw symbol names. The implementation is clean and narrowly scoped, completing the series' goal of making SHA backend selection more transparent to users.

With this patch, the series' technical work appears complete - it addresses all prior feedback and resolves the remaining presentation details for unsafe SHA-1 reporting. The changes are minimal and focused, touching only the version reporting system without introducing runtime overhead.
