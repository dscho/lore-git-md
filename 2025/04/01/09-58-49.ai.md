Continuation of the meson completion installation discussion. Patrick Steinhardt responds to the initial report about tcsh completions not being installed automatically with the meson build system, even when explicitly enabled via `-Dcontrib=completion`.

The response clarifies that this matches the current Makefile behavior (which also doesn't auto-install completions) but acknowledges this isn't ideal. The key issue identified is the lack of standardization across distributions for completion script installation paths - particularly for bash, tcsh, and zsh. Patrick raises important questions about whether there's sufficient consensus on standard paths (`/usr/share/bash-completion` etc.) to justify implementing automatic installation in meson.

This moves the discussion from a potential bug report to a broader packaging policy question. The response suggests that if path standardization exists across distributions, automatic installation would be desirable, but implies this needs verification first. The thread now awaits input from package maintainers or those familiar with cross-distro completion script conventions.
