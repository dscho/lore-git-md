This is a test portability discussion in the ongoing bugfix thread for `--left-only`/`--right-only` behavior with unrelated histories. Johannes Sixt points out two portability issues with Matt Hunter's proposed test implementation: the use of Bash process substitution (`<(sort head)`) which doesn't work on Windows, and notes it's also a Bash-specific feature not guaranteed across all POSIX shells. This continues the thread's pattern of iteratively improving the test implementation, following earlier discussions about moving from output counting to semantic validation of commit separation. The comment reinforces the project's emphasis on cross-platform compatibility, particularly Windows support, while maintaining the test's core purpose of verifying the zero-common-commit invariant.
