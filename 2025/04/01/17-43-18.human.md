This is a continuation of the build system discussion about shell completion script installation paths in the meson build.

Akshay Hegde responds to Patrick Steinhardt's earlier message about the current manual installation requirement for tcsh completions. While acknowledging the current behavior matches the Makefile approach, Hegde notes this isn't ideal. The core issue remains the lack of standardized paths across distributions for bash, tcsh, and zsh completions.

Hegde shares an observation that zsh completions typically install under `/usr/share/zsh/site-functions`, though notes this isn't authoritative for all distros. He suggests a potential solution: extending meson_options to allow specification of completion directories, with automatic installation when paths are provided. This would maintain flexibility while improving the user experience.

The email reinforces that while this is a quality-of-life improvement rather than a critical issue, it's worth considering solutions that work within the reality of varying distro conventions. The discussion remains open-ended, awaiting more authoritative input about cross-distro path standardization.
