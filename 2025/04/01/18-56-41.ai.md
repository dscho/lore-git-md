This is a follow-up in Patrick Steinhardt's series eliminating Perl dependencies from Git's test suite, specifically addressing the GPG test helpers. The patch converts the `sanitize_pgp()` helper from using Perl to `sed`, removing the PERL_TEST_HELPERS dependency. Johannes Schindelin notes the commit message is slightly outdated since the implementation was changed from awk to sed during review.

The changes include:
- Rewriting `sanitize_pgp()` in t/lib-gpg.sh to use sed for stripping PGP signatures
- Adding PERL_TEST_HELPERS to specific tests in t6300-for-each-ref.sh that still require Perl functionality
- Maintaining test coverage while reducing Perl dependencies

This is part of the broader effort to minimize Perl usage in Git's test infrastructure, with only Gitweb and HTTPD CGI remaining as Perl dependencies after this series. The patch has already been reviewed positively, with Schindelin's comment being a minor documentation correction rather than a technical issue. The changes demonstrate careful attention to maintaining test behavior while modernizing the implementation.
