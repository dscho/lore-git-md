Build system fix for contrib tests in Meson builds. This is part of Patrick Steinhardt's v2 series improving Git's build infrastructure.

The patch addresses an issue where contrib tests (for the netrc credential helper and git-subtree) were being wired up in Meson builds even when `-Dtests=false` was specified. This caused errors since the tests depend on the `test_environment` variable that only exists when tests are enabled. The fix simply wraps the test definitions in a conditional check for the tests option.

Johannes Schindelin reviews the patch positively, noting it looks good though he wishes for better code review tools on mailing lists. The change is straightforward - moving test setup code inside `if get_option('tests')` blocks in both contrib modules' meson.build files. This matches the behavior of the Makefile build system and fixes the reported error case.

The patch appears well-contained and uncontroversial, with no outstanding technical concerns. It's a clear improvement that makes Meson builds more consistent with the existing build system behavior.
