This is a refactoring patch for git-gui that removes obsolete Tcl code. The patch simplifies the `_open_stdout_stderr` function by removing a workaround for older Tcl versions (pre-8.4.7) that didn't support stderr-to-stdout redirection. The author notes that git-gui now requires Tcl ≥8.5, making the workaround unnecessary, and has verified the simplified version works on current Linux, Cygwin, and Git for Windows environments.

The change reduces 21 lines of conditional logic down to just 2 lines, eliminating both the special case handling and any potential concern about the command being executed twice. The patch appears well-justified with clear historical context about Tcl version support and testing across platforms. This is a straightforward cleanup of technical debt that was missed in a previous modernization effort (7145c65).
