Build system issue report about meson completion installation. This email reports an apparent gap in the meson build system where shell completions (specifically tcsh completion) are built but not installed when using the `-Dcontrib=completion` option, despite other contrib items like git-subtree being properly installed. The reporter provides detailed build configuration showing they explicitly enabled completion support and observed the files being copied to the build directory but not installed to the target prefix.

Key technical details include:
- Build configuration shows `-Dcontrib=completion,subtree` with custom prefix and libdir
- git-subtree installation works as expected to libexec/git-core
- Completion files are copied to build directory but not installed
- No obvious missing options in meson_options.txt or meson.build
- Reporter is using meson with ninja backend in release mode

This appears to be either an oversight in the meson build configuration or possibly an undocumented requirement for additional installation steps. The report is well-documented with clear reproduction steps and demonstrates the reporter who has carefully investigated before asking. The issue affects users trying to adopt the meson build system for full Git installations including shell completions.
