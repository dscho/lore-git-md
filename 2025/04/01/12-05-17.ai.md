This is a review comment on a patch in the Git cat-file batch mode filtering enhancement series. Karthik Nayak provides feedback on Patrick Steinhardt's v2 patch that introduces object filtering to `git cat-file --batch-all-objects`.

The review focuses on documentation and test coverage clarifications:
1. Suggests making explicit that the new `--filter` option is specifically for `--batch-all-objects` mode in the documentation
2. Questions how filtering interacts with other batch modes (though the implementation shows it's supported more broadly)
3. Recommends adding a test case for the `--no-filter` option

The patch itself adds filtering infrastructure to `cat-file` by:
- Adding `list_objects_filter_options` to the batch options struct
- Wiring up filter option parsing via `OPT_CALLBACK`
- Implementing basic filter validation that currently rejects all non-disabled filters (to be enabled in later patches)
- Adding tests for various invalid/unsupported filter cases

This is part of a larger series that will eventually enable bitmap-accelerated filtering (demonstrated in later versions to provide 41x speedups). The current patch is laying groundwork while explicitly disabling the functionality until the full implementation is ready.

The review is constructive and focused on improving clarity rather than raising fundamental objections. The questions raised don't appear to block progress but rather seek to make the interface and behavior more precisely documented and tested.
