This appears to be a behavioral quirk where the presence of a period in a trailer key (like "My-6.11-Version") causes the parser to stop processing the entire trailer block, even though the man page doesn't document this restriction.

The use case involves tracking backported commits from software versions (like Linux kernel versions), where version numbers in trailer keys would be natural.

The email questions whether this is intentional behavior, noting the man page doesn't mention any restrictions on period characters in trailer keys. The reporter provides their Git version (2.49.0 with Google-internal monitoring additions) but indicates this shouldn't affect core functionality.
