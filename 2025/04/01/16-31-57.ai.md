Build system fix for contrib tests in meson builds, part of Patrick Steinhardt's v2 series. This patch specifically addresses an issue where contrib tests (netrc credential helper and git-subtree) were being wired up unconditionally in meson builds, even when `-Dtests=false` was specified. The fix wraps the test definitions in conditional blocks checking `get_option('tests')`.

The changes affect two meson.build files in contrib/:
- credential/netrc/meson.build
- subtree/meson.build

Johannes Schindelin reviews the patch positively, noting it looks good though he mentions the practical limitation of reviewing via email without proper tooling. The technical solution is straightforward - moving test definitions inside conditional blocks that respect the build configuration. This matches the behavior seen in the Makefile build system and prevents errors when `test_environment` isn't defined.

This appears to be a clean fix for the reported issue with no outstanding technical concerns. The patch maintains consistency with the series' goal of improving build system behavior across different configurations.
