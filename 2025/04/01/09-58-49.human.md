This is a build system discussion about shell completion installation in the meson build system.

Patrick Steinhardt responds to Akshay Hegde's report about tcsh completions not being installed automatically with `-Dcontrib=completion`. He confirms this is the current behavior (matching the Makefile's approach) but questions whether that's the right long-term solution.

The key issue is whether there's sufficient standardization across distributions for where completion files should be installed. Patrick raises important questions about installation paths for bash, tcsh and zsh completions, suggesting that if there's consensus on standard locations, automatic installation would be preferable.

The response indicates this isn't a bug per se, but rather an opportunity to improve the meson build system's behavior if the community can establish standard installation paths. The discussion appears likely to continue with input from distribution maintainers about their preferred completion file locations.
