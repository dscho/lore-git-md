This thread discusses standardizing shell completion script installation paths in Git's meson build system, prompted by inconsistencies in how tcsh completions are handled. Patrick Steinhardt has been leading the technical direction, with Todd Zullinger providing valuable Fedora packaging context.

The discussion has evolved from initial path issues to establishing sensible defaults. Steinhardt advocates for simplicity - hardcoding stable paths for bash and zsh (following Fedora's established locations) while maintaining the current manual approach for tcsh. Zullinger's latest response confirms Fedora's paths for bash, zsh, and fish (though Git lacks fish completions) and agrees that configurability may be unnecessary if paths remain consistent across distributions.

The emerging consensus favors:
1. Automatic installation for bash (`/usr/share/bash-completion/completions`) and zsh (`/usr/share/zsh/site-functions`)
2. Keeping tcsh status quo (manual copying from contrib/)
3. Leaving fish support for future consideration

Both contributors appear aligned on starting with these practical defaults and only adding complexity if real-world problems emerge. The discussion remains focused on implementation rather than theoretical edge cases, with distribution maintainer experience guiding the path selections.
