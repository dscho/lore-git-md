This thread began as a discussion about inconsistent installation paths for tcsh completion scripts in Git's meson build system, but quickly expanded into a broader conversation about standardizing shell completion paths across distributions. Patrick Steinhardt led the technical direction, with valuable input from Todd Zullinger providing Fedora packaging context.

The discussion reached consensus on several key points: Fedora's established paths for bash`/usr/share/bash-completion/completions` and zsh (`/usr/share/zsh/site-functions`) will be adopted as defaults in the meson build system, while tcsh completions will continue to be manually installed as they have been for years. Fish shell completions remain unimplemented for now due to lack of demand. The approach favors simplicity over premature configurability, avoiding new build options unless real-world problems emerge.

Steinhardt has now submitted a patch implementing this consensus approach, marking the transition from discussion to concrete implementation. The patch follows the agreed technical direction without introducing surprises, using Fedora's paths as the reference implementation while maintaining the status quo for tcsh. This appears to conclude the active discussion phase of this thread, with the solution now moving into the implementation and review stage.
