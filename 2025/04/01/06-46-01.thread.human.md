This thread reports an issue with the meson build system's handling of shell completion installation. A contributor has identified that while tcsh completion files are built when using `-Dcontrib=completion`, they are not being installed to the target prefix, unlike other contrib items such as git-subtree which install correctly. The reporter provides detailed configuration showing they explicitly enabled completion support and observed the files being copied to the build directory but not installed.

The issue appears to be either a configuration oversight in the meson build files or possibly missing documentation about additional installation steps needed for completions. The report is thorough, including the exact build configuration used (`-Dcontrib=completion,subtree` with custom prefix and libdir) and clear observations about where files are and aren't being installed. This affects users trying to adopt meson for full Git installations including shell completions. The thread is just starting, so no solutions or responses from maintainers have been posted yet.
