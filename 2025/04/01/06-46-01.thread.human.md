This thread discusses how Git's meson build system should handle installation of shell completion scripts, prompted by a report that tcsh completions weren't being automatically installed. The discussion has evolved from a technical build system question to a broader consideration of distribution packaging practices.

Patrick Steinhardt initially confirmed the current behavior matches the Makefile approach but noted the lack of standardized completion paths across distributions. Akshay Hegde proposed making the meson build configurable per shell. Todd Zullinger then provided valuable Fedora-specific context, showing that different shells already use different paths in practice - bash uses a common path while tcsh has remained in a non-standard location for a decade without issues, and zsh completions are omitted entirely since upstream zsh already covers them.

In the latest response, Steinhardt questions whether per-shell configuration is truly needed, suggesting that for shells like bash and zsh with relatively stable paths across distributions, the build system could just hardcode sensible defaults (modeled after Fedora's paths). For tcsh, the status quo of manual file placement seems acceptable given its long stability. This would simplify the build system while still providing automatic installation for the majority case. The discussion appears to be converging on this pragmatic approach, though no final decision has been made.
