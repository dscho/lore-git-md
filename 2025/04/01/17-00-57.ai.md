Performance optimization patch addressing O(N^2) scaling in bundle creation. This is the second patch in Karthik Nayak's series, replacing the quadratic duplicate refname check in `object_array_remove_duplicates()` with an O(1) `strset`-based solution in `write_bundle_refs()`. The change yields a 6x speedup in repositories with 100k refs (14.6s → 2.4s in benchmarks).

The optimization focuses on eliminating duplicate refnames in the output without comparing referenced objects, which is sufficient for bundle creation. The patch handles two key cases: (1) identical refnames pointing to the same object (e.g. "master" and "refs/heads/master"), and (2) identical refnames pointing to different objects (e.g. from exclusion patterns like "master^!"). The solution only checks refnames of INTERESTING objects being written to the bundle header.

Implementation removes `object_array_remove_duplicates()` entirely since its functionality is now handled during ref writing. Test changes confirm the fix works for edge cases previously marked as failing (duplicate refs with `--all`, short/long name variants). The approach appears technically sound with comprehensive benchmarking showing linear scaling where the original showed 2200x slowdown at 100k refs.
