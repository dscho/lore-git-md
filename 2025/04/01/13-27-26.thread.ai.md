Thread summary:

Bug report regarding git-interpret-trailers' handling of trailer keys containing periods (e.g. "My-6.11-Version"). Current behavior silently fails to parse the entire trailer block when encountering a period in a key, despite no documentation of this restriction. The reporter provides a clear test case demonstrating the issue, with use case context involving version tracking of backported commits (common in kernel development). The discrepancy between documented behavior (no mention of period restrictions) and actual behavior suggests either a documentation gap or a parser bug. The reporter's Git version (2.49.0 with Google-specific additions) is noted but shouldn't affect core functionality. Key open question is whether this is intentional undocumented behavior or a bug to be fixed. The test case provides clear reproduction steps for investigation.
