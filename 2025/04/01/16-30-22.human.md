This is a build system fix for Gitweb's JavaScript generation, part of Patrick Steinhardt's series consolidating build improvements. The patch corrects a regression introduced in commit 19d8fe7da65 where the Makefile rule for generating gitweb.js incorrectly included the build script itself in the concatenated output. The fix modifies the Makefile to properly filter only JavaScript files.

Toon Claes provides a minor typo correction ("ni" -> "in") in the commit message but otherwise approves the patch. The technical solution has already been discussed in the thread, with Johannes Schindelin suggesting a more future-proof approach (filtering out .sh files rather than filtering for .js files) that doesn't affect the immediate correctness of this fix.

This appears to be a straightforward, well-justified build system fix that's part of a larger coordinated effort to improve Git's build infrastructure. The patch is technically sound with no outstanding objections beyond the typo correction.
