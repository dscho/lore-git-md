This is patch 4/7 in Patrick Steinhardt's refactoring series that continues the object-file-cleanup effort. The patch focuses on reorganizing function declarations between header files to better align with where the functions are actually implemented.

The main change moves several object-related function declarations from the general `object-store.h` to more specific headers (`object-file.h` and `packfile.h`) where their implementations live. This includes functions for:
- Loose object handling (`odb_loose_cache`, `for_each_loose_object`, etc.)
- Packed object iteration (`for_each_packed_object`)
- Core object file operations (`hash_object_file`)

The patch updates include paths in 12 files that used these declarations, switching them from `object-store.h` to `object-file.h` where appropriate. This is a mechanical change that doesn't modify any behavior - it just improves code organization by putting declarations closer to their implementations.

This continues the series' pattern of incremental, behavior-preserving changes to clean up the object storage code. The changes appear straightforward and well-contained, with no obvious issues in the implementation. The patch follows naturally from the earlier header reorganization work in the series.
