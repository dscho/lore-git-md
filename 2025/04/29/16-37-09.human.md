This is a feature patch in the ongoing `git send-email` Outlook Message-ID handling series. Aditya Garg introduces a `--[no-]outlook-id-fix` option to control how Git handles Message-IDs when sending through Outlook SMTP servers, which have non-standard behavior that breaks email threading.

The patch adds a boolean toggle that defaults to automatic detection for known Outlook domains (smtp.office365.com and smtp-mail.outlook.com), with explicit `--outlook-id-fix` and `--no-outlook-id-fix` options to override this behavior. The documentation clearly explains the Outlook-specific behavior and warns about using the fix with non-Outlook servers. The implementation includes both the new option and a fix to properly document the existing `--no-smtp-auth` option.

This is an intermediate version (v4) in what will become a 7-part series. The current boolean toggle will later evolve into a tri-state configuration in the final version. The patch shows good attention to Junio Hamano's earlier feedback about documentation structure, with clear separation of automatic vs manual behavior in the help text. The code changes are minimal (14 lines) and focused, with appropriate test coverage.
