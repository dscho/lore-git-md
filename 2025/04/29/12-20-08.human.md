Bugfix proposal for `git mv` command addressing a known assertion failure. Patrick Steinhardt follows up on Junio Hamano's historical context about test t7001-mv by proposing a fix for the underlying issue that causes the test to fail. The test demonstrates a bug where `git mv` allows moving both a parent directory and its child simultaneously, which triggers an assertion in Debug builds.

The proposed patch adds validation to prevent moving parent and child directories in the same command, using a hashmap to track moved directories and checking for parent-child relationships. When detected, it fails with a clear error message: "cannot move both 'builtin/add.c' and its parent directory 'builtin'". The patch is marked as a work-in-progress, not yet passing all tests, but shows the direction for a proper fix.

This moves beyond the immediate CI workaround (building in Release mode) to address the root cause that test t7001-mv was meant to highlight. The patch demonstrates good technical understanding of the problem space, though it will need refinement before being ready for inclusion. This represents progress on the 9-month-old issue that the test was originally added to document.
