Test modernization patch converting reftable basics test to Clar framework.

This is the second patch in a 10-part series migrating reftable unit tests from custom test harnesses to the Clar framework. It converts the reftable basics test file (t-reftable-basics.c) to use Clar assertions (u-reftable-basics.c) while maintaining identical test coverage. The patch updates both Makefile and meson.build build configurations to track the new test location.

Key changes include:
- Replaces custom test assertions with Clar's cl_assert* macros
- Breaks up test cases into individual Clar test methods (test_reftable_basics__*)
- Maintains all existing test coverage for reftable basics functionality:
  * Binary search (binsearch)
  * String array utilities (names_length, names_equal, parse_names)
  * Buffer operations (common_prefix_size)
  * Big-endian encoding (put/get be16/be24)
  * Memory allocation helpers (REFTABLE_ALLOC_GROW)
- Updates build system to reference new test file location
- The conversion appears thorough, maintaining all original functionality while adopting the standard Clar framework conventions
- Follows the pattern established in patch 1/10 by using Clar assertions consistently
- Build system changes are minimal and mechanical, just tracking the new test location
- No behavior changes to actual reftable code - purely a test infrastructure modernization
- Part of broader effort to standardize test framework usage across Git codebase
