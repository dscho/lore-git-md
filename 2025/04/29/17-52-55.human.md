Test modernization patch converting reftable block tests to Clar framework. This is patch 3/10 in a series migrating all reftable unit tests from custom test harnesses to the standard Clar framework.

The patch converts the reftable block tests, which verify read/write operations on different block types (ref, log, obj, index). The conversion maintains the same test coverage while standardizing on Clar assertions (`cl_assert`) and test method naming (`test_reftable_block__*`). The original test file is deleted and replaced with the Clar-based version, with corresponding updates to the Makefile and meson.build files.

The tests validate core block operations including:
- Writing and reading records of each block type
- Block iteration and seeking
- Record equality comparisons
- Error handling for invalid operations

This continues the mechanical but important work of standardizing Git's test infrastructure. The patch appears well-structured, following the same pattern as previous conversions in the series. No behavior changes are introduced - this is purely a test framework migration.
