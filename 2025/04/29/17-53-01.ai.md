This is the ninth patch in a v2 series converting reftable unit tests to use the Clar framework. The patch focuses on migrating the stack test file from the old `t-*.c` pattern to the new `u-*.c` Clar format.

The changes include:
- Renaming `t-reftable-stack.c` to `u-reftable-stack.c`
- Converting test assertions from custom `check()` macros to Clar's `cl_assert()` macros
- Updating build system files (Makefile and meson.build) to reference the new test file
- Removing the old test file pattern check since this completes the migration

The test coverage remains the same, verifying reftable stack functionality including:
- Basic stack operations (add, read, iterator)
- Transaction handling and concurrency
- Auto-compaction behavior
- Error cases and edge conditions
- Log record handling and expiration

This completes the conversion of all reftable unit tests to Clar, removing the last remaining `t-*.c` test file. The patch maintains the same test coverage while standardizing on the modern Clar test infrastructure used elsewhere in Git's test suite.
