This is patch 8/10 in a test modernization series converting reftable unit tests to use the Clar framework. The patch focuses on converting the reftable record tests, which verify the core record handling functionality for different reftable block types (ref, log, obj, index).

The conversion follows the established pattern of the series:
- Replaces custom test assertions with Clar's cl_assert macros
- Maintains all existing test coverage while restructuring into Clar-style test methods
- Updates build files (Makefile and meson.build) to track the new test location
- Preserves all the original test cases including:
  * Record comparison operations for all block types
  * Roundtrip encoding/decoding validation
  * Varint handling tests
  * Key encoding/decoding tests
  * Edge case handling (overflows, empty values)

The tests cover all record operations including:
- Ref records (value types: VAL1, VAL2, SYMREF, DELETION)
- Log records (UPDATE vs DELETION, timestamp handling)
- Obj records (hash prefix and offset handling)
- Index records (key/offset validation)

The conversion appears thorough and maintains the same test coverage while standardizing on the Clar framework. This continues the mechanical conversion pattern established in earlier patches of the series.
