This is part 6/10 of a test modernization series converting reftable unit tests to the Clar framework. The patch focuses on the reftable reader test, transforming it from a custom test harness to use Clar assertions while maintaining the same test coverage.

The conversion follows the established pattern seen in previous patches of this series. The original test file (t-reftable-reader.c) is deleted and replaced with a new Clar-based version (u-reftable-reader.c). The test cases verify two key reader behaviors: single seek operations (test_reftable_reader__seek_once) and repeated seek operations (test_reftable_reader__reseek). Both tests validate that the reader can properly locate and iterate through reference records, including proper handling of empty refname seeks and multiple iterations.

The test cases use the existing cl_reftable_write_to_buf helper introduced earlier in the series to set up test data. Key assertions verify correct record equality comparison and proper iterator behavior. The Makefile and meson.build updates follow the series' standard pattern of removing the old test and adding the new Clar-based version to the test suites.

This patch appears mechanically sound, following the same conversion methodology as the earlier patches in the series. The test coverage remains identical to the original while adopting the standardized Clar framework. No new test cases are added functionality - this is purely an infrastructure modernization change.
