Test modernization in the reftable subsystem. This is patch 8/10 in a series converting reftable unit tests to use the Clar framework, part of Git's ongoing test infrastructure standardization effort.

The patch converts the reftable record test file, which verifies core record operations for different reftable block types (ref, log, obj, and index records). The tests validate comparison functions, round-trip encoding/decoding, and edge cases like varint overflow handling. The conversion maintains all existing test coverage while switching from a custom test harness to Clar's standardized assertions.

The changes follow the established pattern seen in earlier patches of this series - replacing custom test macros with `cl_assert` calls and restructuring test functions to Clar's style. Build system updates remove the old test file and add the new Clar-based version. The patch appears mechanically sound, continuing the series' consistent approach to test modernization.
