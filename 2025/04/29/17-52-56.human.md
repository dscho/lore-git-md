This is the fourth patch in a 10-part series modernizing reftable tests by converting them to the Clar framework. The patch focuses on the merged table tests, which verify how reftable handles merging multiple reference tables together.

The conversion follows the established pattern from earlier patches in the series: the test file `t-reftable-merged.c` is deleted and replaced with `u-reftable-merged.c`, with all assertions updated to use Clar's `cl_assert` macros. The test cases remain functionally identical, covering:

1. Basic merged table operations with single records
2. Handling multiple updates to the same reference
3. Repeated seek operations on merged tables
4. Log record merging behavior
5. Default write option validation

The patch maintains the same test coverage while standardizing on Git's modern test infrastructure. Build system files (Makefile and meson.build) are updated to track the new test location. This continues the series' mechanical conversion approach - no behavior changes, just test framework modernization.
