Refactoring patch as part of the object-file-cleanup series. This is the first of seven patches in v3 of Patrick Steinhardt's series to remove `repo_has_object_file()` and clean up object storage APIs.

The patch moves `struct packed_git` and its associated comparison function `pack_map_entry_cmp()` from the generic "object-store.h" header to the more specific "packfile.h". The rationale is straightforward - since this struct specifically describes packfile metadata, it belongs with other packfile functionality rather than in the general object storage header.

This is a mechanical change with no behavior modifications, just header reorganization. The diff shows the complete movement of the struct definition and function, with corresponding updates to include statements where needed. As the first patch in the series, it sets up the groundwork for subsequent API changes by cleaning up header dependencies.

The change appears well-contained and uncontroversial, following Git's ongoing effort to organize code more logically. Since it's purely structural with no functional impact, it should be an easy merge candidate as part of the larger series.
