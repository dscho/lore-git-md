This is patch 3/10 in a test modernization series converting reftable unit tests to the Clar framework. The patch focuses on converting the reftable block tests, which test the low-level block storage format used by reftables.

The conversion follows the established pattern from previous patches in the series:
- Deletes the old test file (t-reftable-block.c)
- Creates a new test file (u-reftable-block.c) using Clar assertions
- Updates build system files (Makefile and meson.build) to track the new location
- Maintains identical test coverage while using the modern framework

The tests verify read/write operations for four block types:
1. Index blocks (test_reftable_block__index_read_write)
2. Log blocks (test_reftable_block__log_read_write)  
3. Object blocks (test_reftable_block__obj_read_write)
4. Reference blocks (test_reftable_block__ref_read_write)

Each test follows the same structure:
- Sets up test data (30 sample records per test)
- Writes records to a block
- Verifies they can be read back correctly
- Tests seeking behavior
- Validates edge cases like empty refnames

The conversion is mechanical replacements of old test assertions (check_int, check) with Clar equivalents (cl_assert_equal_i, cl_assert). The test logic and coverage remains unchanged from the original version. This continues the series' goal of standardizing test infrastructure while preserving all existing test cases.
