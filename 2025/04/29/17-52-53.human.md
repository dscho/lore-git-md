Test modernization patch converting reftable test helpers to Clar framework.

This is the first patch in a 10-part series migrating reftable unit tests to the Clar testing framework. It introduces three key helper functions (`cl_reftable_set_hash`, `cl_reftable_strbuf_writer`, and `cl_reftable_write_to_buf`) in unit-test.{c,h} that will be used by subsequent test conversions. The helpers provide reftable-specific test utilities that conform to Clar's assertion style while maintaining the same functionality as the original custom test harness.

The implementation looks thorough, with proper error checking via Clar assertions and careful handling of reftable writer operations. The patch follows the series' established pattern of moving functionality first before converting tests to use it. This foundational work enables the actual test file conversions in later patches, completing the reftable test modernization effort.
