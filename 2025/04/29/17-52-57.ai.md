3. `test_reftable_pq__merged_iter_pqueue_top` validates the top-of-queue behavior and heap property maintenance

- Replaces `check()` calls with `cl_assert()` variants
- Converts test functions to Clar-style naming (`test_reftable_pq__*`)
- Maintains all original test logic and edge cases
- Updates build files (Makefile and meson.build) to track the new test location
- Removes the old test file (t-reftable-pq.c) after conversion
