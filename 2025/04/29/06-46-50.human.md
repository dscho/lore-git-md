Refactoring patch in a series converting reftable tests to Clar framework. This is the first of a 9-patch series standardizing Git's test infrastructure by migrating all reftable-related tests to the Clar unit testing framework.

The patch adapts helper functions in `lib-reftable.{c,h}` to use Clar conventions, renaming them from `t_` to `cl_` prefixes. Junio C Hamano reports expected build failures when testing this patch in isolation, as unconverted test files still reference the old function names. The author confirms this is intentional - the series is designed to be applied atomically, with temporary breakage during the transition.

The author proposes an alternative approach of keeping the helpers in `unit-test.{c,h}` during conversion, then moving them back in a final patch. This appears to be a response to Junio's feedback about the intermediate breakage, suggesting the author is open to adjusting the patch series structure if needed.

The changes follow established patterns from prior test framework conversions, with mechanical updates to function names and signatures. This is part of a larger effort to modernize Git's test infrastructure, building on work by Patrick Steinhardt and others. The series appears well-structured and the author demonstrates responsiveness to feedback.
