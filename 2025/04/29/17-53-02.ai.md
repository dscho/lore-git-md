Test modernization patch completing the reftable test conversion to Clar framework. This is the final patch (10/10) in the v3 series, adapting the remaining helper functions from lib-reftable.{c,h} to use Clar assertions and moving them out of unit-test.{c,h}.

The patch:
1. Renames helper functions with `cl_` prefix to match Clar conventions:
   - `t_reftable_set_hash` -> `cl_reftable_set_hash`
   - `t_reftable_strbuf_writer` -> `cl_reftable_strbuf_writer`
   - `t_reftable_write_to_buf` -> `cl_reftable_write_to_buf`
2. Updates all assertions to use Clar's `cl_assert` macros
3. Removes duplicate implementations from unit-test.{c,h}
4. Adjusts build system (Makefile and meson.build) to reflect the new locations

Key technical details:
- Maintains same functionality while standardizing on Clar framework
- Helper functions provide:
  * Hash initialization (`cl_reftable_set_hash`)
  * Strbuf-based writer creation (`cl_reftable_strbuf_writer`)
  * Comprehensive record writing with validation (`cl_reftable_write_to_buf`)
- Fixes a type cast in block iteration loop (`(size_t)stats->ref_stats.blocks`)
- Completes removal of custom test infrastructure for reftable tests

This concludes the mechanical conversion of all reftable tests to Clar, following the pattern established in patches 1-9. The changes are straightforward with no behavior modifications - purely test infrastructure modernization.
