Test modernization patch converting reftable test helpers to Clar framework.

This is the first patch in a 10-part series migrating reftable tests to the Clar framework. It introduces three key test helper functions in unit-test.{c,h} that will be used by subsequent test files:

1. `cl_reftable_set_hash` - Initializes hash values for testing
2. `cl_reftable_strbuf_writer` - Creates a reftable writer that writes to a strbuf
3. `cl_reftable_write_to_buf` - Comprehensive helper that writes ref/log records to a buffer with validation

The implementation maintains the same test coverage while adapting to Clar's assertion model (using `cl_assert`). The helpers handle both ref and log records, validate block structure, and check writer statistics. This is a mechanical conversion preserving existing functionality - no behavior changes to the reftable code itself, just test infrastructure modernization.

Key technical details:
- Helpers moved from lib-reftable.{c,h} to unit-test.{c,h}
- Uses Clar assertions (cl_assert) instead of custom test framework
- Maintains same validation checks for block structure and stats
- Handles both ref and log records with index range tracking
- Preserves all existing test coverage while standardizing framework

This patch sets up the foundation for converting individual test files in subsequent patches. The helpers will be used by all reftable test files being converted to Clar. The implementation appears thorough and matches the style of other Clar-based test helpers in the codebase.
