This is a performance optimization patch for Git's diff machinery, specifically targeting the `--minimal` mode. It modifies xdiff's `cleanup_records` heuristic to skip marking lines as changed when they're surrounded by many changes, but only when `--minimal` is explicitly requested. The change produces shorter diffs in about 1.3% of cases while showing no measurable performance impact in benchmarks.

The patch follows up on previous discussion where reviewers suggested improvements to the implementation and requested performance measurements. The current version includes those measurements (showing no statistically significant runtime difference) and adds a new test case verifying that unchanged lines surrounded by changes don't appear in minimal diffs. The implementation now properly checks the `XDF_NEED_MINIMAL` flag as suggested in earlier feedback.

The change is narrowly scoped to only affect `--minimal` output where shortest-possible diffs are the expected behavior.
