This is patch 4/7 in Patrick Steinhardt's refactoring series that continues the object-file-cleanup effort. The patch focuses on reorganizing function declarations between header files to better align with where the functions are actually implemented.

The main change moves several loose object-related function declarations from object-store.h to object-file.h, where their implementations live. This includes functions like `odb_loose_cache()`, `for_each_loose_file_in_objdir()`, and related iteration callbacks. Similarly, packed object iteration functions are moved from object-store.h to packfile.h. The patch updates include statements in 12 files to reflect these header changes.

This is a mechanical change that continues the series' goal of cleaning up the object store interface by properly organizing declarations with their implementations. The patch doesn't introduce new functionality but improves code organization by:
1) Grouping loose object functions in object-file.h
2) Moving packed object iteration to packfile.h
3) Updating all callers to include the correct headers

The changes appear straightforward and well-contained, following the incremental approach established in earlier patches. Since this is part of a larger series that has already received positive feedback, and given the mechanical nature of these header changes, this patch seems unlikely to be controversial.
