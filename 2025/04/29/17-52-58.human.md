Test modernization converting reftable reader tests to Clar framework. This is patch 6/10 in a series migrating all reftable unit tests from custom test harnesses to the standard Clar framework.

The patch converts the reftable reader tests, which verify basic seeking behavior in reftable files. The original tests checked that:
- A reader can successfully seek to and read a single reference record
- The same reader can repeatedly seek and read the same record multiple times

The conversion maintains identical test coverage while switching from custom `check()` assertions to Clar's `cl_assert()` framework. The test cases now use the shared `cl_reftable_write_to_buf()` helper introduced earlier in the series. Build system files (Makefile and meson.build) are updated to track the new test location.

This continues the mechanical but thorough conversion work seen in previous patches of the series. The changes appear straightforward with no behavior modifications - just test infrastructure modernization. The patch follows the same pattern as earlier conversions in the series and seems ready for review.
