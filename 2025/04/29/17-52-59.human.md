This is part 7/10 of a test modernization series converting reftable unit tests to use the Clar framework. The patch converts the reftable readwrite test file, which verifies core read/write operations for reftable files.

The changes follow the same pattern as previous patches in the series - replacing the test framework's custom `check()` macros with Clar's `cl_assert()` assertions while maintaining all the same test coverage. The test file exercises various scenarios including buffer handling, log record compression, seek operations, index handling, and error cases for corrupted data.

The patch is mechanical in nature, part of the ongoing effort to standardize Git's test infrastructure. It removes the old test file (t-reftable-readwrite.c) and adds the new Clar-based version (u-reftable-readwrite.c), while making corresponding build system updates. The test coverage remains comprehensive, verifying both basic functionality and edge cases in the reftable read/write implementation.
