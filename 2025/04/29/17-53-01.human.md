This is a test modernization patch converting the reftable stack test to use the Clar framework. It's part of a 10-patch series (v2 09/10) to migrate all reftable unit tests from custom test harnesses to Clar.

The patch:
- Deletes the old `t-reftable-stack.c` test file (1451 lines)
- Creates a new `u-reftable-stack.c` using Clar assertions (1247 lines)
- Updates build files (Makefile and meson.build) to use the new test file
- Removes the old test file pattern check since this completes the migration

The test covers reftable stack functionality including:
- Basic stack operations (add, read, iterator)
- Transaction handling and concurrency
- Auto-compaction behavior
- Error cases and edge conditions
- File permissions and locking

The conversion maintains the same test coverage while standardizing on the Clar test framework used elsewhere in Git. This appears to be a mechanical conversion preserving all the test cases from the original, just adapting them to use Clar's assertion macros (cl_assert, cl_assert_equal_i, etc.).

This patch marks the completion of migrating all reftable tests to Clar, as noted in the commit message that there are "no longer any files matching that glob" of the old test pattern. The changes look thorough and well-contained to the test infrastructure modernization effort.
