This is the final patch in a 10-part series modernizing reftable tests by converting them to the Clar framework. The patch focuses on helper functions that were previously split between `lib-reftable.{c,h}` and `unit-test.{c,h}`.

The change consolidates three key test helper functions (`cl_reftable_set_hash`, `cl_reftable_strbuf_writer`, and `cl_reftable_write_to_buf`) back into `lib-reftable.{c,h}` while updating them to use Clar assertions. These helpers provide essential functionality for writing and validating reftable data during tests. The patch also cleans up the build system by removing now-unneeded dependencies and object files.

As the culmination of the series, this completes the migration of all reftable unit tests to Clar while maintaining the same test coverage. The changes are mechanical in nature - no reftable behavior is affected, only test infrastructure. The patch appears well-structured and follows the pattern established in previous conversions in the series.
