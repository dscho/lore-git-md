Test modernization converting reftable priority queue tests to Clar framework. This is patch 5/10 in a series migrating all reftable unit tests from custom test harnesses to the standard Clar framework.

The patch converts the priority queue (pq) tests, which cover three main scenarios: record-based comparison (verifying refname ordering), index-based comparison (testing queue ordering by index), and merged iterator queue behavior (checking top element properties). The conversion maintains all original test coverage while replacing custom assertions with Clar's `cl_assert` macros.

Build system files (Makefile and meson.build) are updated to track the new test location. The old test file (t-reftable-pq.c) is deleted in favor of the new Clar-based version (u-reftable-pq.c). The changes appear mechanical and well-contained, following the same pattern as earlier patches in the series that converted basics, block and merged tests.

This continues the systematic effort to standardize Git's test infrastructure, with no changes to actual reftable functionality - just test framework modernization. The patch looks straightforward and follows the established approach from previous conversions in the series.
