This is a transitional patch in the `git send-email` Outlook Message-ID handling series, showing the shift from a simple boolean toggle to a more flexible string-based control while maintaining backward compatibility. The v4 iteration introduces automatic detection for standard Outlook SMTP hosts (smtp.office365.com and smtp-mail.outlook.com) while preserving the boolean `--[no-]outlook-id-fix` CLI interface. Internally, it implements a string-based control ('auto') that coexists with the boolean options, allowing for future expansion.

The patch includes documentation improvements addressing Junio Hamano's earlier feedback about help text for automatic vs manual behavior cases. The documentation now clearly separates the default hostname-based detection behavior from the explicit override cases, resolving initial confusion around the "irrespective of SMTP server" phrasing from v3. The implementation maintains backward compatibility when the new option is unused.

Key technical changes include modifications to the `is_outlook()` helper to respect both automatic detection and manual overrides, plus a 15-line documentation addition explaining the Outlook-specific behavior and enterprise use cases. The patch shows the evolution toward what will become the final tri-state configuration in v7, with this version serving as the bridge between the initial boolean toggle and the eventual hostname-based solution that Junio Hamano will queue in v6.
