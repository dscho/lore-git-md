Refactoring patch continuing the object-file subsystem reorganization. This is patch 7/9 in Patrick Steinhardt's v2 series that systematically splits Git's object-file handling into logical subsystems.

The patch moves object store management functions from object.c to object-store.c, completing the separation of the object store subsystem. Key changes include:
- Moves `free_object_directory()` and related cleanup functions
- Relocates `raw_object_store_new()` and `raw_object_store_clear()`
- Updates header includes to reflect the new locations
- Maintains all existing functionality with no behavior changes

The changes follow the established pattern of the series - cleanly separating concerns while preserving all existing behavior. The object store subsystem now contains all core object storage management code, while object.c retains the higher-level object handling logic. This continues the architectural goal of clearly defined subsystem boundaries that has been developed through the series.

The patch is consistent with the careful, methodical approach seen in previous patches - each function is moved with its dependencies, header organization is updated appropriately, and the diff shows no functional changes beyond the relocation. This represents another incremental step in the larger refactoring effort to improve Git's internal organization.
