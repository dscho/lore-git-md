This is part 2 of Patrick Steinhardt's 9-part refactoring series reorganizing Git's object-file subsystem, which has now been merged. The series establishes clearer architectural boundaries between subsystems.

This specific patch moves the `git_open_cloexec()` function from object-file.c to compat/open.c. The function provides platform-agnostic file opening with O_CLOEXEC but wasn't actually object-file specific. The change makes the function available unconditionally (it was previously only compiled when OPEN_RETURNS_EINTR was defined) while keeping the retry logic conditional.

The patch updates 11 files - mostly removing now-unnecessary includes of object-file.h from various packfile-related files, and adding the function to compat/open.c with its build system integration. This is a straightforward code organization improvement that better reflects the function's actual role as a compatibility helper rather than object-file functionality.
