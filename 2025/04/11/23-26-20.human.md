Refactoring patch as part of a larger series on cruft pack/MIDX optimization.

This first patch in Taylor Blau's 8-part series standardizes how `pack-objects` handles incompatible command-line options. Rather than using custom error messages for each conflicting pair, it switches to the shared `die_for_incompatible_opt2()` function introduced in Git's i18n effort. The change affects several option pairs including `--stdin-packs`/`--filter` and `--keep-unreachable`/`--unpack-unreachable`.

The patch is straightforward mechanical work - replacing explicit error checks with standard function calls - and includes a corresponding test update. While small, it's a clean preparatory change for the more substantial pack optimization work that follows in the series. The commit message clearly explains both the what and why of the change, including the pre-existing commit it builds upon.
