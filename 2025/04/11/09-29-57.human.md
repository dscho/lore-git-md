This is part of Patrick Steinhardt's ongoing refactoring series to reorganize Git's object-file subsystem, specifically targeting the removal of global state. Patch 8/9 moves the global array of cached objects into the raw object store structure, continuing the effort to make the object database more library-friendly.

The patch focuses on "cached objects" - temporary objects that can be created without writing to disk (used by commands like `git blame` for fake commits). Previously these were stored in global variables; now they're properly scoped within the object store. The changes include:
- Adding cached object storage to `struct raw_object_store`
- Updating all related functions to take a repository parameter
- Moving the cached object lookup and management code
- Proper cleanup in `raw_object_store_clear()`

The implementation appears thorough, with careful attention to maintaining existing behavior while removing global state. The changes touch key areas like object lookup and the blame functionality, but the patch maintains all existing interfaces and behavior. This is another solid step in the series' goal of better code organization and reduced global state.
