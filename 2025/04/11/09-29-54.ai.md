This is part of Patrick Steinhardt's ongoing refactoring series to reorganize Git's object-file subsystem. Patch 5/9 in v2 focuses on disentangling the `HASH_*` flag system that was shared across multiple object-file functions.

The patch splits the previously shared flags into distinct sets for each function family:
- `hash_object_file()`/`write_object_file()` get new `WRITE_OBJECT_FILE_*` flags
- `index_fd()`/related functions get new `INDEX_*` flags
- The `HASH_*` namespace is repurposed specifically for `hash-object` operations

Key technical changes:
- Introduces three new flag enums with clear documentation
- Updates 9 files to use the new flag names
- Maintains all existing behavior while making the flag usage more explicit
- Particularly impacts bulk-checkin, cache-tree, and object-file operations

This continues the series' pattern of cleanly separating concerns while preserving functionality. The flag separation should make the code more maintainable by clarifying which flags apply to which operations. The patch appears thorough, touching all relevant call sites while keeping the changes focused on the flag namespace cleanup.
