This is the final patch in Taylor Blau's series optimizing cruft pack and MIDX interaction during repacking. The patch implements the key optimization promised by the series: excluding cruft packs from the MIDX when possible to reduce bloat and improve lookup performance.

The patch builds on the infrastructure from previous patches to detect when it's safe to exclude cruft packs from the MIDX. The key insight is that when doing geometric repacking with `--stdin-packs=follow` (introduced in patch 6/8), we can guarantee reachability closure without including cruft packs in the MIDX. This works because the follow mode ensures all reachable objects (including those that were previously in cruft packs) are copied into the new geometric packs.

The implementation adds logic to check if there are any existing cruft packs already in the MIDX (which would indicate we can't safely exclude them yet) and modifies the repack command to use `--stdin-packs=follow` when safe. The patch includes thorough tests verifying both the exclusion case (when starting fresh) and the inclusion case (when maintaining compatibility with existing MIDX).

This completes the series' goal of reducing MIDX bloat while maintaining correctness. The change is particularly impactful for repositories with many unreachable objects, as it prevents the MIDX from tracking objects that are rarely accessed. The series appears well-constructed, with each patch building logically toward this final optimization.
