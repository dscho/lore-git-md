This is a follow-up discussion in Patrick Steinhardt's object-file subsystem refactoring series, specifically about patch 1/9 which moves directory creation utilities from object-file.c to dir.c. Elijah Newren points out a minor inaccuracy in the commit message's description of the relationship between `safe_create_leading_directories()` and `mkdir_in_gitdir()`. While agreeing with the move itself, Newren suggests the commit message could more accurately describe these as separate utilities being relocated together rather than implying they are related functions. He provides specific wording suggestions but acknowledges this is a nitpick not worth a re-roll, especially since the rest of the v2 series looks solid. The exchange shows careful attention to commit message clarity while recognizing when perfectionism might not be practical for small issues in an otherwise well-executed series.
