This is a refactoring patch in Patrick Steinhardt's series reorganizing Git's object-file subsystem, specifically targeting the removal of global state for cached objects.

The patch moves the storage of cached objects (temporary objects that can be created without writing to disk, used by commands like `git blame`) from a global array to being stored within the `raw_object_store` structure. This continues the series' architectural goal of removing global state and properly scoping object store functionality. Key changes include:

1. Adds new fields to `raw_object_store` for cached object storage (`cached_objects`, `cached_object_nr`, `cached_object_alloc`)
2. Updates all cached object functions to take a repository parameter and operate on the repository's object store
3. Moves cleanup of cached objects into `raw_object_store_clear()`
4. Updates `blame.c` to pass the repository to `pretend_object_file()`

The patch maintains all existing functionality while better encapsulating the cached object system. This is a significant step in the series' goal of libification, as it removes one of the last remaining global variables in the object store subsystem. The changes are mechanical but thorough, updating all callers and maintaining the same behavior patterns.
