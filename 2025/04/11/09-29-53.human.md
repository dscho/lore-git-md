This is patch 4/9 in Patrick Steinhardt's refactoring series to reorganize Git's object-file subsystem. The patch moves functions related to the object store from object-file.c to a new object-store.c file, continuing the architectural cleanup from previous patches.

The change splits out core object store functionality like alternate ODB handling, object caching, and object existence checking into the new file. This better aligns with the header organization where object-store.h already declares these interfaces. The patch is purely a code movement - no behavior changes are introduced.

Key aspects:
- Creates new object-store.c with 972 lines moved from object-file.c
- Updates includes in 20 files to account for the new split
- Maintains all existing functionality exactly as before
- Follows the same pattern as earlier patches in the series for directory utilities and mmap functions

The change continues the series' goal of clearer subsystem boundaries, with object operations now properly isolated in object-store.c while object-file.c retains file-level operations. The patch appears well-executed with thorough updates to all callers and build systems.
