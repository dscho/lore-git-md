This is the first patch in Patrick Steinhardt's 9-part refactoring series that was later merged, moving directory-related utilities out of object-file.c. The patch relocates `safe_create_leading_directories()` and related functions from object-file.c to dir.c, where they better belong since they provide generic directory functionality rather than object-specific operations.

The changes include:
- Moving the implementation of `safe_create_leading_directories()` and its variants (`_no_share`, `_const`) plus `mkdir_in_gitdir()`
- Adding declarations to dir.h while removing them from object-file.h
- Updating 13 files to include dir.h instead of object-file.h for these utilities
- The implementation remains functionally identical, just in a more appropriate location

The patch is part of a larger architectural effort to better organize Git's code by establishing clear subsystem boundaries, with object-file.c focusing specifically on object storage operations. This first step cleanly separates the directory utilities that were previously mixed in with object handling code. The thread context shows this series was successfully merged after review, with all architectural goals achieved.
