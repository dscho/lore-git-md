This is a cover letter for a refactoring series that has already been merged. The 9-patch series by Patrick Steinhardt reorganizes Git's object-file subsystem by splitting functionality into more logical groupings. The work has been completed and integrated into the main branch by Junio Hamano, with all architectural goals achieved.

The refactoring moves various functions from the catch-all object-file.c to more appropriate homes: directory utilities to dir.c, mmap helpers to wrapper.c, platform-specific code to compat/open.c, index-related functions to read-cache.c, and object store management to a new object-store.c. This creates clearer subsystem boundaries and reduces global state, laying groundwork for future pluggable object database work.

Key technical changes include:
- Establishing object-store.c as the new home for higher-level object directory management
- Moving 150+ functions across 124 files with 2296 insertions and 2224 deletions
- Consolidating header files (object-store-ll.h into object-store.h)
- Removing the global array of cached objects
- Better organizing HASH_* flag enums

The v2 series included only grammatical fixes to commit messages from v1. The work has been thoroughly reviewed, with Elijah Newren's feedback incorporated, and represents a significant architectural improvement in Git's object storage code organization. The thread is now fully resolved with all changes merged.
