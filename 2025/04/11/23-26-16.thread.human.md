This thread discusses Taylor Blau's v3 patch series (9 parts) optimizing MIDX and cruft pack interactions during repacking. The core feature is a new `repack.midxMustContainCruft` config option that controls whether cruft packs must be included in MIDX files, with performance benefits when set to false. The series is nearly ready for merging, with all technical components implemented and comprehensive test coverage.

The latest patch (5/9) improves delta compression for loose objects when using `--unpacked` with `--stdin-packs`. By passing the `rev_info` struct to `add_loose_object()`, it enables name-hash traversal for better delta selection - a clever optimization Junio Hamano praised as surprisingly small yet effective. The change maintains backward compatibility, only activating the optimization during regular pack operations.

The series has received thorough review from Elijah Newren, who suggested documentation improvements and caught minor whitespace issues. Junio has approved key refactoring patches and confirmed the approach. Only minor style nits remain before merging. This work connects to Taylor's broader efforts around MIDX, cruft packs, and geometric repacking, offering more flexible pack maintenance strategies while maintaining reachability guarantees.
