This is the final patch in Patrick Steinhardt's v2 series reorganizing Git's object-file subsystem. The patch completes the architectural cleanup by merging the "object-store-ll.h" header into "object-store.h" now that all low-level object store functionality has been properly organized.

The key changes are:
1. Moves the remaining `odb_path_map` definition from object-store-ll.h to object-store.c
2. Deletes object-store-ll.h entirely
3. Updates 124 files to include object-store.h instead of object-store-ll.h
4. Adds necessary includes (dir.h and khash.h) to object-store.c that were previously in object-store-ll.h

This change follows the completion of moving all object store functionality to proper subsystems in earlier patches. The series has systematically eliminated global state and established clear boundaries between object operations, index operations, and utility functions. This final step removes the transitional header that was introduced to manage compile-time dependencies during the refactoring.

The patch maintains all existing functionality while finalizing the new architectural organization. It represents the culmination of a significant codebase reorganization that improves modularity and reduces global state in Git's object handling code.
