Refactoring patch in a series optimizing cruft packs and MIDX interaction.

This is the third patch in Taylor Blau's series to improve how cruft packs interact with multi-pack indexes during repacking. The change is purely mechanical - it extracts the inline handling of `--stdin-packs` into a separate function `read_stdin_packs()`. 

The commit message explains this prepares for future expansion of the stdin-packs handling logic, which currently dates back to its 2021 introduction. The diff shows a straightforward extraction of the existing code into a new function while maintaining all the same behavior - it still handles excluded packs and optionally adds loose objects when `rev_list_unpacked` is set.

This continues the series' pattern of preparatory refactoring before introducing new functionality. Like the first two patches, this is low-risk cleanup that makes the code more maintainable for the more substantial changes coming later in the series. The patch touches only `builtin/pack-objects.c` with no test changes needed since it's purely a code organization improvement.
