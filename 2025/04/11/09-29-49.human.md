This is a refactoring patch series that reorganizes Git's object-file subsystem to better separate concerns. Patrick Steinhardt's 9-part series splits up the monolithic `object-file.c` into more focused components, moving functions to their logical homes:

- Directory utilities like `safe_create_leading_directories()` go to `dir.c`
- Low-level I/O functions like `xmmap()` move to `wrapper.c`
- Platform-specific code like `git_open_cloexec()` lands in `compat/open.c`
- Index-related functions relocate to `read-cache.c`
- The core object store logic moves to a new `object-store.c`

The changes are purely organizational - no behavior is altered. The series builds on prior work to remove `the_repository` global and lays groundwork for future pluggable object storage. Version 2 includes minor commit message fixes from the initial submission.

The extensive diffstat (145 files touched) reflects the wide impact of these structural changes, though most modifications are straightforward relocations. The patch appears well-considered, with functions grouped by subsystem responsibility rather than historical accident. This cleanup should make the codebase more navigable and maintainable going forward.
