Refactoring patch in Patrick Steinhardt's object-file subsystem reorganization series. This is patch 7/9 in v2, continuing the effort to establish clear subsystem boundaries by moving object store management functions from object.c to object-store.c.

The patch relocates several key functions that handle object store lifecycle management:
- `free_object_directory()` for cleaning up individual object directories
- `raw_object_store_new()` for initialization
- `raw_object_store_clear()` for cleanup of the entire store
- Supporting helper `free_object_directories()`

The changes are purely organizational - 66 lines moved to object-store.c and 67 removed from object.c, with no behavioral modifications. The functions maintain all existing functionality including alternate ODB handling, commit-graph management, and packed-git cleanup.

This continues the series' pattern of methodically separating concerns while preserving behavior, with object-store.c becoming the clear home for object storage management. The patch appears well-contained and follows the architectural direction established in earlier patches.
