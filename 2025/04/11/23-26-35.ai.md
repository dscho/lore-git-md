This is the sixth patch in Taylor Blau's series optimizing cruft pack and MIDX interactions during repacking. It introduces a new `--stdin-packs=follow` mode for `git pack-objects` that creates reachability-closed packs by including objects from unspecified packs when they are reachable from included packs.

The key technical changes:
- Adds a new `STDIN_PACKS_MODE_FOLLOW` enum value and modifies the pack-objects callback functions (`show_object_pack_hint` and `show_commit_pack_hint`) to include reachable objects from unspecified packs when in this mode
- Extends the `--stdin-packs` option to accept an optional `follow` mode parameter via a new `parse_stdin_packs_mode` callback
- Updates documentation to explain the new mode's behavior of "resurrecting" objects from cruft/unspecified packs to maintain reachability closure
- Adds comprehensive tests in `t5331-pack-objects-stdin.sh` verifying the new mode works with both packed and loose objects, including edge cases with excluded packs

The patch builds on the preparatory refactoring from earlier in the series (particularly the `rev_info` handling changes in patch 4/8) to enable the core optimization. This is the first patch that actually changes pack-objects' behavior rather than just refactoring, representing a key step toward the series' goal of allowing cruft pack exclusion from MIDX while maintaining correctness.

The implementation appears thorough with good test coverage, though reviewers will likely want to scrutinize the reachability closure logic and its interaction with other pack optimizations. The changes are focused in `builtin/pack-objects.c` with corresponding documentation and test updates.
