Bug report about `git stash -k` behavior with staged changes. The reporter demonstrates a workflow where editing a file, staging it, then editing the same line again and running `git stash -k` incorrectly creates a stash diff between HEAD and unstaged changes rather than between staged and unstaged changes. This causes unnecessary merge conflicts when popping the stash later. The bug affects Git 2.39.5 on macOS (arm64) but is likely platform-independent. The report includes clear reproduction steps and system information, indicating a legitimate edge case in stash's index handling that violates user expectations about preserving staged/unstaged relationships.
