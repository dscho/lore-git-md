This is the seventh patch in Taylor Blau's series optimizing cruft pack and MIDX interaction during repacking. The patch adds infrastructure to track which packs are currently referenced by the MIDX, which will be used in the next patch to conditionally generate packs during geometric repacking.

The change introduces a new `PACK_IN_MIDX` flag bit and helper function `pack_mark_in_midx()` to mark pack files that appear in the MIDX. This information is collected during the existing pack filename collection phase in `collect_pack_filenames()`. The patch maintains the series' careful approach of building up infrastructure before using it, with clear mechanical changes that are easy to review.

As part of the series' progression from refactoring to feature implementation, this patch provides the necessary plumbing for the final piece that will actually use this MIDX tracking. The implementation looks straightforward and maintains the series' high standard of careful, incremental changes with clear purpose.
