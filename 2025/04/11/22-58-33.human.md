This is Junio Hamano's monthly "What's cooking in git.git" status report, providing updates on the current state of various Git development topics. The report covers both new topics that have recently been merged into the integration branches and ongoing work that's still being refined.

Several notable changes are highlighted in this report:

1. **Performance improvements**: The `kn/bundle-dedup-optim` series fixes non-linear performance scaling when creating bundles with many references, which should significantly speed up bundle operations for repositories with extensive histories.

2. **Build system enhancements**: The `kn/meson-hdr-check` topic adds support for header checking in Meson builds, bringing feature parity with the Makefile build system. Meanwhile, `rj/build-tweaks` introduces various platform-specific build optimizations.

3. **Code cleanup efforts**: Multiple refactoring efforts are progressing, including `ps/object-file-cleanup` (10 commits reorganizing object file handling) and `ab/environment-clean-header` removing unused variables. The `en/merge-recursive-debug` series completes the removal of the old recursive merge strategy backend.

4. **New features**: `ps/cat-file-filter-batch` adds object filtering capabilities to `git cat-file --batch`, similar to transport layer filtering. `kn/non-transactional-batch-updates` introduces a new best-effort batch update mode for references.

5. **Test improvements**: The substantial `ps/test-wo-perl-prereq` series (20 commits) removes Perl as a hard dependency for running tests, making the test suite more portable.

The report also notes several documentation updates, bug fixes, and platform-specific improvements. Many of these changes are already in 'next' (the staging area for the next release), while others are still in 'seen' (the experimental branch) awaiting further review.

This update reflects active development across multiple areas of Git, with particular focus on performance, code quality, and build system modernization. The breadth of changes suggests an upcoming release may include significant improvements across many components.
