The change removes the transitional "object-store-ll.h" header that was introduced earlier in the series to manage header dependencies during the refactoring. With the object store subsystem now properly organized into "object-store.c" and "object-store.h", the low-level header is no longer needed. The patch updates 124 files to use the unified header instead.

This is a mechanical change that doesn't modify any behavior - it simply completes the header reorganization that was carefully built up through the previous 8 patches in the series. The series as a whole has systematically eliminated global state from the object store subsystem while maintaining all existing functionality.

The patch follows the established pattern of the series, making a focused change with a clear rationale.
