This is the fourth patch in Taylor Blau's series optimizing cruft pack and MIDX interactions during repacking, focusing on refactoring the pack-objects code.

The patch moves the initialization and execution of the reachability traversal (using `rev_info`) out of `read_packs_list_from_stdin()` and into its caller `read_stdin_packs()`. This prepares for future changes where the same traversal logic will be needed for both the `--stdin-packs` and `--unpacked` cases. The key changes are:
- `read_packs_list_from_stdin()` now takes a `rev_info` parameter instead of declaring its own
- The traversal setup and execution moves to `read_stdin_packs()`
- All related state (like `ignore_packed_keep_in_core`) is consolidated in the caller

The change is mechanical and maintains existing behavior while making the code more flexible for the planned `--stdin-packs=follow` functionality mentioned in the series. The patch continues the series' pattern of careful preparatory refactoring before introducing new features, touching the same files (`builtin/pack-objects.c`) as previous patches. The commit message clearly explains the motivation and connects to the series' larger goals of optimizing pack maintenance.
