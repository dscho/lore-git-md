This is a build system patch in the ongoing Makefile/meson alignment series, specifically addressing help format defaults on Windows.

Patch 4/13 in the series makes two related changes to how Git's help format is handled in the meson build system. First, it removes the unconditional `-DDEFAULT_HELP_FORMAT` compiler flag, since the code already defaults to 'man' format. The flag will now only be added when a non-default format is requested. Second, it adds special handling for Windows builds by introducing a new 'platform' option that automatically selects 'html' as the default help format on Windows (matching the behavior in the Makefile build) while keeping 'man' as the default elsewhere.

The change is cleanly implemented with a new platform-detection check in meson.build and a corresponding update to the meson_options.txt configuration. This continues the series' theme of aligning meson behavior with the traditional Makefile build while removing unnecessary compiler flags. The patch appears straightforward and well-contained, with no obvious issues in the implementation.
