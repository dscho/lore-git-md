Platform compatibility patch in the build system alignment series (4/13), focusing on help format defaults between Makefile and meson builds on Windows platforms.

This patch adjusts how the meson build system handles the help format default (`DEFAULT_HELP_FORMAT`), bringing it closer to the Makefile behavior where Windows builds default to HTML output rather than man pages. The key changes are:
1. Removes the unconditional `-DDEFAULT_HELP_FORMAT` define from compiler flags
2. Introduces a new 'platform' option value that automatically selects 'html' on Windows and 'man' elsewhere
3. Only adds the define when explicitly overriding the default

The implementation uses meson's `host_machine.system()` detection, though Ramsay notes this has limitations - it broadly classifies Cygwin/MSYS2 as 'cygwin' and native Windows as 'windows', without distinguishing between MinGW variants. The Makefile build handles these cases more granularly by explicitly listing MINGW{32,64} in `config.mak.uname`.

The patch maintains Patrick Steinhardt's earlier decision to exclude the 'info' format option that exists in the Makefile build, and notes the 'pdf' target exists in Makefile but isn't relevant here. The changes are part of the broader effort to align meson behavior with the Makefile system while accounting for platform-specific differences.
