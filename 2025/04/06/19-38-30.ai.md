This is a build system patch (part 4/13 in a series) aligning meson behavior with Makefile defaults for help format on Windows. The change makes the meson build system match the Makefile's behavior of defaulting to HTML help format on Windows (rather than man pages), while avoiding unnecessary compiler defines when using the default (man) format. The implementation adds a new 'platform' option value that automatically selects 'html' on Windows and 'man' elsewhere, only emitting the -DDEFAULT_HELP_FORMAT compiler flag when the format differs from the standard man page default.

Key technical details: The patch modifies meson.build to conditionally add DEFAULT_HELP_FORMAT to libgit_c_args only when not using the default 'man' format, and introduces a platform-specific default via host_machine.system() detection. The meson_options.txt change adds the 'platform' choice and makes it the new default value. This continues the series' theme of build system alignment while reducing unnecessary compiler flags. The change is straightforward and maintains consistency with existing Windows behavior from the Makefile build.
