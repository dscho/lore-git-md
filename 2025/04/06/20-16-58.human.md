Build system alignment patch focusing on Windows help format defaults. This is part of the larger series working to make meson builds behave consistently with Makefile builds across platforms.

Ramsay Jones points out that while the Makefile build overrides Git's help format to HTML on Windows (including MinGW), the meson build currently doesn't make this platform distinction. The patch adds logic to set HTML as the default help format specifically for Windows builds when using meson, matching Makefile behavior.

The implementation introduces a new 'platform' option value that automatically selects the appropriate format (HTML for Windows, man pages for others) based on host system detection. The patch also removes an unnecessary compiler define when using the default man page format.

Jones notes some platform detection nuances: meson's system() method groups Cygwin/MSYS2 separately from Windows, unlike the Makefile which includes MinGW in its Windows handling. He also observes that meson's platform detection can't distinguish between different Windows-like environments (Cygwin vs MSYS2 vs MinGW) as precisely as direct uname checks could.

This appears to be a straightforward alignment change, though the platform detection differences between build systems may warrant further discussion about whether the behavior should be identical or if the meson approach represents an improvement. The patch maintains the earlier decision to drop the 'info' format option that exists in Makefiles.
