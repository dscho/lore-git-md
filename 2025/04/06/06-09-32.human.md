This is a GSOC 2025 project proposal for a new Git command to handle repository information queries, currently named `git info`. The proposal comes from Jayatheerth K, building on previous discussions with mentors Karthik Nayak and Patrick Steinhardt about migrating repository query options from `git rev-parse` to a dedicated command.

The proposal outlines a well-structured plan to create a new `builtin/info.c` that would organize rev-parse's repository/path query options (like `--show-toplevel`, `--git-dir`, `--is-bare-repository`) into logical subcommands (`path`, `repo`, `misc`). The implementation would maintain text output compatibility with rev-parse while adding structured output options (NUL-terminated and JSON formats). The 12-week timeline shows careful planning with incremental delivery in four functional batches, each including tests and documentation updates.

Jayatheerth demonstrates strong engagement with the community through their microproject contributions and responsiveness to mentor feedback. The proposal thoughtfully addresses the project's benefits (cleaner command structure, better scripting interface) while acknowledging remaining design questions about final naming and command structure. The phased approach and clear deliverables make this a compelling GSOC application that would meaningfully improve Git's command architecture.
