Build system refactoring to clean up conditional compilation flags. This is part 2 of a 13-patch series aligning Makefile and meson build systems, with a focus on Cygwin compatibility.

The patch makes several build variables conditional on `RUNTIME_PREFIX` being defined, since they only have meaning in that context. The affected variables relate to platform-specific executable path detection methods (`HAVE_BSD_KERN_PROC_SYSCTL`, `PROCFS_EXECUTABLE_PATH`, etc.) and were previously set unconditionally. The change groups these related flags together under a single `RUNTIME_PREFIX` conditional block in the Makefile.

The modification is straightforward and appears well-justified - these flags are indeed only relevant when runtime prefix support is enabled. The patch follows the series' theme of reducing unnecessary build system differences while maintaining functionality. The change is mechanical but improves Makefile organization by making the conditional nature of these flags more explicit.
