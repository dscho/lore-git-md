Bugfix for Cygwin compatibility in the build system alignment series. This patch corrects RAM calculation in `builtin/gc.c` when using `sysinfo()` by properly accounting for the `mem_unit` field, which specifies the byte multiple for memory size reporting.

The change addresses a discrepancy between Linux and Cygwin implementations of `sysinfo()`. While Linux typically reports sizes in bytes (with `mem_unit=1`), Cygwin uses 4096-byte units. The existing code assumed byte units, which would lead to significantly underestimated memory values on Cygwin systems. The patch demonstrates this with test output showing an 8GB system reporting 2074637 units that need to be scaled by 4096.

This is part of Ramsay Jones's larger series (now at v2 with 13 patches) improving build system consistency across platforms. The fix is straightforward - multiplying `totalram` by `mem_unit` when the latter exceeds 1 - and comes with clear justification from both Linux man pages and empirical testing. The change maintains backward compatibility with Linux while fixing Cygwin support, aligning with the series' goal of platform-agnostic behavior.
