This is a GSOC 2025 project proposal for a new Git command to handle repository information queries, currently named `git info` (The naming is still under discussion, having evolved from earlier suggestions of `git metadata` and `git repo-info`). The proposal comes from Jayatheerth K, who has already engaged with the Git community through a documentation microproject.

The core idea is to extract repository/state query options from `git rev-parse` (like `--show-toplevel`, `--git-dir`, `--is-bare-repository`) into a dedicated command with a subcommand structure (`info path`, `info repo`, `info misc`). The implementation would maintain text output compatibility with rev-parse while adding structured output options (NUL-terminated and JSON formats. The proposal shows thoughtful consideration of technical details like using Git's existing parse-options infrastructure, careful output format handling, and incremental documentation/test updates. The 12-week implementation plan is well-structured in functional batches, showing awareness of Git's patch submission process. Key open questions remain about the final command name and exact subcommand structure, with active discussion ongoing between Jayatheerth and mentors Karthik Nayak and Patrick Steinhardt. The proposal demonstrates strong technical understanding through its analysis of rev-parse.c internals and clear articulation of implementation strategies.
