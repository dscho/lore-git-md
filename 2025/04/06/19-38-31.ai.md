Build system cleanup removing obsolete NEEDS_LIBRT variable. This patch from Ramsay Jones eliminates a legacy build flag that was previously required for linking with librt to access clock_gettime() on older Linux systems (specifically glibc versions before 2.17). The commit message provides detailed historical context, noting that Debian 7 (the last major distribution needing this) reached end-of-life in 2018, and current distributions all use newer glibc versions where clock_gettime() is available directly in libc.

The change removes both the Makefile documentation of NEEDS_LIBRT and its actual usage in the build system (where it added -lrt to EXTLIBS), plus its Linux-specific setting in config.mak.uname. This is a straightforward cleanup that aligns with the series' goal of modernizing and simplifying the build system. The patch appears well-researched with clear justification for the commit timing, including a table showing support timelines for relevant distributions. As a pure removal of obsolete code with no behavior change on modern systems, this should be uncontroversial.
