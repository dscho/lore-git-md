Build system cleanup removing obsolete Linux compatibility code. This patch (5/13 in the series) eliminates the NEEDS_LIBRT build variable, which was originally added in 2016 to handle linking with librt for clock_gettime() on older Linux systems with glibc < 2.17. The change is well-justified with a detailed commit message showing that all major Linux distributions have long since moved to glibc versions where this workaround is unnecessary, including specific EOL dates for affected systems (the last being Debian 7 which ended support in 2018).

The patch simply removes the variable definition from both the Makefile documentation and the Linux-specific config.mak.uname section, along with its associated EXTLIBS += -lrt line. This is a straightforward cleanup that aligns with the series' goal of modernizing and simplifying the build system. The change appears uncontroversial and low-risk, as it only affects very old Linux systems that are no longer supported.
