Build system alignment patch focusing on meson build configuration cleanup. This is patch 3/13 in the ongoing series to standardize Makefile and meson builds.

The change makes meson.build only set DEFAULT_EDITOR and DEFAULT_PAGER preprocessor defines when they differ from the hardcoded defaults ('vi' and 'less' respectively). This avoids unnecessary command-line defines when using standard values, matching how the source code already handles these defaults. The patch also updates the documentation build logic to similarly only pass these values to asciidoc/asciidoctor when they differ from defaults, preventing awkward conditional text for standard configurations.

The changes touch both the main meson.build file (removing unconditional defines) and Documentation/meson.build (adding conditional attribute passing). This continues the series' theme of reducing build system differences while maintaining functionality, though this particular change is more about build cleanliness than cross-platform compatibility. The implementation is straightforward and maintains the existing behavior while removing redundant defines.
