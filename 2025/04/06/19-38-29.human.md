Build system refinement in the ongoing Makefile/meson alignment series. This patch (3/13 in v2) optimizes how default editor and pager settings are handled in the meson build system.

The change makes the redundant passing of default values ('vi' for editor and 'less' for pager) to the compiler when they match Git's built-in defaults. These defines are now only added to compiler flags when explicitly set to non-default values. The patch also updates the documentation build to similarly conditionally include these values in asciidoc attributes.

This is a clean, logical optimization that reduces unnecessary build system noise while maintaining all functionality. The change affects both the main build (`libgit_c_args`) and documentation generation (`asciidoc_common_options`), showing good attention to detail in handling both code and docs consistently. The patch fits well with the series' goal of streamlining build system differences between Makefile and meson.
