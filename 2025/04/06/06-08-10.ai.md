This is a GSoC 2025 proposal (v2) for consolidating ref-related functionality into `git-refs`, building on previous technical discussions with mentors Patrick Steinhardt and Karthik Nayak. Zheng Yuting presents an updated implementation plan that maintains the core architecture decisions from prior reviews while adding concrete timelines and testing/documentation strategies.

The proposal outlines three initial subcommands: `show` (replacing `git-show-ref --verify`), `list` (merging `git-show-ref` and `git-for-each-ref` functionality), and `update` (replacing `git-update-ref`). The `list` subcommand will use `<oid> <ref>` format by default and incorporate extensive filtering/sorting/formatting options from both legacy commands, with some legacy format options (`--tcl`, `--shell`, `--perl`) still under discussion. A detailed 4-month timeline breaks down implementation phases, with `show` targeted first (May 18-June 7), followed by `list` (June 8-July 3) and `update` (July 4-August 4).

Testing will focus on output consistency with legacy commands while adding new tests for integrated functionality. Documentation will explicitly map new options to their legacy equivalents.
