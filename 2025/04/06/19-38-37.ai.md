Platform compatibility patch in the build system alignment series, specifically enabling `sysinfo()` support for Cygwin.

This patch makes three coordinated changes to properly support Cygwin's implementation of the `sysinfo()` system call, which was previously treated as Linux-only. The changes: (1) move the `HAVE_SYSINFO` definition from a direct `-D` flag to a config variable in `config.mak.uname`, (2) add Cygwin to the platforms that set this variable, and (3) add an autoconf test for `sysinfo()` availability. The Makefile change ensures the flag gets added to `BASIC_CFLAGS` when detected.

This is part of the larger effort to align build system behavior across platforms, with particular attention to Cygwin compatibility. The patch follows the series' pattern of moving platform-specific detection into config variables rather than hardcoding assumptions. The autoconf addition provides a more robust detection mechanism that could benefit other platforms in the future. The changes are minimal and focused, with the Linux behavior remaining functionally equivalent while properly extending support to Cygwin.
