Build system alignment patch removing an unnecessary compiler flag. This is the first of 13 patches in v2 of a series focused on making the Makefile and meson build systems more consistent.

The patch removes `-DCURL_DISABLE_TYPECHECK` from the meson build configuration. This flag was originally added to suppress sparse warnings about curl's type checking headers, but since meson doesn't support sparse builds, the flag serves no purpose there. The change helps align the meson build with the Makefile behavior where this flag is only used for sparse builds.

The change is straightforward and well-justified in the commit message, explaining both the original purpose of the flag and why it's not needed in meson. As part of a larger build system cleanup effort, this appears to be a low-risk change that removes dead configuration while maintaining the intended behavior.
