Platform compatibility patch in the build system alignment series (v2 9/13), adding `clock_gettime()` support for Cygwin builds.

This patch brings the Makefile build configuration in line with what autoconf and meson already support for Cygwin. It adds two build variables to `config.mak.uname`: `HAVE_CLOCK_GETTIME` and `HAVE_CLOCK_MONOTONIC`, confirming that these time-related functions are available on Cygwin platforms. The change is straightforward and consistent with the series' goal of aligning build system behavior across different configuration methods.

The patch follows a similar pattern to patch 8/13 in the series (which added `HAVE_GETDELIM` for Cygwin), further standardizing the platform's feature detection. As with other changes in this series, this appears to be a well-justified alignment change that matches actual platform capabilities rather than introducing new functionality. The commit message clearly states the motivation and maintains the series' focus on build system consistency.
