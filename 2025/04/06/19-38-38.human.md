Platform compatibility patch enabling arc4random for Cygwin builds. This is part of a larger series (now at v2) aligning build system behavior across platforms.

The patch adds Cygwin support for `arc4random_buf()`, a cryptographically secure random number generator that has been available in Cygwin since 2016. It does this by setting the `CSPRNG_METHOD` build variable to 'arc4random' in Cygwin's section of `config.mak.uname`. The change follows the series' pattern of moving platform-specific configuration into build variables.

The commit notes this is already handled in autoconf and meson builds, making this change consistent across build systems. The implementation is straightforward - just a one-line addition to the Cygwin configuration block.

This appears to be a well-justified, minimal change that brings Cygwin's random number generation up to modern standards while maintaining consistency with how other platforms are handled in the build system. As patch 12/13 in the series, it fits cleanly with the broader platform compatibility work.
