This is the second patch in a 3-part series restructuring Git's build system to better support future Rust integration. The change removes the separate `XDIFF_LIB` static library and instead compiles xdiff objects directly into `libgit.a`. This matches how meson already builds Git and avoids potential naming conflicts when adding a future 'xdiff' Rust crate. The patch makes mechanical Makefile updates to remove xdiff-specific build rules while preserving all functionality. 

The changes are straightforward: xdiff object files are now included in `LIB_OBJS` rather than being built into a separate library, and all references to `XDIFF_LIB` are removed from the Makefile. The commit message notes this is part of the larger goal to have Rust only need to link against `libgit.a` rather than multiple static libraries. 

This continues the series' clean separation of build system restructuring from actual Rust integration work. The patch appears well-scoped and maintains compatibility with existing builds while preparing for future changes. The meson build system requires no modifications since it already handles xdiff compilation this way.
