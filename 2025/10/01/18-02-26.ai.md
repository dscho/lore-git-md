Build system refactoring preparing for Rust integration.

This is the first of three patches restructuring Git's static library build process to better support future Rust integration. The change moves the definitions of `XDIFF_OBJS` and `REFTABLE_OBJS` earlier in the Makefile, before the `GITLIBS` definition. This is a mechanical change that doesn't alter functionality, but enables subsequent patches to add these objects to `LIB_OBJS` while maintaining correct build order dependencies. The patch performs a straightforward relocation of the xdiff and reftable object file definitions, keeping all their contents identical but positioning them earlier in the Makefile. The commit message notes this should be viewed with `--color-moved` to clearly see it's a pure relocation. This change is part of a larger effort to consolidate xdiff and reftable functionality directly into libgit.a rather than maintaining them as separate libraries, matching how meson already builds these components. The change is cleanly implemented and well-explained, serving as groundwork for future Rust integration without yet introducing any Rust-specific changes.
