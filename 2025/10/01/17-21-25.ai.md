Rust infrastructure implementation (varint subsystem). This is patch 6/9 in the v7 series introducing Rust support to Git core, focusing on the varint implementation as a test balloon. The patch adds `src/varint.rs` containing FFI-compatible Rust versions of `decode_varint()` and `encode_varint()` that exactly match the C implementation's behavior, including overflow handling. The code uses unsafe blocks for pointer operations but employs Rust's wrapping arithmetic for safety. Build system changes conditionally include either the C or Rust version based on `WITH_RUST` configuration. The implementation includes comprehensive tests verifying identical behavior to the C version across normal and edge cases (including overflow conditions). This serves as the first concrete demonstration of mixed C/Rust compilation in Git core, with the varint subsystem chosen for its isolation and testability. The patch follows the series' standardization of using explicit `u64`/`uint64_t` types for varint handling.
