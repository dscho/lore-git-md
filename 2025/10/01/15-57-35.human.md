This is a refactoring patch in Patrick Steinhardt's ongoing `git-history` command series (v4, patch 9/12). It continues the work of separating the interactive add/patch infrastructure, specifically removing the dependency of `add-patch.c` on the `add-interactive` subsystem.

The patch eliminates the use of `init_add_i_state()` in favor of directly initializing the interactive configuration within `struct add_p_state`. This involves:
- Replacing `struct add_i_state` with direct storage of `struct repository` and `struct interactive_config`
- Updating all references to use the new structure
- Maintaining the same functionality while simplifying the code organization

The changes are mechanical but thorough, touching color handling, diff configuration, and repository operations throughout the file. The patch appears well-executed, with careful attention to maintaining existing behavior while cleaning up the architecture. It's part of the broader effort to prepare the codebase for new history editing functionality while improving maintainability.
