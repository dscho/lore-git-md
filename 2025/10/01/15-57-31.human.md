This is the fifth patch in a 12-part series introducing a new `git history` command for more intuitive history editing operations. The patch adds the basic scaffolding for the new command, including:

1. The command implementation in `builtin/history.c` with a simple skeleton that currently just handles argument parsing
2. Documentation in `git-history.adoc` explaining the command's purpose and experimental nature
3. Build system integration across Makefile, meson.build, and command-list.txt
4. A basic test script verifying argument handling

The documentation positions this as an experimental alternative to `git rebase` for common history editing tasks like reordering, splitting, or dropping commits. The implementation currently does nothing functional - subsequent patches will add the actual `reword` and `split` subcommands that form the core of this effort.

This appears to be well-structured foundational work, with all the standard components (documentation, tests, build integration) properly included from the start. The patch follows Git's established patterns for adding new commands and sets up cleanly for the functionality to come in later patches.
