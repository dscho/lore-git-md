This is a refactoring patch in Patrick Steinhardt's `git-history` series (v4 08/12). It reorganizes the interactive add/patch infrastructure to better separate concerns between the interactive add (`-i`) and patch (`-p`) subsystems.

The patch introduces a new `struct interactive_options` to hold common configuration that was previously managed through `struct add_p_opt`. It also creates `struct interactive_config` to centralize color and diff settings that were previously duplicated in `struct add_i_state`. The changes affect multiple commands that use this infrastructure (`add`, `checkout`, `commit`, `reset`, `stash`).

Key technical changes:
- Moves color initialization and diff configuration into new `interactive_config_init()` function
- Splits out declarations from `add-interactive.h` to new `add-patch.h`
- Updates all callers to use the new `interactive_options` struct instead of `add_p_opt`
- Maintains backward compatibility through the transition (some entanglement remains to be fixed in later patches)

The refactoring appears thorough and mechanically sound, with extensive changes across multiple files. It's part of the larger effort to build shared infrastructure for history editing commands while cleaning up technical debt in the interactive add/patch code. The patch follows the established pattern of the series by making incremental improvements while maintaining existing functionality.
