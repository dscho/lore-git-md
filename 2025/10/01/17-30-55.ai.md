This is a documentation patch in an ongoing thread about improving Git's documentation of upstream branch behavior. Jean-Noël Avila provides review feedback on Julia Evans' patch that adds a new "UPSTREAM BRANCHES" section to consolidate scattered information about branch tracking.

The review focuses on two formatting issues in the AsciiDoc markup: (1) suggests moving the `[[UPSTREAM-BRANCHES]]` anchor to a line above the section header rather than inline, which improves readability and translation safety, and (2) recommends using dedicated fence markers (`----`) for the config block example rather than indentation with tabs, which could cause maintenance issues. Both suggestions are purely about documentation presentation, not the technical content.

The patch being reviewed is part of Julia Evans' v4 series that comprehensively documents upstream branch behavior, including automatic setup mechanisms and how various commands use upstream information. This particular patch centralizes previously scattered information about upstream branches into a dedicated section in `urls-remotes.adoc`, covering both manual configuration and automatic setup cases. The review maintains the thread's focus on improving documentation clarity while adhering to Git's documentation standards.
