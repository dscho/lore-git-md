This is the final patch in a build-system refactoring series preparing for potential Rust integration. It follows the same pattern as the previous patch (which handled XDIFF_LIB) by removing the separate REFTABLE_LIB static library and folding its objects directly into LIB_OBJS. The change makes the Makefile behavior match meson's existing approach and simplifies future Rust integration by reducing the number of libraries that would need to be linked.

The author notes they're less certain about whether reftable will eventually become a Rust crate compared to xdiff, but the change is made for consistency. Like the rest of the series, this is purely a build-system change with no impact on runtime behavior - reftable functionality remains identical, just compiled differently. The patch mechanically updates Makefile variable definitions, dependency rules, and clean targets to reflect the consolidation.

This completes the series' goal of restructuring static library handling to better support future Rust work while maintaining compatibility with existing builds. The changes are straightforward and well-contained, following the same proven pattern as the xdiff changes in the previous patch.
