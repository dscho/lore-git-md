Build system refactoring for Rust integration, part 2/3.

This patch continues the Makefile restructuring to prepare for future Rust integration by removing the separate XDIFF_LIB static library and folding its objects directly into LIB_OBJS. The change eliminates potential naming conflicts with a planned 'xdiff' Rust crate while simplifying Rust's linking requirements to just libgit.a. The meson build system remains unchanged as it already handles xdiff this way. The patch mechanically updates Makefile rules, removing XDIFF_LIB references and related build targets while maintaining the same xdiff functionality. This follows the first patch's relocation of XDIFF_OBJS definitions and precedes a similar change for REFTABLE_LIB in the series. The changes are purely build-system focused with no behavioral impact on xdiff itself.
