Build system refactoring to prepare for Rust integration.

This is the first of a 3-patch series from Ezekiel Newren that restructures Git's static library build process. The change moves the definitions of XDIFF_OBJS and REFTABLE_OBJS earlier in the Makefile, before GITLIBS is defined. This is a mechanical change that doesn't affect functionality yet, but it enables future patches in the series to properly include these objects in LIB_OBJS.

The overall goal of the series is to consolidate xdiff and reftable functionality directly into libgit.a rather than maintaining them as separate libraries, which will simplify Rust's linking requirements when interfacing with Git's C code. The change is cleanly implemented with a straightforward Makefile reorganization, and the commit message clearly explains the motivation and relationship to the rest of the series.

This appears to be preparatory work for future Rust integration, though the patch itself contains no Rust-specific changes. The change matches how meson already builds these components, and maintains compatibility with existing builds.
