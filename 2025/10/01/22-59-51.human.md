Implementation exploration for mixed-hash submodule support in the index. Jeff King shares a prototype patch modifying `add_to_index()` to handle submodules with different hash algorithms than the main repository. The patch demonstrates a working approach but reveals significant complexity in the index lookup side, where speculative dual-name lookups would be needed.

Key technical points:
- The patch generates special index entries for foreign-hash submodules using a format like "sha1-<hash>-path"
- Current implementation has known gaps (like `git add -u` support)
- Reveals deeper issues with index lookups when the hash algorithm isn't known in advance
- Jeff now leans toward keeping the hack at tree level only, avoiding index modifications

The email captures the tension between implementation complexity and the value of mixed-hash submodule support. While the prototype works, the follow-on implications for index operations may make this approach too costly. Jeff remains undecided on whether the benefits outweigh the complexity, marking this as exploratory work rather than a final proposal.
