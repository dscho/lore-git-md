This is the third and final patch in a build system refactoring series preparing for potential Rust integration. It follows the same pattern as the previous xdiff changes, removing the separate REFTABLE_LIB static library and folding its objects directly into LIB_OBJS. The key changes are removing all references to REFTABLE_LIB while adding REFTABLE_OBJS to LIB_OBJS, updating the GITLIBS definition, and cleaning up related Makefile rules.

Unlike the xdiff case where Rust integration was explicitly planned, the author notes uncertainty about whether reftable will become a Rust crate. The patch maintains identical reftable functionality while simplifying the build structure to match meson's approach. This continues the series' goal of consolidating static libraries into libgit.a to reduce potential linking complications for future Rust work.

The changes are mechanical Makefile updates with no behavioral impact. The patch completes the series' transition to a unified libgit.a containing both xdiff and reftable functionality, leaving the door open for Rust integration while keeping current builds working unchanged. All three patches work together to provide a cleaner foundation for potential future development.
