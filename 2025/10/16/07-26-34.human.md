Feature introducing a new "geometric-repack" maintenance task for Git repositories. This is the third patch in an 8-part series aimed at improving repository maintenance, particularly for monorepos.

The patch adds a new maintenance strategy that uses geometric repacking (which is faster than traditional repacking) while addressing its main limitation - the inability to expire unreachable objects. The solution is a hybrid approach: when a geometric repack would merge all packs, it instead performs a full repack with cruft packs enabled, allowing unreachable objects to be properly expired later.

Key aspects include:
- A new `maintenance.geometric-repack.auto` config option (default 100) to control when automatic repacks occur
- Careful handling of pack merging thresholds and loose object counts
- Thorough test coverage in t7900-maintenance.sh that verifies both the geometric repack behavior and auto-condition logic
- Integration with the existing maintenance task framework

The implementation appears well-considered, with clear attention to edge cases and performance implications. This continues the series' trend of careful refactoring and enhancement of Git's maintenance capabilities.
