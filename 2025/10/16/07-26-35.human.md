This is a bugfix patch in the geometric maintenance strategy series, addressing silent failure handling for invalid maintenance strategies.

The patch fixes an issue where Git would silently ignore an invalid maintenance strategy configuration (like "invalid") and fall back to a no-op strategy. Now it properly errors out with a clear message when encountering an unknown strategy. The change makes the behavior more predictable and helps users discover configuration mistakes are preventing maintenance from running.

The implementation extracts the strategy parsing logic into a new `parse_maintenance_strategy()` function, which will be reused in later patches. This refactoring improves code organization while maintaining the same behavior for valid strategies. The patch includes a new test case verifying the error message appears when an invalid strategy is configured.

This is a straightforward improvement that makes the maintenance subsystem more robust and user-friendly. It's part of the larger geometric maintenance series but stands on its own as a clear bugfix. The change is well-tested and doesn't appear to introduce any new complexity.
