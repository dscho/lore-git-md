This thread discusses performance optimizations for the `git last-modified` command, which finds the most recent commit modifying each specified path. The original implementation was inefficient for rarely-modified paths due to excessive history walking. Toon Claes has proposed a new algorithm using generation-sorted commits with priority queues, path activity tracking via bitmaps, and Bloom filter optimizations to skip unnecessary diffs. The changes include careful reuse of object flag space and introduce commit slabs for path activity bitmaps.
