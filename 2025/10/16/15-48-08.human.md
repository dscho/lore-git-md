This is a CI/build system patch series that updates several GitHub Actions dependencies. Johannes Schindelin is forwarding version bump suggestions from Dependabot (Git for Windows' dependency management bot) for the main Git project's CI workflows.

The 4-patch series updates four GitHub Actions to their next major versions:
- actions/download-artifact (v4->v5)
- actions/checkout (v4->v5) 
- actions/setup-python (v5->v6)
- actions/github-script (v7->v8)

The changes are mechanical version number updates across four workflow files, with no functional changes described. As these are dependency updates from an automated system, the patches appear straightforward and low-risk. The author notes they're taking authorship to facilitate discussion since Dependabot's email isn't suited for follow-up.
