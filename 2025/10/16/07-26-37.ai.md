This is part of the ongoing geometric maintenance strategy series, specifically extending the `maintenance.strategy` configuration to cover manual maintenance runs in addition to scheduled maintenance.

The patch addresses a gap where the strategy configuration previously only affected scheduled maintenance, while manual runs defaulted to `git gc`. This could lead to conflicting maintenance approaches. The change makes `maintenance.strategy` apply globally while maintaining backward compatibility - the "incremental" strategy will still skip GC during manual runs (matching historical behavior) while other strategies will now apply consistently.

Key technical changes:
- Updates documentation to clarify `maintenance.strategy` now affects all maintenance types
- Modifies the `incremental_strategy` struct to explicitly set `TASK_GC` for manual maintenance
- Restructures strategy selection logic in `initialize_task_config()` to check the strategy config for both maintenance types
- Adds comprehensive tests in t7900-maintenance.sh verifying strategy behavior through trace2 output

The implementation carefully preserves existing behavior while expanding functionality, with particular attention to the incremental strategy's historical GC behavior. The test suite additions provide strong verification of both the new unified strategy handling and backward compatibility requirements. This change completes the strategy unification work started in earlier patches of the series.
