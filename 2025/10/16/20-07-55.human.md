This is a refactoring patch in a series about improving Git's maintenance strategies, particularly for monorepos. It removes a global `repack` variable in `builtin/gc.c` that was used to accumulate command-line arguments for `git-repack`, replacing it with stack-allocated variables passed between functions.

The change makes the code more modular and easier to follow, while maintaining the same behavior. A key insight is that for maintenance tasks, the repack arguments can be recomputed when needed rather than preserved, since they're executed in a separate process anyway. Justin Tobler confirms the approach looks sound, noting the arguments are safely handled in the new `gc_condition` wrapper function.

This is a preparatory change that enables later patches in the series to reuse the repacking infrastructure more cleanly. The patch appears well-reasoned and maintains existing functionality while improving the code structure.
