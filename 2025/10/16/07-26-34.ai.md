Feature introducing a new "geometric-repack" maintenance task, part of the ongoing geometric maintenance strategy series. This patch adds a new maintenance strategy that uses geometric repacking for most operations while falling back to cruft packs when needed to handle unreachable objects.

The implementation introduces a new `maintenance.geometric-repack.auto` config option (default 100) to control when the task runs automatically. The task uses `git repack --geometric=2` for most operations, but switches to an all-into-one repack with cruft packs when packs would be merged completely. This hybrid approach aims to balance the performance benefits of geometric repacking with the need to eventually expire unreachable objects.

The patch includes extensive tests in t7900-maintenance.sh that verify:
- Basic geometric repacking behavior
- Automatic task execution based on loose object counts
- Proper handling of unreachable objects via cruft packs
- Interaction with the auto-configuration threshold

The changes touch builtin/gc.c (adding the new task implementation), documentation, and test scripts. This appears to be a well-considered addition to Git's maintenance capabilities, particularly for large repositories, building on the geometric repacking infrastructure introduced earlier. The implementation is thorough with good test coverage and clear documentation of the tradeoffs involved in the hybrid strategy.
