This is a documentation and build system patch series addressing technical documentation formatting issues and build system coverage. It represents version 3 of Ramsay Jones' effort to align technical docs between Makefile and meson builds while fixing asciidoc warnings.

The series now contains 4 patches after the first patch was separated into its own branch ('rj/doc-missing-technical-docs'). The current focus is on fixing asciidoc formatting warnings in three key documents (`remembering-renames.adoc`, `sparse-checkout.adoc`, `commit-graph.adoc`) and adding `large-object-promisors.adoc` to the docs build. The changes include list renumbering (0->1), section heading level adjustments, and monospaced text formatting fixes.

Two persistent issues remain unsolved: monospaced text containing '{' characters and broken HTML links with reserved characters in URLs. Ramsay acknowledges these require asciidoc expertise beyond his current knowledge. The patches show careful attention to detail despite these limitations, with each iteration improving upon the previous versions (v3 fixes a typo in patch #2 and adds a new patch #4).

The thread context shows this work is part of a larger effort to ensure consistency between Makefile and meson builds, with Patrick Steinhardt's `lint-docs-meson` tool helping identify gaps. Junio Hamano has clarified that these patches can proceed independently after the initial patch was merged to 'next'. The series demonstrates thorough testing across different asciidoc processors (asciidoc vs asciidoctor) and Python versions, though some Python 3.12+ SyntaxWarnings remain unresolved.
