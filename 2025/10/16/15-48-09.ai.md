CI / build system update for GitHub Actions workflow dependencies, specifically bumping `actions/download-artifact` from v4 to v5 in the main workflow file. This is the first of a four-part series adapting version bumps originally suggested by Dependabot for Git for Windows, now being proposed for the main Git repository by Johannes Schindelin.

The change mechanically updates three instances of the download-artifact action in `.github/workflows/main.yml`, all related to Windows build artifacts. The patch includes standard dependency update metadata showing this is a semver-major version bump, though no functional impact on Git's behavior is described. The action is used to fetch build artifacts during Windows CI runs, including the Windows SDK setup and meson build system steps.

As noted in the thread context, this is part of a low-controversy maintenance series updating widely-used GitHub Actions components. The original Dependabot authorship is preserved while Schindelin takes responsibility for mailing list submission. The remaining patches in the series will update other GitHub Actions (`checkout`, `setup-python`, and `github-script`) in different workflow files.
