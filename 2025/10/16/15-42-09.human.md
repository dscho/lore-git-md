This is a documentation update in an ongoing discussion about deprecating the `--committer-date-is-author-date` option in `git-am` and `git-rebase`. The thread has reached consensus that the original use case for this option - using `git-am` as a pseudo-import mechanism to recreate identical commit hashes - was fundamentally flawed and violates Git's timestamp ordering assumptions.

Kristoffer Haugsbakk is working on revising the documentation to reflect this position. The key points now are:
1. The option should be clearly marked as deprecated
2. The documentation should explain why the original use case was invalid (mailboxes aren't suitable commit storage)
3. The warning should be strong but still maintain good flow

Johannes Sixt has provided decisive technical input rejecting the original premise, and Kristoffer is now adjusting the documentation approach accordingly. The remaining discussion is about presentation - whether to use a standalone "Do not use" directive or integrate the warning more naturally into the text. The technical substance is settled; this is now about clear communication of the deprecation.
