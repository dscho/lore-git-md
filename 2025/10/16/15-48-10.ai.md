CI / build system update continuing Johannes Schindelin's series to bump GitHub Actions versions, originally sourced from Git for Windows' Dependabot suggestions. This patch specifically updates `actions/checkout` from v4 to v5 across four workflow files: `check-style.yml`, `check-whitespace.yml`, `coverity.yml`, and `main.yml`. The changes are mechanical version number updates affecting multiple CI jobs including Windows builds, static analysis, and documentation testing.

The previous thread context shows this is part of a planned 4-patch series updating standard GitHub Actions, with this being the second of four. The `actions/checkout` update appears in 10 distinct workflow steps, including some duplicate uses within the same job (notably the Windows vcpkg initialization in `main.yml` that checks out both Git and vcpkg repositories). No functional impact on Git's build or test behavior is described, consistent with the maintenance nature of these updates.

The patch preserves Dependabot's original authorship while adding Schindelin's sign-off, maintaining the established pattern from the series' first patch. The widespread use of `actions/checkout` across the CI pipeline makes this a more substantial change than some other Actions updates, though still presumably low-risk given GitHub's maintenance of these standard components. The remaining two patches in the series will address `actions/setup-python` and `actions/github-script` updates.
