This is a patch in the geometric maintenance strategy series that makes the "gc" strategy explicitly configurable. Currently, while users can select the "incremental" strategy, there's no way to explicitly choose the default "gc" strategy, which prevents repository-specific overrides and scheduled maintenance using git-gc.

The patch makes three key changes:
1. Documents the "gc" strategy option alongside others in maintenance.adoc
2. Modifies the gc_strategy to run for both manual and scheduled maintenance
3. Adds tests verifying the gc strategy works in both contexts

This appears to be a straightforward quality-of-life improvement that completes the strategy unification work from earlier patches in the series. The changes are small but meaningful, with clear documentation updates and thorough test coverage showing the new behavior works as intended. The patch maintains consistency with the series' goal of providing flexible maintenance strategy options while preserving backward compatibility.
