This thread addresses a bug in Git's GPG/SSH signature verification where the `remove_cr_after()` function was incorrectly stripping all carriage return (CR) characters, potentially corrupting binary payloads or text with standalone CRs. Okhuomon Ajayi's initial patch renamed the function to `trim_cr_before_lf()` and modified it to only remove CRs when they immediately precede a line feed (LF), properly handling Windows-style CRLF while preserving legitimate standalone CRs.
