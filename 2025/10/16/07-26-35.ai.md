This is a bugfix patch in the geometric maintenance strategy series, addressing silent failure handling for invalid maintenance strategies.

The patch fixes an issue where Git would silently ignore invalid maintenance strategy configurations, falling back to a no-op strategy without warning the user. The change makes this behavior explicit by erroring out when encountering unknown strategies, improving debuggability. The implementation extracts the strategy parsing logic into a new `parse_maintenance_strategy()` function for reuse in future patches.

Key technical changes include:
- New `parse_maintenance_strategy()` function that validates strategy names
- Error handling that dies with "unknown maintenance strategy" message
- Added test case in t7900-maintenance.sh verifying the new error behavior
- Maintains the existing fallback to `none_strategy` when no strategy is configured

The change is straightforward but important for user experience - it prevents silent failures when users misconfigure maintenance strategies. The patch fits cleanly into the larger geometric maintenance series by improving the strategy selection infrastructure that the new geometric strategy will eventually plug into. The test coverage is minimal but appropriate for the change.
