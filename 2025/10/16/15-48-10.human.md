CI / build system update: This is the second patch in a 4-part series updating GitHub Actions dependencies, mechanically bumping `actions/checkout` from v4 to v5 across multiple workflow files. Johannes Schindelin is shepherding these updates originally proposed by Dependabot for Git for Windows, now adapted for the main Git repository.

The patch updates all instances of the checkout action in four workflow files: `check-style.yml`, `check-whitespace.yml`, `coverity.yml`, and `main.yml`. The changes are straightforward version number updates with no functional modifications to Git's build process. The most notable updates are in `main.yml` where the checkout action is used for Windows SDK setup and meson build steps.

As with the first patch in the series, this appears to be a low-risk maintenance change updating a widely-used CI component. The commit preserves Dependabot's original authorship while enabling proper mailing list review. The changelog and release notes for actions/checkout v5 are referenced but no specific new features or fixes are highlighted as motivating the update.

This continues the pattern seen in the series' first patch, with two more similar dependency updates expected to follow. The changes are mechanical and unlikely to be controversial, though reviewers may want to verify there are no breaking changes in the new major version that could affect Git's CI pipelines.
