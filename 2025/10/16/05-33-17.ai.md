Security-focused patch series introducing mechanisms to prevent arbitrary code execution via Git hooks in untrusted repositories. This is version 3 of the series, incorporating feedback from Junio Hamano and others.

The series builds on prior `safe.directory` security work by adding two main features:
1. A temporary bypass mechanism (`--allow-unsafe` flag and `GIT_ALLOW_UNSAFE` env var)
2. A persistent configuration option to skip ownership checks (`--assume-unsafe` flag, `GIT_ASSUME_UNSAFE` env var, and `safe.assumeUnsafe` config)

Key changes in v3:
- Patch 2's function renamed from `die_upon_assumed_unsafe_repo()` to `die_upon_unsafe_repo()` per Junio's suggestion
- Patch 3's commit message clarified to better explain its preparatory nature for future changes
- Documentation fixes and test improvements from v2 review incorporated

The series progresses through:
