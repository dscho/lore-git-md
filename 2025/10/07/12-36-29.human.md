This is a CI/build system patch that removes redundant `apt-get update` calls in Git's CI dependency installation script. As part of Patrick Steinhardt's series to enhance Rust tooling in Git's CI infrastructure, this first patch focuses on optimizing the setup process.

The change eliminates duplicate package index updates that were happening in both the distribution-specific and job-specific installation steps. Since the distribution step already updates the package lists, the subsequent job-specific updates are unnecessary. The patch simply removes these redundant calls from four job cases: ClangFormat, StaticAnalysis, sparse, and Documentation builds.

The modification is straightforward and uncontroversial - it doesn't change any functionality, just removes wasted cycles. The patch is cleanly focused on its single purpose and touches only the installation script. As the first in a series about Rust CI improvements, this appears to be setting up some basic infrastructure cleanup before the Rust-specific changes in later patches.
