This is a feature patch series introducing new signature handling controls for `git fast-import`, mirroring existing `fast-export` functionality. The main goal is to give tools like `git-filter-repo` more control over how tag signatures are processed during repository filtering operations.

The series starts with a documentation update to modernize `git tag`'s documentation (patch 1), which could stand alone. It then includes preparatory fixes: improving GPG test infrastructure (patch 2), fixing tag counting in tests (patch 3), and extending `fast-export` to properly handle all signature types (patch 4). The key patch (5) adds a `--signed-tags=<mode>` option to `fast-import`, matching `fast-export`'s existing behavior with modes like "verbatim" and "ignore".

The work appears well-structured, with clear incremental steps. The author notes this is just the foundation - future plans include more sophisticated signature handling modes like "re-sign-if-invalid". The test coverage looks thorough, with a dedicated test file created for the new functionality. One unrelated CI failure on Windows is noted but doesn't appear concerning.
