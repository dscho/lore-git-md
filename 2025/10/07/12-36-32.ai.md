This is the fourth patch in Patrick Steinhardt's series enhancing Rust CI infrastructure, focusing on static analysis. The patch introduces Clippy, Rust's official linter, to the CI pipeline to catch common mistakes and suggest code improvements.

The changes are straightforward: the patch modifies `ci/install-dependencies.sh` to install Clippy alongside rustfmt, and updates `ci/run-rust-checks.sh` to run Clippy with strict settings (`-Dwarnings` flag to treat all warnings as errors). The implementation follows the established pattern from previous patches in the series, using the same `group` function for CI output organization.

This continues the systematic approach seen in earlier patches, with each commit adding a specific Rust tooling capability. The patch builds on the foundation laid by the previous documentation work (particularly for unsafe FFI functions in `varint.rs`) by now ensuring code quality through automated static analysis. The changes are minimal but important for maintaining Rust code quality standards, especially as the project's Rust codebase grows. The patch maintains cross-platform compatibility and integrates cleanly with the existing CI infrastructure.
