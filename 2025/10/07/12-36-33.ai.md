CI infrastructure patch adding minimum Rust version validation to Git's CI pipeline, part of Patrick Steinhardt's Rust tooling series.

This fifth patch in the 6-part series introduces version checking for Rust toolchain compatibility. It establishes Git's minimum supported Rust version as 1.49.0 in Cargo.toml and adds CI verification using cargo-msrv. The choice of this older version (from 2020) aims to maintain compatibility with alternative Rust compilers like gccrs while the project's Rust code remains simple.

Key technical changes:
- Adds `rust-version = "1.49.0"` to Cargo.toml
- Installs cargo-msrv 0.18.4 in ci/install-dependencies.sh
- Adds cargo-msrv verification step to ci/run-rust-checks.sh
- Uses Ubuntu-compatible cargo-msrv version (0.18.4) despite newer releases existing

The patch follows the series' pattern of incremental CI improvements, building on previous Rust infrastructure work (formatting, linting) while focusing specifically on version compatibility. The implementation shows attention to cross-distro compatibility by pinning to an Ubuntu-supported cargo-msrv version rather than latest. This maintains the series' focus on establishing robust, production-grade Rust infrastructure for Git.
