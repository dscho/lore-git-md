This is the final patch in a refactoring series cleaning up the packfile store API. The patch renames `packfile_store_get_all_packs()` to simply `packfile_store_get_packs()`, removing the redundant "all" now that the deprecated `packfile_store_get_packs()` function (without "all") was dropped in an earlier patch.

The change is purely mechanical, updating callers in fast-import, pack-objects, and packfile internals to use the new name. The patch also updates the recently introduced `packfile_store_for_each_pack()` macro to use the renamed function. This completes the series' goal of standardizing pack iteration patterns while maintaining identical behavior.

The patch follows the series' careful approach - it's a straightforward cleanup that builds on previous work to simplify the API surface. With this change, the packfile store API now has a cleaner naming scheme while preserving all existing functionality. The series as a whole demonstrates methodical internal refactoring with no user-facing impact.
