This is a test infrastructure patch in Christian Couder's series improving signature handling in fast-import/export. It addresses a fragility in t9350-fast-export.sh where tests were using hardcoded counts of annotated tags, which could break if new tests added more tags.

The patch introduces a counter variable `ANNOTATED_TAG_COUNT` that gets incremented each time a new annotated tag is created in the test setup or test cases. The existing tag-count assertions are then modified to compare against this counter rather than hardcoded values (3 and 4 in the original tests). This makes the tests more maintainable as new tag-adding tests are added to the file.

The changes are mechanical but important for test robustness, particularly as the series adds more tag-related tests. The patch follows the series' pattern of preparatory groundwork before the main signature-handling features. The commit message clearly explains the problem and solution, and the changes are straightforward with no apparent issues.
