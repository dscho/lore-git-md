This is a refactoring patch introducing a wrapper struct for the `each_ref_fn` callback interface, which is part of a larger 13-patch series on refs/tag peeling behavior. The patch aims to make future changes to the callback signature less disruptive by encapsulating parameters in a struct rather than passing them individually.

The key changes are:
1. Introduces a new `struct reference` containing refname, target (for symrefs), oid, and flags
2. Updates all 48 callers of `each_ref_fn` across the codebase to use the new struct
3. Maintains the same functionality while changing the callback signature

The motivation is to avoid the widespread churn seen in previous changes to the callback signature (like e8207717f1 which touched 48 files to add one parameter). The tradeoff is slightly more opaque code since the callback parameters are now hidden in a struct.

This is patch 1/13 in a series focused on refs subsystem improvements, particularly around tag peeling behavior. The series appears to be in its first iteration (v1) and the author notes some uncertainty about later patches in the series. This foundational patch seems straightforward and well-executed, touching all necessary callers while maintaining clear commit message documentation.
