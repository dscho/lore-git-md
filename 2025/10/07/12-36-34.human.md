This is the final patch in Patrick Steinhardt's series improving Rust CI infrastructure, specifically adding Windows support. The patch addresses two key issues preventing Rust builds on Windows: missing linkage against `userenv.dll` (needed for `GetUserProfileDirectoryW()`) and incorrect library path handling for Windows' different naming convention (`gitcore.lib` vs `libgitcore.a`).

The changes span multiple build systems (Makefile, meson) and CI configurations (GitHub, GitLab). The Makefile changes handle Windows-specific library naming and linking, while meson gets Windows-specific dependency detection. The patch also enables Rust testing in GitLab CI by installing the Rust toolchain on Windows runners.

The changes are straightforward and focused, with clear motivation explained in the commit message. The patch builds on prior work from Johannes Schindelin and Ezekiel Newren, suggesting this completes a known gap in the initial Rust integration. With this patch, the series now provides comprehensive Rust CI coverage across all major platforms.
