This is a feature patch series introducing new signature handling capabilities to `git fast-import`, with related documentation and test improvements. The main goal is to add a `--signed-tags=<mode>` option to `git fast-import` that mirrors the existing `--signed-commits` functionality and aligns with `git fast-export`'s behavior.

The series builds on prior work that added commit signature handling to fast-import. The new tag signature control will help tools like `git-filter-repo` manage signatures during repository filtering operations. The implementation starts with simple modes (like "ignore" and "verbatim") matching fast-export's current capabilities, with plans to add more complex modes later.

Key technical details include:
- New `--signed-tags` option in fast-import.c with modes matching fast-export
- Fixes in fast-export.c to properly handle all signature types (not just GPG)
- Test improvements including a new t9306 test file for fast-import signed tags
- Documentation updates to modernize git-tag docs beyond just GPG signatures
- Preparatory patches for test infrastructure (lib-gpg.sh) and tag counting

The series appears well-structured with clear separation of concerns between the preparatory work (patches 1-4) and the main feature (patch 5).
