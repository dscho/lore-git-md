Feature addition to `git fast-import` for handling signed tags. This is the final patch in a series that brings signed tag handling parity between `git fast-export` and `git fast-import`.

The patch adds a new `--signed-tags=<mode>` option to `git fast-import`, mirroring the existing `--signed-commits` functionality. The option supports the same modes as fast-export: "verbatim" (default), "warn-verbatim", "warn-strip", "strip", and "abort". This allows repository filtering tools to properly handle signed tags during import operations.

Implementation includes:
- Documentation updates in git-fast-import.adoc
- Core logic in builtin/fast-import.c that processes tag signatures according to the specified mode
- A comprehensive test suite (t9306-fast-import-signed-tags.sh) covering all signature types (PGP, X.509, SSH) and all handling modes

The patch appears well-structured with thorough test coverage. It completes the series' goal of consistent signature handling across Git's fast-import/export tools, particularly useful for repository filtering workflows. The implementation builds on existing infrastructure like `parse_signed_buffer()` and follows the same patterns as the earlier `--signed-commits` work.
