Packfile store API refactoring series (v6) from Taylor Blau and Patrick Steinhardt, concluding the cleanup of pack iteration patterns. The series systematically converted callers across 20+ files to standardized iteration patterns, focusing on internal pack subsystem improvements with no user-facing impact. Core changes included removing the deprecated `packfile_store_get_packs()`, introducing `packfile_store_for_each_pack()` macro, and simplifying the API by renaming `packfile_store_get_all_packs()` to `packfile_store_get_packs()` in the final patch.

Technical details show the changes touched core pack operations (pack-bitmap, pack-objects), maintenance commands (gc, repack), object lookup paths, and grep's pack preloading. The series eliminated confusing statefulness between `get_packs()` and `get_all_packs()` regarding MIDX'd pack inclusion. Taylor Blau reviewed and approved Patrick Steinhardt's changes across multiple subsystems, including object-name.c, builtin/gc.c, and builtin/grep.c, suggesting minor editorial improvements while maintaining technical approval.
