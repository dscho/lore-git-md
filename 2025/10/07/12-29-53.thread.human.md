Christian Couder's series to improve signature handling in Git's fast-import/export components continues to take shape. The thread began with documentation updates and test infrastructure work, and has now reached the core implementation phase. The latest patch focuses on `git fast-export`, replacing its hardcoded PGP signature detection with the more flexible `parse_signed_buffer()` function to properly handle all Git-supported signature types (PGP, X.509, and SSH).

The expanded test coverage in t9350-fast-export.sh demonstrates the improved functionality, verifying that signatures are correctly preserved in 'verbatim' mode and stripped in 'strip' mode across all signature types. This change aligns with the series' broader goal of enabling repository filtering tools to properly manage signed content during export/import operations. The implementation maintains backward compatibility while fixing the previous limitation where only PGP signatures were properly detected.

The series shows clear progression from preparatory work (including test infrastructure improvements like the new `ANNOTATED_TAG_COUNT` variable) through to these core implementation changes. With the fast-export side now addressed, attention will likely turn to implementing the symmetric `--signed-tags` functionality in fast-import, which remains to be completed in patch 7 of the series.
