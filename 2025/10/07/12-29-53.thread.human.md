This thread has completed the work to bring symmetric signature handling between `git fast-import` and `git fast-export`, allowing consistent processing of PGP, X.509, and SSH signatures across both commands. Christian Couder led the effort with significant input from Patrick Steinhardt, Todd Zullinger, and Collin Funk.

The series began with documentation updates and test infrastructure improvements, including a new `prepare_gnupghome()` helper for GPG setup. The core implementation introduced signature handling modes (verbatim, warn-verbatim, warn-strip, strip, abort) with matching behavior in both commands, though with different defaults (verbatim for import vs abort for export). The work builds on centralized signature parsing logic and includes comprehensive tests covering all signature types and modes.

After multiple review rounds addressing technical feedback and style improvements, Junio C Hamano has now approved the series for integration. The final version incorporates documentation polish, test modernization, and adopts Zullinger's approach for GPGSM test reliability. While some peripheral GPG2 test issues remain marked as NEEDSWORK, the core functionality is complete and ready for merging, marking a significant step forward in Git's cryptographic signature handling capabilities.
