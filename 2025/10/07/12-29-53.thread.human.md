Christian Couder has completed his series to unify signature handling between `git fast-import` and `git fast-export`, with the final patch adding a `--signed-tags=<mode>` option to `git fast-import`. This matches the existing fast-export behavior, supporting all signature types (PGP, X.509, SSH) through a new `handle_tag_signature()` function that uses the shared `parse_signed_buffer()` infrastructure.

Patrick Steinhardt has reviewed the implementation and found it technically sound, though he noted several minor documentation and style issues that need addressing: the option should be alphabetized in the docs, some messages need translation markers, and indentation fixes are needed. He also raised a question about whether signatures always appear at the end of tag messages, which is a key assumption in the current design. The series includes comprehensive tests in t9306-fast-import-signed-tags.sh that verify behavior across all signature types and modes (verbatim, warn-verbatim, warn-strip, strip, abort).

The work modernizes Git's documentation to consistently use "cryptographic signature" terminology and improves test infrastructure, particularly around GPG testing. While there was some discussion about test isolation approaches in t9350-fast-export.sh, the core functionality appears ready for merging once the minor review feedback is incorporated. This completes the effort to provide consistent signature handling across Git's fast-import/export pipeline.
