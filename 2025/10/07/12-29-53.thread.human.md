This thread has two main tracks: the implementation of consistent signature handling across `git fast-import` and `git fast-export`, and a parallel discussion about test infrastructure issues with GPG2 prereq handling. 

The signature handling work, led by Christian Couder with reviews from Patrick Steinhardt and others, is now complete and ready for integration. It provides uniform support for PGP, X.509, and SSH signatures through both commands, with updated documentation and thorough test coverage. Junio Hamano has approved the implementation after all feedback was incorporated.

A separate but related discussion emerged about flaky tests in t1016-compatObjectFormat.sh and other files that use GPG2. Todd Zullinger identified that these tests were silently skipping when GPG home directories didn't exist, masking failures. The consensus is to temporarily remove the problematic t1016 tests as an immediate solution, while leaving the issue visible in the 'seen' branch in hopes someone will debug it. This highlights a broader CI reporting gap where skipped tests aren't properly tracked.

While the test infrastructure issues remain as technical debt, they don't block the signature handling work, which has achieved its goals of consistent behavior across import/export operations with proper documentation and validation. The test discussion shows the project's pragmatic approach to balancing immediate needs with long-term infrastructure improvements.
