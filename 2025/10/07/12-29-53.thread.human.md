Christian Couder has completed a series adding consistent signed tag handling to `git fast-import`, matching the existing `--signed-commits` functionality and bringing parity with `git fast-export`. The implementation introduces a new `--signed-tags=<mode>` option with several behaviors: preserving signatures verbatim (the default), stripping them with or without warnings, or aborting when encountering signed tags. 

The work builds on preparatory patches that modernized documentation to acknowledge non-GPG signing methods (X.509, SSH) and improved test infrastructure. The final implementation uses Git's `parse_signed_buffer()` to properly handle all supported signature types, not just PGP. Test coverage in t9306-fast-import-signed-tags.sh verifies the various modes work as expected across different signature formats, ensuring interoperability with fast-export's behavior.

This completes the project's goal of providing consistent signature handling during repository filtering operations, addressing an oversight where only PGP signatures were properly detected in fast-export. The series shows careful progression from documentation updates to test improvements before implementing the core feature, with Windows CI failures appearing unrelated to the actual changes.
