This thread has been working on standardizing signature handling (PGP, X.509, SSH) across Git's fast-import and fast-export commands, led by Christian Couder with input from Patrick Steinhardt and Collin Funk. The series has gone through multiple iterations to implement matching `--signed-tags` options for both commands, with comprehensive test coverage across all signature formats.

The implementation is now functionally complete, with the recent exchanges focusing on final polish. Christian has addressed Patrick's feedback about test formatting conventions (removing unnecessary empty lines in test scripts) in a v2 revision. The test infrastructure includes a `prepare_gnupghome()` helper and dynamic tag counting in t9350-fast-export.sh, thoroughly exercising all signature types and processing modes (verbatim, warn, strip, abort).

While the core functionality is ready, there remains some known test fragility around GPG2 in certain environments (noted by Todd Zullinger), but this doesn't block the main work. The series appears to be in its final form, with all substantive review feedback incorporated and only minor style adjustments being made before likely inclusion.
