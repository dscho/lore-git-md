This is part 4 of Patrick Steinhardt's series enhancing Git's Rust CI infrastructure, focusing on static analysis. The patch introduces Clippy, Rust's official linter, to the CI pipeline to catch common mistakes and suggest code improvements.

The changes are straightforward: the patch adds Clippy to the Rust toolchain installation in `ci/install-dependencies.sh` and runs it alongside existing checks in `ci/run-rust-checks.sh`. This builds on the previous patches in the series that set up Rust formatting checks and documentation requirements.

The implementation looks clean and well-contained, following the established pattern of the series. This is a logical next piece in building out comprehensive Rust tooling support, though the commit message could benefit from mentioning whether any specific Clippy checks are being enabled or disabled (the `-Dwarnings` flag suggests all warnings are being treated as errors).

As with the rest of the series, this appears to be a solid contribution to Git's Rust infrastructure, though reviewers may want to verify the choice of Clippy settings and whether any exceptions might be needed for Git's specific use cases.
