Taylor Blau has proposed a documentation update to formalize experimental practices around topic branch naming and patch submission workflows. The two-part series aims to improve contributor experience while maintaining backward compatibility with existing practices.

The first patch focuses on topic branch naming conventions, suggesting an "XX/your-topic-name" format where XX represents the author's initials (demonstrated by Blau's own "tb/submitting-patches" example). It builds on a March 2024 experiment (commit d255105c99) that introduced optional topic summaries, now expanding this with branch naming guidance. The changes remain marked as experimental in the documentation.

The proposal appears to have maintainer support, with Junio Hamano's input reflected in the Signed-off-by and Suggested-by tags. The patch series is purely documentation-focused, modifying only the SubmittingPatches file without any code changes. While the initial version is complete, the thread may still discuss whether the experimental practice has seen enough adoption to graduate to recommended status.
