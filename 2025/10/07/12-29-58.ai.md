Feature implementation completing the signed tags handling in git-fast-import.

This final patch in Christian Couder's series adds the `--signed-tags=<mode>` option to `git fast-import`, mirroring the existing `--signed-commits` functionality and bringing parity with `git fast-export`. The implementation:
- Adds a new signed_tag_mode variable defaulting to SIGN_VERBATIM
- Introduces handle_tag_signature() function that processes tags according to the selected mode (verbatim, warn-verbatim, warn-strip, strip, abort)
- Uses parse_signed_buffer() to detect signatures, supporting all Git signature types (PGP, X.509, SSH)
- Includes comprehensive test coverage in t9306-fast-import-signed-tags.sh verifying:
  - Default verbatim behavior preserves signatures
  - Warning modes produce appropriate messages
  - Strip modes remove signatures while preserving tag content
  - Abort mode fails on signed tags
  - Works with all supported signature types (PGP, X.509, SSH)

The implementation follows the same pattern as the earlier signed-commits work, with careful handling of the signature parsing and mode selection. The tests demonstrate interoperability with fast-export's signed tag handling and verify the various mode behaviors work as expected across different signature formats. This completes the series' goal of providing consistent signature handling between fast-export and fast-import operations.
