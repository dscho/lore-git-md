This is the second patch in Patrick Steinhardt's 6-part series enhancing Git's Rust CI infrastructure, focusing on establishing formatting checks for Rust code. The patch introduces a new CI job that verifies code formatting using `rustfmt`, Rust's standard formatting tool.

The changes add a `rust-analysis` job to both GitHub Actions and GitLab CI configurations, install Rust tooling dependencies (rustup and rustfmt), and create a new `ci/run-rust-checks.sh` script that runs the formatting check. The approach follows Rust ecosystem conventions by using the default style edition specified in Cargo.toml rather than customizing formatting rules.

Key technical elements include:
- New CI job definitions in `.github/workflows/main.yml` and `.gitlab-ci.yml`
- Rust toolchain installation in `ci/install-dependencies.sh`
- The core formatting check script `ci/run-rust-checks.sh` using `cargo fmt --check`
- Integration with existing CI infrastructure (job naming conventions, error handling)

The patch maintains consistency with the series' focus on establishing robust Rust tooling while keeping changes focused and incremental. It follows the project's existing CI patterns while adding Rust-specific validation. The implementation appears straightforward and well-contained, with clear documentation of the rationale for using Rust's default formatting style.
