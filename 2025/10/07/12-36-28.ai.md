Cover letter for a CI infrastructure series focused on Rust tooling improvements. This 6-patch series from Patrick Steinhardt enhances the Git project's Rust-related continuous integration checks and adds Windows support.

The series introduces several static analysis measures for Rust code:
- Formatting consistency checks
- Clippy-based linting
- Minimum supported Rust version verification
- Windows build support

The changes span multiple CI configuration files (.github/workflows, .gitlab-ci.yml) and touch build infrastructure (Makefile, meson.build) as well as Rust source files. The series builds on recent work enabling Rust in CI jobs and improving Windows CI pipelines.

Key technical details:
- New `ci/run-rust-checks.sh` script consolidates Rust-specific CI steps
- Adds safety documentation to `src/varint.rs`
- Modifies dependency installation to avoid redundant `apt-get update` calls
- Updates Cargo.toml and meson build configurations
- Adds Windows-specific handling in build scripts

The changes appear focused and well-scoped, with each commit addressing a specific CI improvement. The series follows recent efforts to expand Rust adoption in Git's codebase.
