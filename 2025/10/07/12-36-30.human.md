This is part 2 of Patrick Steinhardt's series to enhance Git's CI infrastructure for Rust tooling, focusing on code formatting checks. The patch introduces a new CI job that verifies Rust code formatting using `rustfmt`, the standard Rust formatting tool.

The change adds Rust formatting checks to both GitHub Actions and GitLab CI pipelines, installing `rustup` and `rustfmt` as dependencies. A new `ci/run-rust-checks.sh` script runs the actual formatting verification using `cargo fmt --check`. The formatting style automatically follows the edition specified in Cargo.toml, matching common Rust ecosystem practices.

This is a straightforward infrastructure improvement that enforces consistent code style from the start as more Rust code gets added to Git. The implementation looks clean and follows the pattern of other static analysis checks in the CI pipeline. As part of the broader Rust tooling effort, this helps maintain code quality while avoiding style debates by adopting Rust's conventional formatting defaults.
