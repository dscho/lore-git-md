Documentation patch modernizing git-tag's documentation to be more inclusive of non-GPG signing methods. This is the first of five patches in a series introducing better signature handling in fast-import/export.

The patch updates git-tag's man page to remove GPG-specific language, making it clear the command supports multiple signing backends (GPG, X.509, SSH) via the `gpg.format` configuration. Key changes include: rewriting the NAME section to remove GPG reference, updating DESCRIPTION to mention cryptographic signatures generically, clarifying OPTIONS text for `-s`/`-u` to reference configurable backends, and expanding CONFIGURATION to document how to set up non-GPG signing.

The changes are thorough and align with Git's growing support for multiple signature types. The patch serves as documentation groundwork for the subsequent fast-import signature handling changes in the series. The commit message clearly explains the motivation (avoiding GPG-centric documentation that might mislead users about tag capabilities) and the changes are well-scoped to just the documentation updates needed.
