Feature implementation for signature handling in `git fast-export`. This patch is part of Christian Couder's series to improve signature handling across Git's fast-import/export components, specifically addressing tag signature processing in `git fast-export`.

The patch modifies `builtin/fast-export.c` to use `parse_signed_buffer()` instead of hardcoded PGP signature detection, enabling proper handling of all Git-supported signature types (PGP, X.509, SSH). The change makes signature processing consistent with Git's broader signing infrastructure. Test coverage is significantly expanded in `t/t9350-fast-export.sh` to verify behavior with X.509 and SSH signatures, including new test cases that:
- Create tags signed with X.509 and SSH keys
- Verify signature preservation in `verbatim` mode
- Confirm signature stripping in `strip` mode

The implementation maintains backward compatibility while fixing the oversight where only PGP signatures were properly detected. The test additions follow the series' pattern of using the `ANNOTATED_TAG_COUNT` variable introduced in patch 6, showing good integration with the preparatory work. This change directly supports the series' goal of enabling repository filtering tools to properly handle signed content during export/import operations.
