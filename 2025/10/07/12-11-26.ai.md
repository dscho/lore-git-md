This is a refactoring patch in the reftable fsck validation series, moving a consistency check message from the files backend to the generic refs layer. 

The change relocates the "Checking references consistency" message from `refs/files-backend.c` to `refs.c`, making it available to all reference backends (including the files and reftable backends) rather than being files-backend specific. The message is printed when fsck runs in verbose mode (`o->verbose`).

The patch is straightforward - it removes the message printing from `files_fsck_refs()` and adds it to the generic `refs_fsck()` function that all backends use. This ensures consistent behavior across backends and eliminates duplicate code. The change is part of the larger effort to bring reftable fsck capabilities to parity with the files backend.

Key files modified:
- `refs.c` (added message printing in generic fsck path)
- `refs/files-backend.c` (removed backend-specific message)

This is a clean, focused change that improves code organization while maintaining identical functionality. It's one of several preparatory refactorings in the series to enable consistent fsck behavior across reference backends.
