This is a follow-up discussion in the submodule gitdir path encoding series, focusing on the config override mechanism. Junio Hamano responds to Adrian Ratiu's patch that added the ability to override gitdir paths via config files.

Junio clarifies two key issues with the current implementation: First, he suggests the config setting should serve as the authoritative source of truth for all submodule paths rather than just being an override mechanism. This aligns with his broader proposal in the thread about handling the transition period when enabling the encoding extension. Second, he points out a documentation mismatch where the patch describes the config key as `submodule.<name>.gitdir` while the code actually implements `submodule.<name>.gitdirpath`.

The exchange shows the series is now in the fine-tuning phase, with Junio providing specific feedback on implementation details after the major design decisions (like using URL percent-encoding) have been settled.
