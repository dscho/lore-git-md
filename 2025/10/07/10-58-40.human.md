This is a refactoring patch in Patrick Steinhardt's series modernizing Git's refs subsystem. It converts the reference status flags from preprocessor defines to an enum and changes their storage type from `int` to `unsigned`, bringing the code in line with modern best practices.

The patch touches the core refs infrastructure by updating the `struct reference` definition in `refs.h`. It reorganizes four existing status flags (`REF_ISSYMREF`, `REF_ISPACKED`, `REF_ISBROKEN`, and `REF_BAD_NAME`) into a proper enum while maintaining their same bit values. The change is mechanical but improves type safety and code organization.

As part of the larger series, this helps pave the way for more substantial refactoring by cleaning up technical debt in the flags system. The patch appears straightforward and well-contained, with no behavior changes - just improved code hygiene. It follows the series' pattern of incremental improvements to the refs subsystem's internal interfaces.
