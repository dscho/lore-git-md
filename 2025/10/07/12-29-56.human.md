Test infrastructure improvement for tag counting in fast-export tests.

This is the third patch in Christian Couder's series improving signature handling in fast-import/export. It addresses a potential fragility in the test suite where hardcoded tag counts could break if new tests add more tags. The patch introduces a counter variable `ANNOTATED_TAG_COUNT` that gets incremented each time a test adds an annotated tag, then uses this counter for verification rather than fixed numbers.

The change affects four test cases in t9350-fast-export.sh that verify tag export behavior. While the patch is small and focused, it demonstrates good test hygiene by making the test suite more maintainable as new tag-related tests are added. The commit message clearly explains the change and its motivation, noting this prepares for upcoming tests that will add more tags.

This appears to be solid preparatory work for the larger signature handling series, though it's worth noting the actual signature-related changes come in later patches. The change is low-risk since it only affects test behavior without modifying production code.
