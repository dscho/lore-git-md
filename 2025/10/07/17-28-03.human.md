This is a brief follow-up in the ongoing Git 3.0 release planning discussion, specifically about ecosystem coordination for the SHA-256 transition. Michal Suchánek responds to Junio C Hamano's question about the status of dulwich (a pure Python Git implementation), noting that while its website appears unmaintained, the Git repository still shows activity. This comes as the thread expands its scope to track not just bindings like pygit2 (which inherit SHA-256 support from libgit2) but also standalone implementations that would need independent updates.

The exchange highlights the challenge of comprehensively identifying all affected projects in the ecosystem, with Michal pointing out dulwich's poor discoverability. This follows earlier discussion about including language bindings and forges in the coordination effort, showing the conversation is now drilling into specific implementation cases. The thread continues to balance technical progress with the practicalities of ecosystem-wide adoption.
