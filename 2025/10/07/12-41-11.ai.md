Refactoring patch in the packfile store API series, introducing a new iteration macro to reduce boilerplate when looping through packs.

This is part 5/6 of Taylor Blau and Patrick Steinhardt's series to clean up the packfile store API, following the removal of the deprecated `packfile_store_get_packs()` in the previous patch. The series has systematically converting callers to use `get_all_packs()` instead, and now introduces a new `packfile_store_for_each_pack()` macro to standardize the iteration pattern seen across 20 different files.

The macro replaces repetitive `for (p = packfile_store_get_all_packs(); p; p = p->next)` loops with a simpler `packfile_store_for_each_pack(store, p)` construct. The change is purely mechanical - no behavior changes - but reduces visual noise and potential for errors in the iteration pattern. The patch updates all relevant callers across builtins, pack operations, and test helpers.

Technical details show the macro is defined in packfile.h to wrap the existing `get_all_packs()` call while maintaining the same iteration semantics. The changes touch core pack operations (pack-bitmap, pack-objects), maintenance commands (gc, repack), and object lookup paths. The series continues its careful approach of incremental, focused changes to the pack subsystem with this quality-of-life improvement for pack iteration.
