This is a refactoring patch in Patrick Steinhardt's series on refs infrastructure improvements. It focuses on modernizing how reference status flags are handled in the codebase.

The patch converts the reference.flags field from an `int` to an `unsigned` type, aligning with Git's modern coding practices for bitfields. More significantly, it replaces the existing preprocessor `#define` constants with a proper `enum reference_status` that groups all flag definitions together with documentation. The flags themselves (REF_ISSYMREF, REF_ISPACKED, REF_ISBROKEN, REF_BAD_NAME) maintain their same meanings and bit positions, just now declared as enum values.

This change is part of the larger effort to clean up and standardize the refs iteration interfaces, building on the new `struct reference` introduced in patch 1/13. The enum approach provides better type safety and documentation grouping compared to scattered #defines. While purely a code quality improvement with no behavior change, it touches the fundamental reference handling infrastructure used throughout Git's refs subsystem. The patch is straightforward and well-contained, affecting only refs.h with mechanical changes to the flag declarations and their usage in `struct reference`.
