This is a refactoring patch that introduces a wrapper struct for the `each_ref_fn` callback function type used throughout Git's codebase. It's the first in a 13-part series aimed at cleaning up and optimizing Git's ref iteration and tag peeling interfaces.

The patch replaces direct callback parameters (refname, referent, oid, flags) with a single `struct reference` parameter containing all these fields. This change affects 48 files with 387 insertions and 454 deletions, showing the wide impact of the ref iteration interface.

The motivation is to reduce future churn when modifying the callback signature - instead of changing dozens of call sites, we can just extend the wrapper struct. The author acknowledges this makes the interface slightly more opaque, but notes there are only a handful of sites that actually populate the struct (ref backends and refs/iterator.c).
