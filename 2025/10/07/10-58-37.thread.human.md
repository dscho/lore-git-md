The work aims to clean up technical debt around ref iteration interfaces, fix inconsistencies in tag object verification, and optimize performance by avoiding unnecessary object parsing.

The first nine patches have introduced significant infrastructure changes: consolidating ref iterator fields into a new `struct reference`, modernizing reference status handling, and removing global state from the peeling process. - A new `PEEL_OBJECT_VERIFY_OBJECT_TYPE` flag for strict tag verification
- Removal of the `deref_tag_noverify()` function as its functionality is now covered by the flag
- Preservation of backward compatibility for existing callers
- Preparation for future patches to use stricter verification where appropriate
