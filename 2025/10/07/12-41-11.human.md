Refactoring patch introducing a new iteration macro for packfile operations. This is part 5/6 in a series by Patrick Steinhardt that's systematically cleaning up the packfile store API, following the removal of the problematic `packfile_store_get_packs()` function in the previous patch.

The patch introduces a new `packfile_store_for_each_pack()` macro to standardize iteration over packs in a packfile store, replacing repetitive manual loops with this cleaner abstraction. It updates 20 files across various builtin commands and core pack operations to use the new macro. The changes are mechanical but improve code readability by eliminating boilerplate while maintaining identical behavior.

This continues the series' methodical approach to pack subsystem cleanup, with all conversions appearing correct and well-tested. The macro will likely see more use as the series progresses toward its conclusion in the final patch. No new functionality is added - this is purely an internal code quality improvement.
