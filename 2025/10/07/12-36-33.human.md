This is part 5 of Patrick Steinhardt's series improving Rust CI infrastructure, focusing on establishing a minimum supported Rust version. The patch adds version validation to ensure Git's Rust code remains compatible with Rust 1.49.0, chosen to maintain compatibility with alternative Rust compilers like gccrs.

The changes introduce three key elements:
1. A `rust-version` field in Cargo.toml specifying 1.49.0 as the minimum
2. Installation of cargo-msrv (version pinned to 0.18.4 for Ubuntu compatibility) in the CI dependencies
3. A new CI check that verifies all code and dependencies work with the minimum version

The patch continues the series' pattern of methodically adding Rust infrastructure checks, this time addressing version compatibility. The project currently has no Rust dependencies, but this preemptively ensures future dependencies won't break compatibility target. The choice of Rust 1.49.0 reflects a conservative approach to maximize compiler compatibility.
