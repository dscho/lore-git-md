This is the final patch in Patrick Steinhardt's series adding Rust CI infrastructure, specifically addressing Windows support. The patch fixes two Windows-specific build issues: linking against `userenv.dll` for the required `GetUserProfileDirectoryW()` function, and handling the different library naming convention on Windows (`.lib` instead of `.a`). It also enables Rust testing on GitLab CI's Windows runners.

The changes span multiple build systems:
- Makefile now conditionally links `-luserenv` on Windows and handles the `.lib` vs `.a` library name difference
- Meson build system adds Windows-specific library dependencies
- `cargo-meson.sh` script is updated to handle Windows library naming
- GitLab CI configuration now installs Rust on Windows runners

The patch builds on prior work in the series by extending the Rust infrastructure to Windows, completing the cross-platform coverage. It references two previous patches from Johannes Schindelin and Ezekiel Newren as the basis for some changes. The implementation appears thorough, addressing both build system integration and CI configuration, though it doesn't include Windows-specific Rust tests which might be a future consideration.
