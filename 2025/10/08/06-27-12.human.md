CI optimization patch removing redundant `apt-get update` calls in the Rust infrastructure series. This first patch in Patrick Steinhardt's 6-part series cleans up the CI dependency installation process by eliminating duplicate package index updates that were happening across different job types. The change removes four redundant `apt-get update` calls from the `ci/install-dependencies.sh` script, since these updates are already performed in an earlier distro-specific step. This is a straightforward optimization that should slightly speed up CI runs without affecting functionality. The patch is small (just 4 lines removed) and focused, with a clear explanation of why the redundant calls can be safely removed. As the first step in a larger Rust infrastructure improvement series, this establishes a clean, efficient baseline for the subsequent more substantive changes.
