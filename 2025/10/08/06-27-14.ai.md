Rust safety documentation patch in the CI infrastructure series. This is patch 3/6 in Patrick Steinhardt's v2 series improving Rust support in Git's CI pipeline.

The patch adds Rust-style documentation comments to unsafe FFI functions `decode_varint()` and `encode_varint()` in src/varint.rs, which interface with C code. Each function now has:
- A description of its behavior and return values
- A `# Safety` section specifying preconditions (NUL-terminated buffer for decoding, minimum buffer size for encoding)
- Helpful notes about edge cases (overflow handling, null buffer behavior)

This change anticipates upcoming Clippy integration (patch 4/6) which would flag undocumented unsafe blocks. The documentation follows Rust conventions while maintaining compatibility with the existing C interface. The changes are purely additive - no behavior is modified - and the safety requirements match those already present in the C implementations these functions mirror. The patch builds on prior Rustification work by "brian m. carlson" who provided guidance on the changes.
