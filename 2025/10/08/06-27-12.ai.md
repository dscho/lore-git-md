CI optimization patch removing redundant `apt-get update` calls in the Rust CI workflow. This first patch in Patrick Steinhardt's 6-part series eliminates duplicate package index updates in `ci/install-dependencies.sh`, where job-specific dependency installations were unnecessarily refreshing the package list after the initial distro-wide update. The change affects ClangFormat, StaticAnalysis, sparse, and Documentation job configurations, removing four redundant update calls while maintaining all actual package installations. The modification is straightforward with a clear commit message explaining the optimization rationale. This appears to be a low-risk cleanup that should slightly speed up CI runs by avoiding repeated network operations, though the impact would be most noticeable in environments with slow package repository access. The patch follows the series' theme of streamlining Rust-related infrastructure while maintaining existing functionality.
