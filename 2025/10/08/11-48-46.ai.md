Documentation patch fixing accidental literal blocks in AsciiDoc formatting.

Kristoffer Haugsbakk submits a patch correcting indentation issues in several Git documentation files that were causing unintended literal blocks in the rendered output. The changes primarily involve removing excessive indentation from regular paragraphs and adding explicit `----` delimiters for intended literal blocks in `git-sparse-checkout.adoc`.

The patch affects five documentation files: `core.adoc`, `git-config.adoc`, `git-rev-parse.adoc`, `git-shortlog.adoc`, and `git-sparse-checkout.adoc`. The author notes they've systematically reviewed user-facing documentation while excluding technical docs (`howto/`, `technical/`, `gitprotocol*`) which have different formatting expectations.

The most substantial change is in `git-sparse-checkout.adoc` where example commands that were previously indented (creating literal blocks) are now properly marked with `----` delimiters. The author explains in the commit message that they've previously fixed similar issues ad-hoc but this time conducted a more thorough review.

The patch appears well-scoped and correctly implements its stated goal of fixing AsciiDoc formatting issues. The commit message provides clear rationale for both the changes made and the documentation files excluded from consideration. The changes are mechanical formatting fixes that don't affect the actual content of the documentation.
