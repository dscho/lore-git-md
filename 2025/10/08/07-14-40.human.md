This is a feature patch adding signed tag handling to `git fast-import`, completing the signature handling parity with `git fast-export` that was the focus of this series. Patrick Steinhardt reviews the implementation, focusing on documentation and code style details.

The patch introduces a `--signed-tags=<mode>` option for `git fast-import` with the same modes (verbatim, warn-verbatim, warn-strip, strip, abort) as the existing `--signed-commits` option, though with a different default (verbatim instead of abort). The implementation uses `parse_signed_buffer()` to detect and handle signatures consistently across formats (PGP, X.509, SSH).

Patrick's review notes several minor issues: the option documentation should be alphabetized after `--signed-commits`, an error message needs translation marking, and some fallthrough comments are misindented. He also asks a clarifying question about whether signatures always appear at the end of tag messages, though this appears to be a confirmation request rather than an objection to the approach.

The review suggests the patch is technically sound but needs minor polish before finalization. This continues the thread's pattern of thorough but constructive feedback on the signature handling implementation.
