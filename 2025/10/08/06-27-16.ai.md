This is part 5/6 of Patrick Steinhardt's series adding Rust infrastructure to Git's test suite, focusing on minimum version verification. The patch establishes Rust 1.49.0 as the minimum supported version (MSRV) for Git's Rust code and dependencies, chosen to maintain compatibility with older toolchains including potential alternatives like gccrs. It implements this through three key changes: adding the `rust-version` field to Cargo.toml, installing cargo-msrv 0.18.4 (the Ubuntu-compatible version) during CI setup, and adding MSRV verification to the Rust checks pipeline.

The implementation downloads and installs cargo-msrv as a binary during the RustAnalysis job setup, placing it in a custom PATH location. The new check runs `cargo msrv verify` to validate that all dependencies can satisfy the 1.49.0 requirement, failing the CI job if not. This maintains the series' pattern of adding Rust infrastructure in discrete, verifiable steps while keeping production code unchanged. The patch follows the established approach of the series by using standard Rust tooling (cargo-msrv) rather than custom solutions, and by pinning tool versions for reproducibility. The choice of Rust 1.49.0 reflects a conservative stance on version requirements while the project is still early in its Rust adoption.
