This is a documentation patch fixing formatting issues in several Git manual pages. Kristoffer Haugsbakk corrects accidental literal blocks in AsciiDoc documentation by removing improper indentation and adding explicit `----` delimiters where needed. The changes affect `core.adoc`, `git-config.adoc`, `git-rev-parse.adoc`, `git-shortlog.adoc`, and `git-sparse-checkout.adoc`.

The patch focuses on user-facing documentation, explicitly noting that technical documentation (howto/ and technical/ directories) and protocol docs were not considered, as they appear to have different formatting standards. The most substantial change is in `git-sparse-checkout.adoc`, where indented examples are converted to proper AsciiDoc literal blocks with `----` markers.

The author notes this is a systematic cleanup rather than random fixes, suggesting they've reviewed the documentation for these issues. The changes are straightforward and non-controversial, improving readability without altering content. The commit message provides clear rationale for both the changes made and the exclusions.
