This is a refactoring patch in Patrick Steinhardt's ongoing series modernizing Git's refs subsystem, specifically focusing on reference status flags. The patch converts the reference flag system from using preprocessor defines to an enum and changes the flags field from `int` to `unsigned` to align with modern Git coding practices.

The changes are straightforward but important for code quality:
1. Replaces `#define` macros with properly scoped `enum reference_status` values
2. Changes the `flags` field in `struct reference` from `int` to `unsigned`
3. Maintains all existing flag values (REF_ISSYMREF, REF_ISPACKED, REF_ISBROKEN, REF_BAD_NAME) with the same bit positions
4. Adds documentation comments for each flag value

This is part of the larger refactoring effort to clean up technical debt in the refs subsystem, with this particular patch focusing on type safety and code organization. The change is performance-neutral and has already been reviewed as part of the merge-ready series, with no outstanding concerns about the implementation. The patch demonstrates the series' attention to modernizing both the high-level architecture and low-level implementation details of the refs code.
