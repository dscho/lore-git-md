This is a documentation patch in Christian Couder's series to modernize Git's tag signing documentation to be format-agnostic, moving away from GPG-specific terminology. The patch responds to Patrick Steinhardt's review of the initial submission.

The main change replaces GPG references with more general "signature" language throughout `git-tag` documentation, though Patrick suggests using "cryptographic signature" in key places for precision. Christian agrees to make this adjustment but questions whether repeating "cryptographic" everywhere is necessary versus using it selectively for initial clarity.

Patrick also proposes using bullet points to list signature formats (OpenPGP, X.509, SSH) in the configuration section, but Christian prefers keeping the current brief reference style that defers details to git-config(1). The discussion shows careful attention to balancing technical accuracy with readability, with both contributors agreeing on the core improvement while working through presentation nuances.

This is a straightforward documentation update that aligns with the series' goal of supporting multiple signature types equally. The changes are uncontroversial and address Patrick's review feedback, with only minor wording details remaining to be resolved in the next version.
