This is a test infrastructure patch in the context of the `--signed-tags` series for `git fast-import`. Patrick Steinhardt is reviewing Christian Couder's change to `t/lib-gpg.sh` that makes the GPG test directory creation more robust by using `mkdir -p`.

The change itself is minor - just adding the `-p` flag to ensure parent directories are created if needed. Patrick raises a good question about whether this manual directory creation is even necessary, noting that the GPGSM prereq doesn't require it as gpgsm handles directory creation automatically. He wonders if `gpg --homedir` might similarly create its own directory.

This is a small but thoughtful review point in the larger effort to improve signature handling in fast-import/export. The discussion here could lead to either keeping the more robust `mkdir -p` approach or potentially removing the manual directory creation entirely if gpg can handle it.
