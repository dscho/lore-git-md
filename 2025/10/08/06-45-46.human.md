Build system patch proposing additional linting for documentation consistency between Makefile and meson builds. This is a follow-up to the ongoing documentation formatting series, focusing on ensuring all technical docs are processed by both build systems.

Patrick Steinhardt suggests extending the existing `lint-docs-meson` check to also verify that technical documentation articles (`.adoc` files) are properly listed in meson.build. His proposed change would catch discrepancies like the currently missing `large-object-promisors.adoc` file. The patch includes a diff showing how to modify the Makefile to compare meson's article list against actual files in the technical directory.

The email notes two remaining gaps in the checking: no equivalent verification in meson.build itself, and no cross-check between Makefile and meson configurations. These are acknowledged as future work rather than blockers for the current proposal. The change appears well-motivated by the recent effort to align documentation processing across build systems, and the implementation looks straightforward, building on existing linting patterns.
