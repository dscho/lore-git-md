This is the final patch in Julia Evans' documentation series improving the `git-pull` man page, focusing on conflict resolution guidance. The patch modernizes the instructions for aborting a conflicted merge or rebase, replacing outdated advice about `git reset --merge` with clearer recommendations to use `git merge --abort` or `git rebase --abort`. It also removes a 15-year-old warning about older Git versions that was causing confusion for current users.

The changes are straightforward: 9 lines of old text removed and 3 new lines added, making the documentation both more concise and more actionable. The patch addresses specific user feedback about confusing terminology and outdated version warnings. This completes the series' goal of clarifying common pain points in the `git-pull` documentation while maintaining technical accuracy.
