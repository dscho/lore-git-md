This is part 6 of Patrick Steinhardt's 14-part series modernizing Git's ref iteration and tag peeling infrastructure, now merge-ready with reviews from Taylor Blau and Junio Hamano. The patch converts `upload-pack.c` to use the new `reference_get_peeled_oid()` API introduced earlier in the series, eliminating its dependency on the global `peel_iterated_oid()` function.

The change refactors `write_v0_ref()` to consistently use `struct reference` throughout, including for the special case of capability announcement where previously it was handling raw OIDs. This required constructing a temporary reference struct when announcing capabilities, but the change is straightforward and maintains the same behavior while aligning with the series' goal of removing global state.

The patch demonstrates how the new reference API simplifies callers by providing a more consistent interface - a key benefit of the overall series. Since this is a mechanical conversion of a well-understood component and follows the architectural direction already approved by reviewers, it should merge cleanly as part of the validated series.
