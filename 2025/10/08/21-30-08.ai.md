Security discussion follow-up regarding submodule trust propagation. Taylor Blau raises important questions about how the proposed security token system would handle recursive submodule clones. The core concern is whether tokens would propagate to submodules - if not, users would still need manual verification for submodules, potentially undermining the claimed benefit of eliminating trust prompts. Blau specifically questions whether the proposal assumes tokens won't be copied to recursively cloned submodules, which would shift rather than eliminate the trust decision burden. This exposes a potential gap in the original proposal's claim to maintain all existing functionality while improving security. The exchange highlights a key technical detail that needs clarification - whether and how the token system would handle transitive trust relationships in submodule graphs. This could significantly impact both the security model and user experience of the proposal.
