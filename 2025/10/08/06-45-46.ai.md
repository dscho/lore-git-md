Build system patch proposing additional linting checks for documentation consistency between Makefile and meson builds. This follows up on the ongoing documentation formatting series by Patrick Steinhardt, who notices that while the Makefile was updated to include technical documentation files, the meson build's linting rules don't fully verify article consistency.

The patch adds two key components to the `lint-docs-meson` target:
1. Extends the awk script to also parse the `articles` list from `technical/meson.build`
2. Includes technical documentation files in the actual files check by listing `technical/*.adoc` and processing them through basename

The change reveals one undocumented file (`large-object-promisors.adoc`) that exists in the tree but isn't listed in meson.build. Patrick notes two remaining gaps in the checking:
- No equivalent article check in Documentation/meson.build
- No cross-check between Makefile and meson article lists

This builds on the thread's theme of documentation build parity, shifting focus from formatting to build system consistency checks. The change is mechanical but surfaces real inconsistencies, suggesting the linting infrastructure could benefit from more comprehensive cross-build verification. The patch appears well-targeted to catch documentation drift between build systems, though it leaves some verification gaps unaddressed.
