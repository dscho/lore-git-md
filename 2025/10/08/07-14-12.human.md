This is a documentation patch in Christian Couder's series adding signature handling parity between `git fast-import` and `git fast-export`. Patrick Steinhardt is reviewing the first patch, which updates the `git-tag` documentation to be more inclusive of all supported signing methods (PGP, X.509, SSH) rather than focusing solely on GPG.

The patch modernizes the man page to use generic "signed tag" terminology instead of "GPG-signed tag" throughout, and properly documents how the `gpg.format` configuration variable controls the signing backend. Patrick generally approves of the changes but suggests a few minor tweaks: consistently using "cryptographic signature" terminology and considering whether to use a bulleted list for the supported formats or simply refer to git-config(1).

The review is positive overall, with Patrick calling it "an obvious improvement" that makes sense given Git's expanded signature support beyond just GPG. This is groundwork for the larger series that will implement matching signature handling in the fast-import/export commands.
