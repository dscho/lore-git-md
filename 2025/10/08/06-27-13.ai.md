Rust CI infrastructure patch (part 2/6) adding formatting enforcement. This patch introduces automated Rust code formatting checks to CI using `cargo fmt`, the standard Rust formatting tool. The changes:

1. Adds new "RustAnalysis" jobs to both GitHub Actions and GitLab CI that run the formatting check
2. Updates ci/install-dependencies.sh to install rustup and rustfmt
3. Creates a new ci/run-rust-checks.sh script that executes the formatting verification

The patch follows Rust ecosystem conventions by using rustfmt's default style (derived from the Cargo.toml edition) rather than customizing formatting rules. This ensures consistency with other Rust projects while avoiding style debates. The implementation is straightforward, adding the standard Rust tooling to CI without modifying any existing Rust source files. As part of the larger Rust infrastructure series, this establishes baseline code quality checks before more substantive Rust changes land. The approach mirrors Git's existing static analysis CI jobs but for the Rust codebase.
