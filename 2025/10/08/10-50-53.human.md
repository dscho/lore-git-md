This is the final patch in a series implementing `--signed-tags=<mode>` for `git fast-import`, bringing it to parity with `git fast-export`'s signature handling. Christian Couder addresses Patrick Steinhardt's final review comments on documentation ordering, translation marking, and code style.

The patch adds the new option with the same modes as fast-export (verbatim, warn-verbatim, warn-strip, strip, abort) but defaults to verbatim instead of abort. Christian explains his rationale for keeping the documentation ordering (matching fast-export and historical precedent) rather than alphabetizing with `--commits`. He also confirms the signature stripping implementation is correct - Git always appends signatures to tag messages, making end-of-buffer truncation safe.

Minor fixes promised for v2 include marking error messages for translation and fixing indentation of fallthrough comments. The technical approach has Patrick's approval, with only these small style issues remaining. This completes the series' goal of consistent signature handling across both commands, supporting PGP, X.509 and SSH signatures uniformly.
