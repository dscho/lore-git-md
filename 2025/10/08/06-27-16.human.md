This is part 5/6 in Patrick Steinhardt's series improving Rust CI infrastructure, focusing on minimum version verification. The patch establishes Rust 1.49.0 as the minimum supported version (MSRV) for Git's Rust code, chosen to maintain compatibility with older toolchains and potentially enable alternative Rust compilers like gccrs sooner.

The changes add the MSRV declaration to Cargo.toml and implement CI verification using cargo-msrv (pinned to v0.18.4 for Ubuntu compatibility). The tool will verify that all current and future dependencies can build with Rust 1.49.0. This is a proactive measure since Git currently has no Rust dependencies, but establishes important guardrails for future development.

The implementation follows the series' pattern of adding Rust-specific checks while maintaining existing workflows. The cargo-msrv installation and verification are integrated into the RustAnalysis CI job alongside the previously added rustfmt and clippy checks from earlier patches in the series. The patch appears straightforward and well-contained, continuing the series' focus on establishing robust Rust development practices.
