This is a refactoring patch in Patrick Steinhardt's ongoing series to modernize Git's refs subsystem, specifically focusing on reference status flags. The patch converts the reference flag system from using preprocessor defines to a proper enum type, while also changing the underlying storage from `int` to `unsigned` to follow modern coding conventions.

The changes are straightforward and mechanical: the existing `#define` flags for symbolic references (`REF_ISSYMREF`), packed references (`REF_ISPACKED`), broken references (`REF_ISBROKEN`), and malformed names (`REF_BAD_NAME`) are converted to an enum. The patch updates the `flags` field in `struct reference` to use this new enum type and changes its storage to `unsigned`.

This is part of a larger effort (now at 14 patches) that has already received extensive review and is nearly ready, with the first 7 patches confirmed merge-ready by Junio Hamano. The changes here are uncontroversial and align with the series' goals of cleaning up technical debt in the refs subsystem while maintaining performance. The patch follows the established pattern of the series by making incremental improvements to the codebase's maintainability without changing behavior.
