This is a refactoring patch in Patrick Steinhardt's series modernizing Git's ref iteration and tag peeling infrastructure. It removes the `current_ref_iter` global variable and associated `peel_iterated_oid()` function, which were previously used as a performance optimization hack to avoid redundant object lookups during ref iteration.

The change builds on earlier patches that introduced `struct reference` to propagate peeled object IDs through the refs subsystem. With that infrastructure in place, the global variable is no longer needed, making the code both more robust and easier to understand. The patch removes the variable and supporting code from three files while maintaining all existing functionality.

This is part of a well-reviewed series that has already seen significant technical discussion and validation from multiple maintainers. The removal of global state aligns with Git's ongoing architectural improvements and follows naturally from the refactoring work done in previous patches. The change is straightforward and low-risk, touching only internal refs infrastructure code.
