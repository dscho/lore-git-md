This is part 4 of a 6-patch series introducing CI infrastructure for Rust development in Git. The patch adds Clippy, Rust's official static analyzer, to the CI pipeline to catch common mistakes and suggest code improvements.

The change is straightforward: it installs Clippy alongside rustfmt in the RustAnalysis CI job and adds a new check that runs `cargo clippy` with warnings treated as errors. This follows the same pattern as the Rust formatting check added in earlier patches, maintaining consistency in how Rust code quality is enforced.

As part of the broader Rust infrastructure effort, this patch represents a logical step in the progression from basic formatting (patch 2) to more sophisticated static analysis. The implementation is clean and minimal, with just two small changes needed to integrate Clippy into the existing Rust CI setup. The patch continues the series' theme of bringing Git's Rust development practices in line with standard Rust ecosystem tooling.
