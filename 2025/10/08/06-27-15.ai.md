This is part 4/6 of Patrick Steinhardt's CI infrastructure improvements for Rust support series, focusing on static analysis integration. The patch adds Clippy linting to the Rust CI pipeline, complementing the rustfmt formatting check introduced earlier in the series.

The changes are minimal but impactful: the RustAnalysis job in ci/install-dependencies.sh now installs clippy alongside rustfmt, and ci/run-rust-checks.sh gains a new check that runs `cargo clippy` with strict warning settings (`-Dwarnings`). The implementation follows Rust ecosystem conventions by using Clippy's default configuration rather than custom rules, consistent with the series' approach to Rust tooling.

This patch builds directly on the infrastructure established in earlier patches of the series, particularly the RustAnalysis CI job framework. It represents a logical next step after code formatting enforcement, addressing another key aspect of Rust code quality. The change is low-risk as it only affects the build system and doesn't modify any production code. The `-Dwarnings` flag ensures all Clippy lints are treated as errors, maintaining Git's existing strict CI standards for static analysis.
