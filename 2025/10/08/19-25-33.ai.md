This is the first patch in Julia Evans' v2 documentation series improving `git-pull` man page clarity. It restructures parameter documentation by moving the `<repository>` and `<refspec>` descriptions from the DESCRIPTION section to the OPTIONS section, addressing user confusion about terminology and parameter usage.

The changes focus on three key improvements: replacing ambiguous "remote" and "merge" configuration references with clearer "upstream" terminology, providing better cross-references to related sections (particularly the UPSTREAM BRANCHES and DEFAULT BEHAVIOUR sections), and separating the parameter documentation from the high-level behavior description. The patch modifies both `git-pull.adoc` and `pull-fetch-param.adoc`, adding an anchor (`[[fetch-refspec]]`) to enable direct linking to the refspec documentation.

Technical details include: the `<repository>` parameter now explicitly mentions URL and remote name options with links to URLS/REMOTES sections, while `<refspec>` gets expanded examples and clearer default behavior explanation. The changes maintain backward compatibility while improving pedagogical flow, moving complex parameter syntax details out of the introductory DESCRIPTION section. This sets up subsequent patches to focus on integration strategies and conflict resolution without parameter documentation cluttering the high-level overview.
