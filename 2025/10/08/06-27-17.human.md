This is the final patch in Patrick Steinhardt's series improving Rust CI infrastructure, specifically adding Windows support. The patch addresses two key issues preventing Git's Rust code from building on Windows: missing linkage against `userenv.dll` (needed for `GetUserProfileDirectoryW()`) and incorrect library path handling for Windows' different naming conventions (`gitcore.lib` vs `libgitcore.a`).

The patch makes platform-specific adjustments across the build system:
- Adds `-luserenv` to linker flags on Windows
- Handles Windows' different static library naming convention in Makefile
- Updates Meson build to find the Windows userenv library
- Modifies the cargo-meson.sh script to handle platform-specific library names
- Enables Rust testing on Windows in GitLab CI by installing the Rust toolchain

The changes are straightforward and build on prior work from Johannes Schindelin and Ezekiel Newren. The patch completes the series' goal of comprehensive Rust support across platforms while maintaining the conservative approach seen in earlier patches - here by using standard platform conventions rather than inventing new ones.
