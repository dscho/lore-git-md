CI infrastructure patch adding Rust code formatting checks. This is the second in Patrick Steinhardt's 6-part series improving Git's Rust development workflow.

The patch introduces CI jobs (for both GitHub Actions and GitLab CI) that verify Rust code formatting using `cargo fmt`, the standard Rust formatting tool. The implementation follows Rust ecosystem conventions by using the default style from the project's specified Rust edition (defined in Cargo.toml) rather than customizing formatting rules. This ensures consistency with other Rust projects while avoiding style debates.

The changes add a new "RustAnalysis" job that installs rustup and rustfmt, then runs the formatting check via a new `ci/run-rust-checks.sh` script. The approach is straightforward and aligns with existing CI patterns in the project. As with the rest of the series, this is a low-risk infrastructure improvement that establishes baseline quality controls as Git's Rust codebase grows.
