This is a documentation patch in an ongoing series about signature handling in Git. Patrick Steinhardt is reviewing Christian Couder's first patch which updates the `git-tag` documentation to be more inclusive of all signature types (PGP, X.509, SSH) rather than focusing solely on GPG.

The review suggests several small improvements to maintain consistency in terminology, recommending "cryptographic signature" instead of just "signature" in several places for clarity. Patrick also considers whether listing all supported formats in a bulleted list would be helpful, but acknowledges that referring to git-config(1) might be sufficient since the information is centralized there.

The changes align with the series' goal of modernizing Git's documentation and infrastructure to properly support all signature types. Patrick approves the overall direction of the patch while offering minor wording suggestions. The review maintains the technical focus on signature handling while considering documentation clarity and maintainability.
