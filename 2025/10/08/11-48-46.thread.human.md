Kristoffer Haugsbakk has submitted a documentation patch fixing AsciiDoc formatting issues in several Git man pages. The changes correct accidental literal blocks caused by incorrect indentation, primarily in `git-sparse-checkout.adoc` where example commands are now properly delimited with `----` markers. The patch also touches four other documentation files (`core.adoc`, `git-config.adoc`, `git-rev-parse.adoc`, and `git-shortlog.adoc`) with similar mechanical formatting fixes.

The author notes this is part of a systematic review of user-facing documentation, deliberately excluding technical documentation which follows different formatting conventions. The changes are purely presentational and don't affect the actual content of the documentation. This appears to be a straightforward, well-scoped improvement to the documentation's rendering quality.
