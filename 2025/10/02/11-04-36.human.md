This is a CI/build system patch that's part of a 5-part series improving Windows CI reliability. The first patch focuses on cleaning up duplicate configuration in GitLab's CI setup.

Patrick Steinhardt removes repeated instructions to disable Windows Defender's realtime monitoring across multiple Windows-based CI jobs, consolidating them into a single YAML anchor (`windows_before_script`).

The change is straightforward - it replaces three identical PowerShell commands with references to a shared definition. This makes future maintenance easier since the setting only needs to be updated in one place. The patch is small (9 lines changed) and focused purely on CI configuration, with no impact on Git's actual code or behavior.

As the first in a series, this sets up for more substantial Windows CI improvements to follow. The clean organization suggests the author is taking a methodical approach to the overall CI cleanup effort.
