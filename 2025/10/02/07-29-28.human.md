This is part of the Rust infrastructure series (patch 3/9), introducing Makefile support for building Git's internal library with Rust code. The patch adds conditional compilation support via a new `WITH_RUST` flag, mirroring the Meson support added in previous patches.

The changes include:
- Adding Rust build artifacts (`/target/`, `Cargo.lock`) to `.gitignore`
- Introducing a `RUST_SOURCES` variable and build rules for `libgitcore.a`
- Setting up quiet build output for Cargo matching Git's existing build verbosity
- Adding clean target support for Rust artifacts
- Conditionally linking the Rust library when `WITH_RUST` is enabled

The implementation follows Git's existing build patterns while adding Rust-specific handling. The patch is well-integrated with the existing Makefile infrastructure and includes proper cleanup rules. This is a foundational piece of the larger effort to introduce Rust into Git's core, with the varint implementation (patch 6) being the first consumer of this infrastructure. The changes are straightforward and appear technically sound, building on Ezekiel Newren's earlier input about Windows/MSVC compatibility.
