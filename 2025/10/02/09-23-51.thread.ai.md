Interactive add bug report summary:

Ulrich Windl reports a regression in `git add --interactive` hunk selection behavior in Git 2.51.0 (Linux, GCC 7.5, glibc 2.38). The issue manifests when using the "J" (join) command after mixed "y"/"n" responses - the interface incorrectly prompts again for both the joined hunk and previously rejected hunks, unlike the expected behavior in Git 2.26.2 where only the joined hunk would be queried. The bug appears in the hunk selection logic's handling of joined hunks in relation to prior rejections, though exact reproduction conditions (file types, diff contexts) remain unspecified. No patch or analysis of the underlying cause is provided in this initial report.
