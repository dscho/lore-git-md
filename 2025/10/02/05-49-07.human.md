This is a follow-up discussion on the refactoring of Git's build system to consolidate static libraries.

Patrick Steinhardt responds to the third patch in Ezekiel Newren's series, which removes REFTABLE_LIB and folds reftable objects directly into LIB_OBJS. He raises the same question he did for the xdiff changes in patch 2/3: whether maintaining REFTABLE_OBJS as a separate variable still makes sense now that the objects are being added directly to LIB_OBJS. 

The question suggests the refactoring could potentially go further by eliminating the intermediate object list variables entirely. Patrick otherwise approves of the changes, noting they simplify the build infrastructure regardless of Rust integration plans. His positive feedback indicates the technical approach is sound, with the only open question being whether the cleanup could be more thorough.

The exchange shows the series is nearing acceptance, with only minor documentation/cleanup considerations remaining before it can be merged. The changes remain purely build-system focused with no impact on reftable functionality itself.
