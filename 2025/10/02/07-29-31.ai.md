This is the Rust implementation patch in Patrick Steinhardt's v8 series introducing Rust infrastructure to Git core, specifically converting the varint subsystem to Rust as a proof-of-concept. The patch demonstrates mixed C/Rust compilation by replacing `varint.c` with `src/varint.rs` when Rust support is enabled via `WITH_RUST`.

The Rust implementation provides identical `decode_varint` and `encode_varint` functions with the same C ABI interface, maintaining bit-for-bit compatibility with the C version. The implementation includes comprehensive test cases validating edge cases including overflow behavior. Build system changes conditionally exclude `varint.c` when Rust is enabled, with both Makefile and Meson build systems updated to handle the Rust source file.

Key technical details for future reference:
- The Rust module is exposed via `pub mod varint` in `src/lib.rs`
- FFI functions use `#[no_mangle]` and `extern "C"` for C compatibility
- Integer handling matches the standardized `uint64_t`/`uint8_t` types from earlier patches
- Tests verify all boundary conditions including multi-byte encoding and overflow cases
- Build system changes maintain backward compatibility when Rust is disabled

This serves as the first concrete demonstration of Rust code in Git's core, chosen for its simplicity and isolation from other subsystems. The implementation shows the technical viability of the Rust integration approach while maintaining identical behavior to the C version.
