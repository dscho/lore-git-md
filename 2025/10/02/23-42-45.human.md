This is a follow-up discussion in the atomic ref updates patch series for `git replay`. The email focuses on implementation details and design decisions for the upcoming v3 revision.

4. Commit message: The v3 will incorporate Elijah's suggested rewrite of the commit message to better explain the rationale for making atomic updates the default behavior.
