This is the v2 version of Ezekiel Newren's build system refactoring series to consolidate xdiff and reftable functionality directly into libgit.a. The changes follow up on earlier discussion where Junio Hamano confirmed this approach matches meson's behavior and is the preferred solution.

The key changes in v2 are:
1. Directly adding xdiff and reftable objects to LIB_OBJS rather than maintaining separate XDIFF_OBJS/REFTABLE_OBJS variables
2. Removing the now-obsolete xdiff-objs make target with explanation
3. Cleaning up related Makefile references to the old library variables

The series has already been reviewed and approved in principle, with this version implementing the final agreed-upon approach. The changes simplify Git's build system by eliminating intermediate static libraries while maintaining compatibility with meson's existing behavior. The motivation remains preparing for future Rust integration by providing a single linkage target (libgit.a), though the changes are valuable build improvements on their own.

The patch series shows careful attention to detail, with thorough commit messages explaining each change and its rationale. The range-diff demonstrates clean evolution from v1 to v2 implementation. With reviewer consensus already established and the changes successfully merged into 'seen', this appears ready for final testing before potential promotion to main.
