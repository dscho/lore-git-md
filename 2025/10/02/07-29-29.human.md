This is a build system patch that adds Rust build status reporting to Git's version information. As part of the ongoing Rust infrastructure series (now at 9 patches in v8), this change makes it easier to diagnose Rust-related issues by exposing whether the current Git build has Rust support enabled.

The patch adds a simple conditional check in `help.c` that reports "rust: enabled" or "rust: disabled" in both `git version --build-options` output and `git bugreport` data. This will help identify Rust-specific bugs during the phased transition period where some subsystems may have both C and Rust implementations.

The change is straightforward and well-justified - during a transitional period where behavior could differ between Rust and non-Rust builds, having this information readily available in diagnostic outputs will make troubleshooting easier. The implementation is minimal (6 lines added) and follows the existing pattern used for other build features like fsmonitor.

This patch fits cleanly into the larger Rust infrastructure effort, providing visibility into build configurations as the project begins mixing C and Rust code. The series as a whole has received extensive review and appears ready for merging, with this being one of the final preparatory steps before introducing actual Rust code.
