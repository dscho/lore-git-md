This is a bugfix and documentation patch in the SHA-1/SHA-256 interoperability series, specifically addressing GPG signature validation in tags. The patch ensures `fsck` properly handles `gpgsig` and `gpgsig-sha256` headers in tag objects, which is important for hash algorithm compatibility.

The changes add explicit validation for GPG signature headers in tags, fixing cases where strict checking would incorrectly flag valid signature headers. The patch documents two new fsck message IDs (`badGpgsig` and `badHeaderContinuation`) and includes comprehensive tests showing both valid and invalid cases.

The implementation carefully checks for proper header formatting and continuation lines, while the tests verify behavior with both SHA-1 and SHA-256 signatures. This appears to be a well-constructed patch with thorough test coverage, addressing a specific edge case in the broader hash transition work. The changes align with Git's existing tag signature handling since 2.29, where signatures for both algorithms may appear in tags.
