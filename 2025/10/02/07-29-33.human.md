CI modernization patch in the Rust infrastructure series. This is the 8th of 9 patches in v8, converting an obsolete "pedantic" CI job into a more useful test of Meson builds with breaking changes enabled on Fedora.

The patch repurposes the Fedora-based pedantic job (which became redundant after pedantic checks were enabled by default) to instead validate two key aspects: Meson builds with breaking changes enabled, and (in a follow-up) Rust compilation. This plugs testing gaps by adding Fedora coverage for these scenarios, complementing the existing Ubuntu-based breaking changes tests.

The changes modify CI configuration files to replace the pedantic job with a new `fedora-breaking-changes-meson` job, update dependency installation to include Meson/Ninja on Fedora, and ensure tests run in all Meson-based jobs. The patch demonstrates careful attention to CI coverage as the Rust integration progresses, ensuring both Makefile and Meson build paths are validated across multiple distros.

This is part of the broader Rust infrastructure effort that's now signaled as merge-ready by Junio Hamano, with the varint subsystem implementation and policy documentation already in place from earlier patches. The CI modernization here helps validate the practical deployment aspects of that work.
