Feature and refactoring patch introducing Rust infrastructure via varint subsystem replacement.

This patch (6/9 in the v8 series) implements the first Rust component in Git core by replacing the varint encoding/decoding subsystem. The varint implementation was chosen as a test balloon because it's self-contained and has no dependencies on other Git components. When Rust support is enabled via `WITH_RUST`, the build system now compiles `src/varint.rs` instead of the C version in `varint.c`.

The Rust implementation provides identical functionality to the C version, with matching `decode_varint` and `encode_varint` functions exposed via FFI. The patch includes comprehensive tests verifying edge cases like overflow handling. Build system changes affect both Makefile and Meson configurations, with the Rust version becoming the default when Rust is enabled.

This serves as a practical demonstration of the mixed C/Rust compilation approach proposed in the larger series. The implementation appears clean and well-tested, with careful attention to maintaining the exact same behavior as the C version. As noted in the thread context, this patch has already received positive feedback from Junio Hamano and is considered merge-ready. It represents a significant milestone in the Rust integration effort by proving the first working example of Rust code in Git's core.
