This thread documents a 4-part patch series addressing asciidoc formatting issues in Git's technical documentation, with the goal of achieving parity between Makefile-built and meson-built outputs. The series focuses on three key documentation files: `commit-graph.adoc`, `sparse-checkout.adoc`, and `remembering-renames.adoc`.

The patches systematically fix various formatting problems including incorrect list numbering (changing 0-based to 1-based), section heading level inconsistencies, improper monospaced text rendering, URL encoding issues, and ASCII diagram display problems. The final patch specifically targets `commit-graph.adoc`, converting markdown-style headers to proper asciidoc syntax and fixing code block formatting. 

While the series resolves many immediate rendering issues, the author notes some remaining challenges with monospaced text and URL encoding that may require input from asciidoc experts. The changes are purely mechanical syntax updates that preserve all technical content while improving cross-toolchain compatibility between asciidoc and asciidoctor. This work represents incremental progress toward the larger goal of documentation build system parity.
