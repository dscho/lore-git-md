CI / build system patch (4/5 in series) that adds JUnit test report artifacts for Meson-based test runs in GitLab CI. This change makes test failures more visible by uploading structured JUnit XML reports alongside existing failure artifacts. The patch modifies three job definitions (`test:linux`, `test:osx`, and `test:msvc-meson`) to declare the JUnit report location, with GitLab CI gracefully handling cases where reports don't exist (like in non-Meson jobs). The author notes this improves debuggability by preserving test execution details that were previously discarded. The change is straightforward - just 7 lines added to `.gitlab-ci.yml` - and fits cleanly into the series' theme of Windows CI improvements, though it also benefits Linux/OSX test visibility. No functional changes to test execution itself, just enhanced reporting of results. The patch follows the series' pattern of practical, focused CI enhancements validated via GitLab pipeline runs.
