This is a build system refactoring patch that removes the separate XDIFF_LIB static library and folds xdiff object files directly into libgit.a. It's part of a larger effort to simplify Git's build system and prepare for Rust integration.

The patch eliminates the XDIFF_LIB variable and related build rules, instead listing all xdiff/*.o files directly in LIB_OBJS. This matches meson's existing behavior and removes intermediate build steps. The change also removes the xdiff-objs convenience target since it depended on the now-removed XDIFF_OBJS variable.

Key technical changes include:
- Deletion of XDIFF_LIB and all related build rules
- Direct inclusion of xdiff/*.o files in LIB_OBJS
- Removal of xdiff-objs target
- Updates to GITLIBS to no longer include XDIFF_LIB
- Cleanup of various Makefile rules and clean targets

The patch maintains identical functionality while simplifying the build process. It's the first of two patches in this series, with the second handling similar changes for REFTABLE_LIB. The changes have already been reviewed and approved, with this approach matching meson's behavior and being independently valuable regardless of future Rust integration plans.
