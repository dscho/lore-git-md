This is the final patch in the Rust infrastructure series, focusing on CI modernization. It enables Rust compilation in the breaking-changes CI jobs to validate the new build infrastructure and Rust subsystem integration.

The patch makes two straightforward changes: it adds the Rust toolchain to dependency installations across Fedora and Ubuntu/Debian CI environments, and ensures the breaking-changes jobs pass the appropriate Rust-related flags to both the Makefile and Meson build systems. This completes the CI validation path for the Rust integration work.

As the capstone to the v8 series, this patch ensures the Rust infrastructure will be automatically tested alongside other breaking changes in CI. The changes are minimal but critical for verifying the real-world viability of the Rust integration approach demonstrated in the varint subsystem. With this in place, the series now provides end-to-end validation from build system support through to runtime behavior verification.
