Build system refactoring finalizing the consolidation of xdiff and reftable into libgit.a. This v2 series implements the direct inclusion approach that was preferred in the v1 discussion, where XDIFF_OBJS and REFTABLE_OBJS are folded directly into LIB_OBJS rather than maintaining separate static libraries.

The key changes in v2 are:
1. Explicitly listing all xdiff and reftable object files in LIB_OBJS rather than using the intermediate *_OBJS variables
2. Removing the now-obsolete xdiff-objs make target since it depended on XDIFF_OBJS
3. Updating GITLIBS to remove references to the eliminated XDIFF_LIB and REFTABLE_LIB

The changes align the Makefile build with meson's existing behavior where these components are already part of libgit.a. The motivation remains simplifying future Rust integration by providing a single static library target, though the changes are independently valuable build system improvements. The series has already been reviewed and approved in principle during v1 discussion, with Junio Hamano specifically confirming the direct LIB_OBJS inclusion approach.

Technical details:
- Makefile modifications remove XDIFF_LIB and REFTABLE_LIB completely
- All xdiff/*.o and reftable/*.o files are now listed directly in LIB_OBJS
- GITLIBS definition simplified to just common-main.o and LIB_FILE
- xdiff-objs target removed as it no longer has meaning
- No functional changes to xdiff or reftable behavior
- Build output remains identical, only the intermediate artifacts change

The series is now in its final form after incorporating feedback from v1, with all technical questions resolved and the changes already merged into the 'seen' branch. The v2 updates primarily document the rationale for removing xdiff-objs and implement the direct inclusion approach that was agreed upon during review.
