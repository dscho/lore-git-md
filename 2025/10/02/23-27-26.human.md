Build system refactoring to consolidate xdiff into libgit.a.

This is the first of two patches in a series that restructures Git's build system to eliminate separate static libraries for xdiff and reftable functionality, instead including them directly in libgit.a. The change matches meson's behavior and supports future Rust integration.

The patch removes the XDIFF_LIB static library and moves all xdiff object files directly into LIB_OBJS. This simplifies the build process by removing intermediate artifacts and reducing linkage complexity. The change also removes the now-obsolete xdiff-objs make target and updates GITLIBS to no longer reference XDIFF_LIB.

The commit message notes this change is preparatory work for Rust integration (to avoid name conflicts with a future xdiff Rust crate), but the build simplification stands on its own merits. The meson build system already works this way, so no meson changes are needed.

This appears to be a well-considered change that has already been reviewed and approved by key maintainers. The patch is part of a completed effort that has been merged into the 'seen' branch for final testing. The changes are straightforward build system improvements that don't affect runtime behavior.
