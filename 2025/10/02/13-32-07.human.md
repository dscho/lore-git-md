Build system refactoring completing the libgit.a consolidation. This is the final patch in Ezekiel Newren's series to simplify Git's static library build process by removing REFTABLE_LIB and folding its objects directly into LIB_OBJS, matching how meson already handles these dependencies.

The change follows the same pattern as the previous xdiff consolidation, removing the separate REFTABLE_LIB while keeping the REFTABLE_OBJS variable for organizational purposes. Patrick Steinhardt again questions whether the intermediate *_OBJS variables are still needed, with Junio Hamano confirming the same rationale applies as in the xdiff case - these variables help with code organization and merge conflict management.

The patch series has received positive feedback for simplifying the build infrastructure independently of the Rust integration plans that initially motivated the xdiff changes. With this final change, both xdiff and reftable functionality are now handled consistently within libgit.a, eliminating the need for special library handling in the build process. The changes are purely build-system focused with no impact on runtime behavior.
