Build system refactoring completing the consolidation of reftable into libgit.a.

This is the second and final patch in Ezekiel Newren's series to simplify Git's build system by eliminating separate static libraries. Following the same approach as the xdiff consolidation in the previous patch, this removes the REFTABLE_LIB static library and directly includes all reftable object files in LIB_OBJS. The changes:

1. Remove REFTABLE_LIB definition and all related build rules
2. Add all reftable/*.o files directly to LIB_OBJS
3. Update GITLIBS to reference only common-main.o and LIB_FILE
4. Clean up related Makefile rules and clean targets
5. Remove now-unused REFTABLE_OBJS variable

The patch follows the same pattern as the xdiff changes that were already approved, applying the simplification to the reftable components. As noted in the commit message, this change is made independently of any potential future Rust integration plans for reftable. The build output remains functionally identical, just with fewer intermediate artifacts.

This completes the build system restructuring work that was previously discussed and approved in the thread. The changes align the Makefile build with meson's approach and provide a cleaner foundation for future development. All technical decisions were already settled in earlier discussion, with this patch implementing the agreed-upon changes for the reftable portion.
