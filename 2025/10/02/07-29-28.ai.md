Build system patch introducing Rust infrastructure to the Makefile build system, complementing the earlier Meson integration. This is part of the v8 Rust infrastructure series that's now in its final form with all typo fixes applied.

The patch adds Makefile support for building the internal Rust library (`libgitcore.a`) via Cargo, with conditional compilation controlled by the `WITH_RUST` flag. Key changes include:
- New `.gitignore` entries for Rust build artifacts (`/target/`, `Cargo.lock`)
- Makefile infrastructure for Rust builds with debug/release configuration support
- `RUST_SOURCES` variable tracking Rust source files (starting with just `src/lib.rs`)
- Quiet build output integration matching Git's existing build verbosity controls
- Clean target updates to remove Rust artifacts
- Documentation of the `WITH_RUST` option and its phased adoption timeline

The implementation mirrors the Meson support added in previous patches, maintaining consistency between build systems. The Rust library gets linked into `GITLIBS` when enabled, and the build produces either debug or release artifacts based on the `DEBUG` flag. The patch includes all the standard Git build system conventions like quiet build support (`QUIET_CARGO`) and proper dependency tracking.

This is the third of nine patches in the final v8 series, following the Meson integration and preceding the varint subsystem standardization. The implementation has been validated on Cygwin by Ramsay Jones and received maintainer approval, with Ezekiel Newren confirming this infrastructure is needed before his follow-up Rust contributions can proceed.
