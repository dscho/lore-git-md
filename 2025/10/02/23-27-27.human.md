This is the second part of a two-patch series restructuring Git's build system to consolidate static libraries. Following the earlier removal of XDIFF_LIB, this patch now removes REFTABLE_LIB and folds all reftable object files directly into LIB_OBJS.

The changes mirror the same pattern as the xdiff consolidation: removing the separate static library target, listing all reftable object files directly in LIB_OBJS, and cleaning up related Makefile rules. The patch notes this is done without any immediate plans to convert reftable to Rust, making the change independently valuable as a build system simplification.

The thread context shows this work has already been reviewed and approved, with Junio Hamano and Patrick Steinhardt agreeing the direct inclusion approach is the right solution. The series matches meson's behavior and has been successfully merged into the 'seen' branch. This appears to be a clean, well-executed build system refactoring that removes intermediate artifacts while maintaining identical functionality.
