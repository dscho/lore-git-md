Build system patch introducing Rust infrastructure to Git via Meson. This is the first of a 9-part series establishing Rust support in Git core, with this initial patch focusing on the build system integration.

The patch adds Meson configuration to optionally build a Rust static library (`libgitcore.a`) when Rust tooling is available, detected automatically but controllable via `-Drust=` option. It sets up Rust 2018 edition compatibility (targeting Rust 1.49 for gcc-rs backend support) and includes test infrastructure using Rust's native unit testing framework. The implementation uses a custom `cargo-meson.sh` wrapper to handle build artifact placement until Cargo's `--artifact-dir` stabilizes.

Key technical components:
- New files: `Cargo.toml`, `src/cargo-meson.sh`, `src/meson.build`, empty `src/lib.rs`
- Build system changes in `meson.build` and `meson_options.txt`
- Conditional compilation via `WITH_RUST` define
- Test integration via `meson test` protocol

This foundational patch enables subsequent Rust work while maintaining optional status, with planned mandatory adoption by Git 3.0 (H2 2026). The implementation follows Ezekiel Newren's inspiration and maintains compatibility with existing C builds, setting up the infrastructure needed for the varint subsystem proof-of-concept that follows in patch 6. The patch demonstrates careful attention to backward compatibility and build system integration concerns.
