Documentation formatting fix for the recently merged git-checkout.adoc improvements. This is a follow-up patch from Kristoffer Haugsbakk correcting a minor markup inconsistency in the `-B` option description that made it through the review process.

The patch fixes two instances where branch placeholders were incorrectly marked up with both backticks and underscores (`_<branch>_`), changing them to use only underscores (_<branch>_). The commit explains that the original mixed syntax was likely unintentional, as the backticks were applying HTML formatting to the underscores rather than the intended placeholder styling. This change aligns with the rest of the document's formatting established in commit 042d6f34 ("doc: git-checkout: clarify `-b` and `-B`").

The fix is straightforward and uncontroversial, addressing a purely presentational issue in documentation that was otherwise approved and merged. It demonstrates the attention to detail in Git's documentation review, where even minor formatting inconsistencies are caught and fixed post-merge. The patch affects only the rendered output's appearance, not the technical content of the documentation.
