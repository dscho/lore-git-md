This is part 2 of Ezekiel Newren's series restructuring Git's static library build process, specifically focusing on removing the separate XDIFF_LIB static library. The patch folds xdiff functionality directly into libgit.a, matching meson's behavior and supporting future integration with Rust (where having a separate 'xdiff' library would conflict with a planned Rust crate name).

In response to Patrick Steinhardt's question about removing the `xdiff-objs` target, Newren clarifies that this target was only needed to ensure xdiff/lib.a was built - now that library is being folded into libgit.a, the target becomes unnecessary. He plans to update the commit message to explain this removal.

The change is purely build-system related with no impact on xdiff functionality. The discussion shows the team converging on the approach of keeping intermediate XDIFF_OBJS variables for organization while eliminating the separate library, with meson already using this model. This patch represents a clear step toward simplifying the build system while preparing for Rust integration.
