This is the first patch in the v8 series introducing Rust infrastructure to Git core. It adds Meson build system support for compiling an optional internal Rust library, marking the start of Git's phased transition to supporting Rust code alongside C code.

The patch establishes the basic scaffolding needed to build Rust code within Git's build system:
- Creates a new `gitcore` Rust crate (named per maintainer feedback in earlier iterations)
- Adds Meson configuration to auto-detect Rust toolchains and conditionally enable Rust builds via a new `-Drust` option
- Sets up Rust unit test integration with Meson's test runner
- Uses Rust 2018 edition for compatibility with older compilers, including the upcoming gcc-rs backend

The implementation is intentionally minimal, focusing on build system integration without yet introducing any substantive Rust code (the initial `lib.rs` is empty). This allows distributors and developers to test the build integration before any Rust functionality is added. The patch follows the series' overall strategy of making Rust optional at first, with plans to make it mandatory in Git 3.0 if the transition proves successful.

As the foundational patch in this major infrastructure change, it has been carefully reviewed through 8 iterations, with particular attention to build system compatibility (including Windows/MSVC support per Ezekiel Newren's input) and maintainability. The empty crate serves as a clean starting point for the varint implementation that follows in patch 6 of the series.
