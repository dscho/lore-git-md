Build system refactoring patch in the Rust infrastructure series.

This is the second patch in the v8 series introducing Rust support to Git core. It reorganizes the Makefile to move source declarations after the inclusion of config.mak files, enabling conditional compilation based on the `WITH_RUST` flag that will be defined in those config files. The change is purely structural - no functionality is altered, just the ordering of variable declarations and includes.

The patch moves a large block of Makefile definitions (176 lines) that were previously before the config.mak includes to after them. This includes common build flags (CFLAGS, LDFLAGS), library settings, and Coccinelle-related configurations. The commit message notes this is preparation for upcoming conditional compilation changes where `WITH_RUST` will control whether certain sources are built.

Ramsay Jones has already confirmed this change works correctly for Cygwin builds. The patch is a straightforward mechanical change that maintains all existing functionality while enabling the build system to properly handle Rust-related conditional compilation in subsequent patches. It's part of the foundational work needed before the actual Rust code can be integrated.
