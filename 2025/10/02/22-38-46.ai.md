This is a cover letter for part 1 of a multi-part series on SHA-1/SHA-256 interoperability, focused on documentation updates and test infrastructure preparation. The series consists of 9 patches that lay groundwork for future interoperability work by correcting documentation, adding test prerequisites, and handling GPG signature validation in tags.

The cover letter explains this initial series focuses on three main components: (1) updating pack format documentation that was found to be incorrect or incomplete during implementation work, (2) adding new documentation for loose object storage format, and (3) establishing test infrastructure prerequisites (`COMPAT_HASH`, `BROKEN_OBJECTS`) for compatibility hash testing. The changes from v1 show responsiveness to Patrick Steinhardt's reviews, including squashing test changes, adding a `BROKEN_OBJECTS` demonstration test, clarifying pack index v3 trailer checksum handling, and improving documentation wording.

Key technical points covered in the series include:
- Pack index v3 format documentation updates (8-byte offsets, checksum algorithm selection)
- Loose object storage documentation (`gitformat-loose.adoc`) describing sharded directory structure
- `rev-parse --show-object-format=compat` plumbing command
- GPG signature validation for both `gpgsig` and `gpgsig-sha256` headers in tags
- Test prerequisites `COMPAT_HASH` and `BROKEN_OBJECTS` for compatibility mode testing
- Skipping tests involving malformed objects in compatibility mode
