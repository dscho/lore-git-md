This is a documentation patch that's part of a series to align the Makefile and meson build systems. Ramsay Jones points out that while recent technical documentation files were properly handled by the meson build system after being renamed from .txt to .adoc format, they were never added to the Makefile's TECH_DOCS variable. 

The patch adds eight technical documents to the Makefile that were previously only built by meson, including topics like commit-graph, sparse-index, and rerere functionality. This ensures both build systems will produce the same documentation output. The change is straightforward and clearly motivated by the recent transition between build systems and documentation formats.

The patch appears well-constructed with a clear commit message explaining the context and rationale. It's a small but useful consistency fix that helps maintain parity between build systems. As the first in a 4-part series, it sets up the groundwork for whatever additional build system alignment comes next.
