CI modernization patch converting the Rust infrastructure series' "pedantic" job into a full Meson build with breaking changes testing. This is part of the v8 Rust integration series that has already received Junio Hamano's approval for merging.

The patch repurposes the obsolete Fedora-based "pedantic" CI job (made redundant by 6a8cbc41ba) into a new `fedora-breaking-changes-meson` job that:
- Tests Meson builds with breaking changes enabled via `-Dbreaking_changes=true`
- Expands distro coverage by adding Fedora to the test matrix
- Prepares for future Rust testing by standardizing on Meson (both Makefile and Meson paths will be tested with Rust in subsequent changes)

Key technical changes:
- Adds Meson/ninja dependencies for Fedora builds
- Removes the `pedantic` job from both GitHub and GitLab CI configs
- Modifies the test runner to always execute tests (previously skipped for pedantic builds)
- Ensures breaking changes flag propagates to Meson builds via `MESONFLAGS`

The change plugs testing gaps by verifying the breaking changes infrastructure works under Meson on Fedora, while maintaining the same test execution flow as other jobs. This is the penultimate patch in the series, with the varint implementation and policy documentation already in place. The conversion demonstrates the CI system's readiness to validate Rust builds across both build systems, though Rust itself isn't enabled in this specific change.
