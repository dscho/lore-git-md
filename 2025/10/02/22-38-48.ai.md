This is a documentation patch in the SHA-1/SHA-256 interoperability series, specifically updating the pack index v3 format documentation to reflect a change in offset ordering. The patch changes how offsets are stored in the pack index v3 format from being sorted by shortened object IDs to being in pack order.

The key technical change is that offset values will now be looked up by pack order rather than object ID order. This makes operations more efficient by allowing direct indexing into offset tables once the pack order position is known, avoiding the need for additional lookups through object ID tables. The documentation update removes references to the old sorted object ID order and clarifies that offsets are now directly indexed by pack position.

The change aligns with existing packfile code expectations where many operations already work with pack order positions. This eliminates the need for a reverse index (revindex) with pack index v3 since offsets can be directly accessed. The patch maintains the same 4-byte offset format with large offsets still using the MSB flag to index into a secondary 8-byte table.
