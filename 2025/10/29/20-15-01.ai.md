This is a build system patch addressing Rust version compatibility in the ongoing SHA-1/SHA-256 interoperability work. Junio C Hamano reports a build failure when using Rust 1.49.0 due to the `cargo::` syntax in `build.rs` which was introduced in Rust 1.77.0. The patch proposes a temporary workaround by reverting to the older single-colon syntax (`cargo:`) that works with the currently declared minimum Rust version.

The change is straightforward - replacing all instances of `cargo::` with `cargo:` in the build script's link directives. This maintains identical functionality while supporting older Rust versions. The patch is marked as a potential "SQUASH" candidate, suggesting it may be folded into the main series rather than standing alone.

This addresses one of the open questions from the thread about Rust version compatibility (1.49.0 vs 1.77.0). The solution opts for backward compatibility rather than raising the minimum version requirement, which would impact users on older distributions. The change is minimal and focused solely on the build system aspect, not affecting the substantive Rust implementation work in the rest of the series.
