This is a build system discussion in the context of the ongoing SHA-1/SHA-256 interoperability work introducing Rust code to Git. Junio C Hamano responds to patch 10/14 in the series, which adds a Rust build script for test binaries.

The patch in question adds linking directives for several Git internal libraries (libgit, reftable, xdiff, zlib) to the Rust test build process. Junio notes some confusion about the approach, recalling that there was previous discussion about consolidating these libraries into libgit.a to simplify linking. He observes that the current patch's approach seems straightforward enough, but points out that XDIFF_LIB and REFTABLE_LIB no longer exist in the main Makefile, suggesting this might indicate the consolidation has already happened.

The email highlights an implementation detail that needs alignment between the Rust build process and Git's existing build system. While not blocking the overall effort, it shows the careful attention being paid to how the new Rust components integrate with Git's established infrastructure. The question about whether to revert previous consolidation work suggests this may need some build system reconciliation before finalizing.
