Build system compatibility fix for Rust integration. Junio C Hamano identifies and proposes a solution for a Rust version mismatch in the ongoing SHA-1/SHA-256 interoperability work. The build system currently fails because it uses `cargo::` syntax (introduced in Rust 1.77.0) while declaring compatibility with Rust 1.49.0. The patch demonstrates the error and provides a straightforward fix by reverting to the older `cargo:` syntax (single colon) for build script outputs.

This is a technical but important adjustment to keep the Rust integration working across different distribution versions. The change is minimal and well-explained, directly addressing the immediate build failure while the broader discussion about minimum Rust version requirements continues. The patch appears ready to apply as a temporary solution while the version policy gets settled.
