Build system compatibility issue in Rust interoperability work. Junio C Hamano reports a build failure when compiling the SHA-1/SHA-256 interoperability patches with Rust support enabled. The error occurs because the build script uses a newer Rust syntax (`cargo::`) that isn't supported by the minimum Rust version (1.49.0) specified in the project.

The problem manifests when trying to build the Rust component `libgitcore.a`, with the build system failing on the syntax difference. Junio suggests two potential fixes: either downgrade the build script syntax to use the older single-colon format (`cargo:`) or update the minimum Rust version requirement to 1.77.0, though he notes this newer version might be too recent for some distributions like Debian oldstable.

This is a practical build system issue that needs resolution before the Rust-based interoperability work can proceed smoothly across different environments. The patch series maintainer (brian m. carlson) will need to address this version compatibility question, balancing modern Rust features with broader system compatibility requirements.
