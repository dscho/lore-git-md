This is a bugfix for a memory leak in test infrastructure, specifically in the `test-delete-gpgsig` helper tool used by GPG-related tests. The leak was exposed by recent improvements to GPG test setup in the `tz/test-prepare-gnupghome` series, which made these tests run more reliably in CI.

Jeff King noticed and fixed the issue where a `strbuf` used to read input wasn't being freed, causing `SANITIZE=leak` failures in test t1016. The patch properly releases the buffer and consolidates cleanup code using a `goto out` pattern. The bug was introduced in October 2023 but only became visible after July 2024 when the test infrastructure improvements made these tests run consistently in CI.
