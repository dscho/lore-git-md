This is part 7/10 of Ezekiel Newren's refactoring series to modernize xdiff data structures for Rust FFI. The patch changes the `nrec` field in `xdfile_t` from `long` to `size_t`, as it represents the number of elements in memory arrays and thus should use the standard size type. 

The change follows the series' pattern of using more precise types for memory-related quantities. It requires numerous casting adjustments throughout xdiff's algorithms (myers, patience, histogram diffs) where `nrec` is compared with `long` variables, but maintains all existing behavior. The commit message clearly explains the rationale for choosing `size_t`.
