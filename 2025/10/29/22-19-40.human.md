This is a refactoring patch in a completed series modernizing xdiff's data structures for Rust FFI compatibility. It changes the type of dstart/dend fields in xdfile_t from long to ptrdiff_t (a change from ssize_t in v1 based on feedback) to properly represent pointer offsets, which can be negative. The fields are also moved to the end of the struct to minimize disruption for a future planned restructuring.

The patch is part of a well-received 10-part series that has already reached consensus, with this particular change being one of the final adjustments made in response to mailing list feedback. The series as a whole establishes clear cross-language type safety for Git's diff algorithm internals while maintaining behavior, with comprehensive documentation added in later patches. This specific change helps ensure proper pointer arithmetic across FFI boundaries while setting up for future structural improvements.
