This thread documents Bello Olamide's Outreachy internship application to work on removing Git's reliance on global variables, specifically targeting those in environment.c. The proposal has evolved through mentor feedback from Christian Couder, with the latest version (v2) showing significant technical refinement.

The core challenge involves migrating repository-scoped variables like git_work_tree_cfg and is_bare_repository_cfg into proper repository structures, learning from both successful prior migrations (core.hooksPath) and problematic cases (git_attributes_file). The new proposal thoughtfully analyzes two technical approaches - accessor functions versus direct parameter passing - and identifies subsystem coupling (particularly with index_state) as a key obstacle. It also properly distinguishes variables that must remain global from those that can migrate.

Christian Couder has guided the discussion toward producing this more structured proposal rather than continuing email debate. The current version demonstrates Bello's growing technical understanding of Git's architecture, particularly in its analysis of why the attributes migration failed and how to approach the bare repository case. With a clear four-phase execution plan and engagement with prior work, the proposal appears ready for the implementation phase of the internship.
