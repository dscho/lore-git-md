This is part 7/10 of Ezekiel Newren's xdiff refactoring series to modernize data structures for Rust FFI compatibility. The patch converts `xdfile_t.nrec` from `long` to `size_t` since it tracks array element counts (number of records in memory for `recs` and `changed` arrays). The change requires adding explicit casts in several algorithms (myers, patience, histogram diffs) where the count is compared with `long`-typed indices.

The patch follows the series' pattern of using size-appropriate types for memory-related quantities while maintaining behavior. It touches all major xdiff components but is mechanically straightforward - mostly adding `(long)` casts at comparison sites. This continues the systematic type safety improvements while keeping the diff algorithms' logic unchanged. The change is well-contained and consistent with the series' goal of unambiguous type definitions for cross-language interoperability.
