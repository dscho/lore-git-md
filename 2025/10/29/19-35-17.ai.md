Bugfix for a memory leak in test infrastructure exposed by GPG test improvements.

This patch fixes a memory leak in the `test-delete-gpgsig` helper tool where a `strbuf` wasn't being freed, causing `SANITIZE=leak` failures in t1016 tests. The leak was introduced in commit 7673ecd2dc but only became visible after GPG test improvements in 6cd8369ef3 made these tests run in CI. Jeff King's fix adds proper cleanup with `strbuf_release()` and consolidates the cleanup path using a `goto out` pattern to handle both the early return case and normal execution.

The change is straightforward and well-contained, affecting only the test helper's memory management. It's part of the ongoing work around GPG test reliability (`tz/test-prepare-gnupghome` series) but stands alone as a clear bugfix. The patch demonstrates good attention to detail by noting both when the bug was introduced and when it became visible, though the actual fix is minimal - just 3 lines changed to ensure proper cleanup.
