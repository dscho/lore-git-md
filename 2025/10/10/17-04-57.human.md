This is a documentation patch improving the `git worktree` man page, part of a two-patch series addressing common worktree usage pitfalls. The patch adds two key clarifications: a warning against creating nested worktrees (which can cause gitignore complications) and a link to the EXAMPLES section showing recommended directory layouts.

The changes are straightforward: a new advice paragraph warns users to place worktrees outside the main repository and existing worktrees, with a cross-reference to the EXAMPLES section. The EXAMPLES section also gets an explicit anchor for linking. The patch has already incorporated feedback from multiple reviewers about documentation formatting, including proper cross-reference syntax and anchor placement.

This is the first of two patches in the series, with the second patch focusing on bare repository examples.
