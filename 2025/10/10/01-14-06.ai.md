Platform compatibility patch for Windows path handling in config file paths.

This is the first patch in a series addressing inconsistent path display in Git's config file handling. It focuses on normalizing path separators to forward slashes on Windows systems. The change modifies `cleanup_path()` in path.c to consistently use `convert_slashes()` for Windows paths, ensuring forward slashes are used even for XDG config file paths that previously showed mixed slashes. The patch includes a signature change from `const char *` to `char *` to accommodate the in-place modification done by `convert_slashes()`.

The technical changes are minimal but important for consistency - the code now handles the "./" prefix cleanup and Windows path conversion in one place. Johannes Schindelin has reviewed and suggested this approach, and the patch includes his Reviewed-by tag. The change is preparatory for the subsequent patch that will verify XDG config path formatting in tests. This appears to be a straightforward platform-specific improvement that aligns with Git's cross-platform path handling conventions while maintaining compatibility with existing callers.
