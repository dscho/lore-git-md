This is a refactoring patch in a series introducing a `--required` flag for `git refs optimize`. It follows patch 1's consolidation of reference backend operations by cleaning up now-redundant code related to the deprecated `pack_refs` functionality.

The patch removes the `pack_refs` function pointer from `struct ref_storage_be` and its associated wrapper function `refs_pack_refs()`, since all backends now exclusively use the unified `optimize` interface. Documentation is updated to clarify that the `PACK_REFS_*` flags now control `refs_optimize()` behavior rather than `pack_refs()`. The changes span three files (`refs.c`, `refs.h`, and `refs/refs-internal.h`) with straightforward deletions and minor doc updates.

This is a mechanical cleanup that maintains identical behavior while simplifying the codebase, continuing the series' pattern of establishing a cleaner foundation before adding new functionality. The changes are well-contained and unlikely to be controversial, with no behavioral impact beyond what was already established in patch 1's backend unification.
