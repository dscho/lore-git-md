This is a test patch in a series fixing Git's config file handling to properly list both `$HOME/.gitconfig` and XDG config files with `git config list --global`.

The patch adds comprehensive test coverage for the upcoming fix, verifying several scenarios: handling of nonexistent config files, cases where only one config file exists, and the correct precedence when both files are present (home config should override XDG). It also checks that the `--show-origin` flag correctly identifies the source files. The tests are currently written to expect failures, which will be resolved by the next patch in the series.

The test additions look thorough and well-structured, covering both the main functionality and edge cases. The patch has already received a Reviewed-by from Johannes Schindelin, suggesting it has undergone platform-specific vetting. This appears to be a solid foundation for the actual implementation change coming in the next patch.
