CI / build system fix for Ubuntu 25.10 compatibility.

Patrick Steinhardt reports that Ubuntu 25.10's switch to sudo-rs (a Rust-based sudo implementation) breaks Git's CI pipelines because sudo-rs lacks support for the `--preserve-env` flag that the test infrastructure relies on. The patch modifies `ci/install-dependencies.sh` to detect Ubuntu 25.10+ systems and explicitly switch back to the traditional C-based sudo implementation (`sudo.ws`) when available via the alternatives system.

The change is straightforward - it checks for the alternatives configuration file and uses `update-alternatives` to select the working implementation. This affects both GitHub and GitLab CI environments. The author suggests fast-tracking the fix since it's breaking active CI jobs. The patch appears well-targeted to solve an immediate compatibility issue with minimal risk, though it may need revisiting if Ubuntu phases out the C-based sudo entirely in the future.
