Bugfix for config file handling regression. This is the final patch in a series addressing inconsistencies between Git's config file reading and listing behavior for global configuration files.

The patch fixes a regression introduced in the previous patch where `git config list --global` would incorrectly succeed when both global config files (`$HOME/.gitconfig` and `$XDG_CONFIG_HOME/git/config`) were unreadable. The fix ensures the command properly fails in this case, matching both documented behavior and user expectations.

Key changes include:
- Modifying `do_git_config_sequence()` to track successful reads of global config files
- Adding logic to return a non-zero status when in global scope and no configs were readable
- Updating tests to verify the fixed behavior (removing the `test_expect_failure` markers)

The implementation carefully maintains backward compatibility while fixing the regression. The patch has been reviewed by Johannes Schindelin and includes a Helped-by from Derrick Stolee, indicating solid technical vetting. With this change, the series now fully aligns Git's config listing behavior with its actual reading behavior for global configuration files.
