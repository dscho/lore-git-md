This is a refactoring patch in Taylor Blau's ongoing series to modularize `builtin/repack.c`. The patch moves the static `packdir` variable into a parameter for the `existing_packs_remove_redundant` function as part of splitting the code into separate compilation units.

Jeff King (Peff) reviewed the change and noted that while the approach works, it creates a somewhat fragile API since the packdir should theoretically be derivable from the repository object already available in the struct. Taylor acknowledges this brittleness but prefers to keep the minimal change for now, planning to address the cleaner solution in follow-up work after the main refactoring is complete.

The discussion highlights the careful balance in this series between making meaningful improvements and keeping the refactoring focused and reviewable. Both reviewers and author seem aligned that this is a reasonable intermediate step, with cleaner APIs to come later. The patch appears uncontroversial and likely to proceed as-is.
