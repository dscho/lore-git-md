The patch makes two key additions: First, it expands the description in the header section to specify that "sourceline" refers to the line number when the commit was made, while "resultline" is the line number in the current file state. Second, it adds a new paragraph under the incremental format specification that directly defines these terms, making it clearer for readers who jump to that section.

The changes are minimal (7 lines added, 2 modified) but address a real documentation gap that had caused user confusion, as evidenced by the referenced StackOverflow question.
