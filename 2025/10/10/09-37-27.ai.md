Documentation formatting fix for AsciiDoc literal blocks in user-facing docs. This is a follow-up patch that has already been reviewed and approved, now including Jeff King's Ack.

The patch systematically corrects indentation issues in several documentation files that were causing unintended literal blocks in the rendered output. The changes are straightforward - mostly removing indentation from regular paragraphs that were being incorrectly rendered as code blocks. The exception is `git-sparse-checkout.adoc` where intentional code examples are now properly marked with `----` delimiters instead of relying on indentation.

Key files modified include `core.adoc`, `git-config.adoc`, `git-rev-parse.adoc`, `git-shortlog.adoc`, and `git-sparse-checkout.adoc`. The author notes they deliberately excluded technical documentation (`howto/`, `technical/`, `gitprotocol*`) as those follow different formatting conventions and have generally worse HTML output quality.

This is version 2 of the patch, now including Jeff King's Ack. The changes from v1 are minimal - just adding the Ack line. The patch appears to be in final form with no outstanding issues, having been reviewed and approved by a documentation expert. The changes are mechanical formatting fixes that don't affect content, just presentation.
