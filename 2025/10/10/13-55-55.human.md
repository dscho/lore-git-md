This is a follow-up discussion in the uncontroversial platform compatibility refactoring series for Windows includes in `compat/mingw.c`. Johannes Schindelin responds to Patrick Steinhardt's positive review of the patches, which standardized include paths and ordering.

The exchange reveals differing perspectives on documentation and automation. While Steinhardt suggested documenting include style guidelines, Schindelin pushes back, concerned about overwhelming new contributors with too much documentation. On automation, both agree in principle that tools like clang-format could handle include sorting, but Schindelin expresses skepticism about the Git project's willingness to adopt such automation based on past resistance to formatting tools.

The technical changes themselves remain approved and uncontentious - this is purely a meta-discussion about project processes. The patches appear ready to proceed as-is, with broader questions about documentation and automation left as open but non-blocking considerations.
