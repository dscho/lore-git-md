This is a test infrastructure discussion about GPG2 prereq handling in the Git test suite.

Todd Zullinger responds to Patrick Steinhardt about a known issue where GPG2 tests silently fail to run due to missing home directories, particularly affecting t1016-compatObjectFormat.sh. The problem has been masked by CI output that doesn't clearly show skipped tests. While agreeing this doesn't block the current signature handling series, Zullinger argues the broader issue should be addressed - either by removing the flaky t1016 tests or improving test visibility. The discussion reveals this affects several other test files (t1461, t6300, t7510) that depend on GPG2 prereqs.

The email highlights a long-standing but previously unnoticed test reliability issue that's now being surfaced by the signature handling work. While not directly related to the main cryptographic signature series, it points to needed improvements in test infrastructure reporting and GPG2 test handling.
