This is the third patch in a series fixing Git's global config file handling. The patch addresses a bug where `git config list --global` only showed the home directory config (`~/.gitconfig`) while Git actually reads both that and the XDG config file (`$XDG_CONFIG_HOME/git/config`).

The key change modifies `config_sequence()` to properly handle the global scope by reading both config files when `--global` is specified. The implementation introduces new flags to ignore non-global scopes and reuses existing config parsing logic. The patch includes test updates to verify the new behavior, though it temporarily marks two tests as known failures - one regarding error handling for unreadable configs (to be fixed in the next patch) and another about config precedence.

The change has been reviewed by Johannes Schindelin and follows the approach suggested in the original bug report. The implementation carefully maintains backward compatibility for write operations while fixing the read behavior. The patch appears well-considered, with clear commit message explanations of both the solution and remaining work.
