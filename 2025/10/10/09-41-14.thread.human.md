This thread addresses a CI/build system issue where Ubuntu 25.10's switch to a Rust-based sudo implementation (sudo-rs) breaks Git's CI pipelines due to missing `--preserve-env` flag support. Patrick Steinhardt initially proposed modifying `ci/install-dependencies.sh` to detect Ubuntu 25.10+ and fall back to the traditional C-based sudo (`sudo.ws`), with Junio C Hamano suggesting refinements to make the fallback more robust by checking binary existence rather than just alternatives configuration.

The discussion has evolved to consider both immediate and long-term solutions. Brian m. carlson filed an upstream feature request with sudo-rs (issue #1299) to implement the missing flag, which could make the current workaround temporary if support arrives by Ubuntu 26.04. In the latest exchange, Patrick confirms awareness of the parallel upstream effort while maintaining the current fallback approach for CI stability. The thread shows consensus on monitoring sudo-rs development while keeping the detection-and-fallback logic in place, with no new technical changes needed at this time. The solution handles both the present Ubuntu 25.10 breakage and potential future resolution paths.
