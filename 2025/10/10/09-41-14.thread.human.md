This thread addresses a CI/build system issue where Ubuntu 25.10's switch to sudo-rs (a Rust-based sudo implementation) breaks Git's CI pipelines due to missing `--preserve-env` flag support. Patrick Steinhardt initially proposed modifying `ci/install-dependencies.sh` to detect Ubuntu 25.10+ and fall back to the traditional C-based sudo (`sudo.ws`) via the alternatives system. Junio C Hamano refined the approach, suggesting making the fallback conditional on binary existence and narrowing the scope to Ubuntu specifically.

Brian m. carlson has now provided additional context, noting they've filed an upstream feature request with sudo-rs (issue #1299) to implement the missing functionality. This suggests the current workaround may only be temporary if sudo-rs adds the capability by Ubuntu 26.04. While no code changes are proposed in this update, it connects the issue to broader ecosystem concerns, indicating other projects are affected as well. The discussion remains focused on a robust solution, balancing immediate CI fixes with awareness of potential upstream resolutions.
