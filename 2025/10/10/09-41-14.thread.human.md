This thread addresses a CI breakage caused by Ubuntu 25.10's switch to a Rust-based sudo implementation (sudo-rs) that lacks the `--preserve-env` flag Git's test infrastructure depends on. Patrick Steinhardt identified the issue and proposed a targeted fix that modifies `ci/install-dependencies.sh` to detect affected Ubuntu versions and explicitly switch back to the traditional C-based sudo (`sudo.ws`) when available through the alternatives system.

The solution is straightforward - checking for the alternatives configuration and using `update-alternatives` to select the working implementation - and affects both GitHub and GitLab CI environments. Given that this is actively breaking CI pipelines, Patrick suggests fast-tracking the fix. While the patch cleanly solves the immediate issue, it may need revisiting if Ubuntu eventually removes the C-based sudo entirely.
