This thread introduces build system improvements for two Git credential helpers in the contrib directory (libsecret for Linux and osxkeychain for macOS). The patch standardizes their Makefiles to match conventions used elsewhere in Git's contrib components, such as contacts and subtree.

The changes focus on build system hygiene rather than functional modifications to the helpers themselves. Key improvements include proper handling of config files, correct flag usage during compilation and linking, pattern-based rules instead of per-file rules, proper install targets, and verbose output for clean operations. Both Makefiles are updated consistently to follow the same patterns.

This appears to be a non-controversial maintenance patch that brings these credential helpers in line with Git's established build practices. The changes should make the build process more reliable and consistent with the rest of the project's contrib components.
