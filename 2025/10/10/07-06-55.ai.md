Documentation update for cryptographic signature handling in git-tag.

This is a follow-up to Junio C Hamano's review of the documentation changes in the ongoing signature handling series. Christian Couder confirms he will incorporate Hamano's suggested wording improvements into the next version (v3) of the patch series. The specific change updates the description of the `-v/--verify` option in `git-tag` to use consistent cryptographic terminology ("Verify the cryptographic signature of the given tags") rather than the previous GPG-specific language. 

This maintains alignment with the series' broader goal of making tag signature documentation format-agnostic, following earlier changes to the `-s/--sign` and `-u/--local-user` options. The exchange shows the final technical review phase where documentation polish is being addressed before integration. The change is straightforward and uncontroversial, building on the already-approved technical implementation of consistent signature handling across Git's fast-import/export pipeline.
