This is a refactoring patch in a series introducing a `--required` flag for `git refs optimize`. It's the second of nine patches that aim to improve reference backend optimization, particularly for GitLab's Gitaly service.

The patch cleans up now-redundant code after the previous patch consolidated reference backend operations around the `optimize` function in `struct ref_storage_be`. It removes the obsolete `pack_refs` function pointer and related infrastructure, including the `refs_pack_refs()` wrapper function and associated documentation. The documentation is updated to clarify that the `PACK_REFS_*` flags now control `refs_optimize()` behavior rather than `pack_refs()`.

This is a straightforward cleanup that follows logically from the first patch in the series, removing now-unused code paths. The changes are mechanical and well-contained, touching only three files with clear deletions and minor doc updates. As part of the larger series, this helps establish a cleaner foundation for the subsequent functional changes.
