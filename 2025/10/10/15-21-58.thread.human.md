This thread documents an improvement to the `git blame --incremental` output format documentation in the git-blame manpage. The original patch clarified the previously undocumented "sourceline" and "resultline" fields, explaining that "sourceline" refers to the line number in the original commit being blamed while "resultline" is the line number in the final output. 

A follow-up patch builds on this by adding more detailed explanations in two places: it expands the header section description to explicitly define these terms, and adds a clarifying paragraph directly in the incremental format specification section. Both changes are minimal (totaling 7 added and 2 modified lines) but make the documentation more complete and accessible, particularly for users who had encountered confusion evidenced by a Stack Overflow question. The entire thread focuses purely on documentation improvements with no code changes involved.
