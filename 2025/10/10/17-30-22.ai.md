This is a build system patch that standardizes and improves the Makefiles for two Git credential helpers (libsecret and osxkeychain) in the contrib directory. The changes bring these Makefiles in line with other contrib components like contacts and subtree.

The patch makes several technical improvements: it properly includes config.mak.autogen and config.mak early, adds missing $(CPPFLAGS) to compilation and $(CFLAGS) to linking commands, introduces pattern rules for compilation instead of per-file rules, adds install targets with proper directory handling, makes the clean target verbose by removing the @ from $(RM), and declares all special targets as .PHONY. The changes affect both the libsecret (Linux) and osxkeychain (macOS) credential helper Makefiles in a consistent way.

Key files modified are contrib/credential/libsecret/Makefile and contrib/credential/osxkeychain/Makefile, with changes focused on build system conventions rather than functional changes to the helpers themselves. The patch follows established patterns seen in other parts of Git's contrib directory, suggesting it's a straightforward quality-of-life improvement for maintainers rather than a controversial change.
