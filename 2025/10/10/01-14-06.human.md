This is a platform compatibility patch that standardizes path handling on Windows by ensuring forward slashes are used consistently. It's part of a series addressing config file path display inconsistencies.

Delilah Ashley Wu modifies `cleanup_path()` in path.c to convert backslashes to forward slashes on Windows, matching Git's preferred path format. The change affects all code paths using this function, including config file path display which currently shows mixed slashes for XDG config paths. The patch maintains compatibility with existing callers by changing the function signature to take/return `char *` rather than `const char *`.

The change builds on previous work that standardized slashes in `interpolate_path()` and has been reviewed by Johannes Schindelin. It serves as preparation for subsequent patches that will test the XDG config path handling. The implementation appears straightforward and aligns with Git's cross-platform path conventions.
