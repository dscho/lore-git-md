This is a CI/build system patch fixing broken test jobs on Ubuntu 25.10. 

Patrick Steinhardt reports that Ubuntu 25.10's switch to the Rust-based sudo-rs implementation breaks Git's CI jobs because sudo-rs doesn't support the `--preserve-env` flag that the test infrastructure relies on. The patch works around this by explicitly configuring the system to use the traditional C-based sudo implementation when available.

The change is straightforward - it adds logic to `ci/install-dependencies.sh` that detects Ubuntu 25.10+ systems and forces the use of `/usr/bin/sudo.ws` (the C implementation) via the alternatives system. The patch appears well-targeted and properly explained, addressing an immediate CI breakage that affects both GitHub and GitLab pipelines. 

Given that this fixes actively broken CI, the author suggests fast-tracking the fix, which seems reasonable since the change is minimal and clearly motivated. The solution is Ubuntu-specific and shouldn't affect other platforms.
