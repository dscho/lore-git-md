This is a documentation formatting patch that fixes accidental literal blocks in Git's AsciiDoc documentation. Kristoffer Haugsbakk systematically corrects indentation issues across several user-facing manual pages that were causing unintended literal blocks in the rendered output. The changes are straightforward - mostly removing incorrect indentation and adding proper line continuations, with one notable exception in `git-sparse-checkout.adoc` where intended literal blocks are properly marked with `----` delimiters.

The patch has already been reviewed and acked by Jeff King, who verified the changes using Git's doc-diff tool. The author notes they've made a thorough pass through the documentation and believes this covers all remaining instances, excluding technical documentation which follows different formatting conventions. This appears to be a clean, well-vetted improvement to the documentation's presentation quality.
