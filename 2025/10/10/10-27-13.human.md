Feature addition to `git refs optimize` and `git pack-refs` commands. This is the final patch in a series introducing a `--required` flag that checks if reference optimization is needed without performing it, primarily for server-side maintenance efficiency.

The patch adds the `--required` flag to both `git refs optimize` and `git pack-refs`, which returns exit code 0 if optimization would be beneficial. This is particularly useful for GitLab's Gitaly service where read operations are cheaper than writes, allowing them to check optimization needs before performing potentially expensive operations.
