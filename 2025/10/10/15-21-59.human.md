This is a documentation patch clarifying the `git blame --incremental` output format. The patch adds explicit explanations for the "sourceline" and "resultline" fields in the incremental blame output, which were previously undocumented despite being part of the output format for years.

The change makes it clear that "sourceline" refers to the line number in the original commit being blamed, while "resultline" is the line number in the final file state. This clarification comes in response to real user confusion documented in a Stack Overflow question, showing the patch addresses a genuine documentation gap.

The modification is straightforward - adding 7 lines with 2 modifications to the git-blame.adoc manpage. The author notes they couldn't verify the docbook build locally but considers this low-risk given the purely documentation nature of the change. This appears to be a well-motivated, focused documentation improvement that should help users understand the blame output format without requiring any code changes.
