Refactoring patch in the reftable optimization series.

This is patch 6/9 in a series introducing a `--required` flag for ref optimization operations. The patch modifies `stack_table_sizes_for_compaction()` in `reftable/stack.c` to directly return compaction segments rather than just table sizes, eliminating an intermediate step where sizes were passed to `suggest_compaction_segment()`. The change enables code reuse for upcoming functionality that will check if auto-compaction is needed without performing it.

The implementation replaces the size array return with direct segment calculation, handling memory allocation errors by returning `REFTABLE_OUT_OF_MEMORY_ERROR`. Patrick Steinhardt approves the change while noting the unnecessary initialization of `err` in `reftable_stack_auto_compact()`. This is a clean refactoring that maintains the existing behavior while preparing for future functionality in the series.
