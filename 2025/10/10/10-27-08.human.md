Test infrastructure patch in a series adding `--required` flag for ref optimization.

This is patch 4/9 in a series preparing for a new `--required` flag for `git refs optimize`, primarily motivated by GitLab's Gitaly service needs. The patch fixes a test organization issue where a shared test script (`pack-refs-tests.sh`) was incorrectly containing the `test_done` directive, preventing additional tests from being added in the scripts that include it (`t0601-reffiles-pack-refs.sh` and `t1463-refs-optimize.sh`).

The change moves the `test_done` directive out of the shared test file and into the individual test scripts that include it. This is a straightforward test infrastructure cleanup that follows good practices for shared test code - the shared file should contain test cases but not control the overall test flow. The patch is well-contained and clearly explained, with a reference to the prior refactoring that introduced the issue.
