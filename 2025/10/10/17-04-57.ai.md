This is a documentation patch in the ongoing `git worktree` UX improvement series. It's the first of two patches that aim to clarify worktree usage through better documentation rather than behavior changes.

The patch makes two key additions to `git-worktree.txt`:
1. Adds a warning advising users to place new worktrees outside the repository and existing worktrees, with a cross-reference to the EXAMPLES section
2. Adds an anchor (`[[EXAMPLES]]`) before the EXAMPLES section to enable proper linking

The changes incorporate prior review discussion about documentation formatting, including:
- Using proper cross-reference syntax (`<<EXAMPLES,EXAMPLES>>`)
- Placing the anchor on a dedicated line
- Formatting placeholders in `_italics_` (`_<path>_`)

The patch builds on earlier feedback from multiple reviewers (Junio Hamano, Jean-Noël Avila, Kristoffer Haugsbakk) and appears to address all outstanding formatting concerns for this portion of the documentation. The maintainer has tentatively queued this version pending minor refinements, suggesting it's nearing final form.

This is part of a coordinated effort to improve worktree documentation that has involved documentation specialists and surfaced broader project standards for AsciiDoc formatting. The patch maintains existing behavior while making the documentation more helpful for users encountering common pitfalls.
