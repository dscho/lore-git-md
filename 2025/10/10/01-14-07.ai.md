This is a test patch in a series addressing Git's config file handling inconsistency, specifically ensuring `git config list --global` properly shows both `$HOME/.gitconfig` and `$XDG_CONFIG_HOME/git/config` files.

The patch adds comprehensive test coverage in t1300-config.sh to verify the expected behavior before the actual fix is implemented in the next patch. It tests several scenarios: handling of nonexistent global configs, cases where only one config file exists (either home or XDG), and when both exist (where home config should take precedence). The tests also check that `--show-origin` correctly identifies the source files and that error handling remains intact for unreadable files. A related test in t1306-xdg-files.sh is modified to expect the new behavior where both configs are read.

The test assertions are designed to fail initially (using `! test_cmp`), as they're testing current broken behavior that will be fixed in the subsequent patch. The test structure follows Git's standard patterns with proper test_when_finished cleanup blocks. The patch has already received a Reviewed-by from Johannes Schindelin, indicating technical approval of the approach. This test-only patch serves as important verification for the behavioral changes coming in the series.
