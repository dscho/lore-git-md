This is a bugfix patch series addressing an inconsistency in how `git config --global` handles configuration files. Currently, while it properly reads both `~/.gitconfig` and `$XDG_CONFIG_HOME/git/config` when applying configuration, the `--global` flag only shows values from the home directory file in contrast to the documentation which states both should be shown.

The series starts with a preparatory Windows path normalization fix, then adds tests to demonstrate the issue. The main fix comes in patches 3-4 which modify the config reading logic to properly include both files under `--global`. The changes appear well-considered, with pre-review from Johannes Schindelin and thorough test coverage. The commit messages clearly explain both the problem and solution, referencing prior discussion on the mailing list.

This fixes a real documentation/behavior mismatch that could confuse users managing their global configuration across both standard and XDG locations. The changes are focused and the series looks ready for consideration.
