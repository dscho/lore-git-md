This is a test fix addressing a regression in test setup logic. The patch corrects t1016-compatObjectFormat.sh to properly persist GPG configuration across test cases.

The issue stems from commit c348192a (2024-10-22) which while fixing style issues inadvertently changed a `git config` to `test_config` for setting up GPG. This broke the test's design where the first test case sets up configuration that subsequent tests rely on, since `test_config` automatically cleans up its changes after each test.

Junio Hamano notes this was an oversight that should have been caught in review. The fix simply reverts to using `git config` for the GPG program setup, ensuring the configuration persists as intended. The change is minimal - just one line modifying how the gpg.program is set.

This appears to be a straightforward correction of test infrastructure with clear motivation. The patch maintains the existing test pattern where early tests configure the environment for later ones. No behavioral changes to Git itself are introduced - this purely affects test reliability.
