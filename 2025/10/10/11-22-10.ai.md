This is a refactoring patch that's part of a larger series introducing a `--required` flag for reference optimization operations. The patch focuses on consolidating the backend interface for reference optimization by moving from having both `pack_refs` and `optimize` functions to just using the more generic `optimize` function across all reference backends.

The change standardizes the interface in preparation for later patches that will add the new `--required` functionality. The key modification is renaming `files_pack_refs` to `files_optimize` in the files backend, though Patrick Steinhardt notes in his review that the `pack_refs_opts` struct name should also be updated to better reflect its more general purpose (which appears to happen in later patches).

This is a mechanical change that doesn't affect behavior - it's cleaning up the backend interface before adding new functionality. The patch is part of a well-structured series that clearly separates preparatory refactoring from feature implementation. The review discussion suggests the naming changes are being carefully considered to maintain clarity as the interfaces evolve.
