This is a documentation patch in Jean-Noël Avila's ongoing series standardizing Git man page formatting. It's a follow-up discussion about a specific edge case in the `git-stash` documentation conversion that was already merged into the 'next' branch.

The thread had identified an Asciidoc formatting nuance where command references in conditional blocks (`ifndef::git-stash[]`) need special handling - single quotes vs backticks for proper verbatim rendering. While Jean-Noël initially planned to reroll the patch to use backticks for the 'show' command reference, he now concludes that making this work consistently across both Asciidoc implementations (asciidoc.py and asciidoctor) isn't straightforward.

The decision is to leave the current formatting as-is in the already-merged version, accepting this minor limitation in the documentation toolchain. This shows the practical tradeoffs being made in the documentation standardization effort - sometimes perfect formatting must yield to what actually works across tooling variations. The discussion demonstrates careful attention to detail while also recognizing when further tweaks aren't worth the churn.
