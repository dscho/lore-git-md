This is a follow-up in the CI/build system thread about Ubuntu 25.10's sudo-rs compatibility issues. Brian m. carlson notes they've filed an issue with the sudo-rs project requesting implementation of the `--preserve-env` flag that Git's CI depends on, linking to the feature request on GitHub. This provides a potential longer-term solution beyond the current workaround of switching back to the C-based sudo implementation. The comment suggests this may be addressed in Ubuntu 26.04 if the upstream project implements it in time. The tone is informational rather than proposing immediate code changes, showing awareness of both the immediate CI fix and the broader ecosystem context.
