This is a build system patch that standardizes the Makefiles for two Git credential helpers (libsecret and osxkeychain) to match the style used in other contrib components. Thomas Uhle makes several technical improvements to bring consistency and modernize the build process.

The changes include: proper handling of config.mak includes, adding missing compiler/linker flags, using pattern rules for compilation, adding install targets, making clean operations verbose, and properly declaring .PHONY targets. The patch affects both the libsecret (Linux) and osxkeychain (macOS) credential helpers.

The changes are mechanical and follow established patterns seen elsewhere in Git's contrib directory. The patch appears well-constructed with clean diffs that show exactly what's being modified in each Makefile. While not fixing any bugs or adding features, this standardization makes the build process more consistent and maintainable.
