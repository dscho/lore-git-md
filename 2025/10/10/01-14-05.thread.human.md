This thread addresses Delilah Ashley Wu's patch series to fix an inconsistency in Git's global config file handling, where `git config list --global` didn't show both `$HOME/.gitconfig` and `$XDG_CONFIG_HOME/git/config` despite Git reading both. The technical implementation is complete and has Johannes Schindelin's thorough review, with all identified issues resolved across four patches that modify config file sequence handling and add appropriate test coverage.

However, Junio C Hamano has held off on merging the series into the `seen` branch, not due to technical concerns but because he wants broader community input. He raises a historical question about whether the original single-file behavior might have been intentional to ease migration paths. While Johannes' Reviewed-by confirms the code quality, Junio wants to hear from more experienced contributors before proceeding, particularly about the change's implications for users with both config files. The series remains in good standing but awaits either community discussion or Junio's further investigation of the migration question.
