This is a test infrastructure patch addressing flaky GPG signing tests in the SHA-1/SHA-256 compatibility suite. Junio Hamano responds to Todd Zullinger's ongoing investigation into why t1016-compatObjectFormat.sh fails intermittently in GitHub CI but passes locally. The core issue appears to be SHA-1 hash mismatches during GPG-signed commit verification, possibly related to time-dependent behavior in the test environment.

Hamano proposes a temporary workaround by marking all GPG2-dependent tests in t1016 as "FLAKEY" alongside their existing prerequisite, which would allow them to be skipped when flaky rather than failing the test run. This would unblock the GNUPGHOME fix while acknowledging the underlying issue isn't fully resolved. The patch shows the straightforward changes to the test prerequisites.

The email highlights the dilemma between wanting reliable test coverage for GPG signing across hash algorithms versus the practical need to unblock other improvements. Hamano expresses reluctance about the workaround, preferring a proper fix if someone can diagnose why the tests behave differently in CI versus local environments. The thread remains open for input from test infrastructure experts who might understand the GPG wrapper's interaction with faked timestamps in CI.
