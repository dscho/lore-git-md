This is a feature patch series for the experimental `git-repo-info` command, implementing the `--all` flag interface that was agreed upon in the thread discussion. The series comes from Lucas Seiki Oshiro as part of GSoC work, with mentorship from Karthik Nayak and Patrick Steinhardt.

The patch series consists of two parts: First, a preparatory refactoring that extracts field printing logic into a dedicated `print_field()` function. Second, the actual implementation of `--all` that prints all available repository metadata keys, now with the important addition of erroring out when both `--all` and specific keys are requested - a safety measure that addresses Junio Hamano's scripting concerns from earlier in the thread.

Key technical changes in v3 include:
- New error handling when `--all` is used with specific keys (dies with error)
- Removal of test cases for duplicate key behavior (now invalid)
- Simplified `print_all_fields()` implementation using direct field access
- Maintained support for both `keyvalue` and `nul` output formats

The implementation appears clean and follows the thread's consensus decision to prioritize scripting safety over interactive convenience. The test coverage is thorough, verifying both the happy path and the new error case. The changeset builds on current master (a483264b01) and maintains the command's experimental status while solidifying its interface design.

This version addresses all major concerns raised in the thread and appears ready for inclusion, pending any final review comments on the implementation details. The separation into a refactoring commit followed by the feature addition follows good patch series hygiene.
