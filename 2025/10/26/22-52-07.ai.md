Refactoring patch for the experimental `git-repo-info` command.

This is the first of two patches in v3 of the series, focusing on code restructuring in preparation for implementing the `--all` flag functionality. The patch extracts the field printing logic from `print_fields()` into a new `print_field()` function, making the code more modular and reusable. This is a clean refactoring with no behavior changes - the diff shows identical output handling being moved to a dedicated function while maintaining both key-value and NUL-terminated output formats.

The change follows good Git development practices by separating refactoring from feature work. The implementation is straightforward, moving the printing logic while keeping all existing functionality intact. This sets up the second patch to implement the `--all` flag more cleanly by being able to reuse the printing logic. The patch maintains the experimental status of the command while improving its internal structure.
