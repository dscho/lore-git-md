The implementation includes:
- New `print_all_fields()` function that iterates through all defined repository info fields
- Error handling for invalid combinations (using `--all` with specific keys)
- Documentation updates to reflect the new flag
- Test cases verifying both successful `--all` usage and the error case

The patch maintains the existing output formats (`keyvalue` and `nul`) and builds on the refactored printing infrastructure from the first patch. The test suite is expanded to cover the new functionality while maintaining compatibility with existing behavior. The implementation follows Git's scripting-first philosophy by prioritizing predictable output over interactive discoverability, as per the thread consensus.
