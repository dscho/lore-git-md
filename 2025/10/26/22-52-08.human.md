Feature implementation for the experimental `git-repo-info` command. This is the second patch in the v3 series, building on the refactoring groundwork from the first patch to add the `--all` flag as previously agreed in the design discussion.

The patch adds a new `--all` flag that outputs all available repository metadata fields at once, which is particularly useful for scripting scenarios. The implementation includes proper handling of the mutually exclusive case where both `--all` and specific keys are provided (which now errors out), and maintains the existing output format options (`keyvalue` and `nul`).

The changes include documentation updates, the core implementation in `builtin/repo.c` with a new `print_all_fields()` function, and comprehensive tests verifying both the happy path and error case. The test suite now includes verification that `--all` produces the same output as explicitly listing all keys, and confirms the error message when `--all` is incorrectly combined with key arguments.

This appears to be a clean implementation of the design that was reached through earlier discussion, with clear separation from the refactoring work in the first patch. The patch maintains the command's experimental status while solidifying its interface for future stabilization.
