Documentation patch updating git-tag's man page to be more inclusive of all signature types. This is part of Christian Couder's series to bring signature handling parity between git fast-import and fast-export.

The patch modernizes the git-tag documentation to reflect that cryptographic signatures aren't limited to GPG - they can also be X.509 or SSH-based, controlled by the gpg.format configuration. It removes GPG-specific language throughout, replacing it with more generic "cryptographic signature" terminology as suggested by Patrick Steinhardt. Key changes include updating the command description, signature option explanations, and configuration section to properly document all supported signing methods.

The changes are thorough and well-motivated, addressing an actual documentation gap where the manual didn't reflect Git's current capabilities. The patch maintains all existing information while making it more accurate and inclusive. This foundational documentation update sets the stage for the subsequent implementation patches in the series.
