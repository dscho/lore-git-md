This is a test infrastructure patch in the SHA-1/SHA-256 interoperability series. It modifies `t1010-mktree.sh` to properly handle broken object tests when in hash compatibility mode.

The patch makes two key changes:
1. Wraps the creation of broken objects in a `BROKEN_OBJECTS` prerequisite check, since these tests can't work in compatibility mode where objects can't be mapped between hash algorithms
2. Adds the `BROKEN_OBJECTS` prerequisite to an existing test that depends on broken objects

This is a straightforward change that aligns with the series' broader goal of supporting hash algorithm interoperability. The patch is small and focused, just adjusting test behavior for compatibility mode scenarios. It follows the pattern established elsewhere in the series for handling tests that involve broken objects.

The change is part of the final patch in v3 of this documentation and test infrastructure series, showing the author is tying up loose ends in the test suite to fully support the new compatibility features.
