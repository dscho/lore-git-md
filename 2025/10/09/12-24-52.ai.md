This is a feature patch series introducing signature handling parity between `git fast-export` and `git fast-import` for tags, completing Christian Couder's work to make signature handling consistent across Git's fast-import/export pipeline. The series adds a `--signed-tags=<mode>` option to `git fast-import` with the same modes (verbatim, warn-verbatim, warn-strip, strip, abort) as fast-export, though defaulting to verbatim rather than abort. 

The implementation builds on prior work adding commit signature handling, with preparatory patches modernizing documentation (patch 1), improving test infrastructure (patches 2-3), and fixing fast-export's signature handling to work with all signature types (patch 4). The core functionality in patch 5 introduces a new signed_tag_mode variable and handle_tag_signature() function in fast-import.c, using parse_signed_buffer() for universal format support.

Key technical details include: signature stripping via strbuf_setlen(), centralized signature logic that handles message size calculations correctly, and test coverage for all signature types (PGP, X.509, SSH). The series addresses review feedback from Patrick Steinhardt and others regarding documentation phrasing (using "cryptographic signature" terminology), test fragility (introducing ANNOTATED_TAG_COUNT), and implementation correctness. 

The changes since v1 reflect thorough review iteration: documentation improvements (patch 1), adopting Todd Zullinger's test infrastructure approach (patch 2), modernized test style (patch 4), and translation marking/comment formatting (patch 5). The series appears ready for merging, having resolved all technical and documentation concerns while maintaining backward compatibility.
