Refactoring patch concluding the packfile store API cleanup series. This completes the series' goal of standardizing pack iteration patterns while eliminating confusing API distinctions between "all" and non-"all" variants. The changes are mechanical replacements with no functional impact, maintaining the series' behavior-preserving approach.

Technical details show the rename affects core pack operations in fast-import (object storage and streaming) and pack-objects (kept pack handling), along with the fundamental pack iteration macro used throughout the codebase.
