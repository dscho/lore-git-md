Feature patch implementing comprehensive signature handling in `git fast-export`.

This is the fourth patch in a five-part series adding consistent signature handling between `git fast-import` and `git fast-export`. The patch focuses on making `fast-export` properly handle all Git-supported signature types (PGP, X.509, and SSH) rather than just PGP signatures.

The key change replaces a hardcoded PGP signature search with `parse_signed_buffer()`, which properly detects all signature formats. This matches the behavior already implemented in `fast-import` and completes the signature handling parity between the two commands. The patch includes new tests for X.509 and SSH signatures, verifying both verbatim export and signature stripping modes work correctly.

The implementation builds on prior work in the series that modernized documentation and test infrastructure. It uses the dynamic tag counting mechanism (ANNOTATED_TAG_COUNT) introduced earlier to maintain test reliability. The changes are cleanly scoped to signature detection logic while maintaining all existing behavior for unsigned tags and commits.

This appears to be a well-constructed patch that completes an important piece of the signature handling feature. The test coverage is thorough, exercising all three signature types with both verbatim and stripped output modes. The change follows the established pattern from earlier in the series and has already received positive review feedback on the technical approach.
