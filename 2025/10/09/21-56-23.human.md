This is a feature patch in the SHA-1/SHA-256 interoperability series, adding a new capability to `git rev-parse` to report the compatibility hash algorithm when one is configured.

The patch extends `git rev-parse --show-object-format` with a new `compat` option that prints the repository's compatibility hash algorithm (if configured) or an empty line if none exists. This provides plumbing command access to the same information that was previously only available through direct repository configuration inspection. The change is well-motivated as part of the broader hash algorithm transition work, where tools need to be aware of both the primary and compatibility hash formats.

Implementation is straightforward, adding the new option to both documentation and code while maintaining backward compatibility. The patch includes comprehensive tests that verify behavior with and without a compatibility hash configured, as well as proper error handling for invalid mode names. The empty-line output for unconfigured compatibility mode is explicitly designed to allow unambiguous parsing when combined with other `--show-object-format` options.

This appears to be a solid, focused addition to the interoperability infrastructure, with clear documentation and thorough test coverage. As part 6 of 9 in its series, it builds on the foundational work established in earlier patches while providing a self-contained feature that will be useful for scripts and tools dealing with hash algorithm compatibility.
