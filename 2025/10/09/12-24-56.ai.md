This is a feature patch extending `git fast-export`'s signature handling to support all Git signature types (PGP, X.509, SSH) consistently, part of Christian Couder's series to achieve parity between fast-import and fast-export.

The patch replaces the hardcoded PGP signature detection in `handle_tag()` with `parse_signed_buffer()`, which properly handles all signature formats Git supports. The change is straightforward - instead of looking specifically for PGP signatures with `strstr()`, it uses the existing `parse_signed_buffer()` helper that already knows about all signature types. The signature stripping behavior remains the same, just more comprehensive.

New tests verify the behavior with X.509 and SSH signatures, mirroring the existing PGP tests. Each signature type gets two test cases: one checking verbatim export (signature preserved) and one checking stripped export (signature removed). The tests use the dynamic `ANNOTATED_TAG_COUNT` mechanism introduced earlier in the series to avoid hardcoding tag counts.

This builds on prior work modernizing signature handling across Git, particularly the preparatory documentation updates and test infrastructure improvements covered in earlier patches. The implementation is clean and maintains backward compatibility while fixing the oversight that fast-export only handled PGP signatures. The test coverage is thorough, exercising all three signature types with both verbatim and stripped modes.
