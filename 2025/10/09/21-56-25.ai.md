This is a test infrastructure patch in the SHA-1/SHA-256 interoperability series, adding support for testing compatibility hash scenarios. It introduces several key testing components:

The patch enables specifying a compatibility hash via `GIT_TEST_DEFAULT_HASH="sha256:sha1"` syntax to test SHA-256 repositories with SHA-1 compatibility. It adds new test prerequisites `COMPAT_HASH` (for detecting compatibility mode) and `BROKEN_OBJECTS` (to skip tests that create deliberately broken objects when in compatibility mode, since they can't be properly rewritten).

Implementation details include:
- Extending `test_detect_hash` to parse the new colon-separated hash syntax, storing both storage and compatibility hashes in `test_hash_algo` and `test_compat_hash_algo` variables
- Adding `test_repo_compat_hash_algo` for global compatibility mode
- Defining `COMPAT_HASH` prerequisite that checks for non-empty `test_repo_compat_hash_algo`
- Creating `BROKEN_OBJECTS` prerequisite that fails when `COMPAT_HASH` is set
- Maintaining backward compatibility with existing `sha256`/`sha1` values

The changes support future work where tests will need to handle both hash algorithms during the transition period, particularly for cases like pack index v3 format testing (since v1/v2 lack multi-algorithm support). The patch lays groundwork for more comprehensive testing of the hash algorithm interoperability features being developed in this series.
