This is a test infrastructure patch in Christian Couder's series implementing signed tag handling parity between `git fast-import` and `git fast-export`. The patch addresses a fragility in the test suite where hardcoded tag counts could break if new tests added more annotated tags.

The change introduces a dynamic counter (`ANNOTATED_TAG_COUNT`) that tracks annotated tags as they're created, replacing the previous hardcoded values (3 and 4) in two test cases. This prevents future test additions from breaking these assertions. The solution is explicitly acknowledged as "a bit ugly" in the commit message, but preferred over alternatives that would hide the test interdependencies.

This patch follows up on earlier test infrastructure improvements in the series (including the `prepare_gnupghome()` helper) and precedes new tests for signed tag handling. The approach shows good attention to test reliability while maintaining clear documentation of the test suite's structure.
