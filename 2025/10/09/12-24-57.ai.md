This is the final patch in a series implementing consistent signature handling across `git fast-import` and `git fast-export`, adding a `--signed-tags=<mode>` option to match the existing `--signed-commits` functionality. The patch completes the symmetry between import/export operations for signed objects.

The implementation introduces a new `signed_tag_mode` variable in `fast-import.c` with the same set of modes as commits (verbatim, warn-verbatim, warn-strip, strip, abort). The default is `verbatim` (unlike fast-export's default of `abort`). The core logic reuses the existing `parse_signed_buffer()` function to handle all signature formats (PGP, X.509, SSH) consistently. The `handle_tag_signature()` function implements the mode behaviors with proper warning messages and signature stripping via `strbuf_setlen()`.

Test coverage is thorough, with new tests in `t9306-fast-import-signed-tags.sh` exercising all signature types and modes. The tests verify both signature preservation (verbatim modes) and removal (strip modes), including warning message output where applicable. The test infrastructure builds on the series' earlier improvements like `prepare_gnupghome()` and handles all three signature formats (PGP, X.509, SSH) through separate test blocks with appropriate GPG prerequisites.
