Test infrastructure patch improving tag counting in fast-export tests.

This patch modifies t9350-fast-export.sh to replace hardcoded tag counts with a dynamic counter (ANNOTATED_TAG_COUNT) that increments whenever a new annotated tag is added. The change addresses potential fragility when new tests adding tags are inserted between existing tests that verify tag counts. Christian Couder acknowledges this solution is "a bit ugly" but argues it's preferable to alternatives like reordering tests, as it makes the test interdependencies explicit rather than hiding them.

The implementation tracks tags through three test scenarios: initial setup (count=1), faked signed tag import (count=2), and two additional test cases that each increment the counter. Each test assertion now compares against $ANNOTATED_TAG_COUNT rather than hardcoded values (3 and 4 in the original). The patch maintains all existing test functionality including checks for tagger-less tags and the --fake-missing-tagger option.

This change comes as part of the larger series implementing --signed-tags support in fast-import/export, where Patrick Steinhardt had previously flagged test fragility concerns. The dynamic counting approach prevents future test additions from breaking existing assertions about tag quantities, though the solution introduces some test coupling via the shared counter variable. The patch follows the series' pattern of improving test infrastructure alongside core functionality changes.
