Feature implementation for `git fast-import` adding signature handling parity with `git fast-export`. This is the cover letter for a 5-patch series that introduces a `--signed-tags=<mode>` option to `git fast-import`, matching the existing functionality in `git fast-export`. The series has undergone significant review and iteration, with all technical concerns now resolved.

Christian Couder's work extends signature support to all types (PGP, X.509, SSH) consistently across both commands. The implementation includes documentation updates, test improvements, and core functionality changes. The series modernizes git-tag documentation to be more inclusive of non-GPG signing methods (per Patrick Steinhardt's suggestion) and improves test infrastructure in t/lib-gpg.sh and t9350-fast-export.sh.

The technical approach centralizes signature logic using parse_signed_buffer() for universal format support. The final patch adds the new `--signed-tags` option with the same modes as fast-export (verbatim, warn-verbatim, warn-strip, strip, abort), though defaulting to verbatim instead of fast-export's abort. The series addresses test fragility through a dynamic tag counting mechanism (ANNOTATED_TAG_COUNT) and incorporates Collin Funk's analysis of GPG directory creation behaviors.

Review feedback from Patrick Steinhardt, Todd Zullinger, and Collin Funk has been incorporated, including documentation wording improvements, test modernization, and proper handling of translation markers. The series is now ready for final submission, having resolved all technical and documentation concerns while maintaining backward compatibility.
