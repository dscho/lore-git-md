This is a test infrastructure discussion in the context of the `--signed-tags` feature series for `git fast-import`.

Collin Funk provides clarification about GPG and GPGSM behavior regarding home directory creation, responding to Christian Couder's uncertainty about whether these tools automatically create their home directories. The key findings are:

1. Both `gpg` and `gpgsm` will automatically create the default `~/.gnupg` directory if it doesn't exist.
2. However, when using a custom `GNUPGHOME` path (as done in tests), neither tool creates the directory automatically - they fail instead.

This technical note helps inform the test setup decisions in the signature handling series, though it doesn't require any immediate changes to the patches. The exchange shows careful attention to test environment details between contributors.
