This is a test infrastructure discussion in the GPG signature handling series. Collin Funk investigates whether GPG and GPGSM automatically create their home directories, responding to Christian Couder's uncertainty about test prereq behavior.

The email provides concrete test results showing that both `gpg` and `gpgsm` automatically create their default home directory (~/.gnupg) when it doesn't exist, but fail to create custom directories specified via GNUPGHOME or --homedir. This clarifies why the test prereqs differ in their directory creation behavior - GPGSSH's explicit `mkdir` is necessary when using non-default location, while GPGSM can rely on automatic creation when using the default path.

The findings suggest the test infrastructure could potentially be simplified by standardizing on default directory locations where possible, though the current explicit creation for GPGSSH remains correct for its use case. This technical clarification helps inform future test maintenance decisions in the signature handling code.
