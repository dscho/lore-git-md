This is a platform compatibility patch addressing a clang compiler warning. Johannes Schindelin fixes a situation where clang's `-Wunreachable` warning incorrectly flags code as unreachable when `NO_SYMLINK_HEAD` is defined (which happens on some systems like Windows). The code in question handles symlink creation for refs, which is platform-dependent behavior.

The solution borrows an existing pattern from the codebase (`NOT_CONSTANT` macro) to suppress the warning while maintaining the warning's usefulness in catching genuinely unreachable code elsewhere. The change is minimal (7 lines added, 1 changed) and clearly explained, targeting the refs/files-backend.c file.
