Documentation patch completing the standardization of `git-worktree` man page formatting. This is the third and final patch in Jean-Noël Avila's series converting command documentation to use Asciidoc's synopsis block format, following similar updates to `git-stash` and `git-tag`.

The changes are purely presentational, converting verse-formatted synopses to synopsis blocks (enabling automatic styling), standardizing option formatting with backticks, and replacing angle brackets with underscores for placeholders. The patch also properly includes the config section in the main man page rather than referring to it externally, matching the approach taken in the previous patches. 

Key technical details include:
- Updates both `git-worktree.adoc` (+161/-84 lines) and `worktree.adoc` config file (+14/-14 lines)
- Standardizes formatting of all commands (`add`, `list`, `lock` etc.) and options (`-f`, `--force`, `-b` etc.)
- Converts `<placeholder>` to _<placeholder>_ syntax throughout
- Adds conditional includes (`ifdef::git-worktree[]`) for config section integration
- Maintains all existing content while improving consistency with project documentation standards

The changes follow the same mechanical transformation pattern seen in the series' earlier patches, completing the standardization effort for these three commands. No behavioral changes or content modifications are introduced - this is purely a formatting improvement to align with Git's evolving documentation conventions.
