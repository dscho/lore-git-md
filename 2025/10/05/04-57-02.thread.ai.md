Gitweb configuration path handling bug report. Thread concerns a runtime failure where gitweb cannot find `gitweb_config.perl` when executed via web server due to Perl's `@INC` path changes (current directory no longer included by default). Two workarounds identified: modifying `gitweb.cgi` to explicitly reference `./gitweb_config.perl` or adjusting Makefile to set `GITWEB_CONFIG = ./gitweb_config.perl`. The Makefile solution was confirmed working after rebuild/reinstall. Issue previously reported in Gentoo's bug tracker (#675864), indicating known Perl compatibility problem. Technical impact limited to gitweb installation and CGI execution, specifically touching `gitweb.cgi` and gitweb Makefile. Open question whether absolute paths would provide more robust solution for production environments.
