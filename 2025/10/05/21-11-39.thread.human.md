This thread continues Jean-Noël Avila's ongoing effort to standardize Git's documentation formatting, focusing this time on the man pages for `git-stash`, `git-tag`, and `git-worktree`. The first patch updates `git-stash`'s formatting to use Asciidoc's synopsis blocks, which automatically apply proper styling to placeholders and options. It also standardizes option formatting with backticks, replaces angle brackets with underscores for placeholders, and reorganizes some sections for clarity—all without changing the actual content. Similar updates for `git-tag` and `git-worktree` will follow in subsequent patches. These changes are part of a broader project-wide documentation cleanup that has touched many commands' man pages, aiming to improve consistency and prepare for future tooling enhancements. The patches are being submitted via GitGitGadget, indicating the author's preference for the GitHub pull request workflow over direct mailing list submissions.
