Jean-Noël Avila has completed a three-part series standardizing the documentation formatting for `git-stash`, `git-tag`, and `git-worktree` commands. The final patch updates `git-worktree`'s man pages (+161/-84 lines) and its config documentation (+14/-14 lines), applying the same mechanical transformations seen in the earlier patches. 

All changes are presentational, converting verse-formatted synopses to Asciidoc's synopsis blocks, standardizing option formatting with backticks, replacing angle brackets with underscores for placeholders, and properly integrating config sections into the main man pages. The series maintains existing content while improving consistency with Git's evolving documentation standards. This work is part of Jean-Noël's ongoing project-wide effort to modernize Git's documentation format, with these three commands now fully aligned with the current conventions. The changes were submitted via GitGitGadget, reflecting the author's GitHub-based workflow.
