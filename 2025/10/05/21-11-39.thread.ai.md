Standardizing Git documentation formatting - part 3 (git-stash, git-tag, git-worktree)

Jean-Noël Avila's documentation patch series converting man pages for `git-stash`, `git-tag`, and `git-worktree` to Asciidoc synopsis style is now in the 'next' integration branch. The three mechanical formatting patches update git-stash.adoc (+85/-78 lines), git-tag.adoc (+104/-78 including config), and git-worktree.adoc (+161/-84 plus config), standardizing option formatting with backticks and converting placeholders to _<placeholder>_ notation.

Kristoffer Haugsbakk identified and Junio C Hamano confirmed a specific formatting edge case needing adjustment: command references in conditional Asciidoc blocks (`ifndef::git-stash[]`) must use backticks (`show`) rather than single quotes ('show') for proper verbatim formatting when included elsewhere. After investigation, Jean-Noël determined no cross-compatible solution works across both asciidoc.py and asciidoctor toolchains for the 'show' command reference in stash.adoc's conditional attribute. The decision is to leave the current single-quote formatting as-is rather than attempt a problematic reroll, accepting this minor compromise given toolchain limitations.

Junio C Hamano has verified the patch is correctly in 'next' branch and not marked "on hold", with Jean-Noël Avila reconfirming the toolchain limitation conclusion. This closes the discussion with consensus that no further changes are needed to the merged version, which remains technically correct despite the formatting compromise in conditional blocks.
