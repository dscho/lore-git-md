This is a documentation patch in René Scharfe's v2 about improving `git add --interactive` navigation. It clarifies the help text for hunk navigation commands (j/J/k/K) by removing redundant mentions of "leave this hunk undecided" since these commands only move between hunks without affecting their state. The changes make the documentation more concise and accurate.

Junio Hamano suggests in his reply that similar improvements could be made to the y/n' commands' help text, since they also move to the next hunk after making a decision. This would extend the patch's theme of making the interactive interface's behavior more transparent through documentation.

The patch is straightforward and uncontroversial, being the first in a series that goes on to implement more substantial behavior changes for hunk navigation. It demonstrates good attention to detail in improving user-facing documentation.
