This is a documentation patch focused on improving translation support by restructuring sentence fragments in the Git manual.

The patch modifies `Documentation/pretty-options.adoc` to combine what were previously broken sentence fragments into complete sentences. The author notes this change helps ensure proper translation, as translation tools work better with complete sentences rather than "lego" pieces that are assembled later.

The specific change affects the documentation of the `--notes` option, where conditional blocks (`ifdef`/`endif`) were previously splitting the description across multiple lines. The new version keeps each conditional variant as a complete sentence while maintaining the same technical content about when notes are shown by default for various Git commands.

This appears to be a straightforward improvement to the documentation's structure that should make it more maintainable and translation-friendly without altering any technical meaning. The patch is small and focused, touching only one file with simple line-oriented changes.
