This is a bugfix for gitweb, addressing a configuration file path issue. Rob Davies reports encountering a "No such file or directory" error when trying to use gitweb with a custom gitweb_config.perl file. The error occurs because Perl's @INC no longer includes the current directory (.) by default in newer versions.

The patch modifies both the gitweb.cgi script and the Makefile to explicitly use "./gitweb_config.perl" instead of just "gitweb_config.perl" when looking for the configuration file. This matches a solution previously identified in a Gentoo bug report. The fix is straightforward and appears to resolve the immediate issue cleanly.

The change is small and focused, affecting only gitweb's configuration handling. While the commit message could be more detailed about the Perl @INC change being the root cause, the practical solution is clearly presented and tested. This seems like a low-risk fix that would benefit anyone running gitweb with custom configurations on modern Perl installations.
