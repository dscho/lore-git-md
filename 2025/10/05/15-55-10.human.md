Documentation patch clarifying interactive hunk navigation commands in `git add -p`.

This is the first patch in René Scharfe's v2 series improving interactive hunk navigation. It focuses on making the help text for navigation commands (j/J/k/K) clearer by removing potentially confusing wording. The current hunk's state is now irrelevant to these commands - they simply move between hunks without affecting any hunk state. The changes are straightforward documentation updates in both the man page and the in-code help text, making the behavior more accurately described. This appears to be a well-justified improvement to user interface clarity, though it doesn't change any actual functionality. The patch is cleanly implemented with matching changes to both documentation sources.
