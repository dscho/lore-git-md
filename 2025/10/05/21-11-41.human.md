Documentation patch standardizing `git-tag` man page formatting.

This is the second patch in Jean-Noël Avila's series to convert Git command documentation to use Asciidoc's synopsis block format. Following the same pattern as the first patch (which updated `git-stash`), this makes mechanical formatting changes to the `git-tag` man page and its related config documentation. The changes include:

1. Converting command synopses from verse to synopsis blocks, enabling automatic styling of placeholders and keywords
2. Standardizing option formatting with backticks
3. Replacing angle brackets with underscores for placeholders in prose
4. Adding conditional includes to avoid redundant references between the man page and config documentation
5. Restructuring sections for better organization

The patch also moves the config documentation directly into the man page where appropriate, eliminating duplicate information. Like the first patch, these are purely presentational changes (+104/-91 lines) with no content alterations. The work continues the project-wide effort to standardize documentation formatting in preparation for future tooling improvements.
