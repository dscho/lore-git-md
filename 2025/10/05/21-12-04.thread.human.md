This thread discusses a documentation improvement to make Git's manual more translation-friendly. The patch restructures sentence fragments in `Documentation/pretty-options.adoc` into complete sentences, particularly around the `--notes` option description. The author explains that translation tools work better with whole sentences rather than conditional fragments that get assembled later. The changes maintain all technical content while improving the documentation's maintainability for translators. The modification is small and focused, touching only one file with clear line-oriented edits.
