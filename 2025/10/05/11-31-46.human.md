This is a feature and bugfix update for gitk, Git's graphical repository browser. The pull request bundles several improvements from multiple contributors, with the most notable being the introduction of UI themes and fixes for macOS compatibility.

The bulk of the changes come from Mark Levedahl's work on theming support, which modernizes gitk's appearance by switching to themed Tk widgets and adding configurable theme system. This includes converting various UI elements to use text labels instead of color blocks and removing legacy color configuration options. The changes appear thorough, touching many parts of gitk's interface while maintaining functionality.

Two notable bugfixes are included: Eric Sunshine addresses a crash on macOS Mojave, while Michael Rappazzo fixes an error that occurred when remote tracking branches were deleted. Johannes Sixt also includes merges of several topic branches that had been developed independently.

The changes are well-contained to gitk's Tcl/Tk codebase and don't affect core Git functionality. The theming work in particular looks like a significant modernization of gitk's aging UI, though the large diff (+164/-119 lines) suggests reviewers should pay attention to the widget conversion logic. The macOS fix and branch deletion handling are straightforward corrections for real user pain points.
