Documentation patch standardizing `git-stash` man page formatting.

This is the first of three patches in Jean-Noël Avila's series converting command documentation to use Asciidoc's synopsis block format. The patch updates both `git-stash.adoc` and its related config documentation (`stash.adoc`) with consistent formatting:

1. Converts the command synopsis to use Asciidoc's `[synopsis]` block format, which will automatically style placeholders and keywords
2. Wraps config variables and command options in backticks for consistent rendering
3. Uses `_<placeholder>_` syntax for variable names in descriptions
4. Cleans up redundant references to the man page within the config documentation
5. Adds conditional includes between the main man page and config documentation

The changes are purely presentational - no content is altered beyond formatting. The patch follows the same pattern as previous documentation standardization work in the Git project. While mechanical in nature, these changes help prepare for future documentation tooling improvements and maintain consistency across man pages.
