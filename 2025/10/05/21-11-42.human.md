Documentation patch completing the `git-worktree` man page standardization series.

This is the third and final patch in Jean-Noël Avila's series converting Git command documentation to use Asciidoc's synopsis block format. Following the same mechanical changes applied earlier to `git-stash` and `git-tag`, this update reformats the `git-worktree` man page (+161/-84 lines) and its associated config documentation (+14/-14 lines).

The changes standardize the formatting without altering content: converting verse-formatted synopses to synopsis blocks (enabling automatic styling), using backticks for commands/options, replacing angle brackets with underscores for placeholders, and properly including the config section in the main man page. The patch also fixes minor inconsistencies like consistently formatting boolean values as "`true`"/"`false`" and standardizing command references.

This completes the current round of documentation standardization for these three commands. The changes are purely presentational, maintaining all existing functionality while improving consistency with Git's evolving style guidelines. The patch follows the same high-quality approach as the previous ones in the series, with careful attention to detail in the mechanical conversions.
