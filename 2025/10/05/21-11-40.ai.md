Documentation patch standardizing git-stash man page formatting.

This is the first of three patches in Jean-Noël Avila's series converting command documentation to use Asciidoc's synopsis block format. The patch updates both `git-stash.adoc` and its related config documentation in `stash.adoc` with consistent formatting:

1. Converts the command synopsis from verse to synopsis blocks, which will automatically apply proper styling to placeholders (italics) and keywords (monospace)
2. Standardizes option formatting with backticks throughout
3. Replaces angle brackets with underscores for placeholders in prose (e.g. `<message>` becomes _<message>_)
4. Adds conditional includes to avoid redundant "see git-stash[1]" references when the config documentation is included in the main man page
5. Restructures some sections for better organization, particularly around command options

The changes are purely presentational - no content is altered beyond formatting. The patch follows the same pattern seen in previous documentation standardization efforts, applying mechanical updates to improve consistency and prepare for future tooling improvements. The diff shows significant line count changes (+85/-78) due to the restructuring, though the actual content remains functionally equivalent.
