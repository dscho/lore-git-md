Performance optimization for `git last-modified` command.

This is a follow-up in the ongoing performance optimization thread for `git last-modified`, which aims to speed up finding the most recent commit modifying each path. The current discussion focuses on a compiler warning fix in v2 of the patch series.

Toon Claes responds to Junio C Hamano's observation about a signed/unsigned comparison issue in the `path_idx()` helper function. The function was incorrectly returning -1 (signed) while declared to return size_t (unsigned). Rather than fixing the type mismatch, Toon chose to eliminate the helper function entirely in v3 by inlining its logic where used.

This is a minor implementation refinement in a larger performance optimization effort that has seen multiple rounds of review. The core algorithm using priority queues and EWAH bitmaps has already shown significant speed improvements (2.5x-9.3x faster on git.git). The thread remains active with detailed technical discussions between Toon Claes, Taylor Blau, Jeff King, and Junio C Hamano addressing both immediate compilation issues and deeper design questions.
