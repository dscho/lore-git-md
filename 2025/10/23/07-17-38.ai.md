This is a CI infrastructure patch, the first in a 3-part series introducing cbindgen support for Rust-C interoperability in Git. The patch switches the 32-bit CI testing platform from Ubuntu (which has ended support for 32-bit systems) to Debian, which continues to maintain its 32-bit port.

The change affects multiple CI configuration files (.github/workflows/main.yml, .gitlab-ci.yml, ci/install-dependencies.sh, ci/lib.sh), updating image references and package installation logic. The Ubuntu image was problematic both because it's end-of-life and because it lacks certain packages needed for the upcoming cbindgen integration. The patch makes straightforward mechanical changes to use Debian instead, with corresponding adjustments to package installation (notably switching from language-pack-is to locales-all for the 32-bit environment).

This appears to be a well-justified infrastructure update that enables the subsequent patches in the series. The changes are focused and clearly motivated by both maintenance concerns (Ubuntu's EOL status) and forward-looking needs (preparing for cbindgen support). The patch maintains the existing 32-bit testing capability while using a better-supported platform.
