This is part 7 of Patrick Steinhardt's 14-part refactoring and performance optimization series for Git's refs subsystem. The patch focuses on propagating peeled object IDs through the ref-filter subsystem to avoid redundant object parsing.

The change modifies the ref-filter interface to carry peeled OIDs through the ref array rather than discarding and re-parsing them. This eliminates unnecessary object database lookups when processing tags, particularly benefiting commands like `git ls-remote`, `git tag`, and `git verify-tag` that work with peeled references. The patch updates several callers to pass the peeled OID where available.

This is a straightforward refactoring that builds on earlier work in the series to modernize the refs interface. It touches multiple commands but follows a consistent pattern - adding a peeled_oid parameter where previously only the base OID was passed. The changes appear mechanical and well-contained, with no obvious behavioral changes beyond the performance optimization.

As part of a larger performance-focused effort, this patch helps pave the way for the lazy object parsing optimizations that come later in the series.
