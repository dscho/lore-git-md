This is a bug report and documentation suggestion regarding custom diff drivers and textconv configuration. The email describes several issues encountered when misconfiguring a PDF diff driver, where the root cause was using `pdftotext` without proper stdout redirection. The author notes this led to empty file outputs without clear warnings from Git.

Key technical details for future reference include:
1. Textconv drivers with `cachetextconv` unexpectedly create commits, exposing repo configuration issues
2. Custom diff drivers execute in temporary directories that Git attempts to clean up, but failure messages about leftover files are unclear
3. `git diff` and `git log` crash ungracefully when diff drivers fail, truncating output
4. `--simplify-by-decoration` behavior creates synthetic commits that might confuse users

The report suggests improving documentation around these edge cases and adding better diagnostics for misconfigured textconv drivers. While the immediate issue was user error, the email highlights several areas where Git's behavior could be more robust or better documented, particularly around temporary file handling and error reporting for custom diff tools.
