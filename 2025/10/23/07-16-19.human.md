Refactoring patch removing obsolete peeling infrastructure in the refs subsystem. This is part 10/14 of Patrick Steinhardt's series modernizing Git's reference handling.

The patch removes the now-unused `ref_iterator_peel()` interface and all its implementations across the refs backend code. This cleanup is possible because the series has migrated all peeling operations to use the new `struct reference`-based approach instead. The changes are mostly straightforward deletions, with one notable update in `packed-backend.c` where it now directly uses the peeled OID from the iterator rather than performing a separate peeling operation.

This continues the architectural cleanup from earlier patches in the series, eliminating technical debt as the new peeling interface becomes the standard. The changes maintain all existing functionality while simplifying the codebase. The patch appears well-contained and mechanical, with no behavioral changes beyond the intended removal of obsolete code paths.
