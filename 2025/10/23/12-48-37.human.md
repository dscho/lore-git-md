This is a debugging update in a thread investigating a platform-specific bug in Git's notes functionality on NonStop systems. Jeff King (Peff) responds to Randall Becker's findings about the mysterious exit code 037777777764 (-12 in decimal) from `git notes show HEAD`.

The key observation is that while directly running `git show $(git notes list HEAD)` works correctly, the wrapped `git --no-pager notes show HEAD` still produces the incorrect exit code. Randall's debugger shows registers rsx and rsi containing 12 at git.c:982, suggesting possible uninitialized return value propagation.

Peff acknowledges the strangeness of the discrepancy between direct and execvp() invocation of git-show, and suggests further debugging by tracing through to the exec system call and potentially continuing execution in the new process image. The response indicates this remains an open investigation into Git's process execution plumbing on the NonStop platform, with the root cause still not identified.
