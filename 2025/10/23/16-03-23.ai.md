Feature patch for configurable diff algorithm in `git blame`, now with additional technical review from Phillip Wood.

Phillip Wood provides a detailed technical review of Antonin Delpeuch's patch to make the diff algorithm configurable in `git blame`. He agrees with the general approach but identifies several specific implementation issues that need addressing. First, he notes the config parsing should clear both `XDF_DIFF_ALGORITHM_MASK` and `XDF_NEED_MINIMAL` flags, mirroring the behavior in the option parsing code. He also points out a C++-style comment that should be converted to standard C comment syntax. Most significantly, he highlights an interaction between the new diff algorithm selection and `git blame`'s existing `--minimal` option that needs to be handled - the `--minimal` flag should clear any previously set diff algorithm selection.
