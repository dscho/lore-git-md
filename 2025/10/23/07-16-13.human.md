This is a refactoring patch in Patrick Steinhardt's performance optimization series for the refactoring subsystem. It's the fourth patch in a 14-part series that builds on previous work modernizing Git's reference handling.

The patch focuses on cleaning up how reference status flags are handled in the code. It changes the flags from preprocessor `#define` macros to a proper `enum` type, and updates the underlying storage from `int` to `unsigned` to follow modern Git coding conventions. The actual flag values and their meanings remain the same - they still track whether references are symbolic, packed, broken, or malformed - but the implementation is now more type-safe and maintainable.

This is part of the larger effort to improve the separation between transport-related `struct ref` and core ref `struct reference` types. While this particular change is purely internal, it helps pave the way for the more significant performance optimizations later in the series, particularly the lazy object parsing in patch 14. The change is straightforward and mechanical, touching only `refs.h` with 21 lines added and 20 removed.

The patch appears well-contained and low-risk, following the established pattern of the series where foundational refactoring comes before behavior changes. It maintains the same careful attention to detail seen in earlier patches of the series.
