This is the final version of a performance-oriented refactoring in the gpg-interface code, part of a completed Outreachy contribution series. The patch simplifies SSH key fingerprint extraction by replacing strbuf_split() operations with direct string parsing using strchr() and xmemdupz(), eliminating unnecessary memory allocations.

The change focuses on `get_ssh_key_fingerprint()`, which processes output from `ssh-keygen`. Previously it used strbuf_split_max() to parse the output into temporary strbufs, despite only needing simple string extraction. The new version directly finds the fingerprint between spaces using strchr() and duplicates just the relevant portion with xmemdupz().

The patch represents the culmination of several review iterations, incorporating feedback from Junio Hamano (who identified the optimization opportunity) and Christian Couder (who suggested readability improvements). The v6 version includes final polish to error messages and code structure while maintaining all security checks through the existing is_literal_ssh_key() validation.
