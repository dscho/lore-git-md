This is a bugfix investigation for a platform-specific issue with Git notes on NonStop systems. Jeff King (peff@peff.net) responds to Randall Becker's debugging efforts around the anomalous exit code -12 (037777777764 octal) from `git notes show HEAD`. The key observation is that while directly running `git show $(git notes list HEAD)` works correctly, the `git notes show` wrapper path still produces the wrong exit code, suggesting the issue lies in Git's process execution plumbing on NonStop.

The discussion focuses on the execution path differences between direct command invocation and the notes wrapper path, with debugger observations showing register values containing 12 at git.c:982. Jeff suggests further debugging by tracing through to the exec system call and attempting to follow into the exec'd process image, as the current evidence points to uninitialized return value propagation or platform-specific handling in `execv_git_cmd()`.

Technical details to note for future reference: the issue manifests specifically in the `git notes show` -> `git show` command chain on NonStop big endian systems, with exit code -12 being observed. The working direct invocation versus broken wrapper path suggests the problem lies in Git's process execution machinery rather than the notes functionality itself. The debugger register observations (rsx and rsi containing 12) hint at potential uninitialized value propagation in the NonStop execution path.
