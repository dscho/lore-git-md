This is a cover letter for a 3-patch series introducing cbindgen support to the Git Rust infrastructure. The series lays groundwork for future Rust-C integration by setting up automated header generation from Rust's `extern "C"` blocks.

The first two patches are preparatory: one updates CI to use Debian instead of deprecated Ubuntu i386 images, while the other renames the Rust library target in meson for consistency. The key patch introduces cbindgen configuration to generate C headers from Rust code, with an initial use case verifying varint implementation parity between Rust and C. The series builds on recent Rust infrastructure work including Windows support.

The changes touch multiple build systems (Makefile, meson), CI configurations, and add a new cbindgen.toml config file. The varint.c additions suggest this will be used immediately for testing Rust/C interoperability, with broader integration planned for future work. The series appears well-structured with clean separation of concerns between the setup patches and the core functionality addition.
