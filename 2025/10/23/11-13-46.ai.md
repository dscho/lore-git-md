This is the final version (v6) of a bugfix and performance optimization patch in the gpg-interface subsystem, completing an Outreachy contribution series. The patch replaces strbuf_split_max() with direct string parsing in get_ssh_key_fingerprint(), implementing Junio Hamano's original suggestion to eliminate unnecessary strbuf overhead when processing SSH key fingerprints.

The key technical change replaces the three-step strbuf split operation with two strchr() calls to locate space delimiters, followed by xmemdupz() to copy the middle token (the actual fingerprint). This maintains the same security checks via is_literal_ssh_key() while simplifying memory management. Error handling remains robust with die() calls for malformed input. The v6 iteration includes final polish on Christian Couder's suggested error message formatting and commit message improvements.

The patch represents the conclusion of a well-reviewed series where all feedback from maintainers (Junio Hamano, Christian Couder, Kristoffer Haugsbakk) has been addressed across multiple iterations. CI tests pass, and no further changes are expected. This change follows the pattern established in sub-process.c (d6fd08bd) for direct string parsing.
