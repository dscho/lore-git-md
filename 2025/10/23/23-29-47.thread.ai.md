Thread summary:

Bug report and documentation suggestion regarding custom diff drivers and textconv configuration, originating from user experience with PDF diff driver misconfiguration. Core issue involves `pdftotext` execution without stdout redirection leading to empty outputs, exposing several Git behavior edge cases.

Technical details captured:
- Textconv with `cachetextconv` creates commits unexpectedly, revealing repo config problems
- Custom diff drivers run in temp dirs with unclear failure messages about leftover files
- `git diff`/`git log` crash ungracefully when diff drivers fail, truncating output
- `--simplify-by-decoration` creates synthetic commits that may confuse users

Documentation gaps identified for:
- Temp file handling in custom diff drivers
- Error reporting for misconfigured textconv
- Behavior of `cachetextconv` commit creation
- Synthetic commit behavior with decoration filtering

Suggested improvements focus on better diagnostics for driver failures and clearer documentation of these edge cases. While root cause was user error (missing stdout redirection), the thread highlights multiple areas where Git's behavior could be more robust or better explained to users configuring custom diff tools.
