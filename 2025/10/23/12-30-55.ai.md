Bugfix follow-up addressing an unrelated but long-standing output redirection issue in external diff handling.

Jeff King identifies a separate bug in the external diff machinery that predates the current dry-run mode fixes. When using `--output` with an external diff (via `GIT_EXTERNAL_DIFF`), the external diff's output incorrectly goes to stdout rather than the specified output file. This has been broken since `--output` was introduced.

The issue stems from `run_external_diff()` not properly respecting the diff output file descriptor (`o->file`), instead only handling quiet mode suppression. Jeff proposes a simple fix that flushes the output file and assigns its descriptor to the child process. While this isn't directly related to the dry-run regression being fixed in the main thread, it's a clear bug that should be addressed separately.

The proposed solution would make external diff output respect `--output` redirection consistently with Git's internal diff output. Jeff notes this doesn't need to block the current dry-run fixes, as it's an independent issue. The patch demonstrates solid understanding of the diff machinery, though Jeff hasn't fully tested it beyond verifying basic functionality.
