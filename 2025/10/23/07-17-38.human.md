CI / build system patch that updates 32-bit testing infrastructure. This is the first of a 3-part series introducing cbindgen support for Rust-C interoperability in Git.

The patch switches CI jobs from the deprecated Ubuntu i386 image to Debian's maintained 32-bit platform. Ubuntu ended support for 32-bit systems, making its image both outdated and missing required packages - notably causing issues for the upcoming cbindgen integration in later patches.

Changes touch CI configuration across GitHub Actions and GitLab CI, updating image references and adjusting package installation logic. The transition appears straightforward, replacing `i386/ubuntu` with `i386/debian` in four files while maintaining the same test coverage.

This is a necessary infrastructure update that enables the path for the series' main goal of Rust-C bindings. The change is well-motivated and cleanly implemented, with no obvious drawbacks to the switch.
