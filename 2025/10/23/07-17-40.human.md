This is the third patch in a series introducing cbindgen support to Git's Rust infrastructure, focusing on automated C header generation from Rust code. The patch implements the core functionality by setting up cbindgen in both Makefile and Meson builds to generate C bindings from Rust's `extern "C"` functions. The initial use case verifies interface compatibility between Rust and C implementations of varint encoding, where mismatches will now cause compilation errors rather than silent runtime issues.

The implementation generates a "c-bindings.h" file that's specifically included in varint.c (rather than varint.h) to avoid unnecessary recompilation of dependent files when Rust interfaces change. The patch also updates CI to install cbindgen and adds proper cleanup rules for generated files.

This appears to be a well-considered technical solution to a real problem in Git's gradual Rust adoption. The approach is pragmatic (focusing first on interface verification) and the implementation is thorough, touching build systems, CI, and core functionality. The commit message clearly explains both the immediate need (varint verification) and the broader context (future Rust-C interoperability).
