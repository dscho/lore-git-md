Refactoring patch in a performance optimization series, converting reference status flags from preprocessor defines to an enum and changing the storage type from `int` to `unsigned`.

This is patch 4/14 in Patrick Steinhardt's series modernizing the refs subsystem. The change converts the reference status flags (symbolic ref, packed ref, broken ref, bad name) from `#define` macros to an `enum reference_status` and changes the storage type in `struct reference` from `int` to `unsigned`. This aligns with Git's modern best practices for flag handling.

The patch is a straightforward mechanical conversion that:
1. Groups related flags into a proper enum
2. Changes the bitfield storage to unsigned
3. Maintains all existing flag values and semantics
4. Updates the documentation to reference the new enum

This continues the series' architectural cleanup work by standardizing how flags are handled in the refs subsystem. The change is purely internal - no behavior or interface changes are introduced. The patch touches only refs.h, modifying 41 lines (21 insertions, 20 deletions) to implement the conversion.

The change fits into the larger series by being part of the interface refactoring phase (patches 1-8) that prepares the performance optimizations in later patches. It follows patch 3's iterator state cleanup and precedes the peeling infrastructure removal in patches 9-10. The enum conversion makes the code more maintainable and provides better type safety for the flags that will be used throughout the refs subsystem modernization.
