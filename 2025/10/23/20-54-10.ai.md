This is the maintainer approval for the symlink deprecation patch series. Junio C Hamano gives final sign-off on Patrick Steinhardt's v2 patch to deprecate `core.preferSymlinkRefs`, indicating it will be merged into the 'next' branch. The patch has gone through two iterations with review feedback incorporated, including documentation wording improvements and adjustments to warning message placement. 

The change marks the end of a 20-year-old feature that allowed writing symbolic refs as symlinks, transitioning fully to the modern textual symref format. While reading symlinks remains supported for backward compatibility, writing them now triggers a deprecation warning. The implementation uses a `warn_once` mechanism to avoid spamming users and carefully positions warnings after potential error conditions.

With this approval, the Git project moves forward with plans to remove symlink writing entirely in Git 3.0, having addressed all technical considerations around warning timing, backward compatibility, and documentation clarity through the review process. The change affects the files backend implementation and related test infrastructure, with updates to both technical docs and user-facing configuration documentation.
