Bugfix patch in a refactoring series improving tag verification. This is part of Patrick Steinhardt's ongoing work to modernize Git's refs subsystem, specifically addressing tag peeling behavior.

The patch fixes a subtle edge case where `git-for-each-ref` could fail to detect corrupted tags when they point to the same object but declare different types. Currently, the corruption is only caught when comparing two such tags, but this change ensures verification happens during the initial peeling operation by using the new `PEEL_OBJECT_VERIFY_OBJECT_TYPE` flag.

The change is small (3 lines of code) but important for correctness, and includes an expanded test case to verify the fix works when dereferencing a single broken tag.
