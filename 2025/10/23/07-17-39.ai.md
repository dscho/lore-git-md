Build system refactoring in the Rust infrastructure series. This is the second patch in a 3-part series introducing cbindgen support for Rust-C interoperability.

The patch simplifies the meson build system by renaming the Rust library target from `git_rs` to `rust`. The change makes the target name more intuitive and consistent with the existing Rust test target naming. The new name allows developers to compile just the Rust components using the more memorable `meson compile rust` command.

The modification is straightforward, touching only the meson.build file to update the custom_target name while keeping all other build parameters unchanged. This appears to be a pure naming improvement with no functional impact, aligning with the series' goal of cleaning up Rust infrastructure in preparation for cbindgen integration.

Key technical details for future reference:
- Build system file modified: src/meson.build
- Old target name: `git_rs`
- New target name: `rust`
- Maintains same build parameters and dependencies
- Matches existing test target convention (`meson test rust`)

The change seems uncontroversial and well-justified as part of standardizing Rust-related build targets. It follows naturally from the CI preparation in patch 1 and precedes the core cbindgen functionality in patch 3.
