This is the final patch in a 2/2 series completing the strbuf refactoring work in gpg-interface.c, specifically targeting the SSH key handling functions. The patch focuses on `get_default_ssh_signing_key()`, which previously used `strbuf_split_max()` to parse key output.

The key change replaces the strbuf-based parsing with direct string manipulation using `strchr()` and `xmemdupz()`/`xstrdup()`. The new implementation:
1. Locates the newline with `strchr()`
2. Conditionally duplicates either the first line (if no newline, the entire buffer) using `xmemdupz()`/`xstrdup()`
3. Maintains the existing security check via `is_literal_ssh_key()`
4. Simplifies memory management by eliminating temporary strbuf allocations

The patch follows Christian Couder's suggestion for clearer newline/null terminator handling, implementing a conditional split that improves readability while maintaining the same functionality. Error handling remains unchanged, continuing to warn about invalid key formats or command failures.
