Final patch in a refactoring series simplifying SSH key handling in gpg-interface.c. This change replaces strbuf_split_max() with direct string parsing in get_default_ssh_signing_key(), using strchr() and xmemdupz()/xstrdup() to extract the first line of key output. The patch follows Junio Hamano's original suggestion to eliminate unnecessary strbuf overhead while maintaining security checks via is_literal_ssh_key().

The implementation now cleanly separates the line extraction logic with conditional for newline handling, addressing Christian Couder's feedback from earlier versions. Memory management is simplified by directly returning the duplicated line when valid, or freeing it immediately when invalid. Error messages remain unchanged for consistency.

As the concluding patch in Bello Olamide's Outreachy contribution, this represents the polished final version after six iterations, with all maintainer feedback incorporated. The series successfully achieves its goal of optimizing these functions while preserving their security properties, marking a clean conclusion to this strbuf cleanup effort.
