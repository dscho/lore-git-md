This is a cover letter for a 3-patch series introducing Rust infrastructure changes, specifically adding cbindgen support for generating C headers from Rust code.

Patrick Steinhardt proposes adding cbindgen to the build system to facilitate calling Rust code from C. The immediate use case is verifying Rust's varint implementation matches the C version, but the infrastructure will enable future Rust-C interoperability. The series builds on recent Rust support work in the codebase.

The patches include CI updates (switching from deprecated i386/ubuntu to Debian), a meson build system tweak (renaming the Rust library target), and the core cbindgen addition with configuration. The changes touch multiple build system files but appear focused and well-contained.

This looks like a solid infrastructure addition that enables future Rust integration work. The commit messages and cover letter clearly explain the motivation and scope. The changes are appropriately scoped for the stated goal, and the series appears ready for review.
