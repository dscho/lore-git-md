This thread addresses a test fix for OpenSSH compatibility in `t7528-signed-commit-ssh.sh`. The test verifies commit signing with SSH keys but broke on OpenSSH 10.1+ due to socket path length limitations. Newer OpenSSH versions changed the agent socket location from `/tmp` to `~/.ssh/agent`, which - combined with Git's test directory structure - could exceed Unix domain socket path limits (108 characters on Linux).

The solution, developed with input from Jeff King and brian m. carlson, uses `ssh-agent -T` to force the old `/tmp` behavior on newer OpenSSH versions while maintaining backward compatibility. This minimal change avoids more invasive path-shortening approaches that might still hit limits. The commit message thoroughly documents both the problem and solution rationale.
