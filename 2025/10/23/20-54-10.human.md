Maintainer approval for symlink ref deprecation patch. This is the final step in the process to phase out the legacy symlink`-based symbolic ref storage in favor of the modern textual format.

Junio C Hamano, the project maintainer, gives the green light to Patrick Steinhardt's v2 patch that deprecates `core.preferSymlinkRefs`. The patch had already gone through one revision with improvements to warning timing and documentation wording. Junio confirms the changes look good and marks it for inclusion in the 'next' branch, meaning it will be part of an upcoming release.

This concludes the discussion thread about deprecating symlink refs, which began with Patrick's initial proposal. The change will first introduce warnings when symlinks are written, with full removal planned for Git 3.0. The implementation preserves backward compatibility by continuing to read existing symlinks while only changing the write behavior.
