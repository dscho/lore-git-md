Git maintainer Junio C Hamano responds to Jeff King's patch fixing the `**` pattern matching issue in `.gitignore` files. This is a bugfix addressing incorrect wildcard matching behavior.

Junio agrees with the core approach of preserving one character of prefix context to fix the `foo**/bar` matching `foobar` problem, calling it a reasonable solution despite being a "disgusting hack." He shares Jeff's intuition that the prefix-matching optimization's main benefit comes from skipping `fnmatch` entirely for non-wildcard patterns, not from shrinking the input to `fnmatch`.

The email suggests two potential alternatives: (1) completely dropping the prefix-shrinking optimization while keeping the no-wildcards fast path, or (2) making a more targeted fix that only adjusts the prefix when encountering `**/` patterns. Junio prefers checking for complete matches before doing any prefix stripping, which would simplify some cases.

The response maintains the patch's RFC status while providing maintainer perspective on the tradeoffs. Junio's feedback indicates the fix is conceptually sound but leaves room for refinement in implementation details before finalizing.
