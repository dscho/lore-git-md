This is a bug report and documentation suggestion regarding custom diff drivers in Git. The author, Gesh, shares their experience troubleshooting a misconfigured `diff.pdf.textconv` setting where they incorrectly used `pdftotext` without proper stdout redirection. While they resolved their specific issue, they highlight several surprising behaviors that could be better documented or improved.

The report notes four key observations: (1) textconv drivers with cachetextconv create commits, which surfaced due to per-repo user configuration; (2) custom diff drivers run in temporary directories that Git attempts to clean up; (3) Git commands crash ungracefully when diff drivers fail; and (4) unexpected behavior with `--simplify-by-decoration`. While acknowledging the root cause was their own configuration error, Gesh suggests these edge cases could benefit from clearer documentation or error messages.

The report is well-articulated and provides concrete examples of real-world confusion points, making a strong case for improving the user experience around diff driver configuration and failure modes. The issues described appear legitimate, though some (like the crash behavior) may be more pressing to address than others (like the decoration behavior).
