This is a refactoring patch in a series introducing cbindgen support for Git's Rust infrastructure. It's the second of three patches, following CI preparation and preceding the core cbindgen functionality.

The patch makes a straightforward change to the meson build system, renaming the Rust library target from `git_rs` to simply `rust`. The author explains this makes the target name more memorable when compiling (`meson compile rust`) and consistent with the existing test target name (`meson test rust`).

The change is minimal - just a single line modification in `src/meson.build` - and appears well-justified for consistency and usability. As part of the larger cbindgen series, this seems like a sensible cleanup before adding new Rust-C interoperability features. The patch follows typical Git contribution standards with a clear commit message and proper sign-off.
