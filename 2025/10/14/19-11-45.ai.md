This is a refactoring patch that removes the now-unused `packfile_store_get_packs()` function, completing the cleanup of pack iteration patterns in the packfile store API. The patch follows the series' methodology of first converting all callers to the new API (in this case, to `packfile_store_get_all_packs()`) before removing the deprecated interface.

The removed function had confusing behavior as it excluded packs referenced by the MIDX (multi-pack index), creating potential inconsistencies. Justin Tobler confirms the cleanup is appropriate now that all callers have been migrated, noting the elimination of this stateful behavior as a positive outcome. The change is purely internal with no user-facing impact, continuing the series' focus on simplifying pack subsystem internals.

The removal affects packfile.h's API surface but requires no other code modifications since all previous callers were already updated in earlier patches. This represents the final step in standardizing pack iteration patterns across the codebase, following the introduction of the `repo_for_each_pack()` macro and other improvements in the series. The patch maintains the series' high quality with a clear, focused change that completes an architectural cleanup path.
