Test modernization patch in the `git rebase --trailer` series.

This is a small but sensible cleanup in the test suite for the ongoing `--trailer` rebase feature. Li Chen updates the test script to use the standard `example.com` domain rather than the made-up `ex.com` in test email addresses. This follows Git's convention of using example.com for test data to avoid any confusion with real domains.

The change is purely cosmetic - it doesn't affect test functionality - but it brings the test in line with Git's standard practices. The patch is straightforward, updating both the test commands and expected output to use the new domain consistently. This is part of the large 29-patch series adding trailer support to rebase, but stands alone as a minor test improvement.
