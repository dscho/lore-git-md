This is a refactoring patch in Dragan Simic's ongoing series to add `--trailer` support to `git rebase`. The change moves trailer processing earlier in the commit sequence, modifying the in-memory commit message directly in `do_pick_commit()` rather than writing to a file first. 

The key changes are:
1. Trailer addition now happens before writing the message file, using the new `amend_strbuf_with_trailers()` function
2. The file-based `amend_file_with_trailers()` path is removed since it's no longer needed
3. The `amend_strbuf_with_trailers()` function is promoted from static to public by adding its declaration to trailer.h

The patch maintains the same behavior while simplifying the flow - trailers are added to the commit message buffer before any file I/O occurs. This appears to be a straightforward improvement to the series' architecture, though it's worth noting that the error handling remains identical (just moved earlier in the process). The change is well-contained, touching only the necessary files with clean, focused diffs.
