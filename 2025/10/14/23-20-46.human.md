This is Junio Hamano's regular "What's cooking in git.git" status update, providing an overview of recent developments in the Git project. The email serves as both a progress report and a coordination tool for maintainers and contributors.

Several topics have recently graduated to 'master' (the main development branch), including:
- Cleanups to the xdiff library internals
- Documentation markup fixes
- A new `:(optional)` prefix for pathname configuration values
- Improvements to how `git add -p` handles hunk splitting
- Enhanced consistency checks for the reftable backend
- CI fixes for Ubuntu's sudo implementation

Notable new topics under discussion include:
- A proposal to deprecate symlink-based symref storage (targeting Git 3.0)
- Rust integration improvements in CI
- A major refactoring of the repack machinery
- New `git history` command for rewriting history
- SHA1-SHA256 interoperability work
- Submodule gitdir path encoding to prevent conflicts

The email also notes some topics that have been discarded due to inactivity, reminding contributors that stalled efforts can be resubmitted when ready. Junio highlights an upcoming maintenance release (2.51.1) that will improve the deprecation warning for the long-obsolete `whatchanged` command.

This status report provides a comprehensive snapshot of Git's development activity, showing both steady progress on core improvements and the emergence of significant new features and infrastructure changes. The mix of documentation fixes, code cleanups, and experimental features reflects the project's balanced approach to maintenance and innovation.
