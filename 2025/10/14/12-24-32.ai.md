This is a test refinement patch in the ongoing `--trailer` support for `git rebase` series. It improves the test assertions in t3440-rebase-trailer.sh by replacing fragile pipeline-based checks with more robust `test_commit_message` verifications.

The changes focus on two test cases that verify trailer behavior during rebase:
1. The duplicate trailer handling test now explicitly checks for the expected commit message format with the last duplicate trailer preserved, rather than using separate grep checks.
2. The multiple Signed-off-by test now verifies both trailers appear in the expected format in the commit message, replacing the previous line-counting approach.

The new assertions are more precise and reliable since they:
- Catch git command failures that might have been missed by the pipeline approach
- Verify the exact message structure rather than just presence/absence of lines
- Make the expected output format more visible in the test itself
- Maintain the same test coverage while being less prone to false positives

This continues the series' pattern of incremental test improvements, now focusing on assertion quality rather than functionality. The change is minimal (17 lines added, 7 removed) but makes the tests more maintainable and their expectations more explicit.
