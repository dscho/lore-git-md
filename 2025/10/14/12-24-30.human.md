This is a test cleanup patch in the ongoing `--trailer` rebase series. It refactors the test setup in t3440-rebase-trailer.sh to create expected output files only when they're needed by specific test cases, rather than generating them all up front during the shared history setup.

The change removes the bulk creation of `*-signed` files in the initial setup and instead creates them just before the tests that actually use them. This makes the test suite more maintainable by:
- Reducing unnecessary fixture creation
- Making it clearer which tests depend on which expected outputs
- Keeping related test data closer to where it's used

The patch is small (4 insertions, 8 deletions) and focused, maintaining all existing test coverage while improving the test structure. It's part of the larger effort to add trailer support to `git rebase`, but this particular change is purely about test organization.
