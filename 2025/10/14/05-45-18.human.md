This is a documentation refinement in the ongoing `gitdatamodel.adoc` patch series discussion. Patrick Steinhardt responds to Junio Hamano's feedback about how to accurately describe Git's reference hierarchy in the new documentation.

Steinhardt proposes new wording that focuses on the semantic meaning of root references rather than their storage location or handling. The suggested text acknowledges that root references have special meaning to Git commands while avoiding discussion of pseudo-refs (like FETCH_HEAD) that might confuse readers. This keeps the documentation focused on the conceptual model rather than storage implementation details.
