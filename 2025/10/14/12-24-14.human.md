Refactoring patch for trailer handling internals, part of a larger series adding `--trailer` support to `git rebase`. This is patch 1/29 in the fourth iteration of the series.

The patch moves trailer manipulation from an external `interpret-trailers` process into in-process Git operations via a new `amend_strbuf_with_trailers()` function. This eliminates fork/exec overhead and simplifies error handling while maintaining the same functionality. The change centralizes trailer processing logic in preparation for the rebase integration that comes later in the series.

Key technical changes:
- Removes tempfile handling from `interpret-trailers.c`
- Adds new `trailer_process()` function that handles all trailer operations in memory
- Makes `amend_file_with_trailers()` use the new in-process path
- Preserves all existing behavior while being more efficient
