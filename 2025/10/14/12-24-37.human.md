Test refinement patch in the `git rebase --trailer` series. This is patch 24/29 in the fourth iteration of Dragan Simic's work to add trailer support to `git rebase`.

The patch introduces a new test helper `expect_trailer_msg()` that wraps `test_commit_message` and deduplicates the trailer checking logic by using a shared `REVIEWED_BY_TRAILER` constant. This replaces several ad-hoc test files and manual trailer checks with a more consistent approach. Key changes include:

1. Consolidating trailer verification into a single helper that handles both the commit message and expected trailer
2. Updating the conflict test to check HEAD (the rebased commit) rather than HEAD~2 for more precise verification
3. Simplifying the --root test by using the new helper for both commits
4. Making the test code more maintainable by removing temporary files and reducing duplication

The changes are mechanical improvements that don't affect test coverage or assertions, just making the test script cleaner and more consistent. This continues the series' pattern of iterative test refinements based on review feedback.
