This is a feature patch series introducing a new `--trailer` option to `git rebase`, along with significant internal refactoring of trailer handling code.

The series (now in its 4th iteration) moves all trailer processing from the external `interpret-trailers` helper into built-in Git code, eliminating fork/exec overhead. The main feature allows appending custom trailers (like `Signed-off-by`) to every commit during a rebase, automatically forcing the merge backend and `--force-rebase` when used. The implementation handles edge cases like interrupted rebases and includes comprehensive tests in a new t3440 test file.

The series appears well-developed, with each version addressing reviewer feedback (notably from Phillip Wood and Junio Hamano). The v4 changes focus on polishing based on v3 comments, including better error handling, test improvements, and fixing trailer persistence across rebase restarts. The commit messages show careful attention to detail, though the sheer size (29 patches) suggests this is a substantial change that may warrant close review of the trailer handling internals.
