This is a test refinement patch in the ongoing series adding `--trailer` support to `git rebase`. It improves the conflict scenario test in t3440-rebase-trailer.sh by making the assertions more precise.

The change fixes a subtle issue where the test was checking the wrong commit after a rebase with conflicts. Previously, it verified the trailer on HEAD~2 (two commits back from the tip), but now correctly checks HEAD (the rebased tip commit) and updates the expected message to match the "third" commit being rebased. This better reflects the actual rebase behavior when conflicts occur and are resolved.

The patch is small (just 2 line changes) but makes the test more accurate by ensuring we're validating the trailer on the final rebased commit rather than an intermediate state. It maintains all the existing test coverage while being more precise about what we're asserting. This continues the series' pattern of iterative test improvements based on review feedback.
