This is a test patch in the ongoing series adding `--trailer` support to `git rebase`. It specifically tests edge case behavior for trailers without values.

The patch adds a new test case to t3440-rebase-trailer.sh that `git rebase --trailer` correctly handles trailers that have a separator but no value (like "Acked-by:"). The test verifies that:
1. The rebase succeeds with such trailers
2. The separator's trailing space is preserved in the commit message
3. The empty value is properly recorded

This builds on the series' earlier work validating trailer syntax, now covering the case where only the key and separator are present. The test uses the existing `test_commit_message` helper to verify the message contents match expectations, following the pattern established in previous test refinements.

The change is small (10 lines) and focused, maintaining the series' pattern of thorough edge case testing. It addresses a real gap in test coverage while being mechanically simple - just adding another test case to the growing suite of trailer-related rebase tests.
