Test refinement patch in the `git rebase --trailer` series.

This patch by Li Chen improves the t3440-rebase-trailer.sh test script by introducing a new `expect_trailer_msg()` helper function that consolidates trailer verification logic. The changes:

1. Replace the `create_expect` function and temporary files with direct in-memory checks using `test_commit_message`
2. Centralize the "Reviewed-by" trailer text in a `REVIEWED_BY_TRAILER` variable
3. Update the conflict resolution test to check HEAD (the rebased commit) rather than HEAD~2
4. Convert the --root test to use the new helper while maintaining the same verification of both the first commit and initial empty commit
5. Make the --apply backend rejection test use the shared trailer variable

The changes are mechanical improvements that don't affect test behavior - they just make the script more maintainable by reducing duplication and removing temporary files. The patch continues the series' pattern of iterative test refinements based on review feedback, with all assertions preserved but expressed more cleanly. The new helper will make future test additions easier by providing a standard way to verify trailers.
