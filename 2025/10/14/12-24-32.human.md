Test refinement patch in the `git rebase --trailer` series.

This is patch 19/29 in Dragan Simic's series adding `--trailer` support to `git rebase`. The patch improves the test suite by replacing fragile pipeline-based trailer assertions with explicit expectations verified by `test_commit_message`. The changes make the tests more robust by:

1. Verifying trailer behavior through Git's test infrastructure rather than raw `grep` pipelines, which could mask command failures
2. Adding full expected message templates for both the "replace" policy test (where only the last duplicate trailer should remain) and the multiple-SOB test (where all trailers should be preserved)
3. Maintaining the same test coverage while making the assertions more precise and reliable

The changes are straightforward test improvements that don't affect runtime behavior, continuing the series' pattern of incremental refinements based on review feedback. The patch demonstrates good attention to test quality by ensuring failures will be caught more reliably.
