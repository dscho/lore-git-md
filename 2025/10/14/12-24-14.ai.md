This is a refactoring patch that's part of a larger series adding `--trailer` support to `git rebase`. It moves trailer manipulation from being handled by forking `git interpret-trailers` to using new in-process functions in trailer.c.

The key changes are:
1. Introduces `amend_strbuf_with_trailers()` to handle trailer insertion in-memory
2. Adds `trailer_process()` as the core in-process trailer handling function
3. Modifies `amend_file_with_trailers()` to use the new in-process approach instead of forking
4. Simplifies `builtin/interpret-trailers.c` to just handle I/O while delegating processing to trailer.c
5. Maintains all existing functionality while eliminating fork/exec overhead
