This is a test patch in the ongoing series adding `--trailer` support to `git rebase`. It adds a regression test to verify that `git rebase --trailer` correctly handles trailers that have a key but no value (like "Acked-by:" with nothing after the colon), preserving the separator's trailing space in the commit message.

The test confirms that:
1. The rebase command accepts trailers with missing values
2. The resulting commit message properly includes the trailer with its trailing space after the separator
3. The behavior matches expectations for this edge case

This is part of the comprehensive test suite being built for the new `--trailer` feature, specifically covering an edge case in trailer syntax handling. The patch is small and focused, adding just 10 lines to the existing t3440-rebase-trailer.sh test file.
