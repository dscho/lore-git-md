This is a bugfix and refactoring patch in the ongoing `--trailer` support series for `git rebase`. It improves error handling when appending trailers to files.

The patch introduces a new `write_file_buf_gently()` function that reports file write errors instead of aborting, and updates `amend_file_with_trailers()` to use it. This means trailer append failures will now propagate errors back to callers rather than terminating the program. The changes ensure proper cleanup of buffers in error cases and maintain consistent error reporting.

Key technical changes:
- Adds `write_file_buf_gently()` to wrapper.c as a non-fatal alternative to `write_file_buf()`
- Modifies `amend_file_with_trailers()` to handle and propagate errors from both trailer processing and file writing
- Ensures proper buffer cleanup in all error paths
- Maintains the same functionality in success cases

This appears to be a well-contained improvement that addresses error handling gaps in the earlier implementation while following the series' pattern of incremental refinements. The changes are focused and clearly motivated, with proper buffer management in all paths.
