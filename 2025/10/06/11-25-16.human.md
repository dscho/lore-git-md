This is part 3/5 of the submodule gitdir path encoding series, focusing on a utility function needed for URL encoding. The patch moves `is_rfc3986_unreserved()` from `credential-store.c` back to `strbuf.[ch]` where it can be more widely used.

The function determines which characters don't need URL encoding (alphanumerics plus `-`, `_`, `.`, and `~`). It was previously made static in credential-store.c when that was its only user, but now the submodule encoding work needs it for safely encoding submodule names in gitdir paths.

The change is straightforward - the function definition moves to strbuf.c with its declaration in strbuf.h, while being removed from credential-store.c (which now uses the public version). This is a clean refactoring that enables the URL encoding functionality needed by the larger submodule path handling series while maintaining the existing credential store behavior.

The patch appears well-constructed with a clear commit message explaining both the historical context and current need. It's a small but necessary piece of the broader submodule encoding work that's progressing through the mailing list.
