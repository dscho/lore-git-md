This is a feature patch series (v3) that implements submodule gitdir path encoding to prevent filesystem conflicts, now gated behind a new `extensions.submoduleEncoding` config. The series represents a significant simplification from v2 by eliminating the split between `.git/modules/` and `.git/submodules/` directories, instead using the extension to control path encoding behavior.

The key technical changes in v3 include moving the entire implementation behind the repository extension (as suggested by Phillip Wood and Patrick Steinhardt), bringing back the `validate_submodule_git_dir()` function for default path checking, and reorganizing tests into a new dedicated file (`t7425-submodule-encoding.sh`) that enables the extension. The series also adds path length validation and maintains the config override mechanism (`submodule.<name>.gitdirpath`) as an optional feature.

Notable implementation details include the reintroduction of `is_rfc3986_unreserved()` in strbuf for URL-style encoding, new platform-specific path length checking via `pathconf(_PC_NAME_MAX)`, and comprehensive test coverage across 20 modified files. The changes maintain backward compatibility while providing a path forward for cross-implementation interoperability through the repository extension mechanism.

The series has addressed several reviewer concerns from v2, including SZEDER Gábor's unused variable reports (now moved to relevant commits), Kristoffer Haugsbakk's documentation fixes, and test reorganization suggestions.
