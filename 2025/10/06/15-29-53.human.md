This is the second patch in a series improving gitk's window geometry persistence, specifically focusing on the Tags/Heads window. Johannes Sixt builds on Michael Rappazzo's initial work to properly save and restore both the position and size of this window between sessions.

The patch stores the window geometry as `geometry(showrefs)` in gitk's config file, with careful handling of variable scoping to avoid overwriting current settings. It also includes Windows-specific fixes to ensure position restoration works correctly on that platform. The implementation uses Tcl's `bindtags` to track window configuration changes while avoiding interference with child windows.

Compared to v1, this version properly handles window positioning on Windows, where transient windows require special treatment. The solution is now more robust while maintaining the minimal approach Johannes Sixt prefers, reducing the original 39-line solution to a cleaner 25-line change.

The patch appears well-considered, with clear commit message explanations of both the technical approach and Windows-specific considerations. It completes the series' goal of full window geometry persistence, addressing a long-standing user experience issue in gitk.
