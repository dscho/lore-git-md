This is a refactoring patch in the reftable fsck validation series, moving a consistency check message from the files backend to the generic refs layer. 

The change relocates the "Checking references consistency" message that was previously printed only by the files backend when running fsck. By moving this to the generic `refs_fsck()` function, both the files and reftable backends will now show this message when fsck runs in verbose mode. 

The implementation is straightforward - the message is removed from `files-backend.c` and added to `refs.c` with the same conditional `o->verbose` check. This is a small but logical change that helps unify behavior between the two backends. 

As part of the larger reftable fsck series that has already received maintainer approval, this patch appears uncontroversial and well-justified. The change maintains the same functionality while reducing code and making the behavior more consistent across backends.
