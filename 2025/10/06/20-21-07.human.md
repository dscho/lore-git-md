This is a test cleanup patch that prepares for the `:(optional)` file prefix series. Junio Hamano identifies and fixes a subtle shell quoting issue in two test cases in t7500 that use `GIT_EDITOR` to simulate commit message editing.

The tests were incorrectly using `echo hello >"$1"` as the editor command, which gets expanded in a way that includes the filename as an argument to the shell rather than the redirection target. The fix simplifies this to just `echo hello >`, letting Git's editor handling append the filename correctly. This is a preparatory cleanup that Phillip Wood noted would be needed during review of the optional file prefix series.

The change is straightforward and clearly correct - it fixes the test setup while maintaining the same test intent (writing "hello" to the commit message file). The patch is ready to go in ahead of the main series it supports.
