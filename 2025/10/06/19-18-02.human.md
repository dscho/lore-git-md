This is a detailed set of notes from the SHA-256 interoperability discussion at the Git Contributor's Summit 2025, led by brian m. carlson. The conversation focuses on the challenges of transitioning between SHA-1 and SHA-256 hashes, particularly around submodules and object compatibility.

Key concerns include handling divergent histories when some objects exist only in one hash format, security implications of server-client mapping, and the practicalities of converting repositories while preserving GPG signatures. The discussion explores various edge cases - like recursive submodules, missing submodules from old commits, and mixed-algorithm repositories. There's also consideration of future-proofing the design to potentially support additional hash algorithms.

The notes reveal several unresolved questions, particularly around submodule conversion strategies and backward compatibility tradeoffs. The group seems to be weighing different approaches, including potentially introducing new tree object formats or mode bits to handle mixed-hash scenarios. The complexity suggests this work may not be ready for Git 3.0, though the design appears to be progressing with multiple compatibility scenarios in mind.
