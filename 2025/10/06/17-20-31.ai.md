Documentation and test update for interactive add navigation.

This patch is part of René Scharfe's v3 series improving `git add --interactive` navigation behavior. It focuses on documenting and testing the roll-over behavior of the 'J' command (next hunk with roll-over at bottom) that was introduced in earlier patches of the series.

The key changes are:
1. Documentation updates in `git-add.adoc` and the in-program help text to explicitly state that 'J' rolls over at the bottom
2. Error message improvement from "No next hunk" to "No other hunk" to better match the circular navigation model
3. Test updates in `t3701-add-interactive.sh` to include 'J' in the command lists and add a new test case verifying the roll-over behavior
4. A condition change in `add-patch.c` to show the 'J' command option when there's more than one hunk (rather than just when not at the last hunk)

The patch builds on the series' goal of making navigation behavior consistent and well-documented. It addresses feedback from Junio Hamano about making the roll-over behavior official and improves the error messaging. The test coverage is thorough, updating existing tests to account for the new behavior while adding a dedicated test for the roll-over functionality.
