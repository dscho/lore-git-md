This is part 2/5 of the submodule gitdir path encoding series, introducing a config override mechanism for submodule gitdir paths. The patch adds a new `submodule.<name>.gitdirpath` config option that allows users to manually specify the gitdir location for specific submodules, bypassing both the default path construction and the upcoming encoding scheme.

The implementation adds a new `git submodule--helper gitdir` command to query paths and includes comprehensive test coverage. The config override is checked first in `submodule_name_to_gitdir()`, falling back to the standard path construction if not set. A new test helper `verify_submodule_gitdir_path()` is introduced to validate the path resolution behavior, which will be reused in later tests for the encoding functionality.

The patch maintains the series' architectural approach of keeping legacy behavior while adding new capabilities, with the config override providing an escape hatch for special cases. Test coverage includes both the default path behavior and explicit overrides, with proper cleanup. The change touches core submodule path resolution while being narrowly scoped to just the config override feature.
