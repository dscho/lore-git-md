This is a feature patch that introduces the `:(optional)` prefix for pathname-type config values, allowing them to be silently skipped if the file doesn't exist. It's part of a series implementing optional file handling across Git's configuration and command-line interfaces.

The patch adds support for marking config values like `commit.template` as optional by prefixing them with `:(optional)`. When such a file is missing, Git will treat it as if the config wasn't set at all, rather than erroring out. This is useful for cases where users want to specify fallback files that may not exist on all systems.

The implementation adds a new `is_missing_file()` function to wrapper.c to distinguish between missing files (which should be skipped when optional) and empty files (which should still be processed). The change includes documentation updates and a new test case verifying the optional template behavior.
