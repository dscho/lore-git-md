This is part 4/6 of a v3 series improving interactive add navigation behavior. The patch extends the circular roll-over functionality to the 'k' and 'K' commands in `git add --interactive`, making them symmetric with the existing 'j' and 'J' behavior. When reaching the top of the hunk list, 'k' now wraps to the last undecided hunk while 'K' wraps to the last hunk overall.

Key technical changes include:
- New `dec_mod()` helper function mirroring `inc_mod()` for circular decrement operations
- Updated navigation logic for 'k' and 'K' commands to use circular wrapping
- Consistent error messages ("No other hunk" / "No other undecided hunk") replacing direction-specific phrasing
- Documentation updates in both man pages and in-program help text
- Test updates verifying the new roll-over behavior, including:
  - New test cases for 'K' command wrapping
  - Expanded test coverage for mixed command sequences involving 'k'
  - Updated prompt expectations to show 'k' and 'K' options when available

The changes maintain the series' focus on interface consistency while completing the circular navigation model. All tests pass, and the implementation appears thorough with careful attention to edge cases. This continues the systematic improvement of interactive add's navigation commands that was established in earlier patches of the series.
