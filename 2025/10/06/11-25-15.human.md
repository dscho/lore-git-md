Feature and refactoring patch in the submodule gitdir path encoding series. This is part 2/5 of a v3 series implementing path encoding for submodule gitdirs to prevent filesystem conflicts.

The patch introduces a config override mechanism (`submodule.<name>.gitdirpath`) that allows users to manually specify custom gitdir paths for submodules, bypassing both the default path construction and the new encoding scheme (when enabled via `extensions.submoduleEncoding`). The override is implemented in `submodule_name_to_gitdir()` and exposed through a new `git submodule--helper gitdir` command for testing purposes.

Test coverage includes:
- A new helper script `t/lib-verify-submodule-gitdir-path.sh` to verify gitdir paths
- Integration tests in t7400 demonstrating config override behavior
- Completion script updates for the new config key

The implementation maintains clean separation between the config override and core path resolution logic, following the series' architectural approach. The patch appears well-constructed with thorough testing, though the commit message could more explicitly connect this to the series' broader goal of safe path handling.
