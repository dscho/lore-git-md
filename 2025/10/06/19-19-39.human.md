This is a set of notes from the Git Contributor's Summit 2025 discussing long-term repository maintenance goals, specifically around packfile and multi-pack index (MIDX) optimizations. The discussion was led by Taylor Blau and builds on previous work around geometric repacking.

The notes highlight several technical challenges in repository maintenance. Geometric repacking has reduced but not eliminated issues with constant repacking into a single pack. Recent changes allow excluding large cruft packs from MIDX, but full repacks still risk breaking bitmaps due to object order dependencies. The discussion explores the concept of "tombstones" to mark missing objects without disrupting bitmaps.

Taylor proposes a "unitary MIDX" concept that would eliminate duplication between MIDX and pack index files, though backward compatibility concerns remain. Brian m. carlson notes limitations with alternative implementations like Git LFS that don't use MIDX. The notes also mention the possibility of running parallel repack strategies - one geometric and one all-into-one.

This appears to be part of ongoing optimization work for large repositories, connecting to broader discussions about object storage and performance. The technical depth suggests this is aimed at Git maintainers working on the packfile subsystem rather than end users. The discussion doesn't reach concrete conclusions but identifies several promising directions for future development.
