Documentation patch adding a simple usage example to `git-push` man page.

This is the final patch in Julia Evans' v5 documentation series that has been through extensive review and refinement. It adds a straightforward example of the most common `git push` usage pattern (`git push origin main`) near the top of the man page, before diving into more complex behaviors. The patch follows the series' goal of making Git documentation more accessible by starting with simple, practical examples rather than technical details.

The change is small but strategic - it gives users an immediately useful command they can run without needing to understand the more complex default push behaviors documented later. The commit message notes this is intentionally simple, acknowledging that full push behavior is complicated (as covered in previous patches) but that basic usage doesn't need to be.

This patch has already incorporated feedback from reviewers including D. Ben Knoble's optional wording suggestion and Jean-Noël Avila's formatting review. The series as a whole has been approved and merged after addressing all feedback, including removing confusing `git branch --track` examples and centralizing upstream branch documentation in earlier patches.
