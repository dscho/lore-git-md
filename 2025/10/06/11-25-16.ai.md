This is part 3/5 of the submodule gitdir path encoding series, focusing on moving a URL encoding helper function back to strbuf for broader use.

The patch relocates `is_rfc3986_unreserved()` from credential-store.c to strbuf.c, making it available for the submodule path encoding work. The function was previously moved to credential-store.c when it was only used there, but now needs to be shared for URL-encoding submodule names when constructing gitdir paths to avoid filesystem conflicts.

The implementation is straightforward - the exact same function definition is moved from credential-store.c to strbuf.c, with the corresponding header declaration added to strbuf.h. The credential-store code continues to work by including strbuf.h and using the now-public function. This change enables the submodule encoding work to use the same RFC3986-compliant URL encoding logic consistently across the codebase.

This is a mechanical refactoring that enables the core functionality needed for the submodule path encoding series while maintaining existing behavior. The patch follows the series' pattern of careful, incremental changes with clear justifications in the commit message.
