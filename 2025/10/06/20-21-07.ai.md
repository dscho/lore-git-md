This is a test cleanup patch that prepares for the `:(optional)` file prefix series by fixing shell script test patterns in t7500.

The patch addresses a subtle issue with how `GIT_EDITOR` is invoked in two test cases. The original test setup from 2010 used `GIT_EDITOR="echo hello >\"\$1\""` intending to write "hello" to the commit message file, but Phillip Wood pointed out this gets expanded incorrectly when Git's internal shell invocation adds the filename parameter. The fix simplifies the editor command to just `"echo hello >"` which properly writes to the file without shell quoting complications.

This change aligns with the broader test hygiene improvements identified during review of the `:(optional)` series. While the immediate impact is limited to these two test cases, Junio notes this is part of cleaning up similar editor patterns throughout t7500 that should be addressed in follow-up work. The patch maintains identical test coverage while using a more robust invocation pattern.

The change is straightforward and clearly motivated by the review discussion, with Junio acting on Phillip Wood's earlier observation about test robustness.
