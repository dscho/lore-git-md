Documentation and help text improvement for interactive add navigation commands.

This patch is part of René Scharfe's v3 series improving `git add --interactive` navigation behavior. It focuses specifically on clarifying the help text for the j/J/k/K navigation commands in both documentation and runtime help output.

The key change is rewording the help text to remove the misleading implication that these commands affect the current hunk's status ("leave this hunk undecided"). The new wording ("go to...") more accurately reflects that these are pure navigation commands that don't modify hunk state. This aligns with the thread's broader goal of making the interactive add interface more consistent and intuitive.

The patch touches:
1. `git-add.adoc` man page documentation
2. Runtime help text in `add-patch.c`
3. Maintains the distinction between undecided-hunk-only navigation (j/k) and all-hunk navigation (J/K)

This is a straightforward documentation improvement that builds on the series' technical changes to navigation behavior. The change is small but meaningful for user experience, removing potential confusion about command effects. The patch follows the series' pattern of careful attention to interface details.
