This is a project management update from the Git Contributor's Summit 2025 discussion thread, specifically covering Conservancy administrative matters. Taylor Blau reports on several operational aspects of the Git project's stewardship under Software Freedom Conservancy.

The update notes increased trademark activity, including a request for Perforce to modify a logo deemed too similar to Git's, highlighting the project's generally restrictive but lightly enforced trademark policy. Financial matters are discussed, with the project holding approximately $100k in funds that could potentially support initiatives like gitoxide development or Outreachy internships, though concerns are raised about long-term sponsorship reliability from major forges.

A new Git ambassador program concept is floated, which would provide stipends to community representatives, though the proposal currently lacks an organizer. The discussion reflects the project's growing need to manage its brand, allocate financial resources effectively, and expand contributor engagement channels beyond corporate sponsorships. These administrative considerations form the backdrop against which the more technical discussions about Git 3.0 features are taking place.
