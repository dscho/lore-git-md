This is a documentation patch that adds explicit clarification about how the new `stash.index` configuration interacts with `--autostash` operations. It's the final piece of the previously approved series that made stash operations respect staged changes via config.

The patch adds a paragraph to `Documentation/config/stash.adoc` explaining that the `stash.index` setting (which controls whether `git stash apply/pop` restores staged changes by default) also affects operations that use stash implicitly through `--autostash` in commands like `git merge`, `git rebase`, and `git pull`. This connection wasn't previously documented despite being implemented in the earlier patches.

The change is purely documentation - no code modifications - and serves to complete the series by making the `--autostash` interaction explicit in the config documentation. The patch builds on the already-merged functionality from commit 9842c0c749 and follows maintainer approval of the overall feature. The documentation addition matches the implementation's behavior where the config setting implicitly affects all stash operations, whether explicit (`stash apply/pop`) or implicit (`--autostash`).
