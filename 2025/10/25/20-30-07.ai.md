Build system patch adding installation support for credential helpers. This is a v2 resubmission that adds a missing Signed-off-by line after feedback on the initial submission.

The patch adds standard `install` targets to the Makefiles for both the libsecret and osxkeychain credential helpers in contrib/. The changes follow the same pattern seen in other contrib/ Makefiles, creating the target directory with proper permissions and installing the built binaries. Each Makefile gets:
- An `INSTALL` variable definition
- New `install` target rules
- Updated `.PHONY` declarations

The changes are straightforward and consistent with existing practices. The author notes this builds on previous cleanup work to these Makefiles that was requested to be split into a separate patch. The implementation looks correct and aligns with how other contrib components handle installation.
