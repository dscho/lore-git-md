Build system patch adding installation support for credential helpers. This follows up on previous cleanup work to the credential helper Makefiles, splitting out the installation target addition as a separate change as requested by reviewers.

The patch adds standard `install` targets to both the libsecret and osxkeychain credential helper Makefiles, following the pattern used in other contrib/ directories. Each install target creates the destination directory if needed and copies the built binary with proper permissions. The changes include:
- Adding `INSTALL ?= install` variable declarations
- New install targets that use `$(DESTDIR)` and `$(gitexecdir)`
- Updating `.PHONY` lists to include the new target
- The libsecret helper gets proper pkg-config based build flags
- The osxkeychain helper maintains its framework linkages
- Both follow the same installation pattern seen in other contrib components

This appears to be a straightforward build system improvement that completes the credential helper Makefile modernization started in the previous patch. The changes are consistent with Git's build system conventions and don't introduce any new dependencies or behavior changes beyond enabling proper binary installation.
