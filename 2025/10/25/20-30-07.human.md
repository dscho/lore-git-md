This is a build system patch adding installation support for credential helper binaries. Thomas Uhle follows up on previous cleanup work in the contrib/credential directory by adding standard `install` targets to the Makefiles for both the libsecret and osxkeychain credential helpers. The changes mirror the installation approach used in other contrib/ directories.

The patch is straightforward - it adds `install` rules that create the target directory and copy the built binaries with proper permissions. The author notes this was split from earlier cleanup work at reviewers' request. While simple, this fills a small gap in the build system by making these helpers installable like other contrib tools.

The changes are cleanly implemented following existing patterns, though the patch is primarily infrastructure rather than user-facing functionality. It's a minor but logical addition for anyone packaging or installing these credential helpers system-wide.
