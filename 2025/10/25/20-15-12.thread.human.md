This thread focuses on improving the build system support for Git's credential helpers, specifically the libsecret and osxkeychain implementations. The original work modernized the Makefiles for these helpers, and this follow-up patch completes the effort by adding proper installation support as requested in prior reviews.

The changes introduce standard `install` targets that follow Git's build conventions, handling directory creation and binary copying with correct permissions. Both helpers maintain their existing build characteristics - libsecret using pkg-config and osxkeychain keeping its framework linkages - while adopting the installation pattern seen elsewhere in Git's contrib directory. This appears to be the final piece in modernizing these credential helper build systems, with no new dependencies or functional changes beyond enabling proper installation.
