This is a feature patch in Christian Couder's series to standardize signature handling between `git fast-import` and `git fast-export`. The patch focuses on making `git fast-export` properly recognize and handle all supported tag signature formats (PGP, X.509, SSH) by using the centralized `parse_signed_buffer()` function rather than hardcoding PGP signature detection.

The key change replaces the direct string search for PGP signatures with a call to `parse_signed_buffer()`, which understands all Git-supported signature formats. This affects how signed tags are processed under different `--signed-tags` modes (verbatim, warn, strip, abort). The patch adds comprehensive test coverage for X.509 and SSH signatures through new test cases in t9350-fast-export.sh, building on the test infrastructure improvements from earlier in the series.

The implementation maintains backward compatibility while properly supporting all signature formats through the existing signed-tag processing modes. Test cases verify both signature preservation (verbatim mode) and removal (strip mode) for X.509 and SSH signatures, matching the existing PGP test patterns. The tests use the dynamic `ANNOTATED_TAG_COUNT` mechanism introduced earlier in the series to maintain test isolation.

This patch completes the signature handling symmetry between import/export operations, with all cryptographic formats now properly supported in both directions. The changes are focused and well-tested, with no outstanding technical concerns apparent from the implementation.
