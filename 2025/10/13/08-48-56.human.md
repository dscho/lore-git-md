Bugfix and test expansion for signature handling in `git fast-export`. This is the 4th patch in Christian Couder's v3 series to unify signature handling between fast-import and fast-export.

The patch fixes `fast-export`'s handling of signed tags, which previously only recognized PGP signatures starting with a specific header. The change makes it properly handle all signature formats Git supports (PGP, X.509, SSH) by using the centralized `parse_signed_buffer()` function. This matches the behavior already implemented in `fast-import` and completes the series' goal of symmetric signature handling.

The patch includes thorough test coverage for the new functionality, adding X.509 and SSH signature scenarios to t9350-fast-export.sh. Tests verify both verbatim signature preservation and stripping behavior for each format. The test additions follow the pattern established earlier in the series, using the `ANNOTATED_TAG_COUNT` variable introduced in previous patches to maintain test isolation.

This appears to be a well-constructed change - the implementation is straightforward (just 7 lines changed in sync with the series' approach), and the test coverage is comprehensive. The patch builds on prior review feedback and fits cleanly into the overall signature unification effort.
