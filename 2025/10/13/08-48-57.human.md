Feature: This is the final patch in Christian Couder's series to add symmetric signature handling between `git fast-import` and `git fast-export`. It introduces a `--signed-tags=<mode>` option for `fast-import` to match the existing `--signed-commits` option and complete the symmetry with `fast-export`.

The patch adds consistent behavior for all supported signature formats (PGP, X.509, SSH) with the same five processing modes as `fast-export`: verbatim, warn-verbatim, warn-strip, strip, and abort. The default is `verbatim` (unlike `fast-export` which defaults to `abort` for historical reasons). The implementation reuses the centralized `parse_signed_buffer()` function that was introduced earlier in the series.

Test coverage is thorough, with a new test script `t9306-fast-import-signed-tags.sh` that exercises all signature types and modes. The tests verify both signature preservation (for verbatim modes) and proper stripping (for strip modes), with warnings checked where appropriate. The test infrastructure builds on the series' earlier work with GPG, GPGSM, and SSH test setup helpers.

This appears to be a well-considered completion of the signature handling symmetry work, with careful attention to backward compatibility and consistent behavior across all signature formats. The patch follows the established patterns from earlier in the series and maintains the same high standard of test coverage. With this change, both import and export operations now handle signed tags and commits in exactly the same way.
