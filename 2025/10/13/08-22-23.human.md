This is a minor documentation patch in a series refactoring reference backend operations. It's part of a larger effort to standardize optimization operations across Git's reference backends, culminating in a new `--required` flag for `git refs optimize`.

The patch removes redundant documentation about `PACK_REFS_*` flags from `refs_optimize()` since this information should be documented in the `pack_refs_opts` struct itself. Patrick Steinhardt pointed out this improvement in review, and Karthik Nayak agrees with the suggestion.

This is a straightforward cleanup following the earlier consolidation of backend operations. The change is uncontroversial and aligns with the series' goal of cleaning up old `pack_refs` terminology in favor of the more general `optimize` operations. The patch doesn't introduce new functionality but helps maintain clean documentation as the series progresses.
