This is a refactoring patch in the `git replay` atomic updates series, specifically addressing option validation cleanup. 

The patch standardizes the validation of incompatible `--advance` and `--contained` options in `git replay` by using the `die_for_incompatible_opt2()` helper function instead of a direct check. Junio Hamano confirms the implementation is correct, noting the slightly unusual but necessary use of the `!!` operator to convert the string pointer `advance_name_opt` to a boolean for the helper function, while `contained` (already an integer) doesn't need conversion. 

This change aligns with the series' broader goal of cleaning up and standardizing the codebase in preparation for the atomic update functionality. The review confirms the technical correctness of the approach while acknowledging the minor visual quirk introduced by the boolean conversion. This patch (1/3) serves as groundwork for the subsequent patches that implement the atomic reference update behavior.
