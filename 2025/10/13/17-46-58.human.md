This is a documentation and code clarification patch from an Outreachy participant, addressing how patch IDs are computed in Git.

The change clarifies that patch IDs must always use SHA1 hashes, regardless of the repository's configured object hash. The existing code had a confusing implementation that relied on `the_hash_algo` (which varies by repository) along with a NEEDSWORK comment acknowledging this was problematic. The patch removes that comment and explicitly sets SHA1 as the required algorithm when unset.

While this doesn't change runtime behavior (since SHA1 was already effectively required by the specification), it makes the code's intent clearer and removes misleading comments that suggested the hashing approach might change. The change is small and focused, touching only the patch-id.c file with minimal modifications. As an intern contribution, it shows good attention to detail in cleaning up technical debt around hash algorithm usage.
