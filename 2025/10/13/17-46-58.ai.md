This is a documentation and code clarification patch targeting the patch-id functionality, submitted as part of Outreachy.

The patch addresses a known issue where `builtin/patch-id.c` was using `the_hash_algo` to compute patch IDs, which could vary based on the repository's object hash. The author notes this was problematic because git-patch-id(1) explicitly requires SHA1 hashes for patch IDs. The patch removes a NEEDSWORK comment and outdated code, replacing it with a clear statement that SHA1 must always be used for patch IDs and enforcing this by explicitly setting SHA1 as the hash algorithm when none is specified.

The changes are minimal but important for correctness - they don't alter functionality but make the code's behavior match its documented requirements. The patch touches only `builtin/patch-id.c`, modifying the hash algorithm initialization logic and improving the explanatory comment. The author is an Outreachy participant, suggesting this may be part of their internship work. The change appears straightforward and uncontroversial, aligning the implementation with long-standing documentation.
