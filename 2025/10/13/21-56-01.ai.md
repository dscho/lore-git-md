Refactoring patch simplifying submodule handling in `git cat-file --batch-check`.

This patch cleans up the implementation of submodule handling in `git cat-file`'s batch mode. The change stems from commit b0b910e052 which added special handling for submodules in batch mode, showing their pointed-to commit directly. The current code explicitly passes the hex OID to `report_object_status()`, but the function already handles NULL obj_name by automatically converting the OID to hex internally (a behavior dating back to 6a951937ae).

The patch simplifies the redundant OID-to-hex conversion by passing NULL instead, letting `report_object_status()` handle the conversion. This is a straightforward cleanup with no behavior change, found while merging v2.50.1 into GitHub's fork. The change affects only the submodule case in `batch_object_write()`, where the mode is S_IFGITLINK. The patch is minimal (1 line changed) and appears to be a clear improvement, though it doesn't address any user-visible bug or performance issue.
