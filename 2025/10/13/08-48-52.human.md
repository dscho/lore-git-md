This is a feature patch series adding signature handling control to `git fast-import`, completing the symmetry with `git fast-export`. It's the third iteration of work that has already undergone significant review and testing.

The main addition is a new `--signed-tags=<mode>` option for `git fast-import`, mirroring the existing `fast-export` capability. The series ensures consistent behavior across both commands for all signature types (PGP, X.509, SSH) with identical mode options (verbatim, warn-verbatim, warn-strip, strip, abort). The implementation builds on prior work that added `--signed-commits` handling.

The series includes preparatory cleanups: modernizing `git-tag` documentation to be format-agnostic (patch 1), fixing test infrastructure for GPGSM/SSH prerequisites (patch 2), and correcting tag counting test (patch 3). Patch 4 fixes `fast-export` to properly handle non-PGP signatures before the main `fast-import` implementation in patch 5.

Review feedback from v2 has been incorporated, primarily improving the `git-tag` documentation wording. The implementation appears solid with thorough test coverage (including a new dedicated test file). This looks ready for integration, completing the thread's goal of consistent signature handling across import/export operations. The author notes plans for more advanced signature modes in future work.
