Test improvement patch for fast-export tag counting. This is part of Christian Couder's v3 series to improve signature handling consistency between `git fast-import` and `git fast-export`.

The patch fixes a potential issue in t9350-fast-export.sh where some tests hardcode the expected number of annotated tags, which could break if new tests add more tags. Instead, it introduces an `ANNOTATED_TAG_COUNT` variable that gets incremented whenever a new annotated tag is created, then uses this counter in the test assertions. The approach is explicitly chosen over alternatives like reordering tests, as it makes the test interdependencies clear rather than hiding them.

This is a straightforward test infrastructure improvement that makes the test suite more robust as the signature handling work progresses. The change is mechanical but thoughtful, with the author acknowledging the slight ugliness of the solution while justifying why it's the best option. The patch fits cleanly into the larger series about signature handling, ensuring the test behavior remains reliable as new tag-related tests are added.
