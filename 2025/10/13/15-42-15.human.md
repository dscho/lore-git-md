This is a documentation patch, part 1 of a 5-part series modernizing the `git-patch-id` man page. It converts the synopsis section from the older `verse` format to the current `synopsis` block style and ensures consistent backtick usage for options and code-like elements throughout the page.

The patch follows established patterns from similar documentation updates (referencing prior work by Jean-Noël Avila and others) and has already incorporated all review feedback from v1, including adding backticks around `--unstable` and config values like `true`. Jeff King has verified the HTML output improvements.

Kristoffer Haugsbakk notes this is the first of several planned updates to the `git-patch-id` documentation, with future patches planned to add examples, clarify usage with multiple diffs, and reference config variables in git-config(1). The current patch focuses on uncontroversial formatting changes to make review easier, deferring more substantive content changes to later in the series.

The changes are mechanical but thorough, updating all option listings (`--stable`, `--unstable`, `--verbatim`), config names (`patchid.verbatim`, `patchid.stable`), and command references (`git diff-tree`, `-O<orderfile>`). While the actual content remains unchanged, the formatting improvements make the documentation more consistent with current standards.
