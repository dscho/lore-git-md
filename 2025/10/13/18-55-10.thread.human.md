Roy Lomicka shared a PowerShell script that uses the soon-to-be-deprecated `git whatchanged` command to preserve file modification times based on commit timestamps. The script carefully processes the command's output to apply historical timestamps to files, demonstrating a legitimate use case for this deprecated command.

Kristoffer Haugsbakk has now responded with a suggested replacement approach using `git log --no-merges --raw`, which produces nearly identical output to `git whatchanged` in most cases. The only difference occurs with empty commits (those with no changes from their parent), which might affect scripted usage but would be irrelevant for interactive scenarios. This exchange serves both as practical migration advice and documentation of the edge case where the commands differ, helping users transition away from `git whatchanged` while maintaining similar functionality.
