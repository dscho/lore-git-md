This thread discusses the deprecated `git whatchanged` command and a real-world use case for it. Roy Lomicka shares a PowerShell script that leverages `git whatchanged` to preserve file modification times based on commit timestamps—a functionality not natively provided by Git. The script carefully parses the command's output to extract timestamps and apply them to files, demonstrating a concrete need for this soon-to-be-removed command.

The discussion highlights that `git whatchanged` will disappear unless users explicitly opt-in with `--i-still-use-this`, making this both a usage report and a technical contribution. The script provides a working solution for users who need to maintain file mtimes from Git history, suggesting there may be valid reasons to preserve this command or its functionality in some form. The thread serves as a case study of the practical implications when deprecating long-standing Git features.
