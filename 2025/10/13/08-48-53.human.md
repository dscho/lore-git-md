This is a documentation patch that modernizes the `git-tag` man page to be more inclusive of different signature types beyond just GPG. It's part of a larger series (v3 1/5) aiming to provide consistent signature handling across Git commands.

The patch updates the `git-tag` documentation to use cryptographic terminology that's format-agnostic, rather than GPG-specific language. Changes include:
- Rewriting the NAME section to remove GPG-specific wording
- Generalizing descriptions of signed tags to cover all signature types (GPG, X.509, SSH)
- Adding references to the `gpg.format` configuration variable that controls signature backends
- Updating option descriptions (`-s`, `-u`) to explain they work with any configured signature type
- Adding configuration details for different signing backends

The changes are thorough and align with Git's growing support for multiple signature types. The patch has already benefited from review feedback in previous iterations (v2) and includes a Helped-by from Patrick Steinhardt. This appears to be a well-considered update that brings the documentation in line with Git's actual capabilities.
