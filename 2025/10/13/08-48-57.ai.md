Final patch in a series adding symmetric signature handling to fast-import/fast-export. This implements `--signed-tags=<mode>` for `git fast-import`, mirroring the existing `--signed-commits` option and completing the symmetry with fast-export's signature handling. The patch adds a new `handle_tag_signature()` function that processes tags using the same `parse_signed_buffer()` infrastructure as commits, supporting all signature formats (PGP, X.509, SSH) through the standard mode options: verbatim, warn-verbatim, warn-strip, strip, and abort. The behavior defaults to `verbatim` (unlike fast-export's default `abort`).
