Documentation patch updating git-tag man page to be signature-format-agnostic, part of a series standardizing signature handling across Git commands. This first patch modernizes the git-tag documentation to remove GPG-specific language, making it clear the command supports multiple cryptographic signature formats (PGP, X.509, SSH) through the `gpg.format` configuration. Key changes include:

Rewriting the NAME section to remove "signed with GPG" specificity, updating DESCRIPTION to explain backend-agnostic signing behavior, and clarifying OPTIONS sections for `-s`/`-u` to reference configurable signature formats. The CONFIGURATION section now properly documents `gpg.format` and related variables for all supported backends, not just GPG.

The changes maintain all existing functionality while making the documentation match Git's actual capabilities. This aligns with the series' goal of consistent signature handling across fast-import/export and other commands. The patch builds on prior review feedback, with Patrick Steinhardt credited for assistance. The updates are thorough, touching all relevant sections of the man page while preserving the command's core behavior and usage patterns.
