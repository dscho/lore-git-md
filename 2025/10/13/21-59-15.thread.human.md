Kristoffer Haugsbakk provided the technical solution, showing how `git log --no-merges --raw` (with optional `--stat` or `--name-only`) can replicate its functionality. Junio Hamano approved including this documentation improvement in the upcoming Git 2.51.1 maintenance release, marking the first routine update after a period of only security fixes.

The discussion has now reached practical validation, with Samer confirming that `git log -p --no-merges --raw <filename>` works perfectly as a drop-in replacement when examining file history during editing sessions. This real-world confirmation reinforces that the documentation changes will effectively guide users transitioning away from the deprecated command.
