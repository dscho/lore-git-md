This is a refactoring patch in a series introducing a `--required` flag for reference optimization operations. It's the third of nine patches, focusing on renaming the `pack_refs_opts` struct to `optimize_refs_opts` to maintain consistency after the removal of `pack_refs()` functions in previous patches. Patrick Steinhardt provides review feedback suggesting further naming improvements: the struct should be named `refs_optimize_opts` to match the function it's used with, and the flags should use `REFS_OPTIMIZE_` prefix rather than `OPTIMIZE_REFS_`. Karthik Nayak accepts these suggestions and will implement them in the next revision.

The changes affect `refs.c` and `refs.h`, updating the struct name and flag definitions while maintaining identical functionality. This is part of the broader effort to standardize reference backend operations under a unified `optimize` callback in preparation for the new `--required` flag. The patch series has undergone multiple review rounds with Steinhardt, and this particular patch appears straightforward with only naming conventions to address before finalization.
