Refactoring patch in the `--required` flag series for reference backends.

This is the first patch in a 9-part series introducing a `--required` flag for reference optimization operations. It prepares for later consolidation by standardizing backend implementations to use the `.optimize` callback rather than having separate `.pack_refs` and `.optimize` functions. The files backend's `files_pack_refs()` is renamed to `files_optimize()` while keeping the same functionality, with Patrick Steinhardt noting the `pack_refs_opts` parameter should eventually be renamed to better match the generalized operation.

The patch addresses Steinhardt's feedback about unclear phrasing regarding when the functions might differ in behavior, and accepts his suggested wording improvement about exclusively implementing the `optimize` callback. The follow-up rename of the options struct is confirmed to happen in a subsequent patch. This appears to be straightforward preparatory work with no functional changes, just paving the way for the new `--required` flag functionality in later patches.
