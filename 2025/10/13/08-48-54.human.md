Test infrastructure patch improving GPG-related test prerequisites.

This is the second patch in Christian Couder's v3 series about consistent signature handling. It refactors how test scripts set up the GPG home directory to avoid conflicts when multiple signature types (GPG, GPGSM, GPGSSH) are tested in sequence. The change introduces a new `prepare_gnupghome()` helper function that safely creates the directory with `mkdir -p` instead of plain `mkdir`, preventing errors when the directory already exists.

The patch documents a known limitation with GPG2 tests, where using the new helper would expose hidden bugs in t1016-compatObjectFormat.sh. This is marked with a NEEDSWORK comment referencing the discussion thread. The change builds on prior work from Todd Zullinger and Collin Funk, who helped identify and address test infrastructure issues.

This appears to be a straightforward technical improvement to make the signature testing infrastructure more robust, though the GPG2 limitation shows there's still some test fragility to address. The patch fits cleanly into the larger series goal of unified signature handling across Git commands.
