This is a test infrastructure patch in Christian Couder's ongoing series to improve signature handling in `git fast-import` and `git fast-export`. The patch addresses a potential fragility in the test suite where hardcoded tag counts could break if new tests add more tags. 

The solution introduces a counter variable `ANNOTATED_TAG_COUNT` that gets incremented each time a test adds an annotated tag, then uses this counter for assertions rather than hardcoded values. While the approach acknowledges some test interdependence, it's presented as a pragmatic solution that's better than alternatives like reordering tests, which would obscure the underlying issue.

Elijah Newren's response notes that isolated test repos or hard resets would be preferable for test independence, but agrees this is a reasonable incremental improvement given the existing test structure. The patch appears technically sound and focused on enabling future test additions in the series without breaking existing assertions.
