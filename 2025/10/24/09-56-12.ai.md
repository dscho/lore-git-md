Refactoring patch completing Patrick Steinhardt's ODB loose object handling series.

This final patch in the 13-part series introduces streaming write capability to the ODB abstraction layer. It adds `odb_write_object_stream()` as the ODB-level interface for streaming large objects, mirroring the existing `odb_write_object()` for buffer-based writes. The implementation renames `stream_loose_object()` to `odb_loose_source_write_stream()` to match the series' naming conventions, moving it from object-file.h to the ODB interface.

The changes are mechanical and consistent with the series' pattern - updating the function name, moving declarations to odb.h, and adjusting the single caller in builtin/unpack-objects.c to use the new interface. The patch introduces a new `struct odb_write_stream` to replace `struct input_stream` while maintaining identical functionality.

This completes the transition of all loose object operations to the ODB source interface, with the exception of `open_istream_loose()` which remains repository-level (noted in previous patches). The changes span object-file.c, odb.c, and their headers, plus the unpack-objects caller, totaling 27 lines added and 17 removed across 5 files.

The patch follows the series' incremental approach - first establishing the infrastructure (patches 1-8), then mechanically transitioning callers (9-13) - and maintains behavior while improving organization. It prepares for future pluggable ODB backends by completing the streaming write interface. The implementation appears straightforward with no obvious technical issues, though the series as a whole remains unreviewed.
