Feature and maintenance strategy enhancement for geometric repacking in Git. This is the final version of a series that introduces a new "geometric" maintenance strategy, addressing limitations in Git's current repository maintenance approaches. The patch set has undergone multiple rounds of review and refinement, with maintainer approval from both Taylor Blau and Junio C Hamano.

The key improvements in this version include:
- Better line wrapping and formatting
- Use of nested designated initializers for improved code readability
- More accurate loose object counting using `git-count-objects`
- Configurable geometric split factor via `maintenance.geometric-repack.splitFactor`
- The new strategy combines geometric repacking with periodic full repacks using cruft packs
- Maintenance strategies now apply to both manual and scheduled maintenance
- Backward compatibility is maintained for existing "incremental" strategy users

The implementation provides a hybrid approach that's particularly beneficial for monorepos, avoiding the performance issues of all-into-one repacks while still maintaining repository health. The series includes comprehensive test coverage and has been refined based on feedback from multiple reviewers.
