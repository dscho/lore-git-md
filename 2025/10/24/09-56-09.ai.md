This is a refactoring patch in Patrick Steinhardt's ongoing series to abstract Git's loose object handling into the ODB (object database) source interface. Patch 10/13 focuses on renaming the `has_loose_object()` function to `odb_loose_source_has_object()` to better reflect its role in the new ODB architecture.

The change is purely mechanical, updating the function name and its callers in builtin/pack-objects.c and object-file.c while maintaining identical behavior. The new name follows the established pattern in this series of prefixing loose object-related functions with `odb_loose_source_` to clearly associate them with the ODB abstraction layer. The patch also moves the function's documentation in object-file.h to group it with other ODB loose source operations.

Key technical details:
- Updates 3 call sites in pack-objects.c (cruft pack and mtime checking logic)
- Updates 1 call site in object-file.c (`force_object_loose`)
- Maintains the same function signature and behavior
- Groups documentation with related ODB source functions
- Part of the broader effort to move loose object operations into the ODB source interface

This continues the series' pattern of mechanical refactoring to improve code organization before introducing behavioral changes. The patch is straightforward and unlikely to be controversial, though reviewers may want to verify the call site updates are complete.
