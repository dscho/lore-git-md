This is a bugfix patch addressing output redirection in external diffs. It's the first in a 4-part series cleaning up diff dry-run behavior, building on earlier work by Lidong.

The patch fixes a long-standing issue (since 2008) where external diff commands weren't properly respecting Git's `--output` redirection. While most diff output goes to the specified file, external diffs were still writing to stdout. The fix involves carefully redirecting the external command's output while handling several edge cases around file handles and flushing.

Jeff King provides a thorough explanation of the technical considerations, including descriptor duplication and stdout handling. The patch includes a new test case demonstrating the fix works, while noting that another existing test already covers the descriptor duplication behavior.

This appears to be a well-crafted fix for a clear bug, with good test coverage and careful attention to edge cases. It sets up the groundwork for the more substantial refactoring coming in later patches of the series.
