This is a documentation patch in Christian Couder's series about unifying signature handling across Git commands. The patch updates the `git-tag` man page to be more accurate about the command's support for multiple signature formats (PGP, X.509, SSH) rather than focusing solely on GPG.

The changes make several improvements: The NAME section now describes the command generically as working with "tags" rather than specifically "GPG-signed tag objects". The DESCRIPTION and OPTIONS sections are updated to reference "cryptographic signatures" generally, with details about how `gpg.format` controls the signing backend. The CONFIGURATION section now explicitly mentions support for multiple signature formats via `gpg.format` and related configuration.

The patch maintains all existing functionality while making the documentation more inclusive of non-GPG signing methods. This aligns with the broader series' goal of making signature handling consistent across Git commands. The changes are straightforward documentation updates with no behavioral impact, and they help set the stage for the implementation changes in the rest of the series.
