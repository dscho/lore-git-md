This is a refactoring patch in Patrick Steinhardt's series to abstract Git's loose object handling. It introduces a new `struct odb_loose_source` to contain all loose object state, moving it out of the more general `struct odb_source`. This is part of the larger effort to make Git's object database pluggable.

The patch adds the new struct and its allocation/free functions, then wires them into the existing ODB infrastructure. The changes are mechanical - the commit message explains this is groundwork for eventually turning this into a proper backend interface. The diff shows straightforward additions to object-file.c/h and odb.c/h, with the new struct being initialized when an ODB source is created and cleaned up when freed.

This continues the series' pattern of incremental, behavior-preserving changes that improve code organization in preparation for more substantial architectural work. The patch appears clean and focused, with clear commit message explaining both the immediate change and its role in the larger effort.
