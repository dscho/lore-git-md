This is a refactoring series that reorganizes how Git handles loose objects, as part of the ongoing effort to make object databases pluggable. Patrick Steinhardt proposes carving out all loose object handling into a dedicated `struct odb_loose_source`, similar to how packfiles are managed via `struct packfile_store`.

The 13-part series starts with preparatory cleanups (patches 1-4), then introduces and populates the new loose object structure (patches 5-8), and finally updates callers to use the new interface (patches 9-13). The changes touch core object handling code across multiple files, with the bulk of modifications in object-file.c and odb.c.

The motivation is clearly stated: this is groundwork for making object storage backends pluggable. The series appears well-structured, breaking down a complex change into logical steps. While the diffstat shows significant churn (nearly 500 lines changed), the changes seem focused and the commit messages provide clear explanations of each step in the transformation. This looks like a serious, well-planned infrastructure change that could enable future flexibility in Git's object storage layer.
