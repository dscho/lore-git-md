This is patch 11/13 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the object database (ODB) abstraction effort. The patch focuses on "freshening" objects (updating their modification times when they already exist in the database).

The key change moves the freshening logic out of object-file.c and splits it into format-specific implementations: `packfile_store_freshen_object()` for packed objects and `odb_loose_source_freshen_object()` for loose objects, with a new `odb_freshen_object()` function coordinating between them. This better aligns with the series' goal of separating concerns between the ODB layer (which coordinates) and the source implementations (which handle format-specific details).

The patch is a straightforward refactoring that maintains existing behavior while improving code organization. It continues the series' pattern of mechanical changes that prepare for pluggable ODB backends. The changes touch object-file.c, odb.c, packfile.c and their headers, moving code between them while keeping the same functionality.
