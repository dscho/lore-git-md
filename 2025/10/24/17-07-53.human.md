This is the second patch in a 4-part series cleaning up diff dry-run behavior, specifically focusing on the color-moved feature. The patch removes unnecessary saving and restoring of the `color_moved` flag during dry-run diffs, where the flag was being toggled off even though it wouldn't be used in that mode anyway.

The author explains that color-moved detection only happens during full patch output generation (via `diff_flush_patch_all_file_pairs()`), not during the single-file-pair checks performed in dry-run mode. The original code from 2017 and a recent 2025 change both included this redundant flag manipulation, which the patch now eliminates.

This is a straightforward cleanup that doesn't change behavior - it removes code that was effectively dead due to how the diff machinery operates. The change is small (4 deleted lines) and focused entirely on `diff.c`. As part of a larger series simplifying dry-run handling, this patch appears uncontroversial and well-justified by the code analysis.
