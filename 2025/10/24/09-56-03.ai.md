This is a refactoring patch in Patrick Steinhardt's ongoing series to modernize Git's object database (ODB) infrastructure. The patch moves the `fetch_if_missing` global variable declaration from object-file.h to odb.h, better reflecting its scope as an ODB-wide setting rather than being specific to loose objects.

The change is straightforward: the variable controls whether `odb_read_object_info_extended()` will fetch missing blobs when partial clone is enabled, and logically belongs with other ODB-level declarations. The patch maintains identical functionality while improving code organization, moving both the declaration and its documentation comment.

This continues the series' pattern of mechanical cleanups preparing for deeper architectural changes to the ODB interface. The patch touches object-file.h and odb.h but requires no behavioral changes. As with previous patches in the series, this appears to be a well-justified, low-risk change that helps untangle object-file.c's mixed responsibilities between loose object handling and general ODB operations.
