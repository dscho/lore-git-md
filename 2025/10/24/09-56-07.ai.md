This is patch 8/13 in Patrick Steinhardt's series refactoring Git's loose object handling as part of the object database (ODB) abstraction effort. The patch continues the mechanical reorganization by moving the loose object map (used for converting between canonical and compatibility hash formats) from the generic `struct odb_source` to the more specific `struct odb_loose_source`.

The changes are straightforward:
- The `loose_map` field is moved from `odb_source` to `odb_loose_source`
- All accessors are updated to use the new location
- The map clearing is moved to `odb_loose_source_free()`
- The diff shows mechanical updates across loose.c, object-file.c/h, and odb.c/h

This follows the series' pattern of gradually moving loose-object-specific functionality into the dedicated loose source structure while maintaining existing behavior. The patch touches core object database code but makes no functional changes - it's purely an organizational improvement that better encapsulates loose object handling details.
