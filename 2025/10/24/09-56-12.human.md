This is the final patch in Patrick Steinhardt's 13-part series refactoring Git's loose object handling as part of the object database (ODB) abstraction effort. The patch introduces streaming write capability at the ODB layer.

The change adds a new `odb_write_object_stream()` function to provide a unified interface for streaming large objects to disk, complementing the existing `odb_write_object()` for in-memory writes. The implementation renames `stream_loose_object()` to `odb_loose_source_write_stream()` to match the series' naming conventions and moves the streaming infrastructure (`struct odb_write_stream`) to odb.h where it logically belongs.

The patch updates the single caller in `builtin/unpack-objects.c` to use the new interface. This completes the mechanical refactoring portion of the series, having now moved all loose object operations to the ODB source interface. The changes are straightforward and maintain existing behavior while improving architectural organization.

As the series conclusion, this represents a significant step toward the goal of making Git's object storage backend more modular and pluggable. The work appears well-executed with careful attention to maintaining backward compatibility and clear naming conventions throughout.
