This is a refactoring patch in Patrick Steinhardt's ongoing series to abstract Git's loose object handling as part of the object database (ODB) backend work. Patch 7/13 focuses on cleaning up the loose object cache management interface.

The patch introduces `odb_loose_source_reprepare()` to handle cache clearing when repreparing loose object sources, matching the existing `packfile_store_prepare()` pattern. This encapsulates the cache clearing logic that was previously exposed directly in `odb_reprepare()`. The change renames `odb_clear_loose_cache()` to the more specific `odb_loose_source_clear_cache()` (made static since it's now an implementation detail) and updates all callers.

Key technical changes:
- New public function `odb_loose_source_reprepare()` in object-file.h
- Renamed/internalized cache clearing function
- Updates call sites in odb.c and object-file.c
- Maintains same cache clearing behavior but with better encapsulation
- Part of consolidating loose object handling into the new `struct odb_loose_source`

This continues the series' pattern of mechanical refactoring to improve the ODB abstraction layer's internal interfaces before more substantial changes. The patch touches core object database files (object-file.c/h, odb.c) but doesn't modify behavior - it just moves and renames functionality to better hide implementation details.
