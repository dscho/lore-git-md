This is a refactoring patch in Patrick Steinhardt's ongoing series to abstract Git's loose object handling. Junio Hamano is reviewing patch 2/13, which introduces `odb_source_new()` to centralize creation of ODB source structures.

The change moves path expansion before source creation, which requires adding an "else" clause to handle the case where sources already exist. While most of the patch is straightforward, Junio notes this particular change is trickier than others in the series because it modifies the control flow around path handling.

The patch maintains the same functionality while improving code organization - a pattern seen throughout this series. It's part of the foundational work to prepare for pluggable ODB backends, though this particular change doesn't yet introduce new capabilities. The review suggests the change is sound but warrants closer attention due to the subtle control flow modification.
