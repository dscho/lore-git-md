CI housekeeping patch in the Rust cbindgen series, addressing platform compatibility for 32-bit testing.

This patch switches the CI system's 32-bit test environment from Ubuntu (which has ended 32-bit support) to Debian, which still maintains a 32-bit port. The change affects both GitHub Actions and GitLab CI configurations, updating the Docker image references and associated package installation logic. The motivation is twofold: Ubuntu's 32-bit images are end-of-life and missing packages needed for upcoming Rust-C binding generation with cbindgen.

The changes span four files: `.github/workflows/main.yml`, `.gitlab-ci.yml`, `ci/install-dependencies.sh`, and `ci/lib.sh`. The modifications include updating image references from `i386/ubuntu` to `i386/debian`, adjusting package installation logic (replacing `language-pack-is` with `locales-all` for the Debian image), and updating platform detection patterns.

This appears to be a straightforward maintenance update that resolves a concrete compatibility issue while maintaining the same test coverage. The patch is part of the larger Rust cbindgen integration effort (v2 series) and follows naturally from earlier CI-related discussions in the thread. It implements a practical solution to a platform-specific problem that was blocking further work in the series.
