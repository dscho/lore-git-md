This is a refactoring patch in Patrick Steinhardt's ongoing object database abstraction series (3/13). It updates function names to match the recent rename from `struct object_directory` to `struct odb_source`, while also aligning with Git's modern naming conventions.

The patch renames two key functions:
- `free_object_directory()` becomes `odb_source_free()`
- `free_object_directories()` becomes `odb_free_sources()`

These functions handle cleanup of ODB sources and their associated memory. The changes are purely mechanical - updating call sites and maintaining the same functionality while improving naming consistency. The patch touches only odb.c, modifying 5 lines across 4 locations where these functions are called or defined.

This continues the series' pattern of gradually modernizing the ODB infrastructure's interface while maintaining existing behavior. The changes are straightforward and unlikely to be controversial, serving as preparation for later patches that will introduce more substantial architectural changes to the loose object handling system.
