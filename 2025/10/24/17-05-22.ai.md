This is a patch series cleaning up diff dry-run behavior, building on recent work by Lidong. The series consists of 4 patches that progressively simplify how Git handles dry-run diffs.

The first patch fixes a long-standing bug (since 2008) where external diff output wasn't properly directed to the specified output file during dry runs. The second patch removes unnecessary color_moved state saving in dry-run mode. The final two patches represent a more significant refactoring - they eliminate the dry_run flag entirely by using NULL file pointers instead, and remove the redirection to /dev/null that was previously used for dry runs.

The changes touch core diff.c logic and its header, plus add a test case. The series appears well-motivated by recent discussion and builds on Lidong's prior fixes. The later patches might be slightly controversial as they change behavior by converting missed dry_run checks into potential segfaults, but the author believes this is an acceptable tradeoff for cleaner code. The series depends on ly/diff-name-only-with-diff-from-content.
