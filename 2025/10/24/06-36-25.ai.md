CI preparation patch follow-up regarding sudo compatibility.

This is a brief reply from Patrick Steinhardt confirming that the switch from Ubuntu to Debian for 32-bit CI builds (as proposed in patch 1/3 of the cbindgen series) won't reintroduce the sudo compatibility issues that were recently addressed. The key point is that Debian still uses the traditional sudo implementation without the `/etc/alternatives/sudo` symlink that caused problems on Ubuntu, making it a safe replacement for the 32-bit testing environment.

The exchange shows Junio Hamano's initial concern about potential regressions from the sudo-rust vs sudo-C changes, and Patrick's confirmation that Debian's current setup avoids this issue. This appears to be the final clarification needed before the CI preparation patch can proceed, as Junio had already queued it pending this verification.
