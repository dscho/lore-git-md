This is part of a series introducing geometric repacking strategies for Git maintenance, now in its third iteration with final sign-off from maintainers. Patch 7/10 refactors how maintenance tasks are executed based on invocation type.

The patch introduces a distinction between manual maintenance (run directly or via `--auto`) and scheduled maintenance (run via `--schedule`). It converts the simple `enabled` flag into a bitmask that tracks which tasks should run in each context. The existing strategies are updated to maintain their current behavior - the default strategy only runs manually while the incremental strategy only runs on schedule.

This change lays groundwork for upcoming patches that will expand strategy support to all maintenance types. The implementation is clean and maintains backward compatibility while adding the necessary flexibility. With maintainer approval already secured, this appears to be a well-considered piece of infrastructure work in a mature patch series.
