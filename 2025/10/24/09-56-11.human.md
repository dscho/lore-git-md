Refactoring patch in Patrick Steinhardt's ongoing ODB abstraction series. This is patch 12/13 in the effort to modernize Git's loose object handling by moving functionality to the object database layer.

The patch performs a straightforward rename of `write_object_file()` to `odb_loose_source_write_object()`, aligning it with the new naming convention established in earlier patches. The change affects three files (object-file.c, object-file.h, odb.c) with minimal code modifications beyond the rename itself.

This continues the series' pattern of systematically updating function names to clearly indicate their relationship to the loose object source interface. The change is mechanical and maintains existing behavior while improving code organization. As with previous patches in the series, this appears to be a well-contained change that moves the codebase toward the eventual goal of pluggable ODB backends.
