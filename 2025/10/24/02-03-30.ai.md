This is a bugfix and feature enhancement for `git fast-export`'s tag signature handling, part of Christian Couder's series to unify signature processing across fast-import/export. The patch replaces fast-export's hardcoded PGP signature detection with the shared `parse_signed_buffer()` function, enabling proper handling of all Git-supported signature formats (PGP, X.509, SSH). 

The implementation removes fragile string matching for PGP signatures in favor of the centralized parser that correctly identifies signatures by their format-specific markers ("BEGIN PGP MESSAGE", "BEGIN SSH SIGNATURE", etc.). This affects the `--strip-tags` behavior, which now properly strips all signature types rather than just PGP.

Test coverage is expanded with new cases for X.509 and SSH signatures, verifying both verbatim passthrough and stripping behaviors. The tests use the dynamic `ANNOTATED_TAG_COUNT` variable introduced earlier in the series. Elijah Newren's review confirms the technical approach, noting the improvement over the previous special-case parsing.

This completes the symmetry between fast-import and fast-export's signature handling, with both now using the same parsing infrastructure. The change is low-risk as it builds on the already-reviewed `parse_signed_buffer()` function and maintains the same interface for signature stripping. The patch appears production-ready with comprehensive test coverage across all signature formats.
