Refactoring patch in the ODB abstraction series. This is patch 4/13 in Patrick Steinhardt's ongoing work to modernize Git's loose object handling infrastructure.

The patch moves the `fetch_if_missing` global variable declaration from object-file.h to odb.h, since it relates to the entire object database rather than just loose objects. The variable controls whether missing objects should be fetched when extensions.partialClone is enabled, with a default value of 1 (fetch enabled).

This is a straightforward mechanical change that continues the series' pattern of cleaning up the object database interface. The patch maintains all existing functionality while better organizing the code according to logical responsibilities. The change is small (8 lines moved between headers) and unlikely to be controversial, though reviewers may want to confirm the new location makes architectural sense as the ODB abstraction work progresses.
