This is a follow-up bugfix to the dry-run refactoring series, addressing a now-redundant quiet-mode check in `run_external_diff()`. Jeff King points out that after the architectural changes in patch 3 (which replaced dry-run booleans with NULL file pointer checks), the existing logic checking for `DIFF_FORMAT_PATCH` can never trigger. The analysis shows the function is only called from two paths where either the dry-run condition is already true or `DIFF_FORMAT_PATCH` is set, making the check unnecessary.

The patch simplifies the code by removing this redundant condition and consolidating the quiet-mode handling to just check for NULL `o->file`. This makes the control flow clearer by keeping all file pointer handling logic together. The change is small (3 lines removed) but improves maintainability by eliminating now-dead logic paths from the earlier dry-run implementation. As a late addition to an already-reviewed series, this appears to be a straightforward cleanup that aligns with the architectural direction already approved by the maintainers.
