This is a patch series cleaning up the diff dry-run implementation, building on recent fixes by Lidong. The series addresses both bug fixes and code simplification in how Git handles dry-run diffs.

The first patch fixes a long-standing bug (since 2008) where external diff output wasn't properly directed to the specified output file during dry runs. While not urgent, it's a clear bug fix that could stand alone.

The second patch simplifies the code path by removing unnecessary color_moved state saving during dry runs, which should be uncontroversial. The final two patches are more substantial changes that completely remove the dry_run flag and its associated redirections to /dev/null, instead relying on NULL file pointers. These may be more controversial as they could expose any remaining dry-run bugs as segfaults, though the author believes Lidong's prior fixes have addressed these cases.

The series touches core diff.c functionality and includes test updates, showing careful attention to maintaining correctness while simplifying the codebase. The changes appear well-motivated by recent discussion and cleanup opportunities, though the latter patches may warrant closer review given their potential to expose latent issues.
