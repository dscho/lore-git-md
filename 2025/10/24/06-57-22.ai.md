This is a feature patch completing the geometric repacking strategy series by making the "gc" strategy explicitly configurable. It addresses two limitations in the maintenance strategy system: the inability to select the default "gc" strategy when a different global strategy is set globally, and the previous restriction of git-gc to manual maintenance only.

The patch modifies the strategy handling to recognize "gc" as a valid strategy alongside "none" and "incremental". It updates the gc_strategy to run for both manual and scheduled maintenance (MAINTENANCE_TYPE_MANUAL | MAINTENANCE_TYPE_SCHEDULED) with a daily schedule. The documentation is updated to reflect that "gc" is now a selectable strategy and remains the default for manual maintenance.

Test coverage is expanded in t7900-maintenance.sh to verify the gc strategy works in both manual and scheduled contexts, checking that it runs the expected git-gc commands. The changes maintain backward compatibility while providing more flexibility in strategy selection.

This patch represents the final piece of the maintenance strategy unification work that has been reviewed and approved by Taylor Blau and Junio C Hamano. It cleanly integrates with the earlier geometric repacking work while solving a clear configuration gap in the maintenance system. The implementation is straightforward and well-tested, with clear documentation updates matching the code changes.
