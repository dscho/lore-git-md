Documentation update clarifying Git's tag signature support beyond just GPG. This patch modernizes the `git-tag` man page to reflect that cryptographic signatures can use multiple backends (GPG, X.509, SSH) via the `gpg.format` configuration, rather than implying GPG is the only option. The changes make the documentation more accurate about lightweight vs annotated tags and properly describe the configurable signing options. The update appears thorough, touching all relevant sections of the man page while maintaining clarity. This is part of a larger series (now in its third iteration) bringing consistent signature handling across Git's import/export commands. The documentation changes align with the code's actual capabilities and have already been reviewed by multiple contributors.
