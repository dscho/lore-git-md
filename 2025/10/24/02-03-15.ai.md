This is a test infrastructure patch in Christian Couder's series on consistent signature handling between `git fast-import` and `git fast-export`. The patch addresses a potential fragility in the test suite where hardcoded tag counts could break if new tests add more tags. 

The solution introduces a dynamic `ANNOTATED_TAG_COUNT` variable that increments each time a test adds an annotated tag, replacing the previous hardcoded values (3 and 4) with references to this counter. This makes the test assertions more robust against future additions while explicitly documenting the test interdependencies. The approach was chosen over more thorough refactoring (like per-test repos or hard resets) to minimize disruption to the existing test structure.

Elijah Newren's response acknowledges the tradeoffs, noting that while isolated test repos would be ideal, the incremental approach is reasonable given the scope of changes needed. The patch appears technically sound and maintains the test coverage needed for the signature handling series while improving maintainability.
