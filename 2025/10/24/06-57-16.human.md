This is part of a series introducing geometric repacking strategies for Git repository maintenance (patch 3/10). The patch adds a new "geometric-repack" maintenance task that combines the benefits of geometric repacking (faster repacks by skipping reachability checks) with periodic full repacks using cruft packs (to properly expire unreachable objects).

The task is configurable via `maintenance.geometric-repack.auto`, which controls when automatic repacks should run based on loose object counts or pack merging opportunities. The implementation includes thorough test coverage verifying the hybrid strategy's behavior across various scenarios.

The patch builds on earlier refactoring work in the series and has already received positive reviews from Taylor Blau and Junio C Hamano. It represents a key piece of infrastructure that will be particularly useful for hosting providers managing large repositories, as it provides better control over the trade-off between repack performance and object expiration.
