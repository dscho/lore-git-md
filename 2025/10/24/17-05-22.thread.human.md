This thread is cleaning up Git's diff dry-run behavior, focusing on simplifying output redirection and state management. The series builds on Lidong's prior work and currently consists of four patches.

The first patch fixed a long-standing issue where external diff` programs (via `GIT_EXTERNAL_DIFF`) ignored the `--output` redirection, writing to stdout instead. The just-received second patch removes unnecessary save/restore operations for the `color_moved` flag during dry-run diffs, as move detection can't affect dry-run outputs which only examine individual file pairs. This is a straightforward cleanup of dead code in `diff.c` around the `diff_flush()` function.

The remaining patches will introduce more substantial changes, including eliminating the dry_run flag entirely in favor of NULL file pointers - a design choice that may generate discussion about safety versus code cleanliness. The changes are concentrated in diff.c with new test coverage being added. No reviews have been posted yet as this is the initial submission, but the early patches appear uncontroversial preparatory work for the more significant refactoring to come.
