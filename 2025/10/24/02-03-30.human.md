This is a bugfix patch in Christian Couder's series to standardize signature handling between `git fast-import` and `git fast-export`. The patch fixes `fast-export`'s tag signature detection to properly handle all supported signature formats (PGP, X.509, SSH) by using the centralized `parse_signed_buffer()` function instead of its previous hardcoded PGP-only check.

The change is straightforward - replacing a string search for PGP signatures with a call to Git's standard signature parser. The patch includes new test cases verifying X.509 and SSH signature handling, building on the series' existing test infrastructure (note the use of the `ANNOTATED_TAG_COUNT` variable introduced earlier).

Elijah Newren's review confirms the technical approach, noting the improvement from removing special-case parsing. The patch appears well-integrated with the broader series goal of consistent signature handling, with no outstanding technical issues raised. The test additions follow the established pattern while expanding coverage to the previously unsupported formats.

This is a focused, production-ready change that completes an important piece of the signature handling unification work. Readers following the series can expect this to be one of the final steps before potential merging, as it addresses the last major asymmetry between import/export signature processing.
