Refactoring patch improving maintenance strategy code readability.

This patch is part of the ongoing geometric repacking strategy series (v3, patch 6/10) that has already received extensive review and maintainer approval. It focuses purely on code organization, restructuring the maintenance strategy definitions in `builtin/gc.c` to use nested designated initializers.

The change makes it visually clearer which configuration fields belong to which maintenance task by grouping them under each task's array index. While functionally identical to the previous flat structure, the new layout helps developers more easily understand the relationship between tasks and their settings. The change was suggested by Taylor Blau during earlier review.

This is a straightforward readability improvement that doesn't affect behavior. The patch is small (36 lines changed) and since it comes late in a well-reviewed series, it's likely to be uncontroversial. The rest of the series has already addressed all technical concerns around the new geometric repacking functionality.
