This is a patch extending Git's maintenance strategy configuration to cover manual maintenance runs, completing the series on geometric repacking strategies.

The patch unifies how maintenance strategies" (predefined task sets) apply across both scheduled and manual maintenance runs. Previously, the `maintenance.strategy` config only affected scheduled runs, while manual runs defaulted to `git gc`. This could lead to conflicting maintenance approaches. The change makes strategies consistently configurable while preserving backward compatibility - the "incremental" strategy now explicitly runs `git gc` during manual maintenance to match historical behavior.

Key changes include:
- Updated documentation clarifying strategy behavior across all maintenance types
- Modified strategy initialization to check config before defaulting to type-specific strategies
- Added test cases verifying strategy behavior for both manual and scheduled runs
- Special handling for the "incremental" strategy to maintain backward compatibility
