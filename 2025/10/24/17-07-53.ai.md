This is a refactoring patch in a series cleaning up diff dry-run behavior. It removes unnecessary save/restore operations for the `color_moved` flag during dry-run diffs, building on the thread's broader goal of simplifying diff output handling.

The author explains that this flag couldn't possibly affect dry-run output since move detection requires comparing across multiple file pairs, while dry-run diffs only examine individual pairs. The change removes three lines that manipulated this flag while maintaining identical behavior.

The modification touches the core diff machinery in `diff.c`, specifically around the `diff_flush()` function where output handling is centralized. This is a straightforward cleanup with no expected controversy, as it merely removes dead code rather than changing functionality. The patch follows logically from the first in the series (which fixed external diff output redirection) and precedes more substantial changes coming in patches 3-4 that will eliminate the dry-run flag entirely.
