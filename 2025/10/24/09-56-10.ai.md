This is part 11/13 of Patrick Steinhardt's series refactoring Git's loose object handling as part of the object database (ODB) abstraction effort. The patch focuses on freshening objects - updating their mtimes when they already exist in the ODB.

The key change moves freshening logic from object-file.c to more appropriate locations:
- Introduces `odb_freshen_object()` as the top-level function in odb.c
- Creates format-specific implementations: `packfile_store_freshen_object()` in packfile.c and `odb_loose_source_freshen_object()` in object-file.c
- Shifts responsibility for iterating through object sources from individual sources to the ODB layer

The patch maintains existing behavior while better organizing the code. It continues the series' pattern of moving functionality from repository-level to ODB-level interfaces. The changes touch object-file.c, odb.c, packfile.c and their headers, with 28 lines removed and 46 added.

This is a mechanical refactoring that prepares for pluggable ODB backends by properly separating concerns - loose and packed object handling now live with their respective subsystems, with the ODB layer coordinating between them. The commit message clearly explains the motivation and design choices.
