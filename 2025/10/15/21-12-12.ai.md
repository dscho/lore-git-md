This patch adds machine-readable output formats to the `git repo structure` command, which is part of the ongoing series introducing repository structural analysis capabilities. The implementation provides two new formats alongside the existing human-readable table output: `keyvalue` (with '=' delimiters) and `nul` (with NUL/newline delimiters for better handling of special characters).

The changes include:
- New `FORMAT_TABLE` enum value alongside existing `FORMAT_KEYVALUE` and `FORMAT_NUL_TERMINATED`
- `structure_keyvalue_print()` helper function that handles both formats with configurable delimiters
- Updated command-line interface with `--format` option accepting all three format types
- Comprehensive tests verifying both new formats against expected output
- Documentation updates explaining the format options and their characteristics

The implementation follows Git's established patterns for machine-readable output, with the NUL format being particularly useful for scripting as it avoids quoting issues with special characters. The patch maintains consistency seen in earlier parts of the series, with careful attention to test coverage and documentation.

This represents the penultimate patch in the series, with only progress reporting remaining before the core functionality is complete. The clean separation between output formatting and the underlying statistics collection continues the good architectural decisions established earlier in the series.
