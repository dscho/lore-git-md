This is a test infrastructure patch that concludes a 4-part refactoring series for Git's reference optimization code. 

The change fixes a minor issue in test organization that emerged when shared test code was moved to `t/pack-refs-tests.sh` in a previous commit. Currently, the `test_done` directive is in the shared test file, which prevents adding test-specific cases to the individual test scripts (`t0601-reffiles-pack-refs.sh` and `t1463-refs-optimize.sh`) that include it. 

The patch moves `test_done` out of the shared file and into each individual test script, allowing future test additions while maintaining the existing test coverage. This is a clean, logical conclusion to the series that properly separates shared test logic from test script control flow.

The change is straightforward and uncontroversial, touching only test infrastructure with no impact on production code. It follows naturally from the earlier refactoring work in the series to standardize reference optimization testing.
