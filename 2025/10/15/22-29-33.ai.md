This is a refactoring patch in Taylor Blau's ongoing repack modularization series (tb/incremental-midx-part-3), specifically moving the `pack_kept_objects` static variable into the `pack_objects_args` struct as part of the broader effort to eliminate global state.

The patch relocates the `pack_kept_objects` flag from being a static variable in `builtin/repack.c` to becoming a field in the `pack_objects_args` struct, which better reflects its logical grouping with other pack-objects configuration. This change affects several key functions:

1. `write_cruft_pack()` now explicitly sets `pack_kept_objects=0` since it always wants to honor pack keep files
2. `write_filtered_pack()` no longer handles the `--honor-pack-keep` flag directly, instead relying on `prepare_pack_objects()`
3. The default initialization of `pack_kept_objects` (based on bitmap/MIDX writing status) is preserved but moved into the `PACK_OBJECTS_ARGS_INIT` macro
4. The pack geometry initialization is simplified by removing its direct dependency on `pack_kept_objects`

The changes maintain all existing behavior while continuing the series' pattern of moving configuration into appropriate structs and reducing direct manipulation of global state. This is a typical incremental step in the series - well-contained, with clear motivation and thorough updates to all affected call sites. The patch follows the established pattern of the series by keeping behavior identical while improving the code organization.
