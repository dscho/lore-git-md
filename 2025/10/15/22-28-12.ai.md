This is a refactoring patch in Taylor Blau's ongoing 49-part series to modularize `builtin/repack.c` and eliminate global variables. It's patch 18/49 in the second version of the series.

The patch addresses compiler warnings that appear under DEVELOPER=1 mode by changing two variable types to better align with their usage contexts. In `existing_packs_mark_for_deletion_1()`, it changes `hexsz` from `int` to `size_t` to match the type returned by `algop->hexsz`. In `existing_packs_collect()`, it changes the loop counter `i` from `int` to `size_t` to match the type of the string_list's `nr` field. Both changes eliminate unnecessary numeric casts while maintaining identical behavior.

This is a minor but thoughtful cleanup that follows the series' pattern of careful mechanical conversions. The changes prepare the code for its eventual move to a separate compilation unit by removing warnings that would otherwise require suppressing with DISABLE_SIGN_COMPARE_WARNINGS. The patch demonstrates the series' attention to detail in establishing clean interfaces and follows established patterns from earlier patches in the series (particularly patches 15-17 which standardized naming conventions for the existing_packs API).
