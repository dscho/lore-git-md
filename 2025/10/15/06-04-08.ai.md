This is a CI/build system patch in Patrick Steinhardt's Rust infrastructure series (v3, patch 4/6), adding Clippy static analysis to the Rust CI pipeline. The patch installs Clippy as a Rustup component alongside rustfmt and runs it across all targets and features with warnings treated as errors. This implements the final major CI check needed for Rust code quality, complementing the previously added rustfmt formatting checks from patch 2.

The change aligns with the thread's established approach of integrating standard Rust tooling while maintaining Git's CI conventions, using the same `group` helper function for output formatting seen in other checks.

This patch completes the core static analysis tooling for Rust in Git's CI, addressing one of the remaining items from the series' scope after rustfmt was handled earlier.
