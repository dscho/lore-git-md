This is patch 10/49 in Taylor Blau's ongoing refactoring series to modularize `builtin/repack.c` and remove global variables, particularly focusing on `the_repository` and `the_hash_algo`.

Taylor notes this represents the practical limit of easy conversions in this direction, as other remaining cases like `is_bare_repository()` would require more invasive changes. The patch maintains the same behavior while making the code more modular and less dependent on global state.

This is a straightforward continuation of the series' pattern - mechanical conversions that thread repository state through function calls rather than relying on globals. The change is small and focused, with no apparent controversy given the established pattern in previous patches.
