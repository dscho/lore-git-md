This is a final ack from Junio C Hamano for Patrick Steinhardt's patch deprecating the `core.preferSymlinkRefs` configuration. The patch is part of an effort to phase out the legacy symlink-based storage of symbolic refs in favor of the modern textual format that has been the default for nearly 20 years.

The v2 patch incorporates several improvements from the initial version, including better terminology ("textual symref format"), adjusted warning timing to avoid interfering with error messages, and refined documentation wording. Junio's approval indicates this is ready to be merged into the codebase.

The change maintains backward compatibility by continuing to read symlink-based refs while only deprecating their creation. The deprecation warning will help users transition before the feature is fully removed in Git 3.0. The patch appears well-considered with thorough test coverage and clear documentation updates.
