This is part 12/49 of Taylor Blau's ongoing refactoring series to modularize Git's repack machinery and eliminate global variables. The patch introduces a new `repack_config_ctx` struct to pass both regular and cruft pack configuration arguments to the `repack_config` callback function.

The change is preparatory work for a future commit that will move the `delta_base_offset` variable from being a static in `builtin/repack.c` to becoming a member of `struct pack_objects_args`. By introducing this context struct now, the configuration callback will have access to both sets of arguments when that change lands.

The patch follows the series' pattern of small, incremental changes that maintain existing behavior while moving toward the larger goal of modularization. It touches only the configuration handling code path in `builtin/repack.c`, adding the new context struct and updating the callback signature and callsite accordingly. The change is well-contained and clearly motivated by the immediate need to support the upcoming `delta_base_offset` relocation.

This continues the careful, step-by-step approach seen throughout the series, where each patch makes a single logical change while keeping the code functional at each step.
