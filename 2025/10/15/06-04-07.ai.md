This is part 3 of Patrick Steinhardt's Rust CI infrastructure series (v3), focusing on safety documentation for varint encoding/decoding functions in the Rust crate. The commit explains this prepares for upcoming Clippy integration by proactively addressing its unsafe code documentation requirements, with Brian m. carlson credited for assistance.

The implementation adds precise Rustdoc comments describing both behavior (overflow handling, NULL pointer cases) and safety contracts. This follows the thread's established pattern of adapting Rust ecosystem practices (like mandatory unsafe documentation) while maintaining compatibility with Git's C interfaces.
