This is the fifth patch in Patrick Steinhardt's Rust CI infrastructure series (v3, 6 patches), focusing on establishing and verifying a minimum supported version (MSRV) for Rust. The patch adds MSRV validation to the CI pipeline using cargo-msrv, targeting Rust 1.49.0 to maintain compatibility with alternative compilers like gccrs.

Key technical elements:
- Adds `rust-version = "1.49.0"` to Cargo.toml
- Installs cargo-msrv 0.18.4 (latest Ubuntu-compatible version) in CI
- Adds MSRV verification step to run-rust-checks.sh
- Uses conservative Rust version (1.49.0) to support alternative compilers
- Maintains consistency with the series' established pattern of adding discrete CI checks

The implementation follows the series' established approach of incremental CI tooling additions, building on the rustfmt and Clippy checks from earlier patches. The MSRV check completes the core Rust CI infrastructure by ensuring dependency version compatibility, though the patch notes there are currently no dependencies to validate against. The conservative version choice reflects the project's goal of supporting alternative Rust implementations.
