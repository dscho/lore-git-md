This thread discusses improving the deprecation warning for `git whatchanged`, a long-deprecated command that was superseded by `git log`. Greg Couch points out that the current warning message is unnecessarily burdensome - it tells users to pass a `--i-still-use-this` flag and email the mailing list if they want to keep using the command. He suggests simply recommending `git log` as the alternative instead, which would provide a clearer migration path for users.

The proposal makes sense from a user experience perspective, as the current message creates friction without clear benefit. Since `git whatchanged` has been deprecated for years with no plans to remove it, simplifying the warning to just point users to the modern equivalent would be a straightforward documentation improvement.
