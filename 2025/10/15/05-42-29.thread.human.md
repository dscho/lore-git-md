This thread discusses improving the deprecation warning for `git whatchanged`, which has been marked as deprecated in favor of `git log`. Greg Couch started the discussion by pointing out that the current warning message is unnecessarily cumbersome - it tells users to use a special `--i-still-use-this` flag and email the Git list, rather than simply recommending `git log` as the alternative.

Kristoffer Haugsbakk has now noted that this controversial warning is scheduled to appear in the upcoming Git 2.51.1 maintenance release, which adds some urgency to the discussion. While no maintainers have yet weighed in on Greg's proposed simplification, the imminent release means the current message will soon reach more users unless the maintainers decide to modify it.

The core issue remains straightforward - whether to keep the current verbose deprecation process or simplify it to just recommend `git log`. The discussion is currently waiting for maintainer input, particularly given the timing consideration raised about the 2.51.1 release.
