This is the final patch in Patrick Steinhardt's Rust CI infrastructure series, completing Windows support for Git's Rust components. The patch addresses two key Windows-specific issues: linking against the required `userenv.dll` for the Rust runtime, and handling the different library naming convention on Windows (`.lib` instead of `.a`). It also extends Rust testing to GitLab CI's Windows environment.

The changes span build system configurations (Makefile and meson) and CI setup (.gitlab-ci.yml), with careful attention to platform differences. The implementation builds on prior work by Johannes Schindelin and Ezekiel Newren, maintaining consistency with the series' established patterns. With Windows support in place, the Rust CI infrastructure now covers all major platforms, marking the completion of this foundational work.
