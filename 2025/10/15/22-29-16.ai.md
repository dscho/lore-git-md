This is patch 40/49 in Taylor Blau's incremental MIDX refactoring series (tb/incremental-midx-part-3), focusing on modularizing repack functionality while removing global variables. The patch introduces a new `struct write_pack_opts` to consolidate common parameters used by pack-writing functions in `builtin/repack.c`.

The change extracts shared parameters from `write_filtered_pack()` and `write_cruft_pack()` (destination path, pack prefix, and pack_objects_args) into a dedicated struct, while also including the static variables `packdir` and `packtmp` that these functions need to access. This reduces parameter duplication and provides a more unified interface. The struct is defined in `repack.h` for broader accessibility.

Key technical details:
- New struct contains: `po_args` (pack objects arguments), `destination`, `pack_prefix`, `packdir`, and `packtmp`
- First consumer is `write_filtered_pack()`, which sees its parameter list shrink from 5 to 2 arguments
- Follows the series' pattern of moving toward more structured parameter passing
- Explicitly leaves potential cleanup (deriving `pack_prefix` from `packdir`/`packtmp`) for a future patch
- Maintains all existing behavior while improving code organization
