This is the final patch in Patrick Steinhardt's Rust CI infrastructure series, completing Windows support for Git's Rust components. The patch addresses two key Windows-specific issues: linking against `userenv.dll` for the `GetUserProfileDirectoryW()` function and handling the different library naming convention on Windows (`.lib` instead of `.a`).

The implementation touches multiple build systems and CI configurations:
- Updates `.gitlab-ci.yml` to install Rust on Windows runners
- Modifies `Makefile` to handle Windows library naming and add `-luserenv`
- Adds Windows detection in `meson.build` to link against userenv.dll
- Adjusts `src/cargo-meson.sh` to account for Windows library filenames

The changes enable Rust support in both GitHub's Meson-based CI (which already had Rust installed) and GitLab CI (which now installs Rust). The patch builds on prior work from Johannes Schindelin and Ezekiel Newren, completing the cross-platform support that was started in earlier patches of this series.

This final piece integrates cleanly with the established CI patterns from previous patches (rustfmt, Clippy, MSRV validation) while resolving the last major platform compatibility issue. The implementation maintains the series' careful balance between Git conventions and Rust ecosystem standards, particularly in handling platform-specific build requirements.
