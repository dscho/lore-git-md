This is part of Taylor Blau's ongoing refactoring series to remove global variables from the repack machinery, specifically targeting `the_hash_algo` in this patch.

The patch modifies `write_oid()`, a callback function used when repacking promisor objects, to avoid using the global `the_hash_algo`. Since callbacks can't easily pass extra parameters, the solution introduces a new `write_oid_context` struct to carry both the original `child_process` pointer and the hash algorithm from the repository. The change is mechanical but necessary for the broader goal of eliminating global state.

This is patch 7/49 in the v2 series, which has already received substantial review from Jeff King (Peff) and others. The series is systematically converting repack functionality to use repository-specific parameters instead of globals, with this patch following the established pattern seen in earlier parts of the series. The change maintains identical behavior while making the code more modular.
