Refactoring patch in Taylor Blau's incremental MIDX repack series (patch 31/49). This continues the modularization of `builtin/repack.c` by extracting the MIDX ref snapshotting functionality into a new `repack-midx.c` compilation unit.

The patch moves the reference snapshotting code that creates a temporary file of commit OIDs for MIDX bitmap generation. This snapshot prevents races where reference updates could cause bitmap generation for commits not in the MIDX. The implementation remains functionally identical but is now properly encapsulated with:
- The `midx_snapshot_ref_data` struct and callback function moved verbatim
- A new public `midx_snapshot_refs()` declaration in `repack.h`
- Build system updates to include the new source file

Key technical details:
- Maintains the same reference walking logic using `for_each_ref` and `bitmap_preferred_tips`
- Preserves the peeling and commit object verification behavior
- Keeps the same tempfile handling and error reporting
- Follows the series pattern of making repository dependencies explicit via parameters

This is a straightforward code movement that follows the series' established approach for modularizing repack functionality while maintaining behavior. The patch appears well-contained and mechanically sound, with no obvious issues in the transformation from builtin/repack.c to the new dedicated module.
