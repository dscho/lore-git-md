Thread identity: Documentation patch proposing breaking change for Git 3.0 regarding `git diff X..Y` syntax, authored by Martin von Zweigbergk.

Core problem: The current `git diff X..Y` syntax is misleading behavior - it shows a two-dot diff (from X to Y) while appearing to suggest a range diff. The change would remove this syntax to allow potential future reintroduction with more intuitive semantics matching `git diff $(git merge-base X Y) Y`.
