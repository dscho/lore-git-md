This is the final patch in a 9-part refactoring series preparing xdiff for Rust FFI compatibility, focusing on renaming the `rindex` field to `reference_index` in xdiff's core data structures. The change is purely a naming improvement - the field's type (converted to `size_t*` in the previous patch) and all its behavior remain unchanged.

The patch updates all references to `rindex` across xdiff's core files (xdiffi.c, xprepare.c) and the type definition in xtypes.h. The new name better reflects the field's purpose as a mapping between compacted array indices and original file line references. Changes include updates to:
- Hash calculation in xdiffi.c's get_hash()
- Changed line marking during diff comparison
- Memory allocation and cleanup in xprepare.c
- Array indexing during record cleanup

As with previous patches in the series, this maintains identical behavior while improving code clarity. The rename completes the structural preparations for Rust FFI compatibility by ensuring field names are explicit about their purpose. Since this is a straightforward rename with no functional changes, it should be uncontroversial and completes the series' goal of modernizing xdiff's types and naming for better cross-language interoperability.
