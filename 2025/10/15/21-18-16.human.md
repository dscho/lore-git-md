The changes affect the core diff hashing logic that handles whitespace and verbatim line comparisons. While the behavior remains identical, the new types better match Rust's expectations and provide clearer semantics about the data being processed.

The modifications span four files, with the changes concentrated in `xutils.c` where the hashing algorithms live. The patch includes necessary type casts at API boundaries to maintain compatibility with existing callers. This continues the series' pattern of making targeted type changes that improve cross-language interoperability while preserving behavior.
