This is a CI optimization patch in Patrick Steinhardt's Rust infrastructure series (v3 1/6). It removes redundant `apt-get update` calls from the CI dependency installation script, where the same command was being run multiple times for different job types on the same platform. The change is straightforward - it simply deletes four identical update calls that were unnecessary since the package lists would already be fresh from an earlier distro-wide update.

The patch is part of the final polishing stage of this Rust CI series, where Justin Tobler had previously confirmed this optimization was valid. The change is low-risk (just removing redundant operations) and uncontroversial, though it does slightly change the CI workflow by relying more on the initial distro-specific update step. The commit message clearly explains the change and its rationale.
