CI optimization patch in the Rust infrastructure series.

This is the first patch in Patrick Steinhardt's v3 series (6 patches) improving CI infrastructure for Rust support. It removes redundant `apt-get update` calls from the dependency installation script, a change Justin Tobler confirmed as valid in previous discussion.

The patch eliminates four identical update calls that were previously made before each job-specific package set (ClangFormat, StaticAnalysis, sparse, Documentation). The rationale is that these updates are unnecessary since the distro-specific step earlier in the script already performed a repository update. The change is straightforward - simply deleting the update lines while keeping the actual package installations.

This appears to be a clean, uncontroversial optimization that reduces CI runtime without affecting functionality. The patch follows the series' established pattern of carefully analyzing and streamlining CI workflows while maintaining cross-platform compatibility. As part of the final polishing stage, this change helps complete the Rust infrastructure work by removing known inefficiencies.
