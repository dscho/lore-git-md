This is the first patch in a two-part refactoring series targeting the GPG interface code, specifically converting from strbuf_split to string_list_split for parsing SSH key fingerprints. The change comes from an Outreachy participant as part of their starter project.

The patch focuses on the `get_ssh_key_fingerprint()` function in gpg-interface.c, which currently uses `strbuf_split_max()` to parse the output of `ssh-keygen` into tokens. The author notes this is overkill since the tokens are only read and not modified, making the simpler `string_list` API more appropriate. The conversion reduces code complexity while maintaining the same functionality.

Key technical changes include replacing the strbuf array with a string_list, adjusting the split count parameter (since string_list_split counts splits rather than tokens), and simplifying the memory management. The patch demonstrates good attention to detail by noting and handling the parameter difference between the two split functions.

This appears to be a straightforward code quality improvement with no expected behavior change. The commit message clearly explains the rationale and the parameter adjustment needed for the conversion.
