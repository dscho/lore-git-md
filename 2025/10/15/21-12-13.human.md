This is the final patch in the `git repo structure` series, adding progress reporting functionality to the new repository analysis command. The patch implements a progress meter that shows during both the reference enumeration and object counting phases of repository analysis. The progress display follows Git's conventions - enabled by default when run interactively (on a tty) with explicit `--[no-]progress` options to override. The implementation integrates cleanly with Git's existing progress API and includes thorough tests verifying both the progress output and the option behavior.

The changes are well-established patterns seen elsewhere in Git - using `start_delayed_progress()`/`display_progress()`/`stop_progress()` for the progress meter, checking `isatty(2)` for default behavior, and following the standard `--[no-]progress` option convention. The tests cover both the automatic tty detection and explicit option cases, with assertions for the expected progress messages.

This completes the core functionality for the `git repo structure` command, which now provides human-readable and machine-parseable output of repository metrics along with user feedback during potentially long-running operations. The series as a whole delivers a robust alternative to external tools like git-sizer, fully integrated into Git's ecosystem.
