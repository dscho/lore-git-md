This is the fifth patch in Patrick Steinhardt's Rust CI infrastructure series, focusing on establishing and verifying a minimum supported Rust version (MSRV) for Git's Rust code.

The patch adds MSRV validation to the CI pipeline, specifying Rust 1.49.0 as the minimum version in Cargo.toml. This conservative choice aims to maintain compatibility with alternative Rust compilers like gccrs. The implementation uses cargo-msrv (pinned to version 0.18.4 for Ubuntu compatibility) to verify that all current and future dependencies can build with this minimum version.

The changes include:
1. Adding rust-version to Cargo.toml
2. Installing cargo-msrv in the dependency setup
3. Adding an MSRV check to the Rust CI workflow

This completes another key piece of the Rust CI infrastructure, following the earlier patches that added rustfmt and Clippy checks. The approach maintains the series' careful balance between Git's stability requirements and Rust ecosystem practices, with attention to cross-platform considerations (Ubuntu package versions) and future compatibility (gccrs support). The patch appears well-integrated with the existing CI framework established in previous patches.
