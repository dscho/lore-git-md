This is part 13/49 of Taylor Blau's repack refactoring series, continuing the work to modularize `builtin/repack.c` and eliminate global variables. The patch moves the `delta_base_offset` static variable into `struct pack_objects_args`, which was identified in the thread context as one of the remaining globals to be removed.

The change is a straightforward mechanical conversion - the static `delta_base_offset` that controlled whether `--delta-base-offset` was passed to pack-objects is now a field in the `pack_objects_args` struct, initialized to 1 by default via a new `PACK_OBJECTS_ARGS_INIT` macro. The patch maintains identical behavior while providing the plumbing needed for future refactoring steps.

Key technical details:
- Adds `delta_base_offset` field to `struct pack_objects_args` in repack.h
- Introduces `PACK_OBJECTS_ARGS_INIT` macro with default value 1
- Updates all references to the static variable to use the struct field instead
- Ensures the cruft pack arguments inherit the same delta_base_offset setting
- Touches the repack config callback, pack preparation, and initialization code paths

This continues the series' pattern of methodically converting global state into properly scoped struct members, following the groundwork laid in patch 12/49 which introduced `struct repack_config_ctx`. The change is well-contained and maintains the series' careful balance between clean interfaces and legacy behavior.
