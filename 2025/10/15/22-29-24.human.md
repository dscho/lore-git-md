This is a refactoring patch in Taylor Blau's ongoing series to modularize Git's repack machinery, specifically part 43/49 of the v2 series. The patch extracts duplicate logic for determining whether a pack destination is local into a new helper function `write_pack_opts_is_local()`.

The change eliminates repeated code in `write_cruft_pack()` and `write_filtered_pack()` that previously used `skip_prefix()` with a dummy scratch variable. The new function operates on the `write_pack_opts` struct (which contains both needed fields) and returns a bool via `starts_with()`, following modern conventions. The patch maintains behavior while cleaning up the implementation.

This continues the series' pattern of methodically breaking down repack functionality into focused, reusable components while addressing review feedback (here adopting Jeff King's suggestion to use `starts_with()`). The change is small but meaningful in the context of the larger effort to create clean, maintainable repack internals.
