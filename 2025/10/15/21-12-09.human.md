This is a small refactoring patch that improves the `ref-filter` interface as part of the larger `git repo structure` series. It modifies two functions in `ref-filter.c` to treat a NULL `name_patterns` array the same as an empty array when filtering references. Previously, callers had to provide an empty array even when no patterns were needed. The change is minimal (just 4 lines modified) but makes the API more intuitive to use.

The patch was already merged in an earlier version of the series (as noted in the thread summary), suggesting it was uncontroversial. It's a straightforward improvement that follows Git's typical patterns for making APIs more robust against NULL inputs. The change helps support the reference counting functionality in the larger `git repo structure` command by making the underlying filtering mechanism more flexible.
