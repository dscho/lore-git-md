This is part of Taylor Blau's ongoing refactoring series to eliminate `the_repository` global from the repack code (patch 3/49 in v2 series). The patch removes direct use of `the_repository` in MIDX-related ref snapshotting functions, passing the repository parameter explicitly instead.

The changes are mechanical but important for the codebase's long-term maintainability. The patch updates several functions that handle reference snapshots during repacking, including `midx_snapshot_ref_one()` and `midx_snapshot_refs()`, to take a `struct repository *` parameter rather than relying on the global. The behavior remains identical - this is purely about improving the code structure.

This continues the pattern established in earlier patches of the series, systematically removing global state while maintaining existing functionality. The changes are focused on the reference handling portion of the MIDX repack workflow, which is used when generating bitmaps. The patch appears well-contained and follows the established approach of the series.
