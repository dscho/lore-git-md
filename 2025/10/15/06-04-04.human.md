This is a cover letter for Patrick Steinhardt's v3 patch series improving Git's Rust CI infrastructure. The 6-part series builds on previous discussions that have already settled major policy questions around Rust formatting standards and Windows support.

The series introduces several key CI checks for Rust code:
- Formatting verification using rustfmt (with the Rust ecosystem's 100-character line length)
- Linting via Clippy
- Minimum Supported Rust Version (MSRV) validation
- Windows build support

Version 3 clarifies the rationale for the CI scripts' error handling approach (running all checks rather than failing fast) and incorporates feedback on varint encoding safety comments. The implementation appears thorough, with changes spanning GitHub Actions, GitLab CI, build files, and Rust source code. 

With major questions already addressed in previous rounds (formatting standards, Windows integration, varint safety), this version focuses on final refinements. The series looks ready for merging as it provides foundational Rust infrastructure while respecting Git's conventions through documented exceptions where needed.
