This is a documentation fix for the `git replay` feature series. Siddharth Asthana responds to Junio Hamano's discovery of a mismatch between the command's `-h` output and its man page synopsis format. The issue was caught by the t0450 test, which verifies consistency between documentation and help text.

The problem stems from the `git replay` usage string in `builtin/replay.c` being on a single line while the documentation splits it across two lines for readability. Junio provided a patch to align them by adding a newline and proper indentation to the C code's usage string. Siddharth confirms this is the right fix and plans to squash it into the next version of the series.

This is a straightforward formatting fix for an otherwise complete and well-tested series that makes atomic reference updates the default in `git replay`. The patch maintains the series' high quality by catching a documentation inconsistency before final integration.
