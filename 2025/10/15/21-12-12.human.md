This is a feature patch in the `git repo structure` series, adding machine-readable output formats to the new repository analysis command. 

The patch introduces two new output formats alongside the existing human-readable table: `keyvalue` (with `=` delimiters) and `nul` (with NUL/newline delimiters). The `keyvalue` format produces one stat per line in `key=value` form, while `nul` uses binary-safe delimiters for scripts that need to handle special characters. The default remains the table format for human consumption.

Implementation-wise, the patch adds a new `structure_keyvalue_print()` helper that emits all metrics with configurable delimiters, plus comprehensive tests verifying both formats against expected output. The changes integrate cleanly with the existing stats collection infrastructure while maintaining the command's clean separation between data gathering and presentation.
