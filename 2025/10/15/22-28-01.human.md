This is part of Taylor Blau's ongoing refactoring series to modularize Git's repack machinery (patch 14/49 in v2). The patch moves the `prepare_pack_objects` function from `builtin/repack.c` to the new `repack.c` module, making it available as a general utility function.

The change is straightforward - the function is copied verbatim to its new location with no behavioral changes. This is possible because previous patches in the series (particularly patch 13/49) removed the function's dependency on static variables, making it self-contained. The function handles setting up the arguments for `git pack-objects` based on a `pack_objects_args` struct.

This continues the series' pattern of incrementally extracting repack functionality into modular components while maintaining existing behavior. The patch looks clean and mechanical, with proper updates to the header file and no surprises in the implementation. It's another small step toward the series' goal of creating a more maintainable repack architecture.
