Refactoring patch in Taylor Blau's incremental MIDX repack series (patch 47/49). This continues the modularization of `builtin/repack.c` by moving the `write_filtered_pack()` function into its own compilation unit (`repack-filtered.c`). The function remains part of the repack API but now lives in a separate file that logically groups related functionality.

The change is straightforward - the function is moved verbatim from the builtin to the new file, with no behavioral changes. This follows the pattern established in earlier patches of the series to break up the monolithic repack implementation into smaller, more focused components. The patch adds the new file to both Makefile and meson.build build systems.

This is part of the broader effort to modernize Git's repack machinery by eliminating global variables and creating cleaner interfaces. The series has already been reviewed by Jeff King, who endorsed the overall approach, and appears to be in its final polishing stages before merging.
