Refactoring patch in Taylor Blau's incremental MIDX repack series (patch 31/49). This continues the modularization of `builtin/repack.c` by moving the reference snapshotting functionality used during MIDX creation into a new `repack-midx.c` compilation unit.

The patch extracts the code that creates a snapshot of repository references to avoid race conditions during bitmap generation. This snapshot is passed to `git multi-pack-index write` via `--refs-snapshot` to ensure bitmap selections remain consistent even if references change during repack. The functionality remains unchanged - it's just being relocated to follow the series' pattern of breaking up the monolithic repack implementation.

This is part of the systematic effort to eliminate global variables and improve code organization in the repack machinery. The change is straightforward - it moves existing code with minimal modifications (just making the function non-static and adding it to the repack.h API). The patch maintains all existing behavior while continuing the series' architectural improvements.
