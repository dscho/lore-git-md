This is a refactoring patch in a series preparing xdiff data structures for Rust FFI compatibility. It changes the type of `dstart` and `dend` fields in `xdfile_t` from `long` to `ssize_t`, which is more appropriate for pointer-relative offsets that can be negative. The fields are also moved to the end of the struct to minimize disruption for a future planned move to a different struct.

The change is small (just 2 lines modified) and appears straightforward, continuing the series' pattern of precise type safety improvements. The commit message clearly explains both the type change rationale and the field reordering purpose. As part of a larger effort with established review precedent, this patch seems uncontroversial and mechanically sound.
