This is the final patch in the `git repo structure` series, adding progress reporting functionality to the repository analysis command. The patch implements a progress meter that shows during both the reference counting and object counting phases of the operation.

The progress meter follows Git's standard patterns:
- Automatically enabled when output is to a terminal (isatty(2))
- Can be explicitly controlled with `--[no-]progress` flags
- Uses `start_delayed_progress()` to avoid flicker for fast operations
- Shows percentage completion for reference counting (known total)
- Shows object counts for the object traversal phase (unknown total)
- Includes test cases verifying both automatic and explicit control

The implementation adds progress callbacks to both `structure_count_references()` and `structure_count_objects()`, with the latter requiring a new `count_objects_data` struct to pass the meter through the path-walk API. Tests verify the progress output appears when enabled and is suppressed with `--no-progress`.

This completes the core functionality of the `git repo structure` command, which now provides:
- Reference type breakdowns
- Object type counts
- Multiple output formats (table, key-value, NUL-delimited)
- Progress reporting
- Comprehensive test coverage

The series has evolved from earlier iterations through naming changes (`repo stats` -> `repo structure`), scope refinement, and now adds this final user-facing polish. With all technical components implemented, the remaining work appears to be documentation (mentioned as coming in a follow-up series).
