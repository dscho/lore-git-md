This is part 4/6 of the `git repo structure` series, adding object counting functionality to the new repository analysis tool. The patch extends the existing reference counting with reachable object statistics, categorizing them by type (commits, trees, blobs, and tags).

The implementation uses Git's path-walk API to traverse all objects reachable from regular references, counting each type separately. The results are displayed in the same formatted table as the reference counts, maintaining the tool's consistent output style. The patch includes verification of both empty repositories and populated ones (with 42 test commits plus tags and notes.

This continues the series' pattern of thorough implementation - the object counting integrates cleanly with the existing reference statistics framework, uses appropriate Git APIs, and includes comprehensive tests. The output formatting preserves the human-readable table style established earlier while now providing a more complete picture of repository structure.
