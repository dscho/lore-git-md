This is part 3 of Patrick Steinhardt's Rust CI infrastructure series (v3, 6 patches), focusing on safety documentation for Rust's varint encoding functions. The patch adds thorough safety comments to `decode_varint()` and `encode_varint()` functions in the Rust crate, which were previously marked as unsafe due to their raw pointer interfaces matching the C implementations.

The changes document both the functions' behavior and their safety requirements - notably that buffers must be NUL-terminated for decoding and have sufficient allocated space for encoding. This addresses a Clippy requirement that will soon be enforced as part of the Rust CI setup being developed in this series. The documentation follows Rust best practices for unsafe code blocks while maintaining compatibility with the C interface.

The patch appears well-considered, with a clear explanation of why these changes are needed now (preparing for Clippy enforcement) and includes a co-author credit to Brian m. carlson for contributions to the varint safety work. As part of the nearly-finalized Rust infrastructure series, this represents one of the last technical refinements before merging.
