This is the eighth patch in a 9-part refactoring series preparing xdiff for better Rust FFI compatibility. The series has been systematically converting xdiff's core data structures to use more precise and platform-independent types.

This particular patch converts the `rindex` field in `xdfile_t` from `long` to `size_t`, as it represents an array index (pointing into the `recs` array). The change follows the established pattern in this series of using `size_t` for array-related fields, which better matches Rust's `usize` type. The patch also notes that the `dstart` and `dend` fields (which were moved to the end of the struct in an earlier patch) will be removed in a future series.

At just 2 lines changed (one in the struct definition and one in the type declaration), this is a straightforward mechanical change that continues the series' careful, incremental approach. Like previous patches, it maintains behavior while improving type safety. The series as a whole has shown good attention to detail, with each patch focusing on one clear type conversion and maintaining compatibility at API boundaries.
