Refactoring patch in a series cleaning up reference optimization code. This is the second of four patches following up on the recently merged `git refs optimize` functionality.

The patch removes now-obsolete code related to the older `pack_refs` interface, which has been fully superseded by the newer `optimize` callback. It deletes the `refs_pack_refs()` function from refs.c, removes its declaration from refs.h, and eliminates the `pack_refs_fn` typedef from refs-internal.h. The documentation in refs.h is also updated to clarify that the `PACK_REFS_*` flags now control `refs_optimize()` behavior.

This is a straightforward cleanup that follows logically from the first patch's standardization on the `optimize` interface. The changes are mechanical and well-contained, touching only three header/source files with clear deletions of now-unused code. The patch maintains the series' focus on technical debt cleanup from the optimization feature introduction, with no behavior changes.
