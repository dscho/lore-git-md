This is the first patch in a series to make `git add` respect `ignore=all` submodule configurations, part of a broader effort to align behavior across Git commands.

The patch modifies the core `add_files_to_cache()` function to accept a new `ignored_too` parameter (equivalent to `--force`), which will be used to handle ignored submodules. The changes propagate this parameter through several callers in `builtin/add.c`, `builtin/checkout.c`, and `builtin/commit.c`. The function signature update in `read-cache-ll.h` and implementation in `read-cache.c` now include this parameter, though the actual submodule handling logic isn't implemented yet in this initial patch.

Key technical details for future reference:
- The `update_callback_data` struct is expanded to carry the new `ignored_too` flag along with repository and pathspec pointers
- All existing call sites are updated to pass `0` for `ignored_too` to maintain current behavior
- The changes are mechanical plumbing updates preparing for subsequent patches that will implement the actual ignore logic

This appears to be a well-structured foundation for the series, cleanly separating the API change from the behavioral changes to come. The patch maintains backward compatibility while setting up the infrastructure needed for consistent submodule ignore handling.
