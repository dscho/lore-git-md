This is a documentation patch completing a series that makes `git add` respect the `ignore=all` submodule configuration. It updates the manual pages for both `git-add` and `gitmodules` to reflect the new behavior where `--force` is required to update submodules marked with `ignore=all`.

The changes clarify that:
1. `git add --force` now explicitly covers submodules with `ignore=all`, requiring the path to be specified
2. The `ignore=all` documentation now notes the `--force` requirement for adding submodules, and lists all commands affected by this setting (`status`, `update-index`, `diff`, and `log`)

The patch follows through on the technical changes from earlier in the series, ensuring users understand the new behavior where `ignore=all` submodules are treated consistently across commands but can still be forcibly updated when needed.
