This is the second patch in a series to make `git add` respect `ignore=all` submodule configurations consistently with other commands. The patch implements the core logic to skip submodules unless explicitly forced, building on the API changes from patch 1.

The key changes in this patch:
- Adds submodule handling to `update_callback()` in `read-cache.c`, checking for `ignore=all` configurations
- Only processes submodules when they match an explicit pathspec and `--force` is used
- Prints guidance messages similar to regular ignored files when skipping
- Maintains silent skipping behavior when no pathspec matches
- Adds trace logging for debugging the ignore logic

The implementation carefully handles edge cases:
- Verifies paths are actually directories before checking submodule status
- Safely iterates pathspecs with proper memory management
- Preserves existing error handling for non-submodule cases
- The change enables workflows where submodules can be loosely tracked without constant SHA-1 updates, similar to the repo tool's approach.

Technical considerations for future discussion:
- The patch introduces new trace messages that may need review
