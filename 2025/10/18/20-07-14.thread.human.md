This thread has finalized the implementation and documentation for making `git add` respect submodule `ignore=all` settings consistently with other Git commands. The solution requires using `--force` to stage updates to ignored submodules, matching how `git status` and `git diff` already handle this case.

The v3 patch series is now ready, with all technical and documentation aspects complete. The implementation splits plumbing from behavior changes, introduces a new `skip_submodule()` helper, and maintains the warning system while adding debug tracing. Test coverage is thorough, with a dedicated test file and updates to existing tests. The documentation has been carefully revised across three files to explain the new `--force` requirement clearly and consistently.
