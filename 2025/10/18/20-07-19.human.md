Documentation update for submodule `ignore=all` behavior with `git add --force`. This is the final patch in a series that aligns `git add`'s handling of `ignore=all` submodules with other commands like `status` and `diff`.

The patch updates two documentation files:
1. `git-add.adoc` now explicitly states that `--force` is required to update submodules when `ignore=all` is set, and that the submodule path must be specified directly.
2. `gitmodules.adoc` clarifies that while `ignore=all` prevents submodules from being considered modified, the `--force` option can override this for `git add`, similar to how it works for ignored files.

The changes complete the documentation side of the feature, matching the implementation changes from earlier patches in the series. The wording is clear and technical, accurately reflecting the new behavior where `ignore=all` submodules now require explicit `--force` to be added, just like other ignored files. This brings consistency to how Git handles ignored content across different commands.
