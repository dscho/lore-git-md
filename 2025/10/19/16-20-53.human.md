This is a bugfix patch (v3) that completes the work to make Git's dry-run diff mode truly quiet. It follows up on an earlier incomplete fix (b55e6d36eb) that silenced content comparison output but still showed file deletions, mode changes, and unmerged path notifications in dry-run mode.

The patch makes three key changes: it suppresses symbol emission in dry-run mode via `emit_diff_symbol_from_struct()`, extends quiet mode handling to external diffs in `run_external_diff()`, and prevents unmerged path notifications in `run_diff_cmd()`. The changes are well-tested with new cases in t4013-diff-various.sh that verify no output is produced for various diff operations in dry-run mode.
