Olamide Caleb Bello has been working on a two-part series to modernize SSH key handling in `gpg-interface.c` by replacing `strbuf_split*()` calls with the more appropriate `string_list_split*()` API. The change was prompted by Junio Hamano noting that `strbuf_split*()` was overkill for these read-only string splitting cases.

The first patch, now in its third version, updated `get_ssh_key_fingerprint()` to use `string_list_split_in_place()` with `STRING_LIST_INIT_NODUP`, carefully adjusting the split count check to look for ≥2 splits (yielding 3 tokens) to properly locate the fingerprint. The just-arrived second patch completes the series by converting `get_default_ssh_signing_key()` similarly, changing from checking array indices to verifying >0 splits and returning the token via the string list's items array. Both patches maintain all safety checks while using the cleaner API, with clear commit messages explaining the counting semantics difference between the old and new approaches. The series has incorporated feedback from Junio and Christian Couder along the way, resulting in a straightforward modernization that improves the code without changing behavior.
