This thread documents a focused improvement to Git's bash completion system for the `git log` and `git shortlog` commands. The patch, contributed by KIYOTA Fumiya, addresses two specific completion issues: it adds the missing `--exclude=` option to the shared completion list for both commands, and properly separates the handling of `--committer` between the commands. The latter change maintains the existing pattern-based `--committer=` for `git log` while implementing a valueless `--committer` for `git shortlog` to match its actual behavior.

Junio C Hamano reviewed the changes and suggested a minor wording adjustment to the commit message, which the author promptly incorporated in the v2 submission. The discussion revealed an underlying inconsistency in how `--committer` behaves differently between the two commands (filtering for `log` versus grouping for `shortlog`), though the patch deliberately maintains the current behavior rather than attempting to resolve this deeper design question.

The changes localized to `contrib/completion/git-completion.bash` and the patch is now ready for merging with maintainer approval, having addressed all feedback. This represents a clean, focused improvement to the completion system that better matches Git's actual command-line behavior.
