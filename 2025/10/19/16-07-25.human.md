This is a follow-up to a bash completion patch that improves `git log` and `git shortlog` tab completion. Junio C Hamano acknowledges the correctness of the original patch from KIYOTA Fumiya, which fixed two issues: adding the missing `--exclude=` option and properly separating `--committer` handling between the commands. 

Junio notes the patch's observation about the inconsistent `--committer` behavior between `git log` (which takes a pattern) and `git shortlog` (which rejects values) is particularly astute. He suggests this might indicate a broader UI inconsistency worth examining, though it's not addressed in this patch. 

The patch is being queued for inclusion, with Junio requesting a minor commit message style tweak to match project conventions (using imperative mood). The changes are localized to the completion script and maintain existing patterns while fixing the completion behavior.
