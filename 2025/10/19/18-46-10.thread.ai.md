Current behavior forces path truncation via `diff.statNameWidth` and `--stat-name-width` when paths exceed terminal width, creating workflow issues for copying long paths (e.g. Java package paths). Two initial solutions proposed: 1) extend `diff.statGraphWidth` beyond terminal width, or 2) add new config option for full path display.

Maintainer position suggests the core team may consider this adequately addressed by standard Unix mechanisms.
