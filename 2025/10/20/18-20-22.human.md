This is a build system patch that harmonizes the Makefiles for Git's credential helper utilities (libsecret and osxkeychain) with other contrib Makefiles. 

Thomas Uhle's v2 patch makes several technical improvements to the build system: it properly includes config.mak.autogen and config.mak for default settings, adds missing $(CPPFLAGS) and $(CFLAGS) to compiler/linker commands, switches to pattern rules for compilation, removes some unnecessary variable indirections, and makes the clean target verbose by removing the @ from $(RM). The changes follow the style of other contrib Makefiles like those for contacts and subtree.

The patch is a follow-up to v1, incorporating feedback to revert some variable indirections in the osxkeychain Makefile that were introduced in v1, and removing an install target that will be handled separately. The changes are straightforward build system cleanups that don't affect runtime behavior, just making the build process more consistent and maintainable. The patch appears well-considered, with clear commit messages tracking the evolution from v1.
