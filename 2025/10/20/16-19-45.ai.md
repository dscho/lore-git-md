This is a feature patch series for the experimental `git repo info` command, introducing a new `--all` flag to show all available repository metadata keys. The series consists of two patches: a preparatory refactoring followed by the main implementation.

The first patch factors out field printing logic into a dedicated function, cleaning up the code before adding new functionality. The second patch adds the `--all` flag which displays all repository metadata keys (like `layout.bare`, `object.format` etc.) when requested. The implementation handles edge cases: when combined with specific keys, it duplicates those keys in output, and maintains existing behavior for invalid keys (showing an error but still outputting valid keys).

The changes include documentation updates, test coverage for the new behaviors, and proper command-line syntax specification showing `--all` as mutually exclusive with key arguments. The commit messages are clear and credit contributors who helped shape the changes. The test suite verifies both the all-keys output and edge cases like duplicate keys and invalid key handling.

Key technical details for future reference:
- New flag: `--all` in `git repo info`
- Output behavior: shows all keys (currently 4: layout.bare, layout.shallow, object.format, references.format)
- Special case: `--all <key>` duplicates <key> in output
- Error handling: invalid keys still trigger warnings but don't prevent other output
- Internal changes: extracted `print_field()` function from `print_fields()`
- Test coverage in t1900-repo.sh verifies all behaviors
