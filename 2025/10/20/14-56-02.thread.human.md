This thread introduces configurable diff algorithm selection for `git blame`, allowing users to choose between Myers (current default), minimal, patience, and histogram algorithms. The series comes from Antonin Delpeuch and has gone through six iterations, with all review concerns addressed in the final version.

The first patch refactors xdiff internals to cleanly support algorithm selection, while the second implements the user-facing `--diff-algorithm` option and `diff.algorithm` config support in `git blame`. The implementation maintains backward compatibility while hiding the legacy `--minimal` option to avoid confusion. Comprehensive tests verify behavior across all algorithms and edge cases.

Junio Hamano and Phillip Wood provided thorough reviews throughout the process, with all technical feedback incorporated. The final version addresses last-minute style nits around test script formatting and documentation comments. With all issues resolved and maintainer approval secured, the series is now ready for merging, giving users finer control over how `git blame` computes line attribution.
