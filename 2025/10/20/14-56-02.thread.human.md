This thread introduces a new feature allowing configurable diff algorithms for `git blame`, with Antonin Delpeuch as the primary author. The series went through six iterations, incorporating feedback from both Junio C Hamano (the maintainer) and Phillip Wood (a domain expert on blame/diff behavior). The implementation consists of two patches: one refactoring xdiff internals to cleanly support algorithm selection, and another adding user-facing `--diff-algorithm` support in `git blame` that mirrors the existing `git diff` interface.

The technical work involved adding `XDF_NEED_MINIMAL` to the algorithm mask in xdiff.h, making some internal macros obsolete while maintaining backward compatibility. The test suite demonstrates practical differences in blame attribution between the Myers (current default), minimal, patience, and histogram algorithms. All substantive feedback was addressed by v6, with the final changes being purely stylistic - restoring some clarifying comments and fixing test script formatting. Both Junio and Phillip have given their final approval, indicating the series is ready for merging into the development branch. This feature will give users more control over how `git blame` attributes lines when multiple algorithms could produce different results.
