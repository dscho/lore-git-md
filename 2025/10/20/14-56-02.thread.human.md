This thread introduces configurable diff algorithms for `git blame`, allowing users to choose between Myers (current default), minimal, patience, and histogram algorithms via a new `--diff-algorithm` option or the existing `diff.algorithm` config. The series comes from Antonin Delpeuch and has gone through four iterations with thorough review from Junio C Hamano and Phillip Wood.

The implementation required refactoring xdiff internals first (patch 1) to cleanly support algorithm selection, then adding the user-facing functionality (patch 2). Key technical aspects include proper handling of the `--minimal` flag, comprehensive test coverage, and shared documentation with `git diff`. All review feedback has been addressed, including test improvements, documentation clarity, and proper separation of algorithm selection from minimal flag behavior.

The series is now feature-complete with consensus on the technical approach. Junio and Phillip have signed off on the implementation after multiple rounds of review, with the final version addressing all remaining concerns about xdiff library impacts and test coverage. The patches are ready for merging pending final maintainer review.
