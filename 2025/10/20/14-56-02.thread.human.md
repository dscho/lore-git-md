Antonin Delpeuch's series to make `git blame`'s diff algorithm configurable is nearing completion after three rounds of review. The patches now allow selecting between Myers (current default), minimal, patience, and histogram algorithms via both a new `--diff-algorithm` option and the existing `diff.algorithm` config. Junio Hamano and Phillip Wood have provided thorough reviews, with all major technical concerns addressed in v3 iteration.

The implementation cleanly separates algorithm selection from the `--minimal` flag while maintaining CLI/config precedence rules. Test coverage in t8015 is comprehensive, verifying default behavior, option interactions, and edge cases. Documentation shares the existing diff-algorithm description via includes.

In the latest exchange, Antonin and Phillip are finalizing the handling of diff flags, particularly how `XDF_NEED_MINIMAL` interacts with algorithm selection. They're considering whether to add the minimal flag to the algorithm mask (which might simplify some code but risk breaking xdiff users) or introduce a dedicated clearing macro. This represents one of just two remaining polish items - the other being restoration of `--no-minimal` behavior - before the series can be merged. With maintainer confirmation that these are the final changes needed, the feature appears ready for inclusion in an upcoming release.
