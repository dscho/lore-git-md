This is the second patch in a two-part series adding an `--all` flag to the experimental `git repo info` command. Building on the preparatory refactoring in patch 1/2, this implements the actual `--all` functionality to display all available repository metadata keys.

The patch adds a new `print_all_fields()` function that iterates through all defined repository metadata fields (layout.bare, layout.shallow, object.format, references.format) and prints them using the existing format handling. The implementation maintains consistency with the command's existing behavior - when combined with specific key arguments, `--all` will duplicate those keys in the output, and invalid keys trigger warnings without preventing other output.

Documentation updates clarify that `--all` is mutually exclusive with key arguments in the command syntax. The test suite verifies several scenarios: basic all-keys output, duplicate key handling with `--all`, and proper warning behavior for invalid keys while still producing valid output. The implementation appears cleanly integrated with the existing codebase, leveraging the refactored `print_field()` function from the first patch.

This completes the series' goal of providing a convenient way to view all repository metadata without needing to know specific key names in advance. The change is well-tested and maintains backward compatibility with existing usage patterns.
