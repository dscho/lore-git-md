Feature patch adding diff algorithm configurability to `git blame`. This allows users to select between Myers (current default), minimal, patience, and histogram diff algorithms via both a new `--diff-algorithm` option and the existing `diff.algorithm` config setting. The change follows the pattern established by other Git commands like `git diff`.

The patch is motivated by ongoing discussions about potentially changing Git's default diff algorithm to histogram in the future (referencing a 2021 thread). The author notes this could significantly impact blame output and wants to ensure configurability is available first. The implementation adds documentation and handles both command-line and config options, with special consideration given to the porcelain output mode's potential need to ignore UI config settings.

Key technical details:
- Adds `--diff-algorithm` option with same values as `git diff`
- Honors `diff.algorithm` config except possibly in porcelain mode (left as open question)
- Modifies `xdl_opts` bitmask to handle algorithm selection
- Follows existing pattern from `git diff` for option parsing
- Touches `builtin/blame.c` and `Documentation/git-blame.adoc`

The patch appears well-constructed with clear motivation and implementation. The author acknowledges needing to add tests if the approach is accepted. The porcelain mode behavior question suggests this may spark some discussion about config handling in plumbing-like outputs.
