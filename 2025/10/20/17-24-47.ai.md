This is a test fix for Windows path handling in the `:(optional)` prefix series. Johannes Sixt clarifies and expands on his earlier explanation about Windows path translation issues in the test suite, specifically around the `:(optional)` prefix implementation.

The key points are that while tests using absolute paths like `/c/dir/template` have worked accidentally since 2007 (by being translated to `C:/dir/template`), they become conceptually incorrect when combined with the new `:(optional)` prefix. The MSYS layer fails to properly translate paths when they follow this prefix marker. 

Sixt explains that existing tests didn't catch this because they all expected the paths to not exist anyway. The new test case that expects a file to exist would fail without the fix, which replaces `$PWD` with `$(pwd)` for proper Windows path translation. He advocates for using `$(pwd)` consistently throughout the test file for better reliability, noting that while the remaining tests could keep using `$PWD`, the change makes the test suite more uniform.
