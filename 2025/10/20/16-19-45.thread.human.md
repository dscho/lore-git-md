This thread introduces a new `--all` flag for the experimental `git repo info` command, making it easier to view all available repository metadata without needing to know specific key names. The series consists of two patches: first, a preparatory refactoring that extracted field printing logic into a shared `print_field()` function, and second, the main implementation adding the `--all` flag functionality.

The implementation displays four metadata keys by default: layout.bare, layout.shallow, object.format, and references.format. It maintains the command's existing behavior patterns - combining `--all` with specific key arguments will show duplicates in the output, and invalid keys trigger warnings without blocking valid output. The test suite thoroughly verifies these behaviors, including edge cases. Documentation updates clarify that `--all` is meant to be used alone, though the implementation gracefully handles mixed usage.

The change appears well-considered, building on solid preparatory refactoring and maintaining backward compatibility. The series achieves its goal of providing a more convenient way to inspect repository metadata while preserving the command's existing functionality and test coverage.
