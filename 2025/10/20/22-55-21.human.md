This is the second part of a refactoring series simplifying strbuf usage in gpg-interface.c, following up on work identified by Junio Hamano. The patch focuses on `get_default_ssh_signing_key()`, which previously used `strbuf_split_max()` to extract the first line of output from a needlessly complex approach since it wasn't actually using strbuf features.

The change replaces the strbuf splitting with direct string manipulation using `strchr()` to find the newline and `xmemdupz()` to copy the first line. This maintains all the existing security checks via `is_literal_ssh_key()` while simplifying the memory management. The error handling and warning messages remain functionally identical.

This appears to be a well-considered change that follows the pattern established in the first patch of the series (which modified `get_ssh_key_fingerprint()` similarly) and aligns with the broader effort to remove unnecessary strbuf operations. The patch has benefited from review by both Junio Hamano and Christian Couder across multiple iterations.
