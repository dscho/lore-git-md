Test infrastructure patch that fixes an issue with shared test scripts. This is the third and final patch in Patrick Steinhardt's refactoring series to consolidate refs optimization code paths.

The patch addresses a problem introduced in an earlier refactoring where the `test_done` directive was incorrectly placed in the shared test script `t/pack-refs-tests.sh`. This prevented additional tests from being added to the individual test files (`t0601-reffiles-pack-refs.sh` and `t1463-refs-optimize.sh`) that include this shared script. The fix moves the `test_done` directive back to the individual test files while keeping all the actual test cases in the shared script.

The change is straightforward and mechanical - it removes `test_done` from the shared script and adds it to both of the including test files. This maintains the ability to share test cases while allowing each test file to add its own additional tests. The patch is small (4 lines added, 2 removed across 3 files) and clearly explained in the commit message.
