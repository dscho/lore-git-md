This is a build system patch that harmonizes the Makefiles for Git's credential helper utilities (libsecret and osxkeychain) with other contrib Makefiles. It's the second version of a patch that follows up on feedback from the initial submission.

The changes standardize the Makefiles by:
1. Properly including config.mak.autogen and config.mak before setting defaults
2. Adding missing $(CPPFLAGS) to compilation and $(CFLAGS) to linking
3. Using pattern rule for compilation instead of per-file rules
4. Removing intermediate variables $(MAIN), $(SRCS), $(OBJS) in favor of direct filenames
5. Making clean targets verbose by removing the @ from $(RM)
6. Adding .PHONY declarations for special targets

The v2 changes revert some osxkeychain Makefile changes from v1 that had introduced variable indirection, and removes the install target to be handled in a separate patch as requested. The patch affects two files: contrib/credential/libsecret/Makefile and contrib/credential/osxkeychain/Makefile.

This appears to be a straightforward quality-of-life improvement for maintainers, bringing consistency to the build system without changing functionality. The changes align with established patterns seen in other contrib/ Makefiles. The patch is focused and well-explained, with clear version-to-version changes documented in the commit message.
