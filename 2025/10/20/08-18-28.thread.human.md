This thread introduces a refactoring series that cleans up the refs optimization code, following the recent addition of `git refs optimize` functionality (db0babf9b2). The series consolidates duplicate code paths by removing the older `pack_refs` functions in favor of the newer, more generic `optimize` variants across the refs subsystem. The changes are purely mechanical renames and deletions with no behavior changes.

The patches remove `pack_refs_fn` and `pack_refs` from the `ref_storage_be` struct, rename `pack_refs_opts` to `refs_optimize_opts` (with corresponding flag renames), and update all backend implementations (files, packed, reftable) to use only the optimize interface. The series builds on master (143f58ef75) with 'ps/ref-peeled-tags' merged in. Version 2 squashes some commits and improves variable naming consistency. Given the straightforward nature of these internal cleanups, the changes are unlikely to be controversial.
