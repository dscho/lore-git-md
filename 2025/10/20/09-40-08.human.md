This is a test fix addressing Windows platform compatibility in the ongoing `:(optional)` file prefix series. Johannes Sixt points out that tests using `$PWD` to construct absolute paths for optional file specifications don't work correctly on Windows due to MSYS path translation quirks. The patch replaces `$PWD` with `$(pwd)` to ensure proper path handling across platforms.

The change affects several test cases in t7500 that verify Git's handling of optional template files, both via command line and config. The key addition is a new test case that specifically checks the happy path where an optional template file exists, which helps validate the Windows path handling. All changes are focused on test correctness without modifying the actual `:(optional)` implementation.

This appears to be a straightforward improvement to the test suite, catching a Windows-specific edge case in the test infrastructure rather than the feature itself. The patch maintains the same test coverage while making it more robust across platforms. It's a focused change that aligns well with the broader series' goal of cross-platform optional file handling.
