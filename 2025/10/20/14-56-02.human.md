Feature patch adding diff algorithm configurability to `git blame`.

Antonin Delpeuch proposes making `git blame` respect the `--diff-algorithm` option and `diff.algorithm` config setting, following the pattern established by other Git commands like `git diff`. The patch adds documentation for the new option and implements the callback to handle it, while maintaining Myers diff as the default algorithm.

The commit message notes this is preparatory work for a potential future change of the default algorithm to "histogram" (referencing a 2021 discussion). The author raises an interesting question about whether the porcelain output format should respect UI config settings like `diff.algorithm`, drawing a parallel to how `git merge-file` behaves differently as a plumbing command.

The implementation appears straightforward, adding about 40 lines of code to handle the new option and config. The author offers to add tests if the general approach is accepted. This seems like a sensible quality-of-life improvement that gives users more control over blame output, particularly since different diff algorithms can produce meaningfully different attribution results.
