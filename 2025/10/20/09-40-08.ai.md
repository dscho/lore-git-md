This is a platform compatibility patch fixing Windows-specific test behavior in the `:(optional)` pathname handling series.

Johannes Sixt identifies an issue where Windows path translation breaks when absolute paths are prefixed with `:(optional)` in the test suite. The MSYS layer normally converts POSIX-style paths like `/c/dir/file` to Windows-style `C:/dir/file`, but this translation fails when the path is preceded by the optional prefix. The existing tests coincidentally pass because they check for non-existent files, but the underlying path handling is incorrect.

The patch makes two key changes: First, it replaces all `$PWD` usage with `$(pwd)` in the test file to generate proper Windows-style paths from the start. Second, it adds a new test case that verifies correct handling of an *existing* template file marked as optional, which would fail with the old path handling. The changes are confined to t/t7500-commit-template-squash-signoff.sh.

This addresses a subtle platform-specific edge case in the otherwise complete `:(optional)` implementation. The fix maintains the series' cross-platform compatibility while properly exercising the Windows path translation behavior. The patch is narrowly focused and follows the established pattern of the test file, though it does highlight that the original tests were accidentally correct rather than intentionally designed to handle Windows paths properly.
