This is a test fix addressing Windows path handling in the `:(optional)` prefix series. Johannes Sixt clarifies and expands on his earlier explanation about Windows path translation issues in the test suite.

The key points are:
1. The existing tests using absolute paths` like `/c/dir/template` worked accidentally since 2007 because they were isolated arguments that MSYS could translate to Windows paths.
2. With the new `:(optional)` prefix, MSYS fails to translate paths when they're prefixed, making the tests conceptually wrong even if they still pass.
3. The fix replaces `$PWD` with `$(pwd)` in the test script to ensure proper path translation, particularly for a new test case that expects a file to exist.

Johannes notes this isn't as severe as it first appeared - the tests were only "wrong in spirit" when combined with the new prefix feature. The change makes the tests more robust and consistent while properly supporting the new optional file handling on Windows.

This patch follows up on earlier Windows-specific fixes in the series and has been reviewed by Junio Hamano, who was surprised the issue went unnoticed for so long. The change helps ensure the `:(optional)` feature works reliably across platforms.
