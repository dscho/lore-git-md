This thread focuses on optimizing string handling in gpg-interface.c by replacing unnecessary strbuf operations with simpler string parsing. The work originated from Junio Hamano's observation that strbuf_split*() calls were being used in cases where simpler string manipulation would suffice.

The v4 patch series now contains two key changes: the first patch refactored `get_ssh_key_fingerprint()` to use strchr() and xmemdupz() instead of strbuf_split_max(), while this new second patch completes the work by applying the same pattern to `get_default_ssh_signing_key()`. Both changes maintain all security checks through is_literal_ssh_key() while simplifying memory management. The approach follows patterns previously established in wt-status.c.

Christian Couder provided input on earlier iterations, and the author has refined the approach through multiple versions (v3 used string_list_split_in_place() before settling on the current simpler solution). With both patches now submitted, the strbuf optimization work in gpg-interface.c appears complete, achieving the original goal of removing unnecessary overhead while preserving all safety checks and error handling.
