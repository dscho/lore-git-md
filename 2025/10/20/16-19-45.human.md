Feature addition to the experimental `git repo info` command. This two-patch series introduces a new `--all` flag to display all available repository metadata keys and their values, with the option to duplicate specific keys when provided as arguments.

The main changes in v2 include:
1. A new preparatory patch that factors out field printing logic into a dedicated function (suggested by reviewers)
2. Improved documentation clarifying that requested keys after `--all` will be duplicated in output
3. Additional test coverage for the new behavior, including handling of invalid keys

The implementation appears clean and well-tested, with clear commit messages and reviewer acknowledgments. The changes follow the pattern of existing code while making it more maintainable. This continues work on the experimental `git repo` command, which provides structured access to repository metadata.
