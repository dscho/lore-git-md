This is a test fix addressing Windows path handling in the `:(optional)` file prefix series.

Junio Hamano acknowledges Johannes Sixt's discovery of long-standing test issues in t7500 that incorrectly assumed absolute paths would work with the `:(optional)` prefix on Windows. The tests have been passing by coincidence (since Git couldn't find the specified files anyway), but the test design was conceptually flawed. The oldest affected test dates back to 2007, having gone unnoticed until now.

The email shows maintainer approval ("will queue") for Sixt's fix, which comes as part of the broader effort to properly handle optional files across platforms. This follows earlier Windows-specific fixes in the series where `$PWD` was replaced with `$(pwd)` for reliable path handling. The patch appears well-justified and builds on the thread's established pattern of improving cross-platform test reliability.
