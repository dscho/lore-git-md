Refactoring patch simplifying SSH fingerprint parsing in gpg-interface.c, part of an ongoing series to remove unnecessary strbuf usage. This is the first of two patches in v4 of the series, continuing work started by Junio Hamano to replace strbuf operations with simpler string parsing where appropriate.

The patch modifies `get_ssh_key_fingerprint()` to replace a `strbuf_split_max()` call with direct string manipulation using `strchr()` and `xmemdupz()`. The original code splits the SSH key fingerprint output into strbufs but only uses them as simple strings, making the strbuf overhead unnecessary. The new version more directly extracts the fingerprint token between spaces.

This change follows the pattern established in prior cleanup work (notably in wt-status.c) and represents a further simplification from earlier versions of the series that used `string_list_split_in_place()`. The patch maintains all existing security checks and error handling while reducing memory allocations and strbuf operations.
