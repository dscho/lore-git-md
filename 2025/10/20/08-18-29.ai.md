Refactoring patch consolidating refs optimization code paths, part of a v2 series to remove redundant `pack_refs` functions in favor of the more generic `optimize` interface.

This first patch removes the `pack_refs` function pointer from the `ref_storage_be` struct and updates all ref backends (files, packed, reftable) to exclusively use the `optimize` callback. The changes are mechanical:
- Deletes `pack_refs_fn` typedef and removes `pack_refs` from backend structs
- Updates debug backend to use `optimize` naming consistently
- Removes redundant wrapper functions where `optimize` was just calling `pack_refs`
- Keeps identical functionality while simplifying the codebase

The patch builds on previous work that introduced the `optimize` interface (db0babf9b2) and is part of ongoing ref backend abstraction efforts. Since all callers already use `optimize`, there are no external behavior changes. The changes touch core refs infrastructure files but are straightforward removals of now-unused code paths.
