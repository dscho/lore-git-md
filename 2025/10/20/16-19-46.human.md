Refactoring patch for the experimental `git repo info` command.

This is the first of two patches preparing for a new `--all` flag in `git repo info`. Lucas Seiki Oshiro extracts the field printing logic from `print_fields()` into a new `print_field()` function, making the code more modular and reusable. The change is purely structural - no behavior is altered. The refactoring will allow the upcoming second patch to reuse this printing logic when implementing the `--all` flag functionality.

The patch is straightforward, moving the printing implementation into a new function while maintaining the same output formats (key-value pairs and NUL-terminated). The diff shows clean extraction with no functional changes, just moving code into the new helper function while updating the original function to call it. This appears to be a well-scoped preparatory change for the feature addition coming in the next patch.
