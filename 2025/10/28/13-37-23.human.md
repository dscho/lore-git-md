Feature patch adding diff algorithm configurability to `git blame`. This is version 2 of the patch, responding to previous technical reviews from Junio Hamano and Phillip Wood.

The patch makes `git blame` respect both the `--diff-algorithm` option and `diff.algorithm` config setting, matching behavior already present in `git diff`. Myers remains the default algorithm. The changes include:

1. Added tests verifying the new functionality
2. Fixed interaction between `--diff-algorithm` and `--minimal` flags
3. Improved documentation by consolidating diff algorithm descriptions into a shared include file
4. Various style improvements based on review feedback

The implementation follows the same pattern used in `git diff`, with the diff algorithm selection modifying the `xdl_opts` bitmask. The patch touches `builtin/blame.c` for the core and adds a new test file.

This appears to be a well-considered addition that aligns with Git's existing diff algorithm handling. The author has addressed the technical feedback from the first round, though some test cases appear to be commented out (marked with "goo") and may need final verification before merging. The change positions `git blame` for a potential future default algorithm change to histogram diff.
