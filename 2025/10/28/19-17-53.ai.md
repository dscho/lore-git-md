This is a CI infrastructure patch in the ongoing cbindgen/Rust integration series. The patch switches 32-bit CI testing from the now-EOL Ubuntu image to Debian, which still maintains 32-bit support. The changes update both GitHub Actions and GitLab CI configurations, along with related dependency installation scripts.

The technical changes are straightforward: replacing `i386/ubuntu` references with `i386/debian` across multiple files, and adjusting the package installation logic to use `locales-all` instead of `language-pack-is` for the Debian image. The patch has already been acked by Ezekiel Newren, who notes it looks good but muses about whether testing additional 32-bit distros might be worthwhile (without making it a blocking suggestion).

This is part of the broader CI preparation work needed for the Rust/cbindgen integration, specifically addressing platform compatibility concerns that were previously raised. The change ensures continued 32-bit testing capability while maintaining package availability for upcoming Rust-related dependencies. The patch appears uncontroversial and well-contained, with all necessary configuration updates included.
