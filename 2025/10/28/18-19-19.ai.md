Documentation patch fixing AsciiDoc markup in git-checkout documentation. This is a follow-up to commit 042d6f34 ("doc: git-checkout: clarify `-b` and `-B`") that landed in master.

The patch corrects the markup for placeholders in the git-checkout manpage, changing from backticks to underscores for branch name placeholders. The author explains that backticks trigger HTML `<code>` formatting for the underscores, which was likely unintended in the original commit. The change affects two instances where branch placeholders were incorrectly marked up.

The patch has gone through two versions, with v2 adding an Acked-by from Julia Evans. The author notes they considered removing "probably" from the commit message description of the original issue as a point-in-time note, but kept it since the message plus ack makes the intention clear. The patch is now being resent as a separate thread after previously being part of another series.

The change is straightforward and non-controversial, fixing a clear documentation formatting issue. The patch is small (4 lines changed) and focused, with the commit message providing adequate context about the problem and solution. The Acked-by suggests the change has already received some review approval.
