Refactoring patch in the packfile store abstraction series. This is the second of eight patches moving packfile management from global structures to per-object-source ownership.

The patch relocates the Most Recently Used (MRU) packfile list from `struct packed_git` to `struct packfile_store`, introducing a new `packfile_list` helper structure to manage the list. This is part of the larger effort to prepare for pluggable object databases, where packfiles should be owned by individual object sources rather than existing as global lists.

Key changes include:
- New `packfile_list` struct with append/prepend/remove operations
- Removal of the MRU list from `packed_git`
- Updates to all MRU list operations to use the new structure
- Modified packfile lookup logic in several core functions

The changes are mechanical and maintain existing behavior while moving toward the architectural goal. The patch appears well-contained, touching packfile.c/h and related consumers like midx.c and pack-objects.c. It follows cleanly from the first patch's strmap conversion and sets up for subsequent patches that will continue moving packfile management into the store.
