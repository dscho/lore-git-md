This thread covers an 8-part series refactoring Git's packfile subsystem as part of the ongoing packfile store abstraction effort, with additional discussion around a MIDX object counting bugfix. The work standardizes packfile management while preparing for future integration with the object source layer.

Taylor Blau has been the primary reviewer, providing detailed feedback throughout. He approved the first patch (replacing a custom hashmap with `strmap`) without changes, sought clarification on alternates handling in patch 2 (resolved by Patrick Steinhardt), and suggested optimizations for the MIDX object count fix. Toon Claes raised API design questions about `packfile_list_find_oid()` that remain open.

The latest discussion focuses on patch 7/8, which standardizes MRU list management. While Patrick's patch makes immediate MRU addition consistent across subsystems, Taylor notes the long-term direction might favor adding packs only after successful object lookups. However, he acknowledges the current approach makes sense as an interim solution. The series demonstrates careful progress toward simplifying packfile management while maintaining functionality, with only minor design questions remaining about MRU strategy. All changes target Git v2.51.2 and maintain behavioral compatibility.
