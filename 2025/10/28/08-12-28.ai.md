This is a refactoring patch that simplifies SSH fingerprint parsing in the GPG interface code. It's the first of five patches in Christian Couder's series combining code cleanups with translation work.

The patch focuses on `parse_ssh_output()` in gpg-interface.c, which processes output from `ssh-keygen` verification commands. The change eliminates a redundant `strstr()` call when setting the `fingerprint` field of a `signature_check` struct. The function was needlessly recomputing the "key " substring position that was already available in a local variable.

This is a straightforward optimization that doesn't change behavior - it removes duplicate work by reusing the existing `key` pointer rather than searching the string again. The patch is small (just 1 line changed) and appears well-contained, touching only the fingerprint assignment logic while leaving the surrounding error handling and other field assignments unchanged.

The change aligns with the series' broader cleanup goals, resurrecting previously dropped improvements to GPG/SSH interface code. As noted in the thread context, these changes stand independently from the later translation-focused patches in the series.
