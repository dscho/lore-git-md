Christian Couder has sent a patch series combining code cleanups with internationalization work in Git's fast-import/export and GPG interface components. The first patch simplifies SSH fingerprint parsing by removing a redundant string search in the GPG interface code - a small but clear optimization that reuses an existing pointer rather than recomputing the same substring position.

The series revives two previously dropped cleanup patches (including this one) alongside extensive translation work marking over 300 strings for i18n in fast-import and fast-export. While the build currently passes, there may be edge cases to verify in the fast-import message conversions. This initial version hasn't yet received review feedback, but the changes appear focused - the GPG interface cleanups stand independently from the later translation work, which connects to broader project internationalization efforts.
