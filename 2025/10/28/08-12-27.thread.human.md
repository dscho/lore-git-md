This thread centers on Christian Couder's patch series to clean up and internationalize error messages in Git's fast-export, fast-import, and gpg-interface components. The six-part series revives some previously dropped cleanup patches while marking hundreds of error and warning messages for translation - completing internationalization support in these areas.

Junio C Hamano has reviewed most of the series, approving the technical approach while suggesting minor style improvements. A key discussion point was whether to standardize capitalization of "Unknown"/"Unexpected" strings in fast-export error messages as part of this work. Christian initially considered doing this separately, but Junio has now clarified that such mechanical style changes fit well within the current patch's scope, provided they remain simple. This resolves the last open question about the fast-export translations.

The series appears ready for merging once these final tweaks are incorporated. Christian's work builds on broader internationalization efforts led by Jean-Noël Avila and Jiang Xin, while also including some standalone code cleanups to GPG/SSH interface code. With Junio's approval of the core approach and only minor editorial decisions remaining, this translation work should soon be complete.
