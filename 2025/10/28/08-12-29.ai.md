This is a refactoring patch in a series combining code cleanups and translation work. It modifies the gpg-interface component to use bitwise left shift operations for defining boolean flags, following a common Git code style pattern.

This makes it clearer that these are bit flags while maintaining identical runtime behavior. The author also fixes minor indentation in the process.
