Platform compatibility bug report for NonStop systems. Randall Becker reports test failures in Git v2.51.2 when building with OpenSSL 3.5, specifically in t7900 (maintenance tests) related to `test_subcommand` assertions. The failures occur when testing `git gc` invocations, with one case failing due to a missing argument in the test harness when checking for the absence of an auto-gc command. The error suggests the test infrastructure may not properly handle negated assertions (`test_subcommand !`) on this platform. The report notes these issues were not present in v2.51.1, implying a regression, though the OpenSSL version change may be coincidental. The failure mode points to platform-specific shell behavior differences in bash 5.0.18 regarding test command parsing. This appears to be a test suite rather than core functionality issue, but one that could mask real problems if left unfixed.
