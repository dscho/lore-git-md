This is a CI infrastructure patch in the ongoing cbindgen/Rust integration series. Ezekiel Newren is responding to Patrick Steinhardt's patch that switches the 32-bit CI testing platform from the now-deprecated Ubuntu image to Debian.

The original patch makes a straightforward change - replacing the EOL Ubuntu 32-bit image with Debian's maintained 32-bit port. It updates the CI configuration files (.github/workflows/main.yml, .gitlab-ci.yml) and related scripts (ci/install-dependencies.sh, ci/lib.sh) to handle the new platform, including changing the language pack from `language-pack-is` to `locales-all` for Debian.

Newren ack's the change ("Makes sense to me") but raises an open-ended thought about whether other 32-bit Linux distros should also be tested. This isn't a blocking concern or request for changes - just a consideration for future testing coverage. The patch itself appears ready to go as-is, addressing the immediate need to move away from the unsupported Ubuntu image.

The change is part of broader CI improvements supporting the Rust integration work, where having reliable 32-bit testing is important for compatibility verification. The patch is well-contained and follows the pattern of other recent CI updates in the series.
