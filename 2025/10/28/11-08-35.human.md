Refactoring patch in the packfile store abstraction series. This is patch 5/8 in Patrick Steinhardt's series to modernize Git's packfile management.

The patch simplifies the logic in `has_sha1_pack_kept_or_nonlocal()`, which checks if an object exists in kept or non-local packs. The current implementation intertwines pack iteration with a performance optimization that caches the last found object's pack, making the code hard to follow. 

The refactoring separates these concerns by first checking the cached pack (if any) before entering the main iteration loop. This makes the control flow more straightforward while maintaining the same behavior. The change reduces the function's complexity by eliminating the need to restart iteration when the cached pack doesn't contain the object, and makes the caching mechanism more obvious.

This continues the series' pattern of cleaning up packfile management code while preserving functionality. The change is focused on `builtin/pack-objects.c` and while not fixing any bugs, it improves maintainability of code that's important for pack operations. The diff shows a net reduction of 13 lines with clearer logic.
