Feature patch adding diff algorithm configurability to `git blame`. This v3 iteration from Antonin Delpeuch addresses all previous technical feedback and is now in final polishing stage before potential merge.

The patch makes `git blame` respect both the `--diff-algorithm` command-line option and `diff.algorithm` config setting, while maintaining Myers as the default algorithm. Key improvements in this version include:

1. Enhanced test coverage that now properly verifies:
   - Command-line vs config precedence
   - Interaction between `--diff-algorithm` and `--minimal` flags
   - More robust output verification with full line context

2. Cleaner implementation that properly separates algorithm selection from minimal flag handling via dedicated callback functions.

3. Documentation sharing via a new `diff-algorithm-option.adoc` include file used by both `git-blame` and `git-diff` manpages.

The implementation follows Git conventions closely, with maintainer Junio Hamano having confirmed the technical soundness in previous reviews. The only remaining minor issue is a duplicate `OPT_BIT()` for `--minimal` flagged for future cleanup.

This appears merge-ready pending final test improvements mentioned in the follow-up. The change is well-motivated as preparation for a potential future default algorithm change to "histogram" diff.
