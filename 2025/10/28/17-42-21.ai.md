Build system integration discussion in the SHA-1/SHA-256 interoperability series. This email from Ezekiel Newren responds to Patrick Steinhardt's review of patch 10/14, which adds a Rust build script for tests.

The discussion focuses on two build system issues: circular dependencies between Rust and C libraries, and proper library linking handling. Patrick had noted that the separate xdiff and reftable libraries referenced in the Makefile changes have since been removed. He also raised concerns about circular dependencies between Rust and C libraries, particularly regarding Meson integration, and questioned how the build script ensures correct library linking precedence (especially for libz).

Ezekiel references his own prior work on Rust integration to address these concerns. He explains his solution using the `USE_LINKING` environment variable to control when linking occurs - disabled during Makefile/Meson builds but enabled for direct `cargo test` invocations. This approach prevents circular dependencies while still allowing test execution.
