Feature patch adding diff algorithm configurability to `git blame`, now at version 3. This iteration incorporates all prior feedback and adds enhanced test coverage for the previously identified edge cases.

The patch makes `git blame` respect both the `--diff-algorithm` command-line option and `diff.algorithm` config setting, with command-line taking precedence. It maintains Myers as the default while supporting all standard diff algorithms (minimal, patience, histogram). Key technical changes include:

- New callback functions `blame_diff_algorithm_minimal()` and `blame_diff_algorithm_callback()` for proper option handling
- Config parsing via `parse_algorithm_value()` with error checking
- Bitmask operations to handle algorithm selection and minimal flag interaction
- Comprehensive new test script `t8015-blame-diff-algorithm.sh` covering:
  - Default behavior
  - Command-line algorithm selection
  - Config-based algorithm selection
  - Precedence rules (CLI > config)
  - Interaction with existing `--minimal` flag
  - Option ordering effects
