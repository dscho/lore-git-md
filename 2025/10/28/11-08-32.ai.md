Refactoring patch in the packfile store abstraction series, moving MRU list management into the packfile store.

This second patch in the 8-part series relocates the Most Recently Used (MRU) packfile list from `struct packed_git` to `struct packfile_store`. The change introduces a new `struct packfile_list` to manage packfile ordering, with supporting functions for list manipulation (clear, remove, prepend, append). 

Key technical changes:
- Removes `mru` list from `struct packed_git`
- Adds `struct packfile_list` with head/tail pointers and entry structs
- Implements list management functions in packfile.c
- Updates all MRU list access points to use new API
- Modifies pack-objects.c, midx.c, and packfile.c to use new list structure
- The MRU list is now owned by the packfile store rather than being global
- Maintains same MRU ordering behavior during object lookups
- Prepares for future per-object-source packfile management

The patch continues the series' pattern of moving global packfile management into the packfile store, with this change focusing specifically on the MRU ordering used during object lookups. It builds on the strmap conversion from patch 1 while maintaining identical functionality. The implementation appears thorough with comprehensive updates to all affected code paths.
