This is part of the ongoing SHA-1/SHA-256 interoperability work introducing Rust code to Git. Patch 11/14 focuses on implementing object hashing functionality in Rust.

Patrick Steinhardt provides detailed review feedback on brian m. carlson's implementation of a Rust `Hasher` struct that wraps Git's hash functions. The key points under discussion are:

1. The distinction between "safe" and "unsafe" hashing in the implementation is questioned - Patrick suggests dropping this distinction until there's a concrete need for it.

2. Several technical improvements are noted:
   - Missing documentation for the `Hasher` struct
   - Suggestion to expose a combined `git_hash_new()` instead of separate alloc/init functions
   - General approval of the `Write` trait implementation and memory management via `Clone`/`Drop`

The implementation appears solid overall, with some minor refinements needed around API design and documentation. This continues the careful, detailed review pattern seen throughout this series, with Patrick providing focused technical feedback while the core approach remains uncontested. The patch moves forward the Rust infrastructure needed for the new loose object format.
