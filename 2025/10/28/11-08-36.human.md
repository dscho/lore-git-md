This is part 6 of an 8-part refactoring series modernizing Git's packfile management infrastructure. The patch moves the main list of packfiles into the new `packfile_store` structure, continuing the series' pattern of consolidating packfile-related state.

The changes replace direct linked-list manipulation with the new `packfile_list` API introduced earlier in the series. Key modifications include:
- Converting all packfile iteration to use `packfile_list_entry` structs
- Updating sort and MRU preparation logic to work with the new list type
- Removing the now-unused `find_oid_pack()` helper
- Adjusting `fast-import.c` to use the new API

The patch maintains existing behavior while making the code more maintainable. It follows the series' incremental approach - this change builds on the MRU list migration from patch 2 and prepares for the final consolidation in patch 8. The diff shows thorough updates across packfile.c, with particular attention to window scanning and pack closing logic.

This continues the systematic modernization of packfile management that has been well-received in previous patches. The changes are mechanical but important for the series' goal of unifying packfile tracking under the store abstraction.
