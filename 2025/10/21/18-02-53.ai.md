This is a documentation and test update patch for the interactive add (`git add -p`) functionality. The patch improves the visibility and documentation of the 'P' option, which prints the current hunk using the pager.

The changes include:
1. Adding explicit documentation for the 'P' option in `git-add.adoc, showing it as a distinct choice from 'p' (which prints without pager)
2. Splitting the combined "p/P" help text in add-patch.c into two distinct lines for clarity
3. Updating numerous test cases in t/t3701-add-interactive.sh to include 'P' in the expected prompt strings, showing it as an available option alongside 'p'

The patch is straightforward and mechanical, updating all relevant test expectations to match the new documentation. The changes are consistent and well-contained, focusing solely on improving the visibility of an existing but under-documented feature. The test updates are thorough, covering various interactive add scenarios including hunk navigation, color output, and error cases.

This appears to be a quality-of-life improvement for users of interactive add, making the pager option more discoverable through both documentation and in-application help. The patch maintains backward compatibility of the existing 'p' behavior while properly documenting the alternative 'P' variant.
