This is part 5/7 of the `git repo structure` series, adding object counting functionality to the new repository analysis tool. The patch extends the existing reference counting with reachable object enumeration by type (commits, trees, blobs, and tags).

The implementation uses Git's path-walk API to traverse all objects reachable from references, counting them by type. The counts are displayed in the reference statistics table introduced in earlier patches, maintaining the same structured output format. The patch includes tests verifying both empty repositories and repositories with objects, showing the expected breakdown of object types.

The implementation is thorough, handling the object walk efficiently while reusing the reference iteration already in place. It maintains the internationalization support and table formatting established in previous patches. The test coverage is comprehensive, checking both the empty case and a populated repository with a known number of objects.

This continues the series' trend of well-structured, incremental additions to the repository analysis tool, with clear documentation and testing. The object counting provides valuable additional insight into repository composition that complements the reference statistics.
