This is a bugfix patch in the geometric repacking series that improves error handling for invalid maintenance strategies. The patch makes Git fail explicitly when encountering an unknown maintenance strategy configuration, rather than silently falling back to a no-op behavior.

The change addresses a discoverability issue where users might unknowingly configure an invalid strategy and have their maintenance tasks silently do nothing. The patch introduces a new `parse_maintenance_strategy()` helper function that validates the strategy name and dies with an error message if it's unrecognized. This function is then used in place of the previous silent fallback logic.

The patch includes a new test case that verifies the error behavior when an invalid strategy is configured. This is part of a larger series (v2 5/9) introducing configurable geometric repacking strategies, with this particular change focusing on making the configuration interface more robust and user-friendly.

The change is straightforward and well-contained, with clear test coverage for the new behavior. It follows the pattern of the series by improving the maintenance infrastructure while maintaining backward compatibility with existing valid configurations.
