Git notes show exit code anomaly on NonStop platform. Thread investigates unexpected exit code -12 (037777777764 octal) from `git notes show HEAD` after adding a note, observed on Git 2.51.0 running on big endian x86 NonStop architecture. Randall Becker (NonStop port maintainer) confirms this is specifically about process exit codes, not shell tab completion, and provides new details about bash truncating the negative exit code to 0xFF (interpreted as 0), masking the actual error. Original reporter verified behavior in gdb and created a standalone test program using !!fn construct, but root cause remains unidentified. Current understanding suggests the issue involves low-level process exit handling or integer representation differences specific to this platform, isolated to the notes subsystem's exit code behavior. Key tracking details: affected command (`git notes show`), exact exit code (-12/037777777764), NonStop big endian context, Git version 2.51.0, bash truncation behavior (0xFF mask), unsuccessful debugging attempts via gdb and standalone test. No other Git commands exhibit similar exit code anomalies. Problem remains unsolved but clearly scoped to platform-specific exit code handling in notes subsystem.
