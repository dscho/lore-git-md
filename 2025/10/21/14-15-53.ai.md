This is the foundational patch for a new `git-history` command in Patrick Steinhardt's v5 series, introducing the command skeleton and basic infrastructure. The series aims to provide imperative history editing operations (currently `reword` and `split` subcommands) as a more direct alternative to interactive rebase for common use cases.

The patch adds the command plumbing:
- Creates `builtin/history.c` with basic command structure and option parsing
- Adds documentation stub in `Documentation/git-history.adoc` (marked experimental)
- Includes basic test file `t/t3450-history.sh` verifying command skeleton behavior
- Updates all relevant build systems (Makefile, meson.build) and command lists
- Explicitly notes the experimental status and merge commit limitations

The implementation follows Git's standard command pattern, with the actual functionality to be added in subsequent patches. The documentation positions this as complementary to `git-rebase`, with different use cases - rebase for reapplying commit ranges and `history` for targeted edits. The test coverage is minimal at this stage, just verifying basic command structure.

This is patch 5/12 in the series, following infrastructure improvements in earlier patches and preceding the actual subcommand implementations. The series has already addressed extensive technical review feedback from previous iterations and appears well-integrated with Git's existing sequencer and replay infrastructure.
