Refactoring patch in the geometric repacking strategy series. This is the first of nine patches in v2 of the series that introduces new geometric repacking strategies for Git maintenance.

The patch removes a global `repack` variable in `builtin/gc.c` that was used to accumulate arguments for `git-repack`. Instead, it passes these arguments around via a stack-allocated `strvec`. The change makes the code more maintainable and reusable, particularly for the upcoming geometric repacking functionality.

Key changes include:
- Converting the global `repack` to a local `repack_args` in `cmd_gc()`
- Modifying helper functions to accept a `strvec*` parameter
- Adding a new `gc_condition()` wrapper for maintenance tasks that discards temporary repack arguments

The refactoring is clean and well-motivated, with clear ground work for the geometric repacking features to come in later patches. The commit message thoroughly explains the rationale and implementation approach, including the handling of the maintenance auto-condition case. This appears to be a solid foundational change for the series.
