This patch extends the maintenance strategy configuration to cover manual maintenance runs, completing the series' goal of unified strategy control. It modifies the `maintenance.strategy` config to apply to both scheduled and manual maintenance, addressing a gap where previously strategies only affected scheduled runs while manual runs defaulted to `git gc`.

Key technical changes include:
- Updates to `Documentation/config/maintenance.adoc` clarifying the expanded scope of strategy configuration
- Special handling for the "incremental" strategy to maintain backwards compatibility by running `git gc` during manual maintenance while keeping other tasks scheduled-only
- Modified logic in `initialize_task_config()` to apply strategy configuration regardless of maintenance type
- New test cases in t7900-maintenance.sh verifying:
  - Strategy validation rejects unknown values
  - Correct command execution for manual vs scheduled runs
  - Backwards compatibility behavior for incremental strategy
  - Proper inheritance of strategy configuration

The patch builds on previous work in the series by:
- Utilizing the `MAINTENANCE_TYPE_*` flags introduced earlier
- Leveraging the refactored task configuration infrastructure
- Maintaining consistency with geometric repacking strategy work
- Preserving the ability to override specific tasks via `maintenance.<task>.enabled`

The implementation carefully handles the transition by:
- Documenting the behavior change clearly
- Maintaining existing behavior for incremental strategy users
- Providing clear error messages for invalid strategies
- Adding comprehensive test coverage for both old and new behaviors

This completes the series' goal of providing unified strategy control while maintaining backwards compatibility, particularly important for users transitioning from the previous gc-based maintenance approach. The changes align with the thread's overall direction of providing flexible, configurable maintenance suitable for monorepos while preserving existing behavior where expected.
