This is a refactoring patch from Patrick Steinhardt's `git-history` series (patch 2/12). It extracts commit-picking logic from `builtin/replay.c` into a new shared `replay.c` file to prepare for reuse by the upcoming `git-history` command.

The patch moves several key functions that handle commit operations:
- `pick_regular_commit()` (renamed to `replay_pick_regular_commit()` with new subsystem prefix)
- Supporting functions like `create_commit()`, `get_author()`, and `mapped_commit()`
- The commit-shortening helper `short_commit_name()`

The extraction is clean and mechanical - no behavior changes are introduced, just code relocation with proper header file additions. The new `replay.h` exposes the core picking function while keeping helpers static. This follows the series' goal of building shared infrastructure between `replay` and the new `history` command.

As part of a well-reviewed series that's already addressed technical feedback, this foundational change looks solid. It's a straightforward preparation step for the more interesting history-editing functionality coming in later patches.
