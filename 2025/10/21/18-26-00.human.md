Feature patch adding machine-readable output formats to `git repo structure`.

This is patch 6/7 in the `git repo structure` series, which introduces a new subcommand for analyzing repository structure. The patch adds two new machine-readable output formats (`keyvalue` and `NUL-delimited`) alongside the existing human-readable table format. The `keyvalue` format uses `key=value` pairs separated by newlines, while the `NUL` format uses newline-delimited keys and NUL-delimited values to better handle special characters. The table format remains the default.

The implementation includes comprehensive documentation updates, new formatting functions in `builtin/repo.c`, and test cases verifying the output formats work correctly. The changes maintain backward compatibility while providing more flexible output options for scripting and programmatic use. This completes the output format support planned for the initial implementation of the subcommand.
