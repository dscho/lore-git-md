This is the final patch in the `git repo structure` series, adding progress reporting to the new repository analysis subcommand. The patch implements a progress meter that shows during both the reference counting and object counting phases of the operation.

The progress meter is enabled by default when running in a terminal (tty), with explicit `--[no-]progress` options to control it. The implementation uses Git's standard progress reporting infrastructure, showing counts increment as references and objects are processed. The patch includes tests verifying both the progress output when enabled and its suppression with `--no-progress`.

This completes the core functionality of the `git repo structure` command, which now provides:
- Reference counting (branches, tags, remotes, etc.)
- Object counting (commits, trees, blobs, tags)
- Multiple output formats (table, key-value, NUL-delimited)
- Progress reporting

The implementation is clean and follows Git's conventions, with proper internationalization support and thorough test coverage. The progress reporting is particularly useful addition for larger repositories where the counting operations might take noticeable time. The patch maintains the series' high quality standard with clear code and good test coverage.
