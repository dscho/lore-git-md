This is patch 5/7 in the `git repo structure` series, adding object counting functionality to the new repository analysis subcommand. The patch extends the existing reference counting with reachable object enumeration by type (commits, trees, blobs, tags).

Key technical details:
- Uses the path-walk API to count reachable objects from all regular references
- Maintains counts in a new `object_stats` struct tracking the four main object types
- Combines reference and object stats in a `repo_structure` container struct
- Updates the table output format to include both reference and object sections
- Adds test cases verifying object counts in empty and populated repositories
- Preserves OID preparation during reference iteration (from patch 4/7) for the path-walk phase
- Follows the same internationalization approach as the reference counting

The implementation counts objects reachable from all references, showing totals broken down by type in the same table format used for reference counts. The test cases demonstrate both empty repository handling and correct counting in a repository with commits, tags, and notes (which create additional objects). The object counting happens in parallel with reference counting during the same repository walk.

This builds on the merged ref-filter NULL-pattern handling (patch 2/7) and reference counting infrastructure (patch 4/7), completing the core metrics functionality planned for the subcommand. The remaining patches in the series add output formats (6/7) and progress reporting (7/7).
