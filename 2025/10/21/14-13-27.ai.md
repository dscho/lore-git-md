This is a bugfix patch in the geometric repacking strategy series, addressing silent failure when invalid maintenance strategies are configured.

The patch changes how Git handles unknown maintenance strategy configurations. Previously, Git would silently fall back to a no-op strategy when encountering an invalid value in `maintenance.strategy`. Now it explicitly errors out with a message identifying the invalid strategy. The change makes misconfigurations immediately visible rather than silently degrading to no maintenance.

Key technical changes include:
- Extracts strategy parsing into a new `parse_maintenance_strategy()` function that dies on unknown strategies
- Replaces the silent fallback logic with explicit error handling
- Adds a test case verifying the error message for invalid strategies
- Maintains backward compatibility by still defaulting to `none_strategy` when no strategy is configured

The change is part of the larger geometric repacking series but stands alone as a clear improvement to error handling. It follows the series' pattern of making maintenance behavior more explicit and configurable while preventing silent failures. The test addition matches the series' thorough test coverage approach.
