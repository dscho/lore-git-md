This is a feature patch in the geometric repacking strategy series, adding configurable split factor support to the maintenance task.

The patch introduces a new `maintenance.geometric-repack.splitFactor` configuration option that allows users to adjust the geometric sequence factor used during repacking. While the default remains 2 (requiring each pack to be at least twice as large as the previous), this change enables tuning for very large repositories where a higher factor might reduce packfile merges further. The implementation mirrors the existing `--geometric=` option in `git repack`.

The change touches three key areas: documentation updates in maintenance.adoc, core logic in gc.c that now reads the config value and passes it to the repack command, and new test coverage in t7900-maintenance.sh. The test verifies that different split factors are properly honored by creating a controlled pack structure and checking the resulting repack behavior.

This is a straightforward addition to the geometric repacking infrastructure that maintains consistency with the command-line interface while providing needed flexibility. The implementation is clean, with clear documentation and thorough test coverage that exercises both the configuration reading and actual repack behavior. As part of the v2 series, it builds on prior refactoring work and aligns with the overall strategy developed through collaboration with Taylor Blau and others.
