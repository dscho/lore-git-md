Refactoring patch in the `git repo structure` series, exporting a helper function for reference type classification.

This patch exports `ref_kind_from_refname()` from ref-filter.c to make it available for the upcoming reference counting functionality in the `git repo structure` command. The function determines reference types (like branch, tag, or remote-tracking) by examining refname patterns. The change is minimal - just removing the `static` modifier and adding the declaration to ref-filter.h with a brief doc comment.

This is part of the infrastructure work needed for patch 4/7's reference counting feature, where the command will categorize and count references by type. The thread context shows this was previously reviewed by Eric Sunshine and that the overall series has reached v6 with core functionality stabilized.
