This is a feature patch adding machine-readable output formats to the `git repo structure` command, part of the ongoing series introducing repository structural analysis functionality.

The patch introduces two new output formats alongside the existing human-readable table format: `keyvalue` (with `=` delimiter) and `nul` (NUL-delimited for machine parsing of special characters). The implementation adds format selection via `--format` option, with `table` remaining the default. The keyvalue format produces one key=value pair per line, while the nul format uses NUL characters as delimiters to safely handle special characters without quoting.

Key technical details include:
- New `FORMAT_TABLE` enum value alongside existing `FORMAT_KEYVALUE` and `FORMAT_NUL_TERMINATED`
- `structure_keyvalue_print()` helper handles both new formats with configurable delimiters
- Documentation updates in git-repo.adoc detailing all three formats
- Comprehensive tests in t1901-repo-structure.sh verifying both new formats against expected output
- Maintains backward compatibility by keeping table format as default

The patch builds on previous work in the series that implemented the core reference and object counting functionality. It follows Git's established patterns for machine-readable output formats while adding the NUL-delimited variant which is particularly useful for scripting. The implementation is thorough, with clear documentation and test coverage for the new functionality.
