Feature patch introducing the `git repo structure` subcommand for repository metrics.

This patch (4/7 in the series) implements the core reference counting functionality for the new `git repo structure` command, which aims to provide repository health metrics similar to git-sizer but built into Git itself. The command currently counts and categorizes references (branches, tags, remotes, others) and displays them in a human-readable table format.

The implementation uses `refs_for_each_ref()` to efficiently enumerate references and the newly exported `ref_kind_from_refname()` helper to categorize them. The output formatting handles internationalization and automatically adjusts column widths. The patch includes thorough tests verifying both empty repository and populated repository cases.

This represents the first concrete step toward the series' goal of providing repository structure analysis. The code is well-structured with clear separation between counting logic and presentation, suggesting it will be maintainable as more metrics are added in future patches. The author notes this is just the initial version, with plans to add more metrics and machine-readable output formats in subsequent commits.
