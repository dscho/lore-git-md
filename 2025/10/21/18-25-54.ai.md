This is a cover letter for a feature series introducing a new `git repo structure` subcommand for repository analysis. The series has evolved through 6 versions with significant optimizations and refinements.

The command provides reference and object counting with multiple output formats (table, key-value, NUL-delimited) and progress reporting. Key technical changes in v6 include:
- Optimized reference counting using `refs_for_each_ref()` callback instead of building a full ref array
- Added progress reporting during reference enumeration and object counting
- Exported `ref_kind_from_refname()` for reference categorization
- Maintained ability to add future features like reference filtering

The implementation now:
- Counts references directly via callback to avoid memory overhead
- Shows progress during both reference and object counting phases
- Supports three output formats (human-readable table, machine-readable key-value, and NUL-delimited)
- Preserves OID preparation during reference iteration for future object analysis

The series builds toward git-sizer-like functionality but starts with basic metrics. Future plans mentioned include:
- Adding "level of concern" indicators
- Including object size metrics
- Supporting reference filtering
- Linking to interesting OIDs

The cover letter notes the command was renamed from "stats" to "structure" to better reflect its focused scope. Several preparatory patches (refactoring, NULL pattern handling) were already merged separately. The remaining patches implement the core functionality with all planned features now complete.
