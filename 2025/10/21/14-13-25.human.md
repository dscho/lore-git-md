This is a feature patch introducing geometric repacking as a Git maintenance task, part of a larger series improving repository maintenance strategies. The patch adds a new "geometric-repack" task that combines the benefits of geometric repacking (faster operations by skipping reachability checks) with periodic full repacks using cruft packs (for proper object expiration).

The implementation includes:
- A new `maintenance.geometric-repack.auto` config option (default 100) to control when automatic repacking occurs
- A hybrid strategy that performs geometric repacks normally but switches to full repacks with cruft packs when packs would be fully merged
- Comprehensive test coverage in t7900-maintenance.sh verifying both the geometric behavior and auto-condition logic

The patch appears well-constructed with thorough testing (139 new test lines) and clear documentation. It addresses a real need for hosting providers and monorepos by providing a middle ground between performance and proper object cleanup. The approach has already been vetted through discussion with Taylor Blau and others in previous iterations of the series.

This is patch 3/9 in v2 of the series, building on earlier refactoring work and setting up for further maintenance strategy improvements. The implementation is now modular and well-tested enough that it could reasonably be considered for merging.
