Feature and refactoring patch series introducing a geometric repacking strategy for Git maintenance.

Patrick Steinhardt presents version 2 of a 9-patch series that introduces a new "geometric" maintenance strategy for Git repositories. The key motivation is addressing shortcomings in Git's current maintenance approaches, particularly for monorepos where traditional all-into-one repacks are inefficient. The series builds on previous work to create a hybrid approach that combines geometric repacking (which preserves pack structure while consolidating) with periodic full repacks using cruft packs for object cleanup. 

Major changes in v2 include making the geometric split factor configurable via `maintenance.geometric-repack.splitFactor` and fixing some test formatting. The implementation now allows maintenance strategies to apply to both manual and scheduled maintenance runs, with backward compatibility preserved for the existing "incremental" strategy.

The series shows careful attention to detail with 246 lines of new test coverage in t7900-maintenance.sh and thorough documentation updates. The design appears well-considered, having incorporated feedback from multiple reviewers (Taylor Blau, Justin Tobler, Junio Hamano) and mirroring GitHub's production setup. The patches follow Git's established patterns while introducing the new geometric maintenance capability in a way that should integrate smoothly with existing workflows.
