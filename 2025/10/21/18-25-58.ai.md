Feature implementation for the `git repo structure` subcommand, focusing on reference counting functionality.

This patch introduces the core reference counting mechanism for the new `git repo structure` command, which aims to provide repository metrics similar to git-sizer but natively in Git. The implementation categorizes references into branches, tags, remotes, and others using the newly exported `ref_kind_from_refname()` helper from ref-filter.c. Results are displayed in a human-readable table format with automatic column sizing.

Key technical details:
- Adds `cmd_repo_structure()` to builtin/repo.c implementing the subcommand
- Uses `refs_for_each_ref()` for direct reference enumeration (optimized in v6)
- Maintains counts in a `ref_stats` struct tracking branches/tags/remotes/others
- Implements table formatting with `stats_table` helper structs and functions
- Includes comprehensive tests in t1901-repo-structure.sh covering empty repos and repos with various reference types
- Handles internationalization with gettext wrappers for displayed strings
- Follows the table output style of git-sizer but marks it as potentially unstable for parsing

The implementation builds on the previously merged NULL-pattern ref-filter changes and establishes the foundation for future additions like object counting (coming in patch 5/7) and machine-readable output formats (patch 6/7). The reference categorization uses the same logic as other Git commands through the shared `ref_kind_from_refname()` function.
