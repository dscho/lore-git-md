This thread investigates an unusual exit code anomaly where `git notes show HEAD` returns -12 (037777777764 in octal) on the NonStop platform (big endian x86) with Git 2.51.0. The original report found that bash truncates this negative exit code to 0xFF, masking the actual error. Initial debugging attempts via gdb and a standalone test program couldn't identify the root cause, though it appeared isolated to the notes subsystem's exit handling.

Jeff King (Peff) has now analyzed the issue and suggests the problem may originate deeper in Git's plumbing - specifically in how `git notes show` executes `git show` via `execv_git_cmd()` to display the note blob. He notes the actual command chain is `git show $(git notes list HEAD)`, with potential exit code propagation from `show_blob_object()`. The pager might also complicate exit code handling, though testing with `--no-pager` hasn't yet been attempted. While the issue remains NonStop-specific, this shifts focus from the notes subsystem to Git's general process execution and exit code plumbing, particularly around blob display. The thread remains active with platform-specific debugging ongoing.
