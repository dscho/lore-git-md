This thread investigates an unusual exit code anomaly in Git's notes subsystem on NonStop platforms. The original report found that `git notes show HEAD` returns exit code -12 (037777777764 octal) on big endian x86 NonStop systems running Git 2.51.0, with Randall Becker confirming this is specifically about process exit codes rather than shell behavior. 

New details reveal that bash truncates the negative exit code to 0xFF (interpreting it as 0), which masks the actual error. Randall attempted to debug this using gdb and created a test program using the !!fn construct, but hasn't yet identified the root cause. The issue appears isolated to the notes subsystem's exit code handling, suggesting it may involve low-level process handling or integer representation differences on this platform. While D.
