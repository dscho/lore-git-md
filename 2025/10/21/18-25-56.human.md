Refactoring patch for the ref-filter subsystem, already merged as part of the `git repo structure` series. This small change makes the `name_patterns` field in `struct ref_filter` more flexible by allowing NULL to indicate no patterns, rather than requiring an empty array. The modification affects two functions that check for pattern matches, making them treat NULL the same way they previously treated an empty array.

The patch is straightforward - just two condition checks changed to first verify the pointer isn't NULL before dereferencing it. This is a minor interface improvement that makes the API slightly more intuitive to use, particularly for cases where callers don't need any pattern matching. The change is already merged and was part of the foundational work for the new `git repo structure` command's reference counting functionality.
