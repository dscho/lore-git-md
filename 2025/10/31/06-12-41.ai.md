This is part of Patrick Steinhardt's ongoing refactoring series to improve Git's loose object handling as part of the object database (ODB) abstraction effort. The patch introduces a new `struct odb_loose_source` to encapsulate loose object state that was previously held directly in `struct odb_source`.

The change creates a new type with allocation/free functions (`odb_loose_source_new()` and `odb_loose_source_free()`) and adds it as a field to `struct odb_source`. This is a preparatory step toward making loose object handling pluggable, with the new structure eventually becoming the backend for loose object access. The implementation touches object-file.c/h and odb.c/h, adding about 25 lines of new code while maintaining existing behavior.

This continues the series' pattern of incremental improvements to the ODB interface, with Karthik Nayak having previously suggested alternative naming (`obd_source_loose`) that Patrick considered but ultimately did not adopt in favor of `odb_loose_source`. The change is straightforward and maintains consistency with the series' existing naming scheme.
