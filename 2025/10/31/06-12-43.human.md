Refactoring patch in Patrick Steinhardt's ongoing ODB abstraction series. This is patch 7/13 in v2 of the series, continuing the work to better encapsulate loose object handling in Git's object database.

The change introduces a new `odb_loose_source_reprepare()` function to handle cache clearing when repreparing loose object sources, matching the pattern already used for packfiles. This replaces direct manipulation of cache internals in `odb_reprepare()`. The patch also renames `odb_clear_loose_cache()` to the more specific `odb_loose_source_clear_cache()` to better reflect its scope.

This continues the series' pattern of moving implementation details behind cleaner interfaces while maintaining existing behavior. The changes are focused and mechanical, touching only the cache clearing logic while leaving the actual cache structure unchanged. Reviewers have generally approved the architectural direction of this series, with naming conventions being the primary point of discussion in earlier patches.

The patch follows the established pattern of the series by introducing symmetrical functions for loose object handling that mirror existing packfile interfaces, suggesting it's a straightforward improvement that fits well with the ongoing refactoring work.
