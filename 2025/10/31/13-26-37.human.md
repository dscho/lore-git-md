This is a feature patch for Git's SVN integration, adding multi-line support for `ignore-paths` and `include-paths` configuration options. Currently, these config values can only store a single entry, but the patch modifies the Perl code to read all values (using `--get-all` instead of `--get`) and join them with a pipe character.

The change is straightforward, touching only `perl/Git/SVN/Fetcher.pm` with minimal modifications to handle the multi-value case. The pipe character joining is a logical choice since these values are used as regex patterns. The patch appears well-scoped and correctly implemented, though it doesn't include tests demonstrating the new multi-line functionality.

This would be useful for users who need more complex path filtering rules in their SVN-to-Git conversions, allowing them to split long regex patterns across multiple config lines for better readability. The change maintains backward compatibility since single-line configurations will continue to work as before.
