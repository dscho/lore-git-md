Bugfix for the debug ref backend implementation. This patch adds a missing `optimize` function pointer to the debug ref backend (`refs_be_debug`), which was causing a segmentation fault when running `GIT_TRACE_REFS=1 git pack-refs --all`.

The debug ref backend is a wrapper that adds tracing to ref operations, delegating actual work to another ref backend. The patch follows the established pattern seen in other debug backend functions - it forwards the call to the underlying backend while adding trace output. The new `debug_optimize` function matches the signature of other debug backend functions, taking a `ref_store` and `pack_refs_opts` and returning an int result.

The fix is straightforward and well-contained, touching only `refs/debug.c`. It adds the function implementation and updates the `refs_be_debug` struct to include the new function pointer. The commit message clearly explains both the problem (segfault during ref tracing) and the solution (adding the optimize implementation).

This appears to be a genuine bug fix rather than a theoretical issue, as evidenced by the segfault under specific tracing conditions. The patch follows existing patterns in the code and includes appropriate tracing output consistent with other debug backend operations.
