Technical polish for documentation build system in Julia Evans' Git data model documentation.

Junio Hamano points out a minor inconsistency in the AsciiDoc cross-references in Julia Evans' `gitdatamodel.adoc` documentation patch. The document refers to `<<object,object type>>` but the anchor ID was defined as `[[objects]]` (plural). This causes a build failure in GitHub Actions CI. The proposed fix changes the anchor to `[[object]]` (singular) to match the cross-reference, though Junio notes either approach would work as long as it's consistent.

This is a small but important technical correction to ensure the documentation builds properly. It follows up on Junio's earlier build system fixes from version 3 of this patch series. The change doesn't affect the content or pedagogical value of the documentation itself - it's purely about making the AsciiDoc markup consistent.

The patch is part of the ongoing refinement of Julia's documentation effort to explain Git's core data model (objects, references, index, and reflogs). This version 5 has already incorporated extensive feedback from multiple reviewers and 48 beta readers, with Junio now providing final polish on technical details like this markup issue.
