Refactoring patch in Patrick Steinhardt's ODB abstraction series, moving object freshening logic to proper abstraction layers. This is part of the ongoing effort to clean up Git's object database implementation.

The patch reorganizes how Git handles "freshening" objects (updating their modification times when they already exist). Previously this logic was mixed between loose and packed object handling in object-file.c. The change introduces three new functions:
- `odb_freshen_object()` at the database level
- `packfile_store_freshen_object()` for packed objects
- `odb_loose_source_freshen_object()` for loose objects

The key architectural improvement is moving the iteration through object sources from individual backends up to the ODB layer, keeping backend implementations focused on their specific formats. This continues the series' pattern of careful, behavior-preserving refactoring that improves separation of concerns.

The implementation looks clean and maintains all existing functionality while better organizing the code. This is a logical next step in the ODB abstraction work that has been receiving positive reviews throughout the series.
