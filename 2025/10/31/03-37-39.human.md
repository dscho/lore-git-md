Bugfix for the debug ref backend. This patch fixes a segmentation fault that occurs when running `git pack-refs --all` with `GIT_TRACE_REFS=1` enabled. The issue stems from the debug ref backend (`refs_be_debug`) missing an implementation for the `optimize` function pointer, which is called during ref packing operations.

The fix adds the missing `debug_optimize` function to mirror the behavior of other ref backend operations in the debug implementation - it forwards the call to the underlying ref store while logging the operation via the trace mechanism. The implementation follows the same pattern seen in other debug ref functions, maintaining consistency of the debugging interface.
