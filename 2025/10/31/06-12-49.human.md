This is the final patch in Patrick Steinhardt's series refactoring Git's object database (ODB) abstraction, focusing on streaming object writes. The patch introduces a new ODB-level interface `odb_write_object_stream()` for writing large objects in chunks rather than requiring the full content in memory, while renaming the existing implementation to follow the series' naming conventions (`stream_loose_object` becomes `odb_loose_source_write_stream`).

The change affects several files including object-file.c, odb.c, and builtin/unpack-objects.c, with the main beneficiary being `unpack-objects` which handles large blob streams. The patch maintains all existing behavior while providing a cleaner interface at the ODB abstraction level. 

This continues the series' pattern of positive technical reception, with careful attention to naming and architectural separation. The implementation looks solid, completing the ODB interface standardization by covering both buffered and streamed write operations. With this patch, the series appears ready for final review and potential merging.
