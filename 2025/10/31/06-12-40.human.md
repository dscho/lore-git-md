Refactoring patch in Patrick Steinhardt's ongoing ODB abstraction series. This is patch 4/13 in version 2 of the series, which aims to improve Git's object database architecture.

The patch moves the `fetch_if_missing` global variable declaration from object-file.h to odb.h, since this setting affects the entire object database rather than just loose objects. The variable controls whether missing objects should be fetched when extensions.partialClone is enabled, with a default value of 1 (fetch enabled).

This is a straightforward mechanical change that better aligns the variable's declaration location to its logical scope. The series has been receiving positive reviews, with most discussion focused on naming conventions rather than technical approach. This particular patch appears uncontroversial and maintains existing behavior while improving code organization.
