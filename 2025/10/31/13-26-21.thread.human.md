This thread addresses a bug in the Git-SVN bridge's path handling during branch operations, where path normalization was incorrectly applying ignore/include regexps to full repository-relative paths. The original patch fixed this by properly stripping branch location prefixes in `perl/Git/SVN/Fetcher.pm`.

Eric Wong, as the Git-SVN maintainer, has now weighed in to request test coverage for both this path-stripping fix and a related multi-line support change. He emphasizes the importance of tests given the bridge's declining userbase and maintenance challenges, though he hasn't raised any technical objections to the implementation itself. The patches appear technically sound but will likely need test cases added before proceeding further. The discussion remains focused and productive, with the next steps being test implementation rather than design changes.
