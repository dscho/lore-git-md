This is a refactoring patch in Patrick Steinhardt's ongoing series to abstract Git's loose object handling into the object database (ODB) layer. It's patch 9/13 in version 2 of the series.

The patch moves loose object reading operations (`loose_object_info()` and `map_loose_object()`) from repository-level to ODB-level by introducing new functions `odb_loose_source_read_object_info()` and `odb_loose_source_map_object()`. The key changes are:

1. Removes repository parameter from core functions, replacing with `odb_loose_source`
2. Simplifies the alternates handling by moving it up to the ODB level
3. Maintains existing behavior while better encapsulating loose object operations
4. Leaves `open_istream_loose()` as the last repository-level function (to be addressed later)

The changes affect multiple files:
- object-file.c: Major refactor of loose object handling functions
- object-file.h: New function declarations and header cleanup
- odb.c: Updates to use new ODB-level functions
- streaming.c: Minor adaptation to new mapping function

This continues the series' pattern of carefully moving functionality while preserving behavior, with each patch focusing on a specific aspect of the ODB abstraction. The changes are consistent with previous architectural decisions in the series and maintain the same level of test coverage.
