This is part of Patrick Steinhardt's ongoing refactoring series to improve Git's object database (ODB) abstraction. The patch focuses on renaming the `write_object_file()` function to `odb_loose_source_write_object()` to better reflect its purpose and align with the new naming conventions being established in the ODB work.

The change is straightforward - it updates the function name in three files (object-file.c, object-file.h, and odb.c) while keeping all parameters and behavior identical. This continues the pattern seen in previous patches of making function names more explicit about their relationship to the ODB infrastructure.

As with other patches in this series, this appears to be a mechanical change that maintains existing functionality while improving code organization. The patch follows the established naming pattern where functions operating on loose objects are prefixed with `odb_loose_source_`. This is part of the broader effort to clearly separate concerns between different object storage backends.

The patch is small and focused, touching only the function renaming without introducing any behavioral changes. It builds on previous work in the series that has already received positive technical feedback from reviewers. The change helps complete the standardization of function names across the ODB interface.
