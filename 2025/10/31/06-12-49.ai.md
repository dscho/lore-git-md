This is the final patch in Patrick Steinhardt's series refactoring Git's object handling as part of the object database (ODB) abstraction effort. It introduces streaming write capability to the ODB layer.

The patch adds a new `odb_write_object_stream()` function at the ODB level, providing a unified interface for streaming large objects to disk without requiring callers to know about the underlying object source implementation. This complements the existing `odb_write_object()` function that handles non-streamed writes. The implementation renames `stream_loose_object()` to `odb_loose_source_write_stream()` to match the series' naming conventions, and updates the single caller in `builtin/unpack-objects.c` to use the new ODB-level interface. The changes affect object-file.[ch], odb.[ch], and builtin/unpack-objects.c.

Key technical details include:
- New `struct odb_write_stream` replaces `struct input_stream` with identical fields but clearer naming
- The streaming interface maintains the same behavior while moving the abstraction boundary
- Callers now interact with the ODB layer rather than directly with loose object implementation
- The patch follows the established pattern of moving functionality to the ODB layer while preserving existing behavior

This completes the ODB interface standardization work in the series, with all object writing operations now properly abstracted. The implementation has received consistently positive reviews throughout the thread, with naming conventions being the primary point of discussion. This final patch continues that pattern of careful refactoring that maintains behavior while improving architectural separation.
