The feature builds on prior discussions about checking maintenance needs and has been generalized to work across all maintenance tasks, though the initial implementation focuses on reference optimization.

The final two commits implement the new subcommand itself, which can check maintenance requirements either generally or for specific tasks via `--task` flags. The implementation integrates with Git's existing `--auto` heuristics and includes comprehensive tests in t7900.
