This is a refactoring patch in Patrick Steinhardt's ongoing series to abstract Git's loose object handling as part of the object database (ODB) work. The patch focuses on better encapsulating cache management for loose objects.

The change introduces a new `odb_loose_source_reprepare()` function to handle cache clearing when repreparing loose object sources, matching the pattern already established for packfiles. This replaces direct calls to `odb_clear_loose_cache()` (which is renamed to the more specific `odb_loose_source_clear_cache()` and made static) in `odb_reprepare()`. The implementation moves the cache clearing logic into the loose source module rather than exposing it at the ODB level.

Key technical details:
- Adds new public function `odb_loose_source_reprepare()` in object-file.h
- Renames and makes private the cache clearing implementation (`odb_loose_source_clear_cache`)
- Updates the single call site in odb.c to use the new interface
- Maintains identical behavior while improving encapsulation

This continues the series' pattern of incrementally improving the ODB interface by better hiding implementation details. The change is straightforward and builds on previous work in the series to consolidate loose object handling. No behavioral changes are introduced - this purely refactors the code to be more maintainable as the ODB abstraction work progresses.
