This is a bugfix for Git's SVN integration. Pavel Dydyshko addresses an issue where paths being checked against ignore/include regexps in SVN branches include an unwanted prefix - the path to the SVN branch location. The patch modifies `Git/SVN/Fetcher.pm` to properly strip this prefix before testing paths against the ignore rules.

The change is straightforward - it adds logic to check for and remove the `path_strip` prefix (if present) from paths being evaluated. This ensures ignore/include patterns work correctly when operating on SVN branches. The fix is small (4 lines added) and appears well-contained, modifying only the path checking logic without introducing broader changes to the SVN fetcher.
