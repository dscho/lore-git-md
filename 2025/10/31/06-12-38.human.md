This is a refactoring patch in Patrick Steinhardt's ongoing series to improve Git's object database (ODB) abstraction. It introduces a new helper function `odb_source_new()` to centralize the creation of ODB source objects, which were previously initialized in three different places with slightly varying code.

The patch replaces three separate initialization patterns with calls to the new function, making the code more maintainable. The changes affect core ODB operations including alternate object database handling and repository setup. The implementation maintains all existing behavior while reducing duplication.

The patch appears well-contained and follows the series' incremental refactoring approach. It has already been through one round of review (as this is v2), with no outstanding issues mentioned in the thread context. The change is straightforward and unlikely to be controversial, though reviewers may want to verify the memory management around the `objects_path` in `repository.c` where a path string is conditionally freed.
