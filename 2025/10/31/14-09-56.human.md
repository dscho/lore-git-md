This is a follow-up in the ongoing discussion about Git v2.51.2 testing issues on NonStop platforms. Randall Becker provides additional context about their CI/CD constraints and confirms the current test status.

The email explains that NonStop's Jenkins-based testing has inherent delays - each test run takes over a day, creating a 2-3 week backlog when triggered per commit. This explains why the ksh93 compatibility issues weren't caught earlier, as their weekly testing cadence missed the window before v2.51.2's release. The good news is that Jeff King's `TEST_SHELL_PATH=/bin/bash` workaround has resolved the immediate test failures, with only the expected t9001 (sendmail-related) test still failing.

Randall notes an interesting platform-specific quirk - their system has a non-compliant `sendmail` implementation that causes t9001 to fail, and suggests adding a `SENDMAIL=NoThanks` option to skip these tests. The email serves as both a status update and a gentle suggestion for future test infrastructure improvements, while highlighting the practical challenges of testing on constrained platforms.
