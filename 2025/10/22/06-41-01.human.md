This is the first patch in a 14-part series refactoring Git's refs subsystem, specifically introducing a wrapper struct for the `each_ref_fn` callback interface. The patch is a refactoring change that aims to make future modifications to the callback signature less disruptive by encapsulating parameters in a struct.

The change replaces direct callback parameters (refname, referent, oid, flags) with a single `struct reference` parameter containing these fields. This affects 49 files with ~800 lines changed, mostly mechanical conversions of callback functions to use the new struct. The author notes this will make future interface changes easier since only the struct needs updating rather than every callback implementation.

Key points:
- Introduces `struct reference` to bundle callback parameters
- Maintains same functionality while changing interface
- Part of larger effort to modernize refs subsystem
- Follows up on earlier discussion about making callback changes less painful
- Tradeoff is slightly more opaque interface (need to check struct fields rather than function signature)

The patch appears well-scoped and mechanically sound, with thorough updates to all callback implementations. It sets up infrastructure for subsequent patches in the series that will build on this change.
