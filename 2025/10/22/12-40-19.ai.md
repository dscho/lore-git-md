Refactoring patch in the final v5 series optimizing strbuf usage in gpg-interface.c, specifically targeting `get_ssh_key_fingerprint()`. This completes the work started by Junio Hamano to replace unnecessary strbuf operations with direct string parsing.

The patch replaces `strbuf_split_max()` with direct string parsing using `strchr()` and `xmemdupz()` to extract the SSH key fingerprint from command output. The new implementation maintains the same security checks while eliminating temporary strbuf allocations. Key changes include:

1. Replacing the strbuf split operation with two `strchr()` calls to find space delimiters in the output string
2. Using `xmemdupz()` to create a copy of the fingerprint substring
3. Adjusting error reporting from `die_errno()` to `die()` where appropriate
4. Removing all temporary strbuf allocations and cleanup code

The commit message references Junio Hamano's original report and acknowledges review input from Christian Couder and Kristoffer Haugsbakk. The implementation follows the pattern established in sub-process.c (d6fd08bd) for direct string parsing. All CI tests pass and no open issues remain - this appears ready for integration as the final version of this optimization.
