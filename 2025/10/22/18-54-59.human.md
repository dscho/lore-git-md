This is a discussion about the proposed default enablement of `rerere.enabled`, focusing on remaining usability issues that need addressing. Junio Hamano responds to Ben Knoble's request to compile a list of known sharp edges by highlighting another specific pain point: the handling of delete/modify conflicts.

However, Junio observes that in practice users often want to resolve these conflicts by deleting the path, suggesting the current behavior may be too conservative.

This adds a third item to Ben Knoble's proposed todo list of UX issues needing polish before enabling `rerere` by default:
1. Unclear messaging about reused resolutions
2. Non-intuitive workflow for handling incorrect cached resolutions
3. Conservative handling of delete/modify conflicts that doesn't match common user expectations
