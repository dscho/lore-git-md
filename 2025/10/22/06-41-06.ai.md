This is a refactoring patch in Patrick Steinhardt's ongoing refs subsystem modernization series, specifically converting upload-pack to use the new `reference_get_peeled_oid()` interface introduced earlier in the series. The patch focuses on cleaning up the `write_v0_ref()` callback in upload-pack.c.

The key change modifies `write_v0_ref()` to take a `struct reference` parameter instead of individual ref components, allowing it to use the new peeling interface consistently. The patch handles two call paths: the normal ref advertisement case (which already had a reference struct) and the special capabilities announcement case (which didn't). For the latter, it now constructs a temporary reference struct to maintain interface consistency.

Technical details include:
- Changes the `write_v0_ref()` signature to take `struct reference` instead of separate name/oid parameters
- Updates both call sites to provide the reference struct
- Replaces `peel_iterated_oid()` with `reference_get_peeled_oid()`
- Constructs a temporary reference for the capabilities announcement case
- Maintains all existing behavior while removing the `peel_iterated_oid()` dependency

This patch builds on the series' earlier work to eliminate global state in peeling operations and standardize on the new reference wrapper interface. It's a straightforward mechanical conversion that helps complete the transition away from the old peeling mechanism while keeping upload-pack's behavior unchanged. The changes are localized to upload-pack.c with minimal churn (13 insertions, 9 deletions).
