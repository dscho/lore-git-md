Refactoring patch for trailer handling infrastructure, part of a larger series adding `--trailer` support to `git rebase`.

This first patch in the 29-part series moves trailer manipulation from an external `interpret-trailers` helper into Git's core via a new `amend_strbuf_with_trailers()` function. The change eliminates fork/exec overhead and tempfile handling while maintaining the same functionality. Key aspects:

1. The `interpret-trailers` command now just handles file I/O before calling into the new shared trailer processing logic
2. Existing `amend_file_with_trailers()` is reimplemented to use the in-process path
3. A new `trailer_process()` function provides the core logic for both use cases
4. Error handling is simplified by removing intermediate file operations

The patch shows careful attention to maintaining backward compatibility while centralizing logic for the upcoming rebase integration. It touches trailer.c, trailer.h, and builtin/interpret-trailers.c with significant code reorganization but no behavior changes. This foundational change enables the rest of the series to build rebase trailer support on top of the new in-process infrastructure.
