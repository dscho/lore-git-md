Feature patch completing the `--trailer` option for `git rebase` series, specifically handling fixup commands in interactive rebase.

This final patch in the 29-part series addresses trailer handling during interactive rebase's fixup operations. It modifies `append_squash_message()` in sequencer.c to properly append trailers when processing both regular fixup and `fixup -C` commands, which replace commit messages. The implementation ensures trailers are added consistently whether the original message is kept or replaced.

The test addition in t3440-rebase-trailer.sh verifies this behavior by:
- Creating a test branch with two commits
- Running interactive rebase with both `fixup` and `fixup -C` commands in the todo list
- Checking that trailers are properly added in both scenarios
- Using the established `REVIEWED_BY_TRAILER` constant and `expect_trailer_msg` helper from earlier in the series

This completes the series' coverage of trailer handling in rebase by ensuring the feature works correctly with all interactive rebase operations. The implementation follows the pattern established in previous patches, using the same trailer processing infrastructure (`amend_strbuf_with_trailers`) and maintaining consistency with the series' approach to error handling and state management.
