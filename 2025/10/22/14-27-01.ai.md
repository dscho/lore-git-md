This is a debugging update in the ongoing investigation of the NonStop platform's exit code anomaly with `git notes show`. Randall Becker reports that using `--no-pager` did not change the behavior, confirming the issue is not pager-related. He observes that while directly running `git show $(git notes list HEAD)` works correctly, `git --no-pager notes show HEAD` still returns the mysterious -12 exit code (037777777764 octal). The debugger shows registers rsx and rsi containing 12 at git.c:982, suggesting the possibility of an uninitialized return value being propagated. This reinforces the earlier suspicion that the problem lies in Git's process execution plumbing rather than the notes subsystem itself, with the NonStop platform's handling of exit codes and register values appearing to play a key role. The thread remains focused on understanding why the same underlying operation (`git show` of a notes blob) succeeds when run directly but fails when invoked through the notes command's execv_git_cmd() path.
