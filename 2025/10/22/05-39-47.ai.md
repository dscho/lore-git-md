Test patch in the `git rebase --trailer` series, focusing on persistence verification.

This patch modifies the conflict resolution scenario in t3440-rebase-trailer.sh to better test trailer persistence across rebase operations. The key changes are:

1. Rebuilds the test branch to include a fourth commit after the third, creating a longer history to test
2. Updates the conflict test to verify trailers are properly added to both the conflicted commit (third) and the subsequent commit (fourth) after resolution
3. Maintains the existing `expect_trailer_msg` verification pattern but now checks two commits instead of one

The test now more thoroughly validates that trailer options persist through the entire operation, including conflict resolution and continuation. This builds on the series' earlier work adding state persistence via `rebase_path_trailer()` and ensures the feature handles the full rebase lifecycle. The test follows the established pattern of using the `REVIEWED_BY_TRAILER` constant and `expect_trailer_msg` helper introduced earlier in the series.
