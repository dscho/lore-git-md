This is a refactoring patch in Patrick Steinhardt's ongoing series to modernize Git's refs subsystem, specifically focusing on the upload-pack component. The patch converts upload-pack to use the new `reference_get_peeled_oid()` interface instead of the older `peel_iterated_oid()` function, which relied on global state.

The change makes the code more consistent by ensuring all calls to `write_v0_ref()` now receive a proper `struct reference` parameter, even in the special case where we're announcing capabilities rather than handling an actual reference. The patch handles this by constructing a temporary reference struct when needed.

This is part of a larger effort to clean up the refs subsystem and eliminate global state dependencies. The change appears straightforward and well-contained, touching only upload-pack.c with minimal churn (13 lines added, 9 removed). It builds on previous work in the series that introduced the new peeling interface and reference wrapper struct.
