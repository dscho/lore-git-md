This is the final version (v5) of a two-patch refactoring series targeting strbuf usage in gpg-interface.c, completing work started by Junio Hamano to replace unnecessary strbuf_split*() calls with direct string parsing. The series is now in its final form with all technical and documentation issues resolved.

The patches focus on two functions handling SSH keys: `get_ssh_key_fingerprint()` and `get_default_ssh_signing_key()`. Both replace strbuf_split_max() with direct string manipulation using strchr() and xmemdupz(), maintaining security checks via is_literal_ssh_key() while simplifying memory management. The v5 changes include proper commit message context, corrected reviewer attribution, and edge case handling for missing newlines in signing key input.

Key technical improvements in v5 include: fixing the initial strchr() call to use the correct buffer pointer, handling null terminators when newlines are absent, and adjusting error reporting from die_errno() to die() where appropriate. The commit messages now properly reference sub-process.c (d6fd08bd) as the canonical example of this string parsing approach, as suggested by Junio Hamano.

The series has undergone thorough review across five iterations, with Christian Couder and Kristoffer Haugsbakk providing key feedback.
