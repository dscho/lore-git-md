This is a test modernization patch in the ongoing `--trailer` option for `git rebase` series. It cleans up the test file `t3440-rebase-trailer.sh` by removing redundant hard resets and making branch specifications more precise where needed.

The patch eliminates several `git reset --hard third` calls that were previously used to ensure a clean state before each test. These are redundant since the test framework already provides isolation. Where the branch target matters (like in trailer duplication and conflict tests), it now explicitly passes `third` as the target branch to `git rebase` rather than relying on implicit state.

Key changes:
- Removes 5 redundant `git reset --hard third` calls
- Modifies 3 test cases to explicitly specify `third` as the target branch in rebase commands
- Maintains all existing test assertions and coverage
- Keeps the same test logic but with cleaner setup

This is part of the broader test modernization effort in the series, following earlier patches that converted assertions to use `test_commit_message` and refactored test setup. The changes align with the series' focus on robustness and clarity in the test suite while maintaining all existing functionality verification.
