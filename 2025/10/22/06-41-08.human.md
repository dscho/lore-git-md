This is a refactoring patch in Patrick Steinhardt's ongoing series to modernize Git's reference handling. It converts `builtin/show-ref.c` to use the new `reference_get_peeled_oid()` interface introduced earlier in the series, replacing the older `peel_iterated_oid()`.

The patch addresses an inconsistency in `git show-ref` where different modes of operation had different access to reference metadata. The main change involves constructing a temporary `struct reference` when verifying refs (in the exact-match mode) to maintain a consistent interface with the pattern-matching mode. This allows both code paths to use the new peeling interface.

The changes are mechanical and focused on interface alignment rather than behavior changes. The patch fits into the larger series' goal of cleaning up reference handling while maintaining the separation between transport-related and core reference data structures. It's a straightforward conversion that helps unify the code paths in `show-ref` while preparing for the series' later performance improvements.
