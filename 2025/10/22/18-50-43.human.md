This is a preparatory refactoring patch in a 3-part series finalizing atomic reference updates for `git replay`. The patch standardizes option validation in `builtin/replay.c` by switching from a direct `die()` call to the shared `die_for_incompatible_opt2()` helper function. This change makes the code more maintainable and consistent with other Git commands, setting up for the introduction of a new `--ref-action` option in the next patch.

The change is straightforward - it replaces a custom error message for conflicting `--advance` and `--contained` options with the standard helper function. The patch is small (3-line change) and well-motivated as groundwork for the series' main feature. Since this is part of a reviewed and nearly-finalized series with maintainer approval, it appears ready for merging.
