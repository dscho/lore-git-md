Feature patch (final in series) adding `--trailer` support for fixup commands in interactive rebase.

This is the 29th and final patch in Li Chen's series adding `--trailer` support to `git rebase`. It specifically handles the case where trailers should be added when using `fixup` and `fixup -C` commands during an interactive rebase. The patch modifies `append_squash_message()` in sequencer.c to properly process trailers when replacing commit messages during fixup operations.

The change comes with a new test case in t3440-rebase-trailer.sh that verifies trailer handling with both regular `fixup` and `fixup -C` commands. The test creates a simple commit history, then performs interactive rebases with both fixup variants while adding trailers, checking that the trailers appear in the expected final commit messages.

This completes the series' coverage of rebase's interactive features, following earlier patches that handled basic rebase operations, conflict resolution, and other edge cases. The implementation appears straightforward, building on the trailer infrastructure introduced earlier in the series. The test follows the established patterns seen in previous patches, using the `REVIEWED_BY_TRAILER` constant and `expect_trailer_msg` helper for consistency.
