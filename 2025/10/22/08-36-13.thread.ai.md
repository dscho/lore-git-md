- Validates unrecognized commands against state terms (good/bad/new/old) using `one_of()`
- Shows proper error for invalid commands instead of processing through state machine
- Maintains backward compatibility with alternate terms (e.g. `bad` vs `new`)
- Interaction between `check_and_set_terms()` and new validation confirmed correct
