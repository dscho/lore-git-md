Current status: patch v1 proposes fixes for both issues - restoring `git bisect help` behavior and properly rejecting invalid commands.

Key technical details:

- Adds explicit `help` subcommand handling before state machine
- Validates unrecognized commands against state terms (good/bad/new/old)
- Shows proper error for invalid commands instead of processing through state machine
- Maintains backward compatibility with alternate terms (e.g. `bad` vs `new`)
