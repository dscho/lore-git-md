Refactoring patch finalizing the strbuf cleanup in gpg-interface.c's SSH key handling. This is the second of two patches in the v5 submission, completing a series that replaces unnecessary strbuf operations with direct string parsing.

The patch simplifies `get_default_ssh_signing_key()` by replacing its use of `strbuf_split_max()` with direct string manipulation via `strchr()` and `xmemdupz()`. The function retrieves an SSH signing key by running a command, then extracts the first line of output. Previously it split the output into strbufs only to immediately convert back to a plain string. The new version directly finds and copies the relevant line while maintaining all security checks through `is_literal_ssh_key()`.

This iteration addresses all feedback from previous rounds, including proper handling of missing newlines and memory management. The change follows patterns established in sub-process.c, as suggested by Junio Hamano. Christian Couder and Kristoffer Haugsbakk provided review that helped catch edge cases. The series appears ready for integration, with clean commit messages and passing CI tests.
