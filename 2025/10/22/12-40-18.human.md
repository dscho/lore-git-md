This is the final version (v5) of a performance-oriented refactoring series that eliminates unnecessary strbuf usage in SSH key handling within gpg-interface.c. The patches follow up on work started by Junio Hamano to replace strbuf_split*() calls with direct string parsing where the strbuf functionality isn't needed.

The series contains two cleanups: one for `get_ssh_key_fingerprint()` and another for `get_default_ssh_signing_key()`. Both functions previously used strbuf_split_max() to parse output strings, since they only needed to extract tokens without modification, the strbuf approach was overkill. The new versions use direct string manipulation with strchr() and xmemdupz(), maintaining all security checks while simplifying memory management.

Version 5 includes minor but important fixes from previous reviews: corrected reviewer attribution, proper handling of missing newlines in input, and more precise commit message references. The changes have been tested via GitHub CI and all technical issues appear resolved. The series is now well-polished and ready for integration, representing a clear improvement in code efficiency without changing functionality.
