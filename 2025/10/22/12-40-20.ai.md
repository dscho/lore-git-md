Final patch in a refactoring series optimizing SSH key processing in gpg-interface.c by replacing strbuf_split*() with direct string parsing. This second patch focuses on `get_default_ssh_signing_key()`, completing the strbuf elimination work started by Junio Hamano.

The patch converts the previous strbuf_split_max() approach (which split the key output into temporary strbufs) to a direct string parsing method using strchr() and xmemdupz(). The new implementation locates the first line of key output by finding either a newline or null terminator, then duplicates that segment. Security validation via is_literal_ssh_key() remains unchanged, but memory management is simplified by eliminating intermediate strbuf allocations.

Key technical changes include:
- Replaces strbuf_split_max() with strchr() to find line boundaries
- Uses xmemdupz() for direct string copying
- Maintains identical security checks via is_literal_ssh_key()
- Handles edge case of missing newline via null terminator fallback
- Removes strbuf_list_free() cleanup by working directly with char* buffers
