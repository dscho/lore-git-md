Test modernization patch in the `git rebase --trailer` series.

This is a cleanup patch in the ongoing series adding `--trailer` support to `git rebase`. It simplifies the test file by removing redundant `git reset` operations and making branch dependencies more clear. The changes:

1. Eliminates several hard resets to the 'third' branch that were previously done before each test, as they weren't actually needed for the test logic
2. Makes the branch relationships more explicit by adding 'third' as a target branch where it matters for the test semantics
3. Maintains all the same test coverage while making the test file cleaner and slightly more efficient

The patch is part of the larger test modernization effort in this series, which has been progressively improving the robustness and clarity of the test suite. This particular change follows the pattern seen in earlier patches of the series to use more precise test assertions and eliminate unnecessary setup steps.
