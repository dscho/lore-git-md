This is a security release announcement for Git for Windows, addressing a high-severity vulnerability.

Johannes Schindelin announces Git for Windows 2.51.1, which urgently fixes CVE-2025-26625 (rated 8.6/10 severity) in Git LFS, which is enabled by default. Users are strongly advised to upgrade immediately before cloning or pulling repositories. The release includes updated versions of core components (Git 2.51.1, OpenSSL 3.5.4, OpenSSH 10.2.P1) and fixes a memory corruption issue in the wincred credential helper.

The announcement notes two significant deprecations: git-svn support will be removed in the next major release due to maintenance challenges, and git-flow has already been removed after years of stagnation. The email provides SHA-256 checksums for all distribution formats (installers, portable versions, MinGit variants).

This is a critical update for Windows users, particularly because of the Git LFS vulnerability. The deprecation notices suggest ongoing efforts to streamline the Windows distribution by removing less-used components.
