This is a bugfix completing the dry-run output suppression in Git's diff machinery. The patch follows up on commit b55e6d36eb which had silenced content comparison output in dry-run mode but missed suppressing file deletion and mode change notifications. Johannes Schindelin reviews the changes positively, noting they cover all remaining cases while being minimally invasive.

The changes are straightforward: `run_extern_diff()` now sets quiet mode for dry-run, and `emit_diff_symbol_from_struct()` returns early in dry-run. A new test verifies the behavior across multiple output formats (--raw, --name-only, --name-status) while also checking interactions with ignore-blank-lines and regex ignore patterns.

Schindelin points out one remaining unguarded `fprintf()` in `run_diff_cmd()` but notes it's not in a dry-run code path. He also observes the test helper function could be more tightly scoped, but considers this a minor stylistic point. The patch appears ready for integration, with Schindelin planning to include it in Git for Windows v2.51.1.
