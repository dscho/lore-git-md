This is part 2/10 of Adrian Ratiu and Emily Shaffer's hook subsystem refactoring series, introducing callback-based stdin handling for hooks. The patch adds a new `feed_pipe` callback to the `run_hooks_opt` struct that enables streaming large inputs to hook processes without buffering, complementing the existing file-based `path_to_stdin` approach. The implementation enforces mutual exclusivity between the two stdin methods via `BUG()` checks and integrates with the parallel process infrastructure from patch 1/10. Key additions include the `feed_pipe_fn` callback pointer, context management fields (`feed_pipe_ctx` and `feed_pipe_cb_data`), and proper stdin fd initialization (-1` for callback mode). The changes maintain backward compatibility while enabling more efficient processing of large hook inputs, particularly relevant for reference transactions and push operations. This foundational change supports the series' broader goals of modernizing hook infrastructure with streaming capabilities and parallel execution.
