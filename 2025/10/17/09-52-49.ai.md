This is a test infrastructure discussion about SSH agent handling in Git's test suite, specifically addressing historical behavior changes in OpenSSH.

Lauri Tirkkonen provides important historical context for the SSH agent socket path issue, explaining that OpenSSH changed its default socket location from `/tmp` to `$HOME` in version 10.1. This explains why the space-handling problem in test paths wasn't noticed earlier - older OpenSSH versions would create sockets in `/tmp` by default, avoiding the space-containing `$HOME` path entirely.

The email notes this issue was encountered in Alpine Linux CI, where they worked around it by using `ssh-agent -T` to disable agent forwarding. However, Tirkkonen points out this solution won't work for pre-10.1 OpenSSH versions, suggesting the Git test suite needs a more comprehensive fix that handles both old and new OpenSSH behavior.

This adds a new dimension to the thread's technical context, showing the problem has version-dependent behavior and that CI environments have already encountered it.
