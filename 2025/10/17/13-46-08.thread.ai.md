Security release for Git for Windows 2.51.1 addressing high-severity CVE-2025-26625 (8.6/10) in Git LFS, which is enabled by default. Urgent update includes bundled components: Git v2.51.1, Git LFS v3.7.1 (with security fix), OpenSSL 3.5.4, MSYS2 runtime (Cygwin 3.6.5), and OpenSSH 10.2.P1. Also removes deprecated git flow tool and fixes wincred credential helper memory corruption. Announcement notes git svn will be dropped in next major release due to maintenance burden. Provides SHA-256 checksums for all distribution formats (installers, portable, MinGit) across 32-bit, 64-bit and ARM64 architectures. Windows users must upgrade immediately, especially those using Git LFS, and avoid untrusted clones/pulls until patched.
