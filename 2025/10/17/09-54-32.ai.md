This is a follow-up in the thread about commit-graph segfaults with alternate object stores. Kristoffer Haugsbakk provides a translation clarification for the German warning message shown in Philipp Hahn's original bug report. The warning "Warnung: konnte nicht alle Commit-Graph-Dateien finden" from Git 2.43.0 corresponds to "unable to find all commit-graph files" in English.

The email doesn't introduce new technical content but helps bridge a language barrier in the bug report by providing the standard English equivalent of the warning message that appears when commit-graph files in alternate repositories are missing. This is relevant context for understanding the error path that leads to the segfault, as the warning appears before the crash occurs during commit-graph writing.

Key technical context remains unchanged from the thread summary: the issue occurs when processing commit-graphs in repositories that use alternates, particularly when the alternate's commit-graph becomes inaccessible. The warning message being translated here is part of the error path that ultimately leads to the NULL pointer dereference in `write_graph_chunk_data()`.
