This is a bugfix patch addressing inconsistent behavior in Git's diff output during dry-run mode. The issue stems from commit b55e6d36eb which only partially suppressed output - while content comparison output was silenced, file deletions and mode changes still produced messages. The patch makes two key changes: modifying `run_extern_diff()` to set quiet mode` in dry-run, and adding an early return in `emit_diff_symbol_from_struct()` when dry-run is active.

The changes affect the diff machinery's output generation, specifically around how deletion and mode change notifications are handled. The patch includes a new test case in t4013-diff-various.sh that verifies no content changes appear in the output when using ignore-blank-lines and regex ignore patterns, while still showing file existence changes. The test checks this behavior across --raw, --name-only, and --name-status output formats.
