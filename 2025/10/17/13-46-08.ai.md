Security release for Git for Windows addressing a high-severity vulnerability. This is an urgent announcement about Git for Windows 2.51.1 which fixes CVE-2025-26625 (rated 8.6/10) in Git LFS, a component enabled by default in Windows installations. Users are strongly advised to upgrade immediately and avoid cloning/pulling from untrusted sources until they do.

The release includes several bundled updates: Git v2.51.1, Git LFS v3.7.1 (with the security fix), OpenSSL 3.5.4, MSYS2 runtime based on Cygwin 3.6.5, and OpenSSH 10.2.P1. It also removes the previously deprecated git flow tool and fixes a memory corruption issue in the wincred credential helper.

Notably, the announcement states that git svn support will be dropped in the next major Git for Windows release due to maintenance challenges and low community engagement. This continues the trend of removing unmaintained components from the Windows distribution.

The email provides SHA-256 checksums for all distribution formats (installers, portable versions, MinGit variants) across 32-bit, 64-bit and ARM64 architectures. The security focus and immediate action required make this a high-priority update for Windows Git users, particularly those working with Git LFS.
