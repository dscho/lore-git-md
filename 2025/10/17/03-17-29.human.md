This is a bugfix patch addressing inconsistent behavior in Git's diff output during dry-run mode. The patch corrects an issue where file deletions and mode changes were still being shown in dry-run output despite other diff content being suppressed, which was partially fixed in commit b55e6d36eb.

The fix modifies two key functions: `emit_diff_symbol_from_struct()` now exits early in dry-run mode, and `run_external_diff()` sets the quiet flag when dry-run is active. The patch includes a new test case that verifies no content changes are shown when using `-I` regex patterns in dry-run mode across different diff output formats (--raw, --name-only, --name-status).

The change appears well-scoped and clearly motivated, with the test coverage demonstrating the fix works as intended. This seems like a straightforward improvement to make dry-run behavior more consistent, though reviewers may want to confirm whether suppressing all output in dry-run (including metadata like filenames) is the desired behavior.
