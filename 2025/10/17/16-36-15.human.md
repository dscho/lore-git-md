This is the first patch in a two-part series restoring full window geometry persistence in gitk, specifically addressing the main window. The patch reverts a 2008 workaround (b9bee11526) that only restored window size (not position) due to Cygwin's problematic Tcl/Tk 8.4.1 implementation. With Cygwin now using modern Tcl/Tk 8.6, the original limitation no longer applies.

Johannes Sixt updates the commit message with historical context from Mark Levedahl, explaining that the original position-restoring behavior (from e9937d2a03) was modified due to multi-monitor complaints, though both authors personally prefer full geometry restoration. The patch itself is a straightforward 12-line change that removes the size-only restriction, letting gitk remember both position and dimensions.

The change reflects a shift from platform-specific compromises to standard desktop application behavior, though Sixt acknowledges the multi-monitor use case remains untested in his environment. This appears ready for inclusion as part of the broader window management improvements, with the second patch handling the Tags/Heads window separately.
