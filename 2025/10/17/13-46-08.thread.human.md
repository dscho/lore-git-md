This is an urgent security announcement for Git for Windows users. The project has released version 2.51.1 to address a high-severity vulnerability (CVE-2025-26625, rated 8.6/10) in Git LFS, which comes enabled by default on Windows installations. Users should upgrade immediately and exercise caution with untrusted repositories until they do.

The release bundles several updated components including Git v2.51.1, Git LFS v3.7.1 (containing the security fix), OpenSSL 3.5.4, and OpenSSH 10.2.P1. It also removes the deprecated git flow tool and fixes a memory corruption issue in the wincred credential helper. Notably, the announcement signals that git svn support will be dropped in the next major release due to maintenance burdens. The email provides SHA-256 checksums for all distribution formats across multiple architectures. This is a critical update for all Windows Git users, particularly those working with Git LFS repositories.
