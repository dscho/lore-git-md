Eloy proposed making `git grep` ignore binary files by default via a new `grep.ignoreBinary` config option, with an eye toward changing the default in Git 3.0. Junio C Hamano firmly rejected the idea, citing longstanding precedent (the existing `-I` flag has sufficed for 20 years), compatibility with GNU grep's behavior, and potential breakage of existing scripts. The maintainer's position was a clear no to the fundamental premise, not just the default-change aspect.

Thomas Braun has now weighed in with a compromise suggestion: keep the current default behavior but still add the config option for user convenience. He describes his personal workflow pain of frequently needing to specify `-I` manually, even with aliases, and questions how often users actually want to grep binary files. While this keeps the conversation alive from a user experience perspective, it doesn't address Junio's core objections about ecosystem compatibility. The thread remains at an impasse unless proponents can present new technical justification that satisfies the maintainer's concerns about precedent and script stability.
