This is part 4/10 of Adrian Ratiu and Emily Shaffer's hook subsystem refactoring series, converting the `pre-push` hook to use the new callback-based API. The patch demonstrates the series' pattern by replacing manual child_process setup and SIGPIPE handling with the new `feed_pipe` callback mechanism.

The conversion moves the hook's stdin feeding logic into a dedicated `pre_push_hook_feed_stdin` callback that streams ref data through a strbuf, while maintaining all the existing filtering of ref statuses. The new implementation is 30% shorter (46 lines removed, 37 added) while preserving identical behavior. Key changes include eliminating explicit SIGPIPE management and consolidating error handling through the new hook API's return conventions.

This follows the series' established approach seen in earlier patches, applying the same streaming pattern to `transport.c` after similar conversions in `sequencer.c`. The patch appears well-integrated with the series' infrastructure work, using the same `feed_pipe_ctx` and callback patterns. Existing tests continue to pass, though as with other patches in the series, performance impact and edge cases remain to be validated.
