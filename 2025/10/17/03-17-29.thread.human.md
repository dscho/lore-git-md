This thread addresses a bugfix to complete the implementation of dry-run mode in Git's diff machinery. The original implementation in commit b55e6d36eb silenced content comparison output but still showed file deletions and mode changes. The current patch fixes this by modifying `run_extern_diff()` and `emit_diff_symbol_from_struct()` to fully suppress output in dry-run mode.

Johannes Schindelin has already approved the patch for inclusion in Git for Windows v2.51.1, noting its minimal and well-contained changes. The test coverage verifies the behavior across multiple output formats (--raw, --name-only, --name-status) and confirms proper interaction with ignore-blank-lines and regex patterns.

Junio Hamano has now reviewed the patch and suggests improvements to the commit message to better document the historical context - specifically explaining why dry-run was originally added, what cases it missed, and how this patch completes the implementation. He also requests additional test coverage for `git diff --quiet` to match a real-world use case, though the existing tests already verify the core functionality. The technical changes themselves remain sound and appear ready for integration after these documentation improvements.
