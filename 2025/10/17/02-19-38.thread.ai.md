Bug report regarding inconsistent behavior of `protocol.file.allow` configuration between local and global scopes, affecting submodule operations. The core issue is that setting `protocol.file.allow=always` locally fails to enable file protocol access for `git submodule add` and `git submodule update` commands, while the same setting works when applied globally. The reporter provides clear reproduction steps showing this discrepancy across Git versions 2.39.5 through 2.51.1. This prevents the intended security workflow where users want to restrict file protocol access system-wide while allowing it for specific repositories via local configuration. The bug impacts core submodule functionality when using local file paths, with security implications for protocol restrictions. Technical details center on the configuration handling difference between scopes for this security-sensitive setting.
