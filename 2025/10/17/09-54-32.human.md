This is a follow-up in the thread about commit-graph segfaults with alternate object stores. Kristoffer Haugsbakk provides a translation clarification for the German warning message shown in Philipp Hahn's original bug report. The warning "Warnung: konnte nicht alle Commit-Graph-Dateien finden" appears when Git fails to find commit-graph files in repositories configured with alternates, and it translates to "unable to find all commit-graph files" in English.

This is a minor but helpful clarification in the ongoing investigation of the segfault issue. The thread is still in the early stages with no proposed fixes yet, but this translation helps ensure all participants understand the exact warning message that appears before the crash occurs. The core issue remains the NULL pointer dereference in `write_graph_chunk_data()` when processing repositories with alternates where commit-graph files become inaccessible.
