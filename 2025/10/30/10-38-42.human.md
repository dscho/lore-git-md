This is a refactoring patch in Patrick Steinhardt's packfile store abstraction series, specifically simplifying object lookup logic in `builtin/pack-objects.c`. The patch cleans up the caching mechanism in `has_sha1_pack_kept_or_nonlocal()`, which checks if an object exists in kept or non-local packs.

The key changes move the cached pack check (`last_found`) to the start of the function rather than interleaving it with the pack iteration loop. This makes the control flow more straightforward and eliminates some awkward restart logic. The patch also replaces a `(void *)1` sentinel value with a simple NULL pointer for clearer initialization state.

Taylor Blau had previously reviewed this patch positively while suggesting optimizations, and Patrick has now implemented Toon Claes' suggestion to move the cache check earlier in the loop. The changes are purely structural - no behavior changes - but make the code more maintainable as part of the larger packfile store effort.

This is patch 5/8 in a series that's nearly ready for inclusion, with only some final review needed on the MRU list consolidation in patch 8. The changes here are straightforward and unlikely to be controversial.
