This is part 9 of Patrick Steinhardt's ongoing refactoring series to improve Git's loose object handling as part of the object database (ODB) abstraction effort. The patch moves responsibility for checking loose objects from repository-level functions to the ODB source level.

The key change is restructuring `stat_loose_object()`, `open_loose_object()`, and `quick_has_loose()` to operate on a single ODB source rather than iterating through all sources at the repository level. The iteration is now handled at a higher level in `do_oid_object_info_extended()` and `open_istream_loose()`. This better aligns with the architectural goal of having backends focus on their specific sources while the ODB manages coordination between them.

Karthik Nayak reviews the patch and approves the changes, noting the simplified function implementations and logical movement of source iteration to higher levels. The changes span multiple files but maintain existing behavior while improving the code organization. This continues the series' pattern of behavior-preserving structural improvements in preparation for pluggable ODB backends.
