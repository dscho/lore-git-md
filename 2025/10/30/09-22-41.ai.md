This is a technical follow-up in the `git blame` diff algorithm configurability series, addressing final implementation details around flag handling.

Antonin Delpeuch responds to Phillip Wood's review feedback about the interaction between `XDF_DIFF_ALGORITHM_MASK` and `XDF_NEED_MINIMAL` flags. The core issue is that the current mask doesn't include the minimal flag, which could cause incorrect behavior when multiple diff algorithms are specified in config. Phillip suggested introducing a `CLEAR_DIFF_ALGORITHM` macro to properly clear both flags.

Antonin explores whether `XDF_NEED_MINIMAL` could be added to `XDF_DIFF_ALGORITHM_MASK` instead, noting this might simplify some existing code paths by making flag clearing more comprehensive. However, he recognizes this could be a breaking change for xdiff library users outside Git, suggesting Phillip's macro approach may be preferable for stability. The discussion focuses on implementation details rather than user-facing behavior, as the core functionality has already been reviewed and approved in previous rounds. This represents one of the final polish items before the series can be merged.
