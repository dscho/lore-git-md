This is a refactoring patch in the gpg-interface component, part of a larger series combining code cleanups and translation work. It simplifies SSH fingerprint parsing by eliminating a redundant `strstr()` call in `parse_ssh_output()`.

The patch modifies `gpg-interface.c` to reuse the already-computed `key` pointer when setting `sigc->fingerprint`, rather than repeating the `strstr(line, "key ")` search. The behavior remains identical - it still extracts the fingerprint from the same position in the string (+4 bytes past "key ") - but avoids the duplicate computation.

This change was previously part of a dropped cleanup series and has been resurrected in this v2 submission. The thread context shows Junio C Hamano had already indicated approval for this patch in v1, and the author has incorporated all feedback. The modification is straightforward with no expected impact on functionality, and the CI tests are passing.

The patch aligns with the series' broader goals of code optimization and standardization, though this particular change is purely a small performance improvement rather than translation-related. It touches the same gpg-interface component that will see additional translation work in later patches of the series.
