This is part 3 of a 5-patch series adding translation support to fast-export, fast-import, and gpg-interface components. The patch focuses specifically on marking strings for translation in fast-export.c.

Christian Couder has incorporated feedback from Junio C Hamano about downcasing initial letters in error messages, doing this work within the same patch rather than splitting it out. The changes include marking 77 strings for translation while also improving message consistency - downcasing initial letters, removing redundant prefixes, standardizing phrasing, and improving multi-line indentation.

The patch required corresponding updates to test cases in t9300-fast-import.sh that were checking error messages in a case-sensitive way. This maintains test coverage while enabling proper translation support. The changes are systematic and focused on translation readiness without altering the underlying functionality.

This continues the series' pattern of thorough internationalization work, following similar improvements made to fast-import.c in patch 4. The changes appear well-considered and maintain test coverage, suggesting this is ready for inclusion pending any final edge case verification.
