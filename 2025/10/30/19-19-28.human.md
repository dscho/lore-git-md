This is the final version of a feature series implementing atomic reference updates for `git replay`, now ready for merging. The series has gone through multiple rounds of review with all feedback addressed, including final polish suggestions from Christian Couder in this v6.

The key change makes atomic ref updates the default behavior for `git replay`, while maintaining flexibility through both a new `replay.refAction` config option and a `--ref-action` command-line flag. The implementation uses Git's ref transaction API to ensure atomic behavior and includes comprehensive tests.

Version 6 includes two minor but important improvements based on Christian's review:
1. Consistent parameter naming in `parse_ref_action_mode()` (changed from `mode_str` to `ref_action`)
2. Better test hygiene by using `test_config` helper instead of manual git config cleanup
