This is Junio C Hamano's monthly "What's cooking in git.git" status update, covering recent developments in the Git project. The email provides a comprehensive overview of patches that have graduated to the main branches, new topics under consideration, and ongoing work in progress.

Several notable changes have been merged to 'master' and 'next':
- A new `commitGraph.changedPaths` config option enables changed-paths bloom filters by default
- Command line completion improvements for `git shortlog` options
- Cleanups in the GPG interface code removing problematic strbuf_split usage
- Deprecation of symlink symrefs (to be removed in Git 3.0)
- Bisect command fixes for handling help/invalid subcommands
- A major refactoring of the repack machinery (50 commits) to prepare for incremental MIDX updates
- Simplification of packfile storage APIs

New topics being proposed include:
- Documentation fixes for git-checkout and git-bisect
- Rust interoperability work for SHA-1/SHA-256 object mapping
- Configurable diff algorithm for git blame
- I18n marking for fast-import/export messages
- A new "geometric" maintenance strategy that avoids full repacks
- A new `git history` command for rewriting history
- Atomic reference updates for the experimental `git replay` command

The email also notes several documentation improvements in flight, test fixes, and ongoing cleanups across various subsystems. Many topics are marked as expecting rerolls or needing further discussion before merging. This provides a comprehensive snapshot of Git's development activity at this point in the release cycle.
