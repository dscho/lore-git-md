This is a small optimization patch in the gpg-interface component, part of a larger series combining code cleanups and translation work. The patch simplifies SSH fingerprint parsing by eliminating a duplicate `str()` call that was already computing the same string position earlier in the function.

The change is straightforward - it reuses the existing `key` variable rather than recomputing the same string search. While minor, this removes redundant work when processing SSH signatures. The patch maintains identical behavior while being slightly more efficient.

This appears to be a well-contained improvement with no visible downsides. It's one of several preparatory cleanups in Christian Couder's series that also includes more substantial translation marking work in fast-export and fast-import. The patch has already incorporated feedback from Junio Hamano on an earlier version.
