This is a refactoring patch in a series combining code cleanups and translation work. It's the second of five patches in v2 of the series.

The change standardizes how boolean flags are defined in gpg-interface.h, replacing direct numeric values (1, 2, 4) with bitwise left shift operations (1<<0, 1<<1, 1<<2). This makes it clearer that these are bit flags while maintaining identical runtime behavior. The patch also fixes a minor indentation issue with one of the existing definitions.

This is part of a larger effort to improve code consistency and prepare components for translation. The change is mechanical but follows Git's preferred style for flag definitions, as noted in the commit message. The patch appears straightforward with no expected impact - it's a pure refactoring that doesn't modify any functionality.

The series has already incorporated feedback from earlier reviews, and this particular patch follows a common Git convention seen elsewhere in the codebase. It's a small but worthwhile cleanup that makes the code more maintainable.
