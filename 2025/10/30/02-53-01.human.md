Shell configuration troubleshooting for NonStop test failures. Jeff King responds to Randall Becker's report about test failures on NonStop systems where `git gc` maintenance tests fail due to shell selection. The issue arises because the Make environment uses `/bin/bash` for outer processing while test scripts' `#!/bin/sh` shebang causes them to run under ksh, leading to test assertion failures.

Jeff suggests trying `make TEST_SHELL_PATH=/bin/bash` as a potential workaround, noting that Git has two distinct shell variables: `SHELL` (for Make recipes) and `SHELL_PATH` (for test script execution and C program invocations). He implies that setting `SHELL_PATH` might resolve the issue if the system's `/bin/sh` is problematic, though this remains to be tested.

This continues the technical discussion about platform-specific shell behavior that affects Git's test infrastructure, with Jeff providing a concrete suggestion to try while acknowledging the underlying complexity of Git's shell handling mechanisms. The exchange remains focused on diagnosis rather than proposing a definitive solution.
