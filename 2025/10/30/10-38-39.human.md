Refactoring patch in the packfile store abstraction series. This is patch 2/8 in a series preparing for pluggable object databases by restructuring how Git manages packfile lists.

The patch moves the Most Recently Used (MRU) packfile list from being stored in each `struct packed_git` to a new `struct packfile_list` within the `packfile_store`. This is part of a larger effort to break up global packfile lists into per-object-source lists, which will be needed for the upcoming pluggable object database work.

Key changes include:
- Introduces new `struct packfile_list` and `struct packfile_list_entry` to manage packfile lists
- Provides list manipulation functions (clear, remove, prepend, append)
- Updates all MRU list operations to use the new API
- Removes the MRU list from `struct packed_git`

The changes are mechanical but thorough, touching packfile operations in `pack-objects`, MIDX handling, and core packfile management. The patch maintains existing behavior while setting up the infrastructure needed for future changes in the series.

This continues the clean architectural direction established in earlier patches, with positive feedback from reviewers so far. The changes appear well-contained and focused on the stated goal of moving toward per-source packfile management.
