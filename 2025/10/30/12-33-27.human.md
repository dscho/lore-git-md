This is a v2 patch series from Christian Couder that combines code cleanups with translation work in fast-export, fast-import, and gpg-interface components. The series resurrects two previously dropped cleanup patches and marks error/warning messages for translation to complete internationalization support in these areas.

The key changes in this revision are stylistic adjustments to error messages in patches 3/5 and 4/5, where uppercase letters at the start of messages were downcased to match Git's style guidelines. Some test cases in t9300-fast-import.sh were also updated to match these changes. The commit messages were adjusted to document these modifications.

The series builds on prior cleanup efforts and connects to broader i18n work in Git. Junio Hamano has already reviewed and approved patches 1/6 and 3/6 from the previous version, with consensus reached to include capitalization fixes directly in the current patches rather than as separate changes.

The patches appear well-crafted with thorough test coverage, addressing both technical debt (the cleanup patches) and user-facing improvements (translation support). The changes are focused and clearly explained, making this a solid contribution to Git's internationalization efforts.
