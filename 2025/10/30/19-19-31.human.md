This is the final patch in a production-ready series implementing atomic reference updates for `git replay`. It adds a config option (`replay.refAction`) to control the default behavior, completing the feature's interface design.

The patch introduces persistent configuration support while maintaining the command-line override capability. Users can now set their preferred default mode (either "update" for atomic ref updates or "print" for pipeline output) in their config, with `--ref-action` still available to override it per-invocation. The implementation follows Git's standard configuration precedence pattern where command-line options override config values.

The patch includes comprehensive tests verifying:
- Config parsing and default behavior
- Command-line override of config settings
- Error handling for invalid config values
- State cleanup between tests
- Both update and print modes

The implementation has been thoroughly reviewed, with all feedback from maintainers and reviewers addressed. It follows Git's standard patterns and includes proper documentation in a new `replay.adoc` file. The patch represents the final refinement of this feature after multiple review cycles, now ready for merging.
