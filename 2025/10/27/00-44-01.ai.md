This is part of a series introducing Rust infrastructure for Git, specifically focusing on object hashing functionality. The patch adds a `Hasher` struct that provides a Rust interface to Git's C-based hashing functions, with implementations for safe hashing operations.

The new `Hasher` struct wraps Git's C hashing functions with Rust memory safety guarantees, implementing `Clone` and `Drop` to properly manage resources. It provides methods to update the hash with new data (`update`), finalize the hash into an `ObjectID` (`into_oid`), or get the raw hash bytes (`into_vec`). The implementation also supports the `std::io::Write` trait for easier integration with other Rust I/O operations.

The patch includes comprehensive tests that verify:
- Algorithm identification round-tripping
- Hash offset conversions
- Correct slice lengths for various object types
- Proper hasher functionality including incremental updates and cloning

The implementation currently only provides safe hashing operations but leaves room for future unsafe hashing additions. This appears to be foundational work for upcoming loose object map functionality mentioned in the commit message. The code follows Rust idioms while properly interfacing with Git's C internals, and includes thorough test coverage for the new functionality.
