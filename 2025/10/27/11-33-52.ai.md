This is the foundational patch in Patrick Steinhardt's v6 series introducing a new `git-history` command, which aims to provide imperative history editing operations as an alternative to interactive rebase for common use cases. The patch establishes the basic command infrastructure without yet implementing any subcommands.

The patch adds the new `builtin/history.c` with a minimal implementation that just handles basic argument parsing, plus all the necessary build system and documentation scaffolding. The documentation file `git-history.adoc` is added with an experimental warning and high-level description positioning the command as complementary to `git-rebase`, though it currently contains placeholder sections for commands that will be added in later patches.

Key technical details:
- New files: `builtin/history.c`, `Documentation/git-history.adoc`
- Build system updates in Makefile, meson.build, command-list.txt
- Basic test file `t/t3450-history.sh` with two simple validation tests
- Documentation explicitly marks the command as experimental and notes current merge commit limitations
- Follow-up patches will add `reword` and `split` subcommands

The patch is cleanly focused on establishing the command framework while leaving the actual functionality to subsequent patches in the series. It follows Git's standard patterns for new builtin commands and includes appropriate test and documentation scaffolding from the start. The experimental warning and clear positioning relative to `git-rebase` help set expectations for users.
