The implementation adds the function to hash.c/hash.h and exposes it through Rust's FFI interface in src/hash.rs. This follows the pattern of other Rust-C interoperability layers in the codebase.

- Rust binding uses `*const c_void` for the opaque pointer type
- Maintains the existing hash algorithm numbering scheme (SHA1=0, SHA256=1)
- Adds FFI declaration in new `c` submodule of `hash.rs`
