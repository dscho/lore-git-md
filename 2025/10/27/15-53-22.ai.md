Maintenance test fix for geometric repacking series. This is a follow-up patch addressing a flaky test in the geometric repacking maintenance strategy series.

The patch modifies t7900-maintenance.sh to work around a known issue where `git repack` always regenerates MIDX files even when no packs have changed, causing timestamp updates that make the test fail spuriously. The fix narrows the file comparison to only check *.pack files rather than the entire pack directory, avoiding the MIDX timestamp issue while still verifying the core geometric repack behavior.

This change comes from Junio Hamano incorporating Patrick Steinhardt's fix that was originally part of v4 but needed to be reapplied after the series was merged to 'next'. The patch maintains the test's verification of no-op geometric repacks while being robust against the MIDX regeneration behavior, which the thread has identified as a separate optimization opportunity in `git-repack` itself.

Key technical details:
- Changes test to compare only *.pack files instead of full directory listing
- Preserves test's ability to verify no pack consolidation occurs
- Works around MIDX regeneration behavior that's being tracked separately
- Follows the pattern of other maintenance tasks that have similar behavior

The patch represents a straightforward test stabilization that doesn't affect the core functionality of the geometric repacking strategy, which has already received maintainer approval and final Acks in the thread. The MIDX regeneration optimization is noted as deferred work that doesn't block this series.
