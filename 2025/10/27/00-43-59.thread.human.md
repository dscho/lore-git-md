This thread is about exposing Git's core hash functionality to Rust code, part of the ongoing Rustification effort. The patch moves several inline hash-related functions from `hash.h` to `hash.c` and introduces new allocation/initialization functions to make the code more accessible from Rust while maintaining memory safety. The changes are mechanical transformations of existing functionality rather than introducing new behavior, keeping the same function signatures but making them callable across language boundaries. The work appears uncontroversial as it maintains all existing hash algorithm capabilities while enabling Rust integration - a key goal for the project's modernization efforts.
