This is an infrastructure patch in Patrick Steinhardt's v6 series introducing the `git-history` command. The patch extracts commit-picking logic from `builtin/replay.c` into new `replay.[ch]` files to share functionality between `git-replay` and the upcoming `git-history` command.

The key changes are:
1. Moves `pick_regular_commit()` and supporting functions (`create_commit()`, `get_author()`, etc.) from `builtin/replay.c` to new `replay.c`
2. Renames functions with `replay_` prefix (`replay_pick_regular_commit()`, `replay_create_commit()`)
3. Updates build systems (Makefile and meson.build) to include new files
4. Maintains all existing functionality while making it reusable
5. Keeps `the_repository` usage in extracted code (marked with `USE_THE_REPOSITORY_VARIABLE`)

The patch is part of the larger effort to implement history editing operations (`reword` and `split` subcommands) while sharing infrastructure with `git-replay`. This particular change is foundational - it doesn't add new features but enables code reuse for the subsequent patches that will implement the actual `git-history` functionality.

The extraction appears clean with no behavior changes, just moving code to a shared location. The patch follows Git's established patterns for such refactorings and includes all necessary supporting changes (header files, build system updates). This continues the series' trend of careful infrastructure preparation before introducing new functionality.
