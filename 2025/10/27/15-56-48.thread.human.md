This maintenance release thread covers Git v2.51.2, which primarily addresses regressions and improves CI stability. The release includes several fixes: Jeff King corrected `git diff --quiet -w` behavior, Jacob Keller fixed `--no-index` path handling, and Johannes Schindelin improved Windows CI reliability. The release also updates Unicode tables and GitHub Actions dependencies.

Randall Becker has now reported platform-specific test failures on NonStop systems when building with OpenSSL 3.5. The issues appear in the maintenance test suite (t7900), specifically around `test_subcommand` assertions checking `git gc` behavior. The failures suggest the test infrastructure may not properly handle negated assertions on this platform, possibly due to shell parsing differences in bash 5.0.18. While this seems to be a test suite rather than core functionality issue, it could mask real problems if not addressed. The regression wasn't present in v2.51.1, though it's unclear whether the OpenSSL version change is related.
