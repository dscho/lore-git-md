This thread concerns test failures on NonStop systems during the Git v2.51.2 maintenance release testing. The issue stems from a shell selection mismatch where test scripts with `#!/bin/sh` shebangs run under ksh instead of bash on NonStop platforms, particularly affecting `git gc` test assertions in t7900 maintenance tests. Randall Becker identified this root cause after earlier investigations with SZEDER Gábor showed discrepancies in command tracing output.

Jeff King has now suggested trying `make TEST_SHELL_PATH=/bin/bash` as a potential solution, explaining this Git-specific variable (which affects script shebangs) differs from Make's `SHELL` variable that Randall had previously experimented with. While manually using bash resolves the test failures, the discussion continues to seek a maintainable solution for NonStop systems, where Randall remains the primary maintainer addressing these platform-specific issues. The problem appears to be an interaction between NonStop's shell configuration and GNU Make behavior rather than a Git test infrastructure bug.
