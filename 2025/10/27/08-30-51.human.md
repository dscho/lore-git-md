This is a refactoring patch that's part of the geometric repacking maintenance series. It removes a global `repack` variable in `builtin/gc.c` that was used to accumulate arguments for `git-repack`, replacing it with stack-allocated `strvec` instances passed through function parameters.

The change makes the code more maintainable by eliminating global state and making data flow explicit. The patch carefully handles the interaction between `git gc --auto` and `git maintenance run --auto`, where the repack arguments need to be computed but then discarded when running GC as a child process.

This is the first of 10 patches in v4 of the series, which has already received maintainer approval. The change is straightforward and uncontroversial, serving as groundwork for later patches that will build on this cleaner architecture. The patch demonstrates good attention to detail, particularly in preserving the existing behavior while making the code more modular.
