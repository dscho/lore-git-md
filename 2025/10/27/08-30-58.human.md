The patch makes strategies apply globally while maintaining backward compatibility - for example, the "incremental" strategy will still run `git gc` for manual maintenance to match historical behavior.

The implementation updates documentation, adds logic to handle strategy selection for both maintenance modes, and includes new tests verifying the behavior. The changes are well-contained, touching only the maintenance subsystem's configuration handling while building on earlier patches in the series that introduced type-based task control.
