This is part 3 of a 10-patch series introducing geometric repacking as a maintenance task, now in its fourth iteration with maintainer approval. The patch adds a new "geometric-repack" maintenance task that uses Git's geometric repacking strategy while addressing its limitation of unconditionally packing all loose objects (including unreachable ones).

The implementation introduces a split strategy: when a geometric repack would merge all packs, it instead performs an all-into-one repack with cruft packs enabled by default. This allows unreachable objects to be properly expired later. The patch includes configuration via `maintenance.geometric-repack.auto` to control when the task runs automatically, with a default threshold of 100 loose objects.

The change comes with extensive test coverage in t7900-maintenance.sh that verifies:
- Basic geometric repacking behavior
- Automatic triggering conditions
- Handling of loose objects
- Cruft pack generation
- Edge cases around pack merging thresholds

This is a well-constructed patch that clearly solves a real problem (object expiration with geometric repacking) while maintaining performance benefits. The implementation is thorough, with careful attention to edge cases and clear documentation. As part of an approved series, it appears ready for integration.
