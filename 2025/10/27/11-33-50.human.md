This is an infrastructure refactoring patch as part of the `git-history` command series. It extracts commit-picking logic from `builtin/replay.c` into new shared `replay.[ch]` files to support both the existing `git-replay` and upcoming `git-history` commands.

The patch moves two key functions - `create_commit()` and `pick_regular_commit()` - into the new replay module, renaming them with `replay_` prefixes for clarity. The implementation remains functionally identical, just relocated. This prepares for reuse by the history editing features while maintaining the existing replay behavior.

Build system files are updated to include the new source files. The changes are mechanical and well-contained, with no behavior modifications. This continues the series' pattern of careful infrastructure preparation before introducing new functionality.

As the second patch in an 11-part series, this follows the initial cover letter that outlined the overall `git-history` goals. The extraction here enables subsequent patches to build on shared commit manipulation logic rather than duplicating it. Junio Hamano has already approved related infrastructure changes in this series.
