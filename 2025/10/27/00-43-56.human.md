This is part of the ongoing Rust integration effort, specifically addressing hash algorithm interoperability between C and Rust code.

Patch 6/14 from brian m. carlson introduces a new helper function `hash_algo_ptr_by_offset()` that returns a pointer to Git's internal hash algorithm structure given its numeric offset. The primary motivation is to enable Rust code to obtain these C structures when calling into C functions that expect them.

The change adds the function to hash.c/hash.h and exposes it through Rust's FFI interface in src/hash.rs. The Rust side gets a new method `hash_algo_ptr()` on the `HashAlgorithm` enum that provides type-safe access to the underlying C structure.

This appears to be a straightforward plumbing change with clear motivation. The implementation is clean and maintains the existing pattern of Rust-C interop in the codebase. As part of a larger series, it likely enables subsequent patches to work with hash algorithms more easily across the language boundary. The patch is well-contained and properly documented in both the commit message and code.
