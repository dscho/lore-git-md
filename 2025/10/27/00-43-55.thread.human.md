This thread introduces Rust abstractions for Git's hash algorithms as part of a broader Rust porting effort. The current patch (5/14) defines a `HashAlgorithm` enum that mirrors Git's existing C implementation, supporting SHA-1 and SHA-256 with conversion utilities and constants for special object IDs. The implementation focuses on internal plumbing rather than user-facing features, carefully maintaining C compatibility through `#[repr(C)]` while adopting Rust idioms like `Option` for unknown algorithms. The patch omits object-hashing functionality for now due to C/Rust interface challenges, indicating this will likely be addressed in future work. The implementation appears thorough, with attention to optimization (using `self` instead of `&self`) and includes precomputed hashes for common cases. This continues the series' pattern of incrementally introducing Rust components while maintaining compatibility with Git's existing architecture.
