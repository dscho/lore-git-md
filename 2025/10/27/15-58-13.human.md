Release announcement for Git v2.51.2 maintenance update.

This is a maintenance release addressing several bugs and CI improvements that have accumulated since v2.51.1. The most notable fix corrects a regression in `git diff --quiet -w` that caused it to emit unnecessary output when there were additions, deletions and conflicts - a behavior that should have remained silent.

The release includes several targeted fixes: Windows CI jobs now disable real-time monitoring that was interfering with tests, `git diff --no-index` handles trailing slashes better, and `git status --short -z` now colors all elements consistently. There's also a Unicode width table update to version 17 and a workaround for newer OpenSSH versions that changed where they create Unix domain sockets.

The changes come from regular contributors including Jeff King, Johannes Schindelin, and Patrick Steinhardt, with Junio Hamano handling the final integration. Most fixes are straightforward corrections, though the CI dependency bumps (GitHub Actions updates) and OpenSSH workaround suggest some ongoing maintenance challenges in the testing infrastructure. As with maintenance releases, this is a collection of small but important fixes rather than any major changes.
