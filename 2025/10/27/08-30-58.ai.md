This patch extends the maintenance strategy configuration to cover both manual and scheduled maintenance operations, addressing a gap where previously strategies only applied to scheduled runs. The change ensures consistent behavior across all maintenance types while preserving backward compatibility.

Key technical changes:
- Updates `Documentation/config/maintenance.adoc` to clarify that `maintenance.strategy` now affects all maintenance types (manual, auto, and scheduled)
- Modifies the `incremental` strategy in `builtin/gc.c` to include `gc` task for manual maintenance while keeping other tasks unchanged
- Adds comprehensive tests in `t/t7900-maintenance.sh` verifying strategy behavior for both manual and scheduled runs
- Introduces a new `test_strategy` helper function for verifying exact command execution via trace2 logs
- Maintains backward compatibility by:
  - Keeping existing incremental strategy tasks as `MAINTENANCE_TYPE_SCHEDULED`
  - Configuring `gc` task to run during manual maintenance
  - Preserving the default `none` strategy for scheduled maintenance

The patch builds on previous work in the series that introduced type-based task control (`MAINTENANCE_TYPE_SCHEDULED`/`MANUAL`). It represents a logical completion of the strategy system, ensuring strategies can coordinate across all maintenance contexts rather than having potentially conflicting approaches between manual and scheduled runs.
