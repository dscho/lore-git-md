This is a documentation and code hygiene patch from Junio Hamano that fixes some incorrect comments about whitespace rule bit assignments in Git's diff machinery. 

The patch corrects a miscount in the bit assignments - the whitespace rules actually use bits 0-11 (not 0-12 as previously documented), with bits 12-14 used for WSEH_NEW/CONTEXT/OLD flags. It also modernizes how these bit constants are defined, switching from octal notation to (1<<n) style which makes the bit positions more obvious and helps prevent similar miscounting errors in the future.

The changes span three files (diff.c, diff.h, and ws.h) but are purely comment and constant definition updates - no runtime behavior is affected. Junio notes in his cover comment that he'd like to eventually add a gap between the whitespace rule bits and WSEH bits to allow for future expansion of whitespace rules.

This is a small but thoughtful cleanup that improves code clarity and maintainability. The patch is straightforward and unlikely to be controversial, coming from Git's maintainer who clearly understands this area of the codebase.
