This is part of an ongoing Rust infrastructure effort (patch 4/14 in the series). It introduces a basic `ObjectID` struct in Rust that mirrors the C `struct object_id`, providing a foundation for working with Git object hashes in Rust code.

The struct is marked with `#[repr(C)]` to ensure compatibility with C code, and derives common traits like `Eq` and `Debug` for practical use. The change is straightforward plumbing work - it doesn't implement any functionality yet, just the data structure.

The implementation appears clean and well-considered, matching Git's existing C structure exactly. This is clearly a building block for future Rust work rather than a standalone feature.
