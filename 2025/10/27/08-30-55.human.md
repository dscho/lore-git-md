This is a bugfix patch in the geometric repacking series that improves error handling for invalid maintenance strategies. 

The patch changes how Git handles unknown maintenance strategies specified in the config. Previously, Git would silently fall back to a no-op strategy when encountering an invalid value, which could lead to maintenance tasks silently failing to run. Now it explicitly errors out with a message about the unknown strategy.

The change pulls the strategy parsing logic into a dedicated function and adds a test case to verify the new error handling. This is part of the larger effort to make maintenance behavior more predictable and debuggable. The patch is small and focused, with clear test coverage for the new behavior.

This appears to be a straightforward improvement that makes the system more robust by failing fast rather than silently doing nothing. It's part of the v4 series that has already received maintainer approval, suggesting this change is uncontroversial and ready for integration.
