To avoid build race conditions, the Makefile is also updated to properly declare these dependencies for the Rust static library build.

The implementation looks straightforward - the new `build.rs` simply outputs the necessary linker directives, while the Makefile change ensures the Rust library rebuilds when any of the linked C libraries change. This appears to be a well-justified plumbing change that maintains build system correctness as the Rust integration expands.
