Git v2.51.2 maintenance release announcement from Junio C Hamano, containing bugfixes and minor improvements since v2.51.1. Key fixes address a regression in `git diff --quiet -w` behavior (now correctly silent when it should be), path handling in `git diff --no-index` with trailing slashes, and `git status --short -z` coloring consistency. Platform-specific fixes include disabling Windows real-time monitoring in GitLab CI (test interference) and OpenSSH 10.1+ ssh-agent socket path workaround. Unicode width tables updated to Unicode 17 standard. Routine maintenance includes GitHub Actions dependency updates (checkout, download-artifact, setup-python, github-script), documentation fixes, code cleanups, and test improvements (notably path checks in t2401). Contributors include Junio C Hamano, Jeff King, Johannes Schindelin, and others. No open questions or unresolved issues - this is a straightforward maintenance release addressing specific regressions and test reliability.
