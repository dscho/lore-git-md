This is part of the ongoing Rust porting effort, specifically adding object hashing functionality. Patch 11/14 in a series by brian m. carlson introduces a `Hasher` struct that provides a safe Rust interface to Git's C hashing functions, with implementations for SHA-1 and SHA-256 algorithms.

The patch adds comprehensive functionality including:
- Safe hashing via `Hasher::new()`
- Methods to update the hash with data and finalize it into an ObjectID or raw bytes
- Implementations of standard Rust traits (`Write`, `Clone`, `Drop`) for better ergonomics
- Thorough test coverage of the hashing operations

The implementation appears well-structured, with proper memory management (via `Drop`) and clear documentation. The tests verify both basic functionality and edge cases like incremental hashing. This looks like a solid foundation for future work with loose object maps mentioned in the commit message.
