This is a test infrastructure patch in the SHA-1/SHA-256 interoperability series. Junio C Hamano is reviewing Brian M. Carlson's addition of new test conditions for handling broken objects in compatibility hash mode.

The patch introduces two new test prerequisites:
- `COMPAT_HASH` detects when tests are running in SHA-256 mode with SHA-1 compatibility
- `BROKEN_OBJECTS` checks whether deliberately broken objects can be created (which isn't possible in compatibility mode since there's no SHA-1 mapping for nonexistent objects)

The change ensures tests that rely on creating malformed objects (like those in t1010-mktree.sh) will be properly skipped when running in compatibility mode. Junio acknowledges the careful attention to detail in handling this edge case. This completes the test coverage for the new hash compatibility infrastructure, building on the previously approved documentation and core functionality changes in the series.
