This is a documentation update in the SHA-1/SHA-256 interoperability series, specifically addressing the pack index v3 format. Junio C Hamano provides positive feedback on Brian M. Carlson's improvements to the technical specification.

The patch clarifies two key aspects of the pack index v3 format: it updates the documentation to specify 8-byte integers for table offsets (supporting larger repositories) and properly describes the "full main hash" checksum behavior. The documentation now makes clear that checksums use the repository's primary hash algorithm (SHA-1 or SHA-256) at full length, not necessarily SHA-256 as previously implied.

The changes appear well-executed, with Junio noting they represent "a nice improvement over v1." This is a small but important piece of the larger hash transition work, ensuring the documentation accurately reflects the technical implementation details for pack file handling across different hash algorithms.
