Documentation patch improving `git-for-each-ref` synopsis formatting. This is part of Karthik Nayak's ongoing cleanup series following their earlier `--start-after` flag addition.

The patch makes two straightforward documentation improvements to the command's synopsis section. First, it adds parentheses around `--exclude=<pattern>` to properly indicate this option can be repeated. Second, it moves the positional pattern arguments (`--stdin | <pattern>...`) to the end of the argument list where they belong, after all flags.

These changes don't affect functionality but make the documentation more accurate and easier to parse. The patch is small and focused, directly addressing a nit from prior review of the `--start-after` feature work. As with the rest of the series, this appears to be a quality-of-life improvement rather than anything urgent.
