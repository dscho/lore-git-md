Git-phoenix repository recovery tool announcement and discussion. Daniil Iaitskov introduces git-phoenix, a standalone tool for recovering unpublished Git repositories after accidental deletion or filesystem failures, addressing Git's lack of built-in local backup mechanisms. The project uses BSD-3-Clause license as specified in its cabal file, Hackage package listing, and now a root-level LICENSE file (added in response to Christian Couder's concern). Couder initially raised a legal concern about license visibility when the license was only specified in project metadata, which Iaitskov resolved by adding the explicit LICENSE file while maintaining the BSD-3-Clause choice (selected for popularity in open source). The license clarity issue is now fully resolved. The tool remains in conceptual stage with implementation details (filesystem scanning, reflog recovery methods) still unspecified. Open questions include technical approach, platform/filesystem support, and whether the pending Git Rev News mention will influence development direction. Key participants: Iaitskov (author), Couder (license discussion).
