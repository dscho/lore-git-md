Git-phoenix repository recovery tool announcement and discussion. Daniil Iaitskov introduces git-phoenix, a standalone tool for recovering unpublished Git repositories after accidental deletion or filesystem failures, addressing Git's lack of built-in local backup mechanisms. The project uses BSD-3-Clause license as specified in its cabal file and Hackage package listing, chosen for popularity rather than specific compatibility reasons. Christian Couder initially raised a legal concern about license visibility, which was resolved when Iaitskov confirmed the license specification in project metadata. Couder offered to help make the licensing information more discoverable (noting GitHub UI doesn't surface cabal/Hackage license info without a root-level LICENSE file). The license choice remains BSD-3-Clause for now, with Iaitskov open to future changes if needed. The tool remains in conceptual stage with implementation details (filesystem scanning, reflog recovery methods) still unspecified. Open questions include technical approach, platform/filesystem support, and whether the pending Git Rev News mention will influence development direction. Key participants: Iaitskov (author), Couder (license discussion).
