This is part 3 of a 10-patch series converting reftable tests to the Clar framework, focusing on block operations. Seyi Kuforiji converts the reftable block test file (t-reftable-block.c -> u-reftable-block.c) while preserving all test cases for ref, log, obj, and index block operations.

The patch maintains the original test coverage while updating assertions to use Clar's `cl_assert*` macros. Key tests include block read/write operations for different block types (REF, LOG, OBJ, INDEX), iterator functionality, and edge case handling. The conversion reduces lines by about 15% (164 -> 80 insertions) through Clar's assertion syntax while keeping the same test logic.

This is part of the broader effort by Patrick Steinhardt, Karthik Nayak, and Seyi Kuforiji to standardize reftable testing on Clar. The patch follows the established pattern from earlier conversions in the series, with Junio C Hamano's sign-off indicating it has addressed previous feedback. The changes are straightforward mechanical conversions with no behavioral modifications.
