This is part 7/10 in a test modernization series converting reftable tests to use the Clar framework. Seyi Kuforiji converts the reftable readwrite test (t-reftable-readwrite.c -> u-reftable-readwrite.c), maintaining all test cases while updating assertions to Clar's macros.

The patch follows the established pattern: replacing test-lib.h assertions with cl_assert* variants, removing the cmd_main() wrapper, and using Clar's test naming convention. Key test cases preserved include:
- Buffer operations and block source functionality
- Log record handling (buffer sizing, overflow conditions, write limits)
- Table read/write operations (sequential access, seek behavior)
- Error handling for corrupted tables
- Index and multi-level index behavior

The conversion shows significant line reduction (405 -> 179 insertions) while maintaining test coverage. Build systems are updated to move from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES. This is a straightforward mechanical conversion that completes the team's effort to standardize on Clar for reftable testing.
