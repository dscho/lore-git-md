This is the 9th patch in a 10-part series converting reftable tests to the Clar framework, specifically targeting the stack test. Seyi Kuforiji completes the migration by converting `t-reftable-stack.c` to `u-reftable-stack.c`, following the established pattern of replacing test-lib.h assertions with Clar's cl_assert macros and updating the test function names.

The patch maintains all existing test coverage for reftable stack functionality, including:
- Basic stack operations (add, read, iterator)
- Transaction handling and auto-compaction behavior
- Concurrency scenarios and error cases
- File permission checks
- Tombstone record handling

With this conversion, there are no remaining `t-*.c` test files, so the patch also removes the corresponding glob check from the meson build configuration. The changes are straightforward mechanical conversions, preserving all test logic while reducing line count (780 -> 332 insertions).
