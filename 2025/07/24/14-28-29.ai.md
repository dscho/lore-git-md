Test modernization in the reftable test suite. This is patch 2/10 in the series converting reftable tests from custom test-lib.h assertions to the Clar framework. Seyi Kuforiji converts the basics test file (t-reftable-basics.c -> u-reftable-basics.c) while maintaining all test coverage and functionality.

The patch preserves all original test cases for reftable basics functionality including binary search (binsearch), string array utilities (names_length, names_equal, parse_names), buffer operations (common_prefix_size), and endian conversion helpers (put/get_be{16,24,32,64}). The conversion breaks up test edge cases into separate Clar test functions for better modularity.

Key technical details carried forward include REFTABLE_BUF operations, REFTABLE_ALLOC_GROW behavior, and all endian conversion tests. The Makefile and meson.build updates move the test from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES. The conversion maintains identical test coverage while using Clar's assertion macros (cl_assert*) instead of test-lib.h's check* macros.

This is a straightforward mechanical conversion following the pattern established in the series' foundational patch, with no behavior changes beyond the test framework migration. The patch has been reviewed and signed off by both the primary author (Kuforiji) and Junio Hamano.
