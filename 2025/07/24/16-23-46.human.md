This is a documentation patch finalizing Git's policy on C99 compound literals, following a thread that examined their use in the reftable subsystem. Junio Hamano adds a section to CodingGuidelines documenting the existing test balloons (specifically the `REFTABLE_FLOCK_INIT` and `REFTABLE_TMPFILE_INIT` macros) and establishing a moratorium on further compound literal usage until mid-2026 for platform compatibility evaluation.

Phillip Wood notes he doesn't deserve credit (as Patrick Steinhardt identified the test cases), which Junio acknowledges while maintaining the documentation. The patch represents the settled consensus from the thread, with the reftable implementation serving as the sole test case until 2026 when wider adoption may be reconsidered. The change is purely documentation - no code is modified - and serves to inform contributors about this intentional limitation.
