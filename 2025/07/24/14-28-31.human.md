This is part of the ongoing reftable test modernization effort, converting tests from custom test-lib.h assertions to the Clar framework. Patch 4/10 in the series focuses on the merged table functionality tests.

Seyi Kuforiji converts t-reftable-merged.c to u-reftable-merged.c, maintaining all test cases for merged table operations while updating the assertion style. The tests verify:
- Single record retrieval from merged tables
- Multiple ref updates across tables
- Repeated seek operations
- Log record merging behavior
- Hash ID and update index handling

The conversion follows the established pattern: replacing test-lib.h's check() with cl_assert(), removing the cmd_main() wrapper, and using Clar's test naming convention (test_reftable_merged__operation). Build systems are updated to move the test from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES.

This is a straightforward mechanical conversion that preserves all the original test cases and their edge case coverage. The patch has already been reviewed and signed off by Junio Hamano, indicating it's ready for inclusion in the broader reftable test modernization series.
