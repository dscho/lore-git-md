Test modernization: conversion of reftable record tests to Clar framework. This is patch 8/10 in Seyi Kuforiji's series completing the migration of all reftable unit tests from custom test-lib.h assertions to the Clar testing framework. The patch converts t-reftable-record.c to u-reftable-record.c, maintaining all test cases while updating assertions to use Clar's cl_assert* macros.

The conversion follows the established pattern seen in previous patches: replacing test-lib.h's check() with cl_assert(), check_int() with cl_assert_equal_i(), removing the cmd_main() wrapper in favor of Clar's test naming convention (test_reftable_*__operation), and using cl_reftable_write_to_buf() helper for test setup. The record test conversion specifically maintains testing of:

- Varint encoding/decoding (test_reftable_record__varint_roundtrip)
- Record comparison operations for ref, log, index and obj records
- Record roundtrip serialization for all record types
- Key encoding/decoding (test_reftable_record__key_roundtrip)
- Edge cases like varint overflow detection

The patch shows significant line reduction (250 -> 131 insertions) due to Clar's more compact assertion syntax while preserving all test coverage. Build systems are updated to move the test from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES in both Makefile and meson.build. This continues the non-controversial modernization effort to standardize reftable testing on Clar.
