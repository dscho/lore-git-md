This is part 4/10 of the reftable test modernization series, converting the merged table functionality tests from custom test-lib.h assertions to the Clar framework. The patch by Seyi Kuforiji focuses on the merged table tests (t-reftable-merged.c -> u-reftable-merged.c), maintaining all test cases while updating the syntax.

Key technical details preserved in the conversion include:
- All test cases for merged table operations (single record, multiple refs, log records, seek behavior)
- REFTABLE_HASH_SHA1/SHA256 handling
- REFTABLE_BLOCK_TYPE_REF/LOG iterator behavior
- Update index range verification (min_update_index/max_update_index)
- REFTABLE_ALLOC_GROW usage patterns

The conversion follows the established pattern:
- Replaces test-lib.h's check() with cl_assert()
- Converts check_int() to cl_assert_equal_i()
- Removes cmd_main() wrapper in favor of Clar's function naming (test_reftable_merged__operation)
- Uses cl_reftable_write_to_buf() helper for test setup
- Preserves all edge case testing (empty refnames, partial seeks, multiple seeks)

Build system changes move the test from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES in both Makefile and meson.build. The patch shows typical line reduction (162 lines changed, 77% similarity) due to Clar's more concise syntax while maintaining identical test coverage. This is a straightforward conversion that completes another piece of the reftable test modernization effort.
