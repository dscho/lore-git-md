This is a build system compatibility note in the ongoing reflog migration infrastructure series. Junio Hamano responds to SZEDER Gábor's observation that the patch series depends on 'odb.h' which wasn't available in v2.50.0.

Junio clarifies that while the series is currently based on v2.50.0, it's meant to fix issues that originated in v2.48 (when reflog migration was introduced) and were partially addressed in v2.49. He notes that for non-security bugfixes, the project typically only supports fixes for the latest release track, suggesting the series should have been based on v2.50 instead.

This exchange highlights a minor but important technical blocker for the series - the need to adjust the codebase dependencies to match the targeted Git version. The discussion doesn't impact the core functionality but needs resolution before the patches can be merged.
