Final patch in the reftable test modernization series, converting stack tests to Clar framework. This patch completes the migration of all reftable unit tests from the custom test-lib.h assertions to Clar framework, specifically targeting the reftable stack functionality (t-reftable-stack.c -> u-reftable-stack.c). 

Key technical details:
- Removes the last remaining t-*.c file from the test suite, eliminating the need for the glob check in meson.build
- Updates both Makefile and meson.build to reflect the conversion (removing old test file from UNIT_TEST_PROGRAMS and adding new one to CLAR_TEST_SUITES)
- Preserves all test logic while converting assertions to Clar equivalents (test_*__* naming convention)
- Tests cover stack operations including:
  - Basic ref addition and reading
  - Transaction API behavior
  - Auto-compaction logic
  - Concurrency scenarios
  - Error handling for invalid operations
- Maintains reftable-specific details like REFTABLE_HASH_SIZE_SHA1 comparisons
- Shows significant line reduction (780 -> 333 insertions) due to Clar's more concise syntax

The patch is well-polished, with all necessary sign-offs (including Junio Hamano's) and follows the established pattern from previous conversions in the series. It represents the completion of the reftable test modernization effort, removing the transitional lib-reftable-clar.{c,h} helpers in the final patch (5/5). The changes are non-controversial and ready for merging.
