Test modernization: final patch in the reftable test conversion series. This patch by Seyi Kuforiji converts the reftable stack test (t-reftable-stack.c) to use the Clar framework (u-reftable-stack.c), completing the migration of all reftable unit tests. The conversion follows the established pattern: replacing test-lib.h assertions with cl_assert* macros, removing cmd_main() in favor of Clar's test naming convention, and updating build systems (Makefile and meson.build) to use CLAR_TEST_SUITES instead of UNIT_TEST_PROGRAMS.

The patch preserves all test cases while modernizing the assertion style, including tests for stack operations (add, read, iterator behavior), transaction handling, auto-compaction behavior, concurrency scenarios, and edge cases like tombstone records and hash ID validation. Key technical details maintained include REFTABLE_HASH_SIZE_SHA1 comparisons, REFTABLE_BUF operations, and all endian conversion tests. The conversion reduces the file size from 780 to 332 lines while maintaining test coverage.

With this change, the series removes the last remaining t-*.c file and eliminates the corresponding glob check in meson.build. The patch is signed off by both the author and Junio Hamano, indicating it's ready for merging as the culmination of Patrick Steinhardt's broader effort to standardize on Clar for reftable testing.
