Test helper cleanup: simplifying error handling in test-delta

This is the first of three patches from Jeff King that refactors the test-delta helper to be more robust and idiomatic. The patch replaces manual error checking and cleanup with Git's standard `die()` and helper functions, reducing the line count by over 30% while fixing several subtle issues.

The key change is replacing explicit error handling (with perror()` and cleanup jumps) with direct `die()` calls, since the test helper exits immediately on errors anyway. This makes the code more consistent - some paths previously forgot cleanup that didn't matter in practice, and the exit code is now uniformly 128 for errors. The patch also adopts standard helpers like `xopen()` and `usage()`.

This follows the thread's emerging consensus that test helpers can rely on process termination for cleanup, though memory handling still matters for leak checking. The changes are straightforward and align with Git's error handling patterns, making this a clear improvement over the original code. The remaining two patches in the series will further simplify memory management and fix descriptor leaks.
