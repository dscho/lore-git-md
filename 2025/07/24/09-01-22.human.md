This is a status update on Rust compiler support for alternative architectures, part of the ongoing Rust adoption discussion in Git.

Pierre-Emmanuel Patry provides an update on GCC-based Rust compilation efforts, which could help address platform compatibility concerns raised earlier in the thread. The team expects to have libcore compilation working by end of summer, though they note this is for an older Rust version (1.49) and still requires significant work. They plan to target Rust 1.78 next to align with Rust-for-Linux, but caution that full support for even 1.49 code may not arrive until next year.

The email highlights `rustc_codegen_gcc` as a potential solution for architectures not supported by LLVM, directly addressing one of the key barriers identified by Gentoo maintainers earlier in the thread. This doesn't immediately resolve all platform concerns, but suggests there may be technical pathways forward for architectures like HPPA and Alpha that currently lack Rust support. The timeline estimates help set expectations about when these solutions might become practical for Git's needs.
