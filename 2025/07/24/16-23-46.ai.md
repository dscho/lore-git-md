Documentation update finalizing Git's compound literal test balloon policy.

This email from Junio Hamano confirms the documentation update about Git's test balloon approach for C99 compound literals, with Phillip Wood noting the credit should also go to Patrick Steinhardt who originally identified the existing reftable usage. The patch adds a section to CodingGuidelines documenting the current test balloons (specifically the reftable macros from v2.48.0-rc0~20) and establishes a moratorium on additional compound literal usage until mid-2026 for platform compatibility evaluation.

The thread is now fully resolved with this documentation in place, having gone through review from both Patrick Steinhardt and Phillip Wood. The documentation serves as a reference point for future contributors while allowing the project to monitor the reftable usage as the sole real-world test case. The technical considerations around compiler compatibility, resource management, and struct evolution remain documented for future evaluation when the moratorium lifts in 2026.
