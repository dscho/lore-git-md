Test modernization: Initial Clar framework helpers for reftable tests. This first patch in the 10-part series introduces Clar-compatible versions of reftable test helper functions that were previously tied to Git's custom test framework. Seyi Kuforiji implements the new `lib-reftable-clar.{c,h}` files containing key utilities like `cl_reftable_set_hash()` for hash generation and `cl_reftable_write_to_buf()` for writing test reftable data, while maintaining the same core functionality as the original helpers.

The implementation handles reftable-specific details including hash types (SHA1/SHA256), block writing with proper header validation, and index range calculations. Build system changes in both Makefile and meson.build integrate the new helpers into the Clar test infrastructure. The patch preserves all necessary assertions (like block format validation and stats checking) while adapting them to Clar's `cl_assert` syntax.

This foundational work enables subsequent patches to convert individual test files to Clar by providing the required testing primitives. The implementation shows careful attention to reftable internals, with thorough buffer handling and error checking that matches the original test behavior. As the first step in a coordinated series, it cleanly separates the helper infrastructure from the actual test conversions that follow.
