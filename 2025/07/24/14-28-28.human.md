This is the first patch in a 10-part series modernizing reftable tests by converting them to the Clar framework. Seyi Kuforiji introduces new helper functions in `lib-reftable-clar.{c,h}` that provide Clar-compatible versions of existing test utilities needed for reftable testing.

The patch adds implementations for three key helpers: `cl_reftable_set_hash()` for hash initialization, `cl_reftable_strbuf_writer()` for test writer creation, and `cl_reftable_write_to_buf()` which handles the core test functionality of writing refs and logs to a buffer while verifying the output. The changes include Makefile and meson.build updates to incorporate the new files into the build system.

This foundational work enables the subsequent test conversions in the series, maintaining the same test coverage while switching frameworks. The implementation looks thorough, with clear assertions and proper handling of reftable-specific details like hash sizes and block formats.
