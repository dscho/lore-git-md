Test modernization: converting reftable table tests to Clar framework. This is part of a larger series (v5 1/5) that completes the migration of all reftable unit tests from custom test-lib.h assertions to the Clar testing framework. The patch focuses on the table functionality tests, renaming t-reftable-table.c to u-reftable-table.c and updating the test assertions to use Clar's syntax.

The changes are mechanical but thorough, converting three main test cases: basic table seeking, repeated seeking (reseek), and block iteration. Each test now uses Clar's assertion macros (cl_assert, cl_assert_equal_i) instead of the older check() and check_int() helpers. The Makefile and meson.build updates remove the old test file and add the new Clar-based version to the test suite.

This appears to be a straightforward conversion that maintains all existing test coverage while modernizing the infrastructure. The patch follows the established pattern seen in earlier conversions of other reftable test components.
