Reftable test modernization: conversion of table test to Clar framework. This is part 6/10 of the series converting reftable unit tests from custom test-lib.h to Clar, specifically targeting the table functionality tests (t-reftable-table.c -> u-reftable-table.c).

The patch follows the established conversion pattern: replacing test-lib.h assertions with Clar's cl_assert* macros, removing the cmd_main() wrapper in favor of Clar's test naming convention (test_reftable_table__*), and using cl_reftable_write_to_buf() helper. The conversion preserves all test cases while reducing boilerplate, maintaining tests for:
- Basic table seek operations (test_reftable_table__seek_once)
- Repeated reseek behavior (test_reftable_table__reseek)
- Block iterator functionality (test_reftable_table__block_iterator)

Key technical details include continued testing of REFTABLE_HASH_SIZE_SHA1 comparisons, REFTABLE_BUF operations, and block iterator behavior with verification of block_type, header_off, and restart_count fields. The build system updates (Makefile and meson.build) move this test from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES while maintaining all test coverage.

The conversion shows 75% similarity to the original test file with expected reductions in line count due to Clar's more concise assertion syntax. This patch continues the collaborative effort between Patrick Steinhardt, Karthik Nayak, and Seyi Kuforiji to complete the reftable test modernization, with Seyi handling this table test conversion. The changes are straightforward and consistent with prior conversions in the series.
