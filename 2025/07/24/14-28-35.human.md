Test modernization: conversion of reftable record tests to Clar framework. This is patch 8/10 in a series by Seyi Kuforiji, Patrick Steinhardt, and Karthik Nayak that completes the migration of reftable unit tests from custom test-lib.h assertions to the Clar testing framework.

The patch converts t-reftable-record.c to u-reftable-record.c, maintaining all test cases while updating assertions to use Clar's cl_assert* macros. Key test areas preserved include:
- Varint encoding/decoding roundtrips and overflow detection
- Ref record comparison and name-based ordering
- Log record comparison and key-based ordering
- Object and index record comparison operations
- Roundtrip testing for all record types (ref, log, obj, index)

The conversion follows the established pattern seen in prior patches: replacing test-lib.h assertions with Clar equivalents, removing the cmd_main() wrapper in favor of Clar's test naming convention (test_reftable_record__*), and updating build systems to use CLAR_TEST_SUITES. The changes are straightforward and maintain 62% similarity with the original test file while reducing line count.

This continues the collaborative effort to standardize reftable testing on Clar, with Seyi Kuforiji handling this record test conversion after contributing several other test migrations in the series. The changes are non-controversial and align with the project's testing modernization goals.
