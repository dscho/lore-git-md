Final cleanup in the reftable test modernization series. This patch removes the transitional `lib-reftable-clar.{c,h}` helper files and renames them back to `lib-reftable.{c,h}` now that all reftable tests have been converted to use the Clar framework. The changes include updating function names from `t_reftable_*` to `cl_reftable_*` to match Clar conventions, removing now-unused build system references to the old test framework, and cleaning up Makefile/meson.build configurations. The patch maintains all test functionality while eliminating 179 lines of redundant code. This represents the completion of the multi-contributor effort to standardize reftable testing on Clar, with Junio Hamano's sign-off indicating readiness for merging.

Key technical details: The patch updates references in all converted test suites (u-reftable-*.c) to point to the renamed header. Build systems are simplified by removing `UNIT_TEST_PROGRAMS` references and consolidating on `CLAR_TEST_SUITES`. The helper functions (`cl_reftable_set_hash`, `cl_reftable_strbuf_writer`, `cl_reftable_write_to_buf`) retain their functionality but now use Clar's assertion macros (`cl_assert*`) instead of the old test-lib.h checks. The changes are mechanical and non-controversial, representing the final step in a well-executed migration effort.
