Test modernization: conversion of reftable priority queue tests to Clar framework.

This is patch 5/10 in a series converting reftable unit tests from custom test-lib.h to Clar. Seyi Kuforiji converts the priority queue test file (t-reftable-pq.c -> u-reftable-pq.c), maintaining all test cases for the reftable priority queue implementation while updating assertions to use Clar's macros.

The patch preserves tests for:
- Record-based comparison (test_reftable_pq__record)
- Index-based comparison (test_reftable_pq__index)
- Merged iterator queue top operation (test_reftable_pq__merged_iter_pqueue_top)

Key changes include replacing check() with cl_assert(), check_int() with cl_assert_equal_i(), and check_str() with cl_assert_equal_s(). The test logic remains largely unchanged (64% similarity) while the file moves from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES in both Makefile and meson.build. This continues the series' pattern of maintaining test coverage while modernizing the test infrastructure.
