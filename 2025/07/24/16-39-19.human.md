This is a documentation update that finalizes Git's policy on C99 compound literals, following earlier discussion in the thread. Junio C Hamano responds to Patrick Steinhardt's approval of the new CodingGuidelines section that establishes a moratorium on additional compound literal usage until mid-2026, using the existing reftable macros as test cases.

Junio clarifies that while the deadline provides structure, the real purpose of the test balloons is to catch platform compatibility issues through normal usage in the reftable code, which all users exercise. He notes that platforms with very slow update cycles would have multiple release cycles to report problems, and those that don't upgrade frequently enough are likely using versions of Git no longer supports anyway.

The exchange shows the documentation has achieved consensus, with both Patrick and Phillip Wood having previously signed off on the approach. Junio's response reinforces that the policy is designed to be practical rather than rigid, focusing on real-world testing through the reftable implementation rather than arbitrary deadlines. The thread appears fully resolved with this final clarification.
