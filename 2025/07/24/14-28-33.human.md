This is part of a test modernization series converting reftable tests to use the Clar framework. Patch 6/10 by Seyi Kuforiji focuses on the reftable table test, converting t-reftable-table.c to u-reftable-table.c.

The conversion follows the established pattern seen in previous patches: replacing test-lib.h assertions with Clar's cl_assert* macros, removing the cmd_main() wrapper in favor of Clar's test naming convention (test_reftable_table__*), and using the cl_reftable_write_to_buf() helper. The patch preserves all test cases while updating the syntax - testing table seek operations, reseek behavior, and block iteration functionality.

The changes are mechanical but thorough, maintaining all the original test coverage for REFTABLE_HASH_SIZE_SHA1 comparisons, REFTABLE_BUF operations, and table iterator behavior. Build systems (Makefile and meson.build) are updated to move the test from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES.

This is a well-executed conversion that follows the pattern established in earlier patches of the series, showing the same attention to detail in preserving test coverage while modernizing the infrastructure.
