Final cleanup in reftable test modernization series. This is the 10th and last patch in Seyi Kuforiji's series converting reftable tests from the custom test-lib.h framework to Clar. The patch removes transitional helper files `lib-reftable-clar.{c,h}` and renames them back to `lib-reftable.{c,h}` now that all tests have been converted. Build systems (Makefile and meson.build) are updated to reflect these changes, removing now-unused references to the old test framework while keeping `test-lib.{c,h}` for other tests that still need it.

The changes are straightforward cleanup after the heavy lifting of test conversion was done in earlier patches. Junio Hamano has signed off, indicating this is ready for merging. The series represents the completion of Patrick Steinhardt's effort to standardize reftable testing on the Clar framework, with significant line count reductions (780 -> 332 lines in the stack test alone) while maintaining all test coverage.
