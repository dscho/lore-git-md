Test modernization: conversion of reftable priority queue tests to Clar framework. This is part 5/10 of the ongoing series to migrate all reftable unit tests from custom test-lib.h assertions to Clar.

The patch converts t-reftable-pq.c to u-reftable-pq.c, maintaining all test cases for priority queue operations while updating the assertions to use Clar's macros. Key changes include:
- Replacing check() with cl_assert()
- Converting check_int() to cl_assert_equal_i()
- Updating string comparisons to use cl_assert_equal_s()
- Removing the cmd_main() wrapper in favor of Clar's test naming convention (test_reftable_pq__*)
- Preserving all test cases for record-based and index-based priority queue operations

The tests verify:
- Correct heap property maintenance in merged_iter_pqueue
- Proper ordering of records by refname
- Index-based comparison when refnames are identical
- Top element behavior in the queue

Build system changes move the test from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES in both Makefile and meson.build. The conversion follows the established pattern seen in previous patches of this series, maintaining all test coverage while reducing boilerplate through Clar's concise syntax.
