This is a documentation patch improving the `git imap-send` man page. It adds a new section explaining how to use the `--list` option to discover available IMAP folders, which is particularly helpful for users whose email clients display different folder names than what the IMAP server actually uses.

The patch provides a concrete example of Gmail's folder structure, showing how the client-visible names ("Junk", "Trash") map to the server's actual folder names ("[Gmail]/Spam", "[Gmail]/Trash"). The new documentation explains that users need to use these server-side names when specifying folders with `git imap-send`.

The change is straightforward and well-motivated, addressing a real point of confusion for users trying to send patches via IMAP. The example output is clear and directly relevant to a common email provider (Gmail), though the documentation notes the same approach works for other providers too. The patch cleanly integrates the new section into the existing man page structure.
