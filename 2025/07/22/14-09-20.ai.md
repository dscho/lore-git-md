This is a test patch that complements the ongoing reflog memory leak fix series. Jeff King adds a test case for per-ref reflog expiration configuration, a feature that has existed since 2008 but was never properly tested. The test creates multiple branches under different namespace patterns (`root1/` and `root2/`), sets up different expiration policies for each pattern, and verifies that `git reflog expire` correctly applies the configuration to only the intended branches.

The test specifically:
- Creates four test branches (two under `root1/` and two under `root2/`)
- Sets `gc.reflogexpire=never` as baseline
- Overrides with `gc.refs/heads/root2/*.reflogExpire=now` for the `root2/` branches
- Verifies only the `root1/` branches retain their reflogs after expiration
- Handles nondeterministic output ordering by sorting before comparison

This test would have caught the memory leak being fixed in the main patch series, as it exercises the same configuration parsing code paths. Jeff notes this was an oversight from the original feature implementation in 2008. The test is designed to be comprehensive enough to prevent similar issues in the future while being simple enough to clearly demonstrate the expected behavior.
