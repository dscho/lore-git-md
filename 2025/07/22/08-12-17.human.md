This is a bugfix patch addressing a file descriptor leak in Git's `archive` command. It's the second in a series of four patches fixing similar resource leaks across test helpers and builtins.

The patch fixes a case in `builtin/archive.c` where a file descriptor opened for output would not be properly closed if the subsequent `dup2()` system call failed. The change adds a single line to close the descriptor in the error path, matching the existing cleanup that already happens when `dup2()` succeeds.

While the leak would only occur in the error case where output redirection fails, the fix follows Git's general principle of robust resource management. The change is minimal and maintains the existing code style, just adding the missing cleanup. This continues the series' focus on plugging small but real resource leaks that could accumulate in edge cases.
