This is a maintenance update for gitk, bringing it in sync with Git 2.50.1 while modernizing its requirements and adding some new features. The changes primarily focus on three areas: security hardening of command execution, modernization of Tcl/Tk dependencies, and new functionality for ref display.

The patch series includes significant security work by Johannes Sixt to properly sanitize arguments passed to 'exec' and 'open' commands in Tcl, addressing potential injection vulnerabilities. Mark Levedahl leads the modernization effort by raising minimum requirements to Git 2.20+ and Tcl/Tk 8.6+, removing legacy code paths, and updating mouse wheel handling to use modern Tk APIs (TIP 171). New user-visible features include SHA-256 repository support (Takashi Iwai) and ref sorting by type in the UI (Michael Rappazzo), with the latter being configurable.

The changes touch nearly all of gitk's code (1405 lines changed), with heavy refactoring to remove old compatibility layers and adopt modern Tk practices. The security fixes appear thorough, with multiple commits systematically addressing different argument-passing scenarios. The modernization work drops support for very old Git and Tcl/Tk versions that were previously maintained for backward compatibility.
