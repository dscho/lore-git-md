This is a major update to gitk, Git's graphical repository browser, bringing compatibility requirements and new features. The pull request syncs gitk with Git 2.50.1 and establishes new minimum versions: Tcl/Tk 8.6 and Git 2.20, allowing removal of legacy compatibility code.

Key changes include:
- New ref sorting in the refs dialog (grouped by local, upstream, other remotes, tags)
- SHA256 repository support
- Modernized Tk theming and mouse wheel handling
- Security improvements in argument sanitization for 'exec' and 'open' commands
- Removal of obsolete code for older Git and Tcl/Tk versions

The changes come from multiple contributors, with Johannes Sixt leading the effort (20 commits) and Mark Levedahl handling much of the Tcl/Tk modernization (15 commits). The patch series appears well-organized, with logical grouping of related changes and clean removal of now-unneeded code. The version requirement bumps seem justified by the modernization work.
