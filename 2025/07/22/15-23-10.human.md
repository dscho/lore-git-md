Bugfix addressing multiple edge cases in merge-ort's rename-to-self handling during directory renames. This is patch 5/6 in a series fixing complex directory rename interactions in merge-ort.

The patch fixes three specific issues that were revealed by test cases:
1. Silent deletion of files that should be kept (testcase 12i2)
2. Silent retention of files that should be removed (testcase 12n2)
3. Incorrect index entry counts after merges (testcase 12n)

The core fix adds a check in process_renames() to skip rename-to-self cases, preventing the code from incorrectly marking paths for deletion. The patch includes substantial test updates, adding a new testcase (12i2) and converting two previously failing tests (12n and 12n2) to expect success.

This builds on earlier work in the series that improved test coverage and documentation for directory rename edge cases. The changes are focused and well-explained, with clear connections to specific test scenarios. The patch comes from Elijah Newren, the merge-ort maintainer, suggesting it represents authoritative fixes for these edge cases.
