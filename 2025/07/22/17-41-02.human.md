Test infrastructure fix for resource leaks in test-delta helper.

This is the second patch in a v3 series addressing file descriptor leaks in test helper programs. Following the earlier fix for test-truncate, this patch cleans up resource management in test-delta.c. The changes initialize the file descriptor to -1 and consolidate cleanup logic to ensure the descriptor is properly closed in all code paths, including error cases.

The patch makes three key improvements: initializing `fd` to -1 to avoid undefined behavior, removing redundant `close()` calls from intermediate error paths, and adding a final safety check before closing. This matches the pattern established in the first patch of the series while being slightly more involved due to test-delta's multiple file operations.

Like the first patch, this change doesn't affect production code but improves test reliability by preventing potential file descriptor exhaustion during test runs. The changes appear well-considered, maintaining the existing error handling patterns while making the cleanup more robust.
