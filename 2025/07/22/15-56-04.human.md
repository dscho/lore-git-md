This is a policy discussion about Rust integration strategy in the ongoing xdiff optimization thread. Junio Hamano responds to Patrick Steinhardt's argument for a full Rust transition rather than maintaining parallel implementations. Hamano notes that Git's current architecture lacks clearly defined subsystem boundaries, making selective Rust adoption difficult - we couldn't realistically choose to implement just some components (like merge backends) in Rust while keeping others in C.

The exchange highlights a key architectural challenge in the Rust migration: the performance benefits demonstrated in the xdiff work come with significant ecosystem tradeoffs (as detailed in earlier thread discussion about platform limitations), and the project lacks the modularity needed for a gradual transition. This suggests any Rust adoption would likely require a more comprehensive architectural restructuring than originally envisioned.
