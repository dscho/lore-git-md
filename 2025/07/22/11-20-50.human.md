This is a documentation patch that's part of a larger series fixing reflog handling in the reftable backend. It updates the `git-reflog` man page to use Git's newer synopsis` typesetting format, which was introduced last year to standardize command documentation formatting.

The change is purely mechanical - it removes the single quotes around command syntax in the SYNOPSIS section and replaces the `verse` directive with `synopsis`. The actual content remains identical, just presented in the newer preferred format. This matches similar changes made across Git's documentation since the synopsis format was introduced.

As the first patch in an 8-part series, this appears to be preparatory work before the substantive reflog fixes.
