Command interface stabilization patch removing the `-m` short flag from `git-switch` and `git-restore`. This is part of a 2-patch series to remove experimental status markers from these commands.

The patch removes the `-m` short flag for the `--merge` option in both commands, keeping only the long form. The rationale is that `-m` is not commonly used (compared to `-c` for `--create`) and removing it now would free up the short flag for potential future use, such as implementing a `--move` option similar to `git-branch`. The change affects both documentation and implementation in builtin/checkout.c.

The patch maintains all existing functionality - the `--merge` option itself remains available, and related options like `--conflict` are preserved. The changes are straightforward doc and code updates with no behavioral impact. This appears to be a well-considered change that simplifies the command interface while preserving flexibility for future extensions.
