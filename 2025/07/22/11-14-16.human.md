This is a feature patch adding IMAP sent-folder archiving to `git send-email`, now in its third version. Aditya Garg's implementation enables users of providers like iCloud Mail to store copies of SMTP-sent messages in an IMAP folder of their choice, addressing a common limitation where SMTP-sent messages don't automatically appear in the Sent folder.

The patch introduces a new `sendemail.imapSentFolder` config option and `--imap-sent-folder` CLI parameter that routes message copies through `git imap-send` after SMTP transmission completes. Key changes from v2 include renaming the option from "imapfolder" to "imap-sent-folder" to better reflect its purpose while maintaining flexibility, and simplifying an error message.

The implementation handles Bcc headers specially (including them in the IMAP copy but not the original email) and preserves all message metadata. Documentation explains the feature's motivation (iCloud Mail's SMTP limitations) and setup requirements (`git imap-send` configuration).

This version appears to resolve the naming debate from earlier in the thread by adopting "sent-folder" terminology while keeping the underlying flexibility to archive to any folder. The code is solid with clear error handling and thorough documentation updates. The patch seems ready for final review, with the discussion now focused on whether to implement a separate IMAP transport mode (B2) - though Garg expresses doubts about its value given `imap-send`'s maintenance history.
