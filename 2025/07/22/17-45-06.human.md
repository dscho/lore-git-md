This is a major update to git-gui, bringing it in sync with Git 2.50.1 and modernizing several aspects of the Tcl/Tk interface. The patch series from Johannes Sixt and Mark Levedahl includes 60 commits that collectively drop support for older Git and Tcl versions while adding SHA-256 repository support and cleaning up the codebase.

The changes establish new minimum requirements: Git 2.36+ and Tcl/Tk 8.6+. This allows removal of numerous compatibility workarounds for older versions, significantly simplifying the code. The update also includes a Bulgarian translation refresh and fixes a minor issue with trailing empty lines in commit messages.

The bulk of the work involves modernizing the codebase - removing deprecated Git command forms, eliminating Windows-specific workarounds no longer needed, and standardizing on newer Tcl/Tk features. The patch touches nearly every part of git-gui, with particularly heavy changes to command execution handling and path sanitization. The diff shows over 3,000 lines removed, indicating substantial cleanup of legacy code.

This appears to be a well-considered modernization effort that maintains functionality while removing technical debt. The changes are consistent with the recent fix for the Tcl file deletion issue (referenced in the base commit), showing continued maintenance of the git-gui component.
