This is a test improvement and bug documentation patch in the ongoing merge-ort rename detection series. Elijah Newren adds detailed test cases that expose two subtle bugs in how Git handles directory renames that result in files being renamed to themselves.

The patch enhances test case 12n by adding proper documentation and index state verification, revealing that Git fails to properly track a file that should be deleted after a directory rename makes its path conflict with itself. A new test case 12n2 is added to show a related bug when directory renames are enabled - here Git silently keeps a file that should be deleted, rather than either properly removing it or at least flagging a conflict.

Both test cases are marked as expecting failure for now, with fixes planned in subsequent patches. The test improvements follow the pattern of other tests in t6423 by including clear English explanations of the setup and expected outcomes. This continues the series' focus on edge cases where directory renames interact with other operations in non-obvious ways.
