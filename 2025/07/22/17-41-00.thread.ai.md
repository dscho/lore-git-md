Test helper resource leak fixes (v3)

This patch series addresses file descriptor leaks in test helper programs `test-truncate` and `test-delta`, now in its third iteration. The core issue involves ensuring proper resource cleanup in test infrastructure code, with v3 focusing first on `test-truncate`. The change adds a missing `close(fd)` call after file truncation operations in `t/helper/test-truncate.c`, following the established error handling pattern while fixing a legitimate resource leak.

The series modifies test infrastructure (not production code) with minimal changes - the current patch shows 3 lines changed (including newline adjustments) to properly close the file descriptor opened earlier in the function. While only affecting test helpers, such leaks could impact test reliability by exhausting file descriptors during test runs. The change maintains the existing `die_errno()` pattern for failures while ensuring cleanup on success.

This version continues the work from v2 which addressed both `test-truncate` and `test-delta`, with reviewers having previously provided feedback that has been incorporated. The current patch appears well-scoped and uncontroversial, directly addressing an issue identified in prior review rounds. The second patch addressing `test-delta` is expected to follow the same careful approach to resource cleanup.
