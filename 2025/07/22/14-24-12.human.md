This is a discussion about platform compatibility concerns for the proposed Rust dependency in Git's xdiff implementation. Patrick Steinhardt responds to Eli Schwartz's concerns about Rust availability across various architectures and distributions.

Schwartz had raised specific issues for Gentoo users, noting that some architectures (HPPA, Alpha, m68k) have no Rust compiler support, while others (s390) only have precompiled binaries that some users avoid. He also mentioned the significant bootstrap chain required for amd64 when not using distro-provided Rust binaries.

Steinhardt acknowledges these concerns and suggests gathering more data about Rust support across common distributions (Debian, Fedora, BSDs) before making a final decision. While he expresses enthusiasm for Rust adoption, he recognizes the need to balance this against potential ecosystem impact, particularly for smaller systems. The tone is cautious, with Steinhardt clearly weighing technical benefits against practical deployment concerns.

This exchange highlights one of the key unresolved questions in the RFC series - how to handle platform support when introducing a Rust dependency. The discussion remains open-ended, with Steinhardt's "Meh :/" suggesting frustration with the tradeoffs involved.
