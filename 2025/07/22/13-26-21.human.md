Feature implementation for `git send-email` IMAP archiving. This email from Aditya Garg confirms the naming discussion around the new `--imap-sent-folder` option, which will allow users to archive sent emails in any IMAP folder (not just "Sent" folders). 

Junio Hamano clarifies that the parameterized option name intentionally supports arbitrary folder names, addressing Garg's concern about the "sent-folder" terminology potentially being misleading. Garg acknowledges this while noting the name might still intuitively suggest using only Sent folder to some users, but ultimately accepts the naming decision.

This exchange finalizes the naming aspect of the feature, which had been through several iterations (originally "imapfolder" in v1). The implementation itself remains unchanged - it will still archive messages via IMAP after SMTP sending, preserving Bcc headers in the archived copies. With this naming clarification, the patch series appears ready for merging, having addressed all substantive feedback from reviewers.
