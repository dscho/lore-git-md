This is a test infrastructure bugfix addressing a file descriptor leak in the `test-truncate` helper program. It's the first patch in a v3 series (of 2 patches) fixing resource leaks in test helpers.

The patch adds a missing `close(fd)` call in `t/helper/test-truncate.c` after the file truncation operation completes. The leak was straightforward - the file descriptor opened earlier in the function was never closed. This is a small but important fix (3 lines added) that improves test reliability by ensuring proper resource cleanup.

The change is clearly correct and uncontroversial - it's the third iteration of this fix, having incorporated prior review feedback about proper resource handling. While this only affects test infrastructure, such leaks can cause problems when running tests repeatedly or in resource-constrained environments. The patch follows the established pattern of the series by focusing on one specific, well-isolated issue.
