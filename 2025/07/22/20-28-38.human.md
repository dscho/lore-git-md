This is a follow-up test patch to a recently merged bugfix that improved path expansion for `gpg.program` configuration. The original fix (now in `master`) made `gpg.program` handle tilde expansion consistently with other Git path settings by using `git_config_pathname()`. 

The current patch adds test coverage for non-absolute paths, including home-directory expansion (using a HOME override) and PATH lookup scenarios. The author notes some mild discomfort with the home-directory test approach, but acknowledges it as the most practical solution without creating test users.

Junio Hamano notes that since the main fix is already merged, he'll treat this as a test-coverage follow-up rather than part of the original series. The patch appears straightforward, adding the expected verification for edge cases that weren't previously tested. This completes the testing story for the path expansion behavior.
