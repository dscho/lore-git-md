This is a test fix patch in a series addressing merge-ort rename detection edge cases. Elijah Newren corrects a minor oversight in test setup for three test cases (12i, 12j, 12k) where a file modification wasn't properly staged before committing. While this doesn't affect the test's core purpose of verifying directory rename behavior, the unstaged change made the tests appear more complex than necessary and could interfere with exposing a deeper bug in merge-ort's handling of rename-to-self cases.

The patch fixes the test setup by properly staging the 'baz' file modifications in each test case and updates the expected status output to show staged ('M') rather than unstaged (' M') changes. It also includes an unrelated fix to test 12n's expected output count. The changes are straightforward and clearly motivated by improving test hygiene and reliability for the ongoing investigation of directory rename edge cases.
