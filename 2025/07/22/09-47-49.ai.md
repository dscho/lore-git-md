Windows-specific bugfix investigation. Johannes Schindelin follows up on James Gao's report of Git for Windows 2.50.1 failing with "Permission denied" errors during basic operations like `git init` and `git add`, even when run as Administrator. Schindelin probes for more details, noting the error may be misleading since it persists with admin privileges. Key questions raised: whether the full error message is being shown, how a clone was created despite the errors, and whether the repository is on a network drive. The response suggests trying the latest snapshot build before downgrading and links to a GitHub issue that may be from the same reporter. This continues the Windows-specific troubleshooting thread, with Schindelin taking a more active diagnostic role while maintaining skepticism about the permissions error being the root cause.
