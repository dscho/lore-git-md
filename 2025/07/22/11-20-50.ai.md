Documentation patch converting git-reflog(1) manpage to use the new synopsis type introduced in commit 974cdca345c. This is the first patch in an 8-part series focused on reftable backend migration issues, though this particular change is purely documentation formatting.

The patch updates the SYNOPSIS section of git-reflog.adoc to use the `[synopsis]` markup instead of the previous `[verse]` style with quoted commands. This maintains the same content but follows the newer, standardized formatting for command documentation. The change affects all subcommands (`show`, `list`, `expire`, `delete`, `drop`, `exists`) and their various options.

This appears to be a straightforward mechanical conversion with no functional changes. The patch is cleanly implemented with a simple 7-line diff that removes quote marks and changes the markup type. As the first patch in the series, it serves as preparatory work before the later patches that address actual reftable migration bugs. The commit message properly references the commit that introduced the synopsis type and follows standard formatting.
