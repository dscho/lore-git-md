This is a documentation patch that improves the `git imap-send` man page by adding a new section explaining how to use the `--list` option to identify IMAP folder names.

The patch adds clear guidance for users who need to specify target folders when using `git imap-send`. It explains that while email clients may show friendly names like "Junk" or "Trash", the actual server-side names (which `git imap-send` requires) can be different. The new documentation provides a concrete example of Gmail's folder structure, showing how to map common folder types to their server-side names (e.g., "[Gmail]/Spam" for Junk).

The addition is well-motivated and addresses a real pain point for users of this somewhat obscure Git feature. The example output is particularly helpful, as IMAP LIST responses can indeed be confusing to parse without guidance. The patch is focused and cleanly implements its stated goal without introducing any complexity.
