This is a bugfix series addressing issues in reflog migration between storage formats, with a new utility command added for testing. The patches come from Patrick Steinhardt's work on implementing reftable support in libgit2, where he discovered two problems in Git's reflog handling during format conversion.

The key fixes are: (1) correcting the identity information written to migrated reflog entries, and (2) properly preserving old commit IDs during migration (they were being zeroed out, which broke libgit2's tests). The series also adds a new `git reflog write` subcommand to help with test reproduction, though this appears primarily as a developer tool rather than user-facing feature.

The changes touch core refs handling code across multiple backends (files and reftable), with corresponding test updates. Given the context of reftable becoming Git's default backend soon, these fixes seem timely and important for compatibility. The series shows thorough test coverage (adding 81 lines of new tests) and careful attention to both behavior and documentation.
