This is a bugfix series addressing resource leaks in test helpers and builtin commands. Hoyoung Lee submits four small patches that ensure file descriptors are properly closed in error paths.

The changes are focused on test utilities (`test-truncate` and `test-delta`) and the `git archive` builtin. Each patch handles a specific case where a file descriptor could be leaked - either when operations fail after opening a file, or when `dup2()` fails during file descriptor manipulation. The fixes are straightforward, adding missing `close()` calls where needed.

The series appears well-scoped and mechanical, following the existing code style. While these leaks might not cause immediate problems (as the programs would typically exit soon after), fixing them improves code hygiene and prevents potential issues if the code paths were to be reused or modified in the future. The changes are minimal and unlikely to be controversial, making them good candidates for quick review and merging.
