This is the foundational patch in a series introducing a new `git repo` command hierarchy, specifically focusing on the `info` subcommand. The patch establishes the basic plumbing for what will become a machine-readable repository information interface, moving functionality out of `git rev-parse`.

The patch creates all the necessary infrastructure:
- Adds `builtin/repo.c` with initial subcommand scaffolding
- Updates build systems (Makefile, meson)
- Adds documentation stub noting this is experimental
- Registers the command in Git's command list
- Key technical elements:
  - Initial implementation uses parse-options for subcommand handling
  - Empty `repo_info()` function that will be filled in later patches
  - Basic documentation structure showing intended usage
  - Explicitly marked as experimental in docs

The commit message explains the motivation - `rev-parse` has accumulated repository information features that don't fit its name, and this provides a more appropriate home. The patch has multiple sign-offs from mentors and contributors, suggesting it's part of an organized effort.

This is patch 1/5 in v5 of the series, which according to the thread context has evolved through several iterations with the output format now stabilized to key=value style. The empty implementation here will be filled out by subsequent patches to actually provide repository metadata access.
