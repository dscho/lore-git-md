This is version 5 of a feature series introducing a new `git repo` command for querying repository metadata, mentored by Karthik Nayak and Patrick Steinhardt as part of GSoC. The series has evolved significantly through previous discussions, with the architecture now largely settled.

The major change in v5 is switching to a key=value output format as the default, replacing the previous NUL-terminated format. The implementation now prints values immediately after retrieval rather than buffering in a strbuf. Callbacks have been simplified to return strings directly rather than filling buffers.

The series adds several repository metadata fields:
- references.format (showing files/reftable storage)
- layout.bare (boolean for bare repos)
- layout.shallow (boolean for shallow clones)

The command remains read-only and experimental, with the name `git repo` retained despite some naming concerns raised in earlier discussion. Open questions remain about future field additions that might need dynamic allocation, and potential aliases for the null format output.

The implementation shows good test coverage for the current features and handles edge cases like duplicate key requests. The documentation has been tightened up, though still marks the command as experimental. This version represents a significant step toward finalizing the command's core functionality.
