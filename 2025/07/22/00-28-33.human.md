Feature implementation for the new `git repo info` command, adding bare repository detection. This is patch 3/8 in the v5 series introducing the new command hierarchy.

The patch adds a `layout.bare` field to the `git repo info` output, which reports whether the current repository is bare (true/false). It leverages the existing `is_bare_repository()` function from Git's environment.c, maintaining consistency with how `git rev-parse --is-bare-repository` works. The implementation follows the established pattern from earlier patches, using the callback-based field system with `bsearch()` lookup.

The change includes documentation updates and comprehensive tests verifying both bare and non-bare repository cases. The implementation is clean and straightforward, building on the scaffolding established in earlier patches. This continues the series' pattern of adding well-tested, focused functionality while maintaining the command's read-only nature and output format consistency.

The patch has multiple sign-offs from mentors and contributors, suggesting it has undergone thorough review. It fits naturally into the series' goal of providing structured repository metadata access, with the bare repository status being a fundamental piece of repository information.
