Bugfix for file descriptor leak in test-delta helper. This is the third patch in a series addressing resource leaks in test helpers and builtins.

Hoyoung Lee fixes another case where a file descriptor could leak in test-delta.c. When `open()` succeeds but `fstat()` fails, the code was returning without closing the file descriptor. The patch adds the missing `close(fd)` call in the error path, matching the pattern from earlier patches in the series.

The change is minimal and focused - just a single line addition to ensure proper cleanup. Like the previous patches, it maintains the existing error reporting via `perror()` while fixing the resource leak. This continues the series' consistent approach to error path handling across different parts of the codebase.

The patch appears straightforward and well-motivated, following the same pattern as the earlier fixes for test-truncate and archive.c. It addresses a real (though likely rare) edge case that could contribute to file descriptor exhaustion.
