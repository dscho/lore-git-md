This is a refactoring patch in Patrick Steinhardt's performance optimization series for remote ref renaming. It's the third patch in v2 of a 6-part series.

The patch fixes sign comparison warnings (-Wsign-comparison) in builtin/remote.c by standardizing loop counter types. It changes various `int` loop variables to `size_t` where appropriate, particularly when iterating over string_list items. The changes are mechanical and straightforward, touching about 30 lines across multiple functions in the file.

This follows preparatory work in earlier patches to standardize reflog callbacks and eliminate redundant data structures. The changes don't affect functionality but clean up compiler warnings as part of the larger effort to optimize remote operations. The patch has already been reviewed and acked in the thread.

The series as a whole is addressing performance issues in remote ref operations, with this being one of several cleanups that pave the way for the more substantial changes in later patches. The compiler warning fixes here are a minor but necessary step in that process.
