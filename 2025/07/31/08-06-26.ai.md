This is part of the ongoing git-gui platform support modernization effort, specifically targeting macOS compatibility. The patch removes the deprecated "Git Gui.app" bundle infrastructure that relied on the system's Tcl/Tk 8.5 framework, which is no longer compatible since git-gui now requires Tcl/Tk 8.6.

The changes delete all macOS-specific app bundle components including:
- The app generator scripts (generate-macos-app.sh and generate-macos-wrapper.sh)
- macOS-specific resource files (AppMain.tcl, Info.plist, git-gui.icns)
- Makefile logic for building the app bundle
- Meson build system integration for the app bundle
- Related build configuration options (TKEXECUTABLE)

This aligns with the architectural decision to treat Tcl/Tk as a third-party dependency rather than a system component on macOS, following the Homebrew model. The removal was expected as part of the v2 series after the minimum Tcl/Tk version was raised to 8.6, making the system's 8.5-based framework unusable. The patch is straightforward and mechanical, deleting obsolete code paths that are no longer relevant with the bundle removal.
