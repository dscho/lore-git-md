This is a refactoring patch in the promisor-remote protocol extension series, specifically addressing parsing improvements for advertised remote attributes. The patch centralizes scattered parsing logic into `parse_one_advertised_remote()` and introduces structured handling via `struct promisor_info`, replacing direct field parsing. Junio Hamano provides a detailed review focusing on the string handling implementation.

Key technical observations from the review:
1. The current implementation uses `string_list_split_in_place()` which modifies the input strbuf, potentially making warning messages less informative. Junio suggests using non-destructive `string_list_split()` instead.
2. The refactoring makes the `strbuf_strip_suffix()` call redundant since the input is already split properly.
3. The parameter type for `parse_one_advertised_remote()` could be simplified from `struct strbuf*` to `const char*` since only the buffer content is used.
4. Memory management is improved through the new `promisor_info_free()` helper.

The review confirms the technical soundness of the approach while suggesting minor implementation refinements. This patch represents the parsing infrastructure improvements needed for the larger feature of configurable remote attribute validation. Junio's feedback indicates the changes are nearly ready, pending these final adjustments to string handling behavior.
