This is a v2 series of 5 patches addressing git-gui's macOS compatibility issues, particularly around the deprecated Tcl/Tk 8.5 framework. The series represents a key architectural decision point in the ongoing git-gui modernization effort.

The main change removes the obsolete "Git Gui.app" bundle (patch 3) which has been broken since macOS 11 and was tied to the system's outdated Tcl/Tk. The remaining changes facilitate using third-party Tcl/Tk 8.6 packages instead. Patch 5 is particularly notable - it changes how git-gui locates its askpass helper to avoid conflicts with Xcode's bundled git, adopting Mark Levedahl's suggested argv0-based approach rather than the exec-path method from v1.

The series shows good technical evolution from v1, with simplified implementations and resolved Makefile issues. It directly addresses core concerns raised in the thread about macOS's problematic system Tcl/Tk and askpass resolution. The changes are substantial (247 lines removed) but focused, removing obsolete macOS-specific files while maintaining functionality.

This appears to be a well-considered solution to a long-standing pain point, though some integration questions remain around RUNTIME_PREFIX handling and meson build support. The patches are cleanly separated and the commit messages clearly explain the macOS-specific context.
