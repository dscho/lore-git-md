This is a macOS-specific cleanup patch in the ongoing git-gui modernization effort. It removes the deprecated "Git Gui.app" bundle infrastructure, which relied on the system's Tcl/Tk 8.5 framework that is no longer supported (the minimum version was recently raised to 8.6). The patch deletes all related files including the app generator scripts, macOS-specific Tcl code, Info.plist, and icon files, while also cleaning up the build system to no longer handle the bundle creation.

The change is part of a larger architectural shift to treat Tcl/Tk as a managed third-party dependency rather than a system component, with Homebrew's approach being validated as the model. This particular patch (3/5 in the v2 series) completes the removal of the macOS app bundle that was started in earlier patches, while the series as a whole focuses on standardizing Tcl/Tk path handling and improving build system integration.

The removal is straightforward and well-justified given the version requirement change, with no obvious technical drawbacks. The patch appears mechanically sound, deleting all related code paths and build system hooks while maintaining compatibility with the new third-party Tcl/Tk approach.
