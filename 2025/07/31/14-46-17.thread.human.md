This thread concerns a small but precise documentation fix for the `git-clone` man page, specifically the formatting of the `--filter` and `--also-filter-submodules` options in the command synopsis. Knut Ryager initially submitted a patch to remove what appeared to be a stray closing bracket after `--also-filter-submodules`. 

Junio Hamano reviewed the patch and pointed out that the issue was more nuanced - the brackets should actually show that `--also-filter-submodules` is nested within `--filter`, since submodule filtering only makes sense when regular filtering is active. He provided historical context from the original commits that introduced these options and later reformatted them. The fix remains a one-character change, but targets a different bracket to properly reflect the option semantics.

Junio also offered style guidance on commit message wording and sign-off matching. While the change is minor, it ensures the documentation accurately represents how these filtering options relate to each other. The thread shows the project's attention to detail even for small documentation corrections.
