This thread concerns a straightforward documentation fix for the git-clone man page, correcting the nested bracket syntax around the `--filter` and `--also-filter-submodules` options. The original incorrect formatting showed these as independent options (`[--filter=<filter>] [--also-filter-submodules]`), when in fact the submodule filtering option requires the main filter to be specified.

Knut Ryager's initial patch fixed the syntax to properly nest the options (`[--filter=<filter> [--also-filter-submodules]]`), which Junio Hamano reviewed with suggestions to improve the commit message. After incorporating this feedback in v2, Kristoffer Haugsbakk noticed the descriptive subject line had been accidentally dropped. Junio has now agreed the clear subject line should be restored while also requesting the commit message explicitly explain why the original formatting was incorrect - since this helps future readers understand the dependency between these options.

The technical content is uncontroversial and already approved, with the discussion now focused on polishing the commit message for maximum educational value. This documentation-only change affects only the man page formatting, with no code impact, and will likely be merged once these final wording tweaks are addressed.
