Core problem/goal: Prevent accidental exposure of sensitive data (credentials) during Git operations by requiring explicit authentication. Current version expands coverage beyond initial proposal, adds token validation, improves error handling, and includes documentation (English/French).

Current status: Version 2 prototype available on GitHub, now covering more operations (pull/fetch/submodules) than initial version. No maintainer feedback yet on integration path.

- Wrapper script intercepts sensitive commands
- Implements token validation checks
- Provides clear authentication failure messages
- Documentation includes French translation
- Exploring deeper Git integration options (new plumbing commands/flags)
