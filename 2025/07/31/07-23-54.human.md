This is part of a 5-patch series extending the promisor-remote protocol to support configurable validation of remote attributes during clone/fetch operations. The series is currently at v7 and appears technically complete, with this patch focusing on server-side functionality.

Currently supported fields are `partialCloneFilter` (specifying the remote's filter definition) and `token` (providing authentication credentials). The implementation:
- Adds documentation for the new config option
- Extends the protocol specification to describe field transmission
- Modifies the promisor-remote code to handle additional fields
- Includes tests verifying the new functionality

The changes are well-contained, with thorough documentation updates and test coverage. The implementation builds on previous refactoring work that introduced `struct promisor_info` for better type safety. While the patch is part of a larger series, it stands on its own as a coherent unit adding server-side field transmission capability.
