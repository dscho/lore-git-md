This is a refactoring patch in the promisor-remote protocol series, specifically addressing parsing improvements for advertised remote fields. The patch centralizes scattered parsing logic into a new `parse_one_advertised_remote()` function and improves memory handling through a new `promisor_info_free()` helper.

Junio Hamano provides a detailed review of the third patch in v7 of this series. He notes that while the current implementation using `string_list_split_in_place()` works (as the caller doesn't examine the modified buffer), it could be improved to preserve the original buffer contents for better error reporting. He suggests using `STRING_LIST_INIT_DUP` with regular `string_list_split()` instead, which would also eliminate the need for a `strbuf_strip_suffix()` call in the caller.

The review highlights how the refactoring makes the code more maintainable by:
1. Replacing manual parsing with structured population of `struct promisor_info`
2. Consolidating memory cleanup
3. Potentially removing redundant suffix stripping
4. Maintaining the same functionality while improving code organization

Junio concludes that the changes look promising, indicating this patch is nearing final form in the series. The review focuses on implementation details rather than the broader protocol changes, suggesting the core design decisions have stabilized.
