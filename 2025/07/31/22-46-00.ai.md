This is a refactoring patch that's part of Junio Hamano's v2 series improving Git's string-list API. The patch converts two error messages from `die()` to `BUG()` in `string-list.c` when invalid combinations of string list flags are detected in `string_list_split()` and `string_list_split_in_place()`. 

The change is straightforward - it replaces `die()` calls with `BUG()` for cases where the string list's `strdup_strings` flag doesn't match what the split function expects. This is clearly a programming error rather than a runtime condition, so `BUG()` is more appropriate. The commit message notes the error message could be more concise but leaves that for future improvement.

The patch touches only the two error reporting lines in `string-list.c`, keeping all other logic identical. This is the first of seven patches in the series, establishing a foundation for subsequent API improvements by properly classifying this error case. The change is uncontroversial and maintains backward compatibility while better expressing the intent that these are programming contract violations rather than recoverable errors.
