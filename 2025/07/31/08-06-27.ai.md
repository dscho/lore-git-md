This is a build system patch in the git-gui modernization series, specifically addressing the askpass helper's Tcl/Tk path handling. The patch converts git-gui--askpass from directly calling the system wish interpreter to being a generated script that properly uses TCLTK_PATH, matching git-gui's behavior.

The key technical changes include:
- Creating a new generate-script.sh that processes git-gui--askpass.sh at build time, substituting SHELL_PATH and TCLTK_PATH
- Updating Makefile and meson build rules to generate git-gui--askpass from the template
- Renaming git-gui--askpass to git-gui--askpass.sh to clarify its role as a template
- Adding proper dependency tracking in the build system

This implements part of the architectural decision to treat Tcl/Tk as a managed dependency rather than using system defaults. The change ensures consistent interpreter usage between git-gui and its askpass helper, addressing a long-standing inconsistency since 2008. The patch builds on the argv0-based askpass resolution approach that emerged as the consensus in the thread, though it doesn't yet address the open RUNTIME_PREFIX questions.

The implementation appears thorough, with proper build system integration in both Make and meson, and maintains backward compatibility while modernizing the infrastructure. This is part of the v2 series that has been converging on the argv0-based approach and removing deprecated bundle infrastructure.
