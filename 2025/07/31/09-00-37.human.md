This is a refactoring patch in the `git refs list` series, extracting core logic from `git for-each-ref` into a shared helper function. The patch creates a new `for-each-ref.h` header to house the common functionality that will be reused by the upcoming `git refs list` command.

The key change moves the option parsing, filtering, and formatting logic from `cmd_for_each_ref()` into a new `for_each_ref_core()` helper function. The original command becomes a thin wrapper that just defines its usage string and calls the helper. A new header file defines both the shared usage string macro (`COMMON_USAGE_FOR_EACH_REF`) and the helper function prototype.

This architectural change follows maintainer feedback from Junio Hamano to use a helper function pattern rather than direct command calls. The patch also fixes a documentation mismatch in the t0450 test by removing `for-each-ref` from the list of commands with help mismatches.

The implementation looks clean and well-motivated, with clear separation of concerns between the core logic and command-specific usage strings. This sets up the foundation for the subsequent `git refs list` implementation while maintaining all existing `for-each-ref` functionality. The patch has thorough mentoring from multiple Git contributors and appears ready for review.
