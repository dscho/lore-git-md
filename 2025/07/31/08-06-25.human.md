Build system patch fixing a Makefile dependency in git-gui's script generation.

This is a straightforward build system fix for git-gui, part of Carlo Arenas Belón's v2 series modernizing git-gui's platform support. The patch corrects a missing dependency in the Makefile - when the script generator (`generate-git-gui.sh`) was extracted from the Makefile in March 2025, it wasn't properly listed as a dependency for the main git-gui script generation. This means changes to the generator wouldn't trigger a rebuild of the main script.

The change is small (a one-line Makefile edit) but important for build correctness. It fits into the broader series' goal of cleaning up git-gui's build system and platform support. The patch appears well-scoped and uncontroversial, addressing a clear oversight in the build process.
