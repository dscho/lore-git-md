This is a build system discussion about integrating git-gui and gitk into Git's meson build system. Patrick Steinhardt responds to Carlo Arenas and Johannes Sixt about the current state of meson support for git-gui, noting that while the meson build works in isolation, full integration requires moving git-gui and gitk into a "subprojects/" directory - a potentially awkward change he's been hesitant to propose.

The email confirms the meson changes for git-gui look reasonable but highlights the remaining architectural hurdle: meson's requirement that subprojects live in a dedicated subdirectory. This would mean restructuring Git's source tree layout to accommodate git-gui and gitk as proper meson subprojects. Steinhardt has working patches but is cautious about proposing the directory move, suggesting this may be a broader discussion point for the project.

The message fits into the ongoing thread about modernizing git-gui's build system and platform support, where recent work has focused on removing deprecated bundle infrastructure and standardizing Tcl/Tk handling. The meson integration represents the final piece needed to complete this modernization effort.
