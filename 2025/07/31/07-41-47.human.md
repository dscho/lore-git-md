Refactoring patch in the string handling modernization series. This is the second of nine patches converting `strbuf_split*()` to `string_list_split*()` usage, focusing on `builtin/clean.c`.

The patch fixes a subtle bug in the interactive menu system of `parse_choice()` where a `strbuf` was being passed by value. While the function modified the buffer contents (replacing commas with spaces), the by-value passing could lead to memory corruption if the buffer needed reallocation. The fix changes the parameter to pass by pointer instead.

This is a clear improvement that prevents a potential double-free scenario. The change is mechanical but important, demonstrating the kind of subtle issues that can arise with string handling. The patch maintains all existing functionality while making the code safer. It's a straightforward change that fits well with the series' goal of modernizing string processing.
