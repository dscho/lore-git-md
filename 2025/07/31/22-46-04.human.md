This is a refactoring patch that simplifies the parsing of `diff.colormovedws` configuration by leveraging the new string-list API improvements from earlier in the series.

Patch 5/7 in Junio Hamano's string-list refactoring series demonstrates the practical benefits of the API changes. The diff code previously had to manually trim whitespace from configuration values after splitting them, using temporary strbufs. Now it can use the new `STRING_LIST_SPLIT_TRIM` flag to handle this automatically during the split operation.

The change reduces the diff.c parsing code by 13 lines while maintaining identical functionality. Each configuration value ("ignore-space-change", "ignore-all-space", etc.) is now compared directly from the string list without intermediate strbuf manipulation. The patch is a clean example of how the series' API unification allows for simpler caller code.

This appears to be a straightforward application of the new API with no behavioral changes. The patch is well-contained and builds logically on the foundation established by earlier patches in the series.
