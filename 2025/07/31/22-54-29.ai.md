- Uses `STRING_LIST_INIT_DUP` for the string list
- Splits on "=" with max splits=1 (producing up to 2 pieces)
- Preserves validation of empty keys
- Keeps the same config parsing behavior via `config_parse_pair()`
- Notes the awkward API design of `string_list_split()`'s max parameter
