This is part 8 of a 9-part refactoring series converting `strbuf_split*()` to `string_list_split*()` usage across Git's codebase. The patch focuses on `environment.c`'s namespace handling.

The change modifies `get_git_namespace()` to use `string_list_split()` when processing the GIT_NAMESPACE environment variable, which contains slash-separated path components. The key improvement is replacing the temporary `strbuf` array with a simpler `string_list` since the split components don't need modification. The new version maintains identical behavior of:
- Skipping empty components (from double slashes)
- Constructing proper "refs/namespaces/" paths
- Validating the final path format

The code becomes slightly more straightforward by eliminating manual memory management of the split components while reducing line count (-7/+12). This follows the series' pattern of mechanical but thoughtful conversions that preserve behavior while modernizing string handling.
