Refactoring patch in the string handling modernization series. This is part 4 of 11 in Junio Hamano's series to replace `strbuf_split*()` with more appropriate alternatives.

The patch converts `builtin/clean.c`'s interactive exclude pattern handling to use `string_list_split_in_place_f()` with trimming, eliminating the need for manual `strbuf` management. The changes:
- Replace `strbuf_split_max()` with `string_list_split_in_place_f()`
- Use `STRING_LIST_INIT_NODUP` and `STRING_LIST_SPLIT_TRIM` flags
- Simplify the pattern processing loop by working directly with string_list items
- Maintain all existing functionality for reading and applying exclude patterns
- The change follows the series' pattern of reducing manual memory management while preserving behavior
- Net change is +11/-9 lines, continuing the series' trend of code reduction
- Part of a larger, well-reviewed effort to modernize string handling across Git's codebase

This appears to be a straightforward conversion that makes the code both safer and more maintainable, following established patterns from earlier patches in the series.
