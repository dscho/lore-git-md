This is a preparatory patch in Patrick Steinhardt's performance optimization series for remote ref renaming. It addresses compiler warnings about signed/unsigned integer comparisons in `builtin/remote.c`.

The patch systematically fixes -Wsign-comparison warnings by changing loop counters to use `size_t` where appropriate, matching the types used by the string_list and strvec APIs they interact with. The changes include:
- Removing the `DISABLE_SIGN_COMPARE_WARNINGS` define that was suppressing these warnings
- Converting `int i` loop counters to `size_t` when iterating over string_list items
- Keeping `int` counters where interacting with APIs that expect signed integers (like remote->push.nr)
- The changes are mechanical and focused on type correctness without altering behavior
- Touches multiple functions in `builtin/remote.c` including `add()`, `migrate_file()`, `mv()`, `rm()`, and others
- Maintains consistency with the broader refactoring effort in this series

This is part of the larger effort to optimize remote operations that has shown dramatic performance improvements (238s->2s for files backend). The patch follows up on earlier preparatory work and precedes the main performance fixes in the series. It addresses feedback from the initial version by properly handling sign comparison warnings rather than suppressing them.
