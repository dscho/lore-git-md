Build system patch fixing a Makefile dependency in git-gui's script generation. This is part of the ongoing git-gui modernization series (v2 2/5) that's restructuring platform support and build infrastructure.

The patch corrects an oversight from commit 854e883 where the script generator (`generate-git-gui.sh`) wasn't listed as a dependency for the main `git-gui` script. Without this, changes to the generator wouldn't trigger a rebuild of the main script. The fix adds the missing dependency line in the Makefile.

Key technical details:
- Touches `Makefile` to include `generate-git-gui.sh` as a dependency for `$(GITGUI_MAIN)`
- Follows the pattern already established for other dependencies (GIT-VERSION-FILE, GIT-GUI-BUILD-OPTIONS)
- Maintains the same generation command and quiet flag behavior

This is a straightforward build system fix that ensures the git-gui script properly rebuilds when its generator logic changes. It's part of the larger effort to clean up git-gui's build infrastructure, particularly around script generation and platform support. The change is small and focused, with no apparent controversy or open questions.
