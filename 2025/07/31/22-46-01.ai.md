This is part 2/7 of Junio Hamano's string-list API refactoring series (v2), focusing on unifying the behavior between `string_list_split()` and `string_list_split_in_place()`. The patch changes `string_list_split()` to accept a string delimiter parameter (e.g. `","`) rather than just a single character, matching the existing `_...in_place()` variant. This is a preparatory change before adding new features in later patches.

The technical changes include:
- Modifying the function signature in string-list.h to take `const char *delim` instead of `int delim`
- Updating the implementation in string-list.c to use `strpbrk()` instead of `strchr()`
- Adjusting 19 callers across the codebase to pass string delimiters
- Updating documentation and tests to reflect the new behavior
- Maintaining backward compatibility in behavior while expanding the interface
