This is a refactoring patch in the string handling modernization series, specifically targeting the trace2 subsystem (patch 10/11). The change removes redundant calls to `strbuf_trim_trailing_newline()` when immediately followed by `strbuf_trim()`, since the latter already handles newline trimming as part of its whitespace removal.

The patch modifies two functions in `trace2/tr2_cfg.c` that process configuration patterns and environment variables:
- `tr2_cfg_load_patterns()`
- `tr2_load_env_vars()`

In both cases, the code was first trimming trailing newlines and then doing a full trim, which is unnecessary since `strbuf_trim()` already removes all trailing whitespace including newlines. The change maintains identical behavior while simplifying the code by removing the redundant operation. The patch follows the series' pattern of cleaning up string handling while preserving functionality.
