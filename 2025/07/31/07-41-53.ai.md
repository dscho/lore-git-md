Part 8 of the string_list refactoring series, converting namespace handling in environment.c. This patch replaces `strbuf_split()` with `string_list_split()` in `get_git_namespace()`, which processes the GIT_NAMESPACE environment variable to construct refs/namespaces/ paths.

The key changes are:
- Switches from allocating an array of strbufs to using a string_list
- Simplifies the path construction loop with `for_each_string_list_item()`
- Adds explicit trailing slash trimming (previously handled implicitly by strbuf_split)
- Maintains the same behavior of skipping empty components from double slashes
- Reduces code by 7 lines while adding 5 (net -2)

The conversion follows the series' pattern of replacing strbuf memory management with string_list's automatic handling. The patch preserves all existing functionality including:
- Empty component skipping
- Refname format validation
- Trailing slash handling
- Static namespace caching

This continues the mechanical but careful refactoring approach seen throughout the series, with each change clearly motivated by string_list's better fit for the task. The patch demonstrates string_list's advantages for simple string splitting cases where the components don't need individual modification.
