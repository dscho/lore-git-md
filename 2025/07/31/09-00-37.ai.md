This is a refactoring patch that extracts core logic from `git for-each-ref` into a shared helper function, part of the ongoing effort to introduce `git refs list` as a thin wrapper. The patch creates a new `for-each-ref.h` header containing the shared `for_each_ref_core()` function and a `COMMON_USAGE_FOR_EACH_REF` macro for standardized option documentation.

The implementation moves all option parsing, filtering, and formatting logic from `cmd_for_each_ref()` into the new helper function, which accepts the command's usage string as a parameter. The original command becomes a thin wrapper that just defines its specific usage array and calls the shared helper. This architectural change follows Junio Hamano's preferred pattern and addresses prior feedback about code sharing.

Key technical elements include:
- New `for-each-ref.h` header with public interface
- `for_each_ref_core()` helper that takes usage strings as parameter
- `COMMON_USAGE_FOR_EACH_REF` macro consolidating shared option documentation
- Removal of a pre-existing documentation test mismatch (t0450 entry)

The patch demonstrates clean separation of concerns and proper header-based sharing of functionality, addressing one of the core architectural requirements for the `git refs list` introduction. It builds on the v4 series' documentation improvements while maintaining backward compatibility. The changes are focused and well-contained, touching only the necessary files with clear, mechanical transformations.
