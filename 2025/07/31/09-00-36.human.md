Documentation patch that factors out common options for ref listing commands. This is the first of five patches in a series introducing `git refs list` as a wrapper around `git for-each-ref`.

The patch extracts all option documentation from `git-for-each-ref.adoc` into a new shared file `for-each-ref-options.adoc`, replacing the original content with an include directive. This is a clean refactoring with no functional changes to the rendered documentation, preparing for the new `git refs list` command to share these same options in its documentation.

The change follows established patterns for documentation sharing in Git and has been reviewed by multiple mentors. As the first patch in the series, it sets up the documentation foundation that subsequent patches will build upon when adding the new command. The approach appears well-considered and maintains existing documentation quality while enabling future sharing.
