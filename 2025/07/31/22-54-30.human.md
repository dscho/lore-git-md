This is part 8 of an 11-patch refactoring series converting Git's string handling from `strbuf_split*()` to more appropriate alternatives. The patch focuses on `environment.c`'s namespace handling.

The change replaces `strbuf_split()` with `string_list_split()` when processing Git namespaces from environment variables. The key improvements are:
- Uses `STRING_LIST_INIT_DUP` for cleaner string list initialization
- Simplifies path construction using `for_each_string_list_item()`
- Explicitly trims trailing slashes with `strbuf_trim_trailing_dir_sep()`
- Maintains all existing functionality (empty component skipping and refname validation)
- Reduces code by 2 lines (19->17)

This follows the series' pattern of replacing manual string handling with more robust utilities while preserving behavior. The change is straightforward and aligns with the overall goal of modernizing Git's string processing code.
