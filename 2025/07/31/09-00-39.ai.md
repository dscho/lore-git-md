This is a test refactoring patch in the `git refs list` RFC series (v4 4/5). The patch prepares the test infrastructure for the new `git refs list` command by making the existing `for-each-ref` test logic shareable.

The key changes are:
- Moves core test logic from `t6300-for-each-ref.sh` to new `for-each-ref-tests.sh`
- Replaces hardcoded `git for-each-ref` calls with `$git_for_each_ref` variable
- Makes original test file a simple wrapper that sets the variable and sources the library
- Follows pattern used for sharing tests between `git-blame` and `git-annotate`

The refactoring enables the same test suite to be reused for testing the new `refs list` command in subsequent commit. The actual test cases and assertions remain unchanged - this is purely an organizational change to support testing both commands with the same test logic.

The patch builds on prior work in the series that established the shared `for_each_ref_core()` helper and documentation infrastructure. It maintains all existing test coverage while setting up for the new command's tests. The implementation follows established patterns in the codebase and has been reviewed by multiple contributors as noted in the mentored-by tags.
