This is the implementation patch for the new `git refs list` subcommand in the refs consolidation series. It builds on the architectural foundation established in previous patches, specifically the shared `for_each_ref_core()` helper function extracted from `git for-each-ref`.

The patch adds the `list` subcommand to `git-refs` with identical functionality to `git-for-each-ref`, implemented as a thin wrapper around the shared core logic. The documentation includes all the same filtering, sorting and formatting options via an included shared options file (`for-each-ref-options.adoc`), maintaining consistency with the existing command while consolidating the interface under the `git refs` umbrella.

Key technical elements:
- New `cmd_refs_list()` function in builtin/refs.c that calls `for_each_ref_core()`
- Usage string synchronization via the `COMMON_USAGE_FOR_EACH_REF` macro
- Documentation integration using AsciiDoc's include directive to share option descriptions
- Explicit declaration of the command as an equivalent to `git-for-each-ref`

The implementation follows the series' architectural approach of factoring out common logic while maintaining existing behavior. This patch represents the main user-facing addition of the series, providing the new consolidated interface while internally reusing the thoroughly tested core ref listing functionality. The changes are minimal and focused, building on the preparatory work done in earlier patches to extract and share the common components.
