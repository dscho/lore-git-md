This is a v2 resubmission of a 5-patch series addressing git-gui's macOS compatibility issues, particularly around the deprecated Tcl/Tk 8.5 framework. The series represents a key architectural decision point in the ongoing git-gui platform modernization effort.

The core changes focus on removing the broken "Git Gui.app" bundle (patch 3) and improving askpass helper handling (patches 4-5). The most significant update from v1 is in patch 5, which now uses Mark Levedahl's suggested argv0-based approach for locating the askpass helper rather than the previous git exec-path method. This better handles cases where git-gui might be invoked via a different Git installation than expected.

Technical details of note:
- Complete removal of macOS-specific app bundle infrastructure (generate-macos-*.sh scripts, AppMain.tcl, Info.plist)
- New generate-script.sh consolidates script generation logic
- Askpass resolution now uses `[file dirname [file normalize $::argv0]]` to find colocated helper
- Makefile cleanup removes obsolete uname_O handling
- Meson build updates included but not fully integrated

The series directly addresses the thread's core architectural question by opting for a third-party Tcl/Tk solution rather than trying to work with macOS's system framework. The askpass changes resolve a specific pain point where Xcode-provided git includes a broken askpass helper. The implementation appears technically sound with clean diffs and reasonable test coverage.
