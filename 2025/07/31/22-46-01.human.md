Refactoring patch in Junio Hamano's string-list API series (v2 2/7). This patch aligns the `string_list_split()` function with its `_in_place()` counterpart by allowing it to accept multiple delimiter characters, rather than just a single character. The change makes the two functions more consistent before additional features are added in later patches.

The patch updates 19 files across the codebase where `string_list_split()` is called, changing single-character delimiters (like `','`) to string versions (`","`). The implementation now uses `strpbrk()` to handle multiple delimiters. Documentation is updated to reflect that the delimiter parameter can now be a string of characters.

This is a straightforward mechanical change that improves API consistency with no expected behavior changes. The patch is well-scoped and follows the series' pattern of methodical string-list API improvements. All test cases are updated to match the new calling convention.
