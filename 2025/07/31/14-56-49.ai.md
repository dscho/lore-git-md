This is a preparatory refactoring patch in Patrick Steinhardt's performance optimization series for remote ref renaming. It standardizes the reflog callback interface (`each_reflog_ent_fn`) across 17 files by adding a `const char *refname` parameter. 

The change makes the reference name directly available to callback functions rather than requiring callers to pass it through callback data. This eliminates awkward bookkeeping in cases where code needs to track which reference it's currently processing. The patch updates all existing callbacks, with most simply marking the new parameter as UNUSED since they don't need it yet. The following patch will leverage this change to simplify reference migration logic.

The mechanical changes touch core refs handling code (`refs.[ch]`), all ref backends (files and reftable), and various commands that process reflogs (`fsck`, `gc`, `stash`, etc.). The patch maintains backward compatibility while setting up for future simplifications, with no behavior changes in this initial step. This foundational change enables more readable and maintainable code in subsequent patches of the series.
