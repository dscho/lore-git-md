This is a preparatory refactoring patch in a performance optimization series for remote ref operations. The patch modifies the reflog iteration callback interface to include the reference name as a parameter, eliminating the need for callers to track this information separately. 

The change standardizes the callback signature (`each_reflog_ent_fn`) across 17 files, with Karthik Nayak confirming it addresses pain points he encountered in the migration code. While primarily a refactoring, this enables simplifications in subsequent patches that optimize remote ref renaming operations. The patch has already received positive review from Justin Tobler and Karthik, with Patrick Steinhardt incorporating minor formatting suggestions but deciding not to respin just for these cosmetic changes.

Technical details: The modification adds a `const char *refname` parameter to the callback function used by `refs_for_each_reflog_ent()`. This affects multiple files including `refs.h`, `reflog-walk.c`, and various builtin commands that process reflogs. The change is backwards-compatible with existing callback implementations since they can simply ignore the new parameter. This preparatory work directly enables the second patch in the series to simplify the reflog migration logic by removing the need for manual refname tracking.
