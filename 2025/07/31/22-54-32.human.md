The change recognizes that `strbuf_trim()` already handles newlines along with other whitespace, making the separate `strbuf_trim_trailing_newline()` calls unnecessary. The modification affects two functions in `trace2/tr2_cfg.c` that parse configuration patterns and environment variables, maintaining the same end result while making the code slightly simpler (-2 lines). This follows the series' pattern of replacing manual string handling with more robust utilities, though in this case it's more about removing redundant operations than switching to a different API. The change is straightforward and unlikely to be controversial.
