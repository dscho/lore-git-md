[PATCH v2] git send-email: add IMAP folder archiving for sent messages

This patch series by Aditya Garg introduces IMAP folder archiving to `git send-email`, solving the problem of email providers (notably iCloud Mail) that don't save SMTP-sent messages to Sent folders. The implementation adds `sendemail.imapfolder` config and `--imap-folder` CLI option to pipe successfully sent messages to `git imap-send` for IMAP storage.

Technical scope spans Perl and C:
- `git-send-email.perl` collects messages during SMTP sending and batches them to `imap-send`
- `imap-send.c` adds special handling for "From git-send-email" prefixed messages to preserve headers including Bcc
- Documentation explains the new workflow and IMAP credential setup
