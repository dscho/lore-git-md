[PATCH] git send-email: add IMAP folder archiving for sent messages

This patch series introduces IMAP folder archiving to `git send-email`, addressing a limitation where some email providers (notably iCloud Mail) don't save SMTP-sent messages to Sent folders. The core change adds a new `sendemail.imapfolder` config option and `--imap-folder` command-line flag that, when set, pipes successfully sent messages to `git imap-send` for storage in the specified IMAP folder.

Technical implementation modifies both Perl and C code:
- `git-send-email.perl` collects messages during SMTP sending and batches them to `imap-send` after successful transmission
- `imap-send.c` adds special handling for "From git-send-email" prefixed messages to properly parse headers including Bcc (which SMTP normally strips)
- Documentation updates explain the new workflow and required IMAP credential setup

The feature is opt-in and maintains backward compatibility when not configured. Key considerations for review:
- Whether this functionality belongs in core vs remaining external
- Robustness of IMAP connection failure handling
- Header preservation requirements (particularly for Bcc fields)

The implementation appears thorough with clear documentation and edge case handling. No reviews or objections have been raised yet in this new thread.
