[PATCH v4] git send-email: add IMAP sent-folder archiving with pure-IMAP mode

Aditya Garg's series implements IMAP-based message archiving in `git send-email`, now supporting both SMTP+archive and pure-IMAP workflows. The v4 iteration fixes the dry-run bug from v3 while adding the previously theoretical "B2" pure-IMAP mode as a fully implemented feature. Core functionality spans `git-send-email.perl` (message routing) and `imap-send.c` (header handling), maintaining the "imap-sent-folder" terminology settled in v3.

Key technical details:
- Config option: `sendemail.imapSentFolder` (backward-compatible)
- CLI flags: `--imap-sent-folder` (archive path), `--no-smtp` (pure-IMAP mode)
- Preserves Bcc headers in archive copies
- Dry-run protection: No IMAP operations during `--dry-run`
- Pure-IMAP mode: Archive messages without SMTP transmission
- Parameter accepts any valid IMAP folder name (not restricted to "Sent" folders)
