This is a feature patch adding IMAP folder support to `git send-email`. 

Aditya Garg proposes adding the ability to save copies of sent emails to an IMAP folder when using `git send-email`. This addresses a limitation with some email providers (like iCloud Mail) that don't automatically copy SMTP-sent messages to the Sent folder. The patch introduces a new `sendemail.imapfolder` config option and `--imap-folder` command-line flag to specify the destination folder.

The implementation pipes the sent messages to `git imap-send` after successful SMTP delivery, including proper handling of Bcc headers which are normally stripped. The documentation is thorough, explaining the feature and noting the requirement to have `git imap-send` properly configured.

The patch appears well-constructed with clear motivation, complete documentation updates, and careful handling of edge cases. It touches four files: two documentation files to explain the new feature, the main send-email script to implement the functionality, and a small modification to imap-send.c to properly handle the message counting for send-email's special "From git-send-email" header.

This would be particularly useful for developers who use email providers with this SMTP limitation and want to maintain proper sent mail archives when contributing to Git projects via email. The implementation follows existing patterns in the codebase and includes appropriate warnings about the dependency on imap-send configuration.
