Aditya Garg's series adding IMAP sent-folder archiving to `git send-email` has reached its final form after five iterations. The feature supports two workflows: the original SMTP-with-archive approach and a new pure-IMAP mode that archives messages without SMTP transmission. The implementation spans both Perl and C components, with careful attention to dry-run behavior and Bcc header preservation.

Junio C Hamano provided key input on naming ("imap-sent-folder") and documentation standards, while Eric Sunshine contributed documentation polish. The v5 iteration completes all requested changes, including the final documentation formatting adjustment that splits the `--use-imap-only` flag into separate entries to match Git's style. With all technical and stylistic issues now resolved, the series appears ready for merging. The pure-IMAP mode addition strengthens the feature's utility, particularly for users needing to work within IMAP-only environments while retaining `send-email`'s formatting capabilities.
