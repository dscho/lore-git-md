This thread introduces a new feature for `git send-email` that addresses a common pain point with email providers like iCloud Mail that don't automatically save SMTP-sent messages to Sent folders. The proposed solution adds IMAP folder archiving capability through a new `sendemail.imapfolder` config option and `--imap-folder` command-line flag. When enabled, successfully sent messages are piped to `git imap-send` for storage in the specified IMAP folder.

The implementation carefully handles technical challenges like preserving Bcc headers (which SMTP normally strips) by adding special processing in both the `git-send-email.perl` and `imap-send.c` components. The v2 iteration maintains all the functionality from the initial proposal while making minor cosmetic improvements to indentation and commit message wording. 

The feature is designed to be opt-in and backward compatible, with clear documentation explaining the new workflow and required IMAP credential setup. The changes are well-contained to the email-sending workflow without broader architectural impacts. So far there haven't been any reviews or objections to the proposal, suggesting the implementation may be on the right track. The author appears responsive to feedback, having already incorporated minor improvements between versions.
