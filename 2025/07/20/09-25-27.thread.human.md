Aditya Garg has proposed adding IMAP folder archiving to `git send-email`, addressing a limitation where some email providers (like iCloud Mail) don't automatically save SMTP-sent messages. The patch introduces a new `sendemail.imapfolder` config option and corresponding `--imap-folder` flag that, when enabled, will use `git imap-send` to store copies of successfully sent messages in the specified IMAP folder.

The implementation carefully preserves all headers (including Bcc) by piping messages to `imap-send` after SMTP transmission completes. The change requires proper IMAP credential setup as documented in `git-imap-send` but maintains full backward compatibility when not configured. The patch includes both Perl and C code modifications to support this workflow, with special handling in `imap-send.c` for messages prefixed with "From git-send-email".

This appears to be a well-considered solution to a real-world workflow problem, with thorough documentation and attention to edge cases. The main open question is whether this functionality belongs in core `send-email` or should remain external, and whether the IMAP integration could be made more robust against connection failures. The patch is currently at version 1 and awaits review feedback.
