This is the first patch in Patrick Steinhardt's 21-part series removing `the_repository` global variable usage from Git's config subsystem. The patch mechanically converts all calls to the `git_config()` wrapper function to use `repo_config(the_repository, ...)` instead.

The change is purely mechanical - it doesn't introduce any functional changes but makes the repository dependency explicit at each callsite. The patch touches 118 files across the codebase, showing how widely used the config API is. The commit message explains this is part of a planned transition where these sites may later be updated to use specific repository instances rather than the global.

The patch appears well-executed - it's a straightforward conversion that maintains the current behavior while moving toward the long-term goal of removing `the_repository`. The series has already gone through one revision addressing feedback, and this initial patch sets the foundation for the more substantive changes that follow in the series.
