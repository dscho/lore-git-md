This is a build system patch finalizing the PCRE2 dependency handling solution for macOS in the meson build system. The patch implements the agreed-upon approach to detect and work around broken system PCRE2 installations on macOS, where the system-provided pkgconf module incorrectly points to a non-existent header. The solution uses meson's `compiler.has_header()` verification for system PCRE2, with three behavior modes: explicit enable (fallback to built-in), auto (disable with warning if broken), and disabled (no action). Windows behavior remains consistent with cmake builds by keeping PCRE2 enabled by default there.

The implementation follows Eli Schwartz's suggestions and incorporates feedback from Carlo Arenas, who confirmed the macOS verification works and identified edge cases. Eric Sunshine provided editorial improvements. The patch changes the default meson option from 'enabled' to 'auto' while maintaining static linking preference. It handles the specific macOS case where the system's pcre2.h points to /usr/local/include incorrectly.
