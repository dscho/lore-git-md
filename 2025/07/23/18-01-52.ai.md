This is a documentation patch finalizing the project's position on C99 compound literals, following up from the earlier discussion thread. The documentation serves both to record this experimental usage and provide clear guidance to contributors.

This email represents the final step in formalizing the thread's consensus - Junio acknowledges Phillip Wood's agreement with the documentation approach and takes responsibility for implementing it.
