This is part 7 of Patrick Steinhardt's 21-patch series removing `the_repository` global variable usage in Git's config subsystem. The patch removes the `git_config_get_string()` wrapper function, converting all callers to explicitly use `repo_config_get_string(the_repository, ...)` instead.

The change follows the established pattern from earlier patches in the series, making repository dependencies explicit while maintaining identical behavior. The patch updates 12 files across various subsystems including apply, branch, gc, log, submodule handling, and transport. Each conversion is mechanical - replacing the wrapper call with its explicit counterpart while passing `the_repository`.

The commit message notes this is an intermediate step - while some callers could potentially use a different repository instance, that optimization is left for future work. The patch maintains the series' disciplined approach, focusing narrowly on removing one wrapper function while keeping behavior unchanged.

This continues the systematic elimination of config-related wrappers that obscure repository dependencies, improving code clarity in preparation for fully removing `the_repository`.
