This is a documentation patch that formalizes Git's policy around test balloons for new C language features, specifically addressing the ongoing evaluation of C99 compound literals.

Junio C Hamano adds a new section to CodingGuidelines that documents the project's approach to cautiously adopting new C features. The patch establishes that new features first undergo a trial period in designated "test balloon" code - small, stable sections that all builds must compile. The reftable subsystem's use of compound literals (introduced in v2.48) serves as the current test case, with a moratorium on wider use until mid-2026 to evaluate platform compatibility.

The documentation provides clear guidance for contributors while acknowledging Phillip Wood's earlier work on this topic. It follows through on the thread's consensus by recording the experimental status of compound literals and setting expectations for future adoption. The patch serves as the authoritative conclusion to the discussion, codifying both the current restrictions and the evaluation timeline.
