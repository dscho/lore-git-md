This is Junio Hamano's monthly "What's cooking in git.git" status update, summarizing the state of various patches and topics in the Git development pipeline as of July 2025. These emails provide a high-level overview of what changes are being considered for inclusion in future Git releases.

The update covers several categories of changes that have either graduated to the main branches or are still under review. Notable highlights include:

1. Graduated changes now in 'master':
   - SHA-256 hash becoming the default in breaking changes mode (bc/use-sha256-by-default-in-3.0)
   - Various documentation updates and mark-up improvements
   - Build system cleanups for Meson-based builds
   - Fixes for handling remote name collisions and GPG program path expansion

2. New topics under consideration:
   - Config options for pull.autostash behavior (ly/pull-autostash)
   - IMAP-related improvements for send-email and documentation (ag/imap-send-list-folders-doc, ag/send-email-imap-sent)
   - Merge strategy fixes for the "ort" backend (en/ort-rename-fixes)
   - Removal of the experimental status for git-switch and git-restore (jt/switch-restore-no-longer-experimental)

3. Ongoing work:
   - Continued efforts to remove reliance on the_repository global (ps/config-wo-the-repository, ps/object-file-wo-the-repository)
   - Sparse-checkout improvements including a new 'clean' command (ds/sparse-checkout-clean)
   - Multi-pack-index and object store refactoring (ps/object-store-midx)
   - New commands like "git last-modified" for file history (tc/last-modified)

The email follows Junio's standard format, marking which topics are stable enough for 'next' (candidates for the next release), which are still in 'seen' (under active development), and which may need rerolls or have outstanding questions. Several topics are noted as being part of larger ongoing efforts like the SHA-256 transition and the_repository removal.
