Feature implementation for `git send-email` adding IMAP-based sent mail archiving.

This patch introduces the ability for `git send-email` to archive sent messages to an IMAP folder, addressing cases where email providers (like iCloud Mail) don't automatically save SMTP-sent messages to the Sent folder. The implementation adds a new `sendemail.imapSentFolder` config option and `--imap-sent-folder` command-line flag to specify the destination folder.

The patch modifies both `git-send-email.perl` (to capture sent messages and pipe them to `git imap-send`) and `imap-send.c` (to handle the special "From git-send-email" header format). It preserves Bcc headers in the archived copies while ensuring they remain hidden from recipients, and skips IMAP operations during dry runs.

This appears to be a well-considered implementation with thorough documentation updates. The commit message clearly explains the motivation (iCloud Mail's SMTP limitations) and the solution mirrors behavior found in clients like Thunderbird. The patch is part of a series that has evolved through several iterations with maintainer feedback, suggesting it's nearing readiness for inclusion.
