This is a feature patch for `imap-send` that adds an option to control whether sent messages are marked as read or unread. The patch introduces a new `--mark-seen` flag that sets the `CURLULFLAG_SEEN` flag when uploading messages via libcurl's IMAP support.

The thread context shows Junio Hamano raised two concerns: first about the style of using braces around single-statement blocks (which appears to be a minor formatting issue), and second about the version requirement - while the patch uses `CURLULFLAG_SEEN` which was introduced in curl 8.13.0, Git only requires curl 7.61.0. The author acknowledges this version mismatch but downplays its importance, calling it "not a very important feature."

Key technical details: the patch adds a new `mark_seen` boolean parameter to `append_msgs_to_imap()` and uses `CURLOPT_UPLOAD_FLAGS` with either `CURLULFLAG_SEEN` or `0L` depending on the flag.
