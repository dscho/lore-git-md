This is a feature patch series (v3) introducing `git refs list` as a modern wrapper around `git for-each-ref`, part of a broader effort to consolidate ref-related commands under a unified `git refs` namespace. The series comes from GSoC participant Meet Soni with mentoring from Patrick Steinhardt and others.

The v3 iteration addresses previous maintainer concerns by restructuring the test approach to follow Git's established patterns for shared test logic. The core test cases now live in a new `for-each-ref-tests.sh` file that's sourced by both the original `for-each-ref` tests and the new `refs list` tests, replacing the previous environment variable approach that raised readability concerns. The implementation remains a thin wrapper forwarding all arguments to `for-each-ref` to ensure identical behavior.

The cover letter explains the long-term vision: while this initial patch maintains strict compatibility, the consolidation under `git refs` could eventually allow for cleaning up legacy options and improving the interface. The series is deliberately conservative, focusing first on proving the wrapper approach works before considering any behavior changes.

The patch organization has been refined in v3, splitting the changes into three logical commits: the core implementation, test refactoring, and new test addition. Documentation has also been updated, incorporating earlier feedback about shared option syntax and man page conventions. The series appears well-considered and responsive to maintainer input, with the test infrastructure concerns from v2 now addressed through established patterns.
