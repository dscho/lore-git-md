This is a documentation patch that formalizes Git's policy around testing new C99 language features before widespread adoption. Junio C Hamano adds a section to CodingGuidelines explaining the "test balloon" approach used for evaluating C99 compound literals, with the reftable subsystem's usage (introduced in v2.48.0-rc0~20) serving as the current test case.

The patch documents that compound literals (like `(struct foo){ .member = value }`) are under evaluation until mid-2026, with a moratorium on additional usage until then. This codifies the thread's consensus while maintaining the reftable macros (`REFTABLE_FLOCK_INIT` and `REFTABLE_TMPFILE_INIT`) as the only permitted usage during the evaluation period. The documentation serves as both a record of the experimental status and guidance for contributors, explicitly forbidding new compound literal usage outside the designated test sites.

The patch references the specific commit where the reftable macros were introduced and follows the discussion pattern where Phillip Wood raised initial concerns about resource management with compound literals. By documenting this as an active test balloon with a clear timeline, the patch provides a framework for future evaluation of C99 features while maintaining the project's conservative approach to language feature adoption.
