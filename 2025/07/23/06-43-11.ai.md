Feature implementation adding `git refs list` as part of the ref command consolidation effort. This is the first patch in v3 series that introduces a thin wrapper around `git for-each-ref` with identical functionality but under the new `git refs` hierarchy.

The implementation forwards all arguments to `cmd_for_each_ref` while maintaining the same behavior, avoiding logic duplication. Key changes include:
- New `cmd_refs_list` function in `builtin/refs.c` that constructs arguments for `cmd_for_each_ref`
- Shared option parsing between both commands via modified `cmd_for_each_ref` that checks argv[0]
- Documentation restructuring with new `refs-list-options.adoc` containing shared option definitions included in both man pages
- Usage string synchronization between the two commands
