This occurs even when explicitly disabling external diff tools with `--no-ext-diff`.

The report also notes a separate but possibly related issue where the external diff tool difftastic appears to completely ignore the `--ignore-matching-lines` option. It's unclear whether this is a limitation in difftastic itself or a problem with how Git passes this option to external diff helpers. 

The core issue seems to be that these two options don't interact as one might expect, and this behavior isn't documented. The reporter hasn't proposed a fix but has provided enough detail to reproduce the issue. This appears to be either an implementation oversight or an undocumented limitation in how these options interact. The external diff helper aspect may require separate investigation.
