This is part 4 of Patrick Steinhardt's 21-patch series removing `the_repository` global variable usage from Git's config subsystem. The patch specifically removes the `git_config_get_value()` wrapper function, converting all callers to use `repo_config_get_value(the_repository, ...)` instead.

The change is mechanical and maintains identical behavior - it simply makes the repository dependency explicit at each call site. The patch updates 5 files (gc.c, pull.c, rebase-interactive.c, test-config.c, and config.h) with straightforward replacements. The commit message notes that while some callers could potentially use a different repository instance, that optimization is left for future work.

This continues the pattern established in earlier patches of the series, following the groundwork laid in commit 036876a1067. The changes appear clean and focused, with each caller being converted in a consistent way. The patch maintains test coverage through updates to the test helper code.

As with previous patches in the series, this is a refactoring change with no intended behavior difference, just making implicit dependencies explicit as part of the larger `the_repository` removal effort.
