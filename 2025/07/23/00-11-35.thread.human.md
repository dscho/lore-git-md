Junio Hamano's latest "What's cooking" report provides a snapshot of Git's current development landscape. The SHA-256 hash algorithm becoming the default in breaking changes mode has now graduated to 'master', marking a significant milestone in Git's multi-year transition away from SHA-1. Other notable changes that have reached 'master' include improvements to daemon signal handling and documentation formatting updates.

Several substantial refactoring efforts continue to progress, including Patrick Steinhardt's work to remove `the_repository` global variable from the config API and ongoing object store abstraction. New command proposals like `git last-modified` and `git repo` are under consideration, while Elijah Newren's merge-ort strategy sees further refinement with rename handling fixes. The report also highlights work on a sparse-checkout clean command and various documentation improvements.

Junio's update clearly delineates which topics are stable (in 'next'), experimental (in 'seen'), or need further review. Many changes are marked as ready to progress to 'next' or 'master', while others await additional feedback or revised patches. This comprehensive overview gives developers visibility into what changes will likely land in upcoming Git releases.
