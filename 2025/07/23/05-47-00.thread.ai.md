Technical analysis revealed the behavior stems from `diffcore_std()` not applying ignore_regex filtering to file pairs, with filtering only in `builtin_diff()`.

Junio C Hamano provides authoritative design principle: metadata-focused outputs like `--name-only` and `--raw` deliberately avoid examining blob contents when possible for performance. Content-ignoring options shouldn't affect metadata outputs as it would make answers pathologically dependent on ignore patterns.
