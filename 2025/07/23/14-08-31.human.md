This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global variable usage, specifically targeting config-related functionality. Patch 10/21 removes the `git_config_get_ulong()` wrapper function, converting all its callers to use `repo_config_get_ulong(the_repository, ...)` instead.

The changes are mechanical and follow the same pattern as previous patches in the series, making repository dependencies explicit while maintaining identical behavior. The patch affects configuration handling in several areas: pack size limits in fast-import, garbage collection thresholds, and HTTP request buffer sizes. 

The conversion is straightforward and low-risk, touching only 4 files with simple substitutions. Like earlier patches in the series, this leaves potential optimizations (using actual repository parameters when available) for future work. The changes align with the project's direction to eliminate implicit global state, and the patch appears to be progressing smoothly through review.
