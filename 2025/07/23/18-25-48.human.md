This is a refactoring patch from Justin Tobler in response to Patrick Steinhardt's reflog migration series. The patch reviews and approves Patrick's changes to export the `ref_transaction_update_reflog()` function and remove its `flags` parameter.

Justin agrees with the rationale that since all callers are expected to use the same set of flags (REF_HAVE_OLD, REF_HAVE_NEW, REF_LOG_ONLY, etc.), it makes sense to hardcode them in the function rather than passing them as a parameter. He notes there's currently only one caller (in the reflog migration code) that would be affected by this change.

The patch also fixes a typo ("functino") in Patrick's original commit message. This appears to be a straightforward review with no objections to the technical changes, just a minor documentation nitpick.
