This is part 8 of Patrick Steinhardt's 21-patch series removing `the_repository` dependencies in the config subsystem. The patch removes the `git_config_get_string()` wrapper function, converting all callers to use `repo_config_get_string(the_repository, ...)` instead. This follows the established pattern from previous patches in the series, making repository dependencies explicit while maintaining identical behavior.

The changes affect configuration handling across several areas: fetch bundle URIs, maintenance task scheduling, remote partial clone filters, submodule settings, checkout default remotes, SSH configuration, editor preferences, command completion, promisor remotes, protocol version negotiation, and sideband colors. The patch updates 14 files with mechanical conversions, removing the wrapper from config.h while leaving other config getter wrappers (like `git_config_get_int()`) for future patches.

As with previous patches in the series, this is a straightforward mechanical conversion that doesn't change behavior - it just makes the repository dependency visible at call sites. The commit message notes that some call sites could be further optimized by passing an actual repository instance rather than `the_repository`, but leaves that for future work. The changes are consistent with the series' disciplined approach to wrapper removal and build cleanly on SHA-256 repositories.
