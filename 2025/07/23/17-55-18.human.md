Feature patch for `imap-send` with potential compatibility concerns.

Aditya Garg proposes adding an option to control whether sent IMAP messages are marked as read or unread. The patch adds a `--mark-seen` flag to `git imap-send`, which would use libcurl's `CURLULFLAG_SEEN` feature when uploading messages. 

Junio Hamano points out two potential issues: the code style uses unnecessary braces around single-statement blocks, and questions whether the required libcurl version (8.13.0) is too new compared to Git's minimum requirement (7.61.0). Garg acknowledges the version concern but downplays it, calling it "not a very important feature."

The patch appears straightforward but raises questions about its necessity and compatibility requirements. The author's response suggests this may not be a high-priority change, though the functionality itself could be useful for some workflows. The version requirement issue would need to be addressed if the patch moves forward.
