This is a test refactoring patch in the `git refs list` series. It's the second of three patches in v3 of the RFC series, focused on restructuring test infrastructure to be shared between `git for-each-ref` and the new `git refs list` command.

The patch moves the core test logic from `t6300-for-each-ref.sh` into a new `for-each-ref-tests.sh` file, replacing hardcoded calls to "git for-each-ref" with a `$git_for_each_ref` variable. The original test file becomes a simple driver that sets up the variable and sources the shared test library. This follows the pattern used for sharing tests between `git-blame` and `git-annotate`.

The changes are extensive (over 2000 lines moved/added) but mechanical in nature, preserving all existing test coverage while making the tests reusable. The commit message indicates this addresses prior maintainer feedback about test infrastructure concerns, specifically moving away from environment variables to a more maintainable shared file approach.

This appears to be a well-crafted change that cleanly separates test setup from test logic while maintaining all existing functionality. The patch is part of a mentored GSoC project with multiple mentors signed off, suggesting it has undergone thorough review. The test restructuring is a prerequisite for adding tests for the new `git refs list` command in the next patch.
