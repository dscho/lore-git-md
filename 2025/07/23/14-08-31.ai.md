This is part 10 of Patrick Steinhardt's series removing `the_repository` global variable usage by converting config wrapper functions to explicit repository-aware variants. The patch removes the `git_config_get_ulong()` wrapper in favor of direct `repo_config_get_ulong(the_repository, ...)` calls.

The changes affect four files, updating configuration handling for several key parameters:
- `fast-import.c`: pack depth and size limits
- `gc.c`: garbage collection thresholds, cache sizes, and timeout values
- `http-backend.c`: maximum request buffer size
- `config.h`: removes the wrapper function declaration

The patch follows the same mechanical conversion pattern established in previous patches of this series (referencing commit 036876a1067). It makes repository dependencies explicit while maintaining identical behavior, leaving potential optimizations of passing actual repository instances for future work. The changes are straightforward replacements with no functional impact, continuing the series' disciplined approach to wrapper removal.
