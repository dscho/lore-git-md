This is a feature patch in the `git last-modified` series, adding an `--extended` output format specifically designed for forge integration. The patch builds on the existing tree-level modification tracking command, which was previously limited to showing just commit OIDs and paths.

The new `--extended` option provides richer output format that includes full commit metadata (tree, parents, author info) and commit message, formatted to match what forges need when displaying tree views. The output can be either newline-delimited (with indented commit messages) or NUL-delimited (with unindented messages when using `-z`). The implementation uses Git's existing pretty-printing infrastructure, leveraging the new `no_indent` field added in patch 4/6 of this series.

The change includes thorough documentation updates explaining both the default and extended output formats, plus new tests verifying the extended output works as expected. The implementation appears clean and well-integrated with the existing code, using standard Git conventions for commit formatting and path quoting. This looks like a polished addition to the series that directly addresses the stated use case of feeding forge tree views.
