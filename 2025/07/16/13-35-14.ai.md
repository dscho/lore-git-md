Performance test addition for the `git last-modified` command series. This patch introduces a new performance test script `t/perf/p8020-last-modified.sh` that benchmarks three key usage patterns of the new `git last-modified` command:

1. Basic top-level operation (`git last-modified HEAD`)
2. Recursive mode (`git last-modified -r HEAD`)
3. Subdirectory-focused operation (targeting the first subdirectory found in the tree)

The tests are designed to detect performance regressions rather than validate correctness (which is covered by the regular test suite). The script follows Git's standard performance test structure, using the `test_perf` framework and operating on the default test repository.

The patch also updates `t/meson.build` to include the new performance script alongside other Git benchmarks. The implementation is straightforward, with test cases that exercise the command's core functionality in ways likely to be performance-sensitive, particularly around tree traversal and path handling.

This is part of the larger `git last-modified` series (now at v5) that introduces tree-level modification tracking as a complement to line-level `git blame`. The performance tests will help validate the claimed 55% speedup from Bloom filter optimizations mentioned in the thread summary.
