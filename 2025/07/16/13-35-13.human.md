This is the first patch in v5 of the `git last-modified` feature, introducing a new plumbing command to track when paths were last modified in repository history at tree-level (unlike line-by-line `git blame`). The command shows the most recent modification to paths by walking backwards through history to find commits where each path changed into its final state.

The implementation uses `last_modified_entry` structs with hashmap lookups to track paths and their states. Key features include:
- `-r` flag for recursive operation into subtrees
- `-t` flag to show tree entries themselves (implies `-r`)
- Path handling follows `git diff-tree` conventions
- Comprehensive test suite covering basic cases, merges, pathspecs, and edge cases

The patch adds all the core infrastructure: command implementation in `builtin/last-modified.c`, documentation, test scripts, and build system integration. The command is marked as EXPERIMENTAL in the docs, with behavior subject to change.

This is a well-structured initial implementation with thorough test coverage. The thread context shows this series has undergone significant review and iteration, with all major design decisions settled. Performance optimizations (including Bloom filter support) will come in later patches of the series.
