This is the final patch in a refactoring series standardizing predicate functions to use C99 `bool` return types. Karthik Nayak provides a style nit on parameter alignment in `strbuf.{c,h}`, specifically pointing out inconsistent indentation in the `skip_to_optional_arg_default()` function and its declaration. The issue was caught by the style checker script, showing that the second parameter line should be indented one additional space to align with the opening parenthesis.

The patch itself (authored by Phillip Wood) converts several strbuf predicate functions (`starts_with()`, `istarts_with()`, `starts_with_mem()`, `skip_to_optional_arg_default()`) from `int` to `bool` return types, completing the series' goal of standardizing predicate function signatures. The changes are purely mechanical type signature updates affecting 20 lines across 4 files, with no behavioral impact.

This appears to be the last remaining issue before the series can be merged, as all substantive technical reviews from core maintainers (Elijah Newren, Junio C Hamano, Brian m. carlson) have already been addressed. The thread context shows this concludes an 18-month effort to modernize predicate function signatures that began with commit 8277dbe987 in December 2023.
