This is a final review confirmation for the byte-swapping optimization series, now at v3. Sebastian Andrzej Siewior confirms that only typo fixes were made to the patch descriptions since v2, with no code changes to the actual patches. The series standardizes and optimizes Git's byte-swapping operations (ntohl/ntohll) across platforms, removing platform-specific assembly in favor of compiler optimizations where possible.

The current version maintains all existing behavior while improving code structure, with particular attention to MSVC compatibility. Sebastian notes that while glibc already optimizes ntohl, musl still uses function calls, and ntohll() remains a special case needing Git's implementation. The put/get_be*() macros still show suboptimal behavior on MSVC, but this is left for potential follow-up work.

With maintainer Junio C Hamano circulating this version and no outstanding objections, the series appears ready for merging pending final confirmation from reviewers. The changes are well-contained in compat/bswap.h, showing a net reduction of 58 lines while maintaining cross-platform correctness.
