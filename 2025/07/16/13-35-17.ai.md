Feature addition to the `git last-modified` command series, introducing an `--extended` output format specifically designed for forge integration. This patch adds detailed commit metadata output including full commit messages, trees, parents in a structured format, complementing the existing path/OID output.

The implementation extends `builtin/last-modified.c` to use Git's pretty-printing infrastructure when `--extended` is specified, with careful handling of both newline-delimited and NUL-delimited output variants. The format includes:
- Path information (quoted when needed)
- Full commit metadata (OID, tree, parents)
- Author/committer info
- Commit message (indented for newline output, raw for NUL-delimited)

Key technical details:
- New `extended` flag in `struct last_modified`
- Uses `pretty_print_commit()` with `CMIT_FMT_RAW`
- Respects existing `-z` NUL-delimiter behavior
- Handles boundary commits (prefixes with `^`)
- Adds comprehensive test case in `t/t8020-last-modified.sh`
- Documents format variants in `Documentation/git-last-modified.adoc`

The change is well-integrated with the series' existing path handling and output formatting conventions, maintaining consistency with the command's `git diff-tree`-inspired behavior. The implementation cleanly separates extended format logic from the base case while sharing core path output handling.
