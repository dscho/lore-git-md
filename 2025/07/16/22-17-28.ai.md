This is a technical follow-up in the meson build system thread about PCRE2 dependency handling, specifically addressing macOS issues. Carlo Arenas clarifies the behavior of the fallback mechanism when detecting broken system PCRE2 installations on macOS.

The discussion focuses on edge case behavior when `dependency()` fails due to `--wrap-mode=nofallback` being set. Carlo explains that in their implementation, since they're not using `method: auto`, the code won't retry pkg-config and will only fall back to the wrap if `allow_fallback` is true (which it is by default when `required` is true). The only failure case would be when `--wrap-mode=nofallback` is explicitly set, which wouldn't trigger an abort in this code path.

This is a refinement of the earlier solution that added header verification for macOS system PCRE2 installations.
