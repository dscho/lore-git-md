This is a documentation patch in an ongoing thread about C99 compound literals in Git's codebase. Phillip Wood concurs with Junio C Hamano's proposal to document the existing test cases for C99 compound literals in the reftable subsystem (introduced in Git 2.48) via a new section in CodingGuidelines. The documentation would formalize these as intentional test balloons while imposing a moratorium on further compound literal usage until mid-2026 for evaluation.

The thread has effectively reached consensus on this approach, treating the reftable macros (`REFTABLE_FLOCK_INIT` and `REFTABLE_TMPFILE_INIT`) as the sole test cases while deferring any decision on wider adoption. The patch represents the project's formal position on this experimental syntax feature, balancing the need for real-world testing with controlled adoption.
