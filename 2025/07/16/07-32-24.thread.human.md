This thread introduces a two-patch series preparing git-gui for SHA-256 support. The first patch, from Pratyush Yadav, standardizes variable naming by replacing all uses of `null_sha1` with the equivalent `nullid` throughout the GUI codebase. The changes are mechanical and touch two files (`git-gui.sh` and `lib/checkout_op.tcl`), removing the redundant variable definition while maintaining identical behavior.

The patch appears well-scoped and correctly implemented, serving as preliminary cleanup before the actual SHA-256 support work arrives in the second patch. While the commit message could be slightly more explicit about how this standardization helps with SHA-256 preparation, the technical changes themselves are straightforward and uncontroversial. The series is currently at version 1, with the core git-gui maintainers yet to weigh in.
