This is the final patch in a refactoring series to standardize Git's use of C99 `bool` type in predicate functions. The patch converts several string-related predicate functions in `strbuf.{c,h}` from returning `int` to `bool`, matching similar changes made to other predicates in the codebase.

The changes are mechanical and behavior-preserving, updating function signatures and return values (changing `1`/`0` to `true`/`false`) for functions like `starts_with()`, `istarts_with()`, and `skip_to_optional_arg()`. The patch affects 4 files with 29 insertions and 26 deletions.

This concludes an 18-month experimental period that began in December 2023 to evaluate using `bool` for predicates. The series has already received thorough review from multiple core maintainers (Elijah Newren, Junio C Hamano, and Brian m. carlson) with all feedback addressed. The changes represent a clean-up to make predicate functions' purposes more explicit through their return types, following Git's conservative approach to C99 adoption.
