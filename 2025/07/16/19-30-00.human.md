This is a build system patch addressing PCRE2 dependency handling on macOS, part of an ongoing series to improve cross-platform compatibility in Git's meson build system.

The patch specifically targets macOS systems where the base PCRE2 library is broken - it installs a pkgconf module pointing to a non-existent header file. The solution adds verification using `compiler.has_header()` to detect this case, then either falls back to a built-in version (if PCRE2 is explicitly enabled) or disables the feature with a warning (if set to "auto", which is now the default).

The implementation maintains consistency with Windows builds through a special case for that platform. The changes are well-considered, with clear attribution to previous suggestions from Eli Schwartz and editorial help from Eric Sunshine. The patch has already been tested and confirmed working by the author, and follows the technical approach agreed upon in the thread.

This appears to be the final iteration of the macOS-specific solution in this series, with Junio Hamano having indicated it will be queued for inclusion. The thread suggests this work may also inspire upstream improvements to meson's dependency handling.
