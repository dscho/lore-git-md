This is a bugfix for the GitHub Actions CI configuration. 

Junio Hamano fixes a shell syntax error in the test failure reporting script that was introduced in a previous commit (eab5dbab). The error involved a malformed variable substitution (`${TEST_OUTPUT_DIRECTORY:t}`) that should have used the `:-` operator to provide a default value (`${TEST_OUTPUT_DIRECTORY:-t}`). This typo caused the CI script to fail with a "Bad substitution" error when trying to report test failures in GitHub Actions.

The fix is straightforward - a one-character change to correct the shell syntax. This restores the ability to properly collect and report test artifacts when tests fail in GitHub Actions CI runs. The patch appears to be a targeted correction of an obvious mistake, with no broader implications for the test infrastructure.
