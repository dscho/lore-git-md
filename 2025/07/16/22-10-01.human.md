This is a technical follow-up to the meson build system's PCRE2 dependency resolution for macOS. Eli Schwartz provides additional implementation advice for the patch that handles broken system PCRE2 installations on macOS.

The email focuses on improving the error handling when falling back from a broken system PCRE2 to a built-in version. Schwartz suggests two alternative approaches to make the error message more precise: either using meson's `not_found_message` parameter in the `dependency()` call, or setting `required: false` and manually checking with an explicit error message (while ensuring `allow_fallback: true` is set).

This is a minor refinement to the already-working solution that was confirmed by Carlo Arenas Belón. The thread has largely settled on the technical approach, with this being one of the final polish items before the changes are fully merged. The discussion remains focused on implementation details rather than architectural questions.
