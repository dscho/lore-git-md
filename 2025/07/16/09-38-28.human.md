This is a documentation patch that formalizes the use of C99's `bool` type in Git's codebase, concluding an 18-month experimental period. Phillip Wood proposes updating the CodingGuidelines to explicitly permit using `<stdbool.h>` for predicate functions, citing the successful test balloon that began with commit 8277dbe987 in December 2023.

The change is minimal - just three lines added to Documentation/CodingGuidelines - but represents the culmination of a carefully managed transition. The patch comes as the first in a fully reviewed 3-part series that has already received acks from core maintainers, with all feedback addressed. The series standardizes return types for various string utility functions from `int` to `bool` while maintaining Git's conservative approach to C99 adoption.

This patch serves as the official documentation update to accompany the mechanical code changes in subsequent patches. The commit message notes the 18-month trial period passed without complaints, suggesting the community is comfortable with this modernization. The change aligns with Git's gradual adoption of select C99 features, following similar moves like allowing `for` loop variable declarations in 2021.
