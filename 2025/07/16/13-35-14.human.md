Performance test addition for the `git last-modified` series. This patch adds a performance test script (`t/perf/p8020-last-modified.sh`) to benchmark the new `git last-modified` command, which tracks tree-level path changes in repository history. The tests measure three scenarios: basic top-level operation, recursive traversal, and subdirectory-specific checks.

The implementation is straightforward, following Git's standard performance test patterns. It benchmarks the command's execution time in different modes, using the test repository's default state. The tests are designed to catch performance regressions rather than verify correctness (which is covered elsewhere).

This is part of a mature series (v5) that has already addressed major design decisions and received maintainer approval. The performance tests complement the existing functional tests, with the thread summary noting a 55% speedup from Bloom filter optimizations in the final implementation.
