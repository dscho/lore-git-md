This thread discusses adding X-Change-ID header support to Git for better integration with change tracking systems like Patchwork and Sourcehut. The initial proposal modified pretty.c to include change-id lines from commit messages as email headers when using format-patch and send-email, carefully limiting the scope to avoid conflicts with downstream tools.

Remo Senekowitsch, a Jujutsu development team, confirmed there would be no conflict with their change-id handling, as testing showed Jujutsu can import these headers from Git repositories without issues. This removed a key technical concern and opened the door to broader integration. The author has now successfully tested Jujutsu's ability to preserve and interpret these headers through Git operations, confirming the approach works across the Git/Jujutsu boundary.

The thread is progressing toward a v2 patch series that will expand the functionality to include git-am support, moving beyond the initial pretty-printing scope. The main open question now is how to properly test this expanded functionality in Git's test suite, which the author plans to address in the v2 submission. With Jujutsu compatibility verified and no technical objections raised, the proposal appears on track for broader integration.
