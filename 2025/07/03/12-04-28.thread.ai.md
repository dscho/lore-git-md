SHA-256 support for git-gui (v2). Patch modifies git-gui to handle SHA-256 repositories by replacing SHA-1 length assumptions with dynamic hash length checks. Changes span main script, blame viewer, repository chooser, commit interface, and remote branch deletion. Key technical details: adds global `hashlength` variable set via `git rev-parse --show-object-format`, replaces hardcoded "40" with `$hashlength` in regexes/string ops, handles null SHA with `string repeat 0 $hashlength`, fixes commit_committree validation in v2. No tests included but changes are mechanical and low-risk, following established SHA-256 patterns in Git.
