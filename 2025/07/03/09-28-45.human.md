This is a build system patch in Patrick Steinhardt's ongoing Meson cleanup series (part 3/8). It improves the output formatting of Git's build configuration summary to be more informative and consistent.

The change modifies meson.build to show version numbers for detected dependencies (like curl, expat, pcre2) in the auto-detected features summary, rather than just boolean true/false. It also enables colorized YES/NO output for boolean options, making the display more readable. The patch doesn't affect build functionality - it's purely about improving the informational output shown during configuration.

The change is well-scoped and clearly demonstrates the improvement with before/after examples in the commit message. This continues the series' theme of technical build system improvements with no user-facing behavior changes beyond better diagnostic output. The patch appears straightforward and unlikely to be controversial.
