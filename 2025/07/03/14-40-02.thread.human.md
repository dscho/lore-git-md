Here's a human-readable thread summary:

This thread documents a previously undocumented behavior in `git init` where passing an empty path to `--template` (as `--template=`) skips template copying entirely. The behavior has existed since at least Git 2.1 (2014) and remains consistent across versions, though the implementation moved the empty string check from `copy_templates()` to `get_template_dir()` in newer releases.

The patch author notes this is particularly useful for tooling like package managers that create repositories just for fetching remote data, where copying template files (such as hooks) would be unnecessary overhead. The proposed change simply adds documentation of this existing feature to the TEMPLATE DIRECTORY section of git-init(1), making the behavior explicit rather than implicit. This appears to be a straightforward documentation improvement with no behavior changes required.
