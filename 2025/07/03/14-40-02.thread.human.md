This thread documents the different ways to skip template copying during `git init`. The original behavior, dating back to 2008, allows skipping template copying by specifying an empty path (via `--template=`, `init.templatedir`, or `GIT_TEMPLATE_DIR`), which is commonly used by package managers. Git 2.38.0 introduced a newer `--no-template` flag (singular, as corrected in the latest email) that provides an explicit way to disable copying, which takes precedence when both methods are specified.

The discussion has established consensus that both mechanisms are valid and should be documented, with Todd Zullinger providing historical context about the safety rationale behind the empty path approach. The current focus is on precisely documenting these behaviors in the TEMPLATE DIRECTORY section of git-init(1), clarifying when each method should be used and how they interact. Kristoffer Haugsbakk has been actively contributing to this effort, most recently correcting an important detail about the flag's name from plural to singular form. No objections to documenting either behavior have been raised, and the documentation patch is being refined to clearly explain both the original empty path mechanism and the newer `--no-template` flag.
