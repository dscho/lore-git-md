This thread discusses a documentation patch to clarify that passing an empty path to `git init --template=` (e.g., `--template=`) skips template copying, a behavior that has existed since Git 1.5.6.4 (2008). The original author noted this is useful for tooling like package managers that create repositories just for fetching remote data, where template files would be unnecessary overhead. Han Young confirmed the behavior's long history and widespread use, reinforcing the case for documenting it. The patch remains non-controversial, focusing solely on documenting existing behavior rather than changing it. No objections or requests for changes have been raised.
