This is a technical discussion about the implementation details of making reftable the default ref storage format in Git 3.0. Patrick Steinhardt responds to Karthik Nayak's suggestion about where to set the default ref storage format value.

The exchange focuses on whether the default should be set in `REPOSITORY_FORMAT_INIT` (as Nayak suggested) or in `repository_format_configure()` (as implemented in the patch). Steinhardt explains his preference for the current approach, arguing it's more contained and makes the default value's origin clearer. He also suggests potentially changing `REPOSITORY_FORMAT_INIT` to use `_UNKNOWN` for both ref storage format and hash, which would make the initialization behavior more consistent.

This is part of the ongoing refinement of the reftable default implementation following architectural approval, with the discussion now focusing on code organization clarity rather than fundamental design questions. The tone remains constructive, with both developers working to improve the implementation's readability and maintainability.
