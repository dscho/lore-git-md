This is a technical discussion about the implementation details of making reftable the default ref storage format in Git 3.0. Karthik Nayak responds to Patrick Steinhardt's proposed change to set the default ref storage format in `repository_format_configure()` rather than the `REPOSITORY_FORMAT_INIT` macro.

Nayak agrees with Steinhardt's approach, noting that the current code makes it hard to trace where the default format is set. He suggests going further by also changing `REPOSITORY_FORMAT_INIT` to use `_UNKNOWN` for both ref storage format and hash algorithm, which would make the initialization behavior more explicit. However, he leaves it to Steinhardt to decide whether to include this additional change in the current patch series.

The exchange shows consensus on the technical direction while leaving room for minor implementation refinements. This is part of the larger effort to make reftable the default storage backend, with careful attention being paid to code clarity and maintainability in the initialization path.
