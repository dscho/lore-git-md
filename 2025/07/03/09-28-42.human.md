This is a cover letter for a series of Meson build system improvements and cleanups. Patrick Steinhardt presents 8 patches addressing various small issues that have accumulated over two months of working with Git's Meson build configuration.

The changes span several areas of the build system: fixing Windows shell detection, correcting path handling when libexecdir is overridden, improving feature summary output, removing redundant variables, and updating subproject wrappers. One notable change updates CI configurations to use Meson's new `--slice` option, which should be a straightforward improvement to build efficiency.

The patches touch multiple build-related files including the main meson.build, CI configurations, and subproject wrappers for expat and pcre2. The changes are relatively small and focused - each appears to address a specific, well-defined issue rather than making sweeping architectural changes. The cover letter doesn't highlight any particularly controversial changes, suggesting these are straightforward maintenance improvements to the build system.
