This is a review comment on Patrick Steinhardt's patch to switch Git's default ref storage to reftable format in Git 3.0. Karthik Nayak provides several constructive nits and suggestions for improvement.

The main feedback points are:
1. The commit message should more accurately reflect that the patch both announces the switch and implements the WITH_BREAKING_CHANGES conditional logic.
2. Minor wording improvements for clarity of the documentation about reftable's advantages.
3. A suggestion to mention reftable's storage efficiency benefits in the documentation.
4. A technical suggestion to move the default format setting to REPOSITORY_FORMAT_INIT in setup.h rather than setup.c.

The review is generally positive, noting that the core approach "makes sense" while offering specific ways to improve the patch's clarity and implementation. Karthik's tone is collegial and focused on making the technical details as precise as possible. The feedback doesn't raise any fundamental objections to the approach, just refinements to the current implementation.
