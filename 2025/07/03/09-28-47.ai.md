Platform compatibility fix in Patrick Steinhardt's Meson build system series (5/8). This patch corrects shell path lookup behavior on MINGW64 systems while maintaining the desired preference for `/bin/sh` that was introduced in an earlier change.

The issue stems from a previous fix (4cba20fbdc6) that added `/bin` to the search path to prefer `/bin/sh` over PATH-based lookups. While this worked on Unix-like systems, it broke on MINGW64 because Meson expects absolute Windows-style paths in that context. The patch changes the approach to search for both `/bin/sh` and `sh` directly, which works correctly across platforms while still preferring the standard `/bin/sh` location when available.

Key technical details:
- Modifies `meson.build` to use `find_program('/bin/sh', 'sh', ...)` instead of searching `/bin` directory
- Maintains cross-compilation support (shown via Nix store path example)
- Preserves the ability to override via `program_path` or cross-files
- Affects the `target_shell` variable used in build configuration

This is a focused technical fix that addresses a specific platform compatibility issue while keeping all existing functionality. The change is minimal (single line modification) but important for Windows users building with Meson. It continues the series' pattern of methodical build system improvements.
