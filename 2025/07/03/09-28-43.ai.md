This is a build system patch that fixes Python version detection in Git's Meson build configuration. It's the first in an 8-part series of Meson build system cleanups.

The patch corrects an inconsistency in how Python is discovered during the build process. Currently, the build system searches for both native (build host) and non-native (target host) Python versions, even though Python isn't used in the build process itself. The only place Python is needed is for determining whether to include git-p4 support, which should depend on the target system's Python availability, not the build system's.

The change modifies meson.build to:
1. Stop searching for native Python entirely
2. Use only non-native Python detection for git-p4 wiring
3. Update the feature summary output to reflect this change

The patch appears focused and well-justified, fixing what seems like an incorrect cross-compilation behavior. It's a straightforward technical correction that doesn't introduce new functionality but aligns the build system with its requirements more accurately. The change is small (4 insertions, 5 deletions) and limited to build configuration logic.
