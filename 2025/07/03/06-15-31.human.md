Feature patch for the reftable backend transition, part 2/2 of the v2 series. This follows the documentation and version plumbing from patch 1/2, now implementing the actual experimental rollout mechanism.

The patch makes reftable the default ref storage for new repositories when `feature.experimental=true` is set, while still allowing explicit overrides via `init.defaultRefFormat` or `GIT_DEFAULT_REF_FORMAT`. This expands testing beyond GitLab's current usage to catch potential issues before the planned Git 3.0 default switch. The implementation adds config documentation, setup.c handling for the experimental flag, and comprehensive tests verifying the precedence rules between experimental mode, config, and environment variables.

The change is well-contained and follows established patterns, with clear test coverage of the interaction points. It represents a cautious rollout strategy for a significant backend change, building on the SHA-256 transition precedent while addressing the specific needs of ref storage migration. The patch maintains all existing override mechanisms while adding the experimental opt-in path.
