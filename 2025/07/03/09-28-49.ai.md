This is the seventh patch in Patrick Steinhardt's series improving Git's Meson build system infrastructure, focusing on dependency updates. The patch updates two subproject wrappers (expat and pcre2) to their latest versions by running `meson wrap update` in the project root.

The changes:
- Updates expat from 2.6.3 to 2.7.1, with corresponding changes to source URLs, hashes, and patch files
- Updates pcre2 from 10.44 to 10.45, similarly updating all related metadata
- Maintains the same wrapper structure and dependency declarations while bumping versions

This continues the series' pattern of technical build system improvements, keeping Git's Meson configuration current with upstream dependencies. The changes are mechanical version bumps with no functional impact on Git's behavior, just ensuring the build system uses newer dependency versions when available. The patch follows the same clean, focused approach as previous patches in the series.
