This is a review comment on Patrick Steinhardt's reftable default format patch, focusing on documentation and implementation details. Karthik Nayak provides several technical suggestions to improve clarity and correctness in the BreakingChanges documentation and implementation approach.

He also confirms the version-dependent macro approach in repository.h makes sense.

The review maintains a constructive tone while identifying specific areas for improvement in both documentation precision and code structure.
