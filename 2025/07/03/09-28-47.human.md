This is a platform compatibility patch in Patrick Steinhardt's ongoing Meson build system cleanup series (5/8). It fixes shell path detection on MINGW64 systems where an earlier change to prefer `/bin/sh` caused build failures due to path format differences between Unix and Windows.

The patch changes how Meson looks up the shell binary - instead of explicitly adding `/bin` to the search path (which fails on Windows-style paths), it now directly searches for `/bin/sh` first while falling back to a PATH-based `sh` lookup. This maintains the original goal of preferring `/bin/sh` while working correctly on MINGW64. The commit includes test cases showing it still allows explicit shell path overrides via cross-compilation files.

The change is small (a one-line modification to meson.build) but addresses a real compatibility issue. Like the rest of the series, it's a focused technical improvement to the build system with no user-facing impact beyond fixing builds on Windows platforms. The fix appears well-considered, maintaining the original behavior where possible while properly handling the Windows path case.
