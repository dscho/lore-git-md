The change is straightforward and mechanical, touching only the manpage generation logic in `Documentation/meson.build`.

The patch continues the series' pattern of tightening up the build system by eliminating redundant variables and simplifying the code. Like previous patches in the series, this is a technical improvement with no impact on the actual build output or functionality - it just makes the build configuration slightly cleaner and easier to maintain. The change is well-scoped and clearly explained, following the same careful approach seen in the earlier patches.
