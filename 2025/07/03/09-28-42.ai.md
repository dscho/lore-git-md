This is a cover letter for a series of CI/build system patches focused on Meson improvements. The 8-patch series from Patrick Steinhardt collects various Meson-related cleanups and fixes that have accumulated over two months.

The changes span several areas of the build system: removing redundant Python version discovery, fixing summary output formatting, cleaning up variable usage, correcting shell lookup on MINGW64, fixing GIT_EXEC_PATH handling with custom libexecdir, updating subproject wrappers, and adopting Meson's new `--slice` option in CI. The patches touch multiple build configuration files including meson.build, CI workflow definitions, and subproject wrappers for expat and pcre2.

The changes appear focused and well-scoped, with each patch addressing a specific technical issue in the Meson build system. The series doesn't introduce major new functionality but rather improves existing infrastructure - fixing bugs, removing redundancy, and keeping dependencies current. The CI change to use Meson's `--slice` suggests the series may include some performance optimizations for CI runs.
