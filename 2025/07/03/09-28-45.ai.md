This is a build system patch in Patrick Steinhardt's Meson cleanup series, focusing on the feature summary output. The change improves the build system's auto-detected features display by showing version numbers for dependencies and formatting boolean values more clearly.

The modification makes two key improvements to meson.build's feature summary output: it now shows version numbers for detected dependencies (like curl 8.14.1 or pcre2 10.44) rather than just "true", and formats boolean values as colored "YES"/"NO" strings instead of bare "true"/"false". The change affects the display of curl, expat, gettext, iconv, and pcre2 dependencies in the build summary.

The patch is a straightforward quality-of-life improvement for developers examining build configurations, making it easier to verify which dependency versions were detected. It touches only the summary display logic in meson.build, modifying how the feature table is rendered without changing any actual build behavior or dependencies. The change is well-scoped and follows the series' pattern of technical Meson build system improvements.
