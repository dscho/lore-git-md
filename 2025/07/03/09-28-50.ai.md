CI / build system patch completing Patrick Steinhardt's Meson cleanup series by adopting Meson 1.8's new `--slice` option for test parallelization in CI. This final patch replaces complex PowerShell test-splitting logic in both GitHub Actions and GitLab CI configurations with Meson's native slicing capability, which the author previously upstreamed to Meson. The change simplifies the CI scripts while maintaining the same parallel test execution behavior, particularly benefiting Windows test runs known to be slow. The patch updates two files (`.github/workflows/main.yml` and `.gitlab-ci.yml`) with straightforward substitutions of the old PowerShell pipeline for the new `--slice` parameter. As with the rest of the series, this is a technical improvement with no impact on Git's runtime behavior, completing the set of Meson build system modernizations.
