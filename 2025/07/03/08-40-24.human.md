This is a build system discussion clarifying Git's current and future build infrastructure support.

Patrick Steinhardt responds to Ramsay Jones' explanation about Git's build systems, providing more details about the project's direction. He confirms that while Meson is still experimental, it will become an officially supported build method once it reaches feature parity with the Makefile-based build. This work is planned for the current release cycle.

The email clarifies that there are no immediate plans to remove the traditional Makefile, but the autotools-based build system is likely to be removed in the future once Meson is fully capable. Patrick estimates this transition will take a few more releases, with the final decision still pending.

This message helps set expectations for packagers and contributors about Git's build system roadmap. It positions Meson as the future direction while maintaining stability through the transition period. The tone is informative and forward-looking, providing useful context for those maintaining Git packages across different distributions.
