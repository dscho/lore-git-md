Platform compatibility and build system discussion.

This email from Patrick Steinhardt provides important clarification about Git's build system roadmap in response to questions from Ramsay Jones and Renato Botelho. While the main technical issue about FreeBSD builds with libsysinfo has been resolved (as noted in the thread summary), this message addresses broader build system strategy.

Key points made:
- Meson is still considered experimental, with Patrick planning to address remaining gaps this release cycle
- Once complete, both Makefile and Meson builds will be officially supported
- No current plans to remove the Makefile-based build
- Autotools will likely be removed once Meson reaches feature parity, though this is still a few releases away
- The decision emphasizes Git's source distribution model, allowing packagers flexibility in build methods

The message serves as authoritative guidance from a core contributor about the project's build system direction, while noting these are forward-looking statements rather than immediate changes. It provides useful context for packagers like Renato Botelho who need to plan their distribution builds. The tone is measured, noting both current status and likely future directions while making clear that final decisions remain pending.
