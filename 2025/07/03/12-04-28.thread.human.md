This thread discusses adding SHA-256 support to git-gui, the graphical interface for Git. The patch modifies git-gui to handle variable-length hashes dynamically rather than assuming SHA-1's fixed 40-character length. 

The second version of the patch makes comprehensive changes across git-gui's components - from the blame viewer to commit interface - replacing hardcoded SHA-1 assumptions with dynamic length checks. Key changes include querying the repository's object format to set a global hash length variable and updating regex patterns and string operations accordingly. The v2 fixes an oversight in commit tree validation that wasn't addressed in the initial version.

The changes follow the established pattern for SHA-256 support in other Git components. While no tests are included, the mechanical nature of the changes and their limited scope suggest low regression risk. The patch appears ready for review, with the author having addressed feedback from the first version.
