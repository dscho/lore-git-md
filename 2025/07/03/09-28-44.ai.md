This is a build system cleanup patch in Patrick Steinhardt's ongoing Meson modernization series. It fixes a minor issue where the build summary output was redundantly displaying the HTTPS backend status twice - once in the auto-detected features section and again in the backend summary section. The patch simply removes the duplicate entry from the features summary list in meson.build.

The change is straightforward and uncontroversial, removing one line that was causing duplicate output without affecting any actual build functionality. This continues the series' focus on cleaning up and improving the Meson build configuration's correctness and output quality. The patch follows the same pattern as others in the series - small, well-scoped technical fixes to specific build system behaviors.

Key technical details for future reference: the modification touches meson.build's summary() function output, specifically removing the 'https' key from the auto-detected features dictionary while preserving its display in the backend summary. The variable https_backend remains available for use elsewhere in the build configuration.
