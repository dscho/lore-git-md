This is the second patch in a two-part series implementing change ID preservation in email workflows, following the initial patch that added X-Change-ID header generation. The series is a feature enhancement targeting patch management systems like Patchwork and Sourcehut.

The patch adds X-Change-ID header parsing to `git am`, completing the round-trip functionality. When applying patches, it now extracts the X-Change-ID header from incoming emails and writes it back into the commit message as a change-id line. The implementation handles all am subcommands including --resume, with proper state management through the am_state struct.

Key technical details:
- New change_id field added to am_state struct with corresponding lifecycle management
- Header parsing added to mailinfo.c to recognize X-Change-ID
- Change ID preservation through the entire am workflow including resume/abort
- Integration with commit creation via commit_extra_header mechanism
