This is a bugfix patch in Patrick Steinhardt's Meson build system cleanup series. It addresses a regression where overriding the libexecdir path during Meson configuration would break Git's ability to find its core binaries like `git daemon`.

The issue occurs when users specify a custom libexecdir path with `-Dlibexecdir=`. While the path was correctly set in GIT_EXEC_PATH, it was missing the crucial `git-core` subdirectory where Git actually installs its binaries. The patch fixes this by always appending `git-core` to the libexecdir path.

The problem was reported by a user who noticed `git daemon` stopped working after the change. The fix is straightforward - a one-line change to meson.build that ensures the path construction includes the `git-core` component. The patch includes before-and-after command output showing the corrected behavior.

This is a focused technical fix that maintains compatibility with custom installation layouts while ensuring Git can find its own binaries. It's part of Steinhardt's ongoing effort to refine Git's Meson build configuration.
