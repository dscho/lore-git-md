Bugfix improving error reporting for index lock failures in `git stash`. This is version 2 of Han Young's patch addressing feedback from the initial review round.

The patch enhances error messages when `git stash` operations fail due to index lock contention. Previously, users would only see a generic "could not write index" message. Now, when index locking fails, the output will include both the original message and a new detailed explanation (e.g., "Unable to create 'index.lock': File exists").

The implementation is straightforward - it passes the `LOCK_REPORT_ON_ERROR` flag to `repo_hold_locked_index()` while maintaining backward compatibility. Version 2 specifically addresses reviewer feedback by ensuring both error messages appear, as confirmed by the updated test cases in t/t3903-stash.sh that now explicitly check for both message formats.
