Platform compatibility follow-up confirming FreeBSD version support policy.

Renato Botelho responds to Junio Hamano's query about the rationale for dropping FreeBSD 4.x support by noting that the oldest currently supported FreeBSD version is 13.5 (which will reach end-of-life in April 2026). This reinforces Brad Smith's earlier patch that removed several FreeBSD 4.x-era build settings (NO_MEMMEM, PTHREAD_LIBS, NO_UINTMAX_T, NO_STRTOUMAX) since they were only needed for versions older than FreeBSD 6.0 (released 2005).

The exchange confirms the project's implicit stance that FreeBSD versions older than 6.0 are no longer relevant, though Junio had requested this be explicitly documented in the commit message. The thread appears to be converging on this cleanup, with no objections to the technical changes themselves. The remaining FreeBSD build infrastructure (OLD_ICONV handling, standard include paths, BSD group semantics) remains intact.

This is a straightforward administrative follow-up that provides the missing version support context requested by the maintainer, clearing the way for the build system simplification.
