This is the final patch in Patrick Steinhardt's series improving Git's Meson build system infrastructure, focusing on CI optimization.

The patch simplifies test execution in CI by adopting Meson's new `--slice` option, which natively supports splitting tests across parallel jobs. Previously, Windows test runs required complex PowerShell scripting to manually distribute tests, but now both GitHub Actions and GitLab CI configurations are updated to use the cleaner built-in slicing feature.

The change affects two CI configuration files, replacing the custom PowerShell logic with a single `--slice` parameter. This maintains the same parallel test execution behavior but with simpler, more maintainable configuration. The update depends on Meson 1.8.2, which is now available on both CI platforms.

This concludes the series of technical Meson build system cleanups, with each patch addressing specific infrastructure pain points. The changes are focused on maintainability and correctness rather than user-facing features, continuing Steinhardt's pattern of careful build system maintenance work.
