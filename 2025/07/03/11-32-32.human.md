This is a follow-up in the X-Change-ID header support thread, confirming compatibility with Jujutsu and previewing upcoming git-am integration.

Drew DeVault confirms that Jujutsu's change-id handling works as expected with the proposed X-Change-ID headers, having tested the behavior through a procedure similar to what Remo Senekowitsch suggested. The testing shows Jujutsu can correctly import change-id headers from Git repositories, which was a key concern for the proposal's broader applicability.

The email previews an upcoming v2 patch series that will add git-am support for these headers, though Drew notes uncertainty about how to properly test this behavior in Git's test suite. This suggests the next version will expand the scope beyond just pretty-printing for email workflows to include patch application as well.

The thread has progressed from initial technical concerns to verified compatibility, with one major downstream tool (Jujutsu) now confirmed to work well with the approach. The next steps appear to be expanding the implementation while addressing testing challenges.
