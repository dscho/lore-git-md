This is a feature patch adding email header support for change tracking systems.

The patch introduces an X-Change-ID header to emails generated by Git's mail formatting (format-patch, send-email). This allows tools like Patchwork and Sourcehut to better track changes through their workflows. The header is extracted from the "change-id" line in the commit message when present.

The implementation modifies pretty.c to scan for "change-id" lines in commit messages and add corresponding X-Change-ID headers to the email format. The author explicitly avoids implementing the git-am side of this feature for now, citing concerns about how it might interact with downstream tools like Jujutsu that may have their own deterministic change ID generation processes.

The patch is focused solely on the email output side, which the author argues provides standalone value even without the complementary git-am functionality. The change is relatively small (7 lines modified) and focused on the pretty-printing code path. The author invites feedback from maintainers about potential impacts on other change-tracking systems before proceeding with the git-am integration.
