This is a follow-up discussion in the reftable-as-default series, focusing on implementation details of the ref storage format initialization.

Patrick Steinhardt responds to Karthik Nayak's suggestion about where to set the default ref storage format. The thread had previously reached consensus on placing the default in `repository_format_configure()` rather than `REPOSITORY_FORMAT_INIT`, and this email confirms that agreement. Steinhardt explains his preference for keeping the change contained to the `else` branch in `repository_format_configure()` rather than modifying the macro, as it makes the code flow clearer about where defaults are established.

While acknowledging Nayak's point that initializing to `_UNKNOWN` in `REPOSITORY_FORMAT_INIT` would be a sensible future change (for both ref storage format and hash algorithm), Steinhardt opts to defer this larger refactoring. He notes that touching the repository format code more extensively would be complex and prefers to keep the current series focused. The exchange shows the careful consideration being given to code organization as the project prepares to make reftable the default ref storage backend.
