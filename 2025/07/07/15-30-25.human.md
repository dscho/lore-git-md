This is a minor review comment on the pagination feature for `git for-each-ref`. Junio C Hamano points out a missing word ("with") in an error message from Karthik Nayak's patch that prevents using `--skip-until` (now renamed to `--start-after`) with custom sort options. 

While noting the grammatical fix, Hamano reflects on the design decision to make pagination and sorting mutually exclusive. He initially thought there might be use cases for sorting within paginated batches, but now agrees with the patch's approach - such a combination would be an unnatural operation that's not worth supporting.
