This is the final ack for a bugfix series addressing `git apply --intent-to-add` behavior. Junio Hamano confirms he will queue Raymond Pasco's v3 patch series, which has evolved through several iterations with expanded commit messages and test coverage.

The series fixes long-standing issues where `--intent-to-add` (or `-N`) failed to properly handle the index, making the feature effectively non-functional except in empty repositories. The four patches comprehensively address both index reading and writing behaviors while adding robust test cases and documentation updates.

Key improvements in v3 include more detailed technical explanations of the index handling decisions, precise specifications for when intent-to-add entries should be written, and expanded test coverage for mixed modification scenarios. The documentation now clearly explains the interaction with `--index` and `--cached` flags.

With Junio's approval, this well-documented and thoroughly tested fix appears ready for integration, resolving a subtle but significant behavior that has been broken since Git 2.19.
