This is a documentation patch in a completed series converting Git's documentation to a standardized synopsis format. It's part 6 of 9 in v3 of the series, focusing on converting the pretty-format options for `git-log`.

The patch mechanically updates `pretty-options.adoc` to use consistent backtick-wrapping for all command-line options and italicized placeholders. Key changes include:
- Wrapping all option names (`--pretty`, `--abbrev-commit`, etc.) and format specifiers (`oneline`, `short`, etc.) in backticks
- Converting angle-bracketed placeholders to italicized form (`<format>` -> `_<format>_`)
- Maintaining all existing functionality while improving rendering consistency
- Handling special cases like the `%` placeholder in format strings and tab expansion behavior

The changes are purely presentational - no content is added or removed, just reformatted to match the project's new documentation standards. This completes the conversion of pretty-format options documentation that was approved in v2, with v3 addressing final formatting polish. The patch follows the same mechanical conversion pattern used throughout the series, applying the standardized syntax to one of Git's core command option sets.
