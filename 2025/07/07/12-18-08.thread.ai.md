Git for Windows regression report and diagnostic follow-up. Fabio Frumento originally reported Git for Windows 2.50.0 failing to launch on Windows 11 Pro 64-bit (terminal window closes immediately, fixed by downgrading to 2.49.0). Brian M. Carlson confirmed this as a Git for Windows-specific issue (distinct from main Git project). Maintainer Johannes Schindelin has now provided diagnostic instructions: first suggesting to test with v2.50.1 and run bash directly with `& "C:\Program Files\Git\bin\bash.exe" -li`, then clarifying this must be executed specifically in a PowerShell session to properly capture error output before window closure. This corrected instruction provides a concrete debugging path forward, though root cause remains unknown - likely a Windows-specific packaging or environment interaction affecting certain configurations. Next step is for original reporter to execute these PowerShell-based diagnostics and share captured error messages, which will enable maintainers to identify the regression source between 2.49.0 and 2.50.x. The thread remains focused on information gathering with maintainer actively engaged, though no speculation yet about potential fixes or affected components beyond the launch mechanism.
