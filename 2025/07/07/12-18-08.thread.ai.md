Git for Windows regression report. Fabio Frumento reports Git for Windows 2.50.0 fails to launch on Windows 11 Pro 64-bit - the Git Bash terminal window appears briefly then closes immediately, with downgrade to 2.49.0 resolving the issue. Brian M. Carlson clarifies this is a Git for Windows-specific issue (not main Git project) since main Git only provides source code without bundled bash. The report currently lacks diagnostic details (event logs, crash dumps) needed for root cause analysis, though the clear reproduction case (upgrade breaks, downgrade fixes) confirms a real regression in Windows-specific components between 2.49 and 2.50. Next step is reporting to Git for Windows project with additional debugging information, as the issue appears environment-specific given 2.50 works on other similar Windows 11 systems. Windows maintainers (likely Johannes Schindelin) will need the enhanced diagnostics to investigate further.
