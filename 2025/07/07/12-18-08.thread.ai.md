Git for Windows regression report. Fabio Frumento reports Git for Windows 2.50.0 fails to launch on Windows 11 Pro 64-bit - the Git Bash terminal window appears briefly then closes immediately. Reverting to 2.49.0 resolves the issue. The report includes a screenshot showing the failed launch behavior but lacks diagnostic details (event logs, crash dumps). Clear reproduction steps (upgrade breaks, downgrade fixes) indicate a regression in Windows-specific components between 2.49 and 2.50. Windows maintainers will need to investigate further.
