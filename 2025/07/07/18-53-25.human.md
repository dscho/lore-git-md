This is a documentation patch in a completed series converting Git's man pages to a new standardized AsciiDoc format. It's part of v3 of a 9-patch series that has already been approved, with this version addressing minor formatting issues.

The change converts commit range notation in the rev-list documentation from single-quoted format to backtick-wrapped syntax, which will be properly rendered by the new documentation engine. Specifically, it updates the notation for `..` (two-dot) and `...` (three-dot) commit ranges, as well as the equivalent `^` notation. The patch maintains all existing examples and explanations while just changing the markup style.

This is a mechanical conversion following the project's new documentation standards, with no behavior changes. The patch is straightforward and aligns with the series' goal of standardizing Git's synopsis formatting. Since this is part of an already-approved series, it represents final polish rather than introducing new changes for review.
