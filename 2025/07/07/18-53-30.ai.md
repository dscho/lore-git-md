Documentation patch converting the pretty-formats documentation to the new AsciiDoc format, part of the v3 series standardizing Git's man page syntax. This patch focuses on the complex formatting requirements for pretty-format placeholders, particularly those containing parentheses like `%(foo)`.

The conversion applies several mechanical transformations: wrapping option names in backticks, using `_<placeholder>_` syntax for variables, and special handling for format specifiers containing parentheses (using `++` escaping). The patch maintains all existing content while improving rendering consistency. Key changes include:

1. All pretty format names (`oneline`, `short`, etc.) and options are now backtick-wrapped
2. Placeholder variables use italic underscore notation (`_<n>_` instead of angle brackets
3. Format specifiers with parentheses (`%C(auto)`, `%w()`, etc.) are wrapped in `++` to prevent syntax highlighting interference
4. Complex options like `%(decorate)` and `%(trailers)` get special formatting for their sub-options
5. The patch preserves all examples and notes about formatting behavior

The changes are purely presentational - no content is added or removed. This completes the pretty-format documentation conversion that was partially done in earlier series versions, addressing the particularly tricky case of format specifiers that could be misinterpreted as AsciiDoc syntax elements. The heavy use of `++` escaping for parenthetical format strings is the most notable technical aspect, required to maintain correct rendering while keeping the documentation's precise meaning.
