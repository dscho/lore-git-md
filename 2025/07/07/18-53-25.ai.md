Documentation patch converting commit range notation in `rev-list-description.adoc` to the new backtick-wrapped synopsis format. This is part of the larger v3 series standardizing Git's documentation format, specifically addressing how commit range syntax (like `A..B` and `A...B`) is presented.

The changes are mechanical but important for consistency with the new documentation style. The patch replaces single-quoted range notations (`'<commit1>..<commit2>'`) with backtick-wrapped versions (`<commit1>..<commit2>`), which the new rendering engine will process as synopsis elements. The same treatment is applied to the equivalent caret notation (`^A B`) and three-dot merge notation.

This follows the pattern established in earlier patches of the series, ensuring all command syntax elements receive uniform formatting. The patch maintains all existing explanatory text and examples while updating their presentation. As with other patches in this completed series, these changes have already been reviewed and approved in previous iterations, with v3 incorporating only final formatting tweaks to the overall effort.
