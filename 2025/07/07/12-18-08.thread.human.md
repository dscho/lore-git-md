This thread reports a Windows-specific regression in Git for Windows 2.50.0 where the Git Bash terminal fails to launch properly on Windows 11 Pro 64-bit systems. Fabio Frumento provided clear reproduction steps showing the terminal window briefly appearing then closing immediately, with the issue resolved by reverting to version 2.49.0. While the report lacks detailed diagnostic information like crash logs, the clean version-specific reproduction makes this a credible regression that will likely require attention from the Git for Windows maintainers. The problem appears isolated to the Windows-specific components rather than core Git functionality.
