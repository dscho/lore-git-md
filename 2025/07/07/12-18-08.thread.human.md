This thread tracks a regression in Git for Windows 2.50.0 where the terminal window closes immediately on launch for some Windows 11 Pro users. Fabio Frumento originally reported the issue, which was confirmed as Git for Windows-specific by Brian M. Carlson. Maintainer Johannes Schindelin provided diagnostic steps, asking the reporter to test in PowerShell to capture error output.

In the latest update, Fabio has narrowed the problem: bash works with `--norc` but fails with Git Bash's default `--login -i -v` options, pointing to an issue during shell initialization rather than a complete launch failure. A screenshot shows the window briefly appearing before closing, though the exact error text isn't visible. This gives the maintainers two key clues - the problem occurs during rc file processing, and the crash happens after some initialization succeeds. 

The thread remains focused on diagnosis, with Johannes now having concrete data about when the failure occurs. Next steps will likely involve analyzing the screenshot for any visible error messages and comparing the initialization paths between working and broken configurations to pinpoint where the regression was introduced between versions 2.49.0 and 2.50.0.
