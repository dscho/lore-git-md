This thread reports a regression in Git for Windows 2.50.0 where Git Bash fails to launch on Windows 11 Pro - the terminal window appears briefly then closes. The original reporter, Fabio Frumento, provided clear reproduction case (downgrading to 2.49.0 fixes it) but lacked diagnostic details like crash dumps. 

Brian M. Carlson clarified this is a Git for Windows-specific issue (not part of main Git) and suggested reporting it to that project's maintainers. While acknowledging the problem appears real, he noted the current report lacks sufficient technical details for diagnosis, recommending gathering more information like event logs. The issue doesn't appear universal since 2.50.0 works for others on similar systems, suggesting an environment-specific interaction. The thread now awaits either more detailed reporting from the original submitter or input from Git for Windows maintainers.
