This thread documents a Windows-specific regression where Git for Windows 2.50.0 fails to launch on some Windows 11 Pro systems (the terminal window closes immediately, while version 2.49.0 works). Original reporter Fabio Frumento was joined by Brian M. Carlson in confirming this is a Git for Windows issue, not affecting the main Git project. Maintainer Johannes Schindelin first provided diagnostic instructions to capture error output by running bash directly, then followed up with a crucial clarification: the command must be executed in PowerShell specifically to properly capture errors before the window closes. The thread remains in the information-gathering phase, with the next step being for the reporter to test the corrected PowerShell approach and share any error messages. While the root cause is still unknown, the maintainer's active engagement suggests progress toward identifying the regression source between versions 2.49.0 and 2.50.x.
