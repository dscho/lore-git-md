Documentation patch completing a series standardizing Git's man page formatting. This is the final patch in Jean-Noël Avila's v3 series converting documentation to the new AsciiDoc synopsis format, now focusing on log-related configuration options in `config/log.adoc`.

The patch mechanically converts all log.* configuration options to use backtick-wrapped names and improves formatting consistency. Notable changes include restructuring the `log.decorate` documentation from a dense paragraph into a clearer description list showing the `short`, `full`, and `auto` options. The changes maintain all existing content while making it more consistently formatted with the rest of the converted documentation.

This completes the series that has already been approved in v2, with v3 addressing final formatting observations. The work demonstrates careful attention to detail, with each option systematically converted to the new style while preserving technical accuracy. As the last patch in the series, it wraps up a comprehensive effort to standardize Git's documentation formatting across multiple complex man pages.
