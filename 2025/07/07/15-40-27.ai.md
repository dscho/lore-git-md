Platform compatibility fix for FreeBSD build system interaction between sysinfo() and sysctl() detection. This email from Junio Hamano serves as the final acknowledgment in the thread, confirming consensus on Ramsay Jones's solution to prioritize BSD's native sysctl() over sysinfo() compatibility. The patch modifies both configure.ac and meson.build to suppress HAVE_SYSINFO when HAVE_BSD_SYSCTL is defined, resolving build failures while maintaining behavior on non-BSD systems. Eric Sunshine had previously noted that while reordering preprocessor conditionals in builtin/gc.c would provide a more comprehensive fix for edge cases, the current approach is sufficient and well-documented. The thread shows clear technical agreement, with Renato Botelho verifying the fix works on FreeBSD. The change is now effectively merged with maintainer approval, closing this platform-specific build issue without requiring further discussion. Key files involved are the build system configuration files, with no changes needed to core Git functionality. The solution deliberately avoids touching the Makefile build system where variables are already correctly set.
