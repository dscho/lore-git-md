This is a documentation patch in the v3 series converting Git's man pages to the new synopsis format. It specifically updates the line range options documentation (`-L`) in `line-range-options.adoc` to match the project's new formatting standards.

The patch mechanically converts the syntax to use backticks for command-line options and italics for placeholders, maintaining consistency with the broader documentation conversion. Key changes include wrapping `-L<start>,<end>:<file>` and `-L:<funcname>:<file>` in backticks, and converting angle-bracketed placeholders like `<funcname>` to italicized `_<funcname>_` format. The content remains identical - only the markup changes to comply with the new AsciiDoc standards.

This change is part of the completed v3 series that was already approved in v2, with v3 addressing minor formatting issues. The patch demonstrates the systematic approach being taken across Git's documentation, where command syntax gets backtick-wrapping while placeholders receive italic treatment. The modifications are straightforward and maintain all existing functionality while improving rendering consistency.
