This is a test-related patch series addressing issues in Perl-less test conversions. The cover letter introduces two fixes for test scripts that were recently converted away from Perl dependencies.

The first patch fixes an awk warning in t4150-am.sh caused by an escaped '@' character that awk interprets specially. The second corrects a missing terminator in a sed command in t5333-pseudo-merge-bitmaps.sh. Both issues were reported by SZEDER following Patrick Steinhardt's earlier work to remove Perl dependencies from test scripts.

The changes are minimal (3 lines modified across 2 files) and appear to be straightforward corrections of syntax issues introduced during the Perl removal effort. The patches target specific test files that deal with git-am functionality and pseudo-merge bitmap testing respectively. The fixes seem well-contained and uncontroversial, addressing clear technical issues in the test infrastructure.
