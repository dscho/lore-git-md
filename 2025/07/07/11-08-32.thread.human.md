This thread covers test infrastructure fixes emerging from Patrick Steinhardt's ongoing work to convert Perl scripts to shell in Git's test suite. The issues were originally reported by SZEDER Gábor and involve two test scripts: t4150-am.sh (fixing an awk warning) and t5333-pseudo-merge-bitmaps.sh (correcting a silent test failure due to a missing sed terminator).

Junio C Hamano has accepted both fixes, though he mildly objected to restructuring the test case in t5333 as over-engineering. In a follow-up, Patrick Steinhardt acknowledged Junio's point about not needing to catch unlikely sed segfaults, but maintained that his two-step approach (writing to a file first, then using update-ref) would have made the original error more visible. The discussion revealed a minor philosophical difference - Patrick favoring explicit error checking, Junio preferring simpler pipelines when the robustness gain is marginal - but both agreed the current solution is technically correct.

The fixes are minimal (6 lines across 2 files) and maintain test functionality while resolving cosmetic issues and silent failure modes. The t5333 fix specifically addresses pseudo-merge bitmap functionality, where the test was passing despite broken reference creation due to empty patterns matching nothing. With no outstanding objections, Junio plans to queue these straightforward improvements to test robustness.
