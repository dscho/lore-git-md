This thread addresses minor test script issues that surfaced after Patrick Steinhardt's work to remove Perl dependencies from Git's test suite. The initial report from SZEDER Gábor identified two problems: an awk warning in t4150-am.sh and a subtle bug in t5333-pseudo-merge-bitmaps.sh.

The first fix dealt with an awk warning about an escaped '@' character in t4150-am.sh, a leftover from the test's Perl origins. The solution was straightforward - simply removing the unnecessary backslash while maintaining the test's functionality.

The latest patch tackles a more interesting issue in the pseudo-merge bitmap tests. Here, a missing terminator in a `sed` command was causing the test to silently fail in a way that still passed - the broken `sed` output was being piped to `git-update-ref`, which then did nothing, resulting in empty pseudo-merge patterns that coincidentally matched the test's expectations. The fix properly terminates the `sed` pattern and restructures the reference creation into two clearer steps, making the test more robust while maintaining its original purpose of verifying bitmap functionality for pseudo-merges.

Both fixes are minimal (totaling just 6 lines changed across two files) but important for maintaining test suite reliability as the codebase moves away from Perl dependencies. The changes appear uncontroversial and well-justified, with SZEDER Gábor's reports providing clear motivation for each fix.
