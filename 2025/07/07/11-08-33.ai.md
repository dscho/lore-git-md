Bugfix for awk warning in test script during Perl-to-shell conversion. This is part of Patrick Steinhardt's series addressing test issues following the dependency removal work.

The patch fixes a warning from gawk about an unnecessary escape sequence in t4150-am.sh. The test was converted from Perl to awk in an earlier commit (6aec8d38fdd), but retained a backslash before the '@' character in an email address pattern, which awk interprets literally rather than as an escape. The change simply drops the backslash while maintaining the same test functionality.

The warning was reported by SZEDER Gábor. The fix is minimal (one character change) and clearly correct, addressing a cosmetic issue in test output rather than affecting test behavior. This continues the thread's theme of cleaning up minor syntax issues in test scripts that were converted from Perl to shell utilities.
