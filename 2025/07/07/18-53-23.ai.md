This is a documentation patch series (v3) converting the `git-log` man page and related documentation to the new synopsis format style. The series has already been approved in v2, with this v3 addressing two minor formatting fixes found post-approval.

The key changes in v3 are:
1. Fixing a missing closing backtick in the `--pretty` option documentation (patch 6/9)
2. Correcting the HTML rendering behavior of arrow symbols in the `--decorate` option documentation (patch 7/9)

The series represents a comprehensive conversion of Git's second-largest man page, with special handling required for log format descriptions containing escaped parentheses and %-prefixed placeholders. The v2 improvements focused on making the text more translation-friendly by removing puns and improving list formatting. 

The changes span 11 documentation files, with the most substantial modifications in `pretty-formats.adoc` and `rev-list-options.adoc`. The conversion maintains all existing functionality while standardizing the syntax to use AsciiDoc's `[synopsis]` blocks and consistent backtick-wrapped formatting.

This work is part of Git's ongoing documentation standardization effort. The series is now complete with these final formatting corrections, though related discussions continue about space notation and special character handling in the documentation toolchain.
