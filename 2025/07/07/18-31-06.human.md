This is a brief follow-up in the `for-each-ref` pagination series, now in its final stages before merging. Karthik Nayak responds to Junio C Hamano's review of the error message wording for the new `--start-after` option (previously called `--skip-until`). 

Junio noted a missing words in the error message when combining pagination with sorting options, which Karthik confirms will be fixed in the next version. They also discuss the intentional decision to make pagination and sorting mutually exclusive - while there might be niche use cases for combining them, both agree the current design is clearer and more maintainable. 

This exchange represents the final polish on a well-discussed feature that has gone through multiple naming iterations (`--skip-until` -> `--start-with` -> `--start-after`) and technical review. With this last wording tweak addressed, the series appears ready for merging with its O(log N) pagination across all ref backends.
