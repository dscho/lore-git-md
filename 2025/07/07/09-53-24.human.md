This is a follow-up discussion about Perl removal in Git's test suite, specifically addressing issues found in patch 12/20 of Patrick Steinhardt's series. The conversation reveals two problems with the original Perl-to-sed conversion in t5333-pseudo-merge-bitmaps.sh:

1. A missing pipe terminator in a sed command caused empty input to `git update-ref --stdin`, making the test pass incorrectly by not creating any refs. The test's subsequent checks then operated on empty data.

2. While the conversion intentionally changed the format of generated refnames (using full hex IDs instead of incrementing numbers), this wasn't the root cause of the test failure - the missing terminator was.

Patrick acknowledges both issues and confirms he'll send a fix. The discussion highlights how subtle test framework changes can mask real problems, and shows the care needed when converting Perl-dependent tests. This follows earlier post-merge findings by SZEDER Gábor about edge cases in the Perl removal effort.
