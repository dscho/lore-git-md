This is a follow-up discussion in the resolved FreeBSD build system thread, confirming consensus on the platform-specific fix for sysinfo/sysctl detection.

Ramsay Jones acknowledges Eric Sunshine's earlier point about a more comprehensive preprocessor fix in builtin/gc.c that would handle edge cases where both HAVE_BSD_SYSCTL and HAVE_SYSINFO are manually defined. While agreeing this would provide theoretical completeness, Jones maintains that such manual configuration is extremely unlikely in practice. He notes implementing this additional fix would require coordination with Carlo Marcelo Arenas Belon's ongoing work, though the resolution would be straightforward.

The email serves as final confirmation that the simpler build system solution (reordering checks in configure.ac and meson.build) is considered sufficient by all parties, with Junio Hamano having effectively merged the change. Jones leaves open the possibility of a follow-up preprocessor fix if desired, while emphasizing the current solution adequately addresses the real-world FreeBSD build failure scenario. The thread appears effectively closed with technical consensus, with only the minor question of whether to pursue the more conservative (but likely unnecessary) edge-case protection remaining.
