Bug report for Windows compatibility issue. Fabio Frumento reports that Git for Windows 2.50.0 fails to launch on Windows 11 Pro 64-bit, with the Git Bash terminal window appearing briefly then closing immediately. The issue is reproducible and reverting to version 2.49.0 resolves the problem. The report includes a screenshot showing the failed launch behavior but no technical details about the crash or error messages. This appears to be a regression in the Windows-specific components between versions 2.49 and 2.50. The report lacks diagnostic information like Windows event logs or crash dumps that would help pinpoint the root cause, but the clear reproduction steps (upgrade breaks, downgrade fixes) make it a credible regression report that Windows maintainers will likely need to investigate.
