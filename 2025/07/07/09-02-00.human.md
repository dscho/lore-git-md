This is a test improvement patch in the ongoing SSH signing bugfix thread. Patrick Steinhardt points out a potential test isolation issue in redoste's v2 patch for cleaning up temporary files during SSH signing. The test currently exports TMPDIR in the main shell, which could leak into subsequent tests. Steinhardt suggests wrapping the test body in a subshell to properly contain the environment variable.

The proposed fix moves the `export TMPDIR` and signing operations into a subshell, maintaining the test's core verification that no temporary files remain after signing operations (checked via `find`). This refinement doesn't change the test's core purpose but improves its isolation from other tests in the thread's technical solution for the tempfile leak has already been validated, this represents a minor but important test hygiene improvement. The change demonstrates careful attention to test reliability, though it doesn't affect the main bugfix's functionality.
