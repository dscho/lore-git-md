Documentation patch series completing the conversion of `git-log` man page to the new synopsis format. This is the third version of a 9-patch series that standardizes Git's second largest man page and its related documentation files to use AsciiDoc markup consistently.

The series builds on previous work converting Git's documentation to a more structured format, with special handling needed for log format descriptions containing escaped parentheses and %-prefixed placeholders. Version 3 includes minor fixes from version 2, notably correcting a missing backtick in the default format value documentation and standardizing the phrasing around plural placeholders to be more translation-friendly.

The changes span 11 documentation files, with the bulk of the work in `git-log.adoc`, `pretty-formats.adoc`, and `rev-list-options.adoc`. The patch set appears well-polished, with only minor formatting tweaks needed since the v2 version that was already approved. The series is now ready for merging, completing this significant documentation standardization effort.
