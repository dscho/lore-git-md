Documentation patch converting `rev-list-options.adoc` to the new standardized synopsis format, part of Jean-Noël Avila's ongoing documentation standardization effort. This is patch 5/9 in v3 of the series that has already been approved, with v3 addressing final formatting issues.

The patch makes several mechanical formatting changes to `rev-list-options.adoc` to match the project's new documentation style:
1. Wraps all option names and syntax elements in backticks for consistent rendering
2. Converts angle-bracketed placeholders to italicized_ format
3. Adds the '%' character to the set of allowed keyword characters in both asciidoc and asciidoctor configurations
4. Fixes some malformed option synopses

The changes are purely presentational - no content is altered, only formatting. The patch modifies three files:
- `Documentation/asciidoc.conf.in` and `asciidoctor-extensions.rb.in` to add '%' to allowed characters
- `rev-list-options.adoc` for the bulk of the formatting updates

This continues the mechanical conversion work from previous patches in the series, applying the same standardized formatting rules to the rev-list options documentation. The changes are consistent with the project's documentation style guidelines and follow the patterns established in earlier patches.
