Test fix addressing a subtle issue in pseudo-merge bitmap testing. This is the second patch in a series cleaning up test script issues from the Perl-to-shell conversion effort.

The patch fixes a missing terminator ('|') in a `sed` command in t5333-pseudo-merge-bitmaps.sh that was introduced when converting from Perl in commit 6aec8d38fdd. While the test still passed due to a chain of fortunate failures (broken `sed` output being piped to `git-update-ref` which then did nothing), the patch properly terminates the `sed` pattern and makes the test more robust by avoiding the problematic pipe. The change is minimal (2 lines modified) and follows up on SZEDER Gábor's report of test issues post-Perl-removal.

Key technical details: The test creates remote tag references using a `sed` transformation of commit hashes, then verifies pseudo-merge behavior. The original broken version silently failed reference creation but still passed due to empty pseudo-merge patterns matching nothing. The fix ensures references are properly created by both fixing the `sed` command and separating the reference creation into a two-step process (first to file, then to `update-ref`). The test file (t5333-pseudo-merge-bitmaps.sh) exercises bitmap functionality for pseudo-merges, a performance optimization for partial clone operations.
