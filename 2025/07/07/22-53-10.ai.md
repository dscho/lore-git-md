This is the final review call for a bugfix series addressing memory leaks in pack-bitmap.c's bitmap loading paths. The series has gone through six iterations with extensive review from Taylor Blau and Jeff King, and now awaits final confirmation before being marked for inclusion in the 'next' branch.

The three-part series fixes memory leaks when loading corrupt bitmaps through two key changes: (1) removing redundant cleanup code in `load_bitmap()` by relying on callers' `free_bitmap_index()` for uniform cleanup, and (2) adding comprehensive test coverage via a new `test-tool bitmap list-commits-with-offset` helper that enables targeted corruption testing. The test infrastructure improvements include tracking bitmap file positions in a new `map_pos` field in `struct stored_bitmap` and verifying full object lists rather than just counts.
