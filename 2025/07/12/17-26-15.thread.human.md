This thread has addressed platform-specific issues with PCRE2 dependency handling in Git's meson build system, with distinct solutions for macOS and Windows. The final implementation, now queued for inclusion, resolves macOS's broken system PCRE2 installations by adding header verification via `compiler.has_header()`. This provides three behaviors: falling back to built-in PCRE2 when explicitly enabled, disabling with warning in auto mode, or taking no action when disabled. The solution maintains static linking preferences and aligns with Windows handling.

The patch incorporates feedback from multiple contributors: Eli Schwartz proposed the core technical approach, Carlo Arenas verified the macOS solution works and caught a Windows regression, while Eric Sunshine improved the commit message wording. The changes affect both the detection logic in meson.build and the default setting in meson_options.txt (changed from 'enabled' to 'auto').

While this immediate build system fix is now complete, broader questions remain about potential upstream improvements to meson's dependency handling - particularly around header validation - that could make such workarounds unnecessary in the future. These architectural considerations will be addressed separately from the current platform-specific solutions. The thread demonstrates Git's careful approach to build system changes, balancing immediate needs with long-term maintainability.
