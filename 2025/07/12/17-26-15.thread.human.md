This thread addresses improvements to Git's meson build system for handling PCRE2 dependencies across platforms, particularly focusing on macOS and Windows. The core issue involved broken system PCRE2 installations on macOS and subproject fallback behavior on Windows. The solution implements platform-specific fixes: macOS now detects invalid system installations via `compiler.has_header()` verification (with different behaviors for explicit enable vs auto configuration), while Windows properly handles subproject fallback through meson mechanisms.

The technical approach was developed with input from Eli Schwartz (who suggested the macOS verification method) and confirmed working by Carlo Arenas (who also caught a Windows regression that was subsequently fixed). Junio Hamano has approved the solution for inclusion. The discussion also surfaced potential upstream meson improvements for PCRE2 handling that could benefit other projects.
