This thread discusses a build system change affecting how Git handles PCRE2 library dependencies in meson builds. The original patch proposes changing meson's default PCRE2 behavior from "enabled" to "disabled" to match the Makefile's opt-in approach (via USE_LIBPCRE2). The motivation comes from macOS compatibility issues, where the system-provided PCRE2 library is reportedly broken (missing headers) despite passing initial build checks.

The change is minimal - just a single line modification to meson_options.txt - but has implications for users relying on PCRE2 features like `git grep --perl-regexp`. While the patch clearly explains the macOS rationale, it doesn't address whether this affects other platforms or if macOS users will need additional guidance about installing working PCRE2 versions. The patch appears technically sound but leaves some open questions about cross-platform impact and documentation needs.
