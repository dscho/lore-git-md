This is a follow-up discussion about the meson build system's PCRE2 dependency handling. The original patch proposed making PCRE2 support opt-in (disabled by default) in the meson build to match Makefile behavior and avoid issues with macOS's broken system PCRE2 library. 

Brian m. carlson questions whether the change should be macOS-specific rather than global, noting that on Linux systems the system PCRE2 library typically works correctly and users expect PCRE support to be available by default. This suggests the original solution might be too broad in its macOS-focused fix.

The discussion highlights a tension between platform-specific behavior and build system consistency. While the problem is clearly demonstrated on macOS, the proposed fix would affect all platforms. No technical analysis is provided yet about how difficult a platform-specific solution would be to implement in meson. The exchange appears constructive, with Brian raising a reasonable concern about Linux user expectations versus the original macOS-specific motivation.
