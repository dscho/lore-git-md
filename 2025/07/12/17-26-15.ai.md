Build system patch changing the default PCRE2 dependency behavior in meson builds.

The patch changes meson's default PCRE2 dependency from 'enabled' to 'disabled' to match Makefile behavior where PCRE2 is opt-in via USE_LIBPCRE2. The motivation stems from macOS compatibility issues - while macOS includes a system PCRE2 library, it's reportedly broken (missing headers) and can cause build failures despite passing initial checks. This matches cmake's behavior and Git for Windows preferences, but prevents automatic linking against problematic system libraries on macOS.

The change is minimal - a single line modification to meson_options.txt flipping the default value. The commit message explains the macOS-specific rationale clearly, though it doesn't mention whether this affects other platforms. No test changes or additional validation is included, which might be worth noting since PCRE2 functionality is important for features like `git grep --perl-regexp`. The patch appears straightforward but leaves open questions about cross-platform impact and whether macOS users will need explicit documentation about installing proper PCRE2 versions.
