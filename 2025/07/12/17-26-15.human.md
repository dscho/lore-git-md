This is a build system patch addressing a macOS compatibility issue with the Meson build configuration. 

Carlo Marcelo Arenas Belón proposes changing the default PCRE2 dependency setting in Meson from 'enabled' to 'disabled' to match the Makefile's behavior. The current Meson default can cause build problems on macOS, where the system-provided PCRE2 library is broken (it includes a pkgconf module pointing to a non-existent header file).

The change aligns Meson's behavior with Git's Makefile, which requires explicit USE_LIBPCRE2 flag to enable PCRE2 support. While PCRE2 is a popular dependency (and remains available when explicitly enabled), the current default can lead to broken builds on macOS systems. The patch cleanly modifies just one line in meson_options.txt to make this change.

This appears to be a straightforward and well-justified change that prevents a real-world build issue while maintaining all existing functionality for users who want PCRE2 support. The commit message clearly explains both the problem and solution, including technical details about the macOS-specific issue.
