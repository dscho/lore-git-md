This better separates test code from production code while maintaining all existing test functionality.

The change is straightforward and mechanical - it updates the bloom filter test helper to use the new API while keeping identical behavior. This appears to be a preparatory step for the larger bloom filter optimization work, cleaning up the API boundaries before introducing more substantive changes in later patches of the series.
