Platform compatibility issue with Git 2.50+ on RHEL 6. Азат Усманов reports compilation failures when building Git 2.50 and 2.50.1 on RHEL 6 (both 6.6 and 6.10), while the same source compiles fine on RHEL 8. The initial error about missing `random.h` in `compat/posix.h` can be worked around by copying the file, but then reveals deeper issues with macro definitions in `sane-ctype.h` causing syntax errors. The last working version is 2.49.1.

The error output shows multiple compilation failures stemming from the `sane_istest` macro in `sane-ctype.h`, suggesting an incompatibility between Git's character type handling and RHEL 6's C library/headers. The reporter notes both systems use the same GCC version (13.4.0), implying the issue lies in system headers or environment differences rather than the compiler itself. This appears to be a genuine platform-specific build problem affecting users stuck on the older RHEL 6 environment.
