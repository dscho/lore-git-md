This is a test infrastructure patch in the bloom filter optimization series. It refactors how the murmur3 hash function is exposed for testing purposes.

The patch makes `murmur3_seeded_v2()` static in bloom.c since it should not be part of the public API, and introduces a new test-specific wrapper `test_bloom_murmur3_seeded()` that can handle both v1 and v2 hash versions. This better separates test code from production code while maintaining all existing functionality.

Key changes:
- Moves murmur3_seeded_v2() implementation to static scope in bloom.c
- Adds new test_bloom_murmur3_seeded() function that takes a version parameter
- Updates test-bloom.c to use the new test helper instead of the direct murmur3 call
- Maintains ability to test both v1 and v2 hash implementations
- The change is straightforward and maintains all existing test coverage
- Part of a larger performance optimization series for pathspec bloom filters
- Follows good practice of isolating test-only functionality
- No behavior changes for production code paths
