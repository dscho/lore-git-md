This is a feature patch series improving diff context configuration support for interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The series builds on prior work to make builtins respect diff.context and diff.interHunkContext configs, addressing inconsistencies in how these commands handle diff context compared to other Git commands.

The v4 series represents the final implementation after extensive discussion and refinement. Key changes from previous versions include test modernization (converting grep calls to test_grep/test_config), validation for negative context values, comprehensive documentation in diff-context-options.adoc, and command-line override support using OPT_DIFF_* macros. The series has addressed all major design concerns, with Junio accepting the macro approach based on their six users and Phillip Wood approving the config reading implementation.

Technical implementation details:
- Adds diff.context and diff.interHunkContext support to add-patch infrastructure
- Implements command-line overrides (-U/--unified and --inter-hunk-context) using OPT_DIFF_* macros
- Validates against negative values consistently
- Documents new options in command man pages and dedicated diff-context-options.adoc
- Modernizes tests in t3701/t4055 to use test_grep/test_config
- Handles config values, command-line overrides, and validation comprehensively
- Maintains consistency with other diff-generating commands like git log -p

The series touches multiple builtins (add, checkout, commit, reset, restore, stash) and their documentation, along with add-interactive infrastructure. Test coverage is comprehensive, verifying config reading, command-line overrides, and validation. The only remaining open question is optional integration with Réne Scharfe's range validation work, which Junio indicated could be deferred.
