This is a policy discussion email in the ongoing RFC series for Rust integration in Git's xdiff component. Haelwenn Monnier adds to Eli Schwartz's distribution concerns by highlighting potential circular dependency issues if libgit2 (used by Rust's git2 crate) were to depend on a Rust-ified xdiff. The email suggests using meson's Rust support rather than cargo to avoid build system complications, reinforcing Schwartz's earlier points about practical deployment obstacles across various architectures (amd64 build complexity, HPPA/Alpha/m68k incompatibility, s390 binary trust issues). The message underscores unresolved ecosystem challenges beyond the technical merits of the xdiff optimizations, particularly how Rust adoption might impact downstream consumers like libgit2 through build system interactions. This continues the thread's tension between performance benefits and real-world deployment constraints.
