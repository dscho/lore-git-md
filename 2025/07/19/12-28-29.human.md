This is a feature patch series improving context line configuration for interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The series builds on prior work to make these commands respect diff.context and diff.interHunkContext configs, adding command-line overrides (-U/--unified and --inter-hunk-context) as well.

The v4 series represents the culmination of several rounds of review and refinement. Key changes from previous versions include test modernization (converting grep calls to test_grep and test_config), validation of negative values, documentation consolidation, and implementation polish. The most controversial aspect - the OPT_DIFF_* macros - was ultimately accepted after Phillip Wood demonstrated they're used by six commands.

The implementation now:
- Reads and validates diff.context/diff.interHunkContext configs
- Provides command-line overrides that take precedence
- Rejects negative values consistently
- Includes comprehensive test coverage
- Documents the behavior in a new diff-context-options.adoc file

All major technical questions appear resolved, with only minor review comments remaining. The series is functionally complete and ready for merging once those final polish items are addressed. The optional integration with Réne Scharfe's range validation work remains a potential future enhancement.

This represents a significant quality-of-life improvement for users who want consistent diff context behavior across all Git commands, particularly those who frequently use interactive patch operations. The implementation is thorough and well-tested, with careful attention to edge cases and validation.
