The thread discusses the removal of Git's long-dormant `--early-output` feature from the revision machinery. Jeff King (Peff) proposed removing this undocumented 2007-era feature, which was originally added for gitk/QGit but never widely adopted. The patch eliminates 154 lines of code including timer-based output logic and signal handling that had broken multiple times without reports, indicating no active users.

Junio C Hamano, the Git maintainer, has now acked the change, confirming Peff's assessment that the feature has no users. Junio recalled the original gitk RFC that prompted the feature's addition and agreed that complete removal - rather than keeping the option as a no-op - was the right approach given the feature's unused state. With no objections raised during discussion, the patch is now queued for inclusion, marking the final step before this clean-up lands in the codebase. The removal simplifies the revision machinery by eliminating untested, undocumented code that had become a maintenance burden.
