The thread discusses removing Git's long-unused `--early-output` feature from the revision machinery. This feature was added in 2007 to support progressive rendering in GUI tools like gitk, but has seen little use and has been broken multiple times without anyone noticing - including currently not working with commit-graphs. Jeff King proposes completely removing the feature, deleting 154 lines of code across several files that handled the timer-based progressive output system, signal handlers, and related infrastructure.

The removal is justified by the feature's dormant state - it was never properly documented or integrated into GUI tools, and has been broken for extended periods (2011-2017 and currently). The patch removes all related code including the `early_output` field from `rev_info`, the global function pointer, timer logic, and signal handling. While considering keeping the option as a no-op, the author argues for complete removal to simplify the codebase for future work, noting the lack of complaints during extended breakage periods indicates no active users exist.
