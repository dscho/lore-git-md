This is a cleanup patch removing the long-unused `--early-output` feature from Git's revision machinery. The `--early-output` option was added in 2007 to help GUIs progressively render history views, but it was never documented and appears to have never been actually used by any major GUI tools. The patch showing interest from gitk and QGit was never merged, and the feature has been broken multiple times over the years without anyone noticing (including a 6-year period where it didn't work at all). Currently it's incompatible with commit-graphs and produces incorrect output.

Jeff King proposes removing the feature entirely rather than fixing it, arguing it's untested, undocumented, and makes revision code maintenance harder. He considers but rejects a "soft" removal that would keep the option working in a degraded state, as there's no evidence anyone is using it. The patch removes about 150 lines of code across three files.

The removal seems well-justified given the feature's history of neglect and current broken state. The commit message provides thorough historical context and technical rationale, making a strong case that this is dead code that can be safely removed without a deprecation period.
