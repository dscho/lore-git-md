This is a set of Windows build fixes for the ongoing Rust xdiff optimization series. Johannes Schindelin contributes three patches addressing Windows-specific compilation issues that arose from the Rust dependency:

1. The first patch ensures Rust builds GCC-compatible libraries on Windows (where Git for Windows traditionally uses GCC rather than MSVC) by setting appropriate toolchain targets and adding the `userenv` library dependency.

2. The second patch handles library naming differences between MSVC (`xdiff.lib`) and GCC (`libxdiff.a`) builds in both the `build_rust.sh` script and Meson configuration.

3. The third patch adds the missing `userenv` library dependency to Meson builds, resolving linker errors about `GetUserProfileDirectoryW`.

The changes are narrowly focused on making the Rust-enabled xdiff build work on Windows, though Johannes notes that test failures remain under win+Meson configurations. These appear to be practical, well-justified fixes from someone deeply familiar with Windows Git builds, though they don't yet fully resolve all Windows test issues. The patches maintain the series' direction while addressing platform-specific realities.
