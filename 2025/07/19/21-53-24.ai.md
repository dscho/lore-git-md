This is a set of Windows build fixes for the ongoing xdiff Rustification RFC series. Johannes Schindelin contributes three patches addressing Windows-specific compilation issues that emerged when making Rust a hard dependency. The changes focus on toolchain compatibility and build system integration:

1. The first patch ensures Windows builds target GCC-compatible toolchains (rather than MSVC) by adding appropriate Rust target specifications and linking against `userenv`. It updates both CI scripts and `config.mak.uname` to handle 32/64-bit and ARM64 Windows variants.

2. The second patch accommodates MSVC's different library naming convention (`xdiff.lib` vs `libxdiff.a`) in both the `build_rust.sh` script and Meson configuration, making the build system compiler-aware.

3. The third patch fixes a linking error in Meson builds by adding the `userenv` library dependency required by Rust's standard library on Windows, mirroring the solution already implemented for Makefile-based builds.

These changes directly address the Windows build failures noted in the RFC thread while maintaining the series' cross-platform goals. The patches demonstrate careful attention to Git's existing Windows build infrastructure and CI practices, though Johannes notes that Windows+Meson test failures remain unresolved due to CI log access limitations. The changes are narrowly scoped to build system compatibility without modifying the core Rust/C interop logic from the main series.
