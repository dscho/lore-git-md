Feature patch completing interactive diff context configuration support. This is the final patch in a series that adds command-line overrides (`-U`/`--unified` and `--inter-hunk-context`) for interactive patch commands (`add`, `checkout`, `commit`, `reset`, `restore`, and `stash` with `--patch`).

The patch allows users to override the diff context settings on a per-command basis, matching the behavior of non-interactive diff commands. It builds on earlier work that made these commands respect the `diff.context` and `diff.interHunkContext` config settings. The implementation adds validation to reject negative values and ensures the options only work with `--patch` mode.

The changes are comprehensive, touching documentation, command implementations, and adding tests. The patch follows the established pattern from earlier in the series, with Phillip Wood having already approved the approach. This appears ready for merging as the last piece of the long-running effort to standardize diff context handling across Git commands.
