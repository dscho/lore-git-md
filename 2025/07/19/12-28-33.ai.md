This is the final patch in a series implementing command-line overrides for diff context in interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The series builds on earlier work to make builtins respect diff.context` and `diff.interHunkContext` configs.

The patch adds `-U/--unified` and `--inter-hunk-context` command-line options to all interactive patch commands, allowing users to override config settings on a per-invocation basis. This matches behavior in other diff-generating commands like `git diff` and `git log`. The implementation:

- Adds new `OPT_DIFF_UNIFIED` and `OPT_DIFF_INTERHUNK_CONTEXT` macros in parse-options.h
- Extends the `add_p_opt` struct to carry context values through the add-patch infrastructure
- Validates negative values consistently (rejecting them)
- Ensures options are only accepted with `--patch`/`--interactive`
- Updates documentation in a new diff-context-options.adoc file included by all relevant commands
- Adds comprehensive tests verifying the new options work across all commands

The implementation has been through multiple rounds of review, with the macro approach being justified by their use in 6 commands. Validation timing and edge cases were addressed in earlier patches. This final piece completes the feature by wiring up the command-line interface consistently across all interactive patch commands.

Key technical details:
- New fields in `struct add_p_opt` carry context values
- Validation happens in `init_add_i_state()`
- Options override config values when specified
- Negative values rejected consistently
- Documentation/diff-context-options.adoc centralizes the option docs
- Tests cover all commands and verify option validation
