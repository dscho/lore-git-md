This is the second patch in a v6 series refactoring sparse-checkout configuration as part of the `the_repository` removal effort. It moves the `core.sparsecheckoutcone` setting from the `core_sparse_checkout_cone` global variable into the `repo_settings` struct as `sparse_checkout_cone`.

The patch updates all access points to use the new location, carefully avoiding redundant `prepare_repo_settings()` calls by leveraging existing initialization in calling functions. Key changes include:
- Removing the global variable declaration and config parsing from `config.c`
- Adding the new field to `repo_settings.h` and its initialization in `repo-settings.c`
- Updating 10 files to use `the_repository->settings.sparse_checkout_cone` instead of the global
- Maintaining all existing behavior while eliminating global state

The changes are concentrated in sparse-checkout handling code (`builtin/sparse-checkout.c`, `sparse-index.c`, `dir.c`) with some plumbing updates. The patch follows the same pattern established in the first patch of the series for `core.sparsecheckout`, completing the migration of sparse-checkout configuration settings. All technical concerns from previous iterations appear resolved, with careful attention paid to initialization timing and performance.
