This is the third patch in a 4-part series expanding `-h` and `--help-all` support across Git commands. The patch extends the "gentle" repository setup behavior (which allows help output without requiring a Git repository) to also cover `--help-all` requests, matching the existing behavior for `-h`.

The change affects several key areas: the main Git dispatcher (`git.c`), the parse-options infrastructure, and the legacy `merge-recursive` command. The author notes that `merge-recursive` uses older APIs and is likely to be deprecated, so they've kept changes there minimal. The patch also adds test coverage in `t1517-outside-repo.sh` to verify the new behavior.

The implementation appears clean and focused, with clear reasoning in the commit message about why certain approaches were taken (like why they couldn't rely solely on parse-options handling). The changes are relatively small but meaningful, touching about 17 lines across 5 files. This continues the series' goal of making help documentation more accessible regardless of repository context, which should be particularly useful for experts checking option syntax or deprecated features.
