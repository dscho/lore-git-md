This thread documents the finalization of a patch series that expands `-h` and `--help-all` option availability across Git commands. The original goal was to make `--help-all` work outside repository contexts while preserving special cases in commands like `ls-remote` and `grep`. The series went through several iterations, with a controversial aspect—allowing `-h` to be used alongside other arguments—being dropped after maintainer feedback about potential confusion (e.g., `git add -h foo` silently ignoring `foo`).

The v3 series, now complete, includes three patches: test infrastructure fixes, parse-options refactoring using clear `USAGE_NORMAL`/`USAGE_FULL` macros, and git.c adjustments for repository-less help. Junio C Hamano has confirmed the series is merge-ready after verifying that argument-tolerant `-h` behavior remains excluded. D. Ben Knoble and Jeff King contributed reviews, with Knoble recently clarifying a lingering documentation inconsistency in the cover letter that still referenced the dropped feature. This final discussion reinforces the maintainer's position while confirming the technical approach is sound. The series builds on test infrastructure from the ua/t1517-short-help-tests branch and is now awaiting merge.
