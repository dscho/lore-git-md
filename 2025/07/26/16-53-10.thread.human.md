This thread has finalized a three-patch series that improves how Git handles `-h` and `--help-all` help output across commands, particularly in repository-less contexts. The key change is making `--help-all` work consistently outside repositories while preserving special cases like `ls-remote -h` and `grep -h`. 

The series includes test fixes, parse-options refactoring (replacing magic numbers with named constants like USAGE_NORMAL/USAGE_FULL), and git.c modifications to bypass repository checks for help requests. The controversial idea of making `-h` work mid-command was dropped due to security concerns raised by Junio Hamano. 

Jeff King and D. Ben Knoble reviewed the technical approach, and the author has incorporated all feedback into this final version. The parse-options refactoring in particular makes the code more readable while maintaining identical behavior. With consensus reached, these changes are ready for merging.
