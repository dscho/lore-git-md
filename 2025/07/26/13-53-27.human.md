This is a follow-up in the git-daemon regression thread, focusing on SELinux as a potential cause for the tilde expansion issue. Todd Zullinger investigates Jeff King's test case on Fedora 40 and identifies SELinux restrictions as the likely culprit for the path access failures.

Zullinger provides a detailed walkthrough of the necessary SELinux adjustments: ensuring proper directory permissions, setting the correct context type (`git_user_content_t`), and enabling the `git_system_enable_homedirs` boolean. His tests confirm these changes resolve the access issues when accessing repositories via paths like `~user/public_git`.

The email suggests this might be environment-specific to Fedora's SELinux configuration rather than a Git regression, though it remains unclear why this would manifest after an upgrade. Zullinger notes the Fedora git-daemon package could benefit from SELinux documentation similar to what's provided with cgit. The response is thorough and actionable, though the original reporter will need to verify if these steps address their specific setup.
