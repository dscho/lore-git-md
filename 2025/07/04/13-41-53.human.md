This is a naming suggestion in the ongoing `--skip-until` pagination feature thread for `git for-each-ref`. Andreas Schwab proposes renaming the new `--skip-until` option to `--start-with`, arguing that this name makes it clearer whether the matched reference is included in the output (it would be, with this name). 

The suggestion comes as the third version of the patch series is being finalized, which implements O(log N) pagination across all ref backends with comprehensive test coverage. The thread has previously addressed technical concerns about race conditions and interface design, but this email focuses purely on the user-facing option name. 

The current implementation includes the matched reference in the output (as confirmed in earlier discussion), so the proposed name might better communicate this behavior to users. This is a relatively minor UX consideration compared to the substantial technical work already completed in the series.
