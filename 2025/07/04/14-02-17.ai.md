This is a naming discussion for the `git for-each-ref` pagination feature, specifically addressing Andreas Schwab's suggestion to rename the `--skip-until` option to `--start-with`. The thread has progressed through technical implementation and is now focused on finalizing the user-facing interface.

Karthik Nayak responds to the naming proposal by listing alternative options considered (`--skip-to`, `--start-after`, `--start-from`, `--seek`, `--skip-before`, `--start-at`) and explains the semantic implications of each. The key concern is that names like `--start-from` or `--start-at` might incorrectly imply the reference must exist, when the actual behavior seeks to the first reference after the given pattern (whether or not the pattern matches an existing ref). The example shows how `--seek=refs/heads/cat` would start output from `refs/heads/foo` even though `cat` doesn't exist.

The discussion remains open-ended, with Karthik expressing willingness to change the name if consensus emerges.
