This thread addressed a build system issue affecting FreeBSD, where recent changes to `sysinfo()` detection conflicted with FreeBSD's preferred `sysctl()` approach. The problem manifested as build failures, traced to commits 50dec7c566 and 187ce0222f. Ramsay Jones proposed a solution that reorders build system checks in `configure.ac` and `meson.build` to prioritize BSD's native `sysctl()` over `sysinfo` compatibility.

Eric Sunshine reviewed the patch, suggesting a more comprehensive fix involving preprocessor conditionals in `builtin/gc.c` for edge cases where both macros might be manually defined. However, he acknowledged the current solution was adequate for the immediate issue. Renato Botelho verified the fix works on FreeBSD.

Junio Hamano, the Git maintainer, has now concluded the discussion by approving the build system reordering as sufficient. While the theoretical edge case remains open, all parties agree it's not worth addressing immediately, especially given Carlo Marcelo Arenas Belon's ongoing related work that might provide a natural resolution point later. The change preserves behavior on non-BSD systems and cleanly resolves the FreeBSD build failures. With maintainer approval and no outstanding objections, this thread is now effectively closed.
