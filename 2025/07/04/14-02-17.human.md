This is a naming discussion for the new pagination feature in `git for-each-ref`, currently implemented with a `--skip-until` option. The thread has reached its third version with all technical implementation details settled, and now focuses on finalizing the user-facing option name.

Andreas Schwab suggests `--start-with` as a clearer alternative to `--skip-until`, arguing it better conveys whether the matched reference is included. Karthik Nayak responds with several other naming possibilities (`--skip-to`, `--start-after`, `--seek`, etc.) and explains the concern that some names might incorrectly imply the reference must exist. The example shows how the feature works when seeking to a non-existent reference (it starts from the next sorted reference).

The discussion is purely about UX clarity - the underlying implementation (which handles edge cases and maintains O(log N) performance across ref backends) is not in question. This appears to be the final polish before the feature is ready for merging, with all technical aspects already thoroughly reviewed in earlier thread discussion.
