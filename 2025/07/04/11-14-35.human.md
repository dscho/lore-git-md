Refactoring patch in the bloom filter optimization series. This is the second of four patches in v4 of Lidong Yan's performance improvement work for pathspec bloom filters.

The patch standardizes function naming conventions for operations on `struct bloom_key`, renaming `fill_bloom_key()` to `bloom_key_fill()` and `clear_bloom_key()` to `bloom_key_clear()`. This aligns with Git's code style where functions operating on a struct should follow the pattern `structname_verb()`. The changes are mechanical but touch several files including bloom.c/h, revision.c, and test helpers.

This appears to be a straightforward cleanup addressing naming consistency feedback from earlier reviews. The changes don't modify functionality but improve code maintainability by following established patterns. The patch is part of a larger effort to optimize bloom filter performance for multiple pathspec queries, with the series already having undergone several rounds of review.
