This is a follow-up in the documentation thread about `git init --template=` behavior. Han Young confirms the empty-template behavior dates back to Git 1.5.6.4 (2008) where it was implemented to mean "skip template copying" rather than incorrectly linking root directory files. They note this undocumented feature is already widely used by package managers and other tools that create temporary repositories just for fetching remote data, where template files would be unnecessary overhead. The email reinforces the original proposal to document this long-standing behavior, suggesting such documentation would help users understand existing real-world usage patterns. No new technical details are added beyond the historical version reference, but the confirmation of widespread adoption strengthens the case for documenting the behavior. The thread remains focused on documentation rather than behavior changes.
