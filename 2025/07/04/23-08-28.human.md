This is a bugfix for SSH signing functionality that addresses a temporary file cleanup issue. The patch fixes a case where using `strbuf_detach()` on a tempfile's filename would prevent proper cleanup, leaving temporary files behind. The fix is straightforward - replacing the detach operation with a simple `xstrdup()` of the filename buffer.

The change is minimal (just one line in `gpg-interface.c`) but important for proper resource cleanup. The commit message clearly explains the problem and solution, though it might benefit from mentioning that this affects the SSH signing path specifically (as opposed to GPG signing). The fix appears correct and well-targeted, though it would be good to see a test case demonstrating the cleanup issue.
