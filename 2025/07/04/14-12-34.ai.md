This is the first patch in a 2-part series removing `the_repository` usage from `builtin/prune.c`, part of the broader `the_repository` removal effort. The patch migrates the `repository_format_precious_objects` global variable into `struct repository`.

The change moves the configuration flag that prevents object-dropping operations from being a global variable to being repository-specific storage. The patch updates all references to use `the_repository->repository_format_precious_objects` instead of the direct global variable, touching several commands that check this setting (gc, prune, repack). The initialization paths in `repository.c` and `setup.c` are updated to properly set the new field.

This is a straightforward mechanical conversion that follows the established pattern for migrating globals into the repository struct. The changes are limited to the variable's declaration, initialization, and usage sites, with no behavioral changes. The patch is cleanly separated from the second patch that will handle the actual prune command conversion, demonstrating good series organization.

Key technical points for future reference: the flag is now stored in `struct repository` as `repository_format_precious_objects`, initialized during `repo_init()` and `setup_git_directory_gently()`, and checked in gc/prune/repack commands. The change maintains all existing functionality while removing one more global variable dependency.
