Documentation patch continuing the discussion about clarifying `git init --template=` behavior. Boris Kolpackov agrees with Han Young's findings that the empty-template behavior (which skips copying template files has existed since Git 1.5.6.4 and is widely used in practice, particularly by package managers creating temporary repositories. He reinforces the case for documenting this behavior more prominently in the git-init(1) manpage, noting that the current obscurity of the feature doesn't change the fact that tools legitimately depend on it. The email provides additional support for the original patch's goal of documenting this long-standing implementation detail without changing any behavior. No new technical details or objections are introduced - this is essentially a +1 to the proposal with the added observation that undocumented-but-widely-used features deserve documentation precisely because they are relied upon.
