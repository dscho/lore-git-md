Refactoring patch exposing internal ref_iterator interface as part of the `--skip-until` pagination series.

This is the first of four patches in v2 of the series implementing pagination for `git for-each-ref`. It moves the `ref_iterator` interface and related functions from the internal `refs/refs-internal.h` to the public `refs.h`, making them available to external callers. The commit message explains this allows advanced users to compose iterator functionality directly rather than requiring new wrapper functions for each combination of features.

The patch is a straightforward code movement with comprehensive documentation preserved. Key elements exposed include:
- The `ref_iterator` struct and its core operations (`advance`, `peel`, `free`)
- The `do_for_each_ref_flags` enum controlling iteration behavior
- Factory function `refs_ref_iterator_begin()`
- Adapter function `do_for_each_ref_iterator()`

The implementation appears clean and well-documented, with all moved functionality retaining its original form. This foundational change enables the subsequent pagination work while maintaining the existing iteration semantics. The thorough documentation in the header should help consumers use the newly-exposed interface correctly.

This patch doesn't introduce new behavior - it just relocates existing code to make it available for the pagination feature and future extensions. The changes are mechanical but important for the series' architecture.
