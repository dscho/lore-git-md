This is a test infrastructure patch in the bloom filter optimization series. It moves murmur3 hash calculation test functionality out of the public bloom.h API and into a dedicated test helper.

The change makes `murmur3_seeded_v2()` static in bloom.c and introduces `test_bloom_murmur3_seeded()` as the new test interface. This helper maintains the same functionality while better isolating test code from production APIs. The patch updates two test cases in t/helper/test-bloom.c to use the new interface.

This is part of Lidong Yan's v4 series addressing feedback about API cleanliness from Junio Hamano and Patrick Steinhardt. The change is straightforward and mechanical - it doesn't modify any core bloom filter logic, just reorganizes where test utilities live. All test functionality remains intact, just accessed through a more appropriate test-specific interface.

Key technical details:
- Removes `murmur3_seeded_v2()` from bloom.h
- Adds `test_bloom_murmur3_seeded()` wrapper that can handle both v1 and v2 hash versions
- Updates test-bloom.c to use new helper
- Maintains same hash calculation behavior for tests
- Part of broader bloom filter API cleanup effort

The patch appears well-contained and properly motivated as part of the series' goal to improve API boundaries. It addresses prior review feedback while keeping all test functionality working as before.
