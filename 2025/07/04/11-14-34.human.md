This is a refactoring patch in a performance optimization effort for Git's pathspec bloom filters. It's the first of four patches in v4 of the series.

The patch moves murmur3 hash calculation functionality used in tests out of the public API and into a dedicated test helper. Previously, `murmur3_seeded_v2()` was exported in bloom.h for test use, but this was misleading since it's not meant for general use. The patch introduces `test_bloom_murmur3_seeded()` as the proper test interface while making the underlying implementation static.

The changes are straightforward: the hash function is made static in bloom.c, the test helper is added to expose it for testing, and the test-bloom.c utility is updated to use the new interface. This cleanup was suggested in earlier review feedback to better separate test-specific code from the public API.

The patch appears well-contained and properly motivated as part of the larger bloom filter optimization work. It doesn't change any behavior - just reorganizes the code to be more maintainable while preserving all existing test functionality.
