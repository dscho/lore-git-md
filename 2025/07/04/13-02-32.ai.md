Feature implementation completing the `--skip-until` pagination series for `git for-each-ref`. This final patch builds on the ref iterator seek infrastructure introduced in earlier patches to add a user-facing `--skip-until` option that enables efficient pagination of reference listings.

The implementation:
- Adds `--skip-until=<pattern>` option to `git-for-each-ref` that seeks to the first matching reference and iterates from there
- Forbids combining with pattern matching or custom sort options to maintain predictable ordering
- Handles edge cases through extensive test coverage in t6302, including:
  - Empty/partial/missing matches
  - Directory vs exact reference paths
  - Overflow conditions
  - Invalid combinations with other options
- Modifies the ref-filter backend to use the new seek functionality while maintaining existing behavior for other cases

The patch integrates with the series' architectural decisions:
- Uses the ref iterator seek API exposed in patch 1
- Maintains O(log N) performance across all ref backends
- Preserves the documented behavior around concurrent modification
- Follows the established pattern of name-based rather than offset-based pagination

Key technical details:
- Adds `seek` field to `struct ref_filter`
- Modifies `do_filter_refs()` to handle seek operations for both prefix-based and general iteration
- Updates documentation to specify the new --skip-until` option's behavior and restrictions
- Includes 12 new test cases covering various skip scenarios
