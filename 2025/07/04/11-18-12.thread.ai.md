Core problem: Clarifying the correct mechanism for converting SHA-1 object hashes to SHA-256 format during the planned transition. Initial proposal to re-hash SHA-1 strings was incorrect as it would break Git's content-addressable storage model and remain vulnerable to SHA-1 collisions.

Implementation exists in `object-file-convert.c`, with v3 pack index functionality in development. The `repo_oid_to_algop` function handles format conversion. Technical documentation in `hash-function-transition.adoc` outlines the design.
