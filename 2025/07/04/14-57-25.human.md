This is a follow-up in the documentation thread about empty template directories in `git init`. Kristoffer Haugsbakk points out that there's an existing `--no-templates` flag that also prevents template copying, though it works slightly differently from passing an empty path (which the thread has established is a long-standing undocumented feature).

The email shows that when using both `--template` and `--no-templates` together, the template directory contents (like a custom `description` file) are still ignored, suggesting these mechanisms aren't perfectly equivalent. This adds a new dimension to the documentation discussion - while the empty path behavior is clearly useful and should be documented, there may be subtle differences between the various ways to skip template copying that warrant clarification.

The thread continues to be non-controversial, with participants collaboratively working to fully document Git's template behavior. This particular observation about `--no-templates` may lead to additional documentation text explaining the relationship between these different methods.
