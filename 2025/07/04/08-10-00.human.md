Lidong Yan suggests a more specific solution to the problem where remote names containing slashes can cause refname ambiguities. The suggestion appears to be a middle ground between completely banning slashes in remote names (which would break existing setups) and allowing all names (which leads to the current ambiguity problems). The proposal would prevent new ambiguous configurations while grandfathering in existing ones, though the email doesn't specify how this would be implemented in practice.
