This is a documentation patch discussion continuing the thread about clarifying `git init --template=` behavior. Boris Kolpackov agrees with Han Young's findings that the empty template parameter behavior (skipping template copying) has existed since Git 1.5.6.4 and is widely used in practice, particularly by package managers creating temporary repositories. He reinforces the case for documenting this long-standing feature more prominently in the git-init(1) manpage, noting that the current obscure documentation means users are already relying on this behavior without official guidance. The exchange shows consensus building around documenting rather than changing this implementation detail, with no objections raised in the thread. The patch remains straightforward and non-controversial as it would simply codify existing practice.
