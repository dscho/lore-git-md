This is a naming suggestion in the ongoing `--skip-until` feature thread for `git for-each-ref`. Andreas Schwab proposes renaming the new pagination option from `--skip-until` to `--start-with`, arguing the latter more clearly indicates whether the matched reference is included in the output. The suggestion comes as the series is in its third version, with the core implementation already established across all ref backends (files, packed, reftable) with O(log N) performance characteristics. The thread has previously addressed technical concerns around race conditions, interface design, and test coverage, making this a relatively minor stylistic point about command-line UX rather than a substantive technical critique. The proposal doesn't challenge the underlying architecture or behavior - which guarantees the skipped reference is included if it exists - but focuses purely on making that behavior more immediately obvious from the option name itself.
