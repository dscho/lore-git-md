This is a Windows compatibility patch in the ongoing git-daemon signal handling series. It prepares the MinGW compatibility layer for future SIGCHLD handling changes by:

1. Adding SA_NOCLDSTOP flag support (copied from Cygwin) to mingw-posix.h
2. Modifying the sigaction() implementation to:
   - Return -1 (without setting errno) for SIGCHLD, matching current signal() behavior
   - Maintain existing SIGALRM handling
   - Keep EINVAL behavior for other signals

The change is part of the pipe-based child process tracking approach discussed in the thread, specifically enabling Windows compatibility for the signal handling changes planned in subsequent patches. The patch maintains backward compatibility with current Windows behavior while providing the necessary infrastructure for the new approach.

Key technical details:
- Adds SA_NOCLDSTOP flag (value 1) to match Cygwin's definition
- SIGCHLD handling explicitly returns -1 without errno, preserving current Windows behavior
- Other signal behaviors remain unchanged (SIGALRM still works, others still EINVAL)
- Part of preparing Windows support for the pipe-based child tracking system

The patch appears focused and well-contained, directly addressing a specific Windows compatibility need for the broader signal handling changes. It follows the thread's direction of maintaining Windows behavior while enabling the pipe-based approach.
