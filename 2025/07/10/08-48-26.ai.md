This is a test infrastructure patch in the bloom filter optimization series. It refactors how the murmur3 hash function is exposed for testing purposes.

The change moves the murmur3_seeded_v2() implementation from being a public function in bloom.h to being static in bloom.c, replacing it with a new test-specific wrapper test_bloom_murmur3_seeded(). This wrapper provides access to both v1 and v2 murmur3 implementations (though only v2 is currently used in tests) while making it clear this is test-only functionality. The patch updates the test-bloom.c helper to use the new interface.

This appears to be a straightforward implementation of the test/production API separation that was requested in earlier review feedback. The change is mechanical and focused - it doesn't affect production bloom filter behavior, only test infrastructure. The commit message clearly explains the change and its motivation (clarifying test-only exports). All test callers are updated to match the new interface.

- Adds test_bloom_murmur3_seeded() wrapper in bloom.c
- Makes murmur3_seeded_v2() static
- Updates test-bloom.c to use new wrapper
- Maintains ability to test both murmur3 versions (though only v2 is currently used)
