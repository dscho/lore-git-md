This is a refinement to the ref iterator API as part of the `git for-each-ref` pagination series. Patrick Steinhardt provides final review feedback on Karthik Nayak's implementation of the seek functionality for reference iteration.

The patch introduces a new `REF_ITERATOR_SEEK_SET_PREFIX` flag to clearly distinguish between seeking to a position and setting a prefix filter, addressing a subtle behavior difference in the iterator API. Steinhardt suggests two minor documentation improvements: consolidating the flag's documentation in one place and renaming the `seek` parameter to `refname` for clarity.

This represents the final polishing of the technical implementation after the core functionality was already approved. The changes are small but important for API clarity and maintainability. With these last nits addressed, the pagination feature appears ready for merging, having gone through multiple rounds of review and refinement.
