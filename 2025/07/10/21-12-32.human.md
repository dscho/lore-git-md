Build system patch addressing path handling in Meson configuration.

Junio Hamano weighs in on an ongoing discussion about path handling in Git's Meson build system, specifically around the `libexecdir` configuration. The thread involves Ramsay Jones and Patrick Steinhardt, with Ramsay proposing an alternative approach to Patrick's earlier patch series that would fix path handling when `-Dlibexecdir` is overridden.

The core issue stems from how Git's executables and scripts are installed when users specify custom paths. Ramsay demonstrates through several test cases that his proposed solution - using `git_exec_path` consistently rather than recomputing paths from `libexecdir` - works correctly with both relative and absolute path overrides. His patch modifies numerous installation directives in `meson.build` to use this approach.

Junio suggests the two developers coordinate to resolve the conflict, proposing that Patrick's series could potentially proceed as a 7-patch set while they work out the best solution for the path handling issue. The patch appears technically sound based on the test cases shown, though Ramsay notes there may be additional follow-up work needed regarding `GITEXECDIR_REL`. This is part of the ongoing effort to improve Git's Meson build system configuration.
