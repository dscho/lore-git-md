Build system fix addressing Meson installation paths. Ramsay Jones points out that a patch in Patrick Steinhardt's Meson cleanup series (currently marked for merging to 'next') would revert a previous fix for `GIT_EXEC_PATH` handling when `-Dlibexecdir` is overridden. Jones proposes an alternative fix that he believes would be better than the revert, though he notes it still needs more testing and may have additional issues to address.

The email includes detailed demonstration of the current behavior with different `libexecdir` settings (default, relative path, and absolute path), showing the installation locations and symlink behavior. The proposed patch changes all `libexecdir/git-core` references to use `git_exec_path` instead, which should properly handle custom `libexecdir` paths. Jones acknowledges this is still a work in progress but suggests it might be ready soon enough to replace the revert in the series.
