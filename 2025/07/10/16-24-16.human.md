This is a build system improvement patch in Patrick Steinhardt's Meson modernization series. The patch enhances the build system's feature detection summary output to show version numbers for dependencies (like curl 8.14.1 and expat 2.7.1) and formats boolean values as colorized YES/NO instead of true/false. 

The change is purely cosmetic - it doesn't affect Git's functionality - but makes the build output more informative and readable. Toon Claes has reviewed and approved the change, and Junio Hamano's brief reply indicates acceptance of the improvement. 

This was patch 3/8 in a series that has now reached full consensus among reviewers, with all technical concerns resolved. The series as a whole modernizes Git's build infrastructure, and this particular patch focuses on improving the clarity of the build configuration summary shown to developers.
