Platform compatibility patch fixing Windows signal handling typos in the final version of a series transitioning Git daemon to use sigaction() for SIGCHLD. This is the first of two patches in v4, which has already received Junio Hamano's approval for queuing.

The patch corrects two typos in the Windows compatibility layer for sigaction() - "Cygwinr" to "Cygwin" and "sigacgtion" to "sigaction". It maintains Windows-specific behavior where the function returns SIG_ERR without setting errno, matching the existing signal() implementation. The change also includes Cygwin's SA_NOCLDSTOP flag in the compatibility layer, though the implementation doesn't actually use this flag.

This is part of a completed effort to modernize signal handling in the Git daemon, with all technical issues resolved across platforms. The series preserves POSIX-consistent behavior while maintaining Windows compatibility, and explicitly defers pipe-based process tracking to future work. The patch represents the final polish on Windows-specific details before integration, with documentation planned as a separate follow-up.
