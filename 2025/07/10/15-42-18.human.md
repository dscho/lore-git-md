This is a refactoring patch in the performance optimization series for pathspec bloom filters. It's a follow-up to Derrick Stolee's earlier work, now being reviewed by Lidong Yan.

The patch extracts the pathspec-to-bloom-key conversion logic from `prepare_to_use_bloom_filter()` into a new helper function `convert_pathspec_to_filter()`. This makes the code more modular and prepares for handling multiple pathspecs in line with the series' goal of optimizing combined pathspec queries. The changes are cleanly separated from the main optimization work and focus on improving code organization. Lidong approves the change and suggests squashing it with patch 3 in the next version of the series. The patch maintains all existing functionality while making the code more maintainable - a straightforward improvement that fits well with the ongoing work.
