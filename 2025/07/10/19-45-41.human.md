This is a v4 patch series addressing signal handling in the Git daemon, specifically focusing on OpenBSD zombie process cleanup and Windows compatibility. The series represents Carlo Marcelo Arenas Belón's latest refinement of the pipe-based child process tracking approach that has been under discussion.

The two patches:
1. Enable `sigaction(SIGCHLD)` on Windows by adding necessary defines and handling
2. Replace `signal()` with `sigaction()` in the daemon code while explicitly avoiding SA_RESTART to maintain expected behavior

Key changes from v3 include dropping two patches per Phillip Wood's suggestion and focusing on the core signal handling modifications. The implementation now ensures BSD signal semantics without relying on SA_RESTART, which was a point of contention in earlier versions. The series appears technically sound, with clean diffs and clear commit messages, though the Windows-specific aspects may need review from platform experts. This continues the OpenBSD zombie cleanup work while maintaining compatibility with the evolving consensus to eliminate SA_RESTART dependence.
