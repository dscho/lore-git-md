Git commit verbose scissor-line bug report with VS Code editor.

Bug report describes unexpected behavior in `git commit --verbose` when VS Code is configured as editor (`core.editor = code --wait`). Reporter observes that text below the scissor-line marker (`# ------------------------ >8 ------------------------`) is incorrectly included in the final commit message rather than being stripped as expected. Reproduction case uses Git 2.50.1 on macOS ARM64 with `commit.verbose = true` and `git ci -a` alias. Issue appears specific to VS Code's handling of Git's temporary commit message file during verbose commit workflow. No root cause identified yet. May affect VS Code users relying on verbose commits.
