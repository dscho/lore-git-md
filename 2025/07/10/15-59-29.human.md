This is a follow-up in the gitk Tcl/Tk error thread, confirming the issue stems from distribution backports rather than upstream Git. Junio Hamano initially worried the problem might indicate a botched backport in Git's own maintenance releases, but after checking confirms Git 2.43.7 and later versions are unaffected. The error occurs when distribution packagers attempt to backport security fixes to older Git versions, as previously diagnosed by Johannes Sixt. The thread now clearly establishes this as a downstream packaging issue rather than an upstream bug, with Ubuntu's bug #2116253 serving as a reference case. No further action is needed from the Git project itself, as the fix must come from distribution maintainers. The exchange provides useful clarification for anyone encountering similar errors to check their distribution's packaging rather than reporting upstream.
