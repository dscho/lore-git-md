[What's cooking in git.git for June 2024] Junio C Hamano provides a comprehensive status update on in-flight Git development topics. The reftable backend is being made the default format for new repositories when experimental features are enabled in Git 3.0. Multiple patches continue the effort to remove `the_repository` global variable, particularly in object-file and object-store subsystems. Performance optimizations include O(n^2) to O(n) improvement in `git fetch --prune` and batched reference updates for fetch/push operations. New commands proposed: `git last-modified` to show file modification times and `git repo-info` for repository characteristics. Documentation, test, and build system improvements are progressing. The update highlights topics that have graduated to 'master', new proposals, ongoing work, and discarded patches, with source references for each topic. Several changes are marked as needing feedback ("Comments?") or expecting updates ("Expecting a reroll"). Key participants include Patrick Steinhardt (reftable, ODB abstraction), René Scharfe (`the_repository` removal), and others contributing to performance optimizations and new features. Open questions remain about the readiness of some changes for merging, particularly around experimental features in Git 3.0.
