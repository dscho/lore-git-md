Refactoring patch in a series moving MIDX tracking to per-source storage. This is the second of eight patches in the series, following the initial introduction of per-source MIDX storage.

The patch simplifies `prepare_packed_git_one()` to work directly with `struct odb_source` rather than taking separate repository and object directory parameters. Since the previous patch already attached MIDX information to the source structure, this removes the need to search for a matching MIDX - it can now be accessed directly from the source. The change makes the code more straightforward by eliminating some intermediate steps and better aligning with the series' goal of moving MIDX handling to be source-specific.

Justin Tobler reviewed the change positively, noting how the consolidated `odb_source` structure (containing MIDX, object directory, and repository pointers) allows for cleaner code. The patch appears to be a straightforward mechanical conversion that builds on the foundation laid by the first patch in the series.

This continues the incremental refactoring approach seen in the first patch, maintaining compatibility while moving toward the eventual removal of global MIDX tracking. The changes are focused and well-contained, touching only `packfile.c` with a net reduction of 5 lines.
