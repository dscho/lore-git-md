This is a monthly "What's cooking" status report from Junio C Hamano, summarizing the current state of Git development. These reports are essential for tracking progress across multiple ongoing efforts in the Git project.

The report covers several categories of work:

1. **Recently graduated to master**: The batched ref updates feature (`kn/fetch-push-bulk-ref-update`) has been merged, improving performance of `git fetch` and `git push` operations.

2. **New topics**: Several small fixes and improvements are queued, including:
   - Documentation updates for ref packing heuristics
   - Cleanup of empty parent directories in ref creation
   - A test TAP format fix
   - Proposals to deprecate `core.commentChar=auto`
   - Significant refactoring work around the object store and multi-pack-index handling

3. **Ongoing cooking topics**: Many active branches are being tested, including:
   - Build system improvements (Meson, FreeBSD fixes)
   - Test suite modernization
   - Performance optimizations (dangling ref reporting, changed-path filters)
   - The transition to SHA-256 as default hash algorithm
   - Continued work to remove `the_repository` global variable
   - New commands like `git last-modified` and `git repo-info`

4. **Stalled or awaiting updates**: Several topics marked as needing rerolls or responses, including sparse checkout variable cleanup, rebase instruction format handling, and submodule path reuse improvements.

The report also notes some discarded work that was either superseded or deemed problematic. Overall, it shows active development across many areas of Git, with particular focus on performance, code quality, and preparing for major changes like the SHA-256 transition and reftable becoming the default ref backend.
