This is a refactoring patch in Patrick Steinhardt's series to remove `the_repository` from object-file.c, specifically focusing on loose object iterators. The patch converts two key iteration functions to use `odb_source` and object database parameters instead of relying on the global repository state.

The main changes rename and modify `for_each_loose_file_in_objdir()` to take an `odb_source` parameter (now called `for_each_loose_file_in_source()`), and refactor `for_each_loose_object()` to accept an object database. This continues the series' pattern of making object-file operations repository-agnostic by passing dependencies explicitly. The changes affect 10 files with 31 lines added and 31 removed, showing a clean mechanical conversion of callers to the new interfaces.
