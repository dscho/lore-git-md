Bug report about `git commit --verbose` behavior with scissor-line text.

This is a bug report describing unexpected behavior in `git commit --verbose` when used with VS Code as the editor. The reporter notes that when using `git commit --verbose` (aliased to `git ci -a` in their setup) with VS Code configured as the editor via `core.editor = code --wait`, the commit message includes all text below the scissor-line (the `# ------------------------ >8 ------------------------` marker) rather than stripping it as expected.

The reporter provides clear reproduction steps and system information showing they're using Git 2.50.1 on macOS (ARM64) with VS Code as their editor. The key configuration elements are the verbose commit setting (`commit.verbose = true`) and the VS Code editor configuration. The issue appears to be specific to the interaction between Git's verbose commit message generation and VS Code's handling of the temporary commit message file, though the exact root cause isn't specified in the report. This could potentially affect users who use VS Code-based Git workflows with verbose commit messages.
