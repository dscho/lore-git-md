This is a test infrastructure patch in a performance optimization series for Git's pathspec bloom filters. It refactors how the murmur3 hash function is exposed for testing purposes.

The patch removes direct exposure of `murmur3_seeded_v2()` from bloom.h and replaces it with a new test-specific wrapper function `test_bloom_murmur3_seeded()`. This better separates test code from production code while maintaining the same testing capabilities. The change affects bloom.c, bloom.h, and the test-bloom.c helper.

This appears to be a straightforward cleanup that improves code organization by making the testing boundary more explicit. It's part of a larger series (1/4) that's been through multiple review iterations, with this particular change addressing earlier feedback about API boundaries. The patch is small, focused, and well-contained, with no apparent controversy in its approach.
