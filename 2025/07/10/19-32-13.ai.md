This is a build system patch addressing an issue with Meson-based Git installations when `-Dlibexecdir` is overridden. Ramsay Jones identifies a regression introduced by commit 837f637cf51 ("meson.build: correct setting of GIT_EXEC_PATH") that's being reverted in Patrick Steinhardt's meson-cleanups series. Jones proposes an alternative fix that directly uses `git_exec_path` instead of recomputing paths from `libexecdir`, demonstrating correct behavior with various `libexecdir` configurations (default, relative, and absolute paths).

The patch modifies `meson.build` to consistently use `git_exec_path` for installation locations of Git executables and related files, affecting core commands (`git`, `git-shell`), helper tools (`git-daemon`, `git-http-backend`), and Perl/Python scripts. Jones notes there may be additional issues with `GITEXECDIR_REL` that need investigation but considers those separable from this fix. The change maintains compatibility with both older and newer Meson versions' path handling.

This appears to be a well-reasoned alternative to the series' current approach, with practical testing shown for different installation scenarios. The patch touches fundamental installation paths but focuses narrowly on the regression while acknowledging follow-up work may be needed. The thread context shows this is part of ongoing Meson build system improvements being coordinated with Junio Hamano.
