Typo fix for ongoing object-file refactoring series.

Toon Claes spots a minor typo in Patrick Steinhardt's large series refactoring Git's object database handling. In patch 9/19, which introduces a new `odb_write_object()` interface, the flag documentation contains a typo ("gose" instead of "goes"). This is a straightforward documentation correction that doesn't affect the series' technical content.

The patch being referenced is part of the major effort to make Git's object-file subsystem repository-agnostic by removing `the_repository` dependencies. While this particular email doesn't engage with the technical substance of the changes, it demonstrates the careful review the series is receiving from the community. The typo appears in the documentation for the `WRITE_OBJECT_QUIET` flag, which suppresses error output during object writing.

This kind of nitpick is common in large refactoring series where reviewers examine both the high-level architecture and low-level details. The correction would likely be folded into the existing patch during a reroll of the series.
