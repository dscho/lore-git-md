Bugfix for `git commit --verbose` scissor-line behavior. This reports an issue where text below the scissor-line (the `# ------------------------ >8 ------------------------` marker) is incorrectly included in the final commit message when using `git commit --verbose` with VS Code as the editor. The reporter provides clear reproduction steps showing the problem occurs with Git 2.50.1 on macOS (ARM64) when using the `code --wait` editor configuration.

The commit message suggests this is a regression in behavior, as the expected outcome is for text below the scissor-line to be automatically stripped (which is Git's normal behavior). The report includes relevant configuration details (core.editor, commit.verbose setting) and uses standard Git bug report format, making it easy to investigate. No workaround is mentioned, implying this may be a hard failure in the current version. The issue appears specific to VS Code integration rather than being a general editor problem.
