This is part 7/8 of Patrick Steinhardt's series refactoring MIDX handling to integrate with the object database (ODB) source system. The patch eliminates redundant information stored in MIDX structures that duplicates data already available in their owning ODB source.

The key changes remove three redundant fields from `struct multi_pack_index`:
1. The `local` flag (now accessed via `source->local`)
2. The object directory path (now via `source->path`)
3. The repository pointer (now via `source->odb->repo`)

The patch updates all MIDX-related code to use the source pointer instead of the removed fields, affecting MIDX loading, writing, bitmap handling, and revindex operations. Changes span midx.c, midx-write.c, pack-bitmap.c, pack-revindex.c, and several callers. The test helper is updated to print the path from the source rather than the (now removed) MIDX field.

This continues the series' systematic elimination of MIDX/ODB redundancy, with all changes being mechanical field access updates rather than functional changes. The patch maintains identical behavior while simplifying the data structures. One notable technical detail is how path computations now consistently use `source->path` where they previously used MIDX's `object_dir`.
