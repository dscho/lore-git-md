This is the final version of a feature series adding diff context configuration support to interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The series has gone through extensive review and refinement over multiple versions, with all major technical concerns now addressed.

The key improvements in v5:
1. Restores three important test cases that were accidentally dropped in v4, ensuring comprehensive coverage of config-based behavior
2. Removes redundant -U option tests from t4055 that duplicated coverage in t3071
3. Maintains all 45 test modernization conversions (38 grep->test_grep and 7 git config->test_config)

The series now provides:
- Consistent respect for diff.context and diff.interHunkContext configs in all interactive patch commands
- New command-line overrides (-U/--unified and --inter-hunk-context) that take precedence over configs
- Proper validation rejecting negative context values
- Centralized documentation in diff-context-options.adoc
- Modernized test infrastructure throughout

The implementation has been thoroughly reviewed by Phillip Wood and Junio Hamano, with Phillip providing the final test fixup patch to complete coverage. The series is now merge-ready, representing a significant improvement in configurability for interactive patch workflows.
