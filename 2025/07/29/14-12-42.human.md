This is part 3 of an 8-part refactoring series to better integrate Git's multi-pack index (MIDX) with the object database (ODB) system. The patch focuses on modifying how in-memory alternate ODB sources are handled.

The key change makes `odb_add_to_alternates_memory()` return the newly created ODB source pointer rather than being void. This prepares for future need to access these sources, though the commit message notes this capability isn't immediately used yet. The implementation required modifying both the declaration in odb.h and the underlying helper `link_alt_odb_entry()` to propagate the source pointer up the call chain.

The changes appear straightforward and mechanical conversions of the function signatures and return value handling. The patch maintains all existing functionality while adding the ability to track created sources. This continues the series' pattern of methodical refactoring to support the larger goal of eliminating redundant MIDX information by better integrating with ODB sources.

As with previous patches, this maintains backward compatibility of the error handling behavior while setting up infrastructure for future changes.
