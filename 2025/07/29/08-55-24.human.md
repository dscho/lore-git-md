Bugfix for reflog migration identity handling. This is part of Patrick Steinhardt's ongoing series improving reflog infrastructure, now at version 3 with 9 patches.

The patch fixes an issue where reflog entries being migrated between storage formats (like files to reftable) were getting malformed committer identities. The code was incorrectly passing the full identity string as just the email parameter to `fmt_ident()`, resulting in output like "pks <Patrick Steinhardt ps@pks.im>". The fix properly splits the identity line into name and email components first.

The change adds new string buffers to store the split name and email components, avoiding repeated allocations during migration. While the fix is straightforward, the commit notes that tests will be added in a follow-up patch that tightens reflog verification in t1450, which will catch this issue along with another bug.
