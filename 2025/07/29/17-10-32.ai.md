This is a feature patch adding SMTP autoconfiguration to `git send-email`. The patch introduces a new `--get-smtp-server` option that attempts to automatically discover SMTP settings for a given email address through three fallback methods: querying Mozilla's ISPDB, checking the email provider's autoconfig endpoint, and falling back to MX record lookup for custom domains.

The implementation adds 153 lines to `git-send-email.perl` and 55 lines of documentation. It introduces several new Perl module dependencies (Net::DNS, URI::Escape, XML::LibXML) to handle DNS lookups, URL encoding, and XML parsing of the autoconfig responses. The feature is modeled after Thunderbird's autoconfig system and includes thorough documentation showing example output and mapping between the discovered settings and Git's existing SMTP configuration options.

Key technical details:
- The feature is activated via new `--get-smtp-server` flag
- Three discovery methods are tried in order: Mozilla ISPDB, provider autoconfig, MX records
- Output shows server, port, encryption type, and username mapping
- New helper functions: `fetch_config_mozilla_ispdb`, `fetch_config_domain_autoconfig`, `get_mx_base_domain`
- Requires additional Perl modules beyond current dependencies
- Settings map to existing `sendemail.*` config options (smtpServer, smtpServerPort, etc.)

The patch appears well-structured with clear documentation and fallback paths. The implementation follows Thunderbird's established autoconfig protocol, suggesting it should work reliably for major email services. The main considerations for reviewers would be the new dependencies and whether the autoconfig behavior should be integrated more tightly with the existing send-email flow rather than being a separate mode.
