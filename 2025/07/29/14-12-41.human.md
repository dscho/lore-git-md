This is the second patch in an 8-part series refactoring Git's multi-pack index (MIDX) handling to better integrate with the object database (ODB) system. The patch modifies `odb_find_source()` to return NULL when an object directory source cannot be found, rather than dying immediately. This prepares for future patches that will need to handle missing sources gracefully.

The change moves the error handling to the callers (in `builtin/commit-graph.c` and `midx-write.c`), which now explicitly die with an error message when the source is not found. The patch is small (8 lines changed across 4 files) and focused, with clear mechanical changes that maintain existing behavior while enabling future work.

This appears to be a straightforward preparatory change in the larger MIDX/ODB refactoring effort, following good practices by keeping the scope narrow and maintaining backward compatibility. The patch follows the series' theme of making ODB source handling more robust and flexible.
