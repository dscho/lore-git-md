This is a documentation and code reorganization patch in Patrick Steinhardt's ongoing reflog infrastructure series (now at v3 with 9 patches). The patch improves the logical grouping of `git reflog` subcommands in both documentation and implementation.

The changes reorder subcommands to place read-only operations (`show`, `list`, `exists`) before write operations (`delete`, `drop`, `expire`), and moves the bulk `expire` command to the end. This creates a more intuitive progression from inspection to modification commands, and prepares for the upcoming introduction of a new `write` subcommand in later patches.

The patch is straightforward - it reorganizes the subcommand listings in both the man page and the C code while keeping all functionality identical. The commit message clearly explains the motivation for the reordering, noting it will help accommodate future additions to the command set. As a pure reorganization with no behavior changes, this is a low-risk change that improves maintainability.
