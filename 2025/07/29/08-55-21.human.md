Refactoring patch in Patrick Steinhardt's reflog migration series. This is patch 3/9 in v3 of the series, which exports the previously internal `ref_transaction_update_reflog()` function to make it available for other parts of the codebase that need to write reflog entries.

The change makes this utility function public by moving its declaration to refs.h and removing the `flags` parameter since all current callers use the same set of flags (REF_HAVE_OLD, REF_HAVE_NEW, REF_LOG_ONLY, etc.). The function's documentation is updated to clarify that the index parameter defaults to ordering by refname when zero.

This is a preparatory change for upcoming work in the series that will need to write reflog entries from other parts of the code. The patch maintains all existing functionality while cleaning up the interface. The implementation appears straightforward and well-contained, with no behavior changes beyond the intended exposure of the function.
