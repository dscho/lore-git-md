This is part 7 of an 8-part refactoring series integrating Git's multi-pack index (MIDX) with the object database (ODB) source system. The patch eliminates redundant information stored in MIDX structures that duplicates data already available in their owning ODB source.

The key change removes three redundant fields from `struct multi_pack_index` - the object directory path, locality flag, and repository pointer - since these are already tracked in the associated `struct odb_source`. The patch updates all MIDX-related code to instead access this information through the source pointer, which was made consistently available in earlier parts of the series.

Changes touch MIDX reading, writing, and utility functions across several files (midx.c, midx-write.c, pack-bitmap.c etc.), with callers now consistently using `m->source->path` instead of `m->object_dir` and similar substitutions for the other fields. The patch maintains all existing functionality while simplifying the data structures.

This continues the series' systematic approach to removing MIDX/ODB redundancy, building on previous parts that established the source pointer infrastructure. The changes are mechanical but thorough, updating all affected code paths to use the new access pattern. As with earlier parts, this appears to be a well-executed step in the larger refactoring effort.
