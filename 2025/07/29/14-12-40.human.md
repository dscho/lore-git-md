This is the first patch in an 8-part series refactoring Git's multi-pack index (MIDX) handling to better integrate with the object database (ODB) source system. The patch focuses on tracking locality (whether a source is the primary repository or an alternate) directly in the ODB source structure rather than computing it repeatedly.

The change adds a `local` boolean field to `struct odb_source` and initializes it when creating sources, removing the need to determine locality by checking if a source is first in the list. This affects MIDX and packfile preparation functions, which now use the stored locality rather than receiving it as a parameter.

The patch touches several key files including midx.c, odb.c, and packfile.c, with straightforward changes that replace the dynamic locality checks with the new stored field. This appears to be a clean, focused refactoring that simplifies the code while maintaining the same behavior. As the first step in a larger series, it lays groundwork for further MIDX/ODB integration work.
