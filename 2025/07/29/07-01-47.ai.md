This is the final version (v5) of a feature series adding diff context configuration support to interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The series builds on earlier work to make builtins respect diff.context and diff.interHunkContext configs.

The key changes in this version are test adjustments based on feedback from Phillip Wood: restoring three accidentally removed config-based behavior tests in t3701 ('add -p respects diff.context', 'add -p respects diff.interHunkContext', 'add -p rejects negative diff.context') and removing 6 redundant -U tests from t4055 that duplicated t3071 coverage. These changes complete the test coverage requirements for merge.

The series now provides consistent diff context configuration through both config (diff.context/diff.interHunkContext) and command-line (-U/--unified, --inter-hunk-context) overrides, with proper validation. The implementation touches multiple builtins and the add-interactive infrastructure, with comprehensive test coverage (including 45 test_grep/test_config conversions) and centralized documentation in diff-context-options.adoc.

All major design concerns have been addressed, including:
- OPT_DIFF_* macros (justified by 6 existing users)
- Validation patterns
- -1 sentinel value handling
- Integration with Réne Scharfe's validation work (considered non-blocking)
