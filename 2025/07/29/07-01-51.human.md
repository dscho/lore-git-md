This is the final patch in a series adding command-line overrides for diff context settings to interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The series builds on earlier work making these commands respect diff.context and diff.interHunkContext configs.

The patch adds -U/--unified and --inter-hunk-context options to all interactive patch commands, allowing users to override the config settings on a per-invocation basis. This matches the behavior in other diff-generating commands like `git diff` and `git log`. The implementation includes:

- New OPT_DIFF_UNIFIED and OPT_DIFF_INTERHUNK_CONTEXT macros for consistent option handling
- Validation matching the config behavior (rejecting negative values)
- Documentation updates in a new diff-context-options.adoc file included by all affected commands
- Comprehensive tests verifying the command-line overrides work and properly reject invalid values

The patch series has gone through multiple rounds of review, with test coverage being a particular focus. This final version restores some accidentally removed config-based tests and removes redundant test coverage, addressing the last round of feedback. The implementation is now ready for merging, providing consistent diff context configuration through both config and command-line overrides.
