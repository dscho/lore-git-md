This is part 3 of an 8-part refactoring series integrating Git's multi-pack index (MIDX) with the object database (ODB) system. The patch modifies ODB source creation to return newly created in-memory sources rather than being void functions.

The key changes are:
- `link_alt_odb_entry()` and `odb_add_to_alternates_memory()` now return `struct odb_source*` instead of `void` or `int`
- Callers can now access the newly created source pointer directly
- The change enables future patches to work with these sources more easily
- Internal helper functions are updated to pass strings directly rather than strbufs where possible
- Error handling remains similar but now returns NULL on failure
- Memory management remains the caller's responsibility

The patch continues the series' pattern of methodical refactoring, this time focusing on making ODB source creation more flexible for upcoming changes. While not immediately used, this prepares for future patches that will need to reference these sources. The changes are contained to odb.c/odb.h with straightforward mechanical updates to function signatures and call sites.
