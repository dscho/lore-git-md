This is a preparatory refactoring patch for the `--max-depth` diff series, originally authored by Jeff King and now being proposed by Toon Claes. The patch fixes an initialization issue in the combine-diff machinery where filepair structs weren't being zeroed out, potentially containing random values in unused fields.

While the patch notes that some fields like `status` might benefit from explicit values in the future, it leaves that for potential follow-up work since the current behavior matches what happens when `diffcore_std` isn't used.

This appears to be a clean, low-risk change that improves code hygiene in preparation for the main feature addition.
