Refactoring patch in the multi-pack index (MIDX) series, focusing on loading MIDX files via their object database source. This is part 5 of an 8-part series working to eliminate redundancy between MIDX and ODB structures.

The patch changes how MIDX files are loaded by using the object source (`odb_source`) rather than passing repository and path parameters. This removes duplicate information (like the object directory path and locality flag) since these are already tracked in the source structure. The change affects several MIDX-related commands and test helpers, requiring them to handle alternate object directories by adding them as in-memory alternates when needed.
