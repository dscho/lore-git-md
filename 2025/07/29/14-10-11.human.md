This is a build system fix addressing an issue with the Meson build configuration. The patch ensures the correct "clar-decls.h" header is used when building unit tests, preventing potential conflicts between Makefile and Meson builds.

The problem occurs when a source tree is built with both Makefile and Meson - the Meson build might accidentally include a stale "clar-decls.h" generated by Makefile, leading to compiler errors. This follows a similar fix made earlier for "version-def.h".

The solution adds a preprocessor define to explicitly specify the absolute path to the correct "clar-decls.h" file in the Meson build configuration. The unit-test.h header is modified to use this define when available, falling back to the relative path include for backward compatibility.
