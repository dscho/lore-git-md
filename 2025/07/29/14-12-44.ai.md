This is part 5 of an 8-part refactoring series integrating Git's multi-pack index (MIDX) handling with the object database (ODB) source system. The patch focuses on loading MIDX files through their ODB source rather than passing redundant parameters.

The key changes:
- Modifies MIDX loading functions (`load_multi_pack_index_one`, `load_multi_pack_index_chain`) to take an `odb_source` parameter instead of separate repository/path/local parameters
- Updates callers including `verify_midx_file` and test helpers to use the new interface
- Handles edge cases where MIDX files exist outside the main object directory by adding them as in-memory alternates
- Maintains all existing functionality while removing duplicate information fields

Technical details:
- Changes MIDX loading to work through `struct odb_source` consistently
- Adds `handle_object_dir_option` helper for command-line tools to resolve object directories to sources
- Updates test infrastructure to use the new loading mechanism
- Modifies 5 files with net +62/-52 line changes
- Preserves all existing error messages and behavior

The patch continues the series' pattern of deduplicating information between MIDX and ODB structures by eliminating redundant path and repository parameters. It surfaces one edge case around external MIDX files that is handled by treating them as alternates. The changes are focused and mechanical, following the groundwork laid by earlier patches in the series.
