Feature addition to Git's diff subsystem, implementing `--max-depth` for tree diffs. This is the main patch in a 3-part series originally authored by Jeff King and now proposed by Toon Claes, adding depth-limiting functionality to diff operations.

The patch introduces a new `--max-depth` option that limits recursion in tree diffs, measured from the closest pathspec match. Key implementation details:
- Adds `max_depth` and `max_depth_valid` fields to `struct diff_options`
- Implements depth checking in `tree-diff.c` with new helper functions `check_recursion_depth()` and `should_recurse()`
- Adds comprehensive documentation showing depth behavior with various pathspecs
- Includes 109 lines of new tests in `t4072-diff-max-depth.sh` covering tree comparisons (additions, modifications, deletions) and verifying edge cases
- Explicitly disallows use with wildcard pathspecs and non-tree diffs (index/worktree)

The implementation differs from `git grep --max-depth`'s approach, maintaining separate code paths. The patch builds on preparatory fixes from earlier in the series (zero-initialized diff_filepair allocation and depth calculation consistency). Test coverage appears thorough, exercising various depth levels with and without pathspecs.

Open questions from the thread remain about potential unification with `git grep`'s approach and whether combine-diff filepairs need special handling, but this patch provides a clean standalone implementation for tree diffs.
