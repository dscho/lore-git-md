[PATCH] git-send-email: add SMTP autoconfiguration via --get-smtp-server

This patch introduces SMTP server autodiscovery for git send-email, implementing a feature that automatically determines SMTP settings for a given email address. The implementation follows Thunderbird's autoconfig protocol with three fallback methods: querying Mozilla's ISPDB, checking the email provider's autoconfig endpoint, and falling back to MX record lookup for custom domains.

The technical implementation adds 153 lines to git-send-email.perl and 55 lines of documentation, introducing new helper functions (fetch_config_mozilla_ispdb, fetch_config_domain_autoconfig, get_mx_base_domain) and requiring additional Perl modules (Net::DNS, URI::Escape, XML::LibXML). The discovered settings map to Git's existing sendemail.* configuration options (smtpServer, smtpServerPort, etc.).

Key open questions for reviewers include whether the new Perl module dependencies are acceptable and whether the autoconfig behavior should be more tightly integrated with the main send-email flow rather than operating as a separate --get-smtp-server mode. The patch currently presents the feature as a standalone configuration discovery tool that outputs the detected settings without automatically applying them.
