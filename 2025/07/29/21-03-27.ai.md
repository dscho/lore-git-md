Bugfix addressing a dangerous strbuf handling pattern in the interactive clean command. This patch fixes a potential double-free scenario in `builtin/clean.c` where a strbuf` was being passed by value between functions while still sharing the underlying buffer.

The issue occurs in the interaction between `list_and_choose()` and `parse_choice()`. The latter was modifying the strbuf's contents (replacing commas with spaces) while operating on a copy of the structure, but since strbuf contains a pointer to the actual buffer, this could lead to dangling pointers if reallocation occurred. The fix changes the parameter to pass the strbuf by pointer instead.

The patch is straightforward - it modifies the function signature and updates all call sites to pass the address of the strbuf rather than the structure itself. The change affects the interactive selection parsing logic in Git's clean command, particularly when processing comma-separated input from users.
