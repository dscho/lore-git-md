This is part 2 of an 8-part refactoring series integrating Git's multi-pack index (MIDX) handling with the object database (ODB) source system. The patch focuses on error handling in the ODB source lookup functionality.

The change makes `odb_find_source()` return NULL when an object directory cannot be found, rather than dying immediately. This prepares for future patches that will need to handle missing sources gracefully. The existing callers in `builtin/commit-graph.c` and `midx-write.c` are updated to explicitly die with an error message when they receive NULL, maintaining the previous behavior at those call sites.

Key technical changes:
- Removes the die() call from `odb_find_source()` implementation in odb.c
- Updates the function's documentation in odb.h to reflect the new NULL return behavior
- Adds explicit error handling to 3 call sites that previously relied on the function to die
- Maintains identical error messages when failing to find an object directory

This is a straightforward preparatory change that enables more flexible error handling in subsequent patches while maintaining existing behavior at current call sites. The patch is small (8 lines net change) and focused, touching only the ODB lookup infrastructure and its immediate consumers.
