Refactoring patch in the MIDX/ODB integration series. This is part 4/8 of Patrick Steinhardt's work to eliminate redundant information between multi-pack indexes and their owning object databases.

The patch removes redundant `struct repository` parameters from MIDX-related functions where the repository can be accessed through the MIDX structure itself. Key changes include:
- Modifies `prepare_midx_pack()`, `nth_bitmapped_pack()`, and `fill_midx_entry()` to take only the MIDX parameter
- Updates all callers across 7 files to match the new signatures
- Reorders `fill_midx_entry()` parameters to put MIDX first per coding guidelines
- Maintains identical functionality while simplifying the interface

The changes are mechanical but thorough, touching core MIDX operations like pack preparation, bitmap handling, and object lookup. This continues the series' pattern of methodically removing duplicate information fields between MIDX and ODB structures. The patch appears well-contained with no obvious edge cases or compatibility issues introduced.
