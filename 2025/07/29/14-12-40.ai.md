This is the first patch in an 8-part series refactoring Git's multi-pack index (MIDX) handling to better integrate with object database (ODB) sources. The patch focuses on tracking locality (whether an ODB source is the primary local objects directory) directly in the `struct odb_source` rather than computing it repeatedly.

The change adds a `local` boolean field to `struct odb_source` and initializes it when creating sources - true for the primary repository source (`.git/objects`) and false for alternates/quarantines. This replaces ad-hoc locality checks that previously compared sources against the first entry. The patch updates MIDX and packfile handling code to use this stored value rather than passing locality as a parameter.

Key technical changes include:
- Adding `local` field to `struct odb_source` with documentation
- Initializing the field in `link_alt_odb_entry()` (false) and `repo_set_gitdir()` (true)
- Modifying `prepare_multi_pack_index_one()` and `prepare_packed_git_one()` to use the stored locality
- Removing the `local` parameter from these functions' signatures

The changes are straightforward and maintain existing behavior while making the code more robust by centralizing locality tracking. This appears to be a clean preparatory step for the larger series' goal of better ODB source integration.
