This is part 6 of an 8-part refactoring series integrating Git's multi-pack index (MIDX) handling with the object database (ODB) source system. The patch focuses on the MIDX writing functionality, continuing the pattern established in previous parts by passing ODB sources instead of separate repository/path parameters.

The key changes in this patch:
- Modifies MIDX writing functions (`write_midx_file`, `write_midx_file_only`, `expire_midx_packs`, `midx_repack`) to take an `odb_source` parameter instead of repository/path pairs
- Updates callers in `builtin/multi-pack-index.c` and `builtin/repack.c` to use the new signatures
- Removes the now-unused `lookup_multi_pack_index()` helper since callers can directly use `get_multi_pack_index()`
- Adjusts path computations to use `source->path` instead of passed-in object directories
- Maintains all existing functionality while simplifying the interface

The changes affect several key MIDX operations:
- Creating new MIDX files
- Expiring old packfiles
- Repacking objects
- Writing bitmaps and reverse indexes

This continues the series' systematic elimination of redundant information by ensuring MIDX writing operations work through ODB sources rather than duplicating path and repository information. The patch follows the established pattern of the series while focusing specifically on the write path.
