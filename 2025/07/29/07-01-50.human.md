Feature patch completing config support for interactive patch commands. This is part of the ongoing series to make interactive patch commands (`add -p`, `checkout -p`, etc.) respect diff context configuration settings.

The patch teaches the add-patch infrastructure to read `diff.context` and `diff.interHunkContext` configurations, passing them to the underlying diff machinery. It adds validation to reject negative values (matching existing diff behavior) and includes tests verifying the new functionality. The implementation builds on previous work in the series that added command-line overrides for these settings.

Key changes include:
- Adding context fields to `struct add_i_state`
- Reading config values in `init_add_i_state()` with validation
- Passing the values through to diff commands
- New test cases verifying config-based behavior

This represents the final piece of config support for the series, which has already addressed command-line overrides and test modernization. The patch follows established patterns from earlier in the thread and has been reviewed by Phillip Wood and Junio Hamano. With this change, users can now control hunk context in interactive patches through config settings, matching behavior of regular diffs.
