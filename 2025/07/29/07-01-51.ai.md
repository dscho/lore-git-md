Feature implementation completing command-line diff context overrides for interactive patch commands. This is the final patch in a series that has been extensively reviewed and tested, now ready for merge.

The patch adds `-U`/`--unified` and `--inter-hunk-context` command-line options to all interactive patch commands (`add -p`, `checkout -p`, `commit -p`, `reset -p`, `restore -p`, and `stash -p`), allowing users to override the diff.context and diff.interHunkContext config values. The implementation:

1. Introduces new `OPT_DIFF_UNIFIED` and `OPT_DIFF_INTERHUNK_CONTEXT` macros in parse-options.h (with 6 existing users each)
2. Extends the `add_p_opt` struct to carry these values through the add-patch infrastructure
3. Validates negative values consistently with config handling
4. Updates documentation in a new diff-context-options.adoc file included by all relevant commands
5. Adds comprehensive tests in t3701 verifying:
   - Basic option functionality
   - Negative value rejection
   - Option-requires-patch-mode validation
   - Context override behavior

The implementation follows the same pattern as other diff-generating commands, with options overriding config values. Negative values are rejected consistently, and the options are only available in patch mode. The patch completes the series' goal of providing consistent diff context configuration through both config and command-line overrides, with all major design concerns addressed and final test adjustments applied.
