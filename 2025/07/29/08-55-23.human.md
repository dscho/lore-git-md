This is a type safety refactoring patch in Patrick Steinhardt's reflog migration series. It changes the `split_ident_line()` function to use `size_t` for its length parameter instead of `int`, since the function is called with values that are naturally unsigned (like `strlen()` results and `strbuf` lengths). The change is straightforward and improves type correctness, though it doesn't affect functionality.

The patch is part of a larger effort to improve reflog handling during the files-to-reftable migration, but this particular change stands alone as a clean-up to the ident parsing code. It's a small but sensible improvement that aligns with Git's ongoing code quality efforts. The change is minimal (just two lines) and low-risk, touching only the function signature in both the implementation and header files.
