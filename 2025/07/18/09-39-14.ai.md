Performance optimization patch adding a new `prio_queue_replace()` function to the priority queue implementation, part of René Scharfe's series improving commit traversal performance. This middle patch in the 3-part series introduces an optimized operation that combines the top element removal and insertion steps common in commit traversal patterns.

The new function avoids the separate heap rebalancing steps that would occur with separate `prio_queue_get()` and `prio_queue_put()` calls by directly replacing the top element and performing a single sift-down operation. The implementation handles both priority-sorted and LIFO modes of the queue, with comprehensive unit tests added in t/unit-tests/u-prio-queue.c covering both cases.

Key technical details:
- Extracts sift_down_root() as a reusable helper from prio_queue_get()
- Adds prio_queue_replace() to prio-queue.[ch] with full documentation
- Includes 4 new test cases (2 priority queue, 2 stack mode) verifying:
  - Basic replacement functionality
  - Empty queue handling
  - Correct ordering after multiple operations
  - Interaction with other queue operations

The change enables more efficient commit traversal by optimizing the common pattern of processing a commit and immediately queueing its parents. This builds on the series' goal of improving worst-case performance in merge-heavy histories while maintaining or improving normal-case performance.
