This is a build system patch addressing PCRE2 dependency handling on macOS, part of the ongoing meson build system improvements. It's the sixth iteration of a solution for macOS's broken system PCRE2 installation, where the pkgconf module incorrectly points to a non-existent header.

The patch implements a three-pronged approach: when system PCRE2 is detected as broken (via `compiler.has_header()` check), it either falls back to a subproject (if explicitly enabled), disables with a warning (in auto mode), or errors out (if required). The solution maintains special Windows behavior for consistency with cmake builds while changing the default from 'enabled' to 'auto' in meson_options.txt.

Key technical details include the use of meson's dependency fallback mechanism with `fallback:` parameter, conditional behavior based on `pcre2_feature.enabled()`, and maintaining static linking preference. The implementation handles edge cases like `--wrap-mode=nofallback` through careful use of meson's dependency resolution rules.

This version incorporates feedback from Eli Schwartz (suggesting the approach) and Eric Sunshine (editorial improvements), and follows confirmation from the author that the solution works on macOS.
