This is a performance optimization patch in René Scharfe's series converting commit traversal to use priority queues. The patch introduces `prio_queue_replace()`, which efficiently replaces the top element of a priority queue without the full rebalancing overhead of separate get+put operations. This is particularly useful for commit traversal where we frequently process a commit and immediately add its parents.

The implementation splits out the heap rebalancing logic into a reusable `sift_down_root()` helper and adds comprehensive unit tests covering both priority queue and stack modes. The change maintains the same behavior as separate get+put operations but with better performance, especially in commit history traversal scenarios.

This is the second of three patches in the series, which has already addressed all technical feedback from reviewers. The optimization shows measurable improvements - up to 92% speedup in pathological cases while maintaining or slightly improving performance in normal case. The series is now ready for merging.
