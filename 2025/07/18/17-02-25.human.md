This is a build system patch addressing PCRE2 dependency handling on macOS, part of the ongoing meson build system improvements. It's the sixth iteration of a fix for broken system PCRE2 installations on macOS, where the system-provided package incorrectly points to a non-existent header.

The patch implements a macOS-specific workaround that first verifies the system PCRE2 installation by checking for the presence of the pcre2.h header. If the header is missing (indicating a broken installation), it attempts to fall back to a bundled subproject when PCRE2 is explicitly enabled, or issues a warning and disables PCRE2 when in 'auto' mode. The solution maintains consistency with Windows builds by keeping PCRE2 enabled by default on Windows.

The implementation follows suggestions from Eli Schwartz and includes editorial improvements from Eric Sunshine. The change appears well-tested and addresses a real platform-specific issue, though it's worth noting this refinement arrived just after the initial merge window, as Junio Hamano observed. The patch represents the culmination of several rounds of review and testing, with the macOS-specific verification approach having been confirmed working by the author.
