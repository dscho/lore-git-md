This is a follow-up in the FreeBSD build compatibility thread, confirming the technical solution for the libsysinfo detection issue. Eli Schwartz from Gentoo weighs in on Ramsay Jones' proposed patch that conditionally enables HAVE_SYSINFO only when BSD sysctl is unavailable.

The patch modifies both autotools and meson build systems to avoid linking against GNU libsysinfo when native BSD sysctl is present. Schwartz notes the approach is sound since the compiler check doesn't verify linkage, making the conditional activation appropriate. This maintains the preference for native BSD interfaces while falling back to libsysinfo when needed.

The email serves as a positive review from another distribution maintainer perspective, though it doesn't provide new testing data. The thread appears to be converging on this solution, with the main outstanding question being meson build verification (which this email doesn't address). The patch itself looks clean and focused, directly addressing the reported issue without introducing new complexity.
