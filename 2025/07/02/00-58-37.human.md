This is a refactoring patch that's part of the performance optimization series for `git fetch --prune`. It removes an obsolete function `refs_warn_dangling_symref()` that was previously used to check for dangling symrefs against a single reference. The function is no longer needed since the series has switched to using `refs_warn_dangling_symrefs()` which checks against a list of references, as part of the O(N^2) to O(N*logN) performance improvement.

The change is straightforward - it removes the unused function definition from refs.c and its declaration from refs.h, while keeping the more general `refs_warn_dangling_symrefs()` variant. The patch also simplifies the underlying `warn_if_dangling_symref()` helper by removing the single-ref case handling that was only used by the now-removed function.

This cleanup follows naturally from the earlier optimization work in the series, showing good attention to API hygiene by removing dead code paths. The patch is small and focused, with no functional changes beyond removing code that's no longer used.
