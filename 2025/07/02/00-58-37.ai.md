This is a refactoring patch in the performance optimization series for `git fetch --prune`. It removes the obsolete `refs_warn_dangling_symref()` function and its supporting infrastructure, which was replaced by the more efficient `refs_warn_dangling_symrefs()` in earlier patches of this series.

The changes eliminate 17 lines from refs.c and 2 from refs.h, primarily the single-ref variant of the dangling symref warning function that is no longer used. The patch simplifies the `warn_if_dangling_symref` helper by removing the `refname` field from its data structure and the conditional logic that handled single-ref lookups. The remaining implementation now exclusively uses the string-list based approach introduced in the series' optimization work.

This cleanup follows naturally from the series' transition to batch processing of refs, maintaining the thread's focus on eliminating O(N^2) behavior while keeping the warning functionality intact. The removal is straightforward and low-risk since the function was already made obsolete by prior changes in the series. The patch demonstrates good attention to API hygiene by cleaning up now-unused declarations and implementation details.
