Feature proposal for a new `git snap` command to support AI-assisted development workflows.

Suraj Bhadrike proposes adding a new `git snap` command to better support modern, rapid iteration workflows, particularly those involving AI coding assistants. The command would create lightweight "snapshot" commits without requiring commit messages, serving as checkpoints during development sessions. The author notes that current Git workflows create friction when developers need to make many small iterations, as is common when collaborating with AI tools.

The proposal suggests the command would allow specifying which files to track at the start of a session, then automatically creating commits for each snapshot. A demo repository is provided to illustrate the concept, though no implementation details or patches are included in this initial email.

This appears to be an early-stage RFC rather than a concrete implementation. The motivation focuses on adapting Git to emerging AI-assisted development patterns, which could be of interest to developers experimenting with these tools. The proposal would need significant technical specification and discussion of how it differs from existing features like `git commit --allow-empty-message` or stash workflows.
