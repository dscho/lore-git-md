Refactoring patch in the performance optimization series for `git fetch --prune`. This is the second of three patches in v4 of the series, following the core optimization that introduced sorted ref lists for pruning.

The patch removes `refs_warn_dangling_symref()`, a helper function that checked for a single dangling symref, now made obsolete by the series' earlier changes. The new implementation uses `refs_warn_dangling_symrefs()` which operates on string lists, matching the optimized pruning approach that processes refs in bulk. The deletion removes 17 lines from refs.c and 2 from refs.h, simplifying the dangling symref warning interface.

Changes are mechanical and straightforward - the function's logic is already covered by the string-list variant, and all callers were updated in previous patches. This cleanup maintains consistency with the series' goal of optimizing ref handling by removing now-unused single-ref codepaths. The patch follows naturally from the architectural changes in the first patch, with no new functionality or behavior changes introduced.
