2. Patch 2 refines when intent-to-add markers are written, ensuring they only appear for new files
3. Patch 3 adds comprehensive tests covering edge cases like applying patches to existing index entries
4. Patch 4 clarifies documentation about when `--intent-to-add` takes effect
