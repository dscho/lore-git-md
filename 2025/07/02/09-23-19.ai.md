This is a refactoring patch that finalizes the integration of the RemoveBracesLLVM rule into Git's main clang-format configuration. As part of the 3-patch series to improve Git's clang-format setup, this change moves the experimental rule from CI-specific testing into the project-wide .clang-format file after successful validation.

The patch removes the temporary CI implementation that previously appended the rule via a generated config file, instead making it a permanent configuration option. The rule automatically removes optional braces from simple single-statement control flow bodies (if/else/for/while) while preserving them in more complex cases, following LLVM's coding style. The commit references prior testing in CI (commit 1b8f306612) which showed no issues with this formatting rule.

The technical changes are straightforward: adding the RemoveBracesLLVM: true line to .clang-format and simplifying ci/run-style-check.sh to use the main config file directly. This represents the culmination of the rule's experimental phase, now deemed stable enough for general use. The change aligns with the series' goal of reducing formatting noise while maintaining code clarity, as evidenced by the sample diffs shown in other patches.
