FreeBSD build system compatibility follow-up. This email from Renato Botelho confirms that Ramsay Jones' proposed fix for the libsysinfo detection issue works correctly on FreeBSD when using autotools. Botelho had previously reported build failures when GNU libsysinfo was present on FreeBSD systems, as the build system would incorrectly try to link against it rather than using the native sysctl interface.

The key technical point here is that the fix has been verified to properly ignore libsysinfo when the BSD sysctl is available, which matches the intended behavior. Botelho notes they haven't tested the meson build since FreeBSD ports still uses autotools, but Eli Schwartz had previously confirmed the meson implementation works correctly.

The email also raises a broader question about build system strategy, asking whether FreeBSD ports should transition to meson and whether there are plans to deprecate autotools. However, this appears to be a separate discussion point from the immediate fix, which Junio Hamano indicates is otherwise ready to proceed. The thread shows consensus that the technical solution for the build issue is complete and working across both build systems.
