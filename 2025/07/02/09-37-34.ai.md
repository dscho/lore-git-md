This is a build system patch series addressing FreeBSD platform compatibility, specifically around `memmem()` implementation and obsolete build flags. It represents the implementation of the consensus reached in the ongoing thread about FreeBSD version support policies.

The series modernizes FreeBSD build configuration in two parts: First, it makes `NO_MEMMEM` conditional on FreeBSD version (12+), allowing the system's `memmem()` to be used on supported versions while falling back to Git's implementation on older systems. This implements the agreed-upon approach from the thread discussion. Second, it removes the obsolete `NO_UINTMAX_T` flag which is no longer needed on any supported platform.

Key technical details include changes across multiple build systems (Makefile, meson) to implement version-aware `memmem()` handling. The patch uses shell expression matching in config.mak.uname to check FreeBSD versions, with the cutoff at version 12 where `memmem()` was fixed. The removal of `NO_UINTMAX_T` is a straightforward cleanup affecting configure.ac and meson.build.

The changes reflect the thread's resolution to actively enforce version requirements through build system changes rather than documentation alone. The implementation appears technically sound and aligns with Junio Hamano's expressed support for this approach. The series is well-structured with clean separation between the version-specific `memmem()` policy change and the unrelated uintmax_t cleanup.
