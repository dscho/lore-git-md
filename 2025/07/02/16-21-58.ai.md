Build system modernization completing FreeBSD compatibility updates. This is Junio Hamano's final review of the two-patch series that implements version-aware build policies for FreeBSD, replacing an earlier single patch from Brad Smith.

The series now finalized consists of: (1) making `NO_MEMMEM` conditional on FreeBSD versions older than 12, and (2) removing obsolete compatibility cruft including `NO_UINTMAX_T` definitions across all build systems (Makefile, autoconf, and meson). Junio confirms the changes appear reasonable and well-described, though notes he lacks FreeBSD systems to test.

This concludes the technical implementation phase of the FreeBSD modernization effort that previously involved discussion of version thresholds and EOL considerations. The patches maintain the ability to override `NO_MEMMEM` manually and preserve Git's fallback implementation for older systems. All build systems now consistently reflect the new policy of requiring FreeBSD 12+ for native `memmem()` while cleaning up decade-old compatibility code.

The only remaining considerations are documentation updates (if needed) and timing the changes with Git's release cycle. The series has received positive feedback from multiple contributors including the original proposer Carlo Arenas and security-conscious reviewers. The changes set a precedent for future version-specific platform support policies in Git's build system.
