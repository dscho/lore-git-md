This is a platform compatibility patch that updates FreeBSD build requirements for the `memmem()` function. It's part of a 2-patch series implementing version requirements for FreeBSD support.

The patch changes the build system to only disable Git's `memmem()` fallback implementation on FreeBSD versions older than 12, rather than disabling it for all FreeBSD versions. The rationale is that while FreeBSD 6 introduced `memmem()`, it had functional bugs until version 10.4 (EOL 2018) and performance issues until 11.4 (EOL 2021). The new policy draws the line at requiring FreeBSD 12+ for using the system's `memmem()`.

The implementation uses a shell expression in `config.mak.uname` to check the FreeBSD version number. Notably, the patch also removes some legacy FreeBSD 4.x compatibility code that's no longer needed. The change affects both the Makefile and meson build systems (though the meson changes appear in a separate patch).

This appears to be a well-justified cleanup that aligns with Git's policy of not supporting EOL platforms. The commit message clearly explains the version history and rationale, and the implementation seems straightforward. Reviewers will likely focus on verifying the version-checking shell expression and ensuring the meson changes match.
