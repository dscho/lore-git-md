This is the final patch in a 3-part series improving Git's clang-format integration, now focused on meson build system support. The patch adds a 'style' target to meson that mirrors the existing Makefile functionality, allowing developers to run `git clang-format` (not just raw clang-format) during meson builds. 

The implementation uses meson's `find_program()` with `native: true` (a cross-compilation convention confirmed earlier in the thread) to locate git-clang-format, then creates a run target that applies the formatter with the same parameters as the Makefile version: file-based style rules, diff output, and limiting to C/h files. The target is only created if git-clang-format is found, maintaining compatibility with systems lacking the tool.

This completes the series' goal of consistent formatting support across both build systems, following earlier patches that finalized the RemoveBracesLLVM rule and removed ColumnLimit restrictions. The implementation incorporates thread feedback about proper program detection and cross-compilation handling, with no outstanding technical questions remaining after Junio Hamano's approval of the full series.
