This is part 2 of Patrick Steinhardt's 21-patch series refactoring config-related functionality to remove dependencies on the `the_repository` global variable. The patch removes the `git_config_clear()` wrapper function, converting all callers to explicitly use `repo_config_clear(the_repository)` instead.

The change is mechanical and maintains identical behavior while making the global state dependency explicit at each callsite. The patch touches three files: removing the wrapper from config.h and updating two callers in scalar.c and setup.c. The author notes this is an intermediate step - some callers that already have repository instances available will be cleaned up in later patches.

This continues the work started in commit 036876a1067 to systematically replace implicit global state dependencies with explicit repository parameters. The changes are straightforward with no expected behavior changes, following the established pattern from the first patch in the series. The patch appears well-contained and focused on the kind of incremental refactoring needed for the larger `the_repository` removal effort.
