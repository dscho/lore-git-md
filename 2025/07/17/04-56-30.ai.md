This is part of Patrick Steinhardt's ongoing series to remove `the_repository` dependencies from object-file.c, enabling pluggable object database support (patch 04/16 in v2).

The patch simplifies the loose object freshness checking code by inlining three helper functions (`check_and_freshen_odb`, `check_and_freshen_local`, and `check_and_freshen_nonlocal`) into their single remaining caller `freshen_loose_object()`. The inlined implementation now directly loops through object sources rather than using intermediate functions. As part of this cleanup, the remaining helper is renamed from `check_and_freshen_odb()` to `check_and_freshen_source()` to better reflect its scope (operating on a single source rather than the whole database).

The changes include:
- Removing 28 lines of now-unnecessary indirection
- Renaming the core checking function for clarity
- Moving the alternates preparation and source iteration logic directly into `freshen_loose_object()`
- Maintaining the same behavior while reducing call stack depth

This continues the series' pattern of methodically removing global state dependencies while keeping functionality intact. The change is straightforward and mechanical, following the established pattern seen in earlier patches of the series. No new test coverage appears needed as this is purely an internal refactoring with no behavior change.
