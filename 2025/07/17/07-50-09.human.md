Test patch for the new `git refs list` subcommand wrapper. This is the second patch in a v2 series that introduces `git refs list` as a thin wrapper around `git for-each-ref`, addressing maintainer's concerns about code duplication from the initial version.

The patch adds comprehensive testing for the new wrapper by:
1. Adapting the existing `t6300-for-each-ref.sh` test script to work with either `for-each-ref` or the new `refs list` command via a `GIT_REFS_LIST_CMD` environment variable
2. Creating a new test script `t1461-refs-list.sh` that specifically tests the wrapper by setting `GIT_REFS_LIST_CMD=refs list` and sourcing the main test file
3. Adding the new test to the build system via `t/meson.build`

The changes show careful attention to maintaining compatibility while adding the new functionality. The test modifications systematically replace `git for-each-ref` calls with `${GIT_REFS_LIST_CMD}` while preserving all existing test cases. A few tests are skipped for the wrapper case (like the `-h` crash test) since the wrapper doesn't need identical help text behavior.

This appears to be a well-constructed test suite that will ensure the wrapper behaves identically to `for-each-ref` while being minimally invasive to the existing test infrastructure. The patch follows the pattern established in the thread of reusing existing test coverage where possible.
