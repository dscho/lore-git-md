This is the third patch in Patrick Steinhardt's 21-part series refactoring config-related functionality as part of the `the_repository` removal effort. The patch removes the `git_config_get()` wrapper function, converting all call sites to explicitly use `repo_config_get(the_repository, ...)` instead.

The change affects several key areas: `builtin/gc.c` (maintenance configuration), `builtin/submodule--helper.c` (submodule initialization and updates), and the test helper code. The patch follows the same mechanical conversion approach as previous patches in the series, making the dependency on `the_repository` explicit while maintaining identical behavior. The commit message notes this is an intermediate step - some call sites that already have repository instances available will be addressed in later patches.

The diff shows straightforward replacements across 4 files, removing 5 lines from config.h (the wrapper declaration) while adding 3 lines at call sites (the explicit `the_repository` parameter). The changes are consistent with the series' goal of eliminating implicit global state dependencies, building on commit 036876a1067 which first moved these wrapper functions. The patch maintains test coverage through the test-config helper updates.
