This is part of Patrick Steinhardt's ongoing series to remove `the_repository` dependencies from object-file.c, enabling pluggable object database support. Patch 05/16 focuses on freshening objects (updating their timestamps to prevent garbage collection).

The patch modifies two key functions - `freshen_loose_object()` and `freshen_packed_object()` - to accept an object database parameter instead of implicitly using `the_repository`. The changes are straightforward: the functions now operate on the passed-in ODB rather than the global repository. The patch also updates all call sites to pass the repository's object database explicitly.

This continues the series' methodical approach to removing global state while maintaining existing behavior. The changes are relatively small (11 lines added/removed) and focused, building on previous refactoring work in the series. The patch appears well-contained and follows the established pattern of the series, making it a low-risk but meaningful step toward the larger goal of repository independence.
