Refactoring patch in Patrick Steinhardt's series to remove `the_repository` dependencies from object-file.c. This patch (12/16 in v2) makes `for_each_file_in_obj_subdir()` static since it's only used within object-file.c, removing its declaration from object-file.h. The change is straightforward - just adding the `static` keyword to the function definition and deleting the header declaration. This continues the series' pattern of reducing unnecessary global visibility while maintaining all existing functionality. The patch doesn't introduce any behavior changes or new dependencies, but helps clean up the interface boundary as part of the larger effort to make the object database handling more modular.
