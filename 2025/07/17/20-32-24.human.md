CI/build system patch completing Rust integration for xdiff optimization series.

This is the final patch in a 7-part series introducing Rust as a hard dependency to optimize xdiff performance (with earlier parts showing 5-19% speedups). It adds Rust toolchain installation and build support across Git's CI infrastructure and build systems (Makefile and Meson). The changes:

1. Adds Rust installation scripts for CI (ci/install-rust.sh) that handle version management via rustup
2. Creates a build_rust.sh wrapper to unify Rust compilation between Make and Meson builds
3. Updates GitHub Actions config to include Rust in test environments
4. Modifies Makefile and meson.build to properly link the Rust-built xdiff library
5. Adds curl as a new dependency (needed for rustup installation)

The patch maintains the series' incremental approach, focusing just on build system integration while preserving the existing xdiff optimization work. It addresses practical concerns like per-user Rust installation in CI (avoiding system-wide changes) and cross-platform library path handling. The changes appear thorough, with appropriate error handling and cleanup of temporary files.

This completes the technical implementation side of the Rust dependency proposal, though the broader debate about mandatory Rust in Git continues (as noted in the thread context). The patch itself is well-contained and follows established patterns for build system modifications.
