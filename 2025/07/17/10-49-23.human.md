The patch touches several builtin commands (gc, submodule--helper) and a test helper, removing the wrapper from config.h while preserving all functionality. The commit message notes this is an intermediate step - some call sites that already have repository instances available will be cleaned up in later patches.

This continues the systematic approach seen in earlier patches of the series, converting implicit global state dependencies to explicit ones.
