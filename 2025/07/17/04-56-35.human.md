This is part of Patrick Steinhardt's ongoing series to remove `the_repository` dependencies from object-file.c, enabling pluggable object database support. Patch 09/16 introduces `odb_write_object()` as a new backend-agnostic interface for writing objects, replacing direct calls to `write_object_file()` which was specific to the loose object format.

The patch is primarily mechanical, converting 21 call sites across various parts of the codebase to use the new interface. While currently just a wrapper around `write_object_file()`, this lays groundwork for future changes where object writing will be routed through specific ODB sources. The implementation includes both a basic `odb_write_object()` and an extended variant supporting compatibility OIDs and flags.

The changes are straightforward and maintain existing behavior while moving toward the series' goal of repository independence. The patch follows the established pattern of the series by introducing the new interface first before later migrating the implementation details. Reviewers should focus on whether the new abstraction makes sense and whether all relevant call sites have been converted.
