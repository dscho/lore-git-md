This is the foundational patch in a series introducing Rust infrastructure to accelerate xdiff performance. It sets up the Rust build system integration with both Make and Meson, creating empty crates for xdiff and interop functionality while adding Rust type definitions to git-compat-util.h for FFI compatibility.

The patch establishes the build pipeline where Cargo builds Rust code as a static library that gets linked into Git. It handles both debug and release builds, with appropriate compiler flags for each. The changes touch build systems (Makefile, meson.build) and create new Rust project files (Cargo.toml, Cargo.lock) while leaving the actual Rust implementation empty for now.

Key technical elements include:
- New `RUST_LIB` variable in Makefile pointing to debug/release builds
- Rust type aliases (u8..u64, i8..i64, f32/f64, usize/isize) in git-compat-util.h
- Meson integration with custom_target for Rust builds
- Empty crates for xdiff` and `interop` with workspace configuration
- The patch explicitly states this is preparation for upcoming xdiff optimizations and Rust porting
- Maintains compatibility approach through type definitions and separate crates
- Follows libification efforts by keeping Rust components modular

This is part of a larger controversial effort to make Rust a hard dependency for performance gains, as noted in the thread context. The patch itself is mechanically sound build system work, though the series' overall direction remains contentious. Future patches will need to demonstrate the promised performance improvements to justify the Rust dependency.
