This is a refactoring patch that introduces a new helper function for directory traversal, part of Derrick Stolee's ongoing work on the `sparse-checkout clean` feature and `the_repository` removal effort.

The patch adds a generic `for_each_file_in_dir()` function that recursively visits every file in a directory, including subdirectories. This provides a simpler alternative to existing methods like `remove_dir_recursively()` (which has extra flags) and `fill_directory()` (which requires an index and pathspec). The new helper will be used in the next patch of the series to implement the `sparse-checkout clean` functionality.

The implementation is straightforward: it uses `opendir()`/`readdir()` to walk the directory tree, skipping "." and ".." entries, and calls a callback function for each regular file found. Directory entries trigger recursive traversal. The callback can stop iteration by returning non-zero.

This appears to be a well-contained utility function that follows Git's existing patterns for directory traversal. The patch includes both the implementation and a clear header declaration with documentation of the callback type and function purpose. It's a building block for the larger sparse-checkout clean feature rather than a user-facing change itself.
