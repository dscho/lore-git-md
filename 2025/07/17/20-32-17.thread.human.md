This RFC thread proposes making Rust a hard dependency for Git to enable xdiff optimizations, with claimed performance gains of 5-19%. The series, now at version 16/17, refactors xdiff internals with Rust implementations of line hashing and comparison functions, focusing on zero-copy FFI and type alignment for cross-language compatibility.

The latest patch optimizes handling of the `--ignore-cr-at-eol` whitespace flag, making this common case as fast as the no-whitespace-flags path. While this is a tactical improvement, broader questions remain about the approach - particularly around performance tradeoffs for other whitespace flags, xxhash algorithm choices, and platform support requirements. Junio Hamano has raised questions about XXH3's non-SIMD performance, and Phillip Wood has proposed alternative approaches that haven't yet been addressed. The discussion continues to balance micro-optimizations against architectural concerns like licensing, supply chain risks, and platform support tradeoffs.
