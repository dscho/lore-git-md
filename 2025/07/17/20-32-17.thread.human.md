This RFC series proposes making Rust a hard dependency for Git to enable xdiff performance optimizations, with claimed speedups of 5-19%. The current version (now up to part 6/7) has methodically laid groundwork through build system integration, type system preparation, and structural refactoring of xdiff's line processing. The latest patch introduces the first measurable performance improvement by conditionally replacing xdiff's DJB2a hash with Rust's xxhash implementation, showing 5-19% speedups in `git log --oneline --shortstat` benchmarks across different processors.

The series remains controversial due to its mandatory Rust dependency, with unresolved concerns about Windows/32-bit support and NonStop platform compatibility (raised by Randall S. Becker). While the technical approach appears sound - carefully restructuring xdiff internals while maintaining existing behavior - the broader debate about Rust adoption continues from Git Merge 2024 discussions. The performance gains demonstrated in this patch validate part of the series' premise, though the optimization currently doesn't apply to whitespace-aware diffs. The final part of the series remains to be seen, which may address remaining platform concerns or provide additional optimizations.
