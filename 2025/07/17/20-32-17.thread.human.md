The RFC series introducing Rust as a hard dependency with xdiff optimizations has reached its final version (17/17), completing the transition by replacing C implementations of key diff functions with Rust counterparts. The changes deliver 5-19% performance gains while removing 158 lines of legacy C code, with Rust now handling all performance-critical diff operations through a zero-copy FFI approach. Core technical work is done, though open questions remain about whitespace flag performance, code style guidelines, and platform tradeoffs.

Ramsay Jones has pointed out a platform compatibility gap - while the series claims to work on "all platforms," it fails on Cygwin. He suggests qualifying this claim to reflect the actual tested platforms (Windows and linux32, thanks to Johannes Schindelin's work). This serves as a useful reminder that despite the technical progress, edge cases in less common environments still need attention as the Rustification effort moves forward.
