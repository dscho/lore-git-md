This RFC thread proposes making Rust a hard dependency for Git to optimize xdiff whitespace processing, with Ezekiel Newren driving the technical implementation. The 17-part series refactors xdiff internals to separate line parsing from hashing, introduces XXH3 hashing optimizations, and handles whitespace flags more efficiently. The final patch completes the transition by fully replacing C implementations of `xdl_hash_record()` and `xdl_recmatch()` with Rust equivalents, deleting 158 lines of legacy code while maintaining all functionality.

The series demonstrates 5-19% performance improvements in operations like `git log --oneline --shortstat`, achieved through zero-copy FFI, type consistency, and optimized whitespace handling (particularly for `--ignore-cr-at-eol`). While the technical foundations are now complete, several open questions remain unresolved: broader whitespace flag optimizations, Rust code style guidelines, licensing policies, and platform support tradeoffs. Junio Hamano has outstanding questions about XXH3 non-SIMD performance, and Phillip Wood's alternative approach using Rust wrappers hasn't been addressed. The series leaves Git with a cleaner xdiff architecture but also permanent Rust dependencies that will impact future contributions.
