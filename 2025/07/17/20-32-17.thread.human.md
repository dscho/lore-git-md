This RFC thread explores a proposal to make Rust a hard dependency in Git by optimizing xdiff with Rust-based hash functions, currently at version 7/7 with CI integration complete. The series shows promising performance gains (5-19% in some cases) through structural refactoring of xdiff internals and xxhash optimization, though these improvements are currently limited to cases where whitespace flags are disabled.

Junio Hamano has acknowledged the technical merit while questioning how much of the speedup comes from the hash algorithm changes versus Rust itself. He's made clear there's no consensus to fully replace xdiff's C implementation, and Phillip Wood has raised important concerns about maintaining xdiff as a standalone C library for third-party consumers like libgit2 and Vim. The technical discussion has converged on using C-side type changes (u8, usize/u64) for better Rust interoperability, with Taylor Blau proposing to document these patterns in CodingGuidelines.

New platform compatibility concerns have emerged from distribution maintainers, particularly Eli Schwartz (Gentoo), highlighting practical deployment obstacles: some architectures lack Rust support entirely (HPPA/Alpha/m68k), while others face heavy build burdens (amd64 needing mrustc) or auditability issues (s390 binaries). This has led to discussion of version policies, with Junio and Taylor favoring a Debian-stable+1-year Rust version requirement while maintaining platform maintainer responsibility for toolchain availability.

Ezekiel Newren's latest response acknowledges the complexity of isolating performance factors between xxhash and Rust implementation benefits, noting the difficulty in direct comparison due to differing data processing approaches. He indicates more time is needed to investigate the raised points, particularly around performance measurement methodology. The thread remains active with open questions spanning technical implementation, platform support, version policies, and the fundamental tradeoffs between optimization benefits and maintenance burdens.
