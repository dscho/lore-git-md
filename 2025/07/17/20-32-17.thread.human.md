This RFC thread proposes making Rust a hard dependency in Git to accelerate xdiff performance with claimed 5-19% gains. The series starts with foundational build system work to integrate Rust infrastructure (Cargo, CI) while maintaining compatibility through careful refactoring. The initial patch sets up empty Rust crates and build integration with both Make and Meson, adding FFI-compatible type definitions in git-compat-util.h.

The technical approach involves separating parse/hash operations and refactoring xdiff's core data structures (xrecord_t/xdfile_t) for Rust compatibility. While the build system changes are mechanically sound, the broader Rust adoption remains controversial - the thread explicitly references unresolved debates from Git Merge 2024. Current status shows known CI failures on Windows and 32-bit systems, with FFI type handling (u32/u64 vs C types) as an open question. The series is still WIP, with future patches expected to demonstrate the promised performance improvements to justify the Rust dependency.
