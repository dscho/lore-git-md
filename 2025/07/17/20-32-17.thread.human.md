This RFC thread proposes making Rust a hard dependency for Git to enable xdiff optimizations that show 5-19% performance gains. The series has evolved through seven versions, with recent focus on Windows platform compatibility (led by Johannes Schindelin and Matthias Aßhauer) and CI integration. Key technical work includes refactoring xdiff internals, optimizing hash functions, and addressing type consistency issues across platforms.

A new licensing discussion has emerged as a significant policy question. Phillip Wood has raised concerns about Johannes Schindelin's suggestion to align the Rust xdiff code's license with Gitoxide's MIT/Apache terms. Wood argues this could effectively relicense parts of Git without proper process and complicate future C-to-Rust conversions, particularly for LGPL components. He maintains these license questions should be addressed separately from the technical optimization work.

The thread continues to grapple with several open issues: Windows target selection, build system integration, performance measurement methodology, and distribution concerns (especially for platforms like NonStop where Rust support is limited). While the technical optimizations appear promising, the licensing discussion introduces a new dimension that may require broader community input before the series can proceed.
