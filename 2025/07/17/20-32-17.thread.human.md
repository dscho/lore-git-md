This RFC thread has been discussing the integration of Rust as a hard dependency into Git, focusing on performance improvements in the xdiff subsystem (5-19% claimed gains). The series reached version 17/17, completing the technical transition by replacing C implementations of diff hashing and comparison functions with Rust equivalents while maintaining all functionality. Key participants include Ezekiel Newren (driving the implementation), Johannes Schindelin (Windows support), and Ramsay Jones (Cygwin compatibility).

The latest discussion centers on Windows build target specifics, where Matthias Aßhauer provided corrections to Johannes Schindelin's patch. Matthias notes that the proposed x86_64 target would unnecessarily raise the minimum Windows version requirement from 8.1 to 10, and identifies the correct target name for ARM64 builds. These are important refinements to maintain backward compatibility while supporting modern toolchains.

Several open questions remain unresolved, including performance impacts of certain whitespace optimizations, Rust code style guidelines, licensing policies, and platform support tradeoffs (now including both Cygwin and Windows version compatibility concerns). While the technical implementation appears complete, the series awaits resolution of these broader architectural and policy questions before potential merging.
