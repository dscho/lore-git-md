This is the final patch (7/7) in the Rust dependency series, focusing on CI integration. It adds Rust installation and build support across Git's CI infrastructure, completing the groundwork laid in previous patches for making Rust a build requirement.

The patch introduces several key CI components:
- A new `build_rust.sh` script that handles Rust compilation for both Make and Meson builds, moving the output library to the build directory
- `ci/install-rust.sh` to install Rust toolchains in CI environments
- Updates to `main.yml`, `install-dependencies.sh`, and other CI scripts to include Rust setup
- Makefile changes to ensure Rust compilation happens as part of the build process

Notable technical details include:
- The `build_rust.sh` script centralizes Rust compilation with flags for debug/release builds
- CI jobs now install Rust via rustup rather than system packages
- The Meson build system integration moves the Rust-built `libxdiff.a` to the build root
- Platform-specific handling (32-bit vs 64-bit) for Rust toolchain installation

This completes the series' CI integration while maintaining the incremental approach seen in previous patches. The changes are methodical and thorough, though they don't address the outstanding platform support concerns raised earlier in the thread. The patch maintains the series' pattern of careful preparation while now fully enabling Rust builds in CI environments.
