This is patch 8/21 in Patrick Steinhardt's series removing implicit `the_repository` usage from config functions, part of the long-running `the_repository` removal effort. The patch eliminates the `git_config_get_string_tmp()` wrapper function, converting all 12 call sites to explicitly use `repo_config_get_string_tmp(the_repository, ...)` instead.

The changes follow the established pattern seen in previous patches, mechanically replacing the implicit global state dependency with explicit repository parameter passing. Key config options affected include maintenance.strategy, fetch.bundleuri, remote.partialclonefilter, submodule update/ignore settings, checkout.defaultremote, core.sshcommand, sequence.editor, and various color/UI settings. The patch removes 5 lines from config.h while making net changes across 14 files.

As with prior conversions, this maintains current behavior while making the codebase more explicit about its repository dependencies. The commit message notes that some call sites already have repository handles available and could be further optimized in future work, but this mechanical change is intentionally minimal to avoid regressions. The series continues to progress systematically through the config API surface area.
