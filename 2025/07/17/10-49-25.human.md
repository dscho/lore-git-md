This is part 5 of Patrick Steinhardt's 21-patch series refactoring config-related functionality to remove dependencies on the `the_repository` global variable. The patch removes the `git_config_get_value_multi()` wrapper function, converting all call sites to explicitly use `repo_config_get_value_multi(the_repository, ...)` instead.

The change is mechanical and follows the same pattern as previous patches in the series - removing wrapper functions that implicitly depend on `the_repository` while making the dependency explicit at call sites. The patch touches only two files: removing the wrapper declaration from config.h and updating a test helper to use the new explicit form.

The commit message notes this is an intermediate step - some call sites may already have repository instances available that could be used instead of `the_repository`, but those will be addressed in later patches. The change maintains the same behavior as before, just with more explicit dependencies.

This continues the systematic conversion of config-related functions that began in earlier patches, with the ultimate goal of removing implicit global state dependencies to enable earlier repository settings parsing during process startup. The patch is small (6 lines removed, 1 added) and focused, following the established pattern of the series.
