This is a documentation patch that updates the sparse index expansion advice message to reference the new `git sparse-checkout clean` command. 

Derrick Stolee notes that leftover files in tracked directories outside the sparse-checkout are a common cause of sparse index expansions. The patch modifies the existing advice text to suggest using the new clean command (introduced earlier in this series) rather than just `git clean`, since the new command is specifically designed to handle this sparse-checkout scenario more effectively.

The change is minimal - just a one-line text update in sparse-index.c - but helps users discover the new functionality when they encounter the expansion warning. This follows naturally from the earlier patches in the series that implemented the clean command and its various safety controls. The patch maintains the same advice structure while making it more actionable for sparse-checkout users.
