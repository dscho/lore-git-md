Performance optimization patch in the Rust dependency series, focusing on xdiff internals. This fifth installment separates line parsing from hashing in xdiff's preparation phase, a prerequisite for the planned hash function switch from DJB2a to xxhash. The change extracts line parsing into a new `xdl_parse_lines()` function while keeping the existing `xdl_hash_record()` calls in a subsequent loop. This structural separation allows for easier hash function swapping later in the series.

The patch modifies `xdiff/xprepare.c` with 44 insertions and 31 deletions, primarily restructuring `xdl_prepare_ctx()` to use the new parsing function. Key changes include: moving record allocation into `xdl_parse_lines()`, converting pointer arithmetic to array indexing, and maintaining the same memory management patterns (CHA allocator, XDL_* macros). The commit message notes this maintains functionality while enabling future optimizations.

This continues the series' incremental approach, now reaching the first performance-sensitive change by decoupling parsing from hashing. The patch appears well-contained and mechanically sound, though the actual performance impact of this preparatory step won't be measurable until the hash function change lands in subsequent patches.
