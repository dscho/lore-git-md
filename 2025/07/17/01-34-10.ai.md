This is a refactoring patch that introduces a new helper function for directory traversal, part of Derrick Stolee's ongoing work on the `git sparse-checkout clean` feature and `the_repository` removal effort.

The patch adds a generic `for_each_file_in_dir()` function to `dir.c` that recursively visits every file in a directory, including subdirectories. The function takes a `strbuf` path, a callback function pointer, and optional callback data. It handles both regular files (DT_REG) and directories (DT_DIR), skipping dotfiles via the existing `readdir_skip_dot_and_dotdot()` helper. The iteration stops if the callback returns non-zero.

Key technical details:
- New `file_iterator` typedef defines the callback signature
- Uses `get_dtype()` to properly handle filesystem entries
- Maintains path state via `strbuf` length manipulation
- Returns 0 on success or the first non-zero callback result
- Will be used by the upcoming sparse-checkout clean implementation
- Complements existing directory utilities like `remove_dir_recursively()`

The implementation is clean and focused, with proper documentation in the header file. This appears to be infrastructure work supporting the sparse-checkout clean feature's need to identify files for potential removal.
