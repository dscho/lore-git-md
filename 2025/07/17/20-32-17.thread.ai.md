RFC series introducing Rust infrastructure for xdiff (now v6/15) continues with the introduction of an FFI-compatible vector type (`ivec`) for C/Rust interop, following CI enhancements from previous patches. - New `ivec` type provides unified vector interface for C/Rust FFI boundaries
- Struct layout identical in both languages (ptr, length, capacity, element_size)
- Includes standard operations (push, reserve, clear) with type-safe C wrappers via `DEFINE_IVEC_TYPE` macros
- Memory management uses Git's allocator on C side, Rust's on Rust side
- Comprehensive test suite in Rust
- Integrated into build system via new `INTEROP_OBJS` and `INTEROP_LIB`
- Maintains CI enhancements from previous patch:
  - GitHub Actions workflows upload `Cargo.lock` files as build artifacts
  - Four distinct job configurations covered (Windows/MSVC, Windows/Meson, Linux test matrices, static analysis)
  - Windows platform handling continues with `-luserenv` linking
- New refactoring in `xdiff/xprepare.c`:
  - Moves `xdl_prepare_env()` after its dependencies
  - Eliminates 66 lines of forward declarations
  - Reorders 116 lines of implementation code
  - Preserves all xdiff behavior and interfaces
