This is part 6/7 of the performance-oriented xdiff refactoring series that introduces Rust as a hard dependency, focusing on hash function optimization. The patch conditionally replaces xdiff's DJB2a hash with Rust's xxhash implementation when no whitespace flags are present, falling back to the original algorithm when whitespace handling is needed.

Key technical details:
- Adds `xxhash-rust` crate dependency (v0.8.15 with xxh3 feature)
- Exposes Rust's `xxh3_64` function via FFI for C access
- Modifies `xdl_prepare_ctx()` to use xxhash for non-whitespace cases
- Maintains existing whitespace-aware hashing path via `xdl_hash_record()`
- Benchmarks show 5-19% speedup in `git log --oneline --shortstat` across three machines (i7-8750H: 5%, i7-9700: 19%, Celeron 3965U: 12%)

The patch represents the first measurable performance improvement in the series, validating some of the claimed benefits of Rust integration. However, it still leaves open questions about platform compatibility (particularly Windows/32-bit) and the ongoing debate about mandatory Rust dependencies. The conditional whitespace handling suggests the xxhash optimization may not apply to all diff scenarios.
