Bugfix for Windows symlink regression in `git difftool`. Johannes Schindelin responds to Chris Conti's report about `difftool --dir-diff` failing with "Function not implemented" errors when using symlinks on Windows in Git 2.49.0. The issue appears to be caused by commit 8241ae63d821 ("difftool: eliminate use of global variables"), which inadvertently changed the symlink behavior default on Windows. Schindelin points to an existing GitHub issue (#5517) tracking this problem and notes the similarity between the reports. The response suggests this is a known regression from Git 2.48.1 behavior, though no fix is yet proposed. The technical core involves how temporary files are handled during directory diff operations when symlinks are involved. This appears to be a Windows-specific issue affecting users who explicitly enable symlinks via `-c core.symlinks=true`.
