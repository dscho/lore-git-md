Refactoring patch addressing compiler warnings in object-file.c, part of Patrick Steinhardt's larger series to remove `the_repository` dependencies. This first patch in the v2 series (01/16) cleans up -Wsign-compare warnings by fixing type mismatches between signed and unsigned variables across several functions in object-file.c. The changes are mechanical but important for correctness and compiler compatibility.

Key technical changes include converting loop counters to `size_t` in `fill_loose_path()` and `unpack_loose_rest()`, adding explicit size comparisons in `check_collision()` and `index_fd()`, and fixing subdirectory range checking in `odb_loose_cache()`. The patch also removes the `DISABLE_SIGN_COMPARE_WARNINGS` preprocessor define that was previously suppressing these warnings.

This foundational cleanup precedes the more substantial refactoring work in later patches of the series. While not directly related to the `the_repository` removal effort, these warning fixes establish better type safety before the more invasive changes. The patch maintains all existing behavior while making the code more robust against signed/unsigned comparison pitfalls.
