Windows compatibility follow-up from Git for Windows maintainer. Johannes Schindelin responds to the reported regression where Git Bash fails to launch on Windows 11 Pro after upgrading to v2.50.0. He suggests testing with v2.50.1 to see if the issue persists, and provides a specific diagnostic command to capture any error messages before the terminal closes. The command runs bash directly with login/interactive flags (`& "C:\Program Files\Git\bin\bash.exe" -li`), which should prevent the window from closing immediately if the issue reproduces. This moves the debugging forward by providing a concrete way to capture error output, though the response doesn't speculate on potential causes or fixes yet.
