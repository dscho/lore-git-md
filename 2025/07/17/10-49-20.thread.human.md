Patrick Steinhardt has begun a 21-patch series to refactor Git's config subsystem as part of the ongoing effort to remove reliance on the `the_repository` global variable. The first patch, which just arrived, mechanically converts all calls to `git_config()` to instead use `repo_config(the_repository, ...)`, touching 118 files but making no functional changes. This establishes the pattern for the rest of the series, which will similarly convert other config-related wrapper functions.

The v2 revision of the full series, which was previously summarized, has already addressed feedback from Phillip Wood regarding error handling in config include condition parsing. That version systematically replaces various `git_config_*()` wrappers with explicit `repo_config_*()` variants while fixing some sign comparison warnings and improving error handling. The changes affect over 55 files but remain non-functional, focusing on code clarity by making repository dependencies explicit. With the v2 revisions having resolved the known issues and no other objections raised, the series appears ready for merging as part of the broader `the_repository` removal effort.
