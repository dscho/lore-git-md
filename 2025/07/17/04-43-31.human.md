Bugfix for GitHub Actions CI test reporting. This is a follow-up to Junio Hamano's patch that corrected a shell syntax error in the test failure reporting script. The original bug caused "Bad substitution" errors when collecting test artifacts in GitHub Actions CI runs.

Patrick Steinhardt confirms the fix, noting that the patch correctly changes `${TEST_OUTPUT_DIRECTORY:t}` to the proper `${TEST_OUTPUT_DIRECTORY:-t}` syntax for default value fallback. The change is minimal (one character difference) and clearly correct, addressing a regression introduced in December 2024 when Meson builds were wired into CI.

As this is a straightforward correction of an obvious mistake from the maintainer, and has already received positive review from another contributor, this patch is likely to be merged quickly. It restores proper test artifact collection without affecting other parts of the CI system.
