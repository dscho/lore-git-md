This is part of Patrick Steinhardt's ongoing series to remove `the_repository` dependencies from object-file.c, enabling pluggable object database support. Patch 02/16 specifically targets the `the_hash_algo` global, which implicitly depends on `the_repository`.

The patch modifies several functions in object-file.c to accept a `git_hash_algo` parameter instead of using the global `the_hash_algo`. Key changes include updating the loose object path generation, object hashing, and stream verification code to use repository-specific hash algorithms. Some callers still temporarily use `the_repository->hash_algo` as an intermediate step, with the understanding these will be converted in later patches.

The changes are mechanical but thorough, touching core object handling paths while maintaining backward compatibility. This continues the series' pattern of incrementally removing global state while keeping behavior unchanged. The patch appears well-scoped and follows the established pattern from earlier in the series, though it doesn't yet fully eliminate all repository dependencies in the affected functions.
