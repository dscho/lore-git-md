This is the foundational patch in a series introducing Rust infrastructure to Git, specifically targeting xdiff optimizations. It sets up the Rust build system with Cargo workspaces and adds type definitions for Rust-C interop in git-compat-util.h. The patch creates empty crates for xdiff and interop functionality, with Makefile and meson.build changes to integrate Rust compilation into Git's build process.

The changes are purely infrastructural at this point - no actual Rust code is implemented yet, just the scaffolding. The patch follows the project's libification efforts by organizing Rust code into modular crates. Build integration supports both debug and release modes, with appropriate compiler flags for each.

This appears to be a well-structured first step in a larger effort, though the controversial aspect of making Rust a hard dependency (mentioned in the thread context) isn't directly addressed in this particular patch. The commit message clearly states this is preparatory work for upcoming xdiff changes, and the clean separation of concerns suggests thoughtful planning.
