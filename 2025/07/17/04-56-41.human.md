This is part of Patrick Steinhardt's ongoing series to remove `the_repository` dependencies from object-file.c, enabling pluggable object database support. Patch 15/16 focuses on `force_object_loose()`, which converts packed objects to loose objects.

The patch modifies `force_object_loose()` to accept an explicit `struct odb_source` parameter instead of implicitly using `the_repository`. While checking for existing loose objects still scans all sources, the actual writing now targets a specific source. The changes maintain the same behavior while removing another instance of global state dependency.

The implementation follows the established pattern seen in earlier patches of this series - propagating repository context through parameters rather than relying on globals. The changes are straightforward, with corresponding updates to the function signature in object-file.h and its single caller in builtin/pack-objects.c. This continues the series' systematic approach to making object-file.c work with explicit repository contexts.
