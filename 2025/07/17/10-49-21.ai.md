Refactoring patch as part of the `the_repository` removal effort. This is the first patch in a 21-part series by Patrick Steinhardt that systematically replaces `git_config()` wrapper functions with explicit `repo_config()` variants that require a repository parameter. 

The patch removes the `git_config()` wrapper function entirely, converting all 118 call sites to use `repo_config(the_repository, ...)` instead. This is a mechanical change that maintains the same behavior while making the dependency on the global `the_repository` explicit at each callsite. The commit message notes this is following through on the intent established in commit 036876a1067, which had already moved these functions to be wrappers around their repository-aware counterparts.

The changes touch a wide range of files across builtins, helper utilities, and core functionality, with a net removal of ~50 lines (550 removed, 500 added). While some callsites could potentially use a different repository instance if available, this initial conversion keeps the same behavior as a safe first step, with further cleanup to follow in the series. The patch appears well-scoped and mechanical, with no functional changes intended - just making implicit repository dependencies explicit.
