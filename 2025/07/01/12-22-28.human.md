This is part of Patrick Steinhardt's ongoing series to refactor Git's object database (ODB) subsystem, specifically patch 16/17 in v6. The patch renames `pretend_object_file()` to `odb_pretend_object()` to align with the established naming pattern in the ODB refactoring effort.

The function is used to temporarily cache an object in memory without writing it to disk, primarily for operations like blame that need to work with unsaved working tree changes. The rename follows the project's modern coding guidelines and the systematic conversion of ODB-related functions to use explicit `object_database` parameters rather than relying on `the_repository` global state.

The changes are mechanical - updating the function name and its parameters in the declaration, implementation, and single caller in `blame.c`. No behavior changes are introduced, and no compatibility wrapper is provided since the function has limited usage. The patch continues the clean, methodical approach seen throughout this high-quality series that's nearing completion.
