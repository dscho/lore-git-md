This is the first patch in Patrick Steinhardt's v6 series to refactor Git's object database (ODB) subsystem, part of the ongoing effort to eliminate `the_repository` global state and enable pluggable ODB backends.

The patch renames the core `raw_object_store` structure to `object_database`, establishing clearer terminology for the subsystem that handles object storage. The commit message explains that the "raw_" prefix was misleading (there is no non-raw variant) and that the new name better reflects the structure's purpose while allowing for cleaner API naming (using "odb_" prefixes). The change affects 8 files with straightforward mechanical renames of the type and related functions like `raw_object_store_new()` becoming `odb_new()`.

This foundational rename sets up the naming convention for subsequent patches that will convert the ODB APIs to explicitly take `object_database` parameters rather than implicitly using `the_repository`. The patch is well-motivated and uncontroversial, touching only type names while preserving all behavior. As the first step in a major architectural change, it cleanly establishes the terminology that will be used throughout the rest of the series.
