Platform compatibility fix for FreeBSD builds with libsysinfo. Ramsay Jones proposes a solution to the ongoing issue where Git fails to build on FreeBSD when the GNU libc sysinfo compatibility library is installed. The problem occurs because the build system detects sysinfo headers but fails to properly link against libsysinfo.

Jones suggests three potential approaches but focuses on implementing one: modifying the build system to only define HAVE_SYSINFO if HAVE_BSD_SYSCTL is not already set, since BSD systems should prefer their native sysctl interface. The patch moves the sysinfo detection logic after the BSD sysctl check in both configure.ac and meson.build.

This appears to be a clean solution that maintains existing behavior on non-BSD systems while fixing the FreeBSD case. The patch follows Git's build system patterns but comes with the caveat that Jones cannot test it personally on FreeBSD. The change is relatively small and targets only build system files, making it low-risk for other platforms.

This builds on the earlier discussion between Renato Botelho and Eric Sunshine about the best way to handle the libsysinfo detection, though it takes a different approach than the two options previously outlined in the thread.
