This is a documentation and code consistency patch in the `git-config` subcommands series. It standardizes the terminology for the `--value` option from `--value=<value>` to `--value=<pattern>` throughout both the man page and implementation code, since the option actually expects a pattern rather than a generic value.

The patch is part of a v2 series that addresses all technical issues from the initial submission, including fixing a test failure in t0450.142 caused by documentation/implementation mismatches. The change is straightforward and already carries an Acked-by from Patrick Steinhardt, indicating maintainer approval.

While this patch completes the core technical work, there remains an open question about whether to update the in-code help text to match the new terminology (currently still shows `--value=<value>`). The series as a whole provides comprehensive update to the config subcommands documentation following their recent merge into Git.
