This is a follow-up to a memory leak bugfix in `send-pack`'s handling of the `extra_have` oid array. The original patch addressed a 2160-byte leak during push operations involving alternate object stores, but Junio C Hamano noticed it didn't cover an early error path. He proposed consolidating cleanup under a `cleanup` label to ensure the `extra_have` array (and other resources) are properly released in all exit paths. Jacob Keller has reviewed and approved this refinement, confirming it maintains correct behavior while being more thorough. The discussion appears concluded with both fixes being uncontroversial, though test coverage for alternate-store push scenarios remains outstanding. This represents a straightforward improvement to the original fix, following Git's established patterns for resource cleanup.
