Platform compatibility follow-up regarding FreeBSD libsysinfo build issue. Renato Botelho, the FreeBSD ports maintainer who originally reported the problem, is seeking guidance on how to properly fix the build failure when GNU libc's sysinfo port is installed on FreeBSD systems. The core issue remains that configure detects libsysinfo but fails to add the necessary `-lsysinfo` linker flag, causing undefined symbol errors during compilation.

Botelho presents two potential approaches for upstream consideration: either making the libsysinfo linking conditional (matching the FreeBSD ports workaround), or implementing FreeBSD-specific detection logic. He explicitly offers to implement whichever solution the Git project prefers, but needs direction on the maintainers' preferred resolution path before submitting a formal patch.

This email moves the discussion forward by shifting from problem reporting to solution design, though it still awaits maintainer input on the architectural decision. The thread remains open on whether Git should support libsysinfo linking when detected or explicitly handle FreeBSD as a special case. The FreeBSD ports system's existing workaround (configurable libsysinfo dependency with proper LDFLAGS handling) serves as one proven implementation approach if the conditional option path is chosen.
