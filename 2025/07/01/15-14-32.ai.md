Documentation patch completing the git-config subcommands standardization effort.

This is the final patch in Kristoffer Haugsbakk's v2 series updating the git-config documentation following the ps/config-subcommands merge. It adds the `--url` option to both the man page synopsis and builtin/config.c usage string for the `get` subcommand, fixing an oversight from the original implementation (4e513890008). The change aligns the synopsis with actual functionality while maintaining consistency with the series' broader goal of documentation standardization.

The patch carries Patrick Steinhardt's Acked-by, confirming it meets technical requirements. It specifically addresses a test failure (t0450.142) caused by the synopsis mismatch between source and documentation. The change is minimal but important for completeness, touching both git-config.adoc and builtin/config.c to ensure parallel updates.

This concludes the series' work on standardizing terminology and documentation for config subcommands, with all technical issues now resolved. The only remaining inconsistency (help text using `--value=<value>` vs documentation's `--value=<pattern>`) is noted as non-blocking for future consideration. The patch maintains the series' focus on precise alignment between implementation and documentation while fixing concrete issues identified during review.
