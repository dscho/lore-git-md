This is a feature patch series adding pagination support to `git for-each-ref`. The main addition is a new `--skip-until` option that allows starting iteration from a specific reference rather than always beginning at the start of the ref list. This enables efficient pagination workflows in repositories with millions of references.

The series makes several internal refs/ changes to support this functionality. It exposes the `ref_iterator` interface publicly, modifies seek behavior to only set prefixes when needed, and updates all three ref backends (files, packed, reftable) to support seeking. The files backend requires the most changes due to its ref-cache implementation.

The implementation looks thorough, with tests covering the new functionality. The author notes they considered broader refs/ cleanup but deferred it to keep the series focused. This appears to be a well-motivated change that could benefit large repositories, though it does touch some core refs/ internals that may warrant careful review from the refs/ maintainers.
