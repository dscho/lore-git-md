This is part 4/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem, continuing the effort to eliminate `the_repository` global state. The patch introduces parent pointers between ODB components to maintain repository relationships without relying on globals.

The change adds `repo` and `odb` pointers to connect `struct object_database` back to its owning repository and `struct odb_source` back to its owning ODB. This enables future patches to access repository-specific configuration without using `the_repository`. The implementation requires adjusting the alternates-handling code to pass through the ODB explicitly when setting up these relationships.

The patch is mechanical but important infrastructure for the larger series, touching core ODB functionality like alternates handling and initialization. It follows the established pattern of the series by making structural changes while maintaining existing behavior. Review feedback from earlier versions has been incorporated, and the changes align with the series' goal of enabling pluggable ODB backends through better encapsulation.
