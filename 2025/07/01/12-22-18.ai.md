This is part of the ongoing `the_repository` removal effort, specifically patch 6/17 in Patrick Steinhardt's v6 series refactoring Git's object database subsystem. The patch converts the `assert_oid_type()` function to take an explicit `object_database` parameter instead of implicitly using `the_repository`, renaming it to `odb_assert_oid_type()` for consistency with the new naming conventions.

The changes are mechanical but important for eliminating global state: the function now operates on a specific ODB instance rather than assuming `the_repository`. The implementation now uses `odb->repo` to access the repository when needed. The patch updates 3 call sites in `builtin/commit-tree.c` and `commit.c` to pass `the_repository->objects` explicitly.

Key technical details:
- Function renamed from `assert_oid_type()` to `odb_assert_oid_type()`
- New parameter `struct object_database *odb` added
- Implementation now uses `odb->repo` instead of `the_repository`
- Call sites updated to pass `the_repository->objects`
- Behavior remains identical - still asserts object type matches expected type or dies
- Touches 4 files with 7 lines added and 5 removed

This continues the series' pattern of methodically eliminating `the_repository` usage while maintaining the same functionality. The changes are straightforward and follow the established pattern seen in previous patches, with all call sites properly updated to pass the ODB explicitly. The patch has already incorporated review feedback from earlier versions and appears ready for inclusion.
