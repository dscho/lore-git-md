This is part 6/11 of the SHA-256 default hash transition series, focusing on test infrastructure updates. The patch makes the test suite more robust by introducing a way to reference the compile-time default hash algorithm (currently SHA-1, but designed to work with future SHA-256 defaults).

The key changes are:
1. Adds `GIT_TEST_BUILTIN_HASH` variable set to sha1 (to be changed later when SHA-256 becomes default)
2. Makes test suite fall back to this built-in hash when no explicit hash is set
3. Adds `--hash=builtin` option to `test_oid` helper to use the compile-time default
4. Introduces `DEFAULT_HASH_ALGORITHM` prerequisite to check if the current hash matches the built-in default

This is a well-contained test infrastructure change that prepares for the SHA-256 transition while maintaining current behavior. The patch is cleanly implemented with clear documentation in the commit message about its purpose. It follows logically from the previous patches in the series that established the hash algorithm infrastructure.
