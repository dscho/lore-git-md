This is the foundational patch in Patrick Steinhardt's 17-part series to eliminate `the_repository` global state from Git's object database (ODB) subsystem. The patch renames the core `raw_object_store` structure to `object_database` (and its acronym ODB), establishing clearer terminology for the object storage layer. The change affects 8 files with mechanical updates to type names and function signatures.

The rationale explains that the "raw_" prefix was misleading (implying a non-raw variant that doesn't exist) and unwieldy in API names. The new name better reflects the structure's role as the central object storage interface while aligning with existing codebase terminology. Key mechanical changes include:
- `raw_object_store_new()` -> `odb_new()`
- `raw_object_store_clear()` -> `odb_clear()`
- Updates to function parameters accepting the structure
- Added documentation clarifying the ODB's purpose

This initial rename enables subsequent patches to convert implicit `the_repository` dependencies to explicit ODB parameters while maintaining clear subsystem boundaries. The change is purely structural - no behavior is altered. The patch has already received Reviewed-by from Derrick Stolee in previous iterations, indicating technical soundness. As the series' first step, it establishes naming conventions that will propagate through all ODB-related APIs in later patches.
