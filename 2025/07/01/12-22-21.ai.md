This is part of Patrick Steinhardt's ongoing series to eliminate `the_repository` global state in Git's object database (ODB) subsystem, specifically targeting iterator-style functions that operate on alternates.

The patch converts three functions that previously relied on `the_repository` to instead take explicit `object_database *odb` parameters:
- `foreach_alt_odb()` -> `odb_for_each_alternate()`
- `for_each_alternate_ref()` -> `odb_for_each_alternate_ref()`

The changes follow the established pattern in this series of:
1. Adding explicit ODB parameters
2. Renaming with `odb_` prefix
3. Updating all callers (8 files modified)
4. Maintaining identical behavior

Key technical details:
- The alternate iteration logic remains the same but now operates on the passed ODB rather than `the_repository->objects`
- Callbacks are renamed/typed (`alt_odb_fn` -> `odb_for_each_alternate_fn`, `alternate_ref_fn` -> `odb_for_each_alternate_ref_fn`)
- The patch updates call sites in critical areas: count-objects, receive-pack, submodule handling, diagnostics, fetch-pack, and revision walking
- Documentation is added for the new API functions in odb.h

This continues the series' systematic elimination of global state while maintaining the existing alternate handling behavior. The changes are mechanical but important for the larger architectural goal of making the object database subsystem repository-agnostic.
