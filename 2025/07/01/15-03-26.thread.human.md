This thread introduces a 4-part series adding pagination support to `git for-each-ref` through a new `--skip-until` option. The series begins by exposing the internal `ref_iterator` interface and adding `ref_iterator_seek()` functionality, then refines this with a `set_prefix` parameter to separate seeking from prefix filtering. The final patch, just submitted, implements the user-facing `--skip-until=<pattern>` option that enables starting iteration from a specific reference rather than the beginning, particularly useful when combined with `--count` for pagination.

The implementation handles edge cases like empty values and partial matches, with special consideration for different ref types. All ref backends (files, packed, reftable) are updated to support the new functionality, with the files backend requiring the most significant changes. The series includes comprehensive tests (180 lines) and documentation updates. While no performance measurements for large repositories are provided yet, this foundational change could significantly benefit tools needing to paginate millions of references. The patches appear well-structured, with each building logically on the last, though the series has not yet received review feedback.
