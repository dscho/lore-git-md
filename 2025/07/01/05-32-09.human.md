This is the final patch in a bugfix series addressing memory leaks in Git's bitmap loading code. The patch adds comprehensive test coverage for handling corrupt bitmap files, completing the work started in earlier patches.

The patch introduces a new `test_bitmap_commits_with_offset()` function that outputs detailed position information about each bitmap entry in the file. This enables targeted corruption tests by revealing exactly where to modify the bitmap file to simulate corruption. The test helper is then used in a new test case that deliberately corrupts a bitmap's xor_offset field while verifying Git still produces correct object lists.

Key technical changes include:
- Adding a `map_pos` field to `struct stored_bitmap` to track positions
- Extending the test-bitmap helper with new offset-reporting functionality
- Adding a test that corrupts specific bitmap fields and verifies behavior

The patch builds on the previous two in the series (which fixed the actual memory leaks and improved comments) to provide robust test coverage. It has undergone multiple review iterations with Taylor Blau and Jeff King, incorporating their feedback on naming and implementation details. The series as a whole represents a complete solution to the original memory leak reports while improving the codebase's test coverage and maintainability.
