This is a documentation refinement for the `git last-modified` feature, part of an ongoing patch series that's in its third revision. Kristoffer Haugsbakk provides some minor but thoughtful suggestions to improve the clarity and precision of the command's documentation.

The email focuses on two specific documentation improvements: clarifying ambiguous phrasing about directory traversal behavior and updating terminology from "sha1" to the more modern "oid" (object ID). It also includes a suggested rewording for the explanation of how path modifications are detected, though the core behavior (tracking all path changes including renames and mode changes) remains unchanged.

These suggestions come as part of the final polishing stage for the `last-modified` command, which has already seen significant performance improvements (36-50% gains) through Bloom filter optimizations in previous patches. The command remains marked as EXPERIMENTAL while these final documentation and code quality issues are being addressed.
