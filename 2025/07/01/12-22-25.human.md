This is part 13/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to eliminate the `the_repository` global state. The patch focuses on renaming the `oid_object_info()` function to `odb_read_object_info()` and its `_extended()` variant to match modern coding guidelines and the ongoing ODB API naming conventions.

The change is mechanical but wide-ranging, touching 48 files across the codebase. The patch introduces compatibility wrappers to avoid breaking in-flight topics, showing consideration for other contributors. The new names better reflect that these functions operate on the object database rather than being general object utilities.

This continues the systematic approach seen in previous patches, with all changes following the established pattern of:
1. Renaming functions to use `odb_` prefix
2. Updating callers consistently
3. Maintaining backward compatibility
4. Documenting transitional changes

The patch appears well-executed with thorough test coverage implied by the breadth of modified files. It builds on the foundational work in earlier patches (particularly patch 12/17 which removed `the_repository` from odb.c internals) and maintains the series' focus on clear API boundaries for pluggable ODB backends.
