This is a documentation patch that's part of an ongoing thread about syncing git-config documentation with implementation details. The email acknowledges a test failure in t0450.142 that was discovered after the patch series was merged, where the synopsis shows `--value=<pattern>` but the help output shows `--value=<value>`.

The test specifically verifies consistency between documentation and help output using `adoc_to_synopsis` and `help_to_synopsis` helpers. This email serves as confirmation of the issue rather than proposing a new fix.

The thread context shows this is part of a larger effort to document git-config subcommand options following the ps/config-subcommands series merge. Key changes included documenting `--[no-]show-names`, standardizing terminology to `--value=<pattern>`, adding `--url` to the synopsis, and documenting various subcommand options. The series built on commits 4e513890008, d4770964d50, and fe3ccc7aab.

The open issue remains that the help text implementation still shows `--value=<value>` while documentation uses `--value=<pattern>`, requiring a follow-up patch to align them.
