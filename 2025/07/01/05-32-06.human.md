This is the final version of a bugfix series addressing memory leaks in pack-bitmap.c's bitmap loading paths. The series has gone through five previous iterations and now incorporates all feedback from reviewers.

The three patches work together to:
1. Fix memory leaks when loading corrupt bitmaps by removing redundant cleanup code in `load_bitmap()` and relying on callers' `free_bitmap_index()` for uniform cleanup (Taylor Blau)
2. Rewrite misleading comments in `test_bitmap_commits()` to accurately describe bitmap lookup behavior (Lidong Yan)
3. Add comprehensive test coverage using a new `test-tool bitmap list-commits-with-offset` helper that outputs structured bitmap entry data, allowing targeted corruption injection tests (Lidong Yan)

The series has been thoroughly reviewed by Jeff King and Taylor Blau across multiple iterations, with all technical concerns addressed. The implementation has been simplified by removing duplicate cleanup paths and improving test infrastructure. The test helper provides reusable instrumentation for future bitmap corruption testing scenarios.

This represents a complete solution to the originally reported memory leaks while improving both code maintainability and test coverage. The patches are now in final form with all sign-offs and approvals in place, ready for merging.
