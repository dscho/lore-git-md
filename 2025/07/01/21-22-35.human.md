This is part 9/11 of the SHA-256 default hash algorithm series, focusing on test updates for operations outside repositories. The patch updates t5300-pack-object.sh to use the new DEFAULT_HASH_ALGORITHM prerequisite and GIT_TEST_BUILTIN_HASH variable instead of hardcoding SHA-1 assumptions. This prepares the tests for when SHA-256 becomes the default hash algorithm when Git is built with WITH_BREAKING_CHANGES.

The changes are mechanical but important for maintaining test correctness across hash algorithms. Three test cases are modified to:
1. Use DEFAULT_HASH_ALGORITHM instead of SHA1 prerequisite for non-repo operations
2. Check GIT_TEST_BUILTIN_HASH instead of hardcoding "sha1" when deciding whether to run verify-pack outside a repo
3. Similarly update the index-pack verification check to use the new variable

This follows the pattern established in earlier patches of the series, continuing the transition to hash-agnostic test infrastructure. The changes are straightforward and maintain existing test coverage while removing SHA-1 assumptions.
