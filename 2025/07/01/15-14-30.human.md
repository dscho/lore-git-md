This is a documentation patch completing the `git-config` man page updates for the `--value`/`--no-value` options, part of a v2 series that has already addressed technical issues and received maintainer approval.

The patch adds documentation for the `--value=<pattern>` and `--no-value` options to `git-config`, which were introduced in an earlier merge but not previously documented. These options work with the `get`, `set`, and `unset` subcommands to match against configuration values using regular expressions (unless `--fixed-value` is specified). The documentation follows the style convention suggested by Junio Hamano and maintains consistency with related options like `--fixed-value`.

This is the third of five patches in a series that has already gone through review, with all technical issues resolved in v2. The patch carries an Acked-by from Patrick Steinhardt, indicating maintainer approval. The series as a whole standardizes terminology between implementation and documentation, with this patch completing the documentation side for these particular options.

The only remaining minor inconsistency noted in the thread is that the implementation's help text still uses `--value=<value>` while the documentation now uses `--value=<pattern>`, but this is considered non-blocking. The patch appears well-crafted and completes an important documentation gap for functionality that's already in use.
