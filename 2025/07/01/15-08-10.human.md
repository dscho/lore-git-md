This is a CI/build system patch continuing the clang-format integration work. Karthik Nayak responds to Patrick Steinhardt's suggestion about renaming the new meson style target from 'style' to 'clang-format-changed' for consistency with meson's built-in clang-format target.

Karthik explains the current implementation matches the Makefile's 'style' target name for consistency, though he's open to adding an alias and eventually deprecating the Makefile name. The patch itself adds meson support for running git-clang-format on changed files only, mirroring existing Makefile functionality.

This is the final patch in a series that has already addressed several technical concerns around clang-format integration, with Junio Hamano having approved the overall approach. The naming discussion here appears to be the last remaining minor point before merging. The implementation looks straightforward and maintains compatibility with the existing build system while adding meson support.
