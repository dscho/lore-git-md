This is the first patch in a 4-part series introducing reference iteration improvements, specifically adding a `--skip-until` pagination feature to `git for-each-ref`. The patch focuses on exposing the internal `ref_iterator` interface through `refs.h`.

The change moves the `ref_iterator` documentation and related flags/enums from `refs-internal.h` to the public `refs.h` header, making them available to external callers. The commit explains this allows advanced users to directly use the lower-level iterator interface rather than being limited to the growing set of `refs_for_each...()` wrapper functions. 

Key technical details include:
- The full `ref_iterator` struct and all related functions (`advance`, `peel`, `free`, etc.) are now public
- The `do_for_each_ref_flags` enum (INCLUDE_BROKEN, PER_WORKTREE_ONLY, etc.) is exposed
- A new `ref_iterator_seek()` function is introduced to support efficient seeking to specific reference prefixes
- The implementation appears thorough with clear documentation of iterator usage patterns

This foundational change enables the subsequent pagination work while keeping the refs API more flexible for future extensions. The patch is well-structured with comprehensive documentation moved intact from the internal header. No behavior changes are introduced - this is purely an API exposure change.
