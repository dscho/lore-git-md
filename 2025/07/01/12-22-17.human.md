This is part of Patrick Steinhardt's ongoing series to eliminate `the_repository` global state in Git's object database (ODB) subsystem. Patch 5/17 continues the mechanical conversion work by removing `the_repository` usage from `find_odb()`, renaming it to `odb_find_source()` to match the new naming conventions.

The patch updates the function to take an explicit `object_database` parameter instead of implicitly using `the_repository`, and adjusts all callers (commit-graph and midx code) to pass the repository's ODB explicitly. The changes are straightforward - just plumbing the new parameter through - and maintain the same behavior while removing global state dependencies.

This is a typical piece of the larger architectural refactoring, following the pattern seen in earlier patches: rename a function to use the new `odb_` prefix, make dependencies explicit, and update callers.
