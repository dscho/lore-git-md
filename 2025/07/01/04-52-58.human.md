This is a CI/build system patch updating Git's FreeBSD testing environment. Carlo Marcelo Arenas Belón proposes moving from FreeBSD 13.4 to 14.3 since 13.x series is nearing end-of-life, with 14.3 being the next stable long-term support version. The changes include updating the Cirrus CI configuration to use the newer FreeBSD version while also making some related improvements: moving variables to the environment section and skipping test t7815.12 which assumes glibc regex behavior. The patch appears straightforward and well-motivated, keeping Git's CI infrastructure current with supported FreeBSD releases.
