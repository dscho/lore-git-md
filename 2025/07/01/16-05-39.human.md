Platform compatibility patch proposal for FreeBSD libsysinfo issue. This is a follow-up to the earlier report about build failures on FreeBSD when the GNU libc sysinfo port is installed. Renato Botelho, who maintains the FreeBSD port of Git, is seeking guidance on how to properly fix this upstream.

The core issue is that Git build system detects libsysinfo but fails to link against it, causing undefined symbol errors. The FreeBSD ports system has implemented a local workaround with a configurable option to handle the dependency, but this isn't an upstream solution.

Botelho is now offering to prepare an upstream patch and is asking the Git community to decide between two approaches: (1) making the libsysinfo linking conditional (matching the FreeBSD ports solution), or (2) implementing FreeBSD-specific handling in the build system. The email is essentially a request for architectural direction before submitting a concrete patch.

This appears to be a well-motivated fix from an experienced FreeBSD maintainer, though the patch itself hasn't been written yet. The response from Git maintainers will determine whether this becomes a platform-specific workaround or a more general solution to libsysinfo detection.
