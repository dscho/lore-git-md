Test infrastructure patch in the SHA-256 default hash algorithm series. This is part 7/11 of the effort to make SHA-256 the default hash algorithm when Git is built with WITH_BREAKING_CHANGES.

The patch updates t1007-hash-object.sh to use the new test_oid --hash=builtin functionality introduced in patch 6/11, rather than hardcoding SHA-1 for operations outside a repository. This prepares the test for when the built-in default hash changes from SHA-1 to SHA-256 in the future. The change is mechanical, replacing a direct SHA-1 reference with the new builtin hash test helper.

This aligns with the series' broader goal of making hash algorithm selection more flexible while maintaining backward compatibility. The test modification is straightforward and maintains the same verification logic, just generalized to work with whatever hash algorithm is configured as the built-in default. The patch follows the pattern established earlier in the series for handling hash algorithm transitions in tests.
