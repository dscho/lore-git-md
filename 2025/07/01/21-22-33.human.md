This is part 7/11 of a series implementing SHA-256 as Git's default hash algorithm when built with WITH_BREAKING_CHANGES. The patch updates a test in t1007-hash-object.sh to prepare for the upcoming hash algorithm change.

The test previously assumed SHA-1 would always be used when operating outside a repository. The patch modifies it to instead query the built-in hash algorithm via `test_oid --hash=builtin`, which will automatically adapt when the default hash algorithm changes to SHA-256. This is a straightforward test modernization that aligns with the series' goal of making Git hash-algorithm-agnostic.

The change is small (just 2 lines modified) but important for maintaining test correctness during the SHA-256 transition. It follows logically from patch 6/11 which introduced the `--hash=builtin` test infrastructure. The commit message is clear and the change appears well-contained, with no new edge cases introduced.
