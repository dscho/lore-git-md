This is part 6/11 of the SHA-256 default hash algorithm series, focusing on test infrastructure updates. The patch makes the test suite more robust against future hash algorithm changes by introducing a new `GIT_TEST_BUILTIN_HASH` variable that represents the compile-time default hash (currently SHA-1). This allows tests to explicitly reference the built-in default rather than hardcoding SHA-1 assumptions.

Key technical changes include:
- Adds `GIT_TEST_BUILTIN_HASH` set to 'sha1' in test-lib.sh
- Modifies hash detection to fall back to `GIT_TEST_BUILTIN_HASH` when `GIT_TEST_DEFAULT_HASH` isn't set
- Extends `test_oid` to accept `--hash=builtin` parameter to use the built-in hash
- Introduces `DEFAULT_HASH_ALGORITHM` prerequisite to check if current hash matches built-in default

The changes maintain backward compatibility while preparing for a future where SHA-256 might be the compile-time default. The patch is well-contained, touching only test infrastructure files (test-lib.sh and test-lib-functions.sh), and includes clear documentation of the new functionality in the commit message. This builds on the series' goal of making hash algorithm selection more flexible while maintaining test coverage for both SHA-1 and SHA-256 cases.
