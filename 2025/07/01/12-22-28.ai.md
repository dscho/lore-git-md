This is part of Patrick Steinhardt's ongoing series to refactor Git's object database (ODB) subsystem, specifically continuing the conversion of functions to use explicit ODB parameters rather than relying on `the_repository` global state. Patch 16/17 renames `pretend_object_file()` to `odb_pretend_object()` to align with the established naming pattern of other ODB-related functions in the series.

The function is used to temporarily cache an object in memory without writing it to disk, primarily for the blame machinery's fake working tree commits. The changes include:
- Renaming the function and all its call sites (only one in `blame.c`)
- Converting the first parameter from `struct repository *` to `struct object_database *`
- Updating internal logic to use the ODB parameter directly rather than accessing it via `repo->objects`
- No behavior changes or compatibility wrapper is needed since the function has limited usage

The patch follows the same transformation pattern seen in previous patches (13-15/17) that converted similar ODB functions. It's a straightforward mechanical change that completes another piece of the larger architectural refactoring to enable pluggable ODB backends. The changes are minimal and focused, touching only 3 files with simple parameter and naming updates.

This continues the series' high-quality approach with clear commit messages and careful attention to maintaining existing behavior while advancing the overall goal of removing `the_repository` dependency from the ODB subsystem.
