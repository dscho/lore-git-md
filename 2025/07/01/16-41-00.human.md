Credential helper configuration fix for Git on Windows. Johannes Schindelin responds to Aditya Garg's issue about the Git Credential Manager persistently overriding custom credential helpers after Windows updates. The solution is to explicitly reset the helper list by first setting an empty credential helper globally, then adding the desired helper. This ensures the system-level configuration doesn't interfere, as the empty helper entry will clear any lower-priority configs before applying the user's preferred helper.

The response confirms this is expected behavior in Git's credential helper chaining system, not a Windows-specific bug, though the symptom manifests prominently in Git for Windows due to its system-level defaults. The solution is portable and should work for any platform where system configurations might override user preferences. This provides a more permanent fix than repeatedly editing the system config after updates.
