- Adds context and interhunkcontext fields to struct add_i_state
- Implements config reading and validation in init_add_i_state()
- Passes values through to diff commands in parse_diff()
- Adds tests verifying:
  * Basic config respect (diff.context=5 shows 11-line context)
  * Inter-hunk context handling (diff.interHunkContext=2 affects hunk ranges)
  * Negative value rejection
