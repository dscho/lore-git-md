Git for Windows v2.50.0(2) release announcement from Johannes Schindelin. This is a bugfix update addressing three critical Windows-specific regressions from v2.50.0: SSH cloning hangs, unresponsive Ctrl+C during POSIX-emulated operations (affecting SSH cloning and Bash prompts), and repository initialization failures on Windows Server 2016. Includes Git LFS v3.7.0 update (no specific features noted). Provides SHA-256 checksums for all distribution formats (installers, portable, MinGit) across 32-bit, 64-bit, ARM64 architectures plus BusyBox variants. Focus is on Windows-specific stability fixes rather than core Git changes or security updates.
