Thread summary:

Bug report regarding inconsistent path expansion in Git's GPG configuration. The `gpg.program` setting fails to expand `~` to the user's home directory, unlike other Git path configurations such as `core.excludesfile`. Reporter demonstrates the issue by showing that setting `gpg.program=~/.local/bin/mygpg` causes a fatal error when executing the program, while an absolute path works. Clear reproduction steps provided: symlink GPG to custom home directory location, set config with tilde path, attempt signed commit. Behavior is inconsistent with Git's typical path handling. Expected behavior would be tilde expansion. Impact limited to users specifying GPG programs in home directory via tilde shorthand. Simple workaround exists (use absolute paths) but reduces portability. No version or documentation analysis provided yet.
