This is a refactoring patch in the `git for-each-ref` pagination series, specifically addressing the ref iterator seek interface. The patch responds to Patrick Steinhardt's review feedback on the v3 implementation.

The key changes in this iteration are:
1. Consolidating documentation for the `REF_ITERATOR_SEEK_SET_PREFIX` flag into a single location (the enum definition) rather than splitting it between the enum and function docs
2. Renaming the `seek` parameter to `refname` for better semantic clarity about what is being sought
3. Maintaining the behavior where prefix handling is now controlled explicitly by the flag - either updating the iterator's prefix when the flag is set, or clearing any previous prefix when it's not

The changes are relatively minor refinements to the already-settled API design, with Patrick approving the overall behavior. The patch maintains the core functionality where seeking can optionally set the prefix for subsequent iterations, while keeping the documentation more organized and parameter names more descriptive.
