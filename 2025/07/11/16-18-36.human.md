This is the cover letter for the final version of a feature series adding pagination support to `git for-each-ref` via a new `--start-after` option. The series has gone through multiple rounds of review and refinement, with all technical aspects now settled and approved by Junio C Hamano for merging.

The implementation provides efficient O(log N) pagination across all ref backends (files, packed, reftable) through sorted reference seeking. The key user-facing behavior is that when given a marker ref, iteration starts from the first reference that would come after it alphabetically, making it suitable for pagination workflows. The series also documents the behavior when references are modified between pagination calls.

The technical foundation includes exposing the `ref_iterator` interface publicly, refactoring the seek functionality to cleanly separate prefix filtering from seeking, and implementing backend-specific optimizations. The changes have been carefully reviewed for API clarity, documentation accuracy, and edge case handling.

This v4 represents the culmination of the effort, incorporating final documentation refinements (parameter syntax, lexicographic behavior wording) and API naming improvements (renaming `seek` parameter to `refname` for clarity). The series is now fully ready for merging with comprehensive test coverage and polished documentation.
