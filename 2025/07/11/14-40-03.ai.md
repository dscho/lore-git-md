Bug report follow-up regarding Windows terminal input handling. Johannes Schindelin identifies this as a known issue in the MSYS2 runtime (POSIX emulation layer used by Git for Windows) and links to an existing Git-for-Windows issue (#5632). The problem manifests as scrambled character ordering during command execution when typing in Git Bash, which Schindelin attributes to the underlying terminal emulation layer rather than core Git. He notes this runtime is a fork of Cygwin's, and requests help verifying whether the same behavior occurs in a pure Cygwin environment with MinTTY. The response effectively transfers responsibility to the MSYS2/Cygwin ecosystem while maintaining engagement by soliciting additional diagnostic data that could help isolate the root cause across related projects. This continues the thread's pattern of redirecting Windows-specific terminal behavior issues to the appropriate downstream components while collaboratively troubleshooting.
