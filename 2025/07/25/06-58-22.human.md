This is a bugfix and feature patch set addressing reflog migration issues between storage formats (files <-> reftable) and adding a new `git reflog write` subcommand. The series comes from Patrick Steinhardt as part of the reftable transition work for Git 3.0.

The key fixes address two serious problems discovered while implementing reftable support in libgit2:
1. Incorrect identity information in migrated reflog entries
2. All-zero old object IDs appearing in migrated reflogs

The series also introduces a new `git reflog write` subcommand that allows manually creating reflog entries, which proved useful for testing the migration behavior. The implementation includes thorough test coverage for both the new command and the migration fixes.

Version 2 of the series includes several improvements:
- Rebased onto v2.50.1 for backportability
- Documentation and man page updates
- Better test coverage
- Code cleanups and simplifications
- Build system compatibility fixes (switching from `odb.h` to `object-store.h`)

The technical changes are well-considered, with careful attention to backward compatibility and thorough test coverage. The series appears ready for merging, addressing all identified issues from the initial review while maintaining compatibility with older Git versions.
