Thread identity: RFC proposal for a permanent-history Git workflow with structured branch lifecycle management and AI-assisted development coordination, originating from Skybuck Flying.

Core problem/goal: Design an alternative Git workflow preserving all development history via non-deleting branches with explicit state tracking (active/merged/rejected) and sequential versioning, now extended to demonstrate AI-assisted parallel development (1 coordinator + 12 workers) and replacing pull requests with direct pushes plus PostgreSQL-based communication.

Key technical details:
- Branch naming: `UserPrefixContributionNNN-Description` with sequential versioning
- State management via directory-like tags: `active/`, `merged/`, `rejected/`, `revive/`
- Seven Bash scripts implementing core workflow:
  * `git-new-contribution`: Creates numbered branches from master
  * State transition commands: `git-set-active`/`git-set-merged`/`git-set-rejected`
  * History commands: `git-back-to` (historical branching), `git-the-future` (rebase)
  * `git-set-revive`: Reactivates archived branches
- New PostgreSQL communication tool `AICommPostgreSQL.exe` with commands:
  * `send`/`receive` for coordinator-worker messaging
  * `reset` for system clearing (password-protected)
- Workflow now integrates message passing for merge requests/status updates
