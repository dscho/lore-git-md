Bugfix for unexpected alias information output with `git grep -h`.

Kevin Brodsky reports an odd interaction between Git's alias handling and the `-h` flag when used with `git grep`. Normally, `-h` shows help text and includes alias information when used with an aliased command. However, with `git grep`, `-h` has a different meaning (suppressing filename output) when combined with other arguments. The current behavior still shows the alias information line even when no help text is printed, which seems inconsistent.

The issue persists in Git 2.50.1 and appears to have existed for years. The suggested fix would be to tie the alias information display to the actual help message output rather than the presence of the `-h` flag alone. This is a small but noticeable UI inconsistency that could confuse users who expect `-h` to behave consistently across commands.
