This is a follow-up patch in Patrick Steinhardt's reflog migration infrastructure series, addressing build system compatibility with older Git versions. The patch responds to feedback from SZEDER Gábor and Junio Hamano about the series being based on v2.50.0 while needing to support older versions. Patrick provides a straightforward fix that replaces the v2.50-specific `odb.h` include and `odb_has_object()` calls with their v2.49-compatible equivalents (`object-store.h` and `has_object()`).

The changes are minimal but important for backward compatibility, particularly since this series fixes reflog migration bugs that existed prior to v2.50. The patch maintains the same functionality while working across versions, though Patrick notes it will require minor adjustments when eventually merged to the development branch. This appears to be a routine but necessary adjustment in the final polishing phase of the series.
