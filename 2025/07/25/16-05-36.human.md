This is a test cleanup patch that simplifies the test suite for `git fast-export` and `git fast-import`. The changes were prompted by a report from Elijah Newren about confusing test patterns.

The patch removes unnecessary sub-shell usage in t9350-fast-export.sh, where several tests were using sub-shells to redirect content to multiple commands when they only needed to go to `git fast-import`. The new version uses `git -C` instead of `cd` and removes the sub-shell wrappers, making the tests more direct and easier to understand.

The changes are mechanical - each test case is modified to:
1. Replace `(cd new && git fast-import)` with `git -C new fast-import`
2. Move verification steps outside the sub-shell
3. Keep all the same test assertions but in a flatter structure

The patch touches 215 lines but is mostly deletions (-124) as the sub-shell syntax is removed. The tests continue to verify the same behaviors around fast-export/fast-import roundtrips, including special cases for signed commits, submodules, and encoding handling.

This appears to be a straightforward improvement to make the tests more maintainable without changing their functionality. The changes align with Git's ongoing effort to modernize test scripts by using `git -C` rather than subshells.
