This is a test style cleanup patch following up on the recently merged signature handling improvements in `fast-export`/`fast-import`. Christian Couder addresses the final stylistic concern raised by Elijah Newren and acknowledged by Junio Hamano regarding input redirection scoping in test cases.

The patch modifies four test cases in t9350-fast-export.sh to move input redirection (`<output`) from subshell blocks to specifically target the `git fast-import` commands that need the input. This matches the preferred style where input redirection is precisely scoped rather than applying to an entire subshell block. The change affects both the new tests added for signature handling and two existing tests that were previously using the broader scoping approach.

The patch represents the final cleanup of the signature handling feature implementation, addressing the last remaining stylistic point after all technical aspects were merged. It follows through on Junio Hamano's condition that the less-ideal test formatting would be cleaned up post-merge. The changes are purely stylistic and don't affect test functionality, just making the test intent clearer by properly scoping the redirections.
