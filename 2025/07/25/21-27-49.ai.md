License clarification and repository update for git-phoenix. This is a follow-up in the git-phoenix repository recovery tool discussion, where Daniil Iaitskov responds to Christian Couder's earlier concerns about license visibility. Iaitskov has now added a root-level LICENSE file containing the full BSD-3-Clause license text to the repository, addressing the discoverability issue Couder noted (previously the license was only specified in the cabal file and Hackage package metadata). The change makes the licensing immediately visible through GitHub's UI. No changes were made to the license choice itself - it remains BSD-3-Clause, which Iaitskov selected for its popularity in open source ecosystem. This resolves the last open question from the initial announcement thread regarding license clarity. The tool's development status remains conceptual, with core technical approaches still to be determined.
