This is a v2 patch series addressing submodule-related improvements, now incorporating review feedback from Junio C Hamano. The series contains two bugfix/optimization patches that have already received positive review with minor suggested improvements.

The first patch prevents .gitmodules overwrites during submodule path reuse by detecting name conflicts in `module_add()` (builtin/submodule--helper.c) and requiring --force to proceed (which then generates numbered names like "child1"). The author has now added explicit error messages in the tests (t7400-submodule-basic.sh) and addressed style issues around indentation and variable scoping.

The second patch optimizes submodule activation by avoiding redundant `submodule.active` entries when pathspec patterns already cover certain paths. In response to Junio's review, the author simplified the configuration checking from two function calls to a single `git_config_get_string_multi()` and further improved code style by properly grouping variables and localizing loop counters. The tests in t7413-submodule-is-active.sh verify this optimization.

Both patches have thorough test coverage and Junio had previously indicated the first patch was ready for integration with his local cleanups. The second patch's changes maintain the core functionality while implementing the suggested improvements. The series demonstrates careful attention to edge cases in submodule handling while respecting subsystem boundaries, with all outstanding review feedback now addressed.
