This is a bugfix in the reflog migration infrastructure, part of Patrick Steinhardt's ongoing series to support migrating between different ref storage formats (files and reftable). The patch fixes how committer identities are handled during reflog migration.

The core issue is that the migration code was incorrectly passing the full committer identity (both name and email) as just the email parameter to `fmt_ident()`, resulting in malformed output like "pks <Patrick Steinhardt ps@pks.im>". The fix properly splits the identity line first using `split_ident_line()` to separate name and email components before formatting.

The patch adds new string buffers to the migration data structures to store the split name and email components, avoiding repeated allocations. While this fixes the immediate formatting issue, the commit message notes there's still another related bug that will be addressed in a subsequent patch, at which point tests will be added to catch both issues.
