This is a discussion thread about the ongoing effort to accelerate and potentially rewrite Git's xdiff library in Rust. The thread originates from an RFC patch series that achieved 5-19% performance improvements while introducing Rust as a hard dependency.

Christian Brabandt raises an important concern from the Vim/Neovim perspective, as those projects rely on Git's xdiff library in C. The response suggests there will likely still be a pure-C version available, while leaving open the possibility for Vim to optionally use a Rust implementation or provide their own xdiff.

The exchange highlights a key tension in the Rustification effort - balancing performance improvements and modernization with maintaining compatibility for downstream users who depend on Git's C libraries. The thread appears to be in early stages, with the original patch series still needing Windows workflow fixes and facing questions about primitive choices.
