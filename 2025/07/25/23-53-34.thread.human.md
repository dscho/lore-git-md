This thread discusses efforts to modernize Git's xdiff library by introducing Rust while improving performance by 5-19%. The original proposal by Ezekiel Newren would make Rust a hard dependency, but Christian Brabandt has raised compatibility concerns from the Vim/Neovim ecosystem, which currently uses xdiff's C implementation. 

Ben Knoble suggests a middle path: maintaining a pure-C xdiff option while allowing for an optional Rust version or external implementations. The discussion remains open on how to balance modernization with downstream compatibility, particularly for projects like Vim that embed xdiff. Performance measurements and Windows build issues were mentioned in earlier messages but haven't been deeply examined in this exchange yet. The core tension is between Git's Rustification goals and the needs of other projects that rely on xdiff's current form.
