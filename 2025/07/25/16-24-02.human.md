This is the second patch in a two-part series optimizing submodule handling, specifically focusing on avoiding redundant configuration entries. The patch improves `configure_added_submodule()` to skip writing explicit `submodule.<name>.active` entries when the submodule's path is already covered by existing `submodule.active` patterns.

The change centralizes pattern matching logic using `wildmatch()` and only writes the active entry when no existing pattern matches the submodule path. This prevents cluttering the config with unnecessary entries while maintaining the same activation behavior. The patch includes a new test case verifying that no redundant active entry is created when adding a submodule under a path already covered by `submodule.active` patterns.
