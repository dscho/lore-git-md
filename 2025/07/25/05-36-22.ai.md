This is a build system compatibility patch in the ongoing reflog migration infrastructure series. Patrick Steinhardt responds to Junio Hamano's observation that the series was based on v2.50.0 but needs to work with older versions. The patch makes two key changes:

1. Replaces the v2.50+ `odb.h` include with the older `object-store.h` header
2. Updates object existence checks from the new `odb_has_object()` to the older `has_object()` API, using `the_repository` global

The changes maintain the same functionality while ensuring backward compatibility. This addresses SZEDER Gábor's earlier identification of the build system issue. The patch represents a straightforward adaptation to older Git versions, keeping the series on track for inclusion while following the project's version support guidelines (targeting v2.50+). The technical core of the reflog write functionality remains unchanged.
