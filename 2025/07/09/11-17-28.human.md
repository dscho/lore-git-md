This is part 18 of Patrick Steinhardt's series to eliminate global state in Git's object handling, specifically targeting the `the_repository` removal effort. The patch moves the object creation mode configuration (which controls whether Git uses hardlinks or renames when creating objects) from a global variable into repository-specific settings.

The change follows the pattern established in previous patches of the series, converting another piece of global state to be tracked per-repository. The implementation:
- Removes the global `object_creation_mode` variable and related definitions
- Adds the setting to `struct repo_settings`
- Updates the config parsing to store the value in repository settings
- Modifies `finalize_object_file_flags()` to check the repository's setting

This is a straightforward refactoring that maintains all existing behavior while continuing the series' systematic elimination of global state. The patch touches several files but makes focused changes that follow the established pattern from earlier parts of the series. As with previous patches, this helps pave the way for pluggable object backends by removing implicit dependencies on global variables.
