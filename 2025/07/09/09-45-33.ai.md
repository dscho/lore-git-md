This patch continues the systematic refactoring of Git's parse-options infrastructure to add precise integer type handling, focusing on OPTION_BIT options. It follows the established pattern from previous patches in the series, applying the same precision-based approach to bit flags.

Key technical aspects:
- Adds precision specification to OPTION_BIT in builtin/write-tree.c's --ignore-cache-tree option
- Introduces get_int_value() helper function to safely read integer values with bounds checking
- Modifies OPTION_BIT handling to use the new type-safe infrastructure rather than direct pointer manipulation
- Updates parse_options_check() to validate OPTION_BIT defval fits the specified precision
- Extends the OPTION_BIT macro to automatically set precision from the target variable size

The changes maintain backward compatibility while enforcing type safety through:
1. Explicit precision declarations for all OPTION_BIT variables
2. Centralized bounds checking via signed_int_fits()
3. Consistent error handling through BUG() on invalid precision
4. Reuse of the set_int_value() helper introduced earlier

This patch demonstrates the same careful, incremental approach seen in previous parts of the series, applying the established precision-handling pattern to another option type. The implementation remains focused on internal improvements with no user-facing behavior changes.
