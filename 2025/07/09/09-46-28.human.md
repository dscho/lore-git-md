This is the final patch in a series refactoring Git's parse-options infrastructure for type safety, specifically handling OPTION_COUNTUP precision. The patch completes a systematic overhaul that has touched all integer option types in the parse-options system.

René Scharfe adds precision handling for OPTION_COUNTUP options, similar to previous work on other integer option types. The changes ensure proper bounds checking when incrementing counter values and prevent overflow. The implementation uses the same type-safe helpers (get_int_value/set_int_value) introduced earlier in the series, maintaining consistency across the codebase.

Key technical changes include:
- Adding bounds checking for counter increments
- Proper handling of negative values (resetting to 0)
- Automatic precision setting in the OPTION_COUNTUP macro
- Extended parse_options_check() validation
- Test updates to verify the new behavior

The patch follows the same high-quality approach seen throughout the series, with thorough test coverage and careful attention to backward compatibility.
