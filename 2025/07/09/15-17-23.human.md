This is a small cleanup patch in Patrick Steinhardt's Meson build system improvement series. It removes a redundant display of the HTTPS backend option in Git's build summary output. The option was being shown twice - once in the auto-detected features list and once in the backends section. 

Junio Hamano acknowledges the fix as sensible, noting that while the distinction between "Auto-detected features" and "Backends" is somewhat blurry, the HTTPS backend is more appropriately categorized with the other backends since it's driven by custom Git code rather than being a simple dependency detection. 

The change is straightforward - a one-line deletion from meson.build that removes the duplicate entry from the auto-detected features summary while keeping it in the backends section. This appears to be a minor but correct cleanup that improves the clarity of the build output. The patch has already been reviewed and acknowledged by Junio, suggesting it's uncontroversial and ready to be included in the series.
