This is part 17 of Patrick Steinhardt's series to refactor object-file handling as part of the `the_repository` removal effort. The patch moves compression level settings for loose objects and packfiles from global variables into repository-specific settings.

The change eliminates two global variables (`zlib_compression_level` and `pack_compression_level`) by storing them in the repository's settings structure instead. The patch handles several edge cases, including:
- Maintaining backward compatibility with command-line overrides in `git pack-objects`
- Preserving the existing precedence rules between different config options
- Using `INT_MIN` as a sentinel value to detect when no command-line option was given

The changes affect compression behavior across multiple commands including `fast-import`, `index-pack`, `pack-objects`, and bulk-checkin operations. The implementation is straightforward but touches many call sites that initialize zlib compression streams. This continues the series' pattern of systematically removing global state while maintaining existing behavior.
