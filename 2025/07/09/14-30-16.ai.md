Test infrastructure update for security release backports. This is a follow-up to Todd Zullinger's patch that modified test scripts to use older `git config` syntax (`--get`/`--unset` flags) instead of newer subcommands (`get`/`unset`) when backporting security fixes to Git versions 2.43-2.45. The changes affect two test files (`t1300-config.sh` and `t7450-bad-git-dotfiles.sh`) that were updated in the newer syntax as part of CVE-2025-48384 fixes for CRLF handling in config/submodules.

Justin Tobler confirms the changes look correct, noting they had overlooked the version compatibility issue. The patch maintains the same test coverage while working across all maintained versions. Todd has verified clean merges to 2.44 and 2.45 and set up CI testing via GitHub Actions. The changes are minimal (4 lines total) and focused solely on test compatibility, not altering the security fixes themselves.
