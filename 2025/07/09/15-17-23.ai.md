This is a CI/build system patch that removes redundant output in the Meson build summary. It's part of Patrick Steinhardt's v3 series modernizing Git's build infrastructure, specifically addressing a minor issue where the HTTPS backend status was being displayed twice in the build output.

The patch removes the HTTPS backend status from the "Auto-detected features" section of the same information already appears in the "Backends" section. Junio Hamano confirms this makes sense since the HTTPS backend detection is Git-specific code rather than a standard dependency check, though he notes the distinction between the two summary categories is somewhat blurry.

The change is straightforward - a single line removal from meson.build that eliminates the duplicate display while maintaining all the actual functionality. This was one of several cleanups in the series, with Junio's response indicating this particular issue can be considered resolved. The patch aligns with the series' broader goal of streamlining and improving the Meson build output.
