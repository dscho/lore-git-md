This is a build system patch from Patrick Steinhardt's Meson modernization series (v3 1/8). It corrects Python version detection in the Meson build system by removing the unnecessary check for a native Python installation (used during build) and focusing solely on the target system's Python (needed for runtime git-p4 functionality).

The key technical changes are:
1. Removes `import('python').find_installation()` call that was checking for build-system Python
2. Uses only `find_program()` with `native: false` to detect target-system Python
3. Updates all conditionals to use `target_python.found()` instead of `python.found()`
4. Adds a clarifying comment explaining the git-p4-specific need for Python detection
5. Updates the feature summary display to reflect the new detection method

The patch addresses feedback from Justin Tobler in the v2 review cycle by explicitly documenting why Python detection is needed (solely for git-p4 runtime support) and properly handling cross-compilation scenarios. This change simplifies the build configuration while maintaining correct behavior for git-p4 functionality. The modification affects only meson.build, with all other patches in the series building on this corrected foundation.
