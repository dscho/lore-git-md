This is a build system improvement patch in Patrick Steinhardt's Meson modernization series (v3, patch 3/8). It enhances the feature summary output in Git's Meson build system to show version numbers for detected dependencies and adds colorized boolean formatting.

The key changes are:
1. Replaces simple boolean checks with direct dependency references in the feature summary, allowing Meson to automatically display version numbers when available (e.g., showing curl 8.14.1 instead of just "true")
2. Enables `bool_yn` formatting which makes the output more readable by showing "YES"/"NO" in color rather than "true"/"false"
3. Maintains all existing functionality while improving the user-facing output

The patch is a straightforward improvement to the build system's reporting capabilities, building on previous work in the series. It follows the established pattern of the Meson conversion effort and has already been reviewed in previous iterations. The changes are limited to `meson.build` and focus solely on presentation rather than build logic.
