This is part 4/19 of Patrick Steinhardt's series to refactor object-file.c as part of the `the_repository` removal effort. The patch simplifies the code by inlining several helper functions that were only used in one place.

The change removes three functions (`check_and_freshen_local()`, `check_and_freshen_nonlocal()`, and `check_and_freshen()`) and moves their logic directly into `freshen_loose_object()`. It also renames `check_and_freshen_odb()` to `check_and_freshen_source()` to better reflect that it operates on a single object source rather than the whole database.

This is a straightforward cleanup that reduces indirection in the code while maintaining the same behavior. The patch is small (28 lines removed, 13 added) and focused, following the series' incremental approach to refactoring. The changes are mechanical and don't introduce new functionality, just simplifying the existing code paths that check and update object timestamps.
