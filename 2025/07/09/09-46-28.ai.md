Refactoring patch completing the parse-options integer type safety overhaul.

This final patch in René Scharfe's series adds precision handling for OPTION_COUNTUP, the last remaining integer type in Git's parse-options infrastructure. The change follows the same pattern established for other integer options (OPTION_BIT, OPTION_NEGBIT, etc.) by:

1. Adding bounds checking using the new precision field
2. Using the type-safe get_int_value()/set_int_value() helpers
3. Maintaining backward compatibility while preventing integer overflow
4. Extending parse_options_check() validation to cover OPTION_COUNTUP

Key technical details:
- Implements proper bounds checking for count-up operations
- Sets precision automatically via the OPTION_COUNTUP macro
- Updates test-parse-options.c to exercise the new behavior
- Handles edge cases like negative values and overflow
- Completes the systematic refactoring started in earlier patches

The patch follows the same high-quality approach seen throughout the series, with thorough implementation and test coverage. It represents the culmination of this multi-patch effort to bring type safety to all integer options in Git's command-line parsing infrastructure. With this change, the series now covers all major integer option types (PARSE_OPT_CMDMODE, OPTION_SET_INT, OPTION_BIT, OPTION_NEGBIT, OPTION_BITOP, and now OPTION_COUNTUP).
