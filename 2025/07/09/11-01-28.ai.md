Documentation bug report for git-subtree. Alexander Krupp reports that the example command in the git-subtree documentation fails with "fatal: '0a8f4f0^..' does not refer to a commit" when run verbatim. The example attempts to split the gitweb subtree from the Git repository, using a specific commit range syntax that appears invalid.

The reporter followed the documentation exactly, cloning the git.git repository and running the `git subtree split` command as shown, but hit this fatal error. They note they lack the subtree expertise to propose a specific fix, but are flagging this as a documentation issue where the example doesn't work as written.

This appears to be a straightforward documentation bug where either the example commit range syntax is incorrect, or the example assumes some repository state that isn't guaranteed when following the steps. The report includes full system info showing this was tested with Git 2.43.0 on Linux. The next step would be for a subtree maintainer to verify the broken example and propose corrected documentation.
