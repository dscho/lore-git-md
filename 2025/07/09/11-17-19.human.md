This is part 9/19 of Patrick Steinhardt's series refactoring object-file.c as part of the `the_repository` removal effort. The patch introduces a new backend-agnostic interface `odb_write_object()` for writing objects to the object database, replacing direct calls to `write_object_file()` which was specific to the loose object format.

The new function currently just wraps `write_object_file()` without using the passed-in object database parameter, but sets up the infrastructure for future changes where it will handle writing to different backend sources. The patch updates 21 files across the codebase to use this new interface, with mechanical changes to call sites that were previously using `write_object_file()` or `write_object_file_flags()`.

This continues the series' pattern of introducing new interfaces while maintaining existing behavior, preparing for pluggable object backends. The changes are widespread but straightforward, touching core object writing operations across various commands like checkout, merge, tag creation, and more. The patch doesn't yet implement the full backend selection logic - that will come in subsequent commits as indicated in the commit message.
