This thread reports a Tcl/Tk error in gitk showing "wrong # args: should be 'safe_open_command_redirect cmd redir'" when executing `git log`. Nicolas Ratier initially described the issue without providing technical details about their environment or reproduction steps.

Johannes Sixt, the gitk maintainer, has now identified the root cause as an incorrect backport of security fixes in pre-2.43.7 Git versions, specifically pointing to a known Ubuntu packaging issue (bug #2116253). The error occurs when gitk's Tcl/Tk scripts interface with Git plumbing commands, and the mismatch suggests this is a distribution-level problem rather than an upstream Git bug. Johannes has offered to assist further if needed, though the solution likely requires maintainer intervention from the distribution side. Users experiencing this issue should check their Git version and consider upgrading or reporting to their distribution's package maintainers.
