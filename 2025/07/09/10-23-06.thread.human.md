This thread began with Nicolas Ratier reporting a Tcl/Tk error in gitk showing "wrong # args: should be 'safe_open_command_redirect cmd redir'" when executing `git log`. Johannes Sixt quickly identified this as a known packaging issue affecting pre-2.43.7 Git versions, caused by incorrect backporting of security fixes in some distributions (specifically referencing Ubuntu bug #2116253).

Junio Hamano initially wondered if this might indicate a backport error in Git's own maintenance releases, but after checking confirmed that Git 2.43.7 and newer versions are unaffected. The consensus is clear: this is a downstream packaging problem rather than an upstream Git issue. The error occurs when distributions incorrectly applied security fixes to older Git versions, affecting the Tcl/Tk command interface in gitk.

The thread has effectively reached resolution, with all parties agreeing the fix must come from distribution maintainers rather than the Git project. Johannes Sixt's prompt diagnosis and Junio's verification have provided the reporter with a clear path forward through distribution bug channels.
