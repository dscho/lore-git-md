This is a refactoring patch in a series improving type safety in Git's parse-options infrastructure. It adds precision handling for OPTION_BITOP, completing the type-safety work for bitwise operation options.

The patch extends the established pattern from earlier in the series to OPTION_BITOP, ensuring bit operations respect the precision (size) of their target variables. It introduces bounds checking for default values while maintaining the ability to use -1 to clear all bits, even when working with narrower types. The changes are minimal but important for consistency, touching just the core parse-options files.

This continues René Scharfe's systematic work to make Git's option parsing more robust, following review feedback from Patrick Steinhardt. The implementation is clean and focused, matching the quality seen in previous patches of the series. With this change, only OPTION_COUNTUP and OPTION_NUMBER remain to complete the type-safety overhaul.
