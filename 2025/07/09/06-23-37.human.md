This is a build system improvement patch in Patrick Steinhardt's ongoing Meson modernization series (v3, 3/8). It enhances the feature summary output in Git's Meson build system to be more informative and visually clearer.

The patch modifies the build summary to show version numbers for detected dependencies (like curl, expat, and pcre2) rather than just boolean true/false values. It also introduces colorized "YES"/"NO" output for boolean options, making the summary more readable at a glance. The change is straightforward - it passes dependency objects directly to Meson's summary() function rather than just their .found() status.

This is part of a well-polished series that has already addressed previous review feedback. The improvement is small but meaningful for developers examining build configurations, and maintains consistency with the series' goal of modernizing Git's build infrastructure.
