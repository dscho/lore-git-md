Gitk GUI tool bug report thread summary:

Nicolas Ratier reports a Tcl/Tk error in gitk showing "wrong # args: should be 'safe_open_command_redirect cmd redir'" when executing `git log`. Johannes Sixt identifies this as a known packaging issue affecting pre-2.43.7 Git versions, caused by an incorrect backport of security fixes. The error manifests in the Tcl/Tk command interface when gitk calls `git log`, with Ubuntu bug #2116253 cited as a reference case. This shifts the diagnosis from a general gitk problem to a distribution-specific packaging error. Johannes offers further assistance if needed, indicating the fix would require maintainer intervention at the distribution level rather than being resolvable by end users. The key technical details include the version threshold (pre-2.43.7), security fix context, and specific Tcl/Tk command interface failure ("safe_open_command_redirect"). The thread now has a clear path forward for the reporter via distribution bug channels.
