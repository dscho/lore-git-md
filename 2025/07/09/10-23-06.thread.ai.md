Gitk GUI tool bug report thread summary:

Nicolas Ratier reports a Tcl/Tk error in gitk showing "wrong # args: should be 'safe_open_command_redirect cmd redir'" when executing `git log`. Johannes Sixt identifies this as a known packaging issue affecting pre-2.43.7 Git versions, caused by an incorrect backport of security fixes in downstream distributions (Ubuntu bug #2116253 cited). Junio Hamano confirms after investigation that Git 2.43.7+ is unaffected, ruling out upstream responsibility. The error manifests in the Tcl/Tk command interface when gitk calls `git log`, specifically in the `safe_open_command_redirect` command. The thread establishes this as a distribution-specific packaging error requiring maintainer intervention, with Johannes offering further assistance if needed. Key technical details include the version threshold (pre-2.43.7), security fix context, and specific Tcl/Tk command interface failure. The path forward is via distribution bug channels, with upstream Git confirmed not at fault.
