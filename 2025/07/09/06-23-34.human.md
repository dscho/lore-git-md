This is the third version of Patrick Steinhardt's Meson build system improvement series, consisting of 8 patches that clean up and optimize Git's build infrastructure. The series has been tested on both GitHub and GitLab CI systems and addresses several technical issues that emerged from earlier versions.

Key improvements in v3 include adding a clarifying comment about Python version detection (now only checking the target system's Python rather than both native and target versions), fixing test slice numbering in GitHub workflows, and maintaining all the fixes from v2. The series continues to address cross-platform concerns like MINGW64 shell path resolution and libexecdir handling while updating subproject dependencies.

The patches show careful attention to detail, with each change clearly motivated and tested across multiple platforms. Review feedback from Justin Tobler has been incorporated, particularly around the Python detection logic. The series appears ready for merging, with only minor documentation improvements remaining as open items. The changes are focused and well-contained, touching build configuration files like meson.build and CI workflow definitions without affecting core Git functionality.
