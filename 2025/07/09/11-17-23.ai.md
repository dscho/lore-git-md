Continuing the `the_repository` removal effort, this patch refactors loose object iteration to eliminate global repository dependencies. Patch 13/19 in the series focuses on two key iterator functions:

1. `for_each_loose_file_in_objdir()` is renamed to `for_each_loose_file_in_source()` and modified to take an `odb_source` parameter instead of a path string. This aligns with the series' pattern of working directly with ODB sources rather than repository-global paths.

2. `for_each_loose_object()` is updated to accept an `object_database` parameter, internally using the new source-based iteration. This removes its dependency on `the_repository` while maintaining the same functionality.

The changes propagate through 10 files, primarily adjusting callers to pass the repository's object database or source rather than paths. Notable updates include:
- `builtin/fsck.c` now uses `fsck_source()` with direct ODB source
- `builtin/gc.c` switches loose object counting to source-based iteration
- `object-file.c` implements the new variants while preserving the iteration logic
- The interface in `object-file.h` is updated to reflect the parameter changes

The patch follows the series' incremental approach, mechanically converting another set of functions to use the new ODB-centric interfaces. It touches core object operations across multiple commands (cat-file, count-objects, fsck, gc, etc.) while maintaining external behavior. The changes are focused but widespread, continuing the systematic elimination of `the_repository` dependencies in preparation for pluggable backends.
