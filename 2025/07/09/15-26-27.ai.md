Performance test addition for the `git last-modified` command series. This patch adds a new performance test script `t/perf/p8020-last-modified.sh` to track the execution time of the new `git last-modified` command in various scenarios. The test measures three cases: basic top-level operation, recursive mode (`-r`), and operation on a subdirectory. The test is added to the meson build configuration alongside other Git performance benchmarks.

The test script follows the standard perf test structure, using the default test repository. It exercises the command's core functionality by checking:
1. Simple invocation on HEAD
2. Recursive mode on HEAD
3. Operation on a randomly selected subdirectory (found via `git ls-tree`)

This builds on previous work in the series (referenced via Based-on-patch-by) and appears straightforward in its implementation. The test cases are minimal but cover the main operational modes that would be performance-sensitive. The patch is part of the v4 series which has already addressed most major review feedback, with this addition completing the performance monitoring aspect of the feature.
