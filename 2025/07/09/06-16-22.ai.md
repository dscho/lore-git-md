This is a follow-up in the Meson build system improvement series, specifically addressing Python version detection. The patch removes the redundant native Python check and relies solely on `find_program()` for cross-compilation scenarios, ensuring the build checks for Python on the target host rather than the build host.

The key technical change is replacing the dual Python checks (native and target) with a single `find_program()` call that properly handles cross-compilation by only checking the target system's Python availability. Justin Tobler confirmed this approach makes sense for Git's use case where Python is needed at runtime rather than build time, though suggested adding a clarifying comment about the rationale.

This change affects the Python-dependent build configuration in `meson.build`, particularly for features like git-p4 that require Python on the target system. The patch maintains all existing functionality while simplifying the detection logic and properly supporting cross-compilation scenarios.
