This is the final patch in Patrick Steinhardt's 8-part series improving Git's Meson build system, focusing on CI test parallelization. The patch replaces a complex PowerShell-based test slicing mechanism with Meson's new native `--slice` option (added in version 1.8) to speed up Windows test execution in both GitHub Actions and GitLab CI.

The change simplifies the CI configuration by replacing a multi-step PowerShell pipeline that manually grouped tests with a single Meson command. The new approach is more maintainable and leverages Meson's built-in capabilities rather than custom scripting. Both CI systems have been confirmed to support Meson 1.8.2, making this a straightforward upgrade.

This patch appears to be a clean, well-justified improvement that completes the series' goal of modernizing Git's build infrastructure. With all technical feedback from previous versions addressed and CI systems verified to support the new Meson feature, this seems ready for merging.
