Feature refinement for Git's fast-export/import signature handling. This v6 patch finalizes the standardized signature output format ("gpgsig <hash-algo> <format>") that cleanly separates Git object hash algorithms from signature protocol types. The implementation now exports all signatures while importing at most one per hash algorithm, with warnings for duplicates.

Key improvements in this version:
- Documentation clarifications about the `gpgsig` command syntax and future verification possibilities
- Code cleanup removing redundant LF-termination handling
- More precise variable naming in parse_one_signature()
- Confirmed support for OpenPGP, X.509, and SSH signature types
- Comprehensive test coverage including dual-signature commits

The patch maintains backward compatibility while providing better tooling support through explicit signature format identification. Christian Couder has incorporated feedback from brian m. carlson, Elijah Newren, and Junio Hamano, with only minor documentation and code style refinements remaining before final merge.

This represents the culmination of a multi-month effort to improve signature handling interoperability, now in its final polishing phase with all major technical questions resolved. The implementation is robust and well-tested, with clear documentation of both current capabilities and future verification plans.
