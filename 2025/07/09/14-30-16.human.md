This is a test infrastructure patch addressing compatibility issues in the security release backport process. Justin Tobler is responding to Todd Zullinger's fix for test scripts that used newer `git config` subcommands (`get`, `set`, `unset`) which aren't available in older Git versions (pre-2.46). The original tests were added as part of CVE-2025-48384 fixes for CRLF handling.

Todd's patch replaces the newer subcommands with the older `--get` and `--unset` flags in two test files (`t1300-config.sh` and `t7450-bad-git-dotfiles.sh`), ensuring the security tests work across all maintained versions (back to 2.43). Justin confirms the changes look correct and acknowledges the oversight in using the newer syntax. The patch is already being tested via GitHub Actions CI across multiple versions.

This is a straightforward but important fix that maintains test coverage while ensuring the security release can be properly validated on older Git versions. The interaction shows good coordination between the security fix authors and the backport testing process.
