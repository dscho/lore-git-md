This is a follow-up in Patrick Steinhardt's Meson build system improvement series, specifically addressing Python version detection. The patch removes the redundant check for a native Python installation during build configuration, since Git only needs to verify Python availability on the target host (not the build host) for features like git-p4.

Justin Tobler confirmed the technical approach is correct - using `find_program()` with `native: false` properly checks the target system's Python rather than the build system's. Patrick agrees to add a clarifying comment about this rationale in the final version. The change is part of broader cross-compilation improvements in the series.

This appears to be a straightforward cleanup that removes unnecessary build-time dependencies while maintaining correct functionality. The change has already been reviewed and approved by Justin, with only minor documentation polish remaining before the series can proceed.
