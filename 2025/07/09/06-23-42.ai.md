This is the final patch in Patrick Steinhardt's Meson build system improvement series (v3, 8/8), focusing on CI optimization. The patch updates GitHub Actions and GitLab CI configurations to use Meson 1.8's new `--slice` option for parallel test execution, replacing the previous complex PowerShell workaround.

Key technical details:
- Replaces PowerShell-based test slicing (`Group-Object` pipeline) with native Meson `--slice` syntax
- Maintains same parallel test distribution (10 slices) as before
- Uses Meson 1.8.2 feature (now available in both CI systems)
- Preserves existing test execution flags (`--no-rebuild`, `--print-errorlogs`)
- Updates both `.github/workflows/main.yml` and `.gitlab-ci.yml` with consistent syntax
- GitHub version uses 1-based indexing (`1+${{ matrix.nr }}`), GitLab uses 0-based (`$Env:CI_NODE_INDEX`)

The change simplifies the CI configuration while maintaining the same parallel test execution strategy that was particularly important for Windows test performance. This completes the series' CI-related improvements, following earlier patches that addressed feature summary enhancements, dependency updates, and build system fixes.
