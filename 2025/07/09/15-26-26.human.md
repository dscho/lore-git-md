This Feature: New `git last-modified` command

This is the first patch in v4 of a series introducing a new `git last-modified` command, which shows the most recent commit that modified each file in a tree. The command works similarly to `git blame` but operates at the tree level rather than line-by-line.

The implementation walks backwards through history to find when each path last changed to match its current state in the target commit. It handles various edge cases including merges, renames, and recursive directory traversal (with `-r` and `-t` flags). The patch includes comprehensive tests covering basic functionality, recursive operation, merge scenarios, and path limiting.

This version consolidates the implementation into `builtin/last-modified.c` with standard command-line parsing and fixes several issues from previous iterations. The command is marked as EXPERIMENTAL in its documentation, allowing for future behavior changes. The implementation appears solid with thorough test coverage, though the unusual command delegation pattern in `cmd_last_modified()` remains a point of discussion.

The series has seen significant review and iteration, with contributions from multiple Git contributors. This foundational patch provides the core functionality that subsequent patches will build upon with performance optimizations.
