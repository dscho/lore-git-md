Build system fix addressing a regression in the Meson build configuration when overriding libexecdir. This patch (6/8 in Patrick Steinhardt's v3 series) corrects an issue where Git couldn't find its binaries when installed with a custom libexecdir path.

The problem occurs when users specify `-Dlibexecdir=` to override the default location - while the path was correctly set in GIT_EXEC_PATH, it failed to append the required 'git-core' subdirectory. This caused commands like `git daemon` to fail with "not a git command" errors. The fix simply ensures the 'git-core' suffix is always appended to the libexecdir path.

Key technical details:
- Modifies `meson.build` to append 'git-core' to custom libexecdir paths
- Maintains backward compatibility with default installations
- Fixes a regression introduced in commit 837f637cf51
- Reported by irecca.kun@gmail.com with reproduction steps
- Verified working with the test case provided in the commit message

This patch completes the libexecdir handling that was partially fixed earlier in the series, ensuring proper binary location detection in all configuration scenarios. The change is minimal (single-line modification) but critical for correct operation when using non-default libexecdir paths.
