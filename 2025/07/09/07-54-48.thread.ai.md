Thread identity: Refactoring series moving MIDX tracking from global object database state to per-source storage in preparation for pluggable backends. Authored by Patrick Steinhardt (now 7/8 patches after removing redundant patch), with review feedback from Taylor Blau and Justin Tobler.

Core problem/goal: Restructure MIDX handling to attach to individual `struct odb_source` instances rather than tracking globally, supporting future pluggable backends. This removes MIDX as an object-database-level concern since it's fundamentally a packfile optimization.

Key technical changes:
- Removed all global MIDX infrastructure in final patch:
  - `multi_pack_index` field from `struct object_database`
  - `next` pointer from `struct multi_pack_index`
  - Global MIDX list maintenance in `prepare_multi_pack_index_one()`
  - Global cleanup paths in `clear_midx_file()` and `close_object_store()`
- Earlier patches establish per-source MIDX tracking:
  - Added `multi_pack_index` field (to be renamed `midx`) to `struct odb_source`
  - Converted all MIDX-related functions to source-specific operation
  - Patch 2/8:
    - Refactored `prepare_packed_git_one()` for per-source operation
    - Removed object directory search by accessing MIDX directly via source
    - Added ASSERT to verify object directory correspondence
  - Patch 3/8:
    - Transitioned MIDX cleanup from global linked-list traversal to per-source handling
    - Eliminated recursive cleanup via `m->next` in favor of direct source iteration
    - `close_midx()` no longer iterates through sources (responsibility moved to callers)
    - Incorporated Taylor Blau's feedback on C99-style for loop formatting
  - Patch 5/8 (updated):
    - Refactored `get_multi_pack_index()` to operate per-source
    - Updated callers in `builtin/repack.c`, `midx-write.c`, and `object-name.c`
    - Added `m->local` check in `builtin/repack.c` for temporary object sources
    - Simplified `lookup_multi_pack_index()` using `odb_find_source()`
    - Implemented per-source iteration in `find_short_packed_object()`
    - Confirmed first source is usually local (except quarantine directories)
    - Verified `odb_find_source()` never returns NULL (currently dies on invalid input)
- Dropped patch 4/8 (redundant `multi_pack_index_loaded` flag) after review feedback
