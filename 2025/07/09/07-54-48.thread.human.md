Patrick Steinhardt's 7-patch series to move MIDX tracking from global state to per-source storage in `struct odb_source` has completed its review cycle and is now being merged. This refactoring, part of the larger object database abstraction effort, eliminates all global MIDX infrastructure while maintaining identical functionality through per-source tracking. The changes recognize MIDX as fundamentally packfile-specific rather than a database-wide concern.

The series received thorough technical reviews from Taylor Blau and Justin Tobler, who confirmed it addresses all prior feedback including style fixes, field renaming, and compatibility with recent cruft pack and object store changes. With no outstanding concerns, Junio Hamano is now queuing the patches in the 'next' branch. The work represents a significant architectural improvement, setting the stage for future cleanups like moving the `local` flag to `struct odb_source`. This marks an important milestone in the ongoing effort to make Git's object storage layer more modular.
