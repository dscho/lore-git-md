This thread centers on Patrick Steinhardt's ongoing effort to restructure Git's MIDX (multi-pack index) handling as part of the broader object database (ODB) abstraction work. The current 7-patch series (now in its second version) moves MIDX tracking from global state to per-source storage in `struct odb_source`, recognizing MIDX is fundamentally a packfile optimization rather than a database-wide concern.

The latest patch (2/7) refactors `prepare_packed_git_one()` to align packfile loading with the new per-source approach. It simplifies the code by directly using each source's MIDX pointer rather than searching by object directory path, while maintaining all existing functionality. The changes are cleanly contained to packfile.c.

Taylor Blau and Justin Tobler have provided thorough reviews, with all their feedback incorporated in v2 - including style improvements, removal of redundant state tracking, and verification of the per-source approach. The series builds cleanly, passes tests, and remains compatible with recent cruft pack/MIDX changes. A few minor follow-ups are still under consideration, like potentially moving the `local` flag to `struct odb_source` and adding a MIDX iteration helper, but the core technical direction appears settled with positive reviewer consensus. This represents another step in the multi-year ODB abstraction effort to enable pluggable storage backends.
