This is a refactoring patch in Patrick Steinhardt's Meson build system improvement series (v3 4/8). It cleans up some unnecessary variables in the documentation build configuration.

The patch removes two variables from Documentation/meson.build that were either unused (`manpage_target`) or only used once (`manpage_path`). The single use of `manpage_path` is inlined directly where it was referenced. This follows the general cleanup theme of the series by simplifying the build configuration.

The changes are straightforward and low-risk, just removing some intermediate variables that weren't providing any benefit. This continues the series' work of streamlining the Meson build configuration after the initial conversion from Makefiles. The patch has already been reviewed in previous iterations of the series and appears ready for inclusion.
