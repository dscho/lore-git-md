This is a performance optimization series for pack-objects and MIDX handling, specifically around cruft packs. The patch series (tb/midx-avoid-cruft-packs) teaches `pack-objects` to avoid including objects from cruft packs when building MIDX files, which should improve performance by reducing unnecessary object lookups. The changes include several preparatory refactors to `pack-objects` before implementing the core functionality.

Key technical points:
- Introduces `--stdin-packs=follow` option for pack-objects
- Performs name-hash traversal for unpacked objects
- Includes various cleanups to pack-objects code (option handling, scope limiting)
- Has been tested in production at GitHub for 1-2 months without issues

The series appears stable and ready for merging to 'next', having addressed previous review feedback from Elijah Newren and Jeff King (Peff). The author notes only minor bugfix-related changes since the last review. This seems like a well-tested, incremental improvement to the pack/MIDX interaction with cruft packs.
