This is a bugfix patch in Patrick Steinhardt's Meson build system improvement series (v3 6/8). It addresses a regression where overriding the libexecdir path with `-Dlibexecdir=` would break Git's ability to find its core binaries like `git-daemon`.

The issue occurs when users specify a custom libexecdir - while the path is correctly set in GIT_EXEC_PATH, the patch was missing the crucial 'git-core' subdirectory that Git expects to contain its binaries. This caused commands like `git daemon` to fail with "not a git command" errors. The fix simply appends 'git-core' to any custom libexecdir path, matching the behavior and restoring functionality.

This appears to be a straightforward correction of an oversight in the earlier Meson build system changes. The patch includes clear reproduction steps showing both the broken behavior and the fixed state, and builds on a report from another contributor (irecca.kun). As part of a well-reviewed series that's already addressed previous feedback, this seems like a low-risk fix that properly completes the libexecdir handling work.
