This is a build system patch from Patrick Steinhardt's Meson modernization series (v3 1/8). It fixes how Python detection works in the build process by removing an unnecessary check for the build system's Python version. The patch clarifies that Git only needs Python for runtime (specifically for git-p4) and thus should only check for the target system's Python availability.

The change simplifies the build configuration while making it more correct for cross-compilation scenarios. The commit message explains the rationale clearly, and the patch has already incorporated feedback from previous review rounds (notably Justin Tobler's suggestion about Python detection). This appears to be a straightforward technical improvement that aligns with the series' goal of modernizing Git's build infrastructure.
