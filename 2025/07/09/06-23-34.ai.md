This is the third version of Patrick Steinhardt's Meson build system improvement series, consisting of 8 patches that clean up and optimize various aspects of Git's Meson build infrastructure. The series has been tested on both GitHub and GitLab CI systems and addresses several technical issues from previous versions.

Key changes in v3 include:
1. Added a clarifying comment explaining why Python detection only needs to find the target system's Python (for git-p4) rather than the build system's Python
2. Maintains all fixes from v2 including:
   - Test slice fix for GitHub Workflows
   - Cross-platform shell path resolution on MINGW64
   - libexecdir regression fix (reverting Ramsay Jones' earlier change)
   - Subproject wrapper updates (expat and pcre2)
   - CI parallelization using Meson 1.8's `--slice` feature

The series touches several build system files:
- `.github/workflows/main.yml` and `.gitlab-ci.yml` for CI integration
- `meson.build` for core build logic improvements
- `Documentation/meson.build` for cleanup
- Subproject wrapper files for dependency updates

Technical improvements include:
- Simplified Python detection that only checks target system (not build system)
- Consolidated feature summary display with version numbers
- Fixed MINGW64 shell path resolution
- Corrected libexecdir handling when custom path specified
- Removed unnecessary variables in documentation build

The series appears well-tested and reviewed, with Justin Tobler confirming the technical soundness of key changes. The only remaining open item is adding a comment about the Python target check rationale, which has been addressed in this version. The patches maintain backward compatibility while modernizing the build system.
