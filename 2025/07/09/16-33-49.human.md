Bugfix for git-subtree documentation. Marc Branchaud confirms Alexander Krupp's report that the example command in git-subtree's documentation fails with "fatal: '0a8f4f0^..' does not refer to a commit". The issue stems from the commit range syntax in the example being invalid when passed to `git rev-parse`.

Branchaud tried removing the ".." from the example, which avoids the immediate error but results in an empty output, suggesting the underlying problem may be more complex than just documentation. He has CC'd the subtree author (from contrib/subtree/README) and the person who added the commit verification check (David, via commit 10a49587fab) for further investigation.

This appears to be a straightforward documentation bug where an example command doesn't work as written, though the empty result when fixing the syntax suggests there may be additional subtleties to resolve. The patch seems likely to be accepted once the correct command syntax is determined, as it's clearly a case where the docs don't match reality.
