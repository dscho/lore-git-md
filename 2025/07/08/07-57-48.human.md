This is a routine dependency update patch in Patrick Steinhardt's Meson build system improvement series. As the 7th of 8 patches in v2 of the series, it updates two subproject wrappers to their latest versions: expat from 2.6.3 to 2.7.1 and pcre2 from 10.44 to 10.45.

The changes are mechanical updates to the wrap configuration files, following the Meson build system's standard format for declaring dependencies. Each update includes new source URLs, hash values, and version numbers, but no functional changes to Git itself. The patch was generated by running `meson wrap update` in the project root.

This maintenance update keeps Git's build dependencies current with upstream releases, which may include security fixes and performance improvements in these libraries. The patch is straightforward and low-risk, fitting cleanly into the broader series that has already been thoroughly tested across multiple CI systems.
