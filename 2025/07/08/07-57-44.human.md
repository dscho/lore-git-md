This is part of Patrick Steinhardt's series improving Git's Meson build system, specifically focusing on the feature summary output. The patch enhances the auto-detected features display in the Meson build by showing version numbers for dependencies and using colored YES/NO indicators instead of true/false.

The change makes the build output more informative by showing which versions of dependencies like curl, expat, and pcre2 were found, while also making the visual presentation clearer with color-coded status indicators. This is a straightforward quality-of-life improvement for developers running the build, giving them more context about their build environment at a glance.

The implementation is clean - it simply passes the dependency objects directly to Meson's summary() function rather than just their .found() status, and enables the bool_yn formatting option. The diff shows the before-and-after output, demonstrating the clear improvement in information density and readability.

This patch is part of a larger v2 series that has already addressed all technical concerns and is ready for merging. The change is non-controversial and aligns with the series' goal of improving the Meson build system's correctness and usability.
