This is a build system patch in Patrick Steinhardt's Meson modernization series, specifically addressing Python version detection. Justin Tobler provides feedback on the first patch in the series, which removes the native Python version check in favor of checking only the target host's Python availability.

The key change here is that Git's build system was incorrectly checking for Python on the build host when it should have been checking the target host instead, since Python is only needed for runtime (specifically for git-p4) rather than during the build process. Justin agrees with the technical approach but suggests adding a clarifying comment to explain the distinction between build-time and runtime Python requirements.

The patch is straightforward - it replaces the Python detection logic to use `find_program()` with `native: false` and updates all related conditionals to check `target_python` instead of the native `python` variable. The changes are clean and focused, touching only the Meson build file.

This is providing constructive feedback on an already solid patch, noting that while the technical changes are correct, some additional documentation in the form of comments would help future maintainers understand the distinction being made. The discussion appears to be moving toward a resolution with this minor suggestion.
