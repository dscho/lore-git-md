Subject: Coordinated security release for Git versions v2.43.7 through v2.50.1 addressing seven CVEs, with ongoing test infrastructure updates for backport compatibility.

Key vulnerabilities fixed:
- Gitk: CVE-2025-27613 (file creation/truncation) and CVE-2025-27614 (arbitrary command execution) via malicious repositories
- Git GUI (Windows): CVE-2025-46334 (malicious executables) and CVE-2025-46835 (file overwrites)
- Core Git: CVE-2025-48384 (CRLF handling in config/submodules), CVE-2025-48385 (bundle URI validation), CVE-2025-48386 (wincred buffer overflow)

Primary contributors: Johannes Sixt (27 commits) and Mark Levedahl (13 commits) on Gitk/Git GUI fixes, Justin Tobler on config CR quoting, Patrick Steinhardt on bundle-uri validation. Todd Zullinger identified and fixed test compatibility issues when backporting to older versions (v2.43-v2.45).

Test infrastructure updates:
- Modified tests for CVE-2025-48384 to use backward-compatible `--get`/`--unset` flags instead of newer subcommands
- 4-line change verified working back to Git 2.43 while maintaining test coverage
- Junio Hamano reviewed and queued the compatibility patch
- CI testing via GitHub Actions confirms cross-version functionality

The security fixes demonstrate comprehensive attention to argument sanitization, path handling, and protocol validation. The test compatibility work ensures the security release testing framework remains functional across all maintained versions during backporting, though the changes do not affect the security fixes themselves. Impact remains critical for Windows users and Gitk/Git GUI users across all listed versions.
