Documentation patch updating the `git-pack-refs` man page to reflect the current heuristic used by the "files" backend for `--auto` packing.

The patch corrects outdated documentation that claimed the "files" backend had no special handling for `--auto`. In reality, since commit c3459ae9ef2 (September 2024), the files backend uses a ratio-based heuristic to decide when to repack loose refs into the `packed-refs` file - the larger the existing packed-refs file, the more loose refs are required before triggering a repack. This change was made to prevent excessive repacking that was occurring with the files backend.

The patch keeps the existing description of the reftable backend's geometric sequence approach while adding the new files backend details. The change is straightforward and clearly motivated by Karthik Nayak's report of the documentation being out of sync with actual behavior. The diff shows the minimal documentation update needed to accurately reflect current behavior.
