Feature improvement for Git's fast-export/fast-import signature handling. This v5 patch from Christian Couder builds on previous iterations to enhance how commit signatures are processed, with Junio Hamano now queuing it for inclusion. The changes focus on completeness and clarity: all signatures are now exported (though import still limits to one per hash algorithm), output formatting is more consistent with LF termination, and documentation is improved. Test coverage expands to verify dual-signature commits (SHA-1 + SHA-256) while maintaining stricter hash algorithm assertions. The patch appears technically sound, with help from brian m. carlson and Elijah Newren, and addresses prior feedback about test precision and output format standardization. While the implementation's complexity versus a simpler passthrough approach remains an open design question, this version seems ready for merging with its clear improvements to signature handling infrastructure.
