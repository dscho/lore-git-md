This is a build system cleanup patch in Patrick Steinhardt's Meson improvement series. It fixes an incorrect Python version detection approach in the Meson build configuration. The patch removes redundant native Python version checking since Git's build process doesn't actually need it, while correcting the one place where Python detection is used (for git-p4 support) to properly check the target system's Python rather than the build system's.

The change is straightforward - it addresses a clear technical inconsistency in the build system where we were checking for Python in two different ways unnecessarily. The patch simplifies the logic while making the git-p4 check more correct by using the target system's Python version rather than the build system's. This is the first of eight patches in a v2 series that has already been reviewed and is considered ready for merging.
