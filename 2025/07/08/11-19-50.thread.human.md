Victoria Dye's patch series introduces a new `git sparse-checkout clean` command to handle leftover sparse directories in cone mode, which can cause unnecessary full index expansions. The command provides a more precise alternative to `git clean` by specifically targeting sparse directories that exist on disk but shouldn't, while preserving staged changes and excluded files within the sparse-checkout scope.

The third patch in the series updates the documentation to complete the feature introduction. It modifies the sparse index expansion advice message to recommend the new `git sparse-checkout clean` command instead of the generic `git clean`. This one-line change ensures users encountering sparse index expansion issues will be directed to the more appropriate tool for this specific use case. The change is straightforward and aligns with the series' goal of improving the sparse-checkout experience by addressing performance problems caused by leftover sparse directories.
