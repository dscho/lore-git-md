Security release announcement for Git v2.50.1 and older maintenance versions. This coordinated set of updates addresses seven CVEs across multiple Git components, with fixes backported as far as v2.43.7. The vulnerabilities range from path injection in Gitk and Git GUI to protocol injection in bundle fetching and buffer overflows in the Windows credential helper.

The most severe issues include CVE-2025-48385 (remote code execution via malicious bundle advertisements) and CVE-2025-48386 (buffer overflow in wincred helper). Several Gitk/Git GUI vulnerabilities (CVE-2025-27613/14/46334/46835) allow file creation/overwrite or arbitrary execution when viewing malicious repositories. A submodule path handling issue (CVE-2025-48384) could lead to unintended hook execution.

The bulk of fixes come from Johannes Sixt (27 commits) and Mark Levedahl (13 commits), primarily hardening argument handling in Gitk and Git GUI. Notable changes include proper argument sanitization, PATH handling improvements, and removal of legacy compatibility code. This appears to be a comprehensive security update addressing multiple attack vectors, particularly in the Tcl-based UI tools.
