This is a critical security update for Git for Windows (v2.50.1) addressing nine CVEs across multiple components. The most severe vulnerabilities allow remote code execution through Gitk (CVE-2025-27613/27614) when cloning untrusted repositories, and through Git GUI (CVE-2025-46334/46835) via malicious worktree programs. Core Git fixes include config file handling issues, bundle protocol validation flaws, and a wincred credential helper buffer overflow (CVE-2025-48384-48386). The release provides installers for 64-bit, ARM64, and 32-bit systems, plus portable and MinGit variants, all with SHA-256 checksums. Windows users should prioritize installing this update due to the high-risk nature of the patched vulnerabilities.
