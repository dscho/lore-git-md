Security release announcement for Git v2.50.1 and older maintenance versions. This is a coordinated set of security fixes addressing seven CVEs across multiple Git components, with backports available as far back as v2.43.7.

The vulnerabilities span several areas: Gitk (the Git repository browser) has multiple issues where malicious repositories could trick users into running arbitrary scripts or overwriting files. Git GUI on Windows has similar vulnerabilities around path handling and executable lookup. The core Git client has three serious issues - improper CRLF handling in config files that could lead to submodule hook execution, insufficient validation of server-advertised bundles allowing protocol injection, and a buffer overflow in the Windows credential helper.

The fixes come from multiple contributors, with Johannes Sixt and Mark Levedahl providing the bulk of the patches for Gitk and Git GUI respectively. The bundle-uri and wincred fixes come from Patrick Steinhardt and Taylor Blau. This appears to be a well-coordinated security response with comprehensive coverage across affected versions. Users should prioritize updating given the severity of some of these issues, particularly the bundle protocol vulnerability that could lead to arbitrary code execution.
