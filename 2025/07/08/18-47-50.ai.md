This is a documentation patch that updates the file extensions for release notes files to match a recent convention. 

The patch renames seven security release note files from `.txt` to `.adoc` extension, following commit 1f010d6bdf which established `.adoc` as the standard extension for AsciiDoc files. The affected files cover security releases from v2.43.7 through v2.49.1. 

The change was needed because these security release notes were prepared before the `.adoc` convention was established in the 2.49 release series, but were merged up through the maintenance branches without the extension change. The patch notes that the `maint` track for v2.50.0 is unaffected since it was tagged after the convention change.

The patch makes no content changes - it's purely a file rename operation affecting Documentation/RelNotes/ files for multiple versions. The commit message clearly explains the context and rationale for the change, referencing the earlier commit that introduced the `.adoc` convention. This appears to be a straightforward documentation maintenance patch to maintain consistency in the codebase.
