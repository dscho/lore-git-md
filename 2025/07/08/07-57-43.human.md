This is a small cleanup patch in Patrick Steinhardt's Meson build system improvement series. It fixes a duplicate display of the HTTPS backend status in the build summary output. The patch simply removes one redundant line from meson.build that was showing the HTTPS status twice - once in the auto-detected features section and again in the backends section.

The change is straightforward and uncontroversial, removing just one line of redundant output while maintaining all the same information in a more concise form. As part of the v2 series that has already been technically reviewed and approved, this patch appears ready for merging along with the rest of the series.
