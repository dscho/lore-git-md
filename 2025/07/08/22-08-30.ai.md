This is a test infrastructure patch related to the recent security release, specifically addressing compatibility issues in the test suite when backporting fixes to older Git versions.

The patch addresses a problem where tests added for security fixes (particularly CVE-2025-48384 regarding CRLF handling) used newer `git config` subcommand syntax (`get`/`set`/`unset`) that wasn't available in Git 2.43 through 2.45. Todd Zullinger identified this when testing the security release on older branches and proposes reverting to the older syntax (using `--get`, `--set`, etc.) to maintain test functionality across all maintained versions.

The changes are minimal (4 lines total) and have been verified to work back to Git 2.43 while still properly testing the security fixes. Junio Hamano has reviewed and queued the patch, noting it merges cleanly across the affected versions. This is a straightforward but important change to ensure the security release testing framework remains functional across all maintained versions, though it doesn't affect the security fixes themselves.
