This thread documents a straightforward maintenance patch to update file extensions for Git's release notes. The patch, which affects only documentation files, renames seven security release note files from `.txt` to `.adoc` extensions to match a convention established in commit 1f010d6bdf. The change applies to security releases from v2.43.7 through v2.49.1, bringing them in line with the current standard while making no content modifications.

The patch author notes that the `maint` track for v2.50.0 already uses the correct extension, as it was tagged after the convention change. This appears to be a clean, uncontroversial change to maintain consistency in the project's documentation structure.
