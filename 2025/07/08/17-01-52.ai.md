This is a coordinated security release announcement covering multiple Git versions (v2.43.7 through v2.50.1) addressing seven CVEs. The fixes primarily target vulnerabilities in Gitk, Git GUI, and core Git functionality that could lead to arbitrary code execution, file manipulation, or protocol injection attacks.

The security issues include:
- Gitk vulnerabilities (CVE-2025-27613/27614) allowing file creation/truncation and arbitrary command execution via crafted repositories
- Git GUI Windows-specific issues (CVE-2025-46334/46835) involving malicious executables and file overwrites
- Core Git problems with CRLF handling in config/submodules (CVE-2025-48384), bundle URI validation (CVE-2025-48385), and wincred buffer overflow (CVE-2025-48386)

The bulk of the fixes come from Johannes Sixt (27 commits) and Mark Levedahl (13 commits), focusing on argument sanitization in Gitk/Git GUI and Windows-specific path handling. Other notable changes include Justin Tobler's config CR quoting fix and Patrick Steinhardt's bundle-uri parameter validation. The release includes detailed descriptions of each vulnerability's impact and attack vectors.

This is a critical security update affecting all listed versions, with particularly severe implications for Windows users and those using Gitk/Git GUI. The fixes demonstrate careful attention to argument sanitization, path handling, and protocol validation across multiple components. The coordinated release across multiple maintenance tracks indicates these vulnerabilities affect a wide range of Git versions in production use.
