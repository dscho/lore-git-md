This is a platform compatibility fix in Patrick Steinhardt's Meson build system series. The patch addresses a shell path lookup issue on MINGW64 systems where the previous solution of adding '/bin' to the search path caused errors because Meson expects absolute Windows-style paths. The new approach searches for both '/bin/sh' and 'sh' directly, which maintains the desired preference for '/bin/sh' while working correctly on Windows. The change is minimal (just one line in meson.build) but important for cross-platform compatibility, and the commit message includes clear examples demonstrating the fix works with both default and cross-compilation scenarios. This is part of a well-tested series that's now ready for merging.
