After thorough discussion, the community has agreed the feature should be removed entirely in Git 3.0, with clear deprecation warnings starting now.

Phillip and Junio agree the simplest approach is to recommend setting a new value in user or repo config (letting Git's standard last-one-wins rules handle precedence) rather than trying to remove the system setting. Phillip plans to send updated patches next week incorporating this resolution.
