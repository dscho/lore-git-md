Junio Hamano responds to Sahil Gautam's proposal about native Git issue tracking with skepticism about current implementations. While acknowledging the valid concern about vendor lock-in for project metadata (issues, reviews), he suggests the solution lies in standardization between hosting providers rather than core Git functionality. Hamano envisions an open interchange format that would enable both migration between providers and potential federated workflows where metadata could be shared across different hosting platforms. The response indicates this is more of a social/standards challenge than a technical one for Git to solve directly. No technical objections are raised, but the reply clearly positions this as outside Git's current scope, preferring an ecosystem-level solution.
