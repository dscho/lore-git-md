Security release for Git for Windows (v2.50.1) addressing nine CVEs across Git, Gitk, and Git GUI components. Critical vulnerabilities include CVE-2025-27613/CVE-2025-27614 in Gitk allowing arbitrary file manipulation and script execution during clone, CVE-2025-46334/CVE-2025-46835 in Git GUI enabling malicious program execution from worktree and file overwrites, and three core Git issues (CVE-2025-48384-48386) covering CRLF config handling, bundle protocol validation, and wincred helper buffer overflow. Release provides installers for 64-bit, ARM64, and 32-bit Windows systems with SHA-256 checksums, including portable and MinGit variants. This is a mandatory update due to multiple remote code execution risks. Maintained by Johannes Schindelin (Dscho) as part of the Git for Windows project, which is a separate distribution from upstream Git.
