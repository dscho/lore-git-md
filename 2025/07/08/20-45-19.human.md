Maintainer ack for documentation fix on `git-pack-refs` auto-packing behavior.

Junio Hamano, the Git maintainer, gives his approval to Patrick Steinhardt's documentation patch that corrects the `git-pack-refs` man page regarding `--auto` behavior. The patch updates the description of how both the "files" and "reftable" backends determine when to automatically repack references, replacing outdated information about the files backend having "no special handling" with its actual ratio-based heuristic.

This comes after Karthik Nayak originally spotted the documentation discrepancy and Patrick submitted the fix, which had already received positive review from Karthik. The thread showed consensus on the main correction, with only minor discussion about whether to mention the logarithmic nature of the ratio (left out as implementation detail).

With this maintainer ack, the documentation update appears ready to be merged into the main Git tree, providing users with accurate information about how reference packing works in both storage backends.
