This is a platform compatibility fix in Patrick Steinhardt's Meson build system improvement series. The patch addresses a MINGW64-specific issue introduced by an earlier change that modified shell path lookup to prefer `/bin/sh` by adding `/bin` to the search path. On Windows-style paths, this caused Meson to error because `/bin` is not an absolute path in that context.

The solution changes the approach to directly search for `/bin/sh` first, falling back to `sh` if not found, while maintaining the same preference order. Justin Tobler confirms this works correctly, noting it preserves the desired behavior on both Unix-like systems and MINGW64 while still allowing override via cross-compilation files. The change is minimal (one line in meson.build) and maintains compatibility with existing cross-compilation setups, as demonstrated by Patrick's test cases showing proper shell path resolution with and without cross-file overrides.

This is the fifth patch in an 8-part series that has already seen extensive review, with Justin having previously validated other technical aspects of the Python detection and feature summary improvements. The thread shows consensus on this particular fix, with no outstanding concerns raised.
