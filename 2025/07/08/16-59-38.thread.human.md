This is a coordinated security release addressing seven critical vulnerabilities (CVEs) across multiple Git versions from v2.43.7 through v2.50.1. The issues span Git's graphical interfaces (Gitk and Git GUI) and core functionality, with potential impacts including arbitrary code execution, file overwrites, and path injection attacks when handling malicious repositories or specially crafted inputs.

Key fixes include hardening Gitk and Git GUI against command injection (led by Johannes Sixt and Mark Levedahl), patching a Windows credential helper buffer overflow (Taylor Blau), and securing the bundle-uri feature against parameter injection (Patrick Steinhardt). The changes involve extensive input sanitization, particularly around shell command execution and Windows path handling. With 52 commits from multiple contributors, this release represents a significant security hardening effort affecting all supported versions back to v2.43.
