This is the final patch in Patrick Steinhardt's Meson build system improvement series, focusing on CI optimization. The patch updates GitHub Actions and GitLab CI configurations to use Meson's new `--slice` option for parallel test execution, replacing a complex PowerShell workaround.

The change simplifies the test parallelization logic by leveraging Meson's native slicing capability, which was added in version 1.8 (Patrick contributed this upstream). This appears to be a straightforward quality-of-life improvement that maintains the same parallel testing functionality while reducing maintenance complexity. As the last patch in a well-tested series that has already addressed all major issues, it seems ready for inclusion. The change is particularly beneficial for Windows testing, which was noted as being "notoriously slow" without parallel execution.
