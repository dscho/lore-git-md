This is a security-focused release announcement for Git for Windows 2.50.1, addressing multiple CVEs across Git and its GUI components. Johannes Schindelin announces the availability of this maintenance release which patches nine security vulnerabilities, some with serious implications.

The most critical issues involve potential arbitrary code execution scenarios. Gitk has two vulnerabilities (CVE-2025-27613/27614) where malicious repositories could trick users into file manipulation or script execution. Git GUI on Windows (CVE-2025-46334/46835) has similar risks where worktree executables could be hijacked or files overwritten. The core Git client has three vulnerabilities: config CRLF handling could lead to submodule hook execution (CVE-2025-48384), bundle protocol validation flaws enable server-side attacks (CVE-2025-48385), and the wincred helper has a buffer overflow risk (CVE-2025-48386).

The release includes the standard 64-bit and ARM64 packages, plus an unexpected 32-bit version described as an "after warranty" addition. All package variants (installers, portable versions, and MinGit) are listed with their SHA-256 checksums for verification. This appears to be a mandatory update for Windows users due to the severity of the fixed vulnerabilities, particularly for those using Git's graphical interfaces or working with untrusted repositories.
