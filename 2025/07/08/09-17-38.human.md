Feature improvement for Git's fast-export/fast-import signature handling. This v5 patch from Christian Couder enhances the signature format in fast-export/import to better support multiple signature types and hash algorithms. The key changes include:

The patch introduces a more informative output format "gpgsig <git-hash-algo> <signature-format>" that clearly distinguishes between the Git object hash algorithm (SHA-1/SHA-256) and signature type (OpenPGP/X.509/SSH/unknown). This helps both with verification and tool processing. While all signatures are now exported, fast-import still only imports one per hash algorithm, warning about additional signatures.

Notable improvements in v5 include better documentation explaining the dual purpose of the format fields, a new test case for commits with both SHA-1 and SHA-256 signatures, and more precise test assertions using $GIT_DEFAULT_HASH. The implementation ensures signatures end with LF for better grep-ability and human readability.

The changes maintain backward compatibility while addressing limitations in the original implementation, particularly around signature identification and multiple signature support. The patch has been through several rounds of review with input from brian m. carlson and Elijah Newren, and all CI tests pass. This represents a thoughtful evolution of the signature handling that should improve interoperability and future extensibility.
