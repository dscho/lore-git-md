This thread addresses a TAP format violation in the test script `t1006-cat-file.sh` when run under Meson. The issue was introduced by commit 9fd38038b9c, which added a `grep` command outside a test case to handle object specifiers with spaces. The grep's direct stdout output violated TAP format requirements, causing Meson to emit warnings even when tests passed.

The proposed fix is minimal and effective: adding a `-q` flag to suppress grep's output while preserving its exit status functionality. This maintains the test's logic (marking tests with spaces in object names as expected failures) while making the output properly formatted. The change is well-justified and addresses a real annoyance in the test suite's output without introducing new complexity.
