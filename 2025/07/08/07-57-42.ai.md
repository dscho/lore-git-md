This is a build system cleanup patch in Patrick Steinhardt's Meson improvement series. It corrects Python version detection in the Meson build configuration by removing an unnecessary search for a native Python installation when checking for Python support.

The patch fixes an inconsistency where the build system was checking for Python on the build host (via `import('python')`) when it should have been checking for Python on the target system (via `find_program()`). This matters because Git doesn't use Python during build - it only needs Python available at runtime for features like git-p4. The change simplifies the configuration by eliminating the native Python check entirely and standardizing on the target system check.

Key technical changes:
- Removes `import('python')` call that was finding native Python
- Makes `target_python` the sole check for Python availability
- Updates the feature summary display to use `target_python.found()`
- Maintains all existing functionality while being more correct about cross-compilation scenarios

This is the first of eight patches in the v2 series that has already been technically vetted and is ready for merging. The change is focused and well-contained, touching only meson.build with straightforward substitutions that don't affect build outputs when Python is available.
