This is a documentation patch that standardizes file extensions for release notes. Taylor Blau noticed that recent security release notes (for versions 2.43.7 through 2.49.1) were still using the `.txt` extension despite Git having switched to `.adoc` for AsciiDoc files earlier this year (commit 1f010d6bdf). 

The patch simply renames these files to use the new `.adoc` extension without changing any content. The change is purely mechanical - the diff shows 100% similarity between the old and new filenames. Taylor notes this was an oversight during the merge process, as these security releases were prepared before the extension change but merged into branches that should have adopted the new convention.

The patch is straightforward and uncontroversial, aligning with an existing documentation standard. It affects only the historical release notes for security fixes and doesn't require any changes to the 2.50.0 series, which was already correct. The change helps maintain consistency across the project's documentation.
