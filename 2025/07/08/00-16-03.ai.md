This is a CI/build system patch in Patrick Steinhardt's Meson build system improvement series. The patch attempts to simplify test parallelization in CI by using Meson 1.8's new `--slice` option, but Junio Hamano reports a test failure showing the implementation isn't working as expected.

The patch replaces complex PowerShell test-splitting logic in both GitHub Actions and GitLab CI configurations with Meson-native slicing. However, the CI run shows the `--slice` argument is being rejected with "SLICE is not a positive integer", suggesting either a syntax issue in the matrix job variable substitution or an unexpected behavior in Meson's implementation.

The changes affect `.github/workflows/main.yml` and `.gitlab-ci.yml`, attempting to replace the existing PowerShell-based test distribution with direct Meson slicing. The failure indicates this final patch in the series needs revision before it can be merged, despite the clean approach of using native Meson functionality that Patrick had previously upstreamed to Meson itself.

This follows the series' theme of modernizing Git's Meson build infrastructure, but stands out as the only patch where immediate technical issues have surfaced during implementation. The problem appears specific to how CI matrix variables interact with Meson's argument parsing rather than a fundamental flaw in the approach.
