This is a documentation patch that has been reviewed and accepted by the maintainer. It corrects an inaccuracy in the gitglossary(7) documentation regarding glob pathspec behavior.

The patch removes an incorrect claim that "**/foo" is equivalent to "foo" in pathspec matching. While these patterns behave the same in gitignore contexts, they differ in pathspecs - "**/foo" matches at any directory level while plain "foo" only matches at the top level. The change is minimal (just removing the misleading equivalence statement) but important for accurate documentation.
