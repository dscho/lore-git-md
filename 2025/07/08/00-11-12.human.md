This is a monthly "What's cooking" status report from Junio C Hamano, summarizing the current state of Git development. These reports provide a high-level overview of patches moving through the integration branches (master, next, seen) and highlight topics that may need attention.

The report covers several graduated topics that have been merged to master, including:
- Resurrected `git imap-send` with OAuth2 support and various fixes
- CI updates for FreeBSD 14.3
- Daemon fixes for signal handling and fd checks
- Submodule remote lookup improvements
- Various leak fixes and documentation updates

New topics being cooked include:
- Making reftable the default ref backend in Git 3.0 (a significant change)
- BSD sysctl fixes for RAM detection
- Improved error reporting for index lock conflicts
- Detection of overlapping remote names
- Meson build system cleanups
- Intent-to-add fixes for `git apply`

Several ongoing efforts are noted as needing rerolls or facing questions, including:
- SHA-256 as default hash transition
- New `git last-modified` command
- SIGCHLD handling in git-daemon
- Sparse checkout variable cleanup
- Reftable unit test migration

The report also lists some discarded topics that were either superseded or deemed problematic. Overall, it shows active development across many areas of Git, with particular focus on the reftable backend transition, performance optimizations, and continued removal of `the_repository` global variable usage.
