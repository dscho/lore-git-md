This thread tracks the progress of various topics being prepared for Git 3.0, as reported by Junio Hamano. The major infrastructure changes - including making reftable the default ref backend (Patrick Steinhardt), enabling SHA-256 by default (brian m. carlson), and Taylor Blau's cruft pack optimizations - have all received positive reviews and are moving forward. Blau's series in particular has been successfully used in production at GitHub and received final approval from Elijah Newren.

However, Carlo Marcelo Arenas Belón's series to improve SIGCHLD handling in `git daemon` remains stalled due to Windows compatibility concerns. The latest discussion reveals platform-specific issues with signal handling in MinGW, where SIGCHLD has a different numeric value (17) compared to Cygwin/macOS (20). Carlo proposes standardizing on value 20, but Johannes Sixt notes this may not address the deeper limitations of signal handling on Windows outside Cygwin. This fundamental platform incompatibility appears to be the main blocker preventing the series from progressing at this time.
