This thread tracks the major infrastructure changes being prepared for Git 3.0, as outlined in Junio Hamano's "What's cooking" report. The focus is on several key performance and modernization efforts, with Taylor Blau's cruft pack optimization series being one of the most significant.

Taylor's 9-patch series improves how pack-objects and MIDX files handle cruft packs, introducing new features like `--stdin-packs=follow` and name-hash traversal for unpacked objects. After thorough review by both Elijah Newren and Jeff King, and successful production testing at GitHub for 1-2 months, Elijah has now confirmed the series is ready to merge to 'next'. This represents the final step before potential inclusion in Git 3.0.

The thread also tracks other major changes: Patrick Steinhardt's work to make reftable the default ref backend, brian m. carlson's SHA-256 default series (now review-complete), and Karthik Nayak's batched reference updates. These infrastructure changes are progressing well, with Taylor's cruft pack optimizations being the latest to receive final approval. The production validation at GitHub and positive reviews from key contributors suggest this is a stable, well-vetted improvement that should benefit repositories using cruft packs.
