This is a security-focused maintenance release announcement covering multiple Git versions (v2.43.7 through v2.50.1) addressing seven CVEs. The fixes primarily target vulnerabilities in Gitk, Git GUI, and core Git functionality across various platforms.

The security issues range from path injection attacks (CVE-2025-27614, CVE-2025-46334) to buffer overflows (CVE-2025-48386) and protocol injection vulnerabilities (CVE-2025-48385). Several CVEs involve malicious repositories being able to execute arbitrary code or overwrite files (CVE-2025-27613, CVE-2025-46835). The bundle-uri feature had a parameter injection flaw that could lead to arbitrary file writes. Windows-specific issues include the wincred credential helper's buffer overflow and Git GUI's unsafe path handling.

The fixes involve extensive sanitization of command arguments in Gitk and Git GUI, proper path handling on Windows-specific code paths, and quoting of values containing CR characters in config files. The changes span 52 commits from multiple contributors, with Johannes Sixt and Mark Levedahl contributing the bulk of the Git GUI/Gitk fixes, Taylor Blau handling the wincred buffer overflow, and Patrick Steinhardt addressing the bundle-uri vulnerability.

This coordinated release affects all supported versions back to v2.43, indicating the severity of the vulnerabilities. The fixes are primarily focused on hardening against malicious repository contents and improving argument sanitization, particularly around shell command execution and file path handling.
