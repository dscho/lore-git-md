Test fix addressing TAP format violations in t1006-cat-file.sh when run under Meson. The issue stems from a `grep` command outside a test case that was added in commit 9fd38038b9c to determine test expectations for object specifiers with spaces. The grep outputs matching lines directly to stdout, violating TAP format requirements and causing Meson to emit warnings despite the tests passing.

The fix adds the `-q` flag to suppress grep's output while maintaining its exit status functionality. This preserves the test's logic (marking tests with spaces in object names as expected failures) while making the output TAP-compliant. The change is minimal (one character added) and clearly motivated by the observable build system behavior. The patch appears straightforward and well-justified, addressing a real annoyance in the test suite's output without introducing new complexity.
