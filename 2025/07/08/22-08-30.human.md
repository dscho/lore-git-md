This is a test infrastructure patch that's part of the coordinated security release effort. It addresses a compatibility issue that arose when backporting security fixes to older Git versions (2.43 through 2.45).

The patch reverts some test scripts to use older `git config` syntax (with `--get`/`--unset` flags) instead of newer subcommand-style invocations (`get`/`set`/`unset`), since the subcommands weren't available in Git 2.43. This ensures the security release's test suite can run properly across all maintained versions.

Junio Hamano (the Git maintainer) has reviewed and accepted the change, noting it merges cleanly with the affected versions. The patch itself is small (4 lines changed) and narrowly focused on maintaining test coverage for the security fixes without modifying the security fixes themselves. This is supporting infrastructure work for the broader security release rather than a security fix per se.
