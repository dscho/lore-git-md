Security release for Git for Windows addressing multiple CVEs. This is a critical security update for Windows users, fixing vulnerabilities across several components including Git, Gitk, and Git GUI.

The release addresses nine CVEs, with several being particularly severe. CVE-2025-27613 and CVE-2025-27614 in Gitk allow arbitrary file creation/truncation and script execution when cloning untrusted repositories. CVE-2025-46334 and CVE-2025-46835 in Git GUI enable execution of malicious programs from the worktree and arbitrary file overwrites. Three core Git vulnerabilities (CVE-2025-48384 through CVE-2025-48386) cover config file CRLF handling issues, bundle protocol validation flaws, and a wincred credential helper buffer overflow.

The release includes Git v2.50.1 and provides installers for 64-bit, ARM64, and (as a courtesy) 32-bit systems, along with portable and MinGit variants. SHA-256 checksums are provided for all download packages. This is a must-install update for Windows Git users due to the severity of the fixed vulnerabilities, particularly those enabling remote code execution.
