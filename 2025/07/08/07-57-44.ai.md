This is a build system improvement patch in Patrick Steinhardt's Meson cleanup series (patch 3/8). It enhances the feature summary output in the Meson build system to show version numbers for detected dependencies and adds colorized boolean indicators.

The change modifies meson.build to pass dependency objects directly to the summary() function rather than just their .found() status. This allows Meson to automatically include version information when available (e.g., showing "YES 8.14.1" for curl instead of just "true"). It also enables bool_yn formatting which colorizes the YES/NO indicators and standardizes their presentation.

Key technical details:
- Changes affect the feature summary section starting at line 2193 in meson.build
- Switches from .found() checks to direct dependency objects for curl, expat, gettext, iconv, and pcre2
- Adds bool_yn: true parameter to enable colored YES/NO output
- Maintains existing behavior for non-dependency features (benchmarks, gitweb, perl, python)
- Output now shows version numbers where available while keeping the same basic structure

This is a straightforward quality-of-life improvement that makes the build summary more informative without changing any actual build behavior. It fits cleanly into the larger series of Meson build system improvements that have already been technically vetted.
