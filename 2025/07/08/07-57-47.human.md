This is a bugfix patch in Patrick Steinhardt's Meson build system series, addressing a regression in how Git's exec-path is configured when libexecdir is overridden. 

The patch fixes an issue where Git couldn't find its core commands (like `git daemon`) when installed with a custom libexecdir path. While a previous commit correctly propagated the custom path, it missed appending the required 'git-core' subpath, causing Git to look in the wrong location for its binaries.

The fix is straightforward - it ensures 'git-core' is always appended to the libexecdir path. The commit includes before/after examples showing the broken and fixed behavior, with clear test commands demonstrating the problem and solution. The issue was reported by another contributor (irecca.kun@gmail.com) who also provided the initial fix approach.

This is the 6th patch in an 8-part series that's already been through review and is considered ready for merging. The change is small (just one line modified in meson.build) but important for correct installation behavior when using custom paths. The series as a whole improves the Meson build system's reliability across different configurations.
