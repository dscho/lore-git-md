This is a CI/build system patch that follows up on the discussion about test parallelization in Patrick Steinhardt's Meson build series. Jeff King provides two solutions to fix the issue where Meson was rejecting the `--slice` argument due to GitHub Actions' 0-based matrix numbering conflicting with Meson's 1-based requirement.

The first solution simply renumbers the matrix from [0..9] to [1..10], which would work but changes job titles. The second, more elegant solution keeps the original numbering but uses PowerShell arithmetic to add 1 to the matrix number in the test invocation. Jeff notes this requires quoting the entire expression to avoid argument splitting, an unexpected behavior for shell users.

This email advances the thread by providing concrete fixes for the CI parallelization issue while maintaining the original 10-way test splitting. The solution preserves the benefits of parallel testing while working around Meson's index requirements.
