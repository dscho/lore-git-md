Documentation update for the new `sparse-checkout clean` feature. This is the third patch in a series introducing a command to clean up sparse directories that cause unnecessary index expansions.

The patch updates the advice message shown when Git has to expand a sparse index to a full one. The message now suggests using the new `git sparse-checkout clean` command (introduced in earlier patches) rather than the more general `git clean`, since the new command is specifically designed to handle sparse directory cleanup while preserving important files.

The change is straightforward - just a one-line modification to the advice text in `sparse-index.c`. This helps users encountering sparse index expansion issues to discover the new specialized tool for solving their problem. The patch maintains consistency with the series' goal of improving the sparse-checkout experience.
