This security release thread covers coordinated fixes for seven CVEs affecting Git versions 2.43.7 through 2.50.1, with vulnerabilities in Gitk, Git GUI, and core Git functionality that could lead to arbitrary code execution and file manipulation. Johannes Sixt and Mark Levedahl led the fixes for Gitk/Git GUI, while Justin Tobler and Patrick Steinhardt addressed core Git issues.

During testing, Todd Zullinger identified a backward compatibility issue where tests using newer `git config` subcommands (introduced in 2.46) were failing on older versions (2.43-2.45). He has now submitted a follow-up patch that modifies the affected tests to use the older `--get`/`--unset` flag syntax instead, ensuring the test suite remains runnable across all maintained versions. The changes are minimal (4 lines total) and specifically target the test infrastructure without altering the security fixes themselves. CI testing is underway to verify the patch works as expected.

The security fixes remain the primary focus, with critical vulnerabilities addressed across multiple components. This test compatibility patch is a secondary but important follow-up to ensure smooth backporting of the security updates to older Git versions.
