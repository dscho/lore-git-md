This security release thread covers coordinated fixes for seven CVEs affecting Git versions v2.43.7 through v2.50.1, with Johannes Sixt and Mark Levedahl leading the Gitk/Git GUI patches while Justin Tobler and Patrick Steinhardt addressed core Git vulnerabilities. The fixes demonstrate thorough attention to argument sanitization and path handling, particularly critical for Windows users.

The discussion has now shifted to test infrastructure compatibility for backporting these security fixes to older versions (2.43-2.45). Todd Zullinger has modified tests to use backward-compatible `--get/--unset` flags instead of newer subcommands, with Justin Tobler reviewing the changes. During CI runs, Todd observed several unrelated test issues in these older branches - including submodule checkout core dumps and compiler warnings - but the consensus is these pre-existing issues don't require fixing for this security backport. The team is maintaining focus on ensuring the security patches can be properly tested across all maintained versions while keeping the changes minimal (just 4 lines for test compatibility). Junio Hamano has already reviewed and queued the compatibility patch.
