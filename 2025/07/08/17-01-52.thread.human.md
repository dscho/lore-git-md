This security release thread covers coordinated fixes for seven CVEs affecting Git versions v2.43.7 through v2.50.1, with vulnerabilities ranging from Gitk/Git GUI exploits to core Git protocol and configuration issues. Johannes Sixt and Mark Levedahl led the Windows-specific fixes, while Justin Tobler and Patrick Steinhardt addressed core functionality problems.

The latest update focuses on test infrastructure adjustments needed for backporting these security fixes to older versions. Todd Zullinger identified that some tests for the CRLF handling fix (CVE-2025-48384) used newer `git config` subcommand syntax that wasn't available in Git 2.43-2.45. His patch switches these tests to use the older `--get`/`--set` flags instead - a minimal 4-line change that maintains test coverage while ensuring compatibility across all maintained versions. Junio Hamano has reviewed and queued this test adjustment, confirming it merges cleanly.

While this test change doesn't affect the security fixes themselves, it's an important piece of the coordinated release effort, ensuring the fixes can be properly validated across all affected versions before being shipped to users. The thread demonstrates the project's thorough approach to security issues, addressing both the vulnerabilities themselves and the infrastructure needed to verify them across Git's extensive version support window.
