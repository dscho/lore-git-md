This thread coordinates a security release addressing seven CVEs across Git versions v2.43.7 through v2.50.1. The vulnerabilities affect Gitk (file creation/truncation and command execution risks), Git GUI on Windows (malicious executables and file overwrites), and core Git (CRLF handling, bundle URI validation, and a wincred buffer overflow). Johannes Sixt and Mark Levedahl led the Gitk/Git GUI fixes, while Justin Tobler and Patrick Steinhardt handled core Git issues.

A follow-up discussion focused on test infrastructure updates needed when backporting these fixes to older versions (v2.43-v2.45). Todd Zullinger identified and fixed compatibility issues by modifying tests to use older `git config` syntax (`--get`/`--unset` flags) instead of newer subcommands. Justin Tobler confirmed the changes maintain test coverage while working across all versions. The minimal 4-line changes have been verified through CI testing and clean merges to affected versions.

The security fixes demonstrate comprehensive improvements to argument sanitization and path handling, with particular importance for Windows and Gitk/Git GUI users. The test compatibility work ensures the security release framework remains functional during backporting without altering the security fixes themselves.
