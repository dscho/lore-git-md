This is a coordinated security release addressing seven critical vulnerabilities across Git versions 2.43.7 through 2.50.1. The fixes target multiple components including Gitk, Git GUI, and core Git functionality, with potential impacts ranging from arbitrary code execution to file manipulation and protocol injection attacks.

The most severe issues affect Windows users and those using Gitk/Git GUI, where specially crafted repositories could trigger file creation/truncation or command execution. Johannes Sixt and Mark Levedahl contributed the bulk of the fixes (40 commits combined), focusing on argument sanitization and Windows-specific path handling. Other notable contributions include Justin Tobler's work on config CRLF handling and Patrick Steinhardt's bundle-URI validation improvements.

The release covers vulnerabilities in multiple areas: Gitk (CVE-2025-27613/27614), Git GUI (CVE-2025-46334/46835), and core Git functionality including config/submodule handling (CVE-2025-48384), bundle URI validation (CVE-2025-48385), and a wincred buffer overflow (CVE-2025-48386). The coordinated nature of this release across multiple maintenance tracks underscores the broad impact of these security issues. All users should upgrade immediately, particularly those on Windows or using graphical Git interfaces.
