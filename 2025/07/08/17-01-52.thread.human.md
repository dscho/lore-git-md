This security release thread covers critical fixes for Git versions 2.43.7 through 2.50.1 addressing seven CVEs across Gitk, Git GUI, and core Git functionality. The vulnerabilities include serious issues like arbitrary code execution and file manipulation, with Johannes Sixt and Mark Levedahl leading the fixes for the GUI components while Justin Tobler and Patrick Steinhardt addressed core protocol and config handling.

A follow-up from Todd Zullinger reports test failures when building the security fixes for v2.45.4 on older systems, where newer config syntax in the test suite (`git config set/get/unset`) isn't backward compatible. He provides a straightforward fix using the older syntax forms (`--get` and `--unset`). While not a security issue itself, this test compatibility problem could affect maintainers backporting these security updates to older versions where the test infrastructure may need similar adjustments. The core security fixes remain unaffected.
