This is a follow-up discussion on Patrick Steinhardt's Meson build system series, specifically addressing patch 1/8 about Python version detection. Justin Tobler confirms the technical approach of checking for the target host's Python rather than the build host's, which was the original incorrect behavior. The patch removes the native Python check entirely since it's not needed for the build process itself.

The key change replaces `python.find_installation()` with `find_program()` for the target Python check, updating all related conditionals to use `target_python.found()`. Justin notes this correctly handles the git-p4 wiring decision based on the target environment rather than the build environment. While approving the change, Justin suggests adding a clarifying comment about why we check for target Python rather than build Python.

The discussion confirms this part of the larger Meson modernization effort, which has already addressed cross-compilation scenarios and other build system improvements. This particular fix aligns with the series' goal of proper cross-platform compatibility and build system correctness.
