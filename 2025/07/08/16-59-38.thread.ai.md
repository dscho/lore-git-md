Security maintenance release covering Git versions v2.43.7 through v2.50.1 addressing seven CVEs (CVE-2025-27614, CVE-2025-46334, CVE-2025-48386, CVE-2025-48385, CVE-2025-27613, CVE-2025-46835). Vulnerabilities span path injection attacks, buffer overflows, and protocol injection flaws in Gitk, Git GUI, and core Git functionality across platforms. Malicious repositories could trigger arbitrary code execution or file overwrites. Fixes include: argument sanitization in Gitk/Git GUI (Johannes Sixt, Mark Levedahl), Windows path handling improvements, wincred buffer overflow fix (Taylor Blau), bundle-uri parameter injection protection (Patrick Steinhardt), and config file quoting for CR characters. Changes comprise 52 commits with focus on hardening against malicious repository contents, particularly around shell command execution and file path handling. Affects all supported versions back to v2.43 due to severity.
