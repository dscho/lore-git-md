Bug report for Git for Windows regarding file permission issues. James Gao reports that Git 2.50.1 on Windows 11 Pro (10.0.22631) is unable to perform basic operations like `git init`, `git pull`, or `git add` due to permission errors. The errors suggest Git cannot write to the repository directory (`.git/objects`) or index files, even when running as Administrator. The reporter has tried various troubleshooting steps without success and is considering downgrading.

Key technical details: The errors specifically mention failure to write to object database (36/dd1796...) and index files, with "Permission denied" messages. The issue persists across multiple operations (init, pull, add) and affects both repository metadata and working tree files. The problem occurs on a fresh Windows 11 Pro system with the latest Git for Windows x64 build. No workarounds are currently known to the reporter. This appears to be a potentially serious regression in the Windows port's file permission handling.
