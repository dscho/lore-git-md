Junio Hamano agrees with Jeff King's proposal to remove the `--early-output` feature from Git's revision machinery. This is a clean-up patch removing an undocumented and apparently unused feature that was originally added in 2007 for GUI tools like gitk, but never saw adoption. 

Hamano confirms his memory of the original gitk RFC patch that never got merged, and concurs with King's assessment that the feature can be removed outright rather than keeping it as a no-op. The decision is based on the strong evidence that nobody is using this feature - it has been broken multiple times over the years without any reports, most recently with the introduction of commit-graphs.

The maintainer notes that while a "softer" removal (keeping the option but making it a no-op) was considered, the complete removal is justified given the feature's unused state. Hamano states he will queue the patch, indicating it's likely to be accepted into the codebase. This change simplifies the revision code with no expected impact on users.
