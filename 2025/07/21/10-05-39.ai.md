This is a v2 of a feature patch adding IMAP folder archiving to `git send-email`. The patch addresses email providers (like iCloud Mail) that don't save SMTP-sent messages to Sent folders by introducing a new `sendemail.imapfolder` config option and `--imap-folder` command-line flag. When set, successfully sent messages are piped to `git imap-send` for storage in the specified IMAP folder.

Key technical changes in this version:
- Fixes indentation in the `imap-send.c` modifications
- Makes minor wording improvements to the commit message
- Maintains all core functionality from v1:
  - Perl-side collection of sent messages including Bcc headers
  - Special handling in `imap-send.c` for "From git-send-email" prefixed messages
  - Documentation of the new option and required IMAP setup

The implementation appears solid, with clear handling of the Bcc field preservation requirement and proper error handling for IMAP connections. The feature remains opt-in and backward compatible. The changes are focused and well-contained to the email-sending workflow without introducing broader architectural impacts.

For future thread reference: this touches `git-send-email.perl`'s message handling, adds IMAP-specific header processing in `imap-send.c`, and documents the new option in both config and command help. The v2 changes are purely cosmetic - no functional differences from the initial proposal.
