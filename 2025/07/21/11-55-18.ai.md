Test modernization patch implementing automated help output verification for commands outside a repository. This is part 1 of a 2-patch series implementing Junio Hamano's proposed test organization strategy.

The patch replaces manual `-h` flag tests in t1517-outside-repo.sh with an automated loop that tests all main commands (from `git --list-cmds=main`) for proper help output when run outside a repository. It maintains the existing verification pattern of checking exit code 129 and usage message format via `test_grep`.

Key technical aspects:
- Uses a case statement to handle known exceptions (like `archimport`, `cvsexportcommit` etc.) that don't follow standard help patterns
- Strips file extensions from command names (like `.sh`, `.perl`) before testing
- Keeps the `nongit` helper for consistent outside-repo context
- Adds a temporary `echo "Hello"` that appears to be debugging output (likely to be removed)

The implementation follows the thread's direction of making t1517 strictly about outside-repo behavior while using tooling (`--list-cmds`) to ensure comprehensive coverage. The patch demonstrates good attention to edge cases with the exception list, though the debugging echo suggests it may need minor cleanup before final merging.
