This is a feature patch adding IMAP folder archiving to `git send-email`, addressing a limitation where some email providers (notably iCloud Mail) don't save SMTP-sent messages to Sent folders. It's version 2 of the patch, with minor fixes to indentation and commit message wording from the initial submission.

The patch introduces a new `sendemail.imapfolder` config option and `--imap-folder` command-line flag. When set, successfully sent messages are piped to `git imap-send` for storage in the specified IMAP folder. The implementation handles edge cases like preserving Bcc headers (which SMTP normally strips) and includes thorough documentation explaining the setup requirements.

The changes span both Perl and C code:
- `git-send-email.perl` collects messages during SMTP sending and batches them for IMAP
- `imap-send.c` adds special handling for messages prefixed with "From git-send-email" to properly parse headers
- Documentation updates explain the new workflow and credential setup

The patch appears well-considered with clear documentation and edge case handling. It maintains backward compatibility when not configured, making it a non-disruptive addition. The feature fills a real need for users of providers like iCloud Mail while leveraging existing Git infrastructure (`imap-send`).
