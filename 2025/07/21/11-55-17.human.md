This is a test refactoring patch series that continues the ongoing discussion about organizing help command tests. Usman Akinyemi proposes changes to better structure the t1517 test file, which recently became the home for testing `-h` help output behavior.

The series does two main things: First, it moves the `update-server-info -h` test to t5200 where it logically belongs with other tests for that command (since it tests behavior inside a repository). Second, it introduces an automated loop in t1517 that tests `-h` output for all main Git commands when run outside a repository, using the `nongit` helper and `git --list-cmds=main`.

This version (v4) simplifies the approach by focusing t1517 exclusively on outside-repo behavior, dropping earlier plans to also test inside-repo cases. The changes make the test file's purpose clearer while ensuring new commands automatically get basic help testing coverage. The implementation looks clean and aligns well with the ongoing discussion about test organization principles.
