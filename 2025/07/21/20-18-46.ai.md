This is the final patch in a 5-part series extending the promisor-remote protocol to support configurable validation of remote attributes. The patch focuses purely on code hygiene by introducing string constants for the mandatory "name" and "url" fields, matching the approach already taken for the optional fields ("partialCloneFilter" and "token") in previous patches.

This completes the standardization of field name handling across all field types in the promisor-remote protocol implementation.
