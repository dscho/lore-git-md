This is a refactoring patch in the blame subsystem that removes dead code, with consensus already established in the thread.

The patch eliminates an unused `detailed` parameter from `get_commit_info()` in `builtin/blame.c` that was meant to enable early termination of commit parsing. Historical analysis by Patrick Steinhardt shows this parameter was never actually used - all callers have always passed `1` since the function's introduction in 2006. Performance testing mentioned in the original patch showed any potential optimization from this feature would be negligible at best.

Junio Hamano confirms the change is a clear simplification, noting the removal of unused code is always welcome. The thread shows unanimous agreement that this is a straightforward cleanup with no behavior change, just the elimination of dead code paths. With no outstanding objections or discussion points, this appears ready for inclusion as a low-risk refactoring of the blame machinery.
