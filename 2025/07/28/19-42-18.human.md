This is a documentation patch removing the experimental status markers from `git-switch` and `git-restore`. It's part of a 2-patch series that has been under review, with this being the uncontested documentation portion.

The patch simply removes the "THIS COMMAND IS EXPERIMENTAL" warnings from both man pages, acknowledging that after six years of stable use (since their introduction in 2019), these commands have effectively stabilized through real-world usage. The change reflects that breaking changes are no longer feasible since users now rely on the current behavior.

The thread has seen consensus on this documentation update, with Junio Hamano approving the removal while framing it as acknowledging a "failed experiment" in UI improvements rather than celebrating stability. Justin Tobler has accepted some wording refinements suggested during review.

While this patch is straightforward and ready to proceed, the companion patch about interface changes (particularly around the `-m` flag) remains unresolved. This documentation change can move forward independently while those design discussions continue separately.
