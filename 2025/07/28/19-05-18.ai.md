This is a performance optimization patch series targeting xdiff's string hashing mechanism, building on prior work by Phillip Wood. The series consists of two patches: a refactoring patch from Phillip Wood (presumably already reviewed) and Alexander Monakov's optimization that claims a 1.5x speedup for xdl_hash_record_verbatim.

The key technical details are that the optimization avoids introducing xxhash as a dependency while matching its performance, using instead an optimized implementation of the additive djb2 hash variant (similar to what's used in ELF symbol lookup and contributed to Glibc by Noah Goldstein). The changes touch xdiff/xutils.{c,h} with significant modifications (66 lines changed across both files).

The optimization appears well-motivated by prior performance work in the area, and builds on established refactoring work. The commit message references relevant prior art (Glibc implementation) which lends credibility to the approach. The patch seems likely to be uncontroversial as it maintains the same hash quality while improving speed, though reviewers may want to verify the performance claims and check for any platform-specific impacts.
