This is a clarification in the ongoing thread about `git status` output for intent-to-add files. D. Ben Knoble follows up on Junio Hamano's explanation that the current behavior already distinguishes intent-to-add files, albeit not exactly as described in an old TODO item from 2011.

The key points are:
1. The thread originally questioned why the TODO item's suggested output format ("I" instead of "A" in short status) wasn't implemented.
2. Junio clarified that while the exact wording from the TODO isn't used, modern Git versions (2.48.1 and 2.50.0.rc0) do show the distinction through different means: section separation in long format and position differences in short status.
3. Knoble confirms this observation but notes the output isn't as explicit as the TODO item suggested it could be.

This email effectively closes the technical question about whether the TODO item was implemented, while leaving open the design question of whether the current output could be made more explicit. The thread continues with Eric Frederickson working on related documentation and test improvements, but this particular sub-thread appears resolved with Junio's authoritative explanation of the current behavior.
