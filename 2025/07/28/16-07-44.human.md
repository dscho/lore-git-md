This is a performance optimization patch in the refs subsystem, specifically part of a series to improve remote ref renaming efficiency. The patch standardizes the reflog callback interface by adding a `refname` parameter, eliminating the need for callers to pass the refname through callback data.

The changes show how this cleanup allows removing awkward workarounds where callers like `fsck_handle_reflog()` and `read_ref_at_ent()` previously had to pass the refname through callback data structures. The new approach makes the code more straightforward by having the refname passed directly to the callback function.

The change is part of a larger performance optimization effort that has already shown dramatic improvements (reducing some operations from hours to seconds for large repositories).
