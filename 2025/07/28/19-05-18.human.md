This is a performance optimization patch series for xdiff string hashing, building on prior work by Phillip Wood. The series consists of two patches: a refactoring from Phillip Wood to prepare the code, followed by Alexander Monakov's optimization that speeds up the existing hash function by 1.5x.

The key claim is that Monakov's approach matches the performance of xxhash (a popular high-speed hash algorithm) without introducing any new dependencies. The optimization is based on a well-tuned implementation of the djb2 hash variant used in ELF symbol lookup, originally contributed to Glibc by Noah Goldstein.

The changes are focused in xdiff/xutils.c and h}, modifying the core hashing functions used during diff calculations. The first patch refactors the existing code to make it more amenable to optimization, while the second introduces the actual performance improvement. The series appears to be a focused, technically sound contribution from someone familiar with low-level optimization techniques.
