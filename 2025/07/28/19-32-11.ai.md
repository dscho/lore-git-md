Second, and more critically, Hamano raises a licensing concern about borrowing Noah Goldstein's optimized djb2 implementation from Glibc, noting that recent GNU code is likely GPLv3 which would be incompatible with Git's GPLv2 license. This could block adoption of the proposed optimization unless the code can be reimplemented or proven to be license-compatible.

The response endorses Monakov's approach of building on Phillip Wood's refactoring work, maintaining the series' technical credibility while flagging a potential legal hurdle that will need resolution before proceeding. The thread now awaits clarification on the Glibc code's licensing status and possibly alternative implementation strategies that avoid license incompatibility.
