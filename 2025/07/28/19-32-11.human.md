This is a performance optimization discussion in the ongoing xdiff string hashing thread. Junio C Hamano responds to Alexander Monakov's proposal to speed up Git's diff hashing by 1.5x using an optimized djb2 variant similar to what's used in Glibc's ELF symbol lookup.

The key concern raised is about licensing compatibility - Junio notes that recent GNU code is typically GPLv3, which would be incompatible with Git's GPLv2 license. This could block adoption of the proposed optimization if it borrows from GPLv3-licensed implementations. The email also clarifies that xxhash was only used as a demonstration in prior work, not as a serious proposal.

Junio approves of the general approach of building on Phillip Wood's refactoring work, but the licensing question needs resolution before the technical merits can be properly evaluated. The thread shows the careful balance required when considering performance optimizations that might borrow from other projects' implementations.
