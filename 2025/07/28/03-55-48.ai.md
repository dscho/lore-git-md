Refactoring patch targeting the blame subsystem. This change simplifies the `get_commit_info()` function in `builtin/blame.c` by removing an unused `detailed` parameter that was meant to enable early termination of commit parsing. The author notes that performance testing showed negligible benefit from this early termination feature, and all existing callers were passing `1` (true) for this parameter anyway. The patch removes the parameter and its associated conditional logic while maintaining identical functionality since all callers were effectively using the "detailed" path. The change touches four call sites that are updated to omit the now-removed parameter. This appears to be a straightforward cleanup of dead code with no expected behavior change.
