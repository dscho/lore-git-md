Performance test addition for the `git last-modified` command series.

This patch adds a performance test script for the new `git last-modified` command, which tracks tree-level path modifications. The test measures three scenarios: basic top-level checks, recursive checks, and subdirectory-specific checks. The subdirectory test uses `git ls-tree -d` to select a real subdirectory path from the repository.

The tests are designed to catch performance regressions between versions, complementing the existing correctness tests in the main test suite. The implementation follows the pattern of other performance tests in Git's test suite and is integrated into the meson build system.

This is part of the ongoing `last-modified` command series (v6 2/4) that introduces Bloom filter optimizations for tracking file modifications at the tree level rather than line-by-line like `git blame`. The performance characteristics mentioned in the thread summary (55% speedup for top-level checks, 44% slowdown in recursive checks) likely come from running these tests.
