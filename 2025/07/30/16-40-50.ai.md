This is a platform compatibility patch removing macOS-specific components from git-gui. It's part of a series modernizing git-gui's macOS support, now expanded to 7 patches (originally 5). This specific change (patch 3/5 in the original numbering) removes the deprecated "Git Gui.app" bundle that relied on macOS's system Tcl/Tk 8.5 framework, which became incompatible when Git raised its minimum Tcl/Tk version to 8.6.

The patch deletes 234 lines across 9 files, including:
- The macOS app generator scripts (generate-macos-app.sh and generate-macos-wrapper.sh)
- macOS-specific resource files (AppMain.tcl, Info.plist, git-gui.icns)
- Related build system logic in both Makefile and meson.build
- The change removes all macOS-specific app bundle generation while maintaining support for using third-party Tcl/Tk installations
- Build system changes affect both Makefile and meson.build configurations
- The removal is clean with no transitional code left behind

Key technical impacts:
- TKEXECUTABLE build option is removed from GIT-GUI-BUILD-OPTIONS
- All macOS-specific installation targets and variables (INSTALL_A0/1, GITGUI_MACOSXAPP) are eliminated
- The change follows the series' pattern of removing obsolete components while maintaining core functionality
