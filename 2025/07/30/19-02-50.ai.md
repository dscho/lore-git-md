This is a build system fix in the git-gui modernization series, specifically focusing on making git-gui--askpass respect TCLTK_PATH consistently with git-gui. The patch converts git-gui--askpass into a script processed at build time, similar to how git-gui is handled.

The key changes include:
- Adding generate-script.sh helper to process both git-gui and git-gui--askpass consistently
- Updating Makefile and meson.build to handle the new build process
- Renaming git-gui--askpass to git-gui--askpass.sh as the source
- Adding proper build dependencies and clean targets

Johannes Sixt reports a build failure where GIT-GUI-BUILD-OPTIONS isn't found during the git-gui--askpass generation, suggesting a missing dependency in the Makefile. He also questions why git-gui--askpass appears twice in the Windows build targets but doesn't have expertise to assess the meson.build changes.

This patch is part of the broader effort to standardize Tcl/Tk path handling across git-gui components. The build issue noted will need to be addressed, likely by ensuring proper dependency ordering in the Makefile. The changes align with the series' goal of making git-gui's build system more robust and consistent across platforms.
