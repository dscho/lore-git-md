Thread identity: Platform compatibility patch series addressing macOS-specific issues with git-gui's Tcl/Tk dependencies, consisting of 5 patches to modernize git-gui's macOS support.

Core problem: The series removes deprecated components and improves compatibility with newer Tcl/Tk versions on macOS, specifically addressing the obsolete "Git Gui.app" bundle that relied on macOS's system Tcl/Tk 8.5 framework which is no longer maintained.

Current status: Initial version (v1) of the series, with clean separation of concerns across 5 patches: preparatory cleanups (1-2), main removal of deprecated components (3), and follow-up fixes (4-5).

Key technical details: Removes generate-macos-app.sh and related macOS-specific files (AppMain.tcl, Info.plist), introduces generate-script.sh as a unified script generator, modifies git-gui--askpass to honor TCLTK_PATH. Changes affect both Makefile and meson.build build configurations, removing ~250 lines of macOS-specific code while adding 22 lines for the new script generator.

Open questions: Potential impact on users still relying on the old macOS bundle needs evaluation. The changes affect build-time configuration and runtime behavior of git-gui on macOS, so testing on various macOS versions would be valuable.

Participant positions: Initial submission with no reviews yet. The series appears well-motivated given macOS's outdated Tcl/Tk situation, presenting a cleanup rather than new functionality.

Related work: Build system changes touch both traditional Makefile and newer meson.build configurations, suggesting coordination between build systems may be needed. The removal of deprecated components aligns with ongoing efforts to modernize platform support.
