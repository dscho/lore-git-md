Platform compatibility patch removing macOS-specific Git Gui.app support. This is patch 3/5 in a series modernizing git-gui's macOS support.

The patch removes the deprecated "Git Gui.app" bundle that relied on macOS's system Tcl/Tk 8.5 framework, which became incompatible when Git raised its minimum Tcl/Tk version to 8.6. The change deletes 234 lines across 9 files, including build scripts, app resources, and Makefile/meson.build rules for the macOS bundle.

The removal is straightforward - users will now use a third-party Tcl/Tk installation if needed. The patch appears well-scoped, focusing only on removing obsolete components without introducing new functionality. It's part of a larger effort to clean up platform-specific code in git-gui, with previous patches having prepared for this removal.

The change impacts macOS users who may have been relying on the bundled app, though the commit message suggests this was already problematic due to the Tcl/Tk version mismatch. The patch maintains Windows-specific handling while removing macOS-specific code.
