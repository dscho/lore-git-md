This is a feature patch adding SMTP autoconfiguration to `git send-email`. The patch introduces a new `--get-smtp-server` option that attempts to automatically discover SMTP settings for a given email address through three fallback methods: querying Mozilla's ISPDB, checking the email provider's autoconfig endpoint, and falling back to MX record lookup for custom domains.

The implementation adds significant new functionality to `git-send-email.perl` (157 lines) and corresponding documentation (55 lines). It introduces several new Perl module dependencies: Net::DNS for MX record lookups, URI::Escape for URL encoding, and XML::LibXML for parsing the autoconfig responses. The v2 revision improves email address checking compared to v1.

The patch models its behavior after Thunderbird's autoconfig system, providing a structured output showing server, port, encryption method, and username for each discovered configuration. These map directly to existing `sendemail.*` config options. The documentation includes a clear example showing how the output corresponds to configuration settings.

This appears to be a well-considered implementation of a feature that could simplify setup for users unfamiliar with SMTP configuration. The fallback chain and MX record handling should cover most common email providers and custom domains. The new dependencies may raise some discussion about whether they're too heavy for core Git, though all are available on CPAN.
