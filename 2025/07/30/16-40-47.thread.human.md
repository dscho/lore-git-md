This thread centers on modernizing git-gui's platform support, particularly for macOS, where the series has evolved into addressing fundamental questions about Tcl/Tk dependency management. The current v9 patchset tackles build system cleanup, macOS modernization, and askpass helper improvements, but faces critical architectural decisions.

Junio Hamano has now confirmed Carlo Arenas' earlier explanation that macOS's system-bundled Tcl/Tk 8.5 framework is problematic to upgrade, validating the core concern driving this effort. This leaves two viable paths: either work with the outdated system version as an immutable component (current approach) or follow Homebrew's lead by managing third-party Tcl/Tk installations. The discussion has narrowed to resolving this architectural question before finalizing implementation details.

Key implementation decisions still pending include choosing between exec-path and argv0-based approaches for the askpass helper (with Mark Levedahl's argv0 proposal gaining traction), completing Meson build integration, and standardizing error handling. Johannes Sixt maintains concerns about RUNTIME_PREFIX handling that need addressing. The series' original goals of fixing macOS's broken "Git Gui.app" bundle and improving Tcl/Tk path handling remain central, but the solution must now account for the confirmed constraints around system framework management.
