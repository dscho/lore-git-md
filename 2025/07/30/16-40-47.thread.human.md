This thread discusses a 5-part patch series modernizing git-gui's macOS support by addressing compatibility issues with Tcl/Tk dependencies. The core change removes the obsolete "Git Gui.app" bundle that relied on macOS's deprecated system Tcl/Tk 8.5 framework, which is no longer maintained. 

The series includes preparatory cleanups and follow-up fixes to ensure proper handling of git-gui--askpass when using third-party Tcl/Tk 8.6 installations. Key technical changes involve removing macOS-specific files like generate-macos-app.sh, AppMain.tcl and Info.plist, while introducing a unified script generator and modifying TCLTK_PATH handling. The changes affect both Makefile and meson.build configurations, removing about 250 lines of macOS-specific code while adding minimal new infrastructure.

The patches appear well-structured as a cleanup effort, though they may impact users still relying on the old macOS bundle. The changes span build systems and runtime behavior, focusing on removing deprecated components rather than adding new functionality.
