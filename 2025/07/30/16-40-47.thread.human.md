This thread focuses on modernizing git-gui's platform support, particularly around macOS compatibility and build system issues. The 9-patch series removes deprecated macOS components (including the old "Git Gui.app" bundle that relied on Tcl/Tk 8.5) while fixing cross-platform path handling and git exec-path propagation.

Johannes Sixt, the gitk and Git GUI maintainer, has raised important concerns about the current version. He identified inconsistencies in the justification for removing the macOS bundle and, more critically, found that the askpass resolution changes break RUNTIME_PREFIX builds. While he hasn't tested the Meson compatibility himself, his analysis suggests these are blocking issues that need addressing.

The series has already incorporated several rounds of feedback, expanding from its original scope to handle additional edge cases. Key remaining work includes resolving the RUNTIME_PREFIX regression, verifying Meson build compatibility, and ensuring consistent error handling. The author will likely need to send another revision addressing these points before the changes can proceed.
