This thread has evolved into a comprehensive modernization of git-gui's platform support, particularly focusing on macOS and build system integration. The discussion began with cleaning up macOS-specific issues but has grown into fundamental architectural decisions about dependency management and build infrastructure.

The key decision has been to treat Tcl/Tk as a managed third-party dependency rather than a system component, with macOS specifics now clearly addressed (Tcl/Tk 8.5 is deprecated and problematic, while Homebrew's model works well). The series has removed all bundle infrastructure and standardized Tcl/Tk path handling across git-gui components.

A recent bugfix patch finalized the askpass helper resolution strategy, implementing Mark Levedahl's suggestion to locate the helper by deriving the path from git-gui's own location rather than querying git's exec-path. This change (just 4 lines) ensures git-gui always uses its bundled helper, avoiding potential macOS system version conflicts. The patch complements earlier build system changes that generate the askpass script with proper TCLTK_PATH handling.

The work has progressed through two parallel patch series (v9 and v2), with v2 now implementing the consensus approach. Key participants include Junio Hamano (who confirmed the architectural shift), Carlo Arenas (providing critical macOS context), Johannes Sixt (raising RUNTIME_PREFIX concerns), and Mark Levedahl (proposing the winning askpass solution). While most technical issues are now resolved, some open questions remain about RUNTIME_PREFIX handling and full meson integration.
