This is a personal workflow fix from Patrick Steinhardt, unrelated to the ongoing reflog discussion. The email explains a frustrating issue where Patrick's messages were being truncated when sent through msmtp with a password manager integration.

The root cause was that rofi (a GUI password prompt tool) was reading from stdin when it shouldn't, interfering with msmtp's mail processing. The fix involves closing stdin (`exec 0<&-`) in the password evaluation script before invoking rofi. This ensures the mail content isn't consumed by the password prompt.

While not a Git patch, this provides useful context about Patrick's development environment and shows how contributors sometimes need to debug their own tooling issues to participate effectively in mailing list discussions. The fix is specific to Patrick's NixOS/home-manager setup with 1Password and rofi.
