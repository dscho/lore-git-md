This is a refactoring patch that exports the `prepare_commit_graph()` function from commit-graph.c to make it available to other parts of the codebase. The change is part of the ongoing `git last-modified` series (v6) which implements a tree-level path tracker with Bloom filter optimization.

The patch removes the `static` qualifier from `prepare_commit_graph()` and moves its documentation to the header file. This allows the function to be called externally, specifically to support Bloom filter usage before `prepare_revision_walk()` is called in the `last-modified` command implementation.

The change is straightforward - it simply exposes an existing internal function that was already well-documented and tested. This is a necessary plumbing change for the Bloom filter integration in the larger series, and follows typical Git development patterns for exposing core functionality when needed by new features.

The patch maintains all existing behavior while enabling the next step in the `last-modified` implementation. It's a small but important piece of infrastructure work that helps connect the commit-graph system with the new path-tracking functionality.
