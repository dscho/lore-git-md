Platform compatibility patch fixing git-gui--askpass behavior to match git-gui's Tcl/Tk path handling. This is part of the expanded 7-patch series modernizing git-gui's macOS support, though this particular change affects all platforms.

The patch corrects a long-standing inconsistency where git-gui--askpass (used for SSH password prompts) would call whatever `wish` interpreter was in the PATH, while git-gui itself properly respected the TCLTK_PATH setting. The solution converts git-gui--askpass into a build-time generated script, similar to how git-gui is handled.

Key technical changes:
- Adds a generate-script.sh helper to process the askpass script at build time
- Makes git-gui--askpass respect TCLTK_PATH by using the same substitution mechanism as git-gui
- Updates both Makefile and meson.build to handle the new build process
- Renames git-gui--askpass to git-gui--askpass.sh as its source file
- Adds proper clean rules and .gitignore entries

The change appears well-contained and properly integrated with both build systems. It maintains compatibility with the existing behavior while fixing the path inconsistency, which should help avoid potential issues when different Tcl/Tk versions are installed. The patch follows the pattern already established for git-gui's script generation.
