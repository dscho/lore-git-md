This is a platform compatibility patch in a series modernizing git-gui's macOS support. It fixes an inconsistency in how git-gui--askpass handles the Tcl/Tk interpreter path.

The patch makes git-gui--askpass respect TCLTK_PATH like git-gui does, rather than calling whatever `wish` interpreter is in the path. This is done by converting git-gui--askpass into a script processed at build time, similar to how git-gui itself is handled.

The changes include:
- Creating a new generate-script.sh helper
- Modifying both Makefile and meson.build to handle the new build process
- Renaming git-gui--askpass to git-gui--askpass.sh (while keeping the installed name the same)
- Updating clean targets and .gitignore

This appears to be a straightforward technical improvement that aligns git-gui--askpass's behavior with git-gui's, making the build more consistent. The patch is part of a larger series removing deprecated components, with this change likely serving as groundwork for those later removals.
