This is a build system fix for git-gui, part of a larger series modernizing macOS support. The patch corrects a missing dependency in the Makefile that was introduced when the git-gui script generation logic was moved to a separate script (generate-git-gui.sh) in March 2025. Without this change, modifications to the generator script wouldn't trigger a rebuild of the main git-gui script.

The change is straightforward - it adds `generate-git-gui.sh` as a dependency to the `$(GITGUI_MAIN)` target in the Makefile. This ensures the main script gets regenerated whenever the generator script changes.
