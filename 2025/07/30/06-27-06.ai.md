Feature patch adding JSON output format to `git status`. This introduces a new `--json` flag that provides machine-readable status information in a structured format, complementing the existing porcelain formats.

The implementation adds a new `STATUS_FORMAT_JSON` enum value and implements JSON output formatting in `wt-status.c`. The output includes branch information (current branch, detached state, ahead/behind counts), plus arrays for staged, unstaged, untracked, and (with `--ignored`) ignored files. The JSON structure is designed for easy parsing and future extensibility.

Key technical details:
- New helper functions `wt_json_print_string_array` and `wt_json_print_change_array` handle the JSON formatting
- Branch information includes detached state and tracking counts when available
- The output matches porcelain v2's classification of changes (WT_STATUS_UPDATED for staged, WT_STATUS_CHANGED for unstaged)
- The patch touches `builtin/commit.c` to expose the flag in both `git status` and `git commit`

This provides a more reliable alternative to parsing the human-readable or porcelain formats for tooling. The implementation appears thorough, with clear output structure that could be extended in future. The commit message explains the motivation well and includes an example output.
