This is a bugfix patch for git-gui, part of the ongoing platform support modernization series. It ensures git-gui consistently uses its own version of the askpass helper rather than potentially picking up a broken system version, particularly addressing macOS issues.

The patch modifies the build system and git-gui's startup code to properly propagate and use the git exec-path determined at build time. Key changes include:
- Adding GITGUI_GITEXECDIR substitution to generate-git-gui.sh
- Storing and normalizing the exec path during git-gui startup
- Using the stored path for SSH_ASKPASS rather than querying git at runtime
- Updating the about dialog to show the resolved exec path

The changes affect three files: the script generator, main git-gui.sh, and about dialog code. This appears to be a focused, well-motivated fix that follows the pattern established in earlier patches of the series for proper path handling. The commit message clearly explains the macOS-specific motivation while the changes themselves are platform-agnostic improvements.
