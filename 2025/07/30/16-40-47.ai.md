Platform compatibility patch series addressing macOS-specific issues with git-gui's Tcl/Tk dependencies. This 5-part series modernizes git-gui's macOS support by removing deprecated components and improving compatibility with newer Tcl/Tk versions.

The core changes focus on removing the obsolete "Git Gui.app" bundle (patch 3) which relied on macOS's system Tcl/Tk 8.5 framework that is no longer maintained. The series includes preparatory cleanups (patches 1-2) and follow-up fixes (patches 4-5) to ensure proper handling of git-gui--askpass when using third-party Tcl/Tk 8.6 installations.

Key technical details include: removal of generate-macos-app.sh and related macOS-specific files (AppMain.tcl, Info.plist), introduction of generate-script.sh as a unified script generator, and modifications to honor TCLTK_PATH in git-gui--askpass. The changes touch build systems (Makefile, meson.build) and remove about 250 lines of macOS-specific code while adding 22 lines for the new script generator.

The series appears well-motivated given macOS's outdated Tcl/Tk situation, with clean separation of concerns across patches. The removal of deprecated components suggests this is a cleanup rather than new functionality, though it may impact users still relying on the old macOS bundle. The changes span multiple build systems and affect both build-time configuration and runtime behavior of git-gui on macOS.
