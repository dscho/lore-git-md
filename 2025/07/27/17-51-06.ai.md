This is the initial patch in a series introducing a new `git repo` command hierarchy, specifically focusing on repository metadata retrieval. The patch establishes the basic command structure with an `info` subcommand, moving functionality that currently lives in `git rev-parse` to a more appropriate home.

The implementation creates all the necessary plumbing for a new Git command:
- Adds `builtin/repo.c` with basic subcommand handling
- Creates documentation stub in `Documentation/git-repo.adoc`
- Updates build systems (Makefile, meson) and command lists
- Marks the command as experimental in documentation

Key technical details:
- Initial subcommand `info` will handle repository metadata retrieval
- Currently just a skeleton - returns 0 without functionality
- Uses Git's standard subcommand parsing infrastructure
- Positioned as a plumbing command in `command-list.txt`

The patch is part of a larger effort to clean up `git rev-parse` by moving non-revision-parsing functionality to more appropriate commands. This initial version lays the groundwork for subsequent patches that will implement actual metadata retrieval capabilities. The implementation follows standard Git patterns for new subcommands and has received input from multiple contributors including the GSoC mentors.
