This is a review comment on the format flag implementation in the `git repo info` command series. Eric Sunshine provides feedback on two aspects of the patch:

More substantively, he questions whether the command should include a `-z` short option for the null format, following Git's convention where `-z` typically indicates null-terminated output in other commands.

Second, he proposes simplifying the test case by:
1. Using `printf` instead of `echo` and `lf_to_nul` for creating the expected output
2. Comparing the full output directly rather than using `tail -n 1` to extract part of it
3. Using `test_cmp_bin` for binary comparison of null-terminated output

The feedback focuses on making the implementation more robust and consistent with Git conventions, particularly around null-terminated output handling. While not blocking, these suggestions would improve the patch's quality and platform compatibility.
