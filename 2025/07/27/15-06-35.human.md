Feature patch for bash completion allowing configurable ref sorting. This is a follow-up to the initial patch introducing the `GIT_COMPLETION_REFS_SORT_BY_FIELDNAME` configuration variable for customizing branch/ref sorting in completion.

The author clarifies a minor formatting issue in their original submission where the tab completion example ("git checkout <TAB>") was mangled by GitHub's processing. No substantive changes are being made to the patch itself - it remains a well-structured addition that lets users configure ref sorting (like `-committerdate` for recently-used branches) while maintaining alphabetical sorting as the default.

The implementation appears solid, with proper input sanitization and integration at 8 call sites. The main open question from the original submission remains whether the community might want to change the default sorting behavior in the future (e.g. to prioritize recently-used branches).
