This is a feature patch in the `git repo info` command series, adding support for querying shallow repository status. The patch implements the `layout.shallow` field, migrating functionality from `git rev-parse --is-shallow-repository` to the new command.

The implementation follows the established pattern seen in previous patches, wrapping the existing `is_repository_shallow()` function and adding appropriate test coverage. The tests verify both shallow and non-shallow repository states, as well as integration with the multi-field output capability. Documentation is updated to include the new field alongside the existing `layout.bare` field.

Key technical details include:
- New field `layout.shallow` returns "true"/"false" strings
- Uses `is_repository_shallow()` from shallow.h
- Maintains lexicographical ordering of fields in the implementation
- Includes comprehensive tests covering:
  - Basic shallow/non-shallow states
  - Multi-field output (combined with `layout.bare`)
  - Error cases (already handled by framework)

This continues the series' pattern of cleanly migrating `git rev-parse` functionality to the new command while maintaining consistent output formatting and error handling. The implementation appears straightforward and well-tested, following the architectural decisions established earlier in the series.
