This is a feature patch adding shallow repository detection to the new `git repo info` command, part of Lucas Seiki Oshiro's GSoC project. The patch introduces a new `layout.shallow` field that reports whether the repository is shallow, migrating functionality from `git rev-parse --is-shallow-repository`.

The implementation follows the established pattern from previous fields in this series, wrapping the existing `is_repository_shallow()` function and adding comprehensive tests. The tests verify both shallow and non-shallow cases, including creating an actual shallow clone to test the true case. The patch also adds a test for multiple field output, showing the command can handle combinations like `layout.shallow` and `layout.bare` together.

This continues the series' pattern of cleanly migrating `git rev-parse` functionality to the new command while maintaining consistent output formatting and error handling.
