Feature patch for bash completion: configurable ref sorting in tab completion.

Nelson Benítez León proposes adding a new `GIT_COMPLETION_REFS_SORT_BY_FIELDNAME` config variable to customize how refs are sorted during tab completion (e.g. for `git checkout <TAB>`). Currently, refs always appear in alphabetical order. The patch would allow users to specify any `--sort` field supported by `git for-each-ref`, with `refname` remaining the default to maintain backward compatibility.

The author's motivation is personal workflow improvement, wanting to see recently worked-on branches first via `-committerdate` sorting. The implementation adds a validation function to ensure only valid sort fields are used. The patch also disables bash's default alphabetical sorting to ensure the Git-specified order takes precedence.

Notably, the author asks for community feedback on whether to change the default sort order in a future patch, presenting two options: keep alphabetical (current behavior) or switch to `-committerdate`. The patch lacks tests, which the author acknowledges, but appears to be a clean implementation otherwise. This would be a useful quality-of-life improvement for users who want to customize their completion experience.
