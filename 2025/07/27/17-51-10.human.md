This is a feature patch adding output format options to the new `git-repo-info` command, part of Lucas Seiki Oshiro's GSoC project to create a structured repository metadata command. The patch introduces two output formats: a human-readable `keyvalue` format (the default) and a machine-parsable `nul` format, following the pattern established by `git-config`.

The implementation adds proper option parsing for the `--format` flag and handles both formats by adjusting the delimiter characters (using `=` and newline for keyvalue, newline and null for nul). The patch includes thorough test coverage for both formats plus error handling for invalid format requests. The documentation is updated to explain the format options.
