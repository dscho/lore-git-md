This is a feature patch in the `git repo info` command series, adding output format options for machine and human consumption. The patch introduces a `--format` flag with two options: `keyvalue` (default, human-readable) and `nul` (machine-parsable), following the pattern established by `git config`.

The implementation adds an `enum output_format` in `builtin/repo.c` with corresponding parsing logic, plus tests to verify both formats work correctly. The `nul` format uses newline as key-value delimiter and null character as field separator, while `keyvalue` uses `=` and newline respectively. Error handling rejects invalid format specifiers.

Key technical details include:
- New `FORMAT_KEYVALUE` and `FORMAT_NUL_TERMINATED` enum values
- Modified `print_fields()` to handle both formats with different separators
- Test cases in `t1900-repo.sh` covering both formats and error cases
- Documentation updates explaining the format options
