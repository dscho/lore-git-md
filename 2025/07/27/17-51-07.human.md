This is a feature patch in the `git repo-info` series, implementing the `references.format` field to report whether a repository uses files or reftable for reference storage. The patch builds on existing `git rev-parse --show-ref-format` functionality but integrates it into the new command's structured output system.

The implementation adds a new field lookup system in `builtin/repo.c` with bsearch-based key matching and strbuf-based value handling. The field returns the same values as the rev-parse flag ("files" or "reftable") but through the new command's output format. The patch includes thorough test coverage verifying correct output for both storage formats, duplicate key handling, and proper error reporting for invalid keys.

This appears to be a well-constructed implementation with clean separation of concerns between the field definition and output formatting logic. The tests follow the established pattern seen in other parts of the series and cover both happy paths and error cases. The change fits naturally into the broader goal of moving repository metadata queries out of `git rev-parse`.
