Each test verifies the command produces the expected message and exit code (129) both inside and outside a repository. The changes are purely organizational - the actual test assertions remain identical, just relocated to a more logical home.

The series is proceeding systematically, with one command's help test being moved per patch. The remaining patches will handle `ls-files`, `pack-refs`, `send-pack`, `verify-commit`, and `verify-tag` in the same straightforward manner.
