Test reorganization patch moving the `verify-commit -h` test to its new home in t1517-outside-repo.sh. This is part of a completed 7-patch series that consolidates help tests (-h flag behavior) for various Git commands into a single dedicated test file.

The patch relocates the verify-commit test from t7510-signed-commit.sh, where it was mixed with GPG-related tests, to the new unified location. Like the other tests in the series, it verifies two things: that the command exits with code 129 when given -h, and that it outputs a usage message (checked case-insensitively). The test runs both inside and outside a repository context.

This follows the established pattern seen in previous patches in the series, demonstrating that help behavior is consistent and independent of command category - in this case showing that verification commands like verify-commit follow the same -h behavior as plumbing, porcelain, and transport commands. The change is purely organizational with no behavior modifications.
