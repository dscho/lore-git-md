This is a feature patch series introducing a new `git repo-info` command for retrieving repository metadata in machine-readable formats, part of Lucas Seiki Oshiro's GSoC project. The series has evolved to version 3 with several notable changes from v2.

The command aims to provide a dedicated interface for repository metadata currently scattered across `git rev-parse` and other commands. The implementation now includes:
- A new null-terminated output format replacing the previous plaintext format, matching `git config --list -z` syntax
- Removal of the `--allow-empty` flag (with plans for a future `--all` flag)
- Complete documentation in git-repo-info.adoc
- Initial field implementations for `references.format`, `layout.bare`, and `layout.shallow`

The technical approach shows careful consideration of output formats and field organization, with fields structured as `<category>.<field>`. The patchset includes thorough build system integration and test coverage in t1900-repo-info.sh. The command is marked as subject to change while experimental.

Key technical details for future reference:
- Output formats: JSON and null-terminated (like `git config -z`)
- Field structure: hierarchical `<category>.<field>` naming
- Current fields implemented:
  - `references.format`
  - `layout.bare`
  - `layout.shallow`
- Build system changes span Makefile, meson.build, and documentation
- Test coverage in t1900-repo-info.sh verifies basic functionality
