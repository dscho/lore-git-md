Feature implementation for the new `git-repo-info` command, adding shallow repository detection capability. This is the final patch in the v3 series introducing repository metadata reporting functionality.

The patch adds a `layout.shallow` field that reports whether the repository is shallow, using the same underlying `is_repository_shallow()` function that powers `git rev-parse --is-shallow-repository`. The implementation follows the established pattern from previous fields (`references.format` and `layout.bare`), supporting both JSON and null-terminated output formats. JSON output shows `"shallow": true/false` while the null-terminated format matches the field pattern used elsewhere in the command.

Test coverage includes verification of shallow repository detection (via a test repository created with `--depth 1`) and confirmation of correct false reporting in regular repositories. The documentation in git-repo-info.adoc is updated to include the new field alongside the existing `layout.bare` documentation.

The implementation appears solid, leveraging existing Git infrastructure and maintaining consistency with the command's established patterns. The patch completes the initial set of three metadata fields planned for the command (reference storage format, bare status, and shallow status), though the series leaves open questions about future field additions and command scope. The change is well-contained, touching only the expected files (command implementation, documentation, and tests) with clean, focused diffs.
