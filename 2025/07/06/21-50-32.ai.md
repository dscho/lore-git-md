This is a cover letter for a completed test refactoring series. The 7-patch set consolidates help tests (-h flag behavior) for seven Git commands into the dedicated t1517-outside-repo.sh test file, implementing Patrick Steinhardt's suggestion for better test organization.

The series moves tests for checkout-index, for-each-ref, ls-files, pack-refs, send-pack, verify-commit, and verify-tag commands from their original context-specific test files (covering areas like reftables, GPG signing, and basic operations) into the unified location. Each patch follows the same pattern: verifying exit code 129 and usage message output in both repository and non-repository contexts using test_grep, while removing the original test from its specialized context file.

Notable aspects include the pack-refs test moving from reftable-specific tests and verify-commit/verify-tag tests moving from GPG/signing contexts, demonstrating these help tests are truly context-independent. The verify-tag move in patch 7/7 completes the series, confirming the pattern works even for commands originally in GPG context without functional dependencies.

The v2 iteration addresses a typo fix from previous feedback. The changes are purely organizational - no behavior is modified. The series provides a clean template for future similar test reorganizations, having successfully consolidated these seven command tests while maintaining their original verification logic. All tests now follow identical verification patterns regardless of command type (plumbing, porcelain, transport, or verification commands).
