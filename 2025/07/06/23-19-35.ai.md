Feature implementation for the new `git repo-info` command, specifically adding output format options. This patch introduces the `--format` flag to control how repository metadata is displayed, with JSON as the default and null-terminated as an alternative machine-readable format.

The implementation establishes the core output formatting infrastructure in builtin/repo-info.c, including:
- `enum output_format` with JSON and null-terminated variants
- `repo_info` struct to track format selection
- Basic JSON output scaffolding using `json-writer.h`
- Command-line option parsing via `OPT_STRING`

The documentation update in git-repo-info.adoc details both formats:
- JSON uses a hierarchical structure with categories and fields
- Null-terminated format provides key-value pairs with NUL delimiters
- Defaults to JSON if unspecified

This builds on the v3 series' focus on machine-readable output, addressing limitations of line-based formats like those from `git rev-parse`. The patch shows clean integration with existing parse-options infrastructure and follows the project's JSON writer conventions. The null-terminated format matches `git config -z` behavior for consistency.

- JSON implementation uses the standard `json-writer` API
