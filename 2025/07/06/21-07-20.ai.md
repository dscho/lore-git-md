The patch moves the `for-each-ref -h` test from `t6300-for-each-ref.sh` to `t1517-outside-repo.sh`, following the pattern established in the first patch for `checkout-index`.

The test verifies that `git for-each-ref -h` produces the expected usage message and exit code (129) both inside and outside a repository. The implementation is a direct move of the existing 7-line test block, maintaining identical assertions while changing only the file location. The test is removed from its original location in `t6300` where it was surrounded by other `for-each-ref` specific tests.

This continues the mechanical reorganization started in patch 1/7, with the same straightforward approach and no behavior changes. The patch follows Patrick Steinhardt's suggestion to group tests of command behavior outside repositories together.
