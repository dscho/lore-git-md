This is a documentation discussion thread about template directory behavior in `git init`. Jeff King (peff) responds to Todd Zullinger's historical context about the long-standing behavior where an empty template path (`--template=`) skips copying templates, noting this was an intentional safety fix from 2008 that's been stable for 17 years.

Peff agrees this behavior should be documented, while also suggesting the newer `--no-template` flag (added in Git 2.38.0) provides a more ergonomic alternative when available. He points out the empty string behavior remains relevant for cases where the flag isn't available (like config/environment variables) and suggests the documentation should mention both approaches while possibly steering users toward `--no-template` when appropriate.

The exchange reinforces that both mechanisms are valid and stable, with the main documentation challenge being how to present them clearly without confusion. The thread shows consensus that documenting these behaviors is worthwhile, with no objections to either approach.
