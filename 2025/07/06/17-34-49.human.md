This is a bugfix patch addressing tempfile cleanup in SSH signing, part of an ongoing thread about fixing leaks in the GPG/SSH signing interface. The patch follows up on previous discussion with a more robust solution and adds test coverage.

The core fix changes how the temporary key filename is handled in `sign_buffer_ssh()`, switching from `strbuf_detach()` to `xstrdup()` to ensure proper cleanup. While functionally equivalent for the leak, the author notes this keeps symmetry with other code paths that also allocate strings. The patch includes a new test that verifies no temporary files remain after signing commits, using a dedicated `tmpdir` for isolation.

This version (v2) improves upon the initial submission by adding both the test case and more explanation in the commit message. The change has already received positive feedback, with brian m. carlson providing a Helped-by tag. The patch appears well-considered - it addresses the original issue while maintaining code consistency and adding verification.
