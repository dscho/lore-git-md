This is the first patch in a v3 submission introducing a new `git repo-info` command, part of Lucas Seiki Oshiro's GSoC project. The patch establishes the basic scaffolding for the new command, adding build system integration, documentation stubs, and a minimal implementation that currently does nothing but parse empty options.

The motivation is to create a dedicated command for repository metadata that's currently scattered across `git rev-parse` and other commands. The documentation describes it as experimental and machine-readable (supporting JSON and null-terminated formats), with a hierarchical `<category>.<field>` query system. The patch includes all the boilerplate needed to make `git repo-info` a recognized command, with help from Phillip Wood and Junio Hamano.

This appears to be a well-structured foundation for the feature, though the actual metadata reporting functionality will come in later patches. The documentation already outlines the planned architecture while clearly marking the command as experimental. As the first in an 8-patch series, it cleanly sets up the infrastructure without prematurely implementing behavior.
