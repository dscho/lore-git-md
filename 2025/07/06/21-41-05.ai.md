This is the fourth patch in a test reorganization series, moving help tests (-h flag behavior) to a dedicated t1517-outside-repo.sh script. The patch relocates the `pack-refs` command's help test from t0610-reftable-basics.sh to the consolidated location.

The test verifies that `git pack-refs -h` shows usage information and exits with code 129, both inside and outside a repository context. The move follows the established pattern seen in previous patches (checkout-index, for-each-ref, ls-files), though this one comes from a different source file (reftable tests rather than the command's main test file).

Key technical details: The test uses `test_expect_code` to verify exit status 129 and `test_grep` with case-insensitive matching for the usage pattern. The test is duplicated for both git and nongit contexts despite being in the "outside-repo" file, maintaining consistency with the series' approach. The patch removes the test from t0610 where it was somewhat out of context among reftable-specific tests.

This continues the series' clean separation of concerns - t0610 file now focuses purely on reftable functionality while t1517 collects all command help tests. The change is purely organizational with no behavior impact.
