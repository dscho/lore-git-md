Bugfix for `git stash create` message argument behavior. José Miguel Armijo Fidalgo reports that the "message" argument to `git stash create` is ignored when the created stash is later stored with `git stash store`. The documentation doesn't clarify the purpose of this argument, leading to confusion. The current behavior shows a generic "Created via git stash store" message rather than using the provided message. The reporter suggests either removing the unused argument or documenting its actual purpose. This appears to be a documentation/behavior mismatch rather than a functional bug, but the unclear interface could confuse users expecting the message to be preserved. The report includes clear reproduction steps and was filed against Git 2.50.0 on an arm64 macOS system.
