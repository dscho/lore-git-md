This thread has completed a multi-stage effort to reorganize how Git tests command help output behavior. The work originated from Patrick Steinhardt's suggestion and was implemented through several patch series, culminating in Usman Akinyemi's v5 3-patch set that Junio has now completed merging.

The key achievement is a clear separation of concerns in help output testing: repository-dependent tests now live with their respective commands (like the prune test moving to t5304-prune.sh), while t1517-outside-repo.sh handles only outside-repository behavior through an efficient automated approach that checks all main commands via `git --list-cmds=main`. The strategy establishes exit code 129 as the standard for script-based commands when testing `-h` behavior outside a repository.

Windows-specific handling of instaweb.sh remains a noted edge case, and some command output mismatches may point to documentation bugs, but these are being addressed incrementally. The core architecture - with its automated testing of outside-repo behavior and properly located command-specific tests - is now firmly established and serves as a model for future test additions.
