This thread documents the completion of a test reorganization series that consolidates help tests (-h flag behavior) for seven Git commands into a dedicated test file (t1517-outside-repo.sh). The work implements a suggestion from Patrick Steinhardt to improve test maintenance by grouping these related tests together.

The series moves tests for checkout-index, for-each-ref, ls-files, pack-refs, send-pack, verify-commit, and verify-tag commands from their original context-specific test files (covering areas like reftables, GPG signing, and basic operations) into the unified location. Each test follows the same verification pattern, checking for exit code 129 and usage message output in both repository and non-repository contexts. The pack-refs test relocation was particularly notable as it came from reftable-specific tests, while verify-commit/verify-tag tests moved from GPG/signing contexts, demonstrating these help tests are truly context-independent.

The series is now complete with all seven patches merged, having addressed earlier typo feedback in v2. The changes are purely organizational with no behavior modifications. This work provides a clean template for future test reorganizations and demonstrates that help tests can be cleanly separated from their original specialized contexts. The consistent approach across all seven commands shows the pattern works reliably regardless of command type (plumbing, porcelain, transport, or verification commands).
