This thread discusses a user confusion around Git's configuration keys, specifically the non-existent `pull.autostash` setting. Lidong Yan initially reported that setting `pull.autostash` had no effect, and Bryan Lee confirmed that the correct key is actually `rebase.autostash` when using `pull --rebase`. 

The discussion revealed that Git silently accepts invalid configuration keys like `pull.autostash` without warning users that these settings have no effect. This behavior can lead to confusion, as users might think they've configured autostashing when in fact they haven't. The issue occurs in both regular and bare repositories.

Participants have suggested two potential improvements: adding warnings for non-existent configuration keys (which would help catch similar issues in the future) and better documenting common configuration misconceptions in the git-config man page. The conversation has shifted from the original bare repository scenario to a broader discussion about Git's configuration system behavior and usability.
