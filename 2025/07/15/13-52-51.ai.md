Refactoring patch converting case-insensitive string predicate functions to use `bool` return type, part of the ongoing C99 `bool` standardization effort. This is the second patch in a 3-part series that has already established policy approval via documentation updates in the first patch.

The change affects two functions in `git-compat-util.h`: `skip_iprefix()` and `skip_iprefix_mem()`, converting their return types from `int` to `bool` and updating their `1`/`0` returns to `true`/`false`. These are the case-insensitive variants of functions that were already converted to `bool` in December 2023 (commit 8277dbe987), making this a mechanical consistency update. The patch maintains identical runtime behavior while improving type clarity for these predicate functions.

The commit message notes this change formalizes the successful 18-month experimental period of using `bool` for predicates, referencing the series' cover letter and first patch which updated Documentation/CodingGuidelines. The diff shows straightforward signature changes (6 lines modified) with no logic alterations, just type updates to match the now-standardized pattern.

This continues the series' pattern of mechanical, behavior-preserving changes that have already passed technical review (including feedback from Elijah Newren and Eric Sunshine on earlier versions). The patch demonstrates careful attention to maintaining ASCII-only case comparison behavior in both functions, with comments preserved verbatim to document this constraint.
