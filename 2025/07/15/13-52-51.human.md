Refactoring patch converting string utility functions to use C99 `bool` type. This is the second patch in a 3-part series standardizing `bool` usage for predicate functions in Git's codebase, following an 18-month experimental period.

The patch updates two case-insensitive string comparison functions in `git-compat-util.h` - `skip_iprefix()` and `skip_iprefix_mem()` - to return `bool` instead of `int`. This change aligns them with their case-sensitive counterparts that were converted earlier, making it clearer that these are predicate functions. The implementation remains functionally identical, just with `true`/`false` return values instead of `1`/`0`.

This is a mechanical change that builds on the foundation established in the first patch (which updated CodingGuidelines to permit `bool` usage) and follows the same pattern as previous conversions in this area. The series has already received thorough review, with all feedback incorporated, and represents the final standardization of this C99 feature in Git's codebase.
