Performance optimization patch in the byte-swapping series, focusing on compiler optimizations for x86 architectures.

This patch removes the x86-specific inline assembly implementation of bswap32/64 in favor of relying on compiler optimizations. The author demonstrates through testing that modern compilers (including MSVC, gcc, and clang) can recognize the shift operations in the default implementations and optimize them to efficient machine code, often matching or exceeding the performance of the hand-written assembly. The change simplifies the code by removing 40 lines of platform-specific implementations while maintaining performance.

Key technical details:
- Drops x86-specific `__asm__` implementations of bswap32/64 from compat/bswap.h
- Retains MSVC-specific path using `_byteswap_uint64()` intrinsic
- Shows test results across multiple compiler versions (MSVC 19.20/19.37, gcc 4.4.7-4.9.4, clang 3.0)
- Demonstrates that even older compilers (gcc-4.5.3, clang-3.0) optimize the shift operations
- Maintains the same behavior through compiler optimizations rather than explicit assembly
