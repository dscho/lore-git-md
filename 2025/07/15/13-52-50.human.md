This is a documentation patch formalizing the use of C99's `bool` type in Git's codebase, part of a 3-patch refactoring series. The change updates Documentation/CodingGuidelines to explicitly permit `bool` for predicate functions, following an 18-month experimental period that began in December 2023 with commit 8277dbe987. The patch notes there have been no complaints during this trial period, declaring the experiment a success.

The change is straightforward - it simply adds a bullet point to the C99 features section of the guidelines, alongside other already-accepted features like for-loop variable declarations. This follows Git's established pattern of gradually adopting C99 features after sufficient real-world testing. Junio C Hamano has already accepted this documentation update, indicating the change has maintainer approval.

This is the first patch in a series that will also convert string utilities and `strbuf` predicate methods to use `bool`. The patch itself is minimal (3 lines added) and uncontroversial, serving as the formal documentation backing for the mechanical changes that follow in subsequent patches. The 18-month timeframe matches Git's previous feature adoption timelines.
