This is a build system fix addressing a regression in the Meson build configuration. Ramsay Jones follows up on a previous discussion about `GIT_EXEC_PATH` handling with two targeted patches to correct installation issues.

The first patch fixes a regression introduced in May 2025 that affected installations where `-Dlibexecdir` was explicitly set. The second adds a missing Irish ('ga') language code to the Meson build configuration that was being omitted from translations. The commit message notes several other installation differences between Make and Meson builds (gitk/git-gui inclusion, builtin command handling, and symlink behavior) but explicitly leaves those for future work to avoid scope creep.

The changes are narrowly focused on the regression and translation omission, with clean 22-line net diff across two files. This appears ready for integration as it addresses the specific issue that was holding up other Meson build improvements, as noted in Junio's earlier "What's cooking" summary. The patch maintains Ramsay's characteristic attention to build system details while avoiding unrelated fixes that could complicate review.
