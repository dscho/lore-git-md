This is a follow-up discussion in the ongoing C99 `bool` standardization thread. Randall S. Becker raises a practical concern about portability, noting that some C99 implementations may require explicitly including `<stdbool.h>` to use the `bool` type. 

The email is brief but touches on an important implementation detail that wasn't fully addressed in the original series. While the patch series has already been reviewed and approved, this comment suggests there may be edge cases where the change could cause compilation issues on certain platforms. 

The concern appears valid but likely minor, as `<stdbool.h>` is already included in Git's codebase where needed (including in `git-compat-util.h` which was modified in this series). However, the comment serves as a useful reminder to double-check this assumption across all platforms Git supports. 

This is the first dissenting voice in what has otherwise been a smooth 18-month transition to using `bool` for predicate functions. The original authors and reviewers will likely need to confirm whether this concern represents a real portability issue or is already handled by Git's existing compatibility layer.
