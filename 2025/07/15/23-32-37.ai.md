Build system fix for Meson regression.

This is a two-patch series addressing installation regressions in the Meson build system, specifically around `GIT_EXEC_PATH` handling that was introduced in May 2025. The series comes from Ramsay Jones, who has been actively working on Meson build system compatibility issues.

The first patch fixes the core regression where `-Dlibexecdir` settings weren't being properly respected, restoring correct installation behavior. The second patch adds the missing Irish ('ga') language code to the Meson build configuration, bringing it in line with the Makefile-based build which includes this translation.

Ramsay's cover letter notes several additional discrepancies between Make and Meson installations that aren't addressed here: missing gitk/git-gui tools, different handling of builtin commands (Make installs them while Meson doesn't), and hard vs symbolic link differences. These are noted as known issues but deliberately left for future work as they would require more extensive changes.

This appears to be a straightforward fix for the immediate regression, following up on previous discussion where Junio Hamano had indicated this would be needed. The changes are focused and the commit messages appear technically sound. The patches modify `meson.build` and `po/meson.build` files, with the main fix involving careful path handling logic in the build configuration.

The series context shows this is part of the ongoing Meson build system work where backward compatibility is being maintained, particularly for versions before Meson 1.3.0. The changes here should unblock other non-controversial build improvements while keeping the installation behavior correct.
