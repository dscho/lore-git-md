Refactoring patch in the ongoing ODB abstraction series, removing global MIDX list usage. This is patch 6/7 in Patrick Steinhardt's series to move MIDX tracking from global state to per-source storage in `struct odb_source`.

The patch simplifies `get_all_packs()` by eliminating its dependency on the global multi-pack-index linked list. Instead, it now iterates through the repository's object sources directly, using each source's `midx` pointer. The change leverages the fact that `prepare_packed_git()` already handles source preparation, making the explicit alternate preparation unnecessary.

The diff shows a clean conversion from the old global list iteration to the new per-source approach, maintaining the same pack preparation behavior while removing another piece of global state. This continues the series' pattern of methodically replacing global MIDX infrastructure with the new source-based design. The change is small (11 lines modified) but meaningful, demonstrating how the refactoring simplifies callers by centralizing MIDX access through sources.

This patch follows positive review feedback on earlier versions and builds on the groundwork laid in previous patches of the series. It represents one of the final steps in eliminating global MIDX state entirely.
