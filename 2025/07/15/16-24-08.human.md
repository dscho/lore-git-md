This is a documentation patch in the ongoing discussion about C99 compound literals in Git's codebase. Junio C Hamano responds to Patrick Steinhardt's observation about existing test balloons in the reftable subsystem by proposing to document them in CodingGuidelines.

The patch adds a new section to CodingGuidelines explicitly calling out the reftable macros (`REFTABLE_FLOCK_INIT` and `REFTABLE_TMPFILE_INIT`) as test cases for C99 compound literals. It notes these were introduced in Git 2.50 and proposes a moratorium on further use of the syntax until mid 2026, when wider adoption can be considered if no platform issues arise.

The change represents a pragmatic middle ground in the thread - neither banning the feature nor encouraging its widespread use yet, while properly documenting the existing real-world test cases. The discussion has moved from theoretical concerns to concrete documentation based on actual usage patterns in the codebase.
