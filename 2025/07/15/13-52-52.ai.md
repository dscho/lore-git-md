Refactoring patch completing the C99 `bool` standardization effort in Git's string utilities. This third and final patch in the series updates the `strbuf` predicate methods to return `bool` instead of `int`, matching the earlier conversion of `git-compat-util.h` string functions. The changes affect six functions across `strbuf.c` and `strbuf.h`:

1. Core string comparison functions (`starts_with`, `istarts_with`, `starts_with_mem`) now return `true`/`false` instead of `1`/`0`
2. Optional argument parsing helpers (`skip_to_optional_arg_default`, inline `skip_to_optional_arg`) updated to `bool` returns
3. The inline `ends_with` function also converted for consistency

All changes are mechanical signature updates (20 lines modified) with no behavioral impact, maintaining the same logic while improving type clarity. The patch follows the pattern established in the series' earlier conversions and builds on the policy foundation laid by the accepted documentation update in patch 1. This completes the standardization effort that began with experimental `bool` usage in December 2023 (commit 8277dbe987), now formalized after 18 months of incident-free production use. The series demonstrates Git's careful approach to language feature adoption, with each step receiving thorough review (including typo fixes from Eric Sunshine, style guidance from Brian m. carlson, and technical review from Elijah Newren).
