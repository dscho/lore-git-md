This is a build system patch that completes Ramsay Jones' two-part series fixing Meson build system issues. The second patch adds the Irish ('ga') language code to the Meson build configuration, ensuring the recently added Irish translation is properly included when building with Meson. 

The change is straightforward - it adds 'ga' to the explicit list of translations in `po/meson.build`. The commit explains that while Make builds automatically pick up new `.po` files via wildcards, Meson requires explicit listing. This matches the behavior between build systems for the Irish translation added in May 2025.

This is a clean, focused follow-up to the first patch in the series (which fixed `GIT_EXEC_PATH` handling). Together they address two distinct but important Meson build system gaps. The patch appears ready to merge as part of the ongoing Meson build system improvements.
