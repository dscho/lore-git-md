This is a documentation patch proposing to codify existing C99 compound literal usage in Git's CodingGuidelines. Junio C Hamano responds to Patrick Steinhardt's observation about the reftable subsystem's existing `REFTABLE_FLOCK_INIT` and `REFTABLE_TMPFILE_INIT` macros (introduced in Git 2.50) as de facto test balloons for compound literals.

The patch adds a new section to CodingGuidelines documenting these macros as intentional test cases for C99 compound literal syntax, with a proposed timeline for wider adoption in mid-2026. The documentation explicitly states these macros should remain the only uses of the feature until that evaluation period concludes. The proposed text references the specific commit (v2.48.0-rc0~20) where the reftable macros were introduced.

This moves the thread forward by formalizing the experimental status of compound literals while acknowledging the existing production usage in reftable. The patch maintains Junio's earlier expressed caution about the feature by proposing a clear moratorium on additional uses until 2026. The documentation approach satisfies both the need to record the test balloons and provide guidance to contributors, while avoiding immediate widespread adoption of the feature.
