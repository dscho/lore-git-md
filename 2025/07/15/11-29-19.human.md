This is part 2 of Patrick Steinhardt's 7-patch series refactoring MIDX handling to work per-source rather than globally, a key step in the ODB abstraction effort for pluggable backends.

The patch refactors `prepare_packed_git_one()` to operate on `struct odb_source` rather than taking a repository and object directory path. This aligns with the series' goal of moving MIDX tracking to individual sources, as the function can directly use the source's pre-loaded MIDX pointer rather than searching through a global linked list. The changes are straightforward:
- Removes the MIDX search loop since the source already has its MIDX
- Simplifies parameter passing by using the source's fields directly
- Updates the caller in `prepare_packed_git()` to pass the source

This is a clean technical refactoring that follows the pattern established in the first patch of the series. The changes are well-contained and maintain the same behavior while removing global state access. The patch builds on positive review consensus from Taylor Blau and Justin Tobler on the overall approach.
