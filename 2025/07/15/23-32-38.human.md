Build system fix for Meson's libexecdir handling. This is the first of two patches from Ramsay Jones addressing installation regressions in Git's Meson build system.

The patch fixes a regression introduced in May 2025 where Git commands would fail to find subcommands when installed to non-standard locations via `-Dlibexecdir`. The issue occurred because while the build system was correctly setting `GIT_EXEC_PATH`, it wasn't using that same path for installing the executables. The fix updates all installation paths to use the calculated `git_exec_path` variable consistently.

The change affects numerous components including core Git commands (`git`, `git-shell`), helper programs (`git-daemon`, `git-http-backend`), and scripting support (Perl/Python scripts). The patch maintains backward compatibility with older Meson versions while ensuring the executables are installed where Git will look for them.

This appears to be a well-scoped technical fix addressing a clear regression, with thorough updates to all affected installation paths. The patch follows naturally from the previous `GIT_EXEC_PATH` correction and should unblock users who need custom installation layouts.
