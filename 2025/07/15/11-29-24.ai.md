This is the final patch in Patrick Steinhardt's 7-part refactoring series to move MIDX tracking from global object database state to per-source storage in `struct odb_source`. The series is part of the broader ODB abstraction effort for pluggable backends.

The patch removes the now-unused global MIDX infrastructure after all callers have been converted to use the per-source MIDX storage. Key changes include:
- Removing the `next` pointer from `struct multi_pack_index`
- Eliminating the `multi_pack_index` field from `struct object_database`
- Cleaning up the global MIDX list maintenance code in `midx.c` and `packfile.c`
- Simplifying `prepare_multi_pack_index_one()` to directly set the source's MIDX pointer without global list manipulation

The changes are straightforward deletions of now-dead code, with no behavior changes. The patch completes the series' goal of fully decoupling MIDX handling from global state, leaving the MIDX tracking entirely at the per-source level. This represents the final step in the refactoring after all review feedback was incorporated in previous patches.
