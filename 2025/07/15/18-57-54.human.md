This is a test infrastructure patch that fixes an issue with `GIT_TEST_INSTALLED` not being respected when detecting the default hash algorithm. The problem caused test failures in the submitter's internal test environment where they use an installed Git binary rather than one from the build directory.

The patch makes two changes to `t/test-lib.sh`: First, it factors out the Git binary path into a variable that properly accounts for `GIT_TEST_INSTALLED`, then uses this same path when querying the default hash algorithm. The change is straightforward and addresses a clear gap in the test infrastructure.

The commit message explains the practical impact (tests failing due to empty hash detection) and notes the Windows compatibility aspect (`.exe` suffix handling). While the change is small, it solves a real problem for the submitter's testing workflow and maintains consistency in how the test suite locates the Git binary.
