This is a build system patch continuing the discussion about PCRE2 dependency handling in the meson build system, specifically addressing macOS compatibility issues. Patrick Steinhardt responds to Eli Schwartz's technical proposal for improving PCRE2 detection on macOS.

The key technical point is about replacing the current platform-specific disable logic (`disable_auto_if`) with active verification of PCRE2 functionality using `compiler.has_header()`. Eli's approach would actively detect broken system PCRE2 installations on macOS (where headers may be missing despite the library being present) and either error out (if PCRE2 was explicitly enabled) or gracefully fall back (if auto-detected). Patrick agrees this is superior to the current approach.

The discussion also touches on the default setting for PCRE2 in meson_options.txt, where they agree to change from 'enabled' to 'auto' since PCRE2 cannot be universally expected to be available. This reflects a more conservative approach to dependency handling while maintaining the ability to use PCRE2 when properly available.

This response moves the technical discussion forward by accepting Eli's concrete proposal for macOS PCRE2 detection while maintaining alignment with the broader goal of making PCRE2 dependency handling more robust across platforms. The solution being discussed would provide better error messages and more reliable behavior than the current platform-specific workaround.
