This is a cover letter for a refactoring series that formalizes the use of C99 `bool` type for predicate functions in Git's codebase. The series builds on an 18-month experimental period that began in December 2023 with initial conversions of some string utility functions.

The three patches systematically convert remaining predicate functions to use `bool` returns: first by updating CodingGuidelines to explicitly permit this usage (already approved by Junio), then converting core string utilities in git-compat-util.h (with feedback from Eric Sunshine and Elijah Newren incorporated), and finally updating strbuf predicate methods. All changes are mechanical type signature updates with no behavior modifications.

The cover letter notes this completes the standardization effort following Git's pattern for gradual C99 feature adoption, with no reported issues during the experimental period. Version 2 incorporates minor typo fixes in commit messages from V1 feedback. The changes are well-scoped (4 files, 29 insertions/26 deletions) and build on established precedent, representing a clean-up of technical debt now that the approach has been proven in production.
