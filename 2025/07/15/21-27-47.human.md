This is a test infrastructure patch that has already received maintainer approval. Junio C Hamano is queueing Kyle Lippincott's fix for inconsistent handling of `GIT_TEST_INSTALLED` when detecting the default hash algorithm during test runs.

Junio specifically praises the solution's elegance in reusing the binary path that was already determined earlier in the test setup. The change is straightforward and focused - it doesn't affect core functionality but makes the infrastructure more robust when running tests against installed Git binaries.
