Refactoring patch completing the standardization of `bool` return types for predicate functions in Git's codebase. This third and final patch in the series updates the `strbuf` utility functions to return `bool` instead of `int`, matching the changes already made to string utilities in `git-compat-util.h`.

The changes are purely mechanical type signature updates affecting six functions in `strbuf.[ch]`: `starts_with`, `istarts_with`, `starts_with_mem`, `skip_to_optional_arg_default`, `skip_to_optional_arg`, and `ends_with`. All runtime behavior remains identical - the patch simply replaces `1`/`0` returns with `true`/`false` for better type safety and consistency.

This work follows the 18-month experimental period for `bool` usage that began in December 2023 (commit 8277dbe987) and was formally approved via the first patch in this series that updated Documentation/CodingGuidelines. The changes are straightforward and well-tested, having been in production use for over a year. With the string utilities and now `strbuf` predicates converted, this completes the mechanical standardization effort for predicate functions.
