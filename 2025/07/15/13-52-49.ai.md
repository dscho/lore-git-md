This is a cover letter for a refactoring series standardizing the use of C99 `bool` for predicate functions in Git's codebase. The series builds on an 18-month experimental period that began with commit 8277dbe987 in December 2023, which introduced `bool` returns for some string utility functions. The current series completes this standardization effort by:

1. Updating Documentation/CodingGuidelines to explicitly permit `bool` usage for predicate functions, which Junio C Hamano has already confirmed will be accepted. This formalizes existing practice after successful production use.

2. Converting core string utility functions in `git-compat-util.h` (including case-insensitive variants like `skip_iprefix()`) from `int` to `bool` returns. This version incorporates feedback from Eric Sunshine (typo corrections) and Brian m. carlson (hyphenation style guidance based on Chicago Manual of Style).

3. Updating `strbuf` predicate methods in `strbuf.[ch]` to use `bool` returns, affecting six functions while maintaining identical runtime behavior.

The changes are purely mechanical type signature updates across four files (29 insertions, 26 deletions) with no behavioral modifications. The series follows Git's established pattern for gradual C99 feature adoption, with this change having been proven safe through 18 months of production use. All reviewer feedback from v1 has been addressed, including typo fixes and documentation style improvements. The thread demonstrates Git's attention to both technical correctness and documentation quality even for straightforward refactorings.
