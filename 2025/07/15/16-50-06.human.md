This is a build system patch addressing PCRE2 dependency handling on macOS, part of an ongoing series to improve cross-platform compatibility in Git's meson build system.

The patch implements a specific workaround for macOS systems where the system-provided PCRE2 library is broken - it installs a pkgconf module pointing to a non-existent header file. The solution detects this case and either falls back to a bundled submodule (if PCRE2 is explicitly enabled) or gracefully disables PCRE2 support with a warning (if set to "auto", which is now the default).

The approach follows Eli Schwartz's suggestion and has been confirmed working by Carlo Arenas Belón, who submitted the patch. This builds on previous discussion in the thread that resolved similar issues for Windows systems. The solution maintains Git's preference for static linking while handling the macOS-specific quirk.

The patch appears well-considered, with clear commit message explaining the problem and solution. It's part of a coordinated effort to improve PCRE2 handling across platforms in the meson build system, with this specific macOS solution now queued for inclusion by Junio Hamano. The thread also suggests this work may inspire upstream improvements to meson itself.
