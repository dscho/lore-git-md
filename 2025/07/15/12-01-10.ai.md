This is a follow-up confirmation in the completed meson build system thread about PCRE2 dependency handling on macOS. Carlo Arenas verifies that Eli Schwartz's proposed solution using `compiler.has_header()` works correctly on his test system to detect and disable broken system PCRE2 installations. The email notes this approach might inspire future enhancement to meson's `dependency()` function to incorporate header validation natively.

The exchange serves as final technical validation for the solution that was already accepted as the thread's resolution.
