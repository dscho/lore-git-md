This is a refactoring patch that removes unused code from the ref-cache implementation. 

Karthik Nayak removes the `find_ref_entry()` function and its associated header declaration, as it's no longer used anywhere in the codebase. The function was previously used to look up a specific entry in the ref cache, but has been made obsolete by other refactoring work. 

The change is straightforward - it simply deletes the function implementation from ref-cache.c and its prototype from ref-cache.h. This is part of a larger series introducing pagination support for `git for-each-ref`, but this particular patch is a clean-up of dead code that was identified during that work.

The removal was previously confirmed by Junio C Hamano as being safe, and the patch follows the typical pattern for removing unused code - deleting both the implementation and declaration while keeping the surrounding code structure intact. This is a minor but worthwhile cleanup that reduces maintenance burden.
