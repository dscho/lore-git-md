This is a build system patch finalizing the macOS-specific solution for broken PCRE2 installations. Junio Hamano acknowledges Carlo Arenas' implementation and indicates it will be queued for inclusion.

The patch implements the header verification approach discussed earlier in the thread, specifically checking for the presence of `pcre2.h` when using system PCRE2 on macOS (Darwin). The solution handles three scenarios: when PCRE2 is explicitly enabled (falling back to built-in if system version is broken), when set to auto (disabling with warning if broken), and when disabled (no action). The meson_options.txt change switches the default from 'enabled' to 'auto' to match this new behavior.

Key technical details include the use of `compiler.has_header()` for verification, the fallback mechanism using `method: 'builtin'`, and maintaining static linking preferences through `default_library=static`. The implementation follows Eli Schwartz's suggestion and has been confirmed working by Carlo Arenas on macOS. This completes one half of the platform-specific PCRE2 solutions discussed in the thread (Windows handling having been addressed separately).

The patch represents the final implementation step for the immediate build system fixes, while leaving open the broader questions about potential meson upstream contributions and long-term regex architecture that were discussed earlier in the thread.
