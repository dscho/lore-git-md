Bugfix discussion regarding Git's handling of invalid configuration keys, specifically the non-existent `pull.autostash` setting.

Bryan Lee confirms Lidong Yan's suggestion that `rebase.autostash` is the correct configuration key for autostashing during rebase operations, not `pull.autostash`. The email demonstrates through test cases that Git silently accepts the invalid `pull.autostash` configuration without warning, leading to user confusion when the setting has no effect. The issue occurs in both regular and bare repositories.

Key technical details:
- The invalid `pull.autostash` key is accepted by Git's config system but has no functional effect
- The working configuration is `rebase.autostash` when using `pull --rebase`
- The discussion reveals a broader issue about Git silently accepting invalid configuration keys

The email raises two potential improvements:
1. Adding warnings for non-existent configuration keys
2. Documenting common configuration misconceptions in the git-config man page

This appears to be a genuine usability issue that could be addressed either through better validation or documentation. The discussion is focused on configuration system behavior rather than the original bare repository scenario.
