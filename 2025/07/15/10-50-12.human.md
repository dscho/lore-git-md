This is a brief follow-up in the ongoing series to make the object-file subsystem repository-agnostic. The email is a simple acknowledgment of a typo fix in patch 09/19, which introduced the `odb_write_object()` interface. 

Toon Claes spotted a typo in the documentation for the `WRITE_OBJECT_PERSIST` flag where "gose" should be "goes". Patrick Steinhardt confirms the fix will be made. This is a minor correction to an otherwise substantial patch that established a key backend-agnostic interface for writing objects.

The thread context shows this is part of a larger architectural effort to enable pluggable object storage backends by removing `the_repository` dependencies. The series has already received extensive review, with maintainers and other contributors weighing in on design decisions. This particular exchange is a quick quality improvement to the documentation of a newly introduced API.
