Build system fix for macOS PCRE2 handling. This is the final version of a patch that addresses broken system PCRE2 installations on macOS, which was causing build issues. The solution detects invalid system PCRE2 installations (where the header file is missing despite pkg-config reporting availability) and provides appropriate fallback behavior - either using a bundled submodule if PCRE2 is required, or gracefully disabling the feature if it was optional.

The patch changes the default meson option from 'enabled' to 'auto' for PCRE2, which better matches the behavior of other optional dependencies. The implementation includes specific handling for macOS (Darwin) systems while maintaining the existing static linking preference. Junio Hamano has reviewed and accepted the patch for inclusion.

This concludes the immediate platform-specific fix for macOS, though the thread discussion revealed potential for upstream meson improvements that could make this workaround unnecessary in the future. The solution is clean and well-tested, with Carlo Arenas confirming it works and Eli Schwartz providing key technical suggestions.
