This is a refactoring patch removing obsolete code from the ref-cache subsystem, part of the larger `for-each-ref` pagination series.

The patch removes the unused `find_ref_entry()` function and its declaration from the ref-cache implementation. This function was previously used to look up ref entries in the files backend's cache, but has been made obsolete by the new ref iterator API introduced earlier in the series. The removal was confirmed as safe by Junio C Hamano in earlier thread discussion.

The changes are straightforward: both the implementation in `ref-cache.c` and its header declaration in `ref-cache.h` are deleted. The function's behavior - searching for a ref entry by name in a ref directory structure - is no longer needed with the new iterator-based approach. This cleanup helps maintain code hygiene by removing dead code that could otherwise confuse future maintainers.

The removal is low-risk as it was verified the function isn't called anywhere in the codebase. This is a typical follow-up to API modernization, where old helper functions become unnecessary after core infrastructure changes. The patch fits naturally into the series' goal of refining the ref iteration internals.
