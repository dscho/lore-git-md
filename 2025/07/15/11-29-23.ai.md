Refactoring patch in the ongoing ODB abstraction series, eliminating the last remaining global MIDX list usage in `get_all_packs()`. This is the 6th of 7 patches in v2 of Patrick Steinhardt's series to move MIDX tracking from global state to per-source storage in `struct odb_source`.

The patch converts `get_all_packs()` to iterate through object database sources rather than the global MIDX linked list. It leverages the existing `prepare_packed_git()` call which already populates all necessary data structures, including the per-source MIDX pointers. The key changes are:
- Removes direct iteration over `r->objects->multi_pack_index`
- Adds iteration through `r->objects->sources` instead
- Checks each source's `midx` pointer directly
- Maintains the same pack preparation logic but with source-local MIDX access

This change is straightforward (11-line diff) and builds on the infrastructure established in earlier patches. It demonstrates the benefits of the refactoring by simplifying the code path while maintaining identical functionality. The patch follows the established pattern of the series and has already incorporated review feedback from Taylor Blau and Justin Tobler on earlier versions.

This leaves just one more patch in the series to complete the global MIDX list removal by deleting the now-unused infrastructure. The changes are well-contained and focused, with no behavioral changes expected.
