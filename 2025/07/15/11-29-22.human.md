This is part 5 of Patrick Steinhardt's 7-patch refactoring series moving MIDX (multi-pack index) tracking from global state to per-source storage in `struct odb_source`. The series is now in its second version after incorporating review feedback.

The patch simplifies `find_pack_entry()` by removing its dependency on the global MIDX linked list. The key insight here is that `prepare_packed_git()` already handles the necessary setup, so the function can work directly with the source structures without additional preparation.

The changes are straightforward - replacing the MIDX list iteration with a source iteration that checks each source's MIDX pointer. The diff shows the function becoming slightly simpler by removing the redundant MIDX list check and consolidating the lookup logic. This continues the series' trend of eliminating global state while maintaining the same behavior.
