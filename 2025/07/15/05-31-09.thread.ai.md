Thread summary:

The thread originated with a bug report about `pull.autostash` not working in bare repositories. Bryan Lee identified the root cause - `pull.autostash` is not a valid configuration option (the correct setting is `rebase.autoStash`). This revealed a broader issue where Git silently accepts invalid configuration keys without warnings. Bryan provided test cases demonstrating this behavior and proposed two solutions: 1) adding warnings for invalid config keys, or 2) documenting common misconfigurations like `pull.autostash` in the git-config man page. The discussion has expanded from the initial bug report to examine Git's configuration validation behavior more generally. Key technical details include the specific config options involved (`pull.autostash` vs `rebase.autoStash`) and the silent acceptance of invalid keys. The open question is whether to implement validation or just better documentation for common mistakes. Bryan Lee is the primary contributor so far.
