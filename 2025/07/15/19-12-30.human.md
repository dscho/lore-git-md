This is the final patch in a series optimizing byte-swapping operations in Git's codebase, focusing on compiler-builtin optimizations. The patch reintroduces support for using compiler built-in functions (`__builtin_bswap32/64`) when available, which can generate more efficient code on certain architectures like RISC-V and MIPS that don't have native byte-swap instructions.

The change builds on previous work (commit 6547d1c9) and makes the bswap macros unconditional to avoid regressions on big-endian systems. It includes a fallback for older compilers that don't support the `__has_builtin` check. The implementation is clean and maintains compatibility while potentially improving performance on affected architectures.
