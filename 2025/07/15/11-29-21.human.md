Refactoring patch in the ODB abstraction series, focusing on MIDX handling. This is patch 4/7 in Patrick Steinhardt's series to move multi-pack index (MIDX) tracking from global state to per-source storage in `struct odb_source`. The patch refactors `get_multi_pack_index()` to operate on individual object database sources rather than returning a global linked list. 

Key changes include:
- Callers now need to explicitly iterate through object sources and check each one's MIDX
- The function signature changes to take a `struct odb_source*` instead of a repository
- Several call sites are updated to handle the new iteration pattern, including in pack-objects, repack, and bitmap code
- The patch maintains existing behavior while removing global MIDX infrastructure

The changes are part of a larger effort to abstract object database access, making the code more suitable for pluggable backends. The patch appears well-constructed, with thorough test coverage and clean integration into the existing series. Reviewers Taylor Blau and Justin Tobler have already provided positive feedback on earlier versions.
