Build system fix for Meson installation paths. This is the first of two patches from Ramsay Jones addressing regressions in the Meson build system. It fixes a critical installation issue where Git commands would fail to execute when built with a custom `-Dlibexecdir` path. The problem occurred because while commit 837f637cf5 properly set `GIT_EXEC_PATH` during build, it didn't update the actual installation paths for executables, causing commands like `git daemon` to fail with "not a git command" errors.

The patch systematically updates all installation paths in `meson.build` to use the precomputed `git_exec_path` variable instead of hardcoding `libexecdir/git-core`. This affects core Git commands, helper executables (daemon, shell, http-backend), remote helpers, Perl/Python scripts, and mergetools. The changes maintain backward compatibility with Meson versions before 1.3.0 while ensuring consistent path handling.

This resolves a reported regression where installations with non-standard libexecdir locations were broken. The fix is straightforward - replacing all instances of the old path calculation with the centralized `git_exec_path` variable. The patch demonstrates careful attention to detail by updating both direct executable installations and symlink creation paths throughout the build system.
