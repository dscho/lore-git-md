Refactoring patch removing obsolete code from the refs subsystem.

This is part 2 of a 4-part series adding pagination support to `git for-each-ref`. The patch removes the unused `find_ref_entry()` function from the ref-cache implementation, which was made obsolete by a 2017 change (ba1c052f). The function had no remaining callers in the codebase.

Junio C Hamano notes in his reply that this cleanup is "long overdue", indicating this is a straightforward removal of dead code. The patch deletes 21 lines across two files - both the implementation in ref-cache.c and its declaration in ref-cache.h. The removal is clean and doesn't affect any other functionality since the function wasn't being used.

This is a minor but sensible cleanup that's part of a larger refactoring effort to support pagination in ref iteration. The change is uncontroversial and has already been merged as part of the complete series.
