This is a feature patch adding shallow repository detection to the `git repo info` command hierarchy, part of Lucas Seiki Oshiro's GSoC project. It introduces a new `layout.shallow` field that reports whether the repository is shallow, following the same pattern as the previously added `layout.bare` field.

The implementation leverages Git's existing `is_repository_shallow()` function from shallow.h, using the same table-driven callback system established in earlier patches. The patch maintains consistency with the series' architectural decisions by using the null-terminated output format and integrating with the field registration system. Test coverage includes both shallow and non-shallow repository cases, plus verification that multiple fields can be queried together.

Key technical details include the new `add_layout_shallow()` callback function, its registration in the `repo_info_fields` table (maintaining lexicographical order), and the test cases that create an actual shallow clone to verify the functionality. The implementation follows the same patterns as the bare repository detection added in earlier patches, demonstrating the extensibility of the field system.
