This is Junio C Hamano's regular "What's cooking in git.git" status update, covering recent developments in the Git project as of July 2025. These updates provide a snapshot of which patches are progressing through the integration branches ('next' and 'seen') and which are being considered for the next release.

Several notable changes have graduated to 'master' (meaning they'll be in the next release), including:
- A fix for `git prune` to stop depending on `the_repository` global (part of the ongoing effort to remove this singleton)
- FreeBSD build improvements dropping support for very old versions
- Corrected behavior for negative-only diff filters in `git log`
- The reftable backend becoming the default for new repositories in Git 3.0
- Various documentation fixes and test improvements

New topics under consideration include:
- A workaround for Amazon Linux 2's ctype.h behavior
- macOS build fixes related to PCRE2
- GPG program pathname expansion support
- Proposals to officially adopt C99 bool type and compound literals
- A new `git last-modified` command proposal to show when files were last changed

Ongoing work includes:
- Continued efforts to remove `the_repository` dependencies
- Multi-pack-index API improvements
- Sparse checkout variable cleanup
- Faster `--prune` operation for dangling refs
- SHA-256 becoming the default hash algorithm in "breaking changes" mode
- Various documentation updates and test reorganizations

The email provides the usual repository locations and reminds contributors about the branch workflow (with 'next' being stable candidates and 'seen' being more experimental). Several topics are noted as needing rerolls or awaiting responses, showing the active discussion and iteration happening on the list.
