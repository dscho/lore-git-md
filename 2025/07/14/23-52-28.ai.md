This is the first patch in a v4 series introducing a new `git repo` command hierarchy, specifically focusing on the initial `info` subcommand. The patch establishes the basic infrastructure for the new command, including documentation and build system integration.

The patch creates a new `git repo` command that will serve as a home for repository metadata and metrics, moving functionality currently scattered in `git rev-parse` to a more appropriate location. The initial subcommand `git repo info` is declared with a minimal implementation that currently does nothing (returns 0), with the actual functionality to be added in subsequent patches. The output format is specified as machine-readable null-terminated key-value pairs (field<LF>value<NUL>).

Key technical elements introduced:
- New `builtin/repo.c` with command dispatch infrastructure
- Basic documentation in `git-repo.adoc` describing the command's purpose and output format
- Build system integration across Makefile, meson.build, and Documentation/meson.build
- Command registration in builtin.h, git.c, and command-list.txt
- .gitignore entry for the new binary

The patch follows the architectural decisions from the thread, particularly the consolidation under the `git repo` hierarchy and the null-terminated output format. It's part of a larger effort to reorganize repository interrogation commands, with future work expected to include a `git repo stats` subcommand based on Justin Tobler's git-survey work. The implementation appears clean and well-integrated with existing Git conventions.
