This is a discussion about PCRE2 dependency handling in the meson build system, particularly focusing on macOS compatibility issues. Carlo Arenas responds to brian m. carlson's suggestion to disable PCRE2 by default only on macOS rather than globally. While acknowledging the technical merits of platform-specific handling, Carlo expresses reservations about creating inconsistency with other build systems and suggests the root issue should be fixed by Apple or meson itself.

The exchange reveals deeper considerations about Git's regex engine future - while there was once a plan to standardize on PCRE2, progress has stalled. Carlo notes most Linux distributions already enable PCRE2 by default in their Git packages, raising the question of whether Git should follow suit despite the macOS complications. The thread shows active debate about balancing platform-specific workarounds with build system consistency and long-term technical direction.
