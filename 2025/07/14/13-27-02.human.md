This is the final patch in a refactoring series to standardize Git's predicate functions to use C99 `bool` return types. The patch converts string predicate functions in `strbuf.{c,h}` to return `bool` instead of `int`, matching the changes made to similar functions in `git-compat-util.h` in the previous patch.

The changes are purely mechanical type signature updates with no behavioral modifications, affecting four functions in `strbuf.c` and their declarations in `strbuf.h`. The patch completes the alignment of all string predicate utilities under the codebase's `bool` return type standard, following an 18-month experimental period that proved the approach in production.

This is a straightforward, low-risk change that follows Git's established pattern for gradually adopting C99 features. The series appears well-considered, with each patch building logically on the last to methodically update related groups of functions. The changes are clean and focused, touching only the necessary type signatures while maintaining all existing functionality.
