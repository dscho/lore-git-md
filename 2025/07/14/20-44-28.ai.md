This is a "What's cooking" status update from Junio C Hamano, summarizing the current state of Git development branches as of July 2025. The email provides a comprehensive overview of patches that have graduated to 'master', new topics under consideration, and ongoing work in various states of review.

Key highlights from the graduated patches include:
- Several `the_repository` removal efforts, including fixes to `git prune` and object-file subsystems
- Build system updates dropping FreeBSD 4 support and fixing BSD-specific memory calculations
- Documentation fixes and improvements to config and remote helpers
- A significant change making reftable the default ref backend in Git 3.0 when experimental features are enabled
- Various bugfixes around diff filters, index locking, and Coccinelle checks

New topics proposed include:
- Build fixes for Amazon Linux and macOS systems
- GPG program path expansion support
- Official adoption of C99 `bool` type in the codebase
- A new `git last-modified` command proposal
- Optimizations for changed-path filters with multiple pathspecs
- SHA-256 becoming the default hash algorithm in breaking changes mode

Ongoing work includes:
- Continued refactoring around object store and multi-pack-index handling
- Sparse checkout variable cleanup
- Rebase instruction format fixes
- Documentation modernization efforts
- Test suite improvements and reftable test framework migration

The email serves as both a status update and call for feedback on several proposed changes, particularly the C99 bool adoption, compound literal testing, and comment character deprecation. It also notes several topics awaiting rerolls or responses from contributors.
