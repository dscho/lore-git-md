This is a refactoring patch that completes the standardization of `bool` return types for string predicate functions in Git's codebase. It converts the case-insensitive variants `skip_iprefix()` and `skip_iprefix_mem()` to return `bool` rather than `int`, matching their case-sensitive counterparts that were converted in an earlier experimental phase.

The change is purely mechanical - updating type signatures and return values from `1`/`0` to `true`/`false` - with no behavioral modifications. Elijah Newren confirms the patch looks good while raising a minor question about hyphenation of "case independent/dependent" in the commit message. This follows Eric Sunshine's earlier typo corrections to the same message.

The patch is part of a 3-part series that formalizes Git's use of C99 `bool` for predicate functions after 18 months of successful production use. With Junio C Hamano having already approved the documentation update (patch 1/3), this represents the final technical implementation work to align all string utility functions with the new standard. The changes are low-risk as they build on established precedent and maintain identical runtime behavior.
