Bugfix addressing path expansion in GPG configuration, part of an ongoing discussion about `gpg.program` behavior.

Junio Hamano responds to Jonas Brandstötter's patch that enables tilde expansion for `gpg.program` paths. The change is straightforward - switching from `git_config_string()` to `git_config_pathname()` in the configuration parser, plus a minor documentation update to clarify the setting expects a pathname. 

Junio notes the patch is technically correct and particularly appreciates the documentation improvement. However, he raises a valid concern about test coverage, suggesting this new behavior should be protected by tests to prevent accidental regression. This comes in the context of a broader thread where the Git maintainer has acknowledged deeper issues with how Git handles GPG program configuration (both path expansion and argument parsing).

The patch represents one piece of the puzzle in resolving the `gpg.program` behavior, focusing specifically on the path expansion aspect while the command-line argument handling questions remain open. Junio's response indicates this change is likely to be accepted, though he's signaling the need for tests before finalizing.
