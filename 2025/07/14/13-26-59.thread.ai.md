Refactoring series to standardize use of C99 `bool` type for predicate functions in Git's codebase, following an 18-month experimental period that began with commit 8277dbe987 in December 2023. Series consists of 3 patches:

1. Updates Documentation/CodingGuidelines to explicitly permit `bool` usage for predicate functions (3 lines added), positioning this as formalizing existing practice after successful production use. References the original test commit and follows Git's incremental C99 adoption pattern. Junio C Hamano confirmed acceptance of Phillip Wood's patch, providing historical context comparing this to Git's pattern for gradually incorporating C99 features (dynamic initializer elements, enum trailing commas, designated initializers, variadic macros, for-loop variable declarations). The 18-month timeframe aligns with previous feature adoptions.

2. Converts core string utility functions in `git-compat-util.h` (e.g. `skip_prefix()`, `starts_with()`, `skip_iprefix()`, `skip_iprefix_mem()`) from `int` to `bool` returns. The case-insensitive variants (`skip_iprefix*`) are newly converted in this version, aligning with their case-sensitive counterparts from the experimental period. Changes are mechanical type signature updates (6 lines per function) with no behavioral modifications.

3. Completes the conversion by updating `strbuf` predicate methods in `strbuf.[ch]`, affecting four functions in `strbuf.c` (`starts_with`, `istarts_with`, `starts_with_mem`, `skip_to_optional_arg_default`) and their declarations in `strbuf.h`, plus two inline helpers (`skip_to_optional_arg`, `ends_with`). All return values changed from `1`/`0` to `true`/`false` literals while maintaining identical runtime behavior.

Technical scope:
- Changes limited to type signatures in headers/implementations (4 files total)
- No behavioral modifications - pure refactoring
- Affects 29 insertions and 26 deletions across:
  * `Documentation/CodingGuidelines` (now with Junio's approval)
  * `git-compat-util.h` (all string predicate variants)
  * `strbuf.h`
  * `strbuf.c`

Series builds on established precedent with 18 months of incident-free use in production. Junio has confirmed the documentation patch will be queued, representing the final step in standardizing `bool` usage. The change formalizes what has already been proven safe through production use, completing the standardization effort following Git's pattern for gradual C99 feature incorporation.
