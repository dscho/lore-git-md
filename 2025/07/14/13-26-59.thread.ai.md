Refactoring series to standardize use of C99 `bool` type for predicate functions in Git's codebase, following an 18-month experimental period that began with commit 8277dbe987 in December 2023. Series consists of 3 patches with cover letter, authored by Phillip Wood and now fully reviewed by Elijah Newren, with prior acceptance from Junio C Hamano for the documentation changes.

Core changes convert string utilities in `git-compat-util.h` (`skip_prefix()`, `starts_with()`, and case-insensitive variants) and `strbuf` predicate methods (`starts_with`, `istarts_with`, `ends_with` etc.) from `int` to `bool` returns (29 insertions, 26 deletions across 4 files). All changes are mechanical type signature updates with no behavioral impact, following Git's pattern for gradual C99 feature adoption.

Documentation updates in CodingGuidelines explicitly permit `bool` for predicate functions, formalizing 18 months of production use. Style questions about hyphenation ("case-dependent" vs "case independent") were resolved with input from Eric Sunshine (typo fixes) and Brian m. carlson (Chicago Manual of Style guidance).

Randall S. Becker raises a new technical concern about `<stdbool.h>` inclusion requirements on some C99 implementations, particularly for platforms with non-standard compliance. This is the first mention of header inclusion in the thread and may require verification across Git's support matrix, though no specific platform failures are cited. The concern doesn't oppose the series' direction (already acked by Elijah Newren) but flags a portability consideration.
