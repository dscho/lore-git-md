This is Junio C Hamano's regular "What's cooking in git.git" status update, covering recent changes in the Git development tree as of July 2025. These updates help track the progress of patches through the integration branches.

The email lists several topics that have recently graduated to 'master', including:
- A fix for `git prune` to stop depending on `the_repository` global (part of the ongoing effort to remove this singleton)
- FreeBSD build system updates dropping support for very old versions
- Various documentation fixes and improvements
- A correction for BSD systems' RAM detection in `git gc`
- The long-awaited switch to make reftable the default ref backend in Git 3.0

New topics being proposed include:
- A workaround for Amazon Linux 2's ctype.h behavior
- macOS build fixes related to PCRE2
- GPG program path expansion improvements
- Two experimental proposals from Phillip Wood about using C99 bool type and compound literals in the codebase

Several significant ongoing efforts are still cooking:
- Multiple branches continuing the `the_repository` removal work
- MIDX (multi-pack-index) improvements and refactoring
- A new `git last-modified` command proposal
- Optimizations for changed-path filters with multiple pathspecs
- The transition to SHA-256 as the default hash algorithm

The email follows Junio's standard format, grouping changes by their integration branch status and providing source links for each patch series. It's a comprehensive snapshot of Git's development activity, showing both incremental improvements and larger architectural changes in progress.
