This is the foundational patch for a new `git repo` command hierarchy, part of Lucas Seiki Oshiro's GSoC project to reorganize repository metadata access. The patch establishes the basic command structure, moving functionality that currently lives in `git rev-parse` into a more appropriate home.

The patch creates the new `git repo` command with an initial `info` subcommand, which will handle repository metadata queries. The output format is standardized as null-terminated key-value pairs (field<LF>value<NUL>), matching Git's existing conventions. The implementation includes all the necessary plumbing: build system integration, command registration, documentation stubs, and a basic subcommand dispatcher.

This is patch 1/8 in a v4 series that has seen significant architectural discussion, with mentors and reviewers converging on the hierarchical `git repo` namespace approach. The patch appears well-structured, with thorough build system integration and clear documentation of the experimental nature of the new command. The implementation follows Git's standard patterns for command registration and subcommand handling.
