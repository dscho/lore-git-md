This is a final review comment on the already-merged signature handling improvements for `fast-export`/`fast-import`. Elijah Newren notes that the technical implementation looks solid but raises a minor stylistic concern about test formatting. The patch series has already standardized signature handling with a "gpgsig <hash-algo> <format>" output format and added comprehensive test coverage for OpenPGP, X.509, and SSH signatures.

Elijah points out that two new tests follow an existing (but rare) pattern of placing the input redirection (`<output`) at the end of a subshell block rather than directly after the `git fast-import` command that consumes it. While he considers this an "eyesore," he acknowledges this matches existing test style and doesn't block merging, offering to propose a separate cleanup later. The comment comes as an afterthought on the now-complete feature rather than requesting changes.
