Refactoring patch converting string utility functions to use `bool` return types. This is part 2 of a 3-patch series standardizing predicate function return types across Git's codebase, following an 18-month experimental period that began in December 2023.

Phillip Wood updates two case-insensitive string prefix checking functions in `git-compat-util.h` - `skip_iprefix()` and `skip_iprefix_mem()` - to return `bool` instead of `int`. This matches the return type already used by their case-sensitive counterparts, making it clearer these are predicate functions. The changes are purely mechanical - replacing `1`/`0` returns with `true`/`false` - with no behavior modifications.

This continues the series that began with updating coding guidelines to permit `bool` usage, and will conclude with similar changes to `strbuf` methods. The approach follows Git's established pattern for gradually adopting C99 features, building on successful production use of the initial `bool` conversions. The patch is straightforward and low-risk, with clear precedent from the earlier experimental changes.
