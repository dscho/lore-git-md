Final patch in a refactoring series standardizing predicate functions to use C99 `bool` return types, focusing on `strbuf` utility functions. This completes the alignment started in earlier patches by converting all string predicate functions in `strbuf.[ch]` from `int` to `bool` returns.

The changes are mechanical type signature updates affecting four functions in `strbuf.c` (`starts_with`, `istarts_with`, `starts_with_mem`, `skip_to_optional_arg_default`) and their declarations in `strbuf.h`, plus two inline helpers (`skip_to_optional_arg`, `ends_with`). All return values are changed from `1`/`0` to `true`/`false` literals. The patch follows the same pattern established in the previous conversion of core string utilities in `git-compat-util.h`.

This is a straightforward continuation of the series' goal to formalize `bool` usage after 18 months of successful experimental use. The changes to behavior or logic - only type signatures and return value literals are modified. The patch maintains perfect symmetry with the earlier conversions, completing the standardization across Git's string utility functions. No new test coverage is needed as this is purely a type system change with identical runtime behavior.
