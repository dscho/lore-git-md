Classification: Documentation update for C99 `bool` adoption

This email from Junio C Hamano confirms the acceptance of Phillip Wood's patch to formally document the use of C99 `bool` type in Git's codebase. The patch adds a 3-line note to Documentation/CodingGuidelines, marking the successful conclusion of an 18-month experimental period that began with commit 8277dbe987 in December 2023.

Junio provides historical context by comparing this adoption to Git's pattern for gradually incorporating C99 features, listing several other C99 features that went through similar experimental periods before being documented in the guidelines. These include dynamic initializer elements (2b6854c8), enum trailing commas (e1327023), designated initializers (cbc0f81d), variadic macros (765dc168), and for-loop variable declarations (44ba10d6). The 18-month timeframe aligns with previous feature adoptions.

The email indicates this patch will be queued, confirming the series' acceptance. This represents the final step in standardizing `bool` usage for predicate functions across Git's codebase, following the mechanical conversions of string utility functions in git-compat-util.h and strbuf methods in the subsequent patches. The change is purely documentation with no code impact, formalizing what has already been proven safe through production use.
