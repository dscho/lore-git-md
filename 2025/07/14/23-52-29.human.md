Feature implementation for the new `git repo info` subcommand. This is patch 2/4 in the v4 series introducing repository metadata querying capabilities.

The patch adds support for reporting the reference storage format (either "files" or "reftable") via a new `references.format` field. It implements this by leveraging the existing `--show-ref-format` flag from `git-rev-parse`. The implementation includes:

1. A table-driven field system with callback functions for different metadata types
2. Proper null-terminated output formatting (matching the series' design decision)
3. Comprehensive tests verifying both files and reftable formats
4. Documentation updates describing the new field
5. Handling for duplicate key requests

The code follows Git's established patterns, with clear separation between the field registration system and output formatting. Test coverage is thorough, including edge cases like duplicate key requests. This appears to be a well-structured addition to the growing `git repo` command hierarchy, building on the architectural decisions established in earlier patches.
