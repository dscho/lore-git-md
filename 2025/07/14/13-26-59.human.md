This is a cover letter for a refactoring series that concludes an experiment with C99's `bool` type in Git's codebase. Phillip Wood proposes to officially adopt `bool` for string predicate functions after an 18-month trial period with no reported issues.

The series consists of three patches: first updating the CodingGuidelines to permit `bool` usage, then converting string predicate functions in `git-compat-util.h` to return `bool` instead of `int`, and finally doing the same for predicate functions in the strbuf` subsystem. The changes are mechanical conversions that don't alter behavior, just make the return types more semantically accurate.

The proposal appears well-considered, building on prior work from December 2023 that introduced `bool` experimentally. The changes are focused and the commit messages reference the original experiment, showing thoughtful progression. This seems like a straightforward quality-of-life improvement for the codebase that aligns with modern C practices.
