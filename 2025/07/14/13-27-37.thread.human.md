This thread established Git's policy on using C99 compound literals, with the reftable subsystem serving as a test case until 2026. Phillip Wood originally raised the question through a test patch examining `strbuf_init()` usage, while Patrick Steinhardt identified existing production usage in reftable (the `REFTABLE_FLOCK_INIT` and `REFTABLE_TMPFILE_INIT` macros). Junio C Hamano codified the project's conservative approach in the CodingGuidelines, documenting these as intentional test cases while placing a moratorium on wider usage.

The policy remains unchanged after Collin Funk's follow-up sharing positive experiences from Gnulib/Coreutils, where compound literals have been used since 2017 without issues, including support in the pcc compiler. While this provides encouraging evidence that the reftable test case is likely to succeed, Git will maintain its cautious timeline for evaluation. The thread is fully resolved with clear documentation in place, balancing technical evidence with the project's conservative approach to language feature adoption. All key contributors - Phillip, Patrick, and Junio - have approved the final policy.
