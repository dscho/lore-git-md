This thread established Git's policy on C99 compound literals through documentation update and review. It began with Phillip Wood examining `strbuf_init()` usage, then identified existing production usage in the reftable subsystem (`REFTABLE_FLOCK_INIT` and `REFTABLE_TMPFILE_INIT` macros from Git 2.50) that initialize structs with file descriptors set to -1 - a pattern originally spotted by Patrick Steinhardt.

Junio C Hamano has now finalized the project's position by committing a CodingGuidelines section that: (1) codifies these reftable macros as intentional test cases, (2) references commit v2.48.0-rc0~20, and (3) establishes a moratorium on additional compound literal usage until mid-2026 for platform compatibility evaluation. Patrick Steinhardt reviewed and approved this approach, while Phillip Wood confirmed the documentation's accuracy while noting surprise at being credited as Helped-by.

The documentation serves as clear contributor reference while preserving flexibility for future reconsideration based on monitoring the reftable usage - which remains the sole real-world test case until 2026. Key technical considerations around compiler compatibility, resource management patterns, and struct evolution remain documented for future evaluation. With Junio's update and both Patrick and Phillip's confirmations, this policy discussion is now fully resolved.
