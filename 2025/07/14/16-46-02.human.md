This is a refactoring patch that completes the standardization of `bool` return types for string predicate functions in Git's codebase. It converts the case-insensitive variants `skip_iprefix()` and `skip_iprefix_mem()` to return `bool` instead of `int`, matching their case-sensitive counterparts that were converted 18 months ago.

The change is purely mechanical - updating type signatures in `git-compat-util.h` while maintaining identical runtime functionality. Eric Sunshine provides minor typo corrections to Phillip Wood's commit message (fixing "sting" to "string" and grammar issues), but the technical content remains unchanged.

This patch is part of a 3-patch series that formalizes Git's use of C99 `bool` for predicate functions after successful production testing. The series has already received approval from Junio Hamano, with this middle patch aligning the remaining string utility functions with the established pattern. The changes are low-risk since they build on proven usage patterns and don't modify behavior.
