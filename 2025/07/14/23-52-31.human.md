This is a feature patch adding shallow repository detection to the new `git repo info` command hierarchy. It's part of a larger GSoC project to create a structured way to query repository metadata.

The patch introduces a new `layout.shallow` field that reports whether the repository is shallow (true/false), matching the behavior of `git rev-parse --is-shallow-repository`. The implementation reuses Git's existing `is_repository_shallow()` function and follows the established pattern for boolean fields to the command's output system.

The change includes thorough test coverage with cases for both shallow and non-shallow repositories, plus verification that the field works correctly when combined with other fields in the output. Documentation is updated to include the new field alongside the existing `layout.bare` field.

As part of the v4 series, this continues the project's clean architectural approach with table-driven field registration and maintains the null-terminated output format decision from earlier discussions. The patch has received input from multiple mentors and contributors, suggesting it's well-vetted within the development process.
