This thread documents the successful standardization of C99 `bool` type usage for predicate functions in Git's codebase, completing an 18-month experimental period that began in December 2023. Phillip Wood's patch series formalizes this practice by updating Documentation/CodingGuidelines to explicitly permit `bool` returns for predicates, following Git's established pattern for gradually adopting C99 features.

The series includes three mechanical conversions: first updating the coding guidelines, then converting core string utility functions in git-compat-util.h, and finally updating strbuf predicate methods. All changes maintain identical runtime behavior while standardizing the return types. Junio C Hamano has now accepted the documentation patch, noting this follows the same incremental adoption used for other C99 features like dynamic initializers and variadic macros. With no objections raised during the experimental period and all technical conversions complete, this change represents a low-risk standardization of existing practice across Git codebase.
