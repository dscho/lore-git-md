This thread documents the final steps in standardizing the use of C99 `bool` return types for predicate functions across Git's codebase, following an 18-month experimental period that began in December 2023. The three-patch series, authored by Phillip Wood, first updates the coding guidelines to formally permit this practice (already approved by Junio Hamano), then mechanically converts string utility functions, and finally updates strbuf predicate methods.

The second patch, which converts case-insensitive string prefix functions like `skip_iprefix()` to return `bool`, received minor typo fixes from Eric Sunshine during review. His feedback was limited to correcting two small wording issues in the commit message ("sting" -> "string" and "lets" -> "let's") and suggesting a slight clarification about the type change. The changes themselves are straightforward signature updates that don't affect runtime behavior, continuing Git's pattern of gradual C99 feature adoption.

With Junio's prior approval of the documentation changes and the mechanical nature of the remaining conversions, this series represents a well-vetted cleanup that formalizes what has already been proven safe through extensive production use. The changes affect only type signatures across four files, making predicate functions more semantically clear through proper use of the boolean type.
