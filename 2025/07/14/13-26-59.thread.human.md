This thread documents and implements the standardization of C99 `bool` type usage for predicate functions in Git's codebase, following an 18-month experimental period that began in December 2023. The series consists of three patches, starting with this documentation update to `Documentation/CodingGuidelines` that formally permits `bool` usage, matching Git's historical pattern for gradually adopting C99 features like dynamic initializers.

Junio C Hamano has already accepted this change, which serves as the policy foundation for the subsequent mechanical conversions. The second patch updates core string utilities in `git-compat-util.h` (including case-insensitive variants), while the third handles `strbuf` predicate methods. All changes maintain identical runtime behavior while switching from `1`/`0` to `true`/`false`.

Reviewers including Eric Sunshine, Elijah Newren, and brian m. carlson have provided feedback on technical correctness, documentation wording, and style guidance - all of which has been incorporated. The changes demonstrate Git's careful approach to even mechanical refactorings, ensuring both code quality and clear documentation of new standards. With Junio's acceptance and all reviewer feedback addressed, this series appears ready for merging as a straightforward standardization of established practice.
