This thread documents the conclusion of an 18-month effort to standardize Git's function signatures to use C99 `bool` for predicate functions. Phillip Wood's 3-patch series updates the CodingGuidelines to permit `bool` usage and converts several key string comparison functions (`skip_iprefix()`, `starts_with()`, etc.) from `int` to `bool` returns. The changes are purely mechanical - affecting 20 lines across 4 files - with no behavioral impact.

The series received thorough review from multiple core contributors: Elijah Newren verified the approach, Eric Sunshine caught typos, Brian m. carlson provided style guidance, and Junio Hamano confirmed the semantic rationale. The last remaining issue - a parameter alignment nit in `skip_to_optional_arg_default()` identified by Karthik Nayak - has now been resolved. Karthik's latest email jokingly suggests ignoring his earlier style complaints, signaling all technical concerns have been addressed to everyone's satisfaction.

With final acks from key maintainers and all review feedback incorporated, this long-running standardization effort is now complete and ready for merging into Git's codebase. The changes formalize production use of `bool` for predicates that began experimentally in December 2023 with commit 8277dbe987.
