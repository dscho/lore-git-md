This thread documents the completion of a multi-year effort to standardize the use of C99's `bool` type for predicate functions in Git's codebase. The work began with experimental adoption in December 2023 and has now been formally accepted after 18 months of incident-free production use, following Git's conservative approach to language feature adoption.

The three-patch series first updated Documentation/CodingGuidelines to permit `bool` usage (already accepted by Junio), then converted string utilities in git-compat-util.h, and now completes the effort by updating strbuf predicate methods. All changes are mechanical type signature updates (from `int` to `bool` returns) with no behavioral impact, affecting functions like `starts_with()`, `skip_prefix()`, and their case-insensitive variants. 

The work received thorough review from multiple contributors: Eric Sunshine caught typos and improved wording, Elijah Newren verified technical correctness, and brian m. carlson provided style guidance on hyphenation in documentation. With this final strbuf conversion, the standardization effort is complete, demonstrating Git's attention to both technical correctness and documentation quality even for mechanical changes. The changes build on established precedent, matching Git's pattern for gradual C99 feature adoption seen with dynamic initializers and enum trailing commas.
