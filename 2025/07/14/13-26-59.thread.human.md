This thread documents the final steps in standardizing Git's use of C99 `bool` for predicate functions, following an 18-month experimental period. The three-patch series updates documentation to formally permit this usage (already approved by Junio) and mechanically converts string utility and strbuf` functions to return `bool` instead of `int` with no behavior changes. 

The latest discussion centers on a minor style question from Elijah Newren about hyphenating "case independent" in commit messages, with brian m. carlson providing a Chicago Manual of Style reference recommending "case-dependent" before nouns but not after. This came up during review of patch 2/3, which aligns case-insensitive string functions (`skip_iprefix` etc.) with their already-converted case-sensitive counterparts. 

The series has received positive reviews from Eric Sunshine (who caught some typos) and Elijah Newren, with Junio having already approved the documentation changes. The hyphenation discussion represents final polish on an otherwise complete effort that follows Git's established pattern for gradually adopting C99 features after proving them in production.
