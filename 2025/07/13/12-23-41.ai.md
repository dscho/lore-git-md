Build system patch modifying PCRE2 dependency configuration in meson, specifically targeting macOS compatibility issues. This v2 revision introduces platform-specific handling where PCRE2 is auto-disabled on macOS by default unless explicitly enabled via a new `macos_workaround_system_pcre2` option. The change aligns meson's behavior more closely with the Makefile's opt-in model for PCRE2 while addressing the specific macOS case where the system-provided PCRE2 is broken (missing headers despite appearing available).

Key technical details: The patch adds conditional logic in meson.build that checks for macOS (`darwin`) and the new workaround flag before deciding whether to require PCRE2. The meson_options.txt change switches PCRE2 from 'enabled' to 'auto' as the global default. The new `macos_workaround_system_pcre2` boolean option provides an escape hatch for users who have installed a working PCRE2 via alternative means (Homebrew, manual compilation) or are forcing the pcre2 wrap.

This builds on the ongoing thread discussion about whether to implement platform-specific defaults versus a blanket disable. The commit message explains the macOS-specific failure mode (pkgconf pointing to non-existent headers) and mentions two workaround scenarios: proper PCRE2 installation or using meson's fallback mechanism.
