Build system patch review from Junio C Hamano. This is part of the ongoing meson build system changes to handle PCRE2 dependencies, specifically addressing macOS compatibility issues where the system-provided PCRE2 is broken. The maintainer is reviewing Carlo Marcelo Arenas Belón's v2 patch that introduces platform-specific handling for PCRE2 on macOS.

Junio notes confusion about the term "wrap" used in the patch's description and option documentation. The patch itself changes the default PCRE2 behavior to auto-disable on macOS unless explicitly enabled via a new `macos_workaround_system_pcre2` option, while changing the global default from 'enabled' to 'auto'. This aligns meson's behavior more closely with the Makefile's opt-in approach while handling the macOS-specific case where system PCRE2 is present but unusable.

The maintainer's feedback is narrowly focused on improving the clarity of the documentation around the new option, specifically requesting clarification of the term "wrap" which appears to refer to meson's fallback dependency handling mechanism. This suggests the technical approach in the patch is acceptable but needs better explanation for future maintainers and users.
