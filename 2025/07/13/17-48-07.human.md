This is a build system patch addressing PCRE2 dependency handling in the meson build, specifically for macOS. It's version 3 of a series that aligns meson build behavior with the Makefile's opt-in approach for PCRE2, while handling macOS's problematic system-provided PCRE2 library.

The patch makes two key changes: first, it switches the default PCRE2 setting from 'enabled' to 'auto' globally. Second, it adds platform-specific logic to automatically disable PCRE2 on macOS unless the user explicitly enables it via a new `macos_workaround_system_pcre2` option. This matches the Makefile's behavior where PCRE2 must be explicitly requested.

The motivation is macOS's broken system PCRE2 installation, which provides a pkgconf module pointing to non-existent headers. The solution allows users to either install a working PCRE2 (via Homebrew or subprojects) or explicitly opt-in to trying the broken system version. The patch appears well-considered, building on previous discussion about platform-specific handling while maintaining functionality on Linux.
