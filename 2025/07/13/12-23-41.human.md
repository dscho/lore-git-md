Build system patch addressing PCRE2 dependency handling in macOS. This v2 revision modifies the meson build configuration to automatically disable PCRE2 detection on macOS by default, while keeping it as an opt-in feature via a new `macos_workaround_system_pcre2` option. The change addresses a specific issue where macOS ships with a broken PCRE2 installation that passes initial checks but fails during actual builds due to missing headers.

The patch aligns meson's behavior more closely with Git's Makefile, where PCRE2 is opt-in via USE_LIBPCRE2. However, it takes a more sophisticated approach than the initial proposal by introducing platform-specific logic rather than a blanket disable. Users can still enable PCRE2 on macOS either by installing a working version (which should appear earlier in PKG_CONFIG_PATH) or by explicitly opting in via the new workaround flag.

The implementation touches both the core meson.build logic and meson_options.txt, adding the new macOS-specific toggle while changing the base pcre2 option from 'enabled' to 'auto'. This appears to be a well-considered solution to the immediate macOS problem while leaving the door open for future platform-specific handling approaches. The patch builds on prior discussion about build system consistency but doesn't yet address the broader question of whether Linux should maintain PCRE2-by-default behavior.
