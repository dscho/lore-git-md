This is a build system patch addressing PCRE2 dependency handling in the meson build, specifically targeting macOS compatibility issues. It's version 3 of a series that has been iterating on platform-specific PCRE2 configuration.

The patch makes two key modifications: first, it changes the default PCRE2 setting from 'enabled' to 'auto' globally, better aligning with the Makefile's opt-in model. Second, it introduces platform-specific logic that automatically disables PCRE2 on macOS (darwin) unless the new `macos_workaround_system_pcre2` option is explicitly enabled. This addresses the core problem where macOS's system-provided PCRE2 appears available but is actually broken due to missing headers.

The implementation uses meson's `disable_auto_if()` to conditionally disable PCRE2 on macOS by default, while maintaining the ability to force-enable PCRE2 when a working version is available (either via Homebrew, manual installation, or meson's subproject fallback mechanism). The changes preserve PCRE2 functionality for `git grep --perl-regexp` when properly configured on all platforms.

This version appears to incorporate feedback from previous iterations, particularly around maintaining PCRE2-by-default on Linux while only disabling it on problematic platforms like macOS. The solution is narrowly targeted at the specific macOS system PCRE2 issue while minimizing impact on other platforms. The patch maintains the existing build infrastructure's static linking preference for PCRE2 via `default_library=static`.

The technical changes are focused in meson.build (adding the platform condition) and meson_options.txt (adding the new macOS-specific toggle and changing the global default). The commit message could benefit from explicitly mentioning this is v3 and summarizing changes from v2, but the code changes appear well-contained and properly motivated by the macOS compatibility problem.
