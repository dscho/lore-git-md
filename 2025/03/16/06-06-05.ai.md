Build system fix addressing Perl detection in Meson configuration. This patch corrects an issue where building documentation (man pages) would fail when Perl bindings were explicitly disabled (`-Dperl=disabled`) but documentation was enabled (`-Ddocs=man`). The problem occurs because the Meson build system wasn't properly checking for Perl as a required dependency when documentation generation was requested, despite documentation tools relying on Perl.

The fix adds documentation building to the list of cases that require Perl availability, alongside existing requirements for tests, gitweb, and credential helpers. The change is minimal - a single line modification to `meson.build` that expands the condition checking when Perl becomes mandatory. The patch includes a real-world error message from Gentoo's bug tracker showing the failure case this fixes.

This appears to be a straightforward and correct fix for a specific build configuration edge case. The change is appropriately scoped and doesn't appear to introduce any new issues or side effects.
