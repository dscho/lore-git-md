This is a feature patch for gitk, adding a new option to hide prefetch refs. The patch comes from Tal Kelrich with Johannes Schindelin providing maintainer visibility.

The change addresses visual clutter in repositories with many branches by adding a checkbox in gitk's preferences to hide refs created by the maintenance prefetch task (those under "prefetch/*"). The option is enabled by default, following the same pattern as the existing "Hide remote refs" option.

The implementation adds the new `hideprefetch` variable throughout gitk's Tcl code, mirroring how `hideremotes` is handled. When toggled, it triggers a refs reread just like the remote refs option does. The patch appears cleanly implemented with all necessary plumbing changes.

This seems like a straightforward quality-of-life improvement for users of large repositories where prefetch refs can dominate the display. The patch is now in its third iteration and appears ready for consideration by the gitk maintainer.
