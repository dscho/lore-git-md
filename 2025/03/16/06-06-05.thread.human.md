This thread addresses a build system issue where the Meson configuration wasn't properly enforcing Perl as a dependency when building documentation (man pages), even when Perl bindings were explicitly disabled. The problem manifested in Gentoo builds where documentation generation would fail in this configuration.

The fix is straightforward - a one-line change to `meson.build` that adds documentation building to the conditions that require Perl availability. The patch includes a clear explanation of the issue and references the Gentoo bug report that uncovered it. This appears to be a well-scoped, correct fix for a specific build configuration edge case.
