This thread addresses a build system edge case where documentation generation would fail when Perl bindings were explicitly disabled (`-Dperl=disabled`) while documentation was enabled (`-Ddocs=man`), since documentation tools rely on Perl. The original patch, referencing a real-world Gentoo build failure, added documentation building to the conditions that enforce Perl as mandatory in `meson.build`.

Patrick Steinhardt has now reviewed and agreed with the solution, noting it correctly handles the immediate issue. He points out that this is currently the only remaining Perl dependency in the build system, and suggests that eliminating this dependency would be a worthwhile long-term goal. However, he accepts the current pragmatic fix as appropriate for the specific configuration problem at hand. The discussion remains tightly focused on this build system detail without expanding scope.
