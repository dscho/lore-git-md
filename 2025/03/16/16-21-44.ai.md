This is a bugfix patch for gitk's external diff functionality, part of an ongoing thread about handling renamed files. The patch (v3 in the series) fixes gitk's inability to properly locate renamed files when launching external diffs, regardless of whether the original or renamed file is selected in the UI. The technical solution involves parsing "rename from/to" markers from diff output using Tcl/Tk text widget regex searches to correctly identify both file versions. The implementation has evolved through three versions, with v3 dropping an earlier experimental GUI toggle and focusing purely on the path resolution logic.
