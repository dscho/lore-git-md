Follow-up in git-gui comment character thread.

Oswald Buddenhagen agrees with Johannes Sixt's suggestion to remove the visual indicator showing the active comment character in git-gui's commit message interface. This was the last open question in the thread - the core functionality of properly handling configurable comment characters had already been approved. 

The patch author confirms the UI element (which displayed text like "(Lines starting with '#' will be discarded)") can be dropped during application, as both parties had acknowledged it looked messy. This resolves the final point of discussion, clearing the way for the patch to be applied without this visual cue while maintaining all the important backend changes to respect core.commentChar/commentString configurations.
