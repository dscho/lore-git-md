Platform compatibility follow-up on CSPRNG configuration. This email from Ramsay Jones responds to Brian Carlson's technical clarification about Linux's arc4random implementation being merely a getrandom() wrapper, unlike BSD's fork-safe userspace version. Jones confirms through code inspection that glibc's arc4random_buf() does indeed wrap getrandom(), though questions the claimed performance overhead. The email notes Cygwin's different implementation (OpenBSD-derived with ChaCha20) and concludes the meson build system should be updated to prefer getrandom() on Linux, dropping the original documentation patch. This aligns with the thread's consensus that getrandom() is the better default for Linux systems. The discussion remains technical and collegial, with Jones acknowledging the need to adjust both meson and autoconf configurations.
