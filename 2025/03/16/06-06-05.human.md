This is a bugfix for the Meson build system affecting documentation generation when Perl bindings are disabled.

The patch addresses a specific build configuration scenario where documentation is enabled (`-Ddocs=man`) but Perl bindings are explicitly disabled (`-Dperl=disabled`). Currently this combination fails because the build system doesn't properly account for Perl being needed for manpage generation even when Perl bindings aren't being built.

The fix is straightforward - it adds documentation generation to the list of features that require Perl availability in the Meson configuration. The change is minimal (a one-line addition to meson.build) and comes with a clear reproduction case showing the error message that occurs without the patch. The bug was originally reported in Gentoo's bug tracker, suggesting this is a real-world issue affecting at least some users.
