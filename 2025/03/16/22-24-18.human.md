Platform compatibility patch discussing a Cygwin regex test case. This is part 6 of a 12-part series modernizing Cygwin-specific workarounds, focusing here on regex handling. Ramsay Jones notes that while the main patch (which restricts NO_REGEX to Cygwin 1.7) is straightforward, there's an outstanding question about test t7815-grep-binary.sh.

The test contains a "# TODO known breakage vanished" marker because Cygwin's regex (imported from FreeBSD) now matches NUL bytes with '.' patterns, unlike Git's compat/regex. Jones is unsure how to handle this - whether to leave it as-is, disable the test on Cygwin, or remove it entirely (leaning toward removal since the test doesn't seem useful). He's soliciting feedback on the best approach before proceeding.
