Platform compatibility follow-up in CSPRNG discussion.

Ramsay Jones concurs with the decision to drop the patch suggesting arc4random configuration on Linux, confirming the technical analysis from Brian Carlson and Junio Hamano. This email serves as a brief acknowledgment that the thread has reached consensus on several key points: glibc's arc4random implementation provides no advantages over direct getrandom usage on Linux, and the original documentation suggestion was misguided.

The exchange highlights how quickly this technical discussion progressed from initial documentation tweak to substantive platform-specific analysis. With Ramsay's agreement, the thread appears to have settled on clear guidance: Linux builds should stick with getrandom, while other platforms (like Cygwin) may still use arc4random where it provides genuine implementation advantage.

This marks the apparent conclusion of the thread's active discussion phase, with only potential follow-up work remaining in build system adjustments (particularly for meson) to properly reflect these platform distinctions.
