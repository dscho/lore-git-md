This is a documentation patch in Christian Couder's v6 series implementing signed commit support in git fast-export/import. The patch clarifies the security implications of using the 'verbatim' and 'warn-verbatim' options for handling signed tags.

The changes improve the warning text to be more explicit about why signature validation might fail - explaining that transformations during export (like excluding revisions) can change the hashes being signed, making signatures invalid. It adds specific guidance that these options should only be used when either no transformations will occur or when signature validity is not a concern.

The patch maintains backward compatibility with the deprecated 'warn' synonym while making the security tradeoffs clearer. This aligns with the series' overall goal of providing robust signed commit handling with proper documentation of the implications. The changes are focused and well-justified, completing the documentation polish that was part of the v6 series' finalization.
