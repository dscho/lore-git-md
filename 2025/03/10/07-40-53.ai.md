Bugfix for promisor-remote subsystem addressing a NULL pointer dereference.

This patch fixes a segfault that occurs when a promisor remote is configured without a URL. The issue arises when `git_config_get_string()` returns NULL for a missing URL, which is then passed to `strvec_push()`. The fix ensures an empty string is pushed instead of NULL when no URL is found, maintaining the strvec's NULL-terminated array invariant.

The change affects `promisor-remote.c` where URL handling is modified to safely handle missing configurations, and includes a new test case in `t5710-promisor-remote-capability.sh` that verifies the fix by creating a client clone with a promisor remote that has no URL configured. The test checks that object availability checks still work correctly in this scenario.

Key technical details:
- Modifies `promisor_info_vecs()` to use an empty string fallback when URL is NULL
- Updates URL handling in the info string generation to skip empty URLs
- Adds test case "clone with 'KnownName' and missing URL in the config"
- Maintains backward compatibility with existing promisor remote behavior
