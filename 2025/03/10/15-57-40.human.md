This is the v6 cover letter for a series implementing signed commit support in git fast-export/import, building on Luke Shumaker's earlier work. The series is now in its final polishing stage with no code changes since v5 - only documentation improvements and commit message fixes.

The core functionality adds a `--signed-commits` option to fast-export (matching the existing `--signed-tags` behavior) with modes like 'abort', 'strip', and 'verbatim'. This provides proper handling of commit signatures during export/import operations, where previously signatures were silently stripped. The series also lays groundwork for future attestation signature support.

Key improvements in v6 include:
- Better documentation explaining when 'verbatim' mode is appropriate (now covering commit history transformations)
- Explicit documentation that 'abort' is the default behavior
- Fixed typos and clarified memory management in code comments
- Rebased onto current master

The series has undergone thorough review with input from Elijah Newren (documentation), Phillip Wood (memory safety), and others. CI tests are clean. This appears production-ready and serves as a foundation for the planned attestation feature work. The cover letter clearly distinguishes between the implemented signature handling and future attestation goals.
