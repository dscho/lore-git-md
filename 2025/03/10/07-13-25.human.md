Refactoring patch in the ongoing `the_repository` removal effort. This is patch 6/12 in Patrick Steinhardt's series eliminating global repository state from Git's object APIs, specifically targeting the pack-revindex subsystem.

The patch removes all remaining dependencies on `the_repository` and `the_hash_algo` from pack-revindex.c, instead using repository-specific hash algorithms available through the `p->repo` pointer that's already present in calling contexts. Key changes include:
- Removing the `USE_THE_REPOSITORY_VARIABLE` define
- Adding explicit repository parameters to functions like `load_revindex_from_disk()`
- Introducing a new `ridx_min_size()` helper to calculate size based on the repo's hash algo
- Updating trace2 calls to use the repository context from MIDX/pack structs

This follows the established pattern seen in earlier patches of the series, systematically converting another core object-handling component to be repository-aware. The changes are mechanical but thorough, covering all pack-revindex operations including verification, position/offset conversions, and MIDX handling. With all major technical questions already resolved in earlier reviews, this appears ready for inclusion as part of the broader architectural improvement.
