This is part of Patrick Steinhardt's major series eliminating `the_repository` usage across Git's object APIs. The first patch focuses on the checksum file handling subsystem (`csum-file.c`), which provides core utilities for writing and verifying hash checksums.

The patch removes implicit dependencies on the global `the_repository` by making the hash algorithm parameter explicit in all `csum-file` functions. This affects numerous callers across Git's codebase that deal with packfiles, commit graphs, multi-pack indexes, and other checksummed data structures. The changes are mechanical but widespread, touching 14 files with 56 insertions and 39 deletions.

Key changes include:
- Adding a `hash_algo` parameter to all `hashfd*()` functions
- Updating checksum validation to take an explicit algorithm
- Converting callers to pass `the_repository->hash_algo` where needed
- Maintaining backward compatibility through transitional repository access

This is a foundational change that enables future work toward repository independence in Git's object handling code. The patch appears well-executed with thorough updates to all affected callers, though it's worth noting this is just the first of 12 patches in the complete series tackling this architectural improvement.
