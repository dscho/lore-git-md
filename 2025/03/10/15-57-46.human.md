This is the final patch in Christian Couder's v6 series adding signed commit support to `git fast-export`/`fast-import`, building on Luke Shumaker's earlier work. The patch completes the implementation with full memory safety and documentation polish.

The change introduces a new `--signed-commits` option that mirrors the existing `--signed-tags` functionality, allowing users to control how commit signatures are handled during export (abort/verbatim/strip modes). The default behavior changes from silently stripping signatures to aborting, with an escape hatch environment variable for backward compatibility.

Key technical aspects include:
- Shared `sign_mode` enum infrastructure with signed tags
- Support for both GPG and GPG-SHA256 signature formats
- Memory-safe parsing via `commit_buffer_cursor`
- Comprehensive test coverage in t9350
- Documentation updates explaining the new option and security implications

The patch has been thoroughly reviewed, with all technical issues (including memory safety concerns raised earlier in the thread) now resolved. It represents the final polished state of the series, which has received approvals from key maintainers. The implementation maintains a clear separation from future attestation signature work that was discussed but remains out of scope for this series.
