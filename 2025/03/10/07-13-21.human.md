This is part 2/12 of Patrick Steinhardt's series to remove `the_repository` dependencies from object APIs, a major refactoring effort in Git's core. The patch focuses on `object.c`, converting several functions that implicitly relied on the global repository variable to instead take an explicit repository parameter.

The changes include modifying fundamental object operations like `get_max_object_index()`, `get_indexed_object()`, `parse_object_or_die()`, and `clear_object_flags()` to require a repository parameter. The patch updates all callers across 15 files to pass `the_repository` where needed, maintaining backward compatibility while moving toward repository independence.

This is a mechanical but important change in the larger effort to make Git's object handling more modular. The patch follows the established pattern seen in other parts of the series, with straightforward conversions that don't introduce new behavior. As with the rest of the series, it's well-executed and clearly part of a coordinated architectural improvement.
