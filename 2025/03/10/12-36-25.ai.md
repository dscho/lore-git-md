Feature implementation adding reflog deletion capability, completing the v2 series after addressing all review feedback. This patch introduces a `git reflog drop` subcommand that removes entire reflogs (not just entries) for specified references, with `--all` support for repository-wide cleanup. The implementation handles worktrees through `get_worktrees()` and `refs_for_each_reflog`, with comprehensive tests in t1410-reflog.sh covering single-ref, multi-ref, and --all cases plus error conditions.

Key technical details: The drop operation uses `refs_delete_reflog` after resolving references via `repo_dwim_log`. Documentation clearly distinguishes "drop" (remove reflog structure) from "expire"/"delete" (remove entries). The implementation enforces mutual exclusion between --all and explicit references, with corresponding test assertions. Error messages for invalid references are standardized with other reflog operations.

The patch follows Git's established patterns for subcommand implementation in builtin/reflog.c, adding the new command alongside existing ones with its own usage string and option parsing. Test coverage verifies both successful operations and edge cases like non-existent refs and invalid --all combinations. Documentation updates clarify the distinction between reflog entry deletion and full reflog removal.
