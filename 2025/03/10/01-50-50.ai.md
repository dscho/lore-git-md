This is a configuration patch in the path-walk delta compression series, adding support for enabling the feature via config settings.

The patch introduces `pack.usePathWalk` as a new config option to control the path-based delta compression algorithm by default. The setting is automatically enabled when either `feature.experimental` or `feature.manyFiles` is set, following the pattern used for other experimental features. The implementation adds the config handling in `repo-settings.c` and wires it up in `pack-objects.c` where it sets the `path_walk` flag unless overridden by command-line options or environment variables.

Key technical details include:
- New `pack.usePathWalk` config documented in `pack.adoc`
- Added to both `feature.experimental` and `feature.manyFiles` groups
- Implementation respects existing precedence rules (CLI flags override config)
- Disabled when bitmaps are in use or for internal rev-list calls
- New `pack_use_path_walk` setting added to `repo_settings` struct
- Default remains off (0) unless enabled via feature groups

The patch maintains the series' careful approach to rollout, keeping the feature opt-in while making it conveniently available through existing experimental/many-files configuration channels. The documentation clearly notes the tradeoff with bitmap usage, which remains an important consideration for server-side operations. This appears to be a straightforward but important piece of the overall path-walk functionality, providing the expected configuration interface while maintaining safety through the feature.* system.
