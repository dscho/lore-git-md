Test modernization patch in the breaking changes infrastructure series.

This is the third patch in a four-part series preparing Git's test infrastructure for handling breaking changes. It focuses on cleaning up test style in t6120-describe.sh, specifically around testing the deprecation warning for `git name-rev --stdin`. The change replaces an unusual quoting pattern with more conventional single-quoted test bodies and double-quoted grep patterns, while also switching from raw `grep -E` to the preferred `test_grep` helper.

The patch is straightforward and uncontroversial, aligning with established test suite conventions. It doesn't introduce new functionality but improves maintainability by making the test more consistent with other tests in the codebase. The change is part of a larger effort to modernize tests in preparation for removing deprecated functionality (in this case, the `--stdin` option to `git name-rev`).
