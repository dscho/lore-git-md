This is a refactoring patch in Patrick Steinhardt's ongoing series to remove `the_repository` global usage. It splits out hash algorithm implementations from object-file.c into a new hash.c file, improving code organization.

The patch moves all hash-related code - including SHA-1 and SHA-256 implementations, null/empty object IDs, and algorithm lookup functions - into a dedicated file. This separation makes the hash subsystem's implementation more discoverable and reduces the intermingling of concerns in object-file.c. The change is purely structural with no behavior modifications.

As part of the larger series eliminating global state, this helps isolate hash algorithm handling from repository-specific code. The mechanical nature of this change follows the established pattern seen in earlier patches of the series, maintaining consistency with the project's architectural direction. The patch appears well-contained and straightforward, with all tests passing in the CI runs for previous versions of the series.
