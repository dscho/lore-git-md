Christian's v2 patch fixes the immediate crash by converting NULL URLs to empty strings while adding explicit warnings for missing URLs in both client and server configurations. The solution maintains backward compatibility while improving diagnostics, with expanded test coverage for edge cases. The discussion evolved to consider broader questions about the strvec API design, particularly whether `strvec_push()` should enforce non-NULL values.

The consensus is that configuration errors should be caught and reported rather than silently tolerated.
