Refactoring patch in the ongoing `the_repository` removal series. This is patch 7/12 in Patrick Steinhardt's v4 series to eliminate global repository state from Git's object APIs.

The patch converts `pack-bitmap-write.c` to stop using the global `the_repository` variable, instead storing and using a repository pointer in the `bitmap_writer` struct. The changes are mechanical replacements of `the_repository` with `writer->repo` throughout the file, along with removing the now-unneeded `USE_THE_REPOSITORY_VARIABLE` define. The writer's repository pointer is initialized when `bitmap_writer_init()` is called.

This follows the established pattern seen in earlier patches of the series, applying the same repository-aware approach to bitmap writing that was previously done for other pack-related subsystems. The changes are straightforward and maintain consistency with the series' architectural goals while preserving all existing functionality.

As with previous patches in this well-reviewed series, the changes are focused and mechanical, with no expected impact on performance or behavior. The patch completes another piece of the larger effort to make Git's object handling properly repository-aware.
