Bugfix and refactoring patch improving type safety in the decoration subsystem. This is the second version of a GSoC-contributed patch addressing sign comparison warnings in `decorate.c`.

The patch makes several cleanups to the decoration hash table implementation. It removes the `DISABLE_SIGN_COMPARE_WARNINGS` macro entirely, replacing it with proper type fixes. Two variables (`i` and `old_size` in `grow_decoration()`) are changed from `int` to `unsigned int` since they represent sizes and should never be negative. The patch also eliminates two intermediate variables (`size` and `nr`) that were just passing through values without modification, inlining their initial values instead for better clarity.

These changes follow up on Junio Hamano's review of the first version, which suggested improving readability by removing unnecessary variables. The technical approach remains sound - fixing type mismatches where `int` variables were being compared with unsigned values. The patch is focused and well-explained, showing good responsiveness to review feedback while maintaining the original goal of type safety improvements.
