This is the third patch in a series adding NUL-delimited output support to `git rev-list`, implementing the core `-z` option functionality. The patch focuses on machine-readable output formatting for object listings.

The key technical changes introduce NUL-delimited output when `-z` is used with `--objects`, replacing newline-based formatting with NUL bytes as separators. The output now uses two NUL bytes to terminate each object entry, with paths (when present) separated by a single NUL. This handles paths containing newlines correctly, unlike the current space-delimited format.

Implementation details include:
- New `print_object_term()` helper for NUL/newline output
- Modified `show_object()` to handle both NUL and space-delimited modes
- Input validation rejecting incompatible options like `--graph` with `-z`
- Comprehensive tests in t/t6000-rev-list-misc.sh verifying the basic NUL output and object+path combinations

The patch maintains the series' clean separation of concerns, building on the earlier refactoring work while focusing specifically on the output format change.
