Performance test addition for the path-walk delta compression series. This patch (04/13) adds comprehensive performance tests comparing the new --path-walk option against both versions of the existing name-hash delta selection method across three repository types (Git, FluentUI, and Linux kernel).

The test framework measures both time and resulting pack size for three scenarios: thin packs (small pushes), big packs (full repacks), and shallow fetch packs. Key findings show --path-walk provides significant improvements for repositories with filename hash collisions (FluentUI sees thin pack size drop from 1.2MB to 18.4KB), while having neutral impact on well-structured repositories like Git itself.

The implementation extends the existing p5313 performance test script by generalizing the test cases to accept either --name-hash-version or --path-walk parameters. The test data shows path-walk is already competitive with name-hash-v2 in timing despite lacking current threading optimizations, while demonstrating better compression in collision-heavy cases.

The patch maintains the series' focus on real-world validation, using both controlled microbenchmarks and data from actual large repositories. The FluentUI JavaScript repository serves as a particularly compelling case where path-based delta selection clearly outperforms hash-based methods.
