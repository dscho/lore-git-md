This is part of Patrick Steinhardt's ongoing series to eliminate `the_repository` global variable usage, specifically targeting the pack-bitmap-write subsystem. The patch converts pack-bitmap-write.c to use repository-specific instances rather than the global `the_repository` by:

1. Adding a `repo` field to `struct bitmap_writer` to store the repository context
2. Updating all call sites that previously used `the_repository` or `the_hash_algo` to instead use the writer's repository instance
3. Removing the `USE_THE_REPOSITORY_VARIABLE` define that was enabling the global usage

Key technical changes include:
- Repository-aware progress reporting via `start_progress()`
- Proper repository context for tree lookups (`lookup_tree()`)
- Correct hash algorithm usage in checksum handling (`hashcpy()`, `hashfd()`)
- Trace2 reporting with proper repository context
- File permission handling with repository-specific paths

The changes follow the established pattern seen in earlier patches of this series, systematically replacing global dependencies with instance-specific ones while maintaining all existing functionality. This completes another critical piece of the pack subsystem conversion, bringing us closer to fully removing `the_repository` from the object APIs.
