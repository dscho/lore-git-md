Refactoring of the path-walk delta compression phase in pack-objects. This patch is part of the ongoing series introducing path-based delta compression grouping.

The change separates the path-walk object grouping from the delta computation phase, storing path-based object groups as "packing regions" that can be processed later. This improves the progress reporting by showing distinct phases (object enumeration then compression) rather than interleaving them. The implementation introduces a new `packing_region` struct to track these groups and modifies the delta selection logic to process them in batches.

Key technical changes:
- Adds `packing_region` struct to track object groups by path
- Splits delta computation into `find_deltas_for_region` and `find_deltas_by_region` functions
- Updates progress reporting to show "Compressing objects by path" phase
- Removes now-unnecessary test workaround in t5530
- Adds progress verification tests in t5300

The patch maintains all existing functionality while improving the code organization and user experience. It explicitly notes that threading support remains a future enhancement. The changes are focused on `builtin/pack-objects.c` with supporting modifications to `pack-objects.h` and test files.

This refactoring appears well-contained and maintains the series' goal of improving delta compression for path-organized objects, particularly benefiting large repositories. The test updates confirm the new progress reporting works as intended.
