This is a documentation and consistency patch in the signed commits series for git fast-export. It renames the `--signed-tags=warn` option to `--signed-tags=warn-verbatim` to better match the existing pattern where `warn-strip` pairs with `strip`. The change makes the behavior more obvious - the "warn-verbatim" name clearly indicates that signatures will be preserved (verbatim) while warning about them, just as "warn-strip" warns while stripping signatures.

The patch maintains backward compatibility by keeping `warn` as a deprecated synonym, and includes tests verifying both the new and old forms work identically. This is part of Christian Couder's v6 series implementing signed commit handling in fast-export/import, which has already addressed technical concerns around memory safety and documentation. The change is purely about naming consistency and doesn't affect the underlying functionality.
