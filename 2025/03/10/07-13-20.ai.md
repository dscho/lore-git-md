This is part 1/12 of Patrick Steinhardt's series to eliminate `the_repository` usage in object APIs, specifically targeting the csum-file subsystem. The patch removes implicit and explicit dependencies on the global `the_repository` variable from csum-file.c and its callers by modifying functions to explicitly take a hash algorithm parameter.

Key changes include:
- Modifying `hashfd()`, `hashfd_check()`, and `hashfd_throughput()` to accept a `git_hash_algo` parameter
- Updating `hashfile_checksum_valid()` to take the hash algorithm explicitly
- Converting all callers to pass either `the_repository->hash_algo` (temporarily) or their own hash algorithm
- Removing the `USE_THE_REPOSITORY_VARIABLE` define from csum-file.c
- Maintaining backward compatibility while preparing for future complete removal of `the_repository` dependencies

The changes affect 14 files with 56 insertions and 39 deletions, touching core pack-writing and verification code paths. This is a foundational change that enables further repository independence in the object subsystem, though it still leaves some transitional uses of `the_repository->hash_algo` at callsites that will be addressed in later patches. The patch follows the established pattern seen in other parts of the series for removing repository globals.
