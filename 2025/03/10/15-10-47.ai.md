This is the first patch in a two-part refactoring series for the `the_repository` removal effort, specifically targeting "core.attributesfile" configuration handling. The patch moves attribute file path resolution from the global `git_attributes_file` variable into per-repository settings stored in `struct repo_settings`.

The implementation removes the global variable from environment.h/c and its related config handling from config.c, while adding proper cleanup in `repo_settings_clear()`. 

This follows the established pattern for repository-scoped configuration in the ongoing global state elimination effort, affecting attr.c, environment.c, and builtin/var.c.
