[PATCH v3 0/13] pack-objects/repack: introduce --path-walk for improved delta compression

Series introducing path-based delta compression via --path-walk option and pack.usePathWalk config has completed technical review with all feedback addressed across three iterations. Core implementation replaces name-hash grouping with path-based delta selection featuring optimizations for shallow clones through edge_aggressive mode. Technical scope spans pack-objects, repack, and Scalar configuration.

Implementation details:

- Edge_aggressive mode for shallow clones via path_walk_info struct
- Repack integration through --path-walk option
- Scalar configuration enabling path-walk by default
- pack.usePathWalk config with experimental/manyFiles auto-enable
- Performance test suite comparing path-walk vs name-hash versions across thin packs, big packs, and shallow fetch packs
- New GIT_TEST_PACK_PATH_WALK test variable to validate path-walk behavior across test suite
