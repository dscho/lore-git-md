[PATCH v2 0/13] pack-objects/repack: introduce --path-walk for improved delta compression

Series introducing path-based delta compression grouping via --path-walk option and pack.usePathWalk config is approved for 'next' but pending final review from Taylor Blau. Core changes replace name-hash grouping with path-based delta selection, with optimizations for shallow clones through edge_aggressive mode. Implementation spans pack-objects, repack, and Scalar configuration.

- Edge_aggressive mode for shallow clones via path_walk_info struct
- Repack integration through --path-walk option
- Scalar configuration enabling path-walk by default
- pack.usePathWalk config with experimental/manyFiles auto-enable
- Performance test suite comparing path-walk vs name-hash versions
