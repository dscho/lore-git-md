This is a bugfix for the promisor-remote subsystem, addressing a segmentation fault that occurs when a remote URL is missing from the configuration. The patch fixes a case where pushing NULL into a 'strvec' (Git's string vector structure) would cause a crash, since strvec expects NULL-terminated arrays. The solution replaces NULL values with empty strings when URLs are missing.

The change is straightforward and well-justified, with Christian Couder providing both the code fix and a new test case that verifies the behavior when cloning with a 'KnownName' configuration but missing URL. The test demonstrates the previously crashing scenario now works correctly.

The patch appears to be part of an ongoing effort ("cc/lop-remote") that Christian mentions was sent late in the development cycle. The fix is small (10 lines changed) but important, as it prevents crashes in promisor remote operations when URLs are not configured. The addition of a test case gives confidence in the fix's correctness.
