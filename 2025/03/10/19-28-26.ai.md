Refactoring patch in the NUL-delimited rev-list output series.

This is the first of four patches from Justin Tobler in Patrick Steinhardt's series adding NUL-delimited output support to `git rev-list`. The change inlines the single-use `show_object_with_name()` function into its caller `show_object()` in builtin/rev-list.c, while also consolidating the common OID printing logic. The modification prepares the codebase for the subsequent introduction of NUL-delimited output formatting.

Key technical details:
- Removes `show_object_with_name()` from revision.c and its declaration from revision.h
- Moves the printing logic directly into `show_object()`
- Factors out the OID printing that was previously duplicated between named and unnamed object cases
- Touches the same code paths that will later implement the `-z` NUL-delimited output

The change is purely structural with no behavior modification, serving as groundwork for the feature implementation in later patches. The commit message clearly explains the motivation and connects it to the series' purpose. The diff shows careful attention to maintain existing functionality while simplifying the code structure.
