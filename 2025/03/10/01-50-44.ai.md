This is the second patch in a 13-part series introducing path-based delta compression to `git pack-objects`. The patch adds the core `--path-walk` option that enables the new path-based object walking algorithm.

The key technical aspects are:
- Implements path-based object grouping during delta selection, organizing trees/blobs by path rather than name-hash
- Performs delta calculations during the walk (though not yet threaded)
- Maintains UNINTERESTING objects for delta base candidates
- Falls back to name-hash for additional delta opportunities after path-based passes
- Documents the new flag and its incompatibilities (bitmaps, delta islands, shallow packs, filters)
- Adds basic tests for path-walk functionality

The implementation shows awareness of current limitations (no threading, incompatible features) that will be addressed in later patches. The patch builds on the preparatory refactoring from patch 01/13 while keeping this change focused on the core path-walk integration.

Key files modified:
- `builtin/pack-objects.c`: Adds path-walk implementation and integration
- Documentation updates for both user-facing and technical details
- New test cases in t5300

This represents the first user-visible piece of the path-walk functionality, though the series note indicates performance optimizations will come later. The patch appears well-structured with clear commit message explaining both benefits and current limitations.
