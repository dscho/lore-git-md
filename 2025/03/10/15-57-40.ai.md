This is a v6 cover letter for a feature series adding signed commit support to git fast-export/import, building on Luke Shumaker's earlier work. The series is now in its final polishing stage with only documentation and commit message improvements since v5.

The core functionality (implemented in v5) provides:
- `--signed-commits` option mirroring `--signed-tags` behavior (abort/verbatim/strip modes)
- GPG and GPG-SHA256 format support
- Memory-safe parsing infrastructure
- Comprehensive test coverage in t9350

Key changes in v6:
- Rebased onto current master
- Fixed commit message subject formatting (adoc vs txt)
- Enhanced documentation for when to use verbatim modes (now explicitly warning about history transformations)
- Clarified default abort-on-signed-commits behavior
- Fixed code comment typos and memory handling documentation
- CI tests passing except possibly pending osx-gcc

The series has seen thorough review with approvals from Jeff King, Eric Sunshine, and Junio Hamano, plus documentation improvements from Elijah Newren and a memory leak fix from Phillip Wood. It serves as groundwork for future attestation signature work while providing immediate signed commit handling capabilities.

The cover letter maintains the clear distinction between this implemented functionality and the unimplemented-but-validated future attestation feature. With all technical issues resolved and documentation polished, this appears ready for final inclusion.
