This is a documentation patch in Christian Couder's v6 series implementing signed commit support for git fast-export/import. It fixes a minor formatting issue in the BNF syntax documentation for `git-fast-import`, adding a missing line feed marker after the encoding specification.

The change is straightforward - it adds an `LF` marker that was accidentally omitted from the BNF grammar description of commit data format. While small, this correction helps maintain accuracy in the documentation, which is important given the series' focus on precise handling of commit metadata. The patch comes from Luke Shumaker's original 2021 work and has been carried forward through the series' iterations.

This is the first of six patches in the final v6 series, which has already addressed all technical concerns raised during review (including memory safety and documentation clarity) and received approvals from key maintainers. The change is purely cosmetic and unlikely to be controversial.
