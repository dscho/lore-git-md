This is a documentation patch in Christian Couder's v6 series implementing signed commit support in git fast-export/import. The patch clarifies the security implications of using the 'verbatim' and 'warn-verbatim' options for handling signed tags.

The update makes two key improvements to the documentation: it explains more precisely why signatures may become invalid (due to hash changes from transformations during or after export), and it adds a stronger warning that these options should only be used when either no transformations will occur or signature validity doesn't matter. The changes maintain consistency with the series' focus on clear security documentation while keeping backward compatibility with the deprecated 'warn' synonym.

This appears to be a straightforward documentation improvement that completes the series' goal of properly documenting the security tradeoffs around signature handling. The patch is well-contained and uncontroversial, building on the extensive review and testing the series has already received.
