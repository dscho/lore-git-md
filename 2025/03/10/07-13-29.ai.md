This is a refactoring patch in Patrick Steinhardt's ongoing series to remove `the_repository` global usage, specifically focusing on hash algorithm implementation.

The patch moves all hash algorithm implementation code from `object-file.c` to a new `hash.c` file, keeping the declarations in `hash.h`. This is a code organization improvement that better separates concerns - the hash algorithm implementations were previously intermingled with object file handling code despite having their own header. The change is purely structural with no behavior modifications.

Key technical details:
- Creates new `hash.c` with 283 lines of hash implementation code moved verbatim from `object-file.c`
- Updates build systems (Makefile and meson.build) to include the new file
- Preserves all hash algorithm functionality including:
  - SHA-1 and SHA-256 implementations (normal and "unsafe" variants)
  - Algorithm lookup by name, ID or length
  - Special OID handling (null, empty tree/blob)
  - Algorithm structure definitions and operations
- Maintains all existing behavior and interfaces

The change follows the series' pattern of improving code organization while working toward repository independence. Since this is a straightforward code movement with no functional changes and the overall series has already been reviewed, this patch appears ready for inclusion. Future patches in the series can now work with the better-organized hash code.
