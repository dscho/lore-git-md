This is a feature patch series introducing a new `--path-walk` option to `git pack-objects` and `git repack`, along with related optimizations. The series builds on previous path-walk API work and aims to improve delta compression by grouping objects by path rather than just name hash.

The key changes include:
- A new `--path-walk` option that uses path-based grouping for delta compression
- Config option `pack.usePathWalk` to enable this by default
- Threading optimizations for the path-walk approach
- New `edge_aggressive` mode for shallow clone scenarios
- Integration with `git repack` and `scalar`

Performance measurements show significant improvements in some repositories (like microsoft/fluentui seeing 3x smaller packs), while more structured repos like nodejs/node and Linux see modest gains. The approach particularly helps with repositories suffering from name hash collisions.

The series comes from Microsoft's experience using this in production, where it reduced push sizes by 100x in some cases. While there are some limitations around bitmap integration, the benefits for space savings and performance appear substantial. This is a mature proposal that's already been shipped in Microsoft's Git fork and incorporates feedback from previous RFC discussions.
