This is a test infrastructure addition for the ongoing path-walk delta compression series. Patch 05/13 introduces `GIT_TEST_PACK_PATH_WALK`, an environment variable that enables the new path-walk delta selection by default in tests, similar to how `GIT_TEST_NAME_HASH_VERSION` works for the name-hash feature.

The patch documents the new test variable and modifies several test scripts that are incompatible with path-walk delta selection, either because they test edge cases around missing objects (t0411, t5306), rely on specific delta behavior (t5310, t5316, t5332), or would produce different error messages (t5530). The submodule update test (t7406) is adjusted to avoid warning messages when combining depth and path-walk features.

Key technical details include:
- Default path-walk behavior is now configurable via the test variable (disabled when using bitmaps or external rev-list)
- The variable is not added to the linux-TEST-vars CI build to avoid overloading it
- Several tests are explicitly marked as incompatible with path-walk due to their reliance on specific delta selection behavior
- One temporary test modification in t5530 will be reverted after future refactoring of the path-walk error handling

The changes demonstrate careful consideration of how the new delta selection strategy interacts with existing test expectations, particularly around edge cases and performance-sensitive behaviors. The patch maintains test coverage while allowing the new feature to be exercised broadly in the test suite.
