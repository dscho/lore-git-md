This is part 3/12 of Patrick Steinhardt's series to eliminate `the_repository` usage in object APIs, specifically targeting pack-writing operations. The patch removes implicit dependencies on `the_repository` and `the_hash_algo` from pack-write.c by:

1. Converting functions like `write_idx_file()`, `write_rev_file()`, and `create_tmp_packfile()` to take explicit `struct repository*` parameters instead of relying on globals
2. Updating all callers across 7 files (fast-import, index-pack, pack-objects, bulk-checkin, midx-write) to pass `the_repository` where needed
3. Maintaining identical functionality while removing the `USE_THE_REPOSITORY_VARIABLE` guard from pack-write.c
4. Preserving all existing behavior including:
   - Index file writing
   - Reverse index generation
   - MTIMES trailer handling
   - Temporary packfile creation
   - Permission adjustments

Key technical changes include converting hash algorithm access from `the_hash_algo` to `repo->hash_algo` and ensuring all file operations respect the repository context. The patch follows the series' pattern of mechanical conversions that don't alter core behavior while removing global state dependencies. This continues the architectural work to enable repository-independent object handling, with all changes being straightforward parameter additions that reviewers have already approved in principle during earlier rounds.
