Feature patch adding config support for the new path-walk delta compression. This is part 8/13 of a series introducing path-based delta grouping to improve compression in repositories with filename hash collisions (like JavaScript projects).

The patch adds a `pack.usePathWalk` config option that enables the new --path-walk behavior by default in `git-pack-objects`. The option is automatically enabled when either `feature.experimental` or `feature.manyFiles` is set, following the same pattern used for other experimental features. The implementation includes documentation updates and the necessary plumbing to make the setting work through Git's repository settings infrastructure.

The commit notes this should primarily be used on client repositories since it disables bitmap walks, which are important for server performance. The path-walk approach shows particular benefits for repositories with many hash collisions, where it can significantly reduce pack sizes (as demonstrated by earlier patches in the series with examples like reducing a 439MB pack to 142MB).

This is a straightforward configuration addition that builds on the core path-walk implementation introduced earlier in the series. The patch follows established patterns for introducing experimental features and includes thorough documentation.
