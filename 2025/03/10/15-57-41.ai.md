This is a documentation patch in Christian Couder's v6 series implementing signed commit support for git fast-export/import. The patch fixes a minor formatting issue in the BNF grammar documentation for git-fast-import by adding a missing line feed (LF) marker after the 'encoding' field specification. While purely cosmetic, this correction ensures the documentation accurately reflects the actual command syntax expected by the parser. The change was originally authored by Luke Shumaker in 2021 and is now as part of the revived signed commits work. This is the first of six patches in the final polished version of the series that has already received thorough review and approval from key maintainers. The fix maintains consistency with how other fields are documented in the BNF grammar and doesn't affect functionality.
