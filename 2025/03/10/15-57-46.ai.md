This is the final patch in Christian Couder's v6 series implementing signed commit support for git fast-export/import, building on Luke Shumaker's original work. The patch completes the memory safety work by properly handling commit signatures using const-correct APIs and length-based string operations.

The key technical additions are:
- New `--signed-commits` option mirroring `--signed-tags` behavior (abort/verbatim/strip modes)
- Shared `sign_mode` enum infrastructure between commit and tag handling
- GPG and GPG-SHA256 signature format support
- Memory-safe parsing via `find_commit_header()` and new `find_commit_multiline_header()`
- Comprehensive test coverage in t9350 including backward compatibility tests
- Environment variable `FAST_EXPORT_SIGNED_COMMITS_NOABORT` for legacy tool compatibility
- Documentation updates clarifying defaults and security implications

The implementation maintains consistency with the existing signed tag handling while fixing the remaining buffer safety issues identified in earlier reviews. The patch includes thorough test cases verifying all signature handling modes and proper interaction with other commit metadata like encodings.

This completes the technical implementation of signed commit support, with all review feedback addressed and all tests passing. The series is now ready for final inclusion, having received approvals from key maintainers. The foundation is also laid for potential future work on attestation signatures during import, though that remains separate from this implementation.
