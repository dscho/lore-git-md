This is part 15/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on refactoring test infrastructure. The patch converts the `name_from_description()` helper function from using Perl to a combination of sed and tr commands.

The change removes Perl usage from a test helper that converts commit descriptions into sanitized names by:
1. Replacing Perl regex operations with equivalent sed commands
2. Maintaining identical string transformation behavior (converting non-alphanumerics to dashes, lowercasing, etc.)
3. Allowing removal of PERL_TEST_HELPERS prerequisites from two test files (t6002 and t6003)

This continues the series' pattern of methodically replacing Perl dependencies while preserving test behavior. The conversion appears straightforward and well-contained, with the sed commands directly mirroring the original functionality. The patch removes 19 lines while adding 6, demonstrating the space efficiency of these conversions.

As with previous patches in the series, this maintains test coverage while reducing the test suite's Perl surface area. The change is unlikely to be controversial as it follows the established pattern of the series and has already addressed prior feedback in earlier iterations.
