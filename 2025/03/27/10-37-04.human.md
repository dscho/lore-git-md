This is part 6/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite. The patch introduces a new `PERL_TEST_HELPERS` prerequisite to distinguish between tests that require Perl because the tested feature depends on Perl (handled by existing `PERL` prerequisite) versus tests that use Perl helpers internally.

The change systematically audits and updates 71 test files, adding `PERL_TEST_HELPERS` to tests that use Perl for:
- Data generation/manipulation (e.g. `perl -e` one-liners)
- Test helpers (e.g. trace2` tests)
- Binary data handling
- Complex text processing
- Protocol testing

The patch maintains the same test coverage while clearly documenting which tests still rely on Perl, making it easier to identify remaining conversion targets. This continues the series' pattern of incrementally removing Perl dependencies while preserving test behavior.

The change is well-contained and follows the established approach of the series. It doesn't introduce any new functionality or behavior - just better dependency tracking. The large number of file modifications reflects the widespread (but decreasing) use of Perl in the test suite.
