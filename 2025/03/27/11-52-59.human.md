Refactoring patch in a completed series eliminating comma operators. This is patch 6/10 in Johannes Schindelin's series to remove potentially confusing comma operator usage throughout Git's codebase. The series has already gone through extensive review and reached consensus on style.

This particular patch converts comma-separated statements in `diff-delta.c` to explicit semicolon-separated statements with curly braces, following Taylor Blau's recommended style. The changes affect delta encoding logic where offset and size values are written to the output buffer, making the control flow more explicit while maintaining identical behavior.

The patch is straightforward - it replaces 6 instances where comma operators were used to combine buffer writes with bitwise operations into clearer block statements. The changes are mechanical and have been reviewed by Phillip Wood, with no impact on functionality. This was one of the last remaining subsystems to be updated in the comprehensive comma-operator cleanup effort.

The series as a whole has addressed all technical concerns across multiple subsystems and is ready for integration, with this patch representing the final style unification for the diff-delta implementation.
