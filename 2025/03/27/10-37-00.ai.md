This is part 2/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, specifically targeting environment sanitization code. The patch converts the Perl-based environment variable filtering in `t/test-lib.sh` to a sed-based solution, removing another Perl dependency from the test infrastructure.

The change replaces a Perl script that selectively unsets Git-related environment variables (keeping certain whitelisted ones) with an equivalent sed pipeline. The new implementation maintains the same filtering logic but uses sed's pattern matching capabilities instead of Perl's regex engine. The whitelist includes variables like GIT_TRACE, GIT_TEST, GIT_VALGRIND and others that should remain set during testing.

Key technical details:
- The sed pipeline uses negative matching (-e '/pattern/d') to exclude whitelisted variables
- A final sed pattern extracts just the variable names from matching lines
- The change preserves all existing functionality while removing the Perl requirement
- The patch is based on prior work by Johannes Schindelin
- Modifies only `t/test-lib.sh` with straightforward sed substitutions
