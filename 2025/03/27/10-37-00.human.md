This is part 2/20 of Patrick Steinhardt's series to remove Perl dependencies from Git's test suite, specifically targeting environment sanitization code. The patch converts the Perl-based environment variable filtering to a `sed` implementation, maintaining the same behavior while eliminating the Perl requirement.

The change replaces a Perl script that selectively unsets Git-related environment variables (keeping certain whitelisted ones) with an equivalent `sed` pipeline. The new version uses a series of `-e` expressions to exclude whitelisted variables and extract the names of others to unset. This is a straightforward mechanical conversion that follows the series' goal of removing Perl from test infrastructure.

The patch appears well-constructed, with the conversion preserving all the original functionality while being more portable. It builds on prior work from Johannes Schindelin and has been refined through multiple rounds of review (now at v3). As part of the larger effort to make Perl optional for testing, this change helps reduce the test suite's dependency on Perl while maintaining identical behavior.
