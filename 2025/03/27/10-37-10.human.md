This is part 12/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite. The patch continues the systematic conversion of test scripts that rely on Perl for printing data, now replacing those uses with awk, sed, and test-tool genzeros.

The changes fall into three categories: conditional pattern matching (converted to awk), repeated data generation (using genzeros + sed), and reversing output (also using awk). The patch touches 14 test files, removing PERL_TEST_HELPERS prerequisites from several tests while maintaining the same test behavior. Notable conversions include:

- Replacing Perl's string repetition with awk in reftable tests
- Converting MERGE_RR parsing in rerere tests to use sed
- Modernizing pack corruption and push certificate tests
- Preserving binary file processing in blame tests
- Updating rev-list tests to use awk for reversing output

The changes follow the series' established pattern of careful, behavior-preserving conversions. Each modification is straightforward and maintains test fidelity while removing Perl dependencies. The patch builds on prior infrastructure work from parts 2-11, including the PERL_TEST_HELPERS prerequisite system and build system adaptations.

This continues the steady progress toward making 99% of Git's tests Perl-free, with only Gitweb and netrc helper tests still requiring Perl after this change. The patch appears well-constructed and aligns with the series' high standards for thorough, incremental modernization.
