Performance optimization for `git cat-file` with object type filters, now using bitmap indices.

This is the final version of Patrick Steinhardt's series to optimize object filtering in `git cat-file --batch-all-objects`. The key improvement allows using bitmap indices to dramatically speed up type-based filtering (e.g. `--filter=object:type=commit`), avoiding the need to scan entire packfiles when only certain object types are needed.

The series builds on Taylor Blau's prerequisite bitmap work and incorporates feedback from the v1 discussion, notably:
- Renamed the option to `--filter=` (matching `git pack-objects`) after Junio Hamano's intervention
- Reuses existing bitmap infrastructure as suggested by Taylor Blau
- Adds support for filtering by object type (commit/tree/blob/tag) and blob size limits

Performance impact is substantial - in the Chromium repo (50GB packfile, 25M objects), filtering commits went from ~86s to ~2s (41x faster). The optimization works by leveraging type-specific bitmaps when available, falling back to full scans for non-bitmapped packs.

The implementation is clean and well-documented, with thorough test coverage. This addresses a real performance pain point for large repositories while maintaining compatibility with existing workflows. The series is now ready for merging pending the prerequisite bitmap work.
