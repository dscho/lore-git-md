This is a feature patch series introducing object filtering to `git cat-file`'s batch mode, building on previous bitmap optimizations. The series is now in its second version with several key developments:

The core functionality adds `--filter=` options to `git cat-file --batch-all-objects`, supporting `blob:none`, `blob:limit=`, and `object:type=` filters similar to `git rev-list`. The initial implementation showed limited gains since it still scanned entire packfiles, but the series now integrates with bitmap indices for dramatic speedups when filtering by object type.

Technical highlights include:
- New bitmap iteration functions in pack-bitmap.c (`for_each_bitmapped_object`)
- Pack bitmap detection (`bitmap_index_contains_pack`)
- Deduplicated object traversal logic in cat-file.c
- Comprehensive test coverage in t1006

The series has evolved through:
- Renaming from `--objects-filter` to `--filter=` per Junio's decision
- Reusing Taylor Blau's bitmap abstractions
- Adding tree-depth=0 optimization pathway
- Documenting filter combination rationale

Performance impact is substantial - filtering commits in Chromium's repo goes from 86s to 2s (41x faster) by leveraging bitmaps to avoid full pack scans. The implementation carefully coordinates with prerequisite bitmap work, maintaining clean separation between architectural patterns and implementation concerns.

Key files touched:
- builtin/cat-file.c (main implementation)
- pack-bitmap.{c,h} (bitmap integration)
- t/t1006-cat-file.sh (tests)
- Documentation/git-cat-file.adoc
