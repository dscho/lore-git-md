This is part 18/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on the trace2 testing infrastructure. The patch converts trace2 output scrubbing from Perl to sed, removing another Perl dependency while maintaining test reliability.

The change replaces a Perl script (`scrub_normal.perl`) with an equivalent sed implementation in the test file itself. The scrubbing handles several variable fields in trace2 output that make testing difficult: elapsed times (replaced with `_TIME_`), executable paths (normalized to `_EXE_`), and omits platform-dependent `cmd_path` and `cmd_ancestry` messages. The new implementation uses sed's pattern matching capabilities to achieve the same normalization effect as the original Perl code.

Key technical details:
- Removes `PERL_TEST_HELPERS` prerequisite from t0210-trace2-normal.sh
- Preserves all existing test expectations while changing the implementation
- Handles the same edge cases as the Perl version (quoted/unquoted paths, floating-point times)
- Maintains compatibility with all existing test cases that verify trace2 output

This follows the series' established pattern of direct Perl-to-POSIX tool replacements while demonstrating the approach works for Git's complex tracing infrastructure. The change is well-contained and maintains the test suite's ability to verify trace2 behavior across platforms.
