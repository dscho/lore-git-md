This is part 13/20 of Patrick Steinhardt's series to eliminate Perl dependencies from Git's test suite, focusing on textconv-related tests. The patch converts three test files (t4030, t4031, t7815) that previously relied on Perl for text conversion scripts to use simpler shell utilities instead.

The changes replace Perl-based hexdump and text conversion scripts with equivalent shell commands using `tr` and a new `test-tool hexdump` helper. While not exact functional matches to the original Perl implementations, the simplified versions maintain the core testing needs - verifying that textconv operations work rather than precisely replicating Perl's behavior. The patch removes several `PERL_TEST_HELPERS` prerequisites as a result.

Notable technical changes include:
- Replacing Perl character-to-number conversion with `tr` command for basic transformations
- Introducing `test-tool hexdump` for binary file inspection
- Simplifying test expectations to match the new implementations' output
- Maintaining test coverage while reducing complexity

This continues the series' pattern of methodically replacing Perl dependencies with POSIX-compatible alternatives while preserving test integrity. The changes appear straightforward and well-contained, following the established approach from earlier patches in the series.
