This is part 14/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on GPG-related tests. The patch refactors the `sanitize_pgp()` helper function in `t/lib-gpg.sh` to use `sed` instead of Perl for stripping PGP signatures from test output.

The change removes the Perl implementation that toggled a state flag when seeing PGP/END PGP markers, replacing it with a simpler `sed` command that deletes everything between the markers while preserving the marker lines themselves. This allows dropping the PERL_TEST_HELPERS prerequisite from most tests that use this helper.

A notable side effect is that some tests in t6300-for-each-ref.sh that still need Perl for other purposes now must explicitly declare PERL_TEST_HELPERS, where previously the test would skip entirely if Perl wasn't available. The patch updates these test cases to maintain functionality while being more precise about their dependencies.

The conversion follows the series' established pattern of direct command-to-command replacements while maintaining test behavior. Johannes Schindelin provided input on the approach, as noted in the Helped-by tag. This continues the systematic reduction of Perl surface area in the test suite while preserving test coverage.
