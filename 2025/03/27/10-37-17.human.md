This is part 19/20 of Patrick Steinhardt's series to eliminate Perl dependencies from Git's test suite, focusing on converting the `max_chain()` helper in t5316-pack-delta-depth.sh from Perl to awk.

The patch refactors a helper function that extracts the maximum delta chain length from `git index-pack` output. The original Perl implementation is replaced with an awk equivalent that performs the same parsing while being more lightweight. This change allows removing several PERL_TEST_HELPERS prerequisites from the test file.

The conversion appears straightforward and maintains the same functionality - the awk version still looks for the "chain length" pattern in the output and extracts the numeric value, just with slightly different syntax. The patch follows the established pattern in this series of replacing Perl with POSIX tools where possible.

This continues the series' steady progress in removing Perl dependencies while preserving test behavior. The change is small and focused, typical of the incremental approach that has worked well so far in this large conversion effort. With only one patch remaining after this, the series is nearing completion of its goal to make Git's test suite Perl-free.
