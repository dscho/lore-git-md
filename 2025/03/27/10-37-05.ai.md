Test modernization patch in the Perl removal series, focusing on prerequisite cleanup. This is part 7/20 of Patrick Steinhardt's ongoing effort to eliminate Perl dependencies from Git's test suite, following the infrastructure established in part 6/20 with the `PERL_TEST_HELPERS` prerequisite.

The patch audits and updates test prerequisites across four test files, addressing three categories of Perl usage: tests that no longer need Perl at all (removing `PERL` prerequisite), tests that still need Perl but were incorrectly marked (switching to `PERL_TEST_HELPERS`), and tests needing more specific Perl module checks (introducing `PERL_IPC_OPEN2`). Key changes include:

1. Removes unnecessary `PERL` prerequisites from several tests in t0021-conversion.sh (delayed checkout progress tests) and t7501-commit-basic-functionality.sh (interactive commit scenarios), showing these no longer depend on Perl.

2. Introduces a new `PERL_IPC_OPEN2` lazy prerequisite in t1006-cat-file.sh for tests requiring IPC::Open2 module, while fixing a variable naming conflict with the test infrastructure by renaming the script variable to `perl_script`.

3. Updates t0090-cache-tree.sh to remove `PERL` from interactive commit tests, confirming these tests no longer need Perl functionality.

The changes maintain the series' pattern of behavior-preserving refactoring while properly documenting test dependencies. The new `PERL_IPC_OPEN2` prerequisite demonstrates the series' attention to precise dependency tracking, even when dealing with specific module requirements rather than just Perl interpreter availability.
