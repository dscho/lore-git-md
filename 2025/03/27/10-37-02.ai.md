Test infrastructure modernization (part 4/20 of Perl removal series). This patch converts the `test_copy_bytes()` helper function from using Perl to using `dd(1)`, continuing the systematic replacement of Perl dependencies in Git's test suite. The function, which copies a specified number of bytes from stdin to stdout, now uses a simple `dd` invocation with byte-counting parameters instead of the previous Perl implementation that manually managed buffer reads.

The change is straightforward - replacing 11 lines of Perl code with a single `dd` command that achieves the same functionality. The new implementation maintains the same behavior while removing the Perl dependency, allowing more tests to run without Perl available. This follows the established pattern seen in earlier patches of the series, where Perl is replaced with standard Unix tools wherever possible.

Key technical details:
- Function location: `t/test-lib-functions.sh`
- Old implementation: Perl sysread loop with error handling
- New implementation: `dd ibs=1 count="$1" 2>/dev/null`
- Behavior remains identical for all callers
- Part of making 97% of tests Perl-free (only Gitweb and netrc helper remain)

The patch is well-contained and follows the series' approach of minimal, behavior-preserving changes. It builds on prior work in the series (parts 2/20 and 3/20) that similarly replaced Perl dependencies in test infrastructure. The change appears uncontroversial given the established consensus on the series' direction and the straightforward nature of this particular conversion.
