This is part 18/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on the trace2 testing infrastructure. The patch converts trace2 output scrubbing from Perl to sed, removing another Perl dependency while maintaining the same test behavior.

The change replaces a Perl script (`scrub_normal.perl`) with an equivalent sed implementation directly in the test file. The scrubbing normalizes variable trace2 output fields like elapsed times and executable paths to make test assertions stable across environments. The new sed version handles:
- Replacing elapsed times with `_TIME_` placeholder
- Normalizing executable paths to `_EXE_`
- Omitting platform-specific `cmd_path` and `cmd_ancestry` messages

The conversion follows the series' pattern of direct Perl-to-POSIX tool replacements while preserving test fidelity. All existing trace2 test cases are updated to use the new sed scrubber instead of the Perl script, and the `PERL_TEST_HELPERS` prerequisite is removed from these tests. The implementation looks thorough, maintaining the same scrubbing logic just in a different implementation language.

This continues the systematic reduction of Perl dependencies while keeping test behavior identical. The change is well-contained to trace2 testing and follows the established pattern of the series.
