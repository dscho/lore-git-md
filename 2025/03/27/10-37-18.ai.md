This is the final patch (20/20) in Patrick Steinhardt's series to eliminate Perl dependencies from Git's test suite, focusing on the HTTP protocol tests in t5703.

The patch tackles two Perl usages in the upload-pack ref-in-want tests. First, it replaces Perl-based capability filtering with `test_grep`, removing the global PERL_TEST_HELPERS prerequisite that previously guarded the entire test file. Second, it keeps Perl for CGI script setup in HTTPD tests but scopes the prerequisite to just those individual test cases that need it (6 out of 7 tests in the file).

Key technical changes:
- Replaces `perl -ne` pattern matching with `test_grep` for checking ref-in-want capability advertisements
- Maintains Perl dependency only where HTTPD CGI setup is required
- Updates test assertions to use Git's built-in test helpers where possible
- Preserves all test coverage while reducing Perl surface area

The patch follows the series' established pattern of methodical Perl removal while being pragmatic about cases where complete elimination would be too invasive. It demonstrates the test suite's ability to handle protocol capability testing without Perl while acknowledging HTTPD's remaining Perl dependency. The changes are surgical - focused on test plumbing rather than core functionality, with clear commit message documentation of the tradeoffs made.
