Feature implementation for `git cat-file` batch filtering, adding size-based blob exclusion.

This patch implements the `blob:limit=<n>` filter for `git cat-file --batch`, allowing users to exclude blobs larger than a specified size (with optional KiB/MiB/GiB suffixes). It builds on the filtering infrastructure established in previous patches, now adding size-based filtering alongside the existing `blob:none` functionality.

Key technical elements:
- New `LOFC_BLOB_LIMIT` enum value for the filter type
- Size comparison logic in `batch_object_write()`
- Documentation of the new filter syntax in `git-cat-file.adoc`
- Comprehensive testing across different blob sizes (1B, 500B, 1000B, 1GB)
- Maintains existing behavior for non-blob objects
- Works consistently across packed/loose and bitmap/non-bitmap cases

The implementation follows the established pattern from the `blob:none` filter, adding size awareness where needed. Test coverage is thorough, including edge cases like zero-byte limits and very large sizes. This appears to be a clean extension of the filtering system with no obvious technical debt introduced.

This is part of Patrick Steinhardt's ongoing series to enhance `git cat-file` filtering capabilities, now delivering the second concrete filter type after the initial `blob:none` implementation. The patch maintains architectural consistency with the previous work while expanding the filtering functionality.
