This is a preparatory patch in Patrick Steinhardt's series enhancing Git's cat-file batch mode filtering capabilities, specifically focusing on bitmap integration. The patch introduces a new helper function `bitmap_index_contains_pack()` that checks whether a given packfile is referenced in a bitmap index, either directly or through a multi-pack-index. The function handles both single-pack and MIDX cases with a simple linear search through the relevant pack lists.

The implementation is straightforward and well-contained, adding 15 lines to pack-bitmap.c and 7 lines to pack-bitmap.h. The function signature and basic behavior are clearly documented in the header file. This appears to be infrastructure work needed for subsequent patches in the series, though the exact usage isn't specified here (the commit message notes it will be used "in a subsequent commit").

Key technical details:
- New function `bitmap_index_contains_pack()` in pack-bitmap.[ch]
- Handles both regular packfiles and MIDX cases
- Returns boolean (1/0) result
- Simple linear search implementation
- Follows existing bitmap index traversal pattern with `bitmap->base` chaining
- Taylor Blau credited as co-author

The patch maintains the series' focus on careful bitmap integration while adding this small but apparently necessary utility function. It doesn't introduce any visible behavior changes on its own but enables the filtering work to come.
