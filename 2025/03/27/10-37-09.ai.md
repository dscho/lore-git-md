Refactoring patch in Patrick Steinhardt's series to eliminate Perl dependencies from Git's test suite (part 11/20). This installment focuses on replacing Perl's substitution operator ("s/") with equivalent sed(1) commands across multiple test files.

The patch modifies 11 test scripts to use sed instead of Perl for simple text substitutions, allowing removal of several PERL_TEST_HELPERS prerequisites. Key changes include:
- Replacing `perl -pe` substitution pipelines with sed equivalents in t0008-ignores.sh, t4029-diff-trailing-space.sh, and others
- Converting MERGE_RR parsing in t4200-rerere.sh from Perl to sed
- Modernizing pack corruption tests in t5303-pack-corruption-resilience.sh
- Updating push certificate tests in t5534-push-signed.sh to use sed
- Replacing binary file processing in t8006-blame-textconv.sh with sed

The changes maintain identical test behavior while reducing Perl dependencies. Notable technical details:
- Uses sed's -e flag for multiple expressions where Perl used semicolons
- Preserves file modification patterns (creating temp files then moving)
- Keeps existing test logic and assertions unchanged
- Drops PERL_TEST_HELPERS from tests that no longer need Perl

This continues the series' pattern of methodically replacing Perl functionality with shell equivalents while maintaining test coverage. The changes are straightforward substitutions with low risk of behavioral changes, following the established approach from previous patches in the series.
