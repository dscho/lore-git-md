This is part 11/20 of Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. The patch focuses on converting tests that use Perl's substitution operator ("s/") to equivalent sed commands, allowing the removal of several PERL_TEST_HELPERS prerequisites.

The changes affect 11 test files, replacing Perl's substitution operations with sed equivalents while maintaining the same functionality. Notable conversions include:
- Replacing Perl-based string manipulation in t0008-ignores.sh with sed/tr pipelines
- Converting MERGE_RR file parsing in t4200-rerere.sh from Perl to sed
- Modernizing pack corruption tests in t5303-pack-corruption-resilience.sh
- Simplifying push certificate tests in t5534-push-signed.sh

The patch follows the series' established pattern of careful, behavior-preserving conversions. Each change is straightforward and well-justified, continuing the project's steady progress toward making Perl optional for nearly all tests. The remaining Perl dependencies after this patch would primarily be in Gitweb and netrc helper tests, which are handled in later parts of the series.
