This is a bugfix patch addressing compiler detection in the build system, specifically for Clang installations that also have CUDA present. The patch modifies the `detect-compiler` script to handle cases where Clang's version output includes CUDA information, which was previously causing the script to misidentify the compiler family. The fix uses `sed` to only process the first matching "version" string rather than all matches, ensuring proper detection of Clang versions even when CUDA is installed.

Key technical details:
- Changes the version detection from using `grep` to `sed -n '/ version /{p;q;}'` to only output the first matching line
- Fixes a case where CUDA installation messages would interfere with compiler family detection
- Maintains the same behavior for normal Clang installations while fixing edge cases
- Builds on Eric Sunshine's earlier work on portable `sed` syntax in this series
