This is part 16/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on HTTP server test infrastructure. The patch converts the "one-time-perl" CGI script used in HTTP tests to a more flexible "one-time-script" version that doesn't require Perl.

The change generalizes a test helper that was previously hardcoded to run Perl scripts, allowing it to execute any script instead. This affects several HTTP protocol tests that simulate server-side repository changes between requests. The patch updates all callers to use shell utilities rather than Perl, allowing removal of PERL_TEST_HELPERS prerequisites from multiple test files.

Key changes include:
- Renaming endpoints from "one_time_perl" to "one_time_script"
- Replacing the Perl-based CGI script with a shell version
- Converting test cases to use sed/printf instead of Perl
- Removing Perl dependencies from t5537, t5616, t5702, and t5703 tests

The conversion follows the series' pattern of direct command-to-command replacements while maintaining behavior. The patch appears well-executed, with comprehensive updates to both infrastructure and test cases. It continues the systematic reduction of Perl surface area in the test suite while preserving testing rigor.
