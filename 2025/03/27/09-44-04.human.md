This is a refactoring patch in Patrick Steinhardt's series enhancing `git cat-file`'s batch mode filtering capabilities. It prepares for upcoming bitmap integration by consolidating duplicate object iteration logic.

The patch extracts common patterns for iterating over both loose and packed objects into a new `batch_each_object()` helper function. While the current implementation is simple (just combining two existing function calls), the commit message explains this groundwork will become more complex in the next patch when bitmap support is added. The refactoring affects the batch processing paths in `builtin/cat-file.c`, touching both ordered and unordered output modes.

The changes are mechanical but well-contained, replacing direct calls to `for_each_loose_object` and `for_each_packed_object` with the new unified interface. The patch maintains all existing functionality while making the codebase more maintainable for the bitmap work to come. As part of a mature series (now at v2), this appears to be a straightforward preparatory step in the larger filtering enhancement effort.
