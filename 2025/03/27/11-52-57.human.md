This is a refactoring patch in Johannes Schindelin's series eliminating comma operators from Git's codebase, specifically targeting the test infrastructure (clar framework). The patch modifies two directory traversal loops in the unit test framework's filesystem helpers to replace comma operator usage with more explicit semicolon-separated statements.

The changes convert while loops that combined error checking and directory entry reading into for loops with clearer control flow. Each loop now:
1. Explicitly sets errno to 0 before reading
2. Checks the readdir result in a separate if statement
3. Breaks if NULL is returned

This matches the series' goal of improving code clarity by removing potentially confusing comma operator usage. The changes are straightforward and maintain the same functionality while being more readable. As part of a well-reviewed series that's already addressed all technical concerns, this patch appears ready for integration.
