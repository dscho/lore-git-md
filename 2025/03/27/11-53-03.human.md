This is a bugfix patch in the final part of Johannes Schindelin's series eliminating comma operators from Git's codebase. The patch addresses a specific edge case in the `detect-compiler` script where CUDA installations could interfere with Clang version detection.

The issue occurs when Clang detects a CUDA installation, causing its version output to include an additional line about CUDA that also contains the word "version". This confused the script's parsing logic, leading it to incorrectly report an "unknown compiler family" instead of properly identifying Clang versions.

The fix is straightforward - modify the version detection to only process the first matching line containing "version" using `sed -n` with an early exit. This ensures CUDA-related output won't interfere while maintaining all existing functionality. Eric Sunshine helped with the solution, which uses the same portable `sed` syntax already established earlier in the series for compiler version detection.

As part of the final patch in this well-reviewed series, this change completes the build system robustness improvements by ensuring consistent compiler detection across all platforms, including edge cases like systems with CUDA toolchains installed. The patch follows the series' established patterns and has no outstanding technical questions.
