This is part 3/20 of Patrick Steinhardt's series to remove Perl dependencies from Git's test suite, focusing on character translation helpers. The patch converts three helper functions in `t/test-lib-functions.sh` from using Perl scripts to using the standard Unix `tr` command:

1. `lf_to_nul` (LF to NUL)
2. `nul_to_q` (NUL to 'Q')
3. `q_to_nul` ('Q' to NUL)

The commit message explains that while NUL handling in `tr` had historical platform inconsistencies, POSIX-compliant implementations now correctly handle NUL character translation. This change is straightforward since the character substitutions are simple one-to-one mappings that `tr` handles well.

The conversion follows the series' pattern of replacing Perl with standard Unix utilities where possible. This particular change enables more tests to run without Perl available, though the commit doesn't specify exactly which tests are affected. The patch is small (6 lines changed) and appears mechanically sound, continuing the series' careful approach to maintaining identical behavior while removing dependencies.
