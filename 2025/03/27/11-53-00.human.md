This is a refactoring patch in a series eliminating comma operator usage in Git's codebase. The patch focuses on `wildmatch.c`, which handles wildcard pattern matching.

The change, Johannes Schindelin converts an intentional but hard-to-read comma operator usage in a loop condition into a clearer `goto`-based approach. The original code used the comma operator to both update `prev_ch` and advance the pointer in the loop condition. The new version moves these operations into the loop body with a `next:` label, maintaining the same behavior while improving readability. Phillip Wood helped review the change to ensure proper handling of the `continue` case for character class matching.

This is part of a larger, well-reviewed series that has already addressed similar changes across multiple subsystems, with all technical questions resolved. The patch follows the project's preferred style of explicit control flow over comma operators, even when their use was originally intentional.
