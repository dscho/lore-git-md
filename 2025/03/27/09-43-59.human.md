Feature implementation for Git's cat-file batch filtering. This is the fourth patch in Patrick Steinhardt's v2 series enhancing `git cat-file`'s object filtering capabilities, following up on the previously implemented `blob:none` filter.

The patch adds support for a new `blob:limit=<size>` filter that excludes blobs larger than a specified size threshold. The implementation handles size specifications with optional k/m/g suffixes for kilobytes, megabytes, and gigabytes. The filter works across all object storage formats (packed with bitmaps, packed without bitmaps, and loose objects), maintaining the series' architectural approach.

Key technical aspects include:
- New `LOFC_BLOB_LIMIT` enum value
- Size comparison logic in the object processing path
- Comprehensive tests covering various size thresholds
- Documentation of the new filter syntax

The implementation appears clean and follows the pattern established by the previous `blob:none` filter. Test coverage is thorough, including edge cases with very large size limits (1GB) and verification across different storage types. This continues the series' trend of well-documented, carefully tested additions to Git's object filtering capabilities.
