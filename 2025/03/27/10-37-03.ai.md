This is part 5/20 of Patrick Steinhardt's series to remove Perl dependencies from Git's test infrastructure, specifically targeting the `test_readlink()` helper function. The patch converts the Perl-based implementation to a new C` implementation in `test-tool path-utils`.

The change replaces the one-line Perl call that reads symlink targets with a new C function in the test helper that uses Git's existing `strbuf_readlink()` infrastructure. The implementation handles multiple input paths and properly reports errors via `die_errno()`. The shell interface in `t/test-lib-functions.sh` is updated to call the new C implementation instead of Perl.

Key technical details:
- New `readlink` subcommand added to `test-tool path-utils`
- Uses Git's `strbuf_readlink()` for actual symlink reading
- Maintains same interface (handles multiple paths, returns targets one per line)
- Preserves error handling (dies on readlink failure)
- Updates all callers via the modified `test_readlink()` shell function

This continues the series' pattern of moving test infrastructure from Perl to either shell or C implementations in test-tool, further reducing the test suite's Perl dependency while maintaining identical behavior. The change is straightforward and builds on existing Git infrastructure (`strbuf_readlink()`), making it a low-risk conversion.
