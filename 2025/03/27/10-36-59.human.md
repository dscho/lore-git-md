This is the first patch in Patrick Steinhardt's v3 series to make Perl optional in Git's test suite. The patch focuses on the chain linter, a Perl script that verifies proper '&&' chaining in test files.

The change makes the chain linter automatically disable itself when Perl isn't available (PERL_PATH unset), while still allowing explicit control via GIT_TEST_CHAIN_LINT. If a developer specifically requests chain linting without Perl available, it will error out rather than silently failing. This provides a smoother experience for developers working without Perl while maintaining the ability to enforce linting when desired.

The patch is a straightforward modification to t/test-lib.sh that adds logic to handle the PERL_PATH case. It's a clean, focused change that serves as groundwork for the larger Perl-removal effort, addressing one of the early pain points developers would face when running tests without Perl installed. The commit message clearly explains both the current behavior and the motivation for the change.
