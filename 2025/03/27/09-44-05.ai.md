This is the final patch in Patrick Steinhardt's series enhancing `git cat-file` with bitmap-based object filtering, specifically focusing on type-based filtering performance. The patch implements bitmap acceleration for object type filtering in `cat-file`, completing the architectural work laid out in previous patches.

The key technical addition is the integration of bitmap lookups when filtering by object type, which provides dramatic performance improvements - up to 41x faster for commit filtering in the Chromium repository benchmark (86s → 2s). The implementation carefully handles mixed scenarios where some packs have bitmaps while others don't, falling back to the existing packfile scan for non-bitmapped packs. The patch introduces a new `batch_one_object_bitmapped` callback handler and modifies the core `batch_each_object` function to first attempt bitmap iteration before falling back to full pack scans.

The changes touch the bitmap iteration infrastructure, adding support for the new filter types while maintaining the existing pack order semantics. The implementation builds on the `for_each_bitmapped_object` function and filter framework introduced earlier in the series. Performance measurements confirm the expected behavior: no regression for unfiltered operation (where bitmaps provide no benefit) and massive speedups when filtering by type.

This completes the series' goal of efficient object filtering in `cat-file`, demonstrating the architectural soundness of the earlier preparatory work. The patch maintains consistency with the series' incremental approach while delivering the promised performance benefits.
