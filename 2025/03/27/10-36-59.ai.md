Test infrastructure patch in Patrick Steinhardt's series to make Perl optional in Git's test suite. This is the first of 20 patches in v3 of the series, which has already undergone extensive review.

The patch modifies `t/test-lib.sh` to automatically disable the chain linter when Perl is unavailable (`PERL_PATH` unset), unless the user has explicitly requested chain linting (in which case it errors out). The chain linter, which verifies proper '&&' chaining in tests, is currently Perl-based and runs before each test. This change is part of the broader effort to reduce Perl dependencies, making the test suite more portable.

The implementation handles three cases: when `GIT_TEST_CHAIN_LINT` is unset (defaults to 0 without Perl), explicitly 0 (no action needed), or enabled (errors out if Perl missing). This maintains functionality for those with Perl while gracefully degrading for those without, following the series' goal of making Perl truly optional. The patch is straightforward and well-contained, touching only the test infrastructure without affecting test behavior itself.
