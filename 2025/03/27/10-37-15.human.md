This is part 17/20 of Patrick Steinhardt's series to eliminate Perl dependencies from Git's test suite, focusing on test infrastructure refactoring.

The patch converts the `generate_random_characters()` helper function in t0021-conversion.sh from using Perl to a combination of POSIX tools. The function generates random lowercase letters for test files. The new implementation uses `test-tool genrandom` piped through `tr` to filter characters, then `test_copy_bytes` to get the desired length. This removes the need for Perl in this test file, allowing the removal of PERL_TEST_HELPERS prerequisites from three test cases.

The change follows the series' established pattern of replacing Perl with POSIX tools while maintaining identical behavior. The conversion appears straightforward and well-contained, affecting only test infrastructure without changing any actual test logic. This continues the systematic reduction of Perl surface area in the test suite while preserving test fidelity.
