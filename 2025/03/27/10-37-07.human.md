This is part 9/20 of Patrick Steinhardt's series to make Perl optional for running Git's test suite. The patch modifies the Makefile to remove hard dependencies on Perl for test execution, while maintaining functionality when Perl is present.

The changes make several test-related targets conditional on Perl availability:
- The `check-chainlint` target (which uses Perl for shell script linting) is now optional
- Shell syntax linting is skipped when Perl isn't available
- The prove target's chainlint check is made optional
- Chain linting is disabled by default when Perl is absent

This continues the series' careful approach of maintaining backward compatibility while progressively removing Perl requirements. The changes align with previous infrastructure work that established the `PERL_TEST_HELPERS` prerequisite system. The patch appears well-considered, with clear conditional logic and appropriate fallback behavior when Perl is unavailable.
