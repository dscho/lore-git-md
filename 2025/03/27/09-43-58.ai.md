This is part of Patrick Steinhardt's series enhancing `git cat-file` with object filtering capabilities, specifically implementing the "blob:none" filter in this patch.

The patch adds support for excluding all blob objects from `git cat-file` output when using batch mode with `--filter=blob:none`. The implementation:
- Updates documentation to describe the new filter
- Modifies `builtin/cat-file.c` to skip blob objects when this filter is active
- Adds comprehensive tests that verify the filter works across different object storage types (bitmapped pack, non-bitmapped pack, and loose objects)

Key technical details include:
- New `LOFC_BLOB_NONE` enum case in `list_objects_filter_choice`
- Filter validation in both batch processing and command-line parsing
- Test coverage that cross-validates against `git rev-list --filter` output
- Careful handling of object type information needed for filtering

The implementation appears clean and well-tested, with particular attention paid to ensuring the filter works consistently regardless of how objects are stored. This builds on the series' earlier work establishing the filtering infrastructure while delivering the first concrete filter type. The test setup specifically exercises all three major object storage pathways (bitmapped, packed, loose) to ensure comprehensive coverage.
