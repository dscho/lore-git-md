This is part 4/20 of Patrick Steinhardt's series to remove Perl dependencies from Git's test infrastructure. The patch converts the `test_copy_bytes()` helper function from using Perl to using `dd(1)`, which is a standard Unix tool available everywhere.

The change is straightforward - the Perl implementation that carefully read and copied bytes is replaced with a simple `dd` command that does the same job. This allows more tests to run without requiring Perl, bringing the project closer to its goal of making Perl optional for 97% of the test suite.

The patch follows the established pattern of the series: identify a Perl dependency in test infrastructure, replace it with equivalent shell/Unix tools, and verify behavior remains identical. This particular change appears clean and well-motivated, continuing the series' steady progress toward Perl independence. The diff shows a significant simplification (11 lines of Perl reduced to 1 line of `dd`), suggesting this was a good candidate for conversion.
