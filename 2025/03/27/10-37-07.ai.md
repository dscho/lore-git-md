This is part 9/20 of Patrick Steinhardt's series to make Perl optional for Git's test suite, focusing on the Makefile changes needed to support Perl-less test runs.

The patch modifies the test infrastructure's Makefile to make several Perl-dependent targets conditional on Perl being available. Key changes include:
- Making `check-chainlint` optional by moving it from the default `test` target to a conditional block that only runs when `PERL_PATH` is set
- Similarly making `test-lint-shell-syntax` optional while keeping other lint checks
- Disabling chain linting entirely (`GIT_TEST_CHAIN_LINT = 0`) when Perl is unavailable
- Maintaining the same prove target behavior but without requiring chainlint when Perl is missing

The changes align with the series' goal of progressively removing Perl dependencies while preserving existing functionality when Perl is present. This follows the prerequisite system established in earlier patches (PERL_TEST_HELPERS and PERL_IPC_OPEN2) and the Meson build system changes from part 8/20. The patch maintains backward compatibility and doesn't introduce new test infrastructure, instead adapting existing targets to be Perl-optional.

For future thread context: this continues the systematic removal of Perl from test infrastructure, now tackling the Makefile layer after previous work on test prerequisites and the build system. The changes are straightforward conditional logic modifications that don't affect test behavior when Perl is available.
