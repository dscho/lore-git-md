This is part 13/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on textconv-related tests. The patch converts three test files (t4030, t4031, t7815) that previously relied on Perl for textconv scripts to use simpler shell utilities instead.

The key changes involve:
- Replacing Perl-based hexdump implementations with simpler `tr` and `test-tool hexdump` calls
- Removing PERL_TEST_HELPERS prerequisites now that Perl is no longer needed
- Simplifying test expectations where exact binary-to-text conversion fidelity isn't critical
- Maintaining the same test coverage while using more lightweight POSIX tools

Notable technical details:
- The `dump` script in t4031 now uses `test-tool hexdump` instead of Perl
- Binary-to-text conversions are simplified to just verify basic functionality rather than exact output
- All three tests retain their core verification of textconv behavior despite the simpler implementations
- The changes follow the series' pattern of direct command-to-command replacements where possible
