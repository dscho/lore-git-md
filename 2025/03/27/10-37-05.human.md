This is part 7/20 of Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. The patch focuses on cleaning up test prerequisites that incorrectly specify PERL when they no longer need Perl functionality.

The changes fall into three categories: removing PERL prerequisites where the underlying logic no longer uses Perl, removing them where the test logic itself no longer depends on Perl, and updating tests that still need Perl to use the new PERL_TEST_HELPERS prerequisite introduced in patch 6/20. The patch updates 4 test files with these changes.

A notable technical detail is in t1006-cat-file.sh, where the patch introduces a new PERL_IPC_OPEN2 prerequisite to properly handle tests that specifically need Perl's IPC::Open2 module. This required renaming a variable from "script" to "perl_script" to avoid conflicts with test infrastructure variables.

The changes are behavior-preserving and follow the series' pattern of careful prerequisite management. This patch continues the series' high standard of technical precision while making incremental progress toward the goal of making Perl optional for most tests.
