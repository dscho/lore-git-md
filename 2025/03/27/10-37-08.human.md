This is part 10/20 of Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. The patch focuses on replacing Perl's transliteration operators ("y/" and "tr/") with the standard Unix `tr` command in several test files.

The changes are straightforward mechanical conversions where Perl was previously used for simple character substitution. The patch modifies 7 test files, removing Perl dependencies from test cases that were doing basic character translation (like converting null bytes to newlines or changing letter cases). As a result, it's able to drop several `PERL_TEST_HELPERS` prerequisites from the tests.

The changes maintain identical test behavior while reducing the Perl footprint. One test in t4103-apply-binary.sh still requires Perl for testing truncated binary diffs, showing this is a targeted change rather than a complete removal where Perl is still needed for more complex cases.

This continues the series' pattern of systematically identifying and removing Perl dependencies where possible while maintaining test coverage. The changes are clean and well-contained, following the established approach from previous patches in the series.
