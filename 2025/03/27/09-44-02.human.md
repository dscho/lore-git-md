Performance enhancement in the Git bitmap subsystem, part of Patrick Steinhardt's ongoing series to improve filtered object iteration.

This patch introduces `for_each_bitmapped_object()`, a new function that efficiently iterates over bitmapped objects while applying a given filter. The implementation builds on the series' earlier work by:
1. Starting with a full bitmap (all objects selected)
2. Applying the filter to reduce the bitmap
3. Iterating through the filtered results by object type (commit, tree, blob, tag)

The changes are focused on the pack-bitmap internals, modifying both the implementation and header files. Key technical points include:
- The function returns -1 for unsupported filters (maintaining backward compatibility)
- Memory management for temporary bitmaps is handled properly
- Existing traversal functions are updated to explicitly pass the result bitmap

This appears to be a well-constructed piece of infrastructure work that enables the series' goal of efficient filtered object access. The changes are focused and maintainable, with clear documentation of the new function's purpose and behavior. As part 7/10 of the series, it builds on established patterns while preparing for subsequent optimizations in `git cat-file`.
