This is part 8/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite, focusing on the Meson build system integration. The patch removes the hard requirement for Perl when tests are enabled, reflecting the series' progress in making most tests run without Perl. 

The change modifies meson.build to only enforce Perl as a hard dependency for Gitweb and the netrc credential helper, which remain Perl-dependent. This aligns with the series' goal of making Perl optional for 97% of tests (30342/31358). The patch is a straightforward one-line change to the build configuration, removing `get_option('tests')` from the conditions that trigger a mandatory Perl requirement.

This builds on infrastructure from previous patches (2/20-7/20) that introduced finer-grained Perl dependency tracking through prerequisites like `PERL_TEST_HELPERS` and `PERL_IPC_OPEN2`. The change maintains backward compatibility while allowing test execution without Perl where possible. The patch follows the series' established pattern of behavior-preserving changes with clear documentation updates.
