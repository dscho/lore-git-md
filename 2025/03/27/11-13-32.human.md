Feature completing the batched reference updates series (v5 8/8). This final patch adds user-facing support for partial reference updates via a new `--batch-updates` flag for `git update-ref --stdin`. 

The flag builds on the infrastructure from earlier patches in the series, allowing individual reference updates to fail while still applying the successful ones. System errors (like I/O failures) still abort the entire transaction, but user errors (invalid refnames, incorrect old values) are reported per-update in a structured format. The patch includes comprehensive tests covering various rejection scenarios - invalid OIDs, nonexistent refs, symref conflicts, and refname collisions.
