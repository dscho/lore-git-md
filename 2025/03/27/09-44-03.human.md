This is a preparatory patch in Patrick Steinhardt's series enhancing Git's cat-file batch mode filtering capabilities, specifically focusing on bitmap integration. The patch introduces a new helper function `bitmap_index_contains_pack()` that checks whether a given packfile is referenced in a bitmap index, either directly or through a multi-pack-index.

The implementation handles both regular packfiles and MIDX cases, with a simple linear search in the MIDX case. While the commit message is brief, it's part of a well-structured series where this utility function will be used in subsequent commits for bitmap filtering operations. The patch appears clean and focused, with Taylor Blau credited as a helper, suggesting it builds on established bitmap expertise.
