Feature enhancement for `git cat-file` batch mode filtering, part of a series to optimize object enumeration.

This patch (2/10 in v2 series) introduces the `--filter` option to `git cat-file`'s batch mode, matching the syntax from `git rev-list`. Currently it just rejects all filter types with an error, but sets up the plumbing for subsequent patches to implement actual filtering. The commit explains this is groundwork for future bitmap-based optimizations that will significantly speed up filtered object enumeration.

The implementation adds:
- Documentation of the new `--filter` option
- Filter option parsing via existing list-objects-filter infrastructure
- Basic validation that rejects unsupported filter types (to be implemented later)
- Test cases verifying error messages for various filter types

This is a well-structured patch that clearly fits into the larger series goal of optimizing object filtering. The commit message provides good context about current limitations (I/O-bound performance) and future plans (bitmap integration). The test coverage appears thorough for this initial scaffolding step.

The patch maintains clean separation of concerns, building on existing filter infrastructure while clearly marking unimplemented functionality. It follows the series' established pattern of incremental implementation, making this a solid foundation for the actual filter implementations to come in later patches.
