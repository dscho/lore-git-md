Continuing Patrick Steinhardt's series to remove Perl dependencies from Git's test suite, this patch (10/20) focuses on replacing Perl's transliteration operator ("y/" or "tr/") with the standard `tr(1)` utility. The changes affect seven test files that previously used Perl for simple character substitutions.

The patch systematically converts all instances of `perl -pe 'y/X/Y/'` to `tr "X" "Y"` across various test scenarios including:
- SHA1 test helper character substitution
- Diff output processing
- Funny filename handling
- Binary file manipulation
- Rerere metadata handling

Notably, this allows removing several `PERL_TEST_HELPERS` prerequisites from tests that no longer need Perl. One exception remains in t4103-apply-binary.sh where Perl is still needed for a truncated binary diff test case.

The changes maintain identical test behavior while reducing the Perl footprint. This follows the series' established pattern of methodically identifying and replacing Perl dependencies with equivalent shell/C alternatives. The patch appears well-scoped and mechanically sound, continuing the series' high standard of careful, incremental modernization.
