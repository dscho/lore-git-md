This is the final patch in Patrick Steinhardt's 20-part series to eliminate Perl dependencies from Git's test suite. It tackles the remaining Perl usage in t5703, which tests the upload-pack ref-in-want protocol capability.

The patch makes two key changes:
1. Replaces Perl-based capability filtering with `test_grep` for checking ref-in-want advertisements, removing the global Perl prerequisite from these tests
2. Keeps Perl for CGI script setup in HTTPD tests but scopes the prerequisite to just those individual test cases

This shows the series' approach in microcosm - aggressively removing Perl where possible while pragmatically retaining it for complex cases that would require significant refactoring. The patch maintains all test coverage while reducing the test suite's Perl surface area. With this change, the series has now converted all test cases except for Gitweb and netrc helper tests, bringing the project closer to its goal of Perl-free testing.
