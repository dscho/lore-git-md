This is part 17/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on test infrastructure refactoring. The patch converts the `generate_random_characters()` helper function in t0021-conversion.sh from using Perl to a POSIX-compatible implementation.

The function generates random lowercase letters by:
1. Using `test-tool genrandom` to produce an infinite stream of random bytes
2. Filtering to just 'a-z' range via `tr -dc`
3. Copying exactly N bytes with `test_copy_bytes`

This change removes the PERL_TEST_HELPERS prerequisite from three test cases that relied on this helper. The conversion follows the series' pattern of direct Perl-to-POSIX replacements while maintaining identical behavior. The implementation appears straightforward and well-contained, affecting only test infrastructure without modifying any core functionality.

Key technical details for future reference:
- Modified file: t/t0021-conversion.sh
- Removed Perl regex substitution in favor of `tr` filtering
- Uses existing test-tool genrandom with modified invocation
- Retains same random generation seed ('some-seed') for reproducibility
- Updates three test cases to no longer require PERL_TEST_HELPERS
