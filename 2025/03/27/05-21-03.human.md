This is a platform compatibility fix for the compiler detection logic in Git's build system. Eric Sunshine points out a subtle but important difference in `sed` behavior between GNU and BSD/macOS variants that affects how we extract compiler version information. 

The issue arises when trying to parse the output of `cc -v` to find the version string. While Jeff King had suggested a simpler `sed` pattern, Eric demonstrates that this would incorrectly quit after the first line of output regardless of content. His corrected version properly matches lines containing "version" before quitting, which is crucial since compiler output may start with copyright notices or other non-version text.

This comes as a follow-up to earlier discussion about BSD/macOS `sed` syntax quirks, where Eric had previously identified and fixed another issue with command termination. The exchange shows careful attention to cross-platform edge cases in the ongoing work to unify Git's build system behavior across different environments. The fix is small but important for reliable compiler detection on BSD/macOS systems.
