Part of Patrick Steinhardt's ongoing series to eliminate Perl dependencies in Git's test suite (16/20). This patch converts the HTTPD test infrastructure's "one-time-perl" CGI script to a more flexible "one-time-script" version that doesn't require Perl.

The change generalizes a test helper that was previously hardcoded to expect Perl scripts, allowing any executable to modify HTTP responses. The core functionality remains the same: a script runs once to transform a response, then gets deleted to prevent re-execution. Key changes include:
- Renaming endpoints and files from `one-time-perl` to `one-time-script`
- Replacing Perl-specific processing with generic script execution
- Updating four test scripts (t5537, t5616, t5702, t5703) to use shell utilities instead of Perl
- Removing PERL_TEST_HELPERS prerequisites where no longer needed

The patch demonstrates the series' pattern of direct command-to-command replacements while expanding the scope to handle HTTP protocol testing scenarios. It maintains behavior fidelity while removing another Perl dependency, with tests now using sed and shell scripts for response modification. The changes affect HTTPD test infrastructure and protocol tests, particularly around fetch operations, shallow clones, and negotiation.
