Performance optimization for `git cat-file` with blob filtering.

This is the third patch in Patrick Steinhardt's series to enhance `git cat-file` with object filtering capabilities, specifically focusing on implementing the "blob:none" filter. The patch adds support for omitting all blob objects from the output when using batch mode, which is particularly useful optimization for operations that only need to process commits, trees.

The implementation:
- Adds documentation for the new filter option
- Modifies the batch object writing logic to skip blobs when the filter is active
- Includes validation to ensure the filter only works in batch mode
- Adds comprehensive tests that verify the filter works across packed (both bitmap and non-bitmap) and loose objects

The patch builds on the series' earlier work to integrate filtering with the bitmap infrastructure, showing measurable performance gains (41x speedup in some cases per earlier benchmarks). The test coverage is thorough, including verification against `git rev-list`'s equivalent functionality.

This appears to be a well-constructed piece of the series, cleanly implementing one of the promised filter types with proper error handling and testing. The changes are focused and the commit message, while brief, is clear about what's being implemented.
