This is part 15/20 of Patrick Steinhardt's series to eliminate Perl dependencies in Git's test suite, focusing on refactoring test infrastructure. The patch converts the `name_from_description()` helper function from Perl to a combination of sed and tr commands. This function is used in t6000-series tests to sanitize test descriptions into filenames by replacing non-alphanumeric characters with dashes and normalizing case.

Key changes:
- Replaces Perl regex processing with equivalent sed/tr commands while maintaining identical transformation behavior
- Removes PERL_TEST_HELPERS prerequisite declarations from t6002-rev-list-bisect.sh and t6003-rev-list-topo-order.sh
- Keeps the same five transformation steps (character substitution, dash compression, leading/trailing dash removal, case conversion)

The conversion follows the established pattern of the series by:
1. Identifying a Perl-dependent test helper
2. Reimplementing its logic with POSIX tools
3. Removing now-unnecessary Perl prerequisites from test files
4. Maintaining identical behavior through the transition

This continues the series' systematic approach to Perl removal while demonstrating the ability to handle string manipulation tasks with POSIX tools. The change is straightforward and maintains test coverage while reducing the Perl surface area in the test suite.
