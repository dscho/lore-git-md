This is the final patch in Patrick Steinhardt's series enhancing `git cat-file`'s batch mode filtering capabilities, specifically focusing on performance optimization through bitmap integration.

The patch enables `git cat-file` to use bitmap indexes when filtering objects by type, which provides a dramatic speed improvement - benchmarks show a 41x speedup when filtering for commits in a large repository (Chromium's 50GB packfile with 25M objects). The key insight is that while bitmaps are typically used for reachability, they also encode type information that can be leveraged to avoid scanning entire packfiles when filtering.

The implementation adds bitmap-aware iteration path while maintaining the existing non-bitmap fallback for packfiles without bitmaps. The changes are focused in `builtin/cat-file.c`, introducing a bitmap callback handler and modifying the object iteration logic to first try the bitmap path before falling back to full scans. The patch maintains the series' careful approach, building on previous refactoring work while delivering measurable performance benefits.

This completes the technical implementation of the filtering feature, demonstrating the value of the preparatory refactoring done in earlier patches. The performance numbers validate the approach, showing the bitmap optimization is particularly effective for type-based filtering scenarios.
