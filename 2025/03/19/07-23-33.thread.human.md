This thread introduces a refactoring and bugfix series for Git's pretty-format parsing code, authored by Martin Ågren. The 8-patch series aims to modernize and clean up the pretty-format logic while fixing some minor bugs in the process.

The changes start with straightforward cleanups like tightening function signatures and reducing code duplication. The middle patches address padding-related issues, fixing parsing of incomplete padding placeholders ("%<" and "%>") and improving padding state handling. Later patches refactor the parsing logic for line-wrapping ("%w"), magic placeholders, and decoration options into more focused functions and data structures.

While these changes don't introduce new functionality, they significantly improve code organization by breaking down complex functions and better structuring related data. The series touches core pretty-format code in pretty.c and includes corresponding test updates. Martin has taken care to CC original authors where appropriate, as some changes affect long-standing code paths. The work appears to lay groundwork for potential future refactoring of the pretty-format system, though the current patches stand on their own as valuable cleanups and bugfixes.
