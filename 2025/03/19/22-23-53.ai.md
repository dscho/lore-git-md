Code cleanup in HTTP keepalive series (v2 3/4):

This patch inlines the `set_curl_keepalive()` helper function into `get_curl_handle()` as part of the HTTP keepalive configuration series. The function had become obsolete after Git dropped support for curl versions older than 7.25.0 (via f7c094060c), making it a simple one-liner that no longer needs its own wrapper.

The change removes historical conditional compilation cruft while maintaining identical functionality - the CURLOPT_TCP_KEEPALIVE option is still set exactly as before, just directly in the calling function. This follows the series' pattern of cleaning up legacy HTTP code while implementing new keepalive configuration options.

Key technical details:
- Removes standalone `set_curl_keepalive()` function from http.c
- Moves its single `curl_easy_setopt()` call inline in `get_curl_handle()`
- Preserves all existing behavior
- Builds on prior curl version compatibility cleanup (f7c094060c)

The patch is a straightforward code hygiene improvement that fits naturally with the series' focus on modernizing HTTP-related curl handling. It shows attention to removing obsolete code paths while keeping the core functionality intact.
