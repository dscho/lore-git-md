This is a preparatory refactoring patch in the HTTP keepalive configuration series. Elijah Newren is responding to Taylor Blau's initial patch that introduces a new helper function `set_long_from_env()` for parsing environment variables into long integers.

The change replaces two existing manual `getenv()` + `strtol()` patterns with calls to the new helper, removing temporary variables and cleaning up some code duplication. As noted, this is groundwork for future patches in the series that will need similar environment-to-long parsing for the new keepalive configuration options.

The patch is straightforward with no behavior changes - it's purely a code hygiene improvement that makes the HTTP initialization code more maintainable. The implementation looks clean and well-contained, exactly what you'd want from preparatory work in a series.
