Feature patch adding HTTP TCP keepalive configuration options.

This final patch in the series introduces three new configuration options (`http.keepaliveidle`, `http.keepaliveinterval`, and `http.keepalivecount`) to control curl's TCP keepalive behavior, addressing bandwidth-limited clone failures. The options allow fine-tuning how often Git sends keepalive probes during HTTP operations, with environment variable overrides (`GIT_HTTP_KEEPALIVE_*`) for each setting.

The implementation carefully handles version compatibility - while KEEPIDLE and KEEPINTVL are set unconditionally (supported since curl 7.25.0), KEEPCNT is only set when compiled with curl 8.9.0 or newer. The patch includes thorough documentation of the new option in config/http.adoc and maintains the series' focus on clean type handling.

This completes the v2 series which has seen positive feedback and refinements from multiple contributors. The implementation appears solid, with clear motivation (reproducible connection drops during bandwidth-limited clones) and proper attention to backward compatibility. The documentation is comprehensive, explaining both the configuration options and their environment variable counterparts.
