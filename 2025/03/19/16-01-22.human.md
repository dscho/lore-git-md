This is a refactoring patch in the HTTP TCP keepalive configuration series. It inlines the `set_curl_keepalive()` helper function into `get_curl_handle()` since the function had become a trivial one-liner after Git dropped support for older versions of curl.

The change is straightforward - it removes the standalone function and directly calls `curl_easy_setopt()` where the helper was previously used. The patch maintains the same functionality while simplifying the code structure. As Elijah Newren notes in his reply, this makes sense here since the helper was doing very little work.

This appears to be a clean, uncontroversial change that follows naturally from the earlier removal of curl version compatibility code. It's part of the broader effort to improve HTTP keepalive handling, though this particular patch is purely about code organization rather than adding new functionality. The change is small (5 lines removed, 1 line added) and well-contained to `http.c`.
