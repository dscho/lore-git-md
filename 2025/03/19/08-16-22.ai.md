Completion script modernization and portability fix (v2 patch 1/2)

This patch updates the shell completion infrastructure to handle manpage formatting changes where options are now backtick-wrapped in definition lists. The key change rewrites `generate-configlist.sh` to use a single portable `sed -E` command instead of multiple piped commands, addressing Junio's feedback about GNU-specific BRE features in v1.

The new implementation:
- Matches lines with optional backticks around config options
- Filters out deprecated items
- Removes trailing `::` and backticks
- Splits comma-separated options across multiple lines
- Maintains the same output format for `config_name_list[]`

Technical details:
- Uses ERE (`-E`) for portability instead of GNU BRE
- Consolidates processing into one `sed` pass
- Preserves all functionality (deprecation filtering, backtick handling, comma separation)
- Still outputs sorted list of config options
- Files touched: `generate-configlist.sh`
- Builds on Jean-Noël Avila's documentation standardization work
- Fixes regression caught by `t9902` completion tests
