Test patch for the new gitconfig userdiff driver.

This is the second patch in a 2-part series introducing a userdiff driver for gitconfig files. It adds four test cases to t4018 (the userdiff test suite) covering the syntax patterns handled by the new driver from patch 1/2. The tests verify correct highlighting of both basic `[section]` headers and `[section "subsection"]` formats, with variants for indented and non-indented configurations. Each test file contains sample gitconfig syntax including comments (both `#` and `;` styles), key-value pairs, and a "ChangeMe" marker to demonstrate diff highlighting behavior.

The test cases are minimal but comprehensive, covering the main syntax forms documented in Git's config file format. The patch follows Git's testing conventions, with each case in a separate file in t/t4018/. This completes the series by providing verification for the simple regex patterns added in the first patch. No changes to the test infrastructure are needed since the new driver uses Git's standard userdiff mechanism.
