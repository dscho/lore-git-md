Refactoring patch completing a series to modularize pretty-format parsing. This is the final patch in Martin Ågren's 8-part series cleaning up Git's pretty-format parsing code in pretty.c. While earlier patches tackled padding and line-wrapping logic, this one focuses on the decoration options parsing (used in `%(decorate)` placeholders).

The change moves the handling of the decoration options' syntax (the ':' separator and closing ')') into `parse_decoration_options()`, making it a more self-contained unit. This includes proper cleanup of allocated memory in error cases. The patch maintains all existing behavior while making the code more maintainable by centralizing the decoration option parsing logic.

Like the rest of the series, this is purely an internal refactoring with no user-visible changes. The work follows the established pattern of breaking down complex formatting logic into smaller, more focused functions. With this patch, the series appears complete, having systematically modularized the pretty-format parsing code while fixing a few edge cases along the way.
