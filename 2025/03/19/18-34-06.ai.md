This is a refactoring patch that's part of a series adding NUL-delimited output support to `git rev-list`.

- Removes `show_object_with_name()` from revision.c` and its declaration from `revision.h`
- Moves the implementation directly into `builtin/rev-list.c`'s `show_object()`
- Factors out common OID printing between named and unnamed object cases
- Maintains identical output format (space-separated OID and path)
- Part of groundwork for NUL-delimited output support in later patches

The change is straightforward and mechanical, with no behavior modification. It simplifies the code by removing an unnecessary abstraction layer and co-locating related functionality. The patch follows the series' pattern of preparatory refactoring before introducing new features.
