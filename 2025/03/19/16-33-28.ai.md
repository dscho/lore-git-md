CI / build system fix for GitHub Actions workflow configuration. This patch from Karthik Nayak addresses the root cause of Meson installation failures in CI by properly setting the `CI_JOB_IMAGE` environment variable in `.github/workflows/main.yml`. The fix applies to several jobs (excluding Windows) that were missing this variable, which is needed by the shared `ci/install-dependencies.sh` script to determine the correct package installation method.

The patch specifically adds the variable to the Documentation job (which requires meson), StaticAnalysis, and sparse jobs. Karthik notes this makes Junio Hamano's earlier workaround (commit 4451a164e5) obsolete. The change follows the standard GitHub Actions YAML format and maintains consistency with existing job configurations.

Key technical details:
- Adds `CI_JOB_IMAGE` to match `runs-on` values (ubuntu-latest, ubuntu-22.04, ubuntu-20.04)
- Explicitly skips Windows jobs which handle dependencies differently
- Affects dependency installation path in `ci/install-dependencies.sh`
- Validated via GitHub Actions test run PR #1927

This appears to be a well-justified fix that properly addresses the underlying issue rather than working around symptoms. The patch is cleanly formatted and follows the established pattern for CI configuration changes. It represents the final implementation phase of the debugging process that began with Junio's temporary workaround.
