Refactoring patch in the HTTP TCP keepalive configuration series.

This is the second patch in a four-part series introducing TCP keepalive configuration for HTTP operations. It introduces a new helper function `set_long_from_env()` to clean up environment variable parsing for long integer values in http.c. The function provides more robust error handling than the previous ad-hoc approach while eliminating code.

The patch replaces two existing instances of manual environment variable parsing (for `GIT_HTTP_LOW_SPEED_LIMIT` and `GIT_HTTP_LOW_SPEED_TIME`) with calls to the new helper. The helper properly checks for parse errors and preserves errno, addressing technical debt from 2009 while maintaining identical behavior.

Key technical details:
- New static function `set_long_from_env()` handles strtol() conversion with full error checking
- Replaces direct getenv()/strtol() pairs for curl_low_speed_limit/time
- Preserves existing behavior while adding warning messages for parse failures
- Prepares for future additions of similar environment variable handling
- Part of broader effort to improve HTTP configuration handling

The change demonstrates good code hygiene and follows the series' theme of improving type safety around curl-related settings. It builds on feedback from the v1 discussion while maintaining focus on the core TCP keepalive functionality to come in later patches.
