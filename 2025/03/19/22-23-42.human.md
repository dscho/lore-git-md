This is a feature patch series introducing HTTP TCP keepalive configuration options, now in its second version. The series has evolved through community review to refine implementation details while maintaining its core purpose of giving users control over curl's TCP keepalive behavior.

The v2 series includes four patches (up from three in v1) with these key changes:
1. Added proper error handling in the new `set_long_from_env()` helper function
2. Removed unnecessary type conversions between int and long
3. Made the keepalive count option conditional on curl version compatibility (8.9.0+)

The implementation provides three new config options (`http.keepaliveidle`, `http.keepaliveinterval`, `http.keepalivecount`) with environment variable overrides, addressing bandwidth-limited clone scenarios. The series has seen productive discussion with consensus reached on default values (using curl's defaults) and implementation approach.

The patches show careful attention to detail, with each change well-justified in the commit messages. The series appears ready for final review, with all substantive feedback addressed and only minor cleanups remaining from the previous version. The documentation is thorough, though testing strategy remains an open question the author invites suggestions on.
