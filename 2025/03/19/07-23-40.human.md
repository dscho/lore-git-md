This is the 7th patch in Martin Ågren's 8-part series refactoring Git's pretty-format parsing code. The series has been systematically breaking down complex formatting logic into more maintainable components while fixing edge cases.

The current change focuses on the "magic" placeholders in pretty formats (like `%-` for line feed handling). It extracts the magic parsing logic from `format_commit_item()` into a new `parse_magic()` function, following the pattern established in previous patches. The refactoring:

1. Makes the code more modular by separating parsing from execution
2. Introduces an explicit `enum magic` for the different placeholder types
3. Maintains all existing behavior, including the special case for `%+w()` combinations
4. Improves error handling by distinguishing between "no magic" (0 chars consumed) and "bad magic" (2 chars consumed)

The change continues the series' trend of making the pretty-format code more maintainable without altering functionality. The diff is clean and focused, with clear commit message explaining the motivation. This appears to be another solid step in the overall refactoring effort.
