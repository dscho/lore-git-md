This is a refactoring patch in Martin Ågren's series cleaning up Git's pretty-format parsing code. It focuses on the padding-related functionality ("%<" and "%>" placeholders) in pretty.c.

The patch extracts three padding-specific fields from the main `format_commit_context` struct into a new `padding_args` substruct. This makes the code's intent clearer by grouping related fields and showing they're only used for padding operations. The change also modifies the `parse_padding_placeholder()` function to take this new struct directly, making the parsing more self-contained.

The changes are mechanical - no behavior is altered, just code organization. This appears to be preparatory work for later patches in the series that will handle more substantial refactoring of the padding logic.
