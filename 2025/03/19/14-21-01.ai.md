This is a refinement to the cruft pack handling series, specifically addressing the final patch introducing `--combine-cruft-below-size`. Elijah Newren provides review feedback on Taylor Blau's implementation, focusing on documentation clarity and edge case handling.

- The wording around how large cruft packs are handled - suggesting "leaves alone" instead of "prohibits" for more precise semantics
- Clarification that `--max-cruft-size` should be used *with* (not instead of) `--combine-cruft-below-size` when size limiting is desired
- A proposal to document recommended size ratios between the two options (e.g., making max size twice the combine threshold)
- Confirmation that the implementation itself looks sound, with the feedback being primarily about documentation improvements

The changes affect:
- Documentation/git-repack.adoc (new option documentation)
- builtin/repack.c (implementation of the size-based combining logic)
- t/t7704-repack-cruft.sh (updated test cases)
