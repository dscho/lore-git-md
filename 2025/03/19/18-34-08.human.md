This is the core implementation patch in a series adding NUL-delimited output support to `git rev-list`. It introduces the `-z` option which formats object output with NUL bytes between records rather than newlines, making it more robust for machine parsing of paths containing special characters.

The patch focuses on the `--objects` case first, producing output in the format `<OID> NUL [path=<path> NUL]`. The implementation carefully handles path printing to avoid newline truncation and uses a key-value syntax for metadata. The change is mechanical but thorough, updating both the documentation and adding comprehensive tests.

Several other output modes (like graph output and verbose headers) are explicitly rejected when used with `-z` for now, though the commit message suggests these could be supported in future work. The implementation appears clean and well-tested, with clear documentation of the new format.

This is part of a well-reviewed series that has evolved through several versions, now focused solely on output formatting (input handling was removed in v4 to match `git log` behavior). The patch follows the project's established patterns and includes good test coverage for the new behavior.
