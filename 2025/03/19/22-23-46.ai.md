Refactoring patch in the HTTP TCP keepalive configuration series.

This is the first patch in v2 of the series, cleaning up unnecessary type casts in HTTP configuration parsing. The patch removes explicit `(long)` casts when assigning values from `git_config_int()` to `curl_low_speed_limit` and `curl_low_speed_time` variables, since `long` is guaranteed to be at least as wide as `int`. The change was suggested by Patrick Steinhardt during review of the initial series.

The modification is straightforward and non-controversial, touching only two lines in `http.c` that handle legacy HTTP speed limit settings. The commit message provides historical context, noting these casts have existed since the original HTTP/DAV support was added in 2005. This cleanup precedes the main TCP keepalive configuration work in subsequent patches, maintaining the series' focus on proper type handling for curl-related settings.

The patch demonstrates good attention to detail in code hygiene while avoiding any behavior changes. It follows the pattern of incremental improvements seen throughout this well-received series, where multiple contributors have refined the implementation based on review feedback. The change is small but meaningful in reducing unnecessary type conversions in the HTTP configuration path.
