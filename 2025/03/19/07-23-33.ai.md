This is a cover letter for a refactoring and bugfix series targeting Git's pretty-format code. The series consists of 8 patches that clean up and modernize the pretty-format parsing logic while fixing a few minor bugs along the way.

The series starts with two straightforward cleanups: tightening function signatures and reducing code duplication. It then moves on to address padding-related issues, fixing parsing bugs for half-valid padding placeholders ("%<" and "%>") and improving the handling of padding state. The later patches focus on refactoring the parsing logic for line-wrapping ("%w"), magic placeholders, and decoration options into smaller, more focused functions and data structures.

The changes touch core pretty-format parsing code in pretty.c and include corresponding test updates in t4205-log-pretty-formats.sh. The author has taken care to CC original authors where possible, suggesting these changes may affect long-standing code paths.
