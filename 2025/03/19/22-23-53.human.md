Refactoring patch in the HTTP TCP keepalive configuration series.

This is the third patch in Taylor Blau's four-part series to add fine-grained control over curl's TCP keepalive behavior. The patch inlines the `set_curl_keepalive()` helper function into `get_curl_handle()`, removing what is now just a thin wrapper around a single `curl_easy_setopt()` call. 

The change is straightforward - the function was originally needed when Git supported multiple curl versions with different keepalive implementations, but since we now require curl 7.25.0 or newer (as of late 2024), the conditional compilation is no longer needed. The patch simply moves the one remaining implementation directly where it's used, making the curl handle setup more self-contained.

This continues the series' theme of cleaning up HTTP-related code while adding new configuration options. The change is mechanical and low-risk, following the pattern established in earlier patches of the series that improved type handling and environment variable parsing. The patch maintains all existing functionality while removing unnecessary indirection.
