This is a bug report about unexpected hint messages appearing despite suppression flags. Alan Norbauer reports that when using both `GIT_ADVICE=0` and `--quiet` flags with `git clone`, Git still shows the "Using 'master' as the name for the initial branch" hint message on stderr. This behavior started appearing between Git versions 2.44.0 and 2.48.1.

The issue is particularly problematic because it affects automated testing environments where the hint output causes test failures. The reporter notes this is a change from previous behavior and offers to help track down exactly which version introduced the regression if needed.

The bug appears to be a regression in how Git handles hint suppression, where either the environment variable or command-line flag should have prevented the message from being shown. The report includes detailed system information showing the issue occurs on macOS with Git 2.48.1. This seems like a straightforward bug that maintainers would want to investigate, as it affects users who rely on quiet operation for scripting purposes.
