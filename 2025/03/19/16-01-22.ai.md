Refactoring patch in the HTTP TCP keepalive configuration series.

This is patch 2/3 in the series, focusing on code cleanup rather than the main feature work. It removes the `set_curl_keepalive()` helper function and inlines its single line of functionality directly into `get_curl_handle()`. The change is straightforward - the helper was originally needed for version compatibility but became obsolete after Git dropped support for curl versions older than 7.25.0.

The patch maintains the same TCP keepalive behavior while simplifying the code structure. The modification touches only `http.c`, removing 5 lines (the helper function) and adding 1 line (the inlined call to `curl_easy_setopt`). The change aligns with the series' broader goal of cleaning up HTTP/curl configuration code, though it's independent of the new keepalive timing options being introduced in patch 3.

The implementation appears correct and well-justified, with the commit message clearly explaining the historical context and current rationale. This is a minor but sensible cleanup that shouldn't affect functionality while making the code slightly more direct and self-contained.
