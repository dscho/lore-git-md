This is a feature patch series adding a new userdiff driver for gitconfig files. The series consists of 2 patches - the implementation and corresponding tests.

The main patch adds a builtin userdiff driver for gitconfig syntax to `userdiff.c`, which will enable better diff highlighting for gitconfig files when viewed with commands like `git diff` or `git log -p`. This is particularly useful for people versioning configuration files in dotfiles repositories.

The test patch adds four test cases covering different gitconfig syntax scenarios:
- Basic section headers
- Section headers without indentation
- Subsection headers
- Subsection headers without indentation

The implementation appears straightforward, adding a simple regex pattern to match gitconfig section headers. The test coverage looks thorough for the main syntax cases. This seems like a well-contained, useful addition that follows Git's existing patterns for userdiff drivers. The patchset is complete with both implementation and tests, and the commit message clearly explains the purpose.
