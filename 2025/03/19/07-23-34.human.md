Refactoring patch in a pretty-format parsing cleanup series.

This is the first of an 8-part series refactoring Git's pretty-format parsing code. Martin Ågren tightens the function signature of `format_commit_one()` by removing an unnecessary `void*` parameter that was being immediately cast to its actual type. Both callers already have the correct type (`struct format_commit_context*`), so this change makes the interface more precise while eliminating a redundant cast.

The change is small (just 3 lines modified) and straightforward, typical of the series' initial cleanups that address low-hanging fruit before tackling more complex parsing logic later in the sequence. This appears to be a preparatory change that improves type safety without altering behavior, setting the stage for subsequent refactoring of the pretty-format state machine. The patch includes no test changes since it's purely an internal interface adjustment.
