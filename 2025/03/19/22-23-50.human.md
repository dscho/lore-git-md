Refactoring patch in the HTTP TCP keepalive configuration series.

This is the second patch in a four-part series introducing TCP keepalive configuration for HTTP operations. It introduces a new helper function `set_long_from_env()` to clean up environment variable parsing in http.c. The function provides robust error handling for converting environment variables to long integers, replacing two ad-hoc implementations that handled the GIT_HTTP_LOW_SPEED_* variables.

The change serves two purposes: it eliminates code duplication for parsing numeric environment variables, and it prepares the codebase for upcoming patches that will need similar functionality for the new TCP keepalive settings. The implementation includes proper error checking and warning messages for malformed input, improving on the original code that could silently ignore parsing errors.

This appears to be a well-considered refactoring that maintains the existing behavior while making the code more maintainable. The patch follows naturally from the first patch in the series (which cleaned up legacy type casts) and sets up for the subsequent patches that will introduce the actual keepalive configuration options. The change is focused and clearly motivated within the context of the larger series.
