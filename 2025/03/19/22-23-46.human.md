Cleanup patch in HTTP keepalive configuration series.

This is the first of four patches in a revised series adding TCP keepalive configuration to Git's HTTP transport. Taylor Blau removes unnecessary type casts when parsing `http.lowSpeedLimit` and `http.lowSpeedTime` configuration values in http.c. The casts from `int` to `long` have been present since 2005 but are redundant since `long` is guaranteed to be at least as wide as `int`.

The change was prompted by feedback from Patrick Steinhardt on the initial version of the series. While minor, this cleanup makes the code slightly more straightforward and maintains consistency with the rest of the series' approach to configuration parsing. The patch is a straightforward removal of legacy cruft with no behavior change.

This appears to be a well-justified cleanup that was identified during review of the larger feature. The change is small, focused, and clearly explained in the commit message. As part of the v2 series, it helps set up cleaner code for the subsequent patches that will add the new keepalive configuration options.
