Test patch for new gitconfig userdiff driver. This is the second patch in a 2-part series introducing improved syntax highlighting for gitconfig files in `git diff` and `git log -p output.

The patch adds four test files to t4018 (Git's userdiff test suite) to verify the new gitconfig driver handles both basic sections and subsections, with and without indentation. Each test case includes comments (both `#` and `;` styles) and a "ChangeMe" line that would show up in diffs. The test files are minimal but cover the key syntax patterns the driver needs to recognize.

The tests complement the implementation patch (1/2) which added the actual driver definition. Together they form a complete, well-tested feature that will make it easier to review gitconfig changes in version control. The patch follows Git's standard testing patterns and appears ready for inclusion.
