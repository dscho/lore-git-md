Performance optimization for bundle-uri reference handling, part of Scott Chacon's v3 patch series. Phillip Wood provides a review comment on the first patch in the series, which expands bundle reference handling from just `refs/heads/` to all `refs/` namespaces while preserving hierarchy (now placing heads under `refs/bundles/heads/`).

Phillip notes the change seems sensible but points out two documentation issues: the modified refspec is documented in bundle-uri.adoc (which should be updated), and that document claims the refspec is configurable when the implementation actually hardcodes it. He suggests addressing both documentation issues together with the functional change.

The review is positive overall, coming from someone who admits they haven't used the bundle-uri feature themselves. The comment focuses on ensuring the implementation matches the documented behavior rather than raising concerns about the technical approach, which aligns with the thread's general consensus that the series is well-developed and nearly ready for merging.
