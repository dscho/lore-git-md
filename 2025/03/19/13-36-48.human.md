Build system patch removing unnecessary compiler flag in meson configuration (1/12 in series). This is a straightforward acknowledgment from Patrick Steinhardt agreeing with Ramsay Jones's patch to remove the `-DCURL_DISABLE_TYPECHECK` flag from the meson build configuration.

The original patch (which this email is replying to) explained that this flag was only needed for sparse builds, which meson doesn't support, and removing it actually improves type safety in the HTTP-related code. Patrick's brief reply indicates he sees no issues with this change and agrees with the rationale.

This appears to be a non-controversial, technical improvement to the build system that should proceed without further discussion. The patch is part of a larger 12-part series, though we haven't seen the cover letter explaining the series' broader goals yet.
