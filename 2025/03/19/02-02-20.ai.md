This is the first of two patches in Zheng Yuting's GSoC project to refactor SMTP authentication error handling in `git-send-email.perl`. The patch focuses on restructuring the error capture mechanism.

The change wraps the entire SMTP authentication process in a Perl `eval {}` block to properly catch all types of errors, not just credential-related failures. It introduces two new state variables (`$error` and `$result`) to track exceptions and authentication results separately. The implementation merges the previously separate SASL and basic auth code paths into a unified flow with clear comments indicating where future SMTP status code handling will be added.

Key technical details:
- Replaces direct returns with a structured error handling approach
- Uses `or do` syntax for exception handling
- Maintains backward compatibility while preparing for future status code parsing
- Touches only the `smtp_auth_maybe` function in `git-send-email.perl`
- Adds documentation comments about the planned status code handling (to be implemented in patch 2/2)

The changes are well-contained within the SMTP authentication subsystem and follow the project's established patterns. The patch has already gone through multiple review iterations with all feedback addressed, including proper rebasing and documentation improvements. This appears ready for integration as part of the overall SMTP error handling improvement series.
