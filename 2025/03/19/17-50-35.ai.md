Test optimization and simplification for bundle-uri clone tests.

Taylor Blau responds to Phillip Wood's feedback on Scott Chacon's bundle-uri test improvements, proposing several test optimizations. The key changes suggested are:

1. Replacing the inefficient `for-each-ref | grep` pattern with direct `for-each-ref` pattern matching, using `refname:lstrip` to compare source and bundle references more cleanly.

2. Expanding test verification to check all bundle references created during cloning (not just tags), better aligning with the series' goal of comprehensive reference handling.

3. Simplifying the test setup by:
   - Reducing from two test commits to one
   - Using standard `test_commit` helper
   - Potentially needing only a single tag to verify functionality

The proposed changes maintain test coverage while making the tests more efficient and focused. This follows the thread's progression from implementation to test quality improvements, with Taylor building on Phillip's earlier suggestions about test optimization. The changes would affect `t/t5558-clone-bundle-uri.sh` but don't impact the core bundle-uri functionality already established in the series.
