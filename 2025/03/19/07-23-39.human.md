Refactoring patch in Martin Ågren's pretty-format parsing series (6/8). This change focuses on the line-wrapping "%w" placeholder handling in `pretty.c`.

The patch extracts the parsing logic for "%w" placeholders into a new helper function `parse_rewrap()` and introduces a `struct rewrap_args` to hold the parsed values (width, indent1, indent2). Unlike previous patches in the series, this isn't fixing any known bugs - it's purely a code organization improvement to make the logic clearer and reduce the complexity of `format_commit_one()`.

Key changes include:
- Moving the three parsing variables into a dedicated struct
- Separating parsing from application of the wrapping parameters
- Maintaining the same behavior while making the code more maintainable
- Adding type safety by using `size_t` consistently (with bounds checking)

This continues the series' pattern of making the pretty-format state machine more robust and modular. The change is relatively low-risk since it doesn't modify behavior for valid inputs, just reorganizes the implementation. The patch follows the same careful approach seen in earlier parts of the series, with clear commit message explanations and thorough code restructuring.
