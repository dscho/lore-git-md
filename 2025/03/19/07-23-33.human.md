This is a cover letter for a series of refactoring patches with some minor bugfixes targeting Git's pretty-formatting code. Martin Ågren presents 8 patches that clean up and modernize parts of `pretty.c`, with a focus on the parsing and handling of format placeholders.

The series starts with two straightforward cleanups to reduce code duplication and tighten function signatures. It then addresses some padding-related issues, including fixing a bug in parsing certain padding placeholders. The later patches refactor the parsing logic for line-wrapping, magic placeholders, and decoration options - though Martin notes these refactorings don't yet have immediate follow-up changes that benefit from them, he believes they improve code clarity through smaller functions and better data organization.

The changes touch core formatting code but appear to maintain existing behavior where intended. Martin has taken care to CC original authors where possible. The patch series shows careful attention to code quality and maintainability, with test coverage included (15 new lines in the test suite). While not addressing any major user-facing issues, these incremental improvements look like solid groundwork for future work on the pretty-formatting system.
