This is a final polish to the `git blame` porcelain output fix thread, addressing a minor but important test output issue. 

Eric Sunshine points out that a test title in Karthik Nayak's v2 patch incorrectly uses single quotes, causing the `$opt` variable to appear literally rather than being interpolated. Junio Hamano acknowledges the mistake with characteristic self-deprecation, noting this stems from an early design decision in Git's test framework that didn't anticipate this common looping pattern.

The fix is straightforward - switching to double quotes for the test title string to enable variable interpolation. While small, this improves test output readability by showing the actual option being tested rather than the literal `$opt`. 

This comes as the final review feedback on a long thread that has already reached consensus on the core solution for showing ignored/unblamable markers in `--line-porcelain` mode. The thread has seen thorough technical discussion, multiple iterations, and now this last bit of test output polish. With all feedback addressed, the patch series appears ready for merging.
