This is a bugfix completing vimdiff mergetool layout configuration support. The patch implements the missing case for "@REMOTE" target detection in the vimdiff mergetool, bringing it in line with the existing support for @LOCAL, @BASE and @MERGED targets.

The change is straightforward - just a 3-line addition to check for "@REMOTE" in the layout string, similar to the existing checks. This allows users to specify that the REMOTE buffer should be the editable target when resolving merge conflicts, rather than defaulting to MERGED.
