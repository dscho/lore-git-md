This is a refactoring patch that's part of the ongoing `the_repository` removal effort. The patch removes a now-unnecessary NULL check before calling `repo_config()` in `builtin/update-server-info.c`, since a previous patch series modified `repo_config()` to safely handle NULL repository parameters.

The change is straightforward - it simply deletes the conditional check while keeping the same `repo_config()` call. More interestingly, the patch proposes consolidating tests for NULL repository handling into a single test script (`t1517-outside-repo.sh`) rather than scattering them across individual command tests. The author includes a new test case in this centralized location and suggests they'll migrate existing tests there if this approach is accepted.

The patch appears well-motivated by prior work (referencing two merged patch series) and follows a suggestion from Patrick Steinhardt about test organization. The changes are minimal and focused, touching only 4 lines in the main code plus adding a new test case. This seems like a clean cleanup that aligns with Git's ongoing architectural improvements around repository handling.
