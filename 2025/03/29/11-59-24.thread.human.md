The patch removes a now-redundant NULL check before calling `repo_config()` in the `update-server-info` command, since a prior commit (1a764cdbdc) made `repo_config()` safely handle NULL repository parameters. The change is minimal 4-line cleanup that improves code clarity.

Patrick Steinhardt reviewed the initial version and suggested better documentation of the prior commit reference, which the author incorporated in v2. The patch also includes a test reorganization, adding a case to `t1517-outside-repo.sh` to verify command behavior both inside and outside repositories, following Patrick's suggestion to consolidate such tests rather than scattering them across command-specific files. The author indicates they'll migrate similar tests from other commands if this approach is accepted.

The change builds cleanly on previous repository API work and has no outstanding technical objections.
