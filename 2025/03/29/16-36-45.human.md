Documentation fix for `git update-ref` synopsis formatting.

This is a follow-up to Jean-Noël Avila's review of the manpage formatting for the new `--batch-updates` flag in `git update-ref`. The original patch had incorrectly formatted the synopsis section by using line continuations for alternative command invocations. Junio Hamano proposes a correction that properly separates each distinct invocation form with its own "git update-ref" prefix, making it clear these are separate usage patterns rather than continuations of a single command.

The change is purely documentation-related and affects only the manpage's presentation of the command's syntax. This aligns with Git's documentation standards for showing command variants. The fix is straightforward and uncontroversial, coming from the project maintainer in response to a documentation review. No functional changes are made to the recently approved batched reference updates feature.
