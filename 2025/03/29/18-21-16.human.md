Bugfix for `git blame` porcelain output, finalizing the implementation to show ignored/unblamable markers in porcelain mode. This patch concludes a well-discussed thread that explored several approaches before settling on adding new metadata lines rather than modifying existing output formats.

The change ensures porcelain mode (both `--porcelain` and `--line-porcelain`) now properly indicates ignored revisions with "ignored" and unblamable lines with "unblamable" on separate metadata lines. This matches the existing behavior of the non-porcelain output which uses '?' and '*' markers, addressing what was clearly an oversight in the original implementation.

Key improvements in this v3 version include:
- Better function naming (`emit_porcelain_per_line_details`)
- Using `puts()` instead of `printf()` for simple string outputs
- Fixed test variable interpolation and naming
- Updated documentation to clarify the porcelain output behavior

The patch has been through multiple rounds of review with input from Patrick Steinhardt and Toon Claes, and addresses all feedback from earlier versions. The implementation maintains backward compatibility while properly extending the porcelain format to include this previously missing information. Test coverage is thorough, verifying the behavior works correctly in both porcelain modes.
