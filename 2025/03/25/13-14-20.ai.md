This is part 2/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite, focusing on environment variable sanitization. The patch converts the Perl-based environment cleanup in `t/test-lib.sh` to a `sed` implementation, removing the dependency on Perl for this core test infrastructure component.

The change replaces a Perl script that unsets all `GIT_*` variables except a whitelist (TRACE, DEBUG, TEST, etc.) with an equivalent `sed` pipeline that performs the same filtering. The new implementation uses negative matching (-e '/^GIT_X/d') to exclude the allowed variables before capturing remaining GIT_* names for unsetting. The logic preserves all the same exception cases as the original Perl version.

This conversion is based on prior work by Johannes Schindelin and maintains identical behavior while eliminating the Perl requirement. The patch is part of the broader effort to achieve 97% test coverage without Perl, with this being one of the foundational changes affecting test execution environment setup. The implementation appears straightforward and maintains the same safety properties as the original while using more universally-available tooling.
