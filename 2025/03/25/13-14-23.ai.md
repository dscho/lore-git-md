This is part 5/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite, focusing on converting the `test_readlink()` helper function.

The patch replaces the Perl-based implementation of `test_readlink()` with a C implementation in `test-tool path-utils`. The helper reads symbolic links and returns their targets, functionality that isn't universally available via shell utilities. The new implementation uses Git's `strbuf_readlink()` function to handle the link reading, with proper error handling via `die_errno()`. The shell wrapper in `t/test-lib-functions.sh` is updated to call the test-tool instead of Perl.

Key technical details:
- Adds new `readlink` subcommand to `test-tool path-utils`
- Uses `strbuf_readlink()` for POSIX-compliant link reading
- Maintains same interface (handles multiple arguments, prints each result)
- Preserves error behavior (dies on failure with errno message)
- Follows the series' pattern of moving Perl dependencies into test-tool

This continues the systematic conversion approach seen in earlier patches, with careful attention to maintaining functionality while removing Perl dependencies. The implementation appears straightforward and well-contained, similar to the Perl-to-dd conversion in patch 4/20. The change enables more tests to run without Perl while keeping the same.
