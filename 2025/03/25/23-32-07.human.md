Refactoring patch in a systematic comma operator cleanup series.

This is patch 3/10 in Johannes Schindelin's v2 series addressing unnecessary use of the comma operator in Git's codebase. The patch focuses on `kwset.c`, which implements string search algorithms used by Git's grep functionality. The changes replace comma operators with semicolons in several tree traversal and string matching routines, improving code clarity without altering behavior.

The modifications are straightforward mechanical conversions, splitting combined statements into separate lines. Notable changes include AVL tree rebalancing operations in `kwsincr()` and the Boyer-Moore string search loop in `bmexec()`. The patch follows the established pattern from earlier approved changes in the series, maintaining the same control flow while using more conventional C syntax.

This continues the project's systematic approach to code hygiene, with previous patches already reviewed and queued by the maintainer. The changes are non-functional but make the code more maintainable by removing an obscure C feature that can sometimes lead to subtle bugs. The series-wide context shows broad consensus on this cleanup approach, with performance-sensitive exceptions being documented rather than changed.
