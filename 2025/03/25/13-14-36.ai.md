The conversion follows the series' established pattern of maintaining identical test expectations while changing the implementation language.

- Handles four specific normalization cases via sed -e flags
- Updates all test cases to use the new function instead of Perl
- Removes PERL_TEST_HELPERS prerequisite since Perl is no longer needed
- Maintains identical expected output files
