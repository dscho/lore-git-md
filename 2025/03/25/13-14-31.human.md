This is part 13/20 of Patrick Steinhardt's series to make Git's test suite work without Perl, focusing on textconv script dependencies. The patch converts three test files (t4030, t4031, t7815) that previously relied on Perl for text conversion scripts to use simpler shell utilities instead. The key changes are:

1. Replaces Perl-based hexdump scripts with `tr` and a new `test-tool hexdump` for binary file conversion
2. Simplifies the textconv logic while maintaining test validity - the tests now verify basic functionality rather than exact output matching
3. Removes PERL_TEST_HELPERS prerequisites from these tests since they no longer need Perl

The conversions follow the series' established pattern of maintaining test coverage while reducing dependencies. The author notes that while the new implementations aren't exact replicas of the Perl versions, they sufficiently verify the textconv behavior. This continues the steady progress toward the series' goal of 97% Perl-free test coverage.
