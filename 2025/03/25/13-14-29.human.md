Refactoring patch in Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. This is part 11/20 of the v2 series, converting tests that use Perl's substitution operator (s///) to equivalent sed commands.

The patch systematically replaces Perl substitution patterns with sed equivalents across 11 test scripts, removing several PERL_TEST_HELPERS prerequisites in the process. Changes include:
- Converting simple text substitutions in t0008-ignores.sh and t4200-rerere.sh
- Handling binary data manipulation in t5303-pack-corruption-resilience.sh
- Preserving test behavior while changing the implementation details

The conversions follow the established pattern from earlier patches in the series, maintaining test reliability while progressing toward the goal of making Perl optional for running Git's test suite. The changes appear mechanical and well-validated, continuing the series' careful approach to removing Perl dependencies without introducing new issues.
