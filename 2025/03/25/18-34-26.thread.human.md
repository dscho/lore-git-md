The Git community is preparing for Git Merge 2025, the annual conference that brings together contributors and users of Git ecosystem projects. Scheduled for September 29-30 at GitHub's San Francisco headquarters, the event will follow a two-day format similar to previous years: a main conference program with talks on the first day (including a cocktail networking session), followed by more interactive breakout discussions and the Contributor's Summit on day two. 

Registration is now available through Eventbrite, and the organizing team has opened a Call for Proposals via Sessionize for those interested in speaking. The announcement highlights financial assistance for Google Summer of Code and Outreachy participants who may need travel support, with the Git Project Leadership Committee (PLC) handling these requests through the Software Freedom Conservancy. 

This official community announcement comes from an established Git contributor involved in conference planning, emphasizing the event's role in connecting the broader Git ecosystem. The organizers are actively seeking input on discussion topics and format suggestions from the community.
