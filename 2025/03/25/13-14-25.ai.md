Refactoring patch in the Perl-to-test-tool conversion series, focusing on test prerequisite cleanup.

This patch (7/20 in v2) systematically reviews and updates PERL prerequisites in test files, categorizing them into three groups: tests that no longer need PERL at all, tests that should use the new PERL_TEST_HELPERS prerequisite, and tests that still require Perl but for helper functionality. The changes touch four test files (t0021, t0090, t1006, t7501) with careful attention to maintaining test functionality while removing unnecessary dependencies.

Key technical changes include:
- Removal of PERL from tests that previously used Perl-based implementations but no longer do (like delayed checkout progress tests in t0021)
- Conversion of interactive commit tests in t7501 that don't actually need Perl
- Introduction of a new PERL_IPC_OPEN2 prerequisite in t1006 for tests that specifically need IPC functionality
- Renaming of a variable in t1006 to avoid collision with test framework internals ("script" → "perl_script")

The patch follows the series' pattern of methodically identifying and converting Perl dependencies while maintaining test coverage. It builds on the PERL_TEST_HELPERS distinction introduced in patch 6/20, showing the progression of the overall effort to make Perl truly optional. The changes are mechanical but demonstrate careful attention to edge cases like the IPC::Open2 module check in t1006.
