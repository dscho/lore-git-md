This is part 14/20 of Patrick Steinhardt's series to make Git's test suite work without Perl, focusing on GPG signature sanitization in tests.

The patch converts the `sanitize_pgp()` helper function from using Perl to using `sed`, removing another Perl dependency from the test infrastructure. The function strips PGP signatures from test output by filtering lines between "BEGIN PGP" and "END PGP" markers. The new `sed` version achieves the same effect with a more compact pattern.

The change requires adding `PERL_TEST_HELPERS` to several tests in t6300 that use Perl-specific features, since the test suite no longer bails out early when Perl is missing. This maintains the series' approach of incrementally removing Perl while preserving test coverage.

The conversion follows the established pattern of the series - replacing Perl with simpler Unix tools where possible. Johannes Schindelin helped with the implementation, suggesting the `sed` approach. The patch is relatively straightforward and maintains the same functionality while reducing dependencies.
