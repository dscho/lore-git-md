Announcement for Git Merge 2025 conference and Contributor's Summit.

Taylor Blau announces the dates and location for Git Merge 2025, the annual Git community conference. The event will take place September 29-30 at GitHub's San Francisco headquarters, following a similar format to last year's Berlin event. The first day will feature the main conference program, while the second day will host breakout sessions and the Contributor's Summit, which is open to anyone working on Git or related ecosystem projects.

Registration and the call for proposals are now open, with links provided to both the ticket sales and session submission pages. The announcement notes that financial assistance may be available for GSoC/Outreachy students who need help with travel costs, with requests to be submitted to the Git PLC by mid-July.

The email invites discussion about potential topics and format suggestions, maintaining the community-driven spirit of the event. This serves as both an official announcement and an open invitation for community participation in shaping the conference.
