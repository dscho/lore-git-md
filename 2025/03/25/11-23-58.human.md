This is a project process discussion about Git release scheduling coordination between core Git and Git for Windows.

Johannes Schindelen responds to Junio Hamano's inquiry about aligning release days between the two projects, strongly advocating against Friday releases. Rather than rehashing previous arguments, he provides a curated set of external references supporting his position, including industry practices (Firefox's Tuesday releases, Microsoft's Patch Tuesday), academic research on time-based releases, and multiple articles discussing the risks of Friday deployments.

The references collectively argue that Friday releases can lead to weekend support escalations and that mid-week releases (particularly Tuesday) are safer industry norms. Johannes notes that his previous attempts to coordinate release schedules have been ineffective, suggesting this is an ongoing point of tension between the projects' release processes.

This email doesn't propose a specific solution but provides substantial background material for Junio to reconsider the current Friday release cadence for core Git. The discussion remains cordial but shows clear disagreement on release timing philosophy.
