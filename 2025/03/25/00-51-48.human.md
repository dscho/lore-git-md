This is the final patch in a series addressing default branch name advice suppression, specifically focusing on architectural improvements to make the advice properly configurable.

The patch introduces `ADVICE_DEFAULT_BRANCH_NAME` as a new advice type, allowing the "Using 'master' as default branch name" hint to be disabled via both `--no-advice` flag and `advice.defaultBranchName=false` config. It modifies `repo_default_branch_name()` to use `advise_if_enabled()` instead of direct `advise()`, bringing this advice in line with Git's standard advice control system. The change includes test coverage verifying the advice can be suppressed via config.

This completes the architectural portion of the fix that Phillip Wood had noted was needed to properly handle this long-standing issue where the advice couldn't be silenced through normal channels. The implementation is cleanly separated from the earlier clone-specific fixes in the series, with clear documentation in the commit message. The patch appears ready for merging as it has addressed all review feedback through multiple iterations.
