This is a cover letter for a major test infrastructure refactoring series aimed at making Perl optional for running Git's test suite. The 20-part patch set from Patrick Steinhardt continues the project's gradual reduction of Perl dependencies, building on previous work to move functionality from Perl to C.

The series refactors various test helpers and scripts to use shell/awk/sed instead of Perl, marking remaining Perl-dependent tests with a new PERL_TEST_HELPERS prerequisite. With these changes, 97% of tests (30,342 out of 31,358) can now run without Perl. The v2 iteration incorporates reviewer feedback from Eric Sunshine and Phillip Wood, particularly around binary diff handling and sed/awk usage patterns.

Key technical changes include:
- New shell implementations for test helpers like character translation and file operations
- Conversion of Perl-based test prerequisites to the new PERL_TEST_HELPERS marker
- Build system updates to remove Perl test requirements
- Careful preservation of test verification capabilities while simplifying implementations

The series demonstrates meticulous attention to maintaining test coverage while removing dependencies. Reviewers have focused on ensuring the shell/awk alternatives properly replicate the verification behavior of the original Perl implementations, with some debate around optimal implementation choices (e.g., tr vs. sed for character translation).

This represents a significant step toward making Perl truly optional for Git development and testing, though some Perl-dependent features (like git-send-email and gitweb) remain as noted in the cover letter. The changes are well-motivated and carefully executed, with clear documentation of the rationale for each conversion.
