Cover letter for a test suite refactoring series to make Perl optional. This 20-part patch series from Patrick Steinhardt continues the effort to reduce Git's Perl dependency by making the test suite runnable without Perl. The series builds on previous review feedback from Eric Sunshine and Phillip Wood, with v2 incorporating several refinements.

The key technical changes convert various test helpers and scripts from Perl to shell/awk implementations, while introducing a PERL_TEST_HELPERS prerequisite for tests that still require Perl. Notable conversions include:
- Environment sanitization helpers
- Character translation utilities
- Test file manipulation functions (copy_bytes, readlink)
- Textconv script processing
- PGP output sanitization
- HTTPD CGI scripts
- Trace2 log scrubbing

The series achieves 97% test coverage (30342/31358 tests) without Perl. Changes in v2 focus on implementation improvements based on reviewer feedback, including:
- Better commit message documentation for textconv conversions
- Fixed test skip messages
- Simplified sed/awk implementations where possible
- Resolved binary diff output handling via tr instead of hexdump

The thread shows careful attention to maintaining test behavior while removing Perl dependencies, with reviewers validating that verification capabilities remain intact despite implementation changes. The series represents a significant step toward making Perl truly optional in Git installations.
