This is a build system patch that improves Coccinelle integration in Meson builds, specifically addressing issues when building from tarballs. The change modifies `contrib/coccinelle/meson.build` to require both `spatch` availability and a Git checkout (presence of `.git` directory) for Coccinelle support, fixing build failure scenarios where `spatch` was installed but Git commands couldn't run in tarball contexts.

The patch uses Meson's `opt.require()` to implement a combined check with clear error messaging, maintaining the existing detection logic while adding the Git checkout prerequisite. This helps distribution packagers who build from tarballs by preventing automatic Coccinelle enablement in those contexts. The error handling is cleanly separated between silent skip for auto-detection cases and explicit error messages when Coccinelle is explicitly requested.

The implementation focuses on the single build file with a 6-line change that adds the Git checkout check while preserving the existing `spatch` detection. The error message clearly explains the requirement ("coccinelle can only be run from a git checkout") when the feature is explicitly enabled. This appears to be a well-scoped, focused improvement to the specific issue of tarball builds, with no apparent technical drawbacks or open questions remaining.
