**Bugfix for git-p4 encoding handling** - This is a follow-up ping for Nikolay Shustov's patch that fixes `git p4` failures when processing non-UTF-8 Perforce error messages. The patch extends the existing metadata transcoding framework to handle error message decoding consistently with other metadata processing.

The change refactors the encoding logic into a new `MetadataTranscoder` class and applies the same configurable fallback strategy (`git-p4.metadataDecodingStrategy`/`git-p4.metadataFallbackEncoding`) to error messages that was previously only used for metadata. This addresses real-world issues encountered during Perforce-to-Git migrations where non-UTF-8 error messages would cause the import process to fail.

The implementation includes thorough test coverage (Python 3 only due to Unicode handling differences) and maintains backward compatibility. Nikolay emphasizes this is an important fix for enterprise adoption of Git, removing a significant roadblock in migration scenarios. The patch appears well-considered, building logically on prior encoding work in the git-p4 bridge, and has seen no technical objections in prior discussion.
