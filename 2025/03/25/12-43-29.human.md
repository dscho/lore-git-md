Test refactoring patch in ongoing Perl-removal series (13/20). This patch converts Perl-based textconv scripts in tests to simpler shell equivalents, specifically changing a hexdump implementation to a basic `tr` command that handles only the expected binary characters (0x00 and 0x01). 

The change follows the series' principle that test conversions need only preserve verification capabilities rather than exact behavior. Phillip Wood had noted the original script was more tolerant of test data changes, but Patrick Steinhardt explains the simplified version was chosen to avoid widespread test modifications that would be needed to use `test-tool hexdump` instead.

This is a typical patch in the series - carefully trading off implementation completeness against practical concerns while maintaining test coverage. The discussion shows reviewers are satisfied with the approach as long as the test's verification purpose remains intact, though they continue to scrutinize each conversion for both correctness and maintainability.
