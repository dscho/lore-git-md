This is part 5/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite while maintaining test coverage. The patch converts the `test_readlink()` helper function from using Perl to a native implementation in `test-tool`.

The change replaces the Perl-based symlink reading implementation with a C version in `test-path-utils.c` that uses Git's existing `strbuf_readlink()` function. This allows tests that check symlink targets to work on platforms without the `readlink` command, without requiring Perl. The implementation handles multiple input paths and properly reports errors when links cannot be read.

This follows the established pattern in the series of moving Perl-dependent test helpers to native implementations. The conversion appears straightforward and maintains the same functionality while removing the Perl dependency. The patch is cleanly implemented with appropriate error handling and memory management.

As with other patches in the series, this helps move toward the goal of making 97% of Git's tests runnable without Perl installed. The change is focused and well-contained, touching only the test helper implementation and its single caller in the test infrastructure.
