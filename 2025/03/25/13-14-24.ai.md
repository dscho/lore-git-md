This is part 6/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite. The patch introduces a new `PERL_TEST_HELPERS` prerequisite to distinguish between tests that require Perl because the tested functionality depends on it (covered by existing `PERL` prerequisite) versus tests that use Perl as a helper tool.

The change systematically audits and updates 71 test files, adding `PERL_TEST_HELPERS` to tests that use Perl for auxiliary purposes like text processing, data generation, or test assertions. The commit message explains that while core Git functionality no longer requires Perl, many tests still rely on Perl helpers. The new prerequisite allows running most tests without Perl while still marking the Perl-dependent ones.

Key technical details:
- Tests using Perl for core functionality (like git-svn or gitweb) keep using `PERL`
- Tests using Perl as a helper tool switch to `PERL_TEST_HELPERS`
- The patch follows the series' pattern of moving Perl dependencies into test prerequisites
- Changes are mechanical additions of the prerequisite without modifying test logic
- Builds on prior conversions of Perl-based test helpers to alternatives

This continues the series' systematic approach to making Perl truly optional while maintaining test coverage. Reviewers have been validating both functional behavior and implementation details as the series progresses.
