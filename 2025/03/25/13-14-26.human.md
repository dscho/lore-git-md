This is a build system patch in Patrick Steinhardt's ongoing series to make Perl optional for Git's test suite. It updates the Meson build configuration to no longer require Perl just for running tests, reflecting the work done in previous patches to remove Perl dependencies from test helpers. The change is minimal - just removing one condition from the Perl requirement check - but it's an important milestone in the series' goal. The patch follows the established pattern of mechanical changes that maintain functionality while reducing dependencies, and comes after several preparatory patches that converted Perl-based test helpers to alternative implementations. This continues the series' systematic approach to making Perl truly optional while preserving test coverage.
