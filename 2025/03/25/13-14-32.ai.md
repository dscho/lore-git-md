This is part 14/20 of Patrick Steinhardt's series to make Git's test suite work without Perl, specifically targeting the GPG test helpers. The patch converts the `sanitize_pgp()` function from using Perl to using sed for stripping PGP signatures, removing another PERL_TEST_HELPERS dependency. 

The key technical changes are:
1. Replaces Perl-based PGP signature stripping in t/lib-gpg.sh with a sed implementation that matches lines between PGP begin/end markers
2. Updates t6300-for-each-ref.sh to explicitly mark Perl-dependent tests with PERL_TEST_HELPERS rather than skipping all tests when Perl is unavailable
3. Affects test files t/lib-gpg.sh and t/t6300-for-each-ref.sh
4. Follows the established pattern of the series by maintaining identical test behavior while changing the underlying implementation

The patch continues the series' methodology of mechanical conversions to shell tools, with this one focusing on GPG signature handling. The change appears straightforward and maintains the test suite's functionality while progressing toward the Perl-free goal. Reviewers have previously validated similar sed/awk conversions in earlier patches.
