This is patch 16/20 in Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. The patch converts the "one-time-perl" HTTPD test helper to a more generic "one-time-script" version that doesn't require Perl.

The change removes the Perl-specific CGI script (`apply-one-time-perl.sh`) and replaces it with a shell-based version (`apply-one-time-script.sh`) that can execute any script rather than specifically Perl code. This allows the test functionality to be preserved while eliminating the Perl dependency. The patch updates all test scripts that used the Perl version to now use shell utilities like `sed` instead.

Key technical details:
- Renames endpoints from `/one_time_perl/` to `/one_time_script/` in Apache config
- Replaces Perl script execution with generic script execution
- Updates 4 test files (t5537, t5616, t5702, t5703) to use shell utilities instead of Perl
- Removes PERL_TEST_HELPERS prerequisite from several tests
- Maintains same test coverage while changing implementation

The patch follows the established pattern of the series by mechanically converting Perl dependencies to shell equivalents while preserving test behavior. It builds on prior work converting other test helpers and continues the steady progress toward making Perl optional for all but Gitweb and netrc functionality.
