This is part 13/20 of Patrick Steinhardt's series to make Git's test suite work without Perl, focusing on converting tests that use Perl for textconv scripts. The patch refactors three test files (t4030, t4031, t7815) to replace Perl-based textconv scripts with simpler shell/tr/test-tool implementations.

The key changes replace complex Perl hexdump conversions with minimal shell equivalents that still verify the essential behavior. For example, the Perl script that converted each byte to its ordinal value is replaced with either a simple `tr` command or a direct `test-tool hexdump` call. The test expectations are adjusted to match these simpler outputs while still verifying the textconv functionality works.

This continues the series' pattern of maintaining test coverage while reducing Perl dependencies. The patch removes several PERL_TEST_HELPERS prerequisites, though some remain where Perl is still genuinely required. The conversions follow the established approach from earlier patches in the series - focusing on verifying behavior rather than exact output matching, and using simpler shell utilities where possible.

Technical details include:
- Replaces Perl hexdump with `tr "\000\001" "01"` in t4030
- Uses new `test-tool hexdump` in t4031
- Converts Perl nul-to-Q translation to simple `tr` in t7815
- Updates test expectations to match simplified outputs
- Removes PERL_TEST_HELPERS where no longer needed
- Maintains same test coverage with simpler implementations

The patch fits cleanly into the series' progression, building on prior conversions while maintaining the project's 97% Perl-free test coverage goal. The changes appear consistent with the careful, mechanical approach seen in earlier patches.
