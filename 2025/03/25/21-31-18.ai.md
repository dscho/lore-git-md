Platform compatibility response regarding Python version selection in Git builds.

Brian m. carlson confirms that git-p4 is currently the only part of Git's codebase that uses Python, and that it supports both Python2 and Python3. They state that setting `PYTHON_PATH` to `/usr/bin/python3` in `config.mak.uname` should be sufficient to force Python3 usage, as Randall Becker had already attempted. The response notes this is based on their understanding since they don't personally use git-p4, leaving room for potential corrections from those more familiar with that component.

Key technical details for future reference: The discussion centers on build-time configuration (`config.mak.uname`) rather than runtime behavior, specifically targeting the git-p4 script. The solution proposed is straightforward (setting `PYTHON_PATH`), but the caveat about limited personal experience with git-p4 suggests this might need verification from other contributors. No other Python-dependent components in Git are mentioned, implying git-p4 is the sole consideration for Python version selection.
