This is a build system patch in Patrick Steinhardt's ongoing series to make Perl optional for Git's test suite. It updates the Meson build configuration to no longer require Perl just because tests are enabled, reflecting the progress made in previous patches that have reduced Perl dependencies in the test infrastructure.

The change is straightforward - it removes the `get_option('tests')` condition from the Perl requirement check in `meson.build`. This aligns with the series' goal of making tests runnable without Perl, while still keeping Perl mandatory for Gitweb and the netrc credential helper which still depend on it. The patch follows the established pattern of the series by mechanically updating build system requirements to match the actual dependencies after test suite modifications.

Key technical details for future reference:
- The meson.build change affects the `perl_required` variable
- Perl remains required for Gitweb (`gitweb.enabled`) and netrc credential helper (`credential_helpers` contains 'netrc')
- This builds on previous test infrastructure conversions that made Perl optional for core test operations
- The patch is part of a systematic effort documented in the series' cover letter and previous patches

The change is minimal and well-justified by the series' context, representing a logical step in the Perl removal effort after the test suite modifications in earlier patches.
