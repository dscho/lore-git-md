This is patch 19/20 in Patrick Steinhardt's series to remove Perl dependencies from Git's test suite, specifically targeting the test helper functions. The patch converts the `max_chain()` helper in t5316-pack-delta-depth.sh from using Perl to using awk, allowing the removal of several PERL_TEST_HELPERS prerequisites.

The `max_chain()` function extracts the maximum delta chain length from `git index-pack --verify-stat-only` output. The Perl implementation used regex capture groups and a BEGIN/END block, while the new awk version similarly captures the chain length but requires an additional `tr -d ':'` to clean up the output format. The conversion follows the series' established pattern of mechanical substitutions while maintaining identical test behavior.

Four test assertions that previously required PERL_TEST_HELPERS are updated to run without Perl, continuing the series' progress toward making Perl optional. The tests verify delta chain behavior under different `--depth` parameters, including edge cases like depth=0 and negative values. The patch maintains all existing test coverage while removing the Perl dependency.

This change is part of the broader effort that has so far converted 98% of Git's test suite to work without Perl, with only Gitweb and netrc helper functionality still requiring it. The conversion approach has been validated through prior patches in the series, with reviewers like Eric Sunshine and Phillip Wood providing ongoing feedback on implementation details.
