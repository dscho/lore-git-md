This is patch 17/20 in Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. The patch converts the `generate_random_characters()` helper function in t0021-conversion.sh from using Perl to a combination of existing shell tools.

The change replaces Perl's character generation with a pipeline using `test-tool genrandom` (modified to produce infinite output), `tr -dc` to filter to just lowercase letters, and `test_copy_bytes` (converted from Perl in patch 4/20) to limit output length. This allows removing the PERL_TEST_HELPERS prerequisite from three test cases in the file.

The conversion follows the series' established pattern of using POSIX-compliant shell tools where possible. The implementation appears straightforward and maintains the same test coverage while reducing Perl dependencies. This continues the series' steady progress toward making Perl optional for all but Gitweb and netrc helper functionality.

Key technical details for future reference:
- Modified `test-tool genrandom` behavior (now infinite output)
- Uses `tr -dc 'a-z'` for character filtering
- Relies on `test_copy_bytes` from earlier in series
- Removes PERL_TEST_HELPERS from tests:
  * 'required process filter should process multiple packets'
  * 'required process filter with clean error should fail'
- Maintains same test file (t0021-conversion.sh) behavior
