This is part 10/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite, focusing on converting Perl-based character transliteration to POSIX `tr` commands. The patch systematically replaces Perl's `y///` and `tr///` operators with equivalent `tr` invocations across several test files, allowing the removal of PERL_TEST_HELPERS prerequisites in most cases.

The changes are mechanical but thorough, covering test helpers and multiple test scripts that previously relied on Perl for simple character translation tasks. Notable conversions include handling NUL bytes in diff tests and binary file manipulation in apply tests. One test (`t4103-apply-binary.sh`) retains its PERL_TEST_HELPERS prerequisite for a more complex binary diff validation check.

This continues the series' pattern of careful, incremental conversions that maintain test functionality while reducing Perl dependencies. The changes appear straightforward and well-contained, following the established approach of the larger effort. Reviewers (including Eric Sunshine and Phillip Wood) have been actively engaged in verifying these conversions in previous patches.
