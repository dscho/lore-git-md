This thread addressed a build system issue where Coccinelle integration in Meson builds was being automatically enabled even when building from tarballs, causing failures when `spatch` was installed but Git commands couldn't run. The solution, proposed by Eli Schwartz, modifies the Meson build configuration to require both `spatch` availability and a Git checkout (handling both `.git` files and directories) for Coccinelle support. This specifically helps distribution packagers who build from tarballs while maintaining functionality for Git checkout builds.

Junio C Hamano reviewed and approved the solution, particularly appreciating the handling of both `.git` file and directory cases, and indicated the patch would be queued for inclusion. In a final follow-up, Eli Schwartz acknowledged the approval and noted their personal interest in the solution as a heavy user of worktrees. The patch is now ready for merging, having cleanly addressed the original issue with no outstanding concerns.
