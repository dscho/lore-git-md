Follow-up to approved build system patch about Coccinelle integration. This is a brief response from Eli Schwartz acknowledging Junio Hamano's approval of their v2 patch that prevents Coccinelle from being automatically enabled when building from tarballs. The patch had added a requirement for both `spatch` availability and a Git checkout (checking for `.git` file or directory).

Schwartz notes their personal interest in the topic as "a heavy user of worktrees," reinforcing the relevance of properly handling both `.git` files and directories (which worktrees use). This appears to be a friendly closing note rather than introducing any new technical discussion, as the patch has already received final approval from Hamano and will be queued for inclusion.
