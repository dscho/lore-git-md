This is a bugfix patch addressing unexpected advice messages during clone operations, specifically when using bundles. It's part 2/3 in a series that fixes a regression and improves the architecture around default branch name advice.

The patch focuses on suppressing the "hint: Using 'master' as the name for the initial branch" advice that started appearing in bundle clones after a refdb initialization change in commit 199f44cb2ead. The issue occurs because the default branch name computation now occurs later in execution, at a point where advice suppression wasn't properly configured.

Justin Tobler modifies two call sites in `builtin/clone.c` to pass the `REMOTE_GUESS_HEAD_QUIET` flag to `guess_remote_head()`, ensuring the advice won't be shown. The changes cover both regular clone paths and `--single-branch` cases. A new test in t5607-clone-bundle.sh verifies the fix works for bundle clones with `--single-branch`, checking that no advice messages are printed.
