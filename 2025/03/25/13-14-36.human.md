This is patch 18/20 in Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. It converts the trace2 output scrubbing logic from Perl to sed, allowing the removal of the PERL_TEST_HELPERS prerequisite from t0210-trace2-normal.sh.

The patch replaces a Perl script that sanitized variable fields in trace2 output (like elapsed times and executable paths) with an equivalent sed implementation. The scrubbing makes test output predictable by replacing environment-specific values with placeholders. The new sed version handles the same cases as the Perl version: elapsed time normalization, path scrubbing, and selective line filtering.

This follows the established pattern of the series - mechanical conversions that maintain test behavior while eliminating Perl. The implementation looks thorough, with careful attention to preserving all the original scrubbing functionality. Reviewers have been validating similar conversions throughout the series, so this change is likely uncontroversial.

With this patch, the test suite moves closer to the series' target of making Perl optional for all but Gitweb and netrc helper functionality. Only two patches remain after this one in the comprehensive effort.
