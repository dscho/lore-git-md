This is a bugfix patch for Git's build system, specifically addressing an edge case in compiler detection. It's part of Johannes Schindelin's larger series refactoring comma operator usage, though this particular change stands alone as a build system improvement.

The patch fixes a problem where the `detect-compiler` script fails to properly identify Clang when CUDA is installed on the system. Currently, the script gets confused by CUDA's version string in the output of `clang -v`, causing it to report an "unknown compiler family" error. The solution is simple but effective: modify the script to only process the first matching version line rather than all matches.

The change is minimal (just one line modified in the script) and well-justified by the real-world scenario the author encountered. This appears to be a straightforward improvement that shouldn't introduce any new issues, as it makes the version detection more robust while maintaining the same behavior in normal cases. The patch follows the pattern of the series in focusing on build system reliability, though it's a standalone fix than the comma operator refactoring work in the rest of the series.
