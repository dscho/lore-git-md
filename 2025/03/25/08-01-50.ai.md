Refactoring patch in a series about removing unnecessary comma operators. This is the second of two patches, following the same pattern as the first (which modified remote-curl.c). The change replaces a comma operator with a semicolon in builtin/rebase.c during rebase initialization code, specifically when setting up the reset_head_opts struct (ropts) for a detached HEAD checkout. The modification affects the assignment of orig_head in the options structure, but like the first patch, this is purely syntactic with no behavioral impact. The comma operator being removed was not serving any meaningful purpose here since the expressions didn't need to be combined into a single statement. The commit message cites the comma operator's obscurity and potential for confusion as motivation, consistent with the series' theme. No tests are included or needed for this type of change. The patch follows the same uncontroversial pattern as the first in the series, touching isolated code with no dependencies or interactions with larger ongoing efforts.
