This is a bugfix patch addressing advice message suppression in Git's remote operations, specifically part of a series dealing with unwanted default branch name advice during clone operations.

The patch modifies `guess_remote_head()` to accept flags rather than a simple boolean `all` parameter, introducing `REMOTE_GUESS_HEAD_QUIET` to suppress advice messages. The change affects several call sites in `builtin/fetch.c`, `builtin/remote.c`, and the remote subsystem internals. Key technical details include:

1. The boolean `all` parameter is converted to `REMOTE_GUESS_HEAD_ALL` flag
2. New `REMOTE_GUESS_HEAD_QUIET` flag controls advice suppression
3. `repo_default_branch_name()` now receives the quiet flag to suppress its advice
4. Call sites in fetch and remote operations are updated to use the new flags
5. The change maintains existing behavior while adding suppression capability

This is the first of three patches in v3 of the series, focusing on the core mechanism for advice suppression in remote operations. The implementation follows the thread's consensus to use explicit flags rather than implicit state, with Phillip Wood and Junio Hamano having reviewed earlier versions. The patch appears well-contained with clear mechanical changes to the remote subsystem interface and its callers.
