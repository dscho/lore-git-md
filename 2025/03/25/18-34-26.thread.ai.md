Git Merge 2025 conference announcement. Event scheduled for September 29-30 at GitHub SF headquarters, following same two-day structure as 2024 Berlin edition: Day 1 - main conference program with cocktail hour, Day 2 - breakout sessions and Contributor's Summit (open to Git/ecosystem contributors). Registration open via Eventbrite, CFP active on Sessionize. Financial assistance available for GSoC/Outreachy students needing travel support - contact Git PLC (Junio Hamano, Christian Couder, Ævar Arnfjörð Bjarmason, Taylor Blau) for details, with Conservancy aiming for mid-July funding decisions. Announcement serves dual purpose of informing community and soliciting input on discussion topics/format suggestions. Includes all essential links (main website, ticketing, CFP) while maintaining inclusive tone. Official community event organized by core contributors.
