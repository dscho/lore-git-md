Git Merge 2025 conference announcement and updates. Event scheduled for September 29-30 at GitHub SF headquarters, following same two-day structure as 2024 Berlin edition: Day 1 - main conference program with cocktail hour, Day 2 - breakout sessions and Contributor's Summit (open to Git/ecosystem contributors). Registration open via Eventbrite, CFP active on Sessionize. Financial assistance available for GSoC/Outreachy students needing travel support - contact Git PLC (Junio Hamano, Christian Couder, Ævar Arnfjörð Bjarmason, Taylor Blau) for details, with May 15, 2025 deadline for assistance requests to allow visa processing time. brian m. carlson has declined attendance due to safety concerns about traveling to the United States as an openly queer individual, citing political climate and potential customs issues.

In response to accessibility concerns, Taylor Blau announces expanded remote participation options: two-way A/V equipment for virtual engagement in both main conference and Contributor's Summit, free remote attendance, and flexibility for speakers to switch to virtual presentations. Refunds available for those switching from in-person to virtual. These changes aim to address travel challenges while maintaining event inclusivity, particularly following brian m. carlson's expressed concerns. Conference organizers continue soliciting input on discussion topics/format suggestions while implementing concrete solutions for accessibility. Official community event organized by core contributors.
