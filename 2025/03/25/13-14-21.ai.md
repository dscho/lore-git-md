This is part 3/20 of Patrick Steinhardt's series to make Perl optional in Git test infrastructure, focusing on character translation helpers. The patch converts three Perl-based character translation functions in t/test-lib-functions.sh to use `tr` instead: `lf_to_nul`, `nul_to_q`, and `q_to_nul`. The commit message notes that while NUL character handling in `tr` had historical platform inconsistencies, POSIX now requires correct NUL processing.

The conversion is straightforward - each Perl one-liner using `y///` transliteration is replaced with an equivalent `tr` command. This maintains the same functionality while removing the Perl dependency. The patch enables more tests to pass in Perl-less environments, continuing the series' goal of achieving 97% test coverage without Perl.

Key technical details for future reference:
- Functions modified: lf_to_nul (LF→NUL), nul_to_q (NUL→'Q'), q_to_nul ('Q'→NUL)
- Uses POSIX-mandated NUL handling in tr
- No behavior change expected when tr is POSIX-compliant
- Part of broader test infrastructure modernization effort
