This is part 4/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite while maintaining test coverage. The patch converts the `test_copy_bytes()` helper function from using Perl to using `dd(1)`.

The change is straightforward - the function, which copies up to N bytes from stdin to stdout, previously used a Perl script with sysread operations. The new version uses `dd` with byte-level copying (ibs=1) and count to limit the number of bytes copied. This simpler implementation achieves the same functionality while removing the Perl dependency.

As noted in the thread context, this series is systematically converting various test helpers to work without Perl while maintaining verification capabilities. This particular conversion appears clean and well-motivated, following the pattern established in earlier patches of the series. The change allows several tests to pass when Perl is not available, contributing to the overall goal of 97% test coverage without Perl.
