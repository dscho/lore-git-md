Maintainer approval for Meson/Coccinelle build fix. Junio C Hamano has reviewed and accepted Eli Schwartz's patch that prevents Coccinelle from being automatically enabled when building from tarballs. The patch adds a requirement for both `spatch` availability and a Git checkout (checking for `.git` file or directory) before enabling Coccinelle support. Hamano specifically notes appreciation for the patch's handling of both regular `.git` files and directories, indicating this attention to detail meets Git's standards. The patch is now queued for inclusion, marking the successful conclusion of this technical discussion about build system behavior. No further changes or discussion appear necessary.
