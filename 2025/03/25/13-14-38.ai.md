This is the final patch in Patrick Steinhardt's 20-part series to remove Perl dependencies from Git's test suite. The patch focuses on t5703 (upload-pack ref-in-want tests), which had two Perl dependencies: capability filtering and CGI script setup.

The patch converts the capability filtering to use `test_grep` instead of Perl, which follows the series' established pattern of replacing Perl with simpler shell utilities where possible. For the CGI script setup (which would be more involved to convert), it adds PERL_TEST_HELPERS prerequisites to the specific tests that need it rather than requiring Perl for the entire test file.

Key technical details:
- Removes blanket PERL_TEST_HELPERS prerequisite from the test
- Replaces three Perl-based capability filtering tests with `test_grep` checks
- Marks 6 specific test cases with PERL_TEST_HELPERS for CGI functionality
- Maintains all test coverage while changing implementation
- Follows the series' approach of minimal, focused conversions

This completes the series' goal of making Perl optional for all but Gitweb and netrc helper functionality, with 98% test coverage (30745/31358 tests) now working without Perl. The patch follows the same careful, mechanical conversion style seen throughout the series, with reviewers having previously validated the general approach. The remaining Perl dependencies are now clearly isolated to specific test cases rather than whole files.
