Refactoring patch targeting `remote-curl.c` to improve code clarity. This is the first of two patches in a series removing unnecessary uses of the comma operator in Git's codebase. Johannes Schindelin replaces a comma with a semicolon in `remote-curl.c` where the comma operator was being used to chain expressions that didn't need to be combined. The change is purely stylistic with no functional impact, motivated by the comma operator being an obscure C feature that can sometimes cause confusion. The modification is straightforward - a one-line change in the `push_git()` function where the comma after setting `rpc.service_name` served no purpose. The patch follows the series' goal of modernizing Git's code style in small, non-controversial ways.
