This is part 12/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite while maintaining test coverage. The patch converts tests that use Perl for printing data in various ways to use alternative tools like awk and sed.

The changes fall into three categories: conditional pattern matching (converted to awk), repeated data generation (using test-tool genzeros with sed), and reversing output (using awk). The patch touches 14 test files, removing PERL_TEST_HELPERS prerequisites where possible while maintaining the same test behavior.

The conversions follow the established pattern of the series - mechanical substitutions that preserve functionality while eliminating Perl dependencies. Reviewers Eric Sunshine and Phillip Wood have been providing consistent feedback on similar conversions in earlier patches, and this appears to be another straightforward step toward the goal of 97% Perl-free test coverage.

Notable changes include converting tests that generate large commit messages (using awk instead of Perl string repetition) and handling reversed output in tests like t6013-rev-list-reverse-parents.sh. The patch maintains the series' careful approach of verifying behavior rather than requiring exact implementation matches.
