This is a build system patch in Patrick Steinhardt's ongoing series to make Perl optional for Git's test suite. It modifies the Makefile to only require Perl-dependent test targets when Perl is actually available on the system.

The key changes make several test suite components conditional on Perl's presence:
- The chain lint check (which verifies test syntax) is now optional
- Shell syntax checking is skipped without Perl
- The prove test runner's Perl dependency is removed
- The GIT_TEST_CHAIN_LINT flag is set to 0 by default if Perl is unavailable

This patch follows the series' established pattern of systematically removing Perl dependencies while maintaining test functionality where possible. The changes are mechanical but important for the overall goal of making the test suite runnable without Perl. Reviewers have been providing detailed feedback on earlier patches in this series, and this one appears to follow the same careful approach to maintaining test reliability while reducing dependencies.
