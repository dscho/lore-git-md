This is part 6/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite while maintaining test coverage. The patch introduces a new `PERL_TEST_HELPERS` prerequisite to distinguish between tests that inherently require Perl (due to features like gitweb or git-send-email) and tests that use Perl as an implementation detail.

The change systematically marks 71 test files that rely on Perl helpers with the new prerequisite. This allows the test suite to run without Perl when these helpers aren't needed, while still skipping Perl-dependent tests cleanly when Perl isn't available. The patch follows the series' pattern of carefully maintaining existing test behavior while incrementally reducing Perl dependencies.

Reviewers Eric Sunshine and Phillip Wood have been providing detailed feedback on earlier versions, and this patch appears well-integrated with the overall series goal. The changes are mechanical but important for the long-term goal of making Perl truly optional for Git development.
