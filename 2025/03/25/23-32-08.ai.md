This is a refactoring patch in the ongoing comma operator cleanup series, specifically targeting the test framework's `clar` implementation (patch 4/10). Johannes Schindelin modifies two directory traversal loops in the unit test framework's filesystem helpers (`fs_copydir_helper` and `fs_rmdir_helper`), replacing comma operator usage with clearer `for(;;)` loops and explicit error handling.

The changes split the combined `errno` reset and `readdir` assignment into separate statements, making the control flow more explicit. Both functions follow the same pattern: moving the `errno = 0` initialization and `readdir` call out of the loop condition into the loop body, with an explicit `break` when `NULL` is returned. This maintains identical behavior while improving readability.

The patch continues the series' established approach of removing unnecessary comma operators in non-performance-critical paths, now applied to test infrastructure code. Like previous patches, this is a straightforward readability improvement with no functional changes, building on the maintainer-approved patterns from earlier parts of the series. The changes affect test framework internals rather than core Git functionality, but follow the same systematic cleanup methodology seen in the `remote-curl.c` and `rebase.c` changes earlier in the series.
