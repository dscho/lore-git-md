This is patch 16/20 in Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. The patch converts the "one-time-perl" CGI script used in HTTP tests to a more generic "one-time-script" implementation that doesn't require Perl.

The change removes the Perl-specific CGI script and replaces it with a shell-based version that can execute any script, not just Perl. This allows several HTTP-related tests to drop their PERL_TEST_HELPERS prerequisite. The patch updates all test scripts that used the old endpoint to use the new one, converting their Perl-based modifications to equivalent shell/sed implementations where needed.

The conversion follows the established approach of the series - maintaining the same test behavior while changing the implementation to avoid Perl. The changes appear mechanical and well-contained, with careful updates to both the test infrastructure and individual test cases. This continues the series' steady progress toward making Perl optional for all but Gitweb and netrc helper functionality.
