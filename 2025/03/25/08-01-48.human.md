This is a small refactoring patch series that removes unnecessary uses of the comma operator in C code. The comma operator is rarely used in modern C and can sometimes indicate typos where a semicolon was intended instead.

The series contains two straightforward changes:
1. Fixes a comma operator in `remote-curl.c` where a semicolon would be more appropriate
2. Makes a similar fix in `builtin/rebase.c`

The changes are minimal (just 2 lines modified across both files) and uncontroversial - they don't affect functionality, just make the code slightly clearer by using more conventional C syntax. The commit messages explain that in both cases there was no need to use the comma operator's behavior of discarding the first statement's result.
