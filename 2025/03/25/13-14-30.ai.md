This is part 12/20 in Patrick Steinhardt's series to make Perl optional in Git's test suite while maintaining test coverage. The patch focuses on converting tests that use Perl for printing data patterns into equivalent shell/awk/sed implementations.

The changes systematically replace three categories of Perl printing patterns:
1. Conditional pattern matching now uses awk
2. Repeated printing uses test-tool genzeros + sed
3. Reverse printing uses awk or sort -r where appropriate

Key technical details:
- Modifies 14 test files (t0610, t0613, t1010, t4150, etc.)
- Drops PERL_TEST_HELPERS from several tests that no longer need it
- Uses established patterns from prior conversions in the series
- Maintains test behavior while changing implementation
- Follows the mechanical substitution approach validated in earlier patches

The patch continues the series' pattern of straightforward conversions that reviewers have previously accepted. It removes more Perl dependencies while keeping the same test coverage, moving closer to the 97% Perl-free test coverage goal. The changes appear consistent with the series' established methodology and don't introduce new complexity.
