This is part 10/20 of Patrick Steinhardt's series to make Perl optional in Git's test suite, focusing on converting Perl-based character transliteration to POSIX `tr` commands. The patch systematically replaces Perl's `y///` and `tr///` operators with equivalent `tr` invocations across multiple test files, removing several PERL_TEST_HELPERS prerequisites in the process. The conversion touches seven test files, with the most significant changes in t4103-apply-binary.sh and t4116-apply-reverse.sh where binary data handling is modified. The patch maintains the same functionality while using standard Unix tools - for example, converting NUL` byte handling from Perl's `y/\000/` to `tr "\000"`. One PERL_TEST_HELPERS prerequisite remains in t4103 for a specific binary diff rejection test that still requires Perl.

This follows the series' pattern of mechanical conversions that maintain test coverage while reducing Perl dependencies. The changes are straightforward substitutions that don't alter test behavior, just the implementation details. Reviewers have previously validated similar conversions in earlier patches, suggesting this should be uncontroversial. The patch continues the project's progress toward making 97% of tests run without Perl.
