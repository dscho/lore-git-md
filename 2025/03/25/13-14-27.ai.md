Build system patch in the Perl-optional test suite series.

This patch modifies the test suite's Makefile to make Perl truly optional when running tests, completing the series' goal of removing Perl as a hard dependency. The changes:

1. Move `check-chainlint` from unconditional to conditional on Perl being available (`PERL_PATH`), affecting both `test` and `prove` targets
2. Make shell syntax linting (`test-lint-shell-syntax`) Perl-dependent while keeping other lint checks always active
3. Disable chain linting entirely when Perl is unavailable by defaulting `GIT_TEST_CHAIN_LINT=0`

The implementation follows the series' pattern of maintaining functionality where possible while cleanly degrading when Perl is absent. The conditional logic preserves the existing behavior for systems with Perl while allowing test execution without it. This builds on prior patches that converted individual Perl-based test helpers to alternative implementations.

Key technical points:
- Makefile targets now reflect actual Perl requirements
- Chain lint behavior matches patch 1/20's GIT_TEST_CHAIN_LINT changes
- Shell syntax lint remains Perl-dependent (uses Perl-based checker)
- Other lint checks (duplicates, executables, filenames) remain always active
- Prove target maintains chain lint when available

The change is mechanical and well-contained, completing the build system side of the Perl-optional effort after the test helper conversions in earlier patches. It demonstrates careful attention to maintaining existing behavior where possible while achieving the series' goal.
