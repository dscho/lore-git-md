This is part 17/20 in Patrick Steinhardt's series to remove Perl dependencies from Git's test suite. The patch converts the `generate_random_characters()` helper function in t0021-conversion.sh from using Perl to a combination of existing shell tools.

The function generates random lowercase letters by:
1. Using `test-tool genrandom` to produce random data (now in an infinite stream)
2. Filtering to just 'a-z' characters with `tr -dc`
3. Copying the exact needed length with the existing `test_copy_bytes` helper

This change follows the series' established pattern of replacing Perl with POSIX-compliant shell tools while maintaining identical test behavior. It also removes the PERL_TEST_HELPERS prerequisite from three test cases that only needed it for this helper function. The conversion looks straightforward and builds on previously-reviewed approaches in the series, using tools that have already been validated in earlier patches.
