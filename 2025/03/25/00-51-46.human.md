Bugfix addressing unwanted advice messages during Git clone. This is part 1 of a 3-patch series fixing a regression where the "hint: Using 'master' as the name for the initial branch" advice appears during bundle operations despite suppression flags.

The patch modifies `guess_remote_head()` to accept flags rather than a simple boolean, adding `REMOTE_GUESS_HEAD_QUIET` to suppress advice messages. This builds on previous discussion in the thread about properly parameterizing advice suppression through the call chain. The change converts the existing `all` parameter to a flag and updates all callers in `builtin/fetch.c`, `builtin/remote.c`, and `remote.h`.

The implementation appears clean and well-contained, touching only the necessary interfaces while maintaining backward compatibility. This addresses the immediate regression while setting up for the architectural improvements in later patches. The patch has already gone through multiple rounds of review with consensus reached on the explicit flags approach.
