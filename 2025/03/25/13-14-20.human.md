This is part 2 of Patrick Steinhardt's 20-part series to make Perl optional in Git's test suite. The patch refactors environment variable sanitization in the test framework to use `sed` instead of Perl.

The test framework currently uses a script to unset certain Git-related environment variables before running tests, which required Perl. This patch replaces that with a `sed` implementation that achieves the same effect - unsetting all `GIT_*` variables while preserving a whitelist of exceptions (like `GIT_TRACE`, `GIT_TEST_*`, etc.).

The conversion is straightforward and maintains the same functionality while removing the Perl dependency. The patch builds on prior work by Johannes Schindelin and is part of the larger effort to get Git's test suite working without Perl, which currently achieves 97% test coverage without it. The implementation looks clean and focused, with the sed expressions clearly matching the original Perl logic's behavior.

This is a solid incremental step in the series, converting one of the foundational pieces of test infrastructure. Reviewers have been actively engaged in the discussion, and this version appears to incorporate their prior feedback well.
