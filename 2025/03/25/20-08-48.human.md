This is a build system patch that improves Coccinelle integration in Meson builds. It addresses an issue where building from tarballs would fail if `spatch` was installed, since the Coccinelle support assumed it could run Git commands to get file lists. The patch now requires both `spatch` availability and a Git checkout (presence of `.git`) for Coccinelle support, with clear error messaging when the requirements aren't met.

The change is particularly relevant for distribution packagers who typically build from tarballs rather than Git checkouts. The implementation cleanly handles both automatic detection (silently skipping when requirements aren't met) and explicit requests (showing an informative error message if someone tries to enable Coccinelle in a tarball build).

The patch appears well-considered, with a clear explanation of the problem and solution. It's a focused change touching only the Coccinelle meson.build file while maintaining the existing detection logic.
