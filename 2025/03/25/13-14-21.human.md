This is part 3 of Patrick Steinhardt's series to make Perl optional in Git's test suite. The patch converts three character translation helper functions from using Perl to using `tr(1)`, which is more universally available. The functions handle linefeed-to-NUL conversions and NUL-to-'Q' substitutions used in various tests.

The change is straightforward, replacing Perl one-liners with equivalent `tr` commands. The commit message addresses a potential concern about NUL character handling in `tr`, noting that POSIX-compliant implementations should handle it correctly. This conversion allows more tests to pass when Perl is not installed.
