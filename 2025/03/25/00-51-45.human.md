This is a bugfix patch series addressing unexpected advice messages during clone operations, particularly when cloning from bundles. The series has evolved through multiple versions with input from reviewers Phillip Wood and Junio Hamano.

The core issue stems from a regression introduced in Git v2.45.0 where the default branch name advice ("hint: Using 'master' as the name...") appears during bundle clones despite suppression flags like GIT_ADVICE=0 or --quiet. The problem occurs due to changes in refdb initialization timing that caused the advice to be triggered in `guess_remote_head()`.

The v3 series makes several key improvements:
1. Adds flag-based advice suppression to `guess_remote_head()` (now using explicit REMOTE_GUESS_HEAD_QUIET flags)
2. Extends suppression to cover `--single-branch` clone cases where the advice was appearing twice
3. Allows global suppression via --no-advice flag and advice.defaultBranchName config

The implementation looks thorough, with good test coverage including a new test case that specifically verifies the advice doesn't appear during bundle clones with --single-branch. The patch series has been refined through review feedback and appears ready for inclusion, addressing both the immediate regression and providing architectural improvements to advice handling.
