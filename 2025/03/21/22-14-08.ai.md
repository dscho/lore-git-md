Build system patch implementing out-of-tree builds for libgit-sys Rust integration.

This second patch in the 5-part series introduces two key technical solutions to enable `cargo package` compatibility for the libgit-sys crate. First, it adds a `git-src` symlink in the crate root that points to the Git repository root, which `cargo package` will flatten into a controlled copy of the source tree. Second, it implements out-of-tree builds by introducing a `CARGO_OUT_DIR` Makefile parameter that redirects all build artifacts to a specified directory, preventing Cargo from complaining about source tree modifications.

The changes are extensive but focused, touching primarily the build system infrastructure:
- Makefile modifications to support artifact redirection via new `maybe_join_path` helper
- Path updates for generated files (GIT-VERSION-FILE, command-list.h etc.)
- Object file output directory handling
- Build script adjustments to use the new paths
- Symlink creation in contrib/libgit-sys/

The patch maintains compatibility with both direct builds and the packaging workflow while solving the immediate problem of source tree isolation. It builds on the directory structure established in patch 1/5 and appears to preserve all existing build behaviors when CARGO_OUT_DIR is not set. The implementation carefully limits the scope to libgitpub.a build artifacts to minimize Makefile churn.
