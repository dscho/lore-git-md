This is the fourth patch in a 5-part series improving the libgit-sys Rust crate's build system, focusing on reducing package size for crates.io publication.

The patch addresses the crates.io 10MB size limit by excluding unnecessary directories from the git-src symlink used during compilation. It specifically omits documentation, CI configurations, GUI tools (git-gui/gitk), web interface (gitweb), fuzzing infrastructure, and localization files that aren't needed to build the core libgitpub.a library. The changes touch the Makefile, Cargo.toml, and build.rs files to implement these exclusions.

The implementation maintains the dual-build system compatibility established in earlier patches while adding explicit NO_GITWEB, NO_PERL, and NO_TCLTK flags in build.rs to prevent building optional components. The patch appears well-scoped and follows the series' pattern of incremental improvements to the packaging system, with clear motivation (size reduction) and straightforward implementation.

This continues the systematic approach seen in previous patches, now tackling the crates.io size constraint while keeping all existing functionality intact. The changes are confined to the libgit-sys components and don't affect core Git operations.
