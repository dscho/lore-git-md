Karthik Nayak has implemented the core solution using new "unblamable" and "ignored" metadata lines, maintaining the porcelain format rules while adding this functionality.

The current discussion focuses on where to emit these status markers. Regular porcelain mode groups lines by author/committer, while `--line-porcelain` shows per-line details. Karthik and others are weighing whether to:
1. Allow status markers in regular porcelain (creating some metadata asymmetry)
2. Restrict them to `--line-porcelain` (requiring users to opt-in but keeping the format cleaner)

Karthik favors option 2 as more maintainable, though the team could revisit this later if needed. With this final design decision nearly settled, the implementation is approaching completion, pending test updates and documentation of the new metadata lines. The solution maintains compatibility with existing parsers while fixing the original inconsistency in marking ignored lines.
