Build system discussion for libgit-sys Rust crate integration.

This email continues the technical discussion about build system approaches for the libgit-sys Rust crate, specifically responding to Phillip Wood's suggestion to consider Meson's out-of-tree build capabilities. Josh Steadmon acknowledges the Meson alternative but indicates he's proceeding with a Makefile-based solution for his upcoming v2 series, keeping Meson as a fallback option if needed.

The exchange highlights two competing technical approaches still under consideration: (1) Josh's Makefile-based solution building in Cargo's working directory (OUT_DIR) which avoids symlink cleanup issues from his v1 series, versus (2) Phillip's suggestion to leverage Git's experimental Meson build system for native out-of-tree support. Key technical constraints remain the build script sandboxing environment and the need to maintain parallel build support through CARGO_MAKEFLAGS propagation.

The thread shows the solution space narrowing, with Josh appears committed to his Makefile approach for v2 while keeping architectural alternatives in reserve. This positions Meson as a potential future direction should the experimental implementation mature or if the Makefile solution proves insufficient. The discussion remains focused on contrib/libgit-sys/ without impacting core Git functionality.
