This is the final patch in a 5-part series addressing Rust crate packaging for libgit integration, specifically focusing on crates.io publication requirements.

The patch adds mandatory metadata fields to the Cargo.toml files for both libgit-sys and libgit-rs crates. For libgit-rs, it includes both a description ("Proof-of-concept Rust API for a portion of libgit") and GPL-2.0-only declaration. The libgit-sys crate gets the same license declaration to complement its existing description field. These additions satisfy crates.io's publication requirements that were identified earlier in the thread.

The changes are minimal but essential for publication, completing the technical requirements established in previous patches. The implementation maintains consistency with the series' approach of keeping modifications confined to the contrib/libgit-* directories while ensuring compatibility with both Makefile and Meson build systems.

This concludes the series that has systematically addressed build isolation, parallel compilation, size optimization, and now publication metadata - all key constraints for Rust crate integration. The patch follows the established pattern of focused, well-contained changes that don't impact core Git functionality.
