Build system patch series for libgit-sys crate packaging.

This cover letter introduces a 5-patch series addressing multiple issues with packaging the libgit-sys Rust crate. The primary focus is enabling `cargo package` to work by restructuring the build artifacts to avoid polluting the source tree and adding necessary metadata. Key changes from v1 include moving to an out-of-tree build approach rather than post-build cleaning, and adding license/description fields required for crates.io publication.

The series:
1. Moves libgitpub to a separate contrib directory (unchanged from v1)
2. Adds symlink to Git root and implements out-of-tree builds (reworked)
3. Enables parallel builds via Cargo's jobserver
4. Excludes unnecessary directories to meet crates.io size limits
5. Adds required license/description metadata

Technical details include:
- Makefile modifications for new build locations
- Cargo.toml updates for packaging requirements
- build.rs changes for parallel builds via CARGO_MAKEFLAGS
- git-src symlink creation
- Directory exclusions in package

The changes maintain compatibility with both Makefile and Meson build systems while solving immediate packaging needs. The approach aligns with the thread's progression toward a Makefile-based solution while keeping architectural flexibility.
