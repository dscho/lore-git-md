This is a bugfix patch series addressing an advice message regression in Git's clone operation, particularly when cloning from bundle files. The series follows up on earlier discussion about unexpected "hint: Using 'master' as the name for the initial branch" messages appearing despite suppression flags.

The root cause stems from changes in Git 2.45.0 that altered when the default branch name gets cached during clone operations. The patch series takes a two-pronged approach: first fixing the immediate clone-specific issue by modifying `guess_remote_head()` to respect advice suppression flags, then making the default branch name advice properly honor `--no-advice` globally.

The implementation has evolved from v1 based on feedback, now using flags parameters (following Git conventions) rather than adding new boolean parameters. The series includes new test cases to verify the fix works for bundle clones and maintains expected behavior. The changes touch several key areas including remote helper interaction, advice system plumbing, and clone internals.
