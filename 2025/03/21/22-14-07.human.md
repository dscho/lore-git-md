Build system refactoring for Rust crate packaging. This is the first of five patches implementing a new approach for building the libgit-sys Rust crate, moving build artifacts to a new `contrib/libgitpub` directory to better support `cargo package` operations.

The patch relocates symbol export files and build artifacts from `contrib/libgit-sys` to the new `libgitpub` directory, updating all relevant Makefile references. This separation allows Cargo to treat non-Rust source files as a distinct tree from the Rust crate's own source files, which is necessary for proper packaging.

The changes are mechanical but important for the overall goal of enabling crates.io publication while maintaining parallel build support. The patch series appears well-structured, with this initial change cleanly separating concerns without introducing new functionality. The commit message clearly explains the motivation for the directory move in the context of Cargo packaging requirements.

This is part of an ongoing effort to improve the Rust integration build system, following earlier discussion about Makefile vs. Meson approaches. The implementation preserves compatibility with both build systems while focusing on the Makefile path for now.
