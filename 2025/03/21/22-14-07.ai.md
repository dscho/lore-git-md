This is the first patch in a 5-part series addressing build system improvements for the libgit-sys Rust crate integration, specifically focused on enabling proper Cargo packaging functionality.

The patch relocates build artifacts from contrib/libgit-sys/ to a new contrib/libgitpub/ directory, establishing a clearer separation between Rust-managed and Makefile-built components. This structural change enables `cargo package` to properly handle non-Rust source files by treating them as a distinct tree from Cargo-managed inputs. The implementation involves:
- Creating the new libgitpub directory
- Updating Makefile references to point to the new location
- Modifying build.rs to find artifacts in the new path
- Renaming and updating paths for public_symbol_export.{c,h} files

The changes are mechanical path updates with no functional alterations, maintaining all existing build behaviors while setting up the directory structure needed for subsequent packaging improvements in the series. The patch demonstrates careful attention to build system details, with comprehensive updates to all affected paths in both Makefile rules and Rust build scripts.
