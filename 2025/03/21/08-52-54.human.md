Maintainer feedback on advice suppression fix.

Junio Hamano weighs in on Justin Tobler's patch to modify `guess_remote_head()` to support advice suppression. He agrees with Patrick Steinhardt's earlier suggestion to convert the boolean `all` parameter into a flags field rather than adding another boolean parameter. Hamano specifically notes that when making such a change, the flags parameter should be an unsigned integer rather than signed.

This brief comment from the Git maintainer signals approval for the architectural direction of the fix while providing a specific implementation detail (unsigned flags) that will need to be incorporated into the next version of the patch series. The feedback comes as part of the broader effort to make advice messages consistently respect suppression mechanisms across Git's codebase.
