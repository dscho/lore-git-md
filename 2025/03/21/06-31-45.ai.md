This is a test optimization discussion in the ongoing bundle-uri performance thread. Junio Hamano responds to Phillip Wood's feedback on Scott Chacon's test implementation for bundle-uri clones with tags.

The discussion focuses on improving test methodology for verifying bundle reference handling. Hamano agrees with Wood's suggestion to replace the `for-each-ref | grep` pattern with direct `git show-ref` checks, noting this would be more efficient. More importantly, Hamano proposes a more comprehensive test scenario to verify the interaction between bundle-uri tags and normal fetch behavior, particularly for annotated tags.

The key test case Hamano describes would verify that:
1. An annotated tag included in a bundle appears under `refs/bundles/tags/` after clone
2. The same tag does NOT appear under `refs/tags/` immediately after cloning
3. The tag properly propagates to `refs/tags/` only after being added to the origin and fetched normally

This builds on the thread's existing focus on comprehensive reference handling while addressing potential edge cases in tag propagation behavior. The discussion remains technical and constructive, with Hamano providing specific steps to enhance test coverage beyond the current implementation.
