This is patch 4/5 in the libgit-sys packaging series, focusing on size optimization for crates.io publication. The patch excludes unnecessary directories from the git-src symlink to reduce the package size below crates.io's 10MB limit.

The changes modify three files to systematically exclude non-essential components. The Cargo.toml now lists specific directories to exclude (Documentation, git-gui, perl bindings, etc.), while build.rs adds NO_GITWEB, NO_PERL, and NO_TCLTK flags to prevent building those components. A minor Makefile tweak fixes the gitweb build rule's conditional placement.

The exclusions target developer-facing and non-core components that aren't needed for libgitpub.a compilation, including documentation, GUI tools, fuzzing infrastructure, and localization files. This follows logically from the series' earlier work on build isolation and parallel compilation, now addressing the crates.io size constraint while maintaining all functional requirements. The implementation appears thorough, excluding all obvious non-essential directories while preserving the core build infrastructure established in previous patches.
