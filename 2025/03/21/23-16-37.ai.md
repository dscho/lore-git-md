This is part 1 of a 3-patch series addressing advice message suppression in Git, specifically focusing on the regression where default branch name advice appears during bundle operations despite suppression flags. The thread context shows this is both a bugfix and architectural improvement to Git's advice system.

The patch modifies `guess_remote_head()` to support advice suppression through a new `REMOTE_GUESS_HEAD_QUIET` flag, converting the existing boolean `all` parameter into a proper flags bitmask following Git conventions. The changes affect several call sites in `builtin/fetch.c` and `builtin/remote.c`, and introduce new flag definitions in `remote.h`. The core modification ensures `repo_default_branch_name()` respects suppression when called through this path.

Key technical details include:
- Conversion of `all` parameter to unsigned flags bitmask with two defined flags: `REMOTE_GUESS_HEAD_ALL` and `REMOTE_GUESS_HEAD_QUIET`
- Updated calls to `repo_default_branch_name()` to pass through the suppression flag
- Preservation of existing behavior when flags aren't set
- Changes to the remote.h interface that affect multiple callers

The implementation appears thorough, with clear commit message explaining the change and rationale. This is part of a larger solution that includes both immediate fixes for the clone regression and broader architectural improvements to advice suppression. The patch series has already incorporated feedback from maintainers about following Git conventions for flags parameters.
