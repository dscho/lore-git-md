This is part 4/20 of the series to make Perl optional in Git's test suite. The patch refactors the `test_copy_bytes()` helper function, which copies a specified number of bytes from stdin to stdout.

The change replaces a Perl implementation with a simpler `dd` command, reducing 12 lines of Perl code to a single line of shell. Karthik Nayak notes the improvement in a reply, calling it "really nice." The conversion is straightforward since `dd` provides the same core functionality (copying bytes) with its `ibs=1 count=N` parameters.

This is a clean, mechanical conversion that maintains the exact same behavior while removing a Perl dependency. It's a good example of the series' approach - identifying simple Perl helpers that can be replaced with standard Unix tools. The change helps more tests pass when Perl isn't available, moving toward the series' goal of making Perl optional.
