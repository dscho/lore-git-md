This is part 2/5 of a series implementing build system improvements for the libgit-sys Rust crate, focusing on enabling `cargo package` compatibility. The patch introduces two key changes to support out-of-tree builds when packaging the crate:

1. Adds a `git-src` symlink in the crate root that points to the Git repository root, which `cargo package` will flatten into a copy of the repo (excluding non-version-controlled files and Cargo.toml-containing directories to prevent recursion).

2. Modifies the Makefile to support building artifacts in a Cargo-specified output directory (CARGO_OUT_DIR) rather than the source tree, addressing Cargo's restrictions on build script modifications. The changes include path adjustments for generated files like version information and object files.

The implementation is thorough, touching build artifacts, version files, and dependencies across the Makefile while maintaining compatibility with existing build processes. This continues the series' systematic approach to solving Rust crate packaging constraints while preserving Meson compatibility as a fallback.
