This is a bugfix and refactoring patch addressing advice message suppression in Git's remote operations. It's part 1 of a 3-patch series fixing a regression where default branch name advice ("hint") appeared during bundle operations despite suppression flags.

The patch modifies `guess_remote_head()` to properly respect advice suppression by:
1. Converting the boolean `all` parameter to a flags bitmask (following Git conventions)
2. Adding a new `REMOTE_GUESS_HEAD_QUIET` flag to suppress advice messages
3. Updating all callers to use the new flag system

The changes affect several core commands (fetch, remote) and their interaction with the advice system. The implementation looks clean and maintains backward compatibility while fixing the immediate issue. This is a focused technical change that builds on prior discussion about properly handling advice suppression throughout Git's codebase.

- Clear commit message explaining the change
