Performance improvement in the libgit-sys Rust crate build system.

This third patch in the 5-part series focuses on optimizing build times by enabling parallel compilation. The change modifies the build.rs script to pass Cargo's jobserver flags to the underlying Make invocation, allowing the build to properly participate in Cargo's parallel build scheduling.

The implementation is straightforward - it simply takes the CARGO_MAKEFLAGS environment variable (which contains jobserver information) and passes it through to make. This builds on the infrastructure established in the first two patches, maintaining compatibility with both the out-of-tree build setup and the dual-build system approach.

The patch appears well-contained and focused, touching only the build.rs file with a minimal change. It addresses a clear performance optimization opportunity while maintaining the existing build system architecture. This continues the series' pattern of practical, incremental improvements to the libgit-sys packaging infrastructure.
