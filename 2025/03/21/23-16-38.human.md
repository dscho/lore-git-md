This matches the behavior before commit 199f44cb2ead changed when default branch names were computed. The patch includes a new test in t5607-clone-bundle.sh that verifies the advice doesn't appear during bundle clones.

The change is well-contained, touching only the clone command and adding targeted test coverage. It builds on architectural improvements discussed in the thread to properly handle advice suppression.
