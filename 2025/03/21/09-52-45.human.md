This is part 2 of a 20-part series refactoring Git's test suite to reduce Perl dependencies. The patch converts environment variable sanitization from Perl to sed, removing one of the test suite's Perl requirements.

The change replaces a Perl script that unset all `GIT_*` environment variables (while preserving a whitelist of exceptions) with an equivalent sed implementation. The new version is more readable while maintaining the same functionality - it still clears all Git-related environment variables except for specific ones needed for testing (like `GIT_TRACE`, `GIT_TEST_*`, etc.).

The conversion is straightforward and appears well-executed, with the sed commands clearly matching the original Perl logic. This is a good example of the series' approach - replacing Perl where possible while keeping the same test behavior. The patch builds on earlier work by Johannes Schindelin and moves the test suite closer to being able to run without Perl installed.
