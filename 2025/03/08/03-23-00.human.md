Bugfix follow-up for tag fetching regression. Bence Ferdinandy (the original author of the commit that introduced the regression) responds to Taylor Blau's fix for the tag-following issue in shallow fetches. The problem occurred when fetching specific commits under protocol v2, where the unconditional addition of "HEAD" to ref prefixes broke tag decoration.

The fix, already approved by Junio Hamano and deemed suitable for backporting to Git 2.49, makes the HEAD prefix addition conditional on there already being other prefixes - mirroring the existing logic for tag prefixes. This maintains the protocol v2 invariant that prefix lists must be either complete or empty.

Ferdinandy's brief response acknowledges the fix ("Thanks for cleaning up my mess!") without adding new technical content, effectively closing the loop on this regression. The thread shows good collaboration between the original author (Ferdinandy), the reporter (Igor Todorovski), and the fix contributors (Taylor Blau and Jeff King), with a clean solution that preserves protocol semantics while fixing the immediate issue.
