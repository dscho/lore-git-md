This is a test improvement patch in Jeff King's ongoing series to fix and improve ref-prefix handling in fetches. The patch strengthens an existing test case that verifies fetching by exact object ID works correctly in protocol v2.

The test originally checked that fetching a specific commit SHA worked, but a later change made the test pass even when the underlying optimization (avoiding unnecessary ref-prefix requests) wasn't working. The patch now adds packet tracing to verify we're not sending bogus ref-prefix requests for exact OID fetches, which is the real optimization we want to preserve.

This is a straightforward test enhancement that provides better coverage for an existing optimization. It's part of a larger effort to clean up and improve the ref-prefix handling logic, but stands on its own as a useful verification of expected protocol behavior. The change is small and focused, just adding a packet trace check to an existing test case.
