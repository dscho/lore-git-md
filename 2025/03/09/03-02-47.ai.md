This is part 4 of Jeff King's 9-patch series improving ref-prefix handling in fetches, building on the earlier tag-fetching regression fixes. The patch focuses on test improvements for exact-OID fetches in protocol v2.

The test being modified was originally added to verify that fetching by exact SHA-1 works without sending bogus ref-prefixes. However, a later transport optimization made the test pass even without its intended fix, making it less effective at catching regressions. This patch enhances the test by adding packet tracing to verify we don't send the unwanted ref-prefix, ensuring the optimization remains intact.

Key technical details:
- Modifies `t/t5516-fetch-push.sh` to add packet tracing verification
- Checks that `ref-prefix` doesn't include the exact OID being fetched
- Builds on commit 6c301adb0a (fetch: do not pass ref-prefixes for fetch by exact SHA1)
- Addresses behavior changed by 0177565148 (transport: do not list refs if possible)
- Uses `GIT_TRACE_PACKET` and `test_grep` to verify protocol behavior

This is a test-only change that strengthens verification of an existing feature, preparing the ground for the more substantial protocol changes coming later in the series. The change is straightforward and well-justified, maintaining the series' focus on both fixing issues and improving test coverage.
