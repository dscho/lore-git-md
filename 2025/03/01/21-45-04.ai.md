This is the fifth patch in a series introducing customizable format specifiers for `git blame` output. The patch adds verification tests for the new `-F/--format` option and `blame.format` config introduced in earlier patches.

The test file `t8015-blame-format.sh` contains three key test cases:
1. Verifies empty format strings work correctly (producing output without blame metadata)
2. Confirms both standard and new blame-specific format specifiers (`%h`, `%F`, `%an`, `%ai`, `%L`) expand as expected
3. Tests the `blame.format` config option by setting it and verifying the output matches the expected format

The tests follow Git's standard test patterns, using `test_expect_success` blocks with setup, execution, and verification steps. They cover both CLI and config-based usage of the new formatting feature while maintaining the existing blame output behavior as a fallback.

This patch continues the series' technical approach of incremental, well-tested additions to the blame functionality. The tests specifically verify the integration points between the new format specifiers and Git's existing pretty-print infrastructure that were established in previous patches. The test cases are appropriately focused on the new functionality while being straightforward to understand and maintain.
