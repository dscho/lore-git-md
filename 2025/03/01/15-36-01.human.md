Documentation maintenance patch series updating text files to AsciiDoc format. This is the second version of a 3-patch set that continues the project's migration from plain text to AsciiDoc documentation.

The series focuses on converting documentation files in the contrib/ directory (contacts and subtree) along with the howto index generator script. The changes are straightforward file renames from .txt to .adoc extensions with corresponding updates to build files (Makefile and meson.build). The v2 revision incorporates feedback by adding changes to the contacts meson.build file that were missed in v1.

This appears to be routine maintenance work as part of Git's ongoing documentation modernization effort. The patches are cleanly presented with proper build system updates and CI testing. The changes are mechanical in nature with no behavioral impact - they simply prepare the files for future AsciiDoc formatting while maintaining current functionality.
