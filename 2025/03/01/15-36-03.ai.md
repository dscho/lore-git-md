Documentation patch converting git-contacts documentation from .txt to .adoc format, part of a series modernizing contrib documentation.

This is the second patch in a 3-part series converting contrib documentation to AsciiDoc format, following the main documentation tree's transition started in commit 1f010d6bdf. The patch mechanically renames git-contacts.txt to git-contacts.adoc and updates the corresponding build system references in both Makefile and meson.build configurations. The content remains identical (100% similarity index on rename), indicating this is purely a format change.

The changes are straightforward: the Makefile updates the GIT_CONTACTS_TXT variable to point to the new .adoc file, while meson.build updates its input file references for both XML and HTML documentation generation. The patch maintains build system compatibility by ensuring all documentation targets still reference the same content, just with the new extension.

This continues the series' work of bringing contrib documentation in line with Git's modern documentation standards. The patch follows the same approach as the first patch in the series (which updated howto-index.sh) and precedes the third patch converting git-subtree documentation. No functional changes are introduced - this is purely a mechanical update to match the project's documentation format standards.
