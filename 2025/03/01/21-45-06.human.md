Final documentation patch for the `git blame` format specifiers series.

This is the seventh and concluding patch in Aleks Todorov's series adding customizable format specifiers to `git blame`. The patch completes the feature by documenting both the new `--format`/`-F` command-line option and the corresponding `blame.format` config setting. It also adds documentation for the two new blame-specific placeholders (`%L` for line number and `%F` for filename) alongside the existing format specifiers.

The patch builds on the documentation refactoring from patch 6/7, which moved common placeholder documentation to a shared file. Here, it adds the blame-specific documentation in three places: the config documentation for `blame.format`, the main `git-blame` man page describing the new option, and the shared placeholders file (with blame-specific additions properly guarded by `ifdef::git-blame[]`).

The implementation looks clean and follows established patterns for Git documentation. The patch completes the series by providing users with clear documentation about how to use the new formatting capabilities, while maintaining consistency with how other Git commands document their format specifiers. With this patch, the series appears ready for final review.
