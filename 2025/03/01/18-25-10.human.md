Follow-up documentation patch addressing a build system oversight in the recent .txt to .adoc conversion. 

Maintainer Junio C Hamano noticed that while the main conversion work was completed in a recent 3-patch series, the Documentation/build-docdep.perl script still contained hardcoded references to .txt files. This script handles dependency tracking for documentation builds, and needed updating to match the new .adoc file extensions.

The patch is a straightforward mechanical update, changing all .txt references to .adoc in the Perl script. It maintains the same logic and behavior, just adapting to the new file naming scheme. The changes include both the file scanning pattern and variable naming to better reflect the current state (e.g., renaming `$text` variables to `$adoc`).

This appears to be the final piece needed to fully complete the documentation format conversion for the build system. The patch is small (24 lines changed) and focused, with no apparent controversy or complexity - just catching a remaining reference that was missed in the initial conversion work.
