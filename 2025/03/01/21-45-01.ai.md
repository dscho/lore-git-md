Feature patch adding config option support to the `git blame` format customization series. This is patch 2/7 in the v1 submission from Aleks Todorov, following the initial infrastructure patch that added the `--format` CLI option.

The patch introduces a `blame.format` configuration option that allows users to set a default format string in their Git config, avoiding the need to repeatedly specify `-F` on the command line. The implementation is minimal - just 5 lines added to `builtin/blame.c` that hook into the existing config parsing infrastructure. It uses the standard `git_config_string()` helper to store the format string, matching how similar format options work in other commands.

This continues the series' pattern of building up the format customization feature incrementally. The change is straightforward and follows established Git config option patterns. The patch doesn't yet implement the actual format expansion (which comes in later patches), but provides the config plumbing needed to support it. The implementation appears clean and properly integrated with the existing blame config handling.

Key technical details for future reference:
- Config option name: `blame.format`
- Uses same storage variable (`format`) as the CLI option from patch 1/7
- Follows standard config callback pattern in `git_blame_config()`
- No behavior change yet - just stores the config value for later use
- Will be used alongside CLI `-F` option (with CLI taking precedence)
