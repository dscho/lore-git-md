This is a feature patch series introducing format specifiers for `git blame`, allowing customizable output similar to `git log --format`. The series comes from a personal workflow improvement need where the author wanted to see commit subjects alongside blame output without extra steps.

The 7-part series:
1. Adds a `--format`/`-F` option to `git blame`
2. Introduces a `blame.format` config option
3. Adds blame-specific `%F` (filename) and `%L` (line number) specifiers
4. Integrates with pretty.c for format expansion
5. Includes comprehensive tests
6-7. Restructures documentation to accommodate the new feature

The implementation reuses existing pretty-format infrastructure but notes one limitation: it can't auto-detect optimal column widths, meaning some manual tweaking of format strings may be needed to match default blame's clean alignment. The author acknowledges this as a potential future improvement area.
