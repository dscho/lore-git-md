This is a documentation patch series continuing the transition from .txt to .adoc (AsciiDoc) format for Git documentation. The v2 series builds on the ps/meson-contrib-bits branch and extends the conversion to include contrib/contacts documentation.

The series consists of three patches:
1. Updates howto-index.sh to handle .adoc extensions instead of .txt
2. Renames git-contacts.txt to git-contacts.adoc and updates build files
3. Renames git-subtree.txt to git-subtree.adoc with corresponding build file updates

The changes are mechanical renames and build system adjustments to accommodate the new file extensions, with no content modifications. The patch series appears to be part of Git's ongoing documentation modernization effort, following up on previous work to transition documentation formats. The author has included CI test results and references the previous version of the series.
