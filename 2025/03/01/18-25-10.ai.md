This is a follow-up build system patch to the recently merged documentation conversion series, addressing a lingering issue with the build dependency generator. Maintainer Junio C Hamano noticed that while the main documentation files were converted from .txt to .adoc format, the build-docdep.perl script still contained hardcoded .txt references.

The patch mechanically updates the Perl script to handle .adoc files instead of .txt files throughout, maintaining the same dependency resolution logic but with the new file extension. The changes are straightforward substitutions in file handling (variable names changed from `$text` to `$adoc`) and pattern matching (s/\.txt$// → s/\.adoc$//).

This completes the mechanical aspects of the documentation format migration that was started in the earlier series. The patch doesn't introduce new functionality but ensures the build system properly tracks dependencies between the newly converted AsciiDoc files. Since this comes from the maintainer as a direct follow-up to the merged series, it carries implicit approval and will likely be applied without further review.
