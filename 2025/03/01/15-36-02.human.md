This is a documentation patch that's part of a series converting Git's contrib documentation from .txt to AsciiDoc format. It specifically fixes the howto-index.sh script to handle .adoc file extensions after the recent transition from .txt files.

The patch updates the script's variable names and logic to work with .adoc files instead of .txt, fixing broken links in the generated howto-index.html. The changes are straightforward mechanical updates to match the new file extensions, including adjusting the script's parsing logic and HTML link generation.

This appears to be a well-scoped, necessary change that follows up on commit 1f010d6bdf which originally converted the file extensions. The patch is clean and focused, with no obvious issues. As the first in a 3-part series, it sets up the infrastructure needed by the subsequent patches that will actually convert the contrib/contacts and contrib/subtree documentation files.
