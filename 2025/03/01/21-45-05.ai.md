Documentation patch in a series adding customizable format specifiers to `git blame`. This is patch 6/7 in the v1 series from first-time contributor Aleks Todorov.

The patch moves the detailed documentation of format placeholders from `pretty-formats.adoc` to a new shared `placeholders.adoc` file, replacing the original content with an include directive. This enables reuse of the documentation by multiple commands, particularly needed for the new `--format` option being added to `git blame` in this series. The change is purely organizational - no content is modified, just relocated. The new file contains all the existing format specifier documentation including:
- Literal character placeholders (%n, %%, %x00)
- Formatting controls (colors, wrapping, padding/truncation)
- Commit information placeholders (hashes, author/committer details, dates)
- Specialized placeholders (ref decorations, describe output, trailers)

This follows the pattern seen elsewhere in Git's documentation where shared content is factored out for reuse. The patch maintains all existing functionality while setting up the structure needed for `git blame` to reference these placeholders in its own documentation (likely coming in the final patch of the series). The change is straightforward with 238 lines moved verbatim and one include directive added.
