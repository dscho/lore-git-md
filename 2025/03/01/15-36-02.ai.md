This is a documentation patch that's part of a series converting contrib documentation from .txt to .adoc format. It specifically updates the howto-index.sh script to handle .adoc file extensions instead of .txt, fixing broken links in the generated howto-index.html.

The patch mechanically updates the script's variable names and string matching patterns from "txt" to "adoc" to align with the file extension change made in commit 1f010d6bdf. The changes are straightforward and maintain the same functionality while accounting for the new file extension. The script continues to extract metadata (title, author, abstract) from the documentation files and generate proper links, just now working with .adoc files instead of .txt.

This appears to be a clean, focused change that's part of Git's broader documentation modernization effort. The patch follows the pattern of similar conversions in the main documentation tree and maintains compatibility with both AsciiDoc and non-AsciiDoc content through the Content-type check. As the first patch in the series, it lays groundwork for the subsequent contrib documentation conversions by ensuring the howto index generation works with the new file format.
