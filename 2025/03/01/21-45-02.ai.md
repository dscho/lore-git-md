Feature patch adding blame-specific format specifiers to the customizable blame output series.

This is patch 3/7 in Aleks Todorov's series introducing format specifiers for `git blame`. It adds two new format placeholders specifically for blame output: `%F` for filename and `%L` for line number. These are implemented in `pretty.c` with a new `is_blame` flag in the pretty print context to gate their availability.

The implementation checks the `is_blame` flag before processing these specifiers, ensuring they only work in blame contexts. The filename comes directly from the pretty print context, while line numbers are formatted into a temporary buffer. The changes are minimal and focused, adding just the necessary fields to `struct pretty_print_context` and the format handling logic.

This patch builds on the infrastructure from patches 1-2 that added the `--format` option and `blame.format` config. The implementation follows the pattern of existing format specifiers while maintaining clear separation between blame-specific and general-purpose placeholders. The next patches in the series will presumably build on this to complete the feature with documentation and tests for these new specifiers.
