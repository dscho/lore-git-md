Completion script fix for modern manpage formatting.

This is the first patch in a 2-part series addressing shell completion issues arising from recent manpage formatting changes. The patch modifies `generate-configlist.sh` to properly handle backtick-wrapped option names in documentation files, which had been breaking completion functionality. The change makes the script strip backticks when generating the completion list while still matching them in the source pattern.

Key technical details for future reference:
- Modifies the grep pattern in `generate-configlist.sh` to optionally match backticks (`\?`)
- Adds a sed command to strip backticks (`s/`//g`)
- Maintains existing functionality for deprecated items and comma-separated lists
- Affects all config option completions derived from documentation files
- Part of broader documentation standardization effort (see thread context)

The change is straightforward and appears well-targeted to solve the immediate issue without introducing new complexity. The patch follows the established pattern of the surrounding code and includes a clear commit message explaining the motivation.
