Build system patch optimizing meson configuration. This is part 3 of a 12-patch series (no cover letter seen yet). The change makes the meson build system only pass compiler definitions for DEFAULT_EDITOR, DEFAULT_HELP_FORMAT and DEFAULT_PAGER when they differ from Git's built-in defaults ('vi', 'man' and 'less' respectively). 

The patch removes the unconditional definitions from libgit_c_args and replaces them with conditional additions that only trigger when the configured values differ from the defaults. This makes the build output slightly cleaner by avoiding redundant compiler flags while maintaining the same functionality.

The change appears straightforward and well-justified - it's a small optimization that follows the principle of avoiding unnecessary configuration. The patch is cleanly implemented with clear conditionals checking against the known default values. As part of a larger series, it likely contributes to broader meson build system improvements.
