CI infrastructure fix for Meson documentation builds.

Junio Hamano responds to Jeff King's report of CI failures in the Meson documentation build job, where `meson` was not found in the CI environment. The issue stems from Patrick Steinhardt's recent "ci-meson-check-build-docs" series that added documentation testing for the Meson build system. 

The patch adds `meson` to the package list installed for Documentation jobs in `ci/install-dependencies.sh`. Junio questions whether this is the right approach, noting that Ubuntu-based jobs should theoretically get Meson through the distro-specific setup earlier in the script. He provides links to CI runs showing the failure and subsequent success after applying this change.

This appears to be a straightforward workaround for an immediate CI blocker, though the discussion suggests there may be a more architecturally sound solution to the dependency management. The fix is minimal (a one-line change) and clearly resolves the immediate issue, though the thread indicates this may warrant follow-up discussion about proper CI dependency handling.
