Shell completion fix for modern manpage formatting.

This is the first patch in a 2-part series that addresses shell completion issues arising from recent manpage formatting changes. The patch modifies `generate-configlist.sh` to properly parse option names that are now wrapped in backticks in the documentation. The change is straightforward - it adds backtick handling to the grep pattern and strips them in the sed processing.

The fix is clearly motivated by the ongoing documentation standardization effort that introduced backtick formatting, and the implementation looks correct. While small (just 2 lines changed), this is the kind of subtle plumbing fix that prevents user-facing completion breakage. The patch appears ready to go with no obvious issues - it's a clean solution to a specific problem introduced by the documentation changes.

This sets the stage for the second patch which will reformat the git-branch documentation itself to match the new standards.
