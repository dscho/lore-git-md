Build system alignment series (now 16 patches in v2) focusing on Makefile/meson consistency and platform-specific cleanup. Core technical work spans: conditional `BASIC_CFLAGS` based on `RUNTIME_PREFIX`, platform-specific fixes (Cygwin regex, `getdelim`, `clock_gettime`, `clock_monotonic`, `sysinfo` support; Linux `NEEDS_LIBRT` removal), and documentation updates. Key patches include RAM calculation fix for Cygwin's `sysinfo()` (handling `mem_unit` multiplication) and now expanded `sysinfo()` support.

New platform compatibility patch (16/16) enables `sysinfo()` for Cygwin through three coordinated changes: (1) moves `HAVE_SYSINFO` definition from direct `-D` flag to `config.mak.uname` variable, (2) adds Cygwin to platforms setting this variable, and (3) introduces autoconf test for `sysinfo()` availability. This follows the series' pattern of moving platform-specific detection into config variables rather than hardcoding assumptions.
