Platform compatibility patch for Cygwin builds, part of a larger series (8/12). This patch adds `HAVE_CLOCK_GETTIME` and `HAVE_CLOCK_MONOTONIC` definitions to the Cygwin section of `config.mak.uname`, bringing the Makefile-based build in line with what autoconf and meson already do for this platform. The change is straightforward - it enables these clock-related features that Cygwin supports but weren't previously declared in the Makefile configuration. The patch is narrowly scoped to this build system alignment and doesn't affect runtime behavior beyond enabling features the platform already provides. No tests or documentation changes are included, as this is purely a build system tweak for feature detection consistency across build systems. The commit message clearly explains the change and its motivation.
