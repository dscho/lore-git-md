The discussion led to concrete changes: Junio updated documentation warnings, Patrick Steinhardt modified the Meson build system to prefer `getrandom()` first on Linux (matching the Makefile behavior), and both build systems now align on this approach. Ramsay Jones has now confirmed agreement with Patrick's Meson changes in a brief follow-up, solidifying the consensus.
