The patch removes these definitions from the default libgit_c_args list and adds them conditionally only when the corresponding meson options are set to non-default values.

The technical changes involve restructuring the meson.build file to move three definitions into conditional blocks that check get_option() values against the defaults. This affects the compilation of libgit.a but doesn't change runtime behavior - it just avoids redundant command-line flags when the defaults are used.

Key variables involved are DEFAULT_EDITOR, DEFAULT_HELP_FORMAT, DEFAULT_PAGER and their corresponding meson options (default_editor, default_help_format, default_pager). The patch maintains all existing functionality while making the build slightly more efficient by not passing unnecessary definitions.
