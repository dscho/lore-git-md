This is a build system patch that removes an unnecessary compiler flag in the meson build configuration. It's part of a larger series (positioned as 1/12) though no cover letter is provided for context.

The change removes `-DCURL_DISABLE_TYPECHECK` from the meson build's `libgit_c_args`. This flag was originally added in 2013 to suppress sparse-specific warnings about function pointer size checks in several HTTP-related files (http-push.c, http.c, http-walker.c, remote-curl.c). The patch notes that since meson doesn't support sparse builds, this flag serves no purpose and actually disables useful curl type checking that would otherwise be active.

The modification is straightforward - a single line removal from meson.build.
