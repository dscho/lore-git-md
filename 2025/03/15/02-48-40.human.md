This is a bugfix patch addressing a platform compatibility issue in Git's memory calculation for garbage collection. 

Ramsay Jones points out that Git's `total_ram()` function makes incorrect assumptions about the `sysinfo()` system call's behavior. While Linux man pages indicate memory sizes should be multiplied by `mem_unit` (especially relevant for 32-bit systems with >4GB RAM), Git's implementation assumes sizes are always in bytes. The patch demonstrates this matters in practice on Cygwin, where `mem_unit` is 4096.

The change modifies `builtin/gc.c` to properly handle cases where `mem_unit` is greater than 1, multiplying the unit size when needed. Ramsay provides test results showing the current behavior under-reports available memory on his 8GB Cygwin system. The fix is straightforward - just 7 lines changed with clear logic.

This appears to be a well-researched fix for a real issue, though it likely only affects Cygwin users.
