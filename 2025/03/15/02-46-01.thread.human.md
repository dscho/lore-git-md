This build system alignment series continues to refine Cygwin support, now at version 3 with 19 patches. The core work standardizes Makefile and meson builds while cleaning up platform-specific code. The latest patch enables `arc4random_buf()` as the CSPRNG method for Cygwin, matching behavior already present in other build systems. This follows recent improvements to Cygwin's timing functions, memory reporting, and regex handling.

Key developments include:
- Platform standardization across Linux and Cygwin for CSPRNG, timing functions (`clock_gettime`), and memory calculation (fixing RAM reporting when `mem_unit > 1`)
- Removal of obsolete NEEDS_LIBRT support and other legacy code
- Documentation updates and build system refinements for DEFAULT_EDITOR/PAGER handling
- The series has addressed most open questions, with remaining decisions focused on Cygwin version support boundaries (particularly pre-v2.x) and meson's path handling limitations.

The work shows strong technical progress, with maintainers generally aligned on modernization while awaiting final input from Cygwin maintainers about version support. Each iteration brings the Makefile build closer to parity with meson while cleaning up technical debt.
