This is a build system cleanup patch removing obsolete platform compatibility code.

Ramsay Jones removes the NEEDS_LIBRT build variable and associated linking logic, which was originally added in 2016 to support older Linux systems where `clock_gettime()` required linking with librt. The patch explains that modern Linux distributions (glibc 2.17+) have included this functionality in libc since 2012, and the last supported distribution requiring this (Debian 7) reached end-of-life in 2018.

The change is straightforward - it simply deletes the NEEDS_LIBRT definitions from both the Makefile and config.mak.uname. The commit message provides thorough historical context about when this was needed and why it became obsolete, including a helpful table showing support timelines for major distributions. This appears to be a well-justified cleanup of legacy build infrastructure.
