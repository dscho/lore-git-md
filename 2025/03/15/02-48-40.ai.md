The current code assumes byte units, which would lead to incorrect memory calculations on Cygwin. The fix properly accounts for the `mem_unit` field when present.

This appears to be a straightforward correction of an edge case that was previously overlooked, though the impact is limited to Cygwin users. The patch maintains the existing behavior on Linux systems while fixing the calculation for platforms where `mem_unit` differs from 1.
