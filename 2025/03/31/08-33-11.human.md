CI / build system patch fixing Windows toolchain selection in GitHub Actions.

This is the final patch in Patrick Steinhardt's v2 series of build system fixes, specifically addressing CI configuration. The change ensures the Windows build job on GitHub Actions uses the Visual Studio toolchain rather than accidentally picking up GCC, which was happening due to PATH precedence. The fix adds the `--vsenv` flag to explicitly request Visual Studio, bringing GitHub's behavior in line with GitLab CI where this was already working correctly.

The patch is straightforward, modifying just two lines across the GitHub and GitLab CI config files. While only GitHub strictly needed the fix, the change is made consistently to both platforms to avoid future confusion. Johannes Schindelin reported the original issue, and the solution matches the intended behavior established in commit 7304bd2bc39 from January.

This completes the series' coverage of build system improvements, which has touched meson configuration, gitweb JavaScript handling, contrib tests, and now CI workflows. The change appears well-justified and low-risk, maintaining consistency across CI platforms while fixing an actual toolchain selection bug.
