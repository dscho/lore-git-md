This is the final patch in a 5-part series adding Meson build system support for Git's performance benchmarks. The patch focuses on wiring up benchmark configuration options in the Meson build system.

The key changes expose three benchmark-related options in `meson_options.txt` and properly pass them through to `GIT-BUILD-OPTIONS`:
- `benchmark_repo`: Specifies the repository to copy for performance tests
- `benchmark_large_repo`: Specifies a larger repository for scaling tests
- `benchmark_repeat_count`: Controls how many times tests are repeated (defaults to 3)

The patch maintains a clean separation between Meson-specific benchmark configuration and the existing `t/perf/run` script, which continues to use its own environment variables (`GIT_PERF_MAKE_COMMAND` and `GIT_PERF_MAKE_OPTS`) that aren't exposed through Meson.

This completes the Meson integration for the benchmark infrastructure while preserving the existing interface for cross-version comparisons. The changes are focused and well-contained, following the pattern established in the series of small, targeted patches that each solve a specific problem. The commit message clearly explains what is and isn't being exposed through Meson.
