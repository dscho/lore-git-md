This is patch 7/8 in Elijah Newren's series to remove the legacy merge-recursive implementation in favor of merge-ort. The patch removes test infrastructure that was used to compare behavior between the old merge-recursive and new merge-ort backends, since merge-recursive is now fully removed.

Key changes:
- Deletes the GIT_TEST_MERGE_ALGORITHM environment variable that was used to toggle between backends
- Removes test_expect_merge_algorithm helper function that conditionally ran tests differently for each backend
- Updates numerous test files to remove conditional logic that handled differences between the backends
- Deletes t/lib-merge.sh which contained the test helper
- Removes CI configuration that set GIT_TEST_MERGE_ALGORITHM

The changes are mechanical removals of now-unneeded scaffolding, with test cases simplified to just test merge-ort behavior. The patch shows the completion of the merge-ort transition by removing the last vestiges of merge-recursive from the test suite.

This is a straightforward cleanup patch that depends on the previous patches in the series having already migrated all callers to merge-ort. The changes are focused on test infrastructure rather than core merge behavior. Reviewers should verify the test changes accurately reflect that merge-ort is now the only supported backend.
