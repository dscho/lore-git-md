Merge-ort refactoring with diff-algorithm support. This is patch 3/8 in Elijah Newren's series to fully replace merge-recursive with merge-ort.

The patch makes merge-ort support configurable diff algorithms, removing its hardcoded use of histogram diff. The change involves:
1. Removing the histogram diff hardcoding from merge-ort.c's merge_start()
2. Adding histogram as the default in merge-recursive.c's init_merge_options() (though this is transitional since merge-recursive is being removed)
3. Updating documentation to show both strategies now support the same diff algorithm options, with ort defaulting to histogram while recursive previously defaulted to myers

Key technical details:
- Changes merge-ort's diff algorithm handling to match merge-recursive's capabilities
- Updates Documentation/merge-strategies.adoc to unify the options documentation
- Maintains backward compatibility by keeping histogram as default for ort
- Affects merge-ort.c, merge-recursive.c, and documentation
- The change is part of making merge-ort fully feature-compatible with merge-recursive before removing the latter
- Documentation changes clarify that both strategies now accept the same options, though with different defaults

This is a straightforward technical change that completes one of the last functional gaps between merge-ort and merge-recursive. The patch maintains the same behavior while removing implementation differences, paving the way for merge-recursive's removal in subsequent patches.
