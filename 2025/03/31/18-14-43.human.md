This is the seventh patch in a series removing the legacy merge-recursive implementation, part of the final cleanup after merge-ort became Git's sole merge backend. The patch removes now-obsolete test infrastructure that previously allowed comparing behavior between the two merge strategies.

The changes delete the GIT_TEST_MERGE_ALGORITHM environment variable and test_expect_merge_algorithm helper function, which were transitional tools for testing both merge backends during the migration period. With merge-recursive fully removed (as established in earlier patches), these testing accommodations are no longer needed.

Eric Sunshine caught a minor typo in the commit message ("use" vs "us"), which Elijah Newren acknowledges in this reply. The patch appears straightforward and uncontroversial, representing the logical conclusion of the test infrastructure changes needed after the backend unification.

This is one of the final steps in a multi-year effort to modernize Git's merge machinery, with merge-ort having completely replaced merge-recursive. The series seems to be nearing completion with only minor editorial feedback so far.
