This is a bugfix for the Meson build system's curl detection logic, part of a larger series of build system improvements.

The patch corrects how Git's Meson build handles the `-Dcurl=auto` option, which controls whether HTTP-related features (like remote helpers) are built. The current implementation incorrectly checks `get_option('curl').enabled()` when deciding whether to build curl-dependent code, which returns false for "auto" even when curl is found. This causes builds with `-Dcurl=auto` to silently skip HTTP features despite curl being available.

The fix changes the condition to check `curl.found()` instead, which properly reflects whether the curl dependency was detected. This matches the intended behavior where curl features should be built whenever curl is available (for both "enabled" and "auto" settings). The change is minimal (one line in meson.build) but important since HTTP functionality is considered essential for most Git installations.
