This is a major refactoring of the reftable API, aimed at both improving external usability and enabling new internal functionality. The series has two main goals: (1) making the reftable library more suitable for standalone use by projects like libgit2 through better naming and API design, and (2) exposing lower-level block access needed for upcoming consistency checks in Git's reftable backend.

The 16-patch series starts with license header cleanup, then systematically renames core data structures to be more intuitive (`reftable_reader` → `reftable_table`, `reftable_block_reader` → `reftable_block`). The middle section (patches 9-13) refactors block iteration to expose records generically, while patches 14-16 add table-level block iteration. The final patch moves printing logic into test helpers.

Key technical changes include new public interfaces in `reftable-block.h` and `reftable-table.h`, consolidation of block source code, and extensive test updates. The work builds on recent reftable standalone efforts and touches nearly every part of the reftable implementation, with over 1,600 lines added and 1,200 removed across 54 files. The changes appear well-motivated and carefully structured, with thorough test coverage including new unit tests for the table interface.
