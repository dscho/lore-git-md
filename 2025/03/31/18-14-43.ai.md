This is the seventh patch in Elijah Newren's series to fully remove the legacy merge-recursive implementation, now that merge-ort has completely replaced its functionality. The patch removes test infrastructure that was previously used to compare behavior between the two merge backends.

The changes delete the GIT_TEST_MERGE_ALGORITHM environment variable and the test_expect_merge_algorithm helper function, which were transitional tools allowing tests to run against either merge backend. With merge-recursive gone and all callers using merge-ort, this scaffolding is no longer needed. The removal is straightforward mechanical cleanup following the earlier patches that migrated all callers to merge-ort.

Eric Sunshine caught a minor typo in the original patch ("use" vs "us") which Elijah Newren acknowledges in this reply. The patch appears to be in good shape otherwise, representing one of the final steps in the multi-year effort to modernize Git's merge architecture. This series marks the completion of a major codebase simplification by removing the last vestiges of the old merge-recursive implementation.
