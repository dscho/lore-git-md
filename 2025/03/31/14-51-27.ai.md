Feature proposal for a new `git metadata` command to provide structured repository information in JSON format. This is a GSOC 2025 project proposal from K Jayatheerth.

The proposal introduces a new `git metadata` command that would output key repository information (gitdir path, HEAD state, remote URLs) in structured JSON format rather than the current human-readable text that requires fragile parsing. The primary motivation is to improve automation and CI/CD pipelines by providing reliable machine-readable output without the current workarounds involving `git rev-parse` and text parsing.

Key technical aspects include:
- New `builtin/metadata.c` implementation using Git's internal APIs
- JSON output containing repository path, bare status, HEAD commit/ref, and remote URLs
- Potential stretch goals for output filtering and structured error reporting
- Comprehensive test coverage for various repository states
- Detailed man page documentation

The proposal includes a 5-phase timeline from preparation through implementation, testing, and final submission. The student demonstrates prior engagement with the Git project through microprojects and mailing list participation.

This appears to be a well-scoped and motivated proposal that addresses a clear pain point in Git automation. The structured output format could significantly simplify scripting use cases. The implementation plan shows good understanding of Git's internals and follows established patterns for new commands.
