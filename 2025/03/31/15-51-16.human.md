This is part 5 of Elijah Newren's series to fully remove the legacy merge-recursive implementation in favor of merge-ort. The patch focuses on converting the remaining recursive merge operations to use merge-ort exclusively.

The changes are straightforward mechanical conversions:
- Replaces all calls to `merge_recursive()` with `merge_ort_recursive()` in `builtin/merge.c` and `sequencer.c`
- Removes now-unnecessary conditional logic that previously selected between the two merge backends
- Updates a test script to stop explicitly testing the recursive backend since it's being removed
- Maintains an existing TODO comment about potential optimizations for working tree updates

The patch continues the series' pattern of methodically eliminating merge-recursive usage while preserving all functionality through merge-ort. The changes are low-risk since merge-ort has been battle-tested as Git's default merge strategy for some time now. This brings us one step closer to the series' goal of completely removing the old merge-recursive implementation.
