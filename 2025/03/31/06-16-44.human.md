This is a bugfix patch in a series adding Meson support for Git's performance benchmarks. It addresses an issue where benchmark tests copying repositories weren't properly preserving the source repository's object and ref storage formats (like SHA256 or reftable).

The patch modifies `t/perf/perf-lib.sh` to explicitly detect and propagate the source repository's configuration for object and ref formats when creating test copies. This fixes benchmark failures that occurred when testing with alternate repository formats, while still maintaining the important optimization of not copying most configuration (which could skew performance measurements).

The change is straightforward - it adds two new git invocations to detect the formats and passes them to `git init`. This maintains the benchmark's isolation requirements while supporting modern repository formats. As the first patch in a series about Meson integration, it's a prerequisite for the build system changes to come, ensuring benchmarks work correctly regardless of repository format.
