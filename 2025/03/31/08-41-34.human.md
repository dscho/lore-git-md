Refactoring patch in Patrick Steinhardt's reftable API series (16/16). This final patch in the v1 series moves block printing functionality from the reftable library into test helper code, now that the public table iterator (introduced in patch 14) makes this possible. The change:

1. Removes `reftable_table_print_blocks()` from the public API since it was only needed for debugging
2. Implements equivalent functionality in the test helper using the new table iterator
3. Adds support for dumping index sections that were previously omitted
4. Updates tests to verify the new index section output

The patch completes the series' goal of cleaning up the reftable implementation while exposing the necessary APIs for external use. It follows the established pattern of carefully managing API boundaries while maintaining test coverage. The change is straightforward and well-contained, affecting only debugging/test infrastructure rather than core functionality.
