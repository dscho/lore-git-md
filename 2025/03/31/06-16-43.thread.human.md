This thread documents the ongoing effort to integrate Git's performance benchmark infrastructure (`t/perf`) with the Meson build system. The work began with D. Ben Knoble's initial series and has progressed through multiple iterations, now at version 3 from Patrick Steinhardt. The current implementation supports core benchmark functionality in Meson, including SHA256/reftable repository formats, out-of-tree builds via `GIT_BUILD_DIR`, and proper Perl script handling. There are 47 benchmark tests wired to Meson's benchmark() function with three configuration options implemented.

Several environment-specific issues remain under investigation: Karthik Nayak is looking into a Linux CI failure related to header file listing interactions, while Windows Python asyncio crashes are being addressed via an upstream Meson PR. Christian Couder identified path handling discrepancies that have since been resolved in the latest version. The series has received technical approval from Junio Hamano, who suggested a temporary revert path for the Linux issue. Documentation has been refined throughout the review process, with explicit examples added for running benchmarks via Meson and clearer explanations of build directory detection.

The benchmarks run in Meson with special handling - no parallel execution, not run by default with tests, and no MALLOC_PERTURB injection. The implementation preserves the existing `t/perf/run` script for advanced use while adding basic Meson support. With the core technical requirements now complete and only environment-specific edge cases remaining, this appears to be in the final review stages before potential merging.
