This thread introduces a 5-part patch series by D. Ben Knoble adding Meson build system support for Git's performance benchmark infrastructure (`t/perf`). The changes focus on integrating the existing benchmark system with Meson while maintaining compatibility with the more full-featured `t/perf/run` script.

The first patch in the series addresses a specific compatibility issue when benchmarking repositories using non-default formats (SHA256 object format or reftable ref format). Currently, benchmark tests copying repositories fail in these cases because they skip copying repository configuration files (to avoid performance contamination) but consequently lose format information. The solution extracts the reference and object formats explicitly using `git rev-parse` and passes them to `git init` when creating benchmark copies, maintaining the security benefits while supporting alternate formats.

The remaining patches in the series will cover: proper PERL_PATH usage, out-of-tree build support, Meson build rules for benchmarks, and benchmark-related build options. The implementation keeps `t/perf/run` as the preferred method for advanced benchmarking while providing simpler Meson integration for basic use cases. The changes are focused on build system integration without modifying benchmark functionality itself, maintaining backward compatibility.
