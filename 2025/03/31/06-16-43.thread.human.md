D. Ben Knoble's series to integrate Git's performance benchmark infrastructure with the Meson build system has reached completion with positive reviews. The 5-patch series handles repository format compatibility (including SHA256 and reftable), Perl path portability, out-of-tree builds, and benchmark test wiring while maintaining the existing `t/perf/run` script functionality.
