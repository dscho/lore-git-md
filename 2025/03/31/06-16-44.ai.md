Performance test infrastructure patch fixing benchmark compatibility with alternate repository formats.

This is the first patch in a 5-part series adding Meson build system support for Git's performance benchmarks. It addresses a specific issue where benchmark tests copying repositories would fail when working with non-default repository formats (SHA256 object format or reftable ref format). The problem occurs because the benchmark infrastructure intentionally skips copying repository configuration files to avoid performance measurement contamination, but this also skips format information.

The fix extracts the reference and object formats from the source repository using `git rev-parse --show-ref-format` and `--show-object-format`, then passes them explicitly to `git init` when creating the benchmark copy. This maintains the security benefit of not copying arbitrary configuration while supporting alternate repository formats. The change is minimal (3 lines added, 1 changed) and focused on `t/perf/perf-lib.sh`.

Key technical details for future reference:
- Adds `refformat` and `objectformat` variable extraction
- Modifies the `git init` call to include `--ref-format` and `--object-format` parameters
- Maintains existing behavior of skipping hooks and other potentially interfering files
- Part of broader Meson benchmark integration but fixes a general benchmark infrastructure issue

The patch appears well-motivated and correctly scoped, addressing a clear edge case in the benchmark infrastructure. It should not affect normal benchmark operation while fixing compatibility with less common repository formats.
