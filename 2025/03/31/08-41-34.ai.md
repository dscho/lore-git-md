Refactoring patch in Patrick Steinhardt's reftable API series (16/16). This final patch in the v1 series moves block printing functionality from the reftable library into test helper code, completing the cleanup of debugging utilities.

The change removes `reftable_table_print_blocks()` from the public API and reimplements it in `test-reftable.c` as `dump_blocks()`, using the new table iterator interface introduced in earlier patches. Key technical aspects:

1. The new implementation properly handles index blocks that were previously omitted from output
2. Uses the public `reftable_table_iterator` interface rather than internal table iteration
3. Maintains identical output format for ref/obj/log blocks while adding index section support
4. Updates test cases to verify index block output matches expectations

This is a logical conclusion to the series' API boundary work, removing debugging code that was only in the main library due to historical lack of proper block access interfaces. The patch follows the series' consistent pattern of carefully managing public/private boundaries while maintaining test coverage.
