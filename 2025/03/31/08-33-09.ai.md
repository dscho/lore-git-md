Build system fix for contrib tests in meson builds. This is patch 3/5 in Patrick Steinhardt's v2 series of build system improvements, carrying forward from v1 with minor adjustments.

The patch addresses a specific issue where contrib tests (for the netrc credential helper and git-subtree) were being unconditionally wired up in meson builds, even when `-Dtests=false` was specified. This caused build failures since the `test_environment` variable they depend on isn't defined in that case. The fix wraps both test definitions in conditional blocks checking `get_option('tests')`, matching the behavior of the main test suite.

Key technical details:
- Modifies `contrib/credential/netrc/meson.build` and `contrib/subtree/meson.build`
- Preserves all existing test dependencies and environment setup (PATH prepending, CREDENTIAL_NETRC_PATH setting)
- Maintains identical test execution behavior when tests are enabled
- Fixes a regression reported by Sam James that affected Gentoo builds

The change is straightforward and builds on prior discussion from v1, where the fix was already reviewed. It's part of a broader effort to improve meson build reliability, particularly around test integration. The patch demonstrates good attention to detail by handling both contrib test suites consistently while preserving all their existing dependencies and timeout settings.
