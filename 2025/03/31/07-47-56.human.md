Patrick Steinhardt responds to Alexander Shpilkin's inquiry about creating stash objects that include untracked files for build system integration. He confirms the current limitations: while `git stash create` could theoretically be extended with an `--include-untracked` option, the underlying implementation would still modify the repository's index. 

The key technical hurdle is that `save_untracked_files()` currently works by updating the on-disk index. Patrick suggests the solution would require modifying this function to operate on an in-memory index instead, which would then allow clean integration with `git stash create`. He notes this isn't a trivial change but indicates such patches would likely be welcome, though he won't be implementing it himself.
