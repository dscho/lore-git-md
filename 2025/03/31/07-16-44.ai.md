Refactoring patch in the `the_repository` removal effort, with minor feedback on commit message style.

Patrick Steinhardt provides a quick review of Usman Akinyemi's patch that removes a redundant NULL check before `repo_config()` in `builtin/update-server-info.c`. The change itself is already well-justified in the thread context - it builds on prior work that made `repo_config()` safely handle NULL repository parameters.

Steinhardt offers one small suggestion for improvement: when referencing previous commits that introduced behavioral changes (in this case, the modification to `repo_config()`), it would be helpful to include the commit hash using `git log -1 --format=reference` output format. This makes it easier for readers unfamiliar with the recent changes to locate the relevant commit history.

The review indicates the patch is otherwise in good shape, with no substantive changes requested. This appears to be a straightforward approval with a minor documentation nit that could be addressed in a v2 if the author chooses to send one.
