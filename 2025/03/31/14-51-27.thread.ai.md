Git metadata command proposal (GSOC 2025 project) - initial version from K Jayatheerth proposing a new `git metadata` command to output structured repository information in JSON format. The command would provide machine-readable access to key repository properties (gitdir path, HEAD state, remote URLs) currently only available through human-readable output or multiple git commands. Implementation would add new `builtin/metadata.c` using Git's internal APIs, with JSON output containing: repository path, bare status, HEAD commit/ref, and remote URLs. Stretch goals include output filtering and structured error reporting. The proposal includes comprehensive test coverage plan and detailed man page documentation, following Git's established patterns for new commands. Timeline outlines 5 phases from preparation through implementation and final submission. The structured output would address current pain points where automation relies on fragile parsing of human-oriented output from commands like `git rev-parse`. Student demonstrates prior Git project engagement through microprojects and mailing list participation.
