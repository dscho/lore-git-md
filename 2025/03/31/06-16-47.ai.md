This is the fourth patch in a 5-part series adding Meson build system integration for Git's performance benchmarks. The patch focuses on wiring up the benchmark infrastructure in Meson while maintaining compatibility with the existing `t/perf/run` script.

The key technical changes include:
1. Adding a `time` program dependency check in `meson.build`
2. Defining a comprehensive list of benchmark scripts (47 in total) in `t/meson.build`
3. Implementing Meson's `benchmark()` target configuration with special handling that differs from regular tests (no parallel execution, not run by default, no `MALLOC_PERTURB` injection)
4. Setting up benchmark environment variables including `GTIME` when available

The patch maintains clear boundaries between Meson's benchmark support and the existing `t/perf/run` script, explicitly stating that cross-version benchmarking should still use the script. The implementation follows Meson conventions while preserving Git's benchmark execution patterns, with all benchmark scripts listed explicitly rather than using pattern matching.

This continues the series' pattern of focused, well-explained changes that incrementally build Meson support while respecting existing infrastructure. The benchmark wiring is comprehensive, covering all current performance tests while leaving room for future extension of the `t/perf/run` script to support Meson builds.
