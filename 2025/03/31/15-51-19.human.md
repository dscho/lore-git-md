Final cleanup in the merge-recursive removal series. This is the last patch in Elijah Newren's 8-part series that completely removes the legacy merge-recursive backend now that merge-ort has fully replaced it.

The patch removes the GIT_TEST_MERGE_ALGORITHM environment variable scaffolding from three commands (`merge`, `rebase`, and `revert`). This test infrastructure was originally added to allow the test suite to easily switch between testing the old merge-recursive and new merge-ort backends. With merge-recursive gone and 'recursive' now remapped to use 'ort' under the hood, this testing variable is no longer needed.

The changes are straightforward deletions of environment variable checks and related logic in the three builtin commands. The diff shows 20 lines removed across the three files, with only one line changed (setting the default strategy to NULL in merge.c). This is purely cleanup work with no functional impact - the series has already done all the heavy lifting in previous patches to transition callers to merge-ort.

As the culmination of a multi-year effort to modernize Git's merge machinery, this patch represents a significant milestone in the project's architecture. Reviewers will want to verify that all test infrastructure related to the old backend has been properly removed, though given Elijah's deep expertise in this area and the mechanical nature of these final changes, the patch appears to be in good shape.
