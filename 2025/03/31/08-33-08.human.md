Build system fix for gitweb JavaScript generation. This is part of Patrick Steinhardt's v2 series consolidating build system improvements, with this particular patch addressing a regression in gitweb's JavaScript file generation.

The patch fixes an issue introduced in commit 19d8fe7da65, where the Makefile rule for generating gitweb.js incorrectly included the build script itself in the concatenated output. This happened because the rule used `$^` (which expands to all dependencies) without filtering for only JavaScript files. The fix is straightforward - adding a `filter %.js` to exclude non-JavaScript files from the concatenation.

The patch is based on original work by Thorsten Glaser and has been carried forward from v1 of the series. It's a clean, focused fix for a clear regression, with the one-line change directly addressing the problem. As part of a larger build system cleanup series that's already seen review, this patch appears uncontroversial and ready for inclusion.
