This is a documentation patch addressing Asciidoctor compatibility issues in Git's manual page generation. SZEDER Gábor confirms that the changes fix the reported problem with `git-diff` manpage rendering, where triple-dot syntax was being incorrectly processed by Asciidoctor 2.0.16. The patch modifies the Ruby extensions file to better handle ellipsis notation (`...`) in command synopses, particularly for patterns like `git-mv <source>... <dest>`.

The technical changes include:
- Adding `{empty}` markers around dots in the main processing function
- Special handling for standalone dots in monospaced and quoted contexts
- More precise regex patterns to avoid matching dots within brackets or before certain characters

While this resolves the immediate issue with `git-diff`, SZEDER notes that a related problem persists in other manpages (diff-files, diff-index, log) that include content from 'diff-generate-patch.adoc'. The patch appears technically sound but leaves some edge cases unaddressed, suggesting this may need follow-up work. The commit message could be more explicit about the specific rendering problems being solved.
