Gitweb build system patch fixing JavaScript generation regression. This is part of Patrick Steinhardt's v2 build system fixes series (patch 2/5), carrying forward Thorsten Glaser's original fix from v1.

The patch corrects a regression introduced in commit 19d8fe7da65 that extracted gitweb.js generation into a separate script. The Makefile rule incorrectly included the build script itself in the concatenated output due to using `$^` (all dependencies) without filtering. The fix modifies `gitweb/Makefile` to use `$(filter %.js,$^)` when calling `generate-gitweb-js.sh`, ensuring only JavaScript files are processed.

Key technical details:
- Affects `gitweb/Makefile` build rule for static/gitweb.js
- Uses Make's `filter` function to select only `.js` files from dependencies
- Preserves original behavior intended by the refactoring while fixing the unintended inclusion
- Based on Thorsten Glaser's Debian packaging experience (retains attribution)

The change is straightforward and addresses a clear regression, with the fix having been reviewed in v1 of the series. It maintains compatibility with the existing gitweb JavaScript pipeline while properly implementing the script extraction.
