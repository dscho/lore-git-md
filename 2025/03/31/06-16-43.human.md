This is a build system patch series adding Meson support for Git's performance benchmarks.

Patrick Steinhardt proposes a 5-part series to integrate the existing `t/perf` benchmarks with the Meson build system. The key points are:

1. The series makes several preparatory fixes to the benchmark infrastructure first - handling alternate repository formats, properly using the configured Perl path, and supporting out-of-tree builds.

2. The main change wires up the benchmarks to run under Meson, though with the limitation that they can only test the current build (unlike the more flexible `t/perf/run` script which can compare across versions).

3. This appears to be a straightforward quality-of-life improvement for Meson users, letting them run benchmarks without switching back to Make. The changes are focused and well-scoped, touching only build infrastructure and benchmark plumbing.

4. The series explicitly states it's not trying to replace the existing benchmark runner, just complement it with Meson compatibility. This suggests careful consideration of the existing tooling.

5. The patch set looks clean with focused commits and good test coverage (modifying 5 files with mostly additive changes). This seems like a low-risk addition that could benefit developers using Meson.
