This is a bugfix for Git's Meson build system, specifically addressing curl detection logic. The patch corrects how the build system handles the `-Dcurl=auto` option, which is particularly important since curl is required for HTTP functionality that most users consider essential.

The issue occurs when users explicitly set `-Dcurl=auto` - the build system would properly detect curl's presence but then fail to enable HTTP-related features because it was checking the wrong condition (`get_option('curl').enabled()` instead of `curl.found()`). This one-line change in meson.build ensures that HTTP features are built whenever curl is actually available, regardless of whether it was auto-detected or explicitly enabled.

The patch is part of a larger v2 series of build system improvements, where this particular fix was carried forward from v1. The change is straightforward and well-explained, with clear justification for why curl handling is important. Since this is a core build system component affecting HTTP functionality, it's likely to be relevant for anyone building Git from source, particularly those using Meson.
