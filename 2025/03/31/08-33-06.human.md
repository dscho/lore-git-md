This is a cover letter for a build system fixes series (v2) collecting five distinct improvements to Git's build infrastructure. The series builds on v1 by dropping one redundant patch and adding two new fixes.

Patrick Steinhardt presents an updated collection addressing:
1. Correct handling of `-Dcurl=auto` in meson builds (fixing a detection logic regression)
2. Gitweb JavaScript generation fix (adapting Thorsten Glaser's solution for a Makefile issue)
3. Ensuring contrib tests respect `-Dtests=false` flag (fixing a real-world issue reported by Sam James)
4. New in v2: Cross-compilation improvements distinguishing build and target host binaries
5. New in v2: CI fix to use Visual Studio properly in win+meson GitHub Workflows

The series drops v1's Perl documentation patch after Junio Hamano identified it as redundant with prior work. The new additions address cross-compilation scenarios and CI configuration, with the cross-compilation fix having undergone prior discussion with Peter and Eli Schwartz.

The patches touch meson.build files across the tree, gitweb/Makefile, and CI configurations, showing careful attention to build system correctness and cross-platform compatibility. The cover letter demonstrates good stewardship by properly crediting contributors (Thorsten Glaser, Sam James) and soliciting feedback on attribution. The technical scope remains focused on build system inconsistencies while expanding to include CI and cross-compilation scenarios.
