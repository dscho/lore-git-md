Performance test infrastructure patch in a series adding Meson build system support for Git's benchmarks. This second patch addresses Perl interpreter path handling in the performance test framework.

The patch modifies both `t/perf/perf-lib.sh` and `t/perf/run` to use the configured `PERL_PATH` variable (from `GIT-BUILD-OPTIONS`) rather than hardcoding `/usr/bin/perl` when executing Perl scripts. This fixes compatibility issues on systems where Perl is installed in non-standard locations, specifically called out for NixOS. The change affects three Perl script invocations: `min_time.perl` for timing measurements and two calls to `aggregate.perl` for result processing.
