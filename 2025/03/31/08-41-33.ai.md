This is a refactoring patch in Patrick Steinhardt's reftable API series, specifically exposing block type constants as part of the public interface. 

The patch moves the block type definitions (`BLOCK_TYPE_REF`, `BLOCK_TYPE_LOG`, etc.) from the private `constants.h` to a new public header `reftable-constants.h`, renaming them with a `REFTABLE_` prefix for consistency with other public symbols. This change enables external callers to distinguish between different block types when using the newly exposed block-level APIs from previous patches in the series.

The mechanical changes span 14 files, updating all internal usage of the new prefixed constants. The implementation maintains the same values ('r', 'g', 'i') but now makes them available through the public API. Test files are updated accordingly to use the new constant names.

This change builds on the table block iterator introduced in patch 14, providing the necessary constants for callers to interpret the types of blocks they receive. The patch follows the series' pattern of carefully exposing implementation details while maintaining clear API boundaries, with thorough updates to all affected test cases. No behavior changes are introduced - this is purely an API visibility improvement to support the ongoing reftable refactoring goals.
