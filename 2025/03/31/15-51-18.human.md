Test cleanup patch removing merge-recursive test infrastructure. This is patch 7/8 in Elijah Newren's series to fully remove the legacy merge-recursive implementation now that merge-ort has completely replaced it.

The patch removes two key pieces of test scaffolding that were used to compare merge-recursive and merge-ort behavior during the transition period:
1. The GIT_TEST_MERGE_ALGORITHM environment variable that could toggle between the two backends
2. The test_expect_merge_algorithm helper function that would run tests with different expected outcomes for each algorithm

Since merge-recursive is now gone and 'recursive' is just an alias for 'ort', this test infrastructure is no longer needed. The patch updates 29 test files, mostly removing conditional logic that previously handled differences between the two merge backends. The changes are mechanical deletions and simplifications with no functional impact.

This is a straightforward cleanup that follows logically from the previous patches in the series that migrated all callers to merge-ort. The changes look correct and well-tested, with extensive test coverage ensuring the merge-ort behavior matches what was previously expected for both algorithms. The patch helps simplify the test suite now that we only need to test one merge backend.
