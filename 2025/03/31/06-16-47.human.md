This is the fourth patch in a 5-part series adding Meson build system support for Git's performance benchmarks. The patch focuses on wiring up the benchmark infrastructure to work with Meson while maintaining compatibility with the existing `t/perf/run` script.

The key addition is defining all benchmark scripts in `t/meson.build` and setting them up to use Meson's `benchmark()` function rather than `test()`. This provides three important differences from regular tests: benchmarks don't run in parallel, aren't executed by default with tests, and avoid the `MALLOC_PERTURB` environment variable that could skew timing results. The patch includes a comprehensive list of 45 existing benchmark scripts that will now be available through Meson.

The implementation is clean and follows the same pattern used for tests, with proper environment setup and dependencies. The author notes this is intentionally limited to benchmarking the current build - cross-version comparisons still require using `t/perf/run`, which may be extended for Meson support in future work.

This continues the series' pattern of focused, well-explained changes that incrementally build Meson support while maintaining existing functionality. The patch appears technically sound and aligns well with Git's ongoing Meson adoption.
