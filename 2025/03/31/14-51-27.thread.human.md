Jayatheerth K is working on a Google Summer of Code 2025 proposal to create a new `git repo-info` command that would migrate repository query functionality (like `--show-toplevel`, `--git-dir`, and `--is-bare-repository`) from `git rev-parse`. The proposal has evolved with mentor feedback from Patrick Steinhardt, including renaming the command from the original `git metadata` suggestion. 

In the latest exchange, Patrick addressed Jayatheerth's concern about potential duplicate proposals for the same project idea, explaining that multiple proposals are expected during the application process. Selection will be based on the quality of the proposal, completion of preparatory microprojects, and demonstrated community engagement rather than who proposed the idea first. The technical scope remains focused on relocating existing functionality with backward compatibility, while JSON output remains a secondary stretch goal. 

The discussion shows the proposal is still in the review phase before implementation work begins, with Patrick providing guidance about the GSOC process itself at this stage. The planned implementation would create `builtin/repo-info.c` to house this functionality while maintaining text output compatibility with rev-parse's current behavior.
