This is part 3 of Patrick Steinhardt's 16-patch series refactoring the reftable API. The patch consolidates block source handling code that was previously scattered across multiple files into a single `reftable/blocksource.[ch]` pair. 

The change moves several block source operations (`block_source_close`, `block_source_read_block`, `block_source_size`, and `block_source_return_block`) from various locations into the new centralized files. This makes the codebase more organized and self-contained, particularly for external consumers of the reftable library. The patch updates all callers to use the new location, including test files.

The changes are mechanical and don't introduce new functionality - this is purely a code organization improvement. The patch is part of the larger effort to make the reftable code more maintainable and usable by external projects like libgit2.
