This is patch 6/8 in Elijah Newren's series to remove the legacy merge-recursive implementation in favor of merge-ort. The patch focuses on deleting the merge-recursive.[ch] files after moving any shared functions to merge-ort.[ch].

The key changes are:
1. Deletes merge-recursive.c and merge-recursive.h entirely
2. Moves several functions from merge-recursive to merge-ort.c:
   - merge_recursive_config()
   - init_merge_options()
   - init_ui_merge_options()
   - init_basic_merge_options()
   - copy_merge_options()
   - clear_merge_options()
   - parse_merge_opt()
3. Updates documentation to note that 'recursive' is now a synonym for 'ort'
4. Removes merge-recursive from the build system and Makefile

The commit message humorously notes this is "debugging" the code by deleting it, following the principle that "deleted code is debugged code." This patch represents the culmination of the multi-year effort to replace merge-recursive with the newer merge-ort implementation, which has been Git's default merge strategy since v2.33.0. The changes are mechanical with no functional differences - just removing now-unused code.
