This is the third patch in a series adding Meson build system support to Git's performance benchmark infrastructure. The patch fixes benchmark execution for out-of-tree builds, which is a common configuration when using Meson or CMake.

The change modifies `t/perf/perf-lib.sh` to properly locate build artifacts when the source and build directories are separate. The patch introduces logic to:
1. Determine the build directory by checking `GIT-BUILD-DIR` (a file created by Meson/CMake)
2. Handle Windows path conversions when needed
3. Source build options and test libraries from their correct locations
4. Update the path to the Perl aggregation script

The changes maintain backward compatibility with in-tree builds while enabling proper operation in out-of-tree scenarios. This is a necessary step for integrating the benchmarks with Meson, as noted in the commit message. The patch appears well-constructed, with clear explanations of both the problem and solution, and includes platform-specific handling for Windows.

This continues the series' pattern of focused, incremental improvements to the benchmark infrastructure while supporting the broader Meson adoption effort. The changes are relatively straightforward and unlikely to be controversial, though reviewers may want to verify the Windows path handling logic.
