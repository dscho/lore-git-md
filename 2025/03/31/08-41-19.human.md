License header standardization in reftable files.

This is the first patch in Patrick Steinhardt's 16-part series to refactor the reftable API. The series aims to improve the reftable library's usability for external projects like libgit2 while also enabling internal improvements to Git's reftable backend.

This particular patch is purely mechanical, standardizing the formatting of license headers across all 34 reftable source files. The changeset is large (199 lines changed) but trivial - each header is reformatted to match Git's standard multi-line comment style with asterisks aligned. The actual license text remains unchanged.

As the series opener, this patch establishes a clean baseline for the more substantive refactoring to follow. The changes are straightforward and unlikely to be controversial, though reviewers may want to verify the license text remains correct in all files.
