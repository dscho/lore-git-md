This is the second patch in a 5-part series adding Meson build system support for Git's performance benchmarks, focusing on Perl interpreter path handling. The patch addresses a portability issue where benchmark Perl scripts were hardcoded to use `/usr/bin/perl`, which fails on systems like NixOS where Perl is installed elsewhere.

The change modifies both `t/perf/perf-lib.sh` and `t/perf/run` to use the `PERL_PATH` variable from `GIT-BUILD-OPTIONS` instead of hardcoding the path. This makes the benchmarks work correctly on systems with non-standard Perl locations while maintaining existing functionality elsewhere. The implementation is straightforward - just four lines changed to wrap Perl script invocations with `$PERL_PATH`.

This appears to be a clean, focused improvement that solves a real portability issue without introducing complexity. It builds on existing build infrastructure (the `PERL_PATH` mechanism) and fits naturally into the series' goal of better Meson integration for benchmarks. The change is small but meaningful for users on alternative systems.
