Feature addition for INI file diff highlighting. This is the third version of a patch adding built-in userdiff support for INI files, now generalized beyond just gitconfig files to handle various INI formats including systemd service files and Windows Desktop.ini.

The patch introduces a new "ini" driver in userdiff.c with regex patterns that:
- Match section headers (text in brackets at line start, with indentation)
- Match words as any non-whitespace sequences (not validating variable names/values)

Test coverage is thorough, with 5 new test files checking:
- Basic section headers with/without indentation
- Section headers on same line as content
- Subsection handling (nested sections in quotes)
- Comment handling (both ; and # styles)

The implementation follows Git's existing userdiff patterns, adding to the collection of built-in diff drivers. The commit message notes this evolved from earlier gitconfig-specific versions to a more general solution, with help from two other contributors. The tests demonstrate the driver handles common INI variations while remaining simple in its matching approach.
