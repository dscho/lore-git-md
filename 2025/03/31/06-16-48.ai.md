This is the final patch in a 5-part series adding Meson build system support for Git's performance benchmarks. The patch focuses on wiring up benchmark configuration options in the Meson build system.

The key changes are:
1. Adds three new Meson options (`benchmark_repo`, `benchmark_large_repo`, `benchmark_repeat_count`) that control benchmark execution parameters
2. Properly quotes and converts these options when writing them to `GIT-BUILD-OPTIONS`
3. Explicitly notes that `GIT_PERF_MAKE_COMMAND` and `GIT_PERF_MAKE_OPTS` are not exposed since they're only used by the traditional `t/perf/run` script

The patch maintains the series' focus on clean Meson integration while preserving the existing benchmark infrastructure. It completes the technical work by exposing the remaining benchmark configuration knobs through Meson's option system, with clear documentation of each parameter's purpose in `meson_options.txt`.

This follows logically from the previous patches' work on repository format handling, path portability, and out-of-tree build support. The changes are minimal (9 lines total) but important for full benchmark configuration support in the Meson build.
