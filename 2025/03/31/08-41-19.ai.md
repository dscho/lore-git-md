Standardizing license header formatting across the reftable library.

This is the first patch in Patrick Steinhardt's 16-part series to refactor the reftable API. It makes purely mechanical changes to standardize the formatting of BSD license headers throughout the reftable implementation. The changes convert all headers to use consistent multi-line comment formatting with asterisks aligned, affecting 34 files with 199 lines added and 199 removed. 

The patch is straightforward and uncontroversial, serving as groundwork for the more substantive API changes that follow in the series. It doesn't modify any functional code - only comment formatting. The changes align with Git's typical coding style for multi-line comments, though the actual license text and copyright notices remain unchanged. This appears to be a clean preparatory step before the more complex refactoring work begins in subsequent patches.
