This is a cover letter for version 2 of a build system fixes series, now expanded to 5 patches after dropping one and adding two new ones. The series continues Patrick Steinhardt's effort to consolidate various build system improvements, with contributions from multiple developers.

The v2 series makes several changes from v1: it drops the redundant Perl documentation build fix (already handled by prior work), adds a cross-compilation fix for Meson that was previously discussed, and includes a CI workflow improvement for Windows builds. The core fixes from v1 remain - curl auto-detection, gitweb.js generation, and contrib test integration - now joined by these new additions.

Key technical changes in the new patches:
- `meson: distinguish build and target host binaries` addresses cross-compilation by properly separating build vs target binaries in meson.build
- `ci: use Visual Studio for win+meson job` updates GitHub Actions workflow to use Visual Studio instead of MinGW for Windows builds

The series touches multiple build system components including meson.build files across the tree, gitweb's Makefile, and CI configurations. It maintains the comprehensive approach to build inconsistencies while expanding scope to include cross-compilation support and CI improvements. The cover letter notes ongoing discussions about some changes (particularly the cross-compilation fix) and shows willingness to adjust attribution as needed. With the v1 patches already reviewed and the new additions building on prior discussion, this appears to be moving toward consensus.
