This is a refactoring patch in Patrick Steinhardt's reftable API improvement series (patch 3/16). It consolidates block source handling code that was previously scattered across multiple files into a single `reftable/blocksource.[ch]` pair.

The patch moves several key block source operations into the new location:
- `block_source_return_block()` (previously `reftable_block_done()`)
- `block_source_close()`
- `block_source_read_block()`
- `block_source_size()`

The changes are mechanical but extensive, touching 10 files with 80 lines added and 62 removed. The consolidation:
1. Removes duplicate implementations of block source operations
2. Updates all callers to use the new centralized functions
3. Improves documentation with clearer header comments
4. Maintains existing functionality while making the codebase more organized

This is part of the larger effort to make the reftable code more maintainable and suitable for standalone use. The patch follows logically after the license standardization (patch 1) and structure renaming (patch 2) in the series, continuing the pattern of incremental improvements to the code organization.
