Build system patch addressing out-of-tree benchmark execution in the ongoing Meson integration series.

This third patch in the 5-part series fixes benchmark execution when Git is built out-of-tree, a common scenario with Meson and CMake builds. The change modifies `t/perf/perf-lib.sh` to properly locate build artifacts and scripts by:

1. Introducing logic to detect the build directory through `GIT-BUILD-DIR` when present, with special handling for Windows paths via `cygpath`
2. Using `GIT_SOURCE_DIR` to reference test infrastructure files like `test-lib.sh`
3. Updating the benchmark aggregation script path to use the source directory

The patch maintains backward compatibility with in-tree builds while adding support for build directories located elsewhere. The Windows path conversion shows attention to platform-specific needs. The changes are focused on the benchmark infrastructure without modifying actual benchmark logic, keeping the scope clean.

Key technical details for future reference:
- New variable handling: `GIT_BUILD_DIR` detection and Windows path conversion
- File paths modified: `GIT-BUILD-OPTIONS`, `test-lib.sh`, `aggregate.perl`
- Platform-specific code path for MinGW/Cygwin
- Maintains existing `TEST_DIRECTORY` usage for config files

This continues the series' pattern of focused, well-explained changes that solve specific Meson integration challenges while improving general benchmark infrastructure. The patch appears technically sound and follows the established approach from previous patches.
