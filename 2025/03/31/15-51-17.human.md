This is patch 6/8 in Elijah Newren's series to remove the legacy merge-recursive implementation in favor of merge-ort. The patch humorously "debugs" merge-recursive by deleting its code files (merge-recursive.c and merge-recursive.h) after moving any shared functions to merge-ort.

The key changes are:
1. Deletion of merge-recursive.[ch] files (over 4000 lines removed)
2. Moving several functions from merge-recursive to merge-ort:
   - merge_recursive_config()
   - init_merge_options()
   - init_ui_merge_options() 
   - init_basic_merge_options()
   - copy_merge_options()
   - clear_merge_options()
   - parse_merge_opt()
3. Updating documentation to note that 'recursive' is now just a synonym for 'ort'
4. Removing merge-recursive build targets from Makefile and meson.build

The patch completes the code removal after the previous patches switched all callers to use merge-ort. It's a significant milestone marking the end of the multi-year effort to replace merge-recursive with the newer merge-ort implementation. The commit message humorously references the adage that "deleted code is debugged code" to celebrate the removal.
