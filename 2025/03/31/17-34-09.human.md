This is a test infrastructure cleanup patch in Elijah Newren's series to remove the legacy merge-recursive implementation. It's patch 7/8 in the final phase of the multi-year merge-ort migration project. The patch removes now-obsolete test scaffolding that was used to compare behavior between the old merge-recursive and new merge-ort backends.

The changes are straightforward mechanical deletions: the GIT_TEST_MERGE_ALGORITHM environment variable and test_expect_merge_algorithm helper function are no longer needed now that merge-ort has completely replaced merge-recursive. The commit message explains these were originally created to allow easy comparison between the two backends during the transition period.

The patch appears uncontroversial as it simply removes test infrastructure that has served its purpose now that merge-ort is the sole merge backend.
