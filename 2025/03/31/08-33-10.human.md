This is a build system patch addressing cross-compilation support in Git's Meson build configuration. It's part of Patrick Steinhardt's v2 series consolidating various build system fixes.

The patch properly distinguishes between build-time and target binaries when cross-compiling Git. Currently, the build system doesn't handle this distinction, which becomes important when the build and target machines differ (like building Windows from Linux). The change modifies `find_program()` calls to explicitly specify whether they should find native (build-time) or target binaries, with special handling for shell, Python, and Perl which need target paths embedded in the final executable.

The implementation adds proper cross-compilation documentation in meson.build and updates all relevant program lookups (documentation tools, gitweb, test environment) to use the correct binary type. This ensures paths embedded in the built Git will work on the target system rather than pointing to build machine locations.

This appears to be a well-considered change that fills a gap in Git's cross-compilation support. The patch maintains all existing functionality while properly handling the cross-compilation case, with clear documentation of the new behavior. It's a focused technical improvement that should help Git work better in cross-compilation scenarios.
