This is a build system patch addressing cross-compilation support in Git's Meson build configuration. It's the fourth patch in a v2 series collecting various fixes to the build infrastructure.

The patch focuses on properly distinguishing between build-host binaries (tools needed during compilation) and target-host binaries (tools whose paths get embedded in the final Git executable). The key change is adding explicit `native: true/false` parameters to `find_program()` calls throughout the build files. 

For cross-compilation scenarios, this allows specifying different paths for tools like `sh`, `perl`, and `python` that will be used at runtime versus those used during build. The patch modifies several build files (`meson.build`, `Documentation/meson.build`, `gitweb/meson.build`, `templates/meson.build`) to use the new target-specific versions of these binaries where appropriate.

The implementation introduces new variables like `target_shell`, `target_perl`, and `target_python` to hold the target-host versions, while keeping the original variables for build-time use. This matches Meson's cross-compilation model where machine files can specify different tool paths for the target system.

The changes are comprehensive but focused - touching only the binary discovery and path embedding logic while maintaining all existing functionality. The patch includes documentation updates explaining the cross-compilation use case and shows an example machine file configuration.
