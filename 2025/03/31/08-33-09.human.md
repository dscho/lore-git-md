Build system fix for contrib tests in meson builds. This is part of Patrick Steinhardt's v2 series consolidating build system improvements.

The patch addresses an issue where contrib tests (for the netrc credential helper and git-subtree) were being unconditionally wired up in meson builds, causing errors when `-Dtests=false` was specified. The fix wraps these test definitions in conditional blocks checking `get_option('tests')`, matching the behavior of the main test suite.

The change is straightforward - it simply moves the test environment setup and test definitions inside `if get_option('tests')` blocks in both `contrib/credential/netrc/meson.build` and `contrib/subtree/meson.build`. This prevents the "Unknown variable 'test_environment'" error that occurred during builds with tests disabled.

The patch was prompted by a report from Sam James and carries their Reported-by tag. It's a clean fix that maintains the existing test functionality while properly respecting the build configuration. This is one of several meson build improvements in the series, with this particular patch being carried forward unchanged from v1 after receiving positive feedback.
