Refactoring patch in the Perl-optional test suite series. This is patch 19/20 in the ongoing effort to make Perl optional for running Git's test suite.

The patch converts the `max_chain()` helper function in t5316-pack-delta-depth.sh from using Perl to using awk. The function extracts the maximum delta chain length from `git index-pack --verify-stat-only` output. The new awk implementation matches the same pattern ("chain length = N:") and extracts the numeric value while maintaining identical functionality.

Key technical details:
- The awk version uses $4 to capture the chain length value from the output line
- A `tr -d ':'` is added to strip the trailing colon from the output
- Four test cases that previously required PERL_TEST_HELPERS are updated to run without Perl
- The tests verify delta chain behavior with various --depth settings (0, 5, -1)

This follows the series' established pattern of identifying Perl dependencies and replacing them with more portable shell/C alternatives where possible. The change is straightforward and maintains the exact same test behavior while reducing Perl dependencies. With this patch, the final remaining Perl dependencies in the test suite are clearly marked via PERL_TEST_HELPERS.
