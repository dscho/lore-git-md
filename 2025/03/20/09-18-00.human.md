Refactoring patch review. Patrick Steinhardt reviews Martin Ågren's first patch in a series cleaning up Git's pretty-format parsing code. The change tightens the function signature of `format_commit_one()` to use the concrete `struct format_commit_context*` type rather than a `void*` that required casting. 

Steinhardt notes this is a sensible modernization - while the original 2009 implementation needed the `void*` because callers only had generic contexts, the current callers now work with the proper type. He agrees with removing the unnecessary indirection through a cast. This appears to be a straightforward cleanup that improves type safety without changing behavior, serving as groundwork for the more substantial refactorings that follow in the series.
