This is a refactoring patch in the ongoing series to make Perl optional in Git's test suite. The patch converts the `name_from_description()` helper function from using Perl to a combination of sed and tr commands. The function transforms test descriptions into sanitized names by replacing non-alphanumeric characters with dashes, compressing multiple dashes, removing leading/trailing dashes, and converting to lowercase.

Eric Sunshine raises a specific technical question about the implementation - whether sed's built-in transliteration (`y//`) could be used instead of piping to a separate `tr` command. This would potentially simplify the implementation by removing the pipe and extra process invocation. The change appears straightforward and maintains the same functionality, though the thread context shows Eric has been carefully reviewing these conversions for potential issues like semantic changes or optimization opportunities.

This patch follows the series' consistent approach of replacing Perl where possible while preserving behavior. The question about sed's `y//` suggests there may be room for minor optimization in this particular conversion, though the current implementation already achieves the primary goal of removing the Perl dependency.
