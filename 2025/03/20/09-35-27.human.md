This is a major refactoring effort to make Perl optional for running Git's test suite. Patrick Steinhardt proposes a 20-patch series that removes Perl dependencies from core test infrastructure and marks remaining Perl-dependent tests with a new PERL_TEST_HELPERS prerequisite.

The series demonstrates that Perl is no longer critical for Git's core functionality (only affecting non-essential features like gitweb and some import scripts), yet remains required for testing. The changes allow 97% of tests (30342/31358) to run without Perl by:

1. Replacing Perl-based test helpers with shell/C alternatives for environment sanitization, file operations, and character translation
2. Introducing PERL_TEST_HELPERS to gate Perl-dependent tests
3. Updating build systems (Makefile and meson) to no longer require Perl for testing
4. Refactoring individual test scripts that relied on Perl for text processing

The work appears thorough, touching 84 files with a clear migration strategy. The remaining Perl-dependent tests are cleanly isolated rather than being haphazard exceptions. This would be valuable for environments where Perl is undesirable or unavailable, while maintaining test coverage where Perl is present. The series builds on Git's gradual shift away from Perl dependencies over recent years.
