This is a refactoring patch in Martin Ågren's series to clean up Git's pretty-format parsing code. It focuses on the line-wrapping ("%w") placeholder handling in pretty.c.

The patch extracts the parsing logic for "%w" placeholders into a new `parse_rewrap()` helper function and introduces a `struct rewrap_args` to hold the parsed values (width, indent1, indent2). Unlike some earlier patches in the series, this doesn't fix any known bugs but improves code organization by better separating parsing from usage. The change also standardizes on using `size_t` for these values throughout.

Patrick Steinhardt has reviewed the patch and approves the approach, noting the code matches the existing logic well. He points out that the `memset()` initialization is unnecessary since all fields are set before use, but considers this a minor observation rather than a blocking issue. The refactoring maintains all existing behavior while making the code more maintainable.

This continues the series' pattern of modularizing pretty.c's formatting logic into clearer components. The changes are non-controversial and build on previous work in the file, with Patrick having already reviewed and approved several other patches in the series.
