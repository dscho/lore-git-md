This is part of Taylor Blau's incremental MIDX bitmap implementation series (v5 12/14), focusing on type-level bitmap tracking across MIDX layers. The patch introduces arrays to store each type's bitmaps (commits, trees, blobs, tags) from all layers in the MIDX chain, enabling efficient cross-layer operations.

Key technical details:
- Adds four new arrays to `struct bitmap_index`: `commits_all`, `trees_all`, `blobs_all`, `tags_all` to track type bitmaps across layers
- Implements `load_all_type_bitmaps()` to populate these arrays by walking the MIDX chain from current layer back to base
- Modifies `load_bitmap()` to accept a `recursing` flag and trigger type bitmap loading only at top level
- Updates `free_bitmap_index()` to clean up the new arrays
- Maintains backward compatibility by keeping single-element arrays for non-incremental cases

The change supports the series' cross-layer bitmap operations by providing structured access to type bitmaps across the MIDX chain, which will be used by the EWAH iterator introduced in patch 11/14. The implementation carefully handles layer counting with a BUG` check for consistency and preserves the existing single-layer behavior when no base MIDX exists.
