Build system patch in the Perl-optional test suite series. This ninth patch modifies the Makefile to make Perl truly optional when running tests, completing the build system side of the effort. It conditionally includes Perl-dependent targets (chain linting and shell syntax checking) only when Perl is available, while ensuring the test suite can run without Perl by default setting GIT_TEST_CHAIN_LINT=0 when Perl is absent. The changes affect several test-related targets: `test`, `prove`, and `test-lint` now have their Perl-dependent components gated behind $(PERL_PATH) checks. This maintains functionality when Perl is present while allowing the test suite to run in reduced-capacity mode without Perl. The patch follows the series' pattern of progressively removing hard Perl dependencies while preserving test coverage, with this change focusing on the build system integration to match the test infrastructure changes from earlier patches.
