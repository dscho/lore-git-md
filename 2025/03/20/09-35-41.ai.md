This is patch 14/20 in the series to make Perl optional in Git's test suite, focusing on PGP signature sanitization in test helpers.

The patch converts the `sanitize_pgp()` helper function from using Perl to using `sed`, removing the PERL_TEST_HELPERS dependency. The function strips PGP signature blocks from input, which is used in GPG-related tests. The new implementation uses a sed range pattern to delete lines between PGP markers while preserving the markers themselves.

The change requires updating t6300-for-each-ref.sh to explicitly mark Perl-dependent tests with PERL_TEST_HELPERS rather than skipping all tests when Perl is unavailable. This affects several test cases that use Perl-specific features like trailer processing, which remain Perl-dependent for now. The patch maintains the series' pattern of mechanical substitutions while preserving test functionality.

Key technical details:
- Replaces Perl state tracking with sed range pattern /^-----BEGIN PGP/,/^-----END PGP/
- Updates 5 test cases in t6300 to use PERL_TEST_HELPERS explicitly
- Keeps the same PGP signature stripping behavior but with different implementation
- Follows the series' approach of maintaining test coverage while removing Perl

The change is straightforward and maintains the existing test behavior, continuing the series' progress toward making Perl optional. The remaining Perl dependencies in t6300 are properly marked for future handling.
