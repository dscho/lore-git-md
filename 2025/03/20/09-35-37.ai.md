This is patch 10/20 in a series refactoring Git's test suite to reduce Perl dependencies. It focuses on replacing Perl's transliteration` operator (y/// or tr///) with the standard `tr(1)` utility in test scripts.

The patch modifies 7 test files (t/helper/test-sha1.sh, t/lib-diff.sh, t/t3300-funny-names.sh, t/t4020-diff-external.sh, t/t4103-apply-binary.sh, t/t4116-apply-reverse.sh, t/t4200-rerere.sh) to use `tr` instead of Perl for simple character substitutions. This allows removing several PERL_TEST_HELPERS prerequisites from tests that previously required Perl just for basic character translation.

Key changes include:
- Replacing `perl -pe 'y/x/y/'` patterns with `tr "x" "y"`
- Removing PERL_TEST_HELPERS markers from tests now using shell-only features
- Maintaining identical test behavior while eliminating Perl as a dependency
- Keeping one Perl-dependent test in t4103-apply-binary.sh that handles binary diff rejection (still marked with PERL_TEST_HELPERS)

The changes are straightforward mechanical conversions where Perl's transliteration was being used for simple character substitution that `tr` can handle equally well. This continues the series' pattern of identifying and removing unnecessary Perl dependencies while maintaining test coverage.
