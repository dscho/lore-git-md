This is a performance optimization in Taylor Blau's incremental MIDX bitmap series (v5 13/14). The patch updates type bitmap iteration to use the new `ewah_or_iterator` introduced earlier in the series, which efficiently combines bitmaps across MIDX layers.

The changes replace direct `ewah_iterator` usage with the new iterator type in several key functions that handle object type filtering and counting (`show_objects_for_type`, `filter_bitmap_exclude_type`, etc.). Each now properly initializes the iterator with the type-specific bitmap arrays (`commits_all`, `trees_all` etc.) and includes proper cleanup with `ewah_or_iterator_release`.

This is a mechanical but important change that enables the cross-layer bitmap operations the series is built around. The patch follows the established pattern from previous commits in the series, maintaining consistency in how MIDX layers are traversed. With this change, all type-specific bitmap operations now properly account for objects across the full MIDX chain.
