This is a test infrastructure patch in Taylor Blau's incremental MIDX bitmap series (v5 08/14). It extends `git rev-list --test-bitmap` to properly handle the new layered MIDX structure.

The patch modifies the bitmap testing code to track which MIDX layer contains each commit being tested, reporting this information in the test output. It introduces recursive `bitmap_test_data` structure that mirrors the MIDX bitmap chain, with helper functions to prepare and release these nested structures. The test output now shows both the total number of bitmap entries across all layers and which specific pack/MIDX file provided the bitmap.

Key technical changes include:
- New `find_bitmap_for_commit()` helper that tracks the originating bitmap layer
- Extended test output showing MIDX/pack origins via `hash_to_hex_algop()`
- Recursive test data preparation/release functions
- Cross-layer object counting via `bitmap_total_entry_count()`

This completes the testing infrastructure needed to validate the incremental MIDX bitmap functionality, maintaining the series' careful attention to resource management and backward compatibility. The changes are well-contained and follow the established patterns from earlier patches in the series.
