This is part 4 of a 20-part refactoring series to make Perl optional in Git's test suite. The patch converts the `test_copy_bytes()` helper function from using Perl to using `dd(1)` for copying bytes from stdin to stdout.

The change is straightforward - replacing a Perl implementation that manually reads and writes bytes with a simple `dd` command that does the same job. The Perl version used sysread to carefully copy exactly N bytes, while the new version uses `dd`'s built-in byte counting with `ibs=1 count=N`. The 2>/dev/null redirect silences dd's statistics output.

This affects test infrastructure rather than any specific test, modifying just one file (`t/test-lib-functions.sh`) with a net removal of 11 lines. The commit message notes this change will allow several tests to pass without Perl, though it doesn't specify which ones. The rest of the series follows this same pattern of identifying and removing Perl dependencies while maintaining test functionality.

Key technical details for future reference:
- Function: `test_copy_bytes()` in `t/test-lib-functions.sh`
- Old implementation: Perl sysread loop
- New implementation: `dd ibs=1 count=N`
- Behavior change: Silences dd statistics output (2>/dev/null)
- Impact: Enables Perl-less operation for tests using this helper
