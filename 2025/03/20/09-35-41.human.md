This is part 14/20 of the series to make Perl optional in Git's test suite, focusing on PGP signature sanitization in test helpers.

The change refactors the `sanitize_pgp()` helper function in t/lib-gpg.sh to use `sed` instead of Perl for stripping PGP signatures from test output. The new implementation uses a simpler `sed` pattern that achieves the same effect of removing PGP blocks while being more portable. 

As a consequence, the patch removes the PERL_TEST_HELPERS prerequisite from t6300-for-each-ref.sh tests that were previously skipped when Perl wasn't available. However, it adds PERL_TEST_HELPERS back to specific test cases in t6300 that still require Perl functionality (like raw output formatting with --perl and trailer processing).

The change follows the series' established pattern of mechanical substitutions that maintain test behavior while reducing Perl dependencies. The implementation appears straightforward and maintains the same functionality, though the commit message notes that some tests in t6300 still need Perl for certain features. This continues the steady progress toward making 97% of tests run without Perl.
