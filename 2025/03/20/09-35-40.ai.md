This is patch 13/20 in the series to make Perl optional in Git's test suite, focusing on textconv-related tests. The patch converts three test files that previously relied on Perl for text conversion scripts to use shell utilities instead, allowing them to drop PERL_TEST_HELPERS prerequisites.

The changes replace Perl-based textconv scripts with simpler shell equivalents:
- In t4030-diff-textconv.sh, replaces a Perl hexdump script with a `tr` command that converts null/control characters to "01"
- In t4031-diff-rewrite-binary.sh, swaps a similar Perl hexdump for a new `test-tool hexdump` helper
- In t7815-grep-binary.sh, converts a Perl null-to-Q transliteration to use `tr` instead

The author notes these aren't always exact functional equivalents, but argues the tests only need to verify textconv functionality rather than precisely match Perl's output. The patch follows the series' pattern of mechanical substitutions while maintaining test coverage, removing PERL_TEST_HELPERS from these files while keeping test behavior meaningful. The changes are straightforward and consistent with the series' goal of reducing Perl dependencies without introducing new edge cases.
