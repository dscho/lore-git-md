Feature patch adding MIDX bitmap testing support to `git rev-list --test-bitmap`.

This is patch 08/14 in Taylor Blau's v5 series implementing incremental MIDX bitmaps. The patch extends the `--test-bitmap` mode of `git rev-list` to properly handle multi-layer MIDX bitmaps, completing the testing infrastructure for the feature.

Key technical changes:
- Introduces `find_bitmap_for_commit()` which tracks which bitmap layer contains a commit (via new `found` output pointer), replacing direct use of `bitmap_for_commit()`
- Extends `bitmap_test_data` with `base_tdata` pointer to mirror MIDX chain structure
- Adds recursive test data preparation/release functions (`bitmap_test_data_prepare()` and `bitmap_test_data_release()`) 
- Implements cross-layer object counting via `bitmap_total_entry_count()`
- Enhances test output to show MIDX/pack origin of found bitmaps using `hash_to_hex_algop()`
- Modifies `test_bitmap_type()` to properly handle base layer objects
- Maintains backward compatibility when no base MIDX exists

The changes follow the series' established patterns for handling MIDX chains, with proper resource management through recursive freeing. Test output now includes both per-layer and total object counts, plus origin tracking for debugging. This completes the testing infrastructure needed to validate the incremental MIDX bitmap functionality introduced in earlier patches.
