This is part 18/20 in a series making Perl optional in Git's test suite, focusing on the trace2 testing infrastructure. The patch converts trace2 output scrubbing from Perl to sed, removing the need for Perl in these tests.

Patrick Steinhardt refactors the test scrubbing logic that handles variable fields in trace2 output (like elapsed times and executable paths) to make test output predictable. The new implementation uses sed instead of Perl while maintaining the same scrubbing behavior - replacing timestamps with placeholders", normalizing executable paths, and omitting platform-specific cmd_path/ancestry lines.

The change follows the series' established pattern: identify Perl usage, replace it with portable shell/C equivalents, and remove PERL_TEST_HELPERS where no longer needed. The commit shows careful attention to preserving test behavior - all existing test expectations remain unchanged, just the implementation differs. This continues the project's steady progress toward making 97% of tests run without Perl.
