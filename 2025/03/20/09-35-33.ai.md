Test infrastructure patch introducing PERL_TEST_HELPERS prerequisite.

This is patch 6/20 in a series making Perl optional for Git's test suite. It introduces a new PERL_TEST_HELPERS prerequisite to distinguish between features that inherently require Perl (tracked by existing PERL prerequisite) and tests that use Perl helpers but could potentially be converted.

The patch:
- Documents the distinction between PERL (built Perl features) and PERL_TEST_HELPERS (test suite Perl usage)
- Adds PERL_TEST_HELPERS to 71 test files that currently rely on Perl helpers
- Skips affected tests when Perl is unavailable via test_done
- Maintains identical test behavior while allowing the suite to run without Perl

Key technical details:
- Tests using Perl for text processing, binary data generation, or complex assertions are marked
- Some tests are skipped entirely when Perl is missing (like t0008-ignores.sh)
- Others have individual test cases marked (like t0021-conversion.sh)
- The change spans 71 test files with 281 insertions and 93 deletions
- Follows the series' pattern of incrementally removing Perl dependencies

This prerequisite will help track remaining Perl dependencies in tests as the series progresses toward making Perl fully optional while maintaining test coverage.
