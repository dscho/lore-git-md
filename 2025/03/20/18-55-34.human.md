This is a review comment on patch 6/20 in the series to make Perl optional in Git's test suite. Eric Sunshine points out what appears to be a copy-paste error in the patch - the skip message for the binary apply tests incorrectly references "ignores tests" (from t0008) rather than "apply-binary tests" (for t4103).

The patch introduced the PERL_TEST_HELPERS prerequisite to clearly mark tests that still require Perl, with the goal of making most tests optional while preserving coverage. While the core change is sound, this appears to be a minor oversight in the test skip messages that should be corrected for clarity. The series overall is methodically removing Perl dependencies, with this patch establishing the framework to mark remaining Perl-required tests.
