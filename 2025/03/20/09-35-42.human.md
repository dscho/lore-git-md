This is part 15/20 of the ongoing series to make Perl optional in Git's test suite. The patch refactors the `name_from_description()` test helper function to remove its Perl dependency.

The function, which converts test descriptions into sanitized filenames by replacing non-alphanumeric characters with dashes and lowercasing, has been rewritten using `sed` and `tr` instead of Perl. This allows the removal of `PERL_TEST_HELPERS` prerequisites from two test files (`t6002-rev-list-bisect.sh` and `t6003-rev-list-topo-order.sh`) that use this helper.

The change follows the series' established pattern of systematically replacing Perl functionality with equivalent shell/C implementations while maintaining the same behavior. The patch is straightforward and maintains the same output format, just with different implementation details under the hood.
