Refactoring of HTTP test infrastructure to remove Perl dependency. This patch is part 16/20 of the series making Git's test suite work without Perl.

Patrick Steinhardt refactors the HTTP test server's "one-time-perl" functionality to work with any script rather than requiring Perl specifically. The endpoint is renamed to "one-time-script" and the supporting CGI script is rewritten in shell. This allows removing PERL_TEST_HELPERS prerequisites from several HTTP protocol tests that previously relied on Perl for modifying server responses.

The change affects multiple test files that simulate server-side repository changes between requests by temporarily installing response-modifying scripts. The patch demonstrates careful attention to maintaining the same behavior while switching from Perl to shell utilities, with tests updated to use sed and other shell tools for their modifications.

This continues the series' pattern of identifying Perl dependencies in tests and replacing them with portable alternatives. The changes here are straightforward and well-contained, focused specifically on the HTTP test infrastructure without broader implications.
