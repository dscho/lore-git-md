This is part 5 of a 20-part series refactoring Git's test suite to reduce Perl dependencies. The patch converts the `test_readlink()` helper function from using Perl to a native implementation in `test-tool path-utils`.

The change replaces the Perl one-liner that reads symlinks with a new C implementation in `test-path-utils.c` that uses Git's existing `strbuf_readlink()` function. The shell wrapper in `t/test-lib-functions.sh` is updated to call the test-tool instead of Perl. This maintains the same functionality (reading symlink targets) while removing the Perl dependency.

Key technical details:
- Adds new `readlink` subcommand to `test-tool path-utils`
- Uses `strbuf_readlink()` for the actual symlink reading
- Preserves the same interface (handles multiple arguments, prints each result)
- Error handling matches Perl version (dies on failure)
- Affects 2 files: test helper (+13 lines) and test-lib wrapper (-1 Perl line, +1 test-tool line)

This follows the series' pattern of identifying Perl dependencies in test infrastructure and replacing them with portable alternatives. The change is straightforward and maintains identical behavior while removing a Perl requirement.
