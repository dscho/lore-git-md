This is part 9 of a 20-part series refactoring Git's test suite to make Perl optional. The patch modifies the test Makefile to conditionally run Perl-dependent targets only when Perl is available.

The key changes remove Perl as a hard requirement by:
- Making `check-chainlint` and shell syntax linting optional when Perl is missing
- Setting `GIT_TEST_CHAIN_LINT=0` by default when Perl isn't present
- Keeping the core test and prove targets functional without Perl

The patch follows the series' pattern of systematically identifying and removing Perl dependencies while maintaining test functionality. It builds on previous work that already converted many Perl-based test helpers to shell/C equivalents. The changes are straightforward - just wrapping Perl-dependent Makefile targets in conditionals - and maintain backward compatibility when Perl is present.

This continues the series' progress toward making 97% of Git's test suite runnable without Perl, while still allowing the full suite to run when Perl is available. The patch appears well-contained and aligns with the overall series goal.
