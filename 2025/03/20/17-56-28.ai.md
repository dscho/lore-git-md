Documentation patch for the incremental MIDX bitmap series, providing technical specifications for the pseudo-pack ordering and bitmap handling in multi-layer MIDX chains.

This patch (2/14 in the v5 series) formally documents the design decisions around object ordering and bitmap handling for incremental MIDX layers. It establishes the key sorting rules that determine object positions across MIDX layers, which is fundamental for the bitmap operations implemented in later patches. The documentation clarifies that the pseudo-pack order concatenates objects from all layers while maintaining the chain's preferred pack property at the global level rather than per-layer.

Key technical details specified:
- Three-level object comparison algorithm for pseudo-pack ordering (layer precedence, then pack order within layer, then pack offset)
- Bitmap file structure remains unchanged from non-incremental MIDX
- Type-level bitmap handling with OR operations across layers
- Position numbering spans entire chain (earlier layers occupy lower positions)
- Only newest layer's bitmap stores full reachability information
- Explicit note about future compaction possibility (though not implemented)

The documentation aligns with the implementation choices made in the series, particularly around the global preferred pack and the avoidance of recursive bitmap lookups. It serves as a reference for both the implementation in subsequent patches and for future maintenance of the feature. The patch follows the series' pattern of thorough documentation accompanying implementation work.
