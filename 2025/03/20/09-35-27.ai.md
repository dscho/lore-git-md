This is a major refactoring series aimed at making Perl optional for running Git's test suite. The cover letter explains that while Perl is already optional for most Git functionality, it remains a hard requirement for testing. The series refactors various test components to remove Perl dependencies, introducing a new PERL_TEST_HELPERS prerequisite for tests that still need Perl.

The technical changes span across multiple test scripts and helper functions, with key refactorings including:
- Replacing Perl-based environment sanitization with shell equivalents
- Adapting character translation and file operation helpers to use shell instead of Perl
- Converting test cases that relied on Perl operators (transliteration, substitution)
- Refactoring specific test scripts like t0210 (trace2) and t5316 (pack delta depth) to remove Perl
- Adding a new PERL_TEST_HELPERS marker for remaining Perl-dependent tests

The series touches 84 files with 471 insertions and 373 deletions, achieving 97% test coverage (30342/31358 tests) without Perl. The changes affect both Makefile and meson build systems to remove the Perl test requirement. This appears to be a well-scoped, systematic effort to modernize the test infrastructure by reducing legacy dependencies.
