Refactoring patch in the Perl-optional test suite series. This is patch 3/20 in Patrick Steinhardt's effort to make Git's test suite work without requiring Perl.

The patch replaces three Perl-based character translation helper functions in `t/test-lib-functions.sh` with equivalent `tr` commands. The functions convert between linefeeds and null bytes (`lf_to_nul`), null bytes and 'Q' (`nul_to_q`), and vice versa (`q_to_nul`). The author notes that while some historical `tr` implementations had issues with null bytes, POSIX-compliant versions handle them correctly.

This is a straightforward conversion that maintains identical functionality while removing the Perl dependency. The change is small (3 lines modified) but helps move toward the series' goal of making 97% of tests runnable without Perl. The commit message provides good context about POSIX compliance and the null byte concern, suggesting careful consideration of edge cases.

This follows the established pattern in the series of identifying Perl dependencies in test infrastructure and replacing them with shell equivalents where possible. The change is low-risk since it doesn't modify test behavior, only the implementation details of helper functions achieve that behavior.
