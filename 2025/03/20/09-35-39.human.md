Test modernization patch in the Perl-removal series. This is patch 12/20 in Patrick Steinhardt's effort to make Git's test suite work without Perl by replacing Perl-specific operations with shell/C equivalents.

The patch focuses on converting tests that use Perl for printing data in various ways. It identifies three common patterns: conditional printing (converted to awk), repeated printing (using test-tool genzeros + sed), and reverse printing (also using awk). The changes affect 14 test scripts across different areas including reftable, pack operations, bitmaps, and shell functionality.

The conversions appear mechanical and well-justified, removing PERL_TEST_HELPERS prerequisites from several tests while maintaining the same functionality. Notable changes include replacing Perl's string repetition with awk loops, Perl's reverse operations with sort -r or custom awk scripts, and Perl's pattern matching with sed equivalents.

This continues the series' pattern of careful, behavior-preserving substitutions. The patch maintains test coverage while reducing Perl dependencies, bringing the project closer to the goal of making Perl optional for running Git's test suite.
