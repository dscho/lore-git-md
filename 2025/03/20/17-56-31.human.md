This is part 3/14 of Taylor Blau's incremental MIDX bitmap series, which enables efficient bitmap operations across multi-pack index layers. The patch focuses on adapting the pack-revindex machinery to handle object lookups in incremental MIDX bitmaps.

Key changes include:
- `load_midx_revindex()` now selects the correct MIDX based on whether it's incremental or not
- `pack_pos_to_midx()` and `midx_to_pack_pos()` are updated to work with global object positions across MIDX layers
- The comparison function `midx_pack_order_cmp()` is adjusted to account for base objects
- A new helper `bitmap_num_objects_total()` is introduced to properly count objects across layers

The changes maintain backward compatibility while preparing for the incremental bitmap functionality that will be built on top.
