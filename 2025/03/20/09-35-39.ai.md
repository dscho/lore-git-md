Refactoring patch in the ongoing Perl-to-shell/C test conversion series. This is patch 12/20 in the effort to make Perl optional in Git's test suite while maintaining test coverage.

The patch converts various test scripts that use Perl for printing data in different ways to use shell/C alternatives instead. The changes fall into three categories: pattern matching (converted to awk), repeated output (using test-tool genzeros + sed), and reversing output (using awk or sort). The patch removes PERL_TEST_HELPERS prerequisites from several tests that no longer need Perl after these conversions.

Key technical changes include:
- Replacing Perl print loops with awk in t0610-reftable-basics.sh (large commit message test)
- Using test-tool genzeros + tr for generating repeated strings in t0613-reftable-write-options.sh and t5300-pack-object.sh
- Converting Perl reverse operations to sort -r in t1010-mktree.sh
- Replacing Perl multi-line header processing with awk in t4150-am.sh
- Implementing delta counting via sed instead of Perl in t5300-pack-object.sh
- Adding a new reverse() helper function using awk in t6013-rev-list-reverse-parents.sh

The changes follow the established pattern of the series - mechanical substitutions that maintain test behavior while removing Perl dependencies. The patch removes PERL_TEST_HELPERS from 12 test files while keeping it in a few cases where Perl is still needed for more complex operations (like delta comparison in t5300-pack-object.sh). The conversions are straightforward and appear to preserve the original test intent.
