Refactoring patch in the Perl-less test suite series. This is part 10 of 20-part effort to make Perl optional for running Git's test suite.

The patch converts several tests that use Perl's transliteration operator (y/// or tr///) to instead use the standard Unix `tr` command. This affects 7 test files where simple character substitutions were being done via Perl. The changes are straightforward mechanical conversions, like replacing `perl -pe 'y/\000/g/'` with `tr "\000" "g"`.

Notable changes include:
- Removing PERL_TEST_HELPERS prerequisites from 5 tests that no longer need Perl
- Keeping one Perl prerequisite in t4103 where the test still needs Perl for other operations
- Maintaining identical test functionality while using more portable shell tools

This continues the series' pattern of systematically identifying and removing Perl dependencies while preserving test coverage. The changes are clean and focused, with each conversion well-justified by the commit message.
