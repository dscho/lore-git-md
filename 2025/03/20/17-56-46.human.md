This is part 8/14 of Taylor Blau's incremental MIDX bitmap series, focusing on testing infrastructure. The patch extends `git rev-list --test-bitmap` to properly handle incremental multi-pack indexes (MIDXs).

The key change is modifying the test framework to understand MIDX bitmap chains. The patch:
1. Introduces a new `find_bitmap_for_commit()` helper that tracks which bitmap layer contains each commit
2. Extends the `bitmap_test_data` structure to mirror MIDX chains with a `base_tdata` pointer
3. Adds recursive test data preparation and cleanup functions
4. Enhances test output to show where bitmaps were found (MIDX or pack) and total object count across all layers

The implementation maintains the existing test behavior while adding support for the new MIDX chain structure. Test output now includes additional diagnostic information that will help debug bitmap lookups across MIDX layers.

This is a well-contained piece of the larger MIDX bitmap effort, providing the testing infrastructure needed to verify the correctness of the incremental bitmap functionality introduced in earlier patches. The changes are focused and follow the established pattern of the series.
