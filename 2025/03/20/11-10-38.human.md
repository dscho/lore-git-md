Follow-up discussion on libgit-sys build approaches

Phillip Wood responds to Josh Steadmon's proposal for an alternative build approach in the libgit-sys Rust crate effort. The thread has been exploring different methods to handle Git source access during Rust builds while avoiding worktree pollution.

Wood notes that Meson's built-in out-of-tree build support could simplify the proposed solution of building in Cargo's working directory, but acknowledges the Git project's Meson support is still experimental. This suggests the Meson path might not yet be viable for production use, though it could be worth considering for future iterations.

The exchange continues the technical discussion about balancing build cleanliness with implementation complexity, with both symlink-based and out-of-tree approaches still under consideration. The response is brief but highlights an important architectural consideration (Meson's capabilities) that could influence the direction of this Rust integration work.
