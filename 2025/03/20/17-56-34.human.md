This is part of Taylor Blau's incremental MIDX bitmap implementation series (patch 4/14), building infrastructure for efficient bitmap operations across multi-pack index layers. The patch focuses on the foundational work needed to handle bitmap layers in a MIDX chain.

The changes introduce a new `base` pointer in `struct bitmap_index` to track the previous MIDX layer's bitmap index, along with a `base_nr` counter for the layer depth. The patch updates various bitmap-handling functions to properly open and manage these layered bitmaps, including:
- Modifying `midx_bitmap_filename()` to handle split MIDX filenames
- Extending pack preparation to include base MIDX packs
- Adding base bitmap loading logic in `load_bitmap()`
- Ensuring proper cleanup with `free_bitmap_index()`

The changes are mostly plumbing work to support the incremental bitmap functionality that will be built on top in later patches. The implementation appears thorough, with clear attention to edge cases (like BUG-checking for invalid base bitmap states). This is a technical but necessary step in the larger MIDX bitmap effort.
