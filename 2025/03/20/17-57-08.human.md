This is the final patch in Taylor Blau's v5 series implementing incremental MIDX bitmaps, completing the writing infrastructure for layered multi-pack index bitmaps. The patch enables Git to write bitmaps that span multiple MIDX layers, building on the reading capabilities added earlier in the series.

Key changes include:
- Modifying `find_object_pos()` to locate objects in previous MIDX layers when they don't exist in the current layer
- Updating `bitmap_writer_build_type_index()` to offset bits based on preceding layers' object counts
- Extending the bitmap writing machinery to handle MIDX chains through a new `midx` parameter
- Adding comprehensive tests in t5334 that verify bitmap functionality across multiple MIDX layers

The implementation maintains backward compatibility while enabling efficient bitmap operations across MIDX layers. The test suite covers both functional correctness (verifying objects can be read from any layer) and performance characteristics (testing pack reuse with different strategies).

This patch completes all planned components of the incremental MIDX bitmap implementation, following through on the writing side after earlier patches established the reading infrastructure. The series appears well-tested and carefully implemented, with clear attention to maintaining existing behavior while adding the new layered functionality.
