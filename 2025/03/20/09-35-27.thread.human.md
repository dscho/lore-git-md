Patrick Steinhardt's ongoing effort to eliminate Perl dependencies from Git's test suite continues with part 17/20, which focuses on random character generation in the test infrastructure. The series has already successfully converted substantial portions of the test suite, including text processing, GPG signature handling, HTTP protocol tests, and test description sanitization, all while maintaining behavior fidelity.

The latest patch converts the `generate_random_characters()` helper in t0021-conversion.sh from using Perl to a POSIX-compatible implementation. The new approach uses Git's existing `test-tool genrandom` to produce random bytes, filters them to the 'a-z' range with `tr`, and copies the required number of bytes. This change removes the PERL_TEST_HELPERS prerequisite from three test cases while keeping the same random seed for reproducibility.

The series has maintained a consistent pattern of direct Perl-to-POSIX replacements, with each conversion carefully preserving test behavior. Previous parts have addressed feedback from reviewers like Phillip Wood and Eric Sunshine, and this latest change continues that trend with a straightforward, well-contained implementation. With this patch, the series has now demonstrated Perl-free handling of random data generation, adding to its coverage of text processing, cryptographic artifacts, and network protocol testing. The remaining work focuses on the final Perl dependencies in Gitweb and netrc helper tests.
