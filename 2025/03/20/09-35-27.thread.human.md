This thread discusses a 20-part series refactoring Git's test suite to make Perl optional while maintaining test coverage. The series systematically replaces Perl dependencies with shell or C equivalents and introduces a PERL_TEST_HELPERS marker for tests that still require Perl.

The first eight patches demonstrated the approach by converting various test helpers (environment sanitization, character translation, file copying) from Perl to shell or test-tool implementations, while properly marking remaining Perl dependencies. The ninth patch, just added, completes the build system side by making Perl truly optional for running tests. It conditionally includes Perl-dependent targets (like linting) only when Perl is available, defaulting to GIT_TEST_CHAIN_LINT=0 when Perl is absent. This allows the test suite to run in reduced-capacity mode without Perl while maintaining full functionality when Perl is present.

The series has achieved 97% test coverage (30,342/31,358 tests) without Perl, with changes spanning 91 files. Each patch follows a consistent pattern of identifying Perl dependencies and replacing them with portable alternatives where possible, while properly marking remaining requirements. The build system changes in patches 8 (Meson) and now 9 (Makefile) complete the end-to-end transition by aligning the configuration with the test suite's reduced Perl needs.
