This thread tracks Patrick Steinhardt's substantial effort to make Perl an optional dependency for Git's test suite, a 20-patch series that's now about halfway complete. The work has progressed methodically, with earlier patches establishing core infrastructure (like the PERL_TEST_HELPERS prerequisite) and converting key test scripts to work without Perl while maintaining backward compatibility. 

The most recent patches show the project entering its final phases. Patch 7/20 cleaned up test prerequisites, carefully categorizing which tests still need Perl versus those that can use the new helpers or never needed Perl dependency at all. Now with patch 8/20, the changes reach the build system itself, updating Meson configuration so the test suite no longer requires Perl by default - though Perl remains necessary for Gitweb and the netrc credential helper. 

The series has garnered consistent approval from key contributors, including Johannes Schindelin (validating the Windows compatibility benefits) and Phillip Wood. Each patch builds carefully on the last, with the latest build system change being a small but important step that completes the logical separation between test execution and Perl requirements established in the technical groundwork. The work demonstrates how even complex, multi-patch refactorings can proceed smoothly when broken into well-defined incremental steps with clear review checkpoints.
