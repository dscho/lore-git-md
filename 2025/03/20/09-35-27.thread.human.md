Patrick Steinhardt's ongoing effort to eliminate Perl dependencies in Git's test suite has reached part 12/20 of his comprehensive series. The work continues to systematically replace Perl functionality while maintaining test fidelity, having already made Perl optional for 99% of tests (with only Gitweb and netrc helper tests still requiring it).

The latest installment focuses on converting tests that use Perl for printing operations, replacing them with alternative tools like awk, sed, and a new test-tool genzeros helper. The changes handle three main use cases: conditional pattern matching (now using awk), repeated data generation (using test-tool genzeros with sed), and reverse output (via awk or sort -r). These conversions affect 14 test files, including reftable tests, reflog message generation, and MERGE_RR parsing in rerere tests.

The series has built substantial momentum, with parts 2-11 having established core infrastructure like the PERL_TEST_HELPERS prerequisite system, environment filtering via standard Unix tools, and build system adaptations. Previous feedback from regular reviewers Phillip Wood and Eric Sunshine has been consistently addressed, contributing to the series' technical consensus. The work demonstrates Git's gradual but determined shift away from Perl, with each patch carefully preserving test behavior while incrementally expanding the range of Perl-free testing capabilities.
