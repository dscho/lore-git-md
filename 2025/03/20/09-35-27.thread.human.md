Patrick Steinhardt's 20-part series to eliminate Perl dependencies in Git's test suite has reached its final form with v3, but we're seeing an earlier patch (2/20) that shows how the conversion was done at a technical level. The series as a whole has already been reviewed and approved, making Perl optional for 97% of the test suite (30342/31358 tests), with only Gitweb and the netrc helper still requiring it.

This particular patch demonstrates the conversion approach by replacing Perl-based environment variable filtering in `t/test-lib.sh` with a sed-based solution. It carefully preserves the existing behavior of whitelisted variables (like GIT_TRACE and GIT_TEST) while removing the Perl dependency. The change builds on prior work by Johannes Schindelin and follows the series' consistent pattern of using standard Unix tools like sed instead of Perl.

The series has already incorporated extensive review feedback from Eric Sunshine and Phillip Wood, with all technical concerns addressed in the final v3 version. This early patch shows the careful, systematic approach taken throughout the conversion effort - each Perl dependency was removed while maintaining identical test functionality. The end result is a test suite that can run almost entirely without Perl, a significant architectural improvement for Git's testing infrastructure.
