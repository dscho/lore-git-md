Patrick Steinhardt's multi-iteration effort to remove Perl as a mandatory dependency for Git's test suite has reached completion with Johannes Schindelin's final sign-off on the v4 series. The 20-patch series systematically converted test infrastructure and individual test files to use shell, awk, and sed alternatives while maintaining all existing test behavior. The changes reduce Git's Windows installer size by 10MB while keeping backward compatibility intact.

The series was structured in two main phases: first establishing the PERL_TEST_HELPERS framework and updating build systems (patches 1-8), then converting test files (patches 9-20). The final patch converted t5703-upload-pack-ref-in-want.sh to use test_grep for capability filtering. The only remaining Perl dependency is for HTTPD/CGI tests, which would require more substantial refactoring.

Schindelin's approval as both a core contributor and Git for Windows maintainer confirms the technical soundness of the approach, particularly for Windows users who benefit most from the reduced footprint. The series received consistent positive feedback through all iterations, with earlier approvals from Phillip Wood and others remaining valid. With no outstanding objections, this marks a successful conclusion to a major infrastructure modernization effort that makes Perl optional for most test scenarios.
