This thread documents Patrick Stehtardt's ongoing effort to make Perl optional in Git's test suite while maintaining full test coverage. The 20-part series systematically converts Perl-dependent test helpers to alternative implementations, with significant progress already made in the first seven patches - including converting chain lint behavior, environment sanitization, character translation functions, file operations, and properly categorizing Perl prerequisites.

The latest patch focuses on build system integration, updating Meson configuration to no longer require Perl just because tests are enabled. This change reflects the series' success in reducing test suite dependencies, though Perl remains required for Gitweb and the netrc credential helper. The modification is straightforward, removing the tests condition from Perl requirements in meson.build while maintaining other legitimate Perl dependencies.

Reviewers including Eric Sunshine and Phillip Wood have provided detailed feedback throughout the series, with consensus forming around the systematic approach. The v2 iteration addressed several technical concerns around binary diff handling, commit message clarity, and test skip messages. A few open items remain regarding specific helper optimizations and performance considerations, but the core conversions demonstrate careful attention to POSIX compliance and verification capabilities.

With 97% of tests now running without Perl and the build system properly reflecting these changes, the series continues its methodical progress toward making Perl truly optional for most Git operations while preserving test reliability.
