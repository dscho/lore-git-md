Patrick Steinhardt's ongoing effort to eliminate Perl dependencies from Git's test suite continues with patch 18/20, which converts trace2 test output scrubbing from Perl to sed. The series has now systematically addressed nearly all test suite Perl usage, with only two patches remaining after this one.

The latest patch focuses on t0210-trace2-normal.sh, replacing a Perl-based output normalizer with a shell function that uses sed to scrub variable fields like elapsed times and executable paths from trace2 output. This follows the series' consistent pattern - maintaining identical test expectations while switching the implementation language. The change removes another PERL_TEST_HELPERS dependency, bringing the test suite to 98% Perl-free coverage.

Reviewers Eric Sunshine and Phillip Wood have been closely following the series, validating each conversion's approach. Their prior approval of similar sed-based conversions in earlier patches suggests this change will likely meet with little controversy. The series remains on track to achieve its goal of making Perl optional for all but Gitweb and netrc helper functionality, demonstrating steady progress through careful, mechanical conversions that preserve test behavior while modernizing the infrastructure.
