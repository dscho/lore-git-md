Core infrastructure patch for incremental MIDX bitmaps, part of Taylor Blau's ongoing series. This fifth patch in the v5 series teaches the `bitmap_for_commit()` function to recursively search through MIDX bitmap layers when a commit isn't found in the current layer.

The change modifies the commit bitmap lookup to handle the layered MIDX structure by:
1. Making the function properly handle NULL bitmap_index pointers (needed for recursion)
2. Adding recursive calls to search previous layers when a commit isn't found
3. Maintaining the existing fast path for commits found in the current layer

This is a key building block for the incremental bitmap functionality, enabling efficient traversal across MIDX layers while preserving the existing performance characteristics for single-layer cases. The patch follows the established pattern of the series with clear commit message explanations and focused changes to the core bitmap lookup logic.
