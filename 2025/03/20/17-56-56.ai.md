Feature patch extending pseudo-merge functionality to work with incremental MIDX bitmaps, part of Taylor Blau's v5 series (10/14) implementing layered MIDX support.

This patch modifies the pseudo-merge application logic to traverse the MIDX bitmap chain when looking for pseudo-merges to apply. The key change replaces a single call to `apply_pseudo_merges_for_commit()` with a loop that walks through each layer's bitmap index via the `base` pointer, accumulating results from all layers. The `pseudo_merges_satisfied_nr` counter now tracks merges satisfied across all layers rather than just the current one.

Technical implementation:
- Maintains the existing `bitmap_index` traversal pattern seen throughout the series
- Uses the same `curr = curr->base` iteration approach established in other patches
- Preserves the existing `pseudo_merges_satisfied_nr` counter semantics while extending its scope
- Modifies only the core application logic in `pack-bitmap.c` without requiring changes to the pseudo-merge data structures

The change is logically consistent with the series' incremental MIDX approach and follows the established patterns for cross-layer operations. As with other patches in the series, it maintains backward compatibility when no base MIDX exists. The modification is focused and well-contained, building naturally on the infrastructure established in earlier patches.
