Performance optimization in Taylor Blau's incremental MIDX bitmap series (v5 13/14). This patch updates type bitmap iteration to use the new `ewah_or_iterator` introduced in v5 11/14, completing the transition to cross-layer bitmap operations. The changes affect several key functions that handle object type filtering and counting:

- Replaces all `ewah_iterator` instances with `ewah_or_iterator` in type-specific operations
- Updates `init_type_iterator()` to initialize the new iterator with type-specific bitmap arrays (`commits_all`, `trees_all`, etc.) and layer count
- Adds proper cleanup with `ewah_or_iterator_release()` in all functions using the iterator
- Maintains existing behavior while enabling cross-layer bitmap combination
- Touches core bitmap operations including:
  - Object display (`show_objects_for_type`)
  - Type filtering (`filter_bitmap_exclude_type`, `filter_bitmap_blob_limit`)
  - Object counting (`count_object_type`)
  - Disk usage calculation (`get_disk_usage_for_type`)

The changes are mechanical but critical for correct cross-layer bitmap operation, ensuring all type-specific bitmap operations properly combine information across MIDX layers while maintaining resource cleanup. This completes the type-level bitmap integration started in v5 12/14.
