This appears to be a regression introduced by commit c92abe71df (builtin/fetch: fix leaking transaction with `--atomic`, 2024-08-22), as bisect points to this change.

The report includes all necessary technical details - exact reproduction steps, error output, and bisect results. This looks like a legitimate bug in atomic reference transaction handling that needs fixing, though the impact is limited to the edge case where a lock file exists during an atomic fetch operation.
