This is part 17/20 of the ongoing series to make Perl optional in Git's test suite. The patch refactors the `generate_random_characters()` helper in t0021-conversion.sh to eliminate its Perl dependency.

The function generates random lowercase letters for test files, previously using Perl's character manipulation. The new version achieves the same result through a pipeline of shell utilities: `test-tool genrandom` produces random data, `tr -dc 'a-z'` filters to just lowercase letters, and `test_copy_bytes` (a previously refactored helper) ensures the correct length. This change allows removing the PERL_TEST_HELPERS prerequisite from three test cases that use this helper.

The conversion follows the series' established pattern of replacing Perl with portable shell/C alternatives while maintaining test behavior. The change is straightforward and well-contained, affecting only one test file while improving the test suite's portability.
