Feature patch extending `git rev-list --test-bitmap` to support incremental MIDX bitmaps, part of Taylor Blau's ongoing MIDX bitmap series (v5 08/14). This patch builds on the recursive MIDX bitmap infrastructure from previous patches to properly test bitmap lookups across MIDX layers.

Key technical changes:
- Extends `bitmap_test_data` with a `base_tdata` pointer to mirror the MIDX bitmap chain structure
- Introduces `find_bitmap_for_commit()` helper that tracks which bitmap layer contains each commit (used by the existing `bitmap_for_commit()`)
- Adds MIDX/pack origin reporting in test output via new `hash_to_hex_algop()` calls
- Implements recursive test data preparation/release with new `bitmap_test_data_prepare()` and `bitmap_test_data_release()` functions
- Modifies `test_bitmap_type()` to handle base layer objects correctly
- Adds total object count across all layers in test output via `bitmap_total_entry_count()`

The changes maintain backward compatibility when no base MIDX exists while properly exercising the new cross-layer bitmap functionality. Test coverage appears thorough, with careful handling of resource allocation and cleanup across the recursive bitmap layers. This is a key verification component for the overall MIDX bitmap series, ensuring the bitmap lookup logic works correctly across MIDX generations.
