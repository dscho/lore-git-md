This is a test infrastructure patch that's part of a larger series to make Perl optional in Git's test suite. It specifically addresses the chain linting mechanism which currently requires Perl.

The patch modifies the chain lint behavior when Perl is unavailable (PERL_PATH unset), automatically disabling the linter in that case while still allowing explicit requests for linting to fail with a clear error. This is a preparatory change for the broader Perl removal effort, making the test suite more usable for developers without Perl installed.

The email contains minor grammatical corrections from Eric Sunshine (changing plural "scripts" to singular since there's only one chain lint script) but confirms the patch is acceptable as-is. This is the first patch in a 20-part series that systematically removes Perl dependencies from Git's test infrastructure while maintaining test coverage.

Key technical details for future reference:
- Chain linting is controlled via GIT_TEST_CHAIN_LINT
- The change affects t/test-lib.sh where the linting logic resides
- The patch maintains backward compatibility while paving the way for Perl-free operation
- Subsequent patches will build on this foundation to replace Perl dependencies throughout the test suite
