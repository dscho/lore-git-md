This is part 16/20 of the series to make Git's test suite work without Perl. The patch refactors an HTTPD test helper that previously required Perl to execute one-time scripts during HTTP requests.

The key change replaces the "one-time-perl" CGI script with a more generic "one-time-script" version that can execute any script, not just Perl. The functionality remains the same - it runs a script once to modify HTTP responses then deletes it - but now works with shell scripts instead of requiring Perl. This allows removing PERL_TEST_HELPERS from several test files that use this feature.

The patch updates:
- The Apache configuration to use the new endpoint name
- The CGI script itself (renamed and simplified)
- 5 test files that used the Perl version (t5537, t5616, t5702, t5703)
- Test cases are modified to use shell utilities (sed, write_script) instead of Perl

The changes follow the series' pattern of maintaining identical test behavior while removing Perl dependencies. Tests continue to verify HTTP protocol edge cases and error conditions, just using shell instead of Perl for the test modifications.
