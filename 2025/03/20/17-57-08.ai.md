Final patch in Taylor Blau's incremental MIDX bitmap series, implementing the writing of layered bitmaps. This completes the v5 series (14 patches) enabling efficient bitmap operations across multi-pack index layers.

Key technical additions in this patch:
- Extends `bitmap_writer_init()` to accept a MIDX parameter for locating objects from previous layers
- Modifies `find_object_pos()` to search base MIDX layers when objects aren't in current pack
- Updates `bitmap_writer_build_type_index()` to offset bits by base layer object counts
- Adds MIDX-aware path generation for bitmap/rev files via new `get_split_midx_filename_ext()`
- Removes restriction preventing incremental MIDX writes with bitmaps
- Includes comprehensive tests in t5334 covering:
  - Multi-layer bitmap creation/verification
  - Cross-layer object access
  - Pack reuse scenarios
  - MIDX chain relinking

The patch integrates with existing MIDX writing infrastructure while maintaining backward compatibility. When writing incremental bitmaps, it properly handles object positions across layers and ensures type-level bitmaps combine correctly via the offset mechanism introduced in earlier patches. Test coverage validates both functional correctness and the expected file layout for split MIDX chains.
