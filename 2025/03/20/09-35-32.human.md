This is part 5 of a 20-part series refactoring Git's test suite to reduce Perl dependencies. The patch converts the `test_readlink()` helper function from using Perl to a native implementation in `test-tool`.

The change moves the symlink reading logic from a Perl one-liner to a new `readlink` subcommand in `test-path-utils.c`. The implementation uses Git's existing `strbuf_readlink()` function to handle the actual symlink reading, making it portable across platforms where the `readlink(1)` command might not be available. The test helper interface remains identical, just routing through `test-tool` instead of Perl.

This is a straightforward conversion that follows the series' pattern of identifying Perl dependencies in test infrastructure and replacing them with equivalent native functionality. The patch is cleanly implemented and maintains the same behavior while removing another Perl requirement from the test suite.
