# Test suite refactoring to remove Perl dependency

This patch continues the series making Perl optional in Git's test suite by converting the `name_from_description()` helper function from Perl to shell utilities. The function transforms test descriptions into sanitized names by replacing non-alphanumeric characters with dashes and converting to lowercase.

The changes replace a Perl one-liner with a combination of `sed` and `tr` commands that achieve the same transformation:
- `sed` handles character substitution and dash compression
- `tr` converts uppercase to lowercase

Two test files (`t6002-rev-list-bisect.sh` and `t6003-rev-list-topo-order.sh`) that previously required PERL_TEST_HELPERS for this function now have those prerequisites removed. The patch follows the established pattern of the series by maintaining identical behavior while eliminating Perl dependencies.

Key technical details:
- The sed transformations preserve the same logic as the original (character substitution, dash compression, leading/trailing dash removal)
- The final lowercase conversion moves from Perl's `y///` to `tr 'A-Z' 'a-z'`
- Test coverage remains unchanged as the helper's output behavior is identical
- Build system changes aren't needed since this is purely a test helper modification

This is a straightforward conversion that follows the series' methodology of replacing Perl with portable shell/C alternatives where possible. The change is low-risk as it only modifies test infrastructure without affecting production code.
