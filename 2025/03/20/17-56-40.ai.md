This is a technical refinement patch in Taylor Blau's incremental MIDX bitmap series (v5 06/14). The change modifies `show_objects_for_type()` in pack-bitmap.c to properly handle pack lookups across MIDX layers by using `nth_midxed_pack()` instead of direct array access.

The key technical detail is that when traversing objects in a MIDX bitmap, we may need to reference packs from earlier MIDX layers (via the `base` pointer chain established in previous patches). The direct `->packs` array access only works for the current MIDX layer, while `nth_midxed_pack()` properly traverses the MIDX chain to find packs in any layer.

This is a small but important correctness fix that enables the layered bitmap operations to work properly when objects reside in packs from different MIDX generations. The change maintains backward compatibility when no base MIDX exists, as `nth_midxed_pack()` handles that case gracefully. This patch builds on the recursive lookup infrastructure added in patch 5/14, further enabling the series' goal of efficient cross-layer bitmap operations.
