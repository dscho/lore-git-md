This is a refactoring patch in Martin Ågren's series to modularize pretty-format parsing. Patch 6/8 focuses on the line-wrapping ("%w") placeholder logic in pretty.c.

The patch extracts the parsing of "%w" placeholders into a new `parse_rewrap()` helper function and introduces a `struct rewrap_args` to hold the parsed width, indent1, and indent2 values (converted from `unsigned long` to `size_t` for consistency). The main changes include:

1. Moving the parsing logic out of `format_commit_one()` into a dedicated function
2. Replacing direct field access in `format_commit_context` with a contained `rewrap` substructure
3. Updating the `rewrap_message_tail()` helper to work with the new struct

Patrick Steinhardt's review confirms the technical approach is sound, noting the improved control flow with early returns and matching behavior to the original implementation. He questions the necessity of the `memset()` initialization but considers this a minor point. The refactoring maintains all existing functionality while making the code more modular and easier to maintain, continuing the series' pattern of separating parsing from application logic.

This patch follows the established pattern from earlier in the series (padding and magic character parsing refactors) but focuses on the line-wrapping case. Unlike some previous patches, this is purely a code organization improvement with no bug fixes, as the original implementation already had decent separation of parsing and application.
