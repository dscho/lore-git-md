Bugfix for git-p4's error message handling when dealing with non-UTF-8 Perforce output.

Nikolay Shustov addresses an issue where `git p4` fails to decode Perforce error messages containing high-bit characters. The patch refactors the metadata decoding logic into a new `MetadataTranscoder` class and extends it to handle error message decoding using the existing `git-p4.metadataDecodingStrategy` and `git-p4.metadataFallbackEncoding` configuration options.

The changes include:
- Moving transcoding logic to a dedicated class for better organization
- Adding error message handling to use the same fallback strategies as metadata
- Including a new test case that verifies the fix works with Python 3

The implementation looks thorough, with careful attention to both Python 2 and 3 compatibility. The test coverage appears adequate, including a Python 3-specific test case. This seems like a solid fix for a real-world issue that could affect users dealing with non-ASCII Perforce error messages.
