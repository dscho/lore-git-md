This is a core infrastructure patch in Taylor Blau's incremental MIDX bitmap series (v5, patch 5/14). It modifies `bitmap_for_commit()` to support recursive lookup across MIDX bitmap layers, a key requirement for the layered bitmap design.

The patch makes `bitmap_for_commit()` recursively check parent bitmap layers when a commit isn't found in the current layer. The main changes are:
1. Moving the `hash_pos` initialization after NULL-checking the `bitmap_git` parameter
2. Adding recursive calls to `bitmap_for_commit()` with `bitmap_git->base` when commit lookups fail
3. Maintaining the same fallback behavior for both direct bitmap lookups and lazy-loaded bitmaps

The implementation preserves all existing behavior when no base MIDX exists (base will be NULL) while adding the recursive capability needed for multi-layer operation. This builds on the `struct bitmap_index`'s `base` pointer introduced in earlier patches to form the chain of bitmap layers.

The changes are focused and mechanical, directly supporting the series' goal of efficient bitmap operations across MIDX layers. The recursive design matches the thread's established approach to handling layered bitmaps, with proper NULL checking to maintain backward compatibility.
