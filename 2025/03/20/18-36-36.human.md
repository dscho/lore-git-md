This is a test infrastructure patch that's part of a larger series making Perl optional in Git's test suite. It specifically addresses the chain linting mechanism, which checks for proper '&&' chaining in test scripts.

The patch automatically disables chain linting when Perl isn't available (PERL_PATH unset), while still allowing explicit requests for linting to fail with an error. This makes the test suite more usable for developers without Perl installed, as they won't need to manually disable linting.

The change is straightforward and uncontroversial - Eric Sunshine's review confirms it's not worth a reroll, suggesting it's ready to proceed. This is the first patch in a 20-part series that systematically removes Perl dependencies from Git's test infrastructure while maintaining test coverage. The series as a whole appears well-planned, with this initial change setting up the foundation for subsequent Perl removal work.
