This is part 7 of a 20-part series refactoring Git's test suite to reduce Perl dependencies. The patch focuses on updating test prerequisites to properly reflect their actual Perl requirements.

The patch audits and updates four test files (t0021, t0090, t1006, t7501) that were incorrectly marked with PERL prerequisites. It identifies three categories of outdated prerequisites: tests that no longer use Perl at all (where PERL tag is simply removed), tests that still need Perl but should use the new PERL_TEST_HELPERS marker (not used here), and tests that need specific Perl modules (like IPC::Open2 in t1006).

The most notable change is in t1006-cat-file.sh, where the patch introduces a new PERL_IPC_OPEN2 prerequisite for tests requiring that specific Perl module, while also fixing a variable naming conflict in the process. The changes are straightforward and maintain existing test functionality while better representing the actual dependencies.

This continues the series' pattern of carefully auditing and updating test infrastructure to make Perl truly optional while preserving test coverage. The changes are mechanical but important for the overall goal of Perl independence.
