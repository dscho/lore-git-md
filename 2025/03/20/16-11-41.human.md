Refactoring patch in a series modernizing Git's pretty-format parsing. This is patch 6/8 in Martin Ågren's series to clean up pretty.c's parsing logic.

The patch extracts the line-wrapping ("%w") placeholder parsing into a new `parse_rewrap()` helper function and introduces a `struct rewrap_args` to hold the parsed values. Reviewer Patrick Steinhardt had questioned the need for a `memset()` initialization since the struct is only used when parsing succeeds and all fields are set. Martin agrees and will remove the unnecessary memset in the next version.

This continues the series' pattern of modularizing the pretty-format parsing code into focused helper functions with clearer data structures. The change is purely internal - no user-visible behavior is modified. The series has seen active collaboration between Martin and Patrick, with each patch being carefully reviewed and refined.
