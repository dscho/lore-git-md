This is the third patch in a 20-part series refactoring Git's test suite to reduce Perl dependencies. It focuses on character translation helpers in `t/test-lib-functions.sh`.

The patch converts three Perl-based character translation functions (`lf_to_nul`, `nul_to_q`, and `q_to_nul`) to use `tr(1)` instead. These functions handle linefeed-to-NUL conversions and NUL-to-'Q' substitutions used in various tests. The author notes that while NUL handling in `tr` had historical platform inconsistencies, POSIX now mandates correct NUL processing.

The change is straightforward, replacing each Perl one-liner with an equivalent `tr` command while maintaining identical functionality. This allows affected tests to pass when Perl is unavailable, continuing the series' goal of making the test suite more portable. The patch follows the established pattern of identifying Perl dependencies and replacing them with shell equivalents where possible.

- Modified functions: `lf_to_nul`, `nul_to_q`, `q_to_nul`
