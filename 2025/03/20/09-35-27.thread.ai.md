Patrick Steinhardt's 20-part series to eliminate Perl dependencies in Git's test suite continues with part 7/20, building on the prerequisite infrastructure from part 6/20. The series aims to make Perl optional for 97% of tests (30342/31358 tests), requiring it only for Gitweb and netrc helper. Current state includes:

- Parts 2/20-6/20 established core infrastructure including the `PERL_TEST_HELPERS` prerequisite to distinguish between tests needing Perl for execution versus testing aids
- New part 7/20 audits and refines prerequisites across four test files, introducing finer-grained dependency tracking
- Key changes in this patch:
  * Removes obsolete `PERL` prerequisites from delayed checkout progress tests (t0021) and interactive commit tests (t7501, t0090)
  * Introduces `PERL_IPC_OPEN2` lazy prerequisite for tests requiring IPC::Open2 module (t1006)
  * Fixes variable naming conflict in t1006 by renaming script variable to `perl_script`
- Maintains series' behavior-preserving approach while improving dependency documentation
- All technical feedback from Phillip Wood and Eric Sunshine on prior parts has been addressed

Technical achievements expanded:
- Environment variable filtering via sed negative matching
- Character translation using POSIX-compliant `tr`
- Byte copying with `dd` proper byte counting
- Symlink reading moved to C via `test-tool path-utils`
- Chain linter modified to degrade gracefully without Perl
- Prerequisite system now includes both `PERL_TEST_HELPERS` and module-specific `PERL_IPC_OPEN2`
- All changes preserve test behavior while removing or clarifying dependencies

The series continues with strong consensus, with part 7 demonstrating the prerequisite system's flexibility by handling both interpreter availability and specific module requirements. The careful prerequisite cleanup in this patch provides a model for the remaining 13 patches in the series, maintaining the established pattern of replacing Perl with either standard Unix tools or C implementations in test-tool. The explicit module-level dependency tracking in `PERL_IPC_OPEN2` shows the series' attention to precise test requirements as the Perl removal progresses.
