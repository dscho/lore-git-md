This is part 17/20 of the series to make Perl optional in Git's test suite, focusing on refactoring test helper functions. The patch converts the `generate_random_characters()` helper in t0021-conversion.sh from Perl to shell utilities.

The function generates random lowercase letters by:
1. Using `test-tool genrandom` to produce an infinite stream of random data
2. Filtering to 'a-z' range via `tr -dc`
3. Copying exactly N bytes with the existing `test_copy_bytes` helper

This change allows removing the PERL_TEST_HELPERS prerequisite from three test cases that use this helper to verify process filter behavior. The conversion follows the series' established pattern of replacing Perl with equivalent shell/C utilities while maintaining test coverage. The patch is straightforward and maintains the same test behavior, just with different implementation details under the hood.
