Performance optimization in Taylor Blau's incremental MIDX bitmap series (v5 11/14) introducing a new EWAH bitmap iterator for cross-layer operations. This patch adds `struct ewah_or_iterator` to efficiently OR together multiple EWAH bitmaps from different MIDX layers without decompressing them fully, addressing a key performance bottleneck in reachability traversals.

The implementation provides three main functions: initialization with an array of parent bitmaps (`ewah_or_iterator_init`), iteration that ORs results from all layers (`ewah_or_iterator_next`), and cleanup (`ewah_or_iterator_release`). The approach was chosen over alternatives like full decompression (memory-heavy) or recursive traversal (inefficient for sparse bitmaps) to maintain performance while minimizing code changes.

Key technical details:
- New `struct ewah_or_iterator` containing an array of `ewah_iterator` structs and count
- Iteration performs bitwise combination of all active iterators
- Memory management via `ALLOC_ARRAY` for iterator storage
- Maintains EWAH compression benefits while spanning layers
- Directly supports the series' cross-layer bitmap operations pattern

This foundational change enables efficient type-level bitmap operations across MIDX layers while preserving the series' design principles of backward compatibility impact and consistent resource management. The implementation avoids intrusive refactoring of existing bitmap traversal code while solving the performance issues identified in earlier approaches.
