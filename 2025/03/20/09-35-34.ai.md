This is part 7 of a 20-part series refactoring Git's test suite to reduce Perl dependencies. The patch focuses on updating test prerequisites to properly reflect their actual Perl requirements.

The patch audits and updates test prerequisites in four test files (t0021, t0090, t1006, t7501), addressing three categories of Perl usage: tests that no longer need PERL at all, tests that should use the new PERL_TEST_HELPERS marker instead, and one special case in t1006 that needs IPC::Open2 Perl module detection. The t1006 change is particularly notable as it introduces a new PERL_IPC_OPEN2 prerequisite and renames a conflicting variable ('script' to 'perl_script') to avoid clashes with test infrastructure.

The changes are straightforward mechanical updates that maintain test functionality while better representing actual dependencies. The patch follows the series' pattern of carefully distinguishing between core Perl requirements (PERL) and test-specific Perl needs (PERL_TEST_HELPERS or other module checks). This continues the effort to make the test suite more portable by clearly identifying and isolating remaining Perl dependencies.
