This is a build system patch in the ongoing series to make Perl optional for Git's test suite. It updates the Meson build configuration to no longer require Perl just for running tests, reflecting changes from previous patches that have made the test suite work without Perl.

The change is straightforward - it removes `get_option('tests')` from the conditions that trigger a Perl requirement in `meson.build`. Perl is still be required for Gitweb and the netrc' credential helper, but tests can now run without it. This aligns with the series' goal of making 97% of tests runnable without Perl, with only Perl-dependent tests being marked via the PERL_TEST_HELPERS prerequisite introduced earlier.

The patch is a natural progression of the series, following the actual test suite changes that made Perl optional. It's a small but meaningful change that completes the build system side of this capability. The commit message clearly explains the context and motivation, linking it to the broader effort.
