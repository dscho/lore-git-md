**Git p4 error message encoding fix** - Patch addresses `git p4` failure when processing non-UTF-8 Perforce error messages by extending the existing metadata transcoding framework. The solution introduces a `MetadataTranscoder` class to consolidate encoding handling, applying the same configurable fallback strategy (`git-p4.metadataDecodingStrategy`/`git-p4.metadataFallbackEncoding`) used for metadata to error messages as well. Key changes include refactoring transcoding logic from `metadata_stream_to_writable_bytes()`, adding error-specific decoding that respects existing configs, and including Python 3-specific test verification (`t9837-git-p4-error-encoding.sh`). The implementation maintains Python 2/3 compatibility through careful byte handling and enhances verbose error diagnostics. No new configuration is introduced; the change leverages existing options to cover error cases consistently with metadata handling. Test coverage targets the specific failure scenario though limited to Python 3 due to Unicode handling differences.
