This is a technical patch in Taylor Blau's incremental MIDX bitmap series, specifically modifying how pack lookups work across MIDX layers. The change teaches `show_objects_for_type()` to properly handle object lookups when the requested pack exists in an earlier MIDX layer than the current bitmap's layer.

The patch replaces a direct array access to `bitmap_git->midx->packs` with a call to `nth_midxed_pack()`, which can traverse MIDX layers to find the correct pack. This is necessary because the series introduces layered MIDX bitmaps where objects may be stored in packs from different MIDX generations.

While small (just a one-line change), this is a key piece of plumbing for the larger feature that enables efficient bitmap operations across MIDX layers. The change maintains backward compatibility when no base MIDX exists, and fits naturally into the series' approach of incrementally updating functions to handle the layered bitmap case.
