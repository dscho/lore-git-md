This is a bugfix for `git p4` handling of non-UTF-8 Perforce error messages. Nikolay Shustov follows up on their earlier patch (submitted via GitGitGadget) that addresses cases where `git p4` fails to decode Perforce error messages containing high-bit characters. The solution refactors the existing metadata transcoding logic into a new `MetadataTranscoder` class and applies the same configurable fallback strategy (via `git-p4.metadataDecodingStrategy` and `git-p4.metadataFallbackEncoding`) to error message handling.

The patch appears well-considered, maintaining Python 2/3 compatibility while adding Python 3-specific test coverage. The changes are focused and the commit message clearly explains both the problem and solution. The implementation builds on existing configuration options rather than introducing new ones, which suggests good architectural alignment.
