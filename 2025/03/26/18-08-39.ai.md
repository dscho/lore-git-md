This is a brief follow-up in the incremental MIDX bitmaps series, specifically addressing naming feedback on a key bitmap function.

Jeff King confirms Taylor Blau's renaming of `bitmap_non_extended_bits` to the clearer `bitmap_num_objects_total()` in response to earlier review feedback. The change helps distinguish this function from the similarly-named `bitmap_num_objects()`, where the former counts objects across all MIDX layers while the latter counts only in the current layer. This naming clarification was one of several documentation improvements requested by Elijah Newren in previous rounds of review.

The email serves as final confirmation that this particular piece of feedback has been satisfactorily addressed in the v5 submission. No new technical discussion or changes are introduced - this is purely an acknowledgement that the naming improvement resolves the earlier concern. The thread context shows this was part of a comprehensive set of reviewer feedback that has now all been incorporated into the series.
