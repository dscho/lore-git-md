[What's Cooking in git.git - June 2024]

Junio C Hamano provides a comprehensive status update on Git development progress, categorizing work into merged changes, new topics, and ongoing efforts. The master branch now includes various fixes and improvements while new topics introduce configurable loose object batch sizes, build system changes, and Windows permission updates. Ongoing work includes path-walk delta compression, non-transactional batch ref updates, the_repository removal, and incremental MIDX bitmaps. 

The incremental MIDX bitmaps feature has progressed through Taylor Blau's v5 series, implementing performance optimizations for multi-pack indexes with 14 commits adding bitmap layer tracking, EWAH iterator functionality, and pack-reuse support in pack-bitmap.c. Both Elijah Newren and Jeff King have now confirmed that all their feedback from v4 has been addressed in v5, with no new issues raised. Jeff King's latest review marks the completion of review for this significant performance optimization that has undergone multiple iterations (v1-v5). The changes maintain backward compatibility while improving efficiency for repositories using multi-pack indexes with bitmaps, making the series ready for merging pending any last-minute comments. 

Separately, the `ib/diff-S-G-with-longhand` series by Illia Bobyr adds long-form options (`--patch-grep` and `--patch-modifies`) as alternatives to `-G` and `-S` diff options. While technically reviewed and deemed "mostly good" by Junio, the series now faces procedural hurdles as D. Ben Knoble seeks to help move it forward but raises concerns about intellectual property and licensing due to missing sign-offs from the author. The technical implementation (touching diff.c, documentation, completion scripts, and tests) is not in question, but the contribution mechanics need resolution before proceeding. Knoble proposes splitting cleanups from feature additions but seeks guidance on proper procedure when assisting with another author's work.

Other ongoing efforts continue advancing core refactorings like the_repository removal (ps/object-wo-the-repository) alongside systematic cleanups and testing improvements across the codebase. The update shows steady progress on both performance optimizations and foundational code quality work.
