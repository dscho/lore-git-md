This is a clarification in the ongoing Python version selection discussion for git-p4 builds. Todd Zullinger responds to Nikolay Shustov's retraction of an earlier over-engineered solution, pointing out a potential confusion between PYTHON_PATH (used by Git's build system to locate the Python executable) and PYTHONPATH (Python's module search path). 

The email reinforces the thread's consensus that system-level Python configuration is the right approach, using Fedora's packaging as an example where setting PYTHON_PATH to python3 worked smoothly after their Python2 deprecation. Todd suggests any remaining NonStop-specific issues would be better addressed with the OS maintainers rather than requiring Git-side changes.

This continues the thread's trajectory toward minimal Git involvement in Python configuration, with the practical example from Fedora's packaging providing additional validation of the simple PYTHON_PATH approach. The tone is collegial while gently correcting the technical distinction between the two similarly-named variables.
