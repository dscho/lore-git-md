This is a brief follow-up in the Python version selection discussion, where Nikolay Shustov acknowledges a terminology mix-up between PYTHON_PATH (build-time Python executable selection) and PYTHONPATH (runtime module path). The email serves as a mea culpa after Todd Zullinger clarified the distinction, noting that Fedora's packaging successfully used PYTHON_PATH to switch between Python versions. The exchange reinforces the thread's resolution that Python environment management belongs at the system level, with Git only needing to handle git-p4's Python executable selection in special cases. The thread appears to reach its natural conclusion with this clarification.
