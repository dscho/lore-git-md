Performance optimization for incremental MIDX bitmaps. This is a follow-up email in the ongoing discussion about Taylor Blau's series to implement incremental updates for multi-pack index bitmaps. The series (14 commits) adds support for tracking bitmap layers, implements EWAH iterators, and enables pack-bitmap operations to work with incremental MIDXs.

Jeff King confirms that his earlier feedback on v4 of the series has been addressed in v5, joining Elijah Newren in approving the changes. With both reviewers satisfied, this performance optimization appears ready for merging. The changes will allow Git to update MIDX bitmaps incrementally rather than rebuilding them from scratch, which should significantly improve performance for repositories using multi-pack indexes.

The email doesn't raise any new concerns, suggesting this feature is likely to be merged soon unless other maintainers have final comments. This represents an important optimization for large repositories that rely on MIDX bitmaps for fast operations like `git rev-list` and other history traversals.
