Performance optimization for pathspec handling in the `git-blame-tree` series. This patch from Jeff King enables automatic creation of pathspec tries (O(log n) lookup structures) when processing simple pathspecs without wildcards. The trie is embedded directly in the pathspec struct to minimize disruption to existing callers.

The change builds on earlier infrastructure work, now making the trie a standard part of pathspec processing rather than requiring explicit construction. The implementation handles memory management through new `pathspec_trie_clear()` and integrates with existing pathspec lifecycle functions like `parse_pathspec()` and `copy_pathspec()`.

This appears to be a well-considered optimization that maintains backward compatibility while preparing for future use by pathspec subsystem consumers. The patch is focused and clean, with corresponding test updates showing the expected behavior. As part of the larger blame-tree effort, this helps optimize one of the key components needed for efficient tree-level blame operations.
