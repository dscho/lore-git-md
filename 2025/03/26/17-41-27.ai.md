This is a build system patch in the final stages of the comma operator refactoring series. Jeff King (peff) reviews Johannes Schindelin's fix for compiler detection in environments where CUDA is installed alongside Clang. The issue occurs when `clang -v` outputs multiple lines containing "version", causing the `detect-compiler` script to fail. The solution uses `sed -n '/pattern/{p;q}'` to only process the first matching line rather than all matches.

Key technical details:
- The fix modifies `get_version_line()` in the compiler detection script
- Original approach used `grep ' version '` which matched multiple lines
- New solution uses POSIX-compliant `sed` to exit after first match
- Jeff considers but rejects `grep -m1` due to non-POSIX compliance
- This completes the build system integration for the series
