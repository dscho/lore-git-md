This is a review comment on a refactoring patch in Martin Ågren's pretty-format parsing series.

Jeff King (Peff) responds to Martin's patch 2/8, which simplifies the handling of color specifiers ("%C(auto,...)" and "%C(always,...)") in the pretty-format code. The patch reduces code duplication by having the "auto" case fall through to the default behavior, rather than duplicating the same code block.

Peff agrees with the approach, noting that while the duplicated code wasn't extremely long, the simplification makes the logic clearer. He specifically endorses Martin's decision not to further "golf" the code into an even more compact form, as that would make the code harder to extend if new specifiers are added later.

This is a straightforward approval with no requested changes, showing consensus on the refactoring approach. The exchange demonstrates the careful balance the series is striking between code cleanliness and maintainability.
