Subject: Security fix for IMAP SSL certificate verification in imap-send

Core problem: The imap-send code was relying on implicit certificate verification through OpenSSL's SSL_VERIFY_PEER flag rather than explicitly checking the verification result, creating a security concern despite technically correct behavior.

Current status: Patch v1 adds explicit SSL_get_verify_result() check after obtaining peer certificate to make verification robust and explicit while maintaining existing hostname verification via verify_hostname().

Key technical details: Modifies ssl_socket_connect() in imap-send.c to check for X509_V_OK verification result. Change is defensive programming addressing both security risks and static analyzer false positives. OpenSSL version considerations noted (referencing 1.1.1 docs).
