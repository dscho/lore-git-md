Refactoring patch in the Perl-optional test suite effort. This is a follow-up to Eric Sunshine's review of patch 15/20 in the series, which converts the `name_from_description()` test helper from Perl to sed/tr. Patrick Steinhardt acknowledges Eric's suggestion to use sed's `y//` function for case conversion instead of a separate `tr` invocation, agreeing to make the change.

The patch originally replaced Perl string processing with a combination of sed and tr commands to eliminate a Perl dependency in test helpers. The exchange shows the careful attention being paid to both functional correctness and implementation cleanliness in this large-scale test modernization effort. 

This minor optimization doesn't affect the core functionality - the helper still converts descriptions to lowercase names with hyphens - but streamlines the implementation as suggested by reviewer feedback. The thread continues to demonstrate the collaborative refinement of this important test infrastructure work.
