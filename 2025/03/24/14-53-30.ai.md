Patch 2/2 implements proper SMTP status code parsing, distinguishing temporary (4xx) and permanent (5xx) errors while handling edge cases like undefined results or missing status codes.

- Uses regex patterns (`/^(\d{3})/` and `/\b(\d{3})\b/`) for status code extraction
- Maintains boolean return contract while adding detailed warning messages
- Treats unrecognized codes as transient (1 return) per RFC guidance
- All changes contained within `smtp_auth_maybe` subroutine
