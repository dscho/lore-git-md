This is a review comment on patch 11/20 in the ongoing series to make Git's test suite Perl-independent. Phillip Wood points out a minor stylistic issue with how file redirections are handled in the Perl-to-sed conversions.

The original patch by Patrick Steinhardt converted several test scripts from using Perl's substitution operator to equivalent sed commands, removing PERL_TEST_HELPERS dependencies. Phillip notes that the sed invocations use `<file` redirection when they could more naturally take the filename as an argument directly (`sed -e ... "$1"`). This appears in multiple converted functions and test cases.

The observation is constructive but not blocking - the changes work as is, just with slightly unconventional shell syntax. The thread context shows this is part of a carefully reviewed effort to maintain test behavior while eliminating Perl dependencies, with Eric Sunshine providing detailed feedback on earlier patches. Phillip's comment continues this pattern of meticulous attention to implementation details.
