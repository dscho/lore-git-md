Performance test addition for the path-walk delta compression feature. This patch adds benchmark tests comparing the new `--path-walk` option against existing name-hash versions (1 and 2) across three repository types (Git, FluentUI, and Linux kernel) and three pack types (thin, big, and shallow).

Key technical details:
- Tests measure both time and resulting pack size
- Uses new `test_all_with_args` helper function to avoid duplication
- Includes repack tests for name-hash versions (but not path-walk yet)
- Shows path-walk performs particularly well in collision-heavy repos (FluentUI)
- Current implementation shows mixed results - sometimes faster, sometimes slower than name-hash-v2
- Shallow pack tests currently don't exercise path-walk logic (API limitations noted)

The performance data reveals:
- In the Git repo, path-walk shows comparable sizes to name-hash-v2 but slightly slower times
- In FluentUI (collision-heavy), path-walk shows significant improvements (18.4K vs 1.2M for thin packs)
- Linux kernel results are mixed, with path-walk sometimes better, sometimes worse than alternatives

The patch is part of the larger path-walk delta compression series (position 4/13) and these benchmarks will help evaluate the feature's real-world impact. The tests are thorough but currently limited by some unimplemented path-walk functionality (shallow packs, threading). Future work could expand these tests as the feature matures.
