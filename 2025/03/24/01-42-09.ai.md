This is the final patch in a 3-part documentation series modernizing Git's MyFirstContribution tutorial, specifically focusing on updating config API usage to be repository-aware as part of the `the_repository` removal effort.

The patch converts `git_config()` calls to `repo_config()` variants throughout the tutorial, demonstrating modern repository-aware configuration handling. Key technical changes include:
- Adding `repository.h` include where needed
- Using `repo_config_get_string_tmp()` as the example API
- Maintaining all educational aspects while updating code patterns
- 39 insertions and 18 deletions in Documentation/MyFirstContribution.adoc

The author Jayatheerth K responds to maintainer Junio C Hamano's feedback about using C++-style `//` comments in the tutorial examples, agreeing to remove them despite their pedagogical value since they violate Git's style guidelines. This was the last outstanding style concern for the series.

The patch remains technically unchanged from its previous submission, having already completed the core API modernization work. With this comment style adjustment, the series appears ready for final documentation expert review, having addressed all substantive feedback while maintaining the tutorial's educational value. The changes align with the broader `the_repository` removal effort and current Git development practices.
