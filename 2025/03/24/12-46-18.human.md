This is a test infrastructure patch in a series making Perl optional for Git's test suite. It's a follow-up to Eric Sunshine's review of patch 6/20, which introduced a new `PERL_TEST_HELPERS` prerequisite for tests requiring Perl. 

Eric spotted a copy-paste error where the skip message for binary apply tests incorrectly referenced "ignores tests" instead. Patrick Steinhardt quickly acknowledges this as a good catch in his reply. 

The exchange shows careful attention to detail in this large refactoring effort, where maintaining clear test output messages is important for future debugging. This minor fix will help ensure accurate test output when Perl is unavailable, though it doesn't affect the core functionality of the test suite modernization.
