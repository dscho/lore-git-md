This is a test infrastructure patch for the ongoing path-walk delta compression series. It introduces `GIT_TEST_PACK_PATH_WALK` to enable path-walk behavior by default in tests, while carefully documenting and working around test cases where this would cause failures or inconsistencies.

The patch modifies `pack-objects.c` to make `path_walk` tri-state (-1/0/1) and adds logic to check the new environment variable when no explicit `--path-walk`/`--no-path-walk` is given. It then updates several test scripts that would be affected by this change:

- Tests involving partial clones or missing boundary objects (t0411, t5306) disable path-walk since it can't handle incomplete repos
- Bitmap comparison tests (t5310) explicitly use `--no-path-walk` in both cases to ensure fair comparison
- Delta chain tests (t5316) avoid path-walk to maintain predictable delta selection
- Multi-pack reuse test (t5332) disables path-walk since it doesn't respect preferred packs
- A temporary workaround is added for t5530 where path-walk currently produces a different error message
- Submodule tests (t7406) disable path-walk to avoid warning messages with `--depth`

The changes demonstrate careful consideration of how the new path-walk behavior interacts with existing test expectations, with clear explanations for each adjustment. The patch maintains test coverage while allowing the new feature to be exercised by default in most cases.
