Bug report regarding mergetool.vimdiff.layout behavior discrepancy. The reporter (kawarimidoll) identifies a mismatch between the documented and actual behavior of the `@REMOTE` buffer in vimdiff merge conflict resolution. 

The documentation suggests that changes made to buffers marked with `@` should be reflected in the final merged file, with `@MERGED` as the fallback. However, in practice, while `@LOCAL` and `@MERGED` work as expected, `@BASE` and `@REMOTE` do not propagate changes to the output file. The reporter provides clear reproduction steps and has uploaded a video demonstration to a GitHub Gist.

This appears to be a genuine documentation/implementation mismatch in the vimdiff backend of `git mergetool`. The report is well-structured with clear expected/actual behavior descriptions and system information (Git 2.48.1 on Darwin/ARM64). The issue affects the merge conflict resolution workflow and could mislead users relying on the documented behavior. The reporter is new to Git contribution but has provided thorough details including a visual reproduction case.
