This is a status update on the reftable library decoupling effort, part of the ongoing work to make the reftable code more standalone.

Patrick Steinhardt follows up on Junio Hamano's "What's cooking" report regarding his 18-commit series that removes Git-specific dependencies from the reftable library. The changes include replacing Git utilities like `BUG()`, `SWAP()`, and `xmmap()` with reftable-specific implementations, making the code more portable for external users.

The series had been waiting for Acks, particularly for Windows-specific changes, but Patrick notes that Johannes Schindelin has given approval to proceed. This suggests the technical review is complete and the changes are ready for integration. The work is foundational for other reftable improvements, including a Windows-specific unlink fix that builds upon it. 

The patch series represents significant plumbing work to disentangle the reftable implementation from Git's core utilities, though the changes shouldn't affect end-user functionality. The maintainer appears ready to merge it into the integration branches.
