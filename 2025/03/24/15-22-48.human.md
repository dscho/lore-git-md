This is a feature patch adding an 'edge_aggressive' option to the path-walk API, part of the ongoing series introducing path-based delta compression.

The patch adds a new mode to the path-walk infrastructure that enables more thorough marking of UNINTERESTING objects during revision walks, particularly useful for shallow clones. This matches behavior from the revision API's `--objects-edge-aggressive` option, ensuring boundary objects are properly marked when both `--shallow` and `--path-walk` options are used together in `git pack-objects`.

The implementation adds the new option to the path-walk API struct and plumbing, with corresponding test coverage showing it correctly marks trees and blobs from UNINTERESTING commits. Documentation is updated to explain the new option's purpose and relationship to the revision API's similar feature.

As part of the larger path-walk delta compression series, this helps ensure consistent behavior when path-walk is combined with other pack-objects features. The patch appears well-integrated with the existing codebase, maintaining the series' focus on improving delta compression for specific repository types while adding necessary functionality for shallow clone scenarios.
