This is part of the ongoing test refactoring series to make Perl optional in Git's test suite. Phillip Wood provides feedback on Patrick Steinhardt's patch 13/20, which converts Perl-based textconv scripts to shell equivalents.

Phillip notes that while the simplified shell version (using `tr`) handles the current test cases, it's less flexible than the original Perl script which could process any binary data. He suggests using `test-tool hexdump` as an alternative but acknowledges it may not be worth a re-roll just for this. The patch had already updated binary diff output assertions from dissimilarity percentages to specific hex patterns ("3d 0a 00/01") to match the shell implementation's output.

The exchange shows careful consideration of test behavior preservation versus implementation simplicity, with Phillip giving overall approval to the series while flagging a minor tradeoff in test robustness.
