Performance optimization patch adding threading to path-based delta compression in pack-objects.

This patch introduces threaded execution for the path-based delta compression algorithm in `git pack-objects`, part of the ongoing `--path-walk` feature series. The changes parallelize the compression work across multiple threads, significantly improving performance while maintaining the same compression ratios.

Key improvements shown in the performance tests:
- Repack time reduced by ~60% in Git repository tests (107s → 45s)
- Similar gains seen across other test repositories (FluentUI, Node.js, Linux kernel)
- Compression sizes remain identical to single-threaded path-walk
- Makes path-walk more competitive with name-hash-v2 in runtime while keeping its superior compression

The implementation:
- Adds thread-safe work distribution for path-based compression
- Uses work-stealing to balance load between threads
- Maintains progress reporting during threaded operation
- Preserves all existing path-walk compression behavior

This appears to be a well-executed optimization that delivers on the promised performance improvements without compromising the compression quality. The patch includes thorough performance data across multiple repository types, showing consistent gains. The implementation builds on the existing threaded infrastructure in pack-objects while adapting it to the path-walk approach.
