Performance optimization patch adding threading to the path-based delta compression in `git pack-objects`. This is part 11/13 of the series introducing the `--path-walk` option for improved delta compression.

The patch implements a threaded version of the path-walk compression step, adapting the existing `ll_find_deltas()` approach. Key technical changes include:
- Adding a `regions` member to `thread_params` struct to track path-based work sections
- New `threaded_find_deltas_by_path()` worker function
- Work-stealing load balancing between threads
- Updated progress reporting for threaded operation

Performance measurements show significant speedups from threading, particularly for repacks:
- Git repo repack time drops from 142.50s to 45.41s (~60% reduction)
- FluentUI repo time improves from 81.29s to 28.16s
- Node.js repo goes from 208.10s to 75.10s
- Linux kernel repack time drops from 1562.36s to 559.00s

The patch maintains the same compression ratios while dramatically reducing runtime, making path-walk more competitive with name-hash approaches. The implementation handles work distribution and load balancing while preserving the two-phase compression strategy (intra-path then cross-path) that characterizes the path-walk approach.
