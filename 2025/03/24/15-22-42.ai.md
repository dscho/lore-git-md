This is a test patch in the ongoing path-walk delta compression series, specifically adding shallow push verification tests.

The patch adds two new test cases to t5538-push-shallow.sh to verify delta behavior during shallow pushes. The first test confirms proper object counting when pushing a new commit from a shallow clone. The second and more substantial test creates a scenario where delta base usage makes a measurable difference (kilobyte vs bytes in the progress output), allowing verification that delta bases are being properly found and used during shallow pushes.

Key technical details include:
- Tests use GIT_PROGRESS_DELAY=0 for immediate progress output
- Second test uses GIT_TRACE2_PERF for performance measurement
- Verifies delta behavior by checking for "bytes" vs "KiB" in progress messages
- Tests shallow clone/push scenarios that are relevant to the path-walk delta compression work
- Adds to existing shallow push test infrastructure in t5538

The tests are well-constructed to catch regressions in delta base handling during shallow pushes, which is important for the path-walk feature's edge cases. The patch fits into the larger series by providing test coverage for scenarios that might be affected by the new path-based delta compression strategy.
