Refactoring effort to decouple reftable library from Git internals. This is part of Patrick Steinhardt's ongoing work to make the reftable implementation more self-contained and portable for external users. The 18-commit series systematically removes dependencies on Git-specific utilities from the reftable code, replacing them with standalone implementations. Key changes include:

- Splitting out POSIX-emulation functionality from git-compat-util.h
- Introducing reftable-specific replacements for common utilities (memory allocation, endian conversion, random number generation)
- Removing BUG() usage in favor of proper error handling
- Replacing Git I/O helpers (xmmap, read_in_full) with reftable-specific versions

The branch has been waiting for Windows-specific reviews, but Johannes Schindelin has now given approval to proceed. The changes are preparatory work for ps/reftable-windows-unlink-fix and align with the broader goal of making reftable usable outside Git's codebase. The series appears ready for integration with no outstanding objections.
