Feature patch with minor style fixes. This is part of the ongoing effort to add syntax highlighting support for gitconfig/INI files in Git's diff output.

Lucas Seiki Oshiro submits version 2 of their patch adding a builtin userdiff driver for gitconfig files. The changes from v1 are minor: they've removed quoted text from the commit message in favor of referencing documentation, and added missing newlines in test files. The patch still adds the same core functionality - recognizing gitconfig sections and subsections as function headers in diffs.

Junio Hamano notes some whitespace issues in the patch application (spaces where tabs should be used for indentation), though these appear to be minor formatting problems rather than functional concerns. The patch continues to use the same regex patterns discussed in the thread: one for section headers and another for word boundaries.

This iteration doesn't yet address Johannes Sixt's broader suggestions from the thread about generalizing to "ini-file" or expanding test coverage, but appears to be a straightforward update to address prior documentation and formatting feedback. The patch remains focused on gitconfig-specific syntax while the thread continues to discuss whether a more generic INI file approach might be preferable.
