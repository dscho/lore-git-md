Performance optimization patch adding edge_aggressive mode to path-walk API, part of the ongoing path-walk delta compression series. This is patch 12/13 in v2 of the series.

The patch introduces a new `edge_aggressive` option to the path-walk API that enables more thorough boundary walking when marking UNINTERESTING objects, particularly useful for shallow clones. This matches the behavior of `--objects-edge-aggressive` in the revision API. The implementation:

1. Adds the new flag to `struct path_walk_info`
2. Sets the corresponding `edge_hint_aggressive` flag in the revision walk preparation
3. Includes test coverage verifying the behavior with pruning
4. Documents the option in the API docs

Key technical details:
- New `edge_aggressive` field in `path_walk_info` struct
- Integration with `mark_edges_uninteresting()` via `edge_hint_aggressive`
- New test case in t6601-path-walk.sh demonstrating the behavior
- API documentation update explaining the option's purpose

This builds on the series' goal of improving delta compression by ensuring proper handling of UNINTERESTING objects when path-walk is used with shallow clones. The implementation is straightforward and well-tested, with clear documentation of both the technical behavior and its relationship to existing revision walk functionality.
