This is the final patch in the path-walk delta compression series, addressing shallow clone compatibility. The patch removes the previous restriction that prevented using `--path-walk` with `--shallow`, now that the underlying path-walk API properly handles shallow cases through the `edge_aggressive` mode introduced in patch 12/13.

The key change is removing the warning/disable logic for `--shallow` with `--path-walk` and properly setting the `edge_aggressive` flag in the path-walk info struct when operating in shallow mode. This builds on the new test coverage added in t5538-push-shallow.sh to verify the behavior works correctly. The patch also fixes a variable scope issue by moving the `shallow` flag to file scope where it can be accessed by the path-walk setup code.

The implementation confirms that shallow commits can be properly processed by the path-walk API when the edge_aggressive mode is enabled, allowing the two features to work together. This completes the series' goal of making path-based delta compression available across all major pack-objects use cases while maintaining compatibility with existing features.
