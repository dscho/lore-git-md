This is a feature patch adding `--path-walk` support to `git repack`, part of the ongoing path-based delta compression series. The patch exposes the pack-objects path-walk functionality through repack's interface and extends performance tests to measure its impact.

Key technical details:
- Adds `--path-walk` option to `git repack` that gets passed through to pack-objects
- Updates repack documentation to explain the option and its benefits/limitations
- Extends p5313 performance tests to include path-walk measurements
- Includes performance data from multiple repositories (FluentUI, Git, Node.js, Linux kernel) showing path-walk's compression benefits (18.4K vs 1.2M for thin packs in collision-heavy repos) but with higher runtime costs
- Notes current limitations: sequential operation (future threading planned), incompatibility with delta-islands/filter options
- Shows path-walk can provide modest size improvements even in repos without heavy name-hash collisions
- Maintains backward compatibility by keeping name-hash-v1 for second delta pass

The patch builds on previous work in the series by making the path-walk functionality available through repack while documenting its tradeoffs. Performance data shows the most significant benefits in repositories with filename hash collisions, though even standard repositories see some size reduction at the cost of increased runtime.
