Performance test addition for the path-walk delta compression feature.

This patch adds performance tests for the new `--path-walk` option in `git pack-objects`, which is part of a larger series improving delta compression. The tests compare three approaches: the original name-hash (v1), the newer name-hash-v2, and the new path-walk method. Results are measured for three pack types (thin, big, and shallow) across time and size metrics.

The data shows path-walk provides significant benefits in collision-heavy repositories like microsoft/fluentui (18.4K vs 1.2M for thin packs), while being competitive in more balanced repositories like Git and Linux. The Linux kernel results show path-walk maintaining similar performance to name-hash-v2 (158.5M vs 159.1M for big packs), suggesting the feature's value depends on repository characteristics.

The test infrastructure is cleanly refactored to avoid duplication between the different hash versions and path-walk cases. The patch maintains the series' focus on measurable improvements while acknowledging current limitations (no threading yet for path-walk, disabled shallow pack logic). This provides a solid foundation for evaluating the feature's real-world impact as the implementation evolves.
