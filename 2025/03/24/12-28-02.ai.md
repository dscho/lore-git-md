This is a security-focused bugfix for the IMAP SSL certificate verification in `imap-send`. The patch addresses a potential security issue where the code was relying on implicit certificate verification through OpenSSL's `SSL_VERIFY_PEER` flag rather than explicitly checking the verification result.

The change adds an explicit check for `SSL_get_verify_result()` after obtaining the peer certificate, ensuring the certificate is properly validated before proceeding. While the author notes that the existing code was technically correct due to OpenSSL's internal behavior (with `SSL_VERIFY_PEER` already performing verification), this change makes the verification more robust and explicit.

- Adds check for `X509_V_OK` verification result
- Maintains existing hostname verification via `verify_hostname()`

- OpenSSL version considerations are relevant (specifically referencing 1.1.1 docs)
