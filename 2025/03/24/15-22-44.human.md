This is a configuration patch in the ongoing path-walk delta compression series. It introduces a new `pack.usePathWalk` config option to enable the path-walk delta compression strategy by default, particularly for client-side operations like push and repack.

The patch makes path-walk available through two configuration paths: explicitly via `pack.usePathWalk`, and implicitly through the existing `feature.experimental` and `feature.manyFiles` configs. The implementation is careful to avoid enabling it on servers where it would interfere with bitmap-based operations. The documentation explains both the potential benefits (smaller packs in collision-heavy repos) and tradeoffs (disabled bitmaps).

This appears to be a well-considered addition to the path-walk feature, providing users with flexible control over when to use the new delta strategy while maintaining safety through sensible defaults. The patch follows the established pattern of experimental features by gating the behavior behind feature flags and explicit configuration.
