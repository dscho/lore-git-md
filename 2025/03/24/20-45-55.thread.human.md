This thread corrects a long-standing documentation error in the vimdiff merge tool's buffer marking sigil. The original documentation incorrectly showed an asterisk ("*") as the buffer marker, when in fact vimdiff uses an arobase ("@") — a discrepancy dating back to the initial documentation in commit 7b5cf8be18. D. Ben Knoble submitted the fix but initially forgot to include the required Signed-off-by line, which Eric Sunshine pointed out. Knoble quickly acknowledged the oversight with a casual "doh, indeed" and will presumably include the sign-off in the next version. While this exchange resolves the immediate documentation correction, the underlying question about why vimdiff uses "@" as the buffer marker (as opposed to other possible sigils) remains an open topic for future discussion. The patch itself is straightforward — a single-line edit with a note clarifying that "arobase" is the French-origin term for "@".
