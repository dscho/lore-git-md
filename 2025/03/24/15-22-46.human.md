Performance optimization in the path-walk delta compression series.

This patch refactors how `git pack-objects --path-walk` handles delta compression to improve both performance and user experience. The key change separates the path-based object grouping from the actual delta computation, storing intermediate regions for later processing rather than computing deltas inline during the path walk. This creates a clearer progress indicator showing distinct phases and prepares the codebase for future threaded implementation.

The patch introduces a new `packing_region` struct to track path-based object groupings and adds corresponding fields to `packing_data`. The core delta computation is split into two new functions: `find_deltas_for_region` handles compression within a single path region, while `find_deltas_by_region` manages the overall process across all regions with proper progress reporting.

Test updates verify the new progress reporting works as expected and remove a now-unnecessary workaround in t5530 since the error message ordering has stabilized. The changes maintain all existing functionality while making the implementation more maintainable and setting the stage for future parallelization.
