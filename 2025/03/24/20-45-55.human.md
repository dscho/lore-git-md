This is a documentation patch correcting an error in the vimdiff merge tool's documentation. 

The patch fixes a minor but potentially confusing discrepancy where the documentation incorrectly stated that users should mark buffers with an asterisk ("*") when using custom vimdiff layouts, when in fact the code has always expected and used the at-sign ("@") symbol (referred to here by its French name "arobase"). 

The author notes this terminology choice may not be universally standard in English but considers it acceptable. They also mention but deliberately avoid addressing a separate bug report about vimdiff behavior, hoping it will be fixed rather than documented around.

This is a straightforward correction that aligns the docs with the actual implementation. The change is minimal (a single character correction plus clarification of the symbol name) and uncontroversial, though the terminology choice might spark minor discussion about whether to use "at-sign" instead of "arobase" in the docs.
