Documentation patch correcting the vimdiff merge tool's buffer marking sigil.

This is a straightforward documentation fix for Git's vimdiff merge tool configuration. The patch corrects an error in the docs where the buffer marker was incorrectly described as an asterisk ("*") when the actual implementation uses an arobase ("@"). The author notes this discrepancy dates back to the original documentation added in commit 7b5cf8be18.

The change is minimal - a single line edit in Documentation/mergetools/vimdiff.adoc. The author mentions but does not address a related bug report, expressing hope that the underlying issue will be fixed rather than just documented. The patch includes a note about the term "arobase" (the French-origin name for "@") being acceptable but not yet standard in English.
