Documentation modernization completing the conversion of core command man pages to AsciiDoc format. This final patch in the series updates `git-mv.adoc` to match the new style used for `git-reset` and `git-rm` in previous patches.

The changes standardize the formatting of the `git-mv` documentation with:
- A proper synopsis block that automatically styles placeholders and keywords
- Consistent use of `_<placeholder>_` notation for variables
- Backtick-wrapped options and keywords throughout
- Minor wording clarifications in the description text

The patch maintains all existing content while improving presentation, though the author notes a remaining ambiguity in how the rendering engine handles ellipsis notation (used both for repeated options and commit ranges). This follows the mechanical conversion pattern established in the series, with matching updates to the command's help text in `builtin/mv.c` (not shown in the diff).

As with the rest of the series, these are purely presentational changes that don't affect the technical content of the documentation. The work demonstrates careful attention to detail, completing the standardization of these three core commands' documentation with consistent formatting and structure.
