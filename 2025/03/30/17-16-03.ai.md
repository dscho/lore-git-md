Documentation modernization patch continuing the series to standardize command synopses in man pages. This fourth patch updates `git-mv.adoc` to match the pattern established in previous conversions of `git-reset` and `git-rm`, moving the command syntax into the proper SYNOPSIS section and applying consistent formatting.

The changes include:
1. Relocating the command variants from the DESCRIPTION section to SYNOPSIS
2. Standardizing option presentation with backticks (`-v`, `-f`, etc.)
3. Updating the in-code help text in `builtin/mv.c` to match the new documentation format
4. Maintaining the same two forms of the command (single rename vs. multiple sources to directory)

This follows the same mechanical transformation pattern seen in earlier patches, with no additional toolchain adjustments needed beyond the configuration changes made in patch 2. The changes are purely presentational, keeping all technical content identical while improving documentation structure. The patch maintains the series' focus on documentation consistency without introducing any behavioral changes to Git itself.
