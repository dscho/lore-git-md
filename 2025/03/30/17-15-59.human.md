This is a documentation patch series converting several Git command manuals to a new documentation format. The series updates the man pages for `git-reset`, `git-rm`, and `git-mv` to use modern AsciiDoc features that provide better automatic formatting of command synopses and options.

The series also includes a fix for the synopsis analysis logic that supports these formatting improvements.

The patch set appears well-structured, with each command getting its own conversion patch plus one technical fix. The changes are purely presentational - no command behavior is altered - and focus on consistency suggests this is part of a broader documentation modernization effort. The modifications touch both documentation files and the underlying AsciiDoc configuration that supports the new formatting features.
