Documentation patch fixing synopsis formatting in the Git man pages modernization series.

This is the second patch in a 5-part series converting Git command documentation to use modern AsciiDoc features. It specifically addresses an issue where the synopsis formatting logic couldn't properly handle backslashes and asterisks used in `git-rm`'s command syntax. The changes update regular expressions in both the AsciiDoc and Asciidoctor configuration files to correctly format these special symbols when they appear in command synopses.

The patch makes purely technical changes to the documentation toolchain, modifying the pattern matching rules in three configuration files (`asciidoc.conf.in`, `asciidoctor-extensions.rb.in`). The changes are focused and mechanical, following the pattern established in the first patch of the series. There's no impact on the actual content or rendering of the documentation - this just ensures special characters will be formatted consistently with other command syntax elements.

The changes appear well-contained and necessary for the broader documentation effort. The commit message clearly identifies the specific limitation being addressed (backslashes and stars in `git-rm` synopses) and the solution (regex updates). This continues Jean-Noël Avila's ongoing work to modernize Git's documentation infrastructure.
