# Platform compatibility note for test fix

Johannes Sixt points out a Windows compatibility issue in Matt Hunter's test case for the `--left-only`/`--right-only` bugfix. The test currently uses shell process substitution (`<(sort head)`) which doesn't work on Windows platforms. This is a brief but important technical note in the ongoing thread about fixing revision walker behavior with unrelated histories.

The suggested fix is straightforward: replace the process substitution with temporary files, which are universally portable across platforms. This doesn't affect the core logic of the test, which verifies that no commits appear in both filtered lists when comparing unrelated histories. The original patch's correctness fix remains sound, but the test needs this adjustment to work properly on all Git-supported systems.

This is a typical example of the kind of platform-specific considerations that regularly come up in Git development, where tests written on Unix-like systems sometimes need adjustment for Windows compatibility. The exchange is brief and to-the-point, focusing just on the technical issue at hand.
