Documentation patch fixing synopsis formatting in the ongoing manpage modernization series. This second patch in the 5-part series addresses a technical limitation in the AsciiDoc processing logic that prevented proper handling of backslashes and asterisks in command synopses, specifically affecting `git-rm` documentation.

The changes modify regular expressions in three configuration files (`asciidoc.conf.in`, `asciidoctor-extensions.rb.in`) to properly escape backslashes (`\\`) and asterisks (`\*`) when processing command syntax. The patch follows the same mechanical, syntax-only approach as the rest of the series, maintaining all existing functionality while expanding the range of supported special characters. The modifications are narrowly targeted at the documentation rendering pipeline and don't affect Git's runtime behavior.

Key technical changes include adding `\\` and `\*` to character classes in multiple regex patterns across both the DocBook and XHTML11 backend configurations. The Ruby extensions receive parallel updates to handle these characters during inline quote processing. This ensures consistent formatting of command options containing these characters (like `git rm --cached \*.txt`) in the final documentation output.

The patch continues the series' pattern of focused, incremental improvements to the documentation toolchain, building on the first patch's conversion of `git-reset.adoc` to use proper synopsis blocks. While the commit message is brief, the changes appear well-scoped and technically sound for their stated purpose of handling special characters in command syntax.
