Documentation modernization for `git-mv` man page. This is the fourth patch in a series standardizing command documentation, following similar updates to `git-reset` and `git-rm`.

Jean-Noël Avila continues the mechanical conversion of Git man pages to modern AsciiDoc syntax, this time focusing on `git-mv`. The patch moves the command synopsis from the DESCRIPTION section to the proper SYNOPSIS section where it belongs, while maintaining identical content. The changes include listing options explicitly (`-v`, `-f`, `-n`, `-k`) and separating the two invocation forms (single rename vs. multiple sources with directory destination).

A corresponding update to `builtin/mv.c` ensures the command's help output matches the new synopsis format. Like previous patches in the series, this is purely presentational - no behavior changes are introduced, just improved documentation structure and consistency with the project's evolving standards.

The patch follows the established pattern seen in earlier conversions, suggesting it will likely be uncontroversial. The series appears methodical and well-executed, with each patch handling one discrete documentation target while maintaining mechanical consistency across the board.
