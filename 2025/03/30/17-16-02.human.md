Documentation modernization patch for `git-rm` man page, part of a series standardizing command documentation.

This is the third patch in a 5-part series converting Git command documentation to use AsciiDoc's modern features. It updates the `git-rm` man page with several mechanical but important formatting improvements: converting the synopsis to a proper synopsis block (which automatically handles formatting), standardizing placeholder notation with `_<placeholder>_` syntax, and consistently wrapping keywords and options in backticks. The changes are purely presentational - all content remains identical, just better formatted.

The patch follows the same pattern seen in previous conversions (like `git-reset` in patch 1), applying Jean-Noël Avila's established documentation standardization approach. It touches only the `git-rm.adoc` file, with no behavioral changes to Git itself. The formatting updates make the documentation more consistent and machine-processable while improving readability - special syntax like command options now render distinctly from prose, and placeholders are clearly marked.

This continues the series that's methodically working through Git's command documentation. The changes are straightforward and unlikely to be controversial, being purely about presentation.
