Refactoring patch in the partial reference transaction series. This is the fourth patch in Karthik Nayak's 8-part series implementing partial reference transactions, which will eventually enable a new `--allow-partial` flag for `git update-ref`.

The patch extracts the core logic for preparing individual reference updates from `reftable_be_transaction_prepare()` into a new `prepare_single_update()` function. This moves all validation and preparation steps (object ID verification, HEAD reference handling, symref processing) into a single logical block. While this is purely a code reorganization with no functional changes, it serves as important groundwork for the partial transaction support coming in later patches.

The refactoring significantly improves code maintainability by centralizing the update preparation logic.
