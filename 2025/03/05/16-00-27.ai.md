Windows release follow-up acknowledging the Git for Windows 2.49.0-rc1 announcement. Junio Hamano provides a brief thank-you response to Johannes Schindelin's detailed release notes. The original announcement covered significant Windows-specific changes including the deprecation of `git svn`, discontinuation of 32-bit installers (with MinGit support extended until 2029), and updates to bundled dependencies. It also incorporated upstream Git changes like the stabilization of the `--name-hash-version=2` option and the new `git backfill` command. Windows-specific issues addressed include symlink renaming fixes, Cygwin FAST_CWD warnings, and VS Code terminal hangs during `git add -p`. The release includes SHA-256 checksums for various 64-bit/ARM64 packages and transitional 32-bit MinGit builds. This follow-up email serves as formal acknowledgment from the Git maintainer of the Windows release process.
