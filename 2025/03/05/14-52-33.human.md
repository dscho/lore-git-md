This is a release announcement for Git for Windows 2.49.0-rc1, marking both new features and some significant deprecations in the Windows-specific distribution.

The announcement notes two major changes in platform support: the phasing out of `git svn` support due to maintenance challenges and low usage, and the discontinuation of 32-bit installers (though MinGit 32-bit builds will continue until 2029). These changes reflect ongoing efforts to streamline the Windows port's maintenance burden.

The release incorporates upstream Git 2.49.0-rc1 with several notable updates: OpenSSH 9.9.P2 and PCRE2 10.45 dependencies, the promotion of the experimental `--full-name-hash` option to stable status (now `--name-hash-version=2`), and the upstream inclusion of the `git backfill` command with a renamed batch size option.

Three Windows-specific bug fixes address issues ranging from symlink renaming (broken in 2.48.0) to Cygwin warnings on Insider Windows builds and terminal freezes when using `git add -p` from VS Code. The announcement provides SHA-256 checksums for all distribution formats including 64-bit/ARM64 installers, portable versions, and MinGit variants.

This pre-release continues Git for Windows' pattern of closely tracking upstream while managing Windows-specific compatibility concerns, though the deprecation notices may warrant attention from users still relying on 32-bit installations or SVN interoperability.
