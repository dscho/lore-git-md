The Git for Windows 2.49.0-rc1 release has been announced by Johannes Schindelin (Dscho), bringing together upstream Git v2.49.0-rc1 changes with Windows-specific updates. Key changes include the deprecation of `git svn` due to maintenance burden, discontinuation of 32-bit installers (with MinGit support extended until April 2029 as a transitional measure), and updates to bundled dependencies like OpenSSH and PCRE2. The release incorporates upstream improvements such as the stabilization of the `--name-hash-version=2` option and the new `git backfill` command, while also addressing Windows-specific issues including symlink renaming regressions and VS Code terminal hangs during interactive adds.

Git maintainer Junio Hamano has acknowledged the release with a brief thank-you response, confirming the Windows team's work in syncing with upstream while maintaining their platform-specific fixes and policies. The release provides SHA-256 checksums for all 64-bit/ARM64 packages while maintaining limited 32-bit MinGit support for compatibility during the transition period.
