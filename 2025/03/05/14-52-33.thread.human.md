This is a release announcement for Git for Windows 2.49.0-rc1, which combines upstream Git v2.49.0-rc1 with Windows-specific updates. Johannes Schindelin (Dscho) announces several significant platform changes, including the planned deprecation of `git svn` support due to maintenance burden and the discontinuation of 32-bit installers (though MinGit will retain 32-bit support until April 2029).

The release incorporates important upstream changes like the stabilization of the `--full-name-hash` option (now `--name-hash-version=2`) and the new `git backfill` command. Windows-specific fixes address a symlink regression from v2.48.0, Cygwin warnings on Insider builds, and terminal hangs in VS Code. The announcement includes SHA-256 checksums for 64-bit/ARM64 installers and portable versions, reflecting Git for Windows' ongoing evolution while maintaining backward compatibility where needed.
