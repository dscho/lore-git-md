CI / build system patch completing a series to align Meson behavior with Makefile for breaking changes.

This is the third and final patch in Patrick Steinhardt's series to make the Meson build system properly handle breaking changes via the `-Dbreaking_changes=true` option. While previous patches addressed compilation flags and binary exclusion, this one focuses on documentation - specifically ensuring the `git-pack-redundant` man page isn't installed when breaking changes are enabled, matching the Makefile behavior.

The change splits the manpage definitions in meson.build, moving `git-pack-redundant.adoc` into a separate `manpages_breaking_changes` dictionary that only gets included when breaking changes are disabled. The patch also updates a documentation sanity check script to properly account for this conditional inclusion.

The implementation is clean and straightforward, completing the series' goal of full build system parity for breaking change scenarios. With this change, both the binary and its documentation will be consistently excluded when breaking changes are enabled. The patch builds on prior work by Karthik Nayak and appears ready for inclusion.
