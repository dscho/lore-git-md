CI/build system patch adding Meson documentation build testing to the Git project's CI pipeline.

This patch extends the existing documentation CI job to include building and verifying documentation generated via Meson, in addition to the current Makefile-based documentation builds. The change comes after a recent incident where Meson documentation breakage went unnoticed (fixed in commit 87eccc3a81d). 

The implementation adds a new `check_docs` helper function that verifies the presence of key documentation files (HTML, XML, manpages) and checks the generator metadata. The script then uses this to test both AsciiDoc and Asciidoctor documentation builds under Meson, mirroring the existing Makefile-based test cases. The Meson builds are configured with `-Ddocs=html,man` and the appropriate backend flag.

The changes are straightforward and maintain consistency with the existing test structure. The patch demonstrates good hygiene by cleaning up build artifacts after verification and reusing the existing artifact checking infrastructure. This fills a clear gap in the CI coverage that could help catch documentation build issues earlier.
