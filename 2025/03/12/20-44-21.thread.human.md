A bug report from Microsoft's Windows App Compatibility Team details an issue with Git GUI's help documentation on Windows 11. When clicking "Online Documentation" in Git GUI version 2.48.1, users encounter an error prompt rather than the expected behavior of opening the documentation in Edge browser. The report comes from program manager Haifang Wang, who provides clear reproduction steps but lacks technical details about the specific error message. 

This appears to be a Windows-specific GUI interaction issue rather than a core Git functionality problem. The report seeks confirmation whether this is a known issue and what the expected timeline for resolution might be. As the first report of this issue in the thread, it establishes the problem but will likely need follow-up with more technical details about the error to enable debugging. The Git GUI component is maintained by Johannes Schindelin (Dscho) as part of Git for Windows, though this report comes through Microsoft's compatibility testing channels rather than the usual Git for Windows development process.
