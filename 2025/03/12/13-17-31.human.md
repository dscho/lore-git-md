This is a build system patch series improving Meson's handling of breaking changes. Patrick Steinhardt follows up on previous discussion with three focused changes to better integrate the `-Dbreaking_changes=true` option into the Meson build system.

The series first ensures the `WITH_BREAKING_CHANGES` define is properly set when the breaking changes option is enabled, bringing Meson in line with the Makefile behavior. It then addresses the `git-pack-redundant` command by both excluding it from compilation and preventing its documentation installation when breaking changes are enabled, matching the Makefile's treatment of this deprecated command.

The changes are straightforward and clearly motivated by aligning Meson build behavior with the existing Makefile implementation. Each patch is focused and touches only the necessary build files. This appears to be a clean, uncontroversial improvement to the Meson build system's feature parity.
