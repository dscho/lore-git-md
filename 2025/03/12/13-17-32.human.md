Build system patch aligning Meson's breaking changes handling with Makefile behavior. This is the first of a 3-part series addressing inconsistencies in how the Meson build system handles the `-Dbreaking_changes=true` option.

The patch fixes an oversight where Meson wasn't properly setting the `WITH_BREAKING_CHANGES` preprocessor macro when breaking changes were enabled. While the build option existed, it only affected tests without propagating to the actual compiled code. The change moves the breaking changes configuration later in meson.build to properly integrate with the `libgit_c_args` array.

The commit notes this issue went unnoticed because current tests only verify disabled behavior, not active breaking changes functionality. The change appears straightforward and well-motivated by the need for build system parity, with credit given to Phillip Wood for prior work on the topic. The diff shows clean relocation of the configuration block with the necessary compiler flag addition.
