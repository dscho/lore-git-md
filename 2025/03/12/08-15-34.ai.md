This is a documentation patch updating the "MyFirstContribution" tutorial to align with current Git practices. It's part of a GSOC (Google Summer of Code) contribution.

The patch makes several technical updates to the tutorial documentation: updating function signatures to include `struct repository *repo` parameters, replacing `git_config()` with `repo_config()`, adding guidance about the `UNUSED` macro, and converting file references from `.txt` to `.adoc` format. It also removes outdated references to the now-deprecated git-mentoring mailing list.

Key technical changes include:
- Updates to `cmd_psuh` function signature and usage throughout the tutorial
- Replacement of `git_config()` calls with `repo_config()`
- Addition of `UNUSED` macro examples for unused parameters
- File extension changes from `.txt` to `.adoc` in documentation references
- Removal of the git-mentoring@googlegroups.com reference

The changes appear well-motivated and correctly implemented, bringing the tutorial up to date with current Git development practices, particularly around repository handling and configuration. The patch touches documentation files but also reflects underlying code changes in how builtins interact with repositories. The modifications should help new contributors avoid common pitfalls when following the tutorial with a modern Git codebase.
