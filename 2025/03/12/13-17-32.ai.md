This is a build system patch that fixes Meson's handling of breaking changes compilation flags, part of a 3-patch series to align Meson with Makefile behavior.

The patch corrects an oversight where Meson's `-Dbreaking_changes=true` option wasn't properly propagating the `WITH_BREAKING_CHANGES` preprocessor macro to the actual code compilation, only affecting tests. The issue went unnoticed because existing tests only verify disabled breaking changes behavior, not enabled cases. The fix moves the breaking changes configuration logic after `libgit_c_args` array definition to properly inject the `-DWITH_BREAKING_CHANGES` flag into compiler arguments while maintaining the existing `build_options_config` setting.

Key technical changes include relocating the breaking changes logic in meson.build to ensure the preprocessor flag gets added to `libgit_c_args`, and maintaining the existing `YesPlease`/empty string behavior in `build_options_config`. The patch builds on prior work by Phillip Wood and appears to be a straightforward technical correction to achieve build system parity. The change is well-contained to meson.build with no behavioral impact beyond fixing the flag propagation issue.
