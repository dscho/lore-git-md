This happens because Meson's `-Ddocs=html,man` configuration still triggers full compilation rather than being documentation-only. While the original patch successfully catches doc build issues, this follow-up identifies an optimization opportunity to make the CI job faster by avoiding the full compilation step when only documentation verification is needed. The thread shows the community refining an already-useful CI improvement to make it more efficient.
