This is the third patch in a series improving Meson build system handling of breaking changes, specifically addressing documentation installation for deprecated commands.

The patch ensures the `git-pack-redundant(1)` manpage is only installed when breaking changes are enabled, matching the Makefile behavior where the command itself is already excluded. The changes modify both the Makefile and meson.build files to properly handle this documentation exclusion. The meson.build changes introduce a new `manpages_breaking_changes` dictionary to cleanly separate these conditionally-included manpages from the main set.

Key technical details include:
- Adds `git-pack-redundant.adoc` to the Makefile's exclusion list in the lint-docs-meson check
- Removes `git-pack-redundant.adoc` from the main `manpages` dictionary in meson.build
- Introduces new `manpages_breaking_changes` dictionary containing just this manpage
- Conditionally includes these breaking-change manpages only when `breaking_changes` option is disabled
- Updates the manpage sanity check to account for both sets of manpages

The patch builds on prior work by Karthik Nayak and completes the series' goal of full Meson/Makefile parity for breaking change handling. The implementation is clean and maintains the existing configuration structure while adding the new conditional logic.
