CI/build system patch adding Meson documentation testing. Patrick Steinhardt proposes extending the documentation test job to verify Meson-built documentation, which currently isn't checked despite being a supported build system. The patch follows up on a recent fix (87eccc3a81d) that addressed Meson doc building issues that went unnoticed.

The change refactors the existing doc testing script to use a new `check_docs` helper function, then adds parallel test cases for Meson builds using both AsciiDoc and Asciidoctor backends. This ensures documentation built via Meson gets the same validation as the Makefile-built docs, catching potential breakages early.

The implementation looks straightforward - it reuses the same verification logic from the Makefile tests while adding the Meson build steps. This fills a clear gap in CI coverage, motivated by a recent incident where Meson doc problems slipped through. The patch is well-contained to the test script with no broader system impact.
