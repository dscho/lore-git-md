Taylor Blau responds to Elijah Newren's patch fixing an overzealous assertion in merge-ort's rename handling, agreeing with the technical solution but raising a broader point about Git's assertion practices. Taylor doesn't request changes to the current patch but floats the idea of codifying these practices for future contributions.
