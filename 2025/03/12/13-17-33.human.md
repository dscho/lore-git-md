Build system patch aligning Meson's handling of deprecated commands with Makefile behavior. This is part 2 of a 3-patch series to ensure consistent treatment of breaking changes between build systems.

The patch removes compilation of `git-pack-redundant` when the `-Dbreaking_changes=true` option is set in Meson builds. This matches the Makefile behavior where deprecated commands are excluded when breaking changes are enabled. The change is straightforward - moving the pack-redundant source file into a conditional block that only includes it when breaking changes are disabled.

The commit explains this isn't strictly necessary (the command isn't exposed anyway), but maintains consistency with the Makefile build system's approach to breaking changes.
