Security hardening patch for remote-object-info format validation. This is a follow-up to Jeff King's discovery of a segfault vulnerability in the remote object info functionality when processing unsupported format placeholders.

The patch addresses a critical issue where the `remote-object-info` command could crash when given format strings containing placeholders other than the supported `%(objectsize)`. The original validation used a simple `strstr()` check that only verified the presence of the correct placeholder but didn't prevent other placeholders from being processed.

The fix implements proper format string validation by:
1. Explicitly checking for and rejecting any unsupported placeholders in the format string
2. Adding comprehensive test coverage for various format string scenarios, including valid, invalid, and mixed cases

This completes the security hardening of the remote object info feature, which has undergone multiple rounds of review focused on security considerations. The patch maintains the existing security measures while closing this final vulnerability. With this fix, the series appears ready for merging, having addressed all identified security concerns through rigorous review and testing.
