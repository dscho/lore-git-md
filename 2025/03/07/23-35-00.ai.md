This is the foundational patch in Usman Akinyemi's v4 series removing `the_repository` usage, focusing on making `repo_config()` handle NULL repositories. The change allows builtin commands to access system/global configs even without a repository context, which is particularly useful for displaying help text (`-h`) before repository validation occurs.

The patch modifies `config.c` to call `read_very_early_config()` when `repo` is NULL, maintaining access to system/global configurations while skipping repository-specific ones. The accompanying documentation in `config.h` explicitly explains this behavior and its purpose - supporting help text display while noting the current limitation regarding `-c` overrides in NULL repo cases.

Key technical details include:
- New NULL repo handling in `repo_config()` implementation
- Documentation of the design tradeoff (help text support vs `-c` override limitation)
- Reference to Junio Hamano's original guidance on this use case
- Maintains config reading behavior via `read_very_early_config()`

This establishes a pattern that will be used throughout the series, demonstrating how to handle NULL repository cases while maintaining necessary functionality. The change is well-documented and follows maintainer guidance, setting up the architectural approach for subsequent patches in the series.
