This is Junio Hamano's regular "What's cooking in git.git" status update, providing a snapshot of the current development branches and their progress toward the upcoming Git 2.49 release. The email highlights several notable changes that have graduated to 'master' and 'next', along with new topics and ongoing work.

Key highlights from the graduated changes include:
- A new promisor-remote protocol extension for large objects (cc/lop-remote)
- Windows build improvements (js/win-2.49-build-fixes)
- Continued progress removing `the_repository` global (ps/path-sans-the-repository)
- Documentation file extension changes from .txt to .adoc (tz/doc-txt-to-adoc-fixes)
- Fixes for merge machinery crashes in rename cases (en/merge-process-renames-crash-fix)

New topics of interest include:
- Support for partial reference updates (kn/non-transactional-batch-updates)
- Further `the_repository` removal in the object layer (ps/object-wo-the-repository)
- Optimizations for refname availability checks (ps/refname-avail-check-optim)
- A new "reflog-expire" task for git maintenance (ps/maintenance-reflog-expire)

The email notes that with Git 2.49's release candidate period underway, most new work will wait until after the release. Several topics are marked as needing review or discussion, while others are queued for inclusion in the next development cycle. The update provides a comprehensive view of Git's current development landscape, showing both stable changes ready for release and active areas of ongoing work.
