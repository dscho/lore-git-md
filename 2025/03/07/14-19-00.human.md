This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global from object-related APIs, specifically targeting the bitmap writing functionality. The patch converts `pack-bitmap-write.c` to use repository-specific instances rather than the global `the_repository` variable.

The changes are systematic and mechanical - the patch adds a `repo` field to `struct bitmap_writer` and updates all affected functions to use this repository instance instead of `the_repository`. Key changes include:
- Removing the `USE_THE_REPOSITORY_VARIABLE` define
- Adding repository parameter to trace2 calls
- Using repository-specific hash algorithms throughout
- Updating tree and commit lookups to use the writer's repository

The patch follows the established pattern seen in other parts of this series, showing careful attention to maintaining existing behavior while eliminating global state. It's a clean conversion that builds on the architectural work done in previous patches of the series. The changes are focused and well-contained to the bitmap writing subsystem, with no apparent impact on other areas of the codebase.
