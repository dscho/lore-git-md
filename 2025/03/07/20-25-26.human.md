Bugfix for zlib version reporting regression. Junio Hamano is queueing Toon Claes's patch that restores the ability to display zlib version information in `git version --build-options` output. The regression was introduced when zlib.h was moved during refactoring for zlib-ng compatibility. 

The change is minimal - just adding one include line in help.c to bring back the zlib version reporting functionality. Hamano notes this is safe since the code was already conditionally using ZLIB_VERSION, so the inclusion won't introduce new issues. 

This is part of a two-patch series (this being the first patch) that has already received internal review and ACKs from Patrick Steinhardt. The thread appears resolved with these changes ready for merging. The fix precisely targets restoring lost debugging/version-checking functionality without introducing new complexity.
