This is a minor cleanup patch in Patrick Steinhardt's ongoing series to remove `the_repository` usage from object APIs. It addresses compiler warnings in the newly split `hash.c` file.

The patch fixes several "-Wsign-compare" warnings by changing loop counters and function parameters from `int` to `size_t` where appropriate. These are straightforward changes that don't affect functionality but improve code hygiene. The modifications touch:
- The `hash_algo_by_name()` function's loop counter
- The `hash_algo_by_id()` function's loop counter
- The parameter type of `hash_algo_by_length()`
- Removal of a now-unneeded `DISABLE_SIGN_COMPARE_WARNINGS` define

This is patch 11/12 in the v3 series, following the major structural work of splitting hash algorithm code into its own file. The changes are mechanical and unlikely to be controversial, serving as final polish on the hash algorithm infrastructure work done earlier in the series.
