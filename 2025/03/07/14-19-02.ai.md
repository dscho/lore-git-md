Part of the ongoing `the_repository` removal effort, specifically targeting delta-islands functionality in pack-objects.

This patch converts delta-islands.c to stop using the global `the_repository` variable, making it fully repository-aware. The changes are straightforward since most functions already had repository context available - the main adaptation is adding a `struct repository*` parameter to `propagate_island_marks()`, the one function that previously relied on the global. The patch updates all callers accordingly, including the pack-objects builtin.

Key technical changes include:
- Removing `USE_THE_REPOSITORY_VARIABLE` define from delta-islands.c
- Converting `propagate_island_marks()` to take explicit repository parameter
- Updating progress reporting and ref iteration to use passed repository
- Ensuring tree and commit parsing uses the correct repository context
- Maintaining all existing behavior while eliminating global state

The changes follow the established pattern seen in earlier patches of this series, systematically removing global state while preserving functionality. The delta-islands conversion is particularly important as it touches core pack-objects behavior related to delta compression strategies. With this change, another major subsystem becomes fully repository-aware, continuing the series' progress toward pluggable object storage backends.
