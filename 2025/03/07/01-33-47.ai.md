The exchange demonstrates the collaborative refinement of this architectural change to the config system as part of the broader `the_repository` elimination effort.

- Current behavior skips per-repo config but reads system/global config via `read_very_early_config()`
- Junio wants the documentation to explain the "why" (design intent) more than the "how" (current implementation)
- The limitation of not handling `-c` overrides in NULL repo case is noted as potentially acceptable for now
