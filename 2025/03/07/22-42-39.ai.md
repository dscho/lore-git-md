This is a build system patch addressing the ongoing `WITH_BREAKING_CHANGES` deprecation work, specifically focusing on the Meson build's handling of deprecated command documentation.

Karthik Nayak proposes a solution for conditionally excluding the `git-pack-redundant` manpage in the Meson build when `WITH_BREAKING_CHANGES` is enabled. The patch works around Meson's immutable dictionary limitation by creating a separate dictionary for deprecated manpages (`manpages_breaking_changes`) and conditionally merging it with the main manpages dictionary when breaking changes are disabled. This matches the behavior already implemented in the Makefile build system.

The solution also updates the manpage sanity check to include both dictionaries when verifying documentation coverage. This maintains consistency with the Makefile implementation while working within Meson's constraints. The approach demonstrates understanding of Meson's dictionary operations and the project's cross-build-system requirements.

This patch follows up on Phillip Wood's earlier identification of the Meson build gap and Junio Hamano's Makefile fix for the same issue. It completes the technical implementation for documentation exclusion in both build systems, leaving only the non-blocking issue of `git help git` output (which requires `cmd-list.perl` changes) as previously noted in the thread.
