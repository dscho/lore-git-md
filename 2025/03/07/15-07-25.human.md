This is a build system patch addressing remaining issues with the deprecation of `git pack-redundant` under `WITH_BREAKING_CHANGES`. Phillip Wood follows up on Junio Hamano's earlier Makefile fix by examining the Meson build system's handling of the deprecated command.

The patch makes two key changes: it conditionally excludes `builtin/pack-redundant.c` from compilation in Meson when breaking changes are enabled, and adds the missing `WITH_BREAKING_CHANGES` define to the C compiler flags. Phillip also notes that the function declaration in `builtin.h` should ideally be guarded, though he considers this less urgent.

The email reveals some technical challenges with Meson's immutable dictionaries that prevent a complete solution for conditional documentation building. Phillip indicates he won't pursue this further, leaving the documentation issue unresolved in Meson while the compilation problem is now fixed. The changes maintain parity with the Makefile's handling of the deprecation, though some inconsistencies remain between the two build systems.
