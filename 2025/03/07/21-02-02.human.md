Bugfix follow-up in the partial reference transaction series. Karthik Nayak acknowledges Jeff King's report of an unreachable code path in the packed-refs backend error handling. This is a straightforward fix for a subtle issue caught by static analysis (Coverity), showing the value of such tools in catching edge cases.
