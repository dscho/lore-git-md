This is the first patch in Usman Akinyemi's v4 series removing `the_repository` usage, focusing on making `repo_config()` handle NULL repositories gracefully. The change allows builtin commands to read system and global configs even when run outside a repository (like when showing help with `-h`), while skipping repository-specific config.

The patch modifies `repo_config()` to call `read_very_early_config()` when the repository parameter is NULL, maintaining access to system/global settings. The commit message and added documentation explain this is particularly useful for help text display before repository validation occurs. The implementation follows Junio Hamano's guidance about supporting this NULL case while noting the current limitation regarding `-c` overrides.

This foundational change enables the subsequent conversions in the series, establishing a pattern for handling NULL repositories that will be reused across multiple builtins. The patch appears well-considered, with clear documentation of both the solution and its intentional limitations.
