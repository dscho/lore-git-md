This is part of the ongoing `the_repository` removal effort, specifically targeting the pack-bitmap-write subsystem. The patch converts bitmap writing functionality to use repository-specific state rather than the global `the_repository` variable.

The changes systematically replace all `the_repository` and `the_hash_algo` references in pack-bitmap-write.c with repository-specific versions stored in the `bitmap_writer` struct. Key modifications include:

1. Adding a `repo` field to `struct bitmap_writer` to track the active repository
2. Updating all trace2 calls to use the writer's repository instead of the global
3. Converting tree and commit lookups to use repository-specific versions
4. Making hash algorithm usage repository-specific throughout bitmap operations
5. Removing the `USE_THE_REPOSITORY_VARIABLE` define that was previously needed

The patch follows the established pattern seen in other parts of this series - methodically eliminating global state dependencies while maintaining identical functionality. All bitmap writing operations now properly respect the repository context they operate in, which is particularly important for cases involving multiple repositories or different hash algorithms.

This conversion is technically straightforward but touches many parts of the bitmap writing process, from initialization through finalization. The changes are mechanical but thorough, covering both explicit `the_repository` uses and implicit ones through hash algorithm access. The patch maintains all existing behavior while making the code properly repository-aware.
