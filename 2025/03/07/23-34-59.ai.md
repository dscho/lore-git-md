This is a v4 patch series in the ongoing `the_repository` removal effort, building on previous maintainer-approved work with additional refinements. The series removes the global variable from 8 builtin commands while improving NULL repository handling and helper function design.

Key technical changes in v4:
1. Enhanced `repo_config()` NULL handling documentation now explicitly states the design intent (supporting `-h` help text display) and current limitations (skipping `-c` overrides)
2. `checkout-index.c` refactored to pass `struct index_state` instead of `struct repository` to helper functions, following Junio's principle of minimal context passing
3. Typo fixes and minor cleanup throughout

The series maintains all previously established patterns:
- NULL repo handling for help text display
- System/global config reading via `read_very_early_config()`
- Behavioral parity with `do_git_config_sequence()`

Notable architectural points:
- Documents the tradeoff between NULL repo support and `-c` override limitation
- Demonstrates application of the "pass minimal context" principle in `checkout-index`
- Maintains test coverage across all affected commands

This iteration shows the series maturing from implementation to establishing patterns, with explicit documentation of design decisions and API principles.
