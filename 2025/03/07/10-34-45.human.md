This is a follow-up clarification in the ongoing thread about Git's bash completion script fixes for remote names containing slashes.

Phillip Wood responds to D. Ben Knoble's correction about the status of the zsh completion script, acknowledging his previous misunderstanding. Knoble had pointed out that the zsh script (git-completion.zsh) is actively maintained, particularly for Homebrew Git users, and referenced recent fixes including his own patch from April 2024 that addressed variable leakage.

The exchange serves to clarify the relationship between the bash and zsh completion scripts, emphasizing that changes to the bash completion should maintain compatibility with zsh since the zsh script reuses bash completion logic. This is part of the thread's broader focus on cross-shell compatibility considerations for the completion script improvements.
