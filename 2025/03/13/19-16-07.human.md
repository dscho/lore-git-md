This is a documentation patch discussion regarding man page formatting issues. Junio Hamano responds to Bjarni Ingi Gislason's report about troff/groff warnings in the `git-filter-branch` man page, explaining why the submitted patches can't be directly applied. 

Hamano clarifies that Git's documentation is written in AsciiDoc format, which then gets processed through a toolchain to produce the final man pages. The formatting issues Gislason identified stem from how URLs are rendered in the intermediate roff output, not from the source files themselves. 

The response suggests the fixes need to target the documentation toolchain rather than individual man pages, effectively redirecting the effort upstream. This maintains Git's documentation workflow where all edits must go through the AsciiDoc source files. The exchange shows the project's documentation maintenance process in action, with core maintainers guiding contributors toward the correct approach for such fixes.
