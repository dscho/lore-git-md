Refactoring patch in the NUL-delimited rev-list output series.

This is the first patch in v2 of the series to add NUL-delimited output support to `git rev-list`. Justin Tobler inlines the `show_object_with_name()` function into its only caller, `show_object()`, as a preparatory cleanup before implementing the NUL-delimited output format. The change consolidates the OID printing logic that will be modified in later patches.

The patch removes the helper function from revision.c and moves its implementation directly into builtin/rev-list.c, while also unifying the OID printing path for both named and unnamed objects. This simplification makes the subsequent NUL-delimited output changes easier to implement, as all the printing logic will be in one place.

The change is straightforward and mechanical, with no behavior changes intended. It touches three files but makes simple, focused modifications that are easy to verify. As the first step in a well-motivated series that has already seen significant discussion and iteration, this patch appears ready to go in.
