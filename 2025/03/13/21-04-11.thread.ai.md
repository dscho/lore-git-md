Documentation bugfix for `git log --ancestry-path` graph example. Han Jiang reports and demonstrates that the current man page example incorrectly omits commit C from the ancestry path between D and M in a complex merge scenario. Reproduction shows commit C (created on branch1 before merging with branch2) is correctly included in the actual output, contrary to documentation. The report provides complete reproduction steps with commit graph structure and command output showing the discrepancy. This requires updating the example graph in the documentation to accurately reflect the ancestry path behavior with merge commits.
