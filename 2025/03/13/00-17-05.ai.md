When `-z` is active, boundary commits now appear as `<OID> NUL boundary=yes NUL` rather than `-<OID> LF`. The implementation maintains all existing validation, including checks for incompatible options like `--graph` and `--left-right`.

Key technical changes include modifications to `show_commit()` to handle the new boundary object formatting, updates to the option compatibility checking in `cmd_rev_list()`, and documentation updates clarifying that `--boundary` is now supported with `-z`. The patch adds test coverage in t6000-rev-list-misc.sh that verifies the new output format matches expectations.

This completes the NUL-delimited output support for all major `rev-list` modes, following the series' established pattern of using single NUL delimiters and key-value attributes for metadata.
