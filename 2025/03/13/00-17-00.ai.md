- Single NUL delimiters replacing the initial double-NUL approach
- Support for NUL-delimited stdin argument parsing when `-z` is active
- Extended compatibility with `--boundary` and `--missing` options
- Preserved diff options processing through `setup_revisions()`
- The implementation now uses a single `line_delimiter` variable and maintains special handling for metadata separation
- Documentation clarifies current limitations and future extensibility points
