Platform compatibility fix addressing a MinGW-specific race condition in file handling. This is a cover letter for a 2-patch series that fixes a flaky test (t0610) on Windows systems.

The main issue occurs when using `O_CREAT|O_EXCL` flags with `_wopen()` on Windows, where the operation fails if another process has marked the same file for deletion via `DeleteFileW()`. The proposed solution changes the error code translation from `EACCESS` to `EEXIST` in this specific case, which matches the expected behavior for this race condition. The author notes this fixes the flakiness in their testing environment.

The second patch is a minor cleanup handling `O_CLOEXEC` in `mingw_open_existing()`, which the author describes as a "while-at-it" change that could be dropped if not deemed necessary. Both patches modify `compat/mingw.c` with a total of 15 lines added and 2 lines removed.

The author specifically requests review from Windows experts to validate the approach, acknowledging the potential for subtle platform-specific gotchas. The changes appear focused and well-motivated, addressing a concrete test flakiness with a minimal change to the error handling logic.
