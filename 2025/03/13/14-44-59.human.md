This is a documentation refinement for the NUL-delimited output format feature in `git rev-list`. 

Justin Tobler responds to Patrick Steinhardt's suggestion about improving the documentation structure for the `-z` option in `rev-list`. The current patch documents how NUL-delimited output works for objects and metadata, but Patrick notes that the mention of `--stdin` behavior being NUL-delimited in this mode appears too late in the documentation. 

Justin agrees with the feedback and plans to move the `--stdin` behavior description to the beginning of the `-z` option documentation for better visibility. This is a minor but sensible improvement to the documentation that makes the feature's behavior more immediately clear to readers. The change appears uncontroversial and aligns with the overall polish being applied to this well-reviewed feature series.
