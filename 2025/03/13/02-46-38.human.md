This is a refactoring patch in Elijah Newren's series to migrate from merge-recursive to merge-ort, specifically addressing verbosity control in the compatibility wrappers.

The patch modifies the merge-ort-wrappers.c file to properly handle cases where callers (like `git am` and `git checkout`) set verbosity to 0 to suppress conflict messages. Previously, these wrappers would always show messages regardless of the verbosity setting. The change introduces a simple conversion of the verbosity flag to a boolean that controls message display in `merge_switch_to_result()`.

This is a straightforward change that maintains backward compatibility while allowing callers to use the existing verbosity control mechanism they were accustomed to with merge-recursive. The patch is small (6 lines added, 2 removed) and focused, with the changes clearly explained in the commit message. As part of the larger merge-ort migration effort, this helps ensure a smooth transition for existing callers by preserving their expected behavior around conflict output.
