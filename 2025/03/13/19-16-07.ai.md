This is a documentation toolchain discussion in response to a formatting patch submission. Junio C Hamano explains why the submitted patches for `git-filter-branch.1` and `imap-send.1` cannot be directly applied - the Git project maintains documentation in AsciiDoc format which gets processed through a toolchain to generate man pages. The issue with URL rendering that Bjarni Ingi Gislason reported would need to be fixed in the AsciiDoc-to-manpage conversion toolchain rather than in the intermediate roff output. 

The response clarifies the project's documentation workflow and indicates this is a systemic issue rather than something that can be fixed through individual man page edits. The thread continues the discussion about man page formatting quality but shifts focus from direct patching to potential toolchain improvements. This positions the conversation as needing input from maintainers familiar with the documentation build system rather than being resolvable through simple documentation patches.
