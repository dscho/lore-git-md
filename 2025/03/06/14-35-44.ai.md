This is a v3 patch series in the ongoing `the_repository` removal effort, consisting of 8 patches that remove the global variable from several builtin commands. The series builds on Junio Hamano's approval of the NULL repository handling approach using `read_very_early_config()`.

The key technical change in this version is the addition of a new preparatory patch (1/8) that teaches `repo_config()` to accept NULL repository arguments by falling back to `read_very_early_config()`. This enables the subsequent patches to safely replace `git_config()` calls with `repo_config()` even when commands are run outside a repository (like with `-h` flag).

Each builtin command patch (2/8 through 8/8) follows the same pattern:
1. Replaces `git_config()` with `repo_config()`
2. Passes the repository parameter through to helper functions
3. Adds tests verifying the command works with `-h` outside a repository

The affected commands are: verify-tag, verify-commit, send-pack, pack-refs, ls-files, for-each-ref, and checkout-index. The changes are well-scoped and consistent, with each patch including tests to verify the behavior.

This version addresses feedback by:
- Consolidating the NULL repository handling into a single preparatory patch
- Adding comprehensive tests for each command
- Cleaning up commit messages to be more focused

The series appears ready for final review, with the architectural approach already approved and now focused on consistent implementation across the targeted commands. The tests provide good coverage of the NULL repository case that was the main concern in the thread.
