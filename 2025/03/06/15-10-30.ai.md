This is part 6/12 of Patrick Steinhardt's series to remove `the_repository` usage from object APIs, specifically targeting pack-revindex operations. The patch converts pack-revindex.c to use explicit repository contexts instead of the global variable, following the established pattern from earlier patches in the series.

Key technical changes include:
- Removes `USE_THE_REPOSITORY_VARIABLE` define from pack-revindex.c
- Replaces all `the_hash_algo` references with `p->repo->hash_algo` or equivalent
- Introduces `ridx_min_size()` helper to calculate minimum revindex size using passed hash algorithm
- Updates revindex loading and verification functions to take explicit hash algorithm parameters
- Modifies trace2 calls to use repository from MIDX/pack context
- Maintains all existing functionality while removing implicit state

The changeset affects core pack operations including:
- Pack revindex creation and loading
- MIDX revindex handling
- Offset-to-position conversions
- Revindex verification checks

This continues the series' methodical approach to repository parameterization, with pack-revindex being a natural next target after the pack-write and pack-check conversions in previous patches. The changes are focused and mechanical, following the established conversion patterns while maintaining all pack revindex functionality. Review attention should focus on the correctness of repository parameter passing through the revindex loading and verification paths.
