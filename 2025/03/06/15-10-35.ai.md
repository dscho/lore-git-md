This is a minor bugfix patch in the ongoing `the_repository` removal series, specifically addressing compiler warnings in the newly created hash.c file.

Patch 11/12 in Patrick Steinhardt's series fixes "-Wsign-compare" warnings in hash.c by changing loop counters and parameter types from `int` to `size_t` where appropriate. The changes are straightforward:
- Removes the now-unneeded `DISABLE_SIGN_COMPARE_WARNINGS` define
- Updates three hash algorithm lookup functions (`hash_algo_by_name`, `hash_algo_by_id`, `hash_algo_by_length`) to use `size_t` for loop counters
- Changes the parameter type of `hash_algo_by_length` from `int` to `size_t` in both implementation and declaration

The patch maintains all existing functionality while cleaning up compiler warnings. This is a small but necessary follow-up to the larger hash algorithm reorganization done in patch 10/12, ensuring clean compilation as the codebase moves toward repository-specific hash implementations. The changes are mechanical and unlikely to be controversial, though reviewers may want to verify the `size_t` usage is appropriate for all platforms.
