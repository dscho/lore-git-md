Build system fix for Meson's Windows source list sorting.

This is the second patch in a 3-part series addressing platform compatibility and build system issues during Git's Meson transition. The patch corrects an alphabetical sorting error in the Windows-specific source file list within `meson.build`, moving `compat/win32/dirent.c` to its proper place in the sequence.

The change is straightforward - a single line move to maintain consistent alphabetical ordering. Patrick Steinhardt has already reviewed this change, and it appears uncontroversial. The patch demonstrates the kind of minor but important housekeeping needed as Git project transitions build systems, ensuring consistency in the new Meson infrastructure.

This particular fix stands in contrast to the more complex ident.c change in patch 1/3, representing the simpler end of the spectrum in this series' build system improvements.
