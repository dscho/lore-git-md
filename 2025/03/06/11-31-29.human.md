This is a CI/build system patch that ensures consistent toolchain selection between GitLab and GitHub CI environments for Windows builds using Meson.

Patrick Steinhardt fixes an inconsistency where GitHub Workflows was using GCC instead of the intended Visual Studio toolchain for Windows Meson builds, despite the presence of both compilers. The issue was reported by Johannes Schindelin. The solution adds the `--vsenv` flag to explicitly request Visual Studio toolchain usage in both CI systems, though it was only strictly necessary for GitHub.

The patch affects two CI configuration files, adding the flag to the Meson setup commands. Build logs show the change successfully enforces MSVC toolchain usage on GitHub while maintaining existing behavior on GitLab. This appears to be a straightforward, well-justified change with clear before/after evidence in the linked CI runs.
