This is part 1/12 of Patrick Steinhardt's series to reduce `the_repository` usage in object APIs, continuing René Scharfe's work. The patch focuses on the csum-file subsystem, which handles checksum calculations for various Git operations.

The changes modify csum-file functions to explicitly take a hash algorithm parameter rather than implicitly using `the_repository->hash_algo`. This affects core functions like `hashfd()`, `hashfd_check()`, and `hashfile_checksum_valid()`, along with their callers across 14 files including pack operations, commit-graph handling, and index writing.

The conversion is mechanical but thorough, touching both the csum-file interface and all its major consumers. The patch maintains existing behavior while removing global state dependencies, a key step toward the series' goal of making object APIs repository-agnostic. As the first in the series, it sets up the pattern for subsequent conversions while demonstrating careful attention to backward compatibility.
