This is the foundational patch in Usman Akinyemi's v3 series to remove `the_repository` usage, implementing Junio Hamano's approved approach for handling NULL repositories. The patch modifies `repo_config()` to gracefully handle NULL repository contexts by falling back to `read_very_early_config()`, which reads only system and global configurations. This maintains the expected configuration cascade behavior (repo → user → system) even when no repository is available.

The change is minimal (just 4 lines of core logic) but strategically important, as it enables the subsequent patches in the series to safely convert several builtin commands to use repository-aware configuration. The implementation preserves all existing configuration semantics, including the behavior of `-h` flags, and comes with updated documentation in config.h explaining the NULL handling behavior.

This patch appears well-considered, with clear motivation and proper attribution to Junio's suggestion. It establishes the architectural pattern that the rest of the series will follow for handling NULL repository cases, addressing one of the key challenges in the broader `the_repository` removal effort. The small, focused change makes it easy to review while providing significant infrastructure support for the conversions that follow.
