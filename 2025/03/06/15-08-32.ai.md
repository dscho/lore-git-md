This is the foundational first patch in a 16-part performance optimization series for the refs subsystem, introducing API groundwork for subsequent optimizations.

The patch adds a new function `repo_get_oid_with_flags()` that extends the existing `repo_get_oid()` by accepting flags to pass through to `get_oid_with_context()`. The implementation is straightforward - it wraps the lower-level function while maintaining the same behavior when no flags are specified. The existing `repo_get_oid()` becomes a simple wrapper that calls the new function with flags=0.

Key technical details:
- Adds the function declaration to object-name.h with documentation
- Implements the function in object-name.c by forwarding to get_oid_with_context
- Keeps backward compatibility by making repo_get_oid() call the new function
- The flags parameter will be used by later patches in the series for optimization purposes

This change follows the pattern seen in other parts of the codebase (like git-cat-file optimizations) where flag-based variants are added to enable more control over object lookup behavior. The patch is cleanly separated from the actual optimizations that will use it, making it a clear foundational change.

As the first patch in a major optimization series, this establishes the pattern of careful API evolution that will be used throughout the rest of the changes. The implementation is minimal and unlikely to be controversial, serving primarily as setup for the more substantial optimizations to come.
