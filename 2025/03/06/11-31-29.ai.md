CI/build system fix for Windows Meson builds. This patch corrects an inconsistency where GitHub Workflows was using GCC instead of the intended Visual Studio toolchain for Windows Meson jobs, while GitLab CI was already using VS correctly. The fix explicitly adds the `--vsenv` flag to force Visual Studio toolchain usage in both CI systems.

The change affects both `.github/workflows/main.yml` and `.gitlab-ci.yml`, adding the flag to Meson setup commands. While only GitHub was actually affected (due to GCC being in PATH), the change is applied to both CI systems for consistency and to avoid implicit toolchain assumptions. The patch includes test results showing successful VS toolchain usage in GitHub Actions, and references Johannes Schindelin's original report of the issue. This appears to be a straightforward technical fix with clear motivation and testing evidence.
