This is a minor cleanup patch in Patrick Steinhardt's ongoing series to remove `the_repository` usage from object APIs. It fixes several "-Wsign-compare" compiler warnings in the newly created hash.c file by changing loop counters and parameters from `int` to `size_t` where appropriate. 

The changes are straightforward and mechanical conversions to eliminate signed/unsigned comparison warnings. The patch touches two files: hash.c (where the actual implementations are fixed) and hash.h (where the function prototype for `hash_algo_by_length()` is updated to match). 

This is patch 11/12 in the series, following the major structural work of separating hash algorithm code from object-file.c in the previous patch. While small, it demonstrates the attention to detail in this series - even compiler warnings are being cleaned up as part of the broader refactoring effort. The changes maintain all existing functionality while making the code more type-safe.
