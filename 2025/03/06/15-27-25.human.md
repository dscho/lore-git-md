Bugfix for a crash in merge-ort during cherry-picks with directory renames. Elijah Newren responds to Dmitry Goncharov's report of a crash that occurs when cherry-picking a commit that moves a file into a directory that was itself renamed in the other branch. The test case shows `merge-ort` crashing with an assertion failure, while the older `recursive` strategy detects a conflict (albeit with its own issues in writing the index).

Goncharov provided a test case and initial fix that prevents the crash by ignoring certain directory renames, but Newren notes this produces a misleading conflict message. Newren plans to submit an alternative fix that properly handles the case while maintaining accurate conflict reporting. The issue affects both cherry-pick and merge operations when using the ort strategy.

This appears to be a legitimate bug in directory rename detection logic that could affect users performing complex cherry-picks. Newren's response indicates the fix will be properly integrated into existing test infrastructure rather than adding a new test file. The patch demonstrates good engagement with contributor reports, though the delayed reply (6 months) is noted.
