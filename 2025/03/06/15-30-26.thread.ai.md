Test case demonstrating crash in merge-ort's directory rename detection when handling circular renames (A/→B/ with new files in A/ that originated from B/). The test follows t6423 style and is marked test_expect_failure as it currently triggers an assertion failure in process_renames() rather than properly detecting the conflict. The scenario involves one branch renaming A/ to B/ while another adds files to A/ that originally came from B/, creating a circular rename path. Expected behavior would be to detect this as a conflict rather than crashing. The test verifies the expected error output via grep but does not yet fix the underlying issue in merge-ort.
