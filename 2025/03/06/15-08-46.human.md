Performance optimization for the files backend's ref iterator, completing the series' iterator seeking implementation across all ref backends. This patch adds seek capability to the files backend's ref iterator by leveraging the underlying ref-cache iterator, following the same pattern used for reftable and packed-refs in previous patches. The implementation is straightforward since it builds on existing infrastructure, though it explicitly does not support seeking for reflog iterators (which matches the reftable backend's behavior). This is patch 15/16 in a series that has already been technically reviewed and approved, with only minor documentation nits remaining.
