This is a cover letter for a 3-patch series addressing platform compatibility and build system issues from Git for Windows maintainer Johannes Schindelin. The series expands on two previously discussed patches (fixing a const-correctness issue in `ident.c` and sorting in the Meson build) and adds a new CMake fix for test object handling.

The cover letter explains these are "hot fixes" needed for Git for Windows v2.49.0-rc0, though the Meson sorting change is more of a cleanup. Version 2 adds significant investigation into when the `ident.c` compiler error manifests (only in Git for Windows' development environment with specific GCC versions/flags, not in CI) and includes a new third patch addressing CMake test object handling that became necessary after -rc1.

The series shows careful attention to build system details across multiple platforms (Windows-specific issues in ident handling, Meson sorting, and CMake test infrastructure). While the changes are small (10 lines total), they reveal non-trivial platform-specific build complexities, particularly around the Meson transition and Windows toolchain variations. The expanded commit message for the ident change provides valuable context about why this long-standing issue surfaces now and the limitations of current CI testing for Windows builds.
