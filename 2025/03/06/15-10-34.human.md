This is patch 10/12 in Patrick Steinhardt's series to reduce `the_repository` usage in object APIs, specifically focusing on refactoring hash algorithm code. The patch moves all hash algorithm implementation code from `object-file.c` to a new `hash.c` file, keeping the header declarations in `hash.h`.

The change is purely organizational - no behavior is modified. The commit explains that having the implementation in `object-file.c` made the hash subsystem harder to find and unnecessarily mixed concerns. The diff shows 283 lines moved to the new file with corresponding deletions from `object-file.c`, plus the necessary build system updates.

This appears to be a straightforward code movement that follows the project's ongoing effort to better organize subsystems. The patch maintains all existing functionality including SHA-1 and SHA-256 implementations, their unsafe variants, and helper functions for working with hash algorithms. As part of the larger series, this helps isolate repository-specific code as the project works toward eliminating global state.
