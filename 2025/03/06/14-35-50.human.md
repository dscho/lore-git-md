This is part 6/8 of Usman Akinyemi's series to remove `the_repository` global variable, focusing on converting `ls-files`. The patch follows the established pattern from previous conversions in the series, removing the global variable in favor of passing repository context through function parameters.

The changes update `builtin/ls-files.c` to:
1. Remove `USE_THE_REPOSITORY_VARIABLE` definition
2. Pass repository context to `expand_objectsize()` and `show_ru_info()`
3. Replace `git_config()` with `repo_config()`
4. Update index operations to use the passed repository
5. Add tests verifying `-h` flag behavior both inside and outside a repository

The conversion maintains existing functionality while properly handling NULL repository cases (like when `-h` is used outside a Git repository). The patch includes the standard test coverage we've seen throughout this series, ensuring the command works correctly in all contexts. This continues the methodical, well-tested approach seen in previous patches of the series, with Christian Couder continuing as mentor.
