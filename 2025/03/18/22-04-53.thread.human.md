This thread introduces a new compiler utility macro to handle -Wunreachable-code warnings more cleanly. The second patch in the series adds a NOT_CONSTANT() macro that explicitly tells compilers not to optimize out certain expressions, particularly for cases like sigfillset() where we want to preserve error checking even when the compiler might otherwise treat the call as a constant. The implementation includes a new compiler-tricks/not-a-constant.c file and modifies both the Makefile and meson.build to support it.

The change demonstrates the macro's use in run-command.c, replacing a more verbose errno check pattern with a direct NOT_CONSTANT() wrapper. This appears to be a thoughtful addition to Git's compiler compatibility layer, providing a more maintainable way to override compiler optimizations when needed for correctness. The patch builds on previous discussion about managing -Wunreachable-code warnings and is part of an ongoing effort to improve Git's handling of compiler-specific behaviors.
