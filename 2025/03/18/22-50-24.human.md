Refspec API cleanup patch in a merged series. This is part of Taylor Blau's ongoing refactoring to modernize the refspec API, following earlier discussions about simplifying the `struct refspec`'s boolean `fetch` field.

The patch removes the thin wrapper function `refspec_item_init_or_die()`, inlining its error handling at the two call sites in `builtin/pull.c` and `refspec.c`. This prepares for introducing fetch/push-specific variants of `refspec_item_init()` in the next commit, avoiding the need for corresponding `_or_die` versions of those new functions. The change slightly duplicates code but reduces API surface area.

This is a straightforward mechanical cleanup with no behavior changes, continuing the series' goal of making the refspec API more maintainable. The patch has already been reviewed and merged as part of the larger refactoring effort that established consensus around the boolean representation of refspec direction.
