Test isolation improvement for promisor-remote test suite.

This is the first patch in Christian Couder's v6 series fixing promisor-remote configuration handling. It addresses a subtle test isolation issue where failed clone operations could leave behind test directories. The patch moves cleanup commands before the clone operations they're meant to clean up, ensuring the "client" directory gets removed even if the clone fails.

The change is straightforward but important for test reliability - while Git's clone does attempt cleanup on failure, this makes the cleanup more robust by ensuring it runs regardless of how the clone fails. The patch touches only the test script, moving 8 `test_when_finished` cleanup commands to precede their corresponding clone operations.

This is a preparatory patch that enables more reliable testing for the subsequent promisor-remote fixes in the series. The change demonstrates good test hygiene and follows the principle of defensive programming by not relying solely on Git's internal failure cleanup.
