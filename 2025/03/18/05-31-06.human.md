Performance optimization patch in the incremental MIDX bitmap series.

This is part of Taylor Blau's ongoing work to implement incremental bitmap support for multi-pack indexes (MIDX). The patch extends the `--test-bitmap` mode of `git rev-list` to work with incremental MIDX bitmaps, adding support for testing bitmaps across multiple layers.

The implementation introduces a new `bitmap_test_data` structure with a "base" pointer that mirrors the bitmap chain structure. When testing a commit, it traverses this chain to find the appropriate bitmap layer containing the commit. The patch includes modifications to `bitmap_for_commit()` and introduces a new helper function `find_bitmap_for_commit()`.

Elijah Newren provides a focused review suggesting a small optimization - avoiding duplicate zeroing of memory in `bitmap_test_data_prepare()`. He notes that the function first zeroes the structure, then uses `CALLOC_ARRAY` (which also zeroes memory) when either removing the initial zeroing or using `xmalloc` would be more efficient. This appears to be the only substantive feedback on this patch.

The change is relatively contained (86 insertions, 21 deletions) and builds on the established architecture of the incremental MIDX bitmap work. It follows the pattern of previous patches in the series and appears technically sound, with only this minor optimization opportunity identified.
