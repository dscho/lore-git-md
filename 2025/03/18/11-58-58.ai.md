- Updating all callers of these functions to pass the repository context
- Converting `git_config()` to `repo_config()`
- Adding test coverage for `-h` help output behavior in both repository and non-repository contexts
- Maintaining the same NULL `repo` handling pattern seen in prior patches, where `show_usage_with_options_if_asked()` handles the help case before repository operations
