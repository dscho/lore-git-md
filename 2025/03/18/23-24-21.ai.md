Build system patch for Rust integration, part 3/4 in a series addressing libgit-sys packaging issues. This patch enables parallel builds by passing Cargo's jobserver flags to the underlying Make invocations in the libgit-sys build script. The change modifies build.rs to propagate CARGO_MAKEFLAGS to both Make calls that compile libgit.a and generate bindings, ensuring build parallelism is maintained through the entire process. The implementation is straightforward - just two lines adding the MAKEFLAGS environment variable to existing Make command setups. This continues the series' focus on build infrastructure improvements while maintaining the separation between Cargo and Make build systems established in earlier patches. The change is contained to contrib/libgit-sys/build.rs and doesn't affect core Git functionality. Technical details include the use of env::var_os() to capture the jobserver flags and their injection via the make_cmd::gnu_make() builder pattern. This appears to be a well-scoped, technically sound improvement that should speed up builds without introducing new side effects or cleanup requirements.
