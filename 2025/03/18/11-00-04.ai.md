The test changes validate these behaviors more thoroughly isolating test cases and ensuring clean state between runs.

Key files modified are `promisor-remote.c`, its documentation, and the expanded test script which now includes 75 lines of test coverage (up from 59 in v5). The test improvements follow the maintainer's earlier feedback about proper test isolation and cleanup.
