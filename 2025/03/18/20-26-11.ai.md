This is a test modernization patch from a GSoC participant, converting various test scripts to use Git's test helper functions (`test_path_exists`, `test_path_is_file`, `test_path_is_dir`) instead of raw `test -(e|f|d)` commands. The change improves test failure diagnostics by providing more descriptive error messages when path checks fail.

The patch touches 12 test files spanning from t0007 to t1700, systematically replacing direct `test` invocations with the appropriate test helper functions. The changes are mechanical but important for maintainability - the helper functions will produce clearer output when tests fail, showing exactly which path check failed rather than just a generic test failure.

Key technical details for future reference:
- Affects test assertions about file/directory status
- Introduces no behavior changes, only test output improvements
- Uses three main test helpers:
  - `test_path_exists` replaces `test -e`
  - `test_path_is_file` replaces `test -f` 
  - `test_path_is_dir` replaces `test -d`
- Also handles some `! test -f` cases with `! test_path_is_file`

The patch appears well-scoped and correctly implemented, though as a mechanical change it doesn't include much rationale beyond the commit message's note about improved error messages. The changes are consistent and the patch applies cleanly to the test suite.
