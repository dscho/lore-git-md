This is a refactoring patch series that concludes the protocol v2 fetch behavior discussion by modernizing the refspec API. It's a follow-up to earlier architectural changes and represents the final cleanup of the refspec handling code.

Taylor Blau presents a 4-part series that simplifies how Git handles refspec direction (fetch vs push). The key change converts the `fetch` field in `struct refspec` from using symbolic constants to a simple boolean, as the field was only ever used as a true/false value despite being declared as an enum. The series also introduces fetch/push-specific API variants to make the code more type-safe and removes obsolete initialization functions.
