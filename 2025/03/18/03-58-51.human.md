This is a follow-up to a bugfix patch addressing shell completion issues caused by manpage formatting changes. The patch modifies `generate-configlist.sh` to handle backtick-wrapped option names in documentation.

Junio C Hamano had raised concerns about the original implementation using GNU-specific regex features (`\?` in BRE) and suggested converting to ERE (`grep -E`) for better portability. He also recommended consolidating the grep+sed pipeline into a single sed command for efficiency.

Jean-Noël Avila acknowledges the GNUism concern while noting the tests passed on multiple platforms. He indicates he will reroll the patch to address the portability suggestion. The change is relatively small (4 lines) but important for maintaining consistent completion behavior across different systems.

This patch is the first in a 2-part series where the second patch (documentation standardization) has already been approved. The completion fix appears straightforward but needs this minor adjustment before final approval.
