This thread discusses a patch series addressing build system integration issues for the libgit-sys Rust crate, part of Git's Rustification effort. The series (currently at v1) focuses on fixing `cargo package` operations by separating Cargo-managed and Makefile-built components. The initial patches relocated build artifacts and introduced a `git-src` symlink that requires worktree cleanup after builds - a tradeoff acknowledged as suboptimal but currently necessary.

The latest patch (3/4) enables parallel builds by passing Cargo's jobserver flags to Make invocations in the libgit-sys build script. This straightforward change modifies build.rs to propagate CARGO_MAKEFLAGS, maintaining build speed through the process while keeping the separation between Cargo and Make systems established earlier. The implementation appears technically sound and well-contained to contrib/libgit-sys/.

Key open questions remain around the worktree cleanup requirement from the symlink approach, which the author flagged as potentially problematic. The series continues to focus on build infrastructure improvements without affecting core Git functionality, with one more patch expected to complete the set by excluding unnecessary directories from git-src. These changes are prerequisites for progressing the libgit-rs packaging effort.
