HTTP TCP keepalive configuration patch series (v2):

This thread introduces new HTTP configuration options for fine-grained control of curl's TCP keepalive behavior through a four-patch series, addressing bandwidth-limited clone failures. The v2 series maintains the core approach while incorporating feedback from multiple contributors.

Key technical details:
- Static variables curl_tcp_keepidle/keepintvl/keepcnt (-1 defaults)
- Config options: http.keepaliveidle, http.keepaliveinterval, http.keepalivecount
- Environment variables GIT_HTTP_KEEPALIVE_* override config
- Implementation in http.c's config callback and get_curl_handle()
- Added version checking for CURLOPT_TCP_KEEPCNT (curl 8.9.0+)
- New helper function set_long_from_env() centralizes environment variable parsing with robust error handling
- Removed obsolete set_curl_keepalive() helper by inlining functionality
- Cleaned up unnecessary (long) casts in legacy speed limit settings
- Series structure:
  - Patch 1: Helper refactoring and type cast cleanup
  - Patch 2: New environment variable parsing helper
  - Patch 3: Removal of obsolete keepalive helper
