HTTP feature patch adding TCP keepalive configuration options.

This is the final patch in a series that adds fine-grained control over curl's TCP keepalive behavior. Taylor Blau introduces three new configuration options (`http.keepAliveIdle`, `http.keepAliveInterval`, and `http.keepAliveCount`) with corresponding environment variables, allowing users to customize when and how often TCP keepalive probes are sent.

The patch addresses a real-world problem where connections could be terminated during slow clones, particularly when bandwidth is in use. The implementation is clean and follows the pattern established in the preparatory patches, using the new `set_long_from_env()` helper for environment variable parsing. Each option maintains curl's default behavior when unset.

Documentation is thorough, explaining each parameter's purpose and noting OS dependency for actual behavior. The changes are focused in http.c with clear variable naming and straightforward curl option setting. This appears to be a well-considered addition that gives users more control over connection behavior while maintaining sensible defaults.
