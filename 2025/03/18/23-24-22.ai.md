This is the final patch in a series addressing build issues for the libgit-sys Rust crate, specifically focusing on reducing package size for crates.io distribution. The patch implements directory exclusions to avoid copying unnecessary source files during packaging, keeping the package under crates.io's 10MB limit. It modifies the build system in three key ways: adding exclusions in Cargo.toml for directories like Documentation, git-gui, and test files; introducing a new `libgit-pkg-clean` Makefile target that removes test and fuzzing directories; and disabling optional components (gitweb, Perl, Tcl/Tk) during build.rs execution.

Technical changes include new Makefile variables (RMDIR with non-empty handling), additional NO_* flags in build.rs, and careful coordination between Cargo.toml exclusions and Makefile cleanup rules. The patch maintains the separation between Rust and C build systems while addressing the specific packaging size constraint. This completes the series' goal of enabling proper libgit-sys packaging, with all changes confined to contrib/ without affecting core Git functionality. The approach appears well-considered, with thorough exclusion of non-essential components and proper cleanup handling.
