Bugfix for promisor-remote NULL pointer dereference, part of a v6 series addressing configuration validation issues. This patch specifically prevents segfaults when remote URLs are missing or empty in the config by skipping such remotes when building the strvec' of names and URLs. The change uses `git_config_get_string_tmp()` for cleaner memory management and adds several test cases to verify the behavior.

The patch is well-motivated, fixing a clear crash scenario while maintaining consistency with Git's handling of missing/empty URLs elsewhere. It includes thorough test coverage for both missing and empty URL cases, showing how these configurations affect cloning behavior with promisor remotes. The implementation follows the architectural principle of rejecting invalid configurations rather than trying to handle edge cases.

This is the second of four patches in a series that has undergone multiple rounds of review and refinement. The changes here are focused and build on the test isolation improvements from patch 1 in the series. The patch appears ready for inclusion, with clean code changes and comprehensive tests that demonstrate both the failure cases and the fixed behavior.
