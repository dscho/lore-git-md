This thread addresses long-standing edge cases in Git's date approximation logic (approxidate), particularly when handling special date/time formats combined with explicit day specifications. The five-patch series by Tuomas Ahola builds on a 2006 bug report from Linus Torvalds about date parsing quirks.

The core fixes include making "today" mean midnight (resolving the uselessness of "--since=today"), properly handling time components with special strings, and introducing a deferred adjustment mechanism for "today"/"yesterday" using negative tm_mday markers. The changes come with comprehensive test coverage and documentation updates.

The second patch, which just arrived, enhances the test infrastructure with time offset support via a new `add_time_offset()` helper function. This allows testing date parsing across boundaries without hardcoding dates, demonstrated with a "January 5th yesterday" test case that verifies year boundary crossing. This infrastructure patch was already accepted in previous iterations and provides the foundation for the substantive fixes that follow.

All five patches are now complete, with the substantive changes (patches 3-5) already accepted. Junio C Hamano confirmed the behavior change for "today" is acceptable since the previous behavior was undocumented and accidental. The series appears ready for merging, with only potential release notes about the "today" behavior change remaining as a loose end.
