Case-sensitive remote name matching in promisor-remote (final patch of bugfix series).

This is the fourth and final patch in Christian Couder's series hardening the promisor-remote subsystem against NULL pointer dereferences and improving configuration validation. The patch aligns promisor-remote's name comparison behavior with Git's standard case-sensitive handling of remote nicknames in configuration.

The change replaces a case-insensitive `strcasecmp()` with case-sensitive `strcmp()` when matching remote names, matching how Git handles remote configurations elsewhere. The documentation is updated to explicitly note this case-sensitivity for both name and URL comparisons.

This completes the series that has evolved through six iterations, with each round adding more robust error handling and test coverage. The changes are now well-tested and maintainer-approved, addressing edge cases while staying true to Git's configuration validation philosophy. The series is ready for inclusion in Git 2.49.0.
