This is a feature patch series introducing new configuration options for fine-tuning curl's TCP keepalive behavior in Git's HTTP transport.

Taylor Blau proposes three new http.* configuration options to control the idle time before keepalive probes (http.keepAliveIdle), interval between probes (http.keepAliveInterval), and number of probes before connection termination (http.keepAliveCount). These give users more control over connection persistence behavior when fetching or pushing over HTTP.

The series starts with two preparatory cleanups: introducing a helper function for environment variable parsing and inlining a keepalive configuration function. The third patch implements the new configuration options with thorough documentation but no tests, as the author notes testing this behavior is non-trivial.

The changes are focused and well-explained, touching only http.c and its documentation. While the lack of tests might normally be a concern, the simplicity of the implementation and the difficulty of testing low-level TCP behavior make this reasonable. The patch appears ready for review, with the testing question left open for discussion.
