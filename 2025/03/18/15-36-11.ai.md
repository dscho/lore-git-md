The second patch maintains standalone test coverage for tag handling, which was a point of discussion in earlier reviews. Changes are minimal in the core code (`bundle-uri.c`), focusing on the refspec modification while maintaining all existing behaviors.

Key technical details:
- Reference hierarchy now preserved: `refs/heads/main` → `refs/bundles/heads/main`
- Tag references now properly included: `refs/tags/v1.0` → `refs/bundles/tags/v1.0`
- Test coverage verifies both path-based and HTTP bundle scenarios
- Implementation avoids breaking changes while improving negotiation
