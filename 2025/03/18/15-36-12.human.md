Performance optimization for bundle-uri reference handling, part 1/2 of a rebased series. This patch expands the bundle-uri functionality to copy all references (not just `refs/heads/`) into the `refs/bundles/` namespace while preserving their hierarchy. The change improves fetch negotiation by including more references, which in testing has shown dramatic reductions in object downloads (from 32% to 1% in some cases).

The core change is minimal - just removing the `heads/` restriction in `bundle-uri.c`. The bulk of the diff updates test expectations to match the new reference hierarchy (`refs/bundles/heads/topic` instead of `refs/bundles/topic`). The tests comprehensively cover path-based and HTTP bundles, bundle lists, and various edge cases.

This version incorporates all prior feedback, with the first two patches from previous iterations now squashed together. The series appears technically sound and well-tested, having addressed earlier concerns about tag handling and backward compatibility. The performance benefits remain validated while maintaining existing behaviors.
