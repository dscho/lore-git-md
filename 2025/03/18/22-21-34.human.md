Refactoring patch introducing a helper function for HTTP environment variable parsing.

This is the first of three preparatory patches in a series adding fine-grained TCP keepalive configuration to Git's HTTP stack. The change introduces a new `set_long_from_env()` helper function that consolidates the pattern of parsing numeric environment variables into long integers. 

The patch replaces two existing instances in `http.c` that were manually handling `GIT_HTTP_LOW_SPEED_LIMIT` and `GIT_HTTP_LOW_SPEED_TIME` environment variables with calls to the new helper. The commit message notes this both cleans up some minor code duplication and prepares for future additions that will need similar functionality.

The change is straightforward and well-contained, touching only HTTP initialization code. The commit message provides clear historical context, referencing the 2009 introduction of the related `set_from_env()` function. This appears to be a clean, logical refactoring that will make the subsequent keepalive configuration patches simpler to implement.
