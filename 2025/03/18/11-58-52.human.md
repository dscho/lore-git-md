The series builds on two prior patch sets from the same author. The changes are mechanical but well-justified, with each patch touching a different builtin command. The author provides clear references to the prerequisite changes that make this cleanup possible. Test coverage appears thorough, with additions to multiple test files to verify the behavior changes.
