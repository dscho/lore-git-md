The patch itself adds core infrastructure for handling incremental bitmap layers by introducing `base` and `base_nr` fields to `struct bitmap_index`, enabling chaining of MIDX bitmap layers. Key changes include:

- New `base` pointer to track previous MIDX layer's bitmap index
- `base_nr` counter for total layer depth
- Modified `midx_bitmap_filename()` to handle split MIDX cases
- Updates to `open_midx_bitmap_1()` and `load_reverse_index()` to traverse MIDX chains
- Recursive bitmap loading via `load_bitmap()`
- Memory management updates in `free_bitmap_index()`

The changes are primarily plumbing work to support the layered bitmap design, with careful handling of pack-revindex loading across MIDX layers.
