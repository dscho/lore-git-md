Build system patch addressing Rust packaging constraints in the libgit-sys crate.

This second patch in the series introduces a `git-src` symlink to solve `cargo package` compatibility issues. The symlink points to the Git repository root, allowing the build process to access necessary files when packaged. However, this creates a new requirement - the build now forcibly cleans the Git worktree after each build to comply with Cargo's restrictions on build script modifications. 

The author acknowledges this is undesirable but currently necessary, as alternatives like making temporary copies would be resource-intensive. The patch adds a `PRESERVE_LIBGIT_TARGET` Makefile variable to control this behavior, though it's unclear if this provides sufficient flexibility for developers.

This change appears technically sound but has clear workflow implications - every libgit-sys build will now clean the worktree. The author explicitly calls this out for discussion, suggesting they're open to alternative approaches. The patch affects build.rs, adds the symlink, and modifies the Makefile, all confined to the contrib/ area.
