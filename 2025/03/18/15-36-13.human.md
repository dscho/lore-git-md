This is the second patch in a performance optimization series for bundle-uri reference negotiation, specifically focusing on tag handling tests. The series expands bundle-uri's reference copying to handle all ref namespaces (not just heads) while preserving hierarchy, which has shown significant performance improvements in fetches.

The current patch adds test coverage for tag handling, which was a point of discussion in earlier iterations. It creates a test repository with multiple branches and tags, bundles it, then verifies that cloning with the bundle properly preserves the tag references under `refs/bundles/tags/`. The test checks that all expected tags (A, B, and tag-A) appear in the correct location after cloning.

This follows the agreed-upon patch organization from earlier feedback, where the first patch handled the reference expansion core changes while this second patch focuses specifically on tag verification. The test appears thorough, covering both creation and verification of tags in the new bundle-uri workflow. With this addition, the series now has comprehensive test coverage for all reference types in the bundle negotiation optimization.
