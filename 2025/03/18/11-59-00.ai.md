This is part 8/9 of the `the_repository` removal effort, converting `builtin/checkout-index.c` to use explicit repository parameters. The patch follows the established pattern seen in previous conversions in this series, removing `USE_THE_REPOSITORY_VARIABLE` and updating the code to work with an explicit `repo` parameter.

Key changes include:
- Removing the global `the_repository` dependency from `checkout_file()` and `checkout_all()` by passing the `index_state` directly
- Converting `git_config()` to `repo_config()`
- Updating repository-specific operations to use the passed `repo` parameter
- Adding test coverage for `-h` help output behavior in both repository and non-repository contexts

The conversion maintains the same careful approach seen throughout the series, with mechanical changes that don't alter observable behavior. The patch includes a new test case verifying that `checkout-index -h` works correctly both inside and outside a Git repository, matching the testing pattern established in earlier patches. The changes touch core checkout-index functionality but are focused on internal API modernization rather than behavior changes.
