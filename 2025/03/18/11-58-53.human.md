This is a refactoring patch that's part of the ongoing effort to handle repository-less cases more gracefully in Git commands. It modifies `repo_config()` to accept NULL repository pointers, falling back to reading only system and global configs via `read_very_early_config()` when no repository is available.

The change enables builtin commands to work in repository-less contexts (like when showing help with `-h`) while still accessing basic configuration. The patch includes clear documentation explaining this behavior and its limitations, noting that per-repo configs and `-c` overrides are skipped in NULL-repo cases.

The implementation is straightforward - just a NULL check and fallback path in `config.c` plus thorough documentation in `config.h`. The commit message references future commits that will build on this change, suggesting this is part of a larger series (positioned as 1/9). The patch carries suggestions and mentorship from established contributors, indicating it's been vetted.
