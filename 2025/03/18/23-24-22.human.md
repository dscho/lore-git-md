Build system patch for Rust integration, final part of a series addressing libgit-sys packaging. This fourth patch reduces the size of the packaged crate by excluding unnecessary directories (documentation, tests, GUI components) from the git-src symlink, helping stay under crates.io's 10MB limit. The changes include:

1. Adding an exclusion list in Cargo.toml for directories not needed to build libgitpub.a
2. Introducing a new `libgit-pkg-clean` Makefile target that removes test and fuzzing directories
3. Disabling optional components (gitweb, Perl, Tcl/Tk) during build

The patch maintains the separation between Rust and C build systems while optimizing for packaging constraints. It builds on previous work in the series that established the git-src symlink approach and parallel build support. The changes are confined to contrib/libgit-sys/ and related build infrastructure without affecting core Git functionality.
