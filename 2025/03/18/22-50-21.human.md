This is part of the refspec API refactoring series, following the earlier decision to simplify the `struct refspec`'s `fetch` field from an enum to a boolean. Taylor Blau's patch replaces the generic `refspec_init()` function with two specialized variants: `refspec_init_fetch()` and `refspec_init_push()`. This makes the code's intent clearer by eliminating the need for a boolean parameter that could be misinterpreted.

The change is mechanical but meaningful - it updates callers across multiple files (`refspec.c`, `remote.c`, and `transport-helper.c`) to use the new functions. The implementation uses `REFSPEC_INIT_FETCH` and `REFSPEC_INIT_PUSH` macros to initialize the structs, which helps maintain consistency. This is the second patch in a 4-part series that's already been reviewed and merged, representing the final cleanup of the refspec API modernization effort that was part of broader protocol v2 fetch behavior improvements.
