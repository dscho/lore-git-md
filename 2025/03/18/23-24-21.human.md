This is a build system patch in a series improving Rust integration for Git. It's the third of four patches addressing libgit-sys crate packaging issues.

The patch enables parallel builds by properly passing Cargo's jobserver flags to Make when building the libgit-sys component. The change modifies build.rs to forward the CARGO_MAKEFLAGS environment variable to both Make invocations, allowing Cargo build system to coordinate parallel job execution with Git's Makefile.

The implementation is straightforward - just three lines adding the flag passing to existing Make command setups. This follows naturally from the previous patches in the series that established the build infrastructure. The change should provide noticeable speed improvements for developers building the Rust components without introducing new complexity or side effects.

As part of an ongoing effort to improve Git's Rust integration, this patch appears well-contained and low-risk, focusing specifically on build performance without altering core functionality. The series remains focused on build system improvements in the contrib/ area.
