This is part 2 of a 9-patch series in the ongoing `the_repository` removal effort, focusing on converting `builtin/verify-tag.c` to use an explicit repository parameter instead of the global variable.

The patch removes `the_repository` usage from the verify-tag command, passing the repository` parameter through to `repo_config()` and `repo_get_oid()`. The change is straightforward but includes a thoughtful addition - a new test case verifying that `git verify-tag -h` works both inside and outside a Git repository (when `repo` would be NULL). This demonstrates good attention to edge cases in the conversion.

The change is part of a larger, well-organized series that's methodically removing `the_repository` usage across Git's codebase. The patch maintains existing functionality while modernizing the code to use the preferred repository parameter pattern. The test addition provides confidence that the help text display (a common case that exercises the NULL repo path) continues to work as expected.
