This is the first patch in a series addressing build issues with the libgit-sys Rust crate, part of Git's Rust integration effort. The patch moves the libgitpub component from contrib/libgit-sys to a new contrib/libgitpub directory, making structural changes to support better Cargo packaging.

The change involves updating Makefile references and build.rs paths to point to the new location, along with moving and updating the public_symbol_export files. The motivation is to better separate dependencies built with Git's Makefile from the Cargo-managed parts, which will allow `cargo package` to handle the non-Rust source as a distinct tree.

This appears to be a straightforward refactoring with no behavior changes, just path updates. It's part of a larger effort to unblock libgit-rs packaging, with subsequent patches in the series addressing more complex build system issues. The patch looks clean with appropriate updates to all affected paths and build configurations.
