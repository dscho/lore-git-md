This thread continues René Scharfe's ongoing effort to eliminate Git's global `the_repository` variable by converting builtin commands to use explicit repository parameters. The series now stands at 7/9 patches completed, with the latest converting `for-each-ref` following the established pattern seen in previous conversions of `verify-tag`, `verify-commit`, `send-pack`, `pack-refs`, and `ls-files`.

Each conversion follows a rigorous approach: removing the `USE_THE_REPOSITORY_VARIABLE` macro, updating `git_config()` calls to `repo_config()`, and carefully handling NULL repository contexts - particularly for command help output. The `for-each-ref` patch maintains this consistency, adding tests to verify the `-h` help output works correctly both inside and outside a repository. 

The series demonstrates mechanical but careful architectural cleanup, with each patch building on prior work while maintaining existing functionality. Two preparatory changes have already been merged, including one that made a NULL check in `update-server-info` obsolete (addressed in patch 9/9). The remaining conversions continue this systematic elimination of `the_repository` usage across Git's builtin commands.
