Build system patch moving libgitpub components to contrib/ directory as part of Rust integration effort. This first patch in a 4-part series relocates the libgitpub build artifacts from contrib/libgit-sys/ to contrib/libgitpub/ to better separate Cargo-managed and Makefile-built components. The changes are mechanical - updating Makefile paths, build.rs references, and include paths. The motivation is to enable proper `cargo package` operations by clearly separating dependency trees. No functional changes are introduced, just the directory structure adjustment. This appears to be foundational work for subsequent patches that will address parallel builds and packaging issues in the libgit-sys crate. The patch touches build configuration files and symbol export infrastructure but doesn't modify any core Git functionality.
