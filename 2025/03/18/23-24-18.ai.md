This is a cover letter for a patch series addressing build issues with the libgit-sys Rust crate, part of the ongoing Rust integration effort. The series aims to fix problems with `cargo package` operations, which are currently broken for this crate.

The most notable change comes in patch 2, which introduces a requirement to clean the Git worktree during libgit-sys builds - an unfortunate side effect that the author explicitly calls out for discussion. The series also includes parallelization improvements and directory exclusions to optimize the build process.

Key technical details for future reference:
- Moves libgitpub to a separate contrib/ directory (patch 1)
- Adds git-src symlink and post-build cleanup (patch 2)
- Implements Cargo jobserver support for parallel builds (patch 3)
- Excludes unnecessary directories from git-src (patch 4)
- Touches build configuration, symlink handling, and parallel build infrastructure

The author notes that libgit-rs packaging remains broken until this libgit-sys work is published first. The changes appear focused and technically sound, though the worktree cleaning requirement in patch 2 seems likely to generate discussion about alternative approaches.
