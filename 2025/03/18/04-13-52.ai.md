Performance enhancement for incremental MIDX bitmaps (pack-reuse optimization).

This patch modifies pack-reuse behavior in `pack-bitmap.c` to properly handle incremental MIDX layers when reusing packfile contents. The key changes are:

1. Extends pack enumeration to consider all packs across MIDX layers (base + current) when doing multi-pack reuse, by adding `num_packs_in_base` to the iteration count.

2. For single-pack reuse cases, now walks the MIDX chain to find the oldest layer's preferred pack (rather than just using the current layer's), since older packs are likely to contain more reusable content. This is done via a new `while (m->base_midx)` traversal loop.

The implementation maintains the existing error handling patterns but adds new warning messages specific to the incremental MIDX context. The changes are focused on the `reuse_partial_packfile_from_bitmap()` function, with careful attention to maintaining the existing control flow while extending it for the multi-layer case.

This builds directly on the incremental MIDX bitmap infrastructure established in earlier patches, particularly the base layer handling from patch 03/13. The modification is performance-oriented, aiming to maximize pack-reuse efficiency across MIDX layers while maintaining correctness.
