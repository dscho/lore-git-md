Refactoring patch introducing a helper function for HTTP configuration.

This is the first of three preparatory patches in a series adding TCP keepalive configuration options. It introduces a new helper function `set_long_from_env()` to handle environment variable parsing into long integers, cleaning up existing code that manually handled `GIT_HTTP_LOW_SPEED_LIMIT` and `GIT_HTTP_LOW_SPEED_TIME` parsing.

The change replaces two nearly identical code blocks that previously used temporary variables and manual `strtol()` calls with calls to the new helper. The implementation follows the pattern of the existing `set_from_env()` function but handles numeric conversion. This refactoring serves both to reduce code duplication and to prepare for future additions that will need similar environment-to-long parsing, particularly for the upcoming TCP keepalive settings.

The patch is focused and mechanical, touching only http.c with straightforward changes to the `http_init()` function. While small in scope, it demonstrates good hygiene of factoring out common patterns before adding new functionality that will use them. The commit message provides clear historical context about the 2009 introduction of `set_from_env()` and how this change builds on that pattern.
