This is a documentation and build system patch that fixes an oversight in the build configuration. Phillip Wood points out that when the BreakingChanges.txt documentation was added last year to announce upcoming breaking changes, it wasn't properly integrated into the build system. The patch adds the file to both the Makefile and meson.build configurations under the TECH_DOCS target, ensuring it will be built alongside other technical documentation.

The change is straightforward and clearly correct - it simply adds the missing build entries for a file that was already committed to the repository. The patch follows the established pattern used for similar documentation files like DecisionMaking and ReviewingGuidelines. This appears to be a minor but useful housekeeping fix that ensures the BreakingChanges documentation will be properly included in built documentation sets.
