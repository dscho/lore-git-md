Documentation patch for incremental MIDX bitmaps, part of Taylor Blau's ongoing series implementing layered bitmap support for multi-pack indexes. This first patch in the 13-part v4 series establishes the technical documentation for the feature, describing the pseudo-pack ordering rules and bitmap structure for incremental MIDX layers.

The documentation explains the global pseudo-pack ordering that spans MIDX layers, with objects from earlier layers sorting before later ones, and within layers following pack/MIDX ordering rules. It details how reachability bitmaps will work across layers, with each layer potentially having its own bitmap file while maintaining position consistency through the global ordering. The text notes current limitations (like no layer compaction yet) and implementation choices (like OR'ing type-level bitmaps rather than recursive lookups).
