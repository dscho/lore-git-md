This is a documentation patch series (34 parts) continuing the conversion of Git's documentation from *.txt to *.adoc (AsciiDoc) format. The series follows up on a previous effort to rename documentation files, fixing remaining references to the old *.txt filenames throughout the codebase.

The first patch fixes a test issue where t0450-txt-doc-vs-help.sh was skipping all tests due to outdated filename references. It renames the test data directory from "txt-help-mismatches" to "adoc-help-mismatches" and updates the test script accordingly. The remaining patches systematically update references to *.txt files in various documentation files, header files, test scripts, and build system components to point to their *.adoc counterparts.

The changes span across multiple areas of the codebase including core documentation (CodingGuidelines, MyFirstContribution), technical documentation (partial-clone, hash-function-transition), header files (advice.h, diff.h, transport.h), test infrastructure (t6012, t6434), and build system (Makefile, .gitattributes). The series also removes an unneeded .gitattributes file in the Documentation directory that was specific to the old *.txt files.

This appears to be a mechanical but thorough update to complete the documentation format transition, touching many files with straightforward filename reference updates. The test fix in the first patch suggests the author verified at least some of the changes against the test suite. The series doesn't introduce new functionality but ensures documentation links remain accurate after the format migration.
