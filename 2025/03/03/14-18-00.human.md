This is a test modernization patch from a GSoC contributor, part of an effort to improve consistency in Git's test suite. The patch replaces direct shell file/directory existence checks (`test -f`, `test -d`) with Git's dedicated test helpers (`test_path_is_file`, `test_path_is_dir`) across several test files, primarily in the chainlint test suite but also touching some interop, httpd, and performance test scripts.

The changes are mechanical substitutions that don't affect test behavior, but improve readability and maintainability by using Git's standard test idioms. The author has verified the changes don't break anything by running the test suite. This appears to be a straightforward, well-scoped improvement - the patch is cleanly focused on test infrastructure modernization without introducing new functionality or behavior.
