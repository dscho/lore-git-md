This is part 14/34 of the documentation format conversion series, updating references from *.txt to *.adoc files. This patch specifically fixes a developer note in builtin.h that incorrectly referenced the old .txt format for new command documentation.

The change is straightforward, updating a comment that tells developers where to document new commands from `Documentation/git-foo.txt` to `Documentation/git-foo.adoc`. This maintains consistency with the project's move to AsciiDoc format for all documentation.

Like previous patches in the series, this is a mechanical change with no functional impact, just ensuring documentation references point to the correct modern format. The patch follows the established pattern of the series, showing careful attention to catching references even in code comments and header files.
