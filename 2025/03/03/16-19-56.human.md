This is a small but important patch in the `git-diff-pairs` plumbing command development, specifically addressing status resolution control in the diff machinery.

The patch introduces a new `skip_resolving_statuses` flag in `struct diff_options` that prevents `diffcore_std()` from automatically resolving file pair statuses when set. This is particularly useful when status information has been manually set (as in the new `git-diff-pairs` command) and should be overwritten. The change is minimal - just two lines of code plus documentation - but provides the final architectural piece needed for status preservation in the new plumbing command.
