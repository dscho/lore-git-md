This is a refactoring patch in the ongoing documentation format conversion series, specifically removing a now-redundant `.gitattributes` file. 

The patch deletes `Documentation/.gitattributes` which contained a single line setting whitespace rules for `.txt` files. The rationale is that these rules are already covered by the top-level `.gitattributes` file, making the Documentation-specific version unnecessary. The commit notes this file hasn't been modified since its introduction in 2008.

This change aligns with the broader series converting documentation from `.txt` to `.adoc` format, though it's a standalone cleanup rather than part of the format conversion itself. The removal is safe as the whitespace handling for documentation files will continue working via the top-level configuration. The patch demonstrates good attention to detail by catching this legacy file while working through documentation-related updates.
