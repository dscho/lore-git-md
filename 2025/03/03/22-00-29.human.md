Test patch completing the `--subject-extra-prefix` series for `git format-patch`. This is the sixth and final patch in the RFC series that adds a new flag to help mentoring program participants clearly mark their contributions in email subjects.

The patch adds comprehensive tests for the new `--subject-extra-prefix` functionality, verifying it works correctly in various scenarios. It tests the basic case of adding an extra prefix, plus combinations with other format-patch flags like `--rfc`, `-n` (numbering), and `-v` (version). It also confirms the expected incompatibility with `-k/--keep-subject` that was enforced in an earlier patch.

The tests follow Git's standard testing patterns, using `test_expect_success` for valid cases and `test_expect_failure` for the invalid `-k` combination. Each test case checks the exact Subject line format produced, with the extra prefix appearing before the standard patch prefix in the expected "[EXTRA][PATCH]" format.
