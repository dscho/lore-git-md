This is the final patch in a 7-part series implementing partial reference updates in Git's transaction system. The patch adds a `--allow-partial` flag to `git update-ref --stdin` mode, letting users to continue with successful updates even if some individual reference updates fail due to user input errors (like invalid refnames or incorrect old OIDs). System errors like I/O failures still abort the entire transaction.
