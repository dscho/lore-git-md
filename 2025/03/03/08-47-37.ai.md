This is part 8/12 of the `the_repository` removal series, focusing on `object-file-convert.c`. The patch eliminates global repository usage in object file conversion functions by:

1. Adding a `struct repository *` parameter to `convert_object_file()` and propagating it through all internal conversion functions (`convert_tree_object()`, `convert_tag_object()`, `convert_commit_object()`)
2. Removing the `USE_THE_REPOSITORY_VARIABLE` define since it's no longer needed
3. Updating all callers (in `builtin/tag.c`, `commit.c`, and `object-file.c`) to pass `the_repository` explicitly

The changes follow the established pattern seen in previous patches of the series, making repository dependencies explicit while maintaining behavior. Key technical points include:
- Conversion functions now use the passed repository for OID mapping via `repo_oid_to_algop()`
- All object types (commit, tree, tag) are handled consistently with repository parameter passing
- The changes affect object conversion during signing (`builtin/tag.c`), commit extra headers (`commit.c`), and various object file operations (`object-file.c`)

This continues the systematic elimination of `the_repository` usage, now covering object format conversion paths.
