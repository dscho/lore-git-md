Documentation test fix in the AsciiDoc conversion series. This is the first patch in a 34-part series converting Git's documentation references from *.txt to *.adoc files.

Todd Zullinger fixes a critical issue in t0450-txt-doc-vs-help.sh where the test was silently failing after the AsciiDoc conversion. The test checks for consistency between command-line help (-h) and documentation files, but was still looking for *.txt files after they had been renamed to *.adoc. The patch updates all references in the test script and renames the mismatch tracking directory accordingly.

Junio Hamano notes this was a serious oversight that could have slipped through, as the test wasn't actually checking anything after the file extension change. The fix ensures the test properly validates documentation consistency again, which is particularly important during the ongoing documentation format transition.

The changes are mechanical but important - updating variable names (txt→adoc), file paths, and test descriptions throughout the script while maintaining all the same functionality. This provides a solid foundation for the rest of the series which will update documentation references across the codebase.
