This is a build system patch addressing cross-compilation support in the Meson build configuration. It distinguishes between build-host and target-host binaries, which becomes important when cross-compiling Git.

The patch modifies how Git's Meson build system locates binaries like `sh`, `python`, and `perl`. Currently, it doesn't properly handle cross-compilation scenarios where the build machine and target machine may have different paths for these binaries. The changes introduce explicit `native: true/false` parameters to `find_program()` calls to properly separate build-time tools from target-system binaries that get embedded in the final Git executable.

Key technical changes include:
- Adding `native: true` to all build-time tool searches (like `asciidoc`, `xmlto`, etc.)
- Introducing new `target_*` variables (`target_shell`, `target_python`, `target_perl`) for the target system versions
- Updating configuration templates to use the target versions where appropriate
- Adding documentation about cross-compilation in the Meson build file

The patch appears well-motivated by a real cross-compilation use case and is part of ongoing Meson build system improvements. It touches several build files but focuses specifically on the binary path distinction needed for proper cross-compilation support. The changes are surgical and maintain backward compatibility when not cross-compiling.
