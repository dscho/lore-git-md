Part of the ongoing `the_repository` removal effort, this patch focuses on the csum-file subsystem. Patrick Steinhardt refactors the checksum file handling code to remove its dependency on the global `the_repository` variable by explicitly passing hash algorithm parameters instead.

The changes touch core checksum functionality used across multiple Git commands including fast-import, index-pack, and pack-objects. The patch modifies the hashfile API to accept a `struct git_hash_algo*` parameter, then updates all callers to pass either `the_repository->hash_algo` (for code still using the global) or their own repository's hash algorithm. This maintains compatibility while moving toward the larger goal of repository independence.

The changes are mechanical but widespread, affecting 14 files with mostly straightforward parameter additions. The patch appears well-executed, with each callsite carefully updated to maintain existing behavior. This is a typical incremental step in the multi-year effort to eliminate `the_repository` usage across Git's codebase.
