This thread documents the implementation of build-time conditional handling for deprecated Git features when configured with `WITH_BREAKING_CHANGES`. The main patch established a pattern for conditionally documenting deprecated repository layout features (`.git/branches` and `.git/remotes` directories) by introducing a `with-breaking-changes` AsciiDoc attribute and modifying both Makefile and Meson build systems. Phillip Wood implemented this solution with support from Junio Hamano and Patrick Steinhardt, creating a reusable approach for future deprecations.

A follow-up bugfix patch from Junio Hamano addresses an inconsistency in how the build system handles the deprecated `git pack-redundant` command. While the command was already excluded from compilation with breaking changes, it wasn't properly marked in `EXCLUDED_PROGRAMS`, causing documentation checks to flag it incorrectly. The small but important fix ensures the build system fully implements the deprecation, though a remaining issue with the command's presence in `git help git` output will need separate attention.
