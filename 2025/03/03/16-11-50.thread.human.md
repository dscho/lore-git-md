This thread documents a change to Git's build system and documentation as part of the ongoing effort to phase out deprecated repository layout features (the `.git/branches` and `.git/remotes` directories). The patch conditionally includes documentation about these legacy features based on whether Git is built with `WITH_BREAKING_CHANGES` enabled by default.

The implementation introduces a new Asciidoc attribute `without-breaking-changes` that mirrors existing test infrastructure, though Phillip Wood has raised concerns about the potentially confusing double-negative syntax (`ifdef::!without-breaking-changes[]`). The changes touch build configuration files for both Make and Meson builds, along with the repository layout man page.

While technically straightforward, the patch may prompt discussion about the attribute naming scheme. The change maintains consistency with prior test infrastructure work (commit c5bc9a7f94a) and represents another step in the gradual removal of these legacy directory features.
