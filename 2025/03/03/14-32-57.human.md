Build system fix for documentation generation. This is a follow-up to Phillip Wood's earlier patch that fixed an oversight in the Meson configuration when the project switched from `.txt` to `.adoc` file extensions for AsciiDoc documentation. The original patch updated the main `meson.build` file but missed the ones in the `technical/` and `howto/` subdirectories, causing HTML documentation builds to fail.

Patrick Steinhardt had reviewed the initial patch and suggested considering making documentation builds part of the default Meson configuration to catch such issues earlier. In this response, Phillip agrees with that broader idea but suggests focusing first on getting this straightforward fix into the upcoming release, with CI changes to follow later.

The change is low-risk and uncontroversial, simply updating file extensions to match the project's documentation format transition. It affects 44 documentation files across technical docs and howtos, plus generated index files. The patch maintains consistency with the main Documentation directory's build configuration and follows the pattern established in commit 1f010d6bdf7.
