This is a bugfix for an inconsistency between documentation and help text in the `git refs migrate` command. Junio Hamano points out that while reviewing Todd Zullinger's earlier patch about test documentation, he noticed `git refs migrate`'s help text was missing the `--no-reflog` option that exists in the documentation.

The patch is a one-line change to `builtin/refs.c` adding the missing option to the command's usage string. This appears to be a straightforward correction of an oversight, though it's notable that the inconsistency made it into `master`. The change aligns with the thread's theme of documentation accuracy, though it's a separate issue from the main *.txt to *.adoc conversion series being discussed.
