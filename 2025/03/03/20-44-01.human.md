Housekeeping patch in the documentation format conversion series. This is patch 3/34 in Todd Zullinger's series updating Git's documentation references from .txt to .adoc format.

The patch removes Documentation/.gitattributes, which contained a single whitespace rule for .txt files that is now redundant. The rule was originally added in 2008 to enforce whitespace policies, but the same rule exists in the top-level .gitattributes file. The Documentation-specific file hasn't been modified since its creation, suggesting it was never needed as a separate file.

This is a straightforward cleanup that follows logically from the documentation format conversion - with .txt files being replaced by .adoc files, the .txt-specific rule in Documentation/.gitattributes becomes obsolete. The change is small and mechanical, aligning with the rest of the series' focus on updating documentation infrastructure.
