[PATCH v4 0/12] object: reduce use of `the_repository` in object APIs

Patrick Steinhardt's comprehensive series eliminating global `the_repository` usage across object subsystems is now complete with the conversion of `null_oid()`. The 134-file series (860+ insertions, 760 deletions) has systematically removed repository globals from all major object-related subsystems, with this final patch addressing the last dependency in `null_oid()` by requiring explicit hash algorithm parameters. Key achievements include:

Core technical conversions:
- Complete removal of `the_repository` from object APIs

- Hash algorithm implementations structurally reorganized
- `null_oid()` converted to take explicit `git_hash_algo*` parameter (48 call sites updated)
