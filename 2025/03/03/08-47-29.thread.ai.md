[PATCH v2 0/12] object: reduce use of `the_repository` in object APIs

Series by Patrick Steinhardt systematically eliminates global `the_repository` usage across object-related APIs in 12 patches covering csum-file.c, object.c, pack-write.c, pack-check.c, core.bigFileThreshold conversion, pack-revindex.c, pack-bitmap-write.c, object-file-convert.c, delta-islands.c, hash algorithm refactoring, hash.c warning fixes, and final `null_oid()` conversion. Builds on previous efforts to remove implicit repository state while maintaining behavior.

Key technical progress:
1-11/12: Previous conversions remain complete and stable
12/12: `null_oid()` conversion:
- Updates 48 files with 135 insertions and 136 deletions
- Converts call sites to pass `the_hash_algo` explicitly
- Maintains special cases for repository-independent subsystems (grep, refs/debug)
- Handles `diff-no-index.c` edge case
- Removes `USE_THE_REPOSITORY_VARIABLE` from hash.c
- Preserves null OID behavior while removing repository dependency
