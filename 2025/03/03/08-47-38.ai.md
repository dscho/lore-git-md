This is part 9/12 of the `the_repository` removal series, focusing on the delta-islands subsystem. The patch removes global repository usage from delta-islands.c by:

1. Adding a `struct repository *` parameter to `propagate_island_marks()`, the only function that previously lacked repository context
2. Converting all remaining implicit `the_repository` usage to explicit repository parameters, including:
   - Progress reporting via `start_progress()`
   - Config access via `repo_config()`
   - Reference iteration via `get_main_ref_store()`
   - Commit parsing via `repo_parse_commit()`
   - Tree access via `repo_get_commit_tree()`

The changes affect three files (delta-islands.c, delta-islands.h, and builtin/pack-objects.c) with straightforward mechanical conversions. The patch maintains the existing delta-islands functionality while properly plumbing the repository context through from callers. This continues the series' pattern of methodically removing global state dependencies while preserving behavior. The delta-islands changes are particularly notable as they touch the pack-objects optimization path, though the impact should be neutral since we're just passing through `the_repository` where it was previously used implicitly.
