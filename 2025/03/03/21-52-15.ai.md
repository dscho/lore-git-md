This is a test fix that was part of a larger documentation conversion effort. The patch updates t0450-txt-doc-vs-help.sh to work with the new *.adoc documentation files after the project-wide transition from *.txt to AsciiDoc format. 

The test was silently failing because it was still looking for *.txt files after the conversion, meaning it wasn't actually checking for documentation/help mismatches. The patch systematically updates all references from "txt" to "adoc" throughout the test script, including renaming variables (builtin_to_txt → builtin_to_adoc), test descriptions, and file operations. It also renames the txt-help-mismatches directory to adoc-help-mismatches while preserving its contents.

Junio Hamano notes this was an important catch, as the test's silent failure meant the project wasn't verifying documentation consistency during the conversion process. The fix ensures the test coverage is restored for validating that command help text matches the corresponding AsciiDoc documentation. This was the first patch in a 34-part series that completed the documentation format transition across the entire codebase.
