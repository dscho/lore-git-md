This is part 7/12 of the ongoing series to remove `the_repository` global usage, focusing on the pack-bitmap-write subsystem. Patrick Steinhardt continues René Scharfe's systematic effort by converting `pack-bitmap-write.c` to use repository-specific contexts rather than the global variable.

The patch adds a `repo` field to `struct bitmap_writer` and updates all affected functions to use this repository pointer instead of `the_repository`. Changes include:
- Removing the `USE_THE_REPOSITORY_VARIABLE` define
- Converting hash algorithm access from `the_hash_algo` to repository-specific versions
- Updating trace2 calls and progress reporting to use the writer's repository
- Adjusting tree and object lookups to use the correct repository context

The changes are mechanical but thorough, touching bitmap writing, lookup tables, and checksum handling. The patch maintains existing behavior while making repository usage explicit, following the established pattern from earlier parts of the series. This continues the project's clean separation of concerns while working toward pluggable object database support.
