This is a test fix as part of the ongoing documentation conversion effort from *.txt to *.adoc format. The patch updates t0450-txt-doc-vs-help.sh to properly test documentation consistency after the AsciiDoc migration. 

The test was silently passing because it was still looking for *.txt files that no longer exist after the format change. The fix renames all references from "txt" to "adoc" in the test script, including renaming the test data directory from txt-help-mismatches to adoc-help-mismatches. 

The changes are mechanical but important - they ensure the test actually verifies that command help text matches the corresponding documentation, which is a key quality check. This is the first patch in a 34-part series completing the documentation format transition, showing the project's commitment to maintaining test coverage through large-scale changes.
