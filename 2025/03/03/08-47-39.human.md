This is part 10 of a 12-part series removing `the_repository` usage from object-related APIs, focusing on hash algorithm implementation. Patrick Steinhardt splits out the hash algorithm implementation from `object-file.c` into a new `hash.c` file, keeping the same functionality but improving code organization.

The patch is purely a code movement - all hash-related functions and data structures (including SHA-1 and SHA-256 implementations, empty tree/blob OIDs, and algorithm lookup functions) are relocated verbatim from `object-file.c` to the new `hash.c`. The change makes the hash subsystem's implementation easier to find by matching its physical location to its logical grouping in the `hash.h` header.

This continues the series' pattern of mechanical but careful changes that improve code structure while maintaining behavior. The patch appears straightforward with no functional changes - it updates the Makefile and meson.build to include the new file while removing the code from object-file.c. The change helps future work on the hash subsystem by giving it a dedicated home.
