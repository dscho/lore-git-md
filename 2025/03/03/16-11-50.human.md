This is a documentation patch that aligns the repository layout documentation with recent breaking changes in Git's build configuration. 

Phillip Wood fixes an inconsistency where the documentation still described the deprecated `.git/branches` and `.git/remotes` directories even though support for them was removed when building with `WITH_BREAKING_CHANGES` in commit 8ccc75c2452. The patch introduces a new AsciiDoc attribute `without-breaking-changes` to conditionally include these sections, matching the test prerequisite naming from c5bc9a7f94a.

The change affects both Makefile and meson build systems, ensuring the documentation accurately reflects the available features based on build configuration. Wood notes some reservations about the double-negative naming convention (`!without-breaking-changes`) but maintains consistency with the test infrastructure. This is a straightforward documentation update that keeps the docs in sync with actual behavior.
