This thread reports two distinct problems encountered after a distribution switched to using Git's meson build system. The meson build appears to incorrectly handle the default template directory path (`DEFAULT_GIT_TEMPLATE_DIR`), causing missing hook templates that users to manually configure. Additionally, there's an inconsistent runtime assertion failure in `exec-cmd.c` when running Git from chroot environments without absolute paths.

The issues were reported by a distribution maintainer who notes the template directory problem seems like an oversight that should have been caught by tests. While the chroot issue may be environment-specific, the template path problem appears to be a legitimate meson build system bug affecting default installation behavior. The reporter provides reproduction steps but hasn't yet proposed fixes. These are the first reported issues in what appears to be a new thread.
