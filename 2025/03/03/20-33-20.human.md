This is a bug report and platform compatibility issue regarding the Meson build system and Git's behavior in chroot environments.

Steffen Nurpmeso reports two distinct problems. First, they noticed that Git installations built with Meson are missing template directories, causing warnings about missing templates. The issue appears to be that the Meson build isn't properly setting the `datadir` path for template directories, though the commit message doesn't provide full technical details about the build configuration.

Second, they describe a separate issue where Git fails with an assertion error when run in a chroot environment on btrfs, specifically when trying to check out a branch. The error occurs in `exec-cmd.c` with an assertion failure about `executable_dirname`. Interestingly, the problem doesn't manifest when using the full path `/usr/bin/git` or in some chroot scenarios, suggesting some path resolution fragility.

The report is somewhat fragmented - it combines two unrelated issues and includes personal commentary about build system preferences. The template directory issue seems like a legitimate Meson build system bug that might affect distributions, while the chroot problem appears to be a more niche platform-specific edge case. Neither issue includes proposed patches - this is purely a problem report.
