Thread summary:

Documentation patch addressing build-time breaking changes for deprecated repository layout features (`.git/branches` and `.git/remotes` directories) when building with `WITH_BREAKING_CHANGES`. The patch conditionally includes documentation sections about these deprecated features based on the build configuration, introducing a new Asciidoc attribute `without-breaking-changes` that mirrors the existing test prerequisite. Phillip Wood has expressed reservations about the double-negative naming scheme (`ifdef::!without-breaking-changes[]`).

The implementation touches three files: `Documentation/Makefile` (adds the attribute when `WITH_BREAKING_CHANGES` isn't set), `Documentation/gitrepository-layout.adoc` (wraps deprecated sections in conditional blocks), and `Documentation/meson.build` (adds equivalent Meson support). The changes maintain consistency with prior test infrastructure work (commit c5bc9a7f94a). The naming convention for the new attribute remains an unresolved discussion point, with the author acknowledging the awkwardness of the double-negative formulation. This is part of the broader effort to phase out legacy repository layout features.
