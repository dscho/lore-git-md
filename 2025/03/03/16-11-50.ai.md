Documentation patch addressing build-time breaking changes. This is part of the ongoing effort to remove deprecated repository layout features (`.git/branches` and `.git/remotes` directories) when building with `WITH_BREAKING_CHANGES`.

The patch conditionally includes documentation sections about the deprecated `branches` and `remotes` directories based on whether `WITH_BREAKING_CHANGES` is enabled. It introduces a new Asciidoc attribute `without-breaking-changes` that mirrors the existing test prerequisite, though Phillip Wood notes some reservations about the double-negative naming scheme (`ifdef::!without-breaking-changes[]`).

The changes affect three build system files:
1. `Documentation/Makefile` - adds the new attribute when `WITH_BREAKING_CHANGES` isn't set
2. `Documentation/gitrepository-layout.adoc` - wraps the deprecated sections in conditional blocks
3. `Documentation/meson.build` - adds equivalent support for Meson builds

The patch is cleanly implemented and maintains consistency with the test infrastructure changes made in commit c5bc9a7f94a. The author's note about the naming awkwardness suggests this might spark some discussion about the attribute naming convention.
