This is a build system patch addressing cross-compilation support in Git's Meson build. Patrick Steinhardt fixes an issue where the build system wasn't properly distinguishing between binaries needed during build time versus those that need to be embedded in the final Git executable for runtime use on the target system.

The key change is adding the `native:` parameter to Meson's `find_program()` calls to explicitly specify whether each program is for the build host (native: true) or target host (native: false). This matters for cross-compilation scenarios where the build and target systems may have different paths or versions of tools like sh, perl, and python. The patch carefully preserves the existing behaviors while adding the new cross-compilation capability.

The change is well-motivated by a real cross-compilation use case (referenced in the cover note) and the implementation appears thorough - it updates all relevant program lookups across the build system files. The commit message clearly explains the problem and solution, including an example cross-compilation configuration file. This seems like a solid improvement to Git's build system flexibility.
