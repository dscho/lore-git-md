Build system documentation fix queued for release. This is a follow-up to the earlier discussion about fixing Meson build files to properly handle the `.adoc` extension for documentation files. Junio Hamano confirms he will include Phillip Wood's minimal fix in the upcoming release, which updates the technical and howto documentation build rules to match the project's switch from `.txt` to `.adoc` files. The patch has been reviewed and agreed upon by both Phillip Wood and Patrick Steinhardt, with no outstanding objections.

The change is purely mechanical and addresses an oversight where some documentation wasn't being built properly when using the Meson build system with HTML documentation enabled. While there was discussion about potentially changing CI to catch such issues earlier and making documentation builds default in Meson, those larger changes are being deferred for now in favor of getting this straightforward fix into the release.

This continues the work started in commit 1f010d6bdf7 and maintains consistency with how documentation is built in the main Documentation directory. The patch is uncontroversial and ready for merging, with Junio indicating it will be included in the next release cycle.
