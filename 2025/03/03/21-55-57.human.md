This is a documentation cleanup patch in the ongoing series converting Git's documentation from .txt to .adoc format. Junio Hamano agrees with Todd Zullinger's patch to remove Documentation/.gitattributes, which contained a now-irrelevant whitespace rule for *.txt files. Since the documentation tree no longer contains any .txt files after the conversion, this attribute has no effect and can be safely removed.

The change is straightforward - it simply deletes the file containing the single line "*.txt whitespace". While Todd's commit message notes the file's history (it was added in 2008 to define whitespace policy), Junio provides additional context that the removal makes sense specifically because the .txt pattern no longer matches any files in the Documentation directory.

This is a minor but logical cleanup that follows naturally from the larger documentation format conversion effort. The patch appears correct and uncontroversial, though very small in scope compared to other patches in the 34-part series.
