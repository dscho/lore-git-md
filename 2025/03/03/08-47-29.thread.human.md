This thread documents Patrick Stehtardt's ongoing effort to eliminate the global `the_repository` variable from Git's object handling code. The current series (now at v3) systematically converts object-related subsystems to use repository-specific parameters instead of global state. The 12-patch series has already tackled core object operations, pack writing, and verification, with the latest addition being pack-revindex conversion.

The work represents a major architectural shift toward making Git's object storage more modular, particularly for future pluggable backends. Each conversion follows a careful pattern: introducing repository parameters, updating algorithm access, and maintaining existing behavior through thorough test coverage. Reviewers including Justin Tobler, Karthik Nayak, and Eric Sunshine have validated the approach, with Junio Hamano confirming resolution of a tricky interaction with `ls-files.c`.

The latest patch (6/12) focuses on pack-revindex operations, introducing repository-aware hash algorithm handling while preserving all revindex functionality. This continues the series' methodical progress - each subsystem conversion builds confidence in the overall approach. With edge cases addressed and core functionality verified, the series appears ready for potential inclusion, though some future work remains around submodule support and remaining global configuration migration.
