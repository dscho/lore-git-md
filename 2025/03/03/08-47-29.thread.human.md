Patrick Steinhardt's series to eliminate `the_repository` global variable continues to make steady progress, now completing the conversion of the pack-revindex subsystem in this latest patch. The series, which has already converted 132 files across Git's object handling code, follows a consistent pattern of replacing global state with repository-specific parameters - in this case ensuring revindex operations use the correct hash algorithm for each repository context.

The pack-revindex changes mirror earlier conversions in the series, with all revindex operations (creation, verification, and position/offset conversions) now properly repository-aware. A new helper function `ridx_min_size()` handles algorithm-specific sizing, while existing functions like `load_revindex_from_disk()` gain explicit repository parameters. The changes maintain backward compatibility while removing the last `USE_THE_REPOSITORY_VARIABLE` define from this subsystem.

With this patch, all major pack-related subsystems (write, check, revindex, and bitmap) have now been converted. The series has received thorough review from Justin Tobler, Karthik Nayak, and Eric Sunshine, with Junio Hamano having already approved earlier parts. As each new patch follows the established mechanical pattern, the series remains in good shape for eventual merging, systematically eliminating global state dependencies to support future work on pluggable backends and multiple hash algorithms.
