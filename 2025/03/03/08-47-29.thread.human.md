This thread documents René Scharfe's comprehensive effort to eliminate the use of `the_repository` global variable across Git's object-related APIs. The 12-part series systematically converts object subsystems to use explicit repository parameters, with contributions from Patrick Steinhardt and reviews from Justin Tobler. 

The work touches over 90 files, converting core object handling functions like `write_idx_file`, `write_rev_file`, and `convert_object_file` to take explicit repository parameters. Key infrastructure changes include moving `core.bigFileThreshold` config to repository-scoped storage and restructuring hash algorithm handling. The series follows a consistent pattern: identifying global state, adding parameters, updating callers, and removing unused globals.

The final patch converts `null_oid()` to take an explicit hash algorithm parameter, affecting 48 files and over 100 call sites. Justin Tobler reviewed the handling of edge cases like `diff-no-index` which operates without a repository. This completes the object API conversions, removing one of the last implicit `the_repository` dependencies and providing a cleaner foundation for future work like pluggable object storage backends. The series demonstrates Git's ongoing effort to eliminate global state while maintaining backward compatibility.
