This is an update on two ongoing performance-related topics in Git's development: cruft pack maintenance and incremental MIDX bitmaps.

Taylor Blau responds to Junio Hamano's status update, noting that the cruft pack refresh fix (which addressed objects not being properly refreshed when multiple cruft packs exist) now has a v5 version that focuses solely on the freshening bug, deferring the more complex --max-pack-size vs --combine-cruft-below-size discussion to a future series.

For the incremental MIDX bitmap work (a 15-part series enabling incremental updates to multi-pack index files), Taylor confirms it's been rerolled but requests additional review from bitmap experts before merging. He notes the changes are subtle despite being relatively compact in terms of code size, suggesting careful scrutiny would be valuable.

Both topics represent important optimizations for Git's object storage efficiency - the cruft pack fixes ensure proper maintenance of rarely-used objects, while the MIDX bitmap work improves performance for repositories using multiple packfiles. The incremental MIDX changes in particular appear to be approaching readiness, pending final review feedback.
