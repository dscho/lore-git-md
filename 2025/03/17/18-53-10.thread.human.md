The discussion centers on understanding why `git add .` doesn't leverage the same optimizations that make `git status` fast, particularly since fsmonitor and untracked cache are enabled in both cases. The report comes from a MacOS environment using Git 2.49.0, raising questions about whether this is a platform-specific issue or a more general optimization opportunity. While no specific code changes have been proposed yet, the workarounds demonstrate there may be room for performance improvements in the core `git add` implementation.
