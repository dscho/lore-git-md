This is the final cover letter for the completed 3-patch series addressing unreachable code detection in the build system. The series has evolved from initial warning enablement through platform-specific workarounds to a generalized architectural solution.

The patches now implement:
1. A macOS-specific `errno` workaround for `sigfillset()` false positives in `run-command.c` (Jeff King)
2. A new `NOT_CONSTANT` macro and compilation unit (`compiler-tricks/not-a-constant.c`) for handling false positives across control structures (Junio Hamano)
3. Final enablement of `-Wunreachable-code` in developer builds (Jeff King)

Key technical aspects include the cross-platform solution working with both Makefile and Meson builds, preservation of POSIX compliance for signal handling, and replacement of the temporary macOS workaround with the generalized approach. The series addresses Taylor Blau's concern about potential build breakage by reordering patches to first implement fixes before enabling warnings.

The cover letter notes an interesting meta-point about the limitations of shortlog output in tracking patch ordering between versions, though this doesn't affect the technical content. The solution is now been merged with all review feedback incorporated, including naming refinements (from `NOT_A_CONSTANT` to `NOT_CONSTANT`) and comment corrections.
