This is a release announcement for Git for Windows 2.49.0, marking both routine updates and some significant platform-specific changes. Johannes Schindelin announces the new version while signaling upcoming deprecations.

The most notable change is the planned phase-out of `git svn` support in Git for Windows due to maintenance challenges and low usage. Additionally, 32-bit installers (except MinGit) are being discontinued, with MinGit's 32-bit variant continuing only until April 2029. 

The release incorporates upstream Git 2.49.0 along with updated dependencies (OpenSSH 9.9.P2 and PCRE2 10.45). Two upstream features graduate from experimental status: the renamed `--name-hash-version=2` (previously `--full-name-hash`) and the newly accepted `git backfill` command with its adjusted `--min-batch-size` option.

Several Windows-specific bugs are addressed, including symlink renaming fixes, a Cygwin FAST_CWD warning resolution, a VS Code terminal hang during `git add -p`, and restored nano editor syntax highlighting. The announcement provides SHA-256 checksums for all distribution formats (installers, portable archives, and MinGit variants) across 64-bit, ARM64, and remaining 32-bit builds.
