This is a release announcement for Git for Windows 2.49.0, the Windows-specific distribution of Git maintained by Johannes Scharfe (Dscho). The release tracks upstream Git 2.49.0 while adding Windows-specific fixes and announcing two significant deprecations: git-svn support will be phased out due to maintenance burden, and 32-bit installers (except MinGit) are being discontinued immediately, with MinGit's 32-bit support itself scheduled to end in April 2029.

The release incorporates several upstream Git changes including the new `git backfill` command and the stabilization of the experimental `--full-name-hash` option (now renamed to `--name-hash-version=2`). Windows-specific fixes address issues with symlink handling, Cygwin compatibility, terminal freezes in VS Code integration, and restored syntax highlighting in the nano editor. Updated dependencies include OpenSSH 9.9.P2 and PCRE2 10.45.

The announcement provides SHA-256 checksums for all distribution formats, highlighting the project's strategic shift toward 64-bit architectures while maintaining minimal 32-bit support through MinGit until 2029. This release continues Git for Windows' pattern of tracking upstream Git releases while managing platform-specific concerns and deprecating legacy components that have become burdensome to maintain.
