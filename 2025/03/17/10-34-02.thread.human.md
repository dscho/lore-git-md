Johannes Schindelin (Dscho) announced the Git for Windows 2.49.0 release, which incorporates upstream Git 2.49.0 changes while adding Windows-specific updates. Key changes include the deprecation of git-svn (phased out due to maintenance burden) and 32-bit installers (except MinGit, which will be supported until April 2029). The release also includes stabilized --name-hash-version=2 (formerly --full-name-hash), the new git backfill command, and various Windows-specific fixes for symlink handling, Cygwin warnings, VS Code terminal freezes, and nano syntax highlighting. Dependencies were updated to OpenSSH 9.9.P2 and PCRE2 10.45. Junio C Hamano acknowledged the release with a simple "Thanks," indicating approval without further discussion. The release includes SHA-256 checksums for all distribution variants (64-bit/ARM64 installers, portable versions, and MinGit). This appears to be a routine stable release with no outstanding issues.
