The change is straightforward mechanical cleanup that improves test hygiene by:
- Eliminating duplicate functionality
- Using the more maintainable helper that cleans up temporary files
- Reducing the test script's footprint by 7 lines

This continues the series' pattern of carefully preparing test infrastructure before making behavior changes to cruft pack handling. The patch maintains identical test coverage while making the test suite more maintainable. The change is low-risk since it only affects test code and doesn't modify any production behavior.
