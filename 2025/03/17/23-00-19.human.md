Test cleanup patch in the cruft pack repacking series. This is the second of five patches that rework how `git repack` handles cruft packs, specifically the `--max-cruft-size` behavior.

Second, it removes misleading references to `--max-cruft-size` from unrelated tests that actually exercise cruft pack freshening behavior (updating mtimes for objects that already exist in cruft packs).

The changes are straightforward test improvements that don't modify any actual functionality. The patch helps separate concerns between testing cruft pack size thresholds (which will change in later patches) and testing mtime freshening behavior (which is independent). This continues the series' careful approach of cleaning up test infrastructure before modifying behavior.
