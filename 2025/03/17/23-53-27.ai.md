This is a platform compatibility patch that's part of the build system improvement series for unreachable code detection. The patch addresses a macOS-specific build failure when `-Wunreachable-code` is enabled, where clang incorrectly marks the error handling for `sigfillset()` as unreachable code since macOS's implementation always returns success.

The key technical change replaces the direct return value check of `sigfillset()` with an `errno`-based check, which works around the compiler optimization while maintaining POSIX compliance. The patch adds explanatory comments documenting why this approach is necessary and how it outsmarts the compiler's dead code analysis. The change is minimal (10 lines total) and focused on `run-command.c`.

This represents the initial workaround stage of what would later evolve into a more systematic solution (the `NOT_CONSTANT` macro approach in subsequent patches). The patch preserves error checking behavior for platforms where `sigfillset()` can fail while avoiding false positives from the compiler. The solution is technically sound but was later superseded by a more general architectural approach in the final series.
