This is a build system improvement patch that's part of a series addressing unreachable code detection warnings. The patch modifies `run-command.c` to work around a macOS-specific compiler warning about unreachable code in `sigfillset()` error handling.

The change replaces a direct check of `sigfillset()`'s return value with an `errno`-based check, since macOS's implementation always returns success (as documented) while POSIX allows for error returns. This cleverly avoids the compiler warning while maintaining correct behavior across platforms.

The patch originated from Jeff King but carries Junio Hamano's sign-off, indicating maintainer approval. It's the first of three patches in this version of the series, with the thread summary showing this was later superseded by a more systematic solution in patch 2. The change is small (10 lines) but demonstrates careful consideration of both POSIX compliance and compiler behavior.

This appears to be a well-justified, platform-specific workaround that was part of the progression toward enabling `-Wunreachable-code` warnings in Git's build system.
