This is a build system fix that follows up on a previous patch addressing Perl detection in Meson configuration. Patrick Steinhardt agrees with Eli Schwartz's solution to explicitly require Perl when documentation generation is enabled, even if Perl bindings are disabled. The patch fixes a real-world issue where documentation builds would error out when configured with `-Ddocs=man -Dperl=disabled`.

Patrick notes that while this is the correct short-term fix, there's a longer-term goal to remove the Perl dependency for documentation generation. The change is minimal and well-justified, adding documentation building to the existing list of features that require Perl (tests, gitweb, and credential helpers). The discussion remains focused on the technical solution without introducing new concerns.
