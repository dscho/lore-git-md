This is an update on the ongoing Rust crates publishing issue, part of Git's Rust integration efforts.

Josh Steadmon follows up on earlier discussions about problems publishing Rust crates to crates.io, where build system incompatibilities between Git's Makefile-based workflow and Cargo's publishing requirements have blocked progress. The core issue remains that `cargo publish` can't access the repository root during builds, preventing access to the Makefile and Git sources needed for compilation.

Steadmon reports he has preliminary fixes ready but needs to properly structure them as RFC-quality patches with explanations and alternative approaches documented. He plans to submit these to the list soon. This comes after his earlier temporary solution of publishing placeholder `libgit*` crates to prevent name squatting, which Junio Hamano had approved.

The email shows active work continuing on this technical challenge that's blocking Git's Rust integration. The proposed fixes, when submitted, will likely spark discussion about the best way to reconcile Git's build system with Rust's publishing requirements while maintaining the project's standards for code quality and maintainability.
