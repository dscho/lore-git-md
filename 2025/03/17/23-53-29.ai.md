This is the final patch in a 3-part series enabling unreachable code detection in Git's developer builds, completing the build system improvement effort. The patch adds `-Wunreachable-code` to both Makefile (`config.mak.dev`) and Meson build systems.

The motivation stems from a real bug found by Coverity that could have been caught earlier with this warning. While GCC ignores this flag (having removed the actual warning in version 4.x while keeping the option for compatibility), Clang still implements it and already runs in Git's CI pipelines, providing early detection. The patch takes the simple approach of enabling it universally since GCC safely ignores it.

Key technical details include:
- The warning was shown to catch the specific case from Jeff King's earlier investigation
- Implementation is consistent across both build systems (Makefile and Meson)
- Follows the architectural solution path established in earlier patches (rather than platform-specific workarounds)
- Maintains the series' cross-build-system compatibility goal
