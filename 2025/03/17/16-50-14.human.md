René Scharfe responds to Junio C Hamano's question about whether the upstream xdiff library is still actively developed, pointing out that the last release (version 0.23) dates back to 2008. This confirms the library appears to be stable and no longer receiving updates, which supports their earlier decision to implement a minimal fix rather than undertake a more invasive refactoring of the xdiff codebase.

The exchange is brief but provides important context about why the team chose the current solution path - since upstream development appears dormant, concerns about diff noise from larger refactorings carry less weight. This helps justify the pragmatic approach taken in the patch while leaving the door open for potential future modernization if needed.
