This is a release announcement for Git for Windows 2.49.0, marking both feature updates and significant deprecation notices. The announcement comes from the Git for Windows maintainer and includes important platform-specific updates alongside the standard Git 2.49.0 release.

The most notable changes are two deprecations: git-svn support will be phased out due to maintenance challenges and low usage, and 32-bit installers (except MinGit) are being discontinued immediately, with MinGit's 32-bit support itself scheduled to end in April 2029. The release incorporates several upstream Git changes including the promotion of the experimental `--full-name-hash` option (now `--name-hash-version=2`) and the new `git backfill` command with its renamed `--min-batch-size` option.

Several Windows-specific bug fixes are included, addressing issues with symlink renaming, Cygwin warnings on Insider Windows builds, terminal freezes in VS Code's git integration, and restoring accidentally disabled syntax highlighting in the nano editor. The release ships with updated dependencies including OpenSSH 9.9.P2 and PCRE2 10.45.

The announcement provides SHA-256 checksums for all distribution formats including 64-bit and ARM64 installers, portable versions, and MinGit variants (including both busybox and standard flavors). The continued support for 32-bit MinGit until 2029 while dropping other 32-bit packages suggests a strategic shift toward modern architectures while maintaining minimal support for legacy systems through the lightweight MinGit option.
