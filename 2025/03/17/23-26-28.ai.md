This is a refactoring patch series that concludes the refspec API modernization effort. The thread has already established consensus on converting the `fetch` field in `struct refspec` from an enum to a boolean, with Junio Hamano advocating for this simplification in earlier discussions.

The 4-patch series from Taylor Blau:
1. Converts the `fetch` field to boolean
2. Replaces `refspec_init()` with fetch/push-specific variants
3. Removes the obsolete `refspec_item_init_or_die()`
4. Replaces `refspec_item_init()` with fetch/push variants

The changes affect multiple files including `refspec.c`, `remote.c`, and fetch/pull implementations. Notably, the series accidentally includes a binary file `git-diff-pairs` which Junio points out in his brief reply.
