[Git for Windows 2.49.0 release announcement from maintainer Johannes Schindelin (Dscho). Key updates: deprecation of git-svn (phased out due to maintenance burden) and 32-bit installers (immediate, except MinGit which continues until April 2029). Incorporates upstream Git 2.49.0 changes including stabilized --name-hash-version=2 (formerly --full-name-hash) and new git backfill command with renamed --min-batch-size option. Windows-specific fixes: symlink renaming, Cygwin warnings on Insider builds, VS Code terminal freezes, restored nano syntax highlighting. Updated dependencies: OpenSSH 9.9.P2, PCRE2 10.45. Distribution includes SHA-256 checksums for 64-bit/ARM64 installers, portable versions, and MinGit variants (busybox/standard). Strategic architecture shift toward modern platforms while maintaining minimal legacy support via MinGit.]
