[Git for Windows 2.49.0 release announcement from maintainer Johannes Schindelin (Dscho), acknowledged by upstream Git maintainer Junio C Hamano. Key updates include: deprecation of git-svn (phased out due to maintenance burden) and 32-bit installers (immediate except for MinGit which continues until April 2029). Incorporates upstream Git 2.49.0 changes including stabilized --name-hash-version=2 (formerly --full-name-hash) and new git backfill command with renamed --min-batch-size option. Windows-specific fixes address symlink renaming, Cygwin warnings on Insider builds, VS Code terminal freezes, and restored nano syntax highlighting. Updated dependencies include OpenSSH 9.9.P2 and PCRE2 10.45. Distribution provides SHA-256 checksums for 64-bit/ARM64 installers, portable versions, and MinGit variants (busybox/standard). The release represents a strategic architecture shift toward modern platforms while maintaining minimal legacy support via MinGit. Junio's acknowledgment confirms the release aligns with upstream expectations and requires no further action.]
