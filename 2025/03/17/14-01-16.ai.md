Build system fix follow-up regarding Perl dependency for documentation. Patrick Steinhardt agrees with Eli Schwartz's patch that adds documentation building to the conditions making Perl mandatory in meson.build, while noting it's currently the only remaining Perl dependency in the build system. The original patch addressed a real-world Gentoo build failure where documentation generation would fail when Perl bindings were explicitly disabled but documentation was enabled. Steinhardt suggests the long-term goal would be to eliminate this Perl dependency for documentation generation, but accepts the current pragmatic solution. The discussion remains focused on this specific build system edge case without introducing new technical points.
