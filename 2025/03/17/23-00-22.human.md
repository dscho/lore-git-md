This is a test refactoring patch, part of a series improving cruft pack handling in `git repack`. 

Patch 3/5 continues the test cleanup work by removing a redundant helper function. The test script had inherited a custom `write_blob()` function when tests were moved from another file, but this duplicates the existing `generate_random_blob()` helper which has the added benefit of cleaning up after itself. The patch updates the one test that used the old helper to use the standard one instead, then removes the now-unused function.

This is a straightforward quality-of-life improvement for test maintenance, eliminating duplicate code and using the more robust existing helper. The change is mechanical and doesn't affect test behavior - it's part of the preparatory work before the series introduces substantive changes to cruft pack handling. The patch follows the series' pattern of cleaning up test infrastructure before modifying behavior, demonstrating careful attention to maintainability.
