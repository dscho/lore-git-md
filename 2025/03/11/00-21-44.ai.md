Test infrastructure cleanup in the cruft pack series.

This patch continues Taylor Blau's systematic reorganization of test infrastructure for cruft pack handling, moving three test helper functions (`generate_random_blob`, `pack_random_blob`, and `generate_cruft_pack`) from `t7704-repack-cruft.sh` to a new shared library `t/lib-cruft.sh`. The motivation is to allow these helpers to be reused by upcoming tests in `t5329-pack-objects-cruft.sh` without duplicating code.

The changes are straightforward:
1. Creates new `t/lib-cruft.sh` with the three helper functions
2. Removes them from `t7704-repack-cruft.sh`
3. Adds the library import to `t7704-repack-cruft.sh`
4. Maintains identical functionality while improving code organization

This is part of the v4 series preparing for cruft pack size threshold testing (patches 3-6). The test helpers being moved are used to create random blob content, pack it, and generate cruft packs - core functionality for testing packfile behavior. The clean separation follows established Git test patterns where reusable test helpers live in the `t/lib-*.sh` directory.

The patch maintains all existing test coverage while setting up for future tests. It's a logical step in the series' progression from object freshening fixes to size threshold handling, with the test infrastructure now better organized to support both. Reviewers should focus on whether the helper extraction is clean and whether the new library location makes sense for anticipated future uses.
