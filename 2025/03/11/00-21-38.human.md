Test reorganization in the cruft pack series.

This is the first patch in Taylor Blau's v4 series improving cruft pack handling. It moves several repack-related tests from t5329-pack-objects-cruft.sh to t7704-repack-cruft.sh, better aligning the test organization with Git's architecture. The former tests low-level pack generation (plumbing), while the latter focuses on user-facing repack functionality (porcelain).

The changes are straightforward - 250 lines of tests are moved verbatim from one file to another. The commit explains this corrects an earlier misplacement of tests that should have been written to t7704 in the first place. This appears to be pure test maintenance with no behavior changes.

The patch is part of a larger effort that includes both settled object freshening fixes and new work on pack size thresholds. While this particular change is uncontroversial, the series as a whole will need review of its new size limit handling functionality.
