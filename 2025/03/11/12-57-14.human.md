Maintenance follow-up on breaking changes infrastructure. Patrick Steinhardt responds to Junio Hamano's patch introducing the `WITH_BREAKING_CHANGES` test prerequisite, suggesting an improvement to the deprecation notice for the old `WITHOUT_BREAKING_CHANGES` flag.

The suggestion is framed as a minor documentation improvement to the test infrastructure, keeping with the thread's focus on establishing clear patterns for handling breaking changes. It doesn't challenge the technical approach but aims to make maintenance easier by providing clearer sunset guidance.
