Test infrastructure cleanup in the cruft pack series.

This patch continues the test reorganization work from the previous patch in Taylor Blau's series, focusing on cleaning up helper functions in `t7704-repack-cruft.sh`. The change removes a redundant `write_blob()` helper function that was moved from another test file, replacing its single usage with the more robust `generate_random_blob()` function that already exists in the test infrastructure. The latter has the advantage of cleaning up after itself automatically.

The modification is straightforward - it updates one test case that was using the old helper to use the preferred alternative instead, then removes the now-unused function. This is part of the broader effort to consolidate and improve the test infrastructure before introducing new cruft pack size threshold functionality in later patches.

Key technical details:
- Removes `write_blob()` helper from `t7704-repack-cruft.sh`
- Updates the 'cruft repack with --max-pack-size' test to use `generate_random_blob()`
- Maintains identical test coverage for large blob handling
- Prepares the test file for upcoming cruft pack size threshold tests

This change doesn't affect test behavior - it's purely a cleanup of test infrastructure that was identified when moving tests between files in the previous patch. The series continues to build on the established consensus around cruft pack object freshening while preparing for new functionality.
