This is a test modernization patch in the ongoing breaking changes infrastructure series, specifically addressing exit code handling in t6120 tests.

The patch fixes a test hygiene issue where several tests in t6120-describe.sh were piping the output of `git rev-list` directly into `git name-rev`, which could mask the exit status of the first command if it failed. The changes split these into two steps with intermediate files, ensuring test failures are properly detected. The affected tests include both the modern `--annotate-stdin` usage and the deprecated `--stdin` case being removed.

The changes are straightforward and mechanical - replacing pipe chains with explicit temporary file usage. This follows established test patterns and improves the reliability of the test suite. The patch maintains the same test coverage while making the implementation more robust.

Key technical details include:
- Modified tests: `name-rev --annotate-stdin` and `name-rev --stdin deprecated`
- Files changed: t/t6120-describe.sh
- Test pattern: replacing `cmd1 | cmd2` with `cmd1 >temp && cmd2 <temp`
- Maintains same grep check for deprecation warning
