This is a cover letter for a patch series addressing cruft pack behavior, specifically around object freshening and size thresholds. The series builds on previous discussion that had reached consensus on fixing object freshening in multi-cruft pack scenarios, but now introduces additional changes to handle pack size limits more gracefully.

The key change in this version is modifying how `--max-pack-size` works with cruft packs - it now allows packs to slightly exceed the size limit (by at most one object) to enable proper pack aggregation. This prevents pathological cases where small cruft packs could never combine due to strict size limits. The series also reorganizes test infrastructure, moving cruft-related test code to a shared library and cleaning up test cases.

The patches are:
1-3: Test reorganization and helper extraction
4: Core change allowing cruft packs to exceed size limits by one object
5: Simplification of cruft pack aggregation logic
6: The previously agreed-upon fix for object freshening (now rebased on top)

The author notes this is too late for the upcoming release but wants review to continue. The changes appear well-motivated, building on established consensus while addressing a newly identified limitation in pack size handling.
