This is a Git for Windows release announcement thread (not to be confused with upstream Git development). Johannes Schindelin announces version 2.49.0-rc2, which bundles upstream Git v2.49.0-rc2 along with Windows-specific updates. Key changes include: deprecation plans for `git svn` support and 32-bit installers (except MinGit which continues until 2029), updated dependencies (OpenSSH, PCRE2), and upstreamed/renamed features (`--full-name-hash` → `--name-hash-version=2`, `git backfill`'s `--batch-size` → `--min-batch-size`). Windows-specific fixes address: symlink renaming regression from v2.48.0, Cygwin warning on Insider builds, VS Code terminal hang with `git add -p`, and nano editor syntax highlighting. The announcement provides SHA-256 checksums for 64-bit, ARM64, and 32-bit distributions (installers, portable versions, MinGit). This release combines upstream updates with platform-specific maintenance while signaling upcoming deprecations in the Windows port.
