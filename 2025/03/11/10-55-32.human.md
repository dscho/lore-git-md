This is a release announcement for Git for Windows 2.49.0-rc2, marking a significant transition period for the Windows port. Johannes Schindelin announces several important changes, including the planned phase-out of `git svn` support due to maintenance challenges and low usage, and the discontinuation of 32-bit installers (though MinGit 32-bit will continue until 2029).

The release includes upstream Git v2.49.0-rc2 with notable changes like the promotion of the experimental `--full-name-hash` option to stable status (now `--name-hash-version=2`) and the upstream acceptance of the `git backfill` command with a renamed `--batch-size` option. Several Windows-specific bug fixes address issues ranging from symlink renaming to Cygwin warnings and VS Code terminal integration problems.

The announcement provides SHA-256 checksums for all distribution formats (installers, portable versions, and MinGit packages) across 64-bit, ARM64, and 32-bit architectures. This appears to be a well-prepared maintenance release that balances new features with platform-specific fixes while signaling strategic deprecations.
