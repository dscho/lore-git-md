This is a test modernization patch in the ongoing breaking changes infrastructure series.

The patch makes stylistic improvements to the t6120-describe.sh test script, specifically around the test for the deprecated `--stdin` option in `git name-rev`. Junio Hamano points out that the test's quoting style was unnecessarily complex - the test body was using double quotes while the grep pattern was single-quoted, when the more conventional approach is to single-quote the test body and double-quote the pattern. The patch also replaces the direct `grep -E` call with the preferred `test_grep` wrapper.

These changes align with the series' broader goal of modernizing test infrastructure while removing deprecated functionality. The modification maintains the same test coverage of the deprecation warning but follows Git's standard test conventions more closely. This is a minor but meaningful improvement to test hygiene that fits naturally with the other test modernization work in the series.
