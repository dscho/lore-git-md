Documentation patch for test infrastructure, part of the breaking changes infrastructure series.

The new documentation explains the lazy evaluation behavior (prerequisites are only checked when first needed), shows the SYMLINKS example as a model, and notes the temporary directory and subshell execution environment. This comes as part of a larger effort to improve test infrastructure documentation while modernizing prerequisite handling for breaking changes.

The patch is straightforward and well-contained, focusing solely on documentation improvements. It maintains consistency with existing documentation style while adding the missing information about lazy prerequisites. The example given (SYMLINKS) is a real-world case that demonstrates both the syntax and practical use of lazy prerequisites. This change supports the broader series' goal of improving test infrastructure, though it stands alone as a documentation improvement that would be valuable regardless of the breaking changes work.
