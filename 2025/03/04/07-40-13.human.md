This is an update on the reftable library decoupling effort, part of the ongoing work to make the reftable code more portable by removing Git-specific dependencies.

Johannes Schindelin reports on his attempt to test the reftable changes on Windows, which is the final blocker for merging the series. His `shears/seen` branch had fallen behind upstream by 5 updates, causing test failures unrelated to the reftable work. After manually updating the branch, he encountered CMake-related build issues and unit test failures (exit code 127) on Windows, though these appear unrelated to the reftable changes themselves.

The email suggests the core reftable decoupling work is technically sound, but Windows testing remains incomplete due to these unrelated infrastructure issues. Schindelin had to time-box his investigation, so the final verification of Windows compatibility remains pending. This continues to hold up both the reftable decoupling series and its dependent Windows-specific unlink fix.
