This thread discusses a proposal to add language-specific `.gitignore` template support to `git init` via flags like `--golang` or `--python`, aiming to streamline project setup by automatically including appropriate ignore patterns from established sources like GitHub's templates. The original RFC suggested sourcing templates from collections like Toptal's Gitignore Generator but lacked implementation details.

brian m. carlson has raised significant concerns about the proposal's feasibility, noting the vast number of languages and platform-specific variations that would need to be maintained. They emphasize Git's neutrality toward third-party sources and object to the idea of `git init` making network connections to fetch templates. While suggesting the existing `--template` mechanism could theoretically handle similar functionality, their response effectively sets a high bar for any implementation that would need to address concerns about scope, maintenance burden, and project neutrality. The discussion remains open but appears unlikely to progress without a substantially revised approach that addresses these core objections.
