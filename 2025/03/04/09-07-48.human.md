Cross-compilation build system discussion continues

Patrick Steinhardt responds to Peter Seiderer's concerns about using Meson's cross-file mechanism for specifying target-host binaries during Git cross-compilation. The core debate centers on whether cross-files should only specify build-time tools (Peter's view) or can also include target-system paths (Patrick's approach).

Patrick cites Eli Schwartz's earlier assessment that using cross-files for embedded paths is acceptable when it doesn't conflict with build-time tool requirements. He argues this unified approach allows complete cross-compilation environments to be specified in a single file, potentially enabling pre-configured machine files for platforms like Windows.

The exchange reveals two technically valid but philosophically different approaches to Meson cross-compilation configuration. Patrick maintains his position isn't rigid and invites further technical arguments for the alternative build-option approach. The discussion remains open-ended, awaiting either stronger technical justification or potential input from Meson experts to resolve the design question.
