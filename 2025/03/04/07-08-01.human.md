This is a response to a bug report about template directory issues in the meson build system. Patrick Steinhardt investigates the problem reported by a distro maintainer where hook templates were missing during `git init`.

The key finding is that the issue occurs when the meson build is configured with `-Druntime_prefix=true`, which was already fixed in commit bd262d07b65 ("meson: fix exec path with enabled runtime prefix"). Patrick provides reproduction steps showing the problem manifests only with runtime prefix enabled, and confirms the template path logic works correctly in normal builds.

He suggests either backporting the fix or disabling runtime prefix as workarounds for the distro. The response is technical but helpful, clearly identifying the root cause and solution while acknowledging the challenge of testing installation paths. This moves the thread forward by providing a concrete answer to one of the two reported meson build issues.
