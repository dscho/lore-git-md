This is a release announcement for Git v2.49.0-rc1, marking the first release candidate for the upcoming Git 2.49.0 version. The release contains 367 non-merge commits from 68 contributors (17 new), with changes spanning features, bugfixes, performance improvements, and internal refactoring.

Key user-visible changes include: a new `git backfill` command for bulk-downloading missing blobs in blobless clones; improved shallow clone support for single commits; atomic push error reporting fixes; and various completion script and documentation updates. Performance improvements center around delta-base selection via a new path-hash function option in `git pack-objects`/`git repack`.

Notable internal changes include: continued progress on removing `the_repository` global; meson build system improvements; zlib-ng compatibility work; and numerous unit test conversions to the clar framework. The release also documentarily clarifies several breaking changes planned for Git 3.0, particularly around legacy `branches/` and `remotes/` directory support.

The announcement follows Git's standard release candidate format, listing all contributors (new and returning), summarizing changes by category, and providing download locations. It represents a typical mid-cycle stabilization point where new features are largely complete and the focus shifts to bugfixes before final release.
