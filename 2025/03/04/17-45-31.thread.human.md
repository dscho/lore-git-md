Git v2.49.0-rc1 has been announced as the first release candidate for the upcoming 2.49.0 version. This release brings together contributions from 68 developers (including 17 new contributors) across 367 non-merge commits. 

The most notable user-facing changes include the introduction of `git backfill` for efficiently downloading missing blobs in blobless clones, improvements to shallow clone functionality for single commits, and fixes for atomic push error reporting. Under the hood, significant work continues on removing the `the_repository` global variable, with additional progress on the meson build system, zlib-ng compatibility, and conversion of tests to the clar framework. Performance improvements focus on delta-base selection through new path-hash function options in the packing machinery.

The announcement also documents several planned breaking changes for Git 3.0, particularly regarding legacy directory support. As with all release candidates, this marks the transition from feature development to stabilization, with the community now focused on identifying and fixing any remaining issues before final release.
