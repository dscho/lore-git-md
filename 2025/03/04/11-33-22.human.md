Test modernization: Converting trailer tests to Clar framework.

This is the first patch in a 2-part series converting Git's test infrastructure to use the Clar unit test framework. It rewrites the trailer parsing tests (previously in `t-trailer.c`) as `u-trailer.c`, maintaining all existing test cases while adopting Clar's assertion style and test organization.

The conversion splits the single test function into multiple focused test cases (like `test_trailer__empty_input` and `test_trailer__non_trailer_in_block`), making failures easier to diagnose. The tests verify trailer parsing edge cases including message formatting, divider handling, and Git's 25% trailer threshold rule. Build system files are updated to reference the new test file location.

The changes appear mechanical and well-executed, with mentoring from Patrick Steinhardt and Phillip Wood. This is part of Git's broader test modernization effort - the second patch will similarly convert URL normalization tests. The patch doesn't add new test coverage but improves maintainability through framework standardization.
