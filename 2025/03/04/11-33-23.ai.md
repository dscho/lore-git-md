This is the second patch in a 2-part test modernization series converting test files to the Clar framework, focusing on URL normalization tests. The patch follows the same pattern as the first one (which converted trailer tests), renaming `t-urlmatch-normalization.c` to `u-urlmatch-normalization.c` and rewriting the test cases to use Clar assertions.

The conversion preserves all the original test coverage while restructuring it into 11 focused test functions (previously organized under a single `cmd_main`). Key test areas include URL scheme validation, authority/port handling, escape sequence processing, UTF-8 handling, and equivalence comparisons. The test verifies both successful normalization cases and expected failures for invalid URLs.

Build system files (Makefile and meson.build) are updated to reference the new test location while removing the old one. Like the first patch, this is a pure test infrastructure change with no production code modifications, maintaining the same test coverage while adopting the project's preferred test framework.
