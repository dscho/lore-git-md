Key unresolved questions: how to address the scale/neutrality concerns if pursuing this feature, whether the UX benefit justifies maintenance overhead, and if this belongs in core Git versus external tooling. The proposal remains in RFC state with no patches yet; brian m. carlson's response establishes a high bar for any implementation that would need to reconcile these design constraints.
