Git v2.49.0-rc1 release thread with platform compatibility updates:

Thread tracks evaluation of Git 2.49.0-rc1 release candidate containing 367 non-merge commits (backfill command, shallow clone improvements, atomic push fixes, the_repository removal, meson build, zlib-ng integration, clar test framework). Primary focus remains the s390x-specific test failure in git backfill's promisor fetch count verification (test 5620.4), originally reported by Todd Zullinger. Junio Hamano acknowledged the issue warrants attention while indicating no immediate alarm, with debugging data pending.

New platform report from Randall Becker confirms successful testing on NonStop systems with OpenSSL 3.4, providing positive compatibility data for this niche platform. This doesn't address the s390x test failure but contributes to broader release validation. Open questions remain about the s390x failure's root cause (platform timing vs command logic) and whether pre-release fixes are needed. Maintainers now have two data points: one platform-specific failure (s390x) and one successful verification (NonStop), with other platforms showing no issues. The release remains otherwise stable pending s390x-specific resolution.
