Git v2.49.0-rc1 release thread with s390x backfill test failure report:

Thread remains focused on the Git 2.49.0-rc1 release announcement, now with a platform-specific bug report regarding the new `git backfill` command. The release includes 367 non-merge commits with major user-facing changes (backfill command, shallow clone improvements, atomic push fixes) and internal progress (the_repository removal, meson build, zlib-ng, clar tests).

Todd Zullinger reports test 5620.4 ('do partial clone 2, backfill min batch size') failing on s390x architecture during release testing. The failure occurs when verifying promisor fetch count metrics in the new backfill command's batch fetching logic, suggesting either platform-specific behavior differences or test timing issues. While s390x is a niche platform, this represents the first reported issue with the backfill functionality and warrants investigation before final release. Complete test logs are available though direct s390x access is not.

Open question remains whether this indicates a backfill command bug or just a test timing issue on s390x. The release otherwise appears stable with no other reported platform-specific issues. Maintainers will need to evaluate whether this requires a fix before final 2.49.0 or can be deferred as a known s390x-specific limitation.
