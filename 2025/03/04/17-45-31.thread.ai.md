Git v2.49.0-rc1 release announcement thread summary:

First release candidate for Git 2.49.0, containing 367 non-merge commits from 68 contributors (17 new). Key user-facing changes include new `git backfill` command for blobless clones, improved shallow clone support for single commits, and atomic push error reporting fixes. Performance improvements focus on delta-base selection via new path-hash function in pack-objects/repack.

Internal changes show progress on major ongoing efforts: continued removal of `the_repository` global, meson build system improvements, zlib-ng compatibility work, and clar framework unit test conversions. The announcement documents planned breaking changes for Git 3.0, particularly regarding legacy `branches/` and `remotes/` directory support.

Standard release candidate format includes complete contributor list (new: 17, returning: 51), categorized change summaries, and download locations. Represents stabilization phase where new features are complete and focus shifts to bugfixes before final release.
