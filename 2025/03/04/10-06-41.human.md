This is a platform compatibility fix for the ongoing reftable decoupling effort. Patrick Steinhardt identifies and resolves a MinGW-specific issue where memory allocation mismatches were causing test failures in the reftable tests. The problem occurs because Git for Windows' custom mimalloc allocator was being used inconsistently between the reftable library and the rest of the Git codebase. Steinhardt's solution moves the mimalloc declarations from git-compat-util.h to compat/posix.h to ensure consistent allocator usage across the codebase.

This patch represents the last technical blocker for the reftable decoupling series, which aims to remove Git-specific dependencies from the reftable code for better portability. The fix is narrowly focused but important, as it resolves test failures that only appeared in MinGW builds (MSVC builds using Meson were unaffected). The change is straightforward and appears well-targeted to the specific issue at hand.
