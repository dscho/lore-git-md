This is a build system patch that enables unreachable code detection in developer builds, part of a 3-patch series combining work from Jeff King and Junio Hamano. The patch adds `-Wunreachable-code` to both Makefile and Meson build configurations, with the goal of catching potential bugs like the one previously found by Coverity in the refs transaction code. While GCC ignores this flag (having removed the warning in version 4.x due to flakiness), Clang still implements it and has already proven useful by detecting the refs transaction issue in CI runs. The patch takes a simple approach of enabling it universally since GCC silently accepts the flag. The change is minimal (2 lines) but strategically important for catching dead code early, particularly given the recent concrete example where it helped. This represents the first step in the series that will ultimately introduce a more systematic solution with the `NOT_A_CONST` macro in patch 3.
