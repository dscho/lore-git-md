Elijah Newren's series introducing safer assertion infrastructure to Git's codebase has now been completed with this final patch. The 3-part series establishes a new `ASSERT()` macro (originally proposed as `BUG_IF_NOT()` in earlier versions) that remains active in production builds while preventing dangerous assertions with side effects.

The core infrastructure was already in place from the first two patches, which added the `ASSERT()` macro definition in git-compat-util.h and created CI detection for problematic assertions through a new Makefile flag and check-unsafe-assertions.sh script. This final patch systematically converts existing risky assertions across key subsystems - particularly the merge machinery (merge-ort.c and merge-recursive.c) and object storage (object-file.c) - to use the new safer primitive.
