Performance and refactoring patch in Taylor Blau's incremental MIDX bitmap series (v4 02/13). This patch adapts the pack-revindex machinery to handle object lookups across MIDX bitmap layers, a prerequisite for the layered bitmap approach.

Key technical changes:
- Introduces `bitmap_non_extended_bits()` helper to calculate total objects across MIDX layers (base + current)
- Modifies `load_midx_revindex()` to use different filename formats for incremental vs standalone MIDX
- Updates position conversion functions (`pack_pos_to_midx`, `midx_to_pack_pos`) to handle base layer objects
- Adjusts `midx_pack_order_cmp()` to work with global positions across layers
- Updates all bitmap position calculations to use the new `bitmap_non_extended_bits()` instead of `bitmap_num_objects()`

The changes maintain backward compatibility while enabling the new incremental bitmap behavior. The patch touches core bitmap operations including pseudo-merges, object filtering, and disk usage calculations. Test coverage appears thorough with existing bitmap tests exercising these paths, though no new tests are added in this specific patch.

This is a foundational change that doesn't introduce new functionality but enables the subsequent patches in the series to build the layered bitmap system. The implementation appears careful and consistent handling of base layer offsets throughout the codebase.
