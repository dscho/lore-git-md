Performance enhancement in the incremental MIDX bitmap series. This patch modifies `show_objects_for_type()` to properly handle pack lookups across MIDX layers by using `nth_midxed_pack()` rather than direct array access. The change ensures correct behavior when querying objects that reside in earlier MIDX layers relative to the current bitmap's layer, maintaining consistency of the layered bitmap design introduced in previous patches. This is a focused technical adjustment that builds on the base infrastructure established in patches 01-04 of the series, specifically addressing pack identification in the object display path. The change is minimal (single line modification) but important for correct cross-layer operation, particularly when dealing with the pseudo-pack ordering rules documented earlier in the series. No new tests are added here as the modification falls under the existing test coverage for MIDX bitmap operations.
