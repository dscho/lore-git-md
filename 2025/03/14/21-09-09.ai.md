Build system improvement introducing a systematic solution for unreachable code warnings. This is the third and final patch in a series addressing `-Wunreachable-code` compiler warnings, specifically focusing on macOS's `sigfillset()` behavior.

Junio Hamano proposes a generic `NOT_A_CONST` macro to document and handle cases where system headers declare functions as constant when they shouldn't be treated as such. The macro works by introducing a global `false_but_the_compiler_does_not_know_it_` variable (defined in a new compilation unit `fbtcdnki.c`) that prevents compiler optimization while maintaining semantic correctness. 

The patch replaces Jeff King's earlier `errno`-based workaround in `run-command.c` with this more general solution, changing the `sigfillset()` error check from an `errno`-based approach to using the new macro. The implementation is cross-build-system compatible, with additions to both Makefile and Meson build configurations.
