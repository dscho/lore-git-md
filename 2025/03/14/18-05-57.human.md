Build system fix for Meson configuration when tests are disabled. This patch addresses an error that occurs when building Git with `-Dtests=false` by making the test environment setup conditional in both the credential/netrc and subtree contrib components. The fix ensures these components can be built without test support by providing a stub environment when tests are disabled, rather than failing with an "Unknown variable" error.

The change is straightforward - it wraps the test environment setup in an `if get_option('tests')` block and provides a fallback empty environment. This is the second version of the patch, with the author noting they fixed the syntax in the netrc component to match the working subtree implementation.

The patch affects two files in the build system and appears to be a clean solution to a real configuration issue. It's a minor but practical improvement for those building Git without tests, particularly for distribution packaging scenarios where test dependencies might not be available.
