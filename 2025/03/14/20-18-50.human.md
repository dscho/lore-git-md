Feature implementation for the incremental MIDX bitmap series. This patch introduces a new `ewah_or_iterator` structure that enables efficient OR operations across multiple EWAH bitmaps from different MIDX layers.

The new iterator allows combining type-level bitmaps (commit, tree, etc.) from multiple MIDX layers while maintaining the compressed EWAH format, avoiding the need to decompress entire bitmaps. This is a key optimization for the layered bitmap approach, where only the topmost layer contains full reachability data while lower layers provide supplemental information.

Taylor Blau considered two alternative approaches - full decompression/OR-ing (too memory intensive) and recursive traversal (inefficient for sparse bitmaps) - before settling on this iterator-based solution. The implementation provides clean initialization, iteration, and cleanup interfaces while preserving the compressed nature of EWAH bitmaps.

This change fits logically into the larger MIDX bitmap series by enabling efficient cross-layer bitmap operations without requiring major refactoring of existing bitmap-handling code. The patch maintains the series' focus on incremental improvements while addressing a core performance consideration for the multi-layer bitmap design.
