This is part 4/13 of Taylor Blau's incremental MIDX bitmap series, focusing on teaching the commit bitmap lookup function to work across MIDX layers.

The patch modifies `bitmap_for_commit()` to recursively search through MIDX bitmap layers when a commit isn't found in the current layer. The key changes are:
1. Making the function handle NULL bitmap_index pointers (needed for recursion)
2. Adding recursive calls to check base layers when a commit lookup fails
3. Maintaining the existing fast path for direct bitmap lookups

The implementation looks clean and focused, directly addressing the need to traverse MIDX bitmap layers while preserving the existing performance characteristics for the happy path. This is a logical next step after the base infrastructure patches (01-03/13) and shows good attention to detail with the NULL check handling.

The change is well-contained (just 11 lines modified) and builds on the layered MIDX bitmap architecture described in the series. It's part of the broader effort to enable efficient bitmap operations across multi-pack indexes, with this patch specifically handling the commit lookup case.
