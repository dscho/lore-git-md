This is a bugfix series addressing multiple issues in the promisor-remote subsystem, now split into three focused patches based on previous discussion. The series represents the culmination of an architectural refinement process that started with a NULL pointer fix and evolved to better align with Git's standard remote conventions.

The first patch fixes the core NULL dereference when remotes lack URLs, now taking the minimal approach of skipping such remotes entirely rather than trying to handle edge cases. The second patch addresses a related issue where no URL is advertised, further hardening the error handling. The third patch resolves a case sensitivity inconsistency between config and runtime behavior for remote names.

Key technical changes from previous versions include complete removal of special-case handling for empty URLs, consolidation of warning messages, and clearer separation between safety fixes and URL validation logic. The test coverage has been significantly expanded to verify all three fixes, with 59 new test lines across the updated test script.

The series demonstrates how the discussion with Junio led to a simpler, more maintainable solution that preserves safety while removing architectural oddities. The patches now cleanly separate the immediate NULL check protection from broader design questions about promisor remote validation. While some questions about filesystem-sharing configurations remain open, the core safety issues are fully addressed in this minimal form.
