Here's a human-readable summary of the Git v2.49.0 release announcement:

Junio Hamano has released Git v2.49.0, a major feature release incorporating contributions from 89 developers (including 24 first-time contributors). This version introduces several user-visible improvements and continues ongoing technical efforts. The headline addition is a new `git backfill` command that helps complete blobless clones by downloading missing objects on demand. For pack operations, `pack-objects` and `repack` now support configurable name hashing to improve delta compression. Under the hood, the release makes progress on two major refactoring efforts: more Rust interfaces are exposed, and the project continues eliminating the `the_repository` global variable by threading repository parameters through callchains.

Performance improvements include faster rename detection during merges and new batched APIs for object processing. The release fixes several edge cases around atomic pushes, stash reflogs, and symbolic ref updates. Build system improvements center on Meson, which now supports building `git-subtree`, while documentation completes its transition from .txt to AsciiDoc format. Security-conscious users will appreciate fixes for credential cache authentication and clearer warnings about personal access tokens in URLs. The release notes also document upcoming breaking changes, notably the deprecation of legacy `.git/branches` and `.git/remotes` directories. Platform-specific enhancements include better Windows symlink handling and improved compatibility with musl libc and zlib-ng. As usual, the release includes localization updates and test suite modernization, including continued adoption of the clar unit testing framework.
