Feature patch extending `rev-list --test-bitmap` for incremental MIDXs.

This is patch 07/13 in Taylor Blau's series implementing incremental MIDX bitmaps. The patch teaches Git's bitmap testing infrastructure to properly handle the new layered MIDX bitmap structure. 

The main change introduces a new `find_bitmap_for_commit()` helper that tracks which bitmap layer contains each commit, replacing the simpler `bitmap_for_commit()`. This allows the test infrastructure to properly traverse the chain of MIDX layers when verifying bitmap correctness. The patch also adds reporting of which MIDX or pack file each bitmap comes from, which will help diagnose issues in the layered structure.

The implementation extends the `bitmap_test_data` structure to mirror the MIDX layer chain, with each layer getting its own test data. This maintains the existing verification logic while properly accounting for objects that may reside in different layers. The changes are focused and well-contained, building naturally on the infrastructure established in earlier patches.

This is a key piece of test infrastructure for the incremental MIDX work, ensuring the bitmap verification tools understand the new layered structure. The patch includes thorough updates to the test output formatting to clearly show which layer each bitmap comes from, which will be valuable for debugging.
