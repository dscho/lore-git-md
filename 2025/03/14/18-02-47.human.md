This is a build system patch addressing a Meson configuration issue. Sam James fixes a problem where building Git with `-Dtests=false` would fail when compiling certain contrib components (subtree and credential-netrc) because they unconditionally referenced the `test_environment` variable. The patch makes the test environment usage conditional, falling back to a stub environment when tests are disabled.

The change is straightforward and clearly motivated by an actual build error. It touches two files in the contrib area, both following the same pattern of test environment setup. The author notes they're unsure if there's a better approach (like using a disabler) but the current solution appears correct and minimal.

This is a low-risk change that improves build flexibility, particularly useful for distro packagers who might want to build Git without tests. The patch is cleanly implemented with matching changes for both affected components.
