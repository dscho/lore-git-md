CI/build system patch addressing Meson configuration issues in the contrib/ subtree. This v2 revision fixes build errors that occur when configuring Git with `-Dtests=false` by making test environment setup conditional in both the credential/netrc and subtree components.

The patch showed a real problem where the build would fail when tests were disabled, as `test_environment` wasn't defined in that case. The solution introduces conditional check for test support and falls back to a basic environment() when tests are disabled. The v2 revision specifically fixes the implementation for the netrc component after discovering syntax issues in the initial version.

Changes affect two files in contrib/: credential/netrc/meson.build and subtree/meson.build, with identical patterns of wrapping test environment setup in a conditional block. The patch is narrowly focused and appears technically sound, though it might be worth considering whether this pattern should be abstracted if it needs to be repeated elsewhere in the build system.
