This is a documentation patch in Taylor Blau's incremental MIDX bitmap implementation series (v4 01/13). It adds technical documentation explaining the pseudo-pack ordering and reachability bitmap behavior for incremental multi-pack indexes (MIDX).

The patch introduces two key sections to the multi-pack-index.adoc file. First, it defines the pseudo-pack ordering for incremental MIDXs, extending the existing single-layer definition to handle multiple MIDX chains. The ordering rules consider layer precedence, pack order within layers, and object offsets. Notably, preferred pack status applies to the entire MIDX chain rather than individual layers.

The documentation explains that only the newest layer's bitmap stores full reachability information, while older layers provide commit/pseudo-merge data and type-level bitmaps. The implementation uses simultaneous iteration and OR operations on type-level bitmaps for efficiency.
