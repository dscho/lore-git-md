Feature implementation adding 'drop' subcommand to `git reflog` for complete reflog removal, addressing a gap where users could previously only expire individual entries. This is the second and final patch in the series, following earlier discussion and refinement.

The patch introduces `git reflog drop` with two key flags: `--all` to remove reflogs across all worktrees and `--single-worktree` to limit scope to the current worktree. The implementation handles reference resolution via `repo_dwim_log` and uses `refs_delete_reflog` for the actual deletion, with proper worktree awareness through `get_worktrees()` and `refs_for_each_reflog`. Error messaging is standardized using `usage()` for invalid cases.

Documentation clearly distinguishes the new 'drop' subcommand from existing 'expire' and 'delete' functionality, noting that it removes the reflog structure itself rather than individual entries. The test suite in t1410-reflog.sh provides comprehensive coverage of single/multiple ref cases, worktree scenarios, error conditions, and the mutual exclusion between `--all` and explicit references.

All prior review feedback from Patrick Steinhardt has been addressed, including documentation reorganization, error handling improvements, code structure refinements, and additional test coverage. The only remaining discussion point was a minor stylistic preference about loop placement that doesn't affect functionality. The patch appears ready for inclusion after the current feature freeze period.
