Build system improvement for unreachable code detection.

Junio Hamano responds to Jeff King's proposal for handling macOS-specific false positives with the `-Wunreachable-code` warning. He agrees with the approach of conditionally enabling the warning everywhere except macOS, though notes this means we won't automatically detect if macOS compiler behavior improves in the future. The maintainer approves this as a temporary experimental measure to evaluate whether the warning's benefits (it already caught one real issue) outweigh the maintenance burden of false positives. The thread shows consensus forming around this pragmatic solution while acknowledging it may need refinement based on real-world experience.
