This is Junio Hamano's regular "What's cooking in git.git" status update, summarizing the state of various topics in the Git development pipeline as of March 2025. These updates provide a snapshot of what changes are being considered for future Git releases.

The email highlights several notable developments:

1. A bugfix for `git log --follow -B` that addresses a corner case when break detection and --follow are used together is ready for merging to 'next'.

2. The ongoing effort to deprecate merge-recursive continues with 6 commits preparing merge-ort as its replacement, including fixes for directory renames and verbosity controls.

3. Performance work includes a new `--path-walk` option for `git pack-objects` that finds delta bases from blobs at the same path, potentially improving compression.

4. Protocol v2 improvements better handle ref advertisement constraints, simplifying logic that previously caused confusion and bugs.

5. New features include machine-parsable NUL-delimited output for `git rev-list` and a `git reflog drop` subcommand to discard entire reflogs.

6. The `the_repository` removal effort progresses with multiple patches removing dependencies from the object layer and various builtins.

7. A security-sensitive fix corrects how objects from multiple cruft packs are refreshed to ensure proper expiration.

The update also mentions many smaller improvements, bugfixes, and cleanups across various parts of the codebase. Several topics are marked as still under discussion or awaiting final review before merging. This comprehensive overview gives Git maintainers and contributors visibility into the project's current development focus areas.
