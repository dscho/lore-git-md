This is a follow-up in the ongoing discussion about `-Wunreachable-code` compiler warnings, specifically addressing a macOS-specific false positive. Jeff King proposes an alternative solution to the previously suggested platform-specific flag disabling, opting instead for a more robust error-checking approach that works across platforms.

The patch modifies `run-command.c` to check `sigfillset()` errors via `errno` rather than the function's return value, circumventing a macOS-specific compiler optimization that makes the error path appear unreachable. This maintains the warning's usefulness on other platforms while silencing the false positive. The change is motivated by POSIX compliance (which allows `sigfillset()` to fail) versus macOS's documented behavior (where it always succeeds).
