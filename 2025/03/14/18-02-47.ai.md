Build system patch addressing Meson configuration for test environments.

This is a small but practical fix for the Meson build system, specifically targeting the conditional use of test environments when building without tests enabled. The patch addresses an error that occurs when configuring Git with `-Dtests=false` where the build system would fail due to referencing the undefined `test_environment` variable in contrib/ components.

The change modifies two contrib components (credential/netrc and subtree) to only use `test_environment` when tests are enabled, falling back to a basic `environment()` otherwise. This matches the build system's behavior when tests are disabled while maintaining existing functionality when tests are enabled. The patch appears straightforward and correctly solves the immediate problem, though the author notes uncertainty about whether a more elegant solution using Meson's disabler feature might be possible.

Key technical details for future reference:
- Affects `contrib/credential/netrc/meson.build` and `contrib/subtree/meson.build`
- Introduces conditional logic based on `get_option('tests')`
- Maintains identical test environment setup when tests are enabled
- Uses empty `environment()` as fallback when tests are disabled
- Preserves all existing test configuration including PATH modification and CREDENTIAL_NETRC_PATH setting

The change is uncontroversial and appears to be a clear improvement over the current behavior, though reviewers might discuss whether the disabler approach would be preferable.
