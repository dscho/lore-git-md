Performance enhancement for incremental MIDX bitmaps. This is the second patch in Taylor Blau's v4 series implementing layered MIDX bitmaps, following the foundational documentation patch.

The patch modifies the pack-revindex machinery to properly handle object lookups in incremental MIDX bitmaps. Key changes include:

1. `load_midx_revindex()` now selects the correct MIDX filename format based on whether the MIDX is incremental
2. Position conversion functions (`pack_pos_to_midx()` and `midx_to_pack_pos`) are updated to work with global object positions across MIDX layers
3. The comparison function `midx_pack_order_cmp()` is adjusted to account for base layer offsets

The changes enable the reverse index to properly navigate the pseudo-pack ordering across multiple MIDX layers, which is essential for the bitmap reachability operations this series is implementing. The patch appears to be a focused, technical adjustment that builds on the architectural foundation established in the series' documentation patch.

This continues the steady progress toward efficient bitmap operations in large repositories, with the implementation now handling the revindex aspects needed for layered MIDXs. The changes are well-contained to the pack-revindex subsystem while supporting the broader bitmap functionality.
