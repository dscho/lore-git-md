This is a follow-up to the Git v2.49.0 release announcement regarding Rust integration issues. Josh Steadmon reports problems publishing the new Rust crates to crates.io due to differences between `cargo publish` and `cargo build` workflows. The main issue is that the repository root isn't included during publishing, preventing build scripts from accessing the top-level Makefile and Git sources outside the `contrib/libgit-*` directories.

As a temporary measure, Steadmon has published placeholder crates to prevent name squatting of the `libgit*` names. This appears to be a technical hurdle in the Rust integration effort that wasn't caught before the release. The problem seems specific to the publishing mechanism rather than the functionality itself, but it will need to be resolved before the crates can be properly published. This is a gap in the otherwise successful Rust foreign interface work mentioned in the release announcement.
