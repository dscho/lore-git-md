Feature implementation in Taylor Blau's incremental MIDX bitmap series (patch 08/13). This patch extends the disk-usage calculation functionality to properly handle incremental MIDX layers by using `nth_midxed_pack()` instead of direct array access to the MIDX's packs.

The changes modify two key functions in pack-bitmap.c:
1. `get_size_by_pos()` - Used for determining object sizes during bitmap traversal
2. `get_disk_usage_for_type()` - Calculates on-disk storage consumption for bitmap operations

Both functions follow the same pattern of replacing direct `midx->packs[pack_id]` array access with the layer-aware `nth_midxed_pack()` helper, maintaining consistency with the series' approach to handling MIDX chains. This builds on the cross-layer pack identification work from patch 05/13 and the recursive lookup infrastructure from patch 04/13.

The changes are minimal (just 2 lines modified) but important for correct behavior when computing disk usage metrics in repositories using incremental MIDX bitmaps. The patch maintains the existing error handling and object identification logic while adapting it to the layered MIDX structure. This continues the series' pattern of methodically updating each bitmap operation to be MIDX-chain aware.
