Feature implementation for incremental MIDX bitmaps in `rev-list --test-bitmap`.

This patch extends the `--test-bitmap` mode of `git rev-list` to properly handle incremental multi-pack index (MIDX) bitmaps. It builds on the layered MIDX bitmap infrastructure introduced in earlier patches of this series.

Key technical changes:
- Introduces `find_bitmap_for_commit()` which extends `bitmap_for_commit()` to track which bitmap layer contains a given commit
- Adds `base_tdata` pointer to `bitmap_test_data` to mirror the MIDX bitmap chain structure
- Implements new helper functions `bitmap_test_data_prepare()` and `bitmap_test_data_release()` to manage the recursive test data structure
- Adds `bitmap_total_entry_count()` to sum entries across all MIDX layers
- Enhances test output to show:
  - Total entry count across all MIDX layers
  - Which MIDX or pack contains the found bitmap
  - Checksum and size information for verification

The changes maintain the existing test functionality while properly accounting for the layered nature of incremental MIDX bitmaps. The implementation follows the pattern established in previous patches of this series, particularly building on the recursive lookup capability introduced in patch 04/13.

This represents another step toward full incremental MIDX bitmap support, specifically addressing the testing infrastructure needed to verify correct behavior. The patch includes appropriate cleanup handling and maintains the existing test coverage while extending it to work with the new MIDX bitmap structure.
