Bugfix for a diffcore-rename issue triggered by `-B --follow` options.

Elijah Newren responds to Jeff King's report of a BUG() being triggered when using `git log -B --follow` on a specific path in the linux-sgx repository. The issue was bisected to commit 9db2ac5616 ("diffcore-rename: accelerate rename_dst setup", 2020-12-11). 

Newren provides a link to a fix that's already been submitted (as pull request #1876). The problem appears to be a corner case in the rename detection logic that wasn't properly handled during the optimization in that 2020 commit. 

This looks like a legitimate bug that could affect users trying to track file history across renames with the -B (break detection) option. The fix appears to be properly targeted at the root cause identified in the bisect.
