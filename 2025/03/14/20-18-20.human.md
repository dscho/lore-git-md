Documentation patch for incremental MIDX bitmaps, part of Taylor Blau's ongoing series to implement layered bitmap functionality. This first patch in the v4 series establishes the technical documentation for how reachability bitmaps will work with incremental MIDX chains.

The patch adds a detailed explanation of two key concepts: the pseudo-pack ordering rules for objects across MIDX layers, and how reachability bitmaps will operate in this incremental context. The documentation specifies that each MIDX layer can maintain its own bitmap file while building on previous layers, with the most recent layer's bitmap handling reachability queries. It also describes the object ordering rules that determine how objects are compared across layers.

The writing is thorough and technical, clearly aimed at developers who will work with or review the implementation. It establishes important invariants like the global object positions in the pseudo-pack order and the OR-based bitmap combination strategy. The patch appears well-considered, with notes about current limitations (like the lack of layer compaction support) that will presumably be addressed in future work.

This foundational documentation will be important for reviewers evaluating the subsequent implementation patches and for future maintainers working with the incremental MIDX bitmap system. The patch stands alone as useful documentation but also clearly sets up concepts that will be needed to understand the code changes coming in the rest of the series.
