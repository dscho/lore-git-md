While this provides an alternative approach, Patrick's patch remains the upstream-focused solution, maintaining the architectural separation agreed upon in earlier discussions.

The thread shows two parallel solutions progressing - Patrick's targeted reftable fix for core Git and Git for Windows' system-wide approach. Both address the same underlying Windows file-locking behavior but through different scopes.
