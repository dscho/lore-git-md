This is a build system improvement patch that enables the `-Wunreachable-code` compiler warning in developer builds. It's the first of a 3-patch series addressing unreachable code detection.

The patch enables the warning for both Makefile and Meson builds, noting that while GCC ignores this option (it was removed in GCC 4.x for being flaky), Clang still implements it and has already caught at least one real bug in Git's codebase. The justification references a specific case where Coverity found unreachable code that could have been caught earlier with this warning.

The change is straightforward - just adding the compiler flag to both build systems. The patch carries sign-offs from both Jeff King (who originally proposed the warning) and Junio Hamano (who squashed in the Meson build change from Patrick Steinhardt). This appears to be a well-justified, low-risk improvement to Git's developer tooling that could help catch bugs earlier.
