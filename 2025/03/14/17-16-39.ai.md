This is a release announcement for Git v2.49.0, marking a new feature release with 460 non-merge commits from 89 contributors (24 new). The announcement follows the standard format for Git version releases, detailing availability, repository locations, and contributor acknowledgments.

Key technical changes span several areas: A new `git backfill` command helps bulk-download missing blobs in blobless clones, while `pack-objects` and `repack` gain a `--name-hash-version` option for improved delta selection. The release also introduces Rust foreign language interfaces and continues the `the_repository` removal effort by passing repository parameters explicitly through more callchains. Performance improvements include batch object visiting APIs and optimized rename processing in merge-recursive.

Notable fixes address atomic push porcelain output, reflog migration for stashes, and symbolic ref updates. The build system sees significant meson improvements including subtree support, while documentation transitions all .txt files to .adoc format. Security-related changes include credential cache authtype fixes and warnings about PATs in URLs.

The release contains typical housekeeping - l10n updates, test modernization (including clar framework conversions), and CI fixes. Breaking changes documentation clarifies the upcoming removal of `.git/branches` and `.git/remotes` support, with an early opt-in available. Platform-specific improvements include Windows symlink handling and musl/zlib-ng compatibility.
