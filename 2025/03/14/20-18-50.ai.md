Performance enhancement for MIDX bitmap operations with new EWAH iterator implementation.

This patch introduces `struct ewah_or_iterator` to efficiently combine multiple EWAH bitmaps from different MIDX layers through logical OR operations. The new iterator allows traversal of a conceptual type-level bitmap spanning all layers without decompressing entire bitmaps or requiring extensive refactoring of existing bitmap traversal code.

Key technical details:
- New `ewah_or_iterator` struct holds an array of individual EWAH iterators
- `ewah_or_iterator_init()` initializes iterators for all input bitmaps
- `ewah_or_iterator_next()` performs the OR operation across all active iterators
- Memory management via `ewah_or_iterator_free()`
- Avoids decompression overhead of alternative approaches
- More efficient than recursive traversal methods that would process unnecessary zero regions

The implementation builds on the incremental MIDX bitmap architecture from previous patches, specifically addressing the need to combine type-level bitmaps (commit, tree, etc.) across layers while maintaining the performance characteristics of the EWAH compressed bitmap format. This is patch 10/13 in the series, continuing the systematic implementation of cross-layer bitmap operations.
