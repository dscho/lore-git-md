Build system fix for contrib tests in meson builds, completing a series addressing inconsistencies across Git's build infrastructure. This final patch ensures the netrc credential helper and git-subtree tests in contrib/ properly respect the `-Dtests=false` build option, matching behavior with the main test suite.

The fix wraps test definitions in conditional blocks checking `get_option('tests')` in both `contrib/credential/netrc/meson.build` and `contrib/subtree/meson.build`. This prevents errors when `test_environment` (only defined when tests are enabled) is referenced during builds with tests disabled. The changes are straightforward - moving existing test setup code inside new conditional blocks.
