This is a build system fix in a series addressing various build infrastructure issues. The patch ensures Perl is properly required when building Git's documentation, fixing a case where builds could fail when documentation was enabled but Perl was explicitly disabled.

The change modifies `meson.build` to add documentation generation to the list of features that require Perl. Without this, builds configured with `-Ddocs=man -Dperl=disabled` would fail when trying to generate command lists via Perl scripts. The fix is straightforward - just adding `get_options('docs')` to the conditions that trigger Perl being marked as required.

The patch was originally authored by Eli Schwartz and adapted by Patrick Steinhardt as part of his build fixes series. It's a clear improvement that prevents a specific build failure scenario, though the impact is limited to users who both want documentation and explicitly disable Perl (a somewhat unusual combination). The change maintains consistency with the build system's handling of other Perl-dependent features.
