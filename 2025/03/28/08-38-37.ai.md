This is a build system fix in a series addressing various build infrastructure issues. The patch enforces Perl as a required dependency when building documentation in the Meson build system, fixing a case where documentation builds would fail when Perl was explicitly disabled.

The issue occurs because Git's documentation generation requires Perl (for cmd-list.perl) but Meson wasn't properly enforcing this dependency when all other optional Perl-dependent features were disabled. The fix adds documentation builds to the list of conditions that require Perl, alongside existing requirements for tests, gitweb, and netrc credential helper.

The change is straightforward - a one-line modification to meson.build that adds `get_options('docs') != []` to the conditions triggering Perl requirement. The patch originated from Eli Schwartz with commit message edits by Patrick Steinhardt, and addresses a real-world build failure scenario where `-Ddocs=man -Dperl=disabled -Dtests=false` would incorrectly succeed at configuration time only to fail later during setup.

This is part of a v1 series collecting build system fixes, with this particular patch being the third of four. The change is well-justified and appears uncontroversial, fixing a clear gap in the build system's dependency handling. The patch maintains consistency with Git's build requirements while preventing a class of misconfigured builds.
