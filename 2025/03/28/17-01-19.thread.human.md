This thread centers on a 2-patch series that enhances `git version --build-options` to report which SHA implementations Git was built with, including both cryptographic (SHA-1/SHA-256) and non-cryptographic variants. The initial implementation by Justin Tobler added clear output lines like "SHA-1: OpenSSL" while introducing a more controversial "unsafe-SHA-1" label for faster, non-cryptographic variants.

The main discussion point has been whether "unsafe-SHA-1" is the right terminology, with suggestions that "fast-SHA-1" might be less alarming to users while still conveying the trade-off. Christian Couder recently contributed a minor but helpful documentation fix, correcting a typo in the man page text without weighing in on the naming debate. The technical implementation remains sound, cleanly adding this diagnostic capability without affecting other code paths.

At this stage, the series appears technically ready pending resolution of the naming question for non-cryptographic SHA-1 variants. The patches have seen light review so far, with Christian's typo fix being the only substantive feedback received to date.
