This thread has successfully concluded the implementation of SHA implementation reporting in `git version --build-options`. The 2-patch series, now in its third iteration, enhances Git's version output to clearly indicate which SHA-1 and SHA-256 implementations are being used, with special attention to non-collision-detecting SHA-1 variants.

The technical approach uses compile-time symbols (SHA1_BACKEND, SHA1_UNSAFE_BACKEND, SHA256_BACKEND) to report the selected implementations while maintaining zero runtime overhead. The output format was carefully designed to be both informative and concise, only showing the non-collision-detecting SHA-1 line when such a backend is actually in use. Documentation includes clear warnings about the security implications of using non-collision-detecting SHA-1 variants.

Key contributors Patrick Steinhardt, Justin Tobler, and Christian Couder worked through several iterations to refine both the implementation and documentation, with Justin's v3 patches representing the final consensus. Junio Hamano has approved the technical direction, and all participants have now signed off on the series. With no outstanding issues remaining, these patches are ready to be merged into the codebase, completing this enhancement to Git's version reporting capabilities.
