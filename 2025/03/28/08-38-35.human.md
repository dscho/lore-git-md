This is a build system bugfix for Git's meson configuration, specifically addressing curl detection logic. It's the first patch in a 4-part series collecting various build system improvements.

The patch corrects how Git's meson build handles the `-Dcurl=auto` option. Currently, when users specify `auto` (the default for most features), the build correctly detects curl's presence but then fails to actually use it due to an incorrect check for `enabled()` rather than `found()`. This matters because curl is essential for HTTP functionality, and the current behavior could lead to builds that appear to succeed but lack important features.

The fix is straightforward - changing one condition in meson.build to check `curl.found()` instead. The commit message clearly explains both the current problematic behavior and why curl is special (being enabled by default unlike most features). This appears to be a well-justified fix for a regression introduced during the meson conversion.
