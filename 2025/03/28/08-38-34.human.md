This is a cover letter for a series of build system fixes. Patrick Steinhardt is bundling four small but important fixes to various build system issues into a single patch series for easier tracking. 

The series addresses: (1) a fix for handling the "-Dcurl=auto" meson option, (2) an alternative solution for a meson test environment fix that's currently in the 'seen' branch, (3) Eli Schwartz's patch to properly require Perl when building documentation (which hasn't been picked up yet), and (4) Thorsten's fix for gitweb.js generation (also not yet picked up). 

The changes touch meson build files for credential/netrc, subtree, and the main meson.build, plus a small Makefile change for gitweb. Patrick is being careful about attribution, offering to adjust authorship or trailers if needed. This looks like a well-organized collection of straightforward build system maintenance fixes that should be uncontroversial to merge.
