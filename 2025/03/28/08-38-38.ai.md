Build system fix for contrib tests in meson builds. This is the fourth and final patch in Patrick Steinhardt's series collecting build system improvements.

The patch addresses an inconsistency where tests for the netrc credential helper and git-subtree in contrib/ were being wired up in meson builds even when `-Dtests=false` was specified. This caused build failures since the `test_environment` variable they depend on is only defined when tests are enabled. The fix wraps the test definitions in conditional blocks checking `get_option('tests')`, matching the behavior of the main test suite.

Key changes:
- Modifies `contrib/credential/netrc/meson.build` to conditionally define tests
- Similarly updates `contrib/subtree/meson.build` to respect the tests flag
- Fixes a real-world failure case reported by Sam James where `-Dtests=false -Dcontrib=subtree` builds would error out

This completes the series' goal of fixing various meson build issues, with this patch specifically ensuring consistent test behavior between main and contrib components. The change is straightforward and aligns with the build system's existing patterns for optional test inclusion.
