This is a build system fix for gitweb's JavaScript generation, part of a series collecting build improvements. The patch corrects an issue where the build script itself was being incorrectly included in the generated `gitweb.js` file due to an overbroad dependency specification in the Makefile.

The problem stems from a December 2024 refactoring that moved the JavaScript concatenation logic into a separate script. The Makefile rule uses `$^` to get all dependencies, which now includes both the JavaScript files and the build script itself. The fix (originally from Thorsten Glaser) adds a filter to only process `.js` files.

This is a straightforward correction that prevents build artifacts from polluting the production JavaScript bundle. The impact is limited to gitweb builds, and the change aligns with the original intent of the refactoring. The patch is small (one-line change) and well-explained, with clear attribution to the original contributor. As part of the build fixes series, it appears ready for integration.
