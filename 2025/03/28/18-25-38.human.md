Build system fix for contrib tests in meson builds. This is the final patch in Patrick Steinhardt's series addressing various meson build system issues, specifically ensuring the contrib/ directory's tests properly respect the `-Dtests=false` flag.

The patch fixes a build error that occurs when configuring with `-Dtests=false` for either the netrc credential helper or git-subtree components in contrib/. Currently these tests are wired unconditionally, causing failures since they depend on the `test_environment` variable that only exists when tests are enabled. The solution wraps the test definitions in conditional blocks checking `get_option('tests')`, matching the behavior of the main test suite.

Sam James (who originally reported the issue) gives the patch a positive review, noting they had considered stylistic improvements but ultimately agrees with the straightforward fix. The changes are clean - just adding conditional blocks around the test definitions in both `contrib/credential/netrc/meson.build` and `contrib/subtree/meson.build`.

This completes the series' goal of making build behavior consistent across Git's entire codebase when tests are disabled, particularly important for packagers and those building without test dependencies. The patch appears ready to merge with no outstanding concerns.
