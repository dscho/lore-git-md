This is a feature patch series (2 parts) that enhances `git version --build-options` to show which SHA implementations Git was built with. The main motivation is diagnostic utility - currently the build options don't indicate whether Git is using SHA-1, SHA-256, or the potentially unsafe SHA-1 implementations.

The first patch adds display of the standard SHA-1 and SHA-256 implementations. The second adds reporting of any "unsafe-SHA-1" implementation, though the author questions whether this terminology might be unnecessarily alarming and suggests "fast-SHA-1" as an alternative. The implementation touches `help.c` to add the reporting logic and updates the `git-version.adoc` documentation.

Key technical details for future reference:
- Adds new output lines to `--build-options` showing "sha1:" and "sha256:" implementations
- Conditionally reports "unsafe-sha1:" if applicable (or potentially renamed to "fast-sha1:")
- Uses existing `git_SHA_CTX` and `git_SHA256_CTX` infrastructure to detect implementations
- Modifies `print_version_info()` in help.c to include the new information
- Updates documentation to reflect the new output format

The series appears well-contained and focused, with clean commit messages and appropriate documentation updates. The naming question around "unsafe-SHA-1" seems like the main point likely to generate discussion.
