This is a feature patch series that enhances Git's build information reporting. The two-patch series aims to the `--build-options` output of `git version` by adding details about which SHA-1 and SHA-256 implementations Git was built with, including any "unsafe-SHA-1" optimizations.

The motivation is to provide better diagnostic information about how Git was compiled, particularly around cryptographic hash implementations. The first patch adds basic SHA implementation reporting, while the second specifically handles the "unsafe-SHA-1" case (which uses potentially faster but cryptographically insecure implementations). The author raises an interesting naming question about whether "unsafe-SHA-1" might be better termed "fast-SHA-1" with appropriate documentation, inviting list discussion on this point.

The changes are straightforward, touching only the help documentation and the help.c implementation file. This seems like a well-motivated quality-of-life improvement for debugging and support scenarios, though the naming question around "unsafe-SHA-1" may generate some discussion about how to properly communicate security tradeoffs to users.
