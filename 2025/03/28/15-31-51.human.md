This is a confirmation of a platform compatibility fix for the reftable decoupling effort.

Johannes Schindelin confirms that Patrick Steinhardt's proposed solution for the MinGW-specific memory allocator mismatch has successfully resolved the CI failures in Git for Windows. The fix involved moving mimalloc override declarations to `compat/posix.h` to ensure allocator consistency between reftable and Git core code. 

This was the last known issue blocking the `ps/reftable-sans-compat-util` series, which aims to remove Git-specific dependencies from the reftable code for better portability. The series is now cleared to move forward, representing significant progress in the long-term ref backend abstraction work.

The discussion highlights the complexity of coordinating changes between upstream Git and downstream distributions like Git for Windows, particularly around platform-specific behaviors. Schindelin notes the challenge of tracking these cross-thread discussions when they span multiple email threads.

With this confirmation, the Git for Windows maintainer gives the green light for the series to proceed, removing the final technical blocker for this important refactoring work.
