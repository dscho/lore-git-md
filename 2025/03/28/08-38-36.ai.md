Build system fix for gitweb JavaScript generation, part of a series collecting build system improvements. This patch addresses a regression introduced in commit 19d8fe7da65 where the Makefile rule for building gitweb.js incorrectly included the build script itself in the concatenated output due to using `$^` which captures all dependencies. The fix filters the input files to only include `.js` files before concatenation.

The issue stems from a refactoring that moved the JavaScript concatenation logic into a separate script but didn't account for the script becoming an implicit dependency. The patch is credited to Thorsten Glaser with Patrick Steinhardt adapting it for inclusion in this series. The change is minimal (one-line Makefile modification) but important for correct gitweb functionality.

Technical details: modifies `gitweb/Makefile` to use `$(filter %.js,$^)` when calling `generate-gitweb-js.sh`, ensuring only JavaScript files are processed. This maintains the original intention of concatenating GITWEB_JSLIB_FILES while excluding the build script itself from the output. The patch follows the series' pattern of precise, focused build system corrections.
