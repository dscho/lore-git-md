Build system fix for contrib tests in meson builds. This is the fourth and final patch in Patrick Steinhardt's series collecting build system improvements.

The patch addresses an issue where tests for the netrc credential helper and git-subtree in the contrib directory were being unconditionally included in meson builds, even when explicitly configured with `-Dtests=false`. This caused build failures since the test environment setup depended on a variable that only exists when tests are enabled. The fix wraps the test definitions in conditional blocks that check the tests option, matching the behavior of the main Git test suite.

The change is straightforward and well-justified, fixing a real-world issue reported by Sam James during Gentoo packaging. The patch maintains consistency with Git's build system behavior while properly respecting the tests configuration flag. As with the rest of the series, this appears ready for merging with no obvious drawbacks.
