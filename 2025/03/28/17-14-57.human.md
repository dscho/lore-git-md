This is a bugfix for interactive rebase's merge commit handling, part of a series improving rebase status reporting. Eric Sunshine provides a code review of Philippe Blain's patch that fixes an edge case where `rebase -r` would fail to create merge commits after empty conflict resolutions.

The review focuses on test improvements, suggesting two changes to make the test case more robust and readable: (1) using `env` to properly scope the `FAKE_LINES` variable rather than polluting the test environment, and (2) adopting existing test suite conventions for quoting branch names in grep patterns. These are minor but important refinements to the test coverage that was added in the original patch.

The review doesn't challenge the core fix (which properly handles merge commit creation and MERGE_HEAD cleanup) but helps strengthen its verification. This appears to be a straightforward improvement to the patch's test implementation while leaving the main functionality unchanged.
