Build system fix for documentation generation.

This patch corrects an oversight in the Meson build system configuration where the file extensions for technical and howto documentation sources weren't updated when the project switched from `.txt` to `.adoc` extensions for AsciiDoc files in commit 1f010d6bdf7. The change affects two build files: `Documentation/howto/meson.build` and `Documentation/technical/meson.build`, updating all references to documentation files with the new `.adoc` extension. Without this fix, the HTML documentation build fails when configured with `-Ddocs=html`.

The patch is straightforward, consisting entirely of mechanical filename extension changes across 16 howto documents and 28 technical documents (5 API docs and 23 articles). It also updates the output filenames for generated index files (`howto-index.adoc` and `api-index.adoc`). The changes are purely build-system related and don't affect the content or functionality of the documentation itself.

This appears to be a clean, focused fix for a clear regression introduced by the earlier extension change. The patch follows the established pattern from the main Documentation directory's meson.build file and should allow the documentation build to complete successfully. No tests are included since this is a build system fix, but the change is simple and low-risk.
