PKCS#11 URI escaping regression in Git 2.48.1 causing smart card authentication failures. Reporter demonstrates that special characters in PKCS#11 URIs (equals signs, colons, semicolons) are incorrectly escaped when read from gitconfig and passed to OpenSSL 3.2.2, breaking YubiKey 5 authentication that worked correctly in Git 4.35.5 on Rocky Linux 9. The bug manifests during repository authentication when Git transforms the raw PKCS#11 URI before passing it to ksshaskpass and OpenSSL. Reproduction case shows the unescaped gitconfig URI versus the malformed escaped version that causes the failure. No proposed fix yet, but the version comparison suggests this is a regression introduced between Git 4.35.5 and 2.48.1. Key technical details include the OpenSSL version and PKCS#11 URI format, though sensitive information like YubiKey serial numbers and repository URLs have been redacted. The error occurs specifically during the authentication phase when Git attempts to use the smart card credentials.
