This thread addressed a straightforward build system fix for Git's documentation generation. Phillip Wood identified and patched an oversight in the Meson configuration where file extensions weren't updated when the project transitioned from `.txt` to `.adoc` for AsciiDoc files. The change updates references in `Documentation/howto/meson.build` and `Documentation/technical/meson.build` to consistently use `.adoc` extensions, covering 44 technical documents and their index files.

Patrick Steinhardt initially reviewed the mechanical fix, which was causing HTML documentation builds to fail when configured with `-Ddocs=html`. While both maintainers discussed the possibility of building documentation by default in Meson to catch such issues earlier, they agreed to defer that broader change. The immediate focus remained on landing this minimal extension fix for the upcoming release.

Junio Hamano has now acknowledged the patch as ready for inclusion, confirming there are no outstanding objections. The change follows the established pattern from the main Documentation directory's meson.build and maintains consistency after the AsciiDoc transition. Phillip noted that CI improvements to automatically detect such issues would be addressed separately after the release. This concludes the thread with the fix queued for merging.
