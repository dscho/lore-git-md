This thread addresses a small but important build system fix for Git's documentation generation under Meson. The issue stemmed from an oversight when the project transitioned from `.txt` to `.adoc` file extensions for AsciiDoc documentation—some Meson configuration files still referenced the old extensions, causing HTML builds to fail. Phillip Wood provided a mechanical patch updating the `meson.build` files in the `Documentation/howto/` and `Documentation/technical/` subdirectories to consistently use `.adoc`, covering 44 documents in total.

Patrick Steinhardt acknowledged the fix while raising a broader question about whether Meson should build documentation by default to catch such issues earlier. In a follow-up, Phillip agreed with the idea but suggested deferring that larger discussion to focus on landing this straightforward correction first. Both maintainers confirmed the patch is uncontroversial and ready for merging, with any CI or build system improvements to prevent similar oversights being considered as future work after the upcoming release. The change has no functional impact beyond fixing the build and follows Git's established practice of not requiring tests for purely build-related adjustments.
