This thread addresses a build system issue affecting documentation generation in Git's Meson build configuration. The problem stems from an oversight during the project-wide transition from `.txt` to `.adoc` file extensions for AsciiDoc documentation files. The patch specifically updates the Meson build files for technical and howto documentation to use the correct `.adoc` extensions, fixing a regression that prevented HTML documentation from building properly when configured with `-Ddocs=html`.

The change is mechanical and focused, touching only the build configuration for 16 howto documents and 28 technical documents (including 5 API docs and 23 articles). It follows the same pattern already established in the main Documentation directory's build configuration. While this is a straightforward fix with no content changes to the documentation itself, it resolves a clear build failure and maintains consistency of the documentation generation system.
