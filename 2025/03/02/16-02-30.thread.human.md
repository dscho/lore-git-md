This thread addresses a build system fix for Git's documentation generation, specifically updating file extensions in Meson configuration files from `.txt` to `.adoc` to match the project's switch to AsciiDoc format. The original patch (commit 1f010d6bdf7) missed updating the `meson.build` files in the `howto` and `technical` subdirectories, causing HTML documentation builds to fail when configured with `-Ddocs=html`. Phillip Wood provided the fix, which Patrick Steinhardt acknowledged as a straightforward mechanical update affecting 16 howto documents and 28 technical documents (including API docs).

While Patrick raised a broader question about whether to build documentation with Meson by default to catch such issues earlier, he explicitly deferred that discussion to focus on landing this immediate fix first. The change is low-risk, purely build-system related, and maintains consistency with the main Documentation directory's configuration. No tests are included, as is typical for build system adjustments of this nature. The thread remains focused on this specific fix, leaving larger build system questions for future discussion.
