This thread introduces a straightforward housekeeping change to ensure consistent formatting for Git's Bash scripts. The patch extends the existing `.editorconfig` rules for shell scripts (`.sh`) to also cover `.bash` files, maintaining the project's tab-based indentation standard. 

The change affects two existing files in the tree - `git-completion.bash` and `check-directional-formatting.bash` - both of which already follow the tab-indented style. This is a purely mechanical adjustment that aligns editor behavior with the project's established conventions, similar to how the file already handles other file types. No functional changes or additional testing is required for this low-impact consistency improvement.
