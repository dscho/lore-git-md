This is a build system fix addressing a documentation build issue in the meson configuration. Phillip Wood corrects an oversight from a recent change that renamed AsciiDoc files from `.txt` to `.adoc` extensions. While the main `Documentation/meson.build` was updated in the `technical/` and `howto/` subdirectories were missed, causing HTML documentation builds to fail when using `-Ddocs=html`.

The patch updates the file lists in both subdirectories' meson.build files to use the new `.adoc` extensions consistently. This is a straightforward maintenance change that aligns with the earlier transition (commit 1f010d6bdf7) and fixes a clear regression in the build process. The change is mechanical but necessary, touching 48 lines across two files to update filenames and their corresponding index targets. No behavioral changes are introduced beyond fixing the build.
