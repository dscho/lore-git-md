Bugfix for PKCS#11 authentication URI escaping issue. Henry Reed reports that Git 2.48.1 incorrectly escapes special characters in PKCS#11 URIs when used for smart card authentication, breaking functionality that worked correctly in Git 4.35.5. The problem manifests when configuring a YubiKey 5 smart card in `.gitconfig` - characters like equals signs and semicolons in the URI get percent-encoded before being passed to OpenSSL, causing authentication failures.

The bug report includes a clear reproduction case showing the malformed URI output, where `pkcs11:model=PKCS#15` becomes `pkcs11%3Amodel%3DPKCS%252315`. This appears to be a regression in newer Git versions, though the reporter notes they can't share exact details about their corporate environment.

The issue seems straightforward - Git's URI handling is being too aggressive with escaping when it shouldn't be for this particular authentication path. This would affect anyone using PKCS#11 smart cards with Git over HTTPS. The report is well-documented with version information (Git 2.48.1 vs 4.35.5 behavior) and system details, though the actual fix would need to confirm whether this is a Git core issue or potentially an interaction with newer OpenSSL 3.2.2.
