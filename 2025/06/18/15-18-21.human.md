This is a feature patch improving signature handling in Git's fast-export/fast-import functionality, part of an ongoing thread about experimental signature support. Christian Couder's v3 patch addresses several limitations in the current signature output format:

The patch enhances the signature format to include both the Git object algorithm (SHA-1/SHA-256) and the signature type (OpenPGP/X.509/SSH/unknown), making it more informative than the current SHA-only indication. It also adds support for handling both SHA-1 and SHA-256 signatures on the same commit, with warnings emitted for any additional signatures of the same type.

Key improvements include:
- New "gpgsig <hash-algo> <format>" output format (e.g. "gpgsig sha1 openpgp")
- Documentation updates explaining the new format
- Warning system for multiple signatures of same type
- Support for X.509 and SSH signatures in addition to OpenPGP
- Better handling of commits with both SHA-1 and SHA-256 signatures

The implementation appears thorough, with new test cases for X.509 and SSH signatures, though the author notes they haven't yet found a way to test commits with both SHA-1 and SHA-256 signatures. The patch builds on previous discussion in the thread while taking a different approach than earlier versions.
