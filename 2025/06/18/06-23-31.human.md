This is a platform compatibility patch fixing a build issue on systems without `d_type` in their `struct dirent` (AIX and NonStop are specifically mentioned). The problem was introduced by commit 09fb155f11 in May 2025, which added direct `d_type` usage in `diff-no-index.c`.

The fix is straightforward - replacing the direct `e->d_type` access with the existing `DTYPE()` macro that handles systems where this field isn't available. The change is minimal (just one line) and clearly correct, addressing a real portability issue that would prevent Git from building on certain platforms.

This appears to be a well-justified and cleanly implemented fix. The commit message clearly identifies both the problem and solution, though it might have noted that `DTYPE()` is Git's standard abstraction for this exact portability case. The patch maintains existing behavior while making it work on more platforms.
