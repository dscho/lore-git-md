Platform compatibility fix for `diff --no-index` on AIX/NonStop systems. This is a follow-up to Carlo Marcelo Arenas Belón's patch that addressed a build regression caused by direct `d_type` usage in `diff-no-index.c`.

Collin Funk confirms the build failure on AIX 7.3 and verifies the fix works, adding a Reviewed-by tag. The change is minimal - just replacing `e->d_type` with the portable `DTYPE(e)` macro wrapper - but important for these niche platforms. The regression originated from commit 09fb155f11 which added pathspec support to `diff --no-index`.

This appears to be a straightforward, well-justified fix with positive early feedback. The patch changes are exactly what one would expect for this type of portability issue, and the existing `DTYPE()` macro is the established solution elsewhere in the codebase. No controversy or complications are apparent.
