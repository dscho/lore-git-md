This is a bugfix patch in Glen Choo's submodule remote lookup series, addressing a memory leak in the remote cleanup code. 

The patch fixes `remote_clear()` to properly free the `push` and `fetch` refspec fields when tearing down a remote struct. While this leak wasn't caught by sanitizers when using `the_repository` (since those values never go out of scope), it would become visible when the series starts using the function with submodule repositories.

The change is straightforward - just two lines adding `refspec_clear()` calls for the previously-leaked fields. This is a clear improvement that plugs a real leak, though it's worth noting the fix is somewhat preemptive since the leak only becomes problematic with the later changes in the series. The patch follows the series' theme of cleaning up remote handling code in preparation for more substantial changes to submodule behavior.
