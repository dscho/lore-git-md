Core problem: Current submodule remote lookup is fragile, particularly when users rename remotes. The series aims to make this more reliable by shifting from name-based to URL-based lookup where possible, since the parent project already knows the submodule's URL from .gitmodules or config.

Current status: v3 of series, with notable simplification of branch->merge_name handling compared to previous versions that just fixed memory leaks. Tests in t7406 verify new behavior. First patch focuses on branch merge configuration cleanup, while second patch fixes memory management in remote.c. Jacob Keller's refactoring patch moves path-checking functions to shared location.

- Maintains backward-compatible behavior while simplifying the code
