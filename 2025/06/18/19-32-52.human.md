This is a bugfix addressing portability issues in `diff --no-index` on platforms without `d_type` in `struct dirent`. Collin Funk confirms Junio Hamano's proposed solution works correctly where the initial patch failed, while fixing two minor implementation issues (reversed `lstat()` arguments and missing `dtype` declaration).

The fix properly handles directory detection by first checking `d_type` where available, then falling back to `lstat()` on platforms without it. This maintains correct pathspec matching behavior, as demonstrated by passing all tests in t4053-diff-no-index.sh where the original patch failed two tests involving nested pathspecs and glob patterns.

The solution comes with a small performance tradeoff (additional `lstat()` calls on affected platforms) but is necessary for correctness. Collin has verified the fix works on AIX 7.3 and suggests adding his Tested-by tag to the final version. This appears ready for inclusion once the commit message is updated.
