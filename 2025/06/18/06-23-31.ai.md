Platform compatibility fix for systems without `d_type` in `struct dirent`.

This is a straightforward portability patch addressing a build failure introduced by commit 09fb155f11 ("diff --no-index: support limiting by pathspec", 2025-05-21). The issue affects platforms like AIX and NonStop that don't have the `d_type` member in their `struct dirent`. The patch replaces a direct `e->d_type` reference with the existing `DTYPE()` macro, which handles the platform abstraction.

The change is minimal (one line in `diff-no-index.c`) and appears correct - it maintains the same logic but uses the portable wrapper. The commit message clearly identifies both the problem and solution, though it doesn't explain why the original change didn't use `DTYPE()` from the start. This seems like a clear improvement that should be uncontroversial to merge.
