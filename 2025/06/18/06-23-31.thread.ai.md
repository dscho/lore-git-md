Thread identity: Portability fix for `diff --no-index` on platforms without `d_type` in `struct dirent`, addressing a regression from commit 09fb155f11.

Core problem: The `diff --no-index` command broke on AIX and NonStop systems due to direct use of `e->d_type` instead of portable directory type detection. Initial solution using `DTYPE()` macro proved insufficient as it would incorrectly report all entries as non-directories on affected platforms, breaking pathspec matching against directories.

Current status: Final solution combines direct `d_type` checks where available with `lstat()` fallback on platforms without `d_type`, ensuring correct directory detection for pathspec matching. Collin Funk has tested and verified the solution passes all relevant tests in `t4053-diff-no-index.sh`, including previously failing cases for nested pathspecs and glob patterns. He identified and corrected two minor implementation issues in Junio's patch: reversed `lstat()` arguments and a missing `dtype` variable.

Key technical details: Fix in `diff-no-index.c` now properly handles directory detection through:
1. Direct `d_type` check where available
2. `lstat()` fallback on platforms without `d_type`
3. Maintained pathspec matching logic with accurate directory info
Solution may incur additional `lstat()` calls on affected platforms but ensures correctness. The `DTYPE()` macro remains valid for other use cases where directory/non-directory distinction isn't critical.
