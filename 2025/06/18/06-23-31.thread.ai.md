Thread identity: Portability fix for `diff --no-index` on platforms without `d_type` in `struct dirent`, addressing a regression from commit 09fb155f11.

Core problem: The `diff --no-index` command broke on AIX and NonStop systems due to direct use of `e->d_type` instead of the portable `DTYPE()` macro wrapper, which these platforms require as they don't include `d_type` in their `struct dirent` implementation.

Current status: Single-line fix changing `e->d_type` to `DTYPE(e)` in `diff-no-index.c` has been verified by Collin Funk on AIX 7.3. The patch maintains original logic while adding portability and now carries Collin's Reviewed-by tag.

Key technical details: Fix touches `diff-no-index.c` where filesystem entries are examined during pathspec-limited diff operations. Uses existing `DTYPE()` macro that properly abstracts platform differences in dirent handling. Collin's testing confirms the solution works on affected AIX systems.

Participant positions: Original author (not yet named) submitted the fix. Collin Funk has reviewed and tested the patch on AIX 7.3, confirming it resolves the build failure and adding a Reviewed-by tag to indicate approval.

Related work: Build regression stems from commit 09fb155f11 ("diff --no-index: support limiting by pathspec"). The `DTYPE()` macro has been used elsewhere in the codebase for similar portability needs, and this fix aligns with that established pattern.
