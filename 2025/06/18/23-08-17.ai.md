Refactoring patch in a submodule remote lookup series. This is the third patch in Glen Choo's v3 series improving submodule remote handling, though the patch itself comes from Jacob Keller.

The change moves two path-checking helper functions (`starts_with_dot_slash` and `starts_with_dot_dot_slash`) from being duplicated in both `submodule--helper.c` and `submodule-config.c` into `dir.h` as static inline functions. The functions check if paths start with "./" or "../" respectively, using the existing `path_match_flags` infrastructure with `PATH_MATCH_XPLATFORM` for cross-platform compatibility.

The motivation is to simplify an upcoming submodule refactor that needs these helpers earlier in `submodule--helper.c`. The patch keeps the same behavior while eliminating code duplication. The author considered but rejected renaming the functions to include a `_platform` suffix, finding it too verbose.

The change affects three files: adds the inline functions to `dir.h` while removing the duplicate implementations from `submodule--helper.c` and `submodule-config.c`. This is a straightforward refactoring with no behavior changes, though it does touch submodule-related code that's part of the larger remote lookup improvements in the series.
