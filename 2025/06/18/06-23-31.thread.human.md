This thread addresses a portability regression in `diff --no-index` that broke on AIX and NonStop systems due to their lack of `d_type` in `struct dirent`. The initial fix using a `DTYPE()` macro proved insufficient as it incorrectly classified all entries as non-directories, breaking pathspec matching.

Junio Hamano proposed a more robust solution combining direct `d_type` checks where available with an `lstat()` fallback for affected platforms. Collin Funk has now tested this approach on AIX 7.3, confirming it resolves both compilation and behavioral issues. He identified and fixed two minor implementation details (reversed `lstat()` arguments and a missing variable) and verified the solution passes all relevant tests, including previously failing cases for nested pathspecs and glob patterns.

The fix maintains correct directory detection for pathspec matching while remaining portable, though it may incur additional `lstat()` calls on platforms without `d_type`. With Collin's testing confirming the solution works and all technical concerns addressed, this appears ready to be finalized and merged to resolve the regression from commit 09fb155f11.
