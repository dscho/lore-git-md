This thread addresses a portability regression in `diff --no-index` that broke compilation on AIX and NonStop systems, where `struct dirent` lacks the `d_type` field. The original one-line fix proposed changing direct `e->d_type` access to use the existing `DTYPE()` macro wrapper in `diff-no-index.c`, maintaining the same logic while adding portability.

Collin Funk has now verified the fix builds correctly on AIX 7.3, where the original code failed, and has added a Reviewed-by tag to the patch. This confirms the solution works on one of the affected platforms and moves the thread toward resolution. The regression stems from commit 09fb155f11, which introduced pathspec limiting for `diff --no-index` but missed this platform-specific consideration. With Collin's validation, the patch appears ready for inclusion.
