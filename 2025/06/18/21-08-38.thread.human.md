The current implementation has O(N^2) behavior that can make pruning 28,000 refs take 410 seconds due to inefficient string comparisons. The changes involve collecting refs to prune upfront in a sorted string list and moving dangling ref warnings to appear after all pruning operations rather than interleaved.
