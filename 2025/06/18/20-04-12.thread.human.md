This thread addresses a platform compatibility issue in `diff-no-index` for systems like AIX that lack `d_type` in `struct dirent`. Junio C Hamano's initial patch modified the code to use the portable `DTYPE(e)` macro with a fallback to `get_dtype()`, though this required some manual path handling since the existing code didn't use `strbuf` as `get_dtype()` expects. The change maintains the optimization of avoiding unnecessary `stat()` calls while working correctly across platforms.

Collin Funk has now confirmed successful testing on AIX 7.3, validating that the solution works as intended on the target platform. With the maintainer's implementation and real-world testing confirmation, this appears to be a straightforward and effective fix for the portability issue.
