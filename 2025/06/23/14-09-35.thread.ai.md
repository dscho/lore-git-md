Platform compatibility issue affecting FreeBSD builds when libsysinfo (GNU libc sysinfo port) is installed. The problem manifests in Git 2.50.0 where configure detects libsysinfo but fails to add `-lsysinfo` to LDFLAGS, causing linker errors about undefined `sysinfo` symbols during build (affecting `scalar.o` and others). The FreeBSD ports system has implemented a local workaround via a user-configurable option to enable/disable libsysinfo dependency with proper LDFLAGS handling, but no upstream patch proposal has been made yet. Open question remains about Git project's preferred approach - whether to properly support libsysinfo linking when detected or explicitly disable it in the build configuration. This is a real-world issue affecting FreeBSD users but currently lacks a clear resolution path for upstream integration.
