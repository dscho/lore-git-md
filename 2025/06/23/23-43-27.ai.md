Cleanup patch completing the performance optimization series for `git fetch --prune`. This second patch removes the now-unused `refs_warn_dangling_symref()` function from refs.c, which was the old O(N^2) implementation for checking dangling refs. The function became obsolete after the first patch in the series switched to using the more efficient string-list based approach from `git remote prune`. The removal eliminates 17 lines of code while maintaining all functionality through the remaining `refs_warn_dangling_symrefs()` function. The change is straightforward with no behavior impact - it simply deletes code that is no longer called after the refactoring. The patch follows through on the series' goal of eliminating quadratic-time operations during ref pruning while keeping the same warning messages about dangling symrefs.
