Performance optimization for MIDX and cruft pack interaction during repacking. This is the final patch (9/9) in Taylor Blau's series to optimize pack maintenance, introducing a configurable way to avoid including cruft packs in MIDX files when possible.

The patch adds a new `repack.midxMustContainCruft` config option (defaulting to true for backward compatibility) that allows Git to exclude cruft packs from MIDX files when they aren't needed for reachability guarantees. This addresses a performance issue where MIDX files were bloated with rarely-accessed cruft objects, slowing down object lookups. The implementation uses the new `--stdin-packs=follow` mode from earlier in the series to ensure reachability is maintained without cruft packs when possible.

The change is well-tested with new scenarios in t7704-repack-cruft.sh covering: when cruft can be excluded, when it must be included due to configuration or existing MIDX state, and edge cases like no-op geometric repacks. The patch has evolved through multiple rounds of review (now at v6) with key approvals from Junio Hamano and Elijah Newren, and represents the culmination of work that has shown 5-20% speed improvements in production at GitHub.
