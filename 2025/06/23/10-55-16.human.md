This is a test suite improvement patch series that adds a format string option to `test_seq`, Git's test helper for generating number sequences. The cover letter explains it's a "quality of life" change that stemmed from a discussion over a year ago.

The first patch is a minor cleanup replacing some confusing `printf` calls with `echo` in test t7422. The second and main patch adds a `-f` option to `test_seq` that allows specifying a printf-style format string for the sequence numbers. This lets tests generate formatted output directly rather than piping through `printf`, simplifying several test files that currently do this manually (as evidenced by the many test file modifications shown).

The change appears well-motivated by real-world test suite needs, with the author noting they've been meaning to do this for a while. The patch series is small and focused, touching only test code, and the risk of regression seems low since it's just adding functionality rather than changing behavior. The diffstat shows it actually reduces overall test code by eliminating redundant printf piping.
