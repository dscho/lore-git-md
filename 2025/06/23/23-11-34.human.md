This is a preparatory refactoring patch in a series working on submodule remote lookup improvements, part of the broader `the_repository` removal effort.

Patch 6/7 in Jacob Keller's series moves the `get_default_remote_submodule()` function in `builtin/submodule--helper.c` to appear after `resolve_relative_url()`. The commit message explains this is to make future refactoring easier to review, as upcoming changes will make `get_default_remote_submodule()` depend on `resolve_relative_url()`, which itself depends on `get_default_remote()`.

The change is purely code reorganization - no behavior is modified. The diff shows the function being cut from its original location and pasted after `resolve_relative_url()`, with all its implementation remaining identical. This maintains the logical ordering of dependencies while keeping the diff minimal and focused.

This patch continues the series' pattern of careful, incremental changes to improve submodule remote handling while removing reliance on the global `the_repository`. The straightforward nature of this change suggests it should be uncontroversial, serving as setup for more substantive modifications to come in the final patch of the series.
