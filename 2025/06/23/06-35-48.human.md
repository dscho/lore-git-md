Test patch adding comprehensive JavaScript function syntax coverage for Git's diff driver.

This is part 3/4 of Derick W. de M. Frias's series to add JavaScript pattern matching to Git's built-in diff drivers. The patch adds 19 test files covering various JavaScript function declaration styles, including:
- Traditional function declarations
- Arrow functions (both single and multi-param)
- Async functions and generators
- Class methods (static, getters, setters)
- Method shorthand in object literals
- Edge cases around reserved words and function calls

The tests follow the established pattern of marking the expected diff hunk with `RIGHT" and using `ChangeMe` to indicate where changes should be detected. This continues the series' thorough approach to testing, now focusing specifically on function syntax recognition after previous patches handled numeric literals and module systems.

The test coverage appears comprehensive, touching on all major JavaScript function variants while maintaining clean, focused test cases. This patch doesn't introduce new functionality but rather verifies the existing implementation handles the full range of JavaScript function syntax correctly.
