This is the final patch (4/4) in a feature series adding comprehensive JavaScript diff driver support, focused on test coverage for export-related function declarations. The patch adds 52 new test files in t4018/ covering all variants of JavaScript export syntax (CommonJS `exports.`/`module.exports.` and ESModules `export`) across function types (regular, async, generator, arrow, anonymous).

The tests follow the established pattern of using `RIGHT` markers and `ChangeMe` comments to verify hunk/word diff behavior. They systematically test all combinations of:
- Export syntax variants (direct exports vs module.exports)
- Function types (regular, async, generator, arrow)
- Declaration styles (named, anonymous, assigned)
- Whitespace variations (including different placements of `*` in generator functions)

The test cases are minimal but complete, each focusing on one specific syntax variant. This brings the total test count for the JavaScript diff driver to 77 files in t4018/, demonstrating thorough coverage of ECMAScript and CommonJS module system patterns.

This patch builds on the previous parts which established core pattern matching (part 1), numeric literals (part 2), and basic function syntax tests (part 3). It completes the test matrix for export-related function declarations while maintaining the series' consistent testing approach. The only remaining open item from earlier reviews is space-to-tab conversion in userdiff.c.
