Performance optimization introducing a new `--stdin-packs=follow` mode for pack-objects. This is part 8/9 of Taylor Blau's series to optimize MIDX and cruft pack interactions during repacking.

The patch adds a new mode that makes pack-objects include objects from packs not explicitly listed on stdin if they are reachable from the included packs and not in excluded packs. This is particularly useful for handling cruft packs - it allows resurrecting once-unreachable objects while maintaining reachability guarantees needed for bitmap generation. The implementation carefully handles edge cases like missing objects and includes thorough test coverage.

The change builds on earlier refactoring in the series and prepares for the final patch that will add a `repack.midxMustContainCruft` config option. Reviewers have already approved key parts of this series, with Junio Hamano and Elijah Newren providing feedback on earlier versions. The patch appears well-tested and production-ready, having been validated at GitHub with measured performance improvements.
