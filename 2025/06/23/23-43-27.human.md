This is the second and final patch in a performance optimization series addressing a quadratic-time bottleneck in `git fetch --prune`. 

The patch removes the now-unused `refs_warn_dangling_symref()` function from refs.c, which was the old implementation for checking single references during pruning operations. The first patch in the series had already replaced this with a more efficient batch-checking approach using sorted string comparisons, making this function obsolete. 

The removal is straightforward - 16 lines deleted while keeping the more general `refs_warn_dangling_symrefs()` function that handles multiple references efficiently. This cleanup completes the transition to the new O(N*logN) algorithm for checking dangling refs during pruning operations.

The change is mechanical and low-risk since the function was already made obsolete by the first patch's changes. This follows good development practice of cleaning up dead code after refactoring. The series as a whole provides dramatic performance improvements for `git fetch --prune` in repositories with many refs.
