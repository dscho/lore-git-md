Regression fix for submodule remote refactoring series. This addresses a segfault found in the test suite after Jacob Keller's v3 patch removed `branch->merge_name` in favor of a simpler `set_merge` flag. The issue manifested when some code paths still relied on null-checking behavior that was inadvertently changed.

Lidong Yan identified the problem: `branch_has_merge_config()` was checking the wrong field after the refactoring, causing null pointer dereferences in fetch operations. The fix updates this function to check `branch->set_merge` instead, restoring the expected behavior. It also improves safety by using `FREE_AND_NULL` when clearing merge configurations to prevent double-free issues.

This is a minimal but critical fix that preserves the series' goals while maintaining test stability. The changes are focused and well-justified, addressing a specific regression without introducing new complexity. With this fix, the v4 series (which includes broader improvements to submodule remote handling) should now be ready for final review and application.
