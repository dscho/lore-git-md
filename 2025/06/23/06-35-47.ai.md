The test additions verify the word diff behavior for:
- Standard floating point numbers (3.14 -> 3.15)
- Scientific notation (1.23e3 -> 1.23e4)
- Various exponent formats (E/e, positive/negative exponents)
- Edge cases like zero prefixes and very small/large numbers

The patch maintains the existing test structure while expanding coverage to match the numeric literal support added in the core diff patterns. It follows the same red/green diff coloring scheme used for other language drivers. The test files (pre/post/expect) are updated in parallel to ensure consistent behavior verification.
