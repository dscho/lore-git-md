This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking. The patch factors out the `--stdin-packs` handling logic from `cmd_pack_objects()` into a new `read_stdin_packs()` function, preparing for future expansion of this functionality. The change is purely structural - moving existing code into a dedicated function without altering behavior - and follows the series' pattern of cleaning up pack-objects internals before introducing new features.

Key technical details include:
- Extraction of inline `--stdin-packs` handling into new `read_stdin_packs()` function
- Preservation of all existing logic including `ignore_packed_keep_in_core` flag and conditional loose object handling
- Function signature includes `rev_list_unpacked` parameter to maintain current behavior
- Original introduction point (commit 339bce27f4) referenced in commit message
- Part of broader refactoring to support upcoming `--stdin-packs=follow` mode in patch 8/9

The patch has already been reviewed and approved by Junio Hamano, as noted in the thread context. This change serves as groundwork for the more substantial modifications coming later in the series, particularly the new pack-following behavior. The clean separation of concerns here will help maintain readability as the `--stdin-packs` functionality grows more complex.
