Bugfix targeting Git's bundle functionality with shallow repositories. This patch reports an issue where cloning from a bundle created from a "grafted" (shallow) repository fails, even though direct cloning from the original shallow repository works fine.

The problem occurs when:
1. Creating a shallow clone (--depth=1) of a repository
2. Creating a bundle from that shallow repository (git bundle create --all)
3. Attempting to clone from the resulting bundle

The error manifests when Git tries to traverse parents of a grafted commit (47f57af... in the example), failing with "remote did not send all necessary objects". This suggests the bundle creation process isn't properly handling grafted commits from shallow clones, though the commit message doesn't specify the exact technical cause.
