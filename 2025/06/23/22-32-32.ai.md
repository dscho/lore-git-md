Performance optimization for MIDX and cruft pack interaction during repacking. This is the final patch (9/9) in Taylor Blau's series, introducing a configurable way to exclude cruft packs from MIDX files when possible.

The patch adds a new `repack.midxMustContainCruft` config option (defaulting to true for backward compatibility) that controls whether cruft packs must be included in the MIDX. When set to false, Git will only include cruft packs when necessary to maintain reachability guarantees for MIDX bitmaps. The key technical work happens in the new `midx_has_unknown_packs()` helper, which determines whether existing MIDX packs might depend on cruft pack objects.

The implementation ensures geometric repacks use `--stdin-packs=follow` (from patch 8/9) to properly track reachability when excluding cruft packs. Extensive tests in t7704-repack-cruft.sh verify the behavior under various conditions: when exclusion is possible, when forced inclusion is requested, when existing MIDX dependencies require inclusion, and when dealing with already-geometric pack arrangements.

This completes the series' goal of optimizing pack maintenance by reducing MIDX bloat from rarely-accessed cruft objects while maintaining correctness. The change is particularly impactful for repositories with many unreachable objects, where MIDX binary searches would otherwise slow down object lookups. The series has undergone thorough review, with this final patch addressing all edge cases around incremental MIDX updates.
