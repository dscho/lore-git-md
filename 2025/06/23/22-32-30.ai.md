Performance optimization introducing a new `--stdin-packs=follow` mode for pack-objects, part of a larger series improving MIDX and cruft pack handling during repacking. This patch (8/9) adds a mode that includes objects from unlisted packs if they are reachable from included packs and not in excluded packs, addressing edge cases where cruft pack objects become reachable via new commits. The change enables geometric repacking to maintain reachability closure while avoiding the need to always include cruft packs in the MIDX.

Key technical details:
- Introduces `enum stdin_packs_mode` with `STDIN_PACKS_MODE_FOLLOW` for the new behavior
- Modifies `show_object_pack_hint()` and `show_commit_pack_hint()` to handle the follow mode, with special blob existence checking
- Adds comprehensive tests in t5331-pack-objects-stdin.sh covering:
  - Basic follow mode behavior
  - Interaction with `--unpacked`
  - Tolerance for missing objects of different types
- Documents the new mode in git-pack-objects.adoc

The patch builds on earlier refactoring in the series (particularly patches 3-5) and prepares for the final config option in patch 9/9. It maintains compatibility with existing `--stdin-packs` behavior while adding the new mode as an opt-in feature. The implementation carefully handles edge cases around missing objects and maintains the existing best-effort traversal approach used for name-hash hints.
