Feature patch adding JavaScript diff driver support, part 1/4 in a GSoC series expanding Git's built-in diff capabilities. This initial patch establishes the core JavaScript pattern matching in userdiff.c while documenting the new driver in gitattributes.

The implementation handles multiple JavaScript function declaration styles (conventional, assigned, arrow, class/object methods) including async/generator variants, with special attention to avoiding false matches on reserved keywords. It adds comprehensive numeric literal support (binary/octal/hex/decimal with underscores and bigint suffixes) and basic punctuation patterns. The v2 revision notably adds CommonJS (`exports.`, `module.exports.`) and ESModules (`export`) syntax support while simplifying some regex patterns from v1 (e.g., converting `={3}` to `===`).

The patch follows Git's existing diff driver architecture, with patterns designed to highlight meaningful changes in JavaScript code. While thorough, the implementation maintains clear boundary around "vanillaJS" syntax, explicitly excluding framework-specific patterns. The accompanying documentation addition is minimal but complete, listing the new `javascript` driver alongside other language options.

This forms the technical foundation for the subsequent patches in the series which add extensive test coverage (77 test files in t4018/) and word-diff support. Outstanding items from review feedback (space-to-tab conversion, nested function support) remain unaddressed in this revision but are tracked for future work. The implementation appears carefully considered with attention to both correctness and maintainability of the regex patterns.
