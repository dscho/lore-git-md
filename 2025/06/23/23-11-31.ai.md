This is a refactoring patch in a series improving submodule remote lookup logic. It moves two helper functions (`starts_with_dot_slash` and `starts_with_dot_dot_slash`) from being duplicated in both `submodule--helper.c` and `submodule-config.c` into `dir.h` as static inline functions. The functions check path prefixes in a cross-platform way using existing `path_match_flags` infrastructure.

The patch is part of a larger effort to refactor submodule remote handling, with this particular change preparing for later use of these helpers earlier in `submodule--helper.c`. The author considered but rejected renaming the functions to include `_platform` suffix, finding it too verbose. The implementation remains functionally identical, just relocated to a shared header with proper documentation comments added.

Key technical details include the use of `PATH_MATCH_XPLATFORM` flag (as opposed to `PATH_MATCH_NATIVE` used by existing similarly-named functions in dir.h), and the removal of 24 lines of duplicate code while adding 23 lines to dir.h. The change touches three files but is purely structural with no behavior modification. This appears to be a straightforward, well-contained refactoring step in preparation for subsequent functional changes in the series.
