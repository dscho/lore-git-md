Refactoring patch in a series improving submodule remote lookup logic. This is the third patch in a 7-part series (v4) that aims to improve submodule remote URL handling.

Jacob Keller moves two helper functions (`starts_with_dot_slash` and `starts_with_dot_dot_slash`) from being duplicated in both `submodule--helper.c` and `submodule-config.c` into `dir.h` as static inline functions. The functions check path prefixes in a cross-platform way, similar to existing `_native` variants in dir.h. 

The change is a clean consolidation that removes duplicate code while maintaining the same functionality. The commit message notes some consideration was given to naming (whether to use `_platform` suffix) but kept the simpler names. This refactoring enables later patches in the series to use these helpers more widely within submodule handling code.

The patch is straightforward - it moves code with no behavior changes, updates the header documentation, and removes the now-redundant implementations. As part of a larger series that's already gone through several iterations, this appears to be a well-considered preparatory change.
