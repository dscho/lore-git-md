This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking. It's patch 7/9 in the v6 series.

The patch reorders two functions in builtin/pack-objects.c - `show_commit_pack_hint()` and `show_object_pack_hint()` - based on Elijah Newren's suggestion. The change is preparatory for a future commit where `show_commit_pack_hint()` will need to call `show_object_pack_hint()`. Currently `show_commit_pack_hint()` is a no-op function since commits don't have a namehash, but the reordering minimizes code movement in the upcoming change.

The diff shows the straightforward swap of these two function definitions, with `show_object_pack_hint()` now appearing first. This maintains all existing functionality while setting up for the next patch in the series. The change is mechanical and low-risk, having been reviewed and approved by Elijah Newren as part of the overall series which has received positive feedback from multiple maintainers.
