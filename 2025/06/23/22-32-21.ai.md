This is a performance optimization patch in Taylor Blau's series improving MIDX and cruft pack interactions during repacking. The patch enhances delta compression for loose objects when using `--unpacked` by properly including them in the name-hash traversal.

The key technical change modifies `add_unreachable_loose_objects()` to accept a `rev_info` struct parameter, allowing loose objects (particularly commits) to be added as reachability tips. This was previously impossible as the rev_info was scoped only to `read_packs_list_from_stdin()`. The patch updates all callers to pass either NULL (maintaining existing behavior) or the active rev_info struct.

The improvement comes from better delta base selection - while excluding loose objects from traversal didn't affect pack correctness, it limited delta opportunities. Now that commits found in loose objects can participate in the name-hash traversal, the packer can find better deltas, producing slightly more space-efficient packs.

This builds on earlier refactoring in the series (particularly patch 4/9) that moved rev_info handling to enable this change. The implementation is clean, passing the rev_info through the callback chain from `read_stdin_packs()` down to `add_loose_object()`, where it's only used for OBJ_COMMIT types to maintain the existing behavior for other object types.

The patch maintains all existing functionality while opening up new optimization opportunities, continuing the series' pattern of careful internal restructuring before introducing new features. With the rev_info plumbing now properly shared across the pack-objects code paths, this sets the stage for further integration work hinted at in the series.
