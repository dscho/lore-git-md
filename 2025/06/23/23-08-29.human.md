Performance optimization in pack-objects for loose object handling.

This is patch 5/9 in Taylor Blau's series improving pack maintenance performance, specifically focusing on delta compression of loose objects. The change allows loose commits to be treated as traversal tips during packing, which should produce more efficient deltas by giving the packer better path-from-root information.

The patch modifies `add_loose_object()` to add loose commits to the revision traversal when a `rev_info` struct is provided. Junio Hamano confirms the approach makes sense - it effectively treats loose commits as branch tips to improve delta compression. This builds on earlier refactoring that moved the `rev_info` declaration to make this sharing possible.

The series has been through multiple rounds of review with approvals from key maintainers. This particular patch appears straightforward and uncontroversial, implementing one piece of the larger performance optimization strategy that has shown 5-20% speedups in production at GitHub. The change is well-contained and maintains existing behavior while enabling better packing efficiency.
