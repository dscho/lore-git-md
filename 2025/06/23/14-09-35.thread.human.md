Here's a human-readable thread summary:

The thread discusses a build compatibility issue on FreeBSD systems where Git 2.50.0 fails to compile when the GNU libsysinfo port is installed. The problem occurs because the configure script detects libsysinfo but doesn't properly add the required linker flag, causing undefined symbol errors during the build - particularly when compiling scalar.o.

A FreeBSD ports maintainer reports they've already implemented a local workaround in their packaging system, which makes libsysinfo support optional and handles the linker flags correctly when enabled. However, they're seeking guidance on how the Git project would prefer to handle this upstream - whether to properly support libsysinfo detection and linking, or explicitly disable it in the build configuration.

No patch has been proposed yet for upstream consideration, but this appears to be a real issue affecting FreeBSD users who have the libsysinfo package installed. The solution will need to address the platform-specific build dependency one way or another.
