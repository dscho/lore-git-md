This thread addressed a FreeBSD build issue where Git 2.50.0 would fail to link when GNU libsysinfo was present, due to incorrect detection logic. Ramsay Jones proposed and implemented a solution using preprocessor conditions to prefer BSD's native sysctl over libsysinfo, which Renato Botelho confirmed works in the FreeBSD ports system. 

The fix has now received additional validation from Eli Schwartz of Gentoo, who confirmed the approach works correctly in the meson build system as well. The solution maintains compatibility across build systems while avoiding unnecessary library linkage. Junio Hamano had already indicated the technical solution was sound, pending meson verification - which this email provides.

With all build systems now confirmed working and no outstanding technical concerns, this thread appears resolved. The separate discussion about Git's broader build system direction (autotools vs meson) remains open but is not blocking this specific fix. The patch should be ready for merging in its current form.
