This thread addresses a build compatibility issue affecting FreeBSD systems where GNU libc's sysinfo port (libsysinfo) is installed. The problem surfaced in Git 2.50.0 when the build system detects libsysinfo but fails to properly link against it, causing undefined symbol errors during compilation - particularly affecting `scalar.o` and other components.

Renato Botelho, the FreeBSD ports maintainer who first reported the issue, has now followed up seeking guidance on how to properly fix this upstream. He presents two potential solutions: either making libsysinfo linking conditional (matching the FreeBSD ports workaround) or implementing FreeBSD-specific detection logic. Botelho has offered to implement whichever approach the Git maintainers prefer, but needs their input before proceeding with a formal submission.

While the FreeBSD ports system already has a working local solution (a configurable option to handle the libsysinfo dependency with proper linker flags), the thread remains open pending maintainer direction on Git's preferred architectural approach. The key decision point is whether Git should support libsysinfo linking when detected or explicitly handle FreeBSD as a special case in the build configuration.
