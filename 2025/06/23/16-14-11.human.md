This is a build system patch that modifies the behavior of `make coccicheck` to fail when Coccinelle suggests code changes, rather than silently succeeding. The change comes from Git maintainer Junio C Hamano and represents the final refinement of an earlier proposal.

The patch makes `make coccicheck` explicitly check that generated patch files are empty, using an efficient `grep -q` approach that Junio suggested after earlier discussion about shell syntax preferences. The implementation handles both the case where rules are processed individually and when they're concatenated (SPATCH_CONCAT_COCCI).

This follows productive discussion where multiple contributors agreed the silent-success behavior was problematic, as it made Coccinelle suggestions easy to miss. The patch is cleanly implemented with a clear commit message, and comes with the maintainer's approval after considering alternative approaches. The change is straightforward and unlikely to be controversial, representing a clear improvement to the developer workflow.
