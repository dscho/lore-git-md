This is a cover letter for a two-patch series improving test infrastructure, specifically focused on the `test_seq` helper function. The series stems from a discussion a year prior about making test output more readable.

The first patch is a minor cleanup in t7422-submodule-output.sh, replacing a confusing `printf` with simpler `echo` commands. The second and more substantial patch adds a `-f` (format) option to `test_seq` that allows controlling the output format of generated sequences, similar to `seq -f`. This eliminates the needless use of `printf` piped to `test_seq` in several test files, making the tests more readable and direct.

The changes touch 9 test files across various subsystems (reftable, submodules, merges, etc.), showing this is a widely used test helper. The author notes this was long-delayed quality-of-life improvement for the test suite. The implementation appears straightforward and the commit message references prior discussion, suggesting this is a well-considered change.
