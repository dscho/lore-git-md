Junio Hamano provides feedback on test improvements for the bloom filter pathspec optimization series. This is a follow-up to Lidong Yan's v2 patch that enables bloom filters for multiple pathspecs.

The core observation is that the existing test framework doesn't properly handle wildcard testing because it doesn't distinguish between literal wildcards and shell-expanded paths. Junio points out that the current test_bloom_filters_{not_,}used helpers can't properly test wildcard behavior since they pass arguments directly to git log without shell evaluation.

Junio suggests several concrete improvements:
1. Renaming the test case to more accurately reflect what's being tested (literal paths rather than wildcards)
2. Modifying the test helpers to use `eval` so they can properly handle quoted wildcards
3. Adding new test cases that demonstrate the difference between shell-expanded wildcards and literal wildcard pathspecs

The feedback is focused on test accuracy and completeness rather than the core bloom filter changes, which appear to be in good shape based on prior discussion. This represents the final polishing phase of the series, with Junio helping ensure the test coverage properly validates the new behavior.
