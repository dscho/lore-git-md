This is a follow-up in the ongoing Windows DFS-mounted network drive regression thread. D. Ben Knoble responds to Erwan Leroy's initial report by providing a link to Git's release notes documentation (RelNotes directory on GitHub) as a resource for investigating changes between versions 2.21 and 2.36 where the regression window was identified. The response is brief and informational, not attempting to diagnose the root cause but rather helping the original reporter access version history that might aid in their investigation.

Key technical details carried forward: The issue involves failed config file operations (specifically renaming `.git/config.lock` to `.git/config`) on DFS paths in Git versions 2.36+, while working correctly on direct UNC paths and in Git <=2.21. The thread remains focused on Windows-specific behavior, with the Git for Windows issue #3825 previously mentioned as a potential related case. No new diagnostic information or solutions are proposed in this response.
