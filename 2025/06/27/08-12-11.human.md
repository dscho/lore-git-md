This is a follow-up discussion about the meson build system integration patch in Karthik Nayak's clang-format series. The patch adds a 'style' target to meson that mimics the Makefile's ability to run `git clang-format` on changed files rather than formatting everything.

Justin Tobler points out that the patch checks for `clang-format` availability but should instead check for `git-clang-format` specifically, since that's the actual command being used. Karthik agrees with this suggestion, acknowledging that while `git-clang-format` comes packaged with `clang-format`, explicitly checking for it would be more precise.

This is a minor but important implementation detail in the final patch of the series, which otherwise appears ready to go. The exchange shows the careful attention being paid to making the meson integration robust and consistent with existing behavior. No other changes to the patch appear to be under discussion at this point.
