This is a bugfix patch addressing a memory leak in the `send-pack` command. Jacob Keller noticed that while a previous commit cleaned up the `shallow` oid array in `cmd_send_pack()`, it missed cleaning up the `extra_have` array, which could leak 2160 bytes during program exit.

The leak was discovered during routine use with sanitizers enabled, though it doesn't appear in the t5539 test suite, likely because those tests don't exercise the code paths that populate the `extra_have` array. The fix is straightforward - adding a call to `oid_array_clear()` for the `extra_have` array alongside the existing cleanup of the `shallow` array.

The patch is small (just one line added) and clearly motivated by both the memory leak report and the symmetry with the existing cleanup code. While the author notes they didn't investigate why the tests don't catch this, the fix itself appears correct and follows the pattern established by the earlier cleanup commit.
