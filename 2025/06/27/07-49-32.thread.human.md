This RFC patch series from GSoC participant Meet Soni, mentored by Patrick Steinhardt, introduces `git refs list` as a thin wrapper around `git for-each-ref` to consolidate ref listing functionality. After four iterations incorporating maintainer feedback, the series has reached a mature architectural state with shared core logic between the commands.

The implementation establishes `for_each_ref_core()` as a shared helper function called by both `cmd_for_each_ref()` and the new `cmd_refs_list()`, following Junio Hamano's preferred pattern. The series includes comprehensive test refactoring to share infrastructure between commands and addresses documentation inconsistencies. Key contributors like Eric Sunshine and Jean-Noël Avila have reviewed the standardized documentation approach.

Patrick Steinhardt's latest review indicates the series is nearly merge-ready, with only minor polishing needed: fixing include ordering in one file, properly documenting a test change, and possibly splitting one documentation fix into a separate commit. These are the final nits after addressing all substantive architectural feedback in prior versions. The series demonstrates how a well-mentored contributor can evolve a feature through the Git review process to reach production quality.
