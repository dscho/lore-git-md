Test infrastructure patch for the new `git refs list` subcommand, part of the RFC series proposing ref command consolidation. This second patch adds testing by:

1. Creating a new test script `t/t1461-refs-list.sh` that runs the existing `for-each-ref` test suite against the new `refs list` command by setting `GIT_REFS_LIST_CMD=refs list` and sourcing `t/t6300-for-each-ref.sh`.

2. Modifying `t/t6300-for-each-ref.sh` to use `${GIT_REFS_LIST_CMD:-for-each-ref}` throughout, making it parameterizable to test either command. The changes are mechanical substitutions of `for-each-ref` with the variable, with one special case to skip the `-h` help test for `refs list` since it currently shares `for-each-ref`'s implementation.

The patch maintains all existing test coverage while verifying the new command's compatibility. It's part of a larger effort to establish `builtin/refs.c` infrastructure, with this test ensuring the initial `refs list` implementation exactly matches `for-each-ref` behavior before potential future divergence. The approach of reusing tests highlights the command's current role as a drop-in replacement while providing a framework to test any future behavioral differences.
