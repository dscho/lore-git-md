Implementation consists of behavior-preserving wrappers in `builtin/refs.c` that forward arguments to `cmd_for_each_ref`. Key technical elements:
- New `cmd_refs_list` function constructs arguments for `strvec` forwarding to `cmd_for_each_ref`
- Modified `cmd_for_each_ref` checks argv[0] to handle both command paths (acknowledged as pragmatic but suboptimal by Junio Hamano)
- Shared option parsing via new `Documentation/refs-list-options.adoc` included in both man pages

- Junio Hamano suggests preparatory refactoring to extract common logic into helper function rather than direct command-to-command calls
- Maintainer notes duplicated `REFS_LIST_USAGE` macro is maintenance hazard but constrained by current usage infrastructure
