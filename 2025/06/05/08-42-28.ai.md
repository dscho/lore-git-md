This is part of the ongoing `imap-send` feature and bugfix series, specifically adding a command-line option to override the configured IMAP folder. The change allows users to specify the destination folder at runtime via `--folder` or `-f` rather than always using the `imap.folder` config value.

The implementation follows Git's standard option parsing patterns, storing the value in `opt_folder` and using it to override `server.folder` before connecting.

This is a straightforward quality-of-life improvement that maintains backward compatibility while giving users more flexibility. The change is well-contained, touching only the expected files (documentation and main implementation) with no surprises. As part of the larger `imap-send` overhaul, it fits naturally alongside the other authentication and configuration improvements in the series.
