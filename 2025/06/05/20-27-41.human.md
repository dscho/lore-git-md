This is a build system regression affecting Git 2.50.0-rc1 on NonStop systems when building without TCL/Tk (NO_TCLTK). Randall Becker provides additional troubleshooting details showing that the git-gui build process is deleting the *.tcl files from git-gui/lib during the build, contrary to expectations.

The key findings:
1. The build fails when generate-tclindex.sh can't find tclsh, but more critically, it appears to be removing the source *.tcl files during this process
2. This behavior wasn't present in Git 2.49, suggesting a regression in the build process
3. The issue manifests when building with specific flags on NonStop systems, though the root cause appears to be in the build system rather than platform-specific behavior

The email shifts the focus from the earlier wildcard expansion discussion to a more serious problem where build artifacts are being incorrectly deleted. This appears to be a release-blocking issue since it prevents successful builds on affected platforms. The regression seems related to recent build system changes that weren't properly tested in NO_TCLTK configurations.
