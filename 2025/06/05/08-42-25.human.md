Feature patch adding OAuth2.0 authentication support to `imap-send`. This is part of a larger v13 series that has been through extensive review rounds, with this specific patch introducing two OAuth2.0 authentication methods: the standard OAUTHBEARER (RFC 7628) and Google's proprietary XOAUTH2.

The implementation adds new helper functions for base64 encoding OAuth tokens (`oauthbearer_base64()` and `xoauth2_base64()`), authentication handlers, and libcurl support via `CURLOPT_XOAUTH2_BEARER`. The documentation is updated with configuration examples for both Gmail and Outlook, noting that Outlook only supports XOAUTH2 while Gmail supports both methods. The patch also includes compile-time guards for OpenSSL support.

This appears to be a well-considered addition, with clear documentation of the security benefits over app-specific passwords and proper handling of the different OAuth variants. The implementation follows the pattern of existing authentication methods in the codebase while adding the necessary protocol-specific handling for OAuth.
