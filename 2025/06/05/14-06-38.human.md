This is part 4/10 of a test modernization series converting reftable tests to the Clar framework. The patch converts the merged table functionality tests (previously in t-reftable-merged.c) to use Clar assertions and the new u-reftable-merged.c naming convention.

The tests verify core merged table operations including:
- Single record retrieval from merged tables
- Multiple ref updates across merged tables
- Repeated seeking behavior
- Log record merging
- Hash ID and update index validation

The conversion maintains all existing test coverage while switching from custom test-lib.h assertions to Clar's cl_assert* macros. Build system changes remove the old test file and add the new Clar version to both Makefile and meson.build. The changes appear straightforward and consistent with the series' goal of standardizing on Clar for reftable tests.

This continues the mechanical but important work of test framework unification, with the actual test logic remaining largely unchanged. The patch follows the same pattern seen in earlier parts of the series, suggesting the approach is working well.
