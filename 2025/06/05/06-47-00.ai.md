This is part of Patrick Steinhardt's ongoing `the_repository` removal effort (patch 10/17 in the v5 series). The patch converts two functions that manage temporary primary object database sources to use explicit ODB parameters instead of relying on the global `the_repository`.

The key changes are:
- Renames `set_temporary_primary_odb()` to `odb_set_temporary_primary_source()` and adds an explicit `object_database` parameter
- Renames `restore_primary_odb()` to `odb_restore_primary_source()` with similar parameter changes
- Updates all callers in `tmp-objdir.c` to pass the repository's ODB explicitly
- Maintains the same functionality while removing implicit repository dependencies
- Follows the established pattern from previous patches in the series

The changes affect temporary object directory handling, particularly operations like `tmp_objdir_replace_primary_odb()` and `tmp_objdir_unapply_primary_odb()`. The patch continues the mechanical conversion work by applying the same repository-agnostic pattern to these ODB management functions, keeping consistent with the series' naming conventions (`odb_` prefix) and parameter passing approach.
