Refactoring patch in Patrick Steinhardt's series to remove `the_repository` global state. This is patch 3/17 in v5 of the series, following the structural renames in patches 1-2 that established `struct object_database` and `struct odb_source` as the new names for the object store components.

The patch renames the core object store implementation files from `object-store.{c,h}` to `odb.{c,h}` to match the new terminology. This is a mechanical change updating 126 files to use the new header name, with no functional changes. The rename aligns with the series' goal of establishing clear ODB (Object DataBase) terminology and follows the pattern of other subsystems like refs that have their main interface in the root directory with implementations in a subdirectory.

Key technical details:
- Updates Makefile and meson.build build system files
- Changes all `#include "object-store.h"` to `#include "odb.h"`
- Renames the implementation files while preserving all content
- Maintains the same header guards (just updating the filename in the comment)
- Follows the established pattern seen in other subsystems like refs.h/refs/

This continues the systematic conversion of the object store subsystem as part of the larger effort to remove global state and enable pluggable backends. The change is straightforward and mechanical, building on the consensus naming established in earlier patches.
