This is Junio Hamano's monthly "What's cooking in git.git" status update, covering recent developments in the Git project. The email provides a comprehensive overview of changes that have graduated to the main branches, new topics under consideration, ongoing work, and discarded proposals.

Several notable changes have been merged to 'master' and 'next', including:
- BSD platform fixes for CPU detection and memory measurement
- Documentation improvements for command synopses and sparse-checkout
- Marking `--signed-commits` in `fast-export` as experimental
- Fixes for `fsck` behavior with worktree refs

New topics being introduced include:
- A resurrection of `imap-send` with OAuth2 support
- GPG signing support for `git subtree`
- Reftable unit test migration to the "clar" framework
- Memory leak fixes in various areas
- Improved `cat-file` handling of submodules and object modes

Ongoing work includes:
- Maintenance command improvements for ref locking
- MIDX API cleanups
- TAP output parsing for Meson builds
- Pathspec handling for `diff --no-index`
- Batched ref updates for push/fetch performance
- Object store API cleanups as part of `the_repository` removal

The email also notes several topics that have been discarded due to lack of interest or being superseded, including some defensive programming changes and Thunderbird patch submission scripts.

This update shows active development across Git's core functionality, with particular focus on platform support, performance, and modernization of internal APIs. The mix of bugfixes, documentation, and new features suggests a healthy balance in the project's current development priorities.
