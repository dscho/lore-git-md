This is the fifth iteration of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove `the_repository` global state, part of the ongoing `the_repository` removal effort. The series systematically converts ODB functions to take an explicit ODB parameter rather than implicitly using `the_repository`, while also establishing a clear `odb_` naming convention for the subsystem.

The v5 version includes some final polishing of terminology (changing "alternates" to "sources" in remaining spots) and commit message clarifications. The series is built on recent Git master and resolves trivial conflicts. It follows the same structure as previous versions: first renaming core structures and files, then converting functions to work with explicit ODB parameters, and finally standardizing function names with `odb_` prefixes.

Reviewers have already signed off on the foundational patches, and the series has stabilized through several rounds of naming discussion (settling on `odb_source` terminology). The changes are mechanical refactorings with no functional impact, preparing the codebase for future pluggable ODB backends. With all major technical questions resolved and only minor polishing remaining, this appears to be the final form of this substantial refactoring effort.
