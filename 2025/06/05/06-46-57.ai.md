This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database subsystem. Patch 7/17 continues the mechanical conversion work by making `odb_mkstemp()` repository-agnostic.

The patch modifies `odb_mkstemp()` to take an explicit `object_database` parameter instead of relying on `the_repository`, updating all 7 call sites to pass `the_repository->objects`. The function creates temporary files in the object database directory (like pack/tmp_pack_XXXXXX) and had previously used `the_repository` internally for path handling and directory creation. The changes include:
- Adding `struct object_database *odb` parameter to function signature
- Replacing `the_repository` with `odb->repo` for path operations
- Updating callers in fast-import, index-pack, bundle-uri, pack-bitmap-write, and pack-write
- Adjusting the odb.h documentation to clarify the function operates on the primary alternate's directory

This follows the established pattern from earlier patches in the series, continuing the systematic elimination of `the_repository` dependencies. The changes are straightforward mechanical conversions with no behavioral changes, similar to patch 6/17's work on `assert_oid_type()`. The patch touches 7 files with 22 insertions and 15 deletions, all following the same simple pattern of adding the ODB parameter at call sites.
