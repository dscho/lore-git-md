Test modernization: conversion of reftable table tests to Clar framework (part 6/10). This patch continues the systematic migration of reftable unit tests from custom test-lib.h assertions to the Clar test framework, focusing on the table functionality tests.

The changes follow the established pattern seen in previous patches: test functions are converted to Clar-style `test_reftable_table__*` naming, assertions are updated to use `cl_assert*` macros, and helper functions are replaced with their Clar equivalents from lib-reftable-clar. The patch maintains all existing test coverage while modernizing the infrastructure.

Key test cases preserved include:
- `test_reftable_table__seek_once`: Verifies basic table seeking behavior
- `test_reftable_table__reseek`: Tests repeated seek operations
- `test_reftable_table__block_iterator`: Validates block iteration with detailed checks of block types, header offsets, restart counts, and record counts

Build system updates (Makefile and meson.build) remove the old test file from UNIT_TEST_PROGRAMS and add the new Clar-based version to CLAR_TEST_SUITES. The changes are mechanical but thorough, with all test logic preserved while updating only the assertion framework. This continues the high-quality conversion pattern established in earlier patches of the series.
