Bugfix for a memory leak in pack-bitmap.c's boundary traversal logic. This is the final version (v5) of a patch series that has already been reviewed and approved for merging.

The patch fixes a memory leak in `find_boundary_objects()` where `roots_bitmap` wasn't being freed when `cascade_pseudo_merges_1()` succeeded. The fix is straightforward - always free `roots_bitmap` after use rather than only on failure. The patch includes a new test case that creates a scenario where the leak would occur (using pseudo-merges in boundary traversal) and verifies the fix works.

This version simplifies the test case compared to v4 by removing some redundant configuration and using direct numeric comparison. The series has already gone through thorough review, with Junio Hamano verifying the test methodology and giving final approval. The changes are minimal and focused - just the essential fix and test needed to address the memory leak.
