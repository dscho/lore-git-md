This is a follow-up in the thread about `git config get` command confusion. Kristoffer Haugsbakk clarifies that the `get` subcommand syntax is only available in Git 2.46.0 and later, while Scott Birl is using Git 2.39.5. The correct syntax for older versions is `git config --get`.

Key technical details:
- The thread originated from user confusion between documentation examples and actual command syntax
- `git config get` was introduced in Git 2.46.0 as a more intuitive alternative to `git config --get`
- Error occurs because pre-2.46.0 versions interpret "get" as a malformed config key rather than subcommand
- This confirms the issue is version-specific rather than a documentation error

The email provides important version context that helps explain the discrepancy between documentation and behavior.
