This is part 2/10 of the reftable test modernization series, converting the basics test file from custom test-lib.h assertions to the Clar framework. The patch deletes the old t-reftable-basics.c and creates a new u-reftable-basics.c with equivalent test coverage using Clar assertions.

Key technical changes:
- Test functions renamed to test_* convention (e.g. test_reftable_basics__binsearch)
- Custom check_* assertions replaced with cl_assert* equivalents
- Test cases remain identical but are now in Clar-style functions
- Build system updates (Makefile and meson.build) to switch from t- to u- prefix
- Tests cover:
  - Binary search (binsearch)
  - String array utilities (names_length, names_equal, parse_names)
  - Buffer operations (common_prefix_size)
  - Big-endian encoding/decoding (put/get_be{16,24,32,64})
  - Memory allocation (REFTABLE_ALLOC_GROW variants)

The conversion appears thorough and maintains all existing test coverage while following the Clar framework conventions established in the series. This is a straightforward mechanical conversion of one of the core reftable test files as part of the larger modernization effort.
