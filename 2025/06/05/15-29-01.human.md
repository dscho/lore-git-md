This is the final approved version of a bugfix patch addressing a memory leak in the pack-bitmap subsystem. The patch unconditionally frees the `roots_bitmap` in `find_boundary_objects()` after calling `cascade_pseudo_merges_1()`, fixing a case where the bitmap would leak when the function succeeded. The original code only freed it on failure, which was clearly an oversight.

The patch includes a new test case in t5333 that creates a simple repository with two commits, enables boundary traversal with pseudo-merges, and verifies the bitmap behavior. Junio Hamano notes this is now merge-ready after addressing all review feedback, though he wonders aloud about how the original bug was introduced in the first place.

This completes a well-reviewed series that establishes good patterns for ASAN-based leak detection while fixing a real issue in bitmap handling. The solution is straightforward and the test coverage is solid, making this a high-quality contribution that's ready for integration.
