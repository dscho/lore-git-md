This is part 14/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem, continuing the `the_repository` removal effort. The patch renames `repo_read_object_file()` to `odb_read_object()` to align with the new naming conventions established in earlier patches, where ODB-related functions are prefixed with `odb_` and take explicit object database parameters rather than repository handles.

The change is mechanical but wide-ranging, touching 47 files to update all callers. A compatibility wrapper is provided to avoid breaking in-flight topics. The patch follows the same pattern as previous conversions in the series, maintaining behavior while removing implicit `the_repository` usage. 

This continues the systematic conversion of object access functions to use the new ODB API, building on the infrastructure established in earlier patches. The change is straightforward and unlikely to be controversial, following the same approach that has already been reviewed in prior patches of the series.
