This is part 3/10 of the reftable test modernization series, converting the reftable block tests to use the Clar framework. The patch focuses on the block-level operations in the reftable backend, which handles low-level storage of ref, log, and object records.

The conversion follows the established pattern from earlier patches in the series: test functions are renamed to `test_reftable_block__*` format, assertions are updated to use `cl_assert*` macros, and the test file is moved from `t-reftable-block.c` to `u-reftable-block.c`. The patch maintains all existing test coverage while modernizing the test infrastructure.

Key test cases include read/write operations for different block types (ref, log, obj, index) and verification of block iterator behavior. The tests validate core functionality like record equality checks, seek operations, and error handling. Build system updates remove the old test file and add the new Clar-compatible version.

This appears to be a straightforward mechanical conversion that maintains the original test coverage while aligning with the project's test modernization effort. The changes are consistent with the series' goal of standardizing on the Clar framework.
