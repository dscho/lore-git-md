This is patch 14/17 in Patrick Steinhardt's v5 series refactoring Git's object database (ODB) subsystem to remove `the_repository` global state. The patch continues the mechanical conversion work by renaming `repo_read_object_file()` to `odb_read_object()` to match the established `odb_` prefix convention for ODB-related functions.

The change updates 47 call sites across the codebase to use the new function name while maintaining identical behavior. A compatibility wrapper is provided for in-flight topics that may still use the old name. The conversion follows the same pattern as previous patches in the series, where functions are updated to take explicit `object_database` parameters rather than implicitly using `the_repository`.

The patch affects core object reading functionality used throughout Git, including in packfile operations, revision walking, and various builtin commands. It builds on the infrastructure established in earlier patches that renamed core structures (`raw_object_store` to `object_database`) and standardized API naming.

This is a straightforward mechanical change that aligns with the series' overall goal of removing global state while maintaining backward compatibility during the transition. The extensive test coverage across the affected areas provides confidence in the correctness of the conversion.
