Kristoffer Haugsbakk clarifies this is version-specific behavior - the `get` subcommand syntax was introduced in Git 2.46.0, while Scott is using Git 2.39.5 where the correct syntax is `git config --get`. Key technical details:
- `git config get` is valid syntax in Git 2.46.0+ but invalid in earlier versions
- Pre-2.46.0 versions parse "get" as malformed config key, producing confusing error
- Correct syntax for older versions is `git config --get <key>`
- Documentation examples showing `git config <key>` are correct but could note version requirements
