This is part 9/17 of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database (ODB) subsystem, continuing the methodical conversion of functions to use explicit ODB parameters.

The patch converts three iterator-style functions that work with alternate object databases:
1. `foreach_alt_odb()` becomes `odb_for_each_alternate()`
2. `for_each_alternate_ref()` becomes `odb_for_each_alternate_ref()`
3. Updates their callback typedefs with new `odb_`-prefixed names

The changes follow the established pattern from previous patches in the series - adding explicit `object_database` parameters and standardizing names with the `odb_` prefix. The patch updates 8 call sites across various parts of the codebase (count-objects, receive-pack, submodule helper, etc.) to use the new API.

The conversion is mechanical but thorough, with clear documentation added to the new functions in odb.h. This continues the series' high-quality approach with consistent naming and careful attention to maintaining functionality while removing global state dependencies. The changes are straightforward and unlikely to be controversial given the established pattern in earlier patches.
