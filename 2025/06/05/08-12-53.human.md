This is a bugfix patch in the OAuth2.0 authentication support series for `imap-send`. Jeff King identified a logic error in the libcurl setup code where the password would incorrectly be set for OAuth methods due to flawed `strcmp()` conditions using OR operators instead of AND. The patch author, Aditya Garg, confirms the issue and acknowledges the need to fix the condition to properly skip password setting for OAuth authentication methods (XOAUTH2 or OAUTHBEARER).

The fix is straightforward but important - it ensures credentials are handled correctly when using OAuth authentication, which doesn't require password-based authentication. This was the last identified issue in the OAuth2.0 implementation, which has otherwise been thoroughly reviewed through 12 iterations of the patch series. The series as a whole adds comprehensive OAuth support while fixing several other IMAP-related bugs and adding new features like folder listing.
