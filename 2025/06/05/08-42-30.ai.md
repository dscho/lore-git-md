This is a user experience improvement patch in the `imap-send` series, specifically addressing credential prompt clarity. The change modifies the credential helper's password request to include the port number alongside the hostname, matching the behavior of `git send-email`. 

The patch makes a straightforward one-line change in `imap-send.c` to format the host string with the port number when filling credentials. The credential prompt will now show URLs like `imaps://user@host:993` instead of just `imaps://user@host`. The author notes this makes the prompts more specific and consistent with other Git commands, while relying on the existing default port logic (993 for IMAPS, 143 for IMAP) when no port is explicitly configured.

This is a small but thoughtful polish to the credential interface that improves transparency about which server is being accessed. The change is minimal (a single line modifying the `cred->host` assignment to use `xstrfmt` with port) and follows established patterns from `git send-email`. As part of the larger `imap-send` overhaul, it contributes to making the IMAP functionality more consistent and user-friendly.
