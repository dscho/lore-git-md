This is a bugfix patch in a series improving `imap-send`. It addresses a critical regression introduced in Git 2.46.0 that made `imap-send` completely unusable. The issue stems from incorrect memory management in the configuration parser - when processing unrelated IMAP config fields (user, password, tunnel, auth method), the code was incorrectly freeing and NULLing the folder field instead of the field being configured. This patch fixes the logic to properly clear each config field individually.

The bug had gone unnoticed for some time, likely because most users prefer `git send-email` for email sending. The fix is straightforward - it corrects the `FREE_AND_NULL` calls to target the correct struct fields. This is the first patch in v13 of a larger series that adds OAuth2.0 support and other IMAP improvements, but this particular fix stands on its own as an important correction to a severe regression.
