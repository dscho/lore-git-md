This is a feature patch adding PLAIN authentication support to the OpenSSL backend of `imap-send`, part of the larger v13 series modernizing IMAP functionality. The patch implements RFC 4616-compliant PLAIN authentication for OpenSSL, which was only available via libcurl previously. The implementation includes a new `plain_base64()` helper function that properly constructs the authentication string (NUL-separated user and password) and handles base64 encoding, plus an `auth_plain()` handler that integrates with the existing IMAP command flow.

Key technical details include: the new `AUTH_PLAIN` capability flag, proper compile-time guards for OpenSSL availability, and updates to the imap.adoc documentation to list PLAIN as a supported method. The implementation follows the same pattern as other authentication methods in the series (OAUTHBEARER, XOAUTH2) with similar error handling and memory management. The patch maintains consistency with the broader series' approach to authentication while filling a specific gap in OpenSSL's supported methods.

This change enables PLAIN authentication (commonly used for app passwords) on OpenSSL builds, matching libcurl's existing support. The implementation is straightforward and well-contained, with clear RFC references and proper integration into the existing authentication flow. As part of the mature v13 series that has undergone extensive review, this patch appears ready for inclusion, completing the PLAIN authentication support across both backends.
