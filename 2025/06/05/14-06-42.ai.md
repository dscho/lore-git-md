Test modernization in the reftable subsystem: conversion of record tests to Clar framework (8/10). This patch continues the mechanical conversion of reftable unit tests from custom test-lib.h assertions to the Clar test framework, focusing on the record test file (t-reftable-record.c -> u-reftable-record.c). The changes follow the established pattern seen in earlier patches of the series, preserving all test logic while updating assertion syntax.

Key test cases being converted include:
- Varint encoding/decoding roundtrips and overflow detection
- Record comparison operations for ref, log, index and obj record types
- Roundtrip tests for each record type's encode/decode behavior
- Key encoding/decoding functionality

The patch removes the old test file from build systems (Makefile and meson.build) and updates assertions to use cl_assert* macros. Test functions are renamed to Clar's test_* naming pattern. All existing test coverage is maintained, with checks for record equality, comparison operations, and error conditions preserved in the new framework.

This is a straightforward mechanical conversion that follows the high-quality precedent set by earlier patches in the series. The changes are consistent with the overall goal of standardizing reftable tests on the Clar framework.
