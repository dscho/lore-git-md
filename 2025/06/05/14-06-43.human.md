Test modernization in the reftable subsystem. This is part 9/10 of a series converting all reftable unit tests from custom test-lib.h assertions to the Clar test framework. The patch converts the stack test file (t-reftable-stack.c -> u-reftable-stack.c), maintaining all existing test coverage while updating to Clar's cl_assert* macros.

The conversion follows the same high-quality pattern seen in earlier patches, with test logic preserved while modernizing the infrastructure. Key test cases include stack operations like adding/reading refs and logs, transaction handling, auto-compaction behavior, and error cases. The patch also removes the now-unused t-*.c glob check from the build system since this marks the completion of all test file migrations.

This mechanical but thorough change continues the reftable test modernization effort, bringing us one step closer to standardizing on the Clar framework for all unit tests in this subsystem. The changes look well-executed and consistent with the series' established approach.
