Test modernization in the reftable subsystem: conversion of record tests to Clar framework. This is patch 8/10 in a series completing the migration of all reftable unit tests from custom test-lib.h assertions to Clar. The patch converts t-reftable-record.c to u-reftable-record.c, updating all test assertions to use Clar's cl_assert* macros while preserving the existing test coverage. Key test cases being maintained include:

- Varint encoding/decoding and overflow detection
- Ref record comparison and roundtrip tests
- Log record comparison and roundtrip tests
- Obj record comparison and roundtrip tests
- Index record comparison and roundtrip tests
- Key encoding/decoding tests

The changes are mechanical but thorough, following the same high-quality pattern seen in earlier patches in the series. Build system updates (Makefile and meson.build) handle the file transition consistently. This continues the project's standardization on the Clar framework for all reftable unit tests.
