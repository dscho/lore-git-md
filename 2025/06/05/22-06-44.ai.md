Junio Hamano confirms the temporary workaround for the NO_TCLTK build regression can indeed be passed as a command-line argument to `make` (as `make NO_TCLTK=NoThanks`), just like other make variables such as V=1. He clarifies this will skip building gitk and git-gui, and notes that setting this in config.mak doesn't count as "modifying" since Git doesn't ship with a default config.mak file. This provides immediate relief for testers while the proper fix for the TCL file deletion issue is being finalized for the 2.50.0 release. The response is brief and technical, focused solely on answering the specific question about variable passing syntax without revisiting the broader build system issue.
