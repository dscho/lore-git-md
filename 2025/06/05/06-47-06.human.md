This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database subsystem (patches 16/17). The patch performs a mechanical conversion of the `pretend_object_file()` function to follow the established `odb_` naming convention, renaming it to `odb_pretend_object()`.

The change is straightforward - the function now takes an explicit `object_database` parameter instead of a `repository` parameter, matching the pattern seen in previous patches. The implementation remains functionally identical, just with updated parameter types and names. The function is used to temporarily cache an object in memory before it's written to persistent storage.

Since this is a rarely used function (only called in `blame.c` for fake working tree commits), no compatibility wrapper is provided. The patch includes the expected updates to the function declaration, implementation, and its single caller in `blame.c`.

This continues the series' systematic approach of converting object database functions to use explicit ODB parameters while maintaining consistent naming. The change is small and mechanical, following the well-established pattern from earlier patches in the series.
