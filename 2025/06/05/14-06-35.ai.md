Refactoring patch in the reftable test modernization series (1/10). This initial patch creates Clar-compatible versions of reftable test helper functions that were previously implemented for the custom test framework. The new implementations in lib-reftable-clar.{c,h} provide equivalent functionality for writing reftable data to buffers and setting hash values, but conform to Clar's conventions. Key technical details: the implementation includes a strbuf-backed writer, functions to write ref/log records to buffers with validation, and hash initialization helpers. The patch updates both Makefile and meson.build to include the new source files. This foundational work enables subsequent patches to convert individual reftable test files to use Clar while maintaining the same test coverage. The implementation appears thorough, with clear assertions and proper cleanup of resources.
