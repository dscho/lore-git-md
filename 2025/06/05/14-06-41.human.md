This is part 7/10 of a test modernization series converting reftable tests to the Clar framework. The patch converts the reftable read/write test file (t-reftable-readwrite.c) to use Clar assertions, following the established pattern from earlier patches in the series.

The changes are mechanical but thorough - all test cases are preserved while updating the assertion style from custom test-lib.h macros to Clar's cl_assert* variants. Key test areas covered include:
- Basic buffer operations and block source functionality
- Log record handling (buffer sizing, overflow conditions, write limits)
- Table read/write operations (sequential access, seeking, empty tables)
- Index behavior and multi-level indices
- Error handling for corrupted tables

The patch maintains the high quality seen in previous conversions, with careful attention to preserving test coverage while modernizing the infrastructure. Build system files (Makefile and meson.build) are updated to handle the old-to-new filename transition. This continues the systematic conversion of reftable tests to Clar, with only a few files remaining to be converted in the final patches of the series.
