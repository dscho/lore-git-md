Final patch in the reftable test modernization series. This cleanup patch removes the transitional `lib-reftable-clar.{c,h}` helper files that were introduced during the migration to the Clar test framework, renaming them back to the original `lib-reftable.{c,h}` names now that all tests have been converted. The changes include:

- Deletes the temporary `lib-reftable-clar` files
- Updates all test files to include `lib-reftable.h` instead of `lib-reftable-clar.h`
- Modifies build system files (Makefile and meson.build) to reflect the simplified structure
- Preserves test helper functionality while updating assertion macros from `check_*` to `cl_assert*` variants
- Leaves `test-lib.{c,h}` in place as it's still needed by other test components

The patch completes the mechanical but thorough conversion work that standardizes all reftable unit tests on the Clar framework, following the high-quality pattern established in earlier patches of this series. Build system changes remove now-unused patterns and simplify the test infrastructure.
