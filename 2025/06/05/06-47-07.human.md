This is the final patch in Patrick Steinhardt's v5 series converting Git's object database (ODB) subsystem to remove `the_repository` global state. The patch renames `read_object_with_reference()` to `odb_read_object_peeled()` to match the established `odb_` prefix convention and better describe the function's purpose of recursively "peeling" commit and tag objects until reaching the requested type.

The change is mechanical, updating 8 files (including documentation) that call this function. The new name more accurately reflects the function's behavior while maintaining the same parameters and functionality. As with previous patches in the series, no compatibility wrapper is needed since the function has limited usage.

This completes the core ODB conversion work in the series, which has systematically renamed and refactored object database functions to use explicit ODB parameters rather than relying on the global `the_repository`. The changes are well-contained and follow the same pattern established in earlier patches, making this a straightforward conclusion to the architectural refactoring effort.
