Bugfix follow-up addressing a memory leak in pack-bitmap boundary traversal. This is a minor refinement to Lidong Yan's recently merged series that fixed memory leaks in the bitmap boundary object handling.

The patch removes a conditional check before freeing the `roots_bitmap` in `find_boundary_objects()`, making the cleanup unconditional. The original code would only free the bitmap if `cascade_pseudo_merges_1()` failed, potentially leaking memory when it succeeded. The change is straightforward - just two lines modified to always free the bitmap.

A new test case is added to t5333 that specifically exercises this scenario by creating commits A and B, adding A to a pseudo-merge, then performing a boundary traversal from A to B. This would trigger the leak under the old code but now verifies proper cleanup.
