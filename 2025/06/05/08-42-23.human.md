This is a feature and bugfix series for `imap-send`, now in its 13th iteration, that makes the command usable again after configuration parsing regressions and adds OAuth2.0 authentication support. The series has undergone extensive review and appears to be in its final polishing stages.

The key fixes address a critical configuration parsing bug that made `imap-send` unusable since Git 2.46.0 by incorrectly NULLing the folder field. The new OAuth2.0 support works with both OpenSSL and libcurl backends, implementing both standard OAUTHBEARER and Google's XOAUTH2 protocols. Version 13 specifically fixes a logic error in the authentication method checking that was using OR operators instead of AND.

Beyond the core authentication work, the series adds several usability improvements:
- New `--folder` option to override the configured IMAP folder
- `--list` option to show available IMAP folders
- Better credential prompts showing host:port
- Progress output showing destination folder
- Various documentation and error message polish

The patch set touches configuration parsing, authentication handlers, IMAP protocol handling, and adds new folder listing capabilities. With all major technical issues resolved in previous versions, this iteration focuses on final correctness and consistency fixes. The series has been thoroughly reviewed by multiple Git maintainers and appears ready for final consideration.
