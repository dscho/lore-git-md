Test modernization in the reftable subsystem: conversion of readwrite tests to Clar framework. This is patch 7/10 in a series completing the migration of all reftable unit tests from custom test-lib.h assertions to Clar. The patch converts t-reftable-readwrite.c to u-reftable-readwrite.c, maintaining all existing test coverage while updating to Clar's cl_assert* macros. Key test cases preserved include buffer handling as a block source, log record compression and size limits, table seeking behavior (both linear and indexed), and various error conditions like corrupted tables and invalid writes. Build system updates (Makefile and meson.build) handle the file transition consistently. The conversion follows the established high-quality pattern seen in earlier patches, with test logic preserved while modernizing the infrastructure. Remaining patches will convert record and stack test files to complete the series.
