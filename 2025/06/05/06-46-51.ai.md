This is the first patch in Patrick Steinhardt's v5 series refactoring Git's object database subsystem as part of the `the_repository` removal effort. The patch renames the central `raw_object_store` structure to `object_database` (ODB) to better reflect its purpose and enable cleaner API naming.

The change addresses several naming issues: the "raw_" prefix was misleading (implying a non-raw variant that doesn't exist), and the new name better aligns with Git's terminology and existing code references to "object database". The rename enables more natural function names like `odb_has_object()` rather than unwieldy variants with "raw_object_store". The patch includes documentation clarifying the ODB's role in managing object storage backends.

This mechanical change touches 8 files with straightforward renames of the struct and related functions (`raw_object_store_new` -> `odb_new`, `raw_object_store_clear` -> `odb_clear`). The diff shows consistent updates across header files, implementation, and repository management code. As the foundational rename for the entire series, it establishes the naming pattern that subsequent patches will follow when converting ODB-related functions to explicit parameter passing.

The change is well-motivated in the commit message, explaining both the immediate naming improvements and how this fits into the larger goals of removing `the_repository` globals and enabling pluggable backends. The patch has already received review attention in previous iterations, with the naming approach now stabilized.
