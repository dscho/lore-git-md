Feature patch adding OAuth2.0 authentication support to `imap-send`, part of a larger v13 series that has undergone extensive review. This specific patch implements both RFC-standard OAUTHBEARER and Google-proprietary XOAUTH2 authentication methods for the IMAP client.

The implementation spans three main areas: documentation updates explaining OAuth2.0 for Gmail/Outlook users, core authentication handlers in `imap-send.c`, and libcurl integration. The patch adds new helper functions `oauthbearer_base64()` and `xoauth2_base64()` to construct the proper authentication strings, following RFC5801/RFC7628 specifications for OAUTHBEARER and Google's protocol for XOAUTH2. Both methods are implemented for the OpenSSL backend with proper compile-time guards, while the curl backend leverages `CURLOPT_XOAUTH2_BEARER` which automatically handles both protocols.

Key technical details include the auth string construction format (notably the GS2 header for OAUTHBEARER), proper base64 encoding via OpenSSL's `EVP_EncodeBlock`, and conditional password handling that skips traditional password auth when using OAuth methods. The documentation provides specific configuration examples for both Gmail and Outlook, noting Outlook's exclusive support for XOAUTH2 and Gmail's MFA requirements when not using OAuth.

This appears to be a well-constructed implementation that follows the established patterns of the existing IMAP authentication code while adding modern OAuth support.
