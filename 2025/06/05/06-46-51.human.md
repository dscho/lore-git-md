This is the first patch in Patrick Steinhardt's v5 series refactoring Git's object database subsystem as part of the `the_repository` removal effort. The patch renames the core `raw_object_store` structure to `object_database` (ODB) to better reflect its purpose and enable cleaner API naming.

The change addresses two key issues: the current awkward "raw_" prefix that implies a non-existent variant, and the need for clearer subsystem attribution in function names. The new name aligns with existing terminology in the codebase and allows for more natural function names like `odb_has_object()`. The patch makes this rename across 8 files, updating both the type definition and all related function signatures.

This foundational change is well-motivated and mechanically sound, touching only the structural rename without altering behavior. It sets the stage for subsequent patches that will convert implicit `the_repository` usage to explicit ODB parameters. The patch has already been reviewed positively in previous iterations, with Justin Tobler confirming the naming choice.
