Test modernization: conversion of reftable priority queue tests to Clar framework (part 5/10). This patch continues the systematic conversion of reftable unit tests from custom test-lib.h assertions to the Clar framework, focusing on the priority queue implementation (t-reftable-pq.c -> u-reftable-pq.c). 

The changes follow the established pattern seen in previous patches: test functions are renamed to Clar's `test_*__*` convention, assertions are converted to `cl_assert*` macros, and the test driver is removed in favor of Clar's test discovery. The patch maintains all existing test coverage for priority queue operations including:
- Record-based comparison (`test_reftable_pq__record`)
- Index-based comparison (`test_reftable_pq__index`)
- Queue top operations (`test_reftable_pq__merged_iter_pqueue_top`)

Build system updates (Makefile and meson.build) remove the old test program and add the new Clar suite consistently with prior conversions. The changes appear mechanical and correct, properly translating the original test logic while removing custom test infrastructure. This maintains the series' high quality standard for completing the reftable test modernization effort.
