Feature patch adding folder listing to `imap-send`, the final patch in a v13 series introducing OAuth2.0 support and other IMAP improvements. This adds a `--list` option that shows available IMAP folders, which vary across providers (e.g., Gmail's "[Gmail]/Trash" vs Outlook's "Deleted"). The implementation handles both OpenSSL and libcurl backends, following RFC6154 for OpenSSL and libcurl's example code for its backend. The output shows folder names and hierarchy markers, helping users identify the correct folder names to use in configuration. The patch includes documentation updates and maintains consistency with the series' earlier style cleanups. This completes the series' goal of comprehensive IMAP functionality by addressing the last major missing feature - folder discovery.
