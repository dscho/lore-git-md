This is part 6/17 of Patrick Steinhardt's series to refactor Git's object database subsystem, continuing the effort to remove `the_repository` global state. The patch converts `assert_oid_type()` to take an explicit object database parameter instead of relying on the global repository, renaming it to `odb_assert_oid_type()` in the process.

The change is mechanical but important - it removes another dependency on `the_repository` while maintaining identical behavior. The function verifies that an object exists and is of the expected type (commit, tree, etc.), and now does so by using the repository pointer stored in the passed object database rather than the global. The patch updates three call sites in commit-tree and commit handling code to pass `the_repository->objects`.

This continues the series' pattern of methodically converting functions to use explicit ODB parameters. The changes are straightforward - just adding the parameter and updating callers - with no behavioral impact. The patch is cleanly implemented and fits well with the series' architectural goal of making the object database subsystem more modular and less dependent on global state.
