Refactoring patch in the ongoing `the_repository` removal series. This is patch 5/17 in Patrick Steinhardt's v5 series to refactor Git's object database subsystem.

The patch removes the dependency on `the_repository` in the `find_odb()` function by passing in the object database directly, and renames the function to `odb_find_source()` for consistency with the new naming scheme. The changes are mechanical but important for the larger goal of eliminating global state - callers now explicitly pass the object database they want to search rather than relying on the implicit `the_repository`.

The patch updates three call sites (in commit-graph and midx code) and moves the function declaration to group it with other object database operations in odb.h. The changes are straightforward and maintain the same behavior while improving the API design. This continues the series' pattern of methodically converting each piece of the ODB subsystem to work without global state.
