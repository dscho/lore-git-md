Test modernization: conversion of reftable priority queue tests to Clar framework. This is patch 5/10 in a series converting reftable unit tests from custom test-lib.h assertions to the Clar test framework.

The patch converts t-reftable-pq.c to u-reftable-pq.c, maintaining all test cases while switching to Clar's assertion macros. The tests verify priority queue functionality for reftable records, including:
- Record-based comparison (test_reftable_pq__record)
- Index-based comparison (test_reftable_pq__index)
- Queue top operations (test_reftable_pq__merged_iter_pqueue_top)

The changes follow the same mechanical pattern as previous patches in the series, replacing custom test-lib.h assertions with Clar equivalents (cl_assert, cl_assert_equal_i, etc.) and updating the test function signatures. Build system files (Makefile and meson.build) are updated to reflect the file rename and new Clar test registration.

This appears to be a straightforward conversion that maintains the original test coverage while standardizing on the Clar framework, continuing the series' goal of modernizing reftable test infrastructure.
