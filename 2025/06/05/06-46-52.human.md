This is part 2/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove `the_repository` global state. The patch renames `struct object_directory` to `struct odb_source` to better reflect its role as an access point for object storage, independent of whether that storage is actually directory-based.

The change anticipates future work to support pluggable ODB backends where objects might be stored in non-filesystem locations like databases. The commit explains the naming choice (`odb_source` was selected over alternatives like `odb_backend` or `odb_alternate`) and shows the mechanical updates across 28 files to handle the rename.

This is a straightforward but wide-reaching change that touches many parts of Git's object storage code. The patch appears well-executed with a clear commit message explaining the rationale. As part of the larger ODB refactoring effort, it helps establish consistent terminology before more substantial architectural changes land.
