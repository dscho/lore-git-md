Part of the reftable test modernization series converting tests to the Clar framework. This patch (3/10) focuses on the block test file (t-reftable-block.c -> u-reftable-block.c), maintaining all existing test coverage while switching from custom test-lib.h assertions to Clar's cl_assert* macros.

The converted tests verify core reftable block functionality across four block types: ref, log, obj, and index. Each test follows the same pattern - initializing a block writer, adding records, verifying write operations, then reading back and validating the data. Key assertions check:
- Block writer/iterator initialization and cleanup
- Record addition and validation (including error cases like empty refnames)
- Binary search behavior via block_iter_seek_key
- Record equality comparisons with hash validation
- Iterator positioning and traversal

The patch makes mechanical changes to:
- Rename test functions to test_reftable_block__* convention
- Replace check()/check_int() with cl_assert()/cl_assert_equal_i()
- Remove the test_done() harness since Clar handles test execution
- Update build files (Makefile/meson.build) to use new u- prefix

This appears to be a straightforward conversion maintaining all existing test coverage while aligning with the series' goal of standardizing on Clar. The changes are consistent with patches 1-2 in the series, focusing purely on test infrastructure rather than modifying the reftable implementation itself.
