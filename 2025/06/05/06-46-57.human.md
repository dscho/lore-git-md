This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database subsystem. Patch 7/17 continues the mechanical conversion work, this time focusing on `odb_mkstemp()`.

The patch removes `the_repository` usage from the temporary file creation function by passing the object database explicitly. This affects several callers across the codebase that create temporary pack files, bitmaps, and other object-related data. The changes are straightforward - each caller now passes `the_repository->objects` (or the repository's object database where available) to the function.

The implementation updates both the fast path (direct mkstemp call) and slow path (fallback with directory creation) to use the provided ODB's repository pointer rather than the global. The odb.h documentation is updated to clarify that files are created in the primary alternate's directory.

This follows the established pattern from earlier patches in the series, maintaining consistency with the broader refactoring effort. The changes touch 7 files with mostly mechanical updates, all following the same simple pattern. The patch appears well-contained and low-risk, continuing the methodical approach seen throughout this architectural refactoring series.
