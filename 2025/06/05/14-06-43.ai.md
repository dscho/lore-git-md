Reftable test modernization: stack test conversion (9/10). This patch converts the reftable stack test file (t-reftable-stack.c) to use the Clar test framework (u-reftable-stack.c), completing the migration of all reftable unit tests. The conversion follows the established pattern seen in previous patches, preserving all test logic while updating assertions to use cl_assert* macros.

Key test cases maintained include:
- Basic stack operations (add_one, add_multiple)
- Transaction API behavior (transaction_api, transaction_with_reload)
- Auto-compaction logic (auto_compaction, auto_compaction_factor)
- Concurrency scenarios (compaction_concurrent, reload_with_missing_table)
- Error handling (lock_failure, invalid_limit_updates)

The patch also removes the now-unused t-*.c pattern check from the build system (Makefile and meson.build) since this is the final test file. The changes are mechanical but thorough, maintaining all existing test coverage while modernizing the infrastructure. This conversion represents the penultimate step in the reftable test modernization series, with only one remaining patch to complete the effort.
