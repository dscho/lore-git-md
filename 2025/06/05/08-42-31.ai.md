This is a user experience improvement patch in the `imap-send` series, adding destination folder information to progress output. The change modifies two functions (`append_msgs_to_imap` and `curl_append_msgs_to_imap`) to display the target folder name when sending messages, making the output more informative. The new format shows "Sending N message(s) to FOLDER folder..." instead of just the count.

The patch is part of a larger v13 series that has been thoroughly reviewed, with this being the second-to-last patch focusing on final polish. It builds on earlier work that standardized log message formatting throughout `imap-send.c`. The change is straightforward - just adding the folder name parameter to existing fprintf calls - but provides better visibility into where messages are being delivered.

Key technical details: modifies progress output in both OpenSSL and libcurl backend paths, maintains the existing pluralization logic ("message" vs "messages"), and follows the series' convention of ending progress messages with ellipses. The patch touches only the user-facing output strings, not the underlying IMAP protocol handling.
