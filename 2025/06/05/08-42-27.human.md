Bugfix patch in the `imap-send` series, addressing CRAM-MD5 authentication when OpenSSL is unavailable. This is part of a larger v13 series that adds OAuth2.0 support and fixes various IMAP authentication issues.

The patch improves error handling when users attempt CRAM-MD5 authentication without OpenSSL support compiled in. Previously this would crash with a `die()` call; now it provides a clear error message and exits gracefully. The change moves the CRAM-MD5 authentication function earlier in the file and adds a compile-time check for OpenSSL before attempting the authentication.

This is a straightforward improvement to user experience, preventing crashes when users attempt an unsupported authentication method. The change is well-contained and follows the pattern established by other authentication methods in the code. As part of the comprehensive IMAP series that has undergone extensive review, this patch helps complete the authentication system's robustness.
