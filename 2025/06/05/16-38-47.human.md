This is a brief follow-up in a thread about version-specific behavior of `git config` subcommands. Scott Birl confirms they've encountered the same issue with Git 2.40.0 as originally reported with 2.39.5, where `git config get` fails with a confusing error message about section parsing. They acknowledge Kristoffer Haugsbakk's explanation that the subcommand syntax was introduced in Git 2.46.0 and that older versions require the `--get` flag instead.

The email serves as a simple confirmation that the version compatibility issue affects multiple pre-2.46.0 releases, but doesn't introduce new technical details or questions. The thread appears to be winding down now that the root cause is understood and the workaround (`git config --get`) is confirmed effective.
