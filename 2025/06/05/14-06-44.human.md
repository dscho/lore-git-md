Final patch in reftable test modernization series. This is the 10th patch in a series converting reftable unit tests from Git's custom test framework to the Clar framework. The patch cleans up the remaining infrastructure by removing the now-unused `lib-reftable-clar.{c,h}` files (which were temporary helpers during the transition) and renaming the Clar-compatible versions back to the original `lib-reftable.{c,h}` names. It also updates build system files (Makefile and meson.build) to remove references to the old test framework.

The changes are mechanical and follow the same high-quality approach seen throughout the series. The patch maintains all existing functionality while simplifying the codebase by eliminating transitional artifacts. With this change, the reftable test suite is now fully standardized on the Clar framework, completing a significant modernization effort for this subsystem's testing infrastructure.
