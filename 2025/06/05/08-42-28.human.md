Feature patch adding command-line folder override to `git imap-send`. This is part of a larger v13 series improving IMAP functionality, which includes OAuth2.0 support and configuration fixes.

The patch introduces a new `-f`/`--folder` option to `git imap-send`, allowing users to specify the destination IMAP folder at runtime rather than relying solely on the `imap.folder` config setting. The documentation is updated to clarify that the config value serves as a fallback when no command-line option is given.

Implementation is straightforward - the option is added to the command-line parser, and when provided, it overrides the configured folder value. This matches similar override patterns elsewhere in Git and provides flexibility for users who frequently need to send to different folders.

As part of the comprehensive IMAP series that has undergone extensive review, this change fits naturally with the other usability improvements. The patch is cleanly implemented with corresponding documentation updates and maintains consistency with existing code patterns.
