This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database (ODB) subsystem. Patch 10/17 focuses on converting two functions that manage temporary primary ODB sources to explicitly take an object database parameter instead of relying on the global.

The patch renames `set_temporary_primary_odb()` to `odb_set_temporary_primary_source()` and `restore_primary_odb()` to `odb_restore_primary_source()`, making them follow the established `odb_` prefix convention. Both functions now take an explicit `object_database` parameter, continuing the series' pattern of removing implicit repository dependencies.

The changes are mechanical but important for the larger goal of enabling pluggable ODB backends. The patch updates 3 files (odb.c, odb.h, and tmp-objdir.c) with straightforward conversions and corresponding documentation updates. As with previous patches in the series, this maintains backward compatibility while moving toward the new architecture.

This continues the methodical, well-documented approach seen throughout the series. The changes are consistent with the established pattern and don't introduce new concepts, making this a relatively straightforward continuation of the refactoring work.
