This is patch 9/17 in Patrick Steinhardt's ongoing series to remove `the_repository` global from Git's object database (ODB) subsystem, part of the larger `the_repository` removal effort. The patch converts iterator-style functions that operate on alternate ODBs to take explicit `object_database` parameters instead of relying on the global state.

The key changes rename and refactor three functions:
- `foreach_alt_odb()` becomes `odb_for_each_alternate()`
- `for_each_alternate_ref()` becomes `odb_for_each_alternate_ref()`
- The internal `alternate_ref_fn` callback type becomes `odb_for_each_alternate_ref_fn`

The patch updates 8 call sites across various subsystems (count-objects, receive-pack, submodule--helper, diagnose, fetch-pack, and revision) to use the new API. The changes are mechanical but wide-ranging, touching core functionality like alternate ref handling and diagnostics. The implementation follows the established pattern from previous patches in the series, maintaining the same callback semantics while removing implicit repository access.

This continues the methodical conversion of ODB-related functions to explicit parameters, building on the infrastructure established in earlier patches (renamed types, standardized `odb_` prefix, repository tracking via parent pointers). The changes are consistent with the series' goal of enabling pluggable ODB backends by eliminating global state dependencies.
