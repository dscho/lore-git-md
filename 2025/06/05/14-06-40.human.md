Refactoring: Part 6/10 of the reftable test modernization series, converting the table test to Clar framework.

This patch continues the mechanical conversion of reftable unit tests from custom test-lib.h assertions to the Clar framework. It focuses on the table functionality tests, specifically:

1. Renames t-reftable-table.c to u-reftable-table.c and updates build files (Makefile and meson.build) accordingly
2. Converts three test functions to Clar style:
   - `test_reftable_table__seek_once`: Tests basic ref record seeking
   - `test_reftable_table__reseek`: Verifies repeated seeking works
   - `test_reftable_table__block_iterator`: Exercises block iteration logic

The changes are straightforward mechanical conversions, replacing custom check() macros with Clar's cl_assert* equivalents while preserving all test coverage. Like previous patches in the series, this maintains the same test cases but expresses them in the standard Clar format. The patch follows the established pattern seen in earlier conversions (basics, block, merged, and pq tests) and appears ready for inclusion.
