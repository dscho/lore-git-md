This is a build system clarification in response to a critical regression affecting NO_TCLTK builds in Git 2.50.0-rc1.

Junio Hamano confirms that the temporary workaround (`NO_TCLTK=NoThanks`) can indeed be passed directly as a command-line argument to `make`, just like other common make variables such as `V=1`. This provides immediate relief for testers experiencing the TCL file deletion issue without requiring edits to `config.mak`. He notes this will skip building gitk and git-gui, which is the expected behavior when TCL/Tk support is disabled.

The response also clarifies that modifying `config.mak` isn't considered harmful since it's a user-controlled file (not shipped with Git). This addresses Randall Becker's practical concern about how to test rc1 while avoiding the build-time file deletion bug.
