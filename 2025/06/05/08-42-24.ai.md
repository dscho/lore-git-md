Bugfix for `imap-send` configuration parsing regression introduced in Git 2.46.0. This is the first patch in a v13 series that primarily adds OAuth2.0 support and other IMAP improvements.

The patch fixes a critical regression where `cfg->folder` was incorrectly being NULLed out when processing unrelated configuration variables (`imap.user`, `imap.pass`, `imap.tunnel`, `imap.authmethod`). The bug originated from commit 6d1f198f34 which attempted to fix memory leaks but introduced incorrect field clearing logic. The fix properly NULLs out each config field individually rather than incorrectly clearing the folder field for all config operations.

This regression made `git-imap-send` completely unusable since Git 2.46.0, though it appears to have gone unnoticed for some time, likely due to most users preferring `git-send-email`. The patch simply corrects the `FREE_AND_NULL` operations to target the correct struct fields for each configuration variable.

The changes are straightforward - four lines modifying which field gets cleared in the configuration parsing logic. This appears to be a well-scoped fix for a clear regression, though it's notable that the bug persisted for nearly a year before being caught. The patch is part of a larger series that has undergone extensive review, with this particular fix being uncontroversial and clearly necessary.
