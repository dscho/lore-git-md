Reftable test modernization: final conversion to Clar framework (complete). This 10-patch series by Patrick Steinhardt and Karthik Nayak has now fully migrated all reftable unit tests from custom test-lib.h assertions to the Clar framework. The first nine patches converted basics, block, merged table, priority queue, readwrite, record, and stack functionality tests (t-*.c -> u-*.c), preserving all test coverage while updating to Clar's cl_assert* macros. The final patch (10/10) completes the effort by removing transitional lib-reftable-clar.{c,h} helper files and renaming them back to lib-reftable.{c,h}, updating includes and build systems (Makefile and meson.build) to reflect the simplified structure. All test helper functionality remains intact while standardizing on Clar's assertion macros. The series maintains the high-quality pattern seen throughout, with careful attention to preserving test coverage during the infrastructure modernization. This completes the reftable subsystem's transition to the Clar framework, aligning with Patrick Steinhardt's broader test modernization efforts and the project's adoption of unit testing patterns from libgit2. The build system now reflects this completed transition by removing obsolete patterns and checks related to the old test infrastructure.
