Reftable test modernization: complete conversion to Clar framework (final). This 11-patch series by Patrick Steinhardt, Karthik Nayak, and Seyi Kuforiji fully migrates all reftable unit tests from custom test-lib.h assertions to the Clar framework, converting basics, block, merged table, priority queue, readwrite, record, stack, and table functionality tests (t-*.c -> u-*.c). The series includes Seyi Kuforiji's conversions of all test files, preserving test cases while updating assertions to Clar's cl_assert* macros and following the established pattern of replacing test-lib.h functions with Clar equivalents.

The final patch removes transitional `lib-reftable-clar.{c,h}` helper files and renames them back to `lib-reftable.{c,h}`, updating function names from `t_reftable_*` to `cl_reftable_*` to match Clar conventions. Build systems are simplified by removing `UNIT_TEST_PROGRAMS` references and consolidating on `CLAR_TEST_SUITES`, eliminating 179 lines of redundant code while maintaining all test functionality. The changes update references in all converted test suites (u-reftable-*.c) to point to the renamed header, with helper functions (`cl_reftable_set_hash`, `cl_reftable_strbuf_writer`, `cl_reftable_write_to_buf`) retaining their functionality but using Clar's assertion macros.
