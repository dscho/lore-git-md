Reftable test modernization: complete conversion to Clar framework (final). This 10-patch series by Patrick Steinhardt, Karthik Nayak, and Seyi Kuforiji fully migrates all reftable unit tests from custom test-lib.h assertions to the Clar framework, converting basics, block, merged table, priority queue, readwrite, record, stack, and table functionality tests (t-*.c -> u-*.c). The series includes Seyi Kuforiji's conversion of the basics test file (t-reftable-basics.c -> u-reftable-basics.c) preserving all test cases for binary search, string array utilities, buffer operations, and endian conversion helpers while breaking edge cases into separate Clar test functions.

The block test (t-reftable-block.c -> u-reftable-block.c) conversion by Seyi Kuforiji maintains all test cases for REF, LOG, OBJ, and INDEX block types and their operations (read/write, iterator behavior) while updating assertions to use Clar's cl_assert* macros. The merged table test (t-reftable-merged.c -> u-reftable-merged.c) conversion preserves all test cases for merged table operations including single record handling, multiple refs/log records, seek behavior, and update index range verification while maintaining REFTABLE_HASH_SHA1/SHA256 handling and REFTABLE_BLOCK_TYPE_REF/LOG iterator behavior.

Key technical details preserved across all conversions include REFTABLE_HASH_SIZE_SHA1 comparisons, REFTABLE_BUF operations, REFTABLE_ALLOC_GROW behavior, and all endian conversion tests. The conversions follow the established pattern: replacing test-lib.h's check() with cl_assert(), check_int() with cl_assert_equal_i(), removing cmd_main() wrapper in favor of Clar's function naming (test_reftable_*__operation), and using cl_reftable_write_to_buf() helper for test setup while preserving all edge case testing.

The final patch will remove transitional lib-reftable-clar.{c,h} helpers and rename them back to lib-reftable.{c,h}, updating build systems (Makefile and meson.build). The series began with Seyi Kuforiji's initial patch introducing Clar-compatible test helpers (lib-reftable-clar.{c,h}) that provided key utilities while maintaining reftable-specific details. Build systems are updated to move tests from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES, showing significant line reduction (1331 deletions vs 1117 insertions overall) due to Clar's concise syntax while maintaining 62-75% similarity in test logic.

The series demonstrates successful collaboration between Patrick Steinhardt, Karthik Nayak, and Seyi Kuforiji to complete this multi-phase modernization, with Seyi contributing conversions of t-reftable-basics.c, t-reftable-block.c, t-reftable-merged.c, t-reftable-table.c, t-reftable-readwrite.c, and t-reftable-record.c alongside the initial helper infrastructure. The changes are non-controversial and ready for merging, representing the culmination of Patrick Steinhardt's broader effort to standardize on Clar for reftable testing.
