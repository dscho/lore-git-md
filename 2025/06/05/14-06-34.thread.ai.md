Reftable test modernization: final conversion to Clar framework (v4). This 10-patch series completes the migration of all reftable unit tests from custom test-lib.h assertions to the Clar test framework. The first six patches (1-6/10) introduced Clar-compatible test helpers and converted basics, block, merged table, priority queue, and table functionality tests. Patch 7/10 now converts the readwrite tests (t-reftable-readwrite.c -> u-reftable-readwrite.c), maintaining all existing coverage while updating to Clar's cl_assert* macros. Key preserved test cases include buffer handling as block source, log record compression/size limits, table seeking behavior (linear and indexed), and error conditions (corrupted tables, invalid writes). Build system updates (Makefile and meson.build) handle the file transition consistently. The conversion follows the established high-quality pattern seen in earlier patches, with test logic preserved while modernizing the infrastructure. Remaining patches will convert record and stack test files to complete the series. The mechanical but thorough changes finalize the reftable test modernization effort, standardizing on Clar framework for all unit tests in this subsystem.
