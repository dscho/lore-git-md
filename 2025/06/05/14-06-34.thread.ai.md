Reftable test modernization: final conversion to Clar framework (v4). This 10-patch series completes the migration of all reftable unit tests from custom test-lib.h assertions to the Clar test framework, converting each reftable test file (basics, block, merged, pq, table, readwrite, record, stack). The first patch (1/10) introduced Clar-compatible test helpers in lib-reftable-clar.{c,h} including strbuf-backed writers, ref/log record writers with validation, and hash initialization helpers, plus build system updates. Patch 2/10 converts the basics test file (t-reftable-basics.c -> u-reftable-basics.c) with full coverage of core functionality: binary search (binsearch), string array utilities (names_length, names_equal, parse_names), buffer operations (common_prefix_size), big-endian encoding/decoding (put/get_be{16,24,32,64}), and memory allocation (REFTABLE_ALLOC_GROW variants). All test functions follow the test_* naming and use cl_assert* assertions while maintaining identical test cases. Changes since v3 focused on code refactoring and cleanup based on review feedback. The series appears ready for merging as it finalizes the reftable test modernization effort, with remaining patches to convert block, merged, pq, table, readwrite, record, and stack test files. Build system updates (Makefile and meson.build) handle the t- to u- prefix transition consistently across all test files.
