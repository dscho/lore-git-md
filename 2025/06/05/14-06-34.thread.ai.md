Reftable test modernization: complete conversion to Clar framework (final). This 11-patch series by Patrick Steinhardt, Karthik Nayak, and Seyi Kuforiji fully migrates all reftable unit tests from custom test-lib.h assertions to the Clar framework, converting basics, block, merged table, priority queue, readwrite, record, stack, and table functionality tests (t-*.c -> u-*.c). The series includes Seyi Kuforiji's conversions of the priority queue test (t-reftable-pq.c -> u-reftable-pq.c), table test (t-reftable-table.c -> u-reftable-table.c), readwrite test (t-reftable-readwrite.c -> u-reftable-readwrite.c), record test (t-reftable-record.c -> u-reftable-record.c), and now the final stack test (t-reftable-stack.c -> u-reftable-stack.c), preserving all test cases while updating assertions to Clar's cl_assert* macros.

The conversions follow the established pattern: replacing test-lib.h's check() with cl_assert(), check_int() with cl_assert_equal_i(), removing cmd_main() wrapper in favor of Clar's function naming (test_reftable_*__operation), and using cl_reftable_write_to_buf() helper for test setup. The stack test conversion specifically maintains testing of stack operations (add, read, iterator behavior), transaction handling, auto-compaction behavior, concurrency scenarios, and edge cases like tombstone records and hash ID validation (REFTABLE_HASH_SIZE_SHA1 comparisons). All conversions preserve REFTABLE_BUF operations, REFTABLE_ALLOC_GROW behavior, varint encoding tests, and endian conversion tests from the original implementations.

Build systems are updated to move tests from UNIT_TEST_PROGRAMS to CLAR_TEST_SUITES, showing significant line reduction (1331 deletions vs 1117 insertions overall, with stack test showing 780 -> 332 line reduction) due to Clar's concise syntax while maintaining test logic. The series demonstrates successful collaboration between Patrick Steinhardt, Karthik Nayak, and Seyi Kuforiji to complete this multi-phase modernization, with Seyi contributing conversions of t-reftable-basics.c, t-reftable-block.c, t-reftable-merged.c, t-reftable-pq.c, t-reftable-table.c, t-reftable-readwrite.c, t-reftable-record.c, and t-reftable-stack.c alongside the initial helper infrastructure.

The final patch removes transitional lib-reftable-clar.{c,h} helpers and renames them back to lib-reftable.{c,h}, updating build systems (Makefile and meson.build) to eliminate the last remaining t-*.c file and corresponding glob check. The changes are non-controversial and ready for merging, representing the culmination of Patrick Steinhardt's broader effort to standardize on Clar for reftable testing, with Junio Hamano's sign-off confirming readiness for integration.
