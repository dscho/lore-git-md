This is a documentation patch improving the `git send-email` SSL certificate configuration instructions. It's the first of five patches in a series aimed at making sendemail documentation more complete and practical.

The patch clarifies the documentation around `--smtp-ssl-cert-path` by explicitly naming OpenSSL's verify(1) manual page as the reference for understanding the `-CAfile` and `-CApath` options, and adds a direct link to OpenSSL's documentation. The change makes it clearer where users should look for authoritative information about certificate validation, addressing what the author describes as confusing wording in the original text.

The modification is straightforward and well-contained, touching only the git-send-email.adoc file. This appears to be a direct response to prior feedback in the thread (as noted in the thread summary) about improving sendemail documentation, though the patch stands on its own merits regardless of that context. The change should help users who need to configure custom certificate authorities for their SMTP connections.
