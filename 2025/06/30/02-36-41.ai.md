This is a patch in Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database subsystem. The patch converts the `find_odb()` function to take an explicit `object_database` parameter and renames it to `odb_find_source()`, following the established naming convention for the ODB API.

The change is mechanical but important - it eliminates one more dependency on global state while maintaining the same functionality. The patch updates all callers (though the exact number isn't specified in this email) to pass the repository's ODB explicitly. This continues the series' systematic approach of converting functions one by one to use the new ODB API.

Justin Tobler notes this addresses a previous comment about the function naming, showing the series is incorporating feedback from reviewers. The change appears straightforward and well-contained, with no new functionality or behavior changes - just the mechanical conversion needed for the larger architectural goal of removing `the_repository` from the ODB subsystem.

Key technical details for future reference:
- Original function: `find_odb()`
- New function: `odb_find_source()` with explicit `struct object_database *odb` parameter
- Part of establishing consistent `odb_` prefix convention
- Updates all existing callers to pass `the_repository->objects` explicitly
- Follows same pattern as previous conversions in the series
