Documentation patch continuing the git-config man page updates. This is part 3 of a 5-part series documenting recently added command-line options following the ps/config-subcommands merge.

The patch adds documentation for the `--value=<pattern>` and `--no-value` options, which were introduced in commit fe3ccc7aab but not previously documented. These options work with `get`, `set`, and `unset` subcommands to match against a pattern (treated as an extended regular expression unless `--fixed-value` is used). The documentation follows the established convention seen in earlier parts of the series.

The changes are straightforward and mechanical documentation updates that match the actual implementation. The patch continues the series' work of standardizing terminology, here replacing the older `value-pattern` positional argument with the new `--value` option syntax. Like the rest of the series, this appears to be a well-justified update that brings the documentation in line with current behavior.
