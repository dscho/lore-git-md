This is the first patch in a 2-part series removing `the_repository` usage from `builtin/prune.c`, specifically targeting the `repository_format_precious_objects` global variable as part of the broader `the_repository` removal effort.

The patch moves the `repository_format_precious_objects` configuration flag from being a global variable to being a member of `struct repository`. This affects several commands that check this setting: `gc`, `prune`, and `repack`. The changes follow a straightforward pattern of replacing direct global variable access with `the_repository->repository_format_precious_objects` lookups.

Key technical changes include:
- Adding the new field to `struct repository` in `repository.h`
- Initializing it during repository setup in `repository.c` and `setup.c`
- Removing the global declaration from `environment.h` and `environment.c`
- Updating all usage sites to use the repository-scoped version instead

The changes touch core repository initialization paths and multiple builtins, but the impact is contained to the precious objects functionality.
