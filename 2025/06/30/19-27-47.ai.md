This is the second patch in a 3-part series refactoring sparse-checkout configuration as part of the `the_repository` removal effort. It specifically migrates the `core.sparsecheckoutcone` setting from the `core_sparse_checkout_cone` global variable to the `repo_settings` struct.

The patch makes several key changes:
1. Moves config parsing of `core.sparsecheckoutcone` from `config.c` to `repo-settings.c` via `prepare_repo_settings()`
2. Updates all access sites (10 files) to use `the_repository->settings.sparse_checkout_cone` instead of the global
3. Adds a missing `prepare_repo_settings()` call in `unpack-trees.c` where initialization was previously missing
4. Documents the access pattern change in `builtin/grep.c`'s comments
5. Removes the now-unused global variable declarations from `environment.c` and `environment.h`

The changes follow the same direct access pattern established in prior migrations, with careful attention to initialization safety. The patch demonstrates good test coverage through the sparse-checkout command's extensive test suite, though no behavioral changes are introduced. This represents a clean, well-contained step in the broader effort to eliminate repository globals.
