This is a test modernization and feature patch series for the interactive patch commands' diff context configuration support.

Junio C Hamano provides a minor but important suggestion on the patch series' subject line. The current "test: use test_grep" and "test: use test_config" subjects are too broad, implying a project-wide change when the patches actually only update specific test files (t3701, t4055, and t9902). This version includes test modernization (converting grep calls to test_grep and git config calls to test_config) as well as implementing command-line overrides (-U/--unified and --inter-hunk-context) for the diff context settings.
