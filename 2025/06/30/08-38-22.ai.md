This is the final patch in a series improving Git's clang-format integration, specifically adding meson build system support for the `git clang-format` wrapper. The patch introduces a new 'style` target in meson.build that mirrors the existing Makefile functionality, allowing developers to run the formatter against their working tree changes rather than the entire codebase.

The implementation uses meson's `find_program()` to locate the `git-clang-format` wrapper (a resolved point from earlier thread discussion) and creates a run target that invokes it with the same parameters as the Makefile version: file-based styling, diff output, and limiting to C/h files. The target is optional, gracefully handling cases where clang-format isn't installed.

This completes the series' goal of making clang-format tooling consistent across build systems while maintaining the project's selective formatting approach. The change is straightforward with no apparent technical concerns, building on the thread's earlier resolution of meson integration questions. The patch-specific impact is limited to meson.build, with no runtime effects or behavior changes beyond adding the new build target.
