Git daemon signal handling bugfix addressing EINTR in child process reaping. Patch modifies daemon.c to properly handle waitpid() interruptions (EINTR) that could leave zombie processes, while converting other waitpid() errors into BUG() reports for debuggability. Fixes issue dating back to 2008 child reaping refactoring that persisted through 2010 run-command API migration. Changes preserve existing successful cases (pid > 0) and no-child cases (pid == 0), explicitly retry on EINTR, and treat other errno values as bugs with PID context in error messages.
