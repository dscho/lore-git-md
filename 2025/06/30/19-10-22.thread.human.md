This thread documents updates to the git-config(1) man page following the merge of the ps/config-subcommands series. The 5-patch series standardized documentation of command-line options, including `--[no-]show-names` and `--url`, while converting terminology from `value-pattern` to `--value=<pattern>`.

After merging, Junio C Hamano discovered a test failure in t0450.142 where the documentation's synopsis (`--value=<pattern>`) didn't match the actual help output (`--value=<value>`). Kristoffer Haugsbakk, who prepared the documentation patches, explains they didn't run the t0450 tests during development, which is how this inconsistency slipped through. The test specifically verifies alignment between documentation and help output using specialized helpers.

While the documentation updates are now complete (touching only git-config.adoc), there remains one open issue: the help text implementation still shows the old `--value=<value>` wording. This will need a follow-up patch to maintain consistency with the now-standardized `--value=<pattern>` terminology used throughout the documentation. The thread serves as both a post-mortem of how this mismatch occurred and a reminder to include these verification tests in future documentation work.
