This is a review comment on patch 4/17 of Patrick Steinhardt's series to refactor Git's object database subsystem. Justin Tobler is providing feedback on the introduction of parent pointers between object databases and their owning repositories.

The patch adds parent pointers from `struct object_database` to its repository and from `struct odb_source` to its object database, which will be needed for future config lookups. Justin notes that while the pointers are set up here, they aren't yet used - that will come in later patches.

Justin identifies one specific issue: a comment references `r->objects->alternate_by_path` but should instead reference `odb->source_by_path` to match the new naming scheme. This appears to be a minor documentation oversight in an otherwise correct mechanical change to pass the ODB through the alternates handling code.

The feedback is constructive and focused - Justin understands the architectural changes and is helping ensure naming consistency across the series. This is the kind of careful review that helps maintain quality during large-scale refactoring work. The parent pointer addition itself looks sound and properly integrated into the alternates handling code.
