This is part 1 of a 2-patch series in the ongoing `the_repository` removal effort, moving the `repository_format_precious_objects` global variable into `struct repository`. The patch is the first step in converting the `prune` builtin to use repository instances rather than globals.

The change migrates the `preciousObjects` configuration flag (which prevents operations that might drop objects) from being a global variable to being repository-specific storage. The patch updates all callers in `gc.c`, `prune.c`, and `repack.c` to access the flag via `the_repository->repository_format_precious_objects` instead of the global variable. The implementation looks clean and thorough, with appropriate updates to repository initialization paths in `setup.c` and `repository.c`.

This appears to be a well-executed refactoring that follows established patterns for removing globals. The commit message clearly explains the motivation as part of the broader effort to improve modularity and libification.
