This is a feature patch completing the command-line override implementation for diff context configuration in interactive patch commands (add/checkout/commit/reset/restore/stash). It builds on previous work that made these commands respect diff.context and diff.interHunkContext configs.

The patch introduces OPT_DIFF_UNIFIED and OPT_DIFF_INTERHUNK_CONTEXT macros for parse-options to allow command-line overrides (-U/--unified and --inter-hunk-context) of the config values. This matches behavior seen in other Git commands like diff and log. The implementation passes context parameters through the add-patch infrastructure using struct add_p_opt and includes comprehensive man page updates and test coverage.
