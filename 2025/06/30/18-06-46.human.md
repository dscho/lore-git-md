Documentation patch adding sendmailCmd explanation to git-send-email. This is the 4th in a 5-part series improving sendemail configuration docs.

The patch adds a new section explaining the `sendmailCmd` option, which allows using external sendmail-like commands instead of git-send-email's built-in SMTP client. The documentation covers both the general use case (preferring an alternative SMTP client) and specific scenarios (working with proprietary email APIs that don't use SMTP).

The new section provides a concrete example using msmtp and links to several community-maintained helpers including the author's own git-protonmail and git-msgraph tools. The protonmail reference connects to the series' upcoming final patch about Proton Mail configuration. The documentation is clear and practical, following the established style of the surrounding content. 

This continues the series' pattern of addressing real-world configuration needs while maintaining consistency with existing documentation structure. The examples and links make this particularly useful for users needing to integrate with non-standard email setups.
