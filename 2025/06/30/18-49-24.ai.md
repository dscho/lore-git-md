Performance test addition for the `git last-modified` command series.

This patch adds a performance test script for the new `git last-modified` command, which tracks file modification history. The test script measures three scenarios: basic top-level operation, recursive traversal, and subdirectory-specific checks. The tests use the default test repository and focus on detecting performance regressions rather than correctness (which is covered by the regular test suite).

The implementation is straightforward, following Git's existing performance test patterns. It measures:
1. Simple `last-modified` execution on HEAD
2. Recursive operation with `-r` flag
3. Operation on a specific subdirectory (dynamically selected from the repository)
