This is a refactoring patch in Patrick Steinhardt's series to remove `the_repository` global state from Git's object database subsystem. The patch converts `find_odb()` to take an explicit `object_database` parameter and renames it to `odb_find_source()`, following the series' naming conventions.

The change is mechanical but important - it eliminates one more dependency on global state while maintaining the same functionality. Justin Tobler confirms this addresses a previous naming suggestion, indicating the series is being actively reviewed and refined. The patch updates all callers to pass the new parameter, showing thorough attention to the conversion's scope.

As part of the larger architectural effort to enable pluggable ODB backends, this change helps establish cleaner API contracts between components.
