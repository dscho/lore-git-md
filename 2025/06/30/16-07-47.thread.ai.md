Dan Pristupov reports the command fails with "fatal: invalid filter-spec" when given paths like "HEAD:changelog.md", working in 2.47.1.windows.2 but broken in 2.50.0.windows.1. The regression appears introduced by commit eb83e4c64b ("cat-file: handle NULL object_context.path", 2024-05-20) merged via a271b05066, part of a series handling NULL object_context.path cases. The report provides clear reproduction steps but no root cause analysis or proposed fix. Key technical details: broken command format `git cat-file --filter "HEAD:path"`, error message "fatal: invalid filter-spec", affected versions 2.50.0.windows.1 vs working 2.47.1.windows.2. The regression appears Windows-specific based on version strings and affects real usage scenarios.
