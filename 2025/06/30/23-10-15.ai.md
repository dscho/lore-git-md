Documentation update with test failure. This email from Junio C Hamano points out a test failure in t0450 that occurs when running the recently submitted documentation patch series for `git-config` subcommands. The test compares the synopsis in the man page (git-config.adoc) against the `-h` help output and finds a mismatch: the adoc file shows `--value=<pattern>` while the help output shows `--value=<value>`. This reveals an inconsistency between the documented interface (which was updated in the patch series to standardize on "pattern" terminology) and the actual command-line help text.

The test failure specifically occurs in test 142 ("config -h output and SYNOPSIS agree") which verifies that the synopsis in the documentation matches the help output. The diff shows the adoc file correctly reflects the new standardized terminology (pattern) while the help text still uses the older (value) formulation. This suggests the implementation's help text needs to be updated to match the now-documented interface.

Key technical details for future reference: the test is t0450.142, the mismatch is between `--value=<pattern>` (documented) and `--value=<value>` (implemented), and the test uses helper functions `adoc_to_synopsis` and `help_to_synopsis` to compare the outputs. The original patch series (ps/config-subcommands) that introduced these changes was merged in fe3ccc7aab, with specific behavior coming from commits 4e513890008 and d4770964d50. This appears to be an oversight where the help text wasn't updated when the terminology was standardized in the documentation.
