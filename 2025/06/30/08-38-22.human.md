This is the final patch in a series improving Git's clang-format integration, specifically adding meson build system support. The patch introduces a 'style' target to meson that mirrors the existing Makefile functionality, allowing developers to run `git clang-format` (which formats only changed code) rather than the default `clang-format` that processes all files.

The implementation uses meson's `find_program()` to locate the git-clang-format wrapper and creates a run target with the same flags as the Makefile version: using the project's .clang-format style file, showing diffs rather than modifying files directly, and limiting to C/h file extensions. This completes the build system parity between make and meson for style formatting.

The patch builds on previous thread discussion where meson integration was tested and validated, with Justin Tobler confirming the wrapper location works correctly. It's a straightforward addition that follows the series' theme of making clang-format tooling more robust and consistent across build systems. The change is low-risk as it only adds a new target without modifying existing behavior.
