This is a feature patch completing the command-line override implementation for diff context configuration in interactive patch commands (add/checkout/commit/reset/restore/stash). It builds on the previous patch that made these commands respect diff.context and diff.interHunkContext configs.

The patch introduces OPT_DIFF_UNIFIED and OPT_DIFF_INTERHUNK_CONTEXT macros in parse-options.h to standardize the command-line interface for these options across commands. It passes the context parameters through the add-patch infrastructure via struct add_p_opt and includes comprehensive man page updates and test coverage.

Junio C Hamano raises two concerns in his review: (1) whether the specialized OPT_DIFF_* macros are worth adding to the parse-options API given their narrow use case, and (2) the potential for duplicated validation logic across different command implementations. While he finds the approach technically reasonable, these design choices may warrant further discussion.

The implementation appears complete with all interactive commands now supporting both config-based and command-line-specified diff context settings, with CLI options taking precedence. This matches the behavior of other Git commands like diff and log. The patch represents the final piece of functionality in this series after extensive test modernization and documentation work.
