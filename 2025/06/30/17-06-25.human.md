Bugfix clarification for `git cat-file` option syntax. Phillip Wood points out that the reported regression with `--filter` is actually due to a misunderstanding of the option name - the correct long form is `--filters`. The command previously accepted the abbreviated `--filter` but this changed in Git 2.50 when a separate `--filter` option was introduced. Phillip notes that while abbreviated options are convenient for interactive use, scripts should always use the full option name for stability. This isn't actually a regression but rather a case where previously accepted (but technically incorrect) syntax stopped working when new functionality was added. The explanation helps clarify the root cause of the behavior change that Dan observed between Git 2.47.1 and 2.50.0 on Windows.
