This is a refactoring patch that moves the `RemoveBracesLLVM` clang-format rule from CI-specific configuration into Git's main `.clang-format` file. The rule removes optional braces from simple single-statement control blocks (if/else/for/while) when they follow LLVM style guidelines, while preserving braces in more complex cases like multi-statement if/else cascades.

The change follows successful testing in CI since July 2024 (commit 1b8f306612) with no reported issues. The patch removes the temporary CI-specific implementation that previously applied this rule through a generated config file, instead making it a permanent part of Git's formatting rules. The CI script is simplified to use the main `.clang-format` file directly.

This is part of a 3-patch series (v2) improving Git's clang-format integration, building on resolved discussions about meson build system support and dropping earlier controversial .editorconfig changes. The series maintains Git's 80-character line guideline while shifting line-wrapping responsibility to developers. This particular patch represents a non-controversial consolidation of a formatting rule into the main configuration.
