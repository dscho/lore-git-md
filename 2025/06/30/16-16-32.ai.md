This is a test modernization and feature completion patch series in the ongoing effort to support configurable diff context in interactive patch commands. The series builds on previous work to make `diff.context` and `diff.interHunkContext` work with `--patch` mode commands (add/checkout/commit/reset/restore/stash).

The first two patches modernize test infrastructure by converting `grep` to `test_grep` and `git config` to `test_config` in specific test files (t3701, t4055, t9902) rather than globally. Junio C Hamano suggests clarifying the scope in the commit messages to avoid implying a broader change.

The key functional changes come in the last two patches:
1. Makes the add-patch infrastructure properly read and respect `diff.context` configuration
2. Implements command-line overrides (-U/--unified) that take precedence over config values

The series appears to complete the implementation work, with all interactive commands now supporting both config-based and command-line diff context configuration.
