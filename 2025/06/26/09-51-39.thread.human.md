This thread discusses a straightforward cleanup of git-daemon's networking code, removing an obsolete check that enforced socket file descriptors to be below FD_SETSIZE. The original patch from Carlo Marcelo Arenas Belón points out this validation became unnecessary after the code switched from select() to poll() back in 2005, referencing two historical commits that provide context.

Phillip Wood has reviewed the change and confirmed it looks good, indicating this cleanup is likely to be accepted. The patch simply removes a 5-line validation block in daemon.c that hasn't been functionally relevant for nearly two decades, affecting both IPv4 and IPv6 socket creation paths. This appears to be a low-risk removal of historical cruft that should proceed without further discussion.
