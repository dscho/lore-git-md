Platform compatibility patch for Windows signal handling, part of the ongoing Git daemon signal handling series. This patch enables `sigaction(SIGCHLD)` support in the Windows compatibility layer, preparing for future changes to the signal handler setup. The change makes the `sigaction()` behavior match the existing `signal()` implementation by returning -1 (error) for SIGCHLD while maintaining current functionality for SIGALRM. The patch also adds the SA_NOCLDSTOP flag definition needed for proper signal handling structure support.

This is the second of four patches in v3 of the series addressing cross-platform signal handling issues. The changes are narrowly focused on Windows compatibility while the broader thread discusses architectural choices between SA_RESTART toggling and self-pipe approaches for signal handling. The patch appears straightforward and well-contained, with clear motivation tied to the series' goals.
