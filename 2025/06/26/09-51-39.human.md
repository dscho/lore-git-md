This is a bugfix patch for the Git daemon, removing an outdated socket file descriptor check that's no longer needed.

Carlo Marcelo Arenas Belón removes a validation check in `daemon.c` that was ensuring socket file descriptors were below `FD_SETSIZE`. This restriction dates back to 2005 when the daemon used `select()`, which has since been replaced with `poll()` that doesn't have this limitation. The patch simply deletes the now-redundant check.

The change is straightforward - just 5 lines removed from the socket setup code. The commit message clearly explains the check's historical context and why it's safe to remove now. This appears to be a clean, well-justified removal of obsolete code that should have no functional impact since we're already using `poll()`.
