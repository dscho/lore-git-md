This is a bugfix patch targeting the git-daemon networking code. It removes an outdated file descriptor size check that became unnecessary after a 2005 switch from select() to poll().

The patch removes a validation in daemon.c that enforced socket file descriptors to be below FD_SETSIZE, which was required for select() but not for poll(). The commit message traces this back to two historical changes: df076bdbcc (2005) which introduced the check when using select(), and 6573faff34 (2005) which switched to poll() but left the now-unneeded check in place.

The change is straightforward - it simply deletes 5 lines of validation code in setup_named_sock() that would reject sockets with descriptors >= FD_SETSIZE. The patch appears well-motivated by historical context and correctly identifies obsolete code. Since poll() has been used for nearly 20 years, this cleanup seems safe and appropriate.

Key technical details for future reference:
- Removes FD_SETSIZE check in daemon.c's setup_named_sock()
- Affects IPv4/IPv6 socket creation path
- Original restriction came from select() limitations in 2005
- Poll() has been used since 2005 without this restriction
- No behavior change expected - just removing dead code
