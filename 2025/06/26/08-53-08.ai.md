This is the final patch in a bugfix series addressing signal handling issues in the Git daemon, specifically around zombie process cleanup on OpenBSD and crashes on AIX. The patch focuses on ensuring reliable EINTR behavior during poll() operations when SIGCHLD signals are received.

The change introduces a new `set_sa_restart()` helper function that toggles the SA_RESTART flag around poll() calls in the daemon's service loop. This ensures poll() will properly interrupt with EINTR when child processes terminate, allowing timely zombie reaping. The implementation includes platform-specific version for systems supporting SA_RESTART (via NO_RESTARTABLE_SIGNALS detection) and a no-op version for others.

Key technical details include:
- SA_RESTART flag manipulation around poll() calls in daemon.c
- Conditional compilation based on NO_RESTARTABLE_SIGNALS
- Maintains existing error handling for non-EINTR poll() failures
- Preserves the service loop's socket event processing logic
- Follows the series' approach of SA_RESTART toggling rather than self-pipe

This patch represents the SA_RESTART-based solution path in the ongoing architectural discussion, providing a working implementation that addresses the immediate issues while leaving the door open for a potential future transition to the self-pipe approach. The change is technically sound but carries the complexity inherent in platform-specific signal handling that the self-pipe alternative would avoid.
