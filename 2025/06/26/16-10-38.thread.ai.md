Thread identity: Bugfix for Git daemon's socket handling during interrupted system calls (EINTR).

Core problem: The daemon incorrectly advances to next socket on EINTR during accept(), potentially leaving clients waiting. Root cause traced to 2005 behavior when IPv6 support was introduced.

Current status: Initial patch version proposing fix, with minor editorial feedback received. Modifies service_loop() in daemon.c with retry logic.

Key technical details:
- Adds EINTR-specific retry loop (max 2 attempts) before socket advance
- Calls check_dead_children() between retries
- Preserves existing EAGAIN/ECONNABORTED fallthrough
- 14-line change focused on service_loop() error handling
