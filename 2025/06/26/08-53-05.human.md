This is a platform compatibility patch that improves the detection and handling of systems without SA_RESTART signal handling support. It's part of a v3 series addressing Git daemon signal handling issues on OpenBSD and AIX.

The patch centralizes the handling of SA_RESTART support by:
1. Introducing a new NO_RESTARTABLE_SIGNALS Makefile variable to track platforms lacking SA_RESTART
2. Moving platform-specific SA_RESTART definitions from individual headers to compat/posix.h
3. Adding proper detection in configure.ac and meson.build
4. Cleaning up redundant definitions in platform-specific files like compat/mingw-posix.h

The changes affect Windows, NonStop, and QNX platforms where SA_RESTART isn't available. This is groundwork for the larger signal handling fixes in the series, making the code more maintainable by properly identifying platforms that need special handling rather than using ad-hoc definitions.

The patch appears well-structured and focused, with clean separation between the build system changes and core compatibility code. It follows the pattern established in the thread of improving the SA_RESTART detection before deciding between the SA_RESTART toggling approach and the alternative self-pipe solution.
