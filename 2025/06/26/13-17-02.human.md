This is a bugfix patch for git-daemon that removes an obsolete file descriptor size check. The patch is a straightforward removal of validation code that enforced socket descriptors to be below FD_SETSIZE, a restriction that was necessary when using select() but became irrelevant after the 2005 switch to poll().

Phillip Wood replies to Carlo Marcelo Arenas Belón's initial patch submission, giving it a positive review with a simple "Nice find, this patch looks good to me." The patch itself removes 5-line validation block from daemon.c's socket setup code that was checking for descriptors >= FD_SETSIZE.

The change is a clear cleanup of technical debt - the FD_SETSIZE check has been unnecessary for nearly 20 years since the switch to poll(), which doesn't have the same descriptor size constraints as select(). The patch appears well-justified with references to the relevant historical commits that provide context for this cleanup.

This is a small, focused change that should be uncontroversial - it removes dead code without any behavior change, and has already gotten positive feedback from one reviewer. The patch is ready for inclusion unless other maintainers spot any issues.
