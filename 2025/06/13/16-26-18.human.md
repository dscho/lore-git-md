This is a documentation refinement in the ongoing merge/pull compact summary feature thread. Git maintainer Junio Hamano responds to Kristoffer Haugsbakk's suggestion about improving the help text for the new `--compact-summary` option. 

Haugsbakk had previously noted that "compactstat" in the help text was too dense and suggested "compact stat" instead. Hamano agrees with the need for improvement but proposes "compact summary" as an even better alternative, since it matches the actual option name `--compact-summary`. 

This is a minor but thoughtful polish to the recently introduced feature that provides more readable merge/pull diffstat output.
