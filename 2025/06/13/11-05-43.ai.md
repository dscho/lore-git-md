Feature implementation refinement for the `git last-modified` command, specifically addressing Bloom filter integration. This patch builds on the established core functionality to optimize path modification tracking by leveraging Bloom filters when available.

The key technical changes in this revision:
- Adds Bloom filter checks via `maybe_changed_path()` to skip unnecessary diff computations
- Initializes Bloom filter settings in `last_modified_init()`
- Cleans up Bloom keys in `last_modified_release()`
- Includes generation number handling (though this may be removable)
