This is a platform compatibility fix for Git's build system, specifically addressing sed portability issues on Solaris. The patch makes two changes: modifying GIT-VERSION-GEN to ensure input ends with newline before sed processing (fixing a regression from v2.49.0), and updating generate-configlist.sh to use basic regex instead of extended regex (-E) for Solaris compatibility (a new issue in the 2.50 cycle).

The technical changes involve converting sed patterns from extended to basic regex syntax (replacing `?` with `*` for optional backticks) and adding `\n` to printf in version generation. Jeff King confirms the changes are correct despite some stylistic reservations about the sed approach. The patch maintains functionality while improving portability.
