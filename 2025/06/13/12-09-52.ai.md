This is a follow-up discussion on the merge.stat configuration extension for compact summaries. Kristoffer Haugsbakk raises several documentation and interface consistency points regarding Junio Hamano's patch that added `compact` as a tri-state option for `merge.stat`.

Key observations:
1. Questions whether `diffstat` should be an alias for `true` given historical context, though recognizes `true` must remain for backward compatibility.
2. Notes the documentation currently shows `git diff --diffstat ORIG_HEAD` as the `true` behavior, but `--diffstat` isn't actually a valid git-diff option (should be `--stat`).
3. Suggests simplifying the default value phrasing from "If this variable is left unspecified, it defaults to `true`" to just "Defaults to `true`", aligning with most other documentation.

The email doesn't propose code changes but identifies documentation inaccuracies and opportunities for consistency improvements in the recently added merge.stat configuration options. These are all editorial suggestions building on the already-accepted technical implementation of the compact summary feature.
