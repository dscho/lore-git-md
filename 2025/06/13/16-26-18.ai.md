This is a documentation refinement in the ongoing merge/pull compact summary thread. Junio Hamano responds to Kristoffer Haugsbakk's suggestion about improving the help text for the new `--compact-summary` option. The original patch used the term "compactstat" in the help text, which Haugsbakk found too dense, proposing "compact stat" instead. Hamano agrees with the need for improvement but suggests "compact summary" would be even better, as it matches the actual option name `--compact-summary`.

This is a minor but thoughtful follow-up to the already-accepted technical implementation of compact merge summaries. The exchange shows attention to detail in making the interface more intuitive, though it doesn't affect the functionality itself. The change would appear in the help text shown when users run `git merge --help`. This kind of polish is typical in the final stages of a feature's development cycle.
