Junio Hamano's latest "What's cooking" report provides a comprehensive snapshot of Git's development pipeline. The most pressing issue is reverting a regression affecting big-endian systems, which comes at the cost of temporarily dropping Windows ARM64 support - a tradeoff favoring stability over new functionality.

Several significant technical efforts are progressing well: the ongoing removal of `the_repository` global (with preload-index changes), major cleanup of endianness handling in compat/bswap.h, and memory leak fixes across multiple subsystems. Documentation work continues with CodingGuidelines updates and Jean-Noël Avila's manpage conversion to AsciiDoc.

Notable new features include an enhanced `git imap-send` with OAuth2 support, batched reference updates for network operations, and path-based delta compression in pack-objects. The build system sees improvements with better Meson test handling and platform-specific fixes for Solaris and FreeBSD. Some topics have been discarded, particularly the problematic bswap.h changes that broke Windows builds, while others need rerolls before reconsideration. The overall focus remains on stabilizing the codebase for the upcoming release.
