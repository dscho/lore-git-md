This thread introduces a documentation patch that clarifies how to properly clone the pre-built Git documentation repositories needed for the `quick-install-html` target. The patch explains that users should clone from the gitster GitHub account (which uses the expected `git-htmldocs` and `git-manpages` repository names and `master` branch) rather than the git organization's repositories (which use different naming conventions and a `gh-pages` branch that can cause the build to fail).

The change adds explicit clone instructions to the Documentation/Makefile comments to help users avoid this potential pitfall. While the patch is straightforward and correctly implemented, the author notes some uncertainty about the indentation style in the Notes section. This appears to be a minor but helpful documentation improvement that doesn't affect the actual build logic.
