Bugfix for `git cat-file` mailmap handling when author and committer differ. This patch addresses two specific issues in the mailmap application code that caused incorrect parsing of commit/tag objects with different author and committer identities.

The core problem stems from newline handling in `apply_mailmap_to_header()` where the code wasn't properly advancing past newlines after processing each identity line, causing subsequent header parsing to fail. Additionally, the patch fixes potential invalid memory access when buffer reallocations occur during mailmap rewrites. The bug was introduced in 2022 during a rewrite of the mailmap handling code.

Siddharth Asthana provides two new test cases in t4203-mailmap.sh that verify the fix works for both committer-only mappings and cases where both author and committer need mapping. The patch has already been reviewed by Christian Couder and incorporates all feedback, including proper handling of buffer reallocations and test script style improvements.

This is a straightforward fix for a real-world issue reported by a GitLab user, with thorough test coverage confirming the solution works as intended. The patch appears ready for merging with no outstanding concerns.
