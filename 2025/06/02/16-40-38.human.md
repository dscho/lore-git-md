This is the first of two preparatory patches in a series adding GPG signing support to `git subtree`. The patch switches the command's argument parsing to use `--stuck-long` mode, which is necessary to cleanly handle the optional parameter for the upcoming `-S/--gpg-sign` option.

The changes refactor how `git-subtree.sh` processes command-line arguments, moving from positional parameter handling to the more robust `--stuck-long` style where options and their values are passed together (e.g., `--branch=name` instead of `-b name`). This affects several existing options including `--annotate`, `--branch`, `--prefix`, `--message`, and `--onto`.

The patch is mechanical and focused - it doesn't introduce new functionality but prepares the ground for the GPG signing support in the next patch. The changes maintain backward compatibility while making the code more consistent with Git's standard option parsing behavior. The diff shows careful attention to preserving all existing functionality while simplifying the parsing logic.
