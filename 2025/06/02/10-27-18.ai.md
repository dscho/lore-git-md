This is the final patch in Patrick Steinhardt's v4 series refactoring Git's object database subsystem to remove `the_repository` global state. The patch renames `read_object_with_reference()` to `odb_read_object_peeled()`, completing the systematic conversion of ODB-related functions to the new naming convention.

The function is used to recursively "peel" commit and tag objects until reaching an object of the requested type (typically a blob or tree). The new name better reflects this behavior compared to the more generic original name. The patch updates 8 files including documentation, builtins (cat-file, fast-import, grep, pack-objects), and core ODB handling code. 

Notable technical details:
- The function signature changes to take an `object_database` parameter instead of `repository`
- No compatibility wrapper is provided since the function has limited usage (only 8 call sites)
- Documentation in user-manual.adoc is updated to reference the new name
- The implementation now uses the ODB's repo pointer for hash algorithm details rather than accessing `the_repository` directly
- Follows the established pattern of the series by using `odb_` prefix and explicit ODB parameter

This concludes the mechanical conversion work in the series, having renamed all major ODB-related functions while maintaining behavior through direct caller updates. The change is low-risk given the function's narrow usage and follows the same proven approach as previous patches in the series.
