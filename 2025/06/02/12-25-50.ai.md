This is the second patch in a 10-part series converting reftable tests to use the Clar framework. The patch focuses on migrating the "basics" test file, which tests fundamental reftable utilities like binary search, string array handling, and buffer operations.

The conversion follows the established pattern from the series: replacing the custom test assertions with Clar's `cl_assert*` functions, splitting the monolithic test into individual test functions, and updating build system references. The test cases themselves remain substantively the same, verifying behaviors like:
- Binary search correctness with various edge cases
- String array utilities (`names_length`, `names_equal`, `parse_names`)
- Buffer prefix comparison (`common_prefix_size`)
- Big-endian number encoding/decoding
- Memory allocation growth patterns

Key technical changes include:
- File renamed from `t-reftable-basics.c` to `u-reftable-basics.c` per Clar conventions
- Test cases converted from `if_test` blocks to individual `test_reftable_basics__*` functions
- Custom `check()` macros replaced with `cl_assert*` equivalents
- Build system (Makefile and meson.build) updated to reference new test file

The patch appears mechanically sound, maintaining all original test coverage while conforming to Clar's structure. It builds on the foundation established in patch 1/10 (lib-reftable-clar helpers) and follows the same conversion approach seen in other subsystem migrations.
