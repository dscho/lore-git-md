This is part of the ongoing `the_repository` removal effort, specifically focusing on the object storage subsystem. The patch renames the `raw_object_store` structure to `object_database` (ODB) to better reflect its purpose and prepare for making the object subsystem more self-contained.

The change addresses two key issues: the awkward "raw_" prefix that implied (incorrectly) there might be a non-raw variant, and the need for clearer subsystem attribution in function names. The new name aligns with existing terminology in the codebase and allows for more concise function names like `odb_has_object()` instead of the unwieldy `raw_object_store_has_object()`.

The patch is the first in a 17-part series, suggesting this is foundational work for larger changes to come. It updates function signatures and type declarations across multiple files (object-store.[ch], repository.[ch], packfile.[ch], commit-graph.[ch]) while maintaining the same functionality. The changes are mechanical but widespread, touching core object storage infrastructure.
