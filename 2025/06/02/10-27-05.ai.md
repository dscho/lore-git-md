This is part of the ongoing `the_repository` removal effort, specifically introducing parent pointers between object databases and their owning repositories. The patch adds bidirectional links between `struct object_database` and `struct repository`, as well as between `struct odb_source` and its owning object database. This enables future patches to access repository-specific configuration without relying on the global `the_repository` variable.

Key technical changes include:
- Adding `repo` field to `struct object_database` and `odb` field to `struct odb_source`
- Modifying `odb_new()` to take a `struct repository` parameter
- Updating all callers of `link_alt_odb_entry()` and related functions to pass through the object database rather than repository
- Ensuring proper parent pointers are set when initializing repositories and alternate object databases

The changes are mechanical but touch several core object database functions. The patch maintains existing behavior while enabling the gradual removal of `the_repository` dependencies. This appears to be a well-structured step in the larger refactoring effort, with clear commit message explaining the motivation and scope.
