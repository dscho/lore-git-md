User experience improvement for `imap-send`. This patch adds the destination folder name to the progress output when sending messages via IMAP, making it clearer where messages are being delivered. The change affects both the OpenSSL and libcurl backends, showing messages like "Sending 1 message to Drafts folder..." instead of just "Sending 1 message". 

This is part of a larger v11 series that has been thoroughly reviewed, adding OAuth2.0 support, folder management features, and fixing various bugs in `imap-send`. The change is straightforward and uncontroversial, following the series' pattern of improving user feedback. Junio Hamano's response ("Nice ;-)") suggests approval of this small but helpful usability enhancement.
