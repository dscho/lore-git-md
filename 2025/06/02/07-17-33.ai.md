This is a refactoring patch in Patrick Steinhardt's v3 series (12 patches) addressing maintenance task race conditions. The patch fixes the typedef declarations for function pointers in `builtin/gc.c`.

The change makes `maintenance_task_fn` and `maintenance_auto_fn` proper function pointer typedefs rather than just function signatures. Previously, users of these types had to manually add the pointer syntax (`*`) when declaring variables, which was inconsistent with typical C function pointer patterns. The patch updates both the typedefs and their usage in the `maintenance_task` struct to use the correct pointer syntax.

This is a straightforward quality improvement that:
- Makes the code more idiomatic by following standard C function pointer patterns
- Reduces potential confusion for future readers
- Requires no behavior changes
- Affects only internal implementation details
- Maintains compatibility with existing callers

The change is minimal (5 lines modified) and focused solely on type system correctness within the maintenance task infrastructure. It continues the series' pattern of improving code quality while working toward resolving the core race condition issues. The patch doesn't require test updates since it's purely a type system change with no runtime impact.
