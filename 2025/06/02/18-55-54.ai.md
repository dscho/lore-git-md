This is a feature patch adding a new formatting atom to `git cat-file`'s batch mode, part of a 3-patch series enhancing object inspection capabilities.

The patch introduces a new `%(objectmode)` format specifier that displays the octal file mode (permissions) for tree entries when using path-based object specifications (`<tree-ish>:<path>`). For objects without mode information (like commits or tags), it returns an empty string. The implementation adds a `mode` field to the `expand_data` struct, initialized to `S_IFINVALID`, and includes thorough test coverage verifying the new atom works with various object types and path specifications.

Key technical details:
- New `%(objectmode)` atom joins existing format specifiers like `%(objecttype)` and `%(objectsize)`
- Mode is stored in `expand_data` struct with `S_IFINVALID` sentinel value
- Tests updated to verify mode output for blobs referenced via tree paths (100644/100755)
- Original test framework extended to handle mode parameter in `run_tests` helper
- Documentation updated in `git-cat-file.adoc`

The patch builds on the test infrastructure changes from patch 1/3, demonstrating the new atom's behavior with both regular and space-containing paths. It maintains compatibility with the test suite's handling of different hash algorithms. The implementation appears clean and well-tested, with clear documentation of the new feature's behavior.
