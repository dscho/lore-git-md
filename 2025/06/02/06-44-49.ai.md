This is a refactoring patch in Patrick Steinhardt's Meson test integration series (v4 09/10). It introduces a `test_kwargs` dictionary in the Meson build system to consolidate common test parameters, starting with the `timeout: 0` setting that was previously duplicated across multiple test definitions. The change affects test configurations in `contrib/credential/netrc/`, `contrib/subtree/`, and the main test suite, moving the timeout parameter into a centralized location in `meson.build`. This prepares for adding more shared test parameters in future commits while maintaining the same behavior. The patch is a straightforward mechanical change that doesn't modify test functionality, only the way common parameters are specified. It's part of the broader effort to improve Meson test integration that has already undergone extensive review, with all technical concerns addressed in previous iterations.
