Feature patch adding folder listing capability to `imap-send`, completing the v12 series' IMAP functionality improvements. This final patch introduces a `--list` option that shows available IMAP folders with RFC6154-compliant output, addressing the common issue where different servers (Gmail, Outlook) use varying naming conventions for standard folders like Drafts and Trash.

The implementation handles both OpenSSL and libcurl backends, with OpenSSL using direct IMAP LIST commands and libcurl following its documented example. The output shows folder hierarchies and attributes (like `\HasNoChildren` flags), helping users identify correct folder names for configuration. Documentation updates explain the new option and suggest its use when troubleshooting folder-not-found errors.

Key technical details:
- New `list_folders` flag and `--list` option in `imap-send.c`
- Separate `list_imap_folders()` and `curl_list_imap_folders()` implementations
- Modified buffer handling to show LIST responses when in list mode
- Conditional logic in `cmd_main` to skip folder validation when listing
- Documentation updates showing example Gmail output and usage guidance

This concludes the series' major features after addressing all review feedback, with the implementation now cleanly handling both authentication methods (OAuth2.0, PLAIN, CRAM-MD5) and folder management (override, listing) across backends. The patch maintains consistency with the series' style improvements for error messages and progress output.
