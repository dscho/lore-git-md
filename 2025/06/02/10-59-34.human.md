This is a feature patch in the ongoing `imap-send` authentication improvements series, specifically adding PLAIN authentication support for the OpenSSL backend. The patch ensures consistent PLAIN auth availability across both libcurl and OpenSSL implementations, addressing a gap where OpenSSL previously only supported the older IMAP LOGIN command.

The change adds a new `AUTH_PLAIN` capability flag and implements the RFC 4616-compliant PLAIN method with proper base64 encoding of credentials. The implementation includes a new `plain_base64()` helper function and `auth_plain()` handler, plus compile-time guards to ensure OpenSSL support. Documentation is updated to list PLAIN among the supported methods when using OpenSSL.

This is part of a well-developed v12 series that has seen extensive review, with this particular patch completing the PLAIN auth implementation that was previously only available via libcurl. The change is straightforward and aligns with the series' goal of providing comprehensive, consistent authentication methods across all backends. The patch appears technically sound with proper error handling and follows the established patterns from other auth methods in the codebase.
