This is part 14/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem, continuing the systematic conversion of ODB-related functions to use the new `odb_` prefix convention and remove `the_repository` global state.

The patch renames `repo_read_object_file()` to `odb_read_object()` to align with the established naming pattern (`odb_read_object_info()`, `odb_has_object()`, etc.). It introduces a compatibility wrapper to maintain backwards compatibility with in-flight topics. The change is mechanical, touching 47 files to update all callers while maintaining identical behavior.

Key technical details:
- The new signature takes an `object_database *` parameter instead of `struct repository *`
- The function remains a thin wrapper around `odb_read_object_info_extended()`
- The patch follows the same conversion pattern as previous patches in the series (adding ODB parameter, renaming with `odb_` prefix)
- All call sites are updated to pass `the_repository->objects` as the ODB parameter

This continues the series' progression toward enabling pluggable ODB backends by removing the last `the_repository` dependencies from the ODB subsystem. The change is well-contained and low-risk, following the established conversion pattern that has already been reviewed in earlier patches.
