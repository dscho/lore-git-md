This is a feature patch adding OAuth2.0 authentication support to `imap-send`, part of a larger v12 series that has been through extensive review. The patch introduces two OAuth2.0 authentication methods: the standard OAUTHBEARER (RFC 5801/7628) and Google's proprietary XOAUTH2.

The implementation adds new helper functions (`oauthbearer_base64()` and `xoauth2_base64()`) to construct and encode the authentication strings, plus corresponding authentication handlers. The patch also updates documentation with configuration examples for both Gmail and Outlook, noting that Outlook requires XOAUTH2 while Gmail supports both methods. The changes include proper OpenSSL integration for base64 encoding and libcurl support via `CURLOPT_XOAUTH2_BEARER`.

This appears to be a well-considered addition, with thorough documentation and clear implementation. The patch fits into the series' broader goal of modernizing `imap-send` authentication while fixing long-standing issues.
