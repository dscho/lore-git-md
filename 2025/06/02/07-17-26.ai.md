This is a v3 patch series (12 patches) addressing race conditions in Git's maintenance operations, particularly around reference locking during garbage collection. The series refactors the task execution framework to properly split work between foreground (pre-detach) and background (post-detach) phases.

Key technical changes in v3:
- Renames concepts from "before/after detach" to "foreground/background" tasks for clarity
- Introduces `gc_foreground_tasks()` (formerly `gc_before_repack`) to handle pre-detach work
- Adds `--skip-foreground-tasks` flag to `git gc` to avoid duplicate work when called from maintenance
- Maintains backward compatibility while fixing the packed-refs.lock/reflog lockfile race
- Updates test cases to verify the new flag behavior

The series builds on prior work to:
- Global state reduction in maintenance tasks
- Type-safe function pointers for task execution
- Standardized error handling
- Trace2 regions reflecting the new execution model

Notable subsystems touched:
- `builtin/gc.c` (major refactoring of task execution flow)
- `t/t7900-maintenance.sh` (updated tests for new flag)
- `usage.c` (added `die(NULL)` support)

The architectural approach remains consistent with v2, but with improved terminology and some implementation refinements. The series appears well-tested and maintains backward compatibility while fixing subtle concurrency issues in maintenance operations.
