This is a platform compatibility patch for OpenBSD/NetBSD systems, following up on a bugfix for physical memory detection in `builtin/gc.c`. The original fix from Brad Smith replaces `HW_PHYSMEM` with `HW_PHYSMEM64` to correctly report system memory on these BSD variants when >=4GB RAM is present, which affects garbage collection heuristics.

Collin Funk has now verified the patch works correctly on both NetBSD 10.0 and OpenBSD 7.6, adding a Reviewed-by tag. Junio Hamano acknowledges the verification and thanks Collin for reviewing this patch along with another unrelated one (about `online_cpus()`).

The patch appears straightforward and well-vetted, with clear evidence it solves the specific platform issue without introducing new problems. It's now in good shape for inclusion, with both the original author and an independent reviewer confirming its correctness.
