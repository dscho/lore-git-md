This is a feature patch in the ongoing `imap-send` improvement series, adding a command-line option to specify the IMAP folder destination. The patch introduces a new `--folder` (or `-f`) option that overrides the `imap.folder` config setting, allowing users to specify different folders without changing their configuration. Documentation is updated to clarify that the config value serves as a fallback when the command-line option isn't used.

The implementation is straightforward - it adds an `opt_folder` variable, updates the option parsing, and applies the override before connecting to the server. This complements the series' broader goal of making `imap-send` more flexible and user-friendly. The change is well-contained and follows the pattern established by other command-line/config interactions in Git.

This patch appears ready for inclusion, having gone through multiple rounds of review in the v12 series. It addresses a clear use case where users might want to send patches to different folders without constantly editing their config, such as when working with multiple projects that use different draft locations. The documentation updates are thorough, showing both the config and command-line syntax with consistent backtick usage as standardized in earlier patches.
