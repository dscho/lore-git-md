Feature patch adding OAuth2.0 authentication support to `imap-send`, part of a larger v12 series addressing IMAP functionality. This patch implements both RFC-standard OAUTHBEARER and Google-proprietary XOAUTH2 authentication methods, with support for both OpenSSL and libcurl backends.

The implementation includes new helper functions `oauthbearer_base64()` and `xoauth2_base64()` to handle the authentication string formatting and encoding, plus corresponding authentication handlers `auth_oauthbearer()` and `auth_xoauth2()`. For libcurl, it leverages `CURLOPT_XOAUTH2_BEARER` which internally handles both protocols. The patch also updates documentation with configuration examples for Gmail and Outlook, noting that Outlook only supports XOAUTH2 while Gmail supports both methods.

Key technical details include:
- New enum values `AUTH_OAUTHBEARER` and `AUTH_XOAUTH2` in the IMAP capability list
- Proper compile-time guards with `NO_OPENSSL` checks
- Documentation updates in both `imap.adoc` and `git-imap-send.adoc` explaining OAuth2 setup
- Special handling in `setup_curl()` to use bearer tokens instead of passwords for OAuth methods
- Error handling for base64 encoding failures and socket write operations

The patch appears well-integrated with the existing authentication framework and maintains consistency with the series' focus on modernizing `imap-send`. It addresses a clear need for modern authentication methods while maintaining backward compatibility. The documentation provides practical guidance for common providers (Gmail/Outlook) and notes credential helper integration.
