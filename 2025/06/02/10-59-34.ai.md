This is a feature patch adding PLAIN authentication support for OpenSSL in `imap-send`, part of a larger series improving IMAP functionality. The patch implements RFC 4616-compliant PLAIN authentication for the OpenSSL backend, which previously only supported LOGIN commands. It introduces a new `AUTH_PLAIN` capability flag, a `plain_base64()` helper function to format credentials, and an `auth_plain()` handler that integrates with the existing IMAP authentication flow.

Key technical changes include:
- New `AUTH_PLAIN` enum value and capability string
- `plain_base64()` function that properly formats credentials per RFC 4616 (NUL-delimited user/pass)
- OpenSSL-specific implementation of `auth_plain()` that replaces the previous NULL stub
- Compile-time guards via `NO_OPENSSL` to prevent use when OpenSSL is unavailable
- Documentation updates to list PLAIN as a supported method for both backends

The implementation matches the existing libcurl behavior while adding proper OpenSSL support, addressing a gap where PLAIN authentication would fail with OpenSSL despite being a common method (particularly for app passwords). The patch follows the series' pattern of adding authentication methods with consistent error handling and memory management.

This is patch 3/10 in v12 of the series, which has already addressed extensive review feedback. The changes here are focused and well-contained, adding the missing OpenSSL implementation while maintaining compatibility with the existing libcurl support. The patch appears ready for inclusion, completing the PLAIN authentication support across both backends.
