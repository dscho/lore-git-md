This is a bugfix patch in Patrick Steinhardt's Meson test integration series (v4 7/10). It addresses a platform-specific test case that was unexpectedly passing on macOS.

The patch fixes `t7815-grep-binary.sh` where a test marked as expected-to-fail was passing on macOS due to regex behavior inherited from FreeBSD. The test checks whether `.` matches a NUL byte in regex patterns, which was thought to only happen on Cygwin. The solution is to exclude macOS from this test case, similar to how Cygwin is already excluded.

The commit message provides historical context about when this behavior appeared (related to FreeBSD-inherited regex code) and acknowledges that a proper fix would require a configure-time check for regex behavior, but that's out of scope for this series. The change is minimal - just adding the macOS exclusion to the test case and adding a corresponding prerequisite in `test-lib.sh`.

This appears to be a straightforward fix that maintains consistency with the series' goal of making tests TAP-compliant. The patch is well-explained with clear rationale and historical context, though it does leave the underlying platform-specific behavior unaddressed (as noted in the commit message).
