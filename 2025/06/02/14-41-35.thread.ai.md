Bugfix addressing `git fsck` regression with pre-2.43.0 worktrees. Patch modifies `files_fsck_refs_dir()` in refs/files-backend.c to maintain backward compatibility when verifying refs in worktrees created by Git versions before 2.43.0 (which didn't auto-create `refs` directories in worktree gitdirs). Key changes:

- Explicitly handles ENOENT errors for linked worktrees (skipping error when `!is_main_worktree(wt)`)
- Adds test case using `git worktree add` that verifies fix by manually removing worktree's refs directory
- Fixes regression introduced in commits 8f4c00de95 and 7c78d819e6 which assumed refs directory existence
- Reported by Kristoffer Haugsbakk

Technical impact:
- Changes refs/files-backend.c behavior for missing refs directories in worktrees
- Preserves compatibility with older worktree layouts
- Test covers both the regression and fix verification
