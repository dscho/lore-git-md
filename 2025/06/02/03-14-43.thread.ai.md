Thread summary:

Platform compatibility patch updating OpenBSD build configuration in config.mak.uname. The changes modernize assumptions about OpenBSD's capabilities, removing outdated workarounds for string functions (strcasestr and memmem) that have been available since OpenBSD 3.8 and 5.4 respectively. The patch adds DIR_HAS_BSD_GROUP_SEMANTICS while removing references to unsupported features like KERN_PROC_PATHNAME sysctl and /proc filesystem paths. Other OpenBSD-specific settings (USE_ST_TIMESPEC, CSPRNG_METHOD=arc4random) remain unchanged. The changes are narrowly scoped to build configuration without runtime impact, though the commit message could specify affected OpenBSD versions more precisely.
