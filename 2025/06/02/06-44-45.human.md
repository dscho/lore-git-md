This is a test infrastructure patch in Patrick Steinhardt's series to improve Meson test integration. It addresses how shell trace output is handled during test execution to maintain proper TAP (Test Anything Protocol) output format.

The patch modifies the test framework to redirect stdout to stderr when verbose mode is enabled, rather than keeping them separate. This fixes cases where shell traces (from `-x` or `--verbose` flags) were being mixed into the TAP output stream, which broke parser compatibility. The change means stdout and stderr can no longer be distinguished in verbose mode, but the commit notes this distinction wasn't practically useful in testing scenarios.

The changes affect core test infrastructure files (`t/test-lib.sh`) and update test cases in `t0000-basic.sh` to match the new behavior. This appears to be a well-justified change that completes the series' goal of proper TAP compliance in Meson builds, with the tradeoff clearly explained in the commit message. The patch follows established patterns from earlier in the series and has already received technical review sign-off.
