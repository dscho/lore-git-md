This is part 3/10 in a test modernization series converting reftable tests to use the Clar framework. The patch focuses on the block-related tests, which verify the core data structure operations in the reftable backend.

Seyi Kuforiji converts the reftable block test file from the old custom test framework to Clar, maintaining all existing test coverage while adopting Clar's conventions. The changes include:
- Renaming the test file from t-reftable-block.c to u-reftable-block.c
- Replacing custom check() assertions with cl_assert*() functions
- Converting test functions to Clar's test_* naming convention
- Updating build system files (Makefile and meson.build) to handle the new test binary

The tests verify various block operations including reading/writing different block types (ref, log, obj, index), iterator functionality, and edge cases. The conversion appears thorough, with all original test cases preserved and simply translated to Clar's syntax. This continues the series' pattern of mechanical but important test infrastructure improvements.
