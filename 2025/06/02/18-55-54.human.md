Feature enhancement for `git cat-file`'s batch mode. This is the second patch in a 3-part series that expands the object inspection capabilities of `git cat-file`.

The patch introduces a new `%(objectmode)` format specifier for `git cat-file`'s batch mode, which displays the octal file mode (permissions) for tree entries and paths. This is particularly valuable when examining tree objects or paths within trees, as it surfaces the permission bits that Git tracks but doesn't normally expose in batch output. The specifier returns an empty string for object types that don't have mode information (like commits or tags).

Implementation-wise, the change adds mode tracking to the internal `expand_data` struct and initializes it properly. The test suite is updated to verify the new functionality, including checking modes for both regular files (100644) and executable files (100755). The patch builds on the test infrastructure updates from the first patch in the series, demonstrating how the new specifier works with path-based object references.

The change is cleanly implemented with thorough test coverage, including compatibility checks across different hash algorithms. It's a natural extension of `git cat-file`'s role as a low-level object inspector, providing more complete information about tree entries without requiring separate commands or parsing.
