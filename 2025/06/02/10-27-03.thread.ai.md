This patch series (v4, 2/17) continues the `the_repository` removal effort by renaming `object_directory` to `odb_source` to better reflect its role as a pluggable object storage backend. The change affects 28 files, updating function signatures and variable names in key object database functions like `get_commit_graph_filename()` and `write_commit_graph()`. The new terminology (`odb_source`) was chosen over alternatives like `odb_backend` (too implementation-focused) or `odb_alternate` (confusing for primary object directories) to support future non-filesystem storage backends while maintaining current functionality. This mechanical rename is preparatory work for making object directories more self-contained in subsequent patches, with no behavior changes in this step. The patch appears uncontroversial as it's part of a well-explained series with clear technical motivation.
