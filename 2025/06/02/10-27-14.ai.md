This is part 13/17 of Patrick Steinhardt's ongoing series to refactor Git's object database (ODB) subsystem, continuing the removal of `the_repository` global state. The patch renames `oid_object_info()` to `odb_read_object_info()` and its `_extended()` variant to match the established `odb_` prefix convention for ODB-related functions.

The change is mechanical, updating 48 files to use the new function names while maintaining identical behavior. Compatibility wrappers are introduced to avoid breaking in-flight topics. The patch follows the same pattern as previous conversions in the series, systematically replacing direct ODB function calls with their repository-aware counterparts.

Key technical details:
- The core change moves from `oid_object_info[_extended]()` to `odb_read_object_info[_extended]()`
- Functions now operate on `struct object_database*` rather than implicitly using `the_repository`
- All call sites are updated to pass the repository's ODB via `repo->objects`
- The patch includes extensive cross-file updates showing the mechanical nature of the conversion

This continues the series' pattern of methodically converting ODB subsystem functions while maintaining backward compatibility. The changes are straightforward and unlikely to be controversial, building on established naming conventions from earlier patches in the series.
