This is a feature patch series adding GPG signing support to `git subtree`. The command currently doesn't honor commit signing configurations, which causes problems for repositories that require signed commits. The two-patch series first refactors the option parsing to use `--stuck-long` for consistency, then adds `-S/--gpg-sign` support that behaves like other Git commands.

The change appears well-motivated for users who need signed commits in their subtree workflows. The implementation touches documentation, the shell script implementation, and adds substantial test coverage (113 new test lines). The author notes this iteration incorporates feedback from Junio Hamano on a previous attempt, suggesting the patch has already gone through some review.

For repositories using signed commits, this will be a welcome addition that brings `git subtree` in line with other Git commands' signing behavior. The thorough test additions give confidence in the implementation.
