This is patch 8/10 in a series converting reftable tests to use the Clar framework, specifically focusing on the record test file. The patch follows the established pattern from earlier conversions in the series, replacing custom test assertions with Clar's cl_assert*() functions and renaming the test file from t-reftable-record.c to u-reftable-record.c.

The test verifies various reftable record operations including varint encoding/decoding, ref/log/obj/index record comparisons, round-trip encoding/decoding, and key handling. Key test cases include:
- Varint handling (roundtrip and overflow detection)
- Ref record comparison by name and value
- Log record comparison by key and update index
- Object record comparison by hash and offset
- Index record comparison by last_key and offset
- Round-trip validation for all record types through encode/decode cycles

The conversion maintains all existing test coverage while standardizing on Clar's assertion macros (cl_assert, cl_assert_equal_i, etc.) and test function naming convention (test_reftable_record__*). Build system files (Makefile, meson.build) are updated to reflect the renamed test.

This is a straightforward mechanical conversion following the pattern established in prior patches of the series, with no behavioral changes to the actual tests. The patch appears well-formed and properly rebased on the ongoing conversion work.
