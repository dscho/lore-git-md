This is a test infrastructure patch in Patrick Steinhardt's series to improve Meson test integration. It refactors Python version detection for git-p4 tests to use proper prerequisite handling.

The patch updates two test scripts (t9835 and t9836) that verify git-p4 works with Python 2 and 3 respectively. Previously, these tests directly checked for Python versions by executing git-p4 and grepping output, which broke the TAP test format. The new version uses `test_lazy_prereq()` to properly encapsulate the version checks as test prerequisites.

The changes are straightforward mechanical conversions that:
1. Move the Python version detection into prerequisite blocks
2. Maintain the same functionality while producing TAP-compliant output
3. Keep the same test behavior (skipping if Python version unavailable)

This is part of the v4 series that has already received technical sign-off, with this patch addressing one of the final TAP compliance issues. The changes are clean and focused, matching the series' goal of modernizing test infrastructure while maintaining strict TAP output requirements.
