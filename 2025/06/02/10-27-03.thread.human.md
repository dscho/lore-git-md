This thread continues the multi-patch effort to eliminate Git's `the_repository` global variable by making object storage handling more modular. The current patch (v4 2/17) renames the `object_directory` struct to `odb_source` to better reflect its role as a pluggable backend interface rather than just a filesystem directory. The change affects 28 files but is purely mechanical - updating function signatures and variable names without altering behavior.

The rename prepares for future work supporting non-filesystem object storage while avoiding confusion with Git's existing "alternate" terminology. Key functions like `get_commit_graph_filename()` and `write_commit_graph()` are updated to use the new naming. The patch appears uncontroversial as it maintains existing functionality while making the codebase more amenable to the larger architectural changes coming later in the series.
