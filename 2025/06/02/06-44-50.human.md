This is the final patch in Patrick Steinhardt's series to integrate Git's test suite with Meson builds, focusing on TAP output parsing. The patch enables Meson to properly interpret the TAP-formatted output from Git's test suite when using Meson 1.8 or newer, which includes an upstream fix Patrick contributed to handle interactive test runs correctly.

With this change, `meson test` now shows detailed subtest counts and properly marks skipped tests in its output. The implementation is straightforward - it adds the 'tap' protocol to test parameters when Meson 1.8+ is detected. Interactive test runs are specially handled (marked as "ignored") since TAP parsing isn't reliable when tests might pause for debugging.

This completes the technical work for the series, which has already received thorough review and approval from multiple contributors. The patch builds on previous infrastructure improvements to make Git's test suite work seamlessly with Meson builds while maintaining compatibility with existing behavior.
