This is a small but useful user experience improvement in the ongoing `imap-send` series. The patch prompts for IMAP credentials with both host and port information, matching the behavior of `git send-email`. Previously, credential helpers would only show the hostname (e.g., "outlook.office365.com"), but with this change they'll include the port (e.g., "outlook.office365.com:993").

The change is straightforward - it modifies the credential helper setup to format the host string with the port number. The port is always available since the code falls back to default ports (993 for IMAPS, 143 for IMAP) when none is specified. This brings consistency with other Git commands and makes it clearer which exact server endpoint is being authenticated against.

As part of the larger v12 series that's nearing completion, this represents one of the final polish items to standardize the user experience. The change is minimal (just one line modified) but meaningful for users who work with multiple IMAP servers or non-standard ports.
