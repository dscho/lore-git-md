This is a refactoring patch in Patrick Steinhardt's series to improve Meson test integration. The patch introduces a `test_kwargs` dictionary to centralize common test parameters that are currently duplicated across multiple Meson build files. 

The main change is adding a `test_kwargs` variable in the common `meson.build` file that contains the shared `timeout: 0` parameter, then updating all test declarations to use this dictionary via the `kwargs:` argument rather than specifying the timeout directly. This affects test configurations in the credential/netrc helper, subtree, and main test suite.

The change is straightforward and mechanical - it doesn't modify any test behavior, just reorganizes how the common timeout parameter is specified. This prepares for adding more shared test parameters in future commits. The patch is part of a well-reviewed series that has already addressed technical feedback and appears ready for integration.
