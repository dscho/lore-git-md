This is a portability fix addressing build failures on OpenBSD. The patch updates `generate-configlist.sh` to work around OpenBSD's `sed` implementation which doesn't support `\n` escape sequences, causing malformed output in `config-list.h` that breaks compilation.

The issue manifests when generating completion options documentation, where newlines in the sed command were previously represented with `\n`. The fix replaces this with a literal backslash-newline sequence, which works across different sed implementations. The regression was introduced in commit e1b81f54da ("completion: take into account the formatting backticks for options") from March 2025.

This is version 2 of the patch, following feedback about additional shell compatibility concerns (particularly with variable expansion in dash). The change is minimal and focused - just a one-line modification to the sed script while maintaining the same output format. The patch appears well-targeted to solve the immediate OpenBSD build issue while being careful not to introduce new portability problems.
