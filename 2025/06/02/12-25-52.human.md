This is part 4/10 of a test conversion series moving reftable tests to the Clar framework. The patch converts the merged table test file (t-reftable-merged.c -> u-reftable-merged.c) to use Clar assertions and test organization.

The changes follow the established pattern from earlier patches in the series:
- Renames test functions to Clar-style `test_reftable_merged__*` naming
- Replaces custom `check()` assertions with Clar's `cl_assert*()` variants
- Updates build system files (Makefile, meson.build) to reference the new test name
- Removes the old test harness main() function since Clar handles test execution

The tests verify merged table functionality for both ref and log records, including:
- Basic record merging from multiple sources
- Iterator behavior and seek operations
- Update index tracking
- Hash ID validation
- Edge cases around repeated seeks without draining

The conversion appears mechanical and consistent with prior patches in the series. The test coverage remains unchanged - it's now just expressed using Clar conventions rather than the custom test framework. This continues the broader effort to standardize Git's test infrastructure.
