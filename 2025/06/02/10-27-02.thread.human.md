The initial patch renames the core `raw_object_store` structure to `object_database` (ODB), a change that better reflects its purpose and paves the way for making the object subsystem more self-contained. The rename addresses long-standing naming issues while maintaining existing functionality.

The change is foundational work in a 17-part series, suggesting more substantial modifications to the object storage layer will follow. The patch mechanically updates function signatures and type declarations across multiple core files, introducing new terminology like `odb_new()` and `odb_clear()` that will likely be referenced throughout the series. The author has thoroughly updated all affected files and provided clear motivation in the commit message, explaining how this change eliminates the misleading "raw_" prefix and enables more concise function naming.
