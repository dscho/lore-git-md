This is part 1 of a 2-patch documentation series updating the MyFirstObjectWalk tutorial to modern Git practices, specifically focusing on removing `the_repository` global usage. - Replacing `git_config()` calls with `repo_config()`
- Fixing `repo_init_revisions()` to use the passed `repo` parameter
- Updating all related tutorial text to match these code changes
