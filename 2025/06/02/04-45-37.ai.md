This is a follow-up clarification in the OpenBSD platform compatibility thread. Carlo Arenas Belón provides a specific version reference (OpenBSD 5.7) to Brad Smith's statement about the lack of KERN_PROC_PATHNAME sysctl and /proc filesystem support in OpenBSD. The citation points to OpenBSD 5.6 manpages as documentation for when these features were last present before being removed.

The exchange serves to precisely document the historical context of these removed features, though it doesn't change the technical substance of the original patch (which already correctly removed these unsupported features). This kind of version-specific detail is useful for future reference when assessing compatibility requirements, but doesn't affect the current build system changes.
