This is a test modernization patch converting reftable basics tests to use the Clar framework, part of a larger series (v3 02/10). Seyi Kuforiji adapts the reftable basics test file to use Clar assertions and reorganizes some test cases for better modularity. The changes follow the pattern established in the series: replacing custom test infrastructure with Clar's standardized functions and renaming files from `t-reftable-*.c` to `u-reftable-*.c`.

The patch maintains all the existing test coverage for reftable basics functionality - binary search, string array handling, buffer operations, and endian-aware I/O - while converting the implementation to use Clar's `cl_assert*` macros. The test cases are now split into individual Clar test functions rather than grouped under `if_test` blocks. Build system files (Makefile and meson.build) are updated to reflect the file rename and new test suite addition.

This appears to be a straightforward mechanical conversion that preserves the test semantics while aligning with the project's test modernization goals. The patch follows the pattern established in the series' foundation (patch 01/10) and should integrate cleanly with the ongoing effort.
