Test modernization converting reftable readwrite tests to Clar framework.

This is patch 7/10 in Justin Tobler's series standardizing reftable tests on the Clar framework. The patch converts the readwrite test file (now renamed from t-reftable-readwrite.c to u-reftable-readwrite.c) to use Clar assertions and helpers. Key changes:

- Replaces custom test assertions with cl_assert*() functions
- Uses cl_reftable_set_hash() and cl_reftable_write_to_buf() helpers from lib-reftable-clar
- Maintains all existing test coverage for reftable read/write operations:
  * Buffer handling and block source operations
  * Log record writing with compression and size limits
  * Table seek/read operations with and without indexes
  * Error cases like corrupted tables and empty keys
  * Object ID length handling

The conversion follows the same pattern as earlier patches in the series, with test functions renamed to Clar's test_*__* naming convention. Build system updates remove the old test file and add the new Clar version. The patch appears mechanically sound, continuing the series' consistent approach to test modernization.
