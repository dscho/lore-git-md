This is part 8/10 of a test modernization series converting reftable tests to use the Clar framework. The patch converts the reftable record test file, which verifies core record operations for refs, logs, objects and indexes in the reftable backend.

The changes follow the established pattern from earlier patches in the series: replacing custom test assertions with Clar's cl_assert*() functions, renaming the test from t-reftable-record.c to u-reftable-record.c, and updating build system files. The test cases themselves remain largely unchanged in functionality, continuing to verify:
- Record comparison operations for all record types
- Round-trip encoding/decoding of records
- Varint handling
- Key encoding/decoding
- Record equality checks

The patch appears mechanically sound, with all test cases properly converted to Clar syntax and the build system updates correctly removing the old test file. This continues the series' steady progress toward standardizing the test infrastructure.
