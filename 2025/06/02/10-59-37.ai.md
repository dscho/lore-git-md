This is a feature patch in the `imap-send` series, introducing a command-line option to specify the IMAP folder. The patch adds a new `--folder`/`-f` option that allows users to override the `imap.folder` configuration setting at runtime, providing flexibility for cases where users frequently need to send to different folders.

The implementation adds the option to both the command-line parser and usage documentation, updates the configuration documentation to clarify precedence (command-line overrides config), and modifies `imap-send.c` to handle the new option by duplicating the provided folder string into the server configuration. The documentation changes standardize the formatting of IMAP folder examples using backticks and add a clear example of the new option's usage.

This is part of the broader `imap-send` improvements in v12, which has already addressed critical configuration parsing bugs and added OAuth2.0 support. The folder override feature is a straightforward user-facing addition that complements the series' goal of making `imap-send` more flexible and usable. The patch follows the established pattern of the series' other command-line options and maintains consistency with the documentation style updates made in earlier patches.
