This is a test infrastructure patch that's part of Patrick Steinhardt's series to improve Meson test integration. The patch focuses on cleaning up test prerequisite announcements to maintain TAP format compliance.

The change removes various test messages that announce whether prerequisites are met (like "will test on a case insensitive filesystem") because these messages break the TAP output format. Instead, it modifies the tests to use the prerequisite system's built-in skipping mechanism where possible. The patch touches several test scripts including filesystem tests, gitweb tests, and bash prompt tests.

This appears to be a straightforward cleanup that doesn't change test behavior, just the output format. The changes are consistent with the series' goal of making test output properly parseable by TAP consumers. Since this is the first patch in a v4 series that's already received technical sign-off, it's likely well-vetted at this point.
