Final cleanup patch in the reftable test migration series. This is the 10th patch in v3 of the series converting reftable tests to use the Clar framework, completing the conversion that was started in earlier patches.

The patch removes the transitional `lib-reftable-clar.{c,h}` files that were introduced during the migration and renames their contents back to the original `lib-reftable.{c,h}` names now that all tests have been converted. It updates all test files to include the renamed header and makes corresponding build system changes across Makefile, meson.build, and t/Makefile to remove references to the old test framework.

Key technical changes:
- Deletes `lib-reftable-clar.c` and `lib-reftable-clar.h`
- Renames helper functions from `cl_reftable_*` back to `t_reftable_*` naming
- Updates all u-reftable-*.c test files to include the renamed header
- Removes old test framework references from build systems
- Cleans up unit test program definitions that are no longer needed

This completes the mechanical conversion work, leaving the test infrastructure in its final Clar-based state with consistent naming. The patch follows the established pattern seen in other subsystem test migrations to Clar.
