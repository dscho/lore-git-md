Test infrastructure patch converting reftable test helpers to Clar framework. This is the first patch in a 10-part series migrating reftable tests to use the Clar unit testing framework.

The patch introduces new helper functions in `lib-reftable-clar.{c,h}` that provide Clar-compatible versions of existing reftable test utilities. Key additions include hash initialization (`cl_reftable_set_hash`), string buffer writer utilities (`cl_reftable_strbuf_writer`), and a comprehensive buffer writing function (`cl_reftable_write_to_buf`) that handles both ref and log records with proper error checking.

The implementation appears thorough, with clear assertions and proper integration into both Makefile and meson build systems. As the foundational patch in the series, it sets up the infrastructure needed for subsequent test conversions. The commit message could better explain why these particular helpers were chosen for conversion first, but the technical implementation looks solid.
