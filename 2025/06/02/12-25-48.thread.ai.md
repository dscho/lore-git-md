[PATCH v3 0/10] reftable: convert tests to use Clar framework

Thread identity: Patch series converting reftable unit tests from custom test framework to Clar (libgit2-originated unit test framework). Originating author: Justin Tobler. Part of ongoing test infrastructure standardization effort.

Core problem/goal: Replace custom test assertions and organization in reftable tests with Clar framework conventions to improve maintainability and consistency with other modern Git test suites. Series completes reftable test migration after prior work on other subsystems.

Current status: Third iteration incorporating review feedback. Changes from v2 include improved helper function organization in new lib-reftable-clar.{c,h} files and build system adjustments. Patch 3/10 now converts block tests (t-reftable-block.c -> u-reftable-block.c) following the established pattern. All 8 major reftable test components being converted (basics, block, merged, pq, readwrite, record, stack, table). Patch 1/10 introduces core helper functions in lib-reftable-clar.{c,h} for hash handling, strbuf-based writing, and buffer validation. Patch 2/10 converted basics tests, patch 3/10 handles block operations.

Key technical details:
- Test files renamed from t-reftable-*.c to u-reftable-*.c (Clar convention)
- Custom check() macros replaced with cl_assert*() functions
- New helper functions in lib-reftable-clar.{c,h} centralize test utilities:
  * cl_reftable_set_hash() for test hash initialization
  * cl_reftable_strbuf_writer() for in-memory test writing
  * cl_reftable_write_to_buf() for validated test data generation
- Build system (Makefile, CMake.build, meson.build) updated to compile/link new test binaries
- Block test (now u-reftable-block.c) verifies:
  * Read/write operations for all block types (ref, log, obj, index)
  * Iterator functionality and seek behavior
  * Record round-trip validation
  * Edge case handling
- Basics test (u-reftable-basics.c) covers:
  * Binary search edge cases
  * String array utilities
  * Buffer prefix comparison
  * Big-endian number encoding
  * Memory allocation patterns
- Handles both ref and log record types in test helpers
