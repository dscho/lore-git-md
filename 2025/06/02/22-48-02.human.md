Platform compatibility fix for Cygwin test failures in pathspec wildcard handling.

Ramsay Jones reports that 11 tests in t6137-pathspec-wildcards-literal.sh fail on Cygwin because the platform treats backslashes in quoted glob patterns (like `\*`) as path separators rather than literal escapes. The tests expect backslashes to escape glob characters literally, but Cygwin's path normalization interprets them differently.

The patch demonstrates the root cause with a temporary hack that disables backslash path separator handling in `is_absolute_path()` and `normalize_path_copy_len()`, but the actual solution is more conservative: it marks all affected tests with a `!CYGWIN` prerequisite to skip them on that platform. The author notes this may have been failing Windows CI silently for some time, though the exact reason this wasn't caught earlier remains unclear.

This follows Git's typical approach for platform-specific test accommodations, where behavior differences lead to test prerequisites rather than core code changes. The patch also includes some minor test title fixes while making these adjustments. The changes are straightforward and focused on the immediate test failures without attempting to resolve the underlying platform behavior difference.
