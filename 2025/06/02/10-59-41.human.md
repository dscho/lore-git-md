Feature patch adding folder listing capability to `imap-send`. This is the final patch in a 12-part series that has significantly enhanced IMAP functionality in Git.

The patch introduces a new `--list` option to `git imap-send` that displays all available folders on an IMAP server, which is particularly useful since different providers (Gmail, Outlook, etc.) use different naming conventions for standard folders like Drafts and Trash. The implementation works with both OpenSSL and libcurl backends, following RFC 6154 for the protocol handling.

The output shows folder hierarchies and attributes (like `\HasNoChildren` or `\Drafts`), helping users identify the correct folder names to use in configuration. The documentation is updated to suggest using this feature when troubleshooting folder naming issues.

This appears to be a well-considered addition that completes the series' goal of making `imap-send` more robust and user-friendly. The implementation is thorough, handling both backends consistently and including proper error checking. The patch fits naturally with the other improvements in the series (OAuth2 support, configuration fixes) and seems ready for inclusion.
