This is the final patch in Patrick Steinhardt's v4 series enabling TAP output parsing for Meson builds, completing the test infrastructure improvements. The patch activates TAP protocol support in Meson (version 1.8+ required) to properly report test results including subtest counts and skipped tests, while handling the interactive mode case by marking those tests as "ignored" since TAP parsing isn't reliable with terminal-connected file descriptors.

Key technical details:
- Requires Meson 1.8+ (fixes interactive mode TAP parsing via upstream PR #13980)
- Adds 'protocol': 'tap' to test_kwargs when version requirement met
- Preserves existing test behavior while adding richer output reporting
- Documents interactive mode limitation (tests marked "ignored" when --interactive used)
- Maintains compatibility with all prior test infrastructure changes in the series

The change builds on the series' comprehensive test modernization including TAP compliance fixes, prerequisite handling, platform-specific test corrections, and the newly introduced test_kwargs parameter consolidation. With all technical review addressed and approvals from Karthik Nayak and others, this final piece completes the Meson test integration work.
