Test modernization patch converting reftable priority queue tests to Clar framework.

This is patch 5/10 in a series converting reftable unit tests from a custom test framework to the Clar framework. The patch focuses on the priority queue (pq) test component, following the pattern established in earlier patches of the series. Key changes include:

- Renames test file from t-reftable-pq.c to u-reftable-pq.c (Clar naming convention)
- Replaces custom check() assertions with cl_assert*() variants from Clar
- Converts test functions to Clar test case format (test_reftable_pq__* naming)
- Updates build system files (Makefile, meson.build) to reference new test name
- Removes old test harness (cmd_main) since Clar handles test execution

The tests verify priority queue behavior for reftable operations, including:
- Record-based comparison (test_reftable_pq__record)
- Index-based comparison (test_reftable_pq__index)
- Merged iterator queue top operation (test_reftable_pq__merged_iter_pqueue_top)

The conversion appears straightforward, mechanically replacing assertion macros while preserving the test logic. The patch follows the same pattern as previous conversions in the series, suggesting it should integrate cleanly with the ongoing test modernization effort. No new test cases are added - this is purely a framework migration.
