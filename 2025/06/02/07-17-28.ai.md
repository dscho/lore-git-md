- Repository repacking
- Auto-packing notifications
- Prune operations
- Commit graph writing

This is a straightforward cleanup that improves code clarity without changing behavior. The patch fits into the series' broader goal of reducing global state and improving maintainability, though it's a minor change compared to the core race condition fixes in later patches. The modification is well-contained to `builtin/gc.c` with no test updates needed since it's purely an internal refactoring.
