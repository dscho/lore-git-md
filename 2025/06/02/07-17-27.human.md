Refactoring patch in Patrick Steinhardt's maintenance task race condition series (1/12). This initial patch modernizes the maintenance task array initialization in `builtin/gc.c` to use designated field initializers rather than positional ones. The change makes the code more maintainable by explicitly naming each struct field (`.name`, `.fn`, `.auto_condition`, etc.) when initializing the array of maintenance tasks.

This is a straightforward code quality improvement that doesn't change behavior but makes future modifications easier by removing the need to count positions when adding new task properties. The patch touches all standard maintenance tasks (prefetch, loose-objects, gc, commit-graph, etc.), converting their initialization to the named style consistently. As the first in a series addressing race conditions in maintenance operations, this sets up cleaner infrastructure for the more substantive changes that follow.
