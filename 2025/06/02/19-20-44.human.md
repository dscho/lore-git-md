This is a follow-up in a thread about a portability fix for generating config-list.h, addressing issues with both OpenBSD's sed and dash shell compatibility.

Collin Funk responds to Jean-Noël Avila's report that the initial fix works on OpenBSD but fails on Debian systems using dash as /bin/sh. The failure manifests by inserting literal "$nl" strings between config options rather than proper newlines. Collin acknowledges the oversight (having only tested with bash) and commits to sending a v2 patch that will work with dash on Fedora 42 while maintaining the OpenBSD compatibility.

The exchange highlights the challenge of writing portable shell scripts that must work across different sed implementations and shell environments. While the technical scope remains focused on the config generation script, the discussion has expanded to consider validation methodology, with Jean-Noël suggesting GitGitGadget's multi-platform CI as a testing resource. Collin's response indicates the fix will likely involve adjusting the shell variable quoting approach rather than a more fundamental redesign.
