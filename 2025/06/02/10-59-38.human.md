This is a documentation and style patch in the ongoing `imap-send` improvement series (v12, patch 7/10). It standardizes log and error message formatting throughout `imap-send.c` to follow Git conventions more closely.

The changes are purely stylistic, fixing several minor inconsistencies:
- Error messages now start with lowercase (e.g., "error: unable to connect" instead of "Error: unable to connect")
- Removes periods from error messages to match Git style
- Ensures protocol terms like "IMAP" and status indicators like "OK" are consistently uppercase
- Makes progress messages more consistent (e.g., "Sending N messages" capitalization)

This patch doesn't introduce new functionality but cleans up the output formatting as part of the larger series' polish phase. The changes are straightforward and align with established Git conventions, though some might consider them nitpicky outside a formal style cleanup effort. Since this is part of a well-reviewed series that's already in its 12th iteration, these final tweaks seem appropriate.
