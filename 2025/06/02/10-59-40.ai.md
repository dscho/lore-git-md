This is a user experience improvement patch in the ongoing `imap-send` feature/bugfix series (v12 09/10). It enhances the progress output during message sending to include the destination folder name, making the operation more transparent to users.

The patch modifies both the OpenSSL (`append_msgs_to_imap`) and libcurl (`curl_append_msgs_to_imap`) backend implementations to display messages like "Sending 1 message to Drafts folder..." instead of the previous generic "Sending 1 message". The change is straightforward - it simply adds the `server->folder` value to the progress message format string in both functions.

This builds on the series' broader effort to improve `imap-send` usability, particularly around folder handling where earlier patches added the `--folder` command-line option and fixed configuration parsing. The implementation is clean and consistent with the series' focus on polishing user-facing messages, though it doesn't address any technical debt or introduce new functionality beyond the improved output.

The change affects two locations in `imap-send.c` with identical formatting, showing the same careful attention to detail seen throughout this well-reviewed series. Since this is part of a mature patch set that has undergone 12 iterations with thorough review, the change can be considered low-risk and ready for inclusion.
