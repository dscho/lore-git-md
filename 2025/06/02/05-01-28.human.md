This is a platform compatibility patch for OpenBSD that has been reviewed and accepted by Junio C Hamano. The patch updates build configuration settings in `config.mak.uname` to reflect modern OpenBSD capabilities, removing outdated workarounds for string functions (strcasestr and memmem) that have been available since OpenBSD 3.8 and 2003) and 5.4 (2013) respectively. It also adds DIR_HAS_BSD_GROUP_SEMANTICS while removing references to unsupported features like KERN_PROC_PATHNAME sysctl and /proc filesystem paths.

The changes are straightforward and well-justified, with Brad Smith providing clear historical context about when various features became available in OpenBSD. Junio notes these adjustments are long past due, given the features have been available for over a decade. The patch maintains other OpenBSD-specific settings like USE_ST_TIMESPEC and arc4random CSPRNG while cleaning up obsolete configurations. This is a clean, focused update that modernizes Git's build configuration for OpenBSD without any runtime impact.
