Reftable test conversion to Clar framework (part 9/10). This patch converts the reftable stack test to use the Clar test framework, completing the migration of all reftable tests from the custom test framework. The changes follow the same pattern as previous conversions in the series:

- Renames test file from t-reftable-stack.c to u-reftable-stack.c
- Replaces custom check() assertions with cl_assert*() functions
- Updates Makefile and meson.build to handle the new test binary
- Removes now-unused t-*.c pattern from meson.build since this is the last conversion

The test verifies stack operations including:
- Basic ref addition and reading
- Multi-process access coordination via reloads
- Transaction API behavior
- Auto-compaction logic and failure cases
- Iterator functionality across stack reloads
- Tombstone record handling
- Hash ID validation
- Log message normalization
- Various edge cases around locked tables and concurrent access

This conversion follows the same approach as the prior 8 patches in the series, using the lib-reftable-clar helper functions introduced in patch 1. With this change, all reftable tests now use the Clar framework, marking completion of this test modernization effort. The patch is cleanly rebased on the series and appears to maintain all existing test coverage while adopting the new framework conventions.
