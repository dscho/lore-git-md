This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database (ODB) subsystem, enabling future pluggable backends. Patch 10/17 continues the mechanical conversion work by refactoring two functions that manage temporary primary object stores.

The patch converts `set_temporary_primary_odb()` and `restore_primary_odb()` to take explicit `object_database` parameters, renaming them to `odb_set_temporary_primary_source()` and `odb_restore_primary_source()` respectively. These functions are used when temporarily redirecting object storage, such as during operations that need to isolate their object writes. The changes follow the established pattern of the series: adding ODB parameters, renaming with `odb_` prefix, and updating callers.

The implementation updates three files (`odb.c`, `odb.h`, and `tmp-objdir.c`) with straightforward mechanical conversions. The changes maintain all existing functionality while removing the last `the_repository` dependencies from these temporary ODB management functions. This continues the series' progress toward completely removing global state from the ODB subsystem.

As with previous patches in the series, this is a well-executed mechanical change that builds on established patterns and has received positive review feedback. It moves the codebase closer to supporting pluggable ODB backends while maintaining strict backward compatibility.
