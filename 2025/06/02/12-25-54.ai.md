This is patch 6/10 in a series converting reftable tests to use the Clar framework, focusing on the table test component. The patch converts t-reftable-table.c to u-reftable-table.c, following the established pattern from earlier patches in the series.

The conversion replaces custom test assertions with Clar's cl_assert*() functions and reorganizes the test cases into Clar-style test functions (prefixed with test_reftable_table__). The test verifies core table operations including:
- Single and repeated seek operations on ref records
- Block iterator functionality checking block types, header offsets, and record counts
- Record equality validation using REFTABLE_HASH_SIZE_SHA1

Build system changes remove the old test from UNIT_TEST_PROGRAMS and add the new u-reftable-table.c to CLAR_TEST_SUITES in both Makefile and meson.build. The test continues to use the shared lib-reftable-clar.h helpers introduced earlier in the series for buffer writing and hash initialization.

This follows the same mechanical conversion approach seen in prior patches, maintaining all existing test coverage while adopting the Clar framework's conventions. The changes are straightforward with no apparent functional modifications to the test logic itself.
