This is a test infrastructure patch in Patrick Steinhardt's series to improve Meson test integration (part 3/10). It fixes TAP output compliance in t9822 by properly handling filesystem encoding prerequisites.

The test t9822 checks Git-p4's handling of non-ASCII paths and needs ISO-8859-1 filesystem support. Previously, when the prerequisite check failed, it would print directly to stderr, breaking the TAP format. The patch converts this to use `test_lazy_prereq` which properly handles output redirection.

This is a straightforward technical improvement that aligns with the series' goal of strict TAP compliance. The change is small (9 lines added, 4 removed) and focused, converting an ad-hoc check into proper test infrastructure. Since this is part of a reviewed series that has already addressed technical feedback, it appears ready for inclusion.
