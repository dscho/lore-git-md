This is a bugfix addressing compatibility issues in `git refs verify` with older-format worktrees. The patch is part of an ongoing discussion about how to handle worktree ref directories, with the maintainer having approved the technical approach but implementation details still being refined.

The patch modifies `files_fsck_refs_dir()` to ignore ENOENT errors specifically for linked worktrees while maintaining error reporting for other cases. A test case verifies the fix by simulating the old directory layout.
