Test modernization patch in the reftable Clar conversion series. This is patch 4/10 in the third iteration of the series converting reftable tests to use the Clar framework. The patch focuses on the merged table tests, which verify behavior when combining multiple reftable sources.

The conversion follows the established pattern seen in earlier patches: test file renamed from t-reftable-merged.c to u-reftable-merged.c, custom test assertions replaced with cl_assert*() functions, and use of the new lib-reftable-clar.h helpers. The tests verify merged table functionality including:
- Single record retrieval (test_reftable_merged__single_record)
- Multiple ref updates (test_reftable_merged__refs)
- Log record merging (test_reftable_merged__logs) 
- Repeated seeks (test_reftable_merged__seek_multiple_times)
- Seek behavior without draining iterator (test_reftable_merged__seek_multiple_times_no_drain)
- Default write options handling (test_reftable_merged__default_write_opts)

Key technical changes include replacing custom check() macros with cl_assert() variants, using cl_reftable_write_to_buf() for test data generation, and restructuring test cases as Clar-style test_* functions. The patch maintains all existing test coverage while conforming to Clar conventions. Build system updates remove the old test file and add the new Clar version to the Makefile and meson.build configurations.

This continues the systematic conversion pattern established in prior patches, with no apparent deviations from the series' overall approach. The changes appear mechanical and focused on test infrastructure rather than altering test semantics.
