This is the fourth version of Patrick Steinhardt's series to enable TAP output parsing in Meson, representing a significant test infrastructure improvement. The series has already received technical approval and only needed minor documentation tweaks in this iteration.

The core change enables Meson (v1.8+) to properly parse TAP output from Git's test suite, providing better reporting of skipped tests and subtest counts. The series includes several preparatory fixes to ensure clean TAP output, such as silencing test setup output, fixing shell trace handling, and addressing platform-specific test behavior (notably a macOS/Cygwin edge case where a test was unexpectedly passing due to shared regex implementation heritage from FreeBSD).

Version 4 contains only small refinements: corrected references to git-p4 (previously mistyped as git-b4), commit message improvements, and avoiding duplicate names in t4041 tests. The technical approach remains unchanged from v3, maintaining strict TAP compliance through output stream routing and treating unexpected passes as failures consistently.

With all major technical concerns addressed and only minor documentation polish remaining, this series appears ready for integration. The changes are well-motivated, thoroughly tested, and have undergone multiple rounds of review with substantive feedback incorporated.
