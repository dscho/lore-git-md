This thread concerns a straightforward update to Git's OpenBSD build configuration, removing outdated workarounds and adding one new define. Brad Smith, the OpenBSD maintainer, submitted the patch to modernize assumptions about OpenBSD's capabilities, with Junio C Hamano confirming the changes are appropriate and planning to apply them.

The changes remove several obsolete defines: NO_STRCASESTR and NO_MEMMEM (both functions have been available in OpenBSD for over a decade), along with references to unsupported features like the KERN_PROC_PATHNAME sysctl and /proc filesystem paths that were removed in OpenBSD 5.7. The patch adds DIR_HAS_BSD_GROUP_SEMANTICS which is required for correct behavior, while preserving other OpenBSD-specific settings like USE_ST_TIMESPEC and arc4random CSPRNG method.

The updates are narrowly scoped to config.mak.uname and have no runtime impact - they simply align Git's build configuration with modern OpenBSD capabilities. The thread shows clear consensus between the OpenBSD maintainer and Git's maintainer that these changes are well-justified and long overdue. Junio plans to apply the patch as-is.
