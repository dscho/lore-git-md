This is part 15/17 of Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem, continuing the effort to remove `the_repository` global state. The patch renames `has_object()` to `odb_has_object()` to match the established `odb_` prefix convention for ODB-related functions.

The change is mechanical, following the same approach as previous patches in the series: updating all callers across 30 files while maintaining behavior through a compatibility wrapper. The wrapper ensures in-flight topics continue to compile during the transition. The patch touches core functionality used throughout Git - checking object existence - but makes no functional changes.

This continues the systematic conversion pattern seen in earlier patches, with positive reviews already on the foundational changes. The series as a whole exemplifies Git's careful API design process and prepares for future pluggable ODB backend work.
