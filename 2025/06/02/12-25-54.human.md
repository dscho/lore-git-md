This is part 6/10 of a test modernization series converting reftable tests to use the Clar framework. The patch focuses on the reftable table tests, continuing the pattern established in earlier patches of the series.

The changes follow the established conversion approach: renaming the test file from `t-reftable-table.c` to `u-reftable-table.c`, replacing custom test assertions with Clar's `cl_assert*()` functions, and using the shared helper functions from `lib-reftable-clar.h`. The test cases themselves (table seeking, reseeking, and block iteration) remain substantively the same, just expressed in Clar's style.

The patch updates both the Makefile and meson.build files to compile the new test binary while removing the old one. Like the rest of the series, this appears to be a straightforward mechanical conversion that maintains all the original test coverage while bringing the code in line with Git's modern test infrastructure standards. The changes are consistent with the series' goal of improving test maintainability through framework standardization.
