Feature patch adding command-line folder specification to `imap-send`, part of the larger IMAP improvements series.

This patch introduces a new `-f`/`--folder` option to `git imap-send`, allowing users to override the default folder specified in the `imap.folder` config. The implementation follows the series' established patterns for command-line handling and includes documentation updates explaining the precedence rules (command line overrides config).

Junio Hamano provides detailed feedback on the documentation wording, suggesting more precise language about the option's behavior and questioning whether the patch should first standardize the documentation style of existing options. He notes the current implementation is locally consistent with the existing style, so this could be deferred to a follow-up cleanup.

The change is straightforward and aligns with the series' goal of improving IMAP functionality. While the documentation style could be polished further, the core functionality appears solid and well-integrated with the rest of the IMAP improvements. This is one of the final patches in the v11 series, which has already addressed numerous technical and usability issues with `imap-send`.
