This is a platform compatibility patch for OpenBSD build configuration, following up on Brad Smith's earlier submission. Junio C Hamano confirms the changes and plans to apply them, noting that OpenBSD's string functions (strcasestr and memmem) have been available since 2013 and it's time to update Git's assumptions.

The patch removes outdated workarounds (NO_STRCASESTR, NO_MEMMEM) and unsupported features (KERN_PROC_PATHNAME sysctl, /proc filesystem paths) while adding DIR_HAS_BSD_GROUP_SEMANTICS. Other OpenBSD-specific settings like USE_ST_TIMESPEC and arc4random CSPRNG remain unchanged. The changes are build-time only with no runtime impact.

Key technical details for future reference: The update reflects OpenBSD's capabilities since versions 3.8 (strcasestr) and 5.4 (memmem), with /proc support having been removed in OpenBSD 5.7. The diff shows precise modifications to config.mak.uname, removing 4 lines while adding 1. The thread shows consensus to modernize these settings after verification of OpenBSD's historical version support.
