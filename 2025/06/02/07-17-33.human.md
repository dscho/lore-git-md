This is a refactoring patch in Patrick Steinhardt's ongoing series to improve Git's maintenance task execution. It's part 7 of 12 in v3 of the series.

The patch fixes a minor but confusing inconsistency in how function pointer typedefs are declared in the maintenance task code. Currently, the typedefs for `maintenance_task_fn` and `maintenance_auto_fn` aren't true function pointer types - they're just function signatures, so users have to manually add the pointer syntax when declaring variables. The patch changes these to be proper function pointer typedefs by adding the `*` in the typedef itself.

This is a straightforward quality-of-life improvement that makes the code more intuitive to work with. While not fixing any functional issues, it follows the series' broader theme of cleaning up the maintenance task infrastructure. The change is mechanical and low-risk, touching only type declarations while keeping all actual behavior identical.

The patch fits into the series' systematic improvements to the maintenance task system's architecture and type safety. It's a small but logical step in the larger effort to make the code more maintainable and less error-prone.
