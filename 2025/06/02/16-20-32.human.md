This is a documentation refinement in the ongoing discussion about signature handling in `fast-export`/`fast-import`. 

Junio Hamano responds to Christian Couder's suggestions about making the experimental nature of the signature handling feature even more explicit in the documentation. Christian had proposed adding notes about the potential for default behavior changes in both the documentation and test comments.

He notes there are no current plans to change the default behavior before the feature matures beyond its experimental status.

The exchange shows the thread's continued focus on setting proper expectations around this unstable feature, with maintainers being cautious about over-documenting temporary states while still wanting to be transparent about potential future changes. This follows the thread's established pattern of prioritizing clear communication about the feature's experimental nature while deferring deeper technical decisions.
