This is a follow-up in the portability fix thread for config-list.h generation, addressing shell compatibility issues.

Collin Funk responds to Jean-Noël Avila's report that the initial OpenBSD sed fix fails on Debian systems using dash shell. The malformed output shows config options incorrectly concatenated with "$nl" literals rather than proper newlines. Collin acknowledges the oversight (having tested only with bash) and commits to sending a v2 patch that will work with both dash (as packaged in Fedora 42) and OpenBSD while maintaining the same output format as bash.

The exchange highlights the need for multi-platform validation, with Jean-Noël having previously recommended using gitgitgadget's CI for broader testing. Collin's response suggests the next version will focus on shell quoting behavior across implementations while preserving the original goal of OpenBSD compatibility. The technical challenge remains confined to generate-configlist.sh but now must satisfy both sed's \n limitation and dash's variable expansion rules.
