This is the 12th iteration of a feature and bugfix series for `imap-send`, focused on restoring functionality and adding OAuth2.0 support. The series has undergone extensive review and is now in its final polishing stages.

The key changes in v12 include:
1. Graceful handling when authentication methods (PLAIN, CRAM-MD5, OAUTHBEARER, XOAUTH2) are requested without OpenSSL support compiled in
2. Documentation formatting improvements (backticks for literals, 75-column wrapping)
3. Minor code style fixes (trailing comma in enum, string literal formatting)

The series as a whole:
- Fixes a critical config parsing bug that made `imap-send` unusable since Git 2.46.0
- Adds OAuth2.0 authentication support (both OAUTHBEARER and XOAUTH2)
- Implements PLAIN authentication for OpenSSL
- Adds new features like folder listing (`--list`) and command-line folder specification
- Includes various UX improvements like showing destination folders and port numbers

This version appears to address all remaining technical issues from previous reviews, with only minor documentation and error message wording left as potential discussion points. The changes are well-considered and the series looks ready for final inclusion after this last round of polish.
