This is a test infrastructure patch that's part of Patrick Steinhardt's Meson test integration series (v4). The patch focuses on improving TAP output compliance by removing test prerequisite announcements that were breaking the TAP format.

The changes modify several test scripts to stop printing messages about test prerequisites (like "will test on a case insensitive filesystem") while maintaining the same test functionality. Instead of announcing prerequisites, the tests now either:
1. Use the prerequisite directly in test_expect_success conditions
2. Skip tests with skip_all when prerequisites aren't met
3. Use test_lazy_prereq for more complex prerequisite checks

Key files modified include t0050-filesystem.sh (handling case sensitivity and Unicode tests), t3600-rm.sh (funny filename tests), t4000-diff-format.sh (filemode tests), t9500-gitweb-standalone-no-errors.sh (syntax highlighting), and t9903-bash-prompt.sh (prompt tests). The changes are mechanical but important for TAP compliance, removing 43 lines while adding 14, with the main impact being cleaner test execution output that properly follows the TAP format. This aligns with the series' goal of proper Meson test integration by ensuring all test output meets TAP specifications.
