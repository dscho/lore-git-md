This is the final patch in Patrick Steinhardt's v4 series refactoring Git's object database subsystem to remove `the_repository` global state. The patch renames `read_object_with_reference()` to `odb_read_object_peeled()`, completing the systematic conversion of ODB-related functions to use the new `odb_` prefix convention.

The new name better describes the function's purpose - it walks down commit and tag objects ("peeling") until finding an object of the required type. The change follows the established pattern of adding an ODB parameter and renaming with the `odb_` prefix, though no compatibility wrapper is needed since the function has limited usage (only 8 call sites across the codebase).

The patch updates documentation and callers in several key areas including `cat-file`, `fast-import`, `grep`, and tree-walking code. As with previous patches in the series, this is a mechanical change with no functional impact, maintaining the careful approach seen throughout this well-reviewed effort to modernize Git's object database API.
