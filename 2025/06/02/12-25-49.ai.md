This is a test infrastructure patch that's part of the ongoing reftable test conversion to the Clar framework (patch 1/10 in the series). It introduces new helper functions needed for the reftable test migration.

The patch creates two new files (`lib-reftable-clar.{c,h}`) that implement Clar-compatible versions of test helper functions previously defined in `lib-reftable.{c,h}`. The key additions are:

1. `cl_reftable_set_hash()` - Helper for setting hash values in tests
2. `cl_reftable_strbuf_writer()` - Creates a reftable writer that writes to a strbuf
3. `cl_reftable_write_to_buf()` - Comprehensive helper for writing reftable test data with validation

The implementation includes proper error checking using Clar's `cl_assert*()` macros and handles both ref and log records. The patch updates both Makefile and meson.build to include the new source files in the build system.

This appears to be a well-structured foundation for the subsequent test conversions in the series. The helper functions cover core reftable operations (writing refs/logs, hash handling) that will be needed across multiple test files. The implementation follows Clar conventions while maintaining the same functionality as the original test framework.
