Test modernization converting reftable block tests to Clar framework. This is patch 3/10 in the ongoing series to migrate reftable tests from a custom framework to Clar (libgit2's unit test framework).

The patch converts t-reftable-block.c to u-reftable-block.c, maintaining all test coverage while adopting Clar conventions. Key changes include:
- Renaming test functions to Clar's test_*__* naming pattern
- Replacing custom check() assertions with cl_assert*() variants
- Removing the cmd_main() test harness in favor of Clar's test discovery
- Updating Makefile and meson.build to compile the new test binary

The tests verify block read/write operations for all reftable block types (ref, log, obj, index) and iterator functionality. Each test case:
- Initializes block writers with different block types
- Writes test records with various edge cases
- Verifies round-trip readback of records
- Tests seek/iteration behavior

Build system changes remove the old t-reftable-block.c from UNIT_TEST_PROGRAMS and add u-reftable-block.c to CLAR_TEST_SUITES. The conversion follows the pattern established in earlier patches of the series, using the shared lib-reftable-clar.h helpers.
