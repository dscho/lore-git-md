Documentation patch converting the `pretty-formats.adoc` file to the new standardized format as part of the `git-log` documentation overhaul. This is patch 7/9 in the v2 series that has already been approved by Junio Hamano.

The patch mechanically converts the pretty format documentation to use `_<placeholder>_` syntax instead of angle brackets, wraps keywords and complex options in backticks, and handles special cases for %-prefixed format specifiers by using `++` escaping for parentheses. The content remains technically identical while improving presentation consistency with the project's documentation standards.

Key changes include:
- All format placeholders (like `%H`, `%an`) now use `++%H++` syntax
- Options and commands wrapped in backticks (e.g., `` `--abbrev` ``)
- Special escaping with `++` for format strings containing parentheses to prevent incorrect syntax highlighting
- Conversion of angle-bracket placeholders to underscore-wrapped (e.g., `<n>` -> _<n>_)
- Preservation of all technical content about pretty formats, tab expansion, signature verification etc.

The patch demonstrates the series' approach to handling special documentation cases - particularly the %-prefixed format specifiers that require careful escaping to render correctly while maintaining the exact same technical meaning. This completes the pretty formats portion of the larger `git-log` documentation conversion effort.
