This is the first patch in a documentation conversion series that updates the `git-log` man page to use Git's new standardized AsciiDoc format. The patch makes several mechanical changes to improve consistency and readability:

1. Converts the synopsis to use the new `[synopsis]` block format which automatically applies proper styling to placeholders and keywords
2. Standardizes placeholder notation from `<placeholder>` to `_<placeholder>_`
3. Wraps commands and options in backticks for consistent monospace rendering
4. Reorganizes the `--decorate` option documentation into a clearer enumerated list format

The changes are purely presentational - no technical information is altered. This is part of a larger effort to standardize Git's man page formatting across the project. The patch follows established conversion patterns and appears to be carefully implemented, with special attention given to preserving all existing content while improving its presentation.

As the first in a 9-part series that has already been reviewed and approved, this patch sets the foundation for the subsequent documentation updates by establishing the core formatting changes that will be applied throughout the `git-log` documentation ecosystem.
