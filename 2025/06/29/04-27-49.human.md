The commit message provides clear historical context tracing back to commit f8c4ab611a and notes that `strmap` would be the modern alternative for position-aware insertion needs.

The change is straightforward - removing the parameter and its conditional logic while maintaining identical behavior. This is part of a well-reviewed series that has already addressed all substantive feedback, with the author choosing to retain the performance test in shell script form.
