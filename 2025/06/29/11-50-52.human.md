This is the third patch in a refactoring series improving type precision in Git's parse-options infrastructure, focusing on OPTION_BIT handling. The change follows the pattern established in previous patches, adding precision specification and bounds checking for bit flag options.

The patch modifies OPTION_BIT to use the same precision-aware infrastructure introduced earlier in the series, requiring explicit size specification via a new 'precision' field. The implementation now uses get_int_value() and set_int_value() helpers for type-safe operations, replacing direct pointer manipulation. A flags field in write-tree.c is updated to demonstrate the new requirement.

Like other patches in the series, this maintains backward compatibility while adding stricter type safety. The changes are internal plumbing improvements with no user-facing effects, continuing the incremental approach of tackling one option type per patch. The implementation appears thorough, with corresponding updates to both the option handling code and its validation checks.
