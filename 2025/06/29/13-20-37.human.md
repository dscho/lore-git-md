Documentation patch converting rev-list options to new format. This is patch 5/9 in a series that standardizes Git's documentation syntax, specifically focusing on the `rev-list-options.adoc` file. The changes are mechanical in nature, updating the formatting to use consistent backtick-wrapped commands and `_<placeholder>_` notation while preserving all technical content. 

The patch makes several systematic changes: wrapping command-line options in backticks, converting angle-bracket placeholders to underscore-wrapped format (e.g., `<pattern>` becomes `_<pattern>_`), and adding the '%' character to the list of allowed characters in documentation markup. These changes align with Git's ongoing documentation standardization effort and have already been reviewed and approved by Junio Hamano for the v2 series.

The modifications are purely presentational - no technical content is altered - and follow the same pattern successfully applied to other documentation files. The patch includes updates to both the AsciiDoc configuration files and the main content file, ensuring consistent rendering across different documentation toolchains. This work is part of a larger project to improve Git's documentation consistency and maintainability.
