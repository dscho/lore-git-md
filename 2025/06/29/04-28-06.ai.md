This is a technical patch in the string-list modernization series, specifically addressing sign comparison warnings (-Wsign-compare) in the string-list implementation.

The patch modifies the binary search algorithm in string-list.c to eliminate sign comparison warnings by changing the return type of `get_entry_index()` from `int` to `size_t`. The key changes include:
1. Initializing the search range with `left = 0` instead of `-1`
2. Using `left < right` as the termination condition rather than `left + 1 < right`
3. Adjusting the search logic to use `left = middle + 1` when searching the right part

These changes allow the `DISABLE_SIGN_COMPARE_WARNINGS` define to be removed entirely from string-list.c. The patch maintains the same binary search behavior while using more appropriate unsigned types throughout. The commit message explains the historical reason for the original signed implementation (related to initializing `left` to -1) and how the new approach avoids this while being functionally equivalent.

This is part of the larger string-list modernization effort that combines test conversion with implementation improvements.
