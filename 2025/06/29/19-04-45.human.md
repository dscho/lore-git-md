This is a documentation patch improving formatting in the branch configuration section of Git's docs. Jakub Ječmínek noticed that the documentation for `branch.<name>.merge` was missing proper formatting for the placeholder `<name>` and for the config key itself. The patch adds AsciiDoc emphasis markers (`_<name>_`) and inline code formatting (`branch.<name>.merge`) to improve readability, particularly for online viewing.

The changes are straightforward and clearly beneficial - they make the documentation more consistent with Git's standard formatting practices without altering any technical content. This appears to be a well-scoped, uncontroversial improvement to the docs. The patch is small (just 2 lines changed) and focused on presentation rather than content.
