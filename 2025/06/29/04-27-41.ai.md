This is the first patch in a completed series modernizing string-list tests and implementation, focusing on warning fixes. The patch addresses sign comparison warnings (-Wsign-compare) in string-list.c by changing loop iterators from `int` to `size_t` where appropriate. 

The modifications touch several functions that iterate over string lists: string_list_remove_duplicates(), for_each_string_list(), filter_string_list(), and the clear functions. The changes are mechanical but important for type safety, as the list->nr field being compared against is of type size_t. One remaining sign comparison warning is deliberately left for a subsequent patch to handle with more care.

The patch demonstrates careful attention to detail, with each change following the same pattern of type adjustment while maintaining the existing logic. This is part of a broader effort that includes test modernization and implementation improvements, with all reviewer feedback already addressed in this v3 series.
