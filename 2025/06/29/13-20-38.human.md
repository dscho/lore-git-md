This is a documentation patch in a series converting Git's man pages to a standardized AsciiDoc format. It focuses on the pretty-format options for `git-log`, updating the syntax is shown in the documentation.

The patch mechanically converts the pretty-options documentation to use the new style guide: angle-bracket placeholders become underscored (_<format>_), command-line options and keywords are wrapped in backticks, and formatting is made more translation-friendly. The content remains identical - it's purely a presentation change to match Git's evolving documentation standards.

Notable changes include:
- Standardizing the placeholder syntax (e.g. `<format>` -> _<format>_)
- Wrapping all command-line flags and references in backticks
- Clarifying the relationship between `--pretty` and `tformat` options
- Maintaining all existing examples and examples while updating their formatting

This is patch 6/9 in a v2 series that has already been reviewed and approved by Junio Hamano. The changes are mechanical but thorough, covering all pretty-format options from `--pretty` itself through to signature verification. The patch follows the same transformation pattern successfully applied to other parts of Git's documentation.
