Refactoring patch completing a series to improve type safety in parse-options.

This is the final patch in René Scharfe's series to add precision-based type handling to Git's parse-options infrastructure. It extends the approach to OPTION_COUNTUP, which is used for incrementing counters (like `-v` for verbose mode). The patch follows the same pattern as previous ones in the series: adding bounds checking, proper type handling, and maintaining backward compatibility.

Key changes include:
- Adding precision-based handling for OPTION_COUNTUP using the get_int_value/set_int_value helpers introduced earlier
- Implementing bounds checking to prevent overflow
- Adding OPTION_COUNTUP to parse_options_check() validation
- Automatically setting precision in the OPTION_COUNTUP macro
- Updating test cases to include precision specifications

The patch maintains the series' focus on internal type safety without changing user-facing behavior. Like the rest of the series, it's a clean implementation that follows the established pattern while completing coverage of all relevant option types in the parse-options machinery. With this patch, the series now provides consistent precision handling across all integer-based parse-options types.
