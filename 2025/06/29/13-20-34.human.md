This is a documentation patch converting commit range notation in `rev-list-description.adoc` to the new AsciiDoc format. It's part of a larger series (v2 2/9) standardizing Git documentation syntax, specifically focusing on how commit ranges like `A..B` and `A...B` are displayed.

The change replaces single-quoted commit ranges with backtick-wrapped versions, which will trigger special rendering in the new documentation system. For example, `'<commit1>..<commit2>'` becomes `` `<commit1>..<commit2>` ``. The patch maintains all technical content while updating the markup style.

Junio Hamano has already reviewed and approved this version of the series, confirming the backtick format correctly displays in colorized viewers. The change is mechanical but important for consistency across Git's documentation. This follows the project's ongoing effort to standardize documentation presentation while preserving accuracy.
