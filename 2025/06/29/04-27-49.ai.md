This is a refactoring patch in shejialuo's series modernizing string-list tests. It removes an unused `insert_at` parameter from the internal `add_entry()` function, which was left behind when `string_list_insert_at_index()` was removed in 2014 (commit f8c4ab611a). The parameter was only ever passed as -1 by the remaining caller `string_list_insert()`, making it dead code. The change simplifies the implementation while maintaining identical behavior, with historical context provided in the commit message explaining the safety of this removal. This is part of the broader cleanup effort in the series, which has addressed all reviewer feedback except for one optional test reorganization. The patch is straightforward and uncontroversial, removing code that has been effectively unused for nearly a decade.
