Documentation patch converting `git-log` man page to new AsciiDoc format, part of a 9-patch series that has already been approved. This first patch focuses on mechanical conversion of the synopsis and option descriptions while preserving all functionality.

The changes standardize the formatting using AsciiDoc's `[synopsis]` block, converting angle-bracket placeholders to `_<placeholder>_` format and wrapping commands/options in backticks. Notable improvements include restructuring the `--decorate` option's value descriptions into a clearer enumerated list format and consistently applying the new markup rules throughout. The patch touches only `git-log.adoc`, with 46 insertions and 40 deletions showing the scope of the reformatting.

Key technical details for future reference: the conversion affects how commit ranges (`<revision-range>`), paths (`<path>...`), and various options like `--decorate-refs` are displayed. The `--decorate` option now shows its possible values (`short`, `full`, `auto`, `no`) in a formatted list. Placeholder phrasing uses "any of the _<pattern>_ parameters" construct that may be relevant for translation considerations.

This patch represents the first step in standardizing Git's second-largest man page, with subsequent patches in the series handling related documentation files. The changes are purely presentational - no behavioral changes or content alterations are made, just conversion to the project's newer documentation standards.
