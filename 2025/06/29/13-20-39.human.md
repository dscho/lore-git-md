Documentation patch converting the pretty formats section of Git's man pages to the new AsciiDoc format. This is patch 7/9 in Jean-Noël Avila's v2 series standardizing Git documentation, which has already been reviewed and approved by Junio Hamano.

The patch mechanically converts the pretty formats documentation in `pretty-formats.adoc` to use the project's new style guidelines. Key changes include:
- Angle-bracketed placeholders (`<placeholder>`) to underscored format (`_<placeholder>_`)
- Single-quoted terms to backtick-wrapped format (`` `oneline` ``)
- Special handling for %-prefixed format placeholders with parentheses (like `%(decorate)`) using AsciiDoc's `++` escaping

The conversion preserves all technical content while making the documentation more consistent with Git's evolving style standards. The changes are purely presentational - no behavior or functionality is altered. This completes the standardization of one of Git's more complex documentation sections, following the same pattern successfully applied to other parts of the documentation system in earlier patches.
