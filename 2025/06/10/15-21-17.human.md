This is the final patch in a 5-part series introducing the new `git repo-info` command, adding shallow repository detection to the metadata reporting capabilities. The patch follows the established pattern of the series by implementing both JSON and plaintext output formats for the new `layout.shallow` field, which reports the same information as `git rev-parse --is-shallow-repository`.

The implementation adds the series' third default field (joining `references.format` and `layout.bare`), showing shallow status alongside other fundamental repository characteristics. The change includes comprehensive tests that verify correct behavior for both shallow and non-shallow repositories across output formats, including a test case that creates an actual shallow clone to validate the true case.

The patch maintains the series' strong technical quality, with clean integration into the established code structure and thorough test coverage. It completes the initial set of repository metadata fields being migrated from `rev-parse`, though the infrastructure could clearly support additional fields in future contributions. With this patch, the RFC series demonstrates a complete working implementation of the proposed `repo-info` command.
