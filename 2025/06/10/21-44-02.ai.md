This is a follow-up to Patrick Steinhardt's Perl removal series, specifically addressing two post-merge issues identified in the test conversions. Junio Hamano notes Patrick is currently unavailable, so this may not warrant an immediate hotfix.

The changes address two distinct problems from the Perl-to-shell/awk/sed migration:

1. In t4150-am.sh, fixes an awk warning about an unnecessary `\@` escape in email headers by using a plain `@` character. This was a cosmetic issue that didn't affect test functionality but produced a warning.

2. More significantly, reverts parts of t5333-pseudo-merge-bitmaps.sh back to Perl for two operations:
   - Creating refs from input lines (where the sed conversion was producing empty input)
   - Extracting remote numbers (where the sed conversion wasn't properly validating)

The patch adds the PERL_TEST_HELPERS prerequisite to the affected test, acknowledging these cases still require Perl. This confirms SZEDER Gábor's earlier finding that the test was passing despite the broken conversion, highlighting a test validation weakness in the original series.

The changes are minimal and targeted, preserving the overall success of the Perl removal while addressing specific edge cases where the conversion either produced warnings or silent failures. The pseudo-merge test case in particular demonstrates the need for more rigorous output validation when converting test helpers.
