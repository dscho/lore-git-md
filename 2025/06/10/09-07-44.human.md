This is a feature patch that extends `git branch --force` to support moving multiple branches to a single target in one command, similar to how `cp` works with multiple source files. Currently, `--force` only allows moving one branch at a time, either to HEAD (1-arg form) or to a specified target (2-arg form).

Andrea Stacchiotti proposes changing the 2-arg form to accept multiple source branches followed by a single target, making the behavior analogous to `cp a b c dest`. The implementation loops through the source branches, creating each one at the target location. The patch includes documentation updates, code changes in `builtin/branch.c` to handle the new multi-branch case, and a new test case verifying the functionality.

The change appears well-considered - the commit message explains why this interpretation was chosen over alternatives (like moving all branches to HEAD), and the implementation maintains consistency with existing behavior while adding the new capability. The patch includes appropriate test coverage and documentation updates. This seems like a straightforward quality-of-life improvement for users who frequently need to move multiple branches.
