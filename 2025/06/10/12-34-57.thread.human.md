This thread discusses adding a `--trailer` option to `git rebase` that would allow appending trailers (like Signed-off-by) directly during rebase operations, avoiding the overhead of forking the `interpret-trailers` helper. The series is currently in its second version, having incorporated feedback from Phillip Wood during the RFC phase.

Junio C Hamano has reviewed the implementation and suggested restructuring the patches to first refactor the trailer handling into a shared helper (used by both `interpret-trailers` and the new rebase functionality) before adding the rebase integration. Phillip Wood has now weighed in, agreeing with Junio's architectural suggestion and noting that the current implementation still has parallel code paths rather than proper refactoring. He plans to review the restructured series more thoroughly when he returns from a two-week absence.

The technical discussion is now centered on ensuring behavior parity between the old and new implementations, particularly around the `amend_strbuf_with_trailers()` helper and its handling of commit message comments. While the core functionality appears sound, the series needs restructuring before it can progress further. The author will need to split the changes into cleaner, more focused patches that first establish the shared infrastructure before building the rebase integration on top.
