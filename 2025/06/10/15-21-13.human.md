This is the first patch in a 5-part series introducing a new `git repo-info` command as a GSoC project. The command will extract repository metadata functionality currently in `git rev-parse` into a dedicated tool with JSON and plaintext output options.

The patch lays the groundwork by:
1. Creating the new command skeleton with empty implementation in builtin/repo-info.c
2. Adding build system support (Makefile, meson.build)
3. Registering the command in git.c and builtin.h
4. Updating .gitignore for the new binary

This is a clean infrastructure patch that follows Git's standard patterns for adding commands. The implementation is minimal but correctly structured, with proper option parsing boilerplate already in place. The patch is part of a well-organized series with clear mentoring from experienced Git contributors.

As noted in the thread context, this is just the scaffolding - the actual metadata query functionality will come in subsequent patches. The current implementation returns immediately with no output, serving as a foundation to build upon.
