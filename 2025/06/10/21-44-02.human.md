This is a follow-up bugfix in Patrick Steinhardt's Perl removal series, addressing two post-merge issues identified by SZEDER Gábor. Junio Hamano is submitting the fixes while Patrick is unavailable.

The patch makes two corrections to the test suite conversions from Perl to shell/awk/sed. First, it removes an unnecessary `\@` escape in an awk email header test in t4150-am.sh that was triggering a warning. Second, and more importantly, it reverts a broken sed conversion in t5333-pseudo-merge-bitmaps.sh back to using the original Perl implementation, as the sed version was silently producing empty input.

The changes are minimal but important - the sed issue in particular could have masked test failures since the test was passing for the wrong reasons. Junio's note suggests this isn't urgent enough for a hotfix, but worth addressing soon since it affects test reliability. The patch maintains the series' overall goal of removing Perl while fixing these edge cases where the initial conversion wasn't quite right.
