This thread introduces a new feature allowing `git branch --force` to move multiple branches to a single target in one command, similar to how `cp` works. The patch modifies the branch creation logic in `builtin/branch.c` to handle multiple source branches, adds test coverage, and documents the change. The implementation follows existing `cp`-like semantics for consistency, and the author notes that other branch operations like move/copy would naturally error on duplicate names anyway. The change appears well-contained and maintains backward compatibility while adding a useful workflow improvement for cases where users need to force-move several branches at once.
