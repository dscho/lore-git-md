This is a follow-up review comment on Patrick Steinhardt's Perl removal series, which has already been merged. SZEDER Gábor points out two issues with the Perl-to-awk/sed conversions in patch 12/20 of the series.

First, in t4150-am.sh, the awk conversion produces a warning about an escaped '@' character being treated literally. While not a functional problem, this suggests the awk syntax could be cleaned up to avoid the warning.

Second, in t5333-pseudo-merge-bitmaps.sh, a sed conversion appears to have a syntax error (unterminated command) yet the test still passes, which Gábor finds suspicious. This may indicate either a test coverage gap or that the sed command isn't actually being exercised properly.

These are minor issues in an already-merged series, but worth noting for future reference. The warnings don't appear to affect functionality, but the sed syntax error that doesn't fail the test is particularly curious and might warrant a follow-up fix. The overall Perl removal effort remains sound, with these being small edge cases in the conversion process.
