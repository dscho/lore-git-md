This thread introduces a proposed new `git repo-info` command as a GSoC project, aiming to split repository metadata functionality from `git rev-parse` into a dedicated command. The RFC patch series has progressed to version 3/5, with each patch building incrementally on the previous work.

The initial patches established the command scaffolding and basic output formatting capabilities, including JSON and plaintext output options. The latest patch (3/5) adds the first concrete metadata field - reference storage format reporting - which exposes the same information as `git rev-parse --show-ref-format` but through the new structured output system. The implementation includes thorough tests for both files and reftable backends, and sets "references.format" as the default field when no specific fields are requested.

The series demonstrates solid technical execution, using Git's established patterns like json-writer.h and standard CLI parsing. While the core functionality is taking shape, several design questions from the RFC remain open, including the field specification syntax and JSON schema design. The incremental approach suggests these higher-level decisions will be addressed in later patches as more fields are implemented. The test coverage at each step indicates careful attention to maintainability and correctness as the command evolves.
