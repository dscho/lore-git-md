This is a localization (l10n) update pull request for Git 2.50.0, containing translation updates for 8 languages: Bulgarian, German, French, Irish, Indonesian, Turkish, Ukrainian, and Chinese. The most significant addition is the inclusion of a full Irish translation (ga.po) for the first time, adding nearly 30,000 new translation strings. 

The update comes from various contributors maintaining different language translations, with Jiang Xin coordinating the merges. The changes are relatively routine for a localization update - mostly incremental updates to existing translations with the notable exception of the new Irish support. 

The patch appears well-organized and follows the standard format for l10n updates, with each language maintainer's changes properly attributed. The Irish translation in particular represents a substantial new contribution to Git's internationalization support.
