Junio Hamano has proposed a new `--compact-summary` option for `git merge` and `git pull` to improve visibility of file creation/deletion during merges. The first patch in this two-part series introduces the core functionality, adding a new output format that explicitly marks created files with "(new)" suffixes in the diffstat. The implementation builds on existing diffstat infrastructure while maintaining backward compatibility - the traditional format remains the default unless users opt in via either the new command-line flag or a future `merge.stat=compact` configuration.

The changes touch merge and pull command implementations, their documentation, and add tests verifying both standard and compact output formats. The technical approach introduces a new `MERGE_SHOW_COMPACTSUMMARY` flag that works alongside the existing diffstat display options. So far there are no objections or open questions about the approach, though the thread is still in its early stages with only the initial submission. The second patch is expected to follow shortly, likely completing the series by adding the config option mentioned in the cover letter.
