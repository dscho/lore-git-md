The second patch, just received, extends this functionality through configuration by enhancing the existing `merge.stat` setting to support three states: `false` (no output), `true` (traditional diffstat), and new `compact` value (using the new format). The implementation carefully handles backward compatibility while providing identical output whether triggered via CLI or config. Both patches include thorough test coverage verifying the new behavior.
