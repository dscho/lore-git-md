This thread centers on a new compact summary format for merge operations, introduced by Junio Hamano in a two-patch series. The changes add both a command-line option (`--compact-summary`) and config setting (`merge.stat=compact`) to modify diffstat output, clearly marking new files with "(new)" suffixes during merges. The implementation touches several core files and includes comprehensive tests.

Kristoffer Haugsbakk has been instrumental in refining the documentation, suggesting improvements to both the CLI help text and config descriptions. After multiple rounds of feedback, Junio agreed that "compact summary" is the clearest terminology since it matches the actual option name, settling the last remaining wording question. While they discussed potentially adding `diffstat` as an alias for `true` in the future, this isn't required for the current implementation.

The technical implementation is complete and merged, with the discussion now focused solely on final documentation phrasing. The core functionality - showing created/deleted paths with clear markers through either command-line or configuration - remains unchanged and ready for use.
