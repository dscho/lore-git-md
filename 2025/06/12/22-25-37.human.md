Classification: feature (configuration extension)

This is the second patch in a two-part series introducing compact merge summaries. It extends the existing `merge.stat` configuration variable to support the new compact format introduced in the first patch. Where previously `merge.stat` was a simple boolean (true/false) controlling whether diffstat output was shown, it now accepts a third value "compact" to trigger the new compact summary format.

The implementation modifies the config parsing in `builtin/merge.c` to handle the new text value, falling back to the traditional diffstat for any unrecognized values (future-proofing against potential additions). Documentation is updated to explain the new option, and a test case confirms the config-driven behavior matches the CLI `--compact-summary` option from patch 1.

The change is cleanly implemented with clear documentation and testing. As the second half of a well-motivated series from the Git maintainer, this appears ready for inclusion. The compact summary format should help users better understand merge outcomes by explicitly calling out file creation/deletion.
