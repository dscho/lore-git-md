This is a platform compatibility patch addressing Solaris build issues with sed. Brad Smith confirms that Junio C Hamano's proposed fixes successfully resolve both reported problems when building Git on Solaris.

The patch makes two key changes: First, it adds a missing newline in `GIT-VERSION-GEN` to prevent a non-critical warning about incomplete text files. Second, it rewrites a sed expression in `generate-configlist.sh` to use basic regex (BRE) instead of extended regex (ERE), removing the problematic `-E` flag that wasn't supported by Solaris' native sed.

The confirmation from Brad Smith indicates the solution works as intended, with no remaining errors or warnings during the Solaris build. This appears to be a clean resolution to the compatibility issues without requiring detection of GNU sed (`gsed`) or other workarounds. The changes maintain the same functionality while improving portability across different sed implementations.
