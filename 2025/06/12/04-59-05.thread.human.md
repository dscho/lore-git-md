This thread covers a two-part patch series by Lidong Yan that makes two related improvements to Git's repository handling. The first patch completed the removal of `the_repository` global variable usage in `run_builtin()`, part of the ongoing multi-year effort to eliminate global state. The second patch, now merged to the `seen` branch, implements stricter validation when Git discovers repository configurations, specifically handling cases where `.git` entries exist but aren't valid (like FIFOs or device files).

Junio C Hamano reviewed and merged the series after Lidong addressed feedback about historical context in the first patch. The changes are now in the integration pipeline for broader testing. The validation improvements in particular help catch malformed repository setups earlier with clearer error messages, while maintaining backward compatibility for normal cases. This work connects to several past changes in repository initialization behavior and is part of Git's continuous effort to harden core operations.
