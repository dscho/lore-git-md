This is a bugfix patch that reverts a problematic change to Git's byte-swapping infrastructure. The patch is part of Sebastian Andrzej Siewior's 6-part series addressing endianness handling in Git codebase.

The reverted commit had incorrectly made built-in bswap functions available on all platforms, including big-endian systems like s390x, breaking assumptions elsewhere in the code that these functions should only be present on little-endian machines. This caused test failures in `t4014-format-patch.sh` and other tests on big-endian architectures.

Junio C Hamano (the Git maintainer) is reviewing the patch and notes a minor typo in the commit message ("31/64" instead of "32/64") that he plans to fix when applying the patch. The change itself is straightforward - it removes the problematic built-in bswap support and falls back to the previous x86-specific implementation.

This first patch in the series demonstrates careful attention to platform-specific behavior, with the revert serving as a necessary foundation for the subsequent improvements to Git's endianness handling. The series as a whole shows thoughtful consideration of both performance and correctness across different architectures.
