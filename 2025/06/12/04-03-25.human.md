This is a platform compatibility patch addressing Solaris build issues with sed. Junio Hamano responds to Brad Smith's report of two problems: a warning about missing newlines in version-def.h generation and an error about the unsupported `-E` flag in config-list.h generation.

The first issue is straightforward - the patch adds a newline to the input passed to sed when generating version-def.h. The second is more involved, replacing the extended regex (`-E`) syntax in generate-configlist.sh with basic regex syntax that Solaris sed can handle. Junio suggests loosening the pattern matching from `\{0,1\}` to `*` for simplicity while maintaining functionality.

The changes are minimal and focused, with Junio noting the patch is untested. This appears to be a pragmatic solution to make Git build on Solaris without requiring GNU sed, addressing the core compatibility issues while keeping the changes as unintrusive as possible. The patch maintains the thread's focus on portable build solutions rather than introducing new dependencies.
