This is a follow-up discussion about review protocol for the mailmap bugfix patch that's already been approved for merging. The thread has moved from technical discussion to Git project conventions around review trailers.

Junio Hamano clarifies that using "Reviewed-by" trailers from GitLab MR reviews is acceptable on the mailing list, as long as the reviewer stands behind the exact same patch content. He notes this is fine in this case since Christian Couder has now reviewed the mailing list version and confirmed it's identical to what he previously approved. The key principle is that reviewers should object if their name is used on substantially different patches they haven't vetted.

The exchange serves as useful documentation of project norms around review attribution across different collaboration channels (mailing list vs. GitLab). No changes to the patch itself are needed - this is purely about proper credit and process. The discussion reinforces that the fix is technically sound and ready for inclusion.
