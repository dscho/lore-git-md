Refactoring patch in the stash import/export series. This is the second of four patches in the final v8 iteration of the series, which has already received extensive review and is ready for merging.

The patch extracts stash revision parsing logic into a new `parse_stash_revision()` function, making it reusable for future work. It handles three cases: when no commit is specified (defaulting to the latest stash), when given a numeric index (like `stash@{2}`), and when given an explicit commit reference. The refactoring maintains all existing behavior while making the code more modular.

This change supports the larger stash export/import feature by providing shared infrastructure for parsing stash references. The implementation is straightforward and well-tested as part of the series' 268 lines of test coverage. Reviewers have already approved the approach in previous iterations, with no outstanding concerns about this particular change.
