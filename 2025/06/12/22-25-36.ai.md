Feature addition to merge/pull commands introducing a compact summary format. This first patch in a two-part series adds a `--compact-summary` option to `git merge` and `git pull` that modifies the diffstat output to explicitly mark created/deleted paths during merges. The implementation builds on existing diffstat infrastructure but adds new flags and output handling in builtin/merge.c and builtin/pull.c, with corresponding documentation updates.

Key technical details: The patch introduces a new `MERGE_SHOW_COMPACTSUMMARY` flag (value 2) alongside the existing `MERGE_SHOW_DIFFSTAT` (1), modifying the diff output format to use `DIFF_FORMAT_DIFFSTAT` with `stat_with_summary` flag when compact mode is active. The change is backward-compatible, defaulting to traditional diffstat output. Tests verify both the standard and compact output formats, with the compact version explicitly marking new files with "(new)" suffix.

The implementation touches core merge machinery (diff.c interaction), command-line interfaces, and their documentation while maintaining existing behavior when the new option isn't used. The patch appears well-tested with new test cases that verify the compact output format's specific labeling of created files. This builds cleanly on the thread's established context of improving merge visibility without introducing observable behavior changes for users not opting into the new format.
