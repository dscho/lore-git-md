FreeBSD build configuration update removing legacy FreeBSD 4.x compatibility settings, establishing FreeBSD 6.0 as the new minimum supported version. The patch deletes obsolete build flags and workarounds: NO_MEMMEM (now provided by FreeBSD 6.0+), special pthread handling, and integer type definitions that were only needed for FreeBSD 4.x. Other FreeBSD-specific paths and flags that remain relevant are preserved. No new code is added - this is purely a cleanup of outdated configuration blocks. The change is straightforward maintenance to align with current platform requirements.
