Platform compatibility patch updating FreeBSD build configuration. 

This removes several obsolete FreeBSD-specific build settings that are no longer needed on modern FreeBSD versions. The key change is removing `NO_MEMMEM` since FreeBSD 6.0 and later provide the `memmem()` function. The patch also cleans up some other outdated conditionals for FreeBSD 4.x systems and iconv handling for 10.1.

The changes appear straightforward and well-motivated - removing build-time workarounds for very old FreeBSD versions that are no longer relevant. The patch maintains all the still-relevant FreeBSD-specific paths and flags while simplifying the configuration. No behavior changes are expected for current FreeBSD systems, just removal of unnecessary legacy cruft.

The patch is minimal and focused, touching only `config.mak.uname` with a clear explanation in the commit message. This appears to be routine maintenance of platform support rather than anything controversial.
