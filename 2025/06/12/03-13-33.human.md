This is a platform compatibility patch for FreeBSD. Brad Smith updates the build settings in `config.mak.uname` to remove several outdated FreeBSD-specific configurations. The key change is removing the `NO_MEMMEM` flag since FreeBSD 6.0 and later now provide the `memmem()` function. The patch also cleans up some other legacy settings for older FreeBSD versions (4.x series) that are presumably no longer relevant.

The changes appear straightforward and well-scoped, focusing specifically on updating build configurations for modern FreeBSD systems. The commit message is quite brief but gets to the point - it's clear this is removing now-unnecessary workarounds rather than introducing new functionality. This seems like routine maintenance to keep the build system aligned with current platform capabilities.
