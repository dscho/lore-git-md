This is the final patch in the v8 series implementing stash import/export functionality, completing the bidirectional transfer capability. The patch adds the `git stash import` subcommand to complement the previously implemented export feature.

The import functionality reconstructs stash entries from an exported ref (created by `git stash export`), validating the commit chain structure and preserving original stash messages. Key technical aspects:
- Uses the same topology validation (`check_stash_topology()`) as export
- Appends imported stashes to existing stash stack rather than replacing (users must explicitly `clear` first if replacement is desired)
- Validates exported commit structure including empty-tree root and message prefixes
- Reuses infrastructure from export (commit walking, validation helpers)
- Adds 101 lines of test coverage in t/t3903.sh for round-trip verification, append behavior, and error cases

The implementation maintains the series' cross-platform compatibility and builds on the shared components established in previous patches (like `parse_stash_revision()` and `write_commit_with_parents()`).
