**Platform compatibility follow-up** - Brad Smith provides additional context about Solaris sed availability in response to Eli Schwartz's skepticism about GNU tools being standard on Solaris.

This email adds historical perspective to the resolved Solaris sed compatibility discussion. Brad Smith clarifies that while Solaris 11 does include GNU sed (`gsed`) in the base OS, this was not true for Solaris 10 and earlier versions. He provides links to Oracle's documentation showing both the native and GNU versions of sed are documented for Solaris 11.4.

The message serves as a post-resolution clarification rather than proposing any new changes, confirming that Junio's portable solution (using basic regex instead of requiring GNU sed) remains the right approach since it works across all Solaris versions. The exchange reinforces the thread's consensus that Git should work with native tools rather than depend on GNU utilities being available.
