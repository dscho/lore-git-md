This is a platform compatibility patch updating build settings for FreeBSD. Brad Smith proposes removing outdated configuration flags that were needed for FreeBSD 4.x, since the project now considers FreeBSD 6.0 the minimum supported version.

The key change is removing `NO_MEMMEM` since FreeBSD 6.0 provides this function, along with dropping several other 4.x-specific workarounds (pthread linking and integer type definitions). The patch is straightforward - it simply deletes these now-unnecessary build configurations while keeping other FreeBSD-specific settings intact.

The change appears well-justified and low-risk, being a simple cleanup of obsolete compatibility code. It follows the pattern seen when other platforms have raised their minimum supported versions. The patch is focused and touches only the intended build configuration.
