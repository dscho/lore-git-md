This is the second patch in a two-part series extending merge/pull statistics output, focusing on configuration support for the new compact summary format introduced in the first patch.

The change extends the existing `merge.stat` configuration variable from a simple boolean to accept three values: `false` (show nothing), `true` (show traditional diffstat), and new `compact` (use the compact summary format). The implementation modifies the config parsing in builtin/merge.c to handle this tri-state option while maintaining backward compatibility. Documentation updates clearly explain the new behavior, and a new test case verifies the config-driven compact output matches the CLI `--compact-summary` behavior from patch 1.

Key technical details include:
- Uses `git_parse_maybe_bool_text()` for flexible config value parsing
- Maps config values to existing `MERGE_SHOW_*` flags (0, `DIFFSTAT`, `COMPACTSUMMARY`)
- Handles unknown future values by falling back to default (`DIFFSTAT`)
- Maintains identical output format between CLI and config-driven compact summaries
- The test case follows the same pattern as the CLI test but uses `-c merge.stat=compact`

This completes the series by providing both CLI and config access to the new compact summary format, with the implementation appearing robust and well-tested. The change is backward compatible and follows established patterns for similar multi-valued config options in Git.
