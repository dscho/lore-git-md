This thread discusses platform compatibility considerations for FreeBSD support in Git, focusing on whether to use the system's `memmem()` implementation and which FreeBSD versions to officially support. The discussion began with Brad Smith suggesting enabling system `memmem()` from FreeBSD 6.0, but Carlo Arenas noted the implementation remained buggy until FreeBSD 12. 

Brian m. carlson has now weighed in, pointing out that FreeBSD 11.x has been end-of-life since 2021, and even earlier versions had functional (if slow) implementations. They strongly advocate dropping FreeBSD 4.x support entirely, given its lack of C99 compliance, missing POSIX features, and incompatibility with modern hardware - a position that aligns with Carlo's earlier observations.

The thread appears to be converging toward a conservative approach: allowing system `memmem()` only for FreeBSD 12+ (where the implementation is known good), while dropping official support for ancient versions like FreeBSD 4.x. The security implications of running end-of-life systems provide additional justification for modernizing Git's FreeBSD requirements. While no final decision has been made, the technical arguments now clearly favor updating the build system's version requirements.
