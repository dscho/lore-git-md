This thread addresses build failures on Solaris systems caused by sed portability issues in Git's build scripts. The patch modifies two scripts - GIT-VERSION-GEN and generate-configlist.sh - to work with older sed implementations that don't support extended regex (-E) or handle files without trailing newlines. The changes use basic regex syntax and ensure proper newline handling while maintaining functionality.

Brad Smith reported the Solaris build failures, and Collin Funk reviewed the solution. While Junio Hamano has some stylistic reservations about the sed approach, he considers the fix important enough to fast-track to master before the next release, prioritizing broad compatibility over perfect implementation. This follows Git's long-standing pattern of balancing modern practices with support for older or more constrained platforms.
