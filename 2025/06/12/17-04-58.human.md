This is a platform compatibility fix addressing build issues on Solaris systems. The patch makes two changes to sed scripts in Git's build system to work around limitations in older sed implementations:

1. In `GIT-VERSION-GEN`, it adds a newline when piping input to sed to avoid problems with implementations that require input to end with a complete line.

2. In `generate-configlist.sh`, it replaces the non-portable `-E` flag (for extended regex) with basic regex syntax and makes some pattern matching adjustments to be compatible with older sed versions.

The changes were prompted by a build failure report from a Solaris user. Junio notes he's not entirely happy with the sed script style but is holding off on further improvements to get this fix in before the release. The patch has already been reviewed by Collin Funk.

This is a straightforward compatibility fix that should help users on older Unix systems while maintaining the same functionality. The changes are minimal and focused, though Junio's comment suggests there may be follow-up cleanups after the release.
