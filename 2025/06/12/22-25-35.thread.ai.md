This thread introduces a new compact summary format for merge/pull operations via a two-patch series from the Git maintainer. The core change adds both CLI (`--compact-summary`) and config (`merge.stat=compact`) options to modify diffstat output, better showing created/deleted paths during merges by explicitly marking new files with "(new)" suffix.

The first patch implemented the CLI interface through a new `MERGE_SHOW_COMPACTSUMMARY` flag, modifying diff output to use `DIFF_FORMAT_DIFFSTAT` with `stat_with_summary` when active. The second patch extends `merge.stat` config to support tri-state values (`false`, `true`, `compact`), using `git_parse_maybe_bool_text()` for flexible parsing while maintaining backward compatibility. Both patches share the same output format, verified by matching test cases.

Implementation touches builtin/merge.c, builtin/pull.c, diff.c, and their documentation, with tests covering both CLI and config-driven behavior. The changes are backward-compatible and opt-in, building on prior discussions about improving merge visibility. The series appears complete with no outstanding questions or objections, providing consistent compact summary output whether activated via command line or configuration.
