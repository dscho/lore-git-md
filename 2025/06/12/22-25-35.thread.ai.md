This thread introduces a new compact summary format for merge/pull operations via a two-patch series from the Git maintainer. The core change adds a `--compact-summary` option and extends `merge.stat` config to support a "compact" value, modifying diffstat output to better highlight created/deleted paths during merges. The motivation stems from current `git diff --stat` not clearly showing path creation/deletion status in merge contexts.

The first patch adds the `--compact-summary` CLI option to `git merge` and `git pull`, implementing it through a new `MERGE_SHOW_COMPACTSUMMARY` flag (value 2) alongside existing `MERGE_SHOW_DIFFSTAT`. The change modifies diff output to use `DIFF_FORMAT_DIFFSTAT` with `stat_with_summary` flag when active, explicitly marking new files with "(new)" suffix while maintaining backward compatibility. Implementation touches builtin/merge.c, builtin/pull.c, diff.c, and their documentation, with new tests verifying both standard and compact output formats.

The series builds on prior discussions about improving merge visibility, with this initial patch focusing on the basic machinery before potentially expanding to other commands. The change is backward-compatible and opt-in through both CLI and future config options. Files affected include merge/pull command code, diff machinery, man pages, and test suite. No open questions or objections raised yet in this initial submission. The implementation appears well-tested with new cases specifically verifying the compact output format's labeling behavior.
