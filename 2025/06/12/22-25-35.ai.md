This is a cover letter for a feature patch series introducing a new compact summary format for merge/pull operations. The series adds a `--compact-summary` option and extends the `merge.stat` config to support a "compact" value, changing the default diffstat output to show created/deleted paths more clearly.

The motivation is that while the current `git diff --stat` output gives a good overview of changes, it doesn't clearly indicate which paths were created or deleted during the merge. The new compact summary format (using `git diff --compact-summary`) will make this more apparent. The series consists of two patches: one implementing the command-line option and another extending the configuration variable. Documentation and tests are included across multiple files.

This appears to be a well-considered enhancement from the Git maintainer, building on previous informal discussions (referenced links show this has been discussed before). The implementation touches merge/pull command implementations, their documentation, and adds comprehensive test coverage. The change is focused and backward-compatible, making the new format opt-in via both CLI and config options.
