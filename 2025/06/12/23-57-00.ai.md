Translation update for Git 2.50.0, version 2 of the localization pull request. This builds on the previous localization updates by adding Traditional Chinese (zh_TW) translations from Yi-Jyun Pan, completing the set of planned updates for the 2.50.0 release.

The v2 update includes Yi-Jyun Pan's contribution of 1191 lines of Traditional Chinese translations (659 additions, 532 deletions), bringing the previously submitted localization changes to completion. This joins the existing updates that added Irish (ga.po) as a new language and updated translations for Bulgarian, German, French, Indonesian, Turkish, Ukrainian, and Simplified Chinese.

The changes are coordinated by Jiang Xin through a series of merges from various translators' repositories. The complete diff shows 33,060 lines added and 3,843 lines removed across 10 PO files, with the new Irish translation accounting for the bulk of additions at 29,758 lines. The update is based on Git 2.50-rc2 and targets the upcoming 2.50.0.
