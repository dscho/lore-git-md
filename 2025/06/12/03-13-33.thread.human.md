This thread discusses cleaning up outdated FreeBSD build configuration in Git. The original patch removes obsolete settings like NO_MEMMEM (available since FreeBSD 5.2.1) and other legacy conditionals for very old FreeBSD versions (4.x systems from 2000). Collin Funk has reviewed the changes, confirming the NO_MEMMEM removal with a Reviewed-by tag, but raised a question about whether we should also remove the FreeBSD 4.x-specific PTHREAD_LIBS and integer type definitions. The discussion is now considering how far back we should maintain compatibility - whether code supporting 20+ year old FreeBSD versions is still worth keeping. So far the changes appear uncontroversial, with just this one open question about the scope of legacy system support removal.
