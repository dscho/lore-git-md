This thread has been cleaning up obsolete FreeBSD build configuration in Git, focusing on removing support for very old FreeBSD versions. The original patch proposed dropping several FreeBSD-specific build settings (NO_MEMMEM, PTHREAD_LIBS, and others) that were only needed for FreeBSD 4.x systems, establishing FreeBSD 6.0 (released in 2005) as the new baseline.

Collin Funk provided initial review approval, while Brad Smith - a FreeBSD expert - confirmed the historical accuracy of these changes and supported dropping the outdated definitions. Junio Hamano requested explicit documentation of the version cutoff rationale before merging. Brad Smith followed up with details about dropping support for versions older than 6.5 (nearly 20 years old).

Renato Botelho has now chimed in to confirm that the oldest currently supported FreeBSD version is actually 13.5 (supported until April 2026), making the removal of these ancient version checks even more clearly justified. With this confirmation from another FreeBSD contributor and the version rationale now clearly documented, the thread appears ready for Junio to pick up the changes. The patch series remains focused on build system cleanup with no runtime behavior changes.
