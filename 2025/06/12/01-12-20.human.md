This is the final patch in the v8 series implementing stash import/export functionality, completing the bidirectional transfer capability. The patch adds the `git stash import` subcommand to complement the previously implemented `export` command.

The import functionality takes a commit created by `stash export` and reconstructs the original stash entries, appending them to the current stash stack rather than replacing it. This design choice - users can either append imported stashes or explicitly clear first if they want replacement behavior. The implementation validates the imported commit chain matches the expected stash format and preserves original commit messages.

Key technical aspects:
- Reuses the topology validation from export (`check_stash_topology()`)
- Carefully parses commit messages to maintain original stash descriptions
- Includes extensive test coverage (101 new test lines) verifying:
  - Round-trip fidelity (export then import produces identical stashes)
  - Append behavior (import doesn't clear existing stashes)
  - Error handling for invalid imports
  - Edge cases like empty imports

This completes a feature that enables stash sharing between repositories while maintaining Git's standard commit-based transfer mechanisms.
