This is a platform compatibility patch updating build configuration for FreeBSD. The change removes several legacy FreeBSD 4.x compatibility settings now that FreeBSD 6.0 is established as the minimum supported version. Key changes include:

1. Removing `NO_MEMMEM` since FreeBSD 6.0 provides `memmem()`
2. Dropping special pthread and integer type handling that was only needed for FreeBSD 4.x
3. Keeping other FreeBSD-specific paths and flags that remain relevant

The patch is straightforward - it simply deletes obsolete configuration blocks without adding new code. The commit message clearly states the rationale (FreeBSD 6.0 becoming the baseline) and the specific functionality being removed. This appears to be a routine maintenance update to keep the build system aligned with current platform requirements.
