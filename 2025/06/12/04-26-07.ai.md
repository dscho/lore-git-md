This is a follow-up discussion in the Solaris build compatibility thread, focusing on the availability of GNU sed (`gsed`) on different Solaris versions. Brad Smith provides clarification about GNU sed's inclusion in Solaris distributions, noting that while Solaris 11 includes GNU sed as part of the base OS, this was not the case for Solaris 10 and earlier versions. He references Oracle's documentation showing both the native and GNU versions of sed are documented for Solaris 11.4.

The email serves as additional context about platform-specific tool availability, reinforcing the earlier decision to use portable sed syntax rather than requiring GNU sed. Brad's observation supports the thread's consensus that mandating GNU tools would be problematic for older Solaris installations, validating Junio's earlier patch that worked around the `-E` flag requirement by using basic regex syntax instead.
