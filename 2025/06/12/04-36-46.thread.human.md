This thread discusses a straightforward build system update for FreeBSD compatibility. The patch removes several legacy configuration settings that were only needed for FreeBSD 4.x, now that FreeBSD 6.0 has become the minimum supported version. The changes include removing NO_MEMMEM (as memmem() is now available) and dropping some obsolete pthread and integer type handling, while preserving other relevant FreeBSD-specific paths and flags. The patch appears uncontroversial - it's a clean-up of obsolete code rather than introducing new functionality. No discussion or objections have been raised so far.
