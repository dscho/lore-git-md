Thread identity: Localization (l10n) update for Git 2.50.0, consisting of translation updates for multiple languages. Originating author is Jiang Xin, who submitted the pull request and coordinated the updates.

Core problem or goal: Update and expand Git's localization support for the upcoming 2.50.0 release by incorporating translations from various language teams. The changes include both updates to existing translations and the addition of a new Irish (ga) translation.

Current status: The changes are based on Git 2.50-rc2 and target the 2.50.0 release. The update includes modifications to 8 existing translation files and introduces one completely new translation (Irish).

Key technical details: The changes affect PO files in the localization directory, with 32,401 lines added and 3,311 lines removed. The new Irish translation (ga.po) is a substantial addition at 29,758 lines. Other updated files include bg.po (Bulgarian), de.po (German), fr.po (French), id.po (Indonesian), tr.po (Turkish), uk.po (Ukrainian), and zh_CN.po (Chinese).

Participant positions: Jiang Xin submitted and coordinated the pull request.
