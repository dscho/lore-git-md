This is a feature patch introducing a new `--compact-summary` option for `git merge` and `git pull`, part of a two-patch series from the maintainer. The change modifies the diffstat output during merges to explicitly mark created/deleted files, addressing a current gap where such status isn't clearly visible in standard merge output.

The implementation adds the new CLI flag and updates both commands' documentation while maintaining backward compatibility. The core change involves modifying the diff output machinery in `builtin/merge.c` to handle the new compact format, which highlights new files with "(new)" markers. Tests verify the behavior, including a case showing the clearer output format when files are created during a merge.

The patch appears well-constructed with thorough test coverage and clean documentation updates. As the first in a series, it lays groundwork for potentially expanding this format to other commands, though the immediate focus is on merge/pull operations. Given the maintainer's authorship and clear motivation, this seems likely to be uncontroversial.
