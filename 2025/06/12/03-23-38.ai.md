Platform compatibility issue with Solaris's `sed` implementation. Brad Smith reports two problems encountered when building Git on Solaris:

1. A warning about missing newline at end of file when generating version-def.h
2. An error about illegal `-E` option when generating config-list.h (introduced recently by commit e1b81f54da)

The email doesn't propose specific fixes but seeks suggestions for solutions. The second issue appears to stem from Solaris's `sed` not supporting the `-E` flag (for extended regex) that was recently introduced in the build process. This is a classic platform compatibility challenge where GNU/Linux tools differ from their BSD/Solaris counterparts. The commit referenced (e1b81f54da) would need to be examined to understand the context of the `-E` flag usage and whether an alternative approach could work across all platforms. The first issue about newlines might be a separate warning that could potentially be suppressed if not critical.
