Bugfix follow-up in the `imap-send` authentication series. The error occurs when an unknown authentication method is specified.

Aditya Garg confirms this will be addressed in the next version (v18) of the patch series. The issue is noted as being outside the main scope of both this specific patch and the overall series, but represents a straightforward fix to improve error message accuracy. This follows the pattern of incremental improvements being made throughout the review process for this comprehensive `imap-send` overhaul.

The thread context shows this is one of the final polish items remaining in the series, which has already addressed more substantive issues like configuration parsing regressions, OAuth2.0 support, and memory management fixes. The main outstanding debate remains the port number formatting in credential prompts, while smaller issues like this error message are being cleaned up as they're identified.
