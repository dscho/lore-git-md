This is a feature patch in the ongoing `imap-send` improvement series, specifically addressing folder management. The patch adds a `--folder` command-line option to override the default IMAP folder specified in config, with proper memory management (freeing the old value before setting the new one via `xstrdup`).

The implementation follows the established pattern in the series, with the command-line option taking precedence over config while maintaining the config value as a fallback. Documentation is updated in both the config and command manpages to clarify this precedence and provide examples. The patch also incidentally fixes some minor markdown formatting inconsistencies in the existing docs.

Junio Hamano's review notes two small suggested improvements: removing the explicit `= NULL` initialization (letting BSS handle it) and mentioning the documentation formatting fixes in the commit message. These are minor style points that don't affect functionality. The core implementation appears solid, matching the careful approach seen elsewhere in the series for handling string allocations and overrides.

This patch was originally part of v16 of the series and has now been rebased to v17 with no functional changes. It fits into the broader effort to modernize `imap-send` with better folder management capabilities alongside the OAuth2 authentication and configuration parser fixes covered in other patches.
