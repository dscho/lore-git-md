User experience improvement in the `imap-send` command, part of the v18 series adding OAuth2.0 support and folder management.

This patch enhances the progress output during message sending to include the destination folder name. Previously, the output would simply show "sending N message(s)", while now it displays "Sending N message(s) to FOLDER folder..." where FOLDER is the configured destination (like "Drafts" or "Sent"). The change is applied consistently to both the OpenSSL and libcurl backend implementations in `imap_send.c`.

The implementation is straightforward - it just adds the folder name to existing progress messages in `append_msgs_to_imap()` and `curl_append_msgs_to_imap()`. The change maintains all existing functionality while providing more context to users about where their messages are being sent. This aligns with other user experience improvements in the series like showing non-default ports in credential prompts.

As part of the larger series that has undergone extensive review, this small but useful change appears well-integrated with the existing code and follows the same style. It doesn't introduce any new configuration or behavior changes beyond the enhanced messaging.
