This is a documentation and style polish patch, the final one in a 10-part series that adds OAuth2.0 support and various improvements to `imap-send`. The patch standardizes log and error message formatting throughout `imap-send.c`:

1. Makes abbreviations like "IMAP" and "OK" consistently uppercase
2. Changes error messages to start with lowercase and drop periods (matching Git's style)
3. Adds missing words in some messages for clarity (e.g., "SSL support is not compiled in")
4. Makes similar messages consistent (e.g., changing "no messages to send" to "no messages found to send")

The changes are mechanical and non-controversial, touching only message strings without affecting functionality. Junio Hamano had previously noted the capitalization issues in his review of the series, and this patch addresses those final nits. As the last patch in a thoroughly reviewed series that has maintainer approval, this appears ready for merging once any final review feedback is addressed.
