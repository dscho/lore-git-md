This is a user experience improvement patch in the `imap-send` series, specifically enhancing progress output during message sending. The change modifies the destination folder display to show which IMAP folder messages are being sent to, making the output more informative.

The patch updates both the OpenSSL and libcurl backend implementations in `imap-send.c` to include the folder name in the progress message. The new output format changes from a generic "sending X messages" to "Sending X messages to FOLDER folder...", where FOLDER is the configured destination (like "Drafts" or "Sent"). The implementation is straightforward - just modifying two fprintf() calls to include the server->folder parameter.

This appears to be a well-contained, non-controversial change that improves user feedback without introducing any new complexity. The patch is part of a larger series that has already received extensive review, with this being one of the final UI polish items. The change is small (4 lines added, 2 removed) and focused solely on output formatting, with no impact on functionality or error handling.
