This is a test infrastructure patch addressing platform compatibility on macOS. Ramsay Jones identifies a missing prerequisite setup in `t/test-lib.sh` that's causing macOS tests to be incorrectly skipped. The issue stems from commit d3d8c601fd which added macOS support but omitted several standard prerequisites (POSIXPERM, BSLASHPSPEC, EXECKEEPSPID) that are set in the default case.

The patch adds these missing prerequisites to the Darwin case block, which should allow more tests to run on macOS systems. The author notes they cannot test this themselves (lacking macOS access) and marks it as RFC, suggesting it could potentially be squashed into the original commit if still in the 'next' branch. The change is minimal (3 lines added) and appears well-motivated by the observation that "lots of tests should be being skipped" on macOS currently.

Key technical details for future reference: the patch modifies test prerequisites in `t/test-lib.sh`, specifically adding POSIXPERM (POSIX permission tests), BSLASHPSPEC (backslash path handling), and EXECKEEPSPID (process ID retention) for Darwin systems. The original oversight occurred in commit d3d8c601fd which introduced macOS test support but didn't carry over these default prerequisites.
