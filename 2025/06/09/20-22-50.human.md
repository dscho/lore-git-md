This is a feature patch in the ongoing `imap-send` authentication improvements series (v18, patch 5/10). It adds PLAIN authentication support for the OpenSSL backend, completing parity with the existing libcurl implementation.

The patch implements RFC 4616-compliant PLAIN authentication by properly encoding the username and password in the required NUL-delimited format before base64 encoding. This addresses a gap where OpenSSL would only support the basic IMAP LOGIN command while libcurl already handled PLAIN. The change is particularly useful for services that use app passwords with PLAIN auth.

Key technical changes include:
- New `AUTH_PLAIN` capability flag
- `plain_base64()` helper function implementing the RFC-specified encoding
- `auth_plain()` handler for the OpenSSL authentication flow
- Documentation update to list PLAIN as a valid auth method

The implementation follows the same pattern as other auth methods in the series, with proper memory management and error handling. This appears to be a well-contained addition that completes the authentication matrix for OpenSSL, bringing it to feature parity with libcurl's capabilities. The patch fits cleanly into the broader series' goal of comprehensive IMAP support.
