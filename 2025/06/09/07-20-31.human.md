This is the v16 cover letter for a feature and bugfix series that makes `imap-send` usable again while adding OAuth2.0 support. The series has undergone extensive review over 16 iterations and is now in its final form, with only minor patch ordering changes from v15 to better group related functionality.

The series fixes a critical regression that broke `imap-send` in Git 2.46.0 by incorrectly NULLing out the folder configuration, and adds modern authentication methods including OAuth2.0 (both OAUTHBEARER and XOAUTH2 protocols) and PLAIN authentication. It also introduces user-facing improvements like command-line folder specification (`--folder`) and folder listing (`--list`), along with better progress output showing the target folder during sends.

The implementation is thorough, with proper error handling for all authentication methods and comprehensive documentation updates. The series has received maintainer approval for its core changes, with only minor polish remaining. The v16 reorganization groups the new authentication methods together followed by the folder management features, then the UI improvements, making the progression more reviewable.

This represents a significant modernization of `imap-send`, bringing it up to date with current email provider requirements while fixing long-standing usability issues. The careful attention to both technical correctness and user experience makes this a high-quality contribution that should benefit users needing to send patches via IMAP.
