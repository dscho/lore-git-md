This is a feature patch adding OAuth2.0 authentication support to `git imap-send`, part of a larger series that has been through extensive review (now at v17). The patch implements both RFC-standard OAUTHBEARER and Google-proprietary XOAUTH2 authentication methods, with helper functions `oauthbearer_base64()` and `xoauth2_base64()` handling the protocol-specific encoding requirements.

The changes include documentation updates explaining how to use OAuth2.0 with both Gmail and Outlook, noting that Outlook requires XOAUTH2 specifically. The implementation works with both OpenSSL and libcurl backends, with special handling in the curl setup to use `CURLOPT_XOAUTH2_BEARER` when appropriate. The patch appears thorough, with clear protocol citations (RFC5801, RFC7628) and proper error handling.

This builds on earlier patches in the series that fixed critical configuration parsing bugs and added other authentication methods. The implementation looks well-researched, with attention to both standards compliance and real-world provider requirements (like Google's XOAUTH2 format). The documentation improvements are particularly useful, explaining the security benefits over app-specific passwords.
