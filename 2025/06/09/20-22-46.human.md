Bugfix for a critical regression in `imap-send` that has been broken since Git 2.46.0. This is the first patch in a larger series (v18) adding OAuth2 support and other improvements to `imap-send`.

The patch fixes a configuration parsing bug where unrelated IMAP settings (`imap.user`, `imap.pass`, etc.) were incorrectly clearing the `cfg->folder` field due to copy-paste errors in the cleanup code. This made `git-imap-send` completely unusable when these common configuration options were set. The fix properly clears each field's corresponding struct member instead of always clearing the folder.

The regression was introduced in commit 6d1f198f34 and went unnoticed for some time, likely because most users have switched to `git-send-email`. The patch is straightforward - just correcting which fields get cleared for each config option - but addresses a showstopper bug for anyone still using `imap-send`.

This is part of a well-reviewed series that has gone through 18 iterations with input from multiple Git maintainers. The bugfix comes first in the series as it unblocks basic functionality before adding new features in subsequent patches.
