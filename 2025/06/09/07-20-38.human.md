Feature patch adding folder listing capability to `imap-send`, part of a larger series improving IMAP functionality. This patch introduces a new `--list` option that shows available IMAP folders, which is particularly useful since different providers (Gmail, Outlook, etc.) use different naming conventions. The implementation works with both OpenSSL and libcurl backends, following RFC6154 standards.

The patch shows good attention to detail, handling both backends consistently and including documentation updates. The example output demonstrates how this helps users discover folder names like "[Gmail]/Trash" versus "Deleted" on Outlook. This is one of the final patches in a well-reviewed series that has already addressed core authentication and configuration issues, with only minor features remaining before merge.
