This is the v16 cover letter for a feature and bugfix series that makes `imap-send` usable again while adding OAuth2.0 support. The series has undergone extensive review over 16 iterations and is now in its final form, with only minor organizational changes from v15.

The series fixes a critical regression (since Git 2.46.0) where `imap-send` would incorrectly NULL out the folder field during config parsing, making the command unusable. It adds OAuth2.0 authentication support via both RFC-standard OAUTHBEARER and Google-proprietary XOAUTH2 protocols, implemented for both OpenSSL and libcurl backends. New helper functions `oauthbearer_base64()` and `xoauth2_base64()` handle the authentication string construction.

Additional features include comprehensive folder management via new `--list` and `--folder` command-line options, with RFC6154-compliant handling of folder enumeration. The implementation provides proper OpenSSL availability checking and refactored authentication logic via a new `try_auth_method()` helper. User experience improvements include showing the destination folder during send operations and displaying host:port in credential prompts.

The v16 reorganization moves the new authentication methods earlier in the series, followed by the folder management features, with minor UI polish patches at the end. No code changes were made from v15 - this is purely an organizational adjustment. The series has received maintainer approval for its core changes and appears ready for merging after final review of the remaining minor features.

Key technical components include:
- Fixed configuration parser bug (regression from 6d1f198f34)
- OAuth2.0 support via OAUTHBEARER/XOAUTH2 with new base64 helpers
- PLAIN authentication method for OpenSSL
- New `--folder` option for runtime folder specification
- New `--list` option showing available folders
- Improved credential prompts and progress output
- Standardized error message formatting

The implementation spans configuration parsing, authentication handlers, base64 utilities, IMAP protocol handling, and folder management, with thorough test coverage. The series maintains backward compatibility while adding these new features.
