This is a user experience improvement patch for `imap-send`, part of a larger v16 series adding OAuth2.0 support and folder management features. The change enhances the progress output during email sending to show the destination folder name, making it clearer where messages are being delivered. 

The patch, `imap-send` would simply show "sending N messages" during transfer. Now it includes the folder name (e.g. "Sending 1 message to Drafts folder..."). This small but helpful change provides better visibility into the operation, especially when users override the default folder via the new `--folder` option introduced earlier in the series.

The implementation is straightforward - modifying two fprintf() calls in both the OpenSSL and libcurl backend paths to include the folder name from server->folder. As the final patch in a well-reviewed series that's already received maintainer approval, this appears ready for inclusion as a nice polish to the user interface.
