This is a feature patch adding PLAIN authentication support to `imap-send`'s OpenSSL backend, part of a larger series modernizing IMAP functionality. 

The patch implements RFC 4616-compliant PLAIN authentication for the OpenSSL backend, which previously only supported LOGIN commands. The implementation follows the same pattern as other auth methods in the series, using a new `plain_base64()` helper to properly encode credentials in the NUL-delimited "user\0pass" format before base64 encoding. The auth method is integrated into the existing authentication dispatch system via a new `AUTH_PLAIN` capability flag and `auth_plain()` handler function.

The change is well-contained, adding about 60 lines of straightforward code with proper error handling and memory management. The documentation is updated to reflect that PLAIN is now available for both curl and OpenSSL backends. This fills a gap where PLAIN (commonly used with app passwords) was previously only available when using curl.

As part of the v17 series that has undergone extensive review, this patch appears ready for inclusion, completing the authentication method support matrix for both backends. The implementation matches the quality and style of the rest of the series, with clear RFC references and consistent error handling patterns.
