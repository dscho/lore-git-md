This is Junio Hamano's regular "What's cooking" status update for June 2025, providing an overview of recent activity in the Git project. The email highlights several notable changes:

The release candidate Git 2.50-rc2 has been tagged, indicating the project is in the final stabilization phase before the next release. Several bugfixes and improvements have graduated to 'master', including a test fix for symbolic link handling and a memory leak fix in submodule handling.

New topics include documentation updates for `git-log`'s mark-up conversion, a stash message fix for submodules, and a memory leak fix in submodule remote branch handling. The `imap-send` command is seeing significant updates after being broken for a long time, now supporting OAuth2 authentication and other modern features.

Ongoing work includes performance improvements to bulk reference updates, Solaris compatibility updates, and continued progress on removing the `the_repository` global variable. The email also notes several topics that may need rerolls or have open questions, including work on the reftable unit tests and an interchange format for stash entries.

The update follows Junio's standard format, clearly marking which branches contain each change and providing links to discussion threads. Several older or less-supported topics have been discarded, including updates to the Thunderbird patch contrib script and various defensive programming changes that lacked community support.
