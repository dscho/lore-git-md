This is a feature patch in the ongoing `imap-send` series, adding a command-line `--folder` option to override the IMAP destination folder. The patch is part of v18 of the series which has already addressed all major technical issues and review feedback.

The change introduces a new `-f/--folder` option that takes precedence over the config's `imap.folder` setting, with proper memory management (freeing the old value before duplicating the new one). The documentation updates clarify that the config value serves as a fallback when the command-line option isn't used, and fixes some minor formatting inconsistencies in the docs (switching quotes to backticks for command/field names).

Implementation-wise, it adds an `opt_folder` static variable, extends the option parsing table, and applies the override before connecting to the server. The change is straightforward and well-contained, with no apparent edge cases or complications. This was one of the simpler patches in the series, which has already undergone extensive review for its more complex authentication and configuration handling changes.
