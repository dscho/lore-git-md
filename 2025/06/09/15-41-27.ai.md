Feature patch in the ongoing `imap-send` series, adding port number display to credential prompts. This is patch 8/10 in v17 of the series, which has already addressed critical configuration parsing bugs and added OAuth2.0 support.

The change modifies the credential helper prompt to include the port number when requesting passwords, making it consistent with `git send-email`'s behavior. The implementation uses `xstrfmt` to combine host and port in the format "host:port" (e.g., "outlook.office365.com:993") when constructing the credential structure. The port will always be present since the code defaults to 993 for IMAPS or 143 for IMAP when not explicitly specified.

This appears to be a straightforward usability improvement that aligns with existing Git conventions. The change is minimal (a single line modified in `server_fill_credential()`) and builds on the series' pattern of enhancing user experience.
