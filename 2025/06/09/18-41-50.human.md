Bugfix for macOS test prerequisites, now approved for merging.

This is a follow-up to Ramsay Jones's patch fixing missing test prerequisites for macOS (POSIXPERM, BSLASHPSPEC, and EXECKEEPSPID) in `t/test-lib.sh`. The issue was introduced in commit d3d8c601fd which added macOS support but omitted these standard test categories.

Junio Hamano has approved the patch despite lacking macOS access himself, recognizing it simply restores pre-bug behavior. The change will be applied to the ps/meson-tap-parse topic branch. Patrick Steinhardt (the topic branch owner) also approves but notes he can't test immediately due to being on vacation.

The 3-line addition is considered low-risk as it aligns with existing platform-specific test patterns. While originally marked RFC due to testing limitations, consensus has been reached that this was a clear oversight needing correction. The patch will ensure macOS systems properly evaluate all relevant tests rather than incorrectly skipping them.
