This is a feature patch in the ongoing `imap-send` authentication improvements series, adding PLAIN authentication support for the OpenSSL backend. The patch fills a gap where PLAIN auth (RFC 4616) was only available via libcurl, despite being commonly used with app passwords. 

The implementation follows the same pattern as other auth methods in the series, adding a new `AUTH_PLAIN` capability flag and implementing the base64 encoding scheme specified in RFC 4616. The code handles the standard PLAIN format of `\0user\0pass` with proper memory allocation and error checking. Documentation is updated to reflect the new supported method.

This is part of a well-reviewed series that has already addressed core authentication infrastructure, so the change fits naturally into the existing codebase. The patch appears technically sound, with proper RFC reference and consistent error handling patterns matching the surrounding code. As the fifth patch of ten, it builds on earlier authentication groundwork while leaving the newer folder management features (--list, --folder) for later in the series.
