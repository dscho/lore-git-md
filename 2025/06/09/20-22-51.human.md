This is a feature patch in the ongoing `imap-send` improvement series, adding a command-line option to specify the IMAP folder destination. 

The patch introduces a new `--folder` (or `-f`) option to `git imap-send`, allowing users to override the default folder configured in `imap.folder`. The implementation properly handles memory management by freeing any previous folder value before assigning the new one. Documentation updates clarify that the config value serves as a fallback when the command-line option isn't used, and fixes some minor formatting inconsistencies in the docs (switching quotes to backticks for command/field references).

This is part of a larger v18 series that has undergone extensive review, with this particular patch addressing a common workflow need - the ability to easily send patches to different folders without editing config files. The change is straightforward and well-contained, with proper attention to memory management and documentation. The series as a whole is in final polishing stages with all major technical issues resolved.
