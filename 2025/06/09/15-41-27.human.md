User experience improvement for `imap-send` credential prompts, part of a larger series adding OAuth2 support and folder management features. This patch makes the password prompt include the port number (e.g., `outlook.office365.com:993`) alongside the hostname, matching the behavior of `git send-email`. The change is minimal (a one-line modification to `server_fill_credential()`) but provides clearer context about which server/port combination is being authenticated against. The patch notes this is particularly useful when different ports might have different credentials. Since this is part of a well-reviewed series that's nearing completion, it appears ready for inclusion.
