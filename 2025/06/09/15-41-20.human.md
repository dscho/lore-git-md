Bugfix for a critical regression in `imap-send` that has made the command unusable since Git 2.46.0. The patch corrects a memory management issue introduced in commit 6d1f198f34 where configuration parsing was incorrectly NULLing out the `cfg->folder` field when processing unrelated IMAP settings like user, password, tunnel, and authmethod. This was causing the folder setting to be lost even when explicitly configured.

The fix is straightforward - it changes the `FREE_AND_NULL` calls to target the correct struct fields (`user`, `pass`, `tunnel`, and `auth_method` respectively) rather than incorrectly clearing `folder`. This restores the expected behavior where folder settings persist when other configuration values are set.

This is the first patch in a larger v17 series that adds OAuth2 support and other improvements to `imap-send`. The bug was likely unnoticed for some time because most users have switched to `git-send-email`, but this fix is important for anyone still relying on the IMAP functionality. The patch has already been reviewed and approved by Junio Hamano in earlier iterations of the series.
