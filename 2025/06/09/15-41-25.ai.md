This is a feature patch in the `imap-send` series, adding command-line folder specification capability. 

The patch introduces a new `--folder` (or `-f`) option to `git imap-send`, allowing users to override the default IMAP folder configured in `imap.folder`. The implementation follows the series' pattern of CLI/config precedence - command-line values take priority over configuration, with config serving as fallback. Documentation updates clearly explain this behavior in both the config and command man pages.

Key technical changes include adding an `opt_folder` static variable, extending the option parsing table with a new `OPT_STRING` entry for `--folder`, and modifying the main command flow to apply the override before connecting to the server. The patch maintains the existing memory management patterns, using `xstrdup` for the new string allocation and properly freeing the previous `server.folder` value when overriding.

This fits into the broader series' goal of improving `imap-send` usability and flexibility, particularly around folder management which has seen several enhancements including the new `--list` capability. The implementation is straightforward and consistent with the codebase's style, though it doesn't include specific tests for the new option (likely covered by the series' overall test strategy). The change addresses a clear use case where users frequently need different folders than their configured default, eliminating the need for temporary config edits.
