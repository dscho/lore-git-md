Git v2.50.0-rc2 release thread summary:

This thread announces the second release candidate for Git 2.50, containing 604 non-merge commits from 85 contributors (33 new). The release focuses on performance optimizations, particularly in ref handling (reftable) and object storage (MIDX bitmaps), while continuing long-term modernization efforts. Key technical changes include Patrick Steinhardt's reftable refactoring (172 commits), Taylor Blau's MIDX bitmap improvements (31 commits), and Elijah Newren's merge-ort consolidation (29 commits). User-facing additions: new `--combine-cruft-below-size` repack option, `git reflog drop` subcommand, configurable loose object batch sizes, and TCP keepalive for HTTP. The release also includes Windows/ARM64 fixes, reduced `the_repository` usage, and expanded test coverage including Meson build support. Randall Becker reports successful testing on the NonStop platform without TCL support, confirming basic functionality on this less common configuration. Backward compatibility is maintained throughout. Technical work spans refs.c, reftable/, object-file.c, and builtin/, showing progress on repository independence and build system modernization while addressing various bugfixes across subsystems.
