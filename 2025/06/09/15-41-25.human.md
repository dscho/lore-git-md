Feature patch adding command-line folder specification to `git imap-send`. This is part of a larger v17 series improving IMAP functionality, which has already addressed critical bugs and added OAuth2 support in earlier patches.

The patch introduces a new `--folder` (or `-f`) option to override the default IMAP folder configured in `imap.folder`. The documentation is updated to clarify that the config value serves as a fallback when the command-line option isn't used. Implementation is straightforward - the option value replaces the config value during initialization.

This appears well-executed with clear documentation updates and proper memory management (using `xstrdup` for the new value). The change addresses a real usability pain point for users who frequently need to send to different folders. As part of the mature v17 series that has undergone extensive review, this patch seems ready for inclusion.
