Feature patch adding PLAIN authentication support for OpenSSL backend in `imap-send`. This is part of the larger v16 series improving IMAP functionality, specifically addressing authentication methods.

The patch implements RFC 4616-compliant PLAIN authentication for the OpenSSL backend, which previously only supported LOGIN command. The implementation includes a new `plain_base64()` helper function that properly formats credentials according to the RFC (using NUL-delimited "user\0pass" format before base64), and a corresponding `auth_plain()` handler. The documentation is updated to reflect that PLAIN is now available for both curl and OpenSSL backends.

Key technical details:
- New `AUTH_PLAIN` capability flag added to enum
- `plain_base64()` handles the credential formatting and encoding
- `auth_plain()` manages the authentication flow
- Documentation updated to include PLAIN in the supported methods list
- Follows same pattern as other auth methods in the codebase

This fills a gap where PLAIN was only available via curl, despite being commonly used by email providers (especially with app passwords). The implementation is cleanly integrated with the existing authentication framework and maintains consistency with the other auth methods in the series.
