This is the second release candidate for Git 2.50, containing 604 commits from 85 contributors (including 33 new ones). The release brings several user-visible improvements, including a new `--combine-cruft-below-size` option for `git repack`, HTTP transport keepalive configuration, and a dedicated `git reflog drop` command. Under the hood, there are performance optimizations for ref handling and reftable operations, along with continued progress on reducing global state usage.

The technical work is led by Patrick Steinhardt (reftable refactoring), Taylor Blau (MIDX bitmaps), and Elijah Newren (merge-ort consolidation). The release also includes Windows/ARM64 compatibility fixes and ongoing test suite modernization, with particular attention to reducing Perl dependencies. The changes maintain backward compatibility while advancing Git's long-term goals around repository independence and build system improvements.
