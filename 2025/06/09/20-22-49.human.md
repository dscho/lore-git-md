Feature patch adding OAuth2.0 authentication support to `git imap-send`. This is part of a larger v18 series that modernizes IMAP functionality, with this specific patch introducing two OAuth2.0 mechanisms: the standard OAUTHBEARER (RFC5801/RFC7628) and Google's proprietary XOAUTH2.

The implementation adds new authentication handlers and base64 encoding utilities for both protocols, with support for both OpenSSL and libcurl backends. The documentation is updated to explain OAuth2.0 usage, including Gmail and Outlook-specific configurations. Notably, this provides a more secure alternative to app-specific passwords for services like Gmail that require multi-factor authentication.

The patch appears well-constructed with thorough documentation updates and proper error handling. It follows the pattern established by existing authentication methods in the codebase while adding the necessary protocol-specific formatting for OAuth2.0 tokens. The changes are focused and maintainable, with clear separation between the two OAuth2.0 variants.
