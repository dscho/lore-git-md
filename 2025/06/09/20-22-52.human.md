This is a feature patch in the ongoing `imap-send` improvement series, adding a new `--list` option to show available IMAP folders. The patch addresses a common pain point where users struggle to determine the correct folder names for different IMAP providers (like Gmail's "[Gmail]/Trash" vs Outlook's "Deleted").

The implementation provides RFC6154-compliant folder listing for both OpenSSL and libcurl backends, with output showing folder names and their attributes (like "\HasNoChildren"). The documentation is updated to mention this new option, particularly helpful for troubleshooting folder naming issues. The code handles both backends cleanly, with libcurl following their documented example implementation.
