Feature patch adding OAuth2.0 authentication support to `imap-send`. This is part of a larger series (v16 04/10) that has been extensively reviewed and is nearing final merge.

The patch implements both RFC-standard OAUTHBEARER and Google-proprietary XOAUTH2 authentication methods for the IMAP protocol. It adds new helper functions `oauthbearer_base64()` and `xoauth2_base64()` to handle the authentication flow, with support for both OpenSSL and libcurl backends. The documentation is updated to explain how to use OAuth2.0 with both Gmail and Outlook, including notes about access tokens and credential helpers.

The implementation appears thorough, with proper error handling and base64 encoding/decoding. The patch maintains backward compatibility while adding the new authentication methods. Given this is part of a well-reviewed series that has maintainer approval for the core changes, this particular patch looks solid and ready for inclusion.
