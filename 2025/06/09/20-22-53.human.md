This is a user experience improvement patch for `imap-send`, part of a larger series adding OAuth2 support and fixing authentication issues. The change makes credential prompts more informative by including the port number alongside the hostname (e.g., showing "outlook.office365.com:993" instead of just the hostname).

The one-line change modifies `server_fill_credential()` to format the host field with both host and port using `xstrfmt()`. This brings `imap-send` in line with `git send-email`'s behavior and helps users distinguish between different server instances running on non-standard ports. The patch is straightforward and appears well-contained, though it's worth noting this is a refinement of an earlier implementation - the thread context shows port display logic was already cleaned up in response to Junio Hamano's review.
