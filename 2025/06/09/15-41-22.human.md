Bugfix for the `imap-send` authentication system, part of a larger series improving IMAP functionality. This patch specifically addresses CRAM-MD5 authentication when OpenSSL is not available.

The code previously would attempt CRAM-MD5 authentication and die with an error if OpenSSL wasn't present. The new version checks for OpenSSL availability first and provides a more graceful failure message if it's missing. The change centralizes authentication logic into a new `try_auth_method()` helper function that handles both capability checking and OpenSSL availability.

This is one of several authentication-related fixes in the series, which also includes OAuth2 support and other improvements. The patch appears well-contained and focused, with clean error handling that matches the pattern established elsewhere in the codebase. Since CRAM-MD5 is a legacy authentication method, this change primarily improves the user experience for those still using it rather than introducing new functionality.
