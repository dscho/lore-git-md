This is a feature patch in the ongoing `imap-send` series, adding a command-line `--folder` option to override the default IMAP destination folder. The patch is now in its 16th revision and has been reviewed by Junio Hamano, who provides final polishing suggestions.

The change allows users to specify an IMAP folder directly via `-f` or `--folder` when running `git imap-send`, with the command-line value taking precedence over the configured `imap.folder` setting. The implementation properly handles memory management by freeing the previous folder value before assigning the new one. Documentation updates clarify the precedence rules and provide usage examples.
