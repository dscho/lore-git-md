This is a test infrastructure patch addressing macOS compatibility. Ramsay Jones noticed that a recent commit (d3d8c601fd) added macOS support but missed setting several standard prerequisites (POSIXPERM, BSLASHPSPEC, EXECKEEPSPID) that are defined for other platforms. This causes tests that should run on macOS to be incorrectly skipped.

The patch is marked RFC because the author doesn't have access to a macOS system to verify the fix. They suggest this could potentially be squashed into the original commit when the 'next' branch is rebased. The change itself is straightforward - adding three prerequisite definitions to the Darwin case in test-lib.sh.

This appears to be a legitimate oversight in the original commit, and the fix seems reasonable, though actual macOS testing would be needed to confirm. The patch is small and focused, though the RFC status means it may need verification from someone with macOS access before merging.
