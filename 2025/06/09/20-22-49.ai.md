This is a feature patch adding OAuth2.0 authentication support to `imap-send`, part of a larger series (v18 04/10) that has undergone extensive review. The patch implements both RFC-standard OAUTHBEARER and Google-proprietary XOAUTH2 mechanisms for both OpenSSL and libcurl backends.

Key technical additions include:
- New `AUTH_OAUTHBEARER` and `AUTH_XOAUTH2` capability flags in `imap-send.c`
- Helper functions `oauthbearer_base64()` (RFC5801/RFC7628 compliant) and `xoauth2_base64()` (Google format) for proper token encoding
- Authentication dispatch in `imap_open_store()` and credential handling in `setup_curl()`
- Documentation updates explaining OAuth2 usage for Gmail and Outlook, including credential helper recommendations
- The implementation handles both OpenSSL and libcurl backends, with libcurl using `CURLOPT_XOAUTH2_BEARER` for both mechanisms
- The patch maintains backward compatibility while adding the new auth methods to the supported configuration options

The thread context shows this is a mature patch in a well-reviewed series that has addressed all technical concerns, including earlier configuration parser regressions and memory leaks. The OAuth2 support is particularly relevant for modern email providers like Gmail and Outlook that increasingly require token-based authentication.
