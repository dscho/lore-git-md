This is a release announcement for Git v2.50.0-rc2, marking the second release candidate in the 2.50 development cycle. The release contains 604 non-merge commits from 85 contributors (33 new) since v2.49.0.

The announcement highlights several notable user-facing changes including:
- New `--combine-cruft-below-size` option for `git repack`
- TCP keepalive configuration for HTTP transports
- `git reflog drop` subcommand for discarding reflog data
- Configurable batch size for loose object coalescing in maintenance
- Machine-parsable NUL-delimited output format for `git rev-list`
- Performance improvements in refname availability checks and reftable operations
- Continued reduction of `the_repository` global usage
- Multiple fixes for Windows/ARM64 compatibility
- Expanded test coverage and CI improvements, including better Meson build support

The release also includes numerous bugfixes across various subsystems, particularly around ref handling, merge/ort behavior, and object storage. Several documentation updates and code cleanups are present, along with ongoing efforts to reduce Perl dependencies in the test suite.
