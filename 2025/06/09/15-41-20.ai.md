Bugfix for a critical regression in `imap-send` configuration parsing. This patch corrects a bug introduced in commit 6d1f198f34 where the wrong struct field (`cfg->folder`) was being NULLed out when processing unrelated configuration options (`imap.user`, `imap.pass`, `imap.tunnel`, and `imap.authmethod`). The incorrect cleanup caused `git-imap-send` to become completely unusable since Git 2.46.0.

The fix properly NULLs out the correct struct fields for each configuration option, matching the intended behavior where each config value should only affect its corresponding field. The patch is minimal (4 line changes) and focused, directly addressing the regression by fixing the field-specific cleanup logic in `git_imap_config()`.

This is the first patch in a larger v17 series that introduces OAuth2.0 support and folder management features for `imap-send`. The thread context shows this regression fix has already been reviewed and approved by multiple maintainers, with the series in its final stages before potential merging. The bug's long unnoticed existence is attributed to `git-send-email` being a more commonly used alternative.
