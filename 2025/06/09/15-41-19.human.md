This is a feature and bugfix series for `imap-send`, now in its 17th iteration, focused on making the command usable again and adding OAuth2.0 support. The series has undergone extensive review and appears ready for merging, with v17 being a simple rebase on master to resolve a minor conflict.

The key improvements in this series include:

1. Critical bugfixes that restore basic functionality, including fixing a regression where `cfg->folder` was incorrectly set to NULL and plugging memory leaks in authentication paths.

2. Comprehensive authentication support with new OAuth2.0 (both OAUTHBEARER and XOAUTH2) and PLAIN authentication methods, implemented for both OpenSSL and libcurl backends. The OAuth2.0 support is particularly notable as it enables modern authentication with services like Gmail.

3. New user-facing features like the `--folder` option to override the destination mailbox at runtime and `--list` to show available IMAP folders, making the tool more flexible for different workflows.

4. UI polish including better credential prompts (now showing port numbers) and progress output that displays the destination folder name during sending.

The series has been thoroughly reviewed by multiple Git maintainers, with all substantive feedback addressed. The v17 changes are minimal (just a rebase), indicating this is likely the final version before merging. The combination of critical bugfixes and useful new features makes this an important improvement to `imap-send` that should benefit users needing to send patches via IMAP.
