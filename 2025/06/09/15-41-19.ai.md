This is version 17 of a feature and bugfix series for `imap-send`, now rebased on master. The series has undergone extensive review and iteration, with all substantive feedback addressed in previous versions. The v17 changes are purely mechanical - a rebase to resolve a merge conflict with commit 30325e2, with no functional changes from v16.

The series provides comprehensive improvements to `imap-send`:
1. Critical bugfixes for configuration parsing regression (since Git 2.46.0) and memory leaks
2. New OAuth2.0 authentication support (both RFC-standard OAUTHBEARER and Google's XOAUTH2)
3. Added PLAIN authentication method for OpenSSL backend
4. New folder management features (`--folder` command-line override and `--list` to show available folders)
5. User experience improvements like showing destination folder during send and including port in credential prompts

The implementation spans authentication handlers, IMAP protocol handling, and configuration management. The series has received thorough review from multiple Git maintainers, with Junio Hamano indicating the early parts are already approved and only final review needed on the last few feature patches. The v17 rebase suggests this is likely the final version before potential merging.
