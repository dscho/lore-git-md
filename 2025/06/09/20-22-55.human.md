- Ensures protocol terms like "IMAP" and status codes like "OK" appear in uppercase
- Fixes an authentication error message to show the auth method rather than hostname
- Tweaks several message wordings for clarity (e.g., "no messages found to send vs "no messages to send")

The patch follows through on earlier review feedback about message formatting, bringing the last few stragglers into alignment.
