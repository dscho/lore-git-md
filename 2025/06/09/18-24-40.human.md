This is a test infrastructure patch addressing macOS compatibility, building on an earlier fix that missed some test prerequisites. The patch adds three standard test prerequisites (POSIXPERM, BSLASHPSPEC, and EXECKEEPSPID) to the Darwin/macOS case block in `t/test-lib.sh`, which were accidentally omitted in a previous commit (d3d8c601fd).

Ramsay Jones identified that without these prerequisites, macOS systems were incorrectly skipping tests they should be running. The patch is marked RFC since neither Ramsay nor Junio Hamano have macOS access to verify the fix, but Junio considers it a safe change that restores the pre-bug behavior. He's queuing it on the ps/meson-tap-parse topic branch.

The change is straightforward - just three lines adding the missing prerequisites to match what other platforms get by default.
