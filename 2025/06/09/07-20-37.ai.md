This is a feature patch in the ongoing `imap-send` series, adding command-line option support for specifying the target IMAP folder. The patch introduces a new `--folder`/`-f` option that overrides the configuration-specified folder, addressing a common workflow where users need to send to different folders than their default.

The implementation adds the option to both documentation and code, with the command-line value taking precedence over the config. The docs clarify that the config value remains required as a fallback when the option isn't used. The code change is straightforward - it parses the new option and, if present, replaces the server.folder value after config loading.

This builds on the series' broader goal of making `imap-send` more flexible and user-friendly. The patch follows the established pattern of the series, with clear documentation updates and proper memory management (freeing the old folder string before replacing it). As part of v16's final review items, this completes one of the three remaining features needing attention before merge.
