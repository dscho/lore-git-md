This is a feature patch in the ongoing `imap-send` improvement series, adding folder enumeration capability via a new `--list` option. The patch implements RFC6154-compliant IMAP folder listing for both OpenSSL and libcurl backends, showing users the exact folder naming conventions used by their IMAP server (which vary significantly between providers like Gmail and Outlook).

The implementation adds a new `list_folders` flag and corresponding CLI option, with output showing folder hierarchies and attributes (like `\Drafts` or `\Trash` flags). For OpenSSL, it uses the IMAP LIST command directly, while the libcurl version adapts the documented example from curl's documentation. The patch includes documentation updates explaining the new option and its use case for discovering server-specific folder names.

Technical changes include:
- New `list_imap_folders()` and `curl_list_imap_folders()` functions
- Modified command-line parsing to accept `--list`
- Adjusted buffer handling to show LIST responses when in list mode
- Conditional logic in curl setup to skip folder-specific operations when listing
- Documentation updates showing example output and usage guidance

This builds on the series' earlier authentication and configuration fixes, providing the first user-facing feature for exploring IMAP server capabilities. The implementation appears thorough, handling both backends consistently and including the expected documentation updates. As one of the final patches in the nearly-ready series, it completes the folder management functionality alongside the previously added `--folder` option.
