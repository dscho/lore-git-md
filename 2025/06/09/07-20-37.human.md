This is a feature patch in the ongoing `imap-send` improvement series, adding a command-line option to override the default IMAP folder configuration.

The patch introduces a new `--folder` (or `-f`) option to `git imap-send`, allowing users to specify the destination folder at runtime rather than relying solely on the `imap.folder` config setting. This addresses a common workflow where users might want to send patches to different folders without constantly modifying their configuration.

The implementation is straightforward, adding the option parsing logic and updating the server configuration when the option is provided. Documentation is updated in both the config and command manual pages to explain the new option and its relationship with the existing config setting. The changes are well-contained, touching only the expected files (command-line parsing, documentation, and the actual folder setting logic).

This is part of a larger series that has already addressed critical bugs and added significant new functionality to `imap-send`. The patch appears cleanly implemented with appropriate documentation updates, and since it builds on the already-reviewed foundation of the series, it seems unlikely to be controversial. The change fills a clear usability gap for users who work with multiple IMAP folders.
