This is Junio Hamano's regular "What's cooking" status update for the Git development cycle. It provides a comprehensive overview of the current state of patches in the Git project's integration branches.

The email announces that Git 2.50 has been tagged and outlines the schedule for the upcoming 2.51 release cycle, which will be shorter than usual (8 weeks) due to the typical summer slowdown. Key dates include RC releases in early August and final release on August 18.

The bulk of the email categorizes patches into several sections:

1. **Graduated to 'master'**: Three patches that have been merged, including build fixes for sed portability, Coverity CI fixes for Windows, and a reversion of a problematic bswap.h change.

2. **New Topics**: One new patch fixing a memory leak in mailinfo.

3. **Cooking**: Over 30 patches in various states of review and testing, covering a wide range of areas:
   - Bugfixes (rebase instruction format, memory leaks)
   - Performance improvements (batched ref updates)
   - Documentation updates
   - New features (compact merge summaries, stash import/export)
   - Code cleanups (the_repository removal, object store API)
   - Test improvements (reftable unit tests, TAP parsing)

Several notable patches include:
- A resurrection of git-imap-send with OAuth2 support
- Path-based delta compression for pack-objects
- Deprecation plans for git-whatchanged
- Various memory leak fixes
- Solaris and FreeBSD compatibility updates

The email also lists some discarded patches that caused issues, like a bswap.h change that broke Windows builds.

This status update shows active development across many areas of Git, with particular focus on performance, memory management, and modernization of the codebase. The volume of patches suggests a healthy development pace despite the approaching summer period.
