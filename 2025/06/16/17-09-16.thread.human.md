Git v2.50.0 has been released, marking a significant update with contributions from 98 developers (including 35 first-time contributors). This release introduces several user-facing improvements like enhanced `git repack` functionality with `--combine-cruft-below-size`, a new `git reflog drop` command, and better SMTP compatibility in `git send-email`. 

Under the hood, the release continues major architectural efforts including reducing reliance on the `the_repository` global variable, optimizing the reftable backend, and deprecating the old merge-recursive strategy. Performance improvements touch areas like refname checking and bundle handling, while build system enhancements include Meson support and CI pipeline upgrades. 

The release addresses numerous bugs across subsystems, particularly in cruft pack handling, merge rename detection, Windows-specific issues, and sparse-index performance. The detailed changelog documents over 50 merged fixes since v2.49.0, showcasing the project's ongoing maintenance work alongside feature development.
