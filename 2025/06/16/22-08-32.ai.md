This is a bugfix for the build system standardization series, specifically the Meson build configuration. The email reports a regression in how `GIT_EXEC_PATH` is set when `libexecdir` is customized, causing Git to fail finding helper tools during Meson builds.

The issue stems from v2 patch 4/5 of the series, where the path construction for `git_exec_path` incorrectly drops the `git-core` component when a non-default `libexecdir` is specified. The proposed fix maintains the `git-core` subdirectory in the path while still respecting custom `libexecdir` locations, matching the intended behavior where Git helpers should be found in `$libexecdir/git-core`.

This appears to be a straightforward correction to a clear regression, though the impact is limited to Meson builds with customized libexec directories. The fix aligns with the series' goal of consistent path handling across build systems. Since this is a follow-up to an already-merged series, it would need to be evaluated whether this warrants a follow-up patch or if it was perhaps fixed in later iterations (the thread summary mentions this went through v4 before merging).
