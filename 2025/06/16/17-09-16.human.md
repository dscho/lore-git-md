This is the official release announcement for Git v2.50.0, marking a new stable version with 621 commits from 98 contributors (35 new). The release highlights several user-facing improvements and internal optimizations.

Key user-visible changes include new features like `git reflog drop`, incremental multi-pack index updates, improved `git diff --minimal` behavior, and better `send-email` compatibility with Outlook. The release also brings configuration options for TCP keepalive in HTTP transports and cruft pack handling in `git repack`. Several commands (`git rev-list`, `git blame`, `git cat-file`) gained new output formats or filtering capabilities.

Under the hood, the release continues the ongoing architectural work with more repository instance parameterization, reftable API improvements, and removal of the legacy merge-recursive backend. Performance optimizations touch ref advertisement logic, bundle handling, and packed-refs access. The build system sees Meson integration improvements and expanded platform support.

The announcement notes 60+ bugfixes backported to maintenance branches, addressing issues ranging from ref handling corner cases to Windows-specific problems and CI/CD pipeline reliability. The release appears well-tested with extensive fixes for edge cases across platforms and thorough documentation updates.
