This is a test modernization patch review, where Eric Sunshine provides feedback on Rodrigo Michelassi's attempt to update `t2400-worktree-add.sh` to use Git's test helper functions. The original patch mechanically replaced shell `test` commands with their `test_path_*` equivalents, but Eric points out several issues with this approach.

Eric explains that the test helper functions are designed to provide better diagnostics when assertions fail, but they're being misapplied in this case. For negative assertions (checking that paths *don't* exist), the `test_path_is_*` functions will emit confusing error messages even when the test is passing. He suggests using `test_path_is_missing` instead for these cases.

The review also includes some stylistic suggestions for the commit message and signature block formatting. Eric recommends:
1. Adding the test number prefix to the subject line
2. Better explaining the advantages of the test helpers
3. Properly wrapping the message at 72 columns
4. Adjusting the order of the Signed-off-by trailers

This is a focused review of a test modernization effort, catching subtle but important misapplications of the test helper functions while maintaining the original test intentions. The feedback shows how these modernization changes require careful consideration of the test's actual assertions rather than just mechanical substitutions.
