[Git for Windows 2.50.0 release announcement from Johannes Schindelin. Updates core Git to v2.50.0 alongside MinTTY 3.7.8, OpenSSH 10.0.P1, cURL 8.14.1, and MSYS2/Cygwin 3.6.3. Fixes three Windows-specific regressions: ReFS file writing on Windows Server 2022, long branch fetches with core.longPaths enabled, and installer editor test file writability. Provides SHA-256 checksums for 11 distribution formats (64/32-bit x86/ARM64, portable, MinGit variants, tarballs). Announcement format with no discussion solicited.]
