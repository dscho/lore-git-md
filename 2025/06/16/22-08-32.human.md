This is a bugfix for the build system standardization series, specifically addressing an issue with Meson builds when a custom `libexecdir` is set. The patch corrects how `GIT_EXEC_PATH` is constructed in `meson.build` to properly locate Git's helper tools.

The reporter (irecca.kun) identifies that the current implementation breaks Meson builds when `libexecdir` is customized, as it fails to append the `git-core` subdirectory. The proposed fix modifies the path construction to always include `git-core` when a non-default `libexecdir` is specified.

This appears to be a straightforward correction to a regression introduced in the build system standardization work. The change aligns with the series' goal of consistent path handling across build systems while maintaining compatibility with custom installation layouts. The fix is minimal and focused, though it would benefit from verification on systems with non-standard `libexecdir` configurations.
