This is the second patch in a finalized 5-part series enhancing the promisor-remote protocol with configurable validation of remote attributes. The series is now ready for merging after addressing all review feedback.

The patch introduces server-side advertisement of additional remote attributes beyond just name and URL. A new `promisor.sendFields` config option lets servers specify which extra fields to include (currently supporting `partialCloneFilter` and `token`). The filter field helps clients verify compatibility with the remote's partial clone settings, while the token field can provide authentication credentials.

Implementation includes thorough documentation updates, case-insensitive field handling, URL encoding preservation, and test coverage for various delimiter formats. The changes maintain backward compatibility while extending the protocol's capabilities. The patch follows Git's established patterns for protocol-v2 and includes comprehensive BNF notation in the documentation.
