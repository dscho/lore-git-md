This is the final patch in a 4-part series improving Git's clang-format integration, specifically adding meson build support. The patch adds a 'style' target to meson.build that mimics the existing Makefile functionality for running `git clang-format` on changed files rather than the entire codebase. 

The implementation checks for clang-format availability and creates a run target that executes the formatter with the same parameters as the Makefile version (using the project's .clang-format file, showing diffs, and limiting to C/h files). This maintains consistency between build systems while keeping the focused formatting behavior that only checks modified code.

The change is straightforward and well-contained, touching only meson.build. It completes the series' goal of making clang-format integration more robust across Git's build systems. The patch appears ready for review, though some might question whether the parameters should be configurable rather than hardcoded.
