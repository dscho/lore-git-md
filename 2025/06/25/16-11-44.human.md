This is a bugfix patch in the ongoing Git daemon signal handling series, specifically addressing how `SA_RESTART` affects `poll()` behavior when reaping zombie child processes. The patch introduces a new `set_sa_restart()` helper function that dynamically toggles the `SA_RESTART` flag around `poll()` calls in the daemon's service loop.

The core issue is that when `SA_RESTART` is set (as it is by default on some platforms), `poll()` may not properly return `EINTR` when interrupted by signals, preventing the daemon from timely cleanup of zombie child processes. The solution explicitly disables `SA_RESTART` around these critical `poll()` operations while maintaining it elsewhere for normal operation.
