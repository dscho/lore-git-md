This is a refactoring patch that moves a clang-format style rule from CI-specific configuration into the main project configuration. 

The patch promotes the 'RemoveBracesLLVM' rule, which removes optional braces from simple single-statement control flow bodies (if/else/for/while), from being an experimental CI-only check to being part of the main .clang-format configuration. The rule was originally added to CI in July 2024 and has been running without issues since then.

The change removes 17 lines of CI-specific configuration that temporarily applied this rule during style checks, while adding 6 lines to the main .clang-format file to make it permanent. The commit message explains this was done because the rule has proven stable in CI testing and the team wants to apply it consistently rather than just in CI.

This appears to be a straightforward, well-justified change that follows the project's typical pattern of testing style changes in CI before making them project-wide. The patch is part of a 4-part series (this is patch 3/4) about making clang-format usage more robust.
