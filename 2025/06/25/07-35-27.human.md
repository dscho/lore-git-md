- The empty `child_handler()` remains but is now properly marked with `MAYBE_UNUSED`
- Platform-specific behavior is preserved (particularly for AIX where rearming the handler could cause crashes)
- The implementation carefully maintains the existing behavior where system calls should be interrupted upon signal receipt
