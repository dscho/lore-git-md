This is a bugfix series addressing signal handling in the Git daemon, particularly around zombie process cleanup on OpenBSD and crashes on AIX. It's the second version of a patch set that has already seen significant discussion between Carlo Marcelo Arenas Belón and Junio C Hamano.

The series modernizes signal handling by moving from `signal()` to `sigaction()` and properly handling `SA_RESTART` flags during `poll()` operations. The changes are carefully staged across three commits: first consolidating `SA_RESTART` definitions, then updating the signal handler installation, and finally ensuring proper EINTR behavior during polling.

The implementation now includes platform-specific handling through a new `USE_NON_POSIX_SIGNAL` build flag, with special consideration for Windows, NonStop, QNX, and MINGW systems. The empty signal handler that was previously questioned has been justified as necessary for correct EINTR behavior on some platforms, supported by historical context from Chris Torek about Unix signal evolution.

While the technical approach has been validated through discussion, there remains some debate about code organization and naming, particularly around balancing POSIX compliance with implementation cleanliness. The series appears well-researched with thorough cross-platform testing and addresses real issues in the daemon's signal handling behavior.
