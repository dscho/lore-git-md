This is a refactoring patch that moves a clang-format style rule from CI-specific configuration to the main project configuration. The patch promotes the 'RemoveBracesLLVM' rule, which removes optional braces from simple single-statement control flow bodies (if/else/for/while) while keeping them for multi-statement cases, from being an experimental CI-only check to a standard project-wide formatting rule.

The change follows a successful trial period where the rule was tested in CI since July 2024 (commit 1b8f306612) without reported issues. The patch removes the temporary CI-specific implementation that created a modified config file at runtime and instead adds the rule directly to `.clang-format`. The CI script is simplified to use the main config file directly.

Key technical details:
- Adds `RemoveBracesLLVM: true` to `.clang-format`
- Removes 17 lines from `ci/run-style-check.sh` that previously generated a temporary config
- Keeps the same formatting behavior but makes it apply to all developers rather than just CI
- References LLVM coding style as the inspiration for this brace-removal approach

The change appears straightforward and well-justified, with the commit message clearly explaining the transition from experimental to standard configuration. The patch maintains the same formatting behavior while simplifying the implementation.
