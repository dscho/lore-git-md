This is the final patch in a 4-part series improving Git's clang-format integration, specifically adding meson build system support. The patch introduces a 'style' target to meson.build that mirrors the existing Makefile functionality for running `git clang-format` with specific parameters.

The implementation adds a new run_target that invokes `git clang-format` with the same options used in the Makefile: enforcing the style defined in .clang-format, showing diffs rather than modifying files directly, and limiting formatting to .c and .h files. The target is only created if clang-format is found on the system, maintaining compatibility with environments lacking the tool.

This completes the series' goal of making clang-format behavior consistent across build systems while reducing false positives. The change is straightforward and maintains parity with existing functionality, though it doesn't address the broader question of whether to make style checks required in CI (which the cover letter noted as future work). The patch touches only meson.build and follows the same careful approach seen in the rest of the series.
