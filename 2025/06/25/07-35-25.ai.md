This is a bugfix series addressing signal handling in the Git daemon, specifically targeting zombie process cleanup on OpenBSD and crashes on AIX. The v2 series refines the approach from v1 by removing most references to the deprecated `siginterrupt()` function in favor of a more portable `sigaction()`-based solution.

The key technical changes in this version include:
1. Introducing a `USE_NON_POSIX_SIGNAL` build flag to track systems without proper SA_RESTART support
2. Modernizing signal handler installation to use `sigaction()` where available
3. Explicitly controlling SA_RESTART behavior around `poll()` operations to ensure proper EINTR handling

The series shows careful attention to platform compatibility, with specific handling for Windows, NonStop, QNX, and MINGW systems. The implementation now properly justifies the previously questioned empty signal handler as necessary for correct EINTR behavior on some platforms.

The changes are well-structured across multiple commits that:
- Centralize SA_RESTART definitions
- Abstract signal handling setup
- Add runtime control of SA_RESTART during poll()

The series builds on previous discussion that established the technical necessity of this approach, with v2 focusing on implementation refinement by reducing conditional compilation and improving naming. The changes touch core daemon functionality, signal handling infrastructure, and build system configuration across multiple files.
