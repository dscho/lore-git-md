This is the final patch in a v4 series improving symbolic port name handling in Git's credential and email subsystems. The patch focuses on better support for symbolic port names (like "smtps") in netrc files, particularly for use with `git-send-email`.

The key changes are:
1. Modifies `git-credential-netrc` to properly handle symbolic port names by converting them to numeric values using a new `port_num` helper function
2. Adds port validation to `git-send-email` to ensure SMTP server ports are valid (either numeric or resolvable symbolic names)
3. Updates tests to verify the new behavior, including a test for invalid port handling

The patch builds on previous work in the series that added core port resolution functionality. It solves a specific pain point where symbolic port names in netrc files (like those used by Emacs) were being incorrectly treated as protocols rather than ports. The implementation looks thorough, with changes to both the credential helper and send-email components, plus corresponding test coverage.
