Performance optimization introducing a new `--stdin-packs=follow` mode for pack-objects, part of a series improving MIDX and cruft pack handling during repacking.

This patch adds a new mode that changes how pack-objects treats objects from packs not explicitly listed in its input. When using `--stdin-packs=follow`, the command will include objects from unlisted packs if they are (1) reachable from the included packs and (2) not in any excluded packs. This is particularly useful for handling cruft packs, where objects may become reachable later.

The change enables geometric repacking to maintain reachability guarantees while avoiding the need to always include cruft packs in the MIDX. The patch includes thorough tests verifying the new behavior with various pack configurations and edge cases (missing blobs, trees, and commits).

This is patch 8/9 in a well-reviewed series that has already addressed all edge cases and received approval from key maintainers. The implementation builds on earlier refactoring in the series and maintains the careful approach seen throughout. Production testing shows measurable performance improvements (5-20% faster repacks).
