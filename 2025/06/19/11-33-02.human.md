This is a platform compatibility note on the final patch of Taylor Blau's performance optimization series for MIDX and cruft pack interaction. Carlo Arenas points out that the test script uses `grep -o`, which isn't POSIX-compliant and would fail on some platforms like AIX. He suggests replacing it with a more portable `sed` command that should achieve the same result.

The patch being discussed is the 9th in a series that introduces configurable way to exclude cruft packs from MIDX files during repacking. While the core functionality has already been reviewed and approved, this is a minor but important portability fix for the test infrastructure. The suggested change doesn't affect the main feature but ensures the tests will run correctly across all supported platforms.

This kind of platform-specific feedback is valuable during the final review stages, especially for test code that needs to run everywhere. The series is otherwise complete and production-validated, with Elijah Newren having given final approval. Taylor will likely want to incorporate this suggestion before the patches are merged.
