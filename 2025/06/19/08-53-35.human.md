This is a documentation/UX improvement patch for `git imap-send`. Jörg Thalheim addresses confusing error messages when required IMAP configuration is missing. The current messages vaguely refer to "no imap store" or "no imap host" without explaining what configuration is needed or how to set it.

The patch improves two error cases: when the target folder is missing (now suggesting `git config imap.folder`) and when the host is missing (suggesting `git config imap.host`). Each now includes both the exact configuration command needed and an example value, making it much clearer for users how to resolve the issue.

The changes are straightforward - just updating error messages in `imap-send.c` to be more helpful - and the commit message clearly explains the motivation. This seems like a clear quality-of-life improvement for anyone using `git imap-send`, which is admittedly a niche feature but one where good error messages are particularly valuable since IMAP configuration can be tricky.
