This is a platform compatibility fix for the cruft pack/MIDX repacking series. Carlo Arenas points out that the test script in patch 9/9 uses `grep -o`, which isn't POSIX-compliant and fails on some platforms like AIX. He provides a portable alternative using `sed` that accomplishes the same task of extracting pack filenames.

The change is minimal (a one-line replacement in t7704-repack-cruft.sh) but important for ensuring the test suite works across all supported systems. This comes as a follow-up to Taylor Blau's performance optimization series that was otherwise ready for merging, with Elijah Newren having given final approval. The fix demonstrates good attention to portability concerns that might not be caught in initial development environments.
