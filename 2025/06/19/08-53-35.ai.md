This is a documentation/UX improvement patch for the `imap-send` command. The patch focuses on making configuration error messages more helpful by clearly stating what's missing and providing concrete examples of how to fix the issues.

The changes target two specific error cases in `imap-send.c`: when the IMAP folder isn't specified and when the IMAP host is missing. Previously, these errors gave minimal information - just stating that the configuration was missing. The new messages now explicitly name the missing configuration keys (`imap.folder` and `imap.host`) and show example `git config` commands to set them, including sample values that would work in typical setups.

The patch is straightforward and well-scoped, touching only the error message output while leaving the underlying functionality unchanged. The commit message clearly explains the motivation (confusing error messages) and the solution approach (adding specific guidance). This should help users more quickly diagnose and fix configuration problems when using `imap-send`. The changes are minimal (6 lines added, 2 removed) and focused purely on improving user experience.
