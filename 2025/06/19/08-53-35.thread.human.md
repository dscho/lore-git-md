This thread introduces a documentation and user experience improvement for the `imap-send` command, focusing on making configuration error messages more actionable. The patch addresses two specific cases where users might encounter unclear errors: when the IMAP folder or host configuration is missing. 

Previously, these errors would simply state that the configuration was missing, leaving users to figure out what exactly needed to be set. The new version explicitly names the missing configuration keys (`imap.folder` and `imap.host`) and provides example `git config` commands with sample values that would work in typical setups. For instance, it now suggests concrete values like `git config imap.host imap.example.com` rather than just saying the host is missing.

The changes are minimal (6 lines added, 2 removed) and well-scoped, touching only the error message output while leaving the underlying functionality intact. The commit message clearly explains the motivation behind the changes - to reduce confusion when users encounter these configuration errors - and demonstrates the improved messaging. This should help users more quickly diagnose and fix configuration problems when setting up `imap-send`.
