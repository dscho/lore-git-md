This thread focuses on improving error messages in `git imap-send`, particularly for missing `imap.folder` and `imap.host` configurations. Aditya Garg originally proposed adding clearer error messages with example `git config` commands. While Junio Hamano acknowledged the UX improvement, he raised concerns that the underlying IMAP functionality might be broken, referencing an in-progress fix series.

Garg has since clarified that reports of broken functionality may come from testing unreleased branches, and maintains that the error message improvements are valuable regardless - users currently just see an unhelpful "no imap store specified" error. The discussion has evolved to consider both the immediate UX fix (now proposed to use Git's `advise()` API instead of direct `fprintf`) and the broader IMAP implementation issues. While the error message patch still needs review and may require rebasing, it represents a clear standalone improvement even as work continues on the deeper IMAP functionality problems Junio referenced.
