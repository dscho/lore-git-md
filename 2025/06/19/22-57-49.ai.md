This is a feature patch in the `git repo-info` GSoC series, adding support for retrieving the repository's reference storage format (files vs reftable). The patch implements the `references.format` field, which exposes the same information as `git rev-parse --show-ref-format` but through the new structured output system.

The implementation adds:
1. A new `CATEGORY_REFERENCES` category and `FIELD_REFERENCES_FORMAT` field in the categorization system
2. Core logic to query `repo->ref_storage_format` and convert it to a string via `ref_storage_format_to_name()`
3. Output handling for both JSON (nested under "references" object) and plaintext (key=value) formats
4. Comprehensive test cases verifying behavior for both files and reftable formats
5. Default field behavior when no specific fields are requested

The patch maintains the series' architectural approach with clean separation between format handling and field implementation. Test coverage is thorough, including verification of the default field output count. The implementation connects to the repository's ref storage backend while fitting into the existing `repo_info` struct and command flow.

This represents meaningful progress in the command's metadata capabilities, though documentation of the new field remains outstanding (a known gap in the series). The changes are well-contained and follow the established patterns from earlier patches.
