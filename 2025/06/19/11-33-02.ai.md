This is a platform compatibility note on the final patch of Taylor Blau's performance optimization series for MIDX and cruft pack interaction. Carlo Arenas points out a portability issue in the test script for patch 9/9, which introduces the final configurable behavior for cruft pack inclusion in MIDX.

The issue concerns the use of `grep -o` in the test_expect_success 'repack --write-midx includes cruft when necessary' block, which isn't POSIX-compliant and would fail on platforms like AIX. Carlo suggests replacing it with a more portable `sed` command that should achieve the same effect of extracting pack filenames from the input.

This is a minor but important technical correction to ensure the test suite works across all supported platforms. The suggestion comes late in the thread after the series has already received final approval from Elijah Newren, so it may require a follow-up fix or could be addressed during integration. The rest of the patch's functionality (the new repack.midxMustContainCruft config and its test coverage) remains unaffected by this observation.
