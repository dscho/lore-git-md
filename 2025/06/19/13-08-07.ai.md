This is a platform compatibility fix for the ongoing MIDX/cruft pack optimization series. Carlo Arenas identifies a portability issue in the test script where `grep -o` was used - this flag isn't POSIX-compliant and fails on some platforms like AIX. The patch replaces it with an equivalent `sed` command that should work more universally.

The change is minimal but important - it modifies just one line in t7704-repack-cruft.sh, swapping the non-portable `grep -o` for a `sed` pattern that achieves the same extraction of pack filenames. This addresses the last known issue with the otherwise-ready series, which has already received thorough review and approval from multiple maintainers.

The fix demonstrates good attention to cross-platform compatibility concerns, though it's worth noting this doesn't affect the core functionality of the series - it's purely about making the test suite more portable. The change is straightforward and unlikely to be controversial, coming from an experienced contributor who has identified a genuine platform limitation.
