This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction. It's patch 3/9 in the v5 series, which Junio has already reviewed and approved.

The patch extracts the inline handling of `--stdin-packs` from `cmd_pack_objects()` into a new `read_stdin_packs()` function. This prepares for future expansion of the stdin-packs functionality while keeping the main command function clean. The change is purely structural - the behavior remains identical, just moved to a dedicated function.

Key technical details:
- New function `read_stdin_packs()` encapsulates the existing stdin-packs logic
- Takes `rev_list_unpacked` parameter to conditionally call `add_unreachable_loose_objects()`
- Maintains all existing behavior including `ignore_packed_keep_in_core` setting
- Follows the pattern seen elsewhere in the file where mode-specific logic is factored out

This is a straightforward preparatory change that enables the more substantial modifications coming in later patches of the series, particularly the new `--stdin-packs=follow` mode introduced in patch 8/9. The clean separation of concerns will help maintain readability as the functionality grows.
