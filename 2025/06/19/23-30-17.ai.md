Performance optimization patch in a series improving MIDX and cruft pack handling during repacking.

This is patch 4/9 in Taylor Blau's v5 series optimizing pack-objects behavior, particularly around cruft pack inclusion in MIDX during repacking. The patch refactors how the reachability traversal is initialized when processing packs from stdin, moving the `rev_info` setup out of `read_packs_list_from_stdin()` and into its caller `read_stdin_packs()`. 

The change prepares for future functionality where this same reachability traversal will be reused to find objects reachable from commits in input packs but packed elsewhere. The diff shows the mechanical movement of the `rev_info` initialization and traversal code, with no behavior change in this patch. The commit message notes this is groundwork for sharing the traversal code with the `--unpacked` case handled by `add_unreachable_loose_objects()`.

This is a straightforward refactoring that follows the series' pattern of incremental preparation for the final optimization. The change is well-contained to pack-objects.c and maintains all existing functionality while making the code more reusable. As with other patches in this series, it has been production-validated at GitHub and received thorough review.
