Refactoring patch in a performance optimization series for MIDX and cruft pack interaction. This is patch 7/9 in Taylor Blau's v5 series addressing pack-objects optimizations.

The patch reorders two functions in builtin/pack-objects.c to prepare for future changes where show_commit_pack_hint() will call show_object_pack_hint(). Currently show_commit_pack_hint() is a no-op function that doesn't do anything with commits (since they don't have namehashes), but the upcoming change will make it useful. The reordering minimizes code movement in the next patch.

The change is straightforward - it simply moves the show_commit_pack_hint() function definition to appear after show_object_pack_hint() in the file. This is a pure code organization change with no behavior impact. The patch was suggested by Elijah Newren during review of the series.

This continues the series' pattern of careful refactoring to enable the later performance optimizations, following earlier patches that standardized option handling (1/9), refined variable declarations (2/9), and refactored stdin-packs handling (3/9-4/9). The series has received thorough review and is production-validated.
