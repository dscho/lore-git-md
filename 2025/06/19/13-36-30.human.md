This is a feature patch improving signature handling in Git's `fast-export` and `fast-import` commands, part of an ongoing thread about better supporting cryptographic signatures. This v4 iteration focuses on fixing test bugs from v3 while maintaining the core improvements.

The patch enhances signature format by:
1. Supporting both SHA-1 and SHA-256 signatures from the same commit
2. Adding signature type identification (OpenPGP/X.509/SSH/unknown)
3. Warning when multiple signatures of the same hash type are found
4. Documenting the new "gpgsig <hash-algo> <format>" syntax

The implementation now properly handles round-tripping signatures through fast-export/import while maintaining backward compatibility. Test coverage includes OpenPGP, X.509 and SSH signatures, though the author notes they haven't yet tested commits with both SHA-1 and SHA-256 signatures simultaneously.
