- Implements format detection in `repo_info_init()` to recognize "plaintext" as a valid format
- Introduces empty `repo_info_print_plaintext()` function that will be populated in later patches
- Adds a test case verifying empty plaintext output produces zero lines (distinct from JSON's 2-line empty object)
- The plaintext format is specified to output key=value pairs, one per line, though the actual content will come in future patches
- Maintains consistency with the series' incremental approach by adding minimal scaffolding first
- Test infrastructure from previous patches is reused, with the new test following the same pattern as the JSON test but expecting different output characteristics
