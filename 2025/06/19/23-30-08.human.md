This is the first patch in a performance optimization series for MIDX and cruft pack interaction during repacking. The patch standardizes how `pack-objects` handles incompatible command-line options by using the existing `die_for_incompatible_opt2()` function instead of custom error messages.

The change makes the error output more consistent across different incompatible option pairs (like `--stdin-packs` with `--filter` vs `--keep-unreachable` with `--unpack-unreachable`). It's a straightforward refactoring that touches 20 lines across two files, with one minor test update to match the new error message style.

As the first patch in a well-reviewed series (now at v5), this sets the foundation for later optimizations by cleaning up the option handling code. The change is small and focused, with no behavior changes beyond error message formatting. The rest of the series builds on this to introduce configurable cruft pack handling in MIDX repacking, with production-validated performance improvements.
