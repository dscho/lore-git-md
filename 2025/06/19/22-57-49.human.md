This is a feature patch in the `git repo-info` GSoC series, adding support for reporting the repository's reference storage format (either "files" or "reftable"). The patch implements the `references.format` field, which exposes the same information as `git rev-parse --show-ref-format` but through the new structured output interface.

The implementation adds a new field category (CATEGORY_REFERENCES) and field type (FIELD_REFERENCES_FORMAT) to the repo-info infrastructure. It includes both JSON and plaintext output formats, with the JSON output nesting the format under a "references" object. The patch maintains the series' pattern of thorough test coverage, adding new test cases that verify the format reporting works correctly for both storage backends.

This is patch 5/7 in the v2 series, building on earlier infrastructure patches while leaving room for additional fields to be added later. The implementation looks clean and follows the established patterns from previous patches, with clear separation between format handling and core functionality. The tests cover both happy paths and edge cases, including verification of the default field output behavior.
