This is the second patch in the repo-info` command series, introducing the `--format` flag for output format selection. The patch establishes JSON as the default output format while laying groundwork for future format additions.

The implementation adds an `output_format` enum and `repo_info` struct to track format preferences, with initial JSON support via Git's existing `json-writer` infrastructure. The empty JSON object output (`{}`) is currently hardcoded as placeholder content, with actual repository metadata to be added in subsequent patches. The test suite is introduced in `t1900-repo-info.sh` with a basic JSON output validation test that checks line count rather than content structure.

Key technical details include:
- New `repo_info` struct storing repository pointer and format preference
- `repo_info_init()` function parsing the `--format` option (defaulting to JSON)
- Basic JSON output scaffolding with `repo_info_print_json()`
- Test infrastructure with PERLJSON prerequisite check
- Meson build system integration for the new test file

The patch maintains architectural consistency with the series' goals by:
- Using the repository parameter passed to `cmd_repo_info()`
- Preserving unknown options via `PARSE_OPT_KEEP_UNKNOWN_OPT`
- Following Git's JSON writer conventions
- Establishing test patterns that will expand with functionality
