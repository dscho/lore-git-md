This is the cover letter for the final version (v4) of a 5-patch series enhancing the promisor-remote protocol with configurable field validation. The series has been through extensive review and is now in its polished state, with all major design points settled.

The core improvement allows servers to advertise additional remote attributes (currently limited to partialCloneFilter and token) via a new `promisor.sendFields` config, while clients can validate these against their local configuration using `promisor.checkFields`. The implementation maintains backward compatibility and includes comprehensive test coverage.

Karthik Nayak notes that Christian Couder has reviewed this version and found only minor nits, suggesting it's likely the final iteration before merging. The series represents part of the broader "LOP" (Large Object Promisors) effort to improve partial clone functionality.

Technical highlights include replacing `struct strvec` with a more appropriate `struct promisor_info`, centralized field parsing, case-insensitive matching, and thorough documentation including BNF notation for the protocol. The only outstanding item is a final test refinement for field list delimiters that Christian suggested.

Given the extensive review history and the maintainer's positive feedback, this appears to be the final version before potential inclusion in the Git codebase.
