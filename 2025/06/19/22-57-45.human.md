Feature introduction: This is the first patch in a 7-part series introducing a new `git repo-info` command as a GSoC project. The command will provide structured repository metadata in JSON or plaintext formats, splitting this functionality from `git rev-parse`.

The patch establishes the basic scaffolding by:
- Creating the command skeleton in builtin/repo-info.c
- Adding build system entries (Makefile, meson.build)
- Registering the command in git.c and builtin.h
- Adding to .gitignore

The implementation uses PARSE_OPT_KEEP_UNKNOWN_OPT to allow flexible field specification after flags, though the actual field parsing will come in later patches. This is a clean, well-structured foundation that follows Git's standard patterns for new commands, with proper mentor oversight from Karthik Nayak and Patrick Steinhardt.

As the series opener, this patch focuses narrowly on the command declaration while leaving technical debt - the thread context shows the subsequent patches will handle the JSON/plaintext output formats, test infrastructure, and metadata field implementations. The v2 reorganization has already addressed several review comments from the RFC phase.
