This is a platform compatibility patch in a series addressing Git daemon signal handling issues. Junio C Hamano is reviewing Carlo Marcelo Arenas Belón's patch that centralizes SA_RESTART definitions from platform-specific compiler flags into compat/posix.h.

The change removes SA_RESTART=0 definitions from config.mak.uname for NonStop and QNX systems, replacing them with a fallback in compat/posix.h that defines SA_RESTART as 0 when not provided by the system. Junio notes this makes the behavior more consistent across platforms, though he's unsure of all implications, he observes that systems lacking SA_RESTART previously wouldn't have built Git at all, so this at least maintains that status quo while cleaning up the build system.

The review points out a grammatical error in the commit message ("where" vs "are") but doesn't raise technical objections to the change itself. This appears to be a straightforward build system cleanup that supports the larger signal handling modernization effort in the series. The patch seems well-contained and maintains backward compatibility while removing platform-specific compiler flags in favor of a more maintainable centralized definition.
