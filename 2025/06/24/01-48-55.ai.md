This is a platform compatibility patch in the git-credential-netrc helper series. It modifies the first patch of Maxim Cournoyer's v3 series to make the Perl shebang more portable.

The change replaces the hardcoded `/usr/bin/perl` path with `/usr/bin/env perl`, which looks up the Perl interpreter from the PATH environment variable. This allows the uninstalled script to be run during development without requiring Perl to be in a specific system location, while maintaining compatibility with the installed version (which still uses PERL_PATH).

The change is straightforward and uncontroversial, aligning with common practices for portable scripting. It doesn't affect the core functionality being discussed in the thread (symbolic port name handling) but improves developer experience when working on the helper script. The patch maintains the same file permissions and only modifies the shebang line.

This is part of the larger v3 series that implements helper-side resolution of symbolic port names, with all of Junio Hamano's requested changes from previous iterations now incorporated. The series is technically complete and awaiting a design decision on the port resolution approach.
