This is Junio Hamano's "What's cooking in git.git" status report, providing a snapshot of the current development state across all in-flight Git topics. The report organizes topics into "New Topics" (recent additions) and "Cooking" (ongoing efforts), with each indicating its current integration branch (seen/next/master/maint) and status.

New topics include:
- `jk/test-seq-format` (Jeff King) adds `-f` option to test_seq helper
- `mc/netrc-service-names` (Michael McClimon) enhances netrc credential helper with symbolic port support
- `ph/fetch-prune-optim` (Patrick Huck) optimizes dangling ref reporting in fetch-prune

Major ongoing efforts in Cooking:
- `bc/use-sha256-by-default-in-3.0` (brian m. carlson) prepares SHA-256 as default hash for Git 3.0 breaking changes
- `lo/repo-info` (Lin Sun) introduces new `git repo-info` subcommand
- `ps/object-store` (Patrick Steinhardt) continues removing `the_repository` global from object API
- `tb/midx-avoid-cruft-packs` (Taylor Blau) prevents midx from pointing to cruft packs
- `cc/promisor-remote-capability` (Christian Couder) enhances promisor-remote capability

Recently graduated topics moving to next/master:
- imap-send improvements
- subtree GPG signing support
- batched reference updates

Several topics are noted as needing review responses or expecting rerolls, indicating active development. The report provides comprehensive coverage of both incremental improvements and major architectural changes across Git's development landscape.
