This is the final patch in Maxim Cournoyer's v3 series improving symbolic port name support in git-credential-netrc, completing the helper-side resolution approach. The patch focuses on better integration with git-send-email and adds validation for SMTP server ports.

The key changes include:
1. Modifying git-credential-netrc to properly handle symbolic port names by converting them to numeric values using a new Git::port_num helper function
2. Adding port validation to git-send-email that rejects invalid port specifications
3. Updating tests to verify the new behavior, including a new test for invalid SMTP ports

The implementation now cleanly separates port handling from protocols in the credential helper, fixing the previous issue where symbolic ports like "smtps" would be incorrectly treated as protocols. The changes maintain backward compatibility while adding proper validation and error reporting.

This completes the technical implementation of the helper-side resolution approach that has been under discussion. The patch series appears well-tested and addresses all previous feedback, including Junio Hamano's requested simplifications. The remaining question is whether this approach will be accepted given the credential protocol's current numeric-only wording.
