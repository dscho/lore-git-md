This is a platform compatibility patch that's part of a series fixing signal handling issues in the Git daemon. It moves platform-specific SA_RESTART definitions from compiler flags in config.mak.uname into a centralized header file, compat/posix.h.

The change standardizes how Git handles systems (like NonStop and QNX) that don't provide SA_RESTART in their signal.h headers. Instead of setting this via compiler flags in the build system, it's now defined in the compatibility layer where it's more maintainable and visible. The commit message notes this consolidation will be useful for upcoming signal handling improvements.

This appears to be solid groundwork for the subsequent patches that will fix platform-specific signal handling bugs.
