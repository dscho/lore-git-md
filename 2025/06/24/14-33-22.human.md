This is a bugfix follow-up to the Git daemon signal handling series, specifically addressing the third patch which deals with EINTR handling during poll() operations.

Carlo Marcelo Arenas Belón submits a small fixup to the signal handler function in daemon.c, adding the UNUSED attribute to the signo parameter in child_handler(). This change clarifies the intentional non-use of the signal number parameter in the empty handler function, which exists solely to interrupt system calls during signal handling.

The fixup is a minor cleanup that improves code clarity but doesn't change the behavior of the signal handling improvements in the series. The original patch had already established that this handler is empty since its purpose is to allow system calls to be interrupted (particularly for platforms like OpenBSD where this helps prevent zombie processes).

This appears to be a straightforward improvement to the already-reviewed signal handling changes, maintaining the series' goal of robust cross-platform behavior while making the code's intentions more explicit. The change is small and focused, unlikely to introduce new issues or require significant re-review.
