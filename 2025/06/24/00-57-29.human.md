This is Junio Hamano's regular "What's cooking in git.git" status update, summarizing the current state of development branches. The email provides a comprehensive overview of active topics in-progress for Git, organized into "New Topics" and "Cooking" sections with merge status indicators.

Several notable new features and improvements are highlighted:
- The test helper `test_seq` gains a `-f` option to simplify test scripts
- The netrc credential helper now supports textual service names (like "smtp") alongside numeric ports
- A new `git repo-info` command is proposed to expose repository characteristics
- `git stash` learns import/export functionality for stash entries
- `git imap-send` sees significant improvements including OAuth2.0 support
- Performance optimizations for fetch/prune operations
- The ongoing SHA-256 transition work continues with plans to make it default in breaking changes mode
- Various memory leak fixes and test modernizations
- Multiple efforts to remove `the_repository` global variable usage
- Documentation improvements including deprecation plans for `git whatchanged`

The email also notes several topics needing review or facing potential issues, like the batched reference updates for fetch/push which was temporarily removed from 'next' for fixes. Many cleanups and refactorings are progressing well, with several already merged to 'next' or awaiting final review before merging to 'master'.
