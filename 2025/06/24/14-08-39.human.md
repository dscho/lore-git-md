This is a bugfix series addressing signal handling issues in Git's daemon mode, particularly affecting OpenBSD and AIX systems. The patches focus on making the daemon more robust when handling interrupts during `poll()` operations.

The core issue stems from historical differences in how Unix-like systems handle signal interruption semantics. The series modernizes the daemon's signal handling by switching from `signal()` to `sigaction()`, which provides more consistent behavior across platforms. The key change in the final patch explicitly allows `EINTR` during `poll()`, fixing a problem where zombie processes weren't being properly cleaned up on OpenBSD until a new connection arrived.

The series also incidentally fixes a known crash on AIX through preparatory changes in the second patch. The changes touch build configuration files and POSIX compatibility code, suggesting careful consideration of cross-platform support. The commit messages indicate the author has done their homework on the historical context of signal handling differences between Unix variants.
