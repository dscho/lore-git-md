This is a v3 bugfix series for the git-credential-netrc helper, completing the implementation of symbolic port name support while incorporating final review feedback. The series represents the helper-side resolution approach in the ongoing debate about where port name-to-number conversion should occur in Git's credential system.

The patches now fully implement Junio Hamano's requested changes from the previous round, including renaming the `is_port()` utility function to `port_num()` for clarity and simplifying its implementation to directly return the scalar value from `getservbyname`. The series maintains all previously added functionality: portable shebang, invalid port warnings, and comprehensive symbolic port support through shared validation logic with `git-send-email`.

Key technical details carried forward from v2 include POSIX-compliant `getservbyname` resolution, backward compatibility with numeric ports, and thorough test coverage of edge cases. The implementation now spans multiple components - the credential helper, `git-send-email`, and core Perl utilities - with consistent behavior across all.

With all technical work complete and review feedback addressed, this submission leaves only the high-level design decision about whether to accept helper-side resolution (as implemented here) versus enforcing numeric-only ports per protocol documentation. The series demonstrates that helper-side resolution is robustly implemented, but the project may still choose the alternative approach for protocol compliance.
