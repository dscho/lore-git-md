This is a bugfix series addressing signal handling issues in the Git daemon, particularly affecting OpenBSD and AIX platforms. The core problem involves zombie process cleanup and potential crashes related to interrupted system calls during signal handling.

The series consists of three preparatory patches leading to the main fix. The first adds infrastructure to track SA_RESTART behavior in compat/posix.h. The second modernizes signal handling in daemon.c by using sigaction() instead of signal(), which incidentally fixes a known crash on AIX. The final patch explicitly handles EINTR during poll() operations, solving the original OpenBSD zombie process issue.

The changes touch build configuration (Makefile, config.mak.uname, configure.ac, meson.build) and core daemon functionality (daemon.c), with new platform-specific behavior tracking in compat/posix.h. The commit messages indicate this addresses historical behavior differences between SysV-style signal() implementations and modern sigaction()-based approaches.

Key technical points for future reference:
- Adds SA_RESTART tracking infrastructure
- Replaces signal() with sigaction() for child_handler()
- Explicitly handles EINTR in poll() loop
- Affects daemon's process cleanup behavior
- Fixes platform-specific issues on OpenBSD (zombies) and AIX (crashes)
- Touches multiple build systems for new compatibility checks

The series appears well-structured with each patch building toward the final solution, though the connection between the OpenBSD zombie issue and the AIX crash fix could be more clearly explained in the cover letter.
