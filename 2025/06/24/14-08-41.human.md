This is part 2 of a bugfix series addressing signal handling issues in the Git daemon, specifically targeting crashes on AIX. The patch modernizes the signal handling in `daemon.c` by replacing the old `signal()` call with `sigaction()` for the child handler.

The change serves two purposes: it prepares for future updates to SIGCHLD processing flags (which require `sigaction()`), and it eliminates the need to manually rearm the signal handler after each invocation (a System V requirement). The new implementation uses BSD semantics with `SA_NOCLDSTOP` and `SA_RESTART` flags, which the series has already centralized platform-specific handling in earlier patches.

The diff is straightforward - removing the manual signal rearming and replacing it with a proper `sigaction()` setup. This is part of a larger effort to fix platform-specific issues, with this particular change addressing known crashes on AIX. The patch appears well-contained and builds on the infrastructure changes from patch 1 in the series.
