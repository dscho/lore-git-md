This is Junio Hamano's regular "What's cooking in git.git" status update, summarizing the current state of various patch series in the Git project. The email provides a comprehensive overview of topics under development, organized into "New Topics" (recently added patches) and "Cooking" (longer-running topics still being refined).

Several notable new topics include:
- `jk/test-seq-format` adds a `-f` option to the test helper `test_seq`
- `mc/netrc-service-names` enhances the netrc credential helper to support symbolic port names
- `ph/fetch-prune-optim` optimizes dangling ref reporting in fetch-prune

The cooking section contains many significant ongoing efforts:
- `bc/use-sha256-by-default-in-3.0` prepares to make SHA-256 the default hash algorithm in breaking changes mode
- `lo/repo-info` introduces a new `git repo-info` subcommand to query repository characteristics
- `ps/object-store` continues the large-scale effort to remove `the_repository` global from object access API
- `tb/midx-avoid-cruft-packs` teaches pack-objects to avoid pointing into cruft packs from midx
- `cc/promisor-remote-capability` enhances the promisor-remote capability mechanism

The email also notes several merged topics moving to 'next' or 'master', including improvements to imap-send, subtree GPG signing, and batched reference updates. Many topics are marked as needing review responses or expecting rerolls, indicating active development. The update provides a valuable snapshot of Git's development landscape, showing both incremental improvements and larger architectural changes in progress.
