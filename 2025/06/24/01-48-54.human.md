This is a v3 bugfix and feature enhancement series for the git-credential-netrc helper, now incorporating all requested changes from maintainer feedback. The patches improve symbolic port name handling in netrc files while maintaining backward compatibility.

The series builds on previous discussion about where port resolution should happen (helper vs caller side), with this implementation choosing the helper-side approach using getservbyname(). The v3 iteration responds to Junio Hamano's review by renaming the key validation function from is_port() to port_num() and simplifying its implementation.

Key improvements in this version include:
- More portable shebang line for the Perl script
- Warnings for invalid port specifications
- Shared port validation logic between git-credential-netrc and git-send-email
- Comprehensive test coverage

The technical work appears complete and well-tested, though the underlying design question remains open: whether symbolic port support should exist at all given the credential protocol's mention of "port number" (numeric). The patches demonstrate robust helper-side resolution while maintaining compatibility with existing numeric port usage.

This represents the final implementation-ready version pending a decision from the maintainers about the design direction. The changes are cleanly separated into logical commits with good commit messages explaining each change.
