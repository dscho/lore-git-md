Platform compatibility fix for Git daemon signal handling, specifically addressing zombie process cleanup on OpenBSD. This is the final patch in a series that modernizes signal handling across different platforms.

The patch ensures the Git daemon properly reaps zombie child processes by explicitly allowing EINTR during poll() operations. The key change is disabling SA_RESTART around poll() calls when handling SIGCHLD signals, which prevents the system call from automatically restarting and allows proper interruption for child process cleanup. The implementation includes platform-specific handling through a new NO_SIGINTERRUPT flag, with appropriate build system updates across Makefile, config.mak.uname, configure.ac, and meson.build.

The changes maintain backward compatibility while fixing a real issue on OpenBSD where zombie processes weren't being properly cleaned up. The patch appears well-considered, with thorough build system integration and conditional compilation paths for different platforms. It completes the series' goal of robust cross-platform signal handling in the Git daemon.
