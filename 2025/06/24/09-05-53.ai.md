Bugfix for gitk's external diff functionality when handling renamed files, now at v6. This final version addresses the remaining issue in v5 where the rename detection wasn't properly filtering for the specific file selected in the GUI. The patch maintains the core approach of using Git's native rename detection via `git diff --find-renames` but now properly escapes special characters in filenames and filters the rename detection to only consider the file being diffed.

The key changes in v6 are:
1. Added filename escaping for special regex characters (backslash, pipe, etc.) to prevent them from being interpreted as regex syntax
2. Split the rename detection into two patterns - one matching when the original filename is the source of the rename, and another when it's the destination
3. Only considers renames involving the specific file being diffed, rather than any rename in the commit range
