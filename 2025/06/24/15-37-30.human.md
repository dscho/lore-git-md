This is part 2 of a bugfix series addressing signal handling issues in the Git daemon, specifically targeting zombie process cleanup on OpenBSD and crashes on AIX. The patch modernizes the daemon's SIGCHLD handler by switching from `signal()` to `sigaction()`, which provides more reliable BSD semantics and eliminates the need for manual handler rearming on SysV systems.

The change removes the now-unnecessary rearming call in `child_handler()` and properly initializes the signal mask with `sigemptyset()`. It also sets `SA_NOCLDSTOP` and `SA_RESTART` flags, though Junio C Hamano questions whether the empty handler is still needed at all given these changes. The answer to that appears to be coming in the next patch.

This is a straightforward technical improvement that builds on the platform-specific SA_RESTART handling infrastructure introduced in patch 1. The implementation looks clean, though the commit message could be clearer about why the empty handler remains (presumably to maintain interrupt behavior for system calls). The series is progressing well with Junio providing light review and Carlo Marcelo Arenas Belón incorporating feedback.
