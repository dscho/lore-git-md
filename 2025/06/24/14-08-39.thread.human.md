This thread addresses signal handling issues in the Git daemon, specifically around zombie process cleanup on OpenBSD and crashes on AIX. The core problem involves interrupted system calls during signal handling, with platform-specific behavior around SA_RESTART in poll() operations. The discussion has evolved through three versions of the patch series, with contributions from Carlo Marcelo Arenas Belon, Junio C Hamano, Phillip Wood, and Chris Torek.

Two main solutions emerged: the current SA_RESTART toggling approach (now improved with better platform detection and Windows support) and a self-pipe alternative that would eliminate platform-specific signal handling complexities. The latest patch (v3) introduces a `set_sa_restart()` helper to manage SA_RESTART flags around poll() calls, providing a working solution while keeping the architectural decision open. 

Junio has validated the technical soundness of the self-pipe approach, which would be more portable and avoid signal handling complexities, though it requires more implementation work. The current solution maintains backward compatibility and addresses the immediate issues, but carries some technical debt. The thread shows consensus that either approach would work, with the choice now being one of architectural preference and maintenance tradeoffs rather than technical correctness.
