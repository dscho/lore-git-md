This thread addresses signal handling issues in the Git daemon that cause zombie processes on OpenBSD and crashes on AIX. The discussion has evolved through three versions of a patch series from Carlo Marcelo Arenas Belón, with input from Junio Hamano, Phillip Wood, and Chris Torek. The core problem involves platform-specific behavior around interrupted system calls during signal handling, particularly with SA_RESTART in poll() operations.

Two solutions have emerged: the current SA_RESTART toggling approach (nearly complete but requiring platform-specific fixes) and a self-pipe alternative (technically validated by Junio). The latest email clarifies a flaw in how the current implementation detects SA_RESTART support, showing the empty `#ifdef` block doesn't work as intended. This reveals additional technical debt in the SA_RESTART approach's platform detection that would need fixing.

Junio has previously validated the self-pipe approach, which would avoid these platform-specific issues entirely by using dedicated file descriptors to wake the event loop. Phillip Wood confirmed this works equally well for both poll() and select(). The decision now weighs the SA_RESTART approach's implementation progress against the self-pipe's cleaner architecture but additional implementation work. Documentation of the signal handling infrastructure will need improvement regardless of which path is chosen.
