This thread addresses signal handling issues in the Git daemon, specifically focusing on zombie process cleanup on OpenBSD and crashes on AIX. The series modernizes the daemon's signal handling by replacing legacy `signal()` calls with `sigaction()`, centralizing platform-specific behavior for `SA_RESTART`, and adding proper EINTR handling during `poll()` operations.

The latest patch introduces a `NO_SIGINTERRUPT` build flag for platforms lacking proper `siginterrupt()` support (Windows, NonStop, QNX, MINGW). Junio Hamano has reviewed the implementation, raising two key points: he questions whether the empty `child_handler()` function is still necessary now that manual rearming has been removed, and suggests better abstraction to reduce `#ifdef` clutter. Carlo Marcelo Arenas Belon previously contributed a fix to mark an unused parameter in `child_handler()`.

The series has already addressed several technical issues: consolidating `SA_RESTART` handling into `compat/posix.h`, modernizing signal setup with proper flags (`SA_NOCLDSTOP` and `SA_RESTART`), and removing legacy rearming requirements. While the platform-specific fixes for OpenBSD and AIX are now complete, Junio's feedback indicates the implementation could be further refined before merging. The thread remains open pending resolution of the empty handler question and potential code reorganization to improve maintainability.
