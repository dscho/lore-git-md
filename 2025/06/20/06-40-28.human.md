This is a feature patch in the ongoing `imap-send` authentication improvements series, adding PLAIN authentication support for the OpenSSL backend. The patch fills a gap where PLAIN authentication (commonly used with app passwords) was only available via libcurl, not OpenSSL.

The implementation follows RFC 4616, constructing the proper `\0user\0pass` format before base64 encoding. It introduces a new `plain_base64()` helper function and adds the `AUTH_PLAIN` capability flag. The documentation is updated to reflect that PLAIN is now available for both backends.

This appears to be a well-constructed patch that completes the authentication method parity between OpenSSL and libcurl backends. The change is part of a mature series (now at v19) that has undergone extensive review, with this specific patch addressing a clearly motivated use case for email providers still using PLAIN authentication.
