Bugfix for a critical regression in `imap-send` that has been present since Git 2.46.0. This is the first patch in a 10-part series that introduces OAuth2.0 support and other improvements to the IMAP functionality.

The patch fixes a configuration parsing bug where `cfg->folder` was incorrectly being set to NULL when processing unrelated configuration options like `imap.user`, `imap.pass`, `imap.tunnel`, and `imap.authmethod`. This made `git-imap-send` completely unusable in affected configurations. The fix properly NULLs out the correct struct fields for each configuration option rather than incorrectly clearing `cfg->folder` in all cases.

The bug appears to have gone unnoticed for some time, possibly because most users prefer `git-send-email`. The fix is straightforward - it corrects the field-specific cleanup in `git_imap_config()` by freeing the correct struct member for each config option. This is a critical fix that should be backported to affected versions.
