This thread begins with a preparatory patch for potential future hash algorithm changes in Git. The initial patch introduces a new constant `GIT_HASH_DEFAULT` (currently set to SHA-1) in hash.h, which will serve as a central reference point for the default hash algorithm throughout the codebase. The change is designed to make future transitions to different hash algorithms easier by requiring updates to just this single definition rather than numerous direct SHA-1 references across the code. While this first patch is purely mechanical and has no immediate behavior impact, it lays groundwork for a 10-part series that will presumably replace direct SHA-1 usage with this new constant. The commit message clearly explains the long-term motivation behind this infrastructure change.
