Feature and bugfix series for `imap-send` at v19, addressing the final outstanding issue from previous reviews. This version resolves the string construction safety concerns in the OAuth2.0 implementation by switching to `xstrfmt()` for OAuth2 strings and `strbuf` for PLAIN authentication, as suggested by Phillip Wood.

Key changes in v19:
1. Replaces fragile `snprintf()` with `xstrfmt()` in `oauthbearer_base64()` and `xoauth2_base64()` functions for safer string construction
2. Uses `strbuf` in `plain_base64()` for PLAIN authentication string building, improving memory management
3. Maintains all other functionality from v18 including OAuth2.0 support, folder management, and configuration fixes

The series now appears technically complete with all major review feedback addressed. The implementation handles:
- OAuth2.0 via OAUTHBEARER (RFC-standard) and XOAUTH2 (Google-proprietary)
- PLAIN authentication with proper RFC4616 compliance
- Folder listing and command-line folder specification
- Various memory leak fixes and error handling improvements

The patch organization remains unchanged from v18, with the string construction improvements being the only substantive code changes in this revision. The series has undergone extensive review from multiple Git maintainers and appears ready for integration.
