Thread identity: Cover letter for a series preparing Git's transition to SHA-256 as the default hash algorithm, targeting Git 3.0 when built with WITH_BREAKING_CHANGES. Authored by brian m. carlson, who previously led the hash-algorithm-agnostic internals work.

Core problem/goal: Implement SHA-256 as the built-in default hash algorithm while maintaining backward compatibility, allowing testing before Git 3.0 release. The series introduces constants (GIT_HASH_DEFAULT for SHA-256, GIT_HASH_ORIGINAL for SHA-1) to distinguish between default/legacy vs intentional SHA-1 usage.

- Repository initialization logic modified in setup.c/setup.h to handle new vs existing repos
- Final patch implements conditional GIT_HASH_DEFAULT definition with corrected preprocessor indentation per Junio's review
