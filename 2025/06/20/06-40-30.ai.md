This is a feature patch in the ongoing `imap-send` series, adding a new `--list` command to display available IMAP folders. The patch implements RFC6154's LIST command for both OpenSSL and libcurl backends, showing folder hierarchies and attributes in a standardized format. Key technical details:

For OpenSSL, it adds a new `list_imap_folders()` function that issues the LIST command and prints responses, with verbosity adjusted to show LIST responses. For libcurl, it modifies the existing setup to skip folder-specific options when listing, adds a new `curl_list_imap_folders()` function, and ensures proper credential handling. The patch updates documentation to mention the new option and its use for discovering folder names (particularly helpful for Gmail's non-standard naming).

The implementation follows the series' pattern of parallel backend support while reusing existing connection/auth infrastructure. It handles both tunnel and direct connections appropriately. The change is well-contained, touching mainly the command dispatch logic in `cmd_main()` and adding backend-specific implementations, with clear separation between listing and message-sending modes.
