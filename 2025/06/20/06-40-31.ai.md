Feature and bugfix in the ongoing `imap-send` series, specifically addressing credential helper output. This patch modifies the credential prompt to include the port number alongside the hostname when requesting passwords, bringing consistency with `git send-email`'s behavior.

The change is a one-line modification in `imap-send.c` that replaces a simple hostname copy with an `xstrfmt` call combining host and port. The credential helper will now show prompts like `imaps://user@host:993` instead of just `imaps://user@host`. This makes the authentication request more specific, particularly useful when dealing with multiple IMAP servers on different ports.

The patch is part of a larger series (v19 08/10) that has already undergone extensive review, with this being a relatively minor but useful UX improvement. It follows the series' pattern of using safe string handling (`xstrfmt` rather than `snprintf`) and maintains the existing credential management structure while making the output more informative. The change is well-motivated by both consistency with other Git commands and practical debugging benefits when working with non-standard ports.
