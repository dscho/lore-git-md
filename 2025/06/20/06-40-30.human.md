Feature patch adding folder listing to `imap-send`, part of a larger series improving IMAP functionality.

This patch introduces a `--list` option to `git imap-send` that displays all available folders on the IMAP server, implemented for both OpenSSL and libcurl backends. The motivation is that different IMAP services (Gmail, Outlook, etc.) use different naming conventions for standard folders like Drafts and Trash, making it hard for users to know what folder names to configure. The implementation follows RFC6154 for OpenSSL backend and libcurl's documentation for its backend.

The patch shows good attention to detail - it handles both backends consistently, includes documentation updates, and maintains the existing verbosity behavior while adding the new LIST output. The example output demonstrates how this helps users see Gmail's non-obvious folder structure. This is a useful quality-of-life improvement that complements the series' other folder-related work (like the `--folder` option).

As part of a mature v19 series that has addressed extensive review feedback, this patch appears solid and well-integrated with the rest of the IMAP improvements. The change is focused and doesn't introduce any obvious technical concerns.
