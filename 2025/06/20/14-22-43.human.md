This is a follow-up in the bugfix thread about symbolic port names in git-credential-netrc. Andreas Schwab provides important clarification about valid service name characters by referencing RFC6335, which explicitly allows hyphens but not underscores in port names. This directly addresses Junio Hamano's earlier question about whether the alphanumeric character class in the proposed patch is sufficiently permissive.

The RFC citation strengthens the case for expanding the validation pattern beyond just alphanumerics to include hyphens, while confirming that underscores should remain excluded. This technical detail will likely help shape the final version of the patch, as it provides a standards-based justification for the character set selection. The exchange shows the maintainer's careful attention to getting the validation rules precisely right, even for what might seem like a minor helper script.
