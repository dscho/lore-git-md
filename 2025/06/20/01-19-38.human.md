This is a test infrastructure update as part of the SHA-256 transition series. The patch prepares the test suite to handle a future where the default hash algorithm may not be SHA-1, though it currently maintains SHA-1 as the built-in default.

The changes introduce a new `GIT_TEST_BUILTIN_HASH` variable that represents the compile-time default hash algorithm (still SHA-1 for now) and makes it the fallback when no hash is explicitly set via `GIT_TEST_DEFAULT_HASH`. This allows tests to be written in a hash-agnostic way while maintaining current behavior.

Key technical additions include:
- A new `--hash=builtin` option for `test_oid` to reference the compile-time default hash
- A `DEFAULT_HASH_ALGORITHM` prerequisite to check if the current hash matches the built-in default
- Updates to hash detection logic to use the built-in default as fallback
