This is a test infrastructure update as part of the SHA-256 default transition series. The patch prepares the test suite to handle a future where the compile-time hash algorithm may not be SHA-1 by default.

The changes introduce a new `GIT_TEST_BUILTIN_HASH` variable (currently set to sha1) that represents the compile-time default hash algorithm. This variable is used as a default when `GIT_TEST_DEFAULT_HASH` isn't set, making the test suite more flexible for future hash algorithm changes. The patch also adds a `--hash=builtin` option to `test_oid` to allow tests to reference the built-in hash algorithm without hardcoding SHA-1.

A new `DEFAULT_HASH_ALGORITHM` prerequisite is added to check whether the current hash matches the built-in default. This will be useful for testing scenarios where the default algorithm changes. The changes are mechanical and maintain current behavior while setting up infrastructure for the SHA-256 transition planned in later patches of this series.

The patch follows the series' pattern of making minimal, focused changes to prepare for the SHA-256 default transition. It builds on the earlier introduction of hash algorithm infrastructure while keeping the test suite working with both current and future configurations.
