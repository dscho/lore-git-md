Feature patch adding command-line folder specification to `git imap-send`, part of the larger `imap-send` improvement series (v19 6/10). This patch introduces a new `--folder`/`-f` option to override the IMAP destination folder at runtime, complementing the existing `imap.folder` config setting. The implementation follows the series' pattern of CLI options taking precedence over config values.

Key technical details:
- Adds `opt_folder` static variable and `OPT_STRING` option to parse the new flag
- Updates usage string and documentation in both `imap.adoc` and `git-imap-send.adoc`
- Implements config override by freeing the existing `server.folder` and replacing it with the CLI value via `xstrdup()`
- Documents the precedence rules (CLI overrides config) and provides example folder syntax
- Includes minor documentation formatting fixes (backtick-wrapping of literals, consistent markup)

The patch fits cleanly into the series' broader folder management improvements, which also include the new `--list` command for inspecting folder hierarchies. The implementation appears straightforward with proper memory management (freeing the old value before replacement). Documentation updates clearly explain the new option's purpose and relationship to the config setting.
