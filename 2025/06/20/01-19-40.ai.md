This is a test infrastructure patch in the SHA-256 default transition series, updating t4042-diff-textconv-caching.sh to handle hash algorithm changes. The change makes the test work correctly regardless of whether the built-in default hash is SHA-1 or SHA-256.

The patch modifies a test that verifies textconv caching behavior outside a repository. Previously, it hardcoded SHA-1 object IDs in the expected output. Now it uses test_oid with the --hash=builtin option to get the correct OIDs for the current default hash algorithm. The test_oid_cache block provides both SHA-1 and SHA-256 values for the test objects, making the test future-proof when SHA-256 becomes the default.

This follows the pattern established earlier in the series of making tests hash-algorithm-agnostic. The change is mechanical but important for maintaining test correctness during the transition period. The patch demonstrates good attention to detail by updating both the test setup (adding the oid_cache) and the test assertion (using the cached values via test_oid).
