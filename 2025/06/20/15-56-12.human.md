This is a v3 patch series improving error messages in `git imap-send`, building on previous work to enhance configuration error reporting. The series follows up on Junio Hamano's feedback about proper use of Git's messaging APIs.

The two patches refine error messages shown when IMAP configuration is missing. The first fixes confusing "store" terminology to match the actual `imap.folder` config name. The second adds actionable configuration advice using Git's error() and advise() APIs, now properly formatted as single multi-line strings per Junio's suggestion.

The changes are small (9 lines total) but improve user experience by providing clearer guidance when setup is incomplete. The series has evolved through three versions with careful attention to API usage patterns and terminology consistency. While separate from ongoing IMAP functionality fixes, these message improvements have standalone value for users encountering configuration issues.
