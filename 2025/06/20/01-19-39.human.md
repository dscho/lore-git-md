This is a test modernization patch in the SHA-256 default transition series. It updates a test in t1007-hash-object.sh to work correctly when the default hash algorithm changes from SHA-1 to SHA-256.

The patch modifies a test case which verifies `git hash-object` behavior outside a repository. Currently the test hardcodes an expectation of SHA-1 output, but this will break when SHA-256 becomes the default. The change replaces the explicit SHA-1 reference with `--hash=builtin`, which will automatically use whatever hash algorithm is configured as the default.

This is a straightforward mechanical change that aligns with the series' goal of preparing tests for the SHA-256 transition. The patch is small and focused, just updating one test case to be hash-agnostic. It demonstrates good attention to detail in catching test assumptions that would break with the default hash change.
