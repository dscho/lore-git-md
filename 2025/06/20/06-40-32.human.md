User experience improvement in the `imap-send` series. This patch (9/10 in v19) enhances the command's output to show the destination mailbox name when sending messages, making it clearer where emails are being delivered. Previously, the output only showed the count of messages being sent (e.g., "sending 1 message"). Now it includes the folder name (e.g., "Sending 1 message to Drafts folder..."). The change is implemented consistently for both the OpenSSL and libcurl backends with simple fprintf statement updates. This is a pattern seen elsewhere in the series - small but thoughtful UX polish that makes the tool more user-friendly. The patch is straightforward and well-contained, following the established style of the surrounding code.
