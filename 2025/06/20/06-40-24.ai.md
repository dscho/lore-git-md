Bugfix for a critical regression in `imap-send` configuration parsing introduced in Git 2.46.0. This is the first patch in a 10-part series that overhauls IMAP functionality, but stands alone as an urgent fix for a breaking change.

The patch corrects a bug where `git_imap_config()` was incorrectly NULLing out `cfg->folder` when processing unrelated configuration options (`imap.user`, `imap.pass`, `imap.tunnel`, `imap.authmethod`). The regression made `git-imap-send` completely non-functional when these common configuration options were present. The fix properly NULLs out the correct struct fields for each configuration option rather than incorrectly clearing `cfg->folder` in all cases.

The bug stems from commit 6d1f198f34 ("imap-send: fix leaking memory in `imap_server_conf`") which introduced incorrect field clearing. The patch restores proper behavior by matching each config option to its corresponding struct member (`user`, `pass`, `tunnel`, `auth_method`). The change is minimal (4 lines modified) but critical for IMAP functionality.
