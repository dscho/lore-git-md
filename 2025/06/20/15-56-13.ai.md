This is a bugfix patch in Joerg Thalheim's v3 series improving `git imap-send` error messages. It corrects a terminology mismatch where the error message referred to an "IMAP store" while the actual configuration variable is called `imap.folder`. The change is minimal (1 line modified) but improves user experience by making the error message match the configuration users need to set.

The patch follows the thread's established pattern of making `imap-send` errors more accurate and actionable. This particular fix addresses a specific point of confusion that could lead users to search for a non-existent `imap.store` configuration. The change is straightforward and uncontroversial, aligning with the configuration variable name.

This is part of a larger effort to improve `imap-send` error handling that has already incorporated Junio Hamano's feedback about message formatting and API usage. The series appears ready for merging while core IMAP functionality issues remain a separate concern.
