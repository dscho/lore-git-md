Maintainer feedback on netrc credential helper port validation patch.

Junio Hamano provides review comments on Maxim Cournoyer's patch to support symbolic port names in the git-credential-netrc helper. The review focuses on three main points:

First, Hamano notes style issues in the commit message - the subject line should downcase "Honor" and drop the trailing period to match Git conventions. He also points out the patch is missing a required sign-off line.

Second, Hamano questions an unrelated change switching the Perl shebang from `/usr/bin/perl` to `/usr/bin/env perl`, noting this is unnecessary since the build system handles Perl path configuration. This change should be dropped from the patch.

Third, regarding the core port validation change, Hamano requests stronger justification for the `[[:alnum:]]` character class choice. He suggests documenting the specific sources (like IANA service names) that validate this character set, rather than making an assumption about what "seems good enough." He also raises whether additional characters like underscores or hyphens might be valid on some systems.

The review maintains a positive stance on addressing the core issue but pushes for more rigorous documentation of the design choices. No changes to the actual port handling behavior are requested beyond potentially adding warning messages for invalid ports. The feedback indicates this is likely to be accepted after addressing these documentation and style concerns.
