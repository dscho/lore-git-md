This is a refactoring patch that's part of a larger series (3/10) about hash algorithm handling. The patch updates several builtin commands that can operate outside a repository to use `GIT_HASH_DEFAULT` instead of hardcoding SHA-1 when no repository is present. 

The change is forward-looking - currently there's no functional difference since SHA-1 is still the default, but this prepares the codebase for when that might change in the future. The patch touches 8 commands including `git apply`, `git diff`, and `git hash-object`, consistently replacing the SHA-1 hardcoding with the default hash reference.

The changes are mechanical but well-justified - the commit message clearly explains that when operating outside a repository, we can't know what hash algorithm would be used, so defaulting to the system default is more correct than assuming SHA-1. The patch appears clean and focused, with each change following the same simple pattern.
