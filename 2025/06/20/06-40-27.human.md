This is a feature patch adding OAuth2.0 authentication support to `git imap-send`, part of a larger series that has gone through 19 iterations of review. The patch implements both the standard OAUTHBEARER protocol (RFCs 5801 and 7628) and Google's proprietary XOAUTH2 mechanism, with support for both OpenSSL and libcurl backends.

The implementation includes new base64 encoding helpers for constructing the authentication strings, updates to the capability negotiation system to handle the new auth methods, and documentation explaining how to use OAuth with both Gmail and Outlook. The patch also improves the curl backend to properly handle OAuth bearer tokens via `CURLOPT_XOAUTH2_BEARER`.

The documentation changes are particularly notable, as they explain the security benefits of OAuth over app-specific passwords and provide clear configuration examples. The implementation appears thorough, with proper error handling and memory management throughout. This is a well-motivated addition given many email providers' increasing restrictions on traditional password-based IMAP access.

As part of the larger series, this patch builds on earlier infrastructure like the `try_auth_method()` helper and configuration parser fixes. The v19 iteration incorporates final review feedback, suggesting the implementation is now mature and ready for inclusion.
