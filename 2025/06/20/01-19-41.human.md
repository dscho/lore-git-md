This is a test infrastructure patch in the SHA-256 default transition series. It updates t5300-pack-object.sh to handle operations outside a repository in a hash-agnostic way, preparing for when SHA-256 becomes the built-in default.

The changes replace hardcoded SHA-1 assumptions with dynamic checks against the default hash algorithm. Tests that previously used the SHA1 prerequisite now use DEFAULT_HASH_ALGORITHM instead, and conditional checks compare against $GIT_TEST_BUILTIN_HASH rather than "sha1". This ensures the tests will continue working correctly regardless of which hash algorithm is configured as the default.

The patch is straightforward and follows the pattern established in earlier parts of the series. It demonstrates good attention to detail by updating both test prerequisites and conditional logic. As with the rest of the series, these changes are mechanical but important for maintaining test coverage during the hash algorithm transition.
