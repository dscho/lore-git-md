This is a feature and bugfix series for `imap-send`, now at its 19th iteration, addressing authentication methods and usability issues. The series has evolved through extensive review and now appears ready for integration.

The patch series fixes several critical issues in `imap-send`, including a configuration parser regression that made the tool unusable in some cases, and adds modern authentication support. The headline feature is OAuth2.0 support (both standard OAUTHBEARER and Google's XOAUTH2), implemented for both OpenSSL and libcurl backends. The series also adds PLAIN authentication, folder management capabilities via new `--list` and `--folder` options, and various user experience improvements like better progress feedback.

Version 19 specifically addresses the last remaining technical concern from reviewers by replacing potentially unsafe string construction in the OAuth2.0 helpers with safer `xstrfmt()` and `strbuf` alternatives. The series has been thoroughly reviewed by multiple Git maintainers and contributors, with all major issues resolved across its 18 previous versions. The changes span configuration parsing, authentication handlers, IMAP protocol handling, and user interface improvements.

This appears to be a well-considered and carefully implemented series that significantly modernizes `imap-send` while fixing long-standing issues. The author has been responsive to feedback throughout the lengthy review process, and the only remaining open question (string safety) has now been addressed in this version.
