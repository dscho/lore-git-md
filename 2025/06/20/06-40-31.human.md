This is a user experience improvement patch in the ongoing `imap-send` series, which is now at version 19. The change makes credential prompts more informative by including the port number alongside the hostname when requesting passwords, matching the behavior of `git send-email`.

The one-line change modifies the credential helper display format from showing just `imaps://user@host` to `imaps://user@host:port`. This provides better context for users are managing multiple IMAP connections, particularly when different ports are involved. The patch aligns with the series' focus on improving IMAP functionality and follows the precedent set by other Git commands.

The change is straightforward and well-contained, modifying only a single line in `imap-send.c` to use `xstrfmt()` for combining host and port. It's a small but thoughtful improvement that builds on the series' broader work to enhance IMAP support.
