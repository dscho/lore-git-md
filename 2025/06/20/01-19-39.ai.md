This is a test infrastructure patch in the SHA-256 default transition series. It updates t1007-hash-object.sh to handle the upcoming change where the built-in default hash algorithm will switch from SHA-1 to SHA-256 when Git is built with WITH_BREAKING_CHANGES.

The change replaces a hardcoded SHA-1 assumption in a test case with a query to test_oid for the built-in hash algorithm. The test verifies `git hash-object` behavior outside a repository, which currently uses SHA-1 but will soon use SHA-256 by default. The patch mechanically updates the test expectation to use `--hash=builtin` rather than `--hash=sha1`, making the test future-proof for the hash algorithm transition.

This is a straightforward test adaptation that follows the pattern established in earlier patches of the series. It demonstrates how the test suite is being prepared to work correctly regardless of the default hash algorithm. The change is minimal (2-line diff) and maintains the test's purpose while removing the SHA-1 assumption.
