This is a cleanup patch in the `imap-send` series, addressing minor logging inconsistencies. It's the final patch (10/10) in v19 of a larger series that adds OAuth2 support and other improvements to Git's IMAP functionality.

The patch standardizes error message formatting throughout `imap-send.c`:
- Making all error messages lowercase (except for proper nouns like "IMAP")
- Ensuring messages end with periods
- Correcting abbreviations to use uppercase ("OK", "IMAP")
- Fixing a misleading error that showed the hostname when it should have shown the authentication mechanism

These are small but worthwhile consistency fixes that follow Git's style guidelines. The changes are mechanical and straightforward string substitutions, with no behavioral impact. As the last patch in a well-reviewed series, this appears to be final polish before potential inclusion.
