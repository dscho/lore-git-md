This is a bugfix and user experience improvement for `git imap-send`, part of Joerg Thalheim's v2 series building on Aditya Garg's earlier work. The patch replaces terse error messages about missing IMAP configuration with more helpful versions that include both the error and actionable advice.

The changes replace direct `fprintf(stderr)` calls with Git's `error()` and `advise()` APIs, showing users exactly how to configure missing `imap.host` and `imap.folder` settings. Each error now includes example values (like `imaps://imap.example.com` for the host) and the specific `git config` commands needed to fix the issue. The advice is properly internationalized and can be disabled via Git's standard advice configuration.

This continues the thread's focus on improving `imap-send` UX while core IMAP functionality issues are addressed separately. The patch is small (9 lines modified) and focused, with the key technical change being the introduction of `advice.h` and conversion to Git's error reporting APIs. It maintains compatibility with the existing error flow while making the output more user-friendly.
