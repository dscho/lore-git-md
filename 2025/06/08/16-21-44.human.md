This is a feature patch adding a new configuration option for Git's Bash completion script. The patch introduces `completion.forEachRefSort` to let users customize how refs are sorted in completion contexts (like `git checkout <TAB>`). The author wants to sort by recent committer date rather than the default alphabetical order.

The change is straightforward - it adds the config variable and modifies the completion script to pass the user's sort option to `git for-each-ref`. The motivation is clear (prioritizing recently-used branches in completions) and the implementation looks correct, though it lacks test coverage as noted by the author. This seems like a useful quality-of-life improvement for users who frequently switch between recent branches.

The patch is self-contained and doesn't appear to be part of a larger series.
