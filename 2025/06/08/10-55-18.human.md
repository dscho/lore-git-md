This is a user experience improvement patch in the `imap-send` series, specifically addressing progress output clarity. 

The change enhances the progress message during email sending to include the destination folder name, making it clearer where messages are being delivered. Previously, the output would show just "Sending N message(s)", while now it adds "...to FOLDER folder..." to the message. The change is applied consistently to both the OpenSSL and libcurl backend implementations.

This is a straightforward quality-of-life improvement that helps users confirm their messages are going to the intended location, particularly useful when working with multiple folders. The patch is small (just two line changes) and well-contained, following the pattern of other recent usability improvements in this series. It's part of the final polish before the larger `imap-send` feature set is merged.
