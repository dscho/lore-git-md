This is a bugfix patch addressing a memory leak in the submodule update code. The issue occurs in `builtin/submodule--helper.c` where a dynamically allocated string (`remote_name`) could leak if `remote_submodule_branch()` fails after successfully obtaining the remote name. While the failure case is unlikely, the patch properly cleans up by adding a `free()` call at the early exit point.

The change is straightforward - just 3 lines modified to ensure proper resource cleanup.
