This is a feature patch in the ongoing `imap-send` series, adding PLAIN authentication support for the OpenSSL backend. The patch completes feature parity between OpenSSL and libcurl backends by implementing RFC 4616-compliant PLAIN authentication, which was previously only available when using curl.

The implementation introduces a new `plain_base64()` helper function that constructs the proper PLAIN authentication string (formatted as "\0user\0pass" then base64) and a corresponding `auth_plain()` handler that integrates with the existing authentication framework. The patch also adds the `AUTH_PLAIN` capability flag and updates the documentation to list PLAIN as a supported method for both backends.

This change is particularly useful for services that use app passwords with PLAIN authentication. The implementation follows the same pattern as other authentication methods in the series, with proper memory management and error handling. The patch fits into the broader context of the series by completing the authentication method support matrix, alongside the previously added OAuth2.0 and CRAM-MD5 implementations.
