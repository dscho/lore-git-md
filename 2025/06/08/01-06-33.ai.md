This is a cover letter for a 2-patch series that's part of the ongoing `the_repository` removal effort, specifically targeting the `prune` builtin. The series comes from Ayush Chandekar as part of GSoC (Google Summer of Code) work.

The first patch moves the global variable `repository_format_precious_objects` into `struct repository`, which requires updating several callers in `gc.c`, `repack.c`, and `setup.c`. This is a prerequisite for the second patch, which removes `the_repository` usage from `builtin/prune.c` by making the code work with repository instances. The changes are mechanical but touch several files that deal with repository initialization and object pruning.

The series appears well-scoped and focused on a clear goal within the larger `the_repository` removal project. The patches follow the established pattern of moving globals into repository structs before eliminating their dependencies. The changes are relatively contained but require careful review since they affect core repository handling code paths that deal with object management. The cover letter clearly explains the motivation and relationship between the two patches.
