This is a platform compatibility patch updating build configuration for Solaris systems. Brad Smith notes that newer Solaris versions (10 and 11) now provide several standard library functions that Git previously had to work around: `strtoumax()` is available in Solaris 10+, while Solaris 11+ adds `mkdtemp()`, `memmem()`, and `strcasestr()`.

The changes reorganize the Solaris-specific build flags in `config.mak.uname` to only disable these functions on older Solaris versions where they're missing. The patch shows careful version-specific handling, with different configurations for Solaris releases 5.8 through 5.11. The changes appear straightforward and well-motivated, cleaning up unnecessary workarounds for modern Solaris systems while maintaining compatibility with older ones.
