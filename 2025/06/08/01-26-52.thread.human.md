This thread addresses build configuration updates for Solaris systems. Brad Smith's patch refines the Solaris-specific build rules in `config.mak.uname` to more accurately reflect function availability across different Solaris versions. The changes remove blanket declarations for missing functions (`NO_STRCASESTR`, `NO_MEMMEM`, `NO_MKDTEMP`) and instead introduce version-specific checks. Solaris 10 gains `strtoumax()`, while Solaris 11 additionally supports `mkdtemp()`, `memmem()`, and `strcasestr()`. The patch maintains backward compatibility while allowing Git to leverage more native functionality on modern Solaris systems. The changes appear well-scoped and researched, focusing solely on build system adjustments without broader code impact.
