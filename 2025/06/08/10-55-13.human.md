This is a feature patch adding OAuth2.0 authentication support to `git imap-send`, part of a larger series that has been through extensive review (now at v15). The patch implements both the standard OAUTHBEARER (RFC 7628) and Google's proprietary XOAUTH2 mechanisms, with support for both OpenSSL and libcurl backends.

The implementation includes new helper functions to construct and encode the authentication strings, updates to handle the new auth methods in both the OpenSSL and libcurl code paths, and documentation updates explaining how to use OAuth with Gmail and Outlook. The patch maintains backward compatibility while adding these modern authentication options.

The changes are well-considered, with proper error handling and memory management. The documentation additions are particularly thorough, covering both the technical implementation details and practical usage instructions for end users. This is a solid addition that brings `imap-send` up to date with modern email provider authentication requirements.
