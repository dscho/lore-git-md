This is a feature patch adding PLAIN authentication support to the OpenSSL backend of `imap-send`, part of a larger series modernizing IMAP functionality.

The patch implements RFC 4616-compliant PLAIN authentication for the OpenSSL backend, bringing it to parity with the existing curl implementation. The author notes that while many email providers still use PLAIN authentication (particularly with app passwords), the OpenSSL backend currently only supports it via the older IMAP LOGIN command rather than the standard AUTH PLAIN mechanism.

The implementation follows the RFC specification, constructing the proper authentication string (a NUL-delimited combination of username and password) and base64-encoding it. The patch adds a new `plain_base64()` helper function and integrates PLAIN into the authentication flow alongside existing methods like CRAM-MD5 and OAuth. Documentation is updated to reflect the new capability.

This appears to be a well-contained addition that completes feature parity between the OpenSSL and libcurl backends. The implementation is straightforward and follows the same patterns as other authentication methods in the codebase. As part of the larger IMAP modernization series that has undergone extensive review, this patch seems ready for inclusion.
