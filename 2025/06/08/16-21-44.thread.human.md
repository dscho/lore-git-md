This thread centers on a proposal to add a `completion.forRefSort` configuration option that would allow customizing how refs are sorted in bash completion (like when tab-completing branch names). The initial patch from Nelson Benítez León implements this by modifying the `for-each-ref` calls in `contrib/completion/git-completion.bash`, with the default remaining alphabetical sorting if unset.

So far, the discussion has focused on style and presentation rather than the technical merits. Kristoffer Haugsbakk provided detailed feedback on improving the patch's commit message to match Git conventions, covering aspects like tense, punctuation, and line wrapping. D. Ben Knoble later chimed in to endorse these suggestions, reinforcing the project's emphasis on documentation quality even for small changes.

The technical implementation itself remains unexamined at this point. The next expected step is for the author to submit a revised version addressing the style feedback, after which reviewers can evaluate the actual change. Two open items stand out: the need for test coverage (not included in the initial submission) and proper technical review of the ref-sorting mechanism once the presentation issues are resolved. The interaction highlights how even straightforward changes undergo careful scrutiny of both form and function in the Git project.
