This is a small but useful user experience improvement in the ongoing `imap-send` series. The patch makes credential prompts show both host and port (e.g., "outlook.office365.com:993") when asking for passwords, matching the behavior of `git send-email`. 

The change is straightforward - it modifies the credential helper's host field to include the port number using `xstrfmt()`. The author notes this makes credential helpers more specific and maintains consistency with other Git commands. Since `imap-send` always uses default ports (993 for IMAPS, 143 for IMAP) when none is specified, there's no need to handle a no-port case.

This is part of the larger v15`imap-send` series that adds OAuth2.0 support and fixes several bugs. While minor, this change improves consistency and helps users verify they're authenticating to the correct endpoint.
