This is a feature patch in the ongoing `imap-send` improvement series, adding command-line folder specification capability. 

The patch introduces a new `--folder` (or `-f`) option to `git imap-send`, allowing users to override the default IMAP folder configured in `imap.folder` at runtime. This provides flexibility for users who frequently need to send messages to different folders without modifying their configuration. The implementation maintains backward compatibility by falling back to the config value when no command-line folder is specified.

The changes include updates to both documentation files (clarifying that the config value serves as a fallback) and the core implementation in `imap-send.c` where a new `opt_folder` variable is added and processed. The patch follows the established pattern of the series, with clean integration into the existing option parsing framework.

As part of the well-reviewed v15 series that has addressed all major technical concerns, this patch appears ready for inclusion. It solves a clear usability pain point for `imap-send` users who work with multiple folders, complementing the other authentication and folder management improvements in the series.
