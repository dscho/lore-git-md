This is a platform compatibility patch updating build configuration for Solaris systems. Brad Smith proposes changes to `config.mak.uname` to better reflect the availability of certain functions across Solaris versions.

The patch makes several adjustments to the Solaris-specific build rules:
1. Removes blanket `NO_STRCASESTR`, `NO_MEMMEM`, and `NO_MKDTEMP` declarations that were previously applied to all Solaris versions
2. Adds version-specific checks for Solaris 5.10 and 5.11 (Solaris 10 and 11)
3. Shows that Solaris 10 gains `strtoumax()` while Solaris 11 additionally gains `mkdtemp()`, `memmem()`, and `strcasestr()`
4. Maintains backward compatibility by keeping older version checks intact

The changes appear well-researched and correctly scoped to the build system. The commit message is concise but covers the key points about which functions become available in which Solaris versions. This should help Git to better utilize native functionality on modern Solaris systems while maintaining compatibility with older versions.
