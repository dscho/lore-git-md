Feature addition to `git merge` and `git pull` commands. Junio Hamano proposes a new `--compact-summary` option that enhances the default diffstat output by explicitly noting created and deleted paths. 

Currently, merge operations show a standard diffstat summary that indicates changed files and their modification counts, but doesn't clearly mark which files are new or removed. The patch introduces an alternative output format that uses the same compact notation as `git diff --compact-summary`, where new files are marked with "(new)" and deleted files with "(gone)".

The implementation touches both merge and pull commands, adding the new option to their documentation and option parsing logic. The core change modifies the diff output generation in `builtin/merge.c` to use the compact summary format when requested. Tests verify the new behavior by comparing output against expected patterns.
