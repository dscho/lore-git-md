Documentation patch converting rev-list options to new format. This is the 5th patch in a 9-part series standardizing Git's man page synopses.

Jean-Noël Avila continues the `git-log` documentation conversion effort by updating `rev-list-options.adoc` to use the new AsciiDoc formatting conventions. The changes are mechanical but extensive (390 lines changed), consistently applying several syntax improvements:

1. Wrapping all option names in backticks for consistent rendering
2. Replacing angle brackets with underscores`_<placeholder>_` for placeholders
3. Adding the '%' character to the set of allowed keyword characters in the AsciiDoc configuration
4. Standardizing the formatting of complex option descriptions

The patch follows the same high-quality pattern seen in previous documentation conversions in this series. While purely mechanical, these changes improve consistency and prepare the documentation for future rendering improvements. The changes are limited to formatting - no content is altered.

This continues the systematic effort to bring all Git documentation to a uniform style, building on prior conversions of `git-log.adoc`, `rev-list-description.adoc`, and other related files. The remaining patches in the series will cover `pretty-formats.adoc` and `diff-options.adoc`.
