Documentation patch completing the `git-log` man page conversion series. This is the ninth and final patch in Jean-Noël Avila's series standardizing Git's documentation format, focusing on the log-related config options.

The patch converts the `log.*` configuration options documentation to the new AsciiDoc format, applying the same systematic changes seen in previous patches. Key changes include:
- Option names wrapped in backticks (e.g., `` `log.decorate` ``)
- Complex option descriptions reformatted as description lists (particularly noticeable for `log.decorate` which now clearly lists possible values)
- Command references standardized with backticks (e.g., `` `git log` `` instead of 'git log')

The changes are mechanical and consistent with the series' goal of uniform documentation formatting. With this patch, the entire `git-log` documentation ecosystem (man page plus related config and option docs) has been converted to the new standard format. The series demonstrates careful attention to detail, particularly in handling special cases like %-prefixed tokens and merge diff options in earlier patches.
