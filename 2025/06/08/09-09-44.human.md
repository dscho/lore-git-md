Documentation patch converting the `pretty-formats.adoc` file to the new standardized format, part of Jean-Noël Avila's ongoing man page conversion series. This is patch 7/9 in the series that aims to modernize the `git-log` documentation ecosystem.

The patch focuses on the pretty format placeholders section, which describes all the `%`-prefixed formatting codes used in `--pretty=format:` strings. The changes are mechanical but require special handling for the many parenthesized placeholders (like `%(decorate)` and `%(trailers)`), which need heavy escaping with `++` markers to prevent them from being interpreted as syntax elements. The conversion also standardizes the formatting of:
- Command names and options in backticks
- Placeholder names in `_<placeholder>_` format
- Literal `%` characters in format strings

The changes are extensive (283 lines modified) but purely presentational - no content is altered beyond the markup. The patch maintains the same careful attention to detail seen in previous patches of this series, with consistent application of the new documentation standards. This brings the pretty formats documentation in line with the rest of the converted `git-log` man page components.
