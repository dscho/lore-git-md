This thread documents the completion of Jean-Noël Avila's multi-patch effort to standardize Git's man pages using AsciiDoc synopsis format. The series, now in its third version, converts documentation for several key commands including git-log (the second-largest man page), rev-list options, line ranges, pretty-format options, and log configuration. 

The final patch addresses a subtle toolchain compatibility issue in pretty-formats.adoc, specifically around the %(decorate) format specifier. By adjusting the verbatim syntax markers (using double ++ instead of single + for certain elements), the patch ensures consistent rendering between Asciidoc.py and Asciidoctor 2.0.16. Jean-Noël provides a detailed technical explanation of the underlying issue - differing handling of {nbsp} in verbatim span detection - which Junio Hamano requested be included in the commit message for future reference.

Junio has approved the entire series for merging into the 'next' branch, marking the successful conclusion of this documentation standardization effort. The work has gone through three thorough iterations, with all identified formatting issues resolved and special attention paid to maintaining compatibility across documentation toolchains.
