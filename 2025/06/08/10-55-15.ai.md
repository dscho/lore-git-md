Feature patch adding command-line folder specification to `git imap-send`. This is part of a larger v15 series improving IMAP`-send` functionality, specifically addressing the ability to override the configured IMAP folder at runtime.

The patch introduces a new `--folder`/`-f` option that takes precedence over the `imap.folder` config value. The implementation stores the command-line value in `opt_folder` and if present, uses it to override `server.folder` after config parsing. Documentation updates clarify that the config value serves as a fallback when no command-line option is given, with examples showing both the config and command-line syntax.

Key technical details include:
- New `opt_folder` static variable to store command-line input
- Added `OPT_STRING` entry for the `--folder` option
- Logic to free and replace `server.folder` when `opt_folder` is set
- Documentation updates in both `imap.adoc` and `git-imap-send.adoc` explaining the precedence rules
- Usage string update to include the new option

This builds on the thread's earlier resolution of configuration parsing bugs (particularly around folder field handling) and maintains backward compatibility by falling back to config when no command-line folder is specified. The implementation is straightforward and aligns with the series' goal of making `imap-send` more flexible while maintaining robustness.
