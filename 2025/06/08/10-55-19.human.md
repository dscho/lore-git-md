This is the final patch in a 15-iteration series adding OAuth2.0 support and folder management to `imap-send`. The patch introduces a new `--list` option that shows available IMAP folders, addressing the common problem where different providers (Gmail vs Outlook) use different naming conventions for standard folders like Trash or Drafts.

The implementation works with both OpenSSL (using RFC6154-compliant IMAP LIST commands) and libcurl backends, showing raw protocol responses that include provider-specific folder names and attributes. For example, Gmail's Drafts folder appears as "[Gmail]/Drafts" while Outlook's is simply "Drafts". The output format matches what users would see when debugging with other IMAP clients.

This completes the series' goal of providing comprehensive IMAP functionality, joining earlier patches that added OAuth2.0 authentication, fixed configuration parsing bugs, and introduced folder override support. The implementation looks solid, with appropriate documentation updates and consistent error handling. As the culmination of a well-reviewed series, this patch appears ready for merging.
