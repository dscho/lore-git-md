This is a small but user-facing improvement to the `imap-send` credential prompt, part of the larger IMAP feature/bugfix series now in its 15th iteration. The patch modifies the credential helper prompt to include the port number alongside the hostname when requesting passwords, matching the behavior of `git send-email`. The change is minimal - just one line in `imap-send.c` that formats the host string to include the port - but provides better specificity for credential helpers. The implementation handles both explicit ports and defaults (993 for IMAPS, 143 for IMAP), though the commit notes the default case is always covered so no special handling is needed. This aligns with the series' broader focus on polishing user experience and standardizing behavior across Git's email components. The change is straightforward and unlikely to be controversial, completing one of the smaller items in the comprehensive IMAP overhaul.
