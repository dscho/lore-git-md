This is the 15th iteration of a feature and bugfix series for `git imap-send`, now ready for merging. The series makes the command usable again after a regression in Git 2.46.0, adds OAuth2.0 authentication support, and introduces several usability improvements.

The key changes in this version are purely organizational - patch 3 (CRAM-MD5 authentication fixes) has been moved earlier in the series as requested by Junio Hamano, with no code changes from v14. The series remains comprehensive, addressing:

1. A critical config parsing bug that made `imap-send` unusable (now patch 1)
2. Modern authentication methods (OAuth2.0 via both OAUTHBEARER and XOAUTH2 protocols, plus PLAIN auth for OpenSSL)
3. New folder management with `--folder` command-line override and `--list` option to discover available folders
4. Various UX improvements like better credential prompts and progress messages

The implementation works with both OpenSSL and libcurl backends and maintains backward compatibility. The series has undergone extensive review and appears polished, with thorough test coverage, consistent error message formatting, and complete documentation updates. This should provide a solid foundation for IMAP functionality in Git going forward.
