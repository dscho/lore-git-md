This is a feature patch introducing a new `--compact-summary` option for `git merge` and `git pull`. The patch comes from Git maintainer Junio Hamano.

The change adds a new output format option that builds on the existing diffstat shown after merges. While the current `--stat` output shows changed files and line counts, the new `--compact-summary` variant additionally marks created/deleted files with `(new)`/`(gone)` annotations. This provides more context about file operations without significantly increasing output size.

The implementation:
- Adds the option to both commands' documentation and option parsing
- Introduces a new `MERGE_SHOW_COMPACTSUMMARY` flag (value 2) alongside the existing `MERGE_SHOW_DIFFSTAT` (1)
- Modifies the diff output generation to use `DIFF_FORMAT_DIFFSTAT` with `stat_with_summary` flag when compact mode is selected
- Includes tests verifying the new output format shows the "(new)" marker for created files

The patch appears well-constructed with:
- Clear commit message explaining the motivation
- Comprehensive documentation updates
- Careful handling of the existing diffstat configuration
- New test cases that specifically check the compact summary output
- Symmetric implementation in both merge and pull commands

This builds on Git's existing diff machinery rather than inventing new formatting, suggesting it should be maintainable long-term. The change is focused and doesn't appear to introduce any backward compatibility concerns.
