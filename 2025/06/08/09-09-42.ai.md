Documentation patch continuing the conversion of Git man pages to the new synopsis format. This is patch 5/9 in the series, focusing on `rev-list-options.adoc`. The changes follow the established pattern seen in previous patches, with mechanical updates to option formatting and placeholder notation.

Key technical changes in this patch:
- Updates 390 lines in `rev-list-options.adoc` with consistent formatting
- Modifies AsciiDoc configuration files to handle the '%' character in option names
- Standardizes option syntax using backticks for commands/options and underscores for placeholders (e.g. `--since=<date>` becomes `--since=_<date>_`)
- Fixes malformed synopses and ensures consistent markup throughout
- Adds '%' to the set of characters recognized in keywords in both `asciidoc.conf.in` and `asciidoctor-extensions.rb.in`

The patch continues the systematic approach seen in earlier parts of the series, maintaining the high quality of mechanical conversions that preserve all existing content while applying the new documentation standards. No functional behavior changes are introduced - this is purely a documentation formatting update.
