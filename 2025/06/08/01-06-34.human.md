This is the first patch in a 2-part series from Ayush Chandekar as part of the `the_repository` removal effort, specifically targeting the `prune` builtin. The patch moves the `repository_format_precious_objects` global variable into `struct repository`, which is a prerequisite for removing `the_repository` usage from `prune.c` in the next patch.

The change affects several files that check whether a repository has the `extensions.preciousObjects` setting enabled, which prevents operations that might drop objects. The patch follows the established pattern for `the_repository` removal by first migrating globals into repository structs before eliminating dependencies. The mechanical changes look straightforward, updating all references to use `the_repository->repository_format_precious_objects` instead of the global variable.

This appears to be a well-scoped preparatory change that follows the project's established patterns for repository modernization. The patch touches core repository initialization paths (`setup.c`, `repository.c`) and three builtins (`gc.c`, `prune.c`, `repack.c`), but the changes are all simple variable access updates. The commit message clearly explains the motivation as part of the ongoing effort to eliminate globals and improve modularity.
