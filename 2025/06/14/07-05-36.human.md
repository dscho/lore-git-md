This is the test suite for the new `git refs list` subcommand, part of a 2-patch series introducing the feature as a Google Summer of Code project. The tests verify both the new functionality and backward compatibility with `git show-ref`.

The test script `t1461-refs-list.sh` contains 95 lines of thorough test coverage for the subcommand's core features: filtering with `--branches`, `--tags`, and `--head` flags, pattern matching behavior, and combinations of these options. A second test block specifically checks that `git refs list` produces identical output to `git show-ref` for equivalent invocations, ensuring backward compatibility for the currently supported flags.

The test setup creates a small repository with annotated tags and branches to exercise the various filtering cases. Tests follow Git's standard pattern of generating expected output and comparing against actual command results. The implementation appears well-tested for its current scope, though as noted in the RFC, some `show-ref` features like `--abbrev` and `--quiet` are intentionally omitted from this initial implementation.

This patch completes the initial RFC series, providing the testing foundation for the new subcommand while the open design questions about long-term direction remain under discussion. The tests will help validate any future changes as more features are added or the matching behavior evolves.
