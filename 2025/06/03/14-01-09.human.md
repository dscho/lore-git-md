Refactoring patch that converts the maintenance task array in `builtin/gc.c` to use designated field initializers. This is the first patch in Patrick Steinhardt's 12-part series addressing race conditions in Git's maintenance tasks.

The change makes the initialization of the `maintenance_task` struct array more explicit by naming each field (`.name`, `.fn`, `.auto_condition`, etc.) rather than relying on positional initialization. This improves maintainability when adding new fields to the struct in the future, as each field's purpose is clearly labeled.

While this is primarily a code quality improvement, reviewer Karthik Nayak noted it raises a broader question about whether the `-Wno-missing-field-initializers` compiler flag might be masking potential initialization bugs elsewhere in the codebase. The patch itself is straightforward and well-contained, touching only the task array in `builtin/gc.c`.
