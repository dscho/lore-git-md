Git v2.50.0-rc1 release candidate from Junio C Hamano, first preview of upcoming Git 2.50.0 version. Contains 592 non-merge commits from 84 contributors (33 new). Release highlights: new diff filters, cruft pack handling, TCP keepalive config, multi-pack index updates. Performance work includes repository instance usage improvements, fsck enhancements, refname optimization, merge-recursive deprecation. Build system updates. Numerous fixes since v2.49 covering ref handling, merge machinery, CI systems, platform-specific issues. Tarballs and repo locations provided for testing.

Platform compatibility issue affecting NonStop builds during testing, with two related problems: 1) Makefile unconditionally creates 'lib/tclIndex' despite missing TCL (regression in Makefile target line 200), and 2) generate-tclindex.sh fails during test phase due to missing required arguments (BUILD_DIR, BUILD_OPTIONS, LIBFILE). Randall S. Becker reports the failures, with Todd Zullinger confirming it appears to be a build system interaction problem rather than local configuration. The issue stems from extensive changes to git-gui build infrastructure between rc0 and rc1, including new build scripts (generate-tclindex.sh, generate-git-gui.sh), meson support, and Makefile restructuring (115 lines modified). Junio Hamano expresses concern these impactful changes should have gone through normal review before rc0. Johannes Sixt confirms the root issue occurs when ALL_LIBFILES is empty during generate-tclindex.sh execution, suggesting this might be a platform-specific path expansion problem on NonStop systems where wildcard expansion fails despite TCL files existing in source tree. The core problem appears when building without TCL/Tk (NO_TCLTK), where the build system still attempts to process non-existent TCL files, particularly when ALL_LIBFILES expands to empty causing generate-tclindex.sh to fail with usage message. This represents a regression in handling optional dependencies, with the fix likely involving proper NO_TCLTK case handling in the new build infrastructure. The discussion continues to determine whether this is purely a Git regression or involves environmental factors specific to NonStop systems, with Johannes Sixt directly asking Randall Becker to investigate why wildcard expansion fails in that environment.
