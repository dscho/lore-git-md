Git v2.50.0-rc1 release candidate from Junio C Hamano, first preview of upcoming Git 2.50.0 version. Contains 592 non-merge commits from 84 contributors (33 new). Release highlights: new diff filters, cruft pack handling, TCP keepalive config, multi-pack index updates. Performance work includes repository instance usage improvements, fsck enhancements, refname optimization, merge-recursive deprecation. Build system updates. Numerous fixes since v2.49 covering ref handling, merge machinery, CI systems, platform-specific issues. Tarballs and repo locations provided for testing.

Critical build system regression affecting NonStop systems when building without TCL/Tk (NO_TCLTK). Randall S. Becker identified the root cause: the official 2.50.0-rc1 tarball's git-gui/lib directory contains no .tcl files, causing `$(wildcard lib/*tcl)` expansion to return empty in git-gui/Makefile. This contradicts earlier assumptions about platform-specific wildcard expansion issues. The build system unconditionally attempts to process non-existent TCL files through generate-tclindex.sh, which fails when ALL_LIBFILES is empty. The problem stems from recent build infrastructure changes (new generate-tclindex.sh script, meson support, Makefile restructuring) that weren't properly tested in NO_TCLTK configurations. Johannes Sixt previously noted the issue occurs when ALL_LIBFILES is empty, but Randall's findings show this is due to missing source files rather than platform behavior. The regression appears in the interaction between the new build scripts and optional dependency handling, requiring fixes to either properly handle empty TCL file cases or ensure required files are included in releases. Junio Hamano had expressed concern these build system changes should have undergone normal review before rc0. The issue has shifted from being considered potentially platform-specific to a clear build system bug affecting all NO_TCLTK builds.
