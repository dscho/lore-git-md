Git v2.50.0-rc1 release candidate from Junio C Hamano, first preview of upcoming Git 2.50.0 version. Contains 592 non-merge commits from 84 contributors (33 new). Release highlights: new diff filters, cruft pack handling, TCP keepalive config, multi-pack index updates. Performance work includes repository instance usage improvements, fsck enhancements, refname optimization, merge-recursive deprecation. Build system updates. Critical build system regression affecting NonStop systems when building without TCL/Tk (NO_TCLTK).

Randall S. Becker identified the root cause: the official 2.50.0-rc1 tarball's git-gui/lib directory contains no .tcl files, causing `$(wildcard lib/*tcl)` expansion to return empty in git-gui/Makefile. This contradicts earlier assumptions about platform-specific wildcard expansion issues. The build system unconditionally attempts to process non-existent TCL files through generate-tclindex.sh, which fails when ALL_LIBFILES is empty. The problem stems from recent build infrastructure changes (new generate-tclindex.sh script, meson support, Makefile restructuring) that weren't properly tested in NO_TCLTK configurations. Johannes Sixt previously noted the issue occurs when ALL_LIBFILES is empty.

Patrick Steinhardt's investigation reveals a discrepancy - while Randall reports missing *.tcl files in the tarball's git-gui/lib, `git ls-tree` shows the v2.50.0-rc1 tag should contain numerous TCL source files there. This shifts the focus from wildcard expansion behavior to potential tarball generation or extraction problems. The issue now appears to involve release artifact corruption rather than build system logic, raising new questions about the distribution packaging process. The regression affects all NO_TCLTK builds but may originate earlier in the release pipeline than previously thought. Junio Hamano had previously expressed concern these build system changes should have undergone normal review before rc0.
