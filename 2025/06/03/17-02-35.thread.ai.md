Git v2.50.0-rc1 release candidate from Junio C Hamano, first preview of upcoming Git 2.50.0 version. Contains 592 non-merge commits from 84 contributors (33 new). Release highlights: new diff filters, cruft pack handling, TCP keepalive config, multi-pack index updates. Performance work includes repository instance usage improvements, fsck enhancements, refname optimization, merge-recursive deprecation. Build system updates. Critical build system regression affecting NonStop systems when building without TCL/Tk (NO_TCLTK).

Randall S. Becker identified the root cause as the build process deleting TCL files during NO_TCLTK builds, not a tarball generation issue as previously suspected. While `git ls-tree` shows TCL files should exist in git-gui/lib, they disappear when `generate-tclindex.sh` runs, failing with "tclsh: command not found". This behavior changed from Git 2.49, implicating the new generate-tclindex.sh script introduced in recent build system changes. The script appears to incorrectly modify source files during NO_TCLTK builds when it should skip TCL processing entirely.

Patrick Steinhardt's earlier investigation had revealed a discrepancy between Randall's report of missing *.tcl files in the tarball and `git ls-tree` showing they should be present, initially suggesting tarball corruption. The new evidence shifts focus to the build process itself, specifically the interaction between NO_TCLTK configuration and the new TCL index generation infrastructure. The regression affects all platforms building without TCL/Tk support. Johannes Sixt previously noted the issue occurs when ALL_LIBFILES is empty. Junio Hamano had expressed concern these build system changes should have undergone normal review before rc0. The problem now appears to be a clear build system bug where TCL processing incorrectly modifies source files in NO_TCLTK configurations.
