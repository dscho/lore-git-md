Git v2.50.0-rc1 release candidate from Junio C Hamano, first preview of upcoming Git 2.50.0 version. Contains 592 non-merge commits from 84 contributors (33 new). Release highlights: new diff filters, cruft pack handling, TCP keepalive config, multi-pack index updates. Performance work includes repository instance usage improvements, fsck enhancements, refname optimization, merge-recursive deprecation. Build system updates. Critical build system regression affecting NonStop systems when building without TCL/Tk (NO_TCLTK) was fixed by Johannes Sixt's patch correcting `generate-tclindex.sh` to properly handle `$@` in NO_TCLTK builds, preventing source file deletion. Randall Becker confirmed successful NonStop builds with the fix.

Johannes Sixt now contributes a major git-gui modernization series syncing with Git 2.50.1, raising minimum requirements to Tcl/Tk 8.6 and Git 2.36 while removing legacy compatibility code for ancient versions (<1.5.3 Git, <8.4 Tk). Key changes include SHA-256 repository support (Takashi Iwai), Bulgarian translation update (Alexander Shopov), process execution refactoring (Mark Levedahl), and elimination of `null_sha1`. The series builds on Sixt's earlier NO_TCLTK fix and touches nearly all git-gui components, with heavy modifications to `git-gui.sh` (877 lines) and Bulgarian translation (3608 lines). Mark Levedahl contributed 35/60 commits, focusing on process handling modernization and Windows compatibility. The changes remove technical debt while maintaining functionality, with the series already synchronized to Git 2.50.1 and ready for integration.
