Platform compatibility issue affecting NonStop builds during testing. Randall S. Becker reports build failures in two related cases: 1) Makefile unconditionally attempts to create 'lib/tclIndex' despite TCL being unavailable on NonStop (regression in Makefile target line 200), and 2) generate-tclindex.sh fails during test phase due to missing required arguments (BUILD_DIR, BUILD_OPTIONS, LIBFILE). The errors occur around git-gui components and suggest improper handling of TCL dependencies in the build system, representing a regression from previous versions' behavior. Todd Zullinger confirms the issue appears to be a build system interaction problem rather than local configuration, suggesting NO_TCLTK settings may not be properly respected. The discussion focuses on determining whether this is a regression in Git's build logic or an environmental change on NonStop systems, with implications for proper handling of optional dependencies across platforms. Detailed error output remains available for both failure cases, with the core problem being TCL-related build steps executing when they should be skipped on NonStop systems.
