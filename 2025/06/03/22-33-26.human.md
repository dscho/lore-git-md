This is a platform compatibility report regarding the Git v2.50.0-rc1 test suite. Randall Becker reports a build failure on NonStop systems when the test suite attempts to build Tcl-related components, which aren't available on their platform. The error occurs during the `lib/tclIndex` target in the Makefile.

The issue appears to be a missing dependency check for Tcl in the build system, causing the test suite to fail on platforms where Tcl isn't installed. Randall suggests suppressing this requirement since Tcl isn't essential for their use case. This is a straightforward build system issue that maintainers will likely want to address before final release, either by making Tcl optional or improving the platform detection.

The report is concise but provides enough detail to reproduce (the specific Makefile target and error message) and indicates this affects NonStop systems specifically. Since this is a release candidate, such platform-specific build issues are exactly what testers are encouraged to report.
