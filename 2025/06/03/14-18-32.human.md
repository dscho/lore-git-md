This is a test modernization patch in the reftable test conversion series. Patrick Steinhardt provides review feedback on Seyi Kuforiji's patch that converts the reftable block test to use the Clar framework.

The main points are:
1. The test function name `test_reftable_block__index_read_write` is incorrect since it tests ref blocks, not index blocks.
2. Assertions could be made more idiomatic - either using `cl_assert(!ret)` for boolean checks or `cl_assert_equal_i()` for numeric comparisons to provide better diagnostics.

This is a minor refinement in the final stages of the reftable test conversion series, which is otherwise ready for integration. The feedback focuses on small consistency improvements rather than any fundamental issues with the test conversion approach.
