This is the second patch in a two-part series completing the project-wide standardization of BUG() messages. While the first patch addressed a memory leak in the sequencer, this one is a mechanical change removing gettext wrappers from BUG() calls in three files (builtin/mktag.c, builtin/worktree.c, and pack-bitmap-write.c).

The change enforces the project's policy that BUG() messages (which target developers rather than end users) should not be translated. Each modification simply removes the `_()` wrapper while keeping the actual error message text identical. The affected cases include an FSCK validation check, an unreachable code path for invalid references, and a bitmap consistency check.

Junio C Hamano notes this patch is unrelated to the sequencer changes from part 1 and will queue them separately. The changes are straightforward and non-controversial, having gone through multiple review iterations in previous versions of the series. This completes the BUG() standardization effort that establishes clear guidelines for future contributions.
