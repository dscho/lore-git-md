Refactoring patch as part of the `the_repository` removal effort. Ayush Chandekar moves the `core.sparsecheckout` configuration from a global variable to the `repo_settings` struct, continuing Git's ongoing effort to eliminate globals and improve code modularity.

The patch introduces new getter/setter functions `repo_settings_get_apply_sparse_checkout()` and `repo_settings_set_apply_sparse_checkout()`, then updates all call sites across 14 files to use these instead of directly accessing the global. This includes changes to core commands like `clone`, `mv`, and `sparse-checkout`, plus supporting infrastructure in `dir.c` and `unpack-trees.c`.

A notable side effect is removing the need for `USE_THE_REPOSITORY_VARIABLE` in `builtin/backfill.c`. The changes appear mechanical and well-scoped, with no behavioral changes intended - this is purely about moving where the setting is stored. The patch follows the established pattern for similar migrations in the codebase.
