Refactoring patch that converts the maintenance task array in `builtin/gc.c` to use designated field initializers. This is the first patch in Patrick Steinhardt's 12-part v4 series addressing maintenance task execution race conditions and code quality improvements.

The change replaces positional initialization of the `maintenance_task` struct array with named field initializers, making the code more maintainable when adding new fields. All maintenance tasks (`prefetch`, `loose-objects`, `gc`, etc.) are updated to explicitly name each field (`name`, `fn`, `auto_condition`, `enabled`). The diff shows a straightforward mechanical conversion with no behavior changes.

Karthik Nayak previously noted this change raises a broader question about whether the `-Wno-missing-field-initializers` compiler flag might mask initialization bugs elsewhere in the codebase. The patch is part of the series' foundational infrastructure work, establishing cleaner type patterns before subsequent patches refactor task execution phases and locking behavior.
