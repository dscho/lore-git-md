This is the second patch in Lidong Yan's v4 series, completing the project-wide standardization of BUG() messages by removing gettext wrappers from the few remaining instances. The patch mechanically converts three BUG() calls in builtin/mktag.c, builtin/worktree.c, and pack-bitmap-write.c from `BUG(_("..."))` to `BUG("...")` format, maintaining the exact same message content but removing the translation markers.

The changes are straightforward and non-controversial, affecting error paths that should never be hit in normal operation: an FSCK callback for an invalid message type, an unreachable code path in worktree creation, and a bitmap writing consistency check. Junio C Hamano notes he will queue this separately from the first patch (which addressed the sequencer memory leak) since they are logically distinct changes.

This patch finalizes the project's stance that BUG() messages (targeting developers) should not be translated, while preserving proper error handling for end-user messages. The changes are purely mechanical with no behavior impact beyond improved debug messaging consistency. The series has reached consensus with all feedback addressed, and this patch represents the completion of the BUG() standardization effort.
