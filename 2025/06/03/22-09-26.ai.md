This is a refinement of the final patch in a v4 series addressing memory leaks in pack-bitmap.c's boundary traversal logic. Taylor Blau provides detailed review feedback on Lidong Yan's patch that unconditionally frees `roots_bitmap` in `find_boundary_objects()` to fix a leak when `cascade_pseudo_merges_1()` succeeds.

Key technical clarifications include:
- Corrects the explanation of when pseudo-merges are satisfied (bitmap subset relation rather than size comparison)
- Notes unnecessary configuration of `stableThreshold` in the test case
- Recommends against single-quotes in test scripts
- Questions the test's use of `GIT_TEST_PACK_USE_BITMAP_BOUNDARY_TRAVERSAL` instead of repository configuration
- Suggests alternative test assertion styles using direct numeric comparison

The feedback maintains the core technical approach (unconditional `bitmap_free`) while refining test implementation details. Taylor provides specific alternative implementations for both the configuration approach (suggesting `pack.useBitmapBoundaryTraversal` instead of environment variable) and test assertions (preferring numeric comparison over file-based `test_cmp`).

This represents final polish on a technically sound series, with all major architectural decisions already settled in prior rounds. The remaining issues are minor test implementation details that don't affect the core memory leak fix but could improve long-term test maintainability.
