This is a bugfix patch that's part of a finalized series addressing memory leaks and BUG() message standardization in Git's sequencer. The patch specifically converts an error() call to BUG() in the `update_squash_messages()` function, which handles squash and fixup operations during interactive rebase.

The change enforces that the function should only receive TODO_SQUASH or TODO_FIXUP commands - any other input is now treated as a programming error rather than a runtime error. The new BUG() message clearly states the expected command types, following feedback from Junio C Hamano to make the API contract more explicit.

This is a mechanical change that improves code correctness and maintainability. The patch is well-contained and follows the series' goal of standardizing BUG() usage while fixing a memory leak issue in the sequencer.
