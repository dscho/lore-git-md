This is a bugfix patch addressing a compiler warning. Mike Hommey fixes a "maybe-uninitialized" warning that appears when compiling with GCC at -O3 optimization level. The warning occurs in `parse-options.c` where the `arg` variable could potentially be used uninitialized in the error handling path.

The fix is straightforward - initializing `arg` to NULL where it's declared. This is a small but correct change that silences the compiler without changing any behavior, since the error path would have exited early anyway. The patch is clean and focused, touching just one line in one file.

While not a functional bug (the uninitialized value wouldn't actually be used in practice), such warnings can mask real issues in other cases, so it's good hygiene to address them. This appears to be part of a 4-patch series, though the cover letter wasn't provided to see the broader context.
