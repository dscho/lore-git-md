This is the second patch in a two-part series completing the project-wide standardization of BUG() messages. The patch mechanically converts the remaining instances of `BUG(_("..."))` to `BUG("...")` in three files: builtin/mktag.c, builtin/worktree.c, and pack-bitmap-write.c.

The change enforces the established convention that BUG() messages (which target developers rather than end users) should not be translated. This follows the same principle applied in the first patch of the series for the sequencer code. The modifications are straightforward string literal changes with no behavioral impact.

The patch completes the series' goal of removing translation markers from all BUG() assertions across the codebase. Each change replaces a localized error string with its direct English equivalent, maintaining the same diagnostic information while removing the gettext wrapper. The changes affect error paths that should theoretically never be reached (invalid FSCK states, unreachable code paths, and bitmap consistency checks).

This final patch appears to be a clean mechanical conversion with no outstanding issues, following the discussion and refinements made to the series. It implements the last piece of the BUG() standardization effort that was previously agreed upon in the thread.
