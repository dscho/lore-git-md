Junio C Hamano has released Git v2.50.0-rc1, the first release candidate for the upcoming 2.50.0 version, with 592 commits from 84 contributors. The release includes new diff filters, cruft pack improvements, TCP keepalive configuration, and various performance optimizations.

During testing, Randall S. Becker reported a build failure on NonStop systems where the build process attempts to create 'lib/tclIndex' despite TCL being unavailable on that platform. The error occurs during test execution when generate-tclindex.sh fails due to missing required arguments. This appears to be a regression in how the build system handles TCL dependencies, specifically affecting git-gui components on platforms without TCL installed. Randall has provided detailed error output showing the problematic Makefile line and script invocation, suggesting the issue requires maintainer attention to either make TCL properly optional or implement correct platform detection.

The problem follows a pattern where platform-specific build issues often surface during release candidate testing, though NonStop represents a less common configuration. The build system may need adjustments to either skip TCL-related targets when appropriate or provide proper fallback behavior, as the current implementation doesn't gracefully handle this case.
