Git 2.50.0-rc1 introduced a build system regression affecting NonStop platforms when building without TCL/Tk support (NO_TCLTK), where source files were incorrectly deleted during the build process. The issue was traced to a change in TCL index generation infrastructure that misinterpreted Makefile syntax. Johannes Sixt provided the definitive fix by correcting the problematic `rm` command in `generate-tclindex.sh`.

Randall Becker has now confirmed the fix works on NonStop systems, marking the regression as resolved. The thread also included discussion of packaging approaches, with Todd Zullinger explaining Fedora's use of config.mak for consistent builds while noting that command-line make variables remain the preferred method for one-off builds. With the core issue addressed and verified, this build system problem is now closed ahead of the final 2.50.0 release.
