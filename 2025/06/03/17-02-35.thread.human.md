Junio C Hamano has released Git v2.50.0-rc1, the first release candidate for the upcoming 2.50.0 version, with contributions from 84 developers. The release includes new diff filters, cruft pack handling, and performance improvements, but a critical build system regression has emerged affecting NonStop systems when building without TCL/Tk support. The bug causes `generate-tclindex.sh` to incorrectly delete TCL source files during NO_TCLTK builds rather than just cleaning up tclIndex, a behavior change from Git 2.49.

After Randall S. Becker reported missing TCL files, Johannes Sixt identified the root cause in the new TCL index generation infrastructure. Two potential fixes are being considered, while Junio acknowledges this was a clear oversight that slipped through review. For immediate testing, Junio confirms users can pass `NO_TCLTK=NoThanks` either as a make command-line argument or in config.mak to skip building gitk and git-gui, providing a workaround until the proper fix is implemented before final release. The regression is considered critical but now has a known mitigation path while the core issue is addressed.
