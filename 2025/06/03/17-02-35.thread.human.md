Junio Hamano has released Git v2.50.0-rc1, the first release candidate for the upcoming 2.50.0 version, featuring 592 commits from 84 contributors. The release includes new diff filters, cruft pack handling, and various performance improvements. However, a build system issue has emerged affecting NonStop systems when building without TCL/Tk support.

The problem initially appeared to be platform-specific, with Randall Becker reporting failures during testing where the build system incorrectly tried to process TCL files even when TCL wasn't available. Further investigation by Randall revealed the core issue: the official release tarball is missing the expected TCL files in the git-gui/lib directory, causing the build system's wildcard expansion to fail. This contradicts earlier assumptions about platform-specific behavior and points to a general regression in how the build system handles optional TCL/Tk dependencies.

The discussion has shifted from diagnosing a NonStop-specific issue to recognizing a broader build system problem that needs fixing before the final release. The changes to git-gui's build infrastructure between rc0 and rc1, including new scripts and meson support, weren't properly tested in NO_TCLTK configurations. Johannes Sixt and others are now working to determine the best way to address this regression.
