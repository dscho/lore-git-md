This is a maintainer follow-up in the ongoing pack-bitmap memory leak fix series. Junio Hamano is reviewing the test case added in v3 of the patch, which verifies the boundary traversal fix for bitmap pseudo-merges.

Junio questions whether the test properly exercises the boundary traversal path, noting that the environment variable `GIT_TEST_PACK_USE_BITMAP_BOUNDARY_TRAVERSAL` is set but not exported in the test script. He suggests this might mean the test isn't actually testing what it claims to test, since the variable wouldn't propagate to child processes without being exported.

This comes after the series has already addressed shell portability concerns by removing `export` commands entirely in v3. The test creates a simple commit topology (A and B) with pseudo-merge config and attempts to verify bitmap functionality across the boundary. The core memory leak fix itself (unconditionally freeing `roots_bitmap`) has already been reviewed and approved, with this being the final verification step before integration.
