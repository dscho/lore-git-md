This is a refactoring patch in Patrick Steinhardt's v4 series (12 patches) that improves maintenance task execution. The change focuses on fixing the typedef declarations for function pointers in `builtin/gc.c`.

The patch corrects the typedefs for `maintenance_task_fn` and `maintenance_auto_fn` to properly declare them as function pointer types. Previously, these typedefs were not true function pointers, requiring users to manually add pointer syntax when using them. The change makes the code more type-safe and clearer by:
- Adding the pointer syntax to both typedefs
- Updating the struct field declarations to use the corrected types
- Maintaining identical runtime behavior while improving compile-time type checking

This is a mechanical change that affects all maintenance tasks (`prefetch`, `loose-objects`, `gc`, etc.) but doesn't modify their functionality. The patch is part of the series' systematic code quality improvements, following earlier patches that addressed global state elimination and task execution modularization. It prepares for upcoming work by ensuring proper type safety in the maintenance task infrastructure.
