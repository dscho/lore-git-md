Git for Windows 2.50.0-rc0 release announcement by Johannes Schindelin, bundling upstream Git v2.50.0-rc0 core with Windows-specific components including MinTTY 3.7.8, OpenSSH 10.0.P1, and cURL 8.14.0 built on MSYS2/Cygwin 3.6.2. Fixes for Windows-specific regressions: file writing failures on ReFS drives (regressed in v2.48.1), fetching long branches with core.longPaths enabled, and installer's custom editor test file writability. Provides SHA-256 checksums for 11 distribution formats covering 64-bit/ARM64 installers, portable packages (7z), MinGit (standard/BusyBox, 32/64-bit), and tarballs. Standard release candidate announcement following Git for Windows packaging and verification practices.
