This thread documents a successful refactoring effort to eliminate global variables related to sparse-checkout configuration, part of the broader `the_repository` removal initiative. The series, now in its fifth version, was authored by Ayush Chandekar with significant review input from Junio Hamano and others.

The changes move sparse-checkout settings from global variables into either the `repo_settings` struct (for configuration that needs repository-wide access) or local function scope (for single-use variables). The final patch focuses on `sparse_expect_files_outside_of_patterns`, which was localized to the single function that uses it, eliminating the last remaining sparse-checkout global. The series demonstrates two complementary approaches to removing globals - migration to repository settings and complete localization - while carefully ensuring proper initialization sequencing.

Junio Hamano provided key architectural guidance throughout, particularly around initialization safety, and identified a final whitespace issue that was promptly fixed. With all review feedback addressed and no outstanding concerns, this series appears ready for merging. It represents a significant step in the ongoing effort to eliminate `the_repository` global while providing a model for future similar migrations. The changes are purely structural with no behavioral impact on sparse-checkout functionality.
