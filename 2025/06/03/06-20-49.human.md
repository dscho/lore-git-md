Bugfix addressing a bitmap memory leak in boundary traversal. This is the fourth version of a patch series that fixes a memory leak in `pack-bitmap.c`'s `find_boundary_objects()` function, where `roots_bitmap` wasn't being freed when `cascade_pseudo_merges_1()` succeeded. The patch removes the conditional check and always frees the bitmap, while adding a test case to verify the fix.

The test creates a scenario with two commits (A and B) where commit A is added to a pseudo-merge list, then verifies the bitmap traversal works correctly between HEAD~1 and HEAD. The v4 revision addresses Junio Hamano's feedback about environment variable handling by moving the `GIT_TEST_PACK_USE_BITMAP_BOUNDARY_TRAVERSAL` setting directly into the `git rev-list` command line rather than setting it as a separate environment variable.

The patch appears technically sound, with the memory management fix being straightforward and the test case well-constructed to exercise the boundary condition. The series has gone through multiple rounds of review, with all prior technical concerns addressed, and now appears ready for inclusion pending final verification of the test environment handling.
