This is a v4 patch series that finalizes two cleanups related to BUG() message formatting and sequencer error handling, following maintainer feedback on the v3 series.

The first patch updates the sequencer's `update_squash_messages()` function to use BUG() instead of error() for invalid command types, incorporating Junio Hamano's suggestion to make the message more explicit by stating "not a FIXUP or SQUASH" rather than just "unknown command". This change better reflects the function's expectations and maintains consistency with Git's error handling practices.

The second patch completes the mechanical conversion of remaining `BUG(_("..."))` instances to `BUG("...")` across several files (builtin/mktag.c, builtin/worktree.c, and pack-bitmap-write.c), enforcing the project's standard that developer-facing assertions should not be translated.

The series appears ready for merging, having addressed all previous review feedback and maintaining the same scope as v3 with only minor wording improvements. The changes are straightforward and uncontroversial, representing the final polish on a cleanup effort that has already gone through multiple rounds of review.
