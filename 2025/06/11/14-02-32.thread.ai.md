[PATCH] ci: show Coverity build logs on analysis failure

This patch modifies the GitHub Actions workflow for Coverity static analysis to display build logs when the analysis fails. The change affects `.github/workflows/coverity.yml`, adding error handling around the `cov-build --dir cov-int make` command. When the build fails (non-zero exit status), the contents of `cov-int/build-log.txt` are now output before propagating the error. This improves debugging by making the failure root cause immediately available rather than just showing a generic error. The modification is self-contained with no dependencies or follow-up work anticipated. The change follows established CI debugging patterns where automated processes provide detailed logs on failure. No technical objections or alternative approaches have been raised in the thread.
