This is a CI/build system patch series addressing Windows-specific issue with Coverity builds. The cover letter explains that recent Coverity releases (2025.3) are causing build failures on Windows due to DLL name conflicts between Coverity's binaries and Git for Windows' SDK. The author identifies that Coverity's DLLs are overriding MSYS2's DLLs, disrupting MSYS2's path resolution logic.

The series contains two patches: the first fixes the DLL conflict issue, while the second improves debugging by ensuring build logs are output on failure. The changes are focused on the GitHub Actions workflow file (`coverity.yml`), suggesting this is a relatively straightforward configuration fix rather than deep code changes.

Key technical details for future reference:
- Problem stems from DLL name collisions in Coverity/bin/ vs Git for Windows SDK
- Specifically affects MSYS2's root directory detection logic
- Changes are contained in `.github/workflows/coverity.yml`
- Second patch adds build log output for debugging future failures

The patch appears well-motivated by actual build failures and provides both a fix and improved diagnostics. The author's investigation seems thorough, noting the Coverity release version and its unusual Java bundling behavior, though this isn't directly relevant to the fix.
