Git for Windows 2.50.0-rc2 release announcement from the Git for Windows maintainer, targeting package maintainers and the Git mailing list. This platform-specific update focuses on dependency upgrades and regression fixes rather than new features. Key updates include Git v2.50.0-rc2, MinTTY 3.7.8, OpenSSH 10.0.P1, cURL 8.14.1, and MSYS2 runtime (Cygwin 3.6.3). Notable bugfixes address: file operation failures on ReFS drives (regression since v2.48.1 on Windows Server 2022), fetch behavior with long branch names when core.longPaths is enabled, and installer writability issues in custom editor test files. Release includes SHA-256 checksums for eleven distribution formats covering 64-bit/32-bit architectures (including ARM64), portable versions, MinGit distributions (regular and BusyBox variants), and traditional tarballs. Maintains focus on enterprise Windows environments with specific attention to Windows Server 2022 compatibility.
