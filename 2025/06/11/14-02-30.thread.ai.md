CI/Windows Coverity Build Fix Summary:

This thread addresses Windows-specific Coverity build failures caused by DLL name conflicts between Coverity 2025.3 binaries and Git for Windows SDK. The issue manifests when Coverity's DLLs override MSYS2's, breaking MSYS2 path resolution. The series contains two configuration patches targeting `.github/workflows/coverity.yml`:
1. Fixes DLL conflict by adjusting PATH ordering to prioritize MSYS2 binaries
2. Adds build log output on failure for better debugging

The problem is specific to Windows CI environments using recent Coverity versions, with no impact on core Git functionality. The changes are contained to GitHub Actions workflow configuration, requiring no modifications to Git's source code. The second patch provides forward-looking diagnostics should similar issues arise.
