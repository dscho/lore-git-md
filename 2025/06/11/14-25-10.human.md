This is a CI configuration patch that improves debugging for Coverity build failures on Windows. It's the second in a two-patch series addressing Windows-specific Coverity build issues.

The patch adds build log output when Coverity's analysis fails, making it easier to diagnose problems. The change is straightforward - it wraps the `cov-build` command in a conditional that prints `cov-int/build-log.txt` before exiting if the build fails. This addresses a practical debugging need that wasn't covered in the original configuration.

Junio Hamano indicates he will queue both patches in the series, suggesting the changes are technically sound and ready for inclusion. The patch builds on the previous PATH ordering fix (1/2) that resolved DLL conflicts between Coverity and MSYS2 binaries. Together, these changes improve both reliability and debuggability of Windows CI runs under Coverity.
