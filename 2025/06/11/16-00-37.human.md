Maintainer approval for stash branch name fix. Junio C Hamano gives final sign-off on K Jayatheerth's patch correcting the branch name display in stash messages when working with submodules. The fix uses `xstrdup()` to preserve the superproject's branch name before it gets overwritten by subsequent submodule operations.

Junio notes one remaining issue - the patch still contains trailing whitespace despite the author's claim of having used a pre-commit hook to remove it. The maintainer clarifies that such hooks only detect whitespace errors rather than automatically fixing them. However, this is a minor stylistic issue that doesn't block the patch's acceptance.

The patch has now cleared all technical and stylistic hurdles through multiple review rounds, with improvements to memory management, test coverage, and code structure. Junio indicates it will be queued for inclusion in the main Git repository, marking the successful conclusion of this bugfix effort that began with Stuart MacDonald's original report of branch name corruption in stash messages.
