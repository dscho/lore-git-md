This thread addresses a regression in byte-swapping macros that caused test failures on big-endian s390x systems. The problematic change modified `compat/bswap.h` to use compiler built-in byte-swap functions universally, breaking Git's assumption that these macros should only be defined on little-endian systems. This assumption is used to properly redefine network-to-host byte order macros (`ntohl/ntohll`).

The fix cleanly reverts the change, removing the compiler built-in detection logic and restoring the previous behavior where byte-swap macros are only defined for x86/x86_64 architectures when using GCC.
