This thread introduces a platform compatibility improvement to better handle byte order detection across different compilers. The patch series (currently at 2/6) adds support for the `__BYTE_ORDER__` macro in `compat/bswap.h`, providing a more reliable way to determine endianness when neither platform-specific nor libc-provided macros are available. The change specifically targets GCC, Clang, and ICC compilers while noting that Microsoft's MSVC still lacks this support. The implementation cleanly integrates with Git's existing byte order detection system, maintaining all current fallback paths while adding this new compiler-provided option. The modification is limited to the compatibility layer and doesn't affect core functionality, making it a focused improvement for better cross-platform support.
