Performance refactoring in the byte-swapping series, removing x86-specific optimizations now handled well by modern compilers. Patch 5/6 from Sebastian Andrzej Siewior's series eliminates hand-written x86 bswap32/64 assembly implementations, showing through compiler version testing that current GCC/Clang/MSVC versions (even relatively old ones) optimize the default shift-based implementations to equivalent machine code. The change removes 40 lines of platform-specific code while maintaining the same performance characteristics, simplifying maintenance. The patch keeps MSVC's built-in `_byteswap_uint64()` but removes all other architecture-specific paths, trusting compiler optimizations that have matured since Git's original hand-tuned versions were written. This continues the series' trend of removing special cases while preserving correctness and performance.
