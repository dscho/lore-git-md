Performance optimization patch reintroducing built-in byte-swap support in Git's bswap.h infrastructure. This is the final patch in Sebastian Andrzej Siewior's series addressing byte-order handling regressions on big-endian systems.

The patch carefully brings back compiler built-in optimizations for byte swapping (bswap32/bswap64) that were previously removed, now that the series has properly fixed the big-endian regression issues. It uses `__builtin_bswap` functions when available (GCC 10+/Clang 10+), which is particularly beneficial for architectures like RISC-V and MIPS where the shift-based implementation would otherwise generate many instructions. The change includes a fallback for older compilers that don't support the `__has_builtin` check.

This completes the series' goal of maintaining performance while fixing correctness, particularly for big-endian systems. The implementation is now more robust, handling both modern compiler optimizations and platform-specific needs. The patch shows good attention to compatibility details with the compiler version checks and maintains the series' careful approach to platform differences.
