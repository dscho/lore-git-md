This is a follow-up in the `git repo-info` feature development thread, specifically addressing documentation needs for the new command. Karthik Nayak responds to Lucas Seiki Oshiro's initial patch (1/5 in the series) that introduced the basic scaffolding for the `repo-info` command.

The key point raised is that while the patch adds the command to build systems and core files (Makefile, meson.build, builtin.h, git.c, .gitignore), it's missing the corresponding documentation in Documentation/git-repo-info.adoc. This is a standard requirement for new Git commands to ensure users can understand the feature's purpose and usage.

The thread context shows this is part of a well-received GSoC project to extract repository metadata functionality from `git rev-parse` into a dedicated command. The implementation has progressed with positive feedback, particularly around the JSON output format, though there are open questions about plaintext formatting safety. This documentation addition would complement the already strong technical implementation with the expected user-facing docs.
