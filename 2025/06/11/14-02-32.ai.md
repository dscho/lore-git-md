This is a CI/build system patch that modifies the Coverity workflow to show build logs when analysis fails. 

The change updates GitHub Actions' `coverity.yml` to output the contents of `cov-int/build-log.txt` when `cov-build` fails. This follows the common pattern of providing more debugging information when automated processes fail.
