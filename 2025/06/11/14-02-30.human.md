This is a CI/build system patch series addressing Windows-specific Coverity scan failures. Johannes Schindelin identifies that recent Coverity releases (2025.3) are causing build failures on Windows due to DLL name conflicts between Coverity's binaries and Git for Windows' SDK. The conflict interferes with MSYS2's path resolution logic.

The two-patch series does two things: first it fixes the DLL conflict issue, and second it improves debugging by ensuring build logs are output when failures occur. The changes are focused on the GitHub Actions workflow file for Coverity scans.

The patch appears well-justified with clear technical details about the root cause (DLL path conflicts) and links to the failing builds. The additional logging improvement is a sensible debugging enhancement that follows naturally from diagnosing the initial issue. This looks like a straightforward maintenance fix for Windows CI infrastructure.
