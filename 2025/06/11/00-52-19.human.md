Part 5/6 in the submodule remote lookup refactoring series. This is a pure code movement patch that relocates the `get_default_remote_submodule()` function in `builtin/submodule--helper.c` to sit after `resolve_relative_url()`. The change is motivated by upcoming work that will make `get_default_remote_submodule()` depend on `resolve_relative_url()`, and this preparatory move keeps the logical flow clear when that dependency is introduced.

The patch makes no functional changes - it simply cuts and pastes the function definition to a new location in the file, with identical implementation. This is part of Jacob Keller's ongoing effort to improve submodule remote handling, building on previous patches that introduced better fallback remote name handling and fixed related crashes. The series has shown careful attention to maintaining clean commit history and logical separation of changes.
