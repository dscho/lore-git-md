This thread discusses a refactoring effort to remove platform-specific byte swapping optimizations for x86 architectures. The series author has demonstrated through testing that modern compilers (GCC 4.5+, Clang 3.0+, and recent MSVC) can automatically optimize generic shift-based implementations to use efficient CPU instructions, making the hand-optimized x86 assembly redundant.

The current patch (5/6 in the series) specifically removes 40 lines of x86-specific inline assembly from `compat/bswap.h` while retaining the MSVC intrinsic path and fallback implementations. The change affects the `bswap32` and `bswap64` macros used throughout Git's codebase. The commit message includes thorough compiler version testing results to justify the removal, showing this is a well-researched simplification that aligns with Git's trend of relying on compiler optimizations where possible.
