This is a v4 patch series extending the promisor-remote protocol to support configurable validation of remote attributes during clone/fetch operations. The series builds on previous versions that were extensively reviewed, with all major design points now settled.

The key changes in v4 are:
1. Replaced the linked list storage with a `struct string_list` holding `struct promisor_info` instances (per Junio's suggestion)
2. Consistently uses "field name" terminology instead of just "fields"
3. Improved documentation formatting with bullet points
4. Added handling for empty fields in config parsing
5. Switched to `test_config` in tests for better cleanup

The series adds server-side advertisement of remote attributes (controlled by `promisor.sendFields`) and client-side validation (via `promisor.checkFields`). Currently only "partialCloneFilter" and "token" fields are supported. The implementation maintains backward compatibility while adding stricter validation capabilities.

This appears to be a well-polished version addressing all previous feedback, with thorough documentation and test coverage. The changes are focused and clearly explained in the commit messages. The series is ready for final review and likely merge.
