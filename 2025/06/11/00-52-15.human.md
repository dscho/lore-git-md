This is a refactoring patch that's part of a 6-part series improving Git's submodule remote lookup logic. Jacob Keller moves two path-matching helper functions (`starts_with_dot_slash` and `starts_with_dot_dot_slash`) from being duplicated in both `submodule--helper.c` and `submodule-config.c` into `dir.h` as static inline functions. 

The change eliminates code duplication while maintaining the same functionality. The author considered but decided against renaming the functions to include a `_platform` suffix, finding it too verbose. The commit message explains this is preparatory work for later submodule refactoring that will use these helpers earlier in `submodule--helper.c`.

The patch is clean and straightforward - it moves code with no behavior changes, adds proper documentation comments, and removes the duplicate implementations. As the first in a series, it sets up infrastructure for subsequent patches that will build on this shared functionality. The commit message clearly explains both the technical change and the reasoning behind naming decisions.
