This is a bugfix reverting a problematic change to byte-swapping macros that caused test failures on s390x (big-endian) systems. The patch reverts commit 6547d1c9, which had modified `bswap.h` to use compiler built-in swap functions when available, regardless of endianness. 

The change broke an assumption elsewhere in the code that these macros would only be defined on little-endian systems, leading to test failures in `t4014-format-patch.sh` and others. The revert cleanly removes the built-in function support while preserving the previous working state.

The patch appears well-justified - it clearly identifies the regression and provides a straightforward solution. As the first in a 6-patch series, it likely sets up subsequent improvements to the byte-swapping infrastructure, though without seeing the cover letter we can't say what those might be. The change is narrowly focused and touches only the compatibility header file.
