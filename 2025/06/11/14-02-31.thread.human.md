This thread addresses a CI build issue affecting Coverity scans on Windows. The first patch in a 2-patch series fixes a problem where newer Coverity Windows binaries conflict with Git for Windows' SDK when their `bin/` directory is prepended to `PATH`, causing build failures with missing `windows.h` errors. The solution is to append the Coverity binaries to `PATH` instead, following current Coverity documentation. The change is minimal (a single line in `.github/workflows/coverity.yml`) but resolves a significant build problem that was producing cryptic errors. The commit message provides detailed technical background about the DLL conflict and includes the error output that motivated the fix.
