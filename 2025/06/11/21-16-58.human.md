This is a documentation patch updating Git's CodingGuidelines to explicitly recommend letting BSS handle zero-initialization of global variables rather than doing it manually.

Junio Hamano notes this has been mentioned in code reviews but wasn't formally documented. The change adds a clear guideline that global variables should not be explicitly initialized to 0 or NULL, since the BSS segment automatically zero-initializes them anyway. This matches existing practice of using NULL (not 0) for null pointers, which is also mentioned in the adjacent guidelines.

The patch is straightforward and uncontroversial - it codifies existing review feedback into the official documentation. As the project maintainer is submitting it, this likely reflects established consensus. The change is minimal (just 3 lines added) and focused solely on the documentation.
