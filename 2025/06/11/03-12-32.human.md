Maintainer response to design questions about the new `--compact-summary` option.

Junio Hamano responds to D. Ben Knoble's suggestion about making the output format more configurable by proposing a concrete implementation path. Rather than introducing a completely new "diff options" configuration system, he suggests extending the existing `merge.stat` boolean configuration to optionally accept the string 'compact-summary' as a value. This would maintain backward compatibility while adding the new format option.

The response clarifies that the current boolean `merge.stat` (which defaults to true) would continue to produce the traditional `--stat` output when set or unset, while the new string value would enable the compact summary format. This provides a lightweight way to make the feature configurable without requiring users to type the full `--compact-summary` flag.

The email doesn't reject the idea of more general output configuration but offers this as an immediate, practical solution that builds on existing configuration infrastructure. It shows the maintainer's preference for incremental evolution of the feature while keeping the door open for more comprehensive solutions in the future. The tone is constructive and focused on implementable next steps rather than theoretical design discussions.
