[PATCH 1/2] CI: fix Coverity builds on Windows by adjusting PATH order

This patch addresses a build failure in the Coverity scan workflow on Windows where newer Coverity binaries' DLLs conflict with Git for Windows SDK components when placed at the start of PATH. The error manifests as missing windows.h during compilation. The solution modifies .github/workflows/coverity.yml to append rather than prepend the Coverity bin directory to PATH, following current Coverity documentation. The change involves a single line edit to the PATH construction, using cygpath -au for Windows path conversion. This fixes interactions between Coverity's cov-configure/cov-build tools and Git for Windows SDK's gcc.exe while maintaining the ability to run Coverity scans. The patch provides detailed technical background about the DLL conflict issue in its commit message.
