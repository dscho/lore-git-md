Platform compatibility patch for MSVC compiler support. This is part 3 of a 6-patch series (no cover letter seen yet).

The patch addresses an issue where Microsoft's Visual C++ compiler doesn't define standard endianness macros like `__BYTE_ORDER__`. Since MSVC-supported architectures (x86 and arm64) are all little-endian, the patch explicitly defines `GIT_BYTE_ORDER` as little-endian when compiling with MSVC.

The change is straightforward - it adds the endianness definitions before falling back to the existing platform detection logic. The diff shows careful handling to avoid conflicts with other platforms' definitions. This appears to be a well-justified platform-specific fix that should help Git compile cleanly on Windows with MSVC.
