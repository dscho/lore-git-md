Bugfix for `git stash -p` pathpec handling regression. This is the first patch in a two-part series that has already received positive review and been queued by the maintainer.

The patch fixes a regression introduced in 2020 where `git stash -p <pathspec>` stopped working correctly. The issue occurred when the code was refactored to prepend "push" to the arguments - it started checking the wrong argument position for the `-p` flag. Phillip Wood's fix is straightforward, changing one line to check `argv[1]` instead of `argv[0]`.

The commit includes two new test cases that verify both the fixed behavior and that invalid command forms are properly rejected. The tests were strengthened in v3 per Martin Ågren's suggestion to better exercise the patch selection interface by setting up a scenario with multiple changes where only some hunks are stashed.

This is a well-tested fix for a clear regression that restores functionality that was working for years before the 2020 refactoring. The patch series as a whole improves `git stash`'s option parsing while maintaining backward compatibility.
