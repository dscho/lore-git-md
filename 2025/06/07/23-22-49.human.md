Follow-up to curl type safety fixes, reporting that the issue has been addressed. This is a bugfix thread concerning type mismatches in Git's libcurl interactions that were causing compiler warnings (and build failures with -Werror) when using curl 8.14.

Todd Zullinger notes that Jeff King (Peff) already submitted and merged a fix series last week, which should appear in the upcoming v2.50.0-rc2 release. The original report came from Peter Michael Green, who observed these warnings when building Git in Debian's environment.

The thread appears resolved with this confirmation that fixes are already in master. The solution addressed type safety issues across multiple components (imap-send.c, http-push.c, etc.) where curl_easy_setopt() calls needed proper type casting for numeric parameters. While the warnings were newly visible in curl 8.14, the underlying type mismatches represented potential undefined behavior that has now been corrected.
