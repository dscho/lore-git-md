This is a platform compatibility patch updating build configuration for Solaris 11. Brad Smith notes that Solaris 11.0 and newer now provide several previously-missing functions (mkdtemp(), memmem(), strcasestr(), and strtoumax()), allowing the removal of some NO_* build flags.

The patch reorganizes the Solaris-specific section of config.mak.uname to maintain these flags for older Solaris versions (5.6 through 5.10) while removing them for the base Solaris case (which will now apply to 11.0+). The changes appear carefully version-gated, with 5.11 keeping only the NO_UNSETENV and NO_SETENV flags.

This looks like a straightforward update reflecting Solaris's improved POSIX compliance in recent versions. The patch is cleanly organized and maintains backward compatibility with older Solaris releases. The commit message could perhaps explain why these particular functions were selected for unblocking, but the changes themselves seem well-considered.
