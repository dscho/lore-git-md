Platform compatibility patch updating build configuration for Solaris 11.

Brad Smith submits a patch to `config.mak.uname` that adjusts the build settings for Solaris systems. The key change is removing the `NO_STRCASESTR`, `NO_MEMMEM`, and `NO_MKDTEMP` flags for Solaris in general, since these functions are now available in Solaris 11.0 and newer. The patch then reorganizes these flags to be version-specific, keeping them for Solaris versions 5.6 through 5.10 while removing them for 5.11 (Solaris 11).

The changes show careful version-specific handling of platform capabilities:
- Solaris 5.11 (11.0+ gets the most modern configuration with only `NO_UNSETENV` and `NO_SETENV` remaining
- Older versions from 5.6 through 5.10 maintain various compatibility flags
- The patch preserves all existing version-specific behavior while adding new sections for Solaris 5.10 and 5.11

This appears to be a straightforward update reflecting actual platform capabilities, with no behavior changes to Git itself - just allowing the build system to use native functions where available. The patch follows the existing style of the file and maintains all previous version checks while adding the new ones.
