Brad Smith's patch updating Solaris build configuration has reached consensus and is ready for merging. The changes modernize the build flags for Solaris 11.0+ while maintaining compatibility with older versions, removing unnecessary NO_* flags where functions are now reliably available. Jonathan Nieder reviewed and approved the technical approach, and Junio C Hamano has now weighed in to confirm the patch is soundly structured and won't break existing Solaris support.

While the immediate changes are uncontroversial, the discussion has surfaced broader questions about how Git should handle support for very old Solaris versions (5.6-5.10), some of which reached end-of-life nearly two decades ago. Junio notes the current version-specific organization actually provides good maintainability when adding or removing support for particular Solaris releases, though there may be opportunities to better separate truly version-independent flags in a future cleanup. This patch will likely be merged as-is while the maintenance philosophy questions remain open for separate consideration.
