This is a bugfix patch addressing memory leaks and NULL pointer access in Git's remote configuration handling, part of the ongoing `the_repository` removal effort. Jacob Keller fixes several issues in `branch_release()` and `remote_clear()` that were revealed when testing with submodule repositories, where memory leaks become apparent (they were previously masked when using `the_repository`).

The patch:
1. Adds NULL checks for `branch->merge` before accessing it
2. Properly clears `remote->push` and `remote->fetch` refspecs
3. Releases `branch->merge_name` elements and array
4. Moves `xstrdup` into `add_merge()` to clarify memory ownership
5. Removes const qualifier from branch structure to allow proper cleanup

Junio Hamano questions whether some NULL checks are redundant given the relationship between `merge_nr` and `merge_name`, and Jacob acknowledges this could use future cleanup. The patch appears well-reasoned and addresses immediate issues while noting areas for potential future improvement in the branch/merge_name relationship. This is a solid fix that enables safer repository handling as part of the broader `the_repository` removal work.
