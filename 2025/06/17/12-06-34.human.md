This is part 1 of a 3-patch series refactoring sparse-checkout configuration as part of the `the_repository` removal effort. The patch moves the `core.sparsecheckout` setting from a global variable to the `repo_settings` struct, following the established pattern for repository-specific configuration.

The change removes the global `core_apply_sparse_checkout` variable and replaces all its direct accesses with `repo->settings.sparse_checkout`. The config parsing is moved to `repo-settings.c` where it's initialized via `prepare_repo_settings()`. This allows removing a workaround `#define` in builtin/backfill.c that was needed to access the global.

The patch touches 15 files across various commands (`clone`, `mv`, `sparse-checkout`, `worktree` etc.), updating them to use the new access pattern. The changes are mechanical but thorough, with no intended behavior changes to sparse-checkout functionality. This is a well-scoped, focused change that makes incremental progress on the larger goal of removing repository globals.

As the first patch in the final version (v4) of this series, it appears ready for merging, having incorporated all maintainer feedback from previous iterations. The changes follow the architectural guidance established by Junio Hamano and others in earlier reviews.
