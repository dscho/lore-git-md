This is a minor build system fix for the submodule remote lookup refactoring series. Junio C Hamano points out that the new `repo_default_remote()` function declaration in remote.h breaks header checks because it references `struct repository` without a forward declaration. The fix adds the missing forward declaration to maintain build compatibility.

The change is straightforward and uncontroversial - it's the sort of minor adjustment that often surfaces during final review of a larger series. Since this is part of an already-reviewed patch series that's just waiting for the release freeze to end, this fix will presumably be incorporated when the series is resent. The core functionality (improving submodule remote fallback logic) remains unchanged by this header tweak.
