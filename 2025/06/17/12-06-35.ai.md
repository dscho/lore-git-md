This is the second patch in a v4 series refactoring sparse-checkout configuration as part of the `the_repository` removal effort. It migrates the `core.sparsecheckoutcone` setting from a global variable to the `repo_settings` struct, following the same pattern established in patch 1 for `core.sparsecheckout`.

The patch removes the global `core_sparse_checkout_cone` variable and moves its storage into `repo->settings.sparse_checkout_cone`. All access sites are updated to use the new location, with changes spanning 10 files including core commands like `grep`, `mv`, and `sparse-checkout`. The config parsing is moved to `repo-settings.c` where it's initialized via `prepare_repo_settings()`.

Key technical details:
- Maintains identical behavior to before - this is purely a refactoring
- Follows the direct access pattern established in earlier migrations
- Updates documentation strings to reference the new variable location
- Removes the variable declaration from environment.h/c
- Adds the new field to repo-settings.h alongside the related sparse_checkout setting

The change is mechanical but thorough, with no behavioral impact. It completes the sparse-checkout configuration migration started in patch 1, leaving only the `sparse_expect_files_outside_of_patterns` global (addressed in patch 3) remaining in this series. The implementation appears clean and consistent with the project's architectural direction.
