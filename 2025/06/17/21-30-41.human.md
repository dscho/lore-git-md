Memory leak fix and cleanup in remote/branch handling.

This is the first patch in a 6-part series improving submodule remote URL handling, focusing here on fixing memory leaks and NULL pointer access in the remote and branch configuration code. Jacob Keller addresses several issues that become apparent when reading configuration for submodule repositories:

1. Fixes NULL pointer access in branch->merge array by adding proper checks
2. Adds missing cleanup of remote->push and remote->fetch refspecs
3. Properly releases branch->merge_name array and its elements
4. Moves string duplication into add_merge() to clarify memory ownership
5. Drops const qualifier on branch->merge_name to allow proper cleanup

The changes are preparatory work needed for later patches in the series that will add submodule repository configuration reading. The patch includes careful analysis of the memory ownership issues and makes the cleanup paths more robust. While there's some noted confusion remaining between merge and merge_name arrays (flagged as potential future cleanup), this patch solidifies the foundation for the subsequent submodule remote URL improvements.
