This is a bugfix patch addressing memory leaks in remote.c's branch and remote struct cleanup, part of the ongoing `the_repository` removal effort.

The patch focuses on memory management issues in `branch_release()` and `remote_clear()` that were uncovered when testing with submodule repositories. Key fixes include: properly clearing remote->push/fetch refspecs, fixing NULL pointer access in branch->merge handling, and cleaning up branch->merge_name elements. The changes make memory ownership clearer by moving xstrdup into add_merge() and removing const qualifiers to enable proper freeing.

Junio Hamano raises a thoughtful question about the NULL checks in branch_release(), suggesting the branch->merge_name check might be redundant since merge_nr should only increment when merge_name grows. This points to potential deeper confusion between branch->merge and branch->merge_name that the author acknowledges could use future cleanup.

The changes are well-motivated by the need for proper memory handling when working with submodule repositories, and the careful approach suggests the patch is production-ready despite the lingering questions about the merge/merge_name relationship. This represents an important step in both memory safety and the broader `the_repository` removal effort.
