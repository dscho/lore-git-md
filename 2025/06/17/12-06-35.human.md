The patch migrates the `core.sparsecheckoutcone` configuration from the global `core_sparse_checkout_cone` variable to `repo->settings.sparse_checkout_cone`. The change follows the same pattern as the first patch in the series (which handled `core.sparsecheckout`), updating all access points across the codebase to use the new location. The config parsing is moved to `repo-settings.c` where it's initialized via `prepare_repo_settings()`.

The changes are mechanical but thorough, touching 10 files including core commands like `grep`, `mv`, and `sparse-checkout`. The commit message notes this is part of the broader effort to eliminate globals and improve code modularity. The patch appears well-executed, with consistent updates to all relevant call sites and no behavioral changes intended.
