This is a feature patch adding SHA-256 repository support to Git GUI. The changes adapt several Tcl scripts that previously assumed fixed 40-character SHA-1 hashes to instead use variable-length hashes based on the repository's object format (40 chars for SHA-1, 64 for SHA-256).

The patch touches core UI components like blame annotation, repository selection, and remote branch deletion, replacing hardcoded SHA-1 patterns with dynamic regex patterns that adjust to the detected hash length. The implementation looks thorough, checking the repository's object format at startup and propagating the hash length consistently through the global `hashlength` variable.

While this is a straightforward adaptation for SHA-256 compatibility, it's worth noting that the changes are mechanical regex substitutions without any deeper architectural changes to how Git GUI handles object IDs. The patch appears well-contained and follows the established pattern seen in other parts of Git's SHA-256 support work.
