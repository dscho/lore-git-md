Refactoring patch in a submodule URL handling series. This is the second of six patches in v2 of a series improving submodule remote URL handling, following preparatory memory management fixes in remote.c.

The patch moves duplicate implementations of `starts_with_dot_slash()` and `starts_with_dot_dot_slash()` helper functions from submodule--helper.c and submodule-config.c to dir.h as static inline functions. These helpers check path prefixes while respecting cross-platform path matching rules via `PATH_MATCH_XPLATFORM` flag. The existing `starts_with_dot(_dot)_slash_native` functions in dir.h are kept but remain distinct as they use `PATH_MATCH_NATIVE`.

The change is motivated by needing these helpers earlier in submodule--helper.c for subsequent refactoring work. The author considered but rejected renaming the moved functions to include a `_platform` suffix, deeming it too verbose. Documentation comments are added to clarify the relationship with `path_match_flags()`.

This is a straightforward code consolidation that removes duplication while maintaining existing behavior. The patch touches three files: adds 23 lines to dir.h while removing 12 lines each from submodule--helper.c and submodule-config.c. The change is part of a larger effort to improve submodule remote URL handling by prioritizing URL matching over name-based lookup.
