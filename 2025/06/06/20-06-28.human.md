Feature patch adding command-line folder specification to `git imap-send`. This is part of a larger v14 series modernizing IMAP functionality.

The patch introduces a new `--folder`/`-f` option to override the IMAP destination folder at runtime, rather than requiring configuration in `imap.folder`. This addresses cases where users frequently need to send to different folders. The implementation:
- Adds the option to documentation and usage strings
- Stores the override in a new `opt_folder` variable
- Applies the override by replacing the configured folder value
- Maintains backward compatibility by falling back to config when unspecified

The change is straightforward and well-contained, with clear documentation updates showing the new option alongside existing ones. As part of the mature v14 series that has undergone extensive review, this appears ready for inclusion, completing the folder management improvements alongside the new `--list` option introduced earlier in the series.
