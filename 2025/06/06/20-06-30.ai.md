This is a user experience improvement patch in the ongoing `imap-send` feature/bugfix series, specifically addressing credential prompt formatting. The change makes the password prompt include the port number alongside the hostname when requesting credentials, matching the behavior of `git send-email`.

The patch modifies the credential helper output in `imap-send` to show the full connection endpoint (host:port) rather than just the hostname. This provides better context for users when authenticating, especially in environments where different ports might require different credentials. The implementation handles both explicit ports and default ports (993 for IMAPS, 143 for IMAP) by always including the port in the prompt.

The change is minimal - a single line modification in `imap-send.c` that replaces a simple string copy with a formatted string including the port. The patch maintains all existing functionality while improving the user experience. This appears to be a straightforward, well-contained improvement that completes the credential handling polish work in the larger `imap-send` series.
