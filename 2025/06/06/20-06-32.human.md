Feature patch adding folder listing to `imap-send`, the final patch in a v14 series that has been extensively reviewed. This adds a `--list` option to show available IMAP folders, which is particularly helpful since different providers (Gmail, Outlook, etc.) use different naming conventions for standard folders like Drafts and Trash.

The implementation works with both OpenSSL and libcurl backends, following RFC6154 for OpenSSL and libcurl's example code for its implementation. The output shows folder names along with their IMAP flags (like `\HasNoChildren` or `\Drafts`), making it clear which folders are available and their intended purposes.

This is the culmination of a series that has fixed critical bugs, added OAuth2.0 support, and improved overall IMAP functionality. The patch appears well-tested and integrates cleanly with the existing codebase, maintaining backward compatibility while adding this useful diagnostic feature. The documentation is updated to mention the new option, particularly helping users who might be confused by provider-specific folder names.
