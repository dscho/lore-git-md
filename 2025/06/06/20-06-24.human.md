This is part of a feature series adding OAuth2.0 support to `imap-send`, specifically implementing the authentication mechanisms. The patch adds support for both RFC-standard OAUTHBEARER and Google's proprietary XOAUTH2 authentication methods.

The implementation includes new helper functions `oauthbearer_base64()` and `xoauth2_base64()` to properly format and encode the authentication strings according to their respective specifications. The patch also updates the documentation with clear examples for both Gmail and Outlook configurations, noting that Outlook only supports XOAUTH2 while Gmail supports both methods.

The changes integrate smoothly with the OpenSSL backend, adding the new authentication methods alongside the existing CRAM-MD5 support. For the libcurl backend, the patch handles OAuth2.0 tokens specially, using `CURLOPT_XOAUTH2_BEARER` rather than treating them as regular passwords. The documentation improvements are particularly thorough, explaining the security benefits of OAuth2.0 over app-specific passwords and providing configuration examples.

This appears to be a well-considered implementation that follows Git's existing patterns while adding modern authentication support. The patch is part of a larger series that has undergone extensive review, and this specific portion looks ready for inclusion.
