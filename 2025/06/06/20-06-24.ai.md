Feature patch introducing OAuth2.0 authentication support for `imap-send`. This is part of a larger v14 series that modernizes IMAP functionality, with this patch specifically adding RFC-compliant OAUTHBEARER and Google-proprietary XOAUTH2 authentication methods.

The implementation spans both OpenSSL and libcurl backends, with new helper functions `oauthbearer_base64()` and `xoauth2_base64()` that construct the proper authentication strings according to their respective specifications (RFCs 5801/7628 for OAUTHBEARER, Google's documentation for XOAUTH2). The patch includes comprehensive documentation updates explaining how to configure OAuth2.0 for both Gmail and Outlook, noting that Outlook only supports XOAUTH2.

Key technical details include:
- New `AUTH_OAUTHBEARER` and `AUTH_XOAUTH2` capability flags
- Special handling in `setup_curl()` to use `CURLOPT_XOAUTH2_BEARER` for OAuth methods rather than standard password authentication
- The `try_auth_method()` helper introduced in v14 to consolidate authentication attempts
- Documentation warnings about Gmail's password restrictions and MFA requirements
- Notes about credential helper compatibility for token generation

The implementation maintains backward compatibility while adding the new authentication methods, with proper compile-time guards and error handling. This addresses a key modernization need for `imap-send` as many email providers are moving away from password-based authentication. The patch appears well-structured with thorough documentation matching the code changes.
