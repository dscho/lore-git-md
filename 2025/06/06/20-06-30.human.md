This is a small but useful improvement to the `imap-send` credential prompt, part of the larger v14 series adding OAuth2.0 support and fixing IMAP functionality. The patch modifies the credential helper prompt to include the port number alongside the hostname when requesting passwords (e.g. showing `outlook.office365.com:993` instead of just the host). This matches the behavior of `git send-email` and makes the authentication request more specific, particularly helpful when dealing with multiple IMAP configurations.

The change is straightforward - a one-line modification to use `xstrfmt()` instead of `xstrdup()` when setting the credential host field. The commit notes this can't produce ambiguous output since the code always provides a default port (993 for IMAPS, 143 for IMAP) when none is specified. This is a polished final piece of the larger IMAP improvements, addressing a small UX gap in credential handling.
