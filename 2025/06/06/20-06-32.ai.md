This is the final patch in a 14-part series adding OAuth2.0 support and folder management to `imap-send`. It introduces a `--list` option that shows available IMAP folders, completing the folder management functionality alongside the previously added `--folder` option.

The patch implements RFC6154-compliant folder listing for both OpenSSL and libcurl backends, showing folder names and attributes (like `\Drafts` or `\Trash`) that vary across providers (Gmail uses "[Gmail]/Drafts" while Outlook uses "Drafts"). The output matches the raw IMAP protocol response format, which helps users identify the exact folder names needed for configuration.

For OpenSSL, it adds a new `list_imap_folders()` function that issues the IMAP LIST command. For libcurl, it adapts the documented example from curl.se. The implementation maintains the existing verbosity handling while ensuring LIST responses are always shown when using `--list`. The documentation is updated to mention the new option as a way to discover folder names when configuration fails.

This completes the series' goal of comprehensive IMAP functionality with both technical fixes (configuration parsing, authentication methods) and user-facing improvements (folder management, better output). The patch appears well-integrated with the prior work and follows the established patterns for error handling and credential management.
