This is a user experience improvement patch in the `imap-send` series, adding clearer progress output during message sending. 

The patch enhances the progress display during `imap-send` operations by showing the destination folder name alongside the message count. Previously, users would only see "Sending N message(s)", but now they'll see "Sending N message(s) to FOLDERNAME folder...". This small but thoughtful change provides better context about where messages are being delivered, particularly useful when working with multiple IMAP folders.

The change is implemented consistently in both the OpenSSL and libcurl backend paths of `imap-send.c`. As part of the larger v14 series that's fixing and modernizing IMAP functionality, this patch represents the final polish on user-facing output, following earlier standardization of error messages and credential prompts. The implementation is straightforward and maintains the existing progress percentage display below the new folder-aware message.
