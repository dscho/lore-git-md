This is a bugfix and feature enhancement for `imap-send`, part of a larger series adding OAuth2.0 support and fixing IMAP authentication issues. The patch specifically implements PLAIN authentication for the OpenSSL backend, which was previously only available when using libcurl.

The commit explains that while PLAIN authentication worked with curl, OpenSSL would incorrectly treat it as an invalid mechanism, defaulting to the older IMAP LOGIN command instead. Since many email providers still use PLAIN authentication (particularly for app passwords), this adds proper support by implementing RFC 4616-compliant PLAIN auth for OpenSSL.

The implementation follows the same pattern as other auth methods in the series, adding a new `AUTH_PLAIN` capability flag and a `plain_base64()` helper function to construct the authentication string. The changes are straightforward - updating documentation to list PLAIN as a supported method and adding the new auth handler with proper error checking.

This is a well-contained patch that fills a clear gap in functionality. The implementation looks solid, with proper memory management and error handling. As part of the larger v14 series that has undergone extensive review, this appears ready for inclusion. The change is particularly useful for users who need to use app passwords with email providers that require PLAIN authentication.
