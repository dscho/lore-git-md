This is a user experience improvement patch in the `imap-send` series, specifically enhancing progress output during message sending. The change modifies both the OpenSSL and libcurl backend implementations to display the destination folder name alongside the message count when sending emails via IMAP.

The patch would show "Sending 1 message to Drafts folder..." instead of just "Sending 1 message", making the output more informative about where messages are being delivered. The change is straightforward, modifying two fprintf() calls in `imap-send.c` to include the `server->folder` value in the progress message.

This appears to be a well-contained, non-controversial quality-of-life improvement that builds on the folder management work in the larger series. The implementation is consistent between both backends and maintains the existing pluralization logic for message counts. As the 9th patch in a 10-part series that has undergone extensive review, this seems like a final polish before the feature set is complete.
