This is a feature and bugfix series for `imap-send`, now in its 14th iteration, that makes the command usable again after a regression and adds OAuth2.0 support. The series has undergone extensive review and addresses all critical issues raised in previous rounds.

The key fixes include:
1. Repairing the configuration parser bug that made `imap-send` unusable since Git 2.46.0 by incorrectly NULLing the folder field
2. Adding comprehensive OAuth2.0 support (both OAUTHBEARER and XOAUTH2) with proper security boundaries
3. Implementing PLAIN authentication for OpenSSL backend
4. Fixing memory leaks in CRAM-MD5 authentication paths

New features include:
- Command-line folder specification via `--folder`
- Folder listing capability with `--list` showing RFC6154-compliant folder flags
- Improved user experience showing destination folders during send operations
- Better credential prompts including port numbers

The v14 iteration specifically:
- Adds clarifying comments about OAuth2.0 password handling
- Introduces a new `try_auth_method()` helper to reduce code duplication
- Maintains all fixes from v13 including the critical OAuth2.0 logic correction (switching `||` to `&&` in auth method checks)

The series appears mature and well-tested, having addressed all major concerns from reviewers including Jeff King and Junio Hamano. The remaining discussion points around code organization appear to be addressed in this version. This represents a significant improvement to `imap-send` functionality and reliability.
