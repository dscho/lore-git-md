This is a documentation patch fixing an Asciidoctor rendering issue in the Git manpages. Martin Ågren noticed that a recent change added unnecessary backticks around ".." in the diff format documentation, which causes Asciidoctor to render the manpage incorrectly. The patch simply removes these backticks to restore proper rendering.

The issue was introduced in commit 0b080a70ab but became more noticeable after c87b2b3a6f changed Asciidoctor's handling of triple-dots. While the current behavior is an improvement, Asciidoctor 2.0.18 still gets confused by these backticks, producing malformed output. The fix is a straightforward one-line change that makes the documentation consistent (the similar "index" line above doesn't use backticks) and works correctly with both Asciidoctor and asciidoc.

This isn't technically a regression fix for Git 2.50, but it does clean up a documentation rendering quirk that would be visible when using doc-diff. The patch is small, focused, and clearly explained - a textbook example of good documentation maintenance.
