This is a discussion about the OAuth2.0 authentication implementation in `imap-send`, specifically focusing on the libcurl password handling logic. - The current implementation checks `if (!is_oauth2_method)` to determine when to set `CURLOPT_PASSWORD`

- Aditya notes this could risk regressions since the original code didn't distinguish auth methods
