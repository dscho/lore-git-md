Feature patch adding JavaScript diff driver support to Git's built-in userdiff patterns. This is the first version from a new participant (Derick W. de M. Frias) as part of GSoC, implementing syntax recognition for JavaScript function declarations and numeric literals.

The patch adds a new JavaScript pattern to userdiff.c that handles four main function declaration styles: conventional named functions, assigned functions (including async variants), arrow functions (both multi-line and single-expression forms), and methods within classes/objects. It also includes comprehensive numeric literal support covering hexadecimal, octal, binary, and decimal formats with optional underscores and bigint suffixes. The implementation follows Git's existing diff driver approach, using regex patterns similar to other language drivers.

Test coverage is thorough, with 13 new test files in t/t4018/ demonstrating recognition of various JavaScript syntax forms including async functions, generators (both space positions for `function*`), class/object methods, and different assignment patterns. The tests verify the driver correctly identifies function names (marked as "RIGHT") across these syntax variations.

The implementation appears well-researched, with patterns that cover modern JavaScript features while avoiding framework-specific syntax. The test cases suggest careful consideration of edge cases in function declaration styles. As this is a new contributor's first submission, reviewers will likely scrutinize the regex patterns for potential false positives/negatives and may suggest additional test cases for less common syntax forms.
