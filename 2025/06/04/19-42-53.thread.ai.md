Git for Windows 2.50.0-rc1 release announcement by Johannes Schindelin. This test version updates the Windows-specific Git distribution with core component version bumps: Git v2.50.0-rc1, MinTTY v3.7.8, OpenSSH v10.0.P1, MSYS2 runtime (Cygwin v3.6.2 base), and cURL v8.14.1. Includes three notable bugfixes: (1) regression fix for ReFS drive writes on Windows Server 2022, (2) fetch operation correction for long branches when core.longPaths is enabled, and (3) installer fix for writable file handling during editor testing. Provides SHA-256 checksums for verification across multiple package formats (installers, portable versions, MinGit variants) supporting 32-bit, 64-bit, and ARM64 architectures. This is a maintenance update addressing Windows-specific filesystem and path handling edge cases.
