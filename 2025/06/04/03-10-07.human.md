This is a bugfix patch addressing memory leaks in two Git commands. The patch fixes cases where `repo_logmsg_reencode()` allocated memory that wasn't properly freed in `git` commands `shortlog` and `replay`. 

The issue occurs when these commands process commit messages - they use `repo_logmsg_reencode()` to handle message encoding, but were missing the corresponding cleanup call to `repo_unuse_commit_buffer()`. The patch adds these missing cleanup calls at the appropriate exit points in both commands.

The changes are straightforward and focused - just two small additions to ensure proper memory management. The first addition is in `builtin/replay.c` to clean up after creating a commit, while the second is in `builtin/shortlog.c` to handle an early return case when processing commit trailers.
