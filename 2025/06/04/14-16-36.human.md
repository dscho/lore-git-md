This is a refactoring patch that's part of a two-patch series adding GPG signing support to `git subtree`. The current patch prepares the codebase by switching the argument parsing in `git-subtree.sh` to use `--stuck-long` mode, which handles optional parameters more cleanly.

The change converts all option handling to use long-option-with-equals syntax (like `--message=msg` instead of `-m msg`), eliminating redundant `shift` operations. While this is a mechanical change, it's important groundwork for the upcoming GPG signing support in patch 2/2, which will need to handle optional signing parameters.

The patch shows good attention to detail - it maintains all existing functionality while simplifying the code structure. The commit message explains the change clearly and notes this is preparation for future optional parameters rather than tying it too tightly to the GPG signing feature. This version (v2) incorporates feedback from Junio C Hamano to frame the change more generally.

The diff is straightforward - mostly removing `shift` operations and converting short options to their long-form equivalents with parameter extraction from the equals syntax. This is the kind of clean refactoring that makes subsequent feature additions easier to implement and review.
