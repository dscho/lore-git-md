This thread addresses a bug in the bundle-uri debug output functionality where the `print_bundle_list()` function was inconsistently using `printf()` instead of the provided FILE* parameter for some debug messages. Jan Mazur originally reported and fixed the issue, with Junio C Hamano reviewing the patch.

The technical fix is straightforward - changing one line in bundle-uri.c to use `fprintf(fp)` consistently. While all current callers pass stdout, maintaining the interface consistency is preferred. The discussion centered more on the commit message quality than the code change itself. Junio suggested improving the message to better document the historical context of how this inconsistency was introduced across two prior commits.

Jan has now submitted a v2 that keeps the same code change but expands the commit message as requested, explaining the issue's history and explicitly considering (but rejecting) the alternative of removing the FILE* parameter entirely. With this documentation improvement addressing the last open point, the patch appears ready for inclusion. The change affects only debug output formatting and has no impact on the actual functionality of Git's bundle URI feature.
