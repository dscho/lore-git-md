Follow-up clarification on GPG test prompts. Junio C Hamano confirms Chris Torek's explanation that GPG's interactive prompts are handled at the OS level, not by Git. He notes that while Git's test suite does set stdin to /dev/null, this basic measure doesn't prevent applications like GPG from bypassing it to access /dev/tty directly. This reinforces the earlier conclusion that the solution must come from GPG/OS configuration rather than Git changes. The exchange serves as a definitive technical explanation for why these prompts appear in test environments and why Git's test infrastructure doesn't handle them. The thread appears fully resolved with this confirmation from the Git maintainer.
