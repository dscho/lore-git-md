This thread addressed a test infrastructure question about suppressing interactive GPG prompts during automated test execution, particularly in t5573-pull-verify-signatures.sh. Haritha D initially reported that "Really update the preferences? (y/N)" prompts from GPG were causing test hangs in automated environments, and found that piping "yes n" didn't resolve the issue.

Chris Torek provided the key technical explanation that these prompts originate from GPG itself rather than Git, and that CI systems work around this by disabling the OS-level interactive interface GPG uses. The thread was effectively resolved with this clarification that the solution lies in GPG/OS configuration rather than Git changes. Maintainer Junio C Hamano later confirmed this understanding, noting that Git's test infrastructure only minimally handles interactivity (by redirecting stdin from /dev/null) and cannot prevent GPG from using interfaces like /dev/tty. The consensus is clear that this is outside Git's control, with CI systems expected to implement their own OS-specific workarounds as needed.
