Build system regression affecting NonStop platforms. Junio Hamano investigates the git-gui build failures reported by Randall Becker, confirming extensive changes to the git-gui build system between rc0 and rc1. The issue occurs when TCL is unavailable and NO_TCLTK is not set, causing the build to fail when attempting to generate tclIndex files. The root cause appears to be that $(wildcard lib/*tcl) expands to nothing during the build process, which shouldn't happen in a proper checkout. 

This represents a significant build system change that slipped into rc1 release candidate without going through the usual 'seen' to 'next' to 'master' progression. While the immediate problem manifests on NonStop systems, the underlying issue could potentially affect other platforms where TCL is unavailable. The discussion is now turning to whether this is purely a build system regression or if there are environmental factors at play on NonStop systems. Johannes Sixt is being consulted for further insight.
