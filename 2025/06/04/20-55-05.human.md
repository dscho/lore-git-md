This is a bugfix series addressing compiler warnings with curl 8.14. Jeff King (Peff) explains that the new curl version triggers warnings when Git passes regular integers instead of longs to `curl_easy_setopt()`, which has always technically required longs. The warnings were previously suppressed due to a bug in curl's type-checking that was recently fixed.

The series is split into three patches handling different cases: integer constants, integer variables, and symbolic constants. The changes are straightforward type fixes across four files (`http-push.c`, `http.c`, `imap-send.c`, and `remote-curl.c`), totaling 21 lines changed. While not urgent (the warnings don't indicate runtime issues), this is a sensible cleanup that aligns Git with curl's documented API expectations. The patches appear well-considered, with Peff noting the rationale for each case.
