This is a bugfix patch addressing a memory leak in the fetch-pack command. The issue occurs when `finish_connect()` fails during execution of `cmd_fetch_pack()` - the function would return an error code without properly cleaning up allocated memory for the `sought_to_free` array and its contents.

The patch adds a `cleanup` label before the existing memory freeing operations at the end of the function, and modifies the error path after `finish_connect()` to jump to this cleanup section rather than returning immediately. The change is straightforward - just 5 lines added/modified in `builtin/fetch-pack.c`, moving the existing cleanup code under a label and adding a `goto` when `finish_connect()` fails.
