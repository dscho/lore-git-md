Feature patch adding JavaScript diff driver support to Git's built-in userdiff patterns.

Derick Frias contributes a new JavaScript diff driver that recognizes various function declaration styles in JavaScript, addressing a notable gap in Git's language support. The implementation covers conventional functions, arrow functions, async functions, generator functions, and class/object methods, along with numeric literals in different bases. The patch includes 13 test files demonstrating the supported syntax forms, showing thorough test coverage of the new patterns.

The implementation follows Git's existing approach for language diff drivers, adding patterns to userdiff.c that match JavaScript syntax while avoiding framework-specific extensions. The test cases are particularly comprehensive, covering edge cases like generator functions with different spacing around the `*` and various assignment forms. This appears to be a well-considered first contribution from a new participant, though reviewers may want to verify the pattern matching against more complex real-world JavaScript code.

The patch fills a practical need since JavaScript is widely used but previously lacked built-in diff support in Git. The implementation focuses on core language features rather than framework syntax, which should make it more maintainable. The thorough test suite gives confidence in the pattern matching's correctness.
