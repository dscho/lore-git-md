This is the second and final patch in a bugfix series addressing logging issues in `git send-email` when email clients like Outlook modify Message-IDs during delivery. The patch improves debug output accuracy by showing the actual delivered Message-IDs in the final logs rather than the original ones.

The change modifies the `send_message` subroutine in `git-send-email.perl` to update the `$header` variable with the server-assigned Message-ID using a regex substitution (`s/^(Message-ID:\s*).*\n/${1}$message_id\n/m`). It also makes the "Message-ID reassigned" notice conditional on `smtp-debug` being enabled, addressing feedback from earlier versions of the patch.

The technical implementation is straightforward - a 3-line change that replaces the Message-ID header in the logged output while maintaining all other headers. The patch includes clear before/after examples showing the improved logging behavior. This represents the final iteration of the change after review feedback, with only minor documentation phrasing cleanup remaining before merge.
