This is a translation (l10n) patch updating the Bulgarian localization for git-gui. The patch represents a resubmission of work originally sent over a month ago, with the author hoping to get it included in the upcoming Git 2.50 release.

The bulk of the change is a significant update to po/bg.po with 1787 insertions and 1821 deletions, suggesting a comprehensive revision rather than just incremental updates. The author also raises a broader question about standardizing the po-file format across Git's GUI tools (git-gui and gitk) to match core Git's approach of omitting source location comments.

The proposal to use `msgcat --no-location` would reduce file sizes and make future translation patch diffs cleaner by eliminating line number changes. This appears to be a recurring discussion point for the author, as they reference a previous submission from May 2025. The patch itself focuses solely on the Bulgarian translation update while using the cover letter to float the format standardization idea.
