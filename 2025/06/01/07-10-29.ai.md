Feature and bugfix patch adding PLAIN authentication support to OpenSSL backend in `imap-send`. This is part of a larger v10 series improving IMAP functionality, specifically addressing authentication methods.

The patch implements RFC 4616-compliant PLAIN authentication for the OpenSSL backend, which previously only supported LOGIN command. This matches the existing curl backend's PLAIN support and enables compatibility with email providers using app passwords. Key technical changes include:

1. New `AUTH_PLAIN` capability flag and corresponding `AUTH=PLAIN` string in capability list
2. Implementation of `plain_base64()` helper function following RFC 4616 for proper credential formatting (NUL-separated user/pass in base64)
3. New `auth_plain()` authentication function with proper error handling
4. Documentation update to list PLAIN as supported method for both backends
5. Integration with existing authentication flow in `imap_open_store()`

The implementation is thorough, with proper memory management (alloc/free of base64 buffers) and error checking. It maintains consistency with the series' approach to authentication methods while filling a gap in OpenSSL backend support. The patch appears well-contained and follows the established pattern seen in other authentication methods in the series.
