This is a feature patch adding PLAIN authentication support to the OpenSSL backend of `imap-send`, part of a larger v11 series improving IMAP functionality. The patch implements RFC 4616-compliant PLAIN authentication for OpenSSL, which was previously only available via libcurl. The implementation includes a new `plain_base64()` helper function to properly format credentials and an `auth_plain()` handler that integrates with the existing IMAP command flow.

Key technical changes include adding `AUTH_PLAIN` to the capability list, implementing the base64 encoding of credentials in the format `\0user\0pass` as specified by RFC 4616, and wiring up the authentication method selection in `imap_open_store()`. The documentation is updated to reflect that PLAIN is now available for both backends.

The patch fits into the series' broader goal of providing complete authentication method support across both OpenSSL and libcurl backends. It addresses a gap where PLAIN (commonly used with app passwords) was only functional with curl. The implementation follows the same pattern as other auth methods in the series, with proper error handling and memory management.
