This is a feature and bugfix series for `imap-send`, now in its 10th iteration, that makes the command usable again after a regression and adds OAuth2.0 authentication support. The series has undergone extensive review and addresses several key issues.

The most critical fix corrects a configuration parsing bug that made `imap-send` unusable since Git 2.46.0 by incorrectly NULLing out the folder field. The series also introduces OAuth2.0 authentication (both OAUTHBEARER and XOAUTH2 protocols) and PLAIN authentication support, with documentation updates promoting OAuth2.0 as the secure choice for Gmail users.

New user-facing improvements include:
- A `--folder` command-line option to override the configured IMAP folder
- A `--list` option to show available IMAP folders (helpful for discovering special folder names like Gmail's "[Gmail]/Drafts")
- Better progress output showing the destination folder during message sending
- More consistent credential prompts that include port numbers

The v10 iteration specifically addresses test failures caught during integration testing and fixes comment style issues. The series appears technically complete at this point, having addressed all previous feedback from reviewers including Junio Hamano, Jeff King, and Eric Sunshine. The changes span configuration parsing, authentication handlers, and IMAP protocol handling while maintaining compatibility with both OpenSSL and libcurl backends.
