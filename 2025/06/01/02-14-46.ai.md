This is a platform compatibility patch that follows up on Brad Smith's earlier change to detect online CPU count on OpenBSD/NetBSD systems. The original patch switched from using HW_NCPU to HW_NCPUONLINE sysctl to correctly handle systems with SMT disabled, where HW_NCPU would report double the actual online CPUs.

Collin Funk provides a positive review, confirming the patch works as intended on OpenBSD 7.7 and NetBSD 10.0. The change is small (4 line modifications in thread-utils.c) but important for accurate CPU detection on these BSD variants. The review suggests this is a straightforward improvement with no apparent issues, though the original motivation (why accurate CPU count matters for Git's operations) isn't restated here.
