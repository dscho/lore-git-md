This is a user experience improvement patch for `imap-send`, part of a larger series adding OAuth2.0 support and fixing IMAP functionality. The patch enhances progress output by showing which IMAP folder messages are being sent to, making the command's feedback more informative.

The change modifies two functions (`append_msgs_to_imap` and `curl_append_msgs_to_imap`) to include the destination folder name in their progress messages. Where previously users would just see "Sending 1 message", they'll now see "Sending 1 message to Drafts folder...". This matches the series' broader effort to improve user-facing messaging and follows the pattern of other recent changes standardizing output formatting.

As part of the mature v11 series that has undergone extensive review, this patch is straightforward and uncontroversial. It completes the user experience polish by adding context that helps users verify their messages are going to the intended location, particularly useful when using the new `--folder` command-line option introduced earlier in the series.
