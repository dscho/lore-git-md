This thread addresses a platform-specific fix for OpenBSD and NetBSD systems to correctly detect the number of online CPUs when SMT (simultaneous multithreading) is disabled. The original patch by Brad Smith switched from using the `HW_NCPU` sysctl to `HW_NCPUONLINE` to avoid overcounting CPUs in this scenario.

Collin Funk has tested and confirmed the patch works correctly on OpenBSD 7.7 and NetBSD 10.0. The change is small but important for accurate CPU detection, which affects Git operations that scale based on available cores (like parallel index operations). With the positive review and successful testing, this appears ready for inclusion.
