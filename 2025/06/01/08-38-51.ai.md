Feature patch adding OAuth2.0 authentication support to `imap-send`, part of a larger v11 series improving IMAP functionality. This patch implements both OAUTHBEARER (RFC-standard) and XOAUTH2 (Google-proprietary) authentication methods, with support for both OpenSSL and libcurl backends. The changes span documentation updates and core authentication handling in `imap-send.c`.

Key technical elements:
- New `AUTH_OAUTHBEARER` and `AUTH_XOAUTH2` capability flags
- `oauthbearer_base64()` and `xoauth2_base64()` helper functions implementing RFC5801/RFC7628 and Google's XOAUTH2 protocol respectively
- Authentication handlers `auth_oauthbearer()` and `auth_xoauth2()` for OpenSSL backend
- libcurl integration via `CURLOPT_XOAUTH2_BEARER` that automatically selects between protocols
- Documentation updates explaining OAuth2.0 setup for Gmail and Outlook, including warnings about MFA requirements

The implementation follows the series' pattern of thorough error handling and matches Git's existing authentication patterns. Documentation provides clear guidance for users transitioning from app-specific passwords to OAuth2.0 tokens, including credential helper recommendations. The patch maintains backward compatibility while adding the new auth methods to the supported `imap.authMethod` configurations.
