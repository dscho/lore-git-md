Bugfix patch in the `imap-send` authentication series, addressing a memory leak in CRAM-MD5 authentication failure paths. This is part of the comprehensive v11 series that introduces OAuth2.0 support and fixes various IMAP-related issues.

The patch specifically fixes a case where the `response` buffer allocated in `auth_cram_md5()` would leak if the subsequent `socket_write()` operation failed. The fix adds proper cleanup by calling `free(response)` in the error path before returning. This matches the memory management pattern seen elsewhere in the series where allocated resources are freed before error returns.

The change is small but important for correctness, as memory leaks in authentication code paths could be security-sensitive.
