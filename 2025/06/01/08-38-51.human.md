Feature patch adding OAuth2.0 support to `imap-send`. This is part of a larger v11 series that overhauls IMAP functionality, with this patch specifically implementing OAUTHBEARER and XOAUTH2 authentication methods. The implementation works for both OpenSSL and libcurl backends, following RFC standards for OAUTHBEARER and Google's protocol for XOAUTH2.

The patch adds new base64 encoding utilities for constructing OAuth tokens, updates documentation to explain the new authentication methods, and provides specific configuration examples for Gmail and Outlook. Notably, it promotes OAuth2.0 as more secure than app-specific passwords for Gmail users. The implementation includes proper error handling and maintains compatibility with existing authentication methods.

This appears to be a well-considered addition, with thorough documentation and clear technical implementation. The patch fits into the series' broader goal of modernizing `imap-send`'s authentication options while fixing long-standing issues. Given that OAuth2.0 is becoming the standard for major email providers, this functionality fills an important gap in Git's email workflow support.
