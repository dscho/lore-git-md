Bugfix and refactoring patch introducing `GET_OID_GENTLY` flag for `get_oid` error handling. This is part of the v7 stash import/export series but focuses on a general object-name.c improvement.

The patch addresses inconsistent error handling in `get_oid_basic()`, which currently either dies or exits when encountering too-short reflog histories, unlike most other `get_oid` paths that return -1. The change introduces a new `GET_OID_GENTLY` flag (0100000) that makes the function return -1 instead, while preserving existing behavior for callers not using the flag.

Key technical details:
- Adds flag definition in `hash.h` alongside other `GET_OID_*` flags
- Modifies `object-name.c` to check the flag before dying/exiting
- Preserves backward compatibility for existing callers
- Explicitly notes this can't be made default due to test dependencies

The change appears well-motivated by the need for consistent error handling in the stash export/import work, where graceful failure is preferable to termination. The implementation is minimal (6 lines changed) and maintains the existing behavior for non-GENTLY callers.
