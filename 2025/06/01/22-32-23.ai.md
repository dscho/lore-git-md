This is a refactoring patch in the final v7 series implementing stash import/export functionality. It factors out stash revision parsing logic into a dedicated `parse_stash_revision()` function for reuse in upcoming work, while maintaining all existing behavior.

The patch moves the logic that handles three stash reference formats (empty/`@{0}` syntax, numeric indices, and direct commit references) from `get_stash_info()` into a new helper function. Key technical details include:
- Preserves the same error handling for missing stashes
- Adds a `quiet` parameter to suppress "No stash entries" messages when needed
- Maintains identical string buffer handling via `strbuf` operations
- Keeps the same special case for numeric-only arguments (interpreting them as `refs/stash@{n}`)

This change prepares for future work that will need the same revision parsing logic without the full `get_stash_info()` behavior. The implementation appears cleanly extracted with no functional impact, consistent with the series' high-quality standards. As part of the mature v7 series, this follows established patterns from prior review rounds and maintains the test coverage added earlier in the series.
