This is a feature patch in the `imap-send` series, introducing a command-line option to specify the IMAP folder at runtime. The patch adds a new `--folder`/`-f` option that overrides the `imap.folder` configuration setting, addressing a common workflow where users need to send to different folders than their configured default.

The implementation follows the established pattern in the series, with changes to documentation (both config and man pages) and the core command-line parsing logic in `imap-send.c`. The option takes precedence over the config value, freeing and replacing the `server.folder` field when specified. Documentation updates clarify the precedence rules and provide example usage.

This is part of the comprehensive v11 series that has been thoroughly reviewed, with this particular addition being a straightforward but useful quality-of-life improvement. The patch maintains consistency with the series' error handling and memory management patterns, properly freeing the old folder string before assignment. The change is well-contained and unlikely to be controversial, completing one of the planned user-facing features in the larger `imap-send` modernization effort.
