This is a user experience improvement in the ongoing `imap-send` series, specifically addressing credential prompts. The patch modifies the credential helper display to include the port number when requesting passwords (e.g., showing `imaps://user@host:993` instead of just `imaps://user@host`).

The change makes credential prompts more specific by including the port information, which helps users verify they're authenticating to the correct endpoint. This brings `imap-send` in line with `git send-email`'s behavior. The implementation is straightforward - just a single line change that formats the host string to include the port number.

Since the code always uses default ports (993 for IMAPS, 143 for IMAP) when none is specified, there's no need to handle a "no port" case. This is a small but thoughtful improvement that makes the authentication process slightly more transparent to users.
