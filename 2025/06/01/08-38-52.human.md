This is a feature patch in the `imap-send` series, adding PLAIN authentication support for the OpenSSL backend. The patch implements RFC 4616-compliant PLAIN authentication, which was previously only available when using libcurl. Many email providers still use PLAIN authentication (often via app passwords), so this fills an important gap in OpenSSL support.

The implementation follows the standard PLAIN mechanism format of `\0user\0pass` base64-encoded, with proper error handling and memory management. The documentation is updated to reflect that PLAIN is now available for both backends. This is part of a larger effort to bring feature parity between OpenSSL and libcurl implementations in `imap-send`.
