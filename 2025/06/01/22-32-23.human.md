This is a refactoring patch in the final version of the stash import/export series. It extracts stash revision parsing logic into a reusable function, preparing for future work while maintaining existing behavior.

The patch moves the logic that handles stash revision specifications (like numeric references or empty arguments defaulting to the latest stash) from `get_stash_info()` into a new `parse_stash_revision()` function. This makes the code more modular and positions it for reuse in upcoming stash export/import operations. The change is purely structural - no behavior is altered, and all existing tests continue to pass.

This is the second of four patches in the v7 series, which has already undergone extensive review and is considered ready for merging. The author, brian m. carlson, has incorporated feedback from multiple reviewers including Junio Hamano and Phillip Wood across seven iterations of the series. The change demonstrates good coding practices by isolating functionality while maintaining the same error handling and user messaging.
