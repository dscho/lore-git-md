This is a documentation patch in the ongoing `imap-send` improvement series, specifically addressing user-facing message formatting. The changes standardize capitalization and punctuation in error messages and status outputs throughout `imap-send.c`, with 44 lines modified to ensure consistent style. Key changes include:

1. Capitalizing first words in error messages (e.g., "cannot" -> "Cannot" in certificate errors)
2. Adding missing periods at sentence endings (e.g., "nothing to send" -> "Nothing to send.")
3. Standardizing status messages (changing "ok" to "OK" in connection success messages)
4. Making warning messages more complete (adding period to "Password is being sent in the clear")

The patch also updates a test expectation in `t1517-outside-repo.sh` to match the new standardized message format. These changes don't affect functionality but improve user experience by making output more professional and consistent. The modifications align with the series' broader goal of polishing `imap-send`'s usability, though this particular patch focuses purely on textual presentation rather than the authentication or protocol improvements seen in other parts of the series.
