Feature addition to `imap-send` in a mature patch series (v10 9/9). This final installment adds a `--list` option to show available IMAP folders, addressing the common problem where different servers (Gmail, Outlook, etc.) use different naming conventions for standard folders like Drafts and Trash.

The implementation works with both OpenSSL and libcurl backends, following RFC 6154 for OpenSSL and libcurl's documented examples. The output shows folder hierarchies and attributes (like `\Drafts` or `\HasNoChildren`), helping users identify the correct folder names to use in their configuration. The patch includes documentation updates and handles both the tunneled and direct connection cases.

This appears to be a well-polished addition to the v10 series, which has already addressed several critical bugs and added OAuth2 support. The implementation is thorough, with clear examples of the output format in the commit message. As the final patch in a heavily reviewed series, it seems ready for inclusion.
