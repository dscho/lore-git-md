This is the final patch in a feature series adding comprehensive IMAP functionality to `git imap-send`. It introduces a new `--list` option that shows available IMAP folders, which is particularly useful since different providers (Gmail, Outlook, etc.) use different naming conventions for standard folders like Trash or Drafts.

The patch implements RFC6154-compliant folder listing for both OpenSSL and libcurl backends, showing the raw IMAP LIST command output with folder flags and hierarchy markers. This helps users identify the correct folder names to use in configuration. The implementation follows the series' established patterns, with proper separation between backends and consistent error handling.

The documentation update notes this can help users who get "Folder doesn't exist" errors by showing them the provider-specific folder names. This completes the series' goal of making `imap-send` a fully-featured IMAP client, with the folder listing being the last major missing piece after the earlier OAuth2.0 support and configuration fixes.

The patch is well-integrated with the rest of the series, maintaining the same code style and error message conventions established in previous iterations. It provides a clear user-facing benefit while being technically sound, matching the high quality of the rest of this thoroughly reviewed series.
