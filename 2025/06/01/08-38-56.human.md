This is a small but useful user experience improvement in the `imap-send` series, which is nearing completion in its 11th iteration. The patch modifies the credential helper prompt to include the port number when asking for a password, making it consistent with `git send-email`'s behavior.

The change is straightforward - it updates the credential host field to include the hostname and port in the format like `host:port`. This provides better context for users are managing multiple IMAP connections or troubleshooting authentication issues. The author notes that since default ports (993 for IMAPS, 143 for IMAP) are always used when none is specified, there's no need to handle a "no port" case.

This patch is part of a larger series that has added OAuth2.0 support, folder management, and fixed several bugs in `imap-send`. While this particular change is minor, it follows the series' theme of improving the user experience and consistency with other Git commands. The implementation is clean and matches the established patterns in the codebase.
