Bugfix for a critical regression in `imap-send` that has made the command unusable since Git 2.46.0. The issue stems from commit 6d1f198f34 which incorrectly cleared the `cfg->folder` field when processing unrelated configuration variables like `imap.user` or `imap.pass`. This patch fixes the bug by properly clearing the correct field for each config variable.

The regression was likely unnoticed because most users prefer `git send-email`, but it completely broke `imap-send` functionality. The fix is straightforward - each config variable now clears its own field rather than incorrectly clearing the folder field. This is the first patch in a larger v11 series that adds OAuth2.0 support and other improvements to `imap-send`.
