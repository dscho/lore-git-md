This is a feature and bugfix series for `imap-send`, now in its 11th iteration. The series makes `imap-send` usable again after a regression in Git 2.46.0 that broke configuration parsing, while also adding significant new functionality including OAuth2.0 authentication support and folder management capabilities.

The v11 version focuses on final polish, with changes to error message formatting to match Git's style guidelines (lowercase first word, no trailing periods). The series includes 9 patches that:
1. Fix the critical config parsing bug that NULLed out the folder field
2. Add OAuth2.0 support via OAUTHBEARER and XOAUTH2 protocols
3. Implement PLAIN authentication for OpenSSL
4. Fix a memory leak in CRAM-MD5 authentication
5. Add command-line folder specification via `--folder`
6. Improve various log messages
7. Show port numbers in credential prompts
8. Display destination folder during message sending
9. Add folder listing via `--list` option

The implementation spans configuration parsing, authentication handlers, IMAP protocol handling, and new user-facing features. Documentation updates promote OAuth2.0 as the secure choice for Gmail users. The series has undergone extensive review with feedback incorporated around error message style consistency and technical implementation details.

Key technical components include new base64 encoding utilities for OAuth tokens, RFC-compliant authentication handlers, and consistent folder handling across both OpenSSL and libcurl backends. The `--list` option implements RFC6154-compliant LIST command handling with proper hierarchy markers. The series is now technically complete with comprehensive authentication support and folder management capabilities.
