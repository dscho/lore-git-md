This is a feature patch in the ongoing `imap-send` series, adding a command-line option to specify the IMAP folder destination. The patch introduces a new `--folder` (or `-f`) option that lets users override the `imap.folder` config setting at runtime, with the command-line value taking precedence.

The change is straightforward: it adds the option parsing, updates the documentation in both the config and command manpages, and implements the folder override logic in `imap-send.c`. The documentation improvements clarify that the config setting remains required unless the command-line option is used, and shows example folder formats.

This is part of a larger effort to improve `imap-send`'s usability, and this particular change addresses a common workflow where users might want to send patches to different folders without constantly editing their config. The implementation looks clean, with proper memory management (freeing the old folder string before replacing it) and clear documentation updates.
