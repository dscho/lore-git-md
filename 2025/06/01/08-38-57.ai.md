This is a user experience improvement patch in the `imap-send` series, adding destination folder visibility during message sending. 

The patch modifies the progress output in both OpenSSL and libcurl backends of `imap-send` to include the destination folder name when displaying the message sending status. Previously, the output simply showed "Sending N message(s)", while the new version adds "to FOLDER folder..." to make it clear where messages are being delivered. The change affects both `append_msgs_to_imap()` (OpenSSL backend) and `curl_append_msgs_to_imap()` (libcurl backend) functions, ensuring consistent behavior across implementations.

This is part of the comprehensive v11 series that has been through extensive review, with this particular patch representing final polish on user-facing messaging. The change is straightforward - just two modified fprintf() calls - but provides useful context about where messages are being delivered, which could help users catch misconfigurations. The patch follows the series' established pattern of standardizing and improving output messages, as seen in earlier patches that addressed error message formatting.
