This is a documentation and style patch in the `imap-send` series, focusing on error message consistency. It's part of the larger v11 series that adds OAuth2.0 support and fixes various IMAP-related issues.

The patch standardizes error messages and output in `imap-send.c` by:
- Making error messages start with lowercase (matching Git's style)
- Ensuring proper punctuation (adding/removing periods where appropriate)
- Capitalizing protocol names like "IMAP" and status codes like "OK" consistently
- Clarifying some error contexts (e.g., specifying "CRAM-MD5" in an auth error)

These changes follow up on Eric Sunshine's earlier feedback about message style consistency in the series. While minor, they improve the user experience by making output more professional and consistent with Git's conventions. The changes are straightforward and unlikely to be controversial, touching only message formatting without affecting functionality.
