This is the 11th iteration of a feature and bugfix series for `imap-send`, now adding OAuth2.0 authentication support and fixing critical configuration parsing issues. The series makes `imap-send` usable again after a regression in Git 2.46.0 that broke config file handling.

The key improvements in this version include:
1. Fixing the critical config parser bug that NULLed out folder settings
2. Adding OAuth2.0 support via both OAUTHBEARER and XOAUTH2 protocols
3. Implementing PLAIN authentication for OpenSSL
4. Adding a `--list` option to show available IMAP folders
5. Various UI improvements like showing destination folders during send

The series has undergone extensive review, with v11 specifically addressing final style nits around error message formatting (lowercase starts, no periods). While the patch set is technically complete, the author's casual "I am surprised this thing even exists" comment suggests `imap-send` may not be widely used or tested in real-world scenarios. The comprehensive changes and thorough review process indicate this is a serious effort to modernize and stabilize the feature.
