Platform compatibility patch for CPU detection on BSD systems. This is a follow-up to Brad Smith's earlier patch that fixes how Git detects online CPU count on OpenBSD and NetBSD by using HW_NCPUONLINE instead of HW_NCPU. The change addresses a discrepancy where SMT-disabled systems would report double the actual online CPU count.

Collin Funk confirms the patch works as intended, having verified it on OpenBSD 7.7 and NetBSD 10.0. The review is straightforward with no suggested changes, indicating this is a well-understood and tested solution to a platform-specific issue.

The change is small (4 lines modified) and focused on the thread-utils.c file. This appears to be a clear improvement for BSD users that shouldn't affect other platforms. The patch seems ready for inclusion, having passed both the original author's and reviewer's testing.
