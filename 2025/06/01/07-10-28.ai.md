This is a feature patch adding OAuth2.0 authentication support to `imap-send`, part of a larger series that has gone through multiple iterations (now at v10). The patch implements both RFC-standard OAUTHBEARER and Google's XOAUTH2 protocols for both OpenSSL and libcurl backends.

The core changes introduce new authentication handlers (`auth_oauthbearer` and `auth_xoauth2`) with corresponding base64 encoding utilities (`oauthbearer_base64` and `xoauth2_base64`). The implementation follows RFC 5801/7628 for OAUTHBEARER and Google's XOAUTH2 specifications, with proper error handling and memory management. For libcurl, it leverages `CURLOPT_XOAUTH2_BEARER` which automatically selects the appropriate OAuth2 variant.

Documentation updates explain the new authentication methods, with specific guidance for Gmail (recommending OAuth2 over app-specific passwords) and Outlook (which requires XOAUTH2). The patch maintains backward compatibility while adding these secure authentication options. Configuration parsing is updated to recognize the new auth methods, and error messages are standardized across implementations.

The technical implementation touches authentication flow, base64 encoding, IMAP protocol handling, and curl integration in `imap-send.c`.
