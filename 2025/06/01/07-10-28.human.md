This is a feature patch adding OAuth2.0 authentication support to `git imap-send`, part of a larger series that has gone through extensive review (now at v10). The patch implements both the standard OAUTHBEARER (RFC 5801/7628) and Google's proprietary XOAUTH2 protocols, addressing a common pain point for users of services like Gmail and Outlook that increasingly require OAuth.

The implementation adds new authentication handlers and base64 encoding utilities in `imap-send.c`, with corresponding documentation updates that explain how to configure OAuth for different providers. Notably, the docs now recommend OAuth over app-specific passwords for Gmail due to better security. The patch handles both OpenSSL and libcurl backends, with a clever reuse of `CURLOPT_XOAUTH2_BEARER` that works for both protocols despite the option's name.

This appears to be a well-considered addition - the commit message cites relevant RFCs, the code follows Git conventions (after earlier style fixes noted in the thread), and the documentation provides clear setup instructions. The patch fits naturally into the broader series that has already addressed critical bugs and added other IMAP improvements.
