This is a feature patch adding PLAIN authentication support to `imap-send`'s OpenSSL backend, part of a larger series improving IMAP functionality. The patch implements RFC 4616-compliant PLAIN authentication for OpenSSL case, matching the existing curl implementation. 

The change adds a new `plain_base64()` helper function that properly formats credentials according to the RFC, plus the necessary protocol handling to use it when `AUTH PLAIN` is specified. The documentation is updated to reflect that PLAIN is now available for both backends. This provides parity between OpenSSL and curl implementations, addressing a gap where OpenSSL previously only supported LOGIN command rather than AUTH PLAIN.

The implementation looks thorough, with proper memory management and error handling. Since many email providers still use PLAIN authentication (particularly with app passwords), this fills an important compatibility gap. The patch fits cleanly into the broader series that's adding multiple authentication methods and fixing related issues in `imap-send`.

This is the third of nine patches in v10 of the series, which has already undergone extensive review. The changes here appear focused and well-contained, just adding the missing PLAIN method support while maintaining the existing behavior for other auth methods.
