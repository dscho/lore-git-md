Feature patch adding command-line folder specification to `git imap-send`. This is part of a larger v11 series that overhauls IMAP functionality with OAuth2.0 support and various fixes.

The patch introduces a new `-f/--folder` option to override the `imap.folder` config setting at runtime. This addresses a common workflow where users need to send patches to different folders without constantly editing config. The implementation is straightforward - it adds the option parsing and applies the override before connecting to the server.

Documentation updates clearly explain the precedence (command line overrides config) and provide example usage. The change is well-contained, touching only the expected files: option parsing in `imap-send.c` and relevant docs.
