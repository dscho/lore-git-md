Platform compatibility fix for physical memory detection on OpenBSD/NetBSD systems with >=4GB RAM. The patch modifies `builtin/gc.c` to add support for `HW_PHYSMEM64` sysctl parameter, which correctly reports memory amounts above 4GB, while maintaining backward compatibility with existing `HW_MEMSIZE` and `HW_PHYSMEM` fallbacks. The change affects Git's auto-detection of system memory used by components like the garbage collector. The minimal patch only adds a condition to check for `HW_PHYSMEM64` in the sysctl path, preserving existing behavior for other platforms. Problem clearly identified as incorrect memory reporting on >=4GB OpenBSD/NetBSD systems.
