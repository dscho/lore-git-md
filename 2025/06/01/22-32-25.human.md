Feature: Stash import functionality completes bidirectional stash transfer capability

This final piece of the stash export/import series adds the `git stash import` subcommand to complement the previously implemented export functionality. The import operation reconstructs stashes from commit chains created by export, appending them to the existing stash stack rather than replacing it - a deliberate design choice to avoid accidental data loss. Users who want to replace their stashes can first run `git stash clear`.

The implementation validates imported commits strictly, checking for the expected stash metadata format and topology (2-3 parent relationships). Test coverage is thorough, verifying round-trip behavior, partial imports, empty cases, and rejection of malformed inputs. The patch builds on the infrastructure from prior versions, including Phillip Wood's topology validation and the shared empty commit handling.

With this addition, the series now provides complete functionality for stash portability across repositories via standard Git transfer mechanisms. The implementation has been carefully reviewed over seven iterations, with all feedback incorporated and no outstanding technical concerns.
