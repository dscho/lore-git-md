This is the final patch in a 4-part series implementing stash import/export functionality, adding the complementary `git stash import` command to read stashes previously exported via `git stash export`. The patch completes the bidirectional transfer capability by:

1. Implementing `do_import_stash()` which:
   - Validates imported commit chains match the expected stash topology
   - Preserves original stash messages while stripping export metadata
   - Appends imported stashes to the existing stash stack (requiring explicit `clear` for replacement)
   - Includes thorough validation of commit headers and parent structure

2. Adding 94 lines of test coverage in `t/t3903.sh` verifying:
   - Round-trip fidelity of stash contents
   - Append behavior (vs. replacement)
   - Edge cases (empty imports, partial exports)
   - Rejection of malformed imports

3. Documenting the new subcommand in `git-stash.adoc` with usage notes about the append-only behavior.

The implementation reuses several components from earlier patches including the topology validation and commit chain walking logic. It introduces a new `c_commit` field in `struct stash_info` to track chain commits during import.
