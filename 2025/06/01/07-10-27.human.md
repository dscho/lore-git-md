Bugfix for a critical regression in `imap-send` that made the command unusable since Git 2.46.0. The patch fixes an incorrect cleanup in the configuration parser where unrelated fields (user, pass, tunnel, authmethod) were incorrectly NULLing out the folder field. This was introduced in commit 6d1f198f34 and went unnoticed for some time, likely because most users prefer `git send-email`. The fix is straightforward - each config field now properly clears its own corresponding struct member rather than incorrectly clearing the folder field. This is the first patch in a larger series that adds OAuth2.0 support and other improvements to `imap-send`, but stands alone as an important bugfix that needs to be backported. The change is minimal (4 lines modified) and clearly corrects the problematic behavior.
