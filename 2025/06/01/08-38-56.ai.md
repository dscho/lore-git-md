This is a small but user-facing improvement in the `imap-send` series, specifically addressing credential prompt formatting. The patch modifies the credential helper display to include the port number alongside the hostname when requesting passwords, matching the behavior of `git send-email`. 

The change is straightforward - it updates the `server_fill_credential()` function in `imap-send.c` to use `xstrfmt()` for combining host and port into a single string (like "host:993") rather than just showing the host. The commit notes this is particularly useful since `imap-send` always uses a default port (993 for IMAPS, 143 for IMAP) even when not explicitly specified, so the port information is always be available.

This patch is part of the larger v11 series that has already addressed more complex issues like OAuth2.0 support and configuration parsing bugs. The change aligns with the series' focus on improving user experience and consistency with other commands, though it's a relatively minor polish compared to the major authentication and folder management features introduced earlier in the series. The implementation is cleanly done with proper memory management via `xstrfmt()`.
