This is Junio Hamano's monthly "What's cooking in git.git" status update, covering development activity in June 2025. The email provides a comprehensive overview of patches currently under review, recently accepted changes, and upcoming release plans.

The most notable development is the preparation for SHA-256 becoming the default hash algorithm in Git 3.0's breaking changes mode (bc/use-sha256-by-default-in-3.0). This significant change is marked as "Needs review" and would affect several test scripts that need to adapt to the new default.

Several infrastructure improvements are progressing well:
- The ongoing effort to remove `the_repository` global continues with multiple patches (ac/deglobal-sparse-variables, ly/run-builtin-use-passed-in-repo, ps/object-store)
- CI/build system improvements include making "make coccicheck" fail when spatch suggests changes (jc/coccicheck-fails-make-when-it-fails)
- Performance work includes batched reference updates for fetch/push (kn/fetch-push-bulk-ref-update) though it's facing some test failures

Notable user-facing changes include:
- A new "git repo-info" command to inspect repository characteristics (lo/repo-info)
- "git stash" improvements for path-specific operations (pw/stash-p-pathspec-fixes)
- Better handling of renamed submodules (kj/renamed-submodule)
- The long-broken "git imap-send" has been resurrected with OAuth2 support (ag/imap-send-resurrection)

The email also outlines the planned 2.51 release schedule, with key dates from June 23rd (cycle start) through August 18th (final release). Junio notes the typical summer slowdown and plans a shorter 8-week cycle accordingly.

Several documentation and test modernization efforts are also in progress, along with the planned deprecation of "git whatchanged" in favor of "git log --raw". The email provides a clear snapshot of Git's development direction, with many significant changes in flight but also showing careful attention to backward compatibility and testing.
