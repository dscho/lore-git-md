This is Junio Hamano's "What's cooking in git.git" status report for June 2025, organizing active development topics for the upcoming Git 2.51 release (RC periods in early August, final release August 18th). The report notes the project's typical summer slowdown and plans an 8-week cycle. 

New topics include `bc/use-sha256-by-default-in-3.0` (preparing SHA-256 as default hash in breaking changes mode with test updates), `lo/repo-info` (new subcommand to query repository characteristics), and `ag/imap-send-resurrection` (reviving `git imap-send` with OAuth2.0 support). Ongoing work includes `ps/object-store` (removing `the_repository` from object APIs), `kn/fetch-push-bulk-ref-update` (performance improvements for ref updates), `tb/midx-avoid-cruft-packs` (preventing MIDX from referencing cruft pack objects), and `jc/you-still-use-whatchanged` (deprecating `git whatchanged`). 

Topics are categorized by status: "Needs review", "Will merge to 'next'", or awaiting rerolls. Several are marked ready for merging while others need review responses. The report maintains the project's standard branch structure (maint, master, next, seen) and follows the Git contribution workflow where patches progress through these branches before final merging.
