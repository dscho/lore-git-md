Here's a human-readable summary of Junio's "What's cooking" update for June 2025:

The Git project is preparing for the upcoming 2.51 release, with RC periods starting in early August and a final release planned for August 18th. Junio notes the usual summer slowdown but plans to keep this cycle shorter at 8 weeks. Several significant new topics have emerged, including a major change to make SHA-256 the default hash algorithm when running in breaking changes mode (preparing for Git 3.0), a new `git repo-info` command for querying repository characteristics, and a revival of the long-broken `git imap-send` with modern OAuth2.0 support.

Ongoing work includes Patrick Steinhardt's large-scale refactoring to remove `the_repository` usage from object access APIs, Karthik Nayak's performance improvements for bulk ref updates, and Taylor Blau's changes to prevent MIDX from referencing cruft pack objects. Junio also mentions the gradual deprecation of the legacy `git whatchanged` command. Several topics are marked as ready to merge to 'next' or 'master', while others await review responses or updated patch versions before progressing further.
