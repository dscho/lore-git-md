This is a small but useful refactoring patch in the ongoing git-credential-netrc helper discussion. It's the first of three patches in v2 of Maxim Cournoyer's series addressing symbolic port name handling.

The change makes the Perl shebang line in git-credential-netrc.perl more portable by using `/usr/bin/env perl` instead of a hardcoded `/usr/bin/perl` path. This allows the script to work better during development when running uninstalled, as it will find Perl from the user's PATH rather than requiring it in a fixed location. The installed version will still use the correct PERL_PATH as set during build.

While minor, this is a sensible improvement that follows common practice for Perl scripts. It doesn't affect the core credential helper functionality but makes development and testing slightly easier. The patch is clean and straightforward with no obvious downsides.

This sets up for the more substantive changes in patches 2/3 and 3/3 of the thread summary indicates will implement symbolic port resolution via getservbyname. The shebang change stands on its own merits regardless of how the larger port resolution discussion is resolved.
