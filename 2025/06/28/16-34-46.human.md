This is the final patch in a series implementing command-line overrides for diff context settings in interactive patch commands (add/checkout/commit/reset/restore/stash). The patch adds `-U` and `--inter-hunk-context` options to these commands, allowing users to override the diff.context and diff.interHunkContext config settings on a per-invocation basis.

The implementation follows the same pattern as other commands like `git diff` and `git log` that already support both config-based and command-line context settings. The patch includes comprehensive documentation updates and test coverage verifying the new options work as expected across all affected commands.

This completes the functionality planned for the series, which has undergone several rounds of review and refinement. The implementation appears solid with thorough test coverage and clear documentation. The only remaining discussion point is about test organization strategy (multi-command vs single-command verification), which Phillip Wood has requested clarification on.

The patch series as a whole represents a well-executed enhancement to Git's interactive patch interface, giving users more control over diff display while maintaining backward compatibility with existing config settings.
