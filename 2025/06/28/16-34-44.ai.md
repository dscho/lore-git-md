This is a test modernization patch in the ongoing series implementing diff context configuration for interactive patch operations. It converts manual `git config` calls to the `test_config` helper in t4055-diff-context.sh, which automatically cleans up test configurations. This change is preparatory work for subsequent patches in the series.

The tests verify how diff.context configuration affects various Git commands (log, diff, diff-files) and handle edge cases like non-integer and negative values. The test assertions remain unchanged - they still check the same behaviors, just with more reliable configuration management.
