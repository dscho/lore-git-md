This is a feature patch completing the implementation of diff context configuration support for interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). It's the final patch in a series that has evolved through multiple iterations with input from Junio C Hamano and Phillip Wood.

The patch adds command-line overrides (-U/--unified and --inter-hunk-context) that allow users to temporarily override their diff.context and diff.interHunkContext config settings when using interactive patch mode. This matches the behavior of other Git commands like diff and log that already support both config and command-line context settings.

Key technical changes include:
- New OPT_DIFF_UNIFIED and OPT_DIFF_INTERHUNK_CONTEXT macros in parse-options.h
- Passing context parameters through the add-patch infrastructure via struct add_p_opt
- Validation ensuring negative values are rejected consistently
- Documentation updates adding the new options to all relevant command man pages
- Comprehensive test coverage verifying the options work across all commands and properly override config settings

The implementation appears thorough, with careful attention to edge cases and validation. The tests cover both happy paths and error conditions. This completes the functionality started in earlier patches while maintaining all previous refinements from the review process. The only remaining discussion point in the thread is about test organization strategy (multi-command vs single-command verification).
