Test modernization patch converting manual `git config` calls to `test_config` in t4055-diff-context.sh.

This is part of a larger series (v3 2/4) improving diff context configuration for interactive patch commands. The patch focuses on test infrastructure cleanup, replacing direct `git config` invocations with the `test_config` helper which automatically cleans up configuration changes after each test. This ensures tests don't interfere with each other through leftover config settings.

The changes are mechanical but important for test hygiene - each of the 7 config operations in t4055-diff-context.sh is updated to use the safer wrapper. The tests themselves remain unchanged in behavior, continuing to verify how diff.context affects various Git commands (log, diff, diff-files) and handling of invalid values.

This groundwork enables subsequent patches in the series to safely add more configuration-related tests. The patch follows the series' pattern of modernizing test infrastructure before adding new functionality, as seen in the earlier grep-to-test_grep conversion.
