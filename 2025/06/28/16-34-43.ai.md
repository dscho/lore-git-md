Test modernization patch converting grep calls to test_grep in interactive patch test files.

This is the first patch in a v3 series implementing diff context configuration support for interactive patch commands. It updates the test suite to use the modern `test_grep` helper instead of raw `grep` in two test files (t/t3701-add-interactive.sh and t/t4055-diff-context.sh). The change provides better debugging output when tests fail by including the failed pattern and input in the error message.

The patch makes 38 line-by-line conversions from `grep` to `test_grep`, including some inverted matches (using `test_grep !`). It maintains all existing test logic while modernizing the implementation. The changes are straightforward mechanical replacements with no behavioral impact, serving as a prerequisite for subsequent patches in the series that will add new tests using this modern test infrastructure.

Key technical details:
- Updates t3701 (add-interactive tests) and t4055 (diff context tests)
- Converts both positive and negative grep assertions
- Maintains exact same test patterns and logic
- Part of larger effort to modernize test infrastructure
- No functional changes to the tests themselves

This is a routine test infrastructure improvement that follows established patterns in the Git test suite. The changes are uncontroversial and well-contained, serving as a foundation for the more substantive patches that follow in the series.
