This is a cleanup patch in Patrick Steinhardt's systematic `contrib/` directory overhaul series. It removes the long-empty `contrib/examples/` directory and its README, which had been kept as a historical note after the actual example scripts were removed in 2018. The rationale is straightforward: after seven years, this placeholder serves no practical purpose and can be safely deleted.

The patch is simple and uncontroversial, deleting a single file (the README) that contained only historical commentary about example scripts that no longer exist. This aligns with the series' broader goal of removing unmaintained or obsolete content from `contrib/` while formalizing clearer policies for what belongs there.

As part of the v3 series that has already incorporated feedback from maintainers, this change appears ready to merge. It's a small but sensible piece of the larger cleanup effort to make `contrib/` more purposeful and maintainable.
