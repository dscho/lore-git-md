This is part of Patrick Steinhardt's ongoing `contrib/` directory cleanup series (v3 09/11). The patch removes the `contrib/emacs/` directory, which has contained only stubs since 2018 when the actual Emacs integration code was removed in commit 6d5ed4836db. The removal follows the established pattern for this series - the directory contains non-functional stubs pointing users to modern alternatives (Emacs's built-in `vc-annotate` mode and third-party packages like Magit). The patch deletes three files totaling 45 lines: the README explaining the historical context and alternatives, plus two `.el` stub files that just showed error messages redirecting users elsewhere.

This is a straightforward application of the series' removal criteria, specifically targeting "broken functionality" (the stubs don't provide any actual features) with "clear alternatives" (Emacs's native VC mode and popular third-party packages). The commit message references the 2018 change that made these files obsolete, providing clear historical justification. The removal is non-controversial and aligns with Junio Hamano's guidance in the thread to focus on technical rather than time-based justifications.
