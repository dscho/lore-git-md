This is part of Patrick Steinhardt's v3 series (6/11) systematically cleaning up Git's `contrib/` directory, following the policy framework established in the cover letter. The patch removes the unmaintained "mw-to-git" MediaWiki transport helper.

The mw-to-git directory contained Perl scripts for accessing MediaWiki via Git, but has been essentially unmaintained in Git's tree for years. The last changes were security fixes in 2020, and tests have likely bitrotted. The original developer confirmed there's no motivation to keep maintaining it, and while the project has been spun out to GitHub, it hasn't seen activity there either.

The removal follows the series' established criteria - this component is unmaintained with a clear alternative (the GitHub fork) and no active community maintaining it in Git. The patch deletes 22 files totaling 3911 lines, including:
- Core Perl modules and scripts (Git/Mediawiki.pm, git-remote-mediawiki.perl)
- Test infrastructure (t/ directory with 5 test scripts)
- Documentation and build files

This continues the series' pattern of removing unmaintained contrib tools while documenting the rationale. The change is straightforward and uncontroversial, matching the policy framework that has already been discussed and refined through earlier thread feedback. No special considerations or edge cases are present in this particular removal.
