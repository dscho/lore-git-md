This is a follow-up discussion in the ongoing thread about improving FQDN detection in `git send-email`. Junio Hamano responds to concerns about platform compatibility with the `hostname` command flags.

The discussion centers around whether to use `hostname --fqdn` (Linux) versus `hostname -f` (macOS) for getting fully-qualified domain names. While `--fqdn` is more semantically clear, some platforms like Alpine Linux and macOS don't support it. Junio expresses initial reservations about `-f` potentially meaning different things on different platforms, but ultimately suggests accepting `-f` as the simplest solution, with the option to add configuration to disable it if platform-specific issues arise.

This email represents a compromise position in the thread, showing the maintainer's willingness to accept a practical solution (`-f`) despite semantic concerns, as long as there's documentation of the reasoning and an escape hatch for problematic platforms. The discussion appears to be converging toward a solution that balances correctness with real-world compatibility.
