This is part 5 of Patrick Steinhardt's v3 series cleaning up Git's `contrib/` directory, following the policy framework established in the cover letter. The patch removes the `contrib/hooks/` directory containing example hook scripts.

The hooks being removed include:
- `post-receive-email` (long deprecated in favor of git-multimail)
- `pre-auto-gc-battery` (checks if on AC power before GC)
- `setgitperms.perl` (manages file permissions metadata)
- `update-paranoid` (access control hook)
- Remaining multimail README

The commit notes these hooks were either unmaintained, had better alternatives (like git-multimail), or their functionality could be better served by documentation in `githooks(5)`. This follows the series' established criteria for broken/unmaintained tools with clear alternatives.

The removal is straightforward and uncontroversial, matching the policy framework's goals. With 1,443 lines deleted, this significantly reduces maintenance burden while preserving the core functionality through other means. The patch is well-justified and appears ready for merging.
