This is a test modernization patch in the `whatchanged` deprecation series. Elijah Newren provides feedback on Junio Hamano's patch that replaces `git whatchanged` calls with `git log --raw` in fast-import test scripts. The changes affect 7 test cases across t9300-fast-import.sh and t9301-fast-import-notes.sh.

He also confirms the typo 'developped' was already caught by Patrick Steinhardt. The technical changes themselves are straightforward replacements of the deprecated command with its modern equivalent, maintaining the same test functionality while preparing for `whatchanged`'s eventual removal.

The patch continues the series' pattern of systematically removing `whatchanged` usage from the codebase, in this case targeting test scripts that used the command for debugging during development. Newren's feedback focuses on commit message clarity rather than the changes themselves, which he endorses as "a definite positive change".
