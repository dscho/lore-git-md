Bugfix and validation tightening for the stash import/export feature. Phillip Wood provides a detailed review of the `do_import_stash()` function in the final patch of Brian Carlson's series, pointing out several validation weaknesses in the current implementation. His proposed fixup commit strengthens the import checks to ensure:

1. The chain consists of commits with exactly two parents (first parent being another imported stash or root commit, second parent being a valid stash commit)
2. Uses commit objects directly rather than converting between strings and object_ids
3. Adds proper parsing of parent commits
4. Reuses the existing `check_stash_topology()` function for validation

The changes make the import process more robust against malformed input while maintaining the same functionality. Phillip notes this is part of the final validation tightening for the export/import feature, which has otherwise reached technical consensus in the thread. The fixup can be applied directly to Brian's v5 patch series.
