Documentation patch in the `whatchanged` deprecation series. This is part of the completed track that systematically removes references to the deprecated `git whatchanged` command across Git's documentation.

The patch updates two documentation files to replace `whatchanged` references with alternative commands that won't be deprecated:
1. In `MyFirstObjectWalk.adoc`, changes the example reference point for new command placement from `cmd_whatchanged()` to `cmd_version()` when describing where to add a new `cmd_walken()` function.
2. In `user-manual.adoc`, replaces the example of commands sharing source files from `whatchanged/log` to `show/log` pair in `builtin/log.c`.

These changes are preparatory steps for the eventual removal of `whatchanged`, ensuring documentation examples won't need further updates when the command is removed. The patch follows the established pattern of the deprecation series by maintaining consistency with other documentation updates and includes Elijah Newren's suggested commit message phrasing. The changes are minimal and focused, affecting only the specific documentation examples without broader impact.
