Documentation patch updating references to the deprecated `git whatchanged` command in preparation for its eventual removal. This is part of the completed `whatchanged` deprecation track that has already been through extensive review.

The patch makes two straightforward documentation changes: replacing `whatchanged` with `version` as an example anchor point in the object walk tutorial, and substituting `show` for `whatchanged` when discussing commands that share source files in the user manual. These changes help future-proof the docs by removing references to a command that will be removed.

The changes are minimal and uncontroversial, following the established deprecation methodology. Junio Hamano (the Git maintainer) is the author, with Elijah Newren credited for help with the commit message, suggesting this has already gone through the review process. The patch appears ready for inclusion as part of the broader `whatchanged` removal effort.
