This is a follow-up patch in the `git send-email` domain validation series, addressing platform compatibility for FQDN detection. The email responds to Julian Swagemakers' feedback about the `hostname --fqdn` command not being universally supported across different platforms (notably macOS and Alpine Linux with BusyBox). - The patch originally used `--fqdn` for clarity in code readability
- Feedback revealed this flag isn't supported on macOS (which errors) and Alpine Linux (BusyBox implementation)
- All platforms do support the `-f` flag for FQDN detection
- Author confirms willingness to switch back to `-f` for broader compatibility
