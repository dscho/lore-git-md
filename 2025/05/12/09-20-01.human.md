This is the final patch in Patrick Steinhardt's v3 series cleaning up Git's `contrib/` directory, focusing on removing unmaintained scripts from the "stats" subdirectory. The patch removes two obsolete scripts while retaining one that still serves a purpose.

The removed scripts are:
1. `git-common-hash`: A tool for analyzing hash prefix uniqueness that hasn't been touched since 2012 and is made redundant by Git's modern automatic prefix scaling.
2. `mailmap.pl`: A Perl script for mailmap statistics that is now completely broken due to Perl syntax changes and clearly hasn't been used in years.

The patch keeps `packinfo.pl` (a `git-verify-pack` output formatter) since it still provides useful functionality with no current replacement, though the commit suggests this might eventually be moved into core Git. The removals follow the series' established criteria - the scripts are obsolete/unmaintained with clear alternatives or broken functionality.

This completes the v3 series' systematic cleanup of 18 `contrib/` components while establishing clearer policies for future maintenance. The changes are straightforward removals of clearly obsolete code with no expected controversy.
