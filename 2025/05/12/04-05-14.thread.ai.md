Thread identity: Discussion about removing unmaintained contrib scripts, specifically the "thunderbird-patch-inline" script from Git's contrib directory. Originated by Patrick Steinhardt as part of broader contrib cleanup efforts, with Phillip Wood now proposing an alternative to removal.

Core problem: The thunderbird-patch-inline script provides Thunderbird integration for editing patches inline but depends on the unmaintained ExternalEditor extension. The thread evaluates whether to remove this script given its unmaintained status or update it to work with the maintained External Editor Revived fork.

Current status: Phillip Wood has submitted a patch to update the script rather than remove it, modifying it to work with External Editor Revived (github.com/Frederick888/external-editor-revived). The changes include handling CR LF line endings as the new separator format and updating documentation references. This provides a working alternative to removal, though the fundamental question of the script's ongoing value remains open.

Key technical details: The original script depended on Thunderbird's unmaintained ExternalEditor extension. Phillip's patch adapts it to work with the maintained External Editor Revived fork by changing the message header/body separator detection logic in appp.sh and updating the README. The core functionality remains the same but now works with the maintained extension.

Participant positions: Patrick Steinhardt originally proposed removal due to unmaintained dependencies. Collin Funk noted the existence of External Editor Revived but didn't oppose removal. Phillip Wood now proposes keeping the script by updating it for the maintained extension, providing a technically sound patch that addresses the compatibility issues.

Open questions: Whether the updated script provides enough value to justify keeping it in contrib, given alternative patch submission methods exist. The technical viability is now addressed, but the maintenance burden question remains.
