Thread identity: Discussion about removing unmaintained contrib scripts, specifically the "thunderbird-patch-inline" script from Git's contrib directory. Originated by Patrick Steinhardt as part of broader contrib cleanup efforts.

Core problem: The thunderbird-patch-inline script provides Thunderbird integration for editing patches inline but depends on the unmaintained ExternalEditor extension. The thread evaluates whether to remove this script given its unmaintained status and available alternatives.

Current status: Consensus forming to remove the script. Collin Funk noted the existence of External Editor Revived (github.com/Frederick888/external-editor-revived) as a maintained alternative, but this doesn't change the fundamental argument that the contrib script is no longer necessary.

Key technical details: The script's functionality depends on Thunderbird's ExternalEditor extension. The original extension is unmaintained, though a maintained fork (External Editor Revived) exists. The script itself would still be redundant even with this alternative available.

Participant positions: Patrick Steinhardt proposed removal due to unmaintained dependencies. Collin Funk provided additional context about alternatives but didn't oppose removal. No other participants have weighed in yet on this specific script removal.

Related work: Part of a larger series cleaning up various unmaintained contrib scripts. This email focuses specifically on the Thunderbird integration aspect.
