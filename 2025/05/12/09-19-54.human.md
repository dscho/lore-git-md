This is a cleanup patch removing an obsolete tool from Git's `contrib/` directory, part of Patrick Steinhardt's systematic v3 series to remove unmaintained components.

The patch removes the "thunderbird-patch-inline" script and its documentation, which was designed to help send Git patches via Thunderbird using the ExternalEditor extension. The removal is justified because the required extension has been unmaintained since 2008 (with a fork seeing no updates since 2020), making the script incompatible with modern Thunderbird versions. The script itself hasn't seen meaningful updates in 10 years, indicating it's no longer in use.

This is one of 12 components being removed in the series, following the policy framework established in the cover letter that prioritizes removing broken or obsolete tools with clear alternatives. The removal is straightforward, deleting 75 lines of code and documentation, and aligns with the series' goal of cleaning up Git's contrib area.
