This is a follow-up discussion about the FQDN detection patch in the `git send-email` series. Julian Swagemakers points out a portability issue with using `hostname --fqdn` across different platforms, noting that while the flag works on some Linux distributions, it fails on macOS and Alpine Linux (which uses BusyBox). The key technical observation is that while the `--fqdn` long option isn't universally supported, the short `-f` option appears to work consistently across these platforms for getting the fully qualified domain name.

The email suggests modifying the patch to use `-f` instead of `--fqdn` for better cross-platform compatibility. This would affect the `maildomain_hostname_command` function added in the follow-up patches, which currently uses `--fqdn` to query the system hostname between the Net::Domain check and final fallback. The change would maintain the same functionality while working on more platforms, aligning with the series' goal of robust domain detection. This is a pattern seen in other Perl modules that perform hostname lookups.
