Documentation patch adding detailed function-level docstrings for the json-writer.h API, part of a GSoC project to improve JSON serialization documentation. This is the first of two patches in v2 of the series, focusing on comprehensive API reference documentation.

The patch adds detailed docstrings for all 25 functions in json-writer.h, explaining each function's purpose, parameters, and behavior. The documentation follows a consistent pattern, with clear descriptions of object vs array operations, parameter meanings (like the `precision` parameter for doubles), and important behavioral notes (such as the lack of bounds checking in `jw_array_argc_argv`). The docstrings also clarify edge cases and safety considerations, like the abort behavior in `jw_end` when called improperly.

This appears to be a thorough and well-structured documentation effort, with clear mentorship from experienced Git contributors (as shown by the Mentored-by tags). The docstrings follow Git's established style for API documentation and should make the json-writer interface more approachable. As noted in the thread context, this patch may be combined with or replaced by the second patch's higher-level usage guide, but it provides valuable standalone reference material in its current form.
