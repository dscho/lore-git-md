Bugfix for a memory leak in the `git am` command's StGit series handling. 

This patch fixes a straightforward memory leak in `builtin/am.c` where `series_dir_buf` wasn't being freed if `fopen()` failed while processing a StGit patch series. The fix adds the missing `free()` call in the error path. 

The change is small (just 3 lines added) and clearly correct - it follows the pattern seen elsewhere in the codebase for cleaning up allocated memory in error cases. The commit message explains the issue concisely and the patch author has included the standard sign-off. 

This appears to be a low-risk maintenance fix that plugs a minor resource leak in an error path. The `git am` command's StGit series functionality isn't one of Git's most heavily used features, but the fix is still worthwhile to keep the code clean.
