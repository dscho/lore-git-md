This is a follow-up patch in the `git send-email` improvement series, addressing platform compatibility for FQDN detection. The patch responds to Julian Swagemakers' feedback about using `hostname -f` instead of `--fqdn` for better cross-platform support, particularly on macOS and Alpine Linux (which uses BusyBox).

The author acknowledges the oversight and agrees to switch back to `-f`, noting they had used this flag previously but thought `--fqdn` would be more readable. This change aligns with the series' goal of robust domain handling while maintaining compatibility across different Unix-like systems. The patch demonstrates good responsiveness to community feedback in this now-mature series that has already received maintainer approval.
