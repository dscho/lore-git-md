Bugfix investigation for `git stash` branch display issue. K Jayatheerth confirms Stuart MacDonald's report about `git stash list` incorrectly showing submodule branch names instead of superproject branches in stash entries. The confirmation includes a minimal reproduction recipe showing how stashing in superproject `bugfix_bar` with submodule on `feature_sdk_foo` results in the stash entry displaying the submodule's branch name. The investigation verifies this is purely a display issue affecting stash metadata (branches and content remain correct) and confirms the behavior occurs on both Windows and Linux. The reporter notes this appears to be a regression from 2021 behavior and plans to examine stash code paths to identify the root cause. The technical details suggest the problem lies in how stash gathers HEAD information, incorrectly pulling from submodule context during superproject operations. No patch yet, but the thorough analysis and cross-platform verification move the bug from initial report to confirmed issue awaiting diagnosis.
