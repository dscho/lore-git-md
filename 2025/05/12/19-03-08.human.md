This is a test modernization patch in the ongoing `git whatchanged` deprecation effort. Junio Hamano updates several fast-import test scripts to replace `git whatchanged` calls with `git log --raw`, which provides equivalent output. The changes are mechanical substitutions across 7 test cases in t9300-fast-import.sh and t9301-fast-import-notes.sh.

The patch explains that these test calls were originally added for manual verification during test development, and while they could be removed entirely, keeping them with modern equivalents maintains the original intent while preparing for `whatchanged`'s eventual removal. The changes are straightforward and maintain test behavior, with Elijah Newren contributing to the commit message.

This is part of a larger series (position 3/6) that's systematically removing `whatchanged` usage throughout Git's codebase and tests. The patch demonstrates the deprecation process's thoroughness - even incidental test usage is being updated, though the command itself remains available for now. The changes are minimal and low-risk, just swapping one plumbing command for another with identical output format.
