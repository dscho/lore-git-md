Bugfix for a memory leak in `git am`'s StGit series handling. This is a follow-up to Lidong Yan's patch that fixes a case where `series_dir_buf` would leak if `fopen` failed in `split_mail_stgit_series()`. Junio C Hamano has reviewed the change and confirms it's correct, stating he will queue it for inclusion. The fix is minimal (adding a single `free()` call in the error path) and maintains the existing error behavior while properly cleaning up the allocated buffer. This appears to be the final word on this straightforward memory management issue, with no outstanding concerns remaining in the thread.
