This is a test modernization patch in the ongoing `git whatchanged` deprecation effort. Junio Hamano updates test scripts to use `git log --raw` instead of `git whatchanged` in preparation for the eventual removal of the deprecated command. The changes affect two fast-import test files (t/t9300-fast-import.sh and t/t9301-fast-import-notes.sh), replacing 7 instances where tests were using `whatchanged` for debugging-style output verification.

The patch maintains identical test functionality while switching to the modern equivalent command. The commit message explains these were likely added during test development for manual verification, and while tempting to remove entirely, keeping the verification with `log --raw` preserves the original intent while making the tests future-proof. Elijah Newren helped with the log message phrasing.

This is part of the completed `whatchanged` deprecation track that has already generalized the infrastructure and systematically removed documentation/test references. The changes align with the deprecation methodology by updating test suites before command removal, though this particular change doesn't touch the core deprecation infrastructure files. The patch demonstrates the thoroughness of the deprecation process by ensuring even incidental test references are updated.
