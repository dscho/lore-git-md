This is a contributor housekeeping patch that's part of a larger series (1/11) to clean up contrib scripts. It removes the obsolete `contrib/remotes2config.sh` script that was meant to migrate old-style remote configurations to the modern config format.

The script was introduced in 2007 to help transition from `.git/remotes/` directory-based remote configuration to the current config-based system. However, the patch argues it's now obsolete for several reasons: (1) Git itself provides better migration via `git remote rename` which handles both `.git/remotes/` and `.git/branches/`, (2) the script isn't advertised or used, (3) it hasn't been modified in 18 years, and (4) it doesn't work out-of-the-box since it requires manual PATH adjustments to find `git-sh-setup`.

The removal appears uncontroversial - the script is clearly deprecated, unused, and superseded by built-in functionality. The patch is straightforward, simply deleting the file with a thorough commit message explaining the rationale. This seems like a safe cleanup as part of the larger series.
