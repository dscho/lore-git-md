Documentation patch adding a usage guide for Git's JSON writer API. This is the second patch in a two-part series from a GSoC participant, following the detailed function-level docstrings added in patch 1.

The patch adds a structured "USAGE" section to json-writer.h that explains how to compose JSON documents using the various jw_* functions. It covers initialization, building objects vs arrays, nested structures, and cleanup. The guidance is practical rather than exhaustive, focusing on common patterns like when to use inline vs separate builders and how to handle string array cases.

As noted in the thread context, this complements the detailed API reference from patch 1, though the author is open to feedback on whether both documentation layers are needed. The patch has mentor sign-offs and appears well-considered, with clear examples of the test helper demonstrating the patterns described. The only minor issue is a typo ("Relase" instead of "Release") in the final bullet point.
