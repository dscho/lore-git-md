This is a refactoring patch that's part of the ongoing deprecation infrastructure work for Git commands. It extracts the deprecation warning logic for `git pack-redundant` into a reusable helper function called `you_still_use_that()`, which can be shared with other commands being deprecated (like `git whatchanged` in the parallel series).

The patch moves the warning message and enforcement logic from `builtin/pack-redundant.c` to a new function in `usage.c`, making it available via `git-compat-util.h`. The behavior remains exactly the same - the command will refuse to run unless the `--i-still-use-this` flag is provided, showing the same warning message about the command's pending removal. A new test case is added in `t5323-pack-redundant.sh` to verify this enforcement.

This is a clean refactoring that follows the established deprecation methodology, with Elijah Newren providing input on the commit message. The change is straightforward and well-tested, serving as a building block for the broader deprecation infrastructure being developed across both the `pack-redundant` and `whatchanged` tracks.
