This is a follow-up patch in the `git send-email` improvement series, specifically addressing FQDN (fully qualified domain name) detection. The patch adds a new fallback check using the `hostname --fqdn` command on Linux and macOS systems before ultimately falling back to 'localhost.localdomain'.

The change makes sense technically - it leverages a commonly available system command that's more reliable than the current Net::Domain Perl module, while still validating the result with the existing `valid_fqdn()` function. The v2 update properly handles command failures by avoiding premature assignment of invalid results.
