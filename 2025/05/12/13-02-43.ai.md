Contrib script maintenance with a proposed update to the planned removal of thunderbird-patch-inline. Phillip Wood responds to the ongoing discussion about removing this Thunderbird integration script by proposing an update instead, adapting it to work with the maintained External Editor Revived extension.

The patch modifies the script to handle a different message header/body separator format used by the new extension (CR LF line endings vs the original's format) and updates documentation references from the unmaintained ExternalEditor to External Editor Revived. The changes include adjustments to the separator detection logic in appp.sh and updates to the README file to reflect the new dependency.

This represents a counterpoint to the removal proposal, suggesting the script could remain useful with maintenance updates. The patch appears technically sound, addressing the specific compatibility issue with the newer extension while maintaining the script's core functionality. However, it doesn't fundamentally change the question of whether this contrib script provides enough value to justify keeping it versus directing users to alternative patch submission methods.
