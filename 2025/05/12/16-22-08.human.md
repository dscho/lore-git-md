This is a technical review from Junio Hamano on Phillip Wood's patch to update rather than remove the thunderbird-patch-inline contrib script. The patch adapts the script to work with the maintained External Editor Revived extension.

Junio notes that the patch was slightly damaged in transit due to email formatting, but identifies a specific issue: the patch removes the old separator logic but doesn't clean up the now-unused SEP variable assignment from earlier in the script. He points out that while the new separator handling is correct, the old SEP assignment should be removed for consistency.

The review is narrowly focused on this technical detail, not rehashing the broader thread discussion about whether to keep or remove the script. Junio's observation suggests the patch needs one more cleanup before being ready, though the core functionality appears sound. This moves the technical discussion forward while leaving the higher-level "keep vs remove" debate to others.
