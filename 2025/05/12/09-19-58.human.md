This is part of Patrick Steinhardt's ongoing cleanup of Git's `contrib/` directory (v3 series, patch 8/11). The patch removes the `git-resurrect.sh` script, which was designed to help recover deleted branches by searching reflogs.

The removal is well-justified: the script hasn't been touched since its introduction in 2009, doesn't work with the reftable backend (it directly reads `.git/logs/HEAD`), and requires manual setup to use since it's not properly installed by Git's build system. The commit message also cites StackOverflow data showing users overwhelmingly prefer direct `git-reflog` usage over this script.

This follows the series' established pattern of removing unmaintained components that either have better alternatives or don't function properly. The patch is straightforward - it simply deletes the 181-line script file with no other changes needed.
