This is a documentation patch series from a GSoC participant, introducing new documentation for the json-writer module. The series consists of two patches that aim to make the JSON serialization functionality in Git more approachable.

The first patch adds docstrings to the various `jw_*` functions in json-writer.h, providing inline documentation for each API. The second patch (new in v2) adds a higher-level usage overview explaining when to use which functions, which the author suggests might be sufficient on its own. The motivation comes from the author's GSoC project which will use this module, and they hope the documentation will help others working with JSON in Git.

The changes are purely additive documentation with no code modifications, touching only json-writer.h. The author is open to feedback on whether both documentation approaches are needed or if the usage overview alone would suffice. This appears to be the author's first contribution since GSoC acceptance, as noted by the mention of their first "Mentored-by" tag. The patch seems well-intentioned and focused, though reviewers may want to evaluate whether both documentation layers are necessary or if they could be consolidated.
