This is the final patch in Patrick Steinhardt's v3 series cleaning up Git's `contrib/` directory, specifically targeting scripts in the "stats" subdirectory. The patch removes two obsolete scripts while retaining one that still serves a purpose.

The removed scripts are:
1. `git-common-hash`: A tool for analyzing hash prefix uniqueness that's been untouched since 2012 and is now redundant with Git's built-in prefix heuristics.
2. `mailmap.pl`: A Perl script for mailmap statistics that has bitrotted to the point of no longer running due to Perl syntax changes, with its last update also in 2012.

The patch retains `packinfo.pl`, which provides useful packfile statistics formatting that isn't currently available in core Git. The commit message suggests this functionality might eventually be moved into `git-verify-pack` itself, but keeps the script for now as it has no direct replacement.

This follows the series' established pattern of removing unmaintained components that either have core alternatives or are clearly unused, while preserving tools that still serve a unique purpose. The removal criteria here focus on technical obsolescence (hash prefix tool superseded by core functionality) and bitrot (non-functional mailmap script) rather than just age.
