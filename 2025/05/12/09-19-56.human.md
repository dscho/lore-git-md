This is part of Patrick Steinhardt's systematic cleanup of Git's `contrib/` directory (v3 patch 6/11 in the series). The patch removes the unmaintained "mw-to-git" MediaWiki integration tools.

The tools provided scripts for accessing MediaWiki via Git, but have been essentially unmaintained in Git for years. The last changes were security fixes in 2020, and tests have likely bitrotted. According to Matthieu Moy (one of the original authors), there's no motivation to keep maintaining it in the Git community. The project has been spun out to GitHub (Git-Mediawiki/Git-Mediawiki) but hasn't seen much activity there either.

The removal follows the policy framework established in the series' cover letter, which targets unmaintained components with clear alternatives. This deletion removes 22 files totaling 3911 lines, including:
- Core Perl modules and scripts for MediaWiki integration
- Test files and infrastructure
- Documentation
- Makefiles and configuration files

The patch is well-justified and part of a coherent series that has incorporated feedback from Junio Hamano and others. It follows the established criteria for removal (unmaintained status, existing alternative home) without relying on time-based justifications.
