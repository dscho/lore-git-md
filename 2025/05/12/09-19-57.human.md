This is part of Patrick Steinhardt's systematic cleanup of Git's `contrib/` directory (v3 series, patch 7/11). The patch removes the unmaintained "persistent-https" remote helper, which was meant to speed up SSL operations by maintaining persistent connections.

The helper is clearly obsolete - it hasn't been updated since 2016 and fails to compile with modern Go toolchains (requiring Go 1.23+). The patch demonstrates the build failure and removes all related files (7 files, 875 lines total) from the contrib directory. This follows the series' established criteria for removal: unmaintained code with broken functionality.

The removal is straightforward and uncontroversial, fitting well with the series' goal of cleaning up `contrib/` by removing components that no longer serve a purpose. The patch maintains the high standard seen throughout the series, providing clear justification and technical details of the obsolescence.
