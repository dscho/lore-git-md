This thread addresses a memory leak in `git am`'s StGit series handling, specifically in the `split_mail_stgit_series` function where a buffer allocated via `xstrdup` wasn't being freed if `fopen` failed. Lidong Yan submitted a minimal, well-scoped fix that adds the missing `free()` call in the error path while maintaining the existing error behavior. Patrick Steinhardt has since reviewed and confirmed the correctness of this solution. The patch is uncontroversial - it fixes a clear memory management issue without introducing new complexity or affecting user-visible behavior. With the fix validated, this appears ready to be picked up for inclusion in the next release cycle.
