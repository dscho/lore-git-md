Thread summary: A patch series (1/11) to clean up contrib scripts begins with removing the obsolete `contrib/remotes2config.sh` script. This script was introduced in 2007 to migrate from the old `.git/remotes/` directory-based remote configuration to the modern config-based system, but is now unused and superseded by built-in `git remote rename` functionality. The script hasn't been modified in 18 years, isn't advertised, and doesn't work out-of-the-box due to PATH issues with `git-sh-setup`. The removal is straightforward and uncontroversial as part of a larger contrib cleanup effort.
