This thread began as a technical fix for Perl 5.41.4+ warnings in git-cvsserver's `escapeRefName` function, but has evolved into a broader discussion about the future of this legacy CVS bridge. Ondřej Pohořelský's v4 patch removing the unused function has been approved by Junio C Hamano after testing confirmed it was dead code since its 2012 introduction. Original author Matthew Ogilvie's input was pivotal, both in confirming the function was intentionally unused and in questioning whether anyone still uses git-cvsserver given CVS's obsolescence.

Junio has now signaled that git-cvsserver's full removal should proceed, following Git's standard deprecation process. This involves documenting the change in BreakingChanges, similar to how other obsolete components have been retired. While the technical work is straightforward (the problematic function is already removed), the thread is now focused on the proper procedure for deprecation. The consensus appears to be forming that git-cvsserver has outlived its usefulness, with Junio referencing recent precedents for similar removals. Ondřej is positioned to drive the implementation, while Junio provides guidance on the process. The discussion serves as a case study in how the project handles legacy components when their maintenance burden outweighs their utility.
