Platform compatibility fix for cvsserver Perl script. This patch addresses a build failure that occurs with Perl 5.41.4 and newer versions due to a precedence warning between the `!` operator and regex pattern matching in the `escapeRefName` function. The fix adds parentheses to clarify the intended evaluation order of the expression `! $refName=~/^[1-9][0-9]*(\.[1-9][0-9]*)*$/`.

The change is minimal (a single line modification) and well-justified by linking to the relevant Perl 5.41.4 changelog that introduced the new warning. The patch credits Jitka Plesnikova for identifying the issue and proposing the solution. This appears to be a straightforward maintenance fix to keep Git's Perl components compatible with newer Perl versions, though it's worth noting the patch doesn't include test coverage for this specific change.
