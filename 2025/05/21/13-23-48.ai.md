Test preparation patch in a series addressing exec-path security issues. This is a follow-up to reviewer feedback on the first version of the patch series.

The patch modifies t7005-editor.sh to better isolate test environment changes, responding to Patrick Steinhardt's suggestion to use `test_when_finished` for cleanup. The original version had used global unset operations, while the new approach would localize the environment modifications to individual test cases. The author questions whether the `export` needs to remain outside the test script to properly test override sequences, indicating this is still an open implementation question.

Key technical details:
- Replaces global `unset EDITOR VISUAL GIT_EDITOR` with per-test cleanup
- Converts `git config` calls to `test_config`
- Maintains test for editor paths containing spaces
- Preserves the test sequence that verifies editor override behavior

The discussion reveals an implementation tension between test isolation requirements and the need to verify environment variable override sequences. This patch sits within a larger series that's addressing cross-platform PATH handling security concerns, with particular attention to Windows Unicode support and Git's subprocess spawning behavior. The test changes here are preparatory work for those more substantial modifications.
