Test cleanup patch in security-focused series. Patrick Steinhardt reviews the first patch in D. Ben Knoble's series addressing PATH security issues, which prepares the test environment in t7005-editor.sh. The original version cleaned up environment variables and config after tests, but Patrick suggests using `test_when_finished` for more robust cleanup that happens even if tests fail. He provides a sample diff showing how to move the cleanup into each test case. The second hunk converting direct `git config` calls to `test_config` gets his approval.

This is part of a larger effort to prevent Git's internal binaries from being exposed in child processes' PATH, particularly important for Windows users experiencing issues with Vim integration. The test improvements here lay groundwork for subsequent patches that modify process spawning behavior. Patrick's feedback focuses on test hygiene rather than the core security changes, suggesting the technical approach is sound but could be made more robust.
