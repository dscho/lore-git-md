Documentation patch addressing references to AsciiDoc files, with feedback from Junio C Hamano on proper linking conventions.

This email continues the thread about updating documentation references from .txt to .adoc extensions following the file renaming in commit 1f010d6. Junio acknowledges the patch's correctness in most cases but raises two important points about the Documentation/ changes:

1. The gitprotocol-v2.adoc changes should use proper `linkgit:` syntax (like `linkgit:git[1]`) rather than just changing the extension, as this would be more consistent with the surrounding links.

2. The xref: syntax used in build-systems.adoc is unusual in Git's docs and its rendering should be verified.

Junio notes that the changes to non-AsciiDoc files (like contrib/subtree/README) are correctly handled as simple extension updates. The feedback suggests the patch needs revision to standardize the documentation linking style while maintaining the extension updates. The thread shows careful attention to documentation consistency beyond just mechanical updates.
