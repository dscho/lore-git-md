This is a feature patch series adding pathspec support to `git diff --no-index`. Jacob Keller proposes allowing pathspec filtering for comparing files outside a Git repository, matching the behavior of regular in-repository diffs.

The series has gone through several iterations, with v4 simplifying the approach by using a single pathspec array and adding logic to skip directory roots during comparison. The key change from v3 is dropping modifications to `prefix_path_gently` in favor of a new `match_leading_pathspec()` helper that handles directory matching more cleanly.

The implementation touches pathspec matching internals and the diff-no-index machinery, with corresponding documentation updates and new test cases. The changes look well-considered, with the commit messages detailing the design decisions and test coverage showing both basic and edge-case behavior. This appears ready for review as it addresses previous feedback while maintaining the original goal of bringing pathspec behavior parity to no-index diffs.
