This is a platform compatibility fix for Git's CVS server Perl script, now in its third iteration. The patch addresses a build warning that appears with Perl 5.41.4+ due to ambiguous operator precedence between `!` and regex matching in the `escapeRefName` function.

Junio C Hamano acknowledges Ondřej Pohořelský's v2 patch, which added parentheses to clarify the precedence (`! ($var =~ /pat/)`) and properly credited Jitka Plesnikova for both reporting and suggesting the fix. While this version resolves the warning, Junio had previously suggested an alternative approach using Perl's dedicated `!~` negation operator (`$var !~ /pat/`) that would be more idiomatic.

The patch is now queued, suggesting the maintainer finds the current solution acceptable, though the thread leaves open the possibility of a v3 incorporating Junio's suggested refinement. This small but precise change demonstrates Git handles even minor compatibility warnings seriously while balancing technical correctness with contributor attribution.
