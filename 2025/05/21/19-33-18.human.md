This is a documentation patch review response from Junio C Hamano regarding a patch that updates references to AsciiDoc files from .txt to .adoc extensions. The original patch by Jouke Witteveen aimed to complete the transition started in commit 1f010d6 by fixing remaining references to the old .txt filenames.

Junio points out that while the patch is generally correct, it doesn't go far enough in some cases. He notes that references in Documentation/ should use the proper `linkgit:` syntax (like `linkgit:git[1]`) rather than just changing the extension. He also questions whether the xref syntax used in one change is actually supported in Git's documentation system.

The review suggests that the patch should either:
1. Consistently update all references to use proper linking syntax where applicable (in Documentation/ files)
2. Or leave the Documentation/ references unchanged if we're not ready to make them proper links yet

Junio does confirm that the changes outside Documentation/ (in contrib/subtree/, mergetools/, and sub-process.h) look correct as-is. The review maintains a constructive tone while clearly identifying areas needing improvement, showing attention to documentation consistency details.
