This is the final patch in a 3-part series adding pathspec support to `git diff --no-index`. The patch implements the actual pathspec filtering functionality when comparing two directories outside a Git repository.

The key technical changes include:
- Modifying `fixup_paths()` to return whether both inputs are directories (enabling pathspec support)
- Adding pathspec` parameter handling in `diff-no-index.c` with `parse_pathspec()` using the new `PATHSPEC_NO_REPOSITORY` flag
- Implementing directory traversal with pathspec matching via `read_directory_contents()`, using the `match_leading_pathspec()` helper from patch 2
- Calculating skip offsets to properly handle relative pathspec matching
- Comprehensive test coverage in t4053-diff-no-index.sh for various pathspec scenarios (positive/negative, globs, nested paths)

The implementation carefully handles edge cases like:
- Rejecting pathspecs when comparing files or file+directory
- Properly matching directory vs non-directory paths
- Maintaining existing DWIM behavior for non-directory cases
- Skipping repository-specific pathspec features (attributes, from-top)

The patch includes documentation updates and 75 lines of new test cases covering:
- Basic pathspec acceptance/rejection
- Negative pathspecs
- Nested directory matching
- Glob patterns
- Combined glob+exclude patterns

This completes the series' goal of bringing repository-style pathspec filtering to `git diff --no-index`, while maintaining the command's existing behavior for non-directory comparisons. The implementation builds cleanly on the infrastructure (flags and helper functions) established in the earlier patches.
