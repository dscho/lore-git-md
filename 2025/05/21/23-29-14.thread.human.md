Jacob Keller's patch series adding pathspec support to `git diff --no-index` was merged in v4, but a critical buffer overflow was subsequently discovered when handling directory paths with trailing slashes (issue #5836). The vulnerability stems from flawed path length calculations in `diff-no-index.c`, specifically around the `skip1`/`skip2` logic for directory prefixes. Jacob is working on a fix while re-examining the matching approach.

Johannes Schindelin, who identified the security issue, has now proposed a more fundamental improvement to the directory comparison logic. Rather than using numeric skip values that require repeated memory operations, he suggests maintaining directory prefixes in persistent `strbuf` buffers throughout the diff operation. This would both address the immediate safety concerns and improve performance by avoiding redundant string manipulations during recursive directory traversal.

The thread now has two parallel tracks: 1) Jacob's immediate fix for the buffer overflow, which remains the priority given its security implications, and 2) Johannes' proposal for structural changes to the path handling architecture. Junio Hamano, who originally merged the series, is monitoring both discussions. The resolution will likely involve a security fix followed by potential optimizations to the directory comparison logic, with additional test cases needed to cover trailing slash scenarios that exposed the original vulnerability.
