Performance optimization for `git repack` when handling promisor packs with kept packs. This is Han Young's second version of a patch that significantly speeds up promisor pack repacking by avoiding unnecessary object enumeration from kept packs (either via `--keep-pack` or `.keep` files).

The patch builds on Tomáš Trnka's original discovery and previous work in this area, now incorporating feedback from the mailing list discussion. The key improvement remains skipping object enumeration from kept packs during promisor repacking, which in testing reduced processing time from 67.6s to 18.8s and output pack size from 4.5MB to 1.6MB for a 2.7GB promisor pack.

The implementation uses `SKIP_IN_CORE_KEPT_PACKS` and `SKIP_ON_DISK_KEPT_PACKS` flags in `builtin/repack.c` to mark and then skip kept packs. The change is focused (14 lines added, 4 modified) and appears well-contained.
