Jouke Witteveen submitted a patch updating documentation references from .txt to .adoc extensions as part of Jean-Noël Avila's documentation modernization effort. Junio C Hamano reviewed the patch and identified two issues: one with `linkgit:` syntax (which he corrected) and another revealing that Git's documentation toolchain doesn't support AsciiDoc's `xref:` feature.

In his latest response, Junio proposes a practical solution for the `build-systems.adoc` file - updating the extension while keeping the basic link format, accompanied by a comment explaining the `xref:` limitation. This maintains backward compatibility while clearly marking the syntax for future improvement once the toolchain evolves. The approach balances immediate needs with long-term goals, though the broader question of documenting these constraints in Git's standards remains open.

The thread has so far involved just the original author and Junio, with the discussion surfacing previously undocumented toolchain limitations that will affect others working on the documentation conversion. The solution demonstrates the careful attention needed when modernizing Git's documentation while maintaining compatibility with existing infrastructure.
