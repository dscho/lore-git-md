This is a bugfix patch addressing a build compatibility issue in git-cvsserver. The change fixes a Perl precedence warning that appears in Perl 5.41.4 and newer versions, where the logical NOT operator (`!`) and regex match operator (`=~`) could be misinterpreted without explicit parentheses. The fix simply adds parentheses around the regex test in the `escapeRefName` function to clarify the intended evaluation order.

The patch is straightforward - a one-line change that adds the parentheses while maintaining the exact same functionality. The commit message clearly explains the issue and credits Jitka Plesnikova for identifying both the problem and solution. This appears to be a clean, well-justified fix for a real compatibility problem that would otherwise break builds with newer Perl versions.
