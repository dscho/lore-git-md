This is a small refactoring patch that addresses a sign-compare warning in the graph drawing code. The author, Octavio Carneiro, notes that `graph_line->width` was declared as `size_t` while being compared with `git_graph->width` (which is `int`), triggering compiler warnings. The solution is straightforward: change the type of `graph_line->width` to `int` to match.

The patch removes the now-unnecessary `DISABLE_SIGN_COMPARE_WARNINGS` define and makes the type change in the `graph_line` struct definition. This appears to be a clean, focused change that aligns the code with the existing type usage pattern in the graph subsystem. The diff is minimal (1 insertion, 3 deletions) and the rationale is clearly explained. While not a critical fix, it's the kind of small cleanup that helps maintain code hygiene.
