Feature patch completing pathspec support for `git diff --no-index`. This is the final patch in Jacob Keller's v4 series that enables pathspec filtering when comparing directories outside a Git repository.

The patch modifies `git diff --no-index` to accept pathspec arguments when both inputs are directories, matching the behavior of repository-based diffs. Key changes include:
- Extending `fixup_paths()` to return whether both paths are directories
- Parsing additional arguments as pathspecs when directory mode is detected
- Modifying directory traversal to respect pathspec filtering
- Adding comprehensive tests for various pathspec scenarios (negations, globs, nested paths)

The implementation builds on the new `match_leading_pathspec()` helper and `PATHSPEC_NO_REPOSITORY` flag introduced earlier in the series. It carefully handles path prefix skipping to ensure pathspecs match relative to the compared directories. The documentation is updated to clarify the new syntax and restrictions (pathspecs must be relative and only work in directory-vs-directory mode).

This appears to be a well-considered implementation with thorough test coverage. The commit message provides clear rationale and explains the technical choices, particularly around directory traversal and pathspec matching edge cases. The patch completes the series' goal of bringing repository-like pathspec filtering to no-index diffs.
