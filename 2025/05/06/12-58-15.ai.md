This is the first patch in a 2-part series introducing a new `--reviewby` feature for `git rebase` and `git am`. The patch adds a convenience flag that automatically appends a `Reviewed-by:` trailer using the committer's identity, similar to how `--signoff` works.

The implementation:
- Adds `--reviewby` option to both `git rebase` and `git am`
- Implements the core functionality in sequencer.c with a new `append_reviewby()` function that mirrors `append_signoff()`
- Includes extensive test coverage (300+ lines across new test files)
- Modifies documentation for both commands
- Handles edge cases like duplicate trailers and conflict resolution

The patch follows the same pattern as signoff functionality, with parallel implementations in the rebase and am code paths. It touches sequencer internals, command implementations, and adds new state tracking for the reviewby option. The tests verify behavior in various scenarios including interactive rebase, conflict resolution, and with empty commits.
