This is the first patch in a 17-part series refactoring the object database (ODB) subsystem as part of the ongoing `the_repository` removal effort. Patrick Steinhardt renames `struct raw_object_store` to `struct object_database` (and the corresponding header file from `object-store.h` to `object-database.h`), arguing that the "raw_" prefix is misleading (there is no non-raw variant) and that "object_database" better reflects its purpose while allowing for cleaner function naming (like `odb_has_object()`).

The change is mechanical but widespread, touching 8 files and updating function signatures, struct definitions, and documentation. The patch establishes the naming convention that will be used throughout the rest of the series, which aims to make the ODB subsystem more self-contained by passing `struct object_database` directly rather than via `the_repository`. This foundational change sets up the architectural direction for the subsequent patches while maintaining careful API boundaries.
