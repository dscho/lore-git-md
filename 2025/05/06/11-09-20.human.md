This is part 7/17 of Patrick Steinhardt's series refactoring the object database (ODB) subsystem to remove `the_repository` global dependencies. The patch focuses on `odb_mkstemp()`, which creates temporary files in the object database directory. 

The change modifies `odb_mkstemp()` to take an explicit `object_database` parameter instead of implicitly using `the_repository`, and updates all callers to pass `the_repository->objects`. The function's documentation is also updated to clarify it operates on the primary ODB backend. 

The patch follows the established pattern of the series by mechanically converting another ODB-related function to work with explicit repository state rather than globals. It touches several pack-related operations (fast-import, index-pack, bitmap writing) and bundle handling, but maintains the same behavior while removing the global dependency. 

This is another incremental step in the larger effort to make the ODB subsystem properly repository-aware, with clean boundaries between repositories. The changes are straightforward and follow the same approach seen in earlier patches of the series.
