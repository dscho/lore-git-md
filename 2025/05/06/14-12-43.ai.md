This is the final patch in Patrick Steinhardt's series to clean up Git's `contrib/` directory, removing the obsolete `git-new-workdir` script and its associated test files. The script was an early solution for creating separate working directories that has been fully superseded by `git worktree` since 2015. The removal follows the series' established pattern - the script hasn't been updated in over a decade (last change in 2014) and its functionality is now better served by core Git features.

The patch deletes the 105-line shell script from `contrib/workdir/` along with its `.gitattributes` file and two test scripts that depended on it (`t1021-rerere-in-workdir.sh` and part of `t3000-ls-files-others.sh`). The test removal is straightforward since these were specifically testing the contrib script's behavior rather than core Git functionality.

This completes the series' goal of removing broken/unmaintained/obsolete components from `contrib/`. The `git-new-workdir` case is particularly well-justified given the direct replacement by `git worktree`, making this a low-controversy removal. No behavior changes in core Git result from this deletion, and users who still need the script can easily find historical versions in the Git archive.
