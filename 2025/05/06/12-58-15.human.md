Feature addition for `git rebase` and `git am` introducing a `--reviewby` option. This is the first patch in a 2-part RFC series proposing new trailer functionality. The patch adds a `--reviewby` flag that automatically appends a `Reviewed-by:` trailer using the committer's identity, similar to how `--signoff` works. The implementation covers both `git rebase` (merge and interactive backends) and `git am`, with extensive test coverage (300+ lines across new test files).

The change appears well-considered, mirroring the existing signoff infrastructure closely. It touches sequencer, rebase, and am components, adding parallel logic for the new trailer type. The tests verify behavior in various scenarios including conflict resolution, interactive rebase, and edge cases around duplicate trailers. 

This would be particularly useful for workflows that track code review through commit trailers. The implementation looks solid, though the RFC status suggests the author is open to discussion about whether this warrants a dedicated flag versus using a more flexible `--trailer` approach (which will be covered in patch 2/2).
