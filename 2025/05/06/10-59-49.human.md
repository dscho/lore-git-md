This is a CI/build system patch series that improves Meson integration with Git's test suite. Patrick Steinhardt proposes changes to make Meson properly parse TAP output from Git's tests, which will give better reporting of test results including skipped tests and subtest counts.

The series includes both Meson configuration changes and fixes to the test scripts themselves to ensure they generate valid TAP output. The Meson changes require version 1.8 or newer due to a bugfix the author contributed upstream. The test script fixes address cases where shell traces or other output was breaking the TAP format.

The main benefit is more informative test output when running tests through Meson, showing passed subtests and properly identifying skipped tests. The changes appear focused and well-motivated, with the author having already contributed the necessary Meson fix upstream. The patch series looks like a solid improvement to the build system integration.
