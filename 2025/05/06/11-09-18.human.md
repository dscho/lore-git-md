This is part 5/17 of Patrick Steinhardt's series refactoring the object database (ODB) subsystem to remove dependencies on `the_repository` global. The patch continues the mechanical work of converting direct repository access to use the new parent pointer relationships established in earlier patches.

The key change here is converting `find_odb()` to take an `object_database` parameter instead of a `repository` parameter, and renaming it to `odb_find_backend()` to better reflect its purpose. The function now searches for an ODB backend within a specific object database rather than implicitly using `the_repository`. All callers (in commit-graph and midx code) are updated to pass `the_repository->objects` instead of `the_repository`.

This is a straightforward mechanical change that builds on the structural foundation laid in patches 1-4. The patch appears well-executed with thorough updates to all call sites and clear documentation of the new function. It advances the series' goal of removing `the_repository` dependencies while maintaining existing functionality. The changes are focused and limited to the ODB lookup mechanism, keeping the scope manageable for review.
