This is a platform compatibility patch addressing BSD variants' errno behavior in symlink operations, specifically for the `open_nofollow()` wrapper function. It's the third iteration of a fix for test failures that occur when checking packed-refs filetypes on NetBSD and FreeBSD.

The patch handles two BSD-specific errno values (EFTYPE on NetBSD and EMLINK on FreeBSD) that these systems return when `open()` with O_NOFOLLOW encounters a symlink, where POSIX specifies ELOOP. The change modifies `wrapper.c` to translate these platform-specific errnos to the standard ELOOP value, maintaining consistent behavior across systems. This builds on the earlier work in cfea2f2da8 that introduced filetype checking for packed-refs.

The implementation uses preprocessor directives to conditionally define and handle the platform-specific errnos, with careful attention to style requirements (proper `#ifdef` nesting and spacing). The patch includes a clear test case showing the failure it fixes, where the error message changes from a generic "Inappropriate file type" to Git's specific "not a regular file but a symlink" wording.
