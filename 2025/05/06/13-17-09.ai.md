This is a test infrastructure patch in a series improving TAP output compatibility for Meson integration. Phillip Wood responds to Patrick Steinhardt's initial patch that redirected repository creation output to /dev/null and converted highlight prerequisite checks to use test_lazy_prereq in several test scripts (hash-object, submodules, gitweb). 

Phillip acknowledges the technical correctness of the changes but raises a design consideration - suggesting these commands might better belong inside test_expect_success() blocks rather than just suppressing their output. He notes the current approach doesn't substantially worsen the situation since the lost test_create_repo output isn't critical, and approves of the highlight prerequisite changes. 

The discussion occurs while the series is on temporary hold due to MinGW compatibility issues, though this particular patch doesn't appear to be the source of those problems. The changes are mechanical test infrastructure tweaks affecting t/t1007-hash-object.sh, t/t4041-diff-submodule-option.sh, t/t4060-diff-submodule-option-diff-format.sh, t/t7401-submodule-summary.sh, and t/t9500-gitweb-standalone-no-errors.sh. Phillip's feedback suggests potential future direction for test structure improvements while not blocking the current changes.
