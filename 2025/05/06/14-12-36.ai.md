This is the third patch in Patrick Steinhardt's series to clean up Git's `contrib/` directory, focusing on removing obsolete remote helper stubs for Mercurial and Bazaar. The patch deletes three files: two stub scripts (`git-remote-bzr` and `git-remote-hg`) and their README, totaling 37 lines removed.

The stubs were created in 2014 (commit b2c851a8e67) when the actual helper implementations were moved to external projects maintained by Felipe Contreras. The stubs simply printed warnings directing users to the new locations, making them effectively documentation artifacts rather than functional code. Given they've existed unchanged for over a decade, the patch argues they're unlikely to still be useful to anyone.

This removal aligns with the series' criteria of eliminating unmaintained components, though unlike the first patch's clearly obsolete migration script, these stubs represent a slightly different case - they're documentation redirects rather than deprecated functionality. The patch doesn't modify any active code paths or affect Git's core operations, only removing what amounts to historical signposts.

Key technical details include the external project locations (github.com/felipec/git-remote-{bzr,hg}) and the 2014 transition context. The removal is straightforward with no behavior changes, just deletion of files that were already non-functional. This continues the series' pattern of low-risk cleanup targeting clearly vestigial components.
