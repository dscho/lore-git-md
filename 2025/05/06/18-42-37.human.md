This is a minor style correction in the context of the completed packed-refs optimization series. Junio Hamano provides feedback on patch 1/4's test case, suggesting a clearer way to create an empty packed-refs file for testing purposes.

The original test used `touch` to create the file, which Junio notes could imply unnecessary concern about file timestamps. He recommends directly specifying the empty file path instead, making the test's intent (creating an empty file) more immediately obvious to readers.

This is a small but thoughtful improvement to the test's readability, coming from the maintainer after the main technical discussion of the series has concluded. The change doesn't affect the functionality of the patch, which already correctly handles empty packed-refs files by skipping consistency checks for them.
