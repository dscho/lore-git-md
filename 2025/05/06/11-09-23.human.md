This is part 10/17 of Patrick Steinhardt's series refactoring the object database (ODB) subsystem to remove `the_repository` global dependencies. The patch focuses on eliminating implicit repository access in functions that handle temporary primary ODB backends.

The changes rename and modify two key functions:
- `set_temporary_primary_odb()` becomes `odb_set_temporary_primary_backend()`
- `restore_primary_odb()` becomes `odb_restore_primary_backend()`

Both functions now take an explicit `struct object_database*` parameter instead of implicitly using `the_repository`. The patch updates all callers in `tmp-objdir.c` to pass the repository's ODB explicitly. The behavior remains the same - these functions still manage temporary object storage during operations like push/pull - but now do so without relying on global state.

This continues the series' pattern of methodically converting ODB subsystem functions to work with explicit ODB pointers.
