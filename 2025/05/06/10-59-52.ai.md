This is a CI/build system patch that's part of a series improving Meson integration with Git's test suite. It introduces a `test_kwargs` dictionary in meson.build to consolidate common test parameters, starting with the `timeout: 0` setting that was previously repeated across multiple test definitions. The change affects test configurations in contrib/credential/netrc, contrib/subtree, and the main test directory, standardizing how timeout values are specified. This prepares for adding more shared test parameters in future commits. The patch is a straightforward refactoring that doesn't modify test behavior, just the build system configuration. It follows logically from the previous patches in the series that addressed TAP output parsing issues, continuing the theme of Meson test infrastructure improvements. The changes are mechanical and unlikely to be controversial, though reviewers might want to verify the timeout value (0 meaning no timeout) is appropriate for all test cases.
