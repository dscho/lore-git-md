This is part 16/17 of Patrick Steinhardt's series refactoring the object database (ODB) subsystem as part of the `the_repository` removal effort. The patch renames `pretend_object_file()` to `odb_pretend_object()` to align with the naming conventions established in previous patches of the series.

The function is used to temporarily register an object in memory without writing it to disk, primarily for operations like blame that need to work with in-memory objects. The rename follows the pattern seen in patches 13-15/17 where ODB-related functions are being standardized to use the `odb_` prefix and take explicit ODB parameters rather than repository parameters.

Key technical changes:
- Function renamed from `pretend_object_file()` to `odb_pretend_object()`
- Parameter changed from `struct repository *repo` to `struct object_database *odb`
- Internal implementation updated to use the ODB's cached objects array directly
- Only one caller updated in `blame.c` since the function has limited usage
- No compatibility wrapper added due to minimal existing usage

The changes are mechanical and follow the same approach as previous patches in the series. The patch continues the pattern of making ODB operations work through explicit object database parameters rather than implicitly through `the_repository`. Since this is a rarely used function and the changes are straightforward, this appears to be a low-risk change that maintains the naming consistency of the larger refactoring effort.
