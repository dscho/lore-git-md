This is the second patch in a series improving Meson's TAP output parsing for Git's test suite. It addresses how shell traces from test verbosity flags (`--verbose`, `-x`) are handled to prevent them from breaking TAP output format.

The patch modifies `test-lib.sh` to redirect test stdout to stderr when verbose mode is active, rather than keeping it on stdout. This ensures TAP parsers receive clean output while still preserving debugging information in the stderr stream. The change is demonstrated by updates to `t0000-basic.sh` tests, where verbose output is now properly separated from the TAP results.

The author notes this loses the ability to separate stdout from stderr in verbose output, but argues this distinction hasn't proven useful in practice. The change appears straightforward and well-tested, with clear updates to both the test-lib infrastructure and its test cases. This continues the series' focus on making Git's test output reliably parseable by Meson's TAP consumer.
