This is part 5/17 of Patrick Steinhardt's series refactoring the object database (ODB) subsystem to remove `the_repository` dependencies, continuing the `the_repository` removal effort. The patch focuses on eliminating `the_repository` usage in `find_odb()` by passing the object database directly and renaming the function to `odb_find_backend()`.

Key technical changes:
- Renames `find_odb()` to `odb_find_backend()` to better reflect its purpose
- Changes the function signature to take a `struct object_database*` instead of `struct repository*`
- Updates all callers (commit-graph and midx code) to pass `the_repository->objects` instead of `the_repository`
- Maintains the same behavior of locating an ODB backend by its object directory path
- Dies with an error if the object directory cannot be found (unchanged behavior)

The patch affects several components:
- `builtin/commit-graph.c` sees the most changes with variable renaming (`odb` -> `backend`) and updated calls
- `midx-write.c` gets a straightforward call site update
- `odb.c` implements the renamed function with the same logic but using the new parameter
- `odb.h` updates the function declaration and adds documentation

This continues the series' pattern of methodically removing `the_repository` dependencies while maintaining functionality. The changes are mechanical but important for establishing proper object database boundaries. Future patches in the series will likely continue this pattern with other ODB-related functions.
