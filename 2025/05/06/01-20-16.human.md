This is Junio Hamano's regular "What's cooking in git.git" status update, summarizing the current state of development branches and upcoming changes. These emails serve as a central coordination point for the Git project, tracking which patches are being considered, which are ready for the next release, and which need more work.

The update covers three main categories of changes:

1. **Recently graduated to 'master'**: Several build system improvements (Meson cleanups, Windows/ARM64 support), a NetBSD errno compatibility fix, and new Meson targets for header checking and performance benchmarking.

2. **New topics proposed for inclusion**: These include more build/CI cleanups, documentation fixes, a bugfix for glob matching with special characters, test result aggregation for Meson, and new `--no-maintenance` options for Scalar subcommands. Most are marked to merge to 'next' soon.

3. **Ongoing work still cooking**: Notable items here include promisor-remote capability extensions, hashmap API fixes, improvements to `git diff --minimal`, object store cleanups, and various performance optimizations around pack bitmaps and delta compression. Several of these are awaiting rerolls or have open questions.

The email also highlights two potentially controversial changes: a plan to deprecate `git whatchanged` (with a humorous `--i-still-use-this` option during transition) and improvements to `send-email` for Outlook compatibility.

For maintainers and active contributors, this provides a comprehensive snapshot of the project's direction. Casual observers can see the broad themes: continued Meson build system maturation, Windows platform improvements, and ongoing internal code cleanups, plus some user-facing refinements in areas like Scalar and diff behavior.
