This is the second patch in a refactoring series aimed at enabling mmap usage for packed-refs files during fsck operations. The patch extracts the buffer allocation logic from `load_contents()` into a new helper function `allocate_snapshot_buffer()`. This prepares for future patches that will need to reuse this allocation logic without opening the packed-refs file directly.

The change is straightforward - it moves the existing mmap/malloc decision making and buffer setup into a reusable function while maintaining identical behavior. The refactoring was suggested by Jeff King and Patrick Steinhardt as part of the ongoing effort to improve memory efficiency when handling large packed-refs files.

This is a clean-up patch that doesn't change functionality yet, but it enables the subsequent patches in the series to more easily implement mmap-based access during fsck operations. The diff shows careful attention to maintaining all existing error handling and edge cases while making the code more modular.
