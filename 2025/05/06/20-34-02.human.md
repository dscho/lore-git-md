This is a cleanup patch removing the MediaWiki integration tools from Git's `contrib/` directory, part of Patrick Steinhardt's ongoing series to remove obsolete/unmaintained components. 

Junio Hamano is responding to Patrick's patch that proposes removing the `mw-to-git/` directory, which contains tools for accessing MediaWiki via Git. The tools have been effectively unmaintained in Git's tree, with only a few security-related fixes in recent years. The tests for these tools are known to be bitrotted and not run regularly.

The key point in this exchange is that while the external project hosting these tools (Git-Mediawiki on GitHub) also shows limited recent activity (last updated March 2022), Junio agrees it's still a more appropriate home than Git's main repository. He notes this removal doesn't need to wait for the Git 3.0 boundary (unlike some other components in the series) since Git was never the primary home for these tools to begin with.

This continues the systematic cleanup of `contrib/` by removing specialized integrations that are better maintained elsewhere or have become obsolete. The patch appears uncontroversial and ready for inclusion.
