Bugfix targeting Git LFS integration in git-p4. This patch corrects how git-p4 handles executable bits for LFS pointer files, bringing it in line with a 2015 LFS spec change that says pointer files should preserve the executable bit from the original file rather than always being non-executable.

The change simplifies the LFS processing code by removing redundant mode handling - the `git_mode` parameter is no longer passed through the LFS processing chain since the mode is now handled at the top level. The patch affects several methods in the LargeFileSystem class and its subclasses, with the most notable changes being in `processContent()` and `generatePointer()`. The MockLFS test class is updated to match the new simplified return signature.

The fix appears straightforward and well-motivated by the LFS spec change referenced in the commit message. The change reduces code complexity while fixing the executable bit behavior, suggesting it's a net improvement. The patch doesn't include new tests, but since it's fixing behavior to match an established spec, that may be reasonable.
