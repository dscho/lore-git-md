This is part 5 of Patrick Steinhardt's series to clean up Git's `contrib/` directory by removing obsolete components. The patch removes the `contrib/hooks/` directory, which contained example hooks that were either highly specific, unmaintained, or already superseded by external projects.

The removed hooks include:
- `post-receive-email` (superseded by git-multimail)
- `pre-auto-gc-battery` (checks if on AC power before GC)
- `setgitperms.perl` (permissions/ownership tracking)
- `update-paranoid` (access control hook)

The rationale is that example hooks should be documented in `githooks(5)` rather than shipped as files. The multimail hook was already removed in 2021 in favor of its upstream project. The removal follows the same pattern as previous patches in the series - targeting clearly abandoned functionality that hasn't seen meaningful updates in years.

This continues the systematic cleanup of `contrib/` that has so far removed obsolete migration scripts, remote helper stubs, and Thunderbird integration. The patch is straightforward with no behavior changes to core Git, just removing 1,443 lines of unmaintained hook examples.
