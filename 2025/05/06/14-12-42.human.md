This is part of Patrick Steinhardt's ongoing series to clean up Git's `contrib/` directory by removing obsolete components. The patch removes the `contrib/emacs/` directory, which has contained only stub files since 2018 when the actual Emacs integration code was removed in commit 6d5ed4836db.

The directory previously housed three Emacs-related files: `git.el` for Git status/command access, `git-blame.el` for blame functionality, and a README explaining the transition. All were effectively deprecated years ago in favor of built-in Emacs VC mode (particularly `vc-annotate` for blame) and third-party packages like Magit. The files being removed have contained only error messages pointing users to these alternatives since 2018.

This follows the same pattern as previous removals in the series - eliminating long-deprecated code where better-maintained alternatives exist. The removal is straightforward with no expected impact, as the files have been non-functional stubs for 7 years. The patch deletes 45 lines of essentially dead code (33 from the README and 6 lines each from the two `.el` stub files).
