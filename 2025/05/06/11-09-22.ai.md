This is part 9/17 in Patrick Steinhardt's series refactoring the object database (ODB) subsystem to remove `the_repository` dependencies, continuing the `the_repository` removal effort. The patch focuses on iterator-style functions that operate on alternate object databases.

The key changes in this patch:
1. Renames `foreach_alt_odb()` to `odb_for_each_backend()` and modifies it to take an explicit `struct object_database*` parameter instead of implicitly using `the_repository`
2. Renames `for_each_alternate_ref()` to `odb_for_each_alternate_ref()` with the same parameter change
3. Updates all callers across 8 affected files to use the new functions with `the_repository->objects` explicitly passed
4. Introduces new typedefs for the callback functions with more descriptive names (`odb_for_each_backend_fn` and `odb_for_each_alternate_ref_fn`)
5. Maintains the same behavior while removing global repository dependencies

The changes are mechanical but touch several important subsystems that handle alternate object databases, including:
- `count-objects` command
- `receive-pack` (push/pull protocol)
- submodule handling
- diagnostics collection
- fetch negotiation
- revision walking

The patch follows the established pattern of the series by:
1. Renaming functions to be ODB-specific
2. Adding explicit ODB parameters
3. Updating callers to pass the repository's ODB explicitly
4. Preserving all existing functionality
