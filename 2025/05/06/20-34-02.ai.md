This is a patch removing the MediaWiki integration tools from Git's `contrib/` directory, part of Patrick Steinhardt's ongoing series to clean up obsolete/unmaintained components.

The patch targets the `mw-to-git/` directory containing tools for accessing MediaWiki via Git. The justification is threefold: the code is effectively unmaintained in Git (last security fixes in 2020), the test suite is unused and likely bitrotted, and the functionality has been spun out to a dedicated GitHub repository (Git-Mediawiki/Git-Mediawiki). 

Junio Hamano approves the removal, noting that while the external project also shows limited recent activity (last update March 2022), it's still a more appropriate home than core Git. He specifically contrasts this with other removals in the series that require Git 3.0 coordination, stating this particular component was never properly Git's responsibility to maintain.

The removal is straightforward with no test dependencies or transition concerns. This continues the systematic cleanup of `contrib/` by removing specialized integrations that belong outside core Git, following the pattern established earlier in the series for components like the persistent-https helper and git-resurrect.sh. The patch represents one of the less controversial removals in the series, with clear justification and no outstanding questions.
