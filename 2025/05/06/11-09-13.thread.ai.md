1. Core structural changes:

   - Renamed `struct object_directory` to `struct odb_source` (patch 2/17)
   - Updated implementation files from `object-store.{c,h}` to `odb.{c,h}` (126 files in patch 3/17)
   - Standardized API names with `odb_` prefix (`odb_read_object()`, `odb_has_object()`, etc.)
   - Added repository tracking via parent pointers in patch 4/17
   - Patch 5/17 converts `find_odb()` to `odb_find_source()` with explicit `object_database` parameter
   - Patch 6/17 makes `assert_oid_type()` repository-agnostic as `odb_assert_oid_type()`, updating 3 call sites in commit-tree and commit code
   - Patch 7/17 converts `odb_mkstemp()` to take explicit `object_database` parameter, updating 7 call sites in fast-import, index-pack, bundle-uri, pack-bitmap-write, and pack-write
