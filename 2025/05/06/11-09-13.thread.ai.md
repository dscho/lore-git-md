Patrick Steinhardt's v5 series (17 patches) completes the refactoring of Git's object database (ODB) subsystem to remove `the_repository` global state and enable pluggable ODB backends. The series components:

1. Structural foundation:
   - Renamed `struct raw_object_store` to `struct object_database` (patch 1/17)
   - Renamed `struct object_directory` to `struct odb_source` (patch 2/17) with Justin Tobler suggesting naming improvements
   - Updated includes from `object-store.{c,h}` to `odb.{c,h}` (126 files in patch 3/17)
   - Added repository tracking via parent pointers (patch 4/17) with Justin noting a comment should reference `odb->source_by_path` instead of `r->objects->source_by_path`
   - Established `odb_` prefix convention for API names

2. Key conversions:
   - `find_odb()` -> `odb_find_source()` with explicit ODB parameter (patch 5/17)
   - `assert_oid_type()` -> `odb_assert_oid_type()` (patch 6/17)
   - `odb_mkstemp()` updated to take explicit ODB (patch 7/17)
   - Alternates handling converted (14 files in patch 8/17) with Justin Tobler providing a typo fix and seeking clarification on path handling during transition
   - Submodule ODB tracking moved to repository storage (patch 11/17)
   - `oid_object_info()` -> `odb_read_object_info()` (48 call sites in patch 13/17)
   - `repo_read_object_file()` -> `odb_read_object()` (47 call sites in patch 14/17)
   - `has_object()` -> `odb_has_object()` (30 call sites in patch 15/17)
   - `pretend_object_file()` -> `odb_pretend_object()` (3 files in patch 16/17)
   - `read_object_with_reference()` -> `odb_read_object_peeled()` (8 files in patch 17/17)

3. Technical impact:
   - Eliminated `the_repository` from odb.c internals (patch 12/17)
   - Established clean API boundaries for future pluggable backends
   - Improved code organization through consistent naming
   - Reduced global state via explicit ODB parameters
   - Maintained backward compatibility throughout transition
   - Path handling for alternates remains temporarily tied to repository storage (patch 8/17) with plans to move to ODB structure
