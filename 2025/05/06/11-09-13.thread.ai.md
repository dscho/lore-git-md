Patrick Steinhardt's v6 series (17 patches) continues the architectural refactoring of Git's object database (ODB) subsystem to eliminate `the_repository` global state and enable pluggable ODB backends. The series begins with foundational renames (`raw_object_store` -> `object_database` in patch 1/17, `object_directory` -> `odb_source` in patch 2/17) and establishes parent pointers between ODB components (patch 4/17) for repository tracking without global state.

The latest patch converts iterator-style alternates functions to explicit `object_database *odb` parameters: `foreach_alt_odb()` -> `odb_for_each_alternate()`, `for_each_alternate_ref()` -> `odb_for_each_alternate_ref()`, updating 8 call sites across count-objects, receive-pack, submodule handling, diagnostics, fetch-pack, and revision walking. Callback types are renamed (`alt_odb_fn` -> `odb_for_each_alternate_fn`) and new API functions documented in odb.h.
