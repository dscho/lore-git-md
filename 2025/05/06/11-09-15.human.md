This is part 2/17 of Patrick Steinhardt's series to refactor the object database (ODB) subsystem as part of the ongoing `the_repository` removal effort. The patch renames `struct object_directory` to `struct odb_backend` to better reflect its role as a storage backend interface, decoupling the name from the filesystem-based implementation.

The change is motivated by the long-term goal of supporting pluggable object storage backends that may not use directories at all (like databases). The rename affects 28 files with 180+ line changes, updating all references to the structure and its related functions. The new name `odb_backend` is more generic and will accommodate future storage implementations like `files_odb_backend`.

This is a straightforward rename with no functional changes, following the pattern established in the first patch of the series. The change is well-contained and mechanical, touching only the ODB-related code paths. It continues the architectural work to make the object storage layer more modular and independent of `the_repository`.
