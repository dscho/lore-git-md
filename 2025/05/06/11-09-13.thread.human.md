Patrick Steinhardt's 17-patch series refactoring Git's object database (ODB) subsystem has reached its third version, systematically eliminating the `the_repository` global while enabling future pluggable backends. The changes rename core functions with an `odb_` prefix (like `odb_read_object()`), reorganize files with `odb.h` at root level and implementations in an `odb/` subdirectory, and update over 100 callers to pass repository state explicitly. Junio Hamano has confirmed this matches Git's established patterns, noting the parallel with how refs are organized (`refs.h` with `refs/` subdirectory). The series maintains all existing behavior while removing global state - a prerequisite for future ODB backend work. Derrick Stolee reviewed the foundational patches, and the changes are now complete with the final patch converting `read_object_with_reference()` to use the new `odb_` naming. The thread shows consensus on the architectural approach as this multi-year effort to modernize Git's object storage layer reaches a milestone.
