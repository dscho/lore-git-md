Patrick Steinhardt's v5 series (17 patches) has completed its refactoring of Git's object database (ODB) subsystem, with the final patch converting `read_object_with_reference()` to `odb_read_object_peeled()`. This concludes a systematic effort to eliminate `the_repository` global state while enabling future pluggable ODB backends.

The series establishes a new architectural foundation by:
- Renaming core structures (`raw_object_store` → `object_database`, `object_directory` → `odb_source`)
- Converting all major functions to use explicit ODB parameters with consistent `odb_` prefixes
- Updating over 150 files while maintaining backward compatibility

Junio Hamano has been reviewing the series, which has evolved through five iterations with input from Derrick Stolee and others. The work touches nearly every part of Git that interacts with objects, from basic existence checks to complex operations like blame and tree-walking. With the final patch now converting the last remaining ODB function, the series appears ready for consideration in the next development cycle.
