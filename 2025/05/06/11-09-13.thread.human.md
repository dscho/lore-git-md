Patrick Steinhardt has kicked off a major refactoring effort to continue removing Git's reliance on the `the_repository` global variable, this time focusing on the object database (ODB) subsystem. The 17-patch series begins with a foundational rename of `struct raw_object_store` to the more accurate `struct object_database`, since there's no "non-raw" variant and the structure truly represents a database of objects. This initial patch updates type declarations and function signatures across 8 files, introducing new `odb_new()` and `odb_clear()` functions while keeping behavior unchanged.

The broader series will make the object storage subsystem self-contained by passing `struct object_database` directly rather than via `the_repository`, following the pattern used in earlier ref store refactorings. Subsequent patches will rename `object-store.h` to `object-database.h`, remove `the_repository` dependencies from the ODB layer, and standardize function names with an `odb_` prefix. The changes touch 139 files and over 1000 lines of code, representing a significant step in the multi-year effort to eliminate global state from Git's architecture. Reviewers should pay particular attention to how the changes affect alternate/submodule ODB handling and the new parent pointer relationships between ODB instances.
