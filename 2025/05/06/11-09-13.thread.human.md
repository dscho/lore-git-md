Patrick Steinhardt's series to refactor Git's object database (ODB) subsystem continues with version 4, now at patch 12/17. The work systematically removes dependencies on the `the_repository` global variable while enabling future pluggable backends. The latest patch focuses on internal ODB functions, converting them to use explicit repository parameters instead of global state.

Key changes in this iteration include updating alternate refs handling and object parsing functions to use repository-specific configurations and hash algorithms. The patch removes the last internal uses of `the_repository` from `odb.c`, following the same mechanical conversion pattern established earlier in the series. This includes switching config lookups to `repo_config_get_value()` and using the passed repository's hash algorithm rather than the global `the_hash_algo`.

The series has seen positive review feedback, with Junio Hamano confirming the integration path and Derrick Stolee providing Reviewed-by tags on foundational patches. The changes maintain existing behavior while preparing the codebase for Patrick's planned pluggable ODB backend work. With this patch, the ODB subsystem conversion nears completion, having addressed both external API and now internal function dependencies on global state.
