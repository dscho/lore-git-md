This thread covers Patrick Steinhardt's v5 series (17 patches) that completes the refactoring of Git's object database (ODB) subsystem to remove `the_repository` global state and enable pluggable backends. The series represents a major architectural change, systematically converting the ODB layer to use explicit parameters instead of global state while maintaining backward compatibility.

The work has undergone thorough review, with Justin Tobler providing detailed feedback across multiple versions. Key changes include renaming core structures (`struct raw_object_store` to `struct object_database`), establishing consistent `odb_`-prefixed APIs, and converting over 150 files to the new patterns. Derrick Stolee has reviewed the foundational patches, and Junio Hamano is currently evaluating the series for merging.

In the latest exchange, Patrick clarified a transitional aspect of path handling in patch 8/17 regarding alternates - while the patch moves to explicit ODB parameters, it still temporarily uses repository paths through `repo_git_path()`. This is one of the final documentation refinements in a series that has already addressed all substantive technical feedback. With all planned conversions complete and only minor commit message clarifications remaining, the work appears ready for integration.
