This is a removal of the "persistent-https" remote helper from Git's contrib directory, part of Patrick Steinhardt's systematic cleanup series. The helper was designed to speed up SSL operations by maintaining persistent connections but has been unmaintained since 2016 and no longer compiles with modern Go versions.

Junio Hamano confirms this removal differs from others in the series because the helper has clearly bitrotted (failing to compile with current toolchains) rather than just being unmaintained. He notes the historical version remains available in Git's history for reference purposes if needed. This aligns with the series' goal of removing broken or obsolete components from contrib/.

The removal is straightforward with no test dependencies or transition period needed, unlike some other components in the series that required coordination with Git 3.0 changes. This marks another uncontroversial step in the broader contrib/ cleanup effort, following the pattern of removing unmaintained functionality that either has core Git equivalents or has become non-functional.
