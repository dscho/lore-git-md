This is part 6/17 of Patrick Steinhardt's series refactoring the object database (ODB) subsystem as part of the `the_repository` removal effort. The patch continues the mechanical work of eliminating global repository dependencies by modifying `assert_oid_type()` to take an object database parameter instead of implicitly using `the_repository`.

The changes are straightforward: the function is renamed to `odb_assert_oid_type()` and now accepts a `struct object_database*` parameter. The implementation now uses the repository pointer stored in the passed ODB rather than the global. The patch updates callers in `commit-tree.c` and `commit.c` to pass `the_repository->objects` (maintaining current behavior while removing the implicit dependency).

This is a typical incremental patch in the series - focused, mechanical, and clearly building on the structural changes from earlier patches. The changes are limited to just what's needed to remove the `the_repository` dependency while preserving existing functionality. Reviewers would mainly check that all call sites were properly updated and that the parent pointer access (`odb->repo`) is correct.
