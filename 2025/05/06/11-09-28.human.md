This is patch 15/17 in Patrick Steinhardt's series refactoring the object database (ODB) subsystem as part of the `the_repository` removal effort. The patch renames the `has_object()` function to `odb_has_object()` to better align with modern coding guidelines and the naming pattern established in previous patches for ODB-related functions.

The change is mechanical but widespread, updating 30 files across the codebase where the function is called. A compatibility wrapper is provided to avoid breaking in-flight topics. The patch follows the same pattern seen in earlier patches (13/17 and 14/17) that standardized other ODB interfaces.

The rest of the series has been methodically eliminating global repository dependencies in the ODB subsystem through structural changes and function conversions. This patch continues that work by standardizing the object existence checking interface while maintaining backward compatibility. The changes appear straightforward and well-contained, following the established pattern from previous patches in the series.
