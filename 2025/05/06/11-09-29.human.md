This is patch 16/17 in Patrick Steinhardt's series refactoring the object database subsystem as part of the `the_repository` removal effort. The patch renames `pretend_object_file()` to `odb_pretend_object()` to align with the naming conventions established in earlier patches for ODB-related functions.

The function is used to temporarily cache an object in memory before it's written to persistent storage, primarily for cases like `blame` where we need to work with unsaved objects. The change follows the pattern seen in patches 13-15, converting from repository-centric to ODB-centric naming and parameters. Unlike some previous conversions, no compatibility wrapper is provided since the function has limited usage (only in `blame.c`).

The mechanical changes update the single call site in `blame.c` and modify the function signature to take an `object_database` parameter instead of a `repository`. The implementation remains functionally identical while better reflecting the ODB subsystem boundaries being established by this series.

This continues the series' steady progress toward eliminating `the_repository` dependencies, with each patch making incremental but focused improvements to the codebase's structure. Reviewers should verify the `blame` functionality remains correct, though the changes appear straightforward.
