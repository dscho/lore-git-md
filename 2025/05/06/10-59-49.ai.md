This is a CI/build system patch series that improves Meson integration with Git's test suite. The main goal is to enable Meson to properly parse TAP output from Git's tests, which allows for better reporting of test results including skipped tests and subtest counts. The series requires Meson 1.8+ due to an upstream bugfix the author contributed.

The changes span several areas: fixing test scripts that produced malformed TAP output, preventing shell traces from polluting test output, and modifying Meson build files to properly configure test execution. The most significant change is in `meson.build` where TAP parsing is implemented, while the test fixes address various output formatting issues that would break TAP compliance.

The series appears well-motivated and technically sound, with each patch addressing a specific aspect of the problem. The author has already contributed the necessary Meson fix upstream, indicating this is part of a coordinated effort. The changes are focused on build/test infrastructure rather than core Git functionality, so they're unlikely to be controversial but will be valuable for developers using Meson builds.
