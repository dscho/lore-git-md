This RFC thread explores adding trailer-handling functionality to `git rebase` and `git am`, with Li Chen proposing two approaches: a specialized `--reviewby` flag (modeled after `--signoff`) and a general `--trailer` option. The discussion has evolved into a debate between specialized convenience versus general configurability.

Phillip Wood has been the primary advocate for a unified `--trailer` approach, arguing that `--signoff`-style flags are historical artifacts. He recently proposed technical solutions to make `--trailer` more flexible, including configurable defaults and author-matching for identity trailers. Kristoffer Haugsbakk raised some implementation concerns about these proposals, which Phillip addressed with alternatives.

Junio Hamano has now weighed in strongly, agreeing with Phillip's view that specialized flags like `--signoff` (and by extension `--reviewby`) represent legacy design choices. While not proposing new technical solutions himself, Junio's position as maintainer carries significant weight. He also noted Phillip's plan to review Li Chen's `--trailer` implementation, keeping the technical evaluation moving forward.

The core questions remain open: whether to support both specialized and general mechanisms, how to best implement default values for trailers, and how to handle committer identity formatting. With Junio's clear signal favoring the general `--trailer` approach, the discussion may now focus more narrowly on refining that implementation rather than maintaining parallel solutions.
