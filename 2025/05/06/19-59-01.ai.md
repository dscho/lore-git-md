This is a final cleanup in Patrick Steinhardt's series to remove obsolete/unmaintained components from Git's `contrib/` directory. The patch removes the `emacs/` directory, which has contained only stub files since 2018 when its functionality was replaced by Emacs' built-in `vc-annotate` mode. 

Junio Hamano approves the removal, noting this particular deletion doesn't need to wait for the Git 3.0 transition like some other components in the series. The emacs stubs represent a clear case of functionality that has been fully superseded by external tooling (Emacs' own version control integration) for over seven years.

This completes the technical review of the series' removals, with only timing considerations remaining for a couple components (`remotes2config.sh` and `git-new-workdir`) that have dependencies on Git 3.0 changes or test infrastructure. The emacs directory removal is straightforward since it's been non-functional for years and has no remaining users or test dependencies.
