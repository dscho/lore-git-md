This is the third patch in a series refactoring the packed-refs backend to enable mmap optimizations. The patch extracts the temporary mmap cleanup logic from `create_snapshot()` into a new helper function `munmap_snapshot_if_temporary()`. This prepares for future work where the same cleanup will be needed during packed-refs consistency checks.

The change is straightforward - moving 13 lines of existing mmap cleanup code into a reusable function and updating the original call site. The new function handles the case where we need to copy mmapped content to a heap buffer when using `MMAP_TEMPORARY` strategy, maintaining the same safety checks and behavior.

This continues the series' pattern of clean refactoring with no behavior changes, following suggestions from Jeff King and Patrick Steinhardt. The extracted function will be used in the upcoming final patch that enables mmap for large packed-refs files during fsck operations. The patch is small (18 lines net change) and well-contained, with the existing test coverage continuing to verify the behavior.
