This is the seventh patch in Patrick Steinhardt's series to clean up Git's `contrib/` directory, targeting the removal of the "persistent-https" remote helper. The helper was designed to speed up SSL operations by maintaining persistent connections, but has been unmaintained since 2016 and no longer compiles with modern Go toolchains (requiring Go 1.23+).

The patch removes 875 lines of Go code (client.go, proxy.go, socket.go), build files (Makefile), documentation (README), and licensing (Apache 2.0). The removal follows the same pattern as previous patches in the series - identifying clearly abandoned functionality that fails to build with current tooling. The helper's last update was in commit accb613afd2 to support Go 1.7+, but modern Go toolchain's module requirements (go.mod) make it uncompilable today.

Key technical details removed include:
- The proxy daemon architecture (git-remote-persistent-https--proxy)
- Unix socket authentication and connection management
- HTTP/HTTPS reverse proxy implementations
- Build infrastructure embedding Git version information
- Configuration documentation for URL rewriting in .gitconfig

This continues the systematic removal of unmaintained components from contrib/, with no impact on core Git functionality. The patch follows the series' established criteria and justification pattern, though unlike some previous removals, there's no mention of an external replacement project for this SSL optimization functionality.
