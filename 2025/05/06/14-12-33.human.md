This is a cover letter for a cleanup series targeting Git's "contrib/" directory. Patrick Steinhardt proposes removing several outdated or broken tools and scripts from contrib/, following up on previous discussions about the directory's purpose. The series removes 10 items based on criteria like being broken, unmaintained for 5+ years, or having better alternatives.

The cover letter outlines a vision for contrib/ as a staging area where tools either graduate to core Git, spin out as independent projects, or get removed. It also suggests future reorganization, like moving development tools to a new "tools/" directory and examples into documentation. The patch series itself is the first step - removing clearly obsolete items like the emacs directory, remote helper stubs, and various scripts.

The changes are straightforward deletions of unmaintained code, with no behavior changes to Git itself. The series appears well-motivated and uncontroversial, though the follow-up policy discussions about contrib/'s role may generate more debate. The cover letter provides good context for reviewers to assess each individual removal patch.
