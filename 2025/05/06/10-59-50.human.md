This is the first patch in a CI/build system series improving Meson's TAP output parsing for Git's test suite. It fixes several test scripts that were producing output outside of TAP-formatted test cases, which could break strict TAP parsers. The changes are straightforward - mostly redirecting test setup output to /dev/null or restructuring prereq checks to avoid printing directly to stdout. The affected tests span various areas including hash-object, submodule diffs, and gitweb functionality.

The patch appears well-scoped and mechanical, addressing a clear technical requirement for proper TAP parsing. While the changes don't affect test behavior, they're important for the broader goal of making Git's test suite work correctly with Meson's test runner. This is part of a coordinated effort where the author has already contributed the necessary fixes upstream to Meson itself.
