This is a patch in Patrick Steinhardt's ongoing series to clean up Git's `contrib/` directory by removing obsolete or unmaintained components. This specific patch (6/10 in the series) removes the "mw-to-git" MediaWiki integration tools.

The "mw-to-git" directory contained Perl scripts for accessing MediaWiki via Git, but the code has been unmaintained in Git's tree for years. The last changes were security fixes in 2020, and the tests haven't been run regularly, likely causing bitrot. The functionality has been spun out to a separate project at GitHub.com/Git-Mediawiki/Git-Mediawiki.

The removal follows the same pattern as previous patches in the series - targeting clearly abandoned functionality that has better-maintained alternatives elsewhere. The patch deletes 22 files totaling nearly 4,000 lines of code, including:
- Core Perl modules and scripts for MediaWiki integration
- Test files and infrastructure
- Documentation
- Build files

This continues the systematic rationalization of the `contrib/` directory that has already seen removal of obsolete remote helpers, Thunderbird scripts, and example hooks. The change is straightforward with no impact on core Git functionality.
