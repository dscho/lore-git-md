This is part 2/17 of Patrick Steinhardt's series to refactor the object database (ODB) subsystem as part of the ongoing `the_repository` removal effort. The patch renames `struct object_directory` to `struct odb_backend` to better reflect its role as a storage backend interface rather than just a filesystem directory.

The change anticipates future work to support pluggable ODB backends where objects may be stored in non-filesystem locations like databases. The current name `object_directory` would become misleading in that context. The new name `odb_backend` is storage-agnostic and allows for future implementations like `files_odb_backend`.

The patch updates 28 files with mechanical renames of the struct and related functions. Key changes include:
- Renaming the core structure and all its references
- Updating function signatures in commit-graph, packfile and repository code
- Modifying callers across the codebase to use the new name

This is a preparatory step before making the ODB backend more self-contained and passing it directly rather than through `the_repository`. The change is wide-ranging but straightforward, touching 139 files with over 1000 lines changed in the full series. The patch appears well-scoped and maintains consistency with the broader refactoring direction.
