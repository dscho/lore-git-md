This is part of Patrick Steinhardt's ongoing series to clean up Git's `contrib/` directory by removing broken/unmaintained/obsolete components (patch 6/10). The focus here is removing the "mw-to-git" MediaWiki integration tools.

The patch removes the entire `contrib/mw-to-git/` directory, which contained Perl scripts for bidirectional synchronization between Git and MediaWiki wikis. The justification is that this code has been effectively unmaintained in Git's tree - the last significant changes were security fixes in 2020, tests haven't been run, and the functionality has been spun out to a separate Git-Mediawiki project on GitHub.

The removal follows the same pattern as previous patches in the series, targeting clearly abandoned functionality. The directory being removed includes:
- Core Perl modules and scripts for MediaWiki interaction
- Test infrastructure and test cases
- Documentation
- Build/Makefile infrastructure

Key technical details:
- The code provided Git commands like `git-remote-mediawiki` for wiki interaction
- Handled MediaWiki page content, revisions, and file uploads
- Included extensive test suites (9360-9365) for clone/push/pull operations
- Had special handling for Unicode filenames and MediaWiki's namespace conventions
- The external project lives at https://github.com/Git-Mediawiki/Git-Mediawiki
- No behavior changes in core Git result from this deletion

This continues the systematic cleanup of `contrib/` by removing technical debt, following the same criteria as previous removals (obsolete/unmaintained functionality with active external alternatives). The change is straightforward with no expected controversy, as the code clearly meets the removal criteria established earlier in the series.
