This thread began as a systematic cleanup of Git's `contrib/` directory, focusing initially on removing obsolete scripts like `git-new-workdir` (replaced by `git worktree`) and `git-resurrect.sh`. The discussion evolved into broader questions about `contrib/` maintenance policies, with Patrick Steinhardt leading the effort and Junio Hamano providing guidance on balancing technical debt removal with stability considerations.

The latest addition to this cleanup series targets the `mw-to-git` MediaWiki integration tools. Matthieu Moy, the original author, confirms the tool has been effectively abandoned - with no activity in either the Git tree or its GitHub fork since 2022. While the external GitHub repository is also inactive, both Matthieu and Junio agree it's still a more appropriate home for this unmaintained code than Git's main tree. The removal follows the established pattern for `contrib/` components that have both bitrotted internally and found external homes, though in this case the external project is equally dormant.

Key decisions have already been made to remove several scripts, with Patrick considering deeper architectural changes (like reftable improvements for branch resurrection) that would make some scripts obsolete. The `git-contacts` script remains under discussion due to its niche utility for Git development. This latest patch continues the pattern of removing clearly unmaintained components while the broader policy questions about `contrib/` expectations remain open for future discussion.
