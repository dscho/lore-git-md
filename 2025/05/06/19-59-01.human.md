This is a cleanup patch removing the `emacs/` directory from Git's `contrib/` area, part of Patrick Steinhardt's ongoing series to remove obsolete or unmaintained components. The directory has contained only stub files since 2018, when its actual functionality was removed in favor of using Emacs' built-in `vc-annotate` mode. 

Junio Hamano approves the removal, noting any dependencies or concerns, and specifically states this change doesn't need to wait for the Git 3.0 transition like some other removals in the series. The patch appears straightforward with no test dependencies or compatibility issues to address.

This completes one of the nine planned removals in the `contrib/` cleanup effort, following the established pattern for components that have been functionally replaced by other tools. The change is uncontroversial and ready to proceed independently of the broader Git 3.0 transition timeline affecting other parts of the series.
