Part of the ongoing `the_repository` removal effort, specifically focusing on the object database (ODB) subsystem. This first patch in a 17-part series renames `struct raw_object_store` to `struct object_database` as a foundational step toward making the object storage subsystem more self-contained.

The change addresses several naming issues: the "raw_" prefix was misleading (no non-raw variant exists), the new name better reflects the structure's purpose as a database for objects, and it enables cleaner function naming (future patches will use `odb_` prefix). The patch updates all related type declarations and function signatures across 8 files, including core components like `object-store.h` (which becomes `object-database.h` in later patches) and repository handling code.

Key technical changes:
- Renames the central object storage structure and updates all references
- Introduces new `odb_new()` and `odb_clear()` functions to replace `raw_object_store_new()` and `raw_object_store_clear()`
- Updates function signatures in commit-graph, packfile, and repository subsystems to use the new type
- Adds clarifying documentation about the ODB's role in managing object backends

This is a mechanical rename with no behavior changes, establishing the naming convention that subsequent patches will build upon when removing `the_repository` dependencies from the ODB layer. The change affects a wide surface area (139 files ultimately modified in the series) but this initial patch focuses solely on the type rename to keep the diff manageable.
