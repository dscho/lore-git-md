CI/build system patch completing a series to improve Meson integration with Git's test suite. This final patch enables TAP protocol parsing in Meson 1.8+ for better test reporting, building on previous infrastructure changes that cleaned up test output formatting. The change allows Meson to properly count subtests and detect skipped test suites, as demonstrated in the sample output showing detailed pass/skip statistics for crlf-related tests. The author notes this was blocked until Meson 1.8 due to an upstream bug they fixed (mesonbuild/meson#13980) that caused hangs with interactive test runs. The implementation adds a protocol parameter to the consolidated test_kwargs dictionary introduced in patch 3/4, conditional on the Meson version. This appears to be a straightforward mechanical improvement to test infrastructure with no expected controversy, completing the series' goal of better Meson test integration. The change affects only meson.build configuration without modifying test behavior.
