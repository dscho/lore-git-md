This is a bugfix for gitk's external diff functionality, specifically addressing file rename detection. The patch is now at v4 and under final review by gitk maintainer Johannes Sixt.

The patch introduces a new `check_for_renames_in_diff` procedure that parses "rename from"/"rename to" markers from diff output to correctly identify renamed files for external diff viewing. The implementation handles both renamed and moved files (which Git treats identically) by searching the diff text widget in both forward and backward directions.

Johannes Sixt's review points focus on code quality and style rather than the core approach. Key feedback includes: questioning whether diff text parsing is necessary given gitk's existing rename handling, noting unescaped regex special characters in filename matching, requesting Tcl variable naming conventions (using 'ne' instead of '!=', removing unnecessary parentheses), and suggesting shorter variable names for readability. He also raises an open question about supporting copied files.

The technical implementation involves 43 lines added to gitk's Tcl script, modifying 2 existing lines. The changes are contained to gitk's UI layer with no architectural impact.
