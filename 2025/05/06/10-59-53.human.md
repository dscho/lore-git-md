This is the final patch in a CI/build system series improving Meson integration with Git's test suite. It enables proper TAP output parsing in Meson 1.8+, which provides more detailed test reporting than just exit codes. The patch builds on the author's earlier upstream contribution that fixed a Meson bug causing hangs with interactive test runs.

With this change, `meson test` now shows detailed subtest counts and proper SKIP status reporting, as demonstrated in the example output where individual test files show their subtest counts (like t0027-auto-crlf showing 2600 subtests). The implementation is straightforward - it adds the 'tap' protocol parameter when Meson 1.8+ is detected.

This completes the series' goal of improving test output handling under Meson. The changes are well-justified and appear technically sound, with the author having already addressed the key compatibility issue upstream. The patch maintains the series' focus on test infrastructure without modifying core Git functionality.
