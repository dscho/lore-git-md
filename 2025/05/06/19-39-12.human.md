Gitk maintainer review of rename detection patch (bugfix)

Johannes Sixt, the gitk maintainer, provides detailed feedback on v4 of Tobias Boesch's patch to fix external diff handling for renamed files. While approving the general goal, he raises several technical and style concerns that need addressing before final acceptance.

Key points from the review:
1. Questions whether parsing diff text is necessary, suggesting the rename information might already be available when clicking files in gitk's UI
2. Asks about extending the fix to handle copied files as well as renames
3. Identifies regex safety issues with unescaped special characters in filenames
4. Requests Tcl style fixes: using 'ne' instead of '!=', removing unnecessary parentheses, and shortening overly verbose variable names
5. Notes the patch follows gitk's imperative mood/present tense style requirements from earlier rounds

The review maintains a constructive tone while being thorough - typical of Johannes Sixt's maintainer style. Tobias will need to address these points in a v5, particularly the regex safety and style issues, but there are no fundamental objections to the approach. The thread appears headed toward eventual acceptance after these polish items are resolved.
