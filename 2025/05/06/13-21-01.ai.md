Performance optimization patch for xdiff's `--minimal` mode, now in its review cycle. Phillip Wood provides final approval for Niels Glodny's v3 patch that modifies the `cleanup_records` heuristic to skip marking lines as changed when surrounded by many changes, but only when `--minimal` is explicitly requested via `XDF_NEED_MINIMAL` flag. The change affects about 1.3% of diffs where this heuristic previously produced longer-than-necessary output.

Key technical elements remain unchanged from previous versions: deriving `need_min` from `cf->flags`, modified marking logic when `need_min` is true (forcing `dis1[i]` to 1), and the new `t4071-diff-minimal.sh` test script. The test verifies unchanged lines surrounded by changes don't appear in minimal diffs using `test_write_lines` and `test_grep` helpers. Benchmark results still show no statistically significant runtime impact (`2.363s ± 0.023s` vs `2.362s ± 0.035s` for `git log -p -3000 --minimal`).
