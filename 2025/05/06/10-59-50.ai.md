This is the first patch in a CI/build system series improving Meson's TAP output parsing for Git's test suite. The patch fixes several test scripts that were producing output outside of `test_expect_*` blocks without proper TAP formatting (which requires diagnostic output to be prefixed with "#"). The changes are mechanical - redirecting test repository creation output to `/dev/null` and converting a highlight prerequisite check to use `test_lazy_prereq`. The affected tests span various areas including hash-object, submodule handling, and gitweb functionality, but the changes are straightforward output suppression rather than test logic modifications. This is a foundational change enabling the subsequent Meson TAP parsing improvements in the series. The patch appears well-scoped and correctly implements the TAP compliance fixes needed for the broader Meson integration goal.
