This is part 11/17 of Patrick Steinhardt's series to remove `the_repository` global from the object database (ODB) subsystem, specifically focusing on submodule backend handling.

The patch moves submodule ODB tracking from a global string list to being stored directly in the object database structure. Previously, `git grep --recursive` and similar operations relied on a global list of submodule paths to access submodule objects. The new approach attaches this list to each repository's ODB instance instead of using `the_repository` as a special case.

Key changes include:
- Adding a `submodule_backend_paths` string list to `struct object_database`
- Renaming functions from `add_submodule_odb_by_path()` to `odb_add_submodule_backend_by_path()`
- Moving the implementation from submodule.c to odb.c
- Removing the special case for `r == the_repository` since submodule backends are now tracked per-ODB

The patch maintains the same behavior while making the code more suitable for libification by eliminating global state. It follows the series' pattern of methodically removing `the_repository` dependencies while preserving functionality. The changes appear straightforward and well-contained, with thorough updates to callers and clear documentation of the new API.
