This is part of Patrick Steinhardt's ongoing series to clean up Git's `contrib/` directory, specifically targeting the removal of the obsolete `emacs/` directory. The patch removes three files that have been effectively non-functional since 2018 when their implementations were replaced with stubs (6d5ed4836db). The README explains these Emacs integrations were superseded by built-in Emacs functionality (vc-annotate mode) and third-party packages like Magit. The actual code was already replaced with error messages pointing users to alternatives, making this a straightforward removal of dead weight.

The deletion follows the same pattern as previous patches in the series - removing clearly obsolete components that have better-maintained alternatives elsewhere. Unlike some other removals in the series, this one has particularly strong justification since the code has been non-functional for 7 years and the README explicitly documents the recommended replacements. The patch touches only the `contrib/emacs/` directory, removing its README and two `.el` files that contained nothing but error messages redirecting users to modern alternatives.

This removal is unlikely to be controversial given how long the code has been effectively disabled and the clear migration path to standard Emacs functionality. It continues the series' theme of removing technical debt from `contrib/` where components are either broken, unmaintained, or have superior alternatives. The patch is clean and straightforward, with no behavior changes since the actual functionality was removed years ago.
