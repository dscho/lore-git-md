Thread identity: Patrick Steinhardt's series to clean up Git's `contrib/` directory by removing broken/unmaintained/obsolete components, now covering eight removals: the obsolete `remotes2config.sh` script, Mercurial/Bazaar remote helper stubs, Thunderbird patch integration scripts, example hooks from `contrib/hooks/`, the MediaWiki integration tools (`mw-to-git/`), the persistent-https remote helper, the `git-resurrect.sh` script, and the non-functional `emacs/` directory.

Core problem/goal: Systematic rationalization of `contrib/` directory by removing technical debt. Components removed so far include: 1) 17-year-old migration script (`remotes2config.sh`) for transitioning from `.git/remotes/` to config-based remotes; 2) stub scripts (`git-remote-bzr` and `git-remote-hg`) that redirected to external implementations; 3) Thunderbird integration scripts (`appp.sh` and documentation that depended on an unmaintained ExternalEditor extension; 4) four example hooks from `contrib/hooks/` that are either obsolete, unmaintained (last updates 2008-2020), or have better alternatives; 5) the MediaWiki integration tools (`mw-to-git/`) which have been spun out to a separate actively maintained GitHub project; 6) the persistent-https remote helper (875 lines of Go code) which is unmaintained since 2016 and no longer compiles with modern Go toolchains; 7) the `git-resurrect.sh` script (181 lines) for recovering lost branch tips via reflog inspection, unmaintained since its 2009 introduction; 8) the `emacs/` directory whose functionality was replaced with stubs in 2018 (6d5ed4836db) pointing to built-in Emacs functionality (vc-annotate mode) and third-party packages like Magit.

Current status: Eight components removed - all meet series' criteria (broken/unmaintained/obsolete). The `emacs/` removal is particularly straightforward as the code has been non-functional for 7 years with clear documented alternatives. Three more components remain for removal as outlined in cover letter.

Key technical details: `remotes2config.sh` was superseded by built-in `git remote rename`. The remote helper stubs (b2c851a8e67) pointed to external projects. The Thunderbird scripts (55-line `appp.sh` and 20-line README) depended on unmaintained ExternalEditor extension. The hooks removed include email notification (`post-receive-email`), battery check (`pre-auto-gc-battery`), permissions tracking (`setgitperms.perl`), and access control (`update-paranoid`). The MediaWiki tools provided `git-remote-mediawiki` for wiki interaction with special Unicode/namespace handling, now maintained externally at Git-Mediawiki/Git-Mediawiki. The persistent-https helper removal includes its proxy daemon architecture (git-remote-persistent-https--proxy), Unix socket authentication, HTTP/HTTPS reverse proxy implementations, and build infrastructure. The `git-resurrect.sh` script implemented reflog scanning for branch checkouts/merges with various search strategies (`-a` for all, `-r` for reflog merges, `-m` for merge commits) and branch recreation capability. The `emacs/` directory contained only stubs (since 2018) that printed error messages directing users to modern alternatives (vc-annotate mode, Magit). No behavior changes in core Git from these deletions. Series may lead to broader `contrib/` reorganization inspired by Linux's staging drivers model.

Open questions: None yet raised about specific removals. Broader policy questions about `contrib/` maintenance standards remain open. The `git-resurrect.sh` removal differs from some others in not having a clear replacement, though its functionality appears unused. Future patches may prompt discussion about other components' status, particularly those with more active users.
