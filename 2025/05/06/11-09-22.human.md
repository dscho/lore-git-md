This is part 9/17 of Patrick Steinhardt's series to remove `the_repository` dependencies from the object database (ODB) subsystem. The patch refactors iterator-style functions that operate on alternate object databases to take an explicit `object_database` parameter instead of implicitly using the global `the_repository`.

The key changes are:
- Renames `foreach_alt_odb()` to `odb_for_each_backend()` and makes it take an explicit ODB parameter
- Renames `for_each_alternate_ref()` to `odb_for_each_alternate_ref()` with the same parameter change
- Updates all callers (count-objects, receive-pack, submodule--helper, diagnose, fetch-pack, revision) to pass `the_repository->objects` explicitly
- Maintains the same behavior while removing global dependencies

The changes are mechanical but thorough, touching several key areas that deal with alternate object storage. This continues the series' pattern of methodically eliminating `the_repository` usage while preserving functionality. The patch appears well-contained and follows the established approach of the series.
