This is the first patch in a series that combines string-list test modernization with implementation improvements, specifically addressing sign comparison warnings in string-list.c.

The patch systematically changes loop iterator variables from `int` to `size_t` across multiple functions in string-list.c to eliminate five of the six sign comparison warnings that occur with `-Wsign-compare`. The changes affect core string-list operations including duplicate removal, iteration, filtering, and clearing. The modifications are straightforward type changes that maintain identical behavior while resolving compiler warnings.

Key technical details:
- Changes loop iterators in `string_list_remove_duplicates()`, `for_each_string_list()`, `filter_string_list()`, and both variants of `string_list_clear()`
- Maintains all existing functionality while fixing type mismatches
- Part of broader effort to modernize string-list implementation
- Follows previous discussion about sign comparison warnings in the codebase
