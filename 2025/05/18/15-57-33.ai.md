This is part 5 of an 8-patch series modernizing string-list tests while improving the implementation. The series combines test conversions from shell to C with core code cleanups.

The patch moves the "test_split" functionality from shell script tests into the new C unit test framework (u-string-list.c). It introduces helper functions to create and verify string lists during testing, then ports all the split test cases to use these helpers. The original shell test file (t0063-string-list.sh) is updated to remove the now-redundant test_split function while keeping split_in_place tests (which will presumably be converted in a later patch).

Key technical details:
- Adds new u-string-list.c with test framework helpers:
  * t_vcreate_string_list_dup() - creates string lists from varargs
  * t_string_list_clear() - verifies list clearing
  * t_string_list_equal() - compares lists
  * t_string_list_split() - tests string splitting
- Ports all split test cases to C:
  * Basic splitting with various delimiters
  * Edge cases (empty strings, maxsplit limits)
  * Maintains same test coverage as shell version
- Updates build systems (Makefile, meson.build)
- Removes test-tool string-list split command
- Keeps split_in_place tests in shell for now
