This is a documentation patch removing outdated information from Git's new contributor tutorial. It's the first in a 3-part series modernizing the MyFirstContribution.adoc guide.

The patch removes references to the now-defunct git-mentoring@googlegroups.com mailing list, which was originally created as a separate space for new contributors to ask questions. The commit message explains that in practice, most questions were already being addressed on the main git@vger.kernel.org list, making the separate mentoring list unnecessary.

The change is straightforward - it deletes 8 lines documenting the mentoring list while keeping the information about the main mailing list and IRC channel. This aligns with the series' goal of keeping the tutorial current with actual Git community practices. The patch appears well-formed with a clear commit message explaining the rationale.
