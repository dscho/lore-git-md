This is an implementation improvement patch in the string-list modernization series. It simplifies the string-list insertion logic by directly returning the index of existing elements rather than using a negative encoding scheme.

The patch changes `add_entry()` to return the positive index when an element already exists, rather than the current `-1 - index` encoding. This makes the code more straightforward since `string_list_insert()` was immediately converting the negative value back to a positive index anyway. The change maintains the same behavior while removing unnecessary transformations.

The author notes this is a stepping stone - if callers ever need to distinguish new vs existing elements, a cleaner approach would be to add an `exact_match` output parameter rather than using index encoding. The change is small (5 lines removed) but makes the code more direct and easier to follow.

This continues the series' theme of cleaning up the string-list implementation while maintaining functionality. It follows logically from the previous patches that removed unused parameters and fixed sign comparison warnings.
