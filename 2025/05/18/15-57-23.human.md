This is a refactoring patch in shejialuo's ongoing string-list modernization series, specifically addressing sign comparison warnings. The patch changes the return type of `get_entry_index()` from `int` to `size_t` to match the unsigned `list->nr` it's compared against, eliminating the need for a special warning suppression macro.

The key changes are:
1. Removing the `DISABLE_SIGN_COMPARE_WARNINGS` macro that was suppressing compiler warnings
2. Modifying the binary search algorithm in `get_entry_index()` to work with `size_t` instead of `int`, including changing the initial `left` value from -1 to 0
3. Updating the return types and callers (`add_entry()` and `string_list_insert()`) to handle the new `size_t` return type

This is a straightforward cleanup that follows naturally from the previous patches in the series. The changes are well-contained and maintain the same functionality while making the code more type-safe.
