This is a documentation patch series completing the reorganization of email provider credential helper documentation in Git. The v3 series builds on previous iterations that moved email-specific credential helpers from gitcredentials.adoc to git-send-email.adoc, now adding formatting improvements to finalize the changes.

The series consists of three patches: First adds references to both the git-credential-yahoo helper and Google's sendgmail tool in git-send-email.adoc. Second improves the git-send-email documentation formatting for better readability. Third removes the now-redundant email helper references from gitcredentials.adoc, completing the separation of email-specific documentation from general credential management.

Key technical details include updates to git-send-email.adoc (adding helper references and reformatting) and gitcredentials.adoc (removing email helper section). The changes reference git-scm.com PR #2005 for website documentation updates. The author notes Yahoo's declining popularity as rationale for simplifying the documentation structure.
