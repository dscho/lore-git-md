Documentation patch consolidating email provider credential helpers. This is the first of three patches in a series that reorganizes Git's email configuration documentation, moving all credential helper references from gitcredentials.adoc to git-send-email.adoc.

The patch adds two items to git-send-email.adoc: a reference to Google's sendgmail tool for Gmail users, and the git-credential-yahoo helper for Yahoo accounts. The changes maintain the existing format used for Gmail and Outlook helpers, creating a consistent presentation of all three email provider options in one place. The patch also removes outdated wording about "Gmail and Outlook" being the only available helpers.

This continues the thread's goal of simplifying email configuration documentation by centralizing provider-specific information. The changes are purely organizational - no functional changes to Git itself. The patch follows Junio Hamano's earlier approval of moving credential helper documentation to git-send-email.adoc, and appears ready for merging as part of the complete series.
