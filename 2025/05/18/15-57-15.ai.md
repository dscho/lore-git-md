Implementation improvement in the string-list series, focusing on simplifying the insertion logic for existing elements.

This patch modifies the string-list implementation to directly return the positive index when an element already exists in the list, rather than using the previous convention of returning -1-index. The change affects two key functions:

1. `add_entry()` now returns the positive index directly when an exact match is found, rather than converting it to a negative value. This makes the behavior more straightforward since the negative value conversion was only used by `string_list_insert()`.

2. `string_list_insert()` is simplified to no longer need the negative-to-positive index conversion, as it receives the direct index from `add_entry()`.

The commit message notes this is a cleanup that could be further extended in the future with an `exact_match` parameter if needed, but the current change stands on its own as a simplification. This continues the series' pattern of making focused, well-explained improvements to the string-list implementation while maintaining all existing functionality.
