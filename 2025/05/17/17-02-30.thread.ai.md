**Thread summary: Feature patch adding MPTCP support for Git on Linux**

Initial patch introduces Multi-Path TCP (MPTCP) support for Linux systems, allowing bandwidth aggregation across multiple network paths (e.g. WiFi + 5G). Implementation requires both kernel (IPPROTO_MPTCP) and glibc support, with fallback to regular TCP if either is missing. Client-side enabled via GIT_ENABLE_MPTCP environment variable, server-side via git-daemon --mptcp flag. Patch carefully handles compatibility: checks socket creation and getaddrinfo() support, includes __linux__ guards to avoid non-Linux systems. Author motivation cites large-repo transfers (50GB+) benefiting from aggregation/failover, with Apple's cloud usage as precedent. Technical implementation modifies socket initialization in network code. Open: whether Makefile configuration would be better than env vars, lacks performance measurements for multi-path scenarios. Patch appears well-structured with robust fallback paths but real-world impact unquantified.
