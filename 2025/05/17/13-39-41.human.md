This is a documentation patch in the final polishing stage of a series modernizing the MyFirstContribution tutorial. Junio Hamano provides feedback on commit message wording for the patch that updates the tutorial to use `repo_config` instead of the older `git_config` pattern.

Junio suggests improving the commit message to better explain why this change matters - specifically noting that the tutorial was outdated and needed alignment with current best practices around repository-specific configuration access.

This is part of a broader effort to update the contributor tutorial to reflect contemporary Git practices, including proper use of repository parameters and configuration APIs. The series has gone through multiple iterations with active review from Junio and others, and is now in its final stages addressing documentation presentation details.
