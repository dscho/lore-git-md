This is a documentation patch removing an obsolete reference to the git-mentoring mailing list from the MyFirstContribution tutorial. It's part of a v3 series (1/3) modernizing the contributor guide.

The patch removes an 8-line section describing the now-unused git-mentoring@googlegroups.com list, which was originally created as a private space for new contributors to ask questions. The rationale is straightforward: new contributors now successfully use the main git@vger.kernel.org list directly, making the separate mentoring list redundant and potentially confusing.

This change follows through on a cleanup that was already approved and merged in the v2 series (3/3), with Junio Hamano providing wording polish. The removal is uncontroversial and aligns with current community practices where all discussion happens on the main list.

The patch is cleanly focused - it only touches the documentation file and makes a single logical change. As part of the larger modernization effort, this represents the documentation hygiene aspect rather than the technical updates that follow in later patches of the series.
