The changes show how to properly use the repository parameter passed to built-in commands rather than relying on the global `the_repository` state. The accompanying documentation text is updated to match, explaining the new API calls with the same pedagogical clarity as the original version.

Key technical changes include adding `#include "repository.h"` where needed and modifying the `wt_status_prepare()` call to use the passed `repo` parameter. The patch maintains the tutorial's educational flow while demonstrating the project's current best practices for configuration access.
