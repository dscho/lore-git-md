This is a documentation patch in a series modernizing the MyFirstContribution tutorial, specifically focusing on teaching modern Git command implementation patterns. It's the second of three patches in v3 of the series.

The patch updates the tutorial to demonstrate two key practices: proper use of the `UNUSED` macro for unused function parameters, and including the `struct repository *repo` parameter in command function signatures. The changes show both the declaration in builtin.h and the implementation in cmd_psuh(), with careful attention to when parameters should be marked UNUSED versus when they're actually used.

The tutorial now explicitly explains the purpose of UNUSED macros to help new contributors understand how to handle compiler warnings about unused parameters. It also shows the transition from marking parameters as UNUSED to actually using them, with the args dumping example removing the UNUSED markers since those parameters are now referenced.

This continues the series' theme of teaching modern Git practices, specifically around repository-aware patterns and proper API usage. The changes are purely pedagogical - they affect only the tutorial documentation, not the actual Git codebase. The patch maintains the tutorial's flow while inserting these technical explanations naturally at the points where they would be relevant to a contributor implementing their first command.
