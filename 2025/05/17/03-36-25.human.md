This is a documentation patch in a series modernizing the MyFirstContribution tutorial, specifically focusing on teaching modern Git coding practices. 

The patch makes two key changes to the tutorial's example code. First, it updates the `cmd_psuh` function signature to include a `struct repository *repo` parameter, demonstrating the project's current preference for repository-aware patterns over global state. Second, it introduces and explains the `UNUSED` macro, which suppresses compiler warnings for unused parameters - a common point of confusion for new contributors.

The changes are well-motivated as part of the broader effort to modernize contributor documentation. The patch maintains the tutorial's pedagogical flow while bringing it in line with current Git development practices. It's the second of three patches in this version of the series, following prior review and iteration. The changes are cleanly implemented and focused solely on the documentation file, with no runtime impact.

This continues the series' goal of providing accurate onboarding materials that teach modern Git development patterns, in this case covering both API usage (repository parameters) and common coding conventions (UNUSED macros).
