Test patch adding corrupt bitmap loading verification.

This is a test infrastructure patch that adds new functionality to verify Git's handling of corrupt bitmap files. The patch introduces:

1. A new test function `test_bitmap_load_corrupt()` in pack-bitmap.c that deliberately corrupts bitmap data structures and verifies they are properly rejected
2. A new `load-corrupt` command for the test-tool bitmap utility
3. A test case in t5310-pack-bitmaps.sh that exercises this functionality

The test works by first setting up a valid bitmap, then deliberately corrupting either the commit position or XOR offset fields before attempting to load them. The test expects these corruptions to be detected and rejected.

This appears to be a well-constructed test that exercises error paths in the bitmap loading code. The commit message clearly explains the approach and the patch includes both the test infrastructure and an actual test case. This should help catch bitmap corruption handling bugs that might otherwise go undetected.
