Bugfix for MPTCP support patch series. This is a follow-up to the feature patch adding Multi-Path TCP support for Git on Linux systems.

Muhammad Nuzaihan fixes a small but important bug in the v2 implementation where the fallback to regular TCP wasn't properly handled when the MPTCP flag was disabled. The correction ensures the code properly reverts to IPPROTO_TCP when MPTCP is either unsupported or explicitly disabled via the environment variable (client) or --mptcp flag (server).

The patch maintains all the careful compatibility checks from v2: Linux-specific guards, glibc version detection, and fallback paths when MPTCP support is missing. The author discovered the issue while debugging with Wireshark, suggesting practical testing of the implementation.

This appears to be a straightforward correction to an otherwise well-considered feature patch. The change is minimal and focused, addressing only the fallback logic while leaving the broader MPTCP implementation intact. Readers interested in the original feature can refer to the v2 links provided in the full context.
