This is a follow-up in the ongoing MPTCP support thread, where Muhammad Nuzaihan responds to concerns about implementing Multipath TCP for Git's legacy protocol. The email includes a Wireshark screenshot demonstrating successful MPTCP operation with the git protocol (port 9418).

Nuzaihan reiterates his position that testing MPTCP with the basic git protocol makes sense as a first step, pushing back against suggestions to focus on SSH/HTTP implementations first. He questions whether deprecating the git protocol entirely would be preferable if MPTCP support isn't added. The response maintains that MPTCP v1 (unlike the problematic v0) properly handles fallback to regular TCP when needed.

While defending the technical approach, Nuzaihan appears open to making MPTCP configurable via `.gitconfig` with a default-off setting, though he continues to challenge the cited compatibility concerns by requesting specific evidence about issues with MPTCP v1. The discussion remains unresolved, with the core tension being between automatic protocol modernization and conservative compatibility considerations.
