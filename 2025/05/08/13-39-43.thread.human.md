This thread documents a clean and efficient code cleanup in Git's reftable subsystem. It began when Lidong Yan identified a theoretical memory leak in the REFTABLE_REALLOC_ARRAY macro, but reviewers René Scharfe and Patrick Steinhardt recognized the macro wasn't actually used anywhere in the codebase. After three iterations refining the patch's formatting and commit message, the final version simply removes the dead code rather than fixing it.

Patrick Steinhardt, as the reftable maintainer, has now given his approval to the v3 patch, confirming all feedback has been addressed. The change deletes the unused macro while preserving the formatting of a related macro (REFTABLE_CALLOC_ARRAY) as requested. Junio C Hamano merged the patch with a characteristically humorous note, bringing this straightforward cleanup to a successful conclusion. The thread demonstrates how reviewer insight can sometimes reveal simpler solutions than initially proposed, in this case removing unused code rather than maintaining it.
