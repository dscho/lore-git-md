This is a documentation patch in the final version (v6) of a series improving `git send-email`'s authentication documentation. It focuses on OAuth2.0 support, which has been enabled by recent updates to the Authen::SASL Perl module.

The patch significantly expands the documentation with clear examples for both Gmail and Outlook configurations, detailing the different OAuth2.0 authentication methods each provider requires (OAUTHBEARER for Gmail, XOAUTH2 for Outlook). It also addresses the practical challenge of obtaining OAuth2.0 tokens by linking to community-maintained credential helpers the author developed, which should help users avoid the painstaking research the author went through.

The changes follow the project's documentation standards, consistently using backticks for commands and config options as requested in earlier feedback. The patch maintains a practical focus, showing both the configuration needed and the actual commands to send patches, while clearly explaining authentication requirements (noting Outlook's lack of app-specific password support).

This appears ready for merging, completing the documentation portion of a series that has already had its technical aspects approved. The author demonstrates the documented workflow by using their own `git-credential-outlook` helper to send this very patch.
