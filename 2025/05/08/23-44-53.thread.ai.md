**Stash import/export as refs - Merged implementation**  
The v8 patch series implementing bidirectional `git stash export` and `import` has been merged into 'next' by Junio Hamano following final approval from Phillip Wood. The feature enables stash state transfer between repositories via `refs/stash-export/` with complete validation and 369 lines of test coverage (`t/t3903.sh`).

**Technical implementation**:  
Core components in `builtin/stash.c` share validation infrastructure between import/export operations:  
- `check_stash_topology()` verifies commit chains via `commit_list`  
- `parse_stash_revision()` helper with quiet mode  
- `write_commit_with_parents()` with corrected memory ownership (v8 fix: no longer freed)  
- `GET_OID_GENTLY` flag (0100000) in `hash.h` for reflog error handling  

Export functionality includes:  
- Standardized `refs_for_each_reflog_entry*` traversal  
- `--print`/`--to-ref` mutual exclusion enforcement  
- Header hygiene and platform-specific handling  

Import functionality provides:  
- `do_import_stash()` with commit chain validation  
- Preservation of original message prefixes (`WIP on`, `On <branch>:`)  
- Append-only behavior to existing stash stack  
- Empty-tree root validation
