**Stash import/export as refs (v7) - Final implementation ready for merge**  
Implementation of bidirectional stash transfer via `git stash export`/`import` subcommands, storing commit chains under `refs/stash-export/`. Core components in `builtin/stash.c`, `object-name.c`, and `reflog-walk` with 268 lines of test coverage in `t/t3903.sh` and documentation in `git-stash.adoc`.

**Technical implementation**:  
1. Export functionality (v1-v6):  
   - Phillip Wood's topology validation (`check_stash_topology()`) via `commit_list`  
   - Standardized `refs_for_each_reflog_entry*` traversal per Junio Hamano  
   - Header hygiene confirmed by Ramsay Jones  
   - Platform-specific handling for Windows/NonStop  
   - New `GET_OID_GENTLY` flag (0100000) in `hash.h` for reflog error handling  
   - Extracted `parse_stash_revision()` and `write_commit_with_parents()` helpers  

2. New import functionality (v7):  
   - `do_import_stash()` validates commit chains and preserves original messages  
   - Appends to existing stash stack (requires explicit `clear` for replacement)  
   - Reuses topology validation and commit walking from export  
   - New `c_commit` field in `struct stash_info` for chain tracking  

**Core capabilities**:  
- Export: Creates commit chains under `refs/stash-export/` with empty base commit  
  - Two output modes: `--print` (stdout hash) and `--to-ref` (ref storage)  
- Import: Reads exported chains with full validation  
  - Preserves message fidelity while stripping export metadata  
  - Append-only behavior maintains existing stash stack
