Stash import/export as refs (v5) - a feature series introducing new `git stash export` and `git stash import` subcommands for bidirectional stash transfer between repositories via commit chains under `refs/stash-export/`. Maintainer Junio Hamano has approved the v5 iteration's core design while providing detailed implementation feedback.

Core implementation spans `builtin/stash.c`, `object-name.c` (with new `GET_OID_GENTLY` flag for reflog handling), and documentation. The v5 series resolves prior issues and includes:
1. Final `import` via `do_import_stash()` with strengthened validation:
   - Sentinel commit checking via `get_oidf()`
   - Message validation enforcing "git stash: " prefix
   - Parent count verification
   - Leveraging `assert_stash_like()` for commit structure validation
   - New topology checks from Phillip Wood's review:
     * Direct commit object validation via `repo_get_commit_tree()`
     * Strict 2-parent requirement for chain entries
     * Second parent stash commit verification
     * Eliminated OID-to-string conversions
2. Non-destructive appending through `do_store_stash()`
3. 78 new test lines covering round-trip scenarios
4. Refined error handling in `get_oid_basic()` for reflog walks

Key use cases clarified by Brian Carlson and D. Ben Knoble. Technical validation covers NULL dereference fixes, integer overflow edge cases, and Phillip Wood's comprehensive topology checks for both export and import paths. All static analysis findings addressed.
