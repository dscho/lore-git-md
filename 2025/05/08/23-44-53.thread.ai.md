**Stash import/export as refs (v7) - Final optimizations before merge**  
Implementation of `git stash export`/`import` subcommands for bidirectional stash transfer via commit chains under `refs/stash-export/`, now in final form after seven iterations. Core components in `builtin/stash.c`, `object-name.c`, and `reflog-walk` with 94 new test cases in `t/t3903.sh` and documentation in `git-stash.adoc`.

**Technical implementation**:  
1. Phillip Wood's topology validation (`check_stash_topology()`) optimized via `commit_list` instead of `oid_array`  
2. Standardized on existing `refs_for_each_reflog_entry*` traversal APIs per Junio Hamano's direction, rejecting low-level `read_complete_reflog()` exposure  
3. Header hygiene in `reflog-walk.h` confirmed by Ramsay Jones  
4. Platform-specific handling: Windows-compatible `(size_t)` casting preserved, NonStop iteration addressed  
5. Final v7 refinements: shared ident strings analyzed, error messages clarified, memory handling improved  
6. New `GET_OID_GENTLY` flag (0100000) in `hash.h` for consistent error handling in `get_oid_basic()`, allowing graceful failure for reflog history checks  
7. New `parse_stash_revision()` helper function extracted from `get_stash_info()` to handle three stash reference formats (empty/`@{0}` syntax, numeric indices, direct commits) with preserved error handling and added `quiet` parameter for message suppression
