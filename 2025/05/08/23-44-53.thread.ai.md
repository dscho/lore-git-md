**Stash import/export as refs (v7) - Final implementation ready for merge with minor fixes**  
Implementation of bidirectional stash transfer via `git stash export`/`import` subcommands, storing commit chains under `refs/stash-export/`. Core components in `builtin/stash.c`, `object-name.c`, and `reflog-walk` with 268 lines of test coverage in `t/t3903.sh` and documentation in `git-stash.adoc`.

1. Export functionality (v1-v7):

   - Standardized `refs_for_each_reflog_entry*` traversal per Junio Hamano  
   - Header hygiene and platform-specific handling confirmed by Ramsay Jones  
   - New `GET_OID_GENTLY` flag (0100000) in `hash.h` for reflog error handling  
   - Extracted `parse_stash_revision()` and `write_commit_with_parents()` helpers
