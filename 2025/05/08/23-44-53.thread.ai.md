Stash import/export as refs (v5) - a feature series introducing new `git stash export` and `git stash import` subcommands to enable transferring stashes between repositories via standard Git operations. The implementation represents stashes as commit chains with two parents per commit (sequence and data) stored under `refs/stash-export/`. Core changes span `builtin/stash.c` (command implementations), `object-name.c` (OID lookup modifications), and `git-stash.adoc` documentation. The v5 iteration includes a bugfix patch adding a `GET_OID_GENTLY` flag (0100000) to make `get_oid_basic()` return -1 for reflog history limits instead of terminating, needed for graceful error handling in stash operations. This change modifies `hash.h` (flag constant) and `object-name.c` (6 lines net). Previous versions addressed memory leaks (using `oid_array`), rebase segfaults, test robustness (78+ new lines in `t/t3903-stash.sh`), and ident validation. The series has evolved through five versions with refinements to memory management, error checking, and corner cases, reaching a mature state with no outstanding technical objections remaining unresolved.
