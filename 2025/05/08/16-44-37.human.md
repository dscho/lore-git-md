This is part 3 of a 5-part build system patch series focused on configuration path fixes. The patch corrects how system-wide gitconfig and gitattributes file paths are handled in the Meson build system.

Currently, these paths default to absolute `/etc` locations regardless of the installation prefix, which only works correctly when prefix is `/usr`. The change makes the paths respect the standard `sysconfdir` convention, where paths are relative to prefix (e.g. `/usr/local/etc` when prefix is `/usr/local`). The patch removes hardcoded defaults from meson_options.txt and implements logic to either use user-specified paths or fall back to `<sysconfdir>/gitconfig` and `<sysconfdir>/gitattributes`.

The changes are mechanical but important for correct installation behavior across different prefix configurations. The implementation cleanly separates the concerns of user overrides versus default paths while maintaining backward compatibility. This continues the series' theme of standardizing path handling across Git's build systems, with the next patches addressing GIT_EXEC_PATH and Autoconf checks.
