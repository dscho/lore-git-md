[PATCH v1] reftable: fix memory leak in REFTABLE_REALLOC_ARRAY macro

Thread identity: Bugfix for reftable memory management, patch series v1 from Lidong Yan.

Core problem: The REFTABLE_REALLOC_ARRAY macro in reftable/basics.h could leak memory when reallocation fails by not freeing the original pointer before setting it to NULL. This affects internal reftable utilities that use this macro for dynamic array management.

Current status: First version of patch submitted, no reviews or acks yet.

Key technical changes:
- Rewrote REFTABLE_REALLOC_ARRAY macro (20+8- in basics.h) to add proper cleanup
- Introduces temporary new_p variable to hold realloc result
- Adds explicit error handling path via cleanup label
- Handles two failure cases: size calculation overflow and actual realloc failure
- Maintains same successful behavior but now properly frees original pointer on failure
- Sets errno=ENOMEM and x=NULL on failure as before
