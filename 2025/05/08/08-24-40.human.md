This is a build system patch that adds Perl library path customization to Git's meson build configuration, matching existing Makefile behavior. It's a v2 revision addressing minor documentation feedback from Patrick Steinhardt.

The patch introduces a new `perllibdir` meson option that allows distributions like Fedora to specify custom Perl library installation paths (such as `/usr/share/perl5/vendor_perl`). When unspecified, it falls back to the default `<datadir>/perl5` location. The changes affect installation paths across 10 Perl-related build files, covering core Git Perl modules, CPAN-related modules, and dependencies.

The v2 revision fixes minor documentation issues in the meson_options.txt description, changing "Default to" to "Defaults to" as requested in the review. The technical implementation remains unchanged from the initial version, which had already received positive feedback for its approach. This appears to be a straightforward, well-motivated change that brings meson's Perl handling to parity with the Makefile build system.
