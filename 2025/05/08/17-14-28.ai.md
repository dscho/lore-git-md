Documentation patch finalizing the OAuth2.0 authentication section for `git send-email`. This is the second of three patches in the v7 series, focusing on restructuring and expanding the documentation around modern authentication methods.

The patch makes several key improvements to the `git-send-email.adoc` documentation:
1. Restructures the examples section into "Examples of SMTP Servers" with dedicated subsections for Gmail and Outlook
2. Documents both OAUTHBEARER and XOAUTH2 authentication methods for Gmail, while noting it only supports XOAUTH2
3. Adds configuration examples for OAuth2.0 with both providers, showing the required `smtpAuth` settings
4. Introduces links to community-maintained credential helpers (`git-credential-gmail` and `git-credential-outlook`) that handle token generation
5. Clarifies the credential storage behavior for both password and OAuth token scenarios

The changes reflect the Authen::SASL Perl module's new OAuth2.0 support while maintaining Git's documentation standards for backtick usage and command formatting. The patch builds on the technical implementation approved in earlier versions of the series, now focusing purely on the user-facing documentation aspects. It addresses the final documentation polish requested in previous reviews, particularly around making OAuth2.0 configuration discoverable and properly distinguishing between provider-specific authentication methods.
