Feature patch completing the stash import/export functionality. This is the final patch in a 4-part series introducing `git stash export` and `git stash import` subcommands for transferring stashes between repositories.

The patch implements the `git stash import` command, which reads stashes exported via `git stash export` and adds them to the current repository's stash stack. The implementation carefully preserves the imported stashes' original structure while appending them to any existing stashes (users can clear first with `git stash clear` if they want replacement behavior).

Key aspects:
- Validates imported commits match the expected stash export format
- Processes the commit chain in reverse to maintain original stash ordering
- Includes extensive test coverage of round-trip scenarios, edge cases, and error handling
- Documents the new subcommand in git-stash.adoc
