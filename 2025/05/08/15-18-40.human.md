This is a documentation and validation improvement patch series for `git send-email`, now in its sixth iteration. The series has two main components that have been refined through multiple rounds of review.

The first patch tightens the validation of fully-qualified domain names (FQDNs) in `git send-email` to strictly follow RFC1035 standards, using a more precise regex pattern while maintaining special handling for macOS `.local` domains. The implementation has been simplified in this version while still catching malformed domains that could cause SMTP issues.

The second and third patches focus on documentation, adding clear examples for OAuth2.0 authentication with Gmail and Outlook, along with references to community-maintained credential helpers. The v6 iteration specifically addresses final formatting details, consistently using backticks for config paths and options as per project standards.

The series appears well-tested and reviewed, with all technical implementation settled in previous versions. The current changes are primarily editorial, bringing the documentation into full compliance with Git's style guidelines. The author notes they're using one of the documented credential helpers (`git-credential-outlook`) to send this very patch series, demonstrating the practical application of these improvements.
