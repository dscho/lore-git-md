This is the final patch in a documentation series about OAuth2.0 authentication for `git send-email`. The patch adds references to two community-contributed credential helpers (`git-credential-gmail` and `git-credential-outlook`) to the list of OAuth helpers in `gitcredentials.adoc`. 

The additions are straightforward - each helper gets a bullet point with a GitHub link and a brief description noting they are cross-platform and specifically designed for email authentication. The Gmail helper is marked as working with `git-send-email`, while the Outlook helper gets the same treatment. Both helpers come from the same GitHub repository maintained by the patch author.

This completes the documentation updates started in earlier patches, which restructured the OAuth2.0 authentication documentation in `git-send-email.adoc`. The series has already been technically approved, with this final patch providing the last piece by documenting the community helpers that implement the OAuth flows described in the earlier documentation. 

The patch maintains consistency with the series' approach of focusing on modern OAuth methods while excluding legacy authentication details. It follows the project's documentation standards for backtick usage and linking. With this addition, users looking to set up OAuth authentication for email now have clear references to both the protocol documentation and available helper implementations.
