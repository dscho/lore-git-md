This is a review comment on patch 3/4 of the completed packed-refs memory optimization series. Jeff King (Peff) points out a subtle behavioral difference in the mmap cleanup logic between the original and refactored versions. The patch had changed the condition from checking `mmap_strategy != MMAP_OK` to specifically checking `mmap_strategy == MMAP_TEMPORARY`, which could theoretically behave differently if `MMAP_NONE` were set while `snapshot->mmapped` was true. 

Jeff suggests either documenting why this inference is safe (since `snapshot->mmapped` should never be set with `MMAP_NONE`) or keeping the original condition. He leans toward preserving the original behavior or splitting this refactoring into a separate preparatory commit.
