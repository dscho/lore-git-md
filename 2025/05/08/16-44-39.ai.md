This is the final patch in a 5-part build system improvement series, focusing on an autoconf configuration check upgrade. The patch addresses a reliability issue in detecting the `sysinfo()` function across platforms, particularly Solaris and Cygwin.

The change replaces a simple function existence check (`AC_CHECK_LIB`) with a more robust compilation test (`AC_COMPILE_IFELSE`) in `configure.ac`. This matches a similar fix already made to the Meson build system and ensures proper detection of the Linux-style `sysinfo()` function used by `git-gc` for RAM calculation. The new test verifies both the function's existence and correct struct fields (`totalram` and `mem_unit`), which are essential for accurate memory reporting.

This completes the series' goal of improving build system reliability across platforms while maintaining consistency between Autoconf and Meson builds. The change is narrowly focused on the configuration check and doesn't affect runtime behavior when the function is properly detected. The patch follows the pattern established in earlier Meson changes and addresses a known issue that could cause incorrect RAM calculations on some platforms.
