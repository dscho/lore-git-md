This is a documentation and bugfix patch series improving email-related functionality in Git. Aditya Garg's v5 series tightens up domain validation in `git send-email` and enhances the documentation around email configuration.

The first patch makes `send-email`'s FQDN validation stricter to properly follow RFC1035 standards for domain names. This fixes potential issues with invalid domain names being accepted. The patch has gone through several iterations to refine the regex pattern.

The second and third patches update documentation, adding practical examples for configuring OAuth2.0 authentication with Gmail and Outlook in `git send-email`. These include links to relevant credential helpers. The documentation changes have been carefully refined across versions, with formatting improvements and content adjustments based on feedback.

The series appears well-considered, with each version showing responsiveness to review comments. The changes are focused and the commit messages clearly explain both the technical and documentation improvements. For users who rely on `git send-email` with modern email providers, the OAuth documentation additions will be particularly valuable. The stricter FQDN validation is a sensible hardening of the email-sending code.
