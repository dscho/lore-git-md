This is a bugfix patch that's part of the "stash import/export as refs" series. It addresses an inconsistency in the `get_oid` function family where some error cases would exit or die rather than returning an error code like most other functions. The patch introduces a new `GET_OID_GENTLY` flag that makes these cases return -1 instead, which is more useful for callers that want to handle errors themselves.

The change is focused on reflog history lookup cases where going too far back would previously terminate the program. This is particularly relevant for the stash export/import feature, which needs robust error handling when processing stash references. The implementation adds the new flag to `hash.h` and modifies the error handling path in `object-name.c`.

The patch is small (6 lines changed) and well-contained, with a clear commit message explaining both the problem and why the behavior can't be changed by default (due to existing test dependencies).
