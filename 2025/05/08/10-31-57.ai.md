Documentation patch improving OAuth2.0 authentication guidance for `git send-email`. This is part 2/3 of a series that also includes FQDN validation changes (covered in the thread summary).

The patch significantly expands the `git-send-email.adoc` documentation to cover OAuth2.0 authentication, which has become necessary as major providers like Gmail and Outlook move away from basic authentication. It provides concrete configuration examples for both services, distinguishing between Gmail's continued support for app-specific passwords and Outlook's OAuth2.0-only approach. The examples show the correct `smtpAuth` values (`OAUTHBEARER` for Gmail, `XOAUTH2` for Outlook) and port settings.

Notably, the author includes links to their own community-maintained credential helpers (`git-credential-gmail` and `git-credential-outlook`) that handle OAuth2.0 token generation, acknowledging the difficulty of finding reliable solutions. The documentation maintains the existing structure while adding new sections for OAuth-specific instructions and credential helper recommendations.

This builds on the thread's established context about email infrastructure improvements, with the documentation changes complementing the technical FQDN validation fixes in other patches. The examples appear well-tested (the author mentions personal use of the Outlook helper) and the formatting follows Git's documentation conventions. The patch is focused and complete, though reviewers may want to verify the accuracy of the OAuth implementation details against current Authen::SASL capabilities.
