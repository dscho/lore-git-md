This change is needed for the stash export/import functionality where the calling code wants to handle such errors gracefully. The flag is opt-in rather than default to maintain compatibility with existing callers that rely on the current behavior, including test code.

The change is relatively small (6 lines net) but important for the series' error handling strategy.
