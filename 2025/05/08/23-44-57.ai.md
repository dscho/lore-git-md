This is the final patch in the v5 series introducing stash import/export functionality, implementing the `git stash import` subcommand to complement the previously added `export` capability. The patch adds the ability to import stashes that were previously exported to refs/stash-export/ back into the local stash stack.

The implementation:
- Adds a new `import` subcommand that takes a commit created by `export` and reconstructs the original stash entries
- Preserves the stash stack by appending imported stashes rather than replacing existing ones (users can `clear` first if desired)
- Validates imported commits match the expected export format (two parents with empty tree)
- Includes extensive test coverage (78 new test lines) verifying round-trip behavior, edge cases, and error handling

Key technical details:
- Uses `do_import_stash()` to walk the commit chain and reconstruct stash entries
- Validates each imported commit has the expected parent structure via `get_oidf()`
- Stores imported stashes using the existing `do_store_stash()` infrastructure
- Tests verify both direct import and ref-based import scenarios

The patch completes the feature by providing the inverse operation to `export`, enabling full stash transfer workflows between repositories. It maintains consistency with the series' design choices around non-destructive operations and robust validation.
