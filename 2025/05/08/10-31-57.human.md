Documentation update for OAuth2.0 support in git-send-email. This is part of a series that also includes stricter FQDN validation in the email functionality.

The patch enhances the git-send-email documentation to better explain OAuth2.0 authentication, which is now become supported through updates to the Authen::SASL Perl module. It provides clear configuration examples for both Gmail and Outlook, noting that Outlook now requires OAuth2.0 exclusively. The author has included links to their own community-maintained credential helpers for both services, which they developed after struggling to find reliable OAuth2.0 token generators.

The documentation improvements are thorough and practical, addressing a real need as email providers move away from basic authentication. The examples are well-formatted and the instructions are clear, though some readers might want to verify the security implications of using third-party credential helpers. This appears to be a well-considered update to keep the documentation current with evolving authentication methods.
