This is a feature patch series introducing the ability to import and export stashes as refs, addressing a long-standing gap where stashes couldn't be shared across repositories. The series comes from Brian Carlson (v5) and represents a mature iteration with multiple rounds of review and refinement.

The core idea is to store stashes as commit chains (with each export commit pointing to both the next stash and the actual stash content) rather than just in reflogs. This enables stash portability through standard Git operations like push/fetch/bundle. The implementation touches stash internals, object name handling, and adds comprehensive tests.

The series has seen significant iteration since its 2022 debut, with v5 addressing memory leaks, segfaults, test improvements, and code organization. Changes span documentation updates, core stash operations, and low-level OID handling. The patch quality appears high, with careful attention to edge cases and test coverage.

For users who work with stashes across multiple repositories, this provides important new functionality. The implementation looks well-considered, though the storage format change may warrant close review from stash heavy users. The extensive changelog shows the patches have already benefited from thorough community scrutiny.
