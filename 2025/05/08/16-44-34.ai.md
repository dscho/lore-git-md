This is a build system patch series (part 2 of 3) focused on fixing various configuration and installation path issues across Git's build systems (Make, Meson, Autoconf). The series comes with some urgency as patch #5 aims to prevent a regression in the Autoconf build system before the next release cycle.

The 5 patches address several technical issues: properly quoting a build configuration path (GITWEBDIR), fixing Perl module (YAML.pm) and system config file installation locations in Meson, correcting GIT_EXEC_PATH setting, and upgrading an Autoconf check from link-time to compile-time for sysinfo detection. The author notes a minor merge conflict with an ongoing Meson/Perl path customization effort that was recently updated.

The changes touch core build configuration files (configure.ac, meson.build) and related components, with most modifications being straightforward path corrections. The sysinfo check upgrade in patch #5 appears to be the most substantial change, switching from AC_CHECK_LIB to AC_COMPILE_IFELSE for better reliability. The author has verified clean merging with 'next' but notes a resolvable conflict with 'seen' due to parallel work.
