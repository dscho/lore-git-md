This is a feature patch series (v5) introducing the ability to import and export stashes as refs, addressing the current limitation where stashes can't be transferred between repositories via push/fetch/bundle. The series builds on previous iterations with significant refinements to memory handling, error checking, and test coverage.

The core functionality adds two new stash subcommands: `export` (converting reflog-based stashes to commit chains) and `import` (reverse operation). The exported format uses commits with two parents - one pointing to the next stash in sequence, the other containing the actual stash data. This maintains the stash chain structure while making it transferable.

Key technical details include modifications to `builtin/stash.c` (339 lines added) for the new commands, `object-name.c` changes to support quiet error returns in OID lookup, and expanded documentation in `git-stash.adoc`. The implementation now uses `oid_array` for better memory management and includes thorough test coverage in `t/t3903-stash.sh` (78 new lines) verifying edge cases like empty stashes and ident validation.

The v5 iteration focuses on fixing memory leaks, segfaults from rebasing, and improving test robustness. Notable changes from earlier versions include switching to `strstr` for commit parsing, additional leak fixes, and ident value verification. The series appears mature after five iterations, with careful attention to edge cases and code quality.
