This is the final patch in a documentation series improving OAuth2.0 authentication support for `git send-email`. The patch adds references to two community-contributed credential helpers (`git-credential-gmail` and `git-credential-outlook`) to Git's official credential helper documentation.

The change is straightforward - it simply lists these helpers alongside the existing `git-credential-oauth` helper in `gitcredentials.adoc`. Each helper gets a brief description noting they are cross-platform and specifically designed for use with `git send-email`. The patch follows the same format as existing helper documentation, including links to the GitHub repositories where they can be found.

This completes the series that has been through seven iterations, with previous patches covering RFC1035 domain validation and restructuring the OAuth2.0 documentation in `git-send-email.adoc`. The series has already received maintainer approval, with Junio Hamano confirming the technical soundness and documentation quality in earlier reviews. This final patch appears to be a clean, uncontroversial addition that provides users with more options for OAuth authentication when sending email patches.
