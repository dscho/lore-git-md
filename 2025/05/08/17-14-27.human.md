This is the first patch in a v7 series improving `git send-email`'s domain validation and OAuth2.0 authentication. The patch tightens the validation of Fully Qualified Domain Names (FQDN) to comply with RFC1035 standards, fixing a real-world issue where invalid hostnames were being sent to SMTP servers.

The current implementation only checked for a dot in the domain name and a special case for macOS `.local` domains. The new version enforces proper label structure (1-63 alphanumeric/hyphen characters per label, no leading/trailing hyphens) using regex lookaheads/lookbehinds. The commit includes clear examples of valid and invalid domains, plus SMTP session logs showing the problem (rejected "MacBook.." hostname) and the fixed behavior (falling back to "localhost.localdomain").

This is a well-motivated bugfix with thorough documentation of both the problem and solution. The patch is small and focused, building on prior discussion in the thread where the technical approach was already approved. It's part of a mature series that maintainers have indicated is ready for merging.
