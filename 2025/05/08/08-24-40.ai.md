Build system patch (v2) implementing `perllibdir` customization for Perl library paths in meson build configuration. This follows up on review feedback from Patrick Steinhardt on the initial version, addressing documentation improvements while maintaining the core functionality.

The patch adds a new `perllibdir` meson option that allows distributions like Fedora to specify custom Perl library installation paths (e.g., `/usr/share/perl5/vendor_perl`), matching existing Makefile behavior. When unspecified, it falls back to the default `<datadir>/perl5`. The changes affect 10 build files covering core Git Perl modules, CPAN-related modules, and dependencies.
