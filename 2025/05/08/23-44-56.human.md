This is a feature patch adding a new `git stash export` subcommand, part of a series addressing stash synchronization between machines. The patch introduces functionality to convert stash entries into regular commit objects that can be pushed/pulled like normal refs, solving a common workflow pain point.

The new `export` subcommand offers two modes: `--print` outputs the commit hash without creating a ref (for scripting), while `--to-ref` writes the converted stash to a specified ref. The implementation creates a chain of commits where each stash entry becomes a commit with two parents - one linking to the previous stash (or an empty base commit) and one preserving the original stash content. This maintains stash history while making it transferable.

The patch appears well-considered, with thorough implementation handling both specific stash references and the full stash stack. It includes documentation updates and preserves original authorship/timestamps in the converted commits. The commit message clearly explains the motivation (enabling stash transfer between machines) and implementation approach. This seems like a useful quality-of-life improvement for developers working across multiple systems.
