This is the second patch in a three-part series improving `git send-email` documentation, specifically focusing on OAuth2.0 authentication support. The patch restructures and expands the documentation to clearly separate Gmail and Outlook configuration examples, while adding details about OAuth2.0 methods.

The key changes include:
- Reorganizing the examples section into distinct "Gmail" and "Outlook" subsections
- Adding OAuth2.0 configuration details for both providers (using `smtpAuth = OAUTHBEARER` for Gmail and `smtpAuth = XOAUTH2` for Outlook)
- Documenting the author's community-maintained credential helpers (`git-credential-gmail` and `git-credential-outlook`) with GitHub links
- Consistently applying backticks to all user-visible elements (commands, options, paths) as requested in previous reviews
- The patch maintains backward compatibility by still documenting traditional password-based authentication while emphasizing OAuth2.0 as the modern approach
- Includes practical examples showing the author used `git-credential-outlook` to send this very patch series
- Follows the project's documentation standards for AsciiDoc formatting and line breaks

This represents the final documentation polish for the OAuth2.0 authentication portion of the series, with all technical content having been approved in v5 and now just receiving its final formatting touches. The patch demonstrates the documented workflow by being sent using the very OAuth2.0 method it describes.
