Documentation update adding OAuth credential helpers for email authentication. This is the final patch in a v6 series that has already been technically approved, now just adding references to two community-maintained credential helpers (`git-credential-gmail` and `git-credential-outlook`) to the gitcredentials documentation.

The patch is straightforward - it simply adds two entries to the "Popular helpers with OAuth support" section, with links to the GitHub repositories and brief descriptions noting they're specifically for `git-send-email` authentication. The author demonstrates the `git-credential-outlook` helper in action by using it to send this very email.

This completes the series that previously addressed RFC1035 domain validation and OAuth2.0 authentication documentation for `git-send-email`. The changes here are purely additive documentation with no technical impact, following the project's formatting standards (using backticks consistently) as confirmed by maintainer Junio Hamano in earlier discussion. The series appears ready for merging.
