This is a bugfix patch for `git send-email` that tightens validation of Fully Qualified Domain Names (FQDNs) according to RFC1035 standards. It's the first of three patches in a v6 series that has already been technically approved, with this version focusing on final documentation formatting.

The patch addresses a real-world issue where `git send-email` was passing invalid domain names (like "MacBook..") to SMTP servers, causing email delivery failures. The new validation enforces proper domain structure: labels must be 1-63 alphanumeric/hyphen characters, can't start/end with hyphens, and must contain at least one dot (while maintaining the existing macOS `.local` exception).

The implementation uses Perl regex with negative lookaheads/lookbehinds to properly validate label boundaries, and includes a test script to verify edge cases. The change is minimal (just 3 lines modified) but effectively prevents invalid domain submissions while maintaining backward compatibility.

This is the final version of a well-tested change that has gone through multiple review iterations, with the v6 version only adjusting documentation formatting per maintainer feedback. The patch demonstrates clear problem/solution pairing with good commit message detail showing both invalid and valid domain examples.
