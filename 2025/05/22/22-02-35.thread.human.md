This thread addresses a bug in `git apply --reverse` where mode bits (executable permissions) were not properly preserved when reversing deletions of executable files. The issue stems from commit 01aff0a in December 2023, which handled most cases correctly but missed this specific scenario. The fix, now in its second version, consists of two patches: one adding comprehensive test suite coverage and another implementing the actual one-line code change in apply.c to include deletion cases in mode preservation. The test matrix covers all combinations of file operations (creation, modification, deletion), mode transitions (executable ↔ non-executable), core.fileMode settings, and working tree vs index states.

Reviewers including Junio Hamano, Mark Mentovai, and Kristoffer Haugsbakk have provided feedback that has been incorporated into v2, improving test structure, commit message clarity, and coverage. Junio's latest review offers final polish, noting a minor style nit in test helper formatting and suggesting adding `git reset --hard` between test segments for better robustness when tests fail. The technical consensus is clear, with no outstanding objections, and the series appears ready for merging with its expanded test coverage that validates the fix across all relevant scenarios while maintaining the original test coverage from commit 01aff0a.
