This thread addresses a bug in `git apply --reverse` where file mode bits (executable permissions) were not properly preserved when reversing deletions of executable files. The issue stems from commit 01aff0a in December 2023, which handled mode preservation in most cases but missed the deletion scenario.

The fix is a one-line change in apply.c to include deletion cases in the mode bit swapping logic. Over three versions, the patch has evolved with increasingly comprehensive test coverage. The latest iteration (v3) adds final test infrastructure improvements, including proper handling of absent files (000000 mode), consistent six-digit octal mode representation, isolated test execution, and verification of warning behavior for mode mismatches.

Key participants include Junio Hamano, who suggested test structure improvements, and reviewers Mark Mentovai and Kristoffer Haugsbakk who provided feedback on mode representation and commit message wording. The tests now cover all combinations of file creation, modification, and deletion with executable/non-executable transitions, working in both forward and reverse directions, and with different core.fileMode settings.

With all review feedback addressed and no outstanding objections, this well-tested fix appears ready for merging. The comprehensive test matrix validates the fix across all relevant cases while maintaining portability, with the v3 changes representing final polish to the test infrastructure.
