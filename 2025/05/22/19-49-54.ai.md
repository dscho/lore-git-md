Bugfix patch completing the `imap-send` series by addressing a memory leak in CRAM-MD5 authentication. This is the final patch in a v2 series that overhauled IMAP authentication with OAuth2.0 support and configuration fixes.

This matches the memory management pattern used elsewhere in the function where `response` is freed after successful transmission.
