This is a feature and bugfix series for the long-neglected `git imap-s`end` command. Aditya Garg submits two patches that both fix existing issues and add modern authentication support.

The first patch fixes a configuration parsing bug that was preventing the command from working at all - specifically, it corrects an issue where the IMAP folder setting was incorrectly being set to NULL. This appears to be a straightforward bugfix for basic functionality.

The second and more substantial patch adds OAuth2.0 support to `git imap-send`, bringing the command's authentication options up to date with modern email providers' requirements. The changes include new documentation for OAuth2.0 configuration and the necessary implementation changes in the imap-send.c code.

The series touches both documentation and core functionality, with about 200 lines changed across three files. The author's surprise at the command's existence suggests this may be one of Git's more obscure features getting some much-needed attention. The changes look focused and well-contained, making this worth reviewing for anyone who uses or maintains Git's email-sending capabilities.
