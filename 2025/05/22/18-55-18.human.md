Build system improvement to prevent unnecessary rebuilds when using compilation databases.

Brian Carlson addresses an issue where enabling `GENERATE_COMPILATION_DATABASE=yes` (used by clangd for editor tooling) causes Git's entire codebase to rebuild unnecessarily on subsequent `make` runs. The problem occurs because the compilation database directory's modification time updates with each build, making it appear newer than the object files.

The solution applies the same pattern used for `.depend` directory handling - filtering out the compilation database directory from rebuild targets if it already exists. This one-line Makefile change prevents the constant rebuilds while maintaining the compilation database functionality.

The patch is straightforward with clear motivation and a real quality-of-life improvement for developers using clangd-based tooling. It comes with sign-off from both the author and Philippe Blain, suggesting it's been reviewed. The change is minimal and low-risk, touching only the build system without affecting runtime behavior.
