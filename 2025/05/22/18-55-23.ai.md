This is the core implementation patch for the `git stash export` feature in the v6 series. It introduces the subcommand that converts stash entries into a chain of commits under `refs/stash-export/`, enabling stash transfer between repositories.

The patch adds 250 lines to `builtin/stash.c` implementing the export logic, plus documentation updates. Key technical aspects:

1. **Export mechanics**:
   - Creates an empty base commit (using fixed timestamp for reproducibility)
   - Processes stashes either from command-line arguments or by walking `refs/stash` reflog
   - Validates stash topology via `check_stash_topology()` helper
   - Reconstructs commits with new parent chains pointing to previous exports

2. **Output options**:
   - `--to-ref` writes to specified ref (typically under `refs/stash-export/`)
   - `--print` outputs hash without creating ref (for scripting)

3. **Safety checks**:
   - Validates stash structure (2-3 parents, proper linkages)
   - Uses `GET_OID_QUIETLY | GET_OID_GENTLY` for graceful error handling
   - Preserves original commit metadata (author, message) with "git stash: " prefix

4. **Integration**:
   - Leverages reflog-walk infrastructure via `read_complete_reflog()`
   - Uses new `parse_stash_revision()` helper from earlier refactoring
   - Maintains existing stash commit structure in second parents

The implementation handles both bulk export (all stashes) and selective export (specific stash references). It represents the culmination of the series' technical work, building on the preparatory refactoring and infrastructure changes from earlier patches.
