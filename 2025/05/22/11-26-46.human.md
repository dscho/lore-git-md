This is a platform compatibility fix for Git's cvsserver Perl script, addressing test failures that occur with Perl 5.41.4 and newer versions. The patch represents the third iteration of a solution that has evolved through community feedback.

The core issue stems from a Perl operator precedence warning in the `escapeRefName` function, which was causing test failures in t9402-git-cvsserver-refs.sh (specifically tests 30-32 and 34). Earlier versions of the patch added parentheses to clarify the precedence, but this final version adopts the more idiomatic Perl `!~` operator for negative pattern matching, as suggested by Brian Carlson.

The change is minimal - a single line modification in git-cvsserver.perl that replaces `! $refName=~/pattern/` with `$refName !~ /pattern/`. While the functional impact is the same, this version better aligns with Perl best practices. The patch maintains backward compatibility while resolving the test failures that were appearing in Fedora builds with newer Perl versions.
