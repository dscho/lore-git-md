This is a documentation patch addressing the ongoing transition from .txt to .adoc file extensions in Git's documentation. Junio C Hamano responds to Jouke Witteveen's earlier patch and discussion about link formatting challenges, specifically around the xref: syntax incompatibility with Git's documentation toolchain.

Junio proposes a pragmatic solution: simply update the file extension while keeping the basic link text format, accompanied by a comment explaining the xref: limitation and suggesting future syntax once asciidoc support is dropped.

The proposed change demonstrates the careful balance needed during this transition period - updating references while maintaining backward compatibility. The comment serves both as documentation of the current constraint and as a placeholder for future improvement. This approach avoids breaking existing documentation builds while clearly signaling the intended direction once toolchain requirements evolve.

Key technical details include the specific file being modified (build-systems.adoc), the exact proposed diff format, and the clear articulation of the toolchain limitation (asciidoc incompatibility and --attribute compat-mode in Asciidoctor). The solution maintains the link's functionality in its simplest form while acknowledging the more sophisticated xref: syntax as a future goal.
