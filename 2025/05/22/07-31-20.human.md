The original fix added parentheses to clarify operator precedence, but after discussion, Ondřej Pohořelský now agrees to switch to the more idiomatic Perl `!~` operator for negative pattern matching, as suggested by Brian Carlson.

The thread has already established that this is the right technical solution, with Junio C Hamano having queued version 2 of the patch. The current email represents a final refinement to use better Perl style while maintaining the same functionality. While the immediate issue is straightforward, broader questions about cvsserver maintenance and the utility of the `escapeRefName` function remain open but separate from this fix.
