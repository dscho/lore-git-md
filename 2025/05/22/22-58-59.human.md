Bugfix review for `git apply --reverse` file mode handling. Junio Hamano provides detailed feedback on Mark Mentovai's test additions for the executable bit preservation fix. The core issue (fixed in commit 01aff0a) was that `git apply --reverse` wasn't properly transferring mode bits when reversing deletions of executable files.

Hamano's review focuses on test improvements, noting:
1. A `reset --hard` in one test might unintentionally reduce coverage of working tree vs index behavior
2. Some test steps appear redundant (like repeated `checkout` operations)
3. Suggests restructuring the test to generate all patches upfront with explicit names rather than repeatedly using `format-patch` with relative references
4. Points out the preferred command-line ordering for Git commands
5. Observes the test could be more efficient by reusing patches across test cases

The feedback is constructive and technical, focusing on making the tests more robust and maintainable while preserving their coverage of the core file mode behavior. No issues are raised with the actual bugfix logic - this appears to be purely about test quality improvements.
