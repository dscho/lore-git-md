This is a technical review comment on the OAuth2.0 authentication patch for `imap-send`. Brian Carlson raises concerns about the implementation's dependency on OpenSSL for base64 encoding, which could create licensing distribution issues. They suggest two alternative approaches: either implementing a minimal base64 encoder within Git (similar to existing decoder code in `mailinfo.c`), or moving the base64 encoding responsibility to the credential helper system.

The comment highlights an important architectural consideration - the patch currently makes OAuth2.0 support contingent on OpenSSL when only basic base64 encoding is needed. Carlson's suggestions aim to maintain functionality while avoiding problematic dependencies, with a preference for leveraging the credential helper system they previously worked on. This feedback will likely require revisions to the OAuth2.0 implementation before the patch can proceed.
