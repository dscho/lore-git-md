This is a documentation patch addressing the ongoing transition from .txt to .adoc file extensions in Git's documentation. Junio C Hamano responds to Jouke Witteveen's earlier patch that attempted to update references while also converting Markdown-style links to AsciiDoc's xref: syntax.

The discussion reveals an important constraint: Git's documentation toolchain doesn't support AsciiDoc's xref: feature due to compatibility requirements with the legacy asciidoc processor. Junio proposes a pragmatic solution - simply updating the file reference while leaving the link format unchanged, with an added comment explaining why xref: can't be used yet and how it might be implemented in the future.

The exchange highlights the careful balance needed in documentation modernization effort between adopting new features and maintaining compatibility. Junio's suggestion provides a clear path forward for this specific case while documenting the limitation for future contributors. The patch appears technically sound and addresses the immediate need while properly accounting for the toolchain constraints.
