This is a style review of a bugfix patch for file mode handling in `git apply --reverse`. The patch itself (already summarized in the thread context) fixes an issue where reversing a deletion of an executable file would not properly restore the executable bit. Kristoffer Haugsbakk provides feedback on the commit message's style and phrasing.

The review focuses on three main style points: (1) the format used to reference commits (noting a semicolon where a comma is conventional), (2) a redundant word ("notable notable"), and (3) suggestions for more active voice and present-tense descriptions of code behavior in commit messages. The reviewer prefers phrasing that describes problematic current behavior before introducing the fix, and recommends imperative mood ("Add tests") over passive constructions.

While the technical content of the patch appears sound (as noted in the thread summary), this review helps polish the commit message to match Git project conventions.
