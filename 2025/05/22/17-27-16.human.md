This is the second patch in a two-part series adding OAuth2.0 authentication support to `git imap-send`. The patch implements support for both the standard OAUTHBEARER mechanism (RFC5801/RFC7628) and Google's proprietary XOAUTH2 protocol, addressing a gap where modern email providers increasingly require OAuth-based authentication.

The implementation adds ~150 lines of new code in `imap-send.c` with helper functions to construct and encode the authentication tokens, plus documentation in `imap.adoc` and `git-imap-send.adoc` explaining the new configuration options (`imap.authmethod=OAUTHBEARER/XOAUTH2`) and usage notes for Gmail and Outlook. The code follows existing patterns for IMAP authentication, with OpenSSL-based base64 encoding and clear error handling.

While the patch appears technically sound, the author notes potential issues: some libcurl bugs may interfere with OAuth2.0 authentication (suggesting `--no-curl` as a workaround), and the implementation will need security review since OAuth flows handle sensitive credentials. Given `imap-send`'s niche status, this feature addition may not get immediate attention, but it modernizes authentication for users who rely on the command with OAuth-only providers like Outlook.
