Feature addition to `imap-send` adding OAuth2.0 authentication support, completing the two-patch series that began with a configuration parsing fix. This patch implements both RFC-standard OAUTHBEARER and Google's XOAUTH2 mechanisms for token-based authentication, addressing modern email provider requirements where basic auth is deprecated.

The implementation adds three new authentication-related capabilities to the IMAP protocol handler (AUTH_OAUTHBEARER, AUTH_XOAUTH2), with corresponding base64 encoding functions for each mechanism's specific payload format. The patch includes ~150 lines of new code in `imap-send.c` implementing the full token flow, plus documentation updates in `imap.adoc` and `git-imap-send.adoc` covering both Gmail and Outlook configurations. New error handling warns when required OpenSSL support is missing.

Key technical details include: new `oauthbearer_base64()` and `xoauth2_base64()` helper functions constructing protocol-specific auth strings; expanded `authmethod` configuration to accept the new options; and credential helper integration notes. The implementation remains contained to the IMAP subsystem but touches sensitive authentication paths. The author notes potential libcurl bugs with OAuth2.0 and recommends `--no-curl` fallback.

This completes the series' dual goals of fixing immediate configuration issues while modernizing authentication. The substantial new functionality may warrant security review, particularly around token handling and OpenSSL dependencies. No reviews yet for either patch in the series.
