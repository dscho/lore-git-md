Feature proposal withdrawn: Windows update help message. The author Aditya Garg has decided to drop the patch proposing to add Windows-specific update instructions to Git's help output, following strong opposition from brian m. carlson. The key objections centered on this being a distribution-specific concern (like Debian package updates) rather than something upstream Git should handle, along with potential issues with corporate environments where the updater might not work. 

This concludes the thread with the feature not moving forward in upstream Git, though the idea could still be implemented as a downstream patch in Git for Windows if its maintainers choose to do so. The discussion highlighted important boundaries around what belongs in core Git versus distribution-specific customizations.
