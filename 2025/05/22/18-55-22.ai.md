This is a refactoring patch in the final iteration of the stash import/export feature series. It extracts stash revision parsing logic into a reusable helper function (`parse_stash_revision`) while maintaining identical behavior. The change prepares for future reuse of this parsing logic in other parts of the stash implementation.

The patch moves the special-case handling of stash references (numeric-only arguments, empty arguments defaulting to `@{0}`) from `get_stash_info` into the new function. Key technical points:
- Preserves all existing error cases and messages
- Adds a `quiet` parameter to suppress "No stash entries" output when needed
- Initializes the strbuf in `get_stash_info` before passing it
- Maintains the same three parsing cases: empty input, numeric index, direct reference

This is a straightforward plumbing change that follows the series' pattern of careful refactoring. The patch fits naturally with the series' goal of robust stash handling, though it doesn't directly impact the import/export functionality itself. The change is well-contained (affecting only `builtin/stash.c) and maintains backward compatibility while enabling future extension points.
