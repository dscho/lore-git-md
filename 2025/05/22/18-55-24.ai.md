Feature implementation for stash import/export functionality. This is the final patch in the v6 series, adding the `git stash import` subcommand to complement the previously implemented `export` capability. The patch implements bidirectional transfer of stashes between repositories by:

1. Adding the `import` subcommand that takes a commit created by `export` and reconstructs the original stashes, appending them to the current stash stack rather than replacing it (users can explicitly `clear` first if desired).

2. Performing rigorous validation of imported commits:
   - Enforcing the special root commit structure with empty tree and fixed metadata
   - Verifying the "git stash: " message prefix on all stash commits
   - Checking parent topology matches expected stash structure
   - Using the shared `check_stash_topology()` helper from earlier in the series

3. Adding comprehensive test coverage in t3903 that:
   - Verifies round-trip fidelity through export/import cycles
   - Tests edge cases like empty exports and malformed imports
   - Confirms the append behavior preserves existing stashes
   - Validates the ref-based storage format

Key technical details:
- The import process walks the commit chain created by export, stripping off the first parent (chain commit) and storing each second parent (stash commit) via `do_store_stash()`
- Uses the same strict validation as export for commit messages, tree structure, and parent relationships
- Maintains the same test OIDs across hash algorithms via `test_oid_cache`
- Adds 94 lines of new test coverage (bringing t3903 to 268 new lines total for the feature)

The implementation builds on all prior series refinements including:
- Reflog infrastructure from patch 1
- Stash parsing helper from patch 2
- Topology validation from patch 3
- Export implementation from patch 4

This represents the completion of the multi-year effort to enable stash portability between repositories while maintaining security and data integrity. The only remaining item is Phillip Wood's sign-off on this final patch.
