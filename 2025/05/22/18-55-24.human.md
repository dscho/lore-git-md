Feature patch completing the stash import/export functionality. This is the final patch in a well-reviewed series that adds bidirectional stash transfer capabilities via `git stash export` and `git stash import`. The patch implements the import side, allowing users to bring stashes back from a reference created by `export`. 

Key aspects:
- Imports stashes by walking the commit chain created by export, validating each commit's structure
- Appends imported stashes rather than replacing existing ones (users can `clear` first if desired)
- Includes thorough test coverage of round-trip scenarios, edge cases, and error handling
- Maintains strict validation of exported stash structure (commit messages, parent relationships)
- Preserves all stash metadata through the export/import cycle

The implementation builds on the series' earlier work with reflog handling and commit validation. This appears production-ready, with all major technical concerns addressed in previous iterations. The patch has Phillip Wood's sign-off pending but otherwise seems poised for merging. The tests demonstrate robust handling of both happy paths and error cases, including malformed imports.
