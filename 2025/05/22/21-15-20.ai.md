This is the final patch in the v6 series introducing stash import/export functionality, implementing the `git stash import` subcommand to complement the previously added `export` capability. The patch builds on the series' established infrastructure for handling stash commit chains under `refs/stash-export/`.

The import operation reconstructs stashes from exported commit chains by:
1. Stripping the first-parent chain commits (the empty base commit and linking structure)
2. Storing the remaining stash commits via `do_store_stash()`
3. Appending them to the existing stash rather than replacing it, with an explicit `git stash clear` suggested for full replacement scenarios

Key technical aspects include:
- Reusing the same strict validation helpers (`check_stash_topology()`) from export
- Preserving original metadata while verifying structure
- Leveraging test OID consistency as a verification mechanism
