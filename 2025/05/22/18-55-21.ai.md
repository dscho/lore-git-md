Refactoring patch for reflog-walk infrastructure as part of the stash import/export series. This is patch 2/5 in the v6 iteration of the feature.

The patch moves the `complete_reflogs` struct definition and two related functions (`read_complete_reflog` and `free_complete_reflog`) from reflog-walk.c to reflog-walk.h, making them for use by the upcoming stash import/export functionality. The implementation remains unchanged - this is purely a visibility change to support the new stash commands' need to fully read and validate reflog entries during import operations.

Key technical details:
- Exposes previously internal reflog reading machinery needed for robust stash import validation
- Maintains identical behavior while making functions available to other compilation units
- Adds necessary headers (git-compat-util.h, hash.h) to the public interface
- Follows standard pattern of moving implementation details to headers when cross-file access is required

This is a straightforward plumbing change that enables the more complex stash import validation work in subsequent patches. The patch has no functional impact on existing code while providing the building blocks needed for the new feature's safety checks.
