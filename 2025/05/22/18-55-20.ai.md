Refactoring of `get_oid` error handling for stash export/import series.

This patch modifies the object-name machinery to add a new `GET_OID_GENTLY` flag that makes `get_oid_basic()` return -1 on reflog history exhaustion rather than dying or exiting quietly. The change is motivated by the stash import/export feature's error handling needs, where callers want to recover from this condition rather than terminate.

The implementation adds the flag definition in `hash.h` and modifies the reflog-walking logic in `object-name.c` to respect it. The patch notes this can't be made the default behavior due to existing test dependencies, so it's introduced as an opt-in flag. The change is narrowly scoped to the reflog exhaustion case while preserving all other existing behaviors.
