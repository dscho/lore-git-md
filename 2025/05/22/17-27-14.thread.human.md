This thread covers Aditya Garg's v5 patch series improving `imap-send`, which has evolved through thorough review to address both technical requirements and user experience. The series fixes a critical configuration parser bug (regression from 6d1f198f34), adds OAuth2.0 support via curl's native API with OpenSSL fallbacks, implements RFC 4616 PLAIN authentication, and comprehensively fixes CRAM-MD5 memory leaks. 

Key reviewers - Jeff King, Eric Sunshine, brian m. carlson, and D. Ben Knoble - helped shape the series, with Knoble validating the final memory management fixes. The latest patch adds `imap.usecurl` configuration to control backend selection (curl vs OpenSSL), complementing the existing `--[no]-curl` CLI flags. This maintains the established pattern where command-line options override config settings, while properly handling build-time constraints. 

The series now provides complete authentication method coverage (OAuth2.0, PLAIN, CRAM-MD5) with robust error handling, along with user conveniences like the `--folder` override and now persistent backend preference via config. All technical issues raised during review have been addressed, making this series merge-ready with comprehensive documentation covering the new features and their interactions.
