This thread covers a substantial update to Git's `imap-send` functionality, now at version 15 of the patch series. The work restores broken features while adding modern capabilities, with OAuth2.0 authentication support being the headline addition. The series fixes a critical configuration parsing bug that had made `imap-send` unusable since Git 2.46.0, along with comprehensive memory leak fixes in the CRAM-MD5 implementation.

Key improvements include new `--list` and `--folder` command-line options for IMAP folder management, standardized error messages, and progress output that now shows destination folders. The latest patch adds PLAIN authentication support for the OpenSSL backend, completing feature parity with the libcurl implementation. This is particularly useful for services using app passwords.

The series has undergone thorough review from Jeff King, Eric Sunshine, Brian Carlson, Junio Hamano, and Ben Knoble. Version 15 reorganizes the patches as requested by Junio, placing CRAM-MD5 changes before the newer authentication methods. With all critical issues resolved and design questions addressed, the implementation now provides a complete solution for IMAP functionality in Git while maintaining backward compatibility.
