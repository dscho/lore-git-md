This thread covers a comprehensive update to Git's `imap-send` functionality, now in its 14th iteration. The series fixes critical configuration parsing bugs that had broken `imap-send` since Git 2.46.0, while adding modern OAuth2.0 authentication support and new folder management features. Key improvements include a new `--list` option to show available IMAP folders, a `--folder` runtime override, and standardized error messages.

The implementation provides feature parity between OpenSSL and libcurl backends, with all authentication methods (including the newly added PLAIN and OAuth2.0) now working consistently. The series has undergone thorough review from Jeff King, Eric Sunshine, and others, with all major technical concerns addressed. The latest discussion focuses on patch organization - Junio Hamano suggested moving the CRAM-MD5 handling earlier in the series for better logical flow, though author Aditya Garg notes this would require non-trivial rebasing. The series appears merge-ready, having restored broken functionality while adding significant new capabilities for IMAP users.
