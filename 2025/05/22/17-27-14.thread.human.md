This thread documents a comprehensive overhaul of Git's `imap-send` functionality, now at version 15 of the patch series. The work introduces OAuth2.0 authentication support (both standard OAUTHBEARER and Google's XOAUTH2), adds new `--list` and `--folder` options for IMAP folder management, and fixes critical configuration parsing bugs that had made `imap-send` unusable since Git 2.46.0. The series has undergone thorough review from Jeff King, Eric Sunshine, Brian Carlson, Junio Hamano, and Ben Knoble, addressing all technical concerns. Version 15 reorganizes the patches to place foundational authentication changes (like CRAM-MD5 improvements) earlier in the series as requested by Junio, while maintaining all functionality from previous versions. The implementation now provides complete RFC-compliant IMAP support with standardized error messages, credential prompts showing port numbers, and progress output indicating destination folders. With all critical issues resolved and design questions addressed, the series is now ready for merging.
