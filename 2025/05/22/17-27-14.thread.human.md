This thread covers a v13 patch series adding OAuth2.0 authentication and other improvements to `git imap-send`. The series fixes several critical issues, including a configuration parsing regression from Git 2.46.0 that made the command unusable, and adds new features like folder listing and OAuth support for both OpenSSL and libcurl backends. Key contributors include Aditya Garg (the primary author), Jeff King (who identified a security-critical logic error in the OAuth implementation), and Eric Sunshine.

The series has addressed most technical concerns through multiple rounds of review, with v13 fixing the final known issues. However, Junio Hamano has raised two design-level questions about the implementation: the placement of OpenSSL availability checks in the code flow, and whether the special-case handling of OAuth methods will scale well as new authentication mechanisms are added. While these don't block functionality (the OAuth implementation works correctly after the v13 fixes), they suggest potential maintainability improvements before merging. The discussion continues to focus on finding the right balance between correctness, readability, and future extensibility in the authentication code paths.
