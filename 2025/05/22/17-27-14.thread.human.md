This thread documents a comprehensive update to Git's `imap-send` functionality, now at version 9 of the patch series. The work adds OAuth2.0 authentication support (for both OpenSSL and libcurl backends), fixes several critical configuration parsing bugs, and introduces new user-facing features like folder listing and improved credential prompts. The most recent patch adds a `--list` option that shows available IMAP folders with their server-specific names (like Gmail's "[Gmail]/Drafts"), solving a common pain point for users.

Key technical improvements include fixing a regression that made `imap-send` unusable since Git 2.46.0, implementing RFC-compliant authentication methods (OAuth2.0, PLAIN, and CRAM-MD5), and adding memory leak fixes across all error paths. The series has undergone thorough review from Jeff King, Eric Sunshine, and others, with each iteration addressing both correctness and usability concerns.

The only remaining open question is whether to maintain both OpenSSL and libcurl backends long-term, as Junio Hamano and Phillip Wood have questioned the maintenance burden. Series author Aditya Garg notes that dropping OpenSSL would mainly affect CRAM-MD5 support while keeping tunnel functionality. With this final folder listing addition, the series appears technically complete pending resolution of the backend support discussion.
