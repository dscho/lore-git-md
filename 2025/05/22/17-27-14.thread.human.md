This thread documents the completion of a major feature and bugfix series for `imap-send`, now at version 11. The work restores functionality broken since Git 2.46.0 (fixing a critical configuration parser regression) while adding substantial new capabilities: OAuth2.0 authentication support (both standard OAUTHBEARER and Google's XOAUTH2), RFC-compliant PLAIN authentication, and comprehensive folder management. The final patch introduces a new `--list` option that shows available IMAP folders with proper handling of server-specific naming conventions, completing the folder management feature set alongside the previously added `--folder` runtime override.

Key contributors including Jeff King, Eric Sunshine, and Junio Hamano have reviewed the series, with Eric providing final polish on error message formatting. The implementation spans both OpenSSL and libcurl backends, with particular attention to memory safety - the latest iteration fixed a CRAM-MD5 memory issue and standardized cleanup patterns. User experience touches like showing destination folders during message sending and including port numbers in credential prompts make the tool more transparent. With all review feedback addressed and no outstanding technical issues, this series appears ready for merging.
