This thread covers a substantial update to `git imap-send` that adds OAuth2.0 authentication, comprehensive folder management, and fixes several long-standing issues. The series, now at v17 (soon to be v18 with a minor fix), has addressed critical feedback from reviewers including Junio Hamano, Jeff King, and Eric Sunshine. Key improvements include fixing a configuration parser regression that made `imap-send` unusable since Git 2.46.0, implementing RFC-compliant authentication methods (OAUTHBEARER, XOAUTH2, and PLAIN), and adding new `--list` and `--folder` options for IMAP folder management.

The discussion has narrowed to one remaining UX decision: whether credential prompts should always show port numbers (matching `send-email` behavior) or only show non-default ports to reduce noise. Junio Hamano prefers the latter approach but has indicated he won't block the series over this difference, leaving the final call to the author Aditya Garg. With all technical issues resolved and only this minor presentation detail outstanding, the series appears ready for integration once this last point is settled. The changes represent a significant upgrade to `imap-send`'s functionality and reliability after careful review and iteration.
