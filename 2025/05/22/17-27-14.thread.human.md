This thread covers a comprehensive v11 patch series improving `imap-send` with OAuth2.0 authentication support and folder management features. The series originated from Aditya Garg and has undergone extensive review from key contributors including Jeff King, Eric Sunshine, and Junio Hamano.

The most critical fix addresses a configuration parsing bug that made `imap-send` unusable since Git 2.46.0, incorrectly NULLing out folder fields when processing unrelated configuration variables. This regression is now properly fixed with field-specific cleanup in `git_imap_config()`. The series also introduces several user-facing improvements: a new `--list` option showing available folders with proper hierarchy markers, a `--folder` runtime override, and clearer progress output showing destination folders during sending.

For authentication, the patches add complete OAuth2.0 support via both standard OAUTHBEARER and Google's XOAUTH2 protocols, implemented consistently across OpenSSL and libcurl backends. Documentation updates guide users through OAuth2.0 setup, particularly helpful for Gmail users transitioning from app-specific passwords. Error messages and credential prompts have been polished to match Git's style guidelines, with Eric Sunshine providing final feedback on consistency.

The series is now technically complete after eleven iterations, having addressed all major review feedback. It represents a significant usability and security improvement for `imap-send`, particularly for users who need OAuth2.0 support or were affected by the configuration parsing regression. Junio will likely merge this into the next release cycle given the thorough review and critical nature of the fixes.
