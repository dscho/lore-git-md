This thread documents a substantial improvement series for Git's `imap-send` functionality, now in its 12th iteration. The work adds OAuth2.0 authentication support (both standard OAUTHBEARER and Google's XOAUTH2), fixes critical configuration parsing bugs that had made the tool unusable since Git 2.46.0, and introduces comprehensive folder management via a new `--list` option. The series has undergone thorough review from key contributors including Jeff King, Eric Sunshine, and Junio Hamano.

The latest patch is a small but meaningful user experience improvement that makes the port number visible in credential prompts, matching `git send-email`'s behavior. This change, while minor, provides clearer context when authenticating to multiple IMAP servers. The series appears ready for merging, having addressed all substantive technical feedback through twelve iterations while maintaining all introduced functionality. Recent changes focus exclusively on final polish and consistency improvements, with this credential prompt update representing one of the last user-facing refinements.
