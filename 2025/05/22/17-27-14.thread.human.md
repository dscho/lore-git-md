This thread documents a major overhaul of `git imap-send` that fixes critical bugs while adding significant new functionality. The series, now at v16, addresses a configuration parsing regression from Git 2.46.0 that made the command unusable, while introducing OAuth2.0 authentication support (both standard OAUTHBEARER and Google's XOAUTH2), RFC-compliant PLAIN authentication, and comprehensive folder management via new `--list` and `--folder` options. The implementation spans both OpenSSL and libcurl backends with consistent behavior.

Junio Hamano has reviewed and approved the core bugfixes and authentication improvements, while noting some minor organizational issues with patch ordering in earlier versions. The author has addressed these in v16 by restructuring the series to place authentication methods first, followed by folder management features, with UI polish patches at the end. The final few patches adding new features like folder listing and destination mailbox display still need review, but the series appears otherwise complete with all substantive feedback incorporated. 

Key contributors include Jeff King, Eric Sunshine, and Brian Carlson who provided thorough technical review, particularly around memory safety in the authentication handlers and configuration parsing. With the critical regression fixed and maintainer approval on the foundational changes, this modernization of `imap-send` is poised to land once the remaining feature patches receive final review.
