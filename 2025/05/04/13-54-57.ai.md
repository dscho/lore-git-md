Documentation patch expanding `git send-email` configuration examples, particularly for OAuth authentication. This is the second in a three-patch series that began with FQDN validation fixes.

The patch significantly enhances the `git-send-email.adoc` documentation with:
1. Detailed OAuth2.0 configuration examples for both Gmail (using OAUTHBEARER) and Outlook (using XOAUTH2), reflecting modern authentication requirements where app-specific passwords are no longer supported
2. A new "SENDING PATCHES" section with practical command-line examples covering single/multiple patches, cover letters, versioning, and recipient management
3. References to community-maintained credential helpers for Gmail and Outlook that support OAuth2.0
4. Improved formatting and organization, separating SMTP server configuration from patch-sending workflow

The changes are well-structured and address real-world needs, particularly for users dealing with modern email provider authentication requirements. The patch maintains consistency with the documentation style while adding substantial practical guidance. It complements the series' first technical patch by providing the user-facing documentation that would help users properly configure the email-sending functionality.
