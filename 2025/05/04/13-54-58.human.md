This is the third and final documentation patch in a series improving `git send-email` functionality, specifically focusing on OAuth authentication support. The patch adds two new credential helpers (`git-credential-outlook` and `git-credential-gmail`) to the list of OAuth-supported helpers in the gitcredentials documentation.

The additions provide dedicated helpers for authenticating with Gmail and Microsoft Outlook accounts when using `git send-email`, addressing the modern need for OAuth authentication as app-specific passwords become less supported. Both helpers are cross-platform and appear to be maintained by the patch author. The documentation follows the existing format, including direct links to the GitHub repositories for each helper.

This completes the series that began with technical FQDN validation fixes and continued with expanded OAuth documentation in `git-send-email.adoc`. The patch is straightforward and aligns well with the series' goal of improving email sending capabilities, particularly for users needing OAuth authentication with major email providers.
