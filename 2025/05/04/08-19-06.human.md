Git for Windows maintainer response regarding `git svn` issues on Windows. Johannes Schindelin acknowledges the reported problems with `git svn clone` failing with unhelpful error messages on Windows, including Perl warnings and path stripping failures. He notes that `git svn` is a high-maintenance component in Git for Windows with known issues, and reveals that there's active consideration to remove it from the Windows builds due to lack of maintainer bandwidth. As a workaround, he suggests using Windows Subsystem for Linux (WSL) for one-off SVN-to-Git migrations, since the Linux version may be more reliable. This response effectively confirms the reported issues as known limitations rather than new bugs to be fixed, while offering a practical alternative path forward for users needing SVN migration on Windows systems.
