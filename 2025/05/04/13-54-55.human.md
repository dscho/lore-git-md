This is a documentation and feature improvement patch series targeting `git send-email`. The series has two main goals: tightening the validation of fully-qualified domain names (FQDNs) in the send-email command to better comply with RFC1035 standards, and expanding the documentation to include practical examples of using OAuth2.0 authentication with Gmail and Outlook.

The first patch focuses on the technical implementation, making the FQDN checks more rigorous. The second and third patches are documentation updates that add clearer instructions and references for users trying to set up OAuth authentication with popular email providers. The changes touch both the send-email man page and the general credentials documentation.

The series appears well-structured with clear separation between code changes and documentation updates. The documentation additions look particularly useful, as OAuth setup is a common pain point for users of git-send-email. The patches don't introduce any breaking changes, just stricter validation and better docs.
