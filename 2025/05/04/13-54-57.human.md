This is a documentation patch that enhances the `git send-email` manual with modern authentication examples and usage patterns. It's the second in a three-part series that began with a technical fix for email validation.

The patch significantly expands the examples section of `git-send-email.adoc`, adding detailed OAuth2.0 configuration for both Gmail and Outlook. It provides clear configuration snippets showing the required settings for each provider, noting that Outlook now requires OAuth while Gmail offers it as an alternative to app passwords. The examples include the specific authentication types (`OAUTHBEARER` for Gmail, `XOAUTH2` for Outlook) and correct server addresses.

A new "SENDING PATCHES" section provides practical command-line examples covering common scenarios: sending single/multiple patches, using cover letters, specifying versions, and customizing subject prefixes. The patch also links to community-maintained credential helpers for OAuth authentication and references the main credentials documentation.

The changes are well-organized and address real user needs, particularly for those using modern email providers that have moved away from basic authentication. The examples are clear and cover both basic and advanced use cases, making this a valuable addition to the documentation.
