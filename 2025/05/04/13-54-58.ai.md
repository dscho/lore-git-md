This is the third and final documentation patch in a series improving `git send-email` functionality, specifically focusing on OAuth support. The patch adds two new credential helpers (`git-credential-outlook` and `git-credential-gmail`) to the list of OAuth-supported helpers in `gitcredentials.adoc`. 

The additions point to the author's own GitHub repository containing dedicated helpers for authenticating with Gmail and Microsoft Outlook accounts when using `git send-email`. Both helpers are described as cross-platform solutions. This completes the documentation improvements started in patch 2/3 of the series, which had already expanded OAuth configuration examples for these services.

The patch is straightforward and aligns with the series' goal of improving OAuth support documentation. However, it's worth noting these helpers appear to be the author's own projects rather than widely-adopted community solutions like the previously listed `git-credential-oauth`. The commit message is minimal but sufficient given the simple nature of the change. No tests are needed for this purely documentation update.
