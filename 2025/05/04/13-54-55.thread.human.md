This thread documents Aditya Garg's ongoing work to improve `git send-email`, focusing on two related efforts: RFC1035 domain validation with OAuth2.0 authentication (now in its seventh version and approved for inclusion), and platform-specific FQDN detection (currently at v4). The core series tightens domain validation with RFC1035-compliant regex checks while properly handling macOS's `.local` domains, and restructures OAuth2.0 with improved documentation and credential helper references.

The FQDN detection follow-up has been the subject of recent discussion, particularly around platform-specific approaches to getting the hostname. Junio Hamano initially expressed reservations about using different flags (`--fqdn` on Linux vs `-f` on macOS) but has now softened his stance, accepting this as a pragmatic solution while requesting clear rationale in the documentation. The implementation will use `hostname --fqdn` on Linux and `hostname -f` on macOS, with proper error handling and a fallback chain that maintains the 'localhost.localdomain' final fallback. Alpine Linux remains unsupported due to its hostname implementation limitations.

With Junio's latest email indicating acceptance of the platform-specific approach (pending documentation of the rationale), the FQDN detection changes appear to be nearing final approval. The thread demonstrates effective collaboration between Aditya and the maintainer, with all technical components now resolved and only documentation polish remaining before this long-running improvement can be merged.
