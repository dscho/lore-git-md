Test infrastructure patch refining path normalization terminology. Torsten Bögershausen suggests clearer wording for Mark Mentovai's patch that fixes test failures caused by symlink handling in path comparisons.

The core issue involves tests failing when run from directories containing symlinks, particularly in t7900's maintenance tests. While the technical solution (normalizing $TRASH_DIRECTORY and $HOME to match the `cd -P` resolved path) is sound, Torsten points out the terminology could be more precise. He proposes replacing "normalized path" with "absolute path" throughout to avoid confusion with CRLF conversion contexts and better align with Git's existing vocabulary.

This is a minor but thoughtful refinement to a test infrastructure change that already has consensus from Junio Hamano and others. The suggestion doesn't alter the patch's behavior but could make its intent clearer to future readers. The thread shows the Git community's attention to both technical correctness and documentation quality, even in small details.
