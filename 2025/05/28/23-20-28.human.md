This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking. 

The patch makes a simple but strategic code reorganization in `builtin/pack-objects.c`, swapping the positions of `show_commit_pack_hint()` and `show_object_pack_hint()`. Currently `show_commit_pack_hint()` is a no-op function, but the next patch in the series will modify it to call `show_object_pack_hint()`. This preparatory move minimizes code churn in the upcoming change.

The change is straightforward - just moving 6 lines of code down after the object hint function it will need to reference. Elijah Newren suggested this ordering improvement, and Taylor has incorporated it while maintaining the function's existing behavior (it still remains a no-op in this patch).
