This thread addressed a build failure on NonStop platforms where the reftable subsystem's `REFTABLE_UNUSED` macro (using GNU's `__attribute__((__unused__))`) failed to compile with the platform's C99 compiler. Carlo Marcelo Arenas Belón proposed a fix using conditional compilation (`#ifdef __GNUC__`), which Junio C Hamano approved for queuing.

A follow-up discussion revealed why core Git's `MAYBE_UNUSED` macro works on NonStop while the reftable version didn't - the core Git compatibility layer includes platform-specific preprocessing that makes `__attribute__()` a no-op before macro definition. Jeff King provided this technical explanation in response to Patrick Steinhardt's question about the inconsistency. Patrick has now confirmed his understanding and agrees the conditional compilation fix is the right approach.

The thread has reached consensus with no remaining open questions, though it has highlighted broader considerations about standardizing attribute handling across Git's codebase. The immediate fix will be included in upcoming releases while the architectural discussion may inform future work.
