The thread began with Randall S. Becker reporting a build failure on the NonStop platform where the reftable subsystem's `REFTABLE_UNUSED` macro (using GNU's `__attribute__((__unused__))`) failed to compile with the platform's C99 compiler. Carlo Marcelo Arenas Belón proposed a straightforward fix making the attribute conditional on `__GNUC__`, which Junio C Hamano approved for queuing.

In follow-up discussion, Brian M. Carlson confirmed the solution's adequacy by noting that older GCC versions (pre-4.5) are no longer relevant since RHEL 7 (GCC 4.8) and Debian 7 (GCC 4.7) are both end-of-life. Hamano observed that similar macros in `git-compat-util.h` and `compat/posix.h` could potentially be simplified using the same approach, though such cleanup would be separate from this focused reftable fix. The exchange serves as both validation of the chosen solution and a pointer to possible future simplification opportunities elsewhere in the codebase.
