The thread addresses a build failure on the NonStop platform in Git 2.50.0-rc0, where the reftable subsystem's `REFTABLE_UNUSED` macro (using GNU's `__attribute__((__unused__))`) failed to compile with the platform's C99 compiler. Carlo Marcelo Arenas Belón proposed a fix making the attribute conditional on `__GNUC__`, which Junio C Hamano has approved for queuing.

Jeff King clarified why core Git's `MAYBE_UNUSED` macro works on NonStop—the platform-specific preprocessing in `git-compat-util.h` makes `__attribute__()` a no-op before the macro definition. This resolved Patrick Steinhardt's initial question about consistency between reftable and core Git's attribute handling. With consensus reached, Junio confirms the fix will be fast-tracked before the next release candidate, addressing Randall S. Becker's original report. While the discussion highlighted potential future work to standardize attribute macros across the codebase, the immediate solution is considered complete.
