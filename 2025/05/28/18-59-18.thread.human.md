The thread reports a build failure on the NonStop platform when compiling Git 2.50.0-rc0's reftable code. Randall S. Becker (rsbecker@nexbridge.com), the NonStop port maintainer, encountered a compiler error in `blocksource.c` where the C99 compiler fails to parse the `REFTABLE_UNUSED` macro usage in the `file_release_data` function declaration. 

This appears to be a platform-specific issue with either the macro expansion or attribute handling in the NonStop compiler. The report is currently just an initial bug notification without analysis of the root cause or proposed fixes. The problem is isolated to the reftable subsystem's blocksource implementation during function parameter attribute processing.
