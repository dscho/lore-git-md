The thread began with Randall S. Becker reporting a build failure on NonStop platforms where the reftable subsystem's `REFTABLE_UNUSED` macro, using GNU's `__attribute__((__unused__))`, failed to compile. Carlo Marcelo Arenas Belón proposed a straightforward fix using conditional compilation (`#ifdef __GNUC__`), which Junio Hamano approved for queuing while noting the main codebase uses a more complex version in `compat/posix.h`.

Brian M. Carlson's follow-up provided important historical context, pointing out that the oldest supported platforms now use GCC 4.5 or later, making the simpler solution sufficient. This confirmation from a long-time contributor with deep knowledge of Git's compatibility requirements effectively closes the discussion. The consensus is clear: the minimal fix is appropriate for this case in the reftable code, and while standardizing UNUSED macros across the codebase remains possible future work, no further action is needed for this specific issue. The fix will proceed as originally proposed.
