This thread addresses a build failure in Git 2.50.0-rc0 on the NonStop platform, where the reftable subsystem's `REFTABLE_UNUSED` macro (using GNU's `__attribute__((__unused__))`) fails to compile with the platform's C99 compiler. Randall S. Becker originally reported the issue, which persists in the release candidate.

Carlo Marcelo Arenas Belón proposed a fix that makes the GNU attribute conditional on `__GNUC__`, which Junio C Hamano has approved for queuing. The discussion revealed that core Git's `MAYBE_UNUSED` macro works on NonStop due to platform-specific preprocessing in `git-compat-util.h`, while the reftable code lacked this compatibility layer. Jeff King and Patrick Steinhardt clarified the technical differences, confirming the proposed fix as the right solution. Kristoffer Haugsbakk noted the queued fix should resolve the issue once incorporated.

In the latest email, Patrick Steinhardt simply points Randall to the existing solution, confirming the thread's consensus. No further action is needed beyond integrating the already-approved patch. The discussion has identified potential future work to standardize attribute macros across Git's codebase, but the immediate issue is resolved.
