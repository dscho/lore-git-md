This thread documents a build failure on the NonStop platform in Git 2.50.0-rc0, where the reftable subsystem's `REFTABLE_UNUSED` macro (using GNU-style `__attribute__` syntax) fails to compile with the platform's C99 compiler. Carlo Marcelo Arenas Belón proposed a fix to make the attribute conditional on `__GNUC__`, which Junio C Hamano has approved for queuing. 

Jeff King and Patrick Steinhardt resolved a deeper question about why core Git's `MAYBE_UNUSED` works on NonStop (due to platform-specific handling in `git-compat-util.h`), confirming the reftable fix is the correct approach. Randall S. Becker's latest email confirms the issue remains in rc0, serving as a reminder that the fix is still needed before the final release. The technical discussion is complete, and the fix is expected to appear in rc1. This is a straightforward platform compatibility issue with a clear resolution path.
