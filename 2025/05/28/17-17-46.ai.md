This is a feature and bugfix series for `imap-send`, now in its 7th iteration, that aims to make the command usable again while adding OAuth2.0 support. The series builds on extensive prior review and addresses all major technical concerns from previous rounds.

Key technical changes in v7 focus on polish and user experience:
- Fixes spelling/grammar in user-facing messages (e.g., "OK" capitalization, proper sentence structure)
- Adds port number display during credential prompts for better debugging
- Shows destination mailbox during message sending for clarity
- Maintains all prior functionality including OAuth2.0 (curl/OpenSSL), PLAIN auth, and CRAM-MD5 fixes

The series now handles all major authentication methods (PLAIN, CRAM-MD5, OAUTHBEARER, XOAUTH2) with proper memory management and fallback paths. Configuration parsing is robust, supporting both runtime (`--folder`, `--curl`) and persistent (`imap.usecurl`) settings. Documentation covers all authentication options and precedence rules.
