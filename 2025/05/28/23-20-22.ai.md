Performance optimization patch in Taylor Blau's MIDX/cruft pack series (v4 5/9). This patch improves delta compression for loose objects when using `--unpacked` with `--stdin-packs` in `git pack-objects`.

The change modifies how loose objects are handled during repacking by including them in the name-hash traversal when they are commits. Previously, loose objects were added to the pack without being considered for delta base selection, which could result in suboptimal delta chains. The patch passes the `rev_info` struct to the loose object handling code, allowing commits to be added as traversal tips. This doesn't affect correctness but can produce more efficient packs.

The implementation involves:
- Modifying `add_unreachable_loose_objects()` to accept a `rev_info` parameter
- Updating `add_loose_object()` to add commit OIDs to the revision walk when a `rev_info` is provided
- Adjusting all callers to pass either NULL or the appropriate `rev_info`
- Maintaining the existing behavior for non-commit objects and when no `rev_info` is provided

This change builds on the refactoring in patch 3/9 where the `rev_info` handling was reorganized. Junio Hamano has already reviewed this patch positively, calling the approach "clever" and noting the surprisingly small code change required. The patch is part of a well-tested series that has been validated in production at GitHub, with all technical components now implemented and reviewed.
