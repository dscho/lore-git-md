This is a feature and bugfix series for `imap-send`, now in its sixth version, addressing both technical debt and adding new authentication capabilities. The series builds on extensive prior review, with v6 focusing on final documentation fixes for the new `--folder` option while maintaining all the substantive improvements from previous versions.

The series combines several important changes: (1) fixing a critical configuration parsing bug where `cfg->folder` was incorrectly NULLed out, (2) adding OAuth2.0 support via both curl's native API and OpenSSL fallback paths, (3) implementing RFC 4616-compliant PLAIN authentication for OpenSSL users, (4) comprehensively fixing CRAM-MD5 memory leaks across all error paths, (5) introducing a `--folder` CLI option to override the configured IMAP folder, and (6) adding `imap.preferredbackend` and `imap.usecurl` configurations for persistent backend selection between curl and OpenSSL.

Key technical details carried forward from v5 include proper handling of all IMAP settings in configuration parsing, with special attention to memory management around the folder field. The OAuth2.0 implementation maintains RFC 5801/7628 compliance through both curl's native `CURLOPT_XOAUTH2_BEARER` and OpenSSL fallback paths. The new PLAIN` authentication method completes feature parity between backends. The CRAM-MD5 fixes now cover all error paths including socket write failures. The `--folder` option follows established CLI patterns in `imap-send.c` while the new configuration options provide persistent backend preferences to complement existing CLI flags.

The v6 changes are minimal, focusing on documentation fixes for the `--folder` option's man page formatting and argument syntax (changing `--folder <folder>` to `--folder=<folder>` in examples). The underlying implementation remains robust, with proper memory management when overriding the folder setting. This version appears ready for merging, having addressed all substantive technical feedback from reviewers across previous iterations while maintaining the series' core improvements to IMAP functionality and usability.
