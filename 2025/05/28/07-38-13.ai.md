This is a feature patch in the v6 series for `imap-send` improvements, adding a command-line option to override the default IMAP folder configuration. The patch introduces a new `--folder` (or `-f`) option that takes precedence over the `imap.folder` config setting, allowing users to specify the destination folder at runtime without modifying their configuration.

The implementation follows the established pattern for CLI options in Git, with proper memory management (freeing the old folder string before assignment) and documentation updates. The man pages now clearly state the precedence order (CLI option over config) and provide examples of valid folder specifications. The change is straightforward, adding the option parsing logic to `imap-send.c` while maintaining backward compatibility.

This patch completes the user-facing convenience features in the series, complementing the earlier technical fixes for authentication methods and configuration handling. The documentation improvements in v6 specifically clarify the argument syntax (`--folder=<folder>`) after earlier feedback. As with the rest of the series, this change maintains all prior fixes (configuration parser correctness, memory management in authentication methods) while adding the new functionality.
