This is a test infrastructure patch that addresses path normalization issues in Git's test suite, specifically around symlink handling. It's a revised version of an earlier patch that now takes a more comprehensive approach based on Junio Hamano's suggestion.

The patch modifies `t/test-lib.sh` to ensure consistent path handling by normalizing both `$TRASH_DIRECTORY` and `$HOME` to match the working directory's canonical path after `cd -P` resolution. This fixes test failures in t7900's maintenance tests where `strbuf_realpath()` would resolve paths differently than test expectations when run from directories containing symlinks.

Key technical details:
- Updates `TRASH_DIRECTORY` and `HOME` to match the normalized working directory path
- Replaces the previous v1 approach that only modified t7900's specific `pwd` call
- Maintains the ability to test path resolution while preventing spurious failures
- Affects all tests that compare paths, not just the macOS maintenance tests

The change reflects the ongoing discussion about whether path normalization belongs in test infrastructure (as Junio advocated) or individual tests (as initially proposed). This implementation follows Junio's infrastructure-focused approach while still allowing for dedicated path resolution tests elsewhere.
