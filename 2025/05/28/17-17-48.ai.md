Feature patch adding OAuth2.0 authentication support for `imap-send`. This is part of a larger v7 series that comprehensively improves IMAP functionality, with this patch specifically introducing OAUTHBEARER (RFC 5801/7628) and XOAUTH2 (Google's proprietary mechanism) authentication methods.

The implementation provides both OpenSSL and curl backend support, with new helper functions `oauthbearer_base64()` and `xoauth2_base64()` handling the protocol-specific encoding. The patch adds configuration guidance for major providers (Gmail and Outlook) and documents the new authentication methods in both config and man pages. Key technical additions include new capability flags `AUTH_OAUTHBEARER` and `AUTH_XOAUTH2`, proper credential handling through curl's `CURLOPT_XOAUTH2_BEARER` when available, and fallback paths for OpenSSL users.

The documentation updates are particularly thorough, covering provider-specific requirements (Gmail's app passwords vs OAuth tokens, Outlook's XOAUTH2-only support) and noting credential helper compatibility. The curl implementation intelligently handles both OAuth variants through a single bearer token interface while maintaining backward compatibility with existing auth methods. This represents a significant step in modernizing Git's email submission capabilities to match contemporary provider requirements.
