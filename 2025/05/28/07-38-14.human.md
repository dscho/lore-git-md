This is the final patch in a feature series adding configuration options to `imap-send`. It introduces a new `imap.usecurl` config setting that allows users to persistently choose between libcurl and OpenSSL backends for IMAP operations, complementing the existing `--curl`/`--no-curl` command-line options.

The patch adds documentation for the new config option in both the imap.adoc config reference and the git-imap-send man page, clarifying that the setting respects the same build-time constraints as the CLI flags (`USE_CURL_FOR_IMAP_SEND` and `NO_OPENSSL`). The implementation is straightforward, adding a single conditional to the config parser in imap-send.c that sets the global `use_curl` flag.

This completes the series' goal of providing comprehensive backend selection options, now available both at runtime via flags and persistently via config. The change maintains consistency with the existing behavior where command-line arguments override config settings. As the final patch in a well-reviewed series that has addressed all technical concerns through multiple iterations, this appears ready for inclusion.
