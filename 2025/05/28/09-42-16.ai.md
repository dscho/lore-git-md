Feature patch adding OAuth2.0 authentication support to git-imap-send. This appears to be a new patch series (v5) that has evolved from an earlier documentation-focused thread, now addressing IMAP authentication mechanisms directly.

The patch introduces OAuth2.0 support for both OAUTHBEARER (RFC-standard) and XOAUTH2 (Google-proprietary) authentication methods. Key technical changes include:
- New authmethod config options (OAUTHBEARER/XOAUTH2) in imap.adoc
- Implementation of oauthbearer_base64() and xoauth2_base64() helper functions following RFC5801/RFC7628 specs
- Updated IMAP capability handling to advertise new auth methods
- Curl integration using CURLOPT_XOAUTH2_BEARER
- Documentation updates showing Gmail/Outlook OAuth2.0 configuration examples
- Special handling for Outlook's XOAUTH2-only requirement

The changes affect multiple files:
- Documentation/config/imap.adoc (new auth methods)
- Documentation/git-imap-send.adoc (configuration examples)
- imap-send.c (core implementation)

Notable technical details:
- Maintains backward compatibility with existing CRAM-MD5 auth
- Handles both OpenSSL and non-OpenSSL builds
- References credential helpers from git-send-email for token management
- Includes comprehensive RFC and Google documentation links

The patch appears well-researched with proper standards compliance and clear documentation. It addresses modern authentication requirements while maintaining backward compatibility. The series also includes related fixes for memory leaks and OpenSSL PLAIN auth support in subsequent patches.
