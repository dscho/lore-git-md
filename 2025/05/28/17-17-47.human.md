Bugfix for a critical regression in `imap-send` that made the command unusable since Git 2.46.0. This is the first patch in a larger v7 series that provides comprehensive IMAP functionality improvements.

The patch fixes a configuration parser bug introduced in commit 6d1f198f34 where `cfg->folder` was incorrectly NULLed out when other IMAP settings (`imap.user`, `imap.pass`, `imap.tunnel`, `imap.authmethod`) were defined. The fix properly clears the correct field-specific variables instead of always clearing `cfg->folder`. This regression had gone unnoticed likely because most users prefer `git-send-email`.

The change is straightforward - four instances where `FREE_AND_NULL(cfg->folder)` was incorrectly used are replaced with the proper field-specific clearing operations. This restores basic functionality to `imap-send` by ensuring the folder setting isn't accidentally cleared when other configuration values are set.

This was identified as a critical issue in the larger IMAP series and has already been reviewed by multiple contributors including Jeff King and Junio Hamano. The fix is part of a well-tested series that has gone through seven iterations with thorough review.
