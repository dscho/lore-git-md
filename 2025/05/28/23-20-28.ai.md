This is a refactoring patch in a performance optimization series for MIDX and cruft pack interaction during repacking.

The patch reorders two functions in builtin/pack-objects.c to prepare for future changes where `show_commit_pack_hint()` will call `show_object_pack_hint()`. Currently `show_commit_pack_hint()` is a no-op function that doesn't do anything with commits (since they don't have namehashes), but the upcoming change will make it useful. The reordering minimizes code movement in the subsequent patch.

The change is purely mechanical - it swaps the positions of the two functions in the file with no behavior changes. The diff shows `show_object_pack_hint()` moving before `show_commit_pack_hint()`, which makes sense since the commit function may soon call the object function. This was suggested by Elijah Newren as part of the ongoing review of this performance optimization series.

This is part of a well-polished v4 series that has already received significant review, with all technical components implemented and tested. The series has been validated in production at GitHub and is nearing final form, with this patch representing one of the final preparatory cleanups before the main optimization logic is added.
