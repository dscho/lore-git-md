This is part of a feature series adding OAuth2.0 authentication support to `git imap-send`. The patch introduces two OAuth2.0 authentication methods - OAUTHBEARER (RFC 5801/7628) and XOAUTH2 (Google's proprietary mechanism) - for use when sending emails via IMAP.

The implementation adds new capability flags (`AUTH_OAUTHBEARER` and `AUTH_XOAUTH2`) and helper functions to handle the base64 encoding required by these protocols. The documentation is updated with specific guidance for using OAuth2.0 with Gmail and Outlook, noting that Outlook only supports XOAUTH2 while Gmail supports both methods. The patch also mentions that credential helpers can be used to manage OAuth2.0 tokens.

This appears to be a well-constructed addition to the IMAP functionality, with thorough documentation updates and clear error handling. The implementation follows the same pattern as existing authentication methods in the codebase. This is patch 2/9 in a series that has already gone through several rounds of review, with this particular authentication support being a key feature of the overall improvements.
