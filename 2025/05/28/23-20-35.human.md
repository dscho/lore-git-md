This is the final patch in Taylor Blau's performance optimization series (v4 9/9) that introduces configurable control over whether cruft packs are included in MIDX during repacking. The patch adds a new `repack.midxMustContainCruft` config option (defaulting to true) that determines whether cruft packs must be included in the MIDX to maintain reachability guarantees for bitmap generation.

The key improvement is that when set to false and when certain conditions are met (like starting from a clean slate after an all-into-one cruft repack), Git can now avoid including cruft packs in the MIDX by using the new `--stdin-packs=follow` mode from patch 8/9. This prevents the MIDX from bloating with rarely-accessed cruft objects while still maintaining reachability guarantees. The patch includes thorough test coverage verifying both the new optimization and backward compatibility with the default behavior.

This completes the series' goal of optimizing pack maintenance through enhanced pack-objects behavior, particularly for cruft pack interaction with MIDX during repacking. The implementation has been validated in production at GitHub and incorporates all review feedback from previous iterations.
