Taylor Blau acknowledges a bug in his earlier patch that could cause negative indexing when accessing `pack_names` array in `open_midx_bitmap_1()`. The issue occurs when `i` is less than `num_packs_in_base` while the code attempts to index into the base pack names. This follows previous discussions about proper bounds checking and API encapsulation in MIDX handling.
