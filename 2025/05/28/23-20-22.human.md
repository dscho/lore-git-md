Performance optimization in the pack-objects series. This patch improves delta compression for loose objects when using `--unpacked` with `--stdin-packs` by including them in the name-hash traversal. 

The change fixes an oversight where loose objects weren't being considered for delta compression opportunities, which could lead to slightly larger packs. The patch passes the `rev_info` struct to the loose object handling code, allowing commits to be included in the reachability analysis. This builds on earlier refactoring in the series that moved the `rev_info` declaration to make this possible.

Junio Hamano has already reviewed this patch positively, calling the approach "clever" and noting the surprisingly small code change required. The optimization maintains correctness while potentially producing more efficient packs, particularly in repository maintenance scenarios where cruft packs and MIDX files are involved.

This is part of a well-polished 9-part series that has been validated in production at GitHub, with all technical issues addressed in previous iterations. The patch stands ready for inclusion with the rest of the series.
