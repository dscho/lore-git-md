Feature patch completing the `imap-send` series with user experience polish. This final patch in the v7 series adds mailbox visibility by displaying the destination folder name in the progress output during message sending. The change affects both the OpenSSL and curl backend implementations in `imap-send.c`, modifying the progress messages to show the folder name (e.g., "Sending 1 message to Drafts folder...").

The patch follows the series' theme of improving user feedback and consistency, matching earlier changes that standardized message formatting and credential helper output. It touches the same two functions (`append_msgs_to_imap` and `curl_append_msgs_to_imap`) that were modified in previous authentication-related patches, maintaining the established pattern of parallel implementations for both backends. The change is minimal (4 insertions, 2 deletions) and focused solely on the progress reporting output.

This completes the user-facing improvements in the series, providing visibility into where messages are being stored - particularly useful when the folder is overridden via the new `--folder` CLI option introduced earlier in the series. The patch maintains the existing percentage-based progress display while adding the contextual folder information.
