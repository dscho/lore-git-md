This is a feature patch adding PLAIN authentication support to `imap-send` when using OpenSSL, part of a larger series improving IMAP authentication options. The patch implements RFC 4616-compliant PLAIN authentication for OpenSSL users, matching functionality already available when using curl. The implementation includes proper base64 encoding of credentials and integrates with the existing IMAP capability detection system.

The change means OpenSSL users can now use PLAIN authentication (commonly used for app passwords) alongside the existing CRAM-MD5, OAUTHBEARER and XOAUTH2 methods. The documentation is updated to reflect this new option in the supported methods list. The implementation follows the same pattern as other authentication methods in the codebase, with proper memory management and error handling.

This is the third patch in a v6 series that has seen extensive review, with previous versions addressing configuration parsing bugs, memory leaks, and adding OAuth2.0 support. The series appears mature and well-tested, with this particular patch completing authentication method parity between curl and OpenSSL backends.
