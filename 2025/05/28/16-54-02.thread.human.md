Git v2.50.0-rc0 marks the start of the 2.50 development cycle with 541 non-merge commits from 73 contributors, including 25 new faces. The release introduces several user-facing improvements like a new `--combine-cruft-below-size` repack option, TCP keepalive for HTTP transports, and a dedicated `git reflog drop` command. Under the hood, significant work continues on reducing `the_repository` global variable usage and overhauling the reftable API.

The release candidate includes performance optimizations for refname checks and completes the deprecation of the merge-recursive backend. Build system updates now better support Meson alongside the traditional Makefile setup. Numerous fixes address edge cases in ref handling, merge behavior, and cruft pack maintenance, showing broad stabilization efforts across the codebase. With contributions touching nearly every major subsystem, this appears to be one of Git's more substantial development cycles in recent memory.
