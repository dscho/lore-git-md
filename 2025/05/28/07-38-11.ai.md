This is a feature patch completing authentication method parity between curl and OpenSSL backends in `imap-send`. It adds RFC 4616-compliant PLAIN authentication support for the OpenSSL backend, matching the existing curl implementation.

The patch introduces a new `plain_base64()` helper function that properly formats credentials according to the RFC 4616 specification (combining username and password with null bytes before base64 encoding). It adds `AUTH_PLAIN` to the IMAP capability list and implements the `auth_plain()` method that handles the authentication flow. The documentation is updated to include PLAIN in the list of supported methods for OpenSSL users.

Key technical details include:
- New `AUTH_PLAIN` capability flag added to IMAP protocol handling
- `plain_base64()` helper implements RFC 4616 formatting with proper memory management
- `auth_plain()` function handles the authentication flow including error cases
- Documentation updated to show PLAIN as available for both curl and OpenSSL backends
- Maintains consistency with the series' overall goal of authentication method parity

This completes one of the remaining items in the larger series by adding support for app password authentication via PLAIN when using OpenSSL. The implementation follows the same pattern as other authentication methods in the codebase, with proper error handling and memory management. The patch fits into the v6 series' broader theme of providing consistent authentication options across backends while maintaining security and RFC compliance.
