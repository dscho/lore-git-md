This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking. It's part 3 of 9 in the v4 series.

The change extracts the inline handling of `--stdin-packs` from `cmd_pack_objects()` into a new `read_stdin_packs()` function. This is a straightforward code organization improvement that makes the main function cleaner and prepares for future expansion of the stdin-packs handling logic. The patch maintains all existing behavior while making the code more maintainable.

Junio Hamano has already reviewed and approved this change with a "Makes sense" comment. The refactoring is mechanical and low-risk, serving as groundwork for later patches in the series that will add more sophisticated pack-objects behavior. This is typical of Taylor's careful, incremental approach in this series - each change builds logically toward the final performance optimization goal.
