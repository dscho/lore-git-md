This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking (v4, 3/9). The patch factors out the `--stdin-packs` handling logic from `cmd_pack_objects()` into a new `read_stdin_packs()` function.

The change is purely structural - it moves the existing inline handling of `--stdin-packs` into a dedicated function while maintaining identical behavior. The motivation is to prepare for future expansion of this logic in subsequent patches. The original implementation dates back to 2021 when the `--stdin-packs` option was introduced.

Key technical details:
- Creates new `read_stdin_packs()` function in builtin/pack-objects.c
- Moves three operations: setting `ignore_packed_keep_in_core`, calling `read_packs_list_from_stdin()`, and conditionally calling `add_unreachable_loose_objects()`
- Takes `rev_list_unpacked` as parameter to maintain existing conditional behavior
- Leaves all other pack-objects modes (cruft, internal rev-list) unchanged

This patch has already been reviewed and approved by Junio Hamano with a "Makes sense" comment. It's a clean preparatory change that improves code organization ahead of more substantive modifications to the pack-objects behavior in later patches of the series. The refactoring follows good practice of keeping functions focused and maintainable while not altering any functionality.
