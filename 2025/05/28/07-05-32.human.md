Documentation patch consolidating email credential helper references. This is the final version (v5) of a series that reorganizes Git's email configuration documentation, now exclusively placing all email-related credential helper references in git-send-email.adoc.

The patch adds two specific items: a reference to the git-credential-yahoo helper for Yahoo accounts, and a link to Google's sendgmail tool as an alternative method for Gmail users. The changes maintain the established formatting style from previous iterations, with consistent bullet point structure for listing the three available credential helpers (Gmail, Outlook, and now Yahoo).

This completes the documentation consolidation effort that began with adding Yahoo support and has gone through several rounds of refinement based on maintainer feedback. The patch follows the approved direction of keeping all email-specific credential documentation in git-send-email.adoc while removing redundant references from gitcredentials.adoc. The changes are cleanly presented with proper formatting and consistent with the surrounding documentation style.
