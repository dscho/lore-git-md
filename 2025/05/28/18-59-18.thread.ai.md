Thread identity: Build failure report and fix for Git 2.50.0-rc0 on NonStop platform involving reftable subsystem's `REFTABLE_UNUSED` macro.

Core problem: Compilation error in `blocksource.c` where NonStop's C99 compiler fails to parse GNU-specific `__attribute__((__unused__))` in `REFTABLE_UNUSED` macro, used for marking unused function parameters in reftable code.

Current status: Carlo Marcelo Arenas Belón's fix making the GNU attribute conditional has been acknowledged by Junio C Hamano, who indicates it will be queued. Brian M. Carlson's follow-up confirms the simpler solution is sufficient given modern GCC version requirements (RHEL 7/GCC 4.8 and Debian 7/GCC 4.7 being EOL), settling any remaining questions. Hamano notes similar macros in `git-compat-util.h` and `compat/posix.h` could potentially be simplified using this approach, though that would be separate work.

Key technical details:
- Failing component: `REFTABLE_UNUSED` macro in `reftable/basics.h`
- Problematic syntax: GNU `__attribute__((__unused__))` not supported on NonStop
- Solution: Conditional compilation with `#ifdef __GNUC__` (empty definition otherwise)
- Introduced in: commit f93b2a0424 (reftable internal UNUSED annotations)
- Historical context: Older GCC versions (pre-4.5) no longer relevant due to EOL distros
- Alternative implementations exist in `compat/posix.h` and `git-compat-util.h` with more complex version checks
- Minimal change focused only on reported issue, with potential for broader cleanup noted

Open questions: None remaining - discussion confirms the simpler solution is adequate and no further standardization needed for this case. Potential future work identified to simplify similar macros elsewhere in codebase.
