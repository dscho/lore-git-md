Thread identity: Build failure report and fix for Git 2.50.0-rc0 on NonStop platform involving reftable subsystem's `REFTABLE_UNUSED` macro.

Core problem: Compilation error in `blocksource.c` where NonStop's C99 compiler fails to parse GNU-specific `__attribute__((__unused__))` in `REFTABLE_UNUSED` macro. The macro is used for marking unused function parameters in reftable code.

Current status: Carlo Marcelo Arenas Belón has proposed a fix making the GNU attribute conditional, falling back to empty definition on non-GNU compilers. The 4-line change follows Git's historical approach to similar compatibility issues and directly addresses Randall S. Becker's original report.

Key technical details:
- Failing component: `REFTABLE_UNUSED` macro in `reftable/basics.h`
- Problematic syntax: GNU `__attribute__((__unused__))` not supported on NonStop
- Solution: Conditional compilation with `#ifdef __GNUC__`
- Introduced in: commit f93b2a0424 (reftable internal UNUSED annotations)
- Minimal change focused only on reported issue

Open questions:
