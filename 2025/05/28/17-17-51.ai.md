Feature patch adding a command-line folder override option to `git imap-send`, part of the comprehensive IMAP functionality series (v7/9). This introduces a new `--folder` (`-f`) option that takes precedence over the `imap.folder` config setting, allowing runtime specification of the destination mailbox. The implementation properly handles memory management by freeing the old folder string before assigning the new one via `xstrdup()`.

Key technical details:
- Adds `opt_folder` static variable and `--folder`/`-f` option to `imap_send_options`
- Updates usage string and documentation in both `imap.adoc` and `git-imap-send.adoc`
- Implements config override logic in `cmd_main()` with proper memory cleanup
- Documents precedence rules (CLI over config) and provides example folder formats
- Maintains consistency with existing option patterns (`--curl`/`--no-curl`)

This is one of the user-facing improvements in the v7 series, complementing the earlier technical fixes for authentication and configuration handling. The patch follows the established pattern for CLI/config precedence seen elsewhere in Git, with clear documentation of the override behavior. The memory management correctly handles the string replacement case.
