The tests verify signing works correctly across all subtree operations (add, merge, split, pull) using both `-S` and `--gpg-sign` flags, including edge cases like squashing and specific key IDs.

The test suite adds 7 new test cases that:
1. Verify basic signing with `-S` flag on add
2. Test equivalent `--gpg-sign` long option
3. Validate specific key ID signing using `-S<keyid>`
4. Check merge operation signing
5. Test split with `--rejoin` signing
6. Verify signing works with `--squash` option
7. Confirm pull operation signing

Each test follows the same pattern: creates test repos, performs a signed subtree operation, then verifies the resulting commit is properly signed using `git verify-commit`. The tests also check commit message formatting remains correct when signing is enabled.
