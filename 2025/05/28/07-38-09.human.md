This is a bugfix patch for `imap-send`, addressing a critical regression introduced in Git 2.46.0. The patch corrects a configuration parsing issue where `cfg->folder` was incorrectly being NULLed out when processing other IMAP settings like `imap.user` or `imap.pass`. This bug effectively broke `git-imap-send` entirely since the 2.46.0 release.

The fix is straightforward - it changes the `FREE_AND_NULL` calls to target the correct struct fields (`cfg->user`, `cfg->pass`, etc.) rather than incorrectly clearing `cfg->folder` in all cases. The regression appears to have gone unnoticed for some time, likely because most users prefer `git-send-email` for mailing patches.

This is the first patch in a 6-part series that adds OAuth2.0 support and other improvements to `imap-send`. While this particular fix is small (just 4 lines changed), it's critical for restoring basic functionality. The thread context shows this series has undergone thorough review, with this specific bug having been identified by Jeff King and reviewed by Junio Hamano.
