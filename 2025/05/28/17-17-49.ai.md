This is a feature patch adding PLAIN authentication support to `imap-send` when using OpenSSL, part of a larger series improving IMAP functionality. The patch implements RFC 4616-compliant PLAIN authentication for OpenSSL users, complementing the existing curl-based implementation.

The changes introduce a new `plain_base64()` helper function that properly formats and encodes credentials according to the RFC 4616 specification (NUL-separated user/pass strings). It adds an `AUTH_PLAIN` capability flag and updates the authentication method selection logic to handle PLAIN alongside other methods. The documentation is adjusted to list PLAIN as a supported method when using OpenSSL.

Key technical details include:
- New `plain_base64()` helper implements RFC 4616 encoding with proper memory management
- `AUTH_PLAIN` capability flag added to capability detection
- Authentication flow modified to handle PLAIN method with OpenSSL
- Documentation updated to reflect PLAIN support availability
- Error handling follows established patterns from other auth methods
- Maintains backward compatibility with existing configurations

This completes the authentication method parity between curl and OpenSSL backends in the IMAP series, addressing a gap where PLAIN was previously only available via curl. The implementation is consistent with the series' approach of comprehensive auth method support and proper memory management.
