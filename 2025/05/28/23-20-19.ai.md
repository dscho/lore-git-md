This is a refactoring patch in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking. The patch moves the initialization and execution of the reachability traversal code from `read_packs_list_from_stdin()` to its caller `read_stdin_packs()`, preparing for future changes where this traversal will be reused for the `--unpacked` case.

The key changes are:
1. The `rev_info` struct initialization and traversal setup is moved out of `read_packs_list_from_stdin()` and into `read_stdin_packs()`
2. `read_packs_list_from_stdin()` now takes a `rev_info*` parameter instead of declaring its own
3. The traversal execution (`prepare_revision_walk()` and `traverse_commit_list()`) is moved to `read_stdin_packs()`

This is a mechanical change that doesn't alter functionality but enables sharing the reachability traversal code between different cases in future patches. The patch maintains all existing behavior while making the code more flexible for the upcoming changes to handle reachable objects in unknown packs when using `--unpacked`.

The change is part of a well-structured series that has already received positive feedback, with this particular refactoring being a straightforward preparation for subsequent optimizations. The patch follows the series' pattern of careful, incremental changes to the pack-objects machinery.
