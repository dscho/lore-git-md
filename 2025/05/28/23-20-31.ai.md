This is patch 8/9 in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking. The patch introduces a new `--stdin-packs=follow` mode for `git pack-objects` that changes how objects from unspecified packs are handled during pack generation.

The key technical change is that when `follow` mode is active, objects from packs not explicitly listed on stdin will be included if they are (1) reachable from the included packs and (2) not in any excluded packs. This solves a reachability problem where objects in cruft packs that later become reachable need to be properly included in the MIDX to maintain bitmap generation capabilities. The implementation adds a new `stdin_packs_mode` enum and modifies the pack hint callbacks to handle the new behavior.

The patch includes thorough documentation updates explaining the new mode and its purpose, particularly for handling cruft pack resurrection scenarios. It also adds extensive test coverage in t5331 that verifies the behavior with various pack combinations, including cases with unknown packs and loose objects. The tests demonstrate how `follow` mode differs from the standard behavior by including additional reachable objects from unspecified packs.
