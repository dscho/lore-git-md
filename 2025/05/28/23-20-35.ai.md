This is the final patch (9/9) in Taylor Blau's performance optimization series for MIDX and cruft pack interaction during repacking. It introduces a configurable way to exclude cruft packs from the MIDX when possible, while maintaining reachability guarantees needed for bitmap generation.

The patch adds a new `repack.midxMustContainCruft` config option (default true) that controls whether cruft packs are always included in the MIDX. When set to false, Git will only include cruft packs when necessary to maintain reachability closure for bitmaps. The implementation builds on the `--stdin-packs=follow` mode introduced in patch 8/9, which ensures geometric repacks properly track reachability of objects that were previously in cruft packs.

Key technical details:
- New `midx_has_unknown_packs()` function checks if any existing packs aren't properly represented in the new MIDX
- Modified `midx_included_packs()` now conditionally includes cruft packs based on config and reachability needs
- Extensive test coverage in t7704-repack-cruft.sh verifies the new behavior
- Maintains backward compatibility while providing optimization path

The change addresses performance issues where MIDX would unnecessarily track many unreachable objects from cruft packs, slowing down object lookups. The series has been validated in production at GitHub and received positive feedback from reviewers. This final patch completes the optimization by making the behavior configurable while maintaining all necessary reachability guarantees.
