This is a correctness patch in the ongoing MIDX (multi-pack-index) refactoring series. Taylor Blau adds assertions to guard against potential issues with incremental MIDX chains in the `want_included_pack()` function and related helpers.

The patch clarifies that while the current implementation is technically safe (because `midx_repack()` explicitly rejects incremental MIDXs), the code structure is fragile and could break if that assumption changes. The added assertions make this safety invariant explicit, helping future maintainers understand the constraints.

This is part of a broader effort to improve MIDX handling that has included performance optimizations, bugfixes, and API improvements. The patch builds on previous work by Patrick Steinhardt and Jeff King, continuing the thread's focus on making MIDX code more robust and maintainable. The changes are straightforward - adding assertions to three functions - but they help document important invariants in the codebase.
