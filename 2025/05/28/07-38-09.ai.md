Bugfix patch for `imap-send` configuration handling, part of a larger v6 series addressing IMAP authentication and configuration issues. This specific patch fixes a critical regression introduced in Git 2.46.0 (commit 6d1f198f34) where the `cfg->folder` field was incorrectly NULLed out when processing other IMAP configuration settings (`imap.user`, `imap.pass`, `imap.tunnel`, `imap.authmethod`). The bug effectively broke `git-imap-send` functionality entirely since the folder field is essential for IMAP operations.

The fix changes four instances where `FREE_AND_NULL(cfg->folder)` was incorrectly used, replacing them with the proper field-specific cleanup (`cfg->user`, `cfg->pass`, `cfg->tunnel`, `cfg->auth_method`). This restores proper configuration parsing behavior while maintaining the memory management improvements from the original commit. The patch is minimal (4 line changes) and focused, directly addressing the regression without introducing new functionality.

This was identified as a critical usability issue that went unnoticed likely due to `git-send-email` being more commonly used. The fix is part of a comprehensive series that has undergone multiple rounds of review (now at v6), with this particular configuration bug having been diagnosed by Jeff King and reviewed by Junio Hamano. The series as a whole adds OAuth2.0 support, new authentication methods, and configuration options while fixing various memory management issues.
