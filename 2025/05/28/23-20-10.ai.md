This is a refactoring patch that's part of a larger performance optimization series for MIDX and cruft pack interaction during repacking. The patch standardizes how `pack-objects` handles incompatible command-line options by replacing custom error checks with the standard `die_for_incompatible_opt2()` function.

The change affects several option pairs in `builtin/pack-objects.c` that were previously checked with ad-hoc error messages. The refactoring ensures consistent error message formatting when users specify mutually exclusive options like `--stdin-packs` with `--filter`, or `--keep-unreachable` with `--unpack-unreachable`. One test in t5331-pack-objects-stdin.sh needed updating to match the new standardized error message format.

This is the first patch in a 9-part series that ultimately introduces configurable optimization of pack maintenance through enhanced pack-objects behavior. While this particular change is purely mechanical, it sets up cleaner infrastructure for the more substantive performance improvements that follow in later patches. The series has already received positive feedback on its technical approach and has been validated in GitHub's production environment.
