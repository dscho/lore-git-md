This is a feature patch adding PLAIN authentication support to `imap-send` when using OpenSSL, part of a larger series improving IMAP functionality. 

The patch enables RFC 4616-compliant PLAIN authentication for OpenSSL users, matching the existing curl implementation. It adds a new `AUTH_PLAIN` capability flag and implements the authentication flow with a new `plain_base64()` helper function that properly encodes credentials according to the spec. The documentation is updated to list PLAIN alongside other supported methods.

The change is well-motivated - many email providers still use PLAIN authentication via app passwords, and the OpenSSL backend previously only supported LOGIN rather than AUTH PLAIN. The implementation follows the same pattern as other auth methods in the codebase, with proper memory management and error handling. 

This is the third patch in a 9-part series that has seen extensive review, with this particular addition completing authentication method parity between curl and OpenSSL backends. The patch appears ready for inclusion, building on the solid foundation established by earlier iterations of the series.
