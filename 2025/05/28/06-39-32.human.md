Bugfix for `git send-email` threading behavior when editing messages. This patch addresses an issue where editing and resending the first message in a thread with `--in-reply-to` and shallow threading could break the thread structure. The problem occurs because the message number counter increments even for edited messages, causing subsequent messages to incorrectly reference the original `--in-reply-to` target rather than the edited message.

The fix decrements both the message number and message ID serial counter when a message is edited or skipped, ensuring proper threading behavior.
