Refactoring patch in the worktree-prune maintenance task series. This is patch 3/7 in v3 of Patrick Steinhardt's series to complete the decomposition of `git gc` functionality into standalone maintenance tasks.

The patch extracts worktree pruning logic from `cmd_gc()` into a new `maintenance_task_worktree_prune()` function, following the pattern established for other maintenance tasks. The implementation remains functionally identical - it still spawns a child process to run `git worktree prune --expire` with the configured expiration time - but now lives in a dedicated function that can be called independently.

This is a straightforward preparatory change that enables the subsequent introduction of a new "worktree-prune" maintenance task in patch 4/7. The diff shows clean extraction of the existing code with no behavior changes, maintaining the same error handling where failures result in `die()`. The change aligns with the series' goal of modularizing `git gc` operations into discrete, configurable maintenance tasks.
