Performance test patch with discussion about delta compression tradeoffs.

This is part 4 of a 13-part series introducing path-based delta compression (--path-walk). The patch adds performance tests comparing the new path-walk approach against existing name-hash methods, showing significant improvements in some cases (like thin packs going from 1.2MB to 18.4KB).

Taylor Blau's review comments focus on clarifying the motivation - he notes that while the series frames hash collisions as problematic, some collisions are actually desirable when paths are related (like after renames). The performance data shows path-walk's strengths (especially for thin packs) while also revealing scenarios where gains are more modest (shallow packs see only slight improvements). 

The test implementation itself is straightforward and well-received. Taylor suggests it would be nice to have more native perf test support for multi-case comparisons like this, but approves the current approach. This continues the positive review trajectory for the series, which Junio has already approved for the 'next' branch pending Taylor's final review.
