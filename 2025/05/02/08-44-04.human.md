This is the final patch in Patrick Steinhardt's series to complete the decomposition of `git gc` functionality into standalone maintenance tasks. The patch introduces a new "rerere-gc" task for garbage collecting stale rerere cache entries, matching the behavior `git gc` previously provided.

The implementation follows the pattern established in earlier patches, with a new `maintenance_task_rerere_gc()` function and associated auto-execution condition check. The task uses a simple directory entry count in the "rr-cache" directory to determine when to run, configurable via `maintenance.rerere-gc.auto` (defaulting to 1 entry). This simplified approach addresses performance concerns raised in the previous version's review.

The patch includes thorough documentation updates and test coverage verifying both manual execution and auto-triggering behavior with various config settings. With this addition, the series now provides complete coverage of all `git gc` functionality through granular maintenance tasks, marking a significant milestone in the multi-year effort to modernize Git's maintenance infrastructure.
