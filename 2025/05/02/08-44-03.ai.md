This is a refactoring patch that's part of Patrick Steinhardt's v3 series to complete the `git gc` decomposition into standalone maintenance tasks. The patch extracts rerere garbage collection functionality from `cmd_gc()` into a new `maintenance_task_rerere_gc()` function, following the same pattern used earlier in the series for worktree pruning.

The change moves the rerere GC implementation (which spawns `git rerere gc` as a child process) into its own function while maintaining identical behavior. This prepares for the next patch which will expose this as a configurable maintenance task. The implementation preserves the existing error handling and reporting through the `FAILED_RUN` mechanism.

Key technical details include:
- New `maintenance_task_rerere_gc()` function with same signature as other maintenance tasks
- Maintained child process spawning approach for compatibility
- Preserved error reporting through `die(FAILED_RUN, "rerere")`
- Cleaned up `cmd_gc()` by removing the now-unused `rerere_cmd` variable
- Follows the established pattern from earlier patches in the series

This is a straightforward refactoring that completes the technical groundwork needed before introducing the new maintenance task in the next patch. The change appears uncontroversial as it doesn't modify behavior and follows the same approach used successfully elsewhere in the series.
