Refactoring of reftable test helpers in final patch of conversion series.

This is Patrick Steinhardt's review feedback on patch 10/10 of the reftable test modernization series, which moves helper functions from unit-test.{c,h} to lib-reftable.{c,h} as the final step in the conversion. The patch completes the three-phase migration approach by relocating the test helpers after all tests have been converted to use the Clar framework versions.

Key technical points in the review:
1. Build system cleanup opportunities:
   - Makefile's `UNIT_TEST_PROGS` now only contains "unit-test" binary, suggesting potential simplification
   - meson.build's `unit_test_programs` loop is now a no-op and could be removed entirely
2. Helper function naming:
   - Functions renamed from `t_reftable_*` to `cl_reftable_*` prefix
   - Patrick questions the initial placement in unit-test.h before final move
3. Migration approach critique:
   - Suggests it would have been cleaner to introduce helpers directly in lib-reftable.{c,h} from the start
   - Current approach creates temporary churn by first adding then removing declarations

The review doesn't block the series but identifies potential improvements to the migration strategy. This feedback aligns with Patrick's earlier comments about test helper organization and completes the thread's discussion of where reftable-specific test infrastructure should live. The core conversion work appears sound, with only minor build system cleanups and historical approach questions remaining.
