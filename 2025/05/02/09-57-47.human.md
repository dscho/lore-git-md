This is a test modernization patch in the ongoing reftable test conversion series. Patrick Steinhardt provides review feedback on patch 3/10, which converts the reftable block test to use the Clar framework.

The review focuses on two main issues: First, the diff incorrectly shows the test file as deleted and recreated rather than renamed (from t-reftable-block.c to u-reftable-block.c), which makes review harder. Patrick suggests using `--find-renames` in future iterations. Second, he points out that two test method names are swapped - one testing ref operations is misnamed as `__index_read_write` while another testing index operations is misnamed as `__ref_read_write`.

Patrick also notes some minor improvements that could be made to assertion style (using `cl_assert(!ret)` rather than `cl_assert(ret == 0)`), though he acknowledges this is a broader issue that will be addressed separately. The patch appears mechanically sound otherwise, continuing the series' work of converting tests while maintaining the same coverage.

This feedback follows Patrick's earlier detailed reviews of other patches in the series, showing his close attention to test naming consistency and proper diff presentation. The issues raised are straightforward to address in a respin.
