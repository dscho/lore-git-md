This is a refactoring patch in Patrick Steinhardt's series to decompose `git gc` functionality into standalone maintenance tasks. The patch moves worktree name collection logic from `builtin/worktree.c` into a reusable function in `worktree.c`, with proper error handling and documentation. The new function returns names via a `strvec` and handles edge cases like missing worktrees directory gracefully. This change simplifies the worktree pruning implementation while maintaining identical behavior.
