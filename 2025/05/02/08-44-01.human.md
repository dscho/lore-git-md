Refactoring patch in the `git gc` decomposition series. This is patch 4/7 in Patrick Steinhardt's v3 series that completes the standalone implementation of maintenance tasks previously handled by `git gc`. 

The patch extracts worktree name retrieval into a new `get_worktree_names()` function in worktree.c, replacing direct directory handling in `builtin/worktree.c`. This is a clean refactoring that centralizes worktree name access while maintaining identical behavior. The new function provides a simpler interface for callers that only need worktree names (not full worktree objects) and properly handles error cases like missing worktrees directory.

The change supports the series' goal of modularizing maintenance operations by providing a reusable component for worktree-related operations. While not changing functionality, it follows the pattern of the series by breaking down monolithic operations into focused, reusable pieces. The implementation looks straightforward with proper error handling and memory management.
