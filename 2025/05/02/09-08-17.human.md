This is a follow-up discussion about the `git whatchanged` deprecation patch. Patrick Steinhardt suggests improving the deprecation warning by having the `you_still_use_that()` helper include information about the recommended replacement command (`git log --raw` in this case). 

The email focuses on two technical aspects: First, it notes the placement of the `i_still_use_this` flag in the `log_config` struct is appropriate despite initial doubts, since configuration parsing happens in `cmd_log_init_finish()`. Second, it proposes enhancing the deprecation infrastructure to include replacement guidance, which would make the transition easier for users.

This is a constructive suggestion that builds on the deprecation infrastructure established in the series, rather than challenging its core approach. The thread continues to develop Git's standardized deprecation pattern, now considering how to make the warnings more actionable for end users.
