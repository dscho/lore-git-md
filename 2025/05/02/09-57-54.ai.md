Test modernization patch review feedback for reftable reader test conversion.

Patrick Steinhardt provides review comments on patch 6/10 in the reftable test conversion series, which moves the reader test to the Clar framework. He identifies two formatting issues in the test file:

1. An unnecessary empty newline in the `test_reftable_reader__seek_once` function
2. Incorrect indentation in assertion blocks in both `__seek_once` and `__reseek` test methods, where continuation lines should use consistent 8-space indentation

The feedback continues the pattern of attention to detail in test formatting that has been seen throughout this series' review. These are minor style issues that don't affect test functionality but should be corrected for consistency with the project's coding standards. The patch otherwise appears to correctly convert the reader test functionality to use the Clar framework while maintaining the same test coverage.

This feedback follows earlier reviews where Patrick identified similar style issues in other converted test files (merged, block, and readwrite tests). The comments suggest the author should do a final pass to ensure consistent indentation and formatting across all converted test files before the series is finalized.
