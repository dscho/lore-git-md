Junio Hamano responds to Leon Michalak's concern about edge case handling in the diff context unification work. This is part of the ongoing effort to standardize how interactive commands inherit diff context settings.

His position is that users who pass invalid values have no grounds to complain when those values are ignored.

The response reinforces the pragmatic approach the thread has taken, where minor edge cases are being accepted to maintain focus on the core unification goal.
