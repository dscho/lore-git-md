This is a build system patch series (part 2 of 3) focusing on configuration and installation path handling across Git's build systems. The series has been validated by multiple contributors and addresses several technical issues in the Meson and Autoconf build configurations.

The v2 iteration incorporates minor but thoughtful improvements from Patrick Steinhardt's review of patch #3, which handles system-wide gitconfig/gitattributes paths in Meson. Ramsay Jones has made the option blocks more readable with blank lines and added comments about default values, though notes some ambiguity remains about prefix handling. The other four patches remain unchanged from v1, having already been tested and confirmed by Eli Schwartz (Solaris regression fix) and others.

The series is technically complete and ready for inclusion, with Ramsay having verified clean merges against master, next, and seen branches (with one expected conflict resolution). The changes demonstrate careful attention to cross-platform build configuration details while maintaining the patches' core functionality. The most notable fix prevents an Autoconf regression that could affect the next release cycle.

This continues the project's broader effort to improve build system hygiene and align behavior between Make and Meson, though the strategic discussion about long-term build system direction (Autoconf maintenance vs Meson adoption) remains ongoing elsewhere in the thread.
