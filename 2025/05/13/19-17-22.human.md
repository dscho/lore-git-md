This is a build system patch fixing path quoting in the Meson configuration. It's the first of five patches in a series improving Git's build system handling, particularly around path configuration and Autoconf compatibility.

The patch changes how the GITWEBDIR path is set in meson.build, switching from `.set()` to `.set_quoted()` to properly handle paths containing spaces. This aligns with how other paths are already handled in the build configuration. The change is straightforward and clearly motivated - it fixes an inconsistency in path quoting that could cause problems with paths containing spaces.

The patch is part of a well-reviewed series that has already seen technical validation from multiple contributors. The change is small and focused, touching only one line in meson.build. Given that this is a build system fix and part of a series addressing pre-release regressions, it appears ready for inclusion with low risk.
