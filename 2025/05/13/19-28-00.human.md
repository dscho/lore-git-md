This is a follow-up discussion on Patrick Steinhardt's refactoring series to eliminate `the_repository` usage in Git's object database subsystem. The thread has already reached consensus on the overall approach, with Junio Hamano confirming the v2 patches will be applied as-is.

Toon Claes provides a detailed review of patch 02/17, which renames `struct object_directory` to `struct odb_alternate` across the codebase. The change aims to make the naming more agnostic of storage implementation details as Git moves toward pluggable object databases. While the technical content is settled, Toon focuses on improving clarity in comments and variable naming to better reflect the new terminology.

Key suggestions include:
- Adjusting comment wording in `submodule--helper.c` to better match the "alternate" terminology
- Considering whether "alternate" or "database" would be clearer in `object-file.h` function documentation
- Rewriting the `struct odb_alternate` docstring to be more precise about its role
- Updating related comments about the alternates list structure in `object-store.h`

The feedback is entirely about documentation clarity - no functional changes are requested, and the technical approach remains approved. This level of polish is typical for a major refactoring at the final review stage before integration.
