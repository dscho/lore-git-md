Thread summary:

Platform compatibility report regarding msgfmt argument ordering in Git's translation build process. Nathan Royce identifies that the POSIXLY_CORRECT environment variable affects how msgfmt processes arguments when building gitk's translations, specifically for Tcl format. The issue manifests during `make all` when building translations, where `msgfmt --statistics --tcl -l bg -d po/ po/bg.po` succeeds but the reverse argument order fails. This is a build system quirk affecting systems with POSIXLY_CORRECT set, though not a core Git code issue. The report demonstrates the failing and working command sequences but doesn't propose a solution, leaving it to maintainers to determine if build process adjustments are needed for robustness against argument ordering variations.
