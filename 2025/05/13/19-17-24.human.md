Build system fix for Meson's system config paths. This is part 3 of a 5-part series improving path handling across Git's build systems, with a focus on preventing Autoconf regressions.

The patch fixes how Meson handles paths to system-wide gitconfig and gitattributes files. Currently, these default to absolute `/etc` paths regardless of the installation prefix, which is only correct when prefix is `/usr`. The change makes them respect the `sysconfdir` setting (which properly handles prefixes like `/usr/local` by using `etc/` relative paths) when no explicit path is provided.

Ramsay Jones implements Patrick Steinhardt's earlier suggestions by:
1. Removing hardcoded defaults from meson_options.txt
2. Using Meson's path-joining operator `/` (with a noted skepticism about its "magic")
3. Adding clear documentation of the default behavior
4. Making the meson.build changes visually distinct for readability

The change is technically sound and has been validated by Junio and Eli Schwartz. It demonstrates careful attention to cross-platform build system details while maintaining flexibility for custom installations. The only remaining open question is about clarifying documentation around prefix=/usr usage.
