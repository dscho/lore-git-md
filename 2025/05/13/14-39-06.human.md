This is a bugfix for the `git stash` command's handling of diff context options in the ongoing interactive patch series.

Phillip Wood points out a validation issue in the stash command's patch mode. Currently, `git stash` checks for changes to stash *before* validating the `-U`/`--unified` and `--inter-hunk-context` options, which means invalid negative values for these options might be silently ignored if there are no changes to stash. The proposed fix would move the option validation earlier in the process to ensure consistent behavior with other interactive commands.

This is a minor but important edge case in the otherwise complete diff context configuration series. The fix ensures `git stash` properly validates its diff context parameters before proceeding with any stash logic, maintaining consistency with how other interactive commands (`add`, `checkout`, etc.) handle these options. The change is narrowly focused on the validation timing in the stash command's control flow.
