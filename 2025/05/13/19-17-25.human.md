This is a build system patch that aligns Meson's GIT_EXEC_PATH handling with the Makefile's behavior, part of a series improving cross-build system consistency. 

The patch fixes how Meson sets the executable path for Git's helper programs (GIT_EXEC_PATH). Currently, Meson defaults to an absolute path, while Make uses a relative path by default. The change makes Meson match Make's approach of defaulting to 'libexec/git-core' while still allowing override via --libexecdir, just like Make's gitexecdir variable.

The implementation carefully preserves two key behaviors: (1) the ability to specify an alternate path (like /some/other/bin) when needed, and (2) proper error checking when runtime_prefix is enabled (which requires relative paths). The changes are well-motivated by comparing against Make's established behavior and include clear examples of both the problem and solution.

This is the fourth of five patches in a v2 series that has already received technical validation from multiple contributors. The changes are focused and appear to be a straightforward improvement to build system consistency without introducing new complexity.
