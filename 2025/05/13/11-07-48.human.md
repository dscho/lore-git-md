This is a refactoring patch in the packed-refs optimization series, specifically addressing buffer allocation. It's the second of three patches that have been through multiple rounds of review (now at v4) with consensus from key reviewers.

The patch extracts the buffer allocation logic from `load_contents()` into a new helper function `allocate_snapshot_buffer()`. This enables the same allocation logic to be reused for fsck verification without duplicating code, while maintaining the existing behavior around mmap thresholds and Windows compatibility. The change is relatively straightforward - 31 lines added, 22 removed - with the core logic preserved but better organized.

Reviewers Jeff King and Patrick Steinhardt suggested this approach, and the implementation has already been approved with only minor style notes (now addressed in v4). The patch is part of a larger effort to optimize packed-refs handling that has reached consensus among all key participants, making this a low-risk change that improves code structure for future maintenance.
