This is a feature patch adding command-line overrides for diff context settings in interactive patch commands, completing a series that previously added config support. Phillip Wood provides review feedback on the implementation, focusing on test improvements and edge cases.

The patch allows `-U`/`--unified` and `--inter-hunk-context` options to override config settings in commands like `add -p`, `checkout -p`, etc. Phillip notes the core implementation looks solid but suggests several test improvements to reduce redundancy while maintaining coverage. He proposes consolidating tests in t3701 (add-interactive) with more focused cases that verify option handling across all affected commands.

Key review points include:
- Need to properly validate negative values in `stash` commands
- Should move option validation earlier in `checkout` to catch cases without pathspecs
- Could reduce test count from 29 to a more maintainable set while keeping equivalent coverage
- Outstanding question about how to handle `-U0` (zero context lines)

The feedback is constructive and technical, focusing on test quality and edge cases rather than fundamental design issues. Phillip's suggested test restructuring would make the test suite more maintainable while preserving the ability to catch regressions. The implementation appears nearly ready pending these test improvements and the resolution of the `-U0` behavior question.
