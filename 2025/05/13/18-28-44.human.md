This is a documentation patch adding Yahoo Mail configuration instructions for `git send-email`. 

Aditya Garg extends the existing documentation to cover Yahoo Mail as an SMTP provider, similar to the existing Gmail and Outlook sections. The patch provides two authentication methods: app-specific passwords (with a link to Yahoo's instructions) and OAuth2.0 (supporting both OAUTHBEARER and XOAUTH2 methods). 

The changes include example configuration blocks showing the necessary settings for Yahoo's SMTP server (smtp.mail.yahoo.com on port 587 with TLS encryption). The patch also adds references to a new credential helper specifically for Yahoo accounts (git-credential-yahoo) in both the send-email documentation and the general gitcredentials documentation.

The patch appears well-structured, following the existing documentation style and format. It provides clear, actionable instructions for users who want to configure Yahoo Mail with Git's email submission workflow. The inclusion of both basic and OAuth authentication methods makes this a thorough addition to the documentation.
