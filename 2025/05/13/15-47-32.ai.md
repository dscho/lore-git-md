This is a bugfix patch in the ongoing series to make interactive patch commands respect diff context configuration. The patch specifically addresses the implementation details of reading and validating `diff.context` and `diff.interHunkContext` config values in the add-patch infrastructure.

The patch modifies `init_add_i_state()` to read these config values and validate that they are non-negative, mirroring the behavior of other diff-related commands.
