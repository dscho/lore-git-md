This is Junio Hamano's monthly "What's cooking in git.git" status update, summarizing the state of various patches and topics in the Git development pipeline as of May 2025. These updates are essential for tracking the progress of features and fixes moving through the Git project's integration branches.

The email lists several topics that have recently graduated to 'master' (the stable branch), including improvements to `send-email` for Outlook compatibility, fixes for delta chain handling in `index-pack`, and various cleanups in the hashmap and object-store APIs. Each graduated topic is marked with its merge status and includes links to the original discussion threads.

New topics under development include enhancements to `git mv` to detect invalid move operations, sparse index integration for `git add -p`, and memory leak fixes in several areas including the reftable backend. There's also a significant cleanup of the contrib/ directory removing obsolete scripts and tools.

Ongoing work includes further object-store API cleanups (part of the `the_repository` removal effort), mmap optimizations for packed-refs handling during fsck, and new maintenance tasks for `git gc`. Some controversial changes are also brewing, like the proposed deprecation of `git whatchanged` in favor of `git log --raw`.

The email provides a comprehensive snapshot of Git's in active work, what's nearly ready for release, and what's still under discussion. For maintainers and active contributors, this serves as both a progress report and a call for review on pending patches. The detailed source links make it easy to dive into any topic of interest.
