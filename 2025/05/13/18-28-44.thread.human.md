This thread has documented a multi-iteration effort to reorganize Git's email configuration documentation, specifically around credential helpers for different email providers (Gmail, Outlook, Yahoo). The discussion began with adding Yahoo Mail-specific instructions but evolved into a broader restructuring of where email-related documentation should live.

Junio Hamano approved the core approach early on, noting that email provider documentation should be consolidated with git-send-email.adoc rather than split across multiple files. The series went through several versions that progressively:
1) Removed redundant SMTP server instructions
2) Consolidated all email credential helper references into git-send-email.adoc
3) Standardized formatting and fixed grammatical issues
4) Added practical references like CPAN module links
5) Finally removed the last vestiges of email helper documentation from gitcredentials.adoc

The final patch (just received) completes this transition by removing the remaining Gmail and Outlook helper references from gitcredentials.adoc, as these are now properly documented alongside the Yahoo helper in git-send-email.adoc. This matches the website documentation updates made in git-scm.com PR #2005. The changes are purely organizational - no functionality was added or removed - and the series is now complete with all feedback addressed.
