This thread documents the evolution of Git's email configuration guidance, specifically around credential helpers for email providers like Yahoo Mail and Gmail. The discussion began with adding Yahoo-specific SMTP settings and credential helper documentation, then progressed through several iterations to reorganize where this information lives.

Junio Hamano initially approved the technical content while noting Yahoo's relatively low usage among Git contributors. The author then simplified the approach by moving all email helper documentation from gitcredentials.adoc to git-send-email.adoc, which Junio supported. The latest version (v3) adds formatting improvements to the consolidated documentation while maintaining the structural separation between email-specific helpers and general credential management.

The changes are purely documentation-focused, with no functional impact on Git itself. The series appears merge-ready, having addressed all feedback through its progression. The documentation now clearly separates email configuration from general credentials, with all email helper information properly consolidated in git-send-email.adoc. The author has indicated no plans to support additional email providers beyond the current set (Gmail, Outlook, Yahoo), suggesting this reorganization may be complete.
