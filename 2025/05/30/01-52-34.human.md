This is a bugfix patch for the sequencer, part of a v3 series that's already received maintainer approval. The patch converts an error() call to BUG() in `update_squash_messages()` when handling invalid command types, since the function should only receive TODO_SQUASH or TODO_FIXUP commands from its callers. 

The change moves the command validation to the function entry using `is_fixup()` and replaces what was previously a translatable error message with an untranslated BUG() assertion. This aligns with the thread's broader effort to standardize BUG() message formatting across the codebase. The patch is cleanly implemented with proper buffer cleanup maintained.

As noted in the thread context, this change has already been reviewed and approved by both the sequencer maintainer (Phillip Wood) and Junio C Hamano, making it effectively merge-ready.
