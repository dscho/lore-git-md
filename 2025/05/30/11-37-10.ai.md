This is a documentation patch in the ongoing email-related documentation improvements series (now at v6). The patch focuses on formatting consistency in the `git-send-email` documentation.

The changes standardize quoting styles throughout the docs, replacing inconsistent use of `"`, ``, and `'` with a more uniform approach. It also removes the `$` prefix from `<num>` and `<int>` placeholders, replacing them with underscore-wrapped versions (e.g. `_<num>_`). The patch adds missing full stops to improve readability and includes CPAN links for required Perl modules to help users with installation.

Key technical details:
- Affects both `sendemail.adoc` config docs and main `git-send-email.adoc`
- Standardizes terminology around email headers (now consistently single-quoted like 'To:' and 'Cc:')
- Updates placeholder syntax from `$<num>` to `_<num>_` throughout
- Adds CPAN links for MIME::Base64, MIME::QuotedPrint, Net::Domain, Net::SMTP, Authen::SASL, and Mail::Address
- Maintains all existing functionality while improving consistency

This continues the documentation cleanup work from earlier in the series, with the changes being primarily stylistic rather than substantive. The patch appears well-scoped and follows the established patterns from previous iterations of this documentation improvement effort.
