Test infrastructure patch addressing TAP output consistency. This is part of Patrick Steinhardt's ongoing series to align test output between Make and Meson builds, now in its third iteration.

The patch focuses on silencing repository initialization messages from `test_create_repo()` that occur outside test cases, which could confuse TAP parsers. It converts four test scripts to either use `git init --quiet` directly (for the t1007 case where repositories are created/destroyed repeatedly) or moves repository setup into proper test cases (for t4041, t4060, and t7401). The changes are mechanical but important for maintaining clean TAP output.

This continues the series' theme of standardizing test output while respecting the deprecation of `test_create_repo()` (from commit f0d4d398e28). The changes are straightforward and unlikely to be controversial, though reviewers may want to verify the test case organization in the converted scripts. The patch demonstrates careful attention to both immediate TAP compliance and long-term test maintainability.
