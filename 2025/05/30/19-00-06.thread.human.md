This thread addresses a bug where `git refs verify` fails with older-format worktrees (created by Git v2.43.0 or earlier) due to a behavior introduced in v2.48.0. The issue occurs because newer Git versions check worktree refs, but older worktree formats didn't create empty refs directories. Shejialuo developed a fix that modifies `files_fsck_refs_dir()` to ignore missing directory errors specifically for worktrees while maintaining other error checks.
