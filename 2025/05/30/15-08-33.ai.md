This is a refactoring patch in Patrick Steinhardt's series addressing maintenance operations race conditions. It fixes the typedef declarations for maintenance task function pointers in `builtin/gc.c` to be proper function pointer types rather than requiring manual pointer dereferencing.

The patch changes two key typedefs - `maintenance_task_fn` and `maintenance_auto_fn` - to include the pointer syntax directly in their definitions. This eliminates the need for users of these types to manually add pointer syntax when declaring variables. The change is purely syntactic and doesn't affect runtime behavior, but makes the code more intuitive by matching the expected function pointer pattern.

The modifications ripple through to the `maintenance_task` struct where the function pointer members are updated to use the corrected typedefs. All changes are contained within `builtin/gc.c` and maintain the same function signatures and calling conventions. This appears to be a straightforward cleanup that follows the series' pattern of improving code structure while preserving functionality.

The patch continues the series' focus on refining the maintenance task infrastructure, in this case by making the type system more accurately represent the intended usage patterns. This change should make subsequent patches in the series (particularly those dealing with task execution) slightly cleaner to implement.
