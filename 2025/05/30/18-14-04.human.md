This is a refactoring patch series addressing memory management in the pack-bitmap subsystem. Lidong Yan follows up on earlier review feedback by submitting a v2 that now includes both the code change and a new test case.

The series removes a conditional bitmap free in `find_boundary_objects()` that could lead to memory leaks when pseudo-merge cascading fails. The first patch makes the free unconditional, while the new second patch adds test coverage to verify the leak is properly fixed. The commit message has been improved to better explain the ownership semantics - the called functions only use the bitmap as a mutable reference without taking ownership.

The change appears well-justified, with the author incorporating Patrick Steinhardt's earlier analysis showing the conditional free could indeed leak memory. The addition of test coverage in v2 addresses a key concern from the initial review. This looks like a focused, incremental improvement to bitmap memory management.
