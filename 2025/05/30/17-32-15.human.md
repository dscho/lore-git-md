Feature patch adding OAuth2.0 support to `imap-send`, part of a larger series (v9 2/9) that has been through extensive review. This patch implements both the standard OAUTHBEARER (RFC 5801/7628) and Google's proprietary XOAUTH2 authentication methods for IMAP, with support in both the OpenSSL and libcurl backends.

The changes include new authentication handlers in `imap-send.c` that construct properly formatted OAuth2.0 protocol messages, plus documentation updates explaining how to use these methods with Gmail and Outlook. The implementation handles the base64 encoding and protocol specifics for each method, with clear error messages when requirements aren't met (like trying to use OAuth2.0 without proper compilation support).

Documentation now recommends OAuth2.0 over app-specific passwords for Gmail users, noting it's more secure and doesn't require multi-factor authentication. The patch also documents Outlook's exclusive use of XOAUTH2. The changes are thorough, with proper RFC citations and clear explanations of the protocol details in both code comments and user-facing docs.
