Documentation patch clarifying Gmail authentication requirements in git-send-email. This is part of the ongoing v6 documentation series that has been refining email-related documentation.

The patch makes several improvements to the Gmail authentication section in git-send-email.adoc. It clarifies that regular passwords no longer work with Gmail regardless of multi-factor authentication status, making app passwords mandatory for basic authentication. The text now explicitly recommends OAuth2.0 as a more secure alternative that works in all cases, and standardizes on the term "mechanism" (rather than "method") for OAuth authentication types to match official documentation.

The changes include rewording the Gmail section to be more direct about password requirements, adding a stronger recommendation for OAuth2.0, and updating the Outlook section to also use "mechanism" terminology. The patch maintains all existing configuration examples while making the security implications clearer. This continues the series' trend of improving documentation accuracy and consistency, particularly around authentication methods for email services.

The patch appears well-focused and addresses a real documentation gap - the previous text could mislead users into thinking app passwords were only needed for MFA accounts. The changes align with the series' broader goals of standardizing terminology and providing clearer guidance for email configuration.
