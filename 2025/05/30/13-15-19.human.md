This is the final patch in a v3 series that standardizes BUG() message formatting across the codebase. The patch mechanically converts the last few remaining instances of `BUG(_("..."))` to the now-standard `BUG("...")` format, completing a project-wide convention that programmer-facing assertions should not be translated strings.

Junio C Hamano provides a minor style suggestion for the commit message wording but otherwise approves the changes, which touch three files (builtin/mktag.c, builtin/worktree.c, and pack-bitmap-write.c) with straightforward string literal modifications. The changes are purely stylistic - removing gettext markers from BUG() calls without altering the actual message content.

This concludes the series that began with a memory leak fix in the sequencer and expanded to establish consistent BUG() message formatting. The maintainer's approval indicates this is ready for merging, with all prior discussion points resolved. The standardization work may serve as a reference for future contributions needing to use BUG() assertions.
