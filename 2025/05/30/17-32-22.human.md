Feature addition to `imap-send` in v9 of the series, adding folder listing capability. This final patch in the series introduces a `--list` option that shows all available folders on an IMAP server, which is particularly useful for discovering the correct folder names needed for configuration (like Gmail's "[Gmail]/Drafts" vs Outlook's "Drafts"). The implementation works with both OpenSSL and libcurl backends, following their respective protocols (RFC 6154 for OpenSSL, libcurl's example code for the curl backend).

The patch includes documentation update and handles the new mode throughout the codebase, with careful attention to not break existing functionality. The output shows raw IMAP LIST responses, which include both folder names and their attributes (like "\HasNoChildren"). This builds on the series' earlier work adding folder support and improves usability by helping users configure the correct folder names without trial and error.

The series as a whole has been through extensive review and iteration, with this being a polished final addition that complements the OAuth2.0 support and configuration fixes from earlier patches. The implementation looks solid, maintaining consistency with the existing code while adding the new capability cleanly.
