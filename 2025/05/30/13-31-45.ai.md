This is a bugfix patch in Patrick Steinhardt's ongoing test infrastructure series, specifically addressing platform-specific test behavior in the Meson/TAP integration effort.

The patch fixes an unexpectedly passing test in t7815-grep-binary.sh that was surfacing during TAP output parsing work. The test checks whether `git grep` correctly handles NUL bytes in regex patterns, which was previously thought to only pass on Cygwin due to its regex implementation. However, the TAP work revealed the test was also passing on macOS, likely due to shared BSD lineage in their regex implementations.

The change adds macOS to the exclusion list alongside Cygwin for this test case, marking both platforms with the new MACOS prerequisite in test-lib.sh. The commit message notes this is a temporary workaround rather than a complete solution - the ideal fix would involve configure-time regex capability checks and potentially using Git's bundled regex library, but that's deferred as out of scope for the current TAP-focused series.

This continues the pattern in the series of making test behavior consistent across platforms while maintaining TAP compliance. The change is mechanical and uncontroversial, affecting only two files with straightforward modifications. It follows the established approach in the thread of handling platform-specific test quirks through prerequisite flags rather than deeper system-level changes.
