This is version 9 of a feature and bugfix series for `imap-send`, now focusing on final documentation improvements while maintaining all the functionality from previous versions. The series has evolved through extensive review to address both technical correctness and user experience.

The patch series fixes a critical config parsing bug that made `imap-send` unusable, adds OAuth2.0 authentication support (both OAUTHBEARER and XOAUTH2 protocols), implements PLAIN authentication for OpenSSL, and fixes memory leaks in CRAM-MD5 handling. User-facing improvements include command-line folder specification (`--folder`), folder listing capability (`--list`), better credential prompts showing port numbers, and clearer progress messages showing the destination folder during sending.

Version 9's main change is improved documentation encouraging OAuth2.0 for Gmail users, noting it as more secure than app-specific passwords and not requiring multi-factor authentication. The series has been simplified by dropping the config-based backend selection patch from v8, leaving only the folder listing implementation that works across both OpenSSL and libcurl backends.

Technical implementation touches configuration parsing, authentication handlers, base64 encoding utilities, and IMAP protocol handling in `imap-send.c`. The changes span 500+ lines across config documentation, command documentation, and core implementation. The thread history shows thorough review from multiple Git contributors, with the only remaining architectural question being whether to maintain both OpenSSL and libcurl backends long-term - though the current series keeps both functional.
