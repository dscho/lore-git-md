User experience improvement in the `imap-send` series, adding destination folder information to progress output. This patch modifies the status messages during message sending to include the target folder name (e.g., "Sending 1 message to Drafts folder...") rather than just the count. The change is applied consistently to both the OpenSSL and libcurl backend implementations in `imap-send.c`.

This appears to be a straightforward quality-of-life enhancement that builds on the earlier introduction of folder support in the series. The implementation is minimal (4 lines changed) and maintains the existing pluralization logic for message counts. As the 8th patch in a 9-part series that has undergone extensive review, this seems like a final polish before the series wraps up. The change aligns with the thread's broader focus on improving `imap-send` usability while maintaining compatibility with both backends.
