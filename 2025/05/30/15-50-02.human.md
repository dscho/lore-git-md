This is the first patch in the final version (v7) of the documentation series, which has now addressed all feedback and appears ready for acceptance. The patch adds two email-related resources to Git's documentation:

1. It links Google's `sendgmail` tool as an alternative method for sending emails through Gmail when using `git send-email`. This provides users with a Google-developed option alongside the existing OAuth-based approaches.

2. It adds `git-credential-yahoo` to the list of community-maintained credential helpers, joining the existing Gmail and Outlook helpers. The Yahoo helper follows the same cross-platform pattern as the others and is maintained by the same author (Aditya Garg).

The changes are straightforward documentation additions that complete the series' goal of improving email-related documentation. The patch maintains the established formatting standards (backtick consistency, clear linking) that were settled in earlier rounds of review. This appears to be a well-polished final version of documentation improvements that have been thoroughly reviewed and debated in previous iterations.
