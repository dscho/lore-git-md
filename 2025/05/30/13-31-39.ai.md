This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP compliance in Git's test suite. The patch focuses on removing test prerequisite announcements that were breaking TAP output format.

The changes eliminate various messages that were printed when checking test prerequisites (like filesystem capabilities or tool availability), replacing them with proper TAP-formatted output. Key changes include:
- Removing explicit prerequisite announcements from 5 test scripts (t0050, t3600, t4000, t9500, t9903)
- Converting some tests to use the prerequisite itself in test_expect_success conditions rather than branching logic
- Using skip_all for filemode tests when core.filemode is false
- Moving highlight tool detection into a test_lazy_prereq block

The patch maintains all test functionality while making the output properly TAP-compliant. It's part of a larger effort to align the test suite's output format between Make and Meson builds, with particular attention to cases that were causing CI inconsistencies. The changes are straightforward mechanical conversions that don't affect test behavior, just output formatting.
