This is a follow-up discussion in the resolved thread about making the reftable subsystem's `REFTABLE_UNUSED` macro C99-compatible for the NonStop platform. The thread had already settled on Carlo Marcelo Arenas Belón's solution of using `#ifdef __GNUC__` for the attribute, with Junio C Hamano indicating it would be queued.

Brian M. Carlson provides additional context confirming that older GCC versions (pre-4.5) are no longer relevant since RHEL 7 (GCC 4.8) and Debian 7 (GCC 4.7) are both end-of-life. This validates the simplicity of the chosen solution. Hamano notes there are similar macros in `git-compat-util.h` and `compat/posix.h` that could potentially be simplified using the same approach, though this would be outside the scope of the current reftable fix.

The discussion serves as a post-mortem confirmation that the minimal solution is sufficient given modern compiler requirements, with no further action needed on this particular issue. It also hints at potential future cleanup opportunities in other parts of the codebase where similar attribute macros could be simplified, though this would be separate work.
