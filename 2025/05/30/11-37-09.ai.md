This is a documentation patch that's part of the ongoing series improving Git's email-related documentation (now at v6). The patch adds references to two credential helpers: one for Yahoo accounts (`git-credential-yahoo`) and Google's `sendgmail` tool as an email sending alternative.

The changes modify `git-send-email.adoc` to:
1. Add a new section mentioning Google's `sendgmail` tool as an alternative to using `git send-email` directly with Gmail
2. Reorganize the credential helper list to include the new Yahoo helper alongside existing Gmail and Outlook helpers
3. Remove redundant phrasing about "Gmail and Outlook" when introducing the credential helpers

The patch maintains the established pattern of providing direct GitHub links to these third-party tools. This continues the series' trend of consolidating email-related credential helper information in the send-email documentation while keeping the content up-to-date with available options. The changes are straightforward and align with the documentation improvements seen in previous versions of this series.
