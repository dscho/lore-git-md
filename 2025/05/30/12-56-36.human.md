This is a refactoring patch that's part of the ongoing effort to clean up global state in Git's codebase. It addresses a quirk in `gc_before_repack()` where a static flag was used to prevent duplicate execution when the function could be called twice during garbage collection with the `--detach` option.

The patch makes several improvements: it removes the static flag entirely, makes the function return an error code instead of dying internally, and moves the duplicate-call prevention logic to the caller by checking `opts.detach`. Ben Knoble notes in their review that this makes the control flow clearer, though they question the use of the magic number 127 for the exit code (a common convention for "command not found" errors).

The changes are straightforward and focused - the diff shows 9 lines added and 15 removed, mostly eliminating the static flag mechanism. This appears to be a clean, logical refactoring that improves code clarity while maintaining the same behavior.
