This is the final patch in a v3 series that standardizes BUG() message formatting across the codebase, removing translation markers from programmer-facing assertions. The patch mechanically converts the last remaining instances of `BUG(_("..."))` to `BUG("...")` in builtin/mktag.c, builtin/worktree.c, and pack-bitmap-write.c, completing a project-wide style unification.

Junio C Hamano provides a maintainer review, approving the changes while offering a minor wording suggestion for the commit message to use imperative mood when describing code modifications. The review confirms the technical correctness of the changes, which simply remove translation wrappers from BUG() calls without altering the actual message content.

The patch represents the conclusion of a thread that began with a memory leak fix in the sequencer and expanded to establish a new project convention: BUG() assertions should never be translated since they target developers rather than end users. This change affects three subsystems - tag verification, worktree operations, and bitmap writing - where assertions were previously marked for translation despite being internal error cases.

With this final review approval, the series is now merge-ready, having achieved consensus on both the specific sequencer fix and the broader BUG() standardization effort. The changes are straightforward mechanical conversions that don't introduce new functionality or behavior changes, only enforcing consistent style for programmer-facing error messages.
