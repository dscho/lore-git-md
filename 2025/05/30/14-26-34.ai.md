This is a follow-up in the NonStop build failure thread regarding the reftable subsystem's `REFTABLE_UNUSED` macro compatibility issue. Patrick Steinhardt points Randall S. Becker to Carlo Marcelo Arenas Belón's already-proposed fix (linked in the email) that should resolve the compilation error on NonStop platforms. The fix makes the GNU `__attribute__((__unused__))` usage conditional on `__GNUC__` being defined, which addresses the C99 compiler's inability to parse the GNU-specific attribute syntax.

The email serves as a simple pointer to the existing solution rather than introducing new technical content. It confirms the thread's current state where the fix has been identified and is awaiting integration, with no new discussion points raised. This aligns with the thread's consensus that the conditional compilation approach is the correct solution, as previously established through technical discussion about the differences between reftable's attribute handling and core Git's compatibility layer.
