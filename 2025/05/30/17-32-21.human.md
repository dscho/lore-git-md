This is a user experience improvement patch in the ongoing `imap-send` series. It enhances the output message when sending emails via `imap-send` to include the destination folder name, making it clearer where messages are being delivered. The change is straightforward - it modifies two fprintf() calls in `imap-send.c` to append the folder name to the progress message. This builds on the series' broader work to improve IMAP functionality and follows previous UX improvements like showing port numbers in credential prompts. The patch is small (6 lines changed) and focused, maintaining consistency with the series' goal of polishing the user experience while not introducing any new functionality or complexity.
