This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP compliance in Git's test suite. The patch focuses on cleaning up how test prerequisites are announced to maintain proper TAP output format.

The change removes various messages that announce whether test prerequisites are met (like "will test on a case insensitive filesystem") since these break TAP formatting. Instead, it relies on the test framework's built-in prerequisite mechanism to handle test skipping appropriately. The patch modifies several test scripts to use `test_expect_success` with prerequisite conditions directly rather than having separate announcement blocks.

This appears to be a straightforward cleanup that improves test output consistency while maintaining all existing functionality. The changes are mechanical but well-contained, touching only the test announcement patterns without altering test logic. As part of a larger series addressing TAP compliance, this patch helps standardize test output behavior between Make and Meson builds.
