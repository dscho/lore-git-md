This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP compliance in Git's test suite. The patch focuses on silencing repository initialization output that could confuse TAP parsers when tests create repositories outside of test cases.

The changes convert several test scripts to create repositories within proper test cases rather than in setup code, using `git init --quiet` where needed. The affected files are t1007-hash-object.sh, t4041-diff-submodule-option.sh, t4060-diff-submodule-option-diff-format.sh, and t7401-submodule-summary.sh. The patch builds on the deprecation of `test_create_repo()` (from f0d4d398e28) by migrating callers to use `git init` directly.

Key technical details include moving repository creation into `test_expect_success` blocks, adding 'setup' test cases, and handling one special case in t1007 where `push_repo()`/`pop_repo()` are used repeatedly. The changes are mechanical and focused on output formatting rather than test behavior, maintaining the thread's goal of TAP compliance while cleaning up deprecated test infrastructure usage.
