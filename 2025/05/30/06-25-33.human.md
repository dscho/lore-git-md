This is a technical follow-up in the thread about making the reftable subsystem's `REFTABLE_UNUSED` macro compatible with NonStop's C99 compiler. Jeff King clarifies why the similar `MAYBE_UNUSED` macro in core Git doesn't cause the same compilation issues on NonStop.

The key insight is that `git-compat-util.h` already includes platform-specific handling that makes `__attribute__()` a no-op on certain platforms, including NonStop. This explains why `MAYBE_UNUSED` works while `REFTABLE_UNUSED` (which doesn't include this compatibility layer) fails. The response is brief but effectively answers Patrick Steinhardt's question about the apparent inconsistency between the two macros.

This doesn't change the already-approved fix from Carlo Marcelo Arenas Belón, but provides useful context about Git's broader attribute handling strategy.
