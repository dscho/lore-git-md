This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP output compliance between Make and Meson builds. The patch specifically addresses a TAP formatting issue in the test-lib.sh warning message when BASH_XTRACEFD is unsupported.

The change is minimal but important for TAP compliance - it adds a "#" prefix to the warning message about unsupported BASH_XTRACEFD functionality. This ensures the warning appears as a TAP comment rather than breaking the protocol format. The warning occurs when running tests with -x tracing on older Bash versions that don't support BASH_XTRACEFD.

This is part of the broader effort to standardize test output formatting across build systems, with particular focus on making all output properly TAP-compliant. The patch follows the series' pattern of mechanical, uncontroversial changes that improve output consistency without affecting test behavior. It builds on previous work in the series that established the TAP output standards and handling of test edge cases.
