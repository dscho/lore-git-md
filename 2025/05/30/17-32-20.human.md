This is a small but useful user experience improvement in the ongoing `imap-send` series. The patch makes the credential helper prompt include the port number when asking for a password, matching the behavior of `git send-email`. 

Previously, the prompt would show just the hostname (e.g., "outlook.office365.com"), but now it includes the port (e.g., "outlook.office365.com:993"). This makes it clearer which exact server connection is being authenticated, which could help users debugging connection issues or managing multiple accounts. 

The change is minimal - just a one-line modification to use `xstrfmt()` instead of `xstrdup()` when setting the credential host field. The patch notes that the port will always be present (defaulting to 993 for IMAPS or 143 for IMAP if not specified), so there's no need to handle a port-less case.

This is part of a larger series that has added OAuth2.0 support and other IMAP improvements, but stands alone as a straightforward quality-of-life enhancement. The change is well-justified and follows existing patterns from `git send-email`.
