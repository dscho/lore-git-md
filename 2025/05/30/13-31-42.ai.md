This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP compliance in Git's test suite. It refactors Python version detection for git-p4 tests to use proper test prerequisites.

The patch modifies t9835 and t9836, which test git-b4 functionality with Python 2 and 3 respectively. Previously, these tests directly checked for Python availability and created wrapper scripts outside the test prerequisite system, producing non-TAP output. The new version moves this logic into `test_lazy_prereq()` blocks (P4_PYTHON2 and P4_PYTHON3) that properly validate Python availability while maintaining TAP format compliance.

Key technical changes include:
- Moves Python binary detection and wrapper script creation into lazy prerequisites
- Uses `test_grep` to verify git-p4 output rather than direct grep
- Maintains the same PATH manipulation but with cleaner variable handling (EXTRA_PATH)
- Preserves the same test skipping behavior when Python is unavailable
- Follows the pattern established in earlier patches of the series for prerequisite handling

This continues the series' focus on standardizing test output while maintaining functionality, addressing one of the remaining cases where direct output was bypassing the TAP formatter. The changes are mechanical and focused on output format rather than test behavior, consistent with the series' approach.
