This is a documentation patch in the final version (v7) of a series that standardizes Git's email-related documentation. It focuses on formatting consistency in the `git-send-email` documentation, building on earlier work that added OAuth2.0 references and credential helper information.

The patch makes several mechanical improvements to the send-email docs:
- Standardizes quoting style throughout (using backticks for commands/options/headers)
- Replaces `$<num>` placeholders with `_<num>_` format
- Adds CPAN links for required Perl modules (MIME::Base64, MIME::QuotedPrint, etc.)
- Fixes missing punctuation and inconsistent terminology
- Maintains the strict backtick consistency that was settled in earlier discussion

The changes are purely presentational - no behavioral changes or new functionality is introduced. This appears to be the final polish on documentation that has undergone extensive review, with all previous feedback (including from Junio Hamano and Ben Knoble) now addressed. The patch follows the series' established conventions and links to external resources consistently.

Key technical details for future reference:
- Files modified: `Documentation/config/sendemail.adoc` and `Documentation/git-send-email.adoc`
- Standardized terms: Uses "mechanism" not "method" for OAuth, wraps all email headers (`To:`, `Cc:`) and config options in backticks
- Added CPAN module links provide direct installation references
- Maintains compatibility with the parallel git-imap-send OAuth2 work (v5 still under review)
