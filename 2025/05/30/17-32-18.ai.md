Feature patch adding command-line folder specification to `git imap-send`, part of the ongoing IMAP improvements series (v9 5/9). This patch introduces a new `--folder`/`-f` option that allows overriding the `imap.folder` configuration at runtime, with the command-line value taking precedence over the config. The implementation adds the option parsing in `imap-send.c` and updates both the config and command documentation to reflect the new behavior.

The change addresses a common workflow where users need to send to different folders than their configured default, particularly useful for those who organize patches in multiple IMAP folders. The patch follows the series' pattern of enhancing usability while maintaining backward compatibility - the config remains required when the command-line option isn't used. Documentation updates include examples of folder syntax and clarify the precedence rules between config and command-line values.

This is a straightforward addition that complements the series' broader IMAP functionality improvements. The implementation is cleanly integrated with existing configuration handling, reusing the same memory management patterns seen elsewhere in the code. As with other patches in this well-reviewed series, it maintains compatibility with both OpenSSL and libcurl backends.
