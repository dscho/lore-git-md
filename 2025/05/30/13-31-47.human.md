This is a refactoring patch in Patrick Steinhardt's ongoing series to improve Meson build system integration with TAP test output. The patch introduces a `test_kwargs` dictionary in the Meson build configuration to consolidate common test parameters, starting with the `timeout: 0` setting that was previously repeated across multiple test definitions.

The change is straightforward - it moves the timeout parameter into a central dictionary that can be reused, making the configuration more maintainable. The patch updates four build files to use this new approach. This is a preparatory change for adding more common test parameters in future commits, as mentioned in the commit message.

As part of the larger series that has been well-reviewed, this appears to be a clean mechanical change that doesn't affect test behavior, just the build system configuration. It follows the pattern of other uncontroversial improvements in the series that standardize test infrastructure code.
