This is a user experience improvement patch for `imap-send`, part of the ongoing v9 series adding OAuth2.0 support and fixing IMAP functionality. The change makes credential prompts include the port number when requesting passwords, matching the behavior of `git send-email`.

The patch modifies `server_fill_credential()` in `imap-send.c` to format the port number into the host string shown in credential prompts. The change is minimal (just 1 line modified) but improves consistency - users will now see prompts like `imaps://user@host:993` instead of just `imaps://user@host`. The author notes this matches existing `git send-email` behavior and that the default ports (993 for IMAPS, 143 for IMAP) are always used when unspecified, so there's no need to handle a "no port" case.

This continues the series' pattern of polishing user-facing details after completing major functional work. The change is straightforward and unlikely to be controversial, though reviewers may want to confirm the credential helper behavior aligns with Git's overall credential handling patterns. The patch builds on the series' broader improvements to IMAP authentication and configuration handling while addressing a minor but noticeable UX inconsistency.
