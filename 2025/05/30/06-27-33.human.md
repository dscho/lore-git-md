Performance optimization series with correctness improvements for MIDX packfile lookups.

Jeff King gives his approval to Patrick Steinhardt's v3 patch series that optimizes packfile access in the MIDX subsystem. The key change in this version is the introduction of a `MIDX_PACK_ERROR` macro to cleanly handle negative cache lookups, replacing the previous magic number approach using `(void *)(intptr_t)-1`. 

This series builds on earlier work that demonstrated significant performance wins - reducing system calls from ~24,000 to ~80 in test cases and providing a 4x speedup for `git log --patch` operations with stale MIDX files. The v3 changes maintain these performance benefits while improving code clarity through better encapsulation of the negative lookup caching mechanism.

The thread has seen extensive review and refinement, with contributions from multiple core Git maintainers addressing both performance and correctness aspects of MIDX handling. With Jeff King's approval, this appears ready for potential inclusion, representing a solid incremental improvement to Git's packfile infrastructure.
