Performance optimization series for packfile handling, now in v3 with macro cleanup.

Jeff King approves Patrick Steinhardt's v3 patch series that reduces system calls for missing packfiles. The key change in this version is replacing the magic number `(void *)(intptr_t)-1` with a proper `MIDX_PACK_ERROR` macro, improving code readability while maintaining the performance benefits. This builds on the earlier work that demonstrated a 4x speedup for `git log --patch` in stale MIDX cases by reducing system calls from ~24,000 to ~80 in test scenarios.

The series is part of broader MIDX optimizations and correctness improvements that have been under discussion, including safety assertions, API refactoring, and bugfixes for MIDX chain handling. The v3 changes address a minor but important code quality concern while preserving the negative lookup caching mechanism that provides the performance wins.
