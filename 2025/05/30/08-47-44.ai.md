This is a follow-up clarification in the ongoing thread about making the reftable subsystem's `REFTABLE_UNUSED` macro C99-compatible for NonStop platforms.

Patrick Steinhardt confirms understanding Jeff King's explanation about why core Git's `MAYBE_UNUSED` macro works on NonStop while the reftable version didn't. The key difference is that `git-compat-util.h` includes platform-specific preprocessing that makes `__attribute__()` a no-op before defining `MAYBE_UNUSED`, which the reftable code lacked. 

With this technical clarification, Patrick now considers Carlo Marcelo Arenas Belón's conditional compilation fix (`#ifdef __GNUC__`) to be the right approach, resolving his earlier question about the inconsistency between the implementations. The thread appears concluded with consensus on the solution, though the discussion has highlighted architectural considerations for attribute handling standardization across Git's codebase.
