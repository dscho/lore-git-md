This is a test infrastructure patch series (10 parts) that improves TAP output parsing in Git's Meson build system. Patrick Steinhardt continues his work to align Meson's test reporting with the traditional Make-based approach, now focusing on proper TAP format compliance and handling edge cases.

The series enables Meson 1.8+ to properly report skipped tests and subtest counts, while also fixing several test script issues that previously broke TAP output formatting. Notable changes in v3 include splitting a large patch into more focused pieces, fixing unexpected test passes on macOS, and treating unexpected passes as failures in both prove and direct test execution.

The patches touch 19 files, with changes ranging from test prereq announcements to shell trace handling and platform-specific test fixes. The work builds on previous feedback from Eric Sunshine and others, showing careful attention to both immediate TAP compliance and long-term test maintainability. The series appears technically solid, with all known issues addressed from prior rounds of review.

For those using Meson builds, this provides more reliable test results and better integration with Meson's test reporting. The changes also help standardize test output across build systems, which should make CI results more consistent.
