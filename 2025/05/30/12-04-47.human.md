This is a bugfix report for the NonStop platform, following up on a previously discussed build failure in Git 2.50.0-rc0. Randall S. Becker reports seeing the same compilation error in the reftable subsystem that was previously fixed by Carlo Marcelo Arenas Belón - specifically, the C99 compiler on NonStop failing to parse the `REFTABLE_UNUSED` macro in `blocksource.c`.

The thread has already reached consensus on the solution (making the GNU attribute conditional), which Junio Hamano has approved for queuing. Randall appears to be testing an earlier version that doesn't yet include this fix, and is seeking confirmation that the issue will be resolved before the rc1 release. No new technical information is presented - this serves as a reminder that the fix needs to propagate to users building on NonStop systems.

The email underscores the importance of platform-specific testing, particularly for less common architectures like NonStop, even when the core issue has already been diagnosed and fixed in the mailing list discussion.
