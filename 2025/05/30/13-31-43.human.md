This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP output consistency between Make and Meson builds. The patch addresses how shell traces are handled in verbose test modes.

The change redirects test stdout to stderr when running with verbose flags (--verbose, --verbose-only, -x) to prevent shell traces from corrupting TAP output. While this makes stdout and stderr indistinguishable, the author notes this distinction hasn't been needed in practice. The patch updates both the test-lib.sh infrastructure and t0000-basic.sh tests to use the new redirection approach.

The modifications are limited to test plumbing and don't affect actual test behavior, just output formatting.
