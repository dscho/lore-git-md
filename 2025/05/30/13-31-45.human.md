Bugfix for platform-specific test behavior in the Meson/TAP integration series. This patch addresses an issue where a test in t7815-grep-binary.sh was unexpectedly passing on macOS due to regex behavior differences, similar to a known Cygwin case. The test checks whether `git grep` correctly handles NUL bytes in patterns, which should only pass on Cygwin but was also passing on macOS.

Patrick Steinhardt notes this was discovered while working on TAP output parsing for Meson builds. The root cause appears to be macOS inheriting regex behavior from FreeBSD that makes the test pass, though the commit message acknowledges this is unclear how long this has been the case. Rather than solving the deeper regex compatibility issue (which would require configure-time checks and potentially using Git's bundled regex library), this patch takes the pragmatic approach of excluding macOS from the test alongside Cygwin.

The change is minimal - just adding the MACOS prereq and modifying the test condition. This keeps the series focused on TAP integration while preventing false positives on macOS. The patch fits into the broader effort to standardize test output across platforms as part of Meson build system integration.
