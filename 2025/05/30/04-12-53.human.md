This is a follow-up discussion in the thread about making the reftable subsystem's `REFTABLE_UNUSED` macro compatible with C99 compilers, particularly for the NonStop platform.

The email confirms that the simpler solution proposed by Carlo Marcelo Arenas Belón (using `#ifdef __GNUC__` for the unused attribute) is sufficient, as Brian M. Carlson provides historical context showing that older GCC versions requiring more complex checks are now well past end-of-life. Junio C Hamano notes there are similar macros in the main Git codebase that could also be simplified, though this is outside the scope of the current reftable fix.

The discussion appears to be wrapping up, with consensus that the straightforward conditional compilation is adequate for modern compiler requirements. Hamano hints at potential future cleanup opportunities in the main codebase's compatibility macros, but this doesn't affect the immediate reftable fix which is already considered settled.
