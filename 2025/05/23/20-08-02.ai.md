Test fix for macOS maintenance tests involving path resolution with symlinks, with additional Windows compatibility considerations. This is a follow-up to Mark Mentovai's patch that fixed test failures when running t7900-maintenance.sh from directories containing symlinks by using `pwd -P` to match Git's path resolution behavior.

Eric Sunshine raises an important platform-specific consideration: while the fix works for macOS/Unix, it may cause issues on Windows where Git overrides `pwd` with a custom shell function that uses `-W` (Windows-style paths). His testing shows `pwd -P` on Windows ignores the `-W` flag and returns a Unix-style path, potentially reintroducing the path mismatch problem the original patch aimed to solve.

The email suggests two key points: 1) the current minimal fix might need platform-specific handling for Windows, and 2) proposes a more robust long-term solution would be to sanitize paths in test output comparisons rather than trying to exactly match system-dependent paths.
