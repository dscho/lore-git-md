This is a feature patch adding PLAIN authentication support to the OpenSSL path in `imap-send`, part of a larger series improving IMAP functionality. The patch introduces a new `AUTH_PLAIN` capability and implements the RFC 4616-compliant PLAIN authentication method for OpenSSL users, complementing the existing curl-based implementation.

The implementation follows the standard PLAIN authentication scheme by base64-encoding a NUL-delimited "user\0pass" string, with proper memory management throughout. The documentation is updated to reflect PLAIN as a supported method when using OpenSSL. This addresses a gap where OpenSSL users could only use LOGIN commands rather than AUTH PLAIN, despite many email providers supporting PLAIN via app passwords.

Key technical details:
- New `AUTH_PLAIN` capability flag and corresponding string constant
- `plain_base64()` helper function implementing RFC 4616 encoding
- New `auth_plain()` handler integrating with existing IMAP command flow
- OpenSSL-specific error handling when PLAIN support is not compiled in
- Documentation update to include PLAIN in the listed auth methods

The patch appears well-structured with clear error handling and follows the pattern established by other authentication methods in the codebase. It completes the series' goal of comprehensive authentication support across both curl and OpenSSL backends.
