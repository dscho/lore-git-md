This is a documentation patch in a 9-part series improving `--stdin` usage documentation in git-notes and related configuration. It's the third patch in v2 of the series, following up on feedback from the initial version.

The patch focuses on improving option documentation by splitting combined `--[no-]option` forms into separate entries for `--separator`/`--no-separator` and `--stripspace`/`--no-stripspace`. This change makes the options easier to search for in the documentation, addressing a suggestion from Junio Hamano. The modification affects only Documentation/git-notes.adoc, with no behavioral changes to the actual commands.

The patch maintains the series' goal of clarifying documentation around git-notes' behavior while following established documentation conventions. It builds on previous work that separated concerns between stripping behavior and comment handling, which were incorrectly coupled in v1. The change is straightforward and uncontroversial, aligning with the series' ongoing refinement of option documentation formatting.
