This is the second patch in a 4-part series adding OAuth2.0 authentication support to `git imap-send`. The patch implements OAUTHBEARER (RFC 5801/7628) and XOAUTH2 (Google's proprietary protocol) authentication methods, addressing a longstanding limitation where only basic auth and CRAM-MD5 were available.

The implementation handles both OpenSSL and curl-based authentication paths. For OpenSSL builds, new helper functions (`oauthbearer_base64` and `xoauth2_base64`) construct and encode the authentication strings. For curl builds, the patch leverages `CURLOPT_XOAUTH2_BEARER` which automatically selects the appropriate mechanism. The documentation is updated with specific examples for Gmail (which requires app passwords or OAuth) and Outlook (which only supports XOAUTH2).

The changes are well-integrated with the existing credential system, allowing use of credential helpers to manage OAuth tokens. The patch appears technically sound, with thorough handling of error cases and proper memory management. It builds on the configuration parsing fixes from patch 1/4 in the series, making this a key step toward modern IMAP authentication support.
