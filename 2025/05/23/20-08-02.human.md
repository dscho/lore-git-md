Test fix addressing macOS maintenance test behavior with symlinks, now considering Windows compatibility. 

This email continues discussion of a patch that makes the macOS maintenance tests work correctly when run from directories containing symbolic links. The original fix changed `pwd` to `pwd -P` to match Git's path resolution behavior, but Eric Sunshine points out this may cause issues on Windows where Git overrides `pwd` with a `-W` flag for MinGW compatibility. Testing shows `pwd -P` and `pwd -W -P` produce different outputs on Windows, suggesting the simple `-P` addition might not be sufficient across all platforms.

Sunshine suggests a more robust long-term solution would be to sanitize paths in test output comparisons rather than trying to match exact paths, since the tests should verify maintenance functionality rather than specific path formatting. The current discussion focuses on ensuring the minimal fix works correctly on Windows while maintaining the macOS symlink resolution behavior. The thread shows careful consideration of cross-platform implications for what initially appeared to be a macOS-specific test fix.
