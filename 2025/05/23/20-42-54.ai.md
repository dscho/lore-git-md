This is a test fix discussion thread exploring cross-platform path resolution issues in Git's maintenance tests, with specific focus on Windows behavior. Junio C Hamano responds to Eric Sunshine's concerns about the proposed `pwd -P` solution for macOS not working as intended on Windows due to Git's custom `pwd` shell function.

The email examines two key technical points: First, that the Windows shell's `pwd` override (which uses `-W` for Windows-style paths) ignores the `-P` flag entirely, meaning the proposed change would have no effect on Windows. Second, it suggests alternative testing approaches for Windows, such as creating symbolic links in the test directory structure.

Junio also considers broader solutions beyond platform-specific fixes, including:
1) Having tests sanitize paths in output by replacing them with placeholders like `%HOME%` before comparison
2) Modifying `test-lib.sh` to force canonical path resolution early in test execution (e.g. via `cd -P .`)

The discussion highlights the tension between quick fixes for specific platforms (macOS symlinks) versus more robust solutions that would handle all platforms consistently. The thread appears to be moving toward favoring a path normalization approach that would make test assertions less dependent on exact path string matching.
