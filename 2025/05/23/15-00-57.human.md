This is a test infrastructure patch addressing a macOS-specific issue discovered during the Meson integration work. Patrick Steinhardt identifies an unexpected test pass in `t7815-grep-binary.sh` where a test marked as `test_expect_failure` (expected to fail everywhere except Cygwin) is actually passing on macOS. The behavior appears related to how macOS's regex implementation handles NUL bytes, similar to Cygwin's known behavior.

The patch proposes two changes: adding a `MACOS` prereq to exclude macOS from the failing test expectation, and adding macOS detection to `test-lib.sh`. While the immediate issue is straightforward, Steinhardt questions the test's value since it's testing platform-specific behavior that may not be meaningful to verify across all systems.

This comes as a follow-up to the nearly-ready Meson test output parsing series, where macOS-specific test output was recently discovered to interfere with TAP formatting. The patch demonstrates careful cross-platform consideration, though the author notes the underlying test case might warrant reevaluation for its broader utility.
