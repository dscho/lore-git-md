This is a follow-up in the Meson test suite integration series, now in its final administrative stage before integration. Patrick Steinhardt responds to Junio Hamano's query about an isolated macOS CI failure that appears when using Meson's TAP parser. The failure occurs only on macOS where certain tests emit output to stdout/stderr, breaking TAP format compliance. Steinhardt confirms this is due to macOS environment now using a newer Meson version that enables the TAP parser, and promises to investigate and send an updated version of the patches. The thread shows all technical aspects were previously resolved, with this being a final platform-specific issue to address before the series can be merged.
