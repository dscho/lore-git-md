This thread discusses improvements to Git's test infrastructure to handle path resolution consistently across platforms, particularly addressing macOS test failures when running from directories containing symlinks. The discussion began with Mark Mentovai identifying the issue and proposing a fix using `pwd -P`, which led to a broader conversation about path handling strategies.

Junio Hamano proposed a canonical approach via `cd -P` in test-lib.sh, which has now been implemented in a patch by Mark. The solution modifies test-lib.sh to normalize both `$TRASH_DIRECTORY` and `$HOME` to match `cd -P` resolved paths, fixing test failures while maintaining the ability to test path resolution edge cases elsewhere. The architectural approach is settled, with Junio's infrastructure-first solution being the agreed direction.

Torsten Bögershausen has now chimed in with a documentation refinement, suggesting clearer terminology in the patch's commit message to distinguish between path canonicalization and unrelated concepts like CRLF/LF normalization. He recommends using "absolute path" consistently instead of potentially ambiguous terms like "normalized path." This is the only remaining open point in what is otherwise a resolved discussion, with the technical implementation already agreed upon by the key participants.
