This is a test fix targeting macOS compatibility. The patch addresses a test failure in t7900-maintenance.sh that occurs when the test is run from a working directory containing symbolic links. The issue arises because `git maintenance start` resolves paths using realpath semantics (following symlinks), while the test was using a simpler path resolution that didn't follow symlinks.

Mark Mentovai explains that the test compares paths generated by `git maintenance` (which uses canonicalized paths) against a test variable `$pfx` that wasn't similarly canonicalized. The fix changes the test to use `pwd -P` (physical path) to match Git's path resolution behavior. This is a straightforward and well-explained fix that aligns test behavior with actual Git behavior, though it's narrowly focused on macOS-specific test infrastructure.
