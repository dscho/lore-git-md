This is a test infrastructure patch addressing a macOS-specific issue discovered during the final review of Patrick Steinhardt's Meson TAP output parsing series. The patch fixes an unexpected test pass in `t7815-grep-binary.sh` where a test marked `!CYGWIN` was also passing on macOS due to shared BSD lineage in regex behavior.

The core issue stems from test 868/1023 (`git grep .fi a`) unexpectedly passing on macOS because the platform's regex engine (like Cygwin's) matches NUL bytes with `.`. The patch adds a `!MACOS` prerequisite to exclude macOS from this test case and introduces a new `MACOS` test prerequisite via `test-lib.sh`.

While the immediate problem is isolated to this test case, the discussion raises broader questions about the value of platform-specific regex behavior validation. The patch takes a minimal approach by simply excluding macOS rather than restructuring the test, as the behavior appears to be an inherited platform quirk rather than a Git bug.

This represents the final platform-specific adjustment needed for Steinhardt's Meson TAP parsing series, which has otherwise received thorough review and technical approval. The changes remain confined to test infrastructure (`t/t7815-grep-binary.sh` and `t/test-lib.sh`) and don't affect core Git functionality.
