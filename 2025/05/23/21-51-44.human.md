Junio Hamano weighs in on the ongoing discussion about fixing macOS and Windows test path resolution in t7900-maintenance.sh. This is part of the test infrastructure improvements around cross-platform consistency.

Junio notes that since tests set HOME to TRASH_DIRECTORY, the path comparison issues aren't specifically about $HOME itself. He suggests the root cause might be that TRASH_DIRECTORY isn't canonicalized early enough in test setup. His proposed solution modifies test-lib.sh to canonicalize TRASH_DIRECTORY via `cd -P` and update both TRASH_DIRECTORY and HOME to the resolved path.

This builds on previous discussion where:
- Mark Mentovai's initial `pwd -P` fix was deemed safe but limited
- Eric Sunshine had proposed placeholder paths as a more comprehensive solution
- The thread had considered various approaches to handle platform differences in path resolution

Junio's suggestion offers a middle ground - addressing the immediate issue through earlier canonicalization in the test infrastructure rather than patching individual tests. The change is minimal but could have broader impact than the original `pwd -P` fix. This keeps the door open for more comprehensive solutions like Eric's placeholder path approach while providing a clean fix for the current test failures.
