Test fix for macOS maintenance tests involving symbolic links.

This patch addresses a test failure in t7900-maintenance.sh that occurs when the test is run from a working directory containing symbolic links. The issue stems from a mismatch in path resolution between the test's expectation ($pfx) and how `git maintenance` actually constructs paths for launchd plist files. The test uses a simple `pwd` to determine the home directory path, while `git maintenance` internally uses realpath semantics via `strbuf_realpath()` which resolves symbolic links.

The fix changes the test to use `pwd -P` (physical path) when setting $pfx, ensuring consistent path comparison regardless of whether the working directory contains symbolic links. This matches the behavior of `git maintenance`'s path resolution. The change is minimal (one character added to the pwd command) but important for test reliability on macOS systems where users might have symlinks in their directory structure.

Key technical details:
- Affects t/t7900-maintenance.sh test for macOS maintenance scheduling
- Changes how $pfx (home directory path) is determined in the test
- Aligns test behavior with `git maintenance`'s path resolution via `interpolate_path()` with `real_home=1`
- Specifically impacts the 'start and stop macOS maintenance' test case
