Thread identity: Documentation patch discussion about submodule URL configuration behavior, initiated by Chris Wilson.

Core problem: The git-config documentation does not clarify that `submodule.<name>.url` only accepts absolute URLs, treating non-absolute inputs as filesystem paths. This differs from `.gitmodules` which handles relative URLs. Wilson encountered this in a CI/CD context where attempting to override submodule URLs with relative paths failed.

Current status: Initial patch proposes documentation clarification. Wilson suggests an alternative solution of adding a new configuration option for relative URL handling, but this remains an undocumented behavior rather than a confirmed bug.

Key technical details: The discrepancy between `submodule.<name>.url` (absolute-only) and `.gitmodules` (relative allowed) behavior is the focus. The patch would modify git-config documentation to explicitly state this difference.

Open questions: Whether to simply document the current behavior or consider adding support for relative URLs in the config option. No maintainer feedback yet on the suggested alternative approach.
