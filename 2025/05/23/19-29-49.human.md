This is a documentation patch in a 9-part series improving `--stdin` usage documentation in git-notes and clarifying `core.commentChar` references. It's the third patch in version 2 of the series, following up on feedback from the initial version.

The patch focuses on improving searchability by splitting combined option forms like `--[no-]separator` into separate entries for the positive and negative variants (`--separator` and `--no-separator`). This change affects both the separator and stripspace options in git-notes documentation. The author notes this makes the options easier to find, addressing a suggestion from Junio Hamano in the v1 discussion.

The change is straightforward and uncontroversial, aligning with the series' goal of improving documentation clarity. It follows the pattern established in earlier patches of the series, which have already received positive feedback on similar formatting improvements. The patch maintains all existing functionality while making the documentation more accessible.
