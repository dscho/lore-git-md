This is a platform compatibility patch addressing macOS-specific regex behavior in Git's test suite. Junio Hamano confirms Patrick Steinhardt's observation that a test case in t7815-grep-binary.sh unexpectedly passes on macOS due to BSD-derived regex behavior where '.' matches NUL bytes - behavior previously thought to occur only on Cygwin.

The patch adds a MACOS prerequisite to exclude the test case (868/1023) from running on macOS, similar to the existing CYGWIN exclusion. This matches the test's original intent while acknowledging the platform-specific behavior. The change is minimal, touching only the test file and test-lib.sh to add the new prerequisite.

The discussion reveals an interesting historical note - this BSD regex behavior was likely inherited from FreeBSD, showing how platform lineage can surface in test behavior. While the fix is straightforward, Hamano raises a good question about why this issue only appears in the Meson test jobs, suggesting there may be more to investigate about test environment differences.

This patch represents the final piece needed for Patrick Steinhardt's Meson test integration series, which has already undergone thorough review. It demonstrates the careful attention to platform-specific edge cases required when making cross-platform test infrastructure changes.
