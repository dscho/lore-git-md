This is a test patch in a bugfix series addressing file mode handling in `git apply --reverse`. It's the first of two patches in version 2 of the series.

The patch adds test coverage to verify that `git apply` properly warns about unexpected file mode changes, particularly when reversing patches that delete executable files. The tests specifically check the behavior that commit 01aff0a fixed in 2023, where mode bits weren't properly preserved during reverse patching. The new tests cover both forward and reverse application of patches, checking for the expected mode mismatch warnings.

The test structure has been carefully designed with helper functions for checking file modes, and it verifies behavior both in the working tree and index. This follows up on feedback from the first version of the patch series, where reviewers suggested improvements to the test organization and coverage.
