This is a feature and bugfix series for `imap-send`, now in its third iteration, addressing both configuration parsing issues and adding OAuth2.0 authentication support. The series has evolved significantly from previous versions based on reviewer feedback, particularly around licensing concerns and memory management.

The third patch completes the memory leak fixes for CRAM-MD5 authentication paths.

The documentation updates cover both the configuration behavior and new OAuth2.0 options, including Gmail and Outlook-specific requirements.
