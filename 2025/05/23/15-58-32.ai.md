This is a platform compatibility patch addressing macOS-specific regex behavior in Git's test suite, building on Patrick Steinhardt's Meson integration series. The issue involves test t7815-grep-binary.sh unexpectedly passing on macOS due to BSD-derived regex behavior where '.' matches NUL bytes - behavior previously thought to occur only on Cygwin.

The patch adds a MACOS test prereq and excludes macOS from the failing test case (868/1023) that checks this behavior. Junio Hamano confirms the BSD regex inheritance suspicion but questions why this issue only surfaces in Meson builds, suggesting the underlying behavior exists in all macOS test runs.

Key technical details:
- Modifies t7815-grep-binary.sh to add !MACOS alongside !CYGWIN in test_expect_failure
- Adds MACOS prereq detection in test-lib.sh via uname -s Darwin check
- References prior regex behavior documentation from commit 064eed36c7f
- Maintains test intent while accounting for platform variance
