This is a follow-up in the completed Meson test suite integration series, addressing a newly discovered macOS-specific test failure. The series had already reached technical consensus and was awaiting final integration when this platform-specific issue emerged.

Patrick Steinhardt notes that macOS's recent Meson update (to a version including his upstream TAP parser fix) has exposed additional test output pollution issues specific to macOS-only tests. The failure manifests as malformed TAP output when certain macOS tests write to stdout/stderr outside the expected TAP format boundaries. This was not caught earlier because the TAP parser was previously disabled on macOS Meson builds.

The email indicates Steinhardt will investigate and send an updated version of the series to handle these macOS-specific cases. The core technical approach (TAP parsing in Meson 1.8+) remains unchanged, but additional test output redirection or suppression may be needed for macOS-specific code paths. This appears to be the final pre-integration issue to resolve for the otherwise complete series.
