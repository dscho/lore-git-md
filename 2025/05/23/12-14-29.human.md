This is a feature patch adding PLAIN authentication support to `imap-send` when using OpenSSL, part of a larger series improving IMAP authentication methods. 

The patch adds PLAIN authentication as an option for OpenSSL users, complementing the existing curl-based implementation. Many email providers still use PLAIN authentication (particularly with app passwords), but until now OpenSSL users were limited to the less secure IMAP LOGIN command. The implementation follows RFC 4616, properly encoding credentials in the required format (NUL-separated user and password strings, base64-encoded).

Key technical changes include:
- New `AUTH_PLAIN` capability flag
- `plain_base64()` helper function for credential encoding
- `auth_plain()` authentication handler
- Documentation updates listing PLAIN as a supported method

This appears to be a well-constructed patch that fills a clear gap in OpenSSL support. The implementation is thorough, with proper error handling and documentation. As the third patch in a v4 series that has already received extensive review, it seems likely to merge. The change is particularly valuable for users who need to work with email providers that mandate PLAIN authentication.
