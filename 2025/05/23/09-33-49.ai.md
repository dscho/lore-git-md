Performance test addition for the `git last-modified` command series.

This patch adds a performance test script for the new `git last-modified` functionality, which Toon Claes builds on Jeff King's initial work. The test measures three scenarios: basic top-level operation, recursive traversal with `-r`, and subdirectory-specific queries. The tests use the default test repository and focus on detecting performance regressions rather than correctness (which is covered elsewhere).

The implementation is straightforward, following Git's standard performance test patterns. It exercises the key operational modes that were discussed in the thread - particularly the recursive vs non-recursive behavior that saw significant debate. The subdirectory test case is notable as it validates the pathspec handling that remains an open discussion point in the thread.

This patch appears technically sound and well-integrated with the series, though it doesn't include any complex repository setups or edge cases that might reveal deeper performance characteristics. The simplicity is appropriate for an initial benchmark that can be expanded later, particularly if the caching layer (currently deferred) gets implemented. The test numbering (p8020) follows Git's standard scheme while avoiding conflicts with existing tests.
