Test patch refining mode change warnings in `git apply`. This is the first of two patches in a v2 series fixing executable mode handling when reversing patches, building on commit 01aff0a from December 2023.

The test suite additions verify that `git apply` properly warns when file modes don't match expectations during both forward and reverse patching. The test infrastructure is improved with helper functions `test_file_mode_staged()` and `test_file_mode_HEAD()` to check modes in the index and HEAD respectively. The tests cover all combinations of executable/non-executable transitions with `core.fileMode=false`.

Junio Hamano provides minor review feedback suggesting the test could be slightly clearer by using `>` instead of `touch` to create test files, since the content/timestamp don't matter for the mode tests. The test design itself is solid, with careful attention to portable executable bit manipulation via `git add --chmod`. The patch appears ready to merge as part of the series addressing the mode preservation issue.
