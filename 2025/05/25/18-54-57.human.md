This is part 2 of a 6-patch series adding OAuth2.0 support to `imap-send`. The patch implements support for both OAUTHBEARER (RFC 5801/7628) and XOAUTH2 (Google's proprietary protocol) authentication methods when using OpenSSL as the backend. 

The implementation adds new helper functions `oauthbearer_base64()` and `xoauth2_base64()` to properly format and encode the authentication strings according to each protocol's specifications. The patch also updates the IMAP capability handling to recognize these new methods and wires them into the authentication flow. Documentation is expanded to explain how to use OAuth2.0 with both Gmail and Outlook, including notes about access tokens and credential helpers.

The changes are well-contained, focusing just on the OpenSSL backend implementation (a later patch in the series handles the native curl implementation). The documentation updates are particularly thorough, addressing real-world configuration needs for major email providers. This appears to be a robust implementation of a frequently-requested feature that will help users work with modern email authentication requirements.

The patch builds on the series' earlier fixes and maintains the same careful approach to memory management seen in the CRAM-MD5 fixes. With comprehensive docs and clear implementation, this looks ready for inclusion.
