This thread concerns adding R language support to Git's diff highlighting, specifically for recognizing function definitions in R code. Rodrigo Carvalho submitted a two-patch series implementing the feature in `userdiff.c` and adding test cases that verify it works with both indented and non-indented R code using the `<- function()` syntax.

Eric Sunshine has raised the first review comment, noting that some R programmers use `= function()` instead of `<-` for function assignment. This suggests the current implementation might miss function definitions in codebases that prefer the `=` style. The thread is now at a point where the author needs to address whether to expand the pattern matching to handle both syntax variants or justify why the current approach is sufficient. This is the first substantive feedback on the series, and the response will determine whether another version of the patches is needed.
