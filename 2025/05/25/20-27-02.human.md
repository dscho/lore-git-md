This is the second patch in a documentation series converting manpages to a new synopsis style format. It focuses on `git-merge.adoc`, making mechanical formatting changes to standardize the documentation without altering content.

The patch converts the SYNOPSIS section to use AsciiDoc synopsis blocks, which automatically format placeholders in italics and keywords in monospace. It also updates the document to consistently use `_<placeholder>_` notation and backticks for command/option references. A notable technical detail is the special handling of conflict markers (`<<<<<<<` etc.), which are formatted with `+` signs instead of backticks to prevent rendering issues.

This continues the series' pattern of purely mechanical changes, following the same style established in the first patch for `git-checkout.adoc`. The changes are straightforward and maintain the existing documentation's meaning while improving its consistency with other modern Git documentation. The patch is cleanly focused on formatting, with 25 lines added and 26 removed, showing the changes are roughly line-for-line replacements.
