Documentation patch fixing a double negation in merge-options.adoc, part of the ongoing documentation standardization series. This is patch 4/9 in the series that previously converted `git-checkout.adoc`, `git-merge.adoc`, and other option documentation files to the new synopsis style.

The change is minimal but meaningful - it fixes a confusing double negative ("no...will not be added") in the documentation for the `--allow-unrelated-histories` merge option. The new phrasing ("exists or will be added") is clearer while maintaining the same technical meaning that there is and will continue to be no configuration variable to enable this behavior by default.

This continues the mechanical documentation improvements from earlier patches in the series, though unlike the larger formatting conversions in patches 1-3, this is a focused language clarification. The change affects only one line in `merge-options.adoc`, modifying the explanation of why there's no default configuration for merging unrelated histories. The patch follows the same established patterns for documentation updates seen throughout this standardization effort.
