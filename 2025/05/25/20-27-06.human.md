This is a documentation patch (6/9 in the series) converting merge-related configuration documentation to the new synopsis format. Jean-Noël Avila continues their systematic update of Git's documentation, this time focusing on the merge-related config options in `merge.adoc` and `fmt-merge-msg.adoc`.

The changes follow the established pattern of the series: replacing angle brackets with `_<placeholder>_` syntax, adding backticks around command/option references, and improving formatting. Notable improvements include converting the `merge.directoryRenames` option values into a clearer definition list and standardizing the conflict marker notation (using `+` signs around `<<<<<<<` markers).

The patch maintains all technical content while making it more consistent with the project's documentation standards. This is part of the larger effort to modernize Git's documentation formatting, building on previous work in the series that converted command manpages and option documentation. The changes are mechanical but thorough, covering all merge-related configuration options.

No functional changes are introduced - this is purely a documentation formatting update. The patch follows the same high-quality approach seen in earlier parts of the series, with careful attention to preserving all existing information while improving presentation.
