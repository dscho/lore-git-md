Refactoring patch in the multi-pack-index (MIDX) subsystem. This is the fourth in a series of five patches improving MIDX internals, following earlier performance optimizations and correctness fixes from Taylor Blau and others.

The patch extracts the inner loop of `fill_packs_from_midx()` into a new helper function `fill_packs_from_midx_1()`. This simplifies the control flow by reducing nesting and making each function's responsibility clearer. The original function had to handle both iterating through MIDX layers and processing individual packs within each layer; now those concerns are separated.

The change is purely structural - no behavior is modified. The new helper maintains all existing functionality including the `MIDX_WRITE_REV_INDEX` flag handling and error checking. This appears to be preparatory work, likely making future changes to the pack enumeration logic easier to implement and review.
