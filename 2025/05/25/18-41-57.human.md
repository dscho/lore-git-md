This is a refactoring patch in Taylor Blau's series improving MIDX (multi-pack-index) handling. It simplifies the logic in `fill_packs_from_midx()` by consolidating two conditions that trigger loading pack indexes. 

The key change moves the check for `preferred_pack_name` outside the main loop and sets the `MIDX_WRITE_REV_INDEX` flag when a preferred pack is specified. This eliminates redundant checks inside the loop and prepares for future extraction of the inner loop into a separate function. The patch maintains all existing functionality while making the code more straightforward.

This is part of a larger effort to improve MIDX correctness and performance that has been under active discussion on the list. The change is small but meaningful - it reduces complexity in a function that handles critical packfile operations. Given Taylor Blau's track record with this subsystem and the careful explanation in the commit message, this appears to be a safe, well-considered improvement.
