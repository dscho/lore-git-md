Documentation patch converting the `git-checkout` manpage to new synopsis style format. This is the first of a 9-patch series standardizing documentation formatting across multiple Git commands.

Jean-Noël Avila updates the `git-checkout.adoc` and related config documentation to use AsciiDoc's synopsis block formatting, which will automatically style placeholders in italics and keywords in monospace. The changes are purely mechanical - replacing angle brackets with underscores for placeholders (`<branch>` -> `_<branch>_`) and adding backticks around command names and options. The patch also converts NOTE sections to proper AsciiDoc admonitions.

This follows established patterns from prior documentation conversion work. The changes affect both the main command documentation and its associated `checkout.*` config options. While verbose in the diff (228 lines changed), the modifications are straightforward syntax updates that don't alter the actual content or behavior being described.

As the opening patch in a larger documentation standardization effort, this sets the pattern for subsequent conversions in the series. The approach appears consistent with Git's documentation style guidelines and previous similar conversions.
