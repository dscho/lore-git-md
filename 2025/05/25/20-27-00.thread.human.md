This thread documents a mechanical conversion of several Git command manpages to the new synopsis-style format as part of Jean-Noël Avila's ongoing documentation standardization effort. The initial 9-patch series targets `git checkout`, `git switch`, `git merge`, and related configuration files, making purely presentational changes to adopt consistent AsciiDoc markup without altering command behavior.

The first patch focuses specifically on `git-checkout.adoc`, converting its SYNOPSIS section to use synopsis blocks and standardizing markup for placeholders and command references (like changing `<branch>` to `_branch_` and using backticks for config options). The changes are net-zero in line count (121 lines added/removed), confirming they're strictly formatting improvements. The remaining patches in the series will apply similar mechanical conversions to the other targeted commands' documentation.

This work follows established patterns from prior documentation conversions and appears uncontroversial - no reviews or objections have been raised yet. The changes are part of a broader project to bring consistency to Git's manpage formatting, with Jean-Noël Avila having shepherded many similar conversions through the review process before.
