This is a feature patch introducing the new `git last-modified` command, part of an ongoing series that has evolved through mailing list discussion. The patch establishes core functionality for tracking when paths were last modified in a repository's history.

The implementation provides a new plumbing command that walks history backwards to find the most recent modification for each path. Key components include:
- `last-modified.[ch]` core logic with path tracking via `last_modified_entry` structs
- `builtin/last-modified.c` implementing the command interface
- Comprehensive test suite in `t/t8020-last-modified.sh` covering basic cases, recursion, subdirectories, revision ranges, and merge scenarios
- Documentation in `Documentation/git-last-modified.adoc` marking the command as experimental
