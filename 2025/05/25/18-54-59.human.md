This is a feature patch in the `imap-send` series, adding PLAIN authentication support for OpenSSL users. It's part of a larger v5 series that has been through extensive review and addresses multiple authentication methods and configuration fixes.

The patch implements RFC 4616-compliant PLAIN authentication for OpenSSL, which was previously only available when using curl. Many email providers still use PLAIN authentication (particularly with app passwords), so this makes `imap-send` more flexible for users who need to use OpenSSL rather than curl. The implementation includes proper base64 encoding of credentials and handles error cases like encoding failures and socket write problems.

The changes are straightforward: adding a new `AUTH_PLAIN` capability flag, implementing the `plain_base64()` helper function, and wiring it into the authentication flow. Documentation is updated to reflect the new supported method. The patch fits cleanly into the existing architecture and follows the same patterns as the other authentication methods in the codebase.

This is part of a well-reviewed series that has addressed all technical concerns in previous iterations, with this particular patch completing the authentication method coverage for OpenSSL users. The implementation looks solid and properly handles memory allocation and error cases.
