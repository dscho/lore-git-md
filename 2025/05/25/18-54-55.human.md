Bugfix for `imap-send` configuration parsing that has been broken since Git 2.46.0. This is the first patch in a v5 series that adds OAuth2 support and other improvements to `imap-send`.

The patch fixes a regression introduced in 6d1f198f34 where the IMAP folder setting would be incorrectly set to NULL when other configuration values (user, password, tunnel, or auth method) were defined. This made `git-imap-send` completely unusable since Git 2.46.0. The bug went unnoticed for some time, likely because most users prefer `git-send-email`.

The fix is straightforward - it corrects which struct fields get cleared when processing each configuration option. Instead of incorrectly clearing `cfg->folder` for all settings, it now clears the appropriate field for each setting (user, pass, tunnel, or auth_method).

This is a critical fix that restores basic functionality before the series adds new features. The thread context shows this has been thoroughly reviewed, with Jeff King diagnosing the configuration bug and Junio Hamano reviewing the fix. The rest of the series builds on this foundation to add OAuth2 support and other improvements.
