This is a feature patch adding R programming language support to Git's diff highlighting.

Rodrigo Carvalho contributes a small but useful addition to Git's userdiff patterns, which help Git better highlight function definitions in diffs. The patch adds recognition for R function definitions that use the `<- function()` assignment syntax, a common pattern in R code. This will make diffs of R source files more readable by properly highlighting function boundaries.

The change is straightforward - it adds a new pattern to `userdiff.c` that matches R function definitions while excluding other lines. The implementation follows the same style as existing language patterns in the file, suggesting it's likely to be uncontroversial.

This appears to be part of a 2-patch series (though the cover letter wasn't provided), and would primarily benefit R developers who use Git for version control. The patch is small, focused, and seems well-formed with a clear purpose.
