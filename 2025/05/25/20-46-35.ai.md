Kristoffer Haugsbakk proposes an alternative test approach for verifying the whitespace cleanup in Git's notes editor template. 1. Create a commit with `--signoff`

4. Use `test_cmp` to verify full template correctness

This would provide stronger verification that the whitespace stripping behaves as intended across the entire template, not just checking for trailing spaces. The test remains focused on the notes subsystem (`t/t3301-notes.sh`) and continues to use the same basic setup (commit creation and editor capture).
