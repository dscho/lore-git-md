Bugfix and logging improvement for `git send-email` when handling Outlook-modified Message-IDs. This is the second patch in Aditya Garg's v4 series addressing email threading and logging issues.

The patch fixes a specific logging inconsistency that occurs when Microsoft Outlook modifies the Message-ID header during email delivery. Currently, while `git send-email` detects and reports the Message-ID change, the final header log still shows the original ID. The change modifies the `$header` variable to reflect the actual delivered Message-ID in the comprehensive log output.

Key technical details:
- Modifies the `send_message` subroutine in `git-send-email.perl`
- Updates the `$header` variable to replace the original Message-ID with Outlook's modified version
- Makes the "Message-ID reassigned" notice conditional on `smtp-debug` being enabled, since the main log now shows the correct ID
- Changes affect 4 lines (3 additions, 1 deletion) in the Perl script

The patch demonstrates careful handling of email client quirks while improving debug output accuracy. The solution is straightforward - updating the stored headers to match what was actually delivered - and the debug message change prevents redundant information when the main log already shows the correct ID. This appears ready for review as part of the complete series.
