This is a review response regarding the R language support patch for Git's diff highlighting. Johannes Sixt raises several technical concerns about the implementation while acknowledging the usefulness of adding R support overall.

The review focuses on three main points: First, Sixt notes the practical limitations of R's function-based diff highlighting since R scripts often contain code outside functions, which wouldn't get proper hunk headers. Second, he critiques the identifier pattern as potentially worse than the default behavior, suggesting a simpler pattern if full worddiff support isn't ready. Third, he requests squashing the test cases into this initial patch and expanding them to cover indented and nested function definitions.

While Sixt expresses personal frustration with R's unsearchable name, he clarifies this doesn't impact the technical merits of the patch. The review maintains a constructive tone, offering specific suggestions for improvement while recognizing the value of the feature. The feedback indicates the patch needs refinement before being ready for inclusion, particularly around test coverage and pattern matching behavior.
