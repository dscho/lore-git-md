This is a refactoring patch in shejialuo's series modernizing string-list tests and implementation. It simplifies the insertion logic in string-list.c by having `add_entry()` return direct positive indices rather than using negative values to indicate existing elements. 

The change is safe because the negative-index pattern was a historical artifact that was only ever converted back to positive in `string_list_insert()`. Jeff King confirmed this was never needed for `add_entry()`. The patch removes this indirection while maintaining identical behavior, as demonstrated by Patrick Steinhardt's review showing the math works out the same.

This is part of a larger effort to clean up the string-list implementation while converting its tests from shell to C. The series is nearly complete, with only minor documentation and test isolation improvements remaining. This particular patch is straightforward and uncontroversial, representing a clear simplification of the code. The author chose not to inline `get_entry_index()` as suggested, but this doesn't affect the correctness of the change.
