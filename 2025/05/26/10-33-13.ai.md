Signature verification improvement (SSH key type extraction).

This patch extends the signature verification infrastructure to extract SSH key types (like "RSA", "ECDSA") from SSH signature status output, storing them in the existing `sig_algo` field of `struct signature_check`. This parallels the previous work that extracted hash algorithms from GPG signatures, completing the signature metadata handling for both major signing protocols.

The implementation adds a new `extract_ssh_key_type()` helper that carefully parses the key type from SSH's status output format, handling whitespace edge cases. The key type is captured during the existing signature verification flow, with proper memory management through the existing `signature_check_clear()` mechanism. The patch maintains backward compatibility by using the same field (`sig_algo`) for both GPG hash algorithms and SSH key types, as they serve similar informational purposes despite their technical differences.

This change enables richer signature verification reporting and lays groundwork for future signature processing in tools like `fast-export`/`fast-import`.
