Feature addition to `git verify-commit` with verification workflow improvements. This final patch in the v2 series introduces a `--summary` flag that provides concise, script-friendly output of signature verification results in the format `STATUS FORMAT ALGORITHM`. The status comes from the `%G?` pretty format specifier, format indicates the signature type (openpgp/x509/ssh), and algorithm shows either the hash algorithm (for GPG/GPGSM) or key type (for SSH).

The implementation adds a new `GPG_VERIFY_SUMMARY` flag, extends the `struct signature_check` with a `format_name` field, and introduces a `print_signature_summary()` function. Tests verify the output format works correctly for both GPG and SSH signatures, including edge cases like unsigned commits and bad signatures. The summary can be combined with `--raw` output when both detailed and concise information is needed.

This builds on the thread's verification-first approach by providing better tooling for automated processing of verification results, complementing the earlier signature metadata extraction work. The implementation maintains backward compatibility and integrates cleanly with the existing gpg-interface improvements from previous patches in the series.
