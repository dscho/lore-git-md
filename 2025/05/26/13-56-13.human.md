**Platform compatibility and dead code removal in cvsserver**

This email from Ondřej Pohořelský follows up on the thread about removing dead code from git-cvsserver.perl that was causing Perl 5.41.4+ test failures. The discussion has progressed from fixing a specific warning to proposing complete removal of the unused `escapeRefName` function, with confirmation from the original author that this was always intended as unused infrastructure.

Pohořelský notes they've submitted v4 of the patch which now removes the function entirely, resolving both the immediate warning issue and the underlying dead code problem. More significantly, they propose the next logical action would be removing git-cvsserver entirely, given CVS's obsolescence and the original author's admission that the code was never really used. They offer to work on a removal patch if this direction is approved.

The thread shows consensus forming around removing this legacy component, with the dead code removal serving as a first step. The original author's lighthearted skepticism about anyone still using git-cvsserver lends weight to the removal proposal. This appears to be moving toward deprecating the entire cvsserver component, though no formal decision has been stated yet.
