This is a platform compatibility fix and dead code removal for the git-cvsserver Perl script. The patch removes the unused `escapeRefName` function that was causing test failures with Perl 5.41.4+ due to new warnings about operator precedence. 

The function was introduced in 2012 but never used, while its counterpart `unescapeRefName` remained active. After thorough investigation including input from the original author, the community has confirmed this is dead code that can be safely removed. The change fixes test failures in t9402 (tests 30-32 and 34) that occurred when Perl's new static analysis warnings were logged during parsing.

The patch is now in its fourth revision, having evolved from an initial fix for the warnings to a full removal of the unused function. It maintains the still-used `unescapeRefName` while updating its documentation to remove references to the now-deleted escaping counterpart. The change simplifies the codebase while resolving the immediate test failures, though it raises broader questions about git-cvsserver's maintenance given CVS's obsolescence.

Junio Hamano has already queued version 2 of this patch, suggesting it's likely to be accepted. The removal approach is now clearly the preferred solution over just fixing the warning, as it addresses both the immediate issue and longer-term code quality.
