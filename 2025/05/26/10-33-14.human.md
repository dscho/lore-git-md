This is a feature patch adding a `--summary` option to `git verify-commit`, part of the ongoing signature verification improvements series. The patch introduces a concise one-line output format showing signature status, format (OpenPGP/X.509/SSH), and algorithm (hash type for GPG, key type for SSH) - useful for scripting and quick verification checks.

The implementation adds a new `GPG_VERIFY_SUMMARY` flag, extends the `signature_check` struct to track format names, and includes thorough test coverage for both GPG and SSH signatures. The output follows the format `STATUS FORMAT ALGORITHM` (e.g., "G openpgp sha1" or "B ssh ?" for bad signatures). The patch maintains backward compatibility by working alongside existing `--raw` and `--verbose` options.
