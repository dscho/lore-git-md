This is a technical patch in the signature verification improvement series, focusing on extracting hash algorithm information from GPG/GPGSM signatures. It's part of the ongoing effort to enhance Git's verification capabilities for various signature formats (OpenPGP/X.509/SSH).

The change adds logic to parse and store the hash algorithm used in signatures (like SHA-1 or SHA-256) from GPG's machine-readable output. This information was previously discarded during verification. The implementation carefully follows RFC 4880 for OpenPGP hash algorithm mappings and handles both valid and invalid signature cases (VALIDSIG/ERRSIG fields).

The patch appears well-constructed with thorough documentation of the GPG output format and clear mapping of algorithm IDs to names. It maintains the existing error handling patterns while adding the new functionality. This is a focused, technical improvement that builds on the thread's verification-first approach, though it doesn't yet address the outstanding test failures from earlier in the series. The change could be useful for future signature processing in tools like fast-export/import, though that integration remains pending.
