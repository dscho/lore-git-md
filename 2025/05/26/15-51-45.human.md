This is the second patch in a two-part bugfix series for `git send-email`, addressing logging issues when email clients modify Message-IDs. The patch specifically improves how Outlook's Message-ID reassignments are reflected in the final debug logs.

Currently, when Outlook changes a Message-ID during delivery, `git send-email` shows both a notification about the change and a final log with headers - but the final log shows the original Message-ID rather than the modified one. This patch makes the final log show the actual delivered Message-ID, while also moving the change notification to only appear when debug mode is enabled (since the information is now redundant in the main log).

The change is small (4 lines modified), focused on the `send_message` subroutine in `git-send-email.perl`, and appears well-considered. The commit message provides clear before-and-after examples showing the improved behavior. This is the fourth iteration of the patch, suggesting careful refinement based on prior feedback. The change should help developers more accurately track email deliveries when using Outlook servers.
