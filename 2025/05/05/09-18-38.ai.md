This is a feature patch (2/3 in a series) that adds command-line overrides for diff context settings to interactive patch commands. The patch builds on commit 8b91eef812 which made builtins respect `diff.context` and `diff.interHunkContext` configs.

The key changes:
- Adds `-U<n>`/`--unified=<n>` and `--inter-hunk-context=<n>` options to `git add`, `checkout`, `commit`, `reset`, `restore`, and `stash` when used with `--patch`
- The options override the corresponding config settings (defaulting to 3 lines for context and 0 for inter-hunk context if unset)
- Implements proper option validation to ensure the new options are only used with `--patch`
- Updates documentation for the affected commands
- Adds tests verifying the command-line overrides work as expected

The implementation introduces a new `add_p_opt` struct to pass the context settings through the interactive add/patch machinery. The patch appears thorough with documentation updates, test coverage, and proper error handling when options are misused. This provides users more flexibility in controlling diff context without requiring config changes.
