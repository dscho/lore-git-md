This is a documentation patch that enhances the `git-send-email` man page with more practical examples and modern authentication methods. It's part of a three-patch series (this being the second) that improves both technical validation and documentation for email sending.

The patch significantly expands the examples section, adding detailed OAuth2.0 configuration for both Gmail (using OAUTHBEARER) and Outlook (using XOAUTH2). It also introduces a new "SENDING PATCHES" section with clear command-line examples for common workflows like sending single/multiple patches, adding cover letters, and customizing subject prefixes. The documentation now references two community-maintained credential helpers (for Gmail and Outlook) that handle OAuth2.0 authentication.

The changes are well-organized, separating SMTP server configuration from patch-sending workflows. The examples are practical and address real-world needs, particularly around modern authentication requirements where app-specific passwords are being phased out. As part of the v2 series, this revision maintains the core improvements while incorporating minor formatting feedback from the previous round.
