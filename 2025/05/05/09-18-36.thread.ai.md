This thread documents the complete implementation and merge of diff context configuration support for interactive patch commands (add/checkout/commit/reset/restore/stash with --patch), building on commit 8b91eef812 which made builtins respect diff.context and diff.interHunkContext configs. The series was merged into 'next' by Junio C Hamano after incorporating Phillip Wood's test fixes and implementation refinements.

Key technical components:
- New OPT_DIFF_UNIFIED and OPT_DIFF_INTERHUNK_CONTEXT macros (6 existing users each)
- Extended add_p_opt struct with new fields
- Validation rejecting negative context values
- Comprehensive documentation in diff-context-options.adoc
- Test modernization converting 38 grep calls to test_grep and 7 git config calls to test_config in t3701/t4055
- Command-line overrides (-U/--unified and --inter-hunk-context) for all interactive patch commands
- Consistent behavior between config and command-line options
- Final test coverage including basic functionality, negative value rejection, and override behavior
