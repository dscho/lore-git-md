This is a follow-up to the `git whatchanged` deprecation series, addressing build system integration. Patrick Steinhardt points out that the Meson build system needs corresponding updates to stop installing `git-whatchanged` documentation when built without `WITH_BREAKING_CHANGES`. 

The patch moves `git-whatchanged.adoc` from the main manpages list to a new `manpages_breaking_changes` section in meson.build, matching the Makefile change that already excludes it from documentation builds. This ensures consistent behavior across build systems as part of the command's phased removal. The change is straightforward and aligns with the series' goal of cleanly removing the deprecated functionality while maintaining build system integrity.

This appears to be a necessary technical follow-up to Junio Hamano's earlier patch that implemented the conditional compilation of `git whatchanged`. The change is narrowly scoped and uncontroversial, simply completing the build system side of the deprecation work that was already agreed upon in the thread.
