Refactoring patch in the `git gc` decomposition series. This is patch 2/7 in v4 of Patrick Steinhardt's series to complete the replacement of `git gc` with granular maintenance tasks.

The patch simplifies `builtin/gc.c` by removing unnecessary global variables that were used to store command-line arguments for subprocesses (`prune`, `prune_worktrees`, and `rerere`). These variables served no real purpose since they were only used in one place each, and their removal makes the code more straightforward by constructing the command arguments directly when needed.

The change is part of the larger effort to clean up `gc.c` as it's being refactored to support standalone maintenance tasks. The patch maintains all existing functionality while reducing global state - a clear improvement. The only global variable kept is `repack`, which is used in multiple places.

This appears to be a straightforward cleanup with no behavior changes, following good refactoring practice by making incremental improvements while working toward the larger goal. It's a small but sensible step in the series that helps prepare for the more substantial changes coming in later patches.
