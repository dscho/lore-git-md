This is a refactoring patch in Patrick Steinhardt's series to decompose `git gc` functionality into standalone maintenance tasks. It introduces a new helper function `get_worktree_names()` that retrieves worktree names from the `.git/worktrees` directory, replacing direct directory operations in the worktree pruning code.

The patch extracts and generalizes the worktree name collection logic from `builtin/worktree.c` into a new public API function in `worktree.c`. This is part of the larger effort to make worktree pruning available as a standalone maintenance task. The implementation handles error cases (missing directory) and skips dotfiles, returning the names via a `strvec`.

While the change itself is straightforward, there's ongoing discussion about whether this helper is too trivial to warrant a public API, with Eric Sunshine suggesting alternatives. The patch maintains existing behavior while making the code more reusable - a typical preparatory refactoring step in this kind of series.
