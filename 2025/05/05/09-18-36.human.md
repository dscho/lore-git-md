This is a feature patch series improving context line customization in interactive patch commands. The series aims to make `--patch` and `--interactive` modes in commands like `git add`, `commit`, and `stash` behave more consistently with other diff-generating commands.

The key improvements are:
1. Making these commands respect the `diff.context` and `diff.interHunkContext` config settings (previously they ignored these)
2. Adding `--unified` and `--inter-hunk-context` command-line options to override the configs
3. Introducing a new "context" subcommand in interactive mode for `add` and `commit` to dynamically adjust context lines during the session

The changes address a long-standing inconsistency where users had to resort to awkward workarounds like `GIT_DIFF_OPTS` to control context lines in these commands. The implementation touches multiple builtins and adds thorough documentation and test coverage. The series appears well-motivated by prior discussion and cleanly implements the proposed solution across all affected commands.
