This is a follow-up discussion in the reftable test modernization series, specifically about Git's diff configuration for patch submission.

Patrick Steinhardt responds to Seyi Chamber's question about using `--find-renames=90` for the patch series. He explains that without the percentage sign, Git interprets the number as a fraction (where 90 becomes 0.9, equivalent to 90%), and provides the correct syntax (`--find-renames=90%`) for clarity. 

The exchange is part of the broader effort to make the test conversion patches easier to review by ensuring file renames are properly detected in the diffs. Patrick suggests experimenting with the option to achieve optimal reviewability, though this is a minor technical point in the larger test modernization work.
