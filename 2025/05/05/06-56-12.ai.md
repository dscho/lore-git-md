This is a follow-up to the `git whatchanged` deprecation series, specifically addressing the Meson build system integration for the command's removal when built with `WITH_BREAKING_CHANGES`. Patrick Steinhardt points out that the previous patch missed updating Meson's documentation handling, and provides a complementary patch to:

1. Remove `git-whatchanged.adoc` from the main manpages list in meson.build
2. Add it to the `manpages_breaking_changes` section
3. Update the lint-docs-meson Makefile target to exclude git-whatchanged.adoc from validation

The changes mirror the treatment of `git-pack-redundant.adoc` in the build system, maintaining consistency in how deprecated commands are handled. This is a straightforward build system adjustment that completes the technical implementation of the deprecation, though Patrick notes the patch is untested. The change is narrowly scoped to the Meson build configuration and documentation validation, separate from the core deprecation logic implemented in the main series.
