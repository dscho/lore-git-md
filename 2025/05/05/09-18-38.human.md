This is a feature patch that adds command-line options to override diff context settings in interactive patch commands. It's part 2 of a 3-patch series.

The patch introduces `-U<n>`/`--unified=<n>` and `--inter-hunk-context=<n>` options to several Git commands that support interactive patching (`add`, `checkout`, `commit`, `reset`, `restore`, and `stash`). These options mirror the existing config settings `diff.context` and `diff.interHunkContext` but allow per-invocation overrides. The options imply `--patch`/`--interactive` mode.

The implementation is thorough, touching documentation, command implementations, and adding tests. The changes are consistent across all affected commands, with each getting the same new options and validation (the options are only valid with `--patch`). The patch adds tests verifying the command-line options override config settings as expected.

This appears to be a well-considered addition that provides more flexibility for users who want temporary context adjustments without modifying their global Git config. The patch follows established patterns from the existing diff context handling.
