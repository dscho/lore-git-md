This is a feature patch series aimed at improving context line customization in interactive patch commands. The cover letter introduces three patches that collectively enhance how diff context lines are handled across several Git commands (`add`, `commit`, `checkout`, `reset`, `restore`, `stash`) when used with `--patch` or `--interactive` flags.

The series addresses inconsistencies where these commands previously ignored standard diff configuration options (`diff.context` and `diff.interHunkContext`), forcing users to rely on the awkward `GIT_DIFF_OPTS` workaround. The changes introduce proper config support, add command-line overrides (`--unified` and `--inter-hunk-context`), and create a new interactive "context" subcommand for `add`/`commit` to adjust context lines dynamically.

Key technical details include modifications to `add-patch.c` and `add-interactive.c` to handle the new functionality, updates to command documentation across six man pages, and new tests in `t4055-diff-context.sh` verifying the behavior. The implementation appears thorough, with 18 files modified including both plumbing and porcelain commands, suggesting careful consideration of the feature's scope.

The changes align interactive patch behavior with other diff-generating commands like `log -p`, resolving a long-standing inconsistency. The series builds on prior discussion (linked in the cover letter) and appears to be well-motivated by user experience concerns. Test coverage looks comprehensive, with new cases for both config and command-line override scenarios.
