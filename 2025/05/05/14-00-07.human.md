CI/build system follow-up confirming a Meson test output fix. Johannes Schindelin replies to Patrick Steinhardt's patch that addresses test result aggregation differences between Make and Meson builds in CI systems. The original issue, reported by Schindelin, caused GitHub Actions to fail when locating test output files because Meson writes them to the build directory by default rather than the source's "t/" subdirectory.

The fix (a one-line change to `ci/run-build-and-tests.sh`) makes Meson respect the existing `TEST_OUTPUT_DIRECTORY` environment variable while defaulting to the source directory when unset. Schindelin confirms the solution works with a simple "Thank you!" reply, indicating this straightforward fix successfully resolves the CI integration issue.

This concludes the thread with a clean resolution to a build system compatibility problem that primarily affected GitHub Actions workflows. The change maintains backward compatibility while aligning Meson's behavior with Git's existing CI expectations.
