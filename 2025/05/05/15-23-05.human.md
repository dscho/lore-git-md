This is the third and final patch in a documentation series improving `git send-email` authentication support. It adds two new credential helpers (`git-credential-outlook` and `git-credential-gmail`) to the list of OAuth helpers in the gitcredentials documentation. 

The patch is straightforward, simply appending two entries to the existing list of OAuth credential helpers. Both helpers are cross-platform solutions specifically designed for authenticating with Gmail and Outlook when using `git send-email`. The author points to their own GitHub repository hosting these implementations, positioning them as alternatives to the existing `git-credential-oauth` helper.

This change complements the series' earlier documentation improvements around OAuth configuration for email submission.
