This is a refactoring patch that's part of Patrick Steinhardt's v4 series to complete the decomposition of `git gc` functionality. The patch extracts rerere garbage collection from `cmd_gc()` into a new `maintenance_task_rerere_gc()` function, following the pattern established by earlier maintenance task implementations.

The change is straightforward - it moves the rerere GC code that was previously inline in `cmd_gc()` into a dedicated function with the standard maintenance task signature. The new function maintains the same behavior of spawning a child process to run `git rerere gc`, which preserves compatibility with the existing implementation. This prepares for the subsequent patch that will make rerere GC available as a standalone maintenance task.

The patch is part of the larger effort to fully replace `git gc` with granular maintenance tasks, with this being one of the final two missing operations (along with worktree pruning). The implementation follows the established pattern seen in other maintenance tasks, and the series as a whole has already addressed Junio Hamano's concerns about the rerere GC auto-condition heuristic in earlier iterations.
