Documentation patch completing a three-part series on `git send-email` improvements by adding references to external OAuth credential helpers. This final patch updates `gitcredentials.adoc` to list two new helpers (`git-credential-outlook` and `git-credential-gmail`) from the author's GitHub repository. The helpers are cross-platform solutions specifically for authenticating with Gmail and Microsoft Outlook when using `git send-email`. 

The patch follows the same pattern as the existing OAuth helper documentation, providing direct GitHub links and noting platform compatibility. This complements the second patch's expanded OAuth documentation by giving users concrete implementation options. The helpers are positioned as alternatives to the more widely distributed `git-credential-oauth` helper already listed. 

Like the rest of the series, this change addresses modern authentication requirements where traditional app-specific passwords are no longer supported by major email providers. The implementation is straightforward documentation-only addition with no technical changes to Git itself. The patch maintains its focus on the send-email use case despite being in the general credentials documentation.
