This is a documentation patch, part of a v3 series improving `git send-email` functionality. The patch focuses on enhancing the `git-send-email.adoc` documentation with modern authentication examples and practical usage guidance.

The changes introduce several key improvements to the send-email documentation. First, it adds detailed OAuth2.0 configuration examples for both Gmail and Outlook, reflecting current authentication requirements where app-specific passwords are no longer universally supported. The Gmail section now includes both traditional app-password and OAuth2.0 methods, while Outlook documentation specifically addresses its OAuth2.0-only requirement.

Second, the patch adds a new "SENDING PATCHES" section with practical command-line examples covering common scenarios: sending individual patches, multiple patches, cover letters, versioned series, custom subject prefixes, and CC management. These examples provide concrete guidance for users at various experience levels.

Third, the documentation now references community-maintained credential helpers for Gmail and Outlook (pointing to the author's GitHub repository), positioned as alternatives to existing OAuth solutions. The patch maintains links to broader credential helper documentation while adding these specific implementations.

The changes show good attention to detail in modern email authentication requirements and practical workflow needs. The documentation improvements complement the technical fixes in patch 1/3 of this series, though they stand independently as useful guidance for `git send-email` users. The v3 revision includes only minor URL formatting changes from v2, indicating stability in the documentation approach.
