This is a refactoring patch in Patrick Steinhardt's v4 series to complete `git gc` decomposition into standalone maintenance tasks. It removes unnecessary global variables in `builtin/gc.c` that were used to store command-line arguments for subprocesses (`prune`, `prune_worktrees`, and `rerere`), keeping only the `repack` variable which is used in multiple places. The patch inlines the argument construction directly into the child process setup for each command, simplifying the code while maintaining identical functionality.

The changes touch the subprocess execution paths for `git prune`, `git worktree prune`, and `git rerere gc`, moving from a pattern of pre-building argument lists in globals to constructing them at point of use. This eliminates three global `strvec` variables while preserving all existing behavior and error handling. The patch follows the series' pattern of cleaning up `gc.c` as part of the maintenance task extraction effort, though this particular change is independent of the main worktree-prune and rerere-gc functionality being introduced elsewhere in the series.

Key technical details:
- Removes `prune`, `prune_worktrees`, and `rerere` global `strvec` variables
- Keeps `repack` global as it's used in multiple functions
- Modifies subprocess execution for prune/worktree-prune/rerere to build args inline
- Maintains identical command behavior and error messages
- Preserves all existing config handling and condition checks
- Part of broader `gc.c` cleanup but not directly tied to new maintenance tasks
- Follows same code style as rest of file for child process setup
