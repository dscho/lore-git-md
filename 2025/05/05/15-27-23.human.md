Feature patch extending the `scalar clone` command with maintenance control. This is part 3/4 of a series introducing `--no-maintenance` flags across Scalar's repository setup commands.

The patch adds a `--no-maintenance` option to `scalar clone`, allowing users to skip automatic background maintenance setup when creating new repositories. This is useful for scenarios like VM image preparation where manual maintenance is preferred. The implementation follows the pattern established in earlier patches, passing the maintenance flag through to `register_dir()` while maintaining the default enabled state for normal use.

Test coverage includes verification that maintenance is skipped when requested, with trace2 events confirming no unwanted maintenance registration occurs. The documentation is updated to explain the new option alongside existing clone flags. The changes are straightforward and consistent with the series' approach, though the broader architectural discussion about maintenance control placement (noted in the thread context) remains unresolved.
