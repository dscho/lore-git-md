This is an outreach email from an IEEE student program seeking to collaborate with the Git project.

The IEEE Summer of Code 2025 program, run by BMS Institute of Technology & Management, is inviting Git to participate as a mentor organization. The hybrid (online + in-person) program running May-June 2025 would have students contribute to Git under the #IEEESOC25 tag, with a request for PR reviews within 36 hours to maintain momentum. The organizers also suggest optional support avenues like sponsorship, social media promotion, or internship offers for participants.

While not a technical contribution itself, this represents a potential for the Git project to engage with student contributors. The request comes with clear parameters around review turnaround times and offers various levels of organizational involvement. The program appears well-structured with both online and in-person components based in Bengaluru, India.
