This thread addressed a CI/build system issue where test output locations differed between Make and Meson builds, breaking GitHub Actions workflows that expected test results in the source directory's "t/" by default. Johannes Schindelin originally reported the problem, and Patrick Steinhardt proposed a one-line fix making Meson respect the TEST_OUTPUT_DIRECTORY environment variable (falling back to the source directory when unset), matching Make's behavior. Both confirmed the solution worked in testing.

The discussion has now concluded with maintainer Junio Hamano acknowledging the successful resolution. The fix maintains compatibility with existing CI systems while fixing GitHub Workflows integration, and all parties agree the minimal change properly addresses the issue without introducing new problems. This marks another small but important step in the ongoing Meson build system integration effort, where subtle behavioral mismatches with the traditional Make-based build continue to surface and be addressed.
