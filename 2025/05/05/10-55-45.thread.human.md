Johannes Schindelin reported an issue where GitHub Actions test results weren't being properly aggregated in Meson builds, as the output files were being written to the build directory rather than the source's "t/" subdirectory (which Make builds use by default). Patrick Steinhardt proposed a one-line fix in `ci/run-build-and-tests.sh` that makes Meson respect the TEST_OUTPUT_DIRECTORY environment variable, defaulting to the source directory when unset.

Johannes has now confirmed the patch resolves their original issue, with Patrick having already verified it in testing. The solution maintains compatibility with CI systems like GitLab's that explicitly set the output directory while fixing the GitHub Workflows case. This small but important fix addresses one of the subtle incompatibilities that continue to surface as the project transitions between Make and Meson build systems. With Johannes' confirmation, the thread appears resolved with no outstanding questions.
