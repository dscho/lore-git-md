Build system cleanup completing Visual Studio project generation removal. This is the third and final patch in Johannes Schindelin's series removing obsolete build infrastructure, following the deletion of the Visual Studio solution generator scripts in the previous patches. The patch removes the `vcxproj` target from `config.mak.uname` that previously invoked those deleted scripts to generate Visual Studio project files. 

The 76-line deletion eliminates a complex Makefile target that handled multiple build system tasks specifically for Visual Studio integration, including generating project files, managing built-in commands, Perl modules, test wrappers, and translated messages. The commit message notes this cleanup is possible now that CMake is the preferred way to build Git on Windows. 

The change is straightforward technical debt removal with no functional impact, continuing the series' clean removal of unmaintained build system components. The patch maintains the same clear, well-documented approach as the previous changes in the series. With this final deletion, the Visual Studio project file generation system is fully removed from the codebase.
