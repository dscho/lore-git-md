IEEE Summer of Code 2025 participation request from IEEE Student Branch at BMS Institute of Technology & Management. The hybrid (online + in-person) program runs May-June 2025 in Bengaluru, inviting Git to participate by having students contribute via PRs tagged #IEEESOC25. They request maintainers review these PRs within 36 hours, offering optional sponsorship, social media promotion, internships, and swag as incentives. The program website is ieeesoc.xyz. Note this is an invitation rather than technical contribution - the 36-hour PR turnaround request may require maintainer evaluation of feasibility.
