This is a CI/build system cleanup series from Johannes Schindelin, removing several obsolete components. The 3-patch series eliminates support for outdated build systems and CI configurations that are no longer in use.

The first patch stops linking the `prove` cache in CI scripts, which appears to be an optimization that's no longer needed. The second and third patches completely remove support for generating Visual Studio project files (.vcproj/.vcxproj) from the build system, deleting over 1900 lines of now-unused Perl code across multiple files in the `contrib/buildsystems/` directory.

The changes are straightforward deletions with no functional impact on current builds, suggesting these were legacy systems that have been fully replaced by modern alternatives. The series follows Git's typical pattern of periodically pruning dead code to reduce maintenance burden. Given the author's track record with Windows and CI-related contributions, this appears to be a well-considered cleanup of genuinely obsolete components.
