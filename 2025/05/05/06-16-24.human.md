This is the third and final patch in a documentation series improving `git send-email` authentication support. It adds references to two new credential helpers (`git-credential-outlook` and `git-credential-gmail`) to the list of OAuth helpers in the gitcredentials man page. 

The patch links to the author's GitHub repository containing these cross-platform helpers specifically designed for authenticating Gmail and Microsoft Outlook accounts when using `git send-email`. This complements the earlier documentation patch that added detailed OAuth configuration examples for these services.

The change is straightforward - it simply adds two new bullet points to an existing list of credential helpers. The helpers themselves are maintained externally rather than being part of core Git. This completes the series' goal of better documenting modern email authentication methods, particularly for services that no longer support app-specific passwords.

The patch follows the same clean style as the rest of the series, with this being the final piece, the series appears ready for potential merging pending any final review feedback.
