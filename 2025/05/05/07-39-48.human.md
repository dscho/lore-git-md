CI/build system cleanup removing obsolete `prove` cache linking. This is the first of three patches from Johannes Schindelin cleaning up unused build infrastructure components.

The patch removes code that created symlinks to a `.prove` cache directory in CI test scripts. This optimization was originally used to persist test results between CI runs, but became unnecessary when Travis CI support was dropped. The change deletes identical cache-linking logic from both `run-build-and-tests.sh` and `run-test-slice.sh`, totaling 10 lines removed.

As part of a larger series eliminating vestigial build system pieces, this appears to be a straightforward, non-controversial cleanup. The removal is well-justified in the commit message, noting the persisted directory hasn't been used since the Travis CI days. No functional changes to the test system itself - just removing dead code paths.
