CI/build system cleanup completing the removal of Visual Studio project generation support. This third patch in Johannes Schindelin's series removes the `vcxproj` target from `config.mak.uname`, deleting 76 lines of Makefile rules that previously generated Visual Studio solution files. The target depended on the `contrib/buildsystems/generate` script removed in the previous patch, making this a straightforward follow-up cleanup. The deleted code handled various build system tasks specific to Visual Studio projects including generating `.vcxproj` files, creating target files for builtins and remote helpers, adding generated headers/scripts/Perl modules, and committing the generated solution. With CMake now the preferred method for Visual Studio builds, this completes the removal of the legacy project generation system, bringing the series' total deletions to 1950 lines across 13 files. The change is well-motivated and non-controversial, maintaining the series' focus on removing obsolete build infrastructure.
