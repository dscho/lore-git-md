This is a documentation patch, part of a series improving `git send-email` functionality. The patch significantly enhances the `git-send-email.adoc` documentation with practical examples and modern authentication methods.

The changes focus on three main areas: First, it adds detailed OAuth2.0 configuration examples for both Gmail and Outlook, reflecting current authentication requirements where app-specific passwords are no longer supported by some providers. The examples show both the configuration syntax and the rationale for using OAuth in certain cases. Second, it introduces a new "SENDING PATCHES" section with clear command-line usage examples covering common scenarios like sending single/multiple patches, adding cover letters, and customizing subject prefixes. Third, it provides links to community-maintained credential helpers for Gmail and Outlook authentication.

The documentation improvements are thorough and well-organized, separating configuration details from workflow guidance. The examples are practical and cover real-world use cases that users frequently ask about. This is the second patch in a three-part series that started with a technical fix for domain validation and concludes with credential helper documentation. The changes in this v3 revision appear to be minor refinements from previous versions, maintaining the substantive content while making small formatting improvements.
