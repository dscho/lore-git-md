This is a review comment on a test improvement for the interactive patch context series. Eric Sunshine points out a cleanup issue in the test cases added by Leon Michalak's patch. The tests check that `diff.context` is respected by various commands, but use `git config` directly for setup/cleanup rather than the safer `test_config` helper. 

The key observation is that if any command in the test's &&-chain fails before reaching the cleanup step, the config setting would remain, potentially affecting subsequent tests. Eric suggests using `test_config` instead, which automatically handles cleanup regardless of test success or failure. This is a minor but important test hygiene improvement for the series.

The comment doesn't raise any objections to the patch's core functionality (which makes interactive commands respect diff.context settings), but helps ensure the test suite remains robust. This follows the thread's pattern of constructive feedback on implementation details.
