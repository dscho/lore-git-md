This thread has successfully implemented configurable diff context support for Git's interactive patch commands (`add --patch`, `checkout --patch`, etc.), allowing users to control the number of context lines shown during patch selection. The feature works through both configuration options (`diff.context` and `diff.interHunkContext`) and command-line overrides (`-U`/`--unified` and `--inter-hunk-context`).

Leon Michalak led the implementation, which evolved through five versions with significant input from Phillip Wood, who provided test refinements and a final fixup patch. The series modernized test infrastructure (converting 38 grep calls to test_grep and 7 git config calls to test_config), added comprehensive validation (rejecting negative values), and centralized documentation. Junio Hamano has now approved merging the completed work into the 'next' integration branch.

The implementation introduces new OPT_DIFF_* macros used across six commands, extends the add_p_opt struct, and ensures consistent behavior between config and command-line options. With all reviewer feedback addressed and consensus reached, this marks the successful conclusion of a feature that began with config support in commit 8b91eef812 and now delivers a complete solution for controlling diff context in interactive sessions.
