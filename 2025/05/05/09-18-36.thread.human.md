The work builds on earlier changes that made builtins respect diff.context and diff.interHunkContext configurations.

The series has evolved through four versions, with v4 representing the complete implementation. Key developments include test modernization (converting 45 grep and config calls to modern test helpers), comprehensive validation that rejects negative context values, and thorough documentation. The implementation handles both configuration and command-line overrides consistently across all affected commands.

The latest patch completes the work by teaching the add-patch infrastructure to properly read and respect the diff context configurations. It adds fields to track these settings, validates them, and passes them to the underlying diff machinery.
