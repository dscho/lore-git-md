The work builds on earlier infrastructure that made builtins respect these configs.

The implementation has gone through several iterations, with key developments including:
- Dropping an initially proposed interactive subcommand feature to focus on config support
- Adding comprehensive test coverage with modern test patterns
- Implementing validation for negative context values
- Documenting the behavior in a new diff-context-options.adoc file
- Numerous refinements from reviewers, particularly around test organization and edge cases

The series is now functionally complete, with all interactive commands properly handling config values and command-line overrides (-U/--unified and --inter-hunk-context).
