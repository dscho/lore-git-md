This thread has been working through the implementation of diff context configuration support for Git's interactive patch commands (`add --patch`, `checkout --patch`, etc.). The work builds on earlier changes that made these commands respect the `diff.context` and `diff.interHunkContext` configuration options.

The series has gone through several iterations, with v1 exploring an interactive subcommand feature that was later dropped in favor of focusing on config support and command-line overrides (`-U`/`--unified` and `--inter-hunk-context`). Along the way, the tests were modernized, negative context values were rejected, and comprehensive documentation was added. Phillip Wood provided extensive feedback on test organization and coverage, while Junio Hamano raised style and design questions.

The most recent discussion centered on whether specialized `OPT_DIFF_*` macros were justified in the codebase. Phillip Wood successfully defended their use by noting they serve six commands each - more than other specialized option macros in the codebase. Junio has now acknowledged this justification with an "OK. Thanks", which appears to resolve the last major design question.

With all key technical concerns addressed and Phillip's approval of the config reading implementation, the series now seems ready for merging. The remaining work appears to be minor - possibly some final test refinements and documentation polish. The core team (Leon Michalak as primary implementer, with reviews from Phillip Wood and Eric Sunshine) has addressed all substantive feedback, and Junio's acceptance of the architectural decisions suggests this work will likely land in an upcoming release.
