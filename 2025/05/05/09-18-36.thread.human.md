This thread documents the implementation of diff context configuration support for interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The work builds on earlier infrastructure that made builtins respect diff.context and diff.interHunkContext configs, now extending this to interactive commands.

The implementation has evolved through several versions, with v1 initially including an interactive subcommand feature that was later dropped in favor of focusing on config support and command-line overrides (-U/--unified and --inter-hunk-context). The series has undergone thorough review, with test modernization using test_grep and test_config, validation for negative context values, and comprehensive documentation in diff-context-options.adoc.
