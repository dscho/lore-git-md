Feature addition to interactive commands, completing a series about diff context control. This is the third and final patch in a series that began with command-line overrides for diff context settings.

The patch adds a new "context" subcommand to `git add -i` and `git commit -i` that allows interactively changing the number of context lines shown in subsequent diff/patch commands. The implementation:
- Adds the subcommand to the interactive menu (position 7, pushing quit/help to 8/9)
- Implements the interactive prompt for setting context lines (accepts numeric input, shows current value)
- Updates documentation and help text
- Includes tests verifying the context change affects subsequent diff output

The change builds on the previous patches' infrastructure for handling diff context settings, providing an interactive way to adjust them without leaving the session. The implementation appears thorough, with proper documentation updates and test coverage. This completes the series' goal of giving users more control over diff context in interactive sessions.
