This is the final patch in a test modernization series converting reftable unit tests to the Clar framework, now addressing build system cleanup and helper function organization.

The email is a response to Patrick Steinhardt's review of patch 10/10, which moves helper functions from unit-test.{c,h} to lib-reftable.{c,h} and renames them with a `cl_reftable_*` prefix. Patrick had identified several build system simplifications that could now be made since the conversion is complete: removing the now-empty `unit_test_programs` loop in meson.build and simplifying `UNIT_TEST_PROGS` in the Makefile (since only the "unit-test" binary remains).

Patrick also critiques the migration approach, suggesting it would have been cleaner to introduce the helper functions directly in lib-reftable.{c,h} rather than temporarily placing them in unit-test.{c,h}. Seyi seeks clarification on whether Patrick means keeping both old and new helper functions in lib-reftable.{c,h} during the transition.

Key technical points:
- Build system changes in this patch:
  * Removes lib-reftable.o from UNIT_TEST_OBJS in Makefile
  * Adds lib-reftable.o to CLAR_TEST_OBJS
  * Reorders source files in meson.build
- Helper function changes:
  * Renamed from `t_reftable_*` to `cl_reftable_*` prefix
  * Moved from unit-test.{c,h} to lib-reftable.{c,h}
- Open questions:
  * Whether to implement Patrick's suggested build system simplifications
  * Whether the migration approach could have been cleaner by avoiding temporary placement of helpers

The thread shows this completes the three-phase migration (implement Clar equivalents, convert tests, remove old functions) with all reftable tests now using the Clar framework. Patrick's feedback suggests potential follow-up work to clean up the build system and reconsider the migration strategy for future test conversions.
