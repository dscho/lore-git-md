This is a refactoring patch in Patrick Steinhardt's series to decompose `git gc` functionality into standalone maintenance tasks. It extracts the rerere garbage collection code from `cmd_gc()` into a new `maintenance_task_rerere_gc()` function, following the pattern established by previous patches in the series.

The change is straightforward - it moves the existing rerere GC implementation (which spawns a child process to run `git rerere gc`) into a dedicated function with the same signature as other maintenance tasks. This prepares for the next patch which will add rerere GC as a configurable maintenance task.

The patch maintains the exact same behavior while making the code more modular. It's part of the larger effort to fully replace `git gc` with granular maintenance tasks, with this being one of the final missing pieces. The implementation looks clean and follows the established pattern from earlier maintenance task conversions.
