This is the third and final patch in a documentation series improving `git send-email` authentication support. It adds two new credential helpers (`git-credential-gmail` and `git-credential-outlook`) to the list of OAuth helpers in the gitcredentials documentation.

The patch specifically updates `gitcredentials.adoc` to include links to the author's cross-platform credential helpers, which are positioned as dedicated solutions for authenticating Gmail and Outlook accounts when using `git send-email`. The helpers are hosted on the author's GitHub repository and serve as alternatives to the existing `git-credential-oauth` helper mentioned in the documentation.

The v3 revision shows only minor changes from previous versions, primarily shortening the GitHub links while maintaining all substantive content. This patch completes the series' documentation improvements by providing concrete implementation references for the OAuth2.0 authentication methods described in patch 2/3. The helpers address modern authentication requirements where traditional app-specific passwords are no longer supported by major providers.

The patch maintains the series' clean separation between technical fixes (patch 1) and documentation (patches 2-3), with this final addition focusing specifically on credential helper availability. The author notes practical experience using their own `git-credential-outlook` helper, suggesting these are actively maintained solutions rather than theoretical examples.
