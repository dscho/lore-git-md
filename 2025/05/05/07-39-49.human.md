This is the second patch in a 3-part series removing obsolete Visual Studio build system components (vcproj/vcxproj support). The patch removes the generator scripts and supporting Perl modules from `contrib/buildsystems/` that were used to create Visual Studio project files before CMake support was available.

Johannes Schindelin explains that while he previously maintained these scripts to enable building embargoed releases via Azure Pipelines, the effort required is no longer justified now that CMake is the preferred and better-supported build system for Visual Studio. The patch deletes 7 files totaling 1864 lines of code, including the main `generate` script and supporting modules for vcproj/vcxproj generation.

The removal appears straightforward and well-justified, continuing the series' focus on cleaning up unused build infrastructure. No objections or concerns were raised in the initial submission, suggesting this is a non-controversial technical debt removal. The patch maintains the same clean, focused scope as the first patch in the series.
