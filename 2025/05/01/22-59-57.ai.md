This is a refactoring patch that extracts the deprecation warning mechanism from `git pack-redundant` into a core helper as part of establishing a standardized deprecation process.

The patch moves the deprecation warning and die logic from builtin/pack-redundant.c to a new `you_still_use_that()` function in usage.c, making it reusable for other commands. The function takes the command name as a parameter and outputs the standardized deprecation message before dying. The declaration is added to git-compat-util.h for wider accessibility.

A test is added to t5323-pack-redundant.sh to verify the deprecation warning appears when running without the `--i-still-use-this` flag. The test uses test_grep to check for the "nominated for removal" message, ensuring the warning behavior works as intended.

The changes maintain all existing functionality while making the deprecation mechanism available to other commands. The patch is cleanly focused on the refactoring aspect, with the actual application to `git whatchanged` coming in the second patch of the series. This establishes the infrastructure first before using it, following good incremental development practice.

Key technical details for future reference:
- New function: `you_still_use_that(const char *command_name)` in usage.c
- Declaration in git-compat-util.h with NORETURN attribute
- Test verification in t5323-pack-redundant.sh
- Maintains identical warning message and behavior to original
- Part of establishing a standardized deprecation pattern for future commands
