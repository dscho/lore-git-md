This is a refactoring patch that extracts the deprecation warning mechanism from `git pack-redundant` into a reusable helper function. The patch moves the warning message and opt-in requirement (via `--i-still-use-this`) into a new `you_still_use_that()` function in usage.c, making it available for other commands to use when they're being deprecated.

The changes include moving code from builtin/pack-redundant.c to usage.c, adding the function declaration to git-compat-util.h, and including a new test in t5323-pack-redundant.sh to verify the deprecation warning behavior. The patch maintains the same user experience - commands marked for deprecation will show a warning and require the opt-in flag to proceed.

This is the first of two patches in a series aimed at establishing a standard deprecation pattern, with the second patch applying this mechanism to `git whatchanged`. The implementation looks clean and well-tested, following the pattern already established with `pack-redundant`. The changes are focused on infrastructure rather than behavior, making this a straightforward refactoring that should be uncontroversial.
