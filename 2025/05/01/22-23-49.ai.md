This is the second patch in a series introducing a standardized deprecation mechanism for Git commands, specifically targeting `git whatchanged`. The patch builds on the infrastructure established in the first patch (which moved deprecation warnings into a shared `you_still_use_that()` helper) by applying it to `git whatchanged`.

Key technical changes include:
- Adding deprecation warning and flag handling in builtin/log.c using the new helper
- Updating git-whatchanged.adoc with a WARNING section and modern [synopsis] markup
- Modifying t4013-diff-various.sh tests to use the new `--i-still-use-this` flag
- Adding a new test case to check the warning appears without the flag

The author notes two additional test adjustments needed:
- t4202-log needs the flag since it actually checks whatchanged output
- t9300-fast-import should switch to `git log --raw` since it discards whatchanged output

The patch maintains the series' approach of surveying active users via mailing list notifications rather than immediate removal, with `git whatchanged` kept for users who haven't transitioned to `git log --raw`. The work is framed as preparation for potential future removal, though the author notes this isn't yet listed in the 3.0 breaking changes document. The changes touch documentation, command plumbing, and tests while reusing the core deprecation infrastructure from patch 1.
