This is a feature proposal and refactoring series from Junio Hamano, resurrecting his earlier work to make pathname configuration options optionally ignore missing files. The series comes in response to recent discussions about improving `git blame`'s handling of missing `.git-blame-ignore-revs` files, though the solution here is more general.

The three patches provide a way to mark pathname configurations and command-line options as ":(optional)", which makes Git silently ignore the setting if the file doesn't exist. This addresses the core complaint in the blame thread where global ignore-revs configurations fail fatally when the file is missing in some repositories. The first patch is a test cleanup, while the next two implement the optional file handling for configs and command-line options respectively.

Junio notes this is a verbatim resubmission of his 2024 patches that didn't gain traction at the time, with only minor doc updates. The implementation appears solid but lacks centralized documentation for the parse-options case, which Junio jokingly leaves as an exercise. Given the prior lack of review attention, this resubmission may need active shepherding to avoid the same fate, though the current blame discussion provides fresh motivation.
