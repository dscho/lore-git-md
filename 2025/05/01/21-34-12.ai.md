Documentation patch continuing the standardization of option presentation in Git man pages. This is the second in Junio C Hamano's 4-part series to update documentation formatting, following Jean-Noël Avila's earlier work.

The patch updates two commands - `git var` and `git write-tree` - to match the newer documentation conventions. Key changes include converting the SYNOPSIS sections from [verse] to [synopsis] format and consistently backquoting all option names (`-l`, `--missing-ok`, `--prefix=<prefix>/`). The changes are purely presentational, with no behavior modifications.

For `git var`, the patch updates the command syntax and backquotes the `-l` option. For `git write-tree`, it makes similar syntax changes and additionally updates references to the command itself within the description text to use backquotes. The option section now shows `--missing-ok` and `--prefix=<prefix>/` in backquotes, matching the series' goal of consistent formatting.

This continues the established pattern from the first patch in the series (which covered verification commands) and demonstrates the same straightforward application of documentation conventions. The changes appear mechanical and uncontroversial, following prior consensus on documentation formatting. The patch maintains the series' focus on improving grepability and consistency without altering functionality.
