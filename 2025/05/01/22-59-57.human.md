This is a refactoring patch that's part of a series establishing a standardized deprecation mechanism for Git commands. The patch extracts the deprecation warning logic from `git pack-redundant` into a reusable helper function called `you_still_use_that()` in usage.c.

The change moves the warning message and die() call from pack-redundant.c to a central location, making it easier to apply the same deprecation pattern to other commands. The helper function takes the command name as a parameter and shows the same warning message that was previously hardcoded in pack-redundant.c.

The patch also adds a missing test case to verify that `git pack-redundant` properly fails when run without the `--i-still-use-this` flag. This completes the test coverage for the deprecation behavior.

This is the first of two patches in the series, with the second one applying this new mechanism to deprecate `git whatchanged`. The work appears well-structured, with clean separation of concerns between the core infrastructure change (this patch) and its application to specific commands (next patch). The changes are minimal and focused, touching only the necessary files to implement the new helper function while maintaining all existing behavior.
