Thread summary:

This thread concerns a bug in `git apply --intent-to-add` behavior where tracked files are incorrectly marked as deleted in the index. Johannes Altmanninger originally proposed a v3 patch series in 2021 to make `--intent-to-add` imply `--index` as a fix. Jason Cho recently inquired about the patch status, prompting Kristoffer Haugsbakk to investigate and find no record of the patches being merged. Junio Hamano raised technical concerns about the proposed solution, pointing to documentation showing `--index` is not the only way to affect the index (other options like `--cached` and `--3way` also modify it), questioning whether automatically forcing `--index` would create incorrect behavior in some cases.

Ryan Hodges has now demonstrated concrete broken behavior where the current implementation causes serious problems - applying a patch with `--intent-to-add` incorrectly marks unrelated tracked files as deleted in the index. The key technical details are: 1) Current behavior completely replaces the index contents with just the intent-to-add files, which is clearly wrong, 2) Ryan provided a clear reproduction case showing this destructive behavior, and 3) He explained the intended workflow where `--intent-to-add` should help maintain consistency between apply/diff/commit operations for new files.

The core issue remains unresolved but now has stronger evidence of actual harm. The conflict is between the documented behavior (where `--intent-to-add` is ignored unless `--index` is not specified) and the real-world impact (index corruption when using the option as intended). Key participants are Altmanninger (original author), Cho (current inquiry), Haugsbakk (status check), Hamano (maintainer feedback), and now Hodges (demonstrating concrete breakage). The thread awaits either a revised technical proposal addressing all index-modifying scenarios or confirmation that the current behavior is working as intended despite the demonstrated problems. The original patch series may have been abandoned due to maintainer concerns rather than being irrelevant.
