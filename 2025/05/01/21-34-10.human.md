This is a documentation patch series from Junio C Hamano, continuing work started by Jean-Noël Avila to improve consistency in Git's man page formatting. The series focuses on standardizing how command synopses and option descriptions are presented across several man pages.

The changes apply a few key formatting rules: using `[synopsis]` markup instead of `[verse]`, consistently backquoting option names, separating negatable options into their positive and negative forms (like `--opt` and `--no-opt`), and removing non-option descriptions from OPTIONS sections. The patches touch documentation for `git-verify-*` commands, `git-var`, `git-write-tree`, `git-daemon`, and `git-worktree`.

Junio notes that the `git-worktree` changes are still work-in-progress. The series appears to be a straightforward cleanup with no behavioral changes, following established documentation conventions. The changes are mechanical but should improve consistency and make the docs more grep-friendly.
