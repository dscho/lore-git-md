This is a documentation patch series (4 parts) continuing an effort to standardize how command options are presented in Git's man pages. The series follows up on Jean-Noël Avila's earlier work to use `[synopsis]` markup consistently instead of `[verse]`.

The changes focus on three main improvements: consistently backquoting option names throughout the text, splitting negatable options (like `--[no-]opt`) into separate `--opt` and `--no-opt` entries to make them more greppable, and removing non-option descriptions from OPTIONS sections. The patches touch documentation for several commands including `git-verify-*`, `git-var`, `git-write-tree`, `git-daemon`, and `git-worktree`.

Junio notes that the `git-worktree` changes are still work-in-progress. The series makes purely presentational changes - no behavior or functionality is affected. The modifications follow an established pattern from previous documentation standardization work, suggesting this is a low-risk cleanup that maintains consistency across the codebase's documentation.
