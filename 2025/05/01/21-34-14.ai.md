This is the final patch in Junio C Hamano's documentation standardization series, focusing on `git-worktree` man page updates. The patch follows the same pattern as the previous ones in the series, applying three mechanical transformations to improve consistency and grepability: converting SYNOPSIS from [verse] to [synopsis] format, backquoting all option names (like `--force` and `--expire <time>`), and splitting negatable options (such as `--[no-]checkout` into separate `--checkout`/`--no-checkout` entries).

The changes are extensive but straightforward, touching nearly every option in the `git-worktree.adoc` file while maintaining all existing functionality. As with the previous patches, this is purely presentational - no behavior changes are introduced. The patch completes the series' coverage of standardizing option documentation across several Git commands, though Junio notes it's still marked as WIP (Work In Progress), suggesting it may need minor adjustments before final acceptance.

Key files affected are limited to `Documentation/git-worktree.adoc`, with all option references updated to the new format. The patch maintains cross-references to other man pages (like git-checkout and git-branch) while updating their mentions to use the new backquote style. This follows the established pattern from Jean-Noël Avila's earlier synopsis-style conversion work, continuing the project-wide documentation standardization effort.
