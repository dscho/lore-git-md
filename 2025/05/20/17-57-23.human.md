The patch specifically addresses a subtle difference between `git notes copy --stdin` and `git notes remove --stdin` - while the remove command can accept both stdin input and command-line arguments, the copy command cannot. The change adds this clarification to the documentation.

The patch is straightforward, adding just three lines to the git-notes man page to explicitly state this behavioral difference. It follows the pattern established in earlier patches of the series by improving documentation consistency and completeness around stdin handling.
