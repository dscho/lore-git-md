Performance optimization for packfile handling with a focus on reducing syscalls for missing packs in multi-pack-index scenarios. This is a revised version of Patrick Steinhardt's earlier patch series, now incorporating feedback from the thread discussion.

The series addresses a specific performance issue where stale MIDX entries cause Git to repeatedly check for missing packfiles via multiple syscalls (access() and stat()). While the impact is minimal in well-maintained repositories, the optimization is worthwhile given its simplicity. The v2 series represents a significant shift from the initial approach, dropping the unsafe reordering of auxiliary file checks in favor of a more robust solution.

Key changes in v2:
1. Adds documentation explaining the critical ordering requirements for packfile auxiliary files (.keep, .promisor, .mtimes) - they must be created before .idx files and deleted after .pack files.
2. Implements a negative lookup cache in midx.c to avoid repeated failed lookups of missing packs, storing -1 in midx->packs[] for missing entries.

The implementation follows Git's established patterns for type-punned pointers and maintains all safety constraints identified in the thread discussion. The patch demonstrates good attention to detail with clear commit messages and proper handling of edge cases. While the performance gains may be modest in most scenarios, the solution is now properly robust against potential race conditions that were identified in the v1 discussion.

Technical details of note:
- New comment in packfile.c documents the invariant: auxiliary files must exist before .idx files
- midx.c now caches failed lookups via midx->packs[] entries set to -1
- Maintains correct cleanup behavior in close_midx()
- Preserves all existing safety checks while eliminating redundant syscalls

The series shows how the discussion has refined the approach from a simple optimization to one that properly respects Git's packfile handling invariants while still achieving the original goal of reducing syscalls for missing packs.
