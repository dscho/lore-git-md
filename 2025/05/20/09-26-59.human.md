Bugfix for git stash command's option parsing behavior. This patch fixes a regression where "git stash -p <pathspec>" stopped working after a 2020 refactoring. The issue occurred because the code was incorrectly checking argv[0] for the -p flag after the command name was prepended, rather than checking argv[1]. Phillip Wood's fix restores the ability to use pathspecs with the -p flag in the no-verb form (where "git stash" is assumed to mean "git stash push"). The patch includes two new test cases - one verifying the restored functionality and another ensuring malformed commands like "stash <pathspec> -p" are properly rejected. This is part of a two-patch series addressing both the regression and related option parsing improvements, with clear test coverage and a well-explained commit message tracing the history of the issue.
