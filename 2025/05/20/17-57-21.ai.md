Documentation patch continuing the series to improve git-notes documentation, specifically focusing on option formatting. This third patch in the six-part series reorganizes how negated options are presented in the git-notes man page.

The change splits combined `--[no-]option` forms into separate `--option` and `--no-option` entries for both the `--separator` and `--stripspace` options. The author cites Junio Hamano's suggestion (referenced via message ID) that this makes options easier to search for in documentation. The patch maintains all existing functionality while improving readability.

This follows the series' pattern of incremental documentation improvements, building on the previous patches' work to standardize documentation style. The change affects only `git-notes.adoc`, modifying how options are listed without altering their behavior or semantics. The patch is cleanly focused and appears to be a straightforward improvement to documentation organization.
