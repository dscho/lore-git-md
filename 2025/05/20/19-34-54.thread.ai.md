Thread identity: Patch series addressing exec-path security and compatibility issues, specifically preventing Git's internal binaries from being exposed in PATH for non-Git child processes. Originating author is not specified in this summary. This is a technical fix targeting process spawning behavior across platforms, with particular Windows implications.

Core problem: Git currently adds its exec-path to PATH for child processes, which can cause unintended execution of Git's internal binaries by editors and other programs. This has caused real-world issues, including specific problems for Git-for-Windows users with Vim integration. The change aims to make this behavior more secure while maintaining compatibility.
