Feature patch series adding pathspec filtering to `git diff --no-index`.

This is the third version of a series that enables pathspec filtering for `git diff --no-index` comparisons between two directories or files outside a Git repository. The implementation builds on existing pathspec machinery but requires several plumbing changes to work without a repository context.

Key technical details:
- Adds `NO_REPO` flag to pathspec matching to handle repository-less operations
- Modifies `prefix_path()` to support prefixes without trailing slashes
- Exposes match_pathspec_with_flags()` for direct use
- Implements separate pathspec processing for each input path in the diff
- Includes comprehensive tests covering basic and edge cases

The author notes several open questions about the design:
1. Pathspecs must follow the two path arguments (can't be reordered)
2. Pathspecs are interpreted relative to each input path
3. Negative pathspecs require full qualification
4. Concerns about exposing `match_pathspec_with_flags()` API

The series appears well-constructed with thorough test coverage (107 new test lines) and documentation updates. The implementation touches core pathspec handling code, which may warrant careful consideration from maintainers familiar with that subsystem. The author is explicitly seeking feedback on the API design choices and potential alternatives.
