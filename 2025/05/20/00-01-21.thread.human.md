This thread is about adding pathspec filtering support to `git diff --no-index`, allowing users to compare files and directories outside Git repositories with the same pathspec filtering capabilities available in repository contexts. The series, now at v3, has evolved through careful iterations addressing edge cases and refining the implementation.

Jacob Keller has led the implementation, which includes introducing a PATHSPEC_NO_REPOSITORY flag, improving path handling functions, and adding comprehensive test coverage. The current version exposes necessary pathspec matching functionality (via `match_pathspec_with_flags()`) while keeping internal details private. Junio Hamano has been actively reviewing the changes, recently noting some minor style issues with comments but generally approving the technical approach.

Key technical decisions include maintaining strict separation between repository and non-repository pathspec handling, with explicit BUG checks for invalid combinations. The implementation carefully processes pathspecs per input path with proper prefixing, while intentionally limiting some features (like negative pathspecs requiring full qualification) for safety and simplicity.

One ongoing design discussion centers on Jacob's changes to `prefix_path_gently()` regarding slash handling - Junio prefers strict input validation before calling the function, while Jacob's implementation is more lenient. This reflects a broader tension between API contracts and input sanitization that may need resolution before finalizing the series. The patches appear well-tested and thorough, with the final piece now being reviewed to enable directory comparison functionality.
