This thread adds pathspec filtering support to `git diff --no-index`, allowing users to compare files and directories outside Git repositories while filtering with the same pathspec syntax used elsewhere in Git. The series has gone through three iterations, with Jacob Keller as the primary author and Junio Hamano providing detailed review feedback.

The core challenge was maintaining consistent behavior between repository and non-repository contexts while implementing pathspec support. The current version introduces a PATHSPEC_NO_REPOSITORY flag and modifies path handling functions to properly process directory inputs and prefixes. Junio has generally approved the technical approach but suggested improvements to documentation and test presentation.

The latest discussion focuses on edge cases in directory comparison, particularly around glob pattern matching (requiring both DO_MATCH_DIRECTORY and DO_MATCH_LEADING_PATHSPEC flags) and the handling of fully-qualified negative pathspecs. There's agreement that pathspec arguments must follow the two directory/file arguments, maintaining consistency with existing `git diff` behavior.

While Jacob defends some BUG() checks as important programmer safeguards, Junio questions whether they're all strictly necessary. The remaining work appears to be minor documentation tweaks and test improvements. With no major technical objections remaining, this feature looks ready for merging once these final polish items are addressed. Junio notes the historical irony that `--no-index`, originally added as a "selfish" feature for Git's own test suite, has become widely used by others.
