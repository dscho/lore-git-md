API exposure patch for pathspec matching in `git diff --no-index` series.

This patch makes `match_pathspec_with_flags()` public and exposes two previously internal flags (`DO_MATCH_DIRECTORY` and `DO_MATCH_LEADING_PATHSPEC`) while keeping `DO_MATCH_EXCLUDE` private. The change enables the upcoming `git diff --no-index` pathspec support to properly handle directory matching and leading pathspec cases where a pathspec like "src/path/..." should match against "src".

The implementation moves the function declaration from dir.c to pathspec.h with minimal changes - just the function signature and flag definitions. The patch maintains the existing behavior while making these components available to other parts of the codebase. This is a key plumbing change for the larger feature that will allow pathspec filtering in non-repository contexts.

Technical details include:
- Exposed flags: `DO_MATCH_DIRECTORY` (1<<1) and `DO_MATCH_LEADING_PATHSPEC` (1<<2)
- Kept private: `DO_MATCH_EXCLUDE` (1<<0) remains internal to dir.c
- Function signature unchanged except for visibility
- Part of enabling pathspec matching for `git diff --no-index` (patch 2/4 in series)

The change appears straightforward and focused, with the commit message clearly explaining the motivation and scope. As this exposes previously internal APIs, maintainers will want to review the design choice of which flags to expose versus keep private.
