This is a test preparation patch in a series addressing exec-path security issues. It cleans up the test environment in t7005-editor.sh to prevent test pollution between cases.

The patch fixes a subtle issue where environment variables (EDITOR, VISUAL, GIT_EDITOR) and config settings (core.editor) modified by some tests could leak into subsequent tests. The changes ensure each test starts with a known-clean state by:
1. Adding explicit cleanup of environment variables after the initial test block
2. Replacing direct `git config` calls with `test_config` which automatically cleans up after itself

The changes are straightforward and well-contained, focusing only on test hygiene without modifying any production code. This appears to be solid groundwork for the subsequent patches in the series that will modify editor and process-handling behavior. The commit message clearly explains the problem being solved (test pollution) and the solution approach.
