[PATCH v3 0/7] git diff --no-index with pathspec filtering

Series adds pathspec support to `git diff --no-index` for comparing directories/files outside Git repos, completing the functionality in the final patch. Core problem remains enabling pathspec filtering while maintaining consistent behavior between repo and non-repo contexts. Key technical implementation includes PATHSPEC_NO_REPOSITORY flag, modified fixup_paths() and read_directory_contents() handling, with special processing for directory inputs and proper prefixing.

Current version incorporates refined NO_REPO pathspec handling and improved prefix_path() behavior from previous iterations. Technical discussion focuses on pathspec matching behavior details: directory comparison requires both DO_MATCH_DIRECTORY and DO_MATCH_LEADING_PATHSPEC flags for correct glob pattern matching, negative pathspecs must be fully qualified from root directory being compared, and pathspec arguments must follow the two directory/file arguments.

Recent discussion between Jacob Keller and Junio Hamano clarifies the split validation design between parse_pathspec (flag validation) and match_pathspec_item (runtime assertions). The BUG() check for NULL istate with PATHSPEC_ATTR serves as a safeguard against invalid combinations where attribute-based pathspecs would be attempted without an index, even though match_pathspec() doesn't receive PATHSPEC_NO_REPOSITORY flag directly. Both maintainers agree this layered validation is sound.
