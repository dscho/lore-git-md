Feature patch adding pathspec support to `git diff --no-index` when comparing directories. This is part 4/4 of a series enabling pathspec filtering for non-repository diffs, building on earlier infrastructure changes.

The patch teaches `git diff --no-index` to accept pathspec arguments when comparing two directories, allowing users to limit which files are included in the diff output. The implementation handles several edge cases:
- Pathspecs must come after the two directory paths (matching `git diff-tree` behavior)
- Pathspecs are interpreted relative to each input directory
- Negative pathspecs require full qualification
- Directory matching requires careful handling of DO_MATCH_LEADING_PATHSPEC and DO_MATCH_DIRECTORY flags

The change includes extensive test coverage (107 new test lines) verifying the new behavior works as expected, including glob patterns and exclude pathspecs. The documentation is updated to reflect the new capability.

This appears to be a well-considered implementation that maintains consistency with repository-based diff behavior while properly handling the no-repo case. The patch addresses all the open questions raised in earlier versions of the series and provides thorough test coverage.
