This thread began as a discussion about security concerns with Git exposing internal binaries in PATH, but evolved into a focused effort to modernize editor-related test infrastructure. D. Ben Knoble is leading a 3-patch series that refactors t7005-editor.sh to use better isolation practices (subshells and test helpers) and updates the editor API to use strvec for environment handling. The changes are behavior-preserving but improve test reliability and maintainability.

Phillip Wood has been the primary reviewer, helping refine the approach and catching subtle issues like proper error propagation in subshells. The series initially used `return 1` for subshell error handling, but Eric Sunshine confirmed that `exit 1` is actually needed to properly propagate failures. This level of attention to test robustness is characteristic of the project's quality standards.

The patches have received positive feedback and are nearly ready for submission as v2, needing only minor administrative fixes (version labeling and CI issues). The technical content is settled, with test modernization, subshell isolation, and strvec conversion all agreed upon. This represents a solid step forward in test infrastructure while leaving the broader question of script assumptions about Git's installation layout for future work.
