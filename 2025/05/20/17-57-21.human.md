This is the third patch in a documentation series improving `--stdin` usage and comment character references across several Git commands. The patch focuses specifically on reorganizing the options documentation in `git-notes.adoc` to make negated options (`--no-*`) more discoverable.

The change splits combined option entries like `--[no-]separator` into separate lines for the positive and negative forms, following a style suggestion from Junio Hamano. This makes the documentation more scannable and helps users searching for specific option forms. The patch applies this change consistently to both the `--separator` and `--stripspace` options in the git-notes manpage.

As part of a larger documentation cleanup effort, this is a straightforward improvement that follows established patterns while making the manual pages more user-friendly. The change is small but meaningful for documentation usability, and the patch follows the series' pattern of focused, incremental improvements.
