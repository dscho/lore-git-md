This is a finalized 2-patch series implementing a hidden `--skip-connectivity-check` option for `git receive-pack`, specifically for GitLab's Gitaly service. The series comes after mailing list feedback and represents a collaboration between GitLab engineers and Git maintainers.

The first patch establishes test infrastructure in `t5410-receive-pack.sh`, consolidating previous test files and verifying baseline connectivity check behavior. The second patch implements the actual option as a hidden flag (preventing casual use) that allows bypassing `receive-pack`'s object graph validation when GitLab's transaction system has already performed equivalent checks.

The implementation is technically sound with thorough test coverage, including verification that the repository remains intentionally unconnected after bypassing checks. Documentation clearly warns about corruption risks and frames this as a GitLab-specific optimization case. The Gitaly service's transaction system provides the necessary guarantees about object connectivity that make this safe in their environment.
