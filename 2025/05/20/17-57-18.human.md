This is a documentation patch series focused on improving clarity around `--stdin` usage in git-notes and `core.commentChar` configuration. Kristoffer Haugsbakk noticed inconsistencies while working on the notes documentation and expanded the scope to related areas.

The series makes several small but useful improvements: it documents where default comment characters come from in `git-stripspace`, adds cross-references between `core.commentChar` and `commit.cleanup` configs, and reorganizes the notes documentation to better handle options with negations. The most notable changes clarify how `--stdin` works equally for both `git notes copy` and `git notes remove` commands, and explicitly mentions when command-line arguments should be used with `--stdin`.

The patches appear well-focused and non-controversial, addressing clear documentation gaps.
