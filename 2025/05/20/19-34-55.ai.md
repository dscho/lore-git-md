Test preparation for exec-path security series. This is the first of four patches in a series addressing security and compatibility issues around Git's exec-path exposure in child process environments. The patch focuses on cleaning up the test environment in t7005-editor.sh to prevent test pollution.

The changes ensure editor-related tests don't leak environment variables (EDITOR, VISUAL, GIT_EDITOR) or config settings (core.editor) between test cases. The key modifications are:
- Explicitly unsetting editor-related variables after their test block
- Replacing direct `git config` calls with `test_config` which automatically cleans up
- Removing redundant `unset GIT_EDITOR` that was previously needed due to pollution

This groundwork is important for the subsequent patches in the series that will modify editor and subprocess behavior, as it ensures test results aren't affected by leftover state. The changes are straightforward test hygiene improvements with no expected controversy, though they do touch the same test file that will be used to verify the main behavior changes later in the series.
