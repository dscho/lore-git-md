This is part 12 of Jeff King's series removing support for non-standard object types in Git. The patch simplifies how the `--literally` flag is handled in `git hash-object`.

The change replaces a boolean flag for `--literally` with an `OPT_NEGBIT` option that directly modifies the `INDEX_FORMAT_CHECK` bit in the flags parameter. This eliminates the need to pass around a separate `literally` boolean through several helper functions, making the code more straightforward. The patch removes 16 lines while adding 11, for a net reduction of 5 lines.

This continues the series' trend of simplifying the object handling code after removing the non-standard type support. The change is mechanical and unlikely to be controversial, building on the foundation laid by earlier patches that removed the `hash_literally()` function. The patch maintains all existing functionality while making the implementation cleaner.
