Performance optimization for `git reset --patch` with sparse index. This is the third patch in Derrick Stolee's series integrating interactive commands with the sparse index, following similar changes for `git add -p` and `git checkout -p`. The patch moves the sparse index check earlier in `cmd_reset()` to prevent unnecessary index expansion when using `--patch`.

The changes are straightforward - moving the `command_requires_full_index=0` setting before the patch mode logic in `builtin/reset.c`. The test additions verify that:
1. The sparse index isn't expanded for in-cone changes
2. It does expand for out-of-cone edits (matching the established pattern)
3. The behavior matches full index operation

Elijah Newren gives his approval, noting the patch follows the same proven pattern as the other interactive command optimizations in the series. This completes the sparse index integration for the main interactive commands, with performance tests showing 95.6% speedup for `git reset --patch` on sparse checkouts.
