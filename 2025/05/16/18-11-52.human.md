Feature patch introducing path-based delta compression in pack-objects.

This is patch 2/13 in a series introducing the new `--path-walk` option for `git pack-objects`, which reorganizes delta compression to first group objects by path before doing cross-path compression. The approach shows promise for improving compression, particularly for repositories with filename hash collisions.

The patch adds the core `--path-walk` option and implements the basic functionality in `builtin/pack-objects.c`, though it notes several current restrictions: no threading support yet, incompatibility with filters/delta-islands/shallow options, and bitmap index ignoring. The implementation handles both regular and thin packs, with new tests verifying basic functionality.

The commit message is thorough, explaining both the current limitations and planned future improvements. Documentation updates clearly explain the option and its restrictions. Performance testing will come in later patches, but early indications suggest this could significantly improve compression for certain repository structures.

As part of a well-structured series that has already gone through multiple review iterations, this patch appears ready for inclusion, with the understanding that threading optimizations will follow in later commits. The implementation is clean and maintains existing functionality while adding the new path-walk capability.
