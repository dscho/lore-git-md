Jeff King (Peff) continues his series to remove support for non-standard object types from Git's core with patch 9/13. This installment introduces a new test helper library `t/lib-loose.sh` that provides a `loose_obj` function for creating loose objects directly in the object database, bypassing `git hash-object`. 

The `loose_obj` helper gives tests low-level control to create objects that would normally be rejected, including those with invalid types. This allows the series to maintain test coverage while removing the `--literally` option from `hash-object` in upcoming patches. Three test scripts (`t1006-cat-file.sh`, `t1450-fsck.sh`, and `t1512-rev-parse-disambiguation.sh`) have been converted to use this new approach.

The changes are mechanical and don't alter test behavior - they provide an alternative way to create test objects as the series works toward completely removing non-standard type support. The helper handles platform-specific edge cases and works with both Makefile and meson builds. So far the series has seen no objections, with the technical approach appearing sound as it systematically removes unused functionality while preserving testing capabilities.
