This thread documents Jeff King's (Peff) completed 13-patch series removing support for non-standard object types in Git's core object handling. The series has now received full technical approval from maintainer Junio Hamano, with all substantive changes agreed upon. The work simplifies Git's object handling by eliminating a decade-old experimental feature that never matured beyond testing purposes.

The discussion has narrowed to just two minor points: a stylistic preference about a test helper's loop structure (where Junio noted an alternative approach but didn't insist on changes) and the documentation approach for making `--allow-unknown-type` a no-op (where Jeff prefers minimal documentation while Patrick Steinhardt suggests a more explicit deprecation notice). With the technical implementation settled, the series appears ready for merging once this final documentation question is resolved. The new `test-tool zlib` helper and `t/lib-loose.sh` library introduced in the series provide useful infrastructure for future object format testing.
