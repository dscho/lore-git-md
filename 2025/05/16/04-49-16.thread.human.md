Jeff King's series to remove support for non-standard object types in Git is now complete with the addition of the final patch. The 13-part series has systematically eliminated both read-side and write-side handling of these experimental object types, which were never properly usable beyond testing scenarios. 

Junio Hamano has approved all technical aspects of the implementation, including the new test infrastructure (the `t/lib-loose.sh` helpers and `test-tool zlib`) that replaces the old testing approach. The final patch removes `write_object_file_literally()` and its helper functions, cleaning up a parallel implementation that had become problematic, particularly for Patrick Steinhardt's ongoing ODB abstraction work.

Only one minor open question remains regarding documentation: whether to explicitly mark `--allow-unknown-type` as a no-op in the manpage (as Patrick Steinhardt suggested) or rely on release notes (Jeff King's preference). This documentation decision doesn't affect the code changes, which are complete and appear ready for merging. The series represents a significant simplification of Git's object handling code by removing a decade-old experiment that never matured beyond its original testing purpose.
