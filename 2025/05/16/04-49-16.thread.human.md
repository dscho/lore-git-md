Jeff King's series to remove support for non-standard Git object types has reached consensus and is ready for merging. The 13-patch series systematically eliminates code that was originally added to test how Git handles unknown object types, but which had become scattered maintenance burden without real-world use cases. 

Junio Hamano, the Git maintainer, has now weighed in with historical context confirming these object types were never intended for production use - only for testing edge cases. This aligns with Jeff's original rationale and Patrick Steinhardt's thorough reviews across the series. The removal particularly benefits Patrick's ongoing ODB abstraction work by eliminating problematic parallel implementations.

The series introduces useful test helpers (`test-zlib` and `lib-loose.sh`) that maintain coverage while allowing the core code simplification. The only minor outstanding item is whether to incorporate Patrick's suggestion to document the deprecation path more explicitly in patch 2/13, but the technical work is complete. With both reviewers and the maintainer in agreement that this doesn't need to wait for Git 3.0, the series appears ready to be picked up for the next release.
