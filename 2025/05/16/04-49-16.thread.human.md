Here's the updated human-readable thread summary:

Jeff King has proposed removing Git's long-dormant support for non-standard object types in a 13-patch series. The changes systematically eliminate both read and write-side handling of these experimental types, which were never properly usable beyond test cases. The series is now complete at version 1, with all technical work finished - the final patch removes the last remaining write-side support code.

Patrick Steinhardt has weighed in on patch 2/13, which makes the `--allow-unknown-type` option a no-op in `git cat-file`. While fully agreeing with the removal direction, Patrick suggests two small improvements: adding a test to verify the option still parses correctly (despite being non-functional), and more explicitly documenting its deprecated status with a note about planned removal in Git 3.0. These are straightforward suggestions that Jeff will likely incorporate.

The discussion remains focused on implementation polish rather than fundamental disagreement. With all technical aspects now addressed and no objections raised to the core changes, the series appears ready for merging. The only remaining question is whether this needs to wait for Git 3.0 - Jeff argues it doesn't, since the functionality was never properly usable in practice.
