This is the final patch in Jeff King's series removing support for non-standard object types in Git's core. 

Patrick Steinhardt responds to patch 13/13, which removes the now-unused `write_object_file_literally()` function and its helpers. The removal eliminates duplicate code paths that had been maintained in parallel with `write_object_file()`, particularly around tricky loose object map updates. 

Patrick notes he had recently been looking at this same code while working on pluggable object databases, finding attempts to unify the paths unsatisfactory. He expresses appreciation for the clean removal approach, which simplifies future work in that area.

The patch appears to be the natural conclusion of the series' work - with `git hash-object --literally` no longer supporting unknown types, these functions have no remaining callers. The removal reduces maintenance burden and potential for bugs from duplicated logic. Patrick's positive reaction suggests this is uncontroversial and likely ready for merging.
