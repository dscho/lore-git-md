It focuses on two technical clarifications for new contributors: properly documenting the `UNUSED` macro (which suppresses compiler warnings for unused parameters) and updating the `cmd_psuh` function signature to include the now-standard `struct repository *repo` parameter.

The changes demonstrate modern Git practices by showing how to mark unused parameters with the `UNUSED` macro (a common pattern in the codebase) and how built-in commands should properly receive the repository parameter. The patch also shows when to remove the `UNUSED` markers when parameters are actually used later in the tutorial.
