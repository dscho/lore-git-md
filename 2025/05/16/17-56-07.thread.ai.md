MPTCP support thread summary:

This thread introduces Multipath TCP (MPTCP) support for Git on Linux systems. The initial patch enables automatic use of MPTCP when available on the host system, falling back to regular TCP otherwise. The implementation specifically supports IPPROTO_MPTCP v1, which improves upon v0 in handling middlebox limitations. MPTCP operates at layer 4, enabling bandwidth aggregation across multiple network paths and seamless failover during network disruptions.

The change modifies socket creation code to use IPPROTO_MPTCP when available, with no behavior change on systems without MPTCP support. The patch targets Linux specifically and activates the feature automatically based on system capability, requiring no new configuration options. The commit message explains MPTCP's technical background but does not yet detail specific Git operations that would benefit from this capability (such as which commands might see improved performance or reliability from multipath networking). The implementation appears straightforward with runtime detection of MPTCP availability.
