This is a v2 patch in the ongoing discussion about the thunderbird-patch-inline contrib script, proposing to update rather than remove it. Phillip Wood has revised his earlier patch to address Junio C Hamano's code review feedback by removing the now-unused SEP variable definition.

The patch updates the script to work with the maintained External Editor Revived Thunderbird extension instead of the original unmaintained ExternalEditor. Key changes include modifying the header/body separator detection logic in appp.sh (now using a regex pattern for CR/LF line endings) and updating the README to reference the new extension. The technical implementation appears sound, with the v2 addressing the code quality issue from the previous review.

This keeps the thread's core debate unresolved - whether to maintain this niche tool now that it has a maintained dependency, versus Patrick Steinhardt's original removal proposal based on broader maintenance concerns. The patch itself is technically complete and ready for consideration, leaving only the higher-level policy decision about contrib script maintenance standards.
