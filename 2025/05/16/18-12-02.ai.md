This is a feature patch adding shallow clone optimization to the path-walk delta compression series. It introduces an 'edge_aggressive' mode that ensures all trees and blobs reachable from UNINTERESTING commits are properly marked during shallow operations, preventing unnecessary object transfers.

The patch adds a new boolean flag to the path_walk_info struct that triggers the existing revision.c edge_hint_aggressive behavior when set. This is particularly useful for shallow clones where boundary commits need more thorough marking to avoid sending extra objects during fetches and pushes. The implementation connects this to the path-walk API while maintaining the existing revision walk behavior.

Key technical details include:
- New edge_aggressive field in path_walk_info struct
- Integration with mark_edges_uninteresting() via revs->edge_hint_aggressive
- Documentation update explaining the shallow clone use case
- Test helper support via --edge-aggressive flag
- New test case in t6601-path-walk.sh verifying UNINTERESTING marking behavior

This completes the shallow clone support for the path-walk feature, building on the earlier parallel processing optimizations.
