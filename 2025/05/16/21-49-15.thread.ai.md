Bug report about symlink regression in Git 2.49.0 on Windows. Reporter Chris Conti describes a custom difftool alias `diffdirsym` that temporarily enables symlinks via `-c core.symlinks=true` failing with "Function not implemented" error during directory diff operations, despite working in Git 2.48.1. The issue occurs when creating symlinks for changed files in temporary locations during `difftool --dir-diff` with Beyond Compare. Environment: Windows 10, PowerShell 5.1, Git built with OpenSSL 3.2.4. Key technical detail: Windows symlink creation appears broken in 2.49.0 during temp file setup for dir-diff operations, representing a regression from 2.48.1 behavior.
