This is a documentation and UX patch that finalizes the implementation of prepending '#' to commit descriptions in interactive rebase todo lists to clarify they are comments rather than directives. The patch follows up on previous discussion where the approach was approved by maintainers Phillip Wood and Junio C Hamano.

The key technical changes in this v2 revision:
- Simplifies the test change in t5520 to use `grep -v -e ^\# -e ^$` as suggested by Ben Knoble, replacing the previous sed-based approach
- Maintains all other aspects of the initial implementation that were already approved:
  - Hardcodes '#' prefix in sequencer.c output rather than using comment_line_str
  - Updates test expectations across multiple test files (t3404, t3415, t3430, t7512)
  - Preserves existing merge directive handling that also uses '#'

The patch rationale remains unchanged - to prevent user confusion by making it visually obvious that commit messages in rebase todo lists are informational comments that should not be edited directly. The implementation is now fully resolved with all test adjustments finalized and no remaining open questions from the maintainers.
