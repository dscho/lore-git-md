This is the final discussion in Jeff King's series removing support for non-standard object types from Git's core. Junio Hamano, the Git maintainer, weighs in to clarify the original purpose of the non-standard type support and express support for its removal.

Hamano notes that the non-standard types were never intended as an experiment in expanding Git's object model, but rather as a testing mechanism to verify how Git handles unknown object types. He expresses surprise at how widely this testing infrastructure had spread through the codebase, requiring 13 patches to fully remove.

The maintainer's approval is significant as it addresses Jeff's earlier concern about whether this change needed to wait for Git 3.0. Hamano's stance suggests the removal is likely to proceed, having now received both technical reviews from Patrick Steinhardt and conceptual approval from the maintainer. This appears to be the final green light for the series after all technical aspects were addressed in the earlier patches.
