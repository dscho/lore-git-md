Performance optimization for packfile handling when dealing with missing packs. The patch reorders checks in `add_packed_git()` (packfile.c) to avoid unnecessary `access(3p)` syscalls for auxiliary files (.keep, .promisor, .cruft) when the main packfile doesn't exist. Current behavior wastes syscalls by checking auxiliary files first; new behavior verifies pack existence via `stat()` before proceeding. Fix addresses an edge case where stale multi-pack-index references cause excessive syscalls for missing packs, reducing them by 75%. Changes are localized to operation order in `add_packed_git()` with packfile name restoration after auxiliary checks. Author considered but rejected adding a negative lookup cache as over-engineering. Low-risk optimization with minimal code impact that benefits pathological cases without affecting normal repository operations.
