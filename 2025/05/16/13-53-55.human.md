This is a maintenance patch for the Thunderbird integration script in Git's contrib directory. Phillip Wood has updated the "thunderbird-patch-inline" script to work with a maintained fork of the previously unmaintained ExternalEditor extension, addressing a technical concern raised in the ongoing discussion about whether to keep or remove this contrib script.

The patch makes two main changes: updating all references from the old ExternalEditor to the new External Editor Revived fork, and modifying the message header/body separator logic to match the new extension's behavior. Phillip has also addressed Junio C Hamano's code review from the previous version by removing the now-unused SEP variable definition.

While this provides a technically sound update path, the broader question remains open - should this niche tool be kept in contrib now that it has a maintained dependency, or removed as originally proposed by Patrick Steinhardt due to limited usage? The patch itself is clean and properly addresses the technical requirements, but the policy decision about keeping contrib scripts with narrow use cases is still under discussion.
