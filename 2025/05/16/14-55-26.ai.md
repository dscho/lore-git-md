This is a performance optimization series integrating the sparse index with interactive commands (`git add -p/-i`, `git checkout -p`, and `git reset --patch`), building on prior work to make these commands sparse-index aware. The series demonstrates substantial speedups (96.7% reduction for `git add -p`) by avoiding unnecessary index expansion in sparse-checkout scenarios.

Key technical changes in v2:
- Fixed test assumptions about index expansion behavior between `git add -p` and `git add -i` (both now expand when editing out-of-cone files)
- Added optimizations for `git reset --patch` (95.6% speedup) following the same pattern as `cmd_add()`
- Confirmed `git checkout --patch` already benefits from existing `git apply` optimizations (91.6% speedup)
- Updated test assertions to properly model `git apply --cached` behavior with partially expanded indexes
- Added comprehensive performance tests in `p2000-sparse-operations.sh` showing consistent improvements across index versions

The implementation follows established sparse-index patterns:
- Sets `command_requires_full_index=0` in `builtin/apply.c`, `builtin/add.c`, and `builtin/reset.c`
- Maintains test coverage in `t1092-sparse-checkout-compatibility.sh` with both `ensure_expanded` and `ensure_not_expanded` checks
- Handles edge cases where commands must expand for out-of-cone edits while optimizing the common in-cone case

The series has addressed all feedback from Elijah Newren and Phillip Wood's reviews, with Junio Hamano indicating readiness for inclusion. The performance improvements are validated through rigorous testing, with the sparse index integration maintaining all existing functionality while optimizing interactive workflows.
