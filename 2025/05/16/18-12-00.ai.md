Refactoring patch in the path-walk delta compression series, focusing on separating path-walk grouping from delta computation.

This patch (10/13) restructures the path-walk delta compression phase in `pack-objects` to improve progress reporting and prepare for future threading support. The key change moves delta computation out of the path-walk phase itself, instead storing path-based object groups in a new `packing_region` structure for later processing. This creates clearer progress indicators by separating the object enumeration phase from delta compression.

The implementation introduces:
- `packing_region` struct to track path-based object ranges in `packing_data`
- `find_deltas_by_region()` to process stored regions with proper progress reporting
- Removal of inline delta computation from `add_objects_by_path()`
- New progress message "Compressing objects by path" verified in tests
- Removal of a now-unnecessary test workaround in t5530

The changes maintain all existing functionality while improving the code structure for future threading work mentioned as coming in the next patch. Test updates confirm the new progress reporting works as expected. This appears to be a well-justified intermediate step in the larger path-walk optimization effort, with clean separation of concerns and thorough test coverage.
