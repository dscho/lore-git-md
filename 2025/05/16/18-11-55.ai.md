Performance test infrastructure patch for the path-walk delta compression series.

This patch introduces GIT_TEST_PACK_PATH_WALK, a test environment variable that enables path-walk delta compression by default in pack-objects when set. The variable helps validate the path-walk implementation by running existing tests with the new algorithm, revealing tests that make assumptions about the default object walk behavior.

Key technical details:
- Modifies builtin/pack-objects.c to check GIT_TEST_PACK_PATH_WALK when path_walk is unset (-1)
- Documents the variable in t/README
- Updates several test scripts that need adjustment when path-walk is enabled:
  - t0411-clone-from-partial.sh and t5306-pack-nobase.sh disable it for boundary object tests
  - t5310-pack-bitmaps.sh explicitly uses --no-path-walk for bitmap comparisons
  - t5316-pack-delta-depth.sh avoids path-walk to preserve delta chain tests
  - t5332-multi-pack-reuse.sh disables it to maintain preferred pack behavior
  - t5530-upload-pack-error.sh works around temporary error message differences
  - t7406-submodule-update.sh prevents warning messages

The patch identifies specific test cases where path-walk either isn't compatible (missing boundary objects) or would change expected outcomes (delta chains, bitmap comparisons). These are marked with comments explaining the temporary nature of some exclusions. The implementation handles these cases while allowing broader test coverage of the path-walk feature.
