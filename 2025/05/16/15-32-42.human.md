This is a test patch in the ongoing `--walk` delta compression series, specifically adding verification for shallow push behavior. The patch adds two test cases that confirm proper delta compression during shallow pushes by examining progress output. 

The first test verifies the object count when pushing a new commit from a shallow clone, while the second (more interesting) test checks whether delta bases are properly found by looking for "bytes" vs "KiB" in the progress output - the former indicating successful delta compression. Taylor Blau had suggested alternative verification methods, but Derrick Stolee defends the high-level approach as better matching real user behavior despite being more fragile than inspecting packfiles directly.

This appears to be a well-considered test addition that completes the shallow clone verification for the path-walk feature.
