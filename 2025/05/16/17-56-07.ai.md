This is a feature patch adding MPTCP (Multipath TCP) support for Linux systems. The change enables Git to use MPTCP when available on the host system, falling back to regular TCP otherwise.

The patch introduces support for IPPROTO_MPTCP v1, which the author notes has improvements over the older v0 protocol in handling middlebox limitations. MPTCP operates at layer 4 of the OSI stack, allowing bandwidth aggregation across multiple network paths (similar to layer 2 link aggregation) and providing seamless failover when a network path becomes unavailable.

The implementation appears straightforward - it checks for MPTCP availability at runtime and uses it if present, with no behavior change on systems without MPTCP support. The commit message explains the technical background of MPTCP but doesn't provide specific Git use cases that would benefit from this capability (such as which Git operations might see improved performance or reliability).

No new configuration options are added - the feature activates automatically based on system capability.
