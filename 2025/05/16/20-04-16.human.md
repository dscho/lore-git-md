This is the final version of Elijah Newren's feature addition to `git merge-tree`, introducing a `--quiet` option for efficient mergeability checking. The series has gone through several naming iterations (originally `--mergeability-only`, then `--dry-run`) based on feedback from Junio Hamano and Phillip Wood about interface consistency. The current `--quiet` name better matches Git's conventions for silent operation modes.

The patch provides two key optimizations for hosting platforms that only need to check if branches can merge: (1) early exit when conflicts are detected, avoiding full merge computation, and (2) skipping object writes for outer merges (with documented edge cases where writes still occur). The implementation includes thorough test coverage verifying empty output, correct exit codes, and no object writes in the expected cases.

The series is approved for merging, with this final version addressing the naming concern raised in previous rounds. The changes are well-contained to merge-ort internals and the merge-tree command-line interface, with comprehensive documentation of both behavior and limitations. This provides a clean solution for Git forges needing lightweight merge checks.
