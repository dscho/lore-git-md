Build system patch refining GIT_EXEC_PATH handling in Meson build.

This patch from Ramsay Jones aligns the Meson build system's GIT_EXEC_PATH behavior with the Makefile implementation. The key change makes Meson default to the relative path 'libexec/git-core' rather than an absolute path, matching Make's behavior. When users specify a custom libexecdir via `-Dlibexecdir`, it will use that path (absolute or relative) unless runtime_prefix is enabled, in which case absolute paths are rejected for consistency with Make's requirements.

The patch introduces new logic to:
1. Default to 'libexec/git-core' string
2. Only override if libexecdir differs from 'libexec' or '.'
3. Enforce relative paths when runtime_prefix is true
4. Maintain the same error behavior as Make for invalid configurations

This completes the path standardization work in the build system series, specifically for the git-core executable location. The changes ensure cross-build-system consistency while preserving the same configuration flexibility as the Makefile. The implementation follows the same constraints as Make, particularly around runtime_prefix requirements, and has been verified against multiple Git branches.
