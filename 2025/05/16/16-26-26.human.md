This is a documentation and UX patch that finalizes the change to prefix commit descriptions in interactive rebase todo lists with '#' to clarify they are comments, not directives. The patch has already gone through review and discussion, with all technical questions resolved.

The change addresses user confusion where people would mistakenly edit commit messages in the todo list, not realizing these are just informational comments. By adding the '#' prefix (similar to how merge directives already work), it makes the comment nature visually obvious. The implementation hardcodes '#' rather than using the more flexible comment_line_str, as this matches existing merge directive behavior and better serves the goal of discouraging edits to these lines.
