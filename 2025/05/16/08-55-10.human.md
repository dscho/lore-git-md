This is a performance optimization patch targeting packfile handling. Patrick Steinhardt addresses a minor inefficiency in how Git checks for missing packfiles, reducing unnecessary system calls when dealing with stale multi-pack-index (MIDX) entries.

The patch reorders operations in `add_packed_git()` to first check for the existence of the main packfile before checking auxiliary files like `.keep` and `.mtimes`. This avoids wasted `access(3p)` calls when the packfile doesn't exist - a situation that arose in production when a stale MIDX referenced nonexistent packs. While this edge case, the change provides a 75% reduction in syscalls for missing packs with minimal code impact.

The solution involves restoring the packfile name after checking auxiliary files, which is a simple memory copy operation. Patrick notes that a more comprehensive solution would involve implementing a negative lookup cache, but considers that overkill for the current problem. The change is cleanly implemented with a 7-line diff that maintains all existing functionality while optimizing the failure path.
