This is a bugfix patch in Jeff King's series removing support for non-standard object types in Git. The patch makes `--allow-unknown-type` in `git cat-file` a no-op while maintaining backward compatibility for existing callers.

The change is part of a larger effort to simplify Git's object handling by removing support for non-standard object types that were properly usable only in test cases. While the option no longer serves its original purpose (allowing unknown object types), it's retained to avoid breaking scripts that might be using it with normal objects. Junio Hamano notes this backward compatibility consideration makes sense after initially questioning why the option wasn't simply removed.

The patch has already been reviewed by Patrick Steinhardt, who suggested adding a test for option acceptance and documenting the deprecation path more explicitly. With Junio's approval here, the technical approach appears sound and ready for inclusion in the series. This is patch 2/13 in a series that's otherwise technically complete and endorsed by both reviewers and the maintainer.
