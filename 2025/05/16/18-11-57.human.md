Feature patch adding `--path-walk` support to `git repack`, part of the path-based delta compression series.

This patch exposes the `--path-walk` option in `git repack`, allowing users to leverage the new path-based delta compression algorithm during repacking. The change is straightforward plumbing - adding the option to the command-line interface and passing it through to the underlying `pack-objects` call. 

Performance data shows the path-walk method consistently produces smaller packs than both name-hash versions, though currently at a higher computational cost (the implementation is still single-threaded, with threading planned for future work). The patch includes test updates to measure repack performance with this new option across several repositories, showing size reductions of 5-15% compared to name-hash v2.

This is patch 7/13 in a series that has already undergone extensive review and is approved for merging. The implementation appears solid, with proper documentation updates and test coverage. The performance benefits are well-demonstrated across multiple real-world repositories, though the current single-threaded nature means it trades speed for space efficiency.
