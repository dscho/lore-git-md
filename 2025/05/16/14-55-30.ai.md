Performance test addition for sparse-index patch-mode commands.

This is the final patch in Derrick Stolee's series optimizing interactive commands (`git add -p`, `git checkout -p`, `git reset -p`) for sparse-index operations. It adds performance tests to `p2000-sparse-operations.sh` to validate the substantial speedups achieved in the previous patches. The tests measure both full and sparse index cases across different index versions (v3/v4).

Key technical details include:
- New test cases for `git add -p`, `git checkout -p`, and `git reset -p` using `test_perf_on_all`
- Test scenarios simulate real usage with `test_write_lines` providing simulated user input
- Performance data shows dramatic improvements for sparse index cases:
  - `git add -p`: 96% reduction (1.94s -> 0.07s)
  - `git reset -p`: 95.6% reduction (1.58s -> 0.07s)
  - `git checkout -p`: 91.6% reduction inherited from `git apply` optimizations
- Full index cases show minimal changes within noise thresholds
- The commit notes that `git add -i` shares the same optimization as `-p` so doesn't need separate testing

The patch follows Elijah Newren's earlier review feedback to include comprehensive performance testing. It demonstrates that the series achieves its goal of making interactive patch-mode commands sparse-index aware while maintaining correctness, with the performance tests serving as both validation and future regression protection. The test additions are minimal (3 lines) but strategically chosen to cover the optimized commands and their key scenarios.
