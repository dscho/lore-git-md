Feature completion for path-based delta compression with shallow support. This final patch in the 13-part series removes the artificial restriction preventing `--shallow` and `--path-walk` from being used together in `git pack-objects`. The change comes after extensive testing and refinement of the path-walk algorithm's handling of shallow repositories.

The patch makes two key changes: it moves the `shallow` flag to file scope so it can be used by the path-walk logic, and removes the warning that previously blocked combined usage. The accompanying test update verifies that shallow pushes now work correctly with path-walk enabled, checking both object counting and delta effectiveness through progress output analysis.

This completes the series' shallow clone support, building on the new `edge_aggressive` mode added in earlier patches. The implementation has been thoroughly reviewed and tested, with Microsoft reporting significant improvements in both pack size and operation speed for path-similar repositories. The series is approved for merging into Git's 'next' branch.
