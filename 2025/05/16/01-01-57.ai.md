Documentation patch series adding API documentation for the json-writer interface. This is the third iteration from Lucas Seiki Oshiro as part of Google Summer of Code, following up on previous review feedback.

The series consists of two patches that comprehensively document the json-writer API. The first adds detailed docstrings to all jw_* functions in json-writer.h, while the second provides usage examples and high-level guidance for working with the API. The changes are focused entirely on documentation - no functional changes are made to the removal of 4 lines in json-writer.c appears to be cleanup of now-redundant comments.

The json-writer API is used internally by Git for generating JSON output in commands like `git for-each-ref` and `git cat-file`, but until now lacked thorough documentation. This series fills that gap with what appears to be careful, well-structured documentation that explains both the individual functions and how to use them together. The v3 iteration suggests the author has incorporated feedback from previous rounds, though the specific changes aren't detailed in the cover letter.
