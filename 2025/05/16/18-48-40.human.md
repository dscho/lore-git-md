Build system fix for Perl module installation path. This is part 2 of a 5-part series standardizing Git's build system behavior across Make and Meson.

Ramsay Jones fixes an incorrect installation path for the YAML.pm Perl module in the Meson build system. Currently it gets placed in `<prefix>/share/perl5/Git/SVN` when it should go in a `Memoize` subdirectory. The change is straightforward - just updating the `install_dir` parameter in the meson.build file.

This appears to be a minor but correct fix that aligns with the series' goal of consistent path handling across build systems. The patch is small and focused, with a one-line change that clearly matches the described problem. As part of the larger build system standardization effort that has already undergone extensive review, this change seems uncontroversial and ready for inclusion.
