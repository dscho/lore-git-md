This is a configuration patch in the path-walk delta compression series, adding the new pack.usePathWalk config option to enable path-based delta compression by default. The patch introduces repository settings integration for the path-walk feature, making it automatically enabled when either feature.experimental or feature.manyFiles is set, following the same pattern as pack.useSparse. The implementation adds a new pack_use_path_walk setting in repo-settings.[ch] and wires it up in pack-objects.c to activate path-walk mode when the config is true and no other incompatible options (like bitmaps) are in use.

Key technical details include the addition of trace2 regions around the path-walk code to verify config activation during operations like push, and test coverage in t5516-fetch-push.sh that confirms the config properly enables path-walk behavior. The documentation updates explain the new config in both pack.adoc and feature.adoc, noting its potential benefits for pack size reduction while cautioning against server-side use due to bitmap incompatibility.

This patch builds on the core path-walk implementation from earlier in the series, with the config option providing the user-facing control mechanism. The test validates the config works through trace2 event checking rather than direct output verification, as the path-walk behavior itself is tested more thoroughly in other parts of the test suite. The changes are focused and well-contained, touching only the necessary configuration plumbing while leveraging the existing path-walk infrastructure.
