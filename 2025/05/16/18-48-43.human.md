The patch upgrades Autoconf's `sysinfo()` detection from a simple function existence check to a full compilation test that verifies the function works as expected (including checking the `totalram` and `mem_unit` fields). This matches a similar change already made to Meson's build system and fixes cases where the function exists but behaves differently (as on Solaris).
