This is a bug report about symlink functionality breaking in Git 2.49.0 on Windows. The reporter, Chris Conti, describes a regression where their custom difftool alias that temporarily enables symlinks fails with a "Function not implemented" error on Windows, despite working in Git 2.48.1.

The issue occurs when running a custom `diffdirsym` alias that combines `difftool --dir-diff` with temporary symlink enablement via -c core.symlinks=true. The error suggests the Windows version of Git 2.49.0 is failing to create symlinks during the directory diff operation, even when explicitly requested. The reporter provides their exact configuration including the Beyond Compare difftool setup and confirms the same setup works in the previous version.

Key technical points for future reference: the error occurs during temp file creation for dir-diff operations, specifically when trying to symlink changed files to temporary locations. The reporter's environment includes Windows 10, PowerShell 5.1, and Git built with OpenSSL 3.2.4. The bug appears to show a regression in Windows symlink handling between versions 2.48.1 and 2.49.0.
