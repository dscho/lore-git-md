Test coverage for path-walk delta compression in shallow pushes.

This patch adds two test cases to verify proper delta compression behavior when pushing from shallow clones, part of the larger `--path-walk` delta compression series. The first test confirms basic object counting works correctly during shallow pushes. The second and more interesting test creates a scenario where detecting proper delta base usage makes a measurable difference - it checks whether the progress output reports bytes (good delta compression) versus KiB (poor compression) when pushing modified files.

The tests are well-constructed to validate edge cases in the path-walk delta compression approach, particularly for the shallow clone scenario that was a focus of optimization in this series. The second test's clever use of progress output to indirectly verify delta effectiveness shows thoughtful test design. As part of the v3 series that has already undergone extensive review, this patch appears ready for inclusion.
