This is a major refactoring series aimed at removing support for non-standard object types in Git. Jeff King proposes dropping what he considers a "failed experiment" - code that has allowed creating and inspecting objects with arbitrary types since 2015, but which was never properly usable in practice (objects couldn't be transferred between repos or have their contents accessed).

The 13-part series systematically removes this functionality in logical phases: first eliminating the ability to read unknown types (patches 2-7), then removing write support (patches 8-13), with preparatory refactors and test updates throughout. The changes touch core object handling code, several builtins (`cat-file`, `fsck`, `hash-object`), and numerous tests. While this is technically a breaking change, Jeff argues it shouldn't require waiting for Git 3.0 since the feature was never functional enough to be useful.

The series appears well-structured, with each patch building toward the final goal while maintaining bisectability. Test coverage is thorough, including a new test helper (`test-zlib`) to maintain testing capabilities that previously relied on the now-removed functionality. This looks like a significant but justified simplification of Git's object handling internals.
