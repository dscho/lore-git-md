This is a build system patch that refines path handling for system-wide Git configuration files in the Meson build system. It's part 3 of a 5-part series standardizing path handling across Git's build systems.

The patch addresses an issue where system-wide config paths (`gitconfig` and `gitattributes`) were hardcoded to `/etc` regardless of the installation prefix. The changes make path resolution more flexible by:

1. Removing hardcoded `/etc` defaults from `meson_options.txt`
2. Using Meson's built-in `sysconfdir` when paths aren't explicitly overridden
3. Implementing proper path resolution logic that:
   - Uses absolute paths as-is when specified
   - Appends relative paths to the prefix
   - Falls back to `<sysconfdir>/gitconfig` and `<sysconfdir>/gitattributes` by default

The implementation maintains backward compatibility while allowing more flexible system configurations. The changes affect the `ETC_GITCONFIG` and `ETC_GITATTRIBUTES` compiler defines, which are used throughout Git's codebase to locate these files. The patch follows the series' pattern of making path handling more consistent between Make and Meson builds, though it doesn't change runtime behavior - it just ensures the build system correctly reflects the intended installation paths.
