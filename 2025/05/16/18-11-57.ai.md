This is part 7 of a 13-patch series introducing path-based delta compression to Git's packing system. The patch adds the `--path-walk` option to `git repack`, exposing the new delta compression strategy that was previously implemented in `git pack-objects`.

The key changes are:
- Adds `--path-walk` option to `git repack` that gets passed through to `pack-objects`
- Updates documentation to include the new option
- Modifies the performance test script p5313 to include path-walk measurements alongside existing name-hash version tests
- Includes extensive performance data comparing path-walk against name-hash versions across multiple repositories (microsoft/fluentui, Git, nodejs/node, Linux kernel)

The performance data shows path-walk generally produces smaller packs than name-hash versions, though with longer runtime in the current sequential implementation (threading optimizations are planned for future changes). The patch maintains compatibility with existing repack options while adding this new compression strategy.

This is a straightforward plumbing-through of functionality that was already reviewed in the pack-objects implementation. The changes are minimal and focused - just adding the option passthrough and test coverage. As part of the larger series that has already been reviewed and approved, this patch appears ready for inclusion.
