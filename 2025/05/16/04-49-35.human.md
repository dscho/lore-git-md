This is patch 2/13 in Jeff King's series removing support for non-standard object types from Git's core. The patch focuses on `git cat-file`, deprecating its `--allow-unknown-type` option which was previously used to inspect objects with non-standard types.

The commit explains that this functionality was of limited practical use - it only worked for loose objects (not packed ones), couldn't show object contents, and couldn't transfer objects between repositories. The patch makes `--allow-unknown-type` a no-op rather than removing it entirely, to avoid breaking any existing scripts that might be using it with normal objects. The documentation is updated to remove mention of the option, and tests are simplified to no longer exercise this path.

This is a straightforward change that removes dead code while maintaining backward compatibility. The patch is cleanly implemented with appropriate test updates. It's part of a larger effort to simplify Git's object handling by removing support for experimental features that never gained real-world adoption.
