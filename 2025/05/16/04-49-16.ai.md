This is a major refactoring series targeting Git's object handling code, specifically removing support for non-standard object types. The series represents a significant simplification of core object code by declaring the 10-year-old experiment with non-standard types as a failed effort.

Jeff King proposes removing both reading and writing support for these non-standard object types, arguing they were never properly usable beyond some test cases. The 13 patches are logically grouped: first removing read-side support (including user-facing `--allow-unknown-type` in `git cat-file`), then cleaning up related code, followed by removing write-side support (with test infrastructure moved to a new helper tool), and finally some cleanups enabled by these removals.

Key technical changes include:
- Removal of `OBJECT_INFO_ALLOW_UNKNOWN_TYPE` flag and related code
- Conversion of type handling from strbuf to enum in several functions
- New test helper `test-zlib` and `lib-loose.sh` to replace removed functionality in tests
- Dropping `write_object_file_literally()` and merging related flags
- Changes to `fsck` output format when encountering unknown types

The series touches core object handling code across multiple files (`object-file.*`, `object-store.*`), several commands (`cat-file`, `fsck`, `hash-object`), and updates numerous tests. Jeff suggests this doesn't need to wait for Git 3.0 since the functionality being removed was never properly usable, though acknowledges others may disagree with this assessment.
