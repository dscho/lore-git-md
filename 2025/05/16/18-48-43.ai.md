Platform compatibility patch completing the build system series' sysinfo() handling.

This final patch in the v3 build system series upgrades the autoconf build's sysinfo() detection to match the meson build's more robust approach. The change addresses a Solaris-specific issue where the header exists but the function behaves differently from Linux/cygwin. The new check verifies not just the function's existence but also its expected behavior by testing access to the totalram and mem_unit fields used by git-gc's RAM calculation.

The patch follows the same pattern as f5e3c56 in the meson build, ensuring consistent behavior across build systems. It builds on prior work (50dec7c, c9a5177) that first identified the Solaris incompatibility and fixed the RAM calculation logic. The implementation uses AC_COMPILE_IFELSE to test a complete usage scenario rather than just function availability.

This completes the series' goal of standardizing path and system capability detection between build systems, with particular attention to cross-platform consistency. The change is narrowly focused on the sysinfo() detection without introducing new variables or affecting other subsystems. The patch has already undergone review and validation as part of the broader series, including Solaris and cygwin testing.
