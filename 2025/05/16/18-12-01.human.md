Performance optimization patch adding threading to path-based delta compression in `git pack-objects`. This is part of the larger path-walk delta compression series that's been under review and is now ready for integration.

The patch introduces `threaded_find_deltas_by_path()` and modifies the path-walk compression to use multiple threads, showing significant speed improvements while maintaining the same compression ratios. Performance tests demonstrate a ~60% reduction in repack times across various repositories (Git, nodejs/node, Linux kernel) when using path-walk compression, making it much more competitive with the existing name-hash methods. The threaded implementation helps offset the inherent computational overhead of the two-pass path-walk compression.

The implementation carefully handles work distribution between threads, with each thread processing path regions and dynamically balancing workloads. The patch maintains all the existing path-walk benefits (better compression for path-similar objects) while dramatically improving its runtime performance, particularly important for large repositories where the feature shows the most benefit. This was the last major piece needed to make the path-walk approach practical for general use.
