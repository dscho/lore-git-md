This is a build system patch that fixes path handling for system-wide Git configuration files in the Meson build system. It's part 3/5 of a series standardizing path handling across Git's build systems.

The patch addresses an issue where Meson was defaulting system-wide config paths (`gitconfig` and `gitattributes`) to absolute `/etc` paths regardless of the installation prefix. The fix makes these paths respect the `sysconfdir` setting (typically `etc` relative to prefix) when not explicitly overridden. This matches the behavior of other build systems and allows proper installation in non-/usr prefixes like `/usr/local`.

Key changes include:
1. Removing hardcoded `/etc` defaults from meson_options.txt
2. Implementing logic to use `sysconfdir` when paths aren't explicitly set
3. Maintaining backward compatibility by still allowing explicit path overrides

The change is well-motivated and clearly explained in the commit message. It's part of a larger, well-tested series that has already received significant review and appears ready for integration. The patch maintains the series' focus on consistent path handling while fixing a real issue in the Meson build configuration.
