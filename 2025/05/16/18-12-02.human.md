This is a feature patch adding shallow clone optimization to the path-walk delta compression series. It introduces an 'edge_aggressive' option that helps avoid sending extra objects during fetches and pushes from shallow clones by more thoroughly marking uninteresting objects at the boundary.

The patch adds the new option to the path-walk API, matching the behavior of the existing `--objects-edge-aggressive` in the revision API. It includes documentation updates, test helper support, and a new test case verifying the behavior when pruning uninteresting paths with aggressive edge walking enabled. The implementation is clean and focused, with clear commit message explaining the motivation and connection to the revision walk API.

This is part of the larger path-walk delta compression series (12/13) that has already gone through multiple rounds of review and is approved for merging. The series as a whole shows significant performance improvements, particularly for monorepo and Scalar use cases, with this patch specifically addressing shallow clone scenarios. The test coverage is thorough, including both unit tests and integration with the existing test suite.
