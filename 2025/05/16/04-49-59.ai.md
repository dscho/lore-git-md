This is a test infrastructure patch, part of Jeff King's series removing non-standard object types from Git's core. Patch 8/13 introduces a new test helper tool for performing raw zlib compression/decompression operations, which will be used in subsequent patches to test the object handling changes.

The `test-zlib` helper provides simple inflate/deflate operations via a command-line interface, reading from stdin and writing to stdout. The implementation buffers all input in memory rather than streaming, which Jeff notes makes the zlib operations less prone to subtle bugs. The commit message cites several historical cases where this tool would have been useful for testing and debugging, including working with hard-coded pack data and corrupted objects.

The patch adds the new test source file and integrates it into both Makefile and meson build systems. The helper supports two modes: `inflate` and `deflate`, wrapping Git's existing `git_zstream` interface. Error handling is basic but sufficient for test purposes, with failures causing immediate termination.

This appears to be a well-constructed utility that fills a genuine testing need, particularly for the object format changes in this series. The simple design and clear motivation suggest it should be uncontroversial. The implementation follows Git's existing patterns for test helpers, and the commit message provides good context about both immediate and historical use cases.
