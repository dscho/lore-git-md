Test infrastructure patch adding a zlib helper tool, part of Jeff King's series removing non-standard object type support.

This patch introduces a new test helper `test-tool zlib` that performs raw zlib compression and decompression operations. The tool is designed to help with testing and debugging Git's object storage, particularly for cases where direct zlib operations are needed to examine or generate object data. The implementation reads all input into memory before processing (avoiding streaming complexity) and supports both inflate (decompress) and deflate (compress) operations.

The commit message explains several historical cases where this tool would have been useful, including generating test packfiles with delta cycles and debugging corrupted objects. While the immediate use case is for upcoming tests in this series, the tool appears generally useful for Git's test suite. The implementation is straightforward and leverages Git's existing zlib wrapper functions.

This appears to be a well-motivated addition to the test infrastructure, cleanly implemented and documented. As part of a larger refactoring series, it provides needed testing support while standing alone as a potentially reusable component. The patch follows the series' pattern of careful, incremental changes with clear rationale.
