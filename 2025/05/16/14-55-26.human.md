This is a performance optimization series integrating the sparse index with interactive commands (`git add -p/-i`, `git checkout -p`, and `git reset -p`), part of the ongoing sparse-index/sparse-checkout effort. The series makes these commands sparse-index aware to prevent unnecessary index expansion, building on previous work that optimized `git apply`.

The key improvements in v2 address reviewer feedback from Elijah Newren and Phillip Wood, including:
- Fixed test assumptions about index expansion behavior
- Added coverage for `git checkout -p` and `git reset -p`
- Improved `git reset -p` performance with sparse index integration

Performance tests show dramatic speedups for sparse-checkout users:
- `git add -p`: 96.7% runtime reduction (1.94s → 0.07s)
- `git checkout -p`: 91.6% reduction (1.31s → 0.11s)
- `git reset -p`: 95.6% reduction (1.58s → 0.07s)

The implementation follows established sparse-index patterns, setting `command_requires_full_index=0` in the relevant builtins (`add.c`, `apply.c`, `reset.c`) and includes comprehensive test coverage in both compatibility (`t1092`) and performance (`p2000`) test suites. The series is now merge-ready with consensus from reviewers.
