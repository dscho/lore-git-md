Build system patch fixing Perl module installation path in Meson build.

This is part 2/5 in the v3 series standardizing Git's build system configuration. The patch corrects the installation path for the YAML.pm Perl module in the Meson build system, moving it from `<prefix>/share/perl5/Git/SVN` to the proper `<prefix>/share/perl5/Git/SVN/Memoize` location. The change aligns with the module's actual usage context in the SVN/Memoize subsystem.

The fix is straightforward - a one-line change to the `install_dir` parameter in perl/Git/SVN/Memoize/meson.build. This follows the series' theme of path handling consistency across build systems. The patch appears technically sound and addresses a clear-cut installation path mismatch, though it doesn't affect runtime behavior since the module would still be found via Perl's include path.

This is one of several path-related refinements in the series, which has already incorporated review feedback and testing across multiple platforms. The change is small but contributes to the overall goal of consistent build system behavior.
