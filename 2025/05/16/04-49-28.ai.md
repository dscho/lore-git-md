Minor typo fix in preparation for major refactoring series.

This is the first patch in Jeff King's 13-part series removing support for non-standard object types from Git's core. It fixes a simple typo in `object-file.h` where a parameter was misspelled as "comapt_oid_in" instead of "compat_oid_in". The change is part of the function signature for `write_object_file_flags()`, which will see more significant modifications later in the series when non-standard type support is removed.

While trivial on its own, this correction ensures clean diffs and accurate variable naming as the subsequent patches refactor this area of the codebase. The patch follows standard Git contribution practices with a clear one-line commit message and minimal, focused changes. As the series opener, it serves as a warm-up for the more substantial changes to come in patches 2-13.
