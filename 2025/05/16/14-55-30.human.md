This is a performance test patch that concludes Derrick Stolee's series optimizing interactive commands (`git add -p`, `git checkout -p`, `git reset -p`) for sparse index operations. The patch adds performance benchmarks to validate the substantial speed improvements shown in the previous patches.

The test results demonstrate dramatic improvements for sparse index cases:
- `git add -p` shows 96% speedup (from ~1.9s to 0.07s)
- `git reset -p` achieves 95.6% speedup
- `git checkout -p` gets 91.6% speedup by inheriting optimizations from `git apply`

The tests confirm that full index cases remain stable (changes within noise levels) while sparse index operations become significantly faster. The patch adds three new test cases to the existing `p2000-sparse-operations.sh` performance suite, covering the interactive variants of these commands with simulated user input.

This final patch in the series has already received positive reviews from Elijah Newren and Junio Hamano, with consensus that the optimizations are ready for inclusion. The performance metrics provide concrete evidence that the sparse index integration successfully avoids unnecessary index expansion while maintaining correctness.
