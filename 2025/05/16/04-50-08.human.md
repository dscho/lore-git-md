This is a refactoring patch in Jeff King's series removing support for non-standard object types. It's the 11th of 13 patches in the v1 series.

The patch simplifies `git hash-object`'s removing an unnecessary layer of flag conversion. Previously, the command used its own `HASH_*` flags that were converted to `INDEX_*` flags before being passed to `index_fd()`. Now that the `hash_literally()` helper was removed in the previous patch, this conversion is no longer needed - the code can just use the `INDEX_*` flags directly.

The change is straightforward mechanical refactoring that:
- Removes the `HASH_OBJECT_CHECK` and `HASH_OBJECT_WRITE` enum definitions
- Updates the flag handling in `hash_fd()` to use the flags directly
- Changes the default flag from `cmd_hash_object()` to use `INDEX_FORMAT_CHECK`
- Updates the option parsing to set `INDEX_WRITE_OBJECT` directly

This continues the series' trend of simplifying the object handling code by removing unnecessary abstractions. The patch appears clean and focused, with no behavior changes beyond the internal flag handling. It builds naturally on the previous patch's removal of `hash_literally()`.
