This is a build system patch that aligns GIT_EXEC_PATH handling between the Meson and Make build systems. It's part 4 of a 5-part series standardizing path configuration across Git's build systems.

The patch focuses on making Meson's GIT_EXEC_PATH behavior match Make's more closely. Currently, Meson defaults to an absolute path for GIT_EXEC_PATH while Make uses a relative path. The change makes Meson default to 'libexec/git-core' (relative path) like Make, while still allowing override via --libexecdir. It also adds the same runtime_prefix validation that exists in Make to prevent absolute paths when runtime prefixing is enabled.

The implementation is straightforward - it replaces the default absolute path calculation with a relative path default, then conditionally overrides it when libexecdir is explicitly set to something other than the default. The error checking for runtime_prefix cases is also ported from Make.
