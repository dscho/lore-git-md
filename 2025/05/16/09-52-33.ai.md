This is a review comment on patch 9/13 of Jeff King's series removing non-standard object types, focusing on the new test helper infrastructure.

Patrick Steinhardt reviews the new `t/lib-loose.sh` test helper library that provides low-level way to write loose objects without using `git hash-object`. The helper allows creating objects with potentially invalid types that `hash-object` would reject, which is needed for testing edge cases as the series removes support for non-standard types.

The review is positive overall, with one minor naming suggestion - Patrick proposes `write_loose_obj()` might be clearer than `loose_obj()` for the main helper function, but explicitly states this is a nit that can be ignored. He confirms the implementation looks sensible, examining the shell function that:
- Takes object type and content from stdin
- Properly handles object size calculation across platforms
- Uses test-tool for hashing and zlib compression
- Correctly structures the object storage path
- Cleans up temporary files
- Returns the object hash

This patch is part of the series' infrastructure work to maintain test coverage while removing the ability to create non-standard objects through normal Git commands. The helper will be used in subsequent test conversions as shown by the modified test files in the diffstat (t1006, t1450, t1512). Patrick's approval suggests this approach to testing is sound as the series progresses toward removing write-side support for non-standard types.
