This is the first patch in a documentation series adding API reference for Git's json-writer interface, part of Lucas Seiki Oshiro's GSoC project. The patch comprehensively documents all functions in json-writer.h with clear docstrings explaining each function's purpose, parameters, and behavior. The documentation follows standard patterns - noting which functions trigger BUG() when used incorrectly (outside an object or array context), explaining parameters like the precision control for doubles, and clarifying the JSON structure being built.

The implementation looks thorough, with consistent formatting and clear technical writing. The patch also removes some now-redundant inline comments from json-writer.c that the header documentation supersedes. Three experienced contributors (Junio Hamano, Patrick Steinhardt, and Karthik Nayak) are credited as helpers, suggesting the patch has already benefited from mentor review.

This foundational documentation will make the json-writer API more approachable for both Git contributors working with JSON output (used by commands like `git for-each-ref`) and potentially for external consumers of the API. The v3 tag indicates this iteration has likely incorporated feedback from prior rounds.
