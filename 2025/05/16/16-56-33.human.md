This is patch 4/13 in Jeff King's series removing support for non-standard object types in Git. The patch simplifies `git cat-file -t` by removing the need to handle unknown object types, allowing it to use a simple enum rather than a string buffer to track object types.

The change removes the `strbuf` handling that was previously needed to accommodate unknown object types, instead using Git's standard `type_name()` function to print the type. Junio Hamano notes this is a nice simplification, though observes that completely removing the `.type_name` field from `object_info` will come in a later patch.

This is a straightforward cleanup that follows naturally from the earlier removal of unknown type support. The patch is small (13 lines changed) and focused purely on the `cat-file` command's implementation details. It maintains all existing functionality while removing now-unnecessary code paths.
