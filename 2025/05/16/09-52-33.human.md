This is a review comment on patch 9/13 of Jeff King's series removing non-standard object types. The patch introduces a new shell helper script `lib-loose.sh` for writing raw loose objects directly to the object database, bypassing `git hash-object` to allow creating intentionally broken objects for testing.

Patrick Steinhardt reviews the implementation and finds it generally sound, offering one minor naming suggestion (preferring `write_loose_obj` over `loose_obj` for clarity of purpose) but explicitly marking it as non-blocking. The helper will be used to replace existing tests that rely on `hash-object --literally`, allowing that feature to be removed in later patches.

The review is positive overall, with no substantive changes requested. This keeps the series moving forward toward its goal of simplifying Git's object handling by removing support for non-standard types that were never properly usable beyond test cases. The new test infrastructure appears well-designed to maintain test coverage while removing the deprecated functionality.
