This is a test infrastructure patch that enables TAP output parsing in Meson 1.8+ for Git's test suite. It builds on Patrick Steinhardt's ongoing series to improve test integration with Meson, now focusing on proper test result reporting.

The patch conditionally sets the `protocol: 'tap'` parameter in Meson build configuration when using Meson 1.8 or newer, allowing the build system to properly interpret the Test Anything Protocol output from Git's test scripts. This provides more detailed test reporting including subtest counts and skipped test detection, as shown in the example output where individual tests are now reported with their subtest counts (e.g., "2600 subtests passed" for t0027).

A key technical detail is the handling of `meson test --interactive` mode - in this case tests are marked as "ignored" since interactive sessions can't reliably parse TAP output while maintaining terminal interactivity. The patch references an upstream Meson fix (PR #13980) that resolved a hanging issue with TAP parsing in interactive mode.

The change is minimal (8 lines added to meson.build) but impactful for test reporting. It follows the series' pattern of gradually improving Meson integration while maintaining compatibility, here using a version check to only enable the feature when supported. The patch fits naturally into the broader test infrastructure standardization effort that has been reviewed and approved by multiple contributors.
