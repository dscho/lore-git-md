This is a test infrastructure patch that fixes TAP output format violations in several test scripts. It's part of Patrick Steinhardt's ongoing series to improve Meson test integration, now in its second version (v2 1/6).

The patch addresses cases where test scripts were emitting output outside of formal test cases without proper TAP formatting (which requires diagnostic output to be prefixed with "#"). Rather than just adding the prefix, the author chose to remove or redirect this output messages entirely since they were deemed "rather uninteresting" for test purposes.

Changes affect 12 test scripts, with most modifications being straightforward removals of diagnostic messages about filesystem characteristics (case sensitivity, Unicode handling) or prerequisite checks. Some notable changes include redirecting repository creation output to /dev/null and converting some say/skip messages to proper test prerequisites.

The patch builds on prior discussion about making Git's test output properly parseable by Meson's stricter TAP parser while maintaining backward compatibility. It's a technical cleanup that helps pave the way for better integration with modern test tooling, though the changes themselves are quite mechanical in nature.
