This is a test infrastructure patch in Patrick Steinhardt's series improving TAP output compliance. It fixes an issue where shell trace output from verbose test runs was being incorrectly mixed with TAP-formatted output, potentially breaking TAP parsers.

The patch changes how test output is routed when using verbose flags (-v, -x, etc.). Previously, stdout and stderr were kept separate when printing to the console, which could corrupt the TAP format. The fix redirects all verbose output to stderr instead, sacrificing the ability to distinguish stdout from stderr but ensuring clean TAP output. The commit notes this tradeoff is acceptable since distinguishing the streams wasn't practically useful.

The changes affect core test infrastructure files (t/test-lib.sh) and update the basic test suite (t0000-basic.sh) to verify the new behavior. This is a mechanical change that aligns with the series' goal of strict TAP compliance, building on prior review consensus about adopting Meson's stricter validation approach. The patch appears straightforward and well-tested, with no obvious technical concerns.
