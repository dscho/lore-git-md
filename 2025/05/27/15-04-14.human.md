This is a review response in the R language diff highlighting thread, where Junio Hamano weighs in on Johannes Sixt's technical concerns about the implementation. The discussion focuses on two main issues: the usefulness of hunk headers in R scripts (where code can live outside functions) and the word-diff behavior. Hamano notes that the hunk header challenge isn't unique to R - shell, Perl, Python and others share similar characteristics - but jokingly suggests the ideal solution would be reliably detecting when we're outside functions. He agrees with Sixt's point about the current word-diff pattern being too strict and suggests falling back to the default behavior if a better pattern isn't ready. Hamano also endorses squashing test cases into the main patch and expanding them to cover nested functions, showing general approval of Sixt's thorough review while keeping the tone light. The exchange indicates these are solvable implementation details rather than fundamental objections to adding R support.
