Bugfix for platform-specific test behavior in Patrick Steinhardt's TAP compliance series (4/6). This patch addresses an unexpected test pass in t7815-grep-binary.sh on macOS, where a test designed to fail (except on Cygwin) was incorrectly passing due to macOS's regex implementation behaving similarly to Cygwin's.

The test checks whether `git grep .fi` matches a NUL byte, which should only happen on Cygwin. The patch extends the existing Cygwin exclusion to also skip the test on macOS, maintaining the test's original intent while acknowledging platform differences. The change is minimal - just adding a MACOS prerequisite and updating the test condition.

This is a tactical fix within Steinhardt's larger series standardizing TAP output parsing. The commit message notes a more robust solution would involve configure-time regex checks, but defers that as out of scope for the current effort. The patch follows the series' pattern of making tests reliably pass across platforms while preserving their original purpose.
