This is a platform compatibility patch that removes dead code from git-cvsserver, building on earlier discussions about Perl 5.41.4+ warnings and the component's future. The patch removes the unused `escapeRefName` function that was causing test failures in t9402.30-32,34 due to Perl warning messages, while keeping its counterpart `unescapeRefName` which remains in use.

The removal is well-justified by historical analysis showing the function was added in 2012 with a "not used yet" comment and never utilized, confirmed by original author Matthew Ogilvie. This follows earlier thread discussion where testing by Jeff King and git-log analysis by Todd Zullinger established the function was truly dead code. The patch updates comments for the remaining unescapeRefName function to clarify the relationship.
