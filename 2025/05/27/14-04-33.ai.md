This is a refactoring patch in Patrick Steinhardt's series fixing race conditions in Git's maintenance operations. The patch corrects the typedefs for function pointers used in the maintenance task infrastructure.

The change makes `maintenance_task_fn` and `maintenance_auto_fn` proper function pointer typedefs by adding the `*` in the typedef declaration rather than requiring callers to add it. This affects how these types are used in the `maintenance_task` struct, where the `fn` and `auto_condition` members no longer need explicit pointer syntax.

The modification is purely syntactic - it doesn't change any runtime behavior but makes the code more idiomatic by properly expressing the pointer nature in the type system. This continues the series' pattern of cleaning up the maintenance task infrastructure before implementing the core race condition fixes. The change is small (5 lines modified) and focused entirely on `builtin/gc.c`.

This patch follows the earlier structural improvements in the series and precedes the expected implementation of the actual race condition fixes for maintenance operations. The clean typedefs will likely make the subsequent patches' changes to task execution logic clearer.
