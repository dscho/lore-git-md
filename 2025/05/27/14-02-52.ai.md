Test infrastructure patch in Patrick Steinhardt's TAP compliance series, addressing platform-specific test behavior. This patch fixes an unexpectedly passing test on macOS in t7815-grep-binary.sh that was previously only known to pass on Cygwin due to regex implementation details. The test checks whether `git grep` correctly handles NUL bytes in patterns, which should fail on most platforms but was passing on macOS due to its BSD-derived regex implementation. Rather than solving the underlying platform inconsistency (which would require configure-time regex checks and potentially using Git's bundled regex), the patch takes the pragmatic approach of excluding macOS alongside Cygwin via a new MACOS prerequisite.

Key technical details:
- Adds MACOS prerequisite in t/test-lib.sh alongside existing platform flags
- Modifies t7815 test to skip on both !CYGWIN and !MACOS
- References historical context (064eed36c7f) about Cygwin's similar behavior
- Acknowledges the test's platform-specific nature makes it of questionable value
- Part of broader 6-patch series standardizing TAP output (now at v2)
- Builds on earlier work to make test output parseable by Meson's TAP parser
- Maintains backward compatibility while fixing edge cases
- Follows series pattern of addressing platform quirks (previously handled Cygwin regex)

The patch represents a minimal fix to maintain test suite stability while the series focuses on TAP output standardization, deferring deeper regex handling improvements. It demonstrates the series' approach of balancing immediate needs (TAP compliance) with acknowledging larger technical debt (platform-specific behavior).
