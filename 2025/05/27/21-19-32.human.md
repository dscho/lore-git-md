This is a documentation patch in a 9-part series improving `--stdin` usage documentation in git-notes. The series is now at v3 and appears ready for merging after addressing review feedback.

Patch 3/9 focuses on making option documentation more searchable by splitting combined `--[no-]option` forms into separate entries for `--option` and `--no-option`. The change affects the documentation of `--separator` and `--stripspace` options in git-notes.adoc, making each variant explicitly listed rather than using the combined form. This follows up on a suggestion from Junio Hamano to improve documentation clarity.

The patch is straightforward and uncontroversial, aligning with the series' goal of documentation standardization. It maintains all existing functionality while making the documentation more accessible. The change is minimal (4 insertions, 2 deletions) and focused purely on presentation, not behavior.

This continues the series' pattern of incremental documentation improvements, with each patch addressing a specific aspect of clarifying git-notes behavior and option handling. The author has incorporated feedback from the v2 review, using the term "negated form" as suggested.
