This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP output compliance. It addresses how shell traces are handled in verbose test modes to prevent breaking TAP parser compatibility.

The patch modifies `t/test-lib.sh` and `t/t0000-basic.sh` to redirect test stdout to stderr when running with `--verbose` or `--verbose-only` flags. The change fixes cases where mixed output streams could corrupt TAP format, though it means stdout and stderr can no longer be distinguished in verbose mode. The author notes this tradeoff is acceptable given no known use cases require the streams to be separated.

Key technical changes include:
- Modifying file descriptor handling in `exec` statements (3 now points to stderr instead of stdout)
- Updating test expectations in t0000-basic.sh to match new output locations
- Introducing `check_sub_test_lib_test_err` to verify stderr content
- Preserving all test functionality while changing only output routing

This builds on the series' goal of strict TAP compliance, with the change being a mechanical adjustment to output handling rather than a behavior modification. The patch maintains the thread's established approach of fixing test infrastructure while preserving backward compatibility.
