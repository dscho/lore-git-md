Bug report about `git branch --show-current` behavior in detached HEAD state.

Ulrich Wittenberg reports unexpected behavior when using `git branch --show-current` in a Jenkins job running in detached HEAD state. The command returns no output when the user expects it to indicate which branch the script is working on. They note that other Git commands that typically show branch information also fail to work properly in this context.

The report includes system information showing Git version 2.39.5 running on a Debian Linux system. The user describes this as a complete failure of expected functionality ("Well, everything!"), though the report doesn't specify whether they tried alternative methods like `git symbolic-ref --short HEAD` or checking reflogs.

This appears to be either a genuine bug in Git's handling of detached HEAD states or possibly a misunderstanding of the command's documented behavior (which is to return nothing when not on a branch). The report lacks details about the specific Git operations leading to the detached state, which might help diagnose whether this is expected behavior or a real issue.
