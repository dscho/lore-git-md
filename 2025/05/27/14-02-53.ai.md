This is a refactoring patch in Patrick Steinhardt's test infrastructure series, focusing on Meson build system improvements. The patch introduces a `test_kwargs` dictionary to centralize common test parameters that are currently duplicated across multiple test definitions in the Meson build files.

The immediate change is to consolidate the `timeout: 0` parameter that appears in many test definitions into a single `test_kwargs` dictionary defined in the root meson.build file. This prepares for adding more common parameters in future commits while reducing duplication. The patch modifies 4 build files, replacing individual timeout declarations with references to the new kwargs dictionary.

The changes are mechanical but demonstrate good build system hygiene by eliminating parameter duplication. This follows the pattern seen elsewhere in the series of standardizing test infrastructure while maintaining backward compatibility. The patch fits naturally into the broader effort to improve test runner consistency across the codebase, though it doesn't directly relate to the TAP output compliance work that dominates other parts of the series.
