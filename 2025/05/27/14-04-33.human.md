This is a refactoring patch in Patrick Steinhardt's series addressing race conditions in Git's maintenance operations. The patch fixes a minor but confusing inconsistency in the codebase where two typedefs (`maintenance_task_fn` and `maintenance_auto_fn`) were defined as function signatures rather than true function pointer types. This required users of these types to manually add pointer syntax when declaring variables.

The change makes these typedefs proper function pointer types by adding the `*` in their definitions, which better matches their actual usage in the `maintenance_task` struct. This is purely a code clarity improvement with no behavior change - all existing code continues to work exactly as before, just with slightly cleaner type declarations.

This patch continues the series' pattern of preparatory refactoring before implementing the core race condition fixes. While small, it demonstrates the author's attention to detail in cleaning up the codebase incrementally. The change is straightforward and unlikely to be controversial, though reviewers may want to confirm it doesn't trigger any compiler warnings on unusual platforms.
