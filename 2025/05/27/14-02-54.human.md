This is the final patch in Patrick Steinhardt's series improving test infrastructure, focusing on Meson build system improvements. The patch enables TAP output parsing in Meson 1.8+ for Git's test suite, which provides more detailed test reporting while maintaining compatibility with interactive test runs.

The change makes Meson aware of individual subtest results (previously it only checked exit codes) and properly handles skipped tests. The implementation is careful to only activate this feature when using Meson 1.8 or newer, as earlier versions had a bug that caused hangs with interactive testing. Even with the new TAP parsing, interactive test runs will still work correctly - they'll just be marked as "ignored" since the output can't be reliably parsed while interacting with the terminal.

The patch demonstrates the improved output format, showing passed subtests and skipped tests clearly. This builds on the series' broader goal of standardizing test infrastructure while maintaining compatibility with existing workflows. The change is minimal (8 lines added to meson.build) but provides meaningful visibility into test results.
