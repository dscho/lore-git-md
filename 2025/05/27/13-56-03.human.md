Bugfix patch series ready for merging, addressing file mode handling in `git apply --reverse`. This is the third version of a fix for preserving executable bits when reversing a patch that deletes a file. The core issue was identified in commit 01aff0a from December 2023, which missed handling mode bits during deletion reversal.

The series has evolved through three versions with extensive test improvements based on reviewer feedback. Version 3 includes final refinements to the test infrastructure: better handling of absent files (represented as mode 000000), more robust checkpointing via tags and resets, consistent file creation methods, and complete coverage of all mode transition cases. The tests now validate both the core functionality and warning behaviors across all relevant scenarios.

Reviewers including Junio Hamano and Mark Mentovai have provided feedback that has been incorporated, leading to standardized six-digit octal representations, improved test isolation, and order-independent execution. The one-line code change in apply.c remains simple and focused, while the comprehensive test suite ensures the fix works across all edge cases.

Junio indicates the series is now ready to be queued for merging, marking the conclusion of this bugfix effort that began with the initial report in December. The thorough test matrix should prevent similar oversights in future changes to this area of the codebase.
