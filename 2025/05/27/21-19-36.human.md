This is a documentation patch in a 9-part series clarifying `--stdin` behavior in git-notes. The series is now at v3 and appears ready for merging after addressing review feedback.

This specific patch (7/9) documents a key difference between `git notes copy --stdin` and `git notes remove --stdin`: while the remove subcommand allows combining `--stdin` with command-line object names, the copy subcommand does not. The patch adds this clarification to the documentation with a simple, clear addition under the copy subcommand's `--stdin` description.

The change is straightforward and uncontroversial, matching the series' goal of precisely documenting current behavior. It follows the established pattern of the series by explicitly stating implementation details that users might otherwise need to discover through trial and error.
