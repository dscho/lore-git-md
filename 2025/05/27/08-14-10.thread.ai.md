Bug report: pathspec handling regression in empty repositories with `git add --update` and exclude patterns. Regression introduced in Git 2.45.0, persisting through 2.49.0.1266. Reproduction case demonstrates that commands like `git add --update -- ':(exclude)foo'` in empty repositories produce duplicate error messages (for both the exclude pathspec and implicit '.' pathspec), while working correctly in pre-2.45.0 versions. Behavior normalizes once any file exists in repository. Issue appears specific to interaction between `--update` flag, empty working tree state, and exclude pathspec processing. No root cause analysis or fix proposed in initial report. Clear regression window and minimal reproduction make this suitable for pathspec experts to investigate.
