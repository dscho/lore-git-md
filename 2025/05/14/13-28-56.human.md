Bugfix for `git stash` branch name display in submodules, with review feedback addressed. This is a follow-up in a thread where K Jayatheerth initially fixed a bug where `git stash list` would incorrectly show a submodule's branch name instead of the superproject's when stashing changes. The core fix uses `xstrdup()` to preserve the correct branch name through submodule operations.

Junio C Hamano and Eric Sunshine provided review feedback noting three issues: inconsistent indentation in the control flow, a memory leak from not freeing the allocated branch name buffer, and the lack of test coverage for the fixed behavior. K Jayatheerth has acknowledged all points and plans to resubmit a complete patch series addressing these concerns, including proper memory cleanup, consistent formatting, and comprehensive tests.

The technical approach remains sound - the patch modifies `do_create_stash()` in `builtin/stash.c` to properly handle branch name preservation while maintaining the existing "(no branch)" fallback behavior. The thread shows good progress with no outstanding technical objections to the core solution, just final polishing needed before maintainer approval.
