Refactoring patch in Patrick Steinhardt's series to remove `the_repository` global from Git's object database handling. This is patch 8/17 in v3 of the series, focusing on alternate object database functionality.

The patch converts functions that manage alternate object databases to explicitly take an `object_database` parameter instead of implicitly using `the_repository`. Key changes include:
- Renaming functions like `add_to_alternates_file()` to `odb_add_to_alternates_file()`
- Updating callers across 14 files including clone, fsck, and packfile operations
- Maintaining the same functionality while removing global state dependencies

The changes are mechanical but thorough, touching core operations like preparing alternates, checking for their existence, and adding new ones. The patch follows the established pattern of the series by keeping the same behavior while making repository dependencies explicit. As with previous patches in the series, this appears to be a well-executed step in the larger `the_repository` removal effort.
