This is the first patch in Patrick Steinhardt's v3 series refactoring Git's object database subsystem as part of the `the_repository` removal effort. The patch renames the central `raw_object_store` structure to `object_database` (abbreviated as ODB) to better reflect its purpose and establish consistent naming for the new ODB subsystem.

The change affects core object storage infrastructure across 8 files (~24 lines added, 19 removed), updating type names and function signatures. Key renames include:
- `raw_object_store` -> `object_database`
- `raw_object_store_new()` -> `odb_new()`
- `raw_object_store_clear()` -> `odb_clear()`

The commit message explains the "raw_" prefix was misleading (implying a non-raw variant that doesn't exist) and the new name aligns with the goal of making object storage a self-contained subsystem with pluggable backends. The ODB acronym is already established in the codebase and will be used for new APIs like `odb_has_object()`.

This foundational rename sets the pattern for subsequent patches that will convert object access functions to explicitly take ODB pointers rather than implicitly using `the_repository->objects`. The changes are mechanical renames with no behavior modifications, maintaining all existing functionality while improving type clarity.
