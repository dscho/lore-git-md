The final patch, just reviewed by Junio C Hamano, mechanically converts the last instances in builtin/mktag.c, builtin/worktree.c, and pack-bitmap-write.c. Junio approved the changes while suggesting a minor commit message wording improvement.

Phillip Wood provided sequencer expertise during review, raising thoughtful questions about validation placement that led to productive discussion about tradeoffs between early validation versus inline error handling. The thread reached full consensus, with the changes now merge-ready. This establishes a clear convention for future: BUG() assertions should never be translated, completing a cross-cutting style improvement across the codebase.
