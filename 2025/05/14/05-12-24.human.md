Opening patch in Patrick Steinhardt's series to eliminate `the_repository` usage from Git's object database subsystem. This first patch renames the central `raw_object_store` structure to `object_database` (ODB) as part of making the object subsystem more self-contained for future pluggable backends.

The change is primarily a naming improvement - the "raw_" prefix was misleading (there is no non-raw variant) and the new name better reflects the structure's role as the central access point for repository objects. The rename enables cleaner API naming like `odb_has_object()` instead of the unwieldy `raw_object_store_has_object()`. 

This foundational change touches 8 files with straightforward mechanical updates to type names and related function names (`raw_object_store_new` becomes `odb_new`, etc.). The patch includes documentation clarifying the ODB's role in managing object directories and alternates. As the first in a fully-reviewed 17-part series, this establishes naming conventions that will be used consistently throughout the remaining patches.
