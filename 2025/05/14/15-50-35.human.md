This is a refactoring patch in the packed-refs optimization series, specifically extracting buffer allocation logic into a reusable helper function. 

The patch moves the core buffer allocation logic from `load_contents()` into a new `allocate_snapshot_buffer()` function, keeping the same behavior but making the code more modular. The change allows this logic to be reused elsewhere (particularly in the fsck verification path) while maintaining all the existing functionality - including the 32KB threshold for mmap vs read decisions and Windows-specific handling.

The patch has gone through multiple review iterations (v1-v5) with input from Jeff King and Patrick Steinhardt, and appears ready for merging. The changes are straightforward - 53 lines modified with 31 additions and 22 deletions - and maintain all the existing edge case handling while making the code more maintainable. This is part of a larger effort to standardize memory handling in the packed-refs backend.
