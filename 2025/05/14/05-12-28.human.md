This is part of Patrick Steinhardt's ongoing refactoring series to remove `the_repository` global state from Git's object database subsystem. Patch 5/17 continues the mechanical conversion by eliminating `the_repository` usage in `find_odb()`, renaming it to `odb_find_alternate()` to match the new naming conventions.

The change is straightforward - instead of taking a `repository` parameter, the function now takes a direct `object_database` pointer, which is more precise since it only needs access to the ODB's alternate list. The patch updates three callers in commit-graph and midx code to pass `the_repository->objects` instead of `the_repository`.

This is a clean, focused change that follows the architectural direction established in earlier patches. The diff shows careful attention to maintaining existing behavior while advancing the series' goal of proper repository encapsulation. With Derrick Stolee's previous review and Junio Hamano's approval of the approach, this appears ready for inclusion.
