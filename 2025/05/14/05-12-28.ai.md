Refactoring patch in the ongoing `the_repository` removal series, specifically targeting the object database (ODB) subsystem. This is patch 5/17 in Patrick Steinhardt's v3 series.

The patch removes the dependency on `the_repository` in the `find_odb()` function by:
1. Renaming it to `odb_find_alternate()` to follow the new ODB API naming convention
2. Changing the parameter from `struct repository *` to `struct object_database *`
3. Updating all callers in `builtin/commit-graph.c` and `midx-write.c` to pass `the_repository->objects` instead of `the_repository`

The changes are mechanical but important for the architectural goal of removing global state. The function now operates directly on the ODB structure (which already contains a backpointer to its owning repository via the `repo` field added in patch 4/17). The patch maintains all existing functionality while making the code more explicit about its dependencies.

Key technical details for future reference:
- Function renamed from `find_odb()` to `odb_find_alternate()`
- Parameter type changed from `repository*` to `object_database*`
- Call sites updated in commit-graph and midx-write operations
- Still dies if object directory can't be found (behavior preserved)
- Documentation added in `odb.h` clarifying the function's purpose

This continues the systematic conversion of ODB-related code to work without `the_repository`, following the foundation laid in earlier patches. The changes are straightforward and unlikely to be controversial given the established direction of the series.
