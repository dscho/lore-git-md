This is part of Patrick Steinhardt's ongoing series to refactor Git's object database (ODB) subsystem, specifically targeting the removal of `the_repository` global state. Patch 9/17 focuses on converting iterator-style functions that operate on alternate object databases to explicitly take an ODB parameter rather than relying on the global state.

The patch renames two key iteration functions: `foreach_alt_odb()` becomes `odb_for_each_alternate()` and `for_each_alternate_ref()` becomes `odb_for_each_alternate_ref()`. Both now require an explicit `object_database*` parameter. The changes propagate through several callers including count-objects, receive-pack, submodule handling, diagnostics, and fetch operations.

This is a mechanical conversion that follows the established pattern from earlier patches in the series - updating function signatures and call sites while maintaining the same behavior. The changes are straightforward and touch expected parts of the codebase that interact with alternate object stores. The patch continues the systematic elimination of `the_repository` usage in the ODB subsystem, building on the architectural changes introduced in earlier patches.
