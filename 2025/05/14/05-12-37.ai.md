This is part 14/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove `the_repository` global state. The patch renames `repo_read_object_file()` to `odb_read_object()` to align with the new naming conventions established in earlier patches. 

The change is mechanical but extensive, updating 47 files across the codebase to use the new function name. A compatibility wrapper is provided to avoid breaking in-flight topics. The rename follows the pattern seen in previous patches of prefixing ODB-related functions with `odb_` and passing the object database explicitly rather than implicitly via `the_repository`.

Key technical details:
- Function signature remains the same but moves from repository.h to odb.h
- Takes `struct object_database*` instead of `struct repository*`
- Maintains same behavior for reading objects from the ODB
- Updates all callers to pass `repo->objects` explicitly
- Part of systematic elimination of `the_repository` usage in ODB code

This continues the series' pattern of mechanical conversions that maintain functionality while enabling future pluggable ODB work. The change is straightforward and unlikely to be controversial given it follows established patterns from earlier reviewed patches in the series.
