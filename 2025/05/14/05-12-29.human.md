This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database subsystem. Patch 6/17 focuses on `assert_oid_type()`, which verifies that an object ID matches an expected type (commit, tree, etc.).

The patch removes the function's implicit dependency on `the_repository` by making the object database parameter explicit, renaming it to `odb_assert_oid_type()` in the process. The changes are straightforward - the function now takes an `object_database` parameter and uses its `repo` field rather than the global. Callers in `commit-tree.c` and `commit.c` are updated to pass `the_repository->objects`.

This continues the series' systematic approach to decoupling the ODB code from global state. The changes are mechanical but important for the larger architectural shift toward repository-aware object handling. The patch maintains all existing behavior while making the repository context explicit, which will enable future work on pluggable ODB backends.
