Refactoring patch in the ongoing `the_repository` removal series. This is patch 15/17 from Patrick Steinhardt's series to modernize Git's object database (ODB) subsystem.

The patch renames `has_object()` to `odb_has_object()` to match the naming convention established in earlier patches, where ODB-related functions are prefixed with `odb_`. The change is mechanical but widespread, touching 30 files across the codebase to update all callers. A compatibility wrapper is provided to avoid breaking any in-flight topics that might still use the old function name.

This continues the systematic approach seen in previous patches - maintaining functionality while updating the API to be more explicit about object database access. The changes are straightforward and follow the established pattern of the series, with no functional changes intended. The patch appears well-contained and properly documented, with a clear commit message explaining the rationale.
