This is patch 3/17 in Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem, part of the ongoing `the_repository` removal effort. Following the renaming of core structures in previous patches, this change updates the filenames from "object-store.{c,h}" to "odb.{c,h}" to better reflect their contents. The patch is mechanical, touching 126 files to update includes and build system references.

The change is straightforward and uncontroversial, aligning the filenames with the new naming scheme where the main structure is now called `struct object_database`. The patch maintains all existing functionality while making the codebase more consistent. Given this is part of an already-reviewed series with Junio Hamano's approval, it's a simple rename with no behavioral impact, and follows logically from the structural changes in earlier patches.
