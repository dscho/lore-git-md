This is part 16/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove `the_repository` global state. The patch continues the mechanical renaming work by converting `pretend_object_file()` to `odb_pretend_object()`, aligning it with the new ODB naming conventions established in earlier patches.

The function is used to temporarily cache an in-memory object before writing it to disk, primarily in `blame.c` for fake working tree commits. The change follows the pattern seen throughout this series: updating the function signature to take an explicit `object_database` parameter instead of a `repository`, and renaming with the `odb_` prefix for consistency.

Since the function has limited usage (only one caller in `blame.c` is shown), no compatibility wrapper is provided. The implementation remains functionally identical while using the new ODB structure and naming. This is a straightforward continuation of the systematic refactoring approach seen in previous patches, maintaining the series' focus on mechanical conversions that don't alter behavior.
