This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global state from Git's object database (ODB) subsystem, specifically focusing on alternate object database handling. Patch 10/17 continues the mechanical conversion of functions to take an explicit `object_database*` parameter instead of implicitly using `the_repository`.

The patch refactors two key functions that manage temporary primary alternates: `set_temporary_primary_odb()` becomes `odb_set_temporary_primary_alternate()` and `restore_primary_odb()` becomes `odb_restore_primary_alternate()`. Both now require explicit ODB parameters. The changes propagate through `tmp-objdir.c` where these functions are used for temporary object directory operations.

This is a well-established pattern in the series - taking functions that previously relied on global state and making their dependencies explicit. The changes are straightforward and maintain existing behavior while advancing the architectural goal of removing `the_repository` usage. The patch follows the series' naming conventions and includes updates to both implementation and header files.

As with previous patches in the series, this appears to be a mechanical but important step in the larger refactoring effort, with no expected functional changes. The changes are focused and the commit message clearly explains the what and why of the modifications.
