Maintainer ack for git-gui newline fix. Junio C Hamano agrees with Johannes Sixt's patch that fixes a double-newline issue in git-gui commit messages. The problem occurs when the text widget's built-in newline combines with Tcl's `puts` adding another. The solution replaces multiple regex substitutions with a single `string trim` operation that handles both leading and trailing newlines more cleanly.

Hamano notes this is particularly important for git-gui since it uses plumbing commands (`commit-tree`) directly rather than porcelain (`git commit`), which means it can't rely on `stripspace`-like behavior to clean up the message. The change maintains the same functionality while simplifying the code.
