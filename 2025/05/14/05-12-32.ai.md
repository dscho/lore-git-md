This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global from Git's object database (ODB) subsystem (patch 9/17). The patch focuses on iterator-style operations that traverse alternate object databases, converting them from global-state-dependent functions to explicitly parameterized versions.

The changes rename and refactor two key iteration functions:
- `foreach_alt_odb()` becomes `odb_for_each_alternate()`
- `for_each_alternate_ref()` becomes `odb_for_each_alternate_ref()`

Both now take an explicit `object_database*` parameter instead of implicitly using `the_repository`. The patch updates all callers across 8 files (count-objects, receive-pack, submodule--helper, diagnose, fetch-pack, revision) to pass `the_repository->objects` explicitly. The implementation preserves all existing behavior while making the ODB dependency graph explicit through the new parameterization.

The changes include thorough documentation updates in `odb.h` clarifying the purpose and usage of these iteration functions. The patch continues the series' systematic approach of mechanical conversions that maintain functionality while enabling future pluggable ODB work. All updates follow the established naming conventions from earlier patches in the series.
