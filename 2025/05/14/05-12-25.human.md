This is part 2/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem, specifically renaming the `object_directory` structure to `odb_alternate`. The change is motivated by the long-term goal of supporting pluggable object storage backends that may not use traditional filesystem directories.

The patch renames the structure and updates all related function signatures and variable names across 28 files (~270 lines changed). The new name better reflects the structure's role as an access point for alternate object storage, without implying filesystem specifics. The commit message explains that while "object directory" works today, future backends might use databases or other storage mechanisms, making "alternate" a more agnostic term.

This is a mechanical rename with no behavior changes, continuing the systematic cleanup from part 1. The change is wide-ranging but straightforward, touching components like commit-graph handling, loose object management, and temporary object directories. The patch maintains consistency with the series' goal of establishing clear naming conventions for the ODB subsystem.

As with the rest of the series, this has already been reviewed (Derrick Stolee's Reviewed-by) and is in final form for integration. It provides foundational naming that will be built upon in later patches for pluggable ODB support.
