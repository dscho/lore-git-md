This is part 2/17 of Patrick Steinhardt's v3 series refactoring Git's object database (ODB) subsystem, continuing the systematic removal of `the_repository` usage. The patch renames the `object_directory` structure to `odb_alternate` to better reflect its role in the future pluggable ODB architecture.

The key change is a mechanical rename across 28 files (~270 lines changed) where `object_directory` becomes `odb_alternate`, with related functions and variables updated to use "alternate" terminology. The commit explains this prepares for a future where object storage may not be directory-based (e.g., database-backed), making the current name misleading. The new name is agnostic to storage format while still indicating this represents an ODB alternate.

The patch maintains all existing behavior - it's purely a naming change building on the foundational work in patch 1/17 that renamed `raw_object_store` to `object_database`. The changes are now in final form with Junio Hamano's approval and Derrick Stolee's Reviewed-by, indicating technical consensus on the approach.

This continues the series' pattern of establishing clear naming conventions (`odb_` prefix for ODB subsystem components) while removing implicit `the_repository` dependencies. The change touches core ODB access paths but is low-risk as it doesn't modify logic - just naming and type signatures.
