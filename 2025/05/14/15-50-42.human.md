Optimization patch for packed-refs fsck verification. This is the final patch in a v5 series that standardizes memory handling in the packed-refs backend, with all technical aspects already reviewed and approved by Jeff King, Patrick Steinhardt, and Junio Hamano.

The patch replaces `strbuf_read()` with the new `allocate_snapshot_buffer()` helper function during fsck operations, bringing memory usage in line with other packed-refs operations. This change means large packed-refs files will now be memory-mapped rather than read into a buffer, reducing memory consumption while maintaining the same verification behavior. The patch preserves all existing functionality including empty file detection and Windows-specific handling.

The series as a whole has gone through multiple review rounds addressing filesystem safety considerations and refactoring improvements. This final patch is a straightforward application of the new helper function, with the diff showing a net reduction of 5 lines. The changes are mechanical with no behavior modifications beyond the memory optimization.
