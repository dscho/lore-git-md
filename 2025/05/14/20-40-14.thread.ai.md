RFC proposal for `git diff --no-index --exclude=<pattern>` to skip matching files during directory comparison. Authored by Jacob Keller, this patch adds a simple wildmatch-based exclusion mechanism to avoid recursing into `.git` directories and similar cases when comparing directories outside a repository.

Core implementation:
- Adds `--exclude` option via `OPT_STRING_LIST` storing patterns
- Uses `wildmatch()` against filenames in `read_directory_contents()`
- Modifies diff queue logic to skip excluded paths
- Limited to `--no-index` mode (regular diffs use pathspecs with `:!` syntax)

Design discussion:
- Junio C Hamano questions whether a separate `--exclude` mechanism is preferable to implementing full pathspec support
- Notes inconsistency between repository diff (pathspecs) and non-repository diff (proposed `--exclude`)
- Suggests users would expect feature parity between modes
- Acknowledges command-line parsing complexity in `--no-index` mode already supports multiple comparison types (files vs directories)

Open questions:
- Whether to proceed with current `--exclude` approach or invest in pathspec support
- Need for tests and documentation before merging
- Potential interaction with other diff options
- Implementation challenges of pathspec support in `--no-index` context

Current status: Initial version remains RFC while design consensus forms. Core exclusion functionality validated but implementation approach under discussion.
