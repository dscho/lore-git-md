This is part of Patrick Steinhardt's ongoing series to remove `the_repository` global from the object database (ODB) subsystem, specifically targeting the `odb_mkstemp()` function. The patch converts `odb_mkstemp()` to take an explicit `object_database*` parameter instead of implicitly using `the_repository`, updating all callers to pass their repository's ODB instance. The changes are mechanical but touch several key areas including packfile creation (`fast-import`, `index-pack`), bitmap writing, and bundle URI handling.

The function now uses the passed ODB's repository pointer for path operations rather than `the_repository`, maintaining the same behavior while removing global state. The patch updates 7 files with straightforward caller adjustments, mostly passing `the_repository->objects` where the function was previously called without context. The ODB header documentation is also updated to clarify the function operates on the primary alternate's directory.

This continues the series' pattern of methodically removing `the_repository` dependencies while preserving all existing functionality. The changes propagate through temporary file creation paths used during pack operations, maintaining the architectural direction established in earlier patches. Since this is a well-contained refactor with no behavior change, it should integrate cleanly with the series' prior work.
