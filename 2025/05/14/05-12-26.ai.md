This is part 3/17 of Patrick Steinhardt's refactoring series to remove `the_repository` usage from Git's object database (ODB) subsystem. The patch renames the core object store files from `object-store.{c,h}` to `odb.{c,h}` to match the new naming conventions established in previous patches (where `raw_object_store` was renamed to `object_database` and `object_directory` to `odb_alternate`).

The change is mechanical, updating 126 files to use the new header name. The diff shows the Makefile and meson.build updates to reference the new filenames, plus the header include changes across the codebase. The patch maintains all existing functionality while aligning the filenames with the new structural naming scheme.

This continues the systematic cleanup from patches 1-2, which introduced the new ODB terminology. The changes are straightforward and unlikely to be controversial, as with the rest of the v3 series which has already received review approvals. The patch helps complete the architectural foundation for future ODB work by ensuring all components use consistent terminology.
