This is a cleanup patch in Patrick Steinhardt's ongoing series to modernize Git's `contrib/` directory. It removes the long-empty `contrib/examples/` directory and its README, which had been kept as a historical note after the actual example scripts were removed in 2018. The patch follows the established pattern in this series of removing clearly obsolete components - in this case, the directory has been empty for over 7 years and the README's advice about examining old commits for examples is no longer relevant to modern Git development.

The change is straightforward and uncontroversial, deleting 20 lines of documentation that pointed to development practices from Git's earlier shell-script-heavy days. The commit message notes this is unlikely to affect anyone, as the examples haven't been actively used in years. This removal aligns with the thread's broader goal of reducing maintenance burden by cleaning up unneeded historical artifacts in `contrib/`.

As with other patches in this series, this demonstrates the project's shift away from keeping "batteries included" historical artifacts toward a more focused `contrib/` directory. The change requires no special handling beyond what's shown in the diff - it's a simple deletion of obsolete material.
