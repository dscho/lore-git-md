This is the final patch (11/11) in Patrick Steinhardt's series cleaning up Git's `contrib/` directory, focusing on removing the obsolete "stats" directory and its scripts. The patch removes three statistical analysis tools that have either bitrotted or been superseded by core Git functionality:

1. `git-common-hash` (last updated 2012) calculates hash prefix uniqueness - functionality now handled automatically by Git's heuristics.
2. `mailmap.pl` (last updated 2012) analyzes mailmap usage but fails to run on modern Perl due to syntax changes.
3. `packinfo.pl` (last updated 2008) prettifies `git verify-pack` output but shows no evidence of current use.

The removal follows the established pattern from earlier patches in the series: identifying unmaintained scripts (5+ years without updates), verifying they're unused (no internet mentions, compilation failures), and noting when core Git provides equivalent functionality. The patch completes the technical cleanup portion of the series, having now excised twenty-four obsolete components from `contrib/`.

This well-documented removal exemplifies the series' systematic approach - each case includes specific evidence justifying deletion while maintaining transparency about the decision process. With this final removal, attention now shifts to formalizing the maintenance policy in `contrib/README`.
