This is a cleanup patch (9/11) in Patrick Steinhardt's systematic removal of obsolete `contrib/` components, specifically targeting the Emacs integration files. The patch removes three files from `contrib/emacs/` that have been effectively non-functional since 2018 when they were replaced with stubs pointing users to modern alternatives.

The removal follows the established pattern for obsolete functionality with modern alternatives, similar to the earlier git-resurrect.sh removal. The commit message notes these Emacs utilities were superseded by Emacs' built-in vc-annotate mode and third-party packages like Magit. The files being removed are:
- `git.el` (wrapper for git status)
- `git-blame.el` (blame interface)
- Their README explaining the deprecation

The patch is straightforward with no technical complications - the files have been effectively deprecated for 7 years and the README already documents the recommended alternatives. This continues the series' pattern of thorough cleanup, removing not just the main files but also their documentation. The removal aligns with the project's criteria for `contrib/` cleanup, demonstrating another case where core functionality has been absorbed into either Git itself or the broader ecosystem.
