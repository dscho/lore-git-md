This is a follow-up in the ongoing discussion about incremental Git backups, focusing on practical implementation details. Michal Suchánek provides specific technical steps for optimizing backup repositories and suggests an untested approach for incremental backups.

For incremental backups, Michal proposes an experimental approach using shared clones from the full backup, with fetch operations to update them. The method involves careful handling of repacking with `--local` and maintaining read-only backups to prevent corruption. While the incremental approach is acknowledged as untested, it builds on Git's object sharing capabilities.

The suggestions align with the thread's technical progression, offering a filesystem-level alternative to the pack-based solutions previously discussed.
