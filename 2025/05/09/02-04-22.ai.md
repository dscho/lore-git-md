Cleanup of unused reftable code. This is version 2 of a patch that originally aimed to fix a theoretical memory leak in the REFTABLE_REALLOC_ARRAY macro, but has now been simplified to just remove the macro entirely since it was found to be unused in the codebase.

The patch removes REFTABLE_REALLOC_ARRAY from reftable/basics.h along with its associated documentation. The macro had a memory leak issue when realloc failed, but since investigation showed it wasn't actually being used anywhere, the simpler solution is to just remove it rather than fix it. The change is straightforward - deleting 10 lines while keeping the related REFTABLE_CALLOC_ARRAY macro intact.

This follows through on the resolution reached in the thread discussion, where reviewer René Scharfe suggested removal would be better than fixing unused code. The author Lidong Yan has updated the commit message to reflect this change in approach from v1 (which contained a more complex fix) to v2's simpler removal. The patch represents good code hygiene by eliminating dead code that could otherwise become a maintenance burden.
