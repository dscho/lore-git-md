This is part 2/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to decouple it from `the_repository`. The patch renames the `object_directory` structure to `odb_alternate` to better reflect its role as an access point for object storage that may not always be directory-based in the future.

The change is motivated by the long-term goal of supporting pluggable object backends beyond filesystem directories, such as databases. The new name `odb_alternate` is storage-agnostic while still indicating this represents an object database alternate. The patch updates 28 files with the rename, affecting function signatures and variable names throughout the codebase.

This is a straightforward mechanical rename that follows the foundational change in patch 1/17 (renaming `raw_object_store` to `object_database`). The series has already undergone architectural review, with core naming decisions settled. This patch continues the systematic modernization of ODB-related terminology while maintaining backward compatibility needed for the multi-patch transition.
