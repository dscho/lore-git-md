This is part 6/11 of Patrick Steinhardt's series removing unmaintained components from Git's `contrib/` directory. The patch removes the "mw-to-git" MediaWiki transport helper, which was previously spun out to a separate project but has seen little activity there as well.

The removal follows the established criteria for `contrib/` cleanups: the code is unmaintained (last security fixes in 2020), tests are likely broken, and there's an external home for the project (Git-Mediawiki/Git-Mediawiki on GitHub). The patch deletes 22 files totaling 3911 lines, including Perl modules, test infrastructure, and documentation.

Key technical details: The mw-to-git directory contained tools for bidirectional synchronization between Git and MediaWiki, including a remote helper implementation (`git-remote-mediawiki.perl`), utility scripts, and extensive test infrastructure. The removal was confirmed with original developer Matthieu Moy, noting the functionality has effectively faded from the ecosystem.

This continues the systematic cleanup pattern seen in previous patches, now addressing a case where code was already externalized but remained in Git's tree. The change doesn't affect core Git functionality but removes technical debt from the project.
