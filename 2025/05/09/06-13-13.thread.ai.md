Platform compatibility fix for BSD CPU detection in `thread-utils.c`, addressing incorrect CPU count reporting on OpenBSD/NetBSD systems with SMT disabled. The patch modifies `online_cpus()` to first check `HW_AVAILCPU`, then the BSD-specific `HW_NCPUONLINE` (where available), falling back to `HW_NCPU`. This ensures accurate reporting of active CPUs rather than physical cores when SMT is disabled, while maintaining existing behavior on other platforms.

No technical objections remain; this is a straightforward, low-risk improvement for affected BSD systems.
