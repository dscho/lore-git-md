This is the cover letter for Patrick Steinhardt's 17-patch series refactoring Git's object database (ODB) subsystem, marking the transition from using the global `the_repository` to passing object databases explicitly. The series builds on prior work to remove `the_repository` dependencies and establishes a clear `odb_` prefix for the ODB subsystem's functions.

The series progresses through several key phases: first renaming core structures and files (patches 1-3), then removing `the_repository` dependencies from ODB functions (patches 4-12), and finally standardizing function names with `odb_` prefixes (patches 13-17). A notable change in v2 is the renaming of `struct odb_backend` to `struct odb_alternate` following feedback, though Patrick remains open to reverting if reviewers prefer the original name.

The changes touch 139 files with over 1,000 lines modified, demonstrating the wide impact of this architectural shift. The series is now in its finalization stage, with reviewers having approved the core approach while identifying some edge cases to verify (particularly around object peeling in patch 17) and documentation clarations needed for the "primary alternate" concept.

Patrick hints at future work for pluggable object backends, suggesting this refactoring lays groundwork for storage implementations beyond the current filesystem approach. The thread shows careful attention to maintaining backward compatibility where needed (like keeping "alternate" in user-facing configs) while modernizing internal APIs.
