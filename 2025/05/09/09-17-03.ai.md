This is part of Patrick Steinhardt's systematic cleanup of Git's `contrib/` directory, specifically targeting obsolete remote helper stubs for Mercurial and Bazaar. The patch removes three files from `contrib/remote-helpers/`: two stub scripts (`git-remote-bzr` and `git-remote-hg`) and their README, which had been converted to mere redirects pointing to external repositories back in 2014 (commit b2c851a8e67).

The removal follows the established pattern for this cleanup series - targeting components that have been obsolete for over a decade (meeting the 5+ years criterion) and where functionality exists in maintained external projects. The stubs served only to warn users about the move to external maintenance, with the actual implementations living in Felipe Contreras' GitHub repositories for both tools.

Technical details show these were simple deletion cases - the files contained only warning messages and installation instructions pointing to the external projects, with no active functionality. This differs slightly from other removals in the series as these weren't replaced by core Git features but rather by separate projects, though the same "clearly obsolete" justification applies.

The patch continues the thread's progression from individual component removals toward establishing formal `contrib/` maintenance policies, though this particular change doesn't introduce new patterns beyond what was already demonstrated with prior removals. It does reinforce the criteria of removing artifacts that have served only as historical markers for extended periods.
