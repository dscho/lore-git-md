This is part 9 of Patrick Steinhardt's ongoing refactoring series to remove `the_repository` dependency from Git's object database subsystem. The patch converts iterator-style functions that walk alternate object databases to explicitly take an object database parameter instead of relying on the global `the_repository`.

The changes rename two key functions:
- `foreach_alt_odb()` becomes `odb_for_each_alternate()`
- `for_each_alternate_ref()` becomes `odb_for_each_alternate_ref()`

The patch updates 8 call sites across various commands (count-objects, receive-pack, submodule--helper, diagnose, fetch-pack, and revision walking) to use the new function signatures. The implementation remains largely the same but now operates on an explicitly passed object database rather than the implicit global.

This continues the series' systematic approach to decoupling object storage operations from repository state. The changes are mechanical but important for enabling future work with multiple repository instances. The patch appears well-contained with no obvious functional changes - it simply threads the object database parameter through existing alternate iteration logic.
