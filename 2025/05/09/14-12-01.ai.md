This is the first patch in Patrick Steinhardt's 17-part series refactoring Git's object database subsystem as part of the `the_repository` removal effort. The patch renames the core `raw_object_store` structure to `object_database` (abbreviated as ODB), establishing clearer terminology for the object storage subsystem.

The change addresses several naming issues: the "raw_" prefix was misleading (implying a non-raw variant that doesn't exist), the new name better reflects the structure's role as the central object storage interface, and it enables more natural function naming conventions like `odb_has_object()`. The patch updates all related function names (`raw_object_store_new` -> `odb_new`, `raw_object_store_clear` -> `odb_clear`) and includes a new comment block explaining the structure's purpose.

The mechanical changes span 8 files with 24 insertions and 19 deletions, primarily updating type names and function signatures. This foundational rename sets up subsequent patches that will make the ODB subsystem more self-contained and explicit about its dependencies, moving away from implicit `the_repository` access. The patch is part of a carefully planned architectural shift that has already undergone significant design review, with this particular naming having been validated in prior discussion.
