This thread addresses a platform-specific issue with CPU detection on OpenBSD and NetBSD systems. The patch modifies `thread-utils.c` to properly handle cases where symmetric multithreading (SMT) is disabled, ensuring Git correctly detects the number of active CPUs rather than physical cores. The change introduces a new check for `HW_NCPUONLINE` where available, while maintaining the existing fallback chain of `HW_AVAILCPU` and `HW_NCPU` for other platforms.

The implementation is focused and non-disruptive, touching only the thread-utils subsystem while preserving behavior on all other platforms. The commit message clearly explains the BSD-specific motivation and maintains Git's established patterns for CPU detection. This appears to be a straightforward, low-risk improvement that better aligns Git's behavior with BSD system realities when SMT is disabled.
