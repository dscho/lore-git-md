This thread addresses a platform-specific issue in Git's CPU detection for BSD systems, particularly OpenBSD and NetBSD with SMT disabled. The original patch from Brad Smith fixed incorrect core count reporting by modifying `online_cpus()` in `thread-utils.c` to properly handle these cases, using `HW_AVAILCPU` and the BSD-specific `HW_NCPUONLINE` parameter before falling back to `HW_NCPU`.

Patrick Steinhardt, a core contributor with deep system knowledge, reviewed and approved the change, confirming it correctly implements the intended behavior by referencing OpenBSD documentation. The solution maintains existing behavior on other platforms while fixing the BSD case, making it a low-risk improvement. With this authoritative review and no outstanding objections, the patch appears ready for inclusion. The change remains neatly contained within the thread-utils subsystem without broader impacts.
