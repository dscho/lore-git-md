This is a cleanup patch in Patrick Steinhardt's systematic `contrib/` directory removal series, specifically targeting the long-obsolete `contrib/examples/` directory. The patch removes a README file that had been kept as a historical marker after the actual example scripts were removed in 2018 (commit 49eb8d39c78). The rationale is straightforward: after 7+ years, the historical note is no longer useful for discovery, and removing it simplifies the codebase.

The technical change is minimal - deleting a single README file that contained explanatory text about previously removed example scripts. The commit message notes these scripts were originally shell implementations of builtins later rewritten in C, and that the README itself suggested alternative ways to study Git's internals (like using `GIT_TRACE=1` or examining `--helper.c` files).

This follows the established pattern in the series of removing clearly obsolete components, though unlike some other removals in the thread, this one doesn't involve functionality being replaced by core Git features - it's purely about cleaning up historical artifacts. The patch is uncontroversial and aligns with the broader effort to reduce maintenance burden of the `contrib/` directory.
