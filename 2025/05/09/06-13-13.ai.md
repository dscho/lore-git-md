Platform compatibility patch for OpenBSD/NetBSD CPU detection. This change modifies `thread-utils.c` to properly detect online CPU counts on BSD systems by prioritizing `HW_NCPUONLINE` where available, falling back to existing methods otherwise.

The patch addresses a specific issue where OpenBSD systems with SMT disabled would get incorrect CPU counts from `HW_NCPU` (which reports physical cores rather than active ones). The implementation maintains the existing fallback chain: first try `HW_AVAILCPU`, then the new `HW_NCPUONLINE` check, and finally default to `HW_NCPU`.

Key technical details:
- Changes the conditional logic in `online_cpus()` to test these macros in order
- Preserves all existing behavior for other platforms
- Specifically helps OpenBSD/NetBSD systems where SMT may be disabled
- Touches only the thread-utils subsystem
