This is part 6/11 of Patrick Steinhardt's series removing unmaintained components from Git's `contrib/` directory. The patch removes the "mw-to-git" MediaWiki transport helper, which provided tools for accessing MediaWiki via Git.

The removal is justified by several factors: the scripts have been essentially unmaintained in Git for years, with the last changes being security fixes in 2020. The tests haven't been run regularly, likely causing test bitrot. The original developer confirmed there's no motivation to keep maintaining it in the Git community. The project has been spun out to GitHub (Git-Mediawiki/Git-Mediawiki) but hasn't seen much activity there either.

The patch removes 22 files totaling 3911 lines of code, including:
- Perl modules and scripts for the MediaWiki interface
- Test files and infrastructure
- Documentation
- Makefiles and configuration files

This follows the established pattern in the series of removing unmaintained components that have clear alternatives or have fallen into disuse. The MediaWiki case demonstrates another category where functionality has been successfully externalized but isn't worth keeping in Git's main repository. The commit message is thorough, explaining the rationale and providing references to the external project location and developer confirmation.

The removal is straightforward with no expected controversy, as it aligns with the series' goal of cleaning up technical debt in contrib/. No functionality is being removed from core Git, just an unmaintained helper script that few if any users likely depend on directly from Git's repository.
