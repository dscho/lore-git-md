This is part of Patrick Steinhardt's ongoing refactoring series to remove `the_repository` global from Git's object database subsystem (patch 6/17). The patch continues the mechanical conversion work by updating `assert_oid_type()` to take an explicit `struct object_database*` parameter instead of implicitly using `the_repository`, renaming it to `odb_assert_oid_type()` in the process.

The changes are straightforward - the function signature and implementation now accept the ODB parameter, and all callers (commit-tree and commit.c) are updated to pass `the_repository->objects` explicitly. The function's behavior remains identical - it still verifies that an object exists and matches the expected type, just with the repository access now routed through the provided ODB structure.

This follows the established pattern in the series of systematically converting functions to use explicit ODB parameters while maintaining the same functionality. The patch is small and focused, with clean mechanical changes that appear correct at first glance. It builds naturally on the structural foundation laid by earlier patches in the series.
