This is part 9/11 of Patrick Steinhardt's systematic cleanup of Git's `contrib/` directory, focusing on removing obsolete Emacs support files. The patch removes the `contrib/emacs/` directory, which has contained only stubs since 2018 when the actual functionality was removed in commit 6d5ed4836db.

The removal is justified by the code being long obsolete, with the README itself recommending modern alternatives like Emacs's built-in vc-annotate mode and third-party packages like Magit. The patch deletes three files: the README explaining the deprecation, and two `.el` files that just contained error messages pointing users to alternatives.

This follows the established pattern in the series of removing components that have been functionally replaced by better-maintained alternatives. The case is straightforward since the code has been non-functional for years and the transition path for users is well-documented. The patch is cleanly scoped, removing exactly the files that have been marked obsolete.
