This is part 10/17 of Patrick Steinhardt's series refactoring Git's object database subsystem to remove dependencies on `the_repository` global. The patch focuses on temporary primary alternate handling.

The patch converts two functions that manage temporary primary alternates (`set_temporary_primary_odb()` and `restore_primary_odb()`) to explicitly take an object database parameter instead of implicitly using `the_repository`. The functions are renamed to `odb_set_temporary_primary_alternate()` and `odb_restore_primary_alternate()` to follow the series' naming conventions.

The changes are mechanical but important for the overall goal of removing global state. The patch updates all three call sites in `tmp-objdir.c` to pass the repository's ODB explicitly. The functionality remains identical - these functions are used when Git needs to temporarily redirect object storage, such as during certain maintenance operations.

This continues the series' systematic approach of making ODB operations repository-agnostic. The changes are straightforward and maintain existing behavior while progressing the architectural goal of removing `the_repository` dependencies from the object storage layer.
