This is a Git-gui maintenance pull request with two main themes: translation workflow improvements and commit message comment character handling.

The pull request combines work from Johannes Sixt and Oswald Buddenhagen. Sixt's changes focus on the translation infrastructure, updating the po/README with current repository information and treating the generated git-gui.pot file as ephemeral (removing it from version control). Buddenhagen's contribution makes git-gui respect the core.commentChar and core.commentString configurations when processing commit messages.

Key technical details:
- The po/git-gui.pot file is deleted from the repository as it should be generated rather than tracked
- po/.gitignore is updated to reflect this
- The commit message template handling in lib/commit.tcl is modified to use configured comment characters
- The Makefile and git-gui.sh receive minor adjustments to support these changes

The changes appear straightforward and well-contained to the git-gui component. The removal of the generated .pot file follows common practice for translation template files, while the comment character handling brings git-gui in line with core Git behavior. The patch series is cleanly split between these two independent improvements.
