This is the first patch in Patrick Steinhardt's 17-part series refactoring Git's object database subsystem as part of the `the_repository` removal effort. It renames the core `raw_object_store` structure to `object_database` (ODB) to better reflect its purpose and establish clearer naming conventions for the object storage subsystem.

The patch makes a straightforward but wide-reaching change, updating the type name across 8 files with mechanical replacements. The commit message explains that the "raw_" prefix was misleading (there is no non-raw variant) and that "object_database" better describes the structure's role while allowing for cleaner function naming (like `odb_has_object()`). This aligns with the series' goal of making the object subsystem more self-contained for potential pluggable backends.

The changes are purely structural - no behavior is modified. The patch shows careful attention to detail, updating both declarations and implementations while adding clarifying documentation for the new `object_database` struct. As the foundational rename in a large series, it sets the naming pattern that subsequent patches will follow when decoupling object storage from `the_repository`.
