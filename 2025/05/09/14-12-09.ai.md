This is part 9/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove dependencies on `the_repository`. The patch converts iterator-style functions that operate on alternate object databases to explicitly take an ODB parameter instead of implicitly using the global repository.

The changes rename and modify three key iteration functions:
- `foreach_alt_odb()` -> `odb_for_each_alternate()`
- `for_each_alternate_ref()` -> `odb_for_each_alternate_ref()`
- Updates their callback typedefs with new `odb_`-prefixed names

The patch updates 8 call sites across various commands (count-objects, receive-pack, submodule--helper, diagnose, fetch-pack, revision) to pass `the_repository->objects` explicitly. The implementation preserves all existing behavior while making the ODB dependency explicit through parameter passing.

Key technical details:
- Maintains same callback signatures but with renamed types
- Preserves all existing error handling and control flow
- Updates function documentation in odb.h
- Touches core ODB iteration logic in odb.c
- Affects alternate ref handling used by fetch, push, and revision walking

This continues the series' systematic approach to ODB decoupling, now tackling the iteration patterns after having established the core structure renaming and parameter passing in earlier patches. The changes are mechanical but important for completing the removal of implicit repository dependencies from the ODB subsystem.
