This is the final patch in Patrick Steinhardt's 17-part series refactoring Git's object database subsystem to remove implicit `the_repository` usage. The patch renames `read_object_with_reference()` to the more descriptive `odb_read_object_peeled()`, better reflecting its actual behavior of recursively following tags and commits ("peeling") to reach an object of the requested type.

The change follows the series' pattern of making object access operations explicitly ODB-centric with consistent naming. The patch does is mechanical - updating callers in 8 files (including documentation) to use the new name and pass the object database parameter directly rather than going through the repository. The function's behavior remains unchanged.

This completes the conversion of all major object database operations in the series. The remaining work (as noted in previous patches) focuses on performance validation and documentation. The patch appears well-executed with thorough updates to all call sites, though it's worth noting this function isn't widely used in the codebase (only 8 callers needed updating).
