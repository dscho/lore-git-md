The main change from v1 is in the commit message - it now references the function name rather than specific line numbers, following project conventions as suggested by Patrick Steinhardt in the previous review. The actual code change remains the same - a straightforward 2-line addition for proper resource cleanup.

The technical solution is minimal and focused, adding the necessary cleanup calls before the error handling jump to `cleanup`. This affects only the error path when dealing with pack index opening failures, with no impact on normal operation.
