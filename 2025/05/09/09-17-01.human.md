This is a cleanup patch removing an obsolete migration script from Git's `contrib/` directory, part of Patrick Steinhardt's systematic effort to modernize this area. The script `remotes2config.sh` was meant to help transition from the old `.git/remotes/` configuration style to the modern config-based approach, but it has several fatal flaws: it can't handle `.git/branches/` migrations, requires manual PATH adjustments to work, and hasn't been updated since 2007. More importantly, Git now provides a built-in migration path via `git remote rename` that handles all cases properly.

The patch is well-justified with clear technical reasoning about why the script is both inadequate and unnecessary. It fits into the broader `contrib/` cleanup effort by removing a tool that is not just unmaintained but actually broken and superseded by core Git functionality. The removal aligns with the project's emerging policy of removing `contrib/` components that meet certain criteria (broken state, long inactivity, or clear alternatives). This appears to be a straightforward and uncontroversial removal that has maintainer support.
