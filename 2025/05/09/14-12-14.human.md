This is part 14/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove reliance on the `the_repository` global. The patch renames `repo_read_object_file()` to `odb_read_object()` to align with the ODB-focused naming pattern established earlier in the series.

The change is mechanical but extensive, updating 48 call sites across the codebase while maintaining identical behavior. A compatibility wrapper is provided for in-flight topics. The new name better reflects the function's purpose - reading objects from the ODB - and matches the naming convention used for other ODB-related functions in the series.

This continues the series' methodical elimination of global state dependencies, with all object database operations now using explicit repository parameters with consistent `odb_`-prefixed names. The patch appears well-executed with thorough updates across the codebase, though as with previous patches in the series, performance validation remains pending for various workflows.
