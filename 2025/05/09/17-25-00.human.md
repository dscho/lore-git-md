This is a maintenance pull request for git-gui, consisting of several small changes focused on translation infrastructure and commit message handling. The changes come from Johannes Sixt and Oswald Buddenhagen.

The most notable change is Oswald's patch making git-gui respect the `core.commentChar` and `core.commentString` configurations, bringing its behavior in line with the command-line Git when handling commit message comments. This addresses a consistency gap between the GUI and CLI interfaces.

Johannes contributes several infrastructure updates: moving the git-gui.pot translation template file to be treated as a generated file (hence deleting it from the repository), updating the po/README with current repository and maintainer information, and merging two branches containing related work. The large deletion of po/git-gui.pot reflects the intentional move to generate this file rather than track it in version control.

The changes appear focused and well-contained, with the comment character handling being the most user-visible improvement while the rest are behind-the-scenes maintenance. The patch set looks like routine upkeep rather than introducing major new functionality.
