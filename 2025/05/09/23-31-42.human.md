This is the final patch in Patrick Steinhardt's series cleaning up Git's `contrib/` directory, specifically removing the obsolete `stats` subdirectory. Elijah Newren points out a minor "nodoby" typo in the commit message that should be "nobody".

The patch removes three statistical analysis scripts that are either broken or have better alternatives in core Git:
1. `git-common-hash` (obsolete since core has built-in hash prefix heuristics)
2. `mailmap.pl` (broken due to Perl syntax changes)
3. `packinfo.pl` (functional but unused, with `git-verify-pack` being a better alternative)

The removal is straightforward with no test adjustments needed, as Patrick notes, these were standalone utilities. The patch follows the established pattern of the series - thorough documentation of each removal with clear justification. With this final removal, the technical cleanup portion of the series is complete, having removed 27 components totaling over 300 lines of code.

The thread shows consensus around these removals, with the remaining discussion focused on finalizing the policy documentation in `contrib/README`. This patch serves as a good example of how to handle statistical/analysis tools that have been superseded by core functionality.
