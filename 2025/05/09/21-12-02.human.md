This is a build system patch addressing an issue with compilation database generation. 

Brian Carlson explains that when `GENERATE_COMPILATION_DATABASE=yes` is set (used by tools like clangd for editor integration), running `make` repeatedly causes unnecessary full rebuilds. The compilation database directory's modification time gets updated with each build, making make think everything needs rebuilding.

The solution applies the same pattern used for `.depend` directory handling - filtering out the compilation database directory from rebuild targets if it already exists. This is a one-line change to the Makefile that prevents the constant rebuilds while maintaining the compilation database functionality.

The patch appears well-motivated and narrowly focused, solving a specific developer workflow pain point. It has a helpful-by from Philippe Blain and follows established Makefile patterns. This should be a straightforward quality-of-life improvement for developers using LSP tools with Git.
