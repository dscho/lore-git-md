This is a bugfix proposal for Git's parse-options machinery, offering an alternative solution to the memory leak issue discussed in the thread. Phillip Wood agrees with Patrick Steinhardt's concerns about complexity and suggests a simpler approach than the previously proposed strdup_fn and marker-based solutions.

The key technical proposal is to modify the argument string in-place rather than making a copy, using MOVE_ARRAY to shift the option text within the existing argv buffer. This avoids both the leak and the need for additional tracking infrastructure. The patch modifies parse_options_step() to handle bundled short options (like "-abc') when encountering an unknown option, moving the relevant portion of the string rather than allocating new memory.
