This is part of Patrick Steinhardt's ongoing series to remove `the_repository` dependency from Git's object database subsystem. Patch 7/17 focuses on `odb_mkstemp()`, converting it to take an explicit `struct object_database*` parameter instead of relying on the global `the_repository`.

The change is mechanical but widespread, touching temporary file creation in several key areas: fast-import, index-pack, bundle-uri, pack-bitmap-write, and general pack writing operations. The implementation now uses the passed ODB's `repo` field internally rather than the global, maintaining consistency with the series' architectural direction.

The patch updates all call sites to pass `the_repository->objects` where the global was previously used implicitly. This includes temporary file creation for pack files, bitmaps, indexes, mtimes, and bundle URIs. The odb.h documentation is updated to clarify the function now operates on the primary alternate's directory rather than the object database directory generally.

This continues the series' pattern of making object database operations repository-agnostic by removing implicit state. The changes appear straightforward with no behavioral modifications beyond the explicit parameter passing. All updates follow the established `odb_` naming convention for ODB subsystem functions.
