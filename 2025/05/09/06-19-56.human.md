This is a discussion about memory leak fixes in Git's option parsing system, continuing from a previous patch submission. Patrick Steinhardt raises concerns about the proposed solution to fix a memory leak when handling unknown short options.

His key concern is whether fixing this bounded memory leak justifies the complexity - he leans toward leaving it as-is unless others disagree.
