This is part 15/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove reliance on the `the_repository` global. The patch focuses on renaming `has_object()` to `odb_has_object()` to align with modern coding guidelines and the ODB abstraction effort.

The change is mechanical but widespread, updating 30 files across the codebase. The new name better reflects the function's purpose in the ODB context, matching the naming pattern established by other ODB-related functions in the series. A compatibility wrapper maintains the old `has_object()` interface to avoid breaking in-flight topics.

This continues the systematic conversion of object database operations to use explicit ODB parameters rather than repository globals. The patch maintains identical behavior while improving naming consistency. As with previous patches in the series, this appears to be a well-executed change with thorough updates across all affected call sites.

The series as a whole is making steady progress toward its goal of eliminating global state dependencies in the ODB subsystem, with this patch handling the object existence checking functionality.
