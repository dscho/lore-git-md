This is part 14/17 of Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to remove reliance on `the_repository` global. The patch renames `repo_read_object_file()` to `odb_read_object()` to align with the ODB-focused naming pattern established earlier in the series.

The change affects 47 files across the codebase, updating all callers to use the new function name while maintaining identical behavior. A compatibility wrapper is introduced to avoid breaking in-flight topics. The new name better reflects the function's purpose of reading objects directly from the ODB rather than being repository-centric.

Key technical details:
- Function moved from repository.h to odb.h
- Signature changed to take `struct object_database*` instead of `struct repository*`
- All call sites updated to pass `repo->objects` where needed
- Wrapper preserves existing `repo_read_object_file()` interface for compatibility
- No behavior changes - same error handling and return values

This continues the series' systematic conversion of object access functions to use explicit ODB parameters rather than implicit repository state. The change is mechanical but thorough, touching many parts of the codebase that read object data.
