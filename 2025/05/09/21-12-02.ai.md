This is a build system patch addressing an issue with compilation database generation. The change prevents unnecessary full rebuilds when `GENERATE_COMPILATION_DATABASE=yes` is set, which currently causes Git to recompile all files on subsequent `make` runs due to the compilation database directory's modification time always appearing newer than built objects.

The patch modifies the Makefile to exclude the compilation database directory from rebuild targets if it already exists, using the same pattern previously implemented for the `.depend` directory. This solves a real pain point for developers using clangd-based editor tooling, as it previously forced full rebuilds after small changes or rebases.

The technical change is small (a one-line Makefile modification) but well-motivated, with clear explanation of both the problem (constant rebuilds disrupting developer workflow) and solution (applying existing directory filtering pattern). The patch includes a Helped-by credit and maintains consistency with surrounding Makefile patterns. No test changes are needed as this is purely a build system optimization.
