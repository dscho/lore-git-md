This is part 3/17 in Patrick Steinhardt's series refactoring Git's object database (ODB) subsystem to decouple it from `the_repository`. Following the renaming of core structures in previous patches (`raw_object_store` to `object_database` and `object_directory` to `odb_alternate`), this patch updates the file names from `object-store.{c,h}` to `odb.{c,h}` to match the new naming scheme.

The change is mechanical, updating include directives in 126 files across the codebase. The patch demonstrates careful attention to detail, with all references to the old filenames systematically replaced. This is a straightforward but important step in the larger architectural effort to make the object storage subsystem more modular and repository-agnostic.

The patch maintains consistency with the series' goal of establishing clear, storage-agnostic terminology. Reviewers can expect this to be a low-risk change since it's purely a filename update following the structural renames already agreed upon in earlier patches. The extensive file list shows the wide impact of the ODB subsystem across Git's codebase.
