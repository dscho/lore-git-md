This is a removal of an unmaintained contrib script as part of Patrick Steinhardt's systematic cleanup of the `contrib/` directory. The patch removes `thunderbird-patch-inline`, a script for sending Git patches via Thunderbird using the ExternalEditor extension.

The removal follows the established pattern for clearly obsolete components: the script depends on an effectively unmaintained extension (last updated in 2008, with a fork last updated in 2020), has seen little maintenance itself, and is unlikely to still work or be in use. The script required the ExternalEditor extension and Zenity as dependencies, and provided functionality to format patches inline in Thunderbird emails while preserving commit messages and signatures.

This represents another case in the ongoing `contrib/` cleanup where functionality wasn't absorbed into core Git but rather became obsolete due to changes in the external ecosystem (Thunderbird extensions in this case). The removal is straightforward with no migration path needed, similar to prior removals of tools like `remotes2config.sh` and `git-resurrect.sh`. The patch deletes both the script (`appp.sh`) and its README, totaling 75 lines removed.

The change continues the thread's pattern of removing components that meet the criteria of being broken, unmaintained for 5+ years, or having clear alternatives, though in this case the "alternative" is simply that the workflow is no longer supported by modern Thunderbird extensions. This removal helps build the case for the emerging `contrib/` policy by demonstrating another concrete example of when removal is appropriate.
