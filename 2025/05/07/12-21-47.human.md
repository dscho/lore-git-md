This is a refactoring patch in a completed series optimizing memory usage in the packed-refs backend. The patch extracts mmap cleanup logic into a new helper function, addressing feedback from Junio Hamano about making the function's purpose clearer and more maintainable.

The author acknowledges Junio's point that the original implementation had maintainability issues by embedding strategy checks in the helper function. The revised version makes callers explicitly check for `MMAP_TEMPORARY` before invoking the new `munmap_temporary_snapshot()` helper, which now focuses solely on the munmap operation itself.

This change improves code organization while maintaining the series' goal of reducing memory pressure during packed-refs operations. Junio had previously confirmed the technical correctness of the approach, and this revision incorporates his specific suggestions about function naming and responsibility separation. The patch appears ready for integration as part of the finalized series.
