This is a performance-focused patch series (3 patches) that integrates the sparse index with `git add -p/-i` and `git apply`. The sparse index optimization can significantly speed up operations in sparse-checkout cone mode, but some commands still need to expand the sparse index to a full one, hurting performance.

The series addresses two specific performance bottlenecks in `git add -p`: first by making `git apply` sparse-index aware (patch 1), then by fixing how `git add`'s interactive modes initialize the sparse index setting (patch 2). The results are dramatic - sparse index operations see a 96.7% speedup in the performance tests added in patch 3.

The changes are well-motivated and come with thorough test coverage, including both functional tests for correctness and new performance benchmarks. This appears to be a straightforward but impactful optimization for users of sparse-checkout. The patches build on existing sparse index infrastructure and follow the project's gradual rollout approach for this feature.
