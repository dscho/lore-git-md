This is a v4 iteration of a feature and documentation patch series improving `git send-email`'s domain validation and authentication documentation. The series has evolved through multiple rounds of review, with the current version incorporating feedback about RFC1035 compliance and documentation clarity.

The first patch tightens domain name validation in `git-send-email.perl` to better match RFC1035 requirements, now enforcing proper label structure (1-63 alphanumeric/hyphen characters, no leading/trailing hyphens) between dots. This addresses previous concerns about dash position enforcement across all domain components while maintaining special handling for local environments.

The second patch continues refining the send-email documentation, particularly around OAuth2.0 configuration examples for major providers. It reverts some mailing list sending instructions while keeping authentication method clarifications. The author notes this may still need another iteration for style alignment and concrete examples as requested by Junio Hamano.

The third patch adds two new credential helpers to the OAuth documentation. The series shows responsiveness to review feedback through multiple version updates, with v4 specifically improving the validation regex and commit messages.
