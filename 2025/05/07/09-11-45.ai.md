This is a patch discussion about removing the `mw-to-git` MediaWiki integration tools from Git's `contrib/` directory, continuing Patrick Steinhardt's systematic cleanup effort. Matthieu Moy, the original author, confirms the tool's abandonment - noting no activity in either the Git tree or its GitHub fork since 2022, and his own disengagement from maintenance. While Junio Hamano observes the GitHub repository is effectively inactive ("a grave"), both agree it's still a more appropriate location than Git's main tree for this unmaintained code.

The discussion reveals this removal was long overdue, with Matthieu recalling prior consensus about deleting it even before the current cleanup series. The patch follows the established pattern for `contrib/` components that have both bitrotted internally and found external homes, though in this case the external project appears equally dormant. Matthieu's closing remarks provide historical context about the tool's origins while acknowledging the mailing list's past support during its development phase.

Key technical details include the last security-related changes in 2020 (commit 9a8606465e8) and known test bitrot documented in f8ab018dafc. The external repository reference (GitHub.com/Git-Mediawiki/Git-Mediawiki) shows no activity since March 2022, reinforcing the removal rationale. This case differs slightly from earlier `contrib/` removals in that the external fork isn't actively maintained, but participants agree the principle of removing unmaintained code from core Git still applies.
