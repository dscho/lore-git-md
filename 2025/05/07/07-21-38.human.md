This is a refactoring patch in Patrick Steinhardt's series to complete the decomposition of `git gc` functionality into standalone maintenance tasks. The patch removes unnecessary global variables used for assembling command-line arguments in `builtin/gc.c`, keeping only the `repack` variable which is used in multiple places.

The change simplifies the code by eliminating three global `strvec` variables (`prune`, `prune_worktrees`, and `rerere`) that were only used once each. Instead, the command strings are now constructed directly in the functions where they're needed. This makes the code more straightforward to follow since the command construction and usage now happens in the same place.

The patch maintains all existing functionality while reducing global state, which is particularly important as this is part of a larger effort to make maintenance tasks more modular. The changes are mechanical and well-contained, with no behavior changes - just cleaner code organization. This continues the preparatory cleanup work seen in earlier patches of the series.
