Derrick Stolee has completed his series optimizing interactive Git commands (`git add -p`, `git checkout -p`, `git reset -p`) for sparse-index operations, with the final patch adding performance tests that validate the substantial speedups. The tests show dramatic improvements: `git add -p` runs 96% faster (1.94s to 0.07s), `git reset -p` 95.6% faster, and `git checkout -p` 91.6% faster when using a sparse index, while full index cases remain stable.

The series has undergone thorough review, with Elijah Newren initially identifying needed test corrections and later approving the performance test methodology. Key technical changes make these commands sparse-index aware while maintaining correct behavior - they only expand the index when editing files outside the sparse-checkout cone. Phillip Wood's suggestion to extend optimizations to `git checkout -p` and `git reset -p` has been implemented, building on foundational `git apply` improvements.

Junio C Hamano has indicated the series is ready for inclusion, marking another step forward in the broader sparse-index/sparse-checkout effort. The comprehensive test coverage in both compatibility (`t1092`) and performance (`p2000`) suites ensures these optimizations will remain robust as the feature evolves.
