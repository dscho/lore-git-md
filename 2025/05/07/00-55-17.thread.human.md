This thread discusses a performance optimization series that integrates sparse index support with `git add -p/-i` and `git apply` commands. The patches, submitted by Derrick Stolee, prevent unnecessary index expansion in these interactive commands - a key improvement for users working with sparse checkouts. The series includes changes to core command implementations and adds performance tests showing dramatic speedups, with `git add -p` operations becoming 96.7% faster (from 2.09s to 0.07s) when using a sparse index.

Junio C Hamano, the Git maintainer, has reviewed the series positively, praising its clear explanation and technical approach. He indicates the changes follow established sparse-index integration patterns and are ready for inclusion. The optimizations maintain all existing functionality while delivering significant performance benefits, particularly for sparse-checkout workflows. The series leaves one potential future optimization (handling out-of-cone edits in `git add -p`) but is otherwise complete, with comprehensive test coverage validating both correctness and the impressive performance gains.
