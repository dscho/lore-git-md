This is the final patch in Patrick Steinhardt's v5 series completing the decomposition of `git gc` functionality into standalone maintenance tasks. It introduces a new "rerere-gc" task for `git-maintenance` that handles garbage collection of the rerere cache, matching what `git gc` previously did.

The patch adds the new task with its own config option (`maintenance.rerere-gc.auto`) that controls when it runs automatically. The auto-condition is simple: if the rr-cache directory exists and has at least one entry, it will run (when the config value is positive). The implementation follows the established pattern for maintenance tasks, with a standalone function and condition check.

The patch includes thorough documentation updates and test coverage that verifies the auto-condition behavior with different config values. This completes the series' goal of moving all `git gc` functionality into configurable maintenance tasks, with worktree pruning handled in the previous patch. The series appears technically solid after multiple rounds of review and addressing feedback.
