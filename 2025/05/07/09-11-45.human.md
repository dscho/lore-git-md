This is a cleanup patch in Patrick Steinhardt's ongoing series to rationalize Git's `contrib/` directory. The email thread has already established consensus around removing unmaintained components, and this patch targets the "mw-to-git" MediaWiki integration tools.

Matthieu Moy, the original author of these scripts, confirms they have been effectively abandoned - there's been no activity either in Git's tree or in the external GitHub repository where they were moved. He notes the code could have been removed long ago, as it's effectively already "resting in its grave." 

The removal follows the pattern seen earlier in the thread for clearly obsolete components: the scripts are unmaintained, have a better home elsewhere (even if inactive), and their functionality isn't critical to Git's core operations. Unlike some other cases in this series, there's no debate here about potential future utility or documentation references - this is a straightforward case of removing dead weight.

This patch appears uncontroversial and well-justified, continuing the systematic cleanup of `contrib/` that has been progressing smoothly in the thread. The author's confirmation of the code's abandoned status removes any doubt about whether removal is premature.
