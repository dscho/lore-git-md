Performance test addition for the sparse-index `git add -p` optimization series. This is the third and final patch in a set that makes `git apply` and interactive add operations (`git add -p/-i`) sparse-index aware, part of the broader sparse-checkout performance work.

The patch adds a performance test case for `git add -p` to demonstrate the dramatic speedups achieved by the series - a 96.7% reduction in runtime (from 2.09s to 0.07s) for sparse index cases, while full checkout performance remains stable. The test simulates a simple edit-and-add workflow by appending to a file and piping 'y' to accept the change. While the test is minimal (a single hunk), it validates the core optimization and will help catch regressions. The author notes that more complex cases would show even greater benefits from avoiding repeated index expansions.

This completes the series with solid performance validation, following the established pattern of adding targeted perf tests for sparse-index optimizations. The test is added to the existing `p2000-sparse-operations.sh` suite alongside other sparse-aware operation benchmarks.
