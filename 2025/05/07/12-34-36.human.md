This is the final patch in a 4-part series optimizing memory usage in the packed-refs backend, specifically focusing on fsck operations. The patch replaces `strbuf_read()` with an mmap-based approach when verifying large packed-refs files during fsck, reducing memory pressure by avoiding unnecessary copying of file contents from kernel to user space.
