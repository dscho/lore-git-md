This is a refactoring patch in Patrick Steinhardt's series to complete the decomposition of `git gc` functionality into standalone maintenance tasks. The patch extracts the rerere garbage collection code from `cmd_gc()` into a new `maintenance_task_rerere_gc()` function, following the pattern established for other maintenance tasks.

The change is straightforward - it moves the child process setup and execution for `git rerere gc` into a dedicated function with the standard maintenance task signature. This prepares for the subsequent patch that will make rerere GC available as a standalone maintenance task. The implementation preserves the existing functionality exactly, just reorganizing where the code lives.

This is part of the final push to fully decompose `git gc`, with all known issues from previous iterations now addressed. The series has been through multiple rounds of review and appears technically complete, with this patch representing one of the last mechanical steps in the refactoring process.
