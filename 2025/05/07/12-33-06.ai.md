This is a documentation patch in the ongoing `git send-email` improvement series, focusing on OAuth2.0 authentication support. The patch updates `git-send-email.adoc` with clearer instructions for configuring OAuth2.0 with major email providers, particularly Gmail and Outlook.

The changes introduce several key documentation improvements: a restructured "Examples" section now explicitly separates Gmail and Outlook configurations, with detailed OAuth2.0 setup instructions for each. The patch adds specific configuration examples showing the required `smtpAuth` values (`OAUTHBEARER` for Gmail, `XOAUTH2` for Outlook) and clarifies that Outlook no longer supports app-specific passwords. 

Notably, the author includes links to their own community-maintained credential helpers for both Gmail and Outlook, which they developed after struggling to find reliable OAuth2.0 token generators. The documentation maintains backward compatibility by still covering traditional password-based methods while prominently featuring the newer OAuth2.0 approach.

This continues the series' trend of practical improvements to `git send-email`'s authentication capabilities, building on the recent Authen::SASL Perl module updates that enabled OAuth2.0 support. The patch demonstrates the author's hands-on experience with the authentication challenges by providing concrete solutions they personally validated.
