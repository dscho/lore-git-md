This is the final patch in the Scalar maintenance configuration series, implementing the tri-state model for `scalar reconfigure` as previously discussed. Junio Hamano provides feedback on the implementation details while accepting the overall approach.

The patch adds `--maintenance=<mode>` to `scalar reconfigure` with three states ("enable", "disable", "keep"), matching the behavior established in `scalar register` and `scalar clone`. However, Hamano raises several UI concerns: the valid modes aren't clearly enumerated in documentation, the help text doesn't show available options, and error messages don't guide users toward correct values. He questions whether the tri-state model is truly necessary here, suggesting OPT_BOOL with default "keep" behavior might suffice while maintaining consistency with other commands.

The implementation uses OPT_STRING parsing with explicit string comparisons for the three modes, converting them to numeric values (-1 for "keep") passed to the existing `toggle_maintenance()` helper. While functionally complete, the interface lacks discoverability features common in Git's CLI patterns. Hamano ultimately accepts the patch as-is but leaves open the question of whether the design could be simplified while still meeting the series' goals.
