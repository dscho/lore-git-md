This is a refactoring patch in Patrick Steinhardt's v5 series to complete the `git gc` decomposition into standalone maintenance tasks. The patch removes unnecessary global variables in `builtin/gc.c` that were used to store command-line arguments for subprocesses (`prune`, `prune_worktrees`, and `rerere`), keeping only the `repack` variable which is used in multiple places.

The change simplifies the code by constructing the command arguments directly in the child process initialization rather than using intermediate global variables. Each subprocess (`prune`, `worktree prune`, and `rerere gc`) now builds its argument list inline when needed. The patch maintains identical functionality while reducing global state, following the series' broader cleanup theme.

Key technical details include:
- Removes `prune`, `prune_worktrees`, and `rerere` global `strvec` variables
- Keeps `repack` global variable as it's used in multiple code paths
- Updates all three affected subprocess calls to build arguments directly
- Preserves all existing functionality including expiration parameters and quiet mode
- Maintains error handling with `FAILED_RUN` messages
- Follows the series' pattern of simplifying `gc.c` internals

This is one of several preparatory refactoring patches in the series that clean up `gc.c` before extracting worktree pruning and rerere GC functionality as standalone maintenance tasks. The change is straightforward with no behavior modification, just internal code organization improvements.
