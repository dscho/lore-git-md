Thread summary:

The thread explores extending meld's 3-pane diff visualization to review committed merge commits, initiated by Britton Kerin. The core proposal is to adapt meld conflict resolution interface (showing LOCAL/BASE/REMOTE) to display merge commit parents (LOCAL/MERGED/REMOTE) for post-merge review. Johannes Sixt notes conceptual limitations since meld's fixed 3-pane model doesn't generalize to octopus merges with >2 parents.

Technical considerations include:
- Current git-difftool meld integration passes $LOCAL/$BASE/$REMOTE during conflict resolution
- Proposed mode would need to handle $MERGED commit instead of $BASE
- Tree diff behavior and diff3 renderer compatibility require special handling
- StackOverflow workaround exists for 2-parent cases but lacks generalization

Britton argues 2-parent merges are common enough to justify tooling support, possibly as a separate utility rather than git-difftool modification. The discussion remains open on whether the use case warrants core Git changes given the conceptual mismatch with n-parent merges and existing workflow alternatives. No patches or concrete implementation plans have been proposed yet.
