This is a documentation patch that concludes a series improving `git send-email` functionality, specifically around OAuth2.0 authentication. It adds two new credential helpers to Git's official documentation: `git-credential-gmail` and `git-credential-outlook`, both developed by the patch author.

The patch simply extends the list of OAuth-supported credential helpers in `gitcredentials.adoc`, providing GitHub links to these new platform-independent helpers. These are positioned as dedicated solutions for authenticating Gmail and Outlook accounts when using `git send-email`. The additions complement the existing `git-credential-oauth` helper mentioned in the document.

This final patch in the v4 series follows earlier work that refined domain validation rules and restructured OAuth documentation. While straightforward, it provides discoverability for these new helpers that were referenced in the series' earlier documentation improvements. The author demonstrates the helpers' utility by using the Outlook variant to send this very patch series.
