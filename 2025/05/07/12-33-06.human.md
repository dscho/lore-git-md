This is a documentation patch in a series improving `git send-email` functionality, specifically focusing on OAuth2.0 authentication support. It's the second of three patches in v4 of the series.

The patch updates the `git-send-email.adoc` documentation to better explain OAuth2.0 authentication for both Gmail and Outlook. It provides clear configuration examples showing how to set up OAuth with each provider, noting that Outlook requires OAuth while Gmail offers it as an alternative to app-specific passwords. The author has included links to their own community-maintained credential helpers for both services, which they developed after finding existing options lacking.

The changes are well-organized, separating the SMTP server examples from the general sending instructions. The documentation now better reflects current authentication realities, particularly Microsoft's move away from app-specific passwords. The patch maintains the existing structure while adding the new OAuth content in a way that should help users avoid common configuration pitfalls.

This appears to be a thoughtful update that addresses real user needs, though as noted in the thread context, some final documentation polish may still be needed in a future iteration. The author demonstrates the changes by sending this very patch using their proposed Outlook helper.
