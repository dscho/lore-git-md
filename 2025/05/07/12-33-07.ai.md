Documentation update adding OAuth credential helpers to the `git-send-email` authentication ecosystem. This is the third patch in a v4 series that has been refining both technical validation and authentication documentation for `git send-email`.

The patch adds two new community-maintained credential helpers to the list of OAuth-capable helpers in `gitcredentials.adoc`: `git-credential-gmail` and `git-credential-outlook`, both authored by the patch submitter. These are presented as cross-platform solutions specifically designed to work with `git-send-email`. Each helper gets its own line with a GitHub link and a brief description noting its provider-specific focus (Gmail or Outlook).

The additions complement the existing `git-credential-oauth` helper mentioned in the documentation, expanding the options available for OAuth authentication with email services. The patch maintains the existing documentation structure while adding these new entries to the "Popular helpers with OAuth support" section.

This change follows logically from the series' earlier work (patches 1-2) which focused on domain validation and OAuth configuration documentation. It provides concrete tooling references to support the authentication methods described in the previous documentation updates. The author demonstrates the helpers' real-world applicability by using one (`git-credential-outlook`) to send this very patch series.
