This is a bugfix patch for `git send-email` that tightens validation of Fully Qualified Domain Names (FQDNs) to comply with RFC1035 standards. It's the first in a v4 series that improves documentation and credential handling for email sending.

The patch addresses a real-world issue where invalid hostnames (like "MacBook..") were being passed to SMTP servers, causing send failures. The new validation enforces proper domain label structure: each component must be 1-63 alphanumeric/hyphen characters, can't start/end with hyphens, and must contain at least one dot (with special handling preserved for macOS `.local` domains).

The change is well-motivated by actual debugging logs showing SMTP servers rejecting malformed domains, and the patch includes clear examples of valid/invalid cases. The implementation maintains backward compatibility while fixing the core validation issue. This appears to be a solid technical improvement to a real pain point in email sending.
