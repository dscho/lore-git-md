This is a refactoring patch in Patrick Steinhardt's v5 series to complete the decomposition of `git gc` functionality into standalone maintenance tasks. The patch extracts worktree pruning logic from `cmd_gc()` into a new `maintenance_task_worktree_prune()` function, preparing for its eventual use as a standalone maintenance task.

The change is straightforward - it moves the existing worktree pruning code that spawns `git worktree prune` into a dedicated function with the same pattern used for other maintenance tasks. The new function takes the same parameters as other task functions and maintains identical behavior, just in a more modular form.

This is one of several preparatory refactoring patches in the series that clean up `builtin/gc.c` before introducing the new maintenance tasks. The patch follows the established pattern seen in previous maintenance task decompositions and appears to be a clean, focused change with no behavioral impact. It's part of the final push to make all `git gc` functionality available as granular maintenance tasks.
