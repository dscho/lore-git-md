This thread discusses a documentation and UX improvement to make it clearer that commit descriptions in interactive rebase todo lists are comments rather than directives. The change prepends '#' to commit messages in the output (e.g., changing "pick COMMIT message" to "pick COMMIT # message") to prevent user confusion.

Elijah Newren originally proposed the change, which received initial pushback from Reto about readability but strong support from Phillip Wood and maintainer Junio Hamano for its error-prevention benefits. The core functionality has been approved, and discussion has now narrowed to test implementation details in t5520.

Ben Knoble's latest contribution weighs in on the test pattern debate, preferring either:
1. Keeping the original approach with grep -v (minimal change)
2. If using sed, adopting Junio's clearer two-command version over more complex alternatives

The thread shows consensus forming around Junio's sed approach as the patch nears finalization. This is a minor refinement to an already-approved change that will make rebase's behavior more intuitive while maintaining all existing functionality. The patch is likely to be merged soon after this last test detail is resolved.
