This is a refactoring patch in a series addressing CodeQL static analysis findings. It simplifies redundant conditional checks in two files:

The patch modifies `help.c` and `transport-helper.c` to remove unnecessary `else if` conditions where the condition is already implied by the previous check. In both cases, an `else if (x > 0)` is replaced with a simple `else` since the condition is already guaranteed to be true by the preceding `if (x <= 0)` check. 

These are small, mechanical changes that don't affect functionality but make the code slightly cleaner and easier to read. The changes were flagged by CodeQL's analysis of redundant conditions. This continues the series' pattern of making small improvements to code clarity and correctness based on static analysis findings.

The changes are straightforward and low-risk, touching only the control flow of helper functions rather than core functionality. As with other patches in this series, there are no user-visible changes - this is purely about code quality.
