This is a refactoring patch in a series addressing CodeQL static analysis findings, specifically improving the clarity of intent-to-add (ITA) entry checking in `builtin/commit.c`.

Jeff King proposes extracting the ITA entry check into a new helper function `has_non_ita_entries()`, building on earlier discussion with Junio Hamano about making the logic more explicit. The new implementation replaces a numeric comparison (cache_nr minus ita_nr) with a direct loop that checks for any non-ITA entries, breaking early when found. This better matches the original intent while maintaining the same behavior.

The change comes after thorough review discussion where both Jeff King and Junio Hamano agreed the original approach (even before the static analysis fix) was unclear in its intent. The new version makes the code's purpose more obvious while still addressing the CodeQL warning about potential numeric overflow in the original calculation.

This patch represents the final iteration of a change that started as a simple static analysis fix but evolved into a more meaningful refactoring through collaborative review. It's part of a larger 11-patch series that has already received comprehensive review from Jeff King and maintainer approval from Junio Hamano.
