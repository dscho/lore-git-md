This is a design discussion follow-up in the `git diff --no-index` pathspec support thread. Junio C Hamano confirms Jacob Keller's proposed approach of treating the first two arguments as comparison targets and subsequent arguments as pathspecs, similar to `git diff-tree -r`'s structure.

The email specifically endorses using the `--` convention in documentation examples to visually separate comparison targets from pathspecs, even though it's not strictly necessary for parsing. This serves as a teaching aid to make the command's structure clearer to users. The example given shows comparing two Git versions' Documentation directories.

The response indicates consensus is solidifying around the pathspec approach rather than the original `--exclude` proposal. Junio's suggestion about documentation style hints at the next steps being implementation and documentation updates rather than further design debate. The tone suggests this direction is now ready to move forward to concrete patches.
