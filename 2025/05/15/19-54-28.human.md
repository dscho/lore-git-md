Refactoring patch in a series addressing CodeQL static analysis findings.

This patch converts a heap-allocated `write_commit_graph_context` struct to stack allocation in `commit-graph.c`, as the context is only needed during the lifetime of `commit_graph_write()`. Jeff King approves the general approach of preferring stack variables but notes the initialization now happens earlier, before `prepare_repo_settings()`. While currently safe, he points out this could become a maintenance issue if `get_configured_generation_version()` is ever moved into `prepare_repo_settings()`. He suggests, a more conservative alternative would be to keep the allocation timing but use `memset()` instead of `CALLOC_ARRAY`.

The change is part of a larger series (11 patches) addressing various memory safety and code clarity issues found by CodeQL across Git's codebase. This particular patch is a clean improvement that eliminates a small memory allocation, though the timing change for generation version checking introduces a subtle future maintenance consideration.
