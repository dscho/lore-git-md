This is a defensive programming patch in the ongoing series addressing static analyzer findings. It modifies `unparse_commit()` in commit.c to add a NULL check for the return value of `lookup_commit()`, which CodeQL static analysis flagged as potentially dangerous. The change is minimal (just adding `!c` to the conditional) but makes the code more robust against malformed input by preventing a NULL dereference if `lookup_commit()` fails. This follows the series' pattern of adding explicit error checking without changing observable behavior. The patch touches core commit parsing infrastructure but maintains the same functionality - it just handles error cases more safely. Like other patches in the series, this is a small but worthwhile hardening change that makes Git more resilient to edge cases.
