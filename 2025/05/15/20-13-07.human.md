This is a refactoring patch in a series addressing CodeQL static analysis findings. Jeff King (peff@peff.net) reviews Johannes Schindelin's changes that simplify redundant conditionals in help.c and transport-helper.c.

The patch removes unnecessary condition checks in else-if clauses where the condition is already implied by the first if's negation. For example, changing `if (i <= 0) ... else if (i > 0)` to the clearer `if (i <= 0) ... else`. These are straightforward readability improvements that don't affect functionality.

Jeff King approves both changes, agreeing they make the code easier to understand by eliminating conditions that might make readers wonder if there are other cases to consider. This continues the series' theme of making Git's code more maintainable while preserving behavior, with each change receiving careful review from domain experts.
