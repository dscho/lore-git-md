RFC proposal from Jacob Keller to add pathspec filtering support to `git diff --no-index` when comparing directories. The patch enables using Git's pathspec syntax to limit which files are compared between two directory trees, matching behavior available in repository-based diffs. Core changes include:

- New PATHSPEC_NO_REPOSITORY flag to disable repository-specific pathspec checks
- match_leading_pathspec() function for directory recursion cases
- prefix_path_gently() modifications for non-/ terminated prefixes
- Disabled PATHSPEC_ATTR and PATHSPEC_FROMTOP features (require repo)
- Pathspec processing only when both inputs are directories
- Pathspecs must follow directory arguments and are root-relative

Implementation touches pathspec.[ch], dir.c, diff-no-index, and setup.c. Open questions remain about negative pathspec behavior, argument ordering constraints, and whether the dual-pathspec approach (separate pathspec objects per input directory) is optimal. No test coverage included in this initial RFC version. Key technical constraints: pathspec features requiring repository context remain unavailable, and directory comparison remains the only supported case for pathspec filtering.
