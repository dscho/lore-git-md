This is a refactoring patch in a series addressing CodeQL static analysis findings. It simplifies redundant conditional checks in two files - `help.c` and `transport-helper.c` - by removing unnecessary explicit positive comparisons when the condition is already implied by the control flow.

The changes are straightforward: in `help.c`, a `cmp > 0` check is removed from an `else if` since the condition is already covered by the preceding `else` case. Similarly, in `transport-helper.c`, a `bytes > 0` check is simplified to just `else` since the negative case was already handled. Both modifications maintain identical behavior while making the code more concise and easier to read.

This continues the series' pattern of small, focused improvements based on static analysis findings. The changes are mechanical and low-risk, touching only control flow structure without altering functionality.
