This is a documentation patch series adjusting how email credential helpers are presented in Git's docs. It's a follow-up to the earlier Yahoo Mail configuration discussion, now addressing two structural documentation issues.

The first patch adds a link to the author's `git-credential-yahoo` helper while also referencing Google's `sendgmail` tool as an alternative Gmail solution. The second patch removes these credential helper links from gitcredentials.adoc entirely, keeping them only in git-send-email.adoc where they're more contextually relevant.

The changes respond to both Junio Hamano's earlier feedback about documentation structure and an open PR (git/git-scm.com#2005) regarding credential helper placement. Notably, the v2 revision removes Yahoo SMTP server instructions that the author now considers unnecessary clutter, though the credential helper itself stays.

The patches appear technically sound and focused on improving documentation organization rather than introducing new functionality. With Junio having already approved the core technical content in previous rounds, this seems ready for final review pending any last documentation structure preferences from maintainers.
