This is a documentation/UX improvement patch targeting the interactive rebase interface. Elijah Newren proposes adding a '#' prefix to commit descriptions in the rebase todo list to make it clearer that these are merely informational comments, not editable directives.

The change addresses user confusion where people mistakenly edit the commit summaries thinking it will affect the rebase operation, when in fact only the 'reword' or 'edit' directives would have that effect. The patch modifies the sequencer to prepend '#' to commit messages in the todo list, with corresponding updates to numerous test files that check the output format.

Newren justifies hardcoding '#' rather than using the more flexible comment_line_str, noting that merge directives already hardcode this character and that the goal here is specifically to discourage editing rather than enable it. The change is well-reasoned with clear explanations of the problem and solution, and includes extensive test updates showing the new output.

This is a straightforward quality-of-life improvement that should help prevent user frustration without introducing any functional changes to the rebase operation itself.
