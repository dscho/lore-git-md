This is a refactoring patch from a series addressing CodeQL static analysis findings. It modifies `builtin/commit.c` to improve code clarity around unsigned integer comparisons.

The change replaces a potentially confusing unsigned subtraction comparison (`cache_nr - ita_nr > 0`) with a direct comparison of the values (`cache_nr > ita_nr`). The original formulation was flagged by CodeQL's `cpp/unsigned-difference-expression-compared-zero` rule as being misleading since unsigned subtraction can't produce negative results. The new version makes the intent clearer while maintaining identical behavior.
