This is a refactoring patch in a series addressing CodeQL static analysis findings. It changes how the commit-graph writing context is managed in `commit-graph.c`, converting a heap-allocated `write_commit_graph_context` struct into a stack variable.

The change eliminates a malloc/free pair while maintaining identical functionality. The author notes this helps CodeQL's static analysis recognize the safety of storing other local variables' addresses in the context's fields. The diff shows mechanical conversion of `ctx->` to `ctx.` throughout the function, with no behavioral changes.

This is part of a larger effort (now 11 patches) to address CodeQL findings across Git codebase. Like others in the series, it improves code hygiene rather than fixing active bugs. The change is straightforward and well-contained, touching only commit-graph writing internals. The patch follows Git's established patterns for such improvements, with a clear commit message explaining both the change and its static analysis benefits.
