Pathspecs would come after the directory arguments and apply relative to each directory's root.

Several open questions remain about edge cases like negative pathspecs and whether the dual-pathspec approach (one per directory) is the right design. The patch currently lacks tests as it's marked RFC, and touches several core components including pathspec.c, dir.c, and the diff-no-index implementation.
