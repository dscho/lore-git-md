Test patch adding coverage for `git apply` mode change warnings. This is part of a bugfix series addressing file mode handling in reverse patches, now in its third iteration. The patch adds tests to verify that `git apply` properly warns when applying patches where the file's current mode doesn't match what the patch expects, covering both forward and reverse application.

The test infrastructure is thorough, with helper functions to check staged and committed file modes, and carefully constructed scenarios that:
- Set up files with specific modes
- Generate patches that expect different modes
- Verify the warning messages appear when modes mismatch
- Check both working tree and index states
- Test both normal and reverse patch application

This appears to be the final test infrastructure piece before the series is ready for merging, following several rounds of review that improved the test structure and coverage.
