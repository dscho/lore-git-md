This is the second patch in a 2-part series addressing submodule configuration safety, focusing on optimizing redundant active flag writes when a submodule's path is already covered by existing patterns.

The patch introduces a new `submodule_active_matches_path()` helper that checks if a submodule path matches any pattern in `submodule.active` using `wildmatch()`. This replaces the previous two-step check that first verified the existence of `submodule.active` and then used `is_submodule_active()`. The new implementation directly queries the config patterns, avoiding redundant lookups.

Key changes:
1. New helper function centralizes pattern matching logic
2. Simplified conditional in `configure_added_submodule()` that only writes the active flag when no existing pattern matches
3. Added test case in t7413 verifying that submodules added under matching patterns don't get redundant active entries
