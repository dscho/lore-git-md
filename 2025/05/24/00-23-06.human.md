This is a minor technical discussion about email address validation in `git send-email`, arising from a typo in the stash import/export patch series. 

Junio Hamano notes that brian m. carlson accidentally CC'd "pwodd" instead of Phillip Wood's correct address "pwood" when sending the v6 stash patches. The typo went unnoticed because the patches were sent from an airport rather than brian's usual setup. 

Junio suggests that `git send-email` could potentially help catch such typos by detecting when an address lacks an @ symbol while other recipients have proper email addresses. This would be particularly useful when the malformed address doesn't match any local aliases. The suggestion comes as a side discussion to the main stash export/import work, which has otherwise reached consensus in its sixth iteration.

The email doesn't propose any concrete implementation - it's more of a thought experiment about improving the patch submission workflow. The core stash functionality remains unaffected by this discussion, which appears to be a brief detour in an otherwise settled thread.
