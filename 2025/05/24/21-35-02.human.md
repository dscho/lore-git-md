This is a small quality-of-life improvement for the notes subsystem. Kristoffer Haugsbakk noticed that when editing Git notes, the editor template includes trailing whitespace on blank lines from the indented commit message. Some editors highlight this as an error immediately upon opening the file.

The patch simply adds `strbuf_stripspace()` to remove this trailing whitespace from the template before it's shown in the editor. A new test confirms the template no longer contains trailing whitespace. This is a straightforward change that addresses a minor but annoying editor behavior, with clean implementation and test coverage.
