This is a documentation patch updating the release notes for Git 2.50.0. The patch adds several new entries to the "What's cooking" document, covering recent developments across multiple areas:

The UI/Workflows section notes that scalar subcommands now have an option to skip enabling scheduled maintenance when adding repositories. Performance improvements include `git send-email` now checking `hostname -f` for mail domain identity and reduced `the_repository` dependency in the replay command.

Several CI/build system updates are documented: Windows+Meson builds now use release mode by default, and GitLab CI automatically runs MSVC-based Meson jobs. The patch also includes the usual assortment of minor fixes and cleanups that will be merged into the maintenance branch.

As a release notes update from the maintainer, this is routine housekeeping that consolidates recent changes for the upcoming version. The entries are concise but provide enough context about each change for users to understand what's new.
