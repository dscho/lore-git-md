This is a bugfix patch series addressing two submodule-related issues. The first prevents accidental overwriting of moved submodules when a new submodule is added at the same path. The second optimizes submodule configuration by avoiding redundant `submodule.<name>.active` entries when the path is already covered by existing patterns.

The series comes with thorough test coverage, adding two new test cases to verify the fixes. The changes focus on `builtin/submodule--helper.c` with about 50 lines of net additions. This appears to be a well-motivated cleanup addressing real edge cases in submodule handling, though the impact is likely limited to users managing complex submodule setups with path changes.
