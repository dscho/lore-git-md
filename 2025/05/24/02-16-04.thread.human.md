Junio Hamano's latest "What's cooking" report provides a broad overview of Git's current development landscape, highlighting progress across multiple fronts. Key areas include memory leak fixes, performance optimizations, documentation updates, and the ongoing `the_repository` removal effort. The report also notes build system improvements and marks the `whatchanged` command for future deprecation.

Patrick Steinhardt follows up with specific updates on two related patch series. His midx-negative-packfile-cache optimization (2 patches) is effectively ready, with Taylor Blau already building on it despite some minor code style questions. More significantly, his 18-patch series refactoring the object store continues the `the_repository` removal work, introducing structural changes and renaming core components like `object_directory` to `odb_alternate`. The only remaining discussion point is a naming choice between `odb_alternate` and `odb_source` - Patrick is open to changing if consensus emerges, otherwise considering the series complete. These changes represent substantial plumbing work modernizing Git's object storage internals.
