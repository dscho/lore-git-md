Junio C Hamano's latest "What's cooking" report provides a comprehensive update on Git's current development state, highlighting progress across multiple fronts. The ongoing effort to remove `the_repository` global variable continues to advance, with Patrick Steinhardt's substantial 18-patch series refactoring the object store/ODB code. This includes significant renames of core structures and APIs to modernize Git's object storage internals.

A key discussion has emerged around naming terminology in Patrick's series, specifically whether to use `odb_alternate` or `odb_source` for the unified object storage model. Junio provided thoughtful analysis, noting that while "alternate" carries historical baggage from when repositories had a primary object directory plus optional alternates, neither name is clearly superior in the new model. This remains the last open question before the series can be considered for merging.

Regarding Patrick's smaller MIDX optimization series, Junio clarified that the `(void *)(intptr_t)-1` syntax can still be cleaned up before merging, even though Taylor Blau has already used these patches as a base for further work. The report also covers various other improvements including leak fixes, performance optimizations, and documentation updates, showing steady progress across Git's core components.
