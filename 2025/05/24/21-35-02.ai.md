This is a bugfix patch addressing a minor but annoying editor behavior in Git's notes functionality. The patch removes trailing whitespace from the editor template shown when adding or editing notes. The issue occurs because the template includes indented commit messages which introduce trailing whitespace on blank lines, causing some editors to highlight these as errors immediately upon opening.

The fix adds `strbuf_stripspace()` to clean up the whitespace in `builtin/notes.c`, and includes a new test case in `t/t3301-notes.sh` to verify the template no longer contains trailing whitespace. The change is straightforward and well-contained, touching only the notes subsystem.

Key technical details for future reference:
- Modifies the `write_commented_object` function in `builtin/notes.c`
- Uses `strbuf_stripspace()` with NULL comment character (treating all lines equally)
- Adds test case using `test_grep ! " $"` to verify absence of trailing whitespace
- Maintains existing behavior while removing the whitespace annoyance
