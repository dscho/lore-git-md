Documentation fix for `git-column` formatting. This is a follow-up to Kristoffer Haugsbakk's patch that corrects incorrect list continuation markers (`+`) in the `git-column` manpage examples. The markers were mistakenly used at top level when adding blank lines around block delimiters in commit 227c4f33a03. Jean-Noël Avila provides an Ack for the fix, which simply removes the erroneous markers while preserving the blank lines. The change is purely cosmetic, affecting only how the documentation renders, not the actual functionality of `git-column`. This appears to be a straightforward, uncontroversial documentation improvement that aligns with the ongoing effort to standardize manpage formatting.
