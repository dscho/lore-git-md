This is Junio Hamano's regular "What's cooking in git.git" status update, covering recent development activity as of May 2025. The email provides a categorized overview of patches that have graduated to 'master', new topics under consideration, ongoing work in 'cooking', and discarded topics.

Several notable changes have recently graduated to 'master':
- A sparse-index optimization avoiding unnecessary name-hash entries for directories
- A receive-pack option to skip connectivity checks when repositories ensure connectivity by other means
- Documentation improvements for git-notes
- A fix for apply --reverse mode when handling file modes
- Performance improvements for MIDX handling of missing packfiles

New topics being proposed include:
- send-email threading fixes when messages are edited
- Memory leak fixes in pack-bitmap loading
- R programming language support in userdiff
- Documentation formatting improvements for sparse-checkout and send-email

Significant ongoing work includes:
- Maintenance command improvements around ref locking during GC
- MIDX API cleanups and improvements
- Meson build system enhancements for TAP output parsing
- Pathspec handling for diff --no-index
- Batch reference updates for fetch/push performance
- Object store API cleanups removing the_repository usage
- Stash import/export functionality
- The deprecation path for git-whatchanged continues

The email also notes several topics that have been discarded or superseded, including bitmap lookup tables and diff pickaxe option renaming. The Git project is currently in the 2.50 release cycle, with rc1 planned for early June.
