This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP compliance in Git's test suite. Karthik Nayak reviews a specific patch that removes test prerequisite announcements that were breaking TAP output format.

The patch cleans up several test scripts (t0050, t3600, t4000, t9500, t9903) by:
1. Removing debug messages about prerequisites that were breaking TAP format
2. Converting some prerequisite checks to use test_expect_success conditions directly
3. Moving highlight tool detection into test_lazy_prereq
4. Simplifying case sensitivity tests by removing if/else blocks in favor of direct prerequisite checks

The changes are mechanical and focused on output formatting rather than test behavior. Karthik's review confirms the changes look correct, noting one case where a variable was defined but never used (and thus removed), and another where the highlight prerequisite check was made more robust. The patch continues the series' pattern of uncontroversial TAP compliance improvements.
