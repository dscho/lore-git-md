This is a test infrastructure patch in Patrick Steinhardt's ongoing series to improve TAP compliance in Git's test suite. The patch focuses on cleaning up prerequisite announcements that were breaking TAP output format.

The changes remove various test script messages that announced prerequisite checks (like filesystem capabilities or tool availability) since these were producing non-TAP output. Instead, it either:
1. Removes unused prerequisite checks entirely (like the CASE_INSENSITIVE_FS block in t0050)
2. Converts them to use test_expect_success with the prerequisite directly
3. Moves tool detection into test_lazy_prereq (as with the highlight tool check in t9500)

Key technical details:
- Modifies 5 test scripts (t0050, t3600, t4000, t9500, t9903)
- Removes 43 lines while adding 14 (net -29)
- Changes highlight tool detection to use test_lazy_prereq with version check
- Converts case-sensitive FS detection to use direct prerequisite checks
- Maintains all test functionality while improving TAP compliance

The patch follows the series' pattern of mechanical, non-controversial changes to standardize test output. It builds on previous work to make test output reliably parseable by TAP consumers like Meson while preserving test behavior. The changes are straightforward and well-contained, with no apparent impact on test reliability or coverage.
