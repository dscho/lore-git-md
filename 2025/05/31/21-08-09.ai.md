Documentation patch fixing formatting in `git-column` manpage. This corrects an issue introduced in commit 227c4f33a03 where list continuation markers (`+`) were incorrectly used at the top level when adding blank lines around block delimiters in the AsciiDoc documentation. The patch removes these erroneous `+` characters from three example blocks in the EXAMPLES section while preserving the blank lines themselves. The change affects only documentation rendering, not functionality. The commit references the original change that introduced the issue and explains the context - that list continuation markers should only be used within blocks, not at top level. The patch is straightforward with a clean diff that makes the intended correction.
