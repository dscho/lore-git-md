This is a test infrastructure patch in Patrick Steinhardt's ongoing Meson build system integration effort, specifically addressing TAP output formatting. The patch fixes a warning message about unsupported BASH_XTRACEFD that was breaking TAP compliance by not being properly commented (TAP requires non-test output lines to start with '#').

Karthik Nayak reviews the change and agrees with the technical approach while suggesting the commit message could better explain why TAP requires the '#' prefix (to distinguish comments from test output). He considers this a minor nit not worth a re-roll of the patch.

The change is part of a broader series (now 19 patches) standardizing test output for Meson integration, with previous discussion around shell trace handling and TAP parser compatibility. This particular patch is a straightforward mechanical fix that maintains the series' focus on strict TAP compliance while handling edge cases in test output formatting.
