This is a "What's cooking" status update from Junio Hamano, summarizing the current state of patches in the Git project as of May 2025. These periodic emails help track which patches are progressing through the integration branches ('next', 'seen', etc.) and which are ready for the upcoming release.

Several topics have recently graduated to 'master', including:
- A sparse-index optimization for name-hash lookups
- A reftable portability fix
- A receive-pack option to skip connectivity checks
- Documentation improvements for git-notes
- A fix for apply --reverse mode with deleted files
- A CVS server Perl warning cleanup
- MIDX performance improvements for missing packfiles

New topics being introduced include:
- send-email threading fixes
- Documentation updates for send-email configuration
- Userdiff support for R programming language
- Sparse-checkout documentation formatting fixes

Notable ongoing work includes:
- Major documentation restructuring for synopsis formatting
- Maintenance command refactoring to avoid ref lock contention
- MIDX API improvements
- Meson build system enhancements for test output parsing
- Pathspec handling for diff --no-index
- Stash command improvements for path-specific operations
- Bulk ref updates for fetch/push performance
- Various defensive programming changes
- The continued effort to remove the_repository global in object store code
- Deprecation path for the legacy 'whatchanged' command

The email also notes that Git 2.50-rc1 is imminent, with the final release planned for mid-June. Any features not already in 'next' will need to wait for the next development cycle. The update provides links to all the relevant patch series for those who want to review the changes in detail.
