**What's cooking in git.git - May 2025 status update** from Junio Hamano. The email provides a comprehensive snapshot of Git development progress across integration branches. Recent graduates to 'master' include sparse-index optimizations (avoiding unnecessary name-hash entries for directories), receive-pack connectivity check skipping option, git-notes documentation improvements, apply --reverse mode fixes, and MIDX performance improvements for missing packfiles. New proposals cover send-email threading fixes, pack-bitmap memory leak fixes, R language userdiff support, and documentation formatting for sparse-checkout/send-email. Ongoing work spans maintenance command ref locking during GC, MIDX API cleanups, Meson build TAP output parsing, diff --no-index pathspec handling, batch reference updates for fetch/push performance, object store API cleanups (the_repository removal), stash import/export functionality, and git-whatchanged deprecation. Discarded/superseded topics include bitmap lookup tables and diff pickaxe option renaming. The project is in the 2.50 release cycle with rc1 planned for early June. Key participants mentioned implicitly through their contributions include Derrick Stolee (sparse-index), Patrick Steinhardt (MIDX), Taylor Blau (MIDX), and René Scharfe (the_repository removal). The status reflects active development across multiple subsystems with particular focus on performance optimizations and API modernization.
