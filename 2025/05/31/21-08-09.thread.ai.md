[PATCH] git-column doc: fix list continuation formatting

This patch corrects a documentation formatting issue in the `git-column` manpage where list continuation markers (`+`) were incorrectly used at top level when adding blank lines around block delimiters. The error was introduced in commit 227c4f33a03. The fix removes these markers from three example blocks in the EXAMPLES section while preserving the blank lines. The change affects only documentation rendering, not functionality. This is part of the ongoing documentation synopsis-style conversion effort led by Jean-Noël Avila. The patch is straightforward with a clean diff that makes the erroneous markers while maintaining the intended visual spacing in the rendered documentation.
