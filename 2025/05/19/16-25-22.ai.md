This is a build system patch in the ongoing series standardizing path handling between Make and Meson builds. It specifically addresses GIT_EXEC_PATH configuration in the Meson build system to better match Make's handling.

The patch makes several key changes to meson.build:
1. Defaults GIT_EXEC_PATH to 'libexec/git-core' (relative path) rather than an absolute path
2. Only overrides via -Dlibexecdir when explicitly different from 'libexec' or '.'
3. Adds runtime_prefix validation to reject absolute paths (matching Make behavior)
4. Maintains the same path concatenation behavior for non-runtime_prefix cases

The changes ensure Meson builds handle GIT_EXEC_PATH consistently with Make builds, particularly around:
- Relative path defaults
- Custom path overrides
- Runtime prefix constraints
- Error conditions

This is part of the series' broader goal of aligning path handling between build systems, with all prior technical feedback incorporated. The patch appears technically sound and focused on the specific GIT_EXEC_PATH alignment issue, building on the established pattern from earlier patches in the series.
