This is a test infrastructure patch in Jeff King's series removing non-standard object type support. It introduces a new `lib-loose.sh` helper for writing loose objects directly in test scripts, bypassing `git hash-object` which will soon lose its `--literally` option for creating objects with non-standard types.

The patch adds a `loose_obj` shell helper that constructs objects manually by:
1. Capturing content from stdin
2. Formatting the object header with type and size
3. Computing the hash of the raw content
4. Compressing with zlib
5. Storing in the proper object directory structure

Junio Hamano reviews the implementation, noting the careful handling of temporary files and whitespace in size calculation. He suggests a minor alternative using `%d` format that would also handle whitespace, but approves the current approach for its clarity. The helper is immediately put to use in `t1006-cat-file.sh` to create test objects with bogus types, replacing the soon-to-be-removed `hash-object --literally` calls.

This provides essential testing infrastructure for the rest of the series while demonstrating good practices in shell script portability and temporary file handling. The implementation looks solid and well-integrated with the series' goals.
