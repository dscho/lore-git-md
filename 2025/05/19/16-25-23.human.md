This is a build system patch that improves cross-platform compatibility for the `sysinfo()` function detection in Git's Autoconf build system. It's the final patch in a 5-part series standardizing build system behavior.

The change upgrades Autoconf's `sysinfo()` check from a simple function existence test to a full compilation check that verifies the Linux-style behavior of `sysinfo()` (including its `totalram` and `mem_unit` fields). This matches a similar change previously made to the Meson build system and fixes incorrect detection on Solaris, where a different `sysinfo()` function exists that isn't compatible with Git's needs.

The patch builds on prior work (commits f5e3c6c57d, 50dec7c566, and c9a51775a3) that addressed Solaris/cygwin compatibility and RAM calculation accuracy in `git gc`. The new check ensures both build systems now use the same rigorous verification method, preventing future platform-specific surprises.

This appears to be a well-justified change that completes the series' goal of consistent behavior between build systems. The implementation follows the established pattern from the Meson side and has already benefited from review in that context. With the series now addressing all identified technical issues, this final patch helps ensure reliable RAM detection across platforms.
