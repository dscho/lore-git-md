This is the final approval for Elijah Newren's `--quiet` option for `git merge-tree`, marking the conclusion of a multi-iteration patch series. Junio Hamano confirms the merge after Phillip Wood's positive review of v4, which included the rename from `--dry-run` to `--quiet` based on earlier naming discussions. The feature provides hosting platforms with efficient mergeability checking by avoiding unnecessary object writes when detecting merge conflicts. While the core functionality is now ready for integration, separate discussions continue about potential batch processing improvements (including Kristoffer Haugsbakk's `--format` proposal) that may build upon this foundation. The implementation spans merge-ort internals, command-line interface changes, and test coverage, with the final version addressing all technical concerns raised during review.
