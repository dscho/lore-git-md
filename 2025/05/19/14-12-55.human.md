Refactoring patch in a series enhancing promisor-remote protocol validation.

This is the first of five patches in v3 of a series that extends the promisor-remote protocol to support configurable validation of remote attributes during clone/fetch operations. The patch replaces the existing `strvec`-based storage of promisor remote information with a new `struct promisor_info` linked list containing explicit `name` and `url` members.

The change improves type safety and prepares for future protocol extensions that will need to handle additional remote attributes beyond just name and URL. The new structure makes it easier to add new fields while maintaining clear documentation of each field's purpose. The implementation includes proper memory management with a new `promisor_info_list_free()` function.

This foundational change was requested during v2 review and has already been through extensive discussion. The patch appears well-crafted with thorough updates to all affected code paths and maintains backward compatibility. It sets up the infrastructure needed by subsequent patches in the series that will add support for validating partial clone filters and tokens.
