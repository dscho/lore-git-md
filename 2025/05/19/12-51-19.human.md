This is the final version of a documentation patch series that reorganizes and improves email-related credential helper documentation. The series has gone through several iterations based on feedback, with the key changes being:

1. Consolidating all email credential helper references (for Yahoo, Gmail, and Outlook) into git-send-email.adoc, removing them from gitcredentials.adoc where they were previously mentioned. This creates a more logical organization since these helpers are specifically for email sending.

2. Adding references to both the sendgmail tool (for Gmail) and git-credential-yahoo helper, while removing now-unnecessary Yahoo SMTP server instructions that were making the docs too crowded.

3. Improving formatting throughout git-send-email.adoc with consistent quoting styles, fixed grammatical errors, and better organization. The v4 update adds CPAN links for required Perl modules.

The changes are purely documentation improvements with no code changes. The series has been reviewed and approved by Junio Hamano, with the final version addressing all feedback. The documentation is now cleaner and better organized, with email-related helpers properly located in the send-email documentation where users would naturally look for them.
