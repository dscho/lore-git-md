This is part 3 of a 5-part series standardizing Git's build system path handling between Make and Meson builds. The patch focuses on correcting how system-wide config and attribute file paths are determined in Meson builds.

Currently, Meson defaults to absolute `/etc` paths for `gitconfig` and `gitattributes` files regardless of the installation prefix, which is only correct when prefix is `/usr`. The patch makes this more flexible by:
1. Removing hardcoded `/etc` defaults from meson_options.txt
2. Using Meson's built-in `sysconfdir` logic (which properly handles relative `etc` paths under custom prefixes)
3. Still permitting explicit path overrides via command line options

The changes ensure consistent behavior with Make builds and follow standard Unix directory layout conventions. This is a well-motivated change that completes the system-wide configuration standardization effort in the series. The implementation looks clean and maintains backward compatibility while fixing the path handling logic.
