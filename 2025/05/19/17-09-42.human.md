Build system fix for Meson configuration display. This patch addresses an issue where `meson configure` would fail to list build options due to a bug in Meson's static analysis of default compiler flags. The problem stems from Meson mishandling constant folding in the C standard version selection logic.

Eli Schwartz reports that since commit 13cb20fc46, users couldn't view pretty-printed build options before compiling. The fix restructures the default options syntax to use a conditional branch rather than string concatenation, working around the upstream Meson issue (#14623) while maintaining the same functionality.

The change is minimal (6 lines added, 8 removed) and preserves the existing behavior where Git requires GNU C99 extensions, falling back to C11 for Meson versions 1.3.0+. The patch has been tested and fixes the immediate usability problem while we wait for an upstream Meson fix. Ramsay Jones originally reported the issue.
