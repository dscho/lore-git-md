This is part 3 of a 5-part series standardizing Git's build system path handling, specifically addressing system-wide config file locations in Meson builds. The patch fixes how Meson determines paths for `gitconfig` and `gitattributes` files by properly respecting the sysconfdir convention rather than defaulting to absolute `/etc` paths.

The key changes remove hardcoded `/etc` defaults from meson_options.txt and implement proper fallback logic in meson.build. When users don't specify custom paths, the build now correctly uses `<sysconfdir>/gitconfig` and `<sysconfdir>/gitattributes`, where sysconfdir follows the standard convention of being `/etc` for `/usr` prefix and `etc` relative to other prefixes. The patch maintains backward compatibility by still allowing explicit path overrides via command line options.

This builds on prior work in the series to align Meson's behavior with Make's path handling. The changes affect the ETC_GITCONFIG and ETC_GITATTRIBUTES compiler defines, which are used throughout Git's codebase to locate these system-wide configuration files. The implementation cleanly handles both absolute and relative path specifications while maintaining the project's cross-platform compatibility requirements.
