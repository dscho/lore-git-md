Documentation patch consolidating email provider credential helpers in git-send-email.adoc. This is part of a v4 series that has evolved through multiple iterations to reorganize and improve email configuration documentation.

The patch adds references to two credential helpers: Google's `sendgmail` tool for Gmail users and the `git-credential-yahoo` helper for Yahoo accounts. It maintains the existing credential helper references (Gmail and Outlook) while standardizing their presentation format. The changes are purely documentation-focused, with no functional impact on Git itself.

This iteration follows Junio Hamano's earlier approval of the documentation restructuring approach, which moves all email-related credential helper references from gitcredentials.adoc to git-send-email.adoc.
