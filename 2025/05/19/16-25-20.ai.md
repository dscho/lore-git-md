This is a build system patch fixing an installation path issue in the Meson build configuration. It's part of the v4 series standardizing path handling across Git's build systems.

The patch corrects the installation location of YAML.pm, a Perl module used by Git's SVN bridge. Currently it's incorrectly placed in `share/perl5/Git/SVN` during Meson builds, when it should be in the `Memoize` subdirectory. The fix updates the `install_dir` parameter in the Meson build file to append `/Memoize` to the path.

This appears to be a straightforward correction aligning Meson's behavior with the expected Perl module layout. The change is minimal (a single path component addition) and follows the pattern seen in other parts of the build system. As part of the larger build system standardization effort, this helps ensure consistent behavior between Make and Meson builds.

The patch builds on the series' goal of path handling consistency, though it addresses a more specific issue than the system-wide configuration paths and platform compatibility work covered in other patches. The fix is technically simple but important for correct Perl module loading when using Meson-built installations.
