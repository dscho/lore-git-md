This is a build system patch that completes the cross-platform sysinfo() detection improvements in Git's build systems. It upgrades the Autoconf build's sysinfo() check to match the Meson build's more robust approach, ensuring consistent behavior across platforms.

The patch modifies configure.ac to perform a full compilation check for sysinfo() functionality rather than just checking for the function's existence. This addresses a Solaris-specific issue where the sysinfo() function exists but behaves differently from Linux/cygwin's version. The new check verifies both the totalram and mem_unit fields of struct sysinfo, which are used in Git's RAM calculation for garbage collection.

This change aligns with prior work in the series (commits f5e3c6c57d and 50dec7c566) that fixed similar issues in the Meson build and cygwin support. The patch maintains the same HAVE_SYSINFO configuration variable but makes its detection more accurate. The implementation uses AC_COMPILE_IFELSE with a custom test program that exercises the actual sysinfo usage pattern from Git's codebase.

This appears to be the final technical piece in the build system standardization series, completing the platform-compatible sysinfo detection across both Autoconf and Meson builds. The change is well-established in the thread's context, having been reviewed and tested on multiple platforms already.
