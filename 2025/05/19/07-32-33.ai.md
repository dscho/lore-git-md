This is a follow-up discussion in the build system standardization series, specifically about system-wide configuration path handling in Meson.

Patrick notes this creates duplicate information - the default paths appear both in the description string and as inline comments.

This is purely about documentation consistency in the meson_options.txt file. The thread context shows this is part of a larger effort to standardize path handling across Git's build systems, with particular attention to making Meson's behavior match Make's while allowing proper configuration flexibility.
