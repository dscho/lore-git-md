Final patch in the series removing non-standard object type support. This eliminates `write_object_file_literally()` and its helper functions, completing the removal of write-side support for unknown object types that began with earlier patches disabling `hash-object --literally` for such types. 

The removal cleans up a parallel implementation of `write_object_file()` that had accumulated tricky duplicated code over time, particularly around loose object map updates. Junio Hamano confirms this is safe since the testing use case has been reimplemented using new test infrastructure (the `t/lib-loose.sh` helpers and `test-tool zlib` from earlier patches in the series).

This marks the technical completion of the 13-patch series after maintainer approval of all previous patches. The only remaining open question is documentation approach for patch 2/13's `--allow-unknown-type` no-op change, but that doesn't affect this final code removal. The series appears ready for merging once that minor documentation point is resolved.
