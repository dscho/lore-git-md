This is the first patch in a v4 series that continues the documentation reorganization effort for email provider configuration in Git. The patch focuses on credential helper references in git-send-email.adoc.

The patch adds two key elements to the documentation: it links Google's sendgmail tool as an alternative method for Gmail users, and it formally adds the git-credential-yahoo helper to the list of available credential helpers. The changes maintain the established pattern of listing credential helpers with consistent formatting, following the series' goal of centralizing email-related credential information in git-send-email.adoc.

The diff shows careful attention to documentation structure - the sendgmail tool is introduced in the Gmail section, while the Yahoo credential helper is added to the existing list of community-maintained helpers. The patch also removes outdated references to "Gmail and Outlook" being the only available helpers, replacing it with a more general statement about available credential helpers.

This iteration builds on previous versions that were approved by Junio Hamano, with the main structural decisions already settled in earlier rounds. The changes are purely documentation-focused, with no functional impact on Git's behavior. The patch maintains the series' progression toward cleaner, more centralized documentation of email configuration options.
