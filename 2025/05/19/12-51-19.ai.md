This is a documentation patch series that finalizes the reorganization of email credential helper documentation in Git's man pages. The v4 iteration adds one new element while maintaining the structural improvements from previous versions.

The series now consists of four key changes: (1) adding references to Yahoo's credential helper and Google's sendgmail tool in git-send-email.adoc, (2) comprehensive formatting improvements to git-send-email documentation, (3) complete removal of email helper references from gitcredentials.adoc, and (4) a new addition of CPAN links for required Perl modules in v4. The changes follow Junio Hamano's earlier approval of the documentation structure approach.

Technical details include updates to three documentation files (git-send-email.adoc, sendemail.adoc, gitcredentials.adoc) with no code changes. The git-send-email.adoc modifications are particularly extensive, with 191 lines changed for formatting improvements and credential helper consolidation. The removal of email helpers from gitcredentials.adoc completes the transition to having all email-related configuration in git-send-email.adoc.

The v4 addition of CPAN module links addresses a practical concern for users setting up git-send-email, though this wasn't part of the original credential helper reorganization goal. The series appears complete with all prior feedback addressed, maintaining the approved documentation approach while adding these final touches. No functional changes to Git's behavior are introduced - this remains purely a cleanup and documentation improvement effort.
