This is patch 10/13 in Jeff King's series removing support for non-standard object types in Git. The patch focuses on `git hash-object`, removing its ability to create objects with unknown types while retaining the `--literally` flag for other format checks.

The change makes `hash-object` fail when given non-standard types, even with `--literally`. This aligns with the series' goal of eliminating support for these experimental types that were never properly usable. A new test confirms this behavior by attempting to create a "bogus" type object with `--literally` and expecting failure.

Junio Hamano's brief reply indicates agreement with the change, particularly noting that the test case is obviously correct. The patch appears straightforward and uncontroversial, building on the series' established direction that has already received maintainer approval for its technical approach.
