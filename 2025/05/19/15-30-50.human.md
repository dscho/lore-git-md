This is a refactoring patch in Jeff King's series removing support for non-standard object types in Git. Patch 12/13 simplifies the flag handling in `git hash-object` by using `OPT_NEGBIT` to directly modify the flags passed to the hashing function, rather than maintaining a separate boolean for the `--literally` option.

The change comes after the removal of the `hash_literally()` function in earlier patches, which means `--literally` now only needs to clear the `INDEX_FORMAT_CHECK` flag. Junio Hamano approves the change, noting that while unexpected, the simplification is obvious in hindsight and cleans up the code path to `hash_fd()`.

This is one of the final patches in the series, with only patch 13/13 remaining to complete the removal of non-standard type support. The maintainer's positive reaction suggests this will likely be accepted as-is. The change is purely internal - it doesn't affect user-facing behavior, just makes the implementation cleaner.
