This is a test infrastructure patch (8/13) in Jeff King's series removing non-standard object types. It introduces a new test helper tool for performing zlib compression/decompression operations, which will be useful for testing object handling changes in subsequent patches.

The patch adds a `test-tool zlib` command that can perform both inflation (decompression) and deflation (compression) operations. The implementation is straightforward - it reads from stdin, processes the data with zlib functions, and writes to stdout. Junio Hamano reviews the code and approves the implementation, noting he's wanted similar functionality before.

The helper will be particularly useful for testing object storage changes later in the series, as it provides low-level access to zlib operations without going through Git's object layer. The code is clean and well-structured, with proper error handling. Since this is test infrastructure rather than core functionality, it doesn't affect production behavior, but it will make future testing of compression-related changes easier.
