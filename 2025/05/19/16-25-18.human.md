This is a build system patch series (v4) that continues refining Git's build infrastructure, focusing on path handling and configuration consistency between Make and Meson builds. The series addresses several technical issues that emerged during the ongoing build system standardization effort. 

The key change in v4 is a minor documentation cleanup in patch #3, removing duplicate default value information from meson_options.txt comments after Patrick Steinhardt's review. The patch now shows defaults only in the description fields. Ramsay Jones notes this is the only change from v3 and expects no test impact, though he's still running the lengthy Cygwin make test as a precaution.

The series includes five technical fixes: proper quoting for GITWEBDIR, corrected YAML.pm installation path, system config/attribute file path handling, GIT_EXEC_PATH alignment between build systems, and an improved sysinfo() detection check for Autoconf. These changes maintain the series' focus on cross-platform consistency, with particular attention to Cygwin and Solaris compatibility.

The patches appear well-tested and reviewed, with multiple iterations incorporating feedback from Patrick Steinhardt, Eli Schwartz, and Junio Hamano. The only remaining item is this final documentation polish in meson_options.txt. The series seems ready for integration, representing incremental but important improvements to Git's build infrastructure.
