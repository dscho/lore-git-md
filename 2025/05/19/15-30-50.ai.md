This is a refactoring patch in Jeff King's series removing non-standard object type support from Git. Patch 12/13 simplifies the `--literally` flag handling in `git hash-object` by using `OPT_NEGBIT` to directly modify the flags parameter rather than maintaining a separate boolean. 

The change comes after patch 10/13 removed the ability to create non-standard types with `--literally`, leaving the flag only responsible for bypassing format checks. Junio Hamano approves the implementation, noting the simplification of the code path to `hash_fd()` is an obvious improvement that wasn't anticipated earlier in the series.

The patch continues the series' trend of cleaning up now-unnecessary code paths while maintaining the same external behavior. With this change, only patch 13/13 remains to complete the removal of write-side support for non-standard types by eliminating `write_object_file_literally()` and its helpers. The maintainer's positive response suggests this uncontroversial refactoring will proceed smoothly.
