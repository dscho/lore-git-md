This is a test infrastructure patch in Jeff King's series removing non-standard object type support. It introduces a new test helper tool for performing zlib compression and decompression operations directly, which will be useful for testing object handling code.

The patch adds a `test-tool zlib` command with `inflate` and `deflate` subcommands, implemented via a shared `do_zlib()` function that handles the core zlib stream operations. The helper reads from stdin and writes to stdout, making it suitable for shell pipelines in test scripts. Junio Hamano reviews the implementation and approves the approach, noting the while-loop structure is acceptable despite potentially preferring a do-while pattern.

The helper provides low-level way to manipulate zlib streams without going through Git's object layer, complementing the earlier `t/lib-loose.sh` test library from patch 9/13. This continues the series' pattern of building test infrastructure before removing functionality, ensuring tests can still verify behavior after the non-standard type support is removed. The implementation is straightforward and well-contained, with proper error handling and cleanup.
