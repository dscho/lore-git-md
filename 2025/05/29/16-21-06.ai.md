This is a feature patch adding PLAIN authentication support to the OpenSSL backend of `imap-send`, part of the ongoing v8 series improving IMAP functionality. The patch implements RFC 4616-compliant PLAIN authentication for OpenSSL users, complementing the existing curl-based implementation.

The change adds a new `AUTH_PLAIN` capability flag and implements the base64 encoding scheme specified in RFC, with proper null-byte handling between username and password components. The implementation follows the same pattern as other auth methods in the codebase, with a new `auth_plain()` handler function and corresponding base64 encoding utility. Documentation is updated to list PLAIN alongside other supported auth methods.

This addresses a gap where OpenSSL users couldn't use PLAIN authentication (commonly used for app passwords) despite it being available via curl. The implementation is thorough, including error handling for encoding failures and socket writes, and maintains consistency with the existing auth method framework. As part of the larger series, this helps provide feature parity between OpenSSL and libcurl backends while supporting modern authentication workflows.
