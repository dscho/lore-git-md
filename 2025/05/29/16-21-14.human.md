This is a user experience improvement patch in the ongoing `imap-send` feature/bugfix series (v8 8/9). It enhances the output shown when sending messages via `imap-send` to include the destination folder name, making the progress messages more informative.

The patch modifies both the OpenSSL and libcurl backend implementations to display messages like "Sending 1 message to Drafts folder..." rather than just "Sending 1 message". This small but thoughtful change helps users verify they're sending messages to the correct IMAP folder, which is particularly useful when the folder is configured via command-line override (a feature added earlier in this series).

The change is straightforward - just two lines modified to include the folder name in the status output. It maintains the existing pluralization logic for message counts and follows the same pattern in both backends. This patch continues the series' trend of polishing user-facing output quality, building on previous work that standardized error messages and improved credential prompts.

As part of a well-reviewed series that's completion, this patch appears ready for inclusion, providing a clear quality-of-life improvement without introducing any technical complexity.
