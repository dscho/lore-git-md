Feature patch adding a command-line folder override option to `git imap-send`. This is part of a larger v8 series improving IMAP functionality, which includes OAuth2.0 support and other authentication improvements.

The patch introduces a new `--folder` (or `-f`) option that lets users specify the destination folder at runtime, overriding any `imap.folder` config setting. This is useful for users who frequently need to send to different folders without editing their config. The implementation is straightforward - it adds the option parsing and applies the override before connecting to the server.

Documentation is updated in both the config and command man pages to explain the new option and its precedence over the config setting. The changes are cleanly implemented with proper memory management (freeing the old folder string when overriding).

This appears to be a well-motivated quality-of-life improvement that fits naturally with the existing configuration system. The patch is focused and follows Git's coding standards, with clear documentation updates. As part of the larger IMAP series, it complements the authentication and usability improvements being made.
