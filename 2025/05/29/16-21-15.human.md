Feature patch adding folder listing to `imap-send`, the final piece in a v8 series improving IMAP functionality. This adds a `--list` option that shows all available IMAP folders, which is particularly useful for services like Gmail that use non-standard folder names (e.g., "[Gmail]/Trash" instead of "Deleted"). The implementation works for both OpenSSL (using RFC6154's LIST command) and libcurl backends, with output showing folder flags and hierarchy. The documentation is updated to suggest using this when troubleshooting folder naming issues. 

This completes the series' user experience improvements by helping users discover correct folder names before sending mail. The patch appears well-integrated with the existing codebase, maintaining consistency with the dual-backend approach used throughout the series. As the final patch in a thoroughly reviewed series, it seems ready for consideration.
