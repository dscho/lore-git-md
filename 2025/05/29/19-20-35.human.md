This is a documentation patch that updates Git's MyFirstObjectWalk tutorial as part of the ongoing `the_repository` removal effort. It's the first of two patches in a series submitted by Lucas Seiki Oshiro, likely as part of Google Summer of Code (GSoC).

The patch modernizes the tutorial's example code to use proper repository handling patterns, specifically:
1. Adding a `struct repository *repo` parameter to the `cmd_walken()` function
2. Replacing `git_config()` calls with `repo_config()`
3. Updating `repo_init_revisions()` to use the passed repository parameter

The changes align with commit 9b1cb50's convention for command handlers and help new contributors learn current best practices. The patch appears well-scoped, focusing only on the repository parameter changes while leaving other tutorial content intact. It maintains the tutorial's pedagogical flow while bringing it up to date technically.

As the first submission in this series, it will need review for both technical accuracy and teaching effectiveness. The changes look straightforward and properly motivated, though reviewers will want to verify the tutorial remains clear for newcomers after these modifications.
