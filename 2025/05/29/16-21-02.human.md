Bugfix for a regression in `imap-send` that made the tool unusable since Git 2.46.0. This is the first patch in a v8 series improving IMAP functionality.

The patch fixes a critical configuration parsing bug introduced in commit 6d1f198f34 where several IMAP configuration fields (`user`, `pass`, `tunnel`, `auth_method`) were incorrectly clearing the `folder` field instead of their own fields. This NULLed out the folder setting, breaking `git-imap-send` completely. The fix properly clears each field's own storage rather than mistakenly clearing the folder field in all cases.

The commit message notes this serious regression went unnoticed for some time, likely because most users prefer `git-send-email`. This is part of a larger series that adds new IMAP capabilities while fixing various issues, as summarized in the thread context. The simple 4-line change corrects the field-specific cleanup while maintaining the same memory management pattern.
