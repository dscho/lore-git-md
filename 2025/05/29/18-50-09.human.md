Documentation refinement in the git-send-email authentication section. This is a follow-up to Aditya Garg's documentation patch clarifying Gmail authentication requirements for `git send-email`. The original patch noted that app passwords are required when multi-factor authentication (MFA) is enabled, but didn't mention they're also required without MFA. 

Junio Hamano reviews the proposed changes, agreeing with the core clarification but suggesting improvements to the phrasing. He points out that the current wording implies OAuth2.0 is only for users avoiding MFA, when in fact it's a valid alternative regardless of MFA status. He proposes more neutral language presenting both methods as equal options, and notes the patch lacks a sign-off.

The technical change is minimal - just a few lines of documentation text in git-send-email.adoc. This continues the thread's theme of refining email-related documentation, building on earlier work that consolidated authentication guidance. The review maintains Junio's characteristic attention to both technical accuracy and clear communication, ensuring the docs don't accidentally steer users toward one authentication method over another.
