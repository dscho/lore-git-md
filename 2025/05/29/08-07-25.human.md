This is a build system modernization patch series for git-gui, adding Meson alongside the existing Makefile build system. The 10-patch series from Patrick Steinhardt (merged by Johannes Sixt) refactors git-gui's build infrastructure to support Meson while maintaining compatibility with the traditional Makefile approach.

The changes extract several build steps into standalone scripts (generating the git-gui executable, macOS wrappers, and Tcl index files) and introduce new Meson build definitions. The series appears carefully constructed with each commit representing a logical step in the Meson integration, from initial preparation (like replacing GIT-GUI-VARS with GIT-GUI-BUILD-OPTIONS) to the final wiring of the Meson build system.

The work follows Git's broader trend toward supporting Meson as an alternative build system, though in this case focused specifically on git-gui rather than the core Git binaries. The changes are largely build-system plumbing with no direct impact on end-user functionality, but should make the project more maintainable and potentially open doors for future build system improvements.
