This is a feature patch in the `imap-send` series, adding a command-line option to override the default IMAP folder configuration. The patch introduces a new `--folder` (or `-f`) option that takes precedence over the `imap.folder` config setting, allowing users who frequently send to non-default folders to avoid constant config changes.

The implementation adds a new `opt_folder` static variable in `imap-send.c` that gets populated via `OPT_STRING` during option parsing. When set, it replaces the configured folder value by freeing and reallocating `server.folder`. Documentation updates clarify the precedence rules and provide usage examples for both the config file and command-line option.

This change complements the series' broader goal of improving `imap-send` usability, particularly for users dealing with multiple IMAP folders. The implementation is straightforward, maintaining consistency with existing option handling patterns in the codebase. The patch follows the series' established approach of adding user-facing conveniences while keeping both OpenSSL and libcurl backend support intact. Documentation changes mirror the style of other recently added options in the series.
