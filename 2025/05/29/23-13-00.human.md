This is a follow-up discussion about the reftable build fix for NonStop platforms, specifically addressing compiler compatibility for the `REFTABLE_UNUSED` macro.

Brian m. carlson weighs in on Junio C Hamano's observation about the main Git codebase using a more complex version of the UNUSED macro in `compat/posix.h`. They note that the older GCC versions (pre-4.5) referenced in that implementation are no longer relevant, as even long-EOL distributions like RHEL 7 and Debian 7 shipped with newer versions. This supports the simpler approach taken in the reftable fix.

The email serves as a technical confirmation that the minimal conditional compilation solution (using just `#ifdef __GNUC__`) is sufficient given current compiler support realities. It doesn't propose any code changes but provides historical context about compiler versions that helps justify why the simpler solution is adequate. This aligns with the thread's general direction of accepting the straightforward fix for this specific case while acknowledging the main codebase's more complex version exists.
