This thread announces the start of the translation cycle for Git 2.50.0, coordinated by Jiang Xin, the project's Chinese (zh_CN) translation maintainer. There are 51 messages requiring translation since the last release. The email provides detailed technical instructions for contributors on generating and updating translation files, including how to use `po/git.pot` as a template and clean up file location metadata before submission.

The workflow aims to balance translation quality with repository cleanliness by allowing optional stripping of location comments from `.po` files. Contributors are asked to submit their updates via pull requests to the git-l10n/git-po repository by June 12, 2025, and to address any issues identified by the git-po-helper CI checks. This follows Git's well-established localization process, providing clear guidance to the translation community for this routine maintenance task ahead of the 2.50.0 release.
