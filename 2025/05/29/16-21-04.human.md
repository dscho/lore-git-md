Feature patch adding OAuth2.0 authentication support to `imap-send`. This is part of a larger v8 series improving IMAP functionality, with this patch specifically introducing support for two OAuth2.0 mechanisms: the standard OAUTHBEARER (RFC 5801/7628) and Google's proprietary XOAUTH2.

The implementation handles both OpenSSL and libcurl backends, with proper error handling and base64 encoding of authentication tokens. The documentation is updated with clear examples for Gmail and Outlook configurations, noting that OAuth2.0 is required for Outlook and recommended for Gmail accounts with multi-factor authentication. The patch also mentions credential helper integration for token management.

This appears to be a well-considered addition, addressing modern authentication requirements while maintaining compatibility with existing setups. The 176-line implementation (plus docs) shows careful attention to both protocol standards and practical use cases. As part of the v8 series, it builds on earlier fixes to configuration handling and authentication methods.
