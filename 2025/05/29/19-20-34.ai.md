This is a documentation patch series (2 parts) updating the MyFirstObjectWalk tutorial as part of Google Summer of Code preparation work. The patches modernize the tutorial to reflect current Git practices around repository handling and build system usage.

The first patch updates the walken.c example code to properly use the `struct repository` parameter that's passed to object-walking functions, rather than relying on the_repository global. This aligns with Git's ongoing effort to eliminate global state. The changes are mechanical but important for teaching modern Git development practices.

The second patch adds meson build system instructions alongside the existing Makefile directions. As Git has moved to supporting meson as an alternative build system, this ensures new contributors following the tutorial won't be confused by missing build instructions. The patch shows how to add the walken.c example to both build systems.

The changes appear straightforward and well-motivated - they address clear gaps in the tutorial documentation that could trip up new contributors. The patches maintain the tutorial's pedagogical approach while bringing it up to date with current Git development practices. As documentation updates, they don't require test coverage but do need to be technically accurate, which they appear to be.
