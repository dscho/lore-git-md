This is a platform compatibility fix for the reftable subsystem. Junio C Hamano is responding to Carlo Marcelo Arenas Belón's patch that makes the `REFTABLE_UNUSED` macro work with non-GNU compilers, specifically addressing a build failure on NonStop systems reported by Randall S. Becker.

The patch conditionally defines `REFTABLE_UNUSED` to use the GNU `__attribute__((__unused__))` only when `__GNUC__` is defined, falling back to an empty definition otherwise. Junio notes this follows Git's historical approach to such compatibility issues, though he points out the main Git codebase has a more complex version of this macro that includes deprecation warnings.

Junio indicates the patch is reasonable and will be applied, though he muses that the simpler approach may be sufficient given that support for older versions of GCC (pre-4.5) may no longer be necessary. The change is minimal and focused, directly addressing the reported build failure without broader implications for the reftable code.
