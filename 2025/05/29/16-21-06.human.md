This is part of a feature series adding authentication methods to `imap-send`, specifically implementing RFC 4616-compliant PLAIN authentication for the OpenSSL backend. The patch enables PLAIN auth (commonly used with app passwords) when using OpenSSL, where previously only the libcurl backend supported it.

The implementation follows the RFC 4616 specification for PLAIN authentication, which requires base64-encoding a specially formatted string containing username and password. The patch adds a new `plain_base64()` helper function to handle this encoding, plus the necessary capability flag (`AUTH_PLAIN`) and authentication handler (`auth_plain`). Documentation is updated to list PLAIN as a supported method for OpenSSL users.

This appears to be a well-contained addition to the ongoing IMAP authentication improvements. The implementation is straightforward, with proper error handling and memory management. It fills a gap where OpenSSL users couldn't use PLAIN method despite it being widely supported by email providers. The patch fits cleanly into the larger series' goal of providing comprehensive authentication support across both OpenSSL and libcurl backends.
