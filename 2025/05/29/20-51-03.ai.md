This is a refactoring and correctness patch in the ongoing MIDX (multi-pack-index) improvements series. The patch introduces a new helper function `nth_midxed_pack_name()` to safely access pack names in MIDX chains, addressing potential array access issues that could occur when dealing with incremental MIDX layers where global and local pack IDs may differ.

The key technical aspects are:
- New helper function `nth_midxed_pack_name()` properly handles pack ID translation between global and local indices in chained MIDX scenarios
- Updates four call sites in midx.c, pack-bitmap.c, and test code to use the new helper
- Maintains existing behavior where safe while preventing incorrect array accesses
- Particularly important for bitmap handling code where original direct array accesses could be incorrect
- Follows the thread's pattern of improving MIDX safety through better encapsulation
