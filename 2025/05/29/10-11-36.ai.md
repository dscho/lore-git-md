Platform compatibility fix for reftable's UNUSED macro.

Carlo Marcelo Arenas Belón proposes a solution to the NonStop build failure reported by Randall S. Becker. The issue stems from the `REFTABLE_UNUSED` macro in `reftable/basics.h` using a GNU-specific `__attribute__((__unused__))` that breaks compilation on NonStop's C99 compiler.

The patch makes the GNU attribute conditional, falling back to an empty definition on non-GNU compilers. This matches Git's historical approach to similar compatibility issues. The change is minimal (4-line addition) and focused specifically on the reported problem without attempting broader refactoring.

The commit message clearly links this to the original report and explains the technical context - this macro was introduced in commit f93b2a0424 as part of reftable's internal UNUSED annotation system. The solution follows Git's established pattern for handling compiler-specific attributes.

This appears to be a straightforward, well-motivated fix that directly addresses the build failure while maintaining functionality on GNU platforms. The patch is properly signed-off and follows Git's contribution conventions. No tests are included since this is purely a build system fix, and the change is simple enough that testing would primarily involve verifying successful compilation on NonStop systems.
