This thread documents the completion of a patch series by D. Ben Knoble that adds configurable index restoration to `git stash`. The inconsistency where `stash push` saves staged changes but `apply/pop` doesn't restore them by default has been resolved through a new `stash.index` config option (defaulting to false for backward compatibility). The series has been thoroughly reviewed and approved by maintainer Junio C Hamano, with all technical concerns addressed.

The latest email focuses on final documentation polish, specifically clarifying how the new config interacts with `--autostash` operations in `merge`, `rebase`, and `pull`. Kristoffer Haugsbakk suggested some wording improvements to the documentation, including removing vague language and reconsidering references to merge commits in the commit message. While D. Ben Knoble acknowledged these points, he noted the merge commit reference was intentional for historical context. This minor stylistic discussion represents the last open item in an otherwise complete series that has already received maintainer acknowledgment and is ready for merging.
