This is a follow-up patch in the `git send-email` improvement series, specifically enhancing FQDN (Fully Qualified Domain Name) detection. The patch adds a new fallback method using the `hostname --fqdn` command on Linux and macOS systems before resorting to the final 'localhost.localdomain' fallback.

The key technical elements include:
- New `maildomain_hostname_command` function that executes `hostname --fqdn` on Linux/macOS
- Proper error handling that checks the command's exit status before processing output
- Validation of results using the existing `valid_fqdn()` function
- Integration into the existing fallback chain between Net::Domain check and MTA check
- Maintains silent operation on non-Linux/macOS systems

The v2 revision specifically addresses Junio Hamano's feedback by:
- Avoiding premature chomping of the domain string
- Only assigning to $maildomain if the command succeeds (exit status check)
- Still validating the result through `valid_fqdn()`

The patch builds on the previously approved domain validation work, adding another layer of reliability to FQDN detection while maintaining robust error handling. The implementation references Perl module internals that already use similar hostname detection methods, suggesting this approach aligns with existing practices.
