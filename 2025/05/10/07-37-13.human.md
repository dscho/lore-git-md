This is a follow-up patch in the `git send-email` domain validation series, specifically improving FQDN (fully qualified domain name) detection. The patch adds a new fallback method using the `hostname --fqdn` command on Linux and macOS systems before resorting to the final 'localhost.localdomain' fallback.

The author notes that while the current Net::Domain Perl module is unreliable, the `hostname` command (which those modules themselves use internally) tends to be more reliable. The patch introduces a new `maildomain_hostname_command` function that safely executes `hostname --fqdn`, checks its exit status, validates the output with the recently improved `valid_fqdn()` function, and only uses it if all checks pass.

This v2 version addresses feedback by fixing an error handling case - it now properly checks the command's exit status before processing the output. The change is straightforward and maintains the existing fallback chain while adding another potentially more reliable detection method. Given the thorough review process this series has undergone and Junio Hamano's approval of the core functionality, this follow-up appears to be a safe incremental improvement to the domain detection logic.
