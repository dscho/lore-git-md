This is a test refactoring patch that's part of a series introducing diff context controls for interactive patch commands. The patch converts manual `git config` calls to the modern `test_config` helper in t4055-diff-context.sh, which automatically cleans up configuration changes when tests complete.

The changes are mechanical replacements of `git config` with `test_config` across seven test cases that verify how Git handles diff.context settings. The tests cover various scenarios including default behavior, override behavior with -U option, plumbing vs porcelain differences, and error handling for invalid values (non-integer and negative numbers).

This refactoring follows the pattern established in patch 1/4 which converted grep calls to test_grep, continuing the modernization of test infrastructure in preparation for the core functionality changes coming in later patches. The use of test_config ensures proper test isolation by automatically cleaning up configuration changes, preventing test pollution that could affect subsequent test cases.

The patch maintains all existing test assertions and behaviors while making the test file more robust. This is a straightforward improvement that aligns with the series' goal of enhancing test reliability before introducing new features. The changes are uncontroversial and follow established test suite modernization patterns.
