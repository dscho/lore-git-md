This is a feature patch series introducing a new `--mergeability-only` option for `git merge-tree`. The option is designed for Git forges and other tools that only need to check if two branches can be merged, without requiring the full merge result or conflict details.

The key benefits are performance improvements: the merge machinery can exit early upon detecting conflicts (rather than computing full merge results) and can avoid writing intermediate objects to the object store when checking mergeability. The series consists of two patches - one adding the core functionality to merge-ort, and another exposing it through the merge-tree command line interface.

The change appears well-motivated for the stated use case of Git forges, and comes with thorough documentation updates and test coverage (38 new test lines). The implementation touches the merge-ort internals, the merge-tree command, and its documentation, suggesting this is a complete, production-ready feature addition rather than an RFC.
