Test update for stash's untracked file handling with breaking changes. This is patch 8/9 in a series that makes `git stash apply` default to restoring the index when GIT_BREAKING_CHANGES is enabled.

The patch updates t3905-stash-include-untracked.sh to account for the new behavior where `stash pop` restores the index by default. It splits two key tests into old/new behavior versions:
1. Verifying that stashed untracked files remain untracked after popping (now requires cleanup of staged changes for the new behavior)
2. Testing stash operations with pathspecs containing IFS characters (now requires explicit `--no-index`)

The changes show careful attention to test isolation, with cleanup steps added where the new behavior would interfere with subsequent tests. The patch maintains the series' pattern of duplicating tests for old/new behavior rather than using conditionals within tests.
