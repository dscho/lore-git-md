This is the final patch in a series adding diff context configuration support for interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The patch implements command-line override support for diff context settings, completing the functionality started in earlier patches.

The core changes introduce `-U/--unified` and `--inter-hunk-context` options to all interactive commands, mirroring existing diff/log behavior. These override any configured diff.context/diff.interHunkContext values. The implementation:
- Adds new parse-option macros OPT_DIFF_UNIFIED/OPT_DIFF_INTERHUNK_CONTEXT
- Passes context values through new add_p_opt struct
- Validates negative values consistently
- Documents options via shared include file
- Adds comprehensive tests covering all commands

Key technical details:
- Options only work with --interactive/--patch (error if used alone)
- Uses same validation as config values (rejects negatives)
- Test coverage verifies overrides work for all commands
- Documentation centralized in diff-context-options.adoc

The patch builds on the test modernization (test_grep/test_config) and config support from earlier in the series. With this addition, users now have full control over diff context via both config and command line, matching Git's standard diff behavior. The implementation is thorough and maintains consistency with existing patterns.
