This is the core implementation patch in a series adding diff context configuration support to interactive patch commands. It makes `add -p`, `commit -p`, `checkout -p`, `stash -p`, and `restore -p` respect the `diff.context` and `diff.interHunkContext` settings, matching behavior already present in other diff-related commands.

The patch adds context configuration fields to the `add_i_state` struct and reads them during initialization, with validation to reject negative values. The diff generation in `add-patch.c` is updated to pass these values through to the underlying diff machinery. New tests verify the behavior across all affected commands, including proper error handling for invalid negative values.

This builds on the test modernization work from earlier patches in the series (converting to `test_grep` and `test_config`).
