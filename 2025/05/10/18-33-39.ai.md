This is the implementation patch in a series proposing to change `git stash` behavior to default to `--index` when breaking changes are enabled. It modifies the core stash functionality in `builtin/stash.c` and updates documentation in `git-stash.adoc`.

The patch flips the default behavior of `stash apply/pop` when `WITH_BREAKING_CHANGES` is defined, making index restoration the default with a new `--no-index` opt-out flag instead of the current `--index` opt-in. The changes include:

1. Conditional compilation blocks in `builtin/stash.c` that:
   - Reverse the default index restoration behavior
   - Replace `--index` flag with `--no-index` in help text and option parsing
   - Update error messages to reference `--no-index` instead of `--index`

2. Documentation updates in `git-stash.adoc` that show both behaviors conditionally based on the breaking changes flag, maintaining backward compatibility while documenting the new default.

The implementation is cleanly gated behind the breaking changes flag and maintains the same underlying functionality - it just changes the default and inverts the flag. The patch leaves test updates for later patches in the series, noting they require more complex changes. This appears to be a well-structured change that directly addresses the stated goal of fixing the "footgun" where stashed index changes are lost by default.
