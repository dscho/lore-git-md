The patch clarifies that environment variable *names* should be written as `GIT_VAR` (without the dollar sign) when referring to the variable itself, reserving `$GIT_VAR` for when discussing the variable's value. This affects documentation for several Git environment variables including `GIT_EDITOR`, `GIT_PAGER`, and configuration paths.

The changes are mechanical but important for consistency - they align with the broader documentation standardization effort that has been progressing through this thread. The patch follows the established pattern of backquoting command and option names while using underscores for variables, completing the documentation standards for environment variable references.
