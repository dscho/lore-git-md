Elijah Newren's patch series to add a `--dry-run` option to `git merge-tree` has now been completed with this final patch. The feature provides Git hosting platforms with an efficient way to check mergeability without performing a full merge computation. 

The implementation builds on earlier plumbing changes that introduced a `mergeability_only` flag in the merge-ort internals. This final patch adds the user-facing `--dry-run` option, which suppresses output and avoids unnecessary object writes while still detecting conflicts. The option includes safety checks to prevent misuse with incompatible flags and has been thoroughly tested to verify correct behavior in both successful and conflicted cases.

Junio Hamano provided naming guidance, suggesting `--dry-run` over the original `--mergeability-only` proposal, and Kristoffer Haugsbakk reviewed the documentation. The series has addressed all feedback and edge case considerations, with tests confirming the optimization works as intended while maintaining correct behavior in all scenarios. This completes the functionality for platforms needing fast mergeability checks.
