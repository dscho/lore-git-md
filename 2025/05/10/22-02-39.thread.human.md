This thread introduced a `--dry-run` option to `git merge-tree` for efficient mergeability checking, primarily targeting Git forges. Elijah Newren's implementation went through multiple iterations, with key refinements to the merge-ort plumbing and user interface before receiving final approval from Junio Hamano. The feature is now queued for merging, with comprehensive test coverage and documentation.

In a follow-up discussion, Phillip Wood noted that while the implementation suppresses all output (similar to `git diff --quiet`), most other Git commands using `--dry-run` (like `git push` or `git send-email`) still produce diagnostic messages. He framed this as an observation about potential inconsistency with user expectations rather than a blocking objection, acknowledging the feature had already gone through extensive review. The naming and behavior remain as approved, with Phillip's comment serving as documentation of this design choice for future reference.
