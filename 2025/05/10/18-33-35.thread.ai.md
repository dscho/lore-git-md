[PATCH 0/9] git stash: make --index the default under breaking changes

Thread identity: Subject proposes changing `git stash` behavior to default to `--index` when breaking changes are enabled (GIT_BREAKING_CHANGES). Originating author not yet named in this summary. Thread type is feature change proposal targeting Git 3.0.

Core problem: Current `git stash apply/pop` defaults to not restoring the index, creating a "footgun" where carefully staged changes are lost during stash application. The original implementation considered making `--restore` the default but didn't implement it. This series rectifies that historical decision when breaking changes are enabled, making `stash apply` properly reverse `stash push` by default.
