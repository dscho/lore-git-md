This is the final patch in a series adding command-line override support for diff context in interactive patch commands (add/checkout/commit/reset/restore/stash with --patch). The patch implements `-U`/`--unified` and `--inter-hunk-context` options that override the config settings, matching the behavior of other Git commands like `diff` and `log`.

The changes are comprehensive, touching documentation, core implementation, and all relevant builtin commands. The patch:
- Adds new documentation in `diff-context-options.adoc` that gets included in all affected command manpages
- Extends the `add_p_opt` struct to carry context values through the interactive patch machinery
- Updates each command to accept the new options and validate them (they only work with `-p/--patch`)
- Adds tests verifying the command-line overrides work and take precedence over config

The implementation looks solid, with careful attention to edge cases like negative values and proper option validation. The test coverage is thorough, checking both the new options and their interaction with config settings across all affected commands. This completes the series' goal of giving users flexible control over diff context in interactive sessions.
