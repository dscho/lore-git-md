This is a cover letter for a v2 patch series improving context line customization in interactive patch commands (`add`, `commit`, `checkout`, `reset`, `restore`, `stash` with `--patch`). The series builds on prior work to make these commands respect `diff.context` and `diff.interHunkContext` configs.

Key changes in v2:
- Drops the interactive subcommand feature from v1 (deemed too complex for now)
- Adds command-line overrides (`-U`/`--unified` and `--inter-hunk-context`) that take precedence over configs
- Improves test coverage and modernizes test infrastructure
- Adds validation for negative context values
- Documents the new options consistently across all affected commands via a shared include file

The series now consists of:
1. Test refactoring to use `test_grep` (new in v2)
2. Test refactoring to use `test_config` (new in v2)
3. Core implementation making patch commands respect diff context configs
4. Command-line override support for context settings

The thread history shows this work has undergone significant review, with Junio C Hamano providing key documentation guidance and Phillip Wood contributing implementation refinements. The current state reflects consensus on requiring explicit `-i/-p` flags when using context overrides, with documentation phrasing updated to "only effective with" rather than "implies".

Technical implementation status:
- Config handling is complete
- Command-line interface is implemented with proper documentation
- Interactive UI features are deferred pending further design work

The series touches multiple builtins' documentation and adds tests verifying behavior across all affected commands. The implementation uses new `OPT_DIFF_UNIFIED` and `OPT_DIFF_INTERHUNK_CONTEXT` macros for consistent option handling.
