This is a documentation patch in the `whatchanged` deprecation series. It updates two documentation files to remove references to `git whatchanged` in preparation for its eventual removal. 

The patch makes two changes: First, it updates the "My First Object Walk" tutorial to reference `cmd_version()` instead of `cmd_whatchanged()` when demonstrating how to add a new command. Second, it changes the example of commands sharing source files in the user manual from `whatchanged`/`log` to `show`/`log`.

These are straightforward documentation updates that remove dependencies on the soon-to-be-deprecated command. The changes are minimal and focused - they don't explain the deprecation itself (that's covered elsewhere in the series) but simply remove mentions of `whatchanged` from places where it was used as an example. The patch follows the series' approach of systematically eliminating references to `whatchanged` across the codebase.
