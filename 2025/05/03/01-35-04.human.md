This is Junio Hamano's monthly "What's cooking in git.git" status update, providing a comprehensive overview of recent developments in the Git project. The email organizes changes into three categories: topics that have graduated to 'master', new topics under consideration, and ongoing work in the pipeline.

Several notable changes have recently landed in master, including:
- A typo fix in environment.h header
- Code cleanups around string array constness and hashmap reuse
- Fixes for launchctl maintenance scheduling and CI infrastructure
- Significant reftable API improvements
- Reduction of Perl dependencies in documentation and scripts

New proposals include:
- Enhancements to promisor-remote capabilities (expecting revisions)
- A fix for `git mv` when moving a directory into its own child
- Scalar subcommands gaining a `--no-maintenance` option
- Plans to deprecate the long-obsolete `git whatchanged` command
- Ongoing work includes:
- Maintenance task expansions (adding rerere-gc and worktree-prune)
- Object store layer cleanups
- Windows ARM64 support improvements
- Performance optimizations for pack bitmaps and delta compression
- The email also highlights several documentation updates and build system improvements, particularly around Meson integration.

This update shows Git's continued focus on code quality, performance, and modernization, with particular attention to reducing technical debt in the codebase and build system. The planned deprecation of `git whatchanged` marks a notable step in simplifying Git's interface by removing redundant commands.
