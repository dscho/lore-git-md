Feature addition introducing a `git remote group` subcommand for listing configured remote groups, building on the existing thread about remote group management. This is the implementation patch following the initial proposal.

The patch adds:
- A new `group` subcommand to `git remote` that lists all remote groups (defined via `remotes.<group>` config)
- Bash completion support that integrates with existing remote completion, making groups available for tab completion in fetch operations (but not push)
- A new test file t/t5506-remote-groups.sh verifying the listing behavior, including group ordering and deduplication

Key technical details:
- Uses git_config() with a callback to collect group names from config
- Implements string_list deduplication for groups
- Adds completion helper functions __git_remote_groups() and __git_remotes_or_groups()
- Tests cover basic listing, multiple groups, and config ordering

The implementation appears complete and well-tested, though it leaves open the thread's questions about rename behavior and local/global config interactions. The patch stands alone but is clearly part of a larger planned effort to add group management commands, with this being the foundational listing functionality.
