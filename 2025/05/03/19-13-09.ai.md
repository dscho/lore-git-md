Documentation patch fixing a typo in `git-branch.adoc` formatting.

This is the second patch in Kristoffer Haugsbakk's two-part series correcting minor documentation issues. It fixes an accidental use of the character `è` instead of a backtick in the `git-branch.adoc` man page, which occurred during a previous formatting update (7b399322a2e). The change is a straightforward one-character fix in the explanation of remote-tracking branch deletion behavior, correcting the formatting of the `git fetch`/`git pull` command reference. The patch maintains the exact same content while fixing the presentation. This follows the same pattern as the first patch in the series (which addressed HTML output issues in `git-reflog.adoc`), being a mechanical formatting correction rather than a content change.

The commit message clearly identifies both the problem and its origin in a prior documentation reformatting effort. The change is minimal and focused, touching only the Documentation/ directory.
