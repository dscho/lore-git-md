Documentation standardization patch for `git-daemon`. This is the final part of Junio C Hamano's series to update Git man pages to the newer synopsis-style format, continuing Jean-Noël Avila's earlier work. The patch focuses on `git-daemon.adoc`, applying three key formatting improvements: converting the SYNOPSIS from [verse] to [synopsis] format, consistently backquoting all options (like `--base-path=<path>`), and splitting negatable options (previously `--[no-]informative-errors`) into separate `--informative-errors` and `--no-informative-errors` entries for better grep-ability.

The changes are purely presentational, with no behavioral modifications. The patch demonstrates careful attention to detail, consistently applying the formatting rules established earlier in the thread (like backquoting command names in body text and maintaining URL example formatting). It completes the series' goal of bringing `git-daemon` documentation in line with the project's current standards while preserving all existing content. The work appears ready for merging as it builds on previously established consensus about documentation formatting.
