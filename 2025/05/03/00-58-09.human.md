This is the first patch in a 6-part series establishing Git's deprecation infrastructure, using `git pack-redundant` as the initial case study. The patch refactors the existing deprecation warning mechanism into a reusable helper function called `you_still_use_that()` in usage.c, which will be available for other commands facing deprecation.

The change moves the deprecation warning and die() logic from `builtin/pack-redundant.c` into this new helper, making the code more maintainable as more commands adopt this deprecation pattern. The patch also adds a missing test case to verify that `git pack-redundant` properly requires the `--i-still-use-this` opt-in flag.

This foundational work is part of a systematic approach to command deprecation that includes documentation updates, test modifications, and eventual removal preparation in later patches. The implementation is clean and well-tested, with clear commit messages explaining both the technical change and its broader context in the deprecation workflow.
