This is a feature patch in the `whatchanged` deprecation series, implementing the opt-in requirement for continued use of the deprecated command. The patch makes `git whatchanged` require the `--i-still-use-this` flag to work, while updating tests and documentation accordingly.

The change enforces the deprecation warning system by making the command fail unless users explicitly opt-in with the new flag. The implementation adds a hidden boolean option to track this opt-in status and uses the existing `you_still_use_that()` helper to show the deprecation warning when the flag isn't provided. Tests are updated in two ways: existing `whatchanged` calls now include the opt-in flag, and new tests verify the command fails without it.

The documentation gets a minor modernization by using the new `[synopsis]` markup while keeping the same content about the command's historical status. This patch follows the series' pattern of gradually tightening restrictions on `whatchanged` usage while maintaining functionality for those who explicitly opt-in. The changes are well-contained, touching only the expected files (documentation, implementation, and tests) with clear commit message explaining both the what and why.
