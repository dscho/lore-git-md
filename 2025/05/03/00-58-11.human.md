This is part of the ongoing `git whatchanged` deprecation effort (patch 3/6 in the series). The patch updates test scripts to stop using `git whatchanged` in favor of `git log --raw`, which provides equivalent functionality. 

The changes affect two fast-import test files (t9300 and t9301), replacing all instances where tests were using `whatchanged` to verify imported commits. The commit message explains these were originally added as debugging aids during test development rather than being essential assertions. 

This is a preparatory step that doesn't yet remove `whatchanged` itself, but eliminates test dependencies on it ahead of its eventual removal. The changes are straightforward mechanical replacements that maintain the same test coverage while using the more standard `log --raw` alternative. 

The patch follows the series' pattern of systematically removing `whatchanged` references from the codebase while maintaining functionality. It's part of a larger effort that includes documentation updates, warning infrastructure, and eventual removal under a compile-time flag.
