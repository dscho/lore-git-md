This is a feature patch adding a `git remote group` subcommand for listing configured remote groups, continuing the thread about remote group management primitives. The patch implements the listing functionality proposed earlier, with Randall Becker now asking for clarification on the use case and side effects.

The implementation collects group names from `remotes.<group>` config entries via a git_config() callback, handles deduplication with string_list, and prints the results. It includes bash completion support through new __git_remote_groups() and __git_remotes_or_groups() helpers, making groups available for tab completion in fetch operations (but not push). Tests verify basic listing, multiple groups, config ordering, and deduplication behavior.

Key technical details for future reference:
- New builtin/remote.c functions: get_remote_group() callback and group() subcommand handler
- Bash completion hooks into existing remote completion infrastructure
- Test file t/t5506-remote-groups.sh with 4 new test cases
- Documentation updates in git-remote.adoc
- Explicitly does not handle remote rename synchronization (deferred per earlier discussion)
