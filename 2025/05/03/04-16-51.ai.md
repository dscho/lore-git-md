Additional platform compatibility fix for BSD variants' errno behavior, extending the earlier NetBSD-specific solution to also handle FreeBSD's EMLINK case. This patch follows the same pattern established in the previous discussion, translating FreeBSD's non-POSIX errno value to the expected ELOOP when O_NOFOLLOW encounters a symlink.

The change modifies wrapper.c's open_nofollow() function to handle both NetBSD's EFTYPE and FreeBSD's EMLINK errno values, maintaining POSIX-expected behavior without additional lstat() calls. The implementation uses conditional compilation approach with SYMLINK_ERRNO macro that's defined differently for each BSD variant. The patch fixes test failures in t0602-reffiles-fsck.sh where the different errno values caused mismatched error messages.

This completes the BSD errno translation work started in the previous patch, addressing both known platform deviations from POSIX behavior. The solution remains narrowly scoped to the symlink case where these errno values are known to occur, avoiding broader errno handling that might mask legitimate errors.
