This is a test modernization patch in the `git whatchanged` deprecation series. It updates fast-import test scripts to use `git log --raw` instead of the deprecated `git whatchanged` command. The changes are mechanical replacements across 7 test cases in t9300-fast-import.sh and 1 in t9301-fast-import-notes.sh.

The patch explains that while these test calls to `whatchanged` were originally added for manual verification during test development, they don't actually check the output. Rather than removing them entirely (which would lose the verification aspect), the patch switches to the modern equivalent `log --raw` command. This prepares the tests for when `whatchanged` is eventually removed, without changing their verification behavior.

The changes are straightforward and maintain the same test coverage while aligning with the ongoing deprecation effort. This patch follows the established pattern in the series of systematically removing `whatchanged` usage from the test suite, similar to previous documentation updates. The modifications are limited to test scripts and don't affect runtime behavior or other parts of the codebase.

- Updates 8 test cases across two test files
- Replaces `git whatchanged` with `git log --raw` (functionally equivalent for these tests)
- Maintains existing test coverage while removing deprecated command usage
- Part of the broader `whatchanged` deprecation track in the series
- Follows same preparatory approach as earlier documentation updates in the series
