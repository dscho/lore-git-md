Feature proposal for better merge commit visualization with meld.

Britton Kerin explores the 3-pane merge conflict view available in `git mergetool --tool=meld` and wonders why similar functionality isn't available for reviewing already-committed merges. The current tools (`git diff`, `git difftool`, `git show`) only offer two-pane diff views, missing the three-way visualization that can be particularly illuminating for merge commits.

They've already prototyped a solution as a shell script shared on Stack Overflow, which extracts the merge parents and base to feed into meld's three-pane mode. The email floats the idea of formalizing this as a dedicated `git-meld3` command, recognizing that shoehorning it into the existing diff tools might create more confusion than value.

This appears to be a genuine usability gap in Git's visualization tools, particularly for developers who frequently work with complex merge histories. The proposal seems technically sound, though the implementation approach (new command vs. extending existing tools) would benefit from discussion on the list. The Stack Overflow prototype suggests the author has already done some practical exploration of the problem space.
