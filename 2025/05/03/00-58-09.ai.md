This is the first patch in a 6-part series establishing Git's deprecation infrastructure, using `git pack-redundant` as the initial case study. The patch refactors the existing deprecation warning mechanism into a reusable helper function `you_still_use_that()` in usage.c, making it available for other commands slated for removal.

The key technical changes include:
- Moving the deprecation warning/die logic from builtin/pack-redundant.c to usage.c
- Adding the new helper function declaration to git-compat-util.h
- Including a test case in t5323 to verify the --i-still-use-this requirement
- Maintaining identical warning text and behavior while making the infrastructure reusable

The patch demonstrates careful attention to backward compatibility and testing - it preserves the exact user-facing behavior while cleaning up the implementation. The test addition fills a gap in the existing test coverage for the deprecation mechanism. This foundational change enables the rest of the series to build upon this infrastructure for `git whatchanged` and potentially other future deprecations.

The implementation follows Junio Hamano's stated approach of focusing first on usage measurement via forced opt-in, deferring more opinionated guidance about replacements. The helper function's design is intentionally minimal, containing just the warning and die logic without additional suggestions about alternative commands.
