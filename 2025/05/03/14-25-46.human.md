CI/build system patch addressing Windows Meson builds in GitHub Actions. This is a follow-up to earlier discussions about test hangs in the Windows environment.

The patch changes the Meson-based Windows CI job to build in Release mode rather than Debug mode, matching the behavior of the existing `win+vs` job. The key motivation is that Debug mode on Windows triggers modal assertion dialogs that hang CI runs when assertions fail, as happened with the t7001-mv test case. While that specific test case is being fixed separately, this change provides a more general solution by preventing any assertion from hanging CI builds.

The commit message explains the history thoroughly: the issue was initially masked by a separate bug (using the wrong compiler), became visible after that, and remains relevant even with the t7001-mv fix because other assertions (including in dependencies) could still trigger hangs. The patch is minimal - just adding `-Dbuildtype=release` to the Meson setup command.

This appears to be a straightforward, well-justified improvement to the CI configuration that aligns with existing practices. The discussion history shows consensus around the approach, with this version refining the commit message to better explain why the change is still needed after the t7001-mv fix.
