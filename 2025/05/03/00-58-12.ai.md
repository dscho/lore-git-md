This is a feature patch in the `whatchanged` deprecation series, implementing the opt-in requirement for continued use of the deprecated command. The patch makes `git whatchanged` require `--i-still-use-this` flag to work, while updating tests and documentation accordingly.

The patch adds the opt-in infrastructure to `builtin/log.c` with a new `i_still_use_this` flag in `struct log_config`. When the flag isn't set, the command calls the existing `you_still_use_that()` helper to show the deprecation warning. The implementation carefully notes that the config system should not touch this flag, keeping it purely for command-line use.

Test updates are comprehensive, covering both positive and negative cases. The test suite now verifies that:
1. The command fails with a deprecation message when run without `--i-still-use-this`
2. Existing test cases that use `whatchanged` are updated to include the flag
3. The command's output remains identical to `git log --raw` when properly invoked

Documentation changes are minimal, just updating the synopsis formatting while keeping the existing deprecation notice. The patch follows the series' pattern of gradual, measurable deprecation by forcing explicit opt-in rather than immediate removal. This continues the strategy of gathering usage data before final removal, as established in earlier patches.

The changes are well-contained, touching only the expected files (implementation, tests, docs) with clear commit message explaining the motivation. The test coverage appears thorough, verifying both the new requirement and backward compatibility when the flag is provided.
