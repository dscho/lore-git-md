This is a feature proposal for better merge commit visualization. Britton Kerin explores adding 3-pane Meld view support for reviewing already-committed merges, similar to what `git mergetool` offers during conflict resolution.

The email notes that current Git tools (`git diff`, `git difftool`, `git show`) only support 2-pane diff views, lacking the 3-pane merge visualization that would show base+left+right versions simultaneously. Kerin has prototyped a solution as a shell script shared on Stack Overflow, but suggests this might warrant a dedicated `git-meld3` command rather than trying to retrofit existing diff tools.

Key technical details include the reference to Meld's 3-pane merge view capability, the Stack Overflow post containing the initial script implementation, and the explicit distinction between merge conflict resolution (where 3-pane exists) and post-merge review (where it doesn't). The proposal implies this would require either a new subcommand or significant changes to the diff tool interface.
