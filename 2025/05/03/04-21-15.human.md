This is a platform compatibility follow-up patch that completes the BSD errno translation work started earlier. Collin Funk confirms that FreeBSD 14.2 also exhibits non-POSIX behavior by returning EMLINK instead of ELOOP for symlink operations, similar to NetBSD's EFTYPE behavior addressed in the previous patch.

The new version extends the solution to handle FreeBSD's EMLINK case using the same pattern established for NetBSD - translating platform-specific errno values to POSIX-standard ELOOP in wrapper.c's open_nofollow() function. The implementation remains narrowly focused on these known BSD variants while maintaining clean separation from POSIX-compliant systems.

Junio C Hamano had suggested this could be handled separately, but Collin proactively addressed both BSD cases together since he had FreeBSD access. The patch appears well-considered, building on the already-reviewed approach and fixing all known test failures in t0602-reffiles-fsck.sh. This completes the platform-specific errno handling work started after commit cfea2f2da8 introduced stricter filetype checking.
