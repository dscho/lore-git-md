Feature improvement to Git's shell function detection in diffs. This final patch in Moumita Dhar's GSoC contribution series completes the Bash function recognition enhancements in `userdiff.c`. The changes:

1. Simplify function detection by capturing the entire definition line rather than requiring specific body markers, fixing issues with line continuations and single-command functions. The regex now properly handles:
   - POSIX-style functions with line continuations (`\`)
   - Bash-style declarations with optional parentheses
   - Single-command functions without braces

2. Expand word-diff tokenization for shell syntax with comprehensive coverage of:
   - Parameter expansion operators (`:-`, `:=`, etc.)
   - Arithmetic and comparison operators
   - Command-line options (both short and long forms)
   - Array operations and special variables

The patch includes extensive test coverage across 9 new test files, validating both function line capture (in `t4018/`) and word-level diff behavior (in `t4034/`). This represents the culmination of several review rounds addressing shell syntax edge cases, with final refinements to regex grouping for comment handling. The implementation maintains backward compatibility while significantly improving shell script diff quality.
