Feature enhancement for Bash function detection in Git's diff machinery. This final patch in Moumita Dhar's GSoC contribution series completes the Bash userdiff driver improvements by addressing function definition line capture and shell syntax recognition.

The key changes modify `userdiff.c` to:
1. Replace the restrictive function body matching (requiring `{`, `(`, etc.) with `.*$` to capture entire function definition lines, fixing issues with line continuations (`\`) and single-command functions
2. Expand the word regex to better handle shell syntax including:
   - Parameter expansion operators (`:-`, `:=`, `:+`, `:?`)
   - Compound operators (`+=`, `*=`, `==`, `&&`)
   - Command-line options (both short and long forms)
   - Array operations and string manipulation (`##`, `%%`)

The patch adds comprehensive test coverage through:
- Four new test files in `t/t4018/` verifying function definition capture for:
  - Bash-style multiline functions
  - POSIX-style multiline functions
  - Single-command functions
  - Complete line capture with trailing comments
- A new word-diff test suite in `t/t4034/bash/` validating tokenization of shell syntax changes

This represents the culmination of the shell function recognition improvements, having incorporated all feedback from shell syntax experts and maintainers through four previous iterations. The changes maintain backward compatibility while significantly expanding Git's ability to properly highlight Bash scripts in diffs.
