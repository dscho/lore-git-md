The Git project has announced its selected participants for Google Summer of Code (GSoC) 2025, welcoming three new contributors. Ayush Chandekar will work on refactoring to reduce global state (mentored by Christian Couder and Ghanshyam Thakkar), Lucas Seiki Oshiro will develop a machine-readable repository query tool (mentored by Karthik Nayak and Patrick Steinhardt), and Meet Soni will focus on consolidating ref-related functionality into git-refs (mentored by Patrick Steinhardt and Jialuo She). 

The announcement, made by Kaartic Sivaraam, notes that mentors will soon contact the selected contributors to begin work. These projects align with ongoing Git efforts - particularly the global state refactoring work that relates to the `the_repository` removal initiative, and the ref consolidation that may interact with the reftable backend work. The selection process was competitive, with thanks extended to all applicants who weren't selected this year.
