Platform compatibility fix for `ident.c`'s GECOS handling.

This first patch in Johannes Schindelin's 2-part series addresses a subtle assumption in Git's identity parsing code. The `ident.c` file had been treating the `gw_gecos` field (which holds user information like full names) as writable by declaring its loop variable as `char *`, when in fact this field should be treated as read-only. The change makes this explicit by switching to `const char *`.

While discovered during Windows-specific work (where the field's immutability is enforced), this is actually a general code quality improvement that makes the intent clearer and prevents potential issues on any platform. The change is minimal (a one-line type modification) but corrects a long-standing assumption dating back to 2011.

As part of preparations for Git for Windows v2.49.0-rc0, this comes from the project's primary Windows maintainer and appears to be a straightforward, uncontroversial improvement. The patch doesn't change any observable behavior - it just makes the code's assumptions match reality.
