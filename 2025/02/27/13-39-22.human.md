This is a CI/build system fix addressing a Windows-specific issue in GitLab's test runner. The patch corrects a problem where the "msvc-meson" test job was incorrectly reporting success even when tests failed, due to a PowerShell quirk in GitLab's Windows runners.

The root cause involves PowerShell 5.1's handling of error codes in loops - specifically, when running tests through `ForEach-Object`, failures weren't properly propagating. The fix explicitly checks the exit code and forces the job to fail when tests don't pass. This matches the behavior that already works correctly on GitHub Actions (which uses a newer PowerShell version) and in other contexts.

The patch is well-explained with clear technical details about the underlying PowerShell behavior differences between CI platforms. While the immediate fix is straightforward (adding an explicit exit check), the commit message provides useful context about a future improvement coming in Meson 1.8 that may allow removing this workaround entirely.

This appears to be a solid fix for a real issue that was previously discussed on the mailing list, with links provided to both the discussion and a concrete failed test run demonstrating the problem.
