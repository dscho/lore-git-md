Test modernization patch in the `git fsck` packed-refs validation series.

This is the first patch in v8 of a 9-part series that enhances `git fsck` to validate packed-refs files. The patch modernizes the test script `t/t0602-reffiles-fsck.sh` by wrapping all test cases in subshells to ensure proper working directory cleanup. This prevents test pollution when individual tests fail between `cd` commands.

The change is mechanical but important - it converts all test blocks that change directories to use subshells, ensuring the working directory is always restored properly. The patch shows good attention to detail, with 967 lines changed (mostly indentation) to wrap the existing tests. The commit message clearly explains the motivation and the change is straightforward.

This is a preparatory cleanup that makes the test suite more robust before adding the new packed-refs validation functionality in later patches. The patch has been reviewed by mentors Patrick Steinhardt and Karthik Nayak, and fits into the larger series which has already addressed reviewer feedback in previous iterations.
