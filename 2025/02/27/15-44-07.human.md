This is a pair of platform compatibility fixes for Windows, extracted from the Git for Windows v2.49.0-rc0 development cycle. The patches address two distinct issues that surfaced during Windows-specific testing.

The first patch fixes a potential crash in the ident.c code where it was incorrectly assuming the `gw_gecos` buffer was always writable. This appears to be a Windows-specific memory handling issue that could lead to crashes when processing user identity information.

The second patch corrects a sorting issue in the Meson build configuration. While not strictly necessary for compilation, it was identified as part of broader Meson build system adjustments needed to make the Windows CI jobs pass reliably. The change is minimal - just adjusting the sort order in meson.build.

Both changes are small (one-line fixes each) and appear to be straightforward corrections rather than major architectural changes. The patches come from Johannes Schindelin, a long-time Windows port maintainer, suggesting they're likely well-vetted for the platform. The fixes are being proposed for upstream inclusion after proving useful in the Git for Windows fork.
