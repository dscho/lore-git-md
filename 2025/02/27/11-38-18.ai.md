Performance optimization for Git cat-file's bitmap-based object filtering.

This is the final patch in Patrick Steinhardt's series enhancing `git cat-file` with bitmap-accelerated object type filtering. The patch implements the bitmap optimization path for both single-type filters (`object:type=`) and the special `blob:none` filter, completing the performance work started earlier in the series.

The implementation introduces a new `batch_one_object_bitmapped()` callback adapter that bridges between the bitmap iteration API and the existing batch processing infrastructure. The key optimization comes from using type-specific bitmaps when available, falling back to traditional packfile iteration for non-bitmapped packs. The patch shows dramatic speed improvements in benchmarks on Chromium's 50GB repository, with tag filtering becoming 4000x faster (20ms vs 82s) and commit filtering 75x faster.

Karthik Nayak provides minor feedback on the commit message wording and suggests making the `LOFC_BLOB_NONE` conditional more explicit in the code. The technical implementation builds on Taylor Blau's type-specific bitmap work (commit 2189649b) and integrates with the filtering infrastructure established in earlier patches of this series. The bitmap optimization path is automatically used when available, maintaining backward compatibility with non-bitmapped repositories.

This completes the core performance work of the series, though the final CLI interface (`--objects-filter` vs `--filter=`) remains under discussion. The patch demonstrates the series' ability to deliver on its promise of massive performance gains for large repositories while maintaining correctness through the existing test framework.
