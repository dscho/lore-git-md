This is a patch in Patrick Steinhardt's series enhancing `git cat-file` with bitmap-accelerated object filtering, specifically implementing the "blob:none" filter type. The patch adds support for omitting all blob objects from batch output, with tests verifying the behavior matches `git rev-list`'s equivalent filter.

The implementation adds a new LOFC_BLOB_NONE case to the filter handling in builtin/cat-file.c, skipping blob objects during batch output. The documentation is updated to describe the new filter option, though Karthik Nayak notes it currently shows `--filter=` syntax rather than the series' proposed `--objects-filter` interface. The test suite is expanded with a new test_objects_filter helper that will support future filter types, with specific verification that blob:none produces matching output between cat-file and rev-list.

The patch maintains the series' technical approach of implementing filters first with traditional object iteration, leaving bitmap acceleration for later patches. It handles all object storage types (packed with bitmap, packed without bitmap, and loose) through comprehensive test coverage. The implementation appears clean and focused, though the CLI syntax question remains open pending resolution of the ongoing `--objects-filter` vs `--filter=` debate noted in the thread context.
