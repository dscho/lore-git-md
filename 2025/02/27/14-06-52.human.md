This is a proposal for improving Git's output formatting, building on the ongoing discussion about backspace escape handling. Marc Branchaud suggests moving beyond terminal detection heuristics (like `isatty()`) toward explicit format options for Git commands, similar to how the `ip` command offers JSON output via `-j`. The proposal envisions a global `--format` option that would let scripts request machine-readable output while defaulting to terminal-friendly formatting when unspecified.

The email positions this as a long-term solution that could be implemented incrementally, addressing not just the current backspace escape issue but providing a framework for consistent output formatting across Git commands. While acknowledging the effort required, Branchaud argues this approach would eliminate guesswork and better serve both human users and script authors. The suggestion comes as the thread has been converging on terminal detection as a solution, offering an alternative direction that might provide more explicit control.
