This is a localization (l10n) coordination email kicking off the translation effort for Git 2.49.0. Jiang Xin, the l10n coordinator, announces that with the release of Git 2.49.0-rc0, there are 35 updated messages needing translation since the last release.

The email provides detailed instructions for translators, explaining that the traditional "po/git.pot" file is no longer maintained in the repository and can be generated on demand. It outlines the workflow for updating translation files, including pulling latest changes, updating PO files, and removing noisy file location comments before submission.

Translators are instructed to send pull requests to the git-l10n/git-po repository by March 13, 2025, and to use the git-po-helper tool to validate their contributions against l10n conventions. The email serves as both an announcement of the translation cycle opening and a reference document for contributors, with clear technical guidance about the modernized localization workflow.
