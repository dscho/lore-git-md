This is a patch in Patrick Steinhardt's series enhancing `git cat-file` batch mode filtering, specifically focusing on wiring up the object filtering option. The patch introduces `--objects-filter` as the command-line interface for filtering objects by type and size, matching the syntax used in `git rev-list` but with a different option name to avoid confusion with the existing `--filters` flag in `cat-file`.

The patch lays groundwork for future bitmap acceleration by establishing the filtering interface, though it currently just rejects filter options with a die() message. Karthik Nayak points out a typo ("fo" → "for") in the commit message. The discussion around option naming (`--objects-filter` vs `--filter=`) continues from earlier in the thread, with Patrick opting for the former to maintain clarity with existing `cat-file` flags, while others (like Toon Claes) have advocated for consistency with `rev-list`'s `--filter=`.

This patch is part of the broader effort to bring rev-list-style filtering to cat-file, with performance improvements expected once bitmap integration (handled in later patches) is complete. The current implementation is intentionally minimal, focusing on the interface while deferring the actual filtering logic and bitmap optimizations to subsequent commits in the series.
