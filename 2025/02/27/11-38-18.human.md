Performance optimization for Git's object filtering with bitmaps. This is the final patch in Patrick Steinhardt's series to enhance `git cat-file`'s batch mode filtering capabilities, now adding bitmap acceleration for type-based filtering.

The patch enables significant performance improvements when filtering objects by type (tags, commits, trees, blobs) or using the new `blob:none` filter, particularly in large repositories. Benchmark results from Chromium's 50GB repository show dramatic speedups - up to 4000x faster for tag filtering (20ms vs 82s) and 75x faster for commits. The implementation uses type-specific bitmaps when available, falling back to traditional scanning for packfiles without bitmaps.

Karthik Nayak provides a minor code review note suggesting an `if/else` structure would improve readability in the blob:none handling section. The patch builds on previous work in the series that established the filtering infrastructure and interfaces, now completing the performance optimization track.

This represents the culmination of work addressing GitLab's large-repository performance needs, with bitmap acceleration being the final piece after establishing the core filtering capabilities. The series remains pending resolution of CLI interface naming (`--objects-filter` vs `--filter=`) and coordination with Taylor Blau's bitmap work, but this patch demonstrates the concrete performance benefits of the approach.
