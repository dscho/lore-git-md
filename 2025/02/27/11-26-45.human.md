This is a patch in Patrick Steinhardt's series enhancing `git cat-file` with bitmap-accelerated object filtering, specifically implementing the "blob:none" filter type. The patch adds support for omitting all blob objects from `cat-file` output when using batch mode with matching behavior to `git rev-list --filter=blob:none`.

Karthik Nayak points out two issues in review: First, the documentation incorrectly shows `--filter=` instead of the series' current `--objects-filter` interface (which is still under debate). Second, he notes the implementation requires filter-specific type checking, lacking a more generic approach.

The patch includes thorough testing that validates the filter works across packed (both bitmap and non-bitmap) and loose objects, with test output matching `rev-list` behavior. The test infrastructure is set up to accommodate future filter types that will come in later patches.

This appears to be a well-constructed piece of the series, though it remains blocked on the ongoing CLI naming debate (`--objects-filter` vs `--filter=`) and depends on Taylor Blau's bitmap work for the full performance optimization. The technical implementation here looks sound, just needing the CLI syntax to be finalized.
