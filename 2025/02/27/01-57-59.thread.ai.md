This thread announces the Git 2.49.0 localization (l10n) cycle, coordinated by Jiang Xin following the 2.49.0-rc0 release. There are 35 updated messages requiring translation since the last release. The email provides detailed technical instructions for contributors: pulling latest changes from git.git master, using `make po-update` to sync translations, and properly formatting `.po` files by removing noisy file location comments (with two suggested `msgcat` cleanup methods). Contributors must submit pull requests to git-l10n/git-po by March 13, 2025, with the git-po-helper tool running CI validation checks that must pass. This follows Git's standard l10n workflow, with the coordinator providing clear procedural guidance to maintain translation consistency. The thread is focused on the translation update process for this specific release cycle.
