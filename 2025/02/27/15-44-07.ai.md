This is a cover letter for a 2-patch series containing platform compatibility fixes from Git for Windows. The series includes two small but important changes needed to make Git for Windows v2.49.0-rc0 compile and pass CI tests.

The first patch fixes an assumption in `ident.c` that the `gw_gecos` buffer is always writable, which appears to be a Windows-specific issue. The second patch corrects sorting in the Meson build system, though the cover letter notes this wasn't strictly required for compilation but emerged from other Meson-related adjustments.

The changes are minimal (2 lines changed total across both patches) but address real issues encountered in the Windows build environment. The cover letter suggests these fixes are worth upstreaming since they're not Windows-specific hacks but general improvements that happen to have been discovered during Windows development work. The patches appear focused and well-scoped, coming from an experienced Windows maintainer.
