This is a performance discussion about Windows test execution times in the Meson build system. Patrick Steinhardt responds to Johannes Sixt's inquiry about whether Meson-built tests are slower than Makefile-built ones on Windows, confirming that from his own testing there appears to be no significant difference between the two build systems. He notes that the initial speed difference observed (where the first ~20 tests run quickly) is expected behavior since unit tests naturally execute faster than integration tests. The email serves to move the discussion forward by providing this comparative data point, though Patrick remains open the possibility of learning about any actual performance differences others might discover. The thread continues to investigate whether the observed slowness is inherent to Windows testing or specific to the Meson build system.
