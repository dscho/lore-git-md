This is a bugfix patch addressing a regression in WebDAV-based HTTP authentication that broke netrc file usage in Git 2.46+. Brian m. carlson explains that while netrc support has long been available as an undocumented feature, the recent proactiveAuth changes inadvertently disabled it for WebDAV operations. The patch restores this functionality with a minimal test case.

The email raises a broader question about netrc's status in Git - currently it exists as an untested, undocumented feature that some users rely on. The author suggests the project should either properly support it with tests and docs or remove it in favor of the more robust git-credential-netrc helper from contrib. While fixing the immediate WebDAV regression, carlson deliberately keeps the scope minimal to avoid committing to long-term netrc support, leaving the door open for others to expand testing if desired.

The technical change itself is small (3 lines in http.c), focused specifically on WebDAV operations, accompanied by a new test in t5540. The patch appears well-scoped to fix the regression while avoiding entanglement with the larger proactiveAuth/netrc compatibility questions that were discussed in the thread. The author's note about accidentally breaking this feature despite familiarity with the HTTP code underscores the risks of maintaining undocumented functionality.
