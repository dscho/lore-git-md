This thread concerns a straightforward correction to the Italian translation of Git's error messages. Ruggero Turra identified and fixed a typo in the Italian localization for `git mv`'s bad source path error, changing "sourgente" to the correct "sorgente" (Italian for "source"). The change is clearly correct and uncontroversial, affecting only the po/it.po file.

Junio C Hamano, the Git maintainer, has now asked Jiang Xin (the project's localization coordinator) whether to apply this single-character fix immediately or wait for the upcoming batch of translation updates in Git 2.49. Given the trivial nature of the change and its clear correctness, this appears to be purely a matter of process rather than any substantive discussion. The patch is effectively ready to go, with the only remaining question being the timing of its inclusion.
