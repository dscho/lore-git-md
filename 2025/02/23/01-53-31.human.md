Bugfix for HTTP authentication regression affecting WebDAV pushes with netrc files. This patch from brian m. carlson addresses a regression introduced in Git 2.46 that broke netrc credential handling for WebDAV-based HTTP pushes. The issue caused subsequent authentication attempts to fail after an initial successful connection when using netrc files.

The fix modifies the condition in `http.c` that determines when to send empty credentials, ensuring netrc fallback works properly when proactive authentication is disabled. The change is minimal (3 lines) but effectively restores the pre-2.46 behavior for this specific case. A new test case in `t5540-http-push-webdav.sh` verifies the fix by testing push operations using credentials from a netrc file.

The patch serves as a targeted fix while the broader discussion about netrc support's future continues. As noted in the thread, netrc functionality has existed as an undocumented feature prone to breakage, and this fix doesn't resolve the fundamental tension between netrc workflows and proactive authentication's design. The change is well-contained and clearly explained, with the commit message providing thorough technical background on both the regression and solution.
