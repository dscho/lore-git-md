This is a bugfix patch addressing a regression in WebDAV-based HTTP authentication that broke netrc file usage in Git 2.46+. The patch comes with a test case but also raises broader questions about the feature's future maintenance.

The core fix is straightforward - restoring netrc functionality for WebDAV pushes that was accidentally broken by earlier changes to HTTP authentication. The patch modifies `http.c` to properly handle netrc credentials in this case and adds a test in `t5540-http-push-webdav.sh` to verify the behavior.

However, the cover letter highlights deeper issues: netrc support has existed as an undocumented, untested feature that maintainers weren't fully aware of, leading to this regression. Brian m. carlson notes the HTTP code's complexity makes such features prone to breakage, and proposes either properly documenting and testing netrc support (making it a first-class feature) or removing it in favor of the existing `git-credential-netrc` helper from contrib.

The technical changes are minimal (3 lines modified in http.c), but the discussion around feature maintenance is significant. The patch serves both to fix an immediate regression and to surface a long-standing technical debt issue in Git's HTTP authentication stack. The test addition provides at least basic coverage, though carlson explicitly states he's not planning to expand this further unless others contribute additional documentation and tests.
