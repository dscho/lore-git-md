This is a philosophical response in the ongoing discussion about Git's attribute handling during history rewriting operations. D. Ben Knoble addresses Josef Wolf's argument that newer `.gitattributes` should automatically apply to older commits during rebase operations.

Knoble provides a technical rationale for Git's current behavior, explaining that older commits can't know which future branch's attributes to use, since multiple valid futures with different attributes could exist. He acknowledges the use case where propagating attributes from the starting point might make sense, but defends Git's default behavior of using commit-specific attributes as reasonable and unsurprising.
