Platform compatibility patch in the ongoing `-Wsign-comparison` warning cleanup series. This is patch 5/6 in the v2 submission from Zejun Zhao, continuing their GSOC work to improve type safety in Git's patch application code.

The patch converts several `int` loop counters to `size_t` throughout `apply.c` to eliminate compiler warnings about signed/unsigned comparisons. The changes are mechanical but widespread - 32 lines modified across 10 different functions, all following the same pattern of replacing `int i` with `size_t i` in for loops where the counter is compared against size-related values. The modifications touch core patch application logic including diff parsing, name matching, and image updating.

This continues the series' established approach of using `size_t` for memory/length operations while maintaining the existing code structure. The changes appear straightforward and consistent with the project's type safety goals, though as with previous patches in the series, some reviewers may want to verify there are no subtle behavioral impacts from the type changes. The patch maintains the series' focus on minimal, targeted changes to address specific warnings while preserving the existing architecture.
