This is patch 4/5 in Meet Soni's refactoring series to centralize refspec-related functions in refspec.c. The patch moves three key matching functions from remote.c to refspec.c: `find_refspec_match()`, `find_all_refspec_matches()`, and `find_negative_refspec_match()`. These functions handle core refspec matching logic including negative refspec evaluation and wildcard pattern expansion.

The movement preserves all existing functionality exactly while improving code organization. The patch includes:
- 123 lines added to refspec.c with matching header declarations
- 122 lines removed from remote.c
- All BUG() assertions and edge case handling preserved
- New `#include "string-list.h"` in refspec.c to support the string list operations used in the negative refspec matching logic

The functions maintain their exact behavior:
- `find_refspec_match()` looks for a single matching refspec
- `find_all_refspec_matches()` collects all matches into a string list
- `find_negative_refspec_match()` handles the special case of negative refspec evaluation
