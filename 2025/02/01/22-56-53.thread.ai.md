Performance regression investigation for Meson-built Git tests on Windows. The thread began with M Hickford's report showing significant test execution slowdowns (some tests jumping from sub-second to 60+ seconds) when built with Meson/Ninja using MSVC compiler on Windows, with concrete data from commit 58b5801aa9 showing abrupt degradation after test 19. Johannes Sixt shifted focus to determining whether this represents a regression compared to Makefile-based Windows builds or is platform-wide behavior. Patrick Steinhardt has now responded with test results indicating no significant performance difference between Meson and Makefile builds on Windows, suggesting the observed slowdowns may be inherent to Windows test execution patterns (with integration tests being substantially slower than unit tests) rather than Meson-specific. The technical context remains: Windows platform, MSVC compiler, Ninja backend, with affected tests (t-reftable-stack, t0013-sha1dc, t0010-racy-git) showing process spawning overhead. While Steinhardt's data points toward this being a Windows characteristic rather than a Meson regression, the thread remains open for others to report any concrete performance differences they observe between the build systems. No root cause has been identified for the specific test timing jumps originally reported, but the working hypothesis is now that these may reflect normal Windows test execution behavior rather than a new regression.
