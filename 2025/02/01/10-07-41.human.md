This is a security-related discussion about the proposed warning for `git-credential-store`. Brian Carlson raises concerns about the practicality of warning users about the insecure credential storage method, particularly for environments without desktop access where alternative credential helpers aren't viable. 

The email argues that warning users in these constrained environments would just create annoyance without providing a viable alternative. Carlson suggests using Git's advice system for the warning instead, which would allow users to disable it if needed. They also mention a personal tool (Lawn) that could theoretically help in these situations, but acknowledge it's not a general solution.
