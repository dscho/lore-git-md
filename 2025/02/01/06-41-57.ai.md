This is version 3 of a refactoring series that centralizes refspec-related logic from remote.c` into `refspec.c`. The series has evolved through multiple rounds of review, with version 2 having been technically approved but receiving some naming and documentation refinements.

Key changes in v3:
1. The series has been expanded from 3 to 5 patches for more granular changes
2. Significant renaming of functions for clarity:
   - `omit_name_by_refspec` → `refname_matches_negative_refspec_item`
   - `query_refspecs` → `find_refspec_match`
   - `query_refspecs_multiple` → `find_all_refspec_matches`
3. More precise documentation, particularly around the `apply_refspecs()` function which now clarifies it searches and returns matches rather than vaguely "applying" changes
4. Maintains all behavior exactly while moving code, with BUG() assertions preserved for invalid inputs

The changes affect several key areas:
- Negative refspec matching logic
- Refname pattern matching
- Multi-match queries
- Ref application operations
