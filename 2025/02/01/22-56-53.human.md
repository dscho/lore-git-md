This is a performance report about test execution times on Windows. Mirth Hickford observes that while the first 19 tests in the Git test suite run quickly (under 2 seconds each) when built with Meson/Ninja using MSVC on Windows, tests starting around #20 show a dramatic slowdown - with some tests taking nearly a minute to complete. The slowdown appears to affect a variety of test types (reftable, sha1dc, crlf handling, signals, etc.), while the same tests run quickly on Linux. 

The report provides detailed timing data showing the abrupt performance cliff, with test times jumping from sub-second to 5+ seconds at test #20, then escalating to 40-60 seconds for later tests. The author is seeking input from the community about whether others have observed this behavior and what might be causing it. 

This appears to be a genuine performance regression specific to the Windows/Meson build configuration, though the root cause isn't obvious from the report alone. The detailed timing data makes this a useful starting point for investigation by Windows or build system experts. The fact that Linux performance is normal suggests this may relate to Windows-specific process handling or filesystem interactions in the test harness.
