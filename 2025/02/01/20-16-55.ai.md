This is a refactoring patch that's part of Justin Tobler's series to improve missing object reporting in `git rev-list`. The patch introduces a new quoting mechanism that ignores `core.quotePath` configuration when requested.

The change adds a `CQUOTE_IGNORE_CONFIG` flag to the C-style quoting functions in `quote.c`. When this flag is set, the quoting behavior will always follow the default rules (as if `core.quotePath=true`) regardless of the actual configuration. This ensures consistent output for operations that need stable quoting behavior independent of user settings.

The implementation modifies the internal `cq_must_quote()` and `next_quote_pos()` functions to accept an `ignore_config` parameter, which is set when the new flag is present. The changes are minimal and focused, touching only the quoting infrastructure while maintaining all existing behavior when the new flag isn't used.

This is a technical prerequisite for the series' goal of providing stable output formatting for missing object information. The patch follows the thread's consensus about avoiding configuration-dependent output, addressing one of Junio Hamano's earlier concerns. The changes are well-contained and properly documented through the new flag definition in `quote.h`.
