This is part 3 of a 4-part series adding enhanced missing object reporting to `git rev-list`. The patch introduces a new `--missing=print-info` action that extends the existing `--missing=print` functionality with additional context about missing objects, specifically their paths.

The key addition is path information for missing objects, displayed in a machine-parseable format like `?<oid> path=<quoted-path>`. Paths containing spaces or special characters are properly quoted in C-style. The implementation uses a new `oidmap` to track missing objects along with their paths, replacing the simpler `oidset` used by the basic print mode.

The changes are well-contained, touching just the rev-list command implementation, its documentation, and adding comprehensive tests. The test suite verifies correct handling of various path cases including spaces and quotes. This builds on previous discussion in the thread about maintaining stable output formats and avoiding configuration-dependent quoting.
