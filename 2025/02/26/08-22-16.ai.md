This is a build system optimization patch in Patrick Steinhardt's Meson refactoring series (v3 6/13). It continues the theme of dependency management improvements by fixing unnecessary libcurl linking across all Git executables.

The patch modifies the Meson build configuration to stop propagating the full libcurl dependency through `libgit_dependencies`, which was causing all executables to link against curl unnecessarily. Instead, it now only includes curl's header directories via `partial_dependency()` for version checking purposes, while maintaining the actual curl linkage only for executables that need it through the `libgit_curl` dependency introduced in patch 5/13.

Key technical changes:
- Replaces `libgit_dependencies += curl` with `libgit_dependencies += curl.partial_dependency(includes: true)`
- Updates `libgit_curl` to explicitly include curl as a dependency
- Maintains curl include directories for `LIBCURL_VERSION` resolution in help.c
- Preserves identical build output while reducing unnecessary linkage

This builds on the architectural simplifications from previous patches (particularly 5/13's curl dependency unification) and represents a logical next step in the series' goal of streamlining the build system. The change is well-contained and maintains compatibility while eliminating redundant linking, setting up for potential further optimizations in later patches.
