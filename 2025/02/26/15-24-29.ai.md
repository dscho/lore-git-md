This is the fourth patch in a 6-part series introducing reflog expiration as a maintenance task. The patch continues the refactoring work to make reflog expiration logic reusable outside of builtin/reflog.c.

The key change moves three reflog expiration helper functions from builtin/reflog.c to reflog.c and exposes them via reflog.h:
- `find_cfg_ent()` (now static in reflog.c) - finds/creates per-ref expiration config entries
- `reflog_expire_config()` - parses reflog expiration configuration
- `reflog_expire_options_set_refname()` - applies per-ref configuration to options

The patch also introduces two new public constants in reflog.h for the expiry flags (REFLOG_EXPIRE_TOTAL and REFLOG_EXPIRE_UNREACH), replacing the previous private EXPIRE_TOTAL/UNREACH defines. All callers in builtin/reflog.c are updated to use the new public functions and constants.

This is a mechanical refactoring with no behavior change, preparing for patch 5 which will split the expiration logic from builtin/gc.c. The changes follow the pattern established in earlier patches of moving functionality from command-specific implementations to shared infrastructure while maintaining the same behavior. The code movement is clean and well-contained, touching only the targeted functions and their call sites.
