Build system patch fixing path handling in Meson builds when runtime prefix is enabled. This is part of a larger series (3rd iteration, patch 1/13) improving Meson build support.

The patch addresses an inconsistency between Makefile and Meson builds regarding how GIT_EXEC_PATH is set when runtime prefix is enabled. Currently, Meson always uses an absolute path for GIT_EXEC_PATH, which can prevent Git from finding its binaries when runtime prefix is active. The fix makes the path relative when runtime_prefix is enabled, matching Makefile behavior.

Key technical details:
- Moves GIT_EXEC_PATH definition to be conditional on runtime_prefix setting
- Uses relative path (just libexecdir/git-core) when runtime_prefix is true
- Maintains absolute path (prefix/libexecdir/git-core) when runtime_prefix is false
- Affects meson.build configuration and libgit_c_args compilation flags

The change appears straightforward and well-motivated, fixing a clear divergence from Makefile behavior. As the first patch in a series, it sets up proper path handling that may be important for subsequent Meson build improvements.
