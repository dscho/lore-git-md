Git for Windows 2.49.0-rc0 release announcement (Windows-specific distribution, not upstream Git). Key changes:

1. Deprecations:
   - Phased removal of `git svn` due to maintenance burden and low usage
   - Discontinuation of 32-bit installers (except MinGit continuing until April 2029)

2. Technical updates:
   - Incorporates upstream Git v2.49.0-rc0
   - Promotes `--full-name-hash` to stable `--name-hash-version=2`
   - Adds new `git backfill` command with renamed `--min-batch-size` option
   - Fixes symlink renaming regression from v2.48.0
   - Updates OpenSSH and PCRE2 dependencies

3. Distribution:
   - Provides SHA-256 checksums for:
     - 64-bit and ARM64 installers/portable archives/tarballs
     - 32-bit MinGit variants
   - Marks transition in architecture support and feature set

This release reflects both upstream updates and Windows-specific maintenance decisions, with `git svn` deprecation being the most significant user-facing change. The checksums enable verification for downstream packaging workflows.
