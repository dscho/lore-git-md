This is a build system optimization patch in Patrick Steinhardt's ongoing Meson refactoring series (v3, patch 10/13). The change eliminates redundant searches for the `sed` executable during the build process.

The build system was previously looking up the `sed` program multiple times - both in a loop checking required tools and when processing documentation. The patch moves this lookup to a single declaration at the top level of the meson.build file, then references that cached result everywhere `sed` is needed. This saves unnecessary filesystem operations during the build.

The change is straightforward and mechanical, touching only two files. It continues the series' theme of streamlining the build system by removing duplicate work. Since this is the 10th patch in a well-reviewed series that has already addressed technical concerns, it appears to be a safe, incremental improvement.
