This is a refactoring patch in Patrick Steinhardt's Meson build system series (v3 04/13), focusing on simplifying the common-main library usage. The change eliminates the separate static library for common-main.c (used by multiple Git executables) in favor of compiling it directly into each executable that needs it. 

The key technical change is replacing the `common_main_library` static library declaration with a `libgit_commonmain` dependency that combines both the common-main sources and `libgit.a` linkage. This removes the need for executables to specify both dependencies separately. The patch updates all affected build files (main meson.build, oss-fuzz, test helpers) to use the new consolidated dependency.

The change maintains identical build behavior while reducing build system complexity. It follows the series' theme of architectural simplification, building on earlier static library consolidation work (patches 1-3/13). The modification is mechanical and straightforward, touching only build system files with no impact on runtime behavior or source code structure.

This appears to be a well-contained refactoring that logically follows the series' progression, with no obvious technical drawbacks. The change is consistent with the Meson build system's idioms and the project's ongoing build system modernization efforts.
