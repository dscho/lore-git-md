This is a build system patch continuing Patrick Steinhardt's Meson refactoring series (v3, patch 6/13). It optimizes how libcurl is linked into Git executables, fixing an inefficiency where the library was being unnecessarily linked into all executables when only a few actually need it.

The change modifies the Meson build configuration to only propagate libcurl's include directories (needed for version checking) through the main `libgit` dependency, while moving the actual library linkage to the new `libgit_curl` dependency introduced in patch 5/13. This matches the intended design where only HTTP-related executables should link against curl.

The patch is a straightforward technical improvement that builds on the architectural simplifications made earlier in the series. It follows the established pattern of reducing unnecessary dependencies while maintaining identical build behavior. The change has already been reviewed in the context of the larger series, with no outstanding concerns noted. This continues the series' theme of making the build system more precise about dependency declarations.
