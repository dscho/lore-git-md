Build system refactoring in Patrick Steinhardt's Meson improvements series (patch 4/13). This change simplifies how executables link against the common-main functionality by eliminating an intermediate static library. Instead of creating a separate `common-main` library that all executables must link against alongside `libgit.a`, the patch combines these into a single dependency (`libgit_commonmain`). 

The change affects multiple build files, updating all executables that previously listed both dependencies to now use the combined one. This includes core Git commands like `git` and `git-shell`, test helpers, and protocol implementations like `git-remote-http`. The modification maintains the same build behavior while reducing boilerplate in the build configuration.

This is part of a larger series that has already received positive technical review, with this particular patch representing a straightforward architectural simplification. The change appears well-contained and mechanically sound, following the series' goal of streamlining the Meson build configuration.
