Git v2.49.0-rc0 release announcement - first release candidate for upcoming version with 326 non-merge commits from 65 contributors (15 new). Key changes include:

New user-facing features:
- `git backfill` command for blobless clone bulk downloads
- Shallow clone support for single non-tip commits
- `git gc`/`git repack` packfile optimization options
- Improved `help.autocorrect` and atomic push behavior (note: `help.autocorrect` must use dot notation "help.autocorrect=1" in both files and CLI - bracketed form invalid per Junio C Hamano)

Internal improvements:
- Continued `the_repository` removal effort (multiple commits)
- Signed/unsigned comparison and alignment fixes
- Meson build system enhancements
- Test infrastructure updates

Documentation:
- Ongoing AsciiDoc conversion
- D. Ben Knoble noted config variable formatting inconsistency ("section.key" vs "[section] key" in Release Notes)
- Junio C Hamano clarified `help.autocorrect` specifically requires dot notation, suggested documentation phrasing improvements to avoid ambiguity
- Numerous other documentation fixes and improvements

The release includes work from 65 contributors (15 new) across all major subsystems. Testing encouraged via standard distribution channels (tarballs, tags). This marks the stabilization phase before final 2.49.0 release. Open documentation precision issue around config variable notation remains, though without functional impact.
