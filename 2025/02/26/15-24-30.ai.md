This is the fifth patch in a 6-part series introducing reflog expiration as a maintenance task. It's a refactoring patch that extracts reflog expiration logic from `builtin/gc.c` into a standalone function, preparing for reuse by the new maintenance task in the next patch.

The patch moves the reflog expiration implementation from inline in `gc_before_repack()` to a new `maintenance_task_reflog_expire()` function. The key changes are:
- Removes the global `reflog` strvec that was previously used to store the command arguments
- Creates a new function that constructs and runs the `git reflog expire --all` command
- Updates the call site in `gc_before_repack()` to use the new function
- Maintains the same error handling behavior (die on failure with "reflog" as the command name)

This is a straightforward code movement that follows the pattern established in earlier patches of the series, continuing the effort to make reflog expiration logic more modular and reusable. The change is well-contained, touching only `builtin/gc.c` and maintains all existing functionality while removing some global state. This prepares for patch 6 which will introduce the new maintenance task using this extracted function.
