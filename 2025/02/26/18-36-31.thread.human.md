This is the first release candidate for Git 2.49.0, announcing a significant update with contributions from 65 developers (including 15 new to the project). The release introduces several user-visible improvements, most notably the new `git backfill` command for blobless clones and expanded shallow clone capabilities. Under the hood, the ongoing `the_repository` removal effort continues to progress, while the build system and test infrastructure see multiple refinements.

The changes span performance optimizations (particularly around packfiles and gc/repack operations), UI behavior tweaks, and a substantial documentation overhaul as part of the AsciiDoc conversion project. With 326 non-merge commits since 2.48.0, this represents a substantial development cycle. The release candidate is now available for community testing, with tarballs and tags published in the usual locations.
