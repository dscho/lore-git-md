This is a follow-up in the ongoing CI/build system discussion about Meson build issues on Windows, now revealing a cross-platform incremental build fragility problem.

Jeff King reports encountering a new issue with Meson builds that affects even Linux systems when switching between Git branches. When moving from 'next' to 'master' and attempting an incremental build, the process fails with a cryptic error about array comparison operators in meson.build. The only workaround is to completely wipe and rebuild, which is particularly painful during bisection operations where frequent branch switching is required.

The email highlights a broader build system concern beyond the Windows-specific CRLF handling issues previously identified. While ccache helps mitigate some rebuild costs, the fundamental fragility of incremental builds across Git branches remains problematic. Jeff is seeking guidance from Patrick Steinhardt on whether there's a better way to handle these incremental builds without requiring full rebuilds.

This adds another dimension to the ongoing Meson build system stabilization effort, showing that the issues may not be limited to Windows configurations. The thread continues to uncover deeper build system integration challenges that need addressing before the Meson work can be considered fully stable.
