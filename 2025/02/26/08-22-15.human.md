This is a refactoring patch in Patrick Steinhardt's Meson build system improvement effort (part 5/13 of the series). It simplifies the build configuration for executables that link against libcurl by introducing a new `libgit_curl` dependency that bundles common curl-related source files.

The change eliminates repetitive declarations of curl-related sources across multiple executables (git-remote-http, git-http-fetch, git-http-push, and their aliases) by centralizing them in a single dependency. The patch also fixes an architectural issue where curl was being pulled in transitively through libgit, which shouldn't actually need curl itself.

This continues the series' theme of simplifying the Meson build configuration while maintaining identical build output. The change is straightforward and appears well-contained, building on the common-main consolidation from earlier in the series. The commit message clearly explains both the current situation and the planned follow-up fix for the curl dependency issue.
