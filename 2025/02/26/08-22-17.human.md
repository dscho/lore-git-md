This is a refactoring patch in Patrick Steinhardt's ongoing Meson build system improvement series (patch 7/13). It removes an unnecessary intermediate library (`libgit_version.a`) that was previously used to handle version information in the build process.

The patch explains that this separate library was originally created to avoid rebuilding all of `libgit.a` when the version changed, but this concern is now obsolete since the introduction of `version-def.h`. The current setup already ensures only version-dependent files get rebuilt when needed. The change simplifies the build by directly including version-related files in `libgit.a` rather than maintaining them in a separate library.

The modification is straightforward - it deletes the custom library definition and moves the version handling directly into the main library configuration. This continues the series' theme of streamlining the Meson build configuration to match (and in some cases improve upon) the behavior of the traditional Makefile-based build.
