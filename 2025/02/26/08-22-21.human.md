This is a refactoring patch in Patrick Steinhardt's ongoing Meson build system series (v3, patch 11/13). It fixes a variable naming collision where `git` was being used to store both the external Git executable and the built Git executable, causing the need to redundantly re-find the external Git executable in the documentation build.

The change renames the built executable variable to `git_builtin` to avoid this collision, eliminating one redundant `find_program('git')` call in the documentation build. This follows the series' pattern of simplifying the build system by reducing redundant operations and improving variable naming.

The change is straightforward and maintains existing functionality while making the build process slightly more efficient. It's a small but logical improvement that fits well with the series' broader goal of Meson build system simplification.
