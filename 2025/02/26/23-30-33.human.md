This is a release announcement for Git for Windows 2.49.0-rc0, marking a significant transition point for the Windows port. Johannes Schindelin announces several important changes, including the upcoming deprecation of `git svn` support due to maintenance challenges and low usage, and the discontinuation of 32-bit installers (though 32-bit MinGit will continue until 2029). 

The release includes updates to core components like Git v2.49.0-rc0, OpenSSH v9.9.P2, and PCRE2 v10.45. Notable feature updates include the promotion of the experimental `--full-name-hash` option to a stable `--name-hash-version=2` and the upstream acceptance of the `git backfill` command (with a renamed `--min-batch-size` option). A bugfix addresses symlink renaming issues introduced in Git v2.48.0.

The announcement provides SHA-256 checksums for various distribution formats (64-bit, ARM64, portable, and MinGit variants), signaling a continued focus on security and verification. This release appears well-prepared, with clear communication about both technical updates and strategic deprecations affecting Windows users.
