This is a build system fix in Patrick Steinhardt's Meson refactoring series (v3 patch 2/13). It corrects OpenSSL fallback behavior when the HTTPS backend is set to 'auto' on systems without system OpenSSL, particularly important for Windows builds where OpenSSL typically isn't available by default.

The patch fixes two issues: First, it ensures the build system falls back to the OpenSSL wrapper subproject when OpenSSL isn't required but the backend is set to 'auto'. Second, it properly reports the backend as 'none' when no HTTPS backend is selected. The changes are minimal (6 lines added, 1 removed) but important for correct dependency handling in the Meson build.

This is part of a well-reviewed series that has already addressed multiple rounds of feedback, with this particular fix being a refinement of the build system's dependency resolution logic. The change is straightforward and aligns with the series' goal of improving the build system's reliability and cross-platform compatibility.
