Maintainer follow-up on pager configuration for control character handling.

Junio Hamano concurs with Jeff King's assessment that adding 'U' to Git's default `$LESS` configuration would negatively impact tab display in diffs, despite initially considering it as a solution for backspace character visibility. This quick follow-up confirms the maintainers' agreement to reject this particular approach, preserving the current diff formatting behavior.

The exchange highlights the careful balancing act between security/visibility concerns (making control characters apparent) and maintaining Git's core functionality (readable diffs). While the 'U' flag would have addressed the backspace display issue, its broader impact on tab rendering was deemed too disruptive.

This leaves the thread's original questions about standardizing escape sequence handling across Git commands still open, but settles the specific sub-thread about pager defaults. The maintainers appear to be favoring more targeted solutions rather than blanket configuration changes that would affect unrelated features.
