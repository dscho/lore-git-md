This is a release announcement for Git for Windows 2.49.0-rc0, the Windows-specific distribution maintained separately from upstream Git. Johannes Schindelin (Dscho) announces several significant changes, including the phased removal of `git svn` support due to maintenance burden and the discontinuation of 32-bit installers (though MinGit 32-bit will continue until 2029). The release incorporates upstream Git v2.49.0-rc0 and updates dependencies like OpenSSH and PCRE2.

Key technical updates include the stabilization of the experimental `--full-name-hash` option as `--name-hash-version=2` and the inclusion of the new `git backfill` command with its renamed `--min-batch-size` option. A notable bugfix addresses symlink renaming issues that were introduced in v2.48.0. The announcement provides SHA-256 checksums for all distribution formats (64-bit, ARM64, and 32-bit MinGit variants) to aid verification.

This release marks a transition in Git for Windows' architecture support and feature set, with the `git svn` deprecation being the most impactful change for remaining users of that subcommand. The provided checksums will be important for downstream packaging and testing workflows.
