Johannes Schindelin announced Git for Windows 2.49.0-rc0, a Windows-specific distribution incorporating upstream Git v2.49.0-rc0. The release includes several notable changes: deprecating `git svn` due to maintenance burden, discontinuing 32-bit installers (except MinGit), promoting the `--full-name-hash` option to stable status, adding a new `git backfill` command, fixing a symlink regression, and updating dependencies. The release also provides SHA-256 checksums for verification across different package formats.

Git maintainer Junio Hamano acknowledged the announcement with a brief "Thanks," maintaining the project's tradition of polite recognition for these regular Windows release updates. The thread confirms this as a routine part of the Git for Windows release cycle, where Windows-specific maintenance decisions are made alongside upstream version tracking.
