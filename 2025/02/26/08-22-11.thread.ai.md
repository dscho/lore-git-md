Build system patch series (v3 1/13) improving Meson build support, focusing on path handling consistency with Makefile builds when runtime prefix is enabled. Core issue addresses GIT_EXEC_PATH behavior divergence between build systems - Meson currently uses absolute paths unconditionally while Makefile uses relative paths when runtime_prefix is enabled, causing binary location issues. Fix modifies meson.build to condition GIT_EXEC_PATH on runtime_prefix setting: relative path (libexecdir/git-core) when enabled, absolute path (prefix/libexecdir/git-core) when disabled. Change affects both build configuration and libgit_c_args compilation flags. This foundational patch establishes correct path handling for subsequent Meson build improvements in the series. Technical scope limited to build system internals, specifically meson.build configuration and related compilation flags. No open questions or unresolved issues noted in this appears to be a straightforward alignment with existing Makefile behavior.
