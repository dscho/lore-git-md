This is the third version of Patrick Steinhardt's Meson build system refactoring series, consisting of 13 patches that clean up and improve various aspects of Git's Meson build infrastructure. The series has already gone through two rounds of review with positive feedback from Justin Tobler and Toon Claes.

The v3 iteration includes two main fixes:
1. Resolved linker arguments for aliased executables on Windows with MSVC (a regression from v2's common-main restructuring)
2. Fixed a variable naming collision where `git` was being overwritten (now using `git_builtin`)

The series continues to focus on architectural simplifications and Windows-specific improvements, including:
- Better PATH handling and sane_tool_path behavior
- Static library consolidation (removing libgit_version.a)
- Common-main restructuring
- Curl dependency management
- Windows CI optimization (limiting parallel linking to work around memory constraints)

The changes appear well-tested, with Patrick running an extra pipeline to verify the new version works on 'next'. Given the thorough review process and the minor nature of the v3 changes, this series looks ready for maintainer consideration. The patches demonstrate careful attention to build system details while maintaining compatibility across platforms.
