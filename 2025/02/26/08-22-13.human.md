Refactoring patch in Patrick Steinhardt's Meson build system series. This is patch 3/13 in the v3 submission, which has already undergone extensive review and is now in its final iteration.

The change simplifies the Meson build configuration by inlining the static 'git' library declaration directly into its dependency declaration. Previously, the library was first declared separately and then referenced, which could lead to confusion about its usage since it was only meant to be consumed via the dependency. The new approach makes the intended usage pattern clearer by eliminating the intermediate variable.

This is part of a broader effort to streamline Git's Meson build system architecture, with this particular change focusing on making the code more straightforward and removing unnecessary indirection. The patch follows the same pattern as earlier versions of the series that were already reviewed and approved, with Toon Claes having previously validated similar architectural simplifications.

The change is well-contained (affecting only meson.build) and maintains all the same functionality while improving code clarity. Given the series has already addressed all reviewer feedback through multiple iterations, this patch appears ready for inclusion as part of the complete series.
