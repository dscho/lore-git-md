This is a build system patch in Patrick Steinhardt's ongoing Meson refactoring series (v3, patch 12/13). It focuses on documentation tool path resolution in the Meson build system.

The patch ensures consistent use of custom program paths when finding documentation tools like asciidoc, asciidoctor, xmlto, and xsltproc. This is particularly important for Windows builds where the custom path points to Git for Windows locations. The change makes the build more reliable by ensuring these tools can be found in the expected locations.

The patch also removes redundant `required: true` arguments since they're the default behavior in Meson. This is a small but sensible cleanup that aligns with the series' goal of simplifying the build configuration.

This appears to be a straightforward improvement that builds on previous work in the series to standardize tool path handling. The change is focused and well-contained, touching only documentation-related build configuration. It follows the pattern established in earlier patches of the series to make the build system more robust, particularly for Windows environments.
