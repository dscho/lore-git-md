This is a refactoring patch in Patrick Steinhardt's Meson build system series (v3 11/13). It addresses a variable naming collision where the `git` variable was being overwritten in multiple contexts - first to store the external Git executable path, then to store the built Git executable, and again in the documentation build for the external Git executable. 

The patch renames the built Git executable variable to `git_builtin` to avoid this collision, eliminating the need to repeatedly resolve the external Git executable path. This change affects both the main meson.build file (where the executable is declared) and the documentation build configuration. The modification is straightforward - it simply changes the variable name in three places while maintaining all existing functionality.

This follows the series' pattern of build system simplification and optimization, though it's a smaller change compared to some of the more substantial architectural improvements in earlier patches. The change appears clean and well-contained, touching only the necessary parts of the build configuration without introducing any new complexity.
