Refactoring patch in Patrick Steinhardt's Meson build system series (v3 3/13). This change simplifies the intermediate `libgit.a` static library handling by inlining its declaration directly into the dependency definition rather than using a separate variable. The patch eliminates the `libgit_library` variable and moves the static library definition into the `declare_dependency()` call that was already its only consumer.

The change clarifies the library's usage pattern (it exists solely to be part of this dependency) and removes potential confusion from having an intermediate variable that isn't meant to be used directly. The actual build behavior remains identical - same sources, compiler flags, dependencies, and include directories are used, just organized more directly. This continues the series' theme of architectural simplification in the Meson build system.

The patch is part of the core architectural changes in the first half of the series (patches 1-7/13) and follows the earlier removal of `libgit_version.a` in patch 1/13. Reviewer Toon Claes had previously approved similar simplifications in this series.
