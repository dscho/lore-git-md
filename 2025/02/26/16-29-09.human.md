CI/build system follow-up regarding Windows Meson build failures.

Patrick Steinhardt responds to Junio Hamano's concern about why CI didn't catch the Windows linker regression earlier. He clarifies that the CI jobs did actually fail, but the failures weren't properly reported due to a bug in the CI setup itself. This explains why the issue wasn't caught before the problematic commit was merged.

Steinhardt mentions he'll be sending a patch series tomorrow to fix this CI reporting issue. This is a separate but related problem to the original Windows linker flags issue - while the build system fix addresses the technical regression, this follow-up will ensure such failures are properly visible in the future.

The exchange highlights how CI infrastructure issues can sometimes mask real problems, and the need to maintain both the build system and the testing infrastructure that verifies it. This comes as part of the broader Meson build system integration effort where multiple platform-specific issues are being uncovered and addressed.
