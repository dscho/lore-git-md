This is a build system fix addressing a discrepancy between Makefile and Meson builds when runtime prefix is enabled. 

Patrick Steinhardt fixes an issue where Git's Meson build system incorrectly handles the GIT_EXEC_PATH when runtime prefix is enabled. The problem occurs because Meson always uses an absolute path for GIT_EXEC_PATH, while it should be relative when runtime prefix is enabled (matching the Makefile behavior). This could prevent Git from finding its binaries when installed with runtime prefix.

The patch is part of a larger series (v3, 01/13) improving Meson build support. The change is straightforward - it moves the GIT_EXEC_PATH definition to be conditional on the runtime_prefix setting, making it relative when needed. The fix appears well-contained and properly motivated, addressing a real inconsistency between build systems.

This affects users building Git with Meson who enable runtime prefix support, particularly those who need to relocate installed Git binaries. The change brings Meson behavior in line with the established Makefile behavior.
