Test modernization patch in the `git fsck` packed-refs validation series.

This is the first patch in v7 series that implements comprehensive validation for packed-refs files. The patch focuses on improving test reliability by wrapping test cases in subshells to ensure working directory changes don't leak between tests. The change affects `t/t0602-reffiles-fsck.sh`, converting all test blocks to use subshells for directory changes.

Key technical details:
- Wraps all test blocks in `( cd repo && ... )` subshells
- Maintains same test assertions and coverage
- Preserves all existing test cases for ref validation (bad refnames, content checks, symref handling)
- Keeps worktree-related tests intact but now in subshells
- No functional changes to the actual ref validation logic

The patch is part of a larger effort to strengthen `git fsck`'s of packed-refs files, but this specific change is purely about test hygiene. It addresses a potential issue where failing tests could leave the working directory in an unexpected state, which could affect subsequent tests. The change is mechanical but important for test reliability.

The patch follows the series' overall approach of thorough validation while maintaining backwards compatibility. It's a straightforward improvement that makes the test suite more robust without introducing any new behavior or complexity to the actual ref validation code.
