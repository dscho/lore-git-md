This is the final version (v3) of a 4-patch series converting Git's oid-related unit tests to the Clar framework, part of the test modernization effort. The series has been through several iterations with all substantive feedback addressed, and now includes a trivial cleanup of an unused variable in the `cl_parse_oid()` helper function as the only change from v2.

The conversion covers test suites for three key data structures (oid-array, oidmap, and oidtree) plus their shared oid helper functions. Each follows a consistent pattern: renaming test files (t-*.c → u-*.c), restructuring tests into discrete functions, sharing global test data, and integrating with both Makefile and meson build systems. The implementation preserves all test coverage while adopting Clar's assertion style (a mix of `cl_assert` and `cl_failf`).

With all technical questions resolved and mentors Patrick Steinhardt and Phillip Wood having signed off, this v3 submission appears ready for merging. The changes are cleanly focused, maintaining test quality while advancing Git's testing standardization goals. The series demonstrates a solid pattern for future Clar conversions.
