This is the second patch in a completed 4-part series converting Git's object ID test suites to the Clar framework. The patch focuses on modernizing the oid-array tests, which verify operations on arrays of object IDs (hashes).

The conversion replaces custom test assertions with Clar's built-in assertions, removes redundant test descriptions, and reorganizes test data into global variables for reuse across test functions. Key changes include introducing a `test_oid_array__initialize()` function to handle hash algorithm setup and splitting the tests into discrete functions (like `test_oid_array__lookup()` and `test_oid_array__enumerate_unique()`) rather than using macros.

The patch follows established patterns from earlier Clar conversions, maintaining all test coverage while making the code more maintainable. Build system files (Makefile and meson.build) are updated to reflect the filename change from t-oid-array.c to u-oid-array.c. The implementation looks clean and consistent with the series' goal of standardizing test infrastructure.

Since this is part of a finalized series where all technical concerns were addressed in previous iterations, the patch appears ready for integration. The changes are focused and well-contained, showing good attention to both the technical conversion and code organization aspects of test modernization.
