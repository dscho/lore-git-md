This is a performance optimization patch for the bundle-uri functionality. Scott Chacon identifies that when downloading bundles, Git only copies references from refs/heads/ into the refs/bundle/ namespace, which leads to suboptimal object negotiation during subsequent fetches. The patch proposes copying all references from refs/ (not just heads) to improve this.

The commit message provides compelling benchmarks showing the impact: in a test with the GitLab repository, the current behavior downloads 32% of total objects during the fetch phase, while the patched version reduces this to just 1%. The change is minimal - a one-line modification to the refspec matching in bundle-uri.c.

The author acknowledges they're unsure if there are downsides to this change, but presents it as a clear improvement to the negotiation efficiency. The patch appears well-motivated with concrete performance data, though it raises questions about whether there was an intentional reason for the original limitation that only copied head references. The change seems straightforward but may warrant discussion about potential side effects of having more references in the bundle namespace.
