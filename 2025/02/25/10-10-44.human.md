Final patch in a test modernization series converting oidtree tests to Clar framework. This is the last of a 4-patch set (v3) that standardizes oid-related test suites (oid-array, oidmap, and now oidtree) by moving them from custom test code to the Clar unit testing framework.

The patch follows the established pattern from previous conversions in the series:
- Renames the test file from `t-oidtree.c` to `u-oidtree.c`
- Adds proper initialization/cleanup handlers (`test_oidtree__initialize` and `test_oidtree__cleanup`)
- Converts test assertions to Clar's `cl_*` variants
- Makes test failures fail-fast for easier debugging
- Updates both Makefile and meson.build build systems

The conversion maintains all existing test coverage while improving maintainability through the framework's standardized patterns. The series has gone through multiple rounds of review with all feedback addressed, and this final patch completes the effort with no outstanding issues. The changes are straightforward and well-contained, following the same high-quality approach seen in the earlier patches.
