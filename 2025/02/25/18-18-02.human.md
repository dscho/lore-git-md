Documentation patch clarifying submodule merge behavior, now in its third revision with maintainer approval. This patch adds clear explanations to the merge strategies documentation about how Git handles submodule conflicts: when one submodule commit is a descendant of another (attempting a fast-forward) and when there are merge commits containing both conflicting submodule commits (suggesting a resolution while leaving it unmerged). The v3 revision improves formatting and removes redundant content while maintaining technical accuracy.
