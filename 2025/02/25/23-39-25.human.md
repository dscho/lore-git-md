This is the final patch in the `git-diff-pairs` series, adding explicit flush control to the new plumbing command. The patch enables more flexible pipeline usage by allowing explicit flushing of the diff queue with a NUL byte between input batches, rather than waiting for stdin to close. Each flushed batch is separated by a NUL byte in the output.

The implementation adds a new control flow path that detects NUL bytes in the input stream, triggering an immediate flush of the queued diffs. This maintains the command's strict NUL-delimited format while giving callers more control over output timing. The change includes documentation updates and a new test case verifying the flush behavior works as expected with multiple batches.

This completes the series' design goals by adding the last piece of pipeline control, following through on earlier architectural decisions about input/output formats and error handling. The patch appears well-integrated with the refactored diff queue infrastructure from earlier in the series, and maintains the same level of test coverage seen in previous patches. With this addition, the `git-diff-pairs` command now offers both the batch processing capability and the pipeline flexibility needed for efficient use in scripts and other Git commands.
