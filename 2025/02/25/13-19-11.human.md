This is the final version (v6) of a bugfix series enhancing `git fsck`'s validation of packed-refs files, now incorporating all reviewer feedback. The series has been through multiple rounds of review and is ready for merging.

The patch series adds comprehensive validation checks for packed-refs files, including filetype verification, syntax checking, NUL character detection, header format validation, and sortedness verification. The v6 iteration includes minor refinements like improved comments, better error message quoting, and an expanded commit message explaining the tightened header format rules.

Key improvements in this version:
- A new patch (4/9) explicitly checks for the correct header format with trailing space
- Error messages now properly format filenames with quotes
- The worktree handling code has clearer documentation about its refdb consistency assumptions
- The changes maintain compatibility with older Git versions while enforcing stricter validation where possible

The series has been thoroughly reviewed by Patrick Steinhardt, Karthik Nayak, and others, with all feedback addressed. It represents a production-ready implementation that closes a security gap while maintaining compatibility across Git implementations.
