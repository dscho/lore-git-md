This is the final version (v3) of a 4-patch series converting oid-related unit tests to the Clar framework, completing the test modernization effort. The series has gone through previous rounds of review with all substantive issues resolved, and this version only includes the trivial cleanup of removing an unused 'ret' variable in the cl_parse_oid() helper function as requested in previous feedback.

The series standardizes testing for Git's object ID handling data structures (oid-array, oidmap, and oidtree) by migrating them from custom test code to the Clar framework. Key technical aspects include file renaming (t-*.c → u-*.c), test case restructuring into discrete functions, global test data sharing patterns, and build system integration. The conversion maintains all existing test coverage while adopting Clar's conventions.

The implementation establishes several patterns for future test conversions, including a mixed assertion style (using both cl_assert and cl_failf) and preserves the test quality while improving maintainability. The series builds on existing unit-test infrastructure and follows the established t-hash → u-hash conversion pattern.

With all technical questions resolved in previous versions and this final cleanup applied, the series appears ready for merging as part of Git's broader test modernization efforts. The changes are consistent across all converted test suites and maintain the project's testing standards.
