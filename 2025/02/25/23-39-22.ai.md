This is a feature patch series introducing a new `git-diff-pairs(1)` plumbing command for batch blob diff generation, building on prior work by Peff. The series has undergone multiple iterations with design refinements based on feedback from Junio Hamano and Karthik Nayak.

The command enables efficient batch processing of blob diffs by accepting NUL-delimited raw diff format input (with full OIDs required) and producing patch output by default. Key design decisions solidified in this version include explicit rejection of tree objects (with future expansion possible via a planned `-r` option), mandatory `-z` mode for input/output, and frontend responsibility for complex operations like rename detection.

The implementation now includes comprehensive test coverage for various diff output formats and input processing scenarios, along with documentation rebased on current doc/.adoc standards. Notable changes since v2 include stricter input validation (rejecting pathspecs and tree objects), output format defaults better matching intended use cases, and improved batch processing control via explicit NUL-byte flushing.

The series is structured with preparatory refactoring in patch 1, core command implementation in patch 2, and flush control improvements in patch 3. All prior feedback has been addressed, leaving only minor documentation details (tree rejection messaging, output sync verification) for final review. The implementation appears thorough, with clear attention to pipeline safety and future extensibility considerations.
