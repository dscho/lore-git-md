This is a documentation refinement for the signed commits feature in git fast-export/import. Elijah Newren suggests two improvements to Christian Couder's v5 patch series that adds signed commit support:

1. The documentation for `--signed-commits` should explicitly state that the default behavior is 'abort' (currently this is only implied by the backward compatibility note about older versions defaulting to 'strip').

2. There's a typo in the code comments ("rathar" should be "rather") in the new `find_commit_multiline_header()` function.

The patch series is otherwise complete and production-ready, having addressed all major concerns from reviewers. These are minor polish suggestions for the final version. The thread shows this feature has gone through extensive review, with Junio Hamano already giving final approval.
