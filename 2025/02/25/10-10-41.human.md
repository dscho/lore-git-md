Test modernization: First patch in a completed 4-part series converting oid-related tests to the Clar framework.

This initial patch adapts two key helper functions (`get_oid_arbitrary_hex()` and `init_hash_algo()`) from the old test infrastructure to work with Clar. The functions are renamed with a `cl_` prefix (`cl_parse_any_oid` and `cl_setup_hash_algo`) and modified to use Clar's assertion system. The changes include:

1. Replacing custom test assertions with Clar's `cl_assert` macros
2. Simplifying error handling since Clar handles test failures internally
3. Updating build systems (Makefile and meson) to properly include the shared oid helpers

The patch is part of a larger effort to standardize Git's test infrastructure by moving from custom test code to the Clar framework. As noted in the thread summary, this series has gone through multiple rounds of review and is now in its final form, ready for merging. The changes in this first patch establish the foundation that subsequent patches will build upon when converting the actual test suites for oid-array, oidmap, and oidtree.
