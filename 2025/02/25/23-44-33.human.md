This is a bug report about inconsistent handling of backspace (`\b`) escape sequences in Git's configuration system. Yaakov Smith reports that while `git fetch` renders the backspace character as a question mark when it appears in a remote URL, `git config --list` outputs the raw escape sequence, which can be misleading output (as demonstrated by a config value that appears to change from "true" to "false" when backspaces are processed by the terminal).

The issue appears in Git 2.34.1 and affects how configuration values are displayed versus how they're interpreted. The report suggests this might be a security-adjacent concern since the raw output could be used to mask actual values. No patch is proposed - this is purely an observation of inconsistent behavior that the author believes should be addressed. The email includes full system information for reproducibility.
