This is a bugfix patch in the final stages of review for the `git fsck` packed-refs validation series. The specific patch focuses on tightening the header format check for packed-refs files to require a trailing space after "# pack-refs with:".

The author (shejialuo) responds to Patrick Steinhardt's review feedback, agreeing to split out the header format change into a separate commit. Patrick had raised concerns about compatibility but confirmed through research that major Git implementations (libgit2, JGit, gitoxide) all expect and write this trailing space, with only go-git being an exception as it doesn't write headers at all.

This represents a minor but important refinement to the series' validation logic, ensuring consistent parsing while maintaining ecosystem compatibility. The patch is well-vetted at this point, with the author promptly addressing the last remaining suggestion about commit organization.
