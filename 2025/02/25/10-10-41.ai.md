This is the first patch in a completed 4-part series converting oid-related unit tests to the Clar framework. The patch focuses on adapting core oid helper functions from the old test infrastructure to work with Clar.

The patch converts two key functions from the lib-oid.{c,h} files: `get_oid_arbitrary_hex()` becomes `cl_parse_any_oid()` and `init_hash_algo()` becomes `cl_setup_hash_algo()`. The new versions use Clar's assertion system (`cl_assert`) rather than the old test framework's `check()` calls. The functions maintain the same core functionality for parsing hex strings into object IDs and handling hash algorithm selection, but now follow Clar's conventions including the `cl_` prefix.

Build system changes ensure the lib-oid.c file is properly included in the Clar test builds while being removed from the old unit test builds. The implementation drops some redundant error messaging that Clar handles through its assertion system, making the code more concise while maintaining the same validation guarantees.

This foundational change enables subsequent patches in the series to convert the actual test suites (oid-array, oidmap, oidtree) to use Clar while relying on these shared helper functions. The conversion follows established patterns from prior test modernization efforts, using consistent `cl_` prefix for Clar-specific helpers and maintaining compatibility with both Makefile and meson build systems.
