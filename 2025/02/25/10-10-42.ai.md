This is the second patch in a completed 4-part series converting oid-related test suites to the Clar framework. The patch focuses on migrating the oid-array test suite from custom test code to Clar-based tests.

Key technical changes include:
- Renames test file from t-oid-array.c to u-oid-array.c following Clar convention
- Replaces custom test assertions with Clar's cl_assert/cl_failf
- Moves test input arrays to global scope for reuse across test functions
- Introduces test_oid_array__initialize() for explicit hash algorithm setup
- Converts TEST macros to direct function calls without descriptions
- Splits test cases into discrete functions (test_oid_array__enumerate_unique, test_oid_array__lookup, etc.)
- Updates both Makefile and meson.build build systems
- Maintains all existing test coverage while modernizing the implementation

The conversion follows patterns established in earlier Clar test migrations:
- Uses cl_parse_any_oid() helper instead of get_oid_arbitrary_hex()
- Leverages cl_setup_hash_algo() for initialization
- Organizes tests into focused functions with clear names
- Preserves all test cases from original implementation
- Handles both Makefile and meson build systems

This patch builds on the foundation established in patch 1/4 (lib-oid conversion) and follows the same high-quality approach seen throughout the series. The implementation is clean and consistent with the project's test modernization goals.
