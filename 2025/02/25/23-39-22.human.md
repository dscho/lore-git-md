This is a feature patch series introducing a new plumbing command `git-diff-pairs(1)` for batch blob diff generation, building on previous work by Peff. The series has gone through multiple iterations with feedback incorporated from Junio C Hamano and Karthik Nayak.

The new command enables efficient batch processing of blob diffs by accepting NUL-delimited raw diff format as input, allowing diff generation to be split across multiple processes. This is particularly useful for server-side operations where large diffs might otherwise time out. The implementation now explicitly rejects tree objects (a change from earlier versions) and requires NUL-delimited input/output.

Key changes in v3 include:
- Required `-z` option for NUL-delimited I/O
- Explicit rejection of tree objects (with future compatibility in mind)
- Default patch output instead of raw output
- Improved NUL-byte handling for explicit diff queue flushes
- Documentation rebased on current standards
- Pathspec support removed (planned for future)

The series is well-documented with comprehensive test coverage and appears ready for final review, addressing all previous feedback except for some minor documentation details around tree rejection messages and output synchronization. The implementation looks solid, with clear separation of frontend/backend responsibilities and careful consideration of pipeline safety.
