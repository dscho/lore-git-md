This is a bugfix series addressing zlib inflation issues in Git's object handling. Jeff King (Peff) presents 10 patches that fix two specific bugs while cleaning up related code. The main fixes are in patches 4 and 5: one prevents an infinite loop when processing broken zlib input (though the trigger conditions are obscure), and another handles a case where specially crafted packs could crash Git via a BUG() (limited to crashing the pusher's own process). The remaining patches modernize and clarify the surrounding zlib handling code, particularly around error conditions and cleanup.

The series touches core object reading code in object-file.c and git-zlib.c, adding new test coverage in t1006-cat-file.sh. While the security implications appear limited, the fixes address real edge cases in object parsing that could affect repository integrity. The cleanups look like straightforward improvements to code that handles the delicate zlib inflation process.
