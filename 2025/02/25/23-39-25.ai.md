This is the final patch in the `git-diff-pairs` series, adding explicit flush control to the new plumbing command. The patch enables more flexible pipeline usage by allowing explicit flushing of the diff queue with NUL bytes between input batches, rather than only flushing at stdin closure. 

The implementation adds a new control flow path that detects NUL bytes in the input stream, triggering an immediate flush of the queued diffs and outputting a NUL byte to delimit batches. The diff queue infrastructure is modified to temporarily disable automatic freeing (`no_free=1`) during processing, ensuring proper resource management. The patch includes comprehensive documentation updates and a new test case verifying the flush behavior works correctly with multiple batches.

This completes all planned functionality for the `git-diff-pairs` command, which now provides:
- Batch processing of raw diff input with NUL-delimited format
- Explicit flush control via NUL bytes
- Proper resource management during pipeline operation
- Comprehensive test coverage
- Documentation matching current standards
