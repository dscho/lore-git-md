Test modernization: This is the third patch in a completed 4-part series converting oid-related test suites to the Clar framework. It focuses on the oidmap tests, following the same pattern established in previous conversions.

The patch replaces the custom test infrastructure with Clar assertions and helper functions. Key changes include moving from a setup-wrapper approach to discrete test functions (`test_oidmap__replace`, `test_oidmap__get`, etc.), using `cl_parse_any_oid()` for hash initialization, and implementing proper initialization/cleanup handlers. The test now fails fast on first error rather than continuing through all cases.

Build system integration is updated in both Makefile and meson.build to reflect the renamed test (t-oidmap.c → u-oidmap.c). The conversion maintains all existing test coverage while adopting the project's preferred unit testing patterns. This work was mentored by Patrick Steinhardt and represents the final iteration (v3) of the series, with all prior feedback addressed.
