This is a documentation refinement in the ongoing Git 3.0 breaking changes effort, specifically addressing the deprecation of legacy "branches/" and "remotes/" directories. Junio Hamano submits a small but important clarification to the BreakingChanges.txt documentation, incorporating Jakub Wilk's observation about the distinction between directory presence versus actual usage.

The patch changes the wording from stating these directories "are not to be found in modern repositories" to "are unlikely to be used in modern repositories," acknowledging that while the directories may exist (having been part of default templates until recently), they are probably empty and unused. This maintains the deprecation message while being more technically accurate about real-world repository states.

The change is straightforward and uncontroversial, already carrying Patrick Steinhardt's Ack and Jakub Wilk's Reported-by tag. It represents the final polishing of documentation for this aspect of Git 3.0's breaking changes, following earlier implementation work on the actual deprecation mechanisms. The patch demonstrates the project's attention to precise wording when communicating potentially disruptive changes to users.
