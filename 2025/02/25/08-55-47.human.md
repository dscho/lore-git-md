This is the first patch in a 16-part performance optimization series for Git's refs subsystem, now in its third iteration. The patch introduces a new function `repo_get_oid_with_flags()` that extends the existing `repo_get_oid()` by adding a flags parameter to pass through to the lower-level `get_oid_with_context()` function. 

The change is straightforward - it serves as plumbing for later optimizations in the series, particularly around refname availability checks. The patch maintains the same behavior as the original function when no flags are passed, and adds the new function to the public API with appropriate documentation. 

As the first patch in a larger series, this is primarily groundwork - the commit message notes this will be used in subsequent commits. The implementation looks clean and focused, with minimal changes needed to both the implementation and header files. This appears to be a well-scoped preparatory change for the more substantial performance optimizations that follow in the series.
