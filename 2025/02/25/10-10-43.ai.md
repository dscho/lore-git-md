This is the third patch in a completed 4-part series converting oid-related unit tests to the Clar framework, focusing on the oidmap test suite. The conversion follows the established pattern from previous patches in the series, maintaining all test coverage while modernizing the implementation.

The patch transforms the oidmap test from a custom test-lib implementation to Clar's framework, with several key changes: the test file is renamed from t-oidmap.c to u-oidmap.c, test cases are split into discrete functions (replace, get, remove, iterate), and initialization/cleanup is handled via Clar's `_initialize`/`_cleanup` hooks. The implementation uses Clar assertions (`cl_assert`, `cl_failf`) throughout and leverages the series' shared `cl_parse_any_oid()` helper for consistent OID parsing.

Notable technical details include moving the oidmap instance to global scope, converting the iteration test to fail fast on first error rather than collecting multiple failures, and removing the custom test harness in favor of Clar's built-in test runner. The patch updates both Makefile and meson.build to reflect the conversion. This follows the same high-quality approach seen in the rest of the series, with thorough test coverage maintained through the conversion.
