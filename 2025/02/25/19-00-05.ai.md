Maintenance patch addressing test cleanup ordering in zlib inflation series.

This is a brief follow-up discussion about test cleanup ordering in Jeff King's zlib inflation series (specifically patch 04/10). Patrick Steinhardt had suggested reversing the order of `mv` and `test_when_finished` operations in a test case to match current Git test conventions. Eric Sunshine argues the existing order is actually preferable in this case since the cleanup only makes sense if the `mv` succeeds. He notes that reversing them would require additional error handling (`||:`) to prevent the cleanup itself from failing unnecessarily.

The exchange highlights an ongoing attention to detail in the test infrastructure portion of this series, though the core zlib inflation changes remain unchanged. This is a minor style discussion that doesn't affect the substantive changes to object parsing safety in the main patch series. The thread continues to maintain its focus on hardening Git's zlib handling while following good testing practices.
