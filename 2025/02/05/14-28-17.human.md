Test fix addressing exit code masking in merge-rename-directories tests. This is a follow-up patch in an already-reviewed thread, now incorporating maintainer feedback.

Ayush Chandekar submits version 2 of a patch that fixes three test cases (12i, 12j, 12k) in t6423-merge-rename-directories.sh where Git's exit code was being suppressed. The original version piped `git ls-files` output directly to `uniq`, which could mask test failures. The new version properly captures the intermediate output in a file first.

The changes are straightforward - each test now uses `git ls-files >actual && uniq actual >tracked` instead of the direct pipe. This matches the maintainer-approved approach discussed in the thread, though Junio Hamano noted two optional stylistic tweaks (commit message precision and `uniq` argument style) that could still be made.

This is purely a test reliability improvement with no behavior changes to Git itself. The patch has already received positive reviews and is considered merge-ready, making it a low-risk contribution that improves the suite's ability to catch failures. The thread shows this was part of a GSOC project, with the author responding well to feedback throughout the review process.
