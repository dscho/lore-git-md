Feature patch introducing `--revision` option to `git clone`, completing a well-reviewed series now ready for merging. This final patch adds the user-facing functionality that allows cloning a specific ref or commit hash without creating remote-tracking branches, detaching HEAD at the requested revision.

The implementation is thorough, with careful handling of edge cases and clear documentation. Key behaviors:
- Works with any ref (not just branches/tags) and commit hashes
- Explicitly incompatible with `--branch` and `--mirror` options
- Designed for CI workflows where minimal clones of specific revisions are useful
- Includes comprehensive tests covering branch/tag/commit cases, error conditions, and interactions with other options

The patch builds on extensive preparatory refactoring (detailed in the thread summary) that improved `builtin/clone.c`'s structure while maintaining all existing behavior.
