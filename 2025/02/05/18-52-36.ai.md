Feature implementation extending Git's agent capability with OS information, completing the v4 series.

This final patch in the v4 series implements the OS version advertisement in Git's protocol by extending the existing `agent` capability string rather than adding a new capability. The format becomes "package/version os" (e.g., "git/1.8.3.1 Linux"), with the OS name obtained from `uname(2)`. A new `transfer.advertiseOSInfo` config option (defaulting to true) allows privacy-sensitive users to disable OS reporting.

Key technical details:
- Adds OS name sanitization via new `test_redact_non_printables()` helper in test-lib-functions.sh
- Implements platform-specific handling for Windows where `uname(1)` and `uname(2)` outputs differ
- Introduces new `os_info_sanitized()` and `advertise_os_info()` functions in version.c
- Updates protocol documentation in gitprotocol-v2.txt and transfer.txt
- Modifies test suites (t5555-http-smart-common.sh, t5701-git-serve.sh) to handle OS-aware agent strings while maintaining Windows compatibility

The implementation follows Junio Hamano's direction to extend the agent string rather than introduce a new capability, with Christian Couder mentoring the refinements. The v4 series has focused on code quality improvements including this patch's standardized string sanitization and modular helper functions.
