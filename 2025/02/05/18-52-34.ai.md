This is part of the ongoing OS version capability series (v4 patch 4/6), refining the implementation that was merged in v3. The patch extends the recently extracted `get_uname_info()` helper function toggling between full OS details and just the OS name via a new `full` parameter. This prepares for future use cases that may need only the OS name while maintaining the existing bugreport functionality that requires full details.

The change modifies three files: updating the bugreport caller to explicitly request full details, adding the parameter to the function declaration in version.h, and implementing the conditional output in version.c. The implementation cleanly separates the two output formats while maintaining the same error handling. The commit message notes this may need further refactoring if future configuration options are added for OS version formatting.

This continues the series' trend of modular improvements, building on v4's earlier extraction of `uname` handling into a reusable helper. The change is straightforward but meaningful - it enables selective information disclosure from system calls while maintaining backward compatibility with existing callers. The patch follows the established pattern of using strbuf` for output and maintains the same error reporting behavior.
