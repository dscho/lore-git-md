This is a refactoring patch in the `--revision` clone option series, introducing a `struct clone_opts` to encapsulate clone-related state that was previously stored in global variables. The patch focuses on moving the `wants_head` logic into this new struct, which tracks whether we should fetch the remote HEAD (disabled when both `--single-branch` and `--branch` are specified).

The changes include:
1. Defining `struct clone_opts` with an initial `wants_head` field (defaulting to true)
2. Modifying `wanted_peer_refs()` to take the opts struct and use it for HEAD handling
3. Moving the `tail_link_ref()` helper from remote.c to remote.h for wider access
4. Updating the clone command to set `opts.wants_head = 0` when appropriate

This is part of a larger effort to clean up `builtin/clone.c` by moving global state into properly scoped structures. The patch maintains all existing behavior while improving code organization - the `wants_head` field will be used more extensively in subsequent patches. The change to make `tail_link_ref()` public is a minor but necessary side effect to support the refactoring.
