This is version 2 of the patch, following previous discussion about naming alternatives like `--grep-in-patch` and `--pickaxe-grep`. The patch comprehensively updates all relevant documentation, error messages, and tests across multiple files (diff.c, diff.h, various docs, and test scripts) to support both old and new option names. Tests are modified to use the long options where it improves readability, while maintaining coverage of both forms. The implementation appears technically sound, preserving all existing behavior while adding the new interface options.

Documentation changes carefully maintain the relationship between the new long options and existing pickaxe`-related flags like `--pickaxe-regex`. The changes touch core diff functionality but don't alter the underlying behavior - this is purely a user interface improvement.
