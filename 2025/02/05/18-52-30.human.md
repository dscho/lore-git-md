Feature implementation for OS version reporting in Git's agent capability.

This is the fourth version of Usman Akinyemi's Outreachy project to add operating system information to Git's protocol capabilities. The series has evolved from introducing a separate `os-version` capability (v3) to now extending the existing `agent` capability to include OS information (v4), following mailing list discussions.

The implementation adds OS name reporting in the format "git/version OS" (e.g., "git/2.47.1 Linux") via the existing agent capability, with a new `transfer.advertiseOSVersion` config option (default true) to address privacy concerns. The series includes preparatory refactoring of version-handling code, platform-specific handling (notably Windows), and test coverage.

The thread shows ongoing debate between Junio Hamano (favoring agent string integration for simplicity) and Christian Couder (preferring separate capability for parsing clarity). This version aligns with Junio's preference while maintaining implementation flexibility. The technical work appears complete and well-tested, with the main remaining questions being about documentation approach and the philosophical balance between structured data and privacy.
