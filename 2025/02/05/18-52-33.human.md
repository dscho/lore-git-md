This is a refactoring patch in the ongoing OS version capability series. It extracts the `uname()` system call handling from `builtin/bugreport.c` into a new reusable `get_uname_info()` function in `version.c`, preparing for its use in the protocol capability implementation.

The change is straightforward - it moves the existing uname handling code into a new function with proper error handling and documentation. The implementation maintains the same behavior while making the functionality available to other parts of Git. Christian Couder mentored this change, which is part of the v4 post-merge refinements to improve code organization.

This patch demonstrates good practice by:
1. Keeping the same functionality while improving structure
2. Adding clear documentation for the new function
3. Using existing Git infrastructure (strbuf, gettext)
4. Following the project's style in error handling

The change is low-risk since it doesn't modify behavior, just reorganizes code in preparation for the OS version feature's needs. It's one of several small improvements being made after the main feature was merged.
