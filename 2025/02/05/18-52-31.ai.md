Refactoring patch in the OS version capability series. This is the first of six patches in v4 of the series, which has since been merged after design review.

The change replaces manual ASCII range checks for non-printable characters in `git_user_agent_sanitized()` with the standard `isprint()` function for clearer intent. The original check handled ASCII values below 32 (control characters) and above 127 (non-ASCII), which `isprint()` covers, but the patch adds an explicit space character check since spaces were previously caught by the <=32 condition.

This is a straightforward code quality improvement that maintains the same behavior while using more readable standard library functions. The change is small (3 lines modified) and focused on the version.c file's string sanitization logic. The patch carries Christian Couder's mentorship tag, indicating it was likely reviewed during development.

This appears to be a preparatory cleanup before the main OS version capability changes in subsequent patches. The use of `sane-ctype.h` (Git's wrapper for ctype.h) ensures consistent behavior across platforms, which is particularly relevant given the series' cross-platform nature.
