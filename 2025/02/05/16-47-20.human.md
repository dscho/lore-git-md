This is a refactoring patch in the `--revision` clone option series, specifically part 5 of 7. The patch introduces a new `struct clone_opts` to encapsulate clone-related state that was previously stored in global variables, with the first field being `wants_head` to track whether we need the remote HEAD reference.

The change moves us toward better encapsulation in `builtin/clone.c` by:
1. Adding the new struct with an initial field for HEAD tracking
2. Modifying `wanted_peer_refs()` to use this struct instead of directly checking globals
3. Making `tail_link_ref()` public in remote.h since it's now needed by clone.c
4. Simplifying the logic for when we want HEAD (only when not doing `--single-branch` with `--branch`)

This is a clean, focused refactoring that improves the code structure while maintaining all existing behavior. The patch fits well with the series' overall goal of cleaning up clone.c's internals while adding the new `--revision` feature. The changes are straightforward and well-contained, with clear motivation explained in the commit message.
