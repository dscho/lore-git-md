This is the final version of a feature series introducing `--revision` to `git clone`, now ready for merging after extensive review. The series has evolved through six versions with refinements to both implementation and documentation, culminating in a robust solution for cloning specific revisions without remote-tracking branches.

The core functionality enables cloning a repository with HEAD detached at a specified commit or tag, particularly useful for CI workflows. Key technical components include a new `detach` flag in `clone_opts`, modified `update_head()` using `lookup_commit_or_die()`, and refactored remote-tracking refspec handling. The implementation includes comprehensive test coverage in `t5621-clone-revision.sh`.

Version 6 brings final polish: documentation rewrites for `--[no-]tags` interaction, removal of an unneeded conditional in `builtin/replay.c`, and a typo fix in `builtin/clone.c`. The series demonstrates good engineering practices with preparatory refactoring commits that improved `builtin/clone.c` maintainability before adding the new feature. All substantive feedback from reviewers (including Patrick Steinhardt and Jean-Noël Avila) has been addressed, with final safety verification confirming the hardening against invalid tree hash inputs.
