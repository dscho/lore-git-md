Refactoring patch in the `--revision` clone feature series. This is the first of seven patches that prepares the codebase for the new `--revision` option by cleaning up global variables in `builtin/clone.c`.

The patch moves 195 lines of variable declarations and option parsing from global scope into `cmd_clone()`, where they are actually used. This includes:
- The `builtin_clone_options` struct and related option variables
- Various clone configuration flags and string options
- Initialization of string lists for submodule handling

This is purely a code organization change with no behavior modifications. The changes make the code more maintainable by reducing global state and better scoping variables to their actual usage context. The patch has already gone through multiple review cycles and is part of a well-vetted series that's now awaiting final merge.

The refactoring serves as important groundwork for the subsequent patches that will implement the actual `--revision` functionality. By cleaning up the variable scoping first, the feature implementation can focus on its core logic rather than fighting with global state.
