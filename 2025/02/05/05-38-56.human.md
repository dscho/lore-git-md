This is a documentation patch adding missing manpage entries for SSL-related configuration options. 

Andrew Carter notices that while `http.sslCertType` and `http.sslKeyType` were added in commit 0a01d41ee4 (March 2023), they were never properly documented. The patch fills this gap by adding clear explanations of these options to `Documentation/config/http.txt`.

The documentation explains which certificate types ("PEM", "DER", "P12") are supported across different SSL backends (openssl, gnutls, schannel, securetransport), notes special cases like PKCS#11 token support, and mentions the corresponding environment variables that can override these settings. The technical details appear accurate and match the underlying libcurl options they wrap (`CURLOPT_SSLCERTTYPE` and `CURLOPT_SSLKEYTYPE`).

This is a straightforward and well-executed documentation update that will help users properly configure Git with different certificate types. The patch is focused, technically precise, and clearly fills a real documentation gap.
