This is a refactoring patch in the ongoing OS version capability series, now in its fourth iteration. It modifies the recently extracted `get_uname_info()` helper to optionally show only the OS name rather than full system details, preparing for future use in the agent string formatting. The change is straightforward - adding a `full` flag parameter that toggles between detailed and minimal output modes.

The patch maintains the function's existing behavior for bugreport (which still gets full details) while enabling the upcoming agent string use case to request just the OS name. The implementation is clean with minimal churn - just adding the flag and conditional formatting while preserving error handling. 

This continues the series' trend of incremental improvements, now focusing on making the uname helper more flexible for different use cases.
