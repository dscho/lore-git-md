Final patch in the OS version capability series. This implements the agreed-upon approach of extending Git's existing `agent` capability string to include OS information (e.g., "git/1.8.3.1 Linux") rather than adding a separate capability. The patch adds a new `transfer.advertiseOSInfo` config option (defaulting to true) to address privacy concerns, allowing users to disable OS reporting if desired.

The implementation handles platform differences, particularly on Windows where `uname(1)` and `uname(2)` outputs differ significantly. Testing on Windows is disabled for simplicity since the behavior would just be testing Git's own fake implementation. The patch includes comprehensive documentation updates and test coverage, with special handling for non-printable characters in OS strings.

This completes the v4 series which has seen significant refinement from earlier versions, including better code organization (extracting helpers like `get_uname_info()`), improved test isolation, and use of standard library functions. The implementation maintains backward compatibility while providing useful debugging information for server operators.
