Feature implementation for OS name in agent capability, completing the series after design discussions.

This cover letter presents the final implementation of Usman Akinyemi's Outreachy project to include OS information in Git's protocol capabilities. The series has evolved from Christian Couder's original proposal through several iterations, now settling on extending the existing `agent` capability string rather than introducing a separate `os-version` capability as initially proposed.

The implementation adds OS name (from `uname(2)`) to the agent string in "package/version os" format (e.g., "git/1.8.3.1 Linux"), with privacy controls via a new `transfer.advertiseOSVersion` config option defaulting to true. The series includes preparatory refactoring of version.c utilities, test coverage, and documentation updates. Notable platform-specific handling includes Windows where `uname` output differs between CLI and syscall.

Key technical components:
- New `get_uname_info()` helper in version.c with redaction of non-printable chars
- Protocol documentation updates in gitprotocol-v2.txt
- Test coverage in t5701-git-serve.sh with careful setup isolation
- Config option documented in transfer.txt

The series resolves the architectural debate by implementing Junio Hamano's preferred approach of extending the agent string rather than Christian Couder's original separate-capability design, while maintaining the option to disable OS reporting for privacy. The implementation preserves backward compatibility and handles edge cases like Windows platform differences.
