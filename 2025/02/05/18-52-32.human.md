This is a refactoring patch in the OS version capability series, specifically extracting sanitization logic for reuse. 

The patch takes the non-printable character sanitization code from `git_user_agent_sanitized()` and moves it into a new `redact_non_printables()` helper function. This prepares for reusing the same sanitization logic in upcoming patches of the series. The refactoring is clean and maintains the existing behavior while making the code more modular.

Key changes include:
1. Extracting the character redaction logic into a dedicated function with clear documentation
2. Switching to `strbuf_detach()` for cleaner memory management
3. Using the standard `isprint()` function (a v4 improvement over earlier ASCII range checks)

The change is straightforward and well-contained, touching only version.c. As part of the now-merged OS version capability work, this refactoring helps keep the codebase clean while enabling future reuse of the sanitization logic. The patch follows good practices with a clear commit message and mentor attribution.
