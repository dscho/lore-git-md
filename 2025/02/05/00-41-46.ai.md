Finalized implementation of extensible missing object reporting for `git rev-list`. This first patch of the v4 series introduces the `--missing=print-info` option that extends the existing `--missing=print` functionality to include path information for missing objects, following the standardized output format established in the thread discussion.

The patch adds:
- A new `MA_PRINT_INFO` enum value and corresponding `print-info` option
- Path tracking via `oidmap` and `missing_objects_map_entry` structure
- Standardized output format: `?<oid> path=<quoted-path>` using Git's existing `quote_path()` with `QUOTE_PATH_QUOTE_SP` flag
- Comprehensive tests in `t6022-rev-list-missing.sh` covering:
  - Basic path reporting
  - Special character handling (spaces, quotes)
  - Various object types (tree, blob)

The implementation strictly follows the plumbing conventions agreed upon in the thread, with all configuration-related changes removed per consensus. Path quoting matches Git's standard behavior for plumbing commands, ensuring proper handling of spaces and special characters while avoiding any `core.quotePath` dependencies.

This represents the core functionality of the series, with the second patch (not shown here) expected to add type information following the same pattern. The thread has reached full technical consensus on the approach, making this version likely ready for final review.
