Refactoring patch in the OS version capability series, focusing on code quality improvements.

This is the second patch in v4 of Usman Akinyemi's series implementing OS version reporting in Git's protocol. The patch extracts character sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` helper function, making the code more modular and reusable for future needs in the series. The refactoring maintains identical behavior while improving structure - it still replaces non-printable ASCII characters and spaces with dots, but now does so through a dedicated function.

Key technical changes:
1. New static `redact_non_printables()` function encapsulates the character sanitization logic
2. Switches from direct buffer access to using `strbuf_detach()` for cleaner memory management
3. Uses standard `isprint()` from sane-ctype.h (a v4 improvement over v3's manual ASCII checks)
4. Preserves all existing functionality while making the code more maintainable

The patch follows Christian Couder's mentorship and represents part of the post-merge code quality improvements mentioned in the thread summary. It prepares for subsequent patches that will reuse this sanitization logic while handling OS version strings. The changes are focused and well-contained to version.c, with no behavior modifications beyond the internal refactoring.
