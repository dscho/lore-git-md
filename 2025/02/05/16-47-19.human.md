This is a refactoring patch in the final stages of the `--revision` clone option work. The patch simplifies tag handling in `git clone` by moving the tags refspec addition earlier in the process, eliminating duplicate code paths.

The key change moves the `TAG_REFSPEC` addition to happen right after remote setup, before processing ref prefixes, rather than handling tags separately in `wanted_peer_refs()`. This makes the code flow more straightforward by unifying the tag fetching logic with the regular refspec processing. The patch also fixes a minor inconsistency where `option_tags` wasn't being cleared for `--mirror` clones (which already handle all refs including tags).
