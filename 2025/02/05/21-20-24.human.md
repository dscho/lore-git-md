This is a documentation patch adding missing information about the `http.uploadarchive` config option.

Piotr Szlazak notes that while HTTP archive support was added in Git 2.44.0, the documentation for `git-http-backend` didn't explain how to enable it. The patch adds a brief but clear description of the `http.uploadarchive` option, noting that it controls archive access over HTTP/HTTPS (disabled by default) and only works with protocol v2.

The change is straightforward - just 4 lines added to `git-http-backend.txt` alongside similar options like `http.receivepack`. This fills a clear documentation gap for a relatively new feature, and the commit message provides good context about why the addition is needed. The patch appears well-targeted and uncontroversial.
