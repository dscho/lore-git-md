Thread documents the addition of `http.uploadarchive` configuration option to git-http-backend.txt, completing documentation for HTTP archive support introduced in Git 2.44.0. The option enables 'git archive' client operations over HTTP/HTTPS when set to true (defaulting to false) and requires protocol version 2. Original patch from Piotr Szlazak adds 4 lines of documentation following the style of adjacent HTTP config options like `http.receivepack`.
