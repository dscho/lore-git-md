[PATCH] Documentation: add missing http.uploadarchive config

Thread documents the addition of `http.uploadarchive` configuration option to git-http-backend.txt, filling a gap for HTTP archive support introduced in Git 2.44.0. The option enables 'git archive' client operations over HTTP/HTTPS when set to true, defaults to false, and requires protocol version 2. Patch adds 4 lines of documentation following the style of adjacent HTTP config options like `http.receivepack`. No technical objections or review feedback yet; appears ready for inclusion as a straightforward documentation improvement.
