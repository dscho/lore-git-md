Test improvement patch in the OS version capability series (v4 5/6).

This patch refactors the test setup in t5701-git-serve.sh to remove a dependency between tests. Previously, the "test capability advertisement" test created files that were used by subsequent tests, creating a side-effect coupling. The change splits this into a dedicated setup test that generates the expected content files (`agent_capability`, `expect.base`, and `expect.trailer`) which can then be reused by multiple tests.

Key technical details:
- Moves file generation into new `setup to generate files with expected content` test
- Uses `printf` to create `agent_capability` file with Git version
- Maintains same test content in `expect.base` and `expect.trailer` but now sources from `agent_capability`
- Keeps all existing test assertions in the capability advertisement test
- Part of v4 series refining the OS version capability implementation
- Follows test isolation best practices by removing implicit dependencies

The change prepares for future test additions while maintaining the same verification of protocol v2 capability advertisement. This is a straightforward test refactoring that improves maintainability without changing test behavior.
