This thread documents the `http.uploadarchive` configuration option, which enables `git archive` operations over HTTP/HTTPS when using protocol v2. The option was introduced in Git 2.44.0 but wasn't properly documented until now. The patch adds clear documentation to git-http-backend.txt, noting that the feature is disabled by default and only works with protocol v2. The change is minimal (just 4 lines added) and follows the style of adjacent documentation for similar HTTP-related options like `http.receivepack`. This fills an important documentation hole for functionality that's been available in Git since version 2.44.0.
