This introduces a new dimension to the discussion that wasn't present in previous iterations - the potential API design tradeoff between logical organization and encapsulation opportunities. The thread had previously reached consensus on the technical soundness of the relocation, but this new point suggests there may be deeper architectural considerations about which functions should be public API versus implementation details.
