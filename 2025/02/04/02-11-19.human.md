Platform compatibility fix for a long-dormant contrib script. This is a follow-up to Brian Carlson's patch that replaced a bash-specific `echo -e` with POSIX-compliant `printf` in the Thunderbird patch processing script. D. Ben Knoble confirms the change looks correct, noting their own experience with POSIX shell compatibility. The discussion highlights how this 9-year-old Debian bug report went unnoticed until now, suggesting the script sees little use. The change is minimal but important for systems using dash as /bin/sh. Knoble's observation about `sed` handling input without final newlines is an interesting technical aside but doesn't affect the validity of the fix.
