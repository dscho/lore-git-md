This is part 4/5 of Meet Soni's refactoring series to centralize refspec-related functions from remote.c to refspec.c, a GSoC project that has already gone through several rounds of review and refinement. The series is now in its final form with all technical and naming conventions settled.

The current patch moves three key refspec matching functions (`refspec_find_match`, `refspec_find_all_matches`, and `refspec_find_negative_match`) from remote.c to refspec.c. This completes the physical relocation of all refspec logic to its dedicated module, improving code organization while maintaining exact behavior. The changes are purely mechanical - the functions are copied verbatim to their new location and removed from the old one, with no functional modifications.

This patch follows the naming standardization work done in part 3/5, using the subsystem-prefixed names that were agreed upon during review. The implementation is straightforward and appears correct, with all necessary header declarations properly updated in refspec.h.
