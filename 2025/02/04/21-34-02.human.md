This is a refactoring patch in a series introducing a new `--revision` option for `git clone`. The patch simplifies the `wanted_peer_refs()` function in builtin/clone.c, which maps server refs to local refs during cloning.

The main change consolidates the code paths for single-branch and regular cloning by having the single-branch case modify the refs list before falling through to the common processing logic. This eliminates duplicate code and reduces nesting depth. The patch also fixes a type safety issue by changing a loop counter from `int` to `size_t` to match the refspec count type.

The refactoring appears well-considered, maintaining all existing functionality while making the code more maintainable. It's part of a larger effort that has gone through multiple rounds of review, with this particular change addressing feedback from Patrick Steinhardt in previous versions.
