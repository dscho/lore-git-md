This is a refactoring patch in a series introducing a new `--revision` option for `git clone`. It's the fifth of seven patches in v5 of the series.

The patch introduces a new `struct clone_opts` to consolidate clone-related state that's currently stored in global variables. The first field added is `wants_head`, which tracks whether the clone operation should care about the remote's HEAD ref. This is particularly relevant when both `--single-branch` and `--branch` are specified, where we don't need the remote's HEAD.

The changes include:
1. Defining the new struct with initialization macro
2. Modifying `wanted_peer_refs()` to take the struct and use its `wants_head` field
3. Moving `tail_link_ref()` from remote.c to remote.h to make it available to clone.c
4. Updating the clone command to initialize and use the new struct
