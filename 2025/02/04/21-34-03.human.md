This is a refactoring patch in a series introducing a `--revision` option for `git clone`. It simplifies tag refspec handling by moving the tags refspec earlier in the clone process.

The patch modifies how tags are handled during cloning by adding the tags refspec to the remote's fetch refspecs upfront, rather than processing them separately later. This eliminates some redundant code paths and makes the logic more straightforward. The change also properly handles the `--mirror` case by setting `option_tags` to 0 when mirroring, since mirrors already include all refs by definition.

The refactoring appears well-considered, building on previous feedback in the thread. It reduces code by 16 lines while maintaining the same behavior, and includes clear comments explaining the changes. This is part of the broader preparatory work for the new `--revision` feature, helping to clean up and simplify the clone internals before the main feature is introduced in patch 7/7.
