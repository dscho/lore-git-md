Platform compatibility fix for Thunderbird patch script.

Junio C Hamano acknowledges and accepts brian m. carlson's patch that replaces a bash-specific `echo -e` with POSIX-compliant `printf` in the `contrib/thunderbird-patch-inline/appp.sh` script. This change, originally reported as a Debian bug in 2014, ensures the script works correctly on systems using dash as `/bin/sh`. The patch is straightforward - a one-line change that modifies how Cc and Signed-off-by headers are processed when generating reply emails.

The maintainer notes the script appears to be in minimal use given the long-standing unfixed bug, and none of the original authors are active anymore. This represents the first update to this contrib script in over 9 years. While the change is simple, it demonstrates Git's attention to portability details even in less-frequently used components. The patch will be queued for inclusion.
