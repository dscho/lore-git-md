Platform compatibility fix for Thunderbird patch script.

Junio C Hamano acknowledges and accepts brian m. carlson's patch that replaces a bashism (`echo -e`) with POSIX-compliant `printf` in the `contrib/thunderbird-patch-inline/appp.sh` script. The change addresses a 9-year-old Debian bug (#772238) that prevented the script from working properly on systems using dash as /bin/sh. The patch specifically modifies how Cc and Signed-off-by headers are processed when generating reply emails.

The maintainer notes the script appears to see little usage given how long the bug went unfixed, and observes that none of the original authors are still involved in the project. The technical change itself is straightforward - replacing one line that concatenated variables with `echo -e` with a `printf` call that does the same thing in a portable way.

This email represents the initial acceptance of the fix into Git's codebase, though the thread indicates there will be a follow-up v2 patch to address additional edge cases around `sed` behavior with missing newlines. The change is part of ongoing maintenance for this long-dormant contrib script, with attention to making it work correctly across different shell implementations.
