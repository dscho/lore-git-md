This is a platform compatibility patch fixing a shell script portability issue in a Thunderbird integration helper script from Git's contrib directory.

Brian Carlson fixes a long-standing Debian bug report from 2014 where the `thunderbird-patch-inline` helper script was using the non-POSIX `echo -e` syntax. The script would fail on systems using `dash` as `/bin/sh` (like Debian/Ubuntu) since dash only supports the `-n` option for echo. The solution replaces `echo -e` with the more portable `printf`, which properly handles escape sequences across all POSIX shells.

The patch is straightforward - a one-line change that replaces the problematic echo command with an equivalent printf statement while maintaining identical functionality. The commit message notes this script appears to be lightly used, given the bug went unfixed for nearly a decade, and the author didn't CC previous contributors since none have been active recently.

This is a clean, low-risk change that improves portability without introducing new complexity. While the impact is limited to users of this specific Thunderbird integration script, it's a good example of fixing long-tail compatibility issues in Git's contrib area.
