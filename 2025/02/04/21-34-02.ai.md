This is a refactoring patch in a 7-part series introducing a `--revision` option for `git clone`. The patch focuses on simplifying the `wanted_peer_refs()` function in `builtin/clone.c`, which maps server refs to local clone refs.

The key changes in this version (v5) address Patrick Steinhardt's feedback from previous iterations. The refactoring eliminates a separate code path for `option_single_branch` by having it modify the `refs` list before falling through to the common processing path. This reduces code duplication and nesting while maintaining the same behavior. The patch also fixes type safety by changing a loop counter from `int` to `size_t` to match `refspec->nr`.

The changes include:
- Consolidation of single-branch handling into the main flow
- Introduction of `to_free` pointer for better resource management
- Simplified tag refspec handling with added explanatory comment
- Removal of redundant warning message (now handled elsewhere)
- Type-safe loop counter update

This is one of several preparatory refactorings in the series that clean up the clone internals before introducing the new `--revision` feature. The changes are focused and well-contained, with the commit message clearly explaining the motivation and approach.
