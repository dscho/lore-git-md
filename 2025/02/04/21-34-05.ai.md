This is a preparatory patch in the `git clone --revision` series, introducing a helper function for option validation. 

The patch adds `die_for_incompatible_opt2()` to complement existing functions that handle 3 or 4 incompatible options. The new helper provides a consistent way to error out when two mutually exclusive options are specified. The implementation reuses the existing `die_for_incompatible_opt4()` infrastructure, passing zeros for the unused option slots.

The change is demonstrated by converting an existing manual error check in `builtin/replay.c` to use the new helper for the `--onto`/`--advance` option conflict. This serves as both an example of intended usage and a test case for the new function.

This addition was specifically requested by Junio C. Hamano in earlier review feedback to separate the option validation utility from the main feature implementation. The patch follows the established pattern of the existing validation functions while keeping the implementation minimal. It's part of the broader effort to clean up and standardize option handling in preparation for the final `--revision` feature implementation.
