Refactoring patch in preparation for new `--revision` clone feature.

This is the first of seven patches introducing a new `--revision` option to `git clone`. It focuses on cleaning up the codebase by moving the `builtin_clone_options` struct and related variables from global to local scope within `cmd_clone()`. The change is substantial (195 lines modified) but mechanical - it moves and reinitializes variables while maintaining all existing functionality.

The patch demonstrates good hygiene by:
1. Clearly separating the refactoring from the actual feature work
2. Including initialization of moved variables to avoid undefined behavior
3. Adding proper cleanup for string lists that were previously leaked
4. Keeping the diff focused on scope changes without altering behavior

This groundwork will make the subsequent feature patches cleaner and easier to review. The changes have already been through several rounds of review in previous versions of the series.
