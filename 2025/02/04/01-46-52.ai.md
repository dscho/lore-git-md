This is a platform compatibility patch fixing a bashism in a contrib script. The change replaces a non-portable `echo -e` with POSIX-compliant `printf` in the `thunderbird-patch-inline/appp.sh` script, which handles email patches in Thunderbird. The issue was originally reported in a 2014 Debian bug but remained unfixed, suggesting the script sees limited use.

The patch is straightforward - a one-line change that modifies how Cc and Signed-off-by headers are processed when generating reply emails. The author notes the script hasn't been touched in 9 years and none of the original authors are active, so they didn't CC anyone. While minor, this makes the script work properly on systems using dash as /bin/sh.

Key technical details for future reference: The script processes patch emails by extracting commit messages (`$CMT_MSG`), headers (`$HEADERS`), and diffs (`$DIFF`). The changed line concatenates these to extract CC and signoff recipients. The fix ensures this works across all POSIX shells by using `printf '%s\n%s'` instead of the non-standard `echo -e`.
