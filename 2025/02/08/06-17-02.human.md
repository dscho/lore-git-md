This is a bugfix patch addressing a memory management issue in the revision walking code. Emily M Klassen reports and fixes a segfault that occurs when using `git log` with `--no-graph` combined with output formats like `--patch`, `--name-status`, or `--name-only`. The problem stems from the code failing to clear the `output_prefix` and `output_prefix_data` pointers when `--no-graph` is specified, leading to use-after-free scenarios.

The fix is straightforward - it adds the missing NULL assignments to properly clean up these pointers when graph output is disabled. The patch is small (just 2 lines) and clearly targets a real issue, though it might be worth noting that the commit message doesn't include any test coverage for this case. The author mentions this follows up on an earlier report, suggesting the problem has been verified in practice.
