Documentation follow-up to standardize commit message terminology. This is a quick reply from M Hickford acknowledging Junio C Hamano's suggestion to extend the terminology standardization work to `git-rebase.txt`. The original patch (already accepted) changed "subject" to "title" in `git-commit.txt` documentation, and this exchange identifies `git-rebase.txt` as needing similar updates, particularly in interactive rebase contexts. The author indicates they will prepare a v2 patch to address this, continuing the straightforward documentation cleanup with no functional impact. The change maintains consistency with how `git-log` and `git-shortlog` already refer to commit message first lines.
