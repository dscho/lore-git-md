This is a refactoring patch in Phillip Wood's series improving `git merge-tree --stdin` handling. It changes the merge configuration initialization in `builtin/merge-tree.c` from `init_ui_merge_config()` to `init_basic_merge_config()`, aligning with the command's plumbing status.

The change follows a previous commit (9c93ba4d0ae) that split merge configuration initialization between plumbing and porcelain commands. While this currently has no behavioral impact since the merge-ort backend ignores `diff.algorithm`, it future-proofs the code against potential changes to `init_ui_merge_config()` that might affect plumbing commands.

The patch is minimal (a single line change) and well-justified, maintaining consistency with Git's plumbing/porcelain distinction. It builds on the thread's theme of cleaning up merge-tree's implementation while keeping behavior stable. The change is straightforward and unlikely to be controversial, fitting naturally with the series' other error-handling and documentation improvements.
