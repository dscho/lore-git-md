This is part 2/6 of a platform compatibility series addressing `-Wsign-comparison` warnings in `apply.c`. The patch focuses on converting specific variables from `int` to more appropriate unsigned types (`size_t` or `unsigned int`) where they are used for array indexing, length/size calculations, or receive values from system functions returning `size_t`.

Key changes in this patch:
- Converts `len` variables used with `strlen()` and string operations to `size_t`
- Changes `preimage_limit` parameter in `line_by_line_fuzzy_match()` from `int` to `size_t`
- Updates line number variables (`backwards_lno`, `forwards_lno`, `current_lno`) in `find_pos()` to `size_t` while preserving negative value handling
- Modifies `ctx` in `update_pre_post_images()` to `size_t` for consistency
- Adjusts filename length calculations in `patch_stats()` to use `size_t`

The changes follow the series' established strategy of: (1) using `size_t` for pointer differences and array indexing, (2) `unsigned int` for counters, and (3) maintaining careful bounds checking. This patch builds on the architectural decisions established in earlier versions while incorporating review feedback about type consistency. The modifications are focused and well-contained, with each change motivated by specific compiler sign-comparison warnings.
