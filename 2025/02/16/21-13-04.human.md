This is a feature proposal to add commit summary formatting to `git blame`, allowing custom output formats similar to `git log --format`. The patch comes from Aleks Todorov, who is reviving an earlier discussion about this functionality.

The current implementation demonstrates a working prototype that adds a new `-F/--format` option to `git blame`, reusing Git's existing commit formatting infrastructure. The example shows it successfully displaying commit hashes, filenames, author names, and dates in a custom format string. However, the author notes this is just a "barebones" version and raises important design questions about implementation approach.

Key considerations in the proposal:
1. Whether to refactor `git log`'s formatting code for reuse (preferred by the author but potentially messy)
2. Need for input sanitization to prevent invalid format specifiers
3. Challenges around width alignment of blame output fields

The patch shows promise but appears to be in early stages - it lacks tests, documentation, and a clear resolution of the architectural questions raised. The author is seeking feedback on the approach before proceeding further. This could be a useful feature for blame output customization, but the implementation path needs careful consideration to avoid code duplication or maintenance headaches.
