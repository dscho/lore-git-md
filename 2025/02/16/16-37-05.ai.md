Bugfix for `git merge-tree --stdin` deadlock issue.

This patch addresses a deadlock that occurs when a process tries to read `git merge-tree --stdin` output before closing merge-tree's stdin. The root cause is that merge-tree wasn't flushing stdout between merge operations while processing stdin input, which could block scripts trying to process the output incrementally. The fix adds a `maybe_flush_or_die(stdout, "stdout")` call after each merge operation in the stdin processing loop.

The patch includes performance measurements showing the flush has negligible impact - benchmark results are statistically identical with and without flushing. The change touches only `builtin/merge-tree.c`, adding the flush call and including the necessary "write-or-die.h" header. This appears to be a straightforward fix for a clear bug, with no obvious downsides.
