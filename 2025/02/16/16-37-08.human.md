Documentation patch improving `git merge-tree --stdin` usage details, part of a series addressing stdin-mode fixes and cleanup. This patch focuses specifically on clarifying the documentation.

He also removes incorrect documentation about negative status codes - the command actually dies before printing in error cases, so that case doesn't need to be documented as output behavior. The changes are straightforward and align with the series' goal of making the stdin mode's behavior more precise and better documented.

This is the fourth patch in a five-part series that has already addressed deadlock fixes, code cleanup, and configuration handling.
