Platform compatibility patch addressing `-Wsign-comparison` warnings in `apply.c`. This is patch 3/6 in Zejun Zhao's series to improve type safety in Git's patch application code.

The change focuses on `git_hdr_len`, an `int` variable that can hold negative values (used for error signaling) but is compared against a `size_t` length. The patch adds a typecast to `git_hdr_len` after confirming it's non-negative, eliminating the compiler warning while maintaining the existing behavior. The negative value check remains in place before the comparison, preserving the error handling path.

This continues the series' pattern of carefully converting signed/unsigned comparisons while respecting the code's existing logic. The change is minimal (just 2 lines modified) and follows the established approach from earlier patches. Review feedback from v1/v2 appears to have been incorporated, as this version cleanly handles both the type safety and error cases.
