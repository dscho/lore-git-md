This is a documentation maintenance discussion about the ongoing `.txt` to `.adoc` format transition for Git's documentation files. Junio Hamano responds to Christian Couder's earlier message about the broken release notes links on git-scm.com, confirming the format change as the root cause.

Hamano notes that while the release notes (`.txt` files) were never actually written in AsciiDoc format, keeping them as an exception would create long-term maintenance headaches. He references his earlier warning about the need for ecosystem tools to adapt during the transition period in the `next` branch, suggesting the git-scm.com maintainers may not have been monitoring these changes closely enough.

The email reinforces that the format transition is the right direction despite this temporary breakage, as it unifies documentation formats and prepares for potential future improvements to release note formatting. Hamano's tone suggests this is more about coordinating the transition than debating the fundamental approach - the solution lies with git-scm.com updating their link generation logic rather than reverting Git's documentation changes.
