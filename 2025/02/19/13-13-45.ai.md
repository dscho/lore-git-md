This is a bugfix patch in Patrick Steinhardt's series adding Meson build system support for Git's contrib components, specifically addressing compilation warnings in the macOS credential helper.

The patch fixes a compilation warning in the "osxkeychain" credential helper by properly validating command-line arguments. The original code only checked if argv[1] was NULL, which could trigger compiler warnings about unused argc parameter. The new version explicitly checks both that at least 2 arguments were provided (argc < 2) and that the first argument is non-NULL, while maintaining the same functionality.

This change follows the pattern seen earlier in the series for other credential helpers (like the libsecret fixes mentioned in the thread summary), where compilation warnings are being systematically addressed across different platforms. The fix is minimal and focused, changing just one line in the osxkeychain helper's main function.

The patch maintains compatibility with the credential helper protocol while making the code more robust against compiler warnings. This is part of the broader effort to ensure all contrib components build cleanly across different build systems (Makefile, CMake, Meson) and platforms (Windows, macOS, Linux).
