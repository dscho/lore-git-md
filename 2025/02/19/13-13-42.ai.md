This is a bugfix patch in Patrick Steinhardt's series adding Meson build system support for Git's contrib components, specifically addressing test failures in the netrc credential helper.

The patch fixes two issues with the netrc credential helper tests that prevent them from working with out-of-tree builds, which is particularly relevant for Meson integration. First, it updates the test script to use the new GIT_SOURCE_DIR variable (introduced in this series) to locate the test.pl script in the source directory rather than assuming it's in the build directory. Second, it adds a new CREDENTIAL_NETRC_PATH environment variable to properly locate the built git-credential-netrc helper when the build directory differs from the source directory.

The changes are minimal but important for cross-build-system compatibility, affecting both the shell wrapper (t-git-credential-netrc.sh) and the Perl test script (test.pl). This continues the series' theme of standardizing build paths across different build systems, with the credential helper tests being one of the components that needed adjustment for proper Meson support. The patch maintains backward compatibility while enabling the new build system integration.
