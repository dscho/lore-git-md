This is a bugfix patch in Patrick Steinhardt's series adding Meson build system compatibility for Git's contrib components. It addresses a compilation warning in the macOS credential helper.

The patch fixes a warning about an unused `argc` parameter in the osxkeychain credential helper by properly validating command-line arguments. Instead of just checking if `argv[1]` exists, it now also verifies that at least two arguments were provided (`argc < 2`). This maintains the same functionality while silencing the compiler warning.

This is part of a larger effort to make Git's contrib tools build cleanly across different build systems (Makefile, CMake, Meson) and platforms. The change is straightforward and appears to be a minor but necessary fix to keep the code warning-free. The patch follows the pattern seen elsewhere in the series of addressing platform-specific build issues.
