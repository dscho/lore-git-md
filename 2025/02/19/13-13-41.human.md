Build system refactoring to standardize source directory handling. This is the first patch in Patrick Steinhardt's v2 series adding Meson support for Git's contrib components.

The patch introduces a new `GIT_SOURCE_DIR` variable in `GIT-BUILD-OPTIONS` to provide a standardized way for tests to locate files relative to the project's source directory. This replaces several ad-hoc variables (`GIT_TEST_MERGE_TOOLS_DIR`, `GIT_TEST_POPATH`) that were previously used for specific test cases. The change is implemented consistently across Makefile, CMake and Meson build systems.

The motivation is to stop the proliferation of specialized variables for source directory access, making the test infrastructure more maintainable. The patch shows careful attention to cross-build-system compatibility, with identical changes made to all three build system implementations. Two test scripts are updated to use the new variable.

This appears to be a straightforward and well-justified cleanup that will make future test additions simpler. As the first patch in the series, it sets up infrastructure that will likely be used by subsequent patches for the contrib components.
