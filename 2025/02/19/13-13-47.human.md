CI / build system patch adding Meson support for git-contacts.

This patch from Patrick Steinhardt extends the ongoing Meson build system integration to include the git-contacts contrib script. It's part of a larger series (v2 7/10) standardizing build support across Makefile, CMake and Meson systems.

The changes:
1. Adds a new meson.build file for git-contacts that handles:
   - Installation of the Perl script to libexec/git-core
   - Man page generation when docs are enabled
   - HTML documentation generation
2. Updates meson_options.txt to include 'contacts' as a build option alongside existing contrib choices like 'completion' and 'subtree'

The implementation follows patterns established earlier in the series for other contrib components, using Meson's custom_target for build steps and maintaining consistent installation paths. The patch appears straightforward and well-integrated with the existing build infrastructure work.

This continues the series' goal of comprehensive Meson support for Git's contrib components, though like other patches in the series, it's primarily build system plumbing rather than user-facing functionality. The changes are focused and appear technically sound based on the established patterns in the thread.
