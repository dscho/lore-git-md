This is a build system patch series adding Meson support for various Git contrib components, now in its second iteration. Patrick Steinhardt continues the work to unify build systems across Git's infrastructure, focusing here on credential helpers (wincred/libsecret/osxkeychain/netrc), the git-contacts script, and Coccinelle integration.

The series has been simplified from v1 by removing the gitk-related changes, which are now being handled separately through Johannes Sixt's gitk repository. The remaining patches show careful attention to cross-platform compatibility, with fixes for MSVC (from Mirth Hickford) and test environment setup for musl-based systems.

Notable technical aspects include:
- Centralized source directory handling in GIT-BUILD-OPTIONS
- Fixed credential helper tests for out-of-tree builds
- New meson.build files for each component
- CI updates to test the credential helpers

The work appears thorough and well-motivated as part of the broader Meson build system adoption. The coordination with other maintainers (like moving gitk changes to a separate track) shows good awareness of the project's development processes. The series is now focused on components where the build system integration is more straightforward, having deferred the more complex gitk integration.
