Build system refactoring to standardize source directory handling across build systems.

This first patch in Patrick Steinhardt's Meson build system series for contrib components introduces a new `GIT_SOURCE_DIR` variable in `GIT-BUILD-OPTIONS` to provide a standardized way for tests to locate files relative to the project root. The change eliminates several ad-hoc variables (`GIT_TEST_MERGE_TOOLS_DIR`, `GIT_TEST_POPATH`) that previously served similar purposes in different contexts, replacing them with path constructions based on the new canonical source directory variable.

The patch updates all three build systems (Makefile, CMake, Meson) to populate `GIT_SOURCE_DIR` appropriately, then modifies two test scripts (`t/lib-gettext.sh` and `t/t7609-mergetool--lib.sh`) to use the new variable. The implementation is straightforward, using `pwd)` for Makefile, `CMAKE_SOURCE_DIR` for CMake, and `meson.project_source_root()` for Meson.

This foundational change enables future test additions to reference source files without introducing new specialized variables, supporting the series' goal of unified build patterns across build systems. The removal of redundant variables simplifies maintenance while maintaining existing functionality.
