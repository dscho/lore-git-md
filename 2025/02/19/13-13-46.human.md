Build system integration for credential helpers. This patch from Patrick Steinhardt adds Meson build support for Git's credential helpers in contrib/, covering libsecret (Linux), osxkeychain (macOS), wincred (Windows), and netrc (cross-platform). The implementation creates new meson.build files for each helper, ensuring they're built and installed to the git-core directory.

The patch notably includes test wiring for the netrc helper, though the commit message acknowledges that none of the credential helpers currently pass their test suites - this is deferred to future work. The changes also update meson.build and meson_options.txt to properly handle credential helper dependencies, including making Perl a required dependency when the netrc helper is enabled.

This is part of Steinhardt's broader v2 series adding Meson support for contrib components, following earlier platform-specific patches for Windows/MSVC and Linux/libsecret. The credential helper integration appears thorough, with appropriate platform-specific dependencies (like CoreFoundation/Security for macOS) and build configurations. The temporary test suite exclusion is clearly documented rather than silently omitted.
