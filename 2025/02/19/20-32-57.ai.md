This is patch 9/12 in Usman Akinyemi's ongoing `the_repository` removal series, converting the `ls-files` builtin to use repository parameters instead of the global variable. The patch follows the established two-phase pattern seen in previous conversions (verify-tag, verify-commit, send-pack, pack-refs).

The changes focus on removing `USE_THE_REPOSITORY_VARIABLE` and propagating the `repo` parameter through the `ls-files` implementation. Key modifications include:
- Removing the global variable declaration
- Passing `repo` to helper functions `expand_objectsize()` and `show_ru_info()`
- Converting `git_config()` to `repo_config()`
- Updating index operations to use the passed repository
- Maintaining the existing "-h" help behavior when called outside a repository

The patch demonstrates the same careful attention to detail seen in previous conversions, with all repository access properly parameterized. The changes are focused and mechanical, following the established pattern while preserving functionality. This continues the series' systematic progress through Git's builtins, with three more conversions to follow after this one.
