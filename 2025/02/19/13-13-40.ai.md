This is a cover letter for a patch series adding Meson build system support for Git's contrib components, now in its second version. The series focuses on credential helpers (wincred/libsecret/osxkeychain/netrc), git-contacts, and Coccinelle integration, with CI configuration updates.

Key changes in v2:
- gitk-related patches have been removed and submitted separately to the gitk repository
- Retains MSVC compilation fix from Mirth Hickford's earlier work
- Maintains all other credential helper and tool integrations from v1

The technical scope includes:
- Build system unification across credential helpers
- Platform-specific fixes (MSVC via Mirth Hickford's contribution)
- CI pipeline updates for credential helper testing
- Coccinelle integration via new meson.build files
- Source directory propagation in GIT-BUILD-OPTIONS

Notable implementation details:
- 10 patches total (9 from Patrick Steinhardt, 1 from Mirth Hickford)
- 24 files modified
- New meson.build files for each component
- CI configuration changes for musl-based jobs
- Test fixes for out-of-tree builds

The series represents continued progress on the broader Meson integration effort, now focusing on contrib/ components after gitk was split out. It demonstrates working cross-platform builds while revealing some test suite integration challenges that remain to be addressed. The credential helper testing in CI appears to be newly enabled in this series.
