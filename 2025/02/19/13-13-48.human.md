Build system patch adding Coccinelle static analysis support to Meson.

This patch from Patrick Steinhardt's Meson build system series adds support for running Coccinelle semantic patches via Meson. It creates a new `coccicheck` target that can be invoked with `meson compile coccicheck`, generating patches from all the standard Git Coccinelle rules. The implementation dynamically finds source files at runtime using `git ls-files` rather than hardcoding paths, ensuring it analyzes all relevant files regardless of platform-specific build configurations.

The change integrates cleanly with the existing Meson infrastructure, adding a new option to control Coccinelle support and properly handling dependencies between source files and headers. It follows the pattern seen elsewhere in the series of maintaining feature parity between build systems while taking advantage of Meson's capabilities. The patch appears well-constructed with thorough handling of edge cases like excluded third-party code and proper file path resolution.

This completes another piece of the comprehensive Meson build system support being added for Git's contrib components. The implementation looks solid and maintains the series' focus on cross-platform compatibility while adding valuable static analysis capabilities to the Meson build.
