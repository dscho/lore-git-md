Build system integration for git-contacts in Meson.

This patch adds Meson build support for the `git-contacts` contrib script, part of Patrick Steinhardt's series to unify build systems for Git's contrib components. The changes include:

1. A new `contrib/contacts/meson.build` file that handles building and installing:
   - The Perl script itself (installed to libexecdir/git-core)
   - Man page generation (when docs=man is enabled)
   - HTML documentation (when docs=html is enabled)

2. An update to `meson_options.txt` to add 'contacts' as a buildable contrib option alongside existing choices like 'completion' and 'subtree'.

The implementation follows the same pattern seen earlier in the credential helper integrations, using Meson's custom_target for the Perl script and documentation generation. The man page and HTML docs are conditional on the docs configuration, matching Git's existing build behavior.

This continues the series' work of bringing all contrib components under Meson's build system while maintaining feature parity with the Makefile/CMake builds. The patch appears straightforward and consistent with the established patterns in the series, though like other contrib components, it will need corresponding CI/test integration in future work.
