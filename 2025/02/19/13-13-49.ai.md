Build system fix for Meson CI job locale configuration.

This patch corrects two issues in the musl-based Meson CI job configuration that were introduced in a previous commit (84bb5eeace7). First, it updates the job name reference from "linux-musl" to the current "linux-musl-meson" name. Second, it fixes the Meson option name for specifying the UTF-8 test locale from `-DGIT_TEST_UTF8_LOCALE` to the correct `-Dtest_utf8_locale`.

The changes are straightforward and clearly motivated by the original commit's oversight. The patch is part of Patrick Steinhardt's ongoing series to add Meson build system support for Git's contrib components, specifically addressing a CI configuration issue that was revealed during testing. The fix ensures proper locale handling for tests in the musl-based environment, maintaining consistency with the series' broader goal of cross-platform build system support.

- Affects the `linux-musl-meson` CI job configuration
