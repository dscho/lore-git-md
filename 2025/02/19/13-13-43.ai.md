This is a platform compatibility patch in Patrick Steinhardt's Meson build system series, specifically addressing MSVC compilation issues for the wincred credential helper. The patch comes from Mirth Hickford with Patrick's sign-off, fixing a Windows-specific build problem where MSVC doesn't support GCC's `__attribute__` syntax.

The wincred credential helper was failing to compile on Windows because it used a GCC-style `__attribute__((format))` without the MSVC compatibility layer from git-compat-util.h. The fix makes the attribute conditional on `_MSC_VER` being undefined, matching how the rest of Git's codebase handles MSVC compatibility. This is a straightforward one-line change that enables the helper to build properly with Microsoft's compiler while maintaining the format-string checking for other platforms. The patch demonstrates the series' attention to cross-platform compatibility, particularly for Windows builds where Mirth Hickford has been providing expertise. It's a focused technical fix that doesn't affect functionality, just compilation success on MSVC.
