This is the final patch in Patrick Steinhardt's series adding Meson build system support for Git's contrib components, focusing on CI integration for credential helpers. The patch enables testing of credential helpers across different CI platforms by:

1. Adding libsecret development package as a dependency for Linux builds
2. Configuring platform-specific credential helpers in CI:
   - wincred for Windows/MSVC builds (GitHub Actions and GitLab CI)
   - libsecret and netrc for Linux Meson builds
   - osxkeychain for macOS Meson builds
3. Maintaining the existing musl locale configuration fix from earlier in the series

The changes touch CI configuration files (.github/workflows/main.yml, .gitlab-ci.yml) and setup scripts (ci/install-dependencies.sh, ci/lib.sh). This completes the CI integration work for credential helpers that was started in earlier patches, though the thread summary notes that test suite failures for Meson-built credential helpers remain an open issue.

Key technical details:
- New Meson build option `-Dcredential_helpers` with platform-specific values
- Linux now requires libsecret-1-dev package
- Maintains cross-platform consistency with wincred (Windows), libsecret/netrc (Linux), and osxkeychain (macOS)
- Preserves previous musl locale configuration (`-Dtest_utf8_locale=C.UTF-8`)

This patch represents the operationalization of the credential helper build system work across CI environments, though test integration remains incomplete per the thread context.
