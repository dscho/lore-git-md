Build system integration for credential helpers in the Meson transition series. This patch wires up all four credential helpers (libsecret, netrc, osxkeychain, wincred) to build under Meson, completing the credential helper portion of the contrib/ directory migration.

The patch creates new meson.build files for each helper, handling their platform-specific dependencies (GLib/libsecret for GNOME, CoreFoundation/Security for macOS, no deps for wincred). The netrc helper gets special treatment with a custom target for the Perl script and test wiring, though the commit notes the test suite currently fails for all helpers. A new meson_options.txt entry lets users select which credential helpers to build.

Key technical details:
- Adds credential_helpers meson option with libsecret/netrc/osxkeychain/wincred choices
- Makes Perl required when netrc helper is selected (for test execution)
- Installs all helpers to libexecdir/git-core like Makefile does
- Sets up test environment for netrc helper with CREDENTIAL_NETRC_PATH
- Maintains same build patterns seen elsewhere in the series

This continues the series' pattern of comprehensive but incremental Meson adoption, with test integration noted as future work. The patch follows the established approach for contrib/ components while revealing test suite challenges that will need follow-up.
