This is a CI/build system patch fixing locale handling in the musl-based Meson test job. It's part of Patrick Steinhardt's ongoing series to add Meson build system support for Git's contrib components, now in its second version.

The patch corrects two issues introduced in a previous commit (84bb5eeace7) that added UTF-8 locale support for testing in the musl environment: (1) the job was renamed from "linux-musl" to "linux-musl-meson" but the old name was still being referenced, and (2) the wrong option name was used to specify the test locale (-DGIT_TEST_UTF8_LOCALE instead of -Dtest_utf8_locale).

The fix is straightforward - updating both the job name reference and the Meson flag in ci/lib.sh. This maintains consistency with the Meson build system's conventions while ensuring proper locale handling during tests. The patch appears well-contained and properly motivated, addressing a clear oversight in the earlier implementation.
