This is a build system patch adding Coccinelle static analysis support to Git's Meson build infrastructure. It's part of Patrick Steinhardt's ongoing series to integrate Git's contrib components with Meson, now in its second version.

The patch introduces a new `coccicheck` target that can be invoked via `meson compile coccicheck`, generating semantic patches for static analysis. Rather than hardcoding source files, it dynamically discovers them using `git-ls-files` at runtime to ensure platform-specific exclusions (like third-party code) are respected. The implementation handles both C source and headers, concatenates all Coccinelle rules into a single file, and produces a unified patch output.

Key technical details include:
- New `contrib/coccinelle/meson.build` with comprehensive rule processing
- Dynamic source file discovery via `git-ls-files` with exclusions for third-party code
- Support for 18 existing Coccinelle rules (array.cocci, commit.cocci, the_repository.cocci etc.)
- Optional integration controlled by new `coccinelle` meson option
- Patch generation that maintains Meson's out-of-tree build capabilities

The approach mirrors Makefile-based Coccinelle support while adapting to Meson's paradigms. This completes another piece of the Meson build system parity, following earlier patches for credential helpers and git-contacts. The implementation appears thorough, with careful consideration given to cross-platform compatibility and build system consistency.
