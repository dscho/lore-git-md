This is a bugfix patch series addressing an edge case in `git repack`'s `--keep-unreachable` behavior. Patrick Steinhardt fixes an issue where `git repack -ad --keep-unreachable` fails when run in a repository with no existing packfiles. The series includes both the fix and new test coverage for this scenario.

The first patch adds comprehensive tests that would have caught this bug, exercising `--keep-unreachable` under various conditions including the empty-pack case. The second patch modifies the repack logic to properly handle repositories without any preexisting packs when `--keep-unreachable` is specified.

The changes are focused and well-justified, touching only the repack builtin and its test file. The test coverage appears thorough, adding 73 lines of tests to verify both the fixed behavior and related cases. This looks like a solid fix for a real (if somewhat edge-case) bug in object repacking behavior.
