Platform compatibility patch in Patrick Steinhardt's ongoing reftable decoupling series (v3 15/18). This splits Windows-specific POSIX compatibility functions from Git-specific utilities into separate headers, continuing the architectural separation of reftable from Git internals.

The patch reorganizes the mingw.h and msvc.h headers by:
1. Creating new compat-util.h headers for Git-specific Windows utilities (path handling, UTF conversion, SSL wrappers)
2. Renaming the original headers to posix.h for pure compatibility functions
3. Updating all build systems (Makefile, CMake, meson) and includes to reference the new paths

Key technical changes include:
- Mingw's POSIX functions now live in compat/mingw/posix.h
- Git-specific utilities moved to compat/mingw/compat-util.h
- MSVC builds follow the same structure via compat/msvc/ subdirectory
- Build system references updated to point to new locations
- Header guards standardized with COMPAT_*_POSIX_H naming

This maintains all existing functionality while better separating concerns - POSIX compatibility stays in posix.h while Git-specific Windows helpers move to compat-util.h. The change is mechanical with no behavior modifications, keeping with the series' pattern of structural reorganization without functional impact. Build system updates ensure all platforms continue working with the new header locations.
