Initial boilerplate for the new `git backfill` command, part of the PATH WALK series v3. This first patch establishes the basic infrastructure for the new builtin, marking it as experimental to allow for future breaking changes. The patch adds all necessary build system integrations (Makefile, meson.build), documentation stub (git-backfill.txt), and a minimal implementation that currently just outputs "not implemented". The command is classified as "mainporcelain" in command-list.txt and includes the standard RUN_SETUP flag indicating it requires a repository.

Key technical details: The implementation currently consists of an empty command handler in builtin/backfill.c that dies with "not implemented", following the standard pattern for new builtins. The documentation declares the command as experimental upfront and provides a basic synopsis. Build system changes touch all the expected locations for a new builtin (.gitignore, Makefile, meson.build, Documentation/meson.build).

This patch is purely foundational - the actual backfill functionality will be added in subsequent patches. The experimental flag remains as discussed in previous reviews, though this appears to be the only remaining open question from v2 feedback. The patch follows standard patterns for new builtin introduction and appears mechanically sound.
