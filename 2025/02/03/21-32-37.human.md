This is a brief CI infrastructure fix that resolves a regression in the Coverity job. Jeff King noticed that Patrick Steinhardt's recent CI modernization series (which switched from `$distro` to `CI_JOB_IMAGE` for dependency installation) accidentally broke the Coverity job by not properly installing curl. The one-line patch adds the missing `CI_JOB_IMAGE` setting to the Coverity workflow file. 

The fix is straightforward and has already been verified by Jeff to be the only remaining instance of this issue. Patrick acknowledged the oversight and thanked Jeff for the correction, while Junio has now queued the patch. This wraps up a minor but important loose end in the broader CI modernization effort that's currently in the 'next' branch.
