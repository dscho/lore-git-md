Refactoring patch in Patrick Steinhardt's reftable decoupling series (part 15/18). This patch splits Windows compatibility headers into POSIX-specific and Git-specific components, continuing the architectural separation of reftable from Git's infrastructure.

The changes reorganize the mingw.h and msvc.h headers by:
1. Creating new compat-util.h files for Git-specific Windows functionality
2. Renaming the original headers to posix.h for POSIX compatibility layer
3. Updating all build systems (Makefile, CMake, meson) to reference the new paths
4. Adjusting git-compat-util.h includes to point to the new locations

The split maintains all existing functionality while making the POSIX/Git boundary clearer. This is part of the larger effort to make reftable usable outside Git by removing Git-specific dependencies. The patch appears mechanically sound with no behavior changes - it's a straightforward file reorganization that follows the established pattern of the series. Build system updates are thorough and consistent across all supported build methods.
