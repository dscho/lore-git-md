This is the final patch in the v3 series introducing the new `git backfill` command, focusing on sparse-checkout integration. The patch makes `--sparse` mode automatic when sparse-checkout is enabled, while still allowing users to override with `--no-sparse`. This matches likely user expectations - those using sparse-checkout would generally want backfill to respect their sparse patterns by default.

The change includes:
1. Documentation updates clarifying the new default behavior
2. Implementation logic to check `core_apply_sparse_checkout` when no explicit `--[no-]sparse` is given
3. New test cases:
   - Verifying `--sparse` fails gracefully when sparse-checkout isn't enabled
   - Confirming `--no-sparse` can override the default to download all objects

This completes the series' sparse-checkout integration after earlier patches established the basic `--sparse` option and path-walk behavior. The implementation is clean, with thorough test coverage that builds on the existing backfill test infrastructure. The patch maintains good separation of concerns while providing sensible defaults that align with user workflows.
