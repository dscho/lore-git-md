Refactoring patch in Patrick Steinhardt's reftable decoupling series (part 6/18). This change removes a Git-specific `BUG()` call from the reftable library's record comparison function, replacing it with proper error handling.

The patch modifies `reftable_record_cmp()` to return an error when comparing records of different types, rather than aborting. This requires cascading changes through several callers in the priority queue and merge iterator code to handle the new error returns. The change is part of the broader effort to make reftable usable as a standalone library by removing Git-specific behaviors.

Test coverage is maintained with updates to unit tests that verify the comparison behavior. The changes appear thorough and well-contained, with all call sites properly updated to handle the new error conditions. This is a typical example of the careful, incremental work in this series to disentangle reftable from Git's internals.
