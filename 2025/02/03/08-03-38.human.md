This is part of Patrick Steinhardt's ongoing effort to decouple the reftable library from Git's core infrastructure. The patch removes the last remaining uses of Git's `BUG()` macro in the reftable code, replacing them with proper error returns using the library's `REFTABLE_API_ERROR` code.

The changes are straightforward mechanical conversions where invalid API usage now returns an error rather than aborting. Notably, the patch removes `BUG()` checks in reference counting functions entirely, since hitting those conditions would already indicate undefined behavior (accessing freed memory). The writer validation also gets converted to return errors for invalid block sizes and type mismatches.

This continues the series' architectural goal of making reftable a proper standalone library by eliminating Git-specific behaviors. The changes maintain all existing functionality while improving the library's robustness for external users. With this patch, the reftable codebase no longer depends on Git's error handling infrastructure at all.
