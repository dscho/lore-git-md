This is a test refactoring patch in the atomic push exit code propagation effort. It's the second in an 8-part series addressing silent failure cases in atomic pushes.

The patch reorganizes test infrastructure in t5548-push-porcelain.sh by splitting the monolithic setup_upstream_and_workbench() function into two reusable components: create_upstream_template() for initial repository creation and setup_upstream() for repository rebuilding. This makes the test setup more modular and protocol-agnostic, with HTTP-specific configuration moved into the setup functions rather than being handled separately.

The changes are mechanical refactoring with no behavior modification - all test cases continue to run exactly as before, just with cleaner internal organization. The refactoring supports the series' goal by making it easier to add new test cases for atomic push behavior across different protocols. The patch carries forward sign-offs from both Jiang Xin (who did the initial work) and Patrick Steinhardt (who is now maintaining the series), suggesting this is a collaborative refinement of existing work rather than a new direction.
