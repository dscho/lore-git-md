This is a test patch in the atomic push exit code propagation series, adding new test cases for dry-run porcelain output. 

The patch adds four new test scenarios in t5548-push-porcelain.sh to verify the porcelain output format of `git push --porcelain --dry-run` under different conditions: regular dry-run, forced dry-run, atomic dry-run, and forced atomic dry-run. Each test case checks both the porcelain output format and that the upstream repository refs remain unchanged (as expected in dry-run mode).

The tests follow the established pattern in this series, using the protocol-agnostic test infrastructure that was refactored in earlier patches. They verify that the dry-run output correctly shows what would happen for each operation (updates, deletes, forced updates, new branches) while actually leaving the repository state untouched. The atomic cases also verify proper rejection behavior when non-fast-forward updates are involved.

This continues the series' thorough test coverage expansion, now ensuring the dry-run porcelain output behaves as expected. The tests are well-structured and consistent with the modern test patterns established in previous patches of this series.
