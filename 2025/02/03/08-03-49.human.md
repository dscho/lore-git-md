This is a build system patch that concludes Patrick Steinhardt's 18-part series decoupling the reftable library from Git's core infrastructure. The series has achieved near-total architectural separation, with this final change excluding reftable sources from Coccinelle checks since they no longer use Git's helper functions.

The patch is straightforward - it simply adds `reftable/%` to the list of paths excluded from Coccinelle's source file scanning. This prevents false positives that might occur when Coccinelle suggests converting patterns to use Git helper functions that the standalone reftable library deliberately avoids.

As noted in the thread summary, this series has been through rigorous review and addresses all major feedback. The reftable decoupling is now architecturally complete, with only some final I/O verification remaining before integration. This particular patch is a clean, logical conclusion to the build system adjustments needed for the separation.
