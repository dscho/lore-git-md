Refactoring patch in Patrick Steinhardt's reftable decoupling series (v3 9/18). This patch standardizes the reftable library's big-endian conversion functions, replacing a mix of Git-provided and reftable-specific implementations with a complete set of reftable-local wrappers.

The changes introduce new inline functions (`reftable_put/get_be{16,24,32,64}`) in basics.h header while removing the previous implementations from basics.c. The patch updates all call sites across the reftable codebase (block.c, reader.c, record.c, writer.c) to use these new functions, and adds corresponding test cases for the 32-bit and 64-bit variants that were previously untested.

This is part of the larger effort to fully decouple the reftable library from Git's core infrastructure. The implementation looks thorough - it maintains the same endian conversion behavior while removing Git dependencies, and includes comprehensive test coverage. The changes are mechanical but important for the library's independence.
