This is part of Patrick Steinhardt's ongoing series to decouple the reftable library from Git core infrastructure. The patch replaces Git's `UNUSED` macro with a reftable-specific `REFTABLE_UNUSED` version, continuing the pattern of removing Git dependencies while preserving functionality.

The change is mechanical but widespread, touching several files where unused parameters were previously annotated. The new macro is simpler behavior - it just suppresses unused parameter warnings without the compiler-enforced safety of Git's version, which the author notes is "good enough" for their needs. This avoids having to implement compiler-specific logic in the reftable codebase.

The patch follows the established approach of the series: each change maintains identical functionality while removing Git-specific dependencies. This particular change appears straightforward and low-risk, affecting only parameter annotations rather than actual logic. It's one of the final steps in the architectural separation of reftable from Git core.
