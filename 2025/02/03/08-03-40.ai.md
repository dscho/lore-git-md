This is part of Patrick Steinhardt's ongoing series to decouple the reftable library from Git core infrastructure (v3 09/18). The patch focuses on replacing Git's big endian conversion functions with reftable-local implementations, continuing the architectural separation effort.

The changes introduce a comprehensive set of inline functions in reftable/basics.h for handling 16/24/32/64-bit big endian conversions (reftable_{get,put}_be{16,24,32,64}), removing the previous Git-specific implementations. The new functions maintain identical behavior but use reftable's naming convention and avoid Git dependencies. The patch updates all callers across the reftable codebase (block.c, reader.c, record.c, writer.c) to use these new functions.

Test coverage is expanded in t-reftable-basics.c to verify the new 32-bit and 64-bit conversion functions, complementing existing tests for 16/24-bit cases. The implementation carefully preserves the original bit manipulation logic while making the code self-contained within reftable. This change is part of the final push to eliminate Git-specific utilities from reftable core, following previous removals of memory allocation helpers and error handling patterns.
