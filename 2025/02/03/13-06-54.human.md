Test coverage patch for `git repack --keep-unreachable` edge case. This is the first of two patches fixing a bug where the command crashes when run with no existing packfiles. Patrick Steinhardt adds three test scenarios: one where all objects are already packed (which works), one with mixed packed/loose objects (which works), and one with no existing packs (which currently fails). The tests verify that unreachable objects are correctly preserved in the new pack regardless of initial state.

The test suite additions are thorough verification helpers, including `expect_object_count` and `expect_object_in_idx` functions) and cover both the working and broken cases. The failing test case is explicitly marked as `test_expect_failure` with a note that it will be fixed in the following patch. This appears to be a well-structured test-first approach to fixing a clear edge case in the repack functionality.
