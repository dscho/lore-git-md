This is a refactoring patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git core infrastructure. The change removes a dependency on Git's `BUG()` macro by converting `reftable_record_init()` to return an error code rather than aborting when given an unknown record type.

The patch modifies the function signature and all its callers to handle the new error case, returning `REFTABLE_API_ERROR` for invalid types. This is part of the broader effort to make reftable usable as a standalone library without Git-specific dependencies. The changes are straightforward and well-contained, touching only the reftable implementation and its unit tests.

This continues the series' pattern of systematically replacing Git-specific functionality with reftable-local equivalents while maintaining the same safety guarantees. The patch appears technically sound and aligns with the series' architectural goals.
