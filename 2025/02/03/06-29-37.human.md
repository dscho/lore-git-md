This is a test patch in the atomic push exit code propagation series, adding new test cases to verify error reporting behavior. 

The patch adds two test cases to t5543-atomic-push.sh that specifically check how `git push --atomic` handles cases where `git-receive-pack` fails after successfully updating refs. The first test verifies regular output, while the second checks the porcelain output format. Both tests simulate a receive-pack that exits with error code 1 after successfully processing ref updates.

The tests are currently marked as `test_expect_failure`, indicating they're documenting known issues that the series aims to fix. The expected output shows the push should report the failure even when ref updates succeed but receive-pack fails later. This addresses an edge case where atomic pushes could silently ignore receive-pack errors.
