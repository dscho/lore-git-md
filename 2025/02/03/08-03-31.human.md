This is the final patch series in Patrick Steinhardt's effort to fully decouple the reftable library from Git's core infrastructure, making it reusable by other projects. The series removes all remaining dependencies on Git's `git-compat-util.h` header by open-coding necessary functionality and introducing a new `compat/posix.h` header specifically for reftable's needs.

The changes are primarily refactoring with no user-visible behavior changes. Key technical aspects include:
- Replacing Git-specific functions like `read_in_full()` and `write_in_full()` with direct system calls
- Removing dependency macros like `COPY_ARRAY()` and `BUG()`
- Splitting POSIX compatibility code into a standalone header
- Maintaining Windows support through MinGW/MSVC compatibility layers

The series has gone through multiple rounds of review addressing safety, build system, and stylistic concerns. The only remaining open item from previous discussions is verifying memory safety around the `COPY_ARRAY()` removal, which appears to have been addressed in this version. The changes are well-motivated and carefully implemented, with thorough test coverage. This represents the culmination of a significant architectural improvement to make reftable a truly standalone library.
