This is a test infrastructure discussion about shell command patterns in Git's test suite, specifically around input redirection versus direct filename arguments for `sort` and `uniq`.

Junio Hamano responds to Eric Sunshine's earlier analysis of command patterns in the test suite, pointing out that the grep-based statistics Eric provided may be misleading. Junio demonstrates that many of the `sort [a-z0-9]` matches are actually in test titles rather than actual command invocations. After more precise filtering, Junio finds the numbers are actually quite close (46 direct filename uses vs 51 input redirections for `sort`, and 0 vs 1 for `uniq`).

The email makes a technical argument that direct filename arguments are preferable from an extensibility standpoint, since they can more easily handle multiple input files without resorting to inefficient `cat` pipelines. However, Junio acknowledges the test suite doesn't consistently follow this logical preference, showing the actual usage is roughly balanced between the two styles. The discussion remains focused on establishing best practices for future test writing rather than proposing any immediate changes to existing tests.
