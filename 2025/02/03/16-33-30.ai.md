Maintainer response to continuous benchmarking proposal. Junio Hamano expresses general support for Patrick Steinhardt's RFC on establishing continuous benchmarking infrastructure for Git, noting the value of catching performance regressions early. The response references Peff's (Jeff King) similar experience with Coverity scans on the `next` branch, drawing a parallel between the benefits of pre-release quality checks. While not making any technical commitments, the reply signals project leadership's openness to the concept by framing it as part of the broader "more eyes before release" philosophy. The response does not address specific implementation questions from the RFC (t/perf extensions, Bencher integration, hardware requirements) but provides the high-level validation that the problem space is worth exploring. This positions the thread for more detailed technical discussion about how to operationalize the benchmarking system while confirming the project's interest in the general goal.
