Test modernization patch in the atomic push error propagation series.

This is the first of eight patches in Patrick Steinhardt's v5 series fixing atomic push exit code propagation. It modernizes test scripts in t5504-fetch-receive-strict.sh by moving heredoc declarations inside test bodies, following current Git test suite conventions. The changes are mechanical but important for maintainability - heredocs are now placed where they're used rather than at file scope, and use the `\EOF` syntax (with backslash) when no variable interpolation is needed, as confirmed by Eric Sunshine and Junio C Hamano as the preferred style.

The patch doesn't change test behavior - it just reorganizes the test file to be more maintainable and consistent with modern practices. This groundwork is part of the larger series that ultimately fixes how atomic push failures are propagated back to the client. The changes are well-scoped and clearly explained in the commit message, with no functional changes to the test logic itself.
