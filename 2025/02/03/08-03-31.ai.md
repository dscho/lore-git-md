This is the final patch series in Patrick Steinhardt's effort to fully decouple the reftable library from Git's core infrastructure, making it reusable by other projects. The series removes all remaining dependencies on "git-compat-util.h" by open-coding Git-specific helpers and introducing a new "compat/posix.h" header for POSIX-related functionality.

The 18-patch series completes the architectural separation that has been under review, with all major technical concerns now resolved except for one pending memory safety verification regarding COPY_ARRAY removal. Key changes in v3 include fixing a type mismatch in fd_read_lines(), dropping a controversial include path change to keep the series focused, and reorganizing platform-specific POSIX headers into a cleaner structure under compat/.

The series demonstrates careful attention to portability concerns across Windows (MinGW/MSVC) and POSIX systems, with 541 lines of POSIX emulation code now cleanly separated. Build system integration is handled via Makefile and meson updates, and Coccinelle is configured to skip the reftable library since it's now considered external code.

This represents the culmination of a multi-iteration review process that has addressed all architectural, build system, and stylistic concerns, leaving only one final safety consideration (the COPY_ARRAY question raised by Justin Tobler) as the reftable decoupling effort nears completion. The changes are well-motivated and technically sound, with the series now in a state where it could be merged pending resolution of that last safety item.
