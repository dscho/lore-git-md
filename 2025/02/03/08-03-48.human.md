This is a key patch in Patrick Steinhardt's ongoing effort to decouple the reftable library from Git's core infrastructure. The change finalizes the architectural separation by removing the last direct dependency on "git-compat-util.h" and replacing it with a new "compat/posix.h" header that provides only the POSIX functionality needed by reftable.

The patch represents the culmination of 17 previous changes that systematically removed Git-specific helpers from reftable. Now the library can be used by external projects like libgit2 without pulling in Git's entire compatibility layer. The only remaining Git-specific pieces are "system.h" and "system.c", which projects will need to implement themselves.

The diff shows the straightforward mechanical changes needed - swapping one header inclusion for another in system.h, while system.c now includes git-compat-util.h directly (presumably temporarily during the transition). This is a clean, well-motivated change that completes a major architectural improvement to make reftable more portable and reusable.
