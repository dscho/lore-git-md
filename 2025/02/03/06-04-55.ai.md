This is a test modernization patch in the atomic push exit code propagation series. Patrick Steinhardt responds to Eric Sunshine's review of an earlier patch that moved heredocs into test bodies in t5504-fetch-receive-strict.sh. Eric had suggested using `\EOF` rather than `EOF` for heredocs when no interpolation is needed, which Patrick confirms he will implement. This is a minor style refinement to the test infrastructure improvements that were part of the series' preparatory work, with Junio C Hamano having previously confirmed this heredoc syntax as the preferred style. The change doesn't affect functionality but brings the tests into alignment with modern Git test conventions. The patch being discussed was the first in the v4 series that ultimately led to fixing the atomic push exit code propagation issue.
