Refactoring patch in Patrick Steinhardt's ongoing series to decouple reftable from Git core. This is patch 13/18 in the v3 series.

The patch replaces Git's `SWAP()` macro with a reftable-specific `REFTABLE_SWAP()` implementation. The new version maintains the same functionality (including type safety checks) but removes the dependency on Git's utility macros. The change affects four files where swap operations are used - basics.h (where the new macro is defined), merged.c, pq.c, and record.c.

This continues the series' pattern of mechanically replacing Git-specific utilities with reftable-local equivalents. The implementation appears straightforward, using memcpy-based swapping with the same safety checks as the original. The patch maintains the existing behavior while progressing the overall goal of making reftable a standalone library.
