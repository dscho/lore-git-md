This is a refactoring patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git core infrastructure. 

The patch removes one of the final Git-specific dependencies by replacing the `ARRAY_SIZE()` macro with a direct calculation of array length using `sizeof()`. This change appears in the `reftable_reader_print_blocks()` function, which prints debugging information about reftable blocks.

This is a straightforward mechanical change that follows the pattern established throughout the series - eliminating Git-specific utilities in favor of standard C equivalents. The change maintains identical functionality while further reducing the reftable library's ties to Git's implementation details.

As part of the larger 18-patch series, this continues the architectural separation of reftable from Git core. The series has already addressed several rounds of review comments and appears to be in its final stages, with only some I/O implementation verification remaining before potential integration.
