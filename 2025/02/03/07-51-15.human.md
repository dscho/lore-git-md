Refactoring patch in the `git clone --revision` series. This is patch 3/6 in v4 of the series, focusing on simplifying the `wanted_peer_refs()` function in `builtin/clone.c`. The function maps server refs to local refs during cloning and had grown complex over time.

The patch reduces the function from 39 to 24 lines by restructuring the logic, though Patrick Steinhardt notes the diff is somewhat hard to follow without more guidance in the commit message. He also suggests a technical improvement - changing the loop counter from `int` to `size_t` to match `refspec->nr`'s type.

This refactoring is part of the larger preparatory work for the new `--revision` feature, which includes moving global variables to local scope and simplifying tag handling. The changes appear focused on code cleanliness rather than behavior modification, maintaining existing functionality while making the code more maintainable for the upcoming feature additions.
