Refactoring patch in Patrick Steinhardt's reftable decoupling series, replacing Git's `SWAP()` macro with a reftable-specific implementation. This continues the systematic removal of Git dependencies from the reftable library.

The patch introduces a new `REFTABLE_SWAP()` macro in basics.h that performs the same value swapping functionality as Git's version but with an implementation that includes a compile-time size check through an intentionally broken array size calculation when types mismatch. The macro is then used to replace all `SWAP()` calls across four files: merged.c (for iterator management), pq.c (priority queue operations), and record.c (ref record handling).

The implementation maintains the same safety properties as Git's version while being completely self-contained within reftable. The changes are mechanical replacements with no behavior differences, following the established pattern in this series. The patch affects core reftable operations including ref decoding, priority queue management, and merged iterator functionality.

This is part of the broader effort (now at patch 13/18) to make reftable a standalone library with minimal Git dependencies. The series has already addressed most major concerns from reviewers, with this being one of the final dependency removals before the I/O implementation verification phase.
