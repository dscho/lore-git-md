Test refactoring in the atomic push error propagation series. This patch (3/8) cleans up the test infrastructure in t5548-push-porcelain.sh as part of the larger effort to fix silent failures in atomic push error reporting. The changes:

1. Simplifies test setup by having setup_upstream() reset the upstream state after each test case via test_when_finished, rather than requiring manual cleanup
2. Adjusts initial branch states in the workbench to reduce per-test setup
3. Moves pre-receive hook setup/cleanup directly into the test cases that need them
4. Updates test descriptions to be more consistent

The changes maintain all test coverage while making the test file more maintainable. This is part of a well-reviewed series that has progressed through multiple iterations with input from Eric Sunshine and Junio C Hamano on test infrastructure improvements. The test changes here support the core fix that ensures atomic push failures properly propagate error codes back to the client.
