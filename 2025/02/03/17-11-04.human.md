Feature implementation for the new `git backfill` command, part 2/5 in the PATH WALK series. This patch adds core functionality to download missing blobs in batches from partial clones, with tests demonstrating both local and HTTP-based scenarios.

The implementation centers around `fill_missing_blobs()`, which uses the path-walk API to identify and fetch missing blobs in configurable batch sizes (default 50,000 objects). The command automatically groups blobs by path to improve server-side delta compression. Tests verify that all reachable objects are downloaded and that the command works over HTTP.

Key aspects include:
- Batch downloading via `promisor_remote_get_direct()`
- Automatic repacking after downloads
- Comprehensive tests covering both local and HTTP transports
- Documentation explaining the command's purpose in blobless partial clone workflows

This appears to be a well-constructed implementation with thorough test coverage. The commit message clearly explains the design decisions around batch sizing and path-based grouping. As part of the ongoing PATH WALK series, it builds on previously merged infrastructure while introducing the first working version of the `backfill` command's core functionality.
