Refactoring patch in the OS version capability series. This is the first of six preparatory patches in the final v5 iteration of the feature.

The patch replaces manual ASCII range checks in `version.c`'s string sanitization code with standard `isprint()` calls for better readability. The change maintains identical behavior by explicitly handling spaces (ASCII 32) which `isprint()` may not cover on all platforms. The modification affects `git_user_agent_sanitized()` which processes the user agent string before transmission.

Key technical details:
- Adds `sane-ctype.h` include for `isprint()`
- Modifies character validation in the redaction loop
- Preserves existing space handling behavior
- Part of broader refactoring to support OS version capability
- Follows established pattern of using Git's ctype wrappers

This is a straightforward quality improvement that doesn't change functionality but makes the code more maintainable. The change is well-contained and clearly explained in the commit message, with proper attribution to the mentor. As the first patch in the series, it sets up cleaner string handling that will be used by later patches adding OS version reporting.
