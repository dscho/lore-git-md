Refactoring patch in the OS version capability series.

This is the third patch in Usman Akinyemi's v5 series implementing OS version reporting in Git's protocol. It extracts the uname(2) system call handling from builtin/bugreport.c into a new get_uname_info() function in version.c, making it reusable for the OS version reporting feature. The patch moves the error handling and string formatting logic while maintaining identical behavior, just in a more modular form.

The implementation creates a new public function in version.h with clear documentation of its return values (-1 for errors with error message in buffer, 0 for success with system info in buffer). The function preserves the existing format of the bugreport output (space-separated sysname, release, version and machine fields) while adding proper gettext marking for the error message. This is a clean preparatory refactoring that enables the subsequent patches to reuse this system information gathering without duplicating code.

Key technical details for future reference:
- New function: get_uname_info() in version.c/version.h
- Maintains same output format as original bugreport code
- Adds proper error handling return value (-1/0)
- Uses strbuf for output buffer management
- Error messages marked for translation
- Part of consolidating system information utilities in version.c
- Follows series pattern of preparatory refactoring before feature implementation
