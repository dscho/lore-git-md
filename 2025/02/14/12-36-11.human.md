Refactoring patch in the OS version capability series. This is the first of six preparatory patches that clean up code before implementing the main feature.

The patch replaces a manual ASCII character range check in `version.c` with the standard `isprint()` function for checking printable characters, making the code more readable and maintainable. It maintains the same behavior by explicitly handling spaces (ASCII 32) which `isprint()` may not include on all platforms. The change is small but improves clarity while keeping the existing functionality of sanitizing non-printable characters in the user agent string.

This appears to be a straightforward, uncontroversial improvement that's part of a larger, already-merged series. The change is well-contained and has been reviewed by the series mentor Christian Couder. It demonstrates good practice by using standard library functions where appropriate while preserving the exact same behavior.
