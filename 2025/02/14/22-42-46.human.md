Maintainer feedback on documentation build system fix. Junio Hamano acknowledges Adam Dinwoodie's patch that restores the expected default build behavior in Documentation/Makefile (where 'make' should build full documentation rather than just config files). While agreeing with the fix's intent, Hamano suggests an alternative approach: following the convention used in other Git Makefiles by placing an empty "all::" target (with double colons) at the file's beginning rather than moving the existing target definition. This would prevent similar regressions in the future. The note also mentions that any existing single-colon "all" targets elsewhere should be corrected to use double colons, as they're phony targets. The feedback is constructive and points to established project conventions, indicating this will likely be a quick resolution with a minor revision to the patch.
