Test infrastructure improvement in the packed-refs validation series.

This is the first patch in v4 of an 8-part series adding packed-refs validation to `git fsck`. The patch focuses on improving test reliability by using subshells to ensure working directory changes don't leak between tests. Previously, tests would `cd` into a repository but might fail to `cd ..` back out if an intermediate test failed. The change wraps all test sections in subshells to automatically maintain proper working directory isolation.

The patch makes no functional changes to the actual ref checking logic - it's purely a test infrastructure improvement. The changes are mechanical but extensive, touching nearly 1000 lines of test code to add subshell wrappers around all test sections. The patch has been reviewed by mentors Patrick Steinhardt and Karthik Nayak.

This is a straightforward improvement that makes the test suite more robust, particularly important as this series is adding new validation logic that will be part of Git's core functionality. The change follows established patterns seen elsewhere in Git's test suite for working directory management.
