Refactoring patch in the OS version capability series. This is the third of six patches in v5 of Usman Akinyemi's series to add OS version information to Git's protocol capabilities.

The patch extracts the `uname()` system call handling from `builtin/bugreport.c` into a new reusable `get_uname_info()` function in `version.c`. This is preparatory work for the main feature implementation in the series, which will need the same system information for the protocol capability. The refactoring:
- Moves the error handling and string formatting logic into a shared function
- Maintains the same behavior (including error messages on failure)
- Adds proper documentation in the header file
- Keeps the existing bugreport` functionality unchanged

This is a clean, focused refactoring that improves code organization while being obviously correct - the changes are mechanical and well-contained. The patch follows good practices by including both the function implementation and its declaration in a single commit, with clear documentation of the new API.
