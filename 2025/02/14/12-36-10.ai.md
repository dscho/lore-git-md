This is a feature patch series extending Git's protocol capabilities to include OS information in the agent string. The series represents the final version (v5) of Usman Akinyemi's Outreachy project, now ready for merging after incorporating maintainer feedback.

The implementation adds OS name reporting via the existing `agent` capability string in the format "package/version os" (e.g., "git/1.8.3.1 Linux"), using the `uname(2)` system call. Key technical aspects include: platform-specific handling for Windows (where `uname(1)` and `uname(2)` differ), string sanitization via `redact_non_printables()`, and modular helper functions in version.c (`get_uname_info()`, `os_info()`). Privacy controls are handled through the existing `GIT_USER_AGENT` environment variable rather than a new config option, following maintainer guidance.

The series includes preparatory refactoring patches (1-5) that improve string handling and test isolation before the core feature (patch 6). Notable changes since v4 include removing the `transfer.advertiseOSInfo` config option and moving the OS info functionality into version.c. The implementation maintains backward compatibility while providing debugging benefits for servers to identify client platforms.

The thread context shows this is the culmination of earlier discussions where Christian Couder initially proposed a separate `os-version` capability, but the maintainers preferred extending the existing agent string. The current implementation represents a compromise that balances functionality with privacy considerations through environment variable controls rather than new configuration.
