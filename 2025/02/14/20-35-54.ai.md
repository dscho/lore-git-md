This is a discussion about the scope of `format.from` configuration in Git's email output functionality.

Junio Hamano responds to Antonin Godard's RFC patch that proposed adding From header support in `git show --format=email`. Hamano questions the fundamental premise, suggesting the `format.*` configurations were designed specifically for `git format-patch` rather than `git show` or `git log`. 

The key point raised is whether this is actually a bug/omission that needs fixing, or if the current behavior is correct by design. Hamano expresses skepticism about the need for the change ("I do not see there is anything that needs fixing") while leaving room for being convinced otherwise ("I may be missing something").

This moves the discussion from implementation details (which were the focus of the original RFC) to a more fundamental question about the intended scope and behavior of email formatting configuration across different Git commands. The thread now hinges on whether there's a legitimate use case for having `format.from` affect `git show` output, or if this would be an inappropriate mixing of concerns between patch generation and commit display.
