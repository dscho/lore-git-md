Maintainer response to documentation build system fix. Junio Hamano acknowledges Adam Dinwoodie's patch that restores the expected default build target behavior in Documentation/Makefile, but suggests an alternative approach. Rather than moving the 'all' target definition, Hamano recommends adopting the convention seen in t/Makefile and the main Makefile: placing an empty 'all::' (double-colon) rule at the file's beginning. This would prevent similar regressions by making the default target explicit from the start. The response includes a footnote clarifying that phony targets like 'all' should always use double-colon rules, noting any existing single-colon instances should be corrected. The suggestion maintains the same functional fix while aligning with existing project conventions for Makefile structure. This appears to be a straightforward improvement to the original patch with no technical objections.
