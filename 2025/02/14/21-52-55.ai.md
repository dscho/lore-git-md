Build system fix addressing a regression in documentation build behavior.

This patch corrects an unintended consequence of commit a38edab7c8 (December 2024) which accidentally changed the default build target in Documentation/Makefile from building documentation (html and man pages) to only producing configuration files. The change occurred because the commit placed new config file targets above the existing 'all' target definition, causing make to use the first target as default.

Adam Dinwoodie's fix simply moves the 'all: html man' declaration to the top of the file, restoring the expected behavior where running 'make' in the Documentation directory builds the full documentation set. The change is minimal (4-line diff) and clearly explained, with the commit message noting both the regression and its cause. This appears to be a straightforward correction of a build system quirk that would affect anyone trying to build Git's documentation locally.
