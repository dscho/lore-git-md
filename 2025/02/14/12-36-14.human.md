Refactoring patch in the OS version capability series. This is patch 4/6 in the final v5 iteration that was later merged.

The patch modifies the recently introduced `get_uname_info()` function to optionally return just the OS name rather than full system details. This prepares for a subsequent change where only the OS name will be needed for the protocol capability string. The function now takes a `full` flag parameter - when true it behaves as before (returning sysname, release, version and machine), when false it returns just the sysname.

The change is straightforward and maintains the existing error handling and strbuf-based output. It updates the single caller in `builtin/bugreport.c` to pass `1` to preserve its current behavior. The header comment is also updated to reflect the new parameter.

This appears to be a clean, focused refactoring that follows the series' pattern of preparatory changes before the main feature implementation. The commit message clearly explains the motivation and leaves room for future extensions if needed. As part of the v5 series that was ultimately merged, this change represents a stable part of the final implementation.
