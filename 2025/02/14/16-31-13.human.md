This is a bugfix proposal addressing an inconsistency in `git show --format=email` behavior. Antonin Godard notes that when `format.from` and `format.forceInBodyFrom` are configured, the command fails to include the expected "From:" line in the email-formatted output, despite the underlying code being capable of handling it.

The patch adds a `from` member to `struct log_config` and properly initializes the `rev.from_ident` field from user configuration, similar to how other Git commands handle email formatting. The author acknowledges this might not be the most elegant solution (due to some redundancy with `struct format_config`) and explicitly marks this as an RFC to validate whether the expected behavior is indeed correct.

The change is relatively contained (21 lines added to builtin/log.c) and appears to be a straightforward fix for what seems like an oversight in the original implementation. The author's question about whether this is the intended behavior suggests this might spark some discussion about the proper handling of email formatting across different Git commands.
