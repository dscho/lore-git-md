This is a feature patch series extending Git's protocol capabilities to include OS information in the agent string. The series has already gone through several iterations and was recently merged after removing a configuration knob (`transfer.advertiseOSVersion`) per maintainer feedback.

The key change in this version is the simplification of the implementation to rely solely on the existing `GIT_USER_AGENT` environment variable for privacy control, rather than introducing a new config option. The OS information (retrieved via `uname(2)`) will now be automatically appended to the agent string unless overridden by `GIT_USER_AGENT`.

The series includes several preparatory refactors (using `isprint()` for ASCII checks, improving string sanitization helpers) before implementing the core functionality. It handles platform differences, particularly Windows' divergence between `uname(1) and `uname(2)` outputs, by special-casing Windows in tests. Documentation updates explain the new agent string format ("package/version os") while maintaining backward compatibility.

This appears to be a well-considered implementation that balances functionality with privacy concerns, following maintainer guidance to avoid configuration proliferation. The changes are focused and well-tested, with clear commit messages explaining each step. The series represents the culmination of previous discussion and refinement, now proposing the final form of a useful debugging aid for server operators.
