This is a refactoring patch from Usman Akinyemi's series adding OS version capability to Git's protocol. It's part of the preparatory work (patch 2/6) that improves code structure before implementing the main feature.

The patch extracts string sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` helper function. The sanitization replaces non-printable characters and spaces with dots to prevent protocol issues. The change makes the code more modular and reusable for the upcoming OS version functionality.

Key technical improvements include:
- Using `isprint()` for clearer character checking
- Switching to `strbuf_detach()` for proper string ownership transfer
- Maintaining identical sanitization behavior while making the code more maintainable

This is a clean, focused refactoring that follows good practices - it's well-explained, has a single clear purpose, and keeps behavior unchanged. The changes will be used by the subsequent patches in the series that implement the OS version reporting feature.
