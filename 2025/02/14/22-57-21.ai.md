This is the fifth patch in Usman Akinyemi's series continuing the `the_repository` removal effort, converting `builtin/ls-files.c` to use explicit repository parameters instead of the global variable. The patch follows the established pattern seen in previous conversions but requires more extensive changes due to `ls-files` being a more complex command.

Key technical changes include:
- Removing `USE_THE_REPOSITORY_VARIABLE` macro
- Removing UNUSED annotation from the `repo` parameter
- Converting config loading to use `repo_config()`
- Passing repository parameter through to helper functions `expand_objectsize()` and `show_ru_info()`
- Updating index operations to use the passed repository
- Maintaining NULL repo handling for `-h` help text display

The patch modifies 32 lines across `builtin/ls-files.c`, more than previous patches in the series, due to `ls-files` having deeper function call chains that need repository parameter passing. The commit message explains the NULL repo handling for help text display, consistent with the series' approach. This represents progress on converting more complex builtins in the `the_repository` removal effort, though still focusing on commands that use only RUN_SETUP in git.c.
