This is a refactoring patch from Usman Akinyemi's v5 series adding OS version capability to Git's protocol. It's the second of six patches in the final version of this now-merged feature.

The change extracts string sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` helper function in version.c. The sanitization replaces non-printable ASCII characters and spaces with dots to prevent protocol parsing issues. The patch also improves memory handling by using `strbuf_detach()` rather than directly accessing the strbuf buffer.

This is a preparatory refactoring that enables code reuse in subsequent patches of the series, particularly for the OS version capability implementation. The change maintains the same behavior while making the code more modular. The implementation uses standard `isprint()` for character checking rather than manual ASCII value comparisons, which was one of the quality improvements noted in the final series.

Key technical details for future reference:
- New static function `redact_non_printables()` in version.c
- Continues using dot replacement for non-printables and spaces
- Changes memory management approach for the sanitized string
- Maintains identical external behavior of `git_user_agent_sanitized()`
- Part of the broader effort to standardize agent string handling
