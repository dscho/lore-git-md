Documentation build system fix addressing a regression in default target behavior. The thread originates with Adam Dinwoodie's patch correcting an unintended consequence of commit a38edab7c8 (Dec 2024) that changed the default build target in Documentation/Makefile from building full documentation (html and man pages) to only producing configuration files. The regression occurred because the commit placed config file targets above the 'all' target definition, causing make to use the first target as default. The fix moves 'all: html man' to the file's top, restoring expected behavior where 'make' builds complete documentation. The change is minimal (4-line diff) and clearly explained, noting both regression and cause. This affects anyone building Git's documentation locally.
