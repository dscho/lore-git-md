Refactoring patch in the OS version capability series. This is patch 4/6 in v5 of the series, modifying the `get_uname_info()` function to optionally show only the OS name rather than full system details. The change prepares for upcoming use cases where just the OS name is needed, while maintaining the existing full-detail output for bugreport functionality.

The patch modifies the recently introduced `get_uname_info()` helper function (previously refactored from bugreport.c) to accept a new `full` parameter. When true, it maintains the current behavior of outputting all system info fields (sysname, release, version, machine). When false, it outputs only the OS name (sysname). The change is straightforward with minimal impact - just 3 files modified with 11 lines added and 9 removed.

Key technical details:
- Function signature change in both version.c and version.h
- Updated call site in builtin/bugreport.c to pass `full=1`
- Maintains same error handling and strbuf-based output
- Preserves all existing functionality while adding flexibility
- Documentation in version.h updated to reflect new parameter

This is a clean preparatory refactoring that enables the next patch's needs while keeping the codebase flexible for potential future format variations. The change aligns with the series' overall goal of consolidating OS-related utilities in version.c while maintaining clean interfaces.
