Documentation patch reorganizing config option descriptions. This is the first of two patches improving documentation for the `remote.<name>.followRemoteHEAD` config option, which controls how `git fetch` handles remote HEAD updates.

The patch fixes a minor organizational issue where the description of `remote.<name>.serverOption` was split by the insertion of the newer `followRemoteHEAD` documentation. It simply moves the second paragraph of `serverOption`'s description back to be contiguous with the first paragraph, placing it after the `followRemoteHEAD` section. No content is changed - this is purely a documentation structure improvement.

The change is straightforward and uncontroversial, addressing a clear documentation flow issue that resulted from the feature's initial addition. The patch maintains all existing information while making the documentation easier to follow by keeping related descriptions together. This sets up the second patch in the series which will improve the wording of the `followRemoteHEAD` option's description itself.
