This is the final patch in a 6-part series implementing partial reference transactions, adding a user-facing `--allow-partial` flag to `git-update-ref`. The flag enables the partial transaction behavior implemented in previous patches, allowing individual reference updates to fail while others proceed when used with `--stdin` mode.

The patch adds documentation for the man page and implements the flag handling in `builtin/update-ref.c`. Key technical details include:
- The flag is only valid with `--stdin` (enforced with a `die()` call)
- Uses the `REF_TRANSACTION_ALLOW_PARTIAL` flag from earlier infrastructure
- Includes a `print_rejected_refs()` helper to format failed updates to match input format
- Maintains atomic behavior as default when flag isn't specified

Patrick Steinhardt provides minor review feedback suggesting:
- SYNOPSIS section could be split across lines for readability
- `print_rejected_refs()` has many placeholders that could be simplified
- `OPT_BIT()` could be used instead of `OPT_BOOL()` for flags
- Overall approves the simple implementation

This completes the series' user-facing functionality while maintaining the safety and compatibility established in earlier patches. The implementation appears straightforward and well-integrated with the transaction infrastructure built up through the series.
