This thread introduces a performance optimization for reference backend migrations by adding a `--skip-reflog` flag to `git refs migrate`, building on commit 246cebe320 which made reflog migration the default behavior. The change targets server repositories that may have accumulated unwanted reflogs (due to bugs, misconfiguration, or debugging) but don't need them, allowing administrators to skip this costly part of migration.

Key technical implementation:
- Adds `REPO_MIGRATE_REF_STORAGE_FORMAT_SKIP_REFLOG` flag bit in `refs.h`
- Modifies `repo_migrate_ref_storage_format()` in `refs.c` to conditionally skip reflog migration
- Extends CLI interface in `builtin/refs.c` with new `--skip-reflog` option
- Adds test coverage in `t/t1460-refs-migrate.sh` verifying the behavior
- Renumbers existing dry-run flag to accommodate the new flag
- Optimization only benefits repositories with reflogs being skipped
