This is part of Patrick Steinhardt's ongoing reftable decoupling series, specifically replacing Git-specific utilities with standalone implementations. Patch 13/18 removes the dependency on Git's `SWAP()` macro by introducing a reftable-specific `REFTABLE_SWAP` implementation.

The change follows the series' pattern of systematically eliminating Git infrastructure dependencies from the reftable code. The new implementation maintains the same functionality while being self-contained, including the size-checking safety that was previously handled by Git's version. The patch touches several files where `SWAP()` was used, replacing each instance with the new macro.

This appears to be a straightforward mechanical change that completes another piece of the architectural separation. The implementation looks clean and maintains the same safety properties as the original. As with previous patches in the series, this moves reftable closer to being a truly standalone library.
