This is a GSoC 2025 mentor assignment update that finalizes the project allocations. The email from Kaartic Sivaraam confirms the mentor assignments for the four proposed projects, resolving the last open question in the mentor track of this thread.

The key assignments are:
- Patrick Steinhardt will primarily mentor "Consolidate ref-related functionality into git-refs" (with Jialuo or Christian Couder as co-mentor)
- Christian Couder takes lead on "Refactoring to reduce Git's global state" (with Karthik or Jialuo co-mentoring)
- Karthik will mentor "Machine-Readable Repository Information Query Tool" (with Patrick co-mentoring)
- Patrick also mentors "Implement support for reftables in 'dumb' HTTP transport" (with Karthik co-mentoring)

The email notes a constraint that only 3 projects can be accepted maximum, and that the ref-related functionality and reftables projects cannot both be selected since Patrick prefers to mentor only one project. Kaartic plans to update the ideas page to reflect these constraints.

With Git's GSoC application now submitted, the next milestone is the selection results announcement on February 26. This completes the mentor assignment portion of the GSoC planning, leaving only the documentation infrastructure decision (git.github.io vs. other options) as the remaining open item in the thread.
