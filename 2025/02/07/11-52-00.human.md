This is a refactoring patch in Patrick Steinhardt's series to decouple the reftable library from Git's core infrastructure. The patch removes a dependency on Git's `BUG()` macro in the reftable record initialization code, replacing it with proper error handling.

The change modifies `reftable_record_init()` to return an error code (REFTABLE_API_ERROR) when given an unknown record type, rather than calling `BUG()` which would abort the program. This is part of the broader effort to make the reftable library usable outside of Git by removing Git-specific dependencies. The patch updates all callers to check the new return value.

The change is straightforward and mechanical, with corresponding updates to unit tests. It follows the established pattern of the series by replacing Git-specific functionality with library-appropriate alternatives. Since this is part of a well-reviewed series that's already addressed all major technical feedback, the change appears uncontroversial and ready for inclusion.
