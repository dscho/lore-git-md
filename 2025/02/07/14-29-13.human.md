This is a follow-up discussion in Patrick Steinhardt's Meson build system refactoring series, specifically addressing patch 9/13 which improves the `sane_tool_path` option handling. The patch converts the option from a string to an array type for better path handling, but Toon Claes raised concerns about backward compatibility when reconfiguring existing build directories.

Patrick responds that since Meson support is still marked as experimental, such breaking changes are acceptable during this iteration phase. He suggests being more careful about backward compatibility once Meson matures, likely starting with Git v2.49 or v2.50. The exchange highlights the practical considerations involved in build system modernization, where the team balances improvements against migration pain during the experimental phase.

This discussion represents one of the final open questions in an otherwise well-received series that has already addressed architectural simplification, Windows reliability improvements, and build optimizations. The resolution here will help determine when this patch can proceed to final maintainer consideration.
