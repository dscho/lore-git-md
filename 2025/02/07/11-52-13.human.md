This is the final patch in Patrick Steinhardt's 18-part series to fully separate the reftable library from Git's core infrastructure. The series has addressed all major technical feedback and is now considered complete.

The patch makes a small but important build system adjustment: it excludes reftable sources from Coccinelle checks. Since the reftable library no longer uses any Git-specific helpers (as established by the previous patches), Coccinelle rules designed for Git code could generate false positives when applied to reftable. This change prevents that by explicitly filtering out reftable sources from Coccinelle's scope.

The change is straightforward - a one-line modification to the Makefile that adds `reftable/%` to the list of excluded sources for Coccinelle checks. This is a logical conclusion to the series' goal of making reftable fully independent from Git's infrastructure. With all previous patches having removed Git dependencies and this final tweak to the build system, the reftable library is now properly decoupled from Git's tooling as well.
