This is the fifth and final iteration of Patrick Steinhardt's series to fully decouple the reftable library from Git's core infrastructure, marking a significant architectural milestone. The series has evolved through multiple rounds of review, with all major technical concerns now resolved.

The key change in v5 is the reworked implementation of `REFTABLE_UNUSED` to use `__attribute__((__unused__))` instead of introducing a new macro, addressing feedback from Toon Claes. This follows the pattern established in previous versions where Git-specific utilities were systematically replaced with reftable-specific implementations or POSIX-compatible alternatives.

The series now cleanly separates reftable from Git's internals by:
- Removing all dependencies on `git-compat-util.h`
- Introducing a new `compat/posix.h` header for POSIX functionality
- Completing build system isolation (including Coccinelle exclusion)
- Maintaining full functionality through carefully designed interfaces

With this version, the reftable library becomes truly portable - other projects like libgit2 can now use it by simply copying the source files. The changes are well-tested and have undergone rigorous review, with only minor header inclusion style questions remaining open from earlier discussions. This represents the culmination of a long effort to make reftable a standalone library while preserving its integration with Git.
