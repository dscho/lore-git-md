Documentation conversion follow-up. Junio C Hamano responds to D. Ben Knoble's investigation into which documentation files are processed by AsciiDoc, confirming that SubmittingPatches is indeed built into HTML despite lacking a .txt extension. This validates part of the ongoing discussion about which files should be included in the first phase of converting documentation from .txt to .adoc extensions.

The email notes an inconsistency where ReviewingGuidelines has a .txt extension while SubmittingPatches does not, despite both being processed similarly. Hamano suggests this should be fixed regardless of the broader conversion effort, to make it easier for editors to identify AsciiDoc files. The exchange helps clarify the scope of files that need conversion in the first phase of this documentation modernization effort.
