Platform compatibility patch in Patrick Steinhardt's reftable decoupling series. This is patch 15/18 in the v5 series that finalizes the architectural separation of the reftable library from Git core.

The patch reorganizes Windows compatibility headers by splitting POSIX-related functionality from Git-specific wrappers. It creates new `compat-util.h` and `posix.h` headers under both `mingw/` and `msvc/` directories, moving:
- POSIX emulation functions to `posix.h`
- Git-specific Windows helpers to `compat-util.h`
- Updates build systems (Makefile, CMake, meson) to use the new paths

This is part of the larger effort to make reftable a standalone library by removing Git-specific dependencies. The changes are mechanical and follow the pattern established in earlier patches of the series. The thread context shows this is one of the final steps in the reftable decoupling work, with all major technical feedback already addressed in previous rounds.
