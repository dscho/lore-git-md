This is part of Patrick Steinhardt's v5 series (18 patches) to decouple the reftable library from Git core infrastructure. The patch focuses on big endian conversion utilities.

The change replaces Git-specific big endian conversion functions (`put_be16`, `put_be24`, `get_be24`) with reftable-specific versions (`reftable_put_be16`, `reftable_put_be24`, `reftable_get_be24`), and additionally introduces new functions for 32-bit and 64-bit conversions (`reftable_put_be32`, `reftable_put_be64`, `reftable_get_be32`, `reftable_get_be64`). All functions are implemented as static inline in basics.h for better performance.

The patch updates all call sites across the reftable codebase (block.c, reader.c, record.c, writer.c) to use the new reftable-specific versions. It also extends the unit tests to cover the new 32-bit and 64-bit variants. The changes maintain identical behavior to the original functions while removing the Git dependency.

This completes another piece of the reftable decoupling effort by eliminating another set of Git-specific utility functions. The implementation follows the established pattern of the series, converting direct dependencies into self-contained reftable implementations.
