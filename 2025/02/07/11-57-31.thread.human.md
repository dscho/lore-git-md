This thread introduces a performance optimization for reference backend migrations by adding a `--skip-reflog` flag to `git refs migrate`. The change builds on commit 246cebe320 which made reflog migration the default behavior, and is particularly useful for server repositories that have accumulated unwanted reflogs (from bugs or debugging) but don't need to preserve them.

Karthik Nayak has led the implementation, which adds a new flag bit to skip reflog migration and modifies the core migration logic.
