Feature addition to the refs migration command. Karthik Nayak proposes adding a `--skip-reflog` flag to `git refs migrate` to allow skipping reflog migration when transferring repositories between reference backends. 

The patch notes that while reflog migration (added in December 2024) is useful for client-side repositories, server-side repos typically don't need reflogs, making their migration unnecessary overhead. The change adds the new flag and corresponding internal flag constant, modifies the migration logic to respect it, and includes tests verifying the behavior.

The implementation looks straightforward - it conditionally skips the reflog migration step when the flag is set, while maintaining all other migration functionality. The test coverage appears thorough, checking both that reflogs are properly skipped when requested and that normal migration continues to work. This seems like a sensible optimization for server-side use cases where reflogs aren't needed.
