This is a refactoring patch in Patrick Steinhardt's v5 series decoupling the reftable library from Git core infrastructure. The patch removes the last remaining use of Git's `ARRAY_SIZE()` macro in the reftable reader code, replacing it with a direct calculation of the array size using `sizeof()`. 

The change follows the series' pattern of eliminating Git-specific dependencies in favor of self-contained implementations. The modification is straightforward - a single line change in `reftable/reader.c` that replaces `ARRAY_SIZE(sections)` with the equivalent `sizeof(sections) / sizeof(*sections)` calculation. The patch maintains identical functionality while further reducing the reftable library's ties to Git's utility macros.

This is one of the final steps in the comprehensive effort to make reftable fully independent, with all major utility dependencies (I/O, memory, error handling, comparison operations, and now array utilities having been addressed in previous patches. The change is small but consistent with the architectural goal of the series.
