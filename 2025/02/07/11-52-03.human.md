This is a refactoring patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git's core infrastructure. The patch focuses on eliminating another Git-specific dependency by replacing `st_mult()` in array allocation macros with a custom overflow-checking implementation.

The change converts the array allocation helpers (`REFTABLE_ALLOC_ARRAY`, `REFTABLE_REALLOC_ARRAY`, and `reftable_alloc_grow`) to use a new `reftable_alloc_size()` function that performs manual overflow checking. This serves two purposes: it removes the dependency on Git's `st_mult()` (which would abort on overflow), and makes the error handling more library-friendly by setting `errno` rather than terminating.

The implementation carefully maintains the same allocation behavior while adding proper error handling.
