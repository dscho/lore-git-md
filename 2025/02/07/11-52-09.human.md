This is part of Patrick Steinhardt's ongoing series to fully decouple the reftable library from Git core infrastructure. The patch introduces a reftable-specific `REFTABLE_UNUSED` macro to replace Git's `UNUSED` attribute annotation throughout the reftable codebase.

The change is straightforward - it defines `REFTABLE_UNUSED` in basics.h to use the same `__attribute__((__unused__))` syntax as Git's `MAYBE_UNUSED`, then updates all existing `UNUSED` annotations in the reftable code to use this new macro instead. The patch touches several key reftable components including blocksource handling, iterator implementations, record encoding/decoding, and writer utilities.

This continues the series' pattern of systematically removing Git-specific dependencies. The change was suggested by Toon Claes in earlier discussion and helps maintain consistency with the reftable library's goal of being self-contained implementation. While mechanically simple, it's another step toward the architectural goal of making reftable usable by external projects.
