This is the final patch in Patrick Steinhardt's 18-part series to fully separate the reftable library from Git core infrastructure. The series has systematically removed all Git-specific dependencies, with this patch addressing a build system detail.

The patch excludes reftable sources from Coccinelle checks since the library no longer uses any Git helper functions that Coccinelle rules target. This prevents false positives from rules that would suggest converting code to use Git-specific helpers that the standalone reftable shouldn't depend on. The change is minimal - just adding `reftable/%` to the filter-out list in the Makefile's COCCI_SOURCES definition.

This completes the architectural separation by ensuring the build system treats reftable as truly independent component. The patch follows naturally from the series' goal of making reftable self-contained, though it's a minor technical cleanup rather than a core architectural change like earlier patches. With all major feedback addressed in previous versions and no new technical concerns raised, this appears to be the final step in the reftable decoupling effort.
