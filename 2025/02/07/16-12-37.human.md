This is a refactoring patch in a series improving Git's reference transaction system. It removes redundant checks in the files backend's `split_symref_update()` function, specifically eliminating duplicate validation of refnames in `affected_refnames`. The change follows from an observation that an early check makes a later one unnecessary.

Patrick Steinhardt confirms the logic is sound but suggests the explanation could be clearer. The patch simplifies the code by removing not just the redundant check but also some related utility pointer assignments that were only used for existence checking. This appears to be a straightforward cleanup with no functional changes, part of a larger effort to centralize and streamline reference validation logic.
