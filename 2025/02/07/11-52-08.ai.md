This is a refactoring patch in Patrick Steinhardt's ongoing series to decouple the reftable library from Git core infrastructure. The patch replaces Git's `SWAP()` macro with a reftable-specific `REFTABLE_SWAP()` implementation, continuing the series' pattern of removing Git-specific dependencies.

The change introduces a new macro in `reftable/basics.h` that performs the same swap operation but includes its own size-checking logic rather than relying on Git's implementation. The patch updates four files that previously used `SWAP()` to use the new macro instead: `merged.c`, `pq.c`, and `record.c`. The implementation carefully maintains the same behavior while being self-contained.
