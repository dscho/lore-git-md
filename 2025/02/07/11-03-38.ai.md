Refactoring patch in Patrick Steinhardt's `the_repository` removal series, introducing a dedicated cleanup function for `repo_settings` struct. This patch (13/16 in v2) adds `repo_settings_clear()` to centralize resource cleanup for repository settings, replacing the previous ad-hoc approach where settings clearing was mixed into `repo_clear()`. The new function properly handles the `fsmonitor` field (freeing it if set) before resetting the struct to its initialized state. This change affects three files: adds the declaration in `repo-settings.h`, implements the function in `repo-settings.c`, and updates `repository.c` to use it. The motivation is to maintain cleaner separation of concerns and make future maintenance easier when new fields are added to the settings struct. This is a mechanical but important piece of the larger repository refactoring effort, following the established pattern of explicit resource management.
