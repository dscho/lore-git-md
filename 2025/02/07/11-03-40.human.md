Repository infrastructure patch continuing the `the_repository` removal effort.

This is patch 15/16 in Patrick Steinhardt's series to eliminate global state from Git's repository handling. It moves management of the "core.sharedRepository" config setting from global variables in environment.c into the repo_settings struct, following the same pattern used for other repository-specific settings in previous patches.

The change replaces direct access to the_shared_repository and need_shared_repository_from_config globals with new repo_settings_get/set/reset_shared_repository() functions. The implementation maintains the same lazy-loading behavior from config while making the state repository-specific. The patch updates all callers across several files (init-db.c, log.c, path.c, setup.c) to use the new accessors.

This continues the systematic approach seen throughout the series - mechanical conversions that preserve existing behavior while removing global state. The changes are straightforward and follow established patterns from prior settings migrations in the series. With only one patch remaining after this, the series appears to be nearing completion of its goal to eliminate implicit repository dependencies.
