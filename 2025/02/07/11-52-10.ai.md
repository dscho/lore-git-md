This is a refactoring patch in Patrick Steinhardt's v5 series (18 patches) to separate the reftable library from Git core infrastructure. The patch focuses on reorganizing Windows compatibility headers by splitting POSIX-related functionality from Git-specific wrappers.

The key changes:
- Creates new `compat/compat-util.h` headers for both MinGW and MSVC builds to hold Git-specific Windows compatibility code
- Moves POSIX-related declarations to new `compat/posix.h` headers
- Updates build systems (Makefile, CMake, meson) to reference the new file locations
- Maintains identical functionality while improving code organization

The patch continues the series' pattern of methodically replacing Git-specific dependencies with self-contained implementations. It builds on previous work that replaced I/O operations, memory utilities, error handling, and other core functionality. The header reorganization prepares for further separation of POSIX compatibility from Git-specific utilities.
