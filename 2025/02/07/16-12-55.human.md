This is the final patch in a 6-part series introducing partial reference updates to Git's transaction system. The patch adds a user-facing `--allow-partial` flag to `git update-ref --stdin`, allowing some reference updates to fail while others proceed - a capability enabled by the earlier infrastructure changes in the series.

Patrick Steinhardt provides a brief review, noting the implementation is straightforward but suggesting some minor improvements. He points out the overly long synopsis line in the documentation could be split, and that the `print_rejected_refs` function has many placeholders that make it hard to read. He also suggests using `OPT_BIT()` for the flag handling rather than `OPT_BOOL()`.

The patch maintains consistency with the series' goals by keeping partial updates opt-in (via the new flag) while preserving atomic behavior as the default. The implementation is cleanly integrated with the existing `--stdin` mode, with appropriate error handling when the flag is used incorrectly. This completes the user-facing side of the partial transactions feature that has been carefully built up through the previous patches.
