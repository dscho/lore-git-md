Documentation patch standardizing boolean value syntax across Git man pages, originating from Junio Hamano. The thread establishes git-config(1) as the canonical reference for boolean value syntax, replacing inconsistent partial definitions scattered across multiple man pages. Key changes:

1. Expands git-config.txt's `--type=bool` documentation to comprehensively list all accepted true/false variants (including "true"/"false", "yes"/"no", "on"/"off", and numeric 1/0).

2. Updates git.txt's environment variables section to reference git-config's definition rather than maintaining a separate incomplete list.

3. Simplifies pretty-formats.txt by removing its boolean value list and pointing to git-config's authoritative version, replacing text originally added by Taylor Blau in commit fb0dc3ba.
