This is version 4 of a feature patch adding long option names for Git's pickaxe search functionality (`--patch-modifies` for `-S` and `--patch-grep` for `-G`). The series has been reorganized based on Junio Hamano's feedback, splitting the changes into 10 smaller, more focused patches for easier review.

The first 5 patches address minor documentation and help text issues that were noticed during the main change. Patch 6 is the core implementation adding the new long option names while maintaining backward compatibility. The remaining patches incrementally update tests, bash completion, and documentation to use the new names where appropriate.

Junio had previously approved the technical approach but requested documentation refinements - specifically preferring to keep short options as primary in docs with long forms introduced alongside rather than wholesale replacement. The author has incorporated this feedback while still making a case for the readability benefits of long options in test code and complex documentation examples.
