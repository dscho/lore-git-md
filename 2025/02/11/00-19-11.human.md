Junio C Hamano's follow-up on the Thunderbird patch script portability fix.

This is a brief technical discussion about the final tweaks to the POSIX-compliant rewrite of the Thunderbird patch processing tool. The core portability issue (replacing bash's `echo -e` with `printf`) was already addressed in the previous patch, which Junio has now merged. 

In this email, Junio comments on the specific implementation choice of using `printf '%s\n%s\n'` rather than the more concise `'%s\n'` format string. While acknowledging either approach would work, he personally finds the shorter version more readable as it more clearly shows printf iterating over its arguments. The author had previously explained they chose the longer form for maintainability reasons.

This represents the final polish on a straightforward portability fix for a rarely-used contrib script. The discussion remains technical and constructive, focusing on minor stylistic preferences now that the functional correctness and POSIX compliance have been established. With the patch already merged, this exchange serves as a post-hoc design rationale rather than requesting further modifications.
