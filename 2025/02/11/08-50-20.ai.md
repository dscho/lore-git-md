This is a test modernization patch in the ongoing series introducing long option names for pickaxe search functionality (--patch-grep for -G and --patch-modifies for -S). As patch 8/10 in v4 of the series, it updates test scripts to use the new long option names for improved readability, while preserving tests that verify both short and long forms work identically.

The changes focus on two test files (t4062-diff-pickaxe.sh and t4209-log-pickaxe.sh), converting -G to --patch-grep and -S to --patch-modifies throughout. The test_description in t4209 is updated to reflect the new terminology. The patch maintains all existing test coverage while making the tests more readable by using descriptive option forms.

Key technical details preserved:
- Tests still verify binary file handling behavior
- --pickaxe-regex interaction tests remain
- Textconv filter tests are maintained
- Regex vs non-regex search behavior is still validated
- The test structure and assertions are unchanged

The changes are mechanical substitutions that don't affect test logic, following the series' goal of making pickaxe options more discoverable while maintaining backward compatibility. This patch completes the test modernization portion of the series after the core implementation and documentation updates in earlier patches.
