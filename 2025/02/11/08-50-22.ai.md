This is the final documentation patch in a series introducing long option names for Git's pickaxe search functionality, specifically converting `-G` to `--patch-grep` and `-S` to `--patch-modifies` throughout the docs. The patch updates three documentation files (diff-options.adoc, git-blame.adoc, and gitdiffcore.adoc) to consistently use the new long option names. The changes are primarily mechanical substitutions, though gitdiffcore.adoc includes a minor restructuring to better introduce the short forms after explaining the long forms. The author notes this was done to maintain the mnemonic explanation for `-G` without awkward repetition.

Key technical details:
- All instances of `-G` are replaced with `--patch-grep` and `-S` with `--patch-modifies`
- The gitdiffcore.adoc changes include reordering content to introduce short forms after long forms while preserving the `-G` mnemonic explanation
- Some reformatting occurs to maintain line lengths with the longer option names
- The patch maintains all existing functionality while improving documentation clarity
- This completes the documentation updates started in earlier patches of the series

The changes are straightforward and complete the series' goal of improving discoverability through more descriptive option names while maintaining backward compatibility with the existing short forms.
