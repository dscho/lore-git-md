Platform compatibility follow-up for Thunderbird patch script.

This is a brief discussion about stylistic choices in the already-accepted v2 patch that fixed bashisms in the `contrib/thunderbird-patch-inline/appp.sh` script. Junio C Hamano notes they personally would have preferred using `printf '%s\n'` with multiple arguments (which automatically iterates over them) rather than the explicit `printf '%s\n%s\n'` approach taken in the patch, finding the former slightly more readable. The patch author brian m. carlson had considered this alternative but chose the more explicit version for better maintainability. 

The technical content remains unchanged from the v2 patch that was already merged - the discussion purely concerns code style preferences between two equally valid POSIX-compliant implementations. The thread shows the maintainer's attention to detail even after acceptance, while acknowledging both approaches are acceptable. This marks the conclusion of all technical discussion around modernizing this long-neglected contrib script's shell portability.
