This is a documentation patch in a series adding long option names for Git's pickaxe functionality. It's part of a larger effort to improve discoverability of the `-G` and `-S` search options by adding `--pickaxe-grep` and `--pickaxe-modifies` aliases.

The patch updates the short help text in diff.h to include both the short (`-G`) and long (`--pickaxe-grep`) forms of the regex-based search option. It also clarifies that `--pickaxe-all` applies to both `-G` and `-S` operations, not just `-S` as previously stated. The change is straightforward and aligns with the series' goal of making these powerful but obscure options more accessible.

This is the fourth patch of a 10-part series that has undergone several revisions based on maintainer feedback. The core implementation is already in place, and this patch focuses on ensuring the help text accurately reflects the available options. The change maintains backward compatibility while improving documentation clarity.
