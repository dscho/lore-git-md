This is a technical discussion about NFSv4 packfile handling and temporary file permissions during failover scenarios. Jeff King (peff) responds to Brian Carlson's concerns about whether modifying Git's file permission handling would actually solve the NFSv4 state recovery issues.

Peff suggests an alternative approach where Git could create temporary packfiles with 0644 permissions during writing, then switch to 0444 before finalizing them into place. He notes this pattern already exists in Git's `adjust_shared_perm()` and would be compatible with systems that currently work fine. The main tradeoff would be slightly more code and an additional `chmod()` syscall.

The email doesn't take a strong position on whether this change should be made, but presents it as a technically feasible option that might address the NFSv4 failover issues while maintaining compatibility.
