This is a documentation patch in a series introducing long option names for Git's pickaxe functionality. It standardizes placeholder terminology in gitdiffcore.adoc, changing from verbose forms like `<regular-expression>` and `<block-of-text>` to the shorter `<regex>` and `<string>` used elsewhere in Git's code and docs. The justification is consistency with existing documentation and the assumption that users will understand the shorter forms. The change affects how both `-G` (regex search) and `-S` (string count modification) options are described, with all examples and explanations updated to use the new placeholders while maintaining the same technical meaning. This is part of the broader effort to improve pickaxe option documentation while keeping it consistent with Git's established style. The patch is straightforward and aligns with the series' goal of clarifying pickaxe options without changing their behavior.
