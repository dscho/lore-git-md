Documentation patch correcting the help text description of `-S` pickaxe search in diff.h.

This patch fixes the short help text for the `-S` option in diff.h to more accurately describe its behavior. The original text suggested `-S` only finds filepairs where one side contains the string while the other doesn't, which was misleading. The new text correctly states that `-S` finds filepairs that differ in the number of occurrences of the string, matching the actual behavior where it detects modifications to the count of a string, not just presence/absence.

The change is minimal - a single line modification in diff.h's help text string. This is part of a larger series (v4, patch 3/10) introducing long option names for pickaxe functionality, where documentation accuracy is being carefully reviewed. The patch itself is straightforward and uncontroversial, simply correcting an existing inaccuracy in the help text.
