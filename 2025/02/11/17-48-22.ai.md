This is a performance optimization patch in the refs migration subsystem, adding a `--skip-reflog` flag to bypass reflog migration when moving between reference backends. The change builds on commit 246cebe320 which made reflog migration the default, and targets server repositories that may have accumulated unwanted reflogs but don't need them preserved.

The implementation adds a `REPO_MIGRATE_REF_STORAGE_FORMAT_SKIP_REFLOG` flag bit and modifies `repo_migrate_ref_storage_format()` to conditionally skip reflog migration. The CLI interface in `builtin/refs.c` gains the new `--skip-reflog` option, while tests in `t/t1460-refs-migrate.sh` verify the behavior. Key technical details include the flag being defined in `refs.h` and the existing dry-run flag being renumbered to accommodate it.
