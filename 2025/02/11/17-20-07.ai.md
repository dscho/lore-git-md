This is a documentation patch that centralizes and clarifies the various ways to spell boolean values across Git's man pages. Junio Hamano noticed inconsistencies in how boolean values were documented in different parts of the documentation and proposes making git-config(1) the canonical source for this information.

The patch makes three key changes: First, it expands the `--type=bool` documentation in git-config.txt to explicitly list all accepted true/false variants (including numeric values). Second, it updates git.txt's environment variables section to reference this canonical definition rather than providing an incomplete list. Third, it simplifies pretty-formats.txt by removing its own boolean value list and pointing to git-config's authoritative version instead.

The changes are straightforward and improve documentation consistency, though they do modify text originally written by Taylor Blau in commit fb0dc3ba. The patch appears well-motivated by the observation that readers currently have no single place to find the complete boolean value syntax, and its implementation is clean with no obvious technical issues.
