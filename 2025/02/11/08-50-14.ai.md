Documentation patch fixing a copy-paste error in the pickaxe search option help text.

This is the second patch in a 10-part series introducing long option names for Git's pickaxe functionality (-S/-G). The patch corrects an inaccuracy in the help text for the `-G` option in diff.c, which had incorrectly described it as counting string occurrences (like `-S`) rather than searching for patches containing matching lines. The fix changes the description to accurately reflect that `-G` looks for differences where a patch contains the specified regex.

The change is minimal (a single line modification) and clearly corrects an obvious documentation error that was likely introduced through copy-paste from the `-S` option's text. This aligns with the series' broader goal of improving pickaxe option clarity, though it stands alone as a straightforward documentation fix independent of the long-option work. The patch follows the series' pattern of cleaning up documentation details before introducing new functionality.
