Completion script update for pickaxe long options.

This patch (7/10 in the series) adds Bash completion support for the new long option names `--patch-grep` and `--patch-modifies` that were introduced as aliases for `-G` and `-S` pickaxe options. The changes ensure command-line completion works consistently whether users type the short or long forms.

The modifications touch the Git completion script to:
1. Add the new long options to the common diff options list
2. Handle completion when these options appear in the middle of a command
3. Support completion after the equals sign (e.g., `--patch-grep=<TAB>`)

This is a straightforward technical follow-up to the core implementation patches, maintaining consistency with the series' goal of making pickaxe options more discoverable while preserving backward compatibility. The changes are minimal and focused, with no functional impact beyond completion behavior.
