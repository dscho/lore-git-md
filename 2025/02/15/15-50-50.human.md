This is a refactoring patch in the final stages of Usman Akinyemi's series adding OS version capability to Git's protocol. The patch modifies the `get_uname_info()` function to optionally return just the OS name rather than full system details, preparing for future use cases where only the OS name is needed.

The change is straightforward - it adds a `full` parameter to control whether the function outputs complete system information (sysname, release, version, machine) or just the OS name (sysname). The patch updates the single existing caller in `bugreport.c` to maintain current behavior by passing `1` for full details.

This appears to be a clean, focused change that follows the series' pattern of modularizing system information handling. The commit message clearly explains the motivation (future needs) without over-promising. As part of the well-reviewed v6 series that's already addressed core protocol concerns, this refinement seems like a low-risk improvement to the underlying infrastructure.
