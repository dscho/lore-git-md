Refactoring patch in the OS version capability series. This patch modifies the `get_uname_info()` function to optionally return just the OS name rather than full system details, preparing for future use cases where only the OS name is needed. The change introduces a `full` parameter that toggles between complete system information (sysname, release, version, machine) and just the sysname. All existing callers are updated to pass `1` to maintain current behavior. The patch is part of the final refinements to the OS version capability implementation, following extensive review cycles that have already settled the protocol design and core functionality. The change demonstrates good forward-thinking design by making the function more flexible while maintaining its existing contract.
