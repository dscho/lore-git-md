Refactoring patch extracting uname(2) system info collection into a reusable helper function. This is part of the v6 series adding OS version capability to Git's protocol, though this particular patch is a preparatory code quality improvement rather than protocol work.

The patch moves the uname(2) system information gathering from builtin/bugreport.c into a new get_uname_info() function in version.c, making it available for reuse elsewhere. The implementation remains functionally identical - it still collects the same system information (sysname, release, version, machine) and handles errors the same way. The main changes are:
1. Moving the code to version.c with proper header declaration
2. Adding gettext.h include for translation support
3. Standardizing the return value (0/-1 for success/failure)

This refactoring supports the series' goal of including OS information in the protocol by providing a clean way to access system info. The change is straightforward with no behavior modifications, just better code organization. Test coverage is maintained since bugreport's existing tests exercise this functionality. The patch follows the series' pattern of careful, incremental improvements to the version-handling infrastructure.
