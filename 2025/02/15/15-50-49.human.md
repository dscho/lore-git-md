Refactoring patch in the OS version capability series. This is the third patch in v6 of Usman Akinyemi's series to add OS information to Git's protocol capabilities. The patch extracts the `uname()` system call handling from `builtin/bugreport.c` into a new reusable `get_uname_info()` function in `version.c`, with proper error handling and internationalization support.

The change is straightforward - it moves existing functionality while maintaining identical behavior, just making the code more modular for reuse in the OS version feature. The implementation includes proper error handling (preserving the existing error messages) and adds the new function to `version.h` with clear documentation. This is a clean refactoring that follows the project's established patterns, and since it's part of a well-reviewed series that's already addressed all major protocol concerns, it should be uncontroversial.
