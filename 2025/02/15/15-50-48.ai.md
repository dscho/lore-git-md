This is a refactoring patch in the v6 series adding OS version capability to Git's protocol. It extracts string sanitization logic from `git_user_agent_sanitized()` into a new `redact_non_printables()` helper function in version.c, preparing for reuse in upcoming patches. The change replaces manual string handling with `strbuf_detach()` for cleaner memory management.

The patch moves the existing character sanitization logic (which replaces non-printable ASCII and space characters with dots) into a dedicated function. This maintains the same behavior while making the code more modular. The implementation uses `isprint()` from sane-ctype.h for character checks, following the series' earlier standardization on library functions.

Key technical details:
- New static function `redact_non_printables()` in version.c
- Replaces inline sanitization in `git_user_agent_sanitized()`
- Uses `strbuf_detach()` instead of direct buffer assignment
- Maintains same character replacement rules (non-printables and spaces become dots)
- Prepares for reuse in subsequent OS version string handling
