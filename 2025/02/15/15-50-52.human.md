Feature implementation adding OS version to Git's agent capability string. This is the final patch in a well-reviewed series that extends Git's protocol capabilities to include operating system information in the format "package/version-os" (e.g., "git/2.8.3-Linux"). The change helps with debugging OS-specific issues while maintaining backward compatibility.

The patch updates protocol documentation, implements OS info collection via `uname(2)`, and handles Windows platform quirks where `uname(1)` and `uname(2)` outputs differ significantly. Windows support is handled by skipping OS-specific tests rather than adding complex test infrastructure. The implementation includes proper string handling with new sanitization utilities and careful memory management.

This represents the culmination of multiple review cycles, with all major technical concerns addressed. The code is well-structured with clear helper functions (`os_info()`, `redact_non_printables()`) and comprehensive test coverage. The only remaining minor open question is behavior with empty GIT_USER_AGENT, but this doesn't block the feature's usefulness.
