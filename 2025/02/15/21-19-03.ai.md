Build system documentation fix implementing the maintainer-approved solution for Makefile default targets. This v2 patch from Adam Dinwoodie follows Junio Hamano's guidance to use an empty double-colon `all::` rule at the start of Makefiles, fixing a regression where Documentation/Makefile's default target unintentionally changed to only building config files after commit a38edab7c8.

The patch now applies this pattern consistently across 15 Makefiles in the codebase, including Documentation/ and various contrib/ directories. Each modified file gets an explicit `all::` declaration at the top (with a comment explaining its purpose) while keeping the existing build rules. The Documentation/Makefile change specifically restores the original behavior of building both html and man pages by default.

This implementation matches Junio's exact specifications from the thread, using the double-colon syntax seen in t/Makefile and the main Makefile. The changes are mechanical but thorough, covering all relevant Makefiles that lacked explicit default target declarations. The patch maintains backward compatibility while preventing future regressions of this nature through consistent Makefile conventions.
