Bugfix confirmation for `git difftool --dir-diff` segfaults. René Scharfe confirms that the segmentation faults reported by Christoph Anton Mitterer were indeed fixed by commit 98e4015593 ("builtin/difftool: initialize some hashmap variables"), which shipped in Git v2.48.0. The issue stemmed from uninitialized hashmap variables causing memory corruption during cleanup operations. This is a straightforward case where users experiencing crashes with `git difftool --dir-diff` should upgrade to Git 2.48.0 or later to resolve the problem. The thread shows good issue tracking from initial report to confirmed solution.
