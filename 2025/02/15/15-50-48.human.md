Refactoring patch in the OS version capability series. This is patch 2/6 in the v6 iteration of Usman Akinyemi's series to add OS version information to Git's protocol handshake.

The patch extracts string sanitization logic from `git_user_agent_sanitized()` into a new helper function `redact_non_printables()`, which will be reused in later patches. The sanitization replaces non-printable characters and spaces with dots to ensure protocol safety. The change also improves memory handling by using `strbuf_detach()` rather than directly accessing the strbuf buffer.

This is a straightforward code quality improvement that follows the series' pattern of modularizing functionality. The change is currently static-scoped to version.c but will be used by subsequent patches in the series. The implementation looks clean and maintains the existing behavior while making the code more maintainable.
