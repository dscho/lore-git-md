This is a refactoring patch that's part of the OS version capability series (v6 1/6). It replaces manual ASCII range checks in the user agent sanitization code with the standard `isprint()` function for better readability and maintainability.

The change modifies `version.c` to use `isprint()` for checking printable characters while explicitly handling spaces (which were previously caught by the ASCII range check but aren't considered printable by `isprint()`). The patch includes a new include for `sane-ctype.h` to access `isprint()`. This is a straightforward code quality improvement that doesn't change behavior, just makes the intent clearer.

Key technical details for future reference:
- Modifies `git_user_agent_sanitized()` in version.c
- Replaces `buf.buf[i] <= 32 || buf.buf[i] >= 127` with `!isprint(buf.buf[i]) || buf.buf[i] == ' '`
- Maintains identical behavior for space handling
