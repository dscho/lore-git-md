This thread documents a bug in `git difftool --dir-diff` that caused segmentation faults (SIGSEGV) and invalid pointer errors (SIGABRT) during hashmap cleanup, specifically in the `run_dir_diff()` function. The issue was traced to uninitialized hashmap variables leading to memory corruption when freeing entries. 

Christian Couder and René Scharfe identified this as a known bug that was fixed in commit 98e4015593 ("builtin/difftool: initialize some hashmap variables"), which landed in Git 2.48.0. The original reporter, Christoph Anton Mitterer, provided detailed reproduction cases with kernel logs and GDB outputs showing consistent crash points. 

In a follow-up, Mitterer confirmed that Git 2.48.0-rc1 from Debian experimental resolves the issue, verifying that the crashes no longer occur. The fix has now been validated by both the original reporter and core contributors familiar with the hashmap implementation. Users experiencing these crashes should upgrade to Git 2.48.0 or later, as this is a confirmed and resolved issue with no further action needed.
