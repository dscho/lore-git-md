This is a test refactoring patch in the final stages of the OS version capability series. It improves test isolation in t5701-git-serve.sh by separating test setup from assertions.

The patch extracts file generation from the capability advertisement test into a dedicated setup test. This creates reusable test artifacts (agent_capability, expect.base, expect.trailer) that multiple tests can consume, making the test suite more modular and maintainable. The change is purely structural - test behavior remains identical, just better organized.

Key changes:
- Moves file generation into new 'setup to generate files with expected content' test
- Splits the original test into setup and assertion phases
- Maintains all existing test files and their contents
- Prepares for future test additions that will reuse these artifacts

This follows the series' pattern of incremental quality improvements, with Christian Couder continuing to mentor the work. The change demonstrates good test hygiene by removing side effects between tests, though it doesn't add new test coverage since it's purely a refactoring.
