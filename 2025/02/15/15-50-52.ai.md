This is the final patch in a v6 series implementing OS version advertisement in Git's protocol capability string. The feature extends the existing agent` capability format from "package/version" to "package/version-os" (e.g., "git/1.8.3.1-Linux") by incorporating the system's OS name from `uname(2)`.

Key technical aspects:
- Adds OS info collection via new `os_info()` helper that caches sanitized `uname(2)` results
- Modifies `git_user_agent_sanitized()` to append OS info when no custom `GIT_USER_AGENT` is set
- Updates protocol documentation/gitprotocol-v2.txt to specify the new format
- Handles Windows platform differences where `uname(2)` is faked by Git itself
- Adds test support via new `test_redact_non_printables()` helper in test-lib-functions.sh
- Skips OS-specific tests on Windows due to platform inconsistencies
- Maintains backward compatibility with existing agent strings

The implementation builds on previous refinements in the series, including string sanitization helpers and test isolation improvements.
