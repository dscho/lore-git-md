This is a platform compatibility patch in Patrick Steinhardt's ongoing reftable decoupling series, specifically addressing Windows build system organization. The patch splits POSIX-related functionality from Windows-specific compatibility layers in the mingw.h header, moving contents into new mingw/posix.h and mingw/compat-util.h files (220 lines added vs 245 removed across 11 files). Johannes Sixt approves the technical approach but notes that Git-for-Windows maintainer Johannes Schindelin will need to coordinate integration with their additional platform patches. Junio Hamano agrees with involving Schindelin for review given the higher stakes in the Git-for-Windows repository. The changes complete the architectural separation of reftable from Git core by properly isolating POSIX functionality while maintaining Windows compatibility through the new header organization. This represents one of the final steps in making reftable a truly standalone library.
