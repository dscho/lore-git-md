Test patch for MIDX QSORT progress reporting.

This is the second patch in Ayush Chandekar's series adding progress reporting during multi-pack-index verification. It adds test coverage for the QSORT progress meter implemented in the first patch. The test creates 100 objects, repacks them, then verifies that `git multi-pack-index verify --progress` shows the "Sorting objects by packfile" message reaching 100% completion.

The test uses `GIT_PROGRESS_DELAY=0` to ensure immediate progress output and checks for the final 100% state. The author notes they couldn't verify intermediate progress states (0% to 100%) and invites suggestions for how to test this progression. The test is straightforward, following Git's standard test patterns by:
- Creating test objects with `hash-object`
- Repacking with `repack -ad`
- Writing and verifying the MIDX
- Grepping the progress output

The patch adds 14 lines to `t5319-multi-pack-index.sh` and maintains the existing test structure. While it verifies basic functionality, the author acknowledges the test doesn't fully exercise the progress meter's incremental updates. Reviewers may want to suggest:
- Alternative approaches to verify intermediate progress states
- Whether 100 objects provides sufficient test scale
- If the test should be expanded to cover edge cases
- Whether the progress message format matches Git's conventions

This test complements the implementation patch by providing basic verification of the new progress reporting feature.
