Platform compatibility fix for a long-dormant contrib script.

This is the second version of a patch that fixes a bashism in the Thunderbird patch processing script `contrib/thunderbird-patch-inline/appp.sh`. The script had used `echo -e` for 9 years, which isn't POSIX-compliant and breaks on systems using dash as `/bin/sh`. The fix replaces it with portable `printf`.

The v2 patch adds a missing newline that was noted in review, addressing a subtle edge case where `sed` might behave consistently across different implementations when processing input without final newlines. While the author notes they could have used `%s\n`, they chose the current form for better readability.

This maintenance change comes after the initial patch was already accepted into Git's codebase, showing the project's attention to thoroughness even for little-used contrib scripts. The fix is straightforward - just a one-line change to make the script work across all POSIX-compliant shells when processing Cc and Signed-off-by headers in patch emails.

The thread has shown careful consideration of shell scripting portability issues, progressing from the initial bashism fix to addressing more subtle concerns. This script remains in limited maintenance status with its original authors no longer active, making this one of its few updates since 2014.
