Feature enhancement for `git rebase`'s `--update-refs` functionality. This patch introduces a new `interactive` mode for the `--update-refs` option, allowing it to be automatically enabled for interactive rebases while remaining disabled for non-interactive ones. The change addresses a common pain point where users who set `rebase.updateRefs=true` in their config find it updating refs unexpectedly during non-interactive rebases.

The implementation adds `--update-refs=interactive` as both a command-line option and config value (`rebase.updateRefs=interactive`). The config setting is particularly useful for workflows involving multiple interdependent feature branches, where users want automatic ref updates during interactive sessions but not in automated contexts. The patch includes documentation updates and careful handling of the interaction between command-line and config options, ensuring the new mode doesn't inherit unwanted config values when used on the command line.

- New `UPDATE_REFS_INTERACTIVE` enum value
- `parse_update_refs_value()` helper to handle the new option syntax
- `coerce_update_refs()` function to properly handle the interactive case
