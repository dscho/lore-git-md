Windows compatibility refactoring in the reftable separation series. This is patch 15/18 in Patrick Steinhardt's series to fully decouple the reftable library from Git core. The patch splits Windows-specific POSIX compatibility functions from mingw.h into new dedicated headers (mingw/posix.h and mingw/compat-util.h), part of the broader effort to cleanly separate platform-specific code. 

The changes involve significant file reorganization (220 lines added, 245 removed across 11 files) but maintain the same functionality. Johannes Sixt has reviewed and approved the mingw.c changes, while noting that Git-for-Windows maintainer Johannes Schindelin should weigh in given their additional platform-specific patches. Junio Hamano agrees with this cautious approach.

This represents one of the final architectural pieces in making reftable truly standalone - the series has already addressed feedback from multiple reviewers on I/O, memory safety, and include style. With the POSIX/Windows separation now properly structured and Windows maintainers being consulted, the series appears to merge-ready pending any final platform-specific considerations.
