This thread discusses enhancing `git rebase`'s `--update-refs` feature by introducing an interactive mode that automatically enables reference updates during interactive rebases while keeping them for non-interactive ones. The original proposal adds `--update-refs=interactive` as both a command-line option and config value, solving a workflow pain point where users with `rebase.updateRefs=true` in their config get unwanted ref changes during automated rebases.

D. Ben Knoble has reviewed the proposal and suggested two documentation improvements: adjusting the option syntax in docs to match Git's style (`--update-refs[=interactive]`) and clarifying wording about configuration overrides. He also noted the lack of test coverage for the new mode, which should be addressed before finalizing the feature. The core implementation - including the new enum values, parsing logic, and rebase behavior changes - remains sound and ready for merging once these polish items are addressed. The discussion shows careful attention to both user experience and code quality from an experienced contributor.
