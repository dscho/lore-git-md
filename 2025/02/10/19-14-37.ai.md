Refactoring patch introducing a helper function for pattern matching in `git clean`.

This is the first of three patches in a series enhancing `git clean` with persistent exclusion patterns. It extracts the pattern-list creation logic from `builtin/clean.c` into a new helper function `add_patterns_from_string_list()` in `dir.c`, making this functionality available to other parts of the codebase. The change reduces code duplication in `cmd_clean()` while maintaining identical behavior.

Key technical details:
- New public function in `dir.h` that converts a `string_list` to a `pattern_list`
- Implementation in `dir.c` that mirrors the existing pattern addition logic
- Simplification of `builtin/clean.c` by replacing manual iteration with the new helper
- The helper preserves the same negative pattern weights (-1, -2, etc.) as the original code

This appears to be preparatory work for the subsequent patches that will introduce the new `clean.exclude` config option and `--remove-excluded` flag. The change is straightforward and well-contained, touching only pattern handling infrastructure without modifying behavior. The patch follows Git's style conventions and includes appropriate documentation for the new function.
