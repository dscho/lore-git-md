NFSv4 packfile handling bug report and proposed fix for temporary file permissions during failover. Core issue: Git creates temporary packfiles with O_RDWR flags but 0444 permissions, causing EACCES errors when NFSv4 servers recover state after failover in HA environments. Reproduction shows clone operations failing with "Bad file descriptor" when NFS server restarts mid-operation, with kernel logs showing "state recovery failed". Affected code paths: object-file.c (git_mkstemp_mode for temp file creation) and wrapper.c (underlying open() implementation). Problem specifically manifests in HA NFSv4 deployments where failover recovery re-evaluates permissions against the originally-set 0444 mode despite O_RDWR being required for the operation. Bug appears legitimate and well-documented with clear reproduction steps, though impact limited to NFSv4 failover scenarios. Technical analysis indicates this is a genuine bug in Git's temporary file handling rather than a configuration issue.
