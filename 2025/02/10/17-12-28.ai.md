Refactoring patch in the `the_repository` removal effort, with maintainer feedback on commit message verbosity.

Junio Hamano responds to Usman Akinyemi's patch converting `builtin/update-server-info.c` to use an explicit repository parameter instead of `the_repository`. Hamano also observes that despite thinking dumb HTTP walker support might be deprecated, maintaining this code is still worthwhile.
