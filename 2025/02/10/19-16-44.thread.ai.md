Feature enhancement for `git rebase`'s `--update-refs` functionality, introducing an `interactive` mode that automatically enables ref updates during interactive rebases while keeping them disabled for non-interactive ones. This addresses the pain point where users with `rebase.updateRefs=true` in config experience unwanted ref updates during automated rebases.

The implementation adds `--update-refs=interactive` as both command-line option and config value (`rebase.updateRefs=interactive`), particularly useful for workflows with interdependent feature branches. Technical changes include new `UPDATE_REFS_INTERACTIVE` enum, `parse_update_refs_value()` helper, `coerce_update_refs()` function, and updates to rebase documentation. The solution maintains backward compatibility while carefully handling option precedence between config and command-line settings.
