Feature enhancement for `git rebase`'s `--update-refs` option, adding an interactive mode. This is a follow-up to Ivan Shapovalov's patch introducing `--update-refs=interactive` that automatically enables ref updates during interactive rebases while keeping them disabled for non-interactive ones.

D. Ben Knoble suggests improving the documentation formatting to match Git's style by using `--update-refs[=interactive]` syntax, while noting a potential ambiguity about whether this might imply `=interactive` is the default (it isn't). They also raise the important question of whether tests should be added for this new functionality, though the patch itself appears thorough with documentation updates and careful handling of the new interactive mode through enum values and coercion logic.

The implementation looks solid, introducing new `UPDATE_REFS_INTERACTIVE` state and helper functions while maintaining backward compatibility. This would be particularly useful for developers managing multiple interdependent feature branches who want automatic ref updates only when they can review them interactively. The missing test coverage is the main gap noted in this review.
