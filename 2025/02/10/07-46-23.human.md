This is the second patch in a two-part series adding progress reporting for MIDX verification's sorting phase. The patch adds test coverage to verify the progress meter works as expected.

The test creates 100 objects, repacks them, writes a MIDX, then verifies it with progress reporting enabled. It checks that the progress reaches 100% by grepping the output for the completion message. The author notes they couldn't find a way to verify the intermediate progress updates (from 0% to 100%) and invites suggestions for how to test that progression.

The test follows Git's standard patterns - it's self-contained, uses existing test helpers like `test_seq`, and checks the actual output against expectations. The use of `GIT_PROGRESS_DELAY=0` ensures the progress meter will show updates immediately rather than waiting for the default delay period.

This completes the series' goal of adding visibility into what was previously an opaque operation. While the test verifies the basic functionality works, the author's question about testing intermediate progress states suggests there may be room to strengthen the test coverage in future iterations if reviewers have suggestions.
