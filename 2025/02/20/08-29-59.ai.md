This is the final cleanup patch in a series converting oid-related unit tests to the Clar framework, completing the test modernization effort for oid-array, oidmap, and oidtree data structures.

The patch removes the now-obsolete `lib-oid.{c,h}` files and their build system references, as their functionality has been fully migrated to `unit-test.{c,h}` in previous patches. This cleanup:
- Deletes 52 lines of C code from `lib-oid.c` implementing test helpers for OID handling
- Removes 25 lines of header declarations from `lib-oid.h`
- Updates both Makefile and meson.build to stop referencing these files
- Maintains all existing test coverage through the consolidated unit-test infrastructure

The changes are straightforward mechanical removals following the successful migration of all test cases to the Clar framework in patches 1-4. The patch demonstrates the series' success in reducing code duplication by eliminating the standalone OID test library entirely while preserving all test functionality through shared infrastructure.
