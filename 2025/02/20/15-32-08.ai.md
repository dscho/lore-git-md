This is a review comment on the first patch of Usman Akinyemi's completed `the_repository` removal series. Junio Hamano raises several technical concerns about the specific approach taken in the verify-tag conversion (patch 1/12).

The key points are:
1. The change (moving `git_config()` call) is too minor to be called a "refactor"
2. The new config call placement could prevent future configuration of options that are already used (like verbose/format.format)
3. The reasoning about needing to switch from `git_config()` to `repo_config()` is questioned - since this is a top-level command, using `the_repository` would be acceptable
4. Notes that while the command itself could use globals, helper functions it calls might need different treatment

The review suggests the patch may be over-engineering the solution for this particular command, and that some global usage might be acceptable at the top level. This provides important context for understanding the series evolved - the final approach shown in later patches appears to have addressed these concerns through a more systematic methodology.
