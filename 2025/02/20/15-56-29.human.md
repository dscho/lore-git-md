This is a status update on two patch series from Patrick Steinhardt that are nearing integration into Git's main development branches. 

The first series (ps/path-sans-the-repository) is a 16-commit refactoring that completes the conversion of path-related functions to explicitly take repository parameters instead of relying on the global `the_repository`. The changes touch core path handling, submodule functionality, and worktree management. It has already received positive reviews from Karthik Nayak and Jialuo Zhu, and Junio indicates he'll do a final scan before moving it to the 'next' branch.

The second series (ps/build-meson-fixes-0130) contains 14 commits improving the Meson build system, addressing issues with PATH handling, libcurl linking, tool resolution, and Windows CI limitations. This too has been reviewed by Toon Claes and Justin Donnelly, and Junio confirms it appears ready for 'next' after his quick check.

Both series represent mature work that has undergone multiple iterations and review cycles. The path refactoring is part of the long-running effort to eliminate `the_repository` globals, while the Meson fixes continue the project's transition to a more modern build system. Junio's responses suggest these will likely progress toward integration soon.
