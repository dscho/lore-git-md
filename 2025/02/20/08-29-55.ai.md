Test infrastructure patch converting oid` helper functions to Clar framework. This is the first in a 5-part series modernizing oid-related tests by moving them from custom test code to the shared Clar testing infrastructure.

The patch implements two key helper functions in the shared unit-test.{c,h} files that were previously in lib-oid.{c,h}:
1. `init_hash_algo()` - Determines hash algorithm from GIT_TEST_DEFAULT_HASH env var with SHA-1 fallback
2. `cl_parse_any_oid()` - Converts arbitrary hex strings to object_ids, padding with zeros as needed

These functions are required for oid-related tests to work under the Clar framework. The implementation includes assertions to validate input (e.g. checking hash algorithm validity) and handles both SHA-1 and SHA-256 cases. The patch adds 61 lines total (42 in .c, 19 in .h) of well-commented code that will be reused by subsequent patches converting t-oid-array, t-oidmap, and t-oidtree tests.

The changes follow the established pattern of test modernization by:
- Moving helpers to shared location
- Using Clar's assertion macros (cl_assert)
- Maintaining compatibility with existing test behavior
- Including thorough header documentation

This foundational work enables the actual test conversions in later patches while reducing code duplication. The implementation appears careful and complete, with clear documentation of edge cases and warnings about input constraints. As the first step in the series, it sets up the necessary infrastructure without yet removing the old test files.
