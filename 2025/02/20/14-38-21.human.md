Refactoring feedback on test modernization series. Phillip Wood responds to Seyi Kuforiji's patch that moves oid helper functions into the shared unit-test framework as part of converting oid-related tests to Clar. While supportive of the overall test modernization effort, Phillip raises a specific concern about the implementation approach.

The core issue is whether helper functions `get_oid_arbitrary_hex()` and `init_hash_algo()` should be moved to the shared unit-test.{c,h} files. Phillip argues this creates unnecessary dependencies (strbuf.o and hex.o) for all unit tests, when only oid-related tests need these functions. He suggests keeping them in lib-oid.c temporarily and removing them later when no longer needed, rather than adding them to the shared framework.

This is a technical implementation detail in an otherwise well-received series that has already converted tests for oid-array, oidmap, and oidtree to the Clar framework. The series is part of Git's broader test modernization effort mentored by Patrick Steinhardt, aiming to reduce code duplication and standardize test infrastructure. Phillip's feedback focuses on keeping the shared framework lean while still enabling the test conversions to proceed.
