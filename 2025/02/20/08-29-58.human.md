This is the fourth patch in a 5-part series converting Git's oid-related test suites to the Clar unit testing framework. The patch focuses on migrating the oidtree tests, following the same pattern as previous conversions in the series.

The changes include:
- Renaming t-oidtree.c to u-oidtree.c to match Clar conventions
- Replacing custom test assertions with Clar's `cl_assert` macros
- Adding standard Clar initialization/cleanup functions
- Using the shared `cl_parse_any_oid()` helper introduced earlier in the series
- Updating both Makefile and meson.build build systems

The conversion maintains all existing test coverage while making the tests more maintainable through Clar's standardized patterns. The patch follows the same successful approach used for oid-array and oidmap conversions earlier in the series, demonstrating consistent application of the modernization effort across Git's object ID handling tests.

The changes are cleanly implemented and well-motivated as part of Git's broader test infrastructure improvements. With this patch, only one conversion (likely the final patch in the series) remains to complete the oid test modernization effort.
