The suggestion implies that if the repository is using partial clone functionality, this known behavior could explain the pack duplication Pierre saw when trying to use `gc.bigPackThreshold`.

This moves the discussion forward by identifying a concrete technical scenario (partial clones) and potential fix, though it remains to be seen if this applies to Pierre's specific case.
