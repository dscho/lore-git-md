This is a maintenance pull request for gitk, focusing on Windows compatibility and build system improvements. The changes come from multiple contributors and include several distinct fixes and enhancements.

The patch series introduces Meson build system support (Patrick Steinhardt) alongside traditional Makefile builds, with new `meson.build` and `generate-tcl.sh` files added. It addresses Windows-specific issues including Unicode filename handling (Karsten Blees), executable path safety (Johannes Schindelin), and proper icon usage (Sebastian Schuberth). The Tcl/Tk 8.6+ arrow key behavior in input fields is also fixed (Schindelin), while James Raden improves the default width of the reference list" window.

The changes touch core gitk functionality (the main script), build infrastructure (Makefile and new Meson files), and localization support (po/ directory). The merge commits from Johannes Sixt integrate work from multiple contributors' branches, suggesting this is a coordinated effort to modernize gitk's build system while maintaining compatibility. The patch appears well-scoped, with each commit addressing a specific issue and the Meson support being introduced incrementally alongside the Makefile system rather than replacing it outright.
