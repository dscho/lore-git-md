Maintenance update for gitk with Windows improvements and Meson build support. This pull request merges several branches of work into gitk's master, bringing together contributions from multiple developers. The changes include Windows-specific fixes for Unicode filename handling, executable path safety, and proper icon usage, along with Tcl/Tk 8.6+ compatibility for arrow key input. There's also a UI tweak to widen the default "list references" window.

The most notable addition is Patrick Steinhardt's Meson build system support, introduced alongside the traditional Makefile without breaking existing builds. The changes are well-organized, with each commit addressing a specific issue, and the merge commits from Johannes Sixt (gitk's maintainer) show careful coordination of the various contributions. The patch set touches core gitk script, build files, and localization infrastructure, representing a significant but focused modernization effort.
