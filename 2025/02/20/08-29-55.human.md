Test infrastructure patch converting oid helper functions to Clar framework.

This is the first patch in a 5-part series modernizing Git's oid-related unit tests by moving them from custom test code to the Clar framework. The patch implements two key helper functions (`get_oid_arbitrary_hex()` and `init_hash_algo()`) in the shared unit-test.{c,h} files, making them available for all Clar-based oid tests.

The implementation handles object ID parsing and hash algorithm initialization, with careful attention to supporting both SHA-1 and SHA-256 via the GIT_TEST_DEFAULT_HASH environment variable. The code includes assertions to validate inputs and hash algorithm selection. The patch shows good attention to detail with thorough documentation of the new functions' behavior and limitations.

This foundational work will be used by subsequent patches in the series to convert the actual test files. The changes are part of Git's broader test modernization effort mentored by Patrick Steinhardt, following the pattern of previous conversions to the Clar framework. The implementation looks solid and well-documented, setting up the infrastructure needed for the rest of the series.
