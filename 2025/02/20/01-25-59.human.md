This is a follow-up discussion in the ongoing Meson build system integration thread, specifically about static analysis and documentation test coverage.

Ramsay Jones responds to Patrick Steinhardt's v2 patch series that added Meson support for various contrib components (credential helpers, git-contacts, and Coccinelle). While acknowledging the progress made, Jones points out several important test and analysis targets that are still missing from the Meson integration.

The email highlights several key testing areas that remain Makefile-only:
- Static analysis targets (`sparse`, `hdr-check`)
- Documentation checks (`check-builtins`, `check-docs`)
- Coverage reporting (`coverage-test`, `coverage-report`)
- Pot file validation (`check-pot`)

Jones notes these are part of his regular development routine, suggesting they should be prioritized for Meson support. The tone is constructive but makes clear there's still significant work needed to achieve full parity between the build systems, particularly around testing infrastructure. This serves as useful input for Patrick's next iteration of the series, identifying concrete gaps that need addressing.
