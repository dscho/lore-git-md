Verification of fixed bug in `git difftool --dir-diff`. 

Christoph Anton Mitterer confirms that the segmentation fault issues in `git difftool --dir-diff` (previously reported with both SIGSEGV and SIGABRT errors) are indeed resolved in Git 2.48.0-rc1. The fix, which addressed uninitialized hashmap variables causing memory corruption during cleanup, was already identified in the thread as commit 98e4015593. This email serves as positive verification from an affected user that upgrading to the patched version eliminates the crashes. No further discussion appears needed as the solution is confirmed working.
