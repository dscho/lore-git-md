This is the second patch in a 5-part test modernization series converting oid-related tests to the Clar framework. It focuses on migrating the oid-array test suite.

The patch converts t-oid-array.c to u-oid-array.c, making several structural changes to align with Clar conventions:
1. Replaces custom test assertions with Clar's `cl_assert` macros
2. Moves test data arrays to global scope for reuse across test functions
3. Introduces `test_oid_array__initialize()` for explicit hash algorithm setup
4. Splits the single test function into multiple focused test cases (enumerate_unique, lookup_non_existent, etc.)
5. Removes redundant test descriptions since Clar provides better test naming

Key technical changes include:
- Uses the new `cl_parse_any_oid()` helper from patch 1 for hex-to-oid conversion
- Maintains all existing test coverage while making tests more modular
- Updates both Makefile and meson.build to reference the new u-oid-array.c
- Preserves SHA-1/SHA-256 compatibility through hash algorithm detection

The conversion follows established patterns from previous test migrations, removing 62 lines while adding 65 (net +3), with the bulk being test reorganization rather than new logic. This sets up the pattern for the remaining oidmap and oidtree conversions in subsequent patches.
