Bugfix confirmation for `git difftool --dir-diff` hashmap corruption. This is a follow-up email confirming that the segmentation fault issues (both SIGSEGV and SIGABRT variants) in `git difftool --dir-diff` have been resolved in Git 2.48.0-rc1. The original reporter, Christoph Anton Mitterer, verifies that the crashes no longer reproducible when testing the pre-release version from Debian experimental. This confirms the fix introduced in commit 98e4015593 ("builtin/difftool: initialize some hashmap variables") properly addresses the memory corruption during hashmap cleanup that was causing the crashes. The thread can now be considered resolved, with the solution verified by both the original submitter and core contributors. Users experiencing these crashes should upgrade to Git 2.48.0 or later.
