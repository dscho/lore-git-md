Build system integration for static analysis and documentation targets in Meson.

This email from Patrick Steinhardt responds to Ramsay Jones' identification of missing static analysis and documentation targets in the ongoing Meson build system integration. The thread has been focused on adding Meson support for Git's contrib components, with previous work covering credential helpers, git-contacts, and Coccinelle integration.

Key points in this response:
- Acknowledges the oversight of `hdr-check` target
- Confirms coverage reporting is already available in Meson through native functionality (`-Db_coverage=true` flag and `coverage-html` target)
- Indicates plans to address the remaining static analysis/documentation targets (`hdr-check`, `check-pot`, `check-builtins`, `check-docs`) in a future patch series

The exchange shows progress in the Meson integration effort, with Patrick demonstrating responsiveness to feedback while maintaining forward momentum. The thread context shows this is part of a larger effort to unify build systems, with Windows/MSVC, Linux/libsecret, and macOS/osxkeychain support already implemented.
