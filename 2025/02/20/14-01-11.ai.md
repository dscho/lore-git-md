This is a merge commit pulling in multiple Windows compatibility and build system improvements for gitk. The changes integrate work from several contributors through two main branches:

1. The 'g4w-gitk' branch from Johannes Schindelin brings Windows-specific fixes:
   - Safety fix preventing accidental execution of worktree executables
   - Arrow key input handling for Tcl/Tk 8.6+
   - Proper external icon file usage on Windows (Sebastian Schuberth)
   - Unicode filename support (Karsten Blees)

2. The 'pks-meson-support' branch from Patrick Steinhardt introduces Meson build system support while maintaining Makefile compatibility:
   - New `generate-tcl.sh` script for executable building
   - Meson build files (`meson.build` and `po/meson.build`)
   - Core gitk script modifications to support both build systems

The merge also includes a UI tweak from James Raden making the reference list window wider by default. The changes touch core gitk script, build infrastructure (Makefile and new Meson files), and localization support. The work appears well-coordinated with maintainer Johannes Sixt merging the branches after they were tested independently. The Meson introduction is particularly notable as it modernizes the build system while carefully preserving existing workflows.
