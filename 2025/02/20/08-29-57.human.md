Test infrastructure patch converting oidmap tests to Clar framework. This is the third patch in a 5-part series modernizing Git's object ID handling tests by moving them from custom test code to the shared Clar unit testing framework.

The patch converts the oidmap test suite, following the same pattern as the earlier oid-array conversion. Key changes include:
- Renaming t-oidmap.c → u-oidmap.c
- Replacing custom test assertions with Clar's `cl_assert` macros
- Adding explicit initialize/cleanup functions for test setup/teardown
- Using the `cl_parse_any_oid()` helper from earlier in the series
- Updating both Makefile and meson.build configurations

The conversion maintains all existing functionality while making the tests more maintainable through Clar's standardized patterns. The patch appears well-structured and follows the established approach from previous conversions in this series. It's part of Git's broader effort to modernize its test infrastructure under Patrick Steinhardt's mentorship.
