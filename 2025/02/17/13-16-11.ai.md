This is a bugfix patch in the ongoing `git fsck` packed-refs validation series, specifically addressing a race condition in file reading.

1. Open the file while preventing symlink following
2. Verify the filetype via `fstat`
3. Read contents safely with `strbuf_read`

This change strengthens the security of the packed-refs validation by closing a race window where malicious symlinks could be introduced. The fix aligns with the series' goal of rigorous validation while maintaining the existing behavior of gracefully handling missing files (ENOENT case).
