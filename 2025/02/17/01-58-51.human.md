Bugfix for pickaxe (-S/-G) crash on empty strings. Brian Carlson confirms Jared Van Bortel's report that `git log -S ""` and `git log -G ""` trigger an abort in diffcore-pickaxe.c, agreeing this is a clear bug. The maintainer states the proper fix is to reject empty string arguments entirely rather than crashing, since empty strings aren't useful search patterns anyway. A patch implementing this validation is in progress and will be submitted soon. This appears to be a straightforward input validation gap where the pickaxe code asserts the presence of a search string without first checking for empty input. The fix should prevent the crash while maintaining the expected behavior that pickaxe operations require meaningful search terms.
