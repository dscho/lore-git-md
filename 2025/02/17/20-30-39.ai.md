Documentation fix for git-merge-tree manpage formatting.

This is a minor documentation patch fixing a formatting issue in the HTML output of the git-merge-tree manpage. Phillip Wood noticed that a cross-reference to the "OUTPUT" section was incorrectly rendered with square brackets in HTML output due to missing explicit link text in the asciidoc markup. The patch adds the proper link text format "<<OUTPUT,OUTPUT>>" to ensure correct HTML rendering.

Elijah Newren reviews the change, confirming it appears to be the only instance of this formatting issue in git-merge-tree.txt. The fix is straightforward and uncontroversial, addressing a purely presentational issue in the documentation output. This patch appears to be the final documentation polish in the ongoing series about merge-tree --stdin improvements, though it's independent of the earlier functional changes.

The change affects only Documentation/git-merge-tree.txt, modifying a single line to fix the cross-reference syntax. No behavior changes or user-facing impacts beyond the HTML documentation formatting. The patch maintains the existing documentation content while correcting its presentation in web-based formats.
