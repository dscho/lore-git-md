Bugfix for pickaxe (-S/-G) crash with empty string arguments. Brian m. carlson follows up on the earlier discussion with a concrete patch that prevents Git from crashing when given empty strings to `-S` or `-G` options. The fix adds input validation in `diff.c` to reject empty arguments early with a clear error message, rather than letting them trigger an assertion failure in the diffcore backend. The patch includes tests verifying the new behavior.

This is a straightforward solution to a clear bug, implementing the approach discussed in the thread. The change is minimal and focused, adding just two similar validation checks (one each for `-G` and `-S`) plus corresponding tests. The error messages are user-friendly and the exit code (129) follows Git's convention for usage errors. The patch appears ready for inclusion with no obvious issues - it solves the crash while maintaining all existing functionality for valid inputs.
