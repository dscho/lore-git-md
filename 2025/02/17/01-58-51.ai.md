This is a bugfix response to a crash in Git's pickaxe functionality. Brian m. carlson confirms Jared Van Bortel's report that `git log -S ""` and `git log -G ""` trigger an assertion failure in diffcore-pickaxe.c, causing Git to abort with a BUG message. The thread had already established this as a clear validation bug where empty string arguments aren't properly handled before reaching the pickaxe diffcore processing path.

Carlson agrees the current behavior is incorrect and proposes rejecting empty arguments entirely rather than treating them as a no-op, since empty search strings aren't practically useful. They indicate a patch is in progress to implement this validation, with plans to send it for review after CI testing completes. The fix will likely involve adding input validation at the command parsing stage to catch empty strings before they reach the diffcore assertion.

This appears to be a straightforward fix targeting a clear edge case in the pickaxe feature's input handling. The proposed solution (rejection rather than silent acceptance) seems reasonable given that empty strings have no meaningful interpretation in this context. The patch should prevent the crash while maintaining the pickaxe feature's existing behavior for valid inputs.
