The discussion has shifted from implementation details to a more fundamental question of configuration scope. Antonin provides concrete evidence that:
1. The codebase already applies some `format.*` configs to `git show`

This moves the debate beyond theoretical design questions by demonstrating both precedent in the code and tangible user impact. The thread now has clearer stakes - either:
