Bugfix for a crash when using empty pickaxe patterns. Jared Van Bortel reports that passing an empty string to `git log -S` or `git log -G` triggers an assertion failure that crashes Git with a "BUG: should have needle under -G or -S" message. The backtrace shows the crash originates in `diffcore-pickaxe.c` when processing these empty patterns.

This appears to be a straightforward bug where the code doesn't properly validate input before processing. The patch doesn't include a fix yet, but clearly identifies the problematic behavior - Git should either handle empty patterns gracefully or provide a proper error message rather than crashing. The report includes detailed backtraces showing the crash path through the diff and log machinery.

This seems like a real issue that should be fixed, though the impact is limited since it requires the user to explicitly pass an empty string. The report is well-documented with clear reproduction steps and stack traces, making it easy for maintainers to investigate.
