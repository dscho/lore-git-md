Test modernization patch in a series enhancing `git fsck` packed-refs validation. This is the first of 8 patches in v5 of the series, focused on improving test reliability by using subshells to properly handle working directory changes in t/t0602-reffiles-fsck.sh.

The patch converts all test cases in t0602-reffiles-fsck.sh to use subshells when changing directories, ensuring the working directory is properly restored even if a test fails. Previously, tests used explicit `cd repo` and `cd ..` commands which could leave the working directory in an inconsistent state if a test failed between them. The change affects all test cases in the file, wrapping their bodies in `( )` subshells.
