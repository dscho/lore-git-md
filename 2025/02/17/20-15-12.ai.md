This is a refactoring patch in a series addressing `git merge-tree --stdin` improvements. The patch removes redundant error handling code in the stdin processing loop, since `real_merge()` already dies on errors (returning only 0 or 1 for clean/unclean merges). Elijah Newren notes that while the return value is unused in stdin mode (where conflicts are reported via output), it remains meaningful for non-stdin operation, explaining why `real_merge()` keeps its return type. The change simplifies control flow while maintaining identical behavior, continuing the series' theme of cleaning up the merge-tree implementation. The patch has already received positive feedback from the original author.
