Platform compatibility patch in Patrick Steinhardt's reftable decoupling series (v4 15/18). This continues the architectural separation of reftable from Git core by reorganizing Windows compatibility headers.

The patch splits mingw.h into mingw/posix.h (containing POSIX compatibility functions) and mingw/compat-util.h (Git-specific Windows functionality). It makes parallel changes for MSVC compatibility, creating msvc/posix.h and msvc/compat-util.h. The changes include:
- Moving Git-specific functions like path validation and UTF conversion to compat-util.h
- Keeping POSIX emulation in posix.h
- Updating build systems (Makefile, CMake, meson) to reference the reorganized files
- Maintaining identical functionality while improving code organization

This is part of the larger effort to make reftable depend only on system.h and posix.h, eliminating git-compat-util.h dependencies. The changes follow the established pattern of utility replacement seen in previous patches (11-14/18) for RNG, sleep, SWAP and UNUSED macros. Build system updates ensure the new header locations work across all supported Windows build methods (MinGW, MSVC).
