This is a refactoring patch in the `git clone --revision` series, focusing on simplifying the `wanted_peer_refs()` function in `builtin/clone.c`. The function handles mapping server refs to local refs during cloning.

The main change consolidates the code paths for single-branch and regular clones, eliminating duplicate logic and reducing nesting. Previously, `option_single_branch` had its own separate path with similar fetch mapping logic. Now it modifies the refs list upfront and shares the common mapping code. The patch also improves memory management by properly freeing temporary refs.

The changes appear well-contained and maintain the same behavior while making the code more maintainable. This is part of a larger effort that has gone through multiple rounds of review, with this particular refactoring helping pave the way for the new `--revision` functionality while cleaning up technical debt in the clone machinery.
