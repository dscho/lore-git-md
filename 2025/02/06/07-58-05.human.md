This is part 9 of Patrick Steinhardt's 16-patch series refactoring path-handling functions to remove reliance on `the_repository` global. The patch changes `get_worktree_git_dir()` to return an allocated string rather than a static buffer, making its memory ownership consistent with other repository-aware path functions being introduced in the series.

The change affects several worktree-related operations across 8 files (branch checking, fsck, receive-pack, worktree commands, reachability checks, and revision walking). Each caller now needs to free the returned string, which the patch handles by adding appropriate `free()` calls. The rationale is that while the previous implementation avoided allocations by using static buffers, the performance impact is negligible since none of these operations are in hot paths.

This continues the series' systematic approach of standardizing path-handling interfaces before removing the old global-dependent versions. The patch is straightforward mechanical conversion with no behavior changes beyond memory management, and follows the established pattern seen in earlier parts of the series.
