This is a feature patch introducing long option names for Git's pickaxe search functionality (`-S` and `-G` options). The patch is version 3 of a series, now split from gitk changes per feedback.

The patch adds `--patch-modifies` as an alias for `-S` and `--patch-grep` for `-G`, making these powerful but cryptically-named options more discoverable and self-documenting. The changes span documentation updates across multiple man pages (diff-options, git-blame, gitdiffcore) and corresponding test updates to verify the new names work identically to their single-letter counterparts.

The implementation touches core diff machinery (diff.c, diff.h) to add the new option names while maintaining backward compatibility. Test coverage appears thorough, with the t4209 test file getting significant updates to exercise both old and new option names across various scenarios.

The author has incorporated feedback from the previous round by separating gitk changes, though leaves open whether those should be a follow-up or part of this series. The patch appears well-constructed with documentation and tests updated in lockstep with the code changes.
