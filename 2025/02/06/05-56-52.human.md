This is a bugfix series (v3, 8/8) that enhances validation checks for packed-refs files. The series builds on previous versions that introduced comprehensive validation, now incorporating refinements from Patrick Steinhardt and Junio Hamano's feedback.

Key changes in this version:
1. Improved commit messages and documentation throughout the series
2. Removed unnecessary header checks and related tests
3. Added code enhancements suggested by Patrick Steinhardt
4. Added comments explaining pointer handling in peeled line parsing
5. Implemented sortedness verification when the "sorted" trait is present in the header
6. Added a new `--[no-]references` option to control ref database checking

The series touches several areas:
- Header validation now only checks for the required "# pack-refs with:" prefix
- Entry validation includes comprehensive checks for OIDs, spacing, refnames, and NUL characters
- Sortedness verification is performed when explicitly declared in the header
- The new `--[no-]references` option gives users control over ref validation

The implementation appears thorough, with good test coverage in t0602-reffiles-fsck.sh. The changes maintain backward compatibility while adding stronger validation where needed. The series seems ready for final review, with most previous feedback addressed.
