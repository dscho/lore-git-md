This is part 13/18 of Patrick Steinhardt's series to fully decouple the reftable library from Git's core infrastructure. The patch replaces Git's `SWAP()` macro with a reftable-specific `REFTABLE_SWAP()` implementation, continuing the effort to eliminate all Git-specific utility functions from the reftable codebase.

The change is straightforward - it introduces a new macro in basics.h that performs the same swap operation but without depending on Git's implementation. The patch updates four files that previously used `SWAP()` to use the new macro instead. The implementation includes a clever buffer size calculation that maintains type safety while avoiding direct sizeof comparisons.

This is a low-risk change that follows the established pattern seen in earlier patches of the series. The commit message clearly explains the motivation (reducing Git dependencies) and notes the need to replicate the size-checking behavior of the original macro. The change appears well-contained and maintains the same functionality while moving reftable closer to complete independence.
