This is part of the ongoing `the_repository` removal effort, specifically targeting the `difftool` command. The patch moves several global variables into a new `difftool_options` struct, including `trust_exit_code`, `has_symlinks`, and `symlinks`. This is a refactoring change that doesn't modify behavior but prepares for future work to eliminate global state.

The changes affect how difftool handles configuration (via the new `difftool_config` callback), symlink operations (through modified `get_symlink` and related functions), and directory diff execution (in `run_dir_diff`). The patch updates all call sites to use the new struct rather than the previous global variables.

Key technical details include:
- New `struct difftool_options` containing the migrated variables
- Configuration callback now takes the struct as context
- `get_symlink` and `run_dir_diff` functions modified to accept the options struct
- Command-line options updated to reference struct fields instead of globals
- Environment variable handling for `GIT_DIFFTOOL_TRUST_EXIT_CODE` remains but uses the struct

This appears to be a straightforward refactoring with good test coverage implied by the lack of test changes needed. The changes are mechanical and focused, touching only the difftool implementation without affecting other parts of Git. As the first in a 3-part series, it lays groundwork for further work in this area.
