This is part 4 of Patrick Steinhardt's 16-patch series refactoring path-handling functions to remove dependencies on `the_repository` global state. The patch focuses on `submodule_to_gitdir()`, which resolves submodule paths to their git directories.

The function previously relied on `the_repository` internally when looking up submodule information. The patch makes this explicit by adding a `struct repository` parameter, requiring callers to pass in the repository they're working with. The changes are mechanical but touch several key areas - submodule handling, path resolution, and ref storage - with straightforward updates to 5 files (submodule.c, path.c, refs.c, etc.).

This continues the series' pattern of making repository dependencies explicit while maintaining existing behavior. The changes are clean and focused, with all callers updated to pass `the_repository` where they previously relied on the implicit global. As with previous patches in the series, this is a building block toward the larger goal of removing `the_repository` usage across Git's codebase.
