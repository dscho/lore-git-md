This is a feature patch proposing more descriptive argument names for Git's pickaxe search options (`-S` and `-G`). The patch is the third version of a series, now split from gitk changes per feedback.

The change introduces new long option names `--patch-modifies` (for `-S`) and `--patch-grep` (for `-G`) to make these powerful but cryptically-named options more discoverable and self-documenting. The implementation touches documentation across several man pages, updates the diff machinery to recognize the new names, and adjusts related tests.

The patch appears well-considered, with thorough updates to documentation and test cases. The v3 iteration shows responsiveness to review feedback by separating gitk changes into a future patch. The core idea seems uncontroversial - improving command-line UX by adding more descriptive aliases for existing functionality - though the exact naming choices may invite discussion (particularly whether "modifies" and "grep" are the most intuitive verbs for these operations).
