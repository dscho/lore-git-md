Junio Hamano provides review feedback on the patch introducing long option names for Git's pickaxe options (`--patch-modifies` for `-S` and `--patch-grep` for `-G`). While generally supportive of the feature, he raises several concerns about the implementation details.

The main critique focuses on documentation changes, where Junio argues against wholesale replacement of short options with long ones in existing text, calling it "unwelcome and needless churn." He suggests a more balanced approach - introducing both forms initially but keeping existing documentation mostly unchanged afterward. He also notes some technical issues like inconsistent indentation and suggests separating unrelated changes (like message rewording) into distinct patches.

Junio approves of the core implementation but wants the documentation approach refined. The feedback indicates this is nearing final review, with only presentation-level issues remaining before the core changes can be merged.
