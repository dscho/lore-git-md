This is part of Patrick Steinhardt's v4 series (18 patches) to fully separate the reftable library from Git core infrastructure. The series has already addressed most major technical concerns through rigorous review.

The current patch removes the final Git-specific dependency in reftable/record.c by replacing `COPY_ARRAY()` with an open-coded memory copy. This continues the architectural goal of making reftable completely independent from Git's utility functions. The change also includes a safety improvement - it now guards against potential NULL pointer dereferences when copying zero-sized arrays, which could previously trigger out-of-memory errors.

The implementation carefully maintains the same memory safety guarantees while eliminating the Git dependency. The patch appears straightforward and well-justified as part of the larger reftable decoupling effort, which has already received positive feedback on its technical approach from multiple reviewers. This seems like a clean, focused change that moves the series closer to completion.
