Build system patch completing the reftable library separation series.

This final patch in Patrick Steinhardt's 18-part series excludes the reftable library from Coccinelle semantic patching, since the now-fully-separated reftable code no longer uses Git's helper functions that Coccinelle checks for. The change prevents false positives from rules that would suggest converting patterns to Git-specific implementations.

The modification is straightforward - adding `reftable/%` to the filter-out list in the Makefile's `COCCI_SOURCES` definition. This builds on the architectural work done in previous patches to completely decouple reftable from Git's internals, including the removal of all `git-compat-util.h` dependencies and the creation of standalone POSIX compatibility layers.

With this change, the reftable library is now fully independent from Git's build infrastructure checks, matching its architectural independence established earlier in the series. The patch maintains consistency with the series' goal of making reftable usable by external projects while preserving Git's internal functionality. No behavioral changes are introduced - this is purely a build system adjustment reflecting the completed separation.
