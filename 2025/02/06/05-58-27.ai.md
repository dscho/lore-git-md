Test modernization patch in a refs/fsck validation series.

This is the first patch in v3 of an 8-part series improving packed-refs validation. The patch converts test scripts to use subshells for directory changes rather than manual `cd`/`cd ..` pairs, preventing working directory pollution if tests fail mid-execution. The change affects `t/t0602-reffiles-fsck.sh`, wrapping all test blocks in subshells while preserving the existing test logic and error checking.

Key technical details:
- Modifies 967 lines across the test file (494 insertions, 473 deletions)
- Maintains all existing test assertions and error message checks
- Preserves the test's focus on refname validation, content checking, and symref handling
- Keeps worktree-related test cases intact
- Follows the pattern of wrapping each test block in `( cd repo && ... )`

The change is straightforward and mechanical, with no behavior modifications beyond the directory handling improvement. It addresses a potential reliability issue where failing tests could leave the test environment in an inconsistent state. The patch has been reviewed by mentors Patrick Steinhardt and Karthik Nayak.
