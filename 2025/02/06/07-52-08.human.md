Bugfix in the reftable library decoupling effort. This patch (6/18 in v4 series) removes the last remaining `BUG()` call from the reftable library by converting `reftable_record_cmp()` to return an error code rather than aborting when comparing records of different types. The change propagates through several callers in merged.c and pq.c, requiring them to handle the new error condition. Test cases are updated to verify the new behavior.

The modification is part of Patrick Steinhardt's ongoing work to fully separate the reftable implementation from Git's core infrastructure. This particular patch addresses a key architectural concern - library code should never abort execution but instead allow callers to handle errors. The changes maintain existing functionality while making the behavior more appropriate for a standalone library.

The patch appears well-constructed with thorough updates to both implementation and tests. It follows the series' pattern of careful, incremental changes to achieve the decoupling goal while preserving correctness. The only notable impact is slightly more verbose error handling in calling code, which seems a reasonable tradeoff for proper library behavior.
