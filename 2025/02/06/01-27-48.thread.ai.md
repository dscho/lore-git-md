Git-p4 Python interpreter path issue. Thread reports `git p4` commands failing when Python isn't in default PATH due to shebang line using `python` rather than `python3`. Problem manifests as cryptic errors during `git p4 clone` on systems where `python` isn't symlinked to Python 3 (e.g., Debian with Git 2.30.2). Reporter demonstrates workaround by manually changing shebang to `python3` and suggests this should be updated since Python 3 is now standard. Core issue involves modernizing script's Python version dependency while considering backward compatibility for systems still using Python 2. No maintainer response or proposed patch yet.
