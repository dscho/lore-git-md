This is part of the ongoing `the_repository` removal effort, specifically targeting `git difftool`. David Aguilar's patch eliminates global variables in the difftool implementation by moving them into a new `difftool_options` struct. This is the first of three patches in the series.

The changes are mechanical but thorough, converting three global variables (`trust_exit_code`, `has_symlinks`, and `symlinks`) into struct members. The patch updates all affected functions to take the struct as a parameter, including the changes to config handling and the core directory diff logic. The behavior remains identical - this is purely a refactoring to prepare for future repository independence work.

The implementation looks clean and focused, with all the expected call sites updated consistently. The commit message could benefit from mentioning why these particular globals were targeted (they appear to be the only ones in difftool.c), but the code changes themselves appear correct. This seems like a straightforward step in the larger effort to remove reliance on the global repository state.
