This is a refactoring patch in the `--revision` clone option series, specifically introducing a `struct clone_opts` to encapsulate clone state. The patch focuses on moving global variables into this new container as part of the broader effort to clean up `builtin/clone.c`.

The key changes include:
1. Introducing `struct clone_opts` with an initial field `wants_head` to track whether HEAD should be fetched from the remote (disabled when both `--single-branch` and `--branch` are specified)
2. Modifying `wanted_peer_refs()` to take the new struct as a parameter and restructuring its logic to use the `wants_head` flag
3. Moving the `tail_link_ref()` helper function from remote.c to remote.h since it's now needed by the refactored clone code
4. Updating the clone command to initialize and use the new struct

The patch maintains all existing functionality while improving code organization. The `wants_head` field is specifically designed to support future needs in the series, though its immediate use is limited to the single-branch-with-branch case. This is part of a systematic effort to eliminate globals in preparation for the new `--revision` feature, with subsequent patches expected to move more state into the struct.
