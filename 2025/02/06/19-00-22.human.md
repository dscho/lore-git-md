This is a bugfix release announcement for Tig (the ncurses Git interface), version 2.5.12. The release primarily addresses a regression in 32-bit x86 builds where the blame view would appear empty when opened from the diff view.

The announcement comes from Thomas Koutcher, who notes this is a targeted fix for issue #1362. The changes are minimal (4 files modified with 12 lines changed) and focused specifically on the i586 architecture regression. The release includes updates to documentation (INSTALL.adoc and NEWS.adoc) alongside the actual code fix in src/diff.c.

For those unfamiliar, Tig is a text-based Git repository browser that also provides commit staging capabilities and can serve as a pager for Git command output. The announcement includes links to the project homepage, manual, and download locations. This appears to be a straightforward maintenance release addressing a specific platform issue rather than introducing new features.
