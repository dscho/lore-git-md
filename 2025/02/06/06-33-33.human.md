This is a refactoring patch in a 7-part series introducing a new `--revision` option for `git clone`. The series has gone through six iterations with all technical implementation and documentation finalized.

This specific patch (5/7) introduces a `struct clone_opts` to encapsulate clone state, starting with a `wants_head` field that tracks whether we need the remote HEAD (disabled when both `--single-branch` and `--branch` are given). The change:
- Moves ref handling logic into the new structure
- Makes `tail_link_ref()` helper function available in remote.h
- Simplifies `wanted_peer_refs()` by using the new struct
- Maintains all existing functionality while improving code organization

The patch is part of a larger effort to clean up global variables in `builtin/clone.c` in preparation for the new `--revision` feature. It follows established patterns seen in earlier patches of the series and has been reviewed by multiple contributors. The changes are focused and well-contained, with clear commit messages explaining both the immediate change and its context in the larger series.
