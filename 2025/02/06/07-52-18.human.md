This is part 16/18 of Patrick Steinhardt's series to fully separate the reftable library from Git's core infrastructure. The change moves 541 lines of POSIX-related definitions (file operations, time functions, socket handling, etc.) to the new header while maintaining all functionality. This is a key architectural step in the reftable decoupling effort, as it allows the reftable library to depend only on the POSIX-emulation layer without pulling in Git-specific code.

The implementation appears thorough, preserving all existing behavior while improving code organization.
