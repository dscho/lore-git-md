This is the fifth patch in Patrick Steinhardt's 16-part series refactoring path-handling functions as part of the `the_repository` removal effort, focusing on submodule path resolution. The patch standardizes the `repo_submodule_path()` family of functions to match the pattern established in earlier patches for common, gitdir, and worktree paths.

The key changes introduce three new repository-aware variants of submodule_path functions: `repo_submodule_path()` (allocates new string), `repo_submodule_path_append()` (appends to existing buffer), and `repo_submodule_path_replace()` (replaces buffer contents). These replace the older `git_pathdup_submodule()` and `strbuf_git_path_submodule()` functions. The implementation centralizes path construction in `do_submodule_path()` which now takes an explicit `struct repository` parameter.

The patch modifies 5 files with 53 insertions and 26 deletions, updating callers in `submodule--helper`, test helpers, and worktree code to use the new interfaces while maintaining existing behavior. Like previous patches in the series, this continues the systematic conversion from implicit `the_repository` usage to explicit repository parameters, with careful attention to error handling and memory management. The changes are consistent with the series' architectural approach while tackling the specific case of submodule path resolution.
