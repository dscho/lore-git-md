Maintainer response about git-p4 Python interpreter path issue. Brian M. Carlson responds to a bug report about `git p4` failing when Python isn't in PATH by noting the shebang line uses `python` rather than `python3`. The response clarifies that the shebang is intentionally left as `python` to maintain compatibility with systems still using Python 2.7, despite Python 3 being the modern default. The maintainer suggests the reporter either set PYTHON_PATH during compilation (for self-built Git) or ensure their package maintainer properly configured the Python dependency. This confirms the issue is known but indicates no immediate plans to change the default shebang due to backward compatibility concerns. The response also notes that while Python upstream allows `python` to refer to any version, most distributions still map it to Python 2.
