Platform compatibility follow-up regarding `git p4`'s Python interpreter path. Illia Bobyr responds to brian m. carlson's position about maintaining `python` (rather than `python3`) in the shebang for backward compatibility, providing a counterexample from Ubuntu 24.10 where `python` does point to Python 3.12.7 by default through the `python-is-python3` package. The email notes Ubuntu offers both `python-is-python2` and `python-is-python3` packages to let users choose their default Python version, suggesting the landscape is shifting toward Python 3 as the default even when invoked as `python`. This adds nuance to the thread's core tension between backward compatibility and modern Python 3 adoption, showing that some major distributions now align with Python 3 by default while still allowing version switching. No patch is proposed solution here — the email serves to update the compatibility assumptions with current Ubuntu behavior.
