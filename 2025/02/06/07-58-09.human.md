This is part of Patrick Steinhardt's ongoing `the_repository` removal effort, specifically patch 13/16 in the series. The patch introduces a new `repo_settings_clear()` function to properly handle cleanup of repository settings.

The change centralizes the clearing of `struct repo_settings` which was previously open-coded in `repo_clear()`. The new function properly handles freeing the fsmonitor field and resets all settings to their defaults. This improves maintainability by ensuring future additions to the structure will automatically get proper cleanup behavior without requiring changes in multiple places.

The patch is a straightforward refactoring that:
1. Adds the new `repo_settings_clear()` function declaration in repo-settings.h
2. Implements the function in repo-settings.c with proper memory management
3. Updates `prepare_repo_settings()` and `repo_clear()` to use the new function

This continues the series' pattern of methodically cleaning up repository-related functionality while maintaining consistent behavior. The change is small (10 lines added, 3 removed) but helps untangle the repository cleanup logic.
