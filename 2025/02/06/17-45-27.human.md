Documentation patch completing the HTTP archive support feature. This is the second version of a straightforward addition to `git-http-backend.txt` documenting the `http.uploadarchive` configuration option introduced in Git 2.44.0. The option enables 'git archive' operations over HTTP/HTTPS when set to true (defaulting to false) and requires protocol version 2.

Piotr Szlazak's patch adds four lines of documentation following the style of adjacent HTTP config options like `http.receivepack`. The only change from v1 is a minor wording improvement to the commit message ("Add missing documentation" replacing the original phrasing), as suggested by Junio Hamano in his review. The documentation accurately describes the option's default state and protocol requirements.

The patch appears ready for inclusion, having received positive review feedback with no outstanding technical concerns. This completes the documentation for a feature that was technically implemented in 2.44.0 but lacked user-facing documentation until now. The change is small and focused, matching the style of existing HTTP-related documentation in the same file.
