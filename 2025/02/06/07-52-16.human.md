This is part 14/18 of Patrick Steinhardt's series to fully decouple the reftable library from Git's core infrastructure. The patch removes the final dependency on Git's `UNUSED` macro by introducing a reftable-specific `REFTABLE_UNUSED` alternative.

The change is straightforward - it replaces all instances of `UNUSED` parameter annotations with the new macro, which is defined to simply cast the parameter to void. This is a slightly less strict approach than Git's version (which also suppresses compiler warnings), but sufficient for reftable's needs while avoiding compiler-specific logic.

The patch touches several key reftable files (basics.h, blocksource.c, iter.c, record.c, writer.c) but makes no functional changes - it's purely about removing the Git dependency. The implementation follows the established pattern seen in earlier patches of this series, where Git-specific utilities are replaced with reftable-specific equivalents.

This continues the series' steady progress toward complete independence, with all major technical concerns already addressed in previous rounds. The change is low-risk and well-contained, affecting only internal implementation details while maintaining identical behavior.
