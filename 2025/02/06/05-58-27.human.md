This is a test modernization patch that's part of a larger series (v3 1/8) improving packed-refs validation. The patch converts test scripts to use subshells for directory changes rather than explicit `cd` commands, making the tests more robust by ensuring working directory changes are properly reverted even if tests fail.

The change affects `t/t0602-reffiles-fsck.sh`, wrapping all test blocks in subshells to contain directory changes. This prevents test pollution when tests fail mid-execution, as the subshell automatically restores the original working directory when it exits. The patch is mechanical in nature, with nearly 500 lines of test code being indented to fit within the new subshell structure.

- Mentorship from established contributors (Patrick Steinhardt and Karthik Nayak)
- No functional changes to the actual test logic
- just improved test hygiene
- Clean application to all relevant test cases in the file
