This is part 7 of Patrick Steinhardt's 16-patch series to remove dependency on `the_repository` global by refactoring path-handling functions. The series is systematically converting repository-aware path APIs across Git's codebase.

This patch removes the `git_pathdup()` function in favor of `repo_git_path()`, which serves the same purpose but takes an explicit repository parameter instead of relying on the global `the_repository`. The change is straightforward - it updates all callers to use the new function while passing `the_repository` as the first parameter, maintaining the same behavior but with explicit repository context.

The patch touches 16 files with mostly mechanical changes (22 insertions, 36 deletions), converting calls in various commands like `bisect`, `am`, `clone`, and `fsck`. The changes are consistent with the series' pattern of first introducing repository-aware variants (done in earlier patches) and then removing the deprecated global-dependent functions.

This continues the series' second phase of eliminating deprecated functions after their callers have been converted. The change is low-risk since all callers were already updated in previous work, and the patch simply removes the now-unused wrapper function. The work positions Git for eventual removal of `the_repository` by methodically standardizing path resolution interfaces.
