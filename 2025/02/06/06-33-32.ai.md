This is a refactoring patch in the `--revision` clone option series, focusing on tag refspec handling. The patch simplifies the code by moving tag refspec processing earlier in the clone operation, specifically before calling `refspec_ref_prefixes()`. 

The key change is appending the `TAG_REFSPEC` directly to `remote->fetch` upfront when tags are requested (either explicitly via `--tags` or implicitly via `--branch`), rather than handling tags separately in `wanted_peer_refs()`. This eliminates the need for temporary tag refspec handling in that function. The patch also ensures `option_tags` is disabled for `--mirror` clones since they already mirror all refs including tags.

The refactoring removes 16 lines while adding 11, with the main changes being:
- Removal of tag refspec handling from `wanted_peer_refs()`
- Early addition of `TAG_REFSPEC` to `remote->fetch` when appropriate
- Explicit `option_tags = 0` when `--mirror` is set
- Removal of now-unnecessary tag prefix pushing in the transport setup

This change builds on previous refactorings in the series and helps streamline the code path in preparation for the new `--revision` functionality. The patch maintains all existing behavior while making the tag handling logic more straightforward by unifying it with the main refspec processing.
