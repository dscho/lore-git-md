This is the final patch in Patrick Steinhardt's 18-part series to fully decouple the reftable library from Git's core infrastructure. The series has been through rigorous review iterations addressing build system integration, memory safety, and I/O independence.

The patch excludes reftable library sources from Coccinelle checks since the library no longer uses any Git-specific helper functions that Coccinelle would analyze. This prevents false positives from rules that expect Git helper usage. The change is minimal - just adding `reftable/%` to the filter-out list in the Makefile.

With this patch, the architectural separation of reftable is complete. The library now depends only on its own system.h/system.c interface and isolated POSIX functionality, making it usable by external projects like libgit2 while maintaining Git's internal functionality. Only a minor header inclusion style discussion remains open from earlier reviews.
