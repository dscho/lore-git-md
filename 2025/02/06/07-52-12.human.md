This is part 10 of Patrick Steinhardt's 18-patch series to fully decouple the reftable library from Git's core infrastructure. The series has undergone extensive review and is now in its fourth iteration with all major technical concerns addressed.

The current patch removes one of the last remaining Git-specific dependencies by eliminating the use of the `ARRAY_SIZE()` macro in the reftable reader. Instead, it uses the standard C idiom `sizeof(array)/sizeof(*array)` to calculate array length. This change follows the established pattern in the series of replacing Git utilities with standard or reftable-specific implementations.

The modification is straightforward - a single line change in `reader.c` that replaces the macro with direct array size calculation. The patch maintains identical behavior while further reducing reftable's dependence on Git internals. As with previous patches in the series, this change is well-contained and unlikely to be controversial.

This continues the series' steady progress toward complete architectural separation, with only minor stylistic discussions remaining open. The patch appears ready for inclusion, following the high standard of quality seen throughout this carefully executed refactoring effort.
