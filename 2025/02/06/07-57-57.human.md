This is the first patch in a 16-part series refactoring path-handling code as part of the ongoing `the_repository` removal effort. Patrick Steinhardt begins by standardizing the inconsistent family of functions that compute paths in Git's common directory (shared across worktrees).

The patch introduces three new variants of path-computing functions with clear semantics: `repo_*_path()` returns an allocated string, `repo_*_path_append()` adds to an existing buffer, and `repo_*_path_replace()` overwrites a buffer's contents. This replaces the previous mix of `strbuf_git_common_path()` and other ad-hoc approaches. The changes affect several core areas including loose object handling, ref storage, and worktree management.

The refactoring appears thorough and well-motivated, with clear documentation of the new interface in path.h. The patch updates all callers to use the new functions, touching 6 files with mostly straightforward mechanical changes. This foundational work sets the pattern for the rest of the series' systematic elimination of implicit repository state dependencies.
