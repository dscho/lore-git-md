This thread announces the release of tig (a text-mode interface for Git) version 2.5.12, which fixes a specific issue affecting 32-bit x86 systems. The regression caused empty blame views when opened from the diff view. The fix, tracked as issue #1362 in tig repository, was implemented by Thomas Koutcher and involves minimal changes to just four files. The release follows tig's standard format, including project resources and a brief description of tig for new users. This is a maintenance release focused solely on addressing this platform-specific bug, with no new features or broader changes included.
