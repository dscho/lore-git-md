This is the second patch in a three-part series refactoring Git's `difftool` command as part of the `the_repository` removal effort. Building on the first patch's introduction of `struct difftool_options`, this change systematically removes all direct uses of the global `the_repository` variable throughout `builtin/difftool.c`.

The patch modifies function signatures to accept a `struct repository*` parameter, propagating it through the call stack to replace `the_repository` accesses. Key changes include:
- Updating `parse_index_info()` to use `repo->hash_algo` for object ID parsing
- Modifying `use_wt_file()` and `changed_files()` to index files through the passed repository
- Adjusting `get_symlink()` and `run_dir_diff()` to read objects via the repository parameter
- Changing the main `cmd_difftool()` to properly pass through the repository parameter and use `repo_config()`

The changes are mechanical but thorough, touching nearly all major functions in the file. The patch maintains all existing functionality while removing global state dependencies. As with the first patch, no test modifications were needed, suggesting the changes are behavior-preserving. This continues the series' clean separation of concerns, with this patch focusing specifically on repository access patterns.
