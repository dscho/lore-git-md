This thread is about adding long option names (`--patch-modifies` and `--patch-grep`) as more discoverable aliases for Git's pickaxe search options (`-S` and `-G` respectively). The series, now at version 4, has been refined based on Junio Hamano's feedback into 10-patch set that focuses on core changes while deferring gitk integration to a future effort.

The latest patch (4/10) improves the help text in diff.h to properly document both forms of the `-G`/`--pickaxe-grep` option, which searches for patches containing lines matching a regex. It also clarifies that `--pickaxe-all` works with both pickaxe variants. This follows earlier patches that fixed test descriptions and option documentation, with later patches planned to update tests and other documentation to use both forms.

The implementation is technically complete, with all tests passing for both short and long options. Remaining discussion centers on documentation style questions like placeholder naming consistency and terminal width considerations for the expanded help text. The series shows steady progress toward its goal of making pickaxe options more accessible while maintaining backward compatibility.
