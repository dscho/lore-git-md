This is the first patch in a 7-part series introducing a new `--revision` option for `git clone`. The series is now in its final iteration (v7) and has been thoroughly reviewed, with all technical concerns addressed.

This particular change is a preparatory refactoring that moves global variables in `builtin/clone.c` into the `cmd_clone()` function scope where they are actually used. The patch converts 195 lines of global variable declarations into local variables, significantly reducing the file's global state. Key changes include:
- Moving the `builtin_clone_options` array and all related option variables into `cmd_clone()`
- Converting global string lists (`option_not`, `option_config`, `server_options`) to local variables with proper initialization
- Adding cleanup for these string lists before function exit
- Maintaining all existing functionality while improving code organization

The refactoring is part of the larger effort to make the codebase more maintainable before adding the new `--revision` feature. While this patch doesn't introduce user-visible changes, it's a substantial internal cleanup that makes subsequent changes in the series easier to implement and review. The patch has been verified through the full test suite and received maintainer approval in previous iterations.
