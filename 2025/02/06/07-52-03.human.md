This is a refactoring patch in Patrick Steinhardt's v4 series to fully separate the reftable library from Git core infrastructure. The patch removes one of the last Git-specific functions (`read_in_full()`) from the reftable code by open-coding its functionality in `reftable/stack.c`.

The change replaces `read_in_full()` with a direct read loop that handles the same basic error cases (EAGAIN/EINTR) but omits the Git-specific `handle_nonblock()` logic since reftable doesn't use non-blocking I/O. The implementation maintains the same safety checks and error handling while reducing dependencies on Git internals.

This is part of the broader architectural effort to make reftable a standalone library, with all major technical concerns already addressed in previous iterations. The change is straightforward and maintains the same behavior for reftable's use case while removing another Git dependency.
