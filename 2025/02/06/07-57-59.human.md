This is the third patch in Patrick Steinhardt's 16-part series refactoring path-handling functions as part of the `the_repository` removal effort. Following the pattern established in the first two patches, it standardizes the "worktree" family of path functions.

The patch introduces three consistent variants for worktree path handling: `repo_worktree_path()` (returns allocated string), `repo_worktree_path_append()` (appends to buffer), and `repo_worktree_path_replace()` (replaces buffer contents). This replaces the previous mix of `strbuf_repo_worktree_path()` and other inconsistent approaches. The changes affect 3 files (path.c, path.h, repository.c) with 33 lines added and 19 removed.

The work continues the systematic conversion of path-related APIs to use explicit repository parameters rather than relying on the global `the_repository`. The patch maintains the same careful approach seen earlier in the series, with clear documentation updates and attention to edge cases (like handling NULL when no worktree exists). This is part of the first phase of the series focused on unifying path-access interfaces.
