This is patch 16/18 in Patrick Steinhardt's v4 series completing the architectural separation of the reftable library from Git core infrastructure. The patch focuses on splitting the POSIX-emulation functionality out of git-compat-util.h into a new compat/posix.h header.

The change moves 541 lines of POSIX-related definitions and compatibility wrappers (file operations, time functions, socket handling, etc.) into the new header while keeping Git-specific utilities in git-compat-util.h. This separation is key for the reftable library to use POSIX functionality without pulling in Git-specific dependencies. The patch maintains all existing functionality while improving code organization - it's a straightforward code movement with no behavior changes.

Key technical details include:
- New compat/posix.h header containing all POSIX emulation code
- Preserved functionality for mmap, file operations, time handling, sockets, etc.
- Maintained platform-specific handling for Windows (MinGW/MSVC) and other systems
- Kept all existing compatibility macros and wrappers
- Updated git-compat-util.h to include the new header

This continues the series' pattern of cleanly separating reftable dependencies from Git internals, following previous patches that addressed RNG, sleep functionality, and Windows compatibility. The change is well-contained and builds on the architectural work done in earlier patches.
