Refactoring patch in Patrick Steinhardt's reftable decoupling series (v4 5/18). This change removes the last `BUG()` usage from the reftable library by converting `reftable_record_init()` to return an error code when given an unknown record type, rather than aborting. The patch updates all callers to handle the potential error, including several test files. This is part of the broader effort to fully separate reftable from Git's core infrastructure by eliminating dependencies on Git-specific functions and behaviors.

The change is straightforward and well-contained, touching only the necessary call sites while maintaining the same safety guarantees. It follows the pattern established in earlier patches of the series where Git-specific error handling is replaced with library-appropriate alternatives. The tests demonstrate the expected behavior continues to work, now with explicit error checking.
