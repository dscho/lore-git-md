This is part 9/18 of Patrick Steinhardt's v4 series to fully decouple the reftable library from Git's core infrastructure. The patch focuses on endianness conversion functions, completing another step in removing Git-specific dependencies.

The change replaces Git's big-endian conversion functions (`put_be16`, `put_be24`, etc.) with reftable-specific versions (`reftable_put_be16`, `reftable_get_be24`, etc.). The new implementations are more comprehensive, adding 32-bit and 64-bit variants that weren't previously available in the reftable code. The patch updates all callers across the reftable codebase to use these new functions and includes corresponding test updates.

This is a straightforward technical change that follows the pattern established in earlier patches of the series. The implementation looks clean and maintains the same functionality while removing another Git dependency. With the major architectural concerns already addressed in previous iterations, this appears to be a low-risk piece of the decoupling effort.
