This is part of Patrick Steinhardt's ongoing `the_repository` removal effort, specifically patch 15/16 in the series. The patch moves the "core.sharedRepository" configuration from global variables into `struct repo_settings`, continuing the pattern established in previous patches of converting repository-specific state from global to per-repository storage.

The changes:
- Removes global `the_shared_repository` and `need_shared_repository_from_config` variables from environment.c
- Adds new `shared_repository` and `shared_repository_initialized` fields to `struct repo_settings`
- Introduces new accessors `repo_settings_get_shared_repository()`, `repo_settings_set_shared_repository()`, and `repo_settings_reset_shared_repository()`
- Updates all callers to use the new repository-aware versions instead of the old globals
- Maintains the same lazy-loading behavior where the value is only read from config when first accessed
- Affects 8 files (58 lines added, 58 removed) including core commands like `init-db` and `format-patch`

The patch follows the established pattern seen in earlier patches of this series, systematically converting another piece of repository state to be properly scoped. The changes are mechanical but thorough, updating all call sites to use the new interface. This continues the series' progression through different types of repository-specific state (after paths and hooks in previous patches), moving Git closer to being able to remove `the_repository` global entirely.
