This is a refactoring patch that introduces a new helper function for option parsing, part of the ongoing `--revision` clone option series.

The patch adds `die_for_incompatible_opt2()` to complement existing functions that handle 3-4 incompatible options. The new helper provides consistent error handling when exactly two incompatible options are specified. The implementation reuses the existing `die_for_incompatible_opt4()` infrastructure, passing zeros for the unused option slots.

The change is demonstrated by converting the `--onto`/`--advance` option check in `builtin/replay.c` to use the new helper. This maintains the same behavior while standardizing the error reporting mechanism. The patch is small (13 lines net change) and focused, with no functional changes beyond the error message formatting.

This appears to be a straightforward quality-of-life improvement for option parsing, following the pattern established by the existing `die_for_incompatible_opt[3-4]` functions. The change is well-contained and unlikely to be controversial, though it's worth noting this is the first use of these helpers outside of the clone functionality where they were originally introduced.
