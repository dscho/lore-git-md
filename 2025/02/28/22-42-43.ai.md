This is a proposal about contributor mentoring infrastructure, specifically addressing the replacement of the problematic git-mentoring@googlegroups.com list. The current Google Groups setup has become untenable due to excessive spam and repeated content takedowns by Google that erase legitimate discussions without recourse. The list sees minimal legitimate traffic (just a few new contributor questions per year) while requiring significant maintenance overhead.

Emily Shaffer reports that Johannes Schindelin (Dscho) suggested moving mentoring discussions to the existing Git Discord server, which already handles some new contributor questions effectively. The Discord alternative offers better moderation control but has tradeoffs: it requires account creation (unlike vger.kernel.org email) and lacks web crawler accessibility. The email seeks community input on this transition or alternative platform suggestions, noting that any solution should maintain a low-barrier option for hesitant newcomers while solving the Google Groups' spam and takedown problems.

Key considerations mentioned include: the Google Groups' repeated content takedowns (with an example notice showing opaque removal processes), the mentoring list's original purpose as a lower-stress alternative to git@vger.kernel.org, and the Discord server's existing but imperfect suitability as a replacement. The message leaves open the possibility of migrating to another mailing list service if better options exist, though Shaffer notes lacking personal experience with alternatives.

This appears to be the start of a discussion thread about community infrastructure rather than a technical patch. The core tension is between maintaining an accessible, archived resource for new contributors while avoiding the administrative headaches of the current solution. The Discord proposal seems practical but may spark debate about discoverability and archival needs versus moderation requirements.
