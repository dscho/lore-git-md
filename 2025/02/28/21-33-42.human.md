This is the final version of a feature series introducing a new `git-diff-pairs` plumbing command for batch blob diff generation. The series has gone through multiple rounds of review and refinement, with all major design decisions now settled.

The new command processes NUL-delimited raw diff input (like from `git diff-tree -z`) and outputs diffs between blob pairs, allowing batch processing that can be split across multiple processes. This is particularly useful for server-side operations where large diffs might otherwise time out. The implementation includes explicit flush control between batches and preserves rename/copy information through a new `skip_resolving_statuses` diff option.

The v5 changes are minor final polish items: standardizing variable names to match project conventions, removing an unneeded parse option flag, and updating tests to use `git init` instead of the deprecated `test_create_repo`. The series appears ready for merging with all substantive feedback addressed and only minor documentation/style tweaks remaining.

The implementation builds on previous work by Peff and has been thoroughly reviewed by multiple contributors, with Junio providing architectural guidance. The design carefully considers future extensibility while maintaining backward compatibility. Test coverage is comprehensive, including submodule handling. This looks like a well-executed addition to Git's diff plumbing layer.
