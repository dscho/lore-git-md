This thread addresses a build system issue in gitweb.js where the build script was incorrectly included in the generated JavaScript output due to a Makefile using `$^` (all dependencies) instead of explicitly specifying only the output file. The initial fix modified the Makefile rule to properly isolate the output by listing files explicitly.

Simon Richter has now suggested an alternative approach using an order-only dependency (marked with `|`), which would keep the script as a prerequisite without including its contents in the output. Both solutions address the core issue, with the explicit file list being more direct and the order-only dependency being more semantically precise. The discussion highlights that this may be a pattern worth auditing more broadly in the Makefile, though the thread hasn't yet settled on which approach to adopt. The fix is straightforward but serves as a good example of build system subtleties in dependency management.
