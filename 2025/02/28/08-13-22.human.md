Follow-up documentation maintenance patch for Meson build system. 

Patrick Steinhardt points out that while Todd Zullinger's patch series updated the contacts documentation from .txt to .adoc format, there was an oversight in the Meson build configuration that still referenced the old .txt extension. This is a straightforward mechanical change that aligns with the series' goal of updating documentation extensions following Git's switch to AsciiDoc format.

The patch updates two references in contrib/contacts/meson.build to use .adoc instead of .txt, mirroring similar changes made elsewhere in the build system. This ensures the documentation will build correctly under Meson, just as it does with the Makefile-based build. The change comes after the recent merge of Meson support for contrib/contacts (ef18273a2d9).

This appears to be the final piece needed to complete the documentation extension updates for the contacts component, addressing a minor but important build system detail that was missed in the original series. The patch follows the same simple, mechanical approach as the rest of the series.
