This is a discussion about potentially deprecating Git's support for unknown object types, part of Jeff King's ongoing zlib inflation series. Taylor Blau is responding to Jeff's observation that the `OBJECT_INFO_ALLOW_UNKNOWN_TYPE` feature and `--literally` flag (added in 2015) appear unused and may be candidates for removal. 

Taylor concurs with Jeff's assessment, suggesting that 10 years is sufficient time to declare this functionality a failed experiment. The exchange reinforces the emerging consensus in the thread (noted in Junio Hamano's earlier comments) that these features were primarily debugging tools and could be deprecated in Git 3.0. This aligns with the series' broader goal of simplifying and hardening Git's object handling code paths.
