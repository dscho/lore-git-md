Maintainer guidance on naming convention for cat-file filtering. Junio Hamano weighs in decisively on the ongoing debate about whether to use `--filter=` (consistent with other commands) or `--objects-filter` (proposed to avoid confusion with cat-file's existing `--filters` option).

Hamano provides historical context that cat-file's `--filters` option (for smudge filters) has always been distinct from the object filtering used elsewhere. He argues strongly for consistency across Git commands, stating cat-file should either use the standard `--filter=` naming or not implement the feature at all. The only alternative he entertains would be renaming *all* existing `--filter=` options to something like `--object-filter=`, which he considers impractical at this point.

This appears to settle the naming debate that had been open between Patrick Steinhardt (the patch author) and Toon Claes (who advocated for consistency). As the Git maintainer, Hamano's position carries significant weight and likely concludes this aspect of the discussion. The technical implementation can now proceed with the standard `--filter=` naming.
