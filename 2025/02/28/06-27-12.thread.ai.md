Thread summary:

Bug report and fix for gitweb's UTF-8 handling in diff output. Thorsten Glaser identified that gitweb double-encodes UTF-8 content in plain diff and patch views by incorrectly treating already-UTF-8 text as Latin-1. The proposed solution wraps output with the existing `to_utf8` helper function in gitweb.perl, specifically modifying print statements for commitdiff_plain and patch formats. The change is minimal (two lines) but addresses a clear display issue.

The author acknowledges this may need to be applied to other output handlers (blobdiff mentioned) but hasn't audited all possible locations. The patch appears correct for the specific cases it targets but suggests a broader UTF-8 handling cleanup may be needed across gitweb. No maintainer feedback or additional review comments yet. The fix is straightforward but its completeness depends on whether similar encoding issues exist in other gitweb output paths.
