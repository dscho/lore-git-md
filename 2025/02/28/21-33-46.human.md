This is the final patch in a series implementing the new `git-diff-pairs` plumbing command, adding explicit flush control for batch processing. The command now allows inserting NUL bytes between input file pairs to trigger immediate diff computation and output, rather than waiting for stdin to close. Each flushed batch is separated by a NUL byte in the output stream.

The implementation sets `diffopt.no_free=1` to preserve the diff queue between batches, then flushes and outputs a delimiter when encountering a NUL in the stream. The patch includes documentation updates and a test verifying the new flush behavior works correctly with rename/copy detection.

This completes the core functionality for the command, which is designed to enable more flexible diff processing pipelines by splitting generation and output stages. The series has gone through five iterations with all major architectural decisions settled, and this final version addresses the last remaining piece of functionality needed for robust batch processing.
