The implementation adds a new flush mechanism where writing a single NUL byte between input file pairs triggers diff computation and output for the current batch. Each flushed batch is separated by a NUL byte in the output. The changes include:

1. Setting `diffopt.no_free=1` to prevent automatic queue freeing between batches
2. Detecting flush triggers (NUL bytes) in the input stream
3. Adding output NUL delimiters between batches
4. Maintaining automatic flush on stdin closure
5. A new test case verifying multi-batch processing

The patch builds on the series' established NUL-delimited format and integrates with the existing diff queue infrastructure. It completes the design goal of enabling staged pipeline processing where `diff-pairs` can act as the output phase while other commands serve as frontends.
