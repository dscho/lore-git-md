This is a bugfix for the gitweb.js build system issue. The patch addresses a regression where the build script for gitweb.js was incorrectly being appended to the generated JavaScript file, causing syntax errors. The problem stems from using `$^` in the Makefile rule which includes all dependencies, when only the script output should be included.

The issue was introduced when the gitweb.js generation was moved into a shell script, creating a new dependency that wasn't properly handled in the Makefile rule. The patch modifies the Makefile to explicitly specify only the intended output file rather than all dependencies.

This appears to be a straightforward fix for a clear build system bug. The patch is small and focused, though it might be worth checking if there are other similar rules in the Makefile that could have the same issue. The problem affects anyone building gitweb with the JavaScript components enabled.
