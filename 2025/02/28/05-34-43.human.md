Bugfix for gitweb.js build error. Thorsten Glaser reports that a recent change to the gitweb.js build process (moving it into a shell script) accidentally appends the shell script itself to the generated JavaScript file, causing syntax errors. The issue stems from using `$^` in the Makefile rule which includes all dependencies, when only the script's output should be included. 

The patch provides a straightforward fix by modifying the Makefile to properly specify the input file. This appears to be a clear-cut build system bug that slipped through review, affecting users who build gitweb from source. The impact is limited to gitweb functionality, and the fix looks correct for the described issue. No discussion or controversy is expected - this seems like a simple but important correction to the build process.
