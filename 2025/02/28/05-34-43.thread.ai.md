Gitweb.js build system bug: Addressing a regression where the build script was incorrectly included in the generated JavaScript output due to Makefile using `$^` (all dependencies) instead of properly isolating output files. The issue emerged when gitweb.js generation was moved to a shell script (commit 19d8fe7da65), creating an unintended dependency. Three approaches were evaluated: (1) Thorsten Glaser's explicit file listing (portable but potentially less maintainable), (2) Simon Richter's order-only dependencies (GNU make-specific), and (3) Patrick Steinhardt's `$(filter %.js,$^)` solution (avoids file list repetition while excluding non-JS files). Patrick has now followed up with Thorsten to coordinate finalizing the fix, offering to take over if needed. Key remaining items are commit message improvements (detailing regression origin from 19d8fe7da65) and Signed-off-by formatting (using real names).
