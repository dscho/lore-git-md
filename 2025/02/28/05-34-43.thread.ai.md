Gitweb.js build system bug: Fix regression where the build script was incorrectly included in the generated JavaScript output due to Makefile using `$^` (all dependencies) instead of properly isolating output files. The issue emerged when gitweb.js generation was moved to a shell script, adding an unintended dependency. Two solutions under discussion: (1) current patch's approach of explicitly listing output files in the Makefile rule, and (2) Simon Richter's proposed alternative using order-only dependencies (`|`) to maintain the script as a prerequisite without including its contents. Both approaches correctly address the build artifact contamination while differing in Makefile semantics - explicit listing being more direct versus order-only being more precise about dependency relationships. The thread has identified this as a Makefile pattern that may need broader auditing elsewhere in the build system. Affects gitweb builds with JavaScript enabled. Straightforward build system correction with ongoing discussion about optimal implementation approach.
