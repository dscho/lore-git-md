This is a proposal about contributor infrastructure, specifically regarding the mentoring channel for new Git contributors. Emily Shaffer reports that the current git-mentoring@googlegroups.com list has become problematic due to excessive spam and repeated content takedowns by Google with no recourse. The list sees very little legitimate traffic (just a few new contributor questions per year) but significant administrative headaches.

The proposal suggests either to:
1. Move mentoring discussions to the existing Git Discord server (which already handles some new contributor questions), or
2. Find an alternative hosting service for the mailing list

The Discord option is noted as having better moderation control but requiring account creation, while losing the web-archiving benefit of the mailing list format. No specific alternative mailing list providers are proposed, but Shaffer is open to suggestions.

The email serves as a request for feedback from the community about the preferred path forward for this low-volume but potentially important resource for onboarding new contributors. The problems with the current setup appear well-documented, with multiple instances of content being removed without explanation or appeal process.
