This is a documentation patch series addressing file extension consistency following the txt-to-adoc conversion in Git's documentation system. The cover letter explains that broken links were noticed in howto-index.html output due to recent documentation format changes from .txt to .adoc. The primary change updates howto-index.sh to use .adoc extensions consistently, though the author notes an alternative approach would be to only modify the glob patterns. 

The series also includes two additional patches that rename .txt files to .adoc in the contrib/contacts and contrib/subtree directories for consistency. The author mentions git-remote-mediawiki.txt in contrib/mw-to-git as another candidate for renaming but left it out due to uncertainty about its maintenance status. 

The changes are mechanical renames with corresponding Makefile updates, affecting:
- Documentation/howto/howto-index.sh (14 line changes)
- contrib/contacts/ (Makefile and file rename)
- contrib/subtree/ (Makefile and file rename)

This appears to be a straightforward cleanup following the documentation system migration, with the author thoughtfully considering but deferring changes to potentially unmaintained components. The patches maintain perfect rename fidelity (100% similarity) for the actual documentation files while updating the build system references.
