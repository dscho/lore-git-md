This thread documents a straightforward documentation maintenance series updating file extensions from .txt to .adoc as part of Git's ongoing documentation system conversion. The series, now complete with three patches, mechanically updates build system references while maintaining file content integrity.

The changes began with updating Documentation/howto/howto-index.sh to handle .adoc files instead of .txt, fixing broken links in the generated howto-index.html. The second patch renamed contrib/contacts/git-contacts.txt to .adoc and updated its Makefile reference. The final patch, just submitted, completes the series by applying the same treatment to contrib/subtree/git-subtree.txt and its Makefile.

All changes follow the pattern established by parent commit 1f010d6bdf that originally converted the documentation system to use AsciiDoc. The series intentionally focused only on maintained components, leaving potentially unmaintained files like git-remote-mediawiki.txt unchanged. With no technical objections raised against the previous patches, this final mechanical update should conclude the series cleanly.
