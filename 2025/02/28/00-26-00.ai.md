This is a feature patch series introducing a new `git-diff-pairs` plumbing command for batch blob diff generation. The series has gone through multiple iterations with extensive review and is now in its final polish phase before merging.

The core functionality enables processing NUL-delimited raw diff format input to generate diffs between blob pairs efficiently, allowing large diff operations to be split across multiple processes. Key design elements include:
- Strict NUL-delimited input/output requirement (-z mode)
- Default patch output format (DIFF_FORMAT_PATCH)
- Explicit flush control via NUL bytes between batches
- New `skip_resolving_statuses` diff option to preserve rename/copy info
- Comprehensive test coverage including submodule handling

The series consists of:
1. Diff queue refactoring to expose `diff_filepair` handles
2. New option to skip status resolution during diffcore processing
3. Core `diff-pairs` command implementation
4. Explicit flush control for batch processing

Changes in v4 address final review feedback:
- Replaced `found_follow` workaround with dedicated `skip_resolving_statuses` field
- Improved options parsing flow while maintaining usage message functionality
- Added submodule test coverage
- Various cleanups and error message improvements

The implementation appears thorough and well-tested, with all major architectural decisions confirmed through the review process. The remaining work consists of minor documentation and style tweaks before merging.
