This thread discusses the proposal to retire the problematic git-mentoring@googlegroups.com list, which has been plagued by spam and content takedowns while seeing little legitimate use. Johannes Schindelin (Dscho) initially suggested moving mentoring discussions to the existing Git Discord server, which already handles some new contributor questions effectively but requires account creation and lacks email's accessibility.

Junio Hamano has now weighed in, supporting the closure of the Google Groups list while raising practical considerations about the transition. The discussion has shifted from platform evaluation to implementation details, with Junio emphasizing the need to clearly document all available help channels (not just Discord) and determine where and how to publicize these resources. This suggests the Discord migration is likely to proceed, pending resolution of these ancillary concerns about discoverability and maintenance of the documentation.

The thread remains open for further community input, but the core decision appears to be moving toward consensus, with the focus now on ensuring the transition is well-communicated and supported for newcomers who may need alternative help options.
