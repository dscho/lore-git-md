The thread discusses retiring the problematic git-mentoring Google Group, which has become unsustainable due to spam and content takedowns while seeing little legitimate use. Johannes Schindelin proposed moving mentoring discussions to the existing Git Discord server, which already handles some new contributor questions effectively. While Discord has some tradeoffs (requiring account creation), it offers better moderation control than the current setup.

Junio Hamano has supported closing the Google Groups list, focusing on implementation details like documentation and maintenance processes. The discussion has now reached broader consensus, with Christian Couder adding support for the shutdown while suggesting the #git-devel IRC channel and main Git mailing list as additional help options alongside Discord. This reinforces the emerging agreement that multiple existing channels could collectively replace the dedicated mentoring list.

Key remaining questions center on documentation - where to list the available support channels (Contributing docs or Maintainer notes) and who will maintain this information. The group also needs to decide whether to formally endorse all three alternatives (Discord, IRC, and the mailing list) or focus primarily on Discord while mentioning others. With clear consensus on retiring the Google Groups list, the thread is now shifting toward finalizing these implementation details.
