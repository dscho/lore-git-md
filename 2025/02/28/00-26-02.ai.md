This is a refactoring patch that introduces a new `skip_resolving_statuses` option to the diff machinery, part of the ongoing `git-diff-pairs` plumbing command development. The patch addresses a specific interaction point where `diffcore_std()` would automatically resolve diff statuses even when they had been manually set, which could interfere with the planned batch processing behavior of `git-diff-pairs`.

The change adds a new flag to `struct diff_options` that prevents `diff_resolve_rename_copy()` from being called when statuses should be maintained as-is. This preserves manually-set status information during batch processing. The implementation is minimal (just 2 lines changed in diff.c plus documentation in diff.h) but provides important control for the new command's use case.
