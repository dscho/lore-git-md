Feature implementation for a new `git-diff-pairs` plumbing command, part of a series that's now in final polish phase. This patch introduces the core command that processes NUL-delimited raw diff format input to generate patch output, enabling batched diff generation in separate pipeline stages.

The command acts as a backend that takes raw diff input (like from `git diff-tree -z -r`) and produces patch output, allowing diffs to be computed incrementally rather than all at once. Key aspects include:
- Requires `-z` for NUL-delimited input/output
- Defaults to patch format output but preserves rename/copy info via new `skip_resolving_statuses` flag
- Rejects tree objects and pathspecs (should be handled upstream)
- Includes comprehensive tests in t4070-diff-pairs.sh covering various diff statuses
- Uses refactored diff queue infrastructure from earlier patches
- Handles all diff status types (added, modified, deleted, renamed, copied, typechanged)

The implementation builds on previous refactoring work and incorporates all major feedback from reviewers. It's now in final stages addressing minor documentation and style issues before merge. The test suite verifies compatibility with raw diff input and proper handling of all diff cases including submodules.
