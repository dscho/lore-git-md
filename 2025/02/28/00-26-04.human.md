This is the final patch in the `git-diff-pairs` plumbing command series, adding explicit flush control to the diff queue. The patch allows users to trigger diff output between batches of input by writing a NUL byte, rather than waiting for stdin to close. This provides more flexibility when using `git-diff-pairs` in pipelines.

The implementation adds a `no_free` flag to prevent automatic queue clearing, then processes NUL bytes as flush triggers - generating output and adding a NUL delimiter between batches. The change maintains the existing behavior of final flush on stdin closure. A new test case verifies the explicit flush functionality works alongside normal operation.

This completes all planned functionality for the new command, with the series now in final polish phase. The patch follows the established design pattern of using NUL delimiters throughout the interface and builds on the refactored diff queue infrastructure from earlier patches. With this addition, `git-diff-pairs` provides full control over batch processing while maintaining pipeline safety.
