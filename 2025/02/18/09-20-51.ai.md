Platform compatibility patch in Patrick Steinhardt's reftable decoupling series.

This is patch 15/18 in the v6 series to separate the reftable library from Git core dependencies. The patch splits POSIX-related definitions from Windows compatibility headers (`mingw.h` and `msvc.h`) into new `*-posix.h` files. This is preparatory work for a future split of `git-compat-utils.h` into POSIX compatibility and Git-specific utility sections.

The changes:
- Creates new `mingw-posix.h` with all POSIX emulation code from `mingw.h`
- Makes `mingw.h` include `mingw-posix.h` while keeping Git-specific Windows code
- Creates new `msvc-posix.h` with MSVC-specific POSIX emulation
- Makes `msvc.h` include both `msvc-posix.h` and `mingw.h`

The patch maintains all existing functionality while reorganizing the code to better separate concerns. This continues the series' pattern of methodically replacing Git-specific components with reftable-native implementations while preserving behavior. The changes are internal plumbing with no user-facing impact, keeping with the series' goal of enabling external reftable usage by removing Git dependencies.
