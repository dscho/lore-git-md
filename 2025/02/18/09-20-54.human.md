This is the final patch in Patrick Steinhardt's 18-part series to fully separate the reftable library from Git core dependencies. The patch makes a small but meaningful change to the build system by excluding reftable sources from Coccinelle checks.

The rationale is straightforward: since the reftable library has been systematically stripped of all Git-specific helpers (as shown in previous patches), Coccinelle rules designed to suggest Git helper usage would now only generate false positives when scanning reftable code. The change simply adds reftable/ to the list of excluded paths in the COCCI_SOURCES variable.

This is a clean-up patch that follows naturally from the architectural work done in the series. It doesn't change any functionality but removes unnecessary processing that could confuse contributors. The patch is minimal (just a one-line Makefile change) and well-justified, marking the completion of the reftable independence effort.
