Build system patch fixing libsecret credential helper compilation warnings. This is part 4/12 of Patrick Steinhardt's series adding Meson support for Git's contrib components.

The patch addresses three compiler warnings that appear when building the libsecret credential helper with developer warnings enabled: a missing field initializer in the SecretSchema struct, a signed/unsigned comparison when iterating through strings, and an unused parameter check in the main function. Each fix follows standard C practices - using designated initializers, matching types for comparisons, and properly validating arguments.

These changes are straightforward technical fixes that maintain existing behavior while making the code more robust against compiler warnings. The patch fits into the larger series' goal of ensuring all credential helpers build cleanly across platforms as part of the Meson build system integration. No controversy is expected here - these are the kind of minor fixes that typically get merged quickly.
