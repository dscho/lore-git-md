Platform compatibility fix for the wincred credential helper in Patrick Steinhardt's Meson build system series.

This patch (3/12 in the series) addresses a Windows-specific issue where the git-credential-wincred helper fails to compile under Microsoft Visual Studio due to unsupported `__attribute__` syntax. The fix, originally from Mirth Hickford, conditionally excludes the printf format attribute when compiling with MSVC, mirroring the approach used elsewhere in Git's codebase via compat/msvc.h. The change is minimal (just a preprocessor conditional) but necessary for proper Windows support.

The patch maintains the series' focus on cross-platform build system improvements, specifically targeting the credential helper components. It follows the established pattern of platform-specific adjustments seen in earlier parts of the series, though this one originates from an external contributor rather than the series author. The change is straightforward and unlikely to be controversial, being a direct port of existing Git compatibility practices to the contrib/ area.

Key technical details include the use of `_MSC_VER` macro detection and the specific printf format attribute being guarded. The patch affects only the wincred credential helper's error reporting function, with no behavioral changes beyond enabling successful compilation on MSVC. This aligns with the series' broader goal of ensuring all contrib components build correctly across supported platforms when using Meson.
