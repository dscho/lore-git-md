This is a refactoring patch in Phillip Wood's v2 series improving `git merge-tree --stdin` plumbing behavior. It switches from using `init_ui_merge_config()` to `init_basic_merge_config()` in the merge-tree implementation, aligning with the command's plumbing nature. The change follows a previous commit (9c93ba4d0ae) that established this split between plumbing and porcelain configuration initialization.

While functionally a no-op currently (since the merge ORT backend ignores `diff.algorithm`), the patch future-proofs against potential future changes to UI-oriented configuration that shouldn't affect plumbing commands. The change is minimal - just a single line modification in `builtin/merge-tree.c` swapping the initialization function call.

This continues the series' theme of properly separating plumbing and porcelain concerns, building on earlier work to fix deadlocks and streamline stdin processing. The patch maintains all previous fixes while making this subtle but important architectural improvement to configuration handling.
