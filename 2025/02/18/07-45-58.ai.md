This is patch 10/12 in Patrick Steinhardt's series adding Meson build system support for Git's contrib components, specifically focusing on wiring up the gitk graphical repository browser.

The patch adds Meson build configuration for gitk, following the established approach from previous patches in the series. Key elements include:
- A new `gitk-git/meson.build` that handles the TCL script generation using the previously introduced `generate-tcl.sh` script
- Internationalization support through a `po/meson.build` file that lists all supported languages
- Integration into the main Meson build system with proper feature detection (checking for `wish` executable)
- Addition of a new `gitk` option in `meson_options.txt` to control build inclusion
- Summary output showing gitk build status

The implementation maintains parity with the existing Makefile build while following Meson conventions, similar to how other contrib components were handled earlier in the series. The patch continues the pattern of careful cross-platform compatibility and build system unification that has characterized this entire effort.
