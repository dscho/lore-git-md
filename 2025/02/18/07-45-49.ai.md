Build system refactoring introducing a centralized source directory variable.

This is the first patch in Patrick Steinhardt's 12-part series adding Meson build system support for Git's contrib components. It addresses a build system wart where tests needing to locate files relative to the source directory had been using ad-hoc variables like `GIT_TEST_MERGE_TOOLS_DIR` and `GIT_TEST_POPATH`. The patch introduces a new `GIT_SOURCE_DIR` variable in `GIT-BUILD-OPTIONS` to serve as a single source of truth for the project root path, then updates all build systems (Makefile, CMake, Meson) and test scripts to use it.

The changes are mechanical replacements removing three specialized variables in favor of the new general-purpose one. Affected areas include gettext test infrastructure and mergetool test scripts. The patch follows the pattern of previous build system unification work, with parallel changes made to all three build systems (Make, CMake, Meson) to maintain consistency.

Key technical details for future reference:
- New variable `GIT_SOURCE_DIR` added to `GIT-BUILD-OPTIONS`
- Removed variables: `GIT_TEST_MERGE_TOOLS_DIR`, `GIT_TEST_POPATH`
- Updates test scripts in `t/lib-gettext.sh` and `t/t7609-mergetool--lib.sh`
- Parallel changes across Makefile, CMakeLists.txt, and meson.build
- Uses `$(shell pwd)` in Makefile, `CMAKE_SOURCE_DIR` in CMake, and `meson.project_source_root()` in Meson

This appears to be a straightforward cleanup with no expected controversy, though reviewers may want to verify the removed variables aren't used in any unpatched locations. The change fits naturally with the series' goal of build system unification.
