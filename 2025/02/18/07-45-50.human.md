Build system fix for the netrc credential helper tests in Patrick Steinhardt's Meson integration series. This is the second patch in a 12-part set adding Meson support to Git's contrib components.

The patch addresses test failures that occur when building out-of-tree (a common Meson pattern) by fixing two path assumptions in the netrc credential helper tests. First, it updates the test script to use the new `GIT_SOURCE_DIR` variable (introduced in patch 1) to locate test files. Second, it adds a `CREDENTIAL_NETRC_PATH` environment variable to properly find the built helper binary in the build directory rather than assuming it's next to the test files.

The changes are straightforward - just a few line modifications to the test script and its wrapper. This appears to be a clean fix for a real issue that would affect anyone using Meson builds, continuing the series' pattern of methodically updating each contrib component's build and test infrastructure. The patch maintains the existing behavior for in-tree builds while properly supporting out-of-tree scenarios.
