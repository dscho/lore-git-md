This is the final version of Patrick Steinhardt's 18-patch series to fully decouple the reftable library from Git's core codebase, enabling standalone use by projects like libgit2. The series has undergone multiple revisions addressing feedback, with the key remaining issue being Windows build system conflicts from header reorganization in patch 15/18.

The current version (v6) makes several adjustments from v5:
- Rebased on master to resolve zlib-ng conflicts and gain MSVC+Meson CI coverage
- Simplified Windows file reorganization to minimize disruption for Git-for-Windows
- Keeps POSIX compatibility headers (mingw-posix.h, msvc-posix.h) in compat/ rather than mingw/ and msvc/ subdirectories to avoid filename collisions
- Maintains all previous technical improvements like removing BUG() calls (541 lines of POSIX compat code)

The series systematically replaces Git-specific helpers (read_in_full, BUG(), COPY_ARRAY etc.) with reftable-specific implementations, culminating in the new compat/posix.h header that provides the minimal POSIX layer needed. The changes span 25 files (+1405/-1155 lines), with the bulk being header reorganization and compatibility code.

This represents the final integration hurdle after all major technical approvals (Junio Hamano, Justin Tobler, Johannes Sixt, Toon Claes). The Windows-specific adjustments in v6 aim to balance architectural cleanliness with practical development needs, though Johannes Schindelin's feedback on the new approach is still pending. The series is otherwise ready for merging as a significant step in Git's modularization.
