This is a plumbing/porcelain configuration cleanup patch in Phillip Wood's ongoing series to improve `git merge-tree --stdin`. 

The patch switches `merge-tree` from using `init_ui_merge_config()` to `init_basic_merge_config()`, properly aligning it with other plumbing commands. While this currently makes no functional difference (since the merge ORT backend ignores `diff.algorithm`), it future-proofs the code against potential changes to the UI-oriented configuration initialization. 

This change continues the series' theme of clearly separating plumbing and porcelain behaviors, building on commit 9c93ba4d0ae which originally introduced the configuration split. The patch is straightforward - just a one-line change to the merge options initialization - and maintains all the previous fixes and improvements from the series.
