Documentation bug report about incorrect release notes URL on git-scm.com.

Bede Skinner-Vennell reports that the git-scm.com downloads page links to a non-functional URL for the v2.48.1 release notes. The current link points to a `.txt` file in the master branch, but since commit 1f010d6bdf, release notes now use `.adoc` extension in master. 

Two working alternatives are provided: either using the tag-specific `.txt` URL (v2.48.1/Documentation/RelNotes/2.48.1.txt) or the master branch's `.adoc` version (master/Documentation/RelNotes/2.48.1.adoc). 

The report is clear and actionable, providing both the broken link and two working alternatives. This appears to be a straightforward documentation issue that needs updating on the git-scm.com side. No patch is included - this is purely an issue report about the website's content.
