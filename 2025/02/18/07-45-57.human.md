This is part of Patrick Steinhardt's ongoing series to add Meson build system support for Git's contrib components, now focusing on gitk (patch 9/12). The change extracts the gitk build script logic from the Makefile into a standalone shell script (`generate-tcl.sh`) to enable reuse with Meson.

The patch moves the TCL/Tk path substitution logic that creates the final `gitk-wish` executable into a new script, keeping the same functionality but making it more portable. The script handles path escaping and file generation in a way that should work consistently across build systems. This is a straightforward refactoring that follows the pattern seen in earlier patches of the series - separating build logic from specific build systems to enable cross-compatibility.

The change is small and focused, maintaining the existing behavior while preparing for Meson integration. As with previous patches in this series, it appears well-constructed and follows the established approach of making minimal, targeted changes to enable build system unification.
