This is part of Patrick Steinhardt's ongoing reftable library decoupling effort (patch 13/18 in v6 series), specifically targeting removal of Git-specific utility functions. The patch replaces Git's `SWAP()` macro with a reftable-native `REFTABLE_SWAP()` implementation, continuing the series' pattern of systematically eliminating Git dependencies while maintaining functionality.

The new implementation in `reftable/basics.h` provides equivalent swap behavior through direct memory operations, including a clever compile-time size check via array declaration that fails if the swapped items have different sizes. The change affects four files: basics.h (new macro), merged.c (priority queue operations), pq.c (more priority queue handling), and record.c (ref record manipulation).

The patch maintains the same safety characteristics as Git's version while removing another link to Git's compat-util.h. Like previous patches in the series, this is an internal implementation change with no user-facing effects, focused on enabling external reftable usage by projects like libgit2. The changes are mechanical replacements with identical behavior, showing the careful, incremental approach characteristic of this well-reviewed series.
