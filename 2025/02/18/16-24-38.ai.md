Documentation patch for `git merge-tree --stdin` behavior, part of an ongoing series improving stdin mode reliability and documentation. This patch adds explicit documentation that `--stdin` implies `-z` mode (NUL-terminated output) and clarifies the exit status behavior - negative status codes now correctly indicate the program dies before producing output, rather than being part of the normal status reporting. The changes align with earlier technical fixes in the series that resolved deadlock issues and streamlined stdin processing.

Key documentation updates:
- Adds new `--stdin` section in OPTIONS explicitly stating it implies `-z`
- Removes incorrect documentation about negative status codes being part of normal output (they now terminate execution)
- Adds cross-reference to INPUT FORMAT section
- Maintains separation between stdout status reporting (0/1) and process termination (negative codes)
