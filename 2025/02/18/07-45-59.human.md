CI build system fix for Meson integration in the musl-based test job.

This patch corrects two small but important issues in the CI configuration for the musl-based Meson build job. The problems stem from a previous commit that wasn't fully updated: the job name still referenced the old "linux-musl" identifier rather than the new "linux-musl-meson" name, and it used an incorrect option name (`-DGIT_TEST_UTF8_LOCALE` instead of `-Dtest_utf8_locale`) for specifying the UTF-8 test locale.

The fix is straightforward - just updating these two strings in `ci/lib.sh`. While minor, this ensures proper locale handling during testing, which is particularly important for the musl environment where locale settings can behave differently than glibc systems. This patch continues Patrick Steinhardt's systematic work on Meson integration by cleaning up a small oversight in the test infrastructure.
