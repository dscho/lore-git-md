This is patch 17/18 in Patrick Steinhardt's series to decouple the reftable library from Git's core codebase. The patch completes the separation by replacing the last remaining inclusion of "git-compat-util.h" with the more focused "compat/posix.h" header.

The change is straightforward - it swaps out the broad Git compatibility header for one that provides just the POSIX functionality needed by reftable. This finalizes the library's ability to be used standalone by other projects like libgit2, with only "system.h" and "system.c" remaining as Git-specific components that would need to be implemented by consumers.

The patch builds on extensive prior work in the series that systematically replaced Git helpers with reftable-native implementations. With this change, the reftable library achieves its architectural goal of being truly independent while maintaining all existing functionality. The diff is minimal (just 3 lines changed across two files), showing how much of the heavy lifting was done in earlier patches.

This appears to be one of the final steps before the series can be merged, following approvals from multiple core maintainers. The change is low-risk since it's the culmination of careful incremental work rather than introducing new functionality.
