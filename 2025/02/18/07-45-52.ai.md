Platform compatibility fix for the libsecret credential helper in Patrick Steinhardt's Meson build system series.

This patch (4/12 in the series) addresses compilation warnings in the libsecret credential helper that surface when developer warnings are enabled. The changes focus on three specific issues: 

1) The SecretSchema initialization now uses designated initializers to properly set all fields, fixing a missing-field-initializers warning about the 'reserved' field. The patch updates both the schema name and attributes initialization syntax.

2) A sign-compare warning between int and guint types is resolved by making the loop counter match the unsigned type returned by g_strv_length().

3) An unused parameter warning for argc is addressed by adding a minimal check that validates the argument count before proceeding, while maintaining the existing behavior.

The changes are straightforward and follow established patterns seen elsewhere in the codebase. This continues the series' pattern of incrementally fixing platform-specific build issues in credential helpers, following the earlier wincred and netrc patches. The fixes appear uncontroversial and maintain backward compatibility while silencing compiler warnings that would otherwise break builds with -Werror enabled.
