This is part of Patrick Steinhardt's ongoing refactoring series to separate the reftable library from Git core dependencies. Patch 9/18 replaces Git's big-endian conversion functions with reftable-native implementations, continuing the architectural decoupling effort.

The patch introduces a comprehensive set of inline functions in `reftable/basics.h` for big-endian conversion of 16, 24, 32, and 64-bit values (`reftable_put/get_be{16,24,32,64}`), removing the previous mix of Git and reftable implementations. The new functions follow reftable's naming conventions and handle all endian conversion needs within the library. Changes propagate through block handling, reader/writer operations, and record encoding/decoding code paths.

Unit tests are expanded to verify the new 32-bit and 64-bit conversion functions while maintaining existing test coverage for 16/24-bit cases. The changes are mechanical replacements with no functional differences, just internal implementation cleanup. This continues the series' pattern of systematically removing Git dependencies while maintaining safety through explicit checks.
