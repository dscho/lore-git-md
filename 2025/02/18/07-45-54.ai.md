This is part 6/12 of Patrick Steinhardt's series adding Meson build system integration for Git's contrib components, specifically focusing on credential helpers. The patch wires up all four credential helpers (libsecret, netrc, osxkeychain, wincred) to build under Meson, following the pattern established in earlier patches for other contrib components.

Each helper gets its own meson.build file with platform-specific dependencies (GLib/libsecret for Linux, CoreFoundation/Security for macOS, etc.). The netrc helper receives special treatment with test integration, though the commit notes that none of the helpers currently pass the full test suite - this is deferred to future work. The patch also adds a new meson_options.txt entry to control which credential helpers are built.

Key technical details include:
- New meson.build files for each credential helper in contrib/credential/
- Platform-specific dependency declarations (libsecret-1, CoreFoundation, Security)
- Custom target setup for the Perl-based netrc helper
- Test environment configuration for netrc testing
- Meson option ('credential_helpers') to selectively enable helpers
- Perl requirement now triggered by netrc helper selection

This continues the series' pattern of methodical Meson integration while maintaining cross-platform compatibility. The patch appears straightforward and follows established patterns from prior credential helper fixes in the series. The deferred test suite work is noted as a known limitation.
