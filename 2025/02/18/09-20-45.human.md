This is part of Patrick Steinhardt's ongoing series to decouple the reftable library from Git core, specifically focusing on replacing Git's endian conversion functions with reftable-native implementations. 

The patch standardizes big-endian integer handling across the reftable codebase by introducing a complete set of inline functions (16/24/32/64-bit variants) in `reftable/basics.h` and removing the previous mix of Git-provided and reftable-specific functions. The new implementations follow reftable's naming conventions (`reftable_get_be*`/`reftable_put_be*`) and include comprehensive test coverage in the unit tests.

This change is part of the architectural effort to make reftable usable as a standalone library, with all previous technical concerns in the series already addressed and approved by multiple core maintainers. The patch appears well-contained, touching only internal implementation details without affecting user-facing behavior, and maintains the same safety guarantees through direct memory operations with proper type handling.
