This is part of Patrick Steinhardt's ongoing effort to separate the reftable library from Git core dependencies. The patch replaces Git's `write_in_full()` helper with a reftable-specific implementation called `reftable_write_full()` in the stack.c file.

The change is straightforward - it introduces a new function that handles partial writes and error conditions (EAGAIN/EINTR) directly, rather than relying on Git's utility functions. This is the second patch in an 18-part series that has already received extensive review and is nearing final approval.

The implementation looks clean and follows the pattern seen elsewhere in the series for replacing Git-specific helpers. Since this is part of a well-vetted architectural change that has already addressed major technical concerns, this particular change appears uncontroversial and focused purely on the dependency reduction goal.
