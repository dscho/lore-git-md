This is a refactoring patch in Patrick Steinhardt's series adding Meson build system support for Git's contrib components, specifically focusing on gitk. The patch extracts the TCL script generation logic from the Makefile into a standalone `generate-tcl.sh` script, making it reusable by both Makefile and Meson build systems.

The change moves the sed-based transformation that adjusts the TCL interpreter path from being inline in the Makefile to a separate script. This maintains the same functionality while improving code organization. The script takes three parameters: the TCLTK path (with proper escaping), input file, and output file.

Junio Hamano notes in his reply that coordination with Johannes Sixt may be needed regarding the gitk subtree arrangement, suggesting there may be additional considerations around how gitk is maintained within the Git project. This doesn't appear to be a blocking issue for the current patch, but rather a note about future coordination.

The patch is part of a larger effort (patch 9/12) to unify build system support across Makefile, CMake and Meson for Git's contrib components. The change is straightforward and appears well-contained, focusing specifically on the gitk build process without introducing new functionality or behavior changes.
