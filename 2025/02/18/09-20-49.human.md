Part of the ongoing reftable library separation effort, this patch continues the systematic removal of Git-specific dependencies. Patrick Steinhardt replaces Git's `SWAP()` macro with a reftable-native implementation called `REFTABLE_SWAP()`, maintaining the same functionality while eliminating another tie to Git's codebase.

The change affects four files, with the most notable addition being a new macro in `reftable/basics.h` that performs the swap operation using direct memory operations. The implementation includes a clever compile-time size check that mirrors Git's original safety mechanism, though expressed differently to avoid Git's macros. The patch updates all existing `SWAP()` callsites in merged.c, pq.c, and record.c to use the new macro.

This appears to be a straightforward mechanical conversion that maintains the same safety guarantees while advancing the series' goal of complete reftable independence. The changes are limited to internal implementation details with no user-facing impact, and the careful preservation of size checking suggests attention to maintaining safety during the transition.
