Platform compatibility patch in Patrick Steinhardt's reftable separation series. This is patch 16/18 in v6 of the effort to make the reftable library independent from Git's core code.

The patch splits POSIX-emulation functionality out of `git-compat-util.h` into a new `compat/posix.h` header. The motivation is to separate Git-specific helpers from general POSIX compatibility shims, as the reftable library only needs the latter. The change moves 541 lines of POSIX-related definitions while leaving Git-specific utilities in the original header.

This continues the series' systematic approach to decoupling - each patch has tackled a different category of Git dependencies. The implementation looks thorough, preserving all existing functionality while reorganizing the code to support the reftable library's independence. The patch follows the established pattern of the series and appears ready for inclusion, pending final maintainer review.
