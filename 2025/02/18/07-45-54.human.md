This is part 6/12 of Patrick Steinhardt's series adding Meson build system integration for Git's contrib components, specifically focusing on credential helpers. The patch wires up all four credential helpers (libsecret, netrc, osxkeychain, wincred) to build under Meson, following the pattern established in earlier patches for other components.

Each helper gets its own meson.build file with appropriate platform-specific dependencies (like CoreFoundation/Security for osxkeychain, glib/libsecret for libsecret). The netrc helper is special-cased as a Perl script with its test harness also integrated. The patch also adds a new meson_options.txt entry to control which credential helpers to build.

The author notes that while the helpers now build, none currently pass their test suites - this verification is deferred to future work. This continues the series' incremental approach to Meson support, with credential helpers being a notable gap that's now addressed. The changes appear straightforward and follow established patterns from prior patches in the series.
