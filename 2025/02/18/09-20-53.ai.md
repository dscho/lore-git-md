This is patch 17/18 in Patrick Steinhardt's series to decouple the reftable library from Git core, specifically focusing on removing the final Git-specific header dependency. The patch completes the transition from including "git-compat-util.h" to using the new "compat/posix.h" header that was split out in patch 16/18. This change finalizes the architectural separation of POSIX compatibility functionality from Git-specific utilities, leaving only "system.h" and "system.c" as the remaining Git-specific components that external users would need to provide implementations for.

The key technical change is replacing the "git-compat-util.h" include in reftable/system.h with "compat/posix.h", while keeping the Git compatibility header in system.c where it's still needed for the remaining system-level implementations. This maintains all existing functionality while clearly delineating the boundary between reftable's needs (POSIX environment) and Git's implementation details.

This patch represents the penultimate step in making reftable truly standalone, following the systematic removal of Git dependencies throughout the series. The only remaining Git-specific code after this will be addressed in the final patch (18/18). The changes are straightforward and build on the extensive groundwork laid by previous patches in the series, particularly the header reorganization in patch 16/18.
