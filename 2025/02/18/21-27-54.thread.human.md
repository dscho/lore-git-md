This thread reports a broken link on the Git website (git-scm.com) for the v2.48.1 release notes. Bede Skinner-Vennell found that the site incorrectly points to a `.txt` file in the `master` branch, which no longer exists after commit 1f010d6bdf converted documentation to `.adoc` format. 

The issue is straightforward to fix, as two working alternatives already exist: either linking to the version-tagged `.txt` file (which was preserved for this release) or updating the link to point to the new `.adoc` file in `master`. This appears to be an oversight in coordinating the documentation format change with the website's link generation logic. Website maintainers will need to update the link generation to account for the new file extensions while maintaining backward compatibility with existing release notes.
