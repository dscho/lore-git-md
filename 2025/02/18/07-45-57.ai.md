This is a refactoring patch in Patrick Steinhardt's series adding Meson build system compatibility for Git's contrib components, specifically targeting gitk (patch 9/12). The patch extracts the gitk build logic from the Makefile into a standalone shell script (`generate-tcl.sh`) to enable reuse with Meson. The script performs the same core function as the original Makefile rules: modifying gitk's shebang line to use the configured TCLTK_PATH and creating an executable wrapper.

Key technical details include:
- New `generate-tcl.sh` script that handles the TCL path substitution and file generation
- Makefile simplification by delegating to the new script
- Maintains identical behavior to original implementation (same sed pattern, same output file handling)
- Uses `SHELL_PATH` variable consistently with other build systems
- The script includes proper error handling with `set -e` and follows Git's standard shell script patterns

This change follows the series' pattern of making contrib components build-system-agnostic by extracting logic from Makefiles into reusable scripts. The gitk work builds on previous patches that handled credential helpers, git-contacts, and Coccinelle. The implementation looks straightforward and maintains functional parity while enabling Meson integration in subsequent patches.
