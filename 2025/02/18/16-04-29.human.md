Performance optimization patch for `update-ref` command. This is part of a larger series improving refname availability checks across Git's ref backends, with Karthik Nayak and Patrick Steinhardt collaborating on the changes.

This specific patch modifies `builtin/update-ref.c` to skip OID ambiguity checks when parsing object IDs, using the new `GET_OID_HASH_SKIP_AMBIGUITY_CHECK` flag introduced earlier in the series. The changes affect both the `--stdin` mode parsing and direct command-line usage of `update-ref`. The patch appears straightforward, simply wrapping existing `repo_get_oid()` calls with the new flag-enabled version.

The optimization makes sense in context - as part of the series' goal to reduce redundant checks during ref operations. The thread context shows this builds on Patrick's foundational work adding the flag, and is part of coordinated changes that have demonstrated 1.19x to 2.32x speedups in benchmarks. The changes are limited to `update-ref` and maintain the same error handling behavior, just skipping the ambiguity check that isn't needed in this context.
