CI / build system fix for the Meson integration series.

This patch corrects two issues in the musl-based CI job configuration that were introduced in an earlier commit (84bb5eeace7) when switching the job to use Meson. First, it updates the job name reference from "linux-musl" to the current "linux-musl-meson" name. Second, it fixes the Meson option name for specifying the UTF-8 test locale from `-DGIT_TEST_UTF8_LOCALE` to the correct `-Dtest_utf8_locale` format.

The changes are straightforward and clearly motivated by the original commit's oversight. The patch maintains consistency with Meson's naming conventions (using lowercase with underscores for options) while ensuring the locale specification works as intended for testing. This is part of Patrick Steinhardt's ongoing series to add Meson support for Git's contrib components, with this particular fix addressing a minor but important CI configuration detail that could affect test reliability on musl systems.
