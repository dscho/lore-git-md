Documentation fix for HTML rendering in git-merge-tree manpage.

This is the final patch in Phillip Wood's v2 series improving `git merge-tree --stdin` behavior and documentation. The series has already addressed deadlock issues, configuration handling, and clarified various aspects of the command's behavior. This particular patch is a minor but important documentation fix - it corrects how a cross-reference to the OUTPUT section appears in the HTML-rendered version of the manpage by adding explicit link text.

The change is straightforward - where the documentation previously had `<<OUTPUT>>` which could render oddly in HTML, it now uses `<<OUTPUT,OUTPUT>>` to ensure proper formatting. This follows standard asciidoc practices for cross-references. While small, it's the kind of polish that improves the quality of the rendered documentation.

The patch maintains the series' focus on documentation accuracy and follows the collaborative review process seen throughout the thread, with Elijah Newren having reviewed earlier versions. As the last patch in a well-reviewed series, it appears ready for inclusion.
