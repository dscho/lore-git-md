This is a platform compatibility patch in Patrick Steinhardt's ongoing series to separate the reftable library from Git core dependencies. Patch 15/18 reorganizes Windows compatibility headers by splitting POSIX-related functionality from MinGW/MSVC-specific code.

The change creates new `*-posix.h` headers that contain all the POSIX emulation code that was previously mixed with Windows-specific implementations in `mingw.h` and `msvc.h`. The main headers now include these POSIX headers while retaining their platform-specific additions. This is preparation for further refactoring of Git's compatibility utilities.

The patch moves 431 lines of POSIX definitions and implementations into `mingw-posix.h` and creates a parallel `msvc-posix.h` with 33 lines of MSVC-specific POSIX adjustments. The diff shows extensive reorganization but no functional changes - it's purely moving code between files to establish clearer separation of concerns.

This continues the series' pattern of methodically untangling dependencies, here focusing on the Windows compatibility layer. The change appears well-contained and maintains all existing functionality while making the codebase more modular.
