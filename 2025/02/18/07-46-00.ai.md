This is the final patch in Patrick Steinhardt's series adding Meson build system support for Git's contrib components, specifically focusing on CI integration for credential helpers. The patch enables credential helper testing across all CI platforms by:

1. Adding `-Dcredential_helpers=wincred` to Windows builds in GitHub Actions and GitLab CI
2. Installing libsecret development packages for Linux builds
3. Configuring platform-appropriate credential helpers in CI scripts:
   - `libsecret` and `netrc` for Linux
   - `osxkeychain` for macOS
   - `wincred` for Windows

The changes touch CI configuration files (`.github/workflows/main.yml`, `.gitlab-ci.yml`) and setup scripts (`ci/install-dependencies.sh`, `ci/lib.sh`), ensuring credential helpers are built and tested across all major platforms. This completes the systematic Meson integration for contrib components by verifying the credential helper subsystem works end-to-end in CI.

The patch follows the established pattern of the series by maintaining cross-platform consistency while enabling proper testing infrastructure. With this final piece, the entire contrib/ directory now has comprehensive Meson build support with CI verification.
