This is part of Patrick Steinhardt's ongoing series to add Meson build system support for Git's contrib components, specifically focusing on the git-contacts script in this patch (7/12).

The patch adds Meson build support for git-contacts, a Perl script in the contrib directory that helps identify potential reviewers for patches. It follows the same pattern established in earlier patches for other contrib components, with three main build components: the script itself, manpage generation, and HTML documentation. The script gets installed to libexec/git-core, while documentation follows standard Git conventions for manpages and HTML docs.

A notable change is the addition of 'contacts' to the list of available contrib options in meson_options.txt, allowing selective building of this component. The implementation appears straightforward and consistent with the Meson patterns used elsewhere in the series, though it doesn't include any test integration (which seems consistent with how git-contacts is treated in the Makefile build system).

This continues the methodical approach seen throughout the series, with each patch cleanly handling one contrib component at a time. The changes are focused purely on build system integration without modifying the actual functionality of git-contacts.
