Documentation patch finalizing Perl version check standardization for Meson builds. This is the second and final patch in Peter Oliver's series, which has gone through multiple review iterations with Patrick Steinhardt.

The patch provides detailed documentation explaining the Meson build system's Perl version parsing behavior, particularly for versions before 1.7.0. It describes two approaches: using `-V:version` for Meson 1.5.0+ (which gives unambiguous version strings) and falling back to matching just the minor version number for older Meson versions. The commit message notes this is a temporary workaround until Meson 1.7.0's fix becomes widely available.

The implementation is minimal but well-documented, maintaining compatibility while clearly explaining the rationale behind the version check differences. The patch references future Perl version numbering changes (possible removal of the leading "5") but confirms this won't affect Git's requirements. With all technical concerns addressed and consensus reached in previous rounds, this appears ready for merging.
