This is a refactoring patch in Patrick Steinhardt's ongoing series to separate the reftable library from Git core dependencies. The change removes use of Git's `COPY_ARRAY()` helper in favor of direct memory operations in the reftable record handling code.

The patch replaces `COPY_ARRAY()` with an open-coded `memcpy()` while adding two important safeguards: it now checks for potential integer overflow when calculating the copy size, and skips the allocation entirely for zero-length arrays to avoid returning spurious out-of-memory errors. The change is part of the systematic effort to make reftable usable as a standalone library by eliminating Git-specific helpers.

The modification is straightforward and maintains the same functionality while improving error handling. Since this is part of a well-reviewed series that has already addressed major architectural concerns, this incremental change appears uncontroversial and aligns with the established pattern of replacing Git internals with reftable-native or POSIX-compatible alternatives.
