This is a build system patch adding Meson support for the git-contacts contrib script, part of Patrick Steinhardt's ongoing series to migrate Git's contrib components to Meson.

The patch 7/12 focuses on the git-contacts Perl script, which provides contact information for Git contributors. It creates a new meson.build file in contrib/contacts/ with three main components: installation of the Perl script itself, manpage generation when documentation is enabled, and HTML documentation generation. The script follows the same pattern seen in earlier patches for other contrib components, using Meson's custom_target() for build steps and proper installation paths.

Key technical details include the use of generate_perl_command for script processing, integration with git_version_file for version information, and proper documentation handling through the existing asciidoc/xmlto pipeline. The patch also adds 'contacts' to the valid choices for the 'contrib' meson option, allowing selective building of this component.

This continues the series' consistent approach to Meson integration, maintaining parity with the existing Makefile build system. The changes are straightforward and follow established patterns from previous patches in the series, suggesting this will be a non-controversial addition. With this patch, git-contacts joins the growing list of contrib components with proper Meson support.
