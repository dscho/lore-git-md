Platform compatibility patch in Patrick Steinhardt's reftable decoupling series.

This is patch 16/18 in v6 of the series to separate the reftable library from Git core dependencies. It splits POSIX-emulation functionality out of git-compat-util.h into a new compat/posix.h header, moving 541 lines while removing 529 from the original file. The change cleanly separates platform compatibility code (like time functions, filesystem operations, and network APIs) from Git-specific utilities, which is key for making reftable usable outside Git.

The patch maintains all existing functionality while reorganizing the code to better logical boundaries. It follows the pattern seen in earlier patches of this series where platform-specific code is isolated into dedicated headers (previously seen with mingw-posix.h and msvc-posix.h). The change is purely structural - no behavior is altered, just the organization of the compatibility layer.

This continues the systematic removal of Git dependencies from reftable, with the series now focusing on the final stages of separating core utility functions. The patch appears well-constructed, maintaining all necessary includes and definitions while cleanly extracting the POSIX-related portions. It builds on prior work to create a self-contained reftable library that could be used by projects like libgit2.
