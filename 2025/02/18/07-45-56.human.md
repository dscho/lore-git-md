This is part of Patrick Steinhardt's ongoing series to add Meson build system support for Git's contrib components, specifically adding Coccinelle static analysis support in patch 8/12.

The patch introduces a new `coccicheck` target for Meson that runs Coccinelle semantic patches across Git's source code. Rather than hardcoding which files to analyze, it dynamically discovers all `.c` and `.h` files using `git ls-files`, excluding third-party code. The implementation concatenates all Coccinelle rules into a single file and processes each source file individually before combining the results into a unified patch.

The approach maintains consistency with the existing Makefile-based Coccinelle support while adapting it to Meson's build system. A new `coccinelle` option is added to meson_options.txt to control whether this feature is built. The implementation is thorough, handling dependencies properly and integrating cleanly with the existing contrib/ build structure.

This continues the series' pattern of methodically adding Meson support for each contrib component while maintaining feature parity with the Makefile build system. The patch appears well-constructed and follows the established approach seen in previous patches of the series.
