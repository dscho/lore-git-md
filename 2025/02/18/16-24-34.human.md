This is a bugfix and documentation cleanup series for `git merge-tree --stdin`. Phillip Wood is submitting version 2 of his patch series that addresses a deadlock issue and improves the code and documentation.

The key fix in this series (patch 1) ensures `git merge-tree --stdin` flushes stdout after each merge operation, preventing deadlocks when scripts process the output incrementally. This was discovered when the author encountered deadlocks while using the command in a squashing workflow.

The remaining patches are cleanups:
- Removing redundant error handling code (patch 2)
- Simplifying merge configuration to only use basic settings (patch 3)
- Improving documentation clarity around `--stdin` behavior (patch 4)
- Fixing HTML link formatting in the docs (patch 5)

Version 2 includes only minor updates from v1, primarily an improved commit message for patch 2 that better explains the exit status behavior. The changes have been reviewed by Elijah Newren, a merge expert, and appear to be straightforward improvements to both functionality and documentation. The series builds on existing work to properly separate plumbing and porcelain behavior in merge-tree.
