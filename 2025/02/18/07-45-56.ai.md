This is part of Patrick Steinhardt's ongoing series to add Meson build system support for Git's contrib components, specifically adding Coccinelle static analysis support in patch 8/12.

The patch introduces a new `coccicheck` target for Meson that runs Coccinelle semantic patches across Git's source files. Key technical aspects include:

- Creates a new `contrib/coccinelle/meson.build` file implementing the Coccinelle integration
- Uses `git ls-files` to dynamically find all source files rather than hardcoding paths, ensuring analysis includes platform-specific files that may not be built
- Excludes third-party code (like compat/ and sha1dc/) from analysis
- Processes 19 existing Coccinelle rules (covering common patterns like memory allocation, string handling, and repository access)
- Generates a unified patch file from all findings
- Adds a Meson option to control Coccinelle support (defaulting to auto-detection)

The implementation follows the established pattern seen in earlier patches of the series, maintaining consistency with the Makefile-based Coccinelle support while adapting to Meson's build system. The approach of dynamically finding source files rather than hardcoding paths is particularly notable as it ensures comprehensive coverage across platforms.

This continues the systematic expansion of Meson support for Git's development tooling, following the credential helper and git-contacts work in previous patches. The clean implementation suggests this will integrate smoothly with the existing build infrastructure.
