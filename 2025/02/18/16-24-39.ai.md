This is a documentation patch fixing HTML rendering in the `git-merge-tree` man page. It's the final patch in Phillip Wood's v2 series addressing `git merge-tree --stdin` improvements.

The change corrects how a cross-reference to the "OUTPUT" section appears in HTML output by adding explicit link text to the asciidoc markup. Currently the link shows up with square brackets in HTML, which is not the intended presentation. The fix is minimal - just adding ",OUTPUT" to the existing `<<OUTPUT>>` reference to properly format the link text.

This follows earlier documentation improvements in the series that clarified `--stdin` behavior and exit status handling. While purely cosmetic, it completes the polish on the man page updates that accompany the functional changes to `merge-tree`'s stdin processing. The patch maintains the same content while fixing the HTML output formatting.

Key technical detail for future reference: The fix modifies the asciidoc cross-reference syntax in `Documentation/git-merge-tree.txt` from `<<OUTPUT>>` to `<<OUTPUT,OUTPUT>>` to properly render the link text in HTML output. This doesn't affect the man page output, only the HTML version.
