Build system refactoring for out-of-tree test support in the netrc credential helper.

This patch fixes test infrastructure for the netrc credential helper to properly support out-of-tree builds, particularly important for the ongoing Meson integration. The tests previously made assumptions about paths being relative to the build directory, which breaks when source and build directories differ. 

The changes introduce two key fixes: First, using the new `GIT_SOURCE_DIR` variable (from patch 01/12) to locate the test script in the source tree. Second, adding a `CREDENTIAL_NETRC_PATH` environment variable to specify the built helper's location in out-of-tree builds. The modifications touch both the shell test wrapper and Perl test script.

This appears to be a straightforward technical adjustment that follows the pattern established in the series' first patch. The changes are minimal (5 lines added/changed across 2 files) and focused specifically on test portability. The patch maintains backward compatibility while enabling the Meson build system's out-of-tree requirements. As part of the larger contrib/ Meson integration effort, this helps standardize build system behavior across different components.
