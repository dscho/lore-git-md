Patrick Steinhardt continues his work to make the reftable library more self-contained by reducing its dependencies on Git-specific utilities. In this latest patch, he replaces the use of `read_in_full()` with direct file reading logic in `reftable/stack.c`. 

The change open-codes the file reading functionality while intentionally omitting `EWOULDBLOCK` handling since the reftable library doesn't use non-blocking I/O. The new implementation maintains the same error handling behavior but implements the reading in a loop to handle partial reads. The patch is part of Steinhardt's ongoing effort to decouple the reftable implementation from Git's core utilities, making it more portable and self-contained.
