This is the 10th patch in Patrick Steinhardt's 12-part series adding Meson build system support for Git's contrib components, now focusing on the gitk graphical repository browser. The patch follows the established pattern seen in previous patches, cleanly integrating gitk into the Meson build system while maintaining compatibility with the existing Makefile approach.

The changes add Meson build rules for gitk, including detection of the required Tcl/Tk 'wish' interpreter and proper handling of gitk's internationalization support (po files for 13 languages). The implementation uses the same `generate-tcl.sh` script introduced in the previous patch to handle path substitutions, ensuring consistent behavior across build systems. The patch also adds gitk to the build summary output and makes it configurable via a new meson option.

As with the rest of the series, this is a well-structured change that maintains the existing functionality while enabling future Meson integration. The patch follows the project's established patterns for build system modernization and shows careful attention to cross-platform compatibility. No new technical issues are introduced, and the change appears ready for inclusion as part of the broader Meson support effort.
