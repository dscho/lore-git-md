This is a build system refactoring patch from Patrick Steinhardt's series adding Meson support for Git's contrib components. It introduces a standardized way for tests to locate the Git source directory, replacing several ad-hoc variables with a single `GIT_SOURCE_DIR` variable in `GIT-BUILD-OPTIONS`.

The change removes three specialized test variables (`GIT_TEST_MERGE_TOOLS_DIR`, `GIT_TEST_POPATH`, and `GIT_TEST_POPATH`) in favor of deriving paths from the new source directory variable. The patch updates all build systems (Makefile, CMake, and Meson) to handle the new variable consistently, and modifies two test scripts to use the new approach.

This appears to be a straightforward cleanup that follows established patterns in the codebase. The change is well-motivated in the commit message, explaining how it prevents future proliferation of similar variables. As the first patch in a 12-part series, it sets up infrastructure that will likely be used by subsequent patches.
