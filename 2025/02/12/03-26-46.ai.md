This is a bugfix patch in the pickaxe long-options series, correcting a documentation error in the `-G` option's help text. The patch fixes a copy/paste mistake where the description for `-G` (which searches for patches containing regex matches) incorrectly used the same wording as `-S` (which counts string changes). The correction makes the help text accurately describe `-G`'s behavior of finding diffs where the patch contains lines matching the given regex.

The change is minimal (a single line in diff.c) but important for user clarity, especially as part of the larger effort to improve pickaxe option discoverability. This patch was included early in the v5 series (patch 2/10) as a straightforward correction that doesn't depend on the later long-option additions. The fix aligns with the thread's broader goal of making pickaxe functionality more accessible while maintaining technical accuracy.
