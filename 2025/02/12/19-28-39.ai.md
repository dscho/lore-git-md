This is a refactoring patch from a GSOC contributor, part of an ongoing effort to improve type safety in Git's commit-reach.c code. The patch changes the type of a `flags` variable from `int` to `unsigned int` in the `paint_down_to_common()` function, which handles commit graph traversal logic.

The rationale is straightforward: since the flags are defined using unsigned bit shifts (1u << N) and represent bitwise combinations (PARENT1, PARENT2, STALE), using an unsigned type is more semantically correct. The change is minimal - just a one-line type modification - but properly aligns with how the flags are actually used.

The patch appears well-scoped and uncontroversial, though it doesn't include any test changes since this is purely a type safety improvement rather than a behavior change. As a GSOC contribution, it shows good attention to detail in matching types to their actual usage patterns in the codebase. The change is unlikely to affect performance but makes the code's intent clearer.
