Feature completion for the new `git-diff-pairs` plumbing command. This is the third and final patch in a series introducing a batch blob diff tool for server-side parallel processing needs.

The patch adds explicit control over when queued diffs are flushed, allowing users to insert a NUL byte between file pairs to trigger immediate output. This provides flexibility for incremental processing of large change sets. Each flush is separated by a line terminator in the output (or NUL when using -z mode).

The implementation includes thorough test coverage for both regular and null-terminated output modes, verifying the new flush behavior works correctly with rename/copy detection. Documentation is updated to explain the new capability.

This completes the series' goal of enabling efficient diff processing for large change sets. The implementation appears solid, with careful attention to edge cases and maintaining consistency with Git's existing diff machinery. The comprehensive test suite gives confidence in the feature's reliability.
