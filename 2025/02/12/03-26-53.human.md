Documentation patch adding long option names to help text. This is part of the ongoing series introducing long option names for pickaxe search functionality (--patch-modifies for -S` and `--patch-grep` for `-G`). 

This patch updates the help text in diff.c and diff.h to show both the short and long forms of these options together, making it clearer that they are equivalent. The changes are straightforward - just adding the short/long form pairs in the help strings. For example, "-S" becomes "-S/--patch-modifies" in the descriptions.

The motivation is to help less experienced users by making the more descriptive long forms visible right in the help text, rather than requiring them to search through documentation to understand what the short options mean. This builds on the previous patches in the series that implemented the actual long option support.

The patch is clean and focused, just doing what it says - no functional changes, just documentation improvements. It's one of the final patches in the series (9/10) which appears to be wrapping up with these last documentation tweaks before potential merging.
