Documentation patch standardizing terminology in pickaxe search options. This is part of a larger series adding long option names (`--patch-modifies` and `--patch-grep`) for Git's pickaxe search functionality (-S and -G).

The patch updates the gitdiffcore.txt documentation to consistently use "regex" and "string" as placeholders for the -G and -S arguments, replacing the longer "regular-expression" and "block-of-text" forms. The author argues this change improves consistency with the rest of Git's documentation while maintaining clarity, since the shorter terms are still understandable to Git users.

The changes are purely documentation-focused, with no functional impact on the pickaxe search behavior itself. This appears to be a straightforward improvement that aligns with the series' goal of making the pickaxe options more discoverable and consistent.
