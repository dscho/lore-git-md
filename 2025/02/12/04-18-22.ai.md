This is a feature patch series introducing a new plumbing command for batch blob diff generation. The series builds on prior work by Peff to create `git-diff-pairs(1)`, which processes null-delimited raw diffs to generate multiple blob diffs in a single process. The primary motivation is server-side use cases where diffing large change sets needs to be parallelized to avoid timeouts.

The series consists of three patches: First adds helper functions to access queued `diff_filepair` structs after `diff_queue()`. Second introduces the core `diff-pairs` command that reads raw diff format input (containing status and object context) to generate diffs. Third adds explicit queue control to flush diffs before stdin EOF. The implementation touches diff core components, adds new documentation in AsciiDoc format, and includes comprehensive tests.

Key technical details for future reference: The new command processes input in raw diff format (-z) from commands like `git diff-tree`, outputting unified diffs (-p). It introduces new diff queue manipulation functions in diff.c/diff.h and a full builtin with its own test suite. The approach avoids redundant revision peeling by leveraging existing context in raw diff lines. The series follows recent documentation format changes (txt→adoc) to avoid conflicts.
