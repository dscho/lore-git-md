Performance optimization for reference backend migrations with a new `--skip-reflog` flag.

This final version of the series adds a `--skip-reflog` option to `git refs migrate`, allowing server administrators to bypass reflog migration when converting between reference backends. The change builds on commit 246cebe320 which made reflog migration the default, addressing cases where server repositories may have accumulated unwanted reflogs (from bugs, misconfiguration, or debugging) that don't needed to be preserved.

Key technical details:
- Adds `REPO_MIGRATE_REF_STORAGE_FORMAT_SKIP_REFLOG` flag bit in `refs.h`
- Modifies `repo_migrate_ref_storage_format()` in `refs.c` to conditionally skip reflog migration
- Extends CLI interface in `builtin/refs.c` with new `--skip-reflog` option
- Adds test coverage in `t/t1460-refs-migrate.sh` verifying the behavior
- Renumbers existing dry-run flag to accommodate the new flag

The implementation has gone through multiple rounds of review with Patrick Steinhardt and Junio C Hamano, with all feedback addressed in this version. Changes from v2 include improved test helper parameter handling (using `"$@"` instead of `$@`, marking optional args correctly, and using `<options...>` syntax) and making the `skip_reflog_verify` parameter optional with a default value. The patch is now in final form with all approvals and ready for inclusion.
