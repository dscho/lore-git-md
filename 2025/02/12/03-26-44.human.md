This is a cover letter for version 5 of a patch series introducing long option names for Git's pickaxe search functionality (`-S` and `-G`). The series now includes 10 patches that have been restructured based on maintainer feedback to make the documentation changes more modular and reviewable.

The core change remains the new long option names `--patch-modifies` (for `-S`) and `--patch-grep` (for `-G`), which aim to make these powerful but cryptically-named options more discoverable. The implementation maintains full backward compatibility while adding the new forms, with error messages showing both variants (e.g., "-G/--patch-grep").

Version 5 splits what was previously a large documentation change into smaller, focused patches (8-10) that can be reviewed and applied separately. This addresses Junio Hamano's preference for maintaining short-option references while still allowing Illia Bobyr's readability improvements through optional documentation updates. The technical implementation (patches 1-7) remains solid, having already addressed all functional concerns in earlier versions.

The series shows good attention to detail, with patches fixing minor inconsistencies in existing documentation and tests before introducing the new functionality. Test coverage verifies identical behavior between old and new option forms, and bash completion has been updated to support both. While the core changes are ready, the documentation approach now offers flexibility in how extensively the long options are promoted in help texts and man pages.
