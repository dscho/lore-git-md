He also raises the larger architectural question of whether to make the functions accept an explicit `diff_queue` parameter instead of using the global queue, which would aid Git's libification efforts.

This discussion represents a design crossroad for the series - whether to make minimal changes (current approach) or take the opportunity for more significant API modernization. The thread context shows this is a late review consideration that doesn't block the core functionality but could improve the API's long-term maintainability.
