This is a test modernization patch in the ongoing series to add long option names for Git's pickaxe search functionality (-G/-S). Patch 8/10 updates test scripts to use the new `--patch-grep` and `--patch-modifies` names instead of the single-letter `-G` and `-S` options.

The changes are purely about test readability - the author argues that long option names make tests more self-documenting. The patch updates two test files (t4062-diff-pickaxe.sh and t4209-log-pickaxe.sh) to use the new forms while preserving tests that specifically verify both short and long forms work interchangeably.

The changes are mechanical and straightforward, just replacing option names in test descriptions and commands. The test logic and assertions remain the same. This follows the series' principle of maintaining backward compatibility while improving discoverability through more descriptive option names.

This patch appears well-executed and uncontroversial, being part of a mature series that has already gone through several iterations. It's a clean follow-up to the core implementation work done in earlier patches.
