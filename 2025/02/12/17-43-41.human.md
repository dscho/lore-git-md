Performance optimization for reference backend migrations. This final version of the patch adds a `--skip-reflog` flag to `git refs migrate`, allowing server repositories to bypass reflog migration when changing reference backends. The change builds on previous work that made reflog migration the default behavior.

The implementation adds a new `REPO_MIGRATE_REF_STORAGE_FORMAT_SKIP_REFLOG` flag bit and modifies the migration logic to conditionally skip reflog processing. Test coverage verifies the new behavior works as expected. The patch has undergone thorough review from both subsystem experts and the maintainer, with all feedback addressed in this version.

Junio Hamano provided some final stylistic suggestions about the patch presentation and test helper implementation, which Karthik Nayak has agreed to incorporate. These are minor cleanups that don't affect the core functionality. The technical implementation itself appears sound and ready for inclusion.

This is a focused optimization that will benefit server administrators migrating repositories where reflogs are unwanted (due to historical artifacts or debugging leftovers). The performance gain comes from avoiding unnecessary reflog processing during migration.
