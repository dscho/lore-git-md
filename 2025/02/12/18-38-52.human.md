Performance optimization for reference backend migrations. This final version of the patch adds a `--skip-reflog` flag to `git refs migrate` to bypass reflog migration, which can be costly for server repositories that don't need their reflogs preserved. The change builds on previous work that made reflog migration the default behavior.

The implementation adds a new flag bit to control reflog migration and updates both the CLI interface and underlying migration logic. Test coverage verifies the new behavior works as expected. The patch has gone through multiple rounds of review with all feedback incorporated, including test improvements and documentation clarifications suggested by Patrick Steinhardt and Junio C Hamano.

This is a focused optimization that will primarily benefit server administrators migrating repositories with unwanted reflogs.
