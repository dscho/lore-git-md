This is the final patch in a series adding signed commit support to git fast-export/import, implementing the core functionality. The patch introduces a new `--signed-commits` option for `git fast-export` that mirrors the existing `--signed-tags` behavior, with the same set of modes (abort, verbatim, warn-verbatim, strip, warn-strip). The default behavior changes from silently stripping signatures to aborting, with an escape hatch via `FAST_EXPORT_SIGNED_COMMITS_NOABORT` environment variable for backward compatibility.

Key technical details:
- Adds `find_commit_multiline_header()` helper to properly parse GPG signature blocks from commits
- Handles both GPG and GPG-SHA256 signature formats
- Maintains correct ordering between signature and encoding headers
- Includes comprehensive tests in t9350 verifying all signature handling modes
- Documents the new option and environment variable in git-fast-export.adoc
- Updates fast-import documentation to include gpgsig syntax in commit BNF

The implementation shares the `sign_mode` enum with tag handling for consistency. Test coverage verifies both the new default abort behavior and all alternative modes, including proper preservation of signatures in verbatim modes and correct stripping in others. The patch completes the series' goal of bringing commit signature handling to parity with tag signature support in the fast-import/export pipeline.
