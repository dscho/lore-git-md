This is a bugfix for the test infrastructure, correcting how missing test prerequisites are reported. 

The patch fixes an invocation of `paste(1)` in the test aggregation code that was causing an error message to appear when running tests with missing prerequisites. The current code omits the `-` argument that tells `paste` to read from stdin, which violates POSIX requirements. The error was introduced in commit 49da404070 ("test-lib: show missing prereq summary", 2021-11-20).

The change is straightforward - adding the `-` to make the `paste` command properly read from standard input. This prevents the "usage" error message from appearing in the test output while still maintaining the same functionality of aggregating missing prerequisite information.

The patch is small (just one character changed) and clearly motivated, with a proper reference to both the problematic behavior and the original commit that introduced it. The fix aligns with POSIX requirements and maintains the intended functionality of showing a summary of missing test prerequisites.
