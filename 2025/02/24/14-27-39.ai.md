Documentation patch fixing a formatting issue in git-fast-import's BNF syntax documentation. This is the first patch in Christian Couder's v5 rebase of Luke Shumaker's signed commit support series.

The change adds a missing line feed (LF) marker in the Backus-Naur Form (BNF) grammar for commit commands in git-fast-import's documentation. The 'encoding' field's syntax now properly shows it should be terminated with LF, matching both the actual implementation and the pattern used by other fields in the grammar.

This is a minor documentation correction that was likely noticed while working on the larger signed commits feature. The patch carries both Shumaker's original sign-off (from when he first wrote it in 2021) and Couder's sign-off for the current version. As a simple doc fix with no behavior impact, it should be uncontroversial and helps maintain documentation accuracy for the fast-import format that the subsequent patches will be extending with signed commit support.
