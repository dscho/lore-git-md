Documentation refinement in the signed commits patch series. This is a follow-up to Christian Couder's v5 series implementing signed commit support in git fast-export/import, specifically addressing the documentation patch that explains signature handling modes.

Elijah Newren suggests strengthening the warning about 'verbatim' signature handling in the git-fast-export documentation. The current text warns about transformations affecting tags, but Newren points out this doesn't cover all cases where signatures could become invalid. He notes that fast-export itself may transform data (like permission canonicalization, tree sorting corrections, or extended header dropping) before the import phase, and proposes expanding the warning to explicitly mention transformations performed by both fast-export and fast-import.

This is a minor but thoughtful refinement to the documentation that would make the security implications clearer to users. The suggestion doesn't require code changes, just documentation updates. Since the v5 series has already received final approval from Junio Hamano, this would likely be incorporated as a follow-up improvement if accepted.
