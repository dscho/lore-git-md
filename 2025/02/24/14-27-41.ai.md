This is a documentation and behavior refinement patch in the signed commit support series for git fast-export/import.

The patch renames the `--signed-tags=warn` option to `warn-verbatim` to better match the existing pattern where `warn-strip` is the counterpart to `strip`. The change makes the option names more consistent and self-documenting, with `warn-verbatim` clearly indicating it will both warn about signed tags while preserving them verbatim in the export. The patch maintains backward compatibility by keeping `warn` as a deprecated synonym.

Key technical changes:
- Updates the enum signed_tag_mode in fast-export.c to use WARN_VERBATIM instead of WARN
- Modifies the option parsing to accept both forms
- Updates documentation to show the new and old forms
- Adds new test cases for both `warn-verbatim` and the legacy `warn` form
- The tests verify both the warning output and that signatures are preserved

This is a straightforward improvement to the v5 series that improves naming consistency without changing functionality. The patch follows the series' pattern of careful attention to backward compatibility and thorough test coverage.
