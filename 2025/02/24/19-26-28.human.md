This is a documentation refinement patch in the signed commits for fast-export/import series. Elijah Newren suggests strengthening the warning about signature validity in the 'verbatim' mode of `--signed-tags`. The current wording cautions about transformations affecting signatures, but Newren points out that even without user modifications, the export/import process itself may alter commit metadata (like permissions, tree ordering, or extended headers) in ways that invalidate signatures. He proposes more explicit language covering both user actions and automatic canonicalizations during the transfer process.

The patch is part of Christian Couder's v5 series reviving Luke Shumaker's work, which has already received Junio Hamano's approval. This is a minor but thoughtful improvement to the documentation, showing attention to edge cases in the security implications of signature handling. The suggestion demonstrates good technical understanding of how Git's internal transformations could affect signature validity, though it remains to be seen whether the maintainers will incorporate this exact wording.
