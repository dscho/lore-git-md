This is the first patch in a 4-part series converting Git's oid-related unit tests (oid-array, oidmap, oidtree) from custom test code to the Clar framework. The series is part of Git's broader test modernization effort.

The patch focuses on adapting helper functions in `lib-oid.{c,h}` to work with Clar. It renames and modifies two key utilities: `init_hash_algo()` becomes `cl_setup_hash_algo()` and `get_oid_arbitrary_hex()` becomes `cl_parse_any_oid()`. The changes include switching from custom test assertions to Clar's `cl_assert()` macros and updating the build system to properly include these helpers in Clar-based tests.

The conversion appears thorough, with clear commit messages explaining the changes. The patch maintains all existing functionality while making the code work within Clar's framework. Build system changes ensure the helpers are properly linked for both old and new test styles during the transition.

This foundational work enables the subsequent patches in the series to convert the actual test files. The changes align with the thread's ongoing discussion about test modernization, though this particular patch doesn't touch the more contentious assertion style debate that's still open in the thread.
