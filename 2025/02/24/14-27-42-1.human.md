Documentation patch clarifying signed tag handling in git-fast-export. This is part of a larger series adding signed commit support to fast-export/import.

The patch improves the documentation for the `--signed-tags` option by more precisely explaining why signatures may become invalid during export operations. It notes that transformations affecting hashes (not just tag names) can invalidate signatures, and adds a caution that the 'verbatim' and 'warn-verbatim' modes should only be used when no such transformations will occur or when signature validity isn't important.

This appears to be a straightforward documentation improvement that builds on the earlier technical work in the series. The change makes the potential risks of using verbatim modes clearer to users while maintaining backward compatibility with the existing 'warn' synonym. The patch is cleanly applied to the existing documentation and fits naturally with the series' focus on proper signature handling.
