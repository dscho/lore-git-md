This is a clarification in the ongoing discussion about HTTP authentication and netrc usage in Git. Brian m. carlson responds to Junio C Hamano's query about whether the previous discussion referred to general HTTP netrc usage or specifically the HTTP walker (an older component). 

Carlson confirms the discussion is about netrc in HTTP code paths generally, not the HTTP walker. He notes that while WebDAV-based HTTP protocol is still in use by some, he expresses skepticism about its viability given its incompatibility with packed-refs and future reftable migration. The response reinforces the core tension between maintaining legacy netrc support versus modernizing Git's authentication stack, while making clear the immediate discussion scope excludes the HTTP walker component. This keeps the focus on deciding netrc's future as either a properly documented feature or a candidate for removal.
