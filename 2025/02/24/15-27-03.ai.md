Test modernization patch converting oidmap tests to Clar framework, part of a 4-patch series. This third patch follows the same pattern as the previous oid-array conversion, continuing the author's preference for `cl_assert()` style assertions despite ongoing debate about debuggability tradeoffs.

The patch converts the oidmap test suite from custom test code to Clar framework, with several notable changes:
1. File renamed from t-oidmap.c to u-oidmap.c
2. Test cases restructured into discrete functions (`test_oidmap__*`) with explicit initialize/cleanup
3. Global test data (oidmap instance) shared across tests
4. Error handling replaced with Clar assertions (`cl_assert`, `cl_failf`)
5. Build system integration updated in both Makefile and meson.build

Key technical details:
- Uses `cl_parse_any_oid()` helper from lib-oid.c for consistent hash parsing
- Maintains test coverage for core oidmap operations (get, put, remove, iterate)
- Changes test behavior to fail-fast on first error rather than collecting all failures
- Includes one instance of `cl_failf()` in the iteration test (unlike previous patches' pure `cl_assert` approach)
- Preserves all test cases while simplifying control flow

The patch continues the series' pattern of thorough conversion while maintaining the assertion style debate - this time with a mix of both approaches that may represent a compromise position. The technical implementation appears solid, with clean separation of test cases and proper resource management. The build system changes follow established patterns from earlier patches in the series.
