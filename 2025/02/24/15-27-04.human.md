Final patch in a test modernization series converting oidtree tests to Clar framework.

This is the fourth and final patch in Seyi Kuforiji's series converting Git's object ID handling tests from custom test code to the Clar unit testing framework. It follows the same pattern established in the previous patches (oid-array and oidmap conversions), completing the migration of oidtree tests with:

1. File renaming from `t-oidtree.c` to `u-oidtree.c` and build system updates
2. Conversion of test cases to discrete Clar test functions (`test_oidtree__contains` and `test_oidtree__each`)
3. Use of Clar's initialization/cleanup hooks (`test_oidtree__initialize` and `test_oidtree__cleanup`)
4. Adoption of Clar assertions (`cl_assert`, `cl_failf`) while maintaining test coverage

Notably, this patch continues the mixed assertion style seen in the oidmap conversion, using both `cl_assert` for basic checks and `cl_failf` for more descriptive failure messages. The implementation appears thorough, preserving all test cases while simplifying control flow. With this patch, the series completes its goal of standardizing oid-related tests under the Clar framework, likely setting a precedent for future test conversions.
