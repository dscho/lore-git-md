This is a bugfix patch in the fast-export series adding signed commit support. It addresses a memory safety issue where the code was improperly modifying read-only commit buffer memory while parsing encoding information.

The patch replaces the custom `find_encoding()` function (which modified buffer contents by inserting null terminators) with the standard `find_commit_header()` from commit.h API. This provides the encoding string length without mutation. The change requires some restructuring of the commit parsing logic to handle the encoding header before finding the commit body separator.

Key improvements:
- Eliminates unsafe modification of commit buffer memory
- Uses more robust core API for header parsing
- Maintains all existing functionality while being safer
- Includes better variable naming (`commit_buffer_cursor`) to track parsing position
