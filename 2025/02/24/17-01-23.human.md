This is the final discussion in a thread about adding signed commit support to git fast-export/import, completing work started by Luke Shumaker in 2021. Junio Hamano acknowledges Christian Couder's effort to revive and polish the series, noting it implements parity between commit and tag signature handling with the new `--signed-commits` option matching `--signed-tags` behavior.

The series has been through multiple rounds of review addressing technical concerns like memory safety and buffer handling, and now appears production-ready with comprehensive test coverage. Hamano observes the implementation cleanly solves the original problem while maintaining backward compatibility.

He muses about a potential future enhancement - an independent option to let importers add their own signatures to attest to imported content - but explicitly notes this is orthogonal to the current work. The comment serves more as a conceptual bookmark than a request for changes, as the core functionality appears complete and well-vetted.
