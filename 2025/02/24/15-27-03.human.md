This is the third patch in a 4-part series converting Git's oid-related test suites to the Clar framework, focusing on the oidmap tests. The patch follows the established pattern from previous conversions, replacing the custom test infrastructure with Clar's standardized assertions and test organization.

The key changes include:
1. Renaming the test file from t-oidmap.c to u-oidmap.c to follow Clar conventions
2. Converting test cases into discrete Clar test functions with initialize/cleanup handlers
3. Replacing custom test assertions with Clar's `cl_assert()` family
4. Using the shared `cl_parse_any_oid()` helper from lib-oid.c for consistent object ID parsing

Notably, this patch continues the author's preference for simple `cl_assert()` calls rather than more verbose `cl_failf()` messages, despite previous discussion about debuggability concerns. The conversion maintains all the original test coverage while adopting Clar's single-failure mode behavior.

The patch integrates cleanly with the build system (both Makefile and meson) and follows the patterns established in the first two patches of the series. It demonstrates the author's consistent approach to these conversions, though the ongoing debate about assertion styles remains unresolved.
