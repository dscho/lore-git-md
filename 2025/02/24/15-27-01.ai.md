Test modernization patch converting oid test helpers to Clar framework.

This is the first patch in Seyi Kuforiji's v2 series migrating oid-related tests to the Clar unit testing framework. It focuses on adapting the core helper functions in lib-oid.{c,h} that are needed by subsequent test conversions. The changes include:

1. Renaming and adapting the key helper functions:
   - `init_hash_algo()` → `cl_setup_hash_algo()`
   - `get_oid_arbitrary_hex()` → `cl_parse_any_oid()`
2. Converting test assertions from custom `check()` macros to Clar's `cl_assert()`
3. Build system updates to properly include lib-oid.c in Clar test builds
4. Removal of verbose test messages in favor of simpler assertions

The patch maintains the same functionality while making the code work within Clar's framework. Notably, it uses the simpler `cl_assert()` style rather than the more verbose `cl_failf()` that was debated in previous thread discussion, though this may still be a point of contention.

Technical details:
- Changes affect Makefile and meson.build for build integration
- Modifies lib-oid.c to use Clar's unit-test.h instead of test-lib.h
- Updates function signatures and documentation in lib-oid.h
- Adds necessary includes to unit-test.c
- Maintains same hash algorithm selection behavior via GIT_TEST_DEFAULT_HASH

This foundational change enables the subsequent test conversions in the series while demonstrating the author's preference for simpler assertion patterns. The implementation appears clean and well-contained, though the assertion style debate from the thread remains unresolved.
