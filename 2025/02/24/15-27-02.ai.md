Refactoring patch converting oid-array tests to Clar framework, part of Seyi Kuforiji's 4-patch series modernizing Git's test infrastructure. This second patch in v2 focuses on migrating the oid-array test suite from custom test code to the Clar unit testing framework.

The patch makes several structural changes: moves test input arrays to global scope for reuse across test functions, replaces custom test macros with Clar assertions (primarily using `cl_assert()`), and introduces explicit initialization via `test_oid_array__initialize()`. The test logic remains largely unchanged but is now organized into discrete test functions rather than a single `cmd_main()`. Build system integration updates remove the old test file and add the new Clar-compatible version.

Key technical details:
- Test file renamed from `t-oid-array.c` to `u-oid-array.c`
- Custom test macros (`TEST_ENUMERATION`, `TEST_LOOKUP`) simplified to direct function calls
- Assertions converted to Clar variants (`cl_assert()`, `cl_assert_equal_i()`)
- Hash algorithm initialization moved to Clar-style setup function
- Test cases split into separate functions (`test_oid_array__lookup()`, `test_oid_array__enumerate_unique()` etc.)
- Build system changes in both Makefile and meson.build

This continues the series' pattern of using simpler `cl_assert()` style assertions rather than the more verbose `cl_failf()`, which may prompt further feedback from Phillip Wood about debuggability concerns. The patch maintains all existing test coverage while adopting the Clar framework's structure and conventions.
