This is part 8 of Patrick Steinhardt's series to enhance `git cat-file` with object type filtering capabilities, focusing on performance optimizations for large repositories.

The patch refactors the object iteration logic in `builtin/cat-file.c` to deduplicate code paths for handling both loose and packed objects. It introduces a new `batch_each_object()` helper function that consolidates what were previously separate loops for loose and packed objects. While the immediate benefit is minimal (just reducing some code duplication), the author notes this is groundwork for upcoming bitmap optimizations in the next patch.

The changes are mechanical but well-contained, replacing direct calls to `for_each_loose_object()` and `for_each_packed_object()` with the new unified interface. The patch maintains all existing functionality while making the codebase more maintainable for the bitmap optimizations to come. As part of a performance-focused series, this refactoring shows careful attention to preparing the infrastructure before adding complex optimizations.
