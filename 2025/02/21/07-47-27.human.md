This is a feature patch adding object filtering to `git cat-file`'s batch mode, part of a larger series. It introduces a new `--objects-filter` option (distinct from `--filter` in `git rev-list` to avoid confusion with existing `--filters`) that will allow filtering objects by type and size in future commits.

The patch lays groundwork by:
1. Adding documentation for the new option
2. Wiring up filter parsing while rejecting all filter types for now (they'll be implemented in later patches)
3. Adding tests verifying error messages for unsupported filters

The commit message explains the motivation well: while `cat-file` batch mode currently shows all objects regardless of reachability, sometimes users want to filter by inherent properties like object type or size. The implementation reuses `git rev-list`'s filter syntax for consistency.

The patch appears carefully constructed with thorough test coverage. Performance impact is noted as minimal for now since I/O remains the bottleneck, though bitmap support could change that later. This looks like a well-considered addition to `cat-file`'s capabilities.
