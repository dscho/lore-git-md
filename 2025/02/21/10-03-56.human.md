Bugfix proposal for clearer bisect-related branch deletion errors. 

The patch addresses a confusing error message when trying to delete a branch that's being used by an ongoing bisect operation. Currently, Git reports this as the branch being "used by worktree", which misleads users into thinking there's an active worktree using the branch when in fact the issue stems from a bisect session.

The proposed change would make the error message explicitly mention bisect operations, helping users understand the real reason they can't delete the branch. This is a straightforward quality-of-life improvement that would save users from unnecessary confusion when cleaning up branches after bisect operations.

The patch appears well-motivated and focused, addressing a specific pain point in the user experience. The proposed solution is simple and non-controversial - just improving an error message to be more accurate about the underlying cause. This seems like a worthwhile change that would help users without introducing any complexity or maintenance burden.
