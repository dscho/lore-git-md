Utility function addition for the remote object-info series.

This first patch in the 8-part v11 series introduces a new helper function `strtoul_ul()` to git-compat-util.h, providing robust unsigned long parsing with error handling. The function follows the pattern of existing `strtoul_ui()` utilities but returns an unsigned long instead of unsigned int. Key features include:
- Rejects negative numbers (which strtoul would otherwise accept)
- Validates the entire string was consumed
- Checks for conversion errors via errno
- Returns 0 on success, -1 on error

The implementation will be used later in the series for parsing object sizes in the remote object-info protocol implementation. This is a common utility pattern in Git's codebase, and the new function fills a gap in the existing numeric parsing utilities. The error handling matches Git's existing conventions for similar functions.
