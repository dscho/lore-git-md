The patch introduces a new helper function `bitmap_index_contains_pack()` that checks whether a given packfile is covered by a bitmap index, either directly or through a multi-pack-index. The function is exposed in pack-bitmap.h with clear documentation about its purpose.

This appears to be a straightforward plumbing function that will be used by subsequent patches in the series, likely to optimize object type filtering by quickly determining which packs need to be scanned.
