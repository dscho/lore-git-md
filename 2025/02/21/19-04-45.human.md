This is a refactoring patch in the remote object-info series, generalizing packet-writing functionality for protocol v2. 

The patch refactors `write_fetch_command_and_capabilities()` from fetch-pack.c into a more generic `write_command_and_capabilities()` in connect.c, making it reusable for other protocol v2 operations beyond just fetch. The key changes involve moving the function to a more central location and adjusting how the `advertise_sid` configuration is handled. 

The refactoring is safe because:
1) The session-id advertisement check for protocol v1 is irrelevant for this v2-only function
2) The config access for `transfer.advertisesid` is already available in connect.c

The patch maintains all existing functionality while making the code more reusable, particularly for the new remote object-info feature being added in this series. It's a clean refactor with no behavior changes, just better code organization. The change was reviewed by Jonathan Tan and Christian Couder, and builds on Calvin Wan's earlier work.
