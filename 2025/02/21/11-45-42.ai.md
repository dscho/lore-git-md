Feature implementation for partial reference updates in `git update-ref`, part of the ongoing ref transaction system refactoring series.

This final patch in the 6-part series adds the user-facing `--allow-partial` flag to `git update-ref --stdin`, enabling partial transaction behavior where some reference updates can fail while others proceed. The implementation builds on the backend infrastructure changes from earlier patches, exposing the functionality through the command line interface.

Key technical details:
- Adds `--allow-partial` flag that sets `REF_TRANSACTION_ALLOW_PARTIAL` when processing stdin updates
- Includes basic error reporting through new `print_rejected_refs` callback
- Enforces flag usage only with `--stdin` via explicit check
- Responds to Patrick Steinhardt's review feedback by:
  - Planning to split the overlong synopsis line
  - Considering `OPT_BIT` for cleaner flag handling
  - Acknowledging the error-prone string formatting in rejection output
