This is a bugfix for a NULL pointer dereference in `git check-mailmap` when processing email addresses without names. The issue was reported by a coworker experiencing segmentation faults when using the recently added sendemail mailmap support. The patch fixes the crash by ensuring a valid empty string pointer is passed instead of NULL when no name is present.

The fix is straightforward - changing a NULL assignment to an empty string in `builtin/check-mailmap.c`. The v2 patch drops some additional mailmap resolution changes from v1 to focus just on the crash fix. A new test case is added to verify the fix works when checking a bare email address against a mailmap entry.

The patch appears well-targeted and low-risk, addressing a clear crash scenario with proper test coverage. It's part of ongoing work to improve mailmap handling in sendemail, though this particular fix stands on its own merit. The commit message clearly explains the problem and solution, making it easy to review.
