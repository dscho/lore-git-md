Performance optimization for `git cat-file` object filtering using bitmaps. This is the final patch in Patrick Steinhardt's series to enhance object filtering in `git cat-file`, building on earlier work that added type-based filtering capabilities.

The patch leverages bitmap indexes to dramatically speed up object type filtering operations. When bitmaps are available (either per-pack or via MIDX), the implementation now uses type-specific bitmaps to directly iterate over matching objects rather than scanning entire packfiles. The benchmarks show impressive speedups - up to 4000x faster for tag filtering in the Chromium repository (50GB packfile with 25M objects).

The implementation handles both the new `object:type=` filter and the existing `blob:none` filter, falling back to the full pack scan for packfiles without bitmap coverage. The key changes involve:
1. A new bitmap-based iteration callback (`batch_one_object_bitmapped`)
2. Logic in `batch_each_object()` to use bitmaps when available
3. Careful handling of mixed scenarios where some packs have bitmaps and others don't

This completes the series' goal of providing efficient object type filtering, with the bitmap optimization making the feature practical for large repositories. The performance numbers validate the approach, showing the implementation scales with the number of matching objects rather than total repository size.
