This is part 7/8 of a feature series implementing remote object-info functionality, focusing on the client-side transport layer implementation. The patch adds client support for querying object sizes from protocol v2 servers without downloading full objects, completing the end-to-end capability that was previously server-side only.

The core addition is a new `fetch_object_info()` function that handles the protocol interaction, along with supporting infrastructure in the transport layer. The client will error out if the server doesn't advertise the object-info capability (controlled by `transfer.advertiseobjectinfo`). The implementation follows the same buffered request pattern used elsewhere in fetch-pack.c.

Key technical aspects include:
- New files `fetch-object-info.[ch]` for the core functionality
- Transport layer integration through new flags in `git_transport_options`
- Protocol v2-only enforcement with clear error messages
- Memory management via `xcalloc` with proper cleanup
- Input validation and error handling

The patch appears well-structured and builds logically on the server-side work from earlier in the series. It includes comprehensive error handling and follows established patterns in the codebase. The implementation is now complete with all security hardening from earlier review feedback incorporated.
