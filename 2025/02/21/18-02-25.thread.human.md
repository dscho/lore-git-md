This thread addresses a platform-specific build issue on OpenBSD, where the `getdelim()` function was not being exposed due to insufficient `_XOPEN_SOURCE` versioning. The proposed solution is a one-line change in `git-compat-util.h`, bumping `_XOPEN_SOURCE` from 600 to 700 specifically for OpenBSD. This ensures `getdelim()` is visible under OpenBSD 7.5/7.6's stricter header guards, preventing compilation failures with clang 19's default warnings-as-errors setting. The patch includes clear references to OpenBSD's source code to justify the change and maintains all existing platform-specific conditions while updating only the relevant comment. The change is minimal and well-documented, targeting a narrow compatibility issue without broader side effects.
