The core issue is that OpenBSD requires `_XOPEN_SOURCE 700` to expose `getdelim()`, while Git's build system only auto-enables `HAVE_GETDELIM` by default on Linux/macOS via `config.mak.uname`, leaving other platforms to rely on autoconf detection.

Audrey Dutcher initially proposed adjusting the `_XOPEN_SOURCE` setting in `git-compat-util.h`, prompting discussion about whether to modify the existing platform handling or create OpenBSD-specific logic as Junio C Hamano suggested.
