This is a refactoring patch in the remote object-info series, moving initialization code in preparation for future state machine changes.

The patch relocates some variable initialization from inside the first state (FETCH_CHECK_LOCAL) of the fetch-pack state machine to just before the state machine begins. This is a preparatory change that enables a subsequent patch to introduce an alternative initial state while still maintaining these initializations. The change is purely structural - no behavior is altered, as the timing of these initializations remains effectively the same.

The patch comes with sign-offs from both Calvin Wan (the original author) and Eric Ju (the submitter), indicating it's part of their collaborative work on the larger remote object-info feature. The change has also received input from Jonathan Tan and Christian Couder, suggesting it's been through review. This appears to be a straightforward, well-justified refactoring that keeps the codebase clean while enabling future development.
