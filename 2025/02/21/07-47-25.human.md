This is a feature series introducing object filtering to `git cat-file --batch-all-objects`, with significant speed improvements when using bitmap indices.

Patrick Steinhardt proposes adding object type filtering to `git cat-file`'s batch mode, motivated by performance issues when processing large repositories like Chromium. Currently, filtering requires piping through `grep` and `cut`, which becomes impractical with 50GB packfiles taking 100+ seconds to scan. The series adds direct support for `blob:none`, `blob:limit=`, and `object:type=` filters matching `git rev-list`'s syntax.

The real performance win comes from leveraging bitmap indices where available, allowing the command to skip scanning entire packfiles when possible. Benchmarks show dramatic improvements - filtering tags becomes ~4000x faster (20ms vs 82s), while commits see a 75x speedup. The implementation cleanly separates the filtering logic from the object iteration, with later patches introducing bitmap optimization.

The 9-part series starts with preparatory refactoring, adds basic filtering support, then introduces bitmap acceleration. Test coverage appears thorough, with new tests in t1006. This looks like a well-motivated change that could benefit large-repository workflows, particularly when combined with existing bitmap infrastructure.
