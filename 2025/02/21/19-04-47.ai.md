This is a server-side capability advertisement patch in the remote object-info feature series. It modifies the server to advertise supported object-info features to clients, specifically the "size" capability when enabled via `transfer.advertiseobjectinfo` config.

The patch changes `object_info_advertise()` in serve.c to:
1. Pass through a `strbuf` parameter that was previously unused
2. When the feature is enabled, append "size" to the value string to indicate this capability is available
3. Maintain the existing behavior where the feature is disabled by default unless explicitly configured

This allows clients to check server capabilities before attempting object-info queries, falling back to full fetches when the feature isn't available. The change is minimal but critical for the end-to-end functionality, building on Calvin Wan's earlier server-side work and integrating with the client-side implementation seen in previous patches of the series.

The patch carries forward sign-offs from both Calvin Wan and Eric Ju, indicating collaborative development, and includes help tags from Jonathan Tan and Christian Couder who provided feedback on earlier iterations. The change aligns with the series' security-hardened approach by maintaining explicit capability negotiation rather than assuming feature availability.
