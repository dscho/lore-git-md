Git cat-file batch mode filtering enhancement series (v1) by Patrick Steinhardt, introducing object type filtering capabilities to address GitLab's performance needs in large repositories. The series adds three filter types matching git rev-list syntax: "blob:none", "blob:limit=", and "object:type=". Current workarounds using shell pipelines are I/O-bound and slow (e.g., 100 seconds to scan Chromium's 50GB packfile).

Implementation splits into two phases: basic filtering support (patches 1-5) and bitmap optimization (patches 6-9). Key changes touch builtin/cat-file.c's object iteration logic and pack-bitmap.* handling. The bitmap optimization shows dramatic speedups: ~4000x faster for tags (20ms vs 82s) and 75x for commits. Benchmarks demonstrate scaling with matching objects rather than total repository size. Maintains backward compatibility while solving performance pain points in large repositories. Comprehensive tests added for new functionality.
