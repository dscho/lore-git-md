This is part of a feature series implementing remote object-info capabilities, specifically the server-side advertisement of supported features. The patch (6/8 in v11) modifies `serve.c` to advertise the "size" capability when the server is configured to support object-info queries.

The change allows clients to check whether a server supports object-size queries before attempting them, falling back to full fetches when unsupported. The advertisement is controlled by `transfer.advertiseobjectinfo` config (disabled by default) and will include the "size" capability string when enabled. This matches the client-side implementation in earlier patches of the series.

The patch is straightforward - it adds capability string output to an existing function while maintaining the same configuration behavior. It's part of a well-developed series that has incorporated extensive review feedback, including from Jonathan Tan and Christian Couder. The change is technically sound and aligns with the series' goal of enabling efficient object metadata queries without full downloads.
