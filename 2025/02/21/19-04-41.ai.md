This is the final version (v11) of an 8-part series implementing client-side support for remote object information queries via `git cat-file --batch-command`. The series builds on Calvin Wan's earlier work and integrates with existing server-side object-info capabilities.

The core addition is a new `remote-object-info` command that lets clients query object sizes from protocol v2 servers without full objects. The implementation spans protocol handling, transport layer modifications, and user-facing command integration, with particular attention to security hardening in this final version. Key technical elements include:

- New `fetch-object-info.[ch]` files handling protocol interaction
- Generalized packet-writing infrastructure in connect.c (`write_command_and_capabilities()`)
- Server capability advertisement via `transfer.advertiseobjectinfo`
- Strict protocol v2 enforcement with clear error messages
- New `strtoul_ul()` utility for robust unsigned long parsing
- Comprehensive t1017 test coverage for protocol scenarios
- Hardened input validation with:
  - Buffer overflow protection (MAX_REMOTE_URL_LEN, MAX_ALLOWED_OBJ_LIMIT)
  - NULL dereference prevention (replaced `xstrdup_or_null()`)
  - Resource exhaustion guards
  - Strict command input length checking

The v11 changes focus on security improvements from Jeff King's review, adding overflow checks and hardening the transport layer. The series now cleanly handles error cases while maintaining the original functionality - querying object sizes from remote servers via `cat-file --batch-command`. While currently limited to object sizes, the architecture is designed for future expansion to support object types and other metadata.

All review feedback has been incorporated, making this a polished implementation ready for consideration. The security hardening in particular addresses potential attack vectors while maintaining the feature's usability. The patch series represents a complete solution with both client and server components, though it leaves room for future expansion to support additional object information types.
