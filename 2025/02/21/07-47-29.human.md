This is a feature patch adding size-based blob filtering to `git cat-file`. It's part of a larger series (4/9) introducing object filtering capabilities.

The patch implements a new `blob:limit=<n>` filter that excludes blobs larger than the specified size (with support for k/m/g suffixes). This complements the existing `blob:none` filter that excludes all blobs. The implementation touches the core cat-file logic to check blob sizes against the limit and updates documentation to explain the new syntax.

The changes appear well-considered: the implementation is straightforward, tests cover various limit sizes (including edge cases), and documentation is clear. The patch builds on existing filter infrastructure while cleanly adding the new capability. This seems like a useful addition for scripts that want to process repository contents while avoiding large binary files.
