Refactoring patch in a series about `git cat-file` improvements.

This is the first of 9 patches from Patrick Steinhardt that appears to be preparing for some changes to `git cat-file`. The current patch is a straightforward renaming of a variable called `usage` to `builtin_catfile_usage` in the `builtin/cat-file.c` file. The change is motivated by avoiding a name collision with a future `usage()` function that will be introduced later in the series.

The patch mechanically updates all references to this variable throughout the file, which is used for storing the command's usage strings and passing them to various option-parsing functions. The new name follows the convention seen in other Git builtins. This appears to be purely preparatory work with no behavior changes - a clean, focused patch that should be uncontroversial to merge.
