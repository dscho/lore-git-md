This is a feature and performance enhancement series for `git cat-file`'s batch mode, introducing object type filtering capabilities. The cover letter explains the motivation comes from GitLab's need to efficiently list objects of specific types in large repositories, where current workarounds using shell pipelines are I/O-bound and slow (e.g., 100 seconds to scan Chromium's 50GB packfile).

The series adds three filter types matching `git rev-list` syntax: "blob:none", "blob:limit=", and "object:type=". The key innovation is leveraging bitmap indices when available to avoid full packfile scans, showing dramatic speedups in benchmarks - filtering tags becomes ~4000x faster (20ms vs 82s), while commits see a 75x improvement. The implementation splits into two phases: first adding basic filtering (patches 1-5), then optimizing with bitmaps (patches 6-9).

The changes touch core object iteration logic in `builtin/cat-file.c` and bitmap handling in `pack-bitmap.*`, with comprehensive tests added. The approach maintains backward compatibility while solving a clear performance pain point in large repositories. The cover letter provides thorough benchmarking showing the filters scale with the number of matching objects rather than total repository size.
