Refactoring patch in the Git cat-file batch mode filtering series, preparing for bitmap optimizations.

This patch consolidates duplicate object iteration logic in `builtin/cat-file.c` into a new `batch_each_object()` helper function. While currently a simple refactoring (replacing two function calls with one), it lays groundwork for upcoming bitmap integration by providing a single point to modify the iteration behavior. The changes:

1. Introduces `for_each_object_fn` callback type and `for_each_object_payload` struct to standardize iteration callbacks
2. Replaces separate loose/packed object handlers (`collect_loose_object`, `batch_unordered_loose`, etc.) with unified variants (`batch_one_object_loose`, `batch_one_object_packed`)
3. Implements new `batch_each_object()` that handles both loose and packed object iteration through a single interface

The refactoring affects the batch object processing paths in cat-file, particularly the unordered output mode and object collection for ordered output. No behavior changes are introduced yet - this is purely preparatory work for patch 9/9 which will add bitmap acceleration. The changes maintain all existing functionality while making the codebase more amenable to the bitmap optimizations discussed in the series.
