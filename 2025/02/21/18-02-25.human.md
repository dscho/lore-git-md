Platform compatibility patch for OpenBSD compilation. 

Audrey Dutcher submits a one-line change to `git-compat-util.h` that bumps the `_XOPEN_SOURCE` define from 600 to 700 when compiling on OpenBSD. This is needed because OpenBSD 7.5/7.6 hides the `getdelim()` function behind stricter POSIX visibility requirements, causing compilation failures with default clang 19 settings that treat implicit function declarations as errors.

The patch is narrowly scoped and well-justified with links to OpenBSD source code showing the relevant header conditions. It maintains the existing pattern of platform-specific adjustments in this compatibility header while updating the comment to accurately reflect the new requirement (getdelim() support rather than S_ISLNK()). 

This appears to be a straightforward fix for a real compilation issue on a supported platform, with no obvious downsides or compatibility concerns raised. The change follows Git's established pattern for handling such platform-specific feature gates.
