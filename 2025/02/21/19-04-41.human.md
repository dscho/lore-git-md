This is the final version (v11) of an 8-part series implementing client-side support for remote object information retrieval via `git cat-file --batch-command`. The series builds on Calvin Wan's earlier work and adds a new `remote-object-info` command that queries object sizes from protocol v2 servers without full objects.

The implementation spans protocol handling, transport layer modifications, and user-facing command integration. Key features include strict protocol v2 enforcement, size capability advertisement via `transfer.advertiseobjectinfo`, and comprehensive error handling. The series has undergone significant security hardening in v11, addressing NULL dereference risks, integer overflow prevention, and input validation.

The patch set includes transport layer generalization (moving packet-writing code from fetch-specific to protocol v2 generic), server capability advertisement, and the final `cat-file` integration with batching support. Testing is thorough, with a new t1017 test suite covering various protocol scenarios.

Notable changes since v10 include additional overflow checks and abuse prevention measures. The series is now complete with all technical and security issues addressed, including all review feedback (particularly from Jeff King on security aspects). Future work may expand support to additional object info types like objecttype and deltabase.

The implementation appears robust and well-tested, with careful attention to security considerations. The changes touch multiple subsystems (protocol, transport, object handling) but maintain clean separation of concerns. This looks ready for final review and potential merging.
