Feature enhancement to `git cat-file`'s batch filtering capabilities, part of Patrick Steinhardt's series improving object filtering performance. This patch specifically adds an "object:type=" filter that allows restricting output to objects of a specified type (blob, commit, tag, or tree), matching the existing `git rev-list` syntax.

The implementation adds a new LOFC_OBJECT_TYPE filter choice to the objects_filter struct, checks the object type during batch output, and skips non-matching objects. Documentation is updated to describe the new filter syntax, and tests are added to verify behavior with all four object types. The change maintains consistency with the series' approach of adding filters that mirror rev-list functionality while optimizing for batch processing performance.

This is the fifth patch in a 9-part series that began with basic filtering support and will conclude with bitmap optimizations. The implementation here is straightforward, building on the filter infrastructure established in earlier patches. Test coverage appears thorough, exercising each object type individually. The patch follows the series' pattern of adding one clearly-scoped filter type per commit while maintaining backward compatibility.
