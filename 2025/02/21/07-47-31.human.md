Performance optimization in the Git cat-file batch filtering series, introducing bitmap iteration for object types. This is patch 6/9 in Patrick Steinhardt's series to enhance `git cat-file --batch` with object type filtering capabilities.

The patch exposes a new function `for_each_bitmapped_object()` that allows efficient iteration over all bitmapped objects of a specific type (commit, tree, blob, or tag). This avoids scanning entire packfiles when only certain object types are needed, which is particularly beneficial for large repositories. The implementation builds on the bitmap infrastructure while maintaining consistency with the existing codebase.

The changes touch several files but primarily focus on `pack-bitmap.c`, where the core iteration logic is refactored to support the new functionality. The patch includes updates to callback signatures to accommodate a new `payload` parameter, making the interface more flexible for future extensions.

This is part of the series' second phase focusing on bitmap optimizations, following the basic filtering support added in earlier patches. Benchmarks mentioned in the thread context show dramatic speedups (up to 4000x for certain operations) when using these bitmap-based approaches compared to traditional packfile scanning.
