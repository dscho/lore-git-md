This is part 7 of a 9-part performance optimization series enhancing `git cat-file`'s batch mode with object type filtering capabilities. The patch introduces a helper function `bitmap_index_contains_pack()` that checks whether a given packfile is covered by a bitmap index, either directly or through a multi-pack index. 

The change is straightforward plumbing work - it adds the new function to both the implementation and header file with clear documentation. While small, this is a building block for the series' later optimizations that will use bitmaps to dramatically speed up object type filtering (as noted in the thread context, showing 4000x speedups for some cases).

The patch maintains the series' clean style and focused approach, with each commit doing one logical thing. Since this is infrastructure for later optimizations rather than a user-facing change itself, the commit message is appropriately brief, simply stating its purpose as groundwork for subsequent work.
