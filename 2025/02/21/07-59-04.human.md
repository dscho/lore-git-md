This is a discussion about test infrastructure in the ongoing series converting oid-related tests to the Clar framework. Patrick Steinhardt responds to Phillip Wood's feedback on patch 1/5, which proposed moving test helper functions into shared unit-tests.{c,h} files.

Patrick agrees with Phillip's concern that putting oid-specific helpers in the shared unit-tests files would create unnecessary dependencies (strbuf.o and hex.o) for all tests. He suggests keeping the helpers in lib-oid.c (the current location) but renaming them with a "cl_" prefix to avoid symbol conflicts and make their Clar-framework purpose clear. Specifically, he proposes renaming `init_hash_algo()` to `cl_setup_hash_algo()`.

The exchange shows the careful consideration being given to test architecture boundaries in this conversion effort. While the technical discussion is specific, it reflects broader concerns about maintaining clean separation between test components and avoiding unnecessary coupling. The author (Seyi Kuforiji) will likely need to revise patch 1/5 based on this feedback.
