This is the final patch (8/8) in a v11 series implementing remote object-info functionality. It adds a new `remote-object-info` command to `git cat-file --batch-command` that queries object sizes from remote repositories without downloading the full objects.

The patch introduces the user-facing command that allows batching multiple OID queries to a remote in a single request, avoiding per-object network overhead. It works across git://, file:// and http:// transports when the server advertises the object-info capability (enabled via `transfer.advertiseobjectinfo`). The implementation handles capability negotiation, request formatting, and response parsing while maintaining the existing batch-command interface.

Key technical details:
- New command syntax: `remote-object-info <remote> <oid> <oid>...`
- Default format is `%(objectname) %(objectsize)` (object type not yet supported)
- Rejects unsupported format options like `%(objecttype)` and `%(deltabase)`
- Implements both buffered and non-buffered modes
- Adds comprehensive tests covering protocol v2 requirements, capability negotiation, and error cases
- Includes security hardening against malformed input and protocol violations
- Documents caveats about current format limitations with warnings about future changes

The implementation builds on the protocol and transport work from earlier patches in the series, completing the end-to-end functionality. All review feedback has been incorporated, including security hardening from Jeff King and transport layer improvements from Jonathan Tan.
