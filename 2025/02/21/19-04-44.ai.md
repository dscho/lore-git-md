This is a test infrastructure patch in the remote object-info series, refactoring test utilities into a shared library.

The patch moves three utility functions from t1006-cat-file.sh into a new lib-cat-file.sh file: `echo_without_newline`, `echo_without_newline_nul`, and `strlen`. These are basic string manipulation helpers used in cat-file tests. The functions remain unchanged - they're just being relocated to make them reusable by other tests that may need similar functionality.

The change is straightforward with no behavior modifications - it deletes the functions from their original location and adds them to the new library file, with t1006-cat-file.sh sourcing the library. This follows Git's common pattern of moving test helpers into shared libraries under t/lib-*.sh when they may be useful across multiple scripts.

This appears to be preparatory work for the later patches in the series that will add new cat-file functionality (the remote-object-info command). Having these utilities in a shared library will allow the new tests to use them without duplication. The patch is cleanly implemented with proper file modes and includes the necessary sourcing of the new library.
