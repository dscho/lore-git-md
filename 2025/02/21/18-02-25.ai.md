Platform compatibility patch addressing OpenBSD build issues. This change bumps `_XOPEN_SOURCE` from 600 to 700 in `git-compat-util.h` specifically to expose `getdelim()` on OpenBSD systems. The commit explains that OpenBSD 7.5/7.6 hides `getdelim()` behind `__POSIX_VISIBLE >= 200809`, which requires the higher `_XOPEN_SOURCE` value. Without this change, compilation fails with implicit declaration errors when using clang 19's default `-Werror=implicit-function-declaration`.

The patch includes links to OpenBSD source code showing the relevant header guards. It maintains all existing platform-specific conditions in the `#if` chain while updating only the OpenBSD-specific comment to reflect the new requirement for `getdelim()` rather than the previous `S_ISLNK()` need. The change is minimal (one line modified) and appears well-researched with clear references to upstream OpenBSD implementation details.
