This is a feature patch adding blob filtering support to `git cat-file`. It implements the "blob:none" filter option, which causes `git cat-file` to skip blob objects when processing batch output. This matches existing filtering behavior in other Git commands like `rev-list`.

The patch adds documentation for the new filter, implements the filtering logic in the cat-file code (skipping blobs when the filter is active), and includes comprehensive tests that verify the filter works across different object storage types (packed with bitmap, packed without bitmap, and loose objects). The tests compare the output against `git rev-list`'s the same filter to ensure consistency.
