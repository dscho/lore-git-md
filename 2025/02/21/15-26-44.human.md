This is a minor documentation correction in the ongoing Git 3.0 breaking changes effort. Jakub Wilk points out that Patrick Steinhardt's claim about "branches/" directories being absent from modern repositories isn't quite accurate - they were part of the default template until recently and thus exist (though often empty) in many repositories. He suggests rewording to say these directories are "unlikely to be used" rather than "not to be found".

The thread context shows this is part of the final patch in a series removing legacy remote configuration support, where the team has been carefully refining deprecation warnings and documentation. While this is a small nit, it demonstrates the attention to detail in accurately describing the transition state for users. The correction doesn't affect the technical implementation but helps set proper expectations about where these legacy directories might still exist.
