This is version 2 of Lucas Seiki Oshiro's patch documenting Git's special handling of submodule conflicts during merges, which has already received technical approval from reviewers. The patch explains two cases where Git provides automated conflict handling for submodules: attempting fast-forwards when one commit is a descendant of another, and suggesting common descendants while keeping the conflict marked for user confirmation.
