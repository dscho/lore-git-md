Review feedback on oidtree test conversion to Clar framework (patch 4/5)

Phillip Wood provides review comments on the fourth patch in Seyi Kuforiji's series converting oid-related tests to the Clar framework. This patch specifically handles the oidtree test conversion.

The review notes several improvements from the original test implementation, including better error reporting through `cl_assert_equal_s()` which will show mismatched OIDs, and the safe removal of return value checks thanks to `cl_parse_any_oid()`. However, Phillip points out that the conversion loses some useful debugging information - the test now stops at the first error rather than continuing to find all issues, and the error message showing which query failed has been removed. He suggests using `cl_failf()` to preserve this information.

This continues the pattern seen in earlier patches of the Clar conversion improving some aspects while potentially losing others. The feedback is constructive, focusing on maintaining test quality during the framework transition. Phillip notes this patch is otherwise looking good, similar to his assessment of patch 3/5, with just this one remaining issue to address regarding error messaging.

The exchange shows steady progress in the series, with the mentor (Patrick Steinhardt) and reviewer (Phillip Wood) working collaboratively with the author to refine the test conversions while maintaining the project's testing standards.
