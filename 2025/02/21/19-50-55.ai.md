This is a follow-up in the ongoing Meson build system integration thread, specifically about coverage reporting functionality. Ramsay Jones confirms Patrick Steinhardt's earlier statement that Meson has native coverage support, sharing his successful test results using the `gcovr` tool with the Meson` coverage-html` target. The output shows Git's current coverage at 85.2% lines, 93.3% functions, and 76.0% branches - numbers Ramsay jokingly notes would be considered low on some projects. This exchange validates that one of the static analysis/documentation targets (coverage reporting) is already properly implemented in the Meson build system, leaving only the remaining targets (hdr-check, check-pot, check-builtins, check-docs) to be addressed in future work as previously discussed in the thread. The positive confirmation helps move the overall Meson integration effort forward by checking off one of the items Ramsay had previously identified as needing attention.
