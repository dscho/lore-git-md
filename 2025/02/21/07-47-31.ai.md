Performance optimization patch in the Git cat-file batch mode filtering series, introducing bitmap iteration for object type filtering.

This patch exposes a new function `for_each_bitmapped_object()` in the pack-bitmap API that enables efficient iteration over all bitmapped objects of a specific type (commit, tree, blob, or tag). The implementation builds on the series' earlier work by refactoring the existing type-specific bitmap handling into a reusable interface. Key changes include:

1. Extracting the bitmap selection logic into `ewah_for_type()` helper
2. Generalizing the iteration callback to accept a payload parameter
3. Adding the new public function that converts the type-specific EWAH bitmap to a regular bitmap for iteration

The patch updates callers in builtin/pack-objects.c, builtin/rev-list.c, and reachable.c to handle the new payload parameter, though they currently ignore it. This change lays groundwork for the upcoming performance optimizations in the series, enabling direct bitmap access for object type filtering rather than scanning entire packfiles. The implementation maintains consistency with the series' goal of matching `git rev-list` syntax while optimizing for batch processing scenarios.
