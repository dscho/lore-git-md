This is a refactoring patch in the remote object-info series, focusing on fetch-pack initialization changes. The patch moves variable initialization out of the FETCH_CHECK_LOCAL state in the fetch-pack state machine to a position before the state machine begins. This prepares for future changes where different initial states might be used while still needing these same initializations.

The changes affect three key variables in fetch-pack.c:
1. `allow_unadvertised_object_request` gets ALLOW_REACHABLE_SHA1 by default
2. `use_sideband` is set to 2 (indicating sideband protocol version)
3. `args->deepen` is set based on depth-related arguments

The patch maintains identical behavior while making the code more flexible for future protocol v2 work. It's a straightforward mechanical change that has already been reviewed by Jonathan Tan and Christian Couder, with their feedback incorporated. The change is part of the larger effort to generalize protocol v2 packet-writing capabilities, though this particular patch doesn't touch that directly - it's more about state machine setup.
