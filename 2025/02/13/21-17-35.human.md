Build system fix for zlib Makefile syntax. This is a follow-up to Taylor Blau's patch that corrects tab indentation in zlib-related Makefile conditionals, which Junio Hamano is responding with an ack. The issue stems from a recent zlib-ng support commit that accidentally reintroduced tab characters in conditional blocks, breaking builds with GNU Make 4.4.90+. The fix mechanically replaces tabs with spaces to maintain compatibility while preserving the exact same build logic. This aligns with the project's established Makefile style from commit 728b9ac0c3. The change is purely about build system syntax and doesn't affect runtime behavior. The patch appears straightforward and well-justified, with Junio's "Yikes" and quick ack suggesting this was an obvious oversight needing prompt correction.
