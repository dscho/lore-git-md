Build system patch adding Windows credential helper support to Meson. This is the first of two patches in a series to enable building credential helpers under Meson, specifically addressing the Windows wincred helper here.

The patch makes several straightforward changes to integrate the wincred helper into the Meson build system:
1. Adds new meson.build files for the credential directory and wincred helper
2. Introduces a credential_wincred build option
3. Fixes an MSVC compilation issue by conditionally applying a GCC attribute
4. Wires up the build configuration to include the helper when requested

The changes appear mechanical and maintain parity with the existing Make-based build system. The patch fixes a specific compilation error that occurs when building with MSVC by making the format attribute GCC-specific. This is part of the ongoing effort to expand Meson support across Git's build system.

The patch is cleanly focused on build system integration with no functional changes to the credential helper itself. The series appears to be progressing the goal of making Meson a fully-supported alternative build system.
