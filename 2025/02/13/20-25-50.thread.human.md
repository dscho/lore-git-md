This thread addresses a build system issue where tab characters in Makefile conditionals were causing failures with GNU Make 4.4.90+. The problem originated in commit b9d6f64393 when adding zlib-ng support, conflicting with an earlier standardization effort (728b9ac0c3) that had replaced tabs with spaces in conditionals.

The fix is straightforward - it converts the tab indentation to 8 spaces in the ZLIB_NG and ZLIB_PATH conditional blocks while keeping the actual logic unchanged. This maintains compatibility with newer Make versions without affecting the zlib backend functionality. The change is mechanical but necessary for building Git on systems with modern toolchains.
