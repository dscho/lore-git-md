This thread introduces a patch series adding Meson build system support for Git's credential helpers on Windows (wincred) and Linux (libsecret). The changes are purely build-related - they wire up these existing platform-specific credential helpers to be properly compiled when using Meson instead of the traditional Make-based build system.

The two patches add the necessary Meson build files for each helper and include them in the parent credential directory's build configuration. The author notes these are straightforward mechanical additions that don't modify the actual helper functionality. One open question remains about how to properly test the wincred helper via GIT_TEST_CREDENTIAL_HELPER, which hasn't been implemented yet in the Meson context.

The changes affect build infrastructure only, specifically the contrib/credential/ subdirectory where these helpers live. Windows and Linux users building with Meson will now get these credential helpers included automatically, matching the existing Make-based behavior.
