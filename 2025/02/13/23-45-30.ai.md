Maintainer response regarding mailmap behavior and crash investigation.

Junio Hamano responds to Jacob Keller's bug report about `git check-mailmap` segfaults with technical clarification about expected mailmap behavior. The discussion centers on whether email-only lookups should match "full" mailmap entries (those specifying both old name and email). Hamano argues that according to documentation, full entries should only match when both name and email are provided, so the current output (returning the input email unchanged) is correct behavior rather than a bug. This contradicts the original reporter's expectation that email-only lookups should match against full entries.

The response provides important context about mailmap's design philosophy - full entries act as stricter mappings that require both name and email to match, while simpler email-only entries apply more broadly. Hamano confirms being able to reproduce the segfault but suggests the underlying issue may be more about clarifying expected behavior than fixing implementation. The discussion leaves open whether the segfault fix should proceed independently of the behavior question, and whether documentation needs updating to better explain these semantics.
