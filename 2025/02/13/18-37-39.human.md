This is the second patch in a build system series adding Meson support for credential helpers, focusing on the Linux libsecret implementation. Following the first patch's wincred support, this one adds the necessary Meson build files for the libsecret credential helper.

The changes are straightforward build plumbing: a new meson.build file for the libsecret helper that declares its glib and libsecret dependencies, an update to the credential directory's meson.build to conditionally include it, and a new credential_libsecret boolean option in meson_options.txt (disabled by default). Like the wincred changes, this maintains parity with the existing Make-based build system.

The patch follows the same approach as the first in the series - purely build system changes with no runtime behavior modifications. The implementation looks clean and consistent with other Meson integrations in the codebase. Together with the wincred patch, this completes the Meson support for these two platform-specific credential helpers.
