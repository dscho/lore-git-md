This is a build system patch series that wires up two credential helpers (`wincred` and `libsecret`) to be built via Meson. The author notes they'd like to test the wincred helper with `GIT_TEST_CREDENTIAL_HELPER=wincred` but haven't figured out how yet.

The two patches add Meson build files for the credential helpers, which were presumably only built via Makefile previously. The changes are straightforward - creating new build files and adding them to the build system. The wincred helper is for Windows credential storage, while libsecret is for Linux/Unix systems using the Secret Service API.

The patch series appears to be a straightforward build system modernization, though the author's testing comment suggests there may be more work needed to fully integrate these helpers into the test suite. The changes are small and focused, touching only build configuration files.
