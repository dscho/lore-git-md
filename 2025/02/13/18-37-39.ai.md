This is the second patch in a two-part series adding Meson build support for credential helpers, specifically focusing on the Linux libsecret implementation. Following the first patch that handled the Windows wincred helper, this completes the credential helper support in the Meson build system.

The patch adds Meson configuration for the libsecret credential helper, creating a new `meson.build` file in the libsecret directory that specifies the required GLib and libsecret dependencies and builds the executable. It updates the parent credential directory's Meson file to conditionally include libsecret based on a new `credential_libsecret` option, and adds that boolean option to `meson_options.txt` (disabled by default).

Key technical details:
- New `meson.build` for libsecret helper with GLib/libsecret dependencies
- Conditional inclusion via `credential_libsecret` option
- Maintains parity with Make-based builds
- Follows same pattern as wincred helper from first patch
- No functional changes to the helper itself

The patch appears straightforward and well-contained, completing the credential helper support in Meson that was started with the wincred helper. The changes are purely build system plumbing with no runtime impact, keeping behavior identical to the Make-based builds. This continues the project's ongoing effort to expand Meson build coverage across all components.
