This is a release announcement for Git for Windows 2.48.1, marking both feature updates and significant deprecation notices. The announcement comes from Johannes Schindelin and targets Windows users and packagers.

The release includes several component updates: Git v2.48.1, MinTTY v3.7.7, Tig v2.5.12, cURL v8.12.1, and OpenSSL v3.2.4. A notable change is the new default Windows-native HTTPS transport backend for installations. The MSYS2 runtime is now based on Cygwin v3.5.7, skipping problematic intermediate versions.

Two major deprecations are announced: this is the last release to include 32-bit installers (except for MinGit, which will continue until April 2029), and git-svn support will be phased out in future versions due to maintenance challenges and low usage. The release also includes several bug fixes, including corrected Windows version blocking for unsupported OSes, a cache credential helper fix, and removal of a misleading .gitignore warning.

The announcement provides SHA-256 checksums for all distribution formats (installers, portable versions, and MinGit packages) across 64-bit, ARM64, and 32-bit architectures. This appears to be a routine maintenance release with some forward-looking platform strategy decisions, particularly around architecture support and feature pruning.
