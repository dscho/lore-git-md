This is a documentation clarification in the ongoing pickaxe long-options series. Junio Hamano reviews Illia Bobyr's patch that fixes the help text for `- S` (pickaxe) in diff.h, which previously inaccurately described the behavior as finding filepairs where only one side contains the string. The corrected text properly explains that `-S` actually shows changes where the number of string occurrences differs between file versions.

Hamano notes that while the original text better reflected the historical intent of `-S` (to detect when a unique block of text appears/disappears), the new wording more accurately describes the current implementation's behavior with non-unique strings. He cites Linus Torvalds' original 2005 email that motivated `-S`'s creation, showing good historical context.

The change is small (a single line in diff.h) but meaningful, as it helps users better understand what `-S` actually does versus what it was originally designed for. This patch is part of a larger v5 series adding long option names for pickaxe functionality, with this particular change addressing a documentation accuracy issue that surfaced during review.
