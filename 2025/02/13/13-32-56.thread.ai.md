Git for Windows 2.48.1 release announcement from Johannes Schindelin. This is a Windows-specific distribution update tracking upstream Git v2.48.1 with bundled components: MinTTY v3.7.7, Tig v2.5.12, cURL v8.12.1, OpenSSL v3.2.4, and MSYS2 runtime based on Cygwin v3.5.7. Key changes include new default Windows-native HTTPS transport backend and two major deprecations: final 32-bit installer release (except MinGit supported until April 2029) and planned git-svn removal due to maintenance burden. Fixes address Windows version blocking, cache credential helper, and .gitignore warning. Provides SHA-256 checksums for 64-bit, ARM64, and 32-bit distribution formats (installers, portable/MinGit packages). This marks strategic platform decisions around architecture support sunsetting and feature pruning while maintaining routine component updates.
