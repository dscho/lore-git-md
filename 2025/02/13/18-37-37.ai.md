This is a build system patch series adding Meson support for credential helpers. The two-patch series wires up the credential-wincred (Windows) and credential-libsecret (Linux) helpers in the Meson build system, which was missing these components.

The changes are straightforward build plumbing - each patch adds the necessary Meson build files to compile and include the respective credential helper. The wincred helper gets a new build file, while libsecret gets both a new build file and an entry in the parent credential directory's build file. The series also adds corresponding options to meson_options.txt to control their inclusion.

The author notes they'd like to also test the wincred helper with GIT_TEST_CREDENTIAL_HELPER=wincred but haven't figured out how to implement that yet. The patches appear to be simple mechanical additions without any behavior changes - they just ensure these existing credential helpers are properly built when using Meson rather than Make.

Key technical details for future reference:
- Adds meson.build files for contrib/credential/{wincred,libsecret}
- New options in meson_options.txt for both helpers
- Touches credential helper subsystem build infrastructure
- No functional changes to the helpers themselves
- Windows (wincred) and Linux (libsecret) platform-specific components
