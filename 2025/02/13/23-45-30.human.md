Maintainer response on mailmap behavior interpretation and crash report. Junio Hamano weighs in on Jacob Keller's reported `git check-mailmap` segmentation fault, confirming the crash but disagreeing with the expected behavior interpretation. The crash occurs when querying email-only lookups against full mailmap entries (those mapping both name and email), which Hamano reproduces using the project's own mailmap. 

On the behavioral question, Hamano argues the current output (returning the input email unchanged) is correct for full entries when no name is provided, as full entries should only match when both name and email match the input. This differs from Keller's expectation that email-only lookups should match against full entries. 

The response clarifies the mailmap specification but doesn't address the technical fix for the NULL pointer crash, focusing instead on establishing the correct expected behavior. This suggests the patch may need revision to align with the maintainer's interpretation of how full mailmap entries should work, beyond just fixing the immediate segfault. The discussion appears headed toward resolving both the technical implementation and the behavioral specification.
