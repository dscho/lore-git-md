Build system patch adding Meson support for the Windows credential helper, part of a series to enable credential helper builds under Meson.

This first patch in the two-part series focuses on the Windows credential helper (wincred), making several build system changes to support compilation under Meson. The key changes include:

1. Adding a new `meson.build` file for the credential directory that conditionally includes the wincred subdirectory based on a new `credential_wincred` option
2. Creating a simple `meson.build` for the wincred helper itself to build the executable
3. Modifying the main contrib build configuration to include the credential directory
4. Adding the new `credential_wincred` boolean option to meson_options.txt (disabled by default)

The patch also includes a small code change to the wincred helper source - adding an `#ifndef _MSC_VER` guard around a `__attribute__` declaration that MSVC doesn't support. This appears to be fixing a compilation error when building with MSVC, though the commit message doesn't provide details about the specific error.

The changes are straightforward and mechanical, maintaining parity with the existing Make-based build system while adding Meson support. The patch follows the pattern seen elsewhere in the codebase for Meson integration of contrib components. The series appears to be part of ongoing work to expand Meson build coverage to more parts of Git.
