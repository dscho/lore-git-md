This is a build system fix addressing Makefile syntax compatibility. The patch corrects tab indentation in conditional statements within the zlib configuration section of the Makefile, replacing them with spaces to maintain compatibility with GNU Make 4.4.90+ while adhering to the project's established style. The issue was introduced in commit b9d6f64393 (adding zlib-ng support) which accidentally reintroduced tab characters that had been standardized to spaces in 728b9ac0c3. The change affects two conditional blocks (`ZLIB_NG_PATH` and `ZLIB_PATH`) but does not alter the build logic or runtime behavior. The fix is mechanical and uncontroversial, with Junio C Hamano acknowledging the quick response to the issue. The patch aligns with the project's prior standardization effort and resolves the build failure on systems with newer Make versions.
