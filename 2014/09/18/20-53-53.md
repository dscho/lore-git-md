**Thread**: [thread](./20-53-53.thread.md#:~:text=2014/09/18/20-53-53)

Add a new format specifier, '%D' that is identical in behaviour to '%d',
except that it does not include the ' (' prefix or ')' suffix provided
by '%d'.
