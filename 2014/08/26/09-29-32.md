I'd like to add a list parameter to the `git remote` command.

We already have:

 - `git remote add`
 - `git remote rename`
 - `git remote delete`

I often write `git remote list` before finaly using `git remote -v` but
it isn't intuitive.

I am proposing to add `git remote list` as a shortcut for `git remote -v`
