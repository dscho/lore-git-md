the incoming ce unnecessary.

As the rule is "if ret is different from ce, then ce must be freed"
in this codepath, I wonder if this is easier to read:

```
	ret = refresh_cache_entry(ce, ...);
        if (ret != ce)
        	free(ce);
	return ret;
