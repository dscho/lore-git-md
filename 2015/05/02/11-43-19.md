> cmd=$(echo $(line | cut -d : -f 1)


There are various ways to do that without a command substitution, eg:

```
   cmd=${line%%:*}
   grp=${line#:*}

```

or:

```
   IFS=:
   set $line
   cmd=$1 grp=$2

```

or:

```
  sort |
  while IFS=: read cmd grp
  do

```
