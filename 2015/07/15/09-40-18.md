Creating a repo `foo`, checkout --to'ing it to ../bar, then try to
clone both resulting repositories..

```
$ git --version

$ mkdir foo
$ cd foo
```

$ git init

$ git commit -m init --allow-empty

$ git branch bar
$ git checkout bar --to ../bar
```

```
$ cd ../bar

$ cd ..
$ git clone bar baz
