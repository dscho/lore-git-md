**Thread**: [thread](./../17/15-47-09.thread.md#:~:text=2019/01/18/09-41-03)

Create a file  .git/info/attributes with contents

If the contents are:
[attr]allowed-ext
*.py allowed-ext=100

then the problem occurs.

If contents are:
#[attr]allowed-ext
*.py allowed-ext=100

the problem is gone
