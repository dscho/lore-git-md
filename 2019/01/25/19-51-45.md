If the readability of a here-doc is preferred, you should be able to
achieve the desired result with the q_to_tab() and lf_to_nul()
functions. For instance:

```
    q_to_tab <<-\EOF | lf_to_nul >expect &&
    ...Q...Q...
    EOF
```
