buffer overrun: in the main loop, `path + sep` might point to the
trailing `NUL`, but we assign `p += sep + 1;` at the end (which is only
correct when `path + sep` points at whitespace).

part of the range-diff reads like this:

     +				printf(_("Huh (%s)?\n"), p);
