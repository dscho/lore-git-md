This thread is about porting Git for Windows' GUI credential and prompt helpers to the mainline git-gui project. The series, originally developed by Heiko Voigt and now rebased by Johannes Schindelin, implements GIT_ASKPASS and GIT_ASK_YESNO functionality with Windows-specific enhancements.

The first patch introduced `git-gui--askyesno`, a Tcl/Tk script for interactive yes/no dialogs, while the second modified git-gui.sh to set GIT_ASKPASS appropriately. The newly arrived third patch adds a `--title` option to customize dialog window titles, a feature requested by Git for Windows' auto-updater to provide more context-specific prompts. The implementation maintains backward compatibility while adding just 10 lines of focused changes.

The series builds on git-gui's existing credential helper patterns and appears uncontroversial, with sign-offs from both original and rebasing authors. The changes have already proven useful in Git for Windows and are now being upstreamed to benefit all users. One patch is still forthcoming to implement Windows-specific icon handling and make these helpers default in git-gui.
