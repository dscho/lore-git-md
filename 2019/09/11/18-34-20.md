Also, after Bert's patch, the toggling becomes much simpler. All you'd 
have to do is something like:

```
  bind . <$M1B-Key-e> {
	# Toggle commit type.
	set commit_type_is_amend [expr {!$commit_type_is_amend}]
	do_select_commit_type
  }

```
