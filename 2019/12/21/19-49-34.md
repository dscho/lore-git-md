**Thread**: [thread](./19-49-16.thread.md#:~:text=2019/12/21/19-49-34)

This test uses $_z40 to express an all-zeros object ID, which doesn't
work for SHA-256.  Use $ZERO_OID instead, which is the right size for
all hash values.
