For safety, it would probably be a good idea to check the exit status
of the 'sed' invocation in the for-loop:

```
    for i in "$1" "$2"
    do
        sed -e ... "$i" >"$i.compare" || return 1
    done &&
    ...

```

(Note, also, that I dropped the whitespace after the '>' operator.)
