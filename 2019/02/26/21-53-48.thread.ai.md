Thread identity: bugfix for `git describe` regarding `--contains --all` with pattern matching options.

Core problem: `git describe --contains --all` silently ignores `--match` and `--exclude` patterns when they should either be respected or rejected. The patch enforces the latter by making this invalid combination fail with an error. Tuomas Ahola independently confirmed the issue still exists in current Git, providing reproduction steps showing both `--match=bogus` and `--exclude="*"` have no effect when combined with `--contains --all`.

Current status: Jacob Keller has submitted an initial untested patch that adds validation to reject this option combination. The thread now has both the solution (Jacob's patch) and additional user-reported impact (Tuomas's experience).
