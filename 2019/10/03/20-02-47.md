> Git gui removes the '++' in front of the marker lines. It therefor
> already 'changes' the 'diff'. Though git-apply cannot handle such
> 'diffs' anyway.
>
> To get the diff3 style do:
>
> ```
> $ git merge --abort
> $ git -c merge.conflictStyle=diff3 merge branch
