-e, -i, -l and -n are all valid options for grep as well as git grep, 
yet git-grep refuses to operate if they appear in a specific order.

Observed:

$ git grep -e abc -lin
error: did you mean `--lin` (with two dashes)?

Expected:

$ git grep -e abc -lin
somefile
