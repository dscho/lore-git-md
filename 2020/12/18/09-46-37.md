-------------------------------------------------

= title =

EOF

git merge-file "$@" --diff3 -p LOCAL BASE REMOTE

In this example the conflicts are so trivial that git doesn't even

If instead in REMOTE you have this:

cat > REMOTE <<EOF
= temporary tite =

sentence.
EOF
-------------------------------------------------
