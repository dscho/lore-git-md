**Thread**: [thread](./../15/17-57-04.thread.md#:~:text=2020/10/17/07-54-51)

Some tests in these scripts are formatted using a very old style:
```
        test_expect_success \
            'title' \
            'body line 1 &&
            body line 2'

```

Updating the formatting to the modern style:
```
        test_expect_success 'title' '
            body line 1 &&
            body line 2
        '

```
