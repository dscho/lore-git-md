Something like:

```
  switch (c) {
  case LOFC_BLOB_NONE:
	return "blob:none":

  case LOFC__COUNT:
	/* not a real filter type; just a marker for counting the number */
	break;
  case LOFC_DISABLED:
	/* we have no name for "no filter at all" */
	break;
  }
  BUG(...);

```
